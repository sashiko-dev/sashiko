# Chinese Documentation Translations: maintainer notes

Review policy for patches that touch the Chinese kernel documentation under Documentation/translations/zh_CN/; the English Documentation/ tree remains the authoritative documentation, and the rules below follow Documentation/translations/zh_CN/how-to.rst and Documentation/translations/index.rst. The detailed contributor guide is Documentation/translations/zh_CN/process/index.rst.

- Report a translation that changes technical meaning: mistranslated commands, function, type or field names, numeric values, error codes, or code examples make readers act on different behavior than the English document describes.
- Report a patch that adds, removes, or changes documentation content only in zh_CN without the matching English change: Documentation/translations/index.rst requires every content addition, removal, or update to be applied to the English documents first, and translations accept only translation-related changes; content that exists only in zh_CN becomes a fork of the official documentation.
- Report a translated file whose location under Documentation/translations/zh_CN/ does not mirror the English source: tools/docs/checktransupdate.py derives the English counterpart by removing translations/zh_CN/ from the translated path, so a misplaced file is tracked against the wrong document.
- Report a missing or mismatched :Original: field: it must name the English document the file translates, as Documentation/<path> or a :ref: to that document's label, so reviewers can verify the correspondence and the header agrees with the path checktransupdate derives.
- Report a missing SPDX line or disclaimer include: how-to.rst requires the SPDX identifier and an include such as ../disclaimer-zh_CN.rst, which carries the translation disclaimer and must resolve from the file's location.
- Report a missing translator or proofreader field (:翻译:, :校译:, or the older :译者:): the fields identify who owns and has reviewed the text, so update requests and review records are lost without them.
- Report a translation commit that does not follow the documented subject and body form: a docs/zh_CN: subject and a Translate ... into Chinese. body make the patch recognizable in git log and the mailing-list archive.
- Report a translation commit without Signed-off-by: how-to.rst lists it as one of the four required lines, and the kernel DCO requires it.
- Report a translation commit that lacks Update the translation through commit <12-hex> ("<subject>") or references a merge commit instead of the last non-merge commit that changed the English file (git log --no-merges --oneline <english-path>): tools/docs/checktransupdate.py recognizes the 12-hex-digit hash after that phrase and uses it as the tracked English revision, so a missing or malformed line falls back to an author-date heuristic and misreports the translation.
- Report lines longer than 40 characters, lines whose width is visibly inconsistent within a paragraph, or lines that do not follow the English original's line breaks where practical: how-to.rst limits each line to 40 characters and asks for a consistent width aligned with the English source; occasional overlong lines are tolerated, so do not report width alone when the paragraph is otherwise consistent.
- Report a heading whose underline does not span the title's display width, counting one CJK character as two columns: how-to.rst aligns the underline this way, and a wrong underline changes the section hierarchy or triggers a Sphinx warning.
- Report RST modifiers that diverge from the English document: how-to.rst requires other modifiers to match the English source, and divergence breaks rendering and review comparison.
- Report a translated file that duplicates an English RST label: the English and zh_CN trees build together, so a duplicate label breaks cross-references; translated labels need a distinct name such as a _zh suffix or cn_ prefix.
- Report a :ref: target or toctree entry that does not resolve, or a toctree entry renamed from the English file name: stale references break the build, and toctree entries keep the English file names.
- Report a translated directory whose parent index does not link the new page in the same series: an index that never links the page leaves the translation unreachable in the built documentation.
- Report a patch that does not build: after the change, make cleandocs followed by make htmldocs (dependencies from tools/docs/sphinx-pre-install) must finish without warnings or errors naming the translated file.
- Report a patch that was not rebuilt cleanly or whose rendered output was not checked: cleandocs must be re-run before a rebuild because an incremental build may not re-emit warnings, and the pages under Documentation/output must be inspected for rendering problems.
- Report checkpatch errors or warnings other than the expected added, moved or deleted file(s), does MAINTAINERS need updating? warning: scripts/checkpatch.pl is the documented check for exported translation patches.
- Report a patch that is not delivered as plain-text mail through git send-email to the recipients from scripts/get_maintainer.pl, including the linux-doc list: HTML or webmail submissions are rejected, and patches sent outside that flow do not get reviewed.
- Report a series that translates the same directory as concurrent separate series, or that merges only part of a directory: how-to.rst documents one combined series per directory because separately merged series conflict and leave partial translations, and the translator should address every review comment in a new revision.
- Report a translation that is unedited machine output, for example terminology inconsistent with the existing zh_CN tree or untranslated fragments: how-to.rst states that the community does not accept pure machine translation; keep this to clear evidence rather than a stylistic impression.
- Do not report wording differences that adapt an English sentence to Chinese grammar when they preserve the meaning: Documentation/translations/index.rst explicitly allows phrasing that carries the same message in a different form.
- Do not report a translation-only patch for missing code, tests, or benchmark evidence: the relevant verification is a clean make htmldocs build and a clean checkpatch run.
