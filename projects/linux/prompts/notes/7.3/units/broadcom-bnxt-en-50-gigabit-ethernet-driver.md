# BROADCOM BNXT_EN 50 GIGABIT ETHERNET DRIVER

This unit provides core header definitions and subsystem modules for the Broadcom NetXtreme-C/E (`bnxt_en`) Ethernet driver, implementing the HWRM firmware command/response protocol, ethtool configuration and NVRAM flashing, devlink management and firmware health reporting, IEEE 802.1Qaz DCB, PTP hardware clock and packet timestamping, coredump collection, hwmon thermal monitoring, and DIM.

## Architecture & Data Flow
- In `__hwrm_send()`, owned contexts (`BNXT_HWRM_INTERNAL_CTX_OWNED`) must set `BNXT_HWRM_INTERNAL_RESP_DIRTY` on exit and zero `ctx->resp` on reuse; after polling sees a non-zero valid byte `*valid`, clear `*valid = 0` because it may overlap newer response fields. [F43, F74]
- `hwrm_req_dma_slice()` suballocates downward from `BNXT_HWRM_DMA_SIZE - ctx->allocated` after verifying `addr < req_addr + max_offset && req_addr + ctx->req_len <= addr`, with at most one `dma_alloc_coherent()` fallback in `ctx->slice_addr`. `hwrm_req_replace()` must free `ctx->slice_addr`, reset `ctx->allocated` and `ctx->req->resp_addr`, and recalculate `ctx->sentinel` via `hwrm_calc_sentinel()`. [F72, F95]
- Read `bp->num_tc` rather than `netdev_get_num_tc(bp->dev)` (which includes software-only mqprio/taprio TCs) when calculating hardware TX ring, channel, or TC counts. In `bnxt_get_channels()`, clamp `bp->num_tc` with `max(tcs, 1)` or guard with `if (tcs > 1)` before dividing `max_tx_rings`. [F64, F136]
- `cpr->cp_desc_ring` is indexed by `[CP_RING(RING_CMP(raw_cons))][CP_IDX(RING_CMP(raw_cons))]`, whereas `TX_CMP_VALID()` requires unmasked `raw_cons` to track `bp->cp_bit` wrap polarity. In `bnxt_poll_loopback()`, test `TX_CMP_VALID()` before `dma_rmb()` and `TX_CMP_TYPE()`, and advance `raw_cons` twice (`NEXT_RAW_CMP`) on 2-slot `CMP_TYPE_RX_L2_CMP` / `CMP_TYPE_RX_L2_V3_CMP` completions. In `bnxt_tx_avail()`, mask `READ_ONCE(txr->tx_prod) - READ_ONCE(txr->tx_cons)` with `bp->tx_ring_mask`. [F108, F123, F134]
- TPA aggregation ID masks (`RX_AGG_CMP_AGG_ID`, `RX_TPA_START_CMP_AGG_ID_P5`, `RX_TPA_END_CMP_AGG_ID_P5`) must remain 12-bit (`0x0fff << 16`) so upper P7 metadata bits are not mixed in. `BNXT_MAX_PAGE_MODE_MTU` must subtract `SKB_DATA_ALIGN((unsigned int)sizeof(struct skb_shared_info))` and stay wrapped in outer parentheses to preserve XDP redirect tailroom. [F92, F188]
- `struct bnxt_filter_base base` must be the first member of `bnxt_ntuple_filter` and `bnxt_l2_filter`. When iterating `bp->usr_fltr_list`, check `fltr->type` or `BNXT_ACT_RSS_CTX` before `container_of()`, and report every `BNXT_ACT_*` flag set during rule insertion in `bnxt_grxclsrule()`. [F82, F145]
- In `bnxt_add_l2_cls_rule()`, `bnxt_grxclsrule()`, and `bnxt_get_rxnfc()`, `fs->ring_cookie` encodes VF indices as 1-based (`vf - 1` / `(u64)(fltr_base->vf_idx + 1) << ETHTOOL_RX_FLOW_SPEC_RING_VF_OFF`); when `vf == 0`, the RX ring's VNIC is `bp->vnic_info[ring + 1]` (`vnic_info[0]` is `BNXT_VNIC_DEFAULT`). [F105, F137]
- In `bnxt_ptp_init()`, non-RTC mode (`!BNXT_PTP_USE_RTC(bp)`) must call `bnxt_ptp_adjfine_rtc(bp, 0)` alongside `bnxt_ptp_timecounter_init(bp, true)` to zero stale hardware PHC frequency adjustments. In `bnxt_ptp_rtc_timecounter_init()`, set `ptp->tc.cycle_last = ns & ptp->cc.mask` after `timecounter_init()`. In `bnxt_ptp_adjphc()`, call `bnxt_ptp_update_current_time(ptp->bp)` on success. [F68, F69, F130]
- `ptp->old_time` stores `ptp->current_time >> BNXT_HI_TIMER_SHIFT` (bits 47:24 in `u32`), so `bnxt_extend_cycles_32b_to_48b()` must cast `READ_ONCE(ptp->old_time)` to `u64` before shifting left by 24 and add `BNXT_LO_TIMER_MASK + 1` when `ts < (time & BNXT_LO_TIMER_MASK)`. In `bnxt_ptp_cfg_pin()`, validate `TSIO_PIN_VALID(pin)` and scale enable shift and `&req->pin0_state` / `&req->pin0_usage` offsets by `pin * 2`. [F100, F128]
- In `__bnxt_get_coredump()` and `bnxt_hwrm_dbg_dma_data()`, bound segment writes by `BNXT_COREDUMP_BUF_LEN(buf_len)` (`buf_len - sizeof(struct bnxt_coredump_record)`), clamp DMA copies to `min_t(u16, len, info->dest_buf_size - off)` and break if `copylen < len`, and on non-`-ENOBUFS` per-segment errors jump to `next_seg` rather than aborting. [F87, F124, F200]
- In `bnxt_hwrm_set_dcbx_app()`, `protocol_id` is big-endian (`cpu_to_be16(app->protocol)`), `data->len` is `sizeof(*fw_app) * n` while the DMA slice and `set->data_len` add `sizeof(*data)`, and on delete (`!add`), `if (n == i) goto set_app_exit;` must guard post-loop `fw_app` access. [F99, F119, F147]
- Callers of `bnxt_queue_remap(bp, tc_mask)` must verify `hweight(tc_mask) <= bp->max_lltc`. When `bnxt_queue_remap()` changes `bp->tc_to_qidx`, it must close/reopen the NIC if running and re-apply `bnxt_hwrm_queue_cos2bw_cfg()` and `bnxt_hwrm_queue_pri2cos_cfg()` if `bp->ieee_ets` is set. In `bnxt_ets_validate()`, iterate TSA/bandwidth validation only up to `max_tc`. [F77, F88, F125]
- When `bnxt_set_coalesce()` modifies `bp->stats_coal_ticks`, update `bp->current_interval` and perform a full `bnxt_close_nic(bp, true, false)` / `bnxt_open_nic(bp, true, false)` cycle if `BNXT_STATE_OPEN` is set. After firmware recovery or driver reinit, re-apply `dl->remote_reset` and `bnxt_ptp_reapply_pps()`. [F78, F81]
- In `bnxt_disable_an_for_lpbk()`, clear `req->flags` and `req->force_link_speed` to `0` after `hwrm_req_send()` on the caller's held request. In `bnxt_flash_package_from_fw_obj()`, keep `bnxt_find_nvram_item()` inside the defrag retry loop and reset `install->flags = 0`. [F75, F76]
- Speed tables below 400GB (`bnxt_nrz_speed_masks`, `bnxt_pam4_speed_masks`, `bnxt_nrz_speeds2_masks`) must retain `[__BNXT_LINK_SPEED_END - 1] = 0`. In `bnxt_update_speed()`, check `if (installed_media && mode_desired)` first, and for non-installed media only toggle `*speeds` when `!(*delta & speed_msk)`. [F106, F114]
- `bnxt_pcie_32b_entries[]` must be ordered by strictly ascending offsets for `bnxt_get_regs()`'s single-pass `le32_to_cpu()` / `le64_to_cpu()` swap. Bound extended port stats by `bp->fw_rx_stats_ext_size` / `bp->fw_tx_stats_ext_size`, and check `bp->fw_rx_stats_ext_size > BNXT_RX_STATS_EXT_NUM_LEGACY` in `bnxt_get_fec_stats()`. [F91, F107, F121]
- Keep `DEVLINK_PARAM_GENERIC(ENABLE_REMOTE_DEV_RESET, ...)` last in `bnxt_dl_params[]`, invert `ctx->val.vbool` for `BNXT_DEVLINK_PARAM_ID_GRE_VER_CHECK`, and set `req->index_0 = bp->pf.fw_fid - BNXT_FIRST_PF_FID` for `BNXT_NVM_FUNC_CFG`. Update `HWRM_API_FLAGS` for new `bnxt_hwrm_ctx_flags` and `bnxt_bstore_to_seg_id[]` when increasing `BNXT_CTX_V2_MAX`. [F85, F86, F102, F103, F117]

## Synchronization
- Always acquire `ptp->ptp_lock` with `irqsave`/`irqrestore` (`write_seqlock_irqsave`, `read_seqlock_excl_irqsave`), never `_bh` (used in hardirq under netpoll). Hold `write_seqlock_irqsave(&ptp->ptp_lock, flags)` for all `ptp->tc` accesses (`timecounter_init()`, `timecounter_read()`, `timecounter_adjtime()`, `bnxt_ptp_rtc_timecounter_init()`, and before updating `ptp->cc.mult` in `bnxt_ptp_adjfine()`), and call `__bnxt_refclk_read()` from `bnxt_cc_read()`. Outside write sections, BAR0 reads of `ptp->refclk_mapped_regs` must hold `read_seqlock_excl_irqsave(&ptp->ptp_lock, flags)` and abort with `-EIO` if `BNXT_STATE_IN_FW_RESET` is set. [F20, F21, F67, F170]
- In `bnxt_get_tx_ts_p5()`, write `txts_req->abs_txts_tmo` before `smp_wmb()` and `txts_req->tx_skb = skb`, paired with `smp_rmb()` in `bnxt_stamp_tx_skb()`. Serialize `ptp->tx_avail` and `ptp->txts_prod` under `spin_lock_bh(&ptp->ptp_tx_lock)`. In `bnxt_ptp_free_txts_skbs()`, call `ptp_cancel_worker_sync(ptp->ptp_clock)` before draining `txts_req[]` or resetting `tx_avail`/`txts_cons`, and `ptp_schedule_worker()` afterward. [F22, F160, F172]
- Lock ordering: `rtnl_lock()` before `netdev_lock(bp->dev)`, and `bp->link_lock` inside `netdev_lock(bp->dev)`. Paths holding `netdev_lock(bp->dev)` (`bnxt_dl_reload_down()`, `bnxt_dl_reload_up()`) must call `netif_close(bp->dev)` instead of `dev_close(bp->dev)`. Callers of `bnxt_sriov_cfg()` must hold `rtnl_lock`. [F32, F174, F177]
- In `__hwrm_send()`, issue `wmb()` before writing the request and doorbell, and `dma_rmb()` before reading `*valid` after polling `READ_ONCE(ctx->resp->resp_len)` and `READ_ONCE(ctx->resp->seq_id)`. In `bnxt_db_write*()`, use 64-bit `bnxt_writeq*()` (under `bp->db_lock` on 32-bit builds) on `BNXT_FLAG_CHIP_P5_PLUS`, and 32-bit `writel*()` (doubled when `BNXT_FLAG_DOUBLE_DB`) on older chips. [F27, F157]
- Enclose `bp->l2_fltr_hash_tbl` and `bp->ntp_fltr_hash_tbl` lookups in `rcu_read_lock()` / `rcu_read_unlock()`, and drop `rcu_read_unlock()` in `bnxt_srxclsrldel()` before blocking HWRM filter frees. [F37]
- Serialize `fw_health->severity` and `fw_health->remedy` under `fw_health->lock`, unlocking it before `devlink_health_report()` or `devlink_health_reporter_state_update()` in `bnxt_devlink_health_fw_report()` and `bnxt_dl_health_fw_status_update()` (whereas `bnxt_fw_diagnose()` holds `h->lock`, so `bnxt_fw_dump()` must not take it). [F34, F178]
- Invoke `bnxt_hwmon_notify_event()` only from process context (`bnxt_sp_task()` via `BNXT_THERMAL_THRESHOLD_SP_EVENT`), never softirq/NAPI. Gate hardware ring updates in `bnxt_set_coalesce()` on `test_bit(BNXT_STATE_OPEN, &bp->state)` rather than `netif_running(dev)`. [F36, F169]

## Object Lifetimes
- `__hwrm_req_init()` requests are freed by `hwrm_req_send()` unless held via `hwrm_req_hold()`; callers holding a request or aborting before `hwrm_req_send()` (including when `hwrm_req_dma_slice()` returns `NULL`) must call `hwrm_req_drop()`. In `bnxt_hwrm_set_dcbx_app()`, hold `get` until `hwrm_req_send(bp, set)` completes. `bnxt_hwrm_dbg_dma_data()` always drops `msg` and frees/clears `info->dest_buf` on error. [F1, F7, F16, F41]
- When `!(bp->fw_cap & BNXT_FW_CAP_SHORT_CMD)` and `len <= BNXT_HWRM_MAX_REQ_LEN`, `hwrm_req_replace()` borrows `ctx->req = new_req` without copying, requiring `new_req` to outlive `req`, and callers must still pass the original `req` pointer to all HWRM API calls. [F4, F140]
- Convert `IS_ERR()` returns from `hwmon_device_register_with_info()`, `ptp_clock_register()`, and `devlink_health_reporter_create()` to `NULL`, and clear `fw_health->fw_reporter`, `ptp->ptp_clock`, and `ptp->ptp_info.pin_config` to `NULL` on teardown. [F11, F14, F45]
- In `bnxt_ptp_init()`, initialize `ptp->ptp_lock` and `ptp->ptp_tx_lock` before calling `bnxt_ptp_timecounter_init()` or `bnxt_ptp_init_rtc()`. In `bnxt_ptp_free()` / `bnxt_ptp_clear()`, call `ptp_clock_unregister(ptp->ptp_clock)` before freeing `pin_config` and calling `bnxt_unmap_ptp_regs(bp)`. [F19, F25]
- Complete port/param setup before `devlink_register(dl)` in `bnxt_dl_register()`, and call `devlink_unregister(dl)` before tearing them down in `bnxt_dl_unregister()`. Call `bnxt_hwrm_temp_query(bp, NULL)` before `hwmon_device_register_with_info()` in `bnxt_hwmon_init()`. [F33, F40]
- Unwind errors after `bp->num_rss_ctx++` in `bnxt_create_rxfh_context()` via `bnxt_del_one_rss_ctx(bp, rss_ctx, true)`. In `bnxt_add_ntuple_cls_rule()`, unwind errors before `bnxt_insert_ntp_filter()` at `ntuple_err:` (`atomic_dec(&l2_fltr->refcnt)` and `kfree(new_fltr)`), and errors after it via `bnxt_del_ntp_filter(bp, new_fltr)`. [F17, F18]

## API Contracts
- Call `__hwrm_req_init()` and `hwrm_req_send*()` only from sleepable context. Call `hwrm_req_alloc_flags()` with `__GFP_ZERO` before `hwrm_req_dma_slice()` if a fallback `dma_alloc_coherent()` slice must be zeroed. Use `bnxt_hwrm_func_cfg_short_req_init()` for basic `HWRM_FUNC_CFG` requests. [F42, F96, F168]
- `bnxt_hwrm_port_ts_query()` takes `txts_tmo` in ms, converts to us (`0` -> `BNXT_PTP_QTS_TIMEOUT`), and clamps to `BNXT_PTP_QTS_MAX_TMO_US` (`65535U`). `bnxt_map_regs()` takes a 1-based GRC window `reg_win` and requires all registers to share `BNXT_GRC_BASE_MASK`. Set `ptp_info->n_ext_ts` and `n_per_out` to `1` and reject `PTP_PF_PHYSYNC` or `usage > BNXT_PPS_PIN_PPS_OUT` in `bnxt_ptp_verify()`. [F51, F52, F202]
- Reject non-zero `rxfh->hfunc != ETH_RSS_HASH_TOP` with `-EOPNOTSUPP` in `bnxt_rxfh_context_check()` and `bnxt_set_rxfh()`. In `bnxt_create_rxfh_context()`, populate default indirection table, `ETH_RSS_HASH_TOP`, and `rss_hash_key` before `bnxt_modify_rss()`. [F90, F187]
- Use `TX_BD_CNT(n)` so `TX_MAX_BD_CNT` (32) wraps to 0 without overflowing into `TX_BD_FLAGS_LHINT`. Pass bit count `nvm_num_bits` to `req->data_len` in `__bnxt_hwrm_nvm_req()`, and null-check optional out-parameters in `bnxt_find_nvram_item()`. [F58, F61, F62]
- `bnxt_dcbnl_setdcbx()` returns `1` on error and `0` on success. Multiply `u8` Celsius values by `1000` in hwmon readers, scale coalesced frames by `hw_coal->bufs_per_record`, preserve `tx_lpi_timer` when EEE is disabled in `bnxt_get_eee()`, and clear succeeded `BNXT_FW_RESET_*` bits in `*flags` in `bnxt_reset()`. [F192, F194, F196, F198, F199]

## Error Handling
- Null-check `bp->ptp_cfg` in all entry points outside `ptp_clock_info` callbacks. Roll back `ptp->rx_filter`, `ptp->rxctl`, and `ptp->tx_tstamp_en` if `bnxt_hwrm_ptp_cfg()` fails in `bnxt_hwtstamp_set()`, and clear `ptp->tstamp_filters` and `bp->ptp_all_rx_tstamp` on failure in `bnxt_ptp_cfg_tstamp_filters()`. [F46, F50]
- In `bnxt_ptp_ts_aux_work()`, `break` without advancing `cons` or `tx_avail` when `!tx_skb` or `bnxt_stamp_tx_skb()` returns `-EAGAIN`, and skip `IS_ERR(tx_skb)` via `goto next_slot`. Check `!IS_ERR_OR_NULL(tx_skb)` in `bnxt_ptp_free_txts_skbs()`. On timeout in `bnxt_stamp_tx_skb()`, log with `netdev_warn_once()`, free `tx_skb`, and set `tx_skb = NULL`. [F47, F122, F186]
- Check `netif_running(bp->dev)` (`-EAGAIN`) in `bnxt_rxfh_context_check()` and `bnxt_srxclsrlins()`, and null-check `bp->bnapi` and `bp->vnic_info` in `bnxt_get_ethtool_stats()` and `bnxt_get_rxfh()`. Zero trailing `bp->rss_indir_tbl_entries - tbl_size` entries in `bnxt_modify_rss()`, and check `IS_ERR(fltr)` on `bnxt_alloc_new_l2_filter()`. [F54, F55, F63]

## External Contracts
- Set `bnxt_ethtool_ops.rxfh_max_num_contexts = BNXT_MAX_ETH_RSS_CTX + 1`. In `bnxt_get_eeprom()` and `bnxt_set_eeprom()`, reject 1-based directory `index == 0` with `-EINVAL` and pass `index - 1` to helpers. Keep `hwrm_port_phy_qcfg_output_compat` at 96 bytes (clearing `SPEEDS2_SUPPORTED` when forwarding to VFs), and write upgraded `ptp->rx_filter` back to `stmpconf->rx_filter` in `bnxt_hwtstamp_set()`. [F89, F93, F104, F185]

## Known Pitfalls
- In `__hwrm_send()`, polling without a completion ring sets `token = NULL` when `token->state == BNXT_HWRM_DEFERRED`; do not dereference `token` unconditionally afterward. [F6]
- Re-read `refclk_mapped_regs[0]` if `refclk_mapped_regs[1]` changes in `__bnxt_refclk_read()`, cast upper 32-bit words to `u64` before shifting in `__bnxt_refclk_read()`, `BNXT_GET_TX_TS_48B_NS`, and `EVENT_PPS_TS`, and define all `BNXT_FW_CAP_*` flags with `BIT_ULL()`. [F127, F129, F135]
- Map `ptp->refclk_regs` via GRC window `BNXT_PTP_GRC_WIN` on `BNXT_CHIP_P5(bp)` vs direct BAR0 offsets on `BNXT_FLAG_CHIP_P7`. Pair `ALL_RX_TS_CAPTURE_ENABLE` with `ALL_RX_TS_CAPTURE_DISABLE` when `!(bp->fw_cap & BNXT_FW_CAP_RX_ALL_PKT_TS)`. Check `!time_after_eq(now, deadline)` before subtracting `now` in PTP timeout calculations. [F113, F133, F159]
- Compare `BNXT_LIVEPATCH_STATE(flags)` with `==` rather than `&`. In `bnxt_reset()`, check `(req & BNXT_FW_RESET_CHIP) == BNXT_FW_RESET_CHIP`, and guard `BNXT_FW_RESET_AP` with `!BNXT_CHIP_P4_PLUS(bp)`. Divide `BNXT_TX_PORT_STATS_BYTE_OFFSET` by 8 when advancing a `u64 *` stats pointer. [F115, F116, F143, F167]
- Branch on `bnxt_get_media(link_info)` in `bnxt_get_link_ksettings()`, pass `unsigned long fw_mask` to `for_each_set_bit()` in `__bnxt_get_ethtool_speeds()` (skipping `0` sentinels in `bnxt_link_modes[][][]`), and return `bnxt_get_nr_rss_ctxs(bp, bp->rx_nr_rings) * BNXT_RSS_TABLE_ENTRIES_P5` from `bnxt_get_rxfh_indir_size()` on P5+. Bound `resp->test_name[i]` with `BNXT_MAX_TEST` / `ETH_GSTRING_LEN` and NUL-terminate HWRM version arrays with `HWRM_FW_VER_STR_LEN`. [F110, F148, F149, F150, F165]
