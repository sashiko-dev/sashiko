# QCOM AUDIO (ASoC) DRIVERS

This unit contains Qualcomm ASoC codec and smart speaker amplifier drivers (PM8916, PM4125, WCD9335/934x/937x/938x/939x, WSA881x/883x/884x), shared Class-H and MBHC libraries, Low-Power Audio Subsystem (LPASS) CPU/DMA/HDMI drivers, machine sound cards, and QDSP6 APR/GPR (q6afe, q6adm, AudioReach) IPC layers.

## Architecture & Data Flow
- On multi-device codecs (`pm4125`, `wcd937x`, `wcd938x`, `wcd939x`), master platform drvdata is `struct *_priv *` while SoundWire slave (`rxdev`/`txdev`) drvdata is `struct *_sdw_priv *`. On `wcd934x`, `pdev->dev` drvdata is `struct wcd934x_codec *` and `dev->parent` is `struct wcd934x_ddata *`. On `wcd9335`, both `dev_get_drvdata(comp->dev)` and `snd_soc_component_get_drvdata(comp)` return `struct wcd9335_codec *`. [F86, F87, F207, F208, F330]
- On `pm4125`, `wcd937x`, `wcd938x`, and `wcd939x`, only the TX SoundWire slave (`is_tx`) allocates `regmap` (`NULL` on RX). TX `regmap` (and `wsa884x->regmap`) must start in `regcache_cache_only(regmap, true)` at probe until `SDW_SLAVE_ATTACHED` syncs it; shared PM/status callbacks must guard `if (regmap)` and pair `regcache_cache_only(true)` + `regcache_mark_dirty()` in runtime suspend with `regcache_cache_only(false)` + `regcache_sync()` in resume. [F32, F96, F210, F211, F295, F486]
- SoundWire hardware port numbers (`port_num`, `port_idx`, `prepare_ch->num`) are 1-based while driver arrays (`ch_info[]`, `port_enable[]`, `port_prepared[]`, `port_config[]`) are 0-based: index `port_config`/`port_prepared` at `port_num - 1`, populate DT port maps starting at `&pdev->m_port_map[1]`, and convert 1-based DT channel indices via `*_SWRM_CH_MASK` (`BIT(ch_idx - 1)`). [F36, F81, F236, F237, F279]
- In `pm4125`, `wcd937x`, `wcd938x`, `wcd939x`, `wsa881x`, `wsa883x`, and `wsa884x` `*_hw_params()`, reset `active_ports = 0` (and `sconfig.ch_count = 1` on WCD937x/8x/9x) before compacting non-zero `port_config` entries into `port_config[active_ports++]` for `sdw_stream_add_slave()`. For an `N`-element `sdw_dpn_prop` array, set `source_ports`/`sink_ports` to `GENMASK(N - 1, 0)`, not `GENMASK(N, 0)`. [F72, F168, F184, F300, F302, F464]
- In `pm4125`, `wcd9335`, `wcd934x`, `wcd937x`, `wcd938x`, and `wcd939x` `*_micbias_control()`, `MIC_BIAS_1..4` are 1-based (`micb_index = micb_num - 1`, validated `< MAX_MICBIAS`). `MICB_PULLUP_ENABLE` must only write pullup bits when `micb_ref[micb_index] == 0 && pullup_ref[micb_index] > 0`, and `MICB_DISABLE` reaching `micb_ref == 0` must switch to pullup mode (not off) if `pullup_ref > 0`. [F57, F109, F174, F306]
- In `wcd934x`, `wcd937x`, `wcd938x`, and `wcd939x` `*_wcd_mbhc_calc_impedance()`, `ANA_MBHC_BTN5..7`, `MBHC_CTL_CLK`, `MBHC_NEW_ZDET_ANA_CTL`, and `ANA_MBHC_ELECT` FSM_EN must be saved before zdet ramps and restored (with `ANA_MBHC_MECH`) at `zdet_complete` on all exit paths. If the left-channel ramp is floating (`ZDET_FLOATING_IMPEDANCE` or `> ZDET_VAL_100K`), reset `zdet_param_ptr = &zdet_param[1]` and `d1 = d1_a[1]` before the right-channel ramp. [F176, F196, F290, F316]
- In `wcd9335` and `wcd934x`, `wcd->tx_chs[port_id].list` and `rx_chs[port_id].list` are shared across DAIs: `slim_tx_mixer_put` and `slim_rx_mux_put` must use `list_del_init()` (never `list_del()`) and guard additions with `list_empty()` / `tx_port_value[port_id]` checks. [F7, F136, F170]
- In `wcd937x` and `wcd938x`, `wcd->ear_rx_path` must be latched from `DIGITAL_CDC_EAR_PATH_CTL` during `SND_SOC_DAPM_PRE_PMU` and reused across `POST_PMU`, `PRE_PMD`, and `POST_PMD` to toggle the matching AUX or HPHL clocks, compander, and PDM watchdog IRQ. [F197, F313]
- In `wcd937x`, `wcd938x`, and `wcd939x`, moisture detection (`MBHC_NEW_CTL_2`) must be forced to `R_OFF` if `!mbhc_cfg.hphl_swh` (NC jack), `mbhc_cfg.moist_rref == R_OFF`, or (on `wcd939x`) `typec_analog_mux` is true. [F180, F291]
- In `lpass-cpu.c`, playback and capture on the same MI2S DAI share `LPAIF_I2SCTL_REG(v, id)`: runtime DAI ops must only touch `spken`/`spkmode`/`spkmono` for playback and `micen`/`micmode`/`micmono` for capture, and `lpass_cpu_daiops_hw_params` must downgrade multi-line SD modes only in a local `mode` variable without overwriting `drvdata->mi2s_*_sd_mode[id]`. [F420, F458]
- In `lpass-platform.c` and `lpass-hdmi.c`, updates to shared `IRQEN` registers must use `regmap_update_bits` masked with `LPAIF_IRQ_ALL(ch)` and `IRQCLEAR` writes must use `regmap_write_bits`. `lpass_dma_interrupt_handler` must test `LPAIF_IRQ_PER`, `LPAIF_IRQ_XRUN`, `LPAIF_IRQ_ERR`, and `val` with separate `if` statements (not `else if`). All `IRQCLEAR`, `IRQSTAT`, and `*DMACURR` (plus DP-reset HDMI TX) registers must be marked volatile, and `.max_register` must be set on all four `REGCACHE_FLAT` regmap configs before `devm_regmap_init_mmio`. [F424, F455, F484, F495, F496]
- In `audioreach_populate_graph()`, `mp_data->mod_prop_obj[nmodule++]` must be populated before `if (!module->max_op_port) continue;`, and `mlobj` must advance by `APM_MOD_LIST_OBJ_PSIZE(mlobj, container->num_modules)` rather than array indexing `mod_list_obj[ncontainer]`. [F453, F454]

## Synchronization
- In `wcd-mbhc-v2.c`, `wcd_cancel_hs_detect_plug()` (`wcd_mbhc_cancel_pending_work()`), `wcd_mbhc_report_plug()`, `wcd_mbhc_adc_detect_plug_type()`, and `wcd_schedule_hs_detect_plug()` require `mbhc->lock` held. Because `wcd_mbhc_cancel_pending_work()` drops and re-acquires `mbhc->lock` across `cancel_work_sync()`, `mbhc_plug_detect_fn()` must set `mbhc->in_swch_irq_handler = true` before calling it and read `mbhc->current_plug` only after it returns. [F2, F13, F16]
- In `wcd-mbhc-v2.c`, `wcd_btn_long_press_fn()` (`mbhc->mbhc_btn_dwork`) must never acquire `mbhc->lock` because `wcd_cancel_btn_work()` calls `cancel_delayed_work_sync()` under `mbhc->lock`. Disabling `mbhc_hs_ins_intr` or `mbhc_hs_rem_intr` from inside MBHC IRQ handlers or under `mbhc->lock` must use `disable_irq_nosync()`. [F113, F114]
- In `wsa883x_get_temp()` and `wsa884x_get_temp()`, hold `sp_lock`: when `pa_on` is true, return cached `temperature * 1000` (millidegrees) without touching `PA_FSM_BYP` or `TADC` registers; when `!pa_on`, balance `pm_runtime_resume_and_get()` with `pm_runtime_put_autosuspend()`, clear `PA_FSM_BYP`/`PA_FSM_BYP0` (and restore `TEMP_VALUE_RD_EN_MASK` on WSA884x) before any exit, check `d1 != d2` before dividing by `d2 - d1`, and validate `in_range(val, LOW_TEMP_THRESHOLD, ...)` before updating `temperature`. [F251, F298, F308, F368, F385, F426, F465, F466, F499]
- In `q6adm.c` and `q6afe.c`, accesses to `adm->copps_list`/`adm->copp_bitmap[port_idx]` and `afe->port_list` must hold `copps_list_lock`/`port_list_lock` via `spin_lock_irqsave()`: `q6adm_alloc_copp()` must use `GFP_ATOMIC`, and `q6adm_find_copp()`, `q6adm_find_matching_copp()`, and `q6afe_find_port()` must store matches in a separate `ret` pointer (not the loop cursor) and call `kref_get()` before unlocking. [F390, F391, F461, F478, F501]
- In `audioreach_send_cmd_sync()`, `q6adm_apr_send_copp_pkt()`, `q6adm_matrix_map()`, and `afe_apr_send_pkt()`, `result->opcode` and `result->status` must be zeroed under the command mutex before sending the packet and calling `wait_event_timeout()`; `q6adm_callback()` must never acquire `adm->lock`. [F392, F463]
- In `wcd934x.c`, `swclk_gate_ops` must wire `swclk_gate_enable`/`disable` to `.prepare`/`.unprepare` (never atomic `.enable`/`.disable`), `wcd->sysclk_mutex` must never nest with `wcd->micb_lock`, and `wcd934x_swrm_clock(wcd, false)` must clear `WCD934X_CDC_SWR_CLK_EN_MASK` before calling `__wcd934x_cdc_mclk_enable(wcd, false)`. [F148, F227, F231]
- In `lpass-cpu.c`, `lpass_cpu_daiops_trigger()` runs in atomic context and must unconditionally call `clk_enable()`/`clk_disable()` on `mi2s_bit_clk[id]` (never `clk_prepare_enable()` or `clk_set_rate()`, and not gated on `mi2s_was_prepared[id]`). [F498, F507]

## Object Lifetimes
- In `wcd9335_trigger()` and `wcd934x_trigger()`, `SNDRV_PCM_TRIGGER_STOP`, `SUSPEND`, and `PAUSE_PUSH` must call `slim_stream_disable()` before `slim_stream_unprepare()`. In `*_slim_set_hw_params()`, free and set `cfg->chs = NULL` on error paths so `hw_free` or `POST_PMD` does not double-free or leak it. [F1, F8, F132, F157]
- `wcd_mbhc_init()` must allocate `struct wcd_mbhc` with non-devm `kzalloc()`, initialize `mbhc->lock` and work structs before requesting the 7 IRQs with non-devm `request_threaded_irq()`, and `wcd_mbhc_deinit()` must `free_irq()` all 7 IRQs before cancelling work and freeing `mbhc`. [F17, F92]
- `wcd_clsh_ctrl_alloc()` uses non-devres `kzalloc()` and returns `ERR_PTR(-ENOMEM)`: callers (`wcd9335`, `wcd934x`, `wcd937x`, `wcd938x`, `wcd939x`) must check `IS_ERR()` and call `wcd_clsh_ctrl_free()` on probe failure and removal. [F5, F216, F242]
- In `wcd938x_bind()` and `wcd939x_bind()`, after `component_bind_all()`, `device_link_add()` (`DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME`) between `dev`, `rxdev`, and `txdev` and `of_sdw_find_device_by_node()` references must be unwound in reverse order (`device_link_remove()`, `put_device()`, `component_unbind_all()`) on error and in `.unbind`, and `*_remove()` must balance runtime PM (`pm_runtime_disable()`, `pm_runtime_set_suspended()`, `pm_runtime_dont_use_autosuspend()`). [F241, F337, F353]
- In `wcd937x`, `wcd938x`, and `wcd939x` `*_soc_codec_probe()`, PDM watchdog IRQs must be disabled with `disable_irq_nosync()` immediately after `request_threaded_irq()` so `enable_irq()` in PA `POST_PMU` and `disable_irq_nosync()` in `PRE_PMD` stay balanced. [F217, F248]

## API Contracts
- `audioreach_alloc_*_pkt()` returns a `kzalloc`-allocated `struct gpr_pkt *` or `ERR_PTR(-ENOMEM)` (never `NULL`): callers must check `IS_ERR(pkt)` and always `kfree(pkt)` after sending. `audioreach_alloc_cmd_pkt()` and `audioreach_alloc_apm_cmd_pkt()` include both `GPR_HDR_SIZE` and `APM_CMD_HDR_SIZE`, whereas `audioreach_alloc_pkt()` and `audioreach_alloc_apm_pkt()` include only `GPR_HDR_SIZE`. [F379, F397, F442]
- `snd_soc_component_write_field()` and `wcd_mbhc_write_field()` shift the value by `__ffs(mask)` and require unshifted field values, whereas `snd_soc_component_update_bits()` and `regmap_update_bits()` require pre-shifted values. [F80, F163, F281]
- `wcd_mbhc_init()` and `wcd_mbhc_start()` store borrowed pointers to `mbhc_cb`, `intr_ids`, `fields` (`>= WCD_MBHC_REG_FUNC_MAX` entries), `cfg`, and `jack` without copying; assign `mbhc->cfg` and `mbhc->jack` before `wcd_mbhc_initialise()`. Non-zero `hs_thr`/`hph_thr` requires positive `cfg->micb_mv`, `get_micbias_val` must write positive mV into `*mb` (threshold helpers divide by both), and `set_btn_thr` must reject `num_btn > WCD_MBHC_DEF_BUTTONS` (8). [F4, F18, F31, F59, F78, F79, F84, F117, F307]
- In `pm4125`, `wcd9335`, `wcd934x`, and `wcd937x` `*_get_channel_map()`, callers may pass `NULL` for the unused direction: playback DAIs must only access `rx_num`/`rx_slot` and capture DAIs must only access `tx_num`/`tx_slot`. [F39, F160]
- SoundWire `struct regmap_config` definitions (`wcd939x`, `wsa881x`, `wsa883x`) must not set `.can_multi_write = true`, and `snd_soc_dai_driver` definitions must keep `.rate_min <= .rate_max` and `.channels_min <= .channels_max`. [F363, F364]
- In `q6afe.c` and `q6adm.c`, `struct q6afe *` and `struct q6adm *` live on the parent `apr_device`, so exported functions taking a child `struct device *dev` must call `dev_get_drvdata(dev->parent)`. Internal lookups (`q6afe_find_port()`, `q6adm_find_copp()`) return `NULL`, while open/get APIs (`q6afe_port_get_from_id()`, `q6adm_alloc_copp()`, `q6adm_open()`) return `ERR_PTR`. [F398, F477]

## Error Handling
- `wcd938x_mbhc_init()` and `wcd939x_mbhc_init()` must check `IS_ERR(wcd_mbhc_init())` and propagate `PTR_ERR()`, whereas `wcd934x_mbhc_init()` must reset `wcd->mbhc = NULL` on `IS_ERR()` because `wcd934x_comp_probe()` ignores its return value and downstream callers only check for `NULL`. [F153, F265]
- `q6adm_apr_send_copp_pkt()` and `q6adm_matrix_map()` return positive remaining jiffies from `wait_event_timeout()` on success, so callers must check `ret < 0` (not `if (ret)`). In `q6adm_open()`, if `q6adm_device_open()` fails after `q6adm_alloc_copp()`, release `copp` via `kref_put(&copp->refcount, q6adm_free_copp)`. [F399, F408]
- In `lpass-cdc-dma.c`, `__lpass_get_dmactl_handle()` leaves `*dmactl` unmodified when `dai_id` is unrecognized, so callers must initialize `dmactl = NULL` before calling it and check `if (!dmactl)`. [F409]

## External Contracts
- In `audioreach.c`, compound APM packets (`APM_CMD_GRAPH_OPEN`, multi-parameter `APM_CMD_SET_CFG`) must align each parameter section to 8 bytes (`ALIGN(..., 8)`) and set `param_data->param_size` to the aligned size minus `APM_MODULE_PARAM_DATA_SIZE`. In `audioreach_i2s_set_media_format()` and `audioreach_codec_dma_set_media_format()`, populate `intf_cfg->cfg.lpaif_type = module->hw_interface_type`. [F411, F441]
- In `lpass_platform_pcmops_prepare()`, `LPAIF_DMABUFF_REG` and `LPAIF_DMAPER_REG` take buffer and period sizes in 32-bit words minus one (`(bytes >> 2) - 1`), whereas `LPAIF_DMABASE_REG` and `LPAIF_DMACURR_REG` report byte addresses. [F414]

## Known Pitfalls
- In `wcd9335` and `wcd934x`, SLIMbus RX channels store `ch->port` offset by `*_RX_START` (16..28) while `ch->shift` holds the 0-based RX index (0..12): subtract `*_RX_START` when indexing RX arrays or `SLIM_PGD_PORT_INT_EN0`, and in `wcd9335_slimbus_irq()` use `port_id = (j >= 16 ? j - 16 : j)` for `INT_EN0`/`INT_TX_EN0` but raw bit `j` for `INT_RX_SOURCE0`/`INT_CLR_RX_0`. [F60, F77, F187]
- In `lpass-platform.c` and `lpass-cdc-dma.c`, `regmap_fields_write()` on capture (`wr_dmactl`, `rxtx_wr_dmactl`, `va_wr_dmactl`) must use the 0-based index `dma_ch - v->*wrdma_channel_start` from `__lpass_get_id()`, whereas `LPAIF_DMA*_REG`, `LPAIF_IRQ_ALL()`, and `drvdata->*substream[]` use raw `pcm_data->dma_ch`. In `lpass-cpu.c`, per-port `drvdata->mi2s_*` arrays are indexed by `variant->dai_driver[i].id`, whereas `variant->dai_*_clk_names` are indexed by loop counter `i`. [F421, F435]
- In `wcd934x`, `wcd937x`, `wcd938x`, and `wcd939x` `*_mbhc_get_result_params()`, `denom = (x1 * d1) - (1 << (14 - noff))` must be a signed 32-bit integer checked for `denom > 0` before dividing, and ramp polling loops must be bounded by `*_ZDET_NUM_MEASUREMENTS`. Callers of `*_wcd_mbhc_qfuse_cal()` must divide milliohm ramp values by 1000 first, and on WCD938x/939x mask sign-magnitude bit 7 (`q1 & 0x7F`) before scaling `q1`. [F200, F201, F226, F310, F317, F323]
- In `wcd_mbhc_initialise()` and `wcd_correct_swch_plug()`, which proceed on `-EACCES` and unconditionally call `pm_runtime_put_autosuspend()` on exit, acquire runtime PM with `pm_runtime_get_sync()` (and `pm_runtime_put_noidle()` on other errors), never `pm_runtime_resume_and_get()`. [F94]
- In `audioreach.c`, topology fields in `struct audioreach_module_priv_data` (such as `module->data->size`) are `__le32` and require `le32_to_cpu()`; in `audioreach_mfc_set_media_format()`, `media_format->channel_mapping[]` is `uint16_t` while `cfg->channel_map[]` is `u8`, so copy elements in a loop rather than `memcpy()`. [F440, F476]
