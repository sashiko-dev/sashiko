# NTB DRIVER CORE

The NTB (Non-Transparent Bridge) driver core and ecosystem provide a bus abstraction (`ntb_bus`), MSI-over-MW library (`ntb_msi`), queue-pair transport (`ntb_transport`, `ntb_transport_bus`), virtual Ethernet driver (`ntb_netdev`), hardware drivers (`ntb_hw_epf`, `ntb_hw_idt`), and test clients (`ntb_tool`, `ntb_perf`, `ntb_pingpong`, `ntb_msi_test`).

## Architecture & Data Flow
- In `ntb_transport_qp`, `qp->remote_rx_info` is NULL until `ntb_transport_setup_qp_mw()` runs at link-up; code reachable while link is down (`ntb_qp_link_down_reset()`, `debugfs_read()`) must check `qp->remote_rx_info` or `qp->link_is_up` before dereferencing it or calling `ntb_transport_tx_free_entry()`. Free TX entries are `tail >= head ? tail - head : qp->tx_max_entry + tail - head`, and `remote_rx_info->entry` must be initialized/reset to `qp->rx_max_entry - 1` so `head == tail` means 0 free. [F41, F67]
- `ntb_transport_init_queue()`, `ntb_transport_setup_qp_mw()`, and `ntb_transport_link_work()` must cap `nt->mw_vec[i].phys_size` at `max_mw_size` (when non-zero), compute `num_qps_mw` as `qp_count / mw_count + (mw_num < qp_count % mw_count ? 1 : 0)` matching `QP_TO_MW`, and cap `rx_max_frame`/`tx_max_frame` at `rx_size / 2` and `tx_size / 2` so `rx_max_entry`/`tx_max_entry` are at least 2. [F51, F97, F98]
- Each `ntb_transport` MW slice reserves `sizeof(struct ntb_rx_info)` at the end and each frame places `struct ntb_payload_header` at `offset + max_frame - sizeof(struct ntb_payload_header)`, so `ntb_process_tx()` and `ntb_transport_max_size()` must subtract `sizeof(struct ntb_payload_header)` from `tx_max_frame`, and `ntb_process_rxc()` must check `hdr->len > entry->len`. In `ntb_process_rxc()`, test `!(hdr->flags & DESC_DONE_FLAG)` before `hdr->flags & LINK_DOWN_FLAG`, and cast `qp->rx_pkts` to `u32` when comparing with `hdr->ver`. [F68, F86, F100, F110]
- In `ntb_rx_copy_callback()` and `ntb_tx_copy_callback()`, `DMA_TRANS_READ_FAILED`, `DMA_TRANS_WRITE_FAILED`, and `DMA_TRANS_ABORTED` must `return;` immediately after calling `ntb_memcpy_rx()` or `ntb_memcpy_tx()`, because those helpers synchronously re-invoke the callback with `res == NULL`. [F87]
- `ntb_transport_link_cleanup()` must zero local scratchpads via `ntb_spad_write()`, and `ntb_transport_link_work()` must write `VERSION` to the peer scratchpad last after `MW0_SZ_*`, `NUM_MWS`, and `NUM_QPS`. When `ntb_msi_init()` is used in `ntb_transport_probe()`, it reserves the last MW per peer, so `ntb_transport_probe()` must decrement `mw_count` and `qp_count` by 1 and reserve `BIT_ULL(qp_count)` in `nt->msi_db_mask`. [F56, F58]
- In `ntb_perf.c`, `perf_init_service()` requires `ntb_peer_mw_count(perf->ntb) >= perf->pcnt`, while scratchpad service requires `PERF_SPAD_CNT(perf->pcnt)` (`3 * (perf->pcnt + 1)`) scratchpads and `GENMASK_ULL(perf->pcnt, 0)` doorbell bits. In `perf_init_peers()`, when `perf->pcnt == 1` and both local and peer port numbers are `0`, reset `perf->gidx` and `perf->peers[0].gidx` to `0`. [F76, F83]
- In `ntb_perf.c`, `perf_setup_inbuf()` must check `peer->inbuf_size <= size_max` (from `ntb_mw_get_align()`) before allocating `peer->inbuf`. When `PERF_CMD_CLEAR` runs in `perf_service_work()`, it must call `init_completion(&peer->init_comp)`, clear `PERF_STS_DONE` in `peer->sts`, and call `perf_terminate_test()` if a test is running against `peer` before freeing `outbuf`/`inbuf`. In `perf_run_test()`, when `flt_dst` wraps at `bnd_dst`, reset both `flt_dst = peer->outbuf` and `flt_src = pthr->src` together. [F65, F77, F91]
- In `drivers/ntb/msi.c`, devres operations (`ntbm_msi_setup_callback()`, `devm_request_threaded_irq()`, `devm_free_irq()`, `devres_destroy()`) must target `&ntb->dev` (not `&ntb->pdev->dev`) because `ntbm_msi_callback_match()` calls `dev_ntb(dev)`. Allocate `struct ntb_msi` and `struct ntb_msit_ctx` using `struct_size()` with `ntb_peer_port_count(ntb)`. [F104, F108]
- In `ntb_hw_idt`, `portdata_tbl` is indexed by physical port and `partdata_tbl` by partition, whereas `ndev->peers` is indexed by dense `pidx`, translated via `ndev->port_idx_map` and `ndev->part_idx_map`. Shared switch registers (`IDT_SW_SE*MSK`, `IDT_SW_TMPCTL`) must not be masked or powered down in `idt_deinit_link()` or `idt_pci_remove()`. [F61, F79]

## Synchronization
- `ntb_link_event()`, `ntb_db_event()`, and `ntb_msg_event()` invoke `ntb->ctx_ops` under `ntb->ctx_lock` with `spin_lock_irqsave()`. `ntb_ctx_ops` callbacks must never sleep, call `ntb_set_ctx()`/`ntb_clear_ctx()`, or call sleeping helpers like `ntb_msi_setup_mws()`, `ntbm_msi_request_threaded_irq()`, or `ntb_epf_send_command()`-backed ops (`ntb_mw_set_trans()`, `ntb_mw_clear_trans()`, `ntb_link_enable()`, `ntb_link_disable()`). [F18, F138, F139]
- In `ntb_complete_rxc()`, `qp->rx_post_q` must be drained with a `while (!list_empty(&qp->rx_post_q))` loop that re-reads `list_first_entry()` under `qp->ntb_rx_q_lock`, stops at the first entry without `DESC_DONE_FLAG`, updates `entry->rx_hdr->flags` and `qp->rx_info->entry`, copies `entry->cb_data` and `entry->len` into locals, moves `entry` to `qp->rx_free_q`, and unlocks `qp->ntb_rx_q_lock` before calling `qp->rx_handler()`. [F23, F88]
- In `ntb_transport.c`, CPU copies in `ntb_memcpy_tx()` and `ntb_memcpy_rx()` must execute `wmb()` before setting `DESC_DONE_FLAG` in `hdr->flags` or clearing `entry->rx_hdr->flags` and updating `qp->rx_info->entry`. In `ntb_transport_rxc_db()`, `ntb_db_clear()` must be followed by `ntb_db_read(qp->ndev)` to flush the posted write before checking `qp->active` and rescheduling `qp->rxc_db_work`. [F24, F134]
- `ntb_transport_link_work()` and `ntb_transport_link_cleanup_work()` serialize on `nt->link_event_lock`. Because `ntb_transport_link_cleanup()` calls `cancel_work_sync(&qp->link_cleanup)` and `cancel_delayed_work_sync(&qp->link_work)` under `nt->link_event_lock`, `ntb_qp_link_work()` and `ntb_qp_link_cleanup_work()` must never acquire `nt->link_event_lock`. [F148]
- In `ntb_perf.c`, `perf_spad_cmd_send()`/`perf_msg_cmd_send()` must write low/high data registers before `PERF_SPAD_CMD`/`PERF_MSG_CMD`, and `perf_spad_cmd_recv()`/`perf_msg_cmd_recv()` must read both data registers before writing `PERF_CMD_INVAL` or calling `ntb_msg_clear_sts()`. Event callbacks must queue commands to `peer->service` via `perf_cmd_exec()` rather than calling `perf_cmd_send()` directly. [F32, F152]
- In `ntb_perf.c`, `perf_terminate_test()` must set `atomic_set(&perf->tsync, -1)` and call `wake_up(&perf->threads[tidx].dma_wait)` before `cancel_work_sync(&perf->threads[tidx].work)`. Accessing `perf->tcnt`, `perf->test_peer`, or `perf->threads[]` stats from DebugFS must be serialized with `test_and_set_bit_lock(0, &perf->busy_flag)` and `clear_bit_unlock(0, &perf->busy_flag)`. [F153, F154]
- In `ntb_hw_epf.c`, `ntb_epf_send_command()` must hold `ndev->cmd_lock`, write `NTB_EPF_ARGUMENT` before `NTB_EPF_COMMAND`, sample `timedout = ktime_after(ktime_get(), timeout)` before `readw()` on `NTB_EPF_CMD_STATUS`, check `COMMAND_STATUS_ERROR`/`COMMAND_STATUS_OK` before `timedout`, and clear `NTB_EPF_CMD_STATUS` with `writew(0, ...)` before unlocking. [F93, F133]
- In `ntb_hw_idt.c`, updates to `IDT_NT_INDBELLMSK` and `IDT_NT_MSGSTSMSK` must use `idt_reg_set_bits()`/`idt_reg_clear_bits()` under `ndev->db_mask_lock` or `ndev->msg_mask_lock`, and `idt_write_temp()` must clear `IDT_TMPALARM_IRQ_MASK` when updating `IDT_SW_TMPALARM`. Indirect register pairs (`GASAADDR`/`GASADATA`, `NTMTBLADDR`/`NTMTBLDATA`, `LUTOFFSET`/`LUT*DATA`) require `spin_lock_irqsave()` (`gasa_lock`, `mtbl_lock`, `lut_lock`), with `gasa_lock` nesting inside `msg_locks` and `hwmon_mtx`. [F62, F150]

## Object Lifetimes
- `ntb_unregister_device()` waits on `ntb->released` (completed when `put_device()` in `ntb_probe()`/`ntb_remove()` triggers `ntb_dev_release()`), and PCI `.remove` callbacks (`ntb_epf_pci_remove()`, `idt_pci_remove()`) must call it before freeing IRQs or unmapping BARs. In `idt_deinit_isr()`, mask hardware interrupts and call `devm_free_irq(&pdev->dev, pci_irq_vector(pdev, 0), ndev)` before `pci_free_irq_vectors(pdev)`. [F2, F17, F19]
- NTB clients must call `ntb_set_ctx()` before `ntb_link_enable()` and `ntb_clear_ctx()` before freeing context. In `perf_disable_service()`, mask interrupts and call `ntb_clear_ctx(perf->ntb)` before queueing `PERF_CMD_CLEAR` and calling `flush_work(&perf->peers[pidx].service)`. [F116, F117]
- In `ntb_transport_register_client_dev()`, once `dev->release = ntb_transport_client_release` is set, a `device_register(dev)` failure must call `put_device(dev)` (not `kfree(client_dev)`) and `ntb_transport_unregister_client_dev(device_name)`. `ntb_netdev` init/exit must call `ntb_transport_unregister_client_dev(KBUILD_MODNAME)` if `ntb_transport_register_client()` fails or after `ntb_transport_unregister_client()`. [F3, F4]
- `ntb_netdev_open()` must enqueue RX buffers and call `timer_setup(&dev->tx_timer, ...)` before `ntb_transport_link_up()` and `netif_start_queue()`. `ntb_netdev_close()` and `ntb_netdev_change_mtu()` must call `ntb_transport_link_down()` before `ntb_transport_rx_remove()`. [F22]
- `ntb_transport_free_queue()` must set `qp->active = false`, clear `qp->tx_dma_chan`/`rx_dma_chan` to `NULL` before `dma_sync_wait()` and `dmaengine_terminate_all()`, mask `qp_bit`, call `tasklet_kill(&qp->rxc_db_work)`, and `cancel_delayed_work_sync(&qp->link_work)` before freeing entries. `ntb_transport_link_cleanup()` and `ntb_transport_free()` must finish `ntb_qp_link_cleanup()` and cancel `qp->link_cleanup` before calling `ntb_free_mw()`. [F25, F52]
- Inbound MW DMA buffers allocated on `&ntb->pdev->dev` (`ntb_set_mw()`, `perf_setup_inbuf()`, `tool_setup_mw()`) must clear translations via `ntb_mw_clear_trans()` before `dma_free_coherent()`. In `ntb_tool.c`, `tool_free_mw()` and `tool_free_peer_mw()` must remove `dbgfs_file`, unmap/free non-NULL `mm_base`/`io_base`, and reset `mm_base`/`io_base` and `dbgfs_file` to `NULL`. [F15, F123]
- On error in `ntb_msi_init()`, unmap all mapped `peer_mws[i]` via `devm_iounmap()`, free `ntb->msi`, and reset `ntb->msi = NULL`. In `ntb_async_rx_submit()`, `ntb_async_tx_submit()`, and `perf_copy_chunk()`, `dma_set_unmap()` takes a ref on `unmap`, so drop the caller's ref with `dmaengine_unmap_put(unmap)` after `dmaengine_submit()` without duplicating the put on error paths. [F7, F10]
- In module init/exit paths, unregister clients/drivers before calling `debugfs_remove_recursive()` on the top-level DebugFS directory. Temporary `kmalloc()` buffers in DebugFS read/write handlers must be freed with `kfree()` on all early error paths. [F12, F16]

## API Contracts
- `ntb_dev_ops_is_valid()` requires port, doorbell-vector, scratchpad, and message callback groups to be all-or-nothing, and requires `mw_set_trans` or `peer_mw_set_trans`. Because `ntb_mw_set_trans()` returns 0 when `ops->mw_set_trans` is NULL, clients requiring inbound MWs (`ntb_transport_probe()`) must check `ndev->ops->mw_set_trans`. `ntb_dev_ops` callbacks `link_is_up()`, `mw_get_align()`, `peer_mw_get_addr()`, and `msg_read()` must check optional output pointers for NULL, and `ntb_mw_get_align()` returns `-ENOTCONN` unless peer `pidx` link is up. [F38, F39, F66, F159]
- Outbound peer MW calls (`ntb_peer_mw_*`) are bounded by `ntb_peer_mw_count(ntb)`, whereas inbound MW calls (`ntb_mw_*`) are bounded by `ntb_mw_count(ntb, pidx)`. `ntb_link_is_up()` is indexed by `BIT_ULL(pidx)`, whereas port doorbell masks in `ntb_pingpong` and `ntb_msi_test` use `BIT_ULL(ntb_port_number(ntb))` or `BIT_ULL(ntb_peer_port_number(ntb, pidx))`. `db_set`/`db_clear`/`db_*_mask` take a `u64` bitmask, whereas `peer_db_addr` takes a bit index (`int db_bit`) and `db_vector_mask`/`ntb_db_event` take a vector index. Scratchpad and message APIs use CPU-endian `u32` values without `cpu_to_le32()`/`le32_to_cpu()`. [F45, F46, F73, F158]
- Because `&ntb->dev` lacks DMA config, `dma_set_mask_and_coherent()` and `dma_alloc_coherent()`/`dma_free_coherent()` must use `&ntb->pdev->dev`. For DMA to an outbound peer MW (`qp->tx_mw`, `peer->outbuf`), map the BAR physical address on `chan->device->dev` via `dma_map_resource()` instead of `virt_to_page()`. [F143, F144]
- Callers of `ntb_transport_tx_enqueue()` must externally serialize TX calls per `ntb_transport_qp`. `ntb_queue_handlers` (`rx_handler`, `tx_handler`) receive a signed `int len` (`-EIO` on error, with `data == NULL` on oversize TX) and must check `len < 0` and `!data`. Transport clients (`ntb_netdev_probe()`, `ntb_transport_create_queue()`) must pass `client_dev->parent` (not `client_dev`) to `dev_ntb()`. [F26, F34, F107]
- `ntb_msi_init()` must run before `ntb_msi_setup_mws()`, `ntbm_msi_request_threaded_irq()`, or `ntb_msi_peer_trigger()`, and `ntb_msi_setup_mws()`/`ntbm_msi_request_threaded_irq()` must hold `msi_descs_lock` on `&ntb->pdev->dev`. [F20]

## Error Handling
- `ntbm_msi_request_threaded_irq()` and `ntbm_msi_request_irq()` return a positive Linux IRQ number or negative errno; store in a signed `int` and check `< 0`. `ntb_msi_set_desc()` must verify `addr >= ntb->msi->base_addr && addr < ntb->msi->end_addr` before computing `addr_offset`, reporting out-of-range addresses with `dev_warn_once()` and returning `-EFAULT` (without `WARN_ON()`). [F35, F72, F168]
- `devm_kzalloc()`/`devm_kcalloc()` return NULL on failure, whereas `idt_create_dev()`, `idt_scan_mws()`, `pp_create_data()`, `tool_create_data()`, and `perf_create_data()` return `ERR_PTR(-ENOMEM)` and require `IS_ERR()`. In `ntb_transport_link_work()`, if `ntb_set_mw()` fails, jump to `out1` to call `ntb_free_mw()` and return without calling `ntb_link_disable(ndev)`. [F36, F167]
- In `ntb_tool.c`, `tool_peer_mw_read()`/`tool_peer_mw_write()` must check `pos >= outmw->size` before `outmw->size - pos`, access `outmw->io_base` via a `kmalloc()` bounce buffer with `memcpy_fromio()`/`memcpy_toio()` and `copy_to_user()`/`copy_from_user()`, and return `-EFAULT` only when `ret == size` (otherwise subtracting `ret` from `size`). DebugFS `sscanf()` write handlers must use `memdup_user_nul()` or NUL-terminated `copy_from_user()` and reject `*offp != 0`. [F37, F44, F75, F165]

## Known Pitfalls
- Use `scnprintf(buf + off, size - off, ...)` (not `snprintf()`) for sequential buffer writes, pass the length excluding NUL to `simple_read_from_buffer()`, and format `resource_size_t`/`phys_addr_t`/`dma_addr_t` by reference (`&val`) with `%pa`/`%pap`/`%pad`. [F74, F105, F106]
- In `ntb_transport.c`, 64-bit QP/doorbell masks must use `BIT_ULL()`. Clamp `qp_count` against `nt->mw_count` (not local `mw_count`) in `ntb_transport_probe()`, and allocate queues from `ffs(nt->qp_bitmap_free)` (not `nt->qp_bitmap`) in `ntb_transport_create_queue()`. [F84, F85, F94]
- Use `upper_32_bits()`/`lower_32_bits()` when splitting `resource_size_t` or `dma_addr_t`, and cast high `u32` values to `u64` before `<< 32`. In `ntb_msi_peer_trigger()`, divide byte offset `desc->addr_offset` by `sizeof(*ntb->msi->peer_mws[peer])` before indexing `peer_mws[peer]`. [F95, F96, F103]
- In `ntb_netdev.c`, schedule `dev->tx_timer` with `usecs_to_jiffies(tx_time)` (not `msecs_to_jiffies()`). In `ntb_perf.c`, divide `pthr->copied` by `ktime_to_us(pthr->duration)` using `div64_u64()`. In `perf_init_service()` and `pp_check_ntb()`, check doorbell support with `(ntb_db_valid_mask(ntb) & mask) == mask`. In `ntb_epf_init_pci()`, when `BAR_PEER_SPAD` shares the BAR with `BAR_CONFIG`, offset `ndev->peer_spad_reg` from `ndev->ctrl_reg` instead of calling `pci_iomap()` twice. [F48, F92, F101, F127]
- In `ntb_hw_idt.c`, `idt_scan_mws()` (`bidx += 1 + bar_64bit`) must reset `bar_64bit = false` before skipping a disabled BAR and update `bar_64bit` before skipping `IDT_BARSETUP_MODE_CFG`. For 64-bit direct-translated BARs, program `(bar + 1)->limit`. `IDT_NT_INDBELLSTS`, `IDT_NT_MSGSTS`, and `IDT_NTINTSTS_SEVENT` are write-1-to-clear, whereas `IDT_NTINTSTS_DBELL` and `IDT_NTINTSTS_MSG` clear only when all doorbell/message status bits are cleared. [F89, F111, F132]
