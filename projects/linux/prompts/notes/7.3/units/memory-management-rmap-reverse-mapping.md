# MEMORY MANAGEMENT - RMAP (REVERSE MAPPING)

Implements physical-to-virtual reverse mapping (rmap) for anonymous, file-backed, KSM, and HugeTLB folios. It manages `anon_vma` and `anon_vma_chain` hierarchies, maintains per-page and per-folio mapcounts (including per-MM large mapcount tracking and `PageAnonExclusive`), and provides page-table walking (`page_vma_mapped_walk`, `rmap_walk`) for reference checks, write-protecting/cleaning mappings, reclaim unmapping, migration, and device-exclusive access.

## Architecture & Data Flow

- Because `anon_vma_cachep` uses `SLAB_TYPESAFE_BY_RCU` with `anon_vma_ctor()`, `anon_vma_alloc()` must reset `refcount` (1), `num_children` (0), `num_active_vmas` (0), `parent` (`anon_vma`), and `root` (`anon_vma`), but must never call `init_rwsem(&anon_vma->rwsem)` because RCU readers in `folio_lock_anon_vma_read()` may access `rwsem` concurrently. [F52]
- In the `anon_vma` hierarchy (`anon_vma_fork()`, `unlink_anon_vmas()`, `__put_anon_vma()`), `rwsem` and tree-lock `refcount` pinning belong to `anon_vma->root`, `num_children` is tracked on `anon_vma->parent`, and `num_active_vmas` is tracked on `vma->anon_vma`. `anon_vma_clone()` may reuse an `anon_vma` only when `!dst->anon_vma && src->anon_vma && anon_vma->num_children < 2 && anon_vma->num_active_vmas == 0`, and because `anon_vma_chain_link()` inserts at the head via `list_add()`, `anon_vma_clone()` must use `list_for_each_entry_reverse()` so `unlink_anon_vmas()` frees the root last. [F58, F99, F104]
- In `__folio_add_rmap()` and `__folio_remove_rmap()`, `folio->_nr_pages_mapped` packs the PTE-mapped subpage count in `FOLIO_PAGES_MAPPED` (`ENTIRELY_MAPPED - 1`) and adds `ENTIRELY_MAPPED` when PMD/PUD-mapped. PTE map/unmap must update `__folio_mod_stat()` only when the updated value is `< ENTIRELY_MAPPED`, and when adding/subtracting `ENTIRELY_MAPPED`, `nr = nr_pages - (nr & FOLIO_PAGES_MAPPED)` (or `nr_pages - nr`) must be clamped to `0` if `nr < 0` or if `ENTIRELY_MAPPED` raced ahead. `PGTABLE_LEVEL_PMD` and `PGTABLE_LEVEL_PUD` share `_entire_mapcount`, but `nr_pmdmapped` must only be set when `level == PGTABLE_LEVEL_PMD`. [F86, F97, F111]
- Under `CONFIG_MM_ID`, `folio_mm_id()` and `folio_set_mm_id()` require `idx` in `{0, 1}` and must mask `folio->_mm_id[idx]` with `MM_ID_MASK` to preserve `FOLIO_MM_IDS_LOCK_BITNUM` and `FOLIO_MM_IDS_SHARED_BITNUM` in the unioned `folio->_mm_ids` word. `folio_mm_id(folio, idx) == MM_ID_DUMMY` holds iff `folio->_mm_id_mapcount[idx] == -1`; when `folio_add_return_large_mapcount()` (via `short` overflow on `!CONFIG_64BIT`) or `folio_sub_return_large_mapcount()` (via underflow below `-1`) drives `_mm_id_mapcount[idx] < 0`, it must reset `_mm_id_mapcount[idx] = -1`, set `MM_ID_DUMMY`, and update `FOLIO_MM_IDS_SHARED_BIT`. [F60, F80, F82, F83]
- When clearing present PTEs in `try_to_unmap_one()`, `try_to_migrate_one()`, or `make_device_exclusive()`, `pte_dirty()` must be propagated via `folio_mark_dirty(folio)`, and deferred TLB flushes flushed via `try_to_unmap_flush_dirty()` before I/O. `set_tlb_ubc_flush_pending()` pairs `tlb_ubc->flush_required = true` with `tlb_ubc->writable = true` if `pte_dirty(pteval)` and advances `mm->tlb_flush_batched` (resetting it to `1` via `atomic_try_cmpxchg` when `(batch & TLB_FLUSH_BATCH_PENDING_MASK) > TLB_FLUSH_BATCH_PENDING_LARGE`), while `try_to_unmap_flush()` resets both `flush_required` and `writable` to `false`. [F67, F110, F142]
- In `page_vma_mapped_walk()`, encountering a non-present `pgd`, `p4d`, `pud`, or `pmd` must advance `pvmw->address` via `step_forward()`—clamping `pvmw->address` to `ULONG_MAX` if `(pvmw->address + size) & ~(size - 1)` wraps to `0`—and `continue` the `do ... while (pvmw->address < end)` loop rather than returning `false`. In `check_pte()` and `check_pmd()`, PFN overlap must be tested using inclusive upper bounds: `(pfn + pte_nr - 1) < pvmw->pfn` (or `HPAGE_PMD_NR`) and `pfn > (pvmw->pfn + pvmw->nr_pages - 1)`. [F76, F77, F102]
- `mlock_vma_folio(folio, vma)` must only be called when the entire folio is mapped within the VMA (`folio_nr_pages(folio) == nr_pages` in `__folio_add_anon_rmap()`/`__folio_add_file_rmap()`, or `ptes == pvmw.nr_pages` without `PVMW_PGTABLE_CROSSED` in `folio_referenced_one()`/`try_to_unmap_one()`). In `invalid_folio_referenced_vma()`, when `folio_referenced()` has a non-NULL `memcg`, any VMA with `!mm_match_cgroup(vma->vm_mm, memcg)` or `!vma_has_recency(vma)` must be skipped (`return true`). [F144, F145]

## Synchronization

- The lock order in `mm/rmap.c` is `mm->mmap_lock` -> `folio_lock` -> `mapping->i_mmap_rwsem` / `anon_vma->root->rwsem` -> `mm->page_table_lock` / `pte_lock` -> `swap_lock` / `mmlist_lock`. `anon_vma->rb_root` requires `anon_vma->root->rwsem`, and linking `vma->anon_vma` in `__anon_vma_prepare()` additionally requires `mm->page_table_lock` while rechecking `!vma->anon_vma`. [F21, F123]
- Because `anon_vma_cachep` is `SLAB_TYPESAFE_BY_RCU`, `folio_get_anon_vma()` and `folio_lock_anon_vma_read()` must take `rcu_read_lock()`, check `folio_mapped(folio)` before and after `atomic_inc_not_zero(&anon_vma->refcount)` (or `down_read_trylock(&root_anon_vma->rwsem)`), and drop the ref/lock if unmapped. Before freeing to `anon_vma_cachep`, `anon_vma_free()` must check `rwsem_is_locked(&anon_vma->root->rwsem)` and cycle `anon_vma_lock_write()` / `anon_vma_unlock_write()` to drain optimistic readers. [F17, F126]
- `rmap_walk_file()` requires `folio_lock` (`VM_BUG_ON_FOLIO(!folio_test_locked(folio), folio)`), whereas `folio_referenced()` must trylock non-anonymous or KSM folios (`!folio_test_anon(folio) || folio_test_ksm(folio)`) when `!is_locked` before calling `rmap_walk()`. [F134]
- In `page_vma_mkclean_one()`, `try_to_unmap_one()`, `try_to_migrate_one()`, and `make_device_exclusive()`, `mmu_notifier_invalidate_range_start()` must precede acquiring any PTL and `mmu_notifier_invalidate_range_end()` must follow `page_vma_mapped_walk_done()` or `folio_walk_end()`. In `make_device_exclusive()`, after `get_user_page_vma_remote()`, locking the folio, and starting the notifier range, `folio_walk_start()` must re-verify `fw_folio == folio && fw.page == page && fw.level == FW_LEVEL_PTE && pte_write(fw.pte)` under PTL. [F28, F34]
- When `map_pte()` and `page_vma_mapped_walk()` use `pte_offset_map_rw_nolock()`, they must save `ptl` before locking and, after `spin_lock(ptl)`, revalidate `pmd_same(pmde, pmdp_get_lockless(pvmw->pmd))`, calling `pte_unmap_unlock(pvmw->pte, ptl)`, setting `pvmw->pte = NULL`, and retrying on mismatch. When `PVMW_SYNC` is set, `map_pte()` must use `pte_offset_map_lock()`, and `page_vma_mapped_walk()` must cycle `pmd_lock(mm, pvmw->pmd)` when `!pmd_present(pmde)` for a PMD-sized THP range. [F33, F65]
- Callers of `folio_try_dup_anon_rmap_ptes/pte/pmd()` must hold PTL and `src_vma->vm_mm->write_protect_seq`, mapping duplicated entries read-only in both parent and child. Callers of `folio_try_share_anon_rmap_pte/pmd()` and `hugetlb_try_share_anon_rmap()` must hold PTL and clear/invalidate the PTE/PMD first; under `CONFIG_HAVE_GUP_FAST`, `smp_mb()` must precede `folio_maybe_dma_pinned()` and `smp_mb__after_atomic()` must follow `ClearPageAnonExclusive()`. [F26, F35]
- In `try_to_unmap_one()` and `try_to_migrate_one()`, `huge_pmd_unshare()` must only be called when `!folio_test_anon(folio)`, requires `TTU_RMAP_LOCKED` (`i_mmap_rwsem` write-locked), and must use `hugetlb_vma_trylock_write(vma)`. [F27]
- `set_tlb_ubc_flush_pending()` must only queue a flush if `pte_accessible(mm, pteval)`, updating `mm->tlb_flush_batched` after a compiler `barrier()` under PTL so `flush_tlb_batched_pending()` under PTL synchronizes against `mprotect`/`munmap`. [F132]

## Object Lifetimes

- Any `page_vma_mapped_walk(&pvmw)` loop exiting before it returns `false` must call `page_vma_mapped_walk_done(&pvmw)` on every early-exit path to unmap `pvmw.pte` and unlock `pvmw.ptl`. [F1]
- `__folio_remove_rmap()` must not clear `folio->mapping` when an anonymous folio's mapcount reaches zero, leaving it to `free_pages_prepare()` to avoid racing with `folio_add_anon_rmap_*()`. [F14]
- `anon_vma_fork()` must pin `anon_vma->root` via `get_anon_vma(anon_vma->root)` before linking the child, and `__put_anon_vma()` must call `anon_vma_free(anon_vma)` before dropping `root->refcount`. [F16]

## API Contracts

- Before calling `page_vma_mapped_walk(&pvmw)`, `pvmw.pmd`, `pvmw.pte`, and `pvmw.ptl` must be `NULL`, and `pvmw.pgoff` must be set whenever `pvmw.nr_pages > 1`. After splitting a PMD in the loop, the caller must call `page_vma_mapped_walk_restart(&pvmw)` (clearing `ptl`, `pmd`, `pte`) before `continue`. [F50, F100]
- `page_vma_mapped_walk_done()` must only call `pte_unmap(pvmw->pte)` when `!is_vm_hugetlb_page(pvmw->vma)`. On HugeTLB VMAs, `page_vma_mapped_walk()` must derive huge page byte size and page count for `hugetlb_walk()`, `huge_pte_lock()`, and `check_pte()` from `hstate_vma(vma)` rather than `pvmw->nr_pages`, and `try_to_unmap_one()` / `try_to_migrate_one()` must use `set_huge_pte_at(..., huge_page_size(hstate_vma(vma)))` rather than `set_pte_at()`. [F53, F121, F137]
- `make_device_exclusive()` must align `addr` with `PAGE_ALIGN_DOWN(addr)` before faulting, setting the `[addr, addr + PAGE_SIZE)` notifier range, walking page tables, and replacing the PTE, and must reject non-anonymous or HugeTLB folios with `ERR_PTR(-EOPNOTSUPP)`. It returns an `ERR_PTR` (never `NULL`) on failure, populates `*foliop` (locked and referenced, rmap mapcount unchanged) only on success, and on retry/error unwinds `folio_walk_end()`, `mmu_notifier_invalidate_range_end()`, `folio_unlock()`, and `folio_put()` in reverse order. [F11, F40, F89]
- `__folio_try_dup_anon_rmap()`, `hugetlb_try_dup_anon_rmap()`, `__folio_try_share_anon_rmap()`, and `hugetlb_try_share_anon_rmap()` return `0` or `-EBUSY` (if potentially DMA-pinned) and must verify all `nr_pages` subpages before clearing `PageAnonExclusive` or incrementing mapcounts. In `anon_vma_clone(dst, src)`, `anon_vma_fork(vma, pvma)`, and `folio_try_dup_anon_rmap_ptes/pte/pmd(..., dst_vma, src_vma)`, destination precedes source. [F41, F55]
- `__folio_rmap_sanity_checks()` requires `nr_pages > 0`, `page` and `page + nr_pages - 1` within `folio`, and `nr_pages == folio_nr_pages(folio)` equal to `HPAGE_PMD_NR` (`PGTABLE_LEVEL_PMD`) or `HPAGE_PUD_NR` (`PGTABLE_LEVEL_PUD`). `folio_set_large_mapcount()` and `folio_add/sub_return_large_mapcount()` take positive 1-based counts (`> 0`) and return 0-based totals (`new_mapcount_val + 1`), while storing `-1`-biased counts in `_large_mapcount` and `_mm_id_mapcount[]`. [F57, F84]
- `folio_referenced()` must set `*vm_flags = 0` before any early return and returns a signed `int` (`-1` on lock contention or exclusive swap-backed anon folio in an exiting/OOM-reaped `mm`). In `struct rmap_walk_control`, `rmap_one()` returns `false` to stop and `true` to continue, `done()` returns non-zero to stop and `0` to continue, and `invalid_vma()` returns `true` to skip. [F39, F42]
- `folio_mkclean()` requires `folio_test_locked(folio)` and cleans only `VM_SHARED` VMAs; to write-protect `VM_SHARED` mappings of a PFN range without a locked folio, callers must use `mapping_wrprotect_range()`, and `__rmap_walk_file()`, `mapping_wrprotect_range_one()`, and `invalid_mkclean_vma()` must handle `folio == NULL` via `rwc->arg` (`struct wrprotect_file_state *`). [F118, F141]
- In `try_to_unmap_one()`, converting a `PageHWPoison(subpage)` PTE to a hwpoison swap entry requires `flags & TTU_HWPOISON`, whereas `try_to_migrate()` rejects `TTU_HWPOISON` and `try_to_migrate_one()` converts `PageHWPoison(subpage)` unconditionally. [F54]

## Error Handling

- In `try_to_unmap_one()` and `try_to_migrate_one()`, if `swap_duplicate()`, `arch_unmap_one()`, `folio_try_share_anon_rmap_pte()`, or `hugetlb_try_share_anon_rmap()` fails after clearing the PTE, `pteval` must be restored via `set_pte_at()`/`set_huge_pte_at()` and any allocated swap entry freed before aborting without modifying RSS or rmap counts. [F72]
- `__folio_rmap_sanity_checks()` must not warn when a large folio lacks `folio_test_large_rmappable(folio)` (used by `vm_insert_page()` on `VM_MIXEDMAP`), and `folio_move_anon_rmap()` must only assert `folio_test_locked(folio)` and `vma->anon_vma != NULL` (not `folio->index == linear_page_index(vma, address)`, which underflows when a large folio starts below `vma->vm_start`). [F146, F148]

## Known Pitfalls

- When `page_vma_mapped_walk(&pvmw)` returns `true`, `pvmw.pte` is `NULL` for PMD-mapped THPs and `pvmw.pmd` is `NULL` for HugeTLB mappings; callers must check `pvmw.pte` before dereferencing, and must guard present-PTE helpers (`pte_dirty()`, `pte_write()`, `pte_unused()`, `pte_young()`, `pte_soft_dirty()`, `pte_uffd_wp()`) and cache/TLB flushes with `pte_present(pteval)`, using `pte_clear()`, `pte_swp_soft_dirty()`, and `pte_swp_uffd_wp()` when non-present. [F43, F45]
- Because KSM folios set both `FOLIO_MAPPING_ANON` and `FOLIO_MAPPING_KSM`, `rmap_walk()` must test `folio_test_ksm(folio)` before `folio_test_anon(folio)`, and `folio_get_anon_vma()` / `folio_lock_anon_vma_read()` must test `(anon_mapping & FOLIO_MAPPING_FLAGS) != FOLIO_MAPPING_ANON`. [F91]
- Operations on `folio->_mm_ids` must pass bit numbers (`FOLIO_MM_IDS_LOCK_BITNUM`, `FOLIO_MM_IDS_SHARED_BITNUM`) to `bit_spin_lock()`, `__bit_spin_unlock()`, and `test_bit()`, but use the shifted mask `FOLIO_MM_IDS_SHARED_BIT` for bitwise `|=` and `&= ~`. [F56]
- In `__folio_dup_file_rmap()`, `__folio_try_dup_anon_rmap()`, and `__folio_add_rmap()`, the `while (page++, --nr_pages > 0)` loop zeroes `nr_pages`, so `folio_add_large_mapcount()` must be passed `orig_nr_pages`. In `__folio_try_dup_anon_rmap()`, `folio_needs_cow_for_dma()` takes `src_vma`, while `folio_add/inc_large_mapcount()` takes `dst_vma`. [F103, F106]
- In `DEFINE_FOLIO_VMA_WALK(name, _folio, _vma, _address, _flags)`, every field initializer must use the underscore-prefixed macro parameters (`_folio`, `_vma`, `_address`, `_flags`). [F105]
