# QUALCOMM ATHEROS ATH10K WIRELESS DRIVER

Core infrastructure, bus/HIF abstraction, BMI bootloader messaging, Copy Engine (CE) DMA ring management, firmware crash dumping, and debugfs instrumentation for the Qualcomm Atheros 802.11ac (`ath10k`) wireless driver. It handles device registration, firmware/board/calibration loading (via BMI, DT, SMBIOS, NVMEM, or EEPROM), asynchronous crash recovery, AHB bus attachment, 32/64-bit CE descriptor rings, devcoredump generation, and per-device/per-station debugfs interfaces.

## Architecture & Data Flow
- On 64-bit targets (`ar->hw_params.target_64bit` / `ce_64_ops` / `ATH10K_HW_WCN3990`), CE ring allocations, zeroing, frees, and indexing must use 16-byte `struct ce_desc_64` (`CE_SRC_RING_TO_DESC_64` / `CE_DEST_RING_TO_DESC_64`) instead of 8-byte `struct ce_desc`. `ce_set_src_ring_base_addr_hi` and `ce_set_dest_ring_base_addr_hi` are `NULL` in 32-bit `ce_ops`, so `ath10k_ce_src_ring_base_addr_set()` and `ath10k_ce_dest_ring_base_addr_set()` must null-check them before calling. [F49, F82]
- `ath10k_ce_alloc_src_ring*()` and `ath10k_ce_alloc_dest_ring*()` must round `nentries` via `roundup_pow_of_two()`, set `nentries_mask = nentries - 1`, and allocate `CE_DESC_RING_ALIGN` extra DMA bytes to align base pointers. `ath10k_ce_init_src_ring()` and `ath10k_ce_init_dest_ring()` must zero `base_addr_owner_space` and sync `sw_index`/`hw_index`/`write_index` from HW registers masked with `nentries_mask`. Free slot checks must pass `sw_index - 1` to `CE_RING_DELTA`, and `ath10k_ce_rx_update_write_idx()` must decrement `nentries` if `write_index` would reach `sw_index`. [F60, F83, F115]
- In `_ath10k_ce_completed_send_next_nolock*()`, when `hw_index == sw_index`, `ath10k_ce_src_ring_read_index_get()` must be checked for `0xffffffff` (`-ENODEV`) before masking with `nentries_mask` and caching in `hw_index`; popping `sw_index` must clear `per_transfer_context[sw_index]` and `desc->nbytes`. In `_ath10k_ce_completed_recv_next_nolock*()`, the descriptor must be snapshotted before checking `nbytes == 0` (`-EIO`), and `per_transfer_context[sw_index]` must be cleared for every pipe except `ce_state->id == 5` (CE5 HTT Rx reuse). [F48, F57, F58]
- `ath10k_core_restart()` must set `ATH10K_FLAG_CRASH_FLUSH` before draining TX and waking waiters (and `ath10k_core_start()` must clear it before booting). Under `ar->conf_mutex`, `ATH10K_STATE_ON` transitions to `ATH10K_STATE_RESTARTING`, calls `ath10k_halt(ar)`, and invokes `ieee80211_restart_hw(ar->hw)` (without calling `ieee80211_hw_restart_disconnect()` beforehand), whereas a crash during `ATH10K_STATE_RESTARTED` transitions `ar->state` to `ATH10K_STATE_WEDGED` without restarting. [F24, F68, F106, F175]
- `ath10k_init_hw_params()` and `_ath10k_coredump_get_mem_layout()` must match the 3-tuple `(target_version/hw_id, bus, dev_id/hw_rev)`, and `ath10k_init_hw_params()` must return `-EINVAL` if `i == ARRAY_SIZE(ath10k_hw_params_list)` before dereferencing `hw_params`. `ath10k_core_fetch_board_data_api_n()` must scan the full `board-2.bin` IE list via `ath10k_core_search_bd()` for the primary variant `boardname` before fallback passes, and `ath10k_core_parse_bd_ie_board()` must gate `ATH10K_BD_IE_BOARD_DATA` on `name_match_found` (exact `strlen(boardname)` and `memcmp`). [F99, F102, F110]
- Calibration data in `ath10k_download_cal_dt()` and `ath10k_download_cal_nvmem()` must equal `ar->hw_params.cal_data_len` (`-EMSGSIZE` otherwise), which must not exceed `ATH10K_DEBUG_CAL_DATA_LEN` (12064); `ath10k_push_board_ext_data()` requires `data_len == board_size + board_ext_size`. In `coredump.c`, `ath10k_mem_section` ranges must be strictly ascending (`mem_region->start <= sections[0].start`, IRAM regions last in `qca6174_hw30_mem_regions`), `ath10k_coredump_get_ramdump_size()` must include `sizeof(struct ath10k_dump_ram_data_hdr)` per region, and `ath10k_coredump_build()` must keep `len` and `sofar` identical across TLV sections. [F89, F90, F92, F93, F124]
- In `debug.c`, `fops_cal_data` and `simple_open` files store `struct ath10k *` in `file->private_data`, whereas `fops_fw_stats` and `fops_tpc_stats*` store a `vmalloc` `char *` buffer; `debugfs_sta.c` files pass `struct ieee80211_sta *sta` to `debugfs_create_file()`. `ath10k_dbg_sta_dump_tx_stats()` must null-check `arsta->tx_stats` under `ar->conf_mutex` and format `stats->bw[j]` in `enum rate_info_bw` order (20, 5, 10, 40, 80, 160 MHz). `arsta->tid_stats` has `IEEE80211_NUM_TIDS + 1` elements (index 16 for non-QoS), using inclusive `<= IEEE80211_NUM_TIDS` bounds. [F54, F79, F95, F130, F131]

## Synchronization
- Never call `cancel_work_sync(&ar->set_coverage_class_work)` (in `ath10k_core_restart()`) or `cancel_delayed_work_sync(&ar->debug.htt_stats_dwork)` (in `ath10k_debug_unregister()`) while holding `ar->conf_mutex`; `ath10k_debug_stop()` holds `ar->conf_mutex` and must use non-sync `cancel_delayed_work()`. `ath10k_core_napi_enable()` and `ath10k_core_napi_sync_disable()` require `ar->conf_mutex` and must check/update `ATH10K_FLAG_NAPI_ENABLED` in `ar->dev_flags`. [F11, F23]
- Always use `spin_lock_bh()` / `spin_unlock_bh()` for `ce->ce_lock` and `ar->data_lock`. `*nolock*`, `__ath10k_ce_send_revert()`, `__ath10k_ce_rx_num_free_bufs()`, and `__ath10k_ce_rx_post_buf*()` require the caller to hold `ce->ce_lock`. `ath10k_ahb_hif_stop()` must call `ath10k_ahb_irq_disable()` and `synchronize_irq(ar_ahb->irq)` before `ath10k_core_napi_sync_disable()` and `ath10k_pci_flush()`. `ath10k_ce_per_engine_service()` must clear CE interrupt status via `ath10k_ce_engine_int_status_clear()` before invoking `recv_cb`/`send_cb`. [F22, F33, F161, F162]
- `spin_lock_bh(&ar->data_lock)` nests inside `ar->conf_mutex` and protects `ar->debug.fw_stats*` and `tpc_stats*`; debugfs readers must allocate `GFP_KERNEL` buffers before `data_lock` and call `simple_read_from_buffer()` after unlocking. `ath10k_debug_fw_stats_process()` holds `data_lock` across `ath10k_sta_update_rx_duration()` (which dispatches on `stats->extended` for `peers_extd` vs `peers` and must not sleep or re-lock). RX TID stats helpers in `debugfs_sta.c` require `rcu_read_lock()` with `spin_lock_bh(&ar->data_lock)` nested inside. `ar->dump_mutex` serializes `ar->coredump.fw_crash_data` and nests outside `ce->ce_lock`. [F28, F29, F30, F53, F164, F171]
- In `ath10k_core_start()`, `ar->free_vdev_map` and `ar->arvifs` must be initialized before `ath10k_htt_setup()`, because starting HTT can immediately trigger RX callbacks iterating `ar->arvifs`. In `ath10k_core_reset_rx_filter()`, `ath10k_wmi_barrier()` must be called after deleting the dummy vdev and before `ath10k_htt_rx_ring_refill()`, as WMI and HTT use separate HIF pipes. [F19, F20]

## Object Lifetimes
- Because AHB embeds `struct ath10k_ahb` at `ath10k_pci_priv(ar)->ahb[0]`, `ath10k_ahb_probe()` must pass `sizeof(*ar_pci) + sizeof(*ar_ahb)` to `ath10k_core_create()`, initialize shared `ar_pci` fields (`mem`, `mem_len`, `ar`, `ce.bus_ops`, `targ_cpu_to_ce_addr`, `ar->ce_priv`, `oper_irq_mode = ATH10K_PCI_IRQ_INTX`), pair `ath10k_pci_setup_resource()` with `ath10k_pci_release_resource()`, and call `ath10k_core_destroy()` last. `ath10k_ahb_resource_deinit()` and init error paths must `iounmap()` `gcc_mem`/`tcsr_mem`, `devm_iounmap()` `mem`, and NULL them. `ath10k_ahb_clock_enable()`/`disable()` must stay balanced across `ath10k_ahb_prepare_device()` and `ath10k_ahb_chip_reset()` and unwind `cmd_clk`/`ref_clk` in reverse order on error. [F1, F2, F3, F62, F128, F157]
- `ath10k_core_free_firmware_files()` and `ath10k_core_free_board_files()` must guard `release_firmware()` with `!IS_ERR()` on `fw_file.firmware`, separate `cal_file` and `pre_cal_file` fields, `board`, and `ext_board`, and reset all pointers/lengths to `NULL`/`0`. `ath10k_core_register_work()` must complete `ath10k_core_probe_fw()` before `ath10k_mac_register()`. `ath10k_core_start()` must unwind `hif_stop`, `htt_rx_free`, `htt_tx_free`, and `wmi_detach` in reverse order under `conf_mutex`. `ath10k_core_unregister()` must call `cancel_work_sync(&ar->register_work)`, check `ATH10K_FLAG_CORE_REGISTERED`, and call `ath10k_spectral_destroy()` before `ath10k_mac_unregister()`. [F5, F9, F10, F66, F146]
- `ath10k_debug_fw_stats_reset()` must clear `fw_stats_done`/`extended` and free all four `fw_stats` lists (`pdevs`, `vdevs`, `peers`, `peers_extd`) under `data_lock`; `ath10k_debug_fw_stats_process()` must free all four temp lists at `free:`, splice `peers_extd` only when `!list_empty(&stats.peers)`, and free both `peers` and `peers_extd` when exceeding `ATH10K_MAX_NUM_PEER_IDS`. `ath10k_debug_tpc_stats*_process()` must `kfree()` old `tpc_stats` under `data_lock` (or `kfree(tpc_stats)` in `!CONFIG_ATH10K_DEBUGFS` stubs). `ath10k_coredump_submit()` transfers the `vzalloc` dump buffer to `dev_coredumpv()`, while `fw_crash_data` and `ramdump_buf` are `vfree()`d on unregister/destroy. [F16, F17, F74, F144]

## API Contracts
- `ar->running_fw` is a borrowed read-only pointer assigned in `ath10k_core_start()` to `normal_mode_fw` or `testmode.utf_mode_fw` and must never be modified or passed to `release_firmware()`. `ath10k_core_fetch_firmware_api_n()` must populate its `struct ath10k_fw_file *fw_file` parameter rather than dereferencing `ar->running_fw` (which is `NULL` during probe) or `ar->normal_mode_fw.fw_file`. [F8, F100]
- Bus drivers must initialize `ar->ce_priv` and `ce.bus_ops` before any CE call, and stop target DMA before `ath10k_ce_revoke_recv_next()` or `ath10k_ce_cancel_send_next()`. In CE completion, revoke, and cancel functions, `per_transfer_contextp` may be `NULL` and must be null-checked, whereas `nbytesp`, `bufferp`, and `transfer_idp` must be non-`NULL`. `_ath10k_ce_send_nolock*()` updates the HW write index register only when `CE_SEND_FLAG_GATHER` is cleared, and `__ath10k_ce_send_revert()` must only roll back uncommitted gather descriptors before that write. [F25, F46, F129, F153]
- Non-coredump callers needing target memory layout (e.g. `ath10k_core_copy_target_iram()`) must call `_ath10k_coredump_get_mem_layout()` instead of `ath10k_coredump_get_mem_layout()` (which checks `ath10k_coredump_mask`) and treat `NULL` as `return 0`. `ath10k_coredump_new()` returns `NULL` when disabled, so callers and `ath10k_ce_dump_registers()` must null-check `crash_data`. [F39, F40]
- Once `ath10k_bmi_done()` sets `ar->bmi.done_sent = true`, BMI commands return `-EBUSY` until `ath10k_bmi_start()` resets `done_sent = false`. `ath10k_bmi_lz_data*()` requires 4-byte aligned `length`, so `ath10k_bmi_fast_download()` must send `rounddown(length, 4)`, pad `trailer_len` into a zero-initialized 4-byte `trailer` (passing `4`), and finish with `ath10k_bmi_lz_stream_start(ar, 0x00)`. [F50, F64, F156]
- In `ath10k_ahb_halt_chip()`, accesses to `ar_ahb->tcsr_mem` must select register offsets matching `ATH10K_AHB_WLAN_CORE_ID_REG` (0 or 1), use read-modify-write on `haltreq_reg` and `glb_cfg_reg`, and clear `AHB_AXI_BUS_HALT_REQ` and `TCSR_WIFIX_GLB_CFG_DISABLE_CORE_CLK` before deasserting `core_cold_rst`. [F63, F137]

## Error Handling
- Errors in `ath10k_core_probe_fw()` after `ath10k_core_fetch_firmware_files()` must jump to `err_free_firmware_files` (or `err_unlock` before it); errors in `ath10k_core_fetch_board_data_api_n()` and `ath10k_core_fetch_firmware_api_n()` after `ath10k_fetch_fw_file()` must jump to `err` to free files. `ath10k_ce_alloc_pipe()` must reset `src_ring`/`dest_ring` to `NULL` after extracting `PTR_ERR()` because `_ath10k_ce_free_pipe*()` only checks non-`NULL`. `ath10k_ahb_clock_enable()`, `ath10k_ahb_release_reset()`, and `ath10k_ahb_halt_chip()` must guard all clock/reset pointers with `IS_ERR_OR_NULL()`. [F6, F7, F38, F44]
- When `ath10k_download_cal_nvmem()` returns `-EPROBE_DEFER`, `ath10k_core_pre_cal_download()` and `ath10k_download_cal_data()` must return `-EPROBE_DEFER` immediately without falling back. `-EOPNOTSUPP` from `ath10k_core_get_*board_id_from_otp()` must be treated as non-fatal, absent optional cal/OTP sources (or `-EOPNOTSUPP` from EEPROM) must log at most via `ath10k_dbg()`, `ath10k_fetch_fw_file()` must use `firmware_request_nowarn()`, and `ath10k_warn()` must use `dev_warn_ratelimited()`. [F51, F52, F177, F178, F182]

## External Contracts
- Debugfs `.write` handlers in `debug.c` and `debugfs_sta.c` must check for an unchanged configuration value first and return `count` (not `0`) before branching on whether the new value is non-zero/enabled, and error jumps to an unlock label must preserve the negative error code in `ret` rather than unconditionally returning `count`. `ath10k_write_reset_htt_stats()` must clear `ar->debug.reset_htt_stats = 0` after `ath10k_debug_htt_stats_req(ar)` under `conf_mutex`, and `ath10k_write_ps_state_enable()` setting `0` must reset all stations via `ath10k_peer_ps_state_disable()`. [F41, F75, F76, F97, F179]
- On 64-bit CE targets, high 32-bit DMA address words in ring base registers, RRI registers, or `_ath10k_ce_send_nolock_64()` must be masked with `CE_DESC_ADDR_HI_MASK` (`GENMASK(4, 0)`), and destination addresses in `__ath10k_ce_rx_post_buf_64()` must be masked with `CE_DESC_ADDR_MASK` (`GENMASK_ULL(34, 0)`). In `ath10k_debug_get_et_stats()`, the number of `data[i++]` entries written must equal `ATH10K_SSTATS_LEN` (`ARRAY_SIZE(ath10k_gstrings_stats)`). [F96, F116]

## Known Pitfalls
- Because `struct bmi_cmd` sizes its union `payload` for `BMI_MAX_DATA_SIZE`, `ath10k_bmi_lz_data_large()` must `kzalloc()` `sizeof(*cmd) + BMI_MAX_LARGE_DATA_SIZE - BMI_MAX_DATA_SIZE` bytes and `kfree(cmd)` on all return paths. In `ath10k_bmi_write_memory()`, each chunk must copy `txlen = min(length, BMI_MAX_DATA_SIZE - hdrlen)` before `roundup(txlen, 4)`, and clamp `txlen = min(txlen, length)` after sending before subtracting from `length`. [F4, F85, F87]
- When walking `struct ath10k_fw_ie` records in `ath10k_core_parse_bd_ie_board()`, `ath10k_core_search_bd()`, and `ath10k_core_fetch_firmware_api_n()`, the cursor and remaining length must advance by `sizeof(*hdr)` and then `ALIGN(ie_len, 4)`. String IE payloads (`ATH10K_FW_IE_FW_VERSION`, `ATH10K_BD_IE_BOARD_NAME`) are not NUL-terminated and must be bounded by `ie_len`/`board_ie_len`, and `ATH10K_FW_IE_FEATURES` must be unpacked byte-by-byte (`i / 8`, `i % 8`) via `__set_bit()` into `fw_file->fw_features`. [F127, F133, F135]
- Callers of `ath10k_core_get_fw_features_str()` must zero-initialize `buf`; `ath10k_core_create_board_name()` must zero-initialize stack buffer `variant`; `ath10k_tpc_stats_fill()` must write a NUL terminator to `vmalloc`-allocated `buf` on all paths (including `!tpc_stats`); and debugfs `.write` handlers parsing `buf` with `sscanf()`/`strcmp()` must zero-initialize `buf` and pass `sizeof(buf) - 1` to `simple_write_to_buffer()`. [F42, F43, F132, F134]
- In `ath10k_core_start()`, initializing `ar->free_vdev_map` must branch on `ar->max_num_vdevs >= 64` to assign `0xFFFFFFFFFFFFFFFFLL` and use `(1LL << ar->max_num_vdevs) - 1` only when `< 64`, and `ath10k_wmi_pdev_set_base_macaddr()` must be called after unified ready (ignoring `-EOPNOTSUPP`). `ath10k_core_stop()` must reset `ar->id.bmi_ids_valid = false`; `ATH10K_FLAG_RAW_MODE` requires `rx_decap_mode = ATH10K_HW_TXRX_RAW` and `max_num_amsdu = 1`; and `ath10k_init_uart()` must return `0` immediately when `!uart_print` after `uart_pin_workaround`. [F65, F69, F70, F98, F113]
