# CLOCKSOURCE, CLOCKEVENT DRIVERS

This component provides core Device Tree and ACPI timer probing infrastructure (`timer-probe.c`, `timer-of.c`) and hardware-specific clocksource, clockevent, `sched_clock`, delay timer, and watchdog drivers for ARM, RISC-V, and MIPS SoCs. It manages early boot timer initialization (`TIMER_OF_DECLARE`), platform driver lifecycles, per-CPU timer interrupts, CPU hotplug callbacks, runtime PM, and clock rate change notifications.

## Architecture & Data Flow

- On TI OMAP timers with `OMAP_TIMER_ERRATA_I103_I767`, `OMAP_TIMER_CTRL_POSTED` must not be enabled if the counter register is ever read: `__omap_dm_timer_enable_posted()` forces `OMAP_TIMER_NONPOSTED`, and `dmtimer_clkevt_init_common()` enables posted mode only because clockevents never read `t->counter`. [F120]
- When stopping a running TI OMAP2+ dmtimer by clearing `OMAP_TIMER_CTRL_ST` in `__omap_dm_timer_stop()` or `dmtimer_clockevent_shutdown()`, the driver must read back the control register to flush the posted write and wait `udelay(3500000 / rate + 1)` before clearing `OMAP_TIMER_INT_OVERFLOW`. [F129]
- In `timer-ti-dm.c`, `omap_dm_timer_write_counter()` must update `timer->context.tcrr = value` alongside writing `OMAP_TIMER_COUNTER_REG` so `omap_timer_restore_context()` does not restore a stale `tcrr`, and `omap_dm_timer_cap_counter()` must preserve `OMAP_TIMER_CTRL_ST` (`l &= ~(0xffff) | 0x1`) when clearing capture configuration because `omap_dm_timer_start()` left the timer started and runtime-resumed. [F61, F63]
- In `timer-ti-dm-systimer.c`, `dmtimer_systimer_setup()` stores `u8` offsets from `t->base` (`io_base`), adding `OMAP_TIMER_V2_FUNC_OFFSET` (`0x14`) only to V2 functional registers (`pend`, `load`, `counter`, `ctrl`, `wakeup`, `ifctrl`) while keeping `sysc`, `irq_stat`, and `irq_ena` at direct `io_base` offsets. Conversely, in `timer-ti-dm.c`, `dmtimer_read()`/`dmtimer_write()` index from `timer->func_base` via `(reg & 0xff)` (with write-pending in `reg >> WPSHIFT`), so `__omap_dm_timer_init_regs()` must subtract `OMAP_TIMER_V2_FUNC_OFFSET` from V2 `irq_stat`, `irq_ena`, and `irq_dis`. [F72, F73]
- In `timer-nxp-stm.c`, `stm_timer->cs` and `stm_timer->ced` share the STM module counter and `STM_CR` enable bits (`STM_ENABLE_MASK`), so module enable/disable must be refcounted via `nxp_stm_module_get()` and `nxp_stm_module_put()` (`stm_timer->refcnt`) while clockevent state changes only toggle `STM_CCR_CEN` in `STM_CCR0`. [F56]
- In `timer-stm32.c` and `timer-stm32-lp.c`, `stm32_timer_set_prescaler()` and `stm32_clkevent_lp_set_prescaler()` must update the cached clock `rate`, `period`, and (for LPTIM) `priv->psc` in lockstep; for 16-bit timers in `stm32_timer_set_prescaler()`, the prescaler must be clamped to `TIM_PSC_MAX` (`USHRT_MAX`) before writing `prescaler - 1` to `TIM_PSC` and dividing `to->of_clk.rate`. In `stm32_timer_init()`, `to->private_data` must be allocated before `stm32_timer_set_width(to)`, which must precede `stm32_timer_set_prescaler()`, `stm32_clocksource_init()`, and `stm32_clockevent_init()`. [F45, F57, F78]
- In `timer-stm32-lp.c`, `stm32_clkevent_lp_set_timer()` must branch on `priv->version == STM32_LPTIM_VERR_23`: v2.3 (`stm32mp25_clkevent_lp_set_evt()`) sets `STM32_LPTIM_ENABLE` (`udelay(63)`) before writing `STM32_LPTIM_ARR`/`STM32_LPTIM_IER`, and its `STM32_LPTIM_ISR` poll must check `(val & STM32_LPTIM_DIEROK_ARROK) == STM32_LPTIM_DIEROK_ARROK` before clearing `STM32_LPTIM_DIEROKCF_ARROKCF`, whereas older versions write `IER` while `STM32_LPTIM_CR` is 0. [F80, F121]
- In `timer-sun4i.c` and `timer-sun5i.c`, `sun4i_clkevt_sync()` and `sun5i_clkevt_sync()` busy-wait until downward-counting 32-bit timer 1 advances by `TIMER_SYNC_TICKS` using `u32` modular subtraction `(old - readl(...)) < TIMER_SYNC_TICKS`; timer 1 must be enabled before `sun4i_clkevt_time_stop()` or `sun5i_clkevt_time_stop()` is ever called and must never be disabled, and `clockevents_config_and_register()` must set `min_delta >= TIMER_SYNC_TICKS`. [F88, F101]

## Synchronization

- In `riscv_timer_init_common()`, `riscv_clock_event_irq`, `riscv_timer_cannot_wake_cpu`, and the `riscv_sstc_available` static branch must be initialized and enabled before `cpuhp_setup_state()` is called, because `cpuhp_setup_state()` immediately invokes `riscv_timer_starting_cpu()` and programs the first timer event. [F14]
- Before calling `sched_clock_register()`, the global pointer and hardware counter read by the `notrace` callback (`stm_sched_clock` in `timer-nxp-stm.c`, `sched_clkevt` in `timer-sp804.c`, `stm32_timer_cnt` in `timer-stm32.c`, and `dmtimer_sched_clock_counter` in `timer-ti-dm-systimer.c`) must be initialized and started. [F27]
- In `nxp_stm_clockevent_set_next_event()`, `stm32_clock_event_set_next_event()`, and `pxa_osmr0_set_next_event()`, after writing the target compare value to the free-running timer's comparator register, the hardware counter must be re-read to return `-ETIME` if the counter wrapped or advanced past the compare target before the write completed. [F28]
- In `timer-ti-dm.c`, `omap_dm_timer_runtime_suspend()` and `omap_dm_timer_runtime_resume()` must verify `timer->func_base` is non-NULL before calling `omap_timer_save_context()` or `omap_timer_restore_context()`, and `omap_dm_timer_runtime_suspend()` must clear `timer->enabled` before `omap_timer_save_context()` while `omap_dm_timer_runtime_resume()` must set `timer->enabled` after `omap_timer_restore_context()` because `omap_timer_context_notifier()` gates save/restore on `atomic_read(&timer->enabled)`. [F25, F36]
- All accesses to `omap_timer_list` and initial `timer->reserved` reservation in `_omap_dm_timer_request()`, `omap_dm_timer_modify_idlect_mask()`, `omap_dm_timer_probe()`, and `omap_dm_timer_remove()` must be protected by `spin_lock_irqsave(&dm_timer_lock, flags)`, while `omap_dm_timer_prepare()` (which invokes synchronous runtime PM) must be called after dropping `dm_timer_lock`. [F140]
- `__omap_dm_timer_stop()` (invoked by `omap_dm_timer_stop()`) must use the cached `timer->fclk_rate` (populated in `omap_dm_timer_probe()` and updated by `omap_timer_fclk_notifier()`) rather than calling `clk_get_rate()`, which acquires a sleeping clock lock. [F139]
- In `timer-orion.c`, all modifications to `timer_base + TIMER_CTRL` (`orion_clkevt_next_event()`, `orion_clkevt_shutdown()`, `orion_clkevt_set_periodic()`, and `orion_timer_init()`) must use `atomic_io_modify()` with only the target timer's enable/reload bits masked so they do not race with `orion_wdt` or clobber the sibling timer's bits. [F51]
- Because Tegra186's 56-bit TSC counter is split across unsynchronized 32-bit registers `TKETSC0` (low) and `TKETSC1` (high 24 bits), `tegra186_timer_tsc_read()` must re-read `TKETSC0` and `TKETSC1` in a loop until `TKETSC1` matches its prior snapshot before combining `((u64)hi << 32 | lo)` (casting `u32` `hi` to `u64` before shifting). [F76, F97]
- `stm32mp25_clkevent_lp_set_evt()` is invoked from atomic `clock_event_device` callbacks (`stm32_clkevent_lp_set_next_event`, `stm32_clkevent_lp_set_periodic`, `stm32_clkevent_lp_set_oneshot`) and must use non-sleeping delays (`udelay`) and atomic polling (`regmap_read_poll_timeout_atomic`). [F148]

## Object Lifetimes

- In `timer-tegra.c`, because `timer_of_init()` is called only on `this_cpu_ptr(&tegra_to)` and the per-CPU loop overwrites each `cpu_to->of_base.base` with `timer_reg_base + base`, the loop must explicitly populate `cpu_to->of_base.base`, `cpu_to->of_clk.rate`, and `cpu_to->of_clk.period` for every CPU; if `request_irq()` fails, `cpu_to->clkevt.irq` must be disposed and cleared to `0`, and any post-loop error path (`out_irq`) must restore `to->of_base.base = timer_reg_base` before calling `timer_of_cleanup(to)`. [F4, F32, F54]
- In `timer-riscv.c`, `riscv_clock_event_stop()` must be called in `riscv_timer_starting_cpu()` before `clockevents_config_and_register()` and `enable_percpu_irq()`, and in `riscv_timer_dying_cpu()` before `disable_percpu_irq()`, so undefined `CSR_STIMECMP` reset values or pending interrupts do not fire. [F113]
- In `_omap_dm_timer_request()`, `timer->reserved` is set to `1` while holding `dm_timer_lock` (clearing any prior non-exact candidate's `timer->reserved = 0` in `REQUEST_BY_CAP` mode), and if `omap_dm_timer_prepare(timer)` fails after dropping `dm_timer_lock`, `timer->reserved` must be reset to `0` and `timer` cleared to `NULL`. [F11]
- In `timer-ti-dm.c`, `omap_dm_timer_start()` and `omap_dm_timer_enable()` hold a `pm_runtime_resume_and_get()` reference until `omap_dm_timer_stop()` or `omap_dm_timer_disable()` calls `pm_runtime_put_sync()`, whereas one-shot helpers like `omap_dm_timer_prepare()` must call `pm_runtime_put_sync()` before returning. [F12]
- In `omap_dm_timer_probe()` and `omap_dm_timer_remove()`, non-always-on timers (`!(timer->capability & OMAP_TIMER_ALWON)`) register `timer->nb` via `cpu_pm_register_notifier()`, enable runtime PM via `pm_runtime_enable()`, and join `omap_timer_list` under `dm_timer_lock`; `omap_dm_timer_remove()` must undo all three and must `break` immediately after `list_del(&timer->node)` when iterating `omap_timer_list` with `list_for_each_entry()`. [F13, F84]
- In `timer-sun5i.c`, `st->clksrc` is registered via non-devres `clocksource_register_hz()` while `st`, `st->base`, `st->clk`, `st->clk_rate_cb`, and the IRQ are devres-managed, so `clocksource_unregister(&st->clksrc)` must be called on `sun5i_setup_clockevent()` failure and in `sun5i_timer_remove()`. [F118]
- Every `struct device_node *` returned by `of_find_compatible_node()` or `of_find_matching_node()`, or held when breaking early out of `for_each_matching_node()` (as in `timer-ti-dm-systimer.c` and `timer-riscv.c`), must have its reference released with `of_node_put()` or `__free(device_node)` on all return paths. [F124]

## API Contracts

- Every callback registered with `sched_clock_register()` (such as `riscv_sched_clock`, `nxp_stm_read_sched_clock`, `tegra_read_sched_clock`, and `dmtimer_read_sched_clock`) and its non-inline helpers (`pistachio_clocksource_read_cycles`, `ti_32k_read_cycles`) must be marked `notrace`. [F137]
- In `timer-of.c`, `timer_of_irq_init()` and `timer_of_irq_exit()` pass `&to->clkevt` (`struct clock_event_device *`) as the `void *dev_id` cookie to `request_irq()` and `free_irq()`, so any `of_irq.handler` registered with `TIMER_OF_IRQ` must cast `dev_id` to `struct clock_event_device *` and use `to_timer_of()` to recover `struct timer_of *`. [F105]
- In `timer-ti-dm.c`, `omap_dm_timer_read_status()`, `omap_dm_timer_write_status()`, and `omap_dm_timer_read_counter()` do not call runtime PM and require `atomic_read(&timer->enabled)` to be non-zero, whereas configuration ops in `dmtimer_ops` bracket access with runtime PM. In `omap_dm_timer_set_int_disable()`, revision 1 timers must write `dmtimer_read(timer, timer->irq_ena) & ~mask` to `timer->irq_ena`, whereas revision 2 timers must write `mask` directly to `timer->irq_dis` (`OMAP_TIMER_V2_IRQENABLE_CLR`). [F65, F158]
- In `timer-ti-dm-systimer.c`, `dmtimer_clkevt_init_common()` must set `dev->set_state_oneshot_stopped` (alongside `set_state_shutdown`, `set_state_oneshot`, and `tick_resume`) to `dmtimer_clockevent_shutdown` so programming `KTIME_MAX` stops `OMAP_TIMER_CTRL_ST` and clears `OMAP_TIMER_INT_OVERFLOW`. [F149]
- In `timer-riscv.c`, `riscv_clocksource.mask` must be `CLOCKSOURCE_MASK(64)` and `sched_clock_register()` in `riscv_timer_init_common()` must pass `64` bits rather than `BITS_PER_LONG` because `riscv_clocksource_rdtime()` and `riscv_sched_clock()` read a 64-bit counter via `get_cycles64()` on both RV32 and RV64. [F150]
- In `timer-tegra186.c`, `tegra186_wdt_set_timeout()`, `tegra186_wdt_get_timeleft()`, `tegra186_timer_suspend()`, and `tegra186_timer_resume()` must check `watchdog_active(&wdt->base)` before touching hardware or computing remaining time. Because `tegra186_wdt_enable()` programs `TMRCR_PTV` in microseconds as `wdt->base.timeout * (USEC_PER_SEC / 5)` for 5 expirations, `tegra186_wdt_get_timeleft()` must reject `WDTSR_CURRENT_EXPIRATION_COUNT > 4`, add `(wdt->base.timeout * (USEC_PER_SEC / 5)) * (4 - expiration)` to `TMRSR_PCV`, and divide by `USEC_PER_SEC`, folding `(USEC_PER_SEC / 5)` at compile time in `u32` arithmetic rather than emitting 64-bit runtime division. [F34, F95, F156]

## Error Handling

- Timer initialization paths that derive tick periods, prescalers, or stop delays from `clk_get_rate()`—including `timer_of_clk_init()`, `sun5i_timer_probe()`, `stm32_clkevent_lp_probe()`, and `dmtimer_systimer_init_clock()`—must check that the rate is non-zero and fail with an error before dividing by rate or registering timekeeping devices. [F98]
- In `timer-ti-dm.c`, `omap_dm_timer_probe()` sets `timer->fclk = ERR_PTR(-ENODEV)` on OMAP1 devices (`timer->omap1`), so any function accessing `timer->fclk` (such as `omap_dm_timer_set_source()` and `omap_dm_timer_get_fclk()`) must check `!IS_ERR(timer->fclk)` rather than only checking for `NULL`. In `dmtimer_systimer_init_clock()` and `ti_32k_timer_enable_clock()`, `ERR_PTR(-EINVAL)` from `of_clk_get_by_name()` for the optional `"ick"` clock must be treated as non-fatal (leaving `t->ick` `NULL`). [F35, F41]
- In `timer-sp804.c`, `sp804_of_init()` must reset `clk1` and `clk2` from `IS_ERR()` to `NULL` on `of_clk_get()` failure because `sp804_get_clock_rate()` only falls back to `clk_get_sys("sp804", name)` when its `clk` argument is `NULL`, and callers of `sp804_get_clock_rate()` must store the result in a signed `long` and check `rate < 0`. [F43]

## External Contracts

- In `timer-ti-dm-systimer.c`, interconnect target module properties (`"ti,no-reset-on-init"`, `"ti,no-idle"`) and clocks (`"fck"`, `"ick"` in `dmtimer_systimer_setup()`) must be queried on `np->parent` (`"ti,sysc"`), whereas timer-specific properties and `of_iomap()` use `np`. `dmtimer_is_preferred()` must reject any timer DT node whose parent lacks `"ti,no-reset-on-init"` or `"ti,no-idle"`, whose node has `"ti,timer-dsp"` or `"ti,timer-pwm"`, or whose non-secure node (`!"ti,timer-secure"`) lacks `"assigned-clocks"` or `"assigned-clock-parents"`. [F93, F127]

## Known Pitfalls

- In timer interrupt handlers that disarm oneshot timers in software (`riscv_timer_interrupt`, `nxp_stm_module_interrupt`, `stm32_clock_event_handler`, `sprd_timer_interrupt`, `pxa_ost0_interrupt`, and `zevio_timer_interrupt`), the timer must be stopped or disarmed before invoking `clkevt->event_handler(clkevt)`. [F152]
- In 32-bit downward-counting clocksource and `sched_clock` readers (`pistachio_clocksource_read_cycles()`, `sun5i_clksrc_read()`, `sun4i_timer_sched_read()`, `orion_read_sched_clock()`, `sp804_read()`, and `sprd_suspend_timer_read()`), bitwise negation `~` must be applied to a 32-bit `u32` before widening to `u64` or masked with `cs->mask`. [F104]
- Because Tegra hardware timers fire after `n + 1` ticks when loaded with `n`, `tegra_timer_setup()` registers tick bounds `[1, 0x1fffffff + 1]` with `clockevents_config_and_register()`, and `tegra_timer_set_next_event()` and `tegra_timer_set_periodic()` must write `(cycles - 1)` and `(period - 1)` into `TIMER_PTV`. [F68]
