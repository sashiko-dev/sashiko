# HWPOISON MEMORY FAILURE HANDLING

This unit (`mm/memory-failure.c` and `mm/hwpoison-inject.c`) implements hardware memory failure (hwpoison) recovery, soft-offlining, software unpoisoning, and debugfs fault injection. It isolates corrupted or suspicious page frames from the buddy allocator, LRU lists, swap cache, or page cache, unmaps affected user-space PTEs, and signals mapped processes with `SIGBUS`, handling standard pages, Hugetlb folios, THPs, KSM pages, and `ZONE_DEVICE` (fsdax/devdax) pages.

## Architecture & Data Flow

- `unmap_poisoned_folio()` must clear `TTU_HWPOISON` from `ttu` when `folio_test_swapcache(folio)` is true, or when `!must_kill && !folio_test_dirty(folio) && mapping && mapping_can_writeback(mapping)` and `folio_mkclean(folio)` returns 0, so `try_to_unmap()` does not install hwpoison swap entries. [F62]
- `folio_clear_hugetlb_hwpoison()` and `folio_free_raw_hwp(folio, true)` must return without clearing `PG_hwpoison` or freeing the `raw_hwp_page` list while `folio_test_hugetlb_vmemmap_optimized(folio)` is true, because tail `struct page` entries cannot be individually marked `PG_hwpoison` until vmemmap optimization is restored. [F49]
- In `has_extra_refcount()`, when `extra_pins` is true (folio remains in pagecache or swapcache), `count` must be decremented by `folio_nr_pages(page_folio(p))` rather than 1, in addition to subtracting 1 for `memory_failure()`'s reference. [F11]
- `folio_set_hugetlb_hwpoison()` only calls `num_poisoned_pages_inc()` when the folio was already poisoned (`ret != 0`) because `action_result()` counts the first error; `unpoison_memory()` skips `num_poisoned_pages_sub()` when `huge` is true because `__folio_free_raw_hwp()` decrements it per node; and `num_poisoned_pages_sub(pfn, i)` treats `pfn == -1UL` as a sentinel to skip `memblk_nr_poison_sub(pfn, i)` (`-1UL` must not be passed to `num_poisoned_pages_inc()`). [F12, F45]
- Because `take_page_off_buddy()` marks isolated free pages with `SetPageHWPoisonTakenOff(page)` (`page_private(page) == MAGIC_HWPOISON`), `__get_unpoison_page()` must check `PageHWPoisonTakenOff(page)` before `get_page_unless_zero(page)` and return `-EHWPOISON` so `unpoison_memory()` routes them to `put_page_back_buddy(p)` instead of `folio_put()`. [F54]
- In `delete_from_lru_cache()`, when `folio_isolate_lru(folio)` succeeds, `folio_clear_active(folio)`, `folio_clear_unevictable(folio)`, and `mem_cgroup_uncharge(folio)` must be called before `folio_put(folio)` because a poisoned folio's refcount may never reach 0. [F55]
- When `memory_failure()` runs without `MF_SW_SIMULATED`, it latches `hw_memory_failure = true` under `mf_mutex`; `unpoison_memory()` must fail with `-EOPNOTSUPP` when `hw_memory_failure` is true (checked under `mf_mutex`) or when `is_huge_zero_folio(folio)` is true (checked before testing/clearing `PageHWPoison(p)` or changing refcounts). [F51, F75]
- In `error_states[]`, specific page-flag bitmasks (`PG_reserved`, `PG_head`, `PG_swapcache`, `PG_mlocked`, `PG_unevictable`) must precede general `PG_lru` entries, and `{ 0, 0, MF_MSG_UNKNOWN, me_unknown }` must remain last because `identify_page_state()` stops at the first `(flags & ps->mask) == ps->res` match. [F72]
- Every `enum mf_result` passed to `action_result()` needs a matching entry in `action_name[]` and a case in `update_per_node_mf_stats()` (which must verify `nid >= 0 && nid < MAX_NUMNODES` on `pfn_to_nid(pfn)` before indexing `NODE_DATA(nid)->mf_stats`), and every `enum mf_action_page_type` needs a non-NULL entry in `action_page_types[]`. [F63, F68]

## Synchronization

- In `__get_hwpoison_page()` and `__get_unpoison_page()`, after `get_hwpoison_hugetlb_folio(folio, &hugetlb, ...)` sets `hugetlb == true`, the caller must revalidate `folio == page_folio(page)` and call `folio_put(folio)` if `ret > 0` on mismatch (due to concurrent hugetlb demotion before `hugetlb_lock`). For non-hugetlb pages in `__get_hwpoison_page()`, `HWPoisonHandlable(&folio->page, flags)` must be checked before `folio_try_get(folio)`, and `folio == page_folio(page)` must be revalidated after `folio_try_get(folio)` (calling `folio_put(folio)` on mismatch). [F22, F23]
- In `unmap_poisoned_folio()`, `hugetlb_folio_mapping_lock_write(folio)` and `TTU_RMAP_LOCKED` must be used when calling `try_to_unmap()` on a shared (`!folio_test_anon(folio)`) hugetlb folio to synchronize against `huge_pmd_unshare()`, and must not be used for anonymous hugetlb folios. [F24]
- Because DAX pages do not use the folio lock, `mf_generic_kill_procs()` must hold `dax_lock_folio(folio)` and `mf_dax_kill_procs()` must hold `dax_lock_mapping_entry(mapping, index, &page)` across `SetPageHWPoison()`, `collect_procs()`/`collect_procs_fsdax()`, and `unmap_and_kill()`; any non-zero `dax_entry_t cookie` returned must be passed to the matching `dax_unlock_*` on every exit path, including when `page` is NULL or `hwpoison_filter()` fails. [F13, F26]
- In `memory_failure()` and `try_memory_failure_hugetlb()`, `hwpoison_filter(p)` must be evaluated while holding `folio_lock(folio)` (and in `mf_generic_kill_procs()` while holding `dax_lock_folio(folio)`), because the pre-check in `hwpoison_inject()` is unlocked and racy. [F30]
- Callers of `task_early_kill()` and `find_early_kill_thread()` (`collect_procs_anon()`, `collect_procs_file()`, `collect_procs_fsdax()`, `collect_procs_ksm()`) must hold `rcu_read_lock()` across process/thread iteration, and `__add_to_kill()` called inside that section must allocate `struct to_kill` with `GFP_ATOMIC`. [F20]
- Accesses to per-CPU `mf_cpu->fifo` in `memory_failure_queue()` and `memory_failure_work_func()` must be protected by `raw_spin_lock_irqsave(&mf_cpu->lock, proc_flags)` (not `spinlock_t`, which sleeps on PREEMPT_RT), and `mf_cpu->lock` must be released before calling `soft_offline_page()` or `memory_failure()`. [F32]
- Traversing a hugetlb folio's `raw_hwp_list_head(folio)` (`folio->_hugetlb_hwpoison`) in `is_raw_hwpoison_page_in_hugepage()` must be protected by `mf_mutex` to serialize against concurrent modifications or freeing in `memory_failure()` and `unpoison_memory()`. [F28]
- `hwpoison_filter_func` must be published via `rcu_assign_pointer()` in `hwpoison_filter_register()`, read via `rcu_dereference()` under `rcu_read_lock()` in `hwpoison_filter()`, and cleared with `RCU_INIT_POINTER(..., NULL)` followed by `synchronize_rcu()` in `hwpoison_filter_unregister()` (which, along with `debugfs_remove_recursive(hwpoison_dir)`, must run in `pfn_inject_exit()` before module unload completes). [F17, F19]
- `kill_accessing_process()` must hold `mmap_read_lock(p->mm)` across `walk_page_range(p->mm, 0, TASK_SIZE, &hwpoison_walk_ops, &priv)` because `hwpoison_walk_ops.walk_lock` is `PGWALK_RDLOCK`. [F109]

## Object Lifetimes

- When `MF_COUNT_INCREASED` is set in `flags`, `memory_failure()` and `soft_offline_page()` take ownership of the caller's page reference and must release it via `put_ref_page(pfn, flags)` or `put_page()` on every early return before `get_hwpoison_page()`. Once `get_hwpoison_page()` runs in `soft_offline_page()`, `get_any_page()` has consumed `MF_COUNT_INCREASED`, so subsequent error paths must only call `put_page(page)` when `ret > 0`, and the `retry` path must clear `MF_COUNT_INCREASED` from `flags`. [F1, F2]
- In `unpoison_memory()`, `ret` must be initialized to `-EBUSY` and `get_hwpoison_page(p, MF_UNPOISON)` stored in a separate variable `ghp` so failure jumps to `unlock_mutex` do not return `1`; when `ghp > 0`, its extra reference on `folio` must be released with `folio_put(folio)` both when `folio_free_raw_hwp(folio, false)` fails (`count == 0`) and before dropping the poison reference under `TestClearPageHWPoison(p)`. [F6, F34]
- `memory_failure()` transfers ownership of `struct dev_pagemap *pgmap` from `get_dev_pagemap(pfn)` to `memory_failure_dev_pagemap()`, which must call `put_dev_pagemap(pgmap)` on all exit paths. [F8]
- Every `struct to_kill` node added by `__add_to_kill()` holds a `get_task_struct()` reference on `tk->tsk`; `kill_procs()` must always be called to iterate with `list_for_each_entry_safe()`, unlink via `list_del(&tk->nd)` (so callers like `mf_dax_kill_procs()` can reuse the `list_head`), call `put_task_struct(tk->tsk)`, and `kfree(tk)` even when `forcekill` is 0. [F9, F77]

## API Contracts

- Every `struct page_state` `.action` callback (`me_kernel`, `me_unknown`, `me_pagecache_clean`, `me_pagecache_dirty`, `me_swapcache_dirty`, `me_swapcache_clean`, `me_huge_page`) is entered with `p`'s folio locked and must unlock it before returning; callers of `identify_page_state()` must not unlock the folio afterward. [F7]
- `__add_to_kill()` and `kill_procs()` use `addr == -EFAULT` (cast to `unsigned long`) as a sentinel to send `SIGKILL` instead of `SIGBUS`: `add_to_kill_anon_file()` must drop `addr == -EFAULT` entries, `dev_pagemap_mapping_shift()` must never be called with `address == -EFAULT`, and in `__add_to_kill()` the `tk->addr == -EFAULT` check must precede `else if (tk->size_shift == 0)` so `-EFAULT` entries stay on `to_kill` while unmapped `ZONE_DEVICE` VMAs (`size_shift == 0`) are freed. [F43, F76]
- `mf_dax_kill_procs()` takes `index` and `count` in `PAGE_SIZE` pages, whereas `unmap_and_kill()` converts `tk->size_shift` to `size = 1UL << tk->size_shift` (guarded by `if (tk->size_shift)` using `1UL` so `size` is 0 for `-EFAULT` entries with `size_shift == 0`, or `>= PAGE_SIZE`) and aligns `((loff_t)index << PAGE_SHIFT) & ~(size - 1)` for `unmap_mapping_range()`. [F85, F115]
- `memory_failure_dev_pagemap()` must verify `pgmap_pfn_valid(pgmap, pfn)` before invoking `pgmap->ops->memory_failure()` or `mf_generic_kill_procs()` (rejecting altmap metadata pages with `-ENXIO`), and must only call `pgmap->ops->memory_failure()` when `pgmap_has_memory_failure(pgmap)` is true, falling back to `mf_generic_kill_procs()` if absent or if it returns `-EOPNOTSUPP`. [F66, F94]
- `unpoison_memory()` and `soft_offline_page()` must resolve PFNs via `pfn_to_online_page(pfn)` rather than `pfn_valid()` plus `pfn_to_page()`, rejecting offline (`PagePoisoned`) or `ZONE_DEVICE` pages before accessing `page_folio()`. [F65]
- Callers of `unmap_poisoned_folio()` (via `hwpoison_user_mappings()`) must ensure `folio` is not a large folio unless `folio_test_hugetlb(folio)` is true, because `try_to_unmap()` here cannot handle non-hugetlb large folios. [F113]
- In `try_memory_failure_hugetlb()`, `bool migratable_cleared` passed to `get_huge_page_for_hwpoison(pfn, flags, &migratable_cleared)` must be initialized to `false` because `__get_huge_page_for_hwpoison()` only assigns `*migratable_cleared = true` when clearing `hugetlb_migratable`. [F44]
- `hwpoison_walk_ops` must define `.test_walk = hwpoison_test_walk` returning 0 so `walk_page_range()` in `kill_accessing_process()` scans all VMAs, including `VM_PFNMAP`. [F110]

## Error Handling

- `__page_handle_poison()` returns `1` only when the page is both dissolved and taken off the buddy freelist (`0` if not taken off buddy, `< 0` on dissolve failure); callers (`page_handle_poison()`, `me_huge_page()`, `try_memory_failure_hugetlb()`) must check `> 0` before calling `page_ref_inc(p)` and reporting `MF_RECOVERED`. [F33]
- In `soft_offline_page()`, when `get_hwpoison_page()` returns `0` and `page_handle_poison(page, true, false)` returns `false` after retries (`!try_again`), `ret` must be set to `-EBUSY`; in `soft_offline_in_use_page()`, `migrate_pages()`'s return must be stored in a `long` and any positive unmigrated count (`ret > 0`) converted to `-EBUSY` after `putback_movable_pages(&pagelist)`. [F36, F37]
- `kill_accessing_process()` and `task_early_kill()` must check that the target task's `->mm` is non-NULL before dereferencing or locking it (since `memory_failure_work_func()` runs in a kthread with `current->mm == NULL`); in `kill_accessing_process()`, `walk_page_range()` returns `1` on match and `0` if already dropped, so `kill_proc()` must only run when `ret == 1 && priv.tk.addr`, returning `ret > 0 ? -EHWPOISON : 0`. [F38, F39]
- In `mf_dax_kill_procs()`, `page` must be reset to `NULL` before each `dax_lock_mapping_entry(mapping, index, &page)` call, and if a non-zero `cookie` is returned with `page == NULL`, the loop must skip `SetPageHWPoison()` and `collect_procs_fsdax()` while still calling `dax_unlock_mapping_entry()`. [F42]

## External Contracts

- In `mm/hwpoison-inject.c`, `hwpoison_inject()` and `hwpoison_unpoison()` must check `capable(CAP_SYS_ADMIN)` before acting on a PFN (`hwpoison_inject()` must also check `pfn_valid(pfn)` before `pfn_to_page(pfn)`), and `hwpoison_filter_dev()` must treat `~0U` in `hwpoison_filter_dev_major` or `hwpoison_filter_dev_minor` as a wildcard matching any device major/minor. [F71, F124]

## Known Pitfalls

- In `hwpoison_user_mappings()`, `collect_procs()` must be called before `unmap_poisoned_folio()` (before rmap teardown), and `forcekill` (`folio_test_dirty(folio) || (flags & MF_MUST_KILL) || !unmap_success`) must be evaluated only after `unmap_poisoned_folio()` has propagated PTE dirty bits to the folio. [F58]
- Before calling `folio_mapped(folio)` in `unpoison_memory()` or `hwpoison_user_mappings()`, callers must check and exclude `folio_test_slab(folio)`, `folio_test_pgtable(folio)`, `folio_test_reserved(folio)`, and `folio_test_offline(folio)` because non-user-mapped types (like SLAB) overload `_mapcount`. [F41]
- In `collect_procs()`, `collect_procs_anon()`, and `collect_procs_file()`, `mapping` and `anon_vma` must be obtained from `folio` (tail `page->mapping` is invalid), while `page_pgoff(folio, page)`, `page_mapped_in_vma()`, and `page_address_in_vma()` must be called with the specific poisoned subpage `page`. Similarly, in `unpoison_memory()`, non-hugetlb pages must use `PageHWPoison(p)` and `TestClearPageHWPoison(p)` on `p` rather than `folio_test_hwpoison(folio)`. [F116, F117]
- In `memory_failure()`, after locking `folio`, `folio_wait_writeback(folio)` must not be skipped unless both `!folio_test_lru(folio)` and `!folio_test_writeback(folio)` hold, because `__munlock_folio()` can clear `PG_lru` on a writeback folio without holding the folio lock. [F120]
- Before calling `hwpoison_user_mappings()`, `memory_failure()` and `try_memory_failure_hugetlb()` must snapshot `page_flags = folio->flags.f` so `identify_page_state()` can merge live `PG_dirty` (`p->flags.f & (1UL << PG_dirty)`) and fall back to pre-unmap flags if `try_to_unmap()` clears flags like `PG_mlocked`. [F73]
- In `hwpoison_pte_range()`, `pte_offset_map_lock()` must be paired with `pte_unmap_unlock(mapped_pte, ptl)` before `cond_resched()` or returning, passing the original `mapped_pte` pointer rather than the `ptep` iterator (which advances past the page-table page at a PMD boundary); in `dev_pagemap_mapping_shift()`, `pte_offset_map()` must be paired with `pte_unmap()`. [F87, F108]
