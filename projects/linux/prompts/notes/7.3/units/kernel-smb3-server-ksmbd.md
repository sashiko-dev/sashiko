# KERNEL SMB3 SERVER (KSMBD)

This unit (`fs/smb/server`) implements SMB1/SMB2/SMB3 PDU parsing, command dispatch, and response generation for ksmbd, alongside Windows Security Descriptor / POSIX ACL translation and the Generic Netlink IPC transport to `ksmbd.mountd`.

## Architecture & Data Flow
- In `is_chained_smb2_message()` and `init_chained_smb2_rsp()`, advancing to a chained command (`next_cmd > 0`) requires 64-bit checks against `get_rfc1002_len(work->request_buf)` and `work->response_sz` (`+ MAX_CIFS_SMALL_BUFFER_SIZE`), saving `work->curr_smb2_rsp_hdr_off = work->next_smb2_rsp_hdr_off` before advancing (so `smb2_set_sign_rsp()` / `smb3_set_sign_rsp()` sign via `ksmbd_resp_buf_curr(work)`), and `ALIGN(len, 8)` padding added to both `work->iov[work->iov_idx].iov_len` and `inc_rfc1001_len()`. [F58, F59, F82]
- In `init_chained_smb2_rsp()`, if the next compound command lacks `SMB2_FLAGS_RELATED_OPERATIONS`, `work->compound_fid` and `work->compound_pfid` must be reset to `KSMBD_NO_FID`; `smb2_close()` must also reset both to `KSMBD_NO_FID` when closing a compound FID. [F60]
- In `smb2_sess_setup()`, `conn->binding` must be set to `false` on new (`!req->hdr.SessionId`) or non-binding reauthenticated sessions, and `true` only on validated `SMB2_SESSION_REQ_FLAG_BINDING` requests. When `conn->binding` is true on `SMB311_PROT_ID`, `generate_preauth_hash()` and `smb3_preauth_hash_rsp()` must update the per-connection `preauth_sess->Preauth_HashValue` from `ksmbd_preauth_session_lookup()` rather than mutating the shared `sess->Preauth_HashValue`. [F61, F62]
- In `smb2_sess_setup()`, any `conn->mechToken` allocated while `conn->use_spnego` is true must be freed and reset to `NULL` before returning so subsequent requests on `conn` do not read a stale token in `user_authblob()` or `session_user()`. [F63]
- In `parse_sec_desc()`, `acl_len` and non-zero `osidoffset`/`gsidoffset`/`dacloffset` must be `>= sizeof(struct smb_ntsd)`, and in `parse_dacl()`, `end_of_acl` must cover `sizeof(struct smb_acl)` and `le16_to_cpu(pdacl->size)` with `num_aces` bounded by `pdacl->size` before allocation. In `smb_inherit_dacl()` and `smb_check_perm_dacl()`, adding `sizeof(struct smb_acl)` to `dacloffset` requires `check_add_overflow()`, and `smb_inherit_dacl()` must cast `osidoffset`, `gsidoffset`, and `dacloffset` to `u64` before adding SID/ACL sizes against `pntsd_alloc_size`. [F92, F115, F116]
- In `parse_sec_desc()`, `pntsd->type` must be sampled into `pntsd_type` before overwriting `pntsd->type = cpu_to_le16(DACL_PRESENT)` in place so `DACL_PROTECTED` and `DACL_AUTO_INHERITED` can be restored before `set_info_sec()` writes `pntsd` to the xattr; `DACL_AUTO_INHERITED` is set only when both `DACL_AUTO_INHERITED` and `DACL_AUTO_INHERIT_REQ` bits are set together in `pntsd_type`. [F71, F99]
- Before calling `ksmbd_vfs_set_sd_xattr()` in `set_info_sec()` or `smb2_open()`, any changes to the target inode's POSIX ACLs (`set_posix_acl()`, `ksmbd_vfs_inherit_posix_acl()`, `ksmbd_vfs_set_init_posix_acl()`) and UID/GID/mode (`notify_change()`) must already be committed to the inode. [F148]
- When validating wire offset/header plus length against buffer bounds in `session_user()`, `smb2_create_link()`, `set_rename_info()`, and `smb2_write_pipe()`, the base offset or `sizeof` expression must be widened to `u64` before adding the 32-bit wire length. [F118]
- In `smb2_query_dir()`, `d_info.num_scan` must be reset to `0` before each `iterate_dir()` at `again:`, and `__query_dir()` must increment `d_info->num_scan` before veto/pattern filters. After `ksmbd_populate_dot_dotdot_entries()`, `d_info.rptr` is set to `d_info.wptr` and `buffer_sz` saved from `d_info.out_buf_len`; before `process_query_dir_entries()`, `d_info.wptr` must be reset to `d_info.rptr` and `d_info.out_buf_len` restored to `buffer_sz`. [F102, F104]
- Directory query `FileInformationClass` changes in `smb2pdu.c` require lockstep updates to `verify_info_level()`, `readdir_info_level_struct_sz()`, `reserve_populate_dentry()`, `dentry_name()`, and `smb2_populate_readdir_entry()`. `reserve_populate_dentry()` must reserve `ALIGN(struct_sz + (d_info->name_len + 1) * 2, KSMBD_DIR_INFO_ALIGNMENT)` bytes, and `smb2_populate_readdir_entry()` must copy `d_info->name` via `ksmbd_convert_dir_info_name()` before writing to `d_info->wptr`. [F66, F103]
- Because `XATTR_USER_PREFIX` is shared between client EAs, streams (`STREAM_PREFIX`), and DOS attributes (`DOS_ATTRIBUTE_PREFIX`), `smb2_get_ea()` must skip `STREAM_PREFIX` and `DOS_ATTRIBUTE_PREFIX` xattrs, and `smb2_remove_smb_xattrs()` must only delete xattrs with `XATTR_USER_PREFIX` followed by `STREAM_PREFIX`. [F157]
- In `smb2_set_ea()`, each `struct smb2_ea_info` step must verify `buf_len >= sizeof(struct smb2_ea_info) + eabuf->EaNameLength + le16_to_cpu(eabuf->EaValueLength)` and `eabuf->EaNameLength <= XATTR_NAME_MAX - XATTR_USER_PREFIX_LEN`, stopping when `next == 0 || buf_len < next`. In `smb2_get_ea()`, `prev_eainfo` must be initialized to `eainfo` (`rsp->Buffer`) and updated before `eainfo` advances on each entry so `prev_eainfo->NextEntryOffset = 0` zeroes the last emitted entry's offset. [F88, F109]
- In `ksmbd_smb_check_shared_mode()`, when `ksmbd_stream_fd(prev_fp)` and `!ksmbd_stream_fd(curr_fp)`, the `FILE_SHARE_DELETE_LE` / `FILE_DELETE_LE` conflict check must execute before skipping the remaining share-mode checks via `continue`. [F96]
- `ksmbd_ipc_init()` must run `ksmbd_nl_init_fixup()` and `INIT_DELAYED_WORK(&ipc_timer_work, ipc_timer_heartbeat)` before `genl_register_family(&ksmbd_genl_family)`, and `ksmbd_ipc_release()` must call `cancel_delayed_work_sync(&ipc_timer_work)`. `ksmbd_nl_policy` must be sized `KSMBD_EVENT_MAX + 1` and `handle_generic_event()` must reject `type > KSMBD_EVENT_MAX` before indexing `info->attrs[type]`. [F22, F76]
- In `ipc_server_config_on_startup()`, non-zero `req->smb2_max_credits` must update `server_conf.max_inflight_req` alongside `init_smb2_max_credits()`. In `__ipc_heartbeat()`, `jiffies` must be checked with `time_after(jiffies, server_conf.ipc_last_active)` before subtracting `server_conf.ipc_last_active`. [F56, F121]

## Synchronization
- Any `cancel_fn` callback registered with `setup_async_work()` (such as `smb2_remove_blocked_lock()`) must not sleep, allocate with `GFP_KERNEL`, or acquire `conn->request_lock` (e.g., via `release_async_work()`), because `smb2_cancel()` invokes `iter->cancel_fn(iter->cancel_argv)` under `spin_lock(&conn->request_lock)`. [F20]
- Calling `notify_change(idmap, dentry, &attrs, NULL)` in `set_file_basic_info()`, `set_info_sec()`, and `set_ntacl_dacl()` requires `inode_lock(inode)`, whereas `inode_lock(inode)` must not be held across `set_posix_acl()` or `ksmbd_vfs_*_xattr()` calls in `set_info_sec()` and `set_file_basic_info()`. Reading `dentry->d_name.name` in `get_file_alternate_info()` requires holding `spin_lock(&dentry->d_lock)` while calling `ksmbd_extract_shortname()`, so `ksmbd_extract_shortname()` runs in atomic context and must not sleep. [F30, F139, F143]
- In `smb2_query_dir()`, the `iterate_dir()` actor `__query_dir()` runs under the directory inode's `i_rwsem` and must only buffer entry names via `reserve_populate_dentry()`, deferring `lookup_one_unlocked()` and `ksmbd_vfs_fill_dentry_attrs()` to `process_query_dir_entries()` after `iterate_dir()` returns. [F138]
- In `smb2_open()`, `fp->daccess`, `fp->saccess`, `fp->attrib_only`, and `fp->stream` must be initialized before acquiring `down_write(&fp->f_ci->m_lock)` to add `fp->node` to `fp->f_ci->m_fp_list`, which `ksmbd_smb_check_shared_mode()` traverses under `down_read(&curr_fp->f_ci->m_lock)`. [F141]
- `startup_lock` must be held in `handle_startup_event()`, `__ipc_heartbeat()`, and `ksmbd_ipc_soft_reset()` when updating `ksmbd_tools_pid`, reconfiguring `server_conf`, and cancelling `ipc_timer_work`. Because `ksmbd_ipc_soft_reset()` calls `cancel_delayed_work_sync(&ipc_timer_work)` under `startup_lock`, `__ipc_heartbeat()` must exit early when `!ksmbd_server_running()` before taking `startup_lock` and never reschedule `ipc_timer_work` after setting `SERVER_STATE_RESETTING`. [F23, F145]
- `fsctl_query_iface_info_ioctl()` must hold `rtnl_lock()` while iterating `for_each_netdev(&init_net, netdev)`, calling `__in_dev_get_rtnl()` / `__in6_dev_get()`, and walking `idev6->addr_list`, whereas `idev_ipv4_address()` must wrap `in_dev_for_each_ifa_rcu()` in `rcu_read_lock()` / `rcu_read_unlock()`. [F140]
- Generic Netlink handlers in `transport_ipc.c` (`handle_startup_event()`, `handle_generic_event()`) must check `netlink_capable(skb, CAP_NET_ADMIN)` under `CONFIG_SMB_SERVER_CHECK_CAP_NET_ADMIN` and `ksmbd_ipc_validate_version(info)` before accessing attributes. [F160]

## Object Lifetimes
- IPC helpers backed by `ipc_msg_send_request()` (`ksmbd_rpc_read()`, `ksmbd_rpc_write()`, `ksmbd_rpc_ioctl()`) return a `kvzalloc()` buffer the caller must `kvfree()`; when an error label also calls `kvfree(rpc_resp)`, the normal path must not free `rpc_resp` before fallible calls like `ksmbd_iov_pin_rsp_read()`. [F3]
- In `ipc_msg_send()`, `nlmsg_free(skb)` must only be called when `genlmsg_put()` or `nla_put()` fails (after `genlmsg_cancel()`), and never after `genlmsg_unicast()`, which consumes `skb` regardless of outcome. [F159]
- In `smb2_sess_setup()`, any error path dropping `sess` via `ksmbd_user_session_put(sess)` before `out_err` must set `sess = NULL`, and when `out_err` calls `ksmbd_user_session_put(sess)` on `rc < 0`, it must also clear `work->sess = NULL` to prevent double put during worker teardown. [F6]
- Both `ksmbd_acls_fattr()` and `parse_sec_desc()` populate `fattr->cf_acls` and `fattr->cf_dacls` with refcounted `struct posix_acl` objects, so callers must call `posix_acl_release()` on both on all exit paths. [F10]
- In `smb2_open()`, `ksmbd_open_fd(work, filp)` takes ownership of `filp` only on success; if it returns an `ERR_PTR`, the caller must `fput(filp)` and set `fp = NULL` before jumping to `err_out`, whereas after success `ksmbd_fd_put(work, fp)` at `err_out2` closes `filp`. [F12]

## API Contracts
- `setup_async_work(work, fn, arg)` takes ownership of `arg` (`work->cancel_argv`) and allocates `work->async_id` only when returning `0`; on failure the caller must `kfree(arg)`, whereas after success `release_async_work(work)` frees `work->cancel_argv` and `work->async_id`. [F5]
- `smb2_check_user_session()` and `smb2_get_ksmbd_tcon()` must only look up and acquire `work->sess` and `work->tcon` when `work->next_smb2_rcv_hdr_off == 0`, reusing existing references on chained commands. Both return negative errno on failure, `0` when exempt (causing `__handle_ksmbd_work()` to skip `get_ksmbd_tcon()`), and `1` when matched. [F7, F32]
- `__ksmbd_override_fsids()` and `ksmbd_override_fsids()` store prior credentials in the single-slot `work->saved_cred` (`WARN_ON(work->saved_cred)`), so callers must not nest them across helpers that override fsids internally (`ksmbd_vfs_remove_file()`, `ksmbd_vfs_link()`, `ksmbd_vfs_rename()`) and must pair each call with `ksmbd_revert_fsids()`. [F146]
- `smb2_find_context_vals()` returns a valid pointer when found, `NULL` when absent, or an `ERR_PTR` when malformed, so callers must check both `!IS_ERR()` and non-NULL before dereferencing. [F40]
- Before `parse_sec_desc()` in `set_info_sec()`, `struct smb_fattr fattr` must be zeroed and initialized with `cf_uid = INVALID_UID`, `cf_gid = INVALID_GID`, and `cf_mode = inode->i_mode`. `set_info_sec()` must only enforce the `!(le16_to_cpu(pntsd->type) & DACL_PRESENT)` early exit before writing the SD xattr when `type_check` is `true`, and both `set_info_sec()` and `smb2_set_ea()` must forward `get_write` to all inner `ksmbd_vfs_*xattr()` calls rather than hardcoding `true`. [F49, F50, F51]
- On idmapped mounts, `sid_to_id()` maps wire RIDs to `kuid_t`/`kgid_t` via `from_vfsuid()`/`from_vfsgid()`, whereas `ksmbd_acls_fattr()`, `find_file_posix_info()`, and `posix_acl_uid_translate()`/`posix_acl_gid_translate()` map inode/ACL IDs via `i_uid_into_vfsuid()`/`make_vfsuid()` before `from_kuid()`. [F150]
- `compare_sids()` returns `0` on match and non-zero otherwise, so equality checks require `!compare_sids(...)`. In `id_to_sid()`, `SIDCREATOR_OWNER` and `SIDCREATOR_GROUP` must `return` early without appending `cid` to `ssid->sub_auth[ssid->num_subauth++]`. [F34, F100]
- `ksmbd_lookup_dialect_by_id()`, `ksmbd_lookup_dialect_by_name()`, and `ksmbd_negotiate_smb_dialect()` return `BAD_PROT_ID` (`0xFFFF`) rather than a negative errno on no match, whereas `ksmbd_lookup_protocol_idx()` returns `-1` (and reverse dialect loops in `smb_common.c` require signed `int` counters). [F35, F86]
- `set_smb2_rsp_status()` must zero `work->iov_idx`, `work->iov_cnt`, and `work->next_smb2_rcv_hdr_off` and write `err` to the base `work->response_buf` header before calling `smb2_set_err_rsp()`. [F57]
- In `smb2_ioctl()` (`FSCTL_QUERY_ALLOCATED_RANGES`), `fsctl_query_allocated_ranges()` takes `in_count` and returns `*out_count` as element counts of `struct file_allocated_range_buffer`, requiring division of `out_buf_len` on input and multiplication of `nbytes` on return. In `smb2_lock()`, zero-length locks (`smb_lock->zero_len == 1`) must bypass `vfs_lock_file()`. [F125, F155]

## Error Handling
- `smb_strndup_from_utf16()` and `smb2_get_name()` return an `ERR_PTR` and never `NULL` on failure, so callers must check `IS_ERR()` and reset the pointer to `NULL` or guard `kfree()` with `!IS_ERR()` on cleanup. [F37]
- `ksmbd_acquire_id(&ipc_ida)` and `ksmbd_ipc_id_alloc()` return negative errno on failure; `ksmbd_rpc_id_free()` does not guard against negative IDs and must only be called when `handle >= 0`, whereas `ipc_msg_send_request()` requires `(int)handle < 0`. [F36]
- Callers of `ksmbd_alloc_work_struct()` (such as `smb2_send_interim_resp()`) must check for `NULL` before passing to `allocate_interim_rsp_buf()`. In `smb2_open()`, `file_present` and `created` must be initialized to `false` and set to `true` only after `ksmbd_vfs_kern_path()` or `smb2_creat()` succeeds. [F41, F47]
- In `ipc_server_config_on_startup()`, multiplying `req->deadtime` by `SMB_ECHO_INTERVAL` into `server_conf.deadtime` must use `check_mul_overflow()` and return `-EINVAL` on overflow. [F114]

## External Contracts
- In `smb2_sess_setup()`, because `rsp->SecurityBufferOffset` is preset to `cpu_to_le16(72)`, the error path (`rc < 0`) must reset `rsp->SecurityBufferOffset = 0` before `smb2_set_err_rsp(work)`. In `smb2_handle_negotiate()` (`SMB311_PROT_ID`), `NegotiateContextOffset` must lie between `Dialects` end and `smb2_buf_len`, with contexts 8-byte aligned in `deassemble_neg_contexts()` and `assemble_neg_contexts()`. [F55, F84]
- `id_to_sid()` writes 16 bytes for `SIDUNIX_USER`/`SIDUNIX_GROUP` and 28 bytes for `SIDOWNER`, so `smb2_posix_info.SidBuffer[32]` and `smb311_posix_qinfo.Sids[32]` place `SIDUNIX_USER` at 0 and `SIDUNIX_GROUP` at 16, whereas `create_posix_rsp.SidBuffer[44]` places `SIDOWNER` at 0 and `SIDUNIX_GROUP` at 28. When pinning an empty `smb2_query_directory_rsp` in `smb2_query_dir()`, pass `offsetof(struct smb2_query_directory_rsp, Buffer) + 1` to `ksmbd_iov_pin_rsp()`. [F94, F122]

## Known Pitfalls
- Because `sizeof(struct smb_sid)` (68) and `sizeof(struct smb_ace)` (76) are maximum in-memory sizes (`sub_auth[15]`), wire/xattr DACL code in `smbacl.c` must advance ACE pointers by `(char *)ace + le16_to_cpu(ace->size)` rather than `ace++`. [F126]
- In `smb2_set_ea()`, skipping an entry in `do { ... } while (next != 0)` must use `goto next;` rather than `continue;` so `next`, `buf_len`, and `eabuf` advance. Calls to `strscpy()` in `ksmbd_extract_shortname()` and `transport_ipc.c` must pass destination size (`sizeof(dst)` / `KSMBD_REQ_MAX_*`), never `strlen(src)`. [F106, F133]
