# X86 MM

`arch/x86/mm` implements x86 (32-bit and 64-bit) memory management: physical-to-virtual linear mappings, identity mappings, page fault and exception table handling, `ioremap`, KASLR virtual layout randomization, NUMA topology setup, AMD SME/SEV memory encryption, and the Page Attribute Table (PAT) / Change Page Attribute (CPA) subsystem (`arch/x86/mm/pat/`).

## Architecture & Data Flow
- `cpa->mask_set` and `cpa->mask_clr` use 4K PTE bit positions (`_PAGE_PAT` at bit 7), so PMD/PUD paths (`__should_split_large_page()`, `__split_large_page()`, `populate_pmd()`, `populate_pud()`, `collapse_pmd_page()`) must convert via `pgprot_large_2_4k()` and `pgprot_4k_2_large()`, and `collapse_pmd_page()` must return 0 when `!cpu_feature_enabled(X86_FEATURE_PSE)`. [F60, F127]
- `_PAGE_GLOBAL` aliases `_PAGE_PROTNONE` on non-present PTEs and `_PAGE_PSE` makes `pmd_present()` true on non-present PMDs: `pgprot_clear_protnone_bits()` and `cea_set_pte()` must clear `_PAGE_GLOBAL` when `!(_PAGE_PRESENT)`, and `__split_large_page()` must clear `_PAGE_PSE` when splitting a `!_PAGE_PRESENT` PUD. [F61]
- In `cpa_data`, `cpa->vaddr` is `NULL` under `CPA_PAGES_ARRAY` and an address array under `CPA_ARRAY`; deriving a single-address alias `cpa_data` with `vaddr = &addr` (`cpa_process_alias()`) must clear `CPA_PAGES_ARRAY | CPA_ARRAY` and reset `curpage = 0`. Without `CPA_NO_CHECK_ALIAS`, `cpa_process_alias()` must update both the direct map (`PAGE_OFFSET`) and 64-bit highmap (`[_text, _brk_end)`), clear `_PAGE_NX` from `alias_cpa` masks, and set `cpa->force_flush_all = 1` on the caller's `cpa` (not `alias_cpa`). [F49, F97, F182]
- In `change_page_attr_set_clr()` and `__change_page_attr_set_clr()`, only return early on zero `mask_set`/`mask_clr` if `cpa->force_split` is false (`should_split_large_page()` returns 1 on `force_split`). In `_set_memory_wc()` and `_set_pages_array()`, transitions to `_PAGE_CACHE_MODE_WC` must first pass through `_PAGE_CACHE_MODE_UC_MINUS`. [F85, F138]
- When kernel page tables are populated, removed (`remove_pte_table()`), split (`__split_large_page()`), or collapsed (`collapse_pmd_page()`, `collapse_pud_page()`), `direct_pages_count[]` must be updated under `pgd_lock` via `update_page_count()`, `split_page_count()`, or `collapse_page_count()` only for direct-mapped PFNs (never `vmemmap` or highmap aliases). [F186]
- `__cachemode2pte_tbl[]` is indexed by `enum page_cache_mode` whereas `__pte2cachemode_tbl[]` is indexed by 3-bit PTE cache indices via `__pte2cm_idx()`; `update_cache_mode_entry()` must keep PAT slot 0 as `_PAGE_CACHE_MODE_WB` and update both tables together, while `init_cache_modes()` iterates from 7 down to 0 so lower slots win. [F66, F197]
- In `memtype_interval.c`, `struct memtype` stores an exclusive `entry->end`, but `INTERVAL_TREE_DEFINE` uses inclusive endpoints (`interval_end(entry) = entry->end - 1`); all `interval_iter_first()` and `interval_iter_next()` calls on `memtype_rbroot` must pass `end - 1`. Non-RAM reservations in `__ioremap_caller()`, `memtype_reserve_io()`, and `reserve_pfn_range()` must follow `memtype_reserve()` with `memtype_kernel_map_sync()` (calling `memtype_free()` on failure). [F69, F189]
- Because `set_mce_nospec()` passes a non-canonical decoy address (`PAGE_OFFSET ^ BIT(63)`), `cpa_flush()` must canonicalize addresses via `fix_addr()`—casting `addr << 1` to `signed long` before right-shifting by 1 so bit 62 sign-extends into bit 63—and `memtype_reserve()`/`memtype_free()` must mask physical addresses with `sanitize_phys()`. [F108, F193]
- NX page-table checks (`verify_rwx()`, `set_memory_x()`, `set_memory_nx()`, `set_memory_rox()`, `note_wx()`, `ptdump_walk_pgd_level_checkwx()`) must test `__supported_pte_mask & _PAGE_NX` rather than `cpu_feature_enabled(X86_FEATURE_NX)`. In `verify_rwx()`, effective permissions must incorporate accumulated non-leaf `_PAGE_NX` (OR-ed) and `_PAGE_RW` (AND-ed) from `lookup_address_in_pgd_attr()`, skipping W^X warnings when `!rw || nx`. [F88, F160]
- When `!pgtable_l5_enabled()`, P4D is folded into PGD (`pgd_none()` is always false): `sync_global_pgds_l4()` and `preallocate_vmalloc_pages()` must operate on P4D/PUD levels rather than stopping at PGD/P4D, and `free_p4d()` / `remove_p4d_table()` must only free the P4D page when `pgtable_l5_enabled()`, while `free_pmd()` and `free_pud()` must skip `pmd_leaf()` and `pud_leaf()` entries. [F16, F104]
- In `access_error()`, `error_code & X86_PF_SHSTK` must precede `error_code & X86_PF_WRITE` because the `X86_PF_WRITE` branch rejects any `VM_SHADOW_STACK` VMA whereas `X86_PF_SHSTK` requires `VM_SHADOW_STACK | VM_WRITE`. In `spurious_kernel_fault()`, `error_code` must be compared for exact equality against `(X86_PF_WRITE | X86_PF_PROT)` and `(X86_PF_INSTR | X86_PF_PROT)` rather than bitwise `&`. [F91, F92]
- In `mem_encrypt_amd.c`, early boot variables written before `.bss` is zeroed (`sme_me_mask`, `sev_status`, `sev_check_data`) must use `__section(".data")`. In `early_set_memory_enc_dec()`, splitting a large page via `kernel_physical_mapping_change()` must not advance `vaddr_next` so the same `vaddr` is re-evaluated at the split level. [F55, F99]
- `get_cpu_entry_area(cpu)` must stay `noinstr`, call only `__always_inline` instrumentation-free helpers (`cea_offset(cpu)`), and index by `cea_offset(cpu) * CPU_ENTRY_AREA_SIZE` (not `cpu * CPU_ENTRY_AREA_SIZE`). `setup_cpu_entry_area()` must call `kasan_populate_shadow_for_vaddr(cea, CPU_ENTRY_AREA_SIZE, ...)` before mapping fields and `setup_cpu_entry_areas()` must call `sync_initial_page_table()`. [F77, F148, F196]
- In `vmemmap`, `vmemmap_flush_unused_pmd()` must flush `unused_pmd_start` before populating a non-contiguous range in `vmemmap_use_sub_pmd()`, before starting a new PMD in `vmemmap_use_new_sub_pmd()`, and before `memchr_inv()` in `vmemmap_pmd_is_unused()`. In `add_pages()`, `update_end_of_memory_vars()` must only run when `params->pgmap == NULL` and `end <= DIRECT_MAP_PHYSMEM_END`. [F181, F198]

## Synchronization
- Non-RAM PAT interval tree accesses in `memtype_reserve()`, `memtype_free()`, `lookup_memtype()`, and `memtype_get_idx()` must hold `memtype_lock`. `memtype_lookup()` returns a borrowed pointer into `memtype_rbroot` that must only be dereferenced and copied out under `memtype_lock` and never freed, whereas `memtype_erase()` unlinks the node under `memtype_lock` and transfers ownership to `memtype_free()` to `kfree()`. In `set_page_memtype()`, updates to `_PGMT_MASK` in `pg->flags.f` must use a `READ_ONCE()` and `try_cmpxchg()` loop. [F2, F33, F34]
- `cpa_flush()`, `cpa_flush_all()`, and `change_page_attr_set_clr()` with `CPA_FLUSHTLB` must not be called with IRQs disabled after early boot. In `clflush_cache_range()` and `cpa_flush()`, `clflush_cache_range_opt()` must be bracketed by a preceding `mb()` (after `flush_tlb_kernel_range()` in `cpa_flush()`) and a trailing `mb()`. When `debug_pagealloc_enabled()`, `probe_page_size_mask()` must disable 2M/1G direct-map pages and `__kernel_map_pages()` must use `CPA_NO_CHECK_ALIAS` and local `__flush_tlb_all()` under `preempt_disable()`. [F39, F157, F158]
- `__set_memory_enc_dec()` must pair `down_read_trylock(&mem_enc_lock)` with `up_read(&mem_enc_lock)` around `__set_memory_enc_pgtable()`, whereas `set_memory_enc_stop_conversion()` intentionally acquires `mem_enc_lock` for write without releasing it to permanently block conversions. [F15]
- In `exc_page_fault()`, read the fault address (`fred_event_data(regs)` / `read_cr2()`) and call `kvm_handle_async_pf()` before `irqentry_enter()` and `instrumentation_begin()`, using `irqentry_enter()` (not `ct_irq_enter()`). In `do_user_addr_fault()`, reject kernel instruction fetches on user addresses, `X86_PF_RSVD`, supervisor SMAP violations, `faulthandler_disabled() || !mm`, and `!(regs->flags & X86_EFLAGS_IF)` before `local_irq_enable()` or locking the VMA/mm. [F143, F146]
- In `do_user_addr_fault()`, `__bad_area()` and `bad_area_access_error()` take a nullable `mm` (`mm != NULL` unlocks via `mmap_read_unlock(mm)`; `mm == NULL` unlocks via `vma_end_read(vma)`). After `handle_mm_fault()`, the RCU path must call `vma_end_read(vma)` unless `VM_FAULT_RETRY | VM_FAULT_COMPLETED` is set (and on `VM_FAULT_RETRY`, set `FAULT_FLAG_TRIED` if `fault & VM_FAULT_MAJOR` before retrying under `mmap_lock`), and the `mmap_lock` path must call `mmap_read_unlock(mm)` unless `fault_signal_pending()`, `VM_FAULT_COMPLETED`, or `VM_FAULT_RETRY` holds. [F20, F50, F195]
- On 32-bit x86, `do_kern_addr_fault()` and `vmalloc_fault()` must sync kernel PMDs from `init_mm.pgd` into `read_cr3_pa()` without locks or `current`, and `dump_pagetable()` must verify `low_pfn()` before `pte_offset_kernel()`. On 64-bit, `__kernel_physical_mapping_init()` must populate child tables via `phys_p4d_init()` before locking `init_mm.page_table_lock` to publish the top entry, and both it and `vmemmap_populate()` must call `sync_global_pgds()`. [F40, F145, F152]

## Object Lifetimes
- `memtype_check_insert()` transfers ownership of `entry_new` into `memtype_rbroot` only when it returns `0`; on error it leaves `entry_new` unlinked and `memtype_reserve()` must `kfree(entry_new)`. [F1]
- `iounmap()` must look up `p` with `find_vm_area()` and finish `kmsan_iounmap_page_range()` and `memtype_free()` before `remove_vm_area()` and `kfree(p)` so the virtual range cannot be reused during cleanup. [F7]
- In `__memremap_is_setup_data()`, every mapping from `early_memremap_decrypted()` / `memremap()` must be unmapped with `early_memunmap()` / `memunmap()` before early returns, before remapping `SETUP_INDIRECT` (unmapping `sizeof(struct setup_data)`, remapping `sizeof(struct setup_data) + data->len` bytes, and passing that updated `size` to `early_memunmap()`), and at loop end; range checks must use `paddr + sizeof(struct setup_data) + len`. [F8, F116, F117]
- In `free_init_pages()`, when `!debug_pagealloc_enabled()`, mark `[begin, end)` NX and RW via `set_memory_nx()` and `set_memory_rw()` before `free_reserved_area()`. In `mem_encrypt_free_decrypted_mem()`, when `sme_me_mask` is set, re-encrypt `[__start_bss_decrypted_unused, __end_bss_decrypted)` with `set_memory_encrypted()` before `free_init_pages()`, aborting without freeing if `set_memory_encrypted()` fails. [F19, F22]

## API Contracts
- `lookup_address()`, `lookup_address_in_pgd()`, and `lookup_address_in_pgd_attr()` return a non-NULL `pte_t *` even for non-present P4D/PUD/PMD entries or empty 4K PTE slots, and the pointer actually points to a `p4d_t`, `pud_t`, or `pmd_t` when `*level` is `PG_LEVEL_512G`, `PG_LEVEL_1G`, or `PG_LEVEL_2M`: callers must check `!pte_none(*pte)` / `pte_present(*pte)` and dispatch on `*level` before extracting PFNs or pgprots. [F43, F123]
- `__change_page_attr_set_clr()` overwrites `cpa->numpages` during its loop and must restore `cpa->numpages = numpages` on exit so callers flush the full range in `cpa_flush()`. `__should_split_large_page()` and `should_split_large_page()` return `0` (keep/update in place), `1` (split), or `-EINVAL`, so `__change_page_attr()` must return early on `do_split <= 0` and call `split_large_page()` only when `do_split > 0`. [F13, F44]
- `pat_pagerange_is_ram()` returns `1` (all RAM), `0` (all non-RAM), or `-1` (mixed), so callers must test `< 0` and `== 1` explicitly. Every success path of `memtype_reserve()` must populate `*new_type` when non-NULL (`memtype_check_insert()` must set `entry_new->type = *ret_type` before insertion), and `memtype_reserve()` must sanitize its exclusive `end` as `sanitize_phys(end - 1) + 1`. In `__ioremap_caller()`, page-align `phys_addr` and `size` (masking with `PHYSICAL_PAGE_MASK`) before reservation and mapping. [F41, F54, F68, F177]
- `prepare_pte_enc()` returns `0` when encryption changes and `1` when `!d->pfn` or `old_prot == d->new_pgprot` (leaving `d->pa` and `d->size` uninitialized); callers must abort on non-zero return. `enc_dec_hypercall()`, `early_set_mem_enc_dec_hypercall()`, and `early_set_memory_enc_dec()` take byte `size`, whereas `amd_enc_status_change_prepare()`, `amd_enc_status_change_finish()`, and `notify_page_enc_status_changed()` take `npages`. [F47, F57]
- `kernel_physical_mapping_init()` and `kernel_physical_mapping_change()` take `page_size_mask` as shifted `enum pg_level` bits (`1 << PG_LEVEL_2M`, `1 << PG_LEVEL_1G`), and `phys_pmd_init()`/`phys_pud_init()` must promote masked 4K `pgprot_t` via `prot_sethuge(prot)`. In `do_user_addr_fault()`, set `FAULT_FLAG_USER` from `user_mode(regs)` (not `error_code & X86_PF_USER`) and `FAULT_FLAG_WRITE` from `error_code & (X86_PF_SHSTK | X86_PF_WRITE)`. In `vm_get_page_prot()`, mask with `__supported_pte_mask` after `__sme_set()` when `_PAGE_PRESENT` is set. [F59, F62, F165, F178]

## Error Handling
- `set_memory_uc()`, `set_memory_wc()`, and `_set_pages_array()` must reserve PAT memtypes via `memtype_reserve()` before changing PTEs and roll back completed reservations via `memtype_free()` on CPA failure (in `_set_pages_array()`, saving `free_idx = i` before resetting `i` and skipping `PageHighMem(pages[i])`), whereas `set_memory_wb()` and `set_pages_array_wb()` must restore WB PTEs before calling `memtype_free()`. [F14, F98]
- `reserve_ram_pages_type()` must finish its first pass verifying `get_page_memtype(page) == _PAGE_CACHE_MODE_WB` for every PFN in `[start, end)` before calling `set_page_memtype()` in the second pass, as it does not unwind page flags on `-EBUSY`. When `CONFIG_X86_PAT` is enabled, `memtype_erase()` returns `ERR_PTR(-EINVAL)` rather than `NULL` on miss, so callers must check `IS_ERR()` before `kfree()`. [F3, F42]
- `__ioremap_caller()` reserves PAT memtype before `get_vm_area_caller()`, and on `memtype_kernel_map_sync()` or `ioremap_page_range()` failure must call `free_vm_area(area)` before `memtype_free()`. When `__change_page_attr_set_clr()` fails after setting `CPA_FLUSHTLB` or in `__set_memory_enc_pgtable()`, callers must still flush TLBs/caches before returning `ret`. In `__cpa_process_fault()` with `cpa->pgd == NULL`, return `0` without warning for unmapped direct-map holes or non-primary passes, and `-EFAULT` without warning when `__cpa_pfn_in_highmap(cpa->pfn)`. [F6, F53, F179]

## External Contracts
- On user-mode page faults resulting in a signal or vDSO fixup, `sanitize_error_code()` must set `X86_PF_PROT` in `error_code` whenever `address >= TASK_SIZE_MAX` before `fixup_vdso_exception()` or `set_signal_archinfo()`. In `pfn_modify_allowed()`, when `boot_cpu_has_bug(X86_BUG_L1TF)` and `__pte_needs_invert(pgprot_val(prot))` hold, reject `!pfn_valid(pfn)` PFNs `>= l1tf_pfn_limit()` unless `capable(CAP_SYS_ADMIN)`. [F80, F169]

## Known Pitfalls
- `pte_pfn()`, `pmd_pfn()`, `pud_pfn()`, and `pg_level_to_pfn()` always return a 4K-granularity PFN regardless of level, so callers (`prepare_pte_enc()`, `slow_virt_to_phys()`) must shift by `PAGE_SHIFT` after casting to `phys_addr_t` (never `page_level_shift(level)`). Likewise, widen `pfn` to `resource_size_t`/`phys_addr_t` before `<< PAGE_SHIFT` in `pfnmap_*()` and `valid_mmap_phys_addr_range()`. [F58, F107]
- In `__should_split_large_page()`, `cpa->pfn` must be set to the target address's offset PFN (`old_pfn + ((address & (psize - 1)) >> PAGE_SHIFT)`) for `cpa_process_alias()`, whereas whole-large-page `static_protections()`, `verify_rwx()`, and `pfn_pte()` calls must use the large page's base `old_pfn` and `lpaddr`. [F96]
- In `set_memory.c`, `overlaps()` takes inclusive endpoints (`r1_start <= r2_end && r1_end >= r2_start`), so `static_protections()` and `protect_*()` must subtract 1 from exclusive end addresses, section end symbols (`_etext`, `__end_rodata`, `__end_rodata_hpage_align`, `BIOS_END`), and PFN counts before calling `overlaps()`. [F71]
- Standalone `pgd_t` variables not in a two-page KPTI PGD (`trampoline_pgd_entry`) must be assigned directly rather than via `set_pgd()`. In `percpu_setup_exception_stacks()`, map every stack (including `VC`/`VC2`) with `cea_map_stack()` using `sizeof(estacks->name##_stack) / PAGE_SIZE` pages rather than a single-page `cea_set_pte()`. [F118, F120]
