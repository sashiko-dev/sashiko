# PAGE CACHE

The PAGE CACHE unit implements the core `address_space` page cache, managing folio indexing in XArrays, buffered/direct file reads and writes, memory-mapped page faults, file readahead, truncation/invalidation, and dirty page writeback throttling across VFS, MM, filesystems, and block devices.

## Architecture & Data Flow

- In `page_cache_delete()`, `page_cache_delete_batch()`, and `__filemap_add_folio()` error rollback, `folio->mapping` must be set to `NULL` while `folio->index` is left intact because concurrent truncation and invalidation batch walks rely on `folio->index`. [F2]
- `folio_clear_dirty_for_io()` clears `PG_dirty` while leaving `PAGECACHE_TAG_DIRTY`/`PAGECACHE_TAG_TOWRITE` set and only decrements `NR_FILE_DIRTY`, `NR_ZONE_WRITE_PENDING`, and `WB_RECLAIMABLE`; callers must start writeback or redirty before unlocking, and `folio_redirty_for_writepage()` must subtract `folio_nr_pages(folio)` from `current->nr_dirtied`, `NR_DIRTIED`, and `WB_DIRTIED` after `filemap_dirty_folio()`. In `folio_clear_dirty_for_io()` and `pagecache_isize_extended()`, if `folio_mkclean()` returns non-zero, `folio_mark_dirty()` must be called immediately. [F17, F176, F177]
- Under `i_pages` lock, `__folio_start_writeback()` must check `mapping_tagged(mapping, PAGECACHE_TAG_WRITEBACK)` before setting that mark to call `wb_inode_writeback_start()` and `sb_mark_inode_writeback()`, whereas `__folio_end_writeback()` must check it after clearing the mark to call `wb_inode_writeback_end()` and `sb_clear_inode_writeback()`. [F79]
- `filemap_fault()` and `next_uptodate_folio()` must convert `i_size_read()` to an exclusive page-index bound via `DIV_ROUND_UP(i_size_read(inode), PAGE_SIZE)` so partial EOF pages stay mappable; `filemap_fault()` must check `vmf->pgoff >= max_idx` both upon entry and after locking the folio, unlocking and putting the folio to return `VM_FAULT_SIGBUS`. [F99, F129]
- In `read_pages()`, unconsumed folios left in `rac` by `aops->readahead()` must be drained via `readahead_folio(rac)`, removed with `filemap_remove_folio()`, and unlocked/put, and `psi_memstall_leave(&rac->_pflags)` and `rac->_workingset = false` must run before returning. [F85]
- In the second pass of `truncate_inode_pages_range()`, when `find_get_entries(mapping, &index, end - 1, &fbatch, indices)` returns 0, the loop must only `break` if `index == start` and otherwise reset `index = start` to rescan `[start, end)`. [F111]
- Pagecache counters (`mapping->nrpages`, `__lruvec_stat_mod_folio`, `wb_stat_mod`, `wbc->nr_to_write`) and folio ref transfers (`folio_ref_add`, `folio_put_refs`) scale by `folio_nr_pages(folio)`, whereas `task_io_account_write()` and `task_io_account_cancelled_write()` take `nr * PAGE_SIZE` bytes. [F134]
- Every `wait_queue_entry_t` on `folio_waitqueue(folio)` must be embedded in `struct wait_page_queue` and woken with a `struct wait_page_key *` key, because `wake_page_function()` casts `arg` to `struct wait_page_key *` and downcasts `wait` via `container_of()`. [F140]

## Synchronization

- `mapping->i_pages` lock must always be acquired with local IRQs disabled (`xa_lock_irq*`/`xas_lock_irq*`) because `__folio_end_writeback()` runs in IRQ context and `folio_account_dirtied()` requires IRQ atomicity. Calls to `inode_to_wb()` and updates to `PAGECACHE_TAG_DIRTY`/`WRITEBACK`/`TOWRITE` marks in `__folio_mark_dirty()`, `__folio_start_writeback()`, and `__folio_end_writeback()` must stay inside `i_pages` lock, whereas `mapping->host->i_lock` must be held outside `xa_lock_irq(&mapping->i_pages)` across `mapping_shrinkable()` and `inode_add_lru()` when deleting entries. [F30, F32, F152]
- Lockless RCU walks of `mapping->i_pages` (`filemap_get_entry()`, `find_get_entry()`, `next_uptodate_folio()`, `filemap_get_folios_contig()`, `filemap_get_read_batch()`) must pin `folio` with `folio_try_get(folio)` before checking `PF_NO_TAIL` flags (`folio_test_locked()`) and verify `folio == xas_reload(xas)`. Any `xa_state` walk dropping RCU/`xas_lock_irq()` or calling `cond_resched_rcu()` must call `xas_pause(&xas)` first. After locking a looked-up folio, callers must recheck `folio->mapping == mapping`. [F40, F42, F162]
- `folio_wait_table` bucket locks (`q->lock`) must be acquired with IRQs disabled (`spin_lock_irq*`), so `folio_unlock()` and `folio_end_read()` must not be called from NMI context. In `folio_wait_bit_common()` and `__folio_lock_async()`, `folio_set_waiters()`, bit retesting, and waitqueue insertion must occur under `q->lock`. `wake_page_function()` pairs `smp_store_release(&wait->flags, flags | WQ_FLAG_WOKEN)` with `smp_load_acquire(&wait->flags)` in `folio_wait_bit_common()`, which determines `0` vs `-EINTR` only after `finish_wait()` (`WQ_FLAG_DONE` for `EXCLUSIVE`, else `WQ_FLAG_WOKEN`). [F34, F45, F115, F154]
- In `filemap_fault()`, if `maybe_unlock_mmap_for_io()` returns a non-`NULL` `fpin`, it must unlock `folio` (if locked) and jump to `out_retry` to release `folio`, `mapping->invalidate_lock` (if `mapping_locked`), and `fput(fpin)` before returning `VM_FAULT_RETRY`. In `filemap_fault_recheck_pte_none()`, `vmf->ptl` must be refreshed via `pte_offset_map_ro_nolock(vma->vm_mm, vmf->pmd, vmf->address, &vmf->ptl)` before `spin_lock(vmf->ptl)`. [F13, F82]
- In `generic_perform_write()`, user copies between `a_ops->write_begin` and `a_ops->write_end` must use `copy_folio_from_iter_atomic()`, calling `fault_in_iov_iter_readable()` only after `write_end` unlocks the folio. When `mapping_writably_mapped(mapping)` is true, `filemap_read()`, `filemap_splice_read()`, and `generic_perform_write()` must call `flush_dcache_folio(folio)` before accessing the folio (and again after `copy_folio_from_iter_atomic()`). [F38, F163]
- In `truncate_inode_pages_final()`, `mapping_set_exiting(mapping)` and (if `!mapping_empty(mapping)`) cycling `xa_lock_irq(&mapping->i_pages)` must precede `truncate_inode_pages()` so reclaim sees `AS_EXITING` and stops installing shadow entries. `invalidate_inode_pages2_range()` must call `unmap_mapping_pages()` before `folio_lock(folio)`. In `filemap_end_dropbehind()`, `folio_unmap_invalidate()` must be gated under the folio lock on `!folio_test_writeback(folio) && !folio_test_dirty(folio)`, `folio_test_clear_dropbehind(folio)`, and `folio->mapping != NULL`. [F27, F39, F43]
- `page_cache_ra_unbounded()` and `page_cache_ra_order()` must hold `memalloc_nofs_save()` and `filemap_invalidate_lock_shared(mapping)` across folio allocation, insertion, and `read_pages(ractl)`. `filemap_invalidate_lock_two()` must lock the lower `address_space` pointer first and only lock `mapping2` (`down_write_nested(..., 1)`) when `mapping1 != mapping2`. Multiple folios in the same `address_space` must be locked in ascending `folio->index` order, so `writeback_iter()` must only reset `mapping->writeback_index = 0` when `writeback_get_folio()` returns `NULL`. [F24, F37, F158]
- `wb_inode_writeback_end()` must serialize `queue_delayed_work(bdi_wq, &wb->bw_dwork, ...)` under `spin_lock_irqsave(&wb->work_lock, flags)` and gate it on `test_bit(WB_registered, &wb->state)`. `file_check_and_advance_wb_err()` must hold `spin_lock(&file->f_lock)` around `errseq_check_and_advance()`. `balance_dirty_pages_ratelimited_flags()` must bracket `this_cpu_ptr()` accesses to `bdp_ratelimits` and `dirty_throttle_leaks` with `preempt_disable()`/`preempt_enable()` and call `balance_dirty_pages()` only after `preempt_enable()`. [F28, F33, F35]
- `mapping_set_folio_order_range()` (and `mapping_set_folio_min_order()` / `mapping_set_large_folios()`) performs a non-atomic read-modify-write on `mapping->flags`, which shares the word with atomic runtime flags (`AS_EIO`, `AS_ENOSPC`, `AS_EXITING`), so it must only be called before the mapping is active. [F146]

## Object Lifetimes

- Before `__filemap_add_folio()` stores a folio into `mapping->i_pages` under `xas_lock_irq()`, `filemap_add_folio()` sets `PG_locked` and charges memcg (using `root_mem_cgroup` and `NR_KERNEL_FILE_PAGES` if `AS_KERNEL_FILE` is set, paired with `filemap_unaccount_folio()`), and `__filemap_add_folio()` sets `folio->mapping`/`folio->index` and adds `folio_nr_pages(folio)` refs; on error, `filemap_add_folio()` uncharges memcg and unlocks `folio` without dropping the caller's ref, so callers must call `folio_put(folio)`. [F1, F25, F174]
- `filemap_remove_folio()` and `delete_from_page_cache_batch()` drop the pagecache's `folio_nr_pages(folio)` references via `filemap_free_folio()`, so callers must hold both `PG_locked` and their own folio reference across the call before unlocking. In `truncate_cleanup_folio()`, `folio_cancel_dirty(folio)` must run after `folio_invalidate()` because filesystem `->invalidate_folio` callbacks may re-dirty the folio before `filemap_remove_folio()`. [F3, F22]
- `folio_attach_private()` gets a folio ref, sets `folio->private`, and sets `PG_private`; `folio_detach_private()` clears `PG_private`, zeroes `folio->private`, and calls `folio_put()` (required before removal in `folio_unmap_invalidate()`). `folio_end_private_2()` clears `PG_private_2`, wakes waiters, and drops the `PG_private_2` ref. Because writeback holds no folio ref, `folio_end_writeback()` must pin `folio` with `folio_get()` across `folio_end_writeback_no_dropbehind()` and `folio_end_dropbehind()` before `folio_put()`. [F6, F7, F8]
- `folio_put_wait_locked()` queues the wait entry under `q->lock` and drops the caller's folio reference (`behavior == DROP`) before sleeping, so callers must never dereference `folio` or call `folio_put(folio)` afterwards. `folio_wait_bit_common()` and `migration_entry_wait_on_locked()` allocate `struct wait_page_queue` on the stack and must call `finish_wait(q, wait)` on all return paths, while `wake_page_function()` must not access `wait` after `list_del_init_careful(&wait->entry)`. [F9, F141]

## API Contracts

- `__filemap_get_folio()`, `filemap_get_folio()`, `filemap_lock_folio()`, `filemap_grab_folio()`, and `do_read_cache_folio()` return `ERR_PTR` on miss/failure and never `NULL`, whereas `filemap_get_entry()` and `filemap_alloc_folio()` return `NULL`. When `__filemap_get_folio()` creates a folio (`FGP_CREAT`) with `FGP_FOR_MMAP` set, it unlocks the folio before returning. `__folio_lock_or_retry()` returns `0` when locked and `VM_FAULT_RETRY` otherwise, whereas `lock_folio_maybe_drop_mmap()` returns `1` when locked and `0` otherwise. [F21, F48, F64]
- `find_get_entries()` and `find_lock_entries()` require a `pgoff_t indices[PAGEVEC_SIZE]` array alongside an initialized `struct folio_batch` and include exceptional XArray value entries in `fbatch->folios[]`, so callers must guard folio operations with `xa_is_value(folio)` and call `folio_batch_remove_exceptionals()` before `folio_batch_release()`. Unlike `find_get_entries()` and `filemap_get_folios_tag()`, `find_lock_entries()` omits any folio or multi-index value entry starting before `*start` or extending past `end`. [F50, F97, F133]
- `__filemap_add_folio()` and `filemap_add_folio()` require `folio_order(folio) >= mapping_min_folio_order(mapping)` and `index` aligned to `folio_nr_pages(folio)`. `fgf_set_order()` and `filemap_get_order()` take a byte length (`size_t size`), not a page order or page count, encoding `ilog2(size) - PAGE_SHIFT` into `fgf_t`. Single-bit `enum mapping_flags` (`AS_EIO`..`AS_KERNEL_FILE`) are bit indices into `mapping->flags` (accessed via bitops or `mapping_*()` helpers), whereas `AS_FOLIO_ORDER_*_MASK` are pre-shifted bitmasks. [F51, F67, F68]
- `mapping_large_folio_support()` must only be called on file-backed `address_space` pointers, never on anonymous `folio->mapping` (`FOLIO_MAPPING_ANON`). In `mapping_set_error()`, `__folio_start_writeback()`, and `__folio_end_writeback()`, `mapping->host` can be `NULL` (e.g. `swapper_space`) and must be null-checked. `truncate_cleanup_folio()`, `truncate_inode_partial_folio()`, and `filemap_release_folio()` must check `folio_needs_release(folio)` (not `folio_has_private(folio)`) so `AS_RELEASE_ALWAYS` mappings are not skipped. [F52, F69, F171]
- `folio_xor_flags_has_waiters()` operates on the low byte of `folio->flags` via `xor_unlock_is_negative_byte()` and tests `PG_waiters` at bit 7, so its mask must only contain flags in bits 0..6 (`PG_locked`, `PG_uptodate`, `PG_writeback`), while flags at bit >= 8 (such as `PG_private_2`) must use `clear_bit_unlock()`. [F145]

## Error Handling

- `filemap_update_page()` and `filemap_create_folio()` return positive `AOP_TRUNCATED_PAGE` after dropping the folio ref, so `filemap_get_pages()` must only call `folio_put(folio)` when `err < 0` and retry on `AOP_TRUNCATED_PAGE`; callers of `filemap_read_folio()`/`filler_t` (`filemap_fault()`, `do_read_cache_folio()`) must also retry on `AOP_TRUNCATED_PAGE` rather than returning `ERR_PTR` or `VM_FAULT_SIGBUS`. In `filemap_fault()`, `out_retry:` must guard `folio_put(folio)` with `if (!IS_ERR(folio))`. In `__filemap_get_folio()`, `-ENOMEM` on `FGP_CREAT` with `FGP_NOWAIT` must return `ERR_PTR(-EAGAIN)`. [F47, F56, F57, F63]
- In `generic_perform_write()`, `copy_folio_from_iter_atomic()` advances `iov_iter` by `copied` before `a_ops->write_end`, so if `status != copied`, it must call `iov_iter_revert(i, copied - max(status, 0L))`. In `generic_file_read_iter()` and `generic_file_direct_write()`, unconsumed `iov_iter` advancement after `a_ops->direct_IO` must be reverted with `iov_iter_revert()` whenever the return is not `-EIOCBQUEUED`. In `filemap_read()`, once `already_read > 0`, `IOCB_NOWAIT` must be set if `IOCB_WAITQ` is present (preventing `-EIOCBQUEUED`), and `already_read` must be returned on later error. [F19, F20, F61]
- Callers of `writeback_iter()` must never exit the loop early via `break` or `goto`, but pass `folio` and `*error` back until `writeback_iter()` returns `NULL` so `wbc->fbatch` is released, `mapping->writeback_index` is updated, and `wbc->saved_err` is restored; under `WB_SYNC_ALL`, a negative `*error` is saved into `wbc->saved_err` without stopping iteration and restored only when `writeback_get_folio()` returns `NULL`. [F59, F109]
- `folio_unmap_invalidate()` returns `1` on success and `< 0` on error, so `invalidate_inode_pages2_range()` must only update `ret` when `ret2 < 0`, and `generic_file_direct_write()` must translate `-EBUSY` from `kiocb_invalidate_pages()` to `0` for buffered fallback. In `filemap_map_pmd()`, `vmf->prealloc_pte` must be checked for non-`NULL` alongside `pmd_none(*vmf->pmd)` before calling `pmd_install()`. [F55, F60]

## Known Pitfalls

- On 32-bit architectures, page indices (`pgoff_t`/`unsigned long`) must be widened to `loff_t` or `u64` before `<< PAGE_SHIFT` or `* PAGE_SIZE` (`folio_pos()`, `readahead_pos()`, `mapping_seek_hole_data()`), and block size `bsz` (`size_t`) in `folio_seek_hole_data()` must be widened to `u64` before `~((u64)bsz - 1)`. In `truncate_inode_partial_folio()` and `truncate_pagecache_range()`, inclusive `loff_t` end bounds derived from `lend == -1` must be cast to `u64` before comparison so `-1` is treated as `ULLONG_MAX`. [F119, F120, F123]
