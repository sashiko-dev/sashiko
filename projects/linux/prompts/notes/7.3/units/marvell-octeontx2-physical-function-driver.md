# MARVELL OCTEONTX2 PHYSICAL FUNCTION DRIVER

This component implements the Marvell OcteonTX2, CN10K, and CN20K RVU Physical Function (PF) Ethernet driver (`drivers/net/ethernet/marvell/octeontx2/nic`). It manages NIX (network interface), NPA (buffer pool/aura), NPC (MCAM flow filtering), and CPT (inline IPsec) hardware blocks via an AF/PF/VF mailbox protocol, exposing netdev, ethtool, devlink, DCBNL, MACsec, and XFRM offload interfaces.

## Architecture & Data Flow

- `otx2_pfvf_mbox_init()` initializes `struct otx2_mbox` only on `pf->mbox_pfvf[0].mbox` and `mbox_up`; PF-VF mailbox paths must access VF `vf_idx` via `pf->mbox_pfvf[0].mbox.dev[vf_idx]` or `mbox_up.dev[vf_idx]`, never `pf->mbox_pfvf[vf_idx].mbox`. In `otx2_queue_vf_work()`, `hdr->num_msgs` must be copied into `mw[i].num_msgs` or `mw[i].up_num_msgs` and zeroed in the IRQ handler before queuing work. [F77, F137]
- Per-VF and per-CQ work structs (`flr_work.work`, `mbox.mbox_wrk`, `mbox.mbox_up_wrk`, `otx2_vf_config.link_event_work`, `refill_work.pool_refill_work`) must stay embedded in contiguous arrays on `struct otx2_nic` because their handlers recover the 0-based VF or CQ index via pointer subtraction. In `otx2_pfvf_mbox_up_handler` and `otx2_pfaf_mbox_handler`, every loop iteration must advance `offset = mbox->rx_start + msg->next_msgoff`, call `__otx2_mbox_reset` when `mdev->msgs_acked == (<num_msgs> - 1)`, and increment `mdev->msgs_acked++`, even on invalid messages (jump to `end:`, never `continue` or `return`). [F118, F139]
- XDP SQs sit between normal TX queues and QoS SQs in `pf->qset.sq[]`: `pf->hw.non_qos_queues` must equal `pf->hw.tx_queues + pf->hw.xdp_queues` in `otx2_alloc_queue_mem()`, `otx2_xmit()` must add `pf->hw.xdp_queues` when `qidx >= pf->hw.tx_queues`, `otx2_update_sq_stats()` must subtract `pfvf->hw.non_qos_queues` before testing `pfvf->qos.qos_sq_bmap`, and `otx2_set_channels()` must set `pf->hw.xdp_queues = channel->rx_count` when `pf->xdp_prog` is set. [F60, F90]
- Hardware RQ aura DMA addresses in `otx2_rq_aura_pool_init` and `cn10k_refill_pool_ptrs` must be offset by `+ OTX2_HEAD_ROOM` when `!pool->xsk_pool` (un-offset when `pool->xsk_pool` is set), and `otx2_free_aura_ptr` must subtract `OTX2_HEAD_ROOM` from `AURA_NIX_RQ` IOVAs before `otx2_free_bufs`. In `otx2_sq_init` and `otx2_sq_aura_pool_init`, `sqe_per_sqb` is `(sqb_size / sqe_size) - 1`, and NPA `stack_pages` uses `DIV_ROUND_UP(count, hw->stack_pg_ptrs)`. [F130, F187]
- Because `otx2_free_hw_resources()` frees NIX LF contexts, QoS queues, and ingress policers on stop, `otx2_open()` must reapply RX VLAN, hardware timestamping, `otx2_qos_config_txschq()`, `otx2_dmacflt_reinstall_flows()`, and `otx2_tc_apply_ingress_police_rules()` before `otx2_rxtx_enable(pf, true)`. `otx2_stop()` must use `memset_startat(qset, 0, sqe_cnt)` so `rqe_cnt`/`sqe_cnt` persist. `otx2_remove()` must set `OTX2_FLAG_PF_SHUTDOWN` before `unregister_netdev()`, and `otx2_free_hw_resources()` must set `NIX_LF_DONT_FREE_TX_VTAG` when `!(pf->flags & OTX2_FLAG_PF_SHUTDOWN)`. [F63, F64, F149]
- `pfvf->flow_cfg` and `pfvf->ptp` can be `NULL` and must be NULL-checked before use; `flow_cfg->ntuple_cnt` and `ucast_flt_cnt` must persist across `otx2_mcam_entry_init()`; and `flow_cfg->def_ent[]` accesses must add `vf_vlan_offset`, `unicast_offset`, or `rx_vlan_offset`. DMAC filters (`OTX2_FLAG_DMACFLTR_SUPPORT`) use `u32` bit positions in `flow_cfg->dmacflt_bmap` bounded to `u32 flow_cfg->dmacflt_max_flows` (never `OTX2_DMAC_FLTR_BITMAP_SZ` or `u8`); bit 0 is reserved for the PF MAC (`-EPERM` on user delete, auto-removed when `bitmap_weight == 1`, and updated along with RX VLAN offload in `otx2_set_mac_address()`). [F46, F47, F56, F59, F91, F92, F119, F143, F195]
- In `otx2_pfc_txschq_alloc_one()` and `otx2_pfc_txschq_stop_one()`, PFC TX scheduler queues are allocated and freed only for `lvl <= pfvf->hw.txschq_link_cfg_lvl` in `pfvf->pfc_schq_list[lvl][prio]` via `otx2_txschq_free_one()`; higher levels share `pfvf->hw.txschq_list[lvl][0]` and must never be freed by PFC stop. `otx2_get_smq_idx()` must check `qidx < NIX_PF_PFC_PRIO_MAX`, and `otx2_select_queue()` must check `vlan_prio <= pf->hw.tx_queues - 1`. [F66, F88]
- In `cn10k_macsec.c`, every SA callback must reject `ctx->sa.assoc_num >= CN10K_MCS_SA_PER_SC` with `-EOPNOTSUPP`. `cn10k_mcs_write_keys()` computes the AES-ECB hash on the original `sak` before byte-reversing `sak`, `hash`, and `salt` into `req->plcy[0]` and placing `((u64)cpu_to_be32(ssci) << 32)` into `req->plcy[0][7]`. In `cn10k_mdo_upd_secy()`, `cn10k_mcs_sync_stats()` must run before updating policy, `cn10k_mcs_link_tx_sa2sc()` runs only if `encoding_sa` changed, and `cn10k_mcs_secy_tx_cfg()` must pass `sw_tx_sa = NULL` to preserve PN. [F70, F71, F93, F99, F124, F183]
- In `otx2_ethtool.c`, `otx2_get_strings()`, `otx2_get_ethtool_stats()`, and `otx2_get_sset_count()` (and `otx2vf_get_*`) must apply identical conditions in lockstep; fields in `otx2_dev_stats`/`queue_stats` must be `u64` and `otx2_drv_stats` fields must be `atomic_t` because stats readers cast them to `u64 *` or `atomic_t *` arrays. In `otx2_pf.c`, `nix_snd_status_e_str` must use designated initializers `[ENUM_VAL] = ...` for sparse `enum nix_snd_status_e` values. [F78, F79, F140]

## Synchronization

- Callers of `otx2_mbox_alloc_msg_*`, `otx2_sync_mbox_msg()`, and `otx2_mbox_get_rsp()` on `pfvf->mbox` must hold `pfvf->mbox.lock` across the entire transaction. `otx2_txschq_config()` and `otx2_pfc_txschq_config()` require `pfvf->mbox.lock` held, whereas `otx2_smq_flush()`, `otx2_txschq_free_one()`, `otx2_txschq_stop()`, `otx2_pfc_txschq_stop_one()`, `otx2_ctx_disable()`, `otx2_free_sq_res()`, and `otx2_free_cq_res()` take `pfvf->mbox.lock` internally and must be called unlocked (unlocking around them in `otx2_pfc_txschq_update()` before `otx2_pfc_update_sq_smq_mapping()`). [F9, F19, F21, F67]
- `otx2_pfvf_mbox_init()` must allocate `pf->mbox_pfvf_wq` with `max_active = 0` (never ordered/single-threaded) because `otx2_pfvf_mbox_up_handler` work items on `pf->mbox_pfvf_wq` must run concurrently to ack `otx2_sync_mbox_up_msg()` waits. Before scheduling `config->link_event_work` or sending an UP message in `otx2_vf_link_event_task()`, the PF must check `if (config->intf_down)` and skip down VFs. [F23, F168]
- Receive buffer allocation from `cq->rbpool` (`page_pool` or NAPI frag cache) must run with BHs disabled or in NAPI poll (`otx2_pool_refill_task()` reschedules `wrk->napi` and `otx2_alloc_rbuf()` wraps `__otx2_alloc_rbuf()` in `local_bh_disable()`/`local_bh_enable()`). Because `NIX_LF_CINTX_INT` is level-triggered, `otx2_cq_intr_handler()` masks `NIX_LF_CINTX_ENA_W1C` before scheduling NAPI, and `otx2_napi_handler()` clears `NIX_LF_CINTX_INT` only after draining CQs and before re-enabling `NIX_LF_CINTX_ENA_W1S`. [F24, F174]
- CN10K LMTST flush helpers (`cn10k_sqe_flush()`, `__cn10k_aura_freeptr()`, `cn10k_cpt_inst_flush()`) must execute `dma_wmb()` before copying descriptors to `lmt_info->lmt_addr` and calling `cn10k_lmt_flush()`, with process-context callers wrapped in `get_cpu()`/`put_cpu()`. In `cn10k_outb_prepare_sa()`, all `cn10k_tx_sa_s` fields must be written and ordered with `wmb()` before `sa_entry->sa_valid = 1`, and `cn10k_outb_write_sa()`/`cn10k_outb_cpt_clean()` must acquire exclusive CPT LF access via `cn10k_cpt_device_set_inuse()`. [F31, F160, F177]
- In `otx2_select_queue()` and `otx2_qos_select_htb_queue()`, `pf->qos.maj_id` must be read with `smp_load_acquire()` before `READ_ONCE(pf->qos.defcls)`. Workqueue handlers (`otx2_reset_task`, `cn10k_ipsec_sa_wq_handler`) must take `rtnl_lock()` before `otx2_stop()`/`otx2_open()` or `netdev_update_features()`, whereas RTNL-locked netdev callbacks must not. [F34, F171]

## Object Lifetimes

- In `otx2_remove()` and `otx2_probe()` error unwind, `unregister_netdev()` must be called before `cn10k_ipsec_clean()` and `cn10k_mcs_free()` because netdev unregistration triggers MACsec notifier callbacks (`cn10k_mdo_del_secy()`) that dereference `pf->macsec_cfg`. [F1]
- Non-devres allocations in `otx2_probe()` and `otx2_init_rsrc()` (`pf->af_xdp_zc_qidx`, `pf->hw.lmt_info`, `pf->dync_lmt`) must be freed on all probe/init error paths and in `otx2_remove()` before `free_netdev()`. Devres buffers freed while the PCI device stays bound (`pf->refill_wrk`, `pfvf->qset.pool`, `pool->xdp`, `pf->flr_wrk`, `flow_cfg->flow_ent`) must use `devm_kfree()`, never `kfree()`, and `otx2_aura_pool_free()` must check `if (!pfvf->qset.pool)` and set `pfvf->qset.pool = NULL`. [F2, F15, F152]
- In `otx2_stop()`, setting `OTX2_FLAG_INTF_DOWN` with `smp_wmb()`, masking CQ IRQs, `synchronize_irq()`, and `napi_synchronize()` must complete before `cancel_delayed_work_sync()` on `pool_refill_work`, `otx2_free_hw_resources()`, `otx2_disable_napi()` (which must `cancel_work_sync(&cq_poll->dim.work)` before `napi_disable()`), and `otx2_free_queue_mem()`. In `otx2_free_hw_resources()`, `otx2_free_pending_sqe()` must run after draining CQEs and before `otx2_free_sq_res()`. [F4, F25, F26]
- In `otx2_sriov_enable()` and `otx2_sriov_disable()`, SR-IOV resources (`otx2_pfvf_mbox_init`, `otx2_register_pfvf_mbox_intr`, `otx2_pf_flr_init`, `otx2_register_flr_me_intr`, `pci_enable_sriov`) must be torn down in exact reverse (LIFO) order. On teardown in `otx2_init_rsrc()`, `otx2_probe()`, and `otx2_remove()`, `otx2_detach_resources(&pf->mbox)` and synchronous AF mailbox calls must complete before `otx2_disable_mbox_intr()` and `otx2_pfaf_mbox_destroy()`. [F13, F22]
- In `otx2_forward_vf_mbox_msgs()` (`MBOX_DIR_PFAF`), `dst_mdev->mbase` is pointed to `src_mdev->mbase` under `pf->mbox.lock` and must be restored to `pf->mbox.bbuf_base` before unlocking on all paths. Because NPA pools are hardware stacks returning IOVAs in arbitrary order, `otx2_free_bufs()` and `otx2_sq_free_sqbs()` must translate IOVAs via `otx2_iova_to_phys()`. `cn10k_outb_cptlf_iq_free()` must pass unadjusted `iq->real_vaddr` and `iq->real_dma_addr` to `dma_free_coherent()`. [F10, F97, F175]

## API Contracts

- `otx2_mbox_alloc_msg_*()` returns `NULL` (never `ERR_PTR`) when the mailbox buffer is full; `otx2_get_fwdata()`, `cn10k_mcs_create_txsc()`, and `cn10k_mcs_create_rxsc()` return `ERR_PTR` on failure (whereas `cn10k_mcs_get_txsc()`/`cn10k_mcs_get_rxsc()` return `NULL`). `otx2_alloc_mcam_entries()` returns `-ENOMEM` or the non-negative count allocated (can be `0`), so callers must use signed `int` and check `<= 0`. Atomic-context AF mailbox callers must use `otx2_sync_mbox_msg_busy_poll()`. [F36, F42, F43, F44, F169]
- `otx2_sqe_add_sg()` and `otx2_sqe_add_sg_ipsec()` reset `sq->sg[sq->head].num_segs = 0` and increment `num_segs` only after each successful DMA mapping so `otx2_sq_append_skb()` can unmap partial fragments via `otx2_dma_unmap_skb_frags()` without freeing `skb`. In `otx2_dma_map_skb_frag()` and `otx2_dma_unmap_skb_frags()`, packets with `xfrm_offload(skb)` must be unshared via `skb_unshare(skb, GFP_ATOMIC)` and mapped/unmapped with `DMA_BIDIRECTIONAL`. [F18, F176]
- Software VF indices (`vf`, `vf_idx`, `pf->vf_configs[vf]`, `pf->mbox_pfvf[vf]`, `set_vf_perm->vf`) are 0-based (`0 .. total_vfs - 1`), whereas `pcifunc & RVU_PFVF_FUNC_MASK`, `npc_install_flow_req->vf`, and `ethtool_get_flow_spec_ring_vf()` use 1-based VF numbers (`vf + 1`, with `0` denoting the PF). Unlike `otx2_pfvf_mbox_intr_handler()` (`pf` cookie), `cn20k_pfvf_mbox_intr_handler()` expects `&irq_data[vec]` (`pf->hw.pfvf_irq_devid[vec]`). [F50, F142]
- Reading indexed NIX/NPA operation registers (`NPA_LF_AURA_OP_ALLOCX`, `NIX_LF_RQ_OP_*`, `NIX_LF_SQ_OP_*`, `NIX_LF_CQ_OP_INT`) must use `otx2_atomic64_add()` with the queue/aura index in the operand, never `otx2_read64()`. `cn10k_sqe_flush()` and `cn10k_cpt_inst_flush()` require `size` in bytes to be a multiple of 16 up to 128. `CN10K_CPT_LF_CTX_FLUSH` takes `FIELD_PREP(CPT_LF_CTX_FLUSH_CPTR, sa_iova >> 7)`, whereas `inst.cptr` takes unshifted `sa_iova`. [F53, F55, F157]

## Error Handling

- In `otx2_open()`, if `otx2_rxtx_enable(pf, true)` fails with `-EIO` after partially enabling MCAM entries, the error path must call `otx2_rxtx_enable(pf, false)` before stopping TX queues. In `otx2_dcbnl_ieee_setpfc()`, errors must restore `pfvf->pfc_en = old_pfc_en`, and if `otx2_pfc_txschq_update()` fails, it must also disable backpressure, call `otx2_pfc_txschq_stop()`, and reconfigure `otx2_config_priority_flow_ctrl()`. [F3, F8]
- Functions that abort after `otx2_mbox_alloc_msg_*()` without calling `otx2_sync_mbox_msg()` must call `otx2_mbox_reset(&mbox->mbox, 0)`. Loops batching AQ messages (`otx2_set_rss_table`, `otx2_aura_init`, `otx2_pool_init`) must flush via `otx2_sync_mbox_msg()` and retry when `otx2_mbox_alloc_msg_*()` returns `NULL`. Callers of `otx2_sync_mbox_msg()` returning negative errnos (e.g., `otx2_add_flow()`) must convert `MBOX_MSG_INVALID` (`0xFFFE`) to `-EINVAL`. [F37, F38, F41]

## External Contracts

- In `otx2_pfvf_mbox_handler` and `otx2_forward_vf_mbox_msgs`, before forwarding VF mailbox messages to the AF (`MBOX_DIR_PFAF`) or a VF, the PF must verify `msg->sig == OTX2_MBOX_REQ_SIG`, stamp `msg->pcifunc` with `(vf_idx + 1) & RVU_PFVF_FUNC_MASK`, and validate `mbox_hdr->msg_size <= dst_size` (and non-zero for `MBOX_DIR_PFAF`), while `otx2_sync_mbox_bbuf()` must clamp `hdr->msg_size` to `mbox->rx_size - msgs_offset`. [F80, F194]

## Known Pitfalls

- `otx2_get_fwdata()` returns a pointer into the shared mailbox buffer (`pfvf->mbox.mbox`), so callers issuing another mailbox message (like `otx2_get_phy_fec_stats()`) must call `otx2_get_fwdata()` again afterwards. In `__cn10k_aura_freeptr()` and `cn10k_refill_pool_ptrs()`, `ptrs[0]` holds the 64-bit batch header, buffer IOVAs start at `ptrs[1]`, and `get_cpu()`/`put_cpu()` must never wrap sleeping `GFP_KERNEL` allocations or `otx2_alloc_rbuf()` in `otx2_sq_aura_pool_init()`/`otx2_rq_aura_pool_init()`. [F69, F95, F167]
- Avoid 32-bit shift overflow into 64-bit registers/descriptors: cast `qidx` to `u64` before `<< 32` (`otx2_nix_rq_op_stats`, `otx2_nix_sq_op_stats`, `otx2_sqb_flush`) and `<< 44` (`otx2_q_intr_handler`); cast `cq_time_wait * 10` (`<< 48`) and `cq_qcount_wait` (`<< 32`) to `u64` and write `cq_ecount_wait - 1` (`otx2_config_irq_coalescing`); and cast `gthr_size` (`DIV_ROUND_UP(num_segs, MAX_SEGS_PER_SG) & 0xF`) to `u64` before `<< 60` (`cn10k_ipsec_transmit`). [F120, F121, F122, F123]
- Across two 64-VF interrupt banks (`otx2_enable_pfvf_mbox_intr`, `cn20k_enable_pfvf_mbox_intr`, `otx2_register_flr_me_intr`, `otx2_disable_flr_me_intr`), bank 0 uses `INTR_MASK(numvfs)` and bank 1 is programmed only when `numvfs > 64` with `INTR_MASK(numvfs - 64)`; single-VF bit ops must normalize to `0..63` and use `BIT_ULL()`. Interrupt setup must clear W1C status registers before setting `*_ENA_W1S`, and `otx2_q_intr_handler()` must inspect and clear (`BIT_ULL(44)`) `NIX_LF_SQ_OP_ERR_DBG`, `NIX_LF_MNQ_ERR_DBG`, and `NIX_LF_SEND_ERR_DBG`. [F125, F126, F146, F158]
