# W1 DALLAS'S 1-WIRE BUS

This unit implements the Linux 1-Wire (Dallas/Maxim w1) bus core subsystem, netlink connector interface, bus master controller drivers (GPIO, UART/serdev, I2C DS2482, USB DS2490, OMAP HDQ, i.MX, Matrox, SGI), and slave family drivers (thermal sensors, EEPROMs/EPROMs, battery gauges, switches, and I2C bridges).

## Architecture & Data Flow

- Both `w1_master` and `w1_slave` devices share `w1_bus_type`; any `w1_bus_type` callback (e.g. `w1_uevent()`) must check `dev->driver == &w1_master_driver` or `&w1_slave_driver` before calling `dev_to_w1_master()` or `dev_to_w1_slave()`. [F42]
- `struct w1_reg_num` bitfields cast to `u64` place `family` in bits 0..7, `id` in 8..55, and `crc` in 56..63 in CPU byte order; serializing a ROM ID onto the bus or into `w1_calc_crc8()` requires `cpu_to_le64()` / `le64_to_cpu()`. [F71]
- `struct w1_cb_block` must keep `struct cn_msg request_cn` as its last member; `w1_cn_callback()` places `w1_cb_node[node_count]` after `request_cn.data + cn->len` and sizes `block->first_cn` at `sizeof(struct cn_msg) + reply_size` with `block->maxlen = reply_size`. In `w1_send_slave()`, save `block->cmd` in `cache_cmd` before `w1_reply_make_space()`; if flushing resets `block->cmd` to `NULL`, zero `cache_cmd->len` and re-queue via `w1_netlink_queue_cmd()`. Appending payload to `block->cmd->data` must increment `block->cn->len`, `block->msg->len`, and `block->cmd->len` in lockstep. [F54, F56, F113, F114]
- When walking variable-length `w1_netlink_msg` or `w1_netlink_cmd` items in `w1_cn_callback()`, `w1_list_count_cmds()`, or `w1_process_cb()`, verify `entry->len + sizeof(*entry) <= remaining_len` before advancing the pointer or subtracting from the remaining length. [F73]
- In `ds2482.c`, every I2C command helper (`ds2482_select_register()`, `ds2482_send_cmd()`, `ds2482_send_cmd_data()`, `ds2482_set_channel()`) must update `pdev->read_prt` to match the hardware read pointer register selected by that command. [F57]
- In `w1_ds2433.c` and `w1_ds28e04.c`, `w1_f23_write()` and `w1_f1C_write()` must clear `addr >> W1_PAGE_BITS` in `validcrc`, and `w1_reset_select_slave()` failure in `w1_f23_refresh_block()` / `w1_f1C_refresh_block()` must zero `validcrc`. [F64]

## Synchronization

- Core mutexes nest as `w1_mlock -> w1_master.mutex -> w1_master.list_mutex` and `w1_master.mutex -> w1_master.bus_mutex`. `w1_process_command_master()` is entered and must return with `dev->bus_mutex` held, temporarily unlocking `bus_mutex` before calling `w1_get_slaves()` or acquiring `dev->mutex` for `w1_process_command_addremove()`. [F10, F145]
- `w1_attach_slave_device()` is entered and must return with `dev->mutex` held, but must unlock `dev->mutex` around `request_module()` so `w1_register_family()` / `w1_reconnect_slaves()` does not deadlock. [F11]
- Callers iterating `w1_master.slist` under `list_mutex` must drop `list_mutex` before calling `w1_slave_detach()`, `w1_attach_slave_device()`, `w1_unref_slave()`, or `w1_slave_search_device()`, and in `w1_reconnect_slaves()` must copy `sl->reg_num` into a local variable before `w1_slave_detach(sl)` can free `sl`. [F19, F70]
- `w1_process_callbacks()` must be entered with `dev->list_mutex` held and drop `dev->list_mutex` around each `async_cmd->cb(dev, async_cmd)`. In `w1_process()`, hold `dev->list_mutex` across `w1_process_callbacks()` until after `__set_current_state(TASK_INTERRUPTIBLE)`, and restore `__set_current_state(TASK_RUNNING)` on any loop exit. [F6, F149]
- In `w1_cn_callback()`, fully initialize `w1_cb_block` and each `w1_cb_node` (including `block->refcnt` and `dev->refcnt`/`sl->refcnt`) before adding `node->async.async_entry` to `dev->async_list`; subsequent error replies in `w1_cn_callback()` must use `w1_netlink_send_error()` without touching `block`. [F22]
- `w1_family_registered()` and `__w1_family_get()` must run within the same `w1_flock` spinlock critical section, while `w1_reconnect_slaves()` must be called outside `w1_flock`. [F26]
- All 1-Wire bus transactions (`w1_reset_bus()`, `w1_reset_select_slave()`, `w1_reset_resume_command()`, `w1_next_pullup()`, bit/byte/block I/O) require `w1_master.bus_mutex`. `w1_search()` and `w1_bus_master.search` (e.g. `ds9490r_search()`) must check `test_bit(W1_ABORT_SEARCH, &dev->flags)` to abort early and unlock `bus_mutex` before invoking `w1_slave_found_callback`. [F27, F101, F148]
- In `w1_io.c`, `w1_read_bit()` disables local IRQs via `local_irq_save()` before calling `write_bit` and `read_bit` (and `w1_write_bit()` does so when `w1_disable_irqs` is set), so `read_bit` and `write_bit` callbacks must be atomic and never sleep or use `_cansleep` GPIO helpers. [F142]
- In `w1_therm.c`, `convert_t()` and `conv_time_measure()` must hold `dev_master->bus_mutex` across `w1_poll_completion()` (and `msleep_interruptible(t_conv)` when `!strong_pullup` in `convert_t()`), and unlock `bus_mutex` before calling `read_scratchpad()`. [F28]
- In `omap_hdq.c`, `hdq_isr()` must bitwise-OR `OMAP_HDQ_INT_STATUS` into `hdq_data->hdq_irqstatus` under `hdq_spinlock`, and process-context callers under `hdq_mutex` must clear only consumed bits via `hdq_reset_irqstatus()` before the next transfer. [F30]
- In `w1-uart.c`, `w1_uart_serdev_tx_rx()` must call `reinit_completion(&w1dev->rx_byte_received)` before `serdev_device_write_buf()`. Both `w1_uart_serdev_tx_rx()` and `w1_uart_serdev_receive_buf()` must guard `rx_byte`/`rx_err` with `rx_mutex`, and `w1_uart_serdev_receive_buf()` must unlock `rx_mutex` before `complete(&w1dev->rx_byte_received)` because `w1_uart_serdev_tx_rx()` uses `mutex_trylock(&w1dev->rx_mutex)`. [F31, F150]

## Object Lifetimes

- `w1_search_slave()` increments both `sl->refcnt` and `sl->master->refcnt`, so callers must release `sl` via `w1_unref_slave()`. Detaching a slave from `w1_master.slist` must go through `w1_slave_detach()`, which sets `W1_SLAVE_DETACH` under `list_mutex` before calling `w1_unref_slave()`. [F1, F4]
- `w1_alloc_dev()` allocates `w1_master` and `w1_bus_master` in one `kzalloc` block (`dev->bus_master = (struct w1_bus_master *)(dev + 1)`), so `w1_master_release()` must only `kfree(md)`. `w1_alloc_dev()` initializes `dev->refcnt` to 1, and `w1_process()` must increment `dev->refcnt` on entry and decrement it on exit. [F5, F112]
- `__w1_remove_master_device()` must unlink `dev` from `w1_masters` under `w1_mlock`, set `W1_ABORT_SEARCH` and stop `dev->thread`, detach all slaves, and drain `w1_process_callbacks(dev)` under `dev->list_mutex` while waiting for `dev->refcnt == 0` before `w1_free_dev(dev)`. Loops over `w1_masters` calling `__w1_remove_master_device()` must use `list_for_each_entry_safe()`. [F23, F95]
- `w1_unregister_family()` must unlink `fent->family_entry` from `w1_families` under `w1_flock` before calling `w1_reconnect_slaves(fent, 0)`, then wait for `atomic_read(&fent->refcnt) == 0`. [F12]
- In `w1_cn_callback()`, `w1_cb_block.refcnt` starts at 1 for the sender and is incremented per queued `w1_cb_node`, with `node->msg` set as an offset into `block->request_cn`; both `w1_cn_callback()` and each `w1_process_cb()` must call `w1_unref_block()`. [F9, F115]
- In `__w1_attach_slave_device()` and `w1_family_notify()`, suppress uevents on `sl->dev` until `fops->add_slave()`, `fops->groups`, and `sl->hwmon` finish, and call `of_node_put(sl->dev.of_node)` if `device_register(&sl->dev)` fails. On `BUS_NOTIFY_DEL_DEVICE`, `hwmon_device_unregister(sl->hwmon)` runs before `fops->remove_slave(sl)`, which runs before `sysfs_remove_groups()` and `device_unregister(&sl->dev)`: `remove_slave` must unregister child devices (`i2c_del_adapter()`, `platform_device_unregister()`) before `sl->dev` teardown. [F25, F126, F127, F135]
- Because `remove_slave` runs before `sysfs_remove_groups()`, `remove_slave` callbacks that free `sl->family_data` must set `sl->family_data = NULL`. In `w1_therm.c`, sysfs handlers must check `sl->family_data` before dereferencing it, operations that sleep or drop `bus_mutex` must hold `THERM_REFCNT(sl->family_data)`, and `w1_therm_remove_slave()` must wait for `THERM_REFCNT` to reach 0 before `kfree(sl->family_data)`. [F15, F128]
- Bus master drivers must initialize all locks, completions, hardware state, and `w1_bus_master` callbacks before `w1_add_master_device()`, and call `w1_remove_master_device()` before disabling clocks/PM or freeing state (`w1_uart_probe()` must init `rx_mutex`/`rx_byte_received` and serdev ops before `w1_uart_serdev_open()`; `mxc_w1` must keep `clk` enabled across register access and master lifetime; `omap_hdq.c` must call `pm_runtime_put_noidle()` on failed `pm_runtime_get_sync()`). [F24, F122, F140, F141]

## API Contracts

- `w1_search_master_id()` increments `dev->refcnt` on the returned `w1_master`, whereas `w1_slave_search_device()` returns a borrowed `w1_slave *` from `dev->slist` without incrementing `sl->refcnt` or `dev->refcnt`. [F2]
- Every `w1_async_cmd.cb` callback invoked by `w1_process_callbacks()` is entered with `dev->list_mutex` unlocked and must lock `dev->list_mutex` to `list_del(&async_cmd->async_entry)`, unlock it, and free its backing storage before returning. [F8]
- `w1_add_master_device()` copies `struct w1_bus_master` by value and `w1_remove_master_device()` matches `dev->bus_master->data == bm->data`, so `bm->data` must be unique per master channel and unchanged at removal. A master with `(write_byte && read_byte && reset_bus)` and `NULL` `touch_bit` must also implement `(read_bit && write_bit)` or `triplet`/`search`. [F153, F154]
- `w1_read_block()` and `w1_bus_master.read_block` return an unsigned `u8` byte count (`0` on error in `ds9490r_read_block()`), so implementations cannot return negative errnos and callers comparing against `len` must bound `len <= 255`. `w1_triplet()` and `w1_bus_master.triplet` return a `u8` bitmask (`id_bit` in `BIT(0)`, `comp_bit` in `BIT(1)`, `dir_taken` in `BIT(2)`) and signal bus error/no slave by setting `(ret & 0x03) == 0x03`. [F35, F36]
- `w1_next_pullup()` sets a one-shot `dev->pullup_duration` consumed and cleared by `w1_post_write()` at the end of the next `w1_write_8()`, so invoke `w1_next_pullup()` immediately before the final command byte. Because `w1_pre_write()` calls `set_pullup(data, duration)` before writing and `w1_post_write()` calls `set_pullup(data, 0)` after, `w1_gpio_set_pullup()` must only save `pullup_duration = delay` when `delay != 0` and execute the GPIO high pulse and `msleep()` when `delay == 0`. [F51, F155]
- On a `w1_slave`, sysfs `device_attribute` callbacks must use `dev_to_w1_slave(dev)` and `bin_attribute` callbacks `kobj_to_w1_slave(kobj)`, whereas `hwmon_ops` callbacks receive the child hwmon `struct device *` and must use `dev_get_drvdata(dev)`. Guard hwmon symbols in `w1.c` and `w1_therm.c` with `IS_REACHABLE(CONFIG_HWMON)`, and use `0x`-prefixed two-digit uppercase hex in `MODULE_ALIAS("w1-family-" __stringify(...))` to match `request_module("w1-family-0x%02X", rn->family)`. [F157, F158, F160]
- In `ds2482.c`, every `w1_bus_master` I/O callback must lock `pdev->access_lock`, call `ds2482_wait_1wire_idle(pdev)`, and call `ds2482_set_channel(pdev, pchan->channel)` only when `pdev->w1_count > 1` (writing `ds2482_chan_wr[channel]` and verifying `ds2482_chan_rd[channel]`). `DS2482_CMD_WRITE_CONFIG` requires `ds2482_calculate_config()`, and `DS2482_CMD_1WIRE_SINGLE_BIT` / `DS2482_CMD_1WIRE_TRIPLET` take their bit in bit 7 (`bit ? 0xFF : 0`). [F50, F58, F88, F130]
- In `ds2490.c`, `ds_send_data()` and `ds_recv_data()` pass `buf` directly to `usb_bulk_msg()`, and `read_block_chunk()` (capped at `FIFO_SIZE` = 128 bytes by `ds_read_block()`) must `memset(buf, 0xFF, len)` and transmit `buf` before `COMM_BLOCK_IO`, so `ds9490r_write_block()` and `ds9490r_read_block()` must use heap buffers. [F49, F89]

## Error Handling

- `w1_unref_slave()` returns the post-decrement `sl->refcnt` (`0` when destroyed, `> 0` when refs remain), whereas `w1_slave_detach()` returns `0` when destroyed immediately or `-EBUSY` if refs remain or `W1_SLAVE_DETACH` was already set. [F38]
- `w1_reset_bus()` masks `bus_master->reset_bus()` with `& 0x1` (`0` for presence, `1` for error), and `w1_reset_select_slave()` / `w1_reset_resume_command()` return `-1` (`-EPERM`) on failure, so slave drivers must translate non-zero returns into standard negative errnos (`-EIO`, `-ENODEV`). [F168]
- In `w1_therm.c`, `bus_mutex_lock()` returns `true` when acquired and `false` after `W1_THERM_MAX_TRY` interrupted attempts; callers must test `!bus_mutex_lock(&dev_master->bus_mutex)` for failure. [F39]
- `w1_netlink_send()` copies all of `struct w1_netlink_msg` with `*pkt_msg = *msg`, so callers with a stack `w1_netlink_msg` must `memset(&msg, 0, sizeof(msg))` first. [F48]

## Known Pitfalls

- `w1_reset_select_slave()` sends `W1_SKIP_ROM` instead of `W1_MATCH_ROM` when `sl->master->slave_count == 1`; do not use it in `w1_ds2405.c` (where `W1_MATCH_ROM` toggles PIO state) or in `w1_therm.c` (`reset_select_slave()`, called while `slave_count == 1` during discovery on multi-slave buses). [F53]
- Lookup loops over `w1_masters`, `dev->slist`, or `w1_families` (`w1_remove_master_device()`, `w1_search_master_id()`, `w1_search_slave()`, `w1_family_registered()`) must record matches in a separate variable/flag rather than returning the loop cursor directly. [F98]
- Widen 8-bit values before 64-bit shifts or high-bit comparisons: widen `(triplet_ret >> 2)` to `u64` before `<< i` in `w1_search()`; widen `w1_calc_crc8()` to `u64` before `<< 56` in `omap_w1_search_bus()`; keep protocol/family bytes as unsigned `u8` rather than `char` when comparing against `0xFF` or `W1_42_FINISHED_BYTE`. In `w1_ds28e04.c`, `w1_f1C_data.validcrc` is a `u32`, so manipulate it with integer bit masks (`1 << block`) rather than `set_bit()`/`clear_bit()`/`test_bit()`. [F105, F106, F108, F120]
- In `w1_therm.c`, `w1_DS18B20_set_resolution()` and `alarms_store()` must call `read_scratchpad()` before `write_scratchpad()` to preserve unchanged `TH`/`TL`/config bytes, and `w1_DS18B20_set_resolution()` must read the scratchpad back to verify resolution bits changed. `w1_DS18B20_convert_temp()` and `w1_DS1825_convert_temp()` must decode `rom[0..1]` via `le16_to_cpup((__le16 *)rom)` into `u16` before shifting/masking and casting to `s16`, and `w1_DS18S20_convert_temp()` must check `rom[7] != 0` before dividing. [F66, F91, F132]
