# LIBRARY CODE

Provides core kernel data structures, allocators, reference-counting primitives, scatterlist/usercopy helpers, parsers, encoders/decompressors, and utility libraries in `lib/`.

## Architecture & Data Flow

- In `lib/assoc_array.c`, `assoc_array_delete()` must keep `edit->ops_for_excised_subtree == NULL` when collapsing a subtree (surviving leaves are copied into `new_n0` without new references; only `edit->dead_leaf` is freed), and when removing the final leaf (`nr_leaves_on_tree == 1`) it must set `edit->set[1]` to clear `array->root = NULL`, `edit->excised_subtree = array->root`, and `edit->adjust_count_on = NULL`. In `assoc_array_rcu_cleanup()`, `edit->excised_subtree`'s root `back_pointer` must be cleared to `NULL` before `assoc_array_destroy_subtree()`. [F7, F53, F54]
- In `assoc_array_gc()`, if any child node could not be folded into `new_n` (`retained == true`) but the final total `new_n->nr_leaves_on_branch <= ASSOC_ARRAY_FAN_OUT`, it must jump back to `retry_compress`; when folding a child at `new_n->slots[slot]`, it must clear `new_n->slots[slot] = NULL` and rewind `next_slot = slot` whenever `slot < next_slot`. [F86, F87]
- In `lib/genalloc.c`, `struct gen_pool_chunk::end_addr` is inclusive (`virt + size - 1`), so `chunk_size()` is `end_addr - start_addr + 1` and range checks (`gen_pool_virt_to_phys()`, `gen_pool_free_owner()`, `gen_pool_has_addr()`) must use `<= chunk->end_addr`. Chunk capacity in bitmap bits rounds down (`size >> order`) and `chunk->bits` must be sized as `BITS_TO_LONGS(nbits) * sizeof(long)` bytes for `unsigned long` `try_cmpxchg()`, whereas alloc/free request `nbits` round up (`(size + (1UL << order) - 1) >> order`) and `chunk->avail` is adjusted by `nbits << pool->min_alloc_order`. [F47, F77, F106, F115]
- In `lib/dynamic_queue_limits.c`, `dql_queued()` must reject `count > DQL_MAX_OBJECT` (`UINT_MAX / 16`) and `dql_completed()` must clamp `dql->limit` to `dql->max_limit <= DQL_MAX_LIMIT` so signed `(int)` differences in `POSDIFF()`, `AFTER_EQ()`, and `dql_avail()` do not overflow on wrapping `unsigned int` counters. When clamped `limit != dql->limit`, `dql_completed()` must reset `ovlimit = 0` before setting `dql->prev_ovlimit = ovlimit` and `dql->adj_limit = limit + completed`. [F50, F81, F107]
- In `lib/stackdepot.c`, `union handle_parts` stores `pool_index + 1` in `pool_index_plus_1` (`stack_max_pools <= (1LL << DEPOT_POOL_INDEX_BITS) - 1`), so `depot_fetch_stack()` must subtract 1 into `u32 pool_index` and reject `pool_index >= pools_num_cached`. Every size passed to `depot_pop_free_pool()` must be aligned to `1 << DEPOT_STACK_ALIGN` via `depot_stack_record_size()`. Because `entries` is unioned with `free_list` and `rcu_state` in `struct stack_record`, a record may be on `free_stacks` only while `refcount_read(&stack->count) == 0`, and `depot_alloc_stack()` must size evictable (`STACK_DEPOT_FLAG_GET`) records for `CONFIG_STACKDEPOT_MAX_FRAMES`. [F220, F231, F262, F263]
- In `sg_append_table`, `sgt.orig_nents` and `sgt.nents` count only scatterlist entries populated with pages, while total allocated entries across chained chunks are tracked in `total_nents` and freed via `sg_free_append_table()`. In `__sg_page_iter_next()` and `__sg_page_iter_dma_next()`, a `while` loop (not `if`) must compare `piter->sg_pgoffset >= sg_page_count(piter->sg)` to skip zero-length SG entries and multi-entry offsets. In `sg_split_phys()`, only the first entry (`!j`) of each split scatterlist adjusts `offset` and `length` by `split->skip_sg0`; `j > 0` retains `in_sg->offset`, and all output entries clear `dma_address` and `dma_length` to 0. [F212, F217, F250]
- In `struct seq_buf`, overflow sets `s->len = s->size + 1` (`seq_buf_set_overflow()`), so readers of `s->buffer` must clamp length with `seq_buf_used(s)` (`min(s->len, s->size)`). String writers (`seq_buf_puts()`, `seq_buf_vprintf()`, `seq_buf_bprintf()`) require room for a trailing NUL (`s->len + text_len < s->size`) without counting NUL in `s->len`, whereas raw writers (`seq_buf_putmem()`, `seq_buf_putc()`) allow `s->len == s->size` and require `seq_buf_str()` before treating `s->buffer` as a C string. [F225, F235]

## Synchronization

- Callers of `assoc_array_iterate()` and `assoc_array_find()` must hold `rcu_read_lock()` or an external write lock, and internal walks (`assoc_array_subtree_iterate()`, `assoc_array_walk()`, `assoc_array_find()`) must load `root`, `slots`, `next_node`, and `back_pointer` with `READ_ONCE()`. `assoc_array_subtree_iterate()` must scan each node in two passes (all leaf slots before descending into metadata slots) so concurrent node splits do not miss leaves. `assoc_array_destroy()` frees subtrees immediately without RCU grace periods and must only be called when all concurrent and RCU read accesses are prevented. [F15, F16, F85]
- In `lib/stackdepot.c`, `pool_lock` (`raw_spinlock_t`) protects all updates to `stack_pools`, `new_pool`, `pools_num`, `pool_offset`, and `free_stacks`, while `depot_fetch_stack()` must never be called with `pool_lock` held. In `depot_init_pool()`, `stack_pools[pools_num] = new_pool` must be assigned before `WRITE_ONCE(pools_num, pools_num + 1)` (pairing with `READ_ONCE(pools_num)` in `depot_fetch_stack()`). [F185, F186]
- In `stack_depot_save_flags()`, when `in_nmi()` or `!gfpflags_allow_spinning(alloc_flags)` (`!allow_spin`), `pool_lock` must be acquired via `raw_spin_trylock_irqsave()` (bailing to `exit` on contention) and page allocation must be skipped. After a lockless `find_stack()` miss and any page allocation outside `pool_lock`, `find_stack()` must be re-run under `pool_lock` before `depot_alloc_stack()`. `find_stack()` must traverse hash buckets under `rcu_read_lock_sched_notrace()` and, when `STACK_DEPOT_FLAG_GET` is set, succeed in `refcount_inc_not_zero(&stack->count)`. `depot_free_stack()` must unlink via `list_del_rcu()`, record `stack->rcu_state = get_state_synchronize_rcu()`, and `list_add_tail()` to `free_stacks`, while `depot_pop_free()` must check `poll_state_synchronize_rcu(stack->rcu_state)` before reuse. [F187, F188, F189, F291]
- In `lib/ref_tracker.c`, `debugfs_reap_worker`, `debugfs_dentries`, and `debugfs_symlinks` must be initialized in `postcore_initcall(ref_tracker_debugfs_postcore_init)` with `XA_FLAGS_LOCK_IRQ`. `ref_tracker_dir_exit()` must mark `debugfs_dentries`/`debugfs_symlinks` `REF_TRACKER_DIR_DEAD` and schedule `debugfs_reap_worker` before acquiring `dir->lock`, while `ref_tracker_debugfs_show()` must check `debugfs_dentries` under `xa_lock_irqsave()` and acquire `dir->lock` before dropping `xa_lock`. Callers of `__ref_tracker_dir_pr_ostream()` and `ref_tracker_dir_print_locked()` must hold `dir->lock`, and internal allocations in `__ref_tracker_dir_pr_ostream()`, `ref_tracker_get_stats()`, and `ref_tracker_free()` must use `GFP_NOWAIT`. [F182, F183, F297, F298]
- In `gen_pool_add_owner()`, all fields of a new `struct gen_pool_chunk` (`phys_addr`, `start_addr`, `end_addr`, `owner`, `avail`) must be initialized in sleepable process context (it calls `vzalloc_node()`) before acquiring `pool->lock` and publishing with `list_add_rcu(&chunk->next_chunk, &pool->chunks)`. [F18, F140]
- Between `dql_queue_stall()` and `dql_check_stall()`, clearing reused `dql->history` slots must be ordered before `WRITE_ONCE(dql->history_head, now_hi)` by `smp_wmb()`, and `dql_check_stall()` must issue `smp_rmb()` after `READ_ONCE(dql->history_head)` and retry if `READ_ONCE(dql->history_head)` changed after scanning `dql->history`. [F20]
- `refcount_dec_and_mutex_lock()`, `refcount_dec_and_lock()`, and `refcount_dec_and_lock_irqsave()` hold `@lock` on return if and only if they return `true`. In `rcuref_put_slowpath()`, transitioning `ref->refcnt` from `RCUREF_NOREF` to `RCUREF_DEAD` via `atomic_try_cmpxchg_release()` must be followed by `smp_acquire__after_ctrl_dep()` before returning `true`. [F169, F179]

## Object Lifetimes

- In `lib/cpu_rmap.c`, `irq_cpu_rmap_release()` and the `err_set` path of `irq_cpu_rmap_add()` must clear `rmap->obj[glue->index] = NULL` before calling `cpu_rmap_put(glue->rmap)` (which may `kfree(rmap)`). `free_irq_cpu_rmap()` must be called in process context before `free_irq()` because `irq_set_affinity_notifier(..., NULL)` sleeps and requires valid IRQ descriptors. [F1, F124]
- In `lib/genalloc.c`, all allocations from a `struct gen_pool` must be freed before `gen_pool_destroy()` or `devm_gen_pool_release()` runs, or `gen_pool_destroy()` triggers `BUG_ON(bit < end_bit)`. `of_gen_pool_get()` returns a borrowed `struct gen_pool *` and must release `of_node_put(parent)`, `put_device(&pdev->dev)`, and `of_node_put(np_pool)` before returning. [F2, F128]
- In `lib/scatterlist.c`, `__sg_free_table()` must receive the same `max_ents` and `nents_first_chunk` passed to `__sg_alloc_table()` (skipping `free_fn` on the first chunk when `nents_first_chunk != 0`), read `next = sg_chain_ptr(&sgl[curr_max_ents - 1])` before `free_fn(sgl, alloc_size)`, and decrement `num_ents` by `sg_size` (`curr_max_ents - 1`). In `sg_alloc_table_chained()` and `sg_free_table_chained()`, `nents_first_chunk == 1` must be normalized to `0` so the pool-allocated first chunk is freed. Every `struct sg_mapping_iter` advanced with `sg_miter_next()` holds an active page mapping when `miter->addr != NULL` that must be unmapped by `sg_miter_stop()`. [F163, F165, F166, F249]
- In `lib/stackdepot.c`, a `prealloc` page allocated in `stack_depot_save_flags()` before `pool_lock` is either consumed by `depot_init_pool()` or `depot_keep_new_pool()` (which set `prealloc = NULL`, never overwriting a non-NULL `new_pool` or `STACK_DEPOT_POISON` when `pools_num == stack_max_pools`) or freed at `exit` via `free_pages_nolock()` when `!allow_spin` and `free_pages()` otherwise. [F172, F221, F295]

## API Contracts

- In `lib/assoc_array.c`, `assoc_array_cancel_edit()` and `assoc_array_insert_set_object()` never free the leaf object in `edit->leaf` (leaving leaf cleanup to the caller until `assoc_array_apply_edit()`). In `assoc_array_gc()`, the `iterator` callback must increment a retained leaf's reference count before returning `true`, because both `assoc_array_rcu_cleanup()` and the `enomem` rollback path call `ops->free_object()` on every leaf in their subtrees. [F5, F6]
- In `lib/devres.c`, `devm_ioremap_resource*()` and `devm_of_iomap()` return `IOMEM_ERR_PTR()` on failure, whereas `devm_ioremap*()` and `devm_ioport_map()` return `NULL`; `devm_iounmap()` and `devm_ioport_unmap()` must only be passed addresses mapped by `devm_ioremap*()`/`devm_ioport_map()`. In `lib/genalloc.c`, `devm_gen_pool_create()` checks `gen_pool_get(dev, name)` and returns `ERR_PTR(-EINVAL)` on duplicate name (`NULL` matches only unnamed pools in `devm_gen_pool_match()`) or `ERR_PTR(-ENOMEM)`, whereas `gen_pool_create()`, `gen_pool_get()`, and `of_gen_pool_get()` return `NULL`. [F30, F31, F49, F125]
- In `lib/genalloc.c`, `gen_pool_virt_to_phys()` returns `(phys_addr_t)-1` on failure while `gen_pool_alloc_algo_owner()` returns `0`; `genpool_algo_t` callbacks must return a bit index `>= size` (`end_bit`) on failure because bit `0` is a valid allocation, and `gen_pool_fixed_alloc()` requires `offset` aligned to `1UL << pool->min_alloc_order` (log2 bytes per bit). `gen_pool_for_each_chunk()` callbacks and `genpool_algo_t` run under `rcu_read_lock()` and must not sleep, and `gen_pool_alloc*()`/`gen_pool_free*()` must not be called from NMI unless `CONFIG_ARCH_HAVE_NMI_SAFE_CMPXCHG` is defined. [F32, F34, F139, F141, F155]
- In `lib/scatterlist.c`, `pages_are_mergeable(a, b)` requires the next candidate page as `a` and the preceding page as `b` (`page_to_pfn(a) != page_to_pfn(b) + 1`). `sg_alloc_append_table_from_pages()` rejects `max_segment < PAGE_SIZE` or a non-zero `offset` when `sgt_append->prv != NULL` with `-EINVAL`, and only calls `sg_mark_end()` when `left_pages == 0`. `extract_iter_to_sg()` pins pages only for `ITER_UBUF`/`ITER_IOVEC`, updates `sgtable->nents` (not `orig_nents`), and does not set `sg_mark_end()`; `extract_folioq_to_sg()` and `extract_xarray_to_sg()` add multi-page folios using `folio_page(folio, 0)` and `offset_in_folio(folio, start)`. `sg_miter_next()`/`sg_miter_stop()` must match `kmap_atomic`/`kmap_local_page`/`kmap` to `miter->__flags` and call `flush_dcache_page()` when `SG_MITER_TO_SG` is set. [F193, F242, F301, F315, F316]
- In `lib/usercopy.c`, `lib/strncpy_from_user.c`, and `lib/strnlen_user.c`, all `unsafe_get_user()` calls must be bracketed by `user_read_access_begin()` (or `masked_user_access_begin()`) and `user_read_access_end()` on all paths. `strnlen_user(str, count)` returns `0` on fault or `count <= 0`, `len + 1` on success, and `> count` on truncation. `check_zeroed_user(from, size)` returns `1` if all-zero, `0` if non-zero bytes exist, or `-EFAULT` (requiring a signed `int`). [F201, F202, F307]
- In `lib/stackdepot.c`, `0` is the empty `depot_stack_handle_t` sentinel, so `stack_depot_set_extra_bits(0, ...)` must return `0` unchanged and `stack_depot_fetch(0, entries)` must set `*entries = NULL` and return `0`. In `lib/rcuref.c`, `__rcuref_put()`/`rcuref_put_rcusafe()` require preemption disabled or `rcu_read_lock()`, and callers may deconstruct the object if and only if `rcuref_put_slowpath()` returns `true` (`rcuref_get_slowpath()` returns `false` and sets `RCUREF_DEAD` when `cnt >= RCUREF_RELEASED`, and returns `true` with `RCUREF_SATURATED` when `cnt > RCUREF_MAXREF`). [F168, F206, F208]

## Error Handling

- In `gen_pool_alloc_algo_owner()`, if `bitmap_set_ll(chunk->bits, start_bit, nbits)` fails partway and returns a non-zero `remain`, the `nbits - remain` bits already set must be rolled back via `bitmap_clear_ll()` before jumping to `retry`. In `__devm_ioremap_resource()`, if `__devm_ioremap()` fails after `devm_request_mem_region()`, `devm_release_mem_region(dev, res->start, size)` must be called immediately. [F4, F11]
- If `__sg_alloc_table()` fails after allocating one or more chunks, it leaves the partial chain in `table->sgl` (incrementing `table->orig_nents` if `prv != NULL`) and the caller must call `__sg_free_table()` to release them. In `sg_alloc_append_table_from_pages()`, `get_next_sg()` returns `ERR_PTR(-ENOMEM)` (not `NULL`), and on `IS_ERR(s)` the caller must restore `sgt_append->prv->length = prv_len` before returning `PTR_ERR(s)`. [F162, F197]

## Known Pitfalls

- In `do_strnlen_user()` and `check_zeroed_user()`, when aligning the user pointer down by `align` bytes and adding `align` to `max`/`size`, the leading `align` bytes of the first word must be masked with `aligned_byte_mask(align)` (and trailing bytes in `check_zeroed_user()` with `aligned_byte_mask(size)`), and the word loop must stop when remaining bytes are `<= sizeof(unsigned long)` (`while (size > sizeof(unsigned long))` / `if (max <= sizeof(unsigned long)) break`). [F237, F258]
- In `extract_user_to_sg()`, `iov_iter_extract_pages()` returning `res <= 0` (including `0` bytes) must jump to `failed` to avoid an infinite loop. In `sgl_alloc_order()`, `nent = round_up(length, PAGE_SIZE << order) >> (PAGE_SHIFT + order)` must be followed by `if (length > (nent << (PAGE_SHIFT + order))) return NULL;` and `nalloc + 1 < nalloc` overflow checks. In `sg_page_count()`, `sg_dma_page_count()`, and `extract_user_to_sg()`, `offset + length` must be rounded up to `PAGE_SIZE` before shifting by `PAGE_SHIFT`. [F246, F269, F270]
- In `refcount_dec_not_one()`, `val` and `new = val - 1` must be `unsigned int` so `val == 0` wraps to `UINT_MAX` and triggers `new > val`. Unlike `of_iomap()`, `devm_of_iomap()` calls `devm_request_mem_region()` and fails with `-EBUSY` on shared overlapping regions. [F127, F266]
