# EROFS FILE SYSTEM

EROFS (Enhanced ROM File System) is a read-only Linux filesystem supporting uncompressed and compressed data layouts across block devices, DAX, fileio, and fscache backends.

## Architecture & Data Flow

- When `z_erofs_bind_cache()` finds all compressed pages in `MNGD_MAPPING` or `z_erofs_pcluster_begin()` handles an inline `pcl->from_meta` pcluster, `fe->mode` must be `Z_EROFS_PCLUSTER_FOLLOWED_NOINPLACE`; when `fe->mode < Z_EROFS_PCLUSTER_FOLLOWED`, file-backed folios must not be used for in-place I/O or `fe->candidate_bvpage` in `z_erofs_scan_folio()` and `z_erofs_attach_page()`, and in `z_erofs_pcluster_end()`, `z_erofs_put_pcluster()` is called only when `fe->mode < Z_EROFS_PCLUSTER_FOLLOWED_NOINPLACE` (otherwise ownership transfers to `fe->head` for `z_erofs_decompress_pcluster()`). [F9, F37, F73]
- `z_erofs_alloc_pcluster()` must be sized by `pageofs_in + map->m_plen`, and `pcl->pageofs_in` and `pcl->pclustersize` must preserve the same `z_erofs_pclusterpages(pcl)` value until `z_erofs_free_pcluster()` looks up the `pcluster_pool` `kmem_cache` from `z_erofs_pclusterpages(pcl)`. [F143]
- Because `EROFS_FEATURE_INCOMPAT_FRAGMENTS` and `EROFS_FEATURE_INCOMPAT_DEDUPE` share bit `0x00000020`, `erofs_sb_has_fragments(sbi)` does not imply `sbi->packed_inode` is non-NULL; callers like `erofs_xattr_prefixes_init()` and `z_erofs_read_fragment()` must check `sbi->packed_inode != NULL` directly. [F42]
- In `erofs_fill_from_devinfo()`, `dif->file` must be checked for both non-NULL and `S_ISBLK(file_inode(dif->file)->i_mode)` before calling `file_bdev(dif->file)`. [F43]
- Extra devices get 0-based IDs in `sbi->devs->tree`, whereas `erofs_map_blocks.m_deviceid` uses 0 for `sbi->dif0` and 1-based IDs for extra devices, so `erofs_map_dev()` must pass `map->m_deviceid - 1` to `idr_find()`. In `erofs_init_device()`, validating and allocating `dis->tag` must be skipped when `sbi->devs->flatdev` is true or `dif->path` is set. [F89, F106]
- In `erofs_read_inode()` for `EROFS_INODE_LAYOUT_COMPACT`, `dic->i_nb` holds `startblk_hi` only when `!S_ISDIR(inode->i_mode)` and `EROFS_I_NLINK_1_BIT` is set in `i_format`; otherwise `dic->i_nb` holds `nlink`, so `copied.i_nb.startblk_hi` must be zeroed and `addrmask` restricted to `BIT_ULL(32) - 1`. [F91]
- Whenever `erofs_map_blocks()` or `z_erofs_map_blocks_fo()` sets `EROFS_MAP_META` on an inline metadata extent, it must verify `erofs_blkoff(sb, map->m_pa) + map->m_plen <= sb->s_blocksize` or return `-EFSCORRUPTED`. [F90]
- In `z_erofs_map_blocks_ext()`, when `la > map->m_la`, `la > lend` (initially `inode->i_size`) must be rejected with `-EFSCORRUPTED` before narrowing `lend = la`. Backward scans in `z_erofs_extent_lookback()` and `z_erofs_load_compact_lcluster()` (`big_pcluster`) must reject `m->delta[0] == 0` and `lo <= 1` with `-EFSCORRUPTED`. In `z_erofs_get_extent_decompressedlen()`, a `Z_EROFS_LCLUSTER_TYPE_NONHEAD` lcluster with `m->delta[1] == 0` must be clamped to `1` before `lcn += m->delta[1]`. [F82, F116, F117]
- In `erofs_xattr_iter_inline()`, `xattr_header_sz >= vi->xattr_isize` and `remaining < entry_sz` (`erofs_xattr_entry_size(it->kaddr)`) must be checked before subtracting them, and `erofs_inode::xattr_isize`, `xattr_header_sz`, `remaining`, and `erofs_xattr_ibody_size()` must be at least 32-bit `unsigned int` rather than `u16`. [F94, F126]
- In `erofs_listxattr_foreach()` and `erofs_getxattr_foreach()`, when `EROFS_XATTR_LONG_PREFIX` is set, `entry.e_name_index & EROFS_XATTR_LONG_PREFIX_MASK` must be checked against `sbi->xattr_prefix_count`, and all accesses to `pf->prefix->infix` (not NUL-terminated on disk) must be bounded by `pf->infix_len`. [F93, F154]
- On 32-bit architectures, `erofs_squash_ino()` folds the 64-bit NID into `inode->i_ino`, so `erofs_iget()` must use `iget5_locked()` with `erofs_iget5_eq()` comparing `EROFS_I(inode)->nid`. [F125]
- `struct z_erofs_bvec::offset` is a signed `int` relative to `map->m_la` (negative when a page starts before `map->m_la`), so `z_erofs_fill_other_copies()` and `z_erofs_fill_bio_vec()` must handle `offset < 0` before converting to unsigned page offsets. [F130]
- In `struct z_erofs_decompressqueue`, `u.work` and `u.kthread_work` must share the same offset in `union u` and `z_erofs_decompressqueue_work()` must only use `work` for `container_of`. [F148]

## Synchronization

- In `z_erofs_register_pcluster()`, a new `struct z_erofs_pcluster` must have `pcl->lockref` initialized to 1, `pcl->next` set to `fe->head`, and `pcl->lock` acquired via `mutex_trylock()` before `__xa_cmpxchg()` publishes `pcl` into `sbi->managed_pslots`. [F18]
- In `z_erofs_pcluster_begin()`, an existing pcluster may only be linked to `fe->head` if `cmpxchg(&fe->pcl->next, NULL, fe->head)` succeeds while holding `fe->pcl->lock`; if `pcl->next` is non-NULL, `fe->mode` must be set to `Z_EROFS_PCLUSTER_INFLIGHT` without modifying `pcl->next`. [F36]
- `pcl->length`, `pcl->vcnt`, `pcl->bvset`, `pcl->partial`, and `pcl->besteffort` are protected by `pcl->lock`; in `z_erofs_decompress_pcluster()`, resetting them and clearing `pcl->next` via `WRITE_ONCE()` must occur before `mutex_unlock(&pcl->lock)`. Concurrent accesses to `pcl->compressed_bvecs[]` across `z_erofs_bind_cache()`, `z_erofs_attach_page()`, `z_erofs_fill_bio_vec()`, and `z_erofs_cache_release_folio()` must hold `pcl->lockref.lock`. [F25, F26]
- In `z_erofs_scan_folio()` and `erofs_fileio_scan_folio()`, `erofs_onlinefolio_init()` must precede sub-requests, `erofs_onlinefolio_split(folio)` must be called only after `bio_add_folio()` or `z_erofs_attach_page()` succeeds, and `erofs_onlinefolio_end()` must run after the loop. In `erofs_fileio_scan_folio()`, `attached` must be reset to `0` whenever `io->rq` is newly allocated (including at `io_retry:`) or across an unmapped segment. [F2, F38, F115]
- In `z_erofs_submit_queue()`, `pending_bios` starts at 0, `z_erofs_endio()` calls `z_erofs_decompress_kickoff(q, -1)`, and `z_erofs_submit_queue()` calls `z_erofs_decompress_kickoff(q[JQ_SUBMIT], nr_bios)` after submitting all BIOs. In `z_erofs_decompress_kickoff()`, reading `z_erofs_pcpu_workers` and calling `kthread_queue_work()` must stay inside `rcu_read_lock()`, paired with `erofs_cpu_offline()` clearing the slot and calling `synchronize_rcu()` before `kthread_destroy_worker()`. [F39, F162]
- In `erofs_shrink_scan()`, iterating `erofs_sb_list` under `erofs_sb_list_lock` must acquire `sbi->umount_mutex` via `mutex_trylock()` and drop `erofs_sb_list_lock` before calling `z_erofs_shrink_scan()`, advance `p = p->next` only after re-acquiring `erofs_sb_list_lock` and before `list_move_tail(&sbi->list, &erofs_sb_list)`, and skip `0` when incrementing `shrinker_run_no`. [F29, F109, F138]
- In `z_erofs_fill_inode()` and `erofs_init_inode_xattrs()`, lazy initialization under `EROFS_I_BL_Z_BIT` or `EROFS_I_BL_XATTR_BIT` must execute `smp_mb()` before setting `EROFS_I_Z_INITED_BIT` or `EROFS_I_EA_INITED_BIT`, paired with `smp_mb()` after `test_bit()` on the fast path. [F19]
- In `z_erofs_gbuf_growsize()`, `z_erofs_load_lzma_config()`, and `z_erofs_load_zstd_config()`, global sizes (`z_erofs_gbuf_nrpages`, `z_erofs_lzma_max_dictsize`, `z_erofs_zstd_max_dictsize`) must never be shrunk, and isolating all streams from `z_erofs_lzma_head` or `z_erofs_zstd_head` to resize workspaces must be serialized by `lzma_resize_mutex` or `zstd_resize_mutex`. [F31, F74]
- `z_erofs_crypto_decompress()` must hold `z_erofs_crypto_rwsem` for reading across `z_erofs_crypto_get_engine()` and `__z_erofs_crypto_decompress()`, while `z_erofs_crypto_enable_engine()` and `z_erofs_crypto_disable_all_engines()` must hold it for writing when modifying `e->tfm`. [F32]

## Object Lifetimes

- In `z_erofs_decompress_pcluster()`, a pcluster with `pcl->from_meta == true` is not in `sbi->managed_pslots` and must release `pcl->compressed_bvecs[0].page` with `folio_put()` and free `pcl` with `z_erofs_free_pcluster()` instead of `z_erofs_put_pcluster()`. For non-meta pclusters, cleanup must read `page = be->compressed_pages[i]` (to recycle bounce pages from `z_erofs_stream_switch_bufs()`) while clearing `pcl->compressed_bvecs[i].page = NULL`. [F50, F119]
- `__erofs_try_to_release_pcluster()` must detach cached folios via `erofs_try_to_free_all_cached_folios()`, erase `pcl` from `sbi->managed_pslots`, and call `lockref_mark_dead(&pcl->lockref)` under `pcl->lockref.lock` before `call_rcu(&pcl->rcu, z_erofs_rcu_callback)`. [F168]
- In `erofs_fc_fill_super()`, `erofs_shrinker_register()`, `erofs_xattr_prefixes_init()`, and `erofs_register_sysfs()` must run after `sb->s_root` is set. In `erofs_put_super()`, `erofs_unregister_sysfs()` and `erofs_shrinker_unregister()` (looping `z_erofs_shrink_scan(sbi, ~0UL)` under `sbi->umount_mutex` until `xa_empty(&sbi->managed_pslots)`) must complete before `erofs_drop_internal_inodes()` evicts `sbi->managed_cache`, where `z_erofs_cache_invalidate_folio()` loops on `z_erofs_cache_release_folio()` until `pcl->lockref.count <= 0`. [F11, F20, F21]
- Because both `erofs_put_super()` and `erofs_kill_sb()` invoke `erofs_drop_internal_inodes()`, `erofs_free_dev_context(sbi->devs)`, and `erofs_fscache_unregister_fs()`, `packed_inode`, `metabox_inode`, `managed_cache`, `sbi->devs`, `dif0.fscache`, `volume`, and `domain` must never hold `IS_ERR` pointers and must be cleared to NULL when freed. [F10]
- In `erofs_register_sysfs()` (on `kobject_init_and_add()` failure) and `erofs_unregister_sysfs()`, `kobject_put(&sbi->s_kobj)` must be followed by `wait_for_completion(&sbi->s_kobj_unregister)` before `sbi` is freed. In `erofs_module_exit()`, `rcu_barrier()` must precede `z_erofs_exit_subsystem()` and `kmem_cache_destroy(erofs_inode_cachep)`. [F16, F22]
- In `erofs_find_target_block()`, each iteration reads into `buf` while keeping the best match in `*target`; `diff < 0` or `!ndirents` must release `&buf`, whereas updating `candidate` or exiting via `out:` when `!IS_ERR(candidate)` must release `target`. [F122]

## API Contracts

- Callers of `erofs_onlinefolio_end()` that write to folios via CPU mappings (`z_erofs_decompress_pcluster()`, `z_erofs_fill_other_copies()`) must pass `dirty = true` so `flush_dcache_folio()` runs before `folio_end_read()`. [F159]
- `erofs_fileio_bio_alloc()` and `erofs_fscache_bio_alloc()` must initialize their embedded `struct bio` with `bdev = NULL` because `z_erofs_endio()` calls `bio_put(bio)` when `bio->bi_bdev` is non-NULL. [F77]
- Because `z_erofs_map_blocks_fo()` only unmaps `map->buf` so `z_erofs_map_blocks_iter()` can reuse `map->buf.page`, every caller of `z_erofs_map_blocks_iter()` must initialize `map->buf` before the first call and call `erofs_put_metabuf(&map->buf)` when done. [F62]
- `erofs_alloc_inode()` zeroes `struct erofs_inode` only up to `offsetof(struct erofs_inode, vfs_inode)`; any new field in `struct erofs_inode` must be placed before `vfs_inode`. [F59]
- `__z_erofs_deflate_decompress()` and `z_erofs_zstd_decompress()` must set `rq->fillgaps = true` before calling `z_erofs_stream_switch_bufs()` so bounce pages are allocated for NULL `rq->out[]` slots. [F51]
- `erofs_read_metadata()` interprets an on-disk `u16` length of `0` as `U16_MAX + 1` (65536), so `len` and `*lengthp` must be `int` (not `u16`), and callers must validate `*lengthp` against expected struct sizes before dereferencing the returned buffer. [F100, F132]
- In `erofs_dirnamecmp()`, `qn->name` must be NUL-terminated, whereas on-disk dirent names (`qd->name`, `de_name` in `erofs_fill_dentries()`) lack a NUL terminator and must be bounded by `qd->end` or `maxsize - nameoff`. [F153]
- In `z_erofs_shrink_scan()` and `erofs_shrink_scan()`, `nr` and `freed` must be `unsigned long` because callers pass `~0UL`. `erofs_get_acl()` must return `ERR_PTR(-ECHILD)` when `rcu` is true. [F128, F172]

## Error Handling

- When `erofs_fileio_ki_complete()`, `erofs_fscache_bio_endio()`, or `erofs_fscache_submit_bio()` encounters a negative error before calling `bio->bi_end_io`, it must set `bio->bi_status = errno_to_blk_status(ret)`. [F41]
- When `z_erofs_fill_bio_vec()` stores `ERR_PTR(-ENOMEM)` in `pcl->compressed_bvecs[nr].page`, `z_erofs_parse_in_bvecs()` must extract `PTR_ERR(page)` and reset `bvec->page = NULL` during `z_erofs_decompress_pcluster()` before unlocking `pcl->lock`. [F49]
- In `z_erofs_scan_folio()` and `erofs_fileio_scan_folio()`, local `err` must be initialized to `0` because `!EROFS_MAP_MAPPED` branches do not assign `err`. [F45]
- In `erofs_init_inode_xattrs()`, if reading `vi->xattr_shared_xattrs` fails after `kmalloc_array()`, `vi->xattr_shared_xattrs` must be freed and reset to `NULL` before unlocking `EROFS_I_BL_XATTR_BIT`. [F53]
- `erofs_init_inode_xattrs()`, `erofs_xattr_iter_inline()`, and `erofs_xattr_iter_shared()` return `-ENODATA` when no xattr matches; `erofs_listxattr()` must convert `-ENODATA` to `0`, and `erofs_get_acl()` to `NULL`. `erofs_getxattr_foreach()` returns `-ENODATA` to continue and `0` on match, whereas `erofs_listxattr_foreach()` must return `0` on skipped entries to continue. [F56, F107]
- `erofs_fill_dentries()` returns `1` when `dir_emit()` stops early, `0` when the block ends, and negative errno on error, so `erofs_readdir()` must break on non-zero `err` and return `err < 0 ? err : 0`. [F57]

## External Contracts

- On-disk fixed-width `erofs_super_block.volume_name` (16B) and `erofs_deviceslot.tag` (64B) may lack a NUL terminator and must be copied with `kstrndup()` or `kmemdup_nul()`, never `strscpy()` or `kstrdup()`. `erofs_export_ops` must encode/decode the full 64-bit `EROFS_I(inode)->nid` via `FILEID_INO64_GEN*`. [F85, F124]

## Known Pitfalls

- In `z_erofs_bvset_flip()`, `iter->bvset->nextpage` must be read before calling `z_erofs_bvec_iter_end(iter)` because `z_erofs_bvec_iter_end()` unmaps `iter->bvset` via `kunmap_local()`. [F65]
- In `erofs_attr_show()` and `erofs_attr_store()`, `sbi` and `ptr` (`__struct_ptr`) must only be dereferenced for `erofs_sb_attrs`, because `erofs_attr_ops` is shared by global `erofs_root.kobj` and `erofs_feat`. [F149]
- In `z_erofs_load_compact_lcluster()`, pack index `i` must be a signed `int` because backward traversal (`i -= lo`) can go negative; for the last lcluster in a pack (`i + 1 == vcnt`) of type `Z_EROFS_LCLUSTER_TYPE_NONHEAD` without `Z_EROFS_LI_D0_CBLKCNT`, `lo` stores `delta[1]`, so `m->delta[0]` must be derived by decoding `i - 1` and adding 1. [F92, F131]
- In `z_erofs_map_blocks_ext()`, fixed-lcluster indexing must keep `lstart` in bytes (`round_down(map->m_la, 1 << vi->z_lclusterbits)`) while advancing `pos` by `(lstart >> vi->z_lclusterbits) * recsz`, and only OR `map->m_pa << 32` into `vi->z_fragmentoff` when `recsz > offsetof(struct z_erofs_extent, pstart_lo)`. [F83]
- High parts of split 48/64-bit on-disk fields (`blocks_hi`, `startblk_hi`, `h_extents_hi`, `pstart_hi`, `lstart_hi`) must be cast to `u64` before `<< 32`. When testing 32/48-bit block addresses in `erofs_blk_t` against `EROFS_NULL_ADDR` (`-1`), `(blk ^ EROFS_NULL_ADDR)` must be masked with `addrmask`. [F123, F129]
- In `z_erofs_scan_folio()`, `erofs_fileio_scan_folio()`, and `z_erofs_iomap_begin_report()`, differences between 64-bit file offsets (`offset`, `pos`, `map->m_la`) and `map->m_llen` must be computed in 64-bit types or guarded by `offset > map->m_la` before narrowing to `unsigned int`. [F127]
