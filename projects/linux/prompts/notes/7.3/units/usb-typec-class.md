# USB TYPEC CLASS

This unit implements USB Type-C and Power Delivery (PD) controller drivers across three sub-areas: TCPM/TCPCI hardware drivers (FUSB302, Maxim TCPCI with contaminant detection, MT6360/MT6370, RT1711H, Intel WhiskeyCove), the TI TPS6598x / Apple CD321x / TI TPS25750 standalone PD controller driver (`tipd`), and the UCSI core framework with its transport backends (ACPI, Cypress CCGx, Qualcomm PMIC GLINK, STM32G0, Lenovo Yoga C630).

## Architecture & Data Flow

- UCSI connector numbers (`con->num`, `UCSI_CCI_CONNECTOR`) are 1-based while `ucsi->connector` and `port_orientation` are 0-based: subtract 1 and validate `1 <= num <= max_ports` (rejecting `0` and `num > max_ports`, not `num >= max_ports`). `ucsi_init()` must allocate `ucsi->cap.num_connectors + 1` elements so the trailing zeroed entry (`con->port == NULL`) terminates `for (con = ...; con->port; con++)` loops. [F81, F97]
- Because `ucsi_register()` schedules `ucsi_init_work()` asynchronously and `ucsi->connector` is only assigned after port registration in `ucsi_init()`, `ucsi_resume()`, `ucsi_unregister()`, and `yoga_c630_ucsi_read_port0_status()` must verify `ucsi->connector != NULL` before dereferencing it. `con->plug` is only allocated when `UCSI_CAP_ALT_MODE_DETAILS` is set, so `ucsi_check_cable()` and `ucsi_unregister_plug()` must check `con->plug` before using it. [F37, F38]
- Power role or connection changes in `ucsi_handle_connector_change()` or `ucsi_register_port()` must call `ucsi_port_psy_changed(con)` alongside `typec_set_pwr_role()`. `ucsi_pwr_opmode_change()` must set `con->rdo = UCSI_CONSTAT(con, RDO)` in `UCSI_CONSTAT_PWR_OPMODE_PD` and `con->rdo = 0` otherwise, while `ucsi_get_src_pdos()` must update `con->num_pdos` and call `ucsi_port_psy_changed(con)`. [F55, F56]
- In `ucsi_register_port()`, test dual-role capabilities (`OPMODE_DRP`, and `PROVIDER && CONSUMER`) before single-role flags. In `ucsi_partner_change()` and `ucsi_register_port()`, force `u_role = USB_ROLE_NONE` when `!UCSI_CONSTAT(con, PARTNER_FLAG_USB)` (and for `UCSI_CONSTAT_PARTNER_TYPE_CABLE` without UFP) before `usb_role_switch_set_role()`. In `pmic_glink_ucsi_connector_status()`, check `UCSI_CONSTAT(con, CONNECTED)` first so unplugged ports get `TYPEC_ORIENTATION_NONE`. [F60, F94, F96]
- Whenever the UCSI PPM is reset after initialization (`ucsi_role_cmd()`) or resumes (`ucsi_resume_work()`), re-send `UCSI_SET_NOTIFICATION_ENABLE | ucsi->ntfy`. [F58]
- In `ucsi_ccg_update_set_new_cam_cmd()`, bounds-check `UCSI_SET_NEW_CAM_GET_AM(*cmd)` against `ARRAY_SIZE(uc->updated)`. When `new_port->linked_idx == UCSI_MULTI_DP_INDEX`, entering a mode (`UCSI_SET_NEW_CAM_ENTER(*cmd)`) must select the matching `uc->orig` index and save `new_port->active_idx`, whereas exiting must reuse `new_port->active_idx`. [F82, F98]
- In `ucsi_stm32g0.c`, `ucsi_stm32g0_register()` is skipped when `g0->in_bootloader` is true and `g0->i2c_bl` is only created when `g0->fw_name` is non-NULL; teardown/PM paths must check `!g0->in_bootloader` before `ucsi_stm32g0_unregister()` or `client->irq` operations, and check `g0->fw_name` before unregistering `g0->i2c_bl`. `ucsi_stm32g0_bl_write()`/`read()` require `1 <= len <= STM32G0_I2C_BL_SZ` (256). [F46, F87]
- In `tipd/core.c`, invoke chip-specific operations (`init`, `register_port`, `unregister_port`, `read_data_status`, `reset`, `connect`, `irq_handler`) through `tps->data`; downcasting `struct tps6598x *` to `struct cd321x *` via `container_of()` is only valid when `tps->data` is `cd321x_data`. In `cd321x_interrupt()` and `tps6598x_interrupt()`, write `TPS_REG_INT_CLEAR1`/`2` before reading status registers, and in `cd321x_queue_status()` OR-accumulate `status_changed |= ...` before updating `status`. [F71, F73, F120, F134]
- In `fusb302.c`, `tcpm_set_pd_rx()` must check `chip->pd_rx_on == on` under `chip->lock` to avoid redundant FIFO flushes. Update `chip->intr_togdone`, `intr_bc_lvl`, and `intr_comp_chng` under `chip->lock` in lockstep with `FUSB_REG_MASK`/`MASKA`, and snapshot them in `fusb302_irq_work()` before `fusb302_handle_togdone()`. Preserve VCONN bits in `FUSB_REG_SWITCHES0` when `chip->vconn_on` is true in `fusb302_set_cc_polarity_and_pull()`, and validate `len <= PD_MAX_PAYLOAD * 4` in `fusb302_pd_read_message()`. [F66, F67, F69, F75]
- In `max_contaminant_read_comparators()`, reset `CCLPMODESEL` in `TCPC_VENDOR_CC_CTRL2` to `LOW_POWER_MODE_DISABLE` when enabling `UA_80_SRC` and `CCCOMPEN`. In `max_contaminant_is_contaminant()`, if toggling is off and `chip->contaminant_state != DETECTED` on an open port, call `max_contaminant_enable_toggling(chip)`. In `rt1711h_probe()`, clear `TCPC_ALERT_MASK` to `0` before `tcpci_register_port()` and `devm_request_threaded_irq()`, then write `alert_mask` after IRQ registration. [F64, F65, F129]

## Synchronization

- UCSI commands sent under `con->lock` acquire `ucsi->ppm_lock`, establishing the lock order `con->lock` -> `ucsi->ppm_lock` -> backend lock (`ucsi_ccg->lock`, `pmic_glink_ucsi->lock`); never acquire `con->lock` while holding `ucsi->ppm_lock` or a backend lock. [F19]
- `ucsi_con_mutex_lock()` keeps `con->lock` held only when it returns `true` (releasing it if disconnected or `!con->partner`); call `ucsi_con_mutex_unlock()` if and only if it returned `true`. `ucsi_displayport_ops` callbacks must use `ucsi_con_mutex_lock(dp->con)` rather than `mutex_lock()`, and `ucsi_displayport_work()` must not hold `dp->con->lock` across `typec_altmode_vdm()`. [F2, F23]
- In `ucsi_dr_swap()` and `ucsi_pr_swap()`, run `reinit_completion(&con->complete)` and `ucsi_role_cmd()` under `con->lock`, and unlock `con->lock` before `wait_for_completion_timeout()`. In `ucsi_init()`, assign `ucsi->connector` and finish `ucsi_register_port()` before setting `UCSI_ENABLE_NTFY_CONNECTOR_CHANGE` in `ucsi->ntfy`. [F24, F25]
- In `ucsi_glink.c`, `pmic_glink_ucsi_probe()` must initialize `ucsi->ucsi`, work, completions, locks, and `ucsi->client` before `pmic_glink_client_register()`, and register `pmic_glink_ucsi_destroy()` before `devm_pmic_glink_client_alloc()`. `pmic_glink_ucsi_pdr_notify()` runs in atomic context and must update `ucsi->pd_running` under `ucsi->state_lock` and schedule `ucsi->register_work`. `pmic_glink_ucsi_callback()` must defer `UC_UCSI_USBC_NOTIFY_IND` to `ucsi->notify_work` rather than calling sleeping `pmic_glink_ucsi_read()`. [F26, F146, F147]
- In `ucsi_ccg.c`, protect `uc->op_data` with `uc->op_lock`: zero `uc->op_data.cci` under `uc->op_lock` before writing `UCSI_CONTROL` in `ucsi_ccg_async_control()`, and call `ccg_op_region_update()` before clearing `CCGX_RAB_INTR_REG` and calling `ucsi_notify_common()` in `ccg_irq_handler()`. Hold `uc->lock` around `ccg_send_command()` and `RESET_PENDING`, and call `ucsi_unregister()` and `free_irq()` before `ccg_fw_update()`. [F27, F28]
- In `tipd/core.c`, `tps->data->irq_handler` must run in process context holding `tps->lock`, and `cd321x->update_status` must be accessed under `tps->lock`. `tps6598x_remove()` must stop the IRQ or `tps->wq_poll` and cancel `cd321x->update_work` via `cd321x_remove()` before `tps6598x_disconnect()` and `unregister_port()`. [F30, F157]
- In `fusb302.c`, `chip->logbuffer_lock` nests inside `chip->lock`; never take `chip->lock` under `chip->logbuffer_lock`. In `fusb302_pm_suspend()`, set `chip->irq_suspended = true` under `chip->irq_lock` before `flush_work(&chip->irq_work)`, and in `fusb302_pm_resume()` check `chip->irq_while_suspended` and clear `chip->irq_suspended` under `chip->irq_lock`. In `tcpci_maxim_core.c`, hard-IRQ `max_tcpci_isr()` must only call `pm_wakeup_event()`, check `chip->port`, and return `IRQ_WAKE_THREAD`. [F31, F155, F156]

## Object Lifetimes

- `ucsi_unregister()` must cancel `ucsi->work` and `ucsi->resume_work`, disable notifications, and per connector cancel `con->work` and reschedule all `con->partner_tasks` with delay `0` under `con->lock` before `destroy_workqueue(con->wq)`. UCSI backends must unregister IRQs/notifiers and call `ucsi_unregister()` before `ucsi_destroy()`. [F4, F141]
- `ucsi_unregister_partner()` must unregister child objects before `typec_unregister_partner(con->partner)`: `ucsi_unregister_partner_pdos()` (which unregisters and NULLs `partner_sink_caps`, `partner_source_caps`, and `partner_pd`), partner altmodes, and `ucsi_unregister_cable()` (which unregisters plug and plug altmodes first), NULLing all pointers. In `ucsi_unregister_altmodes()`, call `ucsi_displayport_remove_partner()` on `typec_altmode_get_partner(adev[i])` before `typec_unregister_altmode(adev[i])` for partner DP/NVIDIA altmodes. [F6, F7, F8]
- `ucsi_register_port()` must release `cap->fwnode` from `ucsi_find_fwnode()` with `fwnode_handle_put()`. In `tps6598x_probe()`, call `fw_devlink_purge_absent_suppliers(fwnode)` on `"connector"` before `fwnode_usb_role_switch_get(fwnode)`, release `fwnode` with `fwnode_handle_put()` on all paths, and release `tps->role_sw` with `usb_role_switch_put()` on error/remove. [F1, F12, F136]
- `cd321x_unregister_port()` and `cd321x_register_port()` error paths must call `typec_mux_put(cd321x->mux)`, unregister and NULL `port_altmode_dp`/`tbt`, and unregister `tps->port` in reverse order. Call `tps->data->reset(tps)` on `tps6598x_probe()` failure and in `tps6598x_remove()`, and re-run `tps->data->init(tps)` in `tps6598x_resume()` if `tps6598x_check_mode(tps) == TPS_MODE_PTCH`. [F11, F137]
- `tps_request_firmware()` frees `*fw` and returns `-EINVAL` if `(*fw)->size == 0`; when it returns `0`, callers own `*fw` and must not dereference `fw` (e.g., `fw->size`) after `release_firmware(fw)`. [F9, F78]
- In `fusb302_remove()`, `free_irq()` must precede `cancel_work_sync(&chip->irq_work)` and `cancel_delayed_work_sync(&chip->bc_lvl_handler)`, which must precede `tcpm_unregister_port()`, `destroy_workqueue(chip->wq)`, and `fwnode_handle_put(chip->tcpc_dev.fwnode)`. In `wcove.c`, pair `fwnode_create_software_node()` with `fwnode_remove_software_node()` on error/remove. [F14, F29, F133]

## API Contracts

- `ucsi_run_command()`, `ucsi_send_command_common()`, and `ucsi_send_command()` return the non-negative CCI byte length or a negative errno (use signed `int` and check `< 0`). Their `size` parameter is in bytes, so `UCSI_GET_*_SIZE` bit-count macros must be wrapped in `BITS_TO_BYTES()`. [F32, F35]
- `struct ucsi_operations` passed to `ucsi_create()` must define `read_version`, `read_cci`, `poll_cci`, `read_message_in`, `sync_control`, and `async_control`. Polling CCI while notifications are disabled (`ucsi_reset_ppm()`) must call `ops->poll_cci()`, not `read_cci()`. `ops->connector_status` is called with `con->lock` held and must not re-lock it. [F158, F159, F160]
- Check `ucsi->version` before reading versioned `UCSI_CONCAP()` or `UCSI_CONSTAT()` fields (`UCSI_DECLARE_BITFIELD_V1_1`..`V3_0`) to avoid `WARN()` in `ucsi_bitfield_read()`. Convert 0-based PD major revision fields (`PARTNER_PD_REVISION_V2_1`, `UCSI_CABLE_PROP_FLAG_PD_MAJOR_REV`) via `UCSI_SPEC_REVISION_TO_BCD()`. [F114, F139]
- `ucsi_get_pd_caps()` returns `NULL` (`ERR_PTR(0)`) for 0 PDOs and an `IS_ERR()` pointer on negative error, and must set `pd_caps.pdo[ret] = 0` when `ret < PDO_MAX_OBJECTS`. `ucsi_read_pdos()` must pass `num_pdos - 1` to `UCSI_GET_PDOS_NUM_PDOS` and `num_pdos * sizeof(u32)` as the byte size. `ucsi_get_partner_identity()` and `ucsi_get_cable_identity()` must read `sizeof(u32[7])` and copy from `&vdo[1]` to skip the VDM header. [F41, F42, F125]
- When `!dp->override`, `ucsi_displayport_enter()` and `ucsi_displayport_vdm()` must allow operations while `!dp->initialized` and return `-EOPNOTSUPP` once `dp->initialized` is true (and always in `ucsi_displayport_exit()`). [F170]
- `ccg_send_command()` returns a negative errno or positive `uc->cmd_resp`, so check `ret != CMD_SUCCESS` (or `RESET_COMPLETE`) rather than `ret < 0`. In `tipd/core.c`, `tps6598x_read_status()`, `tps6598x_read_power_status()`, and `read_data_status()` return `bool` (check `!func(...)`), whereas `tps6598x_check_mode()` returns a mode enum `>= 0` or negative errno (check `ret < 0`). In `tcpci_maxim_core.c`, `tcpci_init()` must return `-1` and `max_tcpci_irq()` must loop `while (status)`. [F45, F48, F49, F130]

## Error Handling

- `ucsi_register_port_psy()` stores `power_supply_register()`'s `ERR_PTR` in `con->psy` on failure, so `ucsi_unregister_port_psy()` and `ucsi_port_psy_changed()` must check `IS_ERR_OR_NULL(con->psy)`. [F39]
- In `ucsi_ccg.c`, `ucsi_ccg_probe()` must call `device_disable_async_suspend(uc->dev)` and only log `!uc->fw_build` inside `if (!status)` when `"firmware-name"` is present; `ucsi_ccg_sync_control()`, `ccg_read()`, and `ccg_write()` must balance `pm_runtime_get_sync()` with `pm_runtime_put_sync()` on every exit path. [F142, F176]
- In `tps6598x_apply_patch()`, if `tps6598x_exec_cmd()` returns `0` but `out[...]` indicates failure, set `ret = -EBUSY` before `goto release_fw`. `tps25750_write_firmware()` must restore `client->addr` and `client->adapter->timeout` after `regmap_raw_write()`, and `tps25750_apply_patch()` must call `tps25750_abort_patch_process()` if `tps25750_start_patch_burst_mode()` fails. In `max_contaminant_read_resistance_kohm()`, `if (mv < 0)` must return `mv`, not `ret`. [F52, F53, F138]

## External Contracts

- In `ucsi_reset_connector()`, bit 23 of `UCSI_CONNECTOR_RESET` depends on `ucsi->version`: `< v1.1` sets `UCSI_CONNECTOR_RESET_HARD_VER_1_0` for Hard Reset, `v1.1..v1.2` omits bit 23, and `v2.0+` uses bit 23 = 0 for Hard Reset and bit 23 = 1 (`UCSI_CONNECTOR_RESET_DATA_VER_2_0`) for Data Reset. [F88]
- In `ucsi/psy.c`, multiply PDO/RDO/`UCSI_TYPEC_*` mV and mA values by 1000 for `power_supply_propval.intval` (uV/uA), and only read `UCSI_CONSTAT(con, BC_STATUS)` in `ucsi_psy_get_charge_type()` when connected as `TYPEC_SINK`. In `ucsi_cmd()` (`debugfs.c`), filter commands through `switch (UCSI_COMMAND(val))` and bound reads to `sizeof(ucsi->debugfs->response)`. [F113, F165, F175]

## Known Pitfalls

- In `ucsi_register_altmodes()`, do not increment `i` on `len == -EBUSY`, stop on `len <= 0`, and advance `i` by `num = len / sizeof(alt[0])`. In `ucsi_register_altmodes_nvidia()`, `break` (do not `return 0`) on `!len` or `!alt.svid` in the collection loop. In `ucsi_reset_ppm()`, clear pre-existing `UCSI_CCI_RESET_COMPLETE` via `UCSI_SET_NOTIFICATION_ENABLE` + `poll_cci()` first, and re-send `UCSI_PPM_RESET` if `cci & ~UCSI_CCI_RESET_COMPLETE` is non-zero. [F92, F93, F95]
- Cast operands to `u64` before shifting in 64-bit UCSI command macros, and use `BIT_ULL()` for `UCSI_ENABLE_NTFY_*` and 64-bit `TPS_REG_INT_*` masks. Use `time_before()` / `time_is_before_jiffies()` / `time_is_after_jiffies()` in jiffies poll loops, and `do_div()` on `u64` timestamps in `_fusb302_log()`. [F106, F107, F108, F111, F115]
- In `ucsi_ccg.c`, verify `fw->size >= sizeof(fw_cfg) + FW_CFG_TABLE_SIG_SIZE`, subtract the `FWCT` trailer from `eof` before `.cyacd` line parsing in `do_flash()`, and validate `line_sz == CYACD_LINE_SIZE` and `len == CCG4_ROW_SIZE`. In `tipd/core.c`, keep `char mode[5] = { }` NUL-terminated in `tps6598x_check_mode()`, use `TPS_65987_8_INTEVENT_LEN` (11) on TPS65987/8 in `tps6598x_interrupt()`, and prefix block I/O with 1 length byte when `tps->i2c_protocol` is set. [F86, F99, F123, F135]
- In `tcpci_maxim_core.c`: do not clear `TCPC_ALERT_RX_STATUS` (or `RX_BUF_OVF` when `RX_STATUS` is set) before `process_rx()`, and clear both when `RX_BUF_OVF` is set alone; read `count + 1` bytes (`<= TCPC_RECEIVE_BUFFER_LEN`) from `TCPC_RX_BYTE_CNT` and parse at `TCPC_RECEIVE_BUFFER_RX_BYTE_BUF_OFFSET` (2); in `process_tx()`, check `TX_SUCCESS` before `TX_FAILED` and separately check both bits set to call `max_tcpci_init_regs(chip)`. [F102, F103, F122]
- In `fusb302.c`: `fusb302_handle_togdone_src()` must measure the first CC pin before `fusb302_set_toggling(chip, TOGGLING_MODE_OFF)` and use the saved `toggling_mode` when restarting toggling; `fusb302_irq_work()` and `fusb302_pd_read_message()` must read the RX FIFO on both `TX_SUCCESS` and `GCRCSENT` and dispatch `tcpm_pd_transmit_complete()` vs `tcpm_pd_receive()` by checking `!len && pd_header_type_le(msg->header) == PD_CTRL_GOOD_CRC`. [F104, F105]
