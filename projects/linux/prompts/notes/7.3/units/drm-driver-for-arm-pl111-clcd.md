# DRM DRIVER FOR ARM PL111 CLCD

This component is the DRM/KMS display driver for the ARM PrimeCell PL110 and PL111 Color LCD Controllers (CLCD) and ST Microelectronics Nomadik LCDC variants attached to the AMBA bus. It exposes a single-pipe KMS display pipeline using `drm_simple_display_pipe`, registers an internal Common Clock Framework divider (`pl111_div`) for the pixel clock, manages GEM DMA framebuffers (including device-specific reserved memory), and provides platform-specific syscon and FPGA multiplexing logic for ARM Integrator, Versatile, RealView, Versatile Express, and ST-Ericsson Nomadik platforms.

## Architecture & Data Flow
- All accesses to the CLCD interrupt-enable and control registers must use the dynamic offsets `priv->ienb` and `priv->ctrl` rather than hardcoded `CLCD_PL110_*` or `CLCD_PL111_*` constants, because PL110/LCDC and PL111/Versatile swap offsets 0x18 and 0x1c. [F54]
- `pl111_drm_dev_private.regs` is a byte-addressed `void *` pointer; all MMIO offsets added to `priv->regs` (including `CLCD_*` macros, `priv->ienb`, `priv->ctrl`, and `pl111_reg_defs[].reg`) must be byte offsets, and `priv->regs` must not be changed to a word-typed pointer such as `u32 __iomem *`. [F49]
- `pl111_display_check()` must enforce that `mode->hdisplay` is a multiple of 16, the framebuffer DMA address (`drm_fb_dma_get_gem_addr`) is 4-byte aligned, `fb->pitches[0]` equals `mode->hdisplay * fb->format->cpp[0]`, and `cstate->mode_changed = true` when both `old_fb` and `fb` are non-NULL and `old_fb->format != fb->format` (since pixel format bits in `priv->ctrl` and `priv->variant_display_enable` are only programmed in `pl111_display_enable()`, not `pl111_display_update()`). [F25, F61]
- In `pl111_display_enable()`, the bridge timing check (`btimings->setup_time_ps >= 3000`) must run after the connector `DRM_BUS_FLAG_PIXDATA_DRIVE_NEGEDGE` check and toggle `TIM2_IPC` with XOR (`tim2 ^= TIM2_IPC`) rather than OR so that it inverts whichever clock edge polarity the connector selected. [F36]
- In `pl111_clk_div_set_rate()` and `pl111_clk_div_recalc_rate()`, a pixel clock divisor `div` of 1 is represented in `CLCD_TIM2` by setting `TIM2_BCD`, whereas any `div >= 2` is split across `TIM2_PCD_LO_MASK` (low 5 bits) and `TIM2_PCD_HI_MASK` (high 5 bits at `TIM2_PCD_HI_SHIFT`) as `div - 2` with `TIM2_BCD` cleared. [F33]
- In `pl111_clk_div_choose_div()`, `*prate` must not be modified inside the `for (div = 1; div < max_div; div++)` loop and must only be written with `best_prate` after the loop terminates, because each iteration with `set_parent == false` reads `*prate` as the input parent rate. [F42]
- `priv->connector` and `bridge->timings` can be NULL at runtime (when using a non-panel bridge or a bridge without timings), so `pl111_display_enable()` must null-check `priv->connector`, `priv->bridge`, and `bridge->timings` before dereferencing them. [F17]
- `priv->variant_display_enable` and `priv->variant_display_disable` are independently optional callbacks (e.g., `INTEGRATOR_CLCD_CM` sets `variant_display_enable` while leaving `variant_display_disable` NULL), so both must be null-checked before invocation. [F18]
- In every `struct pl111_variant_data` instance, `nformats` must be the element count (`ARRAY_SIZE`) of the `u32` array pointed to by `formats` rather than its byte size (`sizeof`), as `pl111_display_init()` passes both to `drm_simple_display_pipe_init()`. [F51]
- Every non-sentinel entry in `pl111_id_table` must store a non-NULL `const struct pl111_variant_data *` in `amba_id.data`, whereas every non-sentinel entry in `versatile_clcd_of_match` and `impd1_clcd_of_match` must store an `enum versatile_clcd` constant cast to `void *` in `of_device_id.data`. [F52]

## Synchronization
- Read-modify-write updates to `CLCD_TIM2` in `pl111_display_enable()` and `pl111_clk_div_set_rate()` must hold `priv->tim2_lock`, with `pl111_display_enable()` preserving `TIM2_BCD | TIM2_PCD_LO_MASK | TIM2_PCD_HI_MASK` (when `!broken_clockdivider`) and `pl111_clk_div_set_rate()` preserving all other `CLCD_TIM2` bits. [F66]
- `pl111_display_enable()` must call `clk_set_rate(priv->clk, ...)` and `clk_prepare_enable(priv->clk)` outside `priv->tim2_lock`, because `clk_set_rate()` sleeps on the clock framework prepare lock and invokes `pl111_clk_div_set_rate()`, which itself acquires `priv->tim2_lock`. [F67]
- In `pl111_init_clock_divider()`, `spin_lock_init(&priv->tim2_lock)` must be called before the early return for `priv->variant->broken_clockdivider` and before `devm_clk_hw_register()`, because `pl111_display_enable()` unconditionally acquires `priv->tim2_lock`. [F7]
- `pl111_display_enable_vblank()` and `pl111_display_disable_vblank()` must be non-sleeping atomic callbacks because DRM vblank core invokes them under spinlocks with interrupts disabled (including from `drm_crtc_vblank_get()` inside `spin_lock_irq(&crtc->dev->event_lock)` in `pl111_display_update()`). [F65]

## Object Lifetimes
- `pl111_display_disable()` must tear down hardware state in reverse order of `pl111_display_enable()`: calling `drm_crtc_vblank_off(crtc)` (when `!priv->variant->broken_vblank`) before powering down, clearing `CNTL_LCDPWR`, waiting 20ms, invoking `priv->variant_display_disable`, zeroing `priv->ctrl`, and calling `clk_disable_unprepare(priv->clk)`. Conversely, `pl111_display_enable()` must call `drm_crtc_vblank_on(crtc)` only after enabling `priv->clk` and setting `CNTL_LCDPWR` in `priv->ctrl`. [F3, F13]
- In `pl111_amba_remove()`, `drm_dev_unregister(drm)` and `drm_atomic_helper_shutdown(drm)` must be called before `drm_panel_bridge_remove(priv->bridge)`, `drm_dev_put(drm)`, and `of_reserved_mem_device_release(dev)` so that userspace access and active scanout are stopped before bridge and memory teardown. [F12]

## API Contracts
- `amba_set_drvdata()` stores `struct drm_device *` on the `amba_device` (with `struct pl111_drm_dev_private *` in `drm->dev_private`), whereas `devm_request_irq()` passes `struct pl111_drm_dev_private *` directly as the `void *data` argument to `pl111_irq()`. Broken by: casting `amba_get_drvdata(amba_dev)` directly to `struct pl111_drm_dev_private *` or passing `drm` to `devm_request_irq()`. [F50]
- Because `pl111_display_funcs` is a single file-scope mutable struct in `pl111_display.c`, `enable_vblank` and `disable_vblank` are only assigned when `!priv->variant->broken_vblank`, and `drm_vblank_init()`, `drm_crtc_vblank_on()`, and `drm_crtc_vblank_off()` must all be gated on `!priv->variant->broken_vblank`. [F76]
- In `pl111_display_update()`, when `crtc->state->event` is non-NULL, the driver must clear `crtc->state->event = NULL` and, under `spin_lock_irq(&crtc->dev->event_lock)`, call `drm_crtc_arm_vblank_event()` only if `crtc->state->active && drm_crtc_vblank_get(crtc) == 0`, falling back to `drm_crtc_send_vblank_event()` otherwise. [F75]
- When `priv->use_device_memory` is `true` (because `of_reserved_mem_device_init()` bound device-specific reserved memory in `pl111_amba_probe()`), `pl111_gem_import_sg_table()` must return `ERR_PTR(-EINVAL)` instead of importing external scatter-gather tables via `drm_gem_dma_prime_import_sg_table()`. [F69]
- `struct pl111_variant_data.fb_depth` specifies color depth in bits (such as 15 on `pl110_impd1`) for `drm_client_setup_with_color_mode()`, so converting `fb_depth` to bytes-per-pixel in `pl111_mode_valid()` must use `DIV_ROUND_UP(priv->variant->fb_depth, 8)` rather than truncating division. [F21]
- Because `drm_display_mode.clock` is in kHz while the Common Clock Framework and `priv->memory_bw` (`max-memory-bandwidth`) use Hz and bytes/s, `pl111_display_enable()` and `pl111_mode_valid()` must scale `mode->clock` by 1000 (`1000ULL` in `pl111_mode_valid()` to prevent 32-bit overflow before multiplying by resolution and `cpp`). [F74]

## Error Handling
- In `pl111_modeset_init()`, if `drm_panel_bridge_add_typed()` fails, `IS_ERR(bridge)` must jump to `finish` rather than `out_bridge` and before assigning `priv->bridge`, and `drm_panel_bridge_remove()` in `out_bridge` and `pl111_amba_remove()` must be guarded by `panel` / `priv->panel`. [F16]
- `pl111_versatile_init()` must return 0 when no node matches `versatile_clcd_of_match`, and `pl111_nomadik_init()` must silently return when `syscon_regmap_lookup_by_compatible()` returns `IS_ERR()`, because both run unconditionally from `pl111_amba_probe()` on all platforms. [F19]

## Known Pitfalls
- In `pl111_display_enable()`, because ARM PL110/PL111 reads the red channel from the least-significant bits while DRM fourcc codes list channels MSB-to-LSB, `CNTL_BGR` must be set for `DRM_FORMAT_*RGB*` and omitted for `DRM_FORMAT_*BGR*` when `priv->variant->st_bitmux_control` is false, and then cleared if `priv->variant->external_bgr` is true. [F34]
- In `pl111_clk_div_recalc_rate()`, the `CLCD_TIM2` register value `tim2` must be stored in an unsigned 32-bit type (`u32`) when extracting `TIM2_PCD_HI_MASK` (`GENMASK(31, 27)`) with `>> (TIM2_PCD_HI_SHIFT - TIM2_PCD_LO_BITS)` so that bit 31 is logically right-shifted without sign extension. [F48]
- 64-bit bandwidth and clock divider divisions in `pl111_mode_valid()`, `pl111_clk_div_choose_div()`, `pl111_clk_div_round_rate()`, and `pl111_clk_div_recalc_rate()` must use explicit 64-bit division helpers (`div_u64` or `DIV_ROUND_UP_ULL`) rather than `/` on `u64` or `unsigned long long` operands. [F46]
