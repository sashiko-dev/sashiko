# EXEC & BINFMT API, ELF

This unit implements process creation (`fork`/`clone`/`vfork`/`clone3`), `task_struct` and `mm_struct` lifecycle management, program execution (`execve`/`execveat`), the `linux_binfmt` dispatch framework, early stack VMA setup (`mm/vma_exec.c`), and built-in loaders and coredump handlers for ELF (standard, compat, FDPIC), FLAT, `#!` scripts, and `binfmt_misc`.

## Architecture & Data Flow
- In `load_elf_binary()` and `load_elf_interp()`, `total_mapping_size()` must only be passed to `elf_load()` for the first `PT_LOAD` segment of `ET_DYN` binaries (never `ET_EXEC`), and subsequent `PT_LOAD` iterations must pass `total_size = 0` with `MAP_FIXED`. For the first `ET_DYN` segment in `load_elf_binary()`, the `ELF_ET_DYN_BASE` `load_bias` branch must be selected by `if (interpreter)`, with the `alignment > ELF_MIN_ALIGN` probe mapping only in the `else` (`!interpreter`) branch. [F80, F101, F103]
- In `load_elf_binary()`, when loading a static PIE (`elf_ex->e_type == ET_DYN && !interpreter`) with `CONFIG_ARCH_HAS_ELF_RANDOMIZE` and `!CONFIG_COMPAT_BRK`, `elf_brk` must move to `ELF_ET_DYN_BASE` and set `brk_moved = true` even if `PF_RANDOMIZE` is unset; whenever `brk_moved` is set, `current->brk_randomized` must be set to `1`. [F68]
- In `create_elf_tables()` and `create_elf_fdpic_tables()`, `ARCH_DLINFO` must precede all other `NEW_AUX_ENT()` calls. Adding or conditioning a `NEW_AUX_ENT()` entry requires updating `AT_VECTOR_SIZE_BASE` (or `AT_VECTOR_SIZE_ARCH` for `ARCH_DLINFO`) to bound `mm->saved_auxv`, and in `create_elf_fdpic_tables()` updating `nitems` (or `DLINFO_ITEMS`) under the exact same condition. [F69, F122]
- While `bprm->mm` is populated prior to installation, `get_arg_page()` charges stack growth (`vma_pages(vma) - bprm->vma_pages`) to `current->mm`'s `MM_ANONPAGES` counter via `acct_arg_size()`; this must be reversed via `acct_arg_size(bprm, 0)` before `exec_mmap(bprm->mm)` in `begin_new_exec()` or `mmput(bprm->mm)` in `free_bprm()`. [F60]
- In `bprm_stack_limits()`, `bprm->argc` and `bprm->envc` must be validated non-negative, `ptr_size` computed using `max(bprm->argc, 1)` with overflow checks, and `bprm_set_stack_limit()` must verify `bprm->p >= limit` before subtracting `limit`. Before `copy_strings()` or `copy_string_kernel()` decrements `bprm->p` by `len`, `valid_arg_len(bprm, len)` must be checked first, followed by `bprm_hit_stack_limit(bprm)` after decrementing. [F85, F86]
- In `begin_new_exec()`, `unshare_files()` must precede `do_close_on_exec(me->files)` and `fd_install()` for `bprm->have_execfd`, and `unshare_sighand(me)` must precede `flush_signal_handlers(me, 0)`, isolating shared `CLONE_FILES` or `CLONE_SIGHAND` tables before mutation. [F74]
- Setting `bprm->execfd_creds` (`MISC_FMT_CREDENTIALS`) requires `bprm->have_execfd` (`MISC_FMT_OPEN_BINARY`) so `exec_binprm()` populates `bprm->executable` before `bprm_creds_from_file()` dereferences it. [F46]
- In `dup_task_struct()`, `tsk->seccomp.filter` must be cleared to `NULL` after `arch_dup_task_struct()` so early fork failure in `free_task()` does not see an unreferenced filter, and `copy_seccomp(p)` under `current->sighand->siglock` must later copy `current->seccomp` while synchronizing `no_new_privs` and `SECCOMP` syscall work. [F76]
- When `copy_process()` resets a cloned task's CPU timer state after `dup_task_struct()`, it must call `tick_dep_init_task(p)` and `clear_posix_cputimers_work(p)` alongside `posix_cputimers_init(&p->posix_cputimers)`. [F77]
- In `load_elf_binary()` and `load_elf_interp()`, `PT_LOAD` bounds must be validated by checking `BAD_ADDR(k)`, `p_filesz > p_memsz`, `p_memsz > TASK_SIZE`, and `TASK_SIZE - p_memsz < k` before computing `p_vaddr + p_filesz` or `p_vaddr + p_memsz`. In `maximum_alignment()`, each `PT_LOAD` segment's `p_align` must be validated with `is_power_of_2(p_align)` and rounded up via `ELF_PAGEALIGN(alignment)` before `load_bias &= ~(alignment - 1)`. [F118, F120]
- In `fill_thread_core_info()`, `do_thread_regset_writeback(t->task, regset)` must be called on each `view_iter` before skipping regsets with `!note_type`, and `t->notes` must be indexed by `note_iter` (incremented only when a note is filled) rather than `view_iter`. [F110]
- In `fs/binfmt_flat.c`, when `DATA_START_OFFSET_WORDS` is non-zero, `load_flat_file()` must reserve `DATA_START_OFFSET_WORDS` words before `datapos` (`start_data`) for negative-offset library pointers written by `load_flat_binary()`; when `DATA_START_OFFSET_WORDS` is `0`, `MAX_SHARED_LIBS_UPDATE` must remain `0`. All header-derived sizes (`(text_len | data_len | bss_len | stack_len | relocs | full_data) >> 28`) must be checked before computing `extra` and `len`. [F70, F92, F119]

## Synchronization
- `tasklist_lock` is an outer IRQ-disabling rwlock (`write_lock_irq(&tasklist_lock)`) that nests outside `sighand->siglock` (`unshare_sighand()`, `copy_process()`) and inside `cgroup_threadgroup_change_begin()` (`de_thread()`). In `copy_process()`, error paths prior to acquiring `tasklist_lock`, calling `sched_core_fork(p)`, and acquiring `current->sighand->siglock` must jump to `bad_fork_cancel_cgroup` (or earlier) and never to `bad_fork_core_free`. [F10, F142]
- In `exec_mmap()`, `tsk->mm` and `tsk->active_mm` must be updated under `task_lock(tsk)` and `local_irq_disable()` while holding `exec_update_lock` for write and `mmap_read_lock_killable(old_mm)`. Functions taking a `spinlock_t` (such as `lru_gen_add_mm()`) must not be called inside this `local_irq_disable()` region because `spinlock_t` sleeps on `PREEMPT_RT`. [F27, F138]
- In `de_thread()`, setting `sig->notify_count = -1` while waiting for `leader->exit_state` requires `write_lock_irq(&tasklist_lock)`, and clearing `sig->group_exec_task` and `sig->notify_count` on the `killed:` path requires `read_lock(&tasklist_lock)`. [F28]
- `check_unsafe_exec()` sets `current->fs->in_exec = 1` under `read_seqlock_excl(&p->fs->seq)` (with `cred_guard_mutex` held) to block concurrent `copy_fs()` with `CLONE_FS`; `in_exec` must be cleared to `0` both after `de_thread()` succeeds in `begin_new_exec()` and in `free_bprm()` when `bprm->cred` is non-NULL. [F73]
- In `search_binary_handler()`, `try_module_get(fmt->module)` must succeed before `read_unlock(&binfmt_lock)` is called to invoke `fmt->load_binary(bprm)`, and `read_lock(&binfmt_lock)` must be re-acquired before calling `put_binfmt(fmt)` and advancing the `formats` list cursor. [F104]
- In `dup_mm()`, `uprobe_start_dup_mmap()` and `uprobe_end_dup_mmap()` must bracket both `dup_mmap(mm, oldmm)` and the error-path `mmput(mm)` when `dup_mmap()` fails. [F17]
- In `kernel_clone()`, when `CLONE_VFORK` is set, `p->vfork_done`, `init_completion(&vfork)`, and `get_task_struct(p)` must be initialized before `wake_up_new_task(p)`, and if `wait_for_vfork_done()` is killed, it must clear `child->vfork_done = NULL` under `task_lock(child)` before returning. [F22]
- In `bprm_fill_uid()`, when `S_ISUID` or `S_ISGID` is set, `inode_lock(inode)` must be held while reloading `inode->i_mode`, mapping `vfsuid`/`vfsgid`, and re-checking `inode_permission(idmap, inode, MAY_EXEC)`, skipping elevation if either ID is unmapped in `bprm->cred->user_ns`. [F169]
- In `__mmdrop()`, `cleanup_lazy_tlbs(mm)` must run before `mm_free_pgd(mm)` and `free_mm(mm)`. Under `CONFIG_VMAP_STACK`, `alloc_thread_stack_node()` must cache `tsk->stack_vm_area` at allocation time because `free_thread_stack()` can run in interrupt context where `find_vm_area()` is forbidden. [F140, F152]

## Object Lifetimes
- Callers of `open_exec()` and `do_open_execat()` must call `exe_file_allow_write_access()` before `fput()` (or use `do_close_execat()`) when releasing the returned `struct file`. [F1]
- In `create_init_stack_vma()`, if `insert_vm_struct(mm, vma)` fails after `ksm_execve(mm)`, it must call `ksm_exit(mm)` before unlocking `mm`, because `bprm_mm_init()` cleans up a failed `mm` via `mmdrop()` rather than `mmput()` (after resetting `bprm->mm = NULL` so `free_bprm()` does not double-drop it). [F6, F45]
- Per-task resources allocated during `dup_task_struct()` or `copy_process()` that are not unwound by `bad_fork_cleanup_*` labels (`bpf_task_storage_free()`, `free_kthread_struct()`, `scs_release()`, `release_user_cpus_ptr()`) must be freed in `free_task()` rather than `__put_task_struct()`. [F12]
- In `copy_process()`, the stack-allocated `struct multiprocess_signals delayed` node on `current->signal->multiprocess` must be unlinked via `hlist_del_init(&delayed.node)` under `current->sighand->siglock` on both the success and `fork_out` paths. [F133]
- `set_binfmt(new)` must only be called after `begin_new_exec()` has installed `bprm->mm` as `current->mm` and while the caller holds a live reference on `new->module`. [F164]
- Each `struct elf_thread_core_info` in `fill_note_info()` must be allocated with `struct_size(t, notes, info->thread_notes)`, with `t->notes[0].data` pointing to `&t->prstatus` and only `t->notes[1 .. info->thread_notes - 1].data` passed to `kvfree()` in `free_note_info()`. [F127]

## API Contracts
- On success, `pidfd_prepare()` returns a reserved fd and stores a new `struct file` in `*ret_file`; on failure, callers must release both via `fput(pidfile)` and `put_unused_fd(pidfd)`. In `copy_process()`, `pidfd_prepare()` and `put_user(pidfd, args->pidfd)` must run after `copy_files()` and before `p->start_time` is recorded, jumping to `bad_fork_free_pid` (not `bad_fork_put_pidfd`) if `pidfd_prepare()` fails, and deferring `fd_install()` until after `write_unlock_irq(&tasklist_lock)`. [F13, F52, F177]
- In `linux_binfmt::load_binary` handlers, all format checks that can return `-ENOEXEC` must run before `begin_new_exec()`, which sets `bprm->point_of_no_return = true` (stopping `search_binary_handler()` even on `-ENOEXEC`). After `begin_new_exec()`, loaders must call `SET_PERSONALITY2()` / `set_personality()` before `setup_new_exec()` and `setup_arg_pages()`, and `finalize_exec(bprm)` before `START_THREAD()` / `start_thread()`. [F105, F156, F158, F161]
- The `executable_stack` parameter of `setup_arg_pages()` takes the tri-state enum `EXSTACK_DEFAULT` (0), `EXSTACK_DISABLE_X` (1), or `EXSTACK_ENABLE_X` (2); passing boolean `1` selects `EXSTACK_DISABLE_X` instead of `EXSTACK_ENABLE_X`. [F40]
- Unlike `remove_arg_zero()`, `copy_string_kernel()` only decrements `bprm->p` and copies the string, so callers (`load_script()`, `load_misc_binary()`, `do_execveat_common()`) must increment `bprm->argc` for each added argument. Whenever an executable or interpreter is mapped, `would_dump(bprm, file)` must be called before `exec_mmap()`. [F64, F167]
- `mmput()` may sleep and runs `exit_mmap()`; callers in atomic context or holding a lock acquired by `__mmu_notifier_release()` callbacks must call `mmput_async()` instead. [F141]
- In `kernel/fork.c`, `copy_process()` and all helpers testing clone flags (`copy_sighand()`, `copy_mm()`, `copy_fs()`, `copy_files()`, `copy_signal()`, `copy_oom_score_adj()`) must accept `clone_flags` as `u64` rather than `unsigned long`. In `clone3_stack_valid()`, `access_ok(kargs->stack, kargs->stack_size)` must be checked before adding `kargs->stack_size` to `kargs->stack`. [F54, F112]
- `copy_strings()` and `copy_string_kernel()` must call `flush_arg_page()` before copying and `flush_dcache_page()` before `kunmap_local()` and `put_arg_page()`. `read_code()` and `load_flat_file()` must call `flush_icache_user_range()` after writing or relocating user text. [F153, F154]

## Error Handling
- When `BAD_ADDR(x)` is true for `elf_load()` or `load_elf_interp()`, `load_elf_binary()` must test `IS_ERR_VALUE(x)` and substitute `-EINVAL` when false before assigning `retval`. Any error path in `load_elf_binary()` after `elf_phdata`, `interp_elf_ex`, `interp_elf_phdata`, and `interpreter` are freed must jump to `out` rather than `out_free_dentry`, `out_free_file`, or `out_free_ph`. [F36, F38]
- In `load_elf_fdpic_binary()`, failure paths jumping to `error:` after an earlier `retval`-setting call must assign a negative errno to `retval`, and reset `interpreter = NULL` if `IS_ERR(interpreter)` or after `fput(interpreter)`. [F37]
- Because `dup_mm()` shallow-copies `oldmm` into `mm` before `try_module_get(mm->binfmt->module)`, its `free_pt` error path must reset `mm->binfmt = NULL` (and `mm_init_owner(mm, NULL)`) before `mmput(mm)`. [F78]
- `unshare_fd()` must check `IS_ERR(fd)` on `dup_fd()` before writing to `*new_fdp`, and callers (`ksys_unshare()`, `unshare_files()`) must initialize their `struct files_struct *` out-parameter to `NULL`. Both `bprm_change_interp()` and `free_bprm()` must guard `kfree(bprm->interp)` with `if (bprm->interp != bprm->filename)`. [F39, F57]
- In `elf_core_dump()`, `dump_emit()`, `dump_user_range()`, `write_note_info()`, `elf_core_write_extra_phdrs()`, and `elf_core_write_extra_data()` return `1` on success and `0` on failure, whereas `elf_coredump_extra_notes_write()` returns `0` on success. [F42]
- In `fs/binfmt_flat.c`, `calc_reloc()` returns `RELOC_FAILED` (`0xff00ff01`) on error; `load_flat_file()` must skip zero relocation values and convert `RELOC_FAILED` to `-ENOEXEC`, and when `vm_mmap()` returns `0`, `ret` must be set to `-ENOMEM`. [F55, F56]

## External Contracts
- When `AT_EXECVE_CHECK` (`bprm->is_check`) is set, `bprm_execve()` must exit immediately after `security_bprm_creds_for_exec(bprm)` without calling `exec_binprm()`. When `BINPRM_FLAGS_PATH_INACCESSIBLE` is set on `bprm->interp_flags` (for `O_CLOEXEC` fds), `load_script()` and `load_misc_binary()` must fail with `-ENOENT`. [F170, F171]
- Legacy `clone()` must mask `clone_flags` with `lower_32_bits(clone_flags)` when populating `kernel_clone_args`. In `elf_load()`, when `p_filesz > 0` and `p_memsz > p_filesz`, the partial page tail must be zeroed via `padzero()`, ignoring faults if `!(prot & PROT_WRITE)`. [F113, F178]
- In `elf_core_dump()` and `elf_fdpic_core_dump()`, when `segs > PN_XNUM` (`0xffff`), `e_phnum` must be clamped to `PN_XNUM` with the full count written in `sh_info` of section header 0 via `fill_extnum_info()`. [F91]

## Known Pitfalls
- After `arch_dup_task_struct(tsk, orig)`, `dup_task_struct()` must repoint `tsk->cpus_ptr = &tsk->cpus_mask` whenever `orig->cpus_ptr == &orig->cpus_mask`. `copy_clone_args_from_user()` must save and restore `kargs->set_tid` across the compound-literal assignment to `*kargs`, bound `set_tid_size` to `MAX_PID_NS_LEVEL`, and copy `set_tid_size * sizeof(pid_t)` bytes. [F75, F134]
- In `load_elf_binary()`, `elf_property_phdata` must be reset to `NULL` before scanning `interp_elf_phdata`. In `relocate_vma_down()`, when `new_end <= old_start`, `free_pgd_range()` must start from `old_start` rather than `new_end`. [F67, F155]
- In `copy_strings()` and `copy_string_kernel()`, the per-page loop must substitute `PAGE_SIZE` when `offset_in_page(pos) == 0`. In `load_script()`, `bprm->buf` is not NUL-terminated on entry; parsing must stay within `sizeof(bprm->buf)` before writing `'\0'`. [F108, F131]
- In `fill_files_note()`, `kvmalloc()` must be checked with `ZERO_OR_NULL_PTR(data)`, filenames compacted with `memmove()`, and pointers into `data` reinitialized after `kvfree(data)` on `-ENAMETOOLONG`. On `!CONFIG_MMU`, `load_flat_file()` must use `memmove()` when shifting `FLAT_FLAG_GZIP` data from `realdatastart` to `datapos`. [F43, F126, F128]
- In `fs/binfmt_elf.c`, `ELF_PAGESTART(_v)` must use `~(int)(ELF_MIN_ALIGN - 1)` for compat `Elf32_Addr` type safety, and top-level symbols in `fs/binfmt_elf.c` must be macro-renamed in `fs/compat_binfmt_elf.c`. `STACK_ROUND(sp, items)` requires `sp` to have type `elf_addr_t __user *` (unlike `STACK_ALLOC(sp, len)`). [F115, F124, F166]
