# ARM/APPLE MACHINE SUPPORT

This component provides core platform, coprocessor IPC, and peripheral device drivers for Apple Silicon SoCs (M-series and A-series), including the AIC interrupt controller, DART IOMMU, SART DMA filter, Mailbox and RTKit IPC frameworks, SMC MFD/GPIO/reboot drivers, ANS NVMe host, bcm4377 PCIe Bluetooth HCI, ADMAC audio DMA, PMGR power/reset domains, CPUFreq, NCO clock, pinctrl/GPIO, I2C, SPI, PWM, NVMEM, and Z2 touchscreen drivers.

## Architecture & Data Flow

- In `apple-dart.c`, `apple_dart_identity_domain` and `apple_dart_blocked_domain` are static `struct iommu_domain` instances; only call `to_dart_domain()` on paging domains. Paging domains from `apple_dart_domain_alloc_paging(NULL)` have `pgtbl_ops == NULL` until `apple_dart_finalize_domain()` runs on attach, so callbacks like `apple_dart_iova_to_phys()` and `apple_dart_map_pages()` must NULL-check `pgtbl_ops`. [F48, F144]
- In `io-pgtable-dart.c`, `APPLE_DART2` PTEs shift physical addresses right by `APPLE_DART2_PADDR_SHIFT` (4) before masking (`APPLE_DART2_PADDR_MASK`) and use `BIT(1)` for `APPLE_DART2_PTE_PROT_NO_CACHE`, whereas `APPLE_DART` uses unshifted addresses and sets `APPLE_DART1_PTE_PROT_SP_DIS` (`BIT(1)`) only when `fmt == APPLE_DART`. [F84, F145]
- `apple_dart_alloc_pgtable()` must validate `cfg->pgsize_bitmap` (`SZ_4K`/`SZ_16K`). `dart_get_last()` and `dart_map_pages()` must reject `tbl >= (1 << data->tbl_bits)` before indexing `data->pgd[tbl]`, and `dart_map_pages()`/`dart_unmap_pages()` must clamp `num_entries` to `DART_PTES_PER_TABLE(data) - dart_get_last_index(data, iova)`. [F82, F83, F124]
- In `apple_dart_setup_translation()` and `apple_dart_resume()`, all `DART_TTBR` registers must be written before `DART_TCR` enables translation, and the second loop `for (; i < stream_map->dart->hw->ttbr_count; ++i)` must continue from `n_ttbrs` without resetting `i = 0` so `apple_dart_hw_clear_ttbr()` only clears trailing unused TTBRs. [F71, F108]
- In `drivers/nvme/host/apple.c`, `q->tcbs` is only allocated when `anv->hw->has_lsq_nvmmu` is true (NULL on T8015). Guard all `q->tcbs` and NVMMU accesses on `has_lsq_nvmmu`; `apple_nvme_submit_cmd_t8103()` must populate `&q->tcbs[tag]` alongside `&q->sqes[tag]` before writing `q->sq_db`, and `apple_nvme_handle_cqe()` must call `apple_nvmmu_inval()`. [F46, F63]
- In `apple_nvme_queue_rq()`, initialize `iod->npages = -1`, `iod->nents = 0`, and set `iod->dma_len = 0` on the scatterlist path vs `bv->bv_len` in `apple_nvme_setup_prp_simple()`. In `apple_nvme_setup_prps()`, `iod->npages` starts at `0` (`prp_small_pool`) or `1` (`prp_page_pool`); chaining a page (`i == NVME_CTRL_PAGE_SIZE >> 3`) must copy `old_prp_list[i - 1]` to `prp_list[0]`, store `prp_dma` in `old_prp_list[i - 1]`, and reset `i = 1`. [F65, F115]
- Set `anv->adminq.is_adminq = true` before calling `apple_nvme_queue_alloc()` (which uses `queue_to_apple_nvme()`). `apple_nvme_reset_work()` must cap `max_hw_sectors` to `min_t(u32, NVME_MAX_KB_SZ << 1, dma_max_mapping_size(anv->dev) >> 9)` and `max_segments` to `NVME_MAX_SEGS` so `apple_nvme_iod_alloc_size()` never exceeds `PAGE_SIZE`. [F134, F199]
- In `irq-apple-aic.c`, reading `AIC_EVENT` masks the hardware IRQ, so `aic_irq_eoi()` must call `aic_irq_unmask(d)` whenever `!irqd_irq_masked(d)` (without checking `irqd_irq_disabled(d)`). Likewise, `aic_fiq_set_mask()` masks guest timer FIQs in `SYS_IMP_APL_VM_TMR_FIQ_ENA_EL2`, so `aic_fiq_mask()`/`unmask()` must maintain per-CPU `aic_fiq_unmasked` for `aic_fiq_eoi()`, and `aic_handle_fiq()` must gate `SYS_CNT{P,V}_CTL_EL02` with `VM_TMR_FIQ_ENABLE_{P,V}`. [F61, F62, F104]
- In `irq-apple-aic.c`, guard EL2/VHE registers (`SYS_ICH_*_EL2`, `SYS_IMP_APL_VM_TMR_FIQ_ENA_EL2`, `SYS_CNT*_CTL_EL02`) with `is_kernel_in_hyp_mode()`. Compute AICv2 register offsets and `die_stride` from `irqc->max_irq`, but bounds-check DT specifiers in `aic_irq_domain_translate()` against `irqc->nr_die` and `irqc->nr_irq`. [F101, F173]
- In `rtkit.c`, `apple_rtkit_shmem` may be MMIO- or RAM-backed (use `apple_rtkit_memcpy()`, and NULL-check `crashlog` in `ops->crashed()`). `APPLE_RTKIT_EP_OSLOG` encodes `size` in bytes and `iova >> 12`, whereas other endpoints encode `size >> 12` and `iova` in bytes. `apple_rtkit_is_running()` masks power states with `0xff` before comparing to `ON` (`0x20`), whereas `apple_rtkit_set_{ap,iop}_power_state()` compares unmasked states. [F51, F94, F110]
- In `macsmc.c`, `apple_smc_enter_atomic()` disables notifications and sets `smc->atomic_mode = true` under `smc->mutex`, after which `apple_smc_cmd_locked()` rejects non-atomic commands and `apple_smc_write_atomic()` uses `smc->atomic_pending`. `apple_smc_rw_locked()` rejects sizes `> SMC_MAX_SIZE` (255) and reads `rsize <= 4` from inline `SMC_DATA` instead of `smc->shmem.iomem`, and `apple_smc_rtkit_shmem_setup()` must overflow-check `[bfr->iova, bfr->iova + bfr->size - 1]` within `smc->sram`. [F76, F91, F93]
- In `hci_bcm4377.c`, check `!ring->virtual`, `ring->allow_wait`, and `ring->mapped_payload_size` before dereferencing `ring->ring`, `ring->events`, or `ring->payloads`. `bcm4377_create_transfer_ring()` must zero `xfer_ring_head`/`tail` and increment `ring->generation` under `ring->lock`. Completion handlers must validate `pos`, `BIT(transfer_ring) & ring->transfer_rings`, `bcm4377_extract_msgid()`, and `len <= ring->mapped_payload_size`, and `bcm4377_handle_event()` error paths under `ring->lock` must jump to `out:` to advance `xfer_ring_head` and ring the doorbell. [F56, F68, F69, F97, F116]
- In `hci_bcm4377.c`, restrict DMA to `BCM4377_DMA_MASK` (`0xfffffe00`), pass `PCI_IRQ_MSI` (never legacy IRQs) to `pci_alloc_irq_vectors()`, propagate `bcm4377->hw` `broken_*` flags via `hci_set_quirk()` before `hci_register_dev()`, and only set `HCI_QUIRK_USE_BDADDR_PROPERTY` in `bcm4377_check_bdaddr()` when `bcm4377_is_valid_bdaddr()` fails. [F95, F154, F155, F158]
- In `apple-admac.c`, even `channo` are TX and odd are RX; per-channel registers index by `channo`, whereas `REG_TX/RX_START/STOP/INTSTATE` use bit `channo / 2`. `admac_alloc_chan_resources()` must allocate an `SRAM_BLOCK` carveout under `ad->cache_alloc_lock` into `REG_CHAN_SRAM_CARVEOUT(adchan->no)` (freed in `admac_free_chan_resources()`), and `admac_interrupt()` must read and clear (`~(u32)0`) `REG_GLOBAL_INTSTATE(ad->irq_index)`. [F57, F59, F147]
- In `clk-apple-nco.c`, `applnco_set_rate()` must disable the channel under `chan->lock` before writing `REG_DIV`/`INC1`/`INC2`/`ACCINIT` and re-enable only if `was_enabled`. In `pwm-apple.c`, clamp `on_cycles`/`off_cycles` to `0xFFFFFFFF` and write them before `APPLE_PWM_CTRL_UPDATE`. In `apple_z2.c`, `apple_z2_shutdown()` must set `z2->booted = false` after disabling IRQ and asserting reset. [F79, F80, F81, F121]

## Synchronization

- `apple_rtkit_send_message()` must execute `dma_wmb()` before `apple_mbox_send()`, and `apple_rtkit_rx()` must execute `dma_rmb()` before reading buffers or calling `recv_message_early`. In `apple_mbox_send()`, atomic callers must pass `atomic = true`; when `atomic = false` drops `mbox->tx_lock` to wait on `mbox->tx_empty`, it must relock `mbox->tx_lock` and recheck `control_full` in the `while` loop before writing `a2i_send0`/`1`. [F21, F22, F174]
- `apple_rtkit_ops.recv_message_early` runs in atomic context under `mbox->rx_lock` and must not sleep; `apple_smc_rtkit_recv_early()` must never acquire `smc->lock` or `smc->mutex` and must return `false` for `SMC_MSG_NOTIFICATION` so `apple_smc_rtkit_recv()` runs `blocking_notifier_call_chain` on `rtk->wq`. [F23, F175]
- Hold `anv->lock` around `writel(tag, q->sq_db)` in both `apple_nvme_submit_cmd_t8103()` and `apple_nvme_submit_cmd_t8015()`. In `apple_nvme_poll_cq()` and `bcm4377_poll_completion_ring()`, execute `dma_rmb()` after `READ_ONCE()` observes the updated CQ status or head index before reading entry fields. [F27, F30, F36]
- In `apple-dart.c`, hold `dart->lock` (`spin_lock_irqsave`) across the command write and `readl_poll_timeout_atomic` sequence in `apple_dart_t8020_hw_stream_command()` and `apple_dart_t8110_hw_tlb_command()`. Write `stream_maps[i].dart` only under `dart_domain->init_lock` before `dart_domain->finalized`, and check `domain_maps[i].dart == master_maps[i].dart` in `apple_dart_mod_streams()`. [F32, F70]
- In `io-pgtable-dart.c`, `dart_install_table()` must execute `dma_wmb()` before `cmpxchg64_relaxed(ptep, curr, new)`, and `dart_map_pages()` must free `cptep` via `iommu_free_pages(cptep)` if `dart_install_table()` loses the race, and execute `wmb()` after `dart_init_pte()`. [F9, F33]
- In `irq-apple-aic.c`, `aic_handle_irq()` must read `ic->event + ic->info.event` with non-relaxed `readl()`, and `aic_handle_ipi()` must execute `isb()` after writing `SYS_IMP_APL_IPI_SR_EL1` before `ipi_mux_process()`. [F34]
- In `apple-admac.c`, `admac_cyclic_read_residue()` must read `REG_REPORT_RING` and `REG_RESIDUE` twice under `adchan->lock`, using `admac_ring_noccupied_slots(ring1) + 1` if `residue2 > residue1`. `admac_chan_tasklet()` must drop `adchan->lock` before `dmaengine_desc_callback_invoke()`. [F26, F179]
- Set `.use_raw_spinlock = true` on `regmap_config` in `pinctrl-apple-gpio.c` (`apple_gpio_irqchip` runs under `raw_spinlock_t`). In `pmgr-pwrstate.c` (`GENPD_FLAG_IRQ_SAFE`), use `regmap_read_poll_timeout_atomic()` in `apple_pmgr_ps_set()` and lock `ps->genpd.slock` in reset callbacks. [F170, F187]

## Object Lifetimes

- In `apple_rtkit_init()`, initialize completions, `endpoints`, `mbox->rx`, `mbox->cookie`, and `rtk->wq` before `apple_mbox_start()` enables `irq_recv_not_empty` (requested with `IRQF_NO_AUTOEN | IRQF_NO_SUSPEND`). `apple_rtkit_reinit()`/`free()` must call `apple_mbox_stop()` and drain `rtk->wq` before freeing buffers (zeroing `size`, `buffer`, `iomem`). In `apple_rtkit_crashlog_rx()`, `kfree(bfr)` after `ops->crashed()`. In `apple_smc_probe()`, register `apple_smc_rtkit_shutdown` after `devm_apple_rtkit_init()`, then `apple_smc_disable_notifications` before `devm_mfd_add_devices()`. [F1, F3, F18, F19, F20, F165]
- In `apple-admac.c`, `admac_terminate_all()` must move `current_tx`, `submitted`, and `issued` onto `adchan->to_free` before clearing `current_tx = NULL`, and `admac_synchronize()` must splice `to_free`, call `tasklet_kill()`, and free with `list_for_each_entry_safe()`. Tear down in `admac_remove()`/probe error in order: `of_dma_controller_free()`, `dma_async_device_unregister()`, `free_irq()`, `reset_control_rearm()`. [F4, F6, F109]
- In `apple-dart.c`, enable clocks before reading registers or calling `apple_dart_hw_reset()` (which must precede `request_irq()` and `iommu_device_register()`). Under `apple_dart_groups_lock`, `apple_dart_device_group()` must merge `cfg` via `apple_dart_merge_master_cfg()` if `iommu_group_get_iommudata(group)` is already set (calling `iommu_group_put(group)` on error) and keep `dart->sid2group[sid]` synced with `group_master_cfg`. [F8, F72, F162]
- In `drivers/nvme/host/apple.c`, if `blk_mq_alloc_queue()` returns `ERR_PTR` for `admin_q`, set `admin_q = NULL` before `nvme_uninit_ctrl()`. When `apple_nvme_reset_work()` queues `remove_work`, take `nvme_get_ctrl()` and drop it if `queue_work()` fails; if `apple_rtkit_is_running()`, disable the controller, call `apple_rtkit_shutdown()`, and clear `APPLE_ANS_COPROC_CPU_CONTROL` before asserting `reset` and calling `apple_rtkit_reinit()`. `apple_nvme_detach_genpd()` must guard `pd_count <= 1`, check `!IS_ERR_OR_NULL(pd_dev[i])`, and delete `pd_link[i]` before detaching `pd_dev[i]`. [F12, F13, F44, F150, F153]
- In `sart.c`, never modify `sart->protected_entries`; `clear_bit(i, &sart->used_entries)` if `sart_set_entry()` fails in `apple_sart_add_allowed_region()`, and zero the hardware entry before `clear_bit()` in `apple_sart_remove_allowed_region()`. In `hci_bcm4377.c`, clear on-stack `ring->events[msgid] = NULL` under `ring->lock` before `bcm4377_enqueue()` returns, and only `kfree_skb(skb)` in `bcm4377_hci_send_frame()` after `bcm4377_enqueue()` succeeds. [F17, F75, F190, F202]

## API Contracts

- In `macsmc.c`, `apple_smc_read()`, `write()`, `rw()`, `write_atomic()`, and `get_key_info()` return non-negative byte count on success and negative errno on error; check `< 0` for failure. [F37]
- Set `.owner = THIS_MODULE` on `apple_dart_iommu_ops`. When `dart->pgsize > PAGE_SIZE`, force `IOMMU_DOMAIN_IDENTITY` in `apple_dart_def_domain_type()` and return `-EINVAL` in `apple_dart_finalize_domain()`. In `dart_map_pages()`, return `-EINVAL` if `!(iommu_prot & (IOMMU_READ | IOMMU_WRITE))` and accumulate `*mapped += num_entries * pgsize`. [F50, F192, F193, F194]
- In `sart.c`, `sart_set_entry()` checks alignment/bounds and passes pre-shifted values to `ops->set_entry()` (writing `PADDR`/`SIZE` before `CONFIG`), while `ops->get_entry()` outputs unshifted byte `paddr`/`size`. In `apple.c` (NVMe), register RTKit DMA buffers via `apple_sart_add_allowed_region()` and remove via `apple_sart_remove_allowed_region()` before `dma_free_coherent()`. [F53, F89, F164, F183]
- Pass a RAM shadow copy to `apple_rtkit_crashlog_dump()` (it mutates `bfr` in-place). In `apple_rtkit_management_rx_epmap()`, reply `APPLE_RTKIT_MGMT_EPMAP_REPLY_MORE` on non-final chunks and start system endpoints before completing `epmap_completion` on the final chunk; echo messages in `apple_rtkit_ioreport_rx()` (`0x8`/`0xc`) and `apple_rtkit_syslog_rx_log()` (via `done:`). [F111, F112, F130]
- Pass `nvme_req(req)->status != NVME_SC_SUCCESS` to `blk_mq_add_to_batch()` in `apple_nvme_handle_cqe()`; pass `order = 0` to `bitmap_find_free_region()`/`bitmap_release_region()` in `hci_bcm4377.c`; set both `src_addr_widths` and `dst_addr_widths` in `admac_probe()` and call `dma_get_slave_channel()` in `admac_dma_of_xlate()`; check both `IS_ERR()` and non-NULL on `apple_z2_build_cal_blob()`; use `void (*)(void *)` wrappers for `devm_add_action_or_reset()`. [F41, F47, F54, F139, F195, F196]

## Error Handling

- Check `of_iomap()`, `devm_kasprintf()`, and `cpufreq_cpu_get_raw()` for `NULL` (not `IS_ERR()`). In `aic_of_ic_init()`, `irqc->event` aliases `irqc->base` on AICv1, so check `irqc->event && irqc->event != irqc->base` before `iounmap(irqc->event)`. In `macsmc-reboot.c`, normalize non-deferring `devm_nvmem_cell_get()` `ERR_PTR`s to `NULL` in `reboot->nvm_cells[i]` (matching `struct macsmc_reboot_nvmem` and `nvmem_names[]`), and store `nvmem_cell_get_u8()` in a signed `int`. Use `*_ratelimited()` in IRQ fault handlers. [F38, F39, F40, F42, F58, F140, F207]

## Known Pitfalls

- Use `lower_32_bits()`/`upper_32_bits()` (never `>> 32`) when splitting `dma_addr_t` across 32-bit MMIO registers, and widen `u32` MMIO reads to `u64`/`phys_addr_t`/`size_t` before `<< 32`, `<< 12`, or addition (`apple_dart_*_irq`, `admac_drain_reports`, `sart*_get_entry`, `apple_pwm_get_state`). [F118, F119, F120, F122]
- In `apple-dart.c`, pack `stream_maps` from index `0` with `NULL` sentinels; in `for_each_stream_map()`, check `i < MAX_DARTS_PER_DEVICE` before `stream_map->dart` and never dereference `stream_map` after the loop. In `apple_dart_free_pgtables()`, cast `ptep` to `(void *)` before adding `DART_GRANULE(data)` and save `start = ptep` before `ptep++`. [F85, F107, F136]
- In `pinctrl-apple-gpio.c` (`REGCACHE_FLAT`), `apple_gpio_get()` must read `readl_relaxed(pctl->base + REG_GPIO(offset))` directly for inputs. In `pmgr-pwrstate.c`, mask out `APPLE_PMGR_FLAGS` on writes to `ps->offset` and sequence `APPLE_PMGR_DEV_DISABLE` outside `APPLE_PMGR_RESET`. [F77, F78]
- Do not read `REG_TX/RX_SRAM_SIZE` in `admac_probe()` while power-gated, and compute `(wrslot + 4 - rdslot) % 4` in `admac_ring_noccupied_slots()`. In `hci_bcm4377.c`, `msleep(100)` after `pci_reset_function_locked()` before BAR access, and clear `PCI_EXP_LNKCTL_ASPMC` in `bcm4377_disable_aspm()`. On T8015 NVMe, index IO SQEs via `(void *)q->sqes + (q->sq_tail << APPLE_NVME_IOSQES)`. Format host-endian `smc_key` with `%p4ch` (`swab32()` in `apple_smc_get_key_by_index()`), never stack-allocate `struct apple_rtkit_crashlog_regs`, and use `unsigned long` for bitops targets. [F92, F125, F129, F132, F141, F143, F146, F156, F157]
