# TRACING

This unit implements advanced ftrace event mechanisms (`trace_events_trigger.c`, `trace_events_hist.c`, `trace_events_synth.c`, `trace_events_user.c`, `trace_events_inject.c`, `trace_export.c`), the `tracefs`/`eventfs` pseudo-filesystem (`fs/tracefs/`), core tracepoint, recursion, sequence-buffer, and BPF probe headers (`include/linux/trace*.h`, `include/trace/`), and subsystem trace event headers (`include/trace/events/`).

## Architecture & Data Flow
- In `event_hist_trigger_parse()`, `create_actions(hist_data)` must run before `save_hist_vars()` (called whenever `has_hist_vars(hist_data) || hist_data->n_var_refs`) and before `tracing_map_init()`, because `hist_trigger_elt_data_alloc()` partitions `elt_data->field_var_str` into `n_field_var_str + n_save_var_str + n_var_str` slots at offsets `0`, `n_field_var_str`, and `n_field_var_str + n_save_var_str`. [F69, F74]
- In `event_hist_trigger()`, `hist_pad->compound_key` (`hist_data->key_size` bytes) and `hist_pad->entries` (`HIST_STACKTRACE_SIZE` bytes) must be zeroed with `memset()` before populating keys (`add_to_key()` clamps string copies to `key_field->size - 1`), and `resolve_var_refs()` must run with `self = false` before `hist_trigger_elt_update()` and `self = true` after it. [F64, F103, F117]
- Because `create_tracing_map_fields()` registers `HIST_FIELD_FL_VAR` entries as map variables rather than map fields, `create_sort_keys()` must skip `HIST_FIELD_FL_VAR` fields when incrementing `k` for `sort_key->field_idx`, and `event_hist_trigger_print()` must add `hist_data->n_vars` back when `idx >= hist_data->n_vals - hist_data->n_vars`. [F110]
- In `struct action_data`, `data->handler` discriminates `match_data` (`HANDLER_ONMATCH`) vs `track_data` (`HANDLER_ONMAX`/`HANDLER_ONCHANGE`), and for `ACTION_TRACE`, `data->synth_event_name` is non-NULL only when `data->use_trace_keyword` is true (else `data->action_name`). `create_var_ref()` and `parse_action_params()`/`trace_action_create()` must bound `n_var_refs < TRACING_MAP_VARS_MAX` and `n_params <= SYNTH_FIELDS_MAX`. [F58, F59, F100]
- Non-constant expression `hist_field`s in `parse_unary()` and `parse_expr()` must copy `size`, `is_signed`, `type`, and timestamp flags from `operand1`. For `FIELD_OP_DIV` with a `HIST_FIELD_FL_CONST` divisor (directly or via `var2`), `parse_expr()` must verify `divisor != 0` and copy it into `operand2->constant` before `hist_field_get_div_fn()`, and `HIST_FIELD_FN_DIV_MULT_SHIFT` requires both `div <= (1 << HIST_DIV_SHIFT)` and `val1 < (1 << HIST_DIV_SHIFT)`. [F72, F122, F123]
- Histogram stacktrace variables store the frame count in `((unsigned long *)str)[0]` and frames from index 1. In `trace_events_synth.c`, `synth_field.offset` and `synth_event.n_u64` count 8-byte `union trace_synth_field` slots in `synth_trace_event.fields[]` (advancing by `STR_VAR_LEN_MAX / sizeof(u64)` for static strings and 1 otherwise), whereas `trace_define_field()` and `trace_dynamic_info.offset` use byte offsets. [F95, F128]
- In `trace_events_user.c`, `ftrace_event_field.offset` and `user_event_validator.offset` include `sizeof(struct trace_entry)`, whereas `user_event.min_size` excludes it; `user_event_ftrace()` and `user_event_perf()` copy user data into `entry + 1` but pass `entry` to `user_event_validate()`, after `user_events_write_core()` checks `0 <= idx < refs->count` and `i->count >= user->min_size`. [F88, F137]
- `user_event_set_tp_name()` allocates a separate `EVENT_TP_NAME(user)` only when `EVENT_MULTI_FORMAT(user->reg_flags)` is set, so `find_user_event()` must require matching `EVENT_MULTI_FORMAT` flags and teardown must free `EVENT_TP_NAME(user)` when `EVENT_NAME(user) != EVENT_TP_NAME(user)`. `user_event_enabler_dup()` must skip `ENABLE_VAL_FREEING_BIT` and mask `orig->values` with `ENABLE_VAL_DUP_MASK`. [F82, F85]
- `trace_alloc_entry()` (`trace_events_inject.c`) must allocate `entry_size + 1` zeroed bytes and initialize `FILTER_DYN_STRING`, `FILTER_RDYN_STRING`, and `FILTER_PTR_STRING` fields to point to the trailing NUL or `""`, encoding dynamic locators at `*(u32 *)(entry + field->offset)` as `(str_len << 16) | str_loc` (reducing `str_loc` by `field->offset + field->size` for `FILTER_RDYN_STRING`). [F65, F99]
- In `struct tracefs_inode`, `ti->private` is a root `struct inode` when `TRACEFS_EVENT_INODE` is clear, `struct eventfs_inode` on eventfs directories, and `NULL` on eventfs regular files (which store their parent `eventfs_inode` in `dentry->d_fsdata`). `tracefs_setattr()` and `tracefs_apply_options()` must set `TRACEFS_UID_PERM_SET`/`TRACEFS_GID_PERM_SET` in `ti->flags` and update `ti->vfs_inode.i_uid`/`i_gid` before `eventfs_remount()` or `set_tracefs_inode_owner()`, and `eventfs_set_attr()` must preserve `~EVENTFS_MODE_MASK` in `update_attr()` and mask with `EVENTFS_MODE_MASK` in `update_inode_attr()`. [F213, F227, F228, F229, F246]
- Iterators over `dyn_event_list` must check `is_synth_event(pos)` before `to_synth_event(pos)`; iterators over `file->triggers` must check `cmd_ops->trigger_type` before casting `private_data`; `find_named_trigger()` must skip `data->named_data != NULL`; `elt_data->comm` must be checked for non-NULL; and in `struct trace_iterator`, persistent session fields must precede `struct trace_seq seq` while per-entry transient state reset on each `pipe_read` must be at or after `seq`. [F60, F62, F120, F141, F233]

## Synchronization
- In `trace_events_user.c`, lock order is `group->reg_mutex` -> `event_mutex` -> `mm->mmap_lock` (`user_event_put()` and `user_event_enabler_destroy()` take `locked == true` iff `event_mutex` is held). `user_event_parse()` holds `group->reg_mutex` for `user_event_set_tp_name()` and `event_mutex` for event counts, registration, and `group->register_table`; `user_events_ref_add()` updates `info->refs` under `group->reg_mutex` via `rcu_assign_pointer()` and `kfree_rcu()`, read under `rcu_read_lock_sched()`. [F32, F154, F158]
- `user_event_enabler_write()` holds `event_mutex` and `mmap_read_lock(mm->mm)`, pins with `FOLL_WRITE | FOLL_NOFAULT`, and releases via `unpin_user_pages_dirty_lock(&page, 1, true)`. On pin failure, callers must drop both `mmap_read_lock` and `event_mutex` before `user_event_mm_fault_in()`, or defer via `user_event_enabler_queue_fault()` (`GFP_NOWAIT`); `user_event_enabler_update()` collects `mm->next` via `user_event_mm_get_all()` under `event_mutex` and drops `rcu_read_lock()` before locking `mm->mm`. [F27, F150, F151, F169]
- In `user_event_mm_remove()`, after decrementing `mm->tasks` to zero and removing `mm->mms_link` under `user_event_mms_lock`, the caller must cycle `mmap_write_lock(mm->mm)` and defer `user_event_mm_put()` via `queue_rcu_work()`, while `user_event_enabler_write()` and `user_event_mm_fault_in()` must verify `refcount_read(&mm->tasks) != 0` under `mmap_read_lock`. [F30]
- `user_events_write_core()` calls `fault_in_iov_iter_readable()` before `rcu_read_lock_sched()`, and `user_event_ftrace()`/`user_event_perf()` copy via `copy_nofault()`. In `trace_events_synth.c`, `trace_event_raw_event_synth()` and `trace_string()` must access strings only via `fetch_store_strlen()`, `fetch_store_string()`, or `strncpy_from_{user,kernel}_nofault()`, and `last_cmd` accesses require `lastcmd_mutex`. [F24, F147, F149]
- `event_mutex` nests outside `trigger_cmd_mutex`. Mutations to `file->triggers` (`list_add_rcu`/`list_del_rcu`) and `update_cond_flag()` require `event_mutex`, and `trace_event_file::flags` writers must use atomic `set_bit()`/`clear_bit()`. `trigger_data_free()`, `set_trigger_filter()`, and `hist_clear()` must call `tracepoint_synchronize_unregister()` before freeing data or clearing a map; in `event_hist_trigger_free()`, `trigger_data_free(data)` must precede `remove_hist_vars()`, `unregister_field_var_hists()`, `destroy_hist_data()`, and `free_hist_pad()`, and `hist_clear()` must pause all sibling `named_triggers` first. [F35, F38, F77, F155, F156, F205]
- `event_hist_trigger()` runs in normal, softirq, hardirq, and NMI contexts: it must acquire its per-CPU `struct hist_pad` via `get_hist_pad()` and release it via `put_hist_pad()`, and `hist_poll_wakeup()` must defer waking `hist_poll_wq` via `irq_work_queue(&hist_poll_work)`. `eventfs_callback` runs under `eventfs_mutex` and must never re-enter `tracefs`/`eventfs`, and `tracefs_d_revalidate()` must check `ei->is_freed` locklessly under `LOOKUP_RCU`. [F145, F197, F278, F287]

## Object Lifetimes
- Only `dentry->d_fsdata` holds a `kref` on `struct eventfs_inode` (`get_ei()`/`put_ei()`); `tracefs_inode.private` is uncounted. `free_ei_rcu()` must free `ei->name` with `kfree_const()` and free `get_root_inode(ei)` when `ei->is_events` is set, and `eventfs_create_dir()` / `eventfs_create_events_dir()` error paths after setting `ei->entries` must call `cleanup_ei(ei)` so `release_ei()` does not invoke `entry->release` callbacks. [F180, F181, F183]
- `event_trigger_parse()` must free `trigger_data` via `trigger_data_free()` (never `kfree()`). `register_snapshot_trigger()` must call `tracing_disarm_snapshot(file->tr)` if `register_trigger()` fails, and `unregister_snapshot_trigger()` disarms only when `try_unregister_trigger()` returns `true`. `event_hist_trigger_free()` must call `free_hist_pad()` on every call regardless of `--data->ref`, `create_hist_data()` takes ownership of `attrs` only on success, and `destroy_hist_field()` is a no-op for `HIST_FIELD_FL_VAR_REF` (freed once via `__destroy_hist_field()` in `destroy_hist_fields()`). [F3, F5, F13, F15, F16]
- `synth_event_reg()` pairs `try_module_get(event->mod)` on `TRACE_REG_[PERF_]REGISTER` with `module_put(event->mod)` on `TRACE_REG_[PERF_]UNREGISTER`; `destroy_synth_event()` requires `se->ref == 0` under `event_mutex`; `synth_event_delete()` calls `tracing_reset_all_online_cpus()` after `event_mutex` when `se->mod != NULL`; and `alloc_synth_event()` takes ownership of `fields[]` only on success. [F7, F8, F10, F174]
- When `user_event_put()` drops the last ref to a non-persistent `user_event`, it must hold `event_mutex`, reset `user->refcnt` to 1 while `user` stays in `group->register_table`, and schedule `delayed_destroy_user_event()`. On payload error after reservation, `user_event_ftrace()` must call `__trace_event_discard_commit()` and `user_event_perf()` must call `perf_swevent_put_recursion_context()`. `parse_entry()` leaves `*pentry` allocated on non-`-ENOMEM` errors, requiring unconditional `kfree(entry)`. [F1, F18, F23]

## API Contracts
- `trace_event_raw_event_synth()` and `[__]synth_event_trace_start()`/`_end()` must bracket buffer reserve/commit with `ring_buffer_nest_start()`/`_end()`, and once `[__]synth_event_trace_start()` succeeds, the caller must call `[__]synth_event_trace_end()` even on error. Across `trace_events_inject.c`, `trace_events_hist.c`, and `trace_events_user.c`, `__data_loc` offsets are relative to the record start, whereas `__rel_loc` offsets are relative to `field->offset + field->size`. [F9, F67, F148]
- `__set_synth_event_print_fmt()` excludes NUL (allocate `len + 1`), whereas `user_event_set_print_fmt()`, `user_dyn_field_set_string()` (which updates `*iout = i` only when `len != 0`), and `user_field_set_string()` return `pos + 1`. `tracefs_create_file()`, `tracefs_create_dir()`, and `tracefs_create_instance_dir()` return `NULL` (never `ERR_PTR`) on failure; `eventfs_callback` returns `> 0` to emit a file and `<= 0` to omit it, with `data` reset to `ei->data` before each call. [F112, F133, F209, F210, F221]
- `trace_test_and_set_recursion()` sets a recursion bit and disables preemption only when returning `bit >= 0`, which must be paired with `trace_clear_recursion(bit)` passing the unshifted bit index (never `BIT(bit)`), and `tracing_gen_ctx_dec()` requires preemption disabled. `trace_trigger_soft_disabled()` must check `EVENT_FILE_FL_TRIGGER_COND` before `__trace_trigger_soft_disabled()`, and `trace_seq` consumers must use `trace_seq_used(s)` rather than `s->seq.len`. [F188, F223, F224, F247, F259]

## Error Handling
- In tracefs file operations on `struct trace_event_file`, the first access under `event_mutex` must call `event_file_file(filp)` (not `event_file_data()`) and return `-ENODEV` if `NULL`. `event_hist_trigger()` must check `if (unlikely(!rbe))` before dereferencing `rbe` or `rec`, and `hist_field_div()` must return `-1` when `!val2` before `__ffs64(val2)` or `div64_u64()`. [F44, F61, F124]
- Callers of `event_trigger_set_filter()` must call `event_trigger_reset_filter()` on failure because `set_trigger_filter()` publishes `data->filter` on error. Error paths in `register_synth_event()` (`event->tp`) and `create_hist_data()` (`hist_data->map`) must clear `ERR_PTR` members to `NULL` before teardown. [F4, F47]
- `parse_field()` returns `ERR_PTR` on error but `NULL` on success for synthetic/common fields while setting `*flags`; `create_hist_field()` returns `NULL` (never `ERR_PTR`) on failure; and `find_match_var()`, `find_synthetic_field_var()`, and `create_target_field_var()` can return `NULL`, a valid pointer, or `ERR_PTR`. `register_trace_event()` returns `0` on failure (translate to `-ENODEV`), and `__synth_event_trace_init()` returns `-ENOENT` when disabled (translate to `0` in exported wrappers). [F46, F51, F52, F53, F177]

## External Contracts
- `user_reg_get()` and `user_unreg_get()` must validate `size` in `[offsetofend(...), PAGE_SIZE]`, copy via `copy_struct_from_user()`, and reject unknown `flags`, non-zero reserved fields, invalid `enable_size`, unaligned/`!access_ok()` `enable_addr`, or `enable_bit >= enable_size * BITS_PER_BYTE`. `user_event_validate()` must verify all `__data_loc`/`__rel_loc` bounds and NUL termination (`VALIDATOR_ENSURE_NULL`), and `user_event_capable()` requires `perfmon_capable()` for `USER_EVENT_REG_PERSIST`. [F86, F163, F165, F166]

## Known Pitfalls
- `create_tracing_map_fields()` must check `hist_field->flags` before using `field->size` because legacy `cpu`/`stacktrace`/`comm` fields return a dummy `field` with `size == 0`. In `check_expr_operands()` and `parse_expr()`, `HIST_FIELD_FL_VAR_REF`/`HIST_FIELD_FL_ALIAS` operands must be resolved via `find_var_field(operand->var.hist_data, ...)`. In `event_enable_*_trigger*()`, `trace_event_trigger_enable_disable()` and `update_cond_flag()` target `file`, while soft-mode calls target `enable_data->file`. [F70, F118, F119]
- In `trace_events_synth.c`, scalar fields in `entry->fields[n_u64]` must use width-matched `union trace_synth_field` members (`as_u8`..`as_u64`), field loops must chain `is_string` / `is_stack` / scalar with `if / else if / else`, and `synth_field_fmt()` must return `"%s"`. In `trace_events_user.c`, `user_events_write_core()` must copy `copy = *i` per probe, `align_addr_bit()` must adjust `uaddr`/`bit` for 32-on-64, `user_event_parse_field()` must check `"__data_loc unsigned "` before `"__data_loc "`, and two-pass `snprintf` helpers must use `LEN_OR_ZERO`. [F84, F90, F93, F94, F106, F109, F132]
- In `parse_entry()`, `krealloc()` requires refreshing `entry = *pentry` (and `kfree(entry)` on failure). `eventfs_get_inode()` must advance `dentry = dentry->d_parent` before reading `pei = dentry->d_fsdata`; `set_tracefs_inode_owner()` tests `rti->flags` for mount-root fallback and `ti->flags` for `inode->i_uid`/`i_gid`; and in `include/trace/events/`, `__get_dynamic_array_len()` returns bytes (divide by `sizeof(type)` for `__print_array()`). [F79, F237, F253, F255]
