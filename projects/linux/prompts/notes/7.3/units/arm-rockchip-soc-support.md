# ARM/Rockchip SoC support

This unit covers core Rockchip SoC infrastructure and peripheral drivers: Clock and Reset Units (CRU), timers, DDR Frequency Interface (DFI) devfreq/PMU monitors, GPIO/IRQ controllers, IOMMU (v1/v2), PCIe Root Complex and Endpoint controllers, RK3x I2C, DesignWare MMC platform glue, SARADC, eFuse/OTP NVMEM, mailbox, and MIPI D-PHY/eMMC/HDMI/USB2 PHYs.

## Architecture & Data Flow

- `rockchip_clk_init_base()` fills `ctx->clk_data.clks` with `ERR_PTR(-EPROBE_DEFER)` or `ERR_PTR(-ENOENT)`, and `rockchip_clk_register_branches()` writes `ctx->clk_data.clks[list->id] = clk` even when `list->id == 0`. Thus `rockchip_clk_get_lookup()` returns `ERR_PTR` (check `IS_ERR()`, not `NULL`) for unregistered IDs, and ID `0` is overwritten by internal clocks and must never be used as a DT clock ID or `linked_clk_id`. [F27, F59]
- In `rockchip_clk_register_branches()`, `clk = NULL` and `flags = list->flags` must be reset at the start of every iteration so unhandled branch types hit `if (!clk)` and `CLK_SET_RATE_PARENT` from gate cases does not leak. Every `rockchip_pll_rate_table` must be sorted in descending `.rate` order, end with a zeroed `{ /* sentinel */ }`, and have divider fields that arithmetically evaluate to `.rate` from the 24 MHz oscillator. [F55, F60, F71]
- When `ROCKCHIP_SOFTRST_HIWORD_MASK` is set, `rockchip_softrst_assert()`/`deassert()` compute register byte offsets as `(id / 16) * 4`, so LUT macros in `rst-rk3562.c`, `rst-rk3576.c`, and `rst-rk3588.c` must scale sub-CRU byte offsets `B` by 4 (`B * 4 + reg * 16 + bit`, `B` 4-byte aligned, `bit < 16`). [F63]
- In `rockchip-dfi.c`, `dfi->clk` must be a valid `struct clk *` or `NULL` (never `ERR_PTR`), `dfi->max_channels` must be `<= DMC_MAX_CHANNELS` (4), and channel loops must check `dfi->channel_mask & BIT(i)`. In `rockchip_ddr_perf_counters_add()` and `rockchip_dfi_get_event()`, `now - last` on `u64` `dmc_count_channel` fields must be cast to `u32` to handle 32-bit MMIO counter wrap. Every `ROCKCHIP_DDRTYPE_*` in `rockchip_dfi_ddrtype_to_ctrl()` must also set `dfi->burst_len` in `rockchip_ddr_perf_init()`. [F35, F65, F78, F84]
- In `gpio-rockchip.c`, `rockchip_interrupts_register()` must write `0xffffffff` to `int_mask`, `port_eoi`, `int_en`, and `gc->mask_cache` before `irq_set_chained_handler_and_data()`. In `rockchip_irq_set_type()`, leaving `IRQ_TYPE_EDGE_BOTH` must clear `BIT(d->hwirq)` in `int_bothedge` (V2) or `bank->toggle_edge_mode` (V1); on V1 with `toggle_edge_mode`, `rockchip_irq_set_type()` and `rockchip_irq_demux()` must keep `int_polarity` inverted relative to `ext_port`, looping in `demux` until `ext_port` stabilizes. [F42, F43, F100]
- In `rockchip-iommu.c`, `iommu->domain` is `&rk_identity_domain` when detached, so callers of `to_rk_domain(iommu->domain)` (`rk_iommu_enable()`, `rk_iommu_identity_attach()`, `rk_iommu_suspend()`, `rk_iommu_resume()`) must verify `iommu->domain != &rk_identity_domain`. `RK_IOMMU_PGSIZE_BITMAP` must not exceed 4 MiB (`NUM_PT_ENTRIES * SPAGE_SIZE`). v2 PTEs pack address bits 39:32 into bits 11:4 (`DTE_HI_MASK1`/`2`), so `rk_mk_pte_v2()` must not set v1 cache flags (bits 8:4) and addresses must be extracted via `rk_ops->pt_address`. [F183, F220, F221]
- `struct rockchip_pcie` is inside `struct pci_host_bridge` only when `rockchip->is_rc` is true (and inside `struct rockchip_pcie_ep` when false); callers must set `rockchip->dev` and `rockchip->is_rc` before `rockchip_pcie_parse_dt()`, and only access `pci_host_bridge_from_priv(rockchip)` or `reg_base` when `is_rc` is true, and `mem_res` when `is_rc` is false. In `rockchip_pcie_wr_own_conf()`, sub-word writes (`size < 4`) must use 4-byte aligned 32-bit `readl`/`writel` RMW. [F180, F228, F264]
- In `i2c-rk3x.c`, writes to `REG_CON` (`rk3x_i2c_start()`, `rk3x_i2c_stop()`, timeout abort) must preserve `i2c_readl(i2c, REG_CON) & REG_CON_TUNING_MASK`. `rk3x_i2c_setup()` may use `REG_CON_MOD_REGISTER_TX` only when `msgs[0].len < 4`. `rk3x_i2c_fill_transmit_buf()` packs the target address as byte 0 of the first 32-byte `TXBUFFER_BASE` chunk (31 payload bytes) and writes `cnt` including it to `REG_MTXCNT`. `rk3x_i2c_prepare_read()`/`handle_read()` must cap chunks to 32 bytes, clear `REG_CON_LASTACK` when `len > 32`, and switch `REG_CON` to `REG_CON_MOD_RX` when `i2c->processed != 0`. [F198, F216, F217, F218]
- In `phy-rockchip-inno-usb2.c`, for `USB2PHY_PORT_OTG`, if `rport->mode` is `USB_DR_MODE_HOST` or `USB_DR_MODE_UNKNOWN`, `otg_sm_work` and `chg_work` are uninitialized and must not be touched in `init`, `exit`, or `irq`. In `rockchip_rk3328_efuse_read()`, `rockchip_rk3399_efuse_read()`, and `rk3588_otp_read()`, unaligned reads must round start down and `offset + bytes` up to 4-byte boundaries and copy from `buf + (offset % 4)`. [F175, F223]

## Synchronization

- In `gpio-rockchip.c`, `bank->slock` (`raw_spinlock_t`) protects GPIO registers and `bank->toggle_edge_mode` across process and hardirq contexts; never hold `bank->slock` across sleeping calls (`pinctrl_gpio_direction_input()`/`output()`, `clk_prepare_enable()`/`clk_disable_unprepare()`). In `rockchip_softrst_assert()`/`deassert()`, when `ROCKCHIP_SOFTRST_HIWORD_MASK` is absent, RMW on `softrst->reg_base` requires `spin_lock_irqsave(&softrst->lock, flags)`. [F18, F112]
- In `timer-rockchip.c`, `rk_timer_disable()` must precede `rk_timer_update_counter()` in `rk_timer_set_next_event()`/`set_periodic()`, and in `rk_timer_interrupt()` it must be called before `ce->event_handler(ce)` when `clockevent_state_oneshot(ce)` is true. In `rockchip-dfi.c`, `dfi->total_count` and `dfi->last_perf_count` must be updated together under `write_seqlock(&dfi->count_seqlock)` and read in a `read_seqbegin()`/`read_seqretry()` loop. [F47, F56, F123]
- In `rockchip-iommu.c`, `rk_domain->dt_lock` nests outside `rk_domain->iommus_lock` (never acquire `dt_lock` under `iommus_lock`). `rk_dte_get_page_table()`, `rk_iommu_map_iova()`, and `rk_iommu_unmap_iova()` require `dt_lock` and `GFP_ATOMIC | rk_ops->gfp_flags`. All `rk_domain->iommus` accesses require `iommus_lock`, and `rk_iommu_zap_iova()`/`rk_iommu_irq()` must only touch MMU registers or clocks when `pm_runtime_get_if_in_use(iommu->dev) > 0`, balancing with `clk_bulk_disable()` and `pm_runtime_put()`. [F143, F158, F159, F288]
- In `i2c-rk3x.c`, `rk3x_i2c_xfer_common()` must hold `i2c->lock` across `clk_enable()`, `rk3x_i2c_setup()`, timeout recovery, and `clk_disable()`, releasing it only while waiting for completion; in polling mode, it must call `disable_irq(i2c->irq)` before `rk3x_i2c_start()`/`wait_xfer_poll()` and `enable_irq(i2c->irq)` before re-acquiring `i2c->lock`. [F149, F162]
- In `pcie-rockchip-ep.c`, `rockchip->perst_gpio` must be checked before enabling/disabling `ep->perst_irq`, `rockchip_pcie_ep_setup_irq()` must set `ep->perst_asserted = true` and `IRQ_NOAUTOEN` before `devm_request_threaded_irq()`, and `rockchip_pcie_ep_stop()` must set `ep->perst_asserted = true` and `disable_irq(ep->perst_irq)` before `cancel_delayed_work_sync(&ep->link_training)`. In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_linestate_irq()` must release `rport->mutex` before calling `rockchip_usb2phy_sm_work()`. [F167, F181, F278]
- In `rockchip_saradc.c`, `rockchip_saradc_conversion()` must set `info->last_chan = chan` under `info->lock` before calling `rockchip_saradc_start()`, and on conversion timeout its callers (`rockchip_saradc_read_raw()`, `rockchip_saradc_trigger_handler()`) must call `rockchip_saradc_power_down(info)` before unlocking `info->lock`. [F150, F214]

## Object Lifetimes

- In `rockchip_clk_register_late_branches()`, every `GATE_LINK` clock's `linked_clk_id` must already be registered in `ctx->clk_data.clks` before that entry is processed, and late branch arrays (e.g. `rk3588_clk_branches`) and their `parent_names` must not be marked `__initdata` or `__initconst` (`PNAME()`). [F4, F110]
- In `rockchip_ddr_perf_init()`, `count_seqlock`, cpuhp state/instance registration, `rockchip_dfi_enable()`, and `hrtimer_setup(&dfi->timer, ...)` must be initialized and devres-tracked before `perf_pmu_register()`. Every `struct device_node *` from `of_get_parent()` in `gpio-rockchip.c` or `of_parse_phandle()` in `rockchip_dfi_probe()` must be released with `of_node_put()`, and `rockchip_interrupts_register()` must call `irq_domain_remove(bank->domain)` if `irq_alloc_domain_generic_chips()` fails. [F12, F16, F109]
- In `rockchip-iommu.c`, `rk_iommu_of_xlate()` must allocate `struct rk_iommudata` with `devm_kzalloc(&iommu_dev->dev, ...)` and call `platform_device_put(iommu_dev)`. `rk_iommu_probe_device()` creates `data->link` with `DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME`, so `rk_iommu_release_device()` must call `device_link_del(data->link)`. `rk_iommu_shutdown()` must free all IRQs with `devm_free_irq()` before `pm_runtime_force_suspend()`. [F142, F170, F269]
- `rockchip_pcie_deinit_phys()` must call `phy_power_off()` only on lanes in `rockchip->lanes_map` while calling `phy_exit()` on all `MAX_LANE_NUM` PHYs, and init error labels `err_power_off_phy`/`err_exit_phy` require `i` to hold the active PHY count (resetting `i = MAX_LANE_NUM` before `err_exit_phy`). `rk3x_i2c_probe()` prepares both `i2c->clk` and `i2c->pclk` (even when aliased on v0), so error/remove paths must call `clk_unprepare()` on both after `clk_notifier_unregister()`. [F144, F148, F238]

## API Contracts

- Callers of `rockchip_clk_init()`/`rockchip_clk_init_early()` sizing `nr_clks` from `rockchip_clk_find_max_clk_id()` must add `1`, and `rockchip_clk_find_max_clk_id()` must assign `max = list->child->id` when `list->child->id > max`. Drivers using `rockchip_clk_init_early()` must call `rockchip_clk_finalize(ctx)`, `of_clk_del_provider(np)`, and `rockchip_clk_of_add_provider(np, ctx)` after registering late branches. In `rockchip_register_softrst_lut()`, when `lookup_table` is non-NULL, `num_regs` must equal `ARRAY_SIZE(lookup_table)` with non-negative entries. [F51, F58, F62, F70]
- In `timer-rockchip.c`, `rk_timer_sched_read()` must stay `notrace`, lockless, and bitwise-negate `TIMER_CURRENT_VALUE0` as `u32` (`~readl_relaxed(...)`) before widening to `u64`; `rk_clkevt` passes `&rk_clkevt->ce` as `dev_id` to `request_irq()`. In `gpio-rockchip.c`, `rockchip_gpio_readl_bit()`/`writel_bit()` take a `0..31` pin index (not `BIT(offset)`), and `irq_chip` callbacks must get `bank` via `((struct irq_chip_generic *)irq_data_get_irq_chip_data(d))->private`. [F38, F90, F97, F98, F122]
- In `pcie-rockchip-host.c`, `rockchip_pcie_rd/wr_conf()` and `own/other_conf()` must return `PCIBIOS_*` codes, zero `*val` on read errors, and reject `PCI_SLOT(devfn) != 0` on the root bus and its immediate child bus. `rockchip_pcie_prog_ob/ib_atu()` expect `num_pass_bits` as `bits - 1` (`ib_atu` shifts `lower_addr` left by 8), whereas `rockchip_pcie_prog_ep_ob_atu()` subtracts 1 internally. In `pcie-rockchip-ep.c`, `rockchip_pcie_ep_set/clear_bar()` use `BAR_CFG0` for BARs 0..3 and `BAR_CFG1` (`bar - BAR_4`) for BARs 4..5, rejecting odd 64-bit BARs and rounding 64-bit sizes via `1ULL << fls64(sz - 1)`. [F178, F179, F227, F304, F305]
- In `phy-rockchip-inno-hdmi.c`, `inno_write()`/`read()`/`update_bits()`/`poll()` take a 1-increment register index (multiplied by 4 internally), and `inno_hdmi_phy_get_pre_pll_cfg()` returns `ERR_PTR(-EINVAL)` on failure. In `phy-rockchip-inno-dsidphy.c`, `inno_dsidphy_mipi_mode_enable()` converts `cfg->clk_pre` (in UI) via `DIV_ROUND_UP(cfg->clk_pre, BITS_PER_BYTE)` while dividing picosecond fields by `t_txbyteclkhs`. In `phy-rockchip-inno-usb2.c`, `dev_get_drvdata(phy->dev.parent)` retrieves `struct rockchip_usb2phy *` while `phy_get_drvdata(phy)` retrieves `struct rockchip_usb2phy_port *`. [F176, F192, F266]

## Error Handling

- In `rockchip_dfi_probe()`, `"rockchip,pmu"` is mandatory (`dfi->regmap_pmu` must be initialized before `soc_init(dfi)`), and `dfi->edev` must be registered before `rockchip_ddr_perf_init()` or `rockchip_dfi_enable()`. In `rockchip_ddr_perf_init()`, `cpuhp_setup_state_multi(CPUHP_AP_ONLINE_DYN, ...)` returns a positive state ID on success, so check `ret < 0` on a signed `int`. [F34, F36, F37]
- In `gpio-rockchip.c`, `bank->db_clk` is `NULL` on `GPIO_TYPE_V1` (where `!IS_ERR(NULL)` is true and `dbclk_div_en`/`con` alias `port_dr`), so debounce code must check `bank->gpio_type == GPIO_TYPE_V2 && !IS_ERR(bank->db_clk)` and validate `debounce <= max_debounce`. In `rockchip_pcie_parse_host_dt()` and `dw_mmc-rockchip.c`, absent optional regulators (`vpcie12v`/`vpcie3v3`) and clocks (`drv_clk`/`sample_clk`) hold `ERR_PTR`, so consumers must check `!IS_ERR()`. [F39, F68, F177, F190]
- When a `0`- or `NULL`-returning call fails after `ret`/`err` was set to `0`—such as `irq_of_parse_and_map()` in `rk_timer_probe()` or `pci_epc_mem_alloc_addr()` in `rockchip_pcie_ep_init_ob_mem()`—assign a negative errno before jumping to cleanup. In `rockchip_usb2phy_otg_port_init()`, do not overwrite `ret` with boolean `property_enabled()` calls. [F33, F172, F174]

## External Contracts

- In `rockchip_saradc.c`, `num_channels` must be `<= SARADC_MAX_CHANNELS`. `rockchip_saradc_trigger_handler()` must zero-initialize its stack scan buffer `data` before `iio_for_each_active_channel()` to avoid leaking stack memory, index `i_dev->channels[i]` with bit index `i` while indexing `data.values[j]` with dense counter `j`, and call `iio_trigger_notify_done(i_dev->trig)` on all exit paths. [F245, F267, F297, F298]

## Known Pitfalls

- In `drivers/clk/rockchip/`, `rockchip_clk_register_branch()` and `rockchip_clk_register_frac_branch()` treat `gate_offset < 0` (`-1`) as "no gate", whereas `rockchip_clk_register_factor_branch()` treats `gate_offset == 0` as "no gate". `HIWORD_UPDATE(val, mask, shift)` does not mask `val`, so callers must ensure `0 <= val <= mask` (1-based dividers passed as `_div - 1` must be `>= 1`) and `shift + fls(mask) <= 16`. [F61, F87]
- In `gpio-rockchip.c`, V2 per-pin control registers split pins `0..15` and `16..31` with HIWORD masks and require `rockchip_gpio_readl/writel*()`, whereas `ext_port`, `int_status`, and `dbclk_div_con` are single 32-bit registers accessed via plain `readl()`/`writel()`. In `rockchip_irq_set_type()`, check `type == IRQ_TYPE_EDGE_BOTH` (exact equality, not `&`). In `rockchip_irq_demux()`, `pending` must be `unsigned long` for `for_each_set_bit(irq, &pending, 32)`. In `rockchip_gpio_find_bank()`, return `found ? bank : NULL`. [F67, F79, F81, F99]
- In `rockchip-dfi.c`, `perf_pmu_register()` sets the PMU sysfs device's drvdata to `struct pmu *`, so PMU sysfs callbacks (e.g. `ddr_perf_cpumask_show()`) must use `container_of(dev_get_drvdata(dev), struct rockchip_dfi, pmu)`. [F96]
- Avoid 32-bit truncation and 64-bit `/` division errors: use `DIV_ROUND_CLOSEST_ULL()` in `rockchip_gpio_set_debounce()`; cast rates to `u64` before multiplying and divide `u64` values with `do_div()`/`div_u64()` in `inno_hdmi_phy` and `inno_dsidphy`; widen `u32 dte` to `u64` before shifting by `DTE_HI_SHIFT2` (32) or `DTE_HI_SHIFT1` (24) in `rk_dte_pt_address_v2()`; define `PCIE_ADDR_MASK` with `GENMASK_ULL(63, ...)`; in `pcie-rockchip-ep.c`, do not mask unshifted `pci_epf_header` fields with `GENMASK(31, 16)` before left-shifting, and store `ROCKCHIP_PCIE_EP_MSI_CTRL_REG` in a `u32` with `PCI_MSI_FLAGS_*` shifted by 16. [F89, F173, F246, F247, F249, F256, F257]
- In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_cfg` tables must end with `{ .reg = 0 }` and any valid entry with `.reg == 0` (`rk3576_phy_cfgs`, `rk3588_phy_cfgs`) must be at index 0 for the `do { ... } while (phy_cfgs[index].reg)` loop; writable `usb2phy_reg` descriptors passed to `property_enable()` must have `bitend <= 15`. In `phy-rockchip-inno-hdmi.c`, `inno_hdmi_phy_rk3328_*` and `rk3228_*` callbacks must not mix `RK3328_*` and `RK3228_*` register macros. [F232, F233, F241]
