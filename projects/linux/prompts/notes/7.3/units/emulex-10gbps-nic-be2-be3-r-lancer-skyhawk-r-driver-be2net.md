# EMULEX 10Gbps NIC BE2, BE3-R, Lancer, Skyhawk-R DRIVER (be2net)

This unit (`drivers/net/ethernet/emulex/benet`) implements the core PCI and `net_device` driver lifecycle, TX/RX/event queue management, NAPI polling, SR-IOV virtual function provisioning, hardware error recovery, and RoCE (`ocrdma`) driver registration for Emulex OneConnect/BladeEngine 10Gbps NICs (BE2, BE3-R, Lancer, and Skyhawk-R).

## Architecture & Data Flow

- `be_tx_setup_wrb_hdr()` asserts `BUG_ON(txo->sent_skb_list[head])` and stores `skb` only at its header WRB index (`NULL` on fragment slots) and updates `txq->used`, `last_req_hdr`, `last_req_wrb_cnt`, and `pend_wrb_cnt` only after all fragment DMA mappings succeed, so `be_xmit_restore()` can roll back failed mappings and `be_tx_compl_process()` can detect header WRBs and clear `sent_skbs[txq->tail] = NULL`. [F13, F55, F67]
- On `!lancer_chip(adapter)`, when `be_xmit_flush()` pads an odd `txo->pend_wrb_cnt` with a dummy WRB, it must increment `txq->head`, `txq->used`, `pend_wrb_cnt`, and `TX_HDR_WRB_NUM` at `last_req_hdr` before notifying hardware and zeroing `pend_wrb_cnt`. When `be_tx_compl_clean()` cleans unnotified WRBs (`used > 0`), it must save `notified_idx = txq->tail` before `be_tx_compl_process()`, zero `pend_wrb_cnt`, and reset `txq->head` and `txq->tail` to `notified_idx`. [F56, F57]
- `AMAP_GET_BITS` and `AMAP_SET_BITS` operate on host-endian `u32` dwords: completions and stats must be swapped with `be_dws_le_to_cpu()` before reading fields, and TX header WRBs swapped with `be_dws_cpu_to_le()` in `be_tx_setup_wrb_hdr()` must only be mutated afterward with `cpu_to_le32()` masks. In `be_rx_compl_get()`, after `be_dws_le_to_cpu()`, `rxcp->vlan_tag` must be swapped with `swab16()` on `!lancer_chip(adapter)`. [F74, F78]
- `adapter->pmac_id` has `be_max_uc(adapter)` entries: `pmac_id[0]` stores `adapter->dev_mac` (updated only after HW activation in `be_mac_addr_set()`, `be_enable_if_filters()`, or BE3 VF `be_mac_setup()`, and zeroed in `be_disable_if_filters()`), and `pmac_id[1 .. uc_macs]` store `uc_list[0 .. uc_macs - 1]`. `be_dev_mac_add()`/`be_uc_mac_add()` must alias `pmac_id[0]` and `pmac_id[uc_idx + 1]` when matching, and `be_dev_mac_del()`/`be_uc_mac_del()` must skip `be_cmd_pmac_del()` while shared. [F50, F51, F66]
- `be_vid_config()` copies every set bit in `adapter->vids` into a 64-element stack array `vids[BE_NUM_VLANS_SUPPORTED]` when `adapter->vlans_added <= be_max_vlans(adapter)`, so `be_vlan_add_vid()` and `be_vlan_rem_vid()` must keep `adapter->vlans_added` equal to the bitmap weight of `adapter->vids`. [F113]
- RSS RX queues occupy `rx_obj[0 .. num_rss_qs - 1]` (`for_all_rss_queues`), while `default_rxo(adapter)` is at `rx_obj[num_rx_qs - 1]` so `for_all_rx_queues_on_eq` polls it on `eq_obj[0]`. `be_poll()` and `be_get_new_eqd()` must iterate with `for_all_rx_queues_on_eq` and `for_all_tx_queues_on_eq`. `MODULO(val, limit)` asserts `BUG_ON(limit & (limit - 1))`, so every `be_queue_info.len` and `be_get_temp_freq` must be a power of two, and `be_rx_qs_create()` must post at most `RX_Q_LEN - 1` fragments. [F65, F70, F71, F97]
- In `be_map_pci_bars()`, `SLI_INTF_REG_OFFSET` must be read to set `sli_family` and `virtfn` before calling `be_physfn()`, `be_virtfn()`, or `db_bar()`. `adapter->csr` is mapped only when `BEx_chip(adapter) && be_physfn(adapter)`, and `pcicfg` only when `skyhawk_chip(adapter) || BEx_chip(adapter)` (VFs alias `db + SRIOV_VF_PCICFG_OFFSET` with `pcicfg_mapped = false`), so `be_unmap_pci_bars()` must check `pcicfg && pcicfg_mapped`. [F40, F121]
- In `be_setup_init()`, `adapter->cmd_privileges` must be initialized to `MAX_PRIVILEGES` only when `be_physfn(adapter)` is true and `MIN_PRIVILEGES` on VFs. `be_update_queues()` must not call `be_msix_disable()` when `adapter->num_msix_roce_vec` is non-zero (shared with `ocrdma`). [F61, F122]
- In `be_rxq_notify()`, `be_txq_notify()`, `be_eq_notify()`, and `be_cq_notify()`, the doorbell `iowrite32()` to `adapter->db` must be skipped if `be_check_error(adapter, BE_ERROR_HW)` is true, and `be_rxq_notify()`/`be_txq_notify()` must execute `wmb()` before `iowrite32()`. In `be_rx_cq_clean()`, when `be_rx_compl_get(rxo)` returns `NULL`, break immediately on `lancer_chip(adapter)` and on other chips when `flush_wait++ > 50` or `BE_ERROR_HW` is set. [F96, F129]
- `be_err_recovery_workq` is nullable, so `be_schedule_err_detection()`, `be_cancel_err_detection()`, and `be_destroy_err_recovery_workq()` must guard against `!be_err_recovery_workq`. In `be_parse_stats()`, `erx->rx_drops_no_fragments` is indexed by HW queue ID `rxo->q.id` (accumulated via `accumulate_16bit_val()` on `BEx_chip`). In `be_get_wrb_params_from_skb()`, `skb_is_gso(skb)` must be `else if` with `CHECKSUM_PARTIAL` so GSO packets never set `IPCS`/`TCPCS`/`UDPCS`. [F39, F79, F85]

## Synchronization

- `adapter->rx_filter_lock` must be held across all updates to `vids`, `vlans_added`, `uc_list`, `uc_macs`, `mc_list`, `mc_count`, and `pmac_id` in `be_mac_addr_set()`, `be_vlan_add_vid()`, `be_vlan_rem_vid()`, and `__be_set_rx_mode()`. In `be_set_mc_list()` and `be_set_uc_list()`, `netif_addr_lock_bh(netdev)` must be acquired to sync/copy addresses and released before issuing `be_cmd_*` calls. [F20, F21]
- `be_set_rx_mode()` runs under `netif_addr_lock_bh` and must use `be_alloc_work()` (`GFP_ATOMIC`) to queue `be_work_set_rx_mode()` on `be_wq`; `be_alloc_work()` callbacks must free `container_of(work, struct be_cmd_work, work)`. `be_ndo_bridge_getlink()` and `be_cmd_get_hsw_config()` run under `rcu_read_lock()` and must not sleep. Calling `be_process_mcc()` from process/workqueue context (e.g., `be_worker()`) requires `local_bh_disable()`/`local_bh_enable()` because it uses `spin_lock(&adapter->mcc_cq_lock)`. [F29, F111, F135, F136]
- `be_setup_queues()` and `be_update_queues()` require callers (`be_setup()`, `be_pci_sriov_configure()`) to hold `rtnl_lock()`, and `be_update_queues()` must not unlock it; when `netif_running(netdev)`, `be_update_queues()` must call `netif_carrier_off(netdev)` under `netif_tx_lock_bh(netdev)` before `be_close()`. In `be_cleanup()`, `rtnl_lock()` must wrap `netif_device_detach()` and `be_close()`, and be released before `be_clear()`. [F17, F27, F34]
- In `be_close()`, `flush_workqueue(be_wq)` must precede `be_disable_if_filters()`, `napi_disable()` and `be_async_mcc_disable()` must precede `netif_tx_disable()` and `be_tx_compl_clean()`, and EQs must be synchronized (`synchronize_irq()`) and cleaned (`be_eq_clean()`) before `be_irq_unregister()`. In `be_clear()`, `be_cancel_worker()` and `flush_workqueue(be_wq)` must precede `be_vf_clear()`, `be_if_destroy()`, `be_clear_queues()`, and `be_msix_disable()`. [F25, F26]
- In `be_probe()`, `be_map_pci_bars()`, `be_drv_init()`, and `be_setup()` must succeed before `register_netdev()`, `be_roce_dev_add()`, and `be_schedule_err_detection()`. In `be_remove()`, `be_roce_dev_remove()`, `be_intr_set(adapter, false)`, `be_cancel_err_detection()`, `unregister_netdev()`, and `be_clear()` must precede `be_cmd_fw_clean()`, `be_unmap_pci_bars()`, `be_drv_cleanup()`, and `free_netdev()`. [F32, F33]
- `be_post_rx_frags()` takes `GFP_ATOMIC` in `be_process_rx()` and `GFP_KERNEL` in process context; when `atomic_read(&rxq->used) == 0` after failing to post, it sets `rxo->rx_post_starved = true`, barring `be_process_rx()` from calling `be_post_rx_frags()` until `be_worker()` replenishes it. In `be_rx_compl_get()`, `be_tx_compl_get()`, and `events_get()`, `rmb()` must follow observing the valid bit before reading/swapping fields, and the valid bit must be zeroed before advancing tail. [F31, F130, F138]

## Object Lifetimes

- `be_xmit_enqueue()` unmaps partial fragments via `be_xmit_restore()` and returns `0` on DMA mapping failure without freeing `skb`, so `be_xmit()` must call `dev_kfree_skb_any(skb)` when it returns `0`. Conversely, `be_xmit_workarounds()`, `be_lancer_xmit_workarounds()`, and `be_insert_vlan_in_pkt()` free `skb` before returning `NULL`, so callers must not free `skb` on `NULL`. TX/completion paths must use `skb_share_check(skb, GFP_ATOMIC)`, `dev_kfree_skb_any()`, and `dev_consume_skb_any()`. [F1, F2, F139]
- In `be_setup_queues()`, `be_mcc_queues_create()` must follow `be_evt_queues_create()` and `be_tx_qs_create()` (MCC CQ shares `mcc_eqo(adapter)->q`), and `be_clear_queues()` must destroy MCC, RX CQ, and TX queues before `be_evt_queues_destroy()`. In `be_rx_qs_destroy()`, for each `q->created`, on `lancer_chip` first call `be_rx_cq_clean(rxo)` and (if `used == 0`) `be_post_rx_frags()`, then on all chips call `be_cmd_rxq_destroy()` and `be_rx_cq_clean()` before `be_rxq_clean()` and `be_queue_free()`. [F7, F8, F119]
- Every `get_rx_page_info()` consumer must clear `page_info->page = NULL` because `be_post_rx_frags()` stops at the first non-NULL slot; in `skb_fill_rx_data()` and `be_rx_compl_process_gro()`, any coalesced fragment (`page_offset != 0` after the first) merged via `skb_frag_size_add()` must call `put_page(page_info->page)`. In `be_tx_compl_process()`, `dev_consume_skb_any(skb)` must be called whenever a new `sent_skbs[txq->tail]` is encountered as well as after the loop. [F11, F12, F93]
- `be_msix_register()` must format the IRQ name into `eqo->desc` (not stack) and sets `irq_update_affinity_hint(vec, eqo->affinity_mask)`, which `be_irq_unregister()` must clear with `NULL` before `free_irq()` and `be_evt_queues_destroy()`. `be_drv_init()` 16-byte aligns `adapter->mbox_mem` from `adapter->mbox_mem_alloced`, so `be_drv_cleanup()` must pass `mbox_mem_alloced` to `dma_free_coherent()`. [F80, F109, F152]
- A PF must not call `be_cmd_reset_function()` outside error recovery when VFs are enabled (`pci_num_vf(pdev) > 0` in `be_reset_required()`, or `pci_vfs_assigned(pdev)` in `be_remove()`), nor reconfigure SR-IOV pool resources in `be_clear()` while VFs are assigned; in `be_func_init()`, `be_cmd_reset_function()` requires `msleep(100)` before `be_cmd_fw_init()`. In `be_eeh_err_detected()`, call `be_roce_dev_remove()`, set `BE_ERROR_EEH` before `be_cleanup()`, and `ssleep(30)` on `devfn == 0`. [F60, F118, F134]

## API Contracts

- `be_post_rx_frags()` maps each `big_page_size` page once with `dma_map_page()` and sets `last_frag = true` with `page_dmaaddr` only on the last fragment (`frag_dmaaddr` on earlier ones), so `get_rx_page_info()` calls `dma_unmap_page()` when `last_frag` is true and `dma_sync_single_for_cpu()` otherwise; doorbell writes via `be_rxq_notify()` must be chunked to at most `MAX_NUM_POST_ERX_DB` (255). [F72, F149]
- `be_xmit_enqueue()` maps linear data with `dma_map_single()` and paged frags with `skb_frag_dma_map()`, so `unmap_tx_frag()` must pass `unmap_single = true` only for the first data WRB when `skb_headlen(skb) > 0`. `be_tx_compl_process()` treats `last_index` as inclusive, so `be_tx_compl_clean()` must advance `end_idx` from `txq->tail` by `atomic_read(&txq->used) - 1`. [F68, F150]
- `be_vxlan_set_port()`/`be_vxlan_unset_port()` must keep `BE_FLAGS_VXLAN_OFFLOADS`, `adapter->vxlan_port`, and `netdev->hw_enc_features` in sync without modifying `hw_features`/`features`. In `be_features_check()`, strip `NETIF_F_CSUM_MASK | NETIF_F_GSO_MASK` from encapsulated packets unless UDP `ETH_P_TEB` matching `adapter->vxlan_port`; for GSO, clear `NETIF_F_TSO6` when `!skyhawk_chip(adapter) && is_ipv6_ext_hdr(skb)`, and `NETIF_F_GSO_MASK` on `lancer_chip` when `gso_size < 256` or `gso_segs == 1`. [F54, F153, F154, F155]
- NDO VF callbacks and `adapter->vf_cfg[vf]` use 0-based `vf` (`0 <= vf < num_vfs`, guarded by `sriov_enabled()`), whereas firmware commands take `0` for PF and `vf + 1` for VF (except `be_cmd_get_if_id()`, which takes 0-based `vf`). `be_cmd_set_hsw_config()` treats `0` as a no-op, so `be_clear_vf_tvt()` passes `BE_RESET_VLAN_TAG_ID` (`0xFFFF`) and `be_set_vf_spoofchk()` passes `ENABLE_MAC_SPOOFCHK`/`DISABLE_MAC_SPOOFCHK`. In `be_set_vf_tx_rate()`, `max_tx_rate == 0` must bypass link/bounds checks, and `max_tx_rate < 100 || max_tx_rate > link_speed` must precede `link_speed / 100`. [F48, F69, F88, F105]
- In `be_setup()`, on `!BEx_chip(adapter)`, `be_cmd_get_func_config(adapter, NULL)` must precede `be_get_config()` and `be_alloc_sriov_res()`. `be_msix()` and `be_intx()` expect `struct be_eq_obj *` as `dev_id` (`&adapter->eq_obj[0]` in INTx). In `be_poll()`, track `max_work = max(work, max_work)` across RX queues and call `napi_complete_done()` / re-arm EQ only when `max_work < budget`. [F110, F117, F162]

## Error Handling

- Firmware command helpers (`be_cmd_*`) return positive MCC completion codes as well as negative errnos, so kernel callbacks (`be_set_vf_*`, `be_pci_sriov_configure`) must convert non-zero `status` via `be_cmd_status(status)`. In `be_msix_enable()`, `num_vec` must be a signed `int`; on `num_vec < 0`, return `num_vec` when `be_virtfn(adapter)` is true and `0` on PFs to fall back to INTx. [F35, F36]
- In `be_process_rx()`, `rxcp->num_rcvd == 0` is a flush completion consuming no descriptors, whereas `rxcp->num_rcvd != 0 && rxcp->pkt_size == 0` must call `be_rx_compl_discard(rxo, rxcp)` to free `num_rcvd` RX fragments. In `be_mac_addr_set()`, a non-zero `be_dev_mac_add()` return only skips `be_dev_mac_del()`; success is determined via `be_cmd_get_active_mac()`. [F38, F73]
- In `be_tpe_recover()`, only `adapter->pf_num == 0` may enter `ERR_RECOVERY_ST_RESET` and call `be_soft_reset(adapter)` (after `ue_to_reset_time` and `be_err_is_recoverable()`), and every terminal failure branch or transition to `ERR_RECOVERY_ST_REINIT` must set `err_rec->resched_delay = 0`. In `be_detect_error()`, on `BE3_chip` ignore `ue_lo`/`ue_hi` unless `be_POST_stage_get()` matches `POST_STAGE_FAT_LOG_START`, `POST_STAGE_ARMFW_UE`, or `POST_STAGE_RECOVERABLE_ERR` via `(val & STAGE) == STAGE`. [F83, F87, F132, F170]

## External Contracts

- In `be_roce.c`, `be_adapter_list_lock` must be held across all accesses to `ocrdma_drv`, `be_adapter_list`, `adapter->entry`, and `adapter->ocrdma_dev` (including callbacks). `_be_roce_dev_add()` requires `ocrdma_drv->be_abi_version == BE_ROCE_ABI_VERSION` and `!(pdev->device == OC_DEVICE_ID5 && !msix_enabled(adapter))`, populates `dev_info.msix.vector_list` from `msix_entries[0]` with `start_vector = num_evt_qs`, and passes stack `&dev_info`. `_be_roce_dev_remove()` clears `adapter->ocrdma_dev = NULL`, and only `be_roce_dev_remove()` calls `list_del(&adapter->entry)`. [F15, F22, F42, F49, F89, F112, F123]
- `be_set_vf_tvt()` must clear guest VLANs on the VF and revoke `BE_PRIV_FILTMGMT` via `be_cmd_set_fn_privileges()`, and `be_clear_vf_tvt()` must restore `BE_PRIV_FILTMGMT`. In `be_probe()`, guard hwmon registration with `be_physfn(adapter) && IS_ENABLED(CONFIG_BE2NET_HWMON)`. [F156, F166]

## Known Pitfalls

- `be_insert_vlan_in_pkt()` calls `skb_share_check(skb, GFP_ATOMIC)` and `__vlan_hwaccel_clear_tag(skb)` before `vlan_insert_tag_set_proto()`, which can reallocate `skb->head`, so callers (`be_lancer_xmit_workarounds()`, `be_send_pkt_to_bmc()`) must re-fetch header pointers afterward. `be_xmit_workarounds()` pads `skb->len <= 32` via `skb_put_padto(skb, 36)` (which frees `skb` on error) and trims packets over `BE_MAX_GSO_SIZE`. [F114, F159, F161]
- Composite `BE_IF_FLAGS_ALL_PROMISCUOUS` must be tested with `(adapter->if_flags & BE_IF_FLAGS_ALL_PROMISCUOUS) == BE_IF_FLAGS_ALL_PROMISCUOUS`, and cleared from `adapter->if_flags` when `be_update_queues()` recreates `if_handle`. In `be_disable_if_filters()`, call `be_cmd_rx_filter(adapter, BE_IF_ALL_FILT_FLAGS, OFF)` only on `lancer_chip(adapter)`, and skip `be_dev_mac_del()` on BEx VFs without `BE_PRIV_FILTMGMT`. [F52, F82, F127]
- Convert `udp_hdr(*skb)->dest` in `be_send_pkt_to_bmc()` and `ip_hdr(skb)->tot_len` in `be_lancer_xmit_workarounds()` with `ntohs()`, whereas `adapter->vxlan_port` is `__be16`. Cast `le32_to_cpu(wrb->frag_pa_hi)` to `u64` before `<< 32` in `unmap_tx_frag()`. In `be_rx_compl_process_gro()` (`u16 j = -1`), keep `i == 0` in `if (i == 0 || page_info->page_offset == 0)` so `j` wraps to `0`. [F77, F91, F101]
