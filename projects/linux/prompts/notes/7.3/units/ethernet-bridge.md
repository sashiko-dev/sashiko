# ETHERNET BRIDGE

The Ethernet bridge subsystem (`net/bridge/`) implements the IEEE 802.1D/802.1Q virtual bridge device, port management, frame ingress/egress forwarding, unicast FDB, IGMP/MLD multicast snooping (MDB and Explicit Host Tracking), STP/MST state machines, ARP/ND proxy and neighbor suppression, MRP, CFM, bridge Netfilter (`br_netfilter`), RTNetlink/ioctl UAPIs, and switchdev hardware offload.

## Architecture & Data Flow
- Stack `struct br_ip`, `struct net_bridge_port_group_sg_key`, and `union net_bridge_eht_addr` keys must be zeroed with `memset()` before setting fields for `br->mdb_hash_tbl`, `br->sg_port_tbl`, or `br_multicast_eht_*_lookup()`, which hash or `memcmp()` the full struct size including padding and union tails. [F54, F128]
- `br_multicast_new_port_group()` inserts `p->rhnode` into `br->sg_port_tbl` only when `!br_multicast_is_star_g(group)`, so `br_multicast_del_pg()` and `br_multicast_del_port_group()` must guard `rhashtable_remove_fast(&br->sg_port_tbl, ...)` with `!br_multicast_is_star_g()`. [F5]
- Each MDB entry's `mp->ports` list (`br_mdb_add_group_sg()`, `br_mdb_add_group_star_g()`) and router port lists must remain sorted in descending order of `struct net_bridge_port *` pointer value so `br_multicast_flood()` can merge-scan `lport` and `rport` in one pass. [F262]
- When `(*, G)` `mp->host_joined` changes, `br_multicast_star_g_host_state()` must propagate it to installed (`BR_SGRP_F_INSTALLED`) `(S, G)` entries, and `br_multicast_sg_host_state()` must copy `star_mp->host_joined` to new `(S, G)` entries. When `br_multicast_should_handle_mode()` holds, `br_mdb_add_group_sg()` must call `br_multicast_sg_add_exclude_ports()`, and `br_mdb_add_group_star_g()` / `br_mdb_replace_group_star_g()` must call `br_multicast_star_g_handle_mode()`. [F73, F241]
- In `br_multicast.c`, `struct net_bridge_mcast_port *pmctx` is `NULL` for bridge/host-originated packets and must be checked before dereferencing `pmctx->port`. `pmctx->vlan` and `brmctx->vlan` are `NULL` for non-VLAN contexts and must only be dereferenced after `br_multicast_port_ctx_is_vlan(pmctx)` or `br_multicast_ctx_is_vlan(brmctx)` (including in `br_multicast_ctx_vlan_global_disabled()`). [F47, F48, F104]
- Whenever `BROPT_MULTICAST_ENABLED` changes after init (including auto-disable in `br_multicast_new_group()` and `br_multicast_toggle()`), `br_mc_disabled_update()` must be called. In `br_multicast_toggle_vlan()`, if `br_vlan_is_brentry(vlan)` holds, `br_multicast_toggle_one_vlan(vlan, on)` must also be called on the master VLAN. [F65, F66]
- Master `struct net_bridge_vlan` entries in `vg->vlan_list` without `BRIDGE_VLAN_INFO_BRENTRY` are context-only placeholders; active VLAN walks must skip `!br_vlan_should_use(v)`. `__get_num_vlan_infos()` and `br_fill_ifvlaninfo_compressed()` must use identical `br_vlan_should_use(v)` filtering and range-coalescing logic. [F46, F114]
- Static FDB MACs are refcounted in non-promiscuous ports via `dev_uc_add()`/`dev_uc_del()` only when `BR_FDB_STATIC` transitions (`fdb_add_hw_addr()`/`fdb_del_hw_addr()`); in `br_add_if()`, if `nbp_update_port_count()` leaves `!br_promisc_port(p)` and `IFF_UNICAST_FLT` is set, `br_fdb_sync_static()` must be called (and undone with `br_fdb_unsync_static()` on error). `br->fdb_n_learned` is incremented in `fdb_create()` after `rhashtable_lookup_insert_fast()` succeeds and decremented only when `test_and_clear_bit(BR_FDB_DYNAMIC_LEARNED, &fdb->flags)` succeeds. [F176, F177, F223]
- Forwarding helpers (`br_allowed_ingress()`, `br_forward()`, `br_flood()`, `br_multicast_flood()`, `__br_forward()`) require `skb->data` to sit `ETH_HLEN` bytes past `skb_mac_header(skb)` (`br_dev_xmit()` pulls `ETH_HLEN`; `br_dev_queue_push_xmit()` pushes `ETH_HLEN` and updates `skb_set_network_header(skb, depth)` on `CHECKSUM_PARTIAL` VLAN frames). In `__br_forward()`, `nbp_switchdev_frame_mark_tx_fwd_offload()` must precede `br_handle_vlan()`; `br_pass_frame_up()` and `br_dev_xmit()` must call `br_switchdev_frame_unmark(skb)`; and `br_netif_receive_skb()` and `br_dev_queue_push_xmit()` must call `br_drop_fake_rtable(skb)`. [F234, F307, F310, F311, F312]
- `br_handle_frame()` and `br_dev_xmit()` must zero `skb->cb` before using `BR_INPUT_SKB_CB(skb)`, and `br_handle_frame_finish()` and `br_dev_xmit()` must test `is_broadcast_ether_addr()` before or inside `is_multicast_ether_addr()`.Every netlink attribute emitted by `fdb_fill_info()`, `br_fill_ifinfo()`, `br_port_fill_attrs()`, `br_fill_info()`, and `br_multicast_dump_querier_state()` must be accounted for in `fdb_nlmsg_size()`, `br_nlmsg_size()`, `br_port_info_size()`, `br_get_size()`, and `br_multicast_querier_state_size()` (using `nla_total_size(0)` rather than `sizeof(0)` for empty nests). [F127, F163, F255, F257, F258]

## Synchronization
- `br->lock` nests outside both `br->hash_lock` and `br->multicast_lock`, so code holding `br->hash_lock` or `br->multicast_lock` must never acquire `br->lock`. Process/workqueue paths acquiring `br->lock`, `br->multicast_lock`, or `br->hash_lock` must use `spin_lock_bh()`/`spin_unlock_bh()`; `br_fdb_update()` uses bare `spin_lock(&br->hash_lock)` and requires process-context callers to wrap it in `local_bh_disable()` and `rcu_read_lock()`. [F136, F137, F290, F291]
- Synchronous timer/work cancellations (`timer_delete_sync()`, `cancel_delayed_work_sync()` in `br_stp_disable_bridge()`, `__br_multicast_stop()`, `br_multicast_port_ctx_deinit()`) and `br_multicast_join_snoopers()` / `br_multicast_leave_snoopers()` in `br_multicast_toggle()` must be called outside `br->lock` and `br->multicast_lock`. [F18, F143]
- All callers of `br_ip4_multicast_mark_router()`, `br_ip6_multicast_mark_router()`, `br_ip4_multicast_add_router()`, and `br_ip6_multicast_add_router()` must hold `br->multicast_lock`. In `br_mdb_get()`, `spin_lock_bh(&br->multicast_lock)` must be held across both `br_mdb_get_reply_alloc()` (`GFP_ATOMIC`) and `br_mdb_get_reply_fill()`. [F26, F294]
- In `br_ip4_multicast_igmp3_report()` and `br_ip6_multicast_mld2_report()`, after `br_ip4_multicast_add_group()` or `br_ip6_multicast_add_group()` drops and re-acquires `br->multicast_lock`, the code must revalidate `br_multicast_ctx_should_use(brmctx, pmctx)`, re-lookup `mdst` and `pg`, and check `!(pg->flags & MDB_PG_FLAGS_PERMANENT)`. [F29]
- In multicast expiration timers (`br_multicast_group_expired()`, `br_multicast_port_group_expired()`, `br_multicast_eht_set*_expired()`), after acquiring `br->multicast_lock`, the callback must verify `!hlist_unhashed()` / `!RB_EMPTY_NODE()` and `!timer_pending()`. Similarly, `br_message_age_timer_expired()` must recheck `p->state == BR_STATE_DISABLED` under `br->lock`, and `br_fdb_cleanup()` / `br_fdb_flush()` must verify `!hlist_unhashed(&f->fdb_node)` under `br->hash_lock`. [F30, F36, F197]
- Paths dereferencing VLAN groups or `p->backup_port` without `rtnl_lock` (`br_multicast_pg_to_port_ctx()`, `br_multicast_port_vid_to_port_ctx()`, `br_multicast_start_querier()`, `br_fill_ifinfo()`, `br_port_fill_attrs()`) must hold `rcu_read_lock()` and use `nbp_vlan_group_rcu()`, `br_vlan_group_rcu()`, or `rcu_dereference(p->backup_port)` (rechecking `rcu_dereference(to->backup_port)` for `NULL` in `br_forward()`). [F138, F140, F198]
- In `fdb_create()`, all fields must be initialized before `rhashtable_lookup_insert_fast()` and `hlist_add_head_rcu()` publish the entry, and RCU readers of `fdb->dst` (`fdb_fill_info()`, `__fdb_flush_matches()`, `br_fdb_test_addr()`, `br_fill_forward_path()`) must load `READ_ONCE(fdb->dst)` into a local variable and null-check it. `IFF_BRIDGE_PORT` must be set only after `netdev_rx_handler_register()` succeeds in `br_add_if()` and cleared before `netdev_rx_handler_unregister()` in `del_nbp()`. [F186, F188, F199, F280]
- `br_info_notify()`, `fdb_notify()`, `__br_mdb_notify()`, `br_rtr_notify()`, and `br_multicast_list_adjacent()` run under spinlocks or RCU and must use `GFP_ATOMIC`. In `br_ioctl.c`, `br_fdb_fillbuf()` and `br_dev_siocdevprivate()` must call `rcu_read_unlock()` before `copy_to_user()`. [F146, F295, F296]

## Object Lifetimes
- Multicast entries removed under `br->multicast_lock` must mark their node unhashed (`hlist_del_init*()` or `RB_CLEAR_NODE()`) and defer `timer_shutdown_sync()` and freeing to `br->mcast_gc_list`. `br_multicast_del_port()` must call `flush_work(&br->mcast_gc_work)` before deinitializing `port->multicast_ctx` and freeing `port->mcast_stats`, and `br_multicast_dev_del()` must drain `mcast_gc_list`, call `cancel_work_sync(&br->mcast_gc_work)`, and call `rcu_barrier()`. [F6, F10]
- In `br_multicast_toin()` and `br_multicast_block()`, when `br_multicast_find_del_pg()` deletes `pg`, the function must set `changed = false` and not access `pg` afterward. In `br_multicast_del_eht_host()`, `eht_host` must not be dereferenced after `hlist_for_each_entry_safe()` because `__eht_del_set_entry()` frees `eht_host` when `set_entries` becomes empty. [F77, F110]
- In `br_add_if()`, errors before `kobject_init_and_add(&p->kobj, ...)` must `kfree(p)` after `netdev_put()`, whereas errors at or after `kobject_init_and_add()` must use `kobject_put(&p->kobj)` and never `kfree(p)`. `del_nbp()` must detach the port under RTNL (including `nbp_backup_clear()`) before deferring `destroy_nbp_rcu` via `call_rcu()`. [F170, F171, F178]
- `struct nf_bridge_info` records the ingress port by `physinif` in `setup_pre_routing()`, and resume callbacks (`br_nf_pre_routing_finish*`, `br_nf_forward_finish`) must resolve it via `nf_bridge_get_physindev()` and free `skb` if `NULL`. `ip_sabotage_in()` must set `nf_bridge->sabotage_in_done = 1` rather than calling `nf_bridge_info_free(skb)`, preserving `SKB_EXT_BRIDGE_NF` until `br_nf_dev_queue_xmit()` or `br_nf_push_frag_xmit()`. [F2, F3]
- In `br_nf_local_in()`, packets with `BR_INPUT_SKB_CB(skb)->promisc` or non-`PACKET_HOST` packets with a shared unconfirmed conntrack (`refcount_read(&nfct->use) != 1`) must call `nf_reset_ct(skb)` instead of confirming. Local `nfct`/`ct` pointers must not be dereferenced after `ct_hook->confirm(skb)`, and if `confirm(skb)` returns `NF_STOLEN`, `br_nf_local_in()` must return `NF_STOLEN` immediately without touching `skb`. [F14, F62, F151, F152]

## API Contracts
- `br_forward()`, `br_flood()`, and `br_multicast_flood()` consume or free `skb` on all paths when `local_rcv` is false, and never when `local_rcv` is true. Unlike `br_allowed_ingress()` and `br_handle_vlan()` (which free `skb` on failure), `br_multicast_rcv()` does not free `skb` on error, so callers (`br_dev_xmit()`, `br_handle_frame_finish()`) must free it. `br_stp_rcv()` must release `br->lock` (if held) and `kfree_skb(skb)` on all exit paths. [F19, F173, F175]
- `br_multicast_new_group()` and `new_nbp()` return `ERR_PTR` on failure (never `NULL`), whereas `br_multicast_new_port_group()` and `br_multicast_new_group_src()` return `NULL` (never `ERR_PTR`). `__br_multicast_add_group()` returns `ERR_PTR` on error, `NULL` when disabled or `!pmctx`, or a valid pointer. `maybe_deliver()` can return `ERR_PTR(err)`, so flood loops must check `IS_ERR(prev)` on every iteration. [F41, F42, F203, F204]
- RCU paths on arbitrary devices must use `br_port_get_check_rcu(dev)` or check `netif_is_bridge_port(dev)` before `br_port_get_rcu(dev)`, and exported functions/notifiers taking `struct net_device *` (`br_device_event()`, `br_fdb_find_port()`, `br_mst_enabled()`, `br_mst_get_info()`, `br_del_bridge()`, `br_ioctl_stub()`, `br_multicast_enabled()`, `br_multicast_router()`) must check `netif_is_bridge_master(dev)` before `netdev_priv(dev)`. `br_switchdev_event()` runs in atomic context and must use `br_port_get_rtnl_rcu(dev)` without sleeping. [F132, F133, F281, F299]
- `br_do_proxy_suppress_arp()`, `br_do_suppress_nd()`, and their callees accept a nullable `struct net_bridge_port *p` (`NULL` from `br_dev_xmit()`) and must null-check `p`. `br_multicast_ctx_should_use()` must check `!br_multicast_port_ctx_state_disabled(pmctx)` when `pmctx` is non-NULL and only check `!br_multicast_ctx_vlan_disabled(brmctx)` when `pmctx` is `NULL`. [F105, F214]
- Bitops on `fdb->flags` and `br_opt_get()` / `br_opt_toggle()` take unshifted `BR_FDB_*` or `BROPT_*` bit indices, whereas `fdb_create()`, `br_fdb_update()`, `br_port_flag_is_set()`, and `br_port_flags_change()` take shifted `BIT(...)` / `BR_*` bitmasks. `br_vlan_add()` and `nbp_vlan_add()` must set `*changed = false` before any return, and `br_cfm_*mep_count()` must set `*count = 0` even on `-EOPNOTSUPP`. [F56, F57, F219, F220]
- In `br_nf_pre_routing_finish*()`, `br_nf_forward_finish()`, and `br_nf_dev_queue_xmit()`, `nf_bridge_update_protocol(skb)` must precede `nf_bridge_push_encap_header(skb)`. `br_nf_forward_ip()` must call `nf_bridge_unshare(skb)` and reload `nf_bridge` before mutating it, and `br_nf_push_frag_xmit()` must call `skb_cow_head(skb, data->size)` before writing `data->mac`. [F68, F153, F155]

## Error Handling
- `-EOPNOTSUPP` from `switchdev_port_attr_set()` (in `br_set_state()`, `__set_ageing_time()`, `br_multicast_add_port()`, `br_multicast_toggle()`, and `br_mst_*()`) must be ignored and treated as success. In `br_multicast_ipv4_rcv()` and `br_multicast_ipv6_rcv()`, `-ENOMSG` / `-ENODATA` from `ip_mc_check_igmp()` / `ipv6_mc_check_mld()` must return `0` without calling `br_multicast_err_count()`. `br_nf_dev_queue_xmit()` must check `skb_valid_dst(skb)` before fragmenting. [F43, F44, F50, F206]
- In `br_multicast_create_eht_set_entry()`, error cleanup must only destroy `eht_host` if `hlist_empty(&eht_host->set_entries)` and only delete `eht_set` if `RB_EMPTY_ROOT(&eht_set->entry_tree)`. In `br_mdb_add_group_srcs()` and `br_mdb_replace_group_srcs()`, failure at signed index `i` must roll back `0..i-1` (`for (i--; i >= 0; i--)`) and clear `BR_SGRP_F_DELETE` on `pg->src_list`. [F7, F180, F250]

## Known Pitfalls
- SKB header pointers (`eth_hdr()`, `arp_hdr()`, `ipv6_hdr()`, `ip_hdr()`, `grec`, `buf`) must be reloaded after `pskb_may_pull()`, `ip_mc_may_pull()`, `ipv6_mc_may_pull()`, `br_allowed_ingress()`, `br_do_proxy_suppress_arp()`, or `br_do_suppress_nd()`; `br_mdb.c` must call `is_valid_mdb_source()` before reading source attributes. [F85, F87, F130, F232, F247, F249]
- In `br_setlink()`, `br_dellink()`, `br_afspec()`, `br_vlan_info()`, `br_process_vlan_info()`, `br_process_vlan_tunnel_info()`, and `br_info_notify()`, `p->br` must be used instead of `br` whenever `p` is non-NULL. Similarly, `br_multicast_rcv()` must branch on `br_vlan_is_master(vlan)` (`vlan` vs `vlan->brvlan`), and port MST VLAN walks must read `v->brvlan->msti`. [F106, F131, F270]
- Jiffies deadline comparisons in FDB/CFM/MRP expiration and multicast timer shortening must use `time_before_eq()` or `time_after()`, and `bridge_mcast_other_query` delay windows must use `timer_pending(&querier->delay_timer)`. `br_mtu_auto_adjust()` must clear `BROPT_MTU_SET_BY_USER` after `dev_set_mtu()`, and `maybe_deliver_addr()` must wrap `pskb_copy()` in `__skb_push(skb, ETH_HLEN)` and `__skb_pull(..., ETH_HLEN)`. [F119, F125, F228, F273, F308]
