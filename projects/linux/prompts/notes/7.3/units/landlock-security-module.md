# LANDLOCK SECURITY MODULE

The Landlock Linux Security Module (LSM) enables unprivileged tasks to sandbox themselves by creating rulesets (`landlock_create_ruleset`), populating rules for filesystem hierarchies and TCP ports (`landlock_add_rule`), and stacking immutable domains onto their own credentials (`landlock_restrict_self`). It enforces access control and IPC scoping across VFS paths, open files, device ioctls, TCP sockets, abstract UNIX sockets, signals, and ptrace via LSM hooks, while recording audit events for domain lifecycles and denials. The component also includes the core VFS `ioctl` syscall dispatcher (`fs/ioctl.c`), whose generic file/superblock commands are closely coupled with Landlock's device ioctl filtering (`is_masked_device_ioctl`).

## Architecture & Data Flow

- `union landlock_key` stores either `struct landlock_object *` (`object`) or `uintptr_t` (`data`) without an internal tag; `key.object` must only be dereferenced or passed to `landlock_get_object()` / `landlock_put_object()` when `is_object_pointer(key_type)` is true (`LANDLOCK_KEY_INODE`). Every `enum landlock_key_type` dispatch in `security/landlock/ruleset.c` (`is_object_pointer()`, `get_root()`, `merge_ruleset()`, `inherit_ruleset()`, `free_ruleset()`, `landlock_init_layer_masks()`) must handle all enabled key types in lockstep, guarding `LANDLOCK_KEY_NET_PORT` with `#if IS_ENABLED(CONFIG_INET)`. [F29, F61]
- `landlock_upgrade_handled_access_masks()` must OR `_LANDLOCK_ACCESS_FS_INITIALLY_DENIED` (`LANDLOCK_ACCESS_FS_REFER`) into `access_masks.fs` only when `access_masks.fs` is non-zero, whereas `landlock_get_fs_access_mask()` unconditionally ORs `_LANDLOCK_ACCESS_FS_INITIALLY_DENIED`. `add_rule_path_beneath()` must validate `path_beneath_attr.allowed_access` against `ruleset->access_masks[0].fs` directly, while `landlock_append_fs_rule()` must OR in `LANDLOCK_MASK_ACCESS_FS & ~landlock_get_fs_access_mask(ruleset, 0)` so `LANDLOCK_ACCESS_FS_REFER` is never implicitly granted. [F53, F54]
- Operations on already-opened files (`hook_file_truncate`, `hook_file_ioctl_common`, `hook_file_send_sigiotask`) must authorize access and attribute audit records using the credentials and masks cached on `struct landlock_file_security` (`file->f_cred`, `allowed_access`, `deny_masks`, `fown_subject`) rather than `current_cred()`. In `hook_file_open()`, `landlock_file(file)->deny_masks` must be updated in lockstep with `allowed_access` via `landlock_get_deny_masks()` for `_LANDLOCK_ACCESS_FS_OPTIONAL`. [F45, F142]
- `get_layer_deny_mask()` and `get_layer_from_deny_masks()` must pack and unpack `deny_masks_t` using the exact same bit-index ordering over `_LANDLOCK_ACCESS_FS_OPTIONAL` and 4-bit width (`HWEIGHT(LANDLOCK_MAX_NUM_LAYERS - 1)`), with each entry storing the 0-based youngest denying layer (`__fls(mask)`). [F46]
- `hook_file_ioctl_common()` must check `is_device(file)` and return 0 for non-device files even when `LANDLOCK_ACCESS_FS_IOCTL_DEV` is not set in `landlock_file(file)->allowed_access`, because `hook_file_open()` only requests `LANDLOCK_ACCESS_FS_IOCTL_DEV` in `optional_access` when `is_device(file)` is true. [F83]
- `is_masked_device_ioctl()` and `is_masked_device_ioctl_compat()` in `security/landlock/fs.c` must classify every command handled in `do_vfs_ioctl()` and `compat_sys_ioctl` (`fs/ioctl.c`) identically between native and compat modes, including `CONFIG_X86_64` `FS_IOC_*_32` preallocation commands and `FS_IOC32_GETFLAGS`/`FS_IOC32_SETFLAGS`. [F130]
- In `is_access_to_paths_allowed()`, when a dual-path refer check (`is_dom_check == true`) satisfies `no_more_access()`, it must clear `is_dom_check = false`, downgrade `access_masked_parent1` and `access_masked_parent2` to the requested masks, and call `scope_to_request()` on both `layer_masks_parent1` and `layer_masks_parent2`. [F57]
- When `is_access_to_paths_allowed()` fails for a cross-directory refer in `current_check_refer_path()`, `request1.audit.u.path.dentry` must be overwritten with `old_parent` and `request2.audit.u.path.dentry` with `new_dir->dentry` before calling `landlock_log_denial()`, because `is_access_to_paths_allowed()` walked from `&mnt_dir`. [F93]
- `get_path_from_fd()` must reject ruleset FDs (`f_op == &ruleset_fops`), `MNT_INTERNAL` mounts, `SB_NOUSER` superblocks, and `IS_PRIVATE` inodes with `-EBADFD` when adding rules, whereas path enforcement (`is_access_to_paths_allowed()`) must unconditionally allow `SB_NOUSER`/`IS_PRIVATE` dentries and disconnected `MNT_INTERNAL` roots. [F146]
- In `sys_landlock_restrict_self()`, `prev_log_subdomains = !new_llcred->log_subdomains_off` must be sampled before `new_llcred->log_subdomains_off` is updated, and `new_dom->hierarchy->log_status` must check `!prev_log_subdomains` so `LANDLOCK_RESTRICT_SELF_LOG_SUBDOMAINS_OFF` only disables logging for future nested domains. It must also set `BIT(new_dom->num_layers - 1)` in `new_llcred->domain_exec`, while `hook_bprm_creds_for_exec()` resets `landlock_cred(bprm->cred)->domain_exec = 0` on `execve()`. [F48, F49]
- In both `hook_ptrace_access_check()` and `hook_ptrace_traceme()`, `domain_ptrace()` must be called with the tracer's domain first (`parent`) and the tracee's domain second (`child`), and `landlock_log_denial()` must attribute the denial to the tracer's `parent_subject` with `audit.u.tsk` set to the tracee. [F94]
- `current_check_access_socket()` must verify `addrlen >= offsetofend(typeof(*address), sa_family)` before reading `address->sa_family`, `addrlen >= sizeof(struct sockaddr_in)` for `AF_UNSPEC`/`AF_INET`, and `addrlen >= SIN6_LEN_RFC2133` for `AF_INET6`, while `is_abstract_socket()` must check `addr->len >= offsetof(struct sockaddr_un, sun_path) + 1`. [F72]
- `landlock_errata_init[]` must end with a zero-initialized `{}` sentinel entry and every `LANDLOCK_ERRATUM(NUMBER)` entry must use a unique 1-based `number` (`>= 1`) with `abi <= landlock_abi_version`, because `compute_errata()` loops while `landlock_errata_init[i].number` is non-zero and sets `BIT(landlock_errata_init[i].number - 1)`. [F75]
- In `ioctl_file_dedupe_range()`, after `memdup_user()` copies the variable-length `struct file_dedupe_range` using the `size` computed from `count`, `same->dest_count` must be overwritten with the validated `count` before calling `vfs_dedupe_file_range()` so a concurrent userspace modification cannot cause an out-of-bounds read of `same->info`. [F62]

## Synchronization

- `get_inode_object()` must look up `inode_sec->object` under `rcu_read_lock()` using `rcu_dereference()` and `refcount_inc_not_zero(&object->usage)` (spinning on `object->lock` and retrying if zero), and when installing a new object under `inode->i_lock` must recheck `rcu_access_pointer(inode_sec->object)` and publish it with `rcu_assign_pointer()`. Every jump to `retry:` must be entered with `rcu_read_lock()` held, including the race path after `spin_unlock(&inode->i_lock)` and `kfree(new_object)`. [F90, F127]
- Both `release_inode()` (invoked by `landlock_put_object()` with `object->lock` held) and `hook_sb_delete()` must clear `object->underobj = NULL` under `object->lock` before clearing `landlock_inode(inode)->object` with `rcu_assign_pointer(..., NULL)` and unlocking `object->lock`. `release_inode()` must increment `landlock_superblock(sb)->inode_refs` before unlocking `object->lock` and decrement it with a conditional `wake_up_var()` only after `iput(inode)` completes, so `hook_sb_delete()` waits via `wait_var_event()` for all in-flight `iput()` calls. [F1, F15, F50]
- `landlock_log_denial()` and `log_domain()` must allocate audit buffers with `GFP_ATOMIC | __GFP_NOWARN` in `audit_log_start()`, because `landlock_log_denial()` is invoked while holding RCU read locks or spinlocks (`hook_ptrace_traceme`, `hook_unix_stream_connect`, `hook_unix_may_send`, `hook_file_send_sigiotask`). [F117]
- Once a domain is published via `commit_creds()`, `hierarchy->log_status` must be accessed with `READ_ONCE()`/`WRITE_ONCE()`, and `log_domain()` must set `LANDLOCK_LOG_RECORDED` only after emitting the `status=allocated` audit record so `landlock_log_drop_domain()` only logs deallocation for previously logged domains. [F23]
- In `security/landlock/task.c`, abstract UNIX socket scoping (`sock_is_scoped()`) must resolve the peer socket's domain from `other->sk_socket->file->f_cred` while holding `unix_sk(other)->lock`, and `hook_unix_may_send()` must allow datagram sends when `unix_peer(sock->sk) == other->sk`. [F140]
- `init_id()` in `security/landlock/id.c` must initialize `next_id` to `BIT_ULL(32) + random_32bits` (so every domain ID is strictly greater than `U32_MAX`) using `atomic64_cmpxchg(counter, COUNTER_PRE_INIT, init)` so an already-initialized counter is never overwritten. [F24, F100]
- Modifying `filp->f_flags` in `ioctl_fionbio()` (`fs/ioctl.c`) must be protected by holding `filp->f_lock`. [F25]

## Object Lifetimes

- In `landlock_put_object()`, dropping the final `object->usage` reference must use `refcount_dec_and_lock(&object->usage, &object->lock)`, invoke `object->underops->release(object)` (which unlocks `object->lock`) before touching `object->rcu_free`, and free `object` via `kfree_rcu(object, rcu_free)`, because `rcu_free` and `underops` share an anonymous union in `struct landlock_object`. [F2, F17]

## API Contracts

- `get_layer_deny_mask()` and `get_blocker()` require `access_bit` to be a 0-based bit position (from `BIT_INDEX()` or `for_each_set_bit()`, or `(unsigned long)-1` in `get_blocker()` for non-bitmask request types) rather than a shifted `LANDLOCK_ACCESS_*` mask. [F33]
- `landlock_merge_ruleset()` and `landlock_init_hierarchy_log()` must only be called in process context when `current`'s subjective credentials are not overridden, because `get_current_details()` records `current_uid()` for domain audit attribution. [F122]
- `fiemap_fill_next_extent()` takes `logical`, `phys`, and `len` in bytes, zeroes `struct fiemap_extent` before `copy_to_user()` (unless `fi_extents_max == 0`), and returns 0 to continue, 1 when `FIEMAP_EXTENT_LAST` is set or `fi_extents_mapped` reaches `fi_extents_max`, or `-EFAULT` on copy failure. Broken by: propagating a positive 1 return as an ioctl error, passing block counts instead of bytes, or omitting `memset(&extent, 0, sizeof(extent))`. [F38]
- Filesystem `->fiemap` implementations must call `fiemap_prep()` to reject `*len == 0` (`-EINVAL`) and `start >= maxbytes` (`-EFBIG`), clamp `*len` to `maxbytes - start` without unsigned wraparound (`*len > maxbytes || (maxbytes - *len) < start`), and on unsupported flags write `incompat_flags` into `fieinfo->fi_flags` and return `-EBADR`. `ioctl_fiemap()` must bound `fm_extent_count` to `FIEMAP_MAX_EXTENTS` and still copy `fieinfo.fi_flags` and `fieinfo.fi_extents_mapped` to `ufiemap` while preserving a non-zero error from `->fiemap()`. [F39, F64]
- `compat_ptr_ioctl()` and the default `do_vfs_ioctl()` path in `COMPAT_SYSCALL_DEFINE3(ioctl)` apply `compat_ptr(arg)` and must only be used for ioctl commands that ignore `arg` or take a layout-compatible pointer, requiring integer-argument commands like `FICLONE` and misaligned structs like `struct space_resv_32` to be handled separately. [F65]

## Error Handling

- `vfs_ioctl()` and `COMPAT_SYSCALL_DEFINE3(ioctl)` must translate `-ENOIOCTLCMD` from `unlocked_ioctl` or `compat_ioctl` into `-ENOTTY`, and `ioctl_fioasync()` must clamp non-negative returns from `filp->f_op->fasync()` to 0 (`error < 0 ? error : 0`), so internal VFS statuses never leak to userspace. [F40]
- In `ioctl_file_dedupe_range()`, when `memdup_user()` fails and returns an `ERR_PTR`, `same` must be reset to `NULL` after saving `ret = PTR_ERR(same)` and before jumping to `out:`, because the `out:` cleanup path unconditionally calls `kfree(same)`. [F41]

## External Contracts

- Landlock UAPI attribute structs (`landlock_ruleset_attr`, `landlock_path_beneath_attr`, `landlock_net_port_attr`) must have no internal or trailing padding (`__attribute__((packed))` when fields are not 64-bit aligned) as checked by `build_check_abi()`, and extensible structs must be copied via `copy_min_struct_from_user()`. In `sys_landlock_create_ruleset()`, `add_rule_path_beneath()`, and `add_rule_net_port()`, 64-bit UAPI fields (`handled_access_fs`, `handled_access_net`, `scoped`, `allowed_access`, `port`) must be validated against their full 64-bit masks or `U16_MAX` before truncation to 16-bit `access_mask_t` or `u16`. [F76, F95]
- When reparenting is denied in `current_check_refer_path()`, it must check `is_eacces()` on both parent layer masks (which tests denied bits in `access_request & ~LANDLOCK_ACCESS_FS_REFER`) and return `-EACCES` before returning `-EXDEV`, so missing creation or removal rights take precedence over refer denials. [F36]
- Signal scoping in `hook_task_kill()` (when `cred == NULL`) and `control_current_fowner()` (called by `hook_file_set_fowner()`) must check `same_thread_group(p, current)` (under `rcu_read_lock()` when resolving `fown->pid` via `pid_task()`) and always allow signals between threads of the same process. [F141]
- In `do_vfs_ioctl()`, ioctl commands valid on both regular and non-regular files such as `FIONREAD` must have an explicit case before the `S_ISREG(inode->i_mode) && !IS_ANON_FILE(inode)`-gated default branch that calls `file_ioctl()`, and `FIGETBSZ` must verify `inode->i_sb->s_blocksize != 0` (`-EINVAL`) before `put_user()`. [F42, F81]

## Known Pitfalls

- Because `for_each_set_bit()` and `for_each_clear_bit()` read `unsigned long` words from their bitmap pointer, functions iterating over a 16-bit `access_mask_t` (`landlock_unmask_layers()`, `landlock_init_layer_masks()`, `scope_to_request()`, `log_blockers()`) must copy the mask into an `unsigned long` local variable before passing its address. Broken by: passing `&access_request` of type `access_mask_t *` directly, causing an out-of-bounds stack read. [F68]
- In `get_inode_object()`, if `rcu_access_pointer(inode_sec->object)` is found non-NULL after acquiring `inode->i_lock`, the unpublished `new_object` must be freed directly with `kfree(new_object)` rather than `landlock_put_object(new_object)`. [F5]
- Callers of `collect_domain_accesses()` and `is_access_to_paths_allowed()` (such as `current_check_refer_path()`) must zero-initialize `layer_masks_dom` and `struct landlock_request` (`= {}`), because `is_nouser_or_private(dir)` early returns skip `landlock_init_layer_masks()`, and `is_access_to_paths_allowed()` only populates `log_request_parent1` or `log_request_parent2` when that specific parent is denied. [F27, F28]
- In `create_rule()`, `new_rule` must be allocated for `new_num_layers` elements and have `new_rule->num_layers` set to `new_num_layers` before `memcpy()`, while `memcpy()` must copy only `flex_array_size(new_rule, layers, num_layers)` bytes from `layers` before assigning `new_rule->layers[new_rule->num_layers - 1]`. [F107]
- LSM blob accessors (`landlock_cred()`, `landlock_file()`, `landlock_inode()`, `landlock_superblock()`, and `hook_inode_free_security_rcu()`) must add `landlock_blob_sizes.lbs_*` to the `void *` security pointer before casting to the Landlock blob struct pointer so that the offset is scaled in bytes rather than by the struct size. [F109]
- In `log_domain()`, task-controlled strings (`hierarchy->details->exe_path` and `hierarchy->details->comm`) must be logged via `audit_log_untrustedstring()` rather than `audit_log_format()` with `%s`. [F114]
- In `ioctl_fibmap()`, the signed `int ur_block` read from user space must be checked for `ur_block < 0` before widening to `sector_t block`, and the resulting `sector_t block` from `bmap()` must be checked for `block > INT_MAX` (returning `-ERANGE`) before narrowing back to `int ur_block`. [F104]
