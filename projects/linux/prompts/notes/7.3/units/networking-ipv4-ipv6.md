# NETWORKING [IPv4/IPv6]

Implements the core TCP receive engine (`tcp_input.c`), IPv4 TCP protocol glue (`tcp_ipv4.c`), TIME-WAIT and SYN-RECV minisock state machines (`tcp_minisocks.c`), destination peer TCP metrics cache (`tcp_metrics.c`), TCPv4 GSO/GRO offload handlers (`tcp_offload.c`), and the Illinois and NV congestion control modules. It handles incoming TCP segments, header/option parsing (including SACK, timestamps, Fast Open, MD5, and TCP-AO), ACK processing, loss recovery, socket lookup/creation, and `/proc/net/tcp` and BPF iterator introspection.
Implements the core IPv6 protocol family (`af_inet6.c`), interface address autoconfiguration, SLAAC, and Duplicate Address Detection (`addrconf.c`, `addrconf_core.c`), RFC 6724 source address selection labels (`addrlabel.c`), anycast group management (`anycast.c`), UDP/RAW datagram socket helpers and control message processing (`datagram.c`), IPv6 extension header parsing and construction (`exthdrs.c`, `exthdrs_core.c`, `exthdrs_offload.c`), policy routing rules (`fib6_rules.c`, `fib6_notifier.c`), and FOU/GUE encapsulation over IPv6 (`fou6.c`).
Implements the IPv6 input and output packet pipelines (`ip6_input.c`, `ip6_output.c`, `ip6_offload.c`, `ip6_checksum.c`), the IPv6 Forwarding Information Database radix tree (`ip6_fib.c`), ICMPv6 reception and transmission (`icmp.c`, `ip6_icmp.c`), IPv6 Flow Label management (`ip6_flowlabel.c`), GRE/ERSPAN over IPv6 virtual tunnel devices (`ip6_gre.c`), In-situ Operations, Administration, and Maintenance (`ioam6.c`, `ioam6_iptunnel.c`), and Identifier-Locator Addressing (`ila/*`).
Implements IPv6-in-IPv6 and IPv4-in-IPv6 generic tunneling (`ip6_tunnel.c`), IPv6 UDP tunnel helpers (`ip6_udp_tunnel.c`), IPv6 Multicast Routing and PIMv6 (`ip6mr.c`), IPv6 socket options (`ipv6_sockglue.c`), Multicast Listener Discovery MLDv1/MLDv2 and multicast group management (`mcast.c`, `mcast_snoop.c`), Mobile IPv6 extension headers and XFRM state (`mip6.c`), and IPv6 Neighbour Discovery Protocol (`ndisc.c`).

## Architecture & Data Flow

- In `tcp_prune_queue`, if `atomic_read(&sk->sk_rmem_alloc)` is zero, the function must return `-1` before calling `tcp_clamp_window`, because `tcp_clamp_window` sets `sk->sk_rcvbuf` to `min(atomic_read(&sk->sk_rmem_alloc), rmem2)` when `sk->sk_rcvbuf < rmem2` and would shrink `sk->sk_rcvbuf` to zero on an empty receive queue. [F62]
- In `tcp_mark_skb_lost`, `tcp_verify_retransmit_hint(tp, skb)` must be called before mutating `tp->lost_out` or `tp->retrans_out`, because `tcp_verify_retransmit_hint` tests `tp->retrans_out >= tp->lost_out` to check whether all previously lost SKBs have already been retransmitted. [F64]
- Whenever `tp->out_of_order_queue` is non-empty, `tp->ooo_last_skb` must point to the last SKB in `tp->out_of_order_queue` (`skb_rb_last(&tp->out_of_order_queue)`), and must be updated whenever nodes are inserted at the tail (`tcp_data_queue_ofo`), collapsed (`tcp_collapse_ofo_queue`), or pruned from the tail (`tcp_prune_ofo_queue`). [F67]
- When `tcpm_new` recycles the oldest `struct tcp_metrics_block` in a hash bucket (`reclaim == true`), it must pass `fastopen_clear = true` to `tcpm_suck_dst` so that `tm->tcpm_fastopen` fields (`mss`, `syn_loss`, `try_exp`, `cookie`) are reset under `fastopen_seqlock` before the block is reused for the new peer. [F75]
- In `tcp_rcv_established` and `tcp_ack`, `tp->rx_opt.ts_recent` must not be updated until after `tcp_checksum_complete(skb)` and sequence/ACK window checks succeed, so that a corrupted or out-of-window segment cannot poison `ts_recent` and cause PAWS to drop all future valid packets. [F77]
- On established sockets, advancing `tp->snd_una` or `tp->rcv_nxt` must use `tcp_snd_una_update` or `tcp_rcv_nxt_update` (and `twsk_rcv_nxt_update` in `TCP_FIN_WAIT2` timewait) so `tp->bytes_acked` / `tp->bytes_received` and TCP-AO sequence number extension counters (`ao->snd_sne` / `ao->rcv_sne`) update on 32-bit wraparound. [F79]
- In `tcp_parse_options`, `tcp_parse_mss_option`, and `tcp_do_parse_auth_options`, any TCP option other than `TCPOPT_EOL` and `TCPOPT_NOP` must verify that `length >= 2` and that `opsize` is in `[2, length]` before reading option payload or advancing `ptr` by `opsize - 2` and decrementing `length` by `opsize`. [F80]
- `tcp_parse_fastopen_option` must require `syn` to be true and `len` to be non-negative and even (`!(len & 1)`), copying `cookie` into `foc->val` only when `len` is between `TCP_FASTOPEN_COOKIE_MIN` and `TCP_FASTOPEN_COOKIE_MAX` inclusive and setting `foc->len = -1` for any other non-zero `len`. [F82]
- `tcp_parse_options` only records `TCP_SKB_CB(skb)->sacked` when `opsize >= TCPOLEN_SACK_BASE + TCPOLEN_SACK_PERBLOCK` and `(opsize - TCPOLEN_SACK_BASE) % TCPOLEN_SACK_PERBLOCK == 0`, and `tcp_sacktag_write_queue` must clamp `num_sacks` to `min(TCP_NUM_SACKS, (ptr[1] - TCPOLEN_SACK_BASE) >> 3)`. [F83]
- `tp->delivered_ecn_bytes` and `tp->received_ecn_bytes` are 3-element arrays indexed by `ecnfield - 1` for non-zero ECN codepoints (`INET_ECN_ECT_1`, `INET_ECN_ECT_0`, `INET_ECN_CE`), so callers such as `tcp_accecn_process_option` and `tcp_ecn_received_counters` must ensure `ecnfield != INET_ECN_NOT_ECT` before subtracting 1. [F84]
- `tcp_skb_shift` must reject shifting bytes into `to` when `to->len + shiftlen >= 65535 * TCP_MIN_GSO_SIZE` or `tcp_skb_pcount(to) + pcount > 65535`. [F85]
- When coalescing receive or backlog SKBs in `tcp_ooo_try_coalesce` and `tcp_add_backlog`, the sum of `gso_segs` from both SKBs must be computed in 32-bit arithmetic and saturated to `0xFFFF` with `min_t(u32, ..., 0xFFFF)` before assigning to `skb_shinfo(...)->gso_segs`. [F86]
- `tcp_v4_parse_md5_keys` must validate `optlen >= sizeof(struct tcp_md5sig)`, `cmd.tcpm_prefixlen <= 32` (when `TCP_MD5SIG_EXT` and `TCP_MD5SIG_FLAG_PREFIX` are used), and `cmd.tcpm_keylen <= TCP_MD5SIG_MAXKEYLEN` before calling `tcp_md5_do_add`. [F90]
- When `tp->retrans_stamp` is zero, `tcp_packet_delayed()` must return `false` if `(!tcp_is_sack(tp) && !before(tp->snd_una, tp->high_seq))` or `sk->sk_state == TCP_SYN_SENT`, because `tcp_is_non_sack_preventing_reopen()` and `tcp_clean_rtx_queue()` clear `tp->retrans_stamp` despite prior retransmissions. [F97]
- In `tcp_collapse()`, when collapsing the out-of-order rbtree (`list == NULL`), newly allocated `nskb` segments must be queued onto the temporary list `tmp` and only inserted into `root` via `tcp_rbtree_insert()` at `end:` after the copy loop finishes. [F100]
- In `tcp_sacktag_write_queue()`, when filtering and sorting wire SACK blocks `sp[]`, `first_sack_index` must be set to `-1` if `i == 0` is discarded and updated to `j + 1` whenever `j == first_sack_index` is swapped during bubble sort, so that `dup_sack` and `next_dup` identify the original first block. [F101]
- In `tcp_sack_maybe_coalesce()` and `tcp_sack_remove()`, when a SACK block at `this_sack` is merged or removed and remaining `tp->selective_acks` entries are shifted down by one slot, the loop must `continue` without incrementing `this_sack` or `swalk`/`sp`. [F102]
- In `tcp_metrics_flush_all()` and `tcp_metrics_nl_cmd_del()`, singly-linked `tcp_metrics_block` bucket chains are traversed under `tcp_metrics_lock` via double pointer `pp`, which must only be advanced (`pp = &tm->tcpm_next`) in the `else` branch when `tm` is not unlinked. [F104]
- In `tcp_metrics_nl_dump()`, the outer bucket loop `for (row = s_row; row < max_rows; row++, s_col = 0)` must reset `s_col = 0` when advancing to the next `row`, and save both `row` and `col` into `cb->args[0]` and `cb->args[1]` at `done:` when `tcp_metrics_dump_info()` returns `< 0`. [F105]
- In `tcp_gso_segment()`, the `while (skb->next)` loop clears `th->fin` and `th->psh` on every non-final segment and masks `th->cwr &= ecn_cwr_mask` on every subsequent segment (`skb = skb->next`), preserving `fin` and `psh` only on the last segment and `cwr` on subsequent segments only when `SKB_GSO_TCP_ACCECN` is set. [F109]
- In `tcp_illinois_acked`, `rtt_us` must be clamped to `RTT_MAX` (`U32_MAX / ALPHA_MAX`) before updating `ca->base_rtt`, `ca->max_rtt`, and `ca->sum_rtt` so that 32-bit delay multiplications in `alpha()` cannot wrap around. [F111]
- `tcp_parse_options` must clamp the wire `TCPOPT_WINDOW` shift count `snd_wscale` to `TCP_MAX_WSCALE` (14), and when `!wscale_ok`, `snd_wscale` and `rcv_wscale` must be zeroed so window shifts (`ntohs(th->window) << snd_wscale`) never exceed 14 bits. [F116]
- In `tcpnv_cong_avoid`, signed `ca->cwnd_growth_factor` must be negated before left-shifting when negative (`tcp_snd_cwnd(tp) << -ca->cwnd_growth_factor`, bounded to `>= -8` in `tcpnv_state`), and right-shifted results when non-negative must be floored with `max(4U, ...)` before calling `tcp_cong_avoid_ai`. [F117]
- In `tcp_illinois.c`, `update_params` and `tcp_illinois_info` must check `ca->cnt_rtt > 0` before dividing `ca->sum_rtt` by `ca->cnt_rtt` via `avg_delay()` or `do_div()`, and `beta()` must return `BETA_MAX` when `d3 <= d2` before dividing by `d3 - d2`. [F118]
- `tcp_cwnd_reduction` must verify `tp->prior_cwnd` is non-zero before calling `div_u64(dividend, tp->prior_cwnd)`, and when `delta < 0`, must compute `dividend = (u64)tp->snd_ssthresh * tp->prr_delivered + tp->prior_cwnd - 1` for 64-bit ceiling division. [F120]
- Segment counts derived from byte lengths in `tcp_gso_segment` (`skb_shinfo(skb)->gso_segs = DIV_ROUND_UP(skb->len, mss)`) and `tcp_dsack_seen` (`dup_segs = DIV_ROUND_UP(seq_len, tp->mss_cache)`) must use `DIV_ROUND_UP` so trailing partial-MSS bytes are counted as a segment. [F123]
- `tcp_in_window` must test 32-bit sequence containment using wrap-safe `after(end_seq, s_win) && before(seq, e_win)` (plus exact equality checks for zero-length segments at `s_win` or `e_win`) rather than direct `<` or `>` operators. [F124]
- In `__tcp_oow_rate_limited`, the elapsed jiffies since `val = READ_ONCE(*last_oow_ack_time)` must be computed as `s32 elapsed = (s32)(tcp_jiffies32 - val)` and checked against `0 <= elapsed && elapsed < READ_ONCE(net->ipv4.sysctl_tcp_invalid_ratelimit)`. [F126]
- Congestion control private state structures accessed via `inet_csk_ca(sk)` (such as `struct illinois` and `struct tcpnv`) are stored inline inside `inet_csk(sk)->icsk_ca_priv` and must not exceed `ICSK_CA_PRIV_SIZE` bytes (`BUILD_BUG_ON(sizeof(...) > ICSK_CA_PRIV_SIZE)`). [F131]
- In `tcp_parse_options`, `ptr` has already advanced 2 bytes past `opcode` and `opsize` when entering `switch (opcode)`, so option header offsets (`TCP_SKB_CB(skb)->sacked` and `opt_rx->accecn`) must be computed as `(ptr - 2) - (unsigned char *)th` and each iteration must advance `ptr` by `opsize - 2` while subtracting `opsize` from `length`. [F134]
- Before invoking a tunnel socket's `udp_sk(sk)->gro_complete` callback, `udp_gro_complete` must clear `NAPI_GRO_CB(skb)->encap_mark = 0` and set `skb->encapsulation = 1` so inner `gro_complete` handlers configure inner header offsets and allow inner fraglist GRO completion. [F241]
- During `udp_tunnel_nic_replay`, all non-free table entries must be marked with `UDP_TUNNEL_NIC_ENTRY_FROZEN` via `udp_tunnel_nic_entry_freeze_used` before calling `udp_tunnel_get_rx_info` and unfrozen via `udp_tunnel_nic_entry_unfreeze` afterward so existing ports do not have `use_cnt` incremented again. [F243]
- When `tcp_fragment` or `__tcp_retransmit_skb` recomputes `tcp_set_skb_tso_segs` on a segment that has already been sent (`!before(tp->snd_nxt, TCP_SKB_CB(buff)->end_seq)` or in `tcp_rtx_queue`), `tcp_adjust_pcount` must be called with the old minus new pcount sum so `packets_out`, `sacked_out`, `retrans_out`, and `lost_out` stay consistent. [F246]
- When splitting an SKB in `tcp_fragment` or `tso_fragment`, `TCPHDR_FIN` and `TCPHDR_PSH` in `TCP_SKB_CB(skb)->tcp_flags` and `TCP_SKB_CB(skb)->eor` must be cleared on the first segment and transferred only to the second segment (`buff`). [F247]
- Before `tcp_collapse_retrans` unlinks and frees `next_skb` after shifting its payload into `skb`, it must update `tp->highest_sack` via `tcp_highest_sack_replace(sk, next_skb, skb)`, repoint `tp->retransmit_skb_hint = skb` if it matched `next_skb`, and call `tcp_adjust_pcount(sk, next_skb, tcp_skb_pcount(next_skb))`. [F250]
- When `tcp_send_fin` tacks `TCPHDR_FIN` onto the last SKB in `sk->tcp_rtx_queue` because `sk->sk_write_queue` is empty under memory pressure, it must increment `tp->snd_nxt` (`WRITE_ONCE(tp->snd_nxt, tp->snd_nxt + 1)`) in addition to `TCP_SKB_CB(tskb)->end_seq++` and `tp->write_seq++` because the retransmit path does not advance `tp->snd_nxt`. [F251]
- When `tcp_event_ack_sent` flushes `tp->compressed_ack`, it must add `tp->compressed_ack` to `LINUX_MIB_TCPACKCOMPRESSED`, zero `tp->compressed_ack`, and call `__sock_put(sk)` if `hrtimer_try_to_cancel(&tp->compressed_ack_timer) == 1`; conversely, `tcp_compressed_ack_kick` must decrement `tp->compressed_ack` before `tcp_send_ack(sk)`. [F252]
- In tcp_select_window() and __tcp_transmit_skb(), SYN/SYN-ACK segments are never scaled and must clamp rcv_wnd to 65535U, while non-SYN segments must clamp new_win to (65535U << tp->rx_opt.rcv_wscale) (or MAX_TCP_WINDOW when unscaled with sysctl_tcp_workaround_signed_windows) before shifting right by rcv_wscale. [F256]
- In tcp_options_write(), the 3-element arrays synack_ecn_bytes and tp->received_ecn_bytes are 0-based and must be indexed by subtracting 1 from the 1-based ECN codepoints (INET_ECN_ECT_0 - 1, INET_ECN_ECT_1 - 1, and INET_ECN_CE - 1). [F258]
- In __tcp_transmit_skb(), before passing the skb to icsk->icsk_af_ops->queue_xmit, skb->cb must be zeroed over max(sizeof(struct inet_skb_parm), sizeof(struct inet6_skb_parm)) bytes to clear struct tcp_skb_cb state before IPv4 or IPv6 layer processing. [F260]
- TCP write and retransmit queue manipulation functions (tcp_fragment(), __pskb_trim_head(), tso_fragment(), and tcp_clone_payload()) require queued data skbs to have zero linear data (skb_headlen(skb) == 0) with all payload stored in page fragments, and tcp_clone_payload() must return -E2BIG if the target skb would exceed MAX_SKB_FRAGS. [F261]
- Congestion control private structs in inet_csk_ca(sk) (struct vegas, struct veno, struct westwood, struct yeah) must not exceed ICSK_CA_PRIV_SIZE bytes, and struct yeah must keep struct vegas as its first member so tcp_yeah can share the tcp_vegas_* callbacks. [F266]
- In net/ipv4/tunnel4.c, the IPv4 protocol receive handlers tunnel4_rcv(), tunnel64_rcv(), and tunnelmpls4_rcv() must validate that the inner header is present in linear skb data via pskb_may_pull() (for sizeof(struct iphdr), sizeof(struct ipv6hdr), and sizeof(struct mpls_label) respectively) before invoking any registered xfrm_tunnel handler. [F268]
- In udp_tunnel_update_gro_rcv(), udp_tunnel_gro_type_nr == UDP_MAX_TUNNEL_TYPES + 1 is an overflow sentinel, so it must return before iterating udp_tunnel_gro_types[] when udp_tunnel_gro_type_nr > UDP_MAX_TUNNEL_TYPES and compact removals via *cur = udp_tunnel_gro_types[--udp_tunnel_gro_type_nr] to keep a single active type at index 0. [F271]
- __udp_gso_segment() must reject skbs with gso_skb->len <= sizeof(*uh) + mss with ERR_PTR(-EINVAL), and when skb_gso_ok(gso_skb, features | NETIF_F_GSO_ROBUST) succeeds, it must recompute skb_shinfo(gso_skb)->gso_segs = DIV_ROUND_UP(gso_skb->len - sizeof(*uh), mss) rather than trusting the existing gso_segs count. [F273]
- In `tcp_options_fit_accecn`, when `opts->num_sack_blocks` is decremented (`sack_blocks_reduce++`) to reclaim option space and the retry loop still finishes with `opts->num_accecn_fields < required`, `opts->num_sack_blocks` must be restored by adding `sack_blocks_reduce` before returning `0`. [F279]
- In `__pskb_trim_head`, the loop over `shinfo->nr_frags` must use a separate compaction index `k` that only increments when `size > eat`, shifting surviving fragments to `shinfo->frags[k]`, clearing `eat = 0` after adjusting the first partially trimmed fragment, and setting `shinfo->nr_frags = k` after the loop. [F282]
- In `tcp_mtu_probe` and `tcp_retrans_try_collapse`, queue walks that coalesce segments must use `tcp_for_write_queue_from_safe` and `skb_rbtree_walk_from_safe` respectively, and `tcp_retrans_try_collapse` must skip calling `tcp_collapse_retrans` on the first iteration (`first == true`) when `skb == to`. [F283]
