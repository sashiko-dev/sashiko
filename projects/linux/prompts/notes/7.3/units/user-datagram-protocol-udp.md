# USER DATAGRAM PROTOCOL (UDP)

Implements the User Datagram Protocol (UDP) and shared UDP-Lite transport layer over IPv4 and IPv6, managing socket port allocation, 1-tuple/2-tuple/4-tuple socket hash tables (`udp_table`), lockless and corked datagram transmission (`udp_sendmsg`, `udpv6_sendmsg`), split receive queues (`reader_queue` and `sk_receive_queue`), early demux, UDP tunnel hooks, GSO/GRO offloads, and `/proc/net/udp[6]` plus BPF socket iterators.

## Architecture & Data Flow

- In `__udp_enqueue_schedule_skb()`, `rmem` and `rcvbuf` must be `unsigned int` when evaluating `rmem + size > rcvbuf`, and `size` must be reloaded from `skb->truesize` after `skb_condense(skb)` before `udp_set_dev_scratch(skb)` and `atomic_add()`, preventing signed `INT_MAX` wraparound of `sk->sk_rmem_alloc` and stale truesize accounting. [F117]
- `udp_rmem_release()` and receive-queue purging helpers (`udp_destruct_common()`, `first_packet_length()`, `__first_packet_length()`) must use `unsigned int` for `skb->truesize` totals and `amt = (size + sk->sk_forward_alloc - partial) & ~(PAGE_SIZE - 1)` to avoid signed overflow. `sk->sk_forward_alloc`, `sk->sk_rmem_alloc`, and `up->forward_deficit` are accounted in bytes, whereas `__sk_mem_reduce_allocated()` takes page units (`amt >> PAGE_SHIFT`). [F118, F162]
- `udp_set_dev_scratch()` ORs `UDP_SKB_IS_STATELESS` (`0x80000000`) into `udp_skb_scratch(skb)->_tsize_state`, so readers of cached truesize must call `udp_skb_truesize(skb)`. `struct udp_dev_scratch` caches `len`, `is_linear`, and `csum_unnecessary` only on 64-bit builds (`BITS_PER_LONG == 64`), may only set `csum_unnecessary` in `udp_skb_csum_unnecessary_set()` when `!skb_shared(skb)`, and must be bypassed via `udp6_skb_len(skb)` in IPv6 RX paths (`udpv6_recvmsg()`) because 16-bit `len` overflows on jumbograms (`inet6_is_jumbogram(skb)`). [F79, F121, F148]
- In `udp_lib_rehash()`, 4-tuple hash updates (`udp_rehash4()` and `hslot2->hash4_cnt` adjustments) must run whenever `udp_hashed4(sk)` holds, even when `hslot2 == nhslot2`. Inserting or removing `udp_sk(sk)->udp_lrpa_node` in `udptable->hash4` (`udp_lib_hash4()` and `udp_unhash4()`) must update both `hslot4->count` under `hslot4->lock` and the 2-tuple slot's `hash4_cnt` via `udp_hash4_inc(hslot2)`/`udp_hash4_dec(hslot2)` under `hslot2->lock`. [F55, F56]
- `udp_table_init()` and `udp_pernet_table_alloc()` allocate `table->hash`, `table->hash2`, and `table->hash4` as one contiguous block of `slot_size` per bucket (including `udp_hash4_slot_size()`), require at least `UDP_HTABLE_SIZE_MIN_PERNET` (128, `log >= 7`) slots so `snum >> udptable->log < PORTS_PER_CHAIN` (512) in `udp_lib_get_port()`, and must set `table->hash2` and `table->mask` before `udp_table_hash4_init()`, which derives `table->hash4` as `table->hash2 + (table->mask + 1)` and initializes each `table->hash4[i].nulls_head` with bucket index `i`. [F88, F122, F126]
- Because `udp_set_table()` can point `net->ipv4.udp_table` at the shared global `&udp_table` (and UDP-Lite shares `udplite_table`), `udp_pernet_table_free()` must skip freeing when `udptable == &udp_table`, and all `udp_table` bucket walks must filter sockets with `net_eq(sock_net(sk), net)`. [F68]
- `UDP_HSLOT_MAIN()` casts `struct udp_hslot *` to `struct udp_hslot_main *`, so `hslot` must remain first in `struct udp_hslot_main` and `udp_has_hash4()`, `udp_hash4_inc()`, and `udp_hash4_dec()` must only take slots from `table->hash2`. Likewise, `struct inet_sock inet` must remain first in `struct udp_sock` because `udp{4,6}_lib_lookup4()` and `bpf_iter_udp_seq_show()` cast directly between `struct udp_sock *` and `struct sock *`. [F127, F128]
- In `udp_queue_rcv_skb()` and `udpv6_queue_rcv_skb()`, `udp_unexpected_gso()` must force software segmentation when a GSO skb lands on a socket with `udp_sk(sk)->encap_rcv` set unless `gso_type` has `SKB_GSO_UDP_TUNNEL` or `SKB_GSO_UDP_TUNNEL_CSUM`. `__skb_push(skb, -skb_mac_offset(skb))` must precede `udp_rcv_segment()` (which rejects `SKB_GSO_UDP` UFO packets before `__skb_gso_segment()`), and each segment must have `__skb_pull(skb, skb_transport_offset(skb))` and `udp_post_segment_fix_csum(skb)` called before `udp{,v6}_queue_rcv_one_skb()`. [F76, F149, F150]
- In `udp_v6_flush_pending_frames()` and `udp_v6_push_pending_frames()`, if `up->pending == AF_INET` (corked via IPv4/v4-mapped `udp_sendmsg()`), they must delegate to `udp_flush_pending_frames()` or `udp_push_pending_frames()`, and all flush/push paths must reset both `up->len = 0` and `WRITE_ONCE(up->pending, 0)`. [F61]
- Because `udp_tunnel_encap_enable()` increments both `udpv6_encap_needed_key` and `udp_encap_needed_key` on `PF_INET6` sockets, `udpv6_destroy_sock()` must decrement both (`static_branch_dec(&udpv6_encap_needed_key)` and `udp_encap_disable()`) and call `udp_tunnel_cleanup_gro(sk)` when `udp_test_bit(ENCAP_ENABLED, sk)` holds. [F58]
- Updating `sk->sk_rcvbuf` in `udp_lib_init_sock()` or via `SO_RCVBUF`/`SO_RCVBUFFORCE` in `udp_lib_setsockopt()` must set `udp_sk(sk)->forward_threshold = sk->sk_rcvbuf >> 2` (under `sockopt_lock_sock(sk)`), and changes to `sk->sk_peek_off` must use `udp_set_peek_off()` so `udp_sk(sk)->peeking_with_offset` (`val >= 0`) stays in sync for `skb_consume_udp()`. [F59, F60]
- In `udp_send_skb()` and `udp_v6_send_skb()`, when `cork->gso_size` is set, the MTU check against `cork->fragsize` must bound the segment payload with `min(datalen, cork->gso_size)` so unsegmented packets (`datalen <= cork->gso_size`) are not rejected with `-EMSGSIZE` when PMTU drops below `cork->gso_size`. [F152]
- In `udp_v4_early_demux()` and `udp_v6_early_demux()`, `pskb_may_pull()` must pull `skb_transport_offset(skb) + sizeof(struct udphdr)` before reading `udp_hdr(skb)` because `skb->data` still points to the network header. `__udp{4,6}_lib_demux_lookup()` must only match connected sockets and inspect only the first entry in `hslot2`, while `__udp4_lib_mcast_demux_lookup()` must return `NULL` if `hslot->count > 10` or if multiple sockets match. [F94, F168]
- In `compute_score()` (`net/ipv4/udp.c` and `net/ipv6/udp.c`), after verifying device compatibility via `udp_sk_bound_dev_eq()`, the device-match score bonus must only be added when `sk->sk_bound_dev_if` is non-zero. [F101]
- Parallel IPv4 and IPv6 socket init (`udp_init_sock()`, `udpv6_init_sock()`) and receive-queue error paths (`__udp_queue_rcv_skb()`, `__udpv6_queue_rcv_skb()`) must be updated in lockstep, including setting `SOCK_SUPPORT_ZC` and calling `trace_udp_fail_queue_rcv_skb(rc, sk, skb)` before `sk_skb_reason_drop()`. [F78]

## Synchronization

- When modifying secondary (`hslot2`) or 4-tuple (`hslot4`) hash buckets, `hash4_cnt`, or `sk->sk_reuseport_cb` in `udp_lib_get_port()`, `udp_lib_hash4()`, `udp_lib_unhash()`, or `udp_lib_rehash()`, the primary bucket lock `hslot->lock` must be held with BH disabled (`spin_lock_bh(&hslot->lock)`) outside `hslot2->lock` and `hslot4->lock`. When moving between `hslot2`/`nhslot2` in `udp_lib_rehash()` or `hslot4`/`nhslot4` in `udp_rehash4()`, the old bucket lock must be released before acquiring the new one while keeping `hslot->lock` held. [F25, F26]
- In UDP receive paths (`__skb_recv_udp()`, `first_packet_length()`, `udp_rmem_release()`), `udp_sk(sk)->reader_queue.lock` must be acquired with BH disabled before `sk->sk_receive_queue.lock`, and `udp_rmem_release()` must be passed `rx_queue_lock_held = true` iff `sk_receive_queue.lock` is held (using `udp_skb_dtor_locked()` instead of `udp_skb_destructor()`). Forward-allocated memory (`sk->sk_forward_alloc`, `udp_rmem_schedule()`, `__sk_mem_reduce_allocated()`) is serialized by `sk->sk_receive_queue.lock` and must not be modified on live sockets without it. [F27, F28]
- In `udp_sendmsg()`, `udpv6_sendmsg()`, `udp_splice_eof()`, and `udpv6_splice_eof()`, any lockless `READ_ONCE(up->pending)` check must be revalidated under `lock_sock(sk)` before reading or mutating cork state (`up->pending`, `up->len`, `inet->cork`), and all writes to `up->pending` must use `WRITE_ONCE()` under `lock_sock(sk)`. [F30]
- `udp_destroy_sock()` and `udpv6_destroy_sock()` must set `SOCK_DEAD` and flush pending frames under the socket lock, and `udp_abort()` must check `sock_flag(sk, SOCK_DEAD)` under `lock_sock(sk)` (when `!has_current_bpf_ctx()`) before setting `sk->sk_err` or calling `__udp_disconnect()`. [F31]
- `__udp{4,6}_lib_lookup()` must run under `rcu_read_lock()` and return an unreferenced `struct sock *` protected only by `SOCK_RCU_FREE`; callers needing a reference outside RCU (`udp{4,6}_lib_lookup()`) must call `refcount_inc_not_zero(&sk->sk_refcnt)` before `rcu_read_unlock()`. Lockless 4-tuple lookups (`udp{4,6}_lib_lookup4()`) must restart from `begin:` if `get_nulls_value(node) != slot`, and `__udp{4,6}_lib_lookup()` must fall back to `udp{4,6}_lib_lookup1()` if 4-tuple and `hslot2` lookups miss. [F32, F140]
- Because UDP RX updates `sk->sk_rx_dst` without the socket lock, updates must use `udp_sk_rx_dst_set()` (`dst_hold_safe(dst)`, `xchg(&sk->sk_rx_dst, RCU_INITIALIZER(dst))`, and `dst_release(old)`), and readers must use `rcu_dereference()`. Locklessly accessed fields (`up->encap_type`, `up->encap_rcv`, `up->gso_size`, `up->pcslen`, `up->pcrlen`, `up->forward_threshold`, `up->peeking_with_offset`, `sk->sk_uid`) require `READ_ONCE()`/`WRITE_ONCE()`, and `up->udp_flags` requires atomic bitops. [F34, F35]
- Before the BPF UDP iterator drops `hslot2->lock` with unvisited sockets in `iter->batch` (`bpf_iter_udp_seq_stop()`, or `bpf_iter_udp_batch()` calling `bpf_iter_udp_realloc_batch()` with `GFP_USER`), `bpf_iter_udp_put_batch()` must replace each `item->sk` in `iter->batch[cur_sk .. end_sk - 1]` with `sock_gen_cookie(item->sk)` and call `sock_put(item->sk)`. When `resizes == 1` jumps to `again`, `state->bucket` must not be modified, `resizes` must be reset to `0` at `next_bucket`, `bpf_iter_udp_seq_show()` must recheck `sk_unhashed(sk)` under `lock_sock(sk)`, and `udp_prog_seq_show()` must decrement `meta->seq_num--` before `bpf_iter_run_prog()`. [F36, F66, F100, F109]

## Object Lifetimes

- When `MSG_PEEK` is not set, `__skb_recv_udp()` unlinks `skb` and reclaims its receive memory via `udp_skb_destructor()` or `udp_skb_dtor_locked()`; when `MSG_PEEK` is set, `skb` stays queued in `reader_queue` and its memory is only reclaimed if dropped via `__sk_queue_drop_skb(..., udp_skb_destructor)`. Because UDP receive SKBs have no `skb->destructor`, `udp_destruct_common()` must splice `sk->sk_receive_queue` into `up->reader_queue`, sum `skb->truesize` across all dequeued SKBs, call `udp_rmem_release(sk, total, 0, true)` (`partial = 0`), and `kfree(up->udp_prod_queue)`. [F5, F7]
- In `udp_queue_rcv_one_skb()`, `__udp4_lib_rcv()`, `udpv6_queue_rcv_one_skb()`, and `__udp6_lib_rcv()`, `nf_reset_ct(skb)` must be called immediately after `xfrm4_policy_check()` or `xfrm6_policy_check()` succeeds so conntrack state is retained for IPsec policy verification and released before `udp_try_make_stateless()`, socket queueing, or ICMP error generation. [F8]
- In `udp_lib_get_port()`, `sock_set_flag(sk, SOCK_RCU_FREE)` must be set and `inet_num`, `udp_port_hash`, and `udp_portaddr_hash` initialized before `sk_add_node_rcu()` publishes `sk` into `hslot->head`, and inserting an unhashed socket into `hslot`, `hslot2`, and `sock_prot_inuse_add(..., 1)` must only occur after `udp_reuseport_add_sock(sk, hslot)` succeeds; on failure, `inet_num` and `udp_port_hash` must be reset to `0` and `udp_portaddr_hash` restored via `^= snum` before unlocking `hslot->lock`. [F12, F23]
- In `__udp4_lib_rcv()` and `__udp6_lib_rcv()`, early-demuxed or BPF-assigned sockets on `skb->sk` must be extracted with `inet_steal_sock()` or `inet6_steal_sock()`, checking `IS_ERR(sk)` and calling `sock_put(sk)` when `refcounted` is true, so `SO_REUSEPORT` BPF programs are executed. [F156]

## API Contracts

- Outgoing UDP checksum paths (`udp_send_skb()`, `udp_v6_send_skb()`, `udp4_hwcsum()`, `udp6_hwcsum_outgoing()`, `udp_set_csum()`) require `uh->check = 0` before computing checksums and must replace any computed `0` checksum with `CSUM_MANGLED_0`. `udp4_hwcsum()` and `udp6_hwcsum_outgoing()` can only use `CHECKSUM_PARTIAL` hardware offload when `!skb_has_frag_list(skb)`; if `frag_list` is present, they must compute a software checksum across all fragments and set `skb->ip_summed = CHECKSUM_NONE`. [F50, F154]
- `udp_ehashfn()` and `udp6_ehashfn()` require `lport` in host byte order (`u16`, e.g., `hnum` or `sk->sk_num`) and `fport` in network byte order (`__be16`, e.g., `sport` or `sk->sk_dport`), with packet destination passed as `(laddr, lport)` and source as `(faddr, fport)` on RX. In `udp6_ehashfn()`, `fhash` is computed with `udp_ipv6_hash_secret`, whereas `__inet6_ehashfn()` must be passed `udp6_ehash_secret + net_hash_mix(net)`. [F53, F115]
- In `__udp4_lib_err()` and `__udp6_lib_err()`, when `tunnel` is true, ICMP errors must not be queued or reported on the tunnel socket via `ip_icmp_error()`/`ipv6_icmp_error()`, `sk->sk_err`, or `sk_error_report()`; instead, `udp_sk(sk)->encap_err_rcv` must be invoked if non-NULL. [F157]

## Error Handling

- When `udpv6_sendmsg()` delegates IPv4 or IPv4-mapped sends to `udp_sendmsg()` by temporarily setting `msg->msg_name` to a stack-local `struct sockaddr_in sin` and `msg->msg_namelen` to `sizeof(sin)`, it must restore `msg->msg_name = sin6` and `msg->msg_namelen = addr_len` before returning. [F17]
- `udp_cmsg_send()` returns `< 0` on error, `0` when all control messages are `SOL_UDP`, and `1` (`need_ip`) when non-`SOL_UDP` control messages are present, so `udp_sendmsg()` and `udpv6_sendmsg()` must only clear `connected` and invoke IP-level cmsg handlers when `udp_cmsg_send()` returns `> 0`. [F37]
- In `udp_sendmsg()` and `udpv6_sendmsg()`, when `ip_route_output_flow()` or `ip6_sk_dst_lookup_flow()` returns an `ERR_PTR`, `rt` or `dst` must be reset to `NULL` before jumping to `out:` (which calls `ip_rt_put(rt)` / `dst_release(dst)`). In `udpv6_sendmsg()`, paths prior to `ip6_sk_dst_lookup_flow()` and the lockless `ip6_make_skb()` path (which steals `dst`) must jump to `out_no_dst:`, while the corked `up->pending` fast path must set `dst = NULL` before `goto do_append_data`. Cleanup at `out_free:` must only `kfree(ipc.opt)` when `free` is set, and `out_no_dst:` must pass `opt_to_free` (not `opt`) to `txopt_put()`. [F46, F47, F48]
- When `udp_recvmsg()` or `udpv6_recvmsg()` drops a datagram on the `csum_copy_err:` path and retries at `try_again:`, it must clear `MSG_TRUNC` from `msg->msg_flags` (`msg->msg_flags &= ~MSG_TRUNC`) because `MSG_TRUNC` is set before checksum verification. [F51]

## External Contracts

- In `udpv6_sendmsg()`, `AF_INET6` destination addresses must be accepted when `addr_len >= SIN6_LEN_RFC2133` (24 bytes), so `sin6->sin6_scope_id` must only be read when `addr_len >= sizeof(struct sockaddr_in6)` (28 bytes). After running `BPF_CGROUP_RUN_PROG_UDP{4,6}_SENDMSG_LOCK` in `udp{,v6}_sendmsg()`, if the destination sockaddr is non-NULL, the caller must re-validate that the port is non-zero (and in `udpv6_sendmsg()` reject `ipv6_addr_v4mapped(&sin6->sin6_addr)` with `-ENOTSUPP`) and reload destination address and port. [F90, F164]
- In `__udp_cmsg_send()`, `UDP_SEGMENT` must be rejected with `-EINVAL` unless `cmsg->cmsg_len == CMSG_LEN(sizeof(__u16))`, and in `udp_lib_setsockopt()`, `UDP_SEGMENT` must reject `val < 0 || val > USHRT_MAX` with `-EINVAL`. `UDP_MAX_SEGMENTS` must remain at least 128 (`1 << 7UL`). [F81, F95]
- In `udp4_format_sock()` and `bpf_iter_udp_seq_show()`, socket UIDs exported via `seq_file` must be translated to the reader's user namespace with `from_kuid_munged(seq_user_ns(seq), sk_uid(sk))`, and `udp4_format_sock()` must format the kernel socket pointer with `%pK`. [F166]
