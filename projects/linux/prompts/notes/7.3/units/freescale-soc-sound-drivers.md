# FREESCALE SOC SOUND DRIVERS

This unit provides ALSA SoC (ASoC) CPU DAI drivers (SAI, S/PDIF, SSI for I2S/AC97, and XCVR for eARC/ARC/SPDIF), PCM platform drivers (DMA, ARM FIQ with hrtimers, and Cortex-M RPMSG IPC), the i.MX AUDMUX routing driver, common clock/DT helpers, and machine/card drivers for Freescale/NXP i.MX and PowerPC SoCs.

## Architecture & Data Flow

- When a SAI stream `dir` is clocked by the opposite direction `adir` (`fsl_sai_dir_is_synced(sai, adir)`), `fsl_sai_set_bclk()` and `fsl_sai_hw_params()` must program `FSL_SAI_xCR2(!tx, ofs)`, `FSL_SAI_xCR4(!tx, ofs)`, and `FSL_SAI_xCR5(!tx, ofs)`; in `fsl_sai_trigger()`, starting must set `FSL_SAI_CSR_TERE` in `FSL_SAI_xCSR(!tx, ofs)`, and stopping must only call `fsl_sai_config_disable()` on a clock-providing direction if the opposite direction's `FSL_SAI_CSR_FRDE` bit is clear. [F54, F55]
- In `fsl_ssi_config_disable()`, when the opposite stream `adir` is active (`ssi->streams & BIT(adir)`), shared bits in `ssi->regvals[adir]` must be excluded via `ssi_excl_shared_bits()` when clearing `REG_SSI_SCR`, `REG_SSI_SIER`, `REG_SSI_SRCR`, and `REG_SSI_STCR`. When `ssi->soc->offline_config` is true, `fsl_ssi_config_enable()` and `fsl_ssi_config_disable()` must only modify `SRCR`, `STCR`, and `SIER` when no other stream is active (`!ssi->streams` on enable, `!aactive` on disable) by programming/clearing `RX | TX` `regvals` at once. [F59, F130]
- Volatile registers require manual PM save/restore: `fsl_ssi_suspend()`/`fsl_ssi_resume()` must save `REG_SSI_SFCSR` and `REG_SSI_SACNT` before `regcache_cache_only()` and restore only `SSI_SFCSR_*WM*` watermark bits and `REG_SSI_SACNT` before `regcache_sync()`; `fsl_spdif_runtime_suspend()`/`fsl_spdif_runtime_resume()` must similarly save and restore `SRPC_CLKSRC_SEL_MASK | SRPC_GAINSEL_MASK` in `REG_SPDIF_SRPC` (`regcache_srpc`). [F61, F62]
- Static `snd_soc_dai_driver` templates (`fsl_sai_dai_template`, `fsl_ssi_dai_template`, `fsl_ssi_ac97_dai`, `fsl_spdif_dai`) must be copied into per-instance `cpu_dai_drv` during probe before mutating `name`, `formats`, or `symmetric_*`, and `cpu_dai_drv[3]` in `struct fsl_sai` must be sized to at least `ARRAY_SIZE(fsl_sai_dai_template)`. [F50, F114]
- In `fsl_sai`, `fsl_sai_check_version()` must return early without reading `FSL_SAI_VERID` (`0x00`) when `FSL_SAI_TCSR(ofs) == FSL_SAI_VERID` (`reg_offset == 0`), and `fsl_sai_probe()` must only write `FSL_SAI_MCTL` (`0x100`) when `sai->soc_data->max_register >= FSL_SAI_MCTL`. In `fsl_ssi`, when `ssi->soc->imx21regs` is true, `fsl_ssi_probe()` must cap `regconfig.max_register` at `REG_SSI_SRMSK` and `fsl_ssi_tx_ac97_saccst_setup()` must skip writing `REG_SSI_SACCDIS` and `REG_SSI_SACCEN`. [F122, F123]
- In `fsl_ssi.c`, `_fsl_ssi_set_dai_fmt()` for `SND_SOC_DAIFMT_I2S` must set `SSI_SxCCR_DC` using `ssi->slots ? : 2` rather than a hardcoded `2`, and `fsl_ssi_probe()` must only request `ssi->irq` (`fsl_ssi_isr`) when `ssi->use_dma` is true, because when `!ssi->use_dma`, `imx_pcm_fiq_init()` routes `ssi->irq` to the ARM FIQ vector via `mxc_set_irq_fiq()`. [F57, F152]
- In `imx-pcm-rpmsg.h`, `struct rpmsg_head`, `struct param_s`, and `struct param_r` must remain `__packed` with 32-bit `unsigned int` fields, `imx_rpmsg_pcm_new()` must enforce `DMA_BIT_MASK(32)` so `dma_addr` fits in `param_s.buffer_addr`, and `s_msg` (`struct rpmsg_s_msg`) must remain at offset 0 of `struct rpmsg_msg` because `imx-pcm-rpmsg.c` `memcpy()`s `sizeof(struct rpmsg_s_msg)` bytes directly between `struct rpmsg_msg *` pointers. [F73, F106]
- In `fsl_xcvr.c`, the 20 KiB RAM is paged in 2 KiB (`FSL_XCVR_REG_OFFSET`) windows at `xcvr->ram_addr`: `fsl_xcvr_load_firmware()` must reject firmware over 16384 bytes (pages 0..7), and Data RAM accesses (`FSL_XCVR_CAP_DATA_STR`, `FSL_XCVR_RX_CS_CTRL_0`) must select `FSL_XCVR_EXT_CTRL_PAGE(8)`. On stop in `fsl_xcvr_trigger()`, `FSL_XCVR_MODE_SPDIF` must `break` when `xcvr->soc_data->spdif_only` is true because `FSL_XCVR_ISR_CLR` is not writeable on `spdif_only` (`!use_phy`) SoCs. [F76, F88]

## Synchronization

- In `imx_rpmsg_pcm_send_message()`, `info->msg_lock` must be held continuously across `reinit_completion(&info->cmd_complete)`, `rpmsg_send()`, `wait_for_completion_timeout(&info->cmd_complete, ...)`, and copying the reply from `info->r_msg`. In `imx_audio_rpmsg_cb()`, `info->lock[TX]` and `info->lock[RX]` must be released after updating `msg->r_msg.param.buffer_tail` and before invoking `info->callback[TX]` or `info->callback[RX]` (`imx_rpmsg_pcm_dma_complete()`). [F26, F28]
- In `imx-pcm-fiq.c`, `snd_imx_pcm_trigger()` must set `iprtd->playing` or `iprtd->capturing` to 1 via `atomic_set()` before calling `hrtimer_start(&iprtd->hrt, ...)`, and `snd_imx_close()` must call `hrtimer_cancel(&iprtd->hrt)` before `kfree(iprtd)`. In `fsl_ssi.c`, AC97 register accesses in `fsl_ssi_ac97_read()`/`fsl_ssi_ac97_write()` must be serialized by `fsl_ac97_data->ac97_reg_lock`, initialized before `snd_soc_set_ac97_ops_of_reset()` and destroyed after `snd_soc_set_ac97_ops(NULL)`. [F32, F33]

## Object Lifetimes

- Device Tree node references must be released on all paths: in `imx_card_parse_of()`, `cpu`, `codec`, and `platform` must be reset to `NULL` after `of_node_put()` at the end of each `for_each_child_of_node_scoped()` iteration so a later jump to `err:` does not double-put them; `fsl_asoc_get_dma_channel()` must `of_node_put()` `dma_channel_np` and `dma_np`; `imx_hdmi_probe()` must `of_node_put(cpu_np)` at `fail:`; and `imx_rpmsg_probe()` must reset `data->card.dev->of_node = NULL` at `fail:`. [F1, F4, F20, F22]
- When an ASoC machine driver acquires a clock from a foreign CPU DAI or CODEC device during `probe`, it must bind devres to its own `&pdev->dev` (via `devm_get_clk_from_child()`) or pair `clk_get()` with `clk_put()`, never call `devm_clk_get()` on the foreign `dev`. In `imx_sgtl5000_probe()` and `imx_es8328_probe()`, every path after `of_find_i2c_device_by_node()` / `of_find_device_by_node()` must reach `put_device:` / `fail:` to call `put_device()`, `of_node_put(ssi_np)`, and `of_node_put(codec_np)`, and `imx_sgtl5000` must call `clk_put(data->codec_clk)` on error and in `imx_sgtl5000_remove()`. [F2, F3, F119]
- Provider-mode clocks are reference-tracked per stream: in `fsl_sai.c`, enabling/disabling `sai->mclk_clk[sai->mclk_id[tx]]` in `fsl_sai_hw_params()`/`fsl_sai_hw_free()` must be gated on `!sai->is_consumer_mode[tx]` and tracked in `sai->mclk_streams` (`BIT(substream->stream)`), and `fsl_sai_set_dai_sysclk()` must not call `fsl_sai_set_mclk_rate()` when `sai->mclk_streams != 0`. In `fsl_ssi.c`, enabling/disabling `ssi->baudclk` in `fsl_ssi_hw_params()`/`fsl_ssi_hw_free()` must be gated on `fsl_ssi_is_i2s_clock_provider(ssi)` and tracked in `ssi->baudclk_streams`, and `fsl_ssi_set_bclk()` must not call `clk_set_rate(ssi->baudclk, ...)` when the opposite stream bit is set in `ssi->baudclk_streams`. [F5, F7]
- In `spdif_reparent_rootclk()` and `fsl_xcvr_en_aud_pll()`, because `spdif_priv->txclk[STC_TXCLK_SPDIF_ROOT]` and `xcvr->phy_clk` are already enabled by runtime resume, they must be disabled with `clk_disable_unprepare()` before calling `fsl_asoc_reparent_pll_clocks()` and re-enabled with `clk_prepare_enable()` afterward. In `fsl_ssi.c`, when `!ssi->has_ipg_clk_name`, `fsl_ssi_imx_probe()` manually enables `ssi->clk`, so `error_pcm:` and `fsl_ssi_imx_clean()` must call `clk_disable_unprepare(ssi->clk)` only when `!ssi->has_ipg_clk_name`. [F8, F135]
- In `fsl_xcvr`, `fsl_xcvr_startup()` sets `xcvr->streams |= BIT(substream->stream)` after `fsl_xcvr_constr()` succeeds, and `fsl_xcvr_startup()`/`fsl_xcvr_shutdown()` must bracket `fsl_xcvr_activate_ctl()` with `down_read(&card->snd_card->controls_rwsem)` / `up_read(...)`, re-activating controls on shutdown only when `!xcvr->streams`. In `fsl_xcvr_remove()`, `cancel_work_sync(&xcvr->work_rst)` must precede `pm_runtime_disable(&pdev->dev)`. [F15, F25]

## API Contracts

- In machine drivers using `snd_soc_pm_ops` (`imx-card.c`, `imx-audmix.c`, `imx-rpmsg.c`, `imx-hdmi.c`, `imx-sgtl5000.c`), device drvdata holds `struct snd_soc_card *` while driver private data is stored via `snd_soc_card_set_drvdata()`, so callbacks must use `snd_soc_card_get_drvdata()`. Every machine driver in this component must also set `card.owner = THIS_MODULE` before calling `devm_snd_soc_register_card()`. [F110, F156]
- In CPU DAI driver probes (`fsl_sai_probe()`, `fsl_spdif_probe()`, `fsl_ssi_probe()`, `fsl_xcvr_probe()`), the PCM platform component (`imx_pcm_dma_init()`, `imx_pcm_fiq_init()`, or `devm_snd_dmaengine_pcm_register()`) must be registered before `devm_snd_soc_register_component()` registers the CPU DAI component. In `fsl_ssi_probe()`, `platform_device_register_data()` for `ssi->card_pdev` must pass `NULL` as `parent` when `fsl_ssi_is_ac97(ssi)` is true so ASoC does not inherit the SSI's DT node for the AC97 CODEC and bypass `fsl_ssi_dai_probe()`. [F118, F157]
- In `imx_audio_rpmsg_probe()`, `data->rpmsg_pdev` must be registered with `&rpdev->dev` as parent (and `imx_rpmsg_pcm_probe()` must set `struct rpmsg_info *` as its drvdata), while `data->card_pdev` (`"imx-audio-rpmsg"`) must pass `strlen(rpdev->id.name) + 1` as the `platform_data` size so `dai_name` is NUL-terminated. Any CPU DAI bound with `imx_rpmsg_soc_component` must store `struct fsl_rpmsg *` as `cpu_dai->dev` drvdata. [F107, F108, F109]
- All `snd_kcontrol_new` controls in `fsl_spdif.c` and `fsl_xcvr.c` must be registered via `snd_soc_add_dai_controls()` because their callbacks cast `snd_kcontrol_chip()` to `struct snd_soc_dai *`; any control looked up via `snd_soc_card_get_kcontrol()` must set `.iface = SNDRV_CTL_ELEM_IFACE_MIXER` rather than `SNDRV_CTL_ELEM_IFACE_PCM`. [F116, F154]
- Before calling `fsl_asoc_get_dma_channel()`, the caller must allocate `dai->platforms` and point `dai->platforms->name` to a writable buffer of at least `DAI_NAME_SIZE` (32) bytes because the helper casts `dai->platforms->name` to `char *` and formats into it with `snprintf()`. Callers of `fsl_asoc_constrain_rates()` must pass a non-stack `target_rates` array with at least `original_constr->count` elements (`FAL_SAI_NUM_RATES` or `SPDIF_NUM_RATES`) matching the lifetime of `target_constr`. [F43, F104]
- In `fsl_sai.h`, `FSL_SAI_CR4_FRSZ(x)`, `FSL_SAI_CR4_SYWD(x)`, `FSL_SAI_CR5_WNW(x)`, and `FSL_SAI_CR5_W0W(x)` subtract 1 internally, whereas `FSL_SAI_CR5_FBT(x)` does not subtract 1 and requires `fsl_sai_hw_params()` to pass 0-based `word_width - 1` (or `0` for LSB-first/PDM). Also, `fsl_sai_check_version()` must right-shift `sai->verid.version` by `FSL_SAI_VERID_MINOR_SHIFT` (16), and `fsl_sai_config_disable()` (called from atomic `fsl_sai_trigger()`) must use `udelay()` rather than sleeping when polling `FSL_SAI_CSR_TERE`. [F38, F49, F153]
- In `fsl_ssi_set_dai_tdm_slot()`, `REG_SSI_STMSK`/`REG_SSI_SRMSK` use `1` bits to disable slots and require `SSI_SCR_SSIEN` to be set while writing them, so the function must write bitwise-inverted `~tx_mask`/`~rx_mask` while `SSI_SCR_SSIEN` is temporarily enabled. In `imx-pcm-fiq.c`, `snd_imx_pcm_prepare()` must call `get_fiq_regs(&regs)` before updating `regs.ARM_r8` or `regs.ARM_r9` and calling `set_fiq_regs(&regs)` so preparing one stream does not clobber the opposite stream's active FIQ registers. [F47, F140]

## Error Handling

- Unlike `fsl_asoc_get_pll_clocks()`, `fsl_sai_probe()`, and `imx_audmux_probe()` which normalize failed `devm_clk_get()` pointers to `NULL`, `fsl_spdif_probe()` and `fsl_ssi_imx_probe()` leave `spdif_priv->spbaclk` and `ssi->baudclk` as `ERR_PTR` values, so every consumer of those two fields must check `!IS_ERR()` before use. [F40]
- In `fsl_xcvr`, `xcvr->regmap_phy` and `xcvr->regmap_pll` are only allocated when `xcvr->soc_data->use_phy` is true, and `xcvr->soc_data->fw_name` is `NULL` on SoCs without M0+ firmware (e.g., i.MX93), so all `regmap_phy`/`regmap_pll` accesses must be gated by `xcvr->soc_data->use_phy` and firmware/RAM CS accesses by `xcvr->soc_data->fw_name`. [F41]
- In `imx-card.c`, `imx-hdmi.c`, and `imx-rpmsg.c`, return values from `snd_soc_dai_set_fmt()`, `snd_soc_dai_set_tdm_slot()`, `snd_soc_dai_set_sysclk()`, and `snd_soc_component_set_jack()` must ignore `-ENOTSUPP` (`if (ret && ret != -ENOTSUPP)`). In `fsl_sai_probe()`, `pm_runtime_put_sync(dev)` must ignore `-ENOSYS` (`if (ret < 0 && ret != -ENOSYS)`) so probing succeeds when `CONFIG_PM` is disabled. [F36, F44]

## External Contracts

- The unidirectional DAI templates `sai-tx` and `sai-rx` in `fsl_sai_dai_template` must keep their distinct stream names `"SAI-Playback"` and `"SAI-Capture"` in lockstep with the `name` route table in `imx-audmix.c`. In `imx_hdmi_probe()`, `cpu_np` must be assigned directly to `data->dai.cpus->of_node` and `data->dai.platforms->of_node` without calling `of_find_device_by_node()` so `devm_snd_soc_register_card()` handles deferred probing. [F56, F124]

## Known Pitfalls

- In `fsl_sai.h` and `fsl_sai.c`, `RX` is `0` and `TX` is `1` (opposite to `SNDRV_PCM_STREAM_PLAYBACK == 0` / `CAPTURE == 1`), so per-direction arrays (`sai->mclk_id`, `sai->slots`, `sai->slot_width`, `sai->is_consumer_mode`, `dl_cfg->*`) must be indexed by `tx`, whereas `sai->mclk_streams` uses `BIT(substream->stream)`. Also, 32-bit DT dataline masks (`u32 rx, tx`) in `fsl_sai_read_dlcfg()` and `fsl_sai_calc_dl_off()` must be widened to `unsigned long dl_mask` before passing `&dl_mask` to `find_first_bit()`/`find_next_bit()`. [F78, F113]
- In `fsl_sai`, asserting and clearing `FSL_SAI_CSR_SR` in `fsl_sai_config_disable()`, `fsl_sai_dai_probe()`, and `fsl_sai_runtime_resume()` must use `regmap_update_bits()` (not `regmap_write()`) and run in both producer and consumer modes. When `sai->soc_data->mclk_with_tere && sai->mclk_direction_output` is true, `fsl_sai_config_disable()` must keep `FSL_SAI_CSR_BCE` set in `FSL_SAI_xCSR`, and `fsl_sai_hw_params()` in provider mode must clear `FSL_SAI_CR4_FSD_MSTR` before updating `FSL_SAI_xCR4`/`FSL_SAI_xCR5` word width and re-enable it after. In `fsl_sai_isr()`, all `FSL_SAI_CSR_xF_MASK` bits must be cleared from `xcsr` before ORing in `flags & FSL_SAI_CSR_xF_W_MASK` to acknowledge W1C flags. [F127, F128, F129]
- In `fsl_ssi`, `fsl_ssi_hw_params()` must compute stream-specific overrides to `ssi->i2s_net` (such as mono or 16-bit `BC_FP`) in a local copy before updating `REG_SSI_SCR`. Also, `ssi_excl_shared_bits()` and `_ssi_xor_shared_bits()` multiply `avals` by `aactive`, so callers must pass `aactive` as a boolean (`0` or `1`) rather than an unnormalized bitmask. [F58, F85]
- In `imx-pcm-rpmsg.c` and `imx-audio-rpmsg.c`, `MSG_TYPE_C` commands (`TX_PERIOD_DONE == 0x0`, `RX_PERIOD_DONE == 0x1`) must index `info->msg` at `cmd + MSG_TYPE_A_NUM`. In `spdif_softreset()`, because `REG_SPDIF_SCR` uses `REGCACHE_FLAT` and `SCR_SOFT_RESET` self-clears in hardware, `regcache_cache_bypass(regmap, true)` must be enabled before writing `SCR_SOFT_RESET` and polling `REG_SPDIF_SCR`, then disabled before calling `regcache_mark_dirty()` and `regcache_sync()`. [F74, F133]
- Because `imx_es8328_probe()` calls `platform_set_drvdata(pdev, data)` without calling `snd_soc_card_set_drvdata()`, `imx_es8328_dai_init()` must use `container_of(rtd->card, struct imx_es8328_data, card)` and `imx_es8328_driver` cannot use `snd_soc_pm_ops` unless drvdata setup is changed. [F111]
