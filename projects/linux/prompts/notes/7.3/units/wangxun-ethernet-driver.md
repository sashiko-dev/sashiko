# WANGXUN ETHERNET DRIVER

This unit comprises the shared `libwx` library, the 1GbE PF/VF drivers (`ngbe`, `ngbevf`) for WX1860 controllers, and the 10/25/40GbE PF/VF drivers (`txgbe`, `txgbevf`) plus XPCS helper (`pcs-xpcs-wx.c`) for Sapphire (SP1000/WX1820) and Amber Lite (AML50xx/51xx) controllers. It manages Tx/Rx rings, page pools, NAPI, MSI-X/MSI/INTx and nested misc IRQ domains, SR-IOV mailbox protocols, PTP timestamping, Flow Director (ATR/perfect filters), and MDIO/I2C/GPIO/SFP/phylink integration.

## Architecture & Data Flow

- Every `net_device` using `libwx` callbacks must allocate `sizeof(struct wx)` private space so `netdev_priv(netdev)` is `struct wx` at offset 0, with driver state in `wx->priv`. Functions shared with `txgbevf` or called before `wx->priv = txgbe` (`txgbe_sw_init`, `txgbe_reset_hw`, `txgbe_validate_eeprom_checksum`, `txgbe_init_service`, `txgbe_test_hostif`) must never dereference `wx->priv`. [F125, F268]
- Optional pointers must be NULL-checked before use: `wx->msix_q_entries` and `wx->msix_entry` (NULL in MSI/INTx fallback; check `pdev->msix_enabled` or non-NULL), `wx->ptp_setup_sdp` (NULL on `wx_mac_sp`), `wx->b4_addr` (NULL on VFs like `ngbevf` in `wx_reset_hw_vf`), and `txgbe->pcs` (NULL on `wx_mac_aml` and copper `wx_mac_sp` in `txgbe_link_irq_handler`). [F38, F39, F40, F204]
- MSI-X queue vectors map to `0..num_q_vectors - 1` with the MISC vector at `num_q_vectors` (`.post_vectors = 1`), except on `wx_mac_em` with `num_vfs == 7` where `__wx_enable_sriov()` sets `WX_FLAG_IRQ_VECTOR_SHARED` (cleared in `wx_sriov_clear_data()`) so misc and queue 0 share vector 0 via `ngbe_misc_and_queue()`. [F77, F136]
- `wx_clean_rx_ring()` must zero `rx_ring->desc` and reset `next_to_alloc`, `next_to_clean`, and `next_to_use` to 0, while `wx_alloc_rx_buffers()` must zero `wb.upper.status_error` and `length` on the sentinel `next_to_use` descriptor before updating indices and `rx_ring->tail`. In `wx_clean_rx_irq()`, `wx_is_non_eop()` must run before any `continue`. Extended status/error bits (`WX_RXD_STAT_*`, `WX_RXD_ERR_*`) live in `rx_desc->wb.upper.status_error` and must be tested via `wx_test_staterr()`. [F51, F85, F104]
- `wx_setup_mrqc()` must call `wx_config_rss_field()`, `wx_enable_rss()`, and `wx_setup_reta()` even when `WX_FLAG_VMDQ_ENABLED` is set. When both `WX_FLAG_SRIOV_ENABLED` and `WX_FLAG_MULTI_64_FUNC` are set, PF RSS helpers must program per-pool registers indexed by `wx->num_vfs`, and all PF RETA loops must bound iteration by `wx_rss_indir_tbl_entries(wx)` (64 with SR-IOV, 128 otherwise). In `wx_set_rss_queues()`, reset `RING_F_FDIR.indices = 1` before checking `if (f->indices > 1)`. [F49, F63, F82, F91]
- In the 64-entry VLVF table (`WX_PSR_VLAN_SWC_IDX`), index 0 is reserved for VLAN 0; non-zero VLAN loops in `wx_find_vlvf_slot()`, `wx_find_vlvf_entry()`, `wx_vlan_promisc_enable()`, and `wx_scrub_vfta()` must iterate only `1..WX_PSR_VLAN_SWC_ENTRIES - 1`, and `wx_vlan_promisc_disable()` must call `wx_scrub_vfta()`. `wx_write_mc_addr_list()` must call `wx_restore_vf_multicasts()` when `WX_FLAG_SRIOV_ENABLED` is set because `wx_update_mc_addr_list()` zeroes `mta_shadow`. [F53, F54, F79]
- Reading `WX_VXMAILBOX` clears `WX_VXMAILBOX_R2C_BITS` (RSTD, PFSTS, PFACK), so VF code must use `wx_read_v2p_mailbox()` to latch them in `wx->mbx.mailbox` and `wx_check_for_bit_vf()` to clear one bit. `wx_set_vf_multicasts()` must clamp the count from `msgbuf[0]` to `WX_MAX_VF_MC_ENTRIES` (30), and `wx_get_queues_vf()` must clamp PF-supplied queue/TC counts to `1..WX_VF_MAX_TX/RX_QUEUES` (4). [F64, F73, F74]
- RAR registers `WX_PSR_MAC_SWC_AD_L` / `AD_H` store MAC bytes reversed (`addr[2..5]` in `AD_L`, `addr[0..1]` in `AD_H`). Tx PTP registers (`WX_TSC_1588_*`) must be accessed via `rd32ptp()` / `wr32ptp()`, and `wx_ptp_rx_hwtstamp()` / `wx_ptp_tx_hwtstamp()` must read `STMPL` before `STMPH` because reading `STMPH` unlocks the hardware timestamp latch. [F67, F87, F145]
- `wx_stop_adapter()` must disable all Tx/Rx queues and call `WX_WRITE_FLUSH(wx)` before `wx_disable_pcie_master()`. `wx_disable_rx()` must save/clear `WX_PSR_CTL_SW_EN` in `wx->mac.set_lben` (restored in `wx_enable_rx()`), and both `wx_disable_rx()` and `txgbe_disable_device()` must skip disabling MAC Rx/Tx when `wx->subsystem_device_id` has `WX_NCSI_SUP` or `WX_WOL_SUP`. `txgbe_reconfig_mac()` must save/restore `WX_MAC_WDG_TIMEOUT` and `WX_MAC_RX_FLOW_CTRL`, and all MAC link-up/reconfig paths must call `txgbe_enable_sec_tx_path(wx)`. [F55, F148, F149, F226, F284, F288]
- `txgbe->fdir_filter_list` must stay sorted by ascending `rule->sw_idx` via `txgbe_update_ethtool_fdir_entry()`, and `txgbe_add_ethtool_fdir_entry()` may update `txgbe->fdir_mask` / call `txgbe_fdir_set_input_mask()` only when `fdir_filter_list` is empty (rejecting mismatched masks otherwise). [F219, F236]

## Synchronization

- `wx_acquire_sw_sync()` and `wx_release_sw_sync()` must hold `wx_sw_sync_lock` and modify only the caller's mask bits in `WX_MNG_SWFW_SYNC`. `wx_read_ee_hostif()` and `wx_read_ee_hostif_buffer()` must hold `WX_MNG_SWFW_SYNC_SW_FLASH` across both `wx_host_interface_command()` and the subsequent `FW_NVM_DATA_OFFSET` mailbox read. [F31, F61]
- `wx_host_interface_command_s()` must release `WX_MNG_SWFW_SYNC_SW_MB` on every exit after `wx_acquire_sw_sync()`, and `wx_host_interface_command_r()` must increment `wx->swfw_index` and clear `WX_STATE_SWFW_BUSY` on every exit after `test_and_set_bit`. Both must convert writes with `cpu_to_le32()`, flush with `rd32a()`, poll `read_poll_timeout()` with `timeout * 1000` us, check the `0x80` status unconditionally, and only be called from process context. [F13, F142, F150]
- All updates to `wx->hw_tc` and `wx->hw_cc` (including `timecounter_read(&wx->hw_tc)` in `wx_ptp_overflow_check()` and `wx_ptp_trigger_calc()`) must hold `write_seqlock_irqsave(&wx->hw_tc_lock, flags)`, while `wx_ptp_timecounter_cyc2time()` uses a `read_seqbegin`/`read_seqretry` loop. `wx->ptp_setup_sdp` must only be called after releasing `wx->hw_tc_lock` and never from hardirq (`wx_ptp_check_pps_event()`). [F20, F151]
- `wx_write/read_mbx_pf` and `wx_write/read_mbx_vf` must first acquire the hardware lock via `wx_obtain_mbx_lock_pf()` or `wx_obtain_mbx_lock_vf()`. VF mailbox callers must hold `spin_lock_bh(&wx->mbx.mbx_lock)` and poll with `readx_poll_timeout_atomic`. PF `wx_msg_task()` and its callees (`wx_rcv_msg_from_vf()`, etc.) run in hardirq context from `__ngbe_msix_misc` and must not sleep or use `GFP_KERNEL`. [F24, F154, F155]
- Ring barriers & NAPI: `wx_tx_map()` executes `wmb()` before setting `first->next_to_watch` and writing `tx_ring->tail` (paired with `smp_rmb()` in `wx_clean_tx_irq()`); `wx_clean_rx_irq()` executes `dma_rmb()` after observing `WX_RXD_STAT_DD` (paired with `wmb()` before `rx_ring->tail` in `wx_alloc_rx_buffers()`); `wx_maybe_stop_tx()` executes `smp_mb()` after `netif_stop_subqueue()` and rechecks `wx_desc_unused()` (paired with `smp_mb()` in `wx_clean_tx_irq()`). `wx_napi_enable_all()` must `INIT_WORK` on DIM work items before `napi_enable()`, and `wx_napi_disable_all()` must `napi_disable()` before `disable_work_sync()`. [F16, F26, F27, F28]
- Hold `txgbe->fdir_perfect_lock` across all accesses to `fdir_filter_list`, `fdir_filter_count`, and `fdir_mask`. `txgbe_fdir_write_perfect_filter()`, `txgbe_fdir_erase_perfect_filter()`, and `txgbe_fdir_enable()` must call `WX_WRITE_FLUSH(wx)` before writing `TXGBE_RDB_FDIR_CMD` or polling, and `txgbe_fdir_check_cmd_complete()` must use `read_poll_timeout_atomic` (runs in softirq `txgbe_atr` and under `fdir_perfect_lock`). [F190, F289, F297]

## Object Lifetimes

- `wx_free_resources()` only frees Tx/Rx rings, not `wx->isb_mem`. In `ngbe_open()` rollback and `ngbe_close()`, call `wx_free_isb_resources(wx)` only after `wx_free_irq(wx)`. In `txgbe`, `wx->isb_mem` persists across `txgbe_close()` and is freed only in `txgbe_remove()` after `unregister_netdev()`. [F3, F182]
- `wx_free_irq()` must skip `free_irq()` on `pdev->irq` and `wx->msix_entry->vector` when `wx->misc_irq_domain` is true, and skip any `msix_q_entries[vector]` whose `q_vector` has neither `rx.ring` nor `tx.ring`. Thus in `txgbe_open()` rollback and `txgbe_close()`, `wx_free_irq(wx)` must run before `txgbe_free_misc_irq(wx->priv)` (which clears `wx->misc_irq_domain`), and `txgbe_free_misc_irq()` must `free_irq()` child/parent IRQs before `txgbe_del_irq_domain()`. In `wx_reset_interrupt_capability()`, check `pdev->msix_enabled` and kfree/NULL `msix_q_entries` and `msix_entry` before `pci_free_irq_vectors()`. [F4, F6, F179, F181]
- `txgbe_sw_init()` and `txgbevf_sw_init()` clean up their own allocations (`rss_key`, `mac_table`, `vfinfo`) on internal failure, so probe must jump to `err_pci_release_regions` if they fail, and unwind through `err_free_mac_table` / `err_free_sw_init` only on later errors. [F177, F178]
- In `ngbe_remove()`, `txgbe_remove()`, and `wxvf_remove()`, call `cancel_work_sync(&wx->service_task)` and `wx_disable_sriov(wx)` before `unregister_netdev()`, and only after `unregister_netdev()` call `phylink_destroy()` / `txgbe_remove_phy()`, `wx_clear_interrupt_scheme()`, or kfree `rss_key`, `mac_table`, and `vfinfo`. Never call `free_netdev()`, `iounmap()`, or `mdiobus_unregister()` on devm-managed resources; for non-copper `wx_mac_sp`, `txgbe_remove_phy()` must tear down in LIFO order (`sfp_dev`, `i2c_dev`, `clock`/`clk`, `phylink`, `pcs`, `nodes.group`), while copper `wx_mac_sp` must call `phylink_disconnect_phy()` before `phylink_destroy()`. [F131, F132, F183, F184, F200]
- `wx_free_q_vector()` must NULL all `wx->tx_ring` and `wx->rx_ring` pointers for its rings and call `netif_napi_del(&q_vector->napi)` before `kfree_rcu(q_vector, rcu)` (paired with `rcu_read_lock()` + `READ_ONCE` in `wx_get_stats64()`). `wx_sriov_clear_data()` must set `wx->num_vfs = 0` before freeing and nulling `wx->vfinfo` and `wx->mv_list`. In `wx_clean_rx_ring()`, sync each buffer with `dma_sync_single_range_for_cpu()` before `page_pool_put_full_page(..., false)`, and call `wx_clean_rx_ring()` before `page_pool_destroy()` in `wx_free_rx_resources()`. [F5, F14, F17, F162]

## API Contracts

- `wx_add_mac_filter()` returns the non-negative RAR slot index on success and negative errno on failure; callers must test `ret >= 0` or `ret < 0`, never `if (ret)`. `wx_tso()` returns `< 0` on error, `1` when TSO was emitted, and `0` otherwise (`wx_xmit_frame_ring()` must drop on `tso < 0` and call `wx_tx_csum()` only when `tso == 0`). [F35, F36]
- `wx_tso()` must call `skb_cow_head(skb, 0)` before mutating headers. When parsing outer/inner IPv6 headers in `wx_encode_tx_desc_ptype()`, `wx_tso()`, and `wx_tx_csum()`, use `ipv6_skip_exthdr()` if the transport header does not immediately follow `struct ipv6hdr`, and treat both `IPPROTO_IPIP` and `IPPROTO_IPV6` as IP-in-IP tunnels. In `wx_tx_csum()`, if `CHECKSUM_PARTIAL` is not TCP/SCTP/UDP, call `skb_checksum_help(skb)` without setting `WX_TX_FLAGS_CSUM`. [F165, F166, F169]
- In `txgbe_phy.c`, MDIO, GPIO, and I2C regmap callbacks pass/cast `struct wx *`, whereas `txgbe_irq.c` domain `host_data` and IRQ handlers pass/cast `struct txgbe *`. `txgbe_phylink_mac_select()` must return `txgbe->pcs` whenever `wx->media_type != wx_media_copper`, and `NULL` for copper. `txgbe_xpcs_switch_mode()` may only be called from process context, and `txgbe_write_pma()` / `txgbe_modify_pma()` automatically add `TXGBE_PMA_MMD` (`0x8020`). [F216, F269, F278, F298]
- In `txgbe_flowspec_to_flow_type()`, mask `fsp->flow_type` with `~FLOW_EXT` before switching, and under `IP_USER_FLOW` allow `proto == 0` only when `m_u.usr_ip4_spec.proto == 0`. `txgbe_atr_compute_perfect_hash()` requires `input_mask->formatted.bkt_hash == 0` and must be called before checking duplicates or writing hardware, and `txgbe_fdir_write_perfect_filter()` requires `queue` mapped to hardware `reg_idx`, not raw `ring_cookie`. [F220, F249, F302]

## Error Handling

- When storing `ERR_PTR`-returning allocators into nullable fields (`rx_ring->page_pool` in `wx_alloc_page_pool()`, `wx->ptp_clock` in `wx_ptp_create_clock()`) or in `txgbe_phy.c` / `txgbe_aml.c` (`xpcs_create_pcs_mdiodev`, `phylink_create`, `clk_register_fixed_rate`, `devm_regmap_init`, `platform_device_register_full`), check `IS_ERR()` and extract `PTR_ERR()` before resetting the field to `NULL` (or check in a local variable before assigning). [F11, F32, F206]
- In `wx_set_interrupt_capability()`, when `wx_acquire_msix_vectors()` fails on a PF and falls back to MSI/INTx via `pci_alloc_irq_vectors()`, explicitly set `wx->num_q_vectors = 1` before calling `wx_alloc_q_vectors()`. In `txgbe_open()`, if `txgbe_request_queue_irqs()` or `netif_set_real_num_tx/rx_queues()` fails after `txgbe_setup_misc_irq()`, unwind via `err_free_misc_irq` (`txgbe_free_misc_irq` then `wx_reset_interrupt_capability`) before `wx_free_resources`. [F41, F180]
- `wx_set_vfta()` must call `wx_set_vlvf()` and verify it returned `0` before writing `WX_PSR_VLAN_TBL(regindex)` or `wx->mac.vft_shadow[regindex]`. In `txgbe_add_ethtool_fdir_entry()`, `err` is initialized to `-EINVAL` and relied upon by flow-type, mask `memcmp`, and duplicate-match jumps to `err_out`/`err_unlock`; no intermediate call may leave `err == 0` before those jumps. [F47, F207]

## External Contracts

- `wx_xmit_frame()` must pad skbs to 17 bytes via `skb_put_padto(skb, 17)` and return `NETDEV_TX_OK` without freeing `skb` if it fails. BQL accounting must stay balanced across `wx_tx_map()` (`netdev_tx_sent_queue`), `wx_clean_tx_irq()` (`netdev_tx_completed_queue`), and `wx_clean_tx_ring()` (`netdev_tx_reset_queue`). [F170, F174]
- In `txgbe_ethtool.c`, only call `txgbe_fdir_write_perfect_filter()` or `txgbe_fdir_erase_perfect_filter()` when `netif_running(wx->netdev)` is true. `txgbe_fdir_set_input_mask()` must bitwise-invert port and IPv4 masks before writing FDIR mask registers, and `txgbe_atr()` on tunneled packets (`wx_decode_ptype(ptype).etype != 0`) must use `skb_inner_network_header` and `inner_tcp_hdr` with inverted ports (`src ^= th->dest`, `dst ^= th->source`). [F239, F299, F303]

## Known Pitfalls

- Widen 32-bit high register reads to `u64` before `<< 32` in `rd64()`, `wx_ptp_readtime()` (which must also bracket `SYSTIML` with two reads of `SYSTIMH`), and `wx_ptp_tx/rx_hwtstamp()`. Use `1ULL << pool` for `u64` `wx->mac_table[i].pools` (`pool` up to 63), and widen ns values to `u64` before `<< cc->shift` (using `div_u64`/`div_u64_rem`) in `wx_ptp.c`. [F109, F110, F111, F118]
- In `union txgbe_atr_input` (must be zero-initialized before setting IPv4 fields) and `txgbe_atr()` (`input, common = { .dword = 0 }` and NULL-check `ring->q_vector`), IP/port/VLAN/flex fields are big-endian (widen `ntohs(dst_port)` / `ntohs(flex_bytes)` to `u32` before `<< 16`), whereas `formatted.bkt_hash` is stored in host byte order via `(__force __be16)` and read without byte-swapping. [F210, F211, F238, F259]
- `wx->rss_key` is a `u32 *` pointer; always pass `WX_RSS_KEY_SIZE` (40), never `sizeof(wx->rss_key)`. Allocate `struct wx_q_vector` with `struct_size(q_vector, ring, txr_count + rxr_count)`. After `list_for_each()` in `wx_set_vf_macvlan()`, test `!entry || !entry->free`; after `hlist_for_each_entry_safe()` in `txgbe_get/update_ethtool_fdir_entry()`, check `rule != NULL` before dereferencing `rule->sw_idx`. [F98, F119, F121, F248]
- VF mailbox callers checking `msgbuf[0]` after `wx_mbx_write_and_read_reply()` must mask off `WX_VT_MSGTYPE_CTS` before comparing against `OPCODE | WX_VT_MSGTYPE_ACK/NACK`. In `txgbe_reset()`, copy `wx->mac_table[0].addr` to a local buffer before `wx_flush_sw_mac_table(wx)` zeroes it in place. In `txgbe_calc_eeprom_checksum()`, callers must zero `*checksum` beforehand and allow wrapping `u16` arithmetic (`TXGBE_EEPROM_SUM - *checksum`). [F66, F224, F258]
