# RUST

The RUST unit comprises the core `kernel` crate (`rust/kernel/*`), C FFI and UAPI bindings (`rust/bindings/*`, `rust/uapi/*`), C helper wrappers (`rust/helpers/*.c`), procedural macros (`rust/macros/*`), and `scripts/generate_rust_target.rs`. It exposes kernel primitives—reference counting (`Arc`, `ARef`, `ListArc`), intrusive collections (`List`, `RBTree`), synchronization (`CondVar`, `Revocable`), workqueues, `UserSlice` and `IovIterSource`/`IovIterDest`, formatting, error handling, and subsystem abstractions—along with build-time target generation and macros.

## Architecture & Data Flow

- `unsafe trait AsBytes` types must have no uninitialized padding or interior mutability and should not contain kernel pointers; `unsafe trait FromBytes` permits padding only if every bit pattern is valid and it has no interior mutability. Broken by: `AsBytes` on structs with padding or raw pointers, or `FromBytes` on `bool`/enums with invalid bit patterns. [F60]
- `UserSliceReader::read_raw` and `IovIterSource::copy_from_iter_raw` must never write uninitialized bytes into `out: &mut [MaybeUninit<u8>]` even on failure or partial copy, because `read_slice` and `copy_from_iter` cast `&mut [u8]` to `&mut [MaybeUninit<u8>]`. [F33]
- `UserSliceReader` (`skip`, `read_raw`, `read`) and `UserSliceWriter` (`write_slice`, `write`) must check `len <= self.length` and verify `copy_from_user`/`copy_to_user` returned `0` before updating `self.ptr` and `self.length`, using `UserPtr::wrapping_byte_add` so addresses near `usize::MAX` do not panic under `CONFIG_RUST_OVERFLOW_CHECKS`. [F51, F88]
- `ListArc` lifecycle transitions must keep `T`'s `ListArcSafe<ID>` tracker synchronized: `From<Pin<UniqueArc<T>>>` and `pair_from_pin_unique` call `on_create_list_arc_from_unique`, `into_arc` and `Drop::drop` call `on_drop_list_arc`, and `into_raw` uses `transmute_to_arc` so tracking stays active while raw. [F48]
- In `ListLinks<ID>`, `prev` and `next` are null iff the item is not in a `List`, and `ListItem::view_links` must return two null pointers outside `prepare_to_insert`..`post_remove`. In `List::remove_internal_inner`, after relinking `(*next).prev` and `(*prev).next`, both `(*item).prev` and `(*item).next` must be set to `ptr::null_mut()` before updating `self.first = (*prev).next` and calling `T::post_remove` and `ListArc::from_raw`. [F7, F41]
- `ListLinksSelfPtr<T, ID>` must remain `#[repr(C)]` with `inner: ListLinks<ID>` first, and `ListItem::prepare_to_insert` must write `me` into `self_ptr` before returning `links_field` so `view_value` and `post_remove` can recover `*const Self`. `List::push_all_back` must reset `other.first` to `ptr::null_mut()` after splicing so dropping `other` does not double-remove elements. [F46, F100]
- In `list::Cursor::prev_ptr`, `next == first` must be checked before `next.is_null()` substitutes `next = first` before dereferencing `(*next).prev`. In `list::Iter::next` and `list::Cursor::move_next`, the pointer must be reset to `ptr::null_mut()` whenever `(*current).next` equals `first` (`stop`). [F74, F75]
- `ForeignOwnable::into_foreign` must return a non-null pointer aligned to `Self::FOREIGN_ALIGN`, and `borrow_mut` must never let callers change the address of the foreign-owned allocation (e.g., yielding `&mut Self` on a pointer wrapper). [F107]
- `unsafe impl AlwaysRefCounted` is only sound when every instance is reference-counted and `inc_ref` keeps the allocation alive until a matching `dec_ref`, since `From<&T> for ARef<T>` upgrades any `&T` to `ARef<T>`. Broken by: implementing it on C wrappers that can be stack-allocated or embedded without active refcounting. [F109]
- In `HasWork<T, ID>` and `HasDelayedWork<T, ID>`, `raw_get_work` and `work_container_of` must be exact inverses for `ID`, and for `HasDelayedWork<T, ID>`, `raw_get_work` must point to the `work` field of a `bindings::delayed_work`. [F99]
- `RawFormatter::write_str` must advance `self.pos` via `saturating_add(s.len())` while clamping copied bytes to `min(pos_new, self.end).saturating_sub(self.pos)` so writes never overrun `self.end` while `self.pos` reflects the total formatted length for `rust_fmt_argument` (`%pA`) and `CString::try_from_fmt`. [F65]
- `Error` wraps a `NonZeroI32` in `>= -(bindings::MAX_ERRNO as i32) && < 0`: `Error::from_errno` and `to_result` treat `< -MAX_ERRNO` (and `from_errno` treats `>= 0`) as a bug (warning and returning `EINVAL`), and `from_result` casts `e.to_errno() as i16`. Broken by: passing `0`, positive values (like `bindings::EINVAL`), or `< -MAX_ERRNO` to `Error::from_errno_unchecked` or `Error::from_errno`. [F69]
- In `rust/kernel/ptr.rs`, `Alignable::align_down` and `align_up` must convert `alignment` (`Alignment`) into `Self` via `try_from` rather than truncating `alignment.mask()` or `alignment.as_usize()` with `as Self`, returning `0` in `align_down` and `None` (for non-zero `self`) in `align_up` when alignment exceeds `Self::MAX`. [F87]

## Synchronization

- Callers holding a `RevocableGuard` (`Revocable::try_access`) or a reference from `Revocable::try_access_with_guard` must not sleep, because `RevocableGuard` holds an RCU read lock (`rcu::Guard`) while `Revocable::revoke` waits on `bindings::synchronize_rcu()`. [F120]
- Calling `bindings::task_active_pid_ns` without RCU protection or refcount elevation (`CurrentTask::active_pid_ns`) is only sound on `current`; arbitrary `Task`s must use `Task::get_pid_ns` (`rust_helper_task_get_pid_ns`), which holds `guard(rcu)()` and calls `get_pid_ns`. [F146]
- `CondVar::wait_internal` must call `prepare_to_wait_exclusive` before releasing `guard` via `guard.do_unlocked`, and `finish_wait` after `do_unlocked` reacquires the lock and before `wait` goes out of scope. When calling `CondVar::wait_interruptible_freezable`, no lock other than `guard` may be held, to avoid freezer deadlocks. [F11, F129]
- `IovIterSource` and `IovIterDest` must remain `!Send` because `struct iov_iter` may reference thread-local `kmap_local_page()` mappings requiring same-task access. [F133]

## Object Lifetimes

- `ForeignOwnable::from_foreign` must be called at most once per `into_foreign` call and only after all borrows from `ForeignOwnable::borrow` or `borrow_mut` on that pointer have ended. [F2]
- `CurrentTask` (`current!()`, `Task::current()`) must never escape the active task context—including across `kthread_use_mm()`/`kthread_unuse_mm()`, `begin_new_exec()`, `release_task()`, or return to userspace—so closures entering a new mm/task sub-context must require `Send` to be blocked by `NotThreadSafe`. [F113]
- When deriving a related or parent device reference from a child wrapper (such as `&usb::Device` from `&usb::Interface<Ctx>` via `AsRef`), the child's `device::DeviceContext` parameter `Ctx` must not be propagated to the target type unless the target device is guaranteed to share that bound and lock state. [F110]
- In `RBTree::drop`, `bindings::rb_next_postorder(next)` must be called before `drop(KBox::from_raw(this))`, and in `rbtree::Cursor::remove_current`, `get_neighbor_raw` must be called before `bindings::rb_erase`. [F9]
- `print_macro!` must bind `fmt!($($arg)+)` as the scrutinee of a `match` around `call_printk` rather than a `let` binding, and `call_printk`'s `module_name` (`__LOG_PREFIX`) must be NUL-terminated for `_printk`'s `%s`. [F92]

## API Contracts

- `ARef::from_raw` takes ownership of an existing refcount increment without calling `AlwaysRefCounted::inc_ref`, whereas `ARef::from(&T)` and `ARef::clone` call `inc_ref` before `ARef::from_raw`. [F4]
- Callers reading and validating userspace memory via `UserSlice` must construct a single `UserSlice` per region and validate the kernel copy rather than calling `UserSlice::new` or `UserSliceReader::clone_reader` to read the same userspace address twice (TOCTOU). [F56]
- Before advancing a `Vec<u8, A>` via `unsafe { buf.inc_len(len) }` after an FFI read into `spare_capacity_mut()`, callers must bound `len` to the byte count actually initialized by C (e.g., `_copy_from_iter` return in `copy_from_iter_vec` or `Ok(())` from `UserSliceReader::read_raw`). [F116]
- Closures passed to `Opaque::ffi_init` and `try_ffi_init` receive an uninitialized `*mut T` and must not read from it before initializing it, and `Opaque::get` callers must ensure the inner `T` was initialized before dereferencing. [F105]
- `DelayedWork::new` must initialize `(*slot).work` via `bindings::init_work_with_key` and `(*slot).timer` via `bindings::timer_init_key` with `Some(bindings::delayed_work_timer_fn)` and `bindings::TIMER_IRQSAFE`. Work items on `workqueue::system_bh()` or `system_bh_highpri()` run in softirq context and must not sleep or allocate with `GFP_KERNEL`. [F23, F132]
- `IovIterSource::from_raw` and `IovIterDest::from_raw` require `data_source` to be `ITER_SOURCE` or `ITER_DEST` respectively, valid buffers for `'data`, and exclusive `iov_iter` access for `'iov`. [F112]
- In `rust/kernel/ioctl.rs`, `_IOC` (`_IO`, `_IOR`, `_IOW`, `_IOWR`) requires `dir <= uapi::_IOC_DIRMASK`, `ty <= uapi::_IOC_TYPEMASK`, `nr <= uapi::_IOC_NRMASK`, and `size_of::<T>() <= (uapi::_IOC_SIZEMASK as usize)` at compile time. [F86]
- Kernel logging macros (`pr_emerg!`..`pr_debug!`) do not append a newline; format strings must end with `\n` unless followed by `pr_cont!`. In `rust/kernel/lib.rs`, top-level subsystem modules must be gated only on their core Kconfig symbol (e.g., `CONFIG_PCI`) rather than optional sub-features (`CONFIG_PCI_MSI`). [F91, F138]

## Error Handling

- `to_result` treats any `err >= 0` as `Ok(())` and only maps negative values via `Error::from_errno`, while `from_err_ptr` only checks `bindings::IS_ERR` and returns `Ok(ptr)` on `NULL`. Broken by: using `to_result` when C returns positive errors or needed positive values, or wrapping `from_err_ptr` in `NonNull::new_unchecked` when C can return `NULL`. [F28, F29]
- In `<Arc<T> as RawWorkItem<ID>>::__enqueue`, `Arc::into_raw(self)` transfers one refcount before `queue_work_on(work_ptr)`, and if `queue_work_on` returns `false`, ownership must be reclaimed via `Err(unsafe { Arc::from_raw(ptr) })`. [F12]
- `copy_from_user`/`copy_to_user` return uncopied bytes (`res != 0` on failure, mapped to `Err(EFAULT)` without advancing `ptr` or `length`), whereas `strncpy_from_user` returns negative errno or copied length. `UserSliceReader::strcpy_into_buf` must reject empty `buf` (`Err(EINVAL)`), cap `raw_strncpy_from_user` to `self.length`, return `Err(EFAULT)` if `len == dst.len() < buf.len()`, and write `0` to the last byte of `buf` when `len == buf.len()`. [F34, F59]
- `IovIterDest::simple_read_from_buffer` must reject `*ppos < 0` with `Err(EINVAL)`, return `Ok(0)` without modifying `*ppos` when `*ppos` exceeds `usize::MAX` or `contents.len()`, and otherwise advance `*ppos` by the bytes copied. [F63]
- `CondVar::wait_interruptible_timeout` must check `crate::current!().signal_pending()` before checking whether remaining jiffies from `schedule_timeout` is `0`, returning `CondVarTimeoutResult::Signal { jiffies }` if both occur. [F42]

## External Contracts

- Rust functions called from C (`rust_fmt_argument`, `WorkItemPointer::run`, `usb::Adapter` callbacks) must be `extern "C"`, and FFI/`#[export]` signatures must use `crate::ffi::{c_char, c_long, c_ulong}` rather than `core::ffi` so signatures and CFI match `bindings` across all architectures. [F90, F134]
- C macro constants using expressions or `BIT()` (e.g., `VM_MERGEABLE`, `BLK_FEAT_ROTATIONAL`, `FOP_UNSIGNED_OFFSET`, `GFP_*`) must be bound via `const <type> RUST_CONST_HELPER_<NAME> = <NAME>;` in `rust/bindings/bindings_helper.h` with their exact C typedef. `rust/uapi/lib.rs` must keep `pin_init::MaybeZeroable` and `__kernel_{size,ssize,ptrdiff}_t` in scope before `uapi_generated.rs`. [F82, F200]
- C-header inline assembly templates (`jump_label.rs`, `bug.rs`) must use `$crate::asm!` rather than `core::arch::asm!` so `options(att_syntax)` applies on x86/x86_64. In `rust/helpers/io.c`, 64-bit MMIO helpers (`rust_helper_{read,write}q*`) must be guarded by `#ifdef CONFIG_64BIT`. Panicking intrinsics in `rust/compiler_builtins.rs` must also be listed in `redirect-intrinsics` in `rust/Makefile`. [F122, F135, F137]
- In `scripts/generate_rust_target.rs`: `KernelConfig::has` takes symbol names without `CONFIG_`; `target-pointer-width` is an integer on `rustc >= 1.91.0` and a string otherwise; endianness checks `cfg.has("CPU_BIG_ENDIAN")`; `X86_32` must panic unless `cfg.has("UML")`; and `X86_64` `features` must include `+retpoline-external-thunk,+retpoline-indirect-branches,+retpoline-indirect-calls` (`MITIGATION_RETPOLINE`) and `+harden-sls-ijmp,+harden-sls-ret` (`MITIGATION_SLS`). [F164, F168, F170, F194, F195]

## Known Pitfalls

- In `list::CursorPeek::remove`, `self.cursor.move_next()` must run before `self.cursor.list.remove_internal(self.ptr)` when `ISNEXT` is true, and `while let Some(next) = cursor.peek_next()` loops must not call `cursor.move_next()` after `next.remove()`. [F76]
- `impl_list_arc_safe!` must call `::pin_init::assert_pinned!($t, $field, $fty, inline)` rather than `$crate::assert_pinned!`. In `static_branch_unlikely!`, the `#[cfg(not(CONFIG_JUMP_LABEL))]` arm must pass `_key.cast_mut()` to `$crate::bindings::static_key_count`. [F49, F54]
- In `rust/bindings/bindings_helper.h`, headers defining C `enum`s (e.g., `<linux/hrtimer_types.h>`) must precede headers that forward-declare them so `bindgen` emits `c_uint` instead of `i32`. `rust/helpers/atomic.c` is generated by `scripts/atomic/gen-rust-atomic-helpers.sh` and must not be hand-edited alone. [F55, F81]
- In `paste::expand`, `tokens.splice(i + 3..i + 4, ...)` must run before `tokens.splice(i..i + 1, ...)` in `.rev()`. In `scripts/generate_rust_target.rs`, `KernelConfig::from_stdin` must call `line.clear()` at the top of the loop before `read_line`, and `TargetSpec` strings must not contain unescaped quotes, backslashes, or newlines. [F161, F175, F179]
