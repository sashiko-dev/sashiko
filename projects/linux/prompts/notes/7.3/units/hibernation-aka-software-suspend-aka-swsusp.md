# HIBERNATION (aka Software Suspend, aka swsusp)

`kernel/power` implements Linux system sleep, hibernation (software suspend / swsusp), autosleep, userspace wakelocks, and Power Management Quality of Service (PM QoS), coordinating process freezing, device power transitions, radix-tree memory snapshots, and swap image I/O.

## Architecture & Data Flow
- `create_basic_memory_bitmaps()` must set `forbidden_pages_map` and `free_pages_map` only after both `memory_bm_create()` calls succeed, and `free_basic_memory_bitmaps()` must set both globals to `NULL` before `memory_bm_free()`. Every image page (and unsafe pages skipped in `get_image_page()`) must be marked in both maps via `swsusp_set_page_forbidden()` and `swsusp_set_page_free()`, and cleared in `free_unnecessary_pages()` or `free_image_page()`. [F47, F62]
- `rtree_next_node()` must test `list_is_last()` before advancing `bm->cur.node` or `bm->cur.zone` so cursors never point to list heads. `memory_bm_next_pfn()` must clamp `find_next_bit()` to `min(pages - bm->cur.node_pfn, BM_BITS_PER_BLOCK)`. In `swsusp_free()`, the intersection loop must advance the smaller of `fb_pfn` and `fr_pfn` until equal, and advance both at `loop:` after freeing each matched page until `BM_END_OF_MAP` (`~0UL`). [F96, F103, F118]
- In `copy_data_pages()`, advance `copy_pfn = memory_bm_next_pfn(copy_bm)` only when `copy_data_page(copy_pfn, pfn)` returns `false` (reusing `copy_pfn` when zero-page sets `zero_bm`). In `snapshot_write_next()`, if a PFN is set in `zero_bm` after `handle->cur++`, zero `handle->buffer` and jump to `next:` so `copy_last_highmem_page()`, `hibernate_restore_protect_page()`, and `get_buffer()` run; also recompute `handle->sync_read = (handle->buffer == buffer)` on every step and set `last_highmem_page` whenever `get_highmem_page_buffer()` returns `buffer`. [F63, F100, F101]
- For source pages with `!kernel_page_present(s_page)`, `safe_copy_page()` must bracket the copy with `hibernate_map_page()` and `hibernate_unmap_page()` (flushing TLB via `flush_tlb_kernel_range()`). `restore_highmem()` must swap `pbe->copy_page` and `pbe->orig_page` in place via `swap_two_pages_data()`, and `resume_target_kernel()` must call `restore_highmem()` a second time if `swsusp_arch_resume()` fails. On restore (`!in_suspend`) in `create_image()`, `clear_or_poison_free_pages()` must run before enabling IRQs or secondary CPUs. [F68, F153, F169]
- `unpack_orig_pfns()` must check `buf[j] == BM_END_OF_MAP` (`~0UL`) before masking `ENCODED_PFN_ZERO_FLAG` with `ENCODED_PFN_MASK`, and verify `pfn_valid(decoded_pfn) && memory_bm_pfn_present(bm, decoded_pfn)` before `memory_bm_set_bit()`. Both `load_image()` and `load_compressed_image()` must flush icaches (`clean_pages_on_read` / `clean_pages_on_decompress`), call `snapshot_write_finalize()`, and verify `snapshot_image_loaded()`. [F71, F82]
- In `load_compressed_image()`: `CMP_SIZE` must be a `PAGE_SIZE` multiple `>= DIV_ROUND_UP(bytes_worst_compress(UNC_SIZE) + CMP_HEADER, PAGE_SIZE) * PAGE_SIZE`; on-disk `data[thr].cmp_len` must be checked non-zero and `<= bytes_worst_compress(UNC_SIZE)` before computing `need` or copying; after decompression, `data[thr].unc_len` must be non-zero, `<= UNC_SIZE`, and `PAGE_SIZE`-aligned; and `page[]` must allocate `ring_size >= CMP_PAGES` pages and wrap `ring` and `pg` at `ring_size`. [F79, F80, F81, F119]
- `struct swsusp_header` (`__packed`, `sizeof == PAGE_SIZE`) must size `reserved[]` so `sig[10]` is at the last 10 bytes of the page. `mark_swapfiles()` must verify `"SWAP-SPACE"`/`"SWAPSPACE2"` and save `orig_sig` before writing `HIBERNATE_SIG`; `swsusp_check()` (immediately via `REQ_OP_WRITE | REQ_SYNC` before checking `SF_HW_SIG` or loading) and `swsusp_unmark()` (including on `power_down()` rollback) must restore `sig` from `orig_sig`. In `swap_read_page()`, when `++handle->k >= MAP_PAGE_ENTRIES`, free the consumed map page/node, refresh `handle->cur` (or call `release_swap_reader()`), and reset `handle->k = 0`. [F67, F73, F84, F176]
- `MAX_ARCH_HEADER_SIZE` must not exceed `offsetof(struct swsusp_info, num_physpages)`. `swsusp_save()` must compute `nr_meta_pages = DIV_ROUND_UP(nr_pages * sizeof(long), PAGE_SIZE)` to match `pack_pfns()`/`unpack_orig_pfns()`. `snapshot_state` is a singleton: `snapshot_open()` must reset `handle`, `free_bitmaps`, `frozen`, `ready`, `platform_support`, and `dev = 0`; `SNAPSHOT_UNFREEZE` must clear `data->free_bitmaps`; `snapshot_set_swap_area()` sets `dev = swdev` and `snapshot_release()` resets `dev = 0`. [F64, F115, F117, F173]
- `enter_state()`, `hibernation_snapshot()`, and `hibernate_quiet_exec()` must call `pm_suspend_clear_flags()`, and `suspend_devices_and_enter()` must call `pm_set_suspend_no_platform()` for `PM_SUSPEND_TO_IDLE`. `entering_platform_hibernation` must be set `true` before suspending consoles/devices in `hibernation_platform_enter()` and around `kernel_power_off()`, and reset `false` on exit/error. `suspend_set_ops()` and `mem_sleep_default_setup()` must keep `mem_sleep_current`, `mem_sleep_states[]`, and `pm_states[]` in sync; `hibernation_set_ops()` must couple `hibernation_mode` (`HIBERNATION_PLATFORM` vs `HIBERNATION_SHUTDOWN`) with `hibernation_ops` under `lock_system_sleep()`. [F59, F60, F66, F133]
- `pm_labels[]`, `pm_states[]`, `mem_sleep_labels[]`, and `mem_sleep_states[]` leave index `0` (`PM_SUSPEND_ON`) NULL, so iterate `PM_SUSPEND_MIN..PM_SUSPEND_MAX`; `hibernation_modes[]` leaves `0` (`HIBERNATION_INVALID`) NULL, so iterate `HIBERNATION_FIRST..HIBERNATION_MAX`. In `struct suspend_stats`, `step_failures[]` is indexed by `step - 1`, so `dpm_save_failed_step()` must never be called with `SUSPEND_WORKING` (`0`). [F74, F75, F76]

## Synchronization
- Lock ordering: `autosleep_lock` -> `system_transition_mutex` -> `lock_device_hotplug()`; run `wait_for_device_probe()` before `system_transition_mutex`. Pass flags from `lock_system_sleep()` to `unlock_system_sleep()` to preserve `PF_NOFREEZE`. Every hibernation entry point and `/dev/snapshot` session (`snapshot_open()`..`snapshot_release()`) must call `hibernate_acquire()` under `system_transition_mutex` and `hibernate_release()` on all exits. `pm_restrict_gfp_mask()`/`pm_restore_gfp_mask()` require `system_transition_mutex`, and when `hibernation_snapshot()` succeeds (`in_suspend && !error`), keep `gfp_allowed_mask` restricted across `dpm_resume()`/`dpm_complete()`. [F29, F30, F132, F145, F147]
- `swsusp_save()` runs inside `swsusp_arch_suspend()` on one CPU with local IRQs disabled; all allocations in `swsusp_save()` and `swsusp_alloc()` must use non-sleeping GFP flags (`GFP_ATOMIC` or `__GFP_HIGHMEM|__GFP_KSWAPD_RECLAIM`). [F151]
- In `kernel/power/swap.c`, worker handshakes must pair `atomic_set_release()` with `atomic_read_acquire()` on `ready` and `stop` in `cmp_data`, `dec_data`, and `crc_data`; in `save_compressed_image()`, wait only on `run_threads = thr` and reset `stop` to `0` after `wait_event()`. In `hib_submit_io_async()`, set `bi_end_io`/`bi_private` and `atomic_inc(&hb->count)` before `submit_bio()`, and in `hib_end_io()` set `hb->error` before `atomic_dec_and_test(&hb->count)`. [F20, F22, F102]
- In `s2idle_enter()`, hold `s2idle_lock` across `pm_wakeup_pending()` and setting `s2idle_state = S2IDLE_STATE_ENTER`, and call `wake_up_all_idle_cpus()` after `swait_event_exclusive()` before resetting `s2idle_state`. In `s2idle_loop()`, when `s2idle_ops && s2idle_ops->wake` is present, break directly on `s2idle_ops->wake()` without calling `pm_wakeup_pending()` or `pm_wakeup_clear()`. [F24, F135]
- Callers of `autosleep_lock` must activate a `wakeup_source` first or use `pm_autosleep_lock()` (`mutex_lock_interruptible`); `try_to_suspend()` must revalidate `pm_save_wakeup_count(initial_count)`, `system_state == SYSTEM_RUNNING`, and `autosleep_state != PM_SUSPEND_ON` under `autosleep_lock`. Mutations of `pm_qos_constraints` (`WRITE_ONCE(c->target_value, ...)`) and `pm_qos_flags` must hold `spin_lock_irqsave(&pm_qos_lock, flags)` and recompute effective values under the lock, call `blocking_notifier_call_chain()` after unlocking, and clear `req->qos = NULL` (and `req->type`) on `cpu_latency_qos_remove_request()`, `freq_qos_remove_request()`, and `freq_qos_add_request()` failure (`freq_qos_apply() < 0`). [F19, F25, F26, F31, F69]
- Under `wakelocks_lock`, `wakelock_lookup_add()` (setting `wl->ws->last_time = ktime_get()`) and `__wakelocks_gc()` must update `wakelocks_tree`, `wakelocks_lru_list`, `wl->ws`, and `number_of_wakelocks` together; `__wakelocks_gc()` must use `list_for_each_entry_safe_reverse()`, check `last_time`/`active` under `spin_lock_irq(&wl->ws->lock)`, and unlock `wl->ws->lock` before `wakeup_source_unregister()`. Hold `suspend_stats_lock` in `dpm_save_failed_dev()`. Validate early-boot `__setup` state strings against static `pm_labels[]`, not `pm_states[]`. [F32, F35, F36, F70, F98]

## Object Lifetimes
- Call `swsusp_free()` before `free_basic_memory_bitmaps()` (because `swsusp_free()` returns early if either bitmap pointer is NULL), and call `hibernate_restore_unprotect_page(page_address(page))` before `__free_page(page)` in `swsusp_free()`. In `snapshot_ioctl()`, `SNAPSHOT_FREE` must call `thaw_kernel_threads()` after `swsusp_free()`. `snapshot_read_next()` must never return a live `kmap_local_page()` mapping in `handle->buffer`; copy highmem pages into `buffer` between `kmap_local_page()` and `kunmap_local()`. [F6, F17, F155, F158]
- Functions using a stack `struct hib_bio_batch` must call `hib_wait_io(&hb)` before freeing buffers or returning; for async writes (`hb != NULL`), `write_page()` must use a newly allocated bounce page because `hib_end_io()` calls `put_page()`. In `save_compressed_image()`/`load_compressed_image()`, reset failed `kthread_run()` pointers to `NULL` (and set `ring_size = i` on `page[i]` alloc failure for `i < CMP_PAGES`) before `goto out_clean`, and call `kthread_stop()` before freeing transforms/buffers. In `swap_writer_finish()`, call `free_all_swap_pages(root_swap)` if `error` or `mark_swapfiles()` fails. [F13, F14, F51, F120, F174]
- Call `dpm_complete()` even when `dpm_prepare(PMSG_FREEZE)` fails. Whenever `dpm_suspend_end()` succeeded in `create_image()`, `hibernate_quiet_exec()`, or `hibernation_platform_enter()`, call `platform_finish()` before `dpm_resume_start()` (and after `platform_leave()` and `arch_resume_nosmt()` on `!in_suspend` in `create_image()`). In `resume_target_kernel()`, once `platform_pre_restore()` is called, call `platform_restore_cleanup()` before `dpm_resume_start(PMSG_RECOVER)` on all error paths. `suspend_enter()` must unwind `platform_*` and `dpm_*` stages in exact reverse order, with `s2idle_ops->wake()`/`check()` running inside `s2idle_loop()` before `platform_resume_noirq()`. [F127, F128, F129, F131, F134, F136]

## API Contracts
- Gate all hibernation/resume entry points on `hibernation_available()` (`nohibernate == 0`, `!security_locked_down(LOCKDOWN_HIBERNATION)`, `!secretmem_active()`, `!cxl_mem_active()`). Check `capable(CAP_SYS_ADMIN)` in `snapshot_ioctl()` before locking `system_transition_mutex`, and `capable(CAP_BLOCK_SUSPEND)` in `pm_wake_lock()`/`pm_wake_unlock()` before `wakelocks_lock`. [F166, F180]
- Zero-initialize `struct snapshot_handle` before starting a stream (`handle->cur == 0`). `snapshot_read_next()`/`snapshot_write_next()` return `PAGE_SIZE`, `0` (EOF), or `< 0`; `swsusp_write()`/`swsusp_read()` must treat header returns `< (int)PAGE_SIZE` as errors (`-EFAULT` if `>= 0`). When `snapshot->sync_read` is set, `load_image()` must call `hib_wait_io(&hb)` after `swap_read_page()`. [F38, F52, F156]
- Call `memory_bm_position_reset(bm)` before `memory_bm_next_pfn(bm)` loops and do not interleave `memory_bm_find_bit()` calls (`set`/`clear`/`test_bit`) on `bm`. In `prepare_image()`, bitmaps created after `mark_unsafe_pages()` must use `PG_SAFE` and `PG_UNSAFE_CLEAR`, while pre-`mark_unsafe_pages()` bitmaps use `PG_UNSAFE_KEEP`. `chain_alloc()` sizes must be `<= LINKED_PAGE_DATA_SIZE` and pointer-aligned. Shift page counts from `snapshot_get_image_size()`, `count_swap_pages()`, and `alloc_swapdev_block()` by `PAGE_SHIFT` for byte ioctls and multiply `page_off` by `(PAGE_SIZE >> 9)` for BIO sectors. [F55, F65, F116, F171]
- Pass `exclusive = true` to `swsusp_check()` in `software_resume()` and `false` in `HIBERNATION_TEST_RESUME`. Non-NULL `hibernation_ops` must provide all callbacks except optional `recover`, and `leave()`/`enter()` must run on the boot CPU with secondary CPUs and local IRQs disabled before `syscore_resume()`. Non-`PM_SUSPEND_TO_IDLE` states require `suspend_ops->valid` and `enter` and `!cxl_mem_active()`; null-check `suspend_ops` and optional callbacks. Check `< 0` (not non-zero) for errors from `pm_qos_update_target()` and `freq_qos_*()`, and exempt `PM_QOS_DEFAULT_VALUE` (`-1`) in `*_qos_value_invalid()`. [F43, F46, F54, F92, F126, F163, F165]

## Error Handling
- `freeze_kernel_threads()` only calls `thaw_kernel_threads()` on error, so its callers must still call `thaw_processes()` on failure from the exact same task that called `freeze_processes()` (`PF_SUSPEND_TASK`). [F5, F161]
- Call `syscore_resume()` only if `syscore_suspend()` returned `0`, but always restore `system_state = SYSTEM_RUNNING` and `local_irq_enable()` on `syscore_suspend()` failure. Do not call `pm_notifier_call_chain(PM_POST_*)` when `pm_notifier_call_chain_robust()` fails, and do not call `swsusp_close()` when `swsusp_check()` fails (it already called `bdev_fput()`). [F11, F18, F50]
- After image transfer loops, drain BIOs via `err2 = hib_wait_io(&hb); if (!ret) ret = err2;`. `get_buffer()`, `get_highmem_page_buffer()`, and `wakelock_lookup_add()` return `ERR_PTR` on failure (check `IS_ERR()`, never `!ptr`). In `resume_store()`, use `lookup_bdev()` (not `early_lookup_bdev()`) and reset `error = 0` after `lookup_bdev()` fails before fallback parsing. [F39, F44, F48, F99, F167]

## External Contracts
- `__setup()` handlers must return `1` even on parse error. `resume_store()` must return `n` (not `0`) when `!hibernation_available()`. `autosleep_store()` must verify `buf` is `"off"`/`"off\n"` when `decode_state()` returns `PM_SUSPEND_ON`. Strip the trailing space in `sysfs_emit_at(..., "%s ", ...)` `.show` helpers. `cpu_latency_qos_write()` must accept both 4-byte binary `s32` and hex ASCII. `snapshot_compat_ioctl()` must use `compat_ptr(arg)` only for pointer ioctls and `compat_resume_swap_area` when `in_compat_syscall()`. [F41, F42, F77, F87, F95, F172]

## Known Pitfalls
- In `create_image()`, call `restore_processor_state()` immediately after `swsusp_arch_suspend()` before any per-CPU access (`trace_suspend_resume()`, `pr_err()`). In `copy_data_page()`, when `!PageHighMem(s_page)` and `PageHighMem(d_page)`, call `safe_copy_page(buffer, s_page)` before `kmap_local_page(d_page)`. [F143, F154]
- Use 10-byte `memcmp()`/`memcpy()` (never string helpers) on `swsusp_header->sig` and `orig_sig`, and use `strncmp(name, wl->name, len) == 0 && wl->name[len] == '\0'` plus `kstrndup()` in `wakelock_lookup_add()`. In `hibernate_setup()`, check `"noresume"` and `"nocompress"` before `!strncmp(str, "no", 2)`. Clamp `centisecs` and `m = nr_to_write / 10` to `1` when `0`, use `do_div()` on `u64 timeout_ms` in `pm_wake_lock()`, and use `time_after()` / signed `long` subtraction on `jiffies`. [F90, F110, F111, F112, F114, F123, F124]
