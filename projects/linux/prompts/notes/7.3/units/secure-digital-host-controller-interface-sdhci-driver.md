# SECURE DIGITAL HOST CONTROLLER INTERFACE (SDHCI) DRIVER

This component contains the SDHCI bus glue and vendor-specific host controller drivers for PCI (`sdhci-pci-core.c`, `sdhci-pci-gli.c`, `sdhci-pci-o2micro.c`, `sdhci-pci-arasan.c`), ACPI (`sdhci-acpi.c`), and platform/Device Tree (`sdhci-pltfm.c`, `sdhci-of-dwcmshc.c`, `sdhci-of-esdhc.c`, `sdhci-cadence.c`, `sdhci-iproc.c`, `sdhci-pxav2.c`, `sdhci-pxav3.c`, etc.). These drivers allocate and configure `sdhci_host` instances, supply hardware-specific `sdhci_ops`, `mmc_host_ops`, and `cqhci_host_ops` callbacks, apply silicon quirks, and manage clocks, PHY tuning, DMA descriptors, and power management transitions.

## Architecture & Data Flow

- Private data layout differs by bus and trailing `private[]` arrays are `____cacheline_aligned` (never compute offsets manually): on platform (`sdhci_pltfm_init`), `platform_get_drvdata(pdev)` is `struct sdhci_host *`, `sdhci_priv(host)` is `struct sdhci_pltfm_host *`, and vendor priv is `sdhci_pltfm_priv(pltfm_host)`; on PCI, `pci_get_drvdata(pdev)` is `struct sdhci_pci_chip *`, `sdhci_priv(host)` is `struct sdhci_pci_slot *`, and vendor priv is `sdhci_pci_priv(slot)`; on ACPI, `dev_get_drvdata(dev)` equals `sdhci_priv(host)` (`struct sdhci_acpi_host *`), and shared code must check `c->is_intel` before casting `sdhci_acpi_priv(c)` to `struct intel_host *`. [F125, F126, F127, F157]
- In `sdhci-pci-core.c`, `chip->fixes` (`NULL` for generic `SYSTEM_SDHCI`) and every callback/table in `struct sdhci_pci_fixes` are optional (`chip->fixes && chip->fixes->...`). In `sdhci-acpi.c`, `c->slot` (`NULL` for `PNP0D40`/unmatched UIDs), `c->slot->chip`, and all `c->slot` callbacks (`probe_slot`, `setup_host`, `remove_slot`, `free_slot`) are optional and must be null-checked before access. [F36, F37]
- In `dwcmshc_adma_write_desc`, `dwcmshc_set_tran_desc`, and `sdhci_sparx5_adma_write_desc`, `!len` must be checked before evaluating `BOUNDARY_OK(addr, len)` (as `addr + len - 1` underflows when `len == 0`). Because 128MB-crossing transfers split into two descriptors, `dwcmshc_probe` and `sdhci_sparx5_probe` must add `min(DIV_ROUND_UP_ULL(dma_get_required_mask(dev), SZ_128M), SDHCI_MAX_SEGS)` to `host->adma_table_cnt` before `sdhci_setup_host`. [F68, F111]
- Sub-32-bit register accessors must mask `reg` to its low byte-offset bits before shifting (`elba_write_w`/`elba_write_b`, `esdhc_writew_fixup`/`esdhc_writeb_fixup`, `sdhci_be32bs_writew`/`sdhci_be32bs_writeb`, `REG_OFFSET_IN_BITS`). Under `CONFIG_MMC_SDHCI_BIG_ENDIAN_32BIT_BYTE_SWAPPER`, `sdhci_be32bs_readw` must XOR `reg` with `0x2` and `sdhci_be32bs_readb` with `0x3`. On GL9750/GL9755, `sdhci_gli_readw`/`sdhci_gli_readb` must read `host->ioaddr + (reg & ~3)` via `readl` and shift right by `REG_OFFSET_IN_BITS(reg)`. [F92, F94, F118]
- In `sdhci_be32bs_writew` and `esdhc_writew_fixup` (`esdhc_be_writew`/`esdhc_le_writew`), 16-bit writes to `SDHCI_TRANSFER_MODE` must be deferred in `pltfm_host->xfer_mode_shadow` (returned by `esdhc_readw_fixup`) and flushed with `SDHCI_COMMAND` as one 32-bit write. In `sdhci_iproc_writew`/`sdhci_iproc_readw`, 16-bit writes to `SDHCI_BLOCK_SIZE`, `SDHCI_BLOCK_COUNT`, and `SDHCI_TRANSFER_MODE` must be shadowed in `shadow_blk`/`shadow_cmd`, read from shadows while active, and flushed as 32-bit writes on `SDHCI_COMMAND`. [F57, F59]
- In `sdhci-cadence.c`, `sdhci_cdns_probe` stores base MMIO in `priv->hrs_addr` and shifts `host->ioaddr += SDHCI_CDNS_SRS_BASE` (`0x200`), so all `SDHCI_CDNS_HRS*` accesses must use `priv->hrs_addr` (never `host->ioaddr` or `sdhci_readl`/`sdhci_writel`). `priv_size` passed to `sdhci_pltfm_init` must use `struct_size(priv, phy_params, nr_phy_params)`, and `priv->hrs_addr`, `priv->priv_writel`, and `data->init(pdev)` must be initialized before `sdhci_cdns_phy_init(priv)` or `__sdhci_read_caps()`. [F44, F119, F124]
- On Freescale eSDHC (`sdhci-of-esdhc.c`), `SDHCI_CAN_DO_ADMA2` in `esdhc_readl_fixup()` and polling `ESDHC_CLOCK_STABLE` in `esdhc_clock_enable()`/`esdhc_of_set_clock()` must be gated on `esdhc->vendor_ver > VENDOR_V_22`, whereas on `<= VENDOR_V_22`, `esdhc_reset` with `SDHCI_RESET_DATA` must save and restore `ESDHC_CTRL_BUSWIDTH_MASK` in `ESDHC_PROCTL` and reprogram `SDHCI_INT_ENABLE`/`SDHCI_SIGNAL_ENABLE` from `host->ier`. Gating the clock via `esdhc_clock_enable(host, false)` (when `clock != 0`) must be followed by `esdhc_clock_enable(host, true)`, and DT compatible checks for `esdhc_irq()` (`quirk_trans_complete_erratum`) must be cached during `esdhc_init()`. [F60, F96, F97, F135]
- In `amd_sdhci_reset`, when `mask & SDHCI_RESET_ALL` is set, the driver must clear `amd_host->tuned_clock` and call `sdhci_acpi_amd_hs400_dll(host, false)`. In `amd_set_ios`, whenever `host->timing` changes while `amd_host->tuned_clock` is true, `SDHCI_CTRL_TUNED_CLK` in `SDHCI_HOST_CONTROL2` must be set for `MMC_TIMING_MMC_HS400` or `MMC_TIMING_MMC_HS200` and cleared for all other modes. [F52, F53]
- In `dwcmshc_request`, `dwcmshc_check_auto_cmd23` must clear `SDHCI_AUTO_CMD23` in `host->flags` when `mrq->sbc && (mrq->sbc->arg & SDHCI_DWCMSHC_ARG2_STUFF)` and set `SDHCI_AUTO_CMD23` otherwise. In `sdhci_pci_probe_slot`, `chip->allow_runtime_pm` must be cleared if `chip->fixes->own_cd_for_runtime_pm` is true and `slot->cd_idx < 0`. On GL9763E, `gl9763e_set_low_power_negotiation(slot, false)` must be called when active (including `gl9763e_suspend` error rollback) and `true` before suspend. [F56, F66, F70]

## Synchronization

- `sdhci_ops.reset` callbacks (`esdhc_reset`, `sdhci_gl9755_reset`, `sdhci_gl9767_reset`, `sdhci_milbeaut_reset`, `rk35xx_sdhci_reset`, `th1520_sdhci_reset`, `cv18xx_sdhci_reset`) must not sleep when `mask` is `SDHCI_RESET_CMD` or `SDHCI_RESET_DATA`, because `sdhci_core` invokes them under `host->lock` with IRQs disabled. [F153]
- On Pensando Elba (`sdhci_elba_ops`), sub-dword writes in `elba_write_w` and `elba_write_b` must compute `shift = reg & GENMASK(1, 0)` and write `ELBA_BYTE_ENABLE_MASK(...)` to `priv->ctl_addr` under `priv->wrlock` before `writew`/`writeb`. In `sdhci-bcm-kona.c`, `sdhci_bcm_kona_sd_card_emulate` must hold `kona_dev->write_lock`, wait `udelay(20)` before accessing `KONA_SDHOST_CORESTAT`, and only run in process context. [F83, F154]
- In `sdhci-pxav2.c`, `pxav1_request_done` must set `pxav2_host->sdio_mrq = mrq` and select `pins_cmd_gpio` before writing `SDHCI_COMMAND` for the dummy CMD0, and `pxav1_irq` must clear `SDHCI_INT_CMD_MASK`, restore `pins_default`, and clear `pxav2_host->sdio_mrq` before calling `mmc_request_done`. [F27]

## Object Lifetimes

- When host registration is split into `sdhci_setup_host` and `__sdhci_add_host` (`sdhci_acpi_probe`, `dwcmshc_probe`, `glk_emmc_add_host`, `gl9763e_add_host`), any error after `sdhci_setup_host` succeeds must call `sdhci_cleanup_host(host)` before returning. [F1]
- In `remove` callbacks of runtime-PM-enabled drivers (`dwcmshc_remove`, `sdhci_pxav3_remove`, `sdhci_acpi_remove`, `sdhci_pci_remove`), the device must be resumed and runtime PM disabled (`pm_runtime_get_sync` and `pm_runtime_disable`, or `sdhci_pci_runtime_pm_forbid` when `chip->allow_runtime_pm` is set) before reading `SDHCI_INT_STATUS` or calling `sdhci_remove_host`/`sdhci_pci_remove_slot`. In platform drivers, `sdhci_remove_host` or `sdhci_*suspend_host` must complete before `clk_disable_unprepare`. [F11, F25, F26]
- In `sdhci_acpi_probe` and `sdhci_acpi_remove`, `c->slot->free_slot(pdev)` must be called on probe failure (`err_free`) and on removal after `sdhci_remove_host` (in `qcom_probe_slot`, `*irq = sdhci_acpi_priv(c)` must be initialized to `-EINVAL` before any early return), whereas `c->slot->remove_slot(pdev)` runs only in `sdhci_acpi_remove` before `sdhci_remove_host`. In `sdhci_pci_probe_slot` and `sdhci_pci_remove_slot`, if `chip->fixes->probe_slot` succeeded, `chip->fixes->remove_slot` must be invoked on later probe failure (`goto remove`) and after `remove_host` on removal. [F4, F5, F7]
- Non-devres references must be freed on all paths: `union acpi_object *obj` in `__intel_dsm` via `ACPI_FREE(obj)`; the matched `sd_dev` cursor on early `break` in `jmicron_probe()` via `pci_dev_put(sd_dev)`; and in `sdhci-of-esdhc.c`, `of_clk_get` via `clk_put(clk)`, `of_find_compatible_node` via `of_node_put(tp)`, and `of_find_matching_node`/`of_iomap` in `esdhc_signal_voltage_switch()` via `of_node_put` and `iounmap`. [F3, F15, F107, F140]
- In `sdhci_pci_add_gpio_lookup_table`, the static `gpiod_lookup_table` must be cloned with `kmemdup` using `struct_size(cd_gpio_lookup_table, table, count + 1)` before `gpiod_add_lookup_table` and freed via `sdhci_pci_remove_gpio_lookup_table`. In `sdhci_pci_gli_resume()`, `pci_free_irq_vectors(slot->chip->pdev)` must precede `gli_pcie_enable_msi(slot)`. [F65, F134]

## API Contracts

- Every `struct sdhci_ops` table assigned to `host->ops` must populate `.set_clock`, `.set_bus_width`, `.reset`, and `.set_uhs_signaling` (invoked without NULL checks). Any driver setting `SDHCI_QUIRK_CAP_CLOCK_BASE_BROKEN` must supply `.get_max_clock`, and if it uses `sdhci_pltfm_clk_get_max_clock`, `pltfm_host->clk` must be initialized before `sdhci_setup_host()`/`sdhci_add_host()`. [F164, F165]
- `sdhci_ops.irq` callbacks (`sdhci_cqhci_irq`, `sdhci_gl9763e_cqhci_irq`, `dwcmshc_cqe_irq_handler`, `esdhc_irq`, `pxav1_irq`) must return a `u32` bitmask of unhandled `SDHCI_INT_*` bits (or `0` if consumed), never `IRQ_HANDLED` (`1`, which equals `SDHCI_INT_RESPONSE`). When a driver implements `sdhci_ops.request_done` (`pxav1_request_done`), SDHCI core skips `mmc_request_done()`, so the driver must complete `mrq` itself. [F33, F174]
- CQHCI-enabled SDHCI drivers (`dwcmshc_probe`, `glk_emmc_add_host`, `gl9763e_add_host`) must call `sdhci_setup_host(host)` first, check `host->flags & SDHCI_USE_64_BIT_DMA` to set `CQHCI_TASK_DESC_SZ_128`, call `cqhci_init()`, and then call `__sdhci_add_host(host)`. Where `SDHCI_RESET_ALL` resets CQHCI hardware (`sdhci_intel_glk_ops`, `sdhci_gl9763e_ops`), `.reset` must use `sdhci_and_cqhci_reset` to call `cqhci_deactivate(host->mmc)` when `(host->mmc->caps2 & MMC_CAP2_CQE) && (mask & SDHCI_RESET_ALL) && host->mmc->cqe_private` before `sdhci_reset`. [F54, F169]
- When splitting a 128MB-crossing DMA segment: in `dwcmshc_set_tran_desc()`, the first `cqhci_set_tran_desc()` call must pass `end = false`, `*desc` must be manually advanced by `cq_host->trans_desc_len`, and the second call must pass `end`; in `dwcmshc_adma_write_desc` and `sdhci_sparx5_adma_write_desc`, callers must not manually increment `*desc` because `sdhci_adma_write_desc()` advances `*desc += host->desc_sz` itself. [F48, F128]
- `sdhci_ops.get_timeout_clock` callbacks must return Hz, whereas pre-populating `host->timeout_clk` directly before `sdhci_setup_host()` requires kHz. When overriding spec version via `__sdhci_read_caps(host, &version, ...)`, the `u16` must be shifted by `SDHCI_SPEC_VER_SHIFT`. [F46, F47]
- `sdhci_alloc_host()`, `sdhci_pltfm_init()`, and `sdhci_pci_probe_slot()` return `ERR_PTR` on failure (never `NULL`), so callers must check `IS_ERR()`. `sdhci_pci_add_gpio_lookup_table()` returns `NULL` (no match), `ERR_PTR(-ENOMEM)`, or a valid pointer, so `sdhci_pci_probe_slot()` must check `IS_ERR()` before passing it to `sdhci_pci_remove_gpio_lookup_table()`. Callers of `sdhci_get_property` must ensure `platform_set_drvdata(pdev, host)` is set on a `struct sdhci_pltfm_host`-backed host. [F17, F31, F32]
- On GL9767 (`sdhci-pci-gli.c`), Vendor Header Space PCI config writes (`0x884`–`0x964`) must be bracketed by `gl9767_vhs_write(pdev)` and `gl9767_vhs_read(pdev)`, functions setting `PCIE_GLI_9767_CFG_LOW_PWR_OFF` must clear it on all return paths, and `sdhci_gl9767_uhs2_phy_reset(host, true)` must be asserted between `SDHCI_POWER_ON` and `SDHCI_VDD2_POWER_ON` and de-asserted after `sdhci_enable_clk()`. In `sdhci-pci-o2micro.c`, writing write-protected PCI config registers requires unlocking (`& 0x7f`) and relocking (`| 0x80`) `O2_SD_LOCK_WP` (`0xD3`). [F142, F143, F145]

## Error Handling

- During driver teardown (`sdhci_pltfm_remove`, `sdhci_acpi_remove`, `sdhci_pci_remove_slot`, `sdhci_milbeaut_remove`, `pic32_sdhci_remove`), if `SDHCI_INT_STATUS` reads as `0xffffffff` (`~0`), `dead = 1` must be passed to `sdhci_remove_host()` and `slot->chip->fixes->remove_slot()` so MMIO writes are skipped. [F175]
- Positive `PCIBIOS_*` codes from `pci_read_config_*()`/`pci_write_config_*()` in PCI probe/resume must be converted via `pcibios_err_to_errno()`; negative `platform_get_irq()` errors must be propagated directly; and `.enable_dma` callbacks (`esdhc_of_enable_dma`) must check and return `dma_set_mask_and_coherent()` errors. In `goto`-unwinding probes (`spacemit_sdhci_probe`, `dwcmshc_probe`, `sdhci_bcm_kona_probe`, `pic32_sdhci_probe`, `sdhci_milbeaut_probe`), every failure before jumping must set a negative errno, and slot rollback loops in `sdhci_pci_probe`/`sdhci_pci_suspend_host` must use a signed `int i` pre-decremented (`--i >= 0`). [F29, F30, F34, F42, F78]
- In `sdhci-of-dwcmshc.c` and `sdhci-pxav3.c`, optional secondary clocks (`priv->bus_clk`, `pxa->clk_core`) from `devm_clk_get()` retain `ERR_PTR` when absent, so `clk_prepare_enable()`/`clk_disable_unprepare()` must check `!IS_ERR(...)`. In `sdhci-pxav2.c` and `sdhci-pxav3.c`, optional pinctrl handles/states are null-checked at runtime, so probe must convert `IS_ERR()` to `NULL`. [F39, F40]

## Known Pitfalls

- Across all SDHCI drivers, `SDHCI_QUIRK_*` flags must only target `quirks`, whereas `SDHCI_QUIRK2_*` flags must only target `quirks2`. In `sdhci_acpi_probe()`, `c->slot->probe_slot()` must run before applying `c->slot->chip` and `c->slot` flags, and `quirks`, `quirks2`, `caps`, `caps2`, and `pm_caps` from both must be bitwise-ORed (`|=`), never assigned (`=`). [F98, F110]
- In `sdhci-of-esdhc.c`: BE and LE MMIO accessors (`esdhc_be_writew`/`esdhc_le_writew` and `read*`/`write*` pairs) must be updated in lockstep (sampling old 32-bit value before `esdhc_writew_fixup` to detect `0 -> 1` on `ESDHC_EXTN` during `esdhc->in_sw_tuning`); in `esdhc_readl_fixup()`/`esdhc_readw_fixup()`, multiple fixups for the same `spec_reg` must be combined before returning `ret`; and in `esdhc_execute_tuning`, `SDHCI_HS400_TUNING` must be saved before `sdhci_execute_tuning` and restored before `esdhc_execute_sw_tuning` and clock-reduced retries. [F58, F61, F95]
- In `sdhci-pci-arasan.c`, `arasan_phy_write(host, data, offset)` takes `data` before `offset`, whereas `arasan_phy_read(host, offset, &data)` takes `offset` before `data`. In `th1520_sdhci_set_phy()` and `cv18xx_sdhci_reset()`, checking `emmc_caps` (`MMC_CAP2_NO_SD | MMC_CAP2_NO_SDIO`) requires `(host->mmc->caps2 & emmc_caps) == emmc_caps`. In `dwcmshc_execute_tuning()` and `intel_execute_tuning()`, `sdhci_reset(host, SDHCI_RESET_DATA)` must follow `sdhci_execute_tuning(mmc, opcode)`. [F50, F99, F149]
