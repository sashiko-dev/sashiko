# QAT DRIVER

This component implements the Intel QuickAssist Technology (QAT) PCI device drivers for Gen2 (`c3xxx`, `c62x` and VFs), Gen4 (`4xxx`, `420xx`), and Gen6 (`6xxx`) accelerators, along with common infrastructure in `qat_common`. It manages device lifecycle, PCI BAR and CSR operations, firmware administration mailboxes, key-value configuration tables, AER error recovery, RAS error reporting, power management, PF/VF mailbox protocols, and debugfs/ioctl control interfaces.

## Architecture & Data Flow

- In `struct adf_accel_dev`, `pf` and `vf` share an anonymous union discriminated by `accel_dev->is_vf`; shared PF/VF paths (such as `adf_notify_fatal_error_worker()`) must check `!accel_dev->is_vf` before reading `accel_dev->pf.vf_info`. Similarly, `accel_dev->admin` is `NULL` on VFs (must check `!accel_dev->admin` in `adf_init_admin_pm()`, `adf_get_pm_info()`, `adf_exit_admin_comms()`), and `accel_dev->fw_loader` is only allocated when `hw_device->fw_name` is non-NULL (must check `hw_device->fw_name` in all `adf_accel_engine.c` functions). [F37, F38, F41]
- On Gen4, non-`SVC_DCC` `adf_fw_config` tables must place `ADF_FW_ADMIN_OBJ` last, preceded by at least `RP_GROUP_COUNT` (2) worker entries. In `adf_gen4_get_ring_to_svc_map()`, when `SVC_DCC` is enabled, all `rps[0..RP_GROUP_COUNT - 1]` entries must be set to `COMP` instead of queried via `uof_get_obj_type`. In `get_accel_cap()` (`qat_4xxx`, `qat_420xx`, `qat_6xxx`), `SVC_DCC` must clear `ICP_ACCEL_CAPABILITIES_CRYPTO_SYMMETRIC` from `capabilities_dc | capabilities_sym`. [F54, F70, F132]
- `adf_get_pmisc_base()`, `adf_get_etr_base()`, and `adf_get_aram_base()` index `pci_bars[ADF_PCI_MAX_BARS]` using compact indices `0..2` from `get_misc_bar_id()`, `get_etr_bar_id()`, and `get_sram_bar_id()`, not raw PCI BAR numbers (`0, 2, 4`). In `qat_c62x/adf_drv.c:adf_probe()`, when `hw_data->fuses[ADF_FUSECTL0] & ADF_DEVICE_FUSECTL_MASK` is set, `pci_bars[]` population must start at `i = 1` so the remaining BARs map to `ADF_C62X_PMISC_BAR` (1) and `ADF_C62X_ETR_BAR` (2). [F77, F78]
- `adf_pfvf_csr_msg_of()` rejects messages overflowing `fmt->type.mask` or `fmt->data.mask`; `csr_gen2_fmt` limits `type` to `0x0F` and `data` to `0x3FF`, making `type >= 0x10` Gen4-only. In `adf_gen2_pfvf.c`, PF2VF (bits 15:0) and VF2PF (bits 31:16) share a 32-bit register where `ADF_GEN2_CSR_IN_USE` (`0x6AC2`) and `ADF_GEN2_CSR_IN_USE_MASK` (`0xFFFE`) must keep bit 0 clear so `gen2_csr_set_in_use()` and `gen2_csr_clear_in_use()` at `remote_offset` never touch the remote `ADF_PFVF_INT` bit. [F81, F82]
- In `adf_gen2_disable_pending_vf2pf_interrupts()` and `adf_gen4_disable_pending_vf2pf_interrupts()`, disabling pending VF2PF interrupts must first mask all VF interrupts (`ADF_GEN2_VF_MSK` / `ADF_GEN4_VF_MSK`) and then write back `sources | disabled` in a second CSR write. In `adf_gen4_set_msix_default_rttable()` and Gen6 `set_msix_default_rttable()`, the loop bound `i <= ADF_GEN4_ETR_MAX_BANKS` (or `ADF_GEN6_ETR_MAX_BANKS`) is inclusive because entry `MAX_BANKS` maps the VF2PF/error interrupt. [F76, F102]
- In `adf_gen4_init_thd2arb_map()`, `ae_cnt` from `get_num_aes()` must be validated with `ae_cnt <= ICP_QAT_HW_AE_DELIMITER` before copying `thrd_to_arb_map_dcc` into `thd_to_arb_map`, and in both `adf_gen4_init_thd2arb_map()` and `adf_gen6_get_arb_mask()`, thread mask iteration must be bounded by `ADF_NUM_THREADS_PER_AE` (8) so `<< (thrd * 4)` never reaches 32. In `uof_get_name()`, `id` from `fw_config[obj_num].obj` must be checked with `id < 0 || id >= num_objs` before indexing `fw_objs`. [F67, F69, F111]
- In `adf_fw_counters_allocate()`, `fw_counters->ae_count` must be set before accessing `ae_counters[]` (`__counted_by(ae_count)`). In `cnv_err_stats_alloc()` and `adf_fw_counters_load_from_device()`, `ae_cnv_errors[]` and `ae_counters[]` are sized by `hweight_long(ae_mask)` and must be indexed by `i++` while `for_each_set_bit()` is bounded by `GET_MAX_ACCELENGINES(accel_dev)`. In `qat_cnv_errors_seq_show()`, check `ae_errors->is_comp_ae` before reading uninitialized fields and clamp `CNV_ERR_TYPE_MASK` via `CNV_ERROR_TYPE_GET()`. [F44, F84, F115, F116]
- On Gen6 (`adf_6xxx_hw_data.c`), `adf_init_device()` must call `adf_gen6_set_vc()` to program `ADF_GEN6_CSR_RINGMODECTL` across all banks and PCI config `PVC0CTL`/`PVC1CTL` on bring-up and after PF FLR, and `get_service()` must clear matched bits in `*mask` via `test_and_clear_bit()`. In `adf_gen4_ras.c`, all accesses to `*_WAT_WCP` CSRs must be guarded by `GET_ERR_MASK(accel_dev)->parerr_wat_wcp_mask != 0`. [F60, F89, F135]

## Synchronization

- `adf_put_admin_msg_sync()` and `adf_send_admin()` callers acquire `admin->lock` (`struct mutex`) and sleep in `read_poll_timeout()`, so they require sleepable context. `admin->lock` must be held continuously across checking `ADF_CSR_RD(mailbox, mb_offset) == 1`, copying the request to `admin->virt_addr`, writing `1` to the mailbox CSR, polling for `0`, and copying the response to `out`. In `adf_init_admin_comms()`, all DMA buffers, CSRs, `admin->lock`, and `mailbox_addr` must be initialized before setting `accel_dev->admin = admin`. [F25, F26, F150]
- `adf_gen2_pfvf_send()` and `adf_gen4_pfvf_send()` must hold `csr_lock` (`pf2vf_lock` or `vf2pf_lock`) continuously across CSR write, `read_poll_timeout()`, and (on Gen2) collision retries and clearing the remote in-use pattern; they cannot run in atomic context. Conversely, `adf_gen2_pfvf_recv()` and `adf_gen4_pfvf_recv()` run in `pf2vf_bh_tasklet` and must remain lockless and non-blocking, and `adf_pfvf_ops` interrupt mask callbacks run under `vf2pf_ints_lock` with IRQs disabled and must not sleep. [F29, F149, F151]
- In `adf_gen2_pfvf_recv()`, `gen2_csr_clear_in_use(&csr_val, remote_offset)` must only be called when `params->compat_ver >= ADF_PFVF_COMPAT_FAST_ACK` and `!params->is_notification_message(msg.type)` (and never for legacy non-system messages), leaving the in-use pattern intact for notifications so `adf_gen2_pfvf_send()` can detect collisions. [F30]
- During AER recovery (`adf_error_detected()`, `adf_dev_aer_schedule_reset()`, `adf_device_reset_worker()`, `adf_slot_reset()`), `ADF_STATUS_RESTARTING` must be set before `adf_dev_down()` or `adf_dev_restart()` and cleared only after `adf_reenable_sriov()` and `adf_dev_restarted_notify()` finish. `adf_device_reset_worker()` on `device_reset_wq` waits for `adf_device_sriov_worker()` on `device_sriov_wq`, so the two workqueues must remain separate. [F20, F155]
- In `adf_cfg_add_key_value_param()`, `down_write(&cfg->lock)` must be held continuously across `adf_cfg_key_val_get()`, `adf_cfg_keyval_remove()`, and `adf_cfg_keyval_add()`. In `qat_dev_cfg_sops` (`adf_cfg.c`), `qat_dev_cfg_start()` must unconditionally acquire `qat_cfg_read_lock` even when returning `NULL` so the unconditional `mutex_unlock(&qat_cfg_read_lock)` in `qat_dev_cfg_stop()` remains balanced. [F17, F163]

## Object Lifetimes

- In drivers using `adf_cleanup_accel()`, `adf_devmgr_add_dev()` must succeed before any error path jumps to `adf_cleanup_accel()` (which unconditionally calls `adf_devmgr_rm_dev()`). During teardown (both `adf_cleanup_accel()` and devres in `qat_6xxx`), `adf_dev_down()` must run before `adf_dbgfs_exit()`, `adf_cfg_dev_remove()`, and `adf_devmgr_rm_dev()`. In `qat_c62xvf` and `qat_c3xxxvf` `adf_remove()`, `adf_flush_vf_wq()` must run before `adf_dev_down()`. [F3, F12, F22]
- When `adf_dev_up()` fails in `adf_probe()` or `adf_ctl_ioctl_dev_start()`, the caller must invoke `adf_dev_down(accel_dev)` to roll back partial state. Every PF `pci_driver` must also register a `.shutdown` callback that calls `adf_dev_down()`. In `qat_420xx` and `qat_4xxx`, `accel_dev`, `hw_data`, and BARs use devres, so `adf_cleanup_accel()` must not manually free/unmap them; in `qat_6xxx/adf_drv.c`, all teardown uses `devm_add_action_or_reset()` with `void (*)(void *)` wrappers, so probe error paths must return directly. [F9, F122, F124, F129, F130]
- In `adf_init_admin_comms()`, failure of the second `dma_alloc_coherent()` must free the first DMA buffer and `admin`, and `adf_exit_admin_comms()` must set `accel_dev->admin = NULL`. In `adf_accel_engine.c`, if `adf_ae_fw_load()` or `adf_ae_fw_load_images()` fails after requesting firmware or mapping UOF objects, it must call `adf_ae_fw_release()`, and inside `adf_ae_fw_load_images()`'s loop `qat_uclo_del_obj(loader)` must run after `qat_uclo_wr_all_uimage(loader)` on each iteration. [F4, F5, F103]
- Drivers that increment `hw_data->dev_class->instances` in `adf_init_hw_data_*()` must decrement it in `adf_clean_hw_data_*()`, and VF drivers must call `adf_devmgr_update_class_index(hw_data)` in both. In `adf_devmgr_rm_dev()`, removing a host VF (`accel_dev->is_vf && pf`) only marks `map->attached = false` (retaining `map` and `id_map` until `adf_clean_vf_map(true)` on module exit) while adjusting subsequent `fake_id`s under `table_lock`. [F10, F11, F58, F91]
- In `adf_cfg_add_key_value_param()`, `kfree()` the new `adf_cfg_key_val` if the key exists with the same value, or remove/free the old entry via `adf_cfg_keyval_remove()` when the value differs. In `adf_gen4_print_pm_status()`, `pm_info` must be allocated with `kmalloc()` and `dma_unmap_single(..., DMA_FROM_DEVICE)` must be called on `p_state_addr` immediately after `adf_get_pm_info()` before checking its return value or reading `pm_info`. [F7, F15, F157]

## API Contracts

- `cnv_err_stats_alloc()` and `adf_fw_counters_get()` return an `ERR_PTR` or transfer ownership of a `kmalloc`'d table to `qat_cnv_errors_file_open()` and `qat_fw_counters_file_open()`, which must check `IS_ERR()` and `kfree()` the table if `seq_open()` fails or on file release. [F6]
- `adf_bank_state_save()`, `adf_bank_state_restore()`, and `adf_gen4_bank_quiesce_coal_timer()` require `adf_gen4_init_hw_csr_ops()` (Gen2 leaves status/config CSR ops `NULL`), and `adf_bank_state_save()`/`restore()` require `(num_rings / 2 - 1) * (tx_rx_gap + 1) + tx_rx_gap < ADF_ETR_MAX_RINGS_PER_BANK` (incompatible with Gen2). Bank reset/save/restore callbacks take PF bank numbers (`vf_nr * num_banks_per_vf + bank_number`), whereas `GET_SRV_TYPE(accel_dev, idx)` takes a bundle-relative index (`ring_num % num_banks_per_vf`). [F39, F51, F53, F87]
- Gen4 `adf_init_hw_data_*()` paths using `adf_gen4_init_thd2arb_map()` must set `get_rp_group`, `get_ena_thd_mask`, `get_num_aes`, `uof_get_num_objs`, and `uof_get_ae_mask` on all device ID branches. Callers of `uof_get_name()` and `uof_get_ae_mask()` must pass `obj_num < uof_get_num_objs(accel_dev)`. `adf_gen4_init_num_svc_aes()` requires `&hw_data->rl_data` with `get_ae_mask` initialized, and `get_sram_bar_id` is `NULL` on VFs so `adf_get_aram_base()` must not be called on VFs unguarded. [F40, F55, F68, F118]
- `adf_cfg_get_param_value()` copies `ADF_CFG_MAX_VAL_LEN_IN_BYTES` (64) bytes into `value`, requiring a `>= 64`-byte buffer. `qat_comp_build_ctx()` requires a `ctx` buffer of at least `2 * sizeof(struct icp_qat_fw_comp_req)` (`QAT_COMP_CTX_SIZE`) bytes and must increment `req_tmpl` after copying `req_tmpl` to `req_tmpl + 1` before calling `build_decomp_block(req_tmpl, algo)`. [F48, F80, F98]
- `adf_gen4_bank_quiesce_coal_timer()` takes `timeout_ms` in milliseconds, must reject `timeout_ms < 0` with `-EINVAL`, and must cast `timeout_ms` to `u64` before multiplying by `USEC_PER_MSEC`, whereas `adf_gen4_bank_drain_start()` takes `timeout_us` in microseconds. `adf_get_dc_capabilities()` must mask out `admin_ae_mask` from `ae_mask` before sending `ICP_QAT_FW_COMP_CAPABILITY_GET`. Any function under `#ifdef CONFIG_DEBUG_FS` in `adf_dbgfs.h` or `#if defined(CONFIG_PCI_IOV)` in `adf_common_drv.h` called unconditionally must have a matching `#else` stub. [F50, F66, F107, F136]

## Error Handling

- Check non-standard return conventions: `pcim_iomap_region()` in `qat_6xxx/adf_drv.c` returns an `ERR_PTR` (check `IS_ERR(bar->virt_addr)`); `hw_data->get_ena_thd_mask()` returns `ADF_GEN4_ENA_THD_MASK_ERROR` on error; `adf_get_service_enabled()` returns `0` for valid `SVC_ASYM` and `< 0` on error (store in signed `int`); `adf_find_free_id()` returns `ADF_MAX_DEVICES + 1` when full (check `accel_id > ADF_MAX_DEVICES`); and `adf_pfvf_csr_msg_of()` returns `0` on overflow (check for `0` before writing the PFVF CSR). [F31, F32, F33, F34, F35]
- `adf_put_admin_msg_sync()` copies all `ADF_ADMINMSG_LEN` (32) bytes of `__packed` `icp_qat_fw_init_admin_req`/`resp` at `offset = ae * ADF_ADMINMSG_LEN * 2` and returns `0` even when firmware rejects a command; callers must zero-initialize `req` and check both the return value and `resp.status`. Similarly, `adf_get_fw_capabilities()` leaves `*caps` unmodified when `admin_ae_mask == 0` or on error, so callers must zero-initialize `*caps`. Early probe rollback paths require `adf_cleanup_accel()`, `adf_cfg_dev_remove()`, and `adf_cfg_dev_dbgfs_rm()` to guard against `NULL` `hw_device` and `cfg`. [F36, F42, F43, F45, F79]

## External Contracts

- When a QAT PF PCI driver supports multiple device IDs that select distinct firmware images in its `hw_data` init (such as `4xxx` and `402xx` in `adf_init_hw_data_4xxx()`), the driver module must declare `MODULE_FIRMWARE()` for both the main firmware (`fw_name`) and MMP binary (`fw_mmp_name`) of every supported device variant. [F158]

## Known Pitfalls

- In `qat_420xx/adf_420xx_hw_data.c`, `get_accel_cap()` calls `update_ae_mask()` to update `hw_data->ae_mask` from the active service config, so it must be called after `ADF_SERVICES_ENABLED` is set in `accel_dev->cfg`. In `adf_get_service_enabled()`, two-bit service mask combinations (`SVC_SYM`/`SVC_ASYM`/`SVC_DC` pairs) must be tested before single-bit checks. In `adf_devmgr_add_dev()`/`rm_dev()`, `pf` is only used in the `accel_dev->is_vf && pf` condition while all list, ID, and BDF operations must target `accel_dev`. [F56, F88, F99]
- In `bank_state_restore()` (`adf_bank_state.c`), before restoring `state->iaintflagsrcsel0`, write `write_csr_ring_head` again for empty TX rings (`state->ringestat & BIT(tx)`) after setting `ADF_RP_INT_SRC_SEL_F_RISE_MASK`, and write `write_csr_ring_tail` again for full RX rings (`state->ringfstat & BIT(rx)`). If `state->ringexpstat` is non-zero, return `0` before writing `state->ringsrvarben` or checking status CSRs; otherwise verify `ops->read_csr_exp_stat(base, bank) == 0` first. [F61, F62]
- In `adf_gen4_ras.c`, composite dispatchers (`adf_gen4_process_errsou1`/`2`/`3`, `adf_handle_iaintstatssm`, `adf_handle_spppar_err`, `adf_handle_ssm`) must accumulate `reset_required` with bitwise `|=`. In `adf_gen4_process_errsou3()`, pass `aram_csr` to `adf_handle_aramcerr()`, `adf_handle_aramuerr()`, and `adf_handle_reg_cppmemtgterr()` (and OR `ADF_GEN4_REG_*_EN_BITMASK` when clearing W1C bits), and pass `csr` to the remaining handlers. Preserve `ADF_GEN4_TIMSCCTL_RELAY_BITMASK` when modifying `ADF_GEN4_TIMISCCTL`. [F95, F100, F142, F143]
- In `adf_gen4_init_device()` and Gen6 `adf_init_device()`, mask `ADF_GEN4_PM_SOU` / `ADF_GEN6_PM_SOU` in `ERRMSK2` before writing `PM_DRV_ACTIVE` to `PM_INTERRUPT`. Use `FIELD_MODIFY()` rather than `val |= FIELD_PREP(...)` when updating multi-bit fields in `ADF_GEN6_CSR_RINGMODECTL`, `PVC0CTL`, and `PVC1CTL`. Copy narrower bitmasks (`u16`/`u32`) into an `unsigned long` before passing to `for_each_set_bit()`/`test_bit()`, cast `u_base` to `u64` before `<< 32` in `read_base()`, use `do_div()` in `adf_gen4_bank_quiesce_coal_timer()`, and check `!delta_us` and parenthesize `(HZ_PER_MHZ / 10)` in `measure_clock()`. [F105, F106, F108, F109, F121, F137, F144]
