# BPF JIT for LOONGARCH

This unit implements the 64-bit LoongArch eBPF JIT compiler and BPF trampoline generator. It translates eBPF bytecode into native LoongArch machine instructions across sizing and emission passes, handles tail calls, subprograms, atomic operations, and BTF exception table fixups, and provides text poking and trampoline preparation for `fentry`, `fexit`, `modify_return`, and `struct_ops` hooks.

## Architecture & Data Flow

- `ctx.offset` must be allocated with `prog->len + 1` `u32` entries in `bpf_int_jit_compile()` and remain in 4-byte instruction-index units throughout all `build_body()` passes (including `extra_pass`), only being scaled in-place by `LOONGARCH_INSN_SIZE` for all `i <= prog->len` immediately before calling `bpf_prog_fill_jited_linfo(prog, ctx.offset + 1)`. `build_body()` must record each BPF instruction's starting native index plus the post-body index at `ctx->offset[prog->len]` only when `ctx->image == NULL`, because emission passes read `ctx->offset[]` via `bpf2la_offset()` and `emit_bpf_tail_call()` to resolve forward jumps. [F22, F46, F77]
- Branch target offsets during JIT compilation, including `tc_ninsn` in `emit_bpf_tail_call()` and `bpf2la_offset()`, must be derived from the per-program `ctx->offset` table rather than static or file-scope variables, because `bpf_int_jit_compile()` skips pass 1 offset calculation on `extra_pass`. [F35]
- Because `ctx->image` is `NULL` during the initial sizing pass in `bpf_int_jit_compile()` and in `arch_bpf_trampoline_size()`, code that writes instructions or backpatches branch pointers (`branch` in `invoke_bpf_prog()` and `branches[i]` in `__arch_prepare_bpf_trampoline()`) must check `ctx->image != NULL` before dereferencing. [F20]
- `add_exception_handler()` must return `0` when `!ctx->image || !ctx->prog->aux->extable`, and in `build_insn()` it must be called immediately after emitting the faulting `BPF_LDX` load instruction because it records the faulting PC as `&ctx->image[ctx->idx - 1]`. Broken by: emitting an extra instruction between the `BPF_LDX` load and `add_exception_handler()`, or accessing `extable` during the sizing pass. [F21]
- `build_prologue()`, `prepare_bpf_tail_call_cnt()`, `__build_epilogue()`, `emit_bpf_tail_call()`, and `BPF_PSEUDO_CALL` in `build_insn()` must agree on placing `tcc` at `stack_size - 72` and `tcc_ptr` at `BPF_TAIL_CALL_CNT_PTR_STACK_OFF(stack_size)` (`stack_size - 80`) below the 8 saved GPR slots. Broken by: changing saved registers in `build_prologue()`/`__build_epilogue()` without updating `BPF_TAIL_CALL_CNT_PTR_STACK_OFF(stack)` and `load_offset` adjustments. [F50]
- `__arch_prepare_bpf_trampoline()` must save `LOONGARCH_GPR_S1` to `FP - sreg_off` in the trampoline prologue and restore it before exit because `invoke_bpf_prog()` clobbers `LOONGARCH_GPR_S1` to hold the `bpf_trampoline_enter()` start timestamp across the `p->bpf_func` call. [F91]
- Executable buffers in `bpf_int_jit_compile()` and `arch_prepare_bpf_trampoline()` must be pre-filled with `INSN_BREAK` via `jit_fill_hole()` before code emission so `validate_code()` (directly or via `validate_ctx()`) rejects any image with unwritten slots or `INSN_BREAK` from `larch_insn_gen_beq()`/`larch_insn_gen_bne()`. [F25]
- In `move_imm()`, `lu32id` can be skipped for a non-32-bit immediate only when bits [51:31] are either all zeros or all ones, so the condition guarding `emit_insn(ctx, lu32id, ...)` must test `imm_51_31 != 0 && imm_51_31 != 0x1fffff` with logical AND. Broken by: using `||` or testing only bits [51:32] without bit 31. [F54]
- In `build_insn()`, 32-bit operations must zero-extend `dst`: `BPF_ALU | BPF_MOV | BPF_X` and `BPF_ALU64 | BPF_MOV | BPF_X` with `off == 8` or `off == 16` must follow `extwb`/`extwh` with `emit_zext_32(ctx, dst, is32)`; 32-bit `BPF_ALU` shifts (`BPF_LSH`, `BPF_RSH`, `BPF_ARSH` with `BPF_X` or `BPF_K`) must follow `sllw`/`slliw`/`srlw`/`srliw`/`sraw`/`sraiw` with `emit_zext_32(ctx, dst, is32)`; and `BPF_ALU | BPF_END | BPF_FROM_BE` and `BPF_ALU64 | BPF_END | BPF_FROM_LE` with `imm == 32` must follow `revb2w` with `emit_zext_32(ctx, dst, true)` (not `is32`). [F65, F66, F67]

## Object Lifetimes

- Whenever `bpf_int_jit_compile()` reaches `out_offset:` (after finishing a single-pass or `extra_pass` compilation, or on any error after allocating `jit_data`), it must free `ctx.offset` with `kvfree()`, free `jit_data` with `kfree()`, and set `prog->aux->jit_data` to `NULL`. Broken by: freeing `jit_data` without clearing `prog->aux->jit_data = NULL`, or returning on error after allocating `ctx.offset` without jumping to `out_offset:`. [F3]

## API Contracts

- `larch_insn_gen_beq()` and `larch_insn_gen_bne()` take a 4-byte-aligned byte offset (computed in `invoke_bpf_prog()` and `__arch_prepare_bpf_trampoline()` via `(void *)(&ctx->image[ctx->idx]) - (void *)branch`), whereas `cond_jmp_offset()`, `emit_cond_jmp()`, `emit_uncond_jmp()`, and `emit_tailcall_jmp()` take offsets in instructions. [F26]
- Because `bpf2la_offset(bpf_insn, off, ctx)` computes `ctx->offset[bpf_insn + 1 + off] - (ctx->offset[bpf_insn + 1] - 1)`, the PC-relative branch `b jmp_offset` emitted by `emit_cond_jmp()` or `emit_uncond_jmp()` in `build_insn()` must be the final LoongArch instruction emitted for that BPF jump instruction. Broken by: emitting any instruction after `emit_cond_jmp()`/`emit_uncond_jmp()` or changing `cond_jmp_offs26()` so `b` is not last. [F27]
- For two-slot `BPF_LD | BPF_IMM | BPF_DW` instructions, `build_insn()` must return `1` (while all other valid single-slot instructions return `0`) so `build_body()` increments `i`, records `ctx->offset[i] = ctx->idx` for the second slot during the sizing pass, and skips executing `build_insn()` on the second slot. [F57]
- For function-entry trampolines (`!(flags & BPF_TRAMP_F_INDIRECT)`), the parent return address is in `LOONGARCH_GPR_RA` and the traced function return address is in `LOONGARCH_GPR_T0`, so `emit_jump_or_nops()` (when `is_call` is true) and `__arch_prepare_bpf_trampoline()` must use `LOONGARCH_GPR_T0` for the traced function link. [F85]
- Before calling `orig_call` in `__arch_prepare_bpf_trampoline()`, `orig_call` must be advanced by `LOONGARCH_FENTRY_NBYTES` (8 bytes) when `is_kernel_text((unsigned long)orig_call)` is true or by `LOONGARCH_BPF_FENTRY_NBYTES` (20 bytes) when `is_bpf_text_address((unsigned long)orig_call)` is true to skip patched entry instructions. [F86]
- In `__arch_prepare_bpf_trampoline()`, when `save_ret` is true and `is_struct_ops` (`flags & BPF_TRAMP_F_INDIRECT`) is set, the return value in `LOONGARCH_GPR_A0` must be derived from `regmap[BPF_REG_0]` via `sign_extend()` using `m->ret_size` and `m->ret_flags & BTF_FMODEL_SIGNED_ARG` rather than reloaded from `FP - retval_off`. In `sign_extend()`, 1-byte and 2-byte unsigned values (`!sign && (size == 1 || size == 2)`) must not be sign-extended, whereas signed 1-byte, signed 2-byte, and all 4-byte values (with `addiw`) must be sign-extended to 64 bits. [F72, F82]

## Error Handling

- `bpf_arch_text_copy()` returns `ERR_PTR(-EINVAL)` rather than `NULL` when `larch_insn_text_copy()` fails, so callers such as `arch_prepare_bpf_trampoline()` must test its return value with `IS_ERR()` and extract the error code with `PTR_ERR()`. [F17]
- In `__arch_prepare_bpf_trampoline()`, any failure after `branches` is allocated for `fmod_ret->nr_links` must jump to `out` before `ret = ctx->idx` is assigned so that `branches` is freed by `kfree(branches)` without overwriting the negative error code in `ret`. [F19]
- Program-dependent branch range overflows in `build_insn()` and `emit_bpf_tail_call()` must log via ratelimited `pr_info_once()` and return an error code (`-E2BIG` or `-1`/`-EINVAL`) without triggering kernel warnings, whereas `WARN_ON_ONCE()` is reserved for internal exception-table invariant violations in `add_exception_handler()` and `validate_ctx()`. [F99]

## Known Pitfalls

- When loading addresses that can differ between JIT passes—such as `func_addr` in `BPF_JMP | BPF_CALL`, `bpf_pseudo_func(insn)` in `BPF_LD | BPF_IMM | BPF_DW`, or `struct bpf_tramp_image *im` in `__arch_prepare_bpf_trampoline()`—the JIT must use fixed 4-instruction `move_addr()` rather than variable-length `move_imm()`. [F34]
- In `emit_atomic()`, fetch/exchange atomic instructions (`BPF_FETCH`, `BPF_XCHG`) must pass `t3` (holding a copy of `src`) as the source operand `rk` when `src` is the destination `rd`, and `BPF_CMPXCHG` must save `r0` to `t2` before `lld`/`llw` and reload `t3` from `src` inside the LL/SC loop before `scd`/`scw` (which overwrites `t3` with the status bit). [F41]
- In `build_insn()`, 32-bit operations that do not write to `src` (such as `BPF_ALU | BPF_DIV | BPF_X` and `BPF_ALU | BPF_MOD | BPF_X`) or that do not write to either operand (`BPF_JMP32` comparisons) must copy mapped BPF registers into temporary registers (`t1`, `t2`) before applying `emit_zext_32()` or `emit_sext_32()`. For `BPF_JMP32`, the temporary copies must be extended via `emit_sext_32()` when `is_signed_bpf_cond(BPF_OP(code))` is true or `emit_zext_32()` otherwise before calling `emit_cond_jmp()`. [F42, F69]
- In `build_insn()`, the second instruction slot (`insn + 1`) must only be dereferenced inside the 16-byte `BPF_LD | BPF_IMM | BPF_DW` case (never hoisted to function entry or read in single-slot cases), where `(insn + 1)->imm` must be cast to `u64` before shifting left by 32 and `insn->imm` must be cast to `u32` before bitwise ORing into `imm64`. [F45, F64]
- When emitting `BPF_SUB | BPF_K` via `addid` in `build_insn()`, the 12-bit signed immediate check must test `is_signed_imm12(-imm)` rather than `is_signed_imm12(imm)`. [F53]
