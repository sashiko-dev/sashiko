# DMA MAPPING HELPERS

This unit (`kernel/dma/` and associated headers) implements the architecture-independent Linux DMA mapping subsystem, covering coherent/non-coherent buffer allocations and streaming mappings across `dma-direct`, `iommu-dma`, and architecture `dma_map_ops`, along with `swiotlb` bounce buffering, CMA integration, per-device/global coherent reserved memory pools, atomic coherent `gen_pool` pools, vmalloc coherent remapping, and runtime `dma-debug` tracking.

## Architecture & Data Flow
- `swiotlb_release_slots()` must subtract both `swiotlb_align_offset(dev, 0, tlb_addr)` and `mem->slots[index].pad_slots` to recover the first allocated slot index before reading `mem->slots[index].alloc_size`, add `swiotlb_align_offset(dev, 0, tlb_addr)` back to `alloc_size` before calling `nr_slots()` (`DIV_ROUND_UP(..., IO_TLB_SIZE)`), and reset `orig_addr = INVALID_PHYS_ADDR`, `alloc_size = 0`, and `pad_slots = 0` across all `nslots` while decrementing `area->used` and `mem->total_used` by `nslots`. [F14, F59, F118]
- In `dma_direct_sync_*_for_device()`, `swiotlb_sync_single_for_device()` must execute before `arch_sync_dma_for_device()`; in `dma_direct_sync_*_for_cpu()`, `arch_sync_dma_for_cpu()` must execute before `swiotlb_sync_single_for_cpu()`. [F155]
- `swiotlb_tbl_map_single()` must copy the original buffer into the bounce slot via `swiotlb_bounce(dev, tlb_addr, mapping_size, DMA_TO_DEVICE, pool)` even when `dir == DMA_FROM_DEVICE` or `DMA_ATTR_SKIP_CPU_SYNC` is set, so a partial device write followed by bounce-back does not overwrite unwritten bytes in `orig_addr`. [F64]
- `dev->dma_skip_sync` is polarity-inverted (`false` by default in zero-initialized `struct device`, set to `true` only by `dma_setup_need_sync()`, and reset to `false` by `dma_reset_need_sync()` on first SWIOTLB mapping) so devices that never call `dma_set_mask()` and devices using SWIOTLB still sync. [F46]
- Because `swiotlb_dev_init()` sets `dev->dma_io_tlb_mem = &io_tlb_default_mem` unconditionally, SWIOTLB paths (`swiotlb_tbl_map_single()`, `is_swiotlb_active()`) must check `mem && mem->nslabs` rather than just `mem != NULL`. Adding a non-transient `io_tlb_pool` to `struct io_tlb_mem` must go through `add_mem_pool()` so `mem->nslabs` is incremented in lockstep with inserting `pool->node` into `mem->pools` under `mem->lock`. [F41, F62]
- Whenever a SWIOTLB pool's `nslabs` is initialized or shrunk on allocation fallback (`swiotlb_init_remap()`, `swiotlb_init_late()`, `swiotlb_alloc_pool()`), `nareas` must be clamped via `limit_nareas(nareas, nslabs)` so each area has at least `IO_TLB_SEGSIZE` slots. In `swiotlb_search_pool_area()`, the 0-based cursor `index` within `[0, pool->area_nslabs)` must be wrapped with `wrap_area_index(pool, ...)` (not bitwise `area_nslabs - 1`, which need not be a power of two after retry) before adding `slot_base = area_index * pool->area_nslabs`. [F58, F80]
- In `swiotlb_search_pool_area()`, `alloc_align_mask` is ORed with `(IO_TLB_SIZE - 1)` for at least slot alignment, and `iotlb_align_mask` is masked with `~alloc_align_mask` before `stride` is computed as `get_max_slots(max(alloc_align_mask, iotlb_align_mask))`. [F97]
- In `__swiotlb_find_pool()`, if `paddr` is not found in `mem->pools` or `dev->dma_io_tlb_pools`, `pool` must be explicitly reset to `NULL` after the second `list_for_each_entry_rcu()` loop before `out:`. [F106]
- `dma_to_phys()` must strip memory encryption bits via `dma_addr_canonical(dma_addr)` before calling `translate_dma_to_phys(dev, dma_addr)`, and unencrypted buffers (such as SWIOTLB bounce buffers) or mask limit checks (`dma_direct_supported()`) must use `phys_to_dma_unencrypted()` instead of `phys_to_dma()`. [F151]
- In `__dma_direct_alloc_pages()` and `swiotlb_alloc_tlb()`, when page allocation returns a page above the device's physical address limit, the retry loop must step `gfp` strictly downward from default zones to `GFP_DMA32` (`__GFP_DMA32`) and then to `GFP_DMA` (`__GFP_DMA`, clearing `GFP_DMA32` via `gfp & ~GFP_DMA32`) before returning `NULL`. [F98]
- `dev->dma_range_map` is a `struct bus_dma_region` array terminated by a `size == 0` sentinel, and every valid entry must have `PFN_DOWN(size) > 0`. In `check_ram_in_range_map()`, the `while (start_pfn < end_pfn)` loop must re-query `dma_find_range(dev, start_pfn)` for a fresh `bdr` on every iteration rather than carrying `bdr` across iterations. [F84, F93]
- In `dma_alloc_attrs()` and `dma_free_attrs()`, per-device coherent memory (`dma_alloc_from_dev_coherent()` and `dma_release_from_dev_coherent()`) must be checked and returned from before stripping GFP zone flags, checking `WARN_ON(irqs_disabled())`, or dispatching to `dma_alloc_direct()`, `use_dma_iommu()`, or `ops->alloc`/`ops->free`. [F109]
- `dma_coherent_mem.size` is in `PAGE_SIZE` pages (matching `dma_coherent_mem.bitmap` bit count), so byte bounds and address math in `kernel/dma/coherent.c` must shift `mem->size` left by `PAGE_SHIFT`. Shared coherent pools (`dma_init_global_coherent()`, `rmem_dma_device_init()`) must set `use_dma_pfn_offset = true` so `dma_get_device_base()` translates `mem->pfn_base` per device via `phys_to_dma()` rather than using a fixed `mem->device_base`. [F71, F122]
- `dma_set_mask()` and `dma_set_coherent_mask()` must truncate the caller-supplied `u64 mask` to `dma_addr_t` before calling `dma_supported()`, `arch_dma_set_mask()`, or storing into `*dev->dma_mask` and `dev->coherent_dma_mask`. [F115]
- In `kernel/dma/debug.c`, `bucket_find_contain()` must bound its backward loop counter `limit` to `min(HASH_SIZE, (index.dev_addr >> HASH_FN_SHIFT) + 1)` so subtracting `1 << HASH_FN_SHIFT` from `index.dev_addr` never underflows. In `__hash_bucket_find()`, the loop must return immediately only on `match_lvl == 4`, and if `matches > 1` without a perfect match, it must return `NULL`. [F86, F104]

## Synchronization
- In `check_unmap()`, `put_hash_bucket(bucket, flags)` must be called before `dma_mapping_error()` on the `!entry` path and before `dma_entry_free(entry)` on the normal path, so `bucket->lock` is never held when `debug_dma_mapping_error()` re-locks the bucket or `active_cacheline_remove()` acquires `radix_lock`. When `bucket_find_contain()` steps backward across hash buckets, it must release `*bucket` via `put_hash_bucket(*bucket, *flags)` and overwrite `*bucket` and `*flags` via `get_hash_bucket(&index, flags)` on each iteration so `check_sync()` unlocks the bucket actually held. [F16, F67]
- In `dma_entry_alloc()`, `__dma_entry_alloc_check_leak()` must be called only after releasing `free_entries_lock`, and `dma_active_cacheline` must use `GFP_ATOMIC | __GFP_NOWARN`, so `printk` calls to console drivers that perform DMA do not re-enter `dma-debug` while internal locks (`free_entries_lock`, `radix_lock`) are held. [F148]
- In `filter_read()` and `filter_write()`, `current_driver_name` must be accessed under `driver_name_lock` with IRQs disabled (`read_lock_irqsave` / `write_lock_irqsave`) with user-space copies done outside the lock via a stack buffer (sized `>= NAME_MAX_LEN + 1` in `filter_read()`, and NUL-terminated at `<= NAME_MAX_LEN - 1` bytes in writers), and `filter_write()` must reset `current_driver = NULL` whenever modifying `current_driver_name`. [F65, F130, F146]
- `dma_debug_init()` must initialize all `dma_entry_hash` bucket lists/locks and preallocate `free_entries` before setting `dma_debug_initialized = true`, and all `struct dma_debug_entry` fields must be populated before `add_dma_entry()` publishes the entry. [F30]
- Under `CONFIG_SWIOTLB_DYNAMIC`, `swiotlb_find_slots()` must execute `WRITE_ONCE(dev->dma_uses_io_tlb, true)` followed by `smp_mb()` before returning a slot so `swiotlb_find_pool()` executing `smp_rmb()` before `READ_ONCE(dev->dma_uses_io_tlb)` observes both the flag and any RCU pool list update. Every `struct io_tlb_mem` init path (including `rmem_swiotlb_device_init()`) must initialize `mem->lock` and `INIT_LIST_HEAD_RCU(&mem->pools)` before calling `add_mem_pool()`. [F19, F20]
- In `kernel/dma/swiotlb.c`, `area->lock` in `struct io_tlb_area` must be held via `spin_lock_irqsave()` across slot search, free-list coalescing, and `area->used`/`area->index` updates in `swiotlb_search_pool_area()` and `swiotlb_release_slots()`, and `pool->area_nslabs` must be a multiple of `IO_TLB_SEGSIZE`. The circular search loop in `swiotlb_search_pool_area()` must bound iteration by counting `slots_checked < pool->area_nslabs` (incrementing by `1` on alignment mismatch and by `stride` otherwise) rather than testing `index != wrap`. [F24, F95]
- When `remap` or `force_dma_unencrypted(dev)` holds and `dma_direct_use_pool(dev, gfp)` is true (`!gfpflags_allow_blocking(gfp) && !is_swiotlb_for_alloc(dev)`), `dma_direct_alloc()` and `dma_direct_alloc_pages()` must allocate via `dma_direct_alloc_from_pool()` instead of calling blocking `dma_common_contiguous_remap()` or `dma_set_decrypted()`. [F142]
- In `kernel/dma/coherent.c`, `__dma_alloc_from_coherent()` and `__dma_release_from_coherent()` must hold `mem->spinlock` via `spin_lock_irqsave()` while modifying `mem->bitmap`, and `__dma_alloc_from_coherent()` must release `mem->spinlock` before calling `memset()` on the allocated region. [F32]

## Object Lifetimes
- Coherent DMA memory allocated with `dmam_alloc_attrs()` is tracked in `struct dma_devres` and must be freed via `dmam_free_coherent()` (never `dma_free_coherent()`/`dma_free_attrs()` directly). In `dmam_free_coherent()`, `devres_destroy()` must remove the `struct dma_devres` entry before `dma_free_coherent()` frees `vaddr`, so a concurrent allocation cannot reuse `vaddr` and register a colliding devres record before teardown completes. [F1, F133]
- Memory allocated from atomic coherent pools via `dma_alloc_from_pool()` is decrypted at pool expansion time and never shrinks, so `dma_direct_free()`, `dma_direct_free_pages()`, and `swiotlb_free_tlb()` must check `dma_free_from_pool()` and return before calling `dma_set_encrypted()` or `set_memory_encrypted()`. [F9]
- In `__swiotlb_tbl_unmap_single()`, if `swiotlb_del_transient()` returns `true` for a transient pool, `swiotlb_release_slots()` must not be called because `swiotlb_del_transient()` already decrements `mem->total_used`, unlinks the pool under `dev->dma_io_tlb_lock`, and schedules `call_rcu(&pool->rcu, swiotlb_dyn_free)`. [F13]
- `rmem_swiotlb_device_release()` must restore `dev->dma_io_tlb_mem = &io_tlb_default_mem` rather than `NULL` (since `is_swiotlb_for_alloc()` dereferences `dev->dma_io_tlb_mem->for_alloc` without a NULL check), whereas `dma_release_coherent_memory()` must clear `dev->dma_mem = NULL` after `_dma_release_coherent_memory(dev->dma_mem)` (since `dma_assign_coherent_memory()` rejects non-NULL `dev->dma_mem` with `-EBUSY`). [F2, F4]
- In `rmem_dma_setup()`, a default coherent pool (`"linux,dma-default"`) must copy `rmem->base` and `rmem->size` into `dma_reserved_default_memory_base` and `dma_reserved_default_memory_size` for `dma_init_reserved_memory()` rather than saving the `struct reserved_mem *` pointer. [F72]
- `swiotlb_create_debugfs_files()` and `dma_atomic_pool_debugfs_init()` must pass only persistent addresses to `debugfs_create_ulong()` and use `debugfs_create_file()` with a getter callback reading the `struct io_tlb_mem *` in `data` (not `io_tlb_default_mem` or stack locals), and `swiotlb_create_debugfs_files()` must not zero `mem->total_used`, `mem->used_hiwater`, or `mem->transient_nslabs` because `swiotlb_create_default_debugfs()` runs at `late_initcall` when allocations are already active. [F22, F63, F128]

## API Contracts
- When `use_dma_iommu(dev)` is true, `get_dma_ops(dev)` is `NULL` and `dma_go_direct()` returns `false`, so helpers in `kernel/dma/mapping.c` and `kernel/dma/ops_helpers.c` must check `use_dma_iommu(dev)` before dereferencing `ops` or treating `!ops` as `dma-direct`. [F34]
- In `dma_supported()`, `ops->dma_supported(dev, mask)` must always be called when `ops` and `ops->dma_supported` are non-NULL even if `dev->dma_ops_bypass` is set, whereas `dma_pci_p2pdma_supported()` must ignore `dev->dma_ops_bypass` and return `false` whenever `get_dma_ops(dev)` is non-NULL. [F172]
- When `dev->dma_mem` is set, `dma_alloc_from_dev_coherent()` must always return `1` so `dma_alloc_attrs()` does not fall back to generic memory on failure, whereas `dma_release_from_dev_coherent()` and `dma_mmap_from_dev_coherent()` must return `0` if `vaddr` is outside `mem->virt_base`. [F70]
- `dma_alloc_attrs()`, `__dma_alloc_pages()`, and `dma_alloc_noncontiguous()` must reject `gfp` flags containing `__GFP_COMP` with `WARN_ON_ONCE` and return `NULL`, and `__dma_alloc_pages()` must also reject caller-supplied `__GFP_DMA`, `__GFP_DMA32`, or `__GFP_HIGHMEM` flags. [F50]
- Callers of `dma_unmap_sg_attrs()`, `dma_sync_sg_for_cpu()`, and `dma_sync_sg_for_device()` (including `dma_unmap_sgtable()` and `dma_sync_sgtable_*()`) must pass the original segment count (`sgt->orig_nents`), not the coalesced count (`sgt->nents`). In `__dma_map_sg_attrs()`, a `map_sg` implementation must return either a positive mapped count or `-EINVAL`, `-ENOMEM`, `-EIO`, or `-EREMOTEIO`; any other non-positive value (including `0`) triggers `WARN_ON_ONCE` and is coerced to `-EIO`. [F51, F165]
- `dma_alloc_from_contiguous()` and `dma_release_from_contiguous()` take `count` in pages and `align` as a `PAGE_SIZE` order, whereas `dma_alloc_contiguous()` and `dma_free_contiguous()` take a `PAGE_ALIGN()`ed byte `size` (since `cma_alloc_aligned()` uses `size >> PAGE_SHIFT` while `dma_free_contiguous()` frees `PAGE_ALIGN(size) >> PAGE_SHIFT` pages) and fall back to `__free_pages(page, get_order(size))` for non-CMA pages. [F123, F179]
- `struct dma_iova_state::__size` reserves bit 63 (`DMA_IOVA_USE_SWIOTLB`) to flag SWIOTLB usage, so callers must extract the mapping byte size via `dma_iova_size(state)` rather than reading `state->__size` directly. [F88]

## Error Handling
- `translate_phys_to_dma()` returns `DMA_MAPPING_ERROR` (`~(dma_addr_t)0`) when no `bus_dma_region` matches, so `dma_capable()` and `dma_coherent_ok()` must test `addr == DMA_MAPPING_ERROR` before computing `addr + size - 1`. [F40]
- `dma_map_sg_attrs()` returns `0` on failure and the positive mapped entry count on success, whereas `dma_map_sgtable()` stores the mapped count into `sgt->nents` and returns `0` on success or a negative errno on failure. [F36]
- `swiotlb_init_remap()` must return gracefully without calling `panic()` when `swiotlb_memblock_alloc()` fails and `nslabs <= IO_TLB_MIN_SLABS` (or when `mem->slots` or `mem->areas` allocation fails). [F175]

## Known Pitfalls
- In `swiotlb_search_pool_area()` and `swiotlb_release_slots()`, the backward slot-merging loops starting at `i = slot_index - 1` (or `index - 1`) must test `io_tlb_offset(i) != IO_TLB_SEGSIZE - 1` before indexing `pool->slots[i].list` to prevent out-of-bounds access at index `-1` when slot 0 is allocated or freed. [F78]
- SWIOTLB slot index-to-address conversions must widen the slot index to `phys_addr_t` before left-shifting by `IO_TLB_SHIFT` via `slot_addr()`. In `get_max_slots()` and `dma_get_seg_boundary_nr_pages()`, segment boundary masks must be shifted right before adding 1 (`(boundary_mask >> shift) + 1`), rather than computing `(boundary_mask + 1) >> shift`. [F85, F111]
- `swiotlb_adjust_nareas()` must clamp a zero `nareas` argument to `1` before calling `!is_power_of_2(nareas)` and `roundup_pow_of_two(nareas)`. [F52]
- Early boot `RESERVEDMEM_OF_DECLARE` setup callbacks (`rmem_swiotlb_setup()`, `rmem_dma_setup()`, `rmem_cma_setup()`) must not call `pfn_to_page()` or `PageHighMem()`, which must be deferred to `reserved_mem_ops.device_init` callbacks such as `rmem_swiotlb_device_init()`. Helpers in `kernel/dma/` calling `__init` early allocators (`memblock_alloc*()`, `cma_declare_contiguous*()`) such as `swiotlb_memblock_alloc()` must be annotated with `__init`. [F132, F141]
