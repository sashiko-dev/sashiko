# CAN NETWORK LAYER

The CAN network layer implements the `PF_CAN` socket protocol family core (`af_can.c`, `proc.c`), CAN frame receive filter dispatching, transmission (`can_send()`), and per-netns procfs statistics, alongside built-in protocols including Raw sockets (`raw.c`), Broadcast Manager (`bcm.c`), ISO 15765-2 ISO-TP (`isotp.c`), the RTNetlink CAN gateway (`gw.c`), and the `em_canid` traffic control classifier (`net/sched/em_canid.c`).

## Architecture & Data Flow

- `struct can_frame`, `struct canfd_frame`, and `struct canxl_frame` share `skb->data` with overlapping header offsets: `canxl_frame::flags` (which must always have `CANXL_XLF` (`0x80`) set) aliases the byte offset of `can_frame::len` and `canfd_frame::len`. Receive and validation paths (`can_rcv()`, `canfd_rcv()`, `canxl_rcv()`, `can_is_can_skb()`, `can_is_canfd_skb()`, `can_is_canxl_skb()`) must first verify `skb->len` against header/MTU bounds and discriminate frame types via `can_is_can*_skb()` or `can_skb_get_len_val()` before reading `len` or `flags`. [F44, F74, F78]
- `can_rcv_list_find()` mutates `*can_id` and `*mask` in-place: it must check `*mask & CAN_ERR_FLAG` first (clearing `*mask &= CAN_ERR_MASK` and routing to `rx[RX_ERR]`), then extract `CAN_INV_FILTER` from `*can_id` before `*can_id &= *mask`, and only route to `rx_sff` or `rx_eff` when `*mask` includes `CAN_EFF_FLAG | CAN_RTR_FLAG` alongside `CAN_SFF_MASK` or `CAN_EFF_MASK` and `!(*can_id & CAN_RTR_FLAG)`. Both `can_rx_register()` and `can_rx_unregister()` must pass `&can_id` and `&mask` through `can_rcv_list_find()` and update `dev_rcv_lists->entries` and `rcv_lists_stats->rcv_entries` in lockstep. [F52, F73, F91]
- In `can_rcv_filter()`, when a received frame has `can_id & CAN_ERR_FLAG` set, only `dev_rcv_lists->rx[RX_ERR]` is traversed (matching `can_id & rcv->mask`) and the function must return immediately without evaluating `RX_ALL`, `RX_FIL`, `RX_INV`, `rx_eff`, or `rx_sff`. [F93]
- Before indexing the 2048-entry `rx_sff` array in `struct can_dev_rcv_lists` or the 2048-bit `match_sff` bitmap in `struct canid_match` (`em_canid_sff_match_add()`), SFF CAN IDs and masks must be masked with `CAN_SFF_MASK` (`0x7FFU`). [F80]
- In `struct can_skb_priv`, the trailing flexible array `struct can_frame cf[]` aligns the struct size to 8 bytes so `can_skb_reserve(skb)` places `skb->data` at an 8-byte aligned address required by `get_u64()` in `bcm.c` and `*(u64 *)cf->data` in `gw.c` at 8-byte-multiple offsets. [F82]
- `can_send()` sets `skb->ip_summed = CHECKSUM_UNNECESSARY` on all transmitted and software-loopback CAN `sk_buff`s; `can_can_gw_rcv()` asserts `BUG_ON(skb->ip_summed != CHECKSUM_UNNECESSARY)` so it can repurpose `skb->csum_start` (`cgw_hops(skb)`) as the gateway routing hop counter. [F151]
- Because `raw_notifier_list`, `bcm_notifier_list`, and `isotp_notifier_list` are global across network namespaces while `ifindex` is only unique per netns, `raw_notify()`, `bcm_notify()`, and `isotp_notify()` must check `net_eq(dev_net(dev), sock_net(sk))` before matching `dev` or `ifindex`. [F159]
- In `raw.c` and `bcm.c`, RX `sk_buff`s queued to the socket store `struct sockaddr_can` at the start of `skb->cb` and an `unsigned int` flags word (`raw_flags()` / `bcm_flags()`) at `&((struct sockaddr_can *)skb->cb)[1]`, requiring `sock_skb_cb_check_size(sizeof(struct sockaddr_can) + sizeof(unsigned int))`. [F128]
- In `raw_setsockopt()`, `ro->fd_frames` must remain enabled whenever `ro->xl_frames` is enabled (setting `ro->fd_frames = ro->xl_frames` on `CAN_RAW_XL_FRAMES` and rejecting `!flag` on `CAN_RAW_FD_FRAMES`), `raw_check_txframe()` must accept CAN FD frames on both `CANFD_MTU` and `can_is_canxl_dev_mtu(mtu)` devices, and updating `ro->raw_vcid_opts` under `CAN_RAW_XL_VCID_OPTS` must recompute `ro->tx_vcid_shifted`, `ro->rx_vcid_shifted`, and `ro->rx_vcid_mask_shifted` (`<< CANXL_VCID_OFFSET`). [F56, F57]
- In `net/can/bcm.c`, when `op->nframes > 1` in an RX `struct bcm_op`, index `0` of `op->frames` stores the 64-bit MUX mask while filter frames and `op->last_frames` state occupy 1-based indices `1 .. op->nframes - 1` (allowing `msg_head->nframes` up to `MAX_NFRAMES + 1` in `bcm_rx_setup()`). `op->last_frames` stores internal flags (`RX_RECV`, `RX_THR`, `RX_LOCAL`, `RX_OWN`) in the upper nibble of `canfd_frame::flags`, so `bcm_send_to_user()` must translate `RX_LOCAL`/`RX_OWN` into `*bcm_flags(skb)` and mask `firstframe->flags &= BCM_CAN_FLAGS_MASK` on the SKB copy when `head->nframes == 1`. [F61, F83]
- In `net/can/bcm.c`, user-supplied `struct bcm_timeval` intervals must be validated by `bcm_is_invalid_tv()` (`0 <= tv_sec <= BCM_TIMER_SEC_MAX` and `0 <= tv_usec < USEC_PER_SEC`) before calling `bcm_timeval_to_ktime()`, preventing negative `ktime_t` values and 32-bit `long` multiplication overflow in `tv.tv_usec * NSEC_PER_USEC`. [F110]
- In `net/can/isotp.c`, `struct tpcon` fields `len` and `idx` must be `unsigned int` so 32-bit `FF_DL` wire lengths cannot wrap negative. `isotp_rcv_ff()` must verify `so->rx.len <= so->rx.buflen` and `so->rx.len + ae + off + ff_pci_sz >= so->rx.ll_dl`, and `isotp_rcv_cf()` must stop copying into `so->rx.buf` as soon as `so->rx.idx >= so->rx.len`. [F88, F108]
- In `net/can/isotp.c`, consecutive frame sequence counters `so->rx.sn` and `so->tx.sn` must be reduced modulo 16 (`%= 16`) after each increment; in `isotp_rcv_cf()`, the `CAN_ISOTP_LISTEN_MODE` early return must come after the `!so->rxfc.bs || ++so->rx.bs < so->rxfc.bs` check that restarts `so->rxtimer` so RX timeout monitoring stays active while suppressing `isotp_send_fc()`. [F102, F113]
- In `isotp_setsockopt_locked()`, `CAN_ISOTP_OPTS` must update `so->frame_txtime` only when `so->opt.frame_txtime != 0` (mapping `CAN_ISOTP_FRAME_TXTIME_ZERO` to `0`) and copy `so->opt.ext_address` to `so->opt.rx_ext_address` when `!(so->opt.flags & CAN_ISOTP_RX_EXT_ADDR)`, while `CAN_ISOTP_LL_OPTS` must sync `so->tx.ll_dl = ll.tx_dl`. [F69]
- In `net/can/gw.c`, `struct cf_mod` and `struct can_can_gw` must be zero-initialized with `memset()` and populated field-by-field via `canframecpy()` or `canfdframecpy()` rather than whole-struct copies, because `cgw_create_job()` and `cgw_remove_job()` compare these structs with `memcmp()`. [F49]
- In `net/can/gw.c`, Classical CAN DLC modifiers (`mod_and_ccdlc`, `mod_set_ccdlc`, etc.) must unpack `ccf->len8_dlc` into `ccf->len` via `mod_retrieve_ccdlc(cf)` and repack DLC 9..15 into `ccf->len8_dlc` (clamping `ccf->len = CAN_MAX_DLEN`) via `mod_store_ccdlc(cf)`. When `modidx > 0`, `can_can_gw_rcv()` must verify `cf->len <= nskb->len - offsetof(struct canfd_frame, data)` before running `mod->csumfunc`, and relative checksum handlers (`cgw_csum_xor_rel`, `cgw_csum_crc8_rel`) must abort if `calc_idx(idx, cf->len) < 0`. [F71, F85]
- In `net/sched/em_canid.c`, `em_canid_change()` must partition `cm->rules_raw` so all `cm->eff_rules_count` EFF rules (`can_id & CAN_EFF_FLAG`) precede all `cm->sff_rules_count` SFF rules while calling `em_canid_sff_match_add()` for each SFF rule, because `em_canid_match()` only scans the first `cm->eff_rules_count` entries of `cm->rules_raw`. [F75]

## Synchronization

- In `can_rx_register()`, the `rcv_cache` slab allocation (`GFP_KERNEL`) must happen before acquiring `spin_lock_bh(&net->can.rcvlists_lock)`, and all fields of `struct receiver` must be initialized before `hlist_add_head_rcu(&rcv->list, rcv_list)` publishes the entry under `rcvlists_lock` (which also serializes all mutations to `struct can_dev_rcv_lists` and `net->can.rcv_lists_stats`). [F21, F133]
- Functions in `raw.c`, `bcm.c`, and `isotp.c` (`raw_release()`, `raw_bind()`, `raw_setsockopt()`) that acquire both `rtnl_mutex` and the socket lock must acquire `rtnl_lock()` before `lock_sock(sk)` and call `release_sock(sk)` before `rtnl_unlock()`, matching the netdev notifier lock order (`raw_notify()`). [F135]
- In `raw.c`, `bcm.c`, and `isotp.c`, the notifier spinlock (`raw_notifier_lock`, `bcm_notifier_lock`, `isotp_notifier_lock`) must be dropped with `*_busy_notifier` set before calling `*_notify()`, and `*_release()` must wait while `*_busy_notifier` points to the closing socket before calling `list_del()`. [F28]
- In `net/can/af_can.c`, `can_get_proto()` must dereference `proto_tab[protocol]` and call `try_module_get(cp->prot->owner)` inside `rcu_read_lock()`, while `can_proto_unregister()` must clear `proto_tab[proto]` under `proto_tab_lock` and call `synchronize_rcu()` before `proto_unregister(cp->prot)`. [F145]

## Object Lifetimes

- `can_skb_set_owner()` must acquire the socket reference using `refcount_inc_not_zero(&sk->sk_refcnt)` before setting `skb->destructor = sock_efree` and `skb->sk = sk`, because `sk->sk_refcnt` may already be 0 if userspace closed the socket while TX skbs are in flight. Broken by: using `sock_hold(sk)` or unconditionally assigning `skb->sk`. [F3]
- When `can_rx_unregister()` unlinks a `struct receiver` with a non-NULL `rcv->sk`, it must pin the socket with `sock_hold(rcv->sk)` before scheduling `call_rcu(&rcv->rcu, can_rx_delete_receiver)` and release it via `sock_put(sk)` inside `can_rx_delete_receiver()`. [F22]
- Removing a `struct cgw_job` must unlink `gwj->list`, call `cgw_unregister_filter(net, gwj)`, and defer freeing `gwj->cf_mod` and `gwj` via `call_rcu(&gwj->rcu, cgw_job_free_rcu)`, while replacing `gwj->cf_mod` in-place in `cgw_create_job()` must use `rcu_assign_pointer()` and `kfree_rcu_mightsleep()`. [F19]
- In `bcm_release()`, `remove_proc_entry(bo->procname, net->can.bcmproc_dir)` must be called before freeing `bo->tx_ops` or `bo->rx_ops`; all `bo->rx_ops` filters must be unregistered via `bcm_rx_unreg()` or `can_rx_unregister()` (with `op->flags |= RX_NO_AUTOTIMER` set before `can_rx_unregister()` in `bcm_delete_rx_op()`) followed by `synchronize_rcu()` before calling `bcm_remove_op(op)` to cancel timers and schedule `bcm_free_op_rcu`. [F30, F31]
- Storing a bound `net_device` in `raw_sock::dev` requires holding a tracked reference via `netdev_hold(ro->dev, &ro->dev_tracker, GFP_KERNEL)` in `raw_bind()` and releasing it via `netdev_put(ro->dev, &ro->dev_tracker)` while clearing `ro->bound` and `ro->dev` in `raw_bind()`, `raw_notify()`, and `raw_release()`. [F9]
- In `can_create()`, if `sk->sk_prot->init(sk)` fails after `sock_init_data(sock, sk)`, it must call `sock_orphan(sk)`, `sock_put(sk)`, and set `sock->sk = NULL` without calling `sock_prot_inuse_add()`, while always calling `can_put_proto(cp)`. [F6]
- In `net/can/isotp.c`, `so->rx.buf` and `so->tx.buf` initially point to inline `sbuf` (`DEFAULT_MAX_PDU_SIZE`) and may be upgraded to a heap buffer only while updating `buflen = max_pdu_size` in lockstep; `isotp_release()` must check `buf != sbuf` before calling `kfree(buf)`. [F64]
- In `can_pernet_exit()`, `can_remove_proc(net)` and `timer_delete_sync(&net->can.stattimer)` must execute before `kfree()` frees `rx_alldev_list`, `pkg_stats`, and `rcv_lists_stats`. During module teardown in `can_exit()` and `cgw_module_exit()`, `rcu_barrier()` must be called after unregistering all handlers/pernet subsystems and before `kmem_cache_destroy()` destroys `rcv_cache` or `cgw_cache`. [F24, F25]

## API Contracts

- `can_send()` and `can_create_echo_skb()` always consume or free their input `skb` on every return path (with `can_send()` normalizing positive `dev_queue_xmit()` statuses via `net_xmit_errno()` and using `GFP_ATOMIC` for loopback clones, never called from hardirq), so callers must never free `skb` after calling either function even on error or `NULL` return. [F2, F42, F130]
- A `can_rx_register()` callback (`rcv->func`) must neither free the passed `skb` nor mutate `skb->data` or `struct can_skb_priv` in-place; it must call `skb_clone()` to retain the packet or `skb_copy()` before modifying frame bytes (as in `can_can_gw_rcv()`), because `can_receive()` shares one `skb` across all matching receivers before calling `consume_skb()`. [F43]
- In `net/can/gw.c`, `cgw_create_job()` and `cgw_remove_job()` must verify `netlink_capable(skb, CAP_NET_ADMIN)`; `cgw_parse_attr()` must allow `ccgw->src_idx == 0 && ccgw->dst_idx == 0` (used by `cgw_remove_job()` to flush all jobs via `cgw_remove_all_jobs()`) while rejecting a single zero interface index, whereas `cgw_create_job()` must reject `!ccgw.src_idx || !ccgw.dst_idx`. [F106, F161]
- `PF_CAN` `proto_ops` tables (`raw_ops`, `bcm_ops`, `isotp_ops`) must set `.ioctl` to a handler returning `-ENOIOCTLCMD` (`raw_sock_no_ioctlcmd`, etc.) rather than `sock_no_ioctl` so unrecognized ioctls reach the NIC layer. [F158]

## Error Handling

- Before accessing a netdevice's `can_ml_priv` receive lists in `can_rx_register()`, `can_rx_unregister()`, or packet handlers (`can_rcv()`, `canfd_rcv()`, `canxl_rcv()`), the code must verify `dev->type == ARPHRD_CAN`, `can_get_ml_priv(dev) != NULL`, and `net_eq(net, dev_net(dev))`, because non-CAN virtual interfaces can set `ARPHRD_CAN` without allocating `ML_PRIV_CAN`. [F40, F160]
- When populating `struct sockaddr_can` in `skb->cb` (`raw_rcv()`, `bcm_send_to_user()`, `isotp_rcv_skb()`) or in `getname` (`raw_getname()`, `isotp_getname()`), the destination region must first be zeroed with `memset()` so alignment padding is not leaked to userspace. [F54]
- Every `isotp` TX path (`isotp_send_fc()`, `isotp_send_cframe()`, `isotp_sendmsg()`) must allocate frame data with `skb_put_zero(skb, so->ll.mtu)` and unconditionally set `cf->flags = so->ll.tx_flags`; `isotp_recvmsg()` and `isotp_sendmsg()` must verify `so->bound` (and `so->tx.state != ISOTP_SHUTDOWN` in `isotp_sendmsg()`) and return `-EADDRNOTAVAIL` before blocking. [F46, F48]
- When populating CAN frame buffers from userspace via `memcpy_from_msg()` (`bcm_tx_setup()`, `raw_sendmsg()`), the negative error return must be checked before reading `cf->len` or overwriting `err` with `-EINVAL`; when `can_rx_register()` fails at index `i` in `raw_enable_filters()`, rollback must use `while (--i >= 0)`. [F45, F98]

## External Contracts

- `struct can_frame`, `struct canfd_frame`, and `struct canxl_frame` (`can_init()`) must keep `can_id`/`prio` at offset 0, `can_frame.len`, `canfd_frame.len`, and `canxl_frame.flags` at the same offset (with `can_frame`'s `len` union marked `__attribute__((packed))`), and `can_frame.data` and `canfd_frame.data` 8-byte aligned at the same offset. [F77]
- Socket address length checks, zeroing, and `msg_namelen` assignments in `raw.c`, `bcm.c`, and `isotp.c` must use `CAN_REQUIRED_SIZE(struct sockaddr_can, ...)` (`RAW_MIN_NAMELEN`, `BCM_MIN_NAMELEN`, `ISOTP_MIN_NAMELEN`) rather than `sizeof(struct sockaddr_can)`. [F79]
- In `isotp_bind()`, user-supplied `tx_id` (and `rx_id` when `isotp_register_rxid(so)` is true) must be masked to `(CAN_EFF_FLAG | CAN_EFF_MASK)` or `CAN_SFF_MASK` and rejected with `-EINVAL` if any other bits were set before comparing `rx_id == tx_id`. In `CAN_ISOTP_LL_OPTS`, `ll.tx_dl` must equal `padlen(ll.tx_dl)`, `ll.mtu` must be `CAN_MTU` or `CANFD_MTU`, and for `CAN_MTU` both `ll.tx_dl > CAN_MAX_DLEN` and `ll.tx_flags != 0` must be rejected. [F81, F89]
- `isotp_recvmsg()` must allow `MSG_CMSG_COMPAT` alongside `MSG_DONTWAIT | MSG_TRUNC | MSG_PEEK`, call `sock_recv_cmsgs()`, and return `skb->len` rather than `size` when `MSG_TRUNC` is set. [F157]

## Known Pitfalls

- In `isotp_rcv_fc()`, `so->txfc.stmin` values in the reserved ranges (`0x80..0xF0` and `0xFA..0xFF`) must be clamped to `0x7F` before computing `(so->txfc.stmin - 0xF0) * 100000`, preventing signed `int` underflow and sign-extension to `u64` in `ktime_add_ns()`. [F109]
- In `net/can/bcm.c`, `bcm_op::frames` and `bcm_op::last_frames` are untyped `void *` buffers with element size `op->cfsiz` (`CAN_MTU` or `CANFD_MTU`), so indexing the `i`-th frame (`bcm_rx_cmp_to_index()`) must use byte-scaled pointer arithmetic (`op->frames + op->cfsiz * i`) rather than typed struct array indexing. [F116]
- In `net/sched/em_canid.c`, `em_canid_change()` receives `len` in bytes, but pointer arithmetic on `cm->rules_raw` (`struct can_filter[]`) scales by `sizeof(struct can_filter)` and must use rule counts (`eff_rules_count`, `sff_rules_count`), while `em_canid_dump()` must pass `cm->rules_count * sizeof(struct can_filter)` to `nla_put_nohdr()`. [F125]
