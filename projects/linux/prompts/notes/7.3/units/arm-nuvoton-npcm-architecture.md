# ARM/NUVOTON NPCM ARCHITECTURE

This unit provides architecture support and SoC peripheral drivers for Nuvoton NPCM Baseboard Management Controller (BMC) families (NPCM7xx Poleg and NPCM8xx Arbel), as well as the Nuvoton NCT3018Y I2C RTC. It covers SMP CPU bringup, clocks, reset controllers, pin control and GPIO/SGPIO, I2C, SPI (FIU flash interface and peripheral SPI), PWM/fan tachometer hwmon, PECI, KCS IPMI BMC, ADC, watchdog, hardware RNG, timers, USB (EHCI and ChipIdea UDC), and SDHCI MMC.

## Architecture & Data Flow
- In `i2c-npcm7xx.c`, Bank 1 is the default register bank; any function selecting `I2C_BANK_0` via `npcm_i2c_select_bank()` must restore `I2C_BANK_1` before returning. Runtime slave helpers (`npcm_i2c_slave_enable()`, `npcm_i2c_get_slave_addr()`, `npcm_i2c_remove_slave_addr()`) must only access Bank-1-visible `NPCM_I2CADDR1`/`NPCM_I2CADDR2` and never select `I2C_BANK_0` without spinlock serialization against Bank 1 FIFO IRQ handlers. [F20, F60]
- Because `npcm_i2c_disable()` clears `NPCM_I2CCTL1` and zeroes slave-address registers, `npcm_i2c_reset()` must save `NPCM_I2CCTL1` before `npcm_i2c_disable()`, restore it (masking `~NPCM_I2CCTL1_RWS`) after `npcm_i2c_enable()`, and re-enable `bus->slave->addr` if `bus->slave` is non-NULL. [F62]
- On FIFO-mode NACK (`bus->fifo_use`), `npcm_i2c_irq_handle_nack()` and `npcm_i2c_slave_wr_buf_sync()` must subtract `npcm_i2c_fifo_usage(bus)` (`NPCM_I2CTXF_STS`) from `bus->wr_ind` or `bus->slv_wr_ind`/`bus->slv_wr_size` before flushing with `NPCM_I2CFIF_CTS_CLR_FIFO`. `bus->data->fifo_size` must be a power of two `<= MAX_I2C_HW_FIFO_SIZE` (32), and `bus->slv_wr_ind` must be a signed `int`. [F63, F75]
- For SMBus block reads (`bus->read_block_use`): in `npcm_i2c_set_fifo()`, on the first byte (`nread > 0 && bus->rd_ind == 0`), override `rxf_ctl` to `1` without `rxf_ctl_last_pec` after checking `nread <= bus->data->fifo_size`; in `npcm_i2c_irq_master_handler_read()`, clamp the wire block length to `[1, I2C_SMBUS_BLOCK_MAX]`. [F76, F86]
- In `npcm_i2c_master_fifo_read()`, when `rcount <= fifo_bytes`, call `npcm_i2c_eob_int(bus, true)` and `npcm_i2c_master_stop(bus)` before `npcm_i2c_read_fifo()`. In `npcm_i2c_int_master_handler()`, check `NMATCH`, `NEGACK`, `BER`, and `EO_BUSY` first and return `0`, but handle `NPCM_I2CST_STASTR` before `NPCM_I2CST_SDAST` without returning early. In `npcm_i2c_master_xfer()`, set `bus->dest_addr = i2c_8bit_addr_from_msg(msg0) & ~I2C_M_RD` before `i2c_recover_bus()`. [F65, F87, F91]
- In `pinctrl-npcm7xx.c` and `pinctrl-npcm8xx.c`, `fn_*` enums and `npcm7xx_groups[]`/`npcm8xx_pingroups[]` must stay 1:1 aligned via `NPCM7XX_GRPS`/`NPCM8XX_GRPS` with `fn_none` and `fn_gpio` last. In `npcm7xx_setfunc()`/`npcm8xx_setfunc()`, when `mode` matches `fn_gpio` or any `cfg->fnN`, update every non-zero `cfg->regN` for that pin—setting `BIT(cfg->bitN)` where `cfg->fnN == mode` and clearing `BIT(cfg->bitN)` in all other `cfg->regN` slots. [F79, F99]
- In `npcm7xx_config_set_one()` and `npcm8xx_config_set_one()`, setting `PIN_CONFIG_INPUT_ENABLE` or `PIN_CONFIG_LEVEL` must update both `GP_N_OEC`/`GP_N_OES` and `GP_N_IEM` (via `bank->direction_input()`/`direction_output()`), and setting pull bias must clear the opposite pull register (`GP_N_PU` vs `GP_N_PD`). In `npcm7xx_gpio_of()` and `npcm8xx_gpio_fw()`, `gpio_generic_chip_init()` must run before saving and overriding `chip.gc.direction_input`, `direction_output`, and `request`. [F58, F59]
- In `gpio-npcm-sgpio.c`, `struct gpio_chip chip` must be the first member of `struct npcm_sgpio`, and `npcm_sgpio_dir_out()` must match `npcm_sgpio_probe()`'s choice of `chip.set` vs `chip.set_rv`. Input SGPIOs sit at `[nout_sgpio, nout_sgpio + nin_sgpio)`, so input callbacks must subtract `nout_sgpio` before indexing `npcm_sgpio_banks[]` or `gpio->int_type[]` and add `nout_sgpio` when dispatching IRQs. In `npcm_sgpio_init_port()`, increment `in_port`/`out_port` from `GPIO_BANK(...)` when `GPIO_BIT(...) > 0`. [F56, F72, F108, F116]
- In `clk-npcm8xx.c`, `npcm8xx_pre_divs[]`, `npcm8xx_divs[]`, and `*_mux_parents[]` reference `npcm8xx_pll_clks[]`, `npcm8xx_muxes[]`, and `npcm8xx_pre_divs[]` by hardcoded indices and rely on `npcm8xx_clk_probe()` copying `*hw` into each parent's static `.hw` field before registering child clocks. `npcm8xx_clk_pll_ops` must only be registered on `struct npcm8xx_clk_pll` via `npcm8xx_clk_register_pll()`. [F66, F117]
- In `spi-npcm-fiu.c`, `npcm_fiu_exec_op()` must update `fiu->clkrate = chip->clkrate` only after `clk_set_rate()` succeeds. In `spi-npcm-pspi.c`, `npcm_pspi_reset_hw()` must set `priv->is_save_param = false` so `npcm_pspi_setup_transfer()` reprograms `NPCM_PSPI_CTL1`. [F52, F53]
- In `rtc-nct3018y.c`, time registers (`SC=0x00`, `MN=0x02`, `HR=0x04`) are interleaved with alarm registers (`0x01`, `0x03`, `0x05`), so block reads must index `buf[0]`, `buf[2]`, `buf[4]`, and `nct3018y_rtc_set_time()` must write `SC`, `MN`, `HR` individually (setting `NCT3018Y_BIT_TWO` in `NCT3018Y_REG_CTRL` first on `NCT3018Y_REG_PART_NCT3018Y` if unset, and clearing it afterward if `restore_flags` is set). [F81, F102]
- Lookup tables must stay ordered: descending `core_clk` in `smb_timing_*khz[]` (`npcm_i2c_init_clk()`); descending divider in `npcm750_SFT_CLK`/`npcm845_SFT_CLK` (`npcm_sgpio_setup_clk()`); and descending frequency `{ 32768, 1024, 32, 1 }` in `clkout_rates[]` matching `NCT3018Y_REG_CLKO_F_MASK` (`nct3018y_clkout_*()`). [F77, F97, F103]
- In `npcm750-pwm-fan.c`: bound PWM loops by `data->pwm_modules` and channel visibility by `data->info->pwm_max_channel` (not `NPCM7XX_PWM_MAX_MODULES`/`CHN_NUM`); clamp `prescale_val >= MIN_PRESCALE1` (2) before `prescale_val--` in `npcm7xx_pwm_init()`; check `fan_cnt > 0 && fan_pls_per_rev > 0` before dividing in `npcm7xx_read_fan()`; and check `flag & flag_timeout` before `flag & flag_cap` in `npcm7xx_check_cmp()`. [F94, F109, F110, F127]
- In `peci-npcm.c`, when `req->tx.len > 0`, `npcm_peci_xfer()` writes `req->tx.buf[0]` to `NPCM_PECI_CMD` and `req->tx.buf[i + 1]` to `NPCM_PECI_DAT_INOUT(i)`, reading RX bytes from `NPCM_PECI_DAT_INOUT(0)`. Because `npcm_peci_irq_handler()` ORs error and done bits into `priv->status`, `npcm_peci_xfer()` must check `priv->status != NPCM_PECI_CTRL_DONE`. [F82, F105]
- In `npcm7xx_kcs_probe()`, 1-based `'kcs_chan'` must be validated in `[1, KCS_CHANNEL_MAX]` and decremented by 1 when indexing `npcm7xx_kcs_reg_tbl[]`. In `reset-npcm.c`, `npcm_reset_xlate()` must validate `args[0]` against `rc->info->ipsrst[]` and `args[1] < NPCM_RC_RESETS_PER_REG`. In `npcm-rng.c`, `npcm_rng_init()` and `npcm_rng_cleanup()` must OR `priv->clkp` into `NPCM_RNGCS_REG`. In `npcm_wdt.c`, keep timeout steps in `npcm_wdt_set_timeout()` and `npcm_wdt_start()` in lockstep, calling `npcm_wdt_start()` when `watchdog_active(wdd)`. [F69, F70, F71, F78]

## Synchronization
- In `i2c-npcm7xx.c`: `npcm_i2c_probe_bus()` must initialize `bus->lock`, `bus->cmd_complete`, and `npcm_i2c_int_enable(bus, false)` before `devm_request_irq()`; `npcm_i2c_callback()` must finish updating `bus->cmd_err`, `msgs[...].len`, `bus->operation`, and `bus->master_or_slave` before `complete(&bus->cmd_complete)`; and `npcm_i2c_master_xfer()`'s `NPCM_I2CCST_BB` loop must hold `bus->lock` (`spin_lock_irqsave()`) across reading `NPCM_I2CCST` and clearing `NPCM_I2CADDR_SAEN` in `NPCM_I2CADDR1` when `!bus_busy && bus->slave`, dropping `bus->lock` each iteration and restoring `(bus->slave->addr & 0x7F) | NPCM_I2CADDR_SAEN` on completion. [F18, F19, F21, F64]
- In `peci-npcm.c`, `npcm_peci_xfer()` must hold `priv->lock` (`spin_lock_irq()`) across `reinit_completion()`, `priv->status = 0`, and setting `NPCM_PECI_CTRL_START_BUSY`, drop it before `wait_for_completion_interruptible_timeout()`, and re-acquire it to check `priv->status`, unlocking on both error and normal paths. [F11, F22]
- In `gpio-npcm-sgpio.c`, `struct npcm_sgpio.lock` must be a `raw_spinlock_t` (`raw_spin_lock_irqsave()`) because `sgpio_irq_chip` callbacks run under genirq's raw `irq_desc->lock`. In `pinctrl-npcm7xx.c` and `pinctrl-npcm8xx.c`, RW GPIO registers (`PU`, `PD`, `OTYP`, `DBNC`, `EVTYP`, `EVBE`, `POL`, `OSRC`, `ODSC`) must use `npcm_gpio_set()`/`npcm_gpio_clr()`, whereas W1S/W1C registers (`OES`, `OEC`, `EVENS`, `EVENC`, `EVST`) are written directly with `BIT(gpio)`. [F30, F134, F140]
- Other locks and atomic contexts: hold `data->fan_lock[fan]` (`spin_lock_irqsave()`) across `fan_st_flg`, `TIEN`, and `TCKC` updates in `npcm750-pwm-fan.c`; hold `rc->lock` (`spin_lock_irqsave()`) in `npcm_rc_setclear_reset()`; hold `info->lock` across `npcm_adc_read()` in `npcm_adc_read_raw()`; use atomic `udelay()`/`readx_poll_timeout_atomic()` in hardirq-called `npcm_i2c_master_stop()`/`npcm_i2c_irq_handle_nack()` and `mdelay()`/`udelay()` in `npcm_rc_restart()`/`npcm_wdt_restart()`; and register `nct3018y_irq()` via `devm_request_threaded_irq(..., IRQF_ONESHOT)`. [F24, F27, F29, F143, F146, F151]

## Object Lifetimes
- In `npcm_i2c_probe_bus()`, set `bus->apb_clk = clk_get_rate(i2c_clk)` before `__npcm_i2c_init()`, and call `npcm_i2c_init_debugfs()` only after `i2c_add_numbered_adapter()`. In `npcm_i2c_unreg_slave()`, disable slave IRQs, remove the slave address, and clear `bus->slave = NULL` under `spin_lock_irqsave(&bus->lock, lock_flags)`. [F7, F8]
- In `npcm-rng.c`, pair `pm_runtime_enable()` with `pm_runtime_disable()` and `pm_runtime_set_suspended()` on probe failure and in `npcm_rng_remove()` (after `devm_hwrng_unregister()`), and pair `pm_runtime_get_sync()` with `pm_runtime_put_sync_autosuspend()` on all paths in `npcm_rng_read()`. [F9, F10]
- In `npcm7xx_clk_init()`, `npcm7xx_init_fail` must pass `npcm7xx_clk_data` (not `->hws`) to `kfree()`, then `iounmap(clk_base)` and `of_node_put(clk_np)`. In `npcm7xx_smp_boot_secondary()` and `npcm7xx_smp_prepare_cpus()`, unmap `gcr_base` and `scu_base` with `iounmap()`. [F1, F16]
- Registration/teardown ordering: call `usb_put_hcd(hcd)` on `npcm7xx_ehci_hcd_drv_probe()` failure and after `usb_remove_hcd()` in remove; call `iio_device_unregister()` / `kcs_bmc_remove_device()` before disabling hardware/regulators/clocks in `npcm_adc_remove()` and `npcm7xx_kcs_remove()`; call `devm_pinctrl_register()` before `npcm7xx_gpio_register()`/`npcm8xx_gpio_register()`; disable IOX via `npcm_sgpio_setup_enable(gpio, false)` before writing `EVENT_CFG` in `gpio-npcm-sgpio.c`; and in `npcm_wdt_probe()`, if `npcm_is_running(&wdt->wdd)`, call `npcm_wdt_start(&wdt->wdd)` and set `WDOG_HW_RUNNING` before `devm_watchdog_register_device()`. [F6, F12, F28, F126, F136]

## API Contracts
- In `npcm7xx_config_set_one()` and `npcm8xx_config_set_one()`, `npcm_gpio_set()`, `npcm_gpio_clr()`, and `OEC`/`OES` writes take `BIT(pin % bank->chip.gc.ngpio)`, whereas `bank->direction_input()`, `direction_output()`, and `debounce_timing_setting()` (via `npcm_set_debounce()` with `arg * 1000` ns) take unshifted `pin % bank->chip.gc.ngpio`. `npcm7xx_config_get()` and `npcm8xx_config_get()` must return `-EINVAL` when a boolean pinconf is inactive and pack drive strength / slew rate via `pinconf_to_config_packed()`. [F46, F47, F158]
- In `rtc-nct3018y.c`: use sleepable `.prepare`/`.unprepare`/`.is_prepared` in `nct3018y_clkout_ops`; in `nct3018y_clkout_determine_rate()`, always set `req->rate` to a valid `clkout_rates[]` entry (defaulting to `clkout_rates[0]`, never 0); offset `tm_mon` by `-1`/`+1` and `tm_year` by `+100`/`-100`; and clear `RTC_FEATURE_UPDATE_INTERRUPT` and `RTC_FEATURE_ALARM` before `devm_rtc_register_device()` when `client->irq <= 0`. [F147, F152, F153, F154]
- In `npcm_rng_read()`, when `!wait`, check `NPCM_RNG_DATA_VALID` with non-blocking `readb()` instead of `readb_poll_timeout()`; on timeout or empty data, break, put runtime PM, and return `retval` if `retval > 0 || !wait` (returning `-EIO` only when `retval == 0 && wait`). [F36, F148]
- Other contracts: cap `data_size <= 16` (`CHUNK_SIZE`) and loop `DIV_ROUND_UP(data_size, 4)` in `npcm_fiu_uma_read()`/`npcm_fiu_uma_write()`; allocate `clk_hw_onecell_data` with `struct_size(..., hws, NPCM*XX_NUM_CLOCKS)` and set `.num`; in `npcm_i2c_slave_get_wr_buf()`, emit `I2C_SLAVE_READ_REQUESTED` only on the first byte when `bus->state == I2C_SLAVE_MATCH` (then setting `I2C_OPER_STARTED`); divide `regulator_get_voltage(info->vref)` by `1000` for `IIO_CHAN_INFO_SCALE` in `npcm_adc_read_raw()`; call `dma_coerce_mask_and_coherent(&pdev->dev, DMA_BIT_MASK(32))` before `usb_create_hcd()` in `npcm7xx_ehci_hcd_drv_probe()`; and set `CI_HDRC_REQUIRES_ALIGNED_DMA` in `npcm_udc_probe()`. [F73, F107, F114, F149, F150, F155, F163]

## Error Handling
- In `npcm7xx_gpio_of()` and `npcm8xx_gpio_fw()`, initialize `ret = -ENXIO` before `for_each_gpiochip_node()`, check `fwnode_iomap()` and `devm_kasprintf()` for `NULL` (not `IS_ERR()`), and check `fwnode_irq_get()` with signed `ret < 0`. [F31, F32, F33, F43]
- In `npcm_i2c_probe_bus()` and `npcm_usb_reset()`, fall back to `syscon_regmap_lookup_by_compatible("nuvoton,npcm750-gcr")` if `syscon_regmap_lookup_by_phandle()` fails, and return `PTR_ERR()` (never `IS_ERR()`). In `npcm_i2c_master_xfer()`, call `npcm_i2c_reset(bus)` if `rxf_ctl_last_pec` remains set after a non-BER error, and always disable stall-after-start and EOB interrupts after every transfer. [F34, F40, F123]
- Guard all `info->vref` uses in `npcm_adc.c` with `!IS_ERR(info->vref)` (since `devm_regulator_get_optional()` returns `ERR_PTR(-ENODEV)`), and store `i2c_smbus_read_byte_data()` in a signed `int` checked `< 0` in `rtc-nct3018y.c`. [F35, F37]

## External Contracts
- In `npcm_usb_reset_npcm7xx()` and `npcm_usb_reset_npcm8xx()`, assert IPSRST bits for USB PHYs and controllers, clear `NPCM_USBXPHYCTL_RS`, deassert PHY resets (`udelay(50)` on NPCM7xx), set `NPCM_USBXPHYCTL_RS`, and only then deassert controller resets, matching `ipsrst1_bits`..`ipsrst4_bits` to `iprst1`..`iprst4` and `NPCM_IPSRST1`..`4`. In `npcm7xx_smp_boot_secondary()`, run `dsb_sev()` after writing `__pa_symbol(npcm7xx_secondary_startup)` to `NPCM7XX_SCRPAD_REG`. [F83, F129, F137]

## Known Pitfalls
- In `i2c-npcm7xx.c`, any RMW of `NPCM_I2CCTL1` not intending a bus action must mask `~NPCM_I2CCTL1_RWS` (`START | STOP | ACK`), and setting one RW1S bit must clear the other two; in `npcm_i2c_callback()`, `case I2C_MASTER_DONE_IND:` must fall through into `case I2C_BLOCK_BYTES_ERR_IND:`. [F61, F85]
- Access 8-bit registers in `i2c-npcm7xx.c` and `kcs_bmc_npcm7xx.c` (`NPCM_I2CCTL3`, `KCSnDO`) only with 8-bit accessors; pack/unpack 16-bit `NPCM_PSPI_DATA` transfers in big-endian order in `spi-npcm-pspi.c`; and in `npcm8xx_gpio_request_enable()`, use `mode = pincfg[pin[0]].fn0` instead of `fn_gpio` for pins 35, 36, and 183–189. [F74, F100, F125]
- Cast `parent_rate` to `u64` before `* fbdv` and use `do_div()` in `npcm*xx_clk_pll_recalc_rate()`; use `time_is_after_jiffies(time_left)` and divide `(2 * 9 * USEC_PER_SEC) / bus->bus_freq` before multiplying by `(2 + nread + nwrite)` in `npcm_i2c_master_xfer()`; use `unsigned long` for `for_each_set_bit()` in `npcm_sgpio_irq_handler()`/`npcmgpio_irq_handler()`; and format `ARRAY_SIZE()` with `%zu`. [F106, F113, F118, F119]
