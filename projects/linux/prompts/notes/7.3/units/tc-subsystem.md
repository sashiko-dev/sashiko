# TC subsystem

This unit implements the Traffic Control (TC) action framework (`net/sched/act_api.c`), packet actions (`act_ct`, `act_mirred`, `act_gate`, `act_csum`, `act_nat`, `act_mpls`, `act_ife`, `act_ctinfo`, `act_gact`), the generic packet scheduler core (`net/sched/sch_generic.c`), and queuing disciplines (`sch_htb`, `sch_hfsc`, `sch_qfq`, `sch_prio`, `sch_multiq`, `sch_mq`, `sch_mqprio`, `sch_ingress`, `sch_gred`, `sch_red`, `sch_pie`, `sch_hhf`, `sch_sfb`, `sch_sfq`, `sch_skbprio`).

## Architecture & Data Flow

- Concrete `struct tcf_*` actions must embed `struct tc_action common` at offset 0 (for `free_tcf()`/`to_<act>()` casts), per-netns structs registered via `tcf_register_action()` must embed `struct tc_action_net` at offset 0, and `struct sfq_slot` must keep `skblist_next` and `skblist_prev` as its first two members for `(struct sk_buff *)` casts. [F128, F130, F318]
- Actions created via `tcf_idr_create_from_flags()` have NULL `cpu_bstats`/`cpu_qstats` when `TCA_ACT_FLAGS_NO_PERCPU_STATS` is set; update stats via `tcf_action_update_bstats()`, `tcf_action_inc_drop_qstats()`, and `tcf_action_inc_overlimit_qstats()` instead of `this_cpu_ptr()`. [F53]
- `tp->chain->block->q` is NULL on shared filter blocks (`tcf_block_shared(block)`); `tcf_bind_filter()`, `tcf_unbind_filter()`, and `tcf_block_q()` callers must check `!tcf_block_shared(block)` or `q != NULL`. Also, `tcf_proto_update_usesw()` must run on every filter insertion so `tcf_block_bypass_sw()` does not skip software filters. [F55, F69]
- In `tcf_mirred_init()`, `tcfm_dev` and `tcfm_blockid` are mutually exclusive: setting `parm->ifindex` under `m->tcf_lock` must zero `m->tcfm_blockid` and update `m->tcfm_mac_header_xmit`, while setting `TCA_MIRRED_BLOCKID` must clear `m->tcfm_dev` via `tcf_mirred_replace_dev(m, NULL)` and set `m->tcfm_mac_header_xmit = false`. `mirred_device_event()` on `NETDEV_UNREGISTER` must only clear `m->tcfm_dev` and release `m->tcfm_dev_tracker` without touching `m->tcfm_blockid`. [F16, F60, F61]
- In `tcf_ct_flow_table_lookup()`, before `flow_offload_refresh()`, call `nf_conn_act_ct_ext_fill()` and `tcf_ct_flow_ct_ext_ifidx_update()`. When `IPS_ASSURED_BIT` is unset on `ct->status`, still call `flow_offload_refresh()` and return `false` so software conntrack can promote `ct`. [F64, F65]
- When a Qdisc `->change()` lowers `sch->limit`, excess packets must be drained with `qdisc_dequeue_internal()` and passed to `qdisc_tree_reduce_backlog()`. On `TCQ_F_CPUSTATS` Qdiscs (like `pfifo_fast_reset()`), `->reset()` must also zero `backlog` and `qlen` across all per-CPU `cpu_qstats`. [F247, F248]
- In `struct htb_class`, `cl->leaf` (`level == 0`) and `cl->inner` (`level > 0`) share a union: check `!cl->level` before accessing `cl->leaf`, erase `cl->pq_node` from `q->hlevel[old_level].wait_pq` and `memset` `inner` when transitioning levels, and in `htb_change_class_mode()` call `htb_deactivate_prios()` before updating `cl->cmode` and `htb_activate_prios()` after. [F240, F252, F255]
- Because child `dequeue()` can trigger `htb_qlen_notify()` -> `htb_deactivate()` (which must return early if `!cl->prio_activity`), `htb_lookup_leaf()` and `htb_dequeue_tree()` must handle `hprio->row.rb_node` becoming NULL mid-dequeue, `htb_dequeue_tree()` must update `start = next` if `cl == start` is deactivated, and rbtree removals in `htb_remove_class_from_row()`/`htb_deactivate_prios()` must update `hprio->ptr` (via `htb_next_rb_node()`, guarding against NULL `*n`) and `last_ptr_id`. [F207, F253, F254, F285]
- In `sch_hfsc`, callers of `qdisc_peek_len(cl->qdisc)` in `hfsc_change_class()` and `hfsc_dequeue()` must re-verify `cl->qdisc->q.qlen != 0` before calling `init_ed()`, `update_ed()`, `update_d()`, `init_vf()`, or `update_vf()`. Attaching a child class in `hfsc_change_class()` must upgrade any non-root parent lacking `HFSC_FSC` via `hfsc_upgrade_rt(parent)` under `sch_tree_lock(sch)`, and any `cf_tree` change in `init_vf()`/`update_vf()` must call `update_cfmin(cl->cl_parent)`. [F258, F259, F260]
- In `sch_qfq`, both `qfq_change_class()` and `qfq_enqueue()` (via `qfq_change_agg()`) must validate `lmax <= QFQ_MAX_LMAX` (and `>= QFQ_MIN_LMAX` in `qfq_change_class()`). Updating `agg->num_classes` or destroying `agg` in `qfq_update_agg()`/`qfq_destroy_agg()` must update `q->nonfull_aggs`, `agg->budgetmax`, `agg->inv_w`, `q->wsum`, and `q->iwsum` in lockstep and advance `q->in_serv_agg` via `qfq_choose_next_agg(q)` if it equals `agg`. [F261, F276]

## Synchronization

- All process-context acquisitions of `tc_action.tcfa_lock` (`tcf_lock`) must use `spin_lock_bh()`/`spin_unlock_bh()`. Updating an existing action's control action (`tcf_action_set_ctrlact()`) and RCU parameters (`rcu_replace_pointer()`) in `->init()` must hold `spin_lock_bh(&a->tcfa_lock)`, calling `tcf_chain_put_by_act()` only after unlocking. [F29, F151]
- `offload_act_setup` callbacks and helpers (`tcf_gate_get_list()`, `tcf_tunnel_info_copy()`, `to_ct_params()`, `tcf_tunnel_info()`, `tcf_police_rate_bytes_ps()`) run under `spin_lock_bh(&act->tcfa_lock)`: callers must hold `tcfa_lock`, and callees must not sleep, must use `GFP_ATOMIC`, and must not re-lock `tcfa_lock`. [F30, F154]
- Dropping the last `struct tc_action` reference outside `idrinfo->lock` in `__tcf_action_put()` must use `refcount_dec_and_mutex_lock(&p->tcfa_refcnt, &idrinfo->lock)`, paired with `refcount_inc_not_zero(&p->tcfa_refcnt)` and an `IS_ERR(p)` check during lockless RCU lookup in `tcf_idr_check_alloc()`. When `idrinfo->lock` is already held (`tcf_del_walker()`, `tcf_reoffload_del_notify()`), use `tcf_idr_release_unsafe()` instead of `tcf_idr_release()` or `__tcf_action_put()`. [F25, F160, F161]
- Process-context callers of `tcf_action_stats_update()` (`tcf_action_update_hw_stats()`, `tcf_exts_hw_stats_update()`) must wrap the call in `preempt_disable()`/`preempt_enable()`. Custom counters updated in lockless RCU-BH datapaths (such as `stats_dscp_set`/`stats_dscp_error`/`stats_cpmark_set` in `struct tcf_ctinfo`) must use `atomic64_t`. [F31, F38]
- Because child Qdiscs (e.g., `netem`) can re-enter parent `enqueue()` during `qdisc_enqueue()`, `hfsc_enqueue()` must check `!cl_in_el_or_vttree(cl)` and `qfq_enqueue()` must check `cl_is_active(cl)` after `qdisc_enqueue()` before activating `cl`. [F206]
- In `sch_direct_xmit()`, `qdisc_lock(q)` (`root_lock`) must be released before `validate_xmit_skb_list()` and `HARD_TX_LOCK()`, and re-acquired only after `HARD_TX_UNLOCK()` before `dev_requeue_skb()`. On `TCQ_F_NOLOCK` Qdiscs, `q->gso_skb` and `q->skb_bad_txq` accesses in `dequeue_skb()`, `dev_requeue_skb()`, `__skb_dequeue_bad_txq()`, and `qdisc_enqueue_skb_bad_txq()` must hold `qdisc_lock(q)` and re-check `skb_peek(&q->gso_skb)` after locking. [F210, F211]
- In `qdisc_maybe_clear_missed()`, clearing `__QDISC_STATE_MISSED` must be followed by `smp_mb__after_atomic()` and a re-check of `netif_xmit_frozen_or_stopped(txq)`. In `pfifo_fast_dequeue()`, if all bands appear empty while `READ_ONCE(qdisc->state) & QDISC_STATE_NON_EMPTY` is set, clear `__QDISC_STATE_MISSED`/`__QDISC_STATE_DRAINING`, issue `smp_mb__after_atomic()`, set `need_retry = false`, and retry once. [F212, F213, F293]
- Because `sch_tree_lock(sch)` disables BH and takes a spinlock, `GFP_KERNEL` allocations, `ndo_setup_tc`, and `qdisc_put()` (which calls sleeping `lockdep_unregister_key()` in `__qdisc_destroy()`) must run outside `sch_tree_lock(sch)`, whereas `qdisc_purge_queue()` (or `qdisc_replace()`) on detached child Qdiscs must run inside `sch_tree_lock(sch)` before unlocking and calling `qdisc_put()`. [F221, F223, F338]
- In `sch_qfq.c`, because `qfq_enqueue()` can replace `cl->agg` in softirq via `qfq_change_agg()` (which must use `GFP_ATOMIC`), all control/dump accesses to `cl->agg` in `qfq_change_class()`, `qfq_delete_class()`, `qfq_dump_class()`, and `qfq_dump_class_stats()` must hold `sch_tree_lock(sch)`. [F222, F340]

## Object Lifetimes

- When `tcf_idr_check_alloc()` returns 0, it inserts an `ERR_PTR(-EBUSY)` placeholder at `*index`; the caller must either complete `tcf_idr_create()` or remove it with `tcf_idr_cleanup()`. Once `tcf_idr_check_alloc()` returns 1 or `tcf_idr_create()` succeeds, any subsequent `->init()` error must roll back via `tcf_idr_release(*a, bind)` after initializing all fields torn down by `ops->cleanup` (`hitimer`/`entries` in `tcf_gate_init()`, `tcfm_list` in `tcf_mirred_init()`, `metalist` in `tcf_ife_init()`). [F1, F2, F47]
- `tcf_action_check_ctrlact()` acquires `*newchain` on `TC_ACT_GOTO_CHAIN` and `tcf_action_set_ctrlact()` returns the old `a->goto_chain`; pass a NULL-initialized pointer and release any non-NULL chain via `tcf_chain_put_by_act()` after swap or on error. [F3]
- `tcf_action_init()` must call `module_put(ops[i]->owner)` for every `tc_action_ops` loaded by `tc_action_load_ops()` on both success and failure, complete `tcf_action_offload_add()` before `tcf_idr_insert_many()` (which skips `ACT_P_BOUND`), and `tcf_action_add()` must call `tca_put_bound_many()` (skipping `ACT_P_CREATED`) to drop the extra ref on bound/replaced actions. `tcf_action_destroy()` and `tcf_action_delete()` must set `actions[i] = NULL` as each slot is released. [F5, F6, F75, F143]
- In `tcf_ct_act()`, if `tcf_ct_handle_fragments()` returns non-zero or a netfilter hook returns `NF_STOLEN` (`(err & NF_VERDICT_MASK) == NF_STOLEN`), return `TC_ACT_CONSUMED` (not `TC_ACT_SHOT`). After `nf_conntrack_confirm(skb)`, `ct` must be re-read via `nf_ct_get(skb, &ctinfo)` before `tcf_ct_flow_table_process_conn()`. [F9, F52, F177]
- `flowtable_ct` must provide `.get` (`tcf_ct_nf_get`) and `.put` (`tcf_ct_nf_put`) callbacks, `tcf_ct_flow_table_get()` must use `refcount_inc_not_zero(&ct_ft->ref)`, and `tcf_ct_flow_table_put()` must defer `nf_flow_table_free()` and `kfree(ct_ft)` via `queue_rcu_work(act_ct_wq, &ct_ft->rwork)`. [F11, F163]
- In `tcf_ctinfo_act()`, `nf_ct_get()` returns a borrowed pointer whereas `nf_conntrack_find_get()` returns a reference in `thash`; call `nf_ct_put(ct)` on exit if and only if `thash != NULL`. [F14]
- `tcf_action_cleanup()` must call `tcf_action_offload_del(p)` before `p->ops->cleanup(p)` and `free_tcf(p)`. When `offload_act_setup` (`bind == true`) allocates memory or takes a device ref for a `flow_action_entry`, it must set `entry->destructor` and `entry->destructor_priv`, and callers of `tc_setup_action()` must call `tc_cleanup_offload_action()`. [F142, F144]
- In HTB offload (`q->offload`), a leaf's child Qdisc is referenced by both `cl->leaf.q` and `dev_queue->qdisc_sleeping`, so `htb_graft()`, `htb_parent_to_leaf_offload()`, and `htb_change_class()` must call `qdisc_refcount_inc()` before `htb_graft_helper()`. In `sch_hfsc`, `q->root` is embedded in `struct hfsc_sched`, so `hfsc_destroy_class()` must guard `kfree(cl)` with `cl != &q->root` and `hfsc_delete_class()` must reject `cl == &q->root`. [F196, F321]
- In classful Qdisc `.destroy()` callbacks (`htb_destroy`, `hfsc_destroy_qdisc`, `qfq_destroy_qdisc`), all `tcf_block_put()` calls on the Qdisc and classes must complete before any class struct is freed, and any work or timers (`htb_destroy`, `pie_destroy`, `red_destroy`, `sfq_destroy`) must be synchronously canceled (`cancel_work_sync()`, `qdisc_watchdog_cancel()`, `timer_delete_sync()` after zeroing `tupdate`/`perturb_period`) before freeing private data or child Qdiscs. [F346, F372]

## API Contracts

- `tc_action_ops->init` must validate `parm->action` via `tcf_action_check_ctrlact()`, immediately return `ACT_P_BOUND` (`0`) without mutating parameters or `goto_chain` when `tcf_idr_check_alloc()` finds an existing action (`err > 0`) and `TCA_ACT_FLAGS_BIND` is set, and return `ACT_P_CREATED` (`1`) for new allocations or `ACT_P_BOUND` (`0`) when replacing. In `tcf_action_init()`, binding to a standalone action (`!tc_act_bind(act->tcfa_flags)`) must never mutate `act->tcfa_flags`. [F43, F73, F74, F86]
- `tc_action_ops.act` callbacks and `tcf_action_exec()` run in softirq under `rcu_read_lock_bh()`: dereference RCU pointers (`goto_chain`, `params`, `tcfm_dev`) with `rcu_dereference_bh()`, allocate with `GFP_ATOMIC`, and transmit packets that may have been defragmented by `act_ct` via `tcf_dev_queue_xmit()`. [F152, F172]
- `tc_action_ops.offload_act_setup` must check `bind` before casting `entry_data` (`struct flow_action_entry *` with non-NULL `index_inc` when `bind == true`; `struct flow_offload_action *` with NULL `index_inc` when `bind == false`), and must reject software-only features (e.g., `tcf_ct_helper(act)`, MPLS `DEC_TTL`/`MAC_PUSH`, gact `continue`/`reclassify`/`pipe`) with `-EOPNOTSUPP`. [F131, F146]
- `qdisc_create_dflt()` and `__qdisc_destroy()` must use `bpf_try_module_get(ops, ops->owner)` and `bpf_module_put(ops, ops->owner)`. `qdisc_create_dflt()` returns `NULL` on failure (in which case classful leaf Qdisc setup must fall back to `&noop_qdisc` and skip `qdisc_hash_add()`), whereas `qdisc_alloc()` and `fifo_create_dflt()` return `ERR_PTR`. [F191, F229, F242]
- Parent Qdiscs that inspect a child with `peek()` or `qdisc_peek_len()` (`prio_dequeue`, `hfsc_dequeue`, `agg_dequeue` in `sch_qfq.c`) must dequeue via `qdisc_dequeue_peeked(child)`. Dequeue helpers building SKB chains (`try_bulk_dequeue_skb`, `try_bulk_dequeue_skb_slow`, `dequeue_head` in `sch_hhf.c`) must call `skb_mark_not_on_list()` on the tail SKB, and `dequeue_skb()` must check for `SKB_XOFF_MAGIC` from `qdisc_dequeue_skb_bad_txq()`. [F230, F355, F362]

## Error Handling

- Because `qdisc_create()` and `__qdisc_destroy()` invoke `ops->reset()` and `ops->destroy()` even when `ops->init()` fails partway, `htb_init()` and `hfsc_init_qdisc()` must initialize `qdisc_watchdog_init()` (and `INIT_WORK()` in HTB) before any fallible step, `htb_init()` must set `q->offload = true` only after `htb_offload()` (`TC_HTB_CREATE`) and all fallible init succeed, and `gred_destroy()`, `pfifo_fast_reset()`, `pfifo_fast_destroy()`, and `hhf_destroy()` must null-check dynamically allocated pointers. [F225, F234, F331]
- On failure in `tcf_ct_fill_params()` after allocating `p->tmpl`, call `nf_connlabels_put(net)` (if `put_labels`), `nf_ct_put(p->tmpl)`, and set `p->tmpl = NULL` so `tcf_ct_params_free()` does not double-put. In `tcf_ct_flow_table_fill_actions()`, if `tcf_ct_flow_table_add_action_nat()` fails, zero the newly added `action->entries` and restore `action->num_entries`. [F12, F114]

## Known Pitfalls

- Any lookup or iteration over `idrinfo->action_idr` (`tcf_idr_search()`, `tcf_dump_walker()`, `tcf_del_walker()`, `tcf_action_reoffload_cb()`) must check `IS_ERR(p)` before dereferencing `p` because in-flight allocations store `ERR_PTR(-EBUSY)` (and `tcf_idr_check_alloc()` must return `-EAGAIN` immediately on `IS_ERR(p)`). In `tcf_action_delete()`, save `a->ops`, `a->idrinfo`, and `a->tcfa_index` into locals before `tcf_action_put(a)`. [F44, F72, F103]
- Packet-inspecting/mangling actions (`tcf_csum_*`, `tcf_ct_flow_table_fill_tuple_ipv4/ipv6`, `tcf_nat_act`) must re-fetch `skb_network_header(skb)`, `ip_hdr(skb)`, or `ipv6_hdr(skb)` after every `pskb_may_pull()`, `pskb_network_may_pull()`, `skb_try_make_writable()`, or `tcf_csum_skb_nextlayer()` call, and `tcf_csum_ipv4()`/`tcf_nat_act()` must check `iph->frag_off & htons(IP_OFFSET)` before inspecting L4 headers. [F120, F136]
- In `act_ct.c`, `zones_params.key_len` must be `offsetofend(struct zones_ht_key, zone)` (covering both `net` and `zone` without trailing alignment padding), `tcf_ct_flow_table_restore_skb()` must mask `cookie` with `NFCT_PTRMASK` before casting to `struct nf_conn *`, and `tcf_ct_fill_params()` must verify `TCA_CT_HELPER_NAME` is NUL-terminated (`name[len - 1] == '\0'`) and `<= NF_CT_HELPER_NAME_LEN`. [F49, F137, F138, F174]
