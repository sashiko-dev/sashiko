# COMPUTE EXPRESS LINK (CXL)

The CXL subsystem implements core infrastructure and drivers for PCIe Type-3 memory expanders (`cxl_pci`), memory devices (`cxl_mem`), port topologies (`cxl_port`), libnvdimm persistent memory (`cxl_pmem`), register mapping (`core/regs.c`), and Host-managed Device Memory (HDM) region management (`core/region.c`). It coordinates HDM decoder programming across root, switch, and endpoint ports, handles device mailbox commands, event logs, and poison lists, and exposes DAX and PMEM regions.

## Architecture & Data Flow
- Optional mapped register pointers (`cxlds->regs.ras`, `dport->regs.rcd_pcie_cap`) and an endpoint decoder's region pointer (`cxled->cxld.region` or `cxl_dpa_to_region()`, even when `cxled->dpa_res` is valid) can be `NULL` and must be checked before dereferencing or MMIO access. [F49, F50]
- In `cxl_region_setup_targets()`, `cxl_region_teardown_targets()`, and `cxl_region_decode_reset()`, when `cxlds->rcd` is true (RCH topology), there are no intermediate switch/host-bridge `cxl_port` levels with `cxl_ep` or `cxl_region_ref` entries between the endpoint and root ports, so walking intermediate ports must be skipped. [F52]
- In `cxl_port_setup_targets()`, when `cxl_rr->nr_targets_set` is non-zero, peer `distance` must be computed by multiplying `cxl_rr_iter->nr_targets` across all ancestor `cxl_port` levels up to the root and then by `cxlrd->cxlsd.cxld.interleave_ways`; `check_last_peer()` must reject `pos < distance` with `-ENXIO` before indexing `p->targets[pos - distance]`. [F67, F92]
- In `cxl_port_setup_targets()`, when `is_cxl_root(parent_port)` is true, `parent_ig` must come from `p->interleave_granularity` (not `cxlrd` or `cxl_rr_load()`), and if `parent_iw` is 3, 6, or 12, it must be divided by 3 before computing `parent_ig * parent_iw` for `granularity_to_eig()`. [F102, F123]
- In `cxl_port_reset_targets()` and `__cxl_decoder_detach()`, `cxl_rr->nr_targets_set` must be reset to `0` and `cxld->hpa_range` to `{ .start = 0, .end = -1 }` alongside clearing `p->targets[cxled->pos]` and decrementing `p->nr_targets`. In `cxl_region_sort_targets()`, every `cxled->pos` must be computed before `sort()` even if an earlier `cxl_calc_interleave_pos()` failed. [F68, F69]
- In `cxl_port_pick_region_decoder()`, if `port == cxled_to_port(cxled)` it must return `&cxled->cxld` directly; otherwise it dispatches to `match_auto_decoder` when `CXL_REGION_F_AUTO` is set or `match_free_decoder` when manual. [F104]
- When `cxl_extended_linear_cache_resize()` shifts `res->start` down by `cxlrd->cache_size`, it must set `p->cache_size = cache_size` so range matching and HPA/DPA helpers offset by `p->cache_size`. In `size_store()`, `free_hpa()` must clear `p->res` and set `p->state = CXL_CONFIG_IDLE` before `alloc_hpa()` allocates a new `p->res`. Updating `p->interleave_ways` requires `sysfs_update_group()` on `get_cxl_region_target_group()` (rolling back `p->interleave_ways` on failure). [F61, F64, F71]
- Downstream-port-specific state (`dport->gpf_dvsec`, `dport->rcrb`, `dport->regs.rcd_pcie_cap`) belongs on `struct cxl_dport`, not `struct cxl_port`, and `cxl_switch_port_probe()` must reset `port->nr_dports = 0` so driver rebind does not accumulate dport counts. [F72, F75]
- In `drivers/cxl/cxlpci.h`, `cdat_header`, `cdat_entry_header`, `cdat_data`, and `cdat_doe_rsp` must remain `__packed` with `__le32`/`__le16` fields; in packed CXL event structs, `u8[3]` fields must be read with `get_unaligned_le24()` and `u8[2]`/`u8[4]` with `get_unaligned_le16()`/`le32()`. [F95, F96]

## Synchronization
- Reading or modifying a live `struct cxl_region`'s `params`, `port->regions` xarray, or `cxlsd->target[]` outside driver-bound callbacks or post-`device_del()` teardown requires holding `cxl_rwsem.region`. When acquiring both `cxl_rwsem.region` and `cxl_rwsem.dpa` (both required for `region_offset_to_dpa_result()`), acquire `cxl_rwsem.region` first. [F28, F166]
- Any path lowering `cxlr->params.state` below `CXL_CONFIG_COMMIT` (`commit_store()`, `cxl_decoder_detach()`) must call `device_release_driver(&cxlr->dev)` (and `device_attach()`) outside `cxl_rwsem.region`: `__cxl_decoder_detach()` must pin `cxlr->dev` with `get_device()` under `cxl_rwsem.region`, and `commit_store()` must set `p->state = CXL_CONFIG_RESET_PENDING` before dropping the lock and revalidate `p->state == CXL_CONFIG_RESET_PENDING` after re-locking before `cxl_region_decode_reset()`. [F25, F26, F62]
- Allocation and recycling of `cxlrd->region_id` in `__create_region()` and `cxl_region_release()` must use `atomic_cmpxchg()` / `atomic_try_cmpxchg()`, freeing the displaced `id` rather than `cxlr->id` on recycle. [F42]
- `cxl_pci_setup_mailbox()` must clamp `cxl_mbox->payload_size` to `SZ_1M` (rejecting `< 256` with `-ENXIO`), wait for `CXLMDEV_MBOX_IF_READY` and `cxl_pci_mbox_wait_for_doorbell()`, and initialize `mds->security.poll_dwork` before requesting `cxl_pci_mbox_irq`. `cxl_pci_mbox_irq()` must wake `cxl_mbox->mbox_wait` via `rcuwait_wake_up()` without acquiring `cxl_mbox->mbox_mutex`. [F31, F83, F164]
- `cxl_event_config()` must allocate `mds->event.buf` via `cxl_mem_alloc_event_buf()` before `cxl_event_irqsetup()` or `cxl_mem_get_event_records()`, and only when `host_bridge->native_cxl_error` is true and `!cxl_event_int_is_fw()`. `cxl_event_thread()` must mask `CXLDEV_DEV_EVENT_STATUS_OFFSET` with `CXLDEV_EVENT_STATUS_ALL` on every iteration. [F32, F110, F144]
- `cxl_nvdimm_probe()` must pass `NDD_REGISTER_SYNC` to `__nvdimm_create()`. In `unregister_nvdimm_bus()`, `detach_nvdimm()` must check `dev->driver` and `cxl_nvd->cxlmd->cxl_nvb == data` under `device_lock(dev)`, drop the lock before `device_release_driver(dev)`, and detach all matching `cxl_nvdimm` devices before `nvdimm_bus_unregister()`. [F35, F36]
- In `rcd_pcie_cap_emit()`, reading `dport->regs.rcd_pcie_cap` requires pinning the root port via `cxl_mem_find_port()` and holding `device_lock(root->uport_dev)` while verifying `root_dev->driver != NULL`. [F162]

## Object Lifetimes
- `cxl_port_find_switch_decoder()` and `cxl_find_root_decoder()` return a reference-counted decoder requiring `put_device()`, whereas `cxl_port_pick_region_decoder()` drops its `device_find_child()` reference immediately and returns a borrowed pointer pinned by `cxl_rwsem.region`. [F7]
- In `cxl_port_attach_region()` and `cxl_port_detach_region()`, `cxl_rr->nr_eps`, `cxl_rr->nr_targets`, `cxl_rr->endpoints`, and `cxld->region` must stay in lockstep: `cxl_rr_ep_add()` takes `get_device(&cxlr->dev)` when setting `cxld->region = cxlr`, and when `cxl_rr->nr_eps` hits `0`, `free_region_ref()` must call `cxl_rr_free_decoder()` to clear `cxld->region = NULL` and call `put_device(&cxlr->dev)`. [F8, F70]
- `cxl_region_iomem_release()` must check `if (p->res->parent)` before `remove_resource(p->res)` and set `p->res = NULL` after `kfree(p->res)`. In `cxl_pmem_region_probe()`, `devm_add_action_or_reset(dev, cxlr_pmem_remove_resource, res)` must be registered immediately after `insert_resource()` so `remove_resource(res)` runs before `devm_kzalloc()` frees `res`. [F6, F18]
- On `commit_decoder()` failure at `iter` on target `i`, `cxl_region_decode_commit()` must reset target `i`'s committed decoders top-down from `iter` to `cxled` guarding the loop with `ep && iter` before `iter = ep->next`, then call `cxl_region_decode_reset(cxlr, i)`. `cxl_region_decode_reset()` must loop `for (i = count - 1; i >= 0; i--)` with signed `i` without aborting on `cxl_region_invalidate_memregion()` failure, keeping `CXL_REGION_F_NEEDS_RESET` set until all decoders are reset. [F11, F12, F65, F94, F106]
- In `cxl_mem_probe()`, `devm_cxl_add_nvdimm()` must precede `devm_cxl_add_endpoint()`, and `cxl_mem_active_inc()` must only be called after all fallible steps succeed right before `devm_add_action_or_reset(dev, enable_suspend, NULL)`. `cxl_port_driver` must use `subsys_initcall(cxl_port_init)` with `MODULE_SOFTDEP("pre: cxl_port")` in `drivers/cxl/mem.c`. [F15, F140, F141]
- In `cxl_endpoint_port_probe()`, `get_device(&cxlmd->dev)` must precede `devm_add_action_or_reset(&port->dev, schedule_detach, cxlmd)` because `detach_memdev` consumes that reference via `put_device(&cxlmd->dev)`. [F16]
- `cxl_setup_regs()` must unconditionally call `cxl_unmap_regblock(map)` before returning. `cxl_rcrb_to_aer()`, `cxl_rcrb_to_linkcap()`, and `__rcrb_to_component()` must always `iounmap()` and `release_mem_region(rcrb, SZ_4K)` (including on `ioremap()` failure) and stop capability walks when `offset == 0` (or `offset > SZ_4K` in `cxl_rcrb_to_linkcap()`). [F19, F20, F93]

## API Contracts
- Callers of `to_cxl_memdev_state(cxlds)` on generic `cxl_memdev` paths must check for `NULL` (`cxlds->type != CXL_DEVTYPE_CLASSMEM`). Device iteration callbacks must check `is_cxl_region()`, `is_endpoint_decoder()`, `is_switch_decoder()`, or `is_cxl_nvdimm()` before `to_cxl_*()`, and `to_cxl_root(port)` requires `is_cxl_root(port)`. [F131, F132, F133]
- `__cxl_pci_mbox_send_cmd()` requires holding `cxl_mbox->mbox_mutex`, verifying `!cxl_doorbell_busy(cxlds)`, writing `CXLDEV_MBOX_CMD_OFFSET` and `payload_in` before setting `CXLDEV_MBOX_CTRL_DOORBELL`, waiting for `cxl_pci_mbox_wait_for_doorbell()` before reading status/output, and clamping output `memcpy_fromio()` to `min3(mbox_cmd->size_out, cxl_mbox->payload_size, out_len)`. [F128, F148]
- `cxl_count_regblock()` returns a negative errno or non-negative count (store in signed `int` and check `< 0`). `cxl_rcd_component_reg_phys()`, `__rcrb_to_component()`, and `cxl_rcrb_to_linkcap()` return `CXL_RESOURCE_NONE` (`(resource_size_t)-1`) on failure (`__rcrb_to_component()` validates `id != U32_MAX`, 64-bit memory BAR bits, non-zero address, and `SZ_64K` alignment without requiring `PCI_COMMAND_MEMORY`). [F45, F46, F87, F142]
- `cxl_region_attach()` requires `pos < 0` when `CXL_REGION_F_AUTO` is set and `0 .. p->interleave_ways - 1` when manual. Target setup (`cxl_port_attach_region()`, `cxl_region_attach()`, `cxl_port_setup_targets()`) must check `cxl_rr->nr_targets <= cxlsd->nr_targets`, power-of-two switch `iw <= 8`, and `check_interleave_cap()`. `__commit()` and `cxl_region_decode_reset()` must flush caches via `cxl_region_invalidate_memregion()`. [F60, F85, F158, F160]
- `discover_region()` must always return `0` so one failing decoder does not abort port discovery. In `poison_by_decoder()` and `cxl_get_poison_unmapped()`, `-EFAULT` from `cxl_mem_get_poison()` for `CXL_PARTMODE_RAM` must be cleared, and `poison_by_decoder()` must return `1` at `ctx->port->commit_end`. [F113, F114]
- Bitmaps for `set_exclusive_cxl_commands()` / `clear_exclusive_cxl_commands()` must use `DECLARE_BITMAP(..., CXL_MEM_COMMAND_ID_MAX)`, and `cxl_nvdimm_probe()` must mark `SET_SHUTDOWN_STATE` and `SET_LSA` exclusive before `__nvdimm_create()`. `cxl_pmem_get_security_flags()` must return `0` on error or set `NVDIMM_SECURITY_*` bit indices. [F137, F174, F177]

## Error Handling
- In `__cxl_pci_mbox_send_cmd()`, a non-zero `mbox_cmd->return_code` still returns `0`, so callers of `cxl_mbox->mbox_send` must check both the return value and `mbox_cmd->return_code == CXL_MBOX_CMD_RC_SUCCESS` (or use `cxl_internal_send_cmd()`), and log doorbell busy/timeout errors with ratelimited `cxl_cmd_err()`. [F44, F185]
- `cxl_find_region_by_name()` and `construct_region()` return `ERR_PTR()` on failure, whereas `cxl_find_region_by_range()` and `__cxl_decoder_detach()` return `NULL`. [F48]
- In `cxl_pci_probe()`, `cxl_mem_probe()`, and `cxl_region_probe()`, missing component/RAS registers or non-fatal helper failures (`cxl_pci_ras_unmask()`, `devm_cxl_setup_features()`, `devm_cxl_setup_fwctl()`, `devm_cxl_memdev_edac_register()`) must not fail probe or leave non-zero `rc`, whereas missing `status`, `mbox`, or `memdev` regs fail `cxl_probe_regs()` with `-ENXIO`. `cxl_probe_component_regs()` and `cxl_probe_device_regs()` must zero `*map` at entry and loop `for (cap = 1; cap <= cap_count; cap++)` resetting `rmap = NULL`. [F54, F56, F109, F152]

## External Contracts
- `cxl_pmem_ctl()` must initialize `*cmd_rc = 0` and return `-ENOTTY` when `!nvdimm` or `cmd` is not in `nvdimm_cmd_mask(nvdimm)`; `cxl_pmem_get_config_data()` must set `cmd->status = 0` and `cxl_pmem_set_config_data()` must write a 4-byte `0` status at `&cmd->in_buf[cmd->in_length]`. [F57, F176]
- New entries in `CXL_CMDS` (`include/uapi/linux/cxl_mem.h`) must only be added immediately before `___C(MAX, ...)`. `cxl_region_visible()` must keep `dev_attr_uuid` `0444` when `cxlr->mode != CXL_PARTMODE_PMEM`, with `uuid_show()` emitting `"\n"`. [F77, F98]

## Known Pitfalls
- CXL bitmap flags (`CXL_FW_CANCEL`, `CXL_REGION_F_AUTO`, `CXL_REGION_F_NEEDS_RESET`, `*_cmd_enabled_bits`) are unshifted bit indices (`0, 1, ...`), whereas `cxl_map_component_regs()` takes `BIT(CXL_CM_CAP_CAP_ID_*)`. In `check_interleave_cap()`, `eiw == 0 || eiw == 8` must return `0` before `GENMASK(high_pos, low_pos)` and multi-bit support must check `interleave_mask & ~cxlhdm->interleave_mask`. [F59, F101]
- For 32-bit safety: use `GENMASK_ULL()` or `~((u64)GENMASK(...))` on 64-bit DPA/HPA masks (`CXL_DPA_MASK`, `CXL_POISON_START_MASK`, `region_offset_to_dpa_result()`, `cxl_dpa_to_hpa()`), cast `reg_hi`/`bar1` to `u64` before `<< 32`, and use `do_div()`/`div64_u64_rem()`/`div64_u64()` for 64-bit divisions in `region.c`. [F118, F119, F120, F124]
- In `__cxl_find_regblock_instance()`, `cxl_decode_regblock()` mutates `map` on every iteration, so `map->resource = CXL_RESOURCE_NONE` must be restored if the loop finishes without a match. [F108]
- Mailbox polling loops must compare jiffies with `time_after()` and re-check `!cxl_doorbell_busy(cxlds)` or `cxl_mbox_background_complete(cxlds)` one final time after timeout before returning `-ETIMEDOUT`. Every `devm_request_threaded_irq()` call in `cxl_request_irq()` must allocate a distinct `struct cxl_dev_id` cookie as `dev_id`. [F111, F125, F145]
- Format `resource_size_t` values with `%pa`/`%pap` and `&var` (or cast to `u64` for `%#llx`), and format 16-byte `mds->firmware_version` and FW slot revision arrays with `%.16s`. [F127, F135]
