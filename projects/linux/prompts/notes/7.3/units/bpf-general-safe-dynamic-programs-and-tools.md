# BPF [GENERAL] (Safe Dynamic Programs and Tools)

This unit implements core and networking BPF infrastructure, including the NMI-safe per-CPU memory allocator (`memalloc.c`), resilient queued spinlocks (`rqspinlock.c`), tracing/probe links and helpers (`bpf_trace.c`), hardware offload (`offload.c`), netns links, tokens, task/VMA iterators, classic-to-eBPF filter conversion, XDP/TC/socket helpers (`net/core/filter.c`), and `BPF_PROG_TEST_RUN` (`net/bpf/test_run.c`).

## Architecture & Data Flow

- In `kernel/bpf/memalloc.c`, non-percpu allocations reserve an `LLIST_NODE_SZ` (8-byte) header inside `unit_size` for `struct bpf_mem_cache *`, whereas percpu allocations use a two-pointer header (`LLIST_NODE_SZ + sizeof(void *)`) without adding `LLIST_NODE_SZ` to `size`; callers always receive `ptr + LLIST_NODE_SZ`. When `__llist_add()` adds to an empty `c->free_by_rcu`, `c->free_by_rcu_tail` must be updated and copied to `c->waiting_for_gp_tail` when moving to `waiting_for_gp`. [F63, F80, F133, F134]
- In `kernel/bpf/offload.c`, device-bound-only (`BPF_F_XDP_DEV_BOUND_ONLY`) `offdevs` entries have `ondev->offdev == NULL`, so `offload->offdev->ops` may only be accessed when `bpf_prog_is_offloaded(prog->aux)` holds. In `__bpf_offload_dev_netdev_unregister()`, migrating `ondev->progs` and `ondev->maps` to `altdev` must update every element's `netdev` pointer to `altdev->netdev` and use `list_splice_init()`, while `!altdev` destruction must use `list_for_each_entry_safe()`. [F48, F67, F111]
- `bpf_kprobe_multi_link_attach()` and `bpf_uprobe_multi_link_attach()` must reject `sizeof(u64) != sizeof(void *)` while address/offset arrays use `unsigned long`, and `bpf_kprobe_multi_link_attach()` must co-sort `cookies[]` with `us.syms[]` (`symbols_swap_r`) and then with `link->addrs[]` (`bpf_kprobe_multi_cookie_swap`) before `register_fprobe_ips()`. Helpers and kfuncs downcasting `current->bpf_ctx` (`bpf_kprobe_multi_run_ctx`, `bpf_uprobe_multi_run_ctx`, `bpf_session_run_ctx`) must only be exposed to `expected_attach_type` values guaranteeing that exact `run_ctx`. [F72, F128, F142]
- In `net/core/filter.c`, every networking `is_valid_access` callback must reject `off % size != 0`, and `bpf_skb_is_valid_access()`, `xdp_is_valid_access()`, and `flow_dissector_is_valid_access()` must reject `info->is_ldsx` on 32-bit UAPI packet pointers (`data`, `data_end`, `data_meta`). Validators with permissive defaults (`bpf_skb`, `sock_ops`, `bpf_sock`) must match 64-bit fields with `bpf_ctx_range*()` and reject padding ranges, whereas strict validators (`sock_addr`, `sk_msg`, `flow_dissector`, `sk_reuseport`, `sk_lookup`) must return `false` in `default`. [F278, F301, F302, F303, F315]
- Every `struct sk_buff` helper that reallocates, linearizes, or shifts `skb->data` or `skb->len` must call `bpf_compute_data_pointers(skb)`, and packet-writing helpers must refresh pointers into `skb->data` (including `srh_state->srh`) after making `skb` writable or pushing/popping headers. In `bpf_skb_net_grow()`/`shrink()`, `encap` inner header offsets must be sampled before `bpf_skb_net_hdr_push()`, and GSO adjustments must set `SKB_GSO_DODGY`, reset `gso_segs = 0`, and update `gso_size` unless `BPF_F_ADJ_ROOM_FIXED_GSO` is set. [F257, F264, F265, F328]
- Every `struct sk_msg` helper that mutates scatterlist entries (`bpf_msg_pull_data()`, `bpf_msg_push_data()`, `bpf_msg_pop_data()`) must call `sk_msg_reset_curr(msg)` (setting `curr = end - 1` and `copybreak = length` when `msg->sg.size > 0`) and recompute `msg->data` and `msg->data_end`. In `bpf_msg_push_data()`, when `start == offset + l` leaves `i == msg->sg.end`, `i` must be stepped back with `sk_msg_iter_var_prev(i)` before indexing `sk_msg_elem(msg, i)`. [F258, F259, F280]
- `bpf_xdp_adjust_head()` and `bpf_xdp_adjust_meta()` must keep `xdp->data_meta >= xdp->data_hard_start + sizeof(struct xdp_frame)`, `xdp->data` within `[xdp_frame_end + metalen, xdp->data_end - ETH_HLEN]`, and `!xdp_metalen_invalid(metalen)`. When `bpf_xdp_frags_increase_tail()` or `bpf_xdp_shrink_data()` adjusts or frees a fragment on `MEM_TYPE_XSK_BUFF_POOL`, it must update the companion AF_XDP `xdp_buff` node (`xsk_buff_get_tail`/`xsk_buff_get_head`). [F268, F289]
- In `bpf_check_classic()` and `bpf_convert_filter()`, classic BPF validation must check `k != 0` on immediate `DIV`/`MOD`, `k < 32` on shifts, `k < BPF_MEMWORDS` (`<= 16`) before `check_load_and_stores()` (which resets `memvalid = ~0` after jumps), forward jumps `< flen`, and a final `BPF_RET`. `bpf_convert_filter()` keeps `CTX` in `R6` (`skb->data` in `R8`, headlen in `R9`), guards `BPF_X` `DIV`/`MOD` against 0, zero-extends negative `BPF_JMP | BPF_K` immediates via `BPF_REG_TMP`, checks `s16` bounds on `insn->off`, and must emit identical instruction counts across passes. [F285, F286, F307, F308, F316, F317, F318, F319, F320, F357]

## Synchronization

- In `kernel/bpf/memalloc.c`, runtime allocator functions (`bpf_mem_alloc()`, `bpf_mem_free()`, `bpf_mem_cache_*()`, `unit_alloc()`, `unit_free*()`, `irq_work_raise()`) must be `notrace` and require migration disabled. In `unit_alloc()` and `unit_free*()`, non-atomic `__llist_del_first()`/`__llist_add()` on `free_llist`/`free_by_rcu` may only run with IRQs disabled when `local_inc_return(&c->active) == 1` (using atomic `llist_add()` on `free_llist_extra*` otherwise), and `local_irq_restore(flags)` must follow `irq_work_raise(c)` (with `inc_active()`/`dec_active()` saving IRQs on `PREEMPT_RT`). [F153, F154, F155, F156, F158]
- In `resilient_queued_spin_lock_slowpath()`, `barrier()` must separate `node->count++` from initializing `node->locked = 0` and `node->next = NULL`, and `smp_wmb()` must precede `xchg_tail(lock, tail)`. On contention after `queued_fetch_set_pending_acquire()`, `clear_pending(lock)` runs only when `!(val & _Q_PENDING_MASK)`; on timeout, a pending waiter must call `clear_pending(lock)`, and an MCS waiter at `waitq_timeout` must either reset tail via `try_cmpxchg_tail(lock, tail, 0)` or set `WRITE_ONCE(next->locked, RES_TIMEOUT_VAL)` before decrementing `mcs.count`. [F35, F36, F101]
- Whenever `task_vma_seq_get_next()` or `task_vma_seq_stop()` drops `mmap_lock`, it must save `prev_vm_start` and `prev_vm_end` (setting `prev_vm_start = ~0UL` in `task_vma_seq_stop()` when `v != NULL`) and re-lookup the VMA via `find_vma(curr_mm, info->prev_vm_end - 1)` after relocking. [F28]
- In `kernel/bpf/net_namespace.c`, under `netns_bpf_mutex`, `net->bpf.progs[type]` and `net->bpf.links[type]` are mutually exclusive, and `struct bpf_netns_link::net` is an unreferenced pointer that link callbacks must check for non-NULL (and `check_net(net)`) under `netns_bpf_mutex`. In `kernel/bpf/reuseport_array.c`, `spin_lock_bh(&reuseport_lock)` must precede `write_lock_bh(&sk->sk_callback_lock)`, `bpf_fd_reuseport_array_update_elem()` must re-run `reuseport_array_update_check()` under both locks, and `bpf_sk_reuseport_detach()` must clear `sk_user_data` and `*socks` under `sk->sk_callback_lock`. [F30, F32, F164, F165, F190]
- In `kernel/trace/bpf_trace.c`, `perf_event_attach_bpf_prog()`, `perf_event_detach_bpf_prog()`, and `perf_event_query_prog_array()` must hold `bpf_event_mutex` when accessing `event->prog` and `event->tp_event->prog_array`, and `perf_event_detach_bpf_prog()` must call `synchronize_rcu_tasks_trace()` after unlocking before `bpf_prog_put(prog)`. [F40]
- In `bpf_send_signal_common()`, after verifying `!(task->flags & (PF_KTHREAD | PF_EXITING))`, `nmi_uaccess_okay()`, and `!is_global_init(task)`, signal delivery must defer to per-CPU `send_signal_work` whenever `preempt_count() != 0 || irqs_disabled()` (checking `irq_work_is_busy()` and pinning `work->task = get_task_struct(task)`). `bpf_probe_write_user()` must reject `in_interrupt()`, `PF_KTHREAD | PF_EXITING`, or `!nmi_uaccess_okay()` with `-EPERM` and use `copy_to_user_nofault()`. [F39, F170, F171]
- In `kernel/trace/bpf_trace.c`, raw tracepoint helpers (`bpf_perf_event_output_raw_tp`, `bpf_get_stack*_raw_tp`) must use `get_bpf_raw_tp_regs()`/`put_bpf_raw_tp_regs()` instead of `bpf_pt_regs`; non-sleepable dynptr user-read kfuncs (`bpf_probe_read_user*_dynptr`) must use `copy_user_*_nofault` (reserving `copy_user_*_sleepable` for `KF_SLEEPABLE` `bpf_copy_from_user*_dynptr`); and `uprobe_prog_run()` must wrap `bpf_prog_run()` in `migrate_disable()`/`migrate_enable()` and `rcu_read_lock_trace()` (if `prog->sleepable`) or `rcu_read_lock()`. [F74, F173, F176]
- `sock_ops` helpers that access or mutate socket state (`bpf_sock_ops_setsockopt`, `bpf_sock_ops_getsockopt`, `bpf_sock_ops_cb_flags_set`, `bpf_sock_ops_load_hdr_opt`) must return `-EOPNOTSUPP` when `!is_locked_tcp_sock_ops(bpf_sock)`, and `sol_tcp_sockopt_congestion()` must guard `do_tcp_setsockopt()` with `tp->bpf_chg_cc_inprogress`. [F214, F227]

## Object Lifetimes

- `task_vma_seq_get_next()` must hold a reference on `info->task`, `mm_users` on `info->mm`, and `mmap_read_lock` on `info->mm` whenever it returns a non-NULL VMA, and release all three and clear `info->task`, `info->mm`, and `info->vma` to `NULL` when returning `NULL`. [F17]
- In `bpf_uprobe_multi_link_attach()`, `link->task` (acquired under `rcu_read_lock()` via `get_pid_task(find_vpid(pid), PIDTYPE_TGID)`), `link->link`, and `uprobes[i].link`/`consumer` must be initialized before `uprobe_register()`; `bpf_uprobe_unregister()` must call `uprobe_unregister_nosync()` for all entries then `uprobe_unregister_sync()` before releasing `link->task`, `link->path`, or freeing memory; and `bpf_kprobe_multi_link_lops` and `bpf_uprobe_multi_link_lops` must use `.dealloc_deferred` (with `get_modules_for_addrs()` before `register_fprobe_ips()` and `unregister_fprobe()` before `kprobe_multi_put_modules()`). [F41, F42, F174, F175]
- All post-init accesses to `prog->aux->offload` and `struct bpf_offloaded_map` must hold `bpf_devs_lock` and verify `prog->aux->offload != NULL` or `offmap->netdev != NULL`. `__bpf_prog_offload_destroy()` must call `offload->offdev->ops->destroy(prog)` only when `offload->dev_state` is set, and bound-only `ondev` entries (`offdev == NULL`) must be unregistered when their last program is destroyed or the netdev unregisters. [F148, F149, F150, F151]
- Socket filter updates (`__sk_attach_prog()`, `sk_detach_filter()`, `sk_get_filter()`) require the socket lock; `sk_filter_charge()` must pin `fp` with `refcount_inc_not_zero(&fp->refcnt)` before `__sk_filter_charge()` (calling `sk_filter_release(fp)` on failure), `sk_filter_release()` must defer `__sk_filter_release()` via `call_rcu()`, and `__bpf_prog_release()` / `sk_reuseport_prog_free()` must release eBPF programs via `bpf_prog_put()` and cBPF programs (`BPF_PROG_TYPE_UNSPEC`) via `bpf_release_orig_filter()` and `bpf_prog_free()`/`bpf_prog_destroy()`. [F208, F221, F222, F347, F376]
- In `sk_lookup()`, `__bpf_sk_lookup()`, and `bpf_sk_lookup()`, any socket returned without a per-lookup reference must have `SOCK_RCU_FREE` set or return `NULL`; `bpf_sk_lookup_assign()` must reject `sk_is_refcounted(sk)` with `-ESOCKTNOSUPPORT`, `sk_select_reuseport()` must `sock_put(selected_sk)` on error if `sk_is_refcounted(selected_sk)`, and `bpf_sk_assign()` must pin refcounted sockets via `refcount_inc_not_zero(&sk->sk_refcnt)` after checking `!sk_unhashed(sk)` before `skb_orphan(skb)`. [F217, F218, F230, F231]
- In `net/core/filter.c`, `skb_dst_set()` requires `skb_dst_drop(skb)` first; `bpf_clone_redirect()` must `kfree_skb(clone)` if `bpf_try_make_head_writable(skb)` fails; `bpf_msg_push_data()` and `bpf_msg_pop_data()` must match `get_page()`/`put_page()` and `sk_mem_charge()`/`sk_mem_uncharge()`; and shrinking XDP frags in `bpf_xdp_frags_shrink_tail()` or `bpf_xdp_pull_data()` must free consumed frags via `bpf_xdp_shrink_data()` and clear frags/pfmemalloc flags when `sinfo->nr_frags == 0` (subtracting residual `offset` from `xdp->data_end`). [F209, F210, F211, F212, F291]
- In `net/bpf/test_run.c`, `xdp_test_run_batch()` must call `xdp_return_buff(ctx)` on failed frame update/redirect, `XDP_DROP`, or invalid action, update `frm` via `xdp_update_frame_from_buff()` when `ctx_was_changed(head)`, and flush redirects at `out:` before `xdp_recv_frames()` without overwriting an earlier `-ENOMEM` `err` with `0` (while `reset_ctx()` restores `head->frame->mem_type`). `bpf_prog_test_run_xdp()` must call `xdp_convert_buff_to_md(&xdp, ctx)` on every exit path after `xdp_convert_md_to_buff()` to `dev_put(xdp.rxq->dev)`, `bpf_prog_test_run_skb()` must only `dev_put(dev)` when `dev != net->loopback_dev`, and `bpf_set_run_ctx()` must pair with `bpf_reset_run_ctx()`. [F198, F199, F201, F247, F260, F261, F340]

## API Contracts

- `netns_bpf_prog_attach()` takes ownership of `prog` only on success (`0`, putting old `attached`) and must not put `prog` on error; conversely, `bpf_prepare_filter()` and `bpf_migrate_filter()` consume `fp` and call `__bpf_prog_release(fp)` on every error path (restoring `fp = old_fp` if `bpf_prog_realloc()` returns `NULL`). [F4, F205, F206]
- Callers of `bpf_mem_cache_raw_free(ptr)` must ensure `ptr` has passed an `rcu_tasks_trace` grace period before it calls `kfree(ptr - LLIST_NODE_SZ)`. In `alloc_bulk()` and `bpf_mem_cache_alloc_flags()`, `__GFP_ACCOUNT` allocations must switch the active memcg to `get_memcg(c)` around `__alloc()`. [F11, F181]
- Read-modify-write helper arguments (`mtu_len` in `bpf_skb_check_mtu_proto`/`bpf_xdp_check_mtu_proto` and `search_res` in `bpf_sock_ops_load_hdr_opt_proto`) must use `MEM_WRITE` without `MEM_UNINIT`; verification-time capability checks (`cg_skb_is_valid_access`, `bpf_sk_base_func_proto`) must use `bpf_token_capable(prog->aux->token, ...)`; `bpf_xdp_pointer()` returns `NULL` when `[offset, offset + len)` crosses frag boundaries (falling back to `bpf_xdp_copy_buf()`) and `ERR_PTR` on error; and `bpf_ctx_init()` returns `NULL` when both `ctx_in` and `ctx_out` are zero. [F243, F250, F290, F375]

## Error Handling

- In `perf_event_detach_bpf_prog()`, when `event->prog` is non-NULL, if `old_array` is `NULL` it must skip `bpf_prog_array_copy()`, and if `bpf_prog_array_copy()` fails it must fall back to `bpf_prog_array_delete_safe()`, still clearing `event->prog = NULL` and calling `bpf_prog_put(prog)` after `synchronize_rcu_tasks_trace()`. [F7, F50]
- Open-coded BPF iterator constructors (`bpf_iter_task_vma_new`, `bpf_iter_css_task_new`, `bpf_iter_task_new`) must set their internal state pointer (`kit->data`, `kit->css_it`, or `kit->pos`) to `NULL` on every error path because `_next` and `_destroy` still run. In `bpf_uprobe_multi_link_attach()`, if `uprobe_register()` fails at index `i`, `link->cnt` must be set to `i` before `goto error_unregister`; in `bpf_kprobe_multi_link_attach()`, once `bpf_link_prime()` succeeds and `link->addrs`/`cookies` are set, errors must call `bpf_link_cleanup(&link_primer)` rather than `goto error`. [F46, F58, F59]
- Helpers writing to `ARG_PTR_TO_UNINIT_MEM` (`bpf_probe_read_*_common`, `bpf_perf_event_read_value`, `bpf_perf_prog_read_value`) and `__queue_map_get()`/`__stack_map_get()` on an empty map must `memset` the destination buffer to `0` on failure; `bpf_skb_get_tunnel_key()` and `bpf_skb_get_xfrm_state()` must zero `&remote_ipv6[1]` and `&local_ipv6[1]` (`sizeof(__u32) * 3`) when writing IPv4 addresses. [F55, F56, F251]

## Known Pitfalls

- In `bpf_msg_pop_data()`, the `while (pop)` loop must not advance `i` after `sk_msg_shift_left(msg, i)` when `pop >= sge->length` because `sk_msg_shift_left()` shifts the next entry into slot `i`; in `bpf_xdp_copy_buf()`, `if (!len || next_frag == end_frag) break;` must precede dereferencing `next_frag`; and in `bpf_search_tcp_opt()`, options other than `EOL`/`NOP` must reject `op[1] < 2` before `op += kind_len`. [F306, F310, F311]
