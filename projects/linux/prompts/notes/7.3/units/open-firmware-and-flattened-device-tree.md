# OPEN FIRMWARE AND FLATTENED DEVICE TREE

The Open Firmware and Flattened Device Tree (OF/DT) subsystem parses early-boot FDT blobs and PROM trees into a live, reference-counted hierarchy of `struct device_node` and `struct property` objects under `/sys/firmware/devicetree`. It provides core APIs and C/Rust bindings (`include/linux/of*.h`, `rust/kernel/of.rs`) for querying nodes, properties, phandles, OF graphs, reserved memory, address/DMA translations, and IRQ mappings, instantiates `platform_device` and `amba_device` hierarchies, and supports runtime mutations via dynamic changesets and DT overlays.

## Architecture & Data Flow

- `of_node_release()` only frees a `struct device_node` and its `properties`/`deadprops` when both `OF_DETACHED` and `OF_DYNAMIC` are set and, if `OF_OVERLAY` is set, `OF_OVERLAY_FREE_CSET` was set by `__of_changeset_entry_destroy()` when `kref` was `1`. Never drop the final ref on an attached node, and never format `node` with `%pOF` in `of_node_release()` when `!of_node_check_flag(node, OF_DETACHED)`. [F11, F33]
- In `__of_detach_node()`, setting `OF_DETACHED` on `np` and calling `__of_phandle_cache_inv_entry(np->phandle)` must both happen under `devtree_lock` before `__of_detach_node_sysfs()` so concurrent `of_find_node_by_phandle()` lookups cannot return or re-cache the detached node. [F56]
- `of_resolve_phandles()` requires `OF_DETACHED` and `of_overlay_phandle_mutex`; `adjust_overlay_phandles()` must update `overlay->phandle` and `phandle`/`linux,phandle` properties by `live_tree_max_phandle() + 1` before `__local_fixups__`. In `init_overlay_changeset()`, any `"__symbols__"` child must be placed at `ovcs->fragments[ovcs->count - 1]` with `ovcs->symbols_fragment = true`. [F68, F87]
- In `add_changeset_property()` and `add_changeset_node()`, overlays targeting `target->in_livetree` must not update `#address-cells` or `#size-cells` (`-EINVAL` if different, `0` if equal) or overwrite a non-zero `tchild` phandle (`-EINVAL`). For `/__symbols__`, `add_changeset_property()` must reject existing symbols (`-EINVAL`) and rewrite `/fragment@N/__overlay__/` via `dup_and_fixup_symbol_prop()`. [F69, F70]
- On `OF_RECONFIG_UPDATE_PROPERTY`, `__of_changeset_entry_apply()` must record the displaced property in `ce->old_prop` via `__of_update_property()`; `__of_changeset_entry_invert()` swaps `ce->prop` and `ce->old_prop`, or sets `rce->action = OF_RECONFIG_REMOVE_PROPERTY` if `ce->old_prop` is `NULL`. Changeset property builders must pass stack `struct property` instances through `of_changeset_add_prop_helper()` / `of_changeset_update_prop_helper()` so `__of_prop_dup()` heap-allocates them. [F60, F130]
- `of_overlay_remove()` returns `-EBUSY` if `overlay_removal_is_ok()` finds overlapping nodes in a later overlay on `ovcs_list`, and only zeroes `*ovcs_id` and calls `free_overlay_changeset(ovcs)` after `OF_OVERLAY_PRE_REMOVE` and `__of_changeset_revert_entries()` succeed. If rollback fails in `of_overlay_apply()` or `of_overlay_remove()`, `devicetree_state_flags` (`DTSF_APPLY_FAIL`/`DTSF_REVERT_FAIL`) must be set and never cleared so `devicetree_corrupt()` rejects future apply/remove calls with `-EBUSY`. [F19, F61]
- In `of_translate_one()`, a missing `rprop` on `parent` fails unless `rprop` is `"dma-ranges"` or `of_empty_ranges_quirk(parent)` is true (1:1 translation); on 1:1 translation, read `offset = of_read_number(addr, na)` before mutating `addr` and zero only cells after `pbus->flag_cells` (`memset(addr + pbus->flag_cells, 0, (pna - pbus->flag_cells) * 4)`). [F65, F141]
- In `of_parse_phandle_with_args_map()`, each nexus step must update both `initial_match_array[i]` and `out_args->args[i]` with the `<list>-map-pass-thru`-merged specifier before `cur = new`. In `of_irq_parse_raw()`, if `ipar` has `"interrupt-controller"`, `"interrupt-map"` still takes precedence unless absent or `ipar` matches `of_irq_imap_abusers`. [F64, F140]
- `of_platform_device_create_pdata()`, `of_amba_device_create()`, and `of_irq_init()` must gate initialization with `OF_POPULATED` and clear it on failure; `of_platform_device_destroy()` and `of_platform_depopulate()` must clear `OF_POPULATED`/`OF_POPULATED_BUS` and check `dev->bus` (`&platform_bus_type` vs `&amba_bustype`) before downcasting. [F62, F129, F134]
- In `__of_address_resource_bounds()`, check `overflows_type(start, r->start)` and set `r->end` via `check_add_overflow()` to `r->start + size - 1` when `size > 0`, or `wrapping_sub(typeof(r->end), r->start, 1)` when `size == 0`. When `"nonposted-mmio"` is set, `__of_address_to_resource()` sets `IORESOURCE_MEM_NONPOSTED` and `of_iomap()`/`of_io_request_and_map()` must use `ioremap_np()`. [F75, F147]
- When changing `OF_RECONFIG_*`, `enum of_overlay_notify_action`, or `drivers/of/` APIs, update `action_names[]`, `of_overlay_action_name[]`, and `!CONFIG_OF*` stubs in `include/linux/of.h` and `drivers/of/of_private.h` in lockstep; `!CONFIG_OF` stubs for `of_property_read_variable_u*_array()`, `of_property_read_string_helper()`, `__of_parse_phandle_with_args()`, and `of_phandle_iterator_next()` must return negative errnos, never `0`. [F73, F74, F220]

## Synchronization

- `devtree_lock` (`raw_spinlock_t`) must be held via `raw_spin_lock_irqsave()` when traversing or mutating live `struct device_node` pointers (`parent`, `child`, `sibling`), `properties`/`deadprops`, or `phandle_cache`, pinning nodes with `of_node_get()` before unlocking. Internal `__of_*` lookup helpers do not take `devtree_lock` and require the caller to hold it or operate on an `OF_DETACHED` tree. [F23, F24]
- `of_mutex` must be held across all live tree mutations, sysfs updates, and post-boot `aliases_lookup` traversals. Always acquire `of_overlay_phandle_mutex` (`of_overlay_mutex_lock()`) before `of_mutex`, acquire `of_mutex` before `devtree_lock`, and release `devtree_lock` before calling any `__of_*_sysfs()` helper. Overlay notifiers (`of_overlay_notifier_register()`) run with `of_mutex` held and must never acquire `of_mutex` or `of_overlay_phandle_mutex`. [F16, F27, F29, F187, F279]
- `__of_changeset_apply_notify()` and `__of_changeset_revert_notify()` are entered with `of_mutex` held, must unlock `of_mutex` before calling `__of_changeset_entry_notify()`, and must re-lock `of_mutex` before returning. `of_reserved_mem_device_release()` must unlink `rmem_assigned_device` entries under `of_rmem_assigned_device_mutex` and drop the mutex before calling `rd->rmem->ops->device_release()`. [F14, F158]

## Object Lifetimes

- Iterative node helpers (`of_find_all_nodes`, `of_find_node_by_*`, `of_find_compatible_node`, `of_find_matching_node_and_match`, `of_find_node_with_property`, `of_get_next_*`, `of_graph_get_next_*`) call `of_node_put()` on `prev`/`from` and `of_node_get()` on the result: callers keeping `from` must `of_node_get(from)` first, and early breaks from non-scoped `for_each_*` loops must call `of_node_put()`. Scoped iterators (`for_each_*_scoped`, `for_each_child_of_node_with_prefix`, `for_each_of_graph_*`) use `__free(device_node)`: never call `of_node_put(child)` on break, and use `return_ptr()`/`no_free_ptr()` to keep `child`. [F1, F174, F176]
- `of_phandle_iterator_next()` drops any prior `it->node` ref on each step and on error; breaking out of `of_for_each_phandle()` early leaves an owned ref in `it.node` requiring `of_node_put()`. Callers of `of_parse_phandle*()` must `of_node_put()` the returned node or `out_args->np` on success, and callers of `of_find_device_by_node()` / `of_find_i2c_device_by_node()` must release non-NULL results with `platform_device_put()` / `put_device()`. [F3, F261, F265]
- `of_irq_parse_raw()` increments `out_irq->np` without dropping the caller's initial `out_irq->np` ref, and on a self-referencing `interrupt-map` entry (`ipar == newpar`) must call `of_node_put(ipar)` because `of_irq_parse_imap_parent()` already took a second ref in `out_irq->np`. `of_irq_parse_one()` must drop its initial parent `p`, and its callers must call `of_node_put(out_irq->np)`. [F4, F5]
- `__of_remove_property()` and `__of_update_property()` never free removed/replaced `struct property` objects—they move them to `np->deadprops` under `devtree_lock` until `of_node_release()`. Because `__of_changeset_entry_destroy()` also does not free `ce->prop`, `of_changeset_add_prop_helper()` must `__of_prop_free(new_pp)` if `of_changeset_add_property()` fails, and on success link `new_pp` onto `np->deadprops`. [F9, F10]
- `of_changeset_create_node()` returns a node with both creation and attach refs held, so callers must call `of_node_put(np)` in addition to `of_changeset_destroy()`. `of_changeset_destroy()` must call `device_link_wait_removal()` first, and both `of_changeset_destroy()` and `of_overlay_remove_all()` must iterate with `list_for_each_entry_safe_reverse()`. In `of_irq_init()`, `of_node_put()` must be called on both `desc->interrupt_parent` and `desc->dev` before `kfree(desc)` on error. [F6, F12, F104, F181]

## API Contracts

- Despite the comment in `drivers/of/of_private.h`, `__of_find_node_by_path()` increments the refcount of the returned node, and `__of_find_node_by_full_path()` consumes the caller's ref on `node` while returning an owned ref. In `__of_translate_address()`, matching an indirect-IO range (`iorange->flags != LOGIC_PIO_CPU_MMIO`) transfers `dev` to `*host = no_free_ptr(dev)`, which the caller must `of_node_put(host)`. [F2, F8]
- `of_find_property()`, `of_get_property()`, `__of_find_property()`, and `__of_get_property()` leave `*lenp` untouched on `NULL`. `of_property_read_u{8,16,32,64}*` and `of_property_read_string*` return borrowed pointers (for strings) and must not modify output parameters on error; `of_property_read_variable_u*_array()`, `of_property_read_string_array()`, and `of_property_count_strings()` return positive counts on success, whereas `of_property_read_u*_array()` (which pass `sz_max = 0`, allowing trailing elements) and `of_property_read_string_index()` return `0`. [F38, F122, F179, F198, F199, F200, F227, F228]
- `of_translate_address()`, `of_translate_dma_address()`, `__of_translate_address()`, and `of_translate_ioport()` return `OF_BAD_ADDR` (`(u64)-1`) on failure, not `<= 0`; `of_dma_get_range()` must skip `OF_BAD_ADDR` entries and return `-EINVAL` if `!num_ranges`. `irq_of_parse_and_map()` returns `0` on failure, whereas `of_irq_get()`, `of_irq_get_byname()`, and `of_irq_to_resource()` return `< 0` errno, `0` on mapping failure, or `> 0` IRQ. [F40, F42]
- `of_read_number()` and `of_read_ulong()` take `size` in 32-bit cells (`sizeof(__be32)`), not bytes. `of_phandle_iterator_init()` requires `cells_name != NULL || cell_count >= 0`; `of_phandle_iterator_next()` resets `it->cur = it->phandle_end`, falls back to `it->cell_count` when `it->cells_name` is absent only if `it->cell_count >= 0`, and sets `it->phandle_end = it->cur + count` before returning `0`. [F50, F51, F108]
- In `of_supplier_bindings[]`, `.parse_prop` and `.get_con_dev` must return refcounted `device_node *` pointers, `.parse_prop` must return the first supplier at `index == 0` and `NULL` once exhausted, and bindings on non-device subnodes (e.g. `"remote-endpoint"`) must set `.get_con_dev` (`of_graph_get_port_parent`) so `of_link_property()` links `con_dev_np`. Never add standalone `"interrupt-parent"` to `of_supplier_bindings[]`. [F99, F111, F144, F145, F170]
- `device_node::_flags` and `property::_flags` are `unsigned long` bitmaps accessed via atomic bitops (`of_node_*_flag()`, `of_property_*_flag()`), where `OF_DYNAMIC`..`OF_OVERLAY_FREE_CSET` are bit indices, not shifted masks. Downcasting `fwnode_handle *` must use `to_of_node()`/`is_of_node()`, and upcasting a possibly-NULL `device_node *` must use `of_fwnode_handle(node)` rather than `&node->fwnode`. [F193, F251, F252, F256]
- `of_fwnode_get_reference_args()` must call `of_node_put(of_args.np)` when `args` is `NULL`, and zero-fill `args->args[i]` up to `NR_FWNODE_REFERENCE_ARGS` when non-NULL. `of_find_node_opts_by_path()` must clear `*opts = NULL` when the path has no `':'`. `of_range_count()` must be called before `for_each_of_range()` advances `parser->range`. [F169, F218, F250]

## Error Handling

- `__of_changeset_apply_entries()` rolls back failures via `list_for_each_entry_continue_reverse()` and `__of_changeset_revert_entries()` rolls back via `list_for_each_entry_continue()`; both keep the primary error in `ret` and write rollback errors only to `*ret_revert`/`*ret_apply`, which callers must initialize to `0`. [F13, F48]
- In `of_overlay_fdt_apply()`, set `ovcs->notify_state = OF_OVERLAY_INIT` and call `of_changeset_init(&ovcs->cset)` before any fallible step, and validate `overlay_fdt_size` and `fdt_check_header()`/`fdt_totalsize()` before copying to `PTR_ALIGN(new_fdt, FDT_ALIGN_SIZE)` (storing unaligned `new_fdt` in `ovcs->new_fdt`). Once `of_overlay_apply()` is called, failure must not call `free_overlay_changeset(ovcs)` directly, but export `*ret_ovcs_id = ovcs->id` for `of_overlay_remove()`. [F37, F47, F80, F124, F183]
- Validate cell counts with `OF_CHECK_COUNTS()` before copying `na * 4` bytes into `addr[OF_MAX_ADDR_CELLS]`. In `of_irq_parse_imap_parent()` and `of_parse_phandle_with_args_map()`, decrement `len`/`map_len` when advancing past a phandle cell before checking `<= MAX_PHANDLE_ARGS`, and in `of_parse_phandle_with_args_map()` explicitly set `ret` to a negative errno before `goto put` because `of_property_read_u32()` overwrites `ret = 0`. In `of_phandle_iterator_next()`, check `it->cur + count <= it->list_end`. [F44, F76, F82, F84]
- String property readers must verify NUL-termination within `prop->length` via `strnlen()` before `strlen()`/`strcmp()`; phandle fixup helpers must verify `offset + sizeof(__be32) <= prop->length` and `prop_fix->length % 4 == 0`; `of_match_bus()` results must be NULL-checked and bus matchers must check `of_property_present(np, "#address-cells")` before `of_bus_n_addr_cells(np)`. `of_iomap()` returns `NULL` on error whereas `of_io_request_and_map()` returns `IOMEM_ERR_PTR` (`IS_ERR()`). [F43, F81, F83, F196]

## External Contracts

- In `__of_add_property_sysfs()`, `"security-"` properties must use mode `0400` and `size = 0`. `early_init_dt_scan_chosen()` must scrub `/chosen/rng-seed` with `fdt_nop_property()` and recompute `of_fdt_crc32`. In `of_kexec_alloc_and_setup_fdt()`, delete existing `"kaslr-seed"` and `"linux,ima-kexec-buffer"` (and its memreserve), only write fresh seeds if `rng_is_initialized()`, and place `crashk_res` before `crashk_low_res` in `"linux,usable-memory-range"`. [F93, F164, F165, F172]

## Known Pitfalls

- Never format a `struct device_node *` with `%pOF` while holding `devtree_lock` (deadlocks in `of_get_parent()`), and never place an alphanumeric literal directly after `%pOF*` in a format string (use `%c`). Divide byte lengths from `of_get_property()`/`fdt_getprop()` by `sizeof(__be32)` (4) when advancing `const __be32 *` pointers, bounding cell loops, or calling `of_read_number(prop, len / 4)` on `"linux,initrd-*"`, while scaling untyped `const void *` offsets by `4 * addr_cells`. [F25, F78, F120, F121, F127]
- In `of_dma_configure_id()`, only reset `dev->dma_range_map = NULL` on `-EPROBE_DEFER` if `set_map` is true, call `of_dma_get_range()` on `__of_get_dma_parent(np)` only when `np == dev->of_node`, and ensure `end` is non-zero before `DMA_BIT_MASK(ilog2(end) + 1)`. In `early_init_dt_add_memory_arch()`, check `size` before subtracting alignment/offset deltas and clamp against `MAX_MEMBLOCK_ADDR`. Use `initial_boot_params_pa`, never `__pa(initial_boot_params)`. [F54, F110, F115, F116, F117, F159]
- In `of_find_node_opts_by_path()` and `__of_find_node_by_path()`, bound alias/component names by both `'/'` and `':'` (`strcspn(path, "/:")`). In `of_graph_get_next_endpoint()`, reset `prev = NULL` before advancing `port`. `_OF_DECLARE()` macros degrade to unused static structs when `MODULE` is defined. [F77, F107, F270]
