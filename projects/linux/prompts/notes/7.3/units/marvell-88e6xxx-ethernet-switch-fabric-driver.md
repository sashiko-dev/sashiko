# MARVELL 88E6XXX ETHERNET SWITCH FABRIC DRIVER

This unit (`drivers/net/dsa/mv88e6xxx`) implements the Distributed Switch Architecture (DSA) driver for the Marvell Link Street 88E6xxx family of Ethernet switches over SMI/MDIO, managing Global 1/2 registers, ATU/VTU/STU translation tables, Cross-chip Port VLAN Tables (PVT), cascaded IRQ domains, Phylink MAC/PCS, PTP timestamping, and Devlink regions/resources.

## Architecture & Data Flow

- Every `mv88e6xxx_table` model using split VTU/STU ops (`mv88e6352_g1_vtu_*` or `mv88e6390_g1_vtu_*`) must set `.max_sid > 0` and both `.stu_getnext` and `.stu_loadpurge`. `mv88e6xxx_has_stu()` must check all three, and all STU/MST entry points (`mv88e6xxx_stu_setup()`, `mv88e6xxx_mst_get()`, `mv88e6xxx_mst_put()`, `mv88e6xxx_vlan_msti_set()`) must gate STU access on `mv88e6xxx_has_stu(chip)`. [F36, F69]
- `mv88e6xxx_stu_setup()` must run after `mv88e6xxx_vtu_setup()` (whose `FLUSH_ALL` flushes both VTU and STU) to load `sid = 0` as valid; `mv88e6xxx_sid_get()` must pre-set bit 0 in its busy bitmap and reject `*sid >= mv88e6xxx_max_sid(chip)`, and `mv88e6xxx_mst_put()` must never purge `sid == 0`. [F51, F80]
- `chip->fid_bitmap` must stay in lockstep with hardware VTU/ATU FIDs: `mv88e6xxx_atu_new()` selects a zero bit, `mv88e6xxx_port_vlan_join()` sets it, `mv88e6xxx_port_vlan_leave()` clears it when `!vlan.valid`, and `mv88e6xxx_g1_vtu_flush()` zeroes the bitmap. [F50]
- `mv88e6xxx_setup_port()` must join `MV88E6XXX_VID_STANDALONE` before `MV88E6XXX_VID_BRIDGED` so `mv88e6xxx_atu_new()` assigns them `MV88E6XXX_FID_STANDALONE` (0) and `MV88E6XXX_FID_BRIDGED` (1), and `mv88e6xxx_port_db_get()` must map `vid == 0` to `MV88E6XXX_FID_BRIDGED` so FID 0 stays empty. [F62]
- `mv88e6xxx_port_commit_pvid()` must be called under `chip->reg_lock` whenever bridge membership, VLAN filtering, or `p->bridge_pvid` changes (`mv88e6xxx_port_bridge_join()`/`leave()`, `mv88e6xxx_port_vlan_filtering()`, `mv88e6xxx_port_vlan_add()`/`del()`). [F53]
- In the PVT, physical switches use `dev = 0 .. dst->last_switch` and virtual bridges use `dev = bridge_num + dst->last_switch` (`ds->max_num_bridges <= MV88E6XXX_MAX_PVT_SWITCHES - ds->dst->last_switch - 1`); on PVT-capable chips, `mv88e6xxx_port_bridge_join()`/`leave()` and `mv88e6xxx_crosschip_bridge_join()`/`leave()` must call `mv88e6xxx_map_virtual_bridge_to_pvt()` alongside `mv88e6xxx_bridge_map()`/`mv88e6xxx_pvt_map()`. [F54, F76]
- In `mv88e6xxx_pvt_map()`, remote LAG ports (`dp && dp->lag`) must be remapped to `dev = MV88E6XXX_G2_PVT_ADDR_DEV_TRUNK` and `port = dsa_port_lag_id_get(dp) - 1`, and `mv88e6xxx_crosschip_lag_join()`/`leave()` must call `mv88e6xxx_pvt_map()` alongside `mv88e6xxx_lag_sync_masks_map()`. [F55]
- Hardware LAG hash distribution (`mv88e6xxx_lag_set_port_mask()`, `mv88e6xxx_lag_sync_masks()`) supports at most 8 ports per LAG and indexes `mv88e6xxx_lag_mask_table[num_tx - 1][nth]` (`0 < num_tx <= 8`, `nth < num_tx`); in `mv88e6xxx_lag_sync_masks()`, the second `dsa_lag_foreach_port()` pass must skip `!dp->lag_tx_enabled` before `nth++`, but increment `nth` across all TX-enabled ports in `ds->dst` even when `dp->ds != ds`. [F75, F96]
- In `mv88e6xxx_port_db_load_purge()`, removing a port (`!state`) must only clear `BIT(port)` from `entry.portvec` and set `entry.state = 0` only when `entry.portvec == 0`; when clearing a policy (`MV88E6XXX_POLICY_ACTION_NORMAL`) in `mv88e6xxx_policy_apply()`, `port_set_policy()` must be skipped if any remaining entry in `chip->policies` has the same `port` and `mapping` with a non-normal action. [F63, F64]
- `mv88e6xxx_set_egress_port()` must update `chip->ingress_dest_port` or `chip->egress_dest_port`, and `mv88e6xxx_port_mirror_add()`/`del()` must check `mirror_ingress`/`mirror_egress` across all ports to reject destination changes when active (`-EBUSY`) and reset the destination to `dsa_upstream_port()` when none remain. [F56]
- In `mv88e6xxx_table[]`, every `mv88e6xxx_info` must set `1 <= num_ports <= 16` to `highest_port + 1` with unrouted intermediate ports in `invalid_port_mask`, set `.atu_move_port_mask` matching the ATU PortVec width (`0xf`, `0x1f`, or `0`), set a non-zero `age_time_coeff`, and set `.max_vid = 8191` on chips supporting `MV88E6390_G1_VTU_VID_PAGE` (where `mv88e6xxx_g1_vtu_vid_read()`/`write()` map VID bit 12 (`0x1000`) to bit 13 (`0x2000`) because bit 12 is `MV88E6XXX_G1_VTU_VID_VALID`). [F72, F86, F103, F104, F125, F127]
- In `mv88e6xxx_ops`, `.phylink_get_caps` must match the C_Mode encoding of `.port_get_cmode` (`mv88e6xxx_translate_cmode()` for `mv88e6352_port_get_cmode`, or `mv88e6185_phy_interface_modes` for `mv88e6185_port_get_cmode`), and callers must verify `cmode < ARRAY_SIZE(...)` and a non-zero table entry before `__set_bit()`. [F71, F128]
- In `mv88e6xxx_g1_atu_prob_irq_thread_fn()`, indexing `chip->ports[spid]` (`spid = entry.state`) on `MV88E6XXX_G1_ATU_OP_FULL_VIOLATION` must be guarded by `spid < ARRAY_SIZE(chip->ports)` because CPU ATU loads can report `spid >= DSA_MAX_PORTS`. [F70]
- Internal PHY port indices must be offset by `chip->info->internal_phys_offset` (`mv88e6xxx_phy_is_internal()`) and MDIO `bus->phy_mask` / `bus->irq[]` indices by `chip->info->phy_base_addr` (`mv88e6xxx_mdio_register()`, `mv88e6xxx_g2_irq_mdio_setup()`); `mv88e6xxx_mdio_register()` must insert the internal bus (`!external`) via `list_add()` and external buses via `list_add_tail()` so `mv88e6xxx_default_mdio_bus()` returns the internal bus. [F73, F123]
- In `mv88e6xxx_setup_port()`, standalone user ports (`dsa_is_user_port(ds, port)`) must start with `mv88e6xxx_port_set_map_da(chip, port, false)`, `MV88E6XXX_PORT_CTL2_8021Q_MODE_DISABLED`, and `MV88E6XXX_PORT_ASSOC_VECTOR = 0` (whereas CPU/DSA ports enable all three); in `mv88e6xxx_change_mtu()`, `chip->info->ops->set_max_frame_size()` must only be called when `dsa_is_cpu_port(ds, port)` is true. [F65, F150]
- When `mv88e63xx_get_port_serdes_cmode()` clears `MV88E6XXX_PORT_STS_PHY_DETECT` in `MV88E6XXX_PORT_STS` to read SERDES `CMODE`, it must restore the original `reg` value before returning; in `global2_scratch.c`, writes to `MV88E6352_G2_SCRATCH_GPIO_DATA0`/`DATA1` (`mv88e6352_g2_scratch_gpio_set_data()`) must update `chip->gpio_data[pin / 8]` in lockstep. [F67, F68, F87]

## Synchronization

- Every register access (`mv88e6xxx_read()`, `mv88e6xxx_write()`, `mv88e6xxx_wait_mask()`, `mv88e6xxx_wait_bit()`) and all accesses to `chip->fid_bitmap`, `chip->policies`, and `chip->gpio_data` must run in a sleepable context with `chip->reg_lock` held (`assert_reg_lock()`), and multi-step indirect hardware sequences (ATU/VTU/STU getnext/loadpurge, `mv88e6xxx_devlink_atu_bin_get()`, `mv88e6xxx_g2_avb_read()`/`write()`, G2 scratch accesses) must hold `chip->reg_lock` continuously across the entire sequence. [F29, F30, F136]
- `irq_chip` `.irq_mask`/`.irq_unmask` callbacks (`mv88e6xxx_g1_irq_mask()`/`unmask()`, `mv88e6xxx_g2_irq_mask()`/`unmask()`) run in atomic genirq context and must only update `g1_irq.masked`/`g2_irq.masked`, deferring SMI writes to `.irq_bus_sync_unlock`. [F137]
- `mv88e6xxx_g1_irq_thread_work()`, `mv88e6xxx_g2_irq_thread_fn()`, and `mv88e6xxx_g1_atu_prob_irq_thread_fn()` must drop `chip->reg_lock` before calling `handle_nested_irq()` or `mv88e6xxx_handle_miss_violation()` (which acquires `chip->reg_lock` and `rtnl_lock`), and IRQ registration/teardown (`request_threaded_irq()`, `free_irq()`, `kthread_cancel_delayed_work_sync()`) and `dsa_devlink_*` setup/teardown must be called without `chip->reg_lock` held. [F138, F139, F141, F144]
- `mv88e6xxx_port_vlan_del()` must call `dsa_flush_workqueue()` before acquiring `chip->reg_lock` and calling `mv88e6xxx_port_vlan_leave()` so deferred FDB deletions finish while the VLAN's FID is still in the VTU. [F61]
- `mv88e6xxx_set_hwtstamp_config()` must clear `MV88E6XXX_HWTSTAMP_ENABLED` before reconfiguring hardware, update `chip->enable_count` with `ptp_ops->global_enable`/`global_disable` under `chip->reg_lock`, and set `MV88E6XXX_HWTSTAMP_ENABLED` only after setup finishes; `mv88e6xxx_port_txtstamp()` must acquire `MV88E6XXX_HWTSTAMP_TX_IN_PROGRESS` via `test_and_set_bit_lock()` (calling `kfree_skb(clone)` on contention), `mv88e6xxx_txtstamp_work()` must clear `ps->tx_skb = NULL` and `clear_bit_unlock()` before `skb_complete_tx_timestamp()`, and `mv88e6xxx_get_rxts()` must splice `rxq` under `spin_lock_irqsave(&rxq->lock, flags)` and drop `rxq->lock` before `chip->reg_lock` or `netif_rx()`. [F59, F147, F156]

## Object Lifetimes

- In `mv88e6xxx_probe()` and `mv88e6xxx_remove()`, G1/G2 IRQ domains (`mv88e6xxx_g1_irq_setup()`, `mv88e6xxx_g2_irq_setup()`) must be set up before `mv88e6xxx_register_switch()` and torn down in reverse order (`mv88e6xxx_unregister_switch()`, G1/G2 sub-IRQs, `mv88e6xxx_g2_irq_free()`, `mv88e6xxx_g1_irq_free()`/`mv88e6xxx_irq_poll_free()`), using the persistent `char[64]` IRQ name buffers in `struct mv88e6xxx_chip` rather than stack buffers. [F23, F118]
- `mv88e6xxx_mdio_register()` borrows `np`, so `mv88e6xxx_mdios_register()` must call `of_node_put(child)` after `of_get_child_by_name()` and on error exit from `for_each_available_child_of_node()`, and call `mv88e6xxx_mdios_unregister(chip)` if external bus registration fails; `mv88e6xxx_setup_port()` must release `ports_fwnode` (`fwnode_handle_put()`) and `phy_handle` (`of_node_put()`) on all return paths. [F6, F7]
- In `mv88e6xxx_vlan_msti_set()`, `mv88e6xxx_mst_get()` takes a ref on `new_sid` even when `new_sid == old_sid`, so if `new_sid != old_sid` and `mv88e6xxx_vtu_loadpurge()` fails it must call `mv88e6xxx_mst_put(chip, new_sid)`, whereas on success (including `new_sid == old_sid`) it must call `mv88e6xxx_mst_put(chip, old_sid)`. [F9]
- In `mv88e6xxx_policy_insert()`, a policy allocated with `devm_kzalloc()` and added to `chip->policies` via `idr_alloc_u32()` must be rolled back with `idr_remove()` and `devm_kfree()` if `mv88e6xxx_policy_apply()` fails, and freed with `devm_kfree()` on `ETHTOOL_SRXCLSRLDEL` in `mv88e6xxx_set_rxnfc()`; once `mv88e6xxx_port_rxtstamp()` queues `skb` and returns `true`, `mv88e6xxx_get_rxts()` must pass every dequeued `skb` to `netif_rx(skb)` even on read failure or sequence mismatch. [F11, F157]

## API Contracts

- `mv88e6xxx_wait_bit()`, `mv88e6xxx_g1_wait_bit()`, and `mv88e6xxx_g2_wait_bit()` take a bit index (`__bf_shf(MASK)`) and target state (`0` or `1`), whereas `mv88e6xxx_wait_mask()` and `mv88e6xxx_g1_wait_mask()` take a shifted 16-bit mask and shifted target value; `mv88e6xxx_g1_is_eeprom_done()` returns `0` when done, `-EBUSY` while resetting (`0xffff`) or busy, and other negative errnos on read failure (callers must loop only on `-EBUSY`). [F33, F46]
- DSA LAG IDs (`lag.id`, `dsa_port_lag_id_get(dp)`) are 1-based while hardware trunk IDs and PVT trunk port indices are 0-based (callers must subtract 1); for MTU vs. hardware frame size, `mv88e6xxx_get_max_mtu()` must subtract `VLAN_ETH_HLEN + EDSA_HLEN + ETH_FCS_LEN`, `mv88e6xxx_change_mtu()` must add `EDSA_HLEN` on CPU/DSA ports, and `mv88e6185_g1_set_max_frame_size()` must add `ETH_HLEN + ETH_FCS_LEN`. [F47, F48]
- `mv88e6xxx_port_setup_mac()` must force the link down via `port_set_link(chip, port, LINK_FORCED_DOWN)` before changing speed, duplex, pause, RGMII delay, or cmode, and restore `link` on both normal and error paths; `mv88e6xxx_g2_avb_read()` can snapshot at most 4 words and must reject `len > 4` with `-E2BIG`. [F66, F81]

## Error Handling

- In `mv88e6xxx_mdio_read_c45()`, when `chip->info->ops->phy_read_c45` is NULL, it must return `-ENODEV` (not `-EOPNOTSUPP`); in `mv88e6xxx_port_config_interface()`, `mv88e6xxx_port_setup_mac()`, `mv88e6xxx_setup_port()`, and `mv88e6xxx_setup_upstream_port()`, `-EOPNOTSUPP` from optional callbacks (`port_set_rgmii_delay`, `port_set_cmode`, `port_set_speed_duplex`, `port_setup_leds`, `mv88e6xxx_set_egress_port`) must be ignored, and callers must check `chip->info->ops->pcs_ops != NULL` before dereferencing `pcs_select`, `pcs_init`, or `pcs_teardown`. [F32, F35, F37]
- `mv88e6xxx_setup_devlink_regions_global()` and `mv88e6xxx_setup_devlink_regions_port()` must check `IS_ERR(region)` before storing into `chip->regions[i]` or `chip->ports[port].region`, and `mv88e6xxx_teardown_devlink_regions_global()` must check `chip->regions[i] != NULL` before `dsa_devlink_region_destroy()`. [F38, F39]
- In `mv88e6xxx_port_lag_leave()` and `mv88e6xxx_crosschip_lag_leave()`, both cleanup steps must run unconditionally with separate error variables (`err_sync ? : err_trunk`/`err_pvt`); in `mv88e6xxx_mst_put()`, when `refcount_dec_and_test(&mst->refcnt)` hits 0, `mv88e6xxx_stu_loadpurge()` must succeed before unlinking/freeing `mst`, restoring `refcount_set(&mst->refcnt, 1)` on failure. [F41, F52]
- `mv88e6xxx_vtu_get()` must `memset(entry, 0, sizeof(*entry))` before `vtu_getnext` (as `mv88e6185_g1_vtu_getnext()` leaves fields like `sid`/`policy` unset); `mv88e6xxx_change_tag_protocol()` must set `chip->tag_protocol` before `mv88e6xxx_setup_port_mode()` and restore `old_protocol` before reverse-loop unwinding on error; and `mv88e6xxx_port_fdb_add()`/`mdb_add()` must verify the entry with `mv88e6xxx_port_db_find()` under `chip->reg_lock` after `mv88e6xxx_port_db_load_purge()`, returning `-ENOSPC` if missing. [F42, F57, F133]

## External Contracts

- `mv88e6xxx_port_check_hw_vlan()` (when a VID is used by another bridge) and `mv88e6xxx_port_vlan_leave()` (when the VTU entry is invalid or the port is a non-member) must return `-EOPNOTSUPP` for software fallback; in `mv88e6xxx_setup_port()`, `MV88E6XXX_PORT_CTL0_IGMP_MLD_SNOOP` must only be set when `dsa_is_user_port(ds, port)` is true. [F149, F152]

## Known Pitfalls

- Because `mv88e6xxx_g1_vtu_getnext()` and `mv88e6xxx_g1_stu_getnext()` write the starting ID only when `!entry->valid` and return the next higher ID, `mv88e6xxx_vtu_get()` must set `entry->vid = vid ? vid - 1 : mv88e6xxx_max_vid(chip)` with `valid = false`, and full VTU/STU walks must start at `max_vid`/`max_sid` with `valid = false`; similarly, `mv88e6xxx_g1_atu_getnext()` writes `entry->mac` only when `!entry->state`, so `mv88e6xxx_port_db_get()` must zero `entry->state` and call `eth_addr_dec(entry->mac)`, while full ATU walks start at broadcast and stop on `is_broadcast_ether_addr()`. [F77, F79]
- In `mv88e6xxx_mst_get()` and `mv88e6xxx_port_mst_state_set()`, `BR_STATE_DISABLED` (and initial user-port STU state) must map to `MV88E6XXX_PORT_CTL0_STATE_BLOCKING` for user ports (`MV88E6XXX_PORT_CTL0_STATE_DISABLED` is only for CPU/DSA ports); in `mv88e6xxx_hardware_reset()`, `hardware_reset_pre`/`post` must wrap `chip->reset`, and on chips using `mv88e6xxx_g1_wait_eeprom_done()`, `MV88E6XXX_G1_STS` must not be read between reset and `mv88e6xxx_g1_wait_eeprom_done()`. [F134, F161]
- In `mv88e6xxx_policy_apply()`, `policy` is reused as the `idr_for_each_entry(&chip->policies, policy, id)` cursor, so its fields must be copied to locals before the loop; in `mv88e6xxx_port_vlan()`, `list_for_each_entry(dp, &dst->ports, list)` must check `if (!found)` before dereferencing `dp`; and `atu_move_port_mask` (`u8`) must be copied to an `unsigned long` before `bitmap_weight()`. [F92, F93, F117]
