# OBJTOOL

Objtool is a compile-time userspace ELF binary analysis and transformation tool for the Linux kernel, paired with kernel headers (`include/linux/objtool.h` and `include/linux/objtool_types.h`) that emit `.discard.*` section annotations from C and assembly. It decodes instructions across x86, LoongArch, and PowerPC, simulates control flow and stack frame state (CFI), validates kernel invariants (frame pointers, `noinstr`, SMAP/uaccess, retpoline/rethunk, IBT/ENDBR, SLS, unret), and generates or rewrites ELF sections such as `.orc_unwind`, `.static_call_sites`, `.retpoline_sites`, `.return_sites`, and `__mcount_loc`.

## Architecture & Data Flow

- `struct cfi_state` objects pointed to by `insn->cfi` (including `init_cfi`, `func_cfi`, `force_undefined_cfi`, and `cfi_hash` entries) are shared across instructions and `alt_group->cfi` arrays and must never be mutated in place; modify a local copy and intern via `cfi_hash_find_or_add()`. Any `struct cfi_state` passed to `cficmp()`, `cfi_key()`, or `cfi_hash_find_or_add()` must have `hash` as its first field and be zero-initialized (or copied from `init_cfi`) before `init_cfi_state()`, as `memcmp()`/`jhash()` cover all bytes after `hash`. [F19, F30]
- `decode_sections()` ordering: `read_annotate(file, __annotate_early)` must precede `add_special_section_alts()` and `read_unwind_hints()` (which read `insn->ignore_alts` and `insn->noendbr`); `add_special_section_alts()` must precede `add_jump_destinations()` (`handle_group_alt()` sets `insn->sym = orig_insn->sym` and resolves replacement-end jumps); and `add_call_destinations()` must run after `read_annotate(file, __annotate_ifc)` and before `read_annotate(file, __annotate_late)`. [F41, F42, F43]
- In `check()`, `validate_unrets()` must run after `validate_functions()`, `validate_unwind_hints()`, `validate_reachable_instructions()`, and `validate_noinstr_sections()` because `validate_unret()` sets `VISITED_UNRET` (`0x04`) in `insn->visited` while earlier passes test `!insn->visited` as a boolean. In `validate_branch()`, `insn->visited` tracks `VISITED_BRANCH << state.uaccess`; when `insn->visited & VISITED_BRANCH_MASK` is non-zero, `insn_cfi_match()` must be checked before returning `0` only if `insn->visited & visited` is already set. [F67, F68]
- In `struct alt_group`, `orig_group` is NULL on the original group and non-NULL only on replacement groups. `orig_alt_group->cfi` is allocated in `handle_group_alt()` with `special_alt->orig_len` entries (after `arch_handle_alternative()` maximizes `orig_len`) and shared with `new_alt_group->cfi`, so replacement offsets in `propagate_alt_cfi()` must not exceed `orig_len`. When `new_len < orig_len`, `handle_group_alt()` attaches a synthetic `INSN_NOP` (`alt_group->nop`; `last_insn == NULL` when `new_len == 0`) that `next_insn_to_validate()` must visit so `propagate_alt_cfi()` records post-last-instruction CFI. [F23, F49, F59]
- Control-flow walkers (`validate_branch()` and `validate_unret()`) must advance via `next_insn_to_validate(file, insn)` rather than `next_insn_same_sec(file, insn)` so reaching `alt_group->last_insn` in a replacement group transitions through `alt_group->nop` back to the instruction after `alt_group->orig_group->last_insn`. [F78]
- `decode_instructions()` allocates `struct instruction` in `INSN_CHUNK_SIZE` chunks with `u8 idx` (`INSN_CHUNK_BITS` must not exceed 8). `next_insn_same_sec()` and `prev_insn_same_sec()` step via pointer arithmetic within a chunk, and `free_insns()` calls `free()` on every `insn` in `file->insn_hash` with `insn->idx == 0`. Broken by: adding a single-element `struct instruction` (like `alt_group->nop`) to `file->insn_hash` with `idx == 0`, or calling `next_insn_same_sec()` on `alt_group->nop`. [F95, F100]
- `struct instruction` has a single `call_node` shared across `objtool_file` site lists; `annotate_call_site()` must return immediately after linking `insn->call_node` into `static_call_list`, `retpoline_call_list`, or `mcount_loc_list` so it is not also added to `file->call_list`. When patching an instruction via `elf_write_insn()` in `annotate_call_site()` or `handle_jump_alt()`, set its relocation to `R_NONE`, update `insn->type` to `INSN_NOP` or `INSN_RETURN`, and set `insn->retpoline_safe = true` when replacing a tail-call with `RET; INT3`. [F39, F40]
- In `read_unwind_hints()`, `UNWIND_HINT_TYPE_SAVE` must clear `insn->hint = false` while setting `insn->save = true` (leaving `insn->cfi` NULL), so `validate_branch()` computes `insn->cfi` from incoming control flow rather than dereferencing a NULL `insn->cfi` in `validate_unwind_hint()`. [F13]
- Before any `INSN_RETURN`, `validate_branch()` requires `state.instr <= 0` when `state.noinstr` is set, `state.df == false`, `state.uaccess == func_uaccess_safe(func)`, and `!has_modified_stack_frame(insn, state)` when `func` is non-NULL. Before an `INSN_CALL` or `INSN_CALL_DYNAMIC`, `opts.stackval` validation must exempt calls where `is_special_call(insn)` is true (`dest->fentry` or `dest->embedded_insn`). [F12, F109]
- In `sec->noinstr` sections, calls while `state->instr <= 0` must only target `noinstr` sections, `static_call` trampolines, `__ubsan_handle_*`, or clean `pv_ops` slots, and functions must not return while `state->instr > 0`. Functions in `uaccess_safe_builtin[]` must only call other `uaccess_safe` functions, must not directly execute `CLAC` (unless restoring flags saved via `PUSHF` in an alternative), and must return with `UACCESS` enabled. [F108, F113]
- In `validate_branch()` and `validate_unret()`, `INSN_SYSCALL` must `break` to continue to the next instruction (unless `insn->dead_end`), whereas `INSN_SYSRET` must `return 0`. In `validate_unret()`, `INSN_JUMP_UNCONDITIONAL` and `INSN_JUMP_CONDITIONAL` must check `if (!is_sibling_call(insn))` and fall through to `case INSN_CALL:` when `is_sibling_call(insn)` is true. Every path from `ANNOTATE_UNRET_BEGIN` (`insn->unret`) requires a `retpoline_safe` `INSN_NOP` (`UNTRAIN_RET`), `INSN_SYSRET`, or `dead_end` before any `INSN_RETURN` or dynamic branch. [F71, F72, F114]
- When checking whether two instructions belong to the same logical function (as in `jump_is_sibling_call()` and `add_jump_table()`), compare `sym->pfunc` rather than `sym` so `.cold` subfunctions match their parent. When setting `func->ignore = true` in `add_ignores()`, also set `func->cfunc->ignore = true` if present. In `__dead_end_function()`, stop sibling-call recursion and return `false` when `recursion == 5`. [F38, F70, F81]
- In `add_jump_table_alts()`, all jump table heads in a function must be marked in `mark_func_jump_tables()` before `add_func_jump_tables()` calls `add_jump_table()`, which detects the next table via `if (reloc != table && is_jump_table(reloc)) break;`. [F80]
- In `validate_ibt()`, non-executable sections holding non-indirect-call text references must be listed in the section exclusion filter, except `.discard.ibt_endbr_noseal` which must remain unskipped so `validate_ibt_data_reloc()` marks target `ENDBR` instructions used. [F116]
- `elf_update_symbol()` requires contiguous symbol indices; inserting an `STB_LOCAL` symbol in `__elf_create_symbol()` must relocate the symbol at `symtab->sh.sh_info` to `sec_num_entries(symtab)` and increment `sh_info`, updating its `elf->symbol_hash` node, `symtab`/`symtab_shndx` entry, `old->relocs` (`elf_update_sym_relocs()`), and `old->group_sec->sh.sh_info` in lockstep. When `elf_update_symbol()` over-allocates `Elf_Data` for `.symtab`/`.symtab_shndx`, it must set `sec->truncate = true` and `mark_sec_changed(elf, sec, true)` while `__elf_create_symbol()` advances `sh_size` by one entry for `elf_truncate_section()`. [F31, F32, F61]
- Every `struct reloc` in `rsec` must reside within the contiguous `rsec->relocs` array (`reloc_idx()` uses `reloc - reloc->sec->relocs`). Before inserting `reloc` into `elf->reloc_hash`, both `reloc->sec` and `set_reloc_offset()` must be set. Because `sec_offset_hash()` masks offsets with `OFFSET_STRIDE_MASK` (`~15UL`), `file->insn_hash` and `elf->reloc_hash` must use `sec_offset_hash()`, and `find_reloc_by_dest_range()` must iterate strides via `for_offset_range()`. Relocation addends (`reloc_addend()`, `set_reloc_addend()`, `elf_init_reloc()`) must use `s64` (`PRIx64`), not `int`/`long`. [F34, F55, F58, F86]
- Arch decoding: on x86 `arch_decode_instruction()`, opcodes `0x80`..`0x83` with `op1 & 2` set must sign-extend `u64 imm` via `(s64)imm` shifts before negating for `SUB` and storing into `int op->src.offset`; on LoongArch, bitfield immediates in `decode_insn_reg*_fomat()` must use `sign_extend64()`, and `arch_jump_table_sym_offset()` must subtract `reloc_offset(reloc) - reloc_offset(table)` for `R_LARCH_{32,64}_PCREL`; on PowerPC, `ins & 0x3fffffc` must be sign-extended when `0x2000000` is set and bit `2` (`AA`) masked off (`insn->immediate & ~2`) in `arch_jump_destination()`. [F90, F91, F92, F97]

## Object Lifetimes

- In `decode_sections()`, `init_pv_ops(file)` must run before `decode_instructions(file)` because x86 `arch_decode_instruction()` calls `objtool_pv_add()`, which fails when `opts.noinstr` is enabled and `file->pv_ops` is unallocated. [F6]
- `mark_endbr_used()` must remove referenced `INSN_ENDBR` instructions from `file->endbr_list` using `list_del_init(&insn->call_node)` (not `list_del()`), and `validate_ibt()` must run before `create_ibt_endbr_seal_sections()` so an `INSN_ENDBR` can be referenced by multiple relocations and only unreferenced entries are sealed. [F9]

## API Contracts

- `struct reloc::_sym_next_reloc` packs the next `struct reloc *` and `RELOC_JUMP_TABLE_BIT` in bit 0; always use `sym_next_reloc()`, `set_sym_next_reloc()`, `is_jump_table()`, and `set_jump_table()`. `struct instruction::_call_dest` and `_jump_table` share a union discriminated by `insn->type`; always use `insn_call_dest()`, `insn_jump_table()`, and `insn_jump_table_size()`. [F15, F37]
- For `struct reloc *reloc`, `reloc->sec` is the `SHT_RELA`/`SHT_REL` section, `reloc->sec->base` is the section modified at `reloc_offset(reloc)`, and `reloc->sym->sec` is the target symbol's section; diagnostics and lookups for the relocated site must pass `reloc->sec->base`. [F21]
- Raw relocation entries in `rsec->data->d_buf` must be accessed via `is_32bit_reloc()`, `__get_reloc_field()`, `__set_reloc_field()`, `set_reloc_sym()`, and `set_reloc_type()`. Any mutation to an ELF section header, `Elf_Data` buffer, or relocation entry must call `mark_sec_changed(elf, sec, true)` (or `set_reloc_*()`). [F33, F56]
- Multi-byte integer fields read/written in `SHT_PROGBITS` buffers (`sec->data->d_buf`), such as `hint->sp_offset`, `type` in `read_annotate()`, and `orc->sp_offset`/`orc->bp_offset` in `write_orc_entry()`, must use `bswap_if_needed(elf, val)` with `val` at its exact serialized width (2, 4, or 8 bytes) before widening. [F25, F50]
- `find_symbol_hole_containing(sec, offset)` returns `0` inside a symbol, `-1` when a hole reaches section end, and `> 0` otherwise; store in a signed `int` and handle `0` and `< 0` separately. `elf_add_string()` returns `-1` on failure; check for `-1` before assigning to `sh_name`/`st_name`. [F17, F28]
- In `init_orc_entry(orc, cfi, insn)`, `cfi` can be NULL, so never dereference `cfi` before `if (!cfi)`. `prev_insn_same_sec()`, `prev_insn_same_sym()`, `next_insn_same_sec()`, and `next_insn_same_func()` return NULL at boundaries and must be NULL-checked. [F20, F24]
- Functions that omit frame-pointer setup but still need ORC metadata when `!CONFIG_FRAME_POINTER` must use `STACK_FRAME_NON_STANDARD_FP`, not `STACK_FRAME_NON_STANDARD`. [F107]

## Error Handling

- In `elf_alloc_hash()` and `cfi_hash_alloc()`, `mmap()` failure returns `(void *)-1L` (`MAP_FAILED`) and must be normalized to `NULL` because callers test for `NULL`. [F27]

## External Contracts

- Non-local `__noreturn` C functions must be annotated `__noreturn` across all Kconfig configurations and listed in `tools/objtool/noreturns.h` (and Rust panic symbols matched in `is_rust_noreturn()`) in lockstep. [F46]
- Changes to `.discard.unwind_hints` or `.discard.annotate_insn` layouts must update `UNWIND_HINT`, `__ASM_ANNOTATE`, and `ANNOTATE` in `include/linux/objtool.h`, `struct unwind_hint` in `include/linux/objtool_types.h`, and `read_unwind_hints()` / `read_annotate()` in `tools/objtool/check.c` in lockstep. Assembly `UNWIND_HINT` macros must end with `.balign 4` after the 9 bytes of fields to match the 12-byte `sizeof(struct unwind_hint)`. [F47, F51]
- For every non-empty `.text` section, `orc_create()` must append an `ORC_TYPE_UNDEFINED` terminator at `sec->sh.sh_size` and emit matching entry counts `nr` to `.orc_unwind` and `.orc_unwind_ip`. [F64]

## Known Pitfalls

- `for_each_reloc()` / `for_each_reloc_from()` bound the loop with `__i < sec_num_entries(rsec)` while stepping `reloc++`; any body that also increments `reloc++` (like `get_rodata_table_size_by_table_annotate()`) must check `reloc_idx(reloc) + 1 == sec_num_entries(rsec)`. `get_rodata_table_size_by_table_annotate()` must skip `reloc->sym->sec->rodata` or mismatched section names and reset `table_list` via `list_del_init(&table_list)` across section boundaries. [F75, F76]
- Loops calling `find_reloc_by_dest_range(elf, sec, off, len)` must advance `off` to `reloc_offset(reloc) + 1` and shrink `len` each iteration. In `orc_create()`, after processing `alt_group->cfi`, set `insn = alt_group->last_insn` so `sec_for_each_insn` advances past the `alt_group`. [F77, F79]
- In `get_alt_entry()`, subtract `0x7ffffff0` when `alt->new_off >= 0x7ffffff0` to strip the x86 `_ASM_EXTABLE_EX` bias. In `sec_offset_hash()`, shift via `(offset >> 16) >> 16` rather than `offset >> 32` for ILP32 safety. Keep null/zero/`OPT_END()` sentinels and trailing commas in lookup tables (`entries[]`, `pv_ops_tables[]`, `uaccess_safe_builtin[]`, `global_noreturns[]`, `check_options[]`). [F65, F87, F98]
