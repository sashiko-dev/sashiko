# INTEL ASoC DRIVERS

This unit implements Intel ALSA SoC (ASoC) machine drivers, board helpers (for Bay Trail/Cherry Trail SST, HDA-DSP, I2S/SSP, and SoundWire SOF systems), common ACPI machine match tables and topology helpers, and the Wildcat Point / Lynx Point AudioDSP (`catpt`) platform driver.

## Architecture & Data Flow
- In `sof_board_helpers.c`, `calculate_num_links()` and the `link_order` loop in `sof_intel_board_set_dai_link()` must count and populate the exact same enabled BE links (`idx == num_links`). In `SOF_LINK_ORDER()`, `SOF_LINK_NONE` (0) must only trail active `SOF_LINK_*` entries, and each 4-bit nibble in `ctx->link_id_overwrite` (`SOF_LINK_IDS()`) must be `<= 0xF` and aligned 1:1 with `link_order` because `link_ids` shifts on every iteration. [F37, F81, F82]
- In `snd_soc_acpi_intel_*_sdw_machines` tables, entries with more links in `.link_mask`, more devices in `.links`, or `.machine_check` must precede subset entries, and every `snd_soc_acpi_link_adr` array must end with `{}`. In I2S `snd_soc_acpi_mach` tables, `.machine_quirk` entries must precede generic entries for the same codec, with amp-only boards last. In `soc-acpi-intel-ssp-common.c`, dual-role codec/amps (e.g., `RT5650`) must be in `codecs[]` and at the end of `amps[]`. [F178, F181, F198, F199]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `sof_es8336.c`, codec software node properties must be registered after DMI/`quirk_override` resolution and before `devm_snd_soc_register_card()`, and `MAX_NO_PROPS` sizing `props[MAX_NO_PROPS] = {}` must exceed the maximum `props[cnt++]` assignments on any path by at least 1 to keep the zeroed sentinel. [F42, F64]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, and `cht_bsw_rt5645.c`, SSP0/SSP2 and AIF1/AIF2 quirks must update BE `cpu`/`codec` `dai_name` in `probe`, SSP-to-AIF DAPM routes in `init`, and 16-bit (SSP0) vs 24-bit (SSP2) TDM slot width/BCLK ratio in `be_hw_params_fixup` and `hw_params` in lockstep. In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `bytcr_wm5102.c`, `log_quirks()` must clamp unrecognized multi-bit routing fields from `quirk` (settable via `quirk_override`) to valid defaults before `probe` indexes string arrays. [F53, F57]
- When creating iDisp HDMI links (`sof_board_helpers.c`, `sof_es8336.c`, `sof_pcm512x.c`), `hdmi_id` (`i`) is 1-based (`1..hdmi_num`) for `"iDisp%d"`/`"intel-hdmi-hifi%d"` names and `hdmi_id == 1`, while indexing `idisp_components[i - 1]` 0-based. In `sof_sdw.c`, pass `asoc_sdw_dmic_init` and `sof_sdw_hdmi_init` only on the first DMIC (`"dmic01"`) and HDMI (`i == 0`) links (`NULL` on subsequent links). [F61, F215]
- In SOF `.late_probe` (`sof_rt5682.c`, `sof_nau8825.c`, `sof_da7219.c`), codec/amp setup (e.g., disabling `'Left Spk'`/`'Right Spk'` for `CODEC_MAX98373`) must run before `sof_intel_board_card_late_probe()`. In `max_98373_hw_params()`, `max_98390_hw_params()`, and `rt1011_hw_params()`, loop index `i` must be checked against `ARRAY_SIZE` of the TDM mask table (plus `fls(tx_mask/rx) <= tdm_slots` for 98373), and `max_98373_ops` `name_prefix` must be `<= 11` bytes. [F59, F68, F94]
- In `sof_sdw.c` and `sof_sdw_hdmi.c`, `snd_soc_card_get_drvdata(card)` is `struct asoc_sdw_mc_private *` while `struct intel_mc_ctx *` is in `ctx->private`. In `mc_probe()`, reset `codec_info_list[i].amp_num = 0` before `sof_card_dai_links_create(card)` and do not overwrite `mach_params->dmic_num` (mic channel count for `cfg-mics:%d`) with the DMIC link count. Each DAI link in `sof_sdw.c` must dynamically allocate its own `snd_soc_dai_link_component *platform`. [F162, F174, F175, F229]
- In `catpt`, `catpt_sram_init()` sets inclusive bounds `[start, start + size - 1]`. Runtime `cdev->dram`/`iram` changes must call `catpt_dsp_update_srampge()` to update active-low PCI `VDRTCTL0` bits (`~(new << __ffs(mask)) & mask`, iterating enabled blocks via `for_each_clear_bit_from()`). `catpt_dsp_do_send_msg()` must bound `request.size` and `reply->size` to `ipc->config.outbox_size`. `catpt_stream_volume()`/`catpt_mixer_volume()` must clamp `channel >= CATPT_CHANNELS_MAX` to 0, `ctlvol_to_dspvol()` must clamp `value > DSP_VOLUME_STEP_MAX` to 0, and `dspvol_to_ctlvol()` must check `volume <= DSP_VOLUME_MAX` and `volume != 0` before `__fls()`. [F166, F187, F188, F194, F214, F219]

## Synchronization
- DAI links whose ops sleep must set `.nonatomic = true`: `sof_es8336_ops` in `sof_es8336.c` (`gpiod_set_value_cansleep()`), `max_98373_ops` in `sof_maxim_common.c` (`snd_soc_dapm_*` taking `card->dapm_mutex`), SoundWire links using `sdw_ops` in `sof_sdw.c`, and BYT/CHT front-end DPCM links (`MERR_DPCM_AUDIO`, `MERR_DPCM_DEEP_BUFFER`) on `"sst-mfld-platform"`. [F110, F111, F112, F149]
- In `sof_es8336_probe()` and `sof_pcm512x.c:sof_audio_probe()`, `INIT_LIST_HEAD(&priv->hdmi_pcm_list)`, `INIT_DELAYED_WORK(&priv->pcm_pop_work, ...)`, and `snd_soc_card_set_drvdata()` must run before `devm_snd_soc_register_card()`. [F18]
- In `catpt_dsp_do_send_msg()`, `catpt_ipc_msg_init()` and `catpt_dsp_send_tx()` must run together under `spin_lock_irqsave(&ipc->lock, flags)` before `CATPT_SHIM_IPCC` triggers an IRQ. In `catpt_boot_firmware()`, `reinit_completion(&cdev->fw_ready)` must precede `catpt_dsp_stall(cdev, false)`, and in `catpt_dsp_process_response()`, `catpt_ipc_arm()` must precede `complete(&cdev->fw_ready)`. [F141, F143]
- In `catpt_dsp_irq_handler()` and `catpt_dsp_irq_thread()`, `catpt_dsp_copy_rx()` and `catpt_dsp_process_response()` must finish reading the mailbox and signaling completions before acknowledging `CATPT_IPCC_DONE`/`CATPT_IPCD_DONE` or unmasking `CATPT_IMC_IPCCD`/`CATPT_IMC_IPCDB`. Delayed replies/notifications (`CATPT_ISC_IPCDB`) must be masked in hard IRQ and handled in `catpt_dsp_irq_thread()` because `catpt_dsp_process_response()` and `catpt_dsp_send_msg()`/`catpt_ipc_*` sleep. [F144, F254, F255]

## Object Lifetimes
- Every `struct acpi_device *adev` from `acpi_dev_get_first_match_dev()` must be held until all uses (`acpi_dev_name()`, `acpi_get_first_physical_node()`, `acpi_dev_gpio_irq_get()`, `acpi_fwnode_handle()`) finish, then released with `acpi_dev_put(adev)` on all paths. `acpi_get_first_physical_node()` returns a borrowed `struct device *` whereas `bus_find_device_by_name()` returns an owned reference; drivers storing `priv->codec_dev` from `acpi_get_first_physical_node()` must call `get_device()` and release `priv->codec_dev` with `put_device()` on all subsequent probe error paths (including when `byt_rt5640_add_codec_device_props()` or `byt_rt5651_add_codec_device_props()` fails) and in `.remove`. [F1, F2, F5, F139]
- After `fwnode_create_software_node()` and `device_add_software_node()`, callers must unconditionally call `fwnode_handle_put(fwnode)` before checking `device_add_software_node()`'s return value, and call `device_remove_software_node(priv->codec_dev)` before `put_device(priv->codec_dev)` on subsequent probe errors and in `.remove`. [F3, F96]
- Non-devm GPIOs acquired on `codec_dev` (`spkvdd_en_gpio` in `bytcr_wm5102.c`, `speaker_en_gpio` in `bytcht_es8316.c`, `gpio_speakers` in `sof_es8336.c`) must be released with `gpiod_put()` on probe failure and in `.remove` (never use `devm_gpiod_get(codec_dev, ...)`). In `sof_es8336_remove()`, `cancel_delayed_work_sync(&priv->pcm_pop_work)` must precede `gpiod_put(priv->gpio_speakers)`, `device_remove_software_node()`, and `put_device()`. [F6, F7]
- Codec DAI link `.exit` callbacks (`sof_es8316_exit`, `sof_rt5682_codec_exit`, `da7219_codec_exit`, `sof_cs42l42_exit`, `sof_nau8825_codec_exit`) must call `snd_soc_component_set_jack(component, NULL, NULL)`. Strings assigned to `dai_link->codecs->name` or `card` `.name`/`.long_name`/`.components` must be static or `devm_*`, never stack buffers. [F10, F93]
- In `hda_dsp_hdmi_build_controls()`, `snd_hdac_display_power(..., true)` must be balanced with `snd_hdac_display_power(..., false)` even if `snd_hda_codec_build_controls()` fails. Before `clk_set_rate()` on `mclk` in codec `.init`, cycle `clk_prepare_enable()` and `clk_disable_unprepare()`. On DAPM power-down in `platform_clock_control()`, switch codec sysclk/FLL off MCLK before `clk_disable_unprepare(mclk)`. [F11, F12, F13]
- In `catpt_acpi_remove()`, `pm_runtime_disable(cdev->dev)` must precede `catpt_dmac_remove(cdev)`. Every SRAM child `struct resource` from `catpt_request_region()`/`__request_region()` must be freed via `release_resource(res)` then `kfree(res)` (saving `res->sibling` first in `catpt_sram_free()`). In `catpt_load_block()`, only call `__request_region()` when `alloc` is true, rolling back with `__release_region()` if `catpt_dma_memcpy_todsp()` fails. [F127, F131, F134, F207]

## API Contracts
- `sof_intel_board_get_ctx()` returns `NULL` (not `ERR_PTR`) on failure, and driver-specific `board_quirk` flags passed to it must stay in bits `0..7` (bits `8..31` are reserved for `sof_board_helpers.h`). `SOF_SSP_PORT_CODEC()`, `SOF_SSP_PORT_AMP()`, and `SOF_SSP_PORT_BT_OFFLOAD()` take a 0-based port number (`0..7`), whereas `SOF_SSP_MASK_HDMI_CAPTURE()` takes a 6-bit port bitmask. [F21, F31, F83]
- `sof_intel_board_set_dai_link()` leaves `codecs` and `num_codecs` on `ctx->codec_link` and `ctx->amp_link` for the caller to populate before registering `card`, and any driver calling it or `sof_intel_board_card_late_probe()` must store `struct sof_card_private *` (from `sof_board_helpers.h`) in `card->drvdata`. `sof_dai_get_mclk()`, `sof_dai_get_bclk()`, and `sof_dai_get_tdm_slots()` return `< 0` on error or `0` when unconfigured; callers must use a signed `int` and reject `<= 0`. [F15, F22, F92]
- In `sof_sdw.c:create_sdw_dailinks()`, initialize `intel_ctx->sdw_pin_index[i]` to `SOC_SDW_INTEL_BIDIR_PDI_BASE` and convert `sof_end->link_mask` to a 0-based index via `ffs(sof_end->link_mask) - 1`. Unlike `.machine_quirk` callbacks (`struct snd_soc_acpi_mach *`), `.machine_check` callback `snd_soc_acpi_intel_sdca_is_device_rt712_vb(void *arg)` takes a nullable `struct sdw_intel_ctx *` and returns `bool`. Guard `soc_intel_is_byt_cr()` in `soc-intel-quirks.h` with `#if IS_REACHABLE(CONFIG_IOSF_MBI)`. [F161, F164, F266]
- In `catpt_coredump()`, `dev_coredumpv()` owns the `vzalloc()` buffer (`vfree()` must not be called). Header-only `catpt_ipc_*` messages must zero-initialize `struct catpt_ipc_msg request = { {0}}`. Use `catpt_to_dsp_offset()` for host DRAM offsets sent to DSP in `catpt_ipc_alloc_stream()` and `catpt_to_host_offset()` for `dx_ctx.meminfo[i].offset`. Disable `CATPT_VDRTCTL2_DCLCGE` in `VDRTCTL2` before modifying `VDRTCTL0`/`PMCS` or power-cycling in `catpt_dsp_update_srampge()`, `catpt_dsp_power_down()`, and `catpt_dsp_power_up()`. [F135, F151, F156, F238]
- In `catpt/pcm.c`, 24-bit audio uses 32-bit containers: advertise `SNDRV_PCM_FMTBIT_S32_LE` with `.subformats = SNDRV_PCM_SUBFMTBIT_MSBITS_24 | SNDRV_PCM_SUBFMTBIT_MSBITS_MAX` (never `SNDRV_PCM_FMTBIT_S24_LE`). Call `catpt_ipc_set_write_pos()` only for `CATPT_STRM_TYPE_RENDER` streams with `frames_to_bytes()`, and convert MMIO positions in `catpt_component_pointer()` with `bytes_to_frames()`. [F265, F268]

## Error Handling
- When scanning `snd_soc_dai_link` arrays containing `COMP_DUMMY()` (`byt_rt5640_dais`, `byt_rt5651_dais`, `byt_cht_es8316_dais`, `byt_wm5102_dais`, `cht_dailink`), check `dais[i].num_codecs != 0` before dereferencing `dais[i].codecs->name`. Card `late_probe` callbacks must check `idisp_codec == true` before calling `hda_dsp_hdmi_build_controls()`. [F20, F26]
- In `sof_rt5682.c`, check both `ctx->rt5682.mclk_en` and `ctx->rt5682.is_legacy_cpu` before using `ctx->rt5682.mclk`. In `snd_byt_rt5651_mc_probe()`, reset `ext_amp_gpio`/`hp_detect` to `NULL` on `-ENOENT` from `devm_fwnode_gpiod_get()`; in `snd_byt_wm5102_mc_probe()`, convert `-ENOENT` from `gpiod_get(codec_dev, "wlf,spkvdd-ena", ...)` to `-EPROBE_DEFER`. In `snd_byt_rt5640_mc_probe()` and `snd_byt_rt5651_mc_probe()`, clear `BYT_RT5640_MCLK_EN`/`BYT_RT5651_MCLK_EN` if `devm_clk_get_optional()` returns `NULL`. [F27, F28, F29, F36]
- In `sof_sdw.c` and `sof-function-topology-lib.c`, check all `devm_kasprintf()` calls for `NULL`. In `create_sdw_dailinks()`, initialize `current_be_id = 0` before each `create_sdw_dailink()` call, and check `sof_end->codec_info->add_sidecar` and `sof_end->dai_info->init` for `NULL`. `sof_sdw_get_tplg_files()` must return `0` (not negative errno) when a DAI link is unsupported or a sub-topology file is missing. [F157, F158, F159, F163]
- In `catpt`, `catpt_dsp_send_msg()` and `catpt_ipc_*` return negative errno or positive `enum catpt_reply_status`; callers returning kernel errnos must check `if (ret)` and translate with `CATPT_IPC_ERROR(ret)`. `catpt_request_region()` returns `NULL` on failure and `cdev->scratch` is `NULL` when `scratch_size == 0`, so `catpt_ipc_alloc_stream()` must null-check `scratch`. In `catpt_dma_memcpy()`, check `dma_submit_error()` before `dma_wait_for_async_tx()` and always clear `CATPT_HMDC_HDDA`. [F150, F153, F154]

## External Contracts
- Every `snd_soc_acpi_mach .drv_name` and matching `platform_device_id .name` must be `<= 23` chars (`PLATFORM_NAME_SIZE - 1`). CS35L56 SoundWire ACPI entries must use `"AMPn"` `.name_prefix` strings. When `idisp_codec` is false, iDisp HDMI links in `set_idisp_hdmi_link()`, `sof_pcm512x.c`, and `ehl_rt5660.c` must still be created with `snd_soc_dummy_dlc`. In `catpt`, DMA masks must be `DMA_BIT_MASK(31)` (bits `31:20` address DSP SRAM), `msg.mailbox_address` must be shifted left by 3 in `catpt_dsp_process_response()`, and `catpt_load_module()` must set `type->entry_point = mod->entry_point - 4`. [F118, F184, F221, F223, F233, F259]

## Known Pitfalls
- Verify NHLT link masks are non-zero before `fls(mask) - 1` (`sof_es8336_probe()`, `skl_hda_get_board_quirk()`). In `sof_ssp_amp.c:create_ssp_dailinks()`, use set-bit `i` for `"SSP%d-Codec"`/`"SSP%d Pin"` and sequential counter `j++` for `"i2c-%s:0%d"`. Do not use `BIT(31)` or higher in drivers with signed `int quirk_override = -1` (sign-extends into `unsigned long`), and read `pdev->id_entry->driver_data` before `dmi_check_system()`. In `sof_es8336.c`, `priv->speaker_en` is inverted (`false` = ON, `true` = OFF) due to `active_low = true`. [F75, F84, F85, F98, F211]
- In `catpt`, `catpt_request_region()` requires `catpt_first_boot_firmware()` to have populated `cdev->dram.child` and reserved the tail `[res->end + 1, cdev->dram.end]`. In `catpt_dsp_set_srampge()`, ungating SRAM blocks in `VDRTCTL0` requires `udelay(60)` and a 4-byte dummy `memcpy_fromio()` from each newly enabled `CATPT_MEMBLOCK_SIZE` block. Both `catpt_dsp_power_down()` and `catpt_dsp_power_up()` must call `catpt_dsp_set_regs_defaults(cdev)`. [F205, F237, F239]
