# BROADCOM B53/SF2 ETHERNET SWITCH DRIVER

This unit implements DSA drivers for Broadcom RoboSwitch (`b53_common.c` and bus glues `b53_mdio.c`, `b53_mmap.c`, `b53_spi.c`, `b53_srab.c`, plus SerDes PCS `b53_serdes.c`) and Starfighter 2 SoC switches (`bcm_sf2.c`, `bcm_sf2_cfp.c`), managing VLANs, ARL tables, bridging, phylink, integrated GPHY/MDIO, Wake-on-LAN, and CFP TCAM rules.

## Architecture & Data Flow

- `b53_vlan_add()` and `b53_vlan_del()` must always update software shadows `dev->vlans[vlan->vid]` and `dev->ports[port].pvid` before returning early when `!dev->vlan_filtering`, and only program hardware VLAN entries and `B53_VLAN_PORT_DEF_TAG` when `dev->vlan_filtering` is true. When `b53_vlan_add()` is called without `BRIDGE_VLAN_INFO_PVID` on a VLAN matching `dev->ports[port].pvid`, it must reset `pvid` to `b53_default_pvid(dev)`, write `B53_VLAN_PORT_DEF_TAG(port)` if `vlan_filtering` is enabled on a non-CPU port, and fast-age `old_pvid` (never `vlan->vid` or `new_pvid`). [F44, F45, F84]
- Always index the default untagged VLAN entry in `dev->vlans[]` by `b53_default_pvid(dev)` rather than `0` (BCM5325/5365 use 1; others use 0). When `dev->vlan_filtering` is true, `b53_br_join()` must clear `BIT(port)` and `b53_br_leave()` must set `BIT(port)` in `dev->vlans[b53_default_pvid(dev)]` (and hardware) and, on `is58xx(dev)`, in `B53_JOIN_ALL_VLAN_EN`, while preserving the CPU port bit and `vl->untag`. [F47, F63]
- Per-port bridge forwarding masks in `B53_PVLAN_PORT_MASK(port)` must be shadowed in `dev->ports[port].vlan_ctl_mask` by `b53_br_join()`/`b53_br_leave()`, and `b53_enable_port()` must OR `vlan_ctl_mask` with `BIT(port)` and call `b53_imp_vlan_setup()`. In `b53_br_leave()`, clearing `BIT(i)` from `pvlan` inside `b53_for_each_port(dev, i)` must be guarded by `if (port != i)` so `port` keeps its own isolation bit. [F48, F95]
- Initial standalone port attributes (unicast/multicast flooding, learning disabled, and `EAP_MODE_SIMPLIFIED` via `b53_set_eap_mode()`) must be configured in `b53_setup_port()` (with EAP mode toggled between `EAP_MODE_BASIC` in `b53_br_join()` and `EAP_MODE_SIMPLIFIED` in `b53_br_leave()`), and never reset in `b53_enable_port()`. [F49]
- `bcm_sf2_sw_set_wol()` must keep `BIT(cpu_port)` set in `priv->wol_ports_mask` whenever any user port has WoL enabled and clear it when the last user port is cleared. When a port's bit is set in `priv->wol_ports_mask`, `bcm_sf2_port_disable()` must only set `BIT(port)` in `CORE_DIS_LEARN` and return without disabling the port, GPHY, or TXQ memory, `bcm_sf2_sw_mac_link_down()` must return early, `bcm_sf2_sw_suspend()`/`bcm_sf2_sw_resume()` must both gate `priv->clk` disable/enable on `!priv->wol_ports_mask`, and `bcm_sf2_sw_remove()` must clear `priv->wol_ports_mask = 0` before `dsa_unregister_switch()`. [F8, F56, F118]
- In `bcm_sf2_cfp.c`, TCAM rule index `0` is permanently reserved (`used` and `unique` bit 0 set in `bcm_sf2_sw_probe()`); valid user locations are `1 .. bcm_sf2_cfp_rule_size(priv)` (`priv->num_cfp_rules - 1`), and `priv->num_cfp_rules` must not exceed `CFP_NUM_RULES` (256). Callers of `bcm_sf2_cfp_rule_addr_set()` on user-supplied indices must first check `index <= bcm_sf2_cfp_rule_size(priv)`. [F72, F109, F145]
- In `bcm_sf2_cfp_ipv6_rule_set()`, slice 0 (`rule_index[0]`) is marked only in `priv->cfp.used`, while chained slice 1 (`rule_index[1]`, returned in `fs->location`) is marked in both `used` and `unique`; `bcm_sf2_cfp_rule_remove()` must follow `CHAIN_ID_MASK` in `CORE_CFP_DATA_PORT(6)` to delete both slices. In `bcm_sf2_cfp_rule_get_all()`, iterate `priv->cfp.unique` with `for_each_set_bit_from(index, ..., priv->num_cfp_rules)` starting at `index = 1` and index `rule_locs[rules_cnt]` with a separate `rules_cnt` counter. [F59, F94]
- `struct cfp_rule::fs` in `priv->cfp.rules_list` must keep un-inverted flow masks from `ETHTOOL_SRXCLSRLINS` for `bcm_sf2_cfp_rule_cmp()` and `bcm_sf2_cfp_resume()`, so `bcm_sf2_cfp_rule_get()` must copy `rule->fs` into `nfc->fs` before calling `bcm_sf2_invert_masks(&nfc->fs)`. In `bcm_sf2_cfp_get_ethtool_stats()`, compute the output index as `iter = (i - 1) * s + j` rather than `iter++`, because the loop skips unused rule indices while `bcm_sf2_cfp_get_strings()` emits strings for all `1 .. priv->num_cfp_rules - 1`. [F61, F93]
- Because `b53_mdio_op()` caches `dev->current_page` and `b53_serdes_set_lane()` caches `dev->serdes_lane`, `b53_mdio_probe()` and `b53_switch_reset_gpio()` must set `dev->current_page = 0xff`, and `b53_reset_switch()` must set `priv->serdes_lane = B53_INVALID_LANE`. After `b53_flush_arl()` polls until `FAST_AGE_DONE` clears on `B53_FAST_AGE_CTRL`, it must write `FAST_AGE_DYNAMIC` back to `B53_FAST_AGE_CTRL`. [F50, F51]
- In `bcm_sf2_port_setup()` and `bcm_sf2_port_disable()`, update `priv->port_sts[port].enabled` before calling `bcm_sf2_recalc_clock(ds)` so `bcm_sf2_num_active_ports(ds)` sees the new count when scaling `priv->clk_mdiv`. Loops in `bcm_sf2.c` that call DSA port helpers (`dsa_is_cpu_port()`, `dsa_is_user_port()`, `dsa_to_port()`) must bound `port` by `ds->num_ports` (or `priv->hw_params.num_ports`), not `DSA_MAX_PORTS` / `ARRAY_SIZE(priv->port_sts)`. [F55, F66]
- In `b53_switch_init()`, `dev->num_ports` and `dev->ports` must be sized with `fls(dev->enabled_ports)` rather than `hweight16(dev->enabled_ports)`, because `dev->ports` is indexed by physical port number across sparse bitmasks. `struct dsa_chip_data cd` must remain the first field of `struct b53_platform_data`, and the six `__iomem` pointers (`core`..`acb`) in `struct bcm_sf2_priv` must remain contiguous and ordered to match `BCM_SF2_REGS_NAME`. [F43, F106]
- In `b53_mmap.c`, `priv->gpio_ctrl` can be an `ERR_PTR`, so `b53_mmap_phy_enable()`/`b53_mmap_phy_disable()` must check `if (priv->phy_info)` before calling `bcm63xx_ephy_set()` or `bcm63268_gphy_set()`, and must verify `BIT(port) & priv->phy_info->ephy_port_mask` before `bcm63xx_ephy_set()` indexes `ephy_offset[port]`. When disabling an EPHY port in `bcm63xx_ephy_set()`, only set the shared bias disable bit `BIT(info->ephy_bias_bit)` in `BCM63XX_EPHY_REG` if no other EPHY ports remain enabled in `(priv->phys_enabled & ~BIT(port)) & info->ephy_port_mask`. [F37, F75, F126]

## Synchronization

- All `struct b53_io_ops` register accesses must go through `b53_read{8,16,32,48,64}` / `b53_write{8,16,32,48,64}`, which acquire the sleeping mutex `dev->reg_mutex` and invoke callbacks that may sleep; never call `dev->ops->read*`/`write*` directly, never call `b53_read*`/`b53_write*` inside a `b53_io_ops` callback, and never call them or `b53_port_event()` from hardirq context. All ARL helpers (`b53_arl_op*`, `b53_arl_read*`, `b53_arl_search*`) require `dev->arl_mutex`, which nests outside `dev->reg_mutex`. [F17, F130, F132]
- In `bcm_sf2`, 64-bit `priv->core` accesses must use `core_readq`/`core_writeq` (which acquire `priv->indir_lock` via `spin_lock` to serialize the shared `REG_DIR_DATA_READ`/`REG_DIR_DATA_WRITE` upper-word latches with `core_readl`/`core_writel`) and must not run in hardirq context (`bcm_sf2_switch_0_isr`/`bcm_sf2_switch_1_isr`). `intrl2_{0,1}_mask_clear` must clear bits in `priv->irq{0,1}_mask` before writing `INTRL2_CPU_MASK_CLEAR`, while `intrl2_{0,1}_mask_set` must write `INTRL2_CPU_MASK_SET` before setting `priv->irq{0,1}_mask`. [F19, F21]
- In `bcm_sf2_cfp.c`, `priv->cfp.lock` must be held across all runtime accesses to CFP indirect registers (`CORE_CFP_ACC`, `CORE_CFP_DATA_PORT`, `CORE_CFP_MASK_PORT`) and CFP rule state (`used`, `unique`, `rules_list`), and must be released before calling `p->ethtool_ops->get_rxnfc` or `set_rxnfc`. [F20]
- MDIO accesses inside `b53_mdio_ops` (`b53_mdio.c`) and `bcm_sf2_sw_mdio_{read,write}` (`bcm_sf2.c`) must use `mdiobus_read_nested()` and `mdiobus_write_nested()` because they execute under slave `user_mii_bus` callbacks that already hold `user_mii_bus->mdio_lock`. [F135]

## Object Lifetimes

- Across all B53/SF2 bus drivers (`b53_mdio`, `b53_mmap`, `b53_spi`, `b53_srab`, `bcm_sf2`), `.shutdown` must clear device drvdata to `NULL` after calling `b53_switch_shutdown()`/`dsa_switch_shutdown()`, and both `.remove` and `.shutdown` must return early if drvdata is `NULL`. [F5]
- In `bcm_sf2_sw_probe()` and `bcm_sf2_sw_remove()`, order setup and teardown strictly: `clk_prepare_enable(priv->clk)` then `priv->clk_mdiv` (checking both return values), `bcm_sf2_gphy_enable_set(ds, true)` before `bcm_sf2_mdio_register(ds)`, and `bcm_sf2_intr_disable(priv)` before `devm_request_irq()`. On remove/error, disable IRQs before `dsa_unregister_switch()`, then call `bcm_sf2_cfp_exit()`, `bcm_sf2_mdio_unregister(priv)`, `clk_disable_unprepare(priv->clk_mdiv)`, and `clk_disable_unprepare(priv->clk)`. `bcm_sf2_sw_shutdown()` must also call `bcm_sf2_gphy_enable_set(ds, true)` when `num_gphy == 1`. [F6, F29, F112, F113]
- In `bcm_sf2_mdio_register()`, when `of_phy_find_device(child)` returns a non-NULL `phydev` to unregister, call both `phy_device_remove(phydev)` and `phy_device_free(phydev)`. Release `dn` from `of_find_compatible_node()` with `of_node_put(dn)`, and release `priv->master_mii_bus->dev` (`put_device()`) and `priv->user_mii_bus` in `bcm_sf2_mdio_unregister()` and on error paths. In `bcm_sf2_sw_probe()`, call `of_node_get(dn)` before `of_find_node_by_name(dn, "ports")` and `of_node_put(ports)` afterward. [F3, F4, F114]
- In `b53_srab.c`, every `b53_srab_read*`/`b53_srab_write*` accessor that calls `b53_srab_request_grant(dev)` must call `b53_srab_release_grant(dev)` on all paths, including when `b53_srab_request_grant()` or `b53_srab_op()` fails. Set `p->irq_enabled = true` in `b53_srab_irq_enable()` only when `p->irq != -ENXIO` and `request_threaded_irq()` succeeds, and check `p->irq_enabled` in `b53_srab_irq_disable()` before calling `free_irq(p->irq, p)` and clearing `p->irq_enabled = false`. [F9, F10]
- In `bcm_sf2_cfp.c`, `bcm_sf2_cfp_ipv6_rule_set()` reserves `rule_index[1]` via `set_bit(rule_index[1], priv->cfp.used)` before searching for `rule_index[0]` and must roll it back with `clear_bit()` on any subsequent error. `bcm_sf2_cfp_rule_remove()` only clears hardware TCAM entries and `used`/`unique` bits (so `bcm_sf2_cfp_resume()` can re-insert rules in place), whereas `bcm_sf2_cfp_rule_del()` and `bcm_sf2_cfp_exit()` (which must iterate `rules_list` with a `_safe` macro) also `list_del(&rule->next)` and `kfree(rule)`. [F11, F12, F89]

## API Contracts

- `b53_read*`/`b53_write*` take `(dev, page, reg, ...)` with page second and register offset third. In `bcm_sf2`, `core_writel`, `reg_writel`, `intrl2_{0,1}_writel`, `fcb_writel`, `acb_writel`, and `core_writeq` take `(priv, val, off)` with value second and offset third. `reg_readl()`/`reg_writel()` take an `enum bcm_sf2_reg_offs` index into `priv->reg_offsets[]` (not a raw byte offset), and callers must resolve per-port RGMII/LED indices via `bcm_sf2_reg_rgmii_cntrl()` and `bcm_sf2_reg_led_base()` or guard by `priv->type`. [F25, F26, F69]
- In `bcm_sf2.c`, `ds->priv` points to `struct b53_device` (use `bcm_sf2_to_priv(ds)` to get `struct bcm_sf2_priv *`), whereas `pdev->dev` drvdata (`dev_get_drvdata` / `platform_get_drvdata`) points directly to `struct bcm_sf2_priv` (unlike `b53_mmap`/`srab`/`mdio`/`spi`, where drvdata is `struct b53_device *`). `b53_switch_alloc()` returns `NULL` on failure (not an `ERR_PTR`), and optional `b53_io_ops` callbacks (`phy_*`, `irq_*`, `phylink_*`, `serdes_*`) must be NULL-checked before invocation. [F30, F35, F105]
- On `BCM5325_DEVICE_ID` and `BCM5365_DEVICE_ID`, the DSA CPU port index `B53_CPU_PORT_25` (5) must be remapped to hardware port index `B53_CPU_PORT` (8) when accessing `B53_PVLAN_PORT_MASK`, `B53_PORT_CTRL`, `B53_IEEE_UCAST_DLF`, `B53_IEEE_MCAST_DLF`, or (on 5365) `B53_MIB_PAGE`. [F41]
- `b53_setup()` must set `ds->untag_vlan_aware_bridge_pvid = true` and `b53_vlan_add()` must force `untagged = false` on CPU ports; when `dev->tag_protocol == DSA_TAG_PROTO_NONE`, `b53_setup()` must also set `ds->untag_bridge_pvid = true` and `b53_vlan_port_needs_forced_tagged()` must return true for CPU ports. On `BCM7278_DEVICE_ID`, port 7 must be rejected with `-EINVAL` in `b53_br_join()` and in `b53_vlan_prepare()` when `!(vlan->flags & BRIDGE_VLAN_INFO_UNTAGGED)`. [F137, F138, F143]
- In `b53_mmap.c`, `b53_mmap_read48()`/`b53_mmap_write48()` require `reg % 2 == 0` and must split into 16-bit low at `reg` + 32-bit high at `reg + 2` when `reg % 4 != 0`, or 32-bit low at `reg` + 16-bit high at `reg + 4` when `reg % 4 == 0`. [F77]

## Error Handling

- `b53_change_mtu()` must return `0` before calling `b53_set_jumbo()` when `is5325(dev) || is5365(dev)` or `!dsa_is_cpu_port(ds, port)`, because `b53_set_jumbo()` returns `-EINVAL` on BCM5325/5365. In `bcm_sf2_get_rxnfc()` and `bcm_sf2_set_rxnfc()`, normalize `-EOPNOTSUPP` from `p->ethtool_ops->get_rxnfc` or `set_rxnfc` to `0`, and on any other `set_rxnfc` error, roll back the switch rule via `bcm_sf2_cfp_rule_del()` under `priv->cfp.lock`. [F28, F33]

## External Contracts

- `b53_get_max_mtu()` and `b53_change_mtu()` operate on L3 payload MTU (comparing `mtu > ETH_DATA_LEN` and subtracting `ETH_HLEN + VLAN_HLEN + ETH_FCS_LEN` from max frame size), whereas `dev->jumbo_size_reg` in `b53_set_jumbo()` takes full frame sizes (`JMS_MIN_SIZE` or `JMS_MAX_SIZE`). [F27]
- `b53_vlan_prepare()` must reject `vlan->vid >= dev->num_vlans` with `-ERANGE` (and `vlan->vid == 0` on BCM5325/5365 with `-EOPNOTSUPP`) before `b53_vlan_add()` indexes `dev->vlans[vlan->vid]`. Device Tree port `reg` properties must be validated against `< B53_N_PORTS` in `b53_mmap_probe_of()` and `< DSA_MAX_PORTS` in `bcm_sf2_identify_ports()` before bit-shifting or array indexing. [F64, F67]
- In `bcm_sf2_cfp_rule_insert()`, after validating `port_num = ring_cookie / SF2_NUM_EGRESS_QUEUES` against `< priv->hw_params.num_ports` and calling `port_vlan_add()`, decrement `port_num` by 1 when `port_num >= 7` before calling `bcm_sf2_cfp_act_pol_set()` (port 6 has no bit in `DST_MAP_IB`). [F74]

## Known Pitfalls

- When modifying `B53_PD_MODE_CTRL_25` on BCM5325 in `b53_setup_port()`, only ports 1..4 may be toggled and `PD_MODE_POWER_DOWN_PORT(0)` (`BIT(0)`) must be cleared because bit 0 powers down the entire switch. In `bcm_sf2_port_intr_enable()`/`disable()`, handle ports 0 and 7 with `P0_IRQ_OFF` and `P7_IRQ_OFF`; `P_IRQ_OFF(port)` (`(6 - port) * P_NUM_IRQ`) is only valid for ports 1..6. [F52, F101]
- In `bcm_sf2_cfp_rule_find()`, return a matching `rule` directly inside `list_for_each_entry()` and `NULL` after the loop (never test the loop cursor for `NULL` after the loop). In `bcm_sf2_cfp_rule_cmp()`, reset `ret = 1` at the start of every iteration before any `continue`, `break` immediately when `ret == 0`, and set `fs_size` to the specific spec struct size (`sizeof(struct ethtool_tcpip4_spec)` or `sizeof(struct ethtool_tcpip6_spec)`) rather than `sizeof(fs->h_u)`. [F88, F90, F111]
- Cast narrower operands to `u64` before left-shifting in 64-bit ARL/EAP helpers (`ent->vid`, `ent->port`, `mode` in `b53_arl_from_entry`, `b53_arl_from_entry_25`, `b53_set_eap_mode`) and in 48/64-bit split register readers (`b53_mmap_read48`/`64`, `b53_srab_read48`/`64`, `SF2_IO64_MACRO`). In `b53_spi_write48()`, `txbuf` must be at least 10 bytes so `put_unaligned_le64(value, &txbuf[2])` does not overflow the stack buffer. [F96, F97, F107]
- In `bcm_sf2_sw_rst()`, `BCM7278_DEVICE_ID` must be reset via `priv->rcdev` (`reset_control_assert`/`deassert`) rather than `CORE_WATCHDOG_CTRL`. In `b53_switch_reset()`, `B53_SOFTRESET` must only be used on `BCM58XX_DEVICE_ID` or `BCM583XX_DEVICE_ID` (never `is58xx(dev)`). In `b53_brcm_hdr_setup()`, do not access `B53_BRCM_HDR` on `DSA_TAG_PROTO_BRCM_LEGACY`/`DSA_TAG_PROTO_BRCM_LEGACY_FCS`, and only access `B53_BRCM_HDR_RX_DIS`/`B53_BRCM_HDR_TX_DIS` when `is58xx(dev)` is true. [F117, F128]
- On `is63xx(dev)`, RGMII configuration in `b53_phylink_mac_config()`, `b53_phylink_get_caps()`, and `b53_adjust_63xx_rgmii()` must be restricted to `in_range(port, B53_63XX_RGMII0, 4)` (never touching `B53_RGMII_CTRL_IMP` on port 8) and must clear `RGMII_CTRL_DLL_RXC | RGMII_CTRL_DLL_TXC`. In `b53_adjust_531x5_rgmii()`, only set `RGMII_CTRL_TIMING_SEL` when `dev->chip_id != BCM53115_DEVICE_ID`. [F119, F120]
