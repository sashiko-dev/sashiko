# WORKQUEUE

The workqueue subsystem (`kernel/workqueue.c`, `include/linux/workqueue.h`, `kernel/workqueue_internal.h`) provides the Linux kernel's generic asynchronous execution mechanism in process and bottom-half (softirq) contexts, managing per-CPU, BH, and unbound `worker_pool` instances, `worker` and `rescuer` kthreads, and `pool_workqueue` intermediaries.

## Architecture & Data Flow

- `work->data` is discriminated by `WORK_STRUCT_PWQ`: upper bits hold an unshifted `struct pool_workqueue *` (requiring `1 << WORK_STRUCT_PWQ_SHIFT` alignment on `struct pool_workqueue`) when `WORK_STRUCT_PWQ` is set, and hold off-queue pool ID, disable depth, and `WORK_OFFQ_*` flags when clear. When modifying off-queue `work->data` (`clear_pending_if_disabled()`, `__cancel_work()`, `enable_work()`), unpack with `work_offqd_unpack()` and repack with `set_work_pool_and_clear_pending()` and `work_offqd_pack_flags()` to preserve `pool_id`, `disable`, and `WORK_OFFQ_BH`. [F46, F77, F80]
- Initialize `work_struct.data` with `WORK_DATA_INIT()` / `WORK_DATA_STATIC_INIT()` (`WORK_STRUCT_NO_POOL`), never `0` (`0` is a valid pool ID). `worker_pool_assign_id()` must allocate IDs `< WORK_OFFQ_POOL_NONE`. Widen operands to `unsigned long` (`1ul`) before shifting by `WORK_OFFQ_POOL_SHIFT` or `WORK_OFFQ_DISABLE_SHIFT` in `set_work_pool_and_*()`, `work_offqd_pack_flags()`, and `WORK_OFFQ_*`. [F53, F81, F113]
- Pseudo-workers for BH pools (`pool->flags & POOL_BH`) have `worker->task == NULL` and execute in softirq (`in_atomic()`) context; shared paths (`create_worker()`, `process_one_work()`, `kick_pool()`) must guard `worker->task` dereferences, and `process_one_work()` must gate both the post-execution `in_atomic()` check and `cond_resched()` on `worker->task != NULL`. [F48, F142]
- In `struct worker`, `entry` (idle list) and `hentry` (busy hash) share an anonymous union discriminated by `WORKER_IDLE`: call `hash_del(&worker->hentry)` before `worker_enter_idle()`, and `worker_leave_idle()` before `hash_add(pool->busy_hash, &worker->hentry, ...)`. [F47]
- Mutations to `WORKER_NOT_RUNNING` flags (`WORKER_PREP`, `WORKER_CPU_INTENSIVE`, `WORKER_UNBOUND`, `WORKER_REBOUND`) on attached workers must use `worker_set_flags()` / `worker_clr_flags()` under `pool->lock` (except in `unbind_workers()`/`rebind_workers()`), which only adjust `pool->nr_running` when transitioning between zero and non-zero `WORKER_NOT_RUNNING` masks. In `process_one_work()`, unconditionally clear `WORKER_CPU_INTENSIVE` via `worker_clr_flags()` after the callback, and copy `worker->current_func` to `worker->last_func` under `pool->lock` before clearing `worker->current_func`. [F65, F67, F68, F95]
- In `wq_worker_sleeping()`, check `worker->flags & WORKER_NOT_RUNNING` before reading `worker->pool` or `worker->current_pwq`, because detached rescuer kthreads have `PF_WQ_WORKER` and `WORKER_PREP` set while `worker->pool == NULL`. [F49]
- In `__queue_work()`, when `req_cpu == WORK_CPU_UNBOUND`, only call `wq_select_unbound_cpu()` if `wq->flags & WQ_UNBOUND` (otherwise use `raw_smp_processor_id()`), and skip `last_pool` non-reentrancy redirection when `wq->flags & __WQ_ORDERED`. For `__WQ_ORDERED` workqueues, `apply_wqattrs_prepare()` must set `ctx->dfl_pwq->plugged = true` when `!list_empty(&wq->pwqs)`, and `pwq_release_workfn()` must call `unplug_oldest_pwq(wq)` when removing a PWQ from a non-empty `wq->pwqs`. [F78, F92, F93]
- Write concurrency limits to `wq->saved_max_active` and `wq->saved_min_active` under `wq->mutex` (clamping `wq->saved_min_active` to `max_active` in `workqueue_set_max_active()` on `WQ_UNBOUND` workqueues), then call `wq_adjust_max_active(wq)`. Look up `wq->node_nr_active[]` (allocated only for `WQ_UNBOUND` with `nr_node_ids + 1` entries) via `wq_node_nr_active(wq, node)`. [F71, F72, F83]
- For shared unbound pools (`init_worker_pool()`, `get_unbound_pool()`), normalize `pool->attrs` via `wqattrs_clear_for_pool()`, ignore workqueue-only fields (`affn_scope`, `ordered`, and `cpumask` when `affn_strict`) in `wqattrs_hash()` / `wqattrs_equal()`, and pass `BITS_TO_LONGS(nr_cpumask_bits) * sizeof(long)` to `jhash()` in `wqattrs_hash()`. Bind `WQ_UNBOUND` `wq->rescuer->task` to `unbound_effective_cpumask(wq)` in both `init_rescuer()` and `apply_wqattrs_commit()`. [F73, F75, F123]
- `struct delayed_work` timers must be initialized with `TIMER_IRQSAFE` so `delayed_work_timer_fn()` runs with local IRQs disabled and `timer_delete()` in `try_to_grab_pending()` guarantees the timer is not running on the local CPU. [F138]

## Synchronization

- In `set_work_pool_and_clear_pending()`, `smp_wmb()` must precede `set_work_data()` and `smp_mb()` must follow it so updates to `work` are visible to the next `PENDING` owner and clearing `WORK_STRUCT_PENDING` is not reordered into `worker->current_func()`. Any path that sets `WORK_STRUCT_PENDING_BIT` and calls `__queue_work()`, `__queue_delayed_work()`, or clears it in `__cancel_work()` / `enable_work()` must keep local IRQs disabled while `work` is `PENDING` and off-queue. [F18, F137]
- `get_work_pool()` and `for_each_pool()` require `rcu_read_lock()` or `wq_pool_mutex`; `for_each_pwq()` requires `rcu_read_lock()` or `wq->mutex`. After locking `pool->lock`, `try_to_grab_pending()` and `start_flush_work()` must re-read `get_work_pwq(work)` and verify `pwq->pool == pool` (or `find_worker_executing_work(pool, work)`). In `__queue_work()`, if `pwq->refcnt == 0` under `pool->lock` on a `WQ_UNBOUND` workqueue after RCU lookup, drop `pool->lock` and `goto retry`. [F23, F155, F158]
- `wq_node_nr_active->lock` (`nna->lock`) nests inside `worker_pool->lock`. In `node_activate_pending_pwq()`, track the held lock in `locked_pool`; if `raw_spin_trylock(&locked_pool->lock)` fails when switching pools, drop `nna->lock` before `raw_spin_lock(&locked_pool->lock)` and re-read `nna->pending_pwqs` at `retry:`; at `out_unlock:`, restore `caller_pool->lock` if `locked_pool != caller_pool`. In `pwq_tryinc_nr_active()`, after queueing `pwq->pending_node` under `nna->lock`, execute `smp_mb()` and retry `tryinc_node_nr_active(nna)`; pass `fill = true` to `pwq_activate_first_inactive()` in `wq_adjust_max_active()` and `unplug_oldest_pwq()`. [F20, F21, F104, F110]
- `put_pwq()` runs under `pwq->pool->lock` and must queue `pwq->release_work` on `pwq_release_worker` rather than tearing down inline. `put_unbound_pool()` must wait on `manager_wait` for `!(pool->flags & POOL_MANAGER_ACTIVE)` before taking `wq_pool_attach_mutex` and `pool->lock`, releasing both to wait again if set on recheck. [F151, F152]
- `POOL_DISASSOCIATED` and `PF_WQ_WORKER` must only be modified under `wq_pool_attach_mutex` (which also serializes worker attach/detach, `idle_cull_fn()`, and `wq_worker_comm()`). Modifying `wq_unbound_cpumask` requires both `wq_pool_mutex` and `wq_pool_attach_mutex`. Never take `cpus_read_lock()` inside `apply_wqattrs_lock()`, `__alloc_workqueue()`, `apply_workqueue_attrs()`, or inside `wq_pool_mutex`. [F33, F149, F153, F169]
- In `rebind_workers()`, restore worker CPU affinity before taking `pool->lock` to clear `POOL_DISASSOCIATED`, and replace `WORKER_UNBOUND` with `WORKER_REBOUND` via `WRITE_ONCE(worker->flags, ...)`. `wq_worker_running()` must disable preemption around checking `!(worker->flags & WORKER_NOT_RUNNING)` and incrementing `pool->nr_running`, and `workqueue_offline_cpu(cpu)` must run `unbind_workers(cpu)` on `cpu` itself. [F32, F146]
- Once `worker_thread()` sees `WORKER_DIE` and drops `pool->lock`, it must not touch `worker->entry` (`reap_dying_workers()` modifies it locklessly). In `maybe_create_worker()`, after `create_worker(pool)` or deleting `mayday_timer` and re-locking `pool->lock`, recheck `need_to_create_worker(pool)` and loop to `restart` if true. [F28, F38]
- In `kick_bh_pool()`, if `pool->cpu != smp_processor_id()` and `!(pool->flags & POOL_BH_DRAINING)`, queue `bh_pool_irq_work(pool)` on `pool->cpu` instead of `raise_softirq_irqoff()`. `bh_worker()` must call `kick_pool(pool)` after `worker_enter_idle()`. In `drain_dead_softirq_workfn()`, set `POOL_BH_DRAINING` and re-test `need_more_worker(pool)` to requeue `work` if needed. [F107, F140, F141]
- When canceling `WORK_OFFQ_BH` items, `__cancel_work_sync()` must check `WARN_ON_ONCE(in_hardirq())` instead of `might_sleep()`, and `__flush_work()` must busy-wait with `try_wait_for_completion()` and `workqueue_callback_cancel_wait_running()`. In `__flush_work()`, reading `*work_data_bits(work)` outside `pool->lock` after `start_flush_work()` is only valid when `from_cancel` is true. [F25, F143]
- Wrap `WQ_BH` lockdep acquisitions in `local_bh_disable()`/`local_bh_enable()` in `touch_wq_lockdep_map()` and `touch_work_lockdep_map()`, and use separate keys (`bh_key` vs `thr_key`) in `insert_wq_barrier()`. In `start_flush_work()`, call `touch_work_lockdep_map()` unconditionally, but skip `check_flush_dependency()` and `touch_wq_lockdep_map()` when `from_cancel` is true. [F144, F145]
- Hold `pool->lock` when updating `pwq->stats[]` in `process_one_work()`, unlock cached `current_pool->lock` on pool changes and exit in `flush_workqueue_prep_pwqs()`, wrap `printk` / state dumps under `pool->lock` in `printk_deferred_enter()`/`printk_deferred_exit()`, and check `in_task() && (current->flags & PF_WQ_WORKER)` in `current_wq_worker()`. [F26, F105, F139, F154]

## Object Lifetimes

- Because a work callback may free its own `work_struct`, `process_one_work()` must copy `work->lockdep_map` to the stack and call `set_work_pool_and_clear_pending()` before `worker->current_func(work)`, never dereferencing `work` afterwards. Both `try_to_grab_pending()` and `process_one_work()` must snapshot `work_data` before overwriting `work->data` and call `pwq_dec_nr_in_flight(pwq, work_data)` as the final step under `pool->lock` (it drops the `pwq` ref and may drop/retake `pool->lock`). [F8, F15]
- In `rescuer_thread()`, sample `kthread_should_stop()` before taking `wq_mayday_lock`, drain all `wq->maydays` entries before exiting, and only call `put_pwq_unlocked(pwq)` after `worker_detach_from_pool(rescuer)` has detached from `pwq->pool`. [F1, F108]
- Clear `worker->pool = NULL` only in the worker's own thread (`worker_detach_from_pool()` or `worker_thread()` after `set_pf_worker(false)`), never in `detach_worker()`. `set_worker_dying()` must call `get_task_struct(worker->task)` under `pool->lock`, paired with `kthread_stop_put(worker->task)` in `reap_dying_workers()`. [F2, F3]
- In `pwq_release_workfn()`, only access `pwq->wq->mutex` and `pwq->wq->pwqs` when `!list_empty(&pwq->pwqs_node)`. In `destroy_workqueue()`, call `workqueue_sysfs_unregister(wq)` before setting `__WQ_DESTROYING` or draining, remove `wq->list` under `wq_pool_mutex` only after `drain_workqueue(wq)`, and hold `rcu_read_lock()` while putting base `unbound_pwq()` references after dropping `wq_pool_mutex`. [F4, F133, F136, F156]
- `apply_wqattrs_commit()` swaps `ctx->dfl_pwq` and `ctx->pwq_tbl[]` in-place with displaced old PWQs, so callers of `apply_wqattrs_prepare()` must always call `apply_wqattrs_cleanup(ctx)`. `__cancel_work_sync()` passes `WORK_CANCEL_DISABLE` to `__cancel_work()`, so when `!(cflags & WORK_CANCEL_DISABLE)` it must call `enable_work(work)` after `__flush_work()`. Initialize on-stack work items with `INIT_WORK_ONSTACK*()`, await completion, and call `destroy_work_on_stack()`. [F6, F11, F128]

## API Contracts

- `try_to_grab_pending()` returns `1` (stole pending), `0` (claimed idle), or `-EAGAIN` (busy); on `>= 0` it leaves local IRQs disabled in `*irq_flags` and `WORK_STRUCT_PENDING_BIT` owned by the caller, while restoring `*irq_flags` on `-EAGAIN`. Use `cancel_delayed_work*()` / `disable_delayed_work*()` (`WORK_CANCEL_DELAYED`) on `struct delayed_work`, never `cancel_work*()` / `disable_work*()` on `&dwork->work`. [F42, F59]
- Pass `enum work_bits` (`WORK_STRUCT_*_BIT`) to bitops (`test_bit`, `__set_bit`, etc.) on `work_data_bits(work)` and shifted masks from `enum work_flags` (`WORK_STRUCT_*`) to bitwise ops and `@extra_flags`. Pass `@cpu < 0` (`-1`) to `unbound_pwq*()` / `install_unbound_pwq()` for `wq->dfl_pwq`, but pass `WORK_CPU_UNBOUND` (`NR_CPUS`) to `queue_work_on()`, `queue_delayed_work_on()`, `mod_delayed_work_on()`, and `workqueue_congested()`. [F54, F55]
- `enable_work()` / `enable_delayed_work()` return `true` only when the disable count reaches zero (`!offqd.disable`). `execute_in_process_context()` returns `0` when run synchronously and `1` when `@ew->work` was scheduled asynchronously (`@ew` must stay valid until completion). In `unbind_worker()`, fall back to `cpu_possible_mask` if `!cpumask_intersects(wq_unbound_cpumask, cpu_active_mask)`. [F44, F45, F58]
- Verify `work->func == wq_barrier_func` before downcasting `work` to `struct wq_barrier *`, only downcast to `struct delayed_work *` when `WORK_CANCEL_DELAYED` is set, and verify `task->flags & PF_WQ_WORKER` before casting `kthread_data(task)` to `struct worker *`. [F127, F130]

## Error Handling

- `apply_wqattrs_prepare()` returns an `ERR_PTR` (check with `IS_ERR()` before adding to `ctxs` or passing to `apply_wqattrs_cleanup()`), whereas `alloc_workqueue*()`, `get_unbound_pool()`, and `alloc_unbound_pwq()` return `NULL`. [F43]
- `init_worker_pool()` must initialize all fields of `@pool` (`id = -1`, `cpu = -1`, `refcnt = 1`, locks, lists, timers, `idle_cull_work`, `worker_ida`, `hash_node`) before `alloc_workqueue_attrs()` so `put_unbound_pool()` can safely clean up on failure. In `init_rescuer()`, save `PTR_ERR(rescuer->task)` before `kfree(rescuer)` and only set `wq->rescuer` on success; in `workqueue_sysfs_register()`, reset `wq->wq_dev = NULL` on failure. [F14, F51, F52]
- Bounds-check `offqd->disable` in `work_offqd_disable()` / `work_offqd_enable()`, handle `!total_cpus` before dividing in `wq_update_node_max_active()`, and return early without warning or decrementing `pool->nr_running` if `READ_ONCE(worker->sleeping)` is already set in `wq_worker_sleeping()`. [F82, F115, F170]

## Known Pitfalls

- Pass `&n` as `@nextp` to `assign_work()` or `move_linked_works()` inside `list_for_each_entry_safe(work, n, &pool->worklist, entry)` so the cursor advances past moved `WORK_STRUCT_LINKED` items. In `start_flush_work()` and `insert_wq_barrier()`, when `worker` is non-NULL (`target` is executing), read `pwq`, `work_color`, and list head from `worker->current_pwq`, `worker->current_color`, and `worker->scheduled.next`, not `target`. In `__flush_workqueue()`, `break` if `list_empty(&wq->flusher_queue)` before dereferencing `next` as `wq->first_flusher`. [F63, F103, F111]
- Check `cpu >= 0` before passing `-1` CPU sentinels (`wq_update_node_max_active()`, `unbound_pwq*()`, `pool->cpu`) to `cpumask_test_cpu()`, `cpu_to_node()`, or `per_cpu_ptr()`. When selecting a CPU from a cpumask (`kick_pool()`, `wq_select_unbound_cpu()`, `select_numa_node_cpu()`), intersect with `cpu_online_mask` and verify the result is `< nr_cpu_ids`. Use `(1U << bits) - 1` with `bits < 32` in `shift_and_mask()`, and keep `wq_watchdog_touch()` marked `notrace`. [F84, F85, F112, F160]
