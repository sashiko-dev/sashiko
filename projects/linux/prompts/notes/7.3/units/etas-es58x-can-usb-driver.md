# ETAS ES58X CAN/USB DRIVER

The ETAS ES58X driver provides SocketCAN network interface support for ETAS USB CAN and CAN-FD bus adapter modules (ES581.4, ES582.1, and ES584.1). It manages USB bulk URB reception and transmission (including BQL-driven multi-frame TX batching, local echo SKB loopback with hardware timestamps, and split-URB reassembly), registers per-channel CAN netdevices, and exposes firmware, bootloader, and hardware revision metadata via devlink.

## Architecture & Data Flow
- `struct can_priv can` must remain first in `struct es58x_priv` (`netdev_priv(netdev)` is cast to both `struct can_priv *` and `struct es58x_priv *`). `rx_cmd_buf` must remain last in `struct es58x_device` and be bounded by `es58x_dev->param->rx_urb_cmd_max_len` rather than `sizeof(es58x_dev->rx_cmd_buf)` because `es58x_init_es58x_dev()` allocates only `es58x_sizeof_es58x_device(param)` bytes. [F78, F83]
- `es58x_check_rx_urb()` must verify `urb_actual_len >= param->urb_cmd_header_len` before reading `urb_cmd->sof` or calling `ops->get_msg_len()`, and must verify `urb_cmd_len <= param->rx_urb_cmd_max_len` and `urb_actual_len >= urb_cmd_len` before calling `es58x_check_crc()` or `es58x_handle_urb_cmd()`. [F51]
- `es58x_handle_incomplete_cmd()` must sample `es58x_dev->rx_cmd_buf_len` into `tmp_cmd_buf_len` before calling `es58x_copy_to_cmd_buf()`. `es58x_split_urb()` must reset `rx_cmd_buf_len = 0` whenever `es58x_handle_incomplete_cmd()` returns anything other than `-ENODATA`, and `es58x_read_bulk_callback()` must ignore `-ENODATA` from `es58x_split_urb()`. [F22, F43]
- `es58x_split_urb_try_recovery()` must only return `dropped_bytes` when `es58x_check_rx_urb()` returns `-ENODATA` or `> 0`, ensuring `dropped_bytes > 0` when called from `es58x_split_urb()` after `es58x_check_rx_urb()` fails. [F65]
- Fixed-size array RX handlers (`es581_4_echo_msg()`, `es581_4_rx_can_msg()`, `es58x_fd_echo_msg()`) must bound element counts with `es58x_msg_num_element()` (storing its return in a signed `int` and checking `<= 0` before looping), while `es58x_fd_rx_can_msg()` must check `es58x_check_msg_max_len()`, `rx_can_msg_len <= rx_can_msg_buf_len`, and `rx_can_msg->len <= CANFD_MAX_DLEN`. [F25, F53]
- CAN messages in `es581_4_bulk_tx_can_msg.tx_can_msg_buf`, `es58x_fd_urb_cmd.tx_can_msg_buf`, and `es58x_fd_urb_cmd.rx_can_msg_buf` are packed at variable byte offsets determined by `es581_4_sizeof_rx_tx_msg()` or `es58x_fd_sizeof_rx_tx_msg()` (including `can_cc_dlc2len(dlc)` bytes even for RTR frames), not fixed struct strides. `es581_4_tx_can_msg()` and `es58x_fd_tx_can_msg()` must validate `msg_len + sizeof(*tx_can_msg)` with `es58x_check_msg_max_len()` before writing to `&raw_msg[msg_len]`. [F55, F82]
- In `es58x_start_xmit()`, `priv->tx_head` and `priv->tx_can_msg_cnt` must only be incremented after both `ops->tx_can_msg()` and `can_put_echo_skb()` succeed, matching `es58x_flush_pending_tx_msg()` which unwinds `tx_can_msg_cnt` entries by decrementing `tx_head` and calling `can_free_echo_skb()` and `netdev_completed_queue()`. [F70]
- Wire channel numbers must be translated between 1-based ES581.4 (`ES581_4_CHANNEL_IDX_OFFSET = 1`) and 0-based ES58X FD (`ES58X_FD_CHANNEL_IDX_OFFSET = 0`), validated against `es58x_dev->num_can_ch` via `es58x_get_netdev()` on RX, and offset by `ES581_4_CHANNEL_IDX_OFFSET` on ES581.4 TX. [F56]
- In `es58x_fd_enable_channel()`, `tx_conf_msg` must be zero-initialized, `CAN_CTRLMODE_FD_NON_ISO` must be tested before `CAN_CTRLMODE_FD` (which is also set in non-ISO mode), and `es58x_send_msg()` must be passed `ES58X_FD_CANFD_CONF_LEN` when `tx_conf_msg.canfd_enabled` is set vs `ES58X_FD_CAN_CONF_LEN` for Classical CAN. [F34, F64]
- `es58x_probe()` must call `es58x_parse_product_info()` before `devlink_register()`, initializing `firmware_version`, `bootloader_version`, and `hardware_revision` to `-1` sentinels and updating them only when `sscanf()` matches all 3 fields. `es58x_devlink_info_get()` must guard formatting with `es58x_sw_version_is_valid()` (`< 100`) and `es58x_hw_revision_is_valid()` (`isalnum(letter)` and `< 1000`), and version sub-number fields (`u8`/`u16`) must remain unsigned so `-1` fails those checks. [F29, F62, F77, F91]

## Synchronization
- No TX submission or echo SKB access (`priv->can.echo_skb[]`, `can_put_echo_skb()`, `can_get_echo_skb()`, or `can_free_echo_skb()`) may occur while `es58x_is_can_state_active(netdev)` is false (`priv->can.state >= CAN_STATE_BUS_OFF`), because `can_restart()` calls `can_flush_echo_skb()` without locks. [F10]
- In `es58x_rx_err_msg()`, `can->state` must be set to `CAN_STATE_BUS_OFF` and `netif_stop_queue()` called before `can_bus_off(netdev)` schedules restart work, and `ES58X_EVENT_CRTL_PASSIVE` / `ES58X_EVENT_CRTL_WARNING` must only update `can->state` when `can->state < CAN_STATE_BUS_OFF`. [F11]
- When restarting from `CAN_STATE_BUS_OFF`, `es58x_set_mode()` must only send `ops->enable_channel(priv)` and defer `es58x_can_reset_echo_fifo()`, setting `priv->can.state = CAN_STATE_ERROR_ACTIVE`, and `netif_wake_queue()` until `es58x_rx_cmd_ret_u32()` receives `ES58X_RET_U32_OK` for `ES58X_RET_TYPE_ENABLE_CHANNEL`. Under `CAN_MODE_STOP`, `es58x_set_mode()` must still call `ops->disable_channel(priv)` when `priv->can.state == CAN_STATE_BUS_OFF`. [F12, F69]
- `es58x_dev->opened_channel_cnt` and the shared URB setup/teardown gated by it (`es58x_alloc_rx_urbs()`, `es58x_set_realtime_diff_ns()`, and `es58x_free_urbs()`) have no internal lock and must only be accessed under `rtnl_mutex`, with `es58x_alloc_rx_urbs()` and `es58x_free_urbs()` called only when `opened_channel_cnt == 0` (including on `es58x_open()` error rollback). [F13, F89]
- `es58x_dev->timestamps`, `es58x_dev->rx_cmd_buf`, and `es58x_dev->rx_cmd_buf_len` are unguarded per-device buffers and must only be accessed in the USB RX completion path (`es58x_read_bulk_callback()` and its callees). [F14]
- Every `usb_anchor_urb()` onto `es58x_dev->tx_urbs_idle` must be paired with `atomic_inc(&es58x_dev->tx_urbs_idle_cnt)` and every `usb_get_from_anchor(&es58x_dev->tx_urbs_idle)` with decrementing `tx_urbs_idle_cnt`. Completed TX URBs in `es58x_write_bulk_callback()` (except `-ENOENT`) must be anchored to `tx_urbs_idle` rather than freed, deferring `usb_free_coherent()` garbage collection above `ES58X_TX_URBS_MAX` to `es58x_get_tx_urb()` because `usb_free_coherent()` cannot run with IRQs disabled. [F15, F101]
- `es58x_get_tx_urb()` and `es58x_submit_urb()` must use `GFP_ATOMIC` for `es58x_alloc_urb()` and `usb_submit_urb()` because they run under the netdev TX lock and from USB RX completion callbacks. Both `es58x_submit_urb()` and `es58x_alloc_rx_urbs()` must populate URB fields and call `usb_anchor_urb()` before `usb_submit_urb()`, and call `usb_unanchor_urb()` if `usb_submit_urb()` fails. [F18, F102]
- `es58x_set_realtime_diff_ns()` must set `es58x_dev->ktime_req_ns = ktime_get_real_ns()` before calling `ops->get_timestamp(es58x_dev)`, and reject concurrent requests with `-EBUSY` while `ktime_req_ns` is non-zero until `es58x_rx_timestamp()` resets it to 0. [F16]

## Object Lifetimes
- `es58x_init_netdev()` must register `priv->devlink_port` and bind it with `SET_NETDEV_DEVLINK_PORT()` before `register_candev()`; on failure after setting `es58x_dev->netdev[channel_idx] = netdev`, it must unregister `devlink_port`, reset `netdev[channel_idx] = NULL`, and call `free_candev(netdev)`. `es58x_free_netdevs()` must call `unregister_candev()` before `devlink_port_unregister()` and `free_candev()`. [F1, F118]
- In `es58x_disconnect()`, `es58x_free_netdevs()` and `es58x_free_urbs()` must complete before `devlink_free(priv_to_devlink(es58x_dev))` because `struct es58x_device` lives inside devlink private memory. In `es58x_free_urbs()` (sleepable context only), `tx_urbs_busy` must be drained with `usb_wait_anchor_empty_timeout()` and `usb_kill_anchored_urbs()` before freeing `tx_urbs_idle`. [F87, F107]
- Every URB from `es58x_alloc_urb()` uses `URB_NO_TRANSFER_DMA_MAP` with a `usb_alloc_coherent()` buffer that `usb_free_urb()` does not release, so every retirement path must call `usb_free_coherent()`. For TX URBs, pass `es58x_dev->param->tx_urb_cmd_max_len` as the size rather than `urb->transfer_buffer_length`, which TX paths overwrite with each command's actual length. [F81, F92]
- In `es58x_start_xmit()`, failures before `can_put_echo_skb()` must jump to `drop_skb` (`dev_kfree_skb(skb)`), whereas failures at or after `can_put_echo_skb()` must jump to `xmit_failure` without freeing `skb` because `can_put_echo_skb()` consumes `skb` and `es58x_flush_pending_tx_msg()` frees queued echo SKBs. [F4]

## API Contracts
- `es58x_submit_urb()` always consumes `urb` via `usb_free_urb(urb)` on both success and failure (after unanchoring and freeing the coherent buffer on `usb_submit_urb()` failure). Every TX URB must pass a non-NULL `netdev` so `urb->context` is populated for `es58x_write_bulk_callback()`; device-level commands pass `ES58X_CHANNEL_IDX_NA` (`0xFF`) to `es58x_send_msg()`, which maps it to `es58x_dev->netdev[0]`. [F7, F57, F84]
- `es58x_start_xmit()` must call `can_dev_dropped_skb(netdev, skb)` before accessing `skb->data`, and if dropped while `priv->tx_urb` is non-NULL, jump to `xmit_commit` so batched frames are still submitted when `es58x_xmit_more()` is false. [F111]
- Every SKB queued via `can_put_echo_skb()` and accounted via `netdev_sent_queue(netdev, frame_len)` must have its `frame_len` (initialized to 0 before calling `can_get_echo_skb()`/`can_free_echo_skb()` in case the slot is NULL) passed to `netdev_completed_queue()`, unless reset by `es58x_can_reset_echo_fifo()`. `es58x_can_get_echo_skb()` requires consecutive packet indexes (callers abort with `-EBADMSG` on any gap) and must call `es58x_set_skb_timestamp()` on `priv->can.echo_skb[skb_idx]` before `can_get_echo_skb()`. [F28, F66, F113, F115]
- `es58x_check_rx_urb()` returns the positive command byte length on success, `-ENODATA` when incomplete, and other negative errnos on framing/CRC errors; callers must store its result in a signed `int` and distinguish `-ENODATA` from fatal errors. [F21]
- The `@msg` argument to `es58x_check_msg_len()` and `es58x_check_msg_max_len()` must be a dereferenced struct, union member, or array (`*tx_ack_msg`), never a pointer (`sizeof(msg)` has no pointer-decay check). [F79]
- `es58x_calculate_crc()`, `es58x_get_crc()`, `es58x_set_crc()`, and `es58x_check_crc()` take the full runtime URB command length `es58x_get_urb_cmd_len(es58x_dev, msg_len)` (`> 4`), whereas `ops->fill_urb_header()` and `es58x_send_msg()` take only `msg_len`; never access `reserved_for_crc16_do_not_use` or pass `sizeof(*urb_cmd)`. [F33, F80]
- In `struct es58x_fd_tx_can_msg` and `struct es58x_fd_rx_can_msg`, the union field is `.len` (raw byte length up to `CANFD_MAX_DLEN`) when `ES58X_FLAG_FD_DATA` is set, and `.dlc` otherwise. In `es58x_rx_can_msg()`, Classical CAN frames must use `can_frame_set_cc_len()` and, when `ES58X_FLAG_RTR` is set, mark `CAN_RTR_FLAG` and zero `len` before copying data and updating `rx_bytes`. [F30, F117]
- `es58x_fd_convert_bittiming()` must subtract 1 from each SocketCAN timing parameter (`prop_seg + phase_seg1`, `phase_seg2`, `brp`, `sjw`), whereas `es581_4_set_bittiming()` must divide `bt->sample_point` by `10U`. [F35]

## Error Handling
- In `es58x_rx_err_msg()`, `alloc_can_err_skb(netdev, &cf)` can fail and leave `cf` NULL while state, stats, and bus-off handling continue: `cf` must be initialized to NULL, all `cf`/`skb` dereferences guarded by `if (cf)`, and no branch after `alloc_can_err_skb()` may return early before `netif_rx(skb)`. [F3, F19]
- In `es58x_handle_urb_cmd()`, any negative errno from `ops->handle_urb_cmd()` not in the non-critical switch cases (`-ENODEV`, `-EINVAL`, `-EMSGSIZE`, `-EBADRQC`, `-EBADMSG`, `-ECHRNG`, `-ETIMEDOUT`) detaches all CAN netdevices and calls `ops->reset_device()` (which is NULL in `es58x_fd_ops` and must be NULL-checked before calling). [F71, F95]
- `es58x_dev->udev->serial` can be NULL if the USB device omits a serial descriptor, so callers such as `es58x_devlink_info_get()` must check it for non-NULL before dereferencing or passing it to `devlink_info_serial_number_put()`. [F20]

## External Contracts
- `es58x_id_table` entries for `ES58X_FD_FAMILY` (`ES582_1_PRODUCT_ID`, `ES584_1_PRODUCT_ID`) must use `USB_DEVICE_INTERFACE_PROTOCOL(..., ES58X_FD_INTERFACE_PROTOCOL)` rather than `USB_DEVICE()`. [F96]
- ES58X FD bulk TX URBs cannot mix Classical CAN and CAN FD frames in one URB command (`ES58X_FD_CMD_TYPE_CAN` vs `ES58X_FD_CMD_TYPE_CANFD`), so `es58x_start_xmit()` must commit any pending `priv->tx_urb` via `es58x_xmit_commit()` whenever `can_is_canfd_skb(skb) != priv->tx_can_msg_is_fd`. [F99]

## Known Pitfalls
- Pointers to `union es58x_urb_cmd` and embedded packed wire messages in RX and bulk TX buffers can lie at arbitrary byte offsets (due to 1-byte `ES58X_HEARTBEAT` stripping, `es58x_split_urb()`, and variable-length CAN frames), so multi-byte fields and trailing CRC16s must use `get_unaligned_le*()`/`put_unaligned_le*()`. [F108]
- `es58x_can_get_echo_skb_recovery()` must test whether `rcv_packet_idx` is in `[tx_tail, tx_head)` using signed 32-bit differences `(s32)(rcv_packet_idx - priv->tx_tail) < 0` and `(s32)(rcv_packet_idx - priv->tx_head) >= 0` for `u32` wraparound, and `es58x_fd_echo_msg()` must cast `rcv_packet_idx` to `u8` when comparing against `echo_msg[i].packet_idx`. [F59, F73]
- In `es58x_fd_rx_can_msg()`, `rx_can_msg_len` (`es58x_fd_sizeof_rx_tx_msg(*rx_can_msg)`) is the full wire struct size used to advance `rx_can_msg_buf` and decrement `rx_can_msg_buf_len`, whereas `rx_can_msg->len` is the CAN-FD payload length checked against `CANFD_MAX_DLEN` and passed to `can_fd_len2dlc()`. [F67]
- `priv->err_passive_before_rtx_success` (`u8`) must be reset to 0 on every RX frame (`es58x_rx_can_msg()`), echo completion (`es58x_can_get_echo_skb()`), and echo FIFO reset (`es58x_can_reset_echo_fifo()`), and must saturate at `U8_MAX` when incremented in `es58x_rx_err_msg()` with `ES58X_CONSECUTIVE_ERR_PASSIVE_MAX` (`254`) strictly `< U8_MAX`. [F42, F76]
- In `es58x_get_netdev()` and `es58x_alloc_urb()`, output pointer parameters (`struct net_device **netdev`, `struct urb **urb`, `u8 **buf`) must be validated by dereferencing (`!*netdev`, `!*urb`, `!*buf`) after assignment rather than testing the parameter address itself. [F63]
