# MEDIATEK T7XX 5G WWAN MODEM DRIVER

The MediaTek T7xx driver supports PCIe-connected 5G WWAN modems by managing PCIe MAC/ATR configuration, Modem Host Cross-Core Interface (MHCCIF) interrupts, power management, and modem state transitions via a finite state machine (FSM). It provides two host interface (HIF) DMA engines: CLDMA (Cross Layer DMA) for control, AT, MBIM, MIPC, fastboot, and debugfs trace ports multiplexed via CCCI headers, and DPMAIF (Data Path Modem AP Interface) for high-speed IP network data paths exposed as CCMNI netdevices.

## Architecture & Data Flow

- In `t7xx_dpmaif_rx_start()`, `rxq->rx_data_info` (`skb_info`) accumulates packet state across a `DES_PT_MSG` PIT and subsequent `DES_PT_PD` PITs across NAPI calls: the budget exit check must be gated by `!skb_info->msg_pit_received`, and `skb_info` must only be zeroed upon the final PD PIT (`!PD_PIT_CONT`) and in `t7xx_dpmaif_rx_alloc()` / `t7xx_dpmaif_stop_rxq()`, freeing `skb_info->cur_skb` if `skb_info->err_payload` is set. [F74, F108]
- In DPMAIF RX payload PIT descriptors (`struct dpmaif_pit`), the 16-bit buffer ID is split across `header` (`PD_PIT_BUFFER_ID`, bits 15:3) and `pd.footer` (`PD_PIT_H_BID`, bits 10:8) and must be reconstructed via `t7xx_normal_pit_bid()` and bounds-checked via `t7xx_bat_cur_bid_check()` or `t7xx_frag_bat_cur_bid_check()` before indexing `bat_skb` or `bat_bitmap`. `bat_req->bat_skb` is a `void *` pointing to `struct dpmaif_bat_page` when `bat_req->type == BAT_TYPE_FRAG` and `struct dpmaif_bat_skb` when `BAT_TYPE_NORMAL`. [F52, F85]
- Each DPMAIF TX SKB consumes `skb_shinfo(skb)->nr_frags + 2` contiguous `struct dpmaif_drb` entries (one `DES_DTYP_MSG` plus `nr_frags + 1` `DES_DTYP_PD` entries), and `t7xx_dpmaif_add_skb_to_ring()` must notify `DMPAIF_TXQ_STATE_FULL` when `txq->tx_budget <= MAX_SKB_FRAGS + 2`. In `t7xx_txq_drb_wr_available()`, writable DRB space must be checked using `txq->drb_release_rd_idx` (not `txq->drb_rd_idx`), whereas `t7xx_dpmaif_tx_release()` uses `drb_release_rd_idx` and `drb_rd_idx`. [F84, F113]
- In `struct cldma_ctrl`, `gpd_dmapool`, `tx_ring`/`rx_ring`, and `tr_done` pointers are only populated when `t7xx_cldma_late_init()` sets `md_ctrl->is_late_init = true`, so `t7xx_cldma_start()`, `t7xx_cldma_stop()`, and `t7xx_cldma_late_release()` must check `is_late_init` first. In `t7xx_cldma_switch_cfg()`, `t7xx_cldma_late_release()` must free old DMA rings before `t7xx_cldma_adjust_config()` mutates `pkt_size`, followed by `t7xx_cldma_late_init()` and `t7xx_cldma_txq_init()` / `t7xx_cldma_rxq_init()`. [F54, F68]
- Whenever CLDMA TX queues are stopped, started, suspended, or lose their UL start address in `t7xx_cldma_hw_start_send()`, `md_ctrl->txq_started` must be cleared so the next transmit calls `t7xx_cldma_hw_start_queue()` instead of `t7xx_cldma_hw_resume_queue()`. Advancing or retreating `tr_done`, `rx_refill`, or `tx_next` around `ring->gpd_ring` must use `list_next_entry_circular()` or `list_prev_entry_circular()` to wrap past the list head sentinel. [F70, F104]
- Raw L2 interrupt status bits read from `L2TISAR0`/`L2RISAR0` in `t7xx_dpmaif_hw_get_intr_cnt()` and `t7xx_cldma_irq_work_cb()` must have already-masked bits cleared using `L2TIMR0`/`L2RIMR0` before W1C-clearing status registers or scheduling work; if `t7xx_mask_dlq_intr()` fails in `t7xx_dpmaif_hw_check_rx_intr()`, that `DP_DL_INT_Q*_DONE` bit must be cleared from `intr_status`. W1C writes to BAR 2 L2 status registers in `t7xx_mhccif_clear_interrupts()`, `t7xx_cldma_hw_tx_done()`, and `t7xx_cldma_hw_rx_done()` must be flushed with an MMIO readback before clearing BAR 0 MSI-X status. [F98, F140, F141]
- `port->seq_nums[MTK_RX]` must be initialized and reset to `INVALID_SEQ_NUM` (`0xffff`) in `t7xx_port_struct_init()` and `t7xx_port_proxy_reset()`, and `t7xx_port_next_rx_seq_num()` must increment 15-bit `CCCI_H_SEQ_FLD` (`GENMASK(30, 16)`) values via `(seq_num + 1) & FIELD_MAX(CCCI_H_SEQ_FLD)` (`0..0x7fff`) so valid sequence numbers never collide with `INVALID_SEQ_NUM`. [F58, F123]
- Callbacks in `struct port_ops` and `struct md_pm_entity` are optional and must be null-checked before invocation. `struct port_proxy` allocates `ports[]` for `T7XX_MAX_POSSIBLE_PORTS_NUM` entries while `port_prox->port_count` bounds active loops (`for_each_proxy_port`); in `t7xx_port_proxy_set_cfg()`, `t7xx_port_proxy_uninit()` must run before updating `ports[i].port_conf` and `port_count`, followed by `t7xx_proxy_init_all_ports()`. [F50, F51, F79, F93]
- On `MD_STATE_EXCEPTION` or `MD_STATE_STOPPED` in `t7xx_ccmni_md_state_callback()`, `t7xx_ccmni_pre_stop()` and `t7xx_ccmni_post_stop()` must disable TX and NAPI (`ctlb->is_napi_en = false`) while preserving `ccmni->usage` and `ctlb->napi_usr_refcnt` so `t7xx_ccmni_start()` can restore TX, carrier, and NAPI on `MD_STATE_READY`. [F81]

## Synchronization

- All acquisitions of `cldma_queue::ring_lock` and `cldma_ctrl::cldma_lock` must use `spin_lock_irqsave()` because `t7xx_cldma_isr_handler()` runs in hardirq context, with `cldma_lock` nesting inside `ring_lock`; callers of `t7xx_cldma_alloc_and_map_skb()` under `ring_lock` must pass `GFP_ATOMIC`. In `t7xx_cldma_gpd_handle_tx_request()`, the GPD data pointer and length must be written before acquiring `cldma_lock`, and `GPD_FLAGS_HWO` must only be set under `cldma_lock` when `md_ctrl->txq_active & BIT(queue->index)` is non-zero; `t7xx_cldma_send_skb()` must release `ring_lock` before `t7xx_pci_sleep_disable_complete()`. [F69, F153, F154, F155]
- In `t7xx_cldma_stop()` and `t7xx_cldma_reset()`, `rxq_active` and `txq_active` must be cleared and CLDMA IRQs disabled before calling `flush_work()` or `cancel_work_sync()` on `cldma_work` outside `cldma_lock`, prior to `md_cd_queue_struct_reset()` and `t7xx_cldma_late_release()`. During `HIF_EX_CLEARQ_DONE` in `t7xx_md_exception()` and `t7xx_cldma_exception()`, both CLDMA instances must stop RX queues, disable IRQs, flush workqueues via `t7xx_cldma_stop()`, and clear RX queues before triggering `H2D_CH_EXCEPTION_CLEARQ_ACK`. [F28, F156]
- `t7xx_dpmaif_napi_rx_poll()` and `t7xx_dpmaif_add_skb_to_ring()` must set `rx_processing = 1` / `tx_processing = 1` followed by `smp_mb()` before checking `que_started` or modifying the DRB ring, and reset it to 0 on every exit path (when not staying in NAPI poll), paired with `t7xx_dpmaif_rx_stop()` polling `rx_processing == 0` and `smp_mb()` before clearing `rxq->que_started`, and `t7xx_dpmaif_tx_stop()` clearing `txq->que_started`, `smp_mb()`, and spinning until `tx_processing == 0`. [F33, F34, F161]
- Concurrent mutations and zero-bit searches on `struct dpmaif_bat_request::bat_bitmap` (`t7xx_dpmaif_set_bat_mask()`, `t7xx_dpmaif_avail_pkt_bat_cnt()`, and `t7xx_dpmaif_release_bat_entry()`) must hold `bat_req->mask_lock` using `spin_lock_irqsave()` (shared between NAPI softirq and `bat_release_wq`) and bound bit indices to `bat_req->bat_size_cnt`. [F133, F160]
- In `t7xx_ccmni_md_state_callback()` on `MD_STATE_EXCEPTION` or `MD_STATE_STOPPED`, `t7xx_ccmni_pre_stop()` must run before `t7xx_dpmaif_md_state_callback()`, and `t7xx_ccmni_post_stop()` (disabling NAPI) must run only after `t7xx_dpmaif_md_state_callback()` finishes. In `t7xx_ccmni_wwan_newlink()` and `t7xx_ccmni_wwan_dellink()`, `ctlb->ccmni_inst[if_id]` is published and cleared with `WRITE_ONCE()` after initializing `t7xx_ccmni` fields and before `unregister_netdevice(dev)`, paired with `READ_ONCE()` on RX/TX paths. [F35, F40]
- In `t7xx_fsm_broadcast_state()`, `ctl->md_state` must be updated and `t7xx_port_proxy_md_status_notify()` called before `fsm_state_notify()`. `fsm_state_notify()` drops `ctl->notifier_lock` before invoking each sleeping `notifier->notifier_fn()` and re-acquires it before `list_for_each_entry()` advances, so `notifier_fn` callbacks must never call `t7xx_fsm_notifier_unregister()`. In `t7xx_fsm_append_cmd()`, when `FSM_CMD_FLAG_WAIT_FOR_COMPLETION` is set, `cmd->done` and `cmd->refcnt` must be initialized before queuing `cmd` under `ctl->command_lock`, and `fsm_finish_command()` must store `cmd->result` before `complete_all(&cmd->done)`. [F31, F44, F106, F158]
- All updates and bit checks on `t7xx_modem::exp_id` across `t7xx_pci_mhccif_isr()` and `t7xx_md_event_notify()` must be serialized under `md->exp_lock`, testing `D2H_INT_EXCEPTION_INIT` before `D2H_INT_PORT_ENUM`, `D2H_INT_ASYNC_MD_HK`, or `D2H_INT_ASYNC_AP_HK`. `t7xx_dev->md_pm_lock` must be acquired with `spin_lock_irqsave()` in `t7xx_pci_disable_sleep()` and `t7xx_pci_enable_sleep()`, and `t7xx_pci_pm_init_late()` must unmask `D2H_INT_DS_LOCK_ACK` before setting `md_pm_state = MTK_PM_RESUMED`. [F29, F37, F100, F165]

## Object Lifetimes

- `t7xx_cldma_gpd_rx_from_q()` must unmap and zero `req->mapped_buff` before `queue->recv_skb(queue, skb)`, and only clear `req->skb = NULL` and advance `tr_done`/`rx_refill` after `queue->recv_skb()` returns `0`. Every `port_ops::recv_skb` callback must consume/free `skb` when returning `0` and leave `skb` unfreed on negative errno so `t7xx_port_proxy_recv_skb()` can restore the CCCI header via `skb_push(skb, sizeof(*ccci_h))` without updating `port->seq_nums[MTK_RX]`. [F2, F71, F167]
- Because `t7xx_dpmaif_add_skb_to_ring()` records the same `skb` pointer in every `dpmaif_drb_skb` entry of a multi-DRB packet, `t7xx_dpmaif_release_tx_buffer()` and `t7xx_dpmaif_tx_free_drb_skb()` must unmap DMA only when `!drb_skb->is_msg` and free `drb_skb->skb` only on the last DRB (`!DRB_HDR_CONT` or `drb_skb->is_last`). [F6]
- All RX queues share `dpmaif_ctrl->bat_req` and `bat_frag`, so `t7xx_dpmaif_bat_free()` only releases BAT resources when `atomic_dec_and_test(&bat_req->refcnt)` is true. When a BAT buffer is consumed (`t7xx_dpmaif_set_data_to_skb()`, `t7xx_dpmaif_set_frag_to_skb()`) or released (`t7xx_unmap_bat_skb()`, `t7xx_unmap_bat_page()`), `bat_skb->skb` or `page_info->page` must be set to `NULL` after DMA unmap; buffers from `netdev_alloc_frag()` in `t7xx_dpmaif_rx_frag_alloc()` must use `virt_to_head_page()` and `put_page()`. [F10, F11, F172]
- `t7xx_cldma_irq_work_cb()` acquires `pm_runtime_get()` before queuing `cldma_work`, so `t7xx_cldma_rx_done()` and `t7xx_cldma_tx_done()` must retain it when re-queuing `cldma_work` and call `pm_runtime_put_autosuspend()` only on final return. Likewise, `t7xx_dpmaif_irq_rx_done()` and `t7xx_ccmni_enable_napi()` must acquire a runtime PM reference before `napi_schedule()` so softirq `t7xx_dpmaif_napi_rx_poll()` can drop it via `pm_runtime_put_autosuspend()`. `t7xx_pci_pm_init_late()`, `t7xx_pci_pm_reinit()`, and `t7xx_pci_reprobe_early()` must keep `pm_runtime_put_noidle()` and `pm_runtime_get_noresume()` balanced. [F16, F135, F146]
- Teardown ordering: `t7xx_cldma_late_release()` must call `t7xx_cldma_ring_free()` before `dma_pool_destroy(md_ctrl->gpd_dmapool)`; `t7xx_ccmni_exit()` must unregister the FSM notifier and `wwan_unregister_ops()` before `t7xx_uninit_netdev_napi()` and `t7xx_dpmaif_hif_exit()`; `t7xx_dpmaif_sw_release()` must stop `tx_thread` and `bat_release_wq` before freeing queues; and `t7xx_fsm_uninit()` / `port_ctl_uninit()` must call `kthread_stop()` before flushing queues. [F17, F19, F20, F43]

## API Contracts

- In `t7xx_ccmni_start_xmit()`, `skb` must be freed with `dev_kfree_skb()` when returning `NETDEV_TX_OK` on an early drop (`skb->len > dev->mtu` or `skb_headroom(skb) < sizeof(struct ccci_header)`), whereas `t7xx_dpmaif_tx_send_skb()` must leave `skb` unconsumed when returning `-EBUSY` so `t7xx_ccmni_start_xmit()` can return `NETDEV_TX_BUSY`. [F4, F91]
- Before accessing CLDMA or DPMAIF hardware in D0, callers must call `t7xx_pci_disable_sleep()`, wait for `t7xx_pci_sleep_disable_complete()`, and pair with `t7xx_pci_enable_sleep()`. `t7xx_pci_sleep_disable_complete()` returns residual jiffies from `wait_for_completion_timeout()`, so `0` is a timeout failure and any positive value is success. [F45, F145]
- `t7xx_dpmaif_release_bat_entry()` returns `0` when empty, negative errno on error, and positive `rel_entry_num` on success (`if (ret <= 0)` skips allocation); initial allocation in `t7xx_dpmaif_start()` must pass `bat_size_cnt - 1`. Callers of `t7xx_dpmaif_hw_get_intr_cnt()` must zero `para->intr_cnt`; `t7xx_dpmaif_irq_rx_done()` / `t7xx_dpmaif_irq_tx_done()` take `BIT(qno)` (not `qno`); and `t7xx_dpmaif_ul_update_hw_drb_cnt()` / `t7xx_dpmaif_ul_update_drb_size()` take DRB count multiplied by `DPMAIF_UL_DRB_SIZE_WORD` (`4`), whereas `t7xx_dpmaif_ul_get_rd_idx()` returns an entry index. [F48, F56, F60, F62, F120]
- `t7xx_mhccif_h2d_swint_trigger()` takes a 0-based `H2D_CH_*` index, whereas `t7xx_mhccif_mask_set()` / `t7xx_mhccif_mask_clr()` take `D2H_INT_*` bitmasks. `t7xx_cldma_hw_start_queue()`, `t7xx_cldma_hw_queue_status()`, and `t7xx_cldma_hw_irq_{dis,en}_{txrx,eq}()` accept a 0-based queue index or `CLDMA_ALL_Q`, whereas `t7xx_cldma_hw_resume_queue()`, `t7xx_cldma_hw_set_start_addr()`, and `t7xx_cldma_tx_addr_is_set()` accept only a single 0-based queue index. [F63, F95]

## Error Handling

- Error rollback loops that unwind 0-based indexed allocations in `t7xx_dpmaif_rx_buf_alloc()`, `t7xx_request_irq()`, `t7xx_cldma_late_init()`, and `t7xx_dpmaif_add_skb_to_ring()` must use post-decrement `while (i--)` so index `0` is released. When `dma_map_single()` fails in `t7xx_dpmaif_add_skb_to_ring()`, `unmap_buffers` must unmap `wr_cnt` buffers in reverse order and restore `txq->drb_wr_idx = drb_wr_idx_backup` without decrementing `txq->tx_budget`, leaving `skb` on `txq->tx_skb_head`. [F8, F75]
- In CLDMA/DPMAIF paths that can run before `t7xx_pci_pm_init_late()` enables runtime PM, `pm_runtime_resume_and_get()` returning `-EACCES` must not be treated as a failure. [F47]

## Known Pitfalls

- In `struct cldma_gpd`, 64-bit DMA pointers store the upper 32 bits (`_h`) before the lower 32 bits (`_l`), whereas 32-bit-aligned 64-bit MMIO registers in CLDMA (`REG_CLDMA_UL_START_ADDRL_0`, `REG_CLDMA_DL_START_ADDRL_0`) and PCIe MAC ATR are low-word first and must use `ioread64_lo_hi()` and `iowrite64_lo_hi()` instead of `ioread64()` and `iowrite64()`. In `t7xx_dpmaif_set_frag_to_skb()` and `t7xx_dpmaif_set_data_to_skb()`, `le32_to_cpu(pkt_info->pd.data_addr_h)` must be widened to 64 bits before `<< 32`. [F86, F115, F134]
- `t7xx_pcie_mac_clear_int()` disables (masks) a host MSI-X interrupt via `IMASK_HOST_MSIX_CLR_GRP0_0` and `t7xx_pcie_mac_set_int()` enables (unmasks) it via `IMASK_HOST_MSIX_SET_GRP0_0`, whereas `t7xx_mhccif_mask_set()` and CLDMA/DPMAIF `L2TIMSR0`/`L2RIMSR0` writes mask interrupts and `_clr`/`L2TIMCR0` writes unmask them. `t7xx_dpmaif_ul_idle_check()` and `t7xx_dpmaif_dl_idle_check()` return `true` when busy and `false` when idle. [F96, F138]
- Because `port_prox->rx_ch_ports` is indexed only by `PORT_CH_ID_MASK` (low 8 bits), `t7xx_port_proxy_find_port()` must match both `queue->md_ctrl->hif_id == port_conf->path_id` and the full 16-bit `channel == port_conf->rx_ch`. CCMNI `struct t7xx_ccmni` must be retrieved via `wwan_netdev_drvpriv(dev)` (not `netdev_priv(dev)`), `t7xx_ring_buf_rd_wr_count()` must keep `pkt_cnt` as a signed `int`, and `void *` DMA ring bases (`bat_base`, `pit_base`, `drb_base`, `drb_skb_base`) must be cast to typed struct pointers before indexing. [F88, F119, F129, F131]
