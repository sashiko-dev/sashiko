# GFS2 FILE SYSTEM

This component implements core subsystems of the GFS2 cluster filesystem, including mount and superblock lifecycle (`main.c`, `ops_fstype.c`, `super.c`), distributed lock manager integration (`lock_dlm.c`), journal logging, active item lists (AIL), and recovery (`log.c`, `lops.c`, `recovery.c`), resource group block allocation and bitmaps (`rgrp.c`), quota management (`quota.c`), metadata buffer I/O (`meta_io.c`), and sysfs/uevent interfaces (`sys.c`).

## Architecture & Data Flow
- Every GFS2 metadata `address_space` (`gfs2_aspace(sdp)` and `gfs2_glock2aspace(gl)`) must set `mapping->host = sdp->sd_inode`. `gfs2_mapping2sbd()` checks `mapping->a_ops == &gfs2_meta_aops` before downcasting `mapping` to `struct gfs2_glock_aspace` (so `gfs2_rgrp_aops` must remain separate for `gfs2_aspace(sdp)`), and `gfs2_glock2aspace(gl)` checks `gl->gl_ops->go_flags & GLOF_ASPACE`. [F50, F132, F165]
- In `rgblk_free()`, if `bi->bi_clone` is NULL it must be allocated to `bi->bi_bh->b_size` (copying `[bi->bi_offset, bi->bi_offset + bi->bi_bytes)`) before `gfs2_setbit()` mutates `bi->bi_bh->b_data` with `do_clone = false`, and `__gfs2_free_blocks()`/`gfs2_free_di()` increment `rgd->rd_free` without incrementing `rd_free_clone`. In `gfs2_alloc_blocks()`/`gfs2_alloc_extent()`, `gfs2_setbit()` uses `do_clone = true` and decrements `rd_reserved`, `rd_free_clone`, and `rd_free` by `*nblocks` under `rgd->rd_rsspin`. [F66, F67, F134]
- In `maybe_release_space()`, when `bi->bi_clone` is non-NULL, `gfs2_rgrp_send_discards()` must run before copying `bd->bd_bh->b_data` into `bi->bi_clone`, and `GBF_FULL`, `rgd->rd_free_clone`, and `rgd->rd_extfail_pt` must be updated to match `rgd->rd_free` under `rgrp_lock_local(rgd)`. Mutations to `rd_flags`, `rd_free`, `rd_dinodes`, or `rd_igeneration` must be written via `gfs2_rgrp_out()`, and `rgd->rd_rgl->rl_unlinked` adjusted in lockstep in `gfs2_unlink_di()`/`gfs2_free_di()`. [F68, F69]
- Whenever `ip->i_res` is initialized (`gfs2_init_inode_once()`, `gfs2_alloc_inode()`) or erased from `rgd->rd_rstree` (`__rs_deltree()`), `RB_CLEAR_NODE(&rs->rs_node)` must be called because `gfs2_rs_active()` tests `!RB_EMPTY_NODE(&rs->rs_node)`. `rs_insert()`, `gfs2_adjust_reservation()`, and `__rs_deltree()` must update `rgd->rd_requested` with `rs->rs_requested` under `rgd->rd_rsspin`, and `__rs_deltree()` adds `rs->rs_requested` to `rgd->rd_extfail_pt`. [F59, F70]
- Converting an AIL buffer into a revoke in `gfs2_add_revoke()` must increment `sdp->sd_log_num_revoke`, hold `bd->bd_gl` on the 0-to-1 transition of `gl->gl_revokes`, detach `bh->b_private` and `bd->bd_bh` after saving `bd->bd_blkno = bh->b_blocknr`, call `gfs2_remove_from_ail(bd)`, and set `GLF_LFLUSH` on `gl->gl_flags`. In `gfs2_ail1_empty()`, iterate `sd_ail1_list` in reverse and clear `oldest_tr` on the first non-empty transaction. [F80, F103]
- Log descriptor/revoke reservations (`gfs2_struct2blk()`, `gfs2_log_try_reserve()`, `gfs2_log_reserve()`, `calc_reserved()`) must use `DIV_ROUND_UP()`. The first revoke block starts with `struct gfs2_log_descriptor` (`sd_ldptrs` entries) while continuation blocks (`GFS2_METATYPE_LB`) start with `struct gfs2_meta_header` (`sd_inptrs` entries). For `GFS2_LOG_DESC_JDATA`, `databuf_limit(sdp)` is `sd_ldptrs / 2`, and jdata buffers starting with `GFS2_MAGIC` must be zero-escaped on commit and restored in `databuf_lo_scan_elements()`. [F90, F91, F129]
- Journal recovery (`clean_journal()`, `gfs2_write_log_header()` with `GFS2_LOG_HEAD_RECOVERY`, and `gfs2_recover_func()` on remote journals) must not touch `sdp->sd_log_flush_head`, call `gfs2_log_pointers_init()`, or write local statfs/quota fields to the log header. Updates to `sdp->sd_statfs_local` must be synced with `sdp->sd_sc_bh` under `sdp->sd_statfs_spin`. [F72, F73]
- Spectator mounts (`sdp->sd_args.ar_spectator`) do not populate `sd_sc_inode`, `sd_sc_bh`, `sd_sc_gh`, `sd_qc_inode`, `sd_qc_gh`, `sd_journal_gh`, or `sd_jinode_gh`, so statfs, journal, per-node, and unmount paths must guard them with `!sdp->sd_args.ar_spectator`. On `FS_CONTEXT_FOR_RECONFIGURE`, `gfs2_init_fs_context()` must copy `sdp->sd_args` into `fc->fs_private`, and `gfs2_reconfigure()` must sync `sdp->sd_tune` under `gt->gt_spin`. [F54, F75]

## Synchronization
- Every `dlm_lock()`/`dlm_unlock()` call on `ls->ls_dlm` in `lock_dlm.c` (`gdlm_lock()`, `gdlm_put_lock()`, `gdlm_cancel()`, `sync_lock()`, `sync_unlock()`) must hold `down_read(&ls->ls_sem)` and verify `ls->ls_dlm != NULL`. Release `ls->ls_recover_spin` before sleeping (`msleep_interruptible()`, `wait_on_bit()`, or `GFP_NOFS` allocations). In `control_mount()`, `mounted_mode` must track `mounted_lock` across `goto restart;` and demote it to `DLM_LOCK_NL` before re-locking `control_lock`. [F21, F110, F148]
- `sdp->sd_ail_lock` protects AIL lists and `bd->bd_tr`, must be held by callers of `gfs2_remove_from_ail()`, and nests inside `gfs2_log_lock(sdp)`. When `gfs2_ail1_start_one()` drops `sd_ail_lock` for writeback (`gfs2_jdata_writeback()` for jdata inodes, else `mapping->a_ops->writepages()`), it must return `-EBUSY` after relocking so `gfs2_ail1_flush()` restarts iteration; `gfs2_ail1_wait()` must call `get_bh(bh)` before dropping `sd_ail_lock` for `wait_on_buffer(bh)`. [F27, F28, F151]
- Callers of `gfs2_log_try_reserve()` and `gfs2_log_release_revokes()` must hold `sdp->sd_log_flush_lock` (and if `__gfs2_log_try_reserve_revokes()` returns `revoke_blks == 0` but `__gfs2_log_try_reserve()` fails, `gfs2_log_try_reserve()` must call `gfs2_log_release_revokes(sdp, revokes)`), whereas `gfs2_log_reserve()`/`__gfs2_log_reserve()` callers must never hold `sd_log_flush_lock`. [F10, F150]
- In `gfs2_recover_func()`, journal replay must hold `sdp->sd_freeze_mutex` (after verifying `SDF_FROZEN` is clear) and `down_read(&sdp->sd_log_flush_lock)`. Every exit from the replay section must call `up_read(&sdp->sd_log_flush_lock)` before jumping to `fail_gunlock_nofreeze:`, and `j_gh`/`ji_gh` must only be dequeued when `jlocked` is non-zero (`jd->jd_jid != sdp->sd_lockstruct.ls_jid`). [F5, F30]
- For `struct gfs2_rgrpd`, lock nesting is `rgd->rd_gl` -> `rgrp_lock_local(rgd)` (`rgd->rd_mutex`, required for node-local bitmap/header updates under `LM_FLAG_NODE_SCOPE`) -> `rgd->rd_rsspin` (protecting `rd_rstree`, `rd_requested`, `rd_reserved`); release `rd_rsspin` before `rgrp_unlock_local()` or `gfs2_rgrp_error()`. Deleting an inode reservation via `gfs2_rs_delete(ip)` requires holding `ip->i_rw_mutex` in write mode and `atomic_read(&inode->i_writecount) <= 1`. [F6, F34, F160]
- In `quota.c`, spinlocks nest as `qd_lock` -> `spin_lock_bucket()` -> `qd->qd_lockref.lock` -> `gfs2_qd_lru` lock or `sdp->sd_bitmap_lock` (`gfs2_qd_isolate()` must use `spin_trylock(&qd->qd_lockref.lock)`). Multiple `qd->qd_gl` acquisitions in `do_sync()`/`gfs2_quota_lock()` must sort the `gfs2_quota_data *` array with `sort_qd` (dereferencing `const struct gfs2_quota_data **`), and `do_sync()`/`gfs2_set_dqblk()` must lock `inode_lock(&ip->i_inode)` -> `qd->qd_gl` -> `ip->i_gl`. [F31, F146, F159]
- When `gfs2_inplace_reserve()` finds `rs->rs_rgd->rd_gl` already locked (`gfs2_glock_is_locked_by_me()`), leave `ip->i_rgd_gh` uninitialized, and check `gfs2_holder_initialized(&ip->i_rgd_gh)` in `gfs2_inplace_release()` before `gfs2_glock_dq_uninit()`. Similarly, `gfs2_dirty_inode()` and `gfs2_rindex_update()` must check `gfs2_glock_is_locked_by_me()` (and `current->journal_info == NULL` in `gfs2_dirty_inode()`) and only release the glock/transaction if they acquired it. [F17, F18]
- In `evict_should_delete()`, lock `ip->i_gl` with `GL_SKIP` and verify `gfs2_check_blk_type(sdp, ip->i_no_addr, GFS2_BLKST_UNLINKED)` before `gfs2_instantiate(gh)`. Under `PF_MEMALLOC`, `gfs2_drop_inode()`, `evict_should_delete()`, and `gfs2_glock_put_eventually()` must defer deletion via `gfs2_queue_verify_delete()` and put glocks via `gfs2_glock_put_async()`. [F161, F172]

## Object Lifetimes
- `sb->s_fs_info` must remain set to `sdp` until `free_sbd()` after all superblock inodes (`sdp->sd_inode`) are released via `iput()`, because `gfs2_drop_inode()` dereferences `GFS2_SB(inode)`. Because `gfs2_gl_hash_clear()` destroys and clears `sdp->sd_glock_wq = NULL`, later error paths in `gfs2_fill_super()` must check `sdp->sd_glock_wq != NULL` before `destroy_workqueue()`. Release `sdp->sd_sc_inode` via `free_local_statfs_inodes(sdp)`, never `iput(sdp->sd_sc_inode)`. [F1, F2, F117]
- `gfs2_put_super()` must set `SDF_NORECOVERY`, issue `smp_mb()`, and wait on `JDF_RECOVERY` for all journals before `gfs2_make_fs_ro()` stops threads, syncs quota/statfs, runs a normal `gfs2_log_flush()` before `GFS2_LOG_HEAD_FLUSH_SHUTDOWN`, and calls `gfs2_quota_cleanup()` (which asserts `SDF_NORECOVERY` or `!SDF_JOURNAL_LIVE` and waits on `sdp->sd_kill_wait` for `sd_quota_count == 0`). `exit_gfs2_fs()` must finish shrinker/glock/workqueue/LRU teardown and `rcu_barrier()` before destroying `gfs2_page_pool` and slab caches. [F14, F36, F37, F169, F170]
- In `gdlm_put_lock()`, skipping `dlm_unlock()` when `SDF_SKIP_DLM_UNLOCK` is set is only allowed if `!gl->gl_lksb.sb_lvbptr || gl->gl_state != LM_ST_EXCLUSIVE`, and must defer freeing `gl` via `gfs2_glock_free_later(gl)` onto `sdp->sd_dead_glocks`. In `gfs2_evict_inode()`, detaching `ip->i_gl` requires `glock_clear_object(ip->i_gl, ip)`, `wait_on_bit_io()` for `GIF_GLOP_PENDING`, `gfs2_glock_put_eventually()`, and `rcu_assign_pointer(ip->i_gl, NULL)`. [F4, F20]
- `gfs2_pin()` calls `get_bh(bh)`; when `gfs2_unpin()` moves the buffer to `tr->tr_ail1_list`, it must call `brelse(bh)` if `bd->bd_tr` was already non-NULL so `bd` holds one `bh` reference until `gfs2_remove_from_ail()`. `gfs2_ail_drain()` must call `gfs2_ail_empty_tr()` on both `&tr->tr_ail1_list` and `&tr->tr_ail2_list`. `gfs2_rgrp_brelse()` and `gfs2_rgrp_go_instantiate()` failure paths must set `bi->bi_bh = NULL` after `brelse()` (and `gfs2_rgrp_brelse()` sets `GLF_INSTANTIATE_NEEDED`). [F8, F16, F105]

## API Contracts
- Any `struct page` passed to `gfs2_log_write_page()` (or `gfs2_log_write()` without `buffer_head`s) must come from `gfs2_page_pool` and is freed by `gfs2_end_log_write()`. Synchronous header writes in `log_write_header()` and `clean_journal()` must pass `REQ_SYNC` alongside `REQ_PREFLUSH | REQ_FUA | REQ_META`. `gfs2_meta_read()` and `gfs2_meta_buffer()` call `brelse(bh)` internally on failure, so callers only `brelse(*bhp)` on `0` return. [F7, F12, F166]
- Callers of `gfs2_queue_verify_delete(gl, ...)` must hold a reference on `gl` beforehand and drop it if and only if it returns `false`. `gfs2_lookupi()` can return `NULL` or `ERR_PTR` (check `IS_ERR_OR_NULL()`), whereas `gfs2_lookup_meta()` converts `NULL` to `ERR_PTR(-ENOENT)`. `gfs2_internal_read()` advances `*pos` by `size`, so `gfs2_adjust_quota()` must subtract `sizeof(q)` from `loc` before writing back. [F19, F42, F49]
- Return conventions: `__get_log_header()`/`get_log_header()` return `0` for valid, `1` for validation failure (`foreach_descriptor()` must translate `1` to `-EIO`), or negative errno; `gfs2_revoke_add()` returns `1` on insert, `0` on update, or `-ENOMEM` (test `error < 0`); `read_rindex_entry()` returns `0` on entry, `1` at EOF, or negative errno; `gfs2_bitfit()` requires a 64-bit-aligned `buf` padded to `ALIGN(len, 8)` and returns `BFITNOENT` (`(u32)~0`) on miss; `gfs2_reservation_check_and_update()` returns `0`, `1` (advanced), or `-E2BIG`. [F43, F44, F46, F47, F48, F135]

## Error Handling
- In `init_statfs()` and `init_per_node()`, calling `iput(pn)` during normal execution requires immediately setting `pn = NULL` because error labels call `iput(pn)`, and any `lsi` failing before `list_add_tail()` in `init_statfs()` must be freed with `kfree(lsi)`. Callers of `filemap_grab_folio()` must check `IS_ERR(folio)` rather than `!folio`. [F3, F41]
- Nullability and live-journal guards: `gfs2_journal_wipe()`, `gfs2_dirty_inode()`, and `gfs2_evict_inode()` must check `ip->i_gl != NULL`; `gfs2_evict_inode()` must check `sdp->sd_jdesc != NULL` and `gfs2_log_flush()` must check `SDF_JOURNAL_LIVE` under `sd_log_flush_lock`; `gfs2_rgrp_dump()` must check `rgd->rd_rgl != NULL`; mark uninitialized `gfs2_holder`s with `gfs2_holder_mark_uninitialized()`. When `evict_should_delete()` fails to lock `ip->i_gl` or `gfs2_evict_inode()` cannot defer delete (`!ip->i_iopen_gh.gh_gl` or `SDF_KILL`), fall back to `EVICT_SHOULD_SKIP_DELETE`. [F51, F52, F53, F55, F58, F101]
- In `gfs2_rgrp_go_instantiate()`, the second loop must use `y` rather than `x` so `fail:` (`while (x--)`) releases all `length` buffers. In `gfs2_alloc_blocks()`, allocation/counter failure must call `gfs2_rgrp_error()` and return `-EIO` (not `BUG()`). In `gfs2_rgrp_send_discards()`, `sb_issue_discard()` failure must only warn and clear `ar_discard = 0`, never withdraw. [F112, F183, F184]

## External Contracts
- Before computing CRCs or exporting LVBs, zero `str->rg_crc`/`rg_reserved` in `gfs2_rgrp_out()`, the page and `lh_header.__pad0` in `gfs2_write_log_header()`, and `__pad` in `gfs2_rgrp_ondisk2lvb()`/`update_qd()`; preserve the `LH_V1_SIZE` split between `lh_hash` (CRC32) and `lh_crc` (CRC32C, accepting `0` on read). Mask `GFS2_RDF_MASK` when copying `rgd->rd_flags` to/from on-disk `rg_flags` or LVB `rl_flags`. `ls_control_lvb` uses little-endian `__le32` at offset 0 and `*_bit_le` at `JID_BITMAP_OFFSET`. [F61, F85, F87, F89]

## Known Pitfalls
- Because `sizeof(struct gfs2_quota)` is 88 bytes, a quota record at `qd2offset(qd)` can straddle a block/page boundary: split writes across pages in `gfs2_write_disk_quota()`, map/log both buffers in `gfs2_write_buf_to_page()`, and reserve an extra transaction block in `do_sync()`/`gfs2_set_dqblk()`. In `buf_lo_scan_elements()` and `databuf_lo_scan_elements()`, advance `ptr` (once for metadata, twice for jdata) before `if (gfs2_revoke_check(...)) continue;`. [F92, F115]
- In `gfs2_rbm_find()`, `GFS2_BLKST_UNLINKED` searches must read `bh->b_data + bi->bi_offset` (not `bi->bi_clone`), and wrap-around must set `last_bii = rbm->bii - (rbm->offset == 0)`, break at `rbm->bii == 0` if `wrapped || nowrap` before setting `wrapped = true`, and break when `wrapped && rbm->bii > last_bii`. In `try_rgrp_unlink()`, call `gfs2_rbm_from_block(&rbm, block + 1)` before any `continue`. In `gfs2_bitfit()`, guard the tail mask shift with `(len & (sizeof(u64) - 1)) != 0`. [F83, F98, F113, F114, F123]
- In `do_glock()`, reset `force_refresh = 0` after `update_qd()` before `goto restart;`. In `gfs2_upgrade_iopen_glock()`, check `glock_needs_demote(ip->i_gl)`, not `gh->gh_gl`. In `gfs2_jhead_folio_search()`, use `lh.lh_sequence >= head->lh_sequence` so sequence 0 is recorded. Cast `abs(delta) - s->stats[index]` to `(s64)` before `>> 2` in `gfs2_update_stats()`, check `len >= (u64)1 << 32` in `gfs2_reservation_check_and_update()`, and skip `0` on `rd_igeneration++` in `gfs2_alloc_blocks()`. [F99, F111, F116, F118, F124, F131]
