# KFENCE

Kernel Electric-Fence (KFENCE) is a low-overhead, sampling-based memory safety error detector for the Linux kernel heap (SLUB/SLAB). It allocates objects from a dedicated page pool surrounded by unmapped guard pages and in-page canary bytes, intercepting page faults and deallocations to detect and report out-of-bounds accesses, use-after-free accesses, memory corruption, and invalid frees.

## Architecture & Data Flow

- Every `struct kfence_metadata` entry must maintain `ALIGN_DOWN(meta->addr, PAGE_SIZE) == metadata_to_pageaddr(meta)`: `kfence_init_pool()` initializes `meta->addr` to the object page base while `KFENCE_OBJECT_UNUSED`, and `kfence_guarded_alloc()` must reset `meta->addr` via `metadata_to_pageaddr(meta)` before applying right-side offsets. Broken by: leaving `meta->addr` zeroed at init or computing a new allocation's address from the previous `meta->addr`, triggering `KFENCE_WARN_ON` in `metadata_to_pageaddr()`. [F50]
- Object pages start mapped in `KFENCE_OBJECT_UNUSED` and are protected on transition to `KFENCE_OBJECT_FREED`. `kfence_guarded_alloc()` must unprotect `meta->addr` via `kfence_unprotect()` when reusing a `KFENCE_OBJECT_FREED` object, and `kfence_guarded_free()` must unprotect `addr` before `check_canary()` under `CONFIG_KFENCE_STRESS_TEST_FAULTS`. [F51]
- In `kfence_guarded_free()`, if `meta->unprotected_page` is non-zero, the entire page at `ALIGN_DOWN(meta->unprotected_page, PAGE_SIZE)` must be zeroed with `memzero_explicit()`, re-protected via `kfence_protect()`, and `meta->unprotected_page` reset to 0 before returning the object to `kfence_freelist`. [F43]
- Unlinking `meta` from `kfence_freelist` in `kfence_guarded_alloc()` must use `list_del_init(&meta->list)` rather than `list_del()`, because `kfence_guarded_free()` checks `KFENCE_WARN_ON(!list_empty(&meta->list))` when returning the object to `kfence_freelist`. [F73]
- `kfence_allocation_gate` and `allocation_gate` in `__kfence_alloc()` must use signed `int` comparisons (`> 0` in `kfence_alloc()` and `toggle_allocation_gate()`, and `> 1` in `__kfence_alloc()`) because `toggle_allocation_gate()` sets `kfence_allocation_gate` to `-kfence_burst`. Stack trace capture (`stack_trace_save()`) and Bloom filter coverage checks (`get_alloc_stack_hash()`, `alloc_covered_contains()`) in `__kfence_alloc()` must run only after `atomic_inc_return(&kfence_allocation_gate)` confirms a sample slot (`allocation_gate <= 1`). [F71, F84]
- `KFENCE_METADATA_SIZE` must remain `PAGE_ALIGN`-ed so dividing `KFENCE_METADATA_SIZE` by `PAGE_SIZE` in `kfence_init_late()` rounds up to cover any partial trailing page of `kfence_metadata_init`. [F85]
- In `get_stack_skipnr()`, the early-exit `goto found` list must only include initial slab entry points (`kfree`, `kmem_cache_free`, `__kmalloc`, `kmem_cache_alloc`), while internal KFENCE/slab helpers (`kfence_`, `__kfence_`, `__kmem_cache_free`, `__slab_free`) must only advance `fallback = skipnr + 1` and continue scanning. Its return value must be clamped to `< num_entries` (falling back to 0), and `kfence_to_kp_stack()` must bound `j < KS_ADDRS_COUNT` and write a `NULL` sentinel at `kp_stack[j]`. [F66, F79]
- In `objects_sops`, `start_object()` and `next_object()` must return `(void *)((long)*pos + 1)` for `*pos < CONFIG_KFENCE_NUM_OBJECTS` and `show_object()` must index `&kfence_metadata[(long)v - 1]` because `seq_file` treats a `NULL` (0) cursor as end-of-iteration. [F65]

## Synchronization

- `kfence_freelist_lock` and `struct kfence_metadata::lock` are `raw_spinlock_t` locks acquired with IRQs disabled (`raw_spin_lock_irqsave()`). All `meta->list` operations on `kfence_freelist` must be serialized by `kfence_freelist_lock`, `kfence_freelist_lock` must never be held while acquiring `meta->lock`, and helpers that may acquire non-raw `spinlock_t` locks (like `get_random_u32_below()`) must execute outside both locks. [F19, F101]
- Callers of `metadata_update_state()`, `kfence_print_object()`, and `kfence_report_error()` (when `meta` is non-`NULL`) must hold `meta->lock` via `raw_spin_lock_irqsave()` (or `raw_spin_trylock_irqsave()`). [F20]
- In `kfence_guarded_free()`, checking `kfence_obj_allocated(meta) && meta->addr == (unsigned long)addr`, restoring protection on `meta->unprotected_page`, and updating `meta->state` to `KFENCE_OBJECT_FREED` via `metadata_update_state()` must happen within a single `meta->lock` critical section. [F26]
- When freeing an object from a `SLAB_TYPESAFE_BY_RCU` cache, `__kfence_free()` must set `meta->state` to `KFENCE_OBJECT_RCU_FREEING` via `metadata_update_state()` under `meta->lock` before calling `call_rcu(&meta->rcu_head, rcu_guarded_free)`, and `metadata_update_state()` must preserve `meta->free_track` when transitioning out of `KFENCE_OBJECT_RCU_FREEING`. [F23]
- Stores to `meta->state` in `metadata_update_state()` and `meta->cache` in `kfence_guarded_alloc()` must use `WRITE_ONCE()` to pair with lockless `READ_ONCE()` checks in `kfence_obj_allocated()`, `kfence_shutdown_cache()`, and `kfence_handle_page_fault()`, and `kfence_shutdown_cache()` must revalidate both fields after acquiring `meta->lock`. [F24]
- In `__kfence_alloc()`, when `kfence_allocation_gate` transitions to 1 and `waitqueue_active(&allocation_wait)` is true, waking `allocation_wait` must be deferred via `irq_work_queue(&wake_up_kfence_timer_work)` instead of calling `wake_up()` directly during slab allocation. [F99]
- Architecture implementations of `kfence_protect_page()` must not send cross-CPU IPIs for TLB shootdowns (and must disable preemption with `preempt_disable()` around local-CPU TLB flushes on x86, LoongArch, and RISC-V) because `kfence_protect_page()` runs with interrupts disabled under `meta->lock` or during page faults. [F27]
- `kfence_debugfs_init()` must check `READ_ONCE(kfence_enabled)` before registering debugfs files, and `kfence_init_late()` must call `kfence_debugfs_init()` only after `kfence_init_pool()` and `kfence_init_enable()` succeed so `show_object()` cannot dereference `NULL` `kfence_metadata` or lock uninitialized `meta->lock`. [F18]

## Object Lifetimes

- During `kfence_shutdown_cache(s)`, after converting still-allocated objects of `s` into zombie freed objects via `kfence_guarded_free(..., true)` (releasing `meta->lock` before calling `kfence_guarded_free()`), a second pass must set `meta->cache = NULL` under `meta->lock` for all `KFENCE_OBJECT_FREED` objects referencing `s`. [F25]
- Once `__kfence_pool` is initialized, disabling KFENCE at runtime must not free `__kfence_pool` or `kfence_metadata`, and re-enabling in `kfence_enable_late()` when `__kfence_pool` is non-`NULL` must skip `kfence_init_late()` and only set `kfence_enabled` and re-queue `kfence_timer`. [F14]
- When `kfence_init_pool()` succeeds in `kfence_init_pool_early()`, it must call `kmemleak_ignore_phys(__pa(__kfence_pool))` so the memblock-allocated pool does not overlap in kmemleak with individual KFENCE objects; this must not be called in `kfence_init_late()` where the pool comes from the page allocator. [F7]
- DebugFS files `/sys/kernel/debug/kfence/objects` and `stats` must use `DEFINE_SEQ_ATTRIBUTE()` and `DEFINE_SHOW_ATTRIBUTE()` (or wire `.release` to `seq_release` / `single_release`) so `seq_file` allocations are freed on close. [F16]
- In `mm/kfence/kfence_test.c`, `kfence_suite_exit()` must call `tracepoint_synchronize_unregister()` after `unregister_trace_console(probe_console, NULL)` so all in-flight `probe_console()` callbacks complete before module exit. [F28]

## API Contracts

- `addr_to_metadata()` must compute `index = (addr - (unsigned long)__kfence_pool) / (PAGE_SIZE * 2) - 1` in a signed type and reject `index < 0 || index >= CONFIG_KFENCE_NUM_OBJECTS` so addresses outside `__kfence_pool`, in the first two guard pages (`index == -1`), or in the trailing guard page return `NULL`. Callers (`kfence_handle_page_fault()`, `kfence_ksize()`, `kfence_object_start()`, `__kfence_obj_info()`) must check `addr_to_metadata(addr)` for `NULL` even after `is_kfence_address(addr)` succeeds, while `__kfence_free()` requires a valid KFENCE object address and callers freeing arbitrary heap pointers must use `kfence_free()` and check its boolean return. [F35, F36, F59]
- `__kfence_alloc()` must reject allocations with `size > PAGE_SIZE`, `flags & GFP_ZONEMASK`, `(flags & __GFP_THISNODE) && num_online_nodes() > 1`, `s->flags & (SLAB_CACHE_DMA | SLAB_CACHE_DMA32)`, or `s->flags & SLAB_SKIP_KFENCE` before incrementing `kfence_allocation_gate`. [F110]
- `__kfence_obj_info()` must return `false` when `addr_to_metadata((unsigned long)object)` is `NULL`, and when non-`NULL` must set `kpp->kp_ptr = object` and return `true` immediately on `WARN_ON(meta->state == KFENCE_OBJECT_UNUSED)` without copying uninitialized metadata. [F119]
- `kfence_protect_page(addr, protect)` expects a page-aligned virtual address (via `ALIGN_DOWN(addr, PAGE_SIZE)` in `kfence_protect()` / `kfence_unprotect()`) and returns `true` on success; arch implementations calling `set_memory_valid()` or `__kernel_map_pages()` must pass `!protect`. [F45]
- `regs` in `kfence_handle_page_fault()` and `kfence_report_error()` may be `NULL` (falling back to `stack_trace_save()` with `get_stack_skipnr()` and `dump_stack_print_info()` instead of `stack_trace_save_regs()` and `show_regs()`), and `seq` in `kfence_print_object()`, `kfence_print_stack()`, and `seq_con_printf()` may be `NULL` to print via `vprintk()`. [F39, F40]

## Error Handling

- In `kfence_guarded_alloc()`, if `raw_spin_trylock_irqsave(&meta->lock, flags)` fails after popping `meta` from `kfence_freelist`, it must re-acquire `kfence_freelist_lock` and return `meta->list` to `kfence_freelist` before returning `NULL`. [F9]
- Metadata initialization must use `kfence_metadata_init` and only publish it to `kfence_metadata` via `smp_store_release()` after `kfence_init_pool()` succeeds, while `kfence_shutdown_cache()` must check `smp_load_acquire(&kfence_metadata)` for `NULL` before indexing. [F32]
- On `kfence_init_pool()` failure (returning non-zero `addr` where protection failed), `kfence_init_pool_early()` and `kfence_init_late()` must only free the unprotected tail `[addr, __kfence_pool + KFENCE_POOL_SIZE)`, free `kfence_metadata_init`, and set `__kfence_pool` and `kfence_metadata_init` to `NULL`. In `kfence_alloc_pool_and_metadata()`, if `memblock_alloc()` for `kfence_metadata_init` fails, `__kfence_pool` must be freed via `memblock_free()` and set to `NULL`. [F4, F6]
- `meta->cache` can be `NULL` after `kfence_shutdown_cache()` destroys the owning `kmem_cache`, so readers such as `__kfence_free()` and `kfence_print_object()` must check `meta->cache` for `NULL` before dereferencing it. [F37]
- Internal KFENCE invariant and page-protection failures must use `KFENCE_WARN_ON()` (which sets `kfence_enabled = false` and `disabled_by_warn = true`, making `param_set_sample_interval()` reject re-enabling with `-EINVAL`), whereas detected target memory bugs must call `kfence_report_error()` without disabling KFENCE. [F117]

## External Contracts

- Heap allocators must never place KFENCE objects onto regular slab freelists and must abort normal slab deallocation whenever `kfence_free()` returns `true`. [F1]
- `print_diff_canary()` and `kfence_report_error()` must gate printing raw corrupted bytes (`0x%02x`) and `show_regs(regs)` behind `no_hash_pointers`, and `print_diff_canary()` must clamp `end` to `meta->addr` (left canary) or `PAGE_ALIGN(address)` (right canary). [F118]
- `probe_console()` must bound console tracepoint searches to `len` with `strnstr()` and copy at most `min(len + 1, sizeof(observed.lines[0]))` bytes via `strscpy()`, and `kfence_report_error()` must preserve the `"BUG: KFENCE: "` and `"at 0x"`/`"of 0x"` prefixes matched by `probe_console()` and `report_matches()`. [F68]
- `get_stack_skipnr()` must prepend `ARCH_FUNC_PREFIX` (defined as `"."` on `CONFIG_PPC64_ELF_ABI_V1` in `<asm/kfence.h>`) to every matched symbol prefix. [F121]

## Known Pitfalls

- In `is_kfence_address()`, `(unsigned long)((char *)addr - __kfence_pool) < KFENCE_POOL_SIZE` must use the `unsigned long` cast and be followed by `&& __kfence_pool` on the right-hand side so addresses below `KFENCE_POOL_SIZE` are rejected when `__kfence_pool` is `NULL` without adding a load to the fast path. [F69, F82]
- `kfence_init_pool()` must read `__kfence_pool` into `addr` and `start_pfn` only after `arch_kfence_init_pool()` returns, and `arch_kfence_init_pool()` implementations that remap `__kfence_pool` (e.g., LoongArch) must restore `__kfence_pool` and free the `vm_struct` on failure. [F8]
- `KFENCE_CANARY_PATTERN_U64` must convert `0x0706050403020100` with `le64_to_cpu()` to match `KFENCE_CANARY_PATTERN_U8(addr)` on big-endian machines; `set_canary()` and `check_canary()` must only access `*(u64 *)addr` at `sizeof(u64)`-aligned addresses and handle unaligned boundary bytes with `check_canary_byte()`. In `check_canary()`, left-side corruption (`addr < meta->addr`) must `break` rather than `return` so right-side canary bytes are also checked. [F62, F72, F91]
- In `get_alloc_stack_hash()` and `metadata_update_state()`, the decayed `unsigned long *stack_entries` entry count must be multiplied by `sizeof(stack_entries[0])` for `jhash()` and `memcpy()`, whereas `stack_trace_save()` and `filter_irq_stacks()` take entry counts. [F90]
- In `kfence_print_stack()`, all stack fields must be read through `track` (`show_alloc ? &meta->alloc_track : &meta->free_track`), and `u64` nanosecond values (`track->ts_nsec`, `interval_nsec`) must be divided by `NSEC_PER_SEC` using `do_div()`. [F78, F81]
- `metadata_update_state()` must remain `noinline` when calling `stack_trace_save(..., 1)`, and `test_free()` in `mm/kfence/kfence_test.c` must remain `__always_inline` so stack skip counts match. [F108]
