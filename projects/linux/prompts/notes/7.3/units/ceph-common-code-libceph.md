# CEPH COMMON CODE (LIBCEPH)

Provides the core Ceph client library (libceph) headers and common infrastructure shared by the CephFS filesystem and RBD block device driver, including client session lifecycle and mount option parsing, v1/v2 TCP messenger, authentication (none and cephx with AES/HMAC crypto and keyring integration), RADOS object class lock operations, CRUSH placement algorithms, wire encoding/decoding helpers, and debugfs inspection.

## Architecture & Data Flow
- Generic `struct ceph_connection` handlers in `net/ceph/messenger.c` must check `ceph_msgr2(from_msgr(con->msgr))` before accessing `con->v1` or `con->v2`, which share an anonymous union. [F32]
- Every `struct ceph_messenger` on a connection or passed to `ceph_encode_my_addr()` must be embedded in `struct ceph_client` (downcast via `from_msgr()`); every authorizer (`struct ceph_none_authorizer`, `struct ceph_x_authorizer`) must keep `struct ceph_authorizer base` at offset 0; and every CRUSH bucket subtype (`crush_bucket_uniform`, `crush_bucket_list`, `crush_bucket_tree`, `crush_bucket_straw`, `crush_bucket_straw2`) must keep `struct crush_bucket h` at offset 0 matching `h.alg`. [F111, F112, F113]
- In `ceph_con_get_out_msg()`, `con->ops->reencode_message(msg)` must only run inside `if (msg->needs_out_seq)` when `msg->hdr.seq` is assigned and `needs_out_seq` is cleared, so messages requeued by `con_fault()` are not re-encoded on retry. `ceph_con_discard_requeued()` must stop on `msg->needs_out_seq` before comparing `msg->hdr.seq` to `reconnect_seq` (unsent tail messages have `seq == 0`). Unlinking from `con->out_queue` or `con->out_sent` must use `list_del_init()` (via `ceph_msg_remove()`) because `ceph_msg_revoke()`, `ceph_msg_release()`, and `ceph_con_send()` check `list_empty(&msg->list_head)`. [F50, F91, F92]
- In `ceph_msg_data_iter_next()` and `ceph_msg_data_iter_advance()`, `cursor->lastlen` tracks bytes pre-advanced by `iov_iter_get_pages2()`: `ceph_msg_data_iter_next()` must revert `cursor->lastlen` when non-zero, and `ceph_msg_data_iter_advance()` must advance `cursor->iov_iter` only by `bytes - cursor->lastlen` when `bytes >= cursor->lastlen`. For `CEPH_MSG_DATA_PAGELIST`, the first page in `pagelist->head` must start at offset 0 and preceding pages must be filled to `PAGE_SIZE`, as `ceph_msg_data_pagelist_next()` and `ceph_msg_data_pagelist_advance()` derive the offset from `cursor->offset & ~PAGE_MASK`. [F94, F146]
- `ceph_compare_options()` uses `memcmp(opt1, opt2, offsetof(struct ceph_options, mon_addr))`, so pointers or non-trivially-comparable fields must be placed at or after `mon_addr` and compared explicitly. Every option in `ceph_print_client_options()` must end with `,` because `m->count` is unconditionally decremented when `m->count != pos`. [F77, F89]
- In `struct ceph_auth_client_ops`, `update_authorizer`, `add_authorizer_challenge`, `verify_authorizer_reply`, `invalidate_authorizer`, `sign_message`, and `check_message_signature` are `NULL` in `ceph_auth_none_ops` and must be NULL-checked. In `ceph_x_invalidate_authorizer()`, invalidating `peer_type` via `invalidate_ticket(ac, peer_type)` must also call `invalidate_ticket(ac, CEPH_ENTITY_TYPE_AUTH)`. [F41, F58]
- In `struct ceph_osdmap`, `osd_state`, `osd_weight`, and `osd_addr` are sized to `map->max_osd` (requiring `0 <= osd < map->max_osd` as in `ceph_osd_exists()`), and `struct ceph_osds.primary` stores the primary OSD ID (or `-1` when empty), not an index into `set->osds[]`. [F86]
- In `struct crush_map`, item IDs `0 <= item < map->max_devices` (type `0`) are devices, while negative IDs (`id < 0`) are buckets indexing `map->buckets`, `work->work`, and `choose_args` at `-1 - id` (`< map->max_buckets`). For `crush_do_rule()`, `choose_args` needs `map->max_buckets` elements; for `CRUSH_BUCKET_STRAW2`, non-NULL `arg->ids` or `arg->weight_set[pos].weights` need `>= bucket->h.size` elements, and `get_choose_arg_weights()` must clamp `position >= arg->weight_set_size` to `arg->weight_set_size - 1`. `struct crush_bucket_tree` maps 0-based item `p` to 1-based `node_weights[crush_calc_tree_node(p)]` and leaf `n` to `h.items[n >> 1]`. [F72, F73, F75, F109]
- `crush_choose_firstn()` and `crush_choose_indep()` must check `in->size != 0` before calling `bucket_perm_choose()` or `crush_bucket_choose()`. In `bucket_perm_choose()`, if `work->perm_n == 0xffff` (`pr == 0` sentinel), a subsequent `pr > 0` call with the same `x` must initialize `work->perm[1..bucket->size-1] = i`, `work->perm[work->perm[0]] = 0`, and `work->perm_n = 1`. In `crush_choose_firstn()`, `retry_descent` resets `in = bucket` and `flocal = 0` while preserving `ftotal`, whereas descending into a child bucket sets `in = map->buckets[-1-item]` and `retry_bucket = 1`. [F95, F96, F103]
- `ceph_has_room()` checks `end >= *p` and `n <= end - *p` (avoiding `*p + n` overflow). `ceph_decode_entity_addr_versioned()` must reject `addr_len > sizeof(addr->in_addr)`, zero `addr->in_addr`, and set `*p = struct_end` upon completion. RADOS lock encoders (`ceph_cls_lock()`, `ceph_cls_unlock()`, `ceph_cls_break_lock()`, `ceph_cls_set_cookie()`, `ceph_cls_lock_info()`, `ceph_cls_assert_locked()`) must verify wire size `<= PAGE_SIZE` (else `-E2BIG`) before allocating a page. [F65, F70, F81]

## Synchronization
- `con->mutex` ranks inner to client locks (`osdc->lock`, `osd->lock`, `monc->mutex`), so `cancel_con()` in `ceph_con_close()` must use non-blocking `cancel_delayed_work()` rather than `cancel_delayed_work_sync()` while holding `con->mutex`. [F121]
- In `ceph_tcp_connect()`, `set_sock_callbacks()` and `con_sock_state_connecting()` must precede `kernel_connect()`, which can immediately invoke `ceph_sock_state_change()` expecting `sk->sk_user_data` and `con->sock_state == CON_SOCK_STATE_CONNECTING`. `ceph_con_close_socket()` must clear `CEPH_CON_F_SOCK_CLOSED` after closing `con->sock`, as `ceph_sock_state_change()` sets it asynchronously without `con->mutex`. [F18, F21]
- `ceph_con_process_message()` must clear `con->in_msg = NULL` before unlocking `con->mutex` to call `con->ops->dispatch(con, msg)`, and `dispatch` callbacks must not synchronously wait on other incoming messages on `ceph_msgr_wq`. [F27]
- Helpers allocating with `GFP_KERNEL` on messenger/cephx I/O paths (`sock_create_kern()` in `ceph_tcp_connect()`, `crypto_alloc_sync_skcipher()` in `set_secret()`) must be wrapped in `memalloc_noio_save()` / `memalloc_noio_restore()`, and TCP sockets must set `sk_allocation = GFP_NOFS`. [F126]
- Readers acquiring a reference to an RCU-protected `struct ceph_string *` (e.g. `ci->i_layout.pool_ns`) without holding the update-side lock must use `ceph_try_get_string()` rather than `ceph_get_string()`. [F29]
- OSD client lock ordering is `osdc->lock` -> `osd->lock` (as in `osdc_show()` -> `dump_requests()`). Searching `osd->o_requests` requires holding either `osd->lock` or `osd->o_requests_lock`, whereas inserting or removing requires holding both. [F31, F125]

## Object Lifetimes
- In `ceph_con_close()`, `ceph_con_reset_protocol()` must precede `ceph_con_reset_session()`, because `ceph_con_reset_protocol()` releases and nulls `con->in_msg` and `con->out_msg`, which `ceph_con_reset_session()` asserts are `NULL` before draining `con->out_queue` and `con->out_sent`. [F8]
- `queue_con_delay()` takes a `con` ref via `con->ops->get(con)` before queueing `con->work` (dropping it if `queue_delayed_work()` returns `false`), which must be released at the end of `ceph_con_workfn()` or by `cancel_con()` when `cancel_delayed_work(&con->work)` returns `true`. [F9]
- `ceph_con_get_out_msg()` moves `msg` to `con->out_sent` (keeping the queue ref) and takes a second ref for `con->out_msg`, so any path stopping `con->out_msg` (`ceph_msg_revoke()`, `ceph_con_reset_protocol()`, or send completion) must call `ceph_msg_put(con->out_msg)` and set `con->out_msg = NULL`. [F12]
- `ceph_con_in_msg_alloc()` drops `con->mutex` across `con->ops->alloc_msg(con, hdr, skip)` and re-locks it; if `con->state != CEPH_CON_S_OPEN` after re-locking or `ceph_alloc_middle()` fails, it must release `msg` via `ceph_msg_put()` and leave `con->in_msg == NULL`. [F13]
- `ceph_msg_data_destroy()` frees `CEPH_MSG_DATA_PAGES` vectors via `ceph_release_page_vector()` if and only if `data->own_pages` is `true`; callers allocating a dedicated page vector for a `struct ceph_msg` must pass `own_pages = true` to `ceph_msg_data_add_pages()` (and clear `data->own_pages = false` if transferring `data->pages` out). [F15]
- `ceph_messenger_init()` pins `current->nsproxy->net_ns` into `msgr->net` via `get_net()` (released by `put_net()` in `ceph_messenger_fini()`), `ceph_tcp_connect()` must use `read_pnet(&con->msgr->net)`, and `ceph_compare_options()` must reject sharing when `!net_eq(current->nsproxy->net_ns, read_pnet(&client->msgr.net))`. [F134]

## API Contracts
- `ceph_con_send()` always consumes one `@msg` reference (dropping it immediately if `con->state == CEPH_CON_S_CLOSED`, or holding it on `con->out_queue` / `con->out_sent`). `ceph_connection_operations.get` and `.put` must be atomic/softirq-safe and non-sleeping because `queue_con_delay()` calls them from TCP socket callbacks. [F11, F120]
- In `ceph_con_in_msg_alloc()`, `con->ops->alloc_msg(con, hdr, skip)` returns `NULL` both when skipping (`*skip != 0`, returning `0` with `con->in_msg == NULL`) and on allocation failure (`*skip == 0`, returning `-ENOMEM`), and must never return non-NULL `msg` with `*skip != 0`. [F37]
- `ceph_con_flag_*()` helpers take a `CEPH_CON_F_*` bit index (`0..4`), not a shifted bitmask, and `BUG_ON` if `!con_flag_valid(con_flag)`. Any new `CEPH_CON_F_*` flag or `CEPH_CON_S_*` state must be added to `con_flag_valid()` or `con_sock_closed()`. [F45, F90]
- Messages passed to `ceph_msg_data_add_*()` must be allocated via `ceph_msg_new2()` with sufficient `max_data_items` (not `ceph_msg_new()`, which sets `max_data_items = 0`). Callers iterating a `struct ceph_msg_data_cursor` must skip empty items via `ceph_msg_data_advance(cursor, 0)` while `!cursor->resid` and `cursor->total_resid > 0` before calling `ceph_msg_data_next()`, which hits `BUG_ON(!*length)`. [F43, F93]
- Every `struct ceph_object_id` must be initialized with `CEPH_DEFINE_OID_ONSTACK()` or `ceph_oid_init()` so `oid->name` points to `oid->inline_name`, and copied only via `ceph_oid_copy()` (never struct assignment or `memcpy()`). `struct ceph_object_locator` and `struct ceph_osds` must be initialized with `ceph_oloc_init()` and `ceph_osds_init()` (`pool == -1` and `primary == -1` denote empty, not `0`). [F34, F35, F114]
- Callers requiring the latest monitor `osdmap` (e.g. after OSD blocklisting or reusing a shared `ceph_client`) must call `ceph_wait_for_latest_osdmap()`. In `ceph_auth_client_ops.handle_reply`, `ceph_auth_set_global_id()` must be called as soon as the `CEPH_ENTITY_TYPE_AUTH` ticket is processed, before building service ticket requests. [F30, F49]
- `setup_sgtable()` must map `is_vmalloc_addr(buf)` buffers with `vmalloc_to_page()` and include the page offset via `PAGE_ALIGN(off + buf_len) >> PAGE_SHIFT` for `chunk_cnt`, and `teardown_sgtable()` must only call `sg_free_table(sgt)` when `sgt->orig_nents > 1`. `ceph_crypto_key_decode()` and `decode_con_secret()` must wipe secret material in the input buffer with `memzero_explicit()`, and `ceph_crypto_key_destroy()` must use `kfree_sensitive()`. [F105, F141, F142]
- `ceph_start_decoding()` checks 6-byte header bounds, rejects `v < struct_compat` with `-EINVAL`, and verifies `*struct_len` bytes remain. `ceph_extract_encoded_string()` validates bounds on a temporary cursor before allocating `len + 1` bytes, NUL-terminates `buf[len]`, and leaves `*p` and `*lenp` unchanged on error. [F66, F67]
- Callers of `crush_do_rule()` must pass a thread-local workspace of `>= crush_work_size(map, result_max)` bytes initialized by `crush_init_workspace(map, cwin)`, and re-initialize (and reallocate if needed) whenever `crush_map` changes. [F147]
- 32-bit wrapping sequence numbers (`ceph_seq_t`) must be compared via `ceph_seq_cmp(a, b)` against `0` (`< 0`, `<= 0`, `> 0`, `>= 0`). Bio-backed data types and helpers (`CEPH_MSG_DATA_BIO`, `CEPH_OSD_DATA_TYPE_BIO`, `struct ceph_bio_iter`, `ceph_msg_data_add_bio()`) must be guarded by `#ifdef CONFIG_BLOCK`. [F106, F143]

## Error Handling
- `ceph_extract_encoded_string()`, `ceph_create_client()`, `ceph_auth_init()`, and `ceph_alloc_page_vector()` return `ERR_PTR(-errno)` on failure (never `NULL`), whereas `ceph_buffer_new()`, `ceph_msg_new2()`, `ceph_msg_new()`, and `ceph_alloc_options()` return `NULL`. [F36]
- `ceph_auth_client_ops->handle_reply()` returns `-EAGAIN` when multi-step auth needs another request and `0` only when all keys are obtained (`ceph_auth_handle_reply_done()` `WARN_ON`s on `-EAGAIN` or `> 0`). In `decode_lockers()`, `*lockers` must be allocated with `kcalloc()` so partial failure safely passes `NULL` `id.cookie` pointers to `ceph_free_lockers()`. [F39, F48]

## External Contracts
- `ceph_entity_addr.in_addr.ss_family` is little-endian for versioned `entity_addr_t` (`marker == 1`), but big-endian for legacy `entity_addr_t` (`ceph_decode_entity_addr_legacy()`) and msgr1 banners (`ceph_encode_banner_addr()`). Feature checks must use `CEPH_HAVE_FEATURE(x, name)` or `HAVE_MSGR2_FEATURE(x, name)` (checking incarnation bits), and wire MDS open flags (`ceph_mds_request_args.open.flags`) must use `CEPH_O_*` constants rather than kernel `O_*` flags. [F68, F82, F84]

## Known Pitfalls
- Because `struct ceph_entity_addr` is `__attribute__((packed))` (at odd offset 9 in `struct ceph_entity_inst`), `addr->in_addr` fields (`ss_family`, `sin_port`, `sin6_port`) must be accessed via `get_unaligned()`/`put_unaligned()` or an aligned stack copy. `ENTITY_NAME(n)` expands to two printf arguments (`const char *`, `u64`), requiring `%s%lld` or `%s%llu`. [F69, F117]
- Read classification must use `ceph_osd_op_mode_read(op)` rather than `op & CEPH_OSD_OP_MODE_RD` (which is also set on `CEPH_OSD_OP_CALL`). In `struct ceph_options`, `CEPH_OPT_NOSHARE`, `CEPH_OPT_NOCRC`, and `CEPH_OPT_NOMSGSIGN` are set when disabled while `CEPH_OPT_TCP_NODELAY` is set when enabled; timeout options in `ceph_parse_param()` must check `<= INT_MAX / 1000` (and `>= 1` for keepalive/idle_ttl) and convert via `msecs_to_jiffies(result.uint_32 * 1000)`. [F63, F88, F137]
- In CRUSH buckets, 32-bit hashes in `bucket_list_choose()`, `bucket_tree_choose()`, and `bucket_straw_choose()` must be widened to `__u64` before multiplying by weights; in `bucket_straw2_choose()`, `crush_ln()` requires a 16-bit input (`u &= 0xffff`), and dividing `ln` by `weights[i]` requires checking `weights[i] != 0` (else `S64_MIN`) and using `div64_s64()`. [F100, F101, F102]
