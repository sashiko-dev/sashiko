# NETWORKING [UNIX SOCKETS]

Implements BSD filesystem and abstract `AF_UNIX` (`PF_UNIX`) sockets supporting `SOCK_STREAM`, `SOCK_DGRAM`, and `SOCK_SEQPACKET` communication, ancillary data (`SCM_RIGHTS` file descriptors and `SCM_CREDENTIALS`/pidfd), and `MSG_OOB` out-of-band data. Includes a Tarjan's SCC cycle-detecting garbage collector for in-flight file descriptors (`net/unix/garbage.c`), Netlink `SOCK_DIAG` monitoring (`net/unix/diag.c`), procfs/BPF socket iterators, and per-netns sysctls.

## Architecture & Data Flow

- In `net->unx.table.buckets`, `0..UNIX_HASH_MOD` hold unbound (`u->addr == NULL`) and BSD-bound sockets (`u->addr != NULL`, `u->path.dentry != NULL`), while `UNIX_HASH_MOD + 1..UNIX_HASH_SIZE - 1` hold abstract sockets (`u->addr != NULL`, `u->path.dentry == NULL`). `__unix_find_socket_byname()` assumes `u->addr != NULL` (never call it on `0..UNIX_HASH_MOD`), and `unix_seq_show()`, `sk_diag_dump_name()`, and `unix_open_file()` must NULL-check `u->addr` and `u->path.dentry`. [F39]
- Abstract sockets are scoped to `sock_net(sk)` via `net->unx.table.buckets`, while BSD sockets are indexed in both `net->unx.table.buckets` (`sk->sk_node` in `__unix_set_addr_hash()`) and global `bsd_socket_buckets` (`sk->sk_bind_node` in `unix_insert_bsd_socket()`) for cross-netns VFS inode lookup via `unix_find_bsd()` / `unix_find_socket_byinode()`; `unix_release_sock()` must unhash from both via `unix_remove_socket()` and `unix_remove_bsd_socket()`. [F52, F134]
- `unix_address.len` includes `offsetof(struct sockaddr_un, sun_path)` (plus trailing NUL only when `sun_path[0] != 0`), so `sk_diag_dump_name()` and `unix_seq_show()` must subtract `offsetof(struct sockaddr_un, sun_path)` from `addr->len` and never pass `sun_path` to string functions without checking `sun_path[0]`. [F107]
- Embryo sockets from `unix_stream_connect()` have `sk_socket == NULL` and `u->listener != NULL` until `unix_accept()` calls `sock_graft()`; peer paths (`unix_maybe_add_creds()`, `unix_dgram_sendmsg()`, `unix_edge_successor()`) must not dereference `other->sk_socket` without checking `other->sk_socket != NULL` or excluding `SOCK_STREAM`/`SOCK_SEQPACKET`. [F40]
- Partial `SOCK_STREAM` reads and `unix_stream_recv_urg()` advance `UNIXCB(skb).consumed` without decrementing `skb->len`; remaining payload must be queried via `unix_skb_len(skb)` and read offsets must start at `UNIXCB(skb).consumed + skip` (`unix_stream_read_actor()`, `unix_stream_splice_actor()`). In `unix_release_sock()`, checking `sk->sk_receive_queue` for unread data to set `skpair->sk_err = ECONNRESET` must skip a leading 0-length consumed OOB marker (`!unix_skb_len(skb)`) via `skb_peek_next()`. [F63, F79]
- In `manage_oob()`, on `!unix_skb_len(skb)`, return `NULL` to stop at the OOB mark only when `copied > 0` and `(!u->oob_skb || skb == u->oob_skb)`; when `copied == 0`, advance `skb` via `skb_peek_next()` (unlinking `skb` only if `!(flags & MSG_PEEK)`) and fall through to `if (skb != u->oob_skb)`. When `skb == u->oob_skb` with `!sock_flag(sk, SOCK_URGINLINE)` and `flags & MSG_PEEK`, set `skb = NULL` if `copied > 0`, or advance via `skb_peek_next()` without clearing `u->oob_skb` or unlinking if `copied == 0`. [F85, F86, F87]
- `unix_stream_read_generic()` is called with `state->msg == NULL` from `unix_stream_splice_read()`, so it must guard all `msg` dereferences with `if (msg)` and call `scm_destroy(&scm)` in the `else` branch when `msg` is `NULL`. [F41]
- When queuing an `skb` with `UNIXCB(skb).fp` to `other->sk_receive_queue`, `scm_stat_add(other, skb)` must be called under `unix_state_lock(other)` after all error checks; when consumed without `MSG_PEEK`, `scm_stat_del(sk, skb)` must precede `unix_detach_fds()` so `fp->inflight` is cleared before `unix_destroy_fpl()`. [F55]
- In `__unix_gc()`, every `skb` on `hitlist` with `UNIXCB(skb).fp` must have `UNIXCB(skb).fp->dead = true` set before `__skb_queue_purge_reason(&hitlist, ...)`, and `unix_del_edge()` / `unix_del_edges()` must gate accesses to `edge->successor` on `!fpl->dead` rather than `gc_in_progress`. [F56]
- When adding/removing an inflight edge (`unix_add_edge()`, `unix_del_edge()`) or accepting an embryo socket with `scm_stat.nr_unix_fds != 0` (`unix_update_edges()`), `unix_update_graph()` must be called under `unix_gc_lock` to set `unix_graph_maybe_cyclic = true` and `unix_graph_grouped = false` if the target `vertex` is non-NULL. [F58]
- `u->peer_wake.private` must equal the peer `struct sock *` on whose `peer_wait` queue `u->peer_wake` is linked (or `NULL`), updated under `unix_sk(other)->peer_wait.lock`, and `unix_dgram_peer_wake_disconnect()` (or `_wakeup()`) must be called before `sock_put()` on an old peer in `unix_release_sock()`, `unix_dgram_connect()`, and `unix_dgram_sendmsg()`. [F66]
- `SOCK_STREAM` and `SOCK_SEQPACKET` sockets must never transition `sk->sk_state` back to `TCP_CLOSE` after entering `TCP_ESTABLISHED` or `TCP_LISTEN` until `unix_release_sock()`; when `unix_dgram_sendmsg()` observes `sock_flag(other, SOCK_DEAD)`, it must not clear `unix_peer(sk)` or set `sk->sk_state = TCP_CLOSE` if `sk->sk_type == SOCK_SEQPACKET`. [F67]
- In `unix_dgram_sendmsg()`, when `unix_state_unlock(other)` is dropped to acquire `unix_state_double_lock(sk, other)` in the non-blocking full-queue path, execution must set `sk_locked = 1` and jump to `restart_locked` to re-validate `unix_may_send()`, `SOCK_DEAD`, `RCV_SHUTDOWN`, `sk_scm_rights`, and `security_unix_may_send()`. [F68]

## Synchronization

- Acquiring two bucket locks in `net->unx.table.locks` must use `unix_table_double_lock()` (locking once if `hash1 == hash2`, else smaller index first). `__unix_set_addr_hash()` must hold `u->bindlock` and `unix_table_double_lock(net, old_hash, new_hash)` while unhashing `sk`, publishing `u->addr` (after populating `u->path`) via `smp_store_release()`, updating `sk->sk_hash`, and re-inserting `sk`; lockless readers (`unix_getname()`, `unix_copy_addr()`, `unix_open_file()`, `sk_diag_dump_name()`) must use `smp_load_acquire(&u->addr)`. [F18, F22, F51]
- In `unix_release_sock()`, `unix_remove_socket()` and `unix_remove_bsd_socket()` must unhash `sk` before `unix_state_lock(sk)` is acquired to set `SOCK_DEAD` via `sock_orphan(sk)`, and `unix_dgram_connect()` / `unix_stream_connect()` must recheck `sock_flag(other, SOCK_DEAD)` after locking `other`. [F20]
- Acquiring two `unix_state_lock()` spinlocks must use `unix_state_double_lock()` (ascending `struct sock *` order), except in `unix_stream_connect()` where `unix_state_lock(other)` on a `TCP_LISTEN` socket may precede `unix_state_lock(sk)` only after verifying `sk->sk_state == TCP_CLOSE` both before and after locking `sk`. [F23]
- `unix_gc_lock` nests inside `unix_state_lock()`, and `sk->sk_receive_queue.lock` nests inside both `unix_state_lock()` and `unix_gc_lock` (with `TCP_LISTEN` listener `sk_receive_queue.lock` nesting outside its embryo's `sk_receive_queue.lock` per `unix_recvq_lock_cmp_fn()`); `__unix_gc()` must unlock `unix_gc_lock` before purging `hitlist`. [F25, F119]
- `unix_wait_for_peer(other, timeo)` consumes and releases the caller's `unix_state_lock(other)` before sleeping while keeping `sock_hold(other)` intact; callers must not unlock `other` after `unix_wait_for_peer()` returns and must still call `sock_put(other)`. [F8]
- Checking `sk->sk_receive_queue` length or emptiness outside `sk->sk_receive_queue.lock` must use `skb_queue_len_lockless()`, `unix_recvq_full_lockless()`, or `skb_queue_empty_lockless()`. In `sk_diag_dump_icons()`, `sk->sk_receive_queue.lock` must be held continuously across reading `qlen` for `nla_reserve()` and walking the queue. [F28, F84]
- All updates to `u->inq_len` (`unix_stream_sendmsg()`, `queue_oob()`, `unix_stream_recv_urg()`, `unix_stream_read_skb()`, `unix_stream_read_generic()`) must hold `sk->sk_receive_queue.lock` and use `WRITE_ONCE()`, while unlocked readers (`unix_inq_len()`, `unix_stream_read_generic()`) must use `READ_ONCE(u->inq_len)`. [F29]
- In `unix_stream_read_generic()` and `unix_stream_recv_urg()`, `unix_state_lock(sk)` and `sk->sk_receive_queue.lock` must be released before calling `state->recv_actor`, while `u->iolock` remains held to serialize readers. [F122]
- `update_peercred()` and `copy_peercred()` must hold `sk->sk_peer_lock`, and `copy_peercred(sk, peersk)` must also hold `unix_state_lock(peersk)`. `prepare_peercred()`, `drop_peercred()`, and `unix_maybe_add_creds()` may sleep and must run outside spinlocks; `update_peercred()` swaps credentials with `peercred`, so `unix_listen()` must call `drop_peercred(&peercred)` after unlocking `unix_state_lock(sk)` on both success and failure. [F10, F31, F115]
- Unlocked reads of `sk->sk_state`, `sk->sk_shutdown`, `sk->sk_sndbuf`, and `net->unx.sysctl_max_dgram_qlen` must use `READ_ONCE()`, paired with `WRITE_ONCE()` on updates. [F32]
- In the BPF iterator, `bpf_iter_unix_hold_batch()` must pin sockets with `sock_hold()` and release `net->unx.table.locks[bucket]` before `bpf_iter_unix_seq_show()` runs, and `bpf_iter_unix_seq_show()` must acquire `lock_sock_fast(sk)` and skip `sk_unhashed(sk)` sockets. [F33]
- `unix_dgram_peer_wake_me(sk, other)` requires holding `unix_state_lock(sk)` and verifying `unix_peer(sk) == other`. `unix_dgram_peer_wake_relay()` runs with `peer_wait.lock` held, so it must use `__remove_wait_queue()` and never sleep. `unix_write_space()` must hold `rcu_read_lock()` across `rcu_dereference(sk->sk_wq)`, `wake_up_interruptible_sync_poll()`, and `sk_wake_async_rcu()`. [F112, F113, F114]

## Object Lifetimes

- `unix_add_edge()` moves a pre-allocated `struct unix_vertex` from `fpl->vertices` to `unix_unvisited_vertices` and sets `vertex->index = unix_vertex_unvisited_index` (not a constant like `0`, since `unix_walk_scc()` swaps `unix_vertex_unvisited_index` and `unix_vertex_grouped_index` between `0` and `1`) only when `edge->predecessor->vertex` is `NULL`; `unix_del_edge()` must reset `edge->predecessor->vertex = NULL` and move `vertex->entry` back to `fpl->vertices` when `vertex->out_degree` reaches 0. [F3, F83]
- `unix_sk(sk)->oob_skb` is a borrowed pointer on `sk->sk_receive_queue` and must be cleared to `NULL` under `sk->sk_receive_queue.lock` when consumed in `unix_stream_recv_urg()` or unlinked in `manage_oob()` or `unix_stream_read_skb()`, and cleared in `unix_release_sock()`. When `unix_stream_recv_urg()` consumes `u->oob_skb` without `MSG_PEEK`, it leaves `oob_skb` queued with `UNIXCB(oob_skb).consumed = 1`, and if `oob_skb->prev != (struct sk_buff *)&sk->sk_receive_queue` and `!unix_skb_len(oob_skb->prev)`, it must unlink `oob_skb->prev` under `sk_receive_queue.lock` and free it after unlocking. [F5, F6, F110]
- `unix_find_other()` and `unix_peer_get()` return a `sock_hold()` reference, so any retry/error path in `unix_dgram_connect()`, `unix_stream_connect()`, or `unix_dgram_sendmsg()` that re-lookups or re-locks `other` must unlock `other` and call `sock_put(other)` before overwriting `other`. [F7]
- In `unix_stream_bpf_update_proto()`, when `!restore && !psock->sk_pair`, acquire `sock_hold(unix_peer(sk))` into `psock->sk_pair` (never increment again if `psock->sk_pair` is already set, nor drop synchronously when `restore` is `true`). [F14]

## API Contracts

- `__unix_find_socket_byname()`, `unix_find_socket_byname()`, `unix_find_socket_byinode()`, `unix_lookup_by_ino()`, and `unix_peer_get()` return `NULL` on miss, whereas `unix_find_bsd()`, `unix_find_abstract()`, `unix_find_other()`, and `unix_create1()` return an `ERR_PTR` and never `NULL`. [F34]
- `unix_inq_len()` returns `-EINVAL` (`long`) when `sk->sk_state == TCP_LISTEN` and a non-negative byte count otherwise; callers must check `< 0` (`unix_ioctl()`) or exclude `TCP_LISTEN` (`sk_diag_show_rqlen()`). [F35]
- `struct unix_stream_read_state.recv_actor` must return positive bytes transferred or a negative errno; `unix_stream_read_actor()` converts `skb_copy_datagram_msg()`'s `0` return via `return ret ?: chunk;`. [F37]
- `unix_get_socket()` must check `S_ISSOCK(inode->i_mode) && !(filp->f_mode & FMODE_PATH)` as well as `sk && ops && ops->family == PF_UNIX`, because `O_PATH` socket FDs (`SIOCUNIXFILE`) have `S_ISSOCK` set. [F38]
- Callers of `unix_mkname_bsd()` (`unix_bind_bsd()`, `unix_find_bsd()`) must validate `addr_len <= sizeof(struct sockaddr_un)` via `unix_validate_addr()` and pass a `struct sockaddr_storage`-backed buffer, and `unix_mkname_bsd()` must NUL-terminate and call `strlen()` via `((struct sockaddr_storage *)sunaddr)->__data`. [F73]
- `unix_dgram_proto` and `unix_stream_proto` must set `.close = unix_close`, and `unix_release()` must call `sk->sk_prot->close(sk, 0)` before `unix_release_sock(sk, 0)` for BPF `sock_map_close()`. [F128]
- In `unix_stream_sendmsg()` with `MSG_SPLICE_PAGES`, set `skb->ip_summed = CHECKSUM_UNNECESSARY` before `skb_splice_from_iter()` and charge `refcount_add(size, &sk->sk_wmem_alloc)`. [F130]

## Error Handling

- In `unix_stream_sendmsg()` and `unix_stream_read_generic()`, positive `sent` or `copied` bytes take precedence over `err` (`return sent ? : err;`, `return copied ? : err;`), and `unix_stream_sendmsg()` only raises `SIGPIPE` when `!sent`. [F36]
- Stack `struct unix_peercred` in `unix_listen()` and `unix_stream_connect()` must be zero-initialized (`= {}`) at declaration before any path to `drop_peercred()`. Stack `struct scm_cookie scm` in `__unix_dgram_recvmsg()`, `unix_stream_read_generic()`, and `unix_destruct_scm()` must be zeroed via `memset(&scm, 0, sizeof(scm))` before `scm_recv_unix()` or `scm_destroy(&scm)`. [F43, F44]
- In `unix_accept()`, when `skb_recv_datagram()` returns `NULL`, `arg->err` is `0` if `RCV_SHUTDOWN` is set, so rewrite `arg->err == 0` to `-EINVAL`. In `unix_dgram_sendmsg()`, when `sk_filter(other, skb) < 0`, free `skb` and return `len` (not a negative error). [F47, F140]

## External Contracts

- In `unix_ioctl()`, `SIOCATMARK` must set `answ = 1` both when head `skb == oob_skb` and when `!unix_skb_len(skb) && (!oob_skb || next_skb == oob_skb)`. [F89]
- `unix_maybe_add_creds()` must populate `UNIXCB(skb)` credentials when `unix_may_passcred(sk)`, `unix_may_passcred(other)`, or `!other->sk_socket` (embryo socket), calling `pidfs_register_pid()` first. [F131]

## Known Pitfalls

- `unix_autobind()` must `kzalloc()` `struct unix_address` with at least one extra byte beyond `addr->len` (`offsetof(struct sockaddr_un, sun_path) + 6`) for `sprintf(addr->name->sun_path + 1, "%05x", ordernum)`'s trailing NUL, and mask both `lastnum = ordernum & 0xFFFFF` and `ordernum = (ordernum + 1) & 0xFFFFF` with `0xFFFFF`. [F45, F102, F106]
- `unix_from_bucket()` uses 1-based indexing (`*pos == 0` is `SEQ_START_TOKEN`), so advancing buckets in `unix_get_first()`, `unix_get_next()`, or `bpf_iter_unix_batch()` must use `set_bucket_offset(bucket, 1)`, with `bucket` typed as `unsigned long` or `loff_t` because `set_bucket_offset()` shifts left by `BUCKET_SPACE` (54 on 64-bit). [F78, F99]
- In `unix_stream_sendmsg()`, clamp `PAGE_ALIGN(data_len)` to `size` via `min_t(size_t, size, PAGE_ALIGN(data_len))` before computing `size - data_len`. In `unix_stream_read_generic()`, clamp signed `int skip = max(sk_peek_offset(sk, flags), 0)` before comparing `skip >= unix_skb_len(skb)` (`unsigned int`). [F100, F101]
