# ACPI

This unit provides core ACPI table parsing and initrd upgrades, AML evaluation and device lookup utilities, thermal zone management, wakeup registration, and backlight detection, alongside x86 platform support (Intel LPSS, s2idle LPS0/Modern Standby, Apple properties, device quirks) and ACPI integration for PCI, ACPI PCI Hotplug (`acpiphp`), and PNPACPI.

## Architecture & Data Flow

- In `acpiphp_glue.c`, an `acpiphp_bridge` on a root bus (`pci_is_root_bus(bridge->pci_bus)`) has `bridge->pci_dev == NULL`, `slot->bus->self == NULL`, `bridge->context == NULL`, and stores `struct acpiphp_root_context` in `adev->hp`; check for root bus or non-NULL before dereferencing or calling `to_acpiphp_context(adev->hp)`. [F41]
- In `drivers/acpi/thermal.c`, `THERMAL_TRIP_CRITICAL` and `THERMAL_TRIP_HOT` entries in `trip_table` have `trip->priv == NULL` (only passive/active trips set `trip->priv` to `struct acpi_thermal_trip`), and `active_trip_index()` downcasts `acpi_trip` via `container_of()` to `struct acpi_thermal_active`; check `trip->priv != NULL` before dereferencing, and check `trip->type != THERMAL_TRIP_PASSIVE` before calling `active_trip_index()`. [F42, F119]
- In `drivers/acpi/thermal.c`, `acpi_thermal_get_trip_points()` initializes `tz->trips.active[0..ACPI_THERMAL_MAX_ACTIVE-1]` contiguously and sets remaining `temp_dk` to `THERMAL_TEMP_INVALID`; `acpi_thermal_add()` and `acpi_thermal_resume()` break at the first invalid entry, whereas `acpi_thermal_free_thermal_zone()` must iterate across all `ACPI_THERMAL_MAX_ACTIVE` entries unconditionally to free every `devices` handle list. [F74, F103]
- In `acpi_thermal_temp()`, any temperature converted by `deci_kelvin_to_millicelsius_with_offset()` that is `<= 0` millicelsius must be returned as `THERMAL_TEMP_INVALID`. When a zone has zero valid trips (`trip == trip_table`), `acpi_thermal_add()` and `acpi_thermal_register_thermal_zone()` must still register it via `thermal_tripless_zone_device_register()`. [F73, F94]
- DMI quirk callbacks in `drivers/acpi/thermal.c` (`thermal_act`, `thermal_nocrt`, `thermal_tzp`, `thermal_psv`) must update the active module parameter variables (`act`, `crt`, `tzp`, `psv`) while respecting non-zero user overrides for `act`, `tzp`, and `psv`. [F58]
- In `drivers/acpi/tables.c`, `acpi_table_initrd_override()` and `acpi_table_initrd_scan()` must atomically mark each consumed table via `test_and_set_bit(table_index, acpi_initrd_installed)`, cache `table_length = table->length` before `acpi_os_unmap_memory()`, jump to `next_table` on every skip path so `table_offset` and `table_index` advance together, and skip `ACPI_SIG_RSDT`/`ACPI_SIG_XSDT` in `acpi_table_initrd_scan()`. [F70, F100, F166]
- In `drivers/acpi/x86/lpss.c`, verify `pdata->mmio_size >= dev_desc->prv_offset + LPSS_CLK_SIZE` before accessing clock registers in `register_device_clock()`, and `>= prv_offset + LPSS_LTR_SIZE` before exposing LTR sysfs attributes in `acpi_lpss_platform_notify()` or setting `acpi_lpss_set_ltr` in `acpi_lpss_bind()`. For `LPSS_SAVE_CTX_ONCE`, call `acpi_lpss_save_ctx()` only in `acpi_lpss_activate()` (never `acpi_lpss_suspend()`), while `acpi_lpss_restore_ctx()` runs in `acpi_lpss_resume()` for both `LPSS_SAVE_CTX` and `LPSS_SAVE_CTX_ONCE`. [F81, F134]
- `pnpacpi_build_resource_template()` sets `buffer->length = sizeof(struct acpi_resource) * (res_cnt + 1) + 1` (allocating `buffer->length - 1` bytes with `ACPI_RESOURCE_TYPE_END_TAG` at `resource[res_cnt]`), which `pnpacpi_encode_resources()` relies on when computing `res_cnt = (buffer->length - 1) / sizeof(struct acpi_resource) - 1` and advancing per-category counters (`irq` for IRQ/EXTENDED_IRQ, `dma`, `port` for IO/FIXED_IO, `mem` for MEMORY24/32/FIXED_MEMORY32). [F48, F104]
- In `drivers/pnp/pnpacpi/rsparser.c`, `pnpacpi_allocated_resource()` must clear `PNP_WRITE` from `dev->capabilities` when a `_CRS` IRQ descriptor has multiple interrupts, and keep the `else if (r->flags & IORESOURCE_DISABLED)` branch immediately after `acpi_dev_resource_interrupt(res, 0, r)` without clobbering `r->flags`. `pnpacpi_parse_ext_irq_option()` must check `p->interrupts[i] < PNP_IRQ_NR` before `__set_bit()`. [F69, F85, F95]
- In `acpi_extract_package()` and `acpi_extract_apple_properties()`, the sizing pass (`size_required`/`tail_offset` or `newsize`) and the extraction pass (`head`/`tail` or `free_space` starting at `&newprops[1 + 3 * numvalid]`) must advance by the exact same byte counts for every element type. [F80, F102]
- When adding an `enum acpi_backlight_type` variant, update `acpi_video_parse_cmdline()` and `__acpi_video_get_backlight_type()` in lockstep. [F55]

## Synchronization

- In `drivers/pci/hotplug/acpiphp_glue.c`, `acpi_hp_context_lock` is an inner lock: `acpiphp_grab_context()` must check `context->func.parent->is_going_away` and call `get_bridge(context->func.parent)` before dropping it, and callers must release `acpi_hp_context_lock` before calling `put_bridge()` (outside `free_bridge()`), `pci_lock_rescan_remove()`, or `bridge_mutex`. When ejecting in `acpiphp_disable_slot()`, acquire `acpi_scan_lock` outer to `pci_lock_rescan_remove()`. [F30, F31, F159]
- In `acpi_thermal_check_fn()`, `tz->thermal_check_count` (initialized to 3) must be decremented via `refcount_dec_not_one()` before acquiring `tz->thermal_check_lock` and incremented via `refcount_inc()` while still holding `tz->thermal_check_lock`. [F21]
- In `drivers/acpi/x86/lpss.c`, hold `lpss_iosf_mutex` in `lpss_iosf_enter_d3_state()` and `lpss_iosf_exit_d3_state()` across reading `PMC_D3_STS_0`, updating `lpss_iosf_d3_entered`, and calling `iosf_mbi_modify()`. `lpss_reg_read()` must hold `dev->power.lock` via `spin_lock_irqsave()` while checking `pm_runtime_suspended(dev)` (returning `-EAGAIN` if suspended) and reading MMIO. When `pdata->dev_desc->resume_from_noirq` is true, `late`/`early` PM callbacks must return 0 so transitions run in `noirq`. [F27, F156, F172]
- In `acpi_pci_find_companion()`, hold `down_read(&pci_acpi_companion_lookup_sem)` across both checking and invoking `pci_acpi_find_companion_hook(pci_dev)`, and hold `down_write()` in `pci_acpi_set_companion_lookup_hook()` and `pci_acpi_clear_companion_lookup_hook()`. [F34]
- `acpi_register_lps0_dev()` and `acpi_unregister_lps0_dev()` must hold `lock_system_sleep()` / `unlock_system_sleep()` while mutating `lps0_s2idle_devops_head`. In `drivers/acpi/wakeup.c`, `acpi_wakeup_device_init()` must hold `acpi_device_lock`, whereas `acpi_enable_wakeup_devices()` and `acpi_disable_wakeup_devices()` must not acquire it during sleep transitions. [F153, F157]

## Object Lifetimes

- `acpi_evaluate_dsm()` and `acpi_evaluate_dsm_typed()` return a heap-allocated `union acpi_object *` that the caller must free with `ACPI_FREE()` on all paths (including early returns in `pci_acpi_preserve_config()`, `acpi_pci_add_bus()`, `pci_acpi_optimize_delay()`, `acpi_check_dsm()`, and `s2idle.c`). `acpi_handle_path()`, `acpi_get_subsystem_id()` (when `!IS_ERR()`), and `ibm_slot_from_id()` return buffers that the caller must free with `kfree()`. [F1, F2, F36]
- `acpi_dev_get_first_match_dev()` and `acpi_dev_get_next_match_dev()` return a `struct acpi_device *` with an elevated refcount that must be released with `acpi_dev_put()`, and `acpi_dev_get_next_match_dev()` unconditionally calls `acpi_dev_put(adev)` on its input argument. `acpi_lpss_find_device()` returns a `struct device *` from `bus_find_device()` that callers must release via `put_device()`. [F3, F17]
- In `acpiphp_enumerate_slots()`, `bridge` pins `pci_dev_get(bus->self)`, `get_device(&bus->dev)`, and (for non-root buses) `acpiphp_get_context(adev)` and `get_bridge(context->func.parent)`, and must be added to `bridge_list` under `bridge_mutex` before `acpi_walk_namespace(..., acpiphp_add_context, ...)`. If `acpi_walk_namespace()` fails, call `cleanup_bridge(bridge)` before `put_bridge(bridge)`. In `free_bridge()`, release all pinned references and clear `context->bridge = NULL` before calling `acpiphp_put_context(context)` under `acpi_hp_context_lock`. [F10, F11, F12]
- `pci_acpi_cleanup()` must unwind `pci_acpi_setup()` in reverse order: `pci_acpi_remove_edr_notifier()`, `pci_acpi_remove_pm_notifier()`, and (when `adev->wakeup.flags.valid`) `acpi_device_power_remove_dependent()`, `device_wakeup_disable()` (if `pci_dev->bridge_d3`), and `device_set_wakeup_capable(dev, false)`. Both `acpi_pci_wakeup()` and `acpi_pci_propagate_wakeup()` must use the refcounted `acpi_pm_set_device_wakeup()`. [F13, F15]
- In `acpi_lpss_create_device()`, always free `resource_list` via `acpi_dev_free_resource_list(&resource_list)` after `acpi_dev_get_memory_resources()`, and if `acpi_create_platform_device()` fails after setting `adev->driver_data = pdata`, reset `adev->driver_data = NULL` before `kfree(pdata)`. `acpi_handle_list_replace()` and `acpi_handle_list_free()` gate `kfree()` on `count` being non-zero; never zero `count` before calling them. [F6, F16]
- In `acpi_table_upgrade()`, after `memblock_phys_alloc_range()`, call both `arch_reserve_mem_area(acpi_tables_addr, all_tables_size)` and `kmemleak_ignore_phys(acpi_tables_addr)`, and pair every page-aligned `early_memremap()` chunk (accounting for `slop = dest_addr & ~PAGE_MASK` and `MAP_CHUNK_SIZE - slop`) with `early_memunmap()`. [F14, F123, F149]

## API Contracts

- `acpi_check_dsm()` takes `funcs` as a non-zero 64-bit bitmask (`BIT(func)`), whereas `acpi_evaluate_dsm()` takes a function index (`u64`). Inside `acpi_check_dsm()`, cast each `obj->buffer.pointer[i]` to `u64` before shifting by `i * 8`, bound the loop by both `i < obj->buffer.length` and `i < 8`, and require `(mask & 0x1)` and `(mask & funcs) == funcs`. [F50, F89, F108, F109]
- In `drivers/acpi/thermal.c` and `thermal_lib.c`, `acpi_*_trip_temp()`, `tz->temp_dk`, and `acpi_thermal_trip.temp_dk` are in deci-Kelvin (with `acpi_trip_temp()` validating `[TEMP_MIN_DECIK, TEMP_MAX_DECIK]` before narrowing `u64` to `int`), module parameters `act`/`crt`/`psv` are in Celsius, and thermal core APIs take millidegrees Celsius (via `acpi_thermal_temp()` or `thermal_acpi_*_trip_temp()`). `_TZP` and `_TSP` are in deci-seconds (multiply by `100` for milliseconds), whereas `_TFP` is already in milliseconds. [F51, F52, F114, F167]
- In `acpi_thermal_add()`, call `acpi_thermal_aml_dependency_fix()` and `acpi_execute_simple_method(tz->device->handle, "_SCP", ACPI_THERMAL_MODE_ACTIVE)` before calling `acpi_thermal_get_trip_points()` and `acpi_thermal_get_temperature()`. [F127]
- `acpi_dev_found()`, `acpi_dev_present()`, `acpi_dev_get_first_match_dev()`, and `acpi_dev_get_next_match_dev()` must not be called from `subsys_initcall()` or earlier (before `acpi_bus_scan()`), and callers must pass `-1` (not `0`) for `hrv` when `_HRV` should not be matched. [F54, F163]
- In `acpi_table_initrd_override()` and `acpi_os_table_override()`, clear output parameters (`*length = 0; *address = 0;` and `*new_table = NULL;`) before returning `AE_OK` on non-override paths. `acpi_table_upgrade()` must abort if `security_locked_down(LOCKDOWN_ACPI_TABLES)` is true. [F47, F165]
- Callers of `acpi_extract_package()` must include the trailing NUL byte in `format->length` (`sizeof("NN")`, not `strlen()`), and when `buffer->length != ACPI_ALLOCATE_BUFFER`, `buffer->length` must equal `size_required` exactly. [F76, F77]
- In `drivers/acpi/x86/lpss.c`, call `acpi_lpss_d3_to_d0_delay(pdata)` after `acpi_dev_resume(dev)` before writing LPSS private MMIO registers in `acpi_lpss_activate()` and `acpi_lpss_resume()`; call `lpss_iosf_enter_d3_state()` after `acpi_dev_suspend()` (when target state is `ACPI_STATE_S0`) and `lpss_iosf_exit_d3_state()` before `acpi_dev_resume()`. [F135, F136]
- In `drivers/pci/hotplug/acpiphp_glue.c`, bracket subordinate bus scans/trims in `trim_stale_devices()` and `acpiphp_check_bridge()` with `pm_runtime_get_sync()` and `pm_runtime_put()` on `bridge->pci_dev`, and in `register_slot()`, do not call `acpiphp_register_hotplug_slot()` when `pdev && hotplug_is_native(pdev)`. In `acpi_pci_choose_state()`, check both `pdev->no_d3cold` and `!pdev->d3cold_allowed` to cap `d_max` at `ACPI_STATE_D3_HOT`. [F56, F143, F175]

## Error Handling

- `acpi_match_platform_list()` takes a `struct acpi_platform_list` array terminated by a sentinel with `oem_id[0] == '\0'` and returns the 0-based index on match or `-ENODEV` on failure; store the result in a signed `int` and check `>= 0` (or `< 0`). [F37, F79]
- In `drivers/acpi/x86/s2idle.c`, `validate_dsm()` returns `-EINVAL` on failure or a positive bitmask; `lps0_dsm_func_mask` and `lps0_dsm_func_mask_microsoft` must remain signed `int`, be checked with `> 0` before calling `acpi_sleep_run_lps0_dsm()`, and on non-AMD systems with both UUIDs present, overlapping bits must not be masked out. [F38, F138]
- In `acpi_lpss_create_device()`, return `1` when `pdev` is created, or jump to `out_free` to return `0` when `!pdata->mmio_base` (after clearing `adev->pnp.type.platform_id = 0`) or `register_device_clock()` fails. Check `dev->parent` for non-NULL before `ACPI_COMPANION(dev->parent)` in `acpi_pci_find_companion()`, `cfg->parent` before `to_acpi_device(cfg->parent)` in `pcibios_root_bridge_prepare()`, and reset `slot->slot = NULL` in `acpiphp_add_context()` if `acpiphp_register_hotplug_slot()` fails. [F39, F40, F43, F45]

## External Contracts

- In `drivers/acpi/x86/s2idle.c`, `acpi_s2idle_prepare_late()` must pass `ACPI_LPS0_MS_ENTRY` (before `ACPI_LPS0_ENTRY`) and `acpi_s2idle_restore_early()` must pass `ACPI_LPS0_MS_EXIT` (after `ACPI_LPS0_EXIT`). [F49]
- In `pci_acpi_optimize_delay()`, `_DSM` `DSM_PCI_DEVICE_READINESS_DURATIONS` values are in microseconds and must be divided by `1000` before comparing or assigning to millisecond `pdev->d3cold_delay` or `pdev->d3hot_delay`. In `acpi_pci_set_power_state()`, call `acpi_pci_config_space_access(dev, false)` before `acpi_device_set_power()` for `PCI_D3cold`, and `acpi_pci_config_space_access(dev, true)` after `acpi_device_set_power()` succeeds for `PCI_D0`. [F53, F67]

## Known Pitfalls

- `acpi_match_device_ids()` returns `0` on match and negative errno on mismatch (opposite to boolean `acpi_dev_uid_match()`); do not negate it as a boolean. In `include/acpi/acexcep.h`, exception macros (`ACPI_ENV_EXCEPTION`, `ACPI_AML_EXCEPTION`, etc.) must test `(((status) & AE_CODE_MASK) == code)` because `AE_CODE_ENVIRONMENTAL` is `0x0000`. [F87, F88]
- In `pci_set_acpi_fwnode()`, check `!dev_fwnode(&dev->dev)` rather than `!ACPI_COMPANION(&dev->dev)` before `ACPI_COMPANION_SET()` so non-ACPI (OF) fwnodes are not overwritten. In `acpi_pci_bridge_d3()`, check cached `dev->is_pciehp` instead of reading PCI config space, and evaluate fallback wakeup, `_S0W`, and `"HotPlugSupportInD3"` checks on the Root Port's companion (`rpadev`), not `adev`. [F57, F107, F144]
- In `drivers/pci/hotplug/acpiphp_glue.c`, any walk of `bus->devices` that may remove devices (`disable_slot()`, `trim_stale_devices()`, `acpiphp_check_bridge()`, `acpiphp_sanitize_bus()`) must use `list_for_each_entry_safe_reverse()`. [F98]
- In `lps0_device_attach()`, check `if (dev_id->id[0])` (not `if (dev_id)`) after iterating the sentinel-terminated `amd_hid_ids` array. In `lpi_device_get_constraints_amd()` and `lpi_device_get_constraints()`, finish the inner element-extraction loop before validating fields and incrementing `lpi_constraints_table_size`. Never add multi-function AudioDSP `_HID`s (such as `"INT3438"`) to `acpi_lpss_device_ids[]`. [F97, F99, F133]
- Fixed-width `ACPI_NONSTRING` fields in `struct acpi_table_header` (`signature`, `oem_id`, `oem_table_id`) are not NUL-terminated; format with `%4.4s`/`%6.6s`/`%8.8s` and compare with `memcmp()`/`strncmp()`. When querying `acpi_get_table(ACPI_SIG_MADT, ...)` for the second MADT (`check_multiple_madt()` / `acpi_apic_instance`), pass instance `2` because `0` and `1` both return the first table. [F72, F122]
