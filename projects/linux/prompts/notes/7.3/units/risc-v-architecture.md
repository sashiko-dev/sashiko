# RISC-V ARCHITECTURE

This unit provides the core RISC-V kernel runtime (`arch/riscv/kernel`), architectural header definitions (`arch/riscv/include`), vendor-specific errata runtime patching (`arch/riscv/errata`), and vector crypto glue drivers (`arch/riscv/crypto`), covering boot/SMP, MMU page tables, traps, context switching, vector/FPU state, SBI calls, module relocations, runtime code patching, kexec/hibernation, and the `riscv_hwprobe` syscall/vDSO.

## Architecture & Data Flow

- Vector status helpers must use `__riscv_v_vstate_or()` and `__riscv_v_vstate_check()` so `SR_VS_THEAD` (bits 24:23) is used when `has_xtheadvector()` is true instead of `SR_VS` (bits 10:9). In `__vstate_csr_save()` and `__vstate_csr_restore()`, when `has_xtheadvector()` is true, `SR_FS_DIRTY` must be set in `CSR_STATUS` before accessing `CSR_VXSAT`/`CSR_VXRM` and restored if `(status & SR_FS) != SR_FS_DIRTY`. [F36, F37]
- `riscv_v_vstate_discard()` must mark `regs->status` dirty via `__riscv_v_vstate_dirty(regs)` after clobbering hardware vector registers, while `riscv_v_vstate_save()` and `riscv_v_vstate_restore()` must mark `regs->status` clean via `__riscv_v_vstate_clean(regs)`. `riscv_v_vstate_set_restore()` must set both `TIF_RISCV_V_DEFER_RESTORE` on `task` and `INITIAL` vector status via `riscv_v_vstate_on(regs)` when `riscv_v_vstate_query(regs)` is true. [F38, F39]
- In `__switch_to_vector()`, if `riscv_preempt_v_started(prev)` and `riscv_v_is_on()` hold, it must call `riscv_v_disable()` and set `RISCV_PREEMPT_V_IN_SCHEDULE`; when switching to `next` with `RISCV_PREEMPT_V_IN_SCHEDULE` set, it must clear that flag and call `riscv_v_enable()` instead of `riscv_preempt_v_set_restore(next)`. [F40]
- Under `CONFIG_RISCV_ISA_SUPM`, `__untagged_addr_remote()` must sign-extend virtual addresses via `(long)(addr << pmlen) >> pmlen` on `CONFIG_MMU` (and zero-extend otherwise), and `access_ok()` must call `untagged_addr()` before `__access_ok()`. `mm->context.pmlen` is non-zero only when `PR_TAGGED_ADDR_ENABLE` is enabled (`init_new_context()` clears `MM_CONTEXT_LOCK_PMLEN` and `activate_mm()` resets `next->context.pmlen = 0`), while active pointer masking length is in `task->thread.envcfg & ENVCFG_PMM`. `envcfg_update_bits()` must immediately write `CSR_ENVCFG` when `task == current`. [F41, F48, F56, F209]
- In multi-level page-table selectors (`PGDIR_SHIFT`, `P4D_SHIFT`, `VA_BITS`), `pgtable_l5_enabled` must be tested before `pgtable_l4_enabled` because `pgtable_l4_enabled` stays true under Sv57. Under `CONFIG_TRANSPARENT_HUGEPAGE`, `pmd_present(pmd)` must check `_PAGE_LEAF` alongside `_PAGE_PRESENT` and `_PAGE_PROT_NONE`. With `CONFIG_ERRATA_THEAD_MAE`, `pfn_pgd`, `pfn_pmd`, `pfn_pte`, and `pte_modify` must apply `ALT_THEAD_PMA` to protection bits. [F49, F74, F139]
- `struct thread_info` must remain at offset 0 of `struct task_struct`, `asm_per_cpu` must load `TASK_TI_CPU_NUM(tp)` with 32-bit `lw` (not `REG_L`), and any `thread_struct` fields accessed in `__switch_to` via `a3`/`a4` must have relative `TASK_THREAD_*_RA` offsets in `asm-offsets.c`. When `CONFIG_SHADOW_CALL_STACK` is enabled, `gp` holds `scs_sp`, so `load_global_pointer` must be a no-op and assembly entry/exit paths must preserve `gp` via `scs_*` macros. [F52, F58, F128, F206]
- `__ALT_PTR(a, f)` must cast `&(a)->f` to `(void *)` before adding the `s32` byte offset `(a)->f`, and `runtime_const_fixup()` must compute target addresses as `*start + (void *)start` while advancing `start++`. `runtime_const_ptr()` and `runtime_const_shift_right_32()` must use `.option norvc`, and in `__runtime_fixup_32()`, when `upper_immediate & 0xfffff000` is zero (`lui_insn == RISCV_INSN_NOP4`), the `addi` branch must still execute to emit `li rd, 0` instead of two `nop`s when `val == 0`. [F69, F73, F95, F96]
- In `arch/riscv/kernel/module.c`, every relocation type that may call `module_emit_plt_entry()` or `module_emit_got_entry()` must be matched in both `rela_needs_plt_got_entry()` and `count_max_entries()`, and `mod->arch.plt` and `mod->arch.got_plt` must be sized and incremented in lockstep. `module_frob_arch_sections()` must sort a scratch copy of `SHT_RELA` rather than sorting in place. [F202, F203, F253]

## Synchronization

- Callers of `untagged_addr_remote(mm, addr)` must hold `mm`'s `mmap_lock` (enforced by `mmap_assert_locked(mm)`). Under `CONFIG_RISCV_ISA_SUPM`, `set_tagged_addr_ctrl()` must reject compat threads with `-EINVAL` and hold `mmap_write_lock_killable(mm)` while checking `MM_CONTEXT_LOCK_PMLEN` to reject changing `mm->context.pmlen` with `-EBUSY` after `CLONE_VM`. [F11, F335]
- `riscv_preempt_v_clear_dirty()` and `riscv_preempt_v_set_restore()` must issue `barrier()` before modifying `task->thread.riscv_v_flags`, and `riscv_v_flags()` must use `READ_ONCE()`. `riscv_v_context_nesting_start()` and `riscv_v_context_nesting_end()` require local IRQs disabled. `kernel_fpu_begin()` must call `preempt_disable()` before `fstate_save()` and setting `SR_FS`, and `kernel_fpu_end()` must clear `SR_FS` and call `fstate_restore()` before `preempt_enable()`. [F14, F171, F173]
- Non-relaxed MMIO accessors (`readb`/`w`/`l`/`q`, `writeb`/`w`/`l`/`q`) must use `__io_ar` (`RISCV_FENCE(i, ir)`) after reads and `__io_bw` (`RISCV_FENCE(w, o)`) plus `__io_aw` (`mmiowb_set_pending()`) around writes, paired with `mmiowb()` (`RISCV_FENCE(o, w)`). `smp_mb__after_spinlock()` must use `RISCV_FENCE(iorw, iorw)`. Fully ordered `arch_xchg()` and `arch_cmpxchg()` must pair `sc.w.rl`/`sc.d.rl` with a trailing `RISCV_FULL_BARRIER` on the successful SC path (or use `.aqrl` on `amoswap`/`amocas`). [F17, F18, F123]
- Text patching in vendor errata patch functions, `__runtime_fixup_32()`, `__runtime_fixup_shift()`, `__patch_insn_set()`, and `__patch_insn_write()` requires `text_mutex` (early boot before MMU uses `memcpy()` and `local_flush_icache_all()`). Under `CONFIG_MMU`, `__patch_insn_set()` and `__patch_insn_write()` must disable preemption while `FIX_TEXT_POKE0`/`1` are mapped and flush the local icache on `waddr` before `patch_unmap()`. In `patch_text_cb()`, the last CPU must call `patch_insn_write()` and `atomic_inc_return_release(&patch->cpu_count)` before all CPUs call `local_flush_icache_all()`. [F122, F155, F167]
- In `__set_pte_at()`, when installing a present executable PTE (`pte_present(pteval) && pte_exec(pteval)`), `flush_icache_pte(mm, pteval)` must be called before `set_pte(ptep, pteval)`. In `arch/riscv/kernel/traps.c`, exception entry points (`DO_ERROR_INFO`, `do_trap_insn_illegal`, `do_trap_misaligned`, `do_trap_break`) must call `local_irq_enable()` after `irqentry_enter_from_user_mode(regs)` and `local_irq_disable()` before `irqentry_exit_to_user_mode(regs)` when `user_mode(regs)` is true. [F130, F304]

## Object Lifetimes

- In `riscv64_aes_cbc_cts_crypt()` and `riscv64_aes_xts_crypt()`, when an initial `skcipher_walk_virt(&walk, req, false)` does not cover the full request and execution switches to a subrequest, `skcipher_walk_abort(&walk)` must be called before starting the subrequest walk. [F1]
- In `arch/riscv/include/asm/pgalloc.h`, `pud_free()` and `__pud_free_tlb()` must only free or remove the page table descriptor when `pgtable_l4_enabled` is true, and `__p4d_free_tlb()` only when `pgtable_l5_enabled` is true. [F3]
- `arch_dup_task_struct()` must save `src`'s FPU state before `*dst = *src` and zero `dst->thread.vstate`, zero `dst->thread.kernel_vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE` on `dst`. During `flush_thread()`, `current`'s vector state must be reset via `riscv_v_vstate_ctrl_init(current)`, `riscv_v_vstate_off()`, freeing `current->thread.vstate.datap`, zeroing `current->thread.vstate`, and clearing `TIF_RISCV_V_DEFER_RESTORE`. [F207, F208]

## API Contracts

- In `__riscv_v_vstate_save()`, `__riscv_v_vstate_restore()`, `__riscv_v_vstate_discard()`, and when reading `CSR_VLENB` in `riscv_v_setup_vsize()` (if `thead_vlenb_of` is zero), vector register/CSR accesses must be bracketed by `riscv_v_enable()` and `riscv_v_disable()`. In `arch/riscv/crypto/*-riscv64-glue.c`, every vector crypto assembly call must be bracketed by `kernel_vector_begin()` and `kernel_vector_end()` with no early return or sleep in between, and synchronous `crypto_alg`/`shash_alg` callbacks must check `crypto_simd_usable()` first and fall back to scalar C routines. [F5, F8, F113, F294]
- In `__get_user_nocheck()` and `__put_user_nocheck()`, when `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` is disabled and `__gu_ptr` is not naturally aligned to `sizeof(*__gu_ptr)`, the access must fall back to `__asm_copy_from_user_sum_enabled()` or `__asm_copy_to_user_sum_enabled()`. [F57]
- `riscv_isa_extension_base()` and `__riscv_isa_extension_available()` treat a `NULL` `isa_bitmap` as selecting the host-wide `riscv_isa` bitmap and non-`NULL` as querying that specific bitmap. `__riscv_isa_vendor_extension_available()` requires `cpu == -1` (`VENDOR_EXT_ALL_CPUS`) or a valid CPU index and `bit < RISCV_ISA_VENDOR_EXT_MAX`, so `riscv_cpufeature_patch_func()` must subtract `RISCV_VENDOR_EXT_ALTERNATIVES_BASE` from `id` first. [F189, F190]
- Functions accessing `CSR_ENVCFG` or pointer-masking state (`set_tagged_addr_ctrl()`, `get_tagged_addr_ctrl()`, `flush_thread()`, `tagged_addr_init()`, `suspend_save_csrs()`, `suspend_restore_csrs()`) must first verify `riscv_has_extension_unlikely(RISCV_ISA_EXT_SUPM)` or `RISCV_ISA_EXT_XLINUXENVCFG`, and any `riscv_isa_ext[]` entry that implies `CSR_ENVCFG` must include `riscv_xlinuxenvcfg_exts` via `__RISCV_ISA_EXT_SUPERSET()`. [F292, F293]
- In `copy_code()` (called from `die()` under `die_lock`), reading instructions must use `get_kernel_nofault()` for kernel `regs` and `copy_from_user_nofault()` (after verifying `regs == task_pt_regs(current)`) for user `regs`. Conversely, in `traps_misaligned.c`, user-mode accesses must use fault-capable `copy_from_user()`, `copy_to_user()`, and `get_user()`. In `stacktrace.c`, `unwind_user_frame()` must check `access_ok()` and use `__copy_from_user_inatomic()`, and `__get_wchan()` must pin the stack with `try_get_task_stack()`/`put_task_stack()`. [F305, F306, F322]
- The first syscall argument is stored in `regs->orig_a0` while `regs->a0` holds the return value, so `syscall_get_arguments()`, `syscall_set_arguments()`, `SC_RISCV_REGS_TO_ARGS`, and `syscall_rollback()` must use `regs->orig_a0` for argument 0. [F145]

## Error Handling

- `sbi_ecall(e, f, a0..a5)` forwards `(f, e)` as the last two arguments to `__sbi_ecall()`. Callers must inspect `ret.error` against `SBI_SUCCESS` (0) or `SBI_ERR_*` and translate errors via `sbi_err_map_linux_errno()` rather than returning raw SBI error codes; `sbi_probe_extension()` returns `0` on error/unsupported and `ret.value` (`> 0`) when supported. [F20, F191, F192]
- `__get_user_error()`, `__get_user()`, and `get_user()` must zero the destination variable `x` whenever `access_ok()` fails or a load faults, and return `-EFAULT`. `__asm_copy_to_user_sum_enabled()`, `__asm_copy_from_user_sum_enabled()`, `raw_copy_from_user()`, `raw_copy_to_user()`, and `clear_user()` return an `unsigned long` residual byte count (non-zero on fault), so callers in `uaccess.h` must treat any non-zero return as a fault. Inline assembly using `_ASM_EXTABLE_UACCESS_ERR` or `_ASM_EXTABLE_UACCESS_ERR_ZERO` without `asm_goto_output` must initialize the error variable to `0` and pass it with `"+r"`. [F23, F24, F26]

## External Contracts

- When adding a `RISCV_HWPROBE_KEY_*` constant, `RISCV_HWPROBE_MAX_KEY` must be updated, any bitmask key must be added to `hwprobe_key_is_bitmask()`, and every key in `0 .. RISCV_HWPROBE_MAX_KEY` must be handled in `hwprobe_one_pair()`. Unrecognized keys in `hwprobe_one_pair()`, `riscv_vdso_get_values()`, `hwprobe_get_cpus()`, and `riscv_vdso_get_cpus()` must overwrite `pair->key` with `-1` (and zero `pair->value` or clear the CPU mask) and continue rather than returning an error. [F62, F249, F327]
- `struct user_regs_struct` must remain an exact layout prefix of `struct pt_regs` (from `pc`/`epc` through `t6`), and `restore_sigcontext()`/`setup_sigcontext()` must copy `sizeof(sc->sc_regs)` bytes rather than `sizeof(*regs)`. `uc_mcontext` must remain the final member of `struct ucontext`, `sc_extdesc` must keep its 129-`u32` `__padding` and zeroed `reserved` word, and `setup_sigcontext()` must terminate the extension chain with `END_MAGIC`/`END_HDR_SIZE`. In `restore_sigcontext()`, the extension loop must advance `sc_ext_ptr` past `sizeof(*head)` before dispatching on `magic`, validate `RISCV_V_MAGIC`, active vector state in `regs`, and `size == riscv_v_sc_size` before calling `__restore_v_state()` (which must call `riscv_v_vstate_set_restore()` before `copy_from_user()`), and set `sc_ext_ptr = (void __user *)head + size`. [F64, F142, F225, F262, F278, F332, F333]

## Known Pitfalls

- Vector crypto assembly functions `aes_encrypt_zvkned()`, `aes_decrypt_zvkned()`, and `sm4_crypt_zvksed_zvkb()` take `(key, src, dst)` (input before output), whereas scalar C fallbacks `aes_encrypt()`, `aes_decrypt()`, and `sm4_crypt_block()` take `(key, dst, src)` (output before input). [F29]
- On RV64, `lr.w` sign-extends 32-bit loads to 64 bits, so `futex_atomic_cmpxchg_inatomic()` must cast `oldval` via `(long)(int)oldval` and the 4-byte case of `_arch_cmpxchg()` must cast `__old` via `(long)(int)(long)` before `bne`. In `THEAD_CMO_OP()` and `ALT_CMO_OP()`, alignment must use `~((_cachesize) - 1UL)` so 64-bit addresses are not truncated by `unsigned int _cachesize`. Under `CONFIG_RISCV_ISA_SVNAPOT`, `pte_pfn(pte)` must be used instead of raw `__page_val_to_pfn(pte_val(pte))` to strip the NAPOT order bit. [F80, F81, F88, F140]
- In `uaccess.h`, `__put_user(x, ptr)` must evaluate `x` into `__val` before `__enable_user_access()` sets `SR_SUM` and call `__disable_user_access()` immediately after `__put_user_error()`. In `__put_user_nocheck()`, the unaligned-fallback temporary must be named `___val` (three underscores) to avoid shadowing `val`/`__val` in callers, and helper macros under `switch` cases (`__get_user_asm`, `__get_user_8`, `__put_user_asm`, `__put_user_8`) must be wrapped in `do { ... } while (0)`. [F71, F121, F146]
- Splitting a 32-bit value across a U-type (`lui`/`auipc`) and I-type (`addi`/`jalr`/LO12) pair in `riscv_insn_insert_utype_itype_imm()`, `__runtime_fixup_32()`, and `module.c` relocations must add `0x800` (or `0x1000` when bit 11 is set) to the upper 20-bit immediate to compensate for I-type sign-extension, and 64-bit PC-relative HI20/CALL/PLT32 offsets in `module.c` must be validated via `riscv_insn_valid_32bit_offset()`. In `simulate-insn.c`, immediates from `RV_EXTRACT_*_IMM()` or `RVC_EXTRACT_*_IMM()` must be cast to `s32` before adding to `unsigned long addr`, and in `simulate_jalr()`, `rv_insn_reg_get_val(regs, rs1_index, &base_addr)` must precede `rv_insn_reg_set_val(regs, rd_index, addr + 4)`. [F84, F219, F271, F273]
- Because slot 0 of `struct pt_regs` holds `epc` rather than `x0`, any code indexing `(unsigned long *)regs` by register number 0..31 (`rv_insn_reg_get_val()`, `rv_insn_reg_set_val()`, `get_step_address()`) must treat index 0 as hardwired zero. In `kprobes.c`, `p->addr` and `p->ainsn.api.insn` are `u32 *`, so adding `GET_INSN_LENGTH()` or byte offsets must cast to `(void *)` or `unsigned long` first. In `get_insn()`, 16-bit `insn` must be masked with `GENMASK(15, 0)` before ORing with `(tmp << 16)`. [F229, F266, F280]
- In `.option arch` blocks requiring 32-bit instructions (`RISCV_RUNTIME_CONST_64_ZBA`, `RISCV_RUNTIME_CONST_64_ZBKB`), `.option norvc` must be placed after `.option arch`. In `__switch_to`, `thread.sum` loaded from `TASK_THREAD_SUM_RA(a4)` must be masked with `SR_SUM` before `csrs CSR_STATUS, s0`. Physical addresses passed to SBI calls must not pass vmalloc or `DEFINE_PER_CPU()` pointers directly to `__pa()`. Multi-word ISA bitmaps must be manipulated and compared with `bitmap_*()` helpers rather than `memcmp()` or single-word operations. [F116, F205, F284, F314]
