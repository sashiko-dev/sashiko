# ARM64 PORT (AARCH64 ARCHITECTURE)

This unit provides the core AArch64 memory management subsystem (`arch/arm64/mm/`), architecture headers and UAPI definitions (`arch/arm64/include/`), ACPI/NUMA boot initialization (`arch/arm64/kernel/`), instruction encoding and checksum library routines (`arch/arm64/lib/`), and Arm CCA Realm / pKVM guest confidential computing drivers (`drivers/virt/coco/`).

## Architecture & Data Flow

- Before `pte_wrprotect()` or `pte_modify()` alters `PTE_WRITE` or `PTE_RDONLY`, it must check `pte_hw_dirty(pte)` (`pte_write(pte) && !pte_rdonly(pte)`) and set `PTE_DIRTY`, and `pte_modify()` must then call `pte_mkdirty(pte)` if `pte_sw_dirty(pte)` is set. `PTE_SWBITS_MASK` must cover all software PTE bits modified on live valid PTEs so `pgattr_change_is_safe()` permits updates without break-before-make. [F86, F138]
- `pte_present_invalid()`, `pte_valid_not_user()`, and `pte_access_permitted_no_overlay()` must test multi-bit masks against exact expected bit combinations (`(val & mask) == expected`), because `PTE_PRESENT_INVALID` aliases `PTE_NG` and execute-only user mappings have `PTE_USER` cleared. `pte_protnone()` must check `pte_present_invalid(pte) && !pte_user(pte) && !pte_user_exec(pte)`, and `pmd_trans_huge()` must OR `PTE_VALID` into `pmd` before calling `!pmd_table()`. [F84, F85]
- In `__get_and_clear_full_ptes()`, `contpte_convert()`, `contpte_ptep_get()`, and `contpte_ptep_get_lockless()`, dirty and young (`PTE_AF`) bits must be ORed across all constituent PTEs in the range or `CONT_PTES` block; in the latter two, the `pte_dirty(pte)` branch must start its inner `pte_young` scan at index `i` without advancing `i` or `ptep`. [F91, F212, F255]
- Before clearing or write-protecting a PTE range in `contpte_clear_full_ptes()`, `contpte_get_and_clear_full_ptes()`, or `contpte_wrprotect_ptes()`, or changing `pte_write()` in `contpte_ptep_set_access_flags()`, any partially covered `CONT_PTES` block must be unfolded via `contpte_try_unfold_partial()` or `__contpte_try_unfold()`. `__contpte_try_fold()`, `__contpte_try_unfold()`, and `contpte_set_ptes()` must guard contiguous PTE manipulation with `mm_is_user(mm)`, and `__contpte_try_fold()` must verify a single non-special `struct folio` spans `CONT_PTE_SIZE`. [F214, F320]
- In `new_context()`, `check_update_reserved_asid(asid, newasid)` must run before checking `refcount_read(&mm->context.pinned)` and scan every CPU in `for_each_possible_cpu()` without early exit to update all matching `per_cpu(reserved_asids, cpu)` entries. In `flush_context()`, if `atomic64_xchg_relaxed(&per_cpu(active_asids, i), 0)` returns 0, the existing `per_cpu(reserved_asids, i)` must be preserved and its bit set in `asid_map`. [F174, F209]
- `mm->context.id`, `active_asids`, and `reserved_asids` store 64-bit context IDs with the generation in `ASID_MASK`, so indexing `asid_map` or `pinned_asid_map` must strip the generation via `ctxid2asid(asid)`. `new_context()` must start `find_next_zero_bit()` on `asid_map` at index `>= 1`, and `asids_update_limit()` must cap `max_pinned_asids` at `num_available_asids - num_possible_cpus() - 2`. Under KPTI (`arm64_kernel_unmapped_at_el0()`), `set_kpti_asid_bits()` fills `asid_map` and `pinned_asid_map` with `0xaa`, and `arm64_mm_context_get()` must set `asid |= 1`. [F239, F240, F285]
- In `do_page_fault()`, if `faulthandler_disabled() || !mm` holds, jump to `no_context` before taking VMA or `mmap_lock` locks; check `is_gcs_fault(esr)` before `is_write_abort(esr)` and read-fault branches so all GCS faults set `VM_WRITE` and `FAULT_FLAG_WRITE`; set `FAULT_FLAG_TRIED` in `mm_flags` when `handle_mm_fault()` under `FAULT_FLAG_VMA_LOCK` returns `VM_FAULT_RETRY | VM_FAULT_MAJOR`; and in `fault_from_pkey()`, validate `POR_EL0` against `vma_pkey(vma)` via `arch_vma_access_permitted()` rather than trusting `ESR_ELx_Overlay`. [F221, F252, F299, F303]
- Because `__pgd_pgtable_alloc()` strips `__GFP_ZERO`, every `alloc_init_*` function in `arch/arm64/mm/mmu.c` allocating via `pgtable_alloc()` must call `init_clear_pgtable()` before `__p*d_populate()`. `mark_rodata_ro()` must set `WRITE_ONCE(rodata_is_rw, false)` before `update_mapping_prot()` on `__start_rodata..__init_begin` so `set_swapper_pgd()` switches to `pgd_set_fixmap()` under `swapper_pgdir_lock` before `swapper_pg_dir` becomes read-only. [F204, F225]
- In `asm/memory.h`, `untagged_addr(addr)` must bitwise-AND `__addr` with `__untagged_addr(__addr)` (`sign_extend64((__force u64)(addr), 55)`) so user addresses clear bits [63:56] while kernel addresses preserve them; `MT_NORMAL` must remain index 0; and under `CONFIG_ARM64_LPA2`, `PHYS_MASK_SHIFT` (and `MAX_PHYSMEM_BITS`) must dynamically check `lpa2_is_enabled()` and fall back to 48 bits when `TCR_DS` is clear. [F79, F99, F118]
- In `huge_pte_offset()`, `pud_none(pud)` and `pmd_none(pmd)` checks for sub-PUD/sub-PMD sizes must precede `!pud_present(pud)` and `!pmd_present(pmd)`, and `huge_pte_alloc()` must allocate the P4D level via `p4d_alloc(mm, pgdp, addr)` rather than `p4d_offset()`. `__sync_icache_dcache()`, `flush_dcache_folio()`, and `flush_dcache_page()` must test, set, and clear `PG_dcache_clean` on `folio->flags.f`, with `__sync_icache_dcache()` calling `sync_icache_aliases()` across `folio_size(folio)`. [F257, F315, F319]
- Functions accessing `SYS_POR_EL0` (`arch_set_user_pkey_access()`) or GCS registers `SYS_GCSPR_EL0` / `SYS_GCSCRE0_EL1` (`gcs_alloc_thread_stack()`, `arch_set_shadow_stack_status()`) must first verify `system_supports_poe()` or `system_supports_gcs()`. `arch_set_user_pkey_access()` must RMW `SYS_POR_EL0` clearing only `~(POE_MASK << POR_ELx_PERM_SHIFT(pkey))`. In `gcs_alloc_thread_stack()`, `alloc_gcs()` is called only when `(args->flags & (CLONE_VFORK | CLONE_VM)) == CLONE_VM`, and `map_shadow_stack()` must issue `gcsb_dsync()` after `put_user_gcs()`. [F226, F262, F293, F313]

## Synchronization

- TLB invalidation routines (`flush_tlb_mm`, `__flush_tlb_page_nosync`, `__flush_tlb_range_nosync`) must execute `dsb(ishst)` after clearing a PTE and before reading `ASID(mm)` via `atomic64_read(&mm->context.id)` so a concurrent ASID rollover cannot walk page tables before the invalid PTE store is visible. In `split_pmd()`, `split_pud()`, and `init_clear_pgtable()`, `dsb(ishst)` must execute after writing/zeroing child entries and before publishing the parent descriptor via `__pmd_populate()` or `__pud_populate()`. [F13, F180]
- Under `CONFIG_ARM64_CONTPTE`, all public PTE accessors and mutators in `asm/pgtable.h` except `ptep_get_lockless()` must be called with the PTL held; because `ptep_get()` can return `PTE_CONT` set, public setters (`set_pte`, `set_ptes`, `ptep_set_access_flags`) must clear `PTE_CONT` via `pte_mknoncont()`, while `PTE_CONT`-aware callers (hugetlb, kernel mappers) must call `__`-prefixed helpers (`__set_ptes`, `__ptep_get`). In `contpte_ptep_get_lockless()`, any `contpte_is_consistent()` failure in outer or inner loops must jump to `retry` and discard accumulated `orig_pte` bits. [F24, F45, F256]
- In-place permission or access/dirty flag updates on live valid PTEs (`__ptep_test_and_clear_young()`, `___ptep_set_wrprotect()`, `__clear_young_dirty_pte()`) must use a `cmpxchg_relaxed()` loop (transferring `pte_hw_dirty(pte)` to `PTE_DIRTY` before clearing `PTE_WRITE`) to avoid racing with hardware AF/DBM updates. With runtime page-table folding (`CONFIG_PGTABLE_LEVELS <= 4`), `p4d_offset_lockless_folded()` must pass `pgdp` (via `p4d_offset(pgdp, addr)`) rather than stack `&pgd` into `p4d_to_folded_pud()`. [F23, F25]
- In `mte_restore_tags()`, `copy_highpage()`, and `tag_clear_highpage()`, callers must acquire the MTE initialization lock via `try_page_mte_tagging()` (or `folio_try_hugetlb_mte_tagging()`) before writing tags and call `set_page_mte_tagged()` (or `folio_set_hugetlb_mte_tagged()`) afterwards. Setting `PG_mte_tagged` requires a preceding `smp_wmb()`, and testing it requires a trailing `smp_rmb()` when true. `mte_check_tfsr_exit()` must execute `dsb(nsh); isb()` before `mte_check_tfsr_el1()`. [F17, F19, F182]
- In `do_page_fault()`, pre-fault rejections must release `vma_end_read(vma)` (after `lock_vma_under_rcu()`) or `mmap_read_unlock(mm)` (after `lock_mm_and_find_vma()`) before `goto bad_area`, after sampling `vma_pkey(vma)` if `fault_from_pkey(vma, mm_flags)` is true. Post-`handle_mm_fault()` code must call `vma_end_read(vma)` only when `!(fault & (VM_FAULT_RETRY | VM_FAULT_COMPLETED))`, and `mmap_read_unlock(mm)` only when `!fault_signal_pending(fault, regs) && !(fault & (VM_FAULT_COMPLETED | VM_FAULT_RETRY))`. [F164, F165, F222]
- In `check_and_switch_context()`, the lockless fastpath may install `asid` into `active_asids` via `atomic64_cmpxchg_relaxed()` only when `old_active_asid != 0` and `asid_gen_match(asid)` holds; if that fails, `cpu_asid_lock` must be acquired and `mm->context.id` reloaded and rechecked with `asid_gen_match()` before calling `new_context(mm)`. `set_swapper_pgd()` must remain `noinstr` and, when `!rodata_is_rw`, hold `swapper_pgdir_lock` across `FIX_PGD` fixmap access, whereas `__create_pgd_mapping()` holds `fixmap_lock`. [F172, F179, F296, F306]

## Object Lifetimes

- When `CONFIG_PGTABLE_LEVELS > 3`, `pud_free()` must return without calling `__pud_free()` when `!pgtable_l4_enabled()` because the PUD level is folded at runtime. `pgd_alloc()` and `pgd_free()` must use matching allocators gated by `pgdir_is_page_size()` (`__pgd_alloc`/`__pgd_free` vs `pgd_cache`). [F4, F169]
- `init_new_context()` must pre-reserve protection key 0 in `mm->context.pkey_allocation_map` (`BIT(0)`), and `arch_dup_pkeys()` must copy `oldmm->context.pkey_allocation_map` on fork. Under `cpu_asid_lock`, `arm64_mm_context_get()` must increment `nr_pinned_asids` and set `pinned_asid_map` only when `mm->context.pinned` transitions from 0 to 1, and `arm64_mm_context_put()` must clear `pinned_asid_map` and decrement `nr_pinned_asids` only when `refcount_dec_and_test(&mm->context.pinned)` is true. [F6, F161]
- In `mte_save_tags()`, after `xa_store(&mte_pages, ...)`, `mte_free_tag_storage()` must free `tag_storage` if `xa_is_err(ret)` or free `ret` if `ret` is a non-NULL prior entry. `mte_restore_tags()` must only look up tag storage with `xa_load(&mte_pages, entry.val)` without erasing or freeing it; tag storage is erased and freed only in `mte_invalidate_tags()` or `mte_invalidate_tags_area()`. [F158, F160]

## API Contracts

- `__TLBI_VADDR(addr, asid)` takes an unshifted virtual address and `__tlbi_level()` accepts `level` in `0..3`, whereas `__TLBI_VADDR_RANGE(baddr, asid, scale, num, ttl)` requires a pre-shifted base address (`addr >> 16` when LPA2 is enabled, else `addr >> PAGE_SHIFT`) and encodes `ttl` in `1..3`. [F40]
- `pte_offset_kimg()`, `pmd_offset_kimg()`, `pud_offset_kimg()`, and `p4d_offset_kimg()` use `__phys_to_kimg()` and must only be called on statically allocated kernel-image tables. `__phys_addr_symbol()` (`__pa_symbol()`) only accepts `[KERNEL_START, KERNEL_END]` addresses, whereas `__virt_to_phys()` only accepts linear-map addresses (`__is_lm_address(__tag_reset(x))`). [F43, F203]
- `set_page_mte_tagged()`, `page_mte_tagged()`, and `try_page_mte_tagging()` require a non-hugetlb page (`!folio_test_hugetlb(page_folio(page))`), whereas hugetlb folios must use `folio_*_hugetlb_mte_*()`. In `arch_calc_vm_flag_bits()`, `VM_MTE_ALLOWED` must be returned when `system_supports_mte()` is true and either `flags & (MAP_ANONYMOUS | MAP_HUGETLB)` or `shmem_file(file) || is_file_hugepages(file)` holds. [F48, F82]
- In `arch/arm64/mm/hugetlbpage.c`, `set_huge_pte_at()`, `huge_pte_clear()`, and `huge_ptep_get_and_clear()` must derive `ncontig` and `pgsize` from `sz` via `num_contig_ptes(sz, &pgsize)` rather than inspecting `pte_cont()`. In `arch/arm64/mm/contpte.c`, callers of `__contpte_try_fold()` must verify `pte_valid(pte) && !pte_special(pte)` beforehand, and `contpte_set_ptes()` must only be called with `nr > 1`. [F195, F197, F198]
- In `arch/arm64/include/asm/uaccess.h`, `access_ok()` must untag the user pointer via `untagged_addr()` when `CONFIG_ARM64_TAGGED_ADDR_ABI` is enabled and `PF_KTHREAD` or `TIF_TAGGED_ADDR` is set, and all uaccess primitives must sanitize user pointers via `uaccess_mask_ptr()` / `__uaccess_mask_ptr()` before dereferencing. [F69, F149]

## Error Handling

- `__get_user_error(x, ptr, err)`, `__put_user_error(x, ptr, err)`, and `put_user_gcs(val, ptr, &ret)` only write to the error variable on failure, so callers must initialize `err` / `ret` to `0` beforehand. In `map_shadow_stack()`, if `put_user_gcs()` fails after `alloc_gcs()`, the VMA must be unmapped with `vm_munmap(addr, size)` before returning `-EFAULT`. [F47, F162, F200]
- In `arch_prepare_to_swap()`, if `mte_save_tags(folio_page(folio, i))` fails, the error path must unwind with `while (i--) __mte_invalidate_tags(folio_page(folio, i));`, and `mte_invalidate_tags_area()` must pass inclusive upper bound `last_entry.val - 1` to `xas_for_each()`. [F159, F245]

## External Contracts

- `rsi_set_addr_range_state()` returns `-EPERM` when `res.a2 != RSI_ACCEPT` and otherwise returns unsigned `res.a0` as `long`, so `rsi_set_memory_range()` must verify `ret == 0` and `start <= top && top <= end` on every iteration before advancing `start = top`. `struct realm_config` must be 4KB-aligned (`__aligned(0x1000)`), and `rsi_attestation_token_init()` must enforce `32 <= size <= 64` before `memcpy(&regs.a1, challenge, size)`. [F38, F74]
- Before exposing fault state to userspace, `set_thread_esr()` must sanitize faults on `!is_ttbr0_addr()` to `ESR_ELx_FSC_FAULT` with RES0/ISS bits masked, and `do_sea()` and `do_mem_abort()` must pass `untagged_addr(far)` (or `0` in `do_sea()` when `esr & ESR_ELx_FnV` is set) to `arm64_notify_die()`. [F207, F242]

## Known Pitfalls

- When advancing a PTE across consecutive physical pages (as in `__set_ptes_anysz()`), callers must use `pte_advance_pfn()` rather than adding to `pte_val(pte)` because 52-bit physical addresses split high OA bits into `PTE_ADDR_HIGH` below `PTE_ADDR_LOW`. In `pte_cont_addr_end(addr, end)` and `pmd_cont_addr_end(addr, end)`, the comparison must use `__boundary - 1 < (end) - 1` so wraparound to `0` at the top of the address space is handled. [F68, F101]
- Casts to prevent 32-bit shift overflow or sign-extension: `sysreg_clear_set*()` must cast `clear` to `u64` before negation (`~(u64)(clear)`); `pfn_pte()`, `pfn_pmd()`, and `pfn_pud()` must cast `pfn` to `phys_addr_t` before `<< PAGE_SHIFT`; `__TLBI_VADDR()` and `__TLBI_RANGE_PAGES()` must cast `asid` and `(num) + 1` to `unsigned long` before shifting; and `pfn_is_map_memory()` must verify `PHYS_PFN(PFN_PHYS(pfn)) == pfn` before calling `memblock_is_map_memory()`. [F93, F94, F95, F271]
- In `__raw_get_user()`, `__raw_put_user()`, `__get_kernel_nofault()`, and `__put_kernel_nofault()`, macro arguments (`ptr`, `x`, `dst`, `src`) must be evaluated into local variables outside the `uaccess_ttbr0_enable()` or `__mte_enable_tco_async()` critical section, and both normal and fault-label paths must disable TTBR0/TCO before exiting. `is_write_abort()` must require `(esr & ESR_ELx_WNR) && !(esr & ESR_ELx_CM)`. [F90, F253]
