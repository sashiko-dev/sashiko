# KERNEL HARDENING (not covered by other areas)

This unit provides core kernel self-protection primitives and KUnit test suites, covering hardened usercopy bounds validation (`mm/usercopy.c`, `include/linux/ucopysize.h`), kernel stack erasing/STACKLEAK (`kernel/kstack_erase.c`, `include/linux/kstack_erase.h`), per-syscall kernel stack offset randomization (`include/linux/randomize_kstack.h`), type-safe overflow/wrapping arithmetic and flexible-array sizing macros (`include/linux/overflow.h`), and KUnit tests for usercopy and structure layout randomization (`lib/tests/usercopy_kunit.c`, `lib/tests/randstruct_kunit.c`).

## Architecture & Data Flow

- In `mm/usercopy.c`, `check_bogus_address()` must test address-space wraparound using the inclusive end address `ptr + (n - 1) < ptr` rather than `ptr + n < ptr`, and relies on `__check_object_size()` returning early when `n == 0` so `n - 1` cannot underflow. Broken by: testing `ptr + n < ptr` or calling `check_bogus_address()` before filtering out `n == 0`. [F32]
- In `mm/usercopy.c`, `overlaps()` treats `[ptr, ptr + n)` and `[low, high)` as half-open intervals and must use non-strict comparisons (`check_low >= high || check_high <= low`) so regions immediately adjacent to `[_stext, _etext)` or its linear alias are not aborted as overlapping. [F33]
- In `check_kernel_text_object()`, when `lm_alias(_stext) != (unsigned long)_stext`, the secondary linear mapping `[lm_alias(_stext), lm_alias(_etext))` must be checked for overlap in addition to `[_stext, _etext)` on architectures where the linear physical map aliases the kernel image. [F68]
- `check_stack_object()` must first return `NOT_STACK` when `[obj, obj + len)` is outside `[stack, stackend)` (`obj + len <= stack || stackend <= obj`) before rejecting `obj < stack || stackend < obj + len` as `BAD_STACK`, and must reject accesses beyond `current_stack_pointer`. Because `arch_within_stack_frames()` returns `NOT_STACK` (`0`) when unsupported or inconclusive, `check_stack_object()` must only return `ret` when `ret != 0` and otherwise fall through to the stack-depth check and return `GOOD_STACK`. [F34, F47]
- `stackleak_task_low_bound(tsk)` must cast `end_of_stack(tsk)` to `unsigned long` before adding `sizeof(unsigned long)` (so it advances one word past `STACK_END_MAGIC` without `unsigned long *` pointer-stride scaling), `stackleak_task_high_bound(tsk)` must stop at `task_pt_regs(tsk)`, and `CONFIG_KSTACK_ERASE_TRACK_MIN_SIZE` must not exceed `KSTACK_ERASE_SEARCH_DEPTH` (128 bytes). [F61, F81]
- `stackleak_find_top_of_poison(low, high)` scans `[low, high)` downward in `sizeof(unsigned long)` steps with `while (sp > low && poison_count < depth)`, requiring `low <= high` and both bounds (including `current->lowest_stack`) to be `sizeof(unsigned long)`-aligned. Every non-poison word (`*(unsigned long *)sp != KSTACK_ERASE_POISON`) must reset `poison_count = 0` and set `poison_high = sp` after decrementing `sp` by `sizeof(unsigned long)`. [F38, F49]
- In `__stackleak_erase()`, `erase_low` must be computed from `current->lowest_stack`, saved to `current->prev_lowest_stack`, and poisoned up to `erase_high` before `current->lowest_stack` is reset to `task_stack_high` for the next syscall. Broken by: resetting `current->lowest_stack` before `stackleak_find_top_of_poison()`, or omitting the post-poison reset. [F26]
- `stackleak_task_init()` must reset `t->lowest_stack` to `stackleak_task_low_bound(t)` and, when `CONFIG_KSTACK_ERASE_METRICS` is enabled, `t->prev_lowest_stack` to `t->lowest_stack` so a newly forked task does not inherit its parent's stack pointers and poisons its full stack on first erase. Broken by: initializing `t->lowest_stack` to `stackleak_task_high_bound(t)` or omitting `t->prev_lowest_stack`. [F27]
- `add_random_kstack_offset()` must use `__builtin_alloca_uninitialized` (when supported by the compiler) via `__kstack_alloca` rather than `__builtin_alloca`, so that `CONFIG_INIT_STACK_ALL` does not zero-initialize the random stack-offset padding or emit an implicit `memset()` call in `noinstr` syscall entry code. [F23]

## Synchronization

- In `check_heap_object()`, `find_vmap_area()` must only be called for `is_vmalloc_addr(ptr)` when `!pagefault_disabled()`, because `find_vmap_area()` acquires a spinlock that can deadlock if taken from atomic usercopy contexts such as `copy_from_user_nofault()` in NMI, kprobe, or BPF handlers. [F65]
- `__sanitizer_cov_stack_depth()` must not update `current->lowest_stack` when `current_stack_pointer` is below `stackleak_task_low_bound(current)` (such as when executing on a separate IRQ or exception stack located below the task stack). [F13]

## Object Lifetimes

- In `include/linux/overflow.h`, `__DEFINE_FLEX()` initializes the pointer `name` to the address of the local on-stack union `name##_u`, so `name` (defined by `DEFINE_FLEX()` or `DEFINE_RAW_FLEX()`) must not be returned or stored in any location that outlives the declaring lexical scope. [F59]
- In `lib/tests/usercopy_kunit.c`, kernel buffers and userspace mappings allocated in `usercopy_test_init()` and test cases must use KUnit-managed allocators (`kunit_kzalloc`, `kunit_kmalloc`, `kunit_vm_mmap`) so resources are automatically freed when a `KUNIT_ASSERT_*` aborts the test early. [F7]

## API Contracts

- `check_add_overflow()`, `check_sub_overflow()`, `check_mul_overflow()`, and `check_shl_overflow()` return `true` when overflow or an invalid shift occurs and `false` on success while always writing the attempted result to `*d`, and callers must not use `*d` from `check_shl_overflow()` when it returns `true`. Broken by: treating `check_*_overflow()` as returning `0`/negative errno, or consuming `*d` after `check_shl_overflow()` returns `true`. [F15]
- `range_overflows(start, size, max)` and `range_end_overflows(start, size, max)` take `(start, size, max)` where `max` is an exclusive upper bound on `[0, max)`, and `range_overflows()` rejects `start == max` even when `size == 0` whereas `range_end_overflows()` allows `start == max` with `size == 0`. Broken by: passing an end offset instead of `size`, passing an inclusive `max`, or using `range_overflows()` where `start == max` with `size == 0` is valid. [F25]
- In `include/linux/ucopysize.h`, `check_copy_size(addr, bytes, is_source)` must validate compile-time object size via `__builtin_object_size(addr, 0)` (checking signed `sz >= 0` before comparing `sz < bytes` against unsigned `size_t bytes`) and reject any `bytes > INT_MAX` before calling `check_object_size(addr, bytes, is_source)`. [F36, F55]
- `check_object_size(ptr, n, to_user)` must skip calling `__check_object_size()` whenever `__builtin_constant_p(n)` is true, relying on compile-time `__builtin_object_size()` checks in `check_copy_size()` for constant-sized copies and only performing runtime heap/stack/text range validation for variable-sized copies. [F79]
- When validating vmalloc-range addresses in `check_heap_object()`, `find_vmap_area()` must be used instead of `find_vm_area()` because `vm_map_ram()` mappings allocate a `struct vmap_area` without an associated `struct vm_struct`. Broken by: using `find_vm_area(ptr)`, which returns `NULL` for `vm_map_ram()` regions and falsely triggers `usercopy_abort("vmalloc", "no area", ...)`. [F66]
- `stackleak_erase_on_task_stack()` must only be called while executing on the current task's stack (where it poisons up to `current_stack_pointer`), whereas `stackleak_erase_off_task_stack()` must only be called from a separate stack when the task stack is no longer in use (where it poisons up to `task_pt_regs(current)`). [F73]
- `stackleak_erase()`, `stackleak_erase_on_task_stack()`, and `stackleak_erase_off_task_stack()` must be marked `noinstr`, and all helpers they call (`__stackleak_erase()`, `__stackleak_poison()`, `stackleak_find_top_of_poison()`, `stackleak_task_low_bound()`, `stackleak_task_high_bound()`) must be `__always_inline`. [F74]
- Under `CONFIG_RANDSTRUCT`, structures whose members are all function pointers (such as `struct randstruct_funcs_shuffled` or `struct contains_func_shuffled`) are randomized automatically without `__randomize_layout`, so vtable structures that require a fixed ABI layout must be annotated with `__no_randomize_layout`. [F85]

## Error Handling

- `check_copy_size()` must report compile-time-known object size overflows (`sz >= 0 && sz < bytes`) and `bytes > INT_MAX` by warning (`copy_overflow()` or `WARN_ON_ONCE()`) and returning `false` without calling `__check_object_size()`, whereas `__check_object_size()` violations must terminate execution via `usercopy_abort()` calling `BUG()` (not process-exit helpers like `do_group_exit()`) so lock-breaking and per-architecture Oops handling run. [F69, F78]

## External Contracts

- `parse_hardened_usercopy()` must return `1` regardless of whether `kstrtobool(str, &enable_checks)` succeeds or returns a negative errno, because `__setup()` handlers return `1` when the boot option is recognized and `0` when it should be passed to `init`'s environment. Broken by: returning the result of `kstrtobool()` directly. [F14]
- `__sanitizer_cov_stack_depth()` must be marked `noinstr` and `__no_caller_saved_registers` because compiler-inserted stack-depth instrumentation invokes it from arbitrary kernel contexts (including via raw inline `call` instructions without saving caller-saved registers). [F75]
- As pinned by `usercopy_test_copy_struct_from_user()` and `usercopy_test_invalid()`, `copy_struct_from_user(dst, ksize, src, usize)` must zero-fill trailing `ksize - usize` bytes when `usize < ksize` and return `-E2BIG` if trailing user bytes are non-zero when `usize > ksize`, and failed `copy_from_user()`/`get_user()` must zero `dst`. [F80]

## Known Pitfalls

- In `include/linux/overflow.h`, `__type_half_max(type)` and `__type_max(T)` must compute a signed type's maximum via `((type)1 << (8*sizeof(type) - 1 - is_signed_type(type)))` rather than shifting `1` into the sign bit, and `__type_min(T)` must cast its operands to `T` before subtracting (`(T)((T)-type_max(T)-(T)1)`). [F53]
- In `include/linux/overflow.h`, `DEFINE_FLEX()` and `DEFINE_RAW_FLEX()` declare `name` as a pointer (`type *name`) to an on-stack union rather than a struct variable, so callers must use `__struct_size(name)`, `__member_size(name->member)`, or `STACK_FLEX_ARRAY_SIZE(name, member)` instead of `sizeof(name)` or `sizeof(*name)`. [F57]
- In `include/linux/overflow.h`, on-stack flexible-array structures whose flexible array member has a `__counted_by` attribute must be defined with `DEFINE_FLEX(TYPE, NAME, MEMBER, COUNTER, COUNT)` rather than `DEFINE_RAW_FLEX()`, because `DEFINE_RAW_FLEX()` zero-initializes `COUNTER` and causes `__struct_size(NAME->MEMBER)` to report 0 bytes. [F42]
- In `usercopy_test_check_nonzero_user()`, the quadratic `(start, end)` loop bound `size` must be capped to a small window across the page boundary (1024 bytes) rather than using the full `priv->size` (`2 * PAGE_SIZE`) buffer size. [F51]
