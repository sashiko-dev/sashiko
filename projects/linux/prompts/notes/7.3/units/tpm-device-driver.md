# TPM DEVICE DRIVER

`drivers/char/tpm` implements the core subsystem and hardware/firmware drivers for TPM 1.2 and TPM 2.0 chips, managing chip lifecycles, character devices (`/dev/tpm#` and `/dev/tpmrm#` with virtualized TPM2 resource manager spaces), command/response transmission, HMAC/encrypted bus sessions, BIOS/EFI/OF/ACPI event logs in securityfs, hwrng integration, sysfs/PPI attributes, and hardware transports (TIS MMIO, CRB, CRB over FF-A, I2C, SPI, PnP, OP-TEE fTPM, and AMD SEV-SNP SVSM vTPM).

## Architecture & Data Flow
- `tpm2_prepare_space()` stages a client `struct tpm_space` into `chip->work_space`, and only `tpm2_commit_space()` copies `chip->work_space` back on success; if `tpm2_prepare_space()`, `tpm_transmit()`, or `tpm2_commit_space()` fails, `tpm2_flush_space(chip)` must flush `chip->work_space` handles without updating `space`. Every `space` must be initialized via `tpm2_init_space()` with `buf_size == TPM2_SPACE_BUFFER_SIZE` (`chip->work_space.buf_size`), as both functions `memcpy()` `space->buf_size` bytes without bounds checks. [F68, F121]
- In `struct tpm_space`, transient virtual handles are encoded by `tpm2_map_to_vhandle()` as `TPM2_HT_TRANSIENT | (0xFFFFFF - i)` and decoded by `tpm2_map_to_phandle()` via `i = 0xFFFFFF - (vhandle & 0xFFFFFF)` with check `i < ARRAY_SIZE(space->context_tbl)`. `space->context_tbl[i]` uses `0` for empty and `~0` for a saved slot flushed from the chip, so `tpm2_flush_space()` and `tpm2_save_space()` must test both `context_tbl[i]` and `~context_tbl[i]`, while `tpm2_load_space()` requires `~context_tbl[i] == 0`. [F81, F82]
- In `struct tpm2_auth`, `session_key` and `passphrase` must remain adjacent and in that order because `tpm_buf_fill_hmac_session()` and `tpm_buf_check_hmac_response()` pass `auth->session_key` with length `SHA256_DIGEST_SIZE + auth->passphrase_len` to `tpm2_KDFa()` and `hmac_sha256_init_usingrawkey()` as one contiguous buffer. `auth->session` holds the command buffer offset of the sessions area (`>= TPM_HEADER_SIZE`) until `tpm_buf_fill_hmac_session()` overwrites it with the 1-based ordinal (`< TPM_HEADER_SIZE`), which `tpm_buf_check_hmac_response()` checks before resetting it to `TPM_HEADER_SIZE`. [F83, F84]
- In `tpm_transmit()`, save `TPM_HEADER_SIZE + 3 * sizeof(u32)` bytes of `buf` before the `tpm_try_transmit()` loop and restore them on each retry because `tpm_try_transmit()` overwrites `buf` in place. In `tpm2_get_cc_attrs_tbl()`, override `TPM2_CC_ATTR_CHANDLES` in `chip->cc_attrs_tbl[]` to 1 for `TPM2_CC_CONTEXT_SAVE` and `TPM2_CC_FLUSH_CONTEXT` so `tpm2_map_command()` translates their handle argument. [F66, F70]
- In `tpm2_map_response_body()`, before iterating over `data->handles[]`, verify `len >= TPM_HEADER_SIZE + 9`, `be32_to_cpu(data->count) <= (UINT_MAX - TPM_HEADER_SIZE - 9) / 4`, and `len == TPM_HEADER_SIZE + 9 + 4 * be32_to_cpu(data->count)`. Unmapped transient handles (`tpm2_map_to_vhandle(space, phandle, false) == 0`) are filtered out in place using separate read/write indices `i` and `j`, updating both `header->length` and `data->count` from `j`. [F80, F101]
- Because `tpm_buf_read_u8()`, `tpm_buf_read_u16()`, and `tpm_buf_read_u32()` return 0 and set `TPM_BUF_BOUNDARY_ERROR` on out-of-bounds reads, callers advancing an offset by a returned length must validate the new offset against `tpm_buf_length(buf)` or `total_len` before indexing `&buf->data[offset]`. [F87]
- `chip->locality` must be initialized to `-1` in `tpm_chip_alloc()` and reset to `-1` in `tpm_relinquish_locality()`, because `tpm_chip_start()` only calls `tpm_request_locality(chip)` when `chip->locality == -1`. `tpm_bios_log_setup()` must return early when `chip->flags & TPM_CHIP_FLAG_VIRTUAL` is set (`pdev == NULL`). [F54, F73]
- When `tpm_is_firmware_upgrade(chip)` is true (`TPM_CHIP_FLAG_FIRMWARE_UPGRADE`), `tpm_get_pcr_allocation()`, `tpm_sysfs_add_device()`, `tpm_is_hwrng_enabled()`, `tpm_add_legacy_sysfs()`, `tpm_del_legacy_sysfs()`, `tpm_devs_add()`, and `tpm_devs_remove()` must all be skipped. Adding a PCR hash algorithm to `enum tpm_algorithms` and `tpm_sysfs_add_device()` requires defining its `PCR_ATTR_BUILD()` group and incrementing `TPM_MAX_HASHES` so `chip->groups[3 + TPM_MAX_HASHES]` does not overflow. [F142, F175]
- In `crb_map_io()`, CRB command/response buffer sizes must be clamped to the enclosing ACPI memory resource via `crb_fixup_cmd_size()`, and if `cmd_pa == rsp_pa`, `cmd_size` must equal `rsp_size` or fail with `-EINVAL`. In `crb_map_res()`, check `start != new_res.start` after assigning `u64 start` to `new_res.start` to reject 64-bit addresses that truncate on 32-bit systems. [F92, F112]

## Synchronization
- In `tpm_try_get_ops()`, `chip->flags & TPM_CHIP_FLAG_SUSPENDED` must be checked after locking `chip->tpm_mutex` and before `tpm_chip_start(chip)`, while `tpm_pm_suspend()` sets `TPM_CHIP_FLAG_SUSPENDED` before `tpm_put_ops(chip)` and `tpm_pm_resume()` clears it followed by `wmb()`. [F151]
- Per-chip TPM2 workspace and session state (`chip->work_space`, `chip->last_cc`, `chip->auth`) has no internal lock and must only be accessed while holding `chip->tpm_mutex` (via `tpm_try_get_ops()`) or `down_write(&chip->ops_sem)` during shutdown. [F26]
- `struct file_priv` fields (`data_buffer`, `response_length`, `response_read`, `command_enqueued`, `priv->space`) are protected by `priv->buffer_mutex`, acquired outside `chip->ops_sem` and `chip->tpm_mutex`. In `tpm_common_write()`, `copy_from_user()` runs under `priv->buffer_mutex` before queuing `priv->async_work`, and `tpm_try_get_ops()` is held only around `tpm_dev_transmit()`. [F30, F159]
- In `tpm_common_release()`, `flush_work(&priv->async_work)` must precede `timer_delete_sync(&priv->user_read_timer)`, which must precede `flush_work(&priv->timeout_work)`, all before `tpm2_del_space()` and `kfree(priv)` in `tpmrm_release()`. In `tpm_common_read()`, when `priv->response_length` reaches 0, reset `*off = 0`, call `timer_delete_sync(&priv->user_read_timer)`, and flush `priv->timeout_work` under `priv->buffer_mutex`. Softirq `user_reader_timeout()` must never lock `priv->buffer_mutex`, instead scheduling `priv->timeout_work`. [F29, F76, F157]
- In `st33zp24` and `tpm_i2c_nuvoton`, hardirq handlers `tpm_ioserirq_handler()` and `i2c_nuvoton_int_handler()` increment `intrs`, wake `read_queue`, and call `disable_irq_nosync()` (never `disable_irq()` or bus transfers). `wait_for_stat()` and `i2c_nuvoton_wait_for_stat()` must snapshot `intrs` into `cur_intrs` before `enable_irq()`, and `i2c_nuvoton_wait_for_stat()` only calls `enable_irq()` when `queue` is non-NULL. `st33zp24_probe()` must initialize `read_queue` and call `clear_interruption()` before `devm_request_irq()`, and call `disable_irq_nosync()` before `tpm_chip_register()`. [F33, F133, F134, F160]
- Serialize `ppi_cache_populated` and `ppi_operations_cache` under `tpm_ppi_lock` (`tpm_ppi.c`); hold `tpm_crb_ffa->msg_data_lock` across populating `direct_msg_data`/`direct_msg_data2`, calling `__tpm_crb_ffa_send_receive()`, and reading results (`tpm_crb_ffa.c`); hold `i2c_lock_bus(..., I2C_LOCK_SEGMENT)` across retry and multi-message `__i2c_transfer()` sequences in `iic_tpm_read()`/`iic_tpm_write_generic()` (`tpm_i2c_infineon.c`). [F37, F165, F169]

## Object Lifetimes
- `tpm_try_get_ops()` acquires a `chip->dev` reference, read-locks `chip->ops_sem`, locks `chip->tpm_mutex`, and calls `tpm_chip_start(chip)` in that order; its failure paths and `tpm_put_ops()` must release those four resources in strict reverse LIFO order. [F1]
- Once `device_initialize(&chip->dev)` runs in `tpm_chip_alloc()`, release `chip` via `put_device(&chip->dev)` (never `kfree(chip)`). `dev_nums_idr` is allocated with `NULL` in `tpm_chip_alloc()`, set to `chip` via `idr_replace()` under `idr_lock` in `tpm_add_char_device()` after `cdev_device_add()` succeeds, reset to `NULL` under `idr_lock` after `cdev_device_del()` in `tpm_del_char_device()` before `down_write(&chip->ops_sem)` clears `chip->ops = NULL`, and removed via `idr_remove()` only in `tpm_dev_release()`. [F4, F27, F130]
- `tpm_devs_add(chip)` takes `get_device(&chip->dev)` on behalf of `chip->devs` (released in `tpm_devs_release()`), so errors after `device_initialize(&chip->devs)` and removal in `tpm_devs_remove()` must call `put_device(&chip->devs)`. If `tpm2_init_space()` fails to allocate `space->session_buf`, it must `kfree(space->context_buf)` and set `space->context_buf = NULL`. [F6, F9]
- In `tpm_chip_register()` (`out_hwrng`) and `tpm_chip_unregister()`, check `tpm_is_hwrng_enabled(chip)` before `hwrng_unregister(&chip->hwrng)`. On x86 in `crb_acpi_add()`, set `TPM_CHIP_FLAG_HWRNG_DISABLED` before `tpm_chip_register()` when `x86_vendor == X86_VENDOR_AMD` and `priv->sm != ACPI_TPM2_COMMAND_BUFFER_WITH_PLUTON`. [F7, F141]
- Because `tpm_buf_append_hmac_session()` sets `TPM2_SA_CONTINUE_SESSION`, `tpm2_end_auth_session(chip)` must be called before userspace commands in `tpm_dev_transmit()`, before `TPM2_SU_STATE` in `tpm_pm_suspend()`, and in `tpm_class_shutdown()` and `tpm_chip_unregister()`. [F12]
- In `tpm_bios_measurements_open()`, `get_device(&chip->dev)` is taken under `inode_lock(inode)` after checking `inode->i_nlink`; if `seq_open()` fails, call `put_device(&chip->dev)` immediately, else `tpm_bios_measurements_release()` releases it. [F17]
- In `crb_acpi_add()`, `check_acpi_tpm2()`, and `tpm_read_log_acpi()`, every exit path after `acpi_get_table()` must call `acpi_put_table()`. For `"MSFT0101"`, `check_acpi_tpm2()` must return `-ENODEV` when `start_method != ACPI_TPM2_MEMORY_MAPPED`, and `crb_acpi_add()` must return `-ENODEV` when `start_method == ACPI_TPM2_MEMORY_MAPPED`. [F20, F140]
- In `tpm_read_log_acpi()`, `log->bios_event_log` must be allocated with `kvmalloc()` and freed via `kvfree()` in `tpm_bios_log_free()`, registered with `devm_add_action(&chip->dev, tpm_bios_log_free, log->bios_event_log)` after validation succeeds, and freed and set to `NULL` on error. In `crb_map_res()`, cache the base mapping of an ACPI `IORESOURCE_MEM` entry `iores` in `*iobase_ptr` via one `devm_ioremap_resource(dev, iores)` call and reuse `*iobase_ptr + (new_res.start - iores->start)` for subregions. [F77, F138, F139]

## API Contracts
- `tpmm_chip_alloc(pdev, ops)` registers `put_device(&chip->dev)` on `pdev` and sets `dev_set_drvdata(pdev, chip)`, so drivers must store their private struct on `&chip->dev` (`dev_set_drvdata(&chip->dev, priv)`). `tpm_chip_alloc()` and `tpmm_chip_alloc()` return `ERR_PTR` (check with `IS_ERR()`), whereas `tpm_default_chip()` and `tpm_find_get_ops()` return `NULL`. [F5, F44]
- `tpm_chip_start()` calls `tpm_clk_enable()`, `tpm_request_locality()` (if `chip->locality == -1`), and `tpm_cmd_ready()`; `tpm_chip_stop()` and `tpm_chip_start()` error paths unwind in reverse (`tpm_go_idle()`, `tpm_relinquish_locality()`, `tpm_clk_disable()`). In `tpm_chip_register()`, `tpm_chip_bootstrap()`, `tpm_sysfs_add_device()`, and `tpm_add_ppi()` must precede `tpm_add_char_device()`. In `tpm_pm_suspend()`, skip `tpm2_shutdown(chip, TPM2_SU_STATE)` and `tpm1_pm_suspend()` when `TPM_CHIP_FLAG_ALWAYS_POWERED` is set or `(TPM_CHIP_FLAG_FIRMWARE_POWER_MANAGED && !pm_suspend_via_firmware())`. [F131, F152, F153]
- In `struct tpm_class_ops`, when `TPM_CHIP_FLAG_SYNC` is set, `send()` synchronously writes the response into `buf` and returns its positive length; otherwise `send()` returns 0 and `recv()` reads the response. `update_timeouts()` writes microseconds into `timeout_cap`, whereas `update_durations()` must write jiffies into all 3 elements of uninitialized `duration_cap[0..2]` and set `chip->duration_adjusted`. [F124, F171, F172]
- Never call `tpm_buf_append_handle()` on a `TPM_BUF_TPM2B` buffer (`tpm_buf_init_sized()`/`tpm_buf_reset_sized()`). Callers of `tpm2_KDFa()` must pass `bytes` as an exact positive multiple of `SHA256_DIGEST_SIZE`. `tpm_crb_ffa_init()` must return `-ENOENT` when `tpm_crb_ffa` is `NULL` (for `-EPROBE_DEFER` in `crb_acpi_add()`) and `-ENODEV` when `IS_ERR_VALUE(tpm_crb_ffa)`. [F86, F117, F176]

## Error Handling
- In `tpm2_map_response_header()`, if a newly created handle (`phandle`) cannot be allocated a slot in `chip->work_space`, flush it immediately via `tpm2_flush_context(chip, phandle)`. `tpm2_prepare_space()` and `tpm2_commit_space()` must check `if (!space) return 0;` because `/dev/tpm#` leaves `priv->space` as `NULL`. [F11, F48]
- `tpm_buf_fill_hmac_session()`, `tpm_buf_check_hmac_response()`, and `tpm2_end_auth_session()` must check `if (!auth)` before dereferencing `chip->auth`. In `tpm_buf_check_hmac_response()`, if input `rc != 0`, jump directly to `out` to preserve `rc` while still cleaning up the session or resetting `auth->session = TPM_HEADER_SIZE`. [F46, F52]
- In `struct tpm_class_ops`, `cancel`, `status`, `req_canceled`, `go_idle`, `cmd_ready`, `request_locality`, `relinquish_locality`, `clk_enable`, `update_timeouts`, and `update_durations` are optional (check for `NULL`), except every TPM 1.x driver must provide a non-NULL `cancel` callback for sysfs `cancel_store()`. [F47, F173]
- `tpm_get_pcr_allocation()`, `tpm2_get_cc_attrs_tbl()`, `tpm2_auto_startup()`, and `tpm1_auto_startup()` must convert unhandled positive `TPM_RC` codes (`rc > 0`) to `-ENODEV`. In `tpm2_sessions_init()`, return immediately on `tpm2_create_null_primary()` failure. On TPM2, `tpm_read_log_acpi()` must validate the log with `tpm_is_tpm2_log()` and return `-ENODEV` on failure so `tpm_read_log()` falls back to EFI. [F40, F50, F78]

## External Contracts
- `tpm_common_write()` must reject writes with `-E2BIG` if `size > TPM_BUFSIZE`, `-EBUSY` if `(!priv->response_read && priv->response_length)` or `priv->command_enqueued`, and `-EINVAL` if `size < 6` or less than the command header length. `tpm_common_read()` and `tpm_timeout_work()` must `memset()` consumed or timed-out `priv->data_buffer` bytes to zero under `priv->buffer_mutex`. When `tpm2_prepare_space()` returns `-EOPNOTSUPP` in `tpm_dev_transmit()`, synthesize a 10-byte `TPM2_ST_NO_SESSIONS` header with `TPM2_RC_COMMAND_CODE | TSS2_RESMGR_TPM_RC_LAYER` and return `sizeof(*header)`. [F95, F182, F183]
- Do not alter the TCG ECC NIST_P256 H-template in `tpm2_create_primary()` (used to match sysfs `null_name`), pass `strlen(...) + 1` for `label`/`str` in `tpm2_KDFa()`/`tpm2_KDFe()`, and in `tpm_crb_ffa_probe()` check `FFA_PARTITION_AARCH64_EXEC` and call `mode_32bit_set()` before sending FF-A direct messages. [F94, F129, F166]

## Known Pitfalls
- Use `to_tpm_chip()` only on `&chip->dev` (`tpm_class`); use `container_of(dev, struct tpm_chip, devs)` on `&chip->devs` (`tpmrm_class`) and `container_of(inode->i_cdev, struct tpm_chip, cdevs)` in `/dev/tpmrm#` open callbacks. [F126]
- In `tpm_read_log_efi()`, copy `efi_tpm_final_log_size` to a local variable before subtracting `final_events_preboot_size`, and after `devm_krealloc()` recompute `log->bios_event_log_end` from the new `log->bios_event_log` pointer. In `tpm_read_log_of()`, convert `"linux,sml-size"` and `"linux,sml-base"` with `be32_to_cpup()`/`be64_to_cpup()` only when not compatible with `"IBM,vtpm"` or `"IBM,vtpm20"`. [F72, F93, F120]
- In `eventlog/tpm2.c`, branch on `v == SEQ_START_TOKEN` before casting `v`, and size `tcg_pcr_event2_head` entries with `calc_tpm2_event_size()` rather than `struct_size()`. In `tpm2_get_pcr_allocation()`, advance `marker` by `sizeof(pcr_selection.hash_alg) + sizeof(pcr_selection.size_of_select) + pcr_selection.size_of_select`. In `get_event_name()`, format `name` with `%.*s` bounded by `n_len`. [F103, F118, F119, F128]
- In `crb_send()`, keep the `CRB_START_INVOKE` and `crb_do_acpi_start()` checks as independent `if` statements so `"MSFT0101"` devices with an ACPI start method execute both; in `crb_map_io()`, cast `pa_high` to `u64` before `<< 32`. In `st33zp24`'s `wait_for_stat()`, cast `timeout = stop - jiffies` to `long` (`(long)timeout <= 0`). [F105, F111, F115]

## Other
- In `tpm_tis.c`, `tpm_tcg_write_bytes()` must use `tpm_tis_iowrite8()`/`tpm_tis_iowrite32()` to flush posted MMIO writes via `tpm_tis_flush()`. In `tpm_try_transmit()` and `crb_wait_for_reg_32()`, re-check the completion condition one final time after the polling loop expires before returning `-ETIME`. [F148, F150]
