# CPU HOTPLUG

This unit implements the Linux kernel's core CPU hotplug state machine (`kernel/cpu.c`), per-CPU hotplug kthreads (`kernel/smpboot.c`), global CPU bitmasks, SMT control, CPU vulnerability mitigation command-line parsing, and Rust CPU bindings (`rust/kernel/cpu.rs`).

## Architecture & Data Flow
- `cpuhp_next_state()` pre-increments `st->state` (`++st->state`) on bringup and post-decrements (`st->state--`) on teardown; `cpuhp_reset_state()` must adjust `st->state` (`--` on bringup, `++` on teardown) only when `st->last == NULL` so partial multi-instance rollback re-runs the failed state up to `st->last`. In `cpuhp_invoke_callback()`, multi-instance transitions with non-NULL `lastp` record the failing node in `*lastp`, stop rollback at `node == *lastp`, and clear `*lastp = NULL` on completion. [F79, F92]
- `cpuhp_invoke_ap_callback()` must reset both `st->node` and `st->last` to `NULL` before returning, because `cpuhp_thread_fun()` passes `st->node` and `&st->last` to `cpuhp_invoke_callback()` during subsequent state transitions. [F42]
- `cpuhp_set_state()` and `cpuhp_reset_state()` must take `cpu` as an explicit parameter (not from `struct cpuhp_cpu_state`) and update `__cpu_dying_mask` via `set_cpu_dying(cpu, !bringup)` whenever `st->bringup` is set or inverted and `cpu_dying(cpu) != !bringup`. [F43, F55]
- Each CPU's `cpuhp_state.fail` field must be initialized and reset to `CPUHP_INVALID` (`-1`), never `0`, because `0` is `CPUHP_OFFLINE` and `cpuhp_invoke_callback()` injects `-EAGAIN` whenever `st->fail == state`. [F44]
- Dynamic state ranges in `enum cpuhp_state` (`CPUHP_AP_ONLINE_DYN`, `CPUHP_BP_PREPARE_DYN`) must be handled in lockstep in `cpuhp_reserve_state()`, `cpuhp_store_callbacks()`, and `dynstate` in `__cpuhp_setup_state_cpuslocked()`. `cpuhp_store_callbacks()` must only call `cpuhp_reserve_state()` when `name != NULL` so removal clears the specified slot; in `__cpuhp_setup_state_cpuslocked()`, `dynstate` must be evaluated before `state = ret` and `ret` reset to `0` before `if (ret || !invoke || !startup)`. [F64, F69, F100]
- `__cpuhp_state_add_instance_cpuslocked()` must run `cpuhp_issue_call(cpu, state, true, node)` on all present CPUs at or above `state` (rolling back via `cpuhp_rollback_install()` on failure) before `hlist_add_head()`, and `__cpuhp_state_remove_instance()` must complete teardown calls before `hlist_del(node)`. [F65]
- When `_cpu_up()` brings up a CPU from `CPUHP_OFFLINE`, it must reset stale stack state on the recycled idle task (`idle_thread_get(cpu)`) via `scs_task_reset(idle)` and `kasan_unpoison_task_stack(idle)` before starting the CPU. [F61]
- `cpu_smt_set_num_threads()` must run after full CPU identification. In `cpu_bootable()`, `CPU_SMT_NOT_IMPLEMENTED` and `CPU_SMT_NOT_SUPPORTED` must be checked before `topology_is_primary_thread(cpu)`, and when SMT is disabled, secondary threads not in `cpus_booted_once_mask` must return `true` so they run `notify_cpu_starting()` before `bringup_wait_for_ap_online()` cancels bringup with `-ECANCELED`. [F86, F132]
- Setting `cpu_smt_control` to any state other than `CPU_SMT_ENABLED` in `cpu_smt_disable()` or `cpu_smt_set_num_threads()` must set `cpu_smt_num_threads = 1`. In `__store_smt_control()`, `else if (num_threads < orig_threads || force_off)` must check `force_off` so transitioning from `CPU_SMT_DISABLED` to `CPU_SMT_FORCE_DISABLED` still calls `cpuhp_smt_disable(ctrlval)`. Every `enum cpuhp_smt_control` value must have a matching entry in `smt_states[]`. [F59, F72, F89]
- `cpuhp_smt_enable()` must check `topology_is_core_online(cpu)` alongside `!cpu_online(cpu)`, `node_online(cpu_to_node(cpu))`, and `cpu_smt_thread_allowed(cpu)` before `_cpu_up()`, so enabling SMT does not online sibling threads of offline cores. [F87]
- In `enum cpuhp_state`, `CPUHP_TIMERS_PREPARE` (`timers_dead_cpu`) must be ordered above `CPUHP_BLK_MQ_DEAD` so teardown runs `timers_dead_cpu()` before `blk_mq_queue_reinit_notify()` (avoiding RCU stalls), and `CPUHP_AP_DUMMY_TIMER_STARTING` must stay after all other `*_TIMER_STARTING` states. [F115, F116]
- In `smpboot_thread_fn()`, `ht->cleanup()` only runs when `td->status != HP_THREAD_NONE` and `ht->park()` only when `td->status == HP_THREAD_ACTIVE` (setting `HP_THREAD_PARKED`). `smpboot_park_threads()` must iterate `hotplug_threads` in reverse (`list_for_each_entry_reverse`) under `smpboot_threads_lock` to mirror forward traversal in `smpboot_unpark_threads()` and `smpboot_create_threads()`. [F66, F127]
- `freeze_secondary_cpus()` must abort its loop with `-EBUSY` when `pm_wakeup_pending()` is true, whereas `smp_shutdown_nonboot_cpus()` must offline all non-primary CPUs without checking `pm_wakeup_pending()`. [F97]

## Synchronization
- Lock order: `lock_device_hotplug()` -> `cpu_maps_update_begin()` (`cpu_add_remove_lock`) -> `cpus_write_lock()` / `cpus_read_lock()` (`cpu_hotplug_lock`) -> `cpuhp_state_mutex`, `smpboot_threads_lock`, `irq_lock_sparse()`. External callers must use `add_cpu()` / `remove_cpu()` (not `cpu_device_up()` / `cpu_device_down()`), while `cpuhp_smt_enable()` and `cpuhp_smt_disable()` (under `cpu_maps_update_begin()`) must call `cpuhp_online_cpu_device()` / `cpuhp_offline_cpu_device()` instead of `device_online()` / `device_offline()`. [F124, F149]
- `cpu_add_remove_lock` (`cpu_maps_update_begin()` / `done()`) must guard all reads/writes of `cpu_hotplug_disabled` and `cpu_hotplug_offline_disabled` and all calls to `_cpu_up()`, `_cpu_down()`, and `cpu_down_maps_locked()`. After acquiring `cpus_write_lock()`, `_cpu_up()` must revalidate `cpu_present(cpu)` and `st->state >= target`. [F20, F34]
- `__cpuhp_setup_state_cpuslocked()`, `__cpuhp_remove_state_cpuslocked()`, `__cpuhp_state_add_instance_cpuslocked()`, and `__cpuhp_state_remove_instance()` must hold both `cpu_hotplug_lock` and `cpuhp_state_mutex` continuously across the `for_each_present_cpu` callback loop, rollback, and `cpuhp_hp_states` / `sp->list` modification. [F23]
- Before setting `st->should_run = true` and waking `st->thread` in `__cpuhp_kick_ap()`, all `struct cpuhp_cpu_state` updates must be ordered by `smp_mb()`, paired with the `smp_mb()` in `cpuhp_thread_fun()` placed after checking `st->should_run` and before reading `st->single`, `st->cb_state`, or `st->target`. `cpuhp_thread_fun()` must bracket AP callbacks with `lockdep_acquire_cpus_lock()` / `cpuhp_lock_acquire(bringup)` and `cpuhp_lock_release(bringup)` / `lockdep_release_cpus_lock()`. [F24, F141]
- `cpuhp_ap_update_sync_state()` must use `atomic_xchg()` (never `atomic_set()`). `cpuhp_wait_for_sync_state()` must poll with `arch_cpuhp_sync_state_poll()` for `NSEC_PER_MSEC` before `usleep_range()`, use `10ULL * NSEC_PER_SEC` for its timeout without modifying `ap_sync_state` on expiry, and `cpuhp_bp_sync_dead()` must not overwrite `SYNC_STATE_DEAD` with `SYNC_STATE_SHOULD_DIE`. [F25, F101, F135]
- `bringup_cpu()`, `cpuhp_bringup_ap()`, and `takedown_cpu()` must hold `irq_lock_sparse()` across low-level AP bringup (until `bringup_wait_for_ap_online()`) and AP takedown (after parking `st->thread`, across `stop_machine_cpuslocked(take_cpu_down, ...)` and `wait_for_ap_thread(st, false)`). If `stop_machine_cpuslocked()` fails in `takedown_cpu()`, it must call `irq_unlock_sparse()` and `kthread_unpark(st->thread)`; on success, after `__cpu_die(cpu)` and `cpuhp_bp_sync_dead(cpu)`, it must call `rcutree_migrate_callbacks(cpu)`. [F9, F29, F120, F146]
- In `cpuhp_online_idle()`, the AP idle task must call `stop_machine_unpark(smp_processor_id())` and set `st->state = CPUHP_AP_ONLINE_IDLE` before `complete_ap_thread(st, true)`, and must never call sleeping functions like `kthread_unpark(st->thread)` (done by `bringup_wait_for_ap_online()` on the BP). [F28, F142]
- In `take_cpu_down()`, `__cpu_disable()` must succeed before `cpuhp_invoke_callback_range_nofail()` runs `DYING` callbacks and `stop_machine_park()` parks the stopper thread. In `cpuhp_report_idle_dead()`, after `rcutree_report_cpu_dead()`, the dying CPU must not call `complete_ap_thread()` directly and must use `smp_call_function_single()` to an online CPU (`cpuhp_complete_idle_dead`). [F119, F145]
- In `cpuhp_bringup_cpus_parallel()`, when `cpuhp_smt_aware()` is true, primary threads (`cpuhp_get_primary_thread_mask()`) must be brought up through both `CPUHP_BP_KICK_AP` and `CPUHP_ONLINE` before secondary SMT sibling threads are kicked to `CPUHP_BP_KICK_AP`. [F133]
- `smpboot_register_percpu_thread()` and `smpboot_unregister_percpu_thread()` must hold both `cpus_read_lock()` and `smpboot_threads_lock`. In `__smpboot_create_thread()`, `tsk` must be marked per-CPU (`kthread_set_per_cpu()`), parked (`kthread_park()`), refcounted (`get_task_struct()`), stored in `*per_cpu_ptr(ht->store, cpu)`, and confirmed parked via `wait_task_inactive(tsk, TASK_PARKED)` before `ht->create(cpu)`. [F35, F36]
- In `smpboot_thread_fn()`, `HP_THREAD_NONE` and `HP_THREAD_PARKED` must set `td->status = HP_THREAD_ACTIVE` and `continue` to recheck stop/park with preemption disabled; `ht->thread_should_run(td->cpu)` runs with preemption disabled and `TASK_INTERRUPTIBLE`, whereas `setup`, `unpark`, `park`, `cleanup`, and `thread_fn` run only after setting `TASK_RUNNING` and `preempt_enable()`. [F91, F143]
- `set_cpu_online()` must use atomic `cpumask_test_and_set_cpu` / `clear_cpu` and `atomic_inc()` / `dec()` on `__cpu_online_mask` and `__num_online_cpus` for concurrent IPI/NMI reboot paths; readers needing stability against hotplug must hold `cpus_read_lock()` or `cpu_maps_update_begin()`. [F37, F153]
- `clear_tasks_mm_cpumask(cpu)` requires `cpu` offline (`WARN_ON(cpu_online(cpu))`) and must call `arch_clear_mm_cpumask_cpu()` and `task_unlock()` on `t = find_lock_task_mm(p)`, not `p`. [F98, F147]
- `cpu_hotplug_pm_callback()` (priority 0) must call `cpu_hotplug_disable()` on `PM_SUSPEND_PREPARE` / `PM_HIBERNATION_PREPARE` and `cpu_hotplug_enable()` on `PM_POST_SUSPEND` / `PM_POST_HIBERNATION`. [F137]

## Object Lifetimes
- In `__smpboot_create_thread()`, check `IS_ERR(tsk)` (freeing `td` on error) before writing `*per_cpu_ptr(ht->store, cpu) = tsk`; once created, `smpboot_thread_fn()` owns `td`, so later teardown must use `kthread_stop_put()`. `smpboot_destroy_threads()` must iterate `for_each_possible_cpu()`, call `kthread_stop_put()`, and set `*per_cpu_ptr(ht->store, cpu) = NULL`. [F1, F2, F48]
- `bus_get_dev_root(&cpu_subsys)` returns a refcounted `struct device *` requiring `put_device()`, whereas `get_cpu_device()` returns an unreferenced pointer that may be `NULL` and must not be passed to `put_device()`. In `rust/kernel/cpu.rs`, `from_cpu()` must remain `unsafe` and check `!ptr.is_null()` on `get_cpu_device()` before `Device::from_raw()`, as the returned `&'static Device` is unreferenced across hot-unplug. [F17, F18, F50, F113]
- `finish_cpu()` (teardown for `CPUHP_BRINGUP_CPU`, after CPU death) must set `idle->active_mm = NULL` and call `mmdrop_lazy_tlb(mm)`. [F154]
- `freeze_secondary_cpus()` must increment `cpu_hotplug_disabled` under `cpu_maps_update_begin()` even on `_cpu_down()` or `pm_wakeup_pending()` failure, because failure paths call `thaw_secondary_cpus()` which unconditionally calls `__cpu_hotplug_enable()`. [F136]
- In `cpuhp_bringup_cpus_parallel()`, `tmp_mask` inside `if (cpuhp_smt_aware())` must remain `static` (`__initdata`) because `mask = &tmp_mask` escapes to `cpuhp_bringup_mask()`. [F109]

## API Contracts
- Callbacks in atomic `STARTING`/`DYING` states (`cpuhp_is_atomic_state()`, `CPUHP_AP_IDLE_DEAD <= state < CPUHP_AP_ONLINE`) run on the target CPU with local IRQs disabled, must never sleep or fail, and must be invoked via `cpuhp_invoke_callback_range_nofail()`; teardown callbacks during state/instance removal or rollback (`cpuhp_issue_call()` with `bringup == false`) must also return `0`. `notify_cpu_starting()` must run with IRQs disabled and call `rcutree_report_cpu_starting(cpu)` before `STARTING` callbacks. [F11, F46, F139, F140]
- `cpuhp_cb_check()` enforces `(CPUHP_OFFLINE, CPUHP_ONLINE)`. Only `STARTING` callbacks or callbacks with ordering dependencies may add explicit `enum cpuhp_state` entries; others must use `CPUHP_BP_PREPARE_DYN` or `CPUHP_AP_ONLINE_DYN` and pass the returned positive state ID to `__cpuhp_remove_state*()`. [F75, F114, F161]
- Callers invoking `struct cpuhp_step` callbacks must branch on `step->multi_instance` (`.multi(cpu, node)` vs `.single(cpu)`). States must be registered via `cpuhp_setup_state_multi()` before adding/removing instances, and `sp->list` must be empty before `__cpuhp_remove_state_cpuslocked()`. [F106, F162]
- `struct smp_hotplug_thread` passed to `smpboot_register_percpu_thread()` must have non-NULL `store`, `thread_should_run`, `thread_fn`, and `thread_comm` (with at most one format specifier matching `unsigned int cpu`, e.g. `"%u"`). [F110, F163]
- In `rust/kernel/cpu.rs`, `CpuId::from_i32_unchecked(id)` and `from_u32_unchecked(id)` require `0 <= id < nr_cpu_ids()` (else use `from_i32()` / `from_u32()`), and `CpuId::current()` uses `raw_smp_processor_id()` without disabling preemption. [F54, F157]

## Error Handling
- On bringup failure in `cpuhp_up_callbacks()` or `cpuhp_bringup_mask()`, rollback via `cpuhp_invoke_callback_range(false, ...)` must be gated by `can_rollback_cpu(st)` so `!CONFIG_HOTPLUG_CPU` does not take down a CPU past `CPUHP_BRINGUP_CPU`. [F6]
- On teardown failure in `cpuhp_down_callbacks()`, `cpuhp_reset_state()` increments `st->state` back to the failed step, so rollback in `cpuhp_down_callbacks()` and AP re-kick in `_cpu_down()` must only run if `st->state < prev_state` (and `st->state == CPUHP_TEARDOWN_CPU` for AP re-kick). [F10]
- `cpuhp_kick_ap()` and `cpuhp_invoke_ap_callback()` must save `st->result` into a local variable before calling `__cpuhp_kick_ap(st)` for rollback, which resets `st->result = 0`. [F41]
- In `__cpuhp_setup_state_cpuslocked()`, if startup fails on a CPU, `cpuhp_rollback_install()` must run teardown on prior CPUs (`cpu < failedcpu`, `st->state >= state`) before `cpuhp_store_callbacks(state, NULL, ...)` clears the step. [F14]
- Under `CONFIG_GENERIC_SMP_IDLE_THREAD`, `idle_thread_get()` returns `ERR_PTR(-ENOMEM)` when `idle_threads` is `NULL`, so `idle_init()` and `_cpu_up()` must check `IS_ERR()` on `fork_idle()` and `idle_thread_get()`. In `bringup_wait_for_ap_online()`, if `!cpu_online(cpu)` after waiting, warn with `WARN_ON_ONCE()` and return `-ECANCELED` instead of `BUG_ON()`. [F47, F167]

## External Contracts
- `cpuhp_get_step(state)` has no bounds check, so `target_store()` and `fail_store()` must reject states outside `[CPUHP_OFFLINE, CPUHP_ONLINE]` first. `target_store()` must also reject non-endpoints when `!CONFIG_CPU_HOTPLUG_STATE_CONTROL` or steps with `!sp->name` or `sp->cant_stop`, and only call `cpu_down()` when `st->state > target` strictly holds. [F74, F88, F165]
- When `cpu_smt_control == CPU_SMT_FORCE_DISABLED`, `__store_smt_control()` must reject all writes with `-EPERM` and `cpu_smt_possible()` must return `false`. Numeric thread counts in `__store_smt_control()` must pass `cpu_smt_num_threads_valid()`. [F82, F166]

## Known Pitfalls
- `cpuhp_bringup_mask()` decrements unsigned `ncpus` before testing (`if (!--ncpus) break;`), so `bringup_nonboot_cpus()` and `cpuhp_bringup_cpus_parallel()` must verify `ncpus > 0` before calling it. In `freeze_secondary_cpus()`, loop variable `cpu` must be signed `int` for `cpu >= 0` termination. [F78, F104]
- `global_mitigations` uses `ARRAY_SIZE()` and `strncmp()` so it must have no `NULL` sentinel and list `"auto,nosmt"` before `"auto"`, whereas `vector_mitigations` uses `match_token()` and must end with `{ NR_VECTOR_PARAMS, NULL }`. `mitigations_parse_cmdline()` must log `pr_crit()` on unknown tokens or bad separators. [F80, F84]
