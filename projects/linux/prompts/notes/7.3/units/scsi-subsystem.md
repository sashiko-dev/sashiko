# SCSI SUBSYSTEM

This unit comprises the SCSI midlayer host lifecycle management (`drivers/scsi/hosts.c`) alongside four SCSI host adapter drivers: the ATTO ExpressSAS R6xx SAS/SATA RAID driver (`esas2r`), the NCR53C9x/FAS/ESP core driver (`esp_scsi`), the Future Domain TMC-16x0/TMC-3260 ISA/PCI driver (`fdomain`), and the Amiga Zorro GVP Series II WD33C93 driver (`gvp11`).

## Architecture & Data Flow
- In `scsi_remove_host()`, `scsi_host_set_state()` calls for `SHOST_CANCEL` and `SHOST_DEL` must fall back to `SHOST_CANCEL_RECOVERY` and `SHOST_DEL_RECOVERY` on failure, because direct transitions from `SHOST_RECOVERY` to `SHOST_CANCEL` and from `SHOST_CANCEL_RECOVERY` to `SHOST_DEL` are rejected. [F101]
- `class_to_shost()` (`container_of` on `shost_dev`) must only be called on `shost_class` devices (`scsi_host_cls_release()`, `scsi_host_lookup()`, `esas2r_adapter_from_kobj()`), whereas `scsi_bus_type` devices (`shost_gendev`, as in `scsi_host_dev_release()`) must use `dev_to_shost()`. Furthermore, `scsi_host_lookup()` and `__scsi_host_match()` must pass and dereference `&hostnum` as `unsigned int` (matching `Scsi_Host::host_no`), not `unsigned short`. [F115, F133]
- Any write to `ESP_CFG3`, `ESP_SOFF`, or `ESP_STP` in `esp_scsi.c` must update `esp->prev_cfg3`, `esp->prev_soff`, or `esp->prev_stp` in lockstep, because `esp_write_tgt_config3()` and `esp_write_tgt_sync()` elide writes when the target's value matches `prev_*`, and `esp_data_bytes_sent()` reads `prev_cfg3` and `prev_soff` to compute transfer counts. [F64]
- In `esp_data_bytes_sent()`, the transferred byte count subtracts both the hardware transfer counter (`ecount`) and `esp->send_cmd_residual` from `esp->data_dma_len`, so any PIO `send_dma_cmd` implementation such as `esp_send_pio_cmd()` must store its untransferred byte count in `esp->send_cmd_residual`. [F65]
- When `esp_advance_dma()` advances `p->cur_sg` to `sg_next(p->cur_sg)`, it must save the previous scatterlist pointer in `p->prv_sg` (and `esp_save_pointers()` / `esp_restore_pointers()` must preserve `saved_prv_sg`) so `IGNORE_WIDE_RESIDUE` handling in `esp_msgin_process()` can rewind `spriv->cur_sg` to `spriv->prv_sg` when `spriv->cur_residue` equals `sg_dma_len(spriv->cur_sg)`. [F66]
- When selection is interrupted by reselection (`esp->ireg == (ESP_INTR_RSEL | ESP_INTR_FDONE)`) in `esp_finish_select()`, the driver must unmap DMA (or sense DMA for `ESP_CMD_FLAG_AUTOSENSE`), free the LUN tag, clear `ESP_TGT_NEGO_SYNC | ESP_TGT_NEGO_WIDE` and `cmd_bytes_ptr`/`cmd_bytes_left`, move `ent` back to `esp->queued_cmds`, and set `esp->active_cmd = NULL`. Because `ESP_CMD_FLAG_AUTOSENSE` commands requeued on reselection keep their LUN tag and data DMA mapping, `find_and_prep_issuable_command()` and `esp_maybe_execute_command()` must check `ESP_CMD_FLAG_AUTOSENSE` and dispatch to `esp_autosense()` before `esp_alloc_lun_tag()` or `esp_map_dma()`. [F67, F106]
- In `find_and_prep_issuable_command()`, when `spi_populate_tag_msg(&ent->tag[0], cmd)` returns `0`, `ent->tag[0]` and `ent->tag[1]` must be zeroed before copying to `ent->orig_tag`, because `esp_alloc_lun_tag()` and `esp_free_lun_tag()` use `ent->orig_tag[0]` to distinguish `lp->non_tagged_cmd` from `lp->tagged_cmds`. [F50]
- In `esp_msgin_wdtr()`, after applying the wide transfer width to `tp->esp_config3` and `ESP_CFG3`, `spi_period(tp->starget)` and `spi_offset(tp->starget)` must be reset to `0` before calling `esp_need_to_nego_sync(tp)` so SDTR negotiation is not skipped. In `esp_reset_cleanup()`, all `esp->active_cmds` must be released via `esp_reset_cleanup_one()` (decrementing `lp->num_tagged`) before invoking `esp_clear_hold()`, and each target's `esp_period`, `esp_offset`, and wide/fast `esp_config3` bits must be cleared with `ESP_TGT_CHECK_NEGO` set. [F68, F69]
- In `fdomain_work()`, `fdomain_read_data()` and `fdomain_write_data()` must run before `fdomain_finish_cmd(fd)` even on the pass where `COMMAND_COMPLETE` sets `done`, so residual FIFO data is drained first. In `fdomain_write_data()`, `FIFO_Size` must be `0x800` for `tmc18c30` and `0x2000` for older chips, and `len = FIFO_Size - inw(fd->base + REG_FIFO_COUNT)` must be clamped to `scsi_bufflen(cmd) - offset` before mapping SG. [F98, F110]
- `clear_vda_request()` must save and restore `rq->vrq->scsi.handle` across `memset(rq->vrq, 0, sizeof(*rq->vrq))` and separately zero `rq->data_buf` for `ESAS2R_DATA_BUF_LEN` bytes, because `rq->vrq->scsi.handle` holds the `a->req_table` index and `rq->data_buf` lies after `union atto_vda_req`. [F125]
- Target database mutation helpers (`esas2r_targ_db_add_raid()`, `esas2r_targ_db_add_pthru()`, `esas2r_targ_db_remove()`) must update only `t->target_state` and leave `t->buffered_target_state` unchanged so `esas2r_targ_db_report_changes()` detects state transitions once `AF_DISC_PENDING` clears and invokes `esas2r_target_state_changed()`. [F74]

## Synchronization
- In `scsi_add_host_with_dma()`, `scsi_mq_setup_tags()`, `kref_init(&shost->tagset_refcnt)`, and `init_completion(&shost->tagset_freed)` must complete before `device_add(&shost->shost_gendev)` and `scsi_host_set_state(shost, SHOST_RUNNING)` publish the host. [F23]
- In `scsi_remove_host()`, `shost->scan_mutex` is acquired outside `shost->host_lock`; `shost->host_lock` must be released before calling `scsi_autopm_get_host()`, `flush_workqueue(shost->tmf_work_q)`, or `scsi_forget_host()`; and `shost->scan_mutex` must be released before waiting on `shost->tagset_freed`. [F26]
- `scsi_host_complete_all_commands()` and `scsi_host_busy_iter()` iterate `shost->tag_set` via `blk_mq_tagset_busy_iter()` without internal locking; callers of `scsi_host_complete_all_commands()` must stop concurrent I/O submission and completion first, and callers of `scsi_host_busy_iter()` must synchronize against concurrent completions. [F174]
- In `esas2r`, `a->queue_lock` must be held in `esas2r_eh_abort()` and `esas2r_check_active_queue()` while searching `a->defer_list` and `a->active_list`, unlinking a deferred request, or formatting an abort request from an active `rq`, and released before calling `esas2r_start_request()` or sleeping. `esas2r_complete_request()` and `esas2r_comp_list_drain()` must never be called under `a->queue_lock`; callers must move requests to a local `comp_list` and drain after unlocking. [F38, F164]
- In `esas2r`, `a->fw_event_lock` protects `a->fw_event_list`, `a->fw_events_off`, and queueing work onto `a->fw_event_q`. In `esas2r_targ_db_remove_all()` and `esas2r_targ_db_report_changes()`, `a->mem_lock` (`spin_lock_irqsave`) protects `t->target_state` and `t->buffered_target_state`, and must be released before calling `esas2r_target_state_changed()` (which takes `a->fw_event_lock`). [F40, F166]

## Object Lifetimes
- In `scsi_add_host_with_dma()`, `pm_runtime_get_noresume(&shost->shost_gendev)` must be taken before `pm_runtime_enable()` and balanced by `scsi_autopm_put_host(shost)` on success or `pm_runtime_put_noidle(&shost->shost_gendev)` after `pm_runtime_disable()` on failure. In `scsi_remove_host()`, `kref_put(&shost->tagset_refcnt, scsi_mq_free_tags)` and `wait_for_completion(&shost->tagset_freed)` must finish before transitioning to `SHOST_DEL` and unregistering `shost_dev` and `shost_gendev`. [F141, F142]
- `scsi_proc_host_rm(shost)` and `scsi_proc_hostdir_rm(shost->hostt)` must be called synchronously in `scsi_remove_host()`, whereas `scsi_host_dev_release()` must only call `scsi_proc_hostdir_rm(shost->hostt)` when `shost->shost_state == SHOST_CREATED` and must call `rcu_barrier()` before destroying workqueues, stopping `shost->ehandler`, or freeing `shost` so all `call_rcu(&scmd->rcu, ...)` callbacks finish first. [F5, F25]
- In `esp_eh_abort_handler()` and `esp_eh_bus_reset_handler()`, `ent->eh_done` and `esp->eh_reset` point to stack-allocated `struct completion` objects and must be cleared to `NULL` under `esp->host->host_lock` both on completion and when `wait_for_completion_timeout()` times out. Similarly, when `esas2r_eh_abort()` or `esas2r_dev_targ_reset()` points `rq->task_management_status_ptr` at stack variable `task_management_status`, it must not return while `task_management_status == RS_PENDING`. [F9, F135]
- `esp_unmap_sense()` must clear `ent->sense_ptr = NULL` after unmapping `ent->sense_dma` because `esp_autosense()` checks `if (!ent->sense_ptr)` to decide whether to call `esp_map_sense(esp, ent)`. [F8]
- `fdomain_destroy()` must call `cancel_work_sync(&fd->work)` before `scsi_remove_host(sh)`, `free_irq(sh->irq, fd)`, and `scsi_host_put(sh)`, and callers must call `fdomain_destroy(sh)` before releasing I/O regions and disabling the device. In `fdomain_finish_cmd()`, `fd->cur_cmd` must be set to `NULL` under `sh->host_lock` right after `scsi_done(fd->cur_cmd)` so `fdomain_irq()` ignores post-command interrupts (`if (!fd->cur_cmd) return IRQ_NONE;`). [F11, F12]
- In `gvp11.c`, `dma_setup()` rounds `wh->dma_bounce_len` up to a 512-byte multiple for allocation, but `memcpy()` in `dma_setup()` and `dma_stop()` must copy only `scsi_pointer->this_residual` bytes; `dma_stop()` must call `dma_unmap_single()` only when `wh->dma_buffer_pool == BUF_SCSI_ALLOCED`, free `wh->dma_bounce_buffer` with `kfree()` for `BUF_SCSI_ALLOCED` or `amiga_chip_free()` for `BUF_CHIP_ALLOCED`, and clear `wh->dma_bounce_buffer = NULL`. [F14, F138]
- `esas2r_free_request(a, rq)` must call `esas2r_rq_destroy_request(rq, a)` to splice `rq->sg_table_head` back to `a->free_sg_list_head` under `a->sg_list_lock` and clear `a->req_table[LOWORD(rq->vrq->scsi.handle)] = NULL` before returning `rq` to `a->avail_request`. Because `esas2r_initmem_alloc()` aligns `mem_desc->virt_addr` and `phys_addr` upward, `esas2r_initmem_free()` must pass `mem_desc->esas2r_data`, `mem_desc->esas2r_param`, and `mem_desc->phys_addr - ((u8 *)mem_desc->virt_addr - (u8 *)mem_desc->esas2r_data)` to `dma_free_coherent()`, and set `mem_desc->virt_addr = NULL`. [F15, F17]
- In `handle_buffered_ioctl()`, `buffered_ioctl_semaphore` must be held across checking/reallocating the global DMA buffer, waiting on `a->buffered_ioctl_waiter`, and copying results to `bi->ioctl`, and reallocation must update `esas2r_buffered_ioctl`, `esas2r_buffered_ioctl_addr`, `esas2r_buffered_ioctl_size`, and `esas2r_buffered_ioctl_pcid` in lockstep so `esas2r_kill_adapter()` frees the buffer and clears `esas2r_buffered_ioctl = NULL` when the owning PCI device is removed. [F42, F75]

## API Contracts
- In `esp_driver_ops.send_dma_cmd` and `esp_send_pio_cmd()`, `write` is `1` for transfers from the SCSI bus into host memory (`ESP_EVENT_DATA_IN` or tag read-in) and `0` from host memory to the SCSI bus. An ESP front-end using `esp_send_pio_cmd()` must set `esp->fifo_reg` and `ESP_FLAG_NO_DMA_MAP`; when `ESP_FLAG_NO_DMA_MAP` is set, `esp_map_dma()` and `esp_map_sense()` store kernel virtual addresses, so `esp_unmap_dma()` and `esp_unmap_sense()` must check `!(esp->flags & ESP_FLAG_NO_DMA_MAP)` before unmapping. [F51, F52, F176]
- In `esp_process_event()`, returning `0` causes `__esp_interrupt()`'s `while (!intr_done)` loop to immediately re-invoke `esp_process_event(esp)`, so every path returning `0` must first transition `esp->event` (such as to `ESP_EVENT_RESET` via `esp_schedule_reset()` or `ESP_EVENT_MSGIN`) toward a state that returns `1`. [F103]
- Scatterlist PIO transfers in `esp_data_bytes_sent()` and `fdomain_read_data()` / `fdomain_write_data()` execute under `host_lock` with interrupts disabled and must use `scsi_kmap_atomic_sg()` and `scsi_kunmap_atomic_sg()`, adding the updated `offset` out-parameter to the returned page base pointer before accessing data and passing the unadjusted base pointer to `scsi_kunmap_atomic_sg()`. [F129, F162]
- When `esas2r_send_task_mgmt(a, rq, ...)` returns `true` (because `AF_FLASHING` is set), the caller `esas2r_dev_targ_reset()` retains ownership of `rq` and must call `esas2r_free_request(a, rq)`; when it returns `false`, `complete_task_management_request()` frees `rq` on completion. [F18]

## Error Handling
- In `scsi_host_alloc()`, if `kthread_run()` fails to spawn `shost->ehandler`, `shost->ehandler` must be reset from `ERR_PTR()` to `NULL` before jumping to `fail` (`put_device(&shost->shost_gendev)`), because `scsi_host_dev_release()` only tests `if (shost->ehandler)` before calling `kthread_stop()`. [F44]
- In `scsi_add_host_with_dma()`, once `device_add(&shost->shost_gendev)` succeeds, `shost_state` is set to `SHOST_RUNNING`, and `get_device(&shost->shost_gendev)` is taken for `shost_dev`, any subsequent error path must call `put_device(&shost->shost_dev)` and `device_del(&shost->shost_gendev)` before disabling runtime PM and freeing tags. [F140]
- `esp_data_bytes_sent()` returns a signed `int` (`-1` when an `ESP100` sync data phase leaves spurious bytes in the FIFO), so `esp_process_event()` must check `bytes_sent < 0` before passing `bytes_sent` to `esp_advance_dma()`. `esp_check_spur_intr()` returns a tri-state `int` (`1` for `ESP_INTR_SR`, `0` for normal, `-1` for spurious IRQ/DMA error), so `__esp_interrupt()` must check `finish_reset < 0` and return before testing `if (finish_reset)` to run `esp_reset_cleanup()`. [F48, F49]
- In `esas2r_queuecommand()`, if `scsi_dma_map(cmd) < 0`, `esas2r_free_request(a, rq)` must be called before returning `SCSI_MLQUEUE_HOST_BUSY`; if `esas2r_build_sg_list(a, rq, &sgc)` fails after `scsi_dma_map(cmd)` succeeded, both `scsi_dma_unmap(cmd)` and `esas2r_free_request(a, rq)` must be called. [F19]

## Known Pitfalls
- In `__esp_interrupt()`, `ESP_STATUS` (`esp->sreg`) and `ESP_SSTEP` (`esp->seqreg`) must be read before `ESP_INTRPT` (`esp->ireg`), because reading `ESP_INTRPT` clears `STATUS` and `SSTEP`. On `FASHME`, `ESP_FDATA` FIFO accesses are 16-bit paired: `hme_read_fifo()` must write a dummy `0` byte to `ESP_FDATA` before reading a trailing odd byte (`ESP_STAT2_F1BYTE`), and `ESP_EVENT_MSGOUT` must follow each message byte written to `ESP_FDATA` with a `0` byte. [F70, F149]
- In `esp_process_event()`, `write = 0` must be reset after the `again:` label because `ESP_EVENT_DATA_IN` sets `write = 1` and other events `goto again`; in `ESP_EVENT_MSGIN`, after `esp_msgin_process(esp)`, `if (esp->event == ESP_EVENT_RESET) return 0;` must be checked before `esp->event != ESP_EVENT_FREE_BUS`, or `ESP_EVENT_CHECK_PHASE` will overwrite a scheduled reset. [F104, F105]
- In `struct esp_cmd_priv`, `cur_residue` and `tot_residue` must remain signed `int` fields so `esp_advance_dma()` can subtract `len` and test `< 0` for overflow. In `esp_maybe_execute_command()`, `esp->msg_out_len` must not exceed `ESP_MAX_MSG_SZ - 2` before prepending the 2-byte `ent->tag`, and the in-place shift must iterate backward (`for (i = esp->msg_out_len - 1; i >= 0; i--)`) using a signed `int i`. [F94, F95, F130]
- In `esas2r_process_vda_ioctl()` for `VDA_FUNC_MGT` commands with a separate payload SGL (`payld_sge`), `cmdcurr_offset` must be computed before building `payld_sge`, and `payld_sge` must be built before `mgt.sge`. Because `esas2r_targ_db_add_pthru()` reuses an existing `a->targetdb` entry and updates its `t->virt_targ_id`, a target's `virt_targ_id` need not match its `a->targetdb` index and must be looked up via `esas2r_targ_db_find_by_virt_id()`. [F72, F86]
