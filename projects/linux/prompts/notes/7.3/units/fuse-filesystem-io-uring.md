# FUSE FILESYSTEM [IO-URING]

The FUSE io_uring backend exchanges FUSE requests and responses between the kernel and the userspace daemon using 128-byte `IORING_OP_URING_CMD` passthrough commands rather than `/dev/fuse` reads and writes. It manages per-CPU ring queues (`struct fuse_ring_queue`), ring entries (`struct fuse_ring_ent`), per-entry or pool-based userspace payload buffers (`struct fuse_bufpool`), zero-copy folio registration with io_uring, synchronous and background request queuing, and asynchronous connection teardown.

## Architecture & Data Flow

- Every `struct fuse_ring_ent` on `queue->ent_w_req_queue` or `queue->ent_in_userspace` must have a non-NULL `ent->fuse_req` because `ent_list_request_expired()` dereferences `ent->fuse_req->create_time` without a NULL check when scanning the head of those lists. Broken by: leaving an entry on `ent_w_req_queue` or moving a cancelled entry onto `ent_in_userspace` when `ent->fuse_req` is NULL. [F38]
- In `fuse_uring_queue_fuse_req()` and `fuse_uring_queue_bq_req()`, `set_bit(FR_URING, &req->flags)` and `req->ring_queue = queue` (`struct fuse_ring_queue *`) must be set under `queue->lock`, and `FR_PENDING` must be cleared under `queue->lock` when `req` is dequeued in `fuse_uring_add_req_to_ring_ent()` or `fuse_uring_abort_end_queue_requests()`; the untyped `void *` field `req->ring_entry` must only point to a `struct fuse_ring_ent`. [F40, F79]
- `queue->payload_mode` transitions monotonically under `queue->lock` from `FUSE_PAYLOAD_UNSET` to `FUSE_PAYLOAD_BUFPOOL` (`fuse_uring_add_bufpool()`) or `FUSE_PAYLOAD_PER_ENT` (`fuse_uring_create_ring_ent()`); `queue->bufpool` is non-NULL iff `bufpool_enabled(queue)`, `queue->bufpool->registered_index` is valid only when `bufpool_registered(queue)`, and when `bufpool_enabled(queue)` is true, `ent->payload.iov_base` is `NULL` when no pool buffer is held, so `fuse_uring_import_payload()`, offset calculation, and `fuse_uring_recycle_buffer()` must null-check it. [F30, F32, F43]
- In `fuse_uring_add_bufpool()`, `struct fuse_bufpool` is allocated with `struct_size(pool, free_map, BITS_TO_LONGS(nr_bufs))` where `nr_bufs = pool_len / buf_size` uses truncating division (requiring non-zero `nr_bufs` and `ring->max_payload_sz >= FUSE_MIN_READ_BUFFER`); `pool->nr_bufs`, `bitmap_set()`, and `find_first_bit()` in `fuse_uring_select_buffer()` use the bit count `nr_bufs` in `[0, nr_bufs)` (1 free, 0 allocated), and `id < pool->nr_bufs` with a 32-bit `pool_len` ensures `id * pool->buf_size` fits in `uint32_t` `ent_in_out.offset`. [F55, F70, F71, F74]
- `fuse_uring_args_to_ring()` extracts `args->in_args[0]` into `FUSE_URING_HEADER_OP` (unconditionally advancing `in_args`/`num_args` when `num_args > 0`, even if `in_args[0].size == 0`), so `fuse_uring_req_has_copyable_payload()` tests `in_numargs > 1` (`> 2` when `in_pages` is zero-copied) vs `out_numargs > 0` (`> 1` when `out_pages` is zero-copied); when `ent->zero_copied` is true, `setup_fuse_copy_state()` sets `cs->skip_folio_copy = true` while still running `fuse_copy_args()`, and `args->in_args[args->in_numargs - 1].size` is added to `ent_in_out.payload_sz` if `args->in_pages`. [F37, F63, F100]
- Before `fuse_uring_dispatch_ent()` schedules `fuse_uring_send_in_task()` or `fuse_uring_prepare_cancel()` marks `cmd` cancelable, `uring_cmd_set_ring_ent(cmd, ent)` must store `ent` in `cmd`'s `struct fuse_uring_pdu` so `uring_cmd_to_ring_ent(cmd)` can recover it in `fuse_uring_send_in_task()` and `fuse_uring_cancel()`. [F49]
- `ring->queues` is a 0-based array of `ring->nr_queues` (`num_possible_cpus()`) nullable pointers lazily populated per `qid`; every path indexing `ring->queues[qid]` must bounds-check `qid < ring->nr_queues` and null-check the loaded `struct fuse_ring_queue` pointer before dereferencing it. [F52]
- Both loops in `fuse_uring_stop_list_entries()` must use `list_for_each_entry_safe()` because the first loop moves matching entries onto `to_teardown` via `list_move()`, and the second loop calls `fuse_uring_entry_teardown()`, which moves each entry from `to_teardown` onto `queue->ent_released`. [F68]

## Synchronization

- `queue->lock` must be released before calling `fuse_request_end()`, `fuse_dev_end_requests()`, `io_uring_cmd_done()`, `fuse_uring_prepare_cancel()`, `fuse_uring_dispatch_ent()`, or `zero_copy_unregister()`; whenever both `queue->lock` and `fch->bg_lock` are acquired, `queue->lock` must be acquired before `fch->bg_lock` (as required by `fuse_uring_flush_bg()`). [F20, F81]
- Only after `fuse_uring_add_req_to_ring_ent()` unlinks `req->list` from `queue->fuse_req_queue` and `fuse_uring_prepare_send()` copies to userspace may `fuse_uring_send()` under `queue->lock` set `FRRS_USERSPACE` on `queue->ent_in_userspace`, clear `ent->cmd`, set `req->ring_entry = ent`, and add `req` to `queue->fpq.processing` (`fuse_uring_add_to_pq()`); in `fuse_uring_commit_fetch()`, before dropping `queue->lock`, `req` must be unlinked from `fpq.processing`, `req->ring_entry` cleared, `fuse_ring_ent_set_commit()` (`FRRS_COMMIT`) called, and `ent->cmd = cmd` set. [F16, F24, F41]
- `queue->stopped` must be set in `fuse_uring_abort_end_requests()` and checked in `fuse_uring_commit_fetch()`, `fuse_uring_queue_fuse_req()`, and `fuse_uring_queue_bq_req()` under `queue->lock`; after setting `queue->stopped = true`, `fuse_uring_abort_end_requests()` must flush `queue->fuse_req_bg_queue` via `fuse_uring_flush_bg(queue)` under `queue->lock` and `fch->bg_lock`, and `fuse_uring_abort_end_queue_requests()` must splice `queue->fuse_req_queue`, clear `FR_PENDING`, and drop `queue->lock` before `fuse_dev_end_requests()`. [F11, F17]
- All fields of `struct fuse_ring` must be initialized before `smp_store_release(&fch->ring, ring)` in `fuse_uring_create()`, `struct fuse_ring_queue` and `queue->fpq.processing` before `smp_store_release(&ring->queues[qid], queue)` under `fch->lock` in `fuse_uring_create_queue()`, and `WRITE_ONCE(fiq->ops, &fuse_io_uring_ops)` before `smp_store_release(&ring->ready, true)` in `fuse_uring_do_register()`, paired with `smp_load_acquire()` or `READ_ONCE()` in lockless readers. [F12, F13, F14]
- During ring entry registration, `atomic_inc(&ring->queue_refs)` in `fuse_uring_create_ring_ent()` must precede checking `fch->connected` under `fch->lock` in `fuse_uring_do_register()`, and if `!fch->connected`, `fuse_uring_do_register()` must decrement `ring->queue_refs`, wake `ring->stop_waitq` on zero, and free `ent`. [F15]
- Allocation and recycling of `struct fuse_bufpool` slots (`fuse_uring_select_buffer()` and `fuse_uring_recycle_buffer()`) and transitions of `queue->payload_mode` and `queue->bufpool` (`fuse_uring_create_ring_ent()` and `fuse_uring_add_bufpool()`) must be serialized under `queue->lock`. [F23]
- `fuse_uring_queue_fuse_req()` and `fuse_uring_queue_bq_req()` must defer `fuse_uring_prepare_send()` via `fuse_uring_dispatch_ent()` (`io_uring_cmd_complete_in_task()`) to `fuse_uring_send_in_task()` so user-buffer copies run in the ring task's context. [F85]

## Object Lifetimes

- Every `struct fuse_ring_ent` allocated in `fuse_uring_create_ring_ent()` increments `ring->queue_refs`, which must be balanced by decrementing `ring->queue_refs` and waking `ring->stop_waitq` on zero across all exit and cancellation paths; `fuse_uring_entry_teardown()` must not `kfree(ent)` immediately, but move `ent->list` to `queue->ent_released` (`ent->state = FRRS_RELEASED`) under `queue->lock` for `fuse_uring_destruct()`, because concurrent `IO_URING_F_CANCEL` callbacks in `fuse_uring_cancel()` dereference `ent` via the command PDU. [F1, F2]
- Before scheduling `ring->async_teardown_work` in `fuse_uring_stop_queues()`, a connection reference must be acquired with `fuse_conn_get(ring->chan->conn)` and held across all reschedules of `fuse_uring_async_stop_queues()` until `ring->queue_refs` reaches zero, where `fuse_conn_put(ring->chan->conn)` is called. [F3]
- `fuse_uring_req_end()` must be called without `queue->lock` held; under `queue->lock` it must clear `ent->fuse_req`, unlink `req->list`, and if `FR_BACKGROUND` is set, decrement `queue->active_background` and call `fuse_request_bg_finish()` before `fuse_uring_flush_bg(queue)` under `fch->bg_lock`, then drop `queue->lock` before calling `fuse_request_end(req)`. [F7, F39]
- Every `fuse_copy_args()` or `fuse_copy_out_args()` call on a `struct fuse_copy_state` in `fuse_uring_args_to_ring()` and `fuse_uring_copy_from_ring()` must be followed by `fuse_copy_finish(&cs)` on both success and error paths to unmap and release any page pinned in `cs.pg`. [F4]
- `fuse_uring_set_up_zero_copy()` pins `ap->folios` with `folio_get()` before `io_buffer_register_bvec()`; on failure it must call `fuse_zero_copy_release(zc_bvs)` directly and leave `ent->zero_copied` false, whereas on success ownership transfers to io_uring until `zero_copy_unregister()` runs. [F5]
- Under `queue->lock`, `fuse_uring_recycle_buffer()` must set `ent->buf_id` in `pool->free_map` and zero `ent->payload` (`iov_base` and `iov_len`) and `ent->buf_id`, and `fuse_uring_ent_assign_req()` must call `fuse_uring_recycle_buffer(ent)` whenever no next `fuse_req` is assigned so idle entries in `ent_avail_queue` never hold a bufpool buffer. [F8]

## API Contracts

- `fuse_uring_destruct()` is invoked from the `fuse_conn` RCU callback `delayed_release()` (`call_rcu(&fc->rcu, delayed_release)`) and executes in RCU softirq context where sleeping calls, mutex acquisitions, and synchronous work cancellations (`cancel_delayed_work_sync()`, `wait_event()`) are forbidden. [F91]
- Because `struct fuse_req` is allocated from `fuse_req_cachep` without a slab usercopy whitelist, headers embedded in `struct fuse_req` (`req->in.h` and `req->out.h`) must be bounced through an on-stack buffer before calling `copy_header_to_ring()` or `copy_header_from_ring()`. [F92]
- In `fuse_uring_cmd()`, the `IO_URING_F_CANCEL` check on `issue_flags` must precede `IO_URING_F_SQE128`, `fuse_get_dev()`, and `fch` state checks so cancellation always reaches `fuse_uring_cancel()`; `fuse_uring_cmd_index_ok()` and all reads of `cmd->sqe` (`io_uring_sqe128_cmd()`, `fuse_uring_get_iovec_from_sqe()`) must only run synchronously in `fuse_uring_cmd()` using `READ_ONCE()` on SQE fields. [F25, F60]
- `fuse_uring_queue_fuse_req()` consumes ownership of `req` on all paths (clearing `FR_PENDING` and calling `fuse_request_end(req)` after dropping `queue->lock` if the queue is missing or stopped), whereas `fuse_uring_queue_bq_req()` only takes ownership of `req` and increments `fch->num_background` when it returns `true`. [F10]
- In `fuse_uring_cmd()`, `FUSE_IO_URING_CMD_REGISTER` and `FUSE_IO_URING_CMD_COMMIT_AND_FETCH` must return `-EIOCBQUEUED` when their handlers return `0`, whereas `FUSE_IO_URING_CMD_ADD_QUEUE` and `FUSE_IO_URING_CMD_ADD_BUFPOOL` return `0` directly; calls to `io_uring_cmd_done()` and fixed-buffer helpers must pass `IO_URING_CMD_TASK_WORK_ISSUE_FLAGS` from `fuse_uring_send_in_task()`, `IO_URING_F_UNLOCKED` from `fuse_uring_entry_teardown()`, and the caller's `issue_flags` from `fuse_uring_cmd()` handlers. [F29, F96]
- In `fuse_uring_set_up_zero_copy()`, `req->args` may only be downcast to `struct fuse_args_pages` via `container_of()` after `can_zero_copy_req()` verifies `args->in_pages || args->out_pages`, and the `io_buffer_register_bvec()` direction must map `out_pages` (read) to `IO_BUF_DEST` and `in_pages` (write) to `IO_BUF_SOURCE`. [F36]
- Any `fuse_uring_*` function declared in `fs/fuse/dev_uring_i.h` or `fs/fuse/dev.h` that is called outside `#ifdef CONFIG_FUSE_IO_URING` guards must have a matching `#else` stub in that header. [F47]

## Error Handling

- When `fuse_ring_ent_set_commit(ent)` fails in `fuse_uring_commit_fetch()`, `ent->cmd` is still `NULL`, so `fuse_uring_commit_fetch()` must explicitly call `fuse_uring_recycle_buffer(ent)` under `queue->lock` and `zero_copy_unregister(cmd, ent, issue_flags)` with `cmd` before `fuse_uring_req_end()`. [F6]
- When `fuse_uring_copy_to_ring()` fails in `fuse_uring_prepare_send()`, it must unlink `ent->list` from `queue->ent_w_req_queue` and set `ent->state = FRRS_INVALID` under `queue->lock` before calling `fuse_uring_req_end()`, and callers must return `ent` to `ent_avail_queue` via `fuse_uring_get_next_fuse_req()`; in `fuse_uring_send_in_task()`, if the fallback `fuse_uring_get_next_fuse_req()` returns `true`, `err` must be reset to `0` before `fuse_uring_send()`, and if `false`, it must return without calling `fuse_uring_send()`. [F9, F66]
- In `fuse_uring_req_end()`, any non-zero `error` argument is assigned directly to `req->out.h.error`, so callers such as `fuse_uring_commit()` must convert positive uncopied byte counts from `copy_from_user()` or `copy_to_user()` into negative errnos like `-EFAULT` before calling `fuse_uring_req_end()`. [F27]
- `fuse_uring_create_queue()` and `fuse_uring_create_ring_ent()` return `ERR_PTR` on failure (check with `IS_ERR()`), whereas `fuse_uring_create()` and `fuse_uring_task_to_queue()` return `NULL`. [F28]

## External Contracts

- In `fuse_uring_cmd()`, `smp_load_acquire(&fch->initialized)` must be checked and return `-EAGAIN` before checking `fch->io_uring`, and any command on an initialized channel with `!fch->io_uring` must be rejected with `-EOPNOTSUPP` regardless of `enable_uring`. [F61]
- In `fuse_uring_commit()`, the userspace `struct fuse_out_header` copied into `req->out.h` must be checked by `fuse_uring_out_header_has_err()` before `fuse_uring_copy_from_ring()` to reject `oh->unique == 0`, out-of-bounds error numbers (`oh->error <= -ERESTARTSYS || oh->error > 0`), and unique ID mismatches. [F59]
- `fuse_uring_create_ring_ent()` validates `iov[FUSE_URING_IOV_HEADERS].iov_len >= sizeof(struct fuse_uring_req_header)` once and stores only `iov_base` in `ent->headers`, so `copy_header_to_ring()` and `copy_header_from_ring()` must never pass a `header_size` larger than the target member (such as `FUSE_URING_OP_IN_OUT_SZ`); `iov[FUSE_URING_IOV_PAYLOAD]` must have `iov_base == NULL && iov_len == 0` when `bufpool_enabled(queue)` is true, and otherwise `iov_len >= ring->max_payload_sz` with `queue->zero_copy` disabled. [F53, F54]
- `fuse_uring_add_queue()` must reject `flags & ~FUSE_URING_ADD_QUEUE_FLAGS` and require `capable(CAP_SYS_ADMIN)` for `FUSE_URING_ZERO_COPY`; `fuse_uring_add_bufpool()` must reject non-zero `flags` or `bufpool.reserved` with `-EINVAL`; `fuse_uring_create_ring_ent()` requires `bufpool_enabled(queue)` when `queue->zero_copy` and `ent_zero_copy_buf_index == 0` when `!queue->zero_copy`; and `fuse_uring_args_to_ring()` must zero-initialize all fields of `struct fuse_uring_ent_in_out` before copying to userspace. [F58, F102, F103]

## Known Pitfalls

- In `fuse_uring_get_iovec_from_sqe()`, `nr_segs` passed to `import_iovec()` must equal `fast_segs` (`FUSE_URING_IOV_SEGS`) and match the caller's stack `iov[]` size because `&iov` passes the address of the decayed pointer parameter; when computing a sub-header user address from `ent->headers` (`struct fuse_uring_req_header __user *`), it must be cast to `void __user *` before adding the byte offset from `ring_header_type_offset()`. [F75, F76]
- In `fuse_uring_get_next_fuse_req()`, every retry after `fuse_uring_prepare_send()` fails makes forward progress only because `fuse_uring_add_req_to_ring_ent()` unlinks the failed request from `queue->fuse_req_queue` and `fuse_uring_prepare_send()` ends it via `fuse_uring_req_end()`; in `fuse_uring_queue_bq_req()`, after queuing `req` onto `queue->fuse_req_bg_queue` and calling `fuse_uring_flush_bg()`, `req` must be reassigned from `list_first_entry_or_null(&queue->fuse_req_queue, ...)` before dispatching. [F65, F67]
- Jiffies deadline checks in `ent_list_request_expired()` and `fuse_uring_async_stop_queues()` must use `time_is_before_jiffies()` and `time_after()` when comparing `jiffies` against `req->create_time + fch->timeout.req_timeout` or `ring->teardown_time + FUSE_URING_TEARDOWN_TIMEOUT`. [F73]
