# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64)

This unit implements the host-side kernel management, UAPI, architectural timer/debug/AT emulation, EL2 hypervisor world-switch engine (VHE, nVHE, and Protected KVM), and Stage-1/Stage-2 page-table management for KVM on arm64.

## Architecture & Data Flow

- Optional Stage-1/EL2 feature registers (`SYS_TCR2`, `SYS_PIR`, `SYS_PIRE0`, `SYS_POR`, `SYS_POR_EL0`, `SCTLR2_EL1`, and `_EL2` variants) and `HCRX_EL2` bits must be gated by per-VM helpers (`kvm_has_*()` / `ctxt_has_*()`), not just host CPU caps; `SYS_POR_EL0` must be switched in `__sysreg_{save,restore}_common_state()` on every world switch. [F137, F320, F347]
- In `enum vcpu_sysreg`, `kvm_sysreg_masks::mask` is indexed by `r - __SANITISED_REG_START__`, whereas `ctxt->vncr_array` is indexed by `r - __VNCR_START__`; registers after `MARKER(__VNCR_START__)` must use `VNCR(r)`, and `APIAKEYLO_EL1`..`APGAKEYHI_EL1` must stay contiguous; `IDREG_IDX(id)` only indexes `kvm_arch::id_regs` for `1 <= crm < 8` (`CRm == 0` and `SYS_CTR_EL0` must use `__vm_id_reg()`). [F77, F78, F81, F121]
- In `vcpu->arch.iflags`, `INCREMENT_PC` (`BIT(1)`) overlaps `EXCEPT_MASK` (`GENMASK(3, 1)`), making `kvm_incr_pc()` and `kvm_pend_exception()` mutually exclusive; `kvm_arch_vcpu_ioctl_run()` must commit either via `kvm_call_hyp(__kvm_adjust_pc, vcpu)` before `vcpu_put()`. [F69]
- Because `to_hw_pstate()` maps virtual `PSR_MODE_EL2t`/`EL2h` to `PSR_MODE_EL1t`/`EL1h` on entry, `__compute_hcr()` sets `VCPU_IN_HYP_CONTEXT` and `fixup_guest_exit()` must restore `PSR_MODE_EL2*` before exit handlers run; when `vcpu_has_nv(vcpu)` and `is_hyp_ctxt(vcpu)`, `__compute_hcr()` must only merge config RES1 bits (`~NV_HCR_GUEST_EXCLUDE`), never raw `__vcpu_sys_reg(vcpu, HCR_EL2)`. [F252, F253]
- `__activate_cptr_traps()` must dynamically compute and write `cptr_el2`/`cpacr_el1` and `fpexc32_el2` on every trap activation and after `kvm_hyp_handle_fpsimd()` or `kvm_hyp_handle_cpacr_el1()`; an `isb()` must follow `__deactivate_traps()` / `__deactivate_cptr_traps()` before accessing FP/SVE/FPMR/`FPEXC32_EL2` registers. [F251, F346]
- `__sysreg32_restore_state(vcpu)` must precede 64-bit sysreg restore, and in nVHE all VM sysregs must be restored before `__load_stage2()`; in `__vgic_v3_activate_traps()`, `!(cpu_if->vgic_hcr & ICH_HCR_EL2_En)` must precede `else if (!cpu_if->vgic_sre)`, and when `!cpu_if->vgic_sre`, write `0` to `ICC_SRE_EL1` with `isb()` before `ICH_VMCR_EL2` and `__vgic_v3_restore_state()`. [F289, F323, F326]
- For physical timers (`TIMER_PTIMER`, `TIMER_HPTIMER`) or when `has_broken_cntvoff()` is true, `timer_save_state()` must subtract `timer_get_offset(ctx)` from `CVAL` and zero hardware `cntpoff`/`cntvoff`, while `timer_restore_state()` adds `offset` to `CVAL`; `isb()` must separate `CVAL` and `CTL` writes and separate disabling `CTL` from zeroing offsets. [F61, F139, F140]
- Runtime loops over active vCPU timers must bound by `nr_timers(vcpu)` (`NR_KVM_EL0_TIMERS` when `!vcpu_has_nv(vcpu)`), not `NR_KVM_TIMERS`; in `kvm_timer_sync_nested()` when `!cpus_have_final_cap(ARM64_HAS_ECV)`, only `map.emul_vtimer` and `map.emul_ptimer` from `get_timer_map()` may be canceled and re-emulated, never overwriting hardware EL1 timers with VNCR state. [F60, F90]
- `push_hyp_memcache()`/`pop_hyp_memcache()` must keep `mc->nr_pages` synced with `mc->head`, and `pop_hyp_memcache()` must check `!mc->nr_pages` and mask `mc->head` with `PAGE_MASK` before `to_va()`; `host_stage2_force_pte_cb()` must force PTE mappings in `host_mmu.pgt` whenever `prot` is not `PKVM_HOST_MEM_PROT`/`PKVM_HOST_MMIO_PROT`, and `stage2_set_prot_attr()` must reject `KVM_PGTABLE_PROT_DEVICE | KVM_PGTABLE_PROT_NORMAL_NC` with `-EINVAL`. [F15, F76, F256, F292]
- In `pvm_sys_reg_descs[]`, entries must be in strict ascending `(Op0, Op1, CRn, CRm, Op2)` order with no duplicates for `find_reg()`, and `pvm_ftr_bits` arrays must end with `FEAT_END`; `kvm_handle_pvm_sys64()` must call `kvm_hyp_handle_sysreg()` before `kvm_handle_pvm_sysreg()`. [F273, F274, F288]

## Synchronization

- Host lock hierarchy: `kvm->lock` -> `vcpu->mutex` -> `kvm->arch.config_lock`. `config_lock` serializes `__kvm_vcpu_set_target()` and updates to `kvm->arch.mpidr_data` (which must use `rcu_assign_pointer()` and `synchronize_rcu()` in `kvm_destroy_mpidr_data()`, paired with `rcu_read_lock()`/`rcu_dereference()` and `mpidr == kvm_vcpu_get_mpidr_aff(vcpu)` in `kvm_mpidr_to_vcpu()`). [F21, F32, F86, F154]
- pKVM lock hierarchy: `vm_table_lock` -> `host_lock_component()` (`host_mmu.lock`) -> `hyp_lock_component()` (`pkvm_pgd_lock`) or `guest_lock_component(vm)` (`vm->lock`). `vm_table_lock` guards `vm_table`, `hyp_vm` refcounts, `loaded_hyp_vcpu`, `hyp_vm->vcpus[]`, and `kvm_init_pvm_id_regs()`; `host_mmu.lock` guards `__host_state` and `host_share_guest_count`; `pkvm_pgd_lock` guards `__hyp_state_comp`; `guest_lock_component(vm)` sets per-CPU `current_vm` for `vm->pgt` `mm_ops`. [F198, F214, F215, F217, F218]
- In `__pkvm_host_share_guest()` and `__pkvm_host_unshare_guest()`, `page->host_share_guest_count`, `set_host_state()`, and the guest Stage-2 PTE (`PKVM_PAGE_SHARED_BORROWED`) must be updated in lockstep under `host_mmu.lock` and `vm->lock`, resetting host state to `PKVM_PAGE_OWNED` only when `host_share_guest_count` reaches 0; for `PKVM_PAGE_SHARED_OWNED` in `__pkvm_host_share_guest()`, check `if (page->host_share_guest_count) continue;` and otherwise fall through to `-EPERM`. [F257, F291]
- In `kvm_arch_vcpu_ioctl_run()`: set `vcpu->mode = IN_GUEST_MODE` via `smp_store_mb()` only after `local_irq_disable()` and before `kvm_vcpu_exit_request()`; keep `kvm_arm_vcpu_enter_exit` `noinstr`; on exit before `local_irq_enable()`, run `kvm_pmu_sync_hwstate()`, then `kvm_vgic_sync_hwstate()`, then `kvm_timer_sync_user()` and `kvm_timer_sync_nested()`. [F19, F146, F156]
- `vcpu->arch.{cflags,iflags,sflags}` use non-atomic RMW (`__vcpu_set_flag`/`__vcpu_clear_flag`) and must only be mutated by the owning vCPU; cross-CPU updates to `HCR_VI`/`HCR_VF` in `vcpu_interrupt_line()` must use atomic bitops on `*vcpu_hcr(vcpu)` followed by `KVM_REQ_IRQ_PENDING` and `kvm_vcpu_kick()`; `vcpu->arch.mp_state` writes require `mp_state_lock` and `WRITE_ONCE()` (readers use `READ_ONCE()`). [F22, F24, F25]
- Hardware `AT` emulation (`__kvm_at_s1e01_fast()`, `__kvm_at_s1e2()`) must hold `write_lock_irqsave(&vcpu->kvm->mmu_lock)`, restore `HCR_HOST_VHE_FLAGS` into `HCR_EL2` before `__mmu_config_restore()`, and save/restore `SYS_PSTATE_PAN`; software Stage-1 walks (`walk_s1()`) sleep via `kvm_read_guest()` and require `srcu_read_lock(&vcpu->kvm->srcu)`. [F33, F70, F159]
- Every `kvm_pgtable_walk_begin()` must pair with `kvm_pgtable_walk_end()`, and hyp walks must never set `KVM_PGTABLE_WALK_SHARED`; when installing PTEs (`hyp_map_walker*`, `stage2_make_pte()`), child table init, cache maintenance (`dcache_clean_inval_poc`/`icache_inval_pou` after `stage2_try_break_pte()`), and `mm_ops->get_page(ctx->ptep)` must precede `smp_store_release(ctx->ptep, new)`. [F14, F158, F211, F349]
- In `nvhe/ffa.c`, `host_buffers.lock` must be held continuously while copying `host_buffers.tx` into `hyp_buffers.tx` via `memcpy()`, parsing descriptors, calling `ffa_host_share_ranges()`, and issuing the SMC (never parsing directly from `host_buffers.tx`). [F219, F258]

## Object Lifetimes

- In `kvm_arch_vcpu_load()`: when `!is_protected_kvm_enabled()` && `vcpu_has_nv(vcpu)`, `kvm_vcpu_load_hw_mmu()` must precede reading `vcpu->arch.hw_mmu` (and `kvm_vcpu_put_hw_mmu()` must follow `kvm_vcpu_put_vhe()`); `kvm_arm_vmid_update(&mmu->vmid)` must precede `kvm_vcpu_load_vhe()` and check `*this_cpu_ptr(mmu->last_vcpu_ran) != vcpu->vcpu_idx` to call `__kvm_flush_cpu_context`; `kvm_timer_vcpu_load()` must precede `kvm_vgic_load()`; `kvm_vcpu_load_debug()` must precede `kvm_vcpu_load_vhe()`. [F7, F8, F16, F74, F155]
- `host_data_ptr(host_ctxt)->__hyp_running_vcpu` must be set to `vcpu` before loading guest sysregs/traps or calling any `sysreg-sr.h` helper on `host_ctxt` (since `ctxt_to_vcpu(ctxt)` uses `container_of` when NULL, and `ctxt->__hyp_running_vcpu != NULL` identifies the host context), and cleared to `NULL` after restoring host state in `__kvm_vcpu_run()` or `kvm_vcpu_put_vhe()`. [F207, F297, F315]
- `stage2_pte_is_counted()` counts both valid and non-zero invalid PTEs, so Stage-2 PTE updates must balance `get_page()`/`put_page()` on `ctx->ptep` and `childp`; `kvm_pgtable_stage2_free_unlinked()` drops the final ref on the root `pgtable` page itself, so callers must not call `mm_ops->put_page(pgtable)` again. [F190, F191]
- In `nvhe/page_alloc.c`, all `hyp_page` refcount and buddy updates must occur under `pool->lock`; only the head page of a coalesced buddy allocation has a valid `p->order` while tail pages have `HYP_NO_ORDER` (so `PAGE_SIZE << p->order` must only be evaluated on head pages, and high-order allocations from `hyp_alloc_pages()` must be split with `hyp_split_page()` before individual `hyp_put_page()` calls); free-list removal must use `page_remove_from_list(p)`, never `list_del()`. [F199, F265, F294, F306]
- `hyp_pin_shared_mem(from, to)` maps `[ALIGN_DOWN(from, PAGE_SIZE), PAGE_ALIGN(to))` into `pkvm_pgtable` when `p->refcount` transitions 0->1, `hyp_unpin_shared_mem()` unmaps when `p->refcount == 1`, and `__pkvm_host_unshare_hyp()` returns `-EBUSY` if `hyp_page_count()` is non-zero; multi-page `void *` buffers like `sve_state` must pass `from + byte_size`, not `buf + 1`. [F196, F311]
- In `psci_cpu_on()`, `try_acquire_boot_args()` must precede writing `boot_args->pc`/`r0` and `wmb()` before `psci_call()`; lock ownership transfers to `__kvm_host_psci_cpu_entry(true)` (which must read `r0`/`pc` before `release_boot_args()`) if and only if `psci_call()` returns `PSCI_RET_SUCCESS`, otherwise `psci_cpu_on()` must call `release_boot_args()` itself. [F205, F210]

## API Contracts

- `__vcpu_sys_reg()`, `__vcpu_assign_sys_reg()`, `__vcpu_rmw_sys_reg()`, and `ctxt_sys_reg()` only access memory (`sys_regs` or `vncr_array`); `vcpu_read_sys_reg()` and `vcpu_write_sys_reg()` must be used whenever a register may be live on the CPU (`SYSREGS_ON_CPU`). [F66]
- `kvm_vcpu_get_fault_ipa()` returns `INVALID_GPA` (`~(gpa_t)0`) when `HPFAR_EL2_NS` is clear in `vcpu->arch.fault.hpfar_el2` (and `__get_fault_info()` can return `true` with `hpfar_el2 == 0` when `!__fault_safe_to_translate(esr)`), so callers must check `HPFAR_EL2_NS` / `INVALID_GPA`; when classifying Stage-2 write faults (`kvm_is_write_fault()`), `kvm_vcpu_abt_iss1tw(vcpu)` must be checked before `kvm_vcpu_trap_is_iabt()` and `kvm_vcpu_dabt_iswrite()`, treating `S1PTW` faults as writes only on permission faults. [F55, F98, F240]
- `kvm_pgtable_stage2_wrprotect()` and `kvm_pgtable_stage2_test_clear_young()` do not invalidate TLBs; `kvm_pgtable_stage2_split()` requires `mc` to be `&mmu->split_page_cache`; `__tlbi_level(ipas2e1*, ipa, level)` requires `ipa >> 12` while `__flush_s2_tlb_range_op()` takes an unshifted byte `start`, and range flushes / table-PTE zapping must pass `TLBI_TTL_UNKNOWN` (with `stage2_try_break_pte()` aligning `ctx->addr` down to `kvm_granule_size(ctx->level)`). [F187, F245, F246, F316, F342]
- Callers of `__kvm_translate_va(vcpu, wi, wr, va)` must zero-initialize `*wi` and `*wr` and check `!wr->failed` before reading `wr->pa`/`desc`/`level`; in `nvhe/mem_protect.c`, range checks must use `range_is_memory()`/`check_range_allowed_memory()` (not `addr_is_memory()`), `__guest_check_transition_size()` restricts guest Stage-2 transitions to 1 page or a PMD block, and `assert_host_shared_guest()` callers that may hit block mappings must pass `size = 0`. [F46, F47, F242, F266, F281]

## Error Handling

- `kvm_pgtable_hyp_unmap()` requires `pgt->mm_ops->page_count` to be non-NULL and returns the `u64` byte count unmapped (check `!= size`, not `< 0`); `__vgic_v2_perform_cpuif_access()` returns `1` (handled), `0` (unhandled), or `-1` (promote to `ARM_EXCEPTION_EL1_SERROR`), which must not be tested as a boolean. [F225, F226, F356]
- In `nvhe/ffa.c`: `do_ffa_rxtx_map()`/`unmap()` must unpin before unsharing and NULL `host_buffers.tx`/`rx` before `ffa_unmap_hyp_buffers()`; `__ffa_host_{share,unshare}_ranges()` return the `u32` count of processed ranges (rolling back that exact count if `< nranges`); `__do_ffa_mem_xfer()` and `do_ffa_mem_frag_tx()` must call `ffa_host_unshare_ranges()` if the SMC fails, only calling `ffa_to_smccc_res(res, ret)` when `ret != 0`. [F202, F203, F230, F235]

## Known Pitfalls

- Signed AArch64 ID register fields must be sign-extended via `sign_extend64()` in `idreg_feat_match()`, compared inside `kvm_cmp_feat_signed()`/`kvm_cmp_feat_unsigned()` so both ternary branches in `kvm_cmp_feat()` return `bool`, and selected with `max(sys_val, pvm_max)` in `get_restricted_features()` when negative (`>= 1UL << (width - 1)`), widening values to `u64` before shifting. [F93, F109, F290, F302]
- Use `kvm_s2_mmu_to_kvm(mmu)` (`container_of` on `mmu->arch`) rather than `container_of(mmu, struct kvm, arch.mmu)` because `mmu` may be in `kvm->arch.nested_mmus`; in `__kvm_pgtable_visit()`, reload `ctx.old = READ_ONCE(*ptep)` and recompute `table = kvm_pte_table(ctx.old, level)` after `kvm_pgtable_visitor_cb()`. [F126, F259]
