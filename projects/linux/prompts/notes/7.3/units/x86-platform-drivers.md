# X86 PLATFORM DRIVERS

This unit contains x86 and OLPC platform drivers (`drivers/platform/x86/`, `drivers/platform/olpc/`, and `include/linux/platform_data/x86/`) that bridge vendor firmware interfaces (ACPI, WMI, SMBIOS, EC, TPMI, P2SB, and MSRs) to standard kernel subsystems including backlight, hwmon, rfkill, input, power_supply, leds, regulator, platform_profile, and vga_switcheroo.

## Architecture & Data Flow

- In `intel/ifs/`, `IFS_TYPE_ARRAY_BIST` sets `.test_msrs = NULL` in `ifs_devices[]`, so `ifs_get_test_msrs(dev)` must never be dereferenced in paths shared with array BIST. In `doscan()` and `ifs_test_core()`, select `.gen2` on `ifs_scan`/`ifs_status` when `ifsd->generation != 0` and `.gen0` when `0` (clearing `activate.gen0.rsvd = 0`). [F51, F52]
- In `intel/ifs/`, `ifs_sbaf_test_core()` must set `activate.bundle_idx = status.bundle_idx + 1`, `activate.pgm_idx = 0`, and `retries = MAX_IFS_RETRIES` on `sbaf_bundle_completed(status)`, or update both indices and reset `retries` on partial progress (`status.pgm_idx != activate.pgm_idx`). All IFS core test retry loops must check deadlines with `time_after(jiffies, timeout)`. [F98, F114]
- In `intel/ifs/load.c`, `find_meta_data()` must stop iterating `metadata_header` blocks when `type == MC_HEADER_META_TYPE_END`, `blk_size == 0`, or `meta_size >= total_meta`. `ifs_load_firmware()` must set `ifsd->loaded = (ret == 0)` on every exit path so failed loads invalidate `ifsd->cur_batch`. [F66, F91]
- In `dell-smbios-base.c`, `parse_da_table()` must ignore DMI type `0xda` records with `dm->length < 17` and append `(dm->length - 11) / sizeof(struct calling_interface_token) - 1` tokens. `build_tokens_sysfs()` must run only after `dmi_walk()` finishes all `krealloc()` calls on `da_tokens`, because `token_entries[i].token` caches `&da_tokens[i]`. [F65, F79]
- In `apple-gmux.c`, on `APPLE_GMUX_TYPE_MMIO`, `gmux_probe()` must force `iolen = 16` and `props.max_brightness = MMIO_GMUX_MAX_BRIGHTNESS` (`0xffff`), `gmux_mmio_read32()`/`write32()` must use `ioread32be()`/`iowrite32be()` under `index_lock`, and `gmux_clear_interrupts()` must call ACPI `"GMSP"` with `0` after writing `GMUX_PORT_INTERRUPT_STATUS`. [F138, F139]
- In `hp-wmi.c`, Omen/Victus profile setters must update `active_platform_profile` under `active_platform_profile_lock`, and `platform_profile_omen_get` must return `active_platform_profile` rather than reading the EC. On `has_omen_thermal_profile_ec_timer` boards, `platform_profile_omen_set_ec` must call `omen_thermal_profile_ec_timer_set(0)` and `omen_thermal_profile_ec_flags_set()` after `omen_thermal_profile_set()`. [F68, F69]
- In `hp-wmi.c`, `victus_s_gpu_thermal_profile_set()` must populate `gpu_power_modes.gpu_slowdown_temp` via `victus_s_gpu_thermal_profile_get()` before `HPWMI_SET_GPU_THERMAL_MODES_QUERY`. In `hp_wmi_rfkill2_setup()` and `hp_wmi_rfkill2_refresh()`, `state.count` must be bounded by `HPWMI_MAX_RFKILL2_DEVICES` (`7`), and refresh must index `state.device` by `rfkill2[i].num`. [F70, F85]
- In `olpc-ec.c` and `olpc-xo175-ec.c`, pre-suspend EC commands must run before setting `suspended = true`, and resume must clear `suspended` before issuing EC commands. If `sscanf()` in `ec_dbgfs_cmd_write()` parses `< 2` items or `ec_dbgfs_resp_bytes > EC_MAX_CMD_REPLY`, reset `ec_dbgfs_resp_bytes = 0` under `ec_dbgfs_lock`. [F61, F62]
- In `p2sb.c`, `p2sb_cache_resources()` must allow `PCI_POSSIBLE_ERROR(class)` when checking `PCI_CLASS_MEMORY_OTHER` because BIOS-hidden P2SB returns `0xffff`. `p2sb_read_bar0()` must copy only value fields (`start`, `end`, `flags`, `desc`) into a zeroed `struct resource`, and `p2sb_read_from_cache()` must verify `cache->bus_dev_id == bus->dev.id` and `p2sb_valid_resource(&cache->res)`. [F202, F222, F244]
- In `intel_ips.c`, `ips_cpu_raise()`/`lower()` must update `THM_MPCPC` and `TURBO_POWER_CURRENT_LIMIT` in lockstep (enabling `TURBO_TDC_OVR_EN | TURBO_TDP_OVR_EN` first), and `ips_probe()`/`remove()` must save and restore `orig_turbo_limit`. `*_avg_temp` fields are in `0.01 C` units (scale degree limits by 100), and `last_sample_period` must be clamped to `>= 1`. [F215, F216, F246, F251]
- In `tpmi_power_domains.c`, `tpmi_power_domain_mask` and `domain_die_map` are indexed by `topology_logical_package_id(cpu)` and `domain_id`, so callers must validate `pkg_id < topology_max_packages()` and `domain_id < MAX_POWER_DOMAINS` (never physical package ID). [F77]

## Synchronization

- In `intel/ifs/`, `ifs_sem` must be acquired before `cpus_read_lock()` across all `do_core_test()` and `ifs_load_firmware()` calls, and every exit path in `do_core_test()` and `scan_chunks_sanity_check()` after `cpus_read_lock()` must jump to `out:` to call `cpus_read_unlock()`. [F5, F31]
- In `intel/ifs/runtest.c`, `scan_cpus_in`, `array_cpus_in`, or `sbaf_cpus_in` must be reset via `atomic_set(..., 0)` before each `stop_core_cpuslocked()` retry. In `doscan()` and `dosbaf()`, all SMT siblings must synchronize via `wait_for_sibling_cpu()` before writing `MSR_ACTIVATE_SCAN`/`MSR_ACTIVATE_SBAF`, whereas only `cpumask_first(cpu_smt_mask(cpu))` may write `MSR_ARRAY_BIST`. In `copy_hashes_authenticate_chunks_gen2()`, `wrmsrq(msrs->copy_chunks, ...)` must run under `local_irq_disable()` and retry up to `IFS_AUTH_RETRY_CT` times on `AUTH_INTERRUPTED_ERROR`. [F67, F146, F148]
- In `apple-gmux.c`, all indexed and MMIO port accessors must hold `gmux_data->index_lock`. `init_completion(&gmux_data->powerchange_done)` must precede `gmux_enable_interrupts()`, and `reinit_completion(&gmux_data->powerchange_done)` must precede writing `GMUX_PORT_DISCRETE_POWER`. `gmux_remove()` must finish debugfs, `vga_switcheroo`, interrupt/GPE, notify handler, and backlight teardown before unmapping I/O or freeing `gmux_data`. [F26, F27, F28]
- In `p2sb.c`, `p2sb_cache_resources()` must hold `pci_lock_rescan_remove()` while unhiding `P2SBC`, scanning/removing the device, and re-hiding `P2SBC_HIDE`. `p2sb_bar()` must read from `p2sb_resources` (populated at `fs_initcall_sync`) without taking `pci_lock_rescan_remove()`, because callers invoke `p2sb_bar()` during PCI rescans that already hold that lock. [F190, F191]
- In `olpc-ec.c`, `ec->cmd_q_lock` (`spin_lock_irqsave`) protects `ec->cmd_q` and must be dropped before `olpc_ec_worker()` takes `ec->cmd_lock` to call `ec_driver->ec_cmd()`. In `olpc_xo175_ec_probe()`, `priv` state and `olpc_ec_driver_register()` must be initialized before registering the `olpc-ec` platform device or calling `olpc_xo175_ec_set_event_mask()`. [F23, F25]
- In `tpmi_power_domains.c`, `tpmi_lock` protects `tpmi_cpu_hash` and `tpmi_power_domain_mask`, and `tpmi_exit()` must call `cpuhp_remove_state()` before freeing `tpmi_power_domain_mask` and `domain_die_map`. In `plr_tpmi.c`, `plr_read_cpu_status()`/`plr_clear_cpu_status()` must hold `plr_die->lock` while polling `PLR_MAILBOX_INTERFACE` until `PLR_RUN_BUSY` clears. In `turbo_max_3.c`, `itmt_legacy_cpu_online()` must defer `sched_set_itmt_support()` via `schedule_work(&sched_itmt_work)`. [F33, F35, F141]
- In `dell-lis3lv02d.c`, `instantiate_i2c_client()` must use `bus_for_each_dev(&i2c_bus_type, ...)` (not `i2c_for_each_dev()`), and module exit must call `bus_unregister_notifier()` and `cancel_work_sync(&i2c_work)` before `i2c_unregister_device()`. In `dell_uart_bl_serdev_probe()`, `serdev_device_set_drvdata()` and `serdev_device_set_client_ops()` must precede `devm_serdev_device_open()`. [F37, F125]
- In `crystal_cove_charger_probe()`, IRQ domain/chip setup, `devm_add_action_or_reset(..., crystal_cove_charger_rm_irq_domain, ...)`, and initial `MCHGRIRQ_REG` masking must precede `devm_request_threaded_irq()`. In `int0002_irq()`, the hardirq handler must use `generic_handle_domain_irq_safe()` and `pm_wakeup_hard_event()` without sleeping. [F21, F38, F156]
- In `xiaomi_wmi_notify()`, key events and `input_sync()` on `data->input_dev` must be serialized under `data->key_lock`. In `silicom-platform.c`, all `MEC_ADDR`/`MEC_DATA_OFFSET` I/O sequences must hold `mec_io_mutex`, and `silicom_gpio_chip.can_sleep` must be `true`. [F189, F268]

## Object Lifetimes

- `olpc_ec_cmd()` queues stack-allocated `struct ec_cmd_desc desc` onto `ec->cmd_q` and must wait uninterruptibly via `wait_for_completion(&desc.finished)` until `olpc_ec_worker()` completes it. [F7]
- In `amd_isp4.c`, `isp_i2c_bus_notify()` must clear `isp4_platform->i2c_dev = NULL` under `isp4_platform->lock` on `BUS_NOTIFY_REMOVED_DEVICE`, and `amd_isp_remove()` must unregister `i2c_nb` before `i2c_unregister_device()` and `software_node_unregister_node_group()`. Similarly, `tink_board_exit()` must unregister `tink_keys_pdev` and `tink_leds_pdev` before `software_node_unregister_node_group()`. [F12, F184]
- In `dell_uart_bl_pdev_probe()`, `put_device(ctrl_dev)` must release the controller after `serdev_device_alloc()`, and once `serdev_device_add()` succeeds, teardown must call `serdev_device_driver_unregister()` then `serdev_device_remove()`. In `serdev_helpers.h`, `get_serdev_controller()` must call `get_device(acpi_get_first_physical_node(adev))` before `acpi_dev_put(adev)`, and `get_serdev_controller_from_parent()` must call `put_device(ctrl_dev)` on each intermediate parent. [F15, F262]
- In `intel_ips.c`, `ips_get_i915_syms()` must unwind `symbol_get()` references in reverse order with `symbol_put()` on failure and in `ips_remove()`, and `ips_monitor()` must call `timer_delete_sync(&ips->timer)` before exiting. In `p2sb.c`, when `p2sb_hidden_by_bios` is false, `p2sb_bar()` must read BAR0 from the live device via `p2sb_read_from_dev()` without scanning/removing it. [F183, F195, F258]
- In `silicom-platform.c`, `silicom_mc_leds_register()` must deep-copy each `struct led_classdev_mc` and its `subled_info` array (`led->num_colors * sizeof(struct mc_subled)`) with `devm_kzalloc()` because the board LED templates are `__initdata`, and every `led_info` array must end with a `{ }` sentinel. [F237, F255]

## API Contracts

- In `dell-smbios`, `dell_smbios_find_token()` returns an unreferenced pointer into `da_tokens` that callers must not `kfree()` or use after module exit. `dell_smbios_call()` returns only transport status, so callers must pass `buffer->output[0]` to `dell_smbios_error()`. Backend priority must be passed via `dell_smbios_register_device(..., priority)`, not `dev->id`. [F3, F46, F64]
- In `dell-smbios`, `dell_smbios_call_filter()` and `dell_smbios_class_is_supported()` must reject `class > 30` before shifting `1 << class`. In `dell_smbios_call_filter()`, unsupported classes, `call_blacklist`, and `token_blacklist`/`token_whitelist` must be checked before `call_whitelist`, and non-whitelisted calls require `capable(CAP_SYS_RAWIO)` (`-EACCES`). Token sysfs `location_show()` and `value_show()` require `capable(CAP_SYS_ADMIN)` (`-EPERM`). [F80, F100, F166, F167]
- In `hp-wmi.c`, `hp_wmi_perform_query()` requires a buffer of `>= max(insize, outsize)` bytes (`outsize <= 4096`), allocates `struct_size(args, data, max(insize, 128))`, and returns `0`, a negative errno, or a positive `bios_return->return_code` (which callers returning kernel errnos must map to a negative errno). [F44, F84]
- In `huawei-wmi.c`, `huawei_wmi_cmd()` returns `-ENODEV` when status byte `buf[0]` is non-zero; callers must check the return value and read payload bytes starting at `buf[1]`. `huawei_wmi_battery_set()` must validate both `start` and `end` in `[0, 100]` before storing into `u8` `arg.args[2..3]`. [F47, F81]
- In `intel/ifs/`, `validate_ifs_metadata()` requires `ifs_test_image_ptr` (`(u64)ifs_meta + sizeof(union meta_data)`) to be 256-byte aligned (`IFS_CHUNK_ALIGNMENT`, so the 8-bit chunk index can be ORed into `linear_addr`) and `starting_chunk` to be a multiple of non-zero `chunks_per_stride`. `scan_chunks_sanity_check()` must use `INIT_WORK_ONSTACK(&local_work.w, ...)`. [F53, F90, F165]
- All `.profile_get` callbacks (`platform_profile_omen_get`, `platform_profile_victus_get`, `hp_wmi_platform_profile_get`, `inspur_platform_profile_get`) must write the profile to `*profile` and return `0`. In `int0002_virtualgpio.c`, `int0002_probe()` must pass `IRQF_ONESHOT | IRQF_SHARED` to `devm_request_irq()`. In Intel SoC PMIC child drivers, `platform_get_irq()` already returns a translated vIRQ and must not be passed to `regmap_irq_get_virq()`. [F143, F144, F163]

## Error Handling

- In `dell_smbios_init()`, `build_tokens_sysfs()` frees its own partial allocations on failure, so `fail_sysfs` must not call `free_group()`. When creating multiple sysfs files in `huawei_wmi_battery_add()` or `irst_add()`, failure of the second `device_create_file()` must roll back the first with `device_remove_file()`. [F2, F8]
- In `ifs_load_firmware()`, every error path after `request_firmware_direct()` succeeds must jump to `release:` to call `release_firmware(fw)`. In `ifs_test_core()` and `ifs_sbaf_test_core()`, `union ifs_status status = {}` must be zero-initialized before the retry loop because timeout breaks early setting only `status.error_code`. [F4, F40]
- In `hp_wmi_perform_query()`, every exit path after `kmalloc()` must jump to `out_free:` to `kfree(obj)` and `kfree(args)`. In `huawei-wmi.c`, `acpi_status` returns must be checked with `ACPI_FAILURE()` and mapped to negative errnos, and `union hwmi_arg` must have `arg.cmd` assigned before setting `arg.args[2..3]`. [F17, F42, F48]
- In `tpmi_cpu_online()` and `itmt_legacy_cpu_online()`, MSR/mailbox read errors must return `0` rather than a negative errno so CPU hotplug bringup is not aborted. [F54]
- In `apple-gmux.c`, if `acpi_evaluate_integer(..., "GMGP", ...)` fails, `gmux_data->gpe` must be set to `-1` and all GPE paths must check `gmux_data->gpe >= 0`. In `gmux_selected_port_data_write()`, `copy_from_user()` non-zero returns must map to `-EFAULT`, and non-zero `*ppos` or sizes other than 1 or 4 bytes must return `-EINVAL`. [F41, F55, F177]
- In `anx7428_probe()`, `read_poll_timeout()` on `i2c_smbus_read_byte_data(..., TX_STATUS)` must check `val >= 0 && (val & OCM_STARTUP)`. In `ec_dbgfs_cmd_write()`, `char cmdbuf[64] = ""` must be zero-initialized before `simple_write_to_buffer()`. [F43, F243]

## Known Pitfalls

- In `dell-smbios-base.c`, `build_tokens_sysfs()` skips `da_tokens[i]` with `tokenID == 0` when compacting `token_attrs[j]`, so `location_show()`/`value_show()` must use `container_of(attr, struct token_sysfs_data, ...)->token` rather than indexing `da_tokens` by attribute offset. [F78]
- In `hp-wmi.c`, `IS_HWBLOCKED(x)` must check `((x & HPWMI_POWER_FW_OR_HW) != HPWMI_POWER_FW_OR_HW)`, `hp_wmi_get_fan_speed()` must cast `char fan_data[2..3]` to `u8` before shifting, and `zero_if_sup(tmp)` must never be passed a pointer variable. [F99, F108, F117]
- In `intel/ifs/load.c`, cast typed pointers (`ifs_header_ptr`, `meta_header`, `ifs_meta`) to `void *` or `u64` before adding byte offsets. In `plr_tpmi.c`, `plr_print_bits()` must use `BITMAP_FROM_U64(val)` rather than `(unsigned long *)&val`. In `pmc_atom.c`, `pmc_power_off()` must invert `SLEEP_TYPE_MASK` (`&= ~SLEEP_TYPE_MASK`), and `pmc_sleep_tmr_show()` must cast `pmc_reg_read()` to `u64` before `<< PMC_TMR_SHIFT`. [F119, F124, F240, F248]
