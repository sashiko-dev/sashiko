# TIMEKEEPING, CLOCKSOURCE CORE, NTP, ALARMTIMER

This unit implements the Linux kernel's core timekeeping infrastructure, hardware clocksource registration and watchdog monitoring, the NTP/PPS clock discipline state machine, and RTC-backed alarm timers. It maintains system clocks (REALTIME, MONOTONIC, MONOTONIC_RAW, BOOTTIME, TAI, and POSIX auxiliary clocks), provides lockless seqcount- and latch-protected time readout APIs (including NMI-safe fast accessors and VDSO/pvclock updates), and handles time-related syscalls, time conversions, and suspend/resume time injection.

## Architecture & Data Flow

- Coupled offset fields in `struct timekeeper` must be updated in lockstep via their helpers: `tk->wall_to_monotonic`, `tk->offs_real`, and `tk->offs_tai` via `tk_set_wall_to_mono()`, `tk->tai_offset` via `__timekeeping_set_tai_offset()`, `tk->offs_boot` and `tk->monotonic_to_boot` via `tk_update_sleep_time()`, and `tk->offs_aux` and `tk->monotonic_to_aux` via `tk_update_aux_offs()` (except during zero-init in `aux_clock_enable()`). [F51, F52, F56]
- In `tk_update_ktime_data()`, `tk->tkr_mono.base` and `tk->tkr_raw.base` must be computed from whole-second fields (`tk->xtime_sec`, `tk->wall_to_monotonic`, and `tk->raw_sec`) without adding shifted `xtime_nsec`, whereas `tk->ktime_sec` must add `tk->tkr_mono.xtime_nsec >> tk->tkr_mono.shift`. `tk->coarse_nsec` must be updated via `tk_update_coarse_nsecs()` only when setting, adding, or forwarding time or when `__timekeeping_advance()` accumulated cycles (`orig_offset != offset`), never after a `TK_ADV_FREQ` call where `orig_offset == offset`. [F53, F54]
- When `timekeeping_apply_adjustment()` changes `tk->tkr_mono.mult` by `mult_adj`, it must adjust `tk->xtime_interval` by `tk->cycle_interval * mult_adj` and subtract `offset * mult_adj` from `tk->tkr_mono.xtime_nsec`. If `xtime_nsec` underflows in `timekeeping_adjust()` (decrementing `tk->xtime_sec`), it must set `tk->skip_second_overflow = 1`, and `accumulate_nsecs_to_secs()` must clear that flag and `continue` before calling `second_overflow()`. [F58, F98]
- When `tk_setup_internals()` switches from a non-NULL `old_clock` to `clock`, it must shift `tk->tkr_mono.xtime_nsec` and `tk->tkr_raw.xtime_nsec` by `clock->shift - old_clock->shift` before updating `shift`. In `struct tk_data`, `seq` must immediately precede `timekeeper`, and `tkr_mono` (56 bytes on 64-bit) must remain the first member of `struct timekeeper` to share one 64-byte cacheline. [F57, F132]
- During `timekeeping_suspend()`, after setting `timekeeping_suspended = 1` and calling `timekeeping_update_from_shadow(&tk_core, 0)`, `halt_fast_timekeeper()` must snapshot `cycles_at_suspend` and switch `tk_fast_mono` and `tk_fast_raw` to `&dummy_clock` before `clocksource_suspend()`. `suspend_timing_needed` is set `true` only in `timekeeping_suspend()` and cleared when sleep time is injected in `timekeeping_resume()` or `timekeeping_inject_sleeptime64()`. [F60, F145]
- Callers of `clocksource_delta()` (`cycles_to_nsec_safe()`, `timekeeping_forward_now()`, `__timekeeping_advance()`) must pass `cs->max_raw_delta` (0.875 of `cs->mask`) as `max_delta` rather than `cs->mask >> 1` or `cs->max_cycles`. In `__clocksource_update_freq_scale()`, when `freq != 0`, `cs->mult` and `cs->shift` must be scaled down until neither `cs->mult + cs->maxadj` nor `cs->mult - cs->maxadj` wraps `u32`, and `clocks_calc_max_nsecs()` must use `mult - maxadj`. [F107, F116]
- `struct timespec64` differences passed to `timespec64_compare()` or `tk_set_wall_to_mono()` must be normalized with `timespec64_sub()` or `set_normalized_timespec64()`. In `ns_to_timespec64()`, negative inputs must use floor division via `-div_u64_rem(-nsec - 1, NSEC_PER_SEC, &rem) - 1` so `0 <= tv_nsec < NSEC_PER_SEC` without `S64_MIN` negation overflow. [F45, F120]
- In `process_adjtimex_modes()`, `txc->constant` (`ADJ_TIMECONST`) must be clamped to `[0, MAXTC]` both before and after adding 4 for `!STA_NANO`; `txc->maxerror` and `txc->esterror` must be clamped to `[0, NTP_PHASE_LIMIT]`. In `ntp_update_offset()`, when `!STA_NANO`, `offset` must be clamped to `[-USEC_PER_SEC, USEC_PER_SEC]` before multiplying by `NSEC_PER_USEC`, then clamped to `[-MAXPHASE, MAXPHASE]`. [F69, F70, F72]
- In `ntp_adjtimex()`, `txc->modes & ADJ_ADJTIME` (which userspace passes as `ADJ_OFFSET_SINGLESHOT = 0x8001` or `ADJ_OFFSET_SS_READ = 0xa001`, overlapping `ADJ_OFFSET` and `ADJ_NANO`) must take an exclusive branch that bypasses `process_adjtimex_modes()`. In `process_adj_status()`, `STA_PLL` transitions must be checked before updating `ntpdata->time_status`. [F101, F102]
- In `alarmtimer.c`, `alarm_bases[ALARM_NUMTYPE]` only contains `ALARM_REALTIME` and `ALARM_BOOTTIME` (`< ALARM_NUMTYPE`); `ALARM_REALTIME_FREEZER` and `ALARM_BOOTTIME_FREEZER` in `freezer_alarmtype` must never index `alarm_bases[]`. Adding a relative timeout to `base->get_ktime()` in `alarm_start_relative()`, `alarm_timer_arm()`, and `alarm_timer_nsleep()` must use `ktime_add_safe()`. [F77, F81]

## Synchronization

- In `kernel/time/clocksource.c`, `clocksource_mutex` is the outer sleeping lock and `watchdog_lock` is the inner IRQ-safe spinlock. Manipulations of `clocksource_list` (`clocksource_enqueue()`, `clocksource_change_rating()`, and `list_del_init(&cs->list)` in `clocksource_unbind()`) must hold both locks so `clocksource_mark_unstable()` can safely test `!list_empty(&cs->list)` under `watchdog_lock` alone. `clocksource_select()` / `timekeeping_notify()` (which calls `stop_machine()`) must not run in a workqueue callback or under `watchdog_lock`, so `clocksource_watchdog_work()` spawns `clocksource_watchdog_kthread` to take `clocksource_mutex`. [F13, F15, F161]
- Auxiliary clock lock order is `aux_clock_mutex` -> `tk_core.lock` -> `aux_tkd->lock`. `aux_clock_enable_store()` must initialize `aux_tkd` under `tk_core.lock` nested outside `aux_tkd->lock` before setting its bit in `aux_timekeepers`; lockless readers of `aux_timekeepers` (`tk_aux_advance()`, `tk_aux_update_clocksource()`) must recheck `shadow_timekeeper.clock_valid` under `aux_tkd->lock` after `tk_core.lock` is released. [F25, F157]
- Lockless seqcount-protected timekeeping readers must read the clocksource via `tk_clock_read()`, which uses `READ_ONCE(tkr->clock)`. `ktime_get_{mono,raw,boot,tai}_fast_ns()` must be marked `notrace`, and `__ktime_get_fast_ns()`, `ktime_get_real_fast_ns()`, and `timekeeping_get_ns()` must remain lockless for NMI/tracing safety. [F152, F153]
- In `ktime_mono_to_any()` and `ktime_get_real_seconds()`, 64-bit fields (`*offset` and `tk->xtime_sec`) may only be read without `tk_core.seq` when `IS_ENABLED(CONFIG_64BIT)` (paired with `WRITE_ONCE()` on `offs_real`, `offs_tai`, and `offs_boot`); 32-bit builds require a `read_seqcount_begin(&tk_core.seq)` retry loop. [F155]
- Time setters (`do_settimeofday64()`, `timekeeping_inject_offset()`, `timekeeping_inject_sleeptime64()`, `__do_adjtimex()`, `do_adjtimex()`) must call `add_device_randomness()`, `audit_tk_injoffset()`, `clock_was_set()`, and `ntp_notify_cmos_timer()` outside `tkd->lock`, while `update_wall_time()` must call `clock_was_set_delayed()`. `pvclock_gtod_chain` runs under `tk_core.lock` and `write_seqcount_begin(&tk_core.seq)`, so its callbacks must not sleep, take non-raw spinlocks, or call `ktime_get()`. [F156, F159]
- In `timekeeping_resume()`, `clockevents_resume()` and `clocksource_resume()` must run before taking `tk_core.lock` to read `tks->tkr_mono` and stop suspend timing, while `tick_resume()` and `timerfd_resume()` must run after updating `tk_core` and dropping `tk_core.lock`. [F144]
- In `alarmtimer.c`, `base->lock` must be held across `alarmtimer_enqueue()` and `alarmtimer_dequeue()` to keep `base->timerqueue`, `ALARMTIMER_STATE_ENQUEUED`, and `alarm->timer` synchronized, but must be released before `alarm->function()` in `alarmtimer_fired()` and before `hrtimer_cancel_wait_running()` in `alarm_cancel()`. [F27, F68]

## Object Lifetimes

- `clocksource_unbind()` must return `-EBUSY` if fallback selection cannot replace `cs` as `watchdog` or `curr_clocksource`, reselect `suspend_clocksource` if `clocksource_is_suspend(cs)`, and unlink `cs` with `list_del_init(&cs->list)` so `clocksource_unregister()` sees `list_empty(&cs->list)`. In `__clocksource_register_scale()`, `clocksource_arch_init()` and `__clocksource_update_freq_scale()` must initialize `cs` parameters before taking `clocksource_mutex` and enqueuing `cs`. [F8, F134]
- In `change_clocksource()`, `try_module_get(new->owner)` and `new->enable(new)` must succeed before `tk_core.lock` is taken (`module_put(new->owner)` on `enable()` failure), and `old->disable(old)` and `module_put(old->owner)` must run only after both `tk_core` and `tk_aux_update_clocksource()` switch to `new`. [F135]
- In `alarmtimer_rtc_add_device()`, setting `rtcdev` under `rtcdev_lock` requires `RTC_FEATURE_ALARM`, `device_may_wakeup(rtc->dev.parent)`, and `try_module_get(rtc->owner)`, and must call `get_device(dev)` and clear `pdev = NULL` so `platform_device_unregister(pdev)` cleans up on failure. `alarmtimer_get_rtcdev()` returns a borrowed pointer; callers must not call `put_device()` or `module_put()`. [F2, F137, F138]
- In `update_rtc()`, the `rtc_device` from `rtc_class_open()` must be closed via `rtc_class_close(rtc)` on all exit paths, and `rtc_set_time()` must only be called when `*offset_nsec == rtc->set_offset_nsec`. [F150]

## API Contracts

- Timekeeping readers (`__ktime_get_fast_ns()`, `ktime_get_real_fast_ns()`, `ktime_get_snapshot()`) must convert cycle deltas to nanoseconds via `timekeeping_get_ns()` or `timekeeping_cycles_to_ns()` before adding to `tkr->base` or `tkr->base_real`. `clocksource_cyc2ns()` must only be passed relative deltas `< cs->max_cycles` (`cycles_to_nsec_safe()` uses `mul_u64_u32_shr()` when `delta >= cs->max_cycles`). [F47, F109]
- Auxiliary clock code must convert between `clockid_t` (`CLOCK_AUX..CLOCK_AUX_LAST`), `timekeeper_data[]` indices (`clockid_to_tkid()`), and `aux_timekeepers` bit indices (`0..MAX_AUX_CLOCKS - 1`, adding `TIMEKEEPER_AUX_FIRST` or `CLOCK_AUX`). `ktime_get_aux()` and `ktime_get_aux_ts64()` return `false` without modifying outputs when disabled, so `ktime_get_clock_ts64()` must pre-initialize `ts->tv_sec = -1; ts->tv_nsec = 0`. [F34, F48]
- Before dereferencing `cs->base` (`convert_base_to_cs()`, `convert_cs_to_base()`, `timekeeping_clocksource_has_base()`), callers must load `READ_ONCE(cs->base)` and verify `base != NULL && base->id == target_id` (and reject `CSID_GENERIC` in `get_device_system_crosststamp()`). Callers of `clock_was_set()` must pass `CLOCK_SET_*` bitmask constants (`CLOCK_SET_WALL`, `CLOCK_SET_BOOT`) rather than `CLOCK_*` IDs. [F39, F44]
- `__do_adjtimex()` must scale `txc->time.tv_usec` by `1000` when `!(txc->modes & ADJ_NANO)`, and `process_adjtimex_modes()` must update `STA_NANO` before processing `ADJ_TIMECONST` or `ADJ_OFFSET`. [F49]
- For a registered clocksource, `__clocksource_update_freq_scale()` (and hz/khz wrappers) must only be called from `cs->enable()` before `tk_setup_internals()` copies `mult` and `shift`. `__clocksource_register_scale()` must unconditionally clamp out-of-range `cs->vdso_clock_mode` to `VDSO_CLOCKMODE_NONE` and `cs->id >= CSID_MAX` to `CSID_GENERIC`. [F133, F166]
- A `CLOCK_SOURCE_SUSPEND_NONSTOP` clocksource must not set `cs->suspend` or `cs->resume`. `clocksource_start_suspend_timing()` and `clocksource_stop_suspend_timing()` must only call `suspend_clocksource->enable()`, `read()`, and `disable()` when `!clocksource_is_suspend(cs)`. `clocksource_suspend()` traverses `clocksource_list` in reverse order; `clocksource_resume()` traverses in forward order and calls `clocksource_resume_watchdog()`. [F141, F142, F167]
- Remaining alarm time (`alarm_expires_remaining()`, `alarmtimer_suspend()`, `alarmtimer_freezerset()`, `alarm_timer_remaining()`, `alarmtimer_do_nsleep()`) must be computed as `ktime_sub(expires, now)`. `alarmtimer_suspend()` must abort with `pm_wakeup_event()` and `-EBUSY` if `min < 2 * NSEC_PER_SEC`, otherwise clamping `min` via `rtc_bound_alarmtime()` before `rtc_timer_start()`, and `alarmtimer_resume()` must call `rtc_timer_cancel()`. [F46, F146]

## Error Handling

- Callers of `__do_adjtimex()` must zero-initialize `struct adjtimex_result result = { };` and check `ret < 0` rather than `ret != 0`, because non-negative NTP states (`TIME_OK`..`TIME_ERROR`) are successes requiring post-update notifications and copy-out. Before taking `tkd->lock`, `timekeeping_validate_timex()` must validate `ADJ_TICK`, `ADJ_SETOFFSET` (`tv_usec`), and 64-bit `ADJ_FREQUENCY` (`txc->freq` within `LLONG_MIN/MAX / PPM_SCALE`). [F30, F41, F74]
- Any path under `tkd->lock` that calls `timekeeping_forward_now(&tkd->shadow_timekeeper)` and aborts before `timekeeping_update_from_shadow()` (`do_settimeofday64()`, `__timekeeping_inject_offset()` when `timespec64_valid_settod()` fails or time becomes negative) must call `timekeeping_restore_shadow(tkd)`. `aux_clock_enable()` must `memset(aux_tks, 0, sizeof(*aux_tks))` and restore `aux_tks->id = aux_tkd->timekeeper.id` before `tk_setup_internals()`. [F37, F43, F76]
- `timekeeping_notify()` must check `tk->tkr_mono.clock == clock` after `stop_machine()` returns because `change_clocksource()` always returns `0`. In `alarm_try_to_cancel()`, `alarmtimer_dequeue()` must only run when `hrtimer_try_to_cancel()` returns `ret >= 0`. [F31, F35]
- `ktime_real_to_base_clock()` and `convert_ns_to_cs()` must verify `(u64)treal >= tk->tkr_mono.base_real` before subtracting, and `scale64_check_overflow()` / `convert_ns_to_cs()` must check `fls64()` bit-width before multiplying by `mult` or shifting by `tkr->shift`. `get/put_old_timex32()` must `memset()` the destination struct, and `get_timespec64()` must mask `kts.tv_nsec &= 0xFFFFFFFFUL` when `in_compat_syscall()`. [F42, F91, F114]

## External Contracts

- `do_sys_settimeofday64()` (and `stime`/`stime32`) must check `security_settime64(tv, tz)` before modifying `sys_tz` or calling `do_settimeofday64()`. Non-zero `txc->modes` (except pure read-only `ADJ_ADJTIME | ADJ_OFFSET_SINGLESHOT | ADJ_OFFSET_READONLY`), `ADJ_SETOFFSET`, and `aux_clock_enable_store()` require `capable(CAP_SYS_TIME)`. [F178, F179]
- In `ntp_adjtimex()`, `ADJ_ADJTIME` must save `ntpdata->time_adjust` into `save_adjust` before overwriting it so `txc->offset` returns the old value. `ADJ_TAI` must accept `txc->constant` in `[0, MAX_TAI_OFFSET]`, and `process_adj_status()` must preserve `STA_RONLY` bits in `ntpdata->time_status`. [F65, F71, F73]
- `alarm_timer_create()` and `alarm_timer_nsleep()` must return `-EOPNOTSUPP` if `!alarmtimer_get_rtcdev()` and `-EPERM` if `!capable(CAP_WAKE_ALARM)`, whereas `alarm_clock_get*()` return `-EINVAL` if `!alarmtimer_get_rtcdev()`. `alarm_timer_nsleep()` must convert `TIMER_ABSTIME` via `timens_ktime_to_host()` and use `set_restart_fn()` on relative sleep interruption (`-ERESTARTNOHAND` for `TIMER_ABSTIME`); `get_boottime_timespec()` must call `timens_add_boottime()`. `get/put_old_timespec32()` must check `COMPAT_USE_64BIT_TIME`. [F86, F175, F176, F177]

## Known Pitfalls

- `timekeeping_forward_now()` must consume `delta` in chunks bounded by `tk->tkr_mono.clock->max_cycles`, calling `tk_normalize_xtime()` each iteration before multiplying by `mult`. [F108]
- Prevent 32-bit overflow: cast `NSEC_PER_SEC` and `ts->tv_nsec` to `u64` before `<< shift` in `timekeeping.c`; use `u64`/`ULL` when multiplying seconds by `NSEC_PER_SEC`/`NSEC_PER_USEC` in `ntp.c`; cast `long` phase/freq values to `s64` before `<< NTP_SCALE_SHIFT` in `hardpps_update_*()`; and cast `lhs.tv_sec` to `timeu64_t` in `timespec64_add_safe()` before saturating to `TIME64_MAX`. [F110, F111, F112, F113]
- Use `shift_right()` instead of `>>` on signed NTP values, and use signed division (`div_s64()`, `div_s64_rem()`, `div64_long()`) for signed offsets/skews (`ntp_adjtimex()`, `clocksource_watchdog()`, `second_overflow()`). `ntpdata` passed to `ntp_update_offset()` and `process_adj_status()` must point into `tk_ntp_data[]` because they use `ntpdata - tk_ntp_data` as the timekeeper index. [F117, F119, F126]
