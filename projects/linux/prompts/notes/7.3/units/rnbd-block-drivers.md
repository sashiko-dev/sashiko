# RNBD BLOCK DRIVERS

The RDMA Network Block Device (RNBD) subsystem consists of a client block driver (`rnbd-client`) and a server target module (`rnbd-server`) that export local block devices over RDMA using the RTRS transport layer. The client exposes remote devices as `blk-mq` gendisks (`/dev/rnbd*`) managed via sysfs, multiplexing I/O and administrative requests (`SESS_INFO`, `OPEN`, `CLOSE`, `IO`) over RTRS sessions with per-CPU requeue lists and optional polling queues. The server opens local block devices, enforces access permissions, and translates RDMA requests into local `bio` submissions.

## Architecture & Data Flow

- In `struct rnbd_iu`, `dev` and `sess` share an anonymous union (`iu->sess` is only valid in `msg_sess_info_conf()`; device callbacks must read `iu->dev` and pass `iu->dev->sess` to `rnbd_put_iu()`), and `first_sgl[]` must remain the last member. `setup_mq_tags()` sets `tag_set->cmd_size` to `sizeof(struct rnbd_iu) + RNBD_RDMA_SGL_SIZE` for `blk-mq` PDUs using `sg_alloc_table_chained()`, whereas admin IUs from `rnbd_get_iu()` are `sizeof(*iu)` and use `sg_alloc_table()` / `sg_free_table()`. [F70, F105]
- In `msg_open_conf()`, `from_map = (dev->dev_state == DEV_STATE_INIT)` must be sampled before `process_msg_open_rsp(dev, rsp)` (which sets `DEV_STATE_MAPPED`), and `msg_open_conf()` must only free `rsp` when `!from_map` because `rnbd_clt_map_device()` reads `rsp` in `rnbd_client_setup_device()` and frees it. Thus `send_msg_open()` must never be called when `dev->dev_state == DEV_STATE_INIT`, and `remap_devs()` and `rnbd_clt_remap_device()` must skip or reject `DEV_STATE_INIT`. [F38, F55]
- `rnbd_get_iu()` must initialize `iu->comp.errno` to `INT_MAX` because `send_usr_msg()` waits on `wait_event(iu->comp.wait, iu->comp.errno != INT_MAX)` until `wake_up_iu_comp()` writes the completion status (`0` on success). [F44]
- In `rnbd_queue_rq()` and `rnbd_client_xfer_request()`, even when `sg_cnt == 0` (`REQ_OP_DISCARD` or `REQ_OP_WRITE_ZEROES`), `sg_alloc_table_chained()` must be called with `blk_rq_nr_phys_segments(rq) ? : 1` and `sg_mark_end(&iu->sgt.sgl[0])` must be called. [F45]
- In `rnbd_rerun_if_needed()`, `*cpup` (`sess->cpu_rr`) must be assigned `cpu_q->cpu` rather than incremented, because `rnbd_get_cpu_qlist()` wraps to the first set bit in `sess->cpu_queues_bm` when the search start exceeds the last set bit. [F53]
- In `rnbd_clt_unmap_device()`, `was_mapped = (dev->dev_state == DEV_STATE_MAPPED)` must be sampled under `dev->lock` before setting `dev->dev_state = DEV_STATE_UNMAPPED`, and `send_msg_close()` must be called after `destroy_gen_disk()` only when `was_mapped && sess->rtrs`. [F57]
- In `find_and_get_or_create_sess()`, sessions with `nr_poll_queues > 0` cannot be shared: mapping must fail with `-EINVAL` if `nr_poll_queues` is requested on an existing session (`!first`) or if a non-polling device attaches to a session with `sess->nr_poll_queues > 0`. `HCTX_TYPE_DEFAULT` and `HCTX_TYPE_READ` share `num_online_cpus()` queues at offset 0 while `HCTX_TYPE_POLL` starts at offset `num_online_cpus()`, so `dev->hw_queues` needs `nr_cpu_ids + nr_poll_queues` elements. [F60, F82]
- Every `enum rnbd_access_mode` variant must have a matching entry at its numeric index in `rnbd_access_modes[]` and be handled in `rnbd_clt_parse_map_options()`, `rnbd_srv_check_update_open_perm()`, and `show_rnbd_access_mode()`. On the server, `open_msg->access_mode` must be validated by the switch in `rnbd_srv_check_update_open_perm()` before indexing `rnbd_access_modes[access_mode].str` or storing it in `rnbd_srv_sess_dev`. [F66, F75]
- `srv_dev->open_write_cnt` is incremented under `srv_dev->lock` in `rnbd_srv_check_update_open_perm()` for non-`RNBD_ACCESS_RO` opens and must be decremented under `srv_dev->lock` both on `process_msg_open()` failure after `rnbd_srv_get_or_create_srv_dev()` and in `rnbd_destroy_sess_dev()` when `!sess_dev->readonly`. [F62]
- In `process_msg_open()`, `find_srv_sess_dev(srv_sess, open_msg->dev_name)` must be checked under `srv_sess->lock` before opening the block device or calling `rnbd_srv_get_or_create_srv_dev()`, jumping directly to `rnbd_srv_fill_msg_open_rsp()` if already open. [F64]
- `process_msg_open()` and `rnbd_srv_get_full_path()` must reject `open_msg->dev_name` with `-EINVAL` if it contains `".."` or if the formatted path with `dev_search_path` reaches or exceeds `PATH_MAX`. In `rnbd_srv_get_full_path()`, `snprintf()` into `full_path` must include a `'/'` separator, and the slash-compaction loop must initialize `a` and `b` to `strchr(full_path, '/')`, advance only `b` on duplicate `'/'`, pre-increment `a` (`a++; *a = *b;`) otherwise, and execute `a++` after the loop before writing `'\0'`. [F76, F95, F107]

## Synchronization

- Every `rtrs_permit` from `rnbd_get_permit()` increments `sess->busy` and must be released via `rnbd_put_permit()` (never directly via `rtrs_clt_put_permit()`). `rnbd_clt_dev_add_to_requeue()` must execute `smp_mb__before_atomic()` between `set_bit(cpu_q->cpu, sess->cpu_queues_bm)` and `atomic_read(&sess->busy)` (clearing `sess->cpu_queues_bm` only if `need_set` and clearing bit 0 of `q->in_list` under `cpu_q->requeue_lock` if `sess->busy` is 0), paired with `smp_mb__after_atomic()` in `rnbd_put_permit()` before `rnbd_rerun_all_if_idle(sess)` loops calling `rnbd_rerun_if_needed(sess)`. [F3, F24, F52, F135]
- `cpu_q->requeue_lock` must be acquired with IRQ-saving primitives (`spin_lock_irqsave()` / `spin_trylock_irqsave()`), per-CPU `sess->cpu_queues` and `sess->cpu_rr` must be accessed between `get_cpu_ptr()` and `put_cpu_ptr()`, and `rnbd_clt_dev_requeue()` must call `blk_mq_run_hw_queue(q->hctx, true)` (`async = true`) because `rnbd_put_permit()` runs from interrupt/softirq contexts. [F125, F126, F127]
- In `rnbd_queue_rq()`, permits must be acquired with `RTRS_PERMIT_NOWAIT` via `rnbd_get_permit()` and scatterlists via `sg_alloc_table_chained()`. `remap_devs()` and `msg_open_conf()` must pass `RTRS_PERMIT_NOWAIT` to `send_msg_sess_info()`, `send_msg_open()`, and `send_msg_close()`, and `msg_conf()` must defer admin completions (`msg_open_conf`, `msg_close_conf`, `msg_sess_info_conf`) via `schedule_work(&iu->work)`. [F122, F123, F124]
- On the client, the lock hierarchy is `sess_lock` -> `sess->lock` -> `dev->lock`; `rnbd_clt_unmap_device()` must release `dev->lock` before calling `delete_dev(dev)` (which takes `sess->lock`). [F29]
- In `__find_and_get_sess()`, `if (sess->rtrs_ready && IS_ERR_OR_NULL(sess->rtrs)) continue;` must precede `rnbd_clt_get_sess()` and `wait_for_rtrs_disconnection()` (which returns immediately without dropping `sess_lock` when `sess->rtrs` is NULL or `ERR_PTR`), and `sess_lock` must be released before sleeping in `wait_for_rtrs_connection()` or `wait_for_rtrs_disconnection()`, restarting the `sess_list` search (`goto again`) after reacquiring `sess_lock`. [F28, F84]
- In `rnbd_srv_sess_dev_force_close()`, `mutex_trylock(&sess->lock)` must be used (aborting on contention rather than blocking with `mutex_lock()`), and `sess_dev->keep_id = true` must only be set after `mutex_trylock(&sess->lock)` succeeds. [F17, F131]
- On the server, every call to `rnbd_srv_destroy_dev_session_sysfs(sess_dev)` must hold `sess_dev->sess->lock`. `srv_dev->lock` protects `srv_dev->open_write_cnt`, `srv_dev->sess_dev_list`, and the `srv_dev->dev_kobj.state_in_sysfs` check-and-registration sequence, and must always nest inside `srv_sess->lock`. [F18, F20]
- In `rnbd_srv_find_or_add_srv_dev()`, lookup and insertion in `dev_list` must hold `dev_lock`, initialize `new_dev` before `list_add()`, and use `kref_get_unless_zero(&dev->kref)` to skip dying devices—continuing (`continue;`, not `break;`) to scan `dev_list` if `kref_get_unless_zero()` returns 0. [F21, F94]
- `rnbd_get_sess_dev()` must hold `rcu_read_lock()` across `xa_load(&srv_sess->index_idr, dev_id)` and `kref_get_unless_zero(&sess_dev->kref)`. In `rnbd_destroy_sess_dev()` and `process_msg_open()` rollback (`free_srv_sess_dev`), `sess_dev` must be removed from `srv_sess->index_idr` (`xa_cmpxchg` to `NULL` when `keep_id` is true so `device_id` is not reused, or `xa_erase` otherwise) followed by `synchronize_rcu()`, and `rnbd_destroy_sess_dev()` must wait on `sess_dev->destroy_comp` after `rnbd_put_sess_dev(sess_dev)` before calling `fput()`, `rnbd_put_srv_dev()`, and `kfree(sess_dev)`. [F11, F13, F50, F133]

## Object Lifetimes

- Admin `struct rnbd_iu` objects from `rnbd_get_iu()` start with `iu->refcount = 2`, and callers of `send_usr_msg()` must first pin `dev` (`rnbd_clt_get_dev`) or `sess` (`rnbd_clt_get_sess`). Callers must distinguish `send_usr_msg()`'s return value from out-parameter `errno`: one `rnbd_put_iu()` is always called by the sender, while the second `rnbd_put_iu()` and `rnbd_clt_put_dev()` / `rnbd_clt_put_sess()` (and `kfree(rsp)`) are done by the completion work, or by the caller only when `send_usr_msg()` returns non-zero. [F1, F26, F37]
- In `rnbd_queue_rq()`, once `rnbd_get_permit()` and `sg_alloc_table_chained()` succeed, any failure in `rnbd_client_xfer_request()` must call `sg_free_table_chained(&iu->sgt, RNBD_INLINE_SG_CNT)` and `rnbd_put_permit()`, matching `rnbd_softirq_done_fn()`. [F4]
- `rnbd_clt_map_device()` holds a transient session reference from `find_and_get_or_create_sess()` in addition to the device's reference from `init_dev()` (`rnbd_clt_get_sess`), and must drop the transient reference via `rnbd_clt_put_sess(sess)` on both success and failure. [F5]
- In `find_and_get_or_create_sess()`, `rtrs_clt_open()` and `rtrs_clt_query()` must initialize `sess->queue_depth` and `sess->nr_poll_queues` before `setup_mq_tags(sess)`, and `wake_up_rtrs_waiters(sess)` must only be called after `setup_mq_tags()` and `send_msg_sess_info()` succeed, or on error after `close_rtrs(sess)` clears `sess->rtrs` (or directly if `rtrs_clt_open()` failed) before `rnbd_clt_put_sess(sess)`. [F6, F58, F110]
- In `rnbd_clt_map_device()`, `send_usr_msg()` and `process_msg_open_rsp()` must complete before `rnbd_client_setup_device()`, where `rnbd_init_mq_hw_queues(dev)` must initialize `hctx->driver_data` before `rnbd_clt_setup_gen_disk()` calls `add_disk(dev->gd)`. [F108, F109]
- In `rnbd_destroy_sessions()`, `rnbd_clt_destroy_sysfs_files()` runs first; iterating `sess_list` must skip sessions where `rnbd_clt_get_sess(sess)` returns false, and for active sessions must call `close_rtrs(sess)` before queueing `dev->unmap_on_rmmod_work` on `rnbd_clt_wq` and `rnbd_clt_put_sess(sess)` before `flush_workqueue(rnbd_clt_wq)` (before `rnbd_client_exit()` unregisters `rnbd_client_major` and `index_ida`). In `rnbd_srv_cleanup_module()`, `rtrs_srv_close(rtrs_ctx)` must precede `rnbd_srv_destroy_sysfs_files()`. [F9, F31, F117]
- Once `rnbd_srv_create_dev_session_sysfs(sess_dev)` succeeds, closing `sess_dev` must go through `rnbd_srv_destroy_dev_session_sysfs(sess_dev)` (which triggers `rnbd_destroy_sess_dev()`). `process_msg_close()` must call `rnbd_put_sess_dev(sess_dev)` before `rnbd_srv_destroy_dev_session_sysfs(sess_dev)`, `rnbd_srv_sess_dev_force_close()` must not access `sess_dev` after it, and sysfs `.store` handlers (`destroy_sysfs`, `rnbd_srv_sess_dev_force_close`) must call `sysfs_remove_file_self()` before `kobject_del()` or `rnbd_srv_destroy_dev_session_sysfs()`. [F10, F15, F114, F115]
- In `destroy_device()`, if `dev->dev_kobj.state_in_sysfs` is true, it must call `rnbd_srv_destroy_dev_sysfs(dev)` (which frees `dev` in `rnbd_srv_dev_release()`); otherwise it must call `kfree(dev)` directly. [F12]
- In `rnbd_clt_unmap_dev_store()` and `rnbd_clt_remove_dev_symlink()`, `try_module_get(THIS_MODULE)` must be acquired before `rnbd_clt_unmap_device()` or `sysfs_remove_link(rnbd_devs_kobj, dev->blk_symlink_name)` (balanced with `module_put(THIS_MODULE)`). `dev` must not be dereferenced after `rnbd_clt_unmap_device()` returns 0, and `dev->blk_symlink_name` must always be freed and set to `NULL` even when `try_module_get()` fails. [F16, F116]

## API Contracts

- In `rnbd_srv_rdma_ev()`, non-IO handlers (`RNBD_MSG_OPEN`, `RNBD_MSG_CLOSE`, `RNBD_MSG_SESS_INFO`) send status via `rtrs_srv_resp_rdma(id, ret)` and return 0, whereas `RNBD_MSG_IO` returns `process_rdma()` directly so synchronous errors are returned to RTRS and asynchronous completions call `rtrs_srv_resp_rdma()` in `rnbd_dev_bi_end_io()`. [F36]
- Callers of `find_or_create_sess(sessname, &first)` must initialize `first = false` before the call because `find_or_create_sess()` only writes `*first = true` when allocating a new session. [F43]
- In `rnbd_client_xfer_request()`, the transfer length passed to `rtrs_clt_request()` must be `rnbd_clt_get_sg_size(iu->sgt.sgl, sg_cnt)` rather than `blk_rq_bytes(rq)` (`msg.bi_size`), because discard and write-zeroes have non-zero `bi_size` but zero RDMA payload. [F46]
- In `rnbd_queue_rq()`, `rnbd_clt_dev_kick_mq_queue()` must be passed `RNBD_DELAY_IFBUSY` (`-1`) only when `rnbd_get_permit()` fails; failures after permit acquisition (`sg_alloc_table_chained()` or `rnbd_client_xfer_request()` returning `-EAGAIN`/`-ENOMEM`) release the permit and must pass a positive millisecond delay. [F51]

## Error Handling

- In `rnbd-clt.c`, `alloc_sess()`, `find_or_create_sess()`, `find_and_get_or_create_sess()`, `init_dev()`, and `rnbd_clt_map_device()` return `ERR_PTR()` on failure and never `NULL`, whereas `__find_and_get_sess()`, `rnbd_get_permit()`, and `rnbd_get_iu()` return `NULL`. In `rnbd-srv.c`, `rnbd_get_sess_dev()` returns `ERR_PTR(-ENXIO)` on failure, whereas `find_srv_sess_dev()` returns `NULL`. Because `sess->rtrs` can be `NULL` or `ERR_PTR`, validity checks in `close_rtrs()`, `wait_for_rtrs_connection()`, `wait_for_rtrs_disconnection()`, and `__find_and_get_sess()` must use `IS_ERR_OR_NULL(sess->rtrs)`. [F32, F33, F34]
- Callers of `rtrs_clt_query()` (`remap_devs()` and `find_and_get_or_create_sess()`) must check its return value before reading `struct rtrs_attrs`. In `rnbd_clt_parse_map_options()`, local integers passed to `match_int()` (`dest_port`, `nr_poll_queues`) and caller options (`*opt->dest_port`, `*opt->access_mode`, `*opt->nr_poll_queues`) must be initialized before parsing. [F35, F42]
- When the server opens a device (`RNBD_MSG_OPEN_RSP` received) but the client fails in `process_msg_open_rsp()` (such as rejecting `!rsp->logical_block_size` with `-EINVAL`) or `rnbd_client_setup_device()`, the client must call `send_msg_close()` with `rsp->device_id` to release the server-side `rnbd_srv_sess_dev` and `open_write_cnt`. [F56, F77]

## External Contracts

- `rnbd_dev_class.name` must remain `"rnbd-client"` and `"rnbd-server"`, and `state_show()` in `rnbd-clt-sysfs.c` must emit `"open\n"` for `DEV_STATE_MAPPED` and `"closed\n"` for `DEV_STATE_MAPPED_DISCONNECTED`. Wire structures in `rnbd-proto.h` (`rnbd_msg_hdr`: 4B, `rnbd_msg_sess_info`: 36B, `rnbd_msg_sess_info_rsp`: 36B, `rnbd_msg_open`: 264B, `rnbd_msg_close`: 8B, `rnbd_msg_open_rsp`: 56B) must keep their exact sizes, padding, and `__le16`/`__le32`/`__le64` encoding, and `process_rdma()` must only read `msg->prio` when `srv_sess->ver >= RNBD_PROTO_VER_MAJOR` and `usrlen >= sizeof(struct rnbd_msg_io)`. [F68, F69, F73, F80]

## Known Pitfalls

- `rnbd_clt_get_path_name()` must format `<pathname>@<sessname>` into `buf` without passing `buf` as a source argument to `snprintf()`, and `rnbd_clt_add_dev_symlink()` must allocate `strlen(dev->pathname) + strlen(dev->sess->sessname) + 2` bytes for `dev->blk_symlink_name` (returning `-ENOMEM` immediately if `kzalloc()` fails, or calling `kfree()` and setting `dev->blk_symlink_name = NULL` if a later step fails). [F41, F103]
