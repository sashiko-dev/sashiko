# X86 ARCHITECTURE (32-BIT AND 64-BIT)

This unit implements x86 host-side confidential computing support for AMD SEV-SNP (`arch/x86/virt/svm/`) and Intel TDX (`arch/x86/virt/vmx/tdx/`), alongside x86 framebuffer/PCI video helpers (`arch/x86/video/`) and host build/test tools (`arch/x86/tools/`). The SEV-SNP and TDX subsystems initialize hardware security tables (RMP and TDMR/PAMT), manage private encryption KeyIDs and page transitions, and expose SEAMCALL and RMP primitives to KVM and memory management, while `relocs.c` processes 32/64-bit ELF relocations for relocatable kernel images.

## Architecture & Data Flow

- `struct rmpentry_raw` bitfields are only valid when `!cpu_feature_enabled(X86_FEATURE_RMPREAD)`; when `X86_FEATURE_RMPREAD` is enabled, `get_rmpentry()` must use the `RMPREAD` instruction and `struct rmpentry_raw` may only be accessed via `lo` and `hi` for raw dumps, whereas on CPUs without `X86_FEATURE_RMPREAD`, `get_rmpentry()` must zero-initialize `struct rmpentry *e` (`memset(e, 0, sizeof(*e))`) and shift `e_raw->gpa << PAGE_SHIFT` so `e->gpa` is a byte address matching `RMPREAD`. [F27, F43]
- Before `rmpupdate()` executes `RMPUPDATE` on a `pfn`, it must call `adjust_direct_map(pfn, level)` to split any overlapping 2MB+ kernel direct-map entry when `level` is `PG_LEVEL_4K`, and retry `RMPUPDATE` while it returns `RMPUPDATE_FAIL_OVERLAP`. In `adjust_direct_map()`, the `rmp_level == PG_LEVEL_2M` alignment and end-PFN validity check (`!IS_ALIGNED(pfn, PTRS_PER_PMD) || !pfn_valid(pfn + PTRS_PER_PMD - 1)`) must run before the `if (rmp_level == PG_LEVEL_2M) return 0;` early return. [F66, F99]
- Callers of `rmpupdate()` (`rmp_make_private()` and `rmp_make_shared()`) must zero-initialize `struct rmp_state` with `memset(&state, 0, sizeof(state))` before setting fields so that `rsvd` and any unset fields (`gpa`, `asid`, `assigned`, `immutable`) passed to the `RMPUPDATE` instruction are zero. [F31]
- In `struct rmp_segment_desc`, `max_index` holds the entry count (`segment_size / sizeof(*desc->rmp_entry)`) whereas `size` holds the byte length (`segment_size`) passed to `memset()` in `snp_rmptable_init()`. In `get_raw_rmpentry()`, both `rst_index` and `segment_index` derived from `pfn` must be bounds-checked against `rst_max_index` and `desc->max_index` respectively and clamped with `array_index_nospec()` before indexing `rmp_segment_table` and `desc->rmp_entry`. [F52, F93]
- Entries in `rmp_segment_table` at indices below `rst_max_index` can be `NULL` for unmapped physical address segments, so every traversal (`free_rmp_segment_table()`, `snp_rmptable_init()`) and lookup (`get_raw_rmpentry()`) must null-check `rmp_segment_table[i]` before dereferencing `desc->rmp_entry` or `desc->size`. [F26]
- `set_rmp_segment_info()` must be used whenever setting `rmp_segment_shift` so that `rmp_segment_size` (computed with a 64-bit shift `1ULL << rmp_segment_shift`) and `rmp_segment_mask` (`rmp_segment_size - 1`) are updated in lockstep for `RST_ENTRY_INDEX()` and `RMP_ENTRY_INDEX()`. For a non-segmented RMP table, `probe_contiguous_rmptable_info()` must set `rst_max_index` to 1 and pass `RMPTABLE_NON_SEGMENTED_SHIFT` (52) to `set_rmp_segment_info()` so `RST_ENTRY_INDEX(paddr)` resolves any 52-bit physical address to index 0. [F40, F81, F83]
- The first `RMPTABLE_CPU_BOOKKEEPING_SZ` (`0x4000`) bytes at `probed_rmp_base` are reserved for CPU bookkeeping, so contiguous RMP entries and the segmented RMP Segment Table (`RST_SIZE`) must be mapped starting at `probed_rmp_base + RMPTABLE_CPU_BOOKKEEPING_SZ`. [F55]
- When reading an RMP Segment Table entry in `fixup_e820_tables_for_segmented_rmp()` and `setup_segmented_rmptable()`, `RST_ENTRY_MAPPED_SIZE(rst[i]) << 30` must be clamped to at most `rmp_segment_size` before computing the RMP segment byte size `PHYS_PFN(mapped_size) << 4`. [F53]
- In `snp_probe_rmptable_info()`, `MSR_AMD64_RMP_CFG` must only be read if `cpu_feature_enabled(X86_FEATURE_SEGMENTED_RMP)` is true, and `probe_segmented_rmptable_info()` must verify that `MSR_AMD64_RMP_SEGMENT_SHIFT(rmp_cfg)` falls within the min/max bounds in `cpuid_eax(0x80000025)`. [F97]
- RMP table coverage validation against `max_pfn` in `setup_contiguous_rmptable()` and `setup_segmented_rmptable()` must be performed during `snp_rmptable_init()` (not early boot in `snp_probe_rmptable_info()`), and contiguous coverage must round `rmp_end` up via `PFN_UP(rmp_end)` rather than `PHYS_PFN(rmp_end)`. [F96]
- When `init_sev_config()` parses `sev=nosnp` on bare metal (`!cpu_feature_enabled(X86_FEATURE_HYPERVISOR)`), it must clear both `X86_FEATURE_SEV_SNP` via `setup_clear_cpu_cap()` and `CC_ATTR_HOST_SEV_SNP` via `cc_platform_clear()`. [F44]
- In `__snp_leak_pages()`, the `while (npages--)` loop must advance `pfn++` and `page++` on every iteration while only linking `page->buddy_list` into `snp_leaked_pages_list` when `!PageCompound(page)` or `(PageHead(page) && compound_nr(page) <= npages)`. Broken by: inserting compound tail pages onto `snp_leaked_pages_list` or skipping `pfn++`/`page++` for tail pages. [F70]
- TDX private KeyIDs start at `_nr_mktme_keyids + 1` with the first TDX KeyID reserved as `tdx_global_keyid`, and `tdx_guest_keyid_alloc()` allocates from the inclusive range `[tdx_guest_keyid_start, tdx_guest_keyid_start + tdx_nr_guest_keyids - 1]`. In `tdx_init()`, host TDX enablement (`X86_FEATURE_TDX_HOST_PLATFORM`) must abort if `nr_tdx_keyids < 2` or `hibernation_available()` is true, and when `CONFIG_ACPI` and `CONFIG_SUSPEND` are enabled, it must disable ACPI S3 by setting `acpi_suspend_lowlevel = NULL`. [F63, F106]
- `alloc_tdmr_list()` must zero-initialize the `tdmr_array` buffer with `__GFP_ZERO` because `fill_out_tdmrs()` relies on `tdmr->size == 0` to distinguish an unused `struct tdmr_info` slot from a populated one and leaves unused `reserved_areas` entries and alignment padding untouched for `TDH.SYS.CONFIG`. [F33]
- In `fill_out_tdmrs()`, when the current `tdmr` at `tdmr_idx` already has a non-zero `tdmr->size`, the loop must skip any `tmb` where `end <= tdmr_end(tdmr)` before incrementing `tdmr_idx`, and clamp `start = tdmr_end(tdmr)` when `start < tdmr_end(tdmr)` before populating the new `tdmr_entry`. [F71]
- In `tdmr_populate_rsvd_holes()`, when a `tdx_memblock` overlaps `[tdmr->base, tdmr_end(tdmr))` with `start <= prev_end`, the loop must update `prev_end = end` before `continue`, and after the loop exits must call `tdmr_add_rsvd_area()` if `prev_end < tdmr_end(tdmr)`. [F72]
- `tdmr_get_pamt_sz()` must round `nr_pamt_entries * pamt_entry_size` up to `PAGE_SIZE` via `ALIGN(pamt_sz, PAGE_SIZE)` for each page level before `tdmr_set_up_pamt()` sums `pamt_size[pgsz]` and shifts right by `PAGE_SHIFT` (`tdmr_pamt_size >> PAGE_SHIFT`) to allocate pages. [F86]
- In `paddr_is_tdx_private()`, the `switch (args.rcx)` on the `TDH_PHYMEM_PAGE_RDMD` page type must handle `PT_RSVD` by returning `is_pamt_page(phys)` rather than returning `false` like `PT_NDA` or `true` like the `default` branch. [F76]
- In `get_tdx_sys_info_td_conf()`, `sysinfo_td_conf->num_cpuid_config` read from TDX metadata must be validated against `ARRAY_SIZE(sysinfo_td_conf->cpuid_config_leaves)` and `ARRAY_SIZE(sysinfo_td_conf->cpuid_config_values)` before populating those arrays. [F58]
- In `arch/x86/tools/relocs.c`, section filtering in `print_absolute_relocs()` and `walk_relocs()` must stay in lockstep: both must skip sections where `!(sec_applies->shdr.sh_flags & SHF_ALLOC)` or `sec_applies->shdr.sh_type == SHT_NOTE`. [F51]
- In `read_symtabs()` and `sym_index()` in `arch/x86/tools/relocs.c`, `SHT_SYMTAB` entries are byte-swapped in place during `read_symtabs()`, whereas `SHT_SYMTAB_SHNDX` (`xsymtab`) entries remain in little-endian format and must be converted with `elf32_to_cpu(xsymtab[index])` when indexed in `sym_index()`. [F64]
- In `do_reloc64()` and `do_reloc32()`, `shn_abs` must be computed as `(sym->st_shndx == SHN_ABS) && !is_reloc(S_REL, symname)` so that linker-defined `SHN_ABS` symbols matching `S_REL` bypass the `if (shn_abs)` guard and have their relocation offsets emitted via `add_reloc()`. [F78]

## Synchronization

- `construct_tdmrs()` must execute `smp_wmb()` after populating `tdx_tdmr_list` and its PAMTs/reserved areas, and `is_pamt_page()` must execute a paired `smp_rmb()` before reading `tdmr_list->nr_consumed_tdmrs` and `tdmr_entry()`, because `tdx_dump_mce_info()` reads `tdx_tdmr_list` locklessly from #MC context. [F11]
- `tdx_memlist` is protected by `mem_hotplug_lock`: `init_tdx_module()` must hold `get_online_mems()` across `build_tdx_memlist(&tdx_memlist)` and across `free_tdx_memlist(&tdx_memlist)` on error rollback before calling `put_online_mems()`, synchronizing with `tdx_memory_notifier()` and `is_tdx_memory()`. [F12]
- On error rollback in `init_tdx_module()` after `config_tdx_module()` succeeds (`err_reset_pamts`), `wbinvd_on_all_cpus()` and `tdmrs_quirk_reset_pamt_all(&tdx_tdmr_list)` (which issues `movdir64b` followed by `mb()` in `tdx_quirk_reset_paddr()`) must run before `tdmrs_free_pamt_all()` frees PAMT pages. [F17]
- `snp_leaked_pages_list` and `snp_nr_leaked_pages` are protected by `snp_leaked_pages_list_lock`, which `__snp_leak_pages()` must hold across list insertion of `page->buddy_list` and increments of `snp_nr_leaked_pages`. [F19]

## Object Lifetimes

- `free_rmp_segment_table()` must unmap every populated `desc->rmp_entry`, free each `struct rmp_segment_desc`, free the `rmp_segment_table` page, and set `rmp_segment_table = NULL` so subsequent `get_raw_rmpentry()` calls return `ERR_PTR(-ENODEV)` instead of dereferencing freed memory. [F5]
- In `setup_segmented_rmptable()`, `rst_max_index` must not be narrowed to `max_index + 1` until after all segment allocations and the `ram_pa_max > ram_pa_end` validation succeed, so `rst_max_index` covers all allocated indices when `free_rmp_segment_table()` runs on error at `e_unmap`. [F6]

## API Contracts

- `psmash()` returns negative kernel errnos (`-ENODEV`, `-EINVAL`) for precondition failures and positive hardware `PSMASH` instruction return codes (such as `PSMASH_FAIL_INUSE`) in the same `int` return value, whereas `rmp_make_private()` and `rmp_make_shared()` translate all `RMPUPDATE` failures into negative errnos (`-ENODEV`, `-EFAULT`). Broken by: checking `if (psmash(pfn) < 0)` and treating positive hardware codes as success. [F21]
- `rmp_make_private(pfn, gpa, level, asid, immutable)` takes the host location as a page frame number (`pfn`, shifted by `PAGE_SHIFT` inside `rmpupdate()`) but the guest address `gpa` as a byte physical address stored directly into `state.gpa` without shifting. [F35]
- In `__snp_lookup_rmpentry()`, after reading the target PFN's RMP entry into `e`, the page size level `*level` must be derived from a second `get_rmpentry(pfn & PFN_PMD_MASK, &e_large)` call (`RMP_TO_PG_LEVEL(e_large.pagesize)`) rather than from `e->pagesize`. [F68]
- Host SEV-SNP runtime and initialization paths in `arch/x86/virt/svm/sev.c` (`__mfd_enable`, `__snp_enable`, `snp_rmptable_init`, `__snp_lookup_rmpentry`, `psmash`, `rmpupdate`, `kdump_sev_callback`) must check `cc_platform_has(CC_ATTR_HOST_SEV_SNP)` rather than `X86_FEATURE_SEV_SNP`. [F95]
- Once `tdx_memlist` is populated (`!list_empty(&tdx_memlist)`), `tdx_memory_notifier()` must return `NOTIFY_BAD` on `MEM_GOING_ONLINE` whenever `[mn->start_pfn, mn->start_pfn + mn->nr_pages)` is not contained within a `tdx_memblock` in `tdx_memlist` (`!is_tdx_memory(...)`). [F130]

## Error Handling

- `construct_tdmrs()` frees all allocated PAMTs via `tdmrs_free_pamt_all(tdmr_list)` internally when `tdmrs_set_up_pamt_all()` or `tdmrs_populate_rsvd_areas_all()` fails, so callers must not call `tdmrs_free_pamt_all()` again when `construct_tdmrs()` returns an error (e.g., `init_tdx_module()` must jump to `err_free_tdmrs`, not `err_free_pamts`). [F3]
- In `init_tdx_module()`, all cleanup labels (`err_reset_pamts`, `err_free_pamts`, `err_free_tdmrs`, `err_free_tdxmem`) jump to `out_put_tdxmem` to release `put_online_mems()` and `return ret;`, so teardown steps in that path must not overwrite the non-zero `ret` from the failing stage. [F30]
- `get_raw_rmpentry()` returns an `ERR_PTR`-encoded error (`-ENODEV` or `-EFAULT`) rather than `NULL` on failure, so every caller (`get_rmpentry()`, `dump_rmpentry()`) must check `IS_ERR()` before dereferencing the returned `struct rmpentry_raw *`. [F22]

## External Contracts

- In `do_reloc64()` and `emit_relocs()`, 64-bit kernel relocation offsets must fit in a signed 32-bit integer (`(int32_t)offset == (int64_t)offset`), and non-realmode relocation tables (`relocs64`, `relocs32`) must be preceded by a `0` sentinel word (`write_reloc(0, stdout)`), whereas `--realmode` tables are preceded by their element `count`. [F65]

## Known Pitfalls

- In `setup_segmented_rmptable()`, the 32-bit `unsigned int` segment loop index `i` must be widened to `u64` before left-shifting by `rmp_segment_shift` (`pa = (u64)i << rmp_segment_shift`) to compute the segment's covered physical base address. [F80]
- In the `while (pfn_i < pfn_end)` loop of `dump_rmpentry()`, the `IS_ERR(e_raw)` error path (and any new `continue` branch) must increment `pfn_i++` before executing `continue`. [F69]
- In `init_sev_config()`, every recognized option branch inside `while ((s = strsep(&str, ",")))` must terminate with `continue` so execution does not fall through into the `warn:` label at the bottom of the loop. [F79]
- In `arch/x86/tools/relocs.c`, `add_reloc()` reallocates `r->offset` via `realloc()` when `r->count == r->size`, so callers must never retain interior pointers into `relocs16.offset`, `relocs32.offset`, or `relocs64.offset` across `add_reloc()` or `walk_relocs()` calls. [F50]
- In `arch/x86/tools/relocs.c`, format strings for `Elf_Ehdr`, `Elf_Shdr`, `Elf_Sym`, and `Elf_Rel` address, offset, and size fields must use the `ELF_BITS`-conditional `FMT` macro (`PRIu64`/`PRIu32`) or `ELF_BITS`-selected `PRIx64`/`PRIx32` specifiers rather than fixed-width specifiers like `%lx` or `PRIx64`. [F92]
