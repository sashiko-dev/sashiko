# SOUND

This unit defines core ALSA subsystem headers (sound cards, PCM streams, mixer controls, AC'97, HD-Audio, and DMA memory management), implements HD-Audio codec drivers for Realtek ALC series and Silicon Labs Si3054 codecs, and provides the ALSA USB audio mixer, PCM substream engine, UAC1/UAC2/UAC3 descriptor parsers, power domain management, and vendor-specific USB mixer quirks.

## Architecture & Data Flow
- After `snd_ctl_add()`, control names/IDs must only be changed via `snd_ctl_rename()` or `snd_ctl_rename_id()` so `card->ctl_hash` and `card->ctl_numids` stay in sync; `snd_ctl_elem_id.numid` is 1-based (`0` is invalid) while `index` and `vd[]` offsets are 0-based; `struct snd_kcontrol` allocations must size `vd[]` via `struct_size(..., vd, count)` and set `kctl->count = count` before indexing `kctl->vd[]` (`__counted_by(count)`). [F44, F57, F97]
- `snd_pcm_set_runtime_buffer()` must be used to assign or clear `runtime->dma_buffer_p` so cached `runtime->dma_area`, `dma_addr`, and `dma_bytes` stay synchronized; `status->hw_ptr` and `control->appl_ptr` wrap modulo `runtime->boundary` (not `buffer_size`). [F46, F63]
- `struct nhlt_endpoint` and `struct nhlt_fmt_cfg` end with variable-length `struct nhlt_specific_cfg`, so iterating `nhlt->desc` must advance by `(u8 *)epnt + epnt->length` and `fmt->fmt_config` by `cfg->config.caps + cfg->config.size`. Broken by: pointer increment or array indexing. [F67]
- In `struct hdac_bus`, `caddr_tbl` has 16 slots (`HDA_MAX_CODEC_ADDRESS + 1`), whereas `corb`/`rirb` (`cmds`, `res`) and `last_cmd` have only `HDA_MAX_CODECS` (8) slots. Broken by: indexing `rirb` or `last_cmd` with codec address `>= 8`. [F71]
- `struct alc_spec` must keep `struct hda_gen_spec gen` as its first member at offset 0 because `snd_hda_gen_*` callbacks cast `codec->spec` directly to `struct hda_gen_spec *`. [F229]
- In Realtek quirk/ID tables, narrower `coef_mask` entries in `rename_tbl`, specific `SND_PCI_QUIRK` entries, and `HDA_CODEC_ID_REV` entries must precede broader mask, `SND_PCI_QUIRK_VENDOR`, or `HDA_CODEC_ID` entries; in `alc269.c`, `SND_PCI_QUIRK_VENDOR` entries belong in `alc269_fixup_vendor_tbl` (not `alc269_fixup_tbl`), and `alc269_fallback_pin_fixup_tbl` allows at most one entry per `(codec, subvendor)`. [F86, F207, F208, F209, F210, F223]
- In `alc_update_headset_mode()`, `ALC_HEADSET_MODE_UNPLUGGED` must reset `spec->current_headset_type = ALC_HEADSET_TYPE_UNKNOWN`, and `ALC_HEADSET_MODE_MIC` must skip the post-switch `snd_hda_set_pin_ctl_cache` block; on S3/S4 resume, `alc_fixup_headset_mode` (`HDA_FIXUP_ACT_INIT`) must reset `current_headset_mode` and `current_headset_type` to `UNKNOWN` and `alc269_resume` must call `alc_write_gpio_data(codec)` when `spec->gpio_data != 0`. [F184, F214, F261]
- Realtek fixup state: enabling VREF on an output/amp pin at `HDA_FIXUP_ACT_INIT` requires `spec->gen.keep_vref_in_automute = 1`; VREF mute LEDs (`vref_mute_led_set`/`vref_micmute_led_set`) require setting `mute_led_nid`/`cap_mute_led_nid` and `codec->power_filter = led_power_filter`; `alc_fixup_no_depop_delay()` must set both `spec->no_depop_delay = 1` and `codec->depop_delay = 0`. [F188, F195, F222]
- For multi-channel `struct usb_mixer_elem_info` (`cval->cmask != 0`), bit `c` in `cmask` and `ch_readonly` maps to 1-based USB `channel = c + 1` and `BIT(c + 1)` in `cval->cached`, whereas `cval->cache_val[idx]` is indexed by the dense 0-based count of set bits in `cmask` (so `restore_mixer_value()` must increment `idx` for every set bit in `cmask` even when uncached); `snd_usb_mixer_notify_id()` and `snd_usb_mixer_interrupt_v2()` must clear affected `info->cached` bits before `snd_ctl_notify()`. [F331, F350, F366]
- Raw USB audio descriptors must be validated via `snd_usb_validate_audio_desc(p, protocol)` before accessing protocol-specific or variable-length fields; `check_input_term()` must zero `state->termbitmap` and `__check_input_term()` must `test_and_set_bit(id, state->termbitmap)` to reject cycles; `parse_audio_unit()` and `snd_usb_mixer_controls()` must mark visited IDs in `state.unitbitmap`. [F347, F362, F364]
- USB PCM data flow: `urb_ctx_queue_advance()` must receive PCM DMA bytes consumed (excluding framing overhead like DSD DoP markers or `copy_to_urb_quirk` headers); `retire_capture_urb()` and `copy_to_urb()` must split `memcpy` calls that wrap past `subs->buffer_bytes`; `snd_usb_pcm_prepare()` must only call `start_endpoints(subs)` when `!subs->lowlatency_playback` if `substream->stream == SNDRV_PCM_STREAM_PLAYBACK`. [F345, F354, F359]

## Synchronization
- Control locking: `snd_power_ref_and_wait(card)` must precede `card->controls_rwsem`, `card->controls_rwlock` nests inside `card->controls_rwsem`, and `snd_ctl_file.read_lock` nests inside `card->controls_rwlock`; `snd_ctl_find_numid()`/`find_id()`/`find_id_mixer()` return unreferenced `snd_kcontrol *` pointers requiring `card->controls_rwsem`; `snd_ctl_notify()` is atomic-safe whereas `snd_ctl_notify_one()` takes sleeping `snd_ctl_layer_rwsem`. [F15, F128, F129, F130]
- PCM stream locking: `snd_pcm_start()`, `snd_pcm_stop()`, `snd_pcm_drain_done()`, `__snd_pcm_set_state()`, and `snd_pcm_period_elapsed_under_stream_lock()` require holding `snd_pcm_stream_lock*`, whereas `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` acquire it internally; locking a second substream requires `snd_pcm_stream_lock_irqsave_nested()`; locking `substream->group` while holding `substream->self_group` must pin `group->refs` on trylock failure, drop the substream lock, lock `group` then `substream`, and recheck `substream->group == group`. [F16, F17, F18, F19, F125]
- When `pcm->nonatomic` is false, `trigger`, `pointer`, `get_time_info`, and `ack` run under spinlock `substream->self_group.lock` with IRQs disabled and must not sleep; when `pcm->nonatomic` is true, `snd_pcm_stream_lock*` takes `substream->self_group.mutex`, so `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` sleep; `__snd_pcm_lib_xfer` must guard user copies with `runtime->buffer_accessing` rather than holding `runtime->buffer_mutex`. [F122, F123, F126]
- HDA & Realtek locks: `snd_hdac_stream_release_locked()` and `snd_hdac_ext_stream_decouple_locked()` require holding `bus->reg_lock` (non-`_locked` variants acquire it internally); `coef_mutex_lock()` must call `snd_hda_power_up_pm(codec)` before locking `spec->coef_mutex` (and unlock before `power_down_pm`), and callers holding `guard(coef_mutex)(codec)` must use `__alc_*_coefex_idx()`. [F134, F153]
- USB PCM & mixer locking: `prepare_playback_urb()`, `retire_playback_urb()`, and `retire_capture_urb()` must protect `hwptr_done`, `transfer_done`, `inflight_bytes`, and `period_elapsed_pending` with `subs->lock` and drop `subs->lock` before calling `snd_pcm_period_elapsed*()` (`prepare_playback_urb()` must use `snd_pcm_period_elapsed_under_stream_lock()` when `in_stream_lock` is true); `snd_usb_pcm_playback_ack()` must call `snd_usb_queue_pending_output_urbs(subs, true)` and return its result directly; `start_endpoints()`/`stop_endpoints()` must track state on `subs->flags` and `sync_pending_stops(subs)` must precede closing or restarting stopped endpoints; runtime USB callbacks must guard device access with `snd_usb_lock_shutdown(chip)`, which nests outside `chip->mutex`. [F299, F300, F301, F304, F305, F408]

## Object Lifetimes
- `snd_ctl_add()`, `snd_ctl_replace()`, `snd_usb_mixer_add_list()`, and `snd_usb_mixer_add_control()` consume ownership of `kctl` (and `kctl->private_data` when `private_free` is set) and call `snd_ctl_free_one(kctl)` on failure; callers must never free `kctl` or `private_data` after calling them. [F2, F289]
- `snd_card_ref()` and `snd_lookup_minor_data()` (when returning non-NULL) acquire a reference released via `snd_card_unref(card)`; when using `snd_devm_card_new()` with subsequent devres allocations accessed by `card->private_free` or `.dev_free`, any probe error before `snd_card_register()` must call `snd_card_free()` or `snd_card_free_on_error()`. [F4, F107]
- `snd_hda_power_up()`/`snd_hda_power_up_pm()` increment the PM counter even on error and require a matching `power_down` call on failure; `CLASS(snd_hda_power, pm)(codec)` and `CLASS(snd_hda_power_pm, pm)(codec)` always call `power_down` at scope exit even on error (storing the status in `pm.err`). [F7, F37]
- Realtek & USB lifetimes: `alc_alloc_spec()` must initialize `codec->spec` and `spec->coef_mutex` before `alc_codec_rename_from_preset(codec)`, and any `alc*_probe` failure after `alc_alloc_spec()` must call `snd_hda_gen_remove()` (or `alc269_remove()`, which must call `hda_component_manager_free(&spec->comps, &comp_master_ops)` before `snd_hda_gen_remove()`); arrays passed to `snd_hda_add_verbs()` or `spec->gen.preferred_dacs` must be `static` and zero-terminated; `snd_usb_mixer_disconnect()` and `snd_usb_mixer_free()` must `usb_kill_urb()` both `mixer->urb` and `mixer->rc_urb` before calling `mixer->private_free()` or freeing buffers. [F156, F160, F230, F231, F269, F306]

## API Contracts
- Control & PCM contracts: multi-element (`count > 1`) control callbacks must compute 0-based element offsets via `snd_ctl_get_ioff*()` (which clamp with `array_index_nospec()`); `snd_kcontrol_info_t` callbacks must leave `uinfo->access == 0`; `hw_param_mask*()`/`constrs_mask()` require `hw_is_mask(var)` and `hw_param_interval*()`/`constrs_interval()` require `hw_is_interval(var)`; `params_period_size()`/`params_buffer_size()` and `snd_pcm_runtime.period_size`/`buffer_size` are in frames, whereas `params_period_bytes()`/`params_buffer_bytes()` and `snd_pcm_hardware.*_bytes_*` are in bytes and `snd_pcm_hardware.formats` is a `SNDRV_PCM_FMTBIT_*` bitmask; `snd_pcm_running(substream)` must be used to check active DMA (includes `SNDRV_PCM_STATE_DRAINING`); `snd_sgbuf_get_addr()`/`get_page()`/`get_chunk_size()` must be used for SG/non-contiguous/vmalloc buffers. [F36, F56, F60, F61, F81, F131, F137, F145]
- Sentinel & table contracts: arrays passed to `snd_pci_quirk_lookup*()`, `snd_hda_sequence_write()`, `snd_pcm_add_chmap_ctls()`, `snd_ctl_add_followers()`, `alc_process_coef_fw()` (`struct coef_fw`), and USB mixer maps (`usbmix_name_map`, `usbmix_selector_map`, `usbmix_connector_map`, `usbmix_ctl_map`, `procunit_value_info`, `std_mono_table`) must end with a zero/NULL sentinel; `snd_pcm_hw_rule_add()` variadic deps must end with `-1` and pass at most 4 non-negative dep IDs. [F69, F82, F117, F198, F355]
- HDA & Realtek contracts: NHLT DMIC callers must verify `device_config.config_type == NHLT_CONFIG_TYPE_MIC_ARRAY`; HDA codec PM callbacks must bracket with `snd_hdac_enter_pm()`/`snd_hdac_leave_pm()` and paths inside them must use `snd_hdac_power_up_pm()`/`down_pm()`; 8/16-bit HDA MMIO accesses/polls must use `snd_hdac_reg_*` / `snd_hdac_chip_*` / `snd_hdac_stream_*_poll` for `bus->aligned_mmio`; `alc_update_coefex_idx()`/`alc_update_coef_idx()` OR `bits_set` directly into `val & ~mask` without masking `bits_set`, whereas `alc_fix_pll_init()` takes a 0-based bit shift index `coef_bit`; `snd_hda_gen_add_mute_led_cdev()`/`add_micmute_led_cdev()` must run at `HDA_FIXUP_ACT_PRE_PROBE`, while `rename_ctl()` and `spec->gen.pcm_rec` modifications must run at `HDA_FIXUP_ACT_BUILD`. [F30, F112, F114, F177, F271, F275, F276]
- USB audio contracts: `snd_usb_pcm_has_fixed_rate()` and `find_format()` accept a nullable `subs`; `snd_usb_ctl_msg()` requires `data` in writable memory even for `USB_DIR_OUT` (`memcpy(data, buf, size)`), and URB buffers (`usb_fill_int_urb`/`usb_fill_control_urb`) must be heap-allocated; `snd_usb_mixer_add_list()` requires `is_std_info = false` for bare `struct usb_mixer_elem_list` (e.g. from `add_single_ctl_with_resume()`), and `for_each_mixer_elem` loops must check `list->is_std_info` before `mixer_elem_list_to_info()`; `snd_usb_hw_params()` and `snd_usb_pcm_prepare()` must set `UAC3_PD_STATE_D0` via `snd_usb_pcm_change_state()` and configure/prepare `subs->sync_endpoint` before `subs->data_endpoint` (passing `is_sync_ep = (fmt == sync_fmt)` to `snd_usb_endpoint_open()`). [F315, F329, F351, F376, F378, F397, F398, F411]

## Error Handling
- Return value conventions: `snd_hdac_read_parm*()`, `snd_hdac_codec_read()`, and `snd_hda_param_read()` return `(int)-1` on failure (whereas `_snd_hdac_read_parm()` returns `0` or negative errno); `snd_hda_codec_device_init()` returns `ERR_PTR` while `snd_hda_codec_pcm_new()`, `snd_ctl_new1()`, and `snd_devm_alloc_dir_pages()` return `NULL`; `snd_pcm_format_signed()`/`unsigned()`/`*_endian()` return `1`, `0`, or `-EINVAL` (tri-state, never test as boolean) and `snd_pcm_format_width()`/`physical_width()`/`size()`/`params_width()` return `-EINVAL` on unknown/variable-width formats; `alc_parse_auto_config()` returns `1` on success and `< 0` on error (probe functions must check `err < 0` and `return 0`). [F27, F28, F33, F34, F167]
- Realtek & USB error handling: `codec->bus->pci` can be `NULL` on non-PCI buses; `alc_get_hp_pin()` and `alc_find_ext_mic_pin()` return `0` when no pin matches; `snd_hda_find_mixer_ctl()` returns `NULL` when absent; if `snd_usb_hw_params()` fails after `snd_media_start_pipeline(subs)`, it must call `close_endpoints()`, `snd_usb_unlock_shutdown()`, and `snd_media_stop_pipeline()`; if `start_endpoints()` fails on either endpoint, it must clear that endpoint's `SUBSTREAM_FLAG_*_EP_STARTED` bit and call `stop_endpoints(subs, false)`; `.get` callbacks returning `filter_error(cval, err)` must initialize their output value on error because `ignore_ctl_error` converts errors to `0`; `restore_mixer_value()` and `connector_mixer_resume()` must return `0` on USB control errors. [F169, F170, F172, F285, F286, F316, F400]

## External Contracts
- `SNDRV_PCM_RATE_*` bit positions in `include/sound/pcm.h` must never be renumbered (and must use unsigned `1U << n` shifts), and `rates[]` / `snd_pcm_known_rates` must remain in exact bit-position order; `SNDRV_CTL_ELEM_ACCESS_SKIP_CHECK` and `SNDRV_CTL_ELEM_ACCESS_LED_MASK` must be masked out before copying `snd_ctl_elem_info` to userspace; non-primary HDA codecs (`codec->core.addr > 0`) without `codec->ctl_dev_id` must offset mixer `kctl->id.index` by `10 * codec->core.addr` rather than setting `kctl->id.device`; UAC class-specific control requests (`snd_usb_ctl_msg()`, `get_ctl_value()`, `snd_usb_mixer_set_ctl_value()`) must pack `wValue` (`validx`) as `(control << 8) | channel`, and `snd_usb_set_cur_mix_value()` must check `cval->master_readonly` or `cval->ch_readonly & BIT(channel - 1)` before writing. [F58, F59, F89, F138, F318, F393]

## Known Pitfalls
- Core ALSA pitfalls: `snd_hdac_chip_update*`, `snd_hdac_update*`, and `snd_hdac_stream_update*` evaluate `(read & ~(mask)) | (val)` without masking `val` by `mask`; after `snd_array_for_each(array, idx, ptr)` finishes without `break`, `ptr` is non-NULL one-past-the-end (must check `idx < array->used`), and `snd_array_new()` invalidates existing element pointers via `krealloc()`; directly narrowing `struct snd_interval` bounds requires `snd_interval_checkempty(i)` (not cached `snd_interval_empty(i)`), and single-valued intervals (`snd_interval_single(i)`) must be read via `snd_interval_value(i)` (not `i->min`); `dev_to_snd_card(p)` is only valid on `card->card_dev`, never `card->dev`. [F77, F78, F83, F84, F98, F102]
- Realtek & USB pitfalls: `alc_fixup_gpio1`/`2`/`3`/`4` suffixes are hex bitmasks (`0x01`..`0x04`, so `gpio3` is GPIO0+GPIO1 and `gpio4` is GPIO2); in `struct hda_fixup`, `.chain_id` has no effect unless `.chained = true` or `.chained_before = true` is set; `spec->gen.mute_bits` is a `u64` indexed by `hda_nid_t` (`>= 32`), requiring `1ULL << nid`; `__check_input_term()` mutates `struct usb_audio_term *term` in place, so callers must assign `term->id` and `term->type` after it returns; `get_min_max_with_quirks()` must pass `cval->min`/`max` through `convert_signed_value()` before computing `dBmin`/`dBmax`, while `get_max_exposed()` and `get_relative_value()` must guard against `cval->res == 0` and use `DIV_ROUND_UP(cval->max - cval->min, cval->res)`; shifting a `u8` by 24 bits (`SND_DJM_DEVICE_SHIFT`) into `unsigned long private_value` requires an unsigned cast before `<< 24`. [F180, F211, F224, F335, F370, F371, F372, F373]
