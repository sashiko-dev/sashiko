# GENERIC INCLUDE/ASM HEADER FILES

Provides architecture-independent fallback implementations, default macros, inline primitives, linker script templates, and UAPI ABI definitions under `include/asm-generic/` and `include/uapi/asm-generic/` for MMIO/port I/O, memory barriers, bitops, spinlocks, per-CPU operations, page table allocation, user-memory access, 64-bit division, and syscall/signal/ioctl ABIs.

## Architecture & Data Flow

- In `vmlinux.lds.h`, `DATA_DATA` must place `*(.data..do_once)` outside `[__start_once, __end_once]` (which bounds `*(.data..once)`) so `clear_warn_once` does not reset `DO_ONCE()` state; because `PER_CPU_BASE_SECTION` is `".data"` on `!CONFIG_SMP`, `DATA_DATA` must also include `*(.data..decrypted)` and `*(.data..shared_aligned)` rather than leaving them only in `PERCPU_INPUT`. [F37, F127]
- In `vmlinux.lds.h`, `BOUNDED_SECTION_{PRE,POST}_LABEL()` must place only `KEEP(*(_sec_))` between labels (sections with `.gnu.linkonce.` headers must use `HEADERED_SECTION_{PRE,POST}_LABEL()`); `_OF_TABLE_1(name)` must follow `KEEP(*(__<name>_of_table))` with `KEEP(*(__<name>_of_table_end))` in `INIT_DATA`, while `.pci_fixup` and `FW_LOADER_BUILT_IN_DATA` stay in `RO_DATA`. [F69, F111]
- In `vmlinux.lds.h`, `NOTES` must discard `*(.note.GNU-stack)` and `*(.note.gnu.property)` in a `/DISCARD/` block before `.notes` collects `BOUNDED_SECTION_BY(.note.*, _notes)`; `SANITIZER_DISCARDS` must be enabled for `CONFIG_GCOV_KERNEL`, `CONFIG_KASAN_GENERIC`, and `CONFIG_KCSAN` to discard `*(.eh_frame)` (`!CONFIG_UNWIND_TABLES`) and `*(.init_array*)` (`!CONFIG_CONSTRUCTORS`). [F128, F142]
- In `vmlinux.lds.h`, `NOINSTR_TEXT` must keep both `*(.noinstr.text)` and `*(.cpuidle.text)` within `[__noinstr_text_start, __noinstr_text_end]`, and `SCHED_DATA` must order `*(__*_sched_class)` in descending priority (`__stop`, `__dl`, `__rt`, `__fair`, `__ext`, `__idle`) between `__sched_class_highest` and `__sched_class_lowest`. [F126, F130]
- In 32-bit `do_div(n, base)` (`div64.h`), the `is_power_of_2(__base)` branch must precede `__builtin_constant_p(__base) && __base != 0` (as `__div64_const32()` overflows `___m` to 0 and divides by zero on power-of-two divisors) and dividends with `(n >> 32) != 0` must dispatch to `__div64_32(&(n), __base)`. [F78, F89]
- In `cmpxchg-local.h`, `__generic_cmpxchg_local()` must mask `old` and `new` to the byte width (`0xffu`, `0xffffu`, `0xffffffffu`) in the 1-, 2-, and 4-byte `switch (size)` cases before comparing `prev == old`, and must reject `size == 8` when `sizeof(unsigned long) != 8` via `wrong_size_cmpxchg(ptr)`. [F84]
- Under `CONFIG_UACCESS_MEMCPY` (`uaccess.h`), `__get_user_fn()`, `__put_user_fn()`, `__get_kernel_nofault()`, and `__put_kernel_nofault()` must use `get_unaligned()`/`put_unaligned()` for multi-byte transfers; in `flat.h`, `flat_{get,put}_addr_{from,at}_rp()` must use `copy_{from,to}_user()` when `!CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`. [F61, F62]
- In `sections.h`, `memory_intersects(begin, end, virt, size)` must test `virt < end && vend > begin` (`vend = virt + size`), generic code must not reference optional `_text`/`_data`, and `__is_kernel()` must check both `[_stext, _end)` and `[__init_begin, __init_end)`; under `CONFIG_FLATMEM` (`memory_model.h`), `pfn_valid(pfn)` must check `pfn >= ARCH_PFN_OFFSET` before subtracting it. [F54, F55, F129]
- In `mmiowb.h`, `mmiowb_set_pending()` must set `ms->mmiowb_pending` only when `ms->nesting_count` is non-zero, and `mmiowb_spin_unlock()` must clear `ms->mmiowb_pending = 0` before calling `mmiowb()` and decrementing `ms->nesting_count`; in `cacheflush.h`, `copy_to_user_page()` must call `flush_icache_user_page()` after `memcpy()`. [F36, F122]

## Synchronization

- In `struct qspinlock` and `struct qrwlock`, sub-word union fields (`locked`, `pending`, `locked_pending`, `tail`, `wlocked`) must reverse order between `#ifdef __LITTLE_ENDIAN` and `#else` so `locked`/`wlocked` alias bits 0..7; `queued_spin_unlock()` and `queued_write_unlock()` must use `smp_store_release(&lock->{locked,wlocked}, 0)` rather than clearing the full 32-bit word. [F39, F40, F67]
- In `qrwlock.h`, `queued_read_trylock()` and `queued_read_lock()` must test `!(cnts & _QW_WMASK)` after `atomic_add_return_acquire(_QR_BIAS, &lock->cnts)`; on failure, `queued_read_trylock()` must subtract `_QR_BIAS`, whereas `queued_read_lock()` must call `queued_read_lock_slowpath(lock)` without subtracting `_QR_BIAS` first. [F6, F80]
- In `qspinlock.h`, `queued_spin_is_locked()` must test the full 32-bit `atomic_read(&lock->val)` (not just `_Q_LOCKED_MASK` or `lock->locked`), whereas `queued_spin_is_contended()` must mask out `_Q_LOCKED_MASK` (`atomic_read(&lock->val) & ~_Q_LOCKED_MASK`). [F79]
- In `ticket_spinlock.h`, contended `ticket_spin_lock()` must emit `smp_mb()` after `atomic_cond_read_acquire()` for RCsc ordering; `ticket_spin_unlock()` must update only the 16-bit serving half via `(u16 *)lock + IS_ENABLED(CONFIG_CPU_BIG_ENDIAN)` and `smp_store_release(ptr, (u16)val + 1)`; `ticket_spin_is_contended()` must cast `(val >> 16) - (val & 0xffff)` to `s16` before comparing `> 1`. [F15, F41, F94]
- In `barrier.h`, `smp_cond_load_relaxed(ptr, cond_expr)` must evaluate `ptr` once into `__PTR` outside the loop and load `READ_ONCE(*__PTR)` into the exact identifier `VAL` for `cond_expr`; `smp_mb__after_switch_mm()` must default to `smp_mb()`; all `virt_*` barriers must expand to `__smp_*` barriers even when `!CONFIG_SMP`. [F12, F13, F81]
- In `bitops/`, `arch_test_and_{set,clear,change}_bit()` must unconditionally execute `raw_atomic_long_fetch_*()` without an early `READ_ONCE()` short-circuit to preserve full barrier semantics; `arch___clear_bit_unlock()` and `__clear_bit_unlock()` use non-atomic `READ_ONCE()` + `raw_atomic_long_set_release()` and require no concurrent bit modifications in the same word. [F8, F9]
- `generic_test_bit()` and `generic_test_bit_acquire()` must mask `nr` with `(BITS_PER_LONG - 1)` when shifting `addr[BIT_WORD(nr)]`, and `generic_test_bit()` must retain `const volatile unsigned long *` on `addr` without casting away `volatile` (unlike `const_test_bit()`, which is only for compile-time constants). [F10, F90]
- In `rwonce.h`, `read_word_at_a_time()` must be `__no_sanitize_or_inline`, check 1 byte via `kasan_check_read(addr, 1)` and `kcsan_check_read(addr, 1)`, and dereference `*(unsigned long *)addr` directly rather than via `READ_ONCE()`; `READ_ONCE_NOCHECK(x)` must read through `__no_sanitize_or_inline` `__read_once_word_nocheck()`. [F11, F124]
- In `percpu.h`, `this_cpu_generic_read()` may use `preempt_disable_notrace()` only when `__native_word(pcp)` is true, while non-native reads and all `this_cpu_generic_*` RMW macros must use `raw_local_irq_save()`; in `local.h`/`local64.h`, `__local{,64}_{inc,dec,add,sub}()` require preemption disabled and variables not accessed in interrupts. [F17, F117]

## Object Lifetimes

- In `pgalloc.h`, if `pagetable_{pte,pmd}_ctor()` fails in `__pte_alloc_one_kernel_noprof()`, `__pte_alloc_one_noprof()`, or `pmd_alloc_one_noprof()`, the `ptdesc` must be freed via `pagetable_free(ptdesc)` (not `pagetable_dtor_free()`), whereas constructed tables in `{pte_free_kernel,pte_free,pmd_free,__pud_free,__p4d_free,__pgd_free}()` must use `pagetable_dtor_free()`. [F1, F2]

## API Contracts

- In `pgalloc.h`, user PTE allocators (`{__,}pte_alloc_one_noprof`) return `pgtable_t` (`struct page *`) via `ptdesc_page()` for `pte_free()`, whereas `__pte_alloc_one_kernel_noprof()` and `pmd_alloc_one_noprof()` return virtual addresses via `ptdesc_address()`; when levels are folded (`pgtable-no{p4d,pud,pmd}.h`), `{p4d,pud,pmd}_alloc_one()` are `NULL`, `{pgd,p4d,pud}_present()` return 1, and `p4d_free()` must check `!mm_p4d_folded(mm)`. [F23, F24]
- In `uaccess.h`, `{put,get,clear}_user()` call `might_fault()` (unlike `__*` variants), and `{put,get}_user()` must cast `void __user *__p` back to `(__typeof__(*(ptr)) __user *)__p` before calling `__{put,get}_user()`; `__get_user_fn(size, from, to)` and `__put_user_fn(size, to, from)` take the `__user` pointer second and kernel pointer third, whereas `raw_copy_{from,to}_user(to, from, n)` take `(dst, src, size)`. [F22, F98, F113]
- In `io.h`, `{read,write}{b,w,l,q}` convert between little-endian MMIO and CPU endianness with `__io_{br,ar,bw,aw}()` barriers (omitted in `_relaxed`) and must guard `log_{read,post_read,write,post_write}_mmio()` with `rwmmio_tracepoint_enabled()`; `_in{b,w,l}()` must return `u8`/`u16`/`u32` with `__io_{pbr,par}()`; generic `ioremap_{np,uc}()` return `NULL` (unlike `ioremap_{wc,wt}()`). [F105, F106, F108, F110]
- In `bitops/`, all bitmap ops (including `void *` `*_bit_le()` wrappers) index `unsigned long` words at `addr + BIT_WORD(nr)`, requiring `unsigned long`-aligned and -sized buffers; `{,generic_}ffs()`, `{,generic_}fls()`, and `fls64()` return 0 on 0 and 1-based positions otherwise, whereas `{,generic_}__ffs()` and `{,generic_}__fls()` are 0-based and undefined on 0; `sched_find_first_bit()` requires a non-zero 100-bit bitmap. [F25, F100, F101]
- In `getorder.h`, `get_order(size)` is undefined when `size == 0` and must subtract 1 from `size` before shifting by `PAGE_SHIFT` so non-power-of-two multiples of `PAGE_SIZE` round up; in `word-at-a-time.h`, both endianness branches of `has_zero(val, data, c)` must return `unsigned long` and store the mask into `*data`, which callers must pass through `prep_zero_mask()` and `create_zero_mask()` before `find_zero()`/`zero_bytemask()`. [F26, F35, F45, F92]
- In `delay.h`, `udelay()` and `ndelay()` require constant args `< DELAY_CONST_MAX` (20000) and must dispatch to their own unit helpers (`{U,N}DELAY_CONST_MULT`, `__bad_{u,n}delay()`, `__{u,n}delay()`); `mdelay()` must be used above `MAX_UDELAY_MS`; in `hugetlb.h`, `__HAVE_ARCH_HUGE_*` fallbacks must keep parameter lists (including `sz`) synced with arch headers, and `huge_ptep_get()` must use `ptep_get(ptep)` rather than `READ_ONCE(*ptep)`. [F27, F47, F112, F120]
- In `qspinlock.h`/`qrwlock.h`, `atomic_try_cmpxchg_acquire()` callers must declare the expected-value temporary as initialized `int` (not `u32`); in `percpu.h`, `raw_cpu_generic_try_cmpxchg()` and `__cpu_fallback_try_cmpxchg()` must sample `*(ovalp)` into a local temporary before comparing and update `*(ovalp)` only on failure. [F28, F43]
- `do_div(n, base)` (`div64.h`) requires a side-effect-free 64-bit lvalue `n` and 32-bit `base`, updating `n` to the quotient and returning the 32-bit remainder; `csum_partial()` (`checksum.h`) requires even `len` on non-final fragments, and `ip_fast_csum(iph, ihl)` takes `ihl` in 32-bit words; in `compat.h`, `compat_arg_u64{,_dual}()` must order pairs `lo, hi` on LE and `hi, lo` on `CONFIG_CPU_BIG_ENDIAN`. [F29, F33, F49]

## Error Handling

- In `uaccess.h`, `raw_copy_{from,to}_user()` and `{__,}clear_user()` return the `unsigned long` uncopied/uncleared byte count, whereas `__{get,put}_user_fn()` must convert non-zero residuals to `-EFAULT`; `{,__}get_user(x, ptr)` must zero `x` on every failure path (both `access_ok()` and `__get_user_fn()` failures across all transfer sizes). [F20, F83]
- In `bug.h`, `WARN_ON_SMP(x)` expands to `({0;})` without evaluating `x` when `!CONFIG_SMP`, the `!CONFIG_BUG` fallback for `WARN()` must pass `format` to `no_printk(format)`, and `__warn()`'s prototype must stay outside `#ifdef CONFIG_BUG`; never use `WARN*()` for user/device input or `ENOMEM`/`EAGAIN`, or `BUG*()` when recovery is possible. [F34, F102, F131, F132, F133]

## External Contracts

- In `uapi/asm-generic/siginfo.h`, `union __sifields` must not contain 64-bit types (`__u64`/`u64`) or >4-byte aligned members on 32-bit architectures, and `_sigfault._addr_{bnd,pkey}` must start with `char _dummy_{bnd,pkey}[__ADDR_BND_PKEY_PAD]`; in 32-bit `{sem,msq,shm}id64_ds` and `compat_*64_ds`, `*_time` must precede `*_time_high` even on big-endian. [F63, F64, F66]
- In `uapi/asm-generic/unistd.h`, syscalls needing 32-bit compat handling or signed `long` sign-extension must use `__SC_COMP{,_3264}()`; in `ioctl.h`, `_IOC()` requires `sizeof(t) < (1 << _IOC_SIZEBITS)` with `_IOR`/`_IOW` relative to userspace read/write; in `access_ok.h`, `__access_ok()` must check `(size <= limit) && (addr <= (limit - size))` against a constant `TASK_SIZE_MAX`; in `vmlinux.lds.h`, `ORC_UNWIND_TABLE` must emit `.orc_header` and size `.orc_lookup` with `+ 1` sentinel entry. [F71, F135, F140, F141]

## Known Pitfalls

- In `io.h`, string I/O helpers (`{reads,writes}{b,w,l,q}`, `{ins,outs}{b,w,l}`, `io{read,write}*_rep`) take `count` as an element count (unlike byte-counted `memset_io`/`memcpy_{from,to}io`), must guard `do { ... } while (--count);` with `if (count)`, and must advance only `buf++` at a fixed FIFO `addr` (contiguous MMIO copies require `memcpy_{from,to}io()`). [F82, F99, F109]
- In `percpu.h`, inner macros `raw_cpu_generic_try_cmpxchg()` and `__this_cpu_generic_read_*()` must use three-underscore locals (`___old`, `___ret`, `___flags`) so they do not shadow `__old`, `__ret`, or `__flags` in outer macros; in `vmlinux.lds.h`, `FTRACE_STUB_HACK` must only alias `ftrace_stub_graph = ftrace_stub` when `!CONFIG_ARCH_SUPPORTS_CFI`. [F75, F96]
