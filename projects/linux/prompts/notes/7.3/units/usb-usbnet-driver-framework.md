# USB "USBNET" DRIVER FRAMEWORK

The usbnet framework provides generic USB network device infrastructure for USB Ethernet adapters, host-to-host cables, WLAN/WWAN dongles, and smart USB peripherals. It manages `net_device` registration, bulk RX/TX URB queues, optional interrupt status polling, runtime power management, and deferred error recovery, while delegating device-specific initialization and packet framing to minidrivers via `struct driver_info` callbacks.

## Architecture & Data Flow

- Every `EVENT_*` bit number used on `struct usbnet::flags` must be `<= 31` (`EVENT_UNPLUG` is at bit 31), because `dev->flags` is a single `unsigned long` word rather than a `DECLARE_BITMAP`, and bit operations on `&dev->flags` would access out of bounds on 32-bit architectures for bits `>= 32`. [F90]
- Minidrivers enabling `dev->can_dma_sg` without setting `FLAG_SEND_ZLP` or `FLAG_MULTI_PACKET` must set `dev->can_dma_sg = 1` inside `info->bind()` during `usbnet_probe()`, because `dev->padding_pkt` is only allocated in `usbnet_probe()` when `dev->can_dma_sg` is already true. Broken by: leaving `can_dma_sg` unset in `bind()` and enabling it later in `reset()` or `open()`. [F29]
- `build_dma_sg()` must allocate and initialize `num_sgs + 1` scatterlist entries while setting `urb->num_sgs = num_sgs`, reserving one extra trailing slot so `usbnet_start_xmit()` can append `dev->padding_pkt` via `sg_set_buf(&urb->sg[urb->num_sgs++], dev->padding_pkt, 1)` when `length % dev->maxpacket == 0`. [F46]
- Whenever `dev->hard_mtu` or `dev->rx_urb_size` may have changed (such as in `usbnet_change_mtu()`, `usbnet_open()` after `info->reset()`, `usbnet_set_link_ksettings_mii()` after `link_reset()`, `__handle_link_change()`, or `usbnet_probe()`), `usbnet_update_max_qlen(dev)` must be called to recompute `dev->rx_qlen` and `dev->tx_qlen`, and `usbnet_update_max_qlen()` must check that neither `rx_urb_size` nor `hard_mtu` is zero before dividing `MAX_QUEUE_MEMORY` by them (falling back to 4). [F43, F80]
- `usbnet_probe()` must leave `net->dev_addr` zeroed before `info->bind()`, evaluate `usbnet_needs_usb_name_format()` immediately after `info->bind()` (testing `is_zero_ether_addr(net->dev_addr) || is_local_ether_addr(net->dev_addr)`), and only afterward call `eth_hw_addr_random(net)` if `!is_valid_ether_addr(net->dev_addr)`. Broken by: assigning a random or shared static MAC address before `info->bind()` or `usbnet_needs_usb_name_format()`. [F53]
- Because `rx_complete()` sets `EVENT_RX_KILL` when `dev->pkt_err > 20` within a 30-packet window (`dev->pkt_cnt`) and `rx_submit()` aborts with `-ENOLINK` while `EVENT_RX_KILL` is set, `usbnet_open()` must reset `dev->pkt_cnt = 0`, `dev->pkt_err = 0`, and `clear_bit(EVENT_RX_KILL, &dev->flags)`, and `usbnet_bh()` must clear `EVENT_RX_KILL`. [F55]
- In `__handle_link_change()`, `test_and_clear_bit(EVENT_LINK_CARRIER_ON, &dev->flags)` and `netif_carrier_on(dev->net)` must execute before branching on `netif_carrier_ok(dev->net)`. Broken by: moving the `EVENT_LINK_CARRIER_ON` check into the `else` branch or after the `netif_carrier_ok(dev->net)` check. [F69]
- Every URB anchored on `dev->deferred` must have `urb->context` pointing to a `struct sk_buff` (and `urb->sg` either `NULL` or a heap-allocated scatterlist), because `usbnet_disconnect()` and `usbnet_resume()` cast `urb->context` unconditionally to `struct sk_buff *` and pass it to `dev_kfree_skb()` / `dev_kfree_skb_any()`. Broken by: anchoring a control or status URB onto `dev->deferred`. [F87]
- `usbnet_probe()` must reject devices where `dev->maxpacket` (`usb_maxpacket(dev->udev, dev->out)`) is 0, and `usbnet_get_endpoints()` must skip endpoints where `usb_endpoint_maxp(&e->desc)` is 0 before registration. [F63]
- In `usbnet_get_endpoints()`, candidate endpoint pointers `in`, `out`, and `status` must be reset to `NULL` at the start of every `intf->num_altsetting` outer-loop iteration before scanning `alt->endpoint`. [F75]

## Synchronization

- Callers of `__usbnet_queue_skb()` must hold `list->lock` (`dev->rxq.lock` or `dev->txq.lock`) across both `usb_submit_urb()` and `__usbnet_queue_skb()` so that concurrent URB completion (`defer_bh()`) or `unlink_urbs()` cannot unlink the SKB or overwrite `entry->state` before it is queued as `rx_start` or `tx_start`. [F14]
- `defer_bh()` acquires `list->lock` (`dev->rxq.lock` or `dev->txq.lock`) with `spin_lock_irqsave()` and nests `dev->done.lock` inside it via `spin_lock_nested()`, so `defer_bh()` must never be called with `list == &dev->done` and `dev->done.lock` must never be acquired before `rxq.lock` or `txq.lock`. [F109]
- In `rx_complete()`, the previous `enum skb_state` returned by `defer_bh(dev, skb, &dev->rxq, state)` must be captured and checked for `state != unlink_start` before resubmitting `urb` via `rx_submit()`. Broken by: discarding the return value of `defer_bh()` or checking the post-completion `state` (`rx_done` or `rx_cleanup`) instead. [F73]
- `dev->txq.lock` must be held when setting or clearing `EVENT_DEV_ASLEEP` in `usbnet_suspend()` and `usbnet_resume()`, and while checking `EVENT_DEV_ASLEEP`, anchoring deferred TX URBs to `dev->deferred`, or draining `dev->deferred` in `usbnet_start_xmit()` and `usbnet_resume()`. [F17]
- `usbnet_start_xmit()`, `tx_complete()`, and `usbnet_device_suggests_idle()` must use the non-sleeping `usb_autopm_get_interface_async()` and `usb_autopm_put_interface_async()` helpers because they execute in softirq/hardirq context or while holding `dev->txq.lock` with IRQs disabled. [F114]
- `__usbnet_read_cmd()` and `__usbnet_write_cmd()` must allocate their temporary USB control transfer buffers with `GFP_NOIO` rather than `GFP_KERNEL` because they may be invoked during USB device reset or resume when paging I/O over sibling USB storage interfaces can deadlock. [F106]
- To break cyclic rescheduling among `dev->delay`, `dev->bh_work`, and `dev->kevent`, teardown in `usbnet_disconnect()` and `usbnet_probe()` failure paths must call `usbnet_mark_going_away(dev)` (`EVENT_UNPLUG`) before draining work/timers, and `usbnet_stop()` must synchronously drain `delay`, `bh_work`, and `kevent` in two passes. [F19]
- `usbnet_terminate_urbs()` must register a waiter on `dev->wait` before unlinking `dev->txq` and `dev->rxq` and keep it registered until `rxq`, `txq`, and `done` are empty, because `usbnet_bh()` relies on `waitqueue_active(&dev->wait)` to suppress refilling RX URBs and waking the TX queue. [F18]
- `usbnet_link_change()` must not call `netif_carrier_on()` directly; when `link && !need_reset`, it must set `EVENT_LINK_CARRIER_ON` in `dev->flags` (and otherwise clear `EVENT_LINK_CARRIER_ON` and call `netif_carrier_off()`) so `__handle_link_change()` enables the carrier serialized with `unlink_urbs()` in `usbnet_deferred_kevent()`. [F51]
- In `usbnet_open()`, `EVENT_DEV_OPEN` must be set in `dev->flags` and `EVENT_RX_KILL` cleared before scheduling `dev->bh_work`, because `rx_submit()` rejects RX URB submissions unless `test_bit(EVENT_DEV_OPEN, &dev->flags)` is true and `test_bit(EVENT_RX_KILL, &dev->flags)` is false. [F23]

## Object Lifetimes

- In `usbnet_start_xmit()`, every TX URB acquires `usb_autopm_get_interface_async(dev->intf)` under `dev->txq.lock` before submission or anchoring to `dev->deferred`, and that reference must be balanced by `usb_autopm_put_interface_async(dev->intf)` in `tx_complete()`, on synchronous submission failure, or in `usbnet_resume()` if deferred submission fails. [F8]
- URBs anchored to `dev->deferred` by `usbnet_start_xmit()` while `EVENT_DEV_ASLEEP` is set must be drained in `usbnet_resume()` under `dev->txq.lock` before clearing `EVENT_DEV_ASLEEP` (freeing `skb`, `res->sg`, `res`, and the async PM ref on error), and any left at `usbnet_disconnect()` must be freed with their `sg` and `urb->context`. [F57]
- `usbnet_open()` retains its `usb_autopm_get_interface(dev->intf)` reference unless `info->manage_power(dev, 1)` succeeds (setting `EVENT_NO_RUNTIME_PM` if it fails, while resetting `retval` to 0 rather than failing open), so `usbnet_stop()` must read `EVENT_NO_RUNTIME_PM` before zeroing `dev->flags` to balance with `info->manage_power(dev, 0)` or `usb_autopm_put_interface(dev->intf)`. [F9, F34]
- Because `usbnet_device_suggests_idle()` sets `EVENT_DEVICE_REPORT_IDLE` via `test_and_set_bit()` and drops an async runtime PM ref with `usb_autopm_put_interface_async(dev->intf)`, `usbnet_resume()` must check `test_and_clear_bit(EVENT_DEVICE_REPORT_IDLE, &dev->flags)` and restore that ref via `usb_autopm_get_interface_no_resume(intf)`. [F58]
- `usbnet_status_start()` and `usbnet_status_stop()` manage `dev->interrupt` submission via `dev->interrupt_count` under `dev->interrupt_mutex` (submitting on `0 -> 1` and killing on `1 -> 0`), whereas suspend and resume must use `__usbnet_status_stop_force()` and `__usbnet_status_start_force()` so `dev->interrupt_count` is preserved across suspend/resume. [F11]
- Because `init_status()` sets `URB_FREE_BUFFER` on `dev->interrupt->transfer_flags`, its `transfer_buffer` is automatically freed by `usb_free_urb(dev->interrupt)` and must never be manually passed to `kfree()` after URB initialization. [F95]

## API Contracts

- `rx_process()` transfers ownership of `skb` to `usbnet_skb_return()` when returning `0`, whereas `usbnet_bh()` frees `skb` via `usb_free_skb()` whenever `rx_process()` returns non-zero (including when `driver_info->rx_fixup()` returns `0` or when `FLAG_MULTI_PACKET` is set), so `rx_fixup()` implementations must never free the passed-in `skb`. [F3]
- `usbnet_read_cmd()` and `usbnet_write_cmd()` must never be called from USB `suspend`, `resume`, or `reset_resume` callbacks because they acquire runtime PM via `usb_autopm_get_interface()` and will deadlock; those paths must call `usbnet_read_cmd_nopm()` or `usbnet_write_cmd_nopm()` instead. [F21]
- `__usbnet_read_cmd()` (and `usbnet_read_cmd()` / `usbnet_read_cmd_nopm()`) returns the non-negative transferred byte count from `usb_control_msg()` or a negative errno, and only copies `err` bytes into `data` when `0 < err <= size`, leaving trailing bytes of `data` unmodified on a short or zero-length read. Broken by: checking only `ret < 0` and reading uninitialized stack `data` without verifying `ret == size`. [F27]
- `__usbnet_write_cmd()` (and `usbnet_write_cmd()` / `usbnet_write_cmd_nopm()`) requires `size == 0` whenever `data == NULL`; passing `data == NULL` with `size > 0` triggers `WARN_ON_ONCE(1)` and returns `-EINVAL`. [F40]
- `__usbnet_read_cmd()`, `__usbnet_write_cmd()`, and `usbnet_write_cmd_async()` must allocate DMA-safe heap buffers via `kmalloc()` or `kmemdup()` for USB control transfers rather than passing caller data pointers directly to `usb_control_msg()` or `usb_fill_control_urb()`. [F99]
- Minidrivers setting `FLAG_MULTI_PACKET` must call `usbnet_set_skb_tx_stats(skb, packets, bytes_delta)` in `tx_fixup()` with a signed byte delta rather than the total frame length, because `usbnet_start_xmit()` adds `urb->transfer_buffer_length` to `entry->length` (clamping non-positive results) before `tx_complete()` updates `tx_bytes`. [F47]
- `usbnet_defer_kevent()` takes an `EVENT_*` bit number (such as `EVENT_TX_HALT` or `EVENT_RX_HALT`), not a shifted bitmask, and indexes `usbnet_event_names[work]` directly along with `set_bit(work, &dev->flags)`. Broken by: passing `BIT(EVENT_...)` or adding a new `EVENT_*` bit without updating `usbnet_event_names[]`. [F124]
- Despite `usbnet_status_start()` accepting `gfp_t mem_flags`, both `usbnet_status_start()` and `usbnet_status_stop()` acquire `dev->interrupt_mutex` (and `usbnet_status_stop()` calls `usb_kill_urb()`), so callers must invoke them only from process context, and must verify `dev->interrupt` is non-NULL before calling `usbnet_status_start()` (which is only allocated by `init_status()` when both `dev->status` and `dev->driver_info->status` are non-NULL). [F30, F115]
- MII ethtool helpers (`usbnet_get_link_ksettings_mii()`, `usbnet_set_link_ksettings_mii()`, `usbnet_nway_reset()`, and `usbnet_get_link()`) must check `dev->mii.mdio_read` or `dev->mii.mdio_write` before invoking MII core functions, returning `-EOPNOTSUPP` (or falling back to `ethtool_op_get_link()`) when the callback is `NULL`. [F31]
- In `struct usbnet`, `dev->rx_speed` and `dev->tx_speed` are expressed in bits per second (or set to `SPEED_UNSET = -1` when unknown), because `usbnet_get_link_ksettings_internal()` divides them by `1000000` to populate `cmd->base.speed` in Mbps. Broken by: assigning Mbps values or `0` instead of `SPEED_UNSET`. [F42]

## Error Handling

- In `usbnet_write_cmd_async()`, because `urb->transfer_flags |= URB_FREE_BUFFER` is set after `usb_fill_control_urb()`, the error cleanup path after a failed `usb_submit_urb()` must clear `urb->transfer_flags = 0` when manually calling `kfree(buf)` before `usb_free_urb(urb)`. [F59]
