# AMD KFD

This component (`drivers/gpu/drm/amd/amdkfd`) implements device-level queue scheduling, Memory Queue Descriptor (MQD) management, interrupt processing, HSA event signaling, doorbell mapping, flat memory aperture configuration, and HMM-based Shared Virtual Memory (SVM) page migration for AMD GPUs across CIK, VI, and GFX9–GFX12 hardware blocks via HWS/HIQ, MES, or direct HQD programming.

## Architecture & Data Flow

- Under `dqm_lock(dqm)`, `qpd->evicted` is a nesting counter: `evict_process_queues_cpsch` and `evict_process_queues_nocpsch` only deactivate queues when `qpd->evicted++ == 0`, and `restore_process_queues_cpsch` and `restore_process_queues_nocpsch` only reactivate when `qpd->evicted == 1`. In `create_queue_nocpsch` and `create_queue_cpsch`, `q->properties.is_evicted` must be initialized to `!!qpd->evicted` under `dqm_lock(dqm)`. In `evict_process_queues_nocpsch` and `restore_process_queues_nocpsch`, every queue in `qpd->queues_list` must have `q->properties.is_evicted` updated before skipping inactive queues, and if `destroy_mqd` or `load_mqd` fails, the loop must record the first error and continue through all remaining queues. [F9, F63, F110]
- Whenever `q->properties.is_active` changes or `q->gws` changes on an active queue, `dqm->active_queue_count`, `dqm->active_cp_queue_count`, `dqm->gws_queue_count`, and `qpd->mapped_gws_queue` must be updated in lockstep via `increment_queue_count()`, `decrement_queue_count()`, or `update_queue()`. In `update_queue()`, `prev_active = q->properties.is_active` must be sampled and the queue unmapped/destroyed on hardware before `mqd_mgr->update_mqd()` mutates the MQD and overwrites `q->properties.is_active`. [F60, F62]
- On SOC15, `init_doorbell_bitmap` marks both `[non_cp_doorbells_start, non_cp_doorbells_end]` and its mirror at `+ KFD_QUEUE_DOORBELL_MIRROR_OFFSET` as reserved in `qpd->doorbell_bitmap`, and `deallocate_doorbell` must not clear `qpd->doorbell_bitmap` for SDMA or XGMI-SDMA queues. [F88]
- In the contiguous `dqm->hiq_sdma_mqd` trunk allocated by `allocate_hiq_sdma_mqd`, `NUM_XCC(dev->xcc_mask)` HIQ MQDs occupy the base region (`kfd_get_hiq_xcc_mqd`) and SDMA MQDs in `allocate_sdma_mqd` start at byte offset `mqd_mgrs[KFD_MQD_TYPE_HIQ]->mqd_size * NUM_XCC(dev->xcc_mask)`. [F89]
- On multi-XCC GFX9 devices (GC 9.4.3, 9.4.4, 9.5.0), `init_mqd_hiq_v9_4_3()`, `init_mqd_v9_4_3()`, and `update_mqd_v9_4_3()` must clear `CP_HQD_PQ_CONTROL__NO_UPDATE_RPTR_MASK` only on master XCC 0 while leaving it set on subordinate XCCs (`xcc > 0`). Every MQD manager's `restore_mqd()` and `restore_mqd_sdma()` must overwrite the MQD doorbell offset register with `qp->doorbell_off` and set `qp->is_active = 0` after copying `mqd_src`. [F74, F75]
- In `struct kernel_queue`, `queue_size` is in bytes while `pq_kernel_addr` is a `uint32_t *` ring of `queue_size_dwords = queue_size / 4` holding at most `queue_size_dwords - 1` dwords (`available_size = (rptr + queue_size_dwords - 1 - wptr) % queue_size_dwords`). `kq_acquire_packet_buffer()` advances only shadow cursors `kq->pending_wptr` (modulo `queue_size_dwords`) and `kq->pending_wptr64` (monotonic); when wrapping, it must verify `packet_size_in_dwords < rptr` before NOP-padding to index 0 while incrementing `wptr64` per NOP. Aborted builds must call `kq_rollback_packet()`. [F72, F80, F111, F123, F132]
- Because `dequeue_ih_ring_entry` uses `kfifo_out_linear_ptr` to peek at `node->ih_fifo` without consuming the entry, `interrupt_wq` must call `kfifo_skip_count(&dev->ih_fifo, dev->kfd->device_info.ih_ring_entry_size)` on every iteration and re-queue `dev->interrupt_work` via `queue_work(dev->kfd->ih_wq, &dev->interrupt_work)` when breaking after `start_jiffies + HZ`. [F104]
- In `event_interrupt_isr_v9`, `event_interrupt_isr_v10`, and `event_interrupt_isr_v11`, the KFD VMID bounds check (`vmid < first_vmid_kfd || vmid > last_vmid_kfd`) must be guarded by `!KFD_IRQ_IS_FENCE(client_id, source_id)` so process-close fence interrupts reach `kfd_process_close_interrupt_drain`. [F105]
- In `svm_migrate_copy_to_vram` and `svm_migrate_copy_to_ram`, `j` counts contiguous pages in the current SDMA batch; whenever a page is skipped or discontiguous (or `cursor.size` is exhausted in `svm_migrate_copy_to_vram`), any pending batch of length `j` at offset `i - j` must be flushed via `svm_migrate_copy_memory_gart` and `j` reset to 0. In `svm_migrate_copy_to_ram`, `addr` must be initialized from `migrate->start` (not `prange->start << PAGE_SHIFT`) and incremented by `PAGE_SIZE` in the loop header so `continue` paths still advance it. [F102, F103]

## Synchronization

- Acquiring and releasing a `device_queue_manager` lock must go through `dqm_lock()` and `dqm_unlock()` so `mutex_lock(&dqm->lock_hidden)` is paired with `memalloc_noreclaim_save()` and `memalloc_noreclaim_restore(dqm->saved_flags)`. Callers of `map_queues_cpsch`, `unmap_queues_cpsch`, `execute_queues_cpsch`, `suspend_single_queue`, `resume_single_queue`, `detect_queue_hang`, `reset_hung_queues`, and `destroy_queue_nocpsch_locked` must hold `dqm_lock(dqm)`. [F26, F153]
- Functions that allocate/free GTT BOs (`amdgpu_amdkfd_alloc_gtt_mem`, `amdgpu_amdkfd_free_gtt_mem`, `mqd_mgr->allocate_mqd`, `mqd_mgr->free_mqd`, `pdd->proc_ctx_bo` allocation in `add_queue_mes`) must not be called while holding `dqm_lock(dqm)` or `adev->reset_domain->sem`. Likewise, `kfd_inc_compute_active`/`kfd_dec_compute_active`, `kfd_dbg_ev_raise()` (`p->event_mutex` nests outside `dqm_lock(dqm)`), and `mqd_mgr->get_wave_state()` (`copy_to_user()`, plus `get_task_mm()`/`kthread_use_mm()` in `copy_context_work_handler()`) must be called outside `dqm_lock(dqm)`. [F21, F151, F155, F158]
- In `add_queue_mes`, `remove_queue_mes`, `suspend_all_queues_mes`, `resume_all_queues_mes`, `unmap_queues_cpsch`, and `execute_queues_cpsch`, once `down_read_trylock(&adev->reset_domain->sem)` succeeds, every subsequent return path must call `up_read(&adev->reset_domain->sem)`. [F1]
- When `kfd_dbg_is_per_vmid_supported(dqm->dev)` is true and `dqm->sched_policy != KFD_SCHED_POLICY_NO_HWS`, `debug_lock_and_unmap(dqm)` returns with `dqm_lock(dqm)` held on `0` and unlocks it on error; callers must call `debug_map_and_unlock(dqm)` only on success. [F10]
- When `wait_on_destroy_queue` sleeps on `dqm->destroy_wait` for a suspended queue, it must set `q->properties.is_being_destroyed = true` beforehand, release `dqm_lock(dqm)` and `q->process->mutex` before `wait_event_interruptible`, and reacquire `q->process->mutex` before `dqm_lock(dqm)` upon waking. [F24]
- In `process_termination_nocpsch` and `process_termination_cpsch`, draining `qpd->queues_list` to call `mqd_mgr->free_mqd` outside `dqm_lock(dqm)` must use `while (!list_empty(&qpd->queues_list))` and unlink `list_first_entry` under `dqm_lock` before unlocking, never `list_for_each_entry_safe`. [F107]
- Updates to `ev->signaled`, `ev->event_age`, `ev->wq`, and attached `waiter->activated`/`waiter->event` fields in `set_event`, `reset_event`, `destroy_event`, `init_event_waiter`, and `free_waiters` must hold `spin_lock(&ev->lock)`, while `test_event_condition` reads `waiter->event` and `waiter->activated` with `READ_ONCE`. [F34]
- In `kfd_wait_on_events`, the wait loop must call `set_current_state(TASK_INTERRUPTIBLE)` before `test_event_condition(all, num_events, event_waiters)` and `schedule_timeout(timeout)`. After dropping `p->event_mutex` to sleep, task state must be restored to `TASK_RUNNING` and `p->event_mutex` reacquired before calling `copy_signaled_event_data` (which must re-verify `waiter->event != NULL`) and `free_waiters`. [F35, F169]
- Callers of `svm_migrate_to_vram`, `svm_migrate_ram_to_vram`, and `svm_migrate_vram_to_vram` must hold the `mm` read lock, `svms->lock`, and `prange->migrate_mutex`, while `svm_migrate_copy_memory_gart` serializes GART window 0 mappings and SDMA copy jobs under `adev->mman.gtt_window_lock`. [F40]

## Object Lifetimes

- In `destroy_queue_nocpsch_locked`, when removing the last queue from `qpd->queues_list` and `qpd->reset_wavefronts` is set, `dbgdev_wave_reset_wavefronts` must be called before `deallocate_vmid(dqm, qpd, q)` and `qpd->reset_wavefronts` must be reset to `false`. [F7]
- MQDs allocated via `allocate_hiq_mqd` or `allocate_sdma_mqd` point into the shared `dqm->hiq_sdma_mqd` GTT buffer and must be freed with `free_mqd_hiq_sdma`, whereas when `enable_mes` is true on GFX11/GFX12, SDMA MQDs must use `allocate_mqd` and `kfd_free_mqd_cp` because `dqm->hiq_sdma_mqd` is not allocated. [F140]
- Mutations to `p->event_idr` and `p->signal_page` in `kfd_event_create`, `kfd_criu_restore_event`, and `kfd_event_destroy` must hold `p->event_mutex`, with `ev->lock` and `ev->wq` initialized before `idr_alloc`. In `destroy_event`, while holding `p->event_mutex`, every waiter on `ev->wq.head` must have `waiter->event` cleared to `NULL` under `ev->lock` before waking `&ev->wq`, and `ev` must be freed via `kfree_rcu(ev, rcu)` after `idr_remove(&p->event_idr, ev->event_id)`. [F18, F33]
- Workqueue handlers that look up a `struct kfd_process` by PASID (`kfd_signal_event_interrupt`, `kfd_signal_hw_exception_event`, `kfd_signal_poison_consumed_event`, `kfd_dqm_suspend_bad_queue_mes`) must release the reference via `kfd_unref_process(p)` on every exit path, while `kfd_signal_reset_event` must hold `srcu_read_lock(&kfd_processes_srcu)`. [F36]
- In `svm_migrate_ram_to_vram` and `svm_migrate_vram_to_ram`, `amdgpu_amdkfd_reserve_mem_limit` must be paired with `amdgpu_amdkfd_unreserve_mem_limit` on exit, `svm_range_vram_node_new` must precede reading `prange->offset`, and `prange->vram_pages`, `prange->actual_loc`, and `prange->ttm_res` must be updated together: when `prange->vram_pages` reaches 0 (or `!mpages && !prange->actual_loc`), `prange->actual_loc` must be 0 and `svm_range_vram_node_free(prange)` must be called. [F12, F70]
- In `svm_migrate_vma_to_vram` and `svm_migrate_vma_to_ram`, once `migrate_vma_setup(&migrate)` succeeds with `migrate.cpages > 0`, `migrate_vma_pages(&migrate)`, `svm_migrate_copy_done(adev, mfence)`, `migrate_vma_finalize(&migrate)`, and `svm_range_dma_unmap_dev(adev->dev, scratch, 0, npages)` must all execute before freeing `buf`. [F15]

## API Contracts

- Under `KFD_SCHED_POLICY_NO_HWS`, `create_queue_nocpsch` and `update_queue` must verify `q->process->mm == current->mm` before passing `current->mm` to `mqd_mgr->load_mqd`, whereas `restore_process_queues_nocpsch` must acquire `mm` via `get_task_mm(pdd->process->lead_thread)` and drop it with `mmput(mm)`. [F187]
- Top-half `interrupt_isr` callbacks (`event_interrupt_isr_v9`, `event_interrupt_isr_v10`, `event_interrupt_isr_v11`) run in hardirq context under `node->interrupt_lock` and must not sleep or modify `ih_ring_entry` in place; if an entry needs patching, the ISR must set `*patched_flag = true` and write the modified copy into `patched_ihre`. [F164]
- `svm_migrate_vma_to_vram` and `svm_migrate_vma_to_ram` return a `long` (non-negative migrated page count on success or negative errno on failure); callers `svm_migrate_ram_to_vram` and `svm_migrate_vram_to_ram` must store it in a signed `long r`, check `r < 0` for errors, and return `r < 0 ? r : 0`. [F46]
- `svm_migrate_addr_to_pfn` and `svm_migrate_put_vram_page` take a 0-based VRAM byte offset `addr` (to which `adev->kfd.pgmap.range.start` is added before `>> PAGE_SHIFT`), whereas `svm_migrate_get_vram_page` takes a host PFN prior to `migrate_pfn` encoding. [F55]

## Error Handling

- In `create_queue_cpsch`, if `execute_queues_cpsch` or `add_queue_mes` fails for an active queue, `cleanup_queue` must undo `qpd->queue_count++`, `list_add(&q->list, &qpd->queues_list)`, `increment_queue_count`, `allocate_mqd`, `allocate_doorbell`, and `allocate_sdma_queue` in reverse order without incrementing `dqm->total_queue_count`. [F6]
- Callers of `lookup_event_by_id` must check that the returned `struct kfd_event *` is non-NULL before acquiring `ev->lock` or accessing `ev` fields. [F43]
- In `kfd_criu_restore_event`, `mutex_unlock(&p->event_mutex)` must be called before the shared `exit:` label because earlier error paths jump to `exit:` before `p->event_mutex` is acquired, and `kfree(ev)` at `exit:` must only run when `ret` is non-zero. [F17]
- When `kfd_wait_on_events` aborts with `-ERESTARTSYS` due to a pending non-fatal signal, `free_waiters` must be called with `undo_auto_reset = true` (`ret == -ERESTARTSYS`) to re-signal any auto-reset events that already activated a waiter, and `*wait_result` must be set to `KFD_IOC_WAIT_RESULT_FAIL` whenever `ret != 0`. [F58]
- If `svm_migrate_copy_to_vram` or `svm_migrate_copy_to_ram` fails after initializing destination pages in `migrate->dst`, it must unlock and put every allocated destination page (`svm_migrate_put_vram_page` or `svm_migrate_put_sys_page`) and clear `migrate->dst[i] = 0` before `migrate_vma_pages` runs. [F14]

## External Contracts

- `svm_migrate_to_ram` (`dev_pagemap_ops.migrate_to_ram`) must return a `vm_fault_t` value (`0` on success or `VM_FAULT_SIGBUS` on failure), translating negative errno returns from `svm_migrate_vram_to_ram` or range lookup into `VM_FAULT_SIGBUS`. [F47]

## Known Pitfalls

- In `qpd->doorbell_bitmap` and `kfd->doorbell_bitmap`, a 0 bit means free and a 1 bit means allocated/reserved, whereas in `dqm->sdma_bitmap`, `dqm->xgmi_sdma_bitmap`, and `dqm->allocated_queues[pipe]`, a 1 bit means free/available and a 0 bit means allocated. [F87]
- In `kfd_get_process_doorbells`, the index returned by `amdgpu_doorbell_index_on_bar` must be multiplied by `sizeof(uint32_t)` (not `doorbell_size`), while `kfd_get_kernel_doorbell` and `kfd_release_kernel_doorbell` must multiply and divide the `doorbell_bitmap` bit index `inx` by 2 when indexing `u32 __iomem *doorbell_kernel_ptr`. [F125]
- In `unmap_queues_cpsch`, after `pm_send_query_status` and `amdkfd_fence_wait_timeout` complete for `KFD_FENCE_COMPLETED`, the driver must still call `mqd_mgr->check_preemption_failed` on the HIQ MQD and `sdma_has_hang(dqm)` to detect and reset hung compute or SDMA queues. [F149]
- In multi-XCC MQD callbacks in `kfd_mqd_manager_v9.c` that iterate over `NUM_XCC(mm->dev->xcc_mask)`, each iteration must compute the per-XCC MQD pointer (base `mqd` plus `stride * xcc`) and pass that per-XCC pointer (and `xcc` index) to helpers (`update_mqd`, `update_cu_mask`, `checkpoint_mqd`, `get_wave_state`) rather than the base `mqd` pointer. [F100]
- Integer width, overflow, and wrap hazards: in `user_timeout_to_jiffies`, finite `user_timeout_ms` values must be clamped to `0x7FFFFFFF` before `msecs_to_jiffies`; in `create_other_event`, `KFD_LAST_NONSIGNAL_EVENT_ID` (`INT_MAX`) must be cast to `uint32_t` before `+ 1` for `idr_alloc`; in `event_interrupt_wq_v9`/`v10`/`v11`, `ih_ring_entry[5] & 0xf` must be cast to `uint64_t` before `<< 32`; in `svm_migrate_to_ram`, granularity `size` must use `1UL << prange->granularity`; and timeout loops in `amdkfd_fence_wait_timeout` and `interrupt_wq` must use `time_after` or `time_is_before_jiffies`. [F114, F115, F116, F122, F124]
