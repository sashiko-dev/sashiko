# PARISC ARCHITECTURE

This unit provides PA-RISC platform bus adapters, SBA and CCIO IOMMU DMA engines (`sba_iommu.c`, `ccio-dma.c`), PCI/GSC/EISA/HP-PB host bridges and ASIC controllers (`lba_pci.c`, `dino.c`, `gsc.c`, `asp.c`, `lasi.c`, `wax.c`, `eisa.c`, `hppb.c`, `superio.c`), the I/O SAPIC interrupt router (`iosapic.c`), PDC Stable Storage sysfs management (`pdc_stable.c`), chassis LED/LCD and soft-power drivers (`led.c`, `power.c`), 8250 serial glue (`8250_parisc.c`), and the STI/NGLE framebuffer driver (`stifb.c`).

## Architecture & Data Flow

- Any non-NULL `dev.platform_data` on a `parisc_device` or PCI bridge must point to `struct pci_hba_data` or a struct embedding it at offset 0 (`dino_device`, `lba_device`) because `parisc_walk_tree()` and `GET_IOC()` dereference it as `struct pci_hba_data *`. Also, `lmmio_space`, `elmmio_space`, and `gmmio_space` must remain contiguous in `struct pci_hba_data` because `dino_bridge_init()` indexes `&dino_dev->hba.lmmio_space` as a 3-element (`DINO_MAX_LMMIO_RESOURCES`) array. [F114, F118]
- In `sba_iommu.c` and `ccio-dma.c`, `ioc->pdir_size` is in bytes (`sizeof(u64)` per page) while `ioc->res_size` is the bitmap byte size (`(pdir_size / sizeof(u64)) >> 3`), so usable PDIR entries equal `ioc->res_size << 3`. In `sba_map_single()`, `sba_unmap_page()`, `ccio_map_single()`, `ccio_unmap_page()`, and `iommu_coalesce_chunks()`, the sub-page offset must be added to byte length before ceiling-aligning to `IOVP_SIZE`. [F109, F122]
- Because `ccio_io_pdir_entry()` and `sba_io_pdir_entry()` run `lci` on `sg_virt(startsg)`, `iommu_coalesce_chunks()` must only coalesce when `prev_end == sg_start` and `((prev_end | sg_start) & ~PAGE_MASK) == 0`; its inner `while (--nents > 0)` loop advances `startsg++` before testing coalescability, and chunk heads are tagged with `PIDE_FLAG` (`0x80000000UL`) in `sg_dma_address(contig_sg)`, which `iommu_fill_pdir()` must strip before indexing `ioc->pdir_base`. [F79, F93, F161]
- In `sba_iommu.c`, `sba_search_bitmap()` and `sba_free_range()` treat `ioc->res_map` as MSB-0 `unsigned long` words (`RESMAP_MASK(n)`), prohibiting `<linux/bitmap.h>` LSB-0 helpers and mappings > `BITS_PER_LONG` pages. Sub-word allocations must align `bitshiftcnt` and step by `o = 1 << get_order(bits_wanted << PAGE_SHIFT)`, and on reaching `res_end`, `sba_search_bitmap()` must wrap `ioc->res_hint` to `(unsigned long *)ioc->res_map` and reset `ioc->res_bitshift = 0`. [F60, F97, F120]
- In `ccio-dma.c`, `CCIO_FIND_FREE_MAPPING` must mask `ioa->res_hint` with `~((size >> 3) - 1)` so `res_ptr` is aligned for access width `size`, and `CCIO_FREE_MAPPINGS` asserts `BUG_ON((*res_ptr & mask) != mask)`, requiring unmap callers to round size to the same power-of-two bucket as allocation. [F83, F121]
- In `dino.c`, `dino_mask_irq()` and `dino_unmask_irq()` must keep `dino_dev->imr` in lockstep with `DINO_IMR`; in `dino_isr()`, initial `DINO_IRR0` reads must be masked with `DINO_IRR_MASK` (`0x5ff`) and post-loop `DINO_ILR` re-checks must be masked with `dino_dev->imr` and bounded by `--ilr_loop > 0`. [F61, F98]
- In `lba_pci.c`, `lba_rd_cfg()` and `lba_wr_cfg()` must save/restore `LBA_ERROR_CONFIG`, `LBA_STAT_CTL`, and `LBA_ARB_MASK`, only writing `CLEAR_ERRLOG` when `(error_status & LBA_FATAL_ERROR) == 0`. Writes in `elroy_cfg_write()` (when `LBA_SKIP_PROBE(d)`), `mercury_cfg_write()`, `lba_pat_out*()`, and `lba_astro_out*()` (`hw_rev < 3`) must flush posted writes by reading `LBA_PCI_CFG_ADDR` or `LBA_FUNC_ID`. [F65, F164]
- In `iosapic.c`, `iosapic_register()` must set `isi->isi_num_vectors = IOSAPIC_IRDT_MAX_ENTRY(isi->isi_version) + 1`. In `iosapic_xlate_pin()` and `irt_find_irqline()`, 1-based `PCI_INTERRUPT_PIN` must be checked for `0` and decremented (`intr_pin - 1`); when `pcidev->bus->parent` is non-NULL, `intr_pin` is swizzled once via `pci_swizzle_interrupt_pin()` while `p` walks `while (p->parent->parent) p = p->parent` before reading `PCI_SLOT(p->self->devfn)`. [F84, F85, F100]
- In `pdc_stable.c`, `struct pdc_module_path` must keep `path` at offset 0 for `(struct hardware_path *)&entry->devpath` casts; `pdcspath_entries` must remain `NULL`-terminated; and only `ktype_pdcspath` attributes may use `PATHS_ATTR` (which downcasts via `to_pdcspath_entry()`), whereas `stable_kobj` attributes must use `PDCS_ATTR`. [F74, F75, F116]
- In `stifb.c`, every `fb_ops` callback or helper that touches NGLE MMIO control registers (`stifb_setcolreg()`, `stifb_blank()`, `stifb_copyarea()`, `stifb_fillrect()`, `stifb_init_display()`) must finish by calling `SETUP_FB(fb)` to restore direct framebuffer access. [F68]

## Synchronization

- In `pdc_stable.c`, `pdcspath_fetch()` and `pdcspath_store()` require `write_lock(&entry->rw_lock)`. Once `entry->ready == 2`, any code clearing `entry->ready = 0` to update `entry->dev` (like `pdcspath_hwpath_write()`) must hold `write_lock(&entry->rw_lock)` across `pdcspath_store(entry)` so `ready` is restored to 2 before unlocking, and must drop `entry->rw_lock` before calling sleeping sysfs/kobject functions (`sysfs_create_link()`, `kobject_init_and_add()`, `kobject_uevent()`). [F2, F17, F63, F156]
- In `dino.c`, `spin_lock_irqsave(&d->dinosaur_pen, flags)` must be held across writing `DINO_PCI_ADDR` and accessing `DINO_CONFIG_DATA` or `DINO_IO_DATA`. In `sba_iommu.c` and `ccio-dma.c`, `spin_lock_irqsave(&ioc->res_lock, flags)` must be held across all PDIR bitmap allocations/frees, `iommu_coalesce_chunks()`, and `iommu_fill_pdir()`. [F20, F24]
- In `eisa.c`, 8259 PIC mask registers (`0x21`, `0xa1`) and `master_mask`/`slave_mask` require `spin_lock_irqsave(&eisa_irq_lock, flags)`, and `eisa_irq()` must drop `eisa_irq_lock` across `generic_handle_irq(irq)`. In `parisc_panic_event()`, soft-power must be updated via `pdc_soft_power_button_panic()` (`spin_trylock_irqsave(&pdc_lock, flags)`) rather than `pdc_soft_power_button()`. [F151, F154]

## Object Lifetimes

- In `pdcs_register_pathentries()`, `rwlock_init(&entry->rw_lock)` must precede `pdcspath_fetch()` and `kobject_init_and_add()`, and if `kobject_init_and_add(&entry->kobj, ...)` fails, `kobject_put(&entry->kobj)` must be called immediately without setting `entry->ready = 2`. In `pdc_stable_init()`, error rollback and `pdc_stable_exit()` must tear down in reverse: `pdcs_unregister_pathentries()`, `kset_unregister(paths_kset)`, then `kobject_put(stable_kobj)`. [F1, F3, F19]
- In `ccio_probe()`, failure after `ioremap()` must call `iounmap(ioc->ioc_regs)` before `kfree(ioc)`. In `eisa_probe()`, failures after `request_resource()`, `request_irq()`, and `ioremap()` must unwind in reverse via `error_iounmap`, `error_free_irq`, and `error_release`. In `dino_probe()` and `lba_driver_probe()`, if `pci_create_root_bus()` returns `NULL`, `pci_free_resource_list(&resources)` must be called. [F4, F11, F13]
- In `iosapic_fixup_irq()` and `iosapic_serial_irq()`, `irte`, `txn_irq`, `txn_addr`, `txn_data`, `eoi_addr`, and `eoi_data` in `struct vector_info` must be initialized before `cpu_claim_irq()`. In `parse_slot_config()`, `board` must only be freed with `kfree(board)` when `id_string_used == 0`. In `hppa_led_generic_probe()`, failure at index `i` must unregister `p->leds[0..i-1].led_cdev`. [F9, F10, F23]

## API Contracts

- `gsc_alloc_irq()` and `gsc_claim_irq()` return `< 0` on failure without populating `struct gsc_irq *i`, and `gsc_claim_irq(i, irq)` takes the unshifted GSC IRQ index (it adds `CPU_IRQ_BASE`). `gsc_assign_irq()` and `gsc_find_local_irq()` return `NO_IRQ` (`-1`) on failure, which callers (`gsc_asic_assign_irq()`, `dino_assign_irq()`) must check before storing. `iosapic_serial_irq()` returns `0` on failure (callers check `!dev->irq`), whereas `iosapic_fixup_irq()` returns `-1`. [F33, F34, F35, F36]
- Unlike `sba_free_range(ioc, iova, size)` (byte count), `ccio_free_range(ioc, iova, pages_mapped)` takes a page count (`size >> IOVP_SHIFT`) and triggers `BUG_ON(pages_mapped > BITS_PER_LONG)` if passed bytes. `sba_dma_supported()` must accept 64-bit masks (`mask > ~0U`). [F42, F167]
- `lba_set_iregs(lba, ibase, imask)` requires `ibase` and unshifted `imask` to have bits 0..20 cleared. `elroy_cfg_*()` and `mercury_cfg_*()` must reject `pos > 255 || devfn > 255` with `-EINVAL`. In `pcibios_allocate_bridge_resources()`, bridge windows must use `pci_claim_bridge_resource()`, zeroing `r->start`, `r->end`, and `r->flags` on failure. [F43, F127, F175]

## Error Handling

- `GET_IOC(dev)`, `ccio_get_iommu(dev)`, and `iosapic_register()` can return `NULL`; all callers (`ccio_ops`, `sba_ops`, `iosapic_fixup_irq()`) must check for `NULL`. Likewise, `entry->dev` in `struct pdcspath_entry` can be `NULL` even when `entry->ready == 1`, and `ioremap()` in `lba_driver_probe()`, `ccio_probe()`, `eisa_probe()`, `serial_init_chip()`, and `stifb_init_fb()` must be checked for `NULL`. [F37, F39, F46, F53]
- In `power_init()`, `soft_power_reg == 0` denotes a Gecko switch read via `__getDIAG(25)` (where bit 31 is active-low), so `kpowerswd()` must check `if (soft_power_reg)` before `gsc_readl(soft_power_reg)`; `power_task` must be initialized to `NULL` and checked with `IS_ERR(power_task)`, calling `pdc_soft_power_button(0)` on failure. In `stifb_init_fb()`, `framebuffer_alloc()` failure returns `-ENOMEM` directly before `out_err0` (`framebuffer_release()`). [F14, F50, F51, F56, F92]

## External Contracts

- In `pdc_stable.c`, all sysfs `.store` handlers must check `capable(CAP_SYS_ADMIN)` (`-EACCES`), clamp string inputs via `strscpy(in, buf, count + 1)`, and stage `pdcs_osdep1_write()`/`pdcs_osdep2_write()` writes into zero-padded 4-byte-aligned buffers (`pdcs_osid == OS_ID_LINUX`). `pdcspath_hwpath_write()` must pre-fill `hwpath` with `0xff`, guard `likely(i)` in its reverse loop from `i = 5` to avoid underflowing `unsigned short i`, and verify `hwpath_to_device(&hwpath) != NULL` before locking `entry->rw_lock`. [F70, F71, F72, F123, F170, F171, F172]

## Known Pitfalls

- In `iosapic_wr_irt_entry()`, each `iosapic_write()` must be flushed with `readl(isp->addr + IOSAPIC_REG_WINDOW)`, and `iosapic_unmask_irq()` must call `iosapic_eoi()`. IRdT updates in `iosapic_mask_irq()` and `iosapic_set_affinity_irq()` require `spin_lock_irqsave(&iosapic_lock, flags)`, and `iosapic_set_affinity_irq()` must pass `&dummy_d0` to `iosapic_set_irt_data()` to preserve `IOSAPIC_IRDT_ENABLE` in `d0`. Also, `irt_cell` loops must check `if (cnt >= irt_num_entry)` rather than `if (!irte)`, and on 32-bit kernels `COMPARE_IRTE_ADDR` must widen `hpa` with `((hpa) | 0xffffffff00000000ULL)` rather than `F_EXTEND(hpa)`. [F66, F105, F106, F132, F165]
- In `sba_mark_invalid()`, the loop `do { ... } while (byte_cnt > IOVP_SIZE)` must stop with one page remaining because the final PDIR entry is cleared (`((u8 *)pdir_ptr)[7] = 0`) unconditionally after the `if` block. In `iommu_coalesce_chunks()`, `max_seg_boundary = dma_get_seg_boundary(dev) + 1` must be checked for non-zero overflow before clamping `max_seg_size`. [F80, F96]
- In `dino_cfg_write()`, under `d->dinosaur_pen`, write `v & 0xffffff00` to `DINO_PCI_ADDR` and dummy-read `DINO_CONFIG_DATA` before writing `v` and `DINO_CONFIG_DATA`. In `dino_unmask_irq()`, if `DINO_ILR` shows the line already asserted after setting `DINO_IMR`, issue `gsc_writel(txn_data, txn_addr)`. Also, `pci_dev_is_behind_card_dino()` must not access `dino_device` fields outside `dino_dev->hba` before checking `dino_dev->hba.dev->id`. [F115, F128, F135]
- In `lba_driver_probe()`, set `LBA_FLAG_SKIP_PROBE` only after `pci_scan_child_bus()` when using `elroy_cfg_ops`. In `lba_pat_resources()`, `PAT_LMMIO` must `break` in the `else` branch before dereferencing `r`. In `stifb.c`, `struct stifb_info` is in `info->par` with back-pointer `fb->info` (do not cast between them), and register sequences must call `SETUP_HW(fb)` and `GET_FIFO_SLOTS()`. GSC HPAs (`soft_power_reg`, `LCD_CMD_REG`) are unmapped physical addresses that must use `gsc_read*()`/`gsc_write*()`. [F102, F113, F131, F147, F150]

## Other

- Because PA-RISC is big-endian, EISA EEPROM fields in `eisa_enumerator.c` require `get_16()`/`get_24()`/`get_32()`; `eisa_in16()`/`eisa_in32()`/`eisa_out16()`/`eisa_out32()` must byte-swap values from/to `gsc_read*()`/`gsc_write*()`; `sba_iommu.c` stores PDIR entries with `cpu_to_le64(pa)` so `SBA_PDIR_VALID_BIT` is at `((u8 *)pdir_ptr)[7]`; and `iosapic_fixup_irq()`/`iosapic_serial_irq()` must set `vi->eoi_data = cpu_to_le32(vi->txn_data)` for `iosapic_eoi()`'s `__raw_writel()`. In `__getDIAG(dr)`, `__res` must stay pinned to `asm("r28")`. [F77, F152, F155, F163, F166]
