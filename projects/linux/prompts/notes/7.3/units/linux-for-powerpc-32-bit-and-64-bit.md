# LINUX FOR POWERPC (32-BIT AND 64-BIT)

This unit provides PowerPC architecture headers (internal and UAPI) and core kernel subsystems for 32-bit and 64-bit platforms, including CPU feature discovery and setup, cache topology sysfs export, alignment emulation, useraccess/spinlocks/vDSO/code patching primitives, lazy IRQ soft-masking, IOMMU TCE DMA mapping, FADump, MCE handling, ELF module relocation, NVRAM/pstore logging, and hardware breakpoints/kprobes.

## Architecture & Data Flow
- Every SPR initialization added to `__setup_cpu_power{7,8,9,10}()` must be mirrored in `__restore_cpu_power{7,8,9,10}()`, and any `dt_cpu_ftrs.c` callback modifying `SPRN_LPCR`, `SPRN_HFSCR`, `SPRN_FSCR`, or `SPRN_PCR` on the boot CPU must run before `cpufeatures_setup_finished()` snapshots `system_registers` for `__restore_cpu_cpufeatures()`. [F36, F215]
- In `cpu_specs[]`, narrower `pvr_mask` revision entries must precede broader family entries (with `pvr_mask = 0` last); in `cpufeatures_cpu_quirks()`, `0xffffefff` POWER9 DD2.0–2.3 checks must precede `(version & 0xffff0000) == 0x004e0000`; and in `update_tlbie_feature_flag()`, Nimbus `((pvr & 0xe000) == 0)` must precede Cumulus `((pvr & 0xc000) == 0)`. [F67, F240, F241]
- In `dt_cpu_ftrs.c`, `feat_enable()` and `feat_try_enable_unknown()` must check that `hfscr_bit_nr`, `fscr_bit_nr`, and `hwcap_bit_nr` are not `-1` and `hv_support`/`os_support` are not `HV_SUPPORT_NONE`/`OS_SUPPORT_NONE` before shifting; `feat_enable_dscr()` must set `f->fscr_bit_nr = -1` before calling `feat_enable(f)` so tasks trap on first DSCR access. [F196, F301]
- In `arch/powerpc/kernel/iommu.c`, `tbl->it_map` and `struct iommu_pool` (`start`, `end`, `hint`) use 0-based indices relative to `tbl->it_offset`, whereas hardware TCE callbacks (`tbl->it_ops->set`, `clear`, `get`) take absolute TCE indices (`bitmap_index + tbl->it_offset`). [F221]
- In `module_64.c` and `module_32.c`, every `SHT_RELA` section must be sorted in-place with `sort(..., relacmp, NULL)` before `count_relocs()` or `count_pcpu_relocs()`. In `module_64.c`, `get_got_size()` must start at `relocs = 1` to zero-terminate `.mygot` for `got_for_addr()`, and `.stubs` allocations in `stub_for_addr()` and `setup_ftrace_ool_stubs()` must check and advance `me->arch.stub_count` (rounding `ool_stubs` up to `sizeof(struct ppc64_stub_entry)`). [F227, F228, F251, F274]
- In `mce.c`, `save_mce_event()` unconditionally increments `mce_nest_count` even when `index >= MAX_MC_EVT`, so `get_mce_event()` with `release == true` must decrement it whenever `index >= 0`. `machine_check_ue_event()` and `machine_check_queue_event()` must decrement `mce_ue_count`/`mce_queue_count` when `index >= MAX_MC_EVT`, and `machine_process_ue_event()` and `machine_check_process_queued_event()` must decrement them on every loop iteration including `continue`. [F153, F154]
- In `mce_handle_derror()`, the loop over `table[]` must continue after the first matching `dsisr_value` to flush all affected structures (SLB, ERAT, TLB), while populating `mce_err` and `*addr` only on the first match (requiring uncorrectable errors to precede recoverable ones in `mce_derror_table`). [F258]
- In `fadump_add_mem_range()`, adjacent ranges must not be folded when `start < fw_dump.boot_mem_top`, and if `mrange_info->is_static` is true, reaching `max_mem_ranges` must return `-ENOSPC` instead of calling `fadump_alloc_mem_ranges()`. `fadump_free_mem_ranges()` must only reset `mem_range_cnt = 0` when `is_static` is true, and when false `kfree(mem_ranges)` and zero only fields after `name`. [F203, F233]
- When `kprobe_handler()` is re-entered while `kprobe_running()` is non-NULL, it must save `(current_kprobe, kcb->kprobe_status, kcb->kprobe_saved_msr)` via `save_previous_kprobe(kcb)` before `set_current_kprobe()`, and restore them via `restore_previous_kprobe(kcb)` on completion or fault. [F213]

## Synchronization
- In `prep_irq_for_enabled_exit()`, `exit_must_hard_disable()` must be evaluated once into a local boolean and reused across `__hard_EE_RI_disable()` and the `lazy_irq_pending_nocheck()` recovery path; `trace_hardirqs_on()` must run before `__hard_EE_RI_disable()` clears `MSR_RI`, and on recovery `PACA_IRQ_HARD_DIS` must be set and `__hard_RI_enable()` called before `trace_hardirqs_off()`. [F163, F308]
- In `arch_local_irq_restore()`, testing `local_paca->irq_happened == 0` and storing `IRQS_ENABLED` to `local_paca->irq_soft_mask` must execute within an `asm goto` block registered with `RESTART_TABLE`. It must bracket `replay_soft_interrupts_irqrestore()` with `irq_enter()`/`irq_exit()` and loop back to `again` if `local_paca->irq_happened != PACA_IRQ_HARD_DIS` after `irq_exit()`. `__replay_soft_interrupts()` must keep `PACA_IRQ_REPLAYING` set in `local_paca->irq_happened` and use `local_paca` (not `get_paca()`). [F166, F169, F312]
- On `CONFIG_PPC64`, `__arch_spin_trylock()` and `__arch_write_trylock()` must store `LOCK_TOKEN` (`0x80000000 | smp_processor_id()`) in the lock word, and `__arch_read_trylock()` must sign-extend the 32-bit `lwarx` value via `__DO_SIGN_EXTEND` (`extsw`). Spin/rwlock wait loops must restore `HMT_medium()` after `HMT_low()` and only call `splpar_spin_yield()`/`splpar_rw_yield()` when `is_shared_processor()` is true. [F13, F81, F112]
- `iommu_range_alloc()` must acquire `pool->lock` with `spin_lock_irqsave()` and, when switching pools, unlock the old `pool->lock` and lock the new `pool->lock` while keeping IRQs disabled. In `__iommu_free()`, `tbl->it_ops->clear()` must clear hardware TCEs before `bitmap_clear()` releases `tbl->it_map` bits under `pool->lock`. After `tbl->it_ops->set()`, `iommu_alloc()`, `ppc_iommu_map_sg()`, and `iommu_flush_tce()` must call `tbl->it_ops->flush(tbl)` (if non-NULL) followed by `mb()`. [F170, F171, F298]
- `machine_check_early()` runs in NMI real-mode: `save_mce_event()` and `machine_check_queue_event()` must defer console logging to `mce_run_irq_context_handlers()` via `mce_irq_work_queue()` and defer `mce_notifier_list` and `memory_failure()` to `machine_process_ue_event()`. In `mce_power.c`, real-mode MCE handlers must skip host flushes, page-table walks, and UE recovery when `mce_in_guest()` is true, and guard `addr_to_pfn()` / `mce_find_instr_ea_and_phys()` with `get_paca()->in_mce < MAX_MCE_DEPTH`. [F317, F318]
- `fadump_mutex` must be held in `fadump_invalidate_release_mem()`, `registered_store()`, and `fadump_region_show()` across checking `dump_active`/`dump_registered` and calling `fadump_cleanup()`, `register_fadump()`, `fadump_unregister()`, or `fadump_region_show()`. `fadump_process()` must finish `fw_dump.ops->fadump_process()` before publishing `elfcorehdr_addr`, while `release_mem_store()` and `fadump_free_elfcorehdr_buf()` must call `vmcore_cleanup()` and set `elfcorehdr_addr = ELFCORE_ADDR_ERR` before freeing memory. [F175, F176]
- In `cacheinfo.c`, `cacheinfo_cpu_online`, `cacheinfo_cpu_offline`, `cacheinfo_teardown`, and `cacheinfo_rebuild` must be called in process context holding the CPU hotplug lock. `cacheinfo_cpu_online()` must finish `cache_chain_instantiate()` before calling `cacheinfo_sysfs_populate()`, and `cacheinfo_create_index_dir()` must assign `index_dir->cache = cache` before `kobject_init_and_add()`. [F9, F10, F121]

## Object Lifetimes
- In `cacheinfo.c`, every `struct cache` allocated by `new_cache()` must be torn down via `release_cache()` (never direct `kfree()`) only when its `shared_cpu_map` becomes empty across the entire `cache->next_local` chain. `cacheinfo_cpu_offline()` must call `remove_cache_dir()` and reset `per_cpu(cache_dir_pcpu, cpu_id) = NULL` before calling `cache_cpu_clear()`, and `cache_cpu_clear()` must save `next = cache->next_local` before `release_cache(cache)` while walking from lower to higher cache levels. [F1, F5, F31, F72]
- Once `cacheinfo_create_index_dir()` calls `kobject_init_and_add(&index_dir->kobj)`, error cleanup and `remove_index_dirs()` must use `kobject_put(&index_dir->kobj)` (saving `next = index->next` before `kobject_put()` in `remove_index_dirs()`) rather than `kfree(index_dir)`. [F4, F73]
- `iommu_alloc_coherent()` must call `free_pages()` if `iommu_alloc()` returns `DMA_MAPPING_ERROR`, and `iommu_free_coherent()` must call `iommu_free()` before `free_pages()`. `iommu_tce_table_get()` must use `kref_get_unless_zero(&tbl->it_kref)`, and `iommu_table_free()` must call `iommu_debugfs_del(tbl)` before freeing `tbl->it_map` and `tbl`. [F146, F174]
- `arch_prepare_kprobe()` must only allocate `p->ainsn.insn` via `get_insn_slot()` after all validations succeed, and `arch_remove_kprobe()` must call `free_insn_slot(p->ainsn.insn, 0)` and set `p->ainsn.insn = NULL`. Once `kprobe_handler()` disables preemption and sets `current_kprobe`, every non-single-stepping exit path must restore/reset `current_kprobe` and call `preempt_enable()`. [F149, F150]
- `hw_breakpoint_handler()` must hold `rcu_read_lock()` while accessing `bp_per_reg` `perf_event` slots, wrap `__get_user_instr()` in `wp_get_instr_detail()` with `pagefault_disable()`/`pagefault_enable()`, and use `perf_event_disable_inatomic()` on error. `arch_uninstall_hw_breakpoint()` must clear `bp_per_reg[i] = NULL` and zero hardware registers, and `flush_ptrace_hw_breakpoint()` must set `t->ptrace_bps[i] = NULL` after `unregister_hw_breakpoint()`. [F152, F319, F320]

## API Contracts
- `cache_lookup_or_instantiate()` and `cache_lookup_by_node_group()` borrow the caller's `device_node`, so callers (`do_subsidiary_caches()`, `cache_chain_instantiate()`, `cache_lookup_by_cpu()`) and `btext_find_display()` (on breaking from `for_each_node_by_type`) must call `of_node_put()`. [F3, F74]
- `get_user(x, ptr)` and `__get_user_size_allowed()` must zero `x` (including both words of a 64-bit load on 32-bit PowerPC) whenever `access_ok()` fails or the load faults; callers of `__get_user_atomic_128_aligned(kaddr, uaddr, err)` must enable kernel VMX beforehand and pre-initialize `err = 0`. [F24, F25]
- In `asm/syscall.h`, helpers taking `struct task_struct *task` (`syscall_get_arguments()`, `syscall_get_arch()`) must test `is_tsk_32bit_task(task)` (never `is_32bit_task()`). `syscall_get_arguments()` and `syscall_set_arguments()` must read/write `regs->orig_gpr3` (and `regs->gpr[3]` on set) for arg 0, masking args with `0xffffffffUL` when `is_tsk_32bit_task(task)` is true, and `syscall_get_nr()` must return `int`. [F59, F66, F133]
- In `iommu.c`, callers of `iommu_range_alloc()`, `iommu_alloc()`, `iommu_init_table()`, and `iommu_table_reserve_pages()` must right-shift byte DMA masks and `res_start`/`res_end` by `tbl->it_page_shift`; TCE page counts and masks must use `IOMMU_PAGE_SIZE(tbl)`, `IOMMU_PAGE_ALIGN()`, and `IOMMU_PAGE_MASK(tbl)` (not CPU `PAGE_SIZE`/`PAGE_MASK`). Optional `tbl->it_ops` callbacks (`flush`, `get`, `free`, `tce_kill`) and optional `fw_dump.ops` callbacks (`fadump_get_metadata_size`, `fadump_setup_metadata`, `fadump_cleanup`) must be checked for NULL before calling. [F182, F183, F195, F262, F325]
- `prep_irq_for_idle()` and `prep_irq_for_idle_irqsoff()` must hard-disable interrupts and set `PACA_IRQ_HARD_DIS` before checking `lazy_irq_pending()`, returning `false` if pending; when `prep_irq_for_idle_irqsoff()` returns `true`, the caller must pair it with `fini_irq_for_idle_irqsoff()`. `arch_cpu_idle()` must re-disable IRQs if `!irqs_disabled()` after `ppc_md.power_save()`. In `irq_set_pending_from_srr1()`, `srr1_to_lazyirq[0]` must be `0`, `IRQ_SYSTEM_RESET` must run `replay_system_reset()` immediately with `in_nmi = 1`, and `PACA_IRQ_DBELL` must call `ppc_msgclr(PPC_DBELL_MSGTYPE)` first. [F160, F238, F305, F307, F314]
- `nvram_create_partition()` returns a negative errno or positive data offset (`part->index + NVRAM_HEADER_LEN`), while `nvram_find_partition()` returns `0` when not found; callers must treat `p <= 0` as failure and initialize `part->index = -1`. `ppc_md.nvram_read()` and `ppc_md.nvram_write()` return bytes transferred (`<= 0` on error) and advance `*index` in-place, so callers must pass a temporary `loff_t` rather than `&part->index`. [F185, F186]

## Error Handling
- `fix_alignment()` and `emulate_spe()` must return `1` on emulated instruction (translating `0` from `emulate_dcbz()` and `emulate_loadstore()` into `1`), `-EFAULT` on user memory fault, and `0` or a negative errno (`-EIO`/`-EINVAL`) without kernel `WARN` on unemulated instructions such as copy/paste or LARX/STCX. [F21, F70, F140]
- In `hw_breakpoint_handler()`, whenever `bp[i]` is disabled on error (`handler_error()`, `larx_stcx_err()`), handled as a one-shot ptrace breakpoint, or deferred to `stepping_handler()`, `bp[i]` must be set to `NULL` before `goto reset` so `__set_breakpoint()` is not called on it. [F198]

## External Contracts
- `syscall_get_error()` and `syscall_set_return_value()` must branch on `trap_is_scv(regs)`: `scv` encodes errors as negative `IS_ERR_VALUE` in `regs->gpr[3]`, whereas non-`scv` sets `0x10000000UL` in `regs->ccr` with a positive errno in `regs->gpr[3]`. On 32-bit/compat (`asm/syscalls.h`), 64-bit syscall parameters must be split into two 32-bit arguments with a dummy 32-bit padding argument when starting in an even GPR (`r4`, `r6`, `r8`) and combined via `merge_64()`. [F26, F113]

## Known Pitfalls
- In `cpu_setup_power.c`, `__setup_cpu_power{7,8,9,10}()` and `__restore_cpu_power{7,8,9,10}()` must verify `MSR_HV` (via `init_hvmode_206(t)` or `mfmsr() & MSR_HV`) before accessing hypervisor-privileged SPRs (`LPID`, `AMOR`, `PCR`, `LPCR`, `PSSCR`, `HFSCR`, `MMCRC`, `MMCRH`), `init_LPCR_ISA300()`/`init_LPCR_ISA206()` take `lpes` as an unshifted 2-bit value, and writes to `SPRN_PTCR` must guard against `firmware_has_feature(FW_FEATURE_ULTRAVISOR)` via `set_ptcr_when_no_uv()`. [F29, F102, F107]
- In 64-bit non-prefixed inline asm in `uaccess.h` (`__put_user_asm2_goto`, `__get_user_asm2_goto`), `ld` and `std` must use `DS_FORM_CONSTRAINT` (not `"m<>"`), and in `unsafe_copy_from_user()`/`unsafe_copy_to_user()`, `_i` must advance by 4 and 2 in the `(_len & 4)` and `(_len & 2)` tail blocks. In `simple_spinlock.h`, 4-operand `lwarx` must pass `IS_ENABLED(CONFIG_PPC64)` as the `eh` hint rather than `1`. [F76, F108, F111]
- In `module_64.c`, `R_PPC64_TOC16_HA` and `R_PPC64_REL16_HA` must compute `(value + 0x8000) >> 16`, and `dedotify_versions()` must use `memmove(vers->name, vers->name + 1, strlen(vers->name))`. In `module_32.c`, `patch_location_16()` must align `loc` down with `PTR_ALIGN_DOWN(loc, sizeof(u32))` before `patch_instruction()`, and `module_trampoline_target()` must subtract `0x10000` when `addr & 0x8000` is set. [F230, F268, F269, F275]
- In `iommu.c`, `iommu_table_reserve_pages()` must use an `unsigned long` loop counter (not `int`) for `[it_reserved_start, it_reserved_end)`, and `ppc_iommu_map_sg()` / `iommu_map_page()` must verify `tbl->it_page_shift < PAGE_SHIFT` before computing `align_order = PAGE_SHIFT - tbl->it_page_shift`. [F261, F264]
- In `asm/vdso/timebase.h` and `asm/vdso/gettimeofday.h`, code shared with the 32-bit compat vDSO must test `__powerpc64__` (never `CONFIG_PPC64`), and on 32-bit builds `get_tb()` must loop `mftbu()`/`mftb()`/`mftbu()` until upper words match while `set_tb()` zeroes `SPRN_TBWL` before writing `SPRN_TBWU` and `SPRN_TBWL`. [F18, F120]
