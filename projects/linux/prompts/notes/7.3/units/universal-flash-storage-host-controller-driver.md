# UNIVERSAL FLASH STORAGE HOST CONTROLLER DRIVER

`drivers/ufs/core/ufshcd.c` implements the Universal Flash Storage Host Controller Driver (UFSHCD) core, bridging the SCSI mid-layer and `blk-mq` subsystem with UFSHCI-compliant hardware controllers. It manages UFS device probing, UPIU command and task management submission in Legacy Single Doorbell (SDB) and Multi-Circular Queue (MCQ) modes, UniPro/UIC link management, error recovery, and runtime/system power management, extensible via `ufs_hba_variant_ops`.

## Architecture & Data Flow
- Shifting a 32-bit or `unsigned long` mask by `task_tag`/`tag` (e.g., `1U << task_tag` for `REG_UTP_TRANSFER_REQ_DOOR_BELL` or `REG_UTP_TRANSFER_REQ_LIST_CLEAR`) and indexing `hba->outstanding_reqs` must only execute when `!hba->mcq_enabled`, because MCQ mode allows `hba->nutrs` (and thus `task_tag`) to exceed 31. [F122]
- Before dispatching any transfer or task management request (`ufshcd_prepare_req_desc_hdr`, `ufshcd_issue_tm_cmd`, `ufshcd_exec_raw_upiu_cmd`), `header.ocs` must be initialized to `OCS_INVALID_COMMAND_STATUS` and, for transfer requests, `lrbp->ucd_rsp_ptr` zeroed with `memset`. `ufshcd_sgl_to_prdt` must encode each segment's byte count in `prd->size` as `cpu_to_le32(len - 1)` (with `len <= SZ_256K`) and zero `prd->reserved`. [F63, F94]
- In `ufshcd_hold`, the switch on `hba->clk_gating.state` must fall through from `REQ_CLKS_OFF` (when `cancel_delayed_work` fails) to `CLKS_OFF` (queuing `ungate_work`) and `REQ_CLKS_ON`, and both `REQ_CLKS_ON` and `CLKS_ON` (when in hibern8) must unlock `clk_gating.lock`, flush `ungate_work`, relock, and jump to `start`. [F108]
- In `ufshcd_setup_clocks`, setting `CLKS_ON` requires `hba->clk_gating.is_initialized` (`ufshcd_suspend` requires `ufshcd_is_clkgating_allowed(hba)` for `CLKS_OFF`), and `clki->keep_link_active` clocks must not be disabled while `ufshcd_is_link_active(hba)` is true. [F72, F154]
- In `ufshcd_update_ee_control`, `hba->ee_ctrl_mask` is `hba->ee_drv_mask | hba->ee_usr_mask`. Neither `hba->ee_ctrl_mask` nor `*mask` may be updated in memory if `__ufshcd_write_ee_control` fails, whereas when `ee_ctrl_mask == hba->ee_ctrl_mask` and `__ufshcd_write_ee_control` is skipped, `*mask` must still be updated to `new_mask`. [F77, F119]
- `ufshcd_copy_query_response` and `ufshcd_issue_devman_upiu_cmd` must verify that the caller's buffer length is at least `be16_to_cpu(lrbp->ucd_rsp_ptr->header.data_segment_length)` before copying `UPIU_QUERY_OPCODE_READ_DESC` data. `ufshcd_read_desc_param` must validate `param_offset < buff_len` (`desc_buf[QUERY_DESC_LENGTH_OFFSET]`) and clamp the copy to `buff_len - param_offset`. [F83, F85]
- `ufshcd_get_lists_status` returns `0` only when all three `UFSHCD_STATUS_READY` bits are set, so `ufshcd_make_hba_operational` must check `!(ufshcd_get_lists_status(reg))` before `ufshcd_enable_run_stop_reg`. After reset/re-init (`ufshcd_post_device_init`, `ufshcd_probe_hba`), volatile state must be resynced via `ufshcd_force_reset_auto_bkops`, `ufshcd_set_active_icc_lvl`, `ufshcd_configure_wb`, and `ufshcd_write_ee_control`. [F78, F105]

## Synchronization
- Because `ufshcd_sl_intr()` runs in both hardirq (`ufshcd_intr()` with MCQ ESI) and threaded IRQ (`ufshcd_threaded_intr()`), its callees (`ufshcd_uic_cmd_compl()`, `ufshcd_check_errors()`, `ufshcd_tmc_handler()`) and `__ufshcd_release()` (under `clk_gating.lock`) must acquire `hba->host->host_lock` with `spin_lock_irqsave()`. `ufshcd_schedule_eh_work(hba)` must only be called while holding `hba->host->host_lock`. [F39, F162]
- Lock hierarchy: `hba->clk_gating.lock` is outer to `hba->host->host_lock`, and `hba->host->scan_mutex` -> `hba->wb_mutex` -> `down_write(&hba->clk_scaling_lock)` is the order in `ufshcd_clock_scaling_prepare()` and `ufshcd_clk_scaling_allow()`. `ufshcd_hold()` must drop `hba->clk_gating.lock` before `flush_work(&hba->clk_gating.ungate_work)`, and `ufshcd_init()` must set `host->queuecommand_may_block = !!(hba->caps & UFSHCD_CAP_CLK_GATING)`. [F40, F161, F165]
- In `ufshcd_err_handler()`, `ufshcd_err_handling_prepare(hba)` (which calls `ufshcd_rpm_get_sync(hba)`) must complete before `ufshcd_set_eh_in_progress(hba)` is called, because `UFSHCD_EH_IN_PROGRESS` causes `ufshcd_queuecommand()` to return `SCSI_MLQUEUE_HOST_BUSY` and block resume commands. [F166]
- `hba->host->host_lock` must be dropped before sleeping recovery helpers (`ufshcd_err_handling_prepare()`, `ufshcd_quirk_dl_nac_errors()`, `ufshcd_abort_all()`, `ufshcd_config_pwr_mode()`, `ufshcd_reset_and_restore()`, `ufshcd_device_reset()`) and re-acquired to recheck `ufshcd_err_handling_should_stop(hba)`. [F44, F169]
- When `hba->pm_op_in_progress` or `hba->system_suspending` is true, error recovery in `ufshcd_uic_pwr_ctrl()`, `ufshcd_err_handler()`, `ufshcd_eh_host_reset_handler()`, and `ufshcd_eh_timed_out()` must invoke `ufshcd_link_recovery(hba)` directly rather than scheduling or flushing `hba->eh_work`. In `ufshcd_queuecommand()`, `UFSHCD_STATE_EH_SCHEDULED_NON_FATAL` returns `SCSI_MLQUEUE_HOST_BUSY` only when `ufshcd_eh_in_progress(hba)` is true. [F41, F110]
- In MCQ mode, reading `hwq->sq_tail_slot`, copying the UTRD into `hwq->sqe_base_addr + hwq->sq_tail_slot`, and advancing the tail via `ufshcd_inc_sq_tail(hwq)` must all be performed under `hwq->sq_lock`. In SDB mode, `hba->outstanding_reqs` and the paired `REG_UTP_TRANSFER_REQ_DOOR_BELL` access in `ufshcd_send_command()` and `ufshcd_poll()` must be protected by `hba->outstanding_lock` with IRQs disabled. [F33, F34]
- UIC command dispatch and waiting in `__ufshcd_send_uic_cmd()`, `ufshcd_dispatch_uic_cmd()`, `ufshcd_wait_for_uic_cmd()`, and `ufshcd_uic_pwr_ctrl()` must hold `hba->uic_cmd_mutex`, while clearing `hba->active_uic_cmd` and `hba->uic_async_done` (which points to an on-stack completion) to `NULL` before returning must also hold `hba->host->host_lock`. Modifying `hba->ee_ctrl_mask`, `hba->ee_drv_mask`, or `hba->ee_usr_mask` and calling `__ufshcd_write_ee_control()` must hold `hba->ee_ctrl_mutex`. [F6, F38, F42]
- `__ufshcd_wl_suspend()` calls `ufshcd_hold(hba)` and sets `hba->clk_gating.is_suspended = true` at entry, undoing both on error and leaving them held on success until `__ufshcd_wl_resume()` clears `is_suspended` and calls `ufshcd_release(hba)`. Because `__ufshcd_wl_suspend()` calls `cancel_delayed_work_sync(&hba->ufs_rtc_update_work)`, `ufshcd_update_rtc()` must use `ufshcd_rpm_get_if_active(hba)` and `ufshcd_rpm_put(hba)` rather than `_sync` variants. [F158, F168]
- `ufshcd_clock_scaling_prepare()` and `ufshcd_err_handling_prepare()` call `blk_mq_quiesce_tagset(&hba->host->tag_set)`, and every exit or cleanup path (`-EBUSY` in `ufshcd_clock_scaling_prepare()`, `ufshcd_clock_scaling_unprepare()`, and `ufshcd_err_handling_unprepare()`) must call `blk_mq_unquiesce_tagset(&hba->host->tag_set)`. [F184]

## Object Lifetimes
- `ufshcd_alloc_host()` registers `ufshcd_devres_release()` via `devm_add_action_or_reset()` to call `scsi_host_put(host)` on device teardown, so callers and error paths must never call `scsi_host_put(hba->host)`. Both `ufshcd_add_scsi_host()` rollback and `ufshcd_remove()` must destroy `hba->tmf_queue` via `blk_mq_destroy_queue()` then `blk_put_queue()`, call `blk_mq_free_tag_set(&hba->tmf_tag_set)`, and then `scsi_remove_host(hba->host)` if `hba->scsi_host_added`. [F11, F12]
- In `__ufshcd_issue_tm_cmd()`, `req->end_io_data` points to an on-stack completion and `hba->tmf_rqs[req->tag]` exposes `req` to `ufshcd_tmc_handler()`; before calling `ufshcd_release(hba)` and `blk_mq_free_request(req)`, `hba->tmf_rqs[req->tag]` must be cleared to `NULL` and `task_tag` cleared from `hba->outstanding_tasks` under `hba->host->host_lock`. [F7]
- In `ufshcd_read_desc_param()`, when `is_kmalloc` is true, every error path after `kzalloc()` must jump to `out` to `kfree(desc_buf)`. Before reinitializing the device with `init_dev_params = true` (which overwrites `hba->dev_info.model`), `ufs_put_device_desc(hba)` must be called. When `ufshcd_alloc_mcq` changes `hba->nutrs` from `old_nutrs`, it must release SDB queues with `old_nutrs` (`ufshcd_release_sdb_queue`), reallocate via `ufshcd_memory_alloc`, and refresh LRB pointers via `ufshcd_host_memory_configure`. [F1, F3, F130]
- In `ufshcd_scsi_add_wlus()`, drop the extra reference from `__scsi_add_device()` via `scsi_device_put()` for each WLUN, and call `scsi_remove_device(hba->ufs_device_wlun)` if adding `sdev_rpmb` fails. Schedule `hba->ufs_rtc_update_work` in `ufshcd_add_lus()` only after `ufshcd_scsi_add_wlus()` succeeds, and cancel it with `cancel_delayed_work_sync()` in `__ufshcd_wl_suspend()` and before `scsi_remove_host()` in `ufshcd_remove()`. [F15, F16, F29]
- `ufshcd_sdev_configure()` takes a runtime PM ref on the device WLUN (`pm_runtime_get_noresume`), which `ufshcd_setup_links()` releases via `ufshcd_rpm_put(hba)` when `hba->luns_avail` reaches `1`. `ufshcd_sdev_destroy()` must clear `hba->ufs_device_wlun` under `host_lock` when destroying the device WLUN, or take a ref on `supplier` under `host_lock` before `device_link_remove()` and `put_device(supplier)`. [F17, F18]
- When `ufshcd_devfreq_init()` runs with `!hba->use_pm_opp`, OPPs added via `dev_pm_opp_add()` must be removed via `dev_pm_opp_remove()` if `devfreq_add_device()` fails and in `ufshcd_devfreq_remove()` after `devfreq_remove_device()`. Callers of `devfreq_recommended_opp()` and `dev_pm_opp_find_freq_floor_indexed()` must release the returned OPP with `dev_pm_opp_put(opp)`. [F19, F20]

## API Contracts
- Return value conventions: `ufshcd_wait_for_dev_cmd`, `ufshcd_exec_dev_cmd`, `ufshcd_query_flag`/`_attr`, `ufshcd_read_desc_param` (and `*_retry` wrappers), `ufshcd_send_uic_cmd`, `ufshcd_uic_pwr_ctrl`, and DME/hibern8 helpers return `0` on success, `< 0` on kernel/link error, or `> 0` on UFS OCS / UIC hardware status, so callers must check `!= 0`. Conversely, `ufshcd_dev_cmd_completion` and `ufshcd_copy_query_response` must return only `0` or `< 0` (`WARN_ONCE(err > 0)`), and `ufshcd_read_string_desc` returns string length `>= 0` or `< 0` errno. [F50, F51, F52, F55]
- `ufshcd_wait_for_register` and `ufshcd_clear_tm_cmd` return `0` on success and `-ETIMEDOUT` on timeout. `ufshcd_issue_tm_cmd` returns `0` even if `treq.header.ocs != OCS_SUCCESS` (leaving `*tm_response` unmodified), so callers must initialize `tm_response` to an invalid sentinel (e.g., `0xF`) and check both return value and `tm_response`. `ufshcd_utrl_clear` takes a pre-shifted bitmask (`1U << task_tag`), whereas `ufshcd_utmrl_clear` takes a 0-based bit position (`u32 pos`). [F53, F54, F66]
- `hba->tmf_queue` is used solely by `__ufshcd_issue_tm_cmd()` via `blk_mq_alloc_request()` to reserve a tag and must never have requests queued on it (`ufshcd_queue_tmf` triggers `WARN_ON_ONCE`). Controllers and variant drivers must toggle IRQs via `ufshcd_enable_irq` and `ufshcd_disable_irq` to keep `hba->is_irq_enabled` synchronized. [F69, F176]
- In `ufshcd_opp_config_clks`, increment `idx` in `dev_pm_opp_get_freq_indexed(opp, idx++)` for every non-null `clki->clk` before skipping zero-frequency entries (`if (!freq) continue;`). Check `ufshcd_is_clkscaling_supported(hba)` before calling `ufshcd_scale_clks()` outside devfreq. [F111, F153]

## Error Handling
- In `ufshcd_err_handler`, each pass at `again:` must reset `needs_restore = false`, `needs_reset = false`, and `hba->ufshcd_state = UFSHCD_STATE_RESET` (if not `UFSHCD_STATE_ERROR`), and loop back to `again:` (up to `MAX_ERR_HANDLER_RETRIES`) if `ufshcd_state` is neither `OPERATIONAL` nor `ERROR`. In `ufshcd_reset_and_restore`, each attempt must accumulate and clear `hba->saved_err`, `hba->saved_uic_err`, and `hba->force_reset` under `host_lock`, restoring the accumulated errors if all retries fail. In `ufshcd_verify_dev_init`, break out of the retry loop immediately on `-ETIMEDOUT`. [F113, F114, F121]
- Regulator pointers in `hba->vreg_info` (`vcc`, `vccq`, `vccq2`, `vdd_hba`) can be `NULL`; `ufshcd_disable_vreg()` must skip `regulator_disable()` when `vreg->always_on` is set, and `ufshcd_config_vreg_load()` must skip `regulator_set_load()` when `!vreg->max_uA`. Clock loops over `hba->clk_list_head` must check `!IS_ERR_OR_NULL(clki->clk)` and skip `clk_set_rate()` when `freq == 0`. In `ufshcd_devfreq_target`, initialize `scale_up = false` and `sched_clk_scaling_suspend_work = false` before any `goto out;`. [F58, F59, F62, F155]

## External Contracts
- In `ufshcd_queuecommand()`, when `hba->ufshcd_state == UFSHCD_STATE_EH_SCHEDULED_FATAL` and `hba->pm_op_in_progress` is true, fail the command immediately with `DID_BAD_TARGET` via `scsi_done(cmd)` (and set `hba->force_reset = true`) rather than returning `SCSI_MLQUEUE_HOST_BUSY`. When issuing `START_STOP` in `ufshcd_set_dev_pwr_mode()` and `ufshcd_execute_start_stop()`, set `hba->host->eh_noresume = 1` and pass `BLK_MQ_REQ_PM | SCMD_FAIL_IF_RECOVERING` to `scsi_execute_cmd()`. In `ufshcd_abort()`, never issue task abort on `UFS_UPIU_UFS_DEVICE_WLUN`; set `hba->force_reset = true` and call `ufshcd_schedule_eh_work(hba)`. [F177, F178, F179]
- Unless `UFSHCD_QUIRK_PRDT_BYTE_GRAN` is set, `ufshcd_host_memory_configure()` must shift `response_offset`, `prdt_offset`, and `ALIGNED_UPIU_SIZE` right by 2 (`>> 2`), and `ufshcd_sgl_to_prdt()` / `ufshcd_print_tr()` must only scale `prd_table_length` by `ufshcd_sg_entry_size(hba)` under that quirk. `ufshcd_transfer_req_compl()` must ignore the return value of `ufshcd_poll()` and unconditionally return `IRQ_HANDLED`. [F124, F174]

## Known Pitfalls
- Because `sizeof(struct utp_upiu_rsp)` exceeds 32 bytes, locating a Query Read Descriptor or EHS payload in `lrbp->ucd_rsp_ptr` must add byte offset 32 (`GENERAL_UPIU_REQUEST_SIZE` or `EHS_OFFSET_IN_RESPONSE`) to `(u8 *)lrbp->ucd_rsp_ptr`, never `lrbp->ucd_rsp_ptr + 1`. Step UCD and PRDT pointers in `ufshcd_init_lrb`, `ufshcd_sgl_to_prdt`, and `ufshcd_print_tr` by `ufshcd_get_ucd_size(hba)` and `ufshcd_sg_entry_size(hba)`. [F98, F131]
- HBA device (`hba->dev`) callbacks use `dev_get_drvdata(dev)` (so `dev_set_drvdata` must precede callback registration in `ufshcd_init()`), whereas `ufs_dev_wlun_template` (`ufshcd_wl_*`) callbacks receive `&sdev->sdev_gendev` and must use `shost_priv(to_scsi_device(dev)->host)`. [F25, F135]
- Multi-byte fields in byte-indexed UFS descriptors (`desc_buf` in `ufshcd_wb_probe`) and `upiu_data->osf3` (`ufshcd_set_timestamp_attr`, `ufshcd_read_device_lvl_exception_id`) must use `get_unaligned_be*` and `put_unaligned_be64`. In `ufshcd_wb_probe`, read `dev_info->ext_wb_sup` as 16-bit BE at `DEVICE_DESC_PARAM_EXT_WB_SUP` and `ext_ufs_feature` as 32-bit BE at `DEVICE_DESC_PARAM_EXT_UFS_FEATURE_SUP`, and reset `d_lu_wb_buf_alloc = 0` on every LUN loop iteration before `ufshcd_read_unit_desc_param`. [F65, F101, F118]
- Use `lower_32_bits()` and `upper_32_bits()` (never `>> 32`) when programming `dma_addr_t` into `REG_UTP_TRANSFER_REQ_LIST_BASE_*` and `REG_UTP_TASK_REQ_LIST_BASE_*`; use `div_u64(..., 1000)` (never `/`) on 64-bit nanosecond timestamps in `ufshcd_print_evt()`, `ufshcd_print_tr()`, and `ufshcd_print_host_state()`; keep the downward loop counter `int i` signed in `ufshcd_get_max_icc_level()`; and check `ts64.tv_sec < hba->dev_info.rtc_time_baseline` before subtracting in `ufshcd_update_rtc()`. [F96, F123, F125, F126]
