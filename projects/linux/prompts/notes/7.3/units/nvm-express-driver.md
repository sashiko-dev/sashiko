# NVM EXPRESS DRIVER

The NVMe host subsystem (`drivers/nvme/host`) manages controller, subsystem, and namespace lifecycles (`nvme_ctrl`, `nvme_subsystem`, `nvme_ns_head`, `nvme_ns`), block-layer request setup and completion, ANA multipath failover, ioctl/`io_uring` passthrough, DH-HMAC-CHAP/TLS authentication, and the PCIe, TCP/TLS, and RDMA transport drivers.

## Architecture & Data Flow

- `nvme_change_ctrl_state()` enforces legal `ctrl->state` transitions under `ctrl->lock` (never transitioning out of terminal `DELETING`, `DELETING_NOIO`, or `DEAD` into `LIVE`, `RESETTING`, or `CONNECTING`), starting `failfast_work` on `RESETTING->CONNECTING` and stopping it, clearing `NVME_CTRL_FAILFAST_EXPIRED`, and kicking requeue lists on `CONNECTING->LIVE`. `nvme_path_is_disabled()` and Fabrics `nvme_check_ready()` must treat `NVME_CTRL_DELETING` as enabled/live. [F32, F51, F94, F95]
- `gendisk->private_data` is `struct nvme_ns_head *` when `nvme_disk_is_ns_head(disk)` (`disk->fops == &nvme_ns_head_ops`) and `struct nvme_ns *` when `disk->fops == &nvme_bdev_ops`. `req->q->queuedata` is `struct nvme_ns *` on I/O queues and `NULL` on admin, fabrics, and connect queues; shared helpers (`nvme_init_request()`, `nvme_req_qid()`, `nvme_map_user_request()`, `nvme_submit_user_cmd()`, `nvme_log_error()`, sysfs callbacks) must check before casting or dereferencing. [F41, F42]
- `struct nvme_request` (`status`, `retries`, `flags`), `struct nvme_iod` (`flags`, `nr_descriptors`, `total_len`, `meta_total_len`), and `struct nvme_tcp_request` (`status`, send counters) in blk-mq request PDUs are not zeroed on allocation: `nvme_prep_rq()` and `nvme_tcp_setup_cmd_pdu()` must reset them, and paths completing un-prepped requests (`!(rq->rq_flags & RQF_DONTPREP)`, e.g., `nvme_fail_nonready_command()`) must call `nvme_clear_nvme_request()` first. [F47, F243]
- All per-request completion effects (error logging, `nvme_end_req_zoned()`, bio completion tracing, `nvme_mpath_end_request()`) must live in `__nvme_end_req()` so both `nvme_end_req()` and batched `nvme_complete_batch_req()` run them. In `nvme_decide_disposition()`, `blk_noretry_request(req)`, `NVME_STATUS_DNR`, and `retries >= nvme_max_retries` must return `COMPLETE` before checking `NVME_SC_AUTH_REQUIRED`, `REQ_NVME_MPATH` failover, or `RETRY`. [F53, F89]
- NVMe I/O queue IDs (`qid`) and `queues[]` indices (`queues[0]` is admin, `queues[1..n]` are I/O) are 1-based, whereas I/O `blk_mq_tag_set` `hctx` indices, `tags[]`, and `mq_map[]` are 0-based; mapping between them (in `nvme_req_qid()`, `__nvme_submit_sync_cmd()`, and `nvme_init_hctx*()`) must offset by `+/- 1`. 1-based `crd` (masked/shifted to `<= 3`), `bi_write_stream`, and `cur_fw_slot` treat `0` as inactive and index `ctrl->crdt[]`, `head->plids[]`, and `log->frs[]` at `val - 1`. [F78, F79, F110, F274]
- Multipath paths (`nvme_scan_work()`, `nvme_handle_aen_notice()`, `nvme_failover_req()`, `nvme_mpath_update()`, `nvme_mpath_stop()`, `nvme_mpath_add_disk()`) must verify `ctrl->ana_log_buf != NULL` (or `nvme_ctrl_use_ana(ctrl)`) before queueing `ana_work` or parsing. `nvme_update_ns_ana_state()` must not call `nvme_mpath_set_live()` when `ctrl->state != NVME_CTRL_LIVE`; `nvme_start_ctrl()` calls `nvme_mpath_update()` once live and unquiesced. [F60, F143]
- Async Event Requests (`nvme_is_aen_req()` on QID 0 or `nvme_tcp_async_req()` matching `&ctrl->async_req`) have no `struct request`, so completion/send/error paths in `pci.c`, `tcp.c`, and `rdma.c` must check for AEN before calling `nvme_find_rq()` or `blk_mq_rq_from_pdu()`. In `nvme_find_rq()`, 8-bit `nvme_req(rq)->genctr` must be masked with `nvme_genctr_mask` (`0xf`) before comparing with `nvme_genctr_from_cid(command_id)`. [F115, F240]
- In `nvme_tcp_recv_pdu()`, `nvme_tcp_c2h_term` must dispatch to `nvme_tcp_handle_c2h_term()` and return before digest checks; otherwise `hdr->hlen == sizeof(struct nvme_tcp_rsp_pdu)` must be verified before `nvme_tcp_verify_hdgst()` accesses `pdu + hdr->hlen`. `nvme_tcp_init_recv_ctx()` must be called before `nvme_tcp_rsp`/`nvme_tcp_r2t` and after C2H data/ddgst completion, never in `nvme_tcp_c2h_data` before payload consumption, and `nvme_tcp_recv_state()` must check `pdu_remaining` before `ddgst_remaining` and `data_remaining` (`-1` initially). [F258, F266, F267, F292, F296]

## Synchronization

- Workqueues drain in order `nvme_delete_wq -> nvme_reset_wq -> nvme_wq`: `nvme_do_delete_ctrl()` must flush `ctrl->reset_work`, call `nvme_stop_ctrl()`, `nvme_remove_namespaces()`, `ctrl->ops->delete_ctrl()`, and `nvme_uninit_ctrl()` in that exact order. Before freeing the admin queue, transports must leave `NVME_CTRL_LIVE` and flush `ctrl->async_event_work`. `nvme_remove_namespaces()` must call `nvme_mpath_clear_ctrl_paths(ctrl)` and `nvme_unquiesce_io_queues(ctrl)` before `flush_work(&ctrl->scan_work)`. [F18, F20, F21, F131]
- When shutting down a controller or removing tagsets in `nvme_dev_disable()`, `nvme_tcp_teardown_admin_queue()`, `nvme_tcp_teardown_io_queues()`, `nvme_rdma_teardown_admin_queue()`, and `nvme_rdma_teardown_io_queues()`, quiesced queues must be unquiesced (`nvme_unquiesce_io_queues()` / `nvme_unquiesce_admin_queue()`) after canceling requests and before removing tagsets. [F380]
- `ctrl->namespaces` updates must hold `ctrl->namespaces_lock`, check `test_bit(NVME_CTRL_FROZEN, &ctrl->flags)` before adding in `nvme_alloc_ns()`, use RCU list primitives, and call `synchronize_srcu(&ctrl->srcu)` after removal before calling `nvme_ns_remove()` unlocked with `list_for_each_entry_safe()`. Readers under `srcu_read_lock(&ctrl->srcu)` must use `list_for_each_entry_srcu()` and `nvme_get_ns()`. [F22, F98, F171]
- `nvme_subsystems_lock` must be acquired before `subsys->lock` when nesting; `nvme_subsystems_lock` protects `nvme_subsystems` (`kref_get_unless_zero(&subsys->ref)` in `__nvme_find_get_subsystem()`) and `subsys->ctrls` (including `nvme_subsys_iopolicy_update()` calling `nvme_mpath_clear_ctrl_paths()`). `delayed_removal_secs_store()` must update `head->delayed_removal_secs` and `NVME_NSHEAD_QUEUE_IF_NO_PATH` in lockstep under `subsys->lock` followed by `synchronize_srcu(&head->srcu)`, and `nvme_mpath_remove_disk()` / `nvme_remove_head_work()` must recheck `list_empty(&head->list)` under `subsys->lock`. [F26, F35, F58, F59, F164]
- `subsys->lock` serializes `subsys->nsheads` and `head->list`, while lockless readers of `head->list` and `head->current_path[]` (including `nvme_find_path(head)` plus synchronous command submission in `ns_head_update_nuse()` and `nvme_send_ns_head_pr_command()`) must hold `srcu_read_lock(&head->srcu)`. In `nvme_ns_remove()`, `synchronize_srcu(&ns->head->srcu)` is required after clearing `NVME_NS_READY`, after `nvme_mpath_clear_current_path(ns)`, and after `list_del_rcu(&ns->siblings)`. Every acquisition of `head->requeue_lock` must disable IRQs (`spin_lock_irqsave()` / `spin_lock_irq()`). [F25, F160, F173, F228]
- Reading/parsing `ctrl->ana_log_buf` must hold `ctrl->ana_lock`, and before freeing or reallocating `ctrl->ana_log_buf` via `nvme_mpath_uninit()` (including when `ana_log_size` grows in `nvme_mpath_init_identify()`, which also resets `ctrl->nr_active = 0`), `nvme_mpath_stop(ctrl)` must synchronously stop `ctrl->anatt_timer` and `ctrl->ana_work`. [F31, F61]
- In `drivers/nvme/host/pci.c`, all SQE copies, `sq_tail`/`last_sq_tail` updates, and doorbell writes (`nvme_sq_copy_cmd()`, `nvme_write_sq_db()`) must hold `nvmeq->sq_lock`; shadow doorbells in `nvme_dbbuf_update_and_check_event()` require `wmb()` before writing `*dbbuf_db` and a full `mb()` before reading `*dbbuf_ei`. In `nvme_poll_cq()`, `dma_rmb()` must follow `nvme_cqe_pending()` before reading CQE fields, and non-IRQ callers must hold `nvmeq->cq_poll_lock` (bracketed by `disable_irq()`/`enable_irq()` in `nvme_poll_irqdisable()`, or after IRQs are freed and before `nvme_cancel_tagset()` in `nvme_reap_pending_cqes()`). [F211, F212, F213, F214, F330]
- In `drivers/nvme/host/pci.c`, during `nvme_setup_io_queues()`, synchronous admin commands must run without `dev->shutdown_lock` (re-acquiring via `nvme_setup_io_queues_trylock()` which checks `NVME_CTRL_CONNECTING`), whereas `nvme_remap_bar()` must hold `dev->shutdown_lock` with `adminq` IRQ disabled and update `adminq->q_db = dev->dbs`, and `nvme_pci_update_nr_queues()` must `mutex_trylock(&dev->shutdown_lock)` and verify `dev->online_queues > 0`. On reset failure or PCI disconnect in `nvme_timeout()`, `dev->ctrl` must transition to `NVME_CTRL_DELETING` before `nvme_dev_disable()`. [F217, F218, F348, F358]
- In `drivers/nvme/host/tcp.c`, draining `queue->req_list` into `queue->send_list` (reversing LIFO via `list_add()` only when `send_list` is empty, and resetting `req->entry`/`req->lentry` in `nvme_tcp_fetch_request()`), modifying `queue->request`, and calling `nvme_tcp_try_send()` must hold `queue->send_mutex`. In `nvme_tcp_try_send_data()`, `req->data_len`, `req->h2cdata_left`, and `req->data_sent` must be snapshotted before `sock_sendmsg()`, calling `nvme_tcp_advance_req()` only when `req_data_sent + ret < req_data_len`. [F221, F299, F305]
- Stopping an NVMe/TCP queue (`nvme_tcp_stop_queue()`, `nvme_tcp_stop_io_queues()`) must run `nvme_tcp_stop_queue_nowait()` (which under `queue_lock` clears `NVME_TCP_Q_LIVE`, calls `kernel_sock_shutdown()`, clears `sk->sk_user_data = NULL` and restores callbacks under `write_lock_bh(&sk->sk_callback_lock)`—read under `read_lock_bh` in softirq—and then calls `cancel_work_sync(&queue->io_work)`) followed by `nvme_tcp_wait_queue()` until `sk_wmem_alloc_get()` drains. `nvme_rdma_stop_queue()` must hold `queue->queue_lock` across `test_and_clear_bit(NVME_RDMA_Q_LIVE, &queue->flags)` and `__nvme_rdma_stop_queue()`. [F223, F226, F333, F355]

## Object Lifetimes

- When removing the last `nvme_ns` from `head->list` in `nvme_alloc_ns()` or tearing down a head in `nvme_remove_head()` and `nvme_mpath_remove_disk()`, the `head->ref` acquired by `nvme_mpath_alloc_disk()` must be dropped via `nvme_put_ns_head()` whenever `head->disk != NULL` (even if `NVME_NSHEAD_DISK_LIVE` was never set). Before `put_disk(head->disk)` in `nvme_mpath_put_disk()`, `head->requeue_work` must be scheduled and flushed and `head->partition_scan_work` flushed. Queuing `head->remove_work` in `nvme_mpath_remove_disk()` requires `try_module_get(THIS_MODULE)` balanced by `module_put(THIS_MODULE)` in `nvme_remove_head_work()`. [F1, F15, F16]
- `nvme_init_ctrl()` sets `ctrl->ctrl_device` refcount to 1 (`nvme_free_ctrl`) and `nvme_add_ctrl()` takes a second reference via `nvme_get_ctrl(ctrl)`, so failures after `nvme_add_ctrl()` must call both `nvme_uninit_ctrl(ctrl)` and `nvme_put_ctrl(ctrl)`. If `nvme_alloc_admin_tag_set()` or `nvme_alloc_io_tag_set()` fails, it must destroy any allocated `request_queue` (`blk_mq_destroy_queue()` + `blk_put_queue()`), free the tagset (`blk_mq_free_tag_set()`), and reset `ctrl->admin_q`, `ctrl->fabrics_q`, or `ctrl->connect_q` to `NULL`. [F5, F13]
- In `nvme_tcp_free_admin_queue()`, `ctrl->async_event_work` must be canceled and `async_req.pdu` freed (`nvme_tcp_free_async_req()`) and nulled before `nvme_tcp_free_queue(ctrl, 0)` drains `queue->pf_cache`; `nvme_rdma_destroy_admin_queue()` must null `ctrl->async_event_sqe.data` after `nvme_rdma_free_qe()`. `nvme_tcp_stop_queue_nowait()` clears `queue->tls_enabled = false`, and in `nvme_tcp_error_recovery_work()` and `nvme_reset_ctrl_work()`, `nvme_tcp_key_revoke_needed()` / `nvme_auth_revoke_tls_key()` must run before `nvme_tcp_teardown_admin_queue()` resets `ctrl->tls_pskid = 0`. [F202, F206, F260]
- In `nvme_tcp_alloc_queue()`, `sock_alloc_file()` consumes `queue->sock` on error (jump to `err_destroy_mutex` without releasing `queue->sock`), whereas after it succeeds `queue->sock` must be released via `fput(queue->sock->file)` and nulled. In `nvme_rdma_process_nvme_rsp()`, if `nvme_rdma_inv_rkey()` is posted because `IB_WC_WITH_INVALIDATE` was not set on a request with `req->mr`, it must return without calling `nvme_rdma_end_request(req)` so `nvme_rdma_inv_rkey_done()` drops the second `req->ref`. [F204, F205]

## API Contracts

- Every transport's blk-mq request PDU must place `struct nvme_request` at offset 0 (`nvme_req(req)`). When `->queue_rq` fails after `nvme_setup_cmd()`, it must call `nvme_cleanup_cmd(req)`, and if calling `nvme_host_path_error(req)` it must unwind transport state and return `BLK_STS_OK`. Untrusted wire `command_id` values must be looked up via `nvme_find_rq()` (never `nvme_cid_to_rq()`, except in `nvme_tcp_recv_data()` / `nvme_tcp_recv_ddgst()` after `nvme_tcp_handle_c2h_data()` validated it), and `nvme_try_complete_req()` shifts wire `status` right by 1, so unshifted `u16` callers (`nvme_tcp_end_request()`) must pass `cpu_to_le16(status << 1)`. [F8, F85, F126, F244, F271]
- In `nvme_rdma_queue_rq()`, `req->sqe.dma` must be synced with `ib_dma_sync_single_for_cpu()` before `nvme_setup_cmd()` and `nvme_rdma_map_data()` mutate `nvme_command`, and `ib_dma_sync_single_for_device()` before `nvme_rdma_post_send()`. `ctrl->async_event_sqe` must set `cqe.done = nvme_rdma_async_done` (never `nvme_rdma_send_done`). In `nvme_tcp_timeout()` and `nvme_rdma_timeout()`, if `nvme_ctrl_state(ctrl) != NVME_CTRL_LIVE`, the handler must stop the queue, call `nvmf_complete_timed_out_request(rq)`, and return `BLK_EH_DONE`. [F264, F322, F382]

## Error Handling

- Synchronous NVMe helpers (`nvme_execute_rq()`, `__nvme_submit_sync_cmd()`, `nvme_submit_sync_cmd()`, `nvme_set_features()`, `nvme_get_features()`, `nvme_get_log()`, `nvme_tcp_setup_ctrl()`, `nvme_rdma_setup_ctrl()`) return `< 0` for errnos and `> 0` for NVMe CQE status codes (`__nvme_submit_sync_cmd()` only populates `*result` when `ret >= 0`): callers testing `NVME_STATUS_DNR` must check `ret > 0`, `ERR_PTR` functions (`nvme_alloc_ns_head()`, `nvme_tcp_create_ctrl()`, `nvme_rdma_create_ctrl()`) must convert `ret > 0` to negative errnos (`blk_status_to_errno(nvme_error_status(ret))` or `-EIO`), and `nvme_set_queue_count()` must treat `status < 0 || status == NVME_SC_HOST_PATH_ERROR` as fatal. [F36, F37, F38, F46, F233]
- In `nvmf_parse_options()`, repeatable string and key fields in `struct nvmf_ctrl_options` must `kfree()` or `key_put()` any prior value before overwriting, and `opts->host`, `opts->keyring`, and `opts->tls_key` must never be left holding an `ERR_PTR` on error because `nvmf_free_options()` unconditionally calls `nvmf_host_put()` and `key_put()`. In `nvme_tcp_setup_ctrl()` and `nvme_rdma_setup_ctrl()`, any failure after initial admin queue setup must jump to `destroy_admin` and pass the caller's `new` flag to `teardown_admin_queue`. [F7, F45, F200]
- `nvme_try_sched_reset()` returns `0` when queued and `-EBUSY` on failure; callers that quiesced I/O queues via `nvme_dev_disable(dev, false)` (`nvme_timeout()`, `nvme_slot_reset()`) must call `nvme_unquiesce_io_queues()` only when `nvme_try_sched_reset()` returns non-zero. In `nvme_rdma_map_sg_fr()`, `ib_map_mr_sg()` returns mapped entry count, so `nr < count` is an error that must return `req->mr` to `queue->qp->rdma_mrs` and set `req->mr = NULL`. [F230, F238]

## Known Pitfalls

- `nvme_find_get_ns()` and `nvme_round_robin_path()` must not use the loop cursor after termination; `nvme_lookup_ana_group_desc()` copies only the fixed header so `nvme_update_ns_ana_state()` and `nvme_mpath_add_disk()` must never read `desc->nsids[]`; `nvme_pci_setup_meta_sgls()` overwrites `cmd.common.flags = NVME_CMD_SGL_METASEG` so SGL checks must use `nvme_pci_cmd_use_sgl()` / `nvme_pci_cmd_use_meta_sgl()`; and `nvme_tcp_try_send()` must use a sequential `if (req->state == ...)` chain and jump to `out` after `NVME_TCP_SEND_CMD_PDU` when `!nvme_tcp_has_inline_data(req)`. [F99, F125, F291, F297]
