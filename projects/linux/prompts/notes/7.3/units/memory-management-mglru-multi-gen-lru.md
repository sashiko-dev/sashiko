# MEMORY MANAGEMENT - MGLRU (MULTI-GEN LRU)

Implements the kernel's page reclaim, LRU list management, workingset refault detection, and Multi-Gen LRU (MGLRU) framework across per-CPU folio batches, per-node/per-memcg lruvecs, and page table walkers (`mm/vmscan.c`, `mm/swap.c`, `mm/workingset.c`).

## Architecture & Data Flow

- While a folio is on `lrugen->folios[]`, `lru_gen_add_folio()` keeps `PG_active` clear and encodes `gen + 1` in `LRU_GEN_MASK`, and `lru_gen_del_folio()` clears `LRU_GEN_MASK` and restores `PG_active` when `!reclaiming && lru_gen_is_active(lruvec, gen)`. `folio_lru_refs()` must return `0` when `PG_referenced` is clear, and `isolate_folio()` must clear stale `LRU_REFS_MASK` bits on unreferenced folios. Shifts by `LRU_GEN_PGOFF` or `LRU_REFS_PGOFF` must widen `int` operands with `1UL`. [F61, F87, F119]
- Before `inc_max_seq()` increments `lrugen->max_seq`, it must adjust active/inactive LRU sizes via `__update_lru_size()` by `lrugen->nr_pages[prev][type][zone] - lrugen->nr_pages[next][type][zone]` for every `(type, zone)` (`prev = (max_seq - 1) % MAX_NR_GENS`, `next = (max_seq + 1) % MAX_NR_GENS`) and call `reset_ctrl_pos(lruvec, type, false)`. Advancing `lrugen->min_seq[type]` in `inc_min_seq()` or `try_to_inc_min_seq()` must first call `reset_ctrl_pos(lruvec, type, true)` under `lruvec->lru_lock`. [F62, F65]
- Because `lrugen->nr_pages[gen][type][zone]` is an eventually consistent signed `long` that can be transiently negative while `reset_batch_size()` is pending, readers accumulating generation sizes into an `unsigned long` (`lruvec_is_sizable()`, `should_run_aging()`, `lru_gen_seq_show()`) must clamp each read with `max(..., 0L)`. [F121]
- Mutating `pgdat->memcg_lru.fifo[gen][bin]` under `pgdat->memcg_lru.lock` (`lru_gen_online_memcg()`, `lru_gen_rotate_memcg()`, `lru_gen_release_memcg()`) must update `lruvec->lrugen.gen` and `pgdat->memcg_lru.nr_memcgs[gen]`, and increment `pgdat->memcg_lru.seq` when the oldest generation empties (`MEMCG_NR_GENS` must be >= 3 for lockless `get_memcg_gen()`). `shrink_many()` must only call `lru_gen_rotate_memcg()` when `shrink_one()` returns non-zero `op`, inserting `MEMCG_LRU_HEAD`/`MEMCG_LRU_OLD` at the head and `MEMCG_LRU_TAIL`/`MEMCG_LRU_YOUNG` at the tail. [F68, F104, F129]
- During MGLRU page table and rmap walks (`get_pte_pfn()`, `get_pmd_pfn()`, `walk_pte_range()`, `walk_pmd_range_locked()`, and `lru_gen_look_around()`), `!pte_young()` or `!pmd_young()` entries must not be skipped when `mm_has_notifiers(vma->vm_mm)` is true, and leaf young bits must be cleared with `{ptep,pmdp}_clear_young_notify()` rather than `{ptep,pmdp}_test_and_clear_young()`. [F82]
- In `reclaim_clean_pages_from_list()`, after `shrink_folio_list()` runs on folios isolated from the file LRU, `NR_ISOLATED_FILE` must be decremented by `nr_reclaimed + stat.nr_lazyfree_fail` and `NR_ISOLATED_ANON` incremented by `stat.nr_lazyfree_fail`, casting unsigned counters to signed `long` before negation (`-(long)nr_reclaimed`) for `mod_node_page_state()`. [F16, F120]
- `LRUVEC_NODE_CONGESTED` on the root lruvec may only be set and cleared by `kswapd` (`shrink_node()`, `clear_pgdat_congested()`), whereas cgroup reclaim in `do_try_to_free_pages()` must only clear `LRUVEC_CGROUP_CONGESTED`. Each `goto retry` in `do_try_to_free_pages()` (`!sc->memcg_full_walk`, `sc->skipped_deactivate`, `sc->memcg_low_skipped`) must reset `sc->priority = initial_priority` and clear its trigger flag. [F78, F79]
- `shrink_zones()` must save `sc->gfp_mask` in `orig_mask` before promoting `sc->gfp_mask |= __GFP_HIGHMEM` when `buffer_heads_over_limit` is true and restore `sc->gfp_mask = orig_mask` before returning. In `flush_reclaim_state()`, `current->reclaim_state->reclaimed` must only be added to `sc->nr_reclaimed` when `root_reclaim(sc)` is true. [F77, F173]
- In `pgdat_balanced()`, `NR_FREE_PAGES_BLOCKS` must only be queried when `defrag_mode && order` (falling back to `NR_FREE_PAGES` once `kswapd_shrink_node()` resets `sc->order = 0`), and `zone_page_state(zone, item)` must fall back to `zone_page_state_snapshot(zone, item)` when `zone->percpu_drift_mark` is non-zero and `free_pages < zone->percpu_drift_mark`. [F81, F101]
- In `read_ctrl_pos()`, callers must pass `MAX_NR_TIERS` (not `MAX_NR_TIERS - 1`) to sum across all tiers `[0, MAX_NR_TIERS - 1]`. In `calculate_pressure_balance()`, `total_cost`, `anon_cost`, and `file_cost` must each be incremented by `1` so divisors `anon_cost + 1` and `file_cost + 1` and `*denominator = ap + fp` are strictly positive. [F99, F123]

## Synchronization

- When isolating a folio without an existing caller reference in `isolate_lru_folios()` or `isolate_folio()`, `folio_try_get(folio)` must succeed before `folio_test_clear_lru(folio)`, calling `folio_put(folio)` if clearing `PG_lru` fails. When moving an on-LRU folio in `folio_batch_move_lru()` (`move_fn != lru_add`) or `check_move_unevictable_folios()`, `folio_test_clear_lru(folio)` must succeed before locking the `lruvec` and `folio_set_lru(folio)` must be called before unlocking. [F5, F22]
- Under `lruvec->lru_lock` in `isolate_lru_folios()`, skipping zone-ineligible folios (`folio_zonenum(folio) > sc->reclaim_idx`) without incrementing `scan` must be capped by `max_nr_skipped < SWAP_CLUSTER_MAX_SKIPPED`, `folios_skipped` must be spliced back to the head (`list_splice(&folios_skipped, src)`), and neither `isolate_lru_folios()` nor `sort_folio()` may skip CMA folios. [F113, F114]
- In `walk_pte_range()`, after `pte_offset_map_rw_nolock(args->mm, pmd, ..., &pmdval, &ptl)` and `spin_trylock(ptl)`, `pmd_same(pmdval, pmdp_get_lockless(pmd))` must be verified before reading PTEs (calling `pte_unmap_unlock(pte, ptl)` on mismatch). `inc_tlb_flush_pending(mm)` must precede acquiring `ptl`, `mm_tlb_flush_pending(mm)` and `mm_tlb_flush_nested(mm)` require `ptl` held, and `dec_tlb_flush_pending(mm)` must follow `flush_tlb_range()`. [F31, F41]
- In `__remove_mapping()`, `folio_ref_freeze(folio, 1 + folio_nr_pages(folio))` must succeed before testing `folio_test_dirty(folio)` (unfreezing via `folio_ref_unfreeze()` if dirty); callers retaining the folio (like `remove_mapping()`) must call `folio_ref_unfreeze(folio, 1)`. For non-swapcache folios, `mapping->host->i_lock` must be acquired before `xa_lock_irq(&mapping->i_pages)`, and `xa_unlock_irq(&mapping->i_pages)` must precede `inode_add_lru()` and `spin_unlock(&mapping->host->i_lock)`. [F4, F102, F159]
- `workingset_update_node()` requires `node->array->xa_lock` held, and `shadow_lru_isolate()` requires `node->array` to be `struct address_space.i_pages`, must use `xa_trylock(&mapping->i_pages)` and `spin_trylock(&mapping->host->i_lock)` (dropping `lru->lock` and returning `LRU_RETRY` on failure), and both must update `WORKINGSET_NODES` in lockstep with `shadow_nodes` insertions/removals. [F37, F73, F134]
- In `shrink_many()`, `hlist_nulls_for_each_entry_rcu(lrugen, pos, ...)` runs under `rcu_read_lock()`, must pin `memcg` with `mem_cgroup_tryget(memcg)` before dropping `rcu_read_lock()` for `shrink_one(lruvec, sc)`, must re-acquire `rcu_read_lock()` before continuing or breaking, and on loop exit must return if `!is_a_nulls(pos)` before calling `get_nulls_value(pos)`. [F106, F150]
- `lru_gen_change_state()` must lock `cgroup_lock()`, `cpus_read_lock()`, `get_online_mems()`, and `state_mutex` in that order (releasing in reverse), and migrate all evictable folios between `lruvec->lists[]` and `lruvec->lrugen.folios[]` via `fill_evictable()` or `drain_evictable()`. `inc_min_seq()`, `fill_evictable()`, and `drain_evictable()` must stop at `MAX_LRU_BATCH` and return `false` so callers drop `lruvec->lru_lock` and `cond_resched()`. [F18, F69, F116]
- In `lru_gen_migrate_mm(mm)`, the caller must hold `mm->owner->alloc_lock` (`task->alloc_lock`) and `lru_gen_migrate_mm()` must return early if `mm->lru_gen.memcg` is NULL before calling `lru_gen_del_mm(mm)` and `lru_gen_add_mm(mm)`. [F33]
- `reclaim_throttle()` must not sleep when `!current_is_kswapd() && (current->flags & (PF_USER_WORKER|PF_KTHREAD))`, and `throttle_direct_reclaim()` must not throttle any `PF_KTHREAD` task or use unbounded waits when `!(gfp_mask & __GFP_FS)`. [F156]

## Object Lifetimes

- When freeing a zero-refcount folio in `__folio_put()`, `folios_put_refs()`, `shrink_folio_list()`, or `move_folios_to_lru()`, `folio_unqueue_deferred_split(folio)` must be called before `mem_cgroup_uncharge()` or `mem_cgroup_uncharge_folios()` clears the folio's memcg association. [F1]
- `lru_gen_del_mm(mm)` must advance any node's `mm_state->head` (to `prev`) and `mm_state->tail` (to `next`) that point to `&mm->lru_gen.list` before calling `list_del_init(&mm->lru_gen.list)` under `mm_list->lock`, and must then call `mem_cgroup_put(mm->lru_gen.memcg)` and reset `mm->lru_gen.memcg = NULL`. [F11]
- `set_mm_walk()` requires `current->reclaim_state`, returns `&pgdat->mm_walk` for `kswapd` or a `kzalloc()` allocation (or `NULL`), and must be paired with `clear_mm_walk()` before clearing `reclaim_state`. Callers must handle a `NULL` `mm_walk`, flush `walk->nr_pages` and `walk->mm_stats` via `reset_batch_size()` and `reset_mm_stats()` before `clear_mm_walk()`, and `clear_mm_walk()` must only `kfree(walk)` when `!current_is_kswapd()`. [F13, F52, F56]
- `lru_gen_seq_stop()` must call `mem_cgroup_iter_break(NULL, lruvec_memcg(v))` whenever `!IS_ERR_OR_NULL(v)`, and must always free `m->private` with `kvfree(m->private)` and reset `m->private = NULL`. [F15]
- `free_anon_vma_name()` must call `anon_vma_name_put(vma->anon_name)` unconditionally without gating on `!vma->vm_file` or calling `anon_vma_name(vma)` without `mmap_lock` held. [F3]

## API Contracts

- In `shrink_folio_list()`, `try_to_unmap()` must pass `TTU_SYNC` for large folios (`folio_test_large(folio)`) and `TTU_SPLIT_HUGE_PMD` when PMD-mappable; `try_to_unmap_flush_dirty()` must precede `pageout()` after `TTU_BATCH_FLUSH` and `try_to_unmap_flush()` must precede `free_unref_folios()`; splitting a large folio must adjust `sc->nr_scanned -= nr_pages - 1` and `nr_pages = 1`; and hwpoisoned large folios must skip `unmap_poisoned_folio()`. [F157, F161, F170, F171]
- `mem_cgroup_calculate_protection()` is stateful and must only be called during a top-down `mem_cgroup_iter()` walk (`lru_gen_age_node()` after `set_initial_priority()`, or `shrink_node_memcgs()`), never in `shrink_one()`. `mem_cgroup_below_min()`, `mem_cgroup_below_low()`, `mem_cgroup_protection()`, and `mem_cgroup_calculate_protection()` take `sc->target_mem_cgroup` (or `NULL` for global reclaim) first and `memcg` second. [F57, F162]
- Callers of `lru_gen_update_size(lruvec, folio, old_gen, new_gen)` must pass `-1` for `old_gen` on addition, `-1` for `new_gen` on deletion, and valid generation indices (`0 <= gen < MAX_NR_GENS`) for both on promotion, and must never pass `-1` for both or demote from an active `old_gen` to an inactive `new_gen` without isolating the folio. [F58]
- Callers of `get_next_vma(mask, size, args, &start, &end)` in `walk_pte_range()`, `walk_pmd_range()`, and `walk_pud_range()` must first check that the table index `i` is strictly less than `PTRS_PER_PTE`, `PTRS_PER_PMD`, or `PTRS_PER_PUD` respectively, because `get_next_vma()` requires `(round_up(end, size) & mask) == (start & mask)`. [F60]
- In `for_each_managed_zone_pgdat(zone, pgdat, idx, highidx)`, `highidx` is an inclusive upper bound (`idx <= highidx`) that must be `< MAX_NR_ZONES` (translating the `MAX_NR_ZONES` sentinel via `kswapd_highest_zoneidx()`), and `zone` is left past the end of the loop and must be reinitialized before reuse. [F98]
- `zone_reclaimable_pages()` must only sum `NR_ZONE_INACTIVE_FILE`, `NR_ZONE_ACTIVE_FILE`, and (when `can_reclaim_anon_pages()` is true) `NR_ZONE_INACTIVE_ANON` and `NR_ZONE_ACTIVE_ANON`, never falling back to `NR_FREE_PAGES`. Page demotion accounting (`PGDEMOTE_KSWAPD + reclaimer_offset(sc)`) in `shrink_inactive_list()` and `evict_folios()` must not be guarded by `CONFIG_NUMA_BALANCING`. [F80, F165]

## Error Handling

- MGLRU page-table scans (`lru_gen_look_around()`, `should_skip_vma()`) must skip `VM_SPECIAL` VMAs before calling `get_pte_pfn()`, and callers of `get_pte_pfn()` and `get_pmd_pfn()` must check `pfn != -1` (`~0UL`) before passing `pfn` to `get_pfn_folio()`, which unconditionally dereferences `pfn_folio(pfn)`. [F43, F163]
- Because `reset_bloom_filter()` can store `NULL` on allocation failure, `test_bloom_filter()` must return `true` and `update_bloom_filter()` must return early when `mm_state->filters[gen]` is `NULL`. Callers of `get_mm_state()` and `get_mm_list()` outside `CONFIG_LRU_GEN_WALKS_MMU` (e.g. `try_to_inc_max_seq()`, `lru_gen_init_lruvec()`) must also check for `NULL`. [F50, F51]

## External Contracts

- `user_proactive_reclaim()` requires exactly one of `memcg` or `pgdat` to be non-NULL, rejects numeric `swappiness=%d` outside `[0, 200]`, and only sets `SWAPPINESS_ANON_ONLY` (`201`) for `"swappiness=max"`. Any `swappiness` passed to `min_type()`, `max_type()`, `evictable_min_seq()`, or `for_each_evictable_type()` must be normalized via `get_swappiness()` to `[0, 201]`. [F92, F97]
- In `init_lru_gen()`, `debugfs_create_file_aux_num()` must pass `false` for `"lru_gen"` (`lru_gen_rw_fops`) and `true` for `"lru_gen_full"` (`lru_gen_ro_fops`) so `debugfs_get_aux_num(m->file)` in `lru_gen_seq_show()` selects full output only for `"lru_gen_full"`. [F100]

## Known Pitfalls

- In `set_initial_priority()`, `sc->nr_to_reclaim` must be at least `MIN_LRU_BATCH` before computing `fls_long(sc->nr_to_reclaim - 1)`, and `sc->priority` must be clamped to `[DEF_PRIORITY / 2, DEF_PRIORITY]`. In `get_scan_count()`, `SCAN_FRACT` division must use `div64_u64()` when `mem_cgroup_online(memcg)` is true and `DIV64_U64_ROUND_UP()` when false. [F94, F122]
- `lruvec_is_reclaimable()` must check generation expiration with `time_is_before_jiffies(birth + min_ttl)`. `lru_to_folio(head)` resolves `list_entry((head)->prev, struct folio, lru)` (the tail folio of a list head or the predecessor of `&folio->lru`, requiring `folio->lru.prev != _base` in `prefetchw_prev_lru_folio()`). [F128, F135]
