# AMD DISPLAY CORE

AMD Display Core bridges the Linux DRM/KMS atomic modesetting framework, the AMDGPU IP lifecycle, and the OS-agnostic Display Core (`dc`) engine, managing hardware init/suspend/resume, atomic commits, color management, vblank/CRC/PSR, DP MST/DSC, HDCP/secure-display TAs, DMUB firmware, VBIOS/ATOMFirmware parsing (`dc/bios`), and display clocks (`dc/clk_mgr`).

## Architecture & Data Flow
- Connector loops must exclude `DRM_MODE_CONNECTOR_WRITEBACK` before calling `to_amdgpu_dm_connector()` because `SIGNAL_TYPE_VIRTUAL` links use `struct amdgpu_dm_wb_connector`. Also keep `struct drm_connector base` at offset 0 of `struct amdgpu_dm_connector` because debugfs callbacks cast `m->private`/`i_private` to both `amdgpu_dm_connector *` and `drm_connector *`. [F70, F296]
- Before `drm_atomic_helper_resume()` in `dm_destroy_cached_state()`, every CRTC in `dm->cached_state` must set `active_changed` and `color_mgmt_changed` to `true`, reset freesync config, and release and null duplicated `dm_new_crtc_state->stream` and `dm_new_plane_state->dc_state`. [F53]
- In `increase_dsc_bpp()` and `try_disable_dsc()`, if `drm_dp_mst_atomic_check(state)` fails after updating `vars[next_index].pbn` and calling `drm_dp_atomic_find_time_slots()`, `vars[next_index].pbn` must be restored and `drm_dp_atomic_find_time_slots()` called again to roll back the time-slot reservation. [F239]
- In `compute_mst_dsc_configs_for_link()` and `set_dsc_configs_from_fairness_vars()`, `params` is indexed `0..count-1` locally while `vars` is shared across all MST links in `dc_state` and must be indexed at `vars[i + k]` (`k = *link_vars_start_index`, advanced by `count` per link). After `compute_mst_dsc_configs_for_link()` succeeds, mark all streams sharing `stream->link` `true` in `computed_streams[]`. [F261, F279]
- In `dm_helpers_dp_write_dsc_enable()` for non-Synaptics DP MST streams with `port->passthrough_aux`, enabling DSC writes `DP_DSC_ENABLE` to `passthrough_aux` before `aconnector->dsc_aux`, while disabling writes `dsc_aux` before `passthrough_aux`. In `dm_dp_mst_is_port_support_mode()`, when `passthrough_aux` and `immediate_upstream_port` are `NULL` (LCT=1), `virtual_channel_bw_in_kbps` must fall back to `root_link_bw_in_kbps` and still be checked against `bw_range.min_kbps`. [F267, F305]
- Overriding DSC settings in `dp_dsc_*_write()` debugfs handlers must set `dm_crtc_state->dsc_force_changed = true` on `crtc->state`, whereas `amdgpu_dm_crtc_duplicate_state()` must leave `dsc_force_changed` zeroed so subsequent commits do not force a modeset. [F238]
- In `amdgpu_dm_update_plane_color_mgmt()`, reset `dc_plane_state->in_transfer_func` to `TF_TYPE_BYPASS` first and reject (`-EINVAL`) simultaneous plane degamma (`__set_dm_plane_degamma() != -EINVAL`) and CRTC degamma (`cm_has_degamma || cm_is_degamma_srgb`). Enable CRTC degamma in `amdgpu_dm_crtc_init()` only when `dpp.dcn_arch` and `dce_version != DCN_VERSION_4_01`, `regamma_tf_property` only when `mpc.ogam_ram`, and 3D LUT in `amdgpu_dm_verify_lut3d_size()` only when both `dpp.hw_3d_lut` and `mpc.preblend` are true. [F237, F308, F309]
- In `mmhub_read_system_context()`, on `AMD_APU_IS_RAVEN2 | AMD_APU_IS_RENOIR | AMD_APU_IS_GREEN_SARDINE`, `logical_addr_high` must add `0x1` to `adev->gmc.fb_end >> 18`, and 32-bit aperture values (`logical_addr_low`, `logical_addr_high`, `agp_base`, `agp_bot`, `agp_top`) must be cast to `uint64_t` before left-shifting by 18 or 24. [F102, F154]
- `fill_dc_dirty_rects()` must ensure total dirty rects (including the 2 plane bounding-box rects when `mpo_requested && bb_changed`) do not exceed `DC_MAX_DIRTY_RECTS`, falling back to a single full-frame rect in `dirty_rects[0]`. [F79]
- Pipe/stream filters: `dm_helpers_dp_handle_test_pattern_request()` must require `!pipes[i].top_pipe && !pipes[i].prev_odm_pipe` and return `false` if `pipe_ctx` is `NULL`; `dce_get_max_pixel_clock_for_all_paths()` must skip `stream == NULL` or `top_pipe != NULL`; and `clk_mgr_helper_get_active_display_cnt()` must skip `SUBVP_PHANTOM` streams. [F278, F416, F417]
- Because `bios_parser_types_internal.h` and `bios_parser_types_internal2.h` define incompatible `struct bios_parser` layouts, `BP_FROM_DCB` must only be used in callbacks belonging to the matching parser's `vbios_funcs` table, never in `bios_parser_helper.c`. [F431]
- In `command_table2.c`, DMUB-capable initializers (`init_dig_encoder_control`, `init_transmitter_control`, `init_set_pixel_clock`, `init_enable_disp_power_gating`) must wire unrecognized table revisions to their `*_fallback` handlers rather than `NULL`. New `enum encoder_id` mappings must update `encoder_id_from_bios_object_id()`, `dal_cmd_table_helper_encoder_id_to_atom()`, and `dal_cmd_table_helper_encoder_id_to_atom2()` in lockstep. [F393, F394]

## Synchronization
- When `amdgpu_in_reset(adev)` is true, `dm_suspend()` returns with `dm->dc_lock` held across the GPU reset until `dm_resume()` unlocks it after `dm_gpureset_commit_state()` and `amdgpu_dm_irq_resume_late()`; do not call helpers that take `dm->dc_lock` (like `amdgpu_dm_backlight_set_level()`) before unlocking. [F144]
- High-context IRQ handlers in `irq_handler_list_high_tab` run under `spin_lock_irqsave(&adev->dm.irq_handler_list_table_lock)` from `amdgpu_dm_irq_handler()` and must not sleep or re-acquire `DM_IRQ_TABLE_LOCK`. `amdgpu_dm_irq_register_interrupt()` allocates with `GFP_KERNEL` (cannot run in atomic context) and must initialize all `handler_data` fields and `INIT_WORK(&handler_data->work, dm_irq_work_func)` before `list_add_tail()`. [F197, F321, F322]
- `amdgpu_dm_crtc_set_vblank()` runs in atomic context under DRM vblank/event spinlocks, so it must allocate `struct vblank_control_work` with `GFP_ATOMIC` and defer operations needing `dm->dc_lock` to `amdgpu_dm_crtc_vblank_control_worker`. [F325]
- `drm_device.event_lock` protects `acrtc->dm_irq_params` and `crtc_ctx->roi`/`crc_info.crc` across hardirq and process/workqueue contexts, so all acquisitions must disable interrupts. In `amdgpu_dm_crtc_handle_crc_window_irq()` (`LEGACY_MODE`), defer DMUB/TA work to `forward_roi_work` and `notify_ta_work`. In those workers, copy `crc` and `roi` under `event_lock` and drop it before taking `psp->securedisplay_context.mutex` or `dm->dc_lock`, and hold `ddev->mode_config.mutex` when calling `get_phy_id()` or `update_phy_id_mapping()`. [F200, F203, F327, F329]
- In `amdgpu_dm_fini()`, if `idle_workqueue->running` is true, set `idle_workqueue->enable = false` and `flush_work(&idle_workqueue->work)` before freeing `idle_workqueue`. In `amdgpu_dm_idle_worker()`, after dropping `dc_lock` across `fsleep()`, re-acquire `dc_lock` and recheck `!amdgpu_dm_is_headless(adev) && !amdgpu_dm_psr_is_active_allowed(dm)` and `idle_work->enable` before entering idle optimizations. [F20, F207]
- Hold per-link `hdcp_w->mutex` across all `mod_hdcp_*` calls, `process_output()`, and `hdcp_w->aconnector[conn_index]` updates. In `event_property_update()`, acquire `dev->mode_config.connection_mutex` before `hdcp_work->mutex` and await `conn_state->commit->hw_done` before `drm_hdcp_update_content_protection()`. In `hdcp_destroy()`, call `cancel_delayed_work_sync()` on `callback_dwork`, `watchdog_timer_dwork`, and `property_validate_dwork` across all links without holding `hdcp_work[i].mutex` before removing sysfs and freeing `hdcp_work`. [F189, F191, F192, F333]
- In `dp_dsc_*_write()` debugfs handlers, lock `dev->mode_config.mutex` -> `dev->mode_config.connection_mutex` -> `crtc->mutex` and unlock in reverse order before freeing `wr_buf`. In `trigger_hotplug`, `dp_is_mst_connector_show`, and `dp_mst_progress_status_show`, acquire `aconnector->hpd_lock` outer-most before `dc_lock`, `mgr->base.lock`, or DRM modeset locks. [F187, F212]
- All DMUB VBIOS command helpers in `command_table2.c` (`*_dmcub*`) must call `dc_wake_and_execute_dmub_cmd` with `DM_DMUB_WAIT_TYPE_WAIT`. [F360]

## Object Lifetimes
- In `dm_resume()`, `dm_dmub_hw_resume()` must precede powering on DMUB/DC (`dc_dmub_srv_set_power_state()`, `dc_set_power_state()`), `amdgpu_dm_irq_resume_early()` must precede `s3_handle_mst()` and `dm_destroy_cached_state()`, and `drm_dp_mst_topology_queue_probe()` and `amdgpu_dm_irq_resume_late()` must follow `dm_destroy_cached_state()`. [F136]
- When releasing an MST connector's `aconnector->dc_sink` in `amdgpu_dm_mst_connector_early_unregister()` or `dm_dp_mst_detect()`, remove the remote sink from `dc_link`, call `dc_sink_release()`, set `aconnector->dc_sink = NULL`, and call `amdgpu_dm_mst_reset_mst_connector_setting()` (holding `root->mst_mgr.base.lock` in `early_unregister`). Likewise, null `aconnector->notifier` and `link->local_sink` immediately after unregistering/releasing them in `hdmi_cec_state_write()` and `trigger_hotplug()`. [F181, F188, F209]
- `dm_dp_add_mst_connector()` must call `drm_connector_dynamic_init()`, `amdgpu_dm_connector_funcs_reset()`, and `drm_dp_mst_get_port_malloc(port)` paired with `drm_dp_mst_put_port_malloc()` in `dm_dp_mst_connector_destroy()`. HDCP `hdcp_w->aconnector[conn_index]` updates must pair `drm_connector_get()` and `drm_connector_put()`. [F307, F349]
- In `pre_validate_dsc()`, `local_dc_state` is shallow-copied from `dm_state->context`, so `clean_exit` must only call `dc_stream_release(local_dc_state->streams[i])` when `local_dc_state->streams[i] != dm_state->context->streams[i]` before `vfree(local_dc_state)`. [F182]
- `bios_get_image()` / `GET_IMAGE` returns a borrowed pointer into `init->bios` (`bp->base.bios`), so VBIOS table pointers in `struct bios_parser` must never be `kfree`d and `init->bios` must outlive `struct dc_bios`. [F355]
- `dc_clk_mgr_create()` must run after `ctx->dc_bios` is initialized and `dc_destroy_clk_mgr()` before `ctx` is freed. Every ASIC clock manager struct must embed `struct clk_mgr_internal base` at offset 0 for `kfree(TO_CLK_MGR_INTERNAL(clk_mgr_base))`; constructors allocating internal resources need a matching `*_clk_mgr_destroy()` case in `dc_destroy_clk_mgr()` that does not `kfree` the outer struct. [F357, F358, F388]
- `clk_mgr_exit_optimized_pwr_state()` and `clk_mgr_optimize_pwr_state()` must be called in matched pairs in LIFO order (`hwss.exit_optimized_pwr_state` before disabling eDP PSR/Replay, and restoring PSR/Replay from `psr_allow_active_cache` before `hwss.optimize_pwr_state`). [F359]

## API Contracts
- `scale_input_to_fw()` and `scale_fw_to_input()` must rescale custom brightness curves with `AMDGPU_MAX_BL_LEVEL` (`0xFF`), whereas `amdgpu_dm_register_backlight_device()`'s fallback `props.max_brightness` must use `MAX_BACKLIGHT_LEVEL` (`0xFFFF`). [F39]
- In `amdgpu_dm_crtc_handle_vblank()`, if `acrtc->event` is set and `acrtc->pflip_status != AMDGPU_FLIP_SUBMITTED`, under `dev->event_lock` call `drm_crtc_send_vblank_event()`, call `drm_crtc_vblank_put(crtc)`, and clear `acrtc->event = NULL`. In `amdgpu_dm_crtc_helper_atomic_check()`, reject `crtc_state->async_flip` with `-EINVAL` if `dm_crtc_state->update_type != UPDATE_TYPE_FAST`. [F344, F346]
- `dm_dp_aux_transfer()` downcasts via `TO_DM_AUX(aux)` and must only be used on `aconnector->dm_dp_aux.aux`, never `drm_dp_mst_port.aux`. During MST payload removal, `dm_helpers_construct_old_payload()` must reconstruct `old_payload` from `mst_state->payloads` before updating DC or calling `drm_dp_remove_payload_part2()`. Multiply whole-bpp DSC limits (`max_dsc_bpp`, `min_target_bpp`, `max_target_bpp`) by 16 for `*_x16` APIs. [F229, F297, F350]
- `dal_bios_parser_destroy()` requires non-NULL `dcb` and `*dcb` and sets `*dcb = NULL`. Use `bios_get_image` with `struct_size(..., 1)` rather than `GET_IMAGE` for flexible-array VBIOS tables. Pass parameter struct lvalues (never pointers) to `EXEC_BIOS_CMD_TABLE(command, params)`, which returns `true` on success (`BP_RESULT_OK`). [F356, F372, F395, F429]
- Guard DCN cases in `dc_clk_mgr_create()` and `dc_destroy_clk_mgr()` with `CONFIG_DRM_AMD_DC_FP`, and `FAMILY_SI`/`DCE_VERSION_6_*` clock manager and command table helpers with `CONFIG_DRM_AMD_DC_SI`. [F448, F450]

## Error Handling
- In `dm_cache_state()`, if `IS_ERR(adev->dm.cached_state)` after `drm_atomic_helper_suspend()`, extract `PTR_ERR()` and reset `adev->dm.cached_state = NULL` because `dm_suspend()` and `dm_destroy_cached_state()` treat any non-NULL pointer as valid. [F36]
- In `compute_mst_dsc_configs_for_link()`, when the uncompressed `drm_dp_mst_atomic_check(state)` returns `-ENOSPC`, fall through to the DSC pass; return any other non-zero error immediately. In `validate_dsc_caps_on_connector()`, keep `dsc_branch_dec_caps` `NULL` unless the 3-byte `drm_dp_dpcd_read()` returns `3`. [F228, F230]
- In `dc/bios` and `dc/clk_mgr`: check `bp->cmd_tbl.*` for `NULL` before calling; zero `tbl_revision->major/minor` on `!atom_data_tbl` in `get_atom_data_table_revision()`; verify `structuresize` covers header plus one entry before subtraction in GPIO LUT parsers; keep `enum bp_result result` non-static in `bios_parser_get_vram_info()`; return `OBJECT_TYPE_UNKNOWN` silently on sparse slots in `bios_parser_get_connector_id()`; and check `dprefclk_ss_divider != 0` in `dce_adjust_dp_ref_freq_for_ss()`. [F364, F371, F378, F396, F424, F449]

## Known Pitfalls
- Copy `context->streams` into `del_streams[]` before calling `dc_state_remove_stream()` in `amdgpu_dm_commit_zero_streams()` because it mutates `context->streams` in place. In `dm_free_gpu_mem()` and `dm_sw_fini()`, `break` immediately after `list_del(&da->list)` and `kfree(da)` when using `list_for_each_entry`. [F89, F90]
- Validate 1D LUT sizes via `amdgpu_dm_verify_lut_sizes()` before `__drm_lut_to_dc_gamma()` or `__is_lut_linear()` (which divides by `size - 1`), and 3D LUT size (4913) via `amdgpu_dm_verify_lut3d_size()` before `__drm_3dlut_to_dc_3dlut()`. Convert CRTC CTM (`drm_color_ctm`, 9 elements) with `__drm_ctm_to_dc_matrix()` and plane CTM (`drm_color_ctm_3x4`, 12 elements) with `__drm_ctm_3x4_to_dc_matrix()`. [F251, F252, F282, F294]
- In `dm_helpers_read_local_edid()` and `dm_dp_mst_get_modes()`, compute raw EDID size as `(edid->extensions + 1) * EDID_LENGTH` after checking `edid->extensions < sizeof(sink->dc_edid.raw_edid) / EDID_LENGTH`. [F300]
- 64-bit math and rounding: widen 32-bit operands to `u64`/`uint64_t` and use `div_u64`/`div64_u64`/`div64_s64`/`DIV64_U64_ROUND_UP` in `dm_mst_get_pbn_divider()`, `kbps_to_peak_pbn()`, `bpp_x16_from_pbn()`, `kbps_from_pbn()`, `adjust_display_pll_v2/v3()` (after checking `pixel_clock_10KHz_in != 0`), and `dce11_pplib_apply_display_requirements()`; use ceiling division in `kbps_to_peak_pbn()` and `increase_dsc_bpp()`; and use `u64` for `raw` and `mask` in `dmub_trace_mask_show/set()`. [F285, F287, F288, F289, F423, F427]
- In `dc/bios` and `dc/clk_mgr`: test `revision.minor >= 3` before `>= 1` in `bios_parser_construct()`; set union members `dplaneset` (`ucDPLaneSet`) and `digmode` (`ucDigMode`) in mutually exclusive `if/else` branches in `transmitter_control_v1_6/v1_7()`; and left-shift `feedback_amount`/`nfrac_amount` before masking in `enable_spread_spectrum_on_ppll_v2/v3()`. [F413, F420, F422]
