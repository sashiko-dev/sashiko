# CONTROL GROUP (CGROUP)

The Control Group (`kernel/cgroup`) subsystem provides the hierarchical process-grouping and resource-accounting framework in Linux, supporting the unified v2 hierarchy and legacy v1 hierarchies mounted via kernfs. It manages task-to-cgroup associations (`css_set`), subsystem state lifecycles (`cgroup_subsys_state`), task migrations, per-CPU recursive statistics (`rstat`), cgroup namespaces, and built-in controllers including freezer (v1/v2), pids, RDMA, misc, and debug.

## Architecture & Data Flow
- A `struct cgroup_subsys_state` is `cgroup::self` iff `css_is_self(css)` (`css->ss == NULL`), so code accepting arbitrary CSS pointers (`css_free_rwork_fn()`, `css_release_work_fn()`, `rstat.c`) must check `css_is_self(css)` before dereferencing `css->ss`. In `css_task_iter`, `it->cset_head` anchors `struct css_set` via `e_cset_node[it->ss->id]` when `it->ss != NULL`, and `struct cgrp_cset_link` via `cset_link` when `it->ss == NULL`. [F49, F134]
- On cgroupfs `kernfs_node` objects, `kn->priv` is `struct cgroup *` on `KERNFS_DIR` and `struct cftype *` on `KERNFS_FILE`; code obtaining a `struct cgroup *` from `kn` must verify `kernfs_type(kn) == KERNFS_DIR` or use `kn_priv(kn)`. [F133]
- `cgroup_add_file()` and `cgroup_rm_file()` compute `struct cgroup_file *` as `(void *)css + cft->file_offset`, requiring `self`/`css` to stay at offset 0 of outer structs. In `struct cgroup_root`, `cgrp_ancestor_storage` must immediately follow `struct cgroup cgrp` to back `root_cgrp->ancestors[0]`, and `cgroup_create()` must allocate `struct_size(cgrp, ancestors, level + 1)` for inclusive `0..cgrp->level` indexing. [F91, F126, F129]
- In `css_set_move_task()`, `css_set_populated()` checks `cset->tasks` and `cset->mg_tasks` emptiness (not `nr_tasks`), updating `to_cset` before `list_add_tail()` and `from_cset` after `list_del_init()`. Before unlinking `task->cg_list`, `css_set_skip_task_iters()` must be called under `css_set_lock` so active cursors advance and set `CSS_TASK_ITER_SKIPPED`. [F77, F110]
- `rebind_subsystems()` must preserve list order under `css_set_lock` and update `it->cset_head` on every `css_task_iter` in `cset->task_iters` when moving `e_csets` entries. `link_css_set()` must use `list_add_tail()` on `cset->cgrp_links` and `find_css_set()` must iterate `old_cset->cgrp_links` in order so `compare_css_sets()` sees identical hierarchy order. [F67, F89]
- `cgroup_migrate_add_src()` and `cgroup_migrate_prepare_dst()` must link `css_set` nodes into `mgctx->preloaded_src_csets` and `preloaded_dst_csets` using separate `mg_src_preload_node` and `mg_dst_preload_node` heads. Before `cgroup_migrate_execute()` returns, it must move all `mg_tasks` back to `cset->tasks`, unlink `cset->mg_node`, and reset `tset->nr_tasks = 0` and `tset->csets = &tset->src_csets`. [F6, F73]
- `struct css_rstat_cpu` must keep `rstatc->updated_children == css` when empty and `rstatc->updated_next == NULL` when unlinked, restoring both under `ss_rstat_lock()`. `cgroup_base_stat_flush()` must propagate `bstat` deltas against `rstatbc->last_bstat` into `cgrp->bstat` and `rstatbc->subtree_bstat`, and when `cgroup_parent(parent)` is non-NULL, into `parent->bstat` and `prstatbc->subtree_bstat` (updating `last_bstat` and `last_subtree_bstat`). [F79, F80]
- `root_cgroup_cputime()` must `memset(bstat, 0, sizeof(*bstat))` and categorize `kernel_cpustat` identically to `__cgroup_account_cputime_field()` (`CPUTIME_NICE` falls through to `CPUTIME_USER`, excluding `STEAL`/`GUEST`/`GUEST_NICE`), and `cgroup_base_stat_add()`/`sub()` must update every field. [F54, F81, F106]
- `tcgrp->freezer.nr_frozen_descendants` must be updated on all ancestors under `css_set_lock` when `CGRP_FROZEN` changes or a cgroup is created/destroyed. In legacy `freezer_attach()`, migrating into a `CGROUP_FREEZING` freezer must clear `CGROUP_FROZEN` on that freezer and all `parent_freezer()` ancestors under `freezer_mutex` before `freeze_task()`. [F82, F84]
- In `pids_event()`, default-hierarchy `PIDCG_MAX` events without `CGRP_ROOT_PIDS_LOCAL_EVENTS` must start at `pids_over_limit` (not `pids_forking`) and walk `parent_pids(p)`. In `rdma.c`, `rpool->num_max_cnt` must be maintained via `set_resource_limit()`, freeing `rpool` via `free_cg_rpool_locked()` when `usage_sum == 0 && num_max_cnt == RDMACG_RESOURCE_MAX`. [F85, F86]

## Synchronization
- `cgroup_mutex` nests outside kernfs `active_ref`: kernfs callbacks needing `cgroup_mutex` must use `cgroup_kn_lock_live()` / `cgroup_kn_unlock()`; if `cgroup_kn_lock_live()` returns `NULL`, it has already cleaned up and `cgroup_kn_unlock()` must not be called. [F9, F37]
- `css_set_lock` is an IRQ-disabled spinlock, so sleeping calls (`kernfs_walk_and_get()`, `GFP_KERNEL`, `cgroup_mutex`) are forbidden under it; use lockless `current_cgns_cgroup_dfl()` for default-hierarchy namespace roots. `task_cgroup_from_root()` / `cset_cgroup_from_root()` for `root != &cgrp_dfl_root` requires `css_set_lock` plus `cgroup_mutex` or `rcu_read_lock()` (checking for `NULL` under RCU). [F45, F146]
- `cgroup_threadgroup_rwsem` nests inside `cpus_read_lock()`: `cgroup_attach_lock()` must take `cpus_read_lock()` first, and `->attach()` callbacks must not take `cpus_read_lock()`. In `legacy_freezer.c`, `cpus_read_lock()` must precede `freezer_mutex` whenever `freezer_active` may change, using `static_branch_inc/dec_cpuslocked()`. [F36, F144]
- `CGRP_ROOT_FAVOR_DYNMODS` must only be updated via `cgroup_favor_dynmods()` under `percpu_down_write(&cgroup_threadgroup_rwsem)`, and `cgroup_enable_per_threadgroup_rwsem` must never be reset to `false` once enabled. [F78, F145]
- `cgroup_procs_write_start()` treats `pid == 0` as `current` (`CGRP_ATTACH_LOCK_NONE` only when `pid == 0 && !threadgroup`), pins `task_struct`, and takes attach locks that must be released via `cgroup_procs_write_finish(task, lock_mode)` iff `!IS_ERR(task)`. When `threadgroup` is true, it must recheck `thread_group_leader(tsk)` after `cgroup_attach_lock()` and retry if lost. [F10, F38, F107]
- `css_rstat_flush()` sleeps between CPUs but holds `__css_rstat_lock(css, cpu)` (`spin_lock_irq`) across `css_rstat_updated_list()` and the `rstat_flush_next` loop per CPU, so `->css_rstat_flush()` callbacks run in atomic IRQ-disabled context. In `cgroup_base_stat_cputime_show()`, `__css_rstat_lock(&cgrp->self, -1)` must be held after `css_rstat_flush()` while reading `cgrp->bstat` and calling `cputime_adjust()`. [F28, F29, F142]
- `css_rstat_updated()` requires preemption disabled and uses `llist_on_list()` and `this_cpu_cmpxchg(rstatc_pcpu->lnode.next, self, NULL)` before `llist_add()`, paired with `llist_del_first_init()`. Per-CPU `rstatbc->bstat` updates must use `get_cpu_ptr()` and `u64_stats_update_begin_irqsave()` / `end_irqrestore()` before `css_rstat_updated()`. [F30, F31]
- CSS destruction stages must use their separate `max_active=1` workqueues (`css_killed_work_fn` -> `cgroup_offline_wq`, `css_release_work_fn` -> `cgroup_release_wq`, `css_free_rwork_fn` -> `cgroup_free_wq`) to avoid deadlock in `cgroup_lock_and_drain_offline()`. [F147]
- In `css_create()`, `ss->css_idr` is allocated with `NULL` and populated via `cgroup_idr_replace()` only after `percpu_ref_init()` and `css_rstat_init()` succeed, and `online_css()` sets `cgrp->subsys[ss->id]` only after `ss->css_online()` succeeds. All `cgroup_idr` / `ss->css_idr` changes require `spin_lock_bh(&cgroup_idr_lock)` with `idr_preload()` outside and `__GFP_DIRECT_RECLAIM` stripped inside. [F22, F153]
- Modifying `nr_descendants` / `nr_dying_descendants` requires both `cgroup_mutex` and `css_set_lock`. Updating `CGRP_FREEZE`, `freeze_start_nsec`, and `frozen_nsec` in `cgroup_do_freeze()` requires `css_set_lock` and `write_seqcount_begin/end(&cgrp->freezer.freeze_seq)`. [F32, F33]
- In `cgroup_post_fork()`, `child` must be linked via `css_set_move_task()` under `css_set_lock` before `ss->fork(child)`, and `cgrp->kill_seq` compared under `css_set_lock` against `kargs->kill_seq`. In `cgroup_exit()`, `tsk` must be unlinked under `css_set_lock` before `ss->exit(tsk)` outside the lock. [F34, F42]
- Dropping `rcu_read_lock()` inside `css_for_each_child()` or `css_for_each_descendant_pre/post()` requires pinning `@pos` first and reacquiring `rcu_read_lock()` before `css_put(pos)` and advancing. [F39]

## Object Lifetimes
- `cgroup_e_css()` and `cgroup_css()` return unpinned pointers (requiring `cgroup_mutex` or `rcu_read_lock()`), whereas `cgroup_get_e_css()` returns a reference requiring `css_put()`. `of_css()` / `seq_css()` may use `rcu_dereference_raw()` only inside active kernfs callbacks because `kill_css()` calls `css_clear_dir()` before `percpu_ref_kill_and_confirm()` and holds an extra `css_get(css)` until `offline_css()` completes. [F1, F19, F150]
- `cgroup_css_set_fork()` acquires `kargs->cset` and `cgroup_threadgroup_change_begin(current)` on all forks (plus `cgroup_mutex` and `kargs->cgrp` on `CLONE_INTO_CGROUP`), all released unconditionally by `cgroup_css_set_put_fork()`. `cgroup_post_fork()` transfers `kargs->cset` to `child->cgroups` (or calls `put_css_set()` if `child->pid == 0`) and must set `kargs->cset = NULL`. [F4, F5]
- Every `css_task_iter_start()` must be paired with `css_task_iter_end()`. `link_css_set()` and `put_css_set_locked()` pin/unpin `cgrp` iff `cgroup_parent(cgrp) != NULL`. [F11, F20]
- `cgroup_do_get_tree()` consumes the caller's `&ctx->root->cgrp` reference; if `cgroup1_get_tree()` sees a dying root after `cgroup_do_get_tree(fc)` succeeds, it must call `fc_drop_locked(fc)` before `restart_syscall()`. [F12, F13]
- `cgroup_sk_alloc()` must always set `skcd->cgroup` (using `&cgrp_dfl_root.cgrp` in interrupt) and take both `cgroup_get()` and `cgroup_bpf_get()`; `cgroup_sk_clone()` must use `cgroup_get()` (not `cgroup_get_live()`). `pressure_write()` must pass `of` to `psi_trigger_create()` and destroy `ctx->psi.trigger` in `cgroup_pressure_release()`. [F14, F21, F163]

## API Contracts
- `struct cgroup_subsys` definitions must set `.css_alloc` and `.css_free`, leave `.id`/`.name` zeroed, omit `.css_rstat_flush` if `.early_init = true`, and set `.threaded = true` if `.implicit_on_dfl = true`. `struct cftype` tables must be non-`const`, `{}`-terminated, with `.ss`/`.kf_ops` initially `NULL`, and set `.seq_next` whenever `.seq_start` is set. [F132, F157, F158, F159, F160]
- `cgroup_is_descendant(cgrp, ancestor)` takes descendant first. Subsystem IDs (`ssid < CGROUP_SUBSYS_COUNT <= 16`) index arrays, while `do_each_subsys_mask()`, `rebind_subsystems()`, `cgroup_setup_root()`, and `u16` masks take `1 << ssid`. `css->id` in `ss->css_idr` is 1-based (`1` for root, `>= 2` for non-root). [F58, F59, F94, F95]
- `pids_try_charge()` sets `*fail` only on `-EAGAIN`; `rdmacg_try_charge()` sets `*rdmacg` only on `0` (uncharging `[cg, p)` and dropping CSS on error). Exported `misc_cg_*` and `rdmacg_*` APIs must bounds-check `valid_type(type)` and `index < RDMACG_RESOURCE_MAX`. [F17, F63, F101]

## Error Handling
- `cgroup_create()` must unwind in reverse order (`out_psi_free` -> `out_stat_exit` -> `out_kernfs_remove`). `css_create()` failures after `init_and_link_css()` must queue `css_free_rwork_fn()` on `cgroup_free_wq`, and `css_rstat_exit()` must guard on `css->rstat_cpu != NULL`. [F2, F3, F50]
- Subtree/domain updates must pair `cgroup_save_control()`, `cgroup_apply_control()`, and unconditional `cgroup_finalize_control(cgrp, ret)`. In `cgroup_addrm_files()`, `cgroup_add_file()` failure rollback must set `cft_end = cft` and `is_add = false` while keeping `ret != 0`. [F15, F113]
- `pids_try_charge()` and `misc_cg_try_charge()` uncharge inclusively on failure, whereas `rdmacg_try_charge()` uncharges `[cg, p)` exclusively. `cgroup_get_from_id/path/fd()`, `task_get_cgroup1()`, and `css_tryget_online_from_dir()` return `ERR_PTR` (never `NULL`). Check `task->nsproxy != NULL` in `current_cgns_cgroup_dfl()` and `cgroupns_get()`. [F47, F51, F118]

## External Contracts
- `__cgroup_procs_write()` and `__cgroup1_procs_write()` must check `of->file->f_cred` (via `override_creds()` in v2) and `ctx->ns` (also in `cgroup_file_write()`) rather than `current`'s cred or `cgroup_ns`. [F168, F169]
- v1 `release_agent` requires `CAP_SYS_ADMIN` in `init_user_ns` (checking `file_ns_capable(of->file, &init_user_ns, CAP_SYS_ADMIN)` and `ctx->ns->user_ns == &init_user_ns`). `cgroupns_install()` requires `ns_capable(..., CAP_SYS_ADMIN)` in both `nsset->cred->user_ns` and `cgroup_ns->user_ns`. [F170, F173]
- `cgroup_get_from_id()` and `cgroup_get_from_path()` must restrict lookups to `current_cgns_cgroup_dfl()`. `apply_cgroup_root_flags()` must only modify `cgrp_dfl_root.flags` when in `&init_cgroup_ns`, keeping v2 mount options synced across parse, apply, and `cgroup_show_options()`. [F87, F171, F174]

## Known Pitfalls
- `init_and_link_css()` zeroes `struct cgroup_subsys_state` after `ss->css_alloc()`, so `css_alloc` must only initialize outer fields. In `cgroup_migrate_prepare_dst()`, `src_cset == dst_cset` must unlink `src_cset` and put both references; if `dst_cset->mg_dst_preload_node` is already linked, put the duplicate `dst_cset` reference. [F119, F128]
- `cgroup_transfer_tasks()` must skip `PF_EXITING` tasks in `css_task_iter_next(&it)` to avoid infinite loops. `cgroup_pidlist_start()` must re-validate cached `ctx->procs1.pidlist` via `cgroup_pidlist_find()` under `pidlist_mutex`. [F70, F116]
- In `legacy_freezer.c`, `CGROUP_FREEZING` stays set when `CGROUP_FROZEN` is set, so `freezer_state_strs()` and `update_if_frozen()` must test `CGROUP_FROZEN` first, while `cgroup_freezing()` tests only `CGROUP_FREEZING`. Skipping a subtree in `css_for_each_descendant_pre()` requires `css = css_rightmost_descendant(css)` before `continue`. [F104, F112]
- Copy `u16` subsystem masks to `unsigned long` bounded by `CGROUP_SUBSYS_COUNT` for `for_each_set_bit()`. Ensure `power >= 0` in `power_of_ten()`, use `do_div()`/`DIV_ROUND_CLOSEST_ULL()` on 64-bit stats, and use `time_in_range()` in `cgroup_file_notify()`. [F123, F124, F125, F138]
