# MARVELL MVPP2 ETHERNET DRIVER

Core driver for the Marvell PPv2 (PPv2.1, PPv2.2, and PPv2.3) packet processor on Armada 375 and Armada 7K/8K/CN913x SoCs, managing shared Buffer Manager (BM) pools, aggregated TX queues, TCAM/SRAM header parser, C2/RSS classifiers, per-port netdev/ethtool ops, phylink MAC/PCS, XDP, and PTP.

## Architecture & Data Flow

- When `priv->percpu_pools` is enabled, `port->pool_long` and `port->pool_short` are `NULL` and `priv->page_pool[]` is used; when disabled, `priv->page_pool[]` is `NULL`. Callers must check `priv->percpu_pools` before dereferencing either, and BM pool loops (`mvpp2_bm_init()`, `mvpp2_bm_pools_init()`, `mvpp2_bm_switch_buffers()`, `mvpp2_remove()`) must iterate to `mvpp2_get_nrxqs(priv) * 2` (or `port->nrxqs * 2`) when enabled vs `MVPP2_BM_POOLS_NUM` otherwise. [F5, F45]
- Shared `priv->page_pool[]` DMA direction must be `DMA_BIDIRECTIONAL` if any port in `priv->port_list[]` has `port->xdp_prog` set and `DMA_FROM_DEVICE` otherwise, updated via `mvpp2_check_pagepool_dma()` in `mvpp2_xdp_setup()`. XDP requires `priv->percpu_pools`, `dev->mtu <= MVPP2_MAX_RX_BUF_SIZE`, and `port->ntxqs >= num_possible_cpus() * 2` (upper half of `port->txqs[]` is for XDP TX). [F75, F98]
- On PPv2.2+, `dma_set_coherent_mask(&pdev->dev, DMA_BIT_MASK(32))` is required because all BM pools share a single `MVPP22_BM_POOL_BASE_ADDR_HIGH_REG` for the upper 32 bits of their coherent ring addresses. [F137]
- In `mvpp2_bm_pool_create()`/`destroy()`, `size` must be a multiple of 16, `bm_pool->virt_addr` 128-byte aligned (`MVPP2_BM_POOL_PTR_ALIGN`), and `dma_alloc_coherent()`/`dma_free_coherent()` must use `bm_pool->size_bytes` (`2 * sizeof(u32) * size` on PPv2.1, `2 * sizeof(u64) * size` on PPv2.2+), never `bm_pool->size * sizeof(*bm_pool->virt_addr)`. [F99, F121]
- Before creating BM pools in `mvpp2_bm_init()`, `mvpp2_bm_pool_cleanup()` must drain `MVPP2_BM_PHY_ALLOC_REG(pool_id)` `MVPP2_BM_POOL_SIZE_MAX` times, set `MVPP2_BM_STOP_MASK`, and mask/clear BM IRQs. Every frame size passed to `MVPP2_RX_MAX_PKT_SIZE()` must exceed `MVPP2_SKB_HEADROOM + MVPP2_SKB_SHINFO_SIZE` (up to 704 bytes when `L1_CACHE_BYTES == 256`). [F82, F133]
- `struct mvpp2_tx_desc` and `struct mvpp2_rx_desc` must remain 32 bytes (`MVPP2_DESC_ALIGNED_SIZE`). `mvpp2_check_ringparam_valid()` must enforce `rx_pending` is a multiple of 16 in `[MSS_THRESHOLD_START, MVPP2_MAX_RXD_MAX]` and `tx_pending` is a multiple of 32 in `[ALIGN(MVPP2_MAX_SKB_DESCS, 32), MVPP2_MAX_TXD_MAX]`. [F88, F120]
- In `mvpp2_poll()`, clear `1 << rxq->logic_rxq` from `cause_rx` only when `budget > 0` after `mvpp2_rx()`, and save remaining `cause_rx` to `qv->pending_cause_rx` when `budget == 0`. [F107]
- `mvpp2_set_hw_csum()` must clear `NETIF_F_IP_CSUM | NETIF_F_IPV6_CSUM` from `dev->features` and `dev->hw_features` when `new_long_pool == MVPP2_BM_JUMBO` on `port->id != 0`, and never advertise `NETIF_F_HW_CSUM` (TX descriptor `L3_offset` is 7 bits). [F161]
- In `mvpp2_probe()`, `priv->port_map` must be populated from child `"port-id"` properties before `mvpp2_init()`, where `mvpp22_rx_fifo_init()` and `mvpp22_tx_fifo_init()` reserve 4 KB RX and 1 KB TX for `MVPP2_LOOPBACK_PORT_INDEX` before partitioning the remaining 44 KB RX and 18 KB TX FIFO across active ports. [F100, F131]
- In dynamic parser TCAM `[MVPP2_PE_FIRST_FREE_TID, MVPP2_PE_LAST_FREE_TID]`, double-VLAN entries (`mvpp2_prs_double_vlan_add()`, allocated low-to-high) must stay strictly below single/triple-VLAN entries (`mvpp2_prs_vlan_add()`, allocated high-to-low). Double-VLAN AI IDs in `priv->prs_double_vlans[]` must start at 1 (`mvpp2_prs_double_vlan_ai_free_get()`) as AI 0 (`MVPP2_PRS_SINGLE_VLAN_AI`) is reserved for single-VLAN. [F96, F97]
- Per-port VID filter searches/removals (`mvpp2_prs_vid_range_find()`, `mvpp2_prs_vid_entry_add()`, `mvpp2_prs_vid_remove_all()`, `mvpp2_dbgfs_port_vid_show()`) must iterate only `MVPP2_PRS_VID_PORT_FIRST(port->id)..MVPP2_PRS_VID_PORT_LAST(port->id)`. `mvpp2_prs_mac_del_all()` must only remove `MVPP2_PE_MAC_RANGE_START..END` entries with `test_bit(port->id, &pmap)` set, skipping broadcast and `port->dev->dev_addr`. [F64, F66]
- In `cls_flows[]`, entries sharing a `flow_id` must be contiguous (`for_each_cls_flow_id`); untagged entries (masking `MVPP2_PRS_RI_VLAN_MASK`) must precede tagged ones and L4 TCP/UDP must precede L3/Ethernet fallbacks; `MVPP2_FL_*_TAG` entries need `MVPP22_CLS_HEK_TAGGED` in `supported_hash_opts`; and `MVPP2_FL_IP*_FRAG_*` entries with `MVPP2_PRS_IP_MASK` in `ri_mask` need `MVPP2_PRS_RI_IP_FRAG_TRUE` in `ri`. [F58, F101, F102, F103]
- `mvpp2_cls_c2_write()` must write `MVPP22_CLS_C2_TCAM_DATA4` last to flush `TCAM_DATA0..4` and `TCAM_INV`. In `mvpp2_cls_c2_build_match()`, fields are packed in header order; for `FLOW_DISSECTOR_KEY_VLAN`, `vlan_id` is at `offs`, `vlan_priority` at `offs + 13`, and `offs` advances by 16 bits before L4 ports, casting all `u16`/`u8` keys/masks to `u64` before `<< offs`. [F53, F59, F113]
- `mvpp2_rss_port_c2_enable()`/`disable()` must pair toggling `MVPP22_CLS_C2_ATTR2_RSS_EN` in `c2.attr[2]` of `MVPP22_CLS_C2_RSS_ENTRY(port->id)` with setting `c2.attr[0]` to the RSS context ID on enable and restoring `port->first_rxq` on disable. [F70]
- `mvpp2_ethtool_cls_rule_ins()`/`del()` must update `port->rfs_rules[loc]`, `port->n_rfs_rules`, C2 TCAM, and `MVPP2_CLS_FLT_C2_RFS` in lockstep, deleting any prior rule at `efs->rule.loc` before replacement. `mvpp22_port_rss_ctx_delete()` must delete all `FLOW_RSS` rules for `port_ctx` via `mvpp2_ethtool_cls_rule_del()` and clear `priv->rss_tables[rss_ctx] = NULL` and `port->rss_ctx[port_ctx] = -1`. [F71, F72]
- Guard `phylink_*` calls with `if (port->phylink)` (NULL in ACPI compat mode), `regmap_*` in `mvpp22_gop_init()` with `if (priv->sysctrl_base)`, and CM3 flow-control functions (`mvpp2_rxq_enable_fc()`, `mvpp2_rxq_disable_fc()`, `mvpp2_bm_pool_update_fc()`) plus pause advertisement with `priv->global_tx_fc` / `port->tx_fc`. In `mvpp22_gop_init_rgmii()`/`sgmii()`, modify only `GENCONF_CTRL0` bits for `port->gop_id` (2 or 3). [F68, F140, F141]

## Synchronization

- Shared Header Parser TCAM/SRAM registers and `priv->prs_shadow` require `priv->prs_spinlock` via `spin_lock_bh()`/`spin_unlock_bh()` (caller-held for `mvpp2_prs_hw_write()`, `__mvpp2_prs_init_from_hw()`, `__mvpp2_prs_mac_promisc_set()`). `mvpp2_prs_hw_write()` must write `MVPP2_PRS_SRAM_DATA_REG` before `MVPP2_PRS_TCAM_DATA_REG` (which activates the entry), updating `priv->prs_shadow[index].valid` in lockstep with `mvpp2_prs_hw_write()`/`mvpp2_prs_hw_inv()`. [F22, F63, F145]
- CM3 SRAM flow-control updates (`mvpp2_rxq_enable_fc()`, `mvpp2_rxq_disable_fc()`, `mvpp2_bm_pool_update_fc()`) must hold `port->priv->mss_spinlock` via `spin_lock_irqsave()` while clearing `FLOW_CONTROL_ENABLE_BIT` in `MSS_FC_COM_REG` before modifying threshold/pool registers and restoring it with `FLOW_CONTROL_UPDATE_COMMAND_BIT`. [F23]
- Per-thread banked registers (`MVPP2_RXQ_NUM_REG`, `MVPP2_TXQ_NUM_REG`, `MVPP2_BM_VIRT_ALLOC_REG`, `MVPP2_BM_VIRT_RLS_REG`) must use `mvpp2_thread_write()`/`read()` on the same `thread` under `get_cpu()`/`put_cpu()`, never `mvpp2_write()`. When `test_bit(thread, &port->priv->lock_map)` is set, `mvpp2_bm_pool_put()` must hold `port->bm_lock[thread]` and `mvpp2_tx()` must hold `port->tx_lock[thread]` via `spin_lock_irqsave()`. [F24, F25, F143]
- Execute `wmb()` before `mvpp2_aggr_txq_pend_desc_add()` (in `mvpp2_tx()`, `mvpp2_xdp_finish_tx()`) and `mvpp2_rxq_status_update()` (in `mvpp2_rx()`). [F30]
- Set bit 0 of `port->state` in `mvpp2_stop_dev()` and clear it only at the end of `mvpp2_start_dev()`, as `mvpp2_xdp_xmit()` checks `test_bit(0, &port->state)`. In `mvpp2_xdp_setup()`, when `port->xdp_prog` transitions between `NULL` and non-`NULL` while running, call `mvpp2_stop()` before `xchg(&port->xdp_prog, prog)` and `mvpp2_open()`; `mvpp2_rx()` reads `port->xdp_prog` via `READ_ONCE()`. [F29, F32]
- Bracket `struct mvpp2_pcpu_stats` updates with `u64_stats_update_begin()`/`end()` and cross-CPU reads (`mvpp2_get_stats64()`, `mvpp2_get_xdp_stats()`) with `u64_stats_fetch_begin()`/`retry()`. Hold `port->gather_stats_lock` when accessing `port->ethtool_stats` and MIB counters in `mvpp2_gather_hw_statistics()` and `mvpp2_ethtool_get_stats()`. [F31, F153]

## Object Lifetimes

- In `mvpp2_rx()`, when `MVPP2_RXD_BUF_HDR` is set on a dropped/errored descriptor, call `mvpp2_buff_hdr_pool_put()` to free the entire buffer chain. In `mvpp2_run_xdp()`, recycle any non-`XDP_PASS` page not consumed by `xdp_do_redirect()` or `mvpp2_xdp_xmit_back()` via `page_pool_put_page(..., true)`, and call `mvpp2_rx_refill()` in `mvpp2_rx()` on all non-`XDP_PASS` outcomes. [F2, F13]
- In multi-descriptor TX (`mvpp2_tx()`, `mvpp2_tx_frag_process()`, `mvpp2_tx_tso()`), pass `NULL` to `mvpp2_txq_inc_put()` for intermediate descriptors and `skb` only on the last (`MVPP2_TXD_L_DESC`), unmapping prior descriptors via `tx_desc_unmap_put()` on failure. Skip `dma_unmap_single()` for `IS_TSO_HEADER(txq_pcpu, dma)` and `MVPP2_TYPE_XDP_TX` buffers, hold `rcu_read_lock()` across `xdp_return_frame_bulk()`/`xdp_flush_frame_bulk()`, and use `dev_kfree_skb_any()`. [F10, F11, F155]
- `mvpp2_tx_hw_tstamp()` must free any existing `queue->skb[i]` via `dev_kfree_skb_any()` before storing `skb_get(skb)`, and `mvpp2_isr_handle_ptp_queue()` must clear `queue->skb[id] = NULL` and call `dev_kfree_skb_any(skb)`. [F12]
- `mvpp2_rxq_deinit()` must drain descriptors via `mvpp2_rxq_drop_pkts()` and unregister `xdp_rxq_short`/`long`; both `mvpp2_rxq_deinit()` and `mvpp2_txq_deinit()` must set `rxq->descs`, `txq->descs`, and `txq_pcpu->tso_headers` to `NULL` after freeing. Reset destroyed `priv->page_pool[i]` entries to `NULL` and test `priv->page_pool[0]`. [F4, F15, F16]
- `mvpp2_stop()` must stop NAPI/IRQs, disconnect phylink, free IRQs, cancel per-CPU `tx_done_timer` hrtimers (`HRTIMER_MODE_REL_PINNED_SOFT`) before `mvpp2_cleanup_txqs()`, clean up queues, and call `cancel_delayed_work_sync(&port->stats_work)`. `mvpp2_irqs_deinit()` must call `irq_set_affinity_hint(qv->irq, NULL)` before `kfree(qv->mask)` and set `qv->mask = NULL`. [F17, F18, F156]
- Use `device_for_each_child_node_scoped()` in `mvpp2_probe()`, and free non-devm port resources in both `mvpp2_port_probe()` rollback and `mvpp2_port_remove()`. `mvpp2_remove()` must call `mvpp2_port_remove()` and destroy `priv->stats_queue` before destroying `priv->bm_pools` and `priv->aggr_txqs`, skipping `clk_disable_unprepare()` on ACPI (`!dev_of_node(&pdev->dev)`). [F20, F136, F142]

## API Contracts

- `MVPP2_TXQ_SCHED_REFILL_REG(q)`, `TOKEN_SIZE_REG(q)`, and `TOKEN_CNTR_REG(q)` take logical `txq->log_id`, whereas `MVPP2_TXQ_NUM_REG`, `SENT_REG()`, `RSVD_REQ_REG`, `RSVD_CLR_REG`, and `mvpp2_txdesc_txq_set()` take physical `txq->id`. `mvpp2_rxq_long_pool_set()`, `short_pool_set()`, and `xdp_rxq_info_reg()` take logical `rxq->logic_rxq`, whereas other RXQ registers/helpers take physical `rxq->id`. `mvpp2_tx_pkts_coal_set()` must write `MVPP2_TXQ_NUM_REG` and `MVPP2_TXQ_THRESH_REG` on all threads (`0..MVPP2_MAX_THREADS - 1`). [F54, F55, F144, F162]
- `__mvpp2_prs_init_from_hw()` returns `MVPP2_PRS_TCAM_ENTRY_INVALID` (`1`) when invalid, `-EINVAL` if out of range, and `0` when valid. When updating a shared fixed-TID parser entry for one port, if `priv->prs_shadow[tid].valid` is true, read it via `__mvpp2_prs_init_from_hw()` before `mvpp2_prs_tcam_port_set()`. `mvpp2_prs_vid_entry_remove(port, vid)` takes a VLAN ID, whereas `mvpp2_prs_hw_inv(priv, tid)` takes a TCAM `tid`. `MVPP2_CLS_FLT_*` macros take `flow->flow_id`, never a `cls_flows[]` index. [F36, F56, F65, F91]
- `mvpp2_tx_tso()` returns `0` (never negative) on error; `mvpp2_xdp_submit_frame()`/`mvpp2_xdp_xmit_back()` return `MVPP2_XDP_TX` (`BIT(1)`) or `MVPP2_XDP_DROPPED` (`BIT(0)`) without freeing the frame/page; and `mvpp2_bm_bufs_add()` returns the non-negative count allocated (`0..buf_num`), so callers must check `num != pkts_num`. [F38, F39, F40]
- Live reconfigurations (`mvpp2_change_mtu()`, `mvpp2_xdp_setup()`, `mvpp2_ethtool_set_ringparam()`, `mvpp2_bm_switch_buffers()`) must gate `mvpp2_stop_dev()`/`mvpp2_start_dev()` or `mvpp2_stop()`/`mvpp2_open()` on `netif_running(dev)`. When `port->phy_interface != interface`, `mvpp2_mac_prepare()` must call `mvpp22_gop_mask_irq(port)` before `port->phy_interface` changes and run `mvpp22_mode_reconfigure()`, while `mvpp2_mac_finish()` must set `port->phy_interface = interface` before `mvpp22_gop_unmask_irq(port)`. [F74, F76, F134]
- Ethtool RXNFC handlers must check `fs.location < MVPP2_N_RFS_ENTRIES_PER_FLOW`; `mvpp2_ethtool_cls_rule_ins()` must copy `input.rss_ctx = info->rss_context` for `FLOW_RSS`; `mvpp2_cls_rfs_parse_rule()` must reject rules with both `act->queue.ctx` and `act->queue.index` non-zero (`-EOPNOTSUPP`); and RSS context lookups must validate indices in `[0, MVPP22_N_RSS_TABLES - 1]`. Set `NETIF_F_NTUPLE` only in `dev->features`, not `dev->hw_features`. [F80, F81, F160, F172]

## Error Handling

- If `mvpp2_ethtool_set_ringparam()` fails `mvpp2_setup_rxqs()` or `mvpp2_setup_txqs()` on a running port, it must restore `prev_rx_ring_size` (or `prev_tx_ring_size`) and retry queue setup. [F19]
- Optional pointers (`priv->cm3_base`, `priv->sysctrl_base`, `port->comphy`, `port->phylink`) must be `NULL` (never `ERR_PTR`) on lookup failure, and `port->pcs_gmac.ops`/`port->pcs_xlg.ops` must be initialized before `!mvpp2_use_acpi_compat_mode()` in `mvpp2_port_probe()`. Set `err = -ENOENT` before `goto err_free_irq` on `!valid` in `mvpp2_open()`. [F41, F43, F48]

## External Contracts

- `mvpp2_gmac_pcs_inband_caps()` must return `LINK_INBAND_ENABLE` for 802.3z modes, and `mvpp2_gmac_pcs_config()` must return non-zero only when `MVPP2_GMAC_FC_ADV_EN | MVPP2_GMAC_FC_ADV_ASM_EN` changes. [F171]

## Known Pitfalls

- On PPv2.2+, `tx_desc->pp22.buf_dma_addr_ptp`, `rx_desc->pp22.buf_dma_addr_key_hash`, and `rx_desc->pp22.buf_cookie_misc` pack 40-bit addresses in `MVPP2_DESC_DMA_MASK` (bits 39:0) and metadata in bits 63:40: mask with `MVPP2_DESC_DMA_MASK` and preserve upper bits, and add `mvpp2_txdesc_offset_get()` to `mvpp2_txdesc_dma_addr_get()` in `mvpp2_txq_inc_put()`. `MVPP2_AGGR_TXQ_DESC_ADDR_REG` and `MVPP2_RXQ_DESC_ADDR_REG` require `descs_dma >> 8`, unlike `MVPP2_TXQ_DESC_ADDR_REG`, and 8-bit high address fields in `mvpp2_bm_bufs_get_addrs()` and `mvpp2_buff_hdr_pool_put()` must be cast to `u64` before `<< 32`. [F83, F84, F85, F86, F115]
- In `mvpp2_prs_vlan_add()` and `mvpp2_prs_double_vlan_add()`, re-zero `pe` (`memset(&pe, 0, sizeof(pe))`) after the `tid_aux` scan loop overwrites it. In `mvpp2_prs_sram_shift_set()` and `mvpp2_prs_sram_offset_set()`, negate negative values, set the sign bit, and OR (`|=`) the magnitude into `pe->sram`. Access the 8-bit SRAM AI field at bit 90 (spanning `pe->sram[2..3]`) only via `mvpp2_prs_sram_ai_update()`/`get()`. [F52, F67, F95, F117]
- Downcast `mvpp2_phylink_gmac_pcs_ops` via `mvpp2_pcs_gmac_to_port()` and `mvpp2_phylink_xlg_pcs_ops` via `mvpp2_pcs_xlg_to_port()`. Use `bitmap_set(&priv->lock_map, 0, nbits)` (not `bitmap_fill()`); store bitmasks passed to `test_bit()`/`for_each_set_bit()` in `unsigned long`; and keep `mvpp2_ethtool_get_strings()` (`ethtool_puts()`/`sprintf()`) and `mvpp2_read_stats()` in identical order (`+=` for HW regs, `=` for `xdp_stats`). [F110, F123, F127, F128, F129]
