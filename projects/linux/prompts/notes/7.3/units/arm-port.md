# ARM PORT

Platform and SoC support code for Samsung Exynos (`mach-exynos`), Samsung S5PV210 (`mach-s5pv210`), Freescale/NXP i.MX (`mach-imx`), Freescale MXS (`mach-mxs`), and NXP LPC18xx (`mach-lpc18xx`). It implements early machine initialization, SMP secondary CPU bring-up and hotplug, Multi-Cluster Power Management (MCPM), TrustZone secure firmware SMC calls, system suspend/resume (including OCRAM-resident assembly routines), cpuidle drivers, interrupt controller hierarchies (PMU, GPC, AVIC, TZIC), reset control (SRC), and MMDC memory controller performance monitoring.

## Architecture & Data Flow

- `struct imx6_cpu_pm_info` and `struct imx5_cpu_suspend_info` must remain `__aligned(8)` (`fncpy()` triggers `BUG_ON` if `suspend_ocram_base + sizeof(...)` is unaligned). Layout changes to `imx6_cpu_pm_info` or `imx6_pm_base` must update `PM_INFO_*_OFFSET` in `suspend-imx6.S` and keep `pm_info_size` equal to the relocated `imx6_suspend` offset; layout changes to `imx5_cpu_suspend_info` or `imx5_suspend_io_state` must update `SUSPEND_INFO_MX53_*_OFFSET` and strides in `suspend-imx53.S` (`suspend_io_count <= MX5_MAX_SUSPEND_IOSTATE`). [F76, F77, F79]
- In `imx6q_suspend_init()`, `suspend_ocram_base` must be mapped with `__arm_ioremap_exec()`, zeroed with `memset(suspend_ocram_base, 0, sizeof(*pm_info))` (as `l2_base` is only populated when `socdata->pl310_compat` is non-NULL and tested for NULL in `imx6q_suspend_finish` and `suspend-imx6.S`), populated, and copied via `fncpy()` before calling `__arm_iomem_set_ro()`. `imx6_pm_ccm_init()` must run before `imx6_pm_common_init()` and `imx6q_suspend_init()` so `ccm_base` is mapped first. [F29, F85, F108]
- `imx_gpc_hwirq_unmask()` and `imx_gpc_hwirq_mask()` take a 0-based GIC SPI hwirq (`0 <= hwirq < GPC_MAX_IRQS`), not the +32 SoC IRQ number. In `imx6_set_lpm()`, when `mode != WAIT_CLOCKED`, hwirq `0` (IOMUX IRQ #32, held pending by `IMX6Q_GPR1_GINT`) must be unmasked via `imx_gpc_hwirq_unmask(0)` immediately before writing `ccm_base + CLPCR` and masked via `imx_gpc_hwirq_mask(0)` immediately after (ERR007265). [F35, F92]
- In `imx6_enable_rbc()`, all GPC interrupts must be masked via `imx_gpc_mask_all()` before modifying `BM_CCR_RBC_EN` and `BM_CCR_RBC_BYPASS_COUNT` in `ccm_base + CCR`, followed by `writel()`, `udelay(65)`, and `imx_gpc_restore_all()`. In `imx6_pm_stby_poweroff()`, `gic_cpu_if_down(0)` must precede `imx6_set_lpm(STOP_POWER_OFF)` and `imx6q_suspend_finish(0)`. In `mx5_suspend_enter()`, `mx5_cpu_lp_set(IMX5_DEFAULT_CPU_IDLE_STATE)` must be restored before returning. [F46, F84, F93]
- In `exynos_pm_init()`, when `exynos_secure_firmware_available()` is true, `pm_state.sysram_base` must be `sysram_ns_base_addr` and `pm_state.secure_firmware` must be set. In `exynos5420_pm_prepare()` and `exynos5420_pm_resume()`, `exynos_smc(SMC_CMD_REG, SMC_REG_ID_SFR_W(addr), ...)` must only run when `pm_state.secure_firmware` is true, passing physical `pm_state.sysram_phys + EXYNOS5420_CPU_STATE` (not virtual `pm_state.sysram_base`). [F37, F89]
- In `arch/arm/mach-exynos/firmware.c`, `EXYNOS_SLEEP_MAGIC` at `sysram_ns_base_addr + EXYNOS_BOOT_FLAG` must be cleared to `0` both in `exynos_resume()` and when `exynos_smc(SMC_CMD_SLEEP, 0, 0, 0)` returns in `exynos_cpu_suspend()`. In `exynos_l2_write_sec()`, enabling `L2X0_CTRL_EN` when `l2cache_enabled == 0` must first call `exynos_smc(SMC_CMD_L2X0INVALL, 0, 0, 0)` and set `l2cache_enabled = 1`, while clearing `L2X0_CTRL_EN` resets `l2cache_enabled = 0`. [F45, F47]
- On Exynos5420/5800, `exynos_cpu_power_down()` must not clear `S5P_CORE_LOCAL_PWR_EN` for CPU 0 when `EXYNOS5_ARM_CORE0_SYS_PWR_REG` has `S5P_CORE_LOCAL_PWR_EN` cleared during suspend, and `exynos5420_pm_resume()` must restore it. In `mcpm-exynos.c`, `exynos_cpu_powerup()`, `exynos_cpu_powerdown_prepare()`, and `exynos_wait_for_powerdown()` must check `cpu < EXYNOS5420_CPUS_PER_CLUSTER` (4) and `cluster < EXYNOS5420_NR_CLUSTERS` (2); `exynos_cpu_powerup()` must call `exynos_cpu_power_up(cpunr)` unconditionally after reading `state`, running the Little-core `EXYNOS_SWRESET` sequence only when `!state && secure_firmware` and the boot CPU shares the non-zero cluster. [F59, F87, F98]
- In `arch/arm/mach-imx/mmdc.c`, `mmdc_pmu_event_add` must check `pmu_mmdc->mmdc_events[cfg] != NULL` before storing `event` and incrementing `active_events`, and `mmdc_pmu_event_del` must clear `mmdc_events[cfg] = NULL`, decrement `active_events`, and call `hrtimer_cancel(&pmu_mmdc->hrtimer)` when `active_events` reaches 0. Any signature change to `imx_mmdc_perf_init()` under `#ifdef CONFIG_PERF_EVENTS` must update the `#else` `#define imx_mmdc_perf_init(...)` macro in lockstep. [F3, F40]
- `avic_set_irq_fiq()` must reject `hwirq >= AVIC_NUM_IRQS` (64) and `tzic_set_irq_fiq()` must reject `(hwirq >> 5) >= 4` (128 IRQs). In `tzic_handle_irq()`, each outer `do { ... } while (handled)` pass must reset `handled = 0`, mask `TZIC_HIPND(i)` with `TZIC_INTSEC0(i)` to exclude secure FIQs, and clear each `1 << irqofs` bit from `stat`. In `exynos_irq_set_wake()`, every `struct exynos_wkup_irq` array in `exynos_pm_data.wkup_irq` must end with a `mask == 0` sentinel. [F58, F61, F67]

## Synchronization

- `exynos_cpu_die()` calls `v7_exit_coherency_flush(louis)` before `platform_do_lowpower()` and `exynos_cpu_power_down()`, so that path runs with cache coherency disabled and must use lockless checks like `soc_is_exynos5420()` rather than functions using `LDREX`/`STREX` atomics like `of_machine_is_compatible()`. Variables written by a coherent CPU and read by a non-coherent secondary CPU—`exynos_pen_release` in `exynos_write_pen_release()` (after `smp_wmb()`) and `g_diag_reg` in `imx_smp_prepare_cpus()`—must be cleaned to memory with `sync_cache_w()`. [F100, F109]
- In `imx_cpu_die()` and `imx_cpu_kill()`, the dying CPU must flush its cache via `v7_exit_coherency_flush(louis)` before signaling readiness with `imx_set_cpu_arg(cpu, ~0)`, and `imx_cpu_kill()` must wait for `imx_get_cpu_arg(cpu)` to become non-zero before calling `imx_enable_cpu(cpu, false)` and clearing the argument back to `0`. [F20]
- Read-modify-write updates to `SRC_SCR` and `SRC_A7RCR1` in `src_base` across `imx_src_reset_module()`, `imx_enable_cpu()`, and `imx_src_init()` must be serialized under `scr_lock`. `imx_src_reset_module()` must release `scr_lock` before its 1000ms reset-completion polling loop, whereas `imx_gpcv2_set_core1_pdn_pup_by_software()` (called by `imx_enable_cpu()` under `scr_lock`) must poll using non-sleeping `readl_relaxed_poll_timeout_atomic()`. [F14, F106]
- In `imx6q_enter_wait()` (`arch/arm/mach-imx/cpuidle-imx6q.c`), state 1 of `imx6q_cpuidle_driver` sets `CPUIDLE_FLAG_RCU_IDLE`, so `num_idle_cpus` and `imx6_set_lpm()` must be protected by `raw_spin_lock(&cpuidle_lock)` outside the `ct_cpuidle_enter()`/`ct_cpuidle_exit()` region wrapping `cpu_do_idle()`, setting `WAIT_UNCLOCKED` when `++num_idle_cpus == num_online_cpus()` before idle and restoring `WAIT_CLOCKED` when `num_idle_cpus-- == num_online_cpus()` after. [F10, F104]
- In `imx_mmdc_perf_init()`, `pmu_mmdc->hrtimer`, `pmu_mmdc->cpu`, `pmu_mmdc->devtype_data`, and the CPU hotplug instance `pmu_mmdc->node` must be initialized and registered before calling `perf_pmu_register()`. Because `mmdc_pmu_event_update()` runs from both perf `.read`/`.stop` callbacks and hardirq `mmdc_pmu_timer_handler()` (via `mmdc_pmu_overflow_handler()`), it must update `event->hw.prev_count` with `local64_cmpxchg()` and add the 32-bit masked delta (`& 0xFFFFFFFF`) to `event->count` via `local64_add()`. [F16, F70, F107]

## Object Lifetimes

- In `arch/arm/mach-imx/mmdc.c`, every PMU ID from `ida_alloc(&mmdc_ida, GFP_KERNEL)` in `mmdc_pmu_init` (`pmu_mmdc->id`) must be freed via `ida_free(&mmdc_ida, pmu_mmdc->id)` both on error in `imx_mmdc_perf_init` (`pmu_release_id` label) and in `imx_mmdc_remove` before `kfree(pmu_mmdc)`. `imx_mmdc_probe` enables `mmdc_ipg_clk` and maps `mmdc_base`; if `imx_mmdc_perf_init` fails, `imx_mmdc_probe` must call `iounmap(mmdc_base)` and `clk_disable_unprepare(mmdc_ipg_clk)`, whereas on success `imx_mmdc_remove` owns both. [F1, F2]
- In `imx6q_suspend_init()` and `imx_suspend_alloc_ocram()`, `pdev` from `of_find_device_by_node(node)` must be released via `put_device(&pdev->dev)` on all paths before `of_node_put(node)`. In `exynos_sysram_init()`, `exynos_map_pmu()`, `imx_init_revision_from_anatop()` (where the inner `MXC_CPU_IMX6ULL` block must pass `src_np`, not outer `np`, to `of_iomap()` and `of_node_put()`), and `imx_gpc_check_dt()`, DT nodes from `of_find_*` or early `for_each_compatible_node()` breaks must be released with `of_node_put()`. [F4, F63, F91]
- In `arch/arm/mach-exynos/suspend.c`, `exynos5420_pm_prepare` must save `pm_state.cpu_state` from `pm_state.sysram_base + EXYNOS5420_CPU_STATE` before zeroing it, and `exynos5420_pm_resume` must restore it before `exynos_pm_central_resume()`. On Exynos4 SoCs, `exynos_set_delayed_reset_assertion(false)` must be called in `exynos_pm_prepare`, and `exynos_set_delayed_reset_assertion(true)` must be called on all exit paths of `exynos_pm_resume` (including `early_wakeup`). [F11, F12]
- In `update_fec_mac_prop()` (`arch/arm/mach-mxs/mach-mxs.c`), `from = np` must precede the `of_property_present(np, "local-mac-address")` `continue` check so `of_find_compatible_node()` advances with `ocotp[i]`. `newmac = kzalloc(sizeof(*newmac) + 6, GFP_KERNEL)` co-allocates `struct property` and its 6-byte payload (`newmac->value = newmac + 1`); if `kstrdup` fails, `kfree(newmac)` must be called, whereas on success `of_update_property(np, newmac)` takes ownership. [F7, F64, F80]

## API Contracts

- In `arch/arm/mach-exynos/platsmp.c`, `exynos_write_pen_release`, `exynos_cpu_power_state`, `exynos_cpu_power_up`, `exynos_cpu_power_down`, `exynos_core_restart`, `exynos_set_boot_addr`, and `call_firmware_op(cpu_boot, ...)` take the hardware core ID (`MPIDR_AFFINITY_LEVEL(cpu_logical_map(cpu), 0)`), not the Linux logical `cpu`. Conversely, `imx_enable_cpu`, `imx_set_cpu_jump`, `imx_get_cpu_arg`, and `imx_set_cpu_arg` in `arch/arm/mach-imx/src.c` translate `cpu = cpu_logical_map(cpu)` internally, so callers must pass the Linux logical `cpu` index. [F32, F33]
- In `arch/arm/mach-exynos/mcpm-exynos.c`, `exynos_pm_power_up_setup()` runs during early bring-up with MMU/caches off and no stack, so it must remain `__naked` assembly with no stack accesses. In `exynos_power_ops`, `exynos_cpu_powerup()` and `exynos_cpu_is_up()` execute with the MCPM lock held and IRQs disabled (requiring `udelay()`, never sleeping), whereas only `exynos_wait_for_powerdown()` runs in sleepable context (`msleep()`). [F102, F103]
- System-suspend finisher callbacks passed to `cpu_suspend()` in Exynos and S5PV210 (`exynos_cpu_suspend` in `firmware.c`, `exynos_cpu_do_idle`, `exynos5420_cpu_suspend`, and `s5pv210_cpu_suspend`) must return a non-zero value (`1`) if execution falls through `wfi`, `exynos_smc`, or `mcpm_cpu_suspend` without powering down. [F25]
- In `exynos_pmu_irq_init()` and `imx_gpc_init()`, `of_node_clear_flag(node, OF_POPULATED)` must be called before returning `0` so platform device probing is not blocked. Their hierarchical irqdomains (`imx_gpc_domain_ops`, `exynos_pmu_domain_ops`) must reject `param_count != 3` or `param[0] != 0` (non-SPIs), `imx_gpc_domain_alloc` must reject `hwirq >= GPC_MAX_IRQS`, and `imx_gpc_irq_set_wake`/`exynos_irq_set_wake` must not call `irq_chip_set_wake_parent`. [F9, F117, F118]
- In `arch/arm/mach-imx/mmdc.c`, `mmdc_pmu_event_init` must reject task-attached (`PERF_ATTACH_TASK` or `event->cpu < 0`) and sampling events, pin `event->cpu` to `cpumask_first(&pmu_mmdc->cpu)`, and validate `cfg >= 0 && cfg < MMDC_NUM_COUNTERS` before calling `mmdc_pmu_group_is_valid`. `mmdc_pmu_group_is_valid` must traverse siblings with `for_each_sibling_event(sibling, leader)` and validate `event` separately when `event != leader`; `mmdc_pmu_group_event_is_valid` must reject software and non-MMDC events before `test_and_set_bit(cfg, used_counters)`. [F62, F75, F115]
- In `imx6sx_enter_wait()`, `cpu_pm_enter()`/`cpu_cluster_pm_enter()` and `cpu_cluster_pm_exit()`/`cpu_pm_exit()` must stay outside `ct_cpuidle_enter()`..`ct_cpuidle_exit()`, and `v7_cpu_resume` in `arch/arm/mach-imx/common.h` must remain built outside `#ifdef CONFIG_SUSPEND`. `mxc_set_irq_fiq()` casts `gc->private` to `struct mxc_extra_irq *`. `mxc_arch_reset_init()` must call `clk_prepare(wdog_clk)` so atomic `mxc_restart()` only calls `clk_enable()`. [F81, F105, F111, F112]

## Error Handling

- `cpu_boot_reg()` returns `IOMEM_ERR_PTR(-ENODEV)` rather than `NULL` when `cpu_boot_reg_base()` is `NULL`, so `exynos_set_boot_addr()` and `exynos_get_boot_addr()` must check `IS_ERR(boot_reg)` and extract `PTR_ERR(boot_reg)`. In both functions, `call_firmware_op()` returns `-ENOSYS` when no firmware hook is registered (triggering fallback to `cpu_boot_reg()`) and other negative errnos on failure; the fallback path must reset `ret = 0` after the MMIO access so `-ENOSYS` is not returned. [F23, F24]
- In `imx6q_suspend_init()`, `pm_info->mmdc_base`, `src_base`, `iomuxc_base`, `gpc_base`, and optional `l2_base` are mapped sequentially via `imx6_pm_get_base()`, and any failure must unwind already-mapped `.vbase` regions in reverse order (`pl310_cache_map_failed` through `src_map_failed`) before `put_device`. Because `mx5_suspend_ops` and `imx6q_pm_ops` are registered even when OCRAM setup is skipped or fails, `mx5_suspend_enter`, `imx6q_pm_enter`, and `imx6q_suspend_finish` must check that `imx5_suspend_in_ocram_fn` / `imx6_suspend_in_ocram_fn` is non-NULL before calling it. [F5, F30]
- In `imx_mmdc_perf_init()`, `cpuhp_setup_state_multi(CPUHP_AP_ONLINE_DYN, ...)` and `mmdc_pmu_init()` return non-negative IDs on success and negative errnos on failure, so `ret` must be tested with `ret < 0`, and if `devm_kasprintf()` returns `NULL`, `ret` must be set to `-ENOMEM` before `goto pmu_release_id`. In `imx_mmdc_probe()`, an `IS_ERR(mmdc_ipg_clk)` from optional `devm_clk_get()` must be normalized to `NULL` before `clk_prepare_enable()`. In `exynos_pmu_irq_init()`, failure after `of_iomap()` must both `iounmap(pmu_base_addr)` and set `pmu_base_addr = NULL`. [F8, F26, F27]

## External Contracts

- In `arch/arm/mach-imx/platsmp.c`, `ls1021a_smp_prepare_cpus()` must byte-swap the physical entry address with `cpu_to_be32()` before passing it to `writel_relaxed(..., dcfg_base + DCFG_CCSR_SCRATCHRW1)`, because the LS1021A DCFG CCSR register block is big-endian while `writel_relaxed()` writes in little-endian byte order. [F60]

## Known Pitfalls

- `imx6_enable_rbc()` in `arch/arm/mach-imx/pm-imx6.c` must not be called between `imx_gpc_pre_suspend()` and `imx_gpc_post_resume()` because both `imx_gpc_mask_all()` (called by `imx6_enable_rbc()`) and `imx_gpc_pre_suspend()` overwrite the single `gpc_saved_imrs[]` array in `arch/arm/mach-imx/gpc.c`. [F42]
- In `arch/arm/mach-imx/src.c`, `imx_enable_cpu()` computes bit shifts using `cpu - 1` (requiring a 1-based secondary hardware CPU ID >= 1), whereas `imx_set_cpu_jump()`, `imx_get_cpu_arg()`, and `imx_set_cpu_arg()` index `SRC_GPR1` by `cpu * 8` (supporting 0-based CPU IDs). [F54]
- In `arch/arm/mach-exynos/mcpm-exynos.c`, `exynos_v7_exit_coherency_flush` must clear `SCTLR.C`, call `v7_flush_dcache_*`, perform a dummy read from `pmu_base_addr + S5P_INFORM0` with a data dependency into `r0`, and clear `ACTLR` bit 6 in a single `asm volatile` block without stack accesses, clobbering `r0`-`r6`, `r9`, `r10`, `ip`, `lr`, and `memory`. In `arch/arm/mach-s5pv210/pm.c`, `s3c_pm_do_restore_core()` must only perform raw `writel_relaxed` writes with no debug logging or peripheral/memory calls. [F101, F110]
