# IO_URING

Implements the `io_uring` asynchronous I/O subsystem, including ring setup, memory mapping, provided/registered buffers and files, SQPOLL/IOPOLL/NAPI polling, the `io-wq` worker pool, inter-ring messaging, and opcode handlers for VFS, block, socket, zero-copy RX/TX, futex, timeout, and `uring_cmd` operations.

## Architecture & Data Flow
- `req->flags` (`io_req_flags_t`) uses 64-bit `IO_REQ_FLAG(bitno)` (`BIT_ULL`) masks (`__REQ_F_LAST_BIT <= 64`) with bits 0..7 reserved for UAPI `IOSQE_*` and internal `REQ_F_*_BIT` starting at bit 8. `io_fixed_file_set()` tags bits 0..1 of `node->file_ptr` by shifting `io_file_get_flags(file)` by `REQ_F_SUPPORT_NOWAIT_BIT`, so `REQ_F_ISREG_BIT` must equal `REQ_F_SUPPORT_NOWAIT_BIT + 1` and `node->file_ptr` must be untagged via `io_slot_file()`. [F60, F121, F141]
- Union and cached-field invariants: on `struct io_kiocb`, `req->kbuf` and `req->buf_node` share a union valid only under `REQ_F_BUFFER_SELECTED` and `REQ_F_BUF_NODE`; `req->creds` and `req->apoll` are not cleared on recycling (and KASAN-poisoned) so they require `REQ_F_CREDS` and `REQ_F_POLLED`. On `struct io_buffer_list`, `buf_list` and `buf_ring` (with `bl->region`) share a union discriminated by `bl->flags & IOBL_BUF_RING`. [F47, F48, F50]
- Poll waitqueue entries tag `IO_WQE_F_DOUBLE` in bit 0 of `poll->wait.private` (requiring `wqe_to_req()`), and `struct io_poll` lives in `req->cmd`/`req->async_data` for `IORING_OP_POLL_ADD` vs `req->apoll->poll`/`req->apoll->double_poll` for other opcodes (`io_poll_get_single()`/`io_poll_get_double()`). `io_poll_parse_events()` must `swahw32(sqe->poll32_events)` on `__BIG_ENDIAN`, and `io_poll_remove()` with `update_events` must only replace the low 16 bits of `poll->events`. [F231, F280]
- CQE overflow and 32-byte CQEs: before `__io_cqring_overflow_flush()` drops `completion_lock` and `uring_lock` with `ctx->cq_overflow_list` non-empty, it must set `ctx->cqe_sentinel = ctx->cqe_cached`; empty/non-empty transitions of `cq_overflow_list` under `completion_lock` must update `IO_CHECK_CQ_OVERFLOW_BIT` and `IORING_SQ_CQ_OVERFLOW` together. On `IORING_SETUP_CQE_MIXED`, 32-byte CQEs set `IORING_CQE_F_32` and advance `cqe_cached` and `cached_cq_tail` by 2 (padding wrap via `io_fill_nop_cqe()`), vs 1 on `CQE32`; `io_alloc_ocqe()` adds `sizeof(struct io_uring_cqe)` (flush copies `2 * sizeof(struct io_uring_cqe)`), and `io_fill_cqe_req()`/`io_alloc_ocqe()` must zero `req->big_cqe` after copying. [F64, F65, F66, F67, F132]
- Because `ctx->sq_sqes` has 64-byte element type `struct io_uring_sqe`, indexing `ctx->sq_sqes` (`io_get_sqe()`, `__io_uring_show_fdinfo()`) must shift the index left by 1 when `IORING_SETUP_SQE128` is set, and SQE byte copies (including `io_uring_cmd_sqe_copy()` into `ac->sqes` before async deferral) must copy `uring_sqe_size(ctx)` bytes; `io_req_uring_cleanup()` must clear `ioucmd->sqe = NULL`. [F135, F256]
- `struct io_uring_buf_ring` overlays `tail` with `bufs[0].resv` at byte offset 14 and its 16-byte header with `bufs[0]`: `io_register_pbuf_ring()` must size it with `flex_array_size(br, bufs, reg.ring_entries)` (not `struct_size()`) and require power-of-2 `ring_entries < 65536` (`MAX_BIDS_PER_BGID`) so 16-bit `tail - head` disambiguates full from empty. [F92, F139]
- In `io_uring/io-wq.c`, `wq->hash_tail[hash]` tracks the last same-hash item in `acct->work_list`: `io_get_next_work()` must clear `wq->hash_tail[hash] = NULL` when cutting `[work, tail]` and fast-forward `node` to `&tail->list` when `test_and_set_bit(hash, &wq->hash->map)` fails; `io_wq_remove_pending()` must update `wq->hash_tail[hash]` to `prev_work` (if same hash) or `NULL`. [F76, F103]
- Link failure and drain accounting: `req_set_fail()` must replace `REQ_F_CQE_SKIP` with `REQ_F_SKIP_LINK_CQES` when setting `REQ_F_FAIL`; `io_submit_fail_init()` on a request with `IO_REQ_LINK_FLAGS` must append it to `submit_state.link` and return `0`. `io_queue_deferred()` must call `__io_req_caches_free(ctx)` before comparing `ctx->nr_req_allocated != ctx->nr_drained`, and `defer_list` changes must adjust `nr_drained` by `io_linked_nr(req)`. [F69, F78, F115]
- Network and RW retry state: partial retries in `io_send()`, `io_recv()`, or `io_recvmsg()` must call `io_net_kbuf_recyle()` before returning `IOU_RETRY`. In `io_recv_finish()` for `IORING_RECVSEND_BUNDLE`, `io_put_kbufs()` and `io_bundle_nbufs()` must use `this_ret = sel->val - sr->done_io`, retry only when `!(sr->flags & IORING_RECV_NO_RETRY)` and `!iov_iter_count(&kmsg->msg.msg_iter)`, and `io_mshot_prep_retry()` must reset `sr->done_io`, `sr->len`, and retry flags. `io_read_mshot()` must reset `rw->len = 0` after `io_kbuf_recycle()` or `io_put_kbuf()`, and RW retries/reissues/short-reads must restore `io->iter` and `io->meta` from `iter_state`/`meta_state`. [F262, F263, F264, F265]
- `struct iou_vec` aliases `iovec` and `bvec`, so `io_prep_reg_iovec()` and `io_import_reg_vec()` must right-align `iovec` entries at `vec->iovec + (vec->nr - nr_iovs)` and add `nr_iovs` extra `iovec` slots when `sizeof(struct bio_vec) > sizeof(struct iovec)`. For user fixed buffers (`!imu->is_kbuf`), only `imu->bvec[0]` may have non-zero `bv_offset`, which `io_import_fixed()` and `io_vec_fill_bvec()` must add before shifting by `imu->folio_shift`; when coalesced in `io_sqe_buffer_register()`, `imu->bvec[0]` offset is `((unsigned long)iov->iov_base & ~PAGE_MASK) + (data.first_folio_page_idx << PAGE_SHIFT)`. [F271, F273, F306]

## Synchronization
- `io_ring_submit_lock()` acquires `ctx->uring_lock` only when `IO_URING_F_UNLOCKED` is set in `issue_flags`; callers must pair it on every exit with `io_ring_submit_unlock()` using the same `IO_URING_F_UNLOCKED` bit, and pass core-supplied `issue_flags` (never hard-coded) to `__io_uring_cmd_done()`, `io_uring_cmd_done()`, `io_uring_cmd_done32()`, and `io_uring_cmd_mark_cancelable()`. Per-context caches (`io_alloc_req()`, `io_cache_alloc()`, `io_cache_free()`, `io_uring_alloc_async_data()`) require `ctx->uring_lock`. [F5, F61, F152]
- Lock ordering around `ctx->uring_lock`: `io_uring_poll()` must never take `ctx->uring_lock` and `io_uring_show_fdinfo()` must only `mutex_trylock(&ctx->uring_lock)`. `__io_uring_add_tctx_node()` and `io_uring_alloc_task_context()` lock `ctx->uring_lock` internally, so callers like `io_ringfd_register()` must unlock it first. In `io_register_clone_buffers()`, when `src_ctx != ctx`, drop `ctx->uring_lock`, lock both via `lock_two_rings(ctx, src_ctx)`, and unlock only `src_ctx->uring_lock` before `fput(file)`. When `io_msg_ring` targets `target_ctx`, bounce via `task_work` if `target_ctx->task_complete` is set, else use `io_lock_external_ctx()`. [F80, F169, F201, F336]
- `sqd->lock` nests outside `ctx->uring_lock`: callers holding `ctx->uring_lock` must pin `sqd->refs` if needed, drop `ctx->uring_lock` before `sqd->lock` or `io_sq_thread_park()`, and verify `sqpoll_task_locked(sqd)` (`sqd->thread`, which is `__rcu`) is non-NULL after parking. In `io_sq_thread_unpark()`, `clear_bit(IO_SQ_THREAD_SHOULD_PARK, &sqd->state)` must precede `atomic_dec_return(&sqd->park_pending)` and be re-set if non-zero. `io_register_resize_rings()` must park `ctx->sq_data` and then hold `uring_lock` -> `mmap_lock` -> `completion_lock`. [F221, F224, F225, F229, F341]
- `ctx->completion_lock` nests outside `ctx->timeout_lock` (`io_kill_timeouts()`, `io_timeout_cancel()`, `io_timeout_remove()`, `io_disarm_next()`). Walking `req->link` via `io_for_each_link` when `REQ_F_LINK_TIMEOUT` is set (`io_match_task_safe()`, `io_prep_async_link()`) requires `raw_spin_lock_irq(&ctx->timeout_lock)`, and callers of `io_match_task_safe()` must not already hold `timeout_lock`. [F29, F334]
- In `io-wq`, `io_acct_run_queue()` returns `true` with `acct->lock` held and `false` unlocked; in `io_worker_handle_work()`, `worker->cur_work` must be assigned under `worker->lock` before releasing `acct->lock`, and `io_wq_worker_cancel()` must hold `worker->lock` (inside `acct->workers_lock`) to inspect `worker->cur_work`. In `io_acct_cancel_pending_work()`, after unlinking `work` and dropping `acct->lock` for `io_run_cancel()`, the loop must return immediately (and `io_wq_cancel_pending_work()` restarts from head). [F24, F45, F102]
- RCU, mmap, and ring barriers: `ctx->napi_list`/`ctx->napi_ht` mutations require `ctx->napi_lock` and RCU primitives/`kfree_rcu` while `io_napi_hash_find()` and `__io_napi_do_busy_loop()` require `scoped_guard(rcu)`. `io_eventfd_signal()` must read `ctx->io_ev_fd` under `guard(rcu)()`, pin `ev_fd->refs`, and hold `ctx->completion_lock` for `ev_fd->last_cq_tail`, with `io_eventfd_put()` freeing via `call_rcu`. Regions and buffer lists must be initialized before publishing via `io_create_region_mmap_safe()` or `io_buffer_add_list()` under `ctx->mmap_lock`. Use `READ_ONCE()` on `io_uring_sqe` fields in `.prep`, `smp_load_acquire()` on `rings->sq.tail` and `br->tail`, and `smp_store_release()` on `rings->cq.tail` and `rings->sq.head`. [F39, F40, F74, F84, F162]

## Object Lifetimes
- Assigning `req->async_data` must set `REQ_F_ASYNC_DATA`, and freeing/recycling it before `io_clean_op()` must clear both `req->async_data` and `REQ_F_ASYNC_DATA` via `io_req_async_data_free()` or `io_req_async_data_clear()`. Before returning `io_async_rw`, `io_async_msghdr`, or `io_async_cmd` to an `io_alloc_cache` via `io_alloc_cache_put()`, callers must call `io_alloc_cache_vec_kasan(&...->vec)`. [F1, F316]
- `io_file_get_normal()` takes an `fget()` ref dropped by `io_put_file()` only when `REQ_F_FIXED_FILE` is clear, whereas `io_file_get_fixed()` increments `req->file_node->refs` (dropped by `io_req_put_rsrc_nodes()`), so assigning a fixed file to `req->file` must set `REQ_F_FIXED_FILE`. Any request targeting an `io_uring` file (`io_is_uring_fops(file)`) or relying on `current->mm` across async execution (`io_futex_prep()`, `io_futexv_prep()`) must call `io_req_track_inflight(req)`. [F2, F8, F164]
- Requests from `io_alloc_req()` carry `ctx->refs` and `ctx->nr_req_allocated` from `__io_alloc_req_refill()` and must be returned via `io_req_add_to_cache()` if aborted, never `kmem_cache_free()`. In `io_submit_sqes()`, unused task refs pre-deducted by `io_get_task_refs(left)` must be restored via `current->io_uring->cached_refs += left` if the loop exits with `left > 0`. [F10, F11]
- `io_wq_submit_work()` holds an extra reference on `req` (refcount 2 or `req_ref_get()`) dropped by `io_wq_free_work()`, which `io_req_complete_post()` relies on when calling `req_ref_put(req)` (so `io_req_complete_post()` must only be called under `IO_URING_F_IOWQ`). In `io_wq_cancel_tw_create()`, call `kfree(worker)` only when `cb->func == create_worker_cont`, not `create_worker_cb`. [F17, F18]
- In `io_send_select_buffer()` and `io_recv_buf_select()`, if `io_buffers_select()`/`io_buffers_peek()` dynamically allocates `arg.iovs` (`!= &kmsg->fast_iov && != kmsg->vec.iovec`), save it in `kmsg->vec` and set `REQ_F_NEED_CLEANUP` before the `ret == 1` branch. When `io_send_zc()`/`io_sendmsg_zc()` flushes `zc->notif` inline (`!(issue_flags & IO_URING_F_UNLOCKED)`), set `zc->notif = NULL` so `io_send_zc_cleanup()` does not double-flush. When `io_kiocb_start_write()` sets `IOCB_WRITE` on a regular file (`REQ_F_ISREG`), every completion/retry/error path must call `io_req_end_write()`. In `io_release_ubuf()` and `io_sqe_buffer_register()` cleanup, unpin pages via `unpin_user_folio(page_folio(page), 1)`. [F193, F194, F349, F350]

## API Contracts
- `io_fixed_fd_install()` consumes `file` via `fput(file)` on error, whereas `__io_fixed_fd_install()` takes ownership of `file` only on success (`ret >= 0`). `__io_fixed_fd_install()`, `io_fixed_fd_install()`, and `io_close_fixed()` take 1-based `file_slot` numbers (or `IORING_FILE_INDEX_ALLOC`), whereas `io_fixed_fd_remove()`, `__io_close_fixed()`, and `io_rsrc_node_lookup()` take 0-based table offsets. [F6, F274]
- `io_alloc_cache_init()` and `io_futex_cache_init()` return `false` on success and `true` on failure. `io_cache_alloc()` only zeroes the first `cache->init_clear` bytes on new allocations or KASAN get, so callers must initialize all fields above `init_clear` and any dirty cached fields. Destructor callbacks passed to `io_alloc_cache_free()` (`io_rw_cache_free`, `io_netmsg_cache_free`, `io_cmd_cache_free`) must have exact signature `void (*)(const void *)` for kCFI. [F42, F57, F317]
- `struct io_br_sel` unions `void __user *addr` with `ssize_t val`: `io_uring_cmd_buffer_select()` can return a negative errno in `sel.val`, and any selected buffer must be passed in the same submission context to `io_uring_mshot_cmd_post_cqe()` with the transfer result or errno in `sel->val` so it commits via `io_put_kbuf()` or recycles via `io_kbuf_recycle()`. [F206, F247]
- When `__io_arm_poll_handler()` returns `0`, poll ownership has transferred to the waitqueue and the caller must not touch `req`; `ipt->result_mask` is valid only on a `> 0` return. In `__io_uring_cmd_done()`, `io_req_complete_defer()` is valid only when `(issue_flags & (IO_URING_F_COMPLETE_DEFER | IO_URING_F_UNLOCKED)) == IO_URING_F_COMPLETE_DEFER`; otherwise non-IOPOLL completions must use `io_req_task_work_add()`. [F230, F328]

## Error Handling
- Because `req->cmd.data` is not zeroed when `struct io_kiocb` is recycled and `io_req_defer_failed()` invokes `def->fail(req)`, any error return in `io_init_req()` before `def->prep(req, sqe)` must go through `io_init_fail_req(req, err)`, and `io_sendmsg_prep()`, `io_recvmsg_prep()`, and `io_send_zc_prep()` must zero `sr->done_io = 0` before any early error return. [F56, F240]
- In `io_uring_create()`, errors before `io_uring_get_file(ctx)` must call `io_ring_ctx_wait_and_kill(ctx)`, whereas errors after `io_uring_get_file(ctx)` attaches `ctx` to `file->private_data` must jump to `err_fput` (`fput(file)`) so `io_uring_release()` kills `ctx` once. On partial returns (`0 < ret < nr_pages`) from `pin_user_pages_fast()` in `io_pin_pages()` or `alloc_pages_bulk_node()` in `io_region_allocate_pages()`, unpin/release the acquired pages before `kvfree(pages)`. [F13, F14]
- Special error codes and ring math: synchronous VFS/socket `.issue` handlers must translate `-ERESTARTSYS` (and `-ERESTART*` in `io_rw_done()`) to `-EINTR`, whereas `io_waitid()` and `io_waitid_cb()` treat `-ERESTARTSYS` from `__do_wait()` as an armed wait; `io_poll_check_events()` and `io_recvzc()` must check `ret == IOU_REQUEUE` (-3072) before `ret < 0`. In `io_ring_buffers_peek()`, check `len = READ_ONCE(buf->len)` for zero before `(arg->max_len + len - 1) / len` and compute available entries via `min_t(__u16, tail - head, UIO_MAXIOV)`. [F126, F130, F249, F289]

## Known Pitfalls
- Use-after-free in list loops: in `io_free_batch_list()`, save `node = req->comp_list.next` before `io_queue_iowq(req)`, `req_ref_put_and_test(req)`, or `io_req_add_to_cache(req, ctx)`; in `io_worker_handle_work()`, read `next_hashed = wq_next_work(work)` before `io_wq_submit_work(work)` and `io_wq_free_work(work)`. In `io_timeout_extract()` and `io_linked_timeout_update()`, record a match in a separate `req = tmp` pointer rather than inspecting the `list_for_each_entry` cursor after loop exit. In `io_ring_exit_work()`, call `list_rotate_left(&ctx->tctx_list)` before `task_work_add()` so `continue` on error does not spin on the head entry. [F101, F104, F105, F294]
- Cancellation, worker creation, and page/msg pitfalls: in `create_worker_cb()`, store `io_acct_activate_free_worker()` in `activated_free_worker` instead of reusing `do_create`; in `io_try_cancel()`, only `!ret` (`0`) from `io_async_cancel_one()` returns immediately while `-EALREADY` must fall through to `io_poll_cancel()`; in `io_sync_cancel()`, refresh `cd.seq = atomic_inc_return(&ctx->cancel_seq)` and re-lookup fixed files on every retry after dropping `ctx->uring_lock`. `io_region_init_ptr()` must check `!PageHighMem(mr->pages[0])` before `page_address()`; `io_copy_page()` must clamp to `PAGE_SIZE` when `folio_test_partial_kmap()` is true and advance `src_offset += n` per loop; `io_sendmsg()`/`io_sendmsg_zc()` must restore `kmsg->msg.msg_control_user = sr->msg_control` before each `__sys_sendmsg_sock()` call. [F98, F106, F108, F147, F267, F285, F345]
