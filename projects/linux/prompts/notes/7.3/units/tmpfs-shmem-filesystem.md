# TMPFS (SHMEM FILESYSTEM)

Implements the Linux swap-backed virtual memory filesystem (`tmpfs`/`shmem`), in-memory user/group quota tracking, and `memfd_create` with file sealing. It provides both a user-mountable filesystem supporting THP/mTHP, xattrs, ACLs, quotas, and casefolding, and the internal backing store (`shm_mnt`) for shared anonymous `mmap`, POSIX/SysV shared memory, userfaultfd, and DRM/GEM objects.

## Architecture & Data Flow
- In `__shmem_get_inode()`, `memset(info, 0, (char *)inode - (char *)info)` zeroes all `struct shmem_inode_info` fields preceding `vfs_inode`, so `vfs_inode` must remain the final member and any new field must precede it. [F49]
- In `shmem_get_folio_gfp()`, `SGP_FALLOC` must zero and mark uptodate an already-cached `!uptodate` folio, but for a newly allocated folio it must convert `sgp` to `SGP_WRITE` before `clear:` so the new folio stays `!uptodate` and will be freed by `shmem_undo_range(..., true)` if `shmem_fallocate()` fails. [F53]
- When `shmem_writeout()` declines to swap out an `!uptodate` folio overlapping an active fallocate range (`!shmem_falloc->waitq && index >= shmem_falloc->start && index < shmem_falloc->next`), it must increment `shmem_falloc->nr_unswapped` by `folio_nr_pages(folio)` (not `1`) under `inode->i_lock`. [F64]
- When splitting or swapping out a large folio at EOF in `shmem_unused_huge_shrink()` or `shmem_writeout()`, the effective end index must be computed via `shmem_fallocend(inode, DIV_ROUND_UP(i_size, PAGE_SIZE))` so `FALLOC_FL_KEEP_SIZE` reservations beyond `i_size` are not discarded. [F161]
- In `shmem_add_to_page_cache()`, when replacing swap entries (`expected != NULL`) with an `nr`-page folio, `xas_for_each_conflict()` must verify every conflicting XArray entry matches contiguous swap values starting at `expected` (`iter.val - nr == swap.val`) or fail with `-EEXIST`. [F158]
- Whenever a folio is added, removed, or replaced in the shmem page or swap cache (`shmem_add_to_page_cache()`, `shmem_delete_from_page_cache()`, `shmem_replace_folio()`), `shmem_update_stats()` must update `NR_FILE_PAGES`, `NR_SHMEM`, and (when `folio_test_pmd_mappable(folio)`) `NR_SHMEM_THPS` in lockstep. [F60]
- In `shmem_find_swap_entries()`, `indices[]` must be indexed by `folio_batch_count(fbatch)` before `folio_batch_add(fbatch, folio)` so `indices[i]` matches `fbatch->folios[i]` and `shmem_unuse_inode()` advances `start` to the last batched index. [F103]
- `memfd_tag_pins()` and `memfd_wait_for_pins()` reuse `PAGECACHE_TAG_TOWRITE` (`MEMFD_TAG_PINNED`) in `mapping->i_pages`, so tmpfs/hugetlbfs must never use it for writeback; `memfd_wait_for_pins()` must call `xas_set(&xas, 0)` before each scan and clear `MEMFD_TAG_PINNED` from every entry on `scan == LAST_SCAN` even on signal or `-EBUSY`. [F109, F174]
- In `shmem_huge_global_enabled()` and `shmem_allowable_huge_orders()`, `shmem_huge == SHMEM_HUGE_DENY` must be checked before `shmem_huge_force` and `SHMEM_HUGE_FORCE`; in `shmem_huge_global_enabled()`, `SHMEM_HUGE_WITHIN_SIZE` must fall through to `SHMEM_HUGE_ADVISE` when `shmem_get_orders_within_size()` returns `0`. [F96, F98]
- In `shmem_evict_inode()`, `mapping_set_exiting(inode->i_mapping)` must be called before `shmem_truncate_range(inode, 0, (loff_t)-1)`. [F67]
- Persistent default superblock flags (like `SB_I_VERSION`) must be set on `fc->sb_flags` in `shmem_init_fs_context()`, and `shmem_reconfigure()` must only overwrite `sbinfo` fields when their `SHMEM_SEEN_*` flag is set in `ctx->seen` (recomputing `sbinfo->free_ispace` from `used_isp` on `SHMEM_SEEN_INODES`). [F73]
- In `shmem_parse_one()` and `shmem_default_max_inodes()`, `inodes` must be bounded to `ULONG_MAX / BOGO_INODE_SIZE` before multiplying by `BOGO_INODE_SIZE` into `unsigned long`, and `Opt_nr_blocks` must reject `ctx->blocks > LONG_MAX`. [F115]

## Synchronization
- `shmem_unuse()` must increment `info->stop_eviction` under `shmem_swaplist_lock` before unlocking for `shmem_unuse_inode()` (after re-locking, restart at `start_over` if `list_empty(&info->swaplist)` and otherwise refresh `next = list_next_entry(info, swaplist)`), and `shmem_evict_inode()` must wait for `atomic_read(&info->stop_eviction) == 0` and recheck it under `shmem_swaplist_lock` before unlinking `info->swaplist`. [F21, F62]
- `shmem_charge()` must increment `mapping->nrpages` under `xa_lock_irq(&mapping->i_pages)` before `shmem_recalc_inode(inode, pages, 0)`; in `shmem_recalc_inode()` and `shmem_alloc_and_add_folio()`, `info->alloced - info->swapped - READ_ONCE(mapping->nrpages)` must be stored in a signed `long freed`, and `info->lock` must be dropped before calling `shmem_inode_unacct_blocks()` (only when `freed > 0`). [F29, F122]
- `shmem_swapin_folio()` must call `get_swap_device(index_entry)` before `shmem_confirm_swap()`, and after `folio_lock(folio)` must revalidate `(!skip_swapcache && !folio_test_swapcache(folio)) || shmem_confirm_swap(mapping, index, swap) < 0 || folio->swap.val != swap.val`. [F30]
- In `shmem_fallocate()` and `shmem_falloc_wait()`, `inode->i_lock` must be held when modifying `inode->i_private` and across `prepare_to_wait()`, `wake_up_all()`, and `finish_wait()` on the stack-allocated `shmem_falloc_waitq` with `synchronous_wake_function`. [F25]
- In the second pass (`whole_folios`) of `shmem_undo_range()`, each locked folio must be checked with `folio_test_large(folio)` and handled via `truncate_inode_partial_folio(folio, lstart, lend)` (resetting `index = start` if split) rather than calling `truncate_inode_folio()` unconditionally. [F160]
- `shmem_unused_huge_shrink()` must use `folio_trylock(folio)` (never `folio_lock(folio)`) and move the inode back to `sbinfo->shrinklist` if contended. [F24]
- In `mm/shmem_quota.c` (`shmem_get_next_id()`, `shmem_acquire_dquot()`, `shmem_release_dquot()`), `((struct rb_root *)info->dqi_priv)->rb_node` must never be read or have its address taken before acquiring `dqopt->dqio_sem`. [F27]
- `shmem_acquire_dquot()` must initialize `dquot->dq_dqb` and `DQ_FAKE_B` under `dquot->dq_dqb_lock` and issue `smp_mb__before_atomic()` before setting `DQ_ACTIVE_B`; `shmem_release_dquot()` must check `dquot_is_busy(dquot)` under `dquot->dq_lock`, and when not busy must only erase/free the `struct quota_id` node if `shmem_is_empty_dquot(dquot)` is true (otherwise persisting limits in the rbtree before clearing `DQ_ACTIVE_B`). [F18, F28]
- In `memfd_add_seals()`, `inode_lock(inode)` must be held across seal updates, and on `F_SEAL_WRITE`, `mapping_deny_writable(file->f_mapping)` must succeed before `memfd_wait_for_pins()` and be reverted via `mapping_allow_writable()` on failure. [F34]
- Updates and mark changes on `mapping->i_pages` in `mm/shmem.c` and `mm/memfd.c` must use IRQ-safe XArray locks (`xa_lock_irq()`, `xas_lock_irq()`, `xa_cmpxchg_irq()`), and loops in `memfd_tag_pins()` / `memfd_wait_for_pins()` must call `xas_pause()` before `xas_unlock_irq()` and `cond_resched()`. [F146]
- In `shmem_file_read_iter()` and `shmem_file_splice_read()`, because reads run without `i_rwsem`, `inode->i_size` must be re-read via `i_size_read(inode)` after `shmem_get_folio(..., SGP_READ)` returns an uptodate folio, and if `mapping_writably_mapped(mapping)` is true, `flush_dcache_folio()` / `flush_dcache_page()` must precede reading or splicing. [F79, F135]
- In `shmem_partial_swap_usage()`, the `xas_for_each()` loop under `rcu_read_lock()` must break when `xas.xa_index == max` (`end - 1`) before calling `cond_resched_rcu()`, because single-page lookups can run under a PTE spinlock. [F136]
- `shmem_get_sbmpol()` must hold `raw_spin_lock(&sbinfo->stat_lock)` across reading `sbinfo->mpol` and `mpol_get()`, and `shmem_reconfigure()` must swap `sbinfo->mpol` under `sbinfo->stat_lock` before calling `mpol_put()` outside the lock; in `shmem_reserve_inode()`, `SB_KERNMOUNT` per-CPU `sbinfo->ino_batch` access must be bracketed with `get_cpu()`/`put_cpu()`. [F35, F143]
- In `shmem_get_link()`, when `dentry == NULL` (RCU-walk), the callback must not sleep or call `shmem_get_folio()`; it must use `filemap_get_folio(inode->i_mapping, 0)` and return `ERR_PTR(-ECHILD)` if missing, `!uptodate`, or `PageHWPoison`. [F145]
- In `shmem_encode_fh()`, lazy hashing via `__insert_inode_hash()` must be serialized by the static spinlock with `inode_unhashed(inode)` rechecked inside the lock. [F36]

## Object Lifetimes
- In `__shmem_file_setup()`, all precondition checks must precede `shmem_acct_size()`, and `shmem_unacct_size()` must be called directly only if `shmem_get_inode()` fails, because once `inode->i_size` is set, `iput(inode)` unaccounts `inode->i_size` via `shmem_evict_inode()`. [F1]
- Because `shmem_destroy_inode()` only calls `mpol_free_shared_policy()` for `S_ISREG` inodes, `__shmem_get_inode()` must pass `NULL` to `mpol_shared_policy_init()` for `S_IFLNK` inodes and never populate `info->policy`'s rbtree on non-regular inodes. [F6]
- When transferring `ctx->mpol` to `sbinfo->mpol` in `shmem_fill_super()` or `shmem_reconfigure()` (or replacing `ctx->mpol` in `shmem_parse_one()`), `ctx->mpol` must be cleared to `NULL` (and any replaced `mpol` released with `mpol_put()`) so `shmem_free_fc()` does not double-free it. [F13]
- In `shmem_unused_huge_shrink()`, every inode moved onto the local `list` must have `info->shrinklist` deleted with `list_del_init()` or moved back to `sbinfo->shrinklist` under `sbinfo->shrinklist_lock` before `iput(inode)`, and `shmem_get_folio_gfp()` must use `list_empty_careful(&info->shrinklist)` under `sbinfo->shrinklist_lock`. [F23]
- In `shmem_file_splice_read()`, after splicing and calling `folio_put(folio)` inside the loop, `folio` must be reset to `NULL` so breaking out of the loop does not double-put `folio` at post-loop cleanup. [F15]

## API Contracts
- `shmem_get_folio_gfp()` and `shmem_get_folio()` return `0` without populating `*foliop` on `SGP_READ` holes or userfaultfd faults and can return early errors without touching `*foliop`, so callers must initialize `folio = NULL` and check `folio != NULL` even after a `0` return. [F40]
- `shmem_truncate_range()` and `shmem_undo_range()` take an inclusive byte end `lend` (`lend == -1` means EOF), so callers on `[offset, offset + len)` must pass `offset + len - 1` and `shmem_fallocate()` must guard rollback with `if (index > start)` so `index == 0` never passes `lend = -1`; conversely, `shmem_partial_swap_usage()` takes page indices `[start, end)` where `end` is exclusive. [F55, F118]
- `memfd_file_seals_ptr()` must check `shmem_file(file)` before `SHMEM_I()` and `is_file_hugepages(file)` before `HUGETLBFS_I()`; because it returns `NULL` for other files or when `!CONFIG_SHMEM`, every caller must NULL-check the returned pointer before dereferencing. [F45, F128]
- `shmem_mapping()` tests `mapping->a_ops == &shmem_aops` (satisfied only by `S_IFREG` and long symlinks `len > SHORT_SYMLINK_LEN`); `shmem_mmap()` sets `vma->vm_ops` to `&shmem_anon_vm_ops` when `inode->i_nlink == 0` and `&shmem_vm_ops` otherwise, which `vma_is_anon_shmem()` uses for mTHP order selection in `shmem_allowable_huge_orders()` (which must also check `thp_disabled_by_hw() || (vma && vma_thp_disabled(vma, vm_flags, shmem_huge_force))`). [F151, F153, F155]
- In `shmem_replace_folio()`, memcg association must be transferred using `mem_cgroup_replace_folio(old, new)` under `swap_cluster_get_and_lock_irq` rather than `mem_cgroup_migrate(old, new)`. [F159]
- In `shmem_symlink()`, `len` is `strlen(symname) + 1`, so `kmemdup()`/`memcpy()` must copy `len` bytes while `inode->i_size` and `inode_set_cached_link()` take `len - 1`, and page-backed symlinks must call `inode_nohighmem(inode)` before `shmem_get_folio()`. [F132]
- In `shmem_file_read_iter()`, when reading a hole (`folio == NULL`), `copy_page_to_iter(ZERO_PAGE(0), ...)` may only be used when `user_backed_iter(to)` is true; otherwise use `iov_iter_zero(nr, to)`. [F166]

## Error Handling
- `shmem_parse_huge()` returns negative constants `SHMEM_HUGE_DENY` (`-1`) and `SHMEM_HUGE_FORCE` (`-2`), so callers permitting them (`shmem_enabled_store()`, `setup_transparent_hugepage_shmem()`) must test `huge == -EINVAL` rather than `huge < 0`, `shmem_enabled_store()` must only assign `SHMEM_SB(shm_mnt->mnt_sb)->huge = shmem_huge` when `shmem_huge > SHMEM_HUGE_DENY`, and `__shmem_get_inode()` must only call `mapping_set_large_folios(inode->i_mapping)` when `sbinfo->huge` is non-zero. [F38, F71]
- In `shmem_parse_opt_casefold()` and `setup_thp_shmem()`, return values of `utf8_parse_version()` and `get_order_from_str()` must be stored in signed `int` variables and checked for `< 0` (`setup_thp_shmem()` must also validate `0 <= start <= end` before `bitmap_set()`/`bitmap_clear()`), and `shmem_huge_global_enabled()` must guard `BIT(HPAGE_PMD_ORDER)` when `HPAGE_PMD_ORDER > MAX_PAGECACHE_ORDER`. [F39, F119]
- In `shmem_file_read_iter()` and `shmem_file_splice_read()`, if `shmem_get_folio(..., SGP_READ)` returns `-EINVAL` (concurrent truncate past `index`), the caller must reset `error = 0` and break out of the loop; in `shmem_unuse_swap_entries()`, only `error == -ENOMEM` may break and return an error, while all other `shmem_swapin_folio()` errors must be reset to `0`. [F57, F104]

## External Contracts
- In `memfd_create()`, `sanitize_flags()` must reject `MFD_HUGE_MASK << MFD_HUGE_SHIFT` without `MFD_HUGETLB`, reject `MFD_EXEC | MFD_NOEXEC_SEAL`, and always call `check_sysctl_memfd_noexec()` (defaulting omitted flags to `MFD_NOEXEC_SEAL` when `sysctl >= MEMFD_NOEXEC_SCOPE_NOEXEC_SEAL`), while `alloc_name()` must cap user name length at `MFD_NAME_MAX_LEN` (`NAME_MAX - 6`). [F92, F97]
- `shmem_parse_one()` must validate `Opt_uid`/`Opt_gid` via `kuid_has_mapping()`/`kgid_has_mapping(fc->user_ns, ...)`, and in `shmem_parse_one()` and `shmem_read_file_info()`, quota limits must be positive (`> 0`) and at most `SHMEM_QUOTA_MAX_SPC_LIMIT` / `SHMEM_QUOTA_MAX_INO_LIMIT` (`0x7fffffffffffffffLL`). [F89, F169]

## Known Pitfalls
- In `shmem_get_orders_within_size()` and `shmem_suitable_orders()`, aligning `index` in the order loop must pass `1 << order` (not `order`) to `round_up()`/`round_down()` and store into `aligned_index` without clobbering `index`; `shmem_get_orders_within_size()` must pass `index + 1` (`round_up(index + 1, 1 << order)`), and EOF tail checks in `shmem_get_folio_gfp()`, `shmem_unused_huge_shrink()`, and `shmem_writeout()` must compare `DIV_ROUND_UP(i_size_read(inode), PAGE_SIZE)` against `folio_next_index(folio)` (not `folio_next_index(folio) - 1`). [F54, F83, F84]
- In `shmem_get_folio_gfp()` and `shmem_fallocate()`, `pgoff_t` indices (`index`, `start`) must be cast to `loff_t` before `<< PAGE_SHIFT`; in `shmem_fallocate()`, after `index = folio_next_index(folio)`, `if (!index) index--;` must clamp `index` on 32-bit wraparound before updating `shmem_falloc` or testing `index < end`. [F112, F117]
- In `shmem_parse_one()` (`Opt_size`), percentage division on `u64 size` must use `do_div(size, 100)` and byte-to-block conversion must use `DIV_ROUND_UP(size, PAGE_SIZE)`; in `shmem_next_opt()`, commas before a digit (`isdigit(*(p+1))`) must not split `mpol=` node lists; and in `shmem_parse_opt_casefold()`, `param->string + 5` must only be dereferenced when `!latest_version` and after `strncmp(param->string, "utf8-", 5)` succeeds. [F95, F120, F131]
- In `shmem_unused_huge_shrink()`, the inner block of the second `list_for_each_safe(pos, next, &list)` loop declares `pgoff_t next`, shadowing the `struct list_head *next` cursor; and `tmpfs_attributes` entries under `tmpfs_kobj` must use `struct kobj_attribute` (`TMPFS_ATTR_*`), never `DEVICE_ATTR*`. [F111, F129]
