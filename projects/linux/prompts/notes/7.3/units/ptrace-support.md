# PTRACE SUPPORT

Implements architecture-specific ptrace support across CPU architectures (`alpha`, `arc`, `arm`, `arm64`, `csky`, `hexagon`, `loongarch`, `m68k`, `microblaze`, `mips`, `nios2`, `openrisc`, `parisc`, `powerpc`, `riscv`, `s390`, and `sh`), including `struct pt_regs`, `user_regset` / `user_regset_view` accessors, `arch_ptrace` and `compat_arch_ptrace` handlers, hardware debug/watchpoint management, single/block-step control, syscall tracing hooks, and kernel stack/register query helpers.

## Architecture & Data Flow

- On arm64, ZA and ZT0 share `target->thread.sme_state` (`thread_zt_state()` is at `ZA_SIG_REGS_SIZE(sme_vq)`), so `sme_alloc()` in `za_set()` and `zt_set()` must flush only when `!thread_za_enabled(&target->thread)`, and `sve_set_common()` must pass `flush = false`. In `sve_init_header_from_task()`, `SVE_PT_REGS_SVE` vs `SVE_PT_REGS_FPSIMD` in `header->flags` must be chosen from `target->thread.fp_type == FP_STATE_SVE` rather than `TIF_SVE`. [F52, F54]
- On s390, 64-bit FPRs and low vector registers share `target->thread.ufpu.vxrs[0..15]` (each FPR in the upper 64 bits of a 128-bit `__vector128` slot): `s390_fpregs_set()` must unpack via `convert_vx_to_fp()` before `user_regset_copyin()` and repack via `convert_fp_to_vx()`, `s390_vxrs_low_set()` must stage and write only `vxrs[i].low`, and `__peek_user()`/`__poke_user()` must multiply the byte offset into `regs.fp_regs.fprs` by 2 when byte-indexing `vxrs`. [F65, F129]
- On arm64 (`gpr_set`, `compat_gpr_set`, `compat_ptrace_write_user`) and arm (`put_user_reg`, `gpr_set`), user GPR writes must be staged in a local `pt_regs`/`user_pt_regs` copy and validated with `valid_user_regs()` (which on arm64 also calls `user_regs_reset_single_step()`) before committing to `task_pt_regs(target)`. In s390 `__poke_user()` and `__poke_user_compat()`, writes to `regs.psw.mask` must be validated with `(data ^ PSW_USER_BITS) & ~mask` (and 31-bit equivalent), rejecting writes that clear `PSW_USER_BITS`, set bits outside `mask`, select `PSW_ASC_HOME`, or set `PSW_MASK_EA` without `PSW_MASK_BA`. [F58, F103]
- Register writes must update coupled state in lockstep: on MIPS (`ptrace_setregs`, `gpr32_set`, `gpr64_set`, `PTRACE_POKEUSR`), modifying GPR `$2` (or GPR `$4` when `mips_syscall_is_indirect(child, regs)`) must call `mips_syscall_update_nr(child, regs)`; on s390 (`__poke_user`, `__poke_user_compat`), writing `regs.gprs[2]` while `test_pt_regs_flag(regs, PIF_SYSCALL)` must set `regs->int_code = 0x20000 | (data & 0xffff)`. [F62, F64]
- On LoongArch (`fpr_set`, `simd_set`) and MIPS (`ptrace_setfpregs`, `fpr_set`, `msa_set`, and `PTRACE_POKEUSR` on `FPR_BASE`/`FPC_CSR`), `init_fp_ctx(target)` must be called before writing `target->thread.fpu` so unused FP contexts are initialized to `~0` and marked `used_math` via `set_stopped_child_used_math(target)`. In MIPS `ptrace_setfcr31()`, writes to `child->thread.fpu.fcr31` must preserve hardware-masked bits in `boot_cpu_data.fpu_msk31` via `(value & ~mask) | (fcr31 & mask)`. [F63, F145]
- In `ptrace_hbp_get_event()` and `ptrace_hbp_set_event()` on arm64 and LoongArch, slot index `idx` must be bounds-checked against `ARM_MAX_BRP`/`LOONGARCH_MAX_BRP` or `ARM_MAX_WRP`/`LOONGARCH_MAX_WRP` and clamped with `array_index_nospec()` before indexing `hbp_break[]` or `hbp_watch[]`. In `ptrace_hbp_fill_attr_ctrl()` (arm64) and `ptrace_sethbpregs()` (arm), decoded permission bits must be checked with `(type & allowed_mask) != type` to reject any bit outside `HW_BREAKPOINT_X` or `HW_BREAKPOINT_RW` with `-EINVAL`. [F78, F102]
- On PowerPC (`arch/powerpc/include/asm/ptrace.h`), `TRAP(regs)` must mask out `TRAP_FLAGS_MASK` (`(regs)->trap & ~TRAP_FLAGS_MASK`) and `set_trap(regs, val)` must preserve `regs->trap & TRAP_FLAGS_MASK` so low-bit flags like `trap_norestart` (`0x1`) are not clobbered or misread, and `sizeof(struct pt_regs)` must remain a multiple of 16 bytes. On arm64 and RISC-V, `struct user_pt_regs` and `struct user_regs_struct` must be an exact prefix of `struct pt_regs`, and in arm64 `struct user_fpsimd_state`, `fpcr` must immediately follow `fpsr`. [F84, F85, F101, F151]
- On LoongArch and MIPS, where `struct pt_regs` ends with zero-length `__last`, `MAX_REG_OFFSET` must be `offsetof(struct pt_regs, __last) - sizeof(unsigned long)` because `regs_get_register()` uses `offset > MAX_REG_OFFSET`. In `arch/arm64/kernel/ptrace.c`, each conditional enumerator in `enum aarch64_regset` must use the exact `#ifdef CONFIG_*` guard as its `aarch64_regsets[]` entry; in `arch/loongarch/kernel/ptrace.c`, `REGSET_HW_BREAK`/`REGSET_HW_WATCH` `.n` and `hw_break_set()` offset must both use `struct user_watch_state_v2`. [F61, F72, F165]

## Synchronization

- In `user_regset` callbacks across arm64, s390, and RISC-V, helpers that save or restore live CPU registers (`fpsimd_preserve_current_state`, `tls_preserve_current_state`, `gcs_preserve_current_state`, `save_access_regs`, `save_user_fpu_regs`, `riscv_v_vstate_save`, `fstate_save`) must only be called when `target == current`. On arm64, all getters reading CPU-cached thread state (`fpr_get`, `fpmr_get`, `sve_get_common`, `za_get`, `compat_vfp_get`, `tls_get`, `gcs_get`) must call the corresponding `*_preserve_current_state()` when `target == current`. [F19, F110]
- On arm64, any regset setter modifying FP, FPMR, SVE, or SME state (`fpr_set`, `fpmr_set`, `sve_set_common`, `za_set`, `zt_set`, `compat_vfp_set`) must call `fpsimd_flush_task_state(target)` to invalidate cached per-CPU vector state. `__fpr_get()` and `__fpr_set()` must call `fpsimd_sync_from_effective_state(target)` before reading or updating `target->thread.uw.fpsimd_state`, and `fpr_set()` must call `fpsimd_sync_to_effective_state_zeropad(target)` after `__fpr_set()`. [F20, F21]
- On ARM, `vfp_get()` and `vfp_set()` must call `vfp_sync_hwstate(thread)` before reading `thread->vfpstate.hard`, and `vfp_set()` must call `vfp_flush_hwstate(thread)` after writing it. On LoongArch, `fpr_get()` and `simd_get()` must call `save_fpu_regs(target)` before reading `target->thread.fpu.fpr`. On PowerPC, modifying `regs->nip` or `regs->msr` (`regs_set_return_ip`, `regs_set_return_msr`, `instruction_pointer_set`) must call `set_return_regs_changed()` to clear `local_paca->hsrr_valid` and `srr_valid`. [F22, F24, F25]

## Object Lifetimes

- In `flush_ptrace_hw_breakpoint()`, each non-NULL `perf_event` pointer in `tsk->thread.debug` (`hbp_break[]`, `hbp_watch[]`, or `hbp[]`) must be set to `NULL` immediately after `unregister_hw_breakpoint()`. When cloning a task on ARM or arm64, the child's breakpoint pointer arrays in `tsk->thread.debug` must be zeroed via `clear_ptrace_hw_breakpoint()` or `ptrace_hw_copy_thread()` without calling `flush_ptrace_hw_breakpoint()`, so the child cannot unregister parent-owned `perf_event`s. [F1, F14]
- When creating or updating a ptrace hardware breakpoint, watchpoint, or single-step slot (`ptrace_hbp_create`, `ptrace_hbp_get_initialised_bp`, `ptrace_sethbpregs`, `set_single_step`), `ptrace_hbp_create()` on arm, arm64, and LoongArch must set `attr.disabled = 1` before `register_user_hw_breakpoint()`; the returned `struct perf_event *` (including on sh) must be checked with `IS_ERR(bp)` before storing into the task's array; and an existing `perf_event` in the slot must be reused via `modify_user_hw_breakpoint()` rather than calling `register_user_hw_breakpoint()` again. [F3, F13, F37]

## API Contracts

- In `user_regset` `.set` callbacks, sequential calls to `user_regset_copyin()` and `user_regset_copyin_ignore()` must use monotonically non-decreasing `start_pos` offsets (or reset `pos = 0` first as in `riscv_vr_set()`) because both helpers `BUG_ON(*pos < start_pos)` when `*count != 0`. Any padding or read-only gap between writable segments (and the resource-info header and per-slot `u32` pad in arm64/LoongArch `hw_break_set()`, plus `membuf_zero(&to, sizeof(u32))` in `hw_break_get()`) must be consumed with `user_regset_copyin_ignore()`. [F107, F167, F170]
- In `user_regset` `.set` callbacks that stage data in a local struct (`__fpr_set`, `gpr_set`, `tls_set`, `poe_set` on arm64; `vfp_set` on arm; `s390_vxrs_low_set`, `s390_gs_cb_set`, `s390_runtime_instr_set` on s390), the local struct must be pre-populated with synchronized target state before `user_regset_copyin()`. On arm64, any `target->thread` field passed directly to `user_regset_copyin()` (`compat_vfp_set`, `sve_set_common`) must reside in the `thread.uw` usercopy whitelist; fields outside `thread.uw` (`por_el0`, `tpidr2_el0`) must be staged through a stack local. [F168, F175]
- Architecture capability checks must gate optional register sets before accessing thread state: on arm64, optional regset callbacks (`fpr_*`, `compat_vfp_*`, `fpmr_*`, `sve_*`, `ssve_*`, `za_*`, `zt_*`, `pac_*`, `poe_*`, `gcs_*`) must check `system_supports_*()` (`-EINVAL`), and `tls_get()`/`tls_set()` must gate `tpidr2_el0` on `system_supports_tpidr2()`; on s390, `update_cr_regs()` and TE requests must check `machine_has_tx()` and `cpu_has_gs()`; on MIPS, DSP paths must check `cpu_has_dsp` (`-EIO`), and `ptrace_get_watch_regs()`/`ptrace_set_watch_regs()` must check `cpu_has_watch` and bound loops by `boot_cpu_data.watch_reg_use_cnt`. [F135, F137, F141, F143, F144]
- In `ptrace_disable()`, per-thread watchpoint and stepping state must be cleared on detach: `TIF_LOAD_WATCH` on LoongArch (where `ptrace_hbp_set_ctrl()` also sets/clears `TIF_LOAD_WATCH` in lockstep with `attr.disabled` via `uctrl & CTRL_PLV_ENABLE`) and MIPS; `TIF_SINGLESTEP` on LoongArch and PA-RISC; `TIF_BLOCKSTEP` and `pa_psw(task)` trap bits (`r`, `t`, `h`, `l`, kept in lockstep by `user_enable_single_step()` and `user_enable_block_step()`) on PA-RISC; and `per_user`, `per_event`, `per_flags`, `TIF_SINGLE_STEP`, and `TIF_PER_TRAP` on s390. [F60, F71, F185]
- In `sve_set_common()` and `za_set()` (`arch/arm64/kernel/ptrace.c`), `header.flags` must be cast to `unsigned long` and shifted left by 16 (after masking out `SVE_PT_REGS_MASK` in `sve_set_common()`) when passed to `vec_set_vector_length()`, and if `count > 0` while the resulting task VL (`task_get_vl()` / `task_get_sme_vl()`) differs from `header.vl`, the function must return `-EIO` without copying register data. [F40, F116]
- Syscall return and instruction pointer helpers must honor ABI conventions: on PowerPC, `is_syscall_success()` and `regs_return_value()` must branch on `trap_is_scv(regs)` (`scv` returns `-errno` in `regs->gpr[3]`, while non-`scv` sets `0x10000000` in `regs->ccr` and negates `regs->gpr[3]`); on MIPS, `regs_return_value(regs)` must negate `regs->regs[2]` only when `user_mode(regs) && !is_syscall_success(regs)`; on arm64, `regs_return_value(regs)` must call `sign_extend64(val, 31)` when `compat_user_mode(regs)`, and reading/writing AArch32 CPSR must translate via `pstate_to_compat_psr()` / `compat_psr_to_pstate()`. [F30, F31, F32, F50]
- In `regs_get_register()` and `regs_get_kernel_stack_nth()`, out-of-bounds offsets and addresses failing `regs_within_kernel_stack(regs, addr)` must return `0`. On arm64 and s390, `regs_get_kernel_stack_nth()` must use `READ_ONCE_NOCHECK(*addr)` to avoid KASAN false positives; on arm64, `regs_within_kernel_stack()` must also accept `on_irq_stack(addr, sizeof(unsigned long))`, and `pt_regs_read_reg()`/`pt_regs_write_reg()` take register index `r` (`r == 31` is XZR) whereas `regs_get_register()` takes a byte offset; on PA-RISC, `regs_get_kernel_stack_nth(regs, n)` must subtract word index `n` (`addr -= n`). [F43, F45, F149, F150, F186]

## Error Handling

- In `arch/arm64/kernel/ptrace.c`, `sve_alloc()` and `sme_alloc()` allocate `target->thread.sve_state` and `target->thread.sme_state` in-place without returning a status code: `sve_set_common()`, `za_set()`, and `zt_set()` must check that the allocated state pointers are non-NULL (returning `-ENOMEM` if NULL), and in `za_set()` and `zt_set()` both `sve_state` and `sme_state` must be verified non-NULL and `user_regset_copyin()` must succeed before setting `TIF_SME` and `SVCR_ZA_MASK`. [F5, F38]
- In `arch/arm64/kernel/ptrace.c`, `za_get()` and `zt_get()` must check `thread_za_enabled(&target->thread)` before reading `target->thread.sme_state` or `thread_zt_state(&target->thread)`, and `sve_get_common()` must only read `target->thread.sve_state` when `header.flags & SVE_PT_REGS_MASK` is `SVE_PT_REGS_SVE` and `header.size > sizeof(header)`. Also, `sve_init_header_from_task()` and `za_get()` must `memset()` `struct user_sve_header` / `struct user_za_header` to zero, and `sve_get_common()` and `za_get()` must zero inter-section gaps and trailing padding up to `ALIGN(header.size, SVE_VQ_BYTES)` via `membuf_zero()`. [F39, F41]

## External Contracts

- On MIPS, `PTRACE_PEEKUSR` and `PTRACE_POKEUSR` for `FPR_BASE .. FPR_BASE + 31` must test `TIF_32BIT_FPREGS` on `child` via `test_tsk_thread_flag(child, TIF_32BIT_FPREGS)` (never `test_thread_flag()` on `current`): when set, odd FP addresses access the high 32 bits of the even FP slot via `get_fpr32()`/`set_fpr32(&fregs[(addr & ~1) - FPR_BASE], addr & 1, ...)`; when clear, they must use `get_fpr64(..., 0)` and `set_fpr64(..., 0, data)`. Also, `gpr32_set()`/`dsp32_set()` must cast `u32` elements to `(s32)` so 32-bit values sign-extend on 64-bit kernels, and `NT_PRFPREG` `fpr_get()`/`fpr_set()` must treat the 64-bit slot after the 32 FPRs as 32-bit `fcr31` followed by read-only `FIR` (`boot_cpu_data.fpu_id`). [F76, F87, F99, F112, F113]
-In `arch/loongarch/kernel/ptrace.c` (`simd_get`) and `arch/mips/kernel/ptrace.c` (`msa_get`), when the target task has not used math or only a narrower FP/SIMD context is live (`TIF_LSX_CTX_LIVE`, `TIF_LASX_CTX_LIVE`, `TIF_MSA_CTX_LIVE`), `copy_pad_fprs()` must pad the upper `regset->size - min(regset->size, live_sz)` bytes of each of the `NUM_FPU_REGS` vector registers with `0xff` (`~0ull`). In `fpr_set_msa()` (MIPS) and `gfpr_set_simd()` (LoongArch), the per-register copyin loop must continue while `i < NUM_FPU_REGS && *count > 0` so `user_regset_copyin()` advances `*pos` and `*count` across every FPR slot before `fpr_set()` copies trailing control registers. [F92, F100]

## Known Pitfalls

- When a `user_regset` `.regset_get` callback (`gpr_get()`, `fpr_get()`) copies a register state struct via a pointer `regs` into a `struct membuf` using `membuf_write(&to, regs, ...)`, the size argument must be the pointee size `sizeof(*regs)` rather than the pointer size `sizeof(regs)`. [F121]
