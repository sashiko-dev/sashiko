# USB XHCI DRIVER

Core USB xHCI driver (`xhci.c`, `xhci-ring.c`), sideband offload (`xhci-sideband.c`), tracepoints (`xhci-trace.h`), and Tegra/RZ glue (`xhci-tegra.c`, `xhci-rzv2m.c`).

## Architecture & Data Flow

- Event rings (`TYPE_EVENT`) use all `TRBS_PER_SEGMENT` entries without Link TRBs, while command and transfer rings reserve `seg->trbs[TRBS_PER_SEGMENT - 1]` for a Link TRB. In `xhci_clear_command_ring()`, only `memset` the first `TRBS_PER_SEGMENT - 1` TRBs and clear `TRB_CYCLE` on each segment's Link TRB (`link.control`) without overwriting the Link TRB itself, before `xhci_initialize_ring_info()` and `xhci_set_cmd_ring_deq()`. [F64, F88, F131]
- Because `inc_enq()` leaves `ring->enqueue` on a Link TRB when `!chain && !more_trbs_coming`, `xhci_num_trbs_free()` and `xhci_ring_expansion_needed()` must treat `trb_is_link(ring->enqueue)` with `ring->enq_seg->next->trbs == ring->dequeue` as an empty ring, and `xhci_ring_expansion_needed()` must check `trbs_past_seg < 0` (`enq_used + num_trbs - (TRBS_PER_SEGMENT - 1)`). In `inc_deq()` and `inc_enq_past_link()`, bound `while (trb_is_link(...))` with `link_trb_count++ > ring->num_segs`. [F86, F105, F106]
- In `xhci_queue_bulk_tx()`, `xhci_queue_ctrl_tx()`, and `xhci_queue_isoc_tx()`, call `prepare_transfer()` (which may advance `ring->enqueue` past a Link TRB) before capturing `start_trb` and `start_cycle`. Write the first TRB with `TRB_CYCLE` inverted (`!start_cycle`) and hand it to hardware only after queuing all TRBs via `giveback_first_trb()` with the saved `start_trb` and `start_cycle`. [F76, F134]
- In `xhci_queue_bulk_tx()`, loop while `first_trb || enqd_len < full_len` so zero-length URBs queue one TRB, and pass `more_trbs_coming | need_zero_pkt` to `queue_trb()` so `inc_enq()` crosses any Link TRB before the zero-packet TD. For Immediate Data (`TRB_IDT`), gate `memcpy` into 8-byte `send_addr`/`addr` with `xhci_urb_suitable_for_idt(urb)` and apply `le64_to_cpus()` before `lower_32_bits()`/`upper_32_bits()`. [F97, F113, F139]
- `xhci_get_endpoint_index()` returns 0-based `ep_index` (`0..30`, `< EP_CTX_PER_DEV`) for `vdev->eps[]`, `sb->eps[]`, and `xhci_get_ep_ctx()`. In contrast, `ctrl_ctx` `add_flags`/`drop_flags` and `LAST_CTX()` use 1-based context indices (`ep_index + 1`), and `TRB_TO_EP_ID` / `DB_VALUE` are 1-based (`1..31`) and must be converted to `ep_index` and validated via `xhci_get_virt_ep()`. [F89, F90]
- Stream ID 0 is reserved: `xhci_virt_ep_to_ring()` uses `ep->ring` when `!(ep->ep_state & EP_HAS_STREAMS)`, and when `EP_HAS_STREAMS` is set requires `ep->stream_info != NULL` and `stream_id` in `1 .. num_streams - 1`. Hardware port IDs (`GET_PORT_ID`), `udev->portnum`, `wIndex`, and `xhci_find_raw_port_number()` (`rhub->ports[port1 - 1]->hw_portnum + 1`) are 1-based, whereas `xhci->hw_ports[]` and `rhub->ports[]` are 0-based. [F53, F92, F93, F184]
- In `xhci_configure_endpoint()`, under `XHCI_EP_LIMIT_QUIRK`, `xhci_reserve_host_resources()` adds endpoints before command submission; on error `xhci_free_host_resources()` subtracts them, and only on success does `xhci_finish_resource_reservation()` subtract dropped endpoints. Under `XHCI_SW_BW_CHECKING`, call `xhci_reserve_bandwidth()` only when `!ctx_change`. [F17, F69]
- In `handle_cmd_completion()`, handle `COMP_COMMAND_RING_STOPPED` by returning early after `complete_all(&xhci->cmd_ring_stop_completion)` before `xhci_trb_virt_to_dma()` checks `cmd_dma` or `xhci->cmd_list` is accessed. `xhci_trb_virt_to_dma()` returns `0` when `trb` is outside `seg->trbs[0 .. TRBS_PER_SEGMENT - 1]`, which `trb_in_td()` relies on. [F94, F101]
- In `process_ctrl_td()` on non-halting `TRB_DATA`/`TRB_NORMAL` events, and in `process_isoc_td()` when `td->error_mid_td` is set on `ep_trb != td->end_trb`, set `td->urb_length_set = true` and return before `finish_td()`. In `handle_tx_event()`, when ignoring an event via `xhci_spurious_success_tx_event()`, reset `ep_ring->old_trb_comp_code = 0`. [F65, F111]
- In `xhci_handle_events()`, each `while (unhandled_event_trb(ir->event_ring))` iteration must call `inc_deq()` before breaking on error, and `xhci_handle_event_trb()` must return `-ENODEV` if `XHCI_STATE_DYING` is set after dispatch. In `xhci_update_erst_dequeue()`, skip writing `erst_dequeue` when `(temp_64 & ERST_PTR_MASK) == (deq & ERST_PTR_MASK)` and `!clear_ehb`, and set `ERST_EHB` only when `clear_ehb` is true. [F112, F150]
- When `!xhci_has_one_roothub(xhci)`, `xhci_run()` defers `xhci_run_finished()` until the non-primary HCD, and `xhci_stop()` returns early when `!usb_hcd_is_primary_hcd(hcd)`. `queue_command()` must never decrement `xhci->cmd_ring_reserved_trbs`. When `xhci_setup_device()` reallocates a slot via `xhci_alloc_dev()`, it must call `xhci_setup_addressable_virt_dev()`. [F24, F68, F147]

## Synchronization

- `xhci_irq()` takes `xhci->lock` with `spin_lock()`, so non-IRQ paths must use `spin_lock_irqsave()` / `spin_lock_irq()`. `xhci->mutex` and `sb->mutex` nest outside `xhci->lock`, and callers waiting on `command->completion` or `cmd_ring_stop_completion` must drop `xhci->lock` before `wait_for_completion*()`. [F165, F170, F171]
- `xhci_abort_cmd_ring()` requires `xhci->lock` held; it calls `reinit_completion(&xhci->cmd_ring_stop_completion)` under `xhci->lock` before writing `crcr | CMD_RING_ABORT` and polling `CMD_RING_RUNNING`, drops `xhci->lock` for `wait_for_completion_timeout()`, and re-acquires `xhci->lock` before returning. `xhci_handle_command_timeout()` must verify `xhci->current_cmd && !delayed_work_pending(&xhci->cmd_timer)` under `xhci->lock` before aborting. [F22, F34, F35, F149]
- In `xhci_handle_cmd_disable_slot()` on `COMP_SUCCESS`, clear `xhci->dcbaa->dev_context_ptrs[slot_id]` and `xhci->devs[slot_id]` under `xhci->lock` before waking the waiter, because the xHC may immediately reuse `slot_id`. Callers (`xhci_free_dev()`, `xhci_disable_and_free_slot()`) must save `xhci->devs[slot_id]` before `xhci_disable_slot()` to pass to `xhci_free_virt_device()`. [F25, F26]
- Execute `wmb()` in `queue_trb()` and `inc_enq_past_link()` after writing TRB payload/chain bits and before writing/toggling `TRB_CYCLE`. Execute `rmb()` in `xhci_handle_event_trb()` after `unhandled_event_trb()` observes a matching `TRB_CYCLE` and before reading event TRB fields. [F29, F31]
- In `xhci_urb_dequeue()`, run `usb_hcd_check_unlink_urb()`, `usb_hcd_unlink_urb_from_ep()`, and `td_on_ring(&urb_priv->td[0], ep_ring)` under `xhci->lock`; if `!td_on_ring()`, do not touch `td->td_list` or queue Stop Endpoint, only unlink `td->cancelled_td_list`, and on `err_giveback` drop `xhci->lock` before `usb_hcd_giveback_urb()`. [F14, F36]
- Hold `xhci->lock` across `xhci_run_finished()`. In `tegra_xhci_id_notify()` (atomic notifier), defer sleeping calls and `tegra->lock` to `tegra->id_work`; in Tegra suspend, call `synchronize_irq(tegra->mbox_irq)` before taking `tegra->lock`, and in `tegra_xusb_mbox_thread()` abort under `tegra->lock` if suspended. [F37, F162, F168]

## Object Lifetimes

- When `cmd->completion == NULL`, `queue_command()` transfers `xhci_command` ownership to `xhci->cmd_list` (caller frees on `queue_command()` error). When `cmd->completion != NULL`, the caller retains ownership on all paths. If `command->in_ctx` is a borrowed context (e.g. `virt_dev->in_ctx`), use `kfree(command->completion); kfree(command);` instead of `xhci_free_command()` (which frees `command->in_ctx`). [F1, F2, F3]
- In `xhci_urb_enqueue()`, allocate `urb_priv` with `struct_size(urb_priv, td, num_tds)` and set `urb_priv->num_tds = num_tds` before indexing `urb_priv->td[]`. On failure, call `xhci_urb_free_priv(urb_priv)` and set `urb->hcpriv = NULL` under `xhci->lock`. [F5, F129]
- `xhci_map_temp_buffer()` sets `URB_DMA_MAP_SINGLE` on SG URBs (`urb->num_sgs > 0`), so `xhci_queue_bulk_tx()` and `xhci_unmap_urb_for_dma()` must check `URB_DMA_MAP_SINGLE` even when `urb->num_sgs > 0`, and `xhci_unmap_temp_buf()` must unmap, free, and reset `urb->transfer_buffer = NULL`. [F7, F55, F176]
- `xhci_endpoint_init()` stages `new_ring`; `xhci_check_bandwidth()` frees old `ring`, promotes `new_ring` to `ring`, and clears `new_ring = NULL`, while `xhci_reset_bandwidth()` frees and clears `new_ring = NULL`. Both must call `xhci_zero_in_ctx()`. [F12, F60]
- In `xhci_handle_cmd_set_deq()`, `cleanup:` must always clear `SET_DEQ_PENDING` and `queued_deq_seg`/`queued_deq_ptr` even when `!ep_ring`, and on `COMP_SUCCESS` with `XHCI_CDNS_SCTX_QUIRK` zero `stream_ctx->reserved[0..1]`. All `cancelled_td_list` / `td_list` unlinking loops must use `list_for_each_entry_safe()`, and `xhci_giveback_invalidated_tds()` must stop if `XHCI_STATE_DYING`. [F15, F109, F156]
- `__xhci_sideband_remove_endpoint()` clears `ep->sideband` and `sb->eps[ep->ep_index]` under `sb->mutex`; `xhci_sideband_unregister()` clears `sb->xhci` and `sb->vdev->sideband` under `xhci->lock` before `kfree(sb)`. Call `xhci_sideband_notify_ep_ring_free()` synchronously before freeing an offloaded ring (`evt` is on stack). [F16, F40, F138]
- Under `XHCI_RESET_ON_RESUME`, `xhci_alloc_dev()` calls `pm_runtime_get_noresume()` after allocations succeed, and `xhci_free_dev()` calls `pm_runtime_put_noidle()` before `xhci_check_args()`. In `xhci_shutdown()` and `xhci_suspend()`, clear `HCD_FLAG_POLL_RH` and `timer_delete_sync(&hcd->rh_timer)` on both roothubs before taking `xhci->lock`. In `tegra_xusb_remove()`, `tegra_xusb_deinit_usb_phy()` must cancel `tegra->id_work` before `usb_remove_hcd()`. [F18, F38, F161]

## API Contracts

- `xhci_check_args()` returns `1` for valid non-roothub devices, `0` for roothubs, and `< 0` on error; non-roothub callers (`xhci_urb_enqueue()`, `xhci_check_streams_endpoint()`) must map `0` to `-EINVAL`. `xhci_alloc_dev()` returns `1` on success and `0` on failure. [F44, F45]
- Always use `hcd_to_xhci(hcd)` (`shared_hcd` has no `xhci_hcd`), pass non-NULL `over` to `xhci_init_driver()`, and use `hcd->self.sysdev` (not `controller`) for all DMA calls. `xhci_sideband_get_endpoint_buffer()` and `xhci_sideband_get_event_buffer()` transfer `sg_table` ownership to the caller. In `xhci_td_cleanup()`, force `PIPE_ISOCHRONOUS` URB giveback `status` to `0`. [F6, F135, F173, F177, F182]

## Error Handling

- In `xhci_endpoint_reset()`, get `udev` via `container_of` only for ep0 and `host_ep->hcpriv` otherwise; verify `udev->slot_id` and `vdev` are non-NULL (`vdev->udev == udev` for ep0); modify `ep->ep_state` under `xhci->lock`; and once `EP_SOFT_CLEAR_TOGGLE` is set, every exit path must reach `cleanup:` to clear it under `xhci->lock` and free `stop_cmd`. [F23, F28, F51, F137]
- In `xhci_handle_cmd_stop_ep()` on `COMP_CONTEXT_STATE_ERROR`, `EP_STATE_STOPPED` must not fall through to `EP_STATE_RUNNING` if `EP_HALTED` or `time_is_before_jiffies(ep->stop_time + msecs_to_jiffies(100))`, whereas `EP_STATE_RUNNING` must unconditionally re-queue Stop Endpoint without the 100ms timeout. [F102, F157]
- In `xhci_queue_isoc_tx()`, if TD setup fails at `i > 0`, jump to `cleanup:` to unlink `td[0..i-1]`, call `td_to_noop(&urb_priv->td[0], true)`, restore `ep_ring` enqueue state, and unlink the URB. In `xhci_reserve_bandwidth()` rollback, call `xhci_drop_ep_from_interval_table()` for `EP_IS_ADDED` before restoring `bw_info`, and `xhci_add_ep_to_interval_table()` for `EP_IS_DROPPED` after. [F57, F114]
- `xhci_irq()` returns `IRQ_NONE` only when `!(status & STS_EINT)` (after `status != ~(u32)0`), and `IRQ_HANDLED` on `~(u32)0`, `STS_HCE`, or `STS_FATAL`. Clamp `urb->actual_length = 0` if `remaining > requested` in `process_bulk_intr_td()` and `xhci_td_cleanup()`. In Tegra, check `dev_pm_domain_attach_by_name()` with `IS_ERR()` and reset `tegra->usbphy[i] = NULL` on `IS_ERR()`. [F46, F47, F54, F95]

## External Contracts

- In `tegra_xusb_mbox_send()`, skip claiming `MBOX_OWNER_SW` and polling `MBOX_OWNER_NONE` for `MBOX_CMD_ACK`/`MBOX_CMD_NAK`, and in `tegra_xusb_mbox_thread()`, write `MBOX_OWNER_NONE` only when `!tegra_xusb_mbox_cmd_requires_ack(msg.cmd)`. [F116]

## Known Pitfalls

- In `xhci_enable_interrupter()` and `xhci_disable_interrupter()`, mask off RW1C `IMAN_IP` (`iman &= ~IMAN_IP`), and follow doorbell or `iman` `writel()` calls with a dummy `readl()`. [F143, F144]
- In `handle_cmd_completion()`, read `TRB_RESET_DEV` `slot_id` from `cmd_trb->generic.field[3]` (event `SLOT_ID` is 0). In `xhci_handle_stopped_cmd_ring()`, check `if (cur_cmd)` before `xhci_mod_cmd_timer(xhci)` (`dequeue != enqueue` can hold on a Link TRB). [F49, F91]
- Before `prepare_ring()`, test segment end with `last_trb_on_seg(ep_ring->enq_seg, ep_ring->enqueue + 1)` rather than `trb_is_link()`. On `XHCI_ETRON_HOST`, `xhci_queue_ctrl_tx()` (`speed >= USB_SPEED_SUPER`) must queue `TRB_TR_NOOP` if `last_trb_on_seg(..., ep_ring->enqueue + 1)`, and `xhci_discover_or_reset_device()` must disable/reallocate the slot instead of queuing Reset Device. [F85, F155, F164]
- Do not dereference `vdev->udev` or `vdev->rhub_port` in `xhci_log_free_virt_dev`. `bus_state` `port_c_suspend`/`suspended_ports`/`port_remote_wakeup` are `u32` (not `unsigned long` bitmaps). In `tegra_xusb_probe()`, `dev_get_drvdata(dev)` is `struct tegra_xusb *`. Cast `xhci->cap_regs` to `(void __iomem *)` before adding byte offsets, scale TRB pointer deltas by `sizeof(*trb)`, use `lower_32_bits()`/`upper_32_bits()` for 64-bit addresses, and use `BIT(i)` for 32-bit endpoint flags. [F52, F119, F120, F132, F133, F136, F141, F142]
