# SCHEDULER

The scheduler subsystem implements the Linux scheduling classes (`stop`, `deadline`, `rt`, EEVDF `fair`, `ext`/`sched_ext`, and `idle`), Per-Entity Load Tracking (PELT), SMP/NUMA/EAS load balancing and domain topology, cgroup and autogroup task grouping, CPU isolation, scheduling clocks, scheduler syscalls/debugfs/procfs interfaces, and kernel-wide waitqueue and completion primitives.

## Architecture & Data Flow
- `sched_dl_entity` (when `dl_server(dl_se)` is true, e.g. `rq->fair_server`), `sched_entity` (when `!entity_is_task(se)`, i.e. `se->my_q != NULL`), and `sched_rt_entity` (when `!rt_entity_is_task(rt_se)`) are not embedded in `task_struct`; callers must check these predicates before downcasting via `dl_task_of()`, `task_of()`, or `rt_task_of()`. [F143, F233, F409]
- `rq->leaf_cfs_rq_list` is kept in bottom-up child-before-parent order using `rq->tmp_alone_branch`: `list_add_leaf_cfs_rq()` callers (`enqueue_task_fair()`, `unthrottle_cfs_rq()`) must walk ancestors until it returns true (`rq->tmp_alone_branch == &rq->leaf_cfs_rq_list`); removal must use `list_del_leaf_cfs_rq()` under `for_each_leaf_cfs_rq_safe()` after `cfs_rq_is_decayed()`, and `child_cfs_rq_on_list()` must verify `prev != &rq->leaf_cfs_rq_list` before `container_of()`. [F201, F262, F286, F314]
- In `replenish_dl_new_period()`, `replenish_dl_entity()`, and `dl_entity_overflow()`, static parameters (`dl_runtime`, `dl_deadline`, `dl_period`) must be read from `pi_of(dl_se)` while dynamic `runtime` and `deadline` are updated on `dl_se`; when `update_curr_dl_se()` throttles a `dl_server` and `is_dl_boosted(dl_se)` holds or `start_dl_timer(dl_se)` returns 0, it must call `replenish_dl_new_period()` and `start_dl_timer()` rather than `enqueue_task_dl()`. [F67, F128]
- In `dequeue_rt_stack()`, hierarchical `sched_rt_entity` nodes must be dequeued top-down from root to `rt_se` before `dequeue_top_rt_rq()` because parent `rt_se_prio()` depends on child `rt_rq->highest_prio.curr`; in `inc_rt_prio_smp()`/`dec_rt_prio_smp()`, `cpupri_set()` is called only for top-level `&rq->rt` when `rq->online`. [F423, F424]
- Delayed-dequeued tasks (`se->sched_delayed == 1`) decrement `cfs_rq->h_nr_runnable` via `set_delayed()` while staying in `cfs_rq->h_nr_queued` and `rq->nr_running`; checks for runnable count on `rq` (e.g. `wake_affine_idle()`) must subtract `cfs_h_nr_delayed(rq)` from `rq->nr_running`. [F256]
- Modifying `load_weight::weight` requires zeroing `inv_weight` (as in `update_load_add/sub/set()`) or updating it in lockstep (`reweight_task_fair()`); on `CONFIG_64BIT`, `scale_load_down(w)` clamps any non-zero shifted weight to at least `2UL` (`MIN_SHARES`). [F251, F494]
- In PELT, `___update_load_avg()` divides `*_sum` by `get_pelt_divider(sa)`, `__update_load_avg_se()` calls `cfs_se_util_change()` to clear `UTIL_AVG_UNCHANGED` (MSB `0x80000000` of `util_est`), and `dequeue_load_avg()`/`update_cfs_rq_load_avg()` clamp `cfs_rq->avg` sums via `sub_positive()`/`add_positive()` to at least `*_avg * PELT_MIN_DIVIDER`. [F307, F440, F643]
- `place_entity()` and `update_deadline()` must overwrite `se->slice` with `sysctl_sched_base_slice` only when `!se->custom_slice`; in `__pick_eevdf()`, traversal must check `node->rb_left` with `vruntime_eligible(cfs_rq, __node_2_se(left)->min_vruntime)` and descend left before testing `entity_eligible(cfs_rq, se)`. [F270, F284]
- `p->sched_throttle_work` and `p->numa_work` use a self-pointing `work.next == &work` unqueued sentinel that must be initialized and restored in `init_cfs_throttle_work()`, `throttle_cfs_rq_work()`, `init_numa_balancing()`, and `task_numa_work()`; in `throttle_cfs_rq_work()`, `dequeue_task_fair(rq, p, DEQUEUE_SLEEP | DEQUEUE_THROTTLE)` must run after resetting `next` and before setting `p->throttled = true`. [F246, F266, F271]

## Synchronization
- `rq_clock()`, `rq_clock_task()`, and `rq_clock_pelt()` require `rq->__lock` held and `update_rq_clock(rq)` called since `rq_pin_lock()`; temporary lock drops or cross-CPU balance calls (`push_dl_task()`, `pull_dl_task()`, `dl_task_offline_migration()`, `pull_rt_task()`) must pair `rq_unpin_lock(rq, rf)` (saving `RQCF_UPDATED` and invalidating `SCX_RQ_CLK_VALID`) with `rq_repin_lock(rq, rf)` (never `rq_pin_lock()`), while `double_rq_lock()`/`double_lock_balance()` clear `RQCF_UPDATED` via `double_rq_clock_clear_update()`. [F25, F176, F375, F388, F446]
- In CFS bandwidth control, `rq->__lock` nests outside `cfs_b->lock` (`do_sched_cfs_period_timer()` and `do_sched_cfs_slack_timer()` must release `cfs_b->lock` before `distribute_cfs_runtime()`, while `runtime_refresh_within()` and `start_cfs_slack_bandwidth()` require `cfs_b->lock` held); in RT bandwidth control, `rq->__lock` nests outside `rt_b->rt_runtime_lock`, which nests outside `rt_rq->rt_runtime_lock`. [F327, F330, F520]
- Accessing root-domain DL bandwidth (`dl_bw_of()`, `dl_bw_cpus()`, `__dl_update()`) requires an RCU-sched read section and mutating `dl_b->total_bw`, `dl_b->bw`, or `rq->dl.extra_bw` requires `dl_b->lock`; `sched_dl_global_validate()`, `sched_dl_do_global()`, and `dl_bw_visited()` additionally require `sched_domains_mutex`. [F23, F24]
- In `__sched_setscheduler()`, blocking calls (`uclamp_validate()`, `cpuset_lock()` when `dl_policy(policy) || dl_policy(p->policy)`) must happen before `task_rq_lock(p, &rf)`, `p->policy` must be rechecked if `oldpolicy != -1` (unlocking `cpuset_unlock()` on all retry/exit paths), and on exit preemption is disabled before `splice_balance_callbacks(rq)` and `task_rq_unlock()`, running `rt_mutex_adjust_pi(p)` and `balance_callbacks()` before `preempt_enable()`. [F368, F399, F400]
- Whenever `double_lock_balance()` in `find_lock_later_rq()`/`push_dl_task()` or `find_lock_lowest_rq()`/`push_rt_task()` may drop `rq->__lock`, callers must pin `next_task` with `get_task_struct()` beforehand (calling `put_task_struct(next_task)` if retrying with a different task) and revalidate `!is_migration_disabled(task)`, `task->cpus_mask`, and `pick_next_pushable_{dl_}task(rq)`; if queueing `push_cpu_stop` via `stop_one_cpu_nowait()`, both `this_rq` and `src_rq` locks must be dropped with preemption disabled (after `get_push_task()` in RT). [F6, F22, F177, F366, F395, F396, F517]
- Pushable task queue updates (`enqueue/dequeue_pushable_dl_task()`, `enqueue/dequeue_pushable_task()`, and `set_next_task_rt()`) must keep `earliest_dl.next` / `highest_prio.next`, `overloaded`, `dlo_mask` / `rto_mask`, and `dlo_count` / `rto_count` in lockstep, with `cpumask_set_cpu()` ordered by `smp_wmb()` before `atomic_inc()` in `dl_set_overload()`/`rt_set_overload()`, paired with `smp_rmb()` in `pull_dl_task()`/`pull_rt_task()`. [F20, F69, F394, F425]
- Lockless 64-bit accesses to `cfs_rq->avg.last_update_time`, `rq->clock_idle`, `rq->clock_pelt_idle`, and `cfs_rq->throttled_pelt_idle` must use `u64_u32_load/store[_copy]()` with their `*_copy` shadow fields; `_update_idle_rq_clock_pelt()` orders `clock_idle` before `clock_pelt_idle` with `smp_wmb()`, paired with `smp_rmb()` in `migrate_se_pelt_lag()`. [F261, F343, F387]
- Waitqueue signaling: `prepare_to_wait*()` must call `set_current_state()` after adding `wq_entry` to `wq_head` (and unserialized wait loops must use `set_current_state()`, not `__set_current_state()`); lockless `waitqueue_active()` / `wq_has_single_sleeper()` checks on wakeup paths (including `wake_up_bit()` and `wake_up_var()`) require `smp_mb()` or `smp_mb__after_atomic()` after updating the condition; on pending signal in `prepare_to_wait_event()`/`prepare_to_swait_event()`, the entry must be unlinked under the queue lock before returning `-ERESTARTSYS`. [F381, F382, F385, F578, F579]

## Object Lifetimes
- For `dl_se->dl_timer` and `dl_se->inactive_timer`, `get_task_struct(dl_task_of(dl_se))` is taken only when `!dl_server(dl_se)` and `!hrtimer_is_queued(timer)`, `put_task_struct()` on cancel is called only when `hrtimer_try_to_cancel()` returns `1` and `!dl_server(dl_se)`, and in `dl_task_timer()`/`inactive_task_timer()`, `put_task_struct(p)` must be called only after `task_rq_unlock()` with no subsequent dereference of `p` or `timer`. [F2, F3]
- Every task detached by `detach_tasks(&env)` or `detach_one_task(&env)` (after `deactivate_task()` sets `TASK_ON_RQ_MIGRATING` and `set_task_cpu()` under `src_rq->__lock`) must be attached via `attach_tasks(&env)` or `attach_one_task()` under `dst_rq` lock; `active_load_balance_cpu_stop()` must only be queued when `busiest->active_balance` transitions from 0 to 1 under `busiest->__lock` and must clear `busiest_rq->active_balance = 0` under `busiest_rq` lock on every exit path. [F195, F196, F225, F226]
- `__block_task(rq, p)` ends with `smp_store_release(&p->on_rq, 0)`; callers must not dereference `p` afterwards without holding `p->pi_lock` or a task refcount, even while still holding `rq->__lock`. [F391]
- Dereferencing `p->numa_group` via `deref_task_numa_group()` requires `p == current`, `rcu_read_lock()`, or `task_rq(p)->__lock` while `!READ_ONCE(p->on_cpu)`; `task_numa_group()` must pin `grp` under `rcu_read_lock()`, transfer faults/`nr_tasks` under `double_lock_irq(&my_grp->lock, &grp->lock)`, and call `put_numa_group(my_grp)`; `task_numa_free(p, final)` must subtract `p`'s faults under `grp->lock` before clearing `p->numa_group` and only `kfree(p->numa_faults)` when `final` is true; `task_numa_assign()`/`task_numa_migrate()` must clear `rq->numa_migrate_on = 0` and `put_task_struct(env.best_task)`. [F202, F203, F212, F244]
- `finish_wait()` and `finish_swait()` rely on `!list_empty_careful()` paired with `list_del_init_careful()` in `autoremove_wake_function()`; in `__wait_on_bit_lock()`, when `action` returns non-zero, `finish_wait()` must be called before `test_and_set_bit()`; in `completion_done()`, `x->wait.lock` must be acquired and released after observing `READ_ONCE(x->done) != 0` before returning `true`, and `do_wait_for_common()` must recheck `x->done` and call `__finish_swait()` under `x->wait.lock` on all exits. [F374, F383, F550, F551, F577]

## API Contracts
- `task_tick_fair()`, `task_tick_idle()`, `task_tick_rt()`, and `task_tick_stop()` can be invoked remotely from the `nohz_full` tick offload CPU and must access all state via their `@rq` and `@curr`/`@p` arguments, never `this_rq()`, `smp_processor_id()`, or `current`. [F326, F522]
- In `update_curr_dl_se()` and `dl_server_update_idle_time()`, runtime accounting for `dl_server(dl_se)` entities must subtract raw unscaled `delta_exec` rather than calling `dl_scaled_delta_exec()`. [F43]
- `util_fits_cpu()` returns `1` (full fit), `0` (capacity fails), or `-1` (capacity fits but `uclamp_min` exceeds `get_actual_cpu_capacity(cpu)`), so full-fit callers must check `> 0`; `__select_idle_cpu()`, `select_idle_core/smt/cpu/capacity()`, `find_energy_efficient_cpu()`, `find_new_ilb()`, and `find_lowest_rq()` return `-1` on failure, whereas `wake_affine_idle/weight()` and `sched_numa_find_nth_cpu()` return `nr_cpumask_bits`/`nr_cpu_ids`. [F236, F239, F403, F405]
- `select_task_rq_fair()` requires `p->pi_lock` held, and `select_idle_sibling/cpu/capacity()` and `find_energy_efficient_cpu()` require IRQs disabled and `rcu_read_lock()`; `cpufreq_update_util(rq, flags)` requires `cpu_of(rq)`, RCU-sched read lock, `rq->__lock`, and updated `rq` clock; `idle_get_state(rq)`, `walk_tg_tree()`, `for_each_rt_rq()`, and `sched_numa_hop_mask()` (which returns `ERR_PTR` or `NULL`, requiring `IS_ERR_OR_NULL()` checks) require `rcu_read_lock()`. [F336, F404, F524, F525, F526, F527]
- `swake_up_all()` unconditionally enables local IRQs via `raw_spin_unlock_irq(&q->lock)` after splicing `q->task_list` to a local list (callers in hardirq/IRQ-disabled context must use `swake_up_all_locked()`), and `complete_all()` must not be called from hardirq/NMI context on `CONFIG_PREEMPT_RT` (nor can `completion_done()` detect active waiters after `complete_all()` sets `x->done = UINT_MAX`). [F380, F471, F586, F684]

## Error Handling
- `start_dl_timer()` returns `0` when the activation time is already in the past and `1` when armed, so throttling callers must check `!start_dl_timer(dl_se)` and immediately replenish or re-enqueue on `0`. [F44]
- Prevent division by zero: `task_non_contending()` must return early if `dl_se->dl_runtime == 0`, `__dl_server_attach_root()` if `!dl_bw_cpus(cpu)`, `proc_sched_show_task()` must check `nr_switches` and `p->se.nr_migrations` before `div64_ul()`/`div64_u64()`, `update_cfs_rq_h_load()`/`task_h_load()` divide by `cfs_rq_load_avg(cfs_rq) + 1`, and `numa_get_avg_runtime()`/`task_numa_placement()` clamp `(s64)*period < 0` to `0` and add `1` to `period` and `total_faults`. [F135, F142, F311, F312]

## External Contracts
- `sched_copy_attr()` must `memset(attr, 0, sizeof(*attr))`, map `uattr->size == 0` to `SCHED_ATTR_SIZE_VER0`, write `sizeof(*attr)` back to `uattr->size` and return `-E2BIG` on size errors, and require `uattr->size >= SCHED_ATTR_SIZE_VER1` when `SCHED_FLAG_UTIL_CLAMP` is set; any new `SCHED_FLAG_*` must be added to `SCHED_FLAG_ALL`, `__sched_setscheduler()` must reject `SCHED_FLAG_SUGOV` and negative `policy` values from userspace, and `sys_sched_getattr()`/`sys_sched_getparam()` must zero-initialize stack structs, mask `kattr.sched_flags &= SCHED_FLAG_ALL`, and copy to userspace outside `rcu`/`task_rq_lock` guards. [F413, F414, F415, F449, F450, F528, F689]

## Known Pitfalls
- Unsigned underflow/overflow: `grub_reclaim()` must check `u_inact + rq->dl.extra_bw > rq->dl.max_bw - dl_se->dl_bw` before subtracting; `__sub_running_bw()` and `__sub_rq_bw()` must clamp to `0` if the new `u64` value exceeds `old`; `___update_load_sum()` must check `(s64)delta < 0` before `delta >>= 10` and advance `last_update_time` by `delta << 10`; `decay_load(val, n)` must return `0` when `n > LOAD_AVG_PERIOD * 63` before truncating `n` to `unsigned int`; `nsec_high()`/`nsec_low()` must negate negative `(long long)nsec` before `do_div()`. [F133, F134, F141, F458, F489]
- In `__wake_up_common()`, `curr->flags` must be read before calling `curr->func` while iterating with `list_for_each_entry_safe_from()`; because `bit_waitqueue()` and `__var_waitqueue()` share `bit_wait_table`, `wake_bit_function()` and `var_wake_function()` must match both `key.flags` and `key.bit_nr` (`-1` for var waiters, which must never call `test_bit()`). [F443, F469, F509]
- `task_numa_fault()` must return early if `!current->mm`, and sizes `p->numa_faults` to `NR_NUMA_HINT_FAULT_BUCKETS * nr_node_ids` whereas `grp->faults[]` has `NR_NUMA_HINT_FAULT_STATS * nr_node_ids` elements (never index `grp->faults[]` with `NUMA_MEMBUF`/`NUMA_CPUBUF`). [F317, F357]
