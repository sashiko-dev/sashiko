# FIREWIRE SUBSYSTEM

The FireWire (IEEE 1394) subsystem provides core bus management, topology tracking, Config ROM parsing, asynchronous and isochronous DMA transactions (`firewire-core`), the `/dev/fw*` character device UAPI, the PCI 1394 OHCI controller driver (`firewire-ohci`), IPv4/IPv6 networking over 1394 (`firewire-net`), the SBP-2 SCSI storage initiator (`firewire-sbp2`), and the TI PCILynx sniffer (`nosy`).

## Architecture & Data Flow

- Both `struct fw_device` and `struct fw_unit` sit on `fw_bus_type` with distinct `dev->type` (`&fw_device_type` vs `&fw_unit_type`), so callbacks taking `struct device *` (`fw_unit_match()`, `show_immediate()`, `show_text_leaf()`, `update_unit()`, `compare_configuration_rom()`) must check `is_fw_unit()` or `is_fw_device()` before downcasting. [F45]
- In `core-cdev.c`, `client->resource_xa` stores heterogeneous `struct client_resource` objects discriminated by `resource->release`, which must be verified before downcasting with `to_*_resource()`. Every event queued via `queue_event()` must embed `struct event` at offset 0 because `queue_event()`, `dequeue_event()`, and `fw_device_op_release()` pass `struct event *` directly to `kfree()`. [F46, F127]
- `struct fw_transaction` completion paths (`close_transaction()`, `split_transaction_timeout_callback()`, `fw_core_handle_response()`, `__fw_send_request()`) must branch on `t->with_tstamp` to invoke `t->callback.without_tstamp` or `with_tstamp`; in `core-cdev.c`, `complete_transaction()` and `outbound_phy_packet_callback()` must switch on `.without_tstamp.type` to access the union's active event struct. [F47, F48]
- In `ohci.c`, `struct descriptor_buffer` tracks `buffer_size` and `used` in bytes while `desc->buffer` is a typed `struct descriptor` array, so pointer offsets divide by `sizeof(*d)` and byte/DMA calculations multiply by `sizeof(*d)`. `context_add_buffer()` offsets `desc->buffer_bus` by `(void *)&desc->buffer - (void *)desc` and reserves `0x10` trailing bytes, which `context_release()` must subtract before `dmam_free_coherent()`. [F135, F136]
- `context_append()` must advance `ctx->buffer_tail->used` by `(z + extra) * sizeof(*d)` and update `ctx->prev` and `ctx->prev_z`. In `context_retire_descriptors()`, `ctx->current_bus = address` must be updated before calling `ctx->callback(ctx, d, last)`, and `old_desc` is only reset (`used = 0`), moved to `ctx->buffer_list` tail, and `ctx->last` updated to `last` if `ctx->callback()` returns non-zero. [F72, F113]
- In `fwnet_incoming_packet()`, the driver must verify `len > RFC2374_FRAG_HDR_SIZE` and `fg_off + len <= dg_size`, discard any existing `fwnet_partial_datagram` if `pd->datagram_size != dg_size` or `fwnet_frag_overlap(pd, fg_off, len)` is true, and adjust `peer->pdg_size` in lockstep under `dev->lock` on every `fwnet_pd_new()` and `fwnet_pd_delete()`. [F79, F96]
- In `sbp2.c`, `struct sbp2_orb base` must remain at offset 0 of `struct sbp2_management_orb` and `struct sbp2_command_orb` for `free_orb()`, and `struct sbp2_target` must reside at `shost->hostdata[0]` of `struct Scsi_Host` for `container_of` downcasts. In `sbp2_status_write()`, the `lu->orb_list` search must save a match in a separate `orb` pointer (initialized to `NULL`) rather than dereferencing the loop cursor `iter` after the loop. [F261, F278, F279]

## Synchronization

- `__fw_send_request()` can run in atomic context and synchronously invokes `handle_local_request()` -> `fw_core_handle_request()` -> `fw_address_callback_t` for local destinations, so inbound request paths (`allocate_request()`, `handle_fcp_region_request()`, `handle_request()`, `fwnet_receive_packet()`) must not sleep and must use `GFP_ATOMIC`. `card->transactions.lock`, `card->split_timeout.lock`, `card->topology_map.lock`, and `phy_receiver_list_lock` must use `spin_lock_irqsave`. [F155, F156]
- `ohci->lock` (`fw_ohci.lock`) is acquired in hardirq context (`irq_handler()`), so non-hardirq callers must use `spin_lock_irq`/`spin_lock_irqsave`, and no code may invoke `packet->callback` or `fw_core_handle_*()` while holding `ohci->lock`. Isochronous callbacks (`iso_callback`, `iso_mc_callback`) allocate with `GFP_KERNEL` and must only run in process/workqueue context, never in IRQ context or under spinlocks. [F159, F160]
- `read_phy_reg()`, `write_phy_reg()`, `update_phy_reg()`, and `read_paged_phy_reg()` in `ohci.c` sleep via `msleep(1)` and require holding `ohci->phy_reg_mutex` (via `ohci_read_phy_reg()` or `ohci_update_phy_reg()`), except during serialized `ohci_enable()`. [F161]
- Writers updating `node_id` and `generation` on `struct fw_card`, `struct fw_device`, or `sbp2` (`tgt->node_id`/`tgt->address_high` and `lu->generation` in `sbp2_login()`/`sbp2_reconnect()`) must write `node_id` (and `address_high`) before `smp_wmb()` and `generation`; lockless readers (including `sbp2_scsi_queuecommand()`, `sbp2_login()`, `sbp2_reconnect()`, `sbp2_remove()`) must read `generation` before `smp_rmb()` and `node_id`, and management ORB callers must pass `device->node_id` rather than `tgt->node_id`. [F22, F214, F266]
- In `handle_selfid_complete_event()`, `ohci->self_id[0]` must be read before `rmb()`, followed by copying `ohci->self_id[]` to `ohci->self_id_buffer[]`, a second `rmb()`, and verifying `OHCI1394_SelfIDCount` still reports the same generation. Before dropping `ohci->lock` to call `at_context_flush()`, `ohci->generation` must be set to `-1` and both AT contexts stopped; only after flushing may `ohci->generation = generation` be set and `OHCI1394_busReset` cleared in `OHCI1394_IntEventClear`. [F25, F73]
- When linking DMA descriptors in `ar_context_link_page()` (`branch_address &= cpu_to_le32(~0xf)`, `res_count = cpu_to_le16(PAGE_SIZE)`, `transfer_status = 0`) and `context_append()`, all descriptor fields must be written before `wmb()` and setting the previous descriptor's `branch_address`. In `ar_search_last_active_buffer()`, `READ_ONCE()` reads of `res_count` across consecutive descriptors must be separated by `rmb()`, with a final `rmb()` before reading DMA buffer data. [F27, F28, F71]
- `fw_iso_context_flush_completions()`, `fw_iso_context_stop()`, `at_context_flush()`, and `ohci_cancel_packet()` must check `current_work() == &ctx->work` and return early before calling `disable_work_sync(&ctx->work)` or `cancel_work_sync(&ctx->work)`. [F29]
- `sbp2_target.lock` (`tgt->lock`) must be acquired with `spin_lock_irqsave` or `spin_lock_irq`. `sbp2_status_write()` and `complete_transaction()` must hold `lu->tgt->lock` while updating `orb->rcode` and unlinking `orb->link`, and must release it before calling `orb->callback`. `sbp2_conditionally_block()` must call `scsi_block_requests(shost)` under `tgt->lock` when `++tgt->blocked == 1`, whereas `sbp2_conditionally_unblock()` and `sbp2_unblock()` must call `scsi_unblock_requests(shost)` after releasing `tgt->lock`. [F199, F207, F306]

## Object Lifetimes

- A `struct fw_device` does not call `device_initialize(&device->device)` until `fw_device_init()` finishes reading the Config ROM, so early failure paths must call `fw_device_release(&device->device)` directly rather than `put_device()`. On the rediscovery (`reused`) path, `fw_device_init()` must swap `device->node` and `reused->node` via `fw_node_set_device()` under `card->lock` before calling `fw_device_release(&device->device)`. [F5, F6]
- Because `fw_unit.directory` points into `device->config_rom`, `fw_device_refresh()` must unregister all child `fw_unit` devices via `shutdown_unit()` before `read_config_rom()` replaces and frees `old_rom` under `down_write(&fw_device_rwsem)`. Readers outside `fw_unit` lifetime (sysfs, `ioctl_get_info()`, `compare_configuration_rom()`) must hold `fw_device_rwsem`. [F34, F63, F218]
- In `fw_card_add()`, `card->isoc_wq` and `card->async_wq` (managed by `__free(workqueue_destroy)`) must be assigned before `card->driver->enable()`, reset to `NULL` if `enable()` fails, and passed to `retain_and_null_ptr()` on success. In `fw_core_remove_card()`, `card` must be unlinked from `card_list` under `card_mutex` before binding `dummy_driver` (preserving `free_iso_context` and `stop_iso`), and `isoc_wq`/`async_wq` destroyed only after `fw_destroy_nodes()`, `fw_card_put()`, and `wait_for_completion(&card->done)`. [F7, F8, F139]
- `fw_schedule_bus_reset()`, `fw_schedule_bm_work()`, and `schedule_iso_resource()` take a reference (`fw_card_get()` or `client_get()`) before queueing delayed work and drop it immediately if queueing returns `false`; `br_work()` reuses its reference when postponing and drops it only when work finishes or re-queueing returns `false`. [F9]
- `handle_exclusive_region_request()` and `handle_fcp_region_request()` must pin `handler->kref` inside `rcu_read_lock()` and invoke `handler->address_callback` outside RCU, while `fw_core_remove_address_handler()` calls `list_del_rcu()`, `synchronize_rcu()`, and `wait_for_completion(&handler->done)`. In `handle_fcp_region_request()`, `handlers` starts at `buffer_on_kernel_stack`, so `krealloc_array()` must receive `NULL` on the first overflow and `kfree(handlers)` must only run if `handlers != buffer_on_kernel_stack`. [F30, F134]
- Coherent DMA buffers allocated with `dmam_alloc_coherent()` in `ohci.c` (`descriptor_buffer` pages and Config ROM buffers) must be freed with `dmam_free_coherent()`, not `dma_free_coherent()`. In `handle_selfid_complete_event()`, `ohci->config_rom` must only be scheduled for `dmam_free_coherent()` when `ohci->next_config_rom != ohci->config_rom` because `ohci_enable()` aliases them on resume (`config_rom == NULL`). [F16, F49, F142]
- Because `fw_send_request()` can complete synchronously, `fwnet_send_packet()`, `fwnet_transmit_packet_done()`, and `fwnet_transmit_packet_failed()` coordinate `ptask` lifetime under `dev->lock` via `ptask->outstanding_pkts` and `ptask->enqueued`, calling `dec_queued_datagrams()` and `fwnet_free_ptask()` only when the last user finishes. In `fwnet_incoming_packet()`, `skb = skb_get(pd->skb)` must be called before `fwnet_pd_delete(pd)` when `fwnet_pd_is_complete(pd)` is true. [F19, F20]
- Before calling `fw_send_request()`, `sbp2_send_orb()` must set `orb->lu`, append `orb->link` to `lu->orb_list` under `lu->tgt->lock`, and take two `kref_get(&orb->kref)` references. Only the path that unlinks `orb` from `lu->orb_list` (`sbp2_status_write()` setting `RCODE_COMPLETE`, `complete_transaction()` when `orb->rcode != RCODE_COMPLETE`, or `sbp2_cancel_orbs()` when `fw_cancel_transaction() != 0`) may call `orb->callback` and drop that `kref`. `sbp2_cancel_orbs()` must splice `lu->orb_list` under `lu->tgt->lock` and iterate with `list_for_each_entry_safe`. [F193, F208, F221, F262]
- In `sbp2_send_management_orb()`, after `wait_for_completion_timeout()`, `sbp2_cancel_orbs(lu)` must be called before unmapping `orb->base.request_bus` and `orb->response_bus` and dropping `orb->base.kref`. In `sbp2_map_scatterlist()`, `orb->page_table_bus` is mapped and `COMMAND_ORB_PAGE_TABLE_PRESENT` set only when `scsi_dma_map()` returns `n > 1`; `sbp2_unmap_scatterlist()` must check `COMMAND_ORB_PAGE_TABLE_PRESENT` before unmapping `orb->page_table_bus`. [F196, F209]

## API Contracts

- When `release_client_resource()` is called with a non-NULL `return_resource`, it erases the handle from `client->resource_xa` and drops the XArray's `client` reference, but skips `resource->release()` and transfers ownership of the resource and its inner references (e.g. `r->request` and `r->card` in `ioctl_send_response()`) to the caller. `ioctl_send_response()` must reject any non-FCP response where `a->length != fw_get_response_length(r->request)` before copying `a->data` into `r->data`. [F3, F94]
- Callers of `__fw_send_request()`, `fw_send_request()`, `fw_send_request_with_tstamp()`, and `fw_run_transaction()` must: pass an extended lock tcode (`TCODE_LOCK_MASK_SWAP`..`TCODE_LOCK_VENDOR_DEPENDENT`, not `TCODE_LOCK_REQUEST`); encode stream headers into `destination_id` via `fw_stream_packet_destination_id()` for `TCODE_STREAM_DATA`; pass at least 4 valid bytes in `payload` for `TCODE_WRITE_QUADLET_REQUEST`; pass a streaming-DMA-mappable buffer (not stack/vmalloc) valid until callback completion when `length > 8` to a non-local node; and allow the callback to run synchronously without retaining its `data` pointer. [F53, F54, F55, F168, F217]
- `fw_iso_resource_manage()` returns `void`, sets `*channel` to `0..63` or a negative errno, and overwrites `*bandwidth` with `0` if no bandwidth was changed; if `allocate` is true, `c >= 0`, and `manage_bandwidth()` fails (`ret < 0`), it must roll back via `deallocate_channel()` and set `*channel = ret`. [F14, F43]
- `context_append(ctx, d, z, extra)` in `ohci.c` requires `z` to be the hardware-executed descriptor count encoded into the low 4 bits of `branch_address` (`d_bus | z`) and `extra` to be trailing out-of-line descriptor slots (`driver_data` or `header_z`). [F57]
- Every `sbp2_orb.callback` (`complete_management_orb()`, `complete_command_orb()`) must handle `status == NULL` (passed when aborted by `complete_transaction()` or `sbp2_cancel_orbs()`). Any non-NULL `response` buffer passed to `sbp2_send_management_orb()` must be at least `sizeof(orb->response)` (16 bytes). [F223, F280]

## Error Handling

- `fw_run_transaction()`, `read_rom()`, `reread_config_rom()`, and `read_config_rom()` return `RCODE_COMPLETE` (`0`) on success and positive `RCODE_*` constants (or negative errnos in `read_config_rom()`) on failure, so callers (`fw_device_init()`, `fw_device_refresh()`) must check `!= RCODE_COMPLETE` rather than `< 0`. [F42]
- In `ohci.c`, `read_phy_reg()`, `write_phy_reg()`, `update_phy_reg()`, and `read_paged_phy_reg()` return negative errnos (`-ENODEV`, `-EBUSY`) on failure, so callers (`detect_initiated_reset()`, `get_status_for_port()`) must store the result in a signed `int` and check `< 0` before bitmasking or converting to `bool`. `fw_card_read_cycle_time()` returns `-ENODEV` without modifying `*cycle_time` when `read_csr == dummy_read_csr`, so callers must zero-initialize the target `u32` variable. [F39, F51]
- `sbp2_cancel_orbs()` returns `0` when at least one pending ORB was still on `lu->orb_list` and had to be canceled (timeout), and `-ENOENT` when `lu->orb_list` was already empty (normal completion). In `sbp2_login()`, the `out_logout_login` error path must reset `lu->workfn = sbp2_login` when failing after setting `lu->workfn = sbp2_reconnect`. [F220, F237]

## External Contracts

- `dispatch_ioctl()` in `core-cdev.c` must validate `_IOC_SIZE(cmd) <= sizeof(union ioctl_arg)` and `memset(&buffer, 0, sizeof(buffer))` before `copy_from_user()`. All `__u64` user pointers must use `u64_to_uptr()`/`uptr_to_u64()`, and `ioctl_get_info()` must copy exactly 36 bytes (not `sizeof(struct fw_cdev_event_bus_reset)`, which is 40 on 64-bit) to `a->bus_reset` for 32-bit compat callers. [F186, F187]
- `fw_iso_resource_manage()` and `deallocate_channel()` split 64-bit `channels_mask` into `CSR_CHANNELS_AVAILABLE_HI` (`0..31`) and `LO` (`32..63`), and `manage_channel()` maps channel `0..31` to `cpu_to_be32(1 << (31 - channel))`; all 64-bit channel mask shifts (`ohci->ir_context_channels`, `r->channels`, `channels_mask`) must use `1ULL << channel`. [F118, F119]

## Known Pitfalls

- Because `fw_csr_iterator_next()` post-increments `ci->p`, callers resolving a relative quadlet offset `value` from the current directory entry (`search_directory()`, `search_leaf()`, `units_show()`, `create_units()`) must compute `ci.p - 1 + value`. [F85]
- During `update_tree()`, because each temporary `node1` from `build_tree()` is freed by `fw_node_put(node1)`, `next1 = fw_node(node1->link.next)` must be saved before `fw_node_put(node1)`, `card->root_node` and `card->irm_node` must be repointed from `node1` to `node0`, and `move_tree()` must update the moved child's parent port pointer from `node1` to `node0`. [F61, F104]
- Because `RCODE_COMPLETE` is `0`, `sbp2_scsi_queuecommand()` must initialize `orb->base.rcode = -1` on zero-allocated command ORBs before `sbp2_send_orb()`. When `sbp2_reconnect()` falls back to `lu->workfn = sbp2_login` or `sbp2_update()` schedules `lu->work`, `lu->retries` must be reset to `0`. [F222, F264]
