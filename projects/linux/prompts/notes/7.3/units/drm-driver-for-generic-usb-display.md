# DRM DRIVER FOR GENERIC USB DISPLAY

The GUD (Generic USB Display) driver implements a DRM/KMS display driver for USB-connected displays using the vendor-specific USB control and bulk protocol defined in `include/drm/gud.h`. It probes device descriptors, supported pixel formats, properties, and connectors over USB control transfers, and flushes damaged framebuffer rectangles (with optional pixel format conversion and LZ4 compression) over USB bulk transfers either synchronously or via an asynchronous workqueue.

## Architecture & Data Flow

- `gud_alloc_bulk_buffer()` must allocate `gdrm->bulk_buf` with `vmalloc_32()` rather than `vmalloc()` so backing pages extracted via `vmalloc_to_page()` for `gdrm->bulk_sgt` are guaranteed to be in 32-bit addressable (non-highmem) memory for `usb_sg_init()` in `gud_usb_bulk()`. [F99]
- `gdrm->compress_buf` and `gdrm->lz4_comp_mem` are allocated in `gud_probe()` only when `gdrm->compression & GUD_COMPRESSION_LZ4` is set and remain `NULL` otherwise; `gud_prep_flush()` must only dereference them when compression is enabled. When `LZ4_compress_default()` fails (`complen <= 0`), the `retry` path in `gud_prep_flush()` must clear local `compression = 0`, rebind `buf` and `dst` to `gdrm->bulk_buf`, and re-populate `gdrm->bulk_buf` and `req` with uncompressed data. [F27, F39]
- In `gud_flush_work()`, `shadow_map` is initialized from `gdrm->shadow_buf` under `gdrm->damage_lock`, and `gud_flush_work()` must check that the snapshot of `gdrm->fb` is non-NULL before passing `shadow_map` to `gud_flush_damage()` because `gdrm->shadow_buf` can be `NULL` when `gdrm->fb` is `NULL`. [F28]
- Whenever `gdrm->fb` is consumed and cleared in `gud_flush_work()` (or reset in `gud_plane_atomic_update()`), `gdrm->damage` must be reset via `gud_clear_damage(gdrm)` (`x1 = y1 = INT_MAX`, `x2 = y2 = 0`) under `gdrm->damage_lock`. Broken by: zeroing `gdrm->damage` with `memset()`. [F37]
- When `GUD_DISPLAY_FLAG_FULL_UPDATE` is set in `gdrm->flags`, `gud_flush_rect()` skips `GUD_REQ_SET_BUFFER` unless `gdrm->prev_flush_failed` is true, and `gud_flush_damage()` must set `gdrm->prev_flush_failed = true` whenever `gud_flush_rect()` returns an error. [F44]
- When splitting a damage rectangle in `gud_flush_damage()`, `lines` must use truncating division (`gdrm->bulk_len / pitch`) while the chunk loop bound must use ceiling division `DIV_ROUND_UP(drm_rect_height(damage), lines)` with `rect.y2` clamped to `damage->y2`. [F70]
- In `gud_xrgb8888_to_r124()` and `gud_xrgb8888_to_color()`, `rect->x1` must be aligned down to `block_width` before computing `width` and `len`, and `format` must have `char_per_block[0] == 1` with `block_width` dividing 8 so `bits_per_pixel = 8 / block_width` and `pixshift` stay within `0..7`. [F71]
- In `gud_probe()`, internal transfer formats `GUD_DRM_FORMAT_R1` and `GUD_DRM_FORMAT_XRGB1111` must update `xrgb8888_emulation_format` and `max_buffer_size` in the format discovery loop, then `continue` before appending to `formats[num_formats++]` so they are never exposed as DRM plane formats. The `formats` array passed to `drm_universal_plane_init()` must be allocated with capacity `GUD_FORMATS_MAX_NUM + 1` to reserve a slot for appending emulated `DRM_FORMAT_XRGB8888`. [F49, F62]
- Every pixel format added to `gud_to_fourcc()` and `gud_from_fourcc()` that can be selected as `xrgb8888_emulation_format` in `gud_probe()` must have a corresponding XRGB8888 conversion branch in `gud_prep_flush()` (and in `gud_xrgb8888_to_color()` for sub-byte color formats). [F42]
- Any change to plane or connector state serialized into `struct gud_state_req` must set `crtc_state->mode_changed = true` (in `gud_plane_atomic_check()`) or `new_crtc_state->connectors_changed = true` (in `gud_connector_atomic_check()`) so `GUD_REQ_SET_STATE_CHECK` and `GUD_REQ_SET_STATE_COMMIT` run in lockstep. [F40]
- `gud_get_properties()` and `gud_connector_add_properties()` must skip unknown property IDs without adding them to `gdrm->properties` or `gconn->properties`, because `gud_plane_atomic_check()` and `gud_connector_fill_properties()` fail with `-EINVAL` (and `WARN_ON_ONCE`) on any unrecognized ID in those arrays. [F91]
- `gconn->initial_brightness` must be initialized to `-ENODEV` in `gud_connector_create()` to indicate no backlight (since 0 is a valid brightness), and `gconn->backlight` must only be assigned in `gud_connector_backlight_register()` after verifying `!IS_ERR(bd)`. In `gud_connector_add_properties()`, `GUD_PROPERTY_BACKLIGHT_BRIGHTNESS` must be validated to be `<= 100` before narrowing to `gconn->initial_brightness` (copied into `connector->state->tv.brightness`) and recorded in `gconn->properties`, but must not be passed to `gud_connector_property_lookup()` or attached as a DRM property. [F29, F72, F92]
- In `gud_probe()`, `drm_mode_config_reset(drm)` must run only after `gud_get_connectors(gdrm)` has populated `gconn->initial_tv_state` and `gconn->initial_brightness`. In `gud_connector_reset()`, `connector->state->tv = gconn->initial_tv_state` must be applied before `drm_atomic_helper_connector_tv_margins_reset(connector)` and before restoring `connector->state->tv.brightness = gconn->initial_brightness` (when `gconn->initial_brightness >= 0`). [F43, F88]
- Connectors must be registered with `drm_connector_init()` in the exact 0-based order returned by `GUD_REQ_GET_CONNECTORS` without any prior connectors on `gdrm->drm`, because `connector->index` is passed directly as the USB protocol connector index (`wValue`) in connector and state requests. [F93]
- `struct drm_connector connector` must remain the first member of `struct gud_connector` so that `kfree(connector)` on the `drm_connector_init()` error path in `gud_connector_create()` frees the enclosing `kzalloc()` allocation. [F78]
- In `gud_flush_rect()`, when `gdrm->stats_length += len` wraps around (`gdrm->stats_length <= len && gdrm->stats_actual_length`), `gdrm->stats_length` and `gdrm->stats_actual_length` must be reset together (`stats_length = len`, `stats_actual_length = 0`) before adding `trlen`. [F45]

## Synchronization

- In `gud_usb_transfer()`, `gdrm->ctrl_lock` must be held continuously across `gud_usb_control_msg()` and the follow-up `gud_usb_get_status()` call whenever a control transfer fails with `-EPIPE` or `GUD_DISPLAY_FLAG_STATUS_ON_SET` is set on an OUT transfer. [F13]
- `gud_fb_queue_damage()` and `gud_flush_work()` must hold `gdrm->damage_lock` while accessing `gdrm->fb`, `gdrm->damage`, and `gdrm->shadow_buf`. `gud_fb_queue_damage()` only calls `drm_framebuffer_get(fb)` and puts the prior `gdrm->fb` when `fb != gdrm->fb` (so `gdrm->fb` holds at most one pending reference), and `gud_flush_work()` must move `gdrm->fb` into a local variable (setting `gdrm->fb = NULL`) before unlocking `gdrm->damage_lock` and calling `gud_flush_damage()`. [F3, F16]
- `gud_probe()` must initialize `gdrm->ctrl_lock` and `gdrm->flags` before calling `gud_usb_get()`, `gud_usb_set()`, `gud_get_properties()`, or `gud_get_connectors()`, and must initialize `gdrm->damage_lock`, `gdrm->work`, and `gud_clear_damage(gdrm)` before `drm_dev_register()`. [F21]
- `gud_disconnect()` must call `drm_kms_helper_poll_fini()` and `drm_dev_unplug()` before `drm_atomic_helper_shutdown()`. [F19]

## Object Lifetimes

- In `gud_plane_atomic_update()`, when `crtc->state->mode_changed || !crtc->state->enable`, cleanup must execute before `drm_dev_enter(drm, &idx)` (so `drm_atomic_helper_shutdown()` cleans up async flush state after `drm_dev_unplug()` in `gud_disconnect()`): it must call `cancel_work_sync(&gdrm->work)` outside `gdrm->damage_lock` before freeing `gdrm->shadow_buf`, and under `gdrm->damage_lock` must put `gdrm->fb`, `vfree(gdrm->shadow_buf)`, and reset both `gdrm->shadow_buf` and `gdrm->fb` to `NULL`. [F2, F81]
- In `gud_flush_damage()`, `fmtcnv_state` must be initialized with `DRM_FORMAT_CONV_STATE_INIT` and released via `drm_format_conv_state_release(&fmtcnv_state)` after the `gud_flush_rect()` loop on both normal completion and error break paths. Broken by: returning early from `gud_flush_damage()` on a `gud_flush_rect()` error. [F12]
- In `gud_usb_bulk()`, `ctx.timer` must be initialized with `timer_setup_on_stack()` only after `usb_sg_init(&ctx.sgr, ...)` succeeds, and must be stopped with `timer_delete_sync(&ctx.timer)` and destroyed with `timer_destroy_on_stack(&ctx.timer)` after `usb_sg_wait(&ctx.sgr)` before returning. [F97]
- In `gud_connector_early_unregister()`, `backlight_device_unregister(gconn->backlight)` must be called before `cancel_work_sync(&gconn->backlight_work)` so `gud_connector_backlight_update_status()` cannot re-queue `gconn->backlight_work` after cancellation. [F83]
- `struct gud_connector` (`gconn`) and `gconn->properties` must be allocated with unmanaged `kzalloc()`/`kcalloc()` and freed only in `gud_connector_destroy()` (or before `drm_connector_init()` succeeds), never via `devm_*` or on error paths after `drm_connector_init()`. [F85]
- In `gud_probe()`, `mutex_init(&gdrm->ctrl_lock)` and `devm_add_action(dev, gud_free_buffers_and_mutex, gdrm)` must run before `gud_alloc_bulk_buffer()` and `gdrm->compress_buf = vmalloc(...)` so `bulk_buf`, `bulk_sgt`, `compress_buf`, and `ctrl_lock` are freed on probe failure or unbind. [F86]
- In `gud_probe()`, the `struct device *dma_dev` returned by `usb_intf_get_dma_device(intf)` must be released with `put_device(dma_dev)` immediately after passing it to `drm_dev_set_dma_dev(drm, dma_dev)`. [F87]

## API Contracts

- Buffers passed to `gud_usb_get()`, `gud_usb_transfer()`, or `gud_usb_control_msg()` must be heap-allocated (DMA-capable) rather than stack-allocated; callers with stack buffers must use `gud_usb_get_u8()`, `gud_usb_set()`, or `gud_usb_set_u8()`. [F94]
- In `gud_usb_transfer()`, the `u16 index` parameter (carrying the connector index for `GUD_REQ_*_CONNECTOR_*` requests) is passed as the `wValue` parameter (`value`) of `gud_usb_control_msg()`, while `wIndex` in `usb_control_msg()` is always the USB interface number `bInterfaceNumber`. [F35]
- Callers of `gud_usb_get()` that receive arrays of fixed-size wire structures (`gud_get_properties()`, `gud_connector_get_modes()`, `gud_connector_add_tv_mode()`, `gud_connector_add_properties()`, and `gud_get_connectors()`) must verify that the returned byte count is positive and a multiple of the element size (`ret > 0` and `ret % sizeof(*elem) == 0`) before dividing to get the element count. [F47]
- When copying damaged pixels into `gdrm->shadow_buf` in `gud_fb_queue_damage()`, `shadow_map` must be advanced by `drm_fb_clip_offset()` and passed to `drm_fb_memcpy()` with `dst_pitch = fb->pitches`, whereas `gud_flush_work()` must pass the un-offset base of `gdrm->shadow_buf` to `gud_flush_damage()` where `gud_prep_flush()` passes `dst_pitch = NULL`. [F34]
- In `gud_plane_atomic_check()`, the `struct gud_state_req` flexible-array buffer `req` must be allocated using `struct_size(req, properties, size_add(GUD_PROPERTIES_MAX_NUM, GUD_CONNECTOR_PROPERTIES_MAX_NUM))` and sent to `gud_usb_set()` with `struct_size(req, properties, num_properties)`. [F73]
- In `gud_get_properties()`, the device-reported `GUD_PROPERTY_ROTATION` value must be masked with `GUD_ROTATION_MASK` before passing it as `supported_rotations` to `drm_plane_create_rotation_property()`. [F107]
- In `gud_connector_detect()`, when the `GUD_REQ_GET_CONNECTOR_STATUS` reply has `GUD_CONNECTOR_STATUS_CHANGED` set, `connector->epoch_counter` must be incremented so DRM probe helpers emit a hotplug uevent even if the connection state did not change. [F111]

## Error Handling

- In `gud_usb_transfer()`, when `gud_usb_get_status()` is called after a stalled (`-EPIPE`) transfer or a `GUD_DISPLAY_FLAG_STATUS_ON_SET` OUT transfer, `ret` must only be overwritten with `status` when `status < 0`, and if `status >= 0` while `ret < 0`, `ret` must be forced to `-EPIPE`. Broken by: unconditionally assigning `ret = gud_usb_get_status(intf)`, which turns a stalled transfer with `GUD_STATUS_OK` into `0` and zeroes the byte-count return value of successful OUT transfers so `gud_usb_set()` fails with `-EIO`. [F57]
- `gud_usb_get()` returns the non-negative received byte count or a negative errno, so callers that store its result in `ret` and return `ret` must reset `ret = 0` after validating a positive byte count (as in `gud_get_properties()` and `gud_connector_add_properties()`). [F23]
- `gud_xrgb8888_to_r124()` returns an unsigned `size_t` byte length and signals `kmalloc()` failure by returning `0` rather than a negative errno, so callers must check for a `0` return value and translate it to `-ENOMEM`. [F25]
- `gud_connector_property_lookup()` and `gud_connector_tv_state_val()` return `ERR_PTR(-EINVAL)` rather than `NULL` for unrecognized property IDs, and `gud_connector_fill_properties()` returns either a non-negative property count or a negative errno, requiring `IS_ERR()` and signed negative checks respectively. [F26]
- In `gud_flush_damage()`, errors returned by `gud_flush_rect()` must be logged with `dev_err_ratelimited()` only when `ret` is not `-ENODEV`, `-ECONNRESET`, `-ESHUTDOWN`, or `-EPROTO`. [F114]

## External Contracts

- Conversions between `drm_display_mode` and `gud_display_mode_req` in `gud_from_display_mode()` and `gud_to_display_mode()` must mask mode flags with `GUD_DISPLAY_MODE_FLAG_USER_MASK` and map `DRM_MODE_TYPE_PREFERRED` to and from the internal protocol bit `GUD_DISPLAY_MODE_FLAG_PREFERRED`. [F54]
- In `gud_get_display_descriptor()` and `gud_probe()`, a display descriptor with both `GUD_DISPLAY_FLAG_FULL_UPDATE` and compression enabled must be rejected, and `max_buffer_size` must be capped to `SZ_64M` before allocating `bulk_buf` and `compress_buf`. [F55]

## Known Pitfalls

- In `gud_prep_flush()`, `gud_set_buffer_req` fields (`x`, `y`, `width`, `height`, `length`) and the LZ4 compression input length must be set after format conversion, because `gud_xrgb8888_to_r124()` and `gud_xrgb8888_to_color()` align `rect->x1` down to `block_width` in place and return the updated byte length. For the same reason, in `gud_flush_damage()`, each iteration of the vertical split loop must re-initialize `struct drm_rect rect = *damage` before computing `rect.y1 += i * lines` and calling `gud_flush_rect()`. [F51, F63]
- Sub-byte pixel conversion helpers `gud_xrgb8888_to_r124()` and `gud_xrgb8888_to_color()` write into reused buffers (`gdrm->bulk_buf` or `gdrm->compress_buf`) using bitwise OR (`*block |= pix << pixshift`) and therefore must zero `*block = 0` at the start of every byte (`!pixpos`). [F32]
- In `gud_xrgb8888_to_color()`, the byte row offset `y * fb->pitches[0]` must be added to the byte-addressed `void *src` pointer before assigning to `__le32 *sbuf32`, while the pixel X offset `rect->x1` must be added to `sbuf32` so it scales by `sizeof(__le32)`. [F76]
- Stack-allocated `struct iosys_map` variables in `gud_pipe.c` must be initialized via `iosys_map_set_vaddr()` or zero-initialization before being passed to `iosys_map_incr()` or `drm_fb_*` helpers so that the boolean `is_iomem` field is never read uninitialized. [F33]
- In `gud_stats_debugfs()`, divisions involving the `u64` counters `gdrm->stats_length`, `gdrm->stats_actual_length`, and `remainder` must use `div64_u64_rem()` and `div64_u64()` rather than the `/` or `%` operators so 64-bit division builds on 32-bit architectures. [F67]
