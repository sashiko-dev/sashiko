# MEMORY MANAGEMENT - CORE

This unit defines core memory management types (`struct page`, `struct folio`, `struct vm_area_struct`, `struct mm_struct`, `struct zone`, `gfp_t`), inline helpers for page flags, reference counting, and page table manipulation, and core implementations for page fault handling (`mm/memory.c`), MMU notifiers (`mm/mmu_notifier.c`), highmem/local kmap (`mm/highmem.c`), nofault memory access (`mm/maccess.c`), and VM debugging (`mm/debug.c`).

## Architecture & Data Flow

- `PG_waiters` must stay at bit 7 of `folio->flags`, and `folio_xor_flags_has_waiters()` only takes a `mask` affecting bits 0-6 under the folio lock. `FOLIO_SECOND_PAGE` flags (`PG_has_hwpoisoned`, `PG_large_rmappable`, `PG_partially_mapped`) must be in `PAGE_FLAGS_SECOND`, must not use bits 0-7 (`folio->_flags_1 & 0xff` stores `folio_large_order()`), and must use atomic `FOLIO_FLAG(..., FOLIO_SECOND_PAGE)`. [F23, F98, F99]
- Each `mm_id_t` in `folio->_mm_id[0..1]` must fit in `MM_ID_BITS` (`<= MM_ID_MAX`), leaving `FOLIO_MM_IDS_LOCK_BITNUM` and `FOLIO_MM_IDS_SHARED_BITNUM` in unioned `unsigned long _mm_ids` reserved. In `folio_maybe_mapped_shared()`, small and hugetlb folios must return `mapcount > 1` first, and partially-mappable large folios must return `false` when `mapcount <= 1` before testing `FOLIO_MM_IDS_SHARED_BITNUM`. [F93, F126]
- Adding a field to `struct vm_area_struct` requires updating `vm_area_init_from()`. Keep `___GFP_*_BIT` and `VM_*` in sync with `include/trace/events/mmflags.h` and `{0, NULL}`-terminated `pageflag_names[]`/`gfpflag_names[]`/`vmaflag_names[]` in `mm/debug.c`, `enum migratetype` with `migratetype_names[]`, `MM_*PAGES` with `resident_page_types[]`, and `enum lru_list` with `NR_ZONE_LRU_BASE`, `NR_LRU_BASE`, and `vmstat_text`. [F68, F81, F106, F266, F283]
- In `struct zone`, `nr_free_highatomic` tracks actual free pages in `MIGRATE_HIGHATOMIC` pageblocks while `nr_reserved_highatomic` tracks reserved capacity; unusable-free watermark checks must subtract `nr_free_highatomic`, and free-page reads below `zone->percpu_drift_mark` must use `zone_page_state_snapshot()`. [F78]
- When initializing a `struct xa_state` to populate or update XArray nodes in a `struct address_space` where `!dax_mapping(mapping) && !shmem_mapping(mapping)`, callers must invoke `mapping_set_update(xas, mapping)`. [F246]
- In `enum fault_flag`, `!(flags & FAULT_FLAG_ALLOW_RETRY) && (flags & FAULT_FLAG_TRIED)` and `(flags & FAULT_FLAG_WRITE) && (flags & FAULT_FLAG_UNSHARE)` are illegal. In `do_page_mkwrite()`, `vmf->flags` must be saved and restored around `vm_ops->page_mkwrite(vmf)`. In `gup_must_unshare()`, `(flags & (FOLL_WRITE | FOLL_PIN)) != FOLL_PIN` requires `FOLL_PIN` set and `FOLL_WRITE` clear. [F83, F254, F294]
- In `__access_remote_vm()` and `__copy_remote_vm_str()`, `addr` must be untagged with `untagged_addr_remote(mm, addr)` after acquiring `mmap_read_lock_killable(mm)` and before `vma_lookup()` or `get_user_page_vma_remote()`. [F276]

## Synchronization

- `pte_offset_map()` and `pte_offset_map_lock()` enter an RCU read-side critical section; callers must not sleep while a PTE is mapped and must unlock `ptl` before calling `pte_unmap()`. Keep `ptl` held between `ptep_modify_prot_start()` (`modify_prot_start_ptes()`) and `ptep_modify_prot_commit()` (`modify_prot_commit_ptes()`). In `copy_pte_range()`, lock `dst_ptl` first and `src_ptl` second via `spin_lock_nested(src_ptl, SINGLE_DEPTH_NESTING)`. [F167, F329, F336]
- Execute `smp_wmb()` after initializing a new page table page and its lock before `pgd/p4d/pud/pmd_populate*()`. `__apply_to_page_range()` must use `p4d/pud/pmd_alloc_track()` and `pte_alloc_kernel_track()` to accumulate `pgtbl_mod_mask mask` and call `arch_sync_kernel_mappings()` when `mask & ARCH_PAGE_TABLE_SYNC_MASK` is non-zero. [F211, F337]
- `vma->vm_lock_seq` may only be written (via `WRITE_ONCE()`) while holding both write `mmap_lock` and the VMA lock (`VMA_LOCK_OFFSET`), while `mm->mm_lock_seq` is updated under write `mmap_lock` with RELEASE semantics and read outside it with ACQUIRE semantics. Under `FAULT_FLAG_VMA_LOCK`, `__vmf_anon_prepare()` must `mmap_read_trylock(vma->vm_mm)` before `__anon_vma_prepare(vma)`, and on trylock failure `vmf_anon_prepare()` must call `vma_end_read(vmf->vma)` and return `VM_FAULT_RETRY`. [F38, F338]
- Lockless `page_folio(page)` can race with folio split; after `folio_try_get(folio)`, callers must recheck `page_folio(page) == folio`. In `remove_device_exclusive_entry()`, pin `folio` with `folio_try_get(folio)` before `folio_lock_or_retry()` and re-verifying `pte_same()` under `ptl`. [F36, F340]
- In `__wp_can_reuse_large_anon_folio()`, `folio_lock_large_mapcount(folio)` must be acquired and both `test_bit(FOLIO_MM_IDS_SHARED_BITNUM, &folio->_mm_ids)` and `folio_large_mapcount(folio) != folio_ref_count(folio)` must be reverified under that lock. Callers of `folio_needs_cow_for_dma(vma, folio)` must hold `ptl` and be in a `vma->vm_mm->write_protect_seq` write critical section. [F35, F218]
- `pgdat->node_size_lock` (`pgdat_resize_lock()`) nests above `zone->lock` and `zone->span_seqlock`. `GFP_ATOMIC` and `GFP_NOWAIT` set `__GFP_KSWAPD_RECLAIM` (`gfpflags_allow_spinning()`) and cannot be used in NMI or `raw_spinlock_t` contexts (use `alloc_pages_nolock()`). `folio_put()`, `folios_put()`, and `put_page()` must not be called in NMI context. [F34, F156, F169]
- `page_ext_lookup()` and `for_each_page_ext()` require `rcu_read_lock()`, and callers of `page_ext_get()` must not sleep before `page_ext_put()`. `folio_evictable()` must hold `rcu_read_lock()` across `folio_mapping(folio)` and `mapping_unevictable()`. [F165, F334]
- In `__mmu_notifier_register()`, publish `mm->notifier_subscriptions` via `smp_store_release()` (paired with `smp_load_acquire()` in unlocked readers). `mn_hlist_release()` and `mmu_notifier_unregister()` must unlink `subscription->hlist` with `hlist_del_init_rcu()` under `subscriptions->lock` and call `synchronize_srcu(&srcu)`. Callers of `mmu_interval_notifier_remove()` and `mmu_interval_read_begin()` must not hold any lock taken inside `invalidate` or `invalidate_range_start` callbacks. [F213, F214, F216]
- Pair every successful `follow_pfnmap_start(args)` with `follow_pfnmap_end(args)` under `mmap_lock` (or `i_mmap_rwsem`). In `generic_access_phys()`, after `follow_pfnmap_end(&args)` and `ioremap_prot()`, call `follow_pfnmap_start(&args)` again to reverify `args.pgprot`, `args.pfn`, and `args.writable` across `memcpy_toio()`/`memcpy_fromio()`. [F203, F224]

## Object Lifetimes

- `release_fault_lock(vmf)` releases either `vma_end_read(vmf->vma)` (`FAULT_FLAG_VMA_LOCK`) or `mmap_read_unlock()`; fault paths must not call `mmap_read_unlock()` directly. In `handle_mm_fault()`, never dereference `vma` after `hugetlb_fault()` or `__handle_mm_fault()`. In `fault_dirty_shared_page()`, sample `folio_raw_mapping(folio)` before `folio_unlock(folio)`. [F16, F222, F255]
- `folio_release_kmap()` calls `kunmap_local(addr)` before `folio_put(folio)`; never reverse this order or access the folio after `folio_put()` without another ref. Mappings created via `__kmap_local_pfn_prot()` push onto `current->kmap_ctrl` with `migrate_disable()` and must be unmapped in strict LIFO order via `kunmap_local_indexed()`. [F5, F206]
- Clean up a non-NULL `folio_walk_start()` via `folio_walk_end(fw, vma)` before dropping the borrowed folio. `anon_vma_name(vma)` requires `mmap_lock` held (or `anon_vma_name->kref` taken before unlocking). In `mm_walk_ops::hugetlb_entry`, dropping and retaking the VMA lock invalidates `pte_t *` and `ptl`. [F7, F13, F21]
- `FOLL_PIN` and `FOLL_GET` are mutually exclusive: never pass `FOLL_PIN` to `get_user_pages*()`, and always release `pin_user_pages*()` pages with `unpin_user_page*()` / `unpin_folio*()` instead of `put_page()` / `folio_put()`. [F190]
- Clear `vmf->prealloc_pte = NULL` when consumed in `pmd_install()` or `deposit_prealloc_pte()`. Clear `*prealloc = NULL` in `copy_present_page()` only after `copy_mc_user_highpage()` succeeds, and `folio_put()` unconsumed `prealloc` after each step in `copy_pte_range()`. In `wp_page_copy()`, complete `ptep_clear_flush()` and `set_pte_at()` before `folio_remove_rmap_pte()`, and put `old_folio` after `mmu_notifier_invalidate_range_end()`. [F199, F200, F204]
- Release the `mmgrab(mm)` from `__mmu_notifier_register()` via `mmdrop(mm)` only after SRCU quiescence; modules using `mmu_notifier_put()` must call `mmu_notifier_synchronize()` in `__exit`. While `mn_itree_is_invalidating(subscriptions)` is true, defer `subscriptions->itree` mutations to `mn_itree_inv_end()` via `deferred_list`, and wait on `subscriptions->wq` in `mmu_interval_notifier_remove()` before `mmdrop(mm)`. [F208, F210, F300, F349]

## API Contracts

- `finish_fault()` consumes the caller's locked folio reference if and only if it returns `0`; on non-zero `VM_FAULT_*`, the caller must unlock and `folio_put()` the folio. If `nr_pages > 1` and `!pte_range_none(vmf->pte, nr_pages)` under `ptl`, `finish_fault()` must set `needs_fallback = true`, call `pte_unmap_unlock()`, and retry at `fallback` (`nr_pages = 1`) rather than returning `VM_FAULT_NOPAGE`. [F201, F288]
- `kmap_local_folio(folio, offset)` takes a byte offset and maps one `PAGE_SIZE` page when `folio_test_partial_kmap(folio)` is true, so clamp accesses to `PAGE_SIZE - offset_in_page(offset)`. Pass the return value of `folio_zero_tail(folio, offset, kaddr)`—not `kaddr`—to `kunmap_local()`. `kmap()` and `kmap_high()` can sleep (illegal in atomic context), whereas `kmap_local_page/folio()` work in any context and must be unmapped in LIFO order via `kunmap_local()`. [F51, F147, F159, F331]
- `folio_zero_segment*()` and `zero_user_segment()` take an exclusive end offset, whereas `folio_zero_range()` and `memzero_page()` take a byte length. `page_frag_alloc_align()` takes a power-of-two `align`, whereas `__page_frag_alloc_align()` takes a pre-negated `align_mask`. [F50, F53]
- Call `folio_batch_remove_exceptionals()` before `folios_put()` or `folio_batch_release()` if a `folio_batch` can contain shadow/swap/DAX entries. `page_mapcount_is_type()` expects `page->_mapcount + 1`; use `page_type_has_type()` or `page_has_type()` on raw `page_type`/`_mapcount`. [F19, F40]
- `mm_flags_test/set/clear*()` take a bit index (`MMF_*` across all 64 bits), whereas `__mm_flags_get/set*_word()` take shifted masks (`MMF_*_MASK`) and only access the first `BITS_PER_LONG` word (dropping bits `>= 32` on 32-bit). [F64, F155]
- `mm->mm_mt` and `interval_sub->interval_tree` store inclusive endpoints `[start, end - 1]`: VMA iterators must pass `end - 1` to `mas_*` primitives, `__mmu_interval_notifier_insert()` must reject `length == 0` or `start + (length - 1)` overflow with `-EOVERFLOW`, and `mn_itree_inv_start_range()`/`next()` must query `[range->start, range->end - 1]`. [F95, F275]
- `folio_pte_batch*()` and `swap_pte_batch()` require `max_nr >= 1` bounded to the current VMA and PMD table; `folio_pte_batch_flags()` requires `@ptentp` to point to a local `pte_t` copy, must clamp `max_nr` up front to `folio_pfn(folio) + folio_nr_pages(folio) - pte_pfn(pte)`, and must return `min(nr, max_nr)`. `modify_prot_start_ptes()` and `get_and_clear_full_ptes()` must merge `pte_dirty` and `pte_young` across the batch, and `modify_prot_commit_ptes()` must advance both `old_pte` and `pte` via `pte_next_pfn()`. [F248, F265, F268, F269]
- In `insert_pages()`, cap `pages_to_write_in_pmd` at `PTRS_PER_PTE - pte_index(addr)`, advance `curr_page_idx` monotonically across `more:`, and subtract `pte_idx` from `remaining_pages_total` on mid-batch error before `*num = remaining_pages_total`. `vm_insert_page*()` pages must belong to a referenced folio that is neither anonymous nor typed, and normal refcounted folios must use `folio_mk_pte/pmd/pud()`, never `*_mkspecial()`. [F177, F272, F299, F358]
- In `mmu_notifier_ops`, an `invalidate_range_start` that can return `-EAGAIN` when `!mmu_notifier_range_blockable(range)` must not define `invalidate_range_end`, and callers of `mmu_notifier_invalidate_range_start_nonblock()` must not modify PTEs on failure. Use `mmu_notifier_range_init_owner()` for `MMU_NOTIFY_MIGRATE` and `MMU_NOTIFY_EXCLUSIVE`, and only read `range->owner` on those two events. [F27, F58]
- Use `for_each_page_ext()` under `rcu_read_lock()` rather than `page_ext_next()` across PFN ranges, and set `.need_shared_flags = true` when using `page_ext->flags`. `first/next_zones_zonelist()` return a sentinel with `zoneref->zone == NULL` (never `NULL`); test `zonelist_zone(z)` and pre-increment `++z`. [F91, F121, F193]
- `__GFP_NORETRY`, `__GFP_RETRY_MAYFAIL`, and `__GFP_NOFAIL` require `__GFP_DIRECT_RECLAIM` (and `order <= 1` for `__GFP_NOFAIL`). Filter nested allocator GFP flags with `gfp_nested_mask()`. Bounds-check lockless `compound_order()` before shifting. `Set/ClearPageAnonExclusive()` require the head page on HugeTLB and `PageAnonNotKsm(page)`. Use `ptdesc_pmd_is_shared()` instead of `page_count()` for hugetlb PMD sharing. [F63, F66, F135, F157, F158]

## Error Handling

- `alloc_anon_folio()` returns a `struct folio *`, `NULL` on OOM, or `ERR_PTR(-EAGAIN)` when `pte_offset_map()` fails; check `IS_ERR(folio)` before `!folio`. In `do_swap_page()`, if `ksm_might_need_to_copy()` returns `NULL` or `ERR_PTR(-EHWPOISON)`, restore `folio = swapcache` before jumping to `out_page`. [F231, F232]
- `get_user_page_vma_remote()` returns an `ERR_PTR` (never `NULL`) on failure and rejects `FOLL_NOWAIT` with `ERR_PTR(-EINVAL)`. `copy_mc_[user_]highpage()` and `copy_folio_from_user()` return `0` or positive uncopied bytes, whereas `copy_from/to_user_nofault()` return `-EFAULT` on non-zero residual. [F52, F59, F244]

## External Contracts

- Read `mm->rss_stat` via `get_mm_counter_sum()` (not `get_mm_counter()`) in user-facing reporting paths. `[__]copy_remote_vm_str()` return `-EFAULT` on error and must write `*(char *)buf = '\0'` whenever `len > 0` on all error paths. `strncpy_from_kernel/user_nofault()` must NUL-terminate `dst` when `count > 0` and return length including NUL. Never export `copy_to_kernel_nofault()`. [F178, F238, F322, F350]

## Known Pitfalls

- Verify `!folio_test_slab(folio)` before `folio_test_anon()`, `PageAnon()`, `PageAnonNotKsm()`, or `folio_test_ksm()` on arbitrary pages; `folio_test_anon()` is also true for KSM folios. `folio_test_swapcache()` must check `folio_test_swapbacked(folio)` first, and `page_has_movable_ops()` must gate `PageMovableOps(page)` on `PageOffline(page) || PageZsmalloc(page)`. [F41, F115, F116]
- `sizeof(struct folio)` is `4 * sizeof(struct page)`; use `folio_page(folio, n)` or `folio_next(folio)`, never `folio + n` or `folio++`. On `!CONFIG_64BIT`, `_entire_mapcount` and `_pincount` live in `folio->__page_2` (absent on order-1 folios); use `folio_entire_mapcount()` and `folio_has_pincount()`. `PAGE_FLAGS_PRIVATE` is only checked on the head page (`folio_has_private()`). [F145, F146, F188]
- Under `CONFIG_HIGHPTE`, `__pte_map()` must cast `kmap_local_page()` to `pte_t *` before adding `pte_index(address)`. Pass the initial mapped `pte_t *` (not the incremented loop cursor) to `pte_unmap_unlock()`. Keep `pte++` in `while (pte++, addr += PAGE_SIZE, addr != end)` in `apply_to_pte_range()`, and execute `if (addr != next) pmd--` in `zap_pmd_range()`. [F289, F296, F317, F318]
- Use `user_alloc_needs_zeroing()` + `clear_user_highpage()`/`folio_zero_user()` for user folios rather than `__GFP_ZERO`. Use `lruvec_pgdat(lruvec)` instead of `container_of`. Pass pointer arguments (`&folio->flags`, `&gfp_mask`, `&vma->vm_flags`) to `%pGp`, `%pGg`, and `%pGv`. [F149, F153, F161]
