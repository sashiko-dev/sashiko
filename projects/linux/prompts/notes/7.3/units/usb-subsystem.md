# USB SUBSYSTEM

This unit contains USB Device Controller (UDC) peripheral drivers (`lpc32xx_udc`, `m66592-udc`, `max3420_udc`, `net2280`, `omap_udc`), the `usbmon` URB snooping subsystem (`drivers/usb/mon/`), and miscellaneous USB host drivers, hub controllers, firmware loaders, and compliance test drivers (`drivers/usb/misc/`).

## Architecture & Data Flow

- In `net2280.c`/`net2280.h`, `dev->usb_ext`, `dev->llregs`, and `dev->plregs` are mapped only when `dev->quirks & PLX_PCIE` is set. In `PLX_PCIE` `enhanced_mode`, IN endpoints offset `ep->regs` by `0xC0` from `ep->cfg` while sharing `ep->cfg` with the same-numbered OUT endpoint, so `ep_cfg` updates (`net2280_enable`, `ep_reset_338x`, `set_fifo_bytecount`) must use `ep->cfg->ep_cfg` and preserve the sibling direction's bits, and the 9-element endpoint order across `ep_info_adv`, `ep_bit`, `ep_key`, `ne`, `ep_reg_addr`, `ep_pl`, and `ep_enhanced` must stay in lockstep. [F65, F66, F76, F132]
- In `net2280.c`, `queue_dma` swaps `req->td`/`req->td_dma` with `ep->dummy`/`ep->td_dma` without clearing `dmacount`, so aborted DMA requests (`net2280_dequeue`, `handle_ep_small`) must set `req->td->dmacount = 0` before `dma_done`. In `net2280_dequeue`, unlinking the queue head (`ep->queue.next == &req->queue`) must reset `req = NULL` after completion so `done()` is not called twice and `start_dma` starts the new head. [F62, F89]
- In `omap_udc.c`, `udc->ep[32]` is indexed by `addr & 0xf` for EP0/OUT and `16 + (addr & 0xf)` for IN, while `ep->dma_channel` is 1-based (`1..3`, `0` unassigned); callers of `dma_channel_release` (`omap_ep_dequeue`, `omap_ep_set_halt`, `nuke`) must check `ep->dma_channel != 0` rather than `ep->has_dma`. In `read_fifo`, EP0 (`!ep->bEndpointAddress`) must `break` before `if (is_last) done(ep, req, 0);` so `ep0_irq` deselects EP0 (`omap_writew(0, UDC_EP_NUM)`) before calling `done()`. [F79, F97, F100]
- In `m66592-udc.c`, `m66592->clk` is only acquired when `m66592->pdata->on_chip` is non-zero, so clock teardown must check `m66592->pdata->on_chip`. `alloc_pipe_config` increments both `m66592->isochronous` and `m66592->bulk` when assigning a bulk endpoint to an isochronous pipe, so `free_pipe_config` must call `pipe_buffer_release` before `m66592_ep_release` clears `ep->pipenum = 0`. `enable_pipe_irq`/`disable_pipe_irq` must save `M66592_INTENB0`, clear `M66592_BEMPE | M66592_NRDYE | M66592_BRDYE` before modifying `M66592_BRDYENB`/`M66592_BEMPENB`/`M66592_NRDYENB`, and restore `M66592_INTENB0`. [F39, F58, F59]
- In `lpc32xx_udc.c`, `iso_status` in `struct lpc32xx_usbd_dd_gad` must remain at byte offset 24 (`dd->this_dma + 24` in `lpc32xx_ep_queue`). `lpc32xx_ep_enable` must reject `usb_endpoint_maxp(desc) == 0` (`udc_ep_in_req_dma` divides by `ep->ep.maxpacket`), and `lpc32xx_ep_enable`/`lpc32xx_ep_disable` must keep `ep->hwep_num`, `udc->udca_v_base[ep->hwep_num]`, and `udc->enabled_ep_cnt` synchronized, waking `udc->ep_disable_wait_queue` on decrement. [F55, F70, F105]
- In `mon_bin.c`, `rp->b_vec` pages are not virtually contiguous, so offsets must be translated via `rp->b_vec[off / CHUNK_SIZE].ptr + off % CHUNK_SIZE` and copies chunked at `CHUNK_SIZE` (`mon_copy_to_buff()`, `copy_from_buf()`). Ring allocations/frees align to `PKT_ALIGN` (`PKT_SIZE` = 64); `mon_bin_hdr::len_cap` excludes `PKT_SIZE` while payload data always starts at `b_out + PKT_SIZE` even when `PKT_SZ_API0` (48) header bytes are copied; multi-slot wrap-around must subtract `rp->b_size` (not reset to `0`); and when `rp->mmap_active` is non-zero, `mon_bin_event` must use `mon_buff_area_alloc_contiguous`. [F224, F236, F238, F265, F283]
- In `drivers/usb/mon/`, `ubus->monitored` must remain `1` iff either `mbus->nreaders` or `mon_bus0.nreaders` is non-zero (`mon_reader_add`, `mon_reader_del`, `mon_stop`, `mon_bus_add`). When `mon_bus_remove` detaches a bus, `mon_dissolve` sets `mbus->u_bus = NULL` while open readers may hold `mbus->ref`, so `mon_stop` and `mon_bin_open` must check `mbus->u_bus != NULL` (for `mbus != &mon_bus0`). In `mon_text_get_data()` and `mon_bin_get_data()`, capture must use `urb->transfer_buffer` when `urb->num_sgs == 0`, and otherwise iterate `urb->sg` via `sg_virt(sg)` only when `!PageHighMem(sg_page(sg))` (and `!(urb->transfer_flags & URB_DMA_SG_COMBINED)` in `mon_bin_get_data()`). [F209, F219, F220]

## Synchronization

- In `net2280.c`, `omap_udc.c`, `lpc32xx_udc.c`, and `m66592-udc.c`, `done()`, `transfer_complete()`, `stop_activity()`, and `udc_handle_ep0_setup()` must drop the controller spinlock around `usb_gadget_giveback_request()`, `driver->disconnect()`, and `driver->setup()` and reacquire it afterward. In `net2280.c` and `omap_udc.c`, `done()` must save `ep->stopped`, set `ep->stopped = 1` before unlocking, and restore it after relocking; in `m66592-udc.c`, `transfer_complete()` must re-read `ep->queue.next` and verify `ep->ep.desc != NULL` after relocking before calling `start_packet()`; and queue-draining loops (`nuke()`, `handle_stat0_irqs()`, `m66592_disable()`) must use `while (!list_empty(&ep->queue))` and re-fetch `ep->queue.next` each pass. [F13, F40, F87, F139, F147]
- In `net2280.c`/`net2280.h`, `fill_dma_desc()` must execute `wmb()` after writing `td->dmaaddr`/`td->dmadesc` before writing `td->dmacount` with `BIT(VALID_BIT)`, paired with `rmb()` in `scan_dma_completions()` before reading `req->td->dmacount`. Under `ep->dev->lock`, `net2280_dequeue()` on a DMA endpoint (`ep->dma`) must set `ep->stopped = 1`, call `stop_dma(ep->dma)`, and run `scan_dma_completions(ep)` before searching `ep->queue`. Once `ep0_start()` enables interrupts, callers of `get_idx_reg()`, `set_idx_reg()`, and `set_max_speed()` must hold `dev->lock`. [F22, F23, F24]
- In `omap_udc.c`, `ep0_irq()` must set `udc->ep0_setup = 1` before dropping `udc->lock` around `udc->driver->setup()` and reset it to `0` after relocking so synchronous non-empty EP0 OUT `omap_ep_queue()` calls jump to `irq_wait`. All runtime accesses that select an endpoint via `UDC_EP_NUM` (`use_ep()`) must hold `udc->lock`, and any path setting `UDC_EP_SEL` must call `deselect_ep()` before releasing `udc->lock`. [F21, F32]
- In `max3420_udc.c`, all SPI helpers call blocking `spi_sync()` and must only run in `max3420_thread()` under `udc->spi_bus_mutex` with `udc->lock` and `ep->lock` dropped (also dropped across `max3420_req_done()`); IRQ handlers and gadget/ep callbacks must set `udc->todo`/`ep->todo` under spinlock and wake `udc->thread_task`. `max3420_irq_handler()` must only call `disable_irq_nosync(spi->irq)` when `(udc->todo & ENABLE_IRQ) == 0` and set `ENABLE_IRQ` under `udc->lock`, and `max3420_thread()` must clear `ENABLE_IRQ` and call `enable_irq(spi->irq)` under `udc->lock` before sleeping. [F16, F29, F144]
- In `drivers/usb/mon/`, `mon_bus_lookup()`, `mon_buses` accesses, `mon_reader_add()`, and `mon_reader_del()` require `mon_lock`, and `mon_reader_add`/`del` must take `spin_lock_irqsave(&mbus->lock, flags)` around `mbus->nreaders` and `mbus->r_list` updates while updating `mbus->ref` outside `mbus->lock`. `mon_reader` callbacks (`rnf_submit`, `rnf_error`, `rnf_complete`) run under `mbus->lock` and must not sleep, use `GFP_KERNEL`, or re-lock `mbus->lock`. In `mon_text.c`, `mon_text_fetch()` must hold `mbus->lock` when accessing `rp->e_list` and `rp->nevents`, and `mon_text_release()` must call `mon_reader_del()` before draining `rp->e_list` unlocked. [F185, F186, F226, F316, F317]
- In `mon_bin.c`, `mon_bin_vma_fault()` must hold `rp->b_lock` across bounds-checking `rp->b_size`, indexing `rp->b_vec`, and calling `get_page()`, while `mon_bin_ioctl(MON_IOCT_RING_SIZE)` must hold `rp->b_lock` when checking `rp->mmap_active` and replacing `rp->b_vec`/`rp->b_size`. Retiring a packet via `mon_buff_area_free` (`mon_bin_get_event`, `mon_bin_read`, `mon_bin_flush`) must hold both `rp->fetch_lock` and `rp->b_lock` and reset `rp->b_read = 0` under `rp->fetch_lock`. [F189, F223]
- Character device `.release` callbacks (`ld_usb_release`, `adu_release`, `iowarrior_release`, `idmouse_release`) must use uninterruptible `mutex_lock()`, never `mutex_lock_interruptible()`. In `yurex.c`, `yurex_write()` must acquire `dev->io_mutex` with `mutex_lock_interruptible()`, call `usb_kill_urb(dev->cntl_urb)` after `finish_wait(&dev->waitq, &wait)` before unlocking, and unlock `dev->io_mutex` on all return paths in `yurex_read()`/`yurex_write()`. [F166, F169, F326, F327]

## Object Lifetimes

- In `m66592-udc.c`, on `usb_add_gadget_udc()` failure in `m66592_probe()`, `m66592->ep0_req` must be set to `NULL` after `m66592_free_request()` before falling through to `clean_up:`; `m66592_remove()` must call `usb_del_gadget_udc()` and `timer_shutdown_sync(&m66592->timer)` before `iounmap()` and `kfree()`; and `get_status()` must point `m66592->ep0_req->buf` to `m66592->ep0_data`, never a stack variable. [F1, F31, F112]
- In `omap_udc.c`, `dma_channel_release()` must clear `ep->dma_channel = 0` and `ep->lch = -1` but leave `ep->has_dma` set until `nuke()` finishes calling `done()` (which gates `usb_gadget_unmap_request()` on `use_dma && ep->has_dma`). In `omap_udc_remove()`, `udc->done` must be set to a stack `struct completion` before `usb_del_gadget_udc(&udc->gadget)` and awaited via `wait_for_completion()` before `release_mem_region()`. [F3, F5]
- In `lpc32xx_udc.c`, `lpc32xx_stop()` and the `!udc->driver` branch of `lpc32xx_vbus_session()` must drop `udc->lock` and wait on `udc->ep_disable_wait_queue` until `atomic_read(&udc->enabled_ep_cnt) == 0` before relocking and calling `udc_clk_set(udc, 0)`; `lpc32xx_udc_probe()` must call `of_node_put()` on the `"transceiver"` node after `isp1301_get_client()`; and for `ep->lep != 0`, `done()` must call `usb_gadget_unmap_request()` and `udc_dd_free(udc, req->dd_desc_ptr)`. [F8, F9, F115]
- In `lpc32xx_udc.c`, `net2280.c`, and `omap_udc.c`, removing a request from `ep->queue` must use `list_del_init(&req->queue)` rather than `list_del()`. In `net2280_remove()`, `dev->ep[i].dummy` (`i = 1..4`) must be freed to `dev->requests` before `dma_pool_destroy(dev->requests)`. In `max3420_probe()`, any failure after `usb_add_gadget_udc()` must jump to `del_gadget` (`usb_del_gadget_udc()`). [F2, F6, F17]
- In `yurex.c`, `iowarrior.c`, and `adutux.c`, driver structs can outlive `.disconnect` while open: `yurex_probe` must pin `usb_get_dev` and `usb_get_intf`, `yurex_disconnect` must poison `dev->urb` and `dev->cntl_urb` without clearing `dev->interface`, and `yurex_delete` must kill both URBs and `usb_free_coherent` their buffers before `usb_put_intf`/`usb_put_dev`; `iowarrior_probe` must pin `usb_get_intf` (released in `iowarrior_delete`) and `iowarrior_disconnect` must hold `dev->mutex` while clearing `dev->present`, checking `dev->opened`, and killing `dev->int_in_urb` and `dev->submitted`; `adu_probe` must pin `usb_get_dev` (released in `adu_delete`). [F164, F165, F170, F171, F192]
- In `uss720.c`, `submit_async_request()` must initialize `rq->ref_count` and `rq->compl`, increment `priv->ref_count`, link `rq->asynclist` under `priv->asynclock`, and take the completion callback's `kref_get(&rq->ref_count)` before `usb_submit_urb()`, returning with two `rq->ref_count` references so callers must call `kref_put(&rq->ref_count, destroy_async)`. `uss720_disconnect` must set `priv->pp = NULL`, remove/put the `parport`, call `kill_all_async_requests_priv(priv)`, and drop `priv->ref_count` without clearing `priv->usbdev` (released in `destroy_priv`). [F167, F168, F199, F298]

## API Contracts

- In `lpc32xx_udc.c`, `net2280.c`, and `omap_udc.c`, DMA endpoints must call `usb_gadget_map_request()` in `.queue` before taking the controller lock and `usb_gadget_unmap_request()` in `done()` before dropping the lock for `usb_gadget_giveback_request()`; in `lpc32xx_udc.c`, `udc_dd_alloc()` must use `GFP_ATOMIC | GFP_DMA`. In all five UDC drivers, `.udc_start` must not clear or modify `driver->driver.bus`. [F143, F152, F156]
- Across `drivers/usb/misc/`, `usb_control_msg()` requires a DMA-capable heap buffer (never stack or `firmware->data` pointers unless `usb_control_msg_send()`/`recv()` is used), a `bRequestType` direction bit matching the pipe, and millisecond timeouts (never `* HZ`). `emi26_probe()` and `emi62_probe()` must return `-EIO` after loading firmware; and atomic `parport_operations` in `uss720.c` (`parport_uss720_frob_control`, `parport_uss720_restore_state`) must pass `GFP_ATOMIC` and `val = NULL` to `get_1284_register()`. [F215, F216, F290, F325, F341]

## Error Handling

- In `lpc32xx_ep_*`, `ep = container_of(_ep, struct lpc32xx_ep, ep)` is computed before NULL checks, so `ep->udc` must not be dereferenced before verifying `_ep`/`ep`. In `net2280_*`, the initial `!_ep` check must return via `pr_err` rather than `goto print_err` (which dereferences `ep->dev->pdev->dev`). In `lpc32xx_ep_dequeue`, `max3420_ep_dequeue`, `net2280_dequeue`, and `omap_ep_dequeue`, `list_for_each_entry` must save a match into a separate `NULL`-initialized pointer before `break` rather than testing the loop cursor after the loop. [F35, F46, F86]
- In `usbtest.c`, `usbtest_ioctl()` must check `if (retval < 0)` after `usbtest_do_ioctl()` because `ctrl_out()` returns a positive byte count; in `ctrl_complete()`, `status = ctx->status` must be restored after `usb_unlink_urb()` (called with `ctx->lock` dropped via `spin_unlock(&ctx->lock)` while keeping IRQs disabled); and `usbtest_do_ioctl()`/`test_queue()`/`test_ctrl_queue()` must validate `param->sglen <= MAX_SGLEN`, `param->sglen > 0`, `param->iterations <= UINT_MAX / param->sglen`, and `param->sglen >= 4` for `unlink_queued()`. [F200, F211, F243, F330]

## External Contracts

- In `mon_bin.c`, `mon_bin_mmap()` must reject `VM_WRITE` with `-EPERM` and clear `VM_MAYWRITE` via `vm_flags_mod()`; every `struct mon_bin_hdr` slot must be zeroed with `memset(ep, 0, PKT_SIZE)` and `dp->_pad = 0` set in `mon_bin_get_isodesc()`; and 64-bit pointer ioctls must have matching compat handlers in `mon_bin_compat_ioctl()`. In `mon_text_add()`, debugfs files must use mode `0600`. In `usbtest_ioctl()`, both `USBTEST_REQUEST_32` and `USBTEST_REQUEST_64` must be supported. [F212, F332, F337, F338, F342]

## Known Pitfalls

- In `lpc32xx_udc.c`, `udc->ep[]` is indexed by logical `ep->lep` while `udc->udca_v_base[]`, protocol commands, and hardware bitmasks use `ep->hwep_num` (`0..31`); `udc_pop_fifo`/`udc_stuff_fifo` unaligned byte loops must shift by `i * 8` (not `n * 8`) with `bl` capped to `4`; and bounded register polling loops in `lpc32xx_udc.c` and `m66592-udc.c` must join state check and timeout with `&&`, not `||`. In `max3420_udc.c`, `DISABLE` (`3 << 7`) contains `ENABLE` (`1 << 7`) under `ENABLE_EP` and `UNSTALL` (`3 << 9`) contains `STALL` (`1 << 9`) under `STALL_EP`, so `ep->todo` updaters must clear the 2-bit mask first, and `spi_max3420_enable`/`spi_max3420_stall` must test `todo` with `==` rather than `&` and return early when `ep->id == 0`. [F75, F83, F84, F85, F94]
- In `mon_text.c`, `mon_text_ctor()` poisons `mon_event_text` with `0xe5`, so `mon_text_read_u()` must check `ep->type == 'E'` before branching on `ep->xfertype`, `mon_text_read_*` must guard `setup`/`data`/`isodesc` on `setup_flag == 0` and `data_flag == 0` while clamping `numdesc` to `ISODESC_MAX` (5) and `length` to `DATA_MAX` (32), and text formatting must use `scnprintf()` (never `snprintf()`). In `mon_stop()`, `mbus` is reused as the `list_for_each_entry` cursor when `mbus == &mon_bus0` and must not be dereferenced after the loop. [F213, F240, F241, F268]
