# USB WEBCAM GADGET

Implements the USB Video Class (UVC) gadget function (`f_uvc`) and legacy composite webcam driver (`g_webcam`), enabling a Linux device with a USB Device Controller (UDC) to present itself as a UVC video source to a USB host via a V4L2 video output device (`VFL_DIR_TX`), custom V4L2 events/ioctls, videobuf2 (`dma-sg` or `vmalloc`), and configfs descriptor hierarchies.

## Architecture & Data Flow

- In `struct uvc_video`, `video->ureqs` links `struct uvc_request` via `ureq->list`, whereas `video->req_free` and `video->req_ready` link `struct usb_request` via `req->list`; converting a `struct usb_request *` to its owning `struct uvc_request *` must use `req->context` rather than `container_of()`. [F104]
- `video->max_payload_size` must remain `0` for isochronous endpoints and non-zero only for bulk endpoints, as `uvcg_video_enable()`, `uvcg_video_pump()`, `uvcg_video_hw_submit()`, and `uvcg_video_usb_req_queue()` test it as a boolean to select bulk vs isochronous encoding and queueing paths. [F46]
- `uvcg_queue_init()` sets `queue->use_sg = 1` with `vb2_dma_sg_memops` when `cdev->gadget->sg_supported` is true (`vb2_vmalloc_memops` otherwise); `buf->sgt` and `buf->sg` are populated only when `queue->use_sg` is set (`buf->mem` is NULL) and `buf->mem` only when `queue->use_sg` is false, and `uvc_buffer_prepare()` must reset `buf->sg = buf->sgt->sgl` on every SG buffer preparation because `uvc_video_encode_isoc_sg()` advances `buf->sg` to `NULL`. [F33, F45, F134]
- In `uvc_video_encode_isoc_sg()`, `ureq->sgt.sgl[0]` holds `ureq->header` and the payload loop iterates `for_each_sg(sg_next(ureq->sgt.sgl), iter, ureq->sgt.nents - 1, i)` using unmapped `buf->sg->length` (never `sg_dma_len(buf->sg)`), setting `req->num_sgs = i + 1` and advancing `buf->sg` only when `part == buf->sg->length - buf->offset`. [F80, F130]
- When an encode callback (`uvc_video_encode_bulk()`, `uvc_video_encode_isoc()`, or `uvc_video_encode_isoc_sg()`) finishes a `uvc_buffer`, it must under `queue->irqlock` reset `video->queue.buf_used = 0` (and `buf->offset = 0` for SG), set `buf->state = UVC_BUF_STATE_DONE`, unlink `buf->queue`, toggle `video->fid`, and set `ureq->last_buf = buf`; `uvcg_queue_cancel()` and `uvcg_queue_enable()` must also reset `queue->buf_used = 0`. [F39, F42]
- In `uvcg_video_pump()`, loop exits inside `while (true)` before dequeueing `req` from `video->req_free` must use `return`, whereas exits after `list_del(&req->list)` and before `uvcg_video_usb_req_queue()` succeeds must use `break` so post-loop cleanup returns `req` to `video->req_free` or frees it. [F76]
- When `video->req_ready` is empty in `uvcg_video_hw_submit()`, the `while (true)` loop must stop and return once `video->req_free` is empty or `atomic_read(&video->queued) > UVCG_REQ_MAX_ZERO_COUNT` before taking a request from `video->req_free` as a zero-length request. [F77]
- In `uvc_video_complete()`, a missed isochronous transfer (`req->status == -EXDEV`) must set `UVC_QUEUE_DROP_INCOMPLETE` on `queue->flags` only when `req->length != 0`, and `uvcg_complete_buffer()` must clear `UVC_QUEUE_DROP_INCOMPLETE` when completing the affected buffer. [F81]
- `uvc_video_prep_requests()` and `uvc_buffer_prepare()` must use `DIV_ROUND_UP()` when computing `nreq`, `video->req_size`, `video->reqs_per_frame`, and `buf->req_payload_size`, keeping `buf->req_payload_size` and `video->req_size` at least `UVCG_REQUEST_HEADER_LEN` (12 bytes); `uvcg_video_usb_req_queue()` must also use `DIV_ROUND_UP(video->uvc_num_requests, 4)` so the interrupt modulus divisor is at least 1 when `uvc_num_requests < 4`. [F68, F88, F89]
- In `uvc_function_bind()`, `opts->streaming_maxpacket` must be rounded up to 1024 when `opts->streaming_maxburst > 0` and clamped to `[1U, 3072U]` before dividing by `max_packet_mult` (1..3) so `max_packet_size <= 1024` fits in bits 10:0 of `uvc_hs_streaming_ep.wMaxPacketSize` (forcing `uvc_hs_streaming_ep.bInterval = 1` when `max_packet_mult > 1`); `gadget_is_superspeed()` must be tested before `gadget_is_dualspeed()`, and `uvc->video.ep->address`, `usb_gstrings_attach()`, and `usb_interface_id()` must be populated before `uvc_copy_descriptors()`. [F53, F74, F83, F91]
- In `uvc_copy_descriptors()`, all input/output descriptor pointer arrays must be `NULL`-terminated, every descriptor and extension unit copied in pass 2 must be counted in pass 1 (`n_desc`, `bytes`, `control_size`/`streaming_size`, with `uvc_control_desc[0]` and `uvc_streaming_cls[0]` first), and dynamic header fields (`wTotalLength`, `bInCollection`, `baInterfaceNr[0]`, `bEndpointAddress`) must be patched on the allocated `mem` copy rather than `uvc->desc`. [F54, F66, F82]
- `uvc_v4l2_enum_format()` and `uvc_v4l2_enum_framesizes()` must bounds-check the 0-based V4L2 `index` against `uvc->header->num_fmt` and `uformat->num_frames` and pass `index + 1` to 1-based `find_format_by_index()` and `find_frame_by_index()`, whereas `uvc_v4l2_enum_frameintervals()` must check `fival->index < uframe->frame.b_frame_interval_type` and index 0-based `uframe->dw_frame_interval[fival->index]` directly. [F63, F86]
- `uvc_function_setup()` must reject USB control requests with `le16_to_cpu(ctrl->wLength) > UVC_MAX_REQUEST_SIZE` (64 bytes) before recording `uvc->event_length`, and `uvc_function_ep0_complete()` must clamp the copy from `req->buf` into `uvc_event->data.data` with `min_t(unsigned int, req->actual, sizeof(uvc_event->data.data))` (60 bytes). [F57, F58]
- In `struct uvcg_streaming_header`, `desc` must remain the final member (ending with flexible array `bmaControls[]`), and because `uvcg_streaming_header` is allocated with `kzalloc(sizeof(*h))`, per-format `bmaControls` must be stored in each `struct uvcg_format` and only appended after `sizeof(h->desc)` when `__uvcg_fill_strm()` serializes `UVCG_HEADER`. [F71, F96]
- In `__uvcg_cnt_strm()` and `__uvcg_fill_strm()`, the fixed frame descriptor header size before `dwFrameInterval` is `sizeof(frm->frame) - 4`, and `UVCG_FRAMEBASED` frames must be serialized with `__uvcg_copy_framebased_desc()` because `struct uvc_frame_framebased` omits `dwMaxVideoFrameBufferSize`. [F70]
- Every configfs struct using `uvcg_config_item_release()` must place its `config_item`, `config_group`, or `uvcg_format` member at offset 0; callers downcasting `struct uvcg_format` via `to_uvcg_*()` must first check `uformat->type`; and every configfs `allow_link` callback must validate `target->ci_parent` before downcasting `target`. [F101, F102, F103]
- `uvcg_streaming_header_allow_link()` must call `uvcg_format_set_indices()` and increment `src_hdr->num_fmt` and `target_fmt->linked` (reverted in `drop_link`), and every `struct uvcg_format` must hold a `color_matching->refcnt` reference to `streaming/color_matching/default` (or a linked `uvcg_color_matching` group), while `uvcg_color_matching` stores reject changes with `-EBUSY` when `refcnt > 0`. [F56, F147]
- Changing `xu->desc.bNrInPins` or `xu->desc.bControlSize` on `struct uvcg_extension` must reallocate `baSourceID` or `bmControls` and recompute `xu->desc.bLength = UVC_DT_EXTENSION_UNIT_SIZE(...)` under `opts->lock`; fixed-size `bmControls` stores (`uvcg_default_processing_bm_controls_store()`, `uvcg_default_camera_bm_controls_store()`) must check `__uvcg_count_item_entries()` against `bControlSize` before copying. [F48, F60]
- 16-byte binary GUID fields (`guidFormat`, `guidExtensionCode`) have no NUL terminator and must be accessed with fixed-length `memcpy()`, and `uvcg_uncompressed_guid_format_store()` must validate `uvc_format_by_guid()` on a temporary buffer before overwriting `ch->desc.guidFormat` while `ch->fmt.linked` and `opts->refcnt` are zero. [F55, F106]

## Synchronization

- `video->req_lock` and `queue->irqlock` are shared across UDC interrupt context, workqueues, and V4L2 process context, so every acquisition of either lock must use `spin_lock_irqsave()` / `spin_unlock_irqrestore()`, and the two locks must never be nested: `uvc_video_complete()`, `uvcg_video_pump()`, and `uvcg_video_disable()` must drop `video->req_lock` before calling `cancel_work_sync(&video->pump)`, `uvcg_queue_cancel()`, `uvcg_complete_buffer()`, or acquiring `queue->irqlock`. [F16, F17, F120, F122]
- Whenever the video stream may be active, accesses to `video->req_free`, `video->req_ready`, `video->ureqs`, and `video->req_int_count`, as well as calls to `uvcg_video_usb_req_queue()` and `uvc_video_free_request()`, must hold `video->req_lock`; because `video->req_lock` disables interrupts, `uvcg_video_ep_queue()` must call `usb_ep_queue()` with `GFP_ATOMIC`. [F18, F121]
- After dropping and re-acquiring `video->req_lock` in `uvc_video_complete()` or `uvcg_video_pump()`, the caller must recheck `video->is_enabled` and call `uvc_video_free_request()` instead of returning `req` to `video->req_free` (or queueing `video->pump`) if `video->is_enabled` is `false`. [F19]
- `uvcg_video_usb_req_queue()` must only pass `queue_to_ep = true` from a single thread per endpoint type—`uvcg_video_pump()` when `video->max_payload_size` is non-zero (bulk) and `uvcg_video_hw_submit()` when `video->max_payload_size` is zero (isoc)—under `video->req_lock`. [F26]
- `uvcg_complete_buffer()`, `uvcg_queue_head()`, and `video->encode()` must only be called while holding `queue->irqlock`, and in `uvc_buffer_queue()` and `uvcg_queue_cancel()`, checking or setting `UVC_QUEUE_DISCONNECTED` in `queue->flags` and modifying `queue->irqqueue` must happen atomically within the same `queue->irqlock` critical section. [F20, F123]
- In `uvc_configfs.c`, callbacks that navigate the configfs hierarchy (`ci_parent` or `config_group_find_item()`) and access `struct f_uvc_opts` must acquire `cg_subsys->su_mutex` before `opts->lock`, matching the lock order when configfs holds `su_mutex` across `.make_item` and `.drop_item` callbacks. [F127]

## Object Lifetimes

- `uvcg_video_usb_req_queue()` must not free `req->context` or add `req` to any list when returning a negative error code; ownership of `req` remains with the caller (`uvcg_video_pump()` or `uvcg_video_hw_submit()`) on failure. [F1]
- `uvcg_video_enable()` must call `uvcg_queue_enable(&video->queue, 1)`, `uvc_video_alloc_requests()`, and set `video->encode` before queueing `video->hw_submit` and `video->pump`; `uvcg_video_disable()` must under `video->req_lock` set `video->is_enabled = false`, move non-NULL `ureq->last_buf` from `video->ureqs` to `inflight_bufs`, unlink `video->ureqs` with `list_del_init()`, and free only `req_free`/`req_ready` requests (leaving in-flight ones to `uvc_video_complete()`), then drop `req_lock`, cancel `pump` and `queue`, and complete `inflight_bufs` before `uvcg_queue_enable(&video->queue, 0)`. [F3, F13, F44, F110, F111]
- When `uvc_v4l2_subscribe_event()` subscribes a file handle to `UVC_EVENT_SETUP`, it sets `uvc->func_connected = true` and `handle->is_uvc_app_handle = true`, and `uvc_v4l2_unsubscribe_event()` must clear `handle->is_uvc_app_handle = false` after calling `uvc_v4l2_disable(uvc)` so `uvc_v4l2_release()` does not disable `uvc` a second time. [F47]
- Because `(*class_array)[0]` owns the contiguous buffer backing all descriptors in `*class_array`, `uvcg_streaming_class_allow_link()` must `kfree(data_save)` (not the advanced `data` cursor) on failure, and `uvcg_streaming_class_drop_link()` must `kfree(**class_array)` before `kfree(*class_array)` and setting `*class_array = NULL`; on function release, `uvc_func_item_release()` must call `uvcg_config_remove_children()` before `usb_put_function_instance(&opts->func_inst)`. [F7, F11]

## API Contracts

- Both `uvc->vdev.lock` and `uvc->video.queue.queue.lock` are assigned `&uvc->video.mutex` to serialize V4L2 ioctls and videobuf2 callbacks, and `uvc_v4l2_release()` must explicitly acquire `video->mutex` around `uvc_v4l2_disable()` because `v4l2_file_operations.release` is invoked by V4L2 core without holding `vdev.lock`. [F132]
- `uvcg_queue_enable()` invokes `vb2_streamon()` / `vb2_streamoff()` and must never be called from interrupt context; interrupt callbacks such as `uvc_video_complete()` must call `uvcg_queue_cancel()` instead. [F125]
- `uvc_v4l2_set_format()` must validate and normalize the requested `struct v4l2_format` via `uvc_v4l2_try_format()` against `uvc->header->formats` before updating `video` format and geometry fields, and `uvc_video_alloc_requests()` must allocate at least `DIV_ROUND_UP(video->req_size - UVCG_REQUEST_HEADER_LEN, PAGE_SIZE) + 2` scatterlist entries per `uvc_request` in `sg_alloc_table()`. [F41, F90]
- `opts->header` in `struct f_uvc_opts` must be `NULL` for configfs gadgets and non-NULL only for legacy gadgets (`webcam_bind()`), as `uvc_alloc()` skips configfs header lookup when set and `uvc_free()` only calls `config_item_put(&uvc->header->item)` when `NULL`; `uvc_video_encode_header()` must check `cdev->gadget->ops->get_frame` before calling `usb_gadget_frame_number()`. [F117, F141]

## Error Handling

- `to_uvc_format()` returns an `ERR_PTR` rather than `NULL` on failure, so callers must check `IS_ERR()`; in `uvc_send_response()`, the signed `data->length < 0` check must precede unsigned `min_t()` / comparisons with `uvc->event_length`; and in `uvcg_video_ep_queue()`, `usb_ep_set_halt(video->ep)` must only be called if `video->ep->desc` is non-NULL and `usb_endpoint_xfer_bulk(video->ep->desc)` is true. [F27, F92, F144]

## External Contracts

- In UVC streaming descriptor arrays (`webcam.c` and `__uvcg_iter_strm_cls()`), a `uvc_color_matching_descriptor` must immediately follow each format's frame descriptors; `video->interval` and `dw_frame_interval` use 100ns units (`10000000`/s, with `bInterval` scaled by `1250` for HS/SS or `10000` for FS in `uvc_video_prep_requests()`); and `uvc_function_set_alt()` streaming transitions must return `USB_GADGET_DELAYED_STATUS` completed by `uvc_function_setup_continue()` in `uvc_v4l2_streamon()` / `uvc_v4l2_streamoff()`. [F72, F119, F139]
- Stack-allocated `struct v4l2_event` instances in `f_uvc.c` must be zeroed with `memset()` before `v4l2_event_queue()`, `uvc_function_setup()` must reject non-`USB_TYPE_CLASS` requests with `-EINVAL` and normalize the low byte of `uvc_event->req.wIndex` to `0` or `UVC_STRING_STREAMING_IDX` (`1`), and `UVCG_OPTS_STRING_ATTR()` stores must pass `size = min(sizeof(opts->aname), len + 1)` to `strscpy()` and map `-E2BIG` to `size - 1`. [F105, F135, F138]

## Known Pitfalls

- Callers of `__uvcg_iter_item_entries()` with `__uvcg_fill_item_entries` (which requires element `size` in `1..sizeof(unsigned int)`) and `__uvcg_iter_strm_cls()` with `__uvcg_fill_strm` must pass the address of a disposable cursor copy rather than the base allocation pointer; `__uvcg_iter_item_entries()` must bound copies into `char *buf` with `bufsize` rather than `sizeof(buf)`; and `uvc_video_encode_header()` must cast `ts.tv_sec` to `u64` and divide `ts.tv_nsec / NSEC_PER_USEC` on `struct timespec64` to avoid 32-bit truncation and 64-bit division link errors. [F84, F87, F93, F98]
