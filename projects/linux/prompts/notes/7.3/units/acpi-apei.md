# ACPI APEI

The ACPI Platform Error Interface (APEI) subsystem provides core infrastructure for firmware-first hardware error reporting, serialization, and injection, including the action table interpreter and GAR resource manager (`apei-base.c`), BERT and HEST parsers, GHES notification and CPER dispatchers (`ghes.c`), EINJ and CXL error injection (`einj-core.c`, `einj-cxl.c`), and the ERST debug miscdevice (`erst-dbg.c`).

## Architecture & Data Flow
- Variable-length `ghes_estatus_pool` allocations (`struct ghes_estatus_cache`, `struct ghes_estatus_node`, `struct ghes_vendor_record_entry`) place payloads right after the header struct and recompute `gen_pool_free()` size via `cper_estatus_len()` or `acpi_hest_get_record_size()`. Never mutate `raw_data_offset`, `raw_data_length`, `data_length`, `revision`, or `error_data_length` before freeing, and in `ghes_proc_in_irq()` save `llnode->next` and `node_len` before `gen_pool_free()`. [F67, F114]
- In `struct ghes`, `list`, `timer`, and `irq` share a union selected by `ghes->generic->notify.type`, while `ghes->elist` links into `ghes_devs` under `ghes_devs_mutex`. Also, `generic` and `generic_v2` alias the same HEST subtable pointer; only access `ghes->generic_v2` (`read_ack_register`, `read_ack_preserve`, `read_ack_write`) or call `map_gen_v2()`, `unmap_gen_v2()`, or `ghes_ack_error()` when `is_hest_type_generic_v2(ghes)` is true. [F64, F119]
- In `hest.c`, every HEST type with `-1` in `hest_esrc_len_tab[]` must be handled in `hest_esrc_len()` (`BUG_ON(len == -1)`), which computes its variable length and caches IA-32 MCA descriptors in `mces` (`cmc`, `mc`, `dmc`) so `is_ghes_assist_struct()` skips the parser callback on subsequent GHES/GHESv2 entries matching an MCA `related_source_id` with `ACPI_HEST_GHES_ASSIST` set. [F60, F129]
- Every `generic->notify.type` accepted by the validation switch in `ghes_probe()` must also be handled in both the registration switch in `ghes_probe()` and the teardown switch in `ghes_remove()` (both end with `default: BUG()`). [F101]
- In `__apei_exec_run()` and `apei_exec_for_each_entry()`, verify `entry->instruction < ctx->instructions` and `ctx->ins_table[entry->instruction].run != NULL`. In `__apei_exec_run()`, increment `ip` only for entries matching `action`; callbacks return negative errno on error, `0` to advance `ctx->ip` by 1, or `APEI_EXEC_SET_IP` (1) if `ctx->ip` was set directly (which skips auto-increment and jumps to `rewind` to reset `ip = 0` if `ctx->ip < ip` after `ip++`). [F28, F68, F90]
- Reading a GHES status block (`ghes_read_estatus()`, `ghes_in_nmi_queue_one_entry()`) must peek `sizeof(struct acpi_hest_generic_status)` bytes via `__ghes_peek_estatus()` and validate with `__ghes_check_estatus()` before reading `cper_estatus_len()` bytes with `__ghes_read_estatus()`. [F74]
- In `einj-core.c`, `error_type_set()` must update `is_v2` based on the `"V2_"` prefix, and `error_inject_set()` must sync `SETWA_FLAGS_EINJV2` in `error_flags` with `is_v2` before `einj_error_inject()`. In `einj-cxl.c`, `einj_cxl_error_type_string[]` must stay in lockstep with `ACPI_EINJ_CXL_CACHE_CORRECTABLE << pos` in `einj_cxl_available_error_type_show()`. [F56, F58]
- In `bert_print_all()`, check `remain >= sizeof(struct acpi_bert_region)`, `estatus_len <= remain`, and `cper_estatus_check(estatus)` before advancing. Cap printing at `ACPI_BERT_PRINT_MAX_RECORDS` (5) and skip printing records with individual `estatus_len >= ACPI_BERT_PRINT_MAX_LEN` (1024), while still clearing `estatus->block_status = 0` on every valid record. [F70, F71, F166]

## Synchronization
- Hold `ghes_notify_lock_irq` with `spin_lock_irqsave` across every call to `ghes_proc()` (`ghes_poll_func()`, `ghes_irq_func()`, `ghes_notify_hed()`, `ghes_probe()`) to serialize per-device `ghes->estatus` and `FIX_APEI_GHES_IRQ`. [F16]
- NMI-like GHES handlers (`ghes_notify_sea()`, `ghes_notify_nmi()`, `ghes_sdei_normal_callback()`, `ghes_sdei_critical_callback()`) must hold their dedicated raw spinlock across `ghes_in_nmi_spool_from_list()` or `__ghes_sdei_callback()` to serialize their `FIX_APEI_GHES_*` slot. `ghes_notify_nmi()` must also gate entry with `atomic_add_unless(&ghes_in_nmi, 1, 1)` and `atomic_dec(&ghes_in_nmi)` on exit. [F17, F18]
- `ghes_in_nmi_queue_one_entry()` must never use `ghes->estatus` or call `ghes_do_proc()` directly; it must peek into stack `tmp_header`, allocate `struct ghes_estatus_node` from `ghes_estatus_pool`, populate it via `__ghes_read_estatus()`, call `ghes_clear_estatus()` with `&tmp_header` (not `estatus`, which zeroes the queued node's `block_status`), and call `llist_add(&estatus_node->llnode, &ghes_estatus_llist)`. Consumers (`ghes_proc_in_irq()`, `ghes_print_queued_estatus()`) must call `llist_reverse_order()` after `llist_del_all()`. [F23, F62, F100, F140]
- Because `ghes_do_proc()` and `ghes_estatus_cache_add()` run in atomic contexts, allocations in `ghes_do_memory_failure()`, `ghes_handle_aer()`, `ghes_defer_non_standard_event()`, and `ghes_estatus_cache_alloc()` must use `gen_pool_alloc(ghes_estatus_pool, ...)` and `gen_pool_free()`. Non-standard CPER sections must be copied into a pool entry by `ghes_defer_non_standard_event()` and deferred via `schedule_work()` so `blocking_notifier_call_chain(&vendor_record_notify_list, ...)` runs in process context. [F25, F142]
- Read `ghes_estatus_caches[]` under `rcu_read_lock()` in `ghes_estatus_cached()`, publish in `ghes_estatus_cache_add()` via `xchg_release(&ghes_estatus_caches[slot], RCU_INITIALIZER(new_cache))`, and free via `call_rcu(&unrcu_pointer(victim)->rcu, ghes_estatus_cache_rcu_free)`. `ghes_estatus_cache_alloc()` increments `ghes_estatus_cache_alloced` upfront and must decrement it on both failure paths and in `ghes_estatus_cache_rcu_free()`. [F13, F147]
- Serialize `ghes_hed`, `ghes_sea`, and `ghes_nmi` mutations with `ghes_list_mutex` using `list_add_rcu()` / `list_del_rcu()`, and call `synchronize_rcu()` in removal paths (`ghes_remove()`, `ghes_sea_remove()`, `ghes_nmi_remove()`) before `ghes_fini()` and `kfree(ghes)`. [F19]
- Hold `einj_mutex` across all runtime calls to `__einj_get_available_error_type()` and `__einj_error_inject()` to serialize bytecode execution and `einj_param` MMIO. Hold `erst_dbg_mutex` in `erst_dbg_read()` and `erst_dbg_write()` across size checks, `erst_dbg_buf` reallocations (checking `kmalloc()` before `kfree(erst_dbg_buf)` and updating `erst_dbg_buf_len`), ERST calls, and user copies. [F9, F26, F27]

## Object Lifetimes
- In `ghes_probe()`, `ghes_new()` pre-maps GARs and allocates `ghes->estatus` before registering notifications; if `IS_ERR(ghes)`, reset `ghes = NULL` before `goto err`. In `ghes_remove()`, set `GHES_EXITING` and synchronously stop notifications (`timer_shutdown_sync()`, `free_irq()`, `list_del_rcu()` + `synchronize_rcu()`, or `apei_sdei_unregister_ghes()`) before `ghes_fini(ghes)` and `kfree(ghes)`, returning early without freeing if `apei_sdei_unregister_ghes()` fails. [F10, F11, F20, F21, F46]
- In `hest_parse_ghes()`, free `ghes_dev` with `platform_device_put()` if `platform_device_add_data()` or `platform_device_add()` fails; once in `ghes_arr.ghes_devs`, rollback in `hest_ghes_dev_register()` must call `platform_device_unregister()`. [F5]
- `apei_resources_request()` mutates `struct apei_resources` in-place (subtracting `apei_resources_all`, NVS, and `arch_apei_filter_addr` regions before requesting and merging into `apei_resources_all`), so pass the same struct to `apei_resources_release()` before `apei_resources_fini()`. [F127]
- Release `acpi_get_table()` references via `acpi_put_table()` on all exit paths in `bert_init()`, on probe failure and in `einj_remove()` for `einj_tab`, and on failure in `acpi_hest_init()`—but keep `hest_tab` mapped on `acpi_hest_init()` success because GHES devices reference entries inside it. [F131]
- In `acpi_hest_init()`, `hest_ghes_dev_register()` must call `ghes_estatus_pool_init()` before `acpi_ghes_init()` calls `ghes_nmi_init_cxt()` and `platform_driver_register(&ghes_platform_driver)`, and `apei_osc_setup()` (which must `kfree(context.ret.pointer)` when `acpi_run_osc()` succeeds) must run after driver registration. In `ghes_estatus_pool_init()`, call `gen_pool_destroy()` on `vmalloc()` failure, and `vfree()` before `gen_pool_destroy()` on `gen_pool_add()` failure. [F8, F14, F122]
- `ghes_handle_aer()` must allocate `aer_capability_regs` for `aer_recover_queue()` from `ghes_estatus_pool` (freed via `ghes_estatus_pool_region_free()`), and override `aer_severity` to `AER_FATAL` when `gdata->flags & CPER_SEC_RESET` is set. [F160]

## API Contracts
- Validate all GARs through `apei_check_gar()` (reads `reg->address` via `get_unaligned()`, checks `access_width` in `1..4`, `bit_width + bit_offset <= access_bit_width`, and `SYSTEM_MEMORY`/`SYSTEM_IO`). Pass `access_bit_width / 8` (bytes, not `reg->bit_width / 8` or bits) to `apei_res_add()` / `apei_resources_add()` in `collect_res_callback()`. [F31, F109, F132]
- `apei_read()` and `apei_write()` use unshifted values, whereas `__apei_exec_read_register()` and `__apei_exec_write_register()` apply `entry->mask` and shift by `bit_offset` (preserving unmasked bits via `apei_read()` when `APEI_EXEC_PRESERVE_REGISTER` is set). In `ghes_clear_estatus()`, zero `estatus->block_status` in physical memory via `ghes_copy_tofrom_phys()` (when `buf_paddr != 0`) before `ghes_ack_error()` writes `read_ack_register` with `read_ack_preserve << bit_offset` and `read_ack_write << bit_offset`. [F30, F133, F134]
- Because a CPER section header is `struct acpi_hest_generic_data_v300` when `acpi_hest_get_version(gdata) >= 3`, always use `acpi_hest_get_payload()`, `acpi_hest_get_size()`, `acpi_hest_get_record_size()`, and `acpi_hest_get_next()` instead of `gdata + 1` or `sizeof(*gdata)`. [F115]
- `ghes_report_chain` notifiers (`ghes_register_report_chain()`) run via `atomic_notifier_call_chain()` in `ghes_do_proc()` under `ghes_notify_lock_irq` or `irq_work` and must not sleep. For `is_hest_sync_notify(ghes)` (`ACPI_HEST_NOTIFY_SEA`), `ghes_do_memory_failure()` queues `memory_failure_cb` onto `current` via `task_work_add(..., TWA_RESUME)` when `flags == MF_ACTION_REQUIRED && current->mm`, and `ghes_do_proc()` calls `force_sig(SIGBUS)` if `sync && !queued`. [F144, F159]
- `ghes_in_nmi_spool_from_list()` and `ghes_notify_hed()` must traverse every RCU list entry without breaking early on the first active source; `ghes_in_nmi_spool_from_list()` and `ghes_notify_sea()` return `0` if any source reported an error (`-ENOENT` otherwise), and `ghes_notify_nmi()` translates `0` to `NMI_HANDLED` (`NMI_DONE` otherwise). [F49, F102]
- `ghes_get_devices()` must return `NULL` (not `&ghes_devs`) when `list_empty(&ghes_devs)` on non-x86 or when an x86 platform is not in `plat_list` (which must end with a `{ }` sentinel) and `ghes_edac_force_enable` is false. [F48, F79]
- `einj_error_inject()` rejects `einj_is_cxl_error_type(type) && (flags & SETWA_FLAGS_MEM)`, whereas `einj_cxl_rch_error_inject()` requires both so CXL RCRB MMIO injections bypass `is_allowed_range()` only via `einj_cxl_inject_rch_error()`. In `cxl_dport_get_sbdf()` and `check_vendor_extension()`, `pcie_sbdf` encodes segment [31:24], bus [23:16], dev [15:11], fn [10:8] (`devfn << 8`), and 0 in [7:0]; `cxl_dport_get_sbdf()` must check `bridge->domain_nr == PCI_DOMAIN_NR_NOT_SET` before assigning `u64 seg` and shift as `u64`. [F39, F103, F153]
- `hest_parse_cmc()` returns `!arch_apei_enable_cmcff()`, so `arch_apei_enable_cmcff()` must return non-zero (`1`) on success. In `hest_parse_ghes()`, `platform_device_add_data(ghes_dev, &hest_hdr, sizeof(void *))` stores a double pointer, so dereference `*(struct acpi_hest_generic **)ghes_dev->dev.platform_data`. `cxl_cper_kfifo_get()` and `cxl_cper_prot_err_kfifo_get()` return `1` when dequeued and `0` when empty. [F34, F47, F120]
- When ACPI is enabled, `einj_init()` must return `0` even if `faux_device_create()` returns `NULL` (recording probe success in `einj_initialized` for `einj_cxl_is_initialized()`); `acpi_ghes_init()` must call `acpi_sdei_init()` before early returns on `acpi_disabled`, `hest_disable`, or `ghes_disable`. [F152, F162]

## Error Handling
- In `apei_resources_request()`, set `rc = -EINVAL` before request loops and record the failing entry in `res_bak`. `err_unmap_ioport` releases regions prior to `res_bak`, must reset `res_bak = NULL` before falling through to `err_unmap_iomem`, and rollback must always call `apei_resources_fini()` on `arch_res` (if `arch_apei_filter_addr` is set) and `nvs_resources`. [F2, F32, F93]
- If `apei_exec_pre_map_gars()` fails at index `end`, unmap only `[0, end)` by passing a shallow copy of `ctx` with `entries = end` to `apei_exec_post_unmap_gars()`, without mutating `ctx->entries`. `apei_map_generic_address()` must return `0` after `apei_check_gar()` for `ACPI_ADR_SPACE_SYSTEM_IO` before calling `acpi_os_map_generic_address()`. [F3, F29]
- In `__einj_error_trigger()`, initialize `p = NULL` and set/reset `rc = -EIO` before calls that jump to `out*` labels, validate the header with `einj_check_trigger_header()` before allocating `full_trigger_tab` or remapping `table_size`, call `iounmap(p)` on the initial header mapping before the second `ioremap_cache()`, and guard `if (p) iounmap(p)` at `out:`. [F6, F36, F81]
- `__ghes_peek_estatus()` must set `*buf_paddr = 0` on error or when `estatus->block_status == 0` so callers' unconditional `ghes_clear_estatus()` skips physical writes. On a `ghes_estatus_cached()` hit, `ghes_in_nmi_queue_one_entry()` clears the status block and frees the node without queueing, whereas `ghes_proc()` only skips `ghes_print_estatus()` and still runs `ghes_do_proc()`. [F45, F164]

## External Contracts
- When `param_extension` or `acpi5` is enabled, `einj_error_inject()` requires memory targets to have `(param2 & PAGE_MASK) == PAGE_MASK`, `!is_zero_pfn(base_addr >> PAGE_SHIFT)`, and `[param1 & param2, + (~param2 + 1))` allowed by `is_allowed_range()`. `einj_validate_error_type()` requires `!(type & GENMASK_ULL(63, 32))`, at most one bit in `0..30`, and (if `ACPI5_VENDOR_BIT` is clear) intersection with `available_error_type | available_error_type_v2`. [F154, F155]
- `einj_check_table()` must accept `header_length` equal to `sizeof(struct acpi_table_einj) - sizeof(einj_tab->header)` or `sizeof(struct acpi_table_einj)` and verify `entries` count; `einj_get_parameter_address()` must unmap and reject v4 parameter blocks with non-zero `reserved1` or `reserved2`. [F80, F83]
- `u128_read()` and `u128_write()` serialize 16-byte `syndrome_data` in reverse byte order (filling with `0xFF` on empty newline `c == 1` for `is_end_of_list()`); `u128_write()` must store `simple_write_to_buffer()` in signed `ssize_t c` and use pre-increment `while (++i < COMPONENT_LEN)` when zero-filling after `break` on `e <= s`. [F40, F87, F97]
- `/dev/erst_dbg`: `erst_dbg_write()` requires `capable(CAP_SYS_ADMIN)`, `usize <= ERST_DBG_RECORD_LEN_MAX` (`0x4000`), and `rcd->record_length == usize`. `erst_dbg_read()` requires `*off == 0` and `usize >= len` (retrying if `len > erst_dbg_buf_len`), and must reset `len = 0` when `erst_get_record_id_next()` yields `APEI_ERST_INVALID_RECORD_ID` after `-ENOENT`. [F41, F89, F158]

## Known Pitfalls
- In `ghes.c`, `GHES_ESTATUS_IN_CACHE_MAX_NSEC` (`10000000000ULL`) and cache timestamps (`now`, `time_in`, `duration`, `period`) must use `unsigned long long`, and `ghes_estatus_cache_add()` must divide via `do_div(period, (count + 1))` (using `do_div()` and `count + 1` since `cache->count` starts at `0`). [F105, F107, F108]
- In `apei_hest_parse()`, advance `hest_hdr` via `(void *)hest_hdr + len` using `hest_esrc_len(hest_hdr)`, never typed pointer arithmetic. Device `.remove` callbacks (`einj_remove`, `ghes_remove`) must not be `__exit`, `acpi_disabled` must be checked in `einj_init()` before `faux_device_create()`, and `__setup()` handlers (`setup_bert_disable()`, `setup_hest_disable()`) must return `1`. [F33, F116, F126]
- In `error_type_set()`, reject `count > sizeof(einj_buf) - 1` and zero-fill `einj_buf` so it stays NUL-terminated; in `einj_timedout()`, cast `*t` (`u64`) to `s64` and compare `< SLEEP_UNIT_MIN` before subtracting `SLEEP_UNIT_MIN`. [F111, F121]
