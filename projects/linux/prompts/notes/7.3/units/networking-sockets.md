# NETWORKING [SOCKETS]

This unit implements the core Linux socket layer (`net/socket.c`, `net/core/sock.c`, `include/net/sock.h`), bridging `sockfs` VFS file operations and syscalls with transport-independent `struct socket` and `struct sock` management. It handles dual process/BH socket locking and backlogs, socket buffer memory accounting, ancillary control messages (`net/core/scm.c`), `SO_REUSEPORT` listener groups (`net/core/sock_reuseport.c`), TFO request queues (`net/core/request_sock.c`), and `sock_diag`.

## Architecture & Data Flow

- `sk->sk_flags` (`__sk_common.skc_flags`) shares a union in `struct sock_common` with `skc_listener` and `skc_tw_dr`; any path that may encounter a `TCP_TIME_WAIT` or `TCP_NEW_SYN_RECV` socket must check `sk_fullsock(sk)` before calling `sock_flag()` or accessing full-socket fields. [F51]
- `sk->sk_socket` and `sk->sk_wq` are `NULL` on un-grafted or orphaned sockets (after `sock_orphan()`). `sk_user_ns(sk)` and `sk_ns_capable(sk, ...)` unconditionally dereference `sk->sk_socket->file` and must only be called when attached to an open file; async, timer, softirq, and wakeup paths must null-check `sk_socket`/`sk_wq`. [F56]
- `sk->sk_user_data` encodes `SK_USER_DATA_NOCOPY`, `SK_USER_DATA_BPF`, and `SK_USER_DATA_PSOCK` in its low bits. Readers must mask with `SK_USER_DATA_PTRMASK`, and `__locked_read_sk_user_data_with_flags()` / `__rcu_dereference_sk_user_data_with_flags()` must test `(sk_user_data & flags) == flags`. [F54, F116]
- `sock_copy()` must skip `sk_dontcopy_begin..sk_dontcopy_end` and preserve `nsk->sk_security` before `security_sk_clone()`. `sk_clone_lock()` must clear `newsk->sk_user_data` if `sk_user_data_is_nocopy(newsk)`, mask `~SOCK_BINDPORT_LOCK` on `sk_userlocks`, and reset `sk_reuseport_cb`, `sk_memcg`, `sk_wq`, and `sk_socket` to `NULL`. When allocating from `prot->slab`, `sk_prot_alloc()` must strip `__GFP_ZERO` and use `sk_prot_clear_nulls()` to preserve `sk_nulls_node.next` for `SLAB_TYPESAFE_BY_RCU`. [F60, F79, F80]
- Replacing or clearing `sk->sk_dst_cache` (`__sk_dst_set()`, `sk_dst_set()`, `__sk_dst_check()`) must also call `sk_tx_queue_clear(sk)` and `WRITE_ONCE(sk->sk_dst_pending_confirm, 0)`. Mutating `sk_bound_dev_if`, `sk_mark`, or `SOCK_LOCALROUTE` (`SO_DONTROUTE`) must call `sk_dst_reset(sk)` (plus `sk->sk_prot->rehash(sk)` for `sk_bound_dev_if`). [F72, F73]
- `scm_fp_copy()` uses `kmalloc()` (not `kzalloc()`) and `scm_fp_dup()` uses `kmemdup(fpl, offsetof(..., fp[fpl->count]), ...)`: `scm_fp_copy()` must initialize all `struct scm_fp_list` fields, and `scm_fp_dup()` must set `new_fpl->max = new_fpl->count` (forbidding appending past `max`) and reset `inflight = false`, `edges = NULL`, and `INIT_LIST_HEAD(&new_fpl->vertices)`. [F63, F92, F139]
- `struct msghdr` unions `msg_control` and `msg_control_user` discriminated by `msg_control_is_user`; kernel-buffer callers (`____sys_sendmsg()`, `kernel_recvmsg()`) must set `msg_control_is_user = false`, and all cmsg writers (`put_cmsg()`, `scm_detach_fds()`, compat variants) must advance the pointer and decrement `msg_controllen` by `min(CMSG_SPACE(len), msg->msg_controllen)`. [F55, F93]
- In `struct sock_reuseport`, `socks[]` (`__counted_by(max_socks)`, initialized immediately after `kzalloc()` in `__reuseport_alloc()`) stores active sockets at `[0, num_socks)` and closed sockets at `[max_socks - num_closed_socks, max_socks)`. `reuseport_grow()` requires `num_socks + num_closed_socks == max_socks`, must copy both sections to their respective ends in `more_reuse`, and must update `sk_reuseport_cb` for all sockets. `reuse->incoming_cpu` must track the count of sockets in `socks[]` with `sk_incoming_cpu >= 0` under `reuseport_lock`. [F74, F76, F99, F137]
- When `sock_needs_netstamp(sk)` is true, `sock_enable_timestamp()` / `sock_disable_timestamp()` must call `net_enable_timestamp()` only on `0 -> non-zero` transitions of `SK_FLAGS_TIMESTAMP` in `sk->sk_flags` (and once in `sk_clone_lock()` if set) and `net_disable_timestamp()` only when all bits clear. `sock_set_timestamping()` must keep `SOCK_TIMESTAMPING_ANY` synced with `!!(sk->sk_tsflags & TSFLAGS_ANY)`, and user flags must never set `SOCKCM_FLAG_TS_OPT_ID` (`BIT(31)`). [F86, F87, F107]

## Synchronization

- All mutations to `sk->sk_backlog` must hold `sk->sk_lock.slock`, and `__sk_add_backlog()` / `__sock_queue_rcv_skb()` must call `skb_dst_force(skb)` before leaving RCU. In `__sk_receive_skb()`, BH context must take `bh_lock_sock()` and use `sk_add_backlog()` whenever `sock_owned_by_user(sk)` is true. `__release_sock()` must detach `head`/`tail` and drop `spin_unlock_bh(&sk->sk_lock.slock)` before `sk_backlog_rcv()`, keeping `sk_backlog.len` non-zero until the loop finishes. [F29, F156, F161]
- `unlock_sock_fast(sk, slow)` must receive the exact boolean returned by `lock_sock_fast(sk)`: when `slow` is false, `sk_lock.slock` is held with BH disabled (`owned == 0`, no sleeping); when `slow` is true, `slock` is dropped and `owned == 1`. [F20]
- `sk_setsockopt()` and helpers reachable from BPF must use `sockopt_lock_sock()`, `sockopt_release_sock()`, `sockopt_ns_capable()`, and `sockopt_capable()` because BPF callers (`has_current_bpf_ctx()`) already hold the socket lock and may run in BH context. Cases after `sockopt_lock_sock()` in `sk_setsockopt()` must set `ret` and `break` rather than returning directly. `SO_PEEK_OFF` must be dispatched before `sockopt_lock_sock(sk)`, accessing `sk->sk_peek_off` via `READ_ONCE()`/`WRITE_ONCE()`. [F35, F115, F155]
- In `sock_init_data_uid()` and `sk_clone_lock()`, `smp_wmb()` must precede `refcount_set(&sk->sk_refcnt, ...)` so `SLAB_TYPESAFE_BY_RCU` readers see initialized fields. In `__reuseport_add_sock()`, storing `reuse->socks[reuse->num_socks]` must precede incrementing `reuse->num_socks` via `smp_wmb()`, paired with `READ_ONCE(reuse->num_socks)` and `smp_rmb()` in `reuseport_select_sock()` / `reuseport_migrate_sock()`. [F22, F24]
- Mutations to `sk->sk_wq`, `sk->sk_socket`, or `sk->sk_user_data` (`sock_orphan()`, `sock_graft()`) must hold `write_lock_bh(&sk->sk_callback_lock)`. Wakeup callbacks (`sock_def_readable()`, `sock_def_write_space()`, `sock_def_wakeup()`, `sock_def_error_report()`) must dereference `sk->sk_wq` under `rcu_read_lock()` and check `skwq_has_sleeper(wq)`. Because `sk->sk_prot` can be replaced concurrently via `sock_replace_proto()`, unlocked callers must load `READ_ONCE(sk->sk_prot)` into a local variable before testing and calling a method. [F41, F43, F158]
- When replacing or clearing `sk->sk_dst_cache`, the pointer must be updated before calling `dst_release(old_dst)`, and lockless `sk_dst_get()` must use `rcuref_get(&dst->__rcuref)` under `rcu_read_lock()`. In `sk_setup_caps()` and `sk_dst_gso_max_size()`, `dst->dev` and device GSO limits must be read under `rcu_read_lock()` using `dst_dev_rcu(dst)` and `READ_ONCE()`. [F44, F163]
- In `__sock_release()`, when `inode` is non-NULL, `inode_lock(inode)` must be held across `ops->release(sock)` and `sock->sk = NULL` to serialize against `sockfs_setattr()`. In `sk_wait_event()`, `sk->sk_disconnects` must be saved before `release_sock()` and checked after `lock_sock()`, returning `-EPIPE` if changed. [F34, F39]
- In `sk_destruct()`, sockets with `SOCK_RCU_FREE` or `sk->sk_reuseport_cb` run `__sk_destruct` via `call_rcu()`, so `sk_setsockopt(SO_REUSEPORT)` must restrict `sk->sk_reuseport` to `sk_is_inet(sk)` sockets whose destructors do not sleep. Because `sk_free()` / `__sk_free()` run in any context, `sock_diag_broadcast_destroy()` must use `GFP_ATOMIC` and defer `GFP_KERNEL` Netlink work and `sk_destruct()` to `broadcast_wq`, and `sock_prot_inuse_add()` / `sock_inuse_add()` must use BH-safe `this_cpu_add()`. [F151, F154, F159]

## Object Lifetimes

- `__sock_create()` pins `pf->owner` under RCU before `pf->create()`, then pins `sock->ops->owner` before `module_put(pf->owner)`, clearing `sock->ops = NULL` if `try_module_get(sock->ops->owner)` fails so `__sock_release()` does not put an unreferenced module. `sock_unregister()` must clear `net_families[family]` under `net_family_lock` and call `synchronize_rcu()`. `sock_diag_lock_handler()` and `sock_diag_rcv_msg()` must dereference handlers and call `try_module_get(owner)` inside `rcu_read_lock()`. [F4, F28, F40]
- `__sk_destruct()` must pass `sk->sk_prot_creator` (not `sk->sk_prot`) to `sk_prot_free()` because `sk->sk_prot` may be mutated by `sock_replace_proto()` while the slab and module ref belong to `sk_prot_creator`. `sock_lock_init_class_and_name()` pins `THIS_MODULE` in `sk->sk_owner` via `sk_owner_set()`, which must remain held until `sk_prot_free()` calls `sk_owner_put(sk)`. [F5, F6]
- `sk_alloc()` and `sk_clone_lock()` bias `sk->sk_wmem_alloc` by 1, and `skb_set_owner_w()` adds `skb->truesize` without touching `sk_refcnt`; `sk_free()` only calls `__sk_free()` when `refcount_dec_and_test(&sk->sk_wmem_alloc)` hits 0, otherwise deferring final destruction to `sock_wfree()` / `__sock_wfree()`. In `sk_common_release()`, `sk->sk_prot->unhash(sk)` must precede `sock_orphan(sk)` and `sock_put(sk)`. [F8, F25]
- `sk_reset_timer()` calls `sock_hold(sk)` only when `mod_timer()` returns 0, and `sk_stop_timer()` / `sk_stop_timer_sync()` call `__sock_put(sk)` only when `timer_delete()` / `timer_delete_sync()` returns non-zero (requiring the caller to hold another reference on `sk`). [F11]
- `__sk_mem_schedule()` adds `amt << PAGE_SHIFT` to `sk->sk_forward_alloc` before `__sk_mem_raise_allocated()` and subtracts it on 0 return (rolling back both `sk_memory_allocated_add()` and `mem_cgroup_sk_charge()`), while `sk_mem_uncharge()` returns bytes to `sk_forward_alloc` and reclaims pages via `sk_mem_reclaim()`. `reuseport_grow()` must free the old struct via `kfree_rcu(reuse, rcu)` (since `prog` and `reuseport_id` move to `more_reuse`), whereas `reuseport_detach_sock()` uses `call_rcu(&reuse->rcu, reuseport_free_rcu)`. [F13, F17]

## API Contracts

- `sock_alloc_file()` consumes `@sock` and calls `sock_release(sock)` if `alloc_file_pseudo()` fails, so callers (`sock_map_fd()`, `__sys_socketpair()`, `do_accept()`) must not call `sock_release(sock)` on `IS_ERR()` return. Every non-NULL `struct socket *` passed to socket lifecycle helpers must be allocated via `sock_alloc()` (`struct socket_alloc`) so `SOCK_INODE(sock)` is valid. [F1, F147]
- `reuseport_select_sock()` returns a borrowed `struct sock *` without incrementing `sk_refcnt`, whereas `reuseport_migrate_sock()` increments `nsk->sk_refcnt` via `refcount_inc_not_zero()` under `rcu_read_lock()`, transferring a +1 reference to the caller. [F18]
- `copy_from_sockptr*()` and `copy_to_sockptr*()` return 0 on success or positive uncopied bytes (not `-EFAULT`), and `copy_from_sockptr()` does not check `optlen`; callers must convert non-zero returns to `-EFAULT` and validate `optlen >= sizeof(...)` (or use `copy_safe_from_sockptr()`). `strncpy_from_sockptr(dst, src, count)` requires `1 <= count <= sizeof(dst) - 1` and explicit `dst[ret] = '\0'` on `ret >= 0`. [F45, F100, F149]
- `sk->sk_err` and `sk->sk_err_soft` store positive errnos while `sock_error(sk)` atomically clears `sk->sk_err` and returns a negative errno. `sock_alloc_send_pskb()` / `sock_alloc_send_skb()` require a non-NULL `int *errcode`. `proto_ops->getname()` returns non-negative sockaddr byte length or negative errno and takes `peer = 0` (local), `1` (connected), or `2` (accept/`SO_PEERNAME`). [F47, F48, F50]
- `put_cmsg()` sets `MSG_CTRUNC` and returns 0 when `msg_control` is NULL or `msg_controllen` is too small; callers with irreversible side effects (like fd installation) must pre-check `msg_controllen` or use `put_cmsg_notrunc()`. `__cmsg_nxthdr()` only checks that `struct cmsghdr` fits, so `for_each_cmsghdr()` loops must check `CMSG_OK(msg, cmsg)` and `cmsg->cmsg_len` before reading `CMSG_DATA(cmsg)`. [F49, F95]
- `__sock_tx_timestamp()` only ORs `SKBTX_*` bits into `*tx_flags` and `_sock_tx_timestamp()` leaves `*tx_flags` untouched when `sockc->tsflags == 0`, so callers must zero-initialize `*tx_flags`. `sock_enable_timestamp()` takes an unshifted `enum sock_flags` bit index, whereas `sock_disable_timestamp()` takes a shifted bitmask (`1UL << flag`). [F64, F65]
- `sock_sendmsg()`, `kernel_bind()`, and `kernel_connect()` `memcpy()` `addrlen` bytes into a local `struct sockaddr_storage` before LSM/BPF/ops hooks (`sock_sendmsg()` also saves and restores `msg_name` and `msg_namelen`); callers must bound-check `0 <= addrlen <= sizeof(struct sockaddr_storage)` beforehand. Buffers from `sock_kmalloc()` / `sock_kmemdup()` must be freed via `sock_kfree_s()` / `sock_kzfree_s()` with the exact charged size. [F91, F110, F140]

## Error Handling

- In `scm_fp_copy()`, any `struct file *` from `fget_raw()` failing validation (e.g., `io_is_uring_fops(file)`) must be `fput()` immediately before incrementing `fpl->count`, whereas files already stored in `fpl->fp[0..fpl->count-1]` are cleaned up by `__scm_destroy()`. In `__scm_send()`, if `scm_replace_pid()` fails, it does not take ownership of `@pid`, so the caller must call `put_pid(pid)` before jumping to `error:`. [F14, F15]
- After `pidfd_prepare()` in `scm_pidfd_recv()` or `sk_getsockopt(SO_PEERPIDFD)`, any failure in `put_cmsg()` or `copy_to_sockptr()` must call both `put_unused_fd(pidfd)` and `fput(pidfd_file)` before returning, only calling `fd_install()` after user copy succeeds. In `reuseport_migrate_sock()`, `bpf_run_sk_reuseport()` can return an `ERR_PTR`; after the `select_by_hash` fallback, `nsk` must be checked with `IS_ERR_OR_NULL(nsk)` and reset to `NULL` before `refcount_inc_not_zero(&nsk->sk_refcnt)`. [F16, F59]

## Known Pitfalls

- In `__sock_cmsg_send()`, 64-bit payloads like `SCM_TXTIME` must be read from `CMSG_DATA(cmsg)` using `get_unaligned()` because `CMSG_ALIGN()` only aligns to 4 bytes on 32-bit architectures. In `sk_setsockopt()`, options accepting `optlen < sizeof(int)` (like `SO_BINDTODEVICE` with `optlen == 0`) must be handled before the `optlen < sizeof(int)` prologue. [F96, F114]
- Timeout conversions in `sock_set_timeout()`, `sock_set_sndtimeo()`, and `SO_LINGER` must check seconds against `MAX_SCHEDULE_TIMEOUT / HZ` before multiplying by `HZ`. `__sk_mem_raise_allocated()` must store `sk_sockets_allocated_read_positive(sk)` as `u64` before multiplying by `sk_mem_pages(...)`. `reuseport_grow()` must compute `more_socks_size = reuse->max_socks * 2U` as `u32` and check `> U16_MAX`. `sock_kmalloc()` must check `(unsigned int)size <= optmem_max` before adding `size` to `sk_omem_alloc`. [F130, F133, F134, F135]
