# MODULE SUPPORT

Implements the Linux kernel loadable module subsystem, including ELF parsing and validation, decompression (gzip/xz/zstd), PKCS#7 signature verification, section layout, execmem/per-CPU memory allocation, symbol resolution, relocation, strict RWX enforcement, and module unloading. It also provides the usermode helper auto-loader (`__request_module`) with duplicate request suppression, fast RCU-safe address lookups via latch RB-trees and kallsyms, and userspace observability through `/proc/modules`, `/sys/module`, and `/sys/kernel/debug/modules`.

## Architecture & Data Flow

- `add_unformed_module()` sets `mod->state = MODULE_STATE_UNFORMED` and calls `mod_update_bounds(mod)` under `module_mutex` before `list_add_rcu(&mod->list, &modules)` and `mod_tree_insert(mod)`. Because `mod->state` stays `MODULE_STATE_UNFORMED` until `complete_formation()` sets `MODULE_STATE_COMING` under `module_mutex` (and `free_module()` resets it to `MODULE_STATE_UNFORMED` after `mod_sysfs_teardown()` while `mod` stays linked on `modules`), readers of `modules` or `mod_tree` (except `find_module_all(..., true)`) must skip `MODULE_STATE_UNFORMED`. [F26, F28, F49]
- `layout_sections()` initializes every section's `sh_entsize` to `~0UL`, and `__layout_sections()` / `module_get_offset_and_type()` pack `enum mod_mem_type` into the upper `SH_ENTSIZE_TYPE_BITS` bits (cast to `unsigned long` and masked with `SH_ENTSIZE_TYPE_MASK` before `<< SH_ENTSIZE_TYPE_SHIFT`) and the byte offset into `SH_ENTSIZE_OFFSET_MASK`, which `move_module()` and `is_core_symbol()` unpack. In `__layout_sections()`, `core_m_to_mem_type`/`init_m_to_mem_type` must match `masks`, and `SHF_RO_AFTER_INIT | SHF_ALLOC` must precede `SHF_WRITE | SHF_ALLOC`. [F54, F66, F104]
- `layout_symtab()` must run after `layout_sections()`, and both `layout_symtab()` and `add_kallsyms()` must use the exact same symbol filter (`i == 0 || is_livepatch_module(mod) || is_core_symbol(...)`), keeping symbol `0` as `find_kallsyms_symbol()`'s not-found sentinel. `mod->core_kallsyms.strtab` must immediately precede `info->core_typeoffs` in `mod->mem[MOD_DATA]` and `strscpy()` must receive remaining `strtab_size` (`core_typeoffs - stroffs`, decremented by `ret + 1`) so writes cannot overflow into `typetab`. [F79, F99, F113]
- Because `layout_and_allocate()` clears `SHF_ALLOC` on `info->sechdrs[info->index.pcpu]`, `apply_relocations()` must exempt a non-zero `infosec == info->index.pcpu` when skipping non-`SHF_ALLOC` sections. In `load_module()`, `flush_module_icache(mod)` must run after `post_relocation()` (`module_finalize()`) and before `ftrace_module_init()`, `complete_formation()`, and `parse_args()`. [F93, F148]
- `module_unload_init()` sets `mod->refcnt` to `MODULE_REF_BASE` and increments it once for initialization, so `do_init_module()` must call `module_put(mod)` on both its success and `fail` paths, and `try_release_module_ref()` must restore `MODULE_REF_BASE` via `atomic_add_unless(&mod->refcnt, MODULE_REF_BASE, 0)` if `atomic_sub_return()` is non-zero. [F10]
- `module_sig_check()` must run before `elf_validity_cache_copy()` in `load_module()`, and `mod_verify_sig()` must copy `struct module_signature` via `memcpy()` and verify `modlen > sizeof(ms)` and `mod_check_sig()` before subtracting `be32_to_cpu(ms.sig_len) + sizeof(ms)` from `info->len`. [F84]
- `elf_validity_cache_sechdrs()` and `validate_section_offset()` must guard against unsigned overflow (`e_shoff >= info->len` before `e_shnum * sizeof(Elf_Shdr) > info->len - e_shoff`; `secend < shdr->sh_offset` before `secend > info->len`) and keep `sechdrs[0]` zeroed (`SHT_NULL`, `sh_size == 0`, `sh_addr == 0`). `elf_validity_cache_secstrings()`, `elf_validity_cache_strtab()`, and `elf_validity_cache_index_versions()` must check `sh_size != 0`, bounds-check `sh_name`/`st_name`, and verify NUL-terminated `__version_ext_names` per CRC. [F77, F78, F107, F166]
- `resolve_symbol()` and `inherit_taint()` forbid combining `GPL_ONLY` symbols with symbols from a `TAINT_PROPRIETARY_MODULE` owner in either order via `mod->using_gplonly_symbols` and `mod->taints`. `mod->taints` stores `TAINT_*` bit indices for `set_bit()`/`test_bit()`, and `try_add_tainted_module()` must return early when `!mod->taints`. [F95, F162, F164]

## Synchronization

- Before `do_init_module()` queues `freeinit` onto `init_free_list` for `do_free_init()`, it must under `module_mutex` switch `mod->kallsyms` to `&mod->core_kallsyms` with `rcu_assign_pointer()`, call `mod_tree_remove_init(mod)` and `trim_init_extable(mod)`, and capture `freeinit` pointers before zeroing `mod->mem[type].base` and `size` for all `init` types (since `within_module_init()` and `mod_tree_remove_init()` read `mod->mem[type]`). Reads of `mod->kallsyms` outside `module_mutex` must use `rcu_dereference(mod->kallsyms)` under RCU. [F24, F38, F59]
- `find_symbol()`, `find_module_all()`, `find_module()`, `__module_address()`, and `__module_text_address()` require `module_mutex` or an RCU read-side critical section (even when holding a module refcount, as in `symbol_put_addr()`), and RCU callers (`__symbol_get()`, `__symbol_put()`) must get/put the module reference before `rcu_read_unlock()`. `module_address_lookup()`, `module_kallsyms_lookup_name()`, and `print_modules()` must use `guard(rcu)()` and never take `module_mutex`. [F32, F136, F137]
- All modifications to `mod_tree` (`mod_tree_insert()`, `mod_tree_remove_init()`, `mod_tree_remove()`) and `mod_update_bounds()`, as well as all mutations and traversals of `struct module_use` lists (`mod->source_list` and `mod->target_list`), require `module_mutex`. `resolve_symbol()` must hold `module_mutex` continuously across `find_symbol()`, `ref_module()`, and copying `module_name(fsa.owner)`. [F29, F30, F138]
- When `module_patient_check_exists()` finds an existing module in `modules`, it must drop `module_mutex` to wait on `module_wq` only if `old->state` is `MODULE_STATE_COMING` or `MODULE_STATE_UNFORMED` (never `MODULE_STATE_GOING`), and after relocking `module_mutex` must re-lookup `old` via `find_module_all()`. [F23]
- `module_notify_list`, `mod->init()`, `mod->exit()`, `klp_module_coming()`, `klp_module_going()`, `ftrace_release_mod()`, and `async_synchronize_full()` must be called outside `module_mutex`. In `do_init_module()` (when `!mod->async_probe_requested`) and `delete_module()`, `async_synchronize_full()` must run before freeing `.init` sections or calling `free_module()`. [F134, F145]
- In `idempotent()`, `u->ret = -EINTR`, `u->cookie`, and `init_completion(&u->complete)` must be initialized before taking `idem_lock` and inserting `&u->entry` into `idem_hash`; `idempotent_complete()` must use `hlist_del_init(&pos->entry)` under `idem_lock`, and `idempotent_wait_for_completion()` must unlink `u->entry` under `idem_lock` if `!hlist_unhashed(&u->entry)` when interrupted. In `kmod_dup_request_exists_wait()`, `wait == false` must never insert into `dup_kmod_reqs`, and when `wait == true` inserts an entry, `call_modprobe()` must call `kmod_dup_request_announce()` on all return paths. [F17, F22, F36]

## Object Lifetimes

- `free_mod_mem()` must skip `MOD_DATA` during `for_each_mod_mem_type()` and free `mod->mem[MOD_DATA]` last (as the final operation on `mod`), because `struct module` resides inside `mod->mem[MOD_DATA].base`. Before `lockdep_free_key_range()` and `module_memory_free()`, `list_del_rcu(&mod->list)`, `mod_tree_remove(mod)`, and `module_bug_cleanup(mod)` must run under `module_mutex` followed by `synchronize_rcu()`. [F65, F141]
- Because `mod->mkobj.kobj` is embedded in `struct module`, `mod_sysfs_init()`, `mod_sysfs_setup()`, and `mod_sysfs_fini()` must release it via `mod_kobject_put()` (waiting on `kobj_completion`) rather than `kobject_put()` directly. `add_notes_attrs()` must use the exact same `!sect_empty(&info->sechdrs[i])` filter as `add_sect_attrs()`, and `remove_notes_attrs()` must precede `remove_sect_attrs()` because `add_notes_attrs()` borrows `sect_attrs` names. [F68, F119]
- Before `rewrite_section_headers()` sets `sh_addr`, helpers reading `info->hdr` sections (`get_next_modinfo()`, `elf_validity_cache_secstrings()`, `elf_validity_cache_strtab()`) must use `(void *)info->hdr + shdr->sh_offset`. After `move_module()` copies `info->mod` to `mod->mem[MOD_DATA]` and updates `SHF_ALLOC` `sh_addr` fields, code must use `mod` and relocated `sh_addr`—specifically, `add_kallsyms()` must set `kallsyms->strtab` from `(void *)info->sechdrs[info->index.str].sh_addr` and never `info->strtab`. [F62, F64, F114]
- In `module_memory_alloc()` and `kmemleak_load_module()`, `kmemleak_not_leak()` and `kmemleak_no_scan()` must only be called on `mod->mem[type].base` when `!mod->mem[type].is_rox`, and `module_memory_alloc()` must use `kmemleak_not_leak()` rather than `kmemleak_ignore()` so writable data sections remain scanned. [F4]
- In `init_module_from_file()` with `MODULE_INIT_COMPRESSED_FILE`, `vfree(buf)` must free the `kernel_read_file()` buffer right after `module_decompress()`, while `info->hdr` and `info->pages` are freed by `module_decompress_cleanup(info)`. In `call_modprobe()`, `call_usermodehelper_setup()` transfers `argv` and `module_name` (`argv[3]`) ownership to `free_modprobe_argv()`, or `call_modprobe()` must `kfree` both if setup returns `NULL`. [F14, F16]

## API Contracts

- `module_memory_alloc()` must `PAGE_ALIGN(mod->mem[type].size)` and store the aligned byte size back into `mod->mem[type].size`. In `kernel/module/strict_rwx.c`, `module_set_memory()` must return `0` when `!mod_mem->base` and pass page counts (`mod_mem->size >> PAGE_SHIFT`) to `set_memory_*` callbacks, whereas `execmem_restore_rox()` in `module_enable_text_rox()` takes `mem->size` in bytes. [F55, F109]
- Because `do_init_module()` frees `MOD_INIT_*` asynchronously via `init_free_wq` (`do_free_init()`), callers requiring init memory and W+X mappings to be torn down must call `flush_module_init_free_work()`. Code classifying ELF sections by name to match `within_module_init()` must call `module_init_layout_section()` rather than `module_init_section()` (which misses `.exit` sections when `!CONFIG_MODULE_UNLOAD`). [F25, F67]
- Synchronous `__request_module(true, ...)` / `request_module()` must not be called from an async worker (`current_is_async()`), and callers must verify the requested service was registered even when `__request_module()` returns `0` (it returns negative errno or positive `modprobe` exit status on failure). [F34, F46]
- `try_module_get()` requires `mod->state != MODULE_STATE_GOING` and `atomic_inc_not_zero(&module->refcnt) != 0` under RCU, `module_mutex`, kernfs active protection, or an existing ref, returning `bool`. `strong_try_module_get()` returns `0` on success, `-EBUSY` if `MODULE_STATE_COMING`, and `-ENOENT` if `try_module_get()` fails. `__symbol_get()` only resolves `GPL_ONLY` symbols (`fsa.license == GPL_ONLY`). [F48, F143, F156]
- Pages mapped with `kmap_local_page()` in `module_gzip_decompress()`, `module_xz_decompress()`, and `module_zstd_decompress()` must be unmapped by passing the returned virtual address (`s.next_out`, `xz_buf.out`, or `zstd_dec.dst`) to `kunmap_local()`, never by passing `struct page *` to `kunmap()` or `kunmap_local()`. [F42]

## Error Handling

- In `move_module()`, `t` must be initialized to `MOD_MEM_NUM_TYPES` before the allocation loop, set to `type` only when `module_memory_alloc()` fails, and unwound with `while (t--)` after `module_memory_restore_rox(mod)` on `out_err`. Both `module_deallocate()` and `move_module()`'s `out_err` path (when `codetag_section_found` is true) must call `codetag_free_module_sections(mod)` before freeing `mod->mem`. [F2, F3]
- In `load_module()`, `free_copy(info, flags)` must precede `do_init_module(mod)`, and any error before `module_allocated = true` must jump to `free_copy:` so `audit_log_kern_module()` and `mod_stat_bump_becoming()` run. In `do_init_module()`, once `mod->state == MODULE_STATE_LIVE`, an error from `module_enable_rodata_ro_after_init(mod)` must only warn and never jump to `fail`. [F6, F7]
- Every `modinfo_attrs[]` entry with a `.free` callback (`free_modinfo_version`) must reset its `mod` pointer field to `NULL` after freeing because error paths call `attr->free(mod)` in both `module_remove_modinfo_attrs()` and `free_modinfo()`. `add_sect_attrs()` and `add_notes_attrs()` must return negative errno on failure and `mod_sysfs_setup()` must unwind on error. [F51, F69]
- `resolve_symbol()` and `resolve_symbol_wait()` return a `struct kernel_symbol *`, `NULL` (not found or blocked by `inherit_taint()`), or an `ERR_PTR` (version, namespace, or `ref_module()` failure). `find_any_unique_sec()` returns `> 0` if unique, `0` if absent, or `< 0` (`-count`) if duplicate. `check_version()`, `check_modstruct_version()`, and `same_magic()` return `1` on success and `0` on failure. `module_get_next_page()` returns `ERR_PTR` on failure, never `NULL`. [F41, F43, F45, F47]

## External Contracts

- `add_kallsyms()` must store symbol types in `kallsyms->typetab` / `mod->core_kallsyms.typetab` rather than `Elf_Sym` fields. In `setup_modinfo()` and `verify_namespace_is_imported()`, `"module:"`-prefixed namespaces are implicitly matched against `mod->name` via `verify_module_namespace()` and must be rejected with `-EPERM` in `.modinfo` `import_ns` tags. [F81, F163]
- A module with `mod->init && !mod->exit` is permanent (`delete_module` rejects unload with `-EBUSY` unless `try_force_unload()` succeeds), and `print_unload_info()` must end every `/proc/modules` dependency entry (`mod->source_list` names and `[permanent]`) with a trailing comma `,` (or `-` when empty). `/proc/modules` (`modules_open()`) and `/sys/module/<mod>/sections/*` (`module_sect_read()`, which uses a `MODULE_SECT_READ_SIZE + 1` bounce buffer and `memcpy()`) must gate `0x%px` on `kallsyms_show_value(file->f_cred)`. [F89, F121, F160, F168]
- Files under `kernel/module/` registering core `module.` parameters must `#define MODULE_PARAM_PREFIX "module."`. `/proc/sys/kernel/modules_disabled` (`proc_dointvec_minmax` with `SYSCTL_ONE`) and `sig_enforce` / `enable_dups_trace` (`bool_enable_only`) must remain one-way latches. [F90, F170]

## Known Pitfalls

- In `apply_relocations()`, checking `SHF_RELA_LIVEPATCH` must precede `sh_type == SHT_RELA` so livepatch relocations route to `klp_apply_section_relocs()`. In `module_get_offset_and_type()` and `layout_symtab()`, `sh_addralign` must be normalized with `sh_addralign ?: 1` before `ALIGN()`. `module_next_tag_pair()` must use `(*secsize)-- <= 1` rather than `--(*secsize) == 0` when `sh_size == 0`. [F94, F106, F112]
- Optional ELF section fields in `struct module` and `find_module_sections()` for tristate Kconfigs (e.g. `CONFIG_KUNIT`) must use `#if IS_ENABLED(CONFIG_...)` rather than `#ifdef`, and guards in `include/linux/module.h` (e.g. `retpoline_module_ok()`) must use the `CONFIG_` prefix (`CONFIG_MITIGATION_RETPOLINE`). [F157, F158]
