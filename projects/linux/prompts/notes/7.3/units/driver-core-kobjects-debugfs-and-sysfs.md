# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS

This unit implements core Linux device model subsystems (`drivers/base/`), kobject/kset lifecycle and uevent delivery (`lib/kobject*.c`), the sysfs and debugfs filesystems, core C headers (`device.h`, `devres.h`, `property.h`, `kobject.h`), and Rust abstractions for devices, platform bus, fwnode properties, devres, and debugfs (`rust/kernel/`).

## Architecture & Data Flow
- `struct bin_attribute` must keep `struct attribute attr` at offset 0 because `sysfs_add_bin_file_mode_ns()` passes `&battr->attr` as `priv` to `__kernfs_create_file()`, while `sysfs_kf_bin_*()` callbacks cast `of->kn->priv` directly to `const struct bin_attribute *`. [F118]
- In `internal_create_group()` and `sysfs_remove_group()`, `kernfs_remove(kn)` must only be called when `grp->name` is non-NULL; when `grp->name` is NULL, `kn` aliases `kobj->sd`. [F98]
- In `__first_visible()`, both `grp->attrs` and `grp->attrs[0]` (or `bin_attrs` and `bin_attrs[0]`) must be checked for non-NULL before calling `is_visible()` / `is_bin_visible()`, because groups can have non-NULL `{ NULL }` arrays. When a group defines both `attrs` and `bin_attrs`, group directory visibility is determined solely by `grp->is_visible(kobj, grp->attrs[0], 0)`. [F51, F69]
- In `__debugfs_create_file()`, `real_fops` may be NULL (requiring `inode->i_fop = &debugfs_noop_file_operations`), and `mode` must only specify `S_IFREG`. Each `FULL_PROXY_FUNC` or `SHORT_PROXY_FUNC` checks `fsd->methods & bit`, so `__debugfs_file_get()` must set the matching `HAS_*` bit in `fsd->methods` for every proxied callback. [F49, F65]
- In `struct property_entry`, `is_inline` discriminates `value` (`true`) vs `pointer` (`false`), and `length` stores total byte size (`_len_ * sizeof(element)`), not element count. [F56]
- In `kobject_uevent_env()`, `top_kobj` is only used to walk `parent` pointers to find `top_kobj->kset`, while `uevent_suppress`, `state_*_uevent_sent`, and `uevent_ops` callbacks (`filter`, `name`, `uevent`) must operate on `kobj`. `state_remove_uevent_sent = 1` is set on `KOBJ_REMOVE` entry before any `kset`, `uevent_suppress`, or `filter` checks, whereas `state_add_uevent_sent = 1` is set only after `KOBJ_ADD` env generation succeeds, gating automatic `KOBJ_REMOVE` in `__kobject_del()`. [F225, F250]
- All pointers in `env->envp[0..env->envp_idx]` must point into `env->buf` in contiguous ascending order (via `add_uevent_var()`), because `zap_modalias_env()` shifts `env->buf` and subtracts `strlen(env->envp[i]) + 1` from subsequent `env->envp[j]` pointers; its outer loop must only increment `i` when `env->envp[i]` does not match `"MODALIAS="`. [F237, F247]
- In `rust/kernel/debugfs/`, `FileOps::adapt()` transmutes `&FileOps<T>` to `&FileOps<T::Inner>`, so every `Adapter` (`WritableAdapter`, `FormatAdapter`, `NoWriter`) must be `#[repr(transparent)]` over `T::Inner`. Callback-file constructors on `Dir` and `ScopedDir` must require a live `&'static F` or `&'static W` reference from the caller so `F`/`W` are proven inhabited before `materialize_zst` creates a reference from `NonNull::dangling()`. [F269, F270]
- `PropertyInt::read_array_from_fwnode_property` and `FwNode::property_read_array_vec` must check `to_result(ret)?` from `fwnode_property_read_*_array` before transmuting `&mut [MaybeUninit<Self>]` to `&mut [Self]` or calling `val.inc_len(len)`. [F277]

## Synchronization
- In `__debugfs_file_get()`, all fields of a new `struct debugfs_fsdata` (`active_users`, `active_users_drained`, `cancellations`, `cancellations_mtx`) must be initialized before `cmpxchg(&dentry->d_fsdata, NULL, fsd)`, and `cancellations_mtx` destroyed before `kfree(fsd)` if `cmpxchg` loses. `d_unlinked(dentry)` must be checked after `cmpxchg` and before `refcount_inc_not_zero(&fsd->active_users)`, pairing with `smp_mb()` before `READ_ONCE(dentry->d_fsdata)` in `__debugfs_file_removed()`. [F20, F21]
- In `__debugfs_file_removed()`, `refcount_dec_and_test(&fsd->active_users)` returns `true` when the initial reference was the last, so it must return immediately when `true` and enter the cancellation / `wait_for_completion(&fsd->active_users_drained)` loop only when `false`. `fsd->cancellations` is protected by `fsd->cancellations_mtx`: `__debugfs_file_removed()` must use `list_del_init(&c->list)` and invoke `c->cancel()` under `cancellations_mtx`. After `debugfs_enter_cancellation()` adds a cancellation and unlocks `cancellations_mtx`, it must check `d_unlinked(dentry)` and call `complete(&fsd->active_users_drained)` if true. [F22, F23, F90]
- In `fs/sysfs/file.c`, `sysfs_file_kobj()` must dereference `kn->__parent` under RCU via `rcu_dereference(kn->__parent)->priv`, and `sysfs_file_ops()` requires an active reference on `kn`. [F27]
- In `platform_dma_configure()`, `dev->driver` must be loaded once via `READ_ONCE(dev->driver)` and checked for non-NULL before `to_platform_driver(drv)->driver_managed_dma`, because IOMMU probe-time DMA configuration can race with async driver binding. [F29]
- Sysfs binary read callbacks formatting live cpumasks via `cpumap_print_bitmask_to_buf()` or `cpumap_print_list_to_buf()` (`cpumap_read()`, `cpulist_read()`, `define_siblings_read_func()`) must snapshot the cpumask into a local `cpumask_var_t` first. [F59]
- In `lib/kobject.c`, `kset_find_obj()` (and any traversal of `kset->list` under `kset->list_lock`) must use `kobject_get_unless_zero()` rather than `kobject_get()`, because `kobject_put()` drops `kobj->kref` to 0 before `kobj_kset_leave()` takes `list_lock`. `kobj_kset_leave()` must unlock `list_lock` before calling `kset_put(kobj->kset)`. [F300, F301]
- Callers of `kobject_rename()` must externally serialize concurrent renames on the same `kobject`. Because `kobject_get_path()` runs `get_kobj_path_length()` and `fill_kobj_path()` without a lock blocking `kobject_rename()`, `fill_kobj_path()` must pre-decrement `length` and check `length <= 0` before each `memcpy()`, and `kobject_get_path()` must free `path` and retry on error. [F192, F194, F263]
- In `rust/kernel/`, `Devres<T>`, `Inner<T>`, `devres::register`, and `platform::Driver` require `Send` because C devres/bus `remove` callbacks may run on another thread. `Devres::devres_callback` must call `inner.data.revoke()` (which awaits `synchronize_rcu()`) rather than `revoke_nosync()`, because other threads may hold RCU-protected `RevocableGuard`s from `Devres::try_access`. [F278, F304]

## Object Lifetimes
- A `struct kobject` holds a reference on `kobj->parent` only while `kobj->state_in_sysfs` is 1. If `create_dir()` fails in `kobject_add_internal()`, it must call `kobj_kset_leave(kobj)`, `kobject_put(parent)`, and clear `kobj->parent = NULL` with `state_in_sysfs == 0`. `__kobject_del()` clears `state_in_sysfs` and `kobj->parent` without dropping `parent` (and calls `sysfs_put(sd)` after `sysfs_remove_dir(kobj)` to drop the extra `sysfs_get(kobj->sd)` from `create_dir()`), so `kobject_del()` and `kobject_cleanup()` must sample `kobj->parent` first and only call `kobject_put(parent)` if `state_in_sysfs` was set. `kobject_cleanup()` must cache `kobj->name` and `kobj->parent` before `t->release(kobj)` and free `name` / drop `parent` only after `t->release(kobj)` returns. [F173, F174, F175, F224]
- In `kobject_move()`, `DEVPATH_OLD` must be captured before `sysfs_move_dir_ns()`; once `sysfs_move_dir_ns()` succeeds and `kobj->parent = new_parent` is set (before `KOBJ_MOVE`), `new_parent` must be set to `NULL` and `old_parent` released with `kobject_put(old_parent)`. [F176, F227]
- In `kobject_uevent_env()`, once `call_usermodehelper_setup()` registers `cleanup_uevent_env` for `env`, calling `call_usermodehelper_exec(info, UMH_NO_WAIT)` consumes `env`, so `env` must be set to `NULL` before `exit:`. `uevent_net_broadcast_untagged()` passes `skb_get(skb)` to each `netlink_broadcast()` in the loop and calls `consume_skb(skb)` after, whereas `uevent_net_broadcast_tagged()` passes `skb` directly to `netlink_broadcast()` (which consumes it). [F177, F178]
- When `platform_device_add()` fails or `platform_device_del()` runs, if `pdev->id_auto` is set it must free `pdev->id` via `ida_free(&platform_devid_ida, pdev->id)` and reset `pdev->id = PLATFORM_DEVID_AUTO`, and call `release_resource(r)` on all resources with non-NULL `r->parent`. `platform_device_add_resources()` and `platform_device_add_data()` must allocate the new `kmemdup*()` copy before calling `kfree()` on existing `pdev->resource` or `pdev->dev.platform_data`. [F6, F7]
- In `soc_device_register()`, once `soc_dev->dev.release = soc_release` is set, `device_register()` failure must clean up via `put_device(&soc_dev->dev)` without jumping to `out3`, whereas `soc_dev->attr` remains caller-owned until after `soc_device_unregister()`. [F9]
- `devm_*` resources on a `struct device` are released during `device_del()`, even if the device never bound to a driver or has no bus. `debugfs_create_devm_seqfile()` stores `devm_kzalloc(dev, ...)` memory in `inode->i_private` without a devres dentry-removal callback, so the debugfs file/directory must be removed before the device's devres resources are released. [F130, F132]
- `debugfs_start_creating()` pins `debugfs_mount` and locks the parent inode; on error, `failed_creating(dentry)` must unlock the parent inode, call `dput(dentry)`, and call `simple_release_fs()`. `full_proxy_release()` must invoke `real_fops->release(inode, file)` unconditionally without gating on `debugfs_file_get()`, and `.release` callbacks must not assume `inode->i_private` outlives `debugfs_remove()`. [F15, F24]
- `sysfs_break_active_protection()` must pin both `kobj` and `kn` before `kernfs_break_active_protection(kn)`, and `sysfs_unbreak_active_protection()` must read `kobj = sysfs_file_kobj(kn)` before `kernfs_unbreak_active_protection(kn)` and `kernfs_put(kn)`. [F28]
- Early exits (`break`, `return`, `goto`) from `fwnode_for_each_child_node()`, `fwnode_for_each_available_child_node()`, or `device_for_each_child_node()` must call `fwnode_handle_put(child)` (or use `_scoped` variants). [F19]
- In `rust/kernel/device/property.rs`, `Device::fwnode` must return a borrowed `Option<&FwNode>` (as `__dev_fwnode` does not increment refcount). In `FwNode::children`, `fwnode_get_next_child_node` drops the refcount of `prev` and increments `next`, so each step must pass `ARef::into_raw(prev)`, wrap `next` in `FwNode::from_raw(next)`, and store `Some(next.clone())` in `prev`. `FwNodeReferenceArgs::drop` must check `!self.0.fwnode.is_null()` before dropping via `FwNode::from_raw`. [F186, F187, F188]
- In `rust/kernel/debugfs/`, `Entry::dynamic_dir` and `Entry::dynamic_file` must retain `Option<Arc<Entry<'static>>>` in `_parent` so parent dentries outlive children. `Scope<T>` must initialize `data: T` in pinned memory before `init(&scope.data)` creates entries, and declare `_entry: Entry<'static>` before `data: T` so `Entry::drop()` calls `debugfs_remove()` before `data` drops. Any root `ScopedDir` must have its `ManuallyDrop<Entry>` extracted via `into_entry()` into a `Scope`. [F181, F182, F203]
- `Devres::access` must verify `self.dev.as_raw() == dev.as_raw()` on the caller's `&'a Device<Bound>` before calling `unsafe { self.data().access() }`. [F280]

## API Contracts
- Once `kobject_init()` / `kobject_init_and_add()` or `platform_device_alloc()` / `platform_device_register()` has initialized the object, callers must never call `kfree()` directly on error and must use `kobject_put()` or `platform_device_put()`. `kobject_add()` does not send `KOBJ_ADD`; callers must create sysfs attributes first, then call `kobject_uevent(kobj, KOBJ_ADD)` from sleepable context. Once in sysfs, renames must use `kobject_rename()` rather than `kobject_set_name()`. [F5, F171, F226, F284, F303]
- `__devm_add_action_or_reset()` immediately calls `action(data)` when `__devm_add_action()` fails, so callers must not call `action(data)` again on error; in Rust, `devres::register_foreign` converts `data` via `into_foreign()` first and must use `bindings::devm_add_action_or_reset`. [F18, F185]
- `platform_get_irq*()` functions treat IRQ 0 as invalid (`-EINVAL`) and return `> 0` on success or `< 0` on error. `platform_get_resource*()` and `platform_device_alloc()` return `NULL` on failure, whereas `devm_platform_ioremap_resource*()`, `platform_device_register_full()`, and `__platform_create_bundle()` return `ERR_PTR()`. [F34, F35, F36]
- `sysfs_emit()` and `sysfs_emit_at()` require `buf` to be page-aligned (`!offset_in_page(buf)`), and `sysfs_emit_at()` returns the bytes written at `buf + at` (not the new offset). Heap-allocated `struct attribute` / `bin_attribute` must be initialized with `sysfs_attr_init()` / `sysfs_bin_attr_init()`. Attributes using `sysfs_bin_attr_simple_read()` (`BIN_ATTR_SIMPLE_RO()`) must set both `.private` and a non-zero `.size` (or `.bin_size`). [F50, F52, F75]
- In debugfs creation/lookup, a `NULL` `parent` is valid (selects root), whereas `IS_ERR(parent)` must be rejected. `debugfs_create_*()` returns `ERR_PTR()` on failure (never `NULL`), while `debugfs_lookup()` returns `NULL` on miss when `CONFIG_DEBUG_FS=y` and `ERR_PTR(-ENODEV)` when `n`. Proxy `.open` handlers must call `__debugfs_file_get()` with `DBGFS_GET_REGULAR` or `DBGFS_GET_SHORT` (translating `-EIO` to `-ENOENT`), not `debugfs_file_get()`. `debugfs_create_file_unsafe()` callbacks must bracket private-data access with `debugfs_file_get()` / `debugfs_file_put()`. `debugfs_enter_cancellation()` requires a non-NULL `cancel` callback, must call `INIT_LIST_HEAD(&cancellation->list)` before any early return, and must be paired with `debugfs_leave_cancellation()` before `debugfs_file_put()`. [F13, F44, F45, F46, F48, F161]
- Rust device wrappers using `impl_device_context_deref!` must be `#[repr(transparent)]` independent of `DeviceContext`, and `AlwaysRefCounted` must only be implemented for `Device<Normal>`. [F275]

## Error Handling
- In `devm_platform_get_irqs_affinity()`, `desc` from `irq_create_affinity_masks()` must be freed with `kfree(desc)` on both error and success paths, and `ptr` freed with `devres_free(ptr)` if an error occurs before `devres_add()` (after setting `ptr->count = nvec` before indexing `ptr->irq[]`). [F8, F83]
-When `pinctrl_bind_pins()` fails, it must free `dev->pins`, set `dev->pins = NULL`, and only propagate `-ENOMEM`, `-EPROBE_DEFER`, or `-EINVAL` (converting other errors like `-ENOENT` to `0`). When `transport_add_class_device()` fails at `sysfs_create_group()`, it must call `attribute_container_class_device_del(classdev)` before `tclass->remove()`. [F11, F41]
- In `lib/kobject.c`, `create_dir()`, `__kobject_del()`, `kobject_cleanup()`, and `kobj_child_ns_ops()` must check `ktype != NULL` before dereferencing it. When `kset_register()` fails, it frees `k->kobj.name` without `kobject_put()`, so `kset_create_and_add()` must use `kfree(kset)` rather than `kset_unregister()`. [F204, F283]
- In Rust, when a parent debugfs `Dir` is `None`, child creation methods must short-circuit to `None` / `Entry::empty()` rather than passing a `NULL` parent dentry to C. In `rust/kernel/platform.rs`, `TryFrom<&device::Device<Ctx>>` for `&platform::Device<Ctx>` must check `bindings::dev_is_platform(dev.as_raw())` before `container_of!`. [F212, F220]

## Known Pitfalls
- Debugfs must not tag pointers in `debugfs_inode_info` or `dentry->d_fsdata` with bit 1, and exposing `unsigned long` in hex must use `debugfs_create_xul()` rather than casting to `u64 *`. In `rust/kernel/platform.rs`, `irq_by_*` methods must check `irq < 0` on the `c_int` from `platform_get_irq*` before casting `irq as u32`. [F78, F79, F245]
- In `kobject_set_name_vargs()`, strings from `kvasprintf_const()` containing `'/'` must be duplicated with `kstrdup()` before `strreplace()` mutates `'/'` to `'!'` in place. In `kset_find_obj()`, do not return the `list_for_each_entry` cursor `k` directly on miss. In `kobject_action_args()`, after `action_arg_word_end(buf, buf_end, '=')`, check `next > buf_end || *next != '='` as well as `!next`. [F228, F249, F253]
