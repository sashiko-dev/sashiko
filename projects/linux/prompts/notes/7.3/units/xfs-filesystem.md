# XFS FILESYSTEM

Provides core shared XFS metadata algorithms and on-disk/UAPI format definitions (`xfs_format.h`, `xfs_fs.h`), including shortform and node-format directory manipulation (`xfs_dir2_sf.c`, `xfs_dir2_node.c`), inode allocation and inobt/finobt B+trees (`xfs_ialloc.c`, `xfs_ialloc_btree.c`), and the in-core B+tree for inode extent maps (`xfs_iext_tree.c`). It also implements atomic file mapping exchange intents (`xfs_exchmaps.c`), dquot buffer verification (`xfs_dquot_buf.c`), generic per-AG/RT-group reference management (`xfs_group.c`), and health/error-injection definitions (`xfs_health.h`, `xfs_errortag.h`).
Implements XFS VFS superblock lifecycle and mount context operations (`xfs_super.c`), copy-on-write and file range remapping (`xfs_reflink.c`), realtime volume extent allocation and growfs (`xfs_rtalloc.c`), and symbolic link creation and reading (`xfs_symlink.c`). It also provides journal log intent/done items and log recovery handlers for reference count (`xfs_refcount_item.c`) and reverse-mapping (`xfs_rmap_item.c`) updates, along with sysfs, sysctl, procfs statistics, and tracepoint glue (`xfs_sysfs.c`, `xfs_sysctl.c`, `xfs_stats.c`, `xfs_trace.c`).

## Architecture & Data Flow

- In `struct xfs_group`, `xg_busy_extents` and `xg_next_reset` share an anonymous union, so `xfs_group_insert` and `xfs_group_free` must guard allocation and `kfree()` of `xg->xg_busy_extents` with `xfs_group_has_extent_busy(mp, type)`. [F35]
- In `xfs_dialloc_ag_inobt`, when a free inode is found on the left branch (`useleft && trec.ir_freecount`), `pag->pagl_leftrec` and `pag->pagl_rightrec` must be assigned from `trec.ir_startino` and `rec.ir_startino` before `rec = trec` overwrites `rec`. [F54]
- When `xfs_dialloc_ag_inobt` reaches both ends of the inobt (`doneleft && doneright`) with `searchdistance > 0`, it must reset `pag->pagl_pagino`, `pag->pagl_leftrec`, and `pag->pagl_rightrec` to `NULLAGINO` and delete both `tcur` and `cur` before jumping to `restart_pagno`. [F55]
- When allocating a sparse inode chunk in `xfs_ialloc_ag_alloc`, `xfs_inobt_insert_sprec` must be called before `xfs_finobt_insert_sprec` so `rec` is merged with any pre-existing sparse `inobt` record before `xfs_finobt_insert_sprec` inserts or overwrites the `finobt` record with the merged `rec`. [F57]
- In `xfs_ialloc_ag_alloc`, after the exact-block allocation attempt (`xfs_alloc_vextent_exact_bno`) sets `args.minalignslop = igeo->cluster_align - 1`, `args.minalignslop` must be reset to `0` before fallback calls to `xfs_alloc_vextent_near_bno` increase `args.alignment`. [F58]
- In `xfs_ialloc_log_agi`, the `offsets[]` table and the region split masks `XFS_AGI_NUM_BITS_R1`, `XFS_AGI_ALL_BITS_R1`, and `XFS_AGI_NUM_BITS_R2` must stay synchronized with `struct xfs_agi` in `fs/xfs/libxfs/xfs_format.h`, where `XFS_AGI_IBLOCKS` logs both `agi_iblocks` and `agi_fblocks`. [F60]
- Whenever the first entry (`pos == 0`) of an existing `xfs_iext_leaf` or `xfs_iext_node` changes its key during `xfs_iext_insert_raw`, `xfs_iext_insert_node`, `xfs_iext_remove`, `xfs_iext_remove_node`, or `xfs_iext_update_extent`, `xfs_iext_update_node` must be called to update the separator key in all ancestor nodes. [F61]
- In `fs/xfs/libxfs/xfs_dir2_sf.c`, shortform directory updates must keep `sfp->i8count` equal to the number of entries (including parent) with ino `> XFS_DIR2_MAX_SHORT_INUM` and `dp->i_disk_size == dp->i_df.if_bytes`, calling `xfs_dir2_sf_toino4` or `xfs_dir2_sf_toino8` when `i8count` crosses 0 and 1. [F65]
- In `xfs_dir2_node_replace`, the new `args->inumber` and `args->filetype` must be saved in local variables before calling `xfs_da3_node_lookup_int`, because `xfs_dir2_leafn_lookup_for_entry` overwrites `args->inumber` and `args->filetype` with the matched entry's existing values. [F66]
- When adding or removing an entry in a node-format directory (`xfs_dir2_node_addname_int`, `xfs_dir2_leafn_remove`), if a data block's longest free space `bf[0].length` changes, the corresponding `freehdr.bests[findex]` entry (and `nvalid`/`nused` counts) in the freespace block must be updated and logged. [F67]
- During each data-fork exchange step in `xfs_exchmaps_one_step`, `xfs_exchmaps_update_size` must advance `i_disk_size` upwards (capped at `xmi_isize1`/`xmi_isize2`) whenever a newly mapped extent ends past `ip->i_disk_size`, using `irec2` for `xmi->xmi_ip1` and `irec1` for `xmi->xmi_ip2` after `swap(irec1->br_startoff, irec2->br_startoff)`. [F69]
- In `xfs_ialloc.c` (`xfs_ialloc_ag_alloc`, `xfs_difree`, and `xfs_imap`), AG block number bounds checks and `max_agbno` calculations must use `xfs_ag_block_count(mp, pag_agno(pag))` rather than `mp->m_sb.sb_agblocks` because the final (runt) AG can be smaller than `sb_agblocks`. [F73]
- In `xfs_dir2_sf_verify()`, each `struct xfs_dir2_sf_entry` must have its fixed header (`(char *)sfep + sizeof(*sfep) < endp`) and non-zero `sfep->namelen` validated before computing `next_sfep = xfs_dir2_sf_nextentry(mp, sfp, sfep)` and checking `endp < (char *)next_sfep`. [F77]
- In `xfs_iext_tree.c`, when `ifp->if_height == 1`, `ifp->if_data` is sized for `xfs_iext_count(ifp)` records without `prev`/`next` pointers until `RECS_PER_LEAF` is reached; code must bound leaf indices by `xfs_iext_max_recs(ifp)` and only access `leaf->next` or `leaf->prev` when `ifp->if_height > 1`. [F86]
- In `xfs_iext_tree.c`, inner B+tree nodes (`struct xfs_iext_node`) must mark unused key slots with `XFS_IEXT_KEY_INVALID` (`1ULL << 63`) rather than `0` because file offset `0` is a valid key, whereas leaf nodes (`struct xfs_iext_leaf`) detect unused record slots via `rec->hi == 0` (`xfs_iext_rec_is_empty()`). [F87]
- In `xfs_exchmaps_finish_one()`, because `xfs_exchmaps_find_mappings()` can exhaust `xmi->xmi_blockcount`, `xmi_has_more_exchange_work(xmi)` must be rechecked before calling `xfs_exchmaps_one_step()`, and `-EAGAIN` must be returned if either `xmi_has_more_exchange_work(xmi)` or `xmi_has_postop_work(xmi)` remains true. [F90]
- In `xmi_delta_nextents_step()`, when both left and right neighbors are contiguous with `curr` (`(state & CBOTH_CONTIG) == CBOTH_CONTIG`) or `new` (`(state & NBOTH_CONTIG) == NBOTH_CONTIG`), `xmi_can_merge_all()` must be checked and `CRIGHT_CONTIG` or `NRIGHT_CONTIG` cleared if the three-extent sum exceeds `XFS_MAX_BMBT_EXTLEN`. [F101]
- When reading the starting file offset from an in-core extent record `struct xfs_iext_rec`, `rec->lo` must be masked with `XFS_IEXT_STARTOFF_MASK` because bits 54..63 of `rec->lo` store the low 10 bits of `br_startblock`. [F103]
- Any container structure inserted into `mp->m_groups` via `xfs_group_insert()` (such as `struct xfs_perag` or `struct xfs_rtgroup`) must embed `struct xfs_group` as its first member at offset 0 because `xfs_group_free()` passes the `struct xfs_group *` pointer directly to `kfree_rcu_mightsleep()`. [F119]
- In `xfs_iext_realloc_root()`, when growing a height-1 root leaf to `RECS_PER_LEAF` records (`new_size / sizeof(struct xfs_iext_rec) == RECS_PER_LEAF`), `new_size` must be expanded to `NODE_SIZE` (256 bytes) and `cur->leaf` must be updated to the new `krealloc()` pointer. [F122]
- Shortform directory inode numbers in `struct xfs_dir2_sf_hdr` and `struct xfs_dir2_sf_entry` must be read and written using unaligned big-endian accessors (`get_unaligned_be32`/`get_unaligned_be64`, `put_unaligned_be32`/`put_unaligned_be64`), and entry inode numbers sit at `sfep->name + sfep->namelen + (xfs_has_ftype(mp) ? 1 : 0)`. [F126]
- The 12-byte filesystem label arrays `struct xfs_sb::sb_fname` (`__nonstring`), `struct xfs_dsb::sb_fname`, and `struct xfs_rtsb::rsb_fname` in `fs/xfs/libxfs/xfs_format.h` have no guaranteed NUL terminator (`XFSLABEL_MAX` = 12), so all copies, comparisons, and string conversions must bound access to `XFSLABEL_MAX` bytes. [F130]
- In `struct xfs_sb` and `struct xfs_dsb` (`fs/xfs/libxfs/xfs_format.h`), the four 64-bit counter fields `sb_icount`, `sb_ifree`, `sb_fdblocks`, and `sb_frextents` must remain contiguous because `xfs_trans_apply_sb_deltas()` logs them as a single byte range from `offsetof(struct xfs_dsb, sb_icount)` through `sb_frextents`. [F131]
- In `fs/xfs/libxfs/xfs_format.h`, whenever any feature bit is set in `sbp->sb_features2` on a V4 superblock, `XFS_SB_VERSION_MOREBITSBIT` must also be set in `sbp->sb_versionnum` (as done in `xfs_sb_version_addattr2` and `xfs_sb_version_addprojid32`), and `sb_bad_features2` is overwritten from `sb_features2` when formatting to disk. [F155]
- In `xfs_init_fs_context()`, `mp->m_finobt_nores` must be initialized to `true` before mount and log recovery so that `ifree` transactions started during log recovery do not depend on per-AG finobt space reservations before those reservations are created. [F189]
- In `struct xfs_rtgroup`, `rtg_rsum_cache` shares a union with `rtg_open_zone` and is only valid when `!xfs_has_zoned(mp)`, and when allocated by `xfs_alloc_rsum_cache()` it must be initialized to `0xFF` (`memset(..., -1, rbmblocks)`) rather than `0` because `rtg_rsum_cache[bbno]` is an upper bound on free summary levels. [F213]
- In `xfs_fs_parse_param()` and `xfs_fs_reconfigure()`, the `fs_context`'s `fc->s_fs_info` (`parsing_mp` / `new_mp`) has `m_super == NULL` and an unpopulated `m_sb`, so `xfs_fs_parse_param()` must not dereference `parsing_mp->m_super` and `xfs_fs_reconfigure()` must run `xfs_finish_flags()` on `mp = XFS_M(fc->root->d_sb)` rather than `new_mp`. [F223]
- When `xfs_growfs_rt_bmblock()` or `xfs_growfs_rt_zoned()` grows the realtime volume, `mp->m_features |= XFS_FEAT_REALTIME`, `xfs_rtrmapbt_compute_maxlevels(mp)`, and `xfs_rtrefcountbt_compute_maxlevels(mp)` (plus `mp->m_rsumlevels`, `mp->m_rsumblocks`, and `xfs_trans_resv_calc(mp, &mp->m_resv)` in `xfs_growfs_rt_bmblock()`) must be updated. [F232]
- Before `xfs_rtallocate_range()` clears `[start, end]` in the realtime bitmap via `xfs_rtmodify_range()`, it must find the enclosing free extent `[preblock, postblock]`, decrement its summary count via `xfs_rtmodify_summary()`, and increment summary counts for any remaining `[preblock, start - 1]` and `[end + 1, postblock]` fragments. [F233]
- In `xfs_rtany_summary()`, `rtg->rtg_rsum_cache[bbno]` stores a strict upper bound on the summary levels containing free extents in bitmap block `bbno`, so scans clamp `high = min(high, rsum_cache[bbno] - 1)` and update `rsum_cache[bbno] = log + 1` only when `log + 1 < rsum_cache[bbno]`. [F234]
- When `xfs_rtalloc_reinit_frextents()` recomputes `mp->m_sb.sb_frextents` from the realtime bitmap, it must also synchronize the per-CPU free realtime extent counter via `xfs_set_freecounter(mp, XC_FREE_RTEXTENTS, mp->m_sb.sb_frextents)`. [F235]
- In `xfs_reinit_percpu_counters()`, the `XC_FREE_RTEXTENTS` per-CPU counter must only be set from `mp->m_sb.sb_frextents` when `!xfs_has_zoned(mp)`. [F236]
- When `xfs_fs_reconfigure()` toggles `XFS_FEAT_SMALL_INUMS` on `mp->m_features` (`inode32` vs `inode64`), it must recompute `mp->m_maxagi` and update per-AG `XFS_AGSTATE_ALLOWS_INODES` and `XFS_AGSTATE_PREFERS_METADATA` flags by calling `xfs_set_inode_alloc(mp, mp->m_sb.sb_agcount)`. [F237]
- Before `xfs_remount_ro()` or `xfs_fs_freeze()` syncs/quiesces metadata, it must drain the reserve block pools into `mp->m_free[i].res_saved` via `xfs_save_resvblks(mp)`, and `xfs_remount_rw()` and `xfs_fs_unfreeze()` must restore them via `xfs_restore_resvblks(mp)`. [F238]
- When `xfs_inactive_symlink_rmt()` sets `ip->i_disk_size = 0` on an unlinked remote symlink before truncating its blocks, it must also change `VFS_I(ip)->i_mode` from `S_IFLNK` to `S_IFREG` (`(VFS_I(ip)->i_mode & ~S_IFMT) | S_IFREG`) and log `XFS_ILOG_CORE` in the same transaction. [F239]
- When `xfs_bmap_rtalloc()` retries after an aligned allocation fails with `-ENOSPC` (`!noalign`), it must restore `ap->offset = orig_offset` and `ap->length = orig_length` (saved before `xfs_rtallocate_align()`) and set `noalign = true` before jumping to `retry`. [F246]
- `xfs_fs_parse_param()` sets the transient `XFS_QFLAGS_MNTOPTS` bit in `parsing_mp->m_qflags` whenever a quota mount option is parsed, and both `xfs_fs_fill_super()` (after checking `!(mp->m_qflags & XFS_QFLAGS_MNTOPTS)`) and `xfs_fs_reconfigure()` must clear `XFS_QFLAGS_MNTOPTS` from `m_qflags`. [F247]
- Because `counter_val()` indexes `struct __xfsstats` as a `uint32_t` array via `xfsstats_offset()`, any change to `uint32_t` fields in `struct __xfsstats` must keep `xstats[]` in `xfs_stats_format()`, `XFSSTAT_START_XQMSTAT` / `XFSSTAT_END_XQMSTAT`, and `struct xfsstats::a` in lockstep, with `uint64_t` fields placed at the end. [F250]
- Entries in `xfs_error_meta_init[XFS_ERR_ERRNO_MAX]` must be ordered to match the `XFS_ERR_*` enum indices (`XFS_ERR_DEFAULT` at index 0, `XFS_ERR_EIO`, `XFS_ERR_ENOSPC`, `XFS_ERR_ENODEV`) that `xfs_error_get_cfg()` uses to index `mp->m_error_cfg[error_class][...]`. [F251]
- In `xlog_recover_cui_commit_pass2()`, `xlog_recover_rtcui_commit_pass2()`, `xlog_recover_rui_commit_pass2()`, and `xlog_recover_rtrui_commit_pass2()`, `item->ri_buf[0].iov_len` must be verified to be at least the 0-extent format size before reading `cui_nextents` or `rui_nextents` and then verified to equal the `nextents`-sized format length. [F252]
- In `xfs_refcount_recover_work()` and `xfs_rmap_recover_work()`, every recovered extent in `cui_extents` or `rui_extents` must be validated with `xfs_cui_validate_phys()` or `xfs_rui_validate_map()` (dispatching to `xfs_verify_rtbext()` when `isrt` is true or `xfs_verify_fsbext()` otherwise) before allocating a transaction. [F253]
- `xfs_cui_init()`/`xfs_cui_item_free()` and `xfs_rui_init()`/`xfs_rui_item_free()` must allocate and free items with `nextents > XFS_CUI_MAX_FAST_EXTENTS` or `XFS_RUI_MAX_FAST_EXTENTS` (16) via `kzalloc()`/`kfree()` using `xfs_cui_log_item_sizeof()`/`xfs_rui_log_item_sizeof()`, and use `xfs_cui_cache` or `xfs_rui_cache` only when `nextents <= 16`. [F254]
- In `xfs_reflink_end_cow_extent_locked()`, the written COW fork extent `got` must be copied to `del`, trimmed to `[*offset_fsb, end_fsb)` with `xfs_trim_extent()`, and clamped to `min(data.br_blockcount, del.br_blockcount)` before remapping into the data fork, while passing the untrimmed `got` to `xfs_bmap_del_extent_cow()`. [F256]
- In `xfs_rtallocate_clamp_len()`, candidate allocation length `rtxlen` at `startrtx` must first be clamped so `startrtx + rtxlen` does not exceed `rtg->rtg_extents` and then rounded down to a multiple of `prod` via `xfs_rtalloc_align_len()`. [F260]
- When computing `sb_rextslog` from a realtime extent count (such as in `xfs_growfs_rt_alloc_fake_mount()`), `xfs_compute_rextslog()` must be used so that a zero `sb_rextents` yields `0` and 64-bit extent counts are handled without 32-bit truncation. [F261]
- In `xfs_growfs_rt()`, user-supplied `in->extsize` (in filesystem blocks) must be converted to bytes via `XFS_FSB_TO_B(mp, in->extsize)` when validating against `[XFS_MIN_RTEXTSIZE, XFS_MAX_RTEXTSIZE]`, and `in->newblocks` must be validated with `xfs_sb_validate_fsb_count()` and `xfs_rt_check_size(mp, in->newblocks - 1)` before growing. [F262]
- In `xfs_setup_devices()`, each `xfs_buftarg` must be configured via `xfs_configure_buftarg()` using the block count for that specific target device (`mp->m_sb.sb_dblocks` for `m_ddev_targp`, `mp->m_sb.sb_logblocks` for an external `m_logdev_targp`, and `mp->m_sb.sb_rblocks` for an external `m_rtdev_targp`). [F264]
- In `xfs_statfs_data()` and `xfs_statfs_inodes()`, `st->f_bfree` and `st->f_ffree` must be clamped at `0` using signed comparisons (`max(0LL, ...)` and `max_t(int64_t, 0, ...)`) so that transient per-CPU counter inaccuracies or unavailable block reservations do not underflow unsigned `kstatfs` fields. [F265]
- In `xfs_fs_parse_param()`, every distinct `Opt_*` case group in `switch (opt)` (such as `Opt_pqnoenforce`, `Opt_uqnoenforce`, and `Opt_gqnoenforce`) must return or break without falling through into another option group that mutates `parsing_mp->m_qflags` or `parsing_mp->m_features`. [F279]
- `xfs_reflink_clear_inode_flag()` must check `xfs_can_free_cowblocks(ip)` before canceling CoW blocks or clearing `XFS_DIFLAG2_REFLINK`, ensuring `VFS_I(ip)` has no `I_DIRTY_PAGES`, no `PAGECACHE_TAG_DIRTY` or `PAGECACHE_TAG_WRITEBACK` mapping tags, and zero `i_dio_count`. [F320]
