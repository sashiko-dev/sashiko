# DRM DRIVERS FOR ROCKCHIP

This unit implements the Rockchip DRM master driver, GEM/DMA/IOMMU memory management, VOP1 and VOP2 CRTC/plane controllers, and display output subdrivers (DisplayPort, MIPI DSI, HDMI, LVDS, and parallel RGB).

## Architecture & Data Flow

- `rockchip_drm_dma_init_device()` sets `private->iommu_dev = ERR_PTR(-ENODEV)` if any bound VOP lacks IOMMU mapping. `rockchip_drm_init_iommu()` must check `IS_ERR_OR_NULL(private->iommu_dev)` and reset `private->domain = NULL` if `iommu_paging_domain_alloc()` returns an `ERR_PTR`, because downstream checks test `private->domain` for non-NULL. [F5, F38]
- In `struct rockchip_gem_object`, PRIME-imported buffers must be discriminated via `obj->import_attach` (and `private->domain` for IOMMU vs DMA unmapping), whereas internally allocated buffers use `rk_obj->pages != NULL`. For DMA-backed buffers (`!rk_obj->pages`) allocated without `alloc_kmap`, `rk_obj->kvaddr` holds a non-NULL DMA cookie, so `rockchip_gem_prime_vmap()` must check `rk_obj->dma_attrs & DMA_ATTR_NO_KERNEL_MAPPING` before using `rk_obj->kvaddr`. [F40, F41]
- `vop_plane_atomic_update()` and `vop_win_disable()` must update `vop->win_enabled` in lockstep with the hardware window `enable` bit under `vop->reg_lock`. During Panel Self-Refresh (`self_refresh_active`), VOP1 must only toggle window enables via `rockchip_drm_set_win_enabled()`, leaving `vop->win_enabled`, clocks, and IOMMU intact so PSR exit in `vop_enable()` restores only previously enabled windows. [F60, F178]
- Because video port and window registers in `vop2_nonvolatile_range` are cached in `vop2->map` (`REGCACHE_MAPLE`) until `vop2_cfg_done()` latches them, `vop2_disable()` and `__vop2_regs_dump()` must call `regcache_drop_region(vop2->map, 0, vop2_regmap_config.max_register)`. [F221]
- On `vop2->version <= VOP_VERSION_RK3588`, `vop2_enable()` must initialize `vop2->old_layer_sel` and `vop2->old_port_sel` by reading `RK3568_OVL_LAYER_SEL` and `RK3568_OVL_PORT_SEL` from hardware. When `rk3568_vop2_setup_layer_mixer()` binds `win` to `layer_id`, it must swap `old_win` into `old_layer_id` so no window is selected by multiple layers at once. [F219, F220]
- In `rk3568_vop2_setup_overlay()` and `rk3576_vop2_setup_overlay()`, `vp->win_mask` and each attached plane's `win->delay` must be updated before calling `vop2_setup_alpha()` and `rk3568_vop2_setup_dly_for_windows()`. In `vop2_setup_alpha()`, the mixer loop over `drm_atomic_crtc_for_each_plane()` must skip `zpos == 0` with `continue` and index `(mixer_id + zpos - 1) * 0x10`, applying `bottom_layer_alpha_en` at `zpos == 1`. [F226, F254]
- For VOP2 cluster windows (`vop2_cluster_window(win)`), `vop2_plane_atomic_update()` and `vop2_win_disable()` must update `VOP2_WIN_CLUSTER_ENABLE` alongside `VOP2_WIN_ENABLE`, and clear `VOP2_WIN_AFBC_ENABLE` and `VOP2_WIN_TRANSFORM_OFFSET` to `0` when `!afbc_en`. On `vop2->version > VOP_VERSION_RK3568`, each AXI window must have unique non-zero `axi_yrgb_r_id` and `axi_uv_r_id` (cluster IDs `< 0xf`). [F225, F280]
- In `vop2_create_crtcs()`, `possible_crtcs` bit positions must use the sequential index `nvp` of connected video ports (`vp->crtc.port != NULL`) rather than `vp->id`, `vp->nlayers` must only be set on connected ports, and RK3566 quirks (`vop2_is_mirror_win()` and `RK3568_OTP_WIN_EN`) must check `vop2->data->soc_id == 3566` rather than `vop2->version`. [F231, F278]
- In `vop2`, `sys_grf`, `vop_grf`, `vo1_grf`, and `sys_pmu` are only populated when their `VOP2_FEATURE_HAS_*` flag is set, and `vop2->lut_regs` is `NULL` when `"gamma-lut"` is absent. On `VOP_VERSION_RK3568`, `vop2_crtc_atomic_check_gamma()` must reject a second active gamma LUT via `vop2_gamma_lut_in_use()`, and `vop2_crtc_atomic_set_gamma_rk356x()` must disable `DSP_LUT_EN`, call `vop2_cfg_done()`, and poll `vop2_vp_dsp_lut_poll_disabled()` before writing `lut_regs`. [F207, F284]
- VOP2 interrupt registers (`RK3568_VP_INT_EN`, `RK3568_VP_INT_CLR`, `RK3568_SYS0_INT_EN`, `RK3568_SYS0_INT_CLR`, `RK3568_SYS1_INT_EN`, `RK3568_SYS1_INT_CLR`) and per-VP bits in `RK3568_REG_CFG_DONE` require upper-16-bit write masks (`mask << 16 | val`). [F289]
- In `dw-mipi-dsi-rockchip.c`, when `dsi->dev->of_node` lacks `"clock-master"` in dual-DSI mode, `dw_mipi_dsi_rockchip_bind()` must set `dsi->is_slave = true` and return `0` immediately (and `unbind` must return immediately when `dsi->is_slave`), while the master (`dsi->slave != NULL`) performs runtime PM, `dw_mipi_dsi_rockchip_config()`, and `dw_mipi_dsi_rockchip_set_lcdsel()` for both `dsi` and `dsi->slave`. [F68, F97]
- GRF and chip data sentinels: `rockchip_dp_chip_data` and `rockchip_dw_dsi_chip_data` arrays must end with a `.reg == 0` sentinel; `u32` GRF offsets in `rockchip_dw_dsi_chip_data` use `0` as unpopulated sentinel whereas `rockchip_hdmi_chip_data.lcdsel_grf_reg` (`int`) uses `-1` (`< 0`); in `analogix_dp-rockchip.c`, `rockchip_grf_reg_field` must be initialized with `GRF_REG_FIELD()` (`.valid = true`) and checked via `field->valid` (not `field->reg`, as `0x0000` is valid on RK3588). [F50, F51, F78, F79]

## Synchronization

- In `rockchip_gem_iommu_map()` and `rockchip_gem_iommu_unmap()`, `private->mm_lock` must protect `drm_mm_insert_node_generic()` and `drm_mm_remove_node()` on `private->mm`, and `rockchip_gem_iommu_unmap()` must call `iommu_unmap()` before removing `rk_obj->mm` from `private->mm`. [F29]
- In VOP1, `vop->reg_lock` must be held when updating plane registers, `vop->win_enabled`, or calling `vop_cfg_done()`, must be released before sleeping `readx_poll_timeout()` calls in `vop_crtc_gamma_set()`, and must never be acquired in `vop_isr()` or hardirq context because process context takes it with non-IRQ-saving `spin_lock()`. [F19, F151, F157]
- In `vop_enable()`, runtime PM and VOP clocks must be enabled before `rockchip_drm_dma_attach_device()`, all windows disabled in hardware when not exiting PSR, and `vop->is_enabled = true` set before `drm_crtc_vblank_on()`. In `vop_crtc_atomic_disable()`, `reinit_completion(&vop->dsp_hold_completion)` and `vop_dsp_hold_valid_irq_enable(vop)` must precede setting standby to 1, `wait_for_completion_timeout()` must finish before `rockchip_drm_dma_detach_device()` or disabling clocks, and `vop_dsp_hold_valid_irq_disable(vop)` must precede setting `vop->is_enabled = false`. [F16, F17, F18]
- In `vop_crtc_atomic_flush()`, `vop_wait_for_irq_handler()` must be called after releasing `vop->reg_lock` (after `vop_cfg_done()`) and before acquiring `crtc->dev->event_lock` to arm `vop->event`. Before setting `VOP_PENDING_FB_UNREF` in `vop->pending`, the caller must take both `drm_framebuffer_get()` and `drm_crtc_vblank_get()` and queue the FB via `drm_flip_work_queue(&vop->fb_unref_work, ...)`. [F21, F153]
- Because `vop_isr()`, `vop2_isr()`, and `rk3576_vp_isr()` run in hardirq context on `IRQF_SHARED` lines, they must check power state with `pm_runtime_get_if_in_use()` (returning `IRQ_NONE` before any register access in VOP2 and releasing with non-sleeping `pm_runtime_put()`). In VOP1, `vop_initial()` leaves `hclk`, `aclk`, and `dclk` prepared until `vop_unbind()` calls `clk_unprepare()`, so `vop_isr()` and `vop_enable()` must only use atomic `clk_enable()`/`clk_disable()`. [F130, F154, F294]
- `vop2_lock(vop2)` (`vop2->vop2_lock`) must be held across `vop2_crtc_atomic_enable()` and `vop2_crtc_atomic_disable()` (and released on every early return) to serialize `vop2->enable_count` transitions (gating `vop2_enable()`/`vop2_disable()` on 0<->1 transitions) and `vop2_crtc_atomic_try_set_gamma()`. In `vop2_crtc_atomic_disable()`, while holding `vop2_lock`, the driver must write `RK3568_VP_DSP_CTRL__STANDBY`, wait for `vp->dsp_hold_completion`, and restore `vp->dclk` to `vp->dclk_src` before decrementing `enable_count` and calling `vop2_disable()`. [F184, F195, F227, F295]
- `vop2_crtc_atomic_flush()` must call `vop2_cfg_done(vp)` before moving `crtc->state->event` to `vp->event` under `crtc->dev->event_lock`, and `vop2_isr()`/`rk3576_vp_isr()` must only deliver `vp->event` and call `drm_crtc_vblank_put()` when `BIT(vp->id)` in `RK3568_REG_CFG_DONE` has cleared. [F228]
- In `cdn-dp-core.c`, all functions transacting with the microcontroller mailbox or modifying hardware/link/audio/suspend state (`dp->suspended`) must hold `dp->lock`. `cdn_dp_request_firmware()` requires `dp->lock` held on entry, drops it around `request_firmware()`, and must re-acquire it before returning on all paths; `cdn_dp_pd_event_work()` must check `dp->suspended` under `dp->lock` and unlock `dp->lock` before calling `drm_bridge_hpd_notify()`. [F11, F25, F145, F165]
- `dw_mipi_dsi_rockchip_host_attach()` and `dw_mipi_dsi_dphy_init()` must verify `dsi->usage_mode == DW_DSI_USAGE_IDLE` and set the new `usage_mode` under `dsi->usage_mutex` before calling `component_add()`, and reset it to `DW_DSI_USAGE_IDLE` under `dsi->usage_mutex` after `component_del()` on error or detach. [F31]

## Object Lifetimes

- Stateless device links added in `rockchip_drm_match_add()` (`DL_FLAG_STATELESS`) must be removed via `rockchip_drm_match_remove(dev)` on probe failure and in `rockchip_drm_platform_remove()`. In `rockchip_drm_bind()`, `component_bind_all()` must precede `rockchip_drm_init_iommu()` and `drm_vblank_init()`, and `rockchip_drm_unbind()` must call `drm_atomic_helper_shutdown()` and `component_unbind_all()` before `rockchip_iommu_cleanup()`. [F12, F125]
- In `rockchip_gem_prime_vunmap()`, `map->vaddr` must only be passed to `vunmap()` when `rk_obj->pages` is non-NULL and `map->vaddr != rk_obj->kvaddr`. In `rockchip_fb_create()`, if `drm_gem_fb_init_with_funcs()` fails, free `afbc_fb` with `kfree(afbc_fb)`, whereas if `drm_gem_fb_afbc_init()` fails afterwards, call `drm_framebuffer_put(&afbc_fb->base)`. [F4, F175]
- In `vop_bind()`, spinlocks, `vop->vop_lock`, `vop_create_crtc()`, `pm_runtime_enable()`, and `vop_initial()` must all complete before `devm_request_irq()`. In `vop2_bind()`, `irq_name` passed to `devm_request_irq()` must be allocated with `devm_kasprintf()` (not a stack buffer). In `vop_destroy_crtc()` and `vop2_destroy_crtcs()`, all `drm_plane` instances must be cleaned up with `drm_plane_cleanup()` before `drm_crtc_cleanup()` (and `of_node_put(crtc->port)` in VOP2). [F23, F177, F271, F274]

## API Contracts

- Subclassing and container downcasts: `vop_crtc_reset()`, `vop_crtc_duplicate_state()`, and `vop2_crtc_duplicate_state()` must allocate `struct rockchip_crtc_state` (`to_rockchip_crtc_state()`); `analogix_dp_probe()` must receive `&dp->plat_data` embedded in `struct rockchip_dp_device` (`pdata_encoder_to_dp()`); `dw_hdmi_rockchip_bind()` must copy `.phy_data` to `hdmi->chip_data` and overwrite `plat_data->phy_data = hdmi` and `priv_data = hdmi` on a `devm_kmemdup()` copy; `vop2_debugfs_list` show callbacks must read `((struct drm_info_node *)s->private)->info_ent->data` to get `struct vop2 *`. [F119, F121, F122, F273]
- Tri-state return values: `rockchip_drm_endpoint_is_subdriver()` returns `1` for subdriver, `0` for external bridge, and `-ENODEV` on missing device (test `== 0` for bridges); `rockchip_rgb_init()` returns `NULL` when unused, `ERR_PTR` on failure, or a valid pointer (`vop2_bind()` must call `vop2_destroy_crtcs()` on `-EPROBE_DEFER` or clear `vop2->rgb = NULL` on other errors, and `vop_unbind()`/`vop2_unbind()` must guard `rockchip_rgb_fini()` with `if (rgb)`). [F39, F47, F277]
- In VOP2, `vop2_vp_write()`/`vop2_vp_read()` take VP-relative offsets (adding `vp->data->offset`), `vop2_writel()`/`vop2_readl()` take absolute offsets, and `vop2_win_write()` takes an `enum vop2_win_regs` index; `vop2_parse_alpha()` must zero-initialize all four `.val` fields in `struct vop2_alpha` before setting `.bits`; `rk3588_calc_dclk()` arguments and `vop2_ops->setup_intf_mux()` return values must be in Hz (converting `crtc_clock` kHz via `* 1000`, with `0` for failure). [F211, F213, F216]
- Whenever writing to Rockchip GRF regmaps on SoCs with a gateable GRF clock (`grf_clk`/`grfclk`), callers must wrap `regmap_write()` with `clk_prepare_enable()` and `clk_disable_unprepare()`. In `dw_hdmi_qp_rockchip_resume()`, `hdmi->ctrl_ops->io_init(hdmi)` must be called before `dw_hdmi_qp_resume()`. [F140, F141]

## Error Handling

- Signedness of return values: in `rockchip_gem_iommu_map()`, store `iommu_map_sgtable()`'s return value in a signed `ssize_t` and compare against `(ssize_t)rk_obj->base.size`; store `vop_convert_format()` and `vop2_convert_format()` return values in a signed `int` (not `enum vop_data_format` / `enum vop2_data_format`) before testing `< 0`; store `cdn_dp_mailbox_read()`'s return value in a signed `int` and check `ret < 0` before truncating to `u8`. [F37, F42, F53, F204]
- Null and logging guards: `vop_crtc_duplicate_state()`, `vop2_crtc_duplicate_state()`, and `inno_hdmi_connector_duplicate_state()` must check `if (WARN_ON(!state))` and return `NULL` before downcasting; in `vop2_create_crtcs()`, verify `vp->primary_plane != NULL` before `drm_crtc_init_with_planes()`; log unsupported atomic configurations with `DRM_DEBUG_KMS()` (not `DRM_ERROR()`) and ISR errors (`VP_INT_POST_BUF_EMPTY`, `VOP2_INT_BUS_ERRPR`) with `drm_err_ratelimited()`. [F44, F171, F205, F206, F300]

## Known Pitfalls

- Register indexing: in `rockchip_drm_vop.c`, `vop->regsbak` (`uint32_t *`) must be indexed by `offset >> 2`, whereas `vop->regs` takes byte offsets; in `inno_hdmi.c`, `hdmi_readb()`/`hdmi_writeb()` multiply their offset by 4 (taking unscaled register indices), unlike `rk3066_hdmi.c` which takes byte offsets; in `vop2_regmap_init()`, unsupported `enum vop2_win_regs` entries in cluster/smart `reg_field` tables must be `{ .reg = 0xffffffff }`; cluster `enum vop2_layer_phy_id` values (`0, 1, 6, 7`) are non-contiguous and must be mapped via `switch`, not stride multiplication. [F115, F118, F222, F235]
- VOP2 scaling and AFBC: in `vop2_afbc_transform_offset()` and `vop2_plane_atomic_update()`, obtain bpp via `vop2_get_bpp(fb->format)` (not `drm_format_info_bpp()`, which is 0 for YUV420); when `afbc_en` is true, `VOP2_WIN_AFBC_HDR_PTR` (and `VOP2_WIN_AFBC_PLD_OFFSET` with `PLD_OFFSET_EN` on RK3576+) takes the uncropped base `rk_obj->dma_addr + fb->offsets[0]`, and `VOP2_WIN_AFBC_AUTO_GATING_EN` must be `0` on `VOP_VERSION_RK3568` and `1` on all other versions; `vop2_scale_factor()` must guard `dst < 2` and `src < 2`, use `DIV_ROUND_UP(src << shift, dst) - 1`, and clamp to `U16_MAX`; in `vop2_setup_scale()`, check `>= 4 * dst_h` before `>= 2 * dst_h` and reset `gt4 = 0; gt2 = 0;` before `cbcr_src_h`. [F253, F257, F258, F287, F288]
- VOP2 SoC-specific muxing: in `rk3568_set_intf_mux()`, every endpoint case must update both `RK3568_DSP_IF_EN` (`die`) and `RK3568_DSP_IF_POL` (`dip`); in `rk3588_set_intf_mux()` and `rk3568_vop2_setup_layer_mixer()`, each endpoint/port must update its own matching `RK3588_SYS_DSP_INFACE_EN_*` or `PORT*_MUX` bitfields; in `rk3588_calc_cru_cfg()`, assign raw divider factors (1, 2, 4) before the final `ilog2()` conversion. [F246, F247, F249, F262]
