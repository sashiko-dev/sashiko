# MEMBLOCK AND MEMORY MANAGEMENT INITIALIZATION

This component manages physical memory regions during early boot via the memblock allocator and transitions the system to the runtime page/buddy and slab allocators during memory management initialization. It discovers, reserves, allocates, and trims physical memory ranges, initializes NUMA node (`pg_data_t`), zone (`struct zone`), and `struct page` metadata (including parallelized deferred page initialization), and hands free memory over to the buddy allocator in `mm_core_init()`.

## Architecture & Data Flow

- Before passing a `struct memblock_region` node ID `nid` to `NODE_DATA(nid)`, `node_online(nid)`, or `reserve_bootmem_region()`, callers must verify `numa_valid_node(nid)` and fall back to `early_pfn_to_nid()`, because `memblock_add()` sets `nid = MAX_NUMNODES` and `memblock_reserve()` sets `nid = NUMA_NO_NODE`. [F65]
- Before accessing newly allocated physical memory via `__va()` or `phys_to_virt()`, `memblock_double_array()` and `memblock_alloc_range_nid()` must call `accept_memory()` on the physical range; `deferred_free_pages()` must also call `accept_memory()` upfront for chunks not naturally aligned to `MAX_ORDER_NR_PAGES`. [F135]
- `memblock.current_limit` must only clamp explicit upper-bound addresses in `memblock_alloc_internal()` (virtual allocations) and must not clamp explicit `end` addresses in `memblock_alloc_range_nid()` or `memblock_find_in_range_node()` (which only substitute `memblock.current_limit` when `end` is `MEMBLOCK_ALLOC_ACCESSIBLE` or `MEMBLOCK_ALLOC_NOLEAKTRACE`). [F43]
- Converting physical `[start, end)` ranges to PFNs must round usable/free memory inward via `[PFN_UP(start), PFN_DOWN(end))` (`memblock_region_memory_base_pfn()`, `memblock_region_memory_end_pfn()`, `__free_memory_core()`) and reserved ranges outward via `[PFN_DOWN(start), PFN_UP(end))` (`reserve_bootmem_region()`). [F102]
- Before computing `base + size` in `memblock_overlaps_region()`, `memblock_add_range()`, `memblock_isolate_range()`, or `memblock_is_region_memory()`, `size` must be clamped via `memblock_cap_size(base, &size)` (`<= PHYS_ADDR_MAX - base`) to prevent `phys_addr_t` overflow. [F62]
- When `memblock_isolate_range()` splits a `struct memblock_region` in place, it must subtract the split-off length from both `rgn->size` and `type->total_size` before calling `memblock_insert_region()`, which adds the inserted size back to `type->total_size`. [F49]
- In `memblock_add_range()`, the `repeat:` target must reset `base = obase` and `nr_new = 0` before the second pass, and `memblock_insert_region(type, idx++, ...)` inside `for_each_memblock_type(idx, type, rgn)` must post-increment `idx`. When `memblock_merge_regions()` merges `type->regions[i]` and `type->regions[i + 1]`, it must decrement both `type->cnt` and `end_rgn` without incrementing `i`. [F88, F89]
- When `memblock_remove_region()` removes the last entry (`type->cnt == 0`), it must reset `type->regions[0]` (`base = 0`, `size = 0`, `flags = 0`, `nid = MAX_NUMNODES`) because `memblock_add_range()` checks `type->regions[0].size == 0` for emptiness and `memblock_search()` unconditionally reads `type->regions[0]`. In-place region shifts in `memblock_remove_region()`, `memblock_merge_regions()`, and `memblock_insert_region()` must use `memmove()` with count scaled by `sizeof(struct memblock_region)`. [F70, F114]
- `memblock_cap_memory_range()` must check for empty memory via `!memblock_memory->total_size` rather than region count, and both `memblock_cap_memory_range()` and `memblock_enforce_memory_limit()` must truncate `memblock.reserved` in lockstep with `memblock.memory`. [F54]
- `memblock_memory` must remain a `__refdata` pointer to `&memblock.memory` cleared to `NULL` by `memblock_discard()` so non-init `should_skip_region()` and `__next_mem_range()` do not access discarded `__initdata_memblock` data when `!CONFIG_ARCH_KEEP_MEMBLOCK`. Unlike `memblock`, `physmem` and `memblock_physmem_init_regions` must not be `__initdata_memblock` or freed in `memblock_discard()`. [F124, F125]
- Every new `enum memblock_flags` bit in `include/linux/memblock.h` must have a matching `[ilog2(FLAG)]` entry in `flagname[]` in `mm/memblock.c` for `memblock_debug_show()`. [F82]
- In `memmap_init_zone_range()` and `memmap_init()`, PFNs in intermediate holes `[hole_pfn, start_pfn)` and in the trailing hole up to `round_up(end_pfn, PAGES_PER_SECTION)` (`CONFIG_SPARSEMEM`) or `round_up(end_pfn, MAX_ORDER_NR_PAGES)` (`CONFIG_FLATMEM`) must be initialized via `init_unavailable_range()`. [F77]
- Under `CONFIG_DEFERRED_STRUCT_PAGE_INIT`, only the highest populated zone on each node (`end_pfn == pgdat_end_pfn(pgdat)`) may defer pages, `NODE_DATA(nid)->first_deferred_pfn` must be `PAGES_PER_SECTION`-aligned (or `ULONG_MAX` if none), and `defer_init()` must reset `nr_initialised = 0` whenever `prev_end_pfn != end_pfn` so each new zone's first section is initialized before deferring. [F78, F98]
- In `find_zone_movable_pfns_for_nodes()`, `node_states[N_MEMORY]` must be saved before `early_calculate_totalpages()` and restored on every exit path, and `zone_movable_pfn[nid]` must be rounded up to `MAX_ORDER_NR_PAGES` and reset to `0` if `>= end_pfn`. [F57, F79]
- Under `CONFIG_FLATMEM`, `alloc_node_mem_map()` must round `pgdat->node_start_pfn` down and `pgdat_end_pfn(pgdat)` up to `MAX_ORDER_NR_PAGES`, set `pgdat->node_mem_map = map + (pgdat->node_start_pfn - start)`, and account allocations globally via `memmap_boot_pages_add(DIV_ROUND_UP(size, PAGE_SIZE))`. Under `!CONFIG_SPARSEMEM`, `usemap_size()` must add `zone_start_pfn & (pageblock_nr_pages - 1)` to `zonesize` before rounding up to `pageblock_nr_pages`, multiplying by `NR_PAGEBLOCK_BITS`, and rounding up to `BITS_PER_LONG`. [F13, F75, F76]
- When `!IS_ENABLED(CONFIG_HIGHMEM)`, `__free_memory_core()` must clamp `end_pfn` to `max_low_pfn`, and under `WANT_PAGE_VIRTUAL`, `__init_single_page()` must only call `set_page_address(page, __va(pfn << PAGE_SHIFT))` when `!is_highmem_idx(zone)`. `set_high_memory()` must not overwrite a non-`NULL` `high_memory`. [F41, F138]
- In `mem_debugging_and_hardening_init()`, active `CONFIG_PAGE_POISONING` takes precedence over `init_on_alloc` and `init_on_free` and forces both static keys disabled. [F148]

## Synchronization

- In `page_alloc_init_late()`, `pgdat_init_n_undone` must be initialized with `atomic_set(&pgdat_init_n_undone, num_node_state(N_MEMORY))` before spawning any `deferred_init_memmap` kthreads, and `wait_for_completion(&pgdat_init_all_done_comp)` must finish before `static_branch_disable(&deferred_pages)`, `memblock_discard()`, `shuffle_free_memory()`, `set_zone_contiguous()`, and `page_ext_init()` run. [F16, F17]
- `deferred_init_memmap()` must read `pgdat->first_deferred_pfn`, set `pgdat->first_deferred_pfn = ULONG_MAX`, and call `pgdat_resize_unlock(pgdat, &flags)` before invoking `padata_do_multithreaded(&job)`, and every exit path (including `first_init_pfn == ULONG_MAX`) must release `pgdat_resize_lock` and call `pgdat_init_report_one_done()` to decrement `pgdat_init_n_undone` and complete `pgdat_init_all_done_comp`. [F10, F18]
- All accesses to `early_pfnnid_cache` via `__early_pfn_to_nid()` must be serialized by `early_pfn_lock` in `early_pfn_to_nid()`. [F22]
- In `mm_core_init()`, `mem_debugging_and_hardening_init()` must configure `init_on_alloc`, `init_on_free`, `check_pages_enabled`, `_page_poisoning_enabled`, `_debug_pagealloc_enabled`, and `_debug_guardpage_enabled` before `memblock_free_all()`. [F28]

## Object Lifetimes

- Before freeing boot-reserved pages in `memblock_free_pages()` or `init_cma_reserved_pageblock()`, `clear_page_tag_ref(page)` must be called before `__free_pages_core()` or `__free_pages()`; in `init_cma_reserved_pageblock()`, all pages in the pageblock must also have `PageReserved` cleared and refcount zeroed, and the head page must have `MIGRATE_CMA` and `set_page_refcounted(page)` applied before `__free_pages(page, pageblock_order)`. [F6, F27]
- `kho_memory_init()` and `page_ext_init_flatmem()` must run before `memblock_free_all()`, `page_ext_init_flatmem_late()` after `memblock_free_all()` and `kmem_cache_init()`, and `page_ext_init()` only after `vmalloc_init()` and deferred page init completion (in `mm_core_init()` only when `!deferred_struct_pages`, otherwise in `page_alloc_init_late()` after `wait_for_completion(&pgdat_init_all_done_comp)`). [F15, F149]
- `memblock_double_array()` replaces `type->regions` and frees `old_array`, invalidating interior `struct memblock_region *` pointers; callers (`memblock_add_range()`, `memblock_isolate_range()`, `memmap_init_reserved_pages()`) must resize before iterating or restart when `memblock.reserved.max` changes. [F113]
- When freeing non-slab region arrays in `memblock_double_array()` or `memblock_discard()`, callers must verify the array is not `memblock_memory_init_regions` or `memblock_reserved_init_regions` and pass the `PAGE_ALIGN()`ed allocation size to `memblock_free()` or `memblock_free_late()`. [F85, F112]

## API Contracts

- Physical memblock allocation/search functions (`memblock_phys_alloc*()`, `memblock_alloc_range_nid()`, `memblock_find_in_range*()`, `__memblock_find_range_*()`) return physical address `0` on failure and leave memory uninitialized (as do `memblock_alloc_*_raw()`), whereas virtual `memblock_alloc*()` wrappers return `NULL` and zero memory via `memblock_alloc_try_nid()`, and `memmap_alloc()` returns `NULL` and poisons memory with `page_init_poison()`. [F29, F38]
- `memblock_set_node(base, size, type, nid)` and all `memblock_add*()`, `memblock_remove()`, `memblock_phys_free()`, `memblock_reserve*()`, `memblock_mark_*()`, and `memblock_clear_*()` APIs take `(base, size)` in bytes, never `(start, end)` addresses. Overlap checks on `[base, base + size)` ranges must use strict inequalities via `memblock_addrs_overlap()`, never `<=` or `>=`. [F42, F63]
- Callers marking a memblock-allocated region with `MEMBLOCK_NOMAP` via `memblock_mark_nomap()` must explicitly notify kmemleak (e.g., `kmemleak_ignore_phys()`). Callers marking a reserved region with `MEMBLOCK_RSRV_NOINIT` via `memblock_reserved_mark_noinit()` must initialize its `struct page` entries themselves because `memmap_init_reserved_pages()` skips them. [F5, F40]
- In `should_skip_region()`, `MEMBLOCK_HOTPLUG` (when `movable_node` is enabled), `MEMBLOCK_NOMAP`, and `MEMBLOCK_DRIVER_MANAGED` are skipped unless set in `flags` (so `for_each_mem_range()` and `for_each_mem_range_rev()` must pass `MEMBLOCK_HOTPLUG | MEMBLOCK_DRIVER_MANAGED`), whereas setting `MEMBLOCK_MIRROR` or `MEMBLOCK_KHO_SCRATCH` in `flags` skips all regions lacking that flag. [F83, F84]
- `__next_mem_range()` and `__next_mem_range_rev()` pack `idx_a` (low 32 bits) and `idx_b` (high 32 bits) in `*idx`, advance only the index whose region ends (or in reverse, starts) first, use `ULLONG_MAX` as termination sentinel (and initial `*idx` for `__next_mem_range_rev()`), and along with `__next_mem_pfn_range()` and `alloc_large_system_hash()` must guard all optional out-parameters (`out_start*`, `out_end*`, `out_nid`, `type_b`, `_hash_shift`, `_hash_mask`) against `NULL`. [F34, F92]
- `memblock_search_pfn_nid()` returns `NUMA_NO_NODE` without writing `*start_pfn` or `*end_pfn` when `pfn` is not found; callers must check the return value first. `memblock_double_array()` returns `-1` on failure, which `memblock_add_range()` and `memblock_isolate_range()` must translate to `-ENOMEM`. [F30, F32]
- When `memblock_alloc_range_nid()` is called after `slab_is_available()`, it must warn with `WARN_ON_ONCE` and fall back to `kzalloc_node(size, GFP_NOWAIT, nid)`. Any function or `static inline` helper (such as `memblock_set_bottom_up()` and `memblock_bottom_up()`) referencing `memblock` or `__initdata_memblock` state must be annotated `__init`, `__init_memblock`, or `__ref`. [F134, F142]
- In `alloc_large_system_hash()`, `numentries`, `low_limit`, and `high_limit` are bucket counts while `bucketsize` is in bytes; `*_hash_shift` receives `ilog2(numentries)` and `*_hash_mask` receives `(1 << log2qty) - 1`. `cmdline_parse_core()` converts `required_kernelcore` and `required_movablecore` into page counts (`>> PAGE_SHIFT`). [F145, F146]

## Error Handling

- In `memblock_alloc_range_nid()`, `!align` must call `dump_stack()` and default `align` to `SMP_CACHE_BYTES` rather than `WARN*()` (unsafe early in boot on powerpc), while `reserve_mem()` clamps `align < SMP_CACHE_BYTES` to `SMP_CACHE_BYTES` before `memblock_phys_alloc()`. When a `MEMBLOCK_MIRROR` allocation fails in `memblock_find_in_range()` or `memblock_alloc_range_nid()` and falls back to non-mirrored memory, it must warn via `pr_warn_ratelimited()` and clear `MEMBLOCK_MIRROR` before retrying. [F151, F152]

## External Contracts

- `reserve_mem()` must enforce `reserved_mem_count < RESERVE_MEM_MAX_ENTRIES` (8), `size > 0`, `align >= SMP_CACHE_BYTES`, a non-whitespace `name` with `0 < strlen(name) < RESERVE_MEM_NAME_SIZE` (16), and uniqueness via `reserve_mem_find_by_name()` before `reserved_mem_add()`. `reserve_mem_kho_revive()` must verify `MEMBLOCK_KHO_NODE_COMPATIBLE`, `RESERVE_MEM_KHO_NODE_COMPATIBLE`, and `sizeof(phys_addr_t)` `"start"`/`"size"` properties with `*p_start` aligned to `align` and `*p_size == size`. [F71, F72]
- `memtest_report_meminfo()` must omit `EarlyMemtestBad:` when `!early_memtest_done` and clamp non-zero `early_memtest_bad_size < 1024` up to `1 kB`. [F81]

## Known Pitfalls

- In `memblock_double_array()`, `type->regions` and `type->max` must be updated to `new_array` before freeing `old_array` or calling `memblock_reserve_kern()`, `*in_slab` must be updated to `use_slab` only after freeing `old_array`, and `memset(new_array + type->max, 0, old_size)` must use element count `type->max` for pointer offset and byte size `old_size` for length. [F50, F111]
- Loops removing multiple regions (`memblock_remove_range()`, `memblock_cap_memory_range()`) must iterate in reverse, `memblock_trim_memory()` must decrement `r--` after `memblock_remove_region()`, and `memblock_isolate_range()` must ensure `type->cnt + 2 <= type->max` via `memblock_double_array()` before iterating and pass `idx--` to `memblock_insert_region()` when splitting a region crossing `end` (`rend > end`) so the loop revisits the bottom half. [F52, F90]
- `__memblock_find_range_top_down()` must check `this_end < size` before `this_end - size`, and `__memblock_find_range_bottom_up()` must check `cand < this_end` after `cand = round_up(this_start, align)` before `this_end - cand >= size`. [F68, F69]
- `__free_pages_memory()` and `node_map_pfn_alignment()` must check `start != 0` before `__ffs(start)`. `free_area_init_node()` and `free_area_init()` must cast PFNs to `u64` before `<< PAGE_SHIFT`. `alloc_large_system_hash()` must guard `round_up(numentries, SZ_1M / PAGE_SIZE)` with `if (PAGE_SIZE < SZ_1M)` and branch on `scale > PAGE_SHIFT` before shifting. [F101, F105, F106]
- In `free_memmap()`, `struct page` hole bounds `[start_pfn, end_pfn)` must be computed as `pfn_to_page(start_pfn - 1) + 1` and `pfn_to_page(end_pfn - 1) + 1` with physical addresses rounded inward (`PAGE_ALIGN(__pa(start_pg))`, `PAGE_ALIGN_DOWN(__pa(end_pg))`) before `memblock_phys_free()`. [F116]
- `deferred_init_memmap()` must check `!cpumask_empty(cpumask)` before `set_cpus_allowed_ptr()`, and `deferred_page_init_max_threads()` must clamp `cpumask_weight(node_cpumask)` to at least `1U`. [F140]
- `early_memtest()` must keep `patterns[0] == 0` and iterate backwards (`for (i = memtest_pattern - 1; i < UINT_MAX; --i)` after `if (!memtest_pattern) return;`) so the final pass zeroes memory; in `memtest()`, `u64 *end` must divide the byte span by `incr` (`sizeof(pattern)`), and `%pa` / `%pap` format calls must pass `&addr`. [F74, F117, F119]
