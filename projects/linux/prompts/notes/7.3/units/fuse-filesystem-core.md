# FUSE FILESYSTEM [CORE]

`fs/fuse` implements the kernel side of the Filesystem in Userspace (FUSE) and Character device in Userspace (CUSE) subsystems, bridging VFS file, directory, dentry, ACL, and DAX operations to userspace daemons. It manages request queuing, serialization, and completion over `/dev/fuse` (via read/write, splice, and io_uring), alongside optional direct backing-file passthrough and the `fusectl` control filesystem.

## Architecture & Data Flow

- `struct fuse_in_arg` and `struct fuse_arg` must maintain identical size, field types, and field offsets (`unsigned size` followed by `[const] void *value`) because `args->in_args` is cast to `(struct fuse_arg *)` and indexed as an array in `fuse_len_args()` and `fuse_copy_args()`. [F140]
- In `fuse_do_statx()` and `fuse_do_getattr()`, `file->private_data` may only be used to populate `inarg.fh` and `FUSE_GETATTR_FH` when both `file` is non-NULL and `S_ISREG(inode->i_mode)` is true, because directories have a separate file-handle namespace. [F54]
- When `fuse_update_get_attr()` populates `struct kstat` from cached attributes via `generic_fillattr()`, it must override `stat->mode`, `stat->ino`, and `stat->blksize` using `fi->orig_i_mode`, `fi->orig_ino`, and `1 << fi->cached_i_blkbits` because `inode->i_mode`, `inode->i_ino`, and `inode->i_blkbits` do not preserve the server's values. [F64]
- In `fuse_do_statx()`, `fuse_change_attributes()` must only be called when all bits of `STATX_BASIC_STATS` are present in `sx->mask` (`(sx->mask & STATX_BASIC_STATS) == STATX_BASIC_STATS`), not on a partial bitwise overlap. [F112]
- Attribute validation in `fuse_invalid_attr()` and `fuse_do_statx()` must verify `fuse_valid_size()` (`size <= LLONG_MAX`) and `fuse_valid_type(mode)`, and `convert_fuse_file_lock()` must verify `ffl->start <= OFFSET_MAX`, `ffl->end <= OFFSET_MAX`, and `ffl->end >= ffl->start` (`-EIO`). [F106]
- Ordinary request IDs generated by `fuse_get_unique_locked()` step by `FUSE_REQ_ID_STEP` (`2`) so bit 0 (`FUSE_INT_REQ_BIT`) is reserved for `FUSE_INTERRUPT` requests; `fuse_req_hash()` and `fuse_request_find()` in `fuse_dev_do_write()` must mask off `FUSE_INT_REQ_BIT` when hashing or looking up requests in `fpq->processing`. [F99]
- In `fuse_file_read_iter()`, `fuse_file_write_iter()`, `fuse_splice_read()`, and `fuse_splice_write()`, `ff->open_flags & FOPEN_DIRECT_IO` takes precedence over `fuse_file_passthrough(ff)`, whereas `FUSE_IS_DAX(inode)` takes precedence over `FOPEN_DIRECT_IO`. [F109]
- Per-IO direct write locking in `fuse_dio_lock()` and `fuse_dio_unlock()` must only acquire and release the inode's uncached I/O reference via `fuse_inode_uncached_io_start(fi, NULL)` and `fuse_inode_uncached_io_end(fi)` without modifying the file-lifetime `ff->iomode` field. [F70]
- In `__fuse_copy_file_range()`, falling back to `FUSE_COPY_FILE_RANGE` (`fc->no_copy_file_range_64`) must rebind `args.out_args[0]` from `outarg_64` to `outarg`, clamp `inarg.len` and `len` to `UINT_MAX & PAGE_MASK`, and read `bytes_copied` from `outarg.size` instead of `outarg_64.bytes_copied`. [F127]
- Before server-side range operations (`fuse_file_fallocate()` punch/zero range and `__fuse_copy_file_range()`), `fuse_writeback_range()` must flush dirty pages from `start` through `LLONG_MAX` (never `-1` or `end`) via `filemap_write_and_wait_range()` and wait for in-flight writeback via `fuse_sync_writes()`. [F60, F182]
- In `fuse_dax_write_iter()`, file-extending writes (`file_extending_write(iocb, from)`) must not use `dax_iomap_rw()` and must instead fall back to synchronous FUSE direct I/O via `fuse_dax_direct_write()`. [F194]
- In `__fuse_dax_fault()`, when `dax_iomap_fault()` returns `VM_FAULT_ERROR` with `error == -EAGAIN`, the retry path must reset `error = 0`, set `retry = true`, and call `filemap_invalidate_unlock_shared(inode->i_mapping)` before `goto retry`. [F122]
- `fuse_readlink_folio()` must request at most `folio_size(folio) - 1` bytes in `desc.length`, reject replies with `res >= PAGE_SIZE` (`-EIO`), and write a terminating NUL byte at `link[res] = '\0'`. [F105]
- `cuse_parse_one()` must advance `*pp` past leading NUL bytes up to `end` and verify `end[-1] == '\0'` before calling `strlen()` or `strsep()` on the packed `key=val` buffer from `CUSE_INIT`. [F96]
- `fuse_ctl_add_conn()` and `fuse_ctl_remove_conn()` must return early when either `fuse_control_sb` is NULL or `fc->no_control` is set. [F51]

## Synchronization

- When `fuse_abort_conn()` sees a request on `fpq->io` with `FR_LOCKED` set, it sets `FR_ABORTED` without moving `req->list` to `to_end`, so the caller (`fuse_dev_do_read()` or `fuse_dev_do_write()`) must clear `FR_LOCKED`, remove `req->list` if `!FR_PRIVATE`, and call `fuse_request_end(req)`. [F10]
- `request_wait_answer()` and `fuse_dev_do_read()` must order `FR_INTERRUPTED` and `FR_SENT` with `smp_mb__after_atomic()`, and `fuse_dev_queue_interrupt()` must execute `smp_mb()` after queuing `req->intr_entry` before testing `FR_FINISHED` (pairing with `test_and_set_bit(FR_FINISHED)` in `fuse_request_end()`). [F40]
- `fuse_set_nowrite()` must only be called with `inode_lock(inode)` held (`BUG_ON(!inode_is_locked(inode))`), and page cache truncation or invalidation (`truncate_pagecache()`, `invalidate_inode_pages2()`) in `fuse_open()` and `fuse_do_setattr()` must only run after `fuse_release_nowrite()` or `__fuse_release_nowrite()` removes `FUSE_NOWRITE`. [F163]
- Operations that modify file size across a userspace request or multi-page write loop (`fuse_do_setattr`, `fuse_perform_write`, `fuse_file_fallocate`, `__fuse_copy_file_range`) must set `FUSE_I_SIZE_UNSTABLE` in `fi->state` before the request and clear it on completion so concurrent `fuse_read_update_size()` calls do not shrink `inode->i_size`. [F68]
- Callers updating cached attributes or shrinking `i_size` from a reply (`fuse_read_update_size()`, `fuse_do_setattr()`, `fuse_dentry_revalidate()`, `fuse_do_getattr()`, `fuse_do_statx()`) must snapshot `fuse_get_attr_version(fc)` before the request and compare it against `fi->attr_version` under `fi->lock`. [F42]
- `fuse_writepage_add_to_bucket()` must hold `rcu_read_lock()` while looping on `rcu_dereference(fc->curr_bucket)` until `atomic_inc_not_zero(&wpa->bucket->count)` succeeds, and `fuse_sync_bucket_dec()` must hold `rcu_read_lock()` across `atomic_dec_and_test(&bucket->count)` and `wake_up(&bucket->waitq)`. [F30]
- DAX range reclaim (`inode_inline_reclaim_one_dmap()`, `lookup_and_reclaim_dmap()`) must acquire `filemap_invalidate_lock(inode->i_mapping)` before `fi->dax->sem` (and `fcd->lock` inside `fi->dax->sem`), and `alloc_dax_mapping_reclaim()` must only sleep on `fcd->range_waitq` when `fi->dax->nr == 0` with neither lock held. In `fuse_setup_new_dax_mapping()`, when `flags & IOMAP_FAULT` is set, it must call `alloc_dax_mapping(fcd)` and return `-EAGAIN` on exhaustion rather than `alloc_dax_mapping_reclaim()`, so `__fuse_dax_fault()` can drop `filemap_invalidate_lock_shared()` before waiting. [F166, F193]
- In `fs/fuse/dax.c`, before dropping `fi->dax->sem` to upgrade a read-only `struct fuse_dax_mapping`, `fuse_iomap_begin()` must increment `dmap->refcnt`; `try_to_free_dmap_chunks()` must pin `pos->inode` with `igrab()` under `fcd->lock` before calling `lookup_and_reclaim_dmap()`; and whenever `fi->dax->sem` is dropped and re-acquired as `down_write(&fi->dax->sem)` (`fuse_setup_new_dax_mapping()`, `fuse_upgrade_dax_mapping()`, `lookup_and_reclaim_dmap_locked()`, `inode_inline_reclaim_one_dmap()`), the caller must re-lookup `start_idx` in `fi->dax->tree` and recheck `dmap->writable` or `refcount_read(&dmap->refcnt) > 1`. [F36, F37, F77]
- In `fuse_dax_inode_cleanup()` and `inode_reclaim_dmap_range()`, which run during `evict_inode()`, `fi->dax->sem` must not be acquired while removing mappings from `fi->dax->tree`. [F164]
- When `fuse_get_user_pages()` extracts pages from a `kvec` iterator (`use_pages_for_kvec_io`) backed by a vmalloc address (`is_vmalloc_addr(user_addr)`), it must call `flush_kernel_vmap_range(ap->args.vmap_base, nbytes)` before writes and set `ap->args.invalidate_vmap` on reads so `fuse_release_user_pages()` calls `invalidate_kernel_vmap_range()`. [F175]
- `fuse_mutex` must be held when calling `fuse_ctl_add_conn()` or `fuse_ctl_remove_conn()`, and `fusectl` file operations must acquire a `struct fuse_conn` reference from `file_inode(file)->i_private` under `fuse_mutex` via `fuse_ctl_file_conn_get()` because `fuse_ctl_remove_conn()` clears `i_private` under `fuse_mutex`. [F28]

## Object Lifetimes

- Every exit path in `fuse_dev_do_write()` after `fuse_copy_one(cs, &oh, sizeof(oh))`—including the `!oh.unique` branch calling `fuse_notify()` and all header validation or request lookup failures—must invoke `fuse_copy_finish(cs)` to release any page (`cs->pg`) or pipe buffer (`cs->currbuf`) held in `struct fuse_copy_state`. Broken by: early `return` or `goto out` instead of `goto copy_finish`. [F1]
- In `fuse_try_move_folio()`, `folio_get(newfolio)` and reading `buf->flags & PIPE_BUF_FLAG_LRU` for `folio_add_lru(newfolio)` must occur before `pipe_buf_release(cs->pipe, buf)` is called, because releasing the pipe buffer without holding an extra reference on the stolen page allows `anon_pipe_buf_release()` to reuse the page or alter `buf->flags`. [F3]
- In `fuse_direct_IO()`, when `io->async` is true, `io->blocking` must be copied to a local variable before calling `fuse_aio_complete()`, and when `io->blocking` is true an extra `kref_get(&io->refcnt)` must be held while waiting on the stack-allocated `DECLARE_COMPLETION_ONSTACK(wait)` (`io->done = &wait`). [F147]
- In `fuse_release()`, when `fc->writeback_cache` is enabled, `write_inode_now(inode, 1)` must be called before `fuse_release_common(file, false)` unlinks the `fuse_file` from `fi->write_files`. [F183]
- In `fuse_read_batch_forget()`, the `while (head)` loop must advance `head = forget->next` and call `kfree(forget)` for every dequeued `fuse_forget_link` node even after `fuse_copy_one()` sets `err` non-zero, skipping only the `fuse_copy_one()` call when `err` is set. [F117]
- `fuse_dax_conn_free()` must set `fc->dax = NULL` after freeing `fc->dax->free_ranges` and `kfree(fc->dax)` so that subsequent teardown calls on the same `struct fuse_conn` do not double-free `fc->dax`. [F5]
- In `cuse_process_init_reply()`, once `device_initialize(dev)` sets `dev->release = cuse_gendev_release`, `dev` must be freed via `put_device(dev)` (or `device_unregister(dev)`) and never passed directly to `kfree(dev)`, while `struct cuse_conn` is freed separately by `cuse_fc_release()` when `fc` reaches zero references. [F154]

## API Contracts

- On idmapped mounts (`!(fm->sb->s_iflags & SB_I_NOIDMAP)`), only inode-creating requests (`fuse_create_open()`, `create_new_entry()`, and `fuse_rename2()` with `RENAME_WHITEOUT`) pass `mnt_idmap` via `fuse_simple_idmap_request()`, while other requests must pass `&invalid_mnt_idmap` so `req->in.h.uid/gid` are `FUSE_INVALID_UIDGID`. [F186]
- PIDs sent to the FUSE server in `fuse_get_req()`, `fuse_force_creds()`, and `fuse_setlk()` must be translated into `fc->pid_ns` via `pid_nr_ns(..., fc->pid_ns)`, and lock PIDs returned by the server in `convert_fuse_file_lock()` must be translated from `fc->pid_ns` into `&init_pid_ns` under `rcu_read_lock()`. [F190]
- File-modifying VFS operations (`fuse_cache_write_iter()`, `fuse_file_fallocate()`, `__fuse_copy_file_range()`, and `fuse_dax_write_iter()`) must call `kiocb_modified()`, `file_modified()`, or `file_remove_privs()` while holding `inode_lock(inode)` before mutating the file. [F185]
- After completing a file, atomic-create, or directory open in `fuse_open()`, `fuse_create_open()`, or `fuse_dir_open()`, if `FOPEN_KEEP_CACHE` is not set in `ff->open_flags` (and the page cache was not already truncated to 0 by `atomic_o_trunc`), `invalidate_inode_pages2(inode->i_mapping)` must be called. [F66]
- `create_new_nondir()` converts the dentry pointer returned by `create_new_entry()` directly via `PTR_ERR()`, which is only valid for non-directory modes (`!S_ISDIR(mode)`) because `d_splice_alias()` can return a non-NULL alternate dentry for directories. [F47]
- In `fuse_do_statx()`, `fuse_do_getattr()`, and `fuse_update_get_attr()`, the `struct kstat *stat` parameter may be NULL (such as when called from `fuse_update_attributes()` or `fuse_perm_getattr()`), so `stat` must be checked for non-NULL before dereferencing. [F50]
- `fuse_copy_out_args()` includes `sizeof(struct fuse_out_header)` in `reqsize` only when `!cs->is_uring`, rejects `nbytes > reqsize` or (`nbytes < reqsize && !args->out_argvar`), and when `args->out_argvar` is set requires `reqsize - nbytes <= lastarg->size` before shrinking `lastarg->size`. [F91]
- `fuse_try_move_folio()` returns `0` when the pipe buffer folio was stolen into the page cache, a negative errno on abort or pipe confirmation failure, and positive `1` when page stealing fell back so `fuse_copy_folio()` must copy the data from `cs->pg`. [F48]
- `alloc_dax_mapping()` returns NULL when no free DAX range is available, whereas `alloc_dax_mapping_reclaim()` blocks or reclaims inline and returns an `ERR_PTR()` on failure; `fuse_setup_new_dax_mapping()` must check `!alloc_dmap` for `alloc_dax_mapping()` and `IS_ERR(alloc_dmap)` for `alloc_dax_mapping_reclaim()`. [F45]
- `fuse_dax_break_layouts()` takes inclusive start and end byte offsets (`u64 dmap_start`, `u64 dmap_end`); callers unmapping layouts across an entire inode must pass `0` and `-1` (`ULLONG_MAX`) rather than `0` and `0`. [F59]
- `fuse_dev_ioctl_clone()` must verify `fd_file(f)->f_op == file->f_op` before calling `__fuse_get_dev(fd_file(f))`, and `cuse_init()` must clear `cuse_channel_fops.unlocked_ioctl = NULL`, because CUSE channels also store a `struct fuse_dev *` in `file->private_data` but assume a single channel per `cuse_conn` on release. [F155]

## Error Handling

- Write and copy completion paths (`fuse_aio_complete_req()`, `fuse_send_write()`, `fuse_send_write_pages()`, and `__fuse_copy_file_range()`) must reject userspace replies where the reported byte count (`ia->write.out.size` or `bytes_copied`) exceeds the requested byte count by returning `-EIO`. [F89]
- In `fuse_get_user_pages()`, the in/out parameter `*nbytesp` must be updated to the number of bytes actually packed into `ap` (`0` on early allocation failure) on all return paths. [F55]

## External Contracts

- All kernel `fl_owner_t` values (such as `current->files`, `file`, or `fl->c.flc_owner`) sent to userspace in FUSE request headers must be scrambled with `fuse_lock_owner_id(fc, id)` so that kernel pointer addresses are not leaked to the FUSE daemon. [F189]
- When `!fc->posix_acl`, `fuse_get_inode_acl()` must return NULL, `fuse_no_acl()` must reject `fuse_get_acl()` and `fuse_set_acl()` with `-EOPNOTSUPP` when `i_user_ns(inode) != &init_user_ns`, and `fuse_set_acl()` must not set `FUSE_SETXATTR_ACL_KILL_SGID` or call `forget_all_cached_acls()` and `fuse_invalidate_attr()`. [F187]
- In `fuse_getattr()`, when `!fuse_allow_current_process(fc)` and `request_mask` is 0, it must set `stat->result_mask = 0` and `stat->dev = inode->i_sb->s_dev` and return 0 rather than failing with `-EACCES`. [F188]

## Known Pitfalls

- Because `fuse_folios_alloc()` allocates the `folios` and `descs` arrays in a single compound buffer (`*desc = (void *)(folios + nfolios)`), `fuse_pages_realloc()` must copy and update both `ap->folios` and `ap->descs` before freeing the old `ap->folios` pointer, and callers must never `kfree(ap->descs)`. [F75]
- `extend_arg()` reallocates `buf->value` via `krealloc()` (and frees `buf->value` and resets `buf->value = NULL` on failure), so callers must not retain pointers into `buf->value` across `extend_arg()` calls. [F139]
- Because `struct fuse_inode::inval_mask` is a 32-bit `u32` rather than an `unsigned long` bitmap, atomic bit modifications on `fi->inval_mask` must use `set_mask_bits(&fi->inval_mask, ...)` and never `set_bit()` or `clear_bit()`. [F151]
- When `fuse_copy_folio()` maps a folio via `kmap_local_folio(folio, offset)`, if `folio_test_highmem(folio)` is true and `count > PAGE_SIZE - offset_in_page(offset)`, the per-iteration copy size must be clamped to `PAGE_SIZE - offset_in_page(offset)` before calling `fuse_copy_do()`. [F176]
