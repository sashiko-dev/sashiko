# HISILICON NETWORK SUBSYSTEM 3 DRIVER (HNS3)

This component implements the Hisilicon Network Acceleration Engine 3 (HNAE3) bus/matching framework, the HNS3 Ethernet client driver (`hns3_enet` netdev, TX/RX ring datapath, NAPI, ethtool, DCBNL, and debugfs), and the PF/VF common hardware library (command queue, RSS, and TQP statistics).

## Architecture & Data Flow
- `priv->ring` holds `2 * h->kinfo.num_tqps` elements (`[0, num_tqps)` TX, `[num_tqps, 2 * num_tqps)` RX), while `ring->queue_index` and `ring->tqp->tqp_index` stay in `[0, num_tqps)`. `hns3_dbg_bd_file_init()` creates debugfs files for `hns3_get_max_available_channels(handle)`, so `hns3_dbg_tx_bd_info()` and `hns3_dbg_rx_bd_info()` must check `data->qid >= h->kinfo.num_tqps` before indexing `priv->ring`. [F63, F64]
- `hns3_init_tx_spare_buffer()` leaves `ring->tx_spare = NULL` when `tx_spare_buf_size` is `0`, exceeds `MAX_PAGE_ORDER`, or fails allocation/DMA mapping (resetting `kinfo.tx_spare_buf_size = 0`). Callers must check `ring->tx_spare != NULL`, and `hns3_set_tunable()` for `ETHTOOL_TX_COPYBREAK_BUF_SIZE` must revert if `priv->ring->tx_spare` is `NULL` when `new_tx_spare_buf_size != 0`. [F33, F47]
- `hns3_tx_spare_space()` computes `max(ntc, tx_spare->len - ntu) - 1` in `u32` and `hns3_tx_spare_alloc()` aligns `size` to `dma_get_cache_alignment()`, so `tx_spare->next_to_use` must stay `< tx_spare->len` and callers (`hns3_can_use_tx_bounce()`, `hns3_can_use_tx_sgl()`) must verify `ALIGN(size, dma_get_cache_alignment()) <= space`. On wrap to `0`, `hns3_tx_spare_alloc()` must add `(tx_spare->len - ntu)` to `*cb_len`, and `hns3_tx_spare_rollback()` / `desc_cb->length` must use `*cb_len` rather than `size`. [F69, F107, F121]
- In `hns3_nic_net_xmit()`, pad every TX packet to `HNS3_MIN_TX_LEN` (33 bytes) via `skb_put_padto()`, and call `hns3_tx_doorbell()` on every exit path (including error/busy returns) so queued `netdev_xmit_more()` descriptors in `ring->pending_buf` are flushed. Direct push via `hns3_tx_push_bd()` is only valid when `HNS3_NIC_STATE_TX_PUSH_ENABLE` is set, `ring->pending_buf == 0`, `0 < num <= HNS3_MAX_PUSH_BD_NUM`, and `doorbell` is true. [F96, F163]
- `hns3_skb_bd_num()` and `hns3_tx_bd_num()` must abort as soon as `bd_num > HNS3_MAX_TSO_BD_NUM` so writes to `bd_size[HNS3_MAX_TSO_BD_NUM + 1U]` in `hns3_nic_maybe_stop_tx()` stay in bounds. `hns3_skb_need_linearized()` computes unsigned bounds `max_non_tso_bd_num - 1U` and `bd_num - max_non_tso_bd_num`, so callers must ensure `max_non_tso_bd_num >= 1` and `max_non_tso_bd_num < bd_num <= HNS3_MAX_TSO_BD_NUM`. [F70, F108]
- Per-packet RX completion metadata (`pkt_len`, `l234_info`, `ol_info`, `csum`, `rss_hash`, `vlan_tag`, `ot_vlan_tag`, `ts_nsec`/`ts_sec`) is only valid on the last descriptor (`BIT(HNS3_RXD_FE_B)`), so `hns3_handle_bdinfo()` must read it from `pre_ntc` (`next_to_clean - 1` mod `desc_num`). In `hns3_clean_rx_ring()`, when `hns3_handle_rx_bd()` returns `-ENXIO` or `!ring->skb`, jump to `out` without adding `ring->pending_buf` to `unused_count` or clearing `ring->skb` / `ring->pending_buf`; other errors must reset `ring->skb = NULL` and reclaim `ring->pending_buf`. [F42, F93]
- `hns3_rx_ptype_tbl` is indexed by `HNS3_RXD_PTYPE_M` only when `HNS3_NIC_STATE_RXD_ADV_LAYOUT_ENABLE` is set; otherwise `ptype` is `HNS3_INVALID_PTYPE`, which `hns3_checksum_complete()` and `hns3_rx_handle_csum()` must reject. In `hns3_rx_checksum()`, calling `hns3_checksum_complete()` must not return early before checking `BIT(HNS3_RXD_L3L4P_B)` and RX error bits (`HNS3_RXD_L3E_B`, `HNS3_RXD_L4E_B`, `HNS3_RXD_OL3E_B`, `HNS3_RXD_OL4E_B`), which reset `skb->ip_summed` to `CHECKSUM_NONE`. [F71, F158]
- Keep device and per-queue state in lockstep: `hns3_set_ringparam()` must update `h->kinfo` (`num_tx_desc`, `num_rx_desc`, `rx_buf_len`, `tqp[i]->buf_size`) alongside `priv->ring` and revert both from `hns3_backup_ringparam()` on `hns3_init_all_ring()` failure; `hns3_set_tunable()` must propagate `priv->tx_copybreak`/`rx_copybreak` to every TX/RX ring; `hns3_set_coalesce()` and `hns3_set_cq_period_mode()` must update `priv`, each `tqp_vector`, and hardware registers together (guarding `HNS3_GL0_CQ_MODE_REG`/`HNS3_GL1_CQ_MODE_REG` with `hnae3_ae_dev_cq_supported(ae_dev)`). [F46, F48, F50, F135]
- `ring_space()` and `hclge_comm_ring_space()` must subtract 1 (`desc_num - used - 1`) so `next_to_use` never catches up to `next_to_clean`. `hns3_get_max_available_channels()` divides by `h->kinfo.tc_info.num_tc` and `hns3_nic_init_vector_data()` computes `i % priv->vector_num` without zero checks, so `h->kinfo.tc_info.num_tc >= 1` and `priv->vector_num >= 1` (when `num_tqps > 0`) must always hold. [F66, F104, F105]
- Single-descriptor command structs cast onto `struct hclge_desc::data` must not exceed `HCLGE_DESC_DATA_LEN * sizeof(__le32)` (24 bytes). Mailbox structs in `hclge_mbx.h` must stay `#pragma pack(1)` and at most `HCLGE_MBX_MAX_MSG_SIZE` (14 bytes) for messages or `HCLGE_MBX_MAX_RESP_DATA_SIZE` (8 bytes) for responses. [F112, F113]

## Synchronization
- Accesses to `hnae3_ae_algo_list`, `hnae3_client_list`, and `hnae3_ae_dev_list` in `hnae3_register_*` / `hnae3_unregister_*` must hold `hnae3_common_lock`. However, `hnae3_unregister_ae_algo_prepare()` must hold `device_lock(&ae_dev->pdev->dev)` around `pci_disable_sriov(ae_dev->pdev)` and must NOT hold `hnae3_common_lock`, because VF removal synchronously calls `hns3_remove()` -> `hnae3_unregister_ae_dev()`, which takes `hnae3_common_lock`. `hns3_exit_module()` must hold `hnae3_acquire_unload_lock()` / `hnae3_release_unload_lock()`. [F16, F19, F143]
- `hclge_comm_cmd_send()` must hold `spin_lock_bh(&hw->cmq.csq.lock)` across checking `HCLGE_COMM_STATE_CMD_DISABLE` and `hclge_comm_ring_space()`, writing descriptors and `HCLGE_COMM_NIC_CSQ_TAIL_REG`, and polling completion in `hclge_comm_wait_for_resp()` with non-sleeping `udelay()`. `hclge_comm_cmd_init()` and `hclge_comm_cmd_uninit()` must nest `crq.lock` inside `csq.lock`. [F27, F141]
- In `hns3_tx_doorbell()`, update `ring->last_to_use` via `smp_store_release(&ring->last_to_use, ring->next_to_use)`—paired with `smp_load_acquire()` in `hns3_nic_reclaim_desc()`—before `hns3_tx_push_bd()` or ringing the doorbell. `hns3_nic_reclaim_desc()` must update `ring->next_to_clean` with `smp_store_release()` paired with `smp_load_acquire()` in `ring_space()`, and `hns3_nic_maybe_stop_tx()` / `hns3_clean_tx_ring()` must execute `smp_mb()` between stopping/checking the subqueue and rechecking `ring_space(ring)`. [F23, F24]
- `hns3_tx_spare_reclaim_cb()` must complete `dma_sync_single_for_cpu()` or `dma_unmap_sg()` before `hns3_tx_spare_update()` publishes `tx_spare->next_to_clean` to `tx_spare->last_to_clean` via `smp_store_release()`, pairing with `smp_load_acquire(&tx_spare->last_to_clean)` in `hns3_tx_spare_space()`. `hns3_tx_push_bd()` and `hns3_tx_mem_doorbell()` must issue `dma_wmb()` before `__iowrite64_copy()`, and `hns3_handle_rx_bd()` / `hns3_add_frag()` must issue `dma_rmb()` after checking `HNS3_RXD_VLD_B`. [F149, F151]
- `hns3_enable_irqs_and_tqps()` must enable NAPI and OS IRQs (`hns3_irq_enable()`) for all vectors in one loop before unmasking vector IRQs (`hns3_mask_vector_irq(..., 1)`) and enabling TQPs (`hns3_tqp_enable()`) in separate loops. `hns3_disable_irqs_and_tqps()` must reverse these three phases: disable TQPs (`hns3_tqp_disable()`), mask vector IRQs (`hns3_mask_vector_irq(tqp_vector, 0)`), and then call `hns3_irq_disable()` (`disable_irq()`, `napi_disable()`, and `cancel_work_sync()` on both `rx_group.dim.work` and `tx_group.dim.work`). [F21, F128]
- In `hns3_reset_notify_uninit_enet()`, if `HNS3_NIC_STATE_DOWN` is not set on `priv->state`, call `hns3_nic_net_stop(netdev)` before clearing `HNS3_NIC_STATE_INITED` and calling `hns3_nic_uninit_vector_data()` (`netif_napi_del()`). [F22]

## Object Lifetimes
- `ae_dev->ops->init_client_instance` must set `hnae3_set_client_init_flag(client, ae_dev, 1)` on success because `hnae3_uninit_client_instance()` checks `hnae3_get_client_init_flag()`. In `hnae3_unregister_ae_algo()` and `hnae3_unregister_ae_dev()`, uninitialize all matching clients via `hnae3_uninit_client_instance()` before calling `ae_algo->ops->uninit_ae_dev(ae_dev)` and clearing `HNAE3_DEV_INITED_B` and `ae_dev->ops`. [F1, F2]
- In `hclge_comm_cmd_uninit()`, set `HCLGE_COMM_STATE_CMD_DISABLE` on `hw->comm_state` and complete `msleep(HCLGE_COMM_CMDQ_CLEAR_WAIT_TIME)` before zeroing CSQ/CRQ registers under `csq.lock`/`crq.lock` and freeing descriptor DMA memory with `hclge_comm_free_cmd_desc()`. [F3]
- In `hns3_client_init()`, `hns3_state_init(handle)` (`HNS3_NIC_STATE_INITED`) and `register_netdev(netdev)` must run only after rings, vectors, IRQs (`IRQ_NOAUTOEN` set before `request_irq()`), `hns3_client_start()`, and `hns3_dbg_init()` succeed. `hns3_client_uninit()` must call `unregister_netdev(netdev)` first, gate IRQ/ring/vector teardown on `test_and_clear_bit(HNS3_NIC_STATE_INITED, &priv->state)` (shared with `hns3_reset_notify_uninit_enet()`), and then call `hns3_dbg_uninit(handle)` and `free_netdev(netdev)`. [F6, F20, F127]
- Although `priv->ring`, `priv->tqp_vector`, `ring->desc_cb`, `ring->tx_spare`, and `hnae3_ring_chain_node` use `devm_kzalloc`/`devm_kcalloc` on `&pdev->dev`, they are reallocated across resets, channel changes, and ringparam updates and must be explicitly freed with `devm_kfree()`. In `hns3_fini_ring()`, `hns3_free_desc(ring)` must run before `devm_kfree(ring->desc_cb)`, before freeing `ring->tx_spare`, and before `page_pool_destroy(ring->page_pool)`. [F7, F8]
- While `hns3_nic_resetting(netdev)` is true, `hns3_nic_net_down()` and `hns3_external_lb_prepare()` must skip `hns3_clear_all_ring()` and `hns3_nic_reset_all_ring()`, deferring cleanup to `hns3_reset_notify_uninit_enet()`, which calls `hns3_clear_all_ring(handle, true)` to unmap un-reused RX buffers without allocating replacements. [F9]
- When `ring->page_pool` is active, `hns3_alloc_and_map_buffer()` / `hns3_unmap_buffer()` must not `dma_map_page()` / `dma_unmap_page()` on `DESC_TYPE_PP_FRAG` buffers; `hns3_alloc_skb()` (`length > HNS3_RX_HEAD_SIZE`) and `hns3_add_frag()` (`frag_list` `new_skb`) must call `skb_mark_for_recycle()`, and `hns3_rx_skb()` must call `napi_gro_flush(&ring->tqp_vector->napi, false)` before `napi_gro_receive()` when `skb_has_frag_list(skb)` is true. For non-`page_pool` `DESC_TYPE_PAGE` buffers, drain remaining bias via `__page_frag_cache_drain(cb->priv, cb->pagecnt_bias)` when `reuse_flag` is 0. [F12, F154, F167]

## API Contracts
- Callers of `hns3_free_buffer()`, `hns3_free_buffer_detach()`, and `hns3_clean_tx_ring()` outside NAPI softirq poll context must pass `budget = 0` for `napi_consume_skb()`. When `hns3_clean_rx_ring()` is called from process context in `hns3_lb_check_rx_ring()`, bracket it with `preempt_disable()` / `preempt_enable()` because it uses `napi_alloc_skb()` and `napi_alloc_frag()`. [F146, F147]
- `hns3_handle_rx_copybreak()` returns `0` on success and `-ENOMEM` on failure, so `hns3_nic_reuse_page()` must return early when `ret == 0`. Before modifying in-packet headers on TX (`hns3_handle_vtags()`, `hns3_set_tso()`), call `skb_cow_head(skb, 0)` and abort on negative return. `hns3_nic_set_features()` must only program hardware for `netdev->features ^ features` and never modify `netdev->features` directly. [F32, F156, F162]

## Error Handling
- In `hclge_comm_cmd_init()`, after `clear_bit(HCLGE_COMM_STATE_CMD_DISABLE, &hw->comm_state)`, any error must jump to `err_cmd_init` to set `HCLGE_COMM_STATE_CMD_DISABLE` again. In `hns3_client_init()`, if `register_netdev()` fails, rollback must call `hns3_state_uninit()`, `hns3_dbg_uninit()`, and `hns3_client_stop()` before tearing down IRQs, PHY, rings, vectors, and `netdev`. [F4, F5]
- On TX descriptor filling errors in `hns3_handle_skb_desc()`, `hns3_handle_tx_bounce()`, or `hns3_handle_tx_sgl()`, `hns3_clear_desc()` and `hns3_tx_spare_rollback()` must rewind `ring->next_to_use` and `tx_spare->next_to_use`. In `hns3_clear_desc()`, zero `ring->desc[ring->next_to_use]` before checking `ring->next_to_use == next_to_use_orig`, and only call `ring_ptr_move_bw(ring, next_to_use)` and unmap `ring->desc_cb[ring->next_to_use]` after that check. [F11, F89]
- In `hns3_change_channels()` and `hns3_set_tx_spare_buf_size()`, if `HNAE3_UP_CLIENT` fails after `HNAE3_INIT_CLIENT` succeeded, call `hns3_reset_notify(handle, HNAE3_UNINIT_CLIENT)` before returning. Store rollback return codes in `hns3_set_channels()` and `hns3_set_tunable()` in a separate variable (`ret1`) so `ret1 == 0` does not overwrite `ret`. In `hns3_set_ringparam()`, `hns3_backup_ringparam()` copies `priv->ring` into `tmp_rings` with `skb = NULL` before `hns3_init_all_ring()`: free `tmp_rings` via `hns3_fini_ring()` on success, or copy `tmp_rings` back without `hns3_fini_ring()` on failure. [F14, F15, F36]
- Because `hns3_put_ring_config()` sets `priv->ring = NULL` during reset uninit, ethtool callbacks (`hns3_get_ringparam()`, `hns3_check_ringparam()`, `hns3_set_tunable()`) must check both `hns3_nic_resetting(ndev)` and `priv->ring != NULL`. `hns3_alloc_page_pool()` must set `ring->page_pool = NULL` on `IS_ERR()`, and callers must check `ring->page_pool != NULL`. [F34, F35]

## Known Pitfalls
- `hnae3_set_bit()` and `hnae3_get_bit()` in `hnae3.h` use `0x1 << (shift)` (signed 32-bit `int`), so `shift` must be in `[0, 30]`. `hnae3_set_field(origin, mask, shift, val)` complements `mask` in `mask`'s type and shifts `val` in `val`'s type, so for a 64-bit `origin`, `mask` must be 64-bit (`GENMASK_ULL`) and `val` widened to 64-bit when `(val) << (shift)` reaches bit 31+. Unlike `hnae3_set_field()`, `hns3_set_field()` in `hns3_enet.c` only bitwise-ORs `(val) << (shift)` without clearing target bits, requiring `origin` (`struct hns3_desc_param`) to be zero-initialized via `hns3_init_desc_data()`. [F81, F97, F98]
- In `hns3_desc_unused()`, `ring->next_to_clean == ring->next_to_use` is ambiguous between a refilled and an empty RX ring, so check `!ring->desc_cb[ntc].refill` to return `ring->desc_num` only when empty. In `hns3_add_frag()`, when `ring->tail_skb` is non-NULL (`frag_list` active), accumulate `truesize`, `data_len`, and `len` on `head_skb` (`ring->skb`) before reassigning `skb = ring->tail_skb` for `hns3_nic_reuse_page(skb, ...)`. [F65, F95]
- In `hclge_comm_set_rss_indir_table()` and `hclge_comm_set_rss_algo_key()`, call `hclge_comm_cmd_setup_basic_desc(&desc, ..., false)` inside each loop iteration because `req` aliases `desc.data` and both loops accumulate fields (`req->rss_qid_h` via `hclge_comm_append_rss_msb_info()` and `req->hash_config`) with `|=`. `hclge_comm_get_rss_indir_tbl()` must copy `u16 rss_indirection_tbl[]` into `u32 indir[]` element-by-element, not with `memcpy()`. [F77, F88, F124]
