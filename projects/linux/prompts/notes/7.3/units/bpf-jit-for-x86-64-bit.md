# BPF JIT for X86 64-BIT

This component implements the x86-64 Just-In-Time (JIT) compiler for eBPF programs, BPF trampolines (`fentry`/`fexit`/`fmod_ret`/`struct_ops`), and BPF dispatchers. It translates verified eBPF bytecode into native x86-64 machine instructions across multiple convergence passes, manages executable text packing and runtime text poking (for direct tail calls and trampolines), and provides exception fixup handling (`ex_handler_bpf`) and ORC-based stack walking for BPF exceptions.

## Architecture & Data Flow

- Every JITed exit and unwind path (`BPF_EXIT` in `do_jit()`, `emit_bpf_tail_call_indirect()`, `emit_bpf_tail_call_direct()`, and `is_exception_cb` in `emit_prologue()`) must pop callee-saved registers in reverse prologue order (`pop_callee_regs()` then `pop_r12()`), saving/restoring `r12` when `arena_vm_start` is non-zero (where `X86_REG_R12` holds `arena_vm_start` and must not be used as scratch) or `exception_boundary` is true, and using `all_callee_regs_used` on `exception_boundary` frames (where `is_exception_cb` sets `%rsp = %rsi`, `%rbp = %rdx`, pops registers, and sets `%rsp = %rbp`). [F9, F102, F111]
- `emit_prologue()` must emit `X86_TAIL_CALL_OFFSET` (`12 + ENDBR_INSN_SIZE`) bytes between `prog->bpf_func` (`image + cfi_get_offset()`) and the post-frame-setup `EMIT_ENDBR()` for non-cBPF, non-exception-callback programs. Before jumping to `target->bpf_func + X86_TAIL_CALL_OFFSET`, `emit_bpf_tail_call_indirect()` and `emit_bpf_tail_call_direct()` must pop callee-saved registers and `r12`, pop both 8-byte tail-call stack slots from `emit_prologue_tail_call()`, and add `round_up(stack_depth, 8)` back to `rsp`. [F10, F52]
- Whenever stack offsets or frame pointers depend on `stack_depth` (`emit_prologue()`, `BPF_TAIL_CALL_CNT_PTR_STACK_OFF()`, `LOAD_TAIL_CALL_CNT_PTR()`, `LOAD_TRAMP_TAIL_CALL_CNT_PTR()`), the depth must be rounded up via `round_up(..., 8)`. When `tail_call_reachable` is true, `emit_prologue_tail_call()` places `tail_call_cnt_ptr` at `BPF_TAIL_CALL_CNT_PTR_STACK_OFF(stack_depth)` (`-16 - round_up(stack_depth, 8)` from `%rbp`), and `BPF_PSEUDO_CALL` must load it into `%rax` via `LOAD_TAIL_CALL_CNT_PTR(stack_depth)` without clobbering `%rax` before `emit_call()`. [F44, F104]
- When `prog->aux->jits_use_priv_stack` is set, `priv_stack_ptr` is allocated as `round_up(stack_depth, 8) + 2 * PRIV_STACK_GUARD_SZ` bytes with `PRIV_STACK_GUARD_VAL` at index 0 and `(alloc_size - PRIV_STACK_GUARD_SZ) >> 3`. When `priv_stack_ptr` is non-NULL in `do_jit()`, `priv_frame_ptr` is set to that upper guard offset (`priv_stack_ptr + PRIV_STACK_GUARD_SZ + round_up(stack_depth, 8)`), `stack_depth` must be zeroed for kernel-stack prologue/tail-call emission, `BPF_REG_FP` must be remapped to `X86_REG_R9`, and `X86_REG_R9` must be preserved with `push_r9`/`pop_r9` around every `BPF_JMP | BPF_CALL`. [F38, F57]
- In `__arch_prepare_bpf_trampoline()`, when `flags & BPF_TRAMP_F_CALL_ORIG` is set, the trampoline must emit `__bpf_tramp_enter(im)` before `fentry`/`fmod_ret` and emit `__bpf_tramp_exit(im)` after the `fmod_ret` branch target (`do_fexit`) and `fexit` links while recording `im->ip_after_call` and `im->ip_epilogue`. When `BPF_TRAMP_F_TAIL_CALL_CTX` is set, it must push `%rax` after allocating `stack_size`, restore `%rax` via `LOAD_TRAMP_TAIL_CALL_CNT_PTR(stack_size)` before `orig_call` or epilogue return, and use `%rbx` (`BPF_REG_6`) instead of `%rax` for `BPF_TRAMP_F_ORIG_STACK` calls. [F8, F105]
- `struct exception_table_entry` packs instruction length, `reg2pt_regs[]` offsets (or `DONT_CLEAR` = 1 for stores), and `FIXUP_ARENA_ACCESS` into `fixup` and a 16-bit signed offset with `EX_TYPE_BPF` into `data`; any register indexed in `reg2pt_regs[]` must be `<= BPF_REG_9` (never `BPF_REG_FP`, `BPF_REG_AX`, `AUX_REG`, or `X86_REG_R9`), and `fixup`/`data` bitfield changes must update `ex_handler_bpf()`. [F51]
- Because `bpf_arch_uaddress_limit()` returns 0 on x86-64, `do_jit()` must precede every `BPF_PROBE_MEM` or `BPF_PROBE_MEMSX` load with an unsigned check `(src_reg + insn->off) - VSYSCALL_ADDR > TASK_SIZE_MAX + PAGE_SIZE - VSYSCALL_ADDR` that zeroes `dst_reg` and skips the load on non-kernel addresses without clobbering registers other than `BPF_REG_AX` (`%r10`), `AUX_REG` (`%r11`), and `dst_reg`. [F109]
- `addrs` in `bpf_int_jit_compile()` and `do_jit()` has `prog->len + 1` elements where `addrs[0]` holds the prologue length and `addrs[1..prog->len]` hold 1-based instruction end offsets; `BPF_LD | BPF_IMM | BPF_DW` consumes two `struct bpf_insn` slots and must increment both `insn` and `i` in lockstep, and 0-based callers like `bpf_prog_fill_jited_linfo()` must be passed `addrs + 1`. [F43, F48]
- Short jump offsets in `do_jit()` are checked with `is_imm8_jmp_offset()` (`[-128, 123]`) rather than `is_imm8()`, and when `jmp_padding` is active, any shrinkage from a near jump to a short or elided jump must be padded with `INSN_SZ_DIFF` NOPs before the jump instruction so `addrs[i]` cannot shrink. When `do_jit()` compiles `BPF_JMP | BPF_JA` with `insn->off == -1` or `BPF_JMP32 | BPF_JA` with `insn->imm == -1`, it must set `jmp_offset = -2` directly instead of computing `addrs[i - 1] - addrs[i]`. [F53, F59]
- `reg2hex[]` stores only the lower 3 bits of each x86-64 register number, so any encoder using `reg2hex[]` (`add_1reg()`, `add_2reg()`, `emit_3vex()`) must test `is_ereg()` to set the REX/VEX extension bit for `r8`..`r15`. For 8-bit register stores (`BPF_B` in `emit_stx()`), `is_ereg_8l(src_reg)` must also be checked so `BPF_REG_1` (`%rdi`), `BPF_REG_2` (`%rsi`), and `BPF_REG_FP` (`%rbp`) emit a `0x40` REX prefix (`%dil`, `%sil`, `%bpl`) instead of `%bh`, `%dh`, `%ch`. [F49, F112]
- In `bpf_tail_call_direct_fixup()`, each `poke_tab` entry must be checked for `(!poke->aux || poke->aux == prog->aux)` and `poke->reason == BPF_POKE_REASON_TAIL_CALL` before downcasting `poke->tail_call.map` to `struct bpf_array`. In `emit_bpf_tail_call_indirect()`, the tail-call index in `%edx` and `array->map.max_entries` are 32-bit unsigned values, so `%edx` must be zero-extended (`mov edx, edx`) and compared with a 32-bit `cmp` before indexing `array->ptrs[index]`. [F28, F45]
- In `do_jit()`, 16-bit endianness conversions (`BPF_ALU | BPF_END | BPF_FROM_BE`, `BPF_ALU64 | BPF_END | BPF_FROM_LE`, and `BPF_ALU | BPF_END | BPF_FROM_LE` with `imm32 == 16`) must emit `movzwl` (`0x0F 0xB7`) and 32-bit `BPF_ALU | BPF_END | BPF_FROM_LE` (`imm32 == 32`) must emit 32-bit `mov` (`0x89`) to zero-extend to 64 bits. Emitting `BPF_DIV` or `BPF_MOD` must zero `rdx` (`xor edx, edx`) before `div` when `insn->off == 0`, and sign-extend via `cdq` (`BPF_ALU`) or `cqo` (`BPF_ALU64`) before `idiv` when `insn->off != 0`. [F73, F78]
- In `emit_spectre_bhb_barrier()`, when `X86_FEATURE_CLEAR_BHB_LOOP` is enabled, `%rax` and `%rcx` must be saved on the stack before calling `clear_bhb_loop` and restored afterward, and the subsequent IBHF emission check must remain an independent `if` (not `else if`) so both execute when `X86_FEATURE_HYPERVISOR` is also set. [F95]
- `do_jit()` emits each BPF instruction into `u8 temp[BPF_MAX_INSN_SIZE + BPF_INSN_SAFETY]` without per-byte bounds checks and only validates `ilen <= BPF_MAX_INSN_SIZE` (128 bytes) and `proglen + ilen <= oldproglen` after the instruction is emitted. [F54]

## Synchronization

- In `__bpf_arch_text_poke()`, verifying that existing bytes at `ip` match `old_insn` (`memcmp(ip, old_insn, X86_PATCH_SIZE)`) and patching `new_insn` via `smp_text_poke_single()` must occur under a single continuous hold of `text_mutex`. In `bpf_int_jit_compile()`, `bpf_jit_binary_pack_finalize(header, rw_header)` must succeed before `bpf_tail_call_direct_fixup(prog)` is called. [F15, F16]
- In `invoke_bpf_prog()`, every generated call to `p->bpf_func` must be bracketed by `bpf_trampoline_enter(p)` (storing the returned start timestamp in callee-saved `BPF_REG_6` / `%rbx` and skipping `p->bpf_func` on a zero return) and an unconditional call to `bpf_trampoline_exit(p)` receiving `(p, rbx, &run_ctx)`. [F107]

## Object Lifetimes

- Because `bpf_jit_binary_pack_finalize(header, rw_header)` consumes and frees both `rw_header` and `header` even on error, `bpf_int_jit_compile()` must set `header = NULL` before jumping to `out_image:` on failure. In `bpf_jit_free()`, if `prog->jited` is set and `prog->aux->jit_data` is non-NULL, it must call `bpf_jit_binary_pack_finalize()` and free `jit_data->addrs` and `jit_data` before `bpf_jit_binary_pack_free()`, and must always call `bpf_prog_unlock_free(prog)`. [F3, F6]
- In `__arch_prepare_bpf_trampoline()`, once `branches` is allocated for `fmod_ret->nr_links`, every subsequent error path must jump to `cleanup:` so `kfree(branches)` runs before returning. [F7]

## API Contracts

- All relative branch and call emitters (`emit_patch`, `emit_call`, `emit_rsb_call`, `emit_jump`, `emit_cond_near_jump`, `emit_indirect_jump`, `emit_return`, and `x86_call_depth_emit_accounting`) require `ip` to be the target instruction's address in the final executable `image` buffer while writing bytes to `*pprog` in the temporary or `rw_image` buffer, and callers must advance `ip` by the exact byte count of all instructions emitted since the base `ip` (including `x86_call_depth_emit_accounting`, `push_r9`, and `LOAD_TAIL_CALL_CNT_PTR`). [F19, F30]
- In `add_2mod(byte, r1, r2)` and `add_2reg(byte, dst_reg, src_reg)`, the first register is encoded in ModR/M `r/m` (bits 0..2, `REX.B`) and the second in ModR/M `reg` (bits 3..5, `REX.R`), while `add_1reg(byte, dst_reg)` encodes `dst_reg` in bits 0..2; in `add_3mod(byte, r1, r2, index)`, `r1` sets `REX.B` (SIB base), `r2` sets `REX.R` (ModR/M `reg`), and `index` sets `REX.X` (SIB index), matching `emit_insn_suffix_SIB(ptr_reg, val_reg, index_reg)`. Broken by: calling `add_1reg(0x04, dst_reg)` for a SIB ModR/M byte, or passing `(dst_reg, src_reg)` to `add_2mod`/`add_2reg` for `IMUL`/`MOVZX`/`MOVSX`/`CMOVcc`. [F17, F18]
- `bpf_arch_poke_desc_update()` and `bpf_tail_call_direct_fixup()` must invoke `__bpf_arch_text_poke()` directly rather than `bpf_arch_text_poke()`. In `__arch_prepare_bpf_trampoline()`, `im` must only be dereferenced when `flags & BPF_TRAMP_F_CALL_ORIG` is set (as `bpf_struct_ops` passes `im = NULL` with `BPF_TRAMP_F_INDIRECT`), and `BPF_TRAMP_F_INDIRECT` is only compatible with `BPF_TRAMP_F_RET_FENTRY_RET`. [F14, F121]

## Error Handling

- `bpf_arch_text_copy()` returns `dst` on success and `ERR_PTR(-EINVAL)` (never `NULL`) when `text_poke_copy()` returns `NULL`, so callers such as `arch_prepare_bpf_trampoline()` must check `IS_ERR()` rather than `NULL`. [F21]

## External Contracts

- `emit_prologue()` must emit `cfi_bpf_subprog_hash` (arity 5) for subprograms and `cfi_bpf_hash` (arity 1) for main programs, while `__arch_prepare_bpf_trampoline()` must emit `emit_cfi()` with `cfi_get_func_hash(func_addr)` and `cfi_get_func_arity(func_addr)` (with `emit_fineibt()` calling `__bhi_args[arity]` at `ip + 11`) when `BPF_TRAMP_F_INDIRECT` is set, and must emit `x86_call_depth_emit_accounting(&prog, NULL, image)` when `BPF_TRAMP_F_INDIRECT` is not set. [F87, F97]
- `bpf_jit_supports_exceptions()` must return `IS_ENABLED(CONFIG_UNWINDER_ORC)` to match `#if defined(CONFIG_UNWINDER_ORC)` in `arch_bpf_stack_walk()`. When `in_arena` is true, `bpf_jit_supports_insn()` must return `false` for 32/64-bit `BPF_STX | BPF_ATOMIC` with `BPF_AND/OR/XOR | BPF_FETCH` because `BPF_PROBE_ATOMIC` lowers via `emit_atomic_rmw_index()`, which rejects them. In `do_jit()`, `BPF_ST | BPF_NOSPEC` must emit `EMIT_LFENCE()`. [F114, F115, F123]

## Known Pitfalls

- When `do_jit()` populates `bpf_prog->aux->extable[excnt++]`, it must compute `delta = _insn - (u8 *)&ex->insn` while `ex` still points into the read-only `image` buffer, and then remap `ex` to `rw_image` via byte-addressed arithmetic `(void *)rw_image + ((void *)ex - (void *)image)` before writing `*ex`. Similarly, when `bpf_int_jit_compile()` resumes on `extra_pass` using `jit_data`, `rw_image` must be computed via byte-addressed `(void *)rw_header + ((void *)image - (void *)header)` rather than typed pointer arithmetic or `rw_header->image`. [F82, F85]
- When emitting instructions in `do_jit()` that require fixed x86 registers (`%rcx`/`BPF_REG_4` for non-BMI2 variable shifts, or `%rax`/`BPF_REG_0` and `%rdx`/`BPF_REG_3` for `BPF_DIV`/`BPF_MOD`), conflicting `src_reg` or `dst_reg` operands must be staged through `AUX_REG` (`%r11`) and only non-destination fixed registers may be pushed/popped. In the non-BMI2 shift path, when `src_reg != BPF_REG_4` and `dst_reg == BPF_REG_4`, `dst_reg` is reassigned to `AUX_REG`, so the post-shift restore check must test `insn->dst_reg == BPF_REG_4` rather than `dst_reg == BPF_REG_4`. [F34, F66]
- In `do_jit()`, multi-instruction sequences that save `BPF_REG_0` (`%rax`) to `BPF_REG_AX` (`%r10`) before clobbering `%rax` (such as `BPF_AND/OR/XOR | BPF_FETCH` `cmpxchg` loops) must remap `src_reg` and `dst_reg` to `BPF_REG_AX` whenever either equals `BPF_REG_0`, and must restore `BPF_REG_0` from `BPF_REG_AX` before writing the fetched result to `BPF_REG_0`. [F33]
- `emit_insn_suffix()` always emits a 1-byte or 4-byte displacement (never `mod=00`) because `BPF_REG_7` (`R13`) and `BPF_REG_FP` (`RBP`) require an offset in ModR/M, and `X86_REG_R12` (`reg2hex` = 4) must only be addressed via `emit_insn_suffix_SIB()`. When emitting x86 memory operands for struct fields or stack offsets, 1-byte displacements (`ModR/M` `0x40`) are only valid if `is_imm8()` holds; larger offsets such as `offsetof(struct bpf_array, ptrs)` require `EMIT*_off32()`. [F46, F50]
- When `nr_regs > 6` and `BPF_TRAMP_F_CALL_ORIG` is set in `__arch_prepare_bpf_trampoline()`, `stack_size` must be padded so `stack_size + 24` is 16-byte aligned (`stack_size % 16 == 8`). In `save_args()`, `first_off` must be initialized to 0, stack arguments must be copied from `rbp + 0x18 + nr_stack_slots * 8`, and `clean_stack_garbage()` must zero `[rbp - (first_off - 4)]` when `nr_stack_slots == 1` and the final argument's size is `<= 4` bytes. [F25, F106]
- In `emit_mov_imm64()`, `imm32_lo` must be cast to `u32` when constructing `imm64`, and `is_uimm32(imm64)` (passing `sign_propagate = false` to `emit_mov_imm32()`) must be checked before `is_simm32(imm64)` so 64-bit immediates with `imm32_hi == 0` and bit 31 of `imm32_lo` set are zero-extended rather than sign-extended. [F72]
- `struct jit_context::cleanup_addr` and `addrs[]` elements in `do_jit()` must be signed `int` so `s64 jmp_offset = ctx->cleanup_addr - addrs[i]` and `addrs[i + insn->off] - addrs[i]` perform signed subtraction before widening. In `emit_priv_frame_ptr()` and `insn_is_mov_percpu_addr(insn)` in `do_jit()`, emitting `add <reg>, gs:[&this_cpu_off]` must be guarded by `#ifdef CONFIG_SMP`. [F74, F116]
