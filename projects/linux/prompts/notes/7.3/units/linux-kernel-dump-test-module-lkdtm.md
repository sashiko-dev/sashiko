# LINUX KERNEL DUMP TEST MODULE (LKDTM)

The Linux Kernel Dump Test Module (LKDTM) is a fault-injection and kernel hardening test module that intentionally triggers crashes, memory corruptions, permission violations, and undefined behavior. Tests can be invoked directly via debugfs (`DIRECT`) or deferred via kprobes attached to predefined kernel symbols (`crashpoints`) after a configurable hit count, evaluating crash dump reliability and kernel self-protection mechanisms across stack, heap, usercopy, refcount, CFI/PAC/SCS, UBSAN, and page table permissions.

## Architecture & Data Flow

- In `lkdtm_register_cpoint()`, `lkdtm_crashpoint`, `lkdtm_crashtype`, and `lkdtm_kprobe` must be assigned after unregistering any prior `lkdtm_kprobe` and before calling `register_kprobe()`, and all three globals must be cleared to `NULL` in lockstep if `register_kprobe()` returns an error. [F24]
- In `drivers/misc/lkdtm/perms.c`, `do_overwritten()` must be defined immediately after `do_nothing()` and both must be marked `noinline`, because `lkdtm_WRITE_KERN()` computes the byte size of `do_nothing()` by subtracting the dereferenced text address of `do_nothing` from `do_overwritten`. [F58]
- `lkdtm_rodata_do_nothing()` in `drivers/misc/lkdtm/rodata.c` must be marked `noinstr` so that `rodata_objcopy.o` renames only `.noinstr.text` to `.rodata` without compiler instrumentation or moving compiler-generated `.text` constructors into non-executable `.rodata`. [F80]
- In `check_stackleak_irqoff()`, `untracked_high` must be aligned down to `sizeof(unsigned long)` with `ALIGN_DOWN()` before calling `stackleak_find_top_of_poison()`, and the `poison_low` loop must decrement by `sizeof(unsigned long)` bytes before dereferencing `*(unsigned long *)poison_low`. [F63]
- In `set_return_addr_unchecked()` and `set_return_addr()` (`drivers/misc/lkdtm/cfi.c`), `__builtin_frame_address(0)` must be cast to `(unsigned long **)` before adding `FRAME_RA_OFFSET` so the offset scales by word size, and `*ret_addr` must be masked with `no_pac_addr()` before comparing with `expected`. [F64]
- In `__lkdtm_REPORT_STACK_CANARY()`, the stack word scan loop must start at index `i = 1` above `stack` (`for (i = 1; i < 16; i++)`) because offset `0` is the "not found" sentinel for `current_offset` and `init_offset`. Since `canary` advances to the end of the 16-word window during the loop, it must be recomputed as `(unsigned long *)stack + current_offset` after verifying `current_offset != 0` before dereferencing `*canary`. [F42, F50]
- In `__lkdtm_REPORT_STACK_CANARY()`, `stack_canary`, `stack_canary_pid`, and `stack_canary_offset` must be recorded together when `stack_canary_pid == 0`, and `stack_canary_pid` must be reset to `0` once a differing canary is verified for a second PID. Similarly, in `lkdtm_REPORT_STACK()`, `stack_pid` and `stack_addr` must be updated together whenever `task_pid_nr(current)` differs from `stack_pid`. [F26, F27]
- `lkdtm_do_action()` must remain `noinline` and return a non-void `int` value after invoking `crashtype->func()` so the compiler cannot tail-call optimize `crashtype->func()` and omit `lkdtm_do_action` from crash stack traces. [F46]
- `lkdtm_debugfs_read()` must format crash type names into the `PAGE_SIZE` page using `scnprintf(buf + n, PAGE_SIZE - n, ...)` rather than `snprintf()`, so `n` never reaches `PAGE_SIZE`, `PAGE_SIZE - n` cannot underflow, and `buf[n] = '\0'` stays in bounds. [F35]
- In `lkdtm_module_init()`, the loop creating debugfs files for `crashpoints[]` must use a separate cursor variable (`cur`) rather than overwriting the local `crashpoint` pointer resolved from `cpoint_name`, which is checked afterward to register the initial crashpoint. [F52]
- Architecture/platform feature guards: in `drivers/misc/lkdtm/bugs.c`, x86 hardware tests and headers (`<asm/desc.h>`, `lkdtm_DOUBLE_FAULT()`, `lkdtm_UNSET_SMEP()`) must guard `CONFIG_X86_32`/`CONFIG_X86_64` checks with `!IS_ENABLED(CONFIG_UML)`; in `lkdtm_PPC_SLB_MULTIHIT()`, `!radix_enabled()` must be checked before calling `inject_vmalloc_slb_multihit()`, `inject_kmalloc_slb_multihit()`, or `insert_dup_slb_entry_0()`; on ARM64, `lkdtm_CORRUPT_PAC()` must check `system_supports_address_auth()` before calling `change_pac_parameters()`. [F71, F72, F81]

## Synchronization

- In `lkdtm_kprobe_handler()`, `crash_count_lock` must be acquired with `spin_lock_irqsave()` across the decrement, zero check, and reset of `crash_count` to `cpoint_count`, and released with `spin_unlock_irqrestore()` before calling `lkdtm_do_action()`. [F12]
- `check_stackleak_irqoff()` must be called with local interrupts disabled (`local_irq_save()`) and remain marked `noinstr`, deferring any `instrumentation_begin()` and `pr_info()`/`pr_err()` calls until after the stack poison scan completes or fails. Every path reaching the `out:` label must call `instrumentation_begin()` exactly once before jumping to `out:`, because `out:` unconditionally calls `instrumentation_end()` before returning to `lkdtm_KSTACK_ERASE()`. [F7, F78]
- In `lkdtm_SMP_CALL_LOCKUP()`, `cpus_read_lock()` must be acquired before `get_cpu()` and released after `put_cpu()`, and both must be held across `cpumask_any_but(cpu_online_mask, cpu)` and `smp_call_function_single()`. [F13]
- In `panic_stop_irqoff_fn()` invoked via `stop_machine()` from `lkdtm_PANIC_STOP_IRQOFF()`, `panic()` must only be called when `atomic_inc_return(v) == num_online_cpus()` so that all online CPUs have entered the IRQ-disabled callback first. [F14]
- In `drivers/misc/lkdtm/powerpc.c`, `insert_slb_entry()` and `insert_dup_slb_entry_0()` must keep preemption disabled via `preempt_disable()`/`preempt_enable()` across `slbmfee`, `slbmfev`, and `slbmte` inline assembly instructions. [F79]

## Object Lifetimes

- In `lkdtm_debugfs_entry()` and `direct_entry()`, the temporary page allocated with `__get_free_page(GFP_KERNEL)` must be freed via `free_page()` on `copy_from_user()` failure and immediately after `find_crashtype(buf)` returns, before invoking `lkdtm_register_cpoint()` or `lkdtm_do_action()`. [F5]
- In `lkdtm_module_init()`, `lkdtm_kernel_info` and category initializers (`lkdtm_bugs_init()`, `lkdtm_perms_init()`, `lkdtm_usercopy_init()`, `lkdtm_heap_init()`) must run before `debugfs_create_file()` or `lkdtm_register_cpoint()`, and `lkdtm_module_exit()` must call `debugfs_remove_recursive(lkdtm_debugfs_root)` before calling `lkdtm_heap_exit()` and `lkdtm_usercopy_exit()`. [F76]

## API Contracts

- `do_usercopy_page_span()` borrows the `PAGE_SIZE`-aligned kernel buffer `kaddr` from its caller and manages only its own user mapping via `vm_mmap()`/`vm_munmap()`, while callers (`lkdtm_USERCOPY_VMALLOC()` and `lkdtm_USERCOPY_FOLIO()`) retain ownership and must release backing memory via `vfree()` or `folio_put()`. Callers must pass a `kaddr` pointing to the start of a `PAGE_SIZE` page at the end of the target object (e.g., `addr + PAGE_SIZE` for the order-1 folio in `lkdtm_USERCOPY_FOLIO()`), because `do_usercopy_page_span()` memsets `PAGE_SIZE` bytes and advances `kaddr` by `PAGE_SIZE / 2`. [F4, F66]
- In `drivers/misc/lkdtm/perms.c`, code that copies or executes function bodies (`execute_location()`, `execute_user_location()`, `lkdtm_WRITE_KERN()`, `lkdtm_EXEC_RODATA()`, `lkdtm_perms_init()`) must obtain text addresses with `dereference_function_descriptor()` and construct call targets with `setup_function_descriptor()`. In `execute_location()` and `lkdtm_WRITE_KERN()`, `flush_icache_range()` must be called over the destination range after `memcpy()` writes machine instructions and before calling the target function. [F59, F75]
- `do_usercopy_slab_whitelist()` must verify `whitelist_cache` is non-NULL before allocating from it, and its whitelisted offset (`cache_size / 4`) and size (`cache_size / 16`) must match the `useroffset` and `usersize` arguments passed to `kmem_cache_create_usercopy()` in `lkdtm_usercopy_init()`. [F19]
- In `drivers/misc/lkdtm/heap.c`, `lkdtm_heap_init()` must create `double_free_cache`, `a_cache`, and `b_cache` with `SLAB_NO_MERGE` so the slab allocator keeps them distinct for `lkdtm_SLAB_FREE_DOUBLE()` and `lkdtm_SLAB_FREE_CROSS()`. [F92]
- In `lkdtm_UNSET_SMEP()`, `native_read_cr4()` must be checked for `X86_CR4_SMEP` before clearing the bit, and any path where `X86_CR4_SMEP` remains cleared after `native_write_cr4()` or `direct_write_cr4()` must restore `X86_CR4_SMEP` via `native_write_cr4()` before returning. [F28]
- In `check_negative()`, `refcount_read(ref) == start` must be checked before the `switch (refcount_read(ref))` statement because `refcount_t` leaves the counter unchanged at its pre-operation value `start` (which may be non-zero, such as 3 in `lkdtm_REFCOUNT_SUB_AND_TEST_NEGATIVE`) when an over-subtraction does not saturate. [F51]
- In `drivers/misc/lkdtm/core.c` and `drivers/misc/lkdtm/lkdtm.h`, `lkdtm_check_bool_cmdline()` and its call from `pr_expected_config_param()` must remain guarded by `#ifndef MODULE` because `parse_args()` is not exported to loadable modules. `lkdtm_check_bool_cmdline()` must initialize `check_cmdline_args.value` to `-ESRCH` so `lkdtm_parse_one()` stops at the first valid boolean match and returns `0`, `1`, or a negative errno. [F17, F86]
- `lkdtm_bugs_init(int *recur_param)` acts as an in-out initializer: when `*recur_param` is negative (the default `-1` in `core.c`), it writes `bugs.c`'s default `recur_count` back into `*recur_param`, and otherwise copies `*recur_param` into `bugs.c`'s `recur_count`. [F22]
- Every non-NULL kernel symbol name in `crashpoints[]` in `drivers/misc/lkdtm/core.c` must refer to an existing, non-inlined kernel function so `register_kprobe()` in `lkdtm_register_cpoint()` can attach to it. When creating debugfs trigger files in `lkdtm_module_init()`, `debugfs_create_file()` must pass the `struct crashpoint` pointer as the private data argument because `lkdtm_debugfs_entry()` retrieves it from `file_inode(f)->i_private`. [F87, F88]

## Error Handling

- When a test function performs multiple non-crashing setup allocations (such as `not_checked` and `checked` in `lkdtm_ARRAY_BOUNDS()`, `one` and `two` in `do_usercopy_slab_size()`, or `base`/`p` and `val` in `lkdtm_READ_AFTER_FREE()` and `lkdtm_READ_BUDDY_AFTER_FREE()`), it must check each allocation for `NULL` and free any already-succeeded allocations before returning. [F3]
- Callers of `vm_mmap()` in `drivers/misc/lkdtm/usercopy.c` and `drivers/misc/lkdtm/perms.c` must store the return value in an `unsigned long` and treat values `>= TASK_SIZE` as allocation failure before using the address or calling `vm_munmap()`. [F15]
- In `lkdtm_debugfs_entry()` and `direct_entry()`, the user buffer length `count` must be rejected when `count >= PAGE_SIZE` before copying into the `PAGE_SIZE` page from `__get_free_page()`, because `buf[count] = '\0'` writes one byte at index `count`. [F34]
- In `execute_user_location()`, the return value of `access_process_vm()` is the number of bytes copied and must be checked for `< EXEC_SIZE` before jumping to `dst`. [F20]
- In `lkdtm_SMP_CALL_LOCKUP()`, the CPU index returned by `cpumask_any_but(cpu_online_mask, cpu)` must be checked against `>= nr_cpu_ids` before calling `smp_call_function_single()`. [F21]
- In UBSAN bounds tests such as `lkdtm_ARRAY_BOUNDS()` and `lkdtm_FAM_BOUNDS()` (`drivers/misc/lkdtm/bugs.c`), surviving an out-of-bounds access when `CONFIG_UBSAN_BOUNDS` is enabled must report `pr_expected_config(CONFIG_UBSAN_TRAP)`, and `lkdtm_FAM_BOUNDS()` must gate `__counted_by` expectations on `IS_ENABLED(CONFIG_CC_HAS_COUNTED_BY)`. [F94]

## External Contracts

- `lkdtm_REPORT_STACK()` must log `"Starting stack offset tracking for pid %d\n"` when `pid != stack_pid` and `"Stack offset: %d\n"` with the integer offset as the final whitespace-delimited field on each call. [F44]

## Known Pitfalls

- In `drivers/misc/lkdtm/perms.c`, `drivers/misc/lkdtm/bugs.c`, and `drivers/misc/lkdtm/cfi.c`, pointers used to perform intentional bad writes or frame return-address overwrites (`lkdtm_WRITE_RO()`, `lkdtm_WRITE_RO_AFTER_INIT()`, `lkdtm_ACCESS_NULL()`, `lkdtm_EXCEPTION()`, `set_return_addr()`, and `set_return_addr_unchecked()`) must be `volatile`-qualified so the compiler does not optimize away the access. [F62]
- `execute_location()` (`drivers/misc/lkdtm/perms.c`) must copy machine instructions from the runtime-initialized pointer `do_nothing_ptr` (set to `dereference_function_descriptor(do_nothing)` in `lkdtm_perms_init()`) rather than directly from `do_nothing`. Furthermore, `execute_location()` must be marked with both `__nocfi` and `ANNOTATE_NOCFI_SYM(execute_location)`, and `rodata.o` in `drivers/misc/lkdtm/Makefile` must strip `$(CC_FLAGS_CFI)` via `CFLAGS_REMOVE_rodata.o`. [F23, F61]
- In `lkdtm_READ_AFTER_FREE()` and `lkdtm_KFENCE_READ_AFTER_FREE()` (`drivers/misc/lkdtm/heap.c`), the index `offset` into `int *base` must be `sizeof(*base)` rather than `0` or `(len / sizeof(*base)) / 2` so that SLUB's freelist pointer does not overwrite the test value after `kfree()`. [F57]
- In `lkdtm_KFENCE_READ_AFTER_FREE()`, `jiffies` deadlines `resched_after` and `timeout` must be compared using `time_after()` and `time_before()` rather than `<` or `>`, and the `do ... while (time_before(jiffies, timeout))` allocation loop must call `cond_resched()` on every failed attempt once `time_after(jiffies, resched_after)` holds so the KFENCE allocation-gate timer is not starved on non-preemptible kernels. [F49, F56]
- In `do_usercopy_stack_callee()` (`drivers/misc/lkdtm/usercopy.c`), the local stack address returned to `do_usercopy_stack()` must be passed through the `noinline` helper `trick_compiler()` and must point to `&buf[(128/2)-32]` in the middle of `buf`. [F65]
- In `drivers/misc/lkdtm/cfi.c`, `no_pac_addr()` must cast its pointer argument to `uintptr_t` (not `u64`) before bitwise-ORing with `PAGE_OFFSET` so the integer width matches the pointer width on both 32-bit and 64-bit architectures. [F37]
- In `drivers/misc/lkdtm/bugs.c`, `REC_STACK_SIZE` must only use `CONFIG_FRAME_WARN` when `CONFIG_FRAME_WARN > 0` (falling back to `THREAD_SIZE / 8UL` otherwise) so `REC_NUM_DEFAULT` and `sizeof(buf)` in `recursive_loop()` never divide by zero, and every preprocessor branch defining `REC_STACK_SIZE` must evaluate to `unsigned long` (using `_AC(CONFIG_FRAME_WARN, UL) / 2` and `THREAD_SIZE / 8UL`) to match `%lu` in `lkdtm_EXHAUST_STACK()`. [F55, F68]
- `lkdtm_HUNG_TASK()` (and any other `__noreturn` crashtype callback in LKDTM) must terminate its unreachable path after `schedule()` with `BUG()` rather than `BUG_ON(1)` so `schedule()` is not tail-call optimized and compilers on architectures where `BUG_ON()` is an inline function recognize the function never returns. [F45]
- Every `struct crashtype_category` defined in a category source file must be declared in `drivers/misc/lkdtm/lkdtm.h` and listed in `crashtype_categories[]` in `drivers/misc/lkdtm/core.c` under the same Kconfig condition as its `Makefile` build rule. When a test function is compiled unconditionally with an `XFAIL` fallback (such as `lkdtm_DOUBLE_FAULT`, `lkdtm_UNSET_SMEP`, `lkdtm_CORRUPT_PAC`, or `lkdtm_KSTACK_ERASE`), its `CRASHTYPE()` entry in `crashtypes[]` must also be unconditional. [F32, F33]
