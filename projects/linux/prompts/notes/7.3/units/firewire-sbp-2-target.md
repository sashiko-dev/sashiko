# FIREWIRE SBP-2 TARGET

This component implements a Linux SCSI Target (TCM/LIO) fabric module for the Serial Bus Protocol 2 (SBP-2) over IEEE 1394 (FireWire). It exposes target ports, portal groups, and LUNs via a Config ROM unit directory and FireWire CSR address handlers for the Management Agent and per-login Command Block Target Agents, fetching initiator ORBs, CDBs, and page tables, submitting SCSI commands to target core, transferring data buffers, and writing status blocks back to the initiator's status FIFO.

## Architecture & Data Flow
- Because `tgt_agent_fetch_work` pre-populates `req->status.status` with `STATUS_BLOCK_ORB_OFFSET_HIGH` and `STATUS_BLOCK_SRC`, every subsequent status update on `sbp_target_request` before `sbp_send_status` must OR (`|=`) into `req->status.status` and include `STATUS_BLOCK_LEN`. Broken by: assigning `=` instead of `|=` or omitting `STATUS_BLOCK_LEN`. [F42]
- When `CMDBLK_ORB_PG_TBL_PRESENT` is set, `CMDBLK_ORB_DATA_SIZE(be32_to_cpu(req->orb.misc))` is the `struct sbp_page_table_entry` count rather than a byte size: `sbp_fetch_page_table` must multiply it by `sizeof(struct sbp_page_table_entry)` while `sbp_calc_data_length_direction` and `sbp_rw_data` use it as the entry count. [F70]
- Shift exponents extracted from initiator ORB `misc` fields by `LOGIN_ORB_RECONNECT` in `sbp_management_request_login` and `CMDBLK_ORB_MAX_PAYLOAD` in `sbp_rw_data` must be masked to 4 bits (`& 0x0f`) before computing `1 << exp` or `4 << exp`. [F64]
- `session_check_for_reset` drops `sess->card` and sets `sess->card = NULL` when `sess->card->local_node` is NULL, so `sbp_session_release`, `sbp_management_request_reconnect`, and `session_check_for_reset` must check `sess->card != NULL` before calling `fw_card_put(sess->card)` or reading `sess->card->generation`. [F30]
- In `sbp_session`, `sess->node_id == -1` marks a session awaiting reconnect after a bus reset: `session_check_for_reset` must set `sess->node_id = -1` and `sess->reconnect_expires` together, and `sbp_management_request_reconnect` must restore `sess->node_id`, `sess->generation`, `sess->card`, and `sess->speed` under `sess->lock`. [F43]
- When `sbp_mgt_get_req` allocates a `struct sbp_target_request` from `se_sess->sess_cmd_map`, it zeroes the structure with `memset` and restores `req->se_cmd.map_tag` and `req->se_cmd.map_cpu`, and `sbp_free_request` must `kfree` per-request buffers (`pg_tbl`, `cmd_buf`) before `target_free_tag`. [F44]
- Mutations to `sbp_tport` fields or LUN links encoded into the Config ROM (`enable`, `mgt_orb_timeout`, `max_reconnect_timeout`, and `tpg_lun_hlist` via `sbp_post_link_lun`/`sbp_pre_unlink_lun`) must call `sbp_update_unit_directory(tport)` (or reject changes while `tport->enable` is set, as `sbp_tpg_directory_id_store` does). [F40]
- `sbp_enable_tpg` refuses to enable a TPG when `sbp_count_se_tpg_luns(&tpg->se_tpg) == 0`, and `sbp_pre_unlink_lun` clears `tport->enable = 0` when the last LUN is unlinked before calling `sbp_update_unit_directory(tport)`. [F99]
- `sbp_tpg_directory_id_store` and `sbp_tpg_attrib_max_reconnect_timeout_store` must bound `directory_id` to `-1` or `0..0xffffff` and `max_reconnect_timeout` to `1..32767` so `sbp_update_unit_directory` does not corrupt `CSR_DIRECTORY_ID` and `sbp_management_request_login` keeps `reconnect_hold >= 0`. [F54]

## Synchronization
- `sbp_management_agent.lock`, `sbp_target_agent.lock`, and `sbp_session.lock` are acquired in softirq FireWire address callbacks (`sbp_mgt_agent_rw` and `tgt_agent_rw`) and must always be taken with `spin_lock_bh`/`spin_unlock_bh` in process and workqueue contexts. [F84]
- All traversals and emptiness checks of `tpg->se_tpg.tpg_sess_list` must hold `tpg->se_tpg.session_lock` via `spin_lock_bh`, and all traversals or mutations of `sess->login_list` must hold `sess->lock` via `spin_lock_bh`, nesting `sess->lock` inside `tpg->se_tpg.session_lock` when both are acquired. Broken by: calling `target_remove_session` under `sess->lock`. [F19]
- In `session_check_for_reset`, inspecting `sess->card->local_node` requires holding `spin_lock_irq(&sess->card->lock)` nested inside `spin_lock_bh(&sess->lock)`, and if `card_valid` is false, `sess->card` must be released via `fw_card_put` and set to NULL before unlocking `sess->lock`. [F25]
- In `sbp_run_request_transaction` and `sbp_rw_data`, callers must pin `sess->card` with `fw_card_get` and snapshot `sess->node_id` and `sess->generation` under `spin_lock_bh(&sess->lock)`, unlock `sess->lock` before calling blocking `sbp_run_transaction`, and call `fw_card_put(card)` afterward. [F22]
- In `tgt_agent_fetch_work`, after the blocking ORB fetch via `sbp_run_transaction` returns without holding `agent->lock`, `tgt_agent_check_active(agent)` must be rechecked before queueing `req->work`; if no longer active (or `doorbell` was set), `req` must be freed with `sbp_free_request(req)` instead of being submitted. [F23]
- `sbp_login_release` and `sbp_target_agent_unregister` must never be called while holding `sess->lock` (or any spinlock), because `sbp_target_agent_unregister` calls `cancel_work_sync(&agent->work)` and `sbp_session_release` calls `cancel_delayed_work_sync` and `target_remove_session`. [F89]
- When `sbp_session_release` is called outside `session_maintenance_work` (`cancel_work == true`), it must call `cancel_delayed_work_sync(&sess->maint_work)` before `target_remove_session`, `fw_card_put`, and `kfree(sess)`, whereas `session_reconnect_expired` inside `maint_work` must pass `cancel_work = false`. [F17]
- Traversals of `se_tpg->tpg_lun_hlist` via `hlist_for_each_entry_rcu` in `sbp_get_lun_from_tpg`, `sbp_count_se_tpg_luns`, and `sbp_update_unit_directory` (including dereferencing `lun->lun_se_dev`) must be enclosed in an `rcu_read_lock()` / `rcu_read_unlock()` critical section. [F24]

## Object Lifetimes
- Because `sbp_handle_command` submits `req->se_cmd` with `TARGET_SCF_ACK_KREF`, `sbp_send_status` must unconditionally drop the extra reference via `target_put_sess_cmd(&req->se_cmd)` even when the status block transaction fails, so `sbp_release_cmd` -> `sbp_free_request` can free `req->pg_tbl`, `req->cmd_buf`, and the session tag. [F8]
- In `sbp_login_release`, `sbp_target_agent_unregister(login->tgt_agt)` must complete before unlinking `login->link` from `sess->login_list` under `sess->lock`, which in turn must precede `sbp_session_release` and `kfree(login)` because `sbp_session_release` returns without freeing `sess` if `sess->login_list` is non-empty. [F1, F16]
- In `session_reconnect_expired`, each login moved from `sess->login_list` to the local `login_list` under `sess->lock` must have `login->sess` set to NULL before `sbp_login_release` is called outside the lock, so `sbp_login_release` does not re-delete `login->link` or call `sbp_session_release` per login. [F57]
- In `sbp_target_agent_unregister` and `sbp_management_agent_unregister`, `fw_core_remove_address_handler(&agent->handler)` must be called before `cancel_work_sync(&agent->work)` and `kfree(agent)` so softirq CSR callbacks (`tgt_agent_rw` or `sbp_mgt_agent_rw`) cannot re-queue `agent->work` during teardown. [F74]
- Before `fw_core_add_address_handler` publishes a CSR handler, `sbp_target_agent_register` / `sbp_management_request_login` must initialize `login->sess` and all `struct sbp_target_agent` fields (`lock`, `handler`, `login`, `state`, `work`, `orb_pointer`, `doorbell`), and `sbp_make_tpg` / `sbp_management_agent_register` must initialize `tport->enable` and all `struct sbp_management_agent` fields (`lock`, `tport`, `handler`, `state`, `work`, `orb_offset`, `request`). [F13, F14]

## API Contracts
- `sbp_get_lun_from_tpg` always returns its unsigned `login_lun` argument regardless of whether a matching `se_lun` exists in `tpg->se_tpg.tpg_lun_hlist`, reporting success (`0`) or failure (`-ENODEV`) exclusively through its `*err` out-parameter. Broken by: testing the returned `u32` instead of `*err`. [F27]
- `sbp_parse_wwn` returns the positive parsed character length (`cp - name`) on success and `-1` on failure, so callers such as `sbp_init_nodeacl` and `sbp_make_tport` must check `< 0` rather than non-zero. [F28]
- `sbp_run_transaction` must return immediately without retrying when `fw_run_transaction` returns `RCODE_COMPLETE`, `RCODE_TYPE_ERROR`, `RCODE_ADDRESS_ERROR`, or `RCODE_GENERATION`, and may only be called from sleepable context because retry backoff uses `usleep_range`. [F79]
- In `sbp_rw_data`, scatterlist mapping over `req->se_cmd.t_data_sg` must use non-atomic `sg_miter_start` (`SG_MITER_FROM_SG` or `SG_MITER_TO_SG` without `SG_MITER_ATOMIC`), set `iter.consumed = tfr_length` after each successful transaction before the next `sg_miter_next(&iter)`, and unconditionally call `sg_miter_stop(&iter)` after the loop because `sbp_run_transaction` sleeps while `iter.addr` is mapped. [F60, F91]
- CSR register access handlers (`tgt_agent_rw_agent_state`, `tgt_agent_rw_orb_pointer`, and `sbp_mgt_agent_rw`) dereference `void *data` directly as `__be32 *` or `struct sbp2_pointer *`, requiring `tgt_agent_rw` and `sbp_mgt_agent_rw` to verify the exact register offset, byte length (`4` or `8`), and `tcode` before accessing `data`. [F50]
- `sbp_session_create` passes `sizeof(struct sbp_target_request)` and `sess` to `target_setup_session`, establishing the invariant that `se_sess->sess_cmd_map` is an array of `struct sbp_target_request` and `se_sess->fabric_sess_ptr` points to the owning `struct sbp_session`. [F95]
- In `sbp_write_pending`, once `sbp_rw_data(req)` finishes transferring the Data-Out payload from the initiator into `se_cmd->t_data_sg`, it must call `target_execute_cmd(se_cmd)` and return `0`. [F98]

## Error Handling
- `sbp_run_transaction`, `sbp_run_request_transaction`, and `read_peer_guid` return FireWire `RCODE_*` constants where success is `RCODE_COMPLETE` (`0`) and errors are positive values, whereas `sbp_fetch_command`, `sbp_fetch_page_table`, `sbp_rw_data`, and `sbp_send_status` translate non-`RCODE_COMPLETE` results into `-EIO`. Broken by: checking `ret < 0` instead of `ret != RCODE_COMPLETE` on `sbp_run_*_transaction`. [F26]

## External Contracts
- FireWire address handler callbacks `tgt_agent_rw` and `sbp_mgt_agent_rw` must terminate every execution path by calling `fw_send_response(card, request, rcode)`, including error paths for disabled `tport`, generation or `node_id` mismatch, invalid register offset/length/tcode, or busy agent state. [F80]
- `STATUS_BLOCK_LEN` encodes status block length as `(quadlets - 1)` whereas `sbp_run_transaction` takes bytes, so `sbp_send_status` must scale the 3-bit length field by `(((val >> 24) & 0x07) + 1) * 4` and `sbp_mgt_agent_process` must pair `STATUS_BLOCK_LEN(DIV_ROUND_UP(status_data_len, 4) + 1)` with `8 + status_data_len` bytes. [F72]
- `sbp_parse_wwn` requires a 16-character hexadecimal string without a `0x` prefix or separators (terminated by `\0` or `\n\0` within `SBP_NAMELEN - 1` bytes), matching the `%016llx` format produced by `sbp_format_wwn` and `sbp_session_create` when looking up initiator NodeACLs. [F55]

## Known Pitfalls
- `sbp2_pointer_to_addr` masks off the upper 16 bits of `ptr->high` (`& 0x0000ffff`) and the low 2 bits of `ptr->low` (`& 0xfffffffc`) to form a 48-bit quadlet-aligned FireWire offset, so callers like `tgt_agent_fetch_work` must check upper control bits such as the null-ORB flag (`0x80000000` in `next_orb.high`) before calling `sbp2_pointer_to_addr`. [F47]
- In `sbp_update_unit_directory`, `data` is a `u32 *` allocated as `num_entries + 4` quadlets: `num_entries` (upper 16 bits of `data[0]`) counts only immediate/offset entries (excluding the header and 3-quadlet unit unique ID leaf), `memcpy` of `sbp_unit_directory_template` must advance `idx` by `ARRAY_SIZE(...)` rather than `sizeof(...)`, the unit unique ID offset entry (`0x8d000000 | (num_luns + 1)`) requires the leaf to immediately follow the `num_luns` LUN entries, and `unit_directory.length` is the quadlet count `idx`. [F39, F46, F68]
- In `sbp_fetch_command`, `req->orb.command_block` is 12 bytes, so `memcpy` must clamp to `min_t(int, cmd_len, sizeof(req->orb.command_block))` and fetch any remaining CDB bytes from `req->orb_pointer + sizeof(req->orb)` into byte-addressed `req->cmd_buf + sizeof(req->orb.command_block)`. [F71]
- In `sbp_parse_wwn`, the loop bound `cp < &name[SBP_NAMELEN - 1]` reserves 1 byte for the `cp[1] == '\0'` lookahead on newline characters (requiring caller buffers to be at least `SBP_NAMELEN` bytes), and `isdigit(c)` must be checked before `isxdigit(c)` because `isxdigit(c)` is also true for `'0'..'9'` while its branch computes `tolower(c) - 'a' + 10`. [F56, F73]
- In `sbp_session_find_by_guid`, `sbp_login_find_by_lun`, and `sbp_login_find_by_id`, `list_for_each_entry` traversals run to completion under spinlocks without breaking, so matched entries must be saved in a separate NULL-initialized `found` variable rather than returning the loop cursor. [F58]
- When assembling 48-bit FireWire addresses or 64-bit GUIDs from big-endian wire fields in `sbp2_pointer_to_addr`, `read_peer_guid`, and `sbp_rw_data`, the upper word from `be32_to_cpu` or `be16_to_cpu` must be cast to `u64` before shifting left by 32 bits. [F63]
