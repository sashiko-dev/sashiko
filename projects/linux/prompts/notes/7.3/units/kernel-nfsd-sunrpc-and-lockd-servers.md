# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS

`fs/nfsd` implements the kernel NFSv2/v3/v4 server, including SunRPC service lifecycle, filehandle verification, the duplicate reply cache (DRC), XDR codecs, the NFSv4.0/4.1/4.2 state manager, ACL/ID-mapping translation, client reboot recovery, and LOCALIO network-bypass support.

## Architecture & Data Flow
- Embedded base structs must stay at offset 0 for slab/`void *` casts: `nfs4_stid` (`dl_stid`, `st_stid`, `ls_stid`) in `nfs4_delegation`, `nfs4_ol_stateid`, and `nfs4_layout_stateid`; and `nfs4_stateowner` (`oo_owner`, `lo_owner`) in `nfs4_openowner` and `nfs4_lockowner`. Also, `nfs4_cb_fattr` (with `NFSPROC4_CLNT_CB_GETATTR`) must be embedded at `nfs4_delegation.dl_cb_fattr` and `nfsd4_cb_offload` (with `nfsd4_cb_offload_ops`) at `nfsd4_copy.cp_cb_offload` for two-level `container_of` downcasts. [F133, F295, F296]
- `clp->cl_ownerstr_hashtbl` mixes `nfs4_openowner` and `nfs4_lockowner` (check `so->so_is_open_owner` before `openowner()`/`lockowner()`), `fp->fi_stateids` mixes open and lock `nfs4_ol_stateid`s (`st->st_openstp == NULL` for open stateids), and VFS `file_lease`/`file_lock` `fl->c.flc_owner` may only be cast to `nfs4_delegation *` if `fl->fl_lmops == &nfsd_lease_mng_ops` or to `nfs4_lockowner *` if `fl->fl_lmops == &nfsd_posix_mng_ops`. [F221, F224]
- Session backchannel slots (`se_cb_seq_nr[NFSD_BC_SLOT_TABLE_SIZE]`) are 0-indexed up to `ses->se_cb_highest_slot` (clamped to `NFSD_BC_SLOT_TABLE_SIZE - 1`). `grab_slot` and `highest_slotid` must subtract 1 from `ffs`/`fls` bit positions and verify `0 <= idx <= ses->se_cb_highest_slot` before `BIT(idx)`. `cb->cb_held_slot` uses `-1` for "no slot held", and growing `se_cb_highest_slot` in `update_cb_slot_table` under `ses->se_lock` must reset newly exposed `se_cb_seq_nr[i] = 1`. [F50, F57, F85, F126, F262]
- Each bit in `stp->st_access_bmap` holds one ref in `fp->fi_access[O_RDONLY]` and/or `fi_access[O_WRONLY]`, so callers mutating `st_access_bmap` must check `test_access()` before `__nfs4_file_get_access()` or `nfs4_file_put_access()`. `fp->fi_share_deny` caches the union of `bmap_to_share_mode(stp->st_deny_bmap)` across `fp->fi_stateids` and must be updated under `fp->fi_lock` when adding deny bits or recomputed via `recalculate_deny_mode()` / `reset_union_bmap_deny()` when clearing/unhashing. [F237, F238]
- `put_ol_stateid_locked()` reuses `stp->st_locks` for the `reaplist` (`WARN_ON_ONCE(!list_empty(&stp->st_locks))`), so child lock stateids must be unlinked via `unhash_open_stateid()` / `release_open_stateid_locks()` first. Likewise, delegation reaping reuses `dp->dl_recall_lru` after `unhash_delegation_locked()` and must unlink it with `list_del_init(&dp->dl_recall_lru)` before `revoke_delegation()` or `destroy_unhashed_deleg()`. [F276, F277]
- When `nfsd4_deleg_getattr_conflict()` returns a `nfs4_delegation` in `nfsd4_encode_fattr4()`, `args.change_attr` must come from `dp->dl_cb_fattr.ncf_initial_cinfo` (after incrementing `ncf_initial_cinfo` and updating `args.stat.size` from `ncf_cur_fsize` if `ncf_file_modified` is set) rather than `nfsd4_change_attribute()`. `nfs4_open_delegation()` snapshots timestamps into `dp->dl_atime`/`dl_mtime`/`dl_ctime` so `cb_getattr_update_times()` vets `CB_GETATTR` timestamps via `nfsd4_vet_deleg_time()` against `dp->dl_*time`. [F241, F398]

## Synchronization
- Spinlocks in `fs/nfsd/nfs4state.c` nest in order `state_lock` -> `clp->cl_lock` -> `fp->fi_lock`, and `nn->client_lock` -> `clp->cl_lock` -> `nfsd_session_list_lock`; thus `reduce_session_slots` (called under `nfsd_session_list_lock`) must use `spin_trylock(&nn->client_lock)`. In `fs/nfsd/nfs4layouts.c`, `ls->ls_lock` nests inside `fp->fi_lock` and `clp->cl_lock` (and `fp->fi_lock` inside `ls->ls_mutex`), so never take `fp->fi_lock`, `clp->cl_lock`, or `ls->ls_mutex` while holding `ls->ls_lock`. [F146, F209, F308]
- `stp->st_mutex` nests outside `clp->cl_lock` and `fp->fi_lock`: callers locking an existing `nfs4_ol_stateid` must pin `stp->st_stid.sc_count`, drop spinlocks, and call `nfsd4_lock_ol_stateid(stp)` (which locks `st_mutex` with `LOCK_STATEID_MUTEX` and revalidates `sc_status` via `nfsd4_verify_open_stid`). In `init_open_stateid` and `init_lock_stateid`, the candidate `stp->st_mutex` is locked with `OPEN_STATEID_MUTEX` before `retry:`, must stay locked across `goto retry`, and under `cl_lock`/`fi_lock` must verify `!nfs4_openowner_unhashed(oo)` or `!nfs4_ol_stateid_unhashed(open_stp)`. [F211, F212, F287, F313]
- VFS lease-break callbacks `nfsd_break_one_deleg` and `nfsd4_layout_lm_break` run under the atomic VFS `flc_lock` spinlock and must never sleep, allocate with `GFP_KERNEL`, or lock mutexes. If `nfsd4_run_cb(&dp->dl_recall)` fails in `nfsd_break_one_deleg`, drop the ref with `refcount_dec(&dp->dl_stid.sc_count)` rather than `nfs4_put_stid(&dp->dl_stid)` (and `nfs4_free_deleg` must never sleep). Likewise, `nfsd_client_shrinker` callbacks must offload work to `nn->nfsd_shrinker_work` on `laundry_wq` rather than expiring state synchronously. [F148, F204, F309]
- Callers unhashing a delegation for `revoke_delegation` (`nfs4_laundromat`, `nfsd4_revoke_states`) must increment `dp->dl_stid.sc_count` before dropping `state_lock`, and synchronize `clp->cl_revoked` under `clp->cl_lock` with `SC_STATUS_FREEABLE`/`SC_STATUS_FREED`. In `nfsd4_free_stateid`, a `SC_STATUS_REVOKED` delegation must be marked `SC_STATUS_CLOSED` under `s->sc_lock` and `SC_STATUS_FREED` under `cl->cl_lock` before dropping `cl->cl_lock` to call `nfs4_put_stid(s)`. `nfsd4_drop_revoked_stid` must release `cl->cl_lock` on all paths before returning or putting stateids. [F201, F206, F207]
- In `nfsd4_del_conns()`, drop `clp->cl_lock` after unlinking each `nfsd4_conn` before calling `unregister_xpt_user()` and `free_conn()`, as `nfsd4_conn_lost()` acquires `clp->cl_lock`. Only `nfsd4_process_cb_update()` on `clp->cl_callback_wq` may clear `NFSD4_CLIENT_CB_UPDATE` in `clp->cl_flags`; while set, `nfsd4_mark_cb_down()` and `nfsd4_mark_cb_fault()` must not overwrite `clp->cl_cb_state`. `nfsd4_shutdown_callback` must run in process context to flush `cl_callback_wq` and wait in `nfsd41_cb_inflight_wait_complete`. [F61, F153, F332]
- In `nfsd4_lock`, a blocking lock (`flags & FL_SLEEP`) must be queued onto `lock_sop->lo_blocked` and `nn->blocked_locks_lru` with `kref_get(&nbl->nbl_kref)` under `nn->blocked_locks_lock` before `vfs_lock_file`. Because `remove_blocked_locks()` and `nfs4_laundromat()` clear `nbl->nbl_list` while moving `nbl->nbl_lru` to a `reaplist`, `nfsd4_lock()` cleanup must check `!list_empty(&nbl->nbl_list) && !list_empty(&nbl->nbl_lru)` under `nn->blocked_locks_lock` before unlinking and putting `nbl_kref`, and `locks_delete_block`/`free_blocked_lock` must run outside `blocked_locks_lock`. [F217, F278, F316]

## Object Lifetimes
- Callers of `fh_verify()` or `fh_verify_local()` must call `fh_put(fhp)` even on error because `nfsd_set_fh_dentry()` populates `fh_dentry` and `fh_export` before later checks in `__fh_verify()` can fail. `fh_put()` must call `fh_drop_write(fhp)` before `exp_put()` and clear `fh_dentry`, `fh_export`, `fh_want_write`, and pre/post attrs. When `fh_compose(fhp, exp, dentry, ref_fh)` has `ref_fh == fhp`, read `set_version_and_fsid_type()` and `fh_no_wcc` and call `fh_put(ref_fh)` before assigning `fhp->fh_dentry`/`fh_export`. [F337, F338, F340, F490]
- In `nfsd4_proc_compound`, `RQ_USEDEFERRAL` on `rqstp->rq_flags` must be cleared before running ops and restored at `out:`; jumping to `out:` without `fh_put(current_fh)` and `fh_put(save_fh)` is only valid before any op populates them (or on `SEQUENCE` `nfserr_replay_cache`). `nfsd3_proc_fsstat`, `nfsd3_proc_fsinfo`, and `nfsd3_proc_pathconf` have no `.pc_release` and must call `fh_put(&argp->fh)` before returning; in NFSv2, `.pc_release` only releases `resp->fh`, so handlers must `fh_put()` `argp->fh`/`ffh`/`tfh` on paths not copying into `resp->fh`. [F16, F20, F69, F341]
- In `nfsd_open_local_fh`, fast-path lookup of `*pnf` must dereference `*pnf` and call `nfsd_file_get` inside `rcu_read_lock()` after `nfsd_net_try_get(net)` (both `nfsd_net_try_get` and `nfsd_net_put` require RCU and `percpu_ref_tryget_live`). Before installing `localio` into `*pnf` via `cmpxchg`, take a second `nfsd_net_try_get` and `nfsd_file_get` ref (dropping both `localio` refs and the extra `net` ref if `cmpxchg` loses), and always call `put_group_info(rq_cred.cr_group_info)` after `svcauth_map_clnt_to_svc_cred_local`. [F142, F143, F163, F371]
- `nfsd4_process_cb_update` acquires `c->cn_xprt` via `svc_xprt_get` and transfers it to `clp->cl_cb_conn.cb_xprt` in `setup_callback_client`, so it must call `svc_xprt_put(c->cn_xprt)` if `setup_callback_client` fails and clear `cb_xprt` and `cl_cb_client` to `NULL` on teardown. `nfsd4_run_cb` increments `clp->cl_cb_inflight` via `nfsd41_cb_inflight_begin` (decrementing if `nfsd4_queue_cb` returns `false`), and every queued callback work must end through `nfsd41_destroy_cb` or `nfsd4_cb_probe_release` to call `nfsd41_cb_inflight_end`. [F6, F7]
- `nfsd4_sequence_check_conn` unconditionally consumes `new` (hashing onto `ses->se_conns` or calling `free_conn(new)`), so `nfsd4_sequence` must set `conn = NULL` right after calling it. When `nfsd4_process_open2` or `init_open_stateid` hashes `open->op_file`, `open->op_stp`, or `open->op_odstate`, it must clear that `open->op_*` pointer to `NULL` so `nfsd4_cleanup_open_state` only frees unconsumed objects. `move_to_close_lru` must set `s->st_stid.sc_file = NULL` after `put_nfs4_file`. [F185, F186, F193]

## API Contracts
- `nfs4_preprocess_stateid_op` sets `*nfp = NULL` on entry, transfers the `nfs4_stid` ref to `*cstid` only on `nfs_ok` with `cstid != NULL` (dropping `s` on error or when `cstid == NULL`), and leaves `*cstid` untouched on `ZERO_STATEID`/`ONE_STATEID`, so callers passing `cstid` must pre-initialize `*cstid = NULL` and null-check `*cstid` even on `nfs_ok`. Likewise, `nfsd4_deleg_getattr_conflict` only writes `*pdp = dp` on `nfs_ok` when `ncf_file_modified` is true, so callers must pre-initialize `*pdp = NULL` and call `nfs4_put_stid(&dp->dl_stid)` when `*pdp != NULL`. [F188, F230, F234]
- `nfs4_preprocess_seqid_op`, `nfs4_preprocess_confirmed_seqid_op`, and `nfsd4_preprocess_layout_stateid` return `nfs_ok` (`0`) with a stateid ref and `stp->st_mutex` or `ls->ls_mutex` held (and neither on error); callers must unlock the mutex and call `nfs4_put_stid`. In `nfsd4_preprocess_layout_stateid`, only downcast `stid` to `nfs4_layout_stateid` when `stid->sc_type == SC_TYPE_LAYOUT`, and in the `sc_type != SC_TYPE_LAYOUT` branch `nfs4_put_stid(stid)` runs right after `nfsd4_alloc_layout_stateid`, so `!ls` must jump to `out`, not `out_put_stid`. [F51, F109, F131, F199]
- Callers of `get_client_locked(clp)` under `nn->client_lock` must verify it returns `nfs_ok` before using `clp` or later calling `put_client_renew_locked`/`put_client_renew`, as it returns `nfserr_expired` without incrementing `cl_rpc_users` when `is_client_expired(clp)`. Overwriting `clp->cl_cred` or `slot->sl_cred` via `copy_cred()` requires freeing any prior cred with `free_svc_cred()`. [F219, F336]
- `stp->st_access_bmap` and `stp->st_deny_bmap` store bit indices `1 << mode` (bits 1..3), not wire `NFS4_SHARE_*` masks, so converting to a wire mask requires `bmap_to_share_mode(bmap)` (e.g., for `reset_union_bmap_deny`). In `struct nfs4_file`, `fi_fds[3]` is indexed by `O_RDONLY`/`O_WRONLY`/`O_RDWR` via `nfs4_access_to_omode()`, whereas `fi_access[2]` and `__nfs4_file_put_access(fp, oflag)` only accept `O_RDONLY` (0) or `O_WRONLY` (1) (`1 - oflag`). [F225, F226]

## Error Handling
- In `fs/nfsd/nfs4callback.c`, backchannel XDR reply decoders (`decode_cb_fattr4`, `decode_cb_op_status`, `decode_cb_compound4res`, `decode_cb_sequence4resok`, `nfs4_xdr_dec_cb_getattr`) must return `-EIO` on XDR stream/bounds failures rather than wire status like `-NFSERR_BAD_XDR`, and callers of `decode_cb_sequence4res` and `decode_cb_op_status` must check that both `status` and `cb->cb_seq_status` / `cb->cb_status` are zero before decoding further payload. [F34, F35]
- In `nfsd4_sequence()`, `seq->maxslots`, `seq->target_maxslots`, and `seq->status_flags` must be populated after `out:` so `nfserr_replay_cache` replays jumping to `out:` still return initialized fields. In `nfsd4_create_session`, if `mark_client_expired_locked(old)` fails with `nfserr_jukebox` after `cs_slot->sl_seqid` was incremented, `out_expired_error` must revert `cs_slot->sl_seqid--` and skip `nfsd4_cache_create_session` before unlocking `nn->client_lock` and freeing `conn` and `new`. [F202, F220]
- In `fs/nfsd/nfsfh.c`, `__fh_verify()`, `nfsd_set_fh_dentry()`, and `nfsd_setuser_and_check_port()` must guard every `rqstp` dereference with a NULL check because `fh_verify_local()` passes `rqstp == NULL` for LOCALIO, and `nfsd_set_fh_dentry()` must check `exportfs_decode_fh_raw()` with `IS_ERR_OR_NULL()` before assigning `fhp->fh_dentry` and `fhp->fh_export`. In `nfsd_open_local_fh`, check `nfs_fh->size <= NFS4_FHSIZE` before `memcpy`, and convert non-zero `beres` via `ERR_PTR(nfs_stat_to_errno(be32_to_cpu(beres)))`. [F38, F89, F376, F377]

## External Contracts
- In `nfsd4_lookup_stateid()`, `statusmask` must always include `SC_STATUS_ADMIN_REVOKED | SC_STATUS_FREEABLE` (and `SC_STATUS_REVOKED` when `typemask & SC_TYPE_DELEG`) before `find_stateid_by_type()`. In `check_special_stateids()`, `ONE_STATEID(stateid) && (flags & RD_STATE)` must return `nfs_ok` before `opens_in_grace(net)`, whereas WRITE with `one_stateid` and READ/WRITE with `zero_stateid` must check `opens_in_grace(net)` first. [F267, F281]

## Known Pitfalls
- XDR strings and netobjs (`xdr_netobj_dup` buffers `cl_name`, `cl_nii_domain`, `cl_nii_name`, `so_owner`, `ld_owner`; strings from `nfsd4_decode_component4`, `nfsd4_decode_opaque`, `nfsd4_decode_nl4_server`, `svcxdr_decode_filename`; and `name` in `idmap_name_to_id` / `numeric_name_to_id`) are not NUL-terminated: never pass them to `%s`, `strcmp`, `strlen`, or `kstrtouint` without bounding by `.len`/`namelen` (or copying into a bounded buffer and NUL-terminating at `buf[namelen]`). [F137, F303, F470]
- In `nfs4_open_delegation()` and `nfs4_delegation_stat()`, `currentfh` is the parent directory during `NFS4_OPEN_CLAIM_NULL`, so delegation file attributes must be queried from `file_dentry(nf->nf_file)` on `dp->dl_stid.sc_file` with `STATX_MODE` rather than `currentfh->fh_dentry`. Also, `struct nfs4_clnt_odstate` pointers (`op_odstate`, `st_clnt_odstate`, `dl_clnt_odstate`) are `NULL` unless both `nfsd4_has_session(cstate)` and `NFSEXP_PNFS` are set, so all consumers must tolerate `NULL`. [F227, F268]
- In `nfsd4_lock()`, when `lock->lk_is_new` is true, `cstate->replay_owner` is `&open_sop->oo_owner`, so `out:` must also manually increment `lock_sop->lo_owner.so_seqid++` when `cstate->replay_owner && cstate->replay_owner != &lock_sop->lo_owner && seqid_mutating_err(ntohl(status))`. In `nfsd4_setclientid_confirm()`, `old` is destroyed by `expire_client(old)` after dropping `nn->client_lock`, so any failure in the `!conf` branch after `old = find_confirmed_client_by_name(...)` before `mark_client_expired_locked(old)` must reset `old = NULL` before `goto out`. [F285, F286]
