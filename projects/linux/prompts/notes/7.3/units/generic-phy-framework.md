# GENERIC PHY FRAMEWORK

The Generic PHY framework (`include/linux/phy/*`, `include/dt-bindings/phy/*`) defines subsystem-wide API contracts (`struct phy`, `struct phy_ops`, `union phy_configure_opts`) and provides transceiver, multi-protocol SERDES, clock/reset controller, and USB OTG/charger PHY drivers across Cadence, Freescale/NXP i.MX, Socionext UniPhier, STMicroelectronics, and Texas Instruments SoCs.

## Architecture & Data Flow

- In `cdns_sierra_phy_configure_multilink()` and `cdns_torrent_phy_configure_multilink()`, the second pass (`node == 1` in Sierra, `protocol == 1` in Torrent) must swap `phy_t1`/`phy_t2` (and `ref_clk`/`ref_clk1` in Torrent) before table lookup; when Torrent temporarily rewrites two PCIe subnodes from `TYPE_PCIE` to `TYPE_PCIE_ML`, it must restore `TYPE_PCIE` before returning so `cdns_torrent_phy_on` and `cdns_torrent_phy_resume_noirq` observe `TYPE_PCIE`. [F48, F74]
- In `phy-cadence-sierra.c`, when `sp->nsubnodes > 1`, common CDB registers and `sp->phy_rst` are configured once during probe, so `cdns_sierra_phy_init` returns early and `cdns_sierra_phy_on` only deasserts `sp->phy_rst` when `sp->nsubnodes == 1`. When `sp->already_configured` is non-zero at probe, `PHY_CLK` and resets are not acquired, child PHYs use `noop_ops`, and `cdns_sierra_phy_disable_clocks` skips `PHY_CLK`. Lane CDB regmaps are indexed by `i + ins->mlane` and status fields by `ins->mlane`. [F45, F46, F47]
- In `phy-cadence-torrent.c`, `base`, `regmap_dptx_phy_reg`, and `phy_reset_ctrl` are only initialized for `TYPE_DP`, and `inst->mlane + inst->num_lanes` (and `inst->mlane + dp->lanes`) must stay `<= MAX_NUM_LANES` (4). Every `struct cdns_torrent_vals` in `link_cmn_vals_tbl` must have `num_regs >= 1` with `PHY_PLL_CFG` at `reg_pairs[0]` (`reg_pairs[1..num_regs-1]` go to `regmap_common_cdb`). [F31, F62, F92]
- In `phy-cadence-torrent.c`, `cdns_torrent_dp_get_pll()` must populate `cdns_phy->dp_pll` (`DP_PLL0`/`DP_PLL1`) before `cdns_torrent_dp_common_init()` or rate/VCO helpers, and 100 MHz rate changes must only touch PLL registers for bits in `cdns_phy->dp_pll`. `cdns_torrent_dp_configure_rate` requires lanes in `POWERSTATE_A3` and PLL clocks disabled; in `cdns_torrent_dp_set_voltages`, `TX_DIAG_ACYA_HBDC_MASK` must bracket the four TX swing/pre-emphasis writes. [F42, F51, F52, F53]
- In `phy-fsl-imx8-mipi-dphy.c`, `lvds_regmap` and `ipc_handle` are only populated when `devdata->is_combo` is true (`MIXEL_IMX8QXP`), whereas `reg_tx_rcal` and RX settle/RP offsets are only populated when `is_combo` is false (`MIXEL_IMX8MQ`); `mixel_dphy_configure_lvds_phy` must update `priv->is_slave` alongside `IMX_SC_C_DUAL_MODE`, and `mixel_dphy_power_on_lvds_phy` must skip `DPHY_LOCK` polling when `priv->is_slave` is true. [F29, F54]
- In `phy-fsl-samsung-hdmi.c`, `phy->cur_cfg` is NULL until `fsl_samsung_hdmi_phy_configure()` runs via `clk_ops.set_rate`, so `phy_clk_recalc_rate()` and `fsl_samsung_hdmi_phy_resume()` (which must re-enable `phy->apbclk` first) must null-check `phy->cur_cfg`. `fsl_samsung_hdmi_phy_configure()` uses 8-bit accesses at 4-byte `PHY_REG(reg)` offsets, mirrors `cfg->pll_div_regs[2] >> 4` into `REG21_PMS_S_MASK` of `PHY_REG(21)`, and sets `REG33_FIX_DA | REG33_MODE_SET_DONE` before polling `REG34_PLL_LOCK`. [F33, F59, F66, F118, F119]
- In `phy-gmii-sel.c`, `phy_gmii_init_phy()` must copy each template from `soc_data->regfields[port - 1]` into a local `struct reg_field`, add `priv->reg_offset`, and increment `*fields++` at every enum position even when its feature bit in `soc_data->features` is unset. In `phy_gmii_sel_mode()`, `if_phy->phy_if_mode` is updated only after validation; `RGMII_RXID` sets `rgmii_id = 0` while `RGMII_ID`/`RGMII_TXID` set `rgmii_id = 1`, and `PHY_GMII_SEL_FIXED_TX_DELAY` SoCs reject `rgmii_id != 0` while still defining `RGMII_ID_MODE` in `regfields`. [F199, F200, F226, F233, F255]
- In `phy-ti-pipe3.c` and `phy-omap-usb2.c`, optional or mode-unused clocks (`refclk`, `wkupclk`, `div_clk`, `optclk`) hold `ERR_PTR` when absent and must be checked with `!IS_ERR()`, not non-NULL. In `phy-tusb1210.c`, ULPI writes to `ULPI_OTG_CTRL` or `TUSB1210_VENDOR_SPECIFIC2` must be cached in `tusb` for restoration, and once `TUSB1210_CHG_DET_CONNECTING` gets runtime PM on `tusb->dev->parent`, every path must reach `TUSB1210_CHG_DET_FINISH_DET` to put it. [F183, F201, F234]

## Synchronization

- `struct phy` protects `phy_ops` callbacks with `struct mutex mutex` using a per-instance `lockdep_key`, so `phy_ops` run in sleeping process context and must never be called from atomic context. Before calling `of_phy_provider_register()` or `devm_of_phy_provider_register()`, drivers must set `phy_set_drvdata()`, `dev_set_drvdata()`, and finish all subnode/multilink setup (`sp->nsubnodes`, `cdns_phy->nsubnodes`, `priv->phys[i]`). [F14, F21, F158, F159, F274]
- In `phy-fsl-imx8qm-lvds-phy.c`, `mixel_lvds_phy_probe` must initialize `priv->lock` and `dev_set_drvdata` before `pm_runtime_enable` and `mixel_lvds_phy_reset`, and `mixel_lvds_phy_reset` must not hold `priv->lock` across runtime PM calls. `PHY_NUM` is 2 (`id` in `{0, 1}`): `mixel_lvds_phy_validate` caches `opts->lvds` into `lvds_phy->cfg` under `priv->lock` for companion checks via `id ^ 1`, and `power_on`/`off` return 0 for slaves while the master under `priv->lock` toggles `phy_ref_clk` and `CH_EN(0) | CH_EN(1)`. [F13, F57, F70, F117]
- In `phy-fsl-imx8mq-usb.c`, `tca_blk_typec_switch_set()` must enable `imx_phy->clk` around `tca_blk_orientation_set()`. `tca_blk_orientation_set()` must hold `tca->mutex` (so `tca_blk_init()` must not hold it when calling), set `TCA_SYSMODE_TCPC_DISABLE` before changing `TCA_SYSMODE_TCPC_FLIP`, and cache `tca->orientation` for `tca_blk_init()` to re-apply after toggling `TCA_CLK_RST_SW`. [F16, F58, F113]
- Regmaps accessed by atomic CCF `clk_ops` (`.enable`, `.disable`, `.is_enabled`)—`cdns_sierra_common_cdb_config`, `cdns_torrent_common_cdb_config`, `cdns_torrent_phy_pcs_cmn_cdb_config`, and `wiz_regmap_config` (`wiz_phy_en_refclk_ops`)—must remain non-sleeping spinlock-backed (`.fast_io = true`). Conversely, `usbphyc_clk48_ops` (`phy-stm32-usbphyc.c`) must hook `stm32_usbphyc_pll_enable`/`_disable` into `.prepare`/`.unprepare` because they sleep, and `wiz_phy_reset_deassert` (ID 0 with `gpio_typec_dir`) sleeps. [F19, F280, F281, F282]

## Object Lifetimes

- Non-devm OF clock providers in `cdns_sierra_clk_register`, `cdns_torrent_clk_register` (registering `derived_refclk` and `received_refclk` before `cdns_torrent_refclk_driver_register`), `phy-fsl-samsung-hdmi.c`, `serdes_am654_probe` (jumping to `clk_err` on failure), and `wiz_clock_probe` (`J721E_WIZ_16G`/`10G` child providers cleaned up with `of_node_put`, matching `switch (wiz->type)` in `wiz_clock_cleanup`) must be unregistered via `of_clk_del_provider` in `.remove` and probe error paths. [F8, F18, F150, F152, F230]
- In `cdns_sierra_phy_probe` and `cdns_torrent_phy_probe`, subnode link resets (`phys[node].lnk_rst`) use non-devm `of_reset_control_array_get_exclusive`: in Torrent, loop errors before it succeeds jump to `put_lnk_rst` while errors after jump to `put_child` (incrementing `node`), and in Sierra, errors after it succeeds must release `lnk_rst` for both the current unincremented `node` and `0 .. node - 1`. [F3, F26]
- Shared resource refcounting: in `phy-fsl-imx8qm-hsio.c`, `imx_hsio_power_on`/`off` update `priv->open_cnt` under `priv->lock`, configuring shared misc/clock-pad registers on `0 -> 1` and asserting shared resets on `1 -> 0`. In `phy-stm32-usbphyc.c`, the PLL is refcounted via `stm32_usbphyc_pll_enable`/`_disable` (`n_pll_cons`); `usbphyc_phy->active` tracks port references, and `stm32_usbphyc_remove` must exit active ports and unregister `clk48` before disabling `usbphyc->clk`. [F10, F165, F195, F271]
- Device, node, and lookup lifetimes: `omap_usb2_probe()` and `ti_pipe3_get_sysctrl()` must register `put_device(&control_pdev->dev)` via `devm_add_action_or_reset()` after `of_find_device_by_node()`. `wiz_probe()` must `of_node_put(child_node)` for `"serdes"` on all exits and `wiz_remove()` must destroy `serdes_pdev` before `wiz_clock_cleanup()`. `tusb1210_get_online()` must `power_supply_put()` immediately, and `ulpi_phy_destroy()` must call `phy_remove_lookup()` before `phy_destroy()`. [F144, F145, F151, F154]

## API Contracts

- In `include/linux/phy/phy.h` (and `omap_control_phy.h`), exported declarations under `#if IS_ENABLED(CONFIG_GENERIC_PHY)` and `#else` stubs must be updated in lockstep: `devm_phy_optional_get()` and `devm_of_phy_optional_get()` return NULL when absent or disabled (whereas non-optional getters return `ERR_PTR`), and operation stubs (`phy_init`, `phy_power_on`, `phy_configure`, `phy_validate`, etc.) must return 0 when `!phy` before returning `-ENOSYS`/`-ENODEV`. [F169, F170, F211]
- `struct phy_ops::validate` may adjust `union phy_configure_opts *opts` but must never mutate hardware or `struct phy` state (`cdns_dphy_validate` and `mixel_dphy_validate` use stack-local configs without mutating `dphy->cfg`/`priv->cfg`), whereas `.configure` requires `phy_init()` first. In `cdns-dphy.c`, `cdns_dphy_configure()` only updates `dphy->cfg` and sets `is_configured = true`, while register writes and lock polling happen in `cdns_dphy_power_on()`; in `cdns_dphy_ops`, only `get_wakeup_time_ns` is mandatory. [F30, F43, F55, F98, F171]
- Unit conventions: in `phy_configure_opts_dp`, `link_rate` is in Mb/s, updates are gated on `set_rate`/`set_lanes`/`set_voltages`, and `set_voltages` only programs lanes `0 .. lanes - 1` (in Torrent, `cdns_torrent_dp_verify_config` checks `voltage[i] + pre[i] <= 3` to avoid `0xFFFF` in `vltg_coeff`). In `phy_configure_opts_mipi_dphy`, `hs_clk_rate`/`lp_clk_rate` are in Hz (`cdns_dphy_rx_get_band_ctrl` uses `hs_clk_rate / 1000000UL * 2`), `clk_pre` in UI, `init`/`wakeup` in us (`get_wakeup_time_ns / 1000`), and other timings in ps. [F41, F63, F128, F172, F173, F284]
- Driver data and indexing: in `phy-cadence-sierra.c`, `phy-cadence-torrent.c`, `phy-fsl-imx8qm-lvds-phy.c`, `phy-stm32-usbphyc.c`, and `phy-gmii-sel.c`, `phy_get_drvdata(phy)` holds the per-link/per-port struct while `dev_get_drvdata(phy->dev.parent)` holds the controller struct. In `phy-gmii-sel.c`, 1-based port IDs (`1..num_ports`) convert to `id - 1`; in `phy-j721e-wiz.c`, reset ID 0 is whole-SERDES reset and IDs `1..num_lanes` map to lane `id - 1`. [F96, F179, F181, F239, F247]

## Error Handling

- Signedness and NULL vs `ERR_PTR`: `cdns_dphy_rx_get_band_ctrl()`, `cdns_dphy_tx_get_band_ctrl()`, `twl4030_readb()`, and `twl4030_usb_read()` return `0` as a valid value and negative errno on failure, so store in a signed `int` and check `< 0` / `>= 0`. In `cdns_torrent_refclk_driver_register()`, after `IS_ERR_OR_NULL(hw)`, return `IS_ERR(hw) ? PTR_ERR(hw) : -ENOENT`. In `wiz_probe()`, `devm_ioremap()` and `of_platform_device_create()` return NULL on failure, and jumping to cleanup labels in Sierra, Torrent, or WIZ probes after `ret == 0` requires setting a negative errno. [F22, F24, F27, F180, F187]
- Optional resource fallbacks and unwinds: when `devm_regulator_get_optional()` in `stm32_usbphyc_probe` or UniPhier USB PHY probes returns an `IS_ERR()` other than `-EPROBE_DEFER`, `vbus` must be set to NULL; similarly, failed optional syscon lookups in `wiz_probe()`, `ti_pipe3_get_sysctrl()`, or `omap_usb2_probe()` must clear the regmap pointer to NULL. Early exits from `for_each_child_of_node()` in `stm32_usbphyc_probe()` and `uniphier_u2phy_probe()` must call `of_node_put(child)`, and errors in `stm32_usbphyc_pll_enable()` after `atomic_inc_return(&usbphyc->n_pll_cons)` must decrement `n_pll_cons`. [F148, F156, F177, F182, F184]

## External Contracts

- In `phy-j721e-wiz.c`, `wiz->output_clks[]` and `output_clk_names[]` are indexed by sparse `TI_WIZ_*` DT binding constants (up to `TI_WIZ_PHY_EN_REFCLK == 16`), so `WIZ_MAX_OUTPUT_CLOCKS` and `wiz->clk_data.clk_num` must remain larger than the highest `TI_WIZ_*` constant, and `wiz_phy_en_refclk_register` must allocate `strlen(dev_name(dev)) + strlen(output_clk_names[TI_WIZ_PHY_EN_REFCLK]) + 2` bytes for `"%s_%s"`. In `stm32_usbphyc_of_xlate()`, port 0 requires `args->args_count == 0` while port 1 requires `args->args_count == 1`. [F218, F224, F246]

## Known Pitfalls

- Arithmetic overflow/underflow and 64-bit division: in `cdns_dphy_get_pll_cfg()`, `fsl_samsung_hdmi_phy_find_pms()` (checking `tmp <= 255` before assigning to `_m`), and `stm32_usbphyc_get_pll_params()` (after checking `clk_rate` in `[PLL_INFF_MIN_RATE_HZ, PLL_INFF_MAX_RATE_HZ]`), widen rates/FVCO to 64-bit before multiplication and divide via `DIV_ROUND_UP_ULL`/`div_u64`/`do_div()`. In `mixel_dphy_config_from_opts()`, check `hs_prepare >= lp_t` before subtracting `lp_t`; in `fsl_samsung_hdmi_phy_lookup_rate()` (`rate >= 22250000`), cast both operands to `long` inside `abs()`. [F64, F86, F88, F89, F91, F236, F237, F238]
- Driver-specific quirks: in `phy-cadence-torrent.c`, `CDNS_TORRENT_KEY` uses 3-bit fields (`0..7`), and `enum cdns_torrent_phy_type` is already at 7 (`TYPE_PCIE_ML`). In `phy-cadence-sierra.c`, `cdns_sierra_pll_mux_get_parent()`/`_set_parent()` must test `strstr(..., "pll_cmnlc1")` before `"pll_cmnlc"`. In `wiz_probe()`, skip `wiz_init(wiz)` if any lane has `P_ENABLE`/`P_ENABLE_FORCE` set, and in `wiz_mode_select()`, place all `lane_phy_type[i]` branches before `else continue;`. In `phy-gmii-sel.c`, only set `priv->reg_offset = __be32_to_cpu(*offset)` when `!priv->no_offset`. [F85, F97, F216, F225, F254, F260]
