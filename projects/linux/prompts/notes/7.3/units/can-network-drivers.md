# CAN NETWORK DRIVERS

The CAN network drivers unit provides the core SocketCAN device framework (`drivers/net/can/dev/*`)—handling `net_device` allocation (`alloc_candev_mqs`), RTNetlink configuration (`can_link_ops`), bittiming, TX echo SKBs, NAPI RX offloading (`can_rx_offload`), and bus-off recovery—alongside controller drivers for MMIO/PCI/ISA/PCMCIA (`at91_can`, `c_can`/`d_can`, `cc770`, `flexcan`, `grcan`, `ifi_canfd`, `sja1000`, `softing`, `sun4i_can`, `ti_hecc`), SPI (`hi311x`, `mcp251x`), USB (`ems_usb`, `gs_usb`, `kvaser_usb`, `peak_usb`, `ucan`, `usb_8dev`), and virtual interfaces (`vcan`, `vxcan`).

## Architecture & Data Flow

- Every `candev` driver's private struct must embed `struct can_priv` at offset 0 and pass `sizeof(*priv)` to `alloc_candev_mqs()`. `vcan` and `vxcan` lack `can_priv` (`vxcan` places `can_ml_priv` at `netdev_priv(dev) + ALIGN(sizeof(struct vxcan_priv), NETDEV_ALIGN)`) and must never call `can_dev_dropped_skb()` or `can_change_mtu()`, whereas `candev` drivers must use `can_dev_dropped_skb()` in `ndo_start_xmit` and `safe_candev_priv()` on arbitrary netdevs. [F71, F109, F111, F112, F344, F428, F450]
- On RX paths, 4-bit hardware DLCs for Classical CAN frames must be clamped to `CAN_MAX_DLEN` (8) via `can_cc_dlc2len()` or `can_frame_set_cc_len()` (mandatory when advertising `CAN_CTRLMODE_CC_LEN8_DLC` in `sja1000`/`gs_usb`, and in `kvaser_usb_hydra_rx_msg_ext()`/`pcan_usb_fd_decode_canmsg()` when `alloc_can_skb()` allocates into a `canfd_frame *` pointer) rather than `can_fd_dlc2len()` or raw `reg & 0xf`. [F70, F351, F463]
- In `flexcan`, mailbox layout (`mb_size`, `mb_count`, `tx_mb_reserved`, `tx_mb_idx`, `tx_mb`, `tx_mask`, `rx_mask`) must be recomputed in `flexcan_rx_offload_setup()` on every `flexcan_open()` and addressed via `flexcan_get_mb(priv, mb_index)`. Payload words in `flexcan` (`mb->data[i / sizeof(u32)]`) and `ti_hecc` (`HECC_CANMDL`/`HECC_CANMDH`) are big-endian and require `be32_to_cpu()`/`cpu_to_be32()`. [F46, F53, F83, F115, F117, F270]
- In `c_can`, hardware message objects are 1-based (`1..msg_obj_num`), whereas TX ring indices `idx` (`0..msg_obj_tx_num - 1`, power of two) are 0-based (`obj = idx + priv->msg_obj_tx_first`); `c_can_get_tx_free()` only uses modular `head - tail` for `BOSCH_D_CAN`. If RTR changes vs `priv->tx_dir` in `c_can_setup_tx_object()`, call `c_can_inval_msg_object()` and `change_bit()`, and clear `priv->tx_dir = 0` in `c_can_chip_config()`. [F58, F77, F105]
- In `drivers/net/can/dev/netlink.c`, `can_get_size()` (and `can_data_bittiming_get_size()`, `can_tdc_get_size()`, `can_ctrlmode_ext_get_size()`) must stay synchronized with `can_fill_info()`, computing pointer-backed array sizes (`termination_const`, `bitrate_const`, `data_bitrate_const`) as `sizeof(*ptr) * cnt` rather than `sizeof(ptr)`. [F65, F114]
- In `kvaser_usb_leaf`, `kvaser_cmd` overlays incompatible `u.leaf` and `u.usbcan` layouts; handlers must verify `cmd->len` via `kvaser_usb_leaf_verify_size()` (registered in `kvaser_usb_leaf_cmd_sizes_leaf`/`_usbcan`) and branch on `dev->driver_info->family`. In `kvaser_usb_hydra`, downcast `kvaser_cmd *` to `kvaser_cmd_ext *` only when `cmd_no == CMD_EXTENDED` (and format TX as ext only if `KVASER_USB_HYDRA_CAP_EXT_CMD`), and verify `channel < dev->nchannels` before indexing `dev->nets[channel]`. [F393, F395, F415, F420]

## Synchronization

- In `c_can_start_xmit()`, `flexcan_start_xmit()`, `grcan_start_xmit()`, and `ifi_canfd_start_xmit()`, `can_put_echo_skb()` must be called before writing the hardware register/command that triggers transmission (`c_can_object_put(dev, IF_TX, obj, cmd)`, `priv->write(ctrl, &priv->tx_mb->can_ctrl)`, `grcan_write_reg(&regs->txwr, ...)`, or `writel(IFI_CANFD_TXSTCMD_ADD_MSG, ...)`). [F2, F20]
- `close_candev()` and `can_restart_now()` must call `cancel_delayed_work_sync(&priv->restart_work)` (under `rtnl_lock`) before `can_flush_echo_skb()` or `can_restart()`, so `can_restart()` and `do_set_mode` callbacks must never acquire `rtnl_lock`. In `can_restart()`, `netif_carrier_on(dev)` must precede `priv->do_set_mode(dev, CAN_MODE_START)` (and revert on error) so an immediate bus-off IRQ is not overwritten. [F15, F16, F154]
- `can_rx_offload_queue_timestamp()` and `can_rx_offload_queue_tail()` enqueue only to `offload->skb_irq_queue`, spliced into `offload->skb_queue` under `offload->skb_queue.lock` by `can_rx_offload_irq_finish()` or (from threaded IRQs, which wrap `napi_schedule()` with `local_bh_disable()`/`enable()`) `can_rx_offload_threaded_irq_finish()`. After `napi_complete_done()` in `can_rx_offload_napi_poll()`, recheck `!skb_queue_empty(&offload->skb_queue)` and reschedule NAPI if non-empty. [F17, F18, F147]
- Configuration mutations on registered CAN devices (`can_change_mtu`, `can_ctrlmode_changelink`, `can_dbt_changelink`, `can_changelink`, `at91_can` `mb0_id_store`, and `vcan`/`vxcan` MTU changes) must hold `rtnl_lock` and reject changes with `-EBUSY` when `dev->flags & IFF_UP`. [F29, F161, F429]
- In `c_can`, `c_can_start_xmit()` must use interface bank `IF_TX` (`1`) while `c_can_poll()` and `c_can_configure_msg_objects()` use `IF_NAPI` (`0`). `c_can_tx_busy()` must execute `smp_mb()` after `netif_stop_queue()` and recheck `c_can_get_tx_free()`, pairing with `smp_mb()` between `tx_ring->tail += pkts` and `netif_wake_queue()` in `c_can_do_tx()`. [F21, F57]
- In `grcan.c`, `priv->lock` (`spin_lock_irqsave`) protects `eskbp`, `resetting`, `closing`, `catch_up_echo_skb()`, `grcan_start()`, `regs->imr` in `grcan_poll()`, and `netif_wake_queue()`/`grcan_reset_timer()` (requiring `!resetting && !closing`). `grcan_close()` must set `closing = true` under `priv->lock`, drop `priv->lock` for `timer_delete_sync()`, and re-acquire it for `grcan_stop_hardware()`. [F23, F26, F60, F61, F141, F151]
- In `hi311x` and `mcp251x`, all runtime SPI transfers and `spi_tx_buf`/`spi_rx_buf` accesses must hold `hi3110_lock`/`mcp_lock`. In `hi3110_stop()` and `mcp251x_stop()`, set `force_quit = 1` and call `free_irq(spi->irq, priv)` before acquiring `hi3110_lock`/`mcp_lock`. `mcp251x_hw_wake()` (under `mcp_lock`) must use `disable_irq_nosync(spi->irq)` and `enable_irq(spi->irq)`. [F334, F335, F336]
- In `sja1000` and `sun4i_can`, writes to `SJA1000_CMR` / `SUN4I_REG_CMD_ADDR` must use `sja1000_write_cmdreg()` / `sun4i_can_write_cmdreg()` under `spin_lock_irqsave(&priv->cmdreg_lock, flags)`. On `SJA1000_QUIRK_RESET_ON_OVERRUN`, `sja1000_reset_interrupt()` must hold `netif_tx_lock(dev)` while freeing echo slot 0 and calling `sja1000_set_mode(dev, CAN_MODE_START)`. [F211, F234]
- In `gs_usb`, `gs_usb_timestamp_read()` is called under `spin_lock_bh(&parent->tc_lock)`, drops `tc_lock` for sleeping `gs_usb_get_timestamp()`, and must re-acquire `spin_lock_bh(&parent->tc_lock)` before returning on every path. In `gs_can_open()`, call `gs_usb_timestamp_init(parent)` before submitting RX URBs when `!parent->active_channels`, and hold `dev->tx_ctx_lock` (`spin_lock_irqsave`) in `gs_alloc_tx_context()`/`gs_get_tx_context()`. [F190, F202, F204]
- In `kvaser_usb`, synchronous `kvaser_usb_recv_cmd()` is only allowed during probe before `kvaser_usb_setup_rx_urbs()` sets `dev->rxinitdone`; later replies must use `struct completion` (initialized via `init_completion()` in `kvaser_usb_init_one()` and reset via `reinit_completion()`). Because `usb_rx_leftover_lock` wraps `kvaser_usb_hydra_handle_cmd()`, paths holding `tx_contexts_lock` or `transid_lock` must never acquire `usb_rx_leftover_lock`. [F359, F368, F370, F476, F489]
- In `ucan`, `up->context_lock` (`spin_lock_irqsave`) protects `context_array[i].allocated`, `available_tx_urbs`, and `netif_stop_queue()`/`netif_wake_queue()`, while `up->echo_skb_lock` (`spin_lock_irqsave`) must protect all `can_put_echo_skb()`, `can_get_echo_skb()`, and `can_free_echo_skb()` calls; `ucan_tx_complete_msg()` must only get/free the echo SKB when `ucan_release_context()` returns `true`. [F365, F375, F376]

## Object Lifetimes

- In `gs_can_start_xmit()` and `ems_usb_start_xmit()`, `can_put_echo_skb()` precedes `usb_submit_urb()`, so if `usb_submit_urb()` fails, free the SKB via `can_free_echo_skb()` (never `dev_kfree_skb()`) while rolling back `active_tx_urbs`, the URB anchor, and the TX context. In `gs_usb`, setting `URB_FREE_BUFFER` transfers buffer ownership to `usb_free_urb(urb)` (do not `kfree()`), whereas `ems_usb` and `ucan` RX URBs use `usb_alloc_coherent()` and must call `usb_free_coherent()` whenever an URB completes without resubmission or fails on submission. [F186, F187, F188, F364, F492]
- On USB disconnect/close (`ems_usb`, `gs_usb`, `kvaser_usb`, `peak_usb`, `ucan`, `usb_8dev`): unregister netdevs before unlinking URBs; kill anchored URBs (`usb_kill_anchored_urbs()`) before freeing `rxbuf` coherent buffers, `ucan`'s `context_array`, or channel state (`ops->dev_remove_channel()`, `kvaser_usb_devlink_port_unregister()`, `free_candev()`). In `gs_can_close()`, only kill `parent->rx_submitted` and stop `parent->timestamp` when `--parent->active_channels == 0`. In `peak_usb_unlink_all_urbs()`, free unsubmitted `tx_contexts[i].urb` (`echo_index == PCAN_USB_MAX_TX_URBS`) before `usb_kill_anchored_urbs(&dev->tx_submitted)`, and in `peak_usb_write_bulk_callback()`, always release `echo_skb` and reset `echo_index` even when `urb->status != 0`. [F205, F206, F358, F360, F372, F377, F379, F407, F493]
- In `flexcan`, keep chip interrupts masked in `flexcan_open()` until `can_rx_offload_enable()` and all `request_irq()` calls succeed; in `flexcan_close()`, call `flexcan_chip_interrupts_disable()`, `can_rx_offload_disable()` before stopping the chip, and `can_rx_offload_del()` before `close_candev()`. `register_flexcandev()` calls `pm_runtime_put()` only on success, so `flexcan_probe()` must call `pm_runtime_put_noidle()` on failure. [F12, F13, F130]
- In `grcan`, `grcan_close()` must call `close_candev(dev)` before clearing `echo_skb_max`/`echo_skb` and `kfree(priv->echo_skb)`; `grcan_free_dma_buffers()` must pass `dma->base_size`, `dma->base_buf`, and `dma->base_handle` to `dma_free_coherent()`. In `c_can`, free devices via `free_c_can_dev()`; in `cc770` and `sja1000`, any failure after `alloc_cc770dev()`/`alloc_sja1000dev()` must call `free_cc770dev()`/`free_sja1000dev()` before unmapping I/O. [F8, F10, F11, F120, F183]
- In `vxcan`, `vxcan_setup()` sets `dev->needs_free_netdev = true`, so `vxcan_newlink()` must call `free_netdev(peer)` if `register_netdevice(peer)` fails, but roll back via `unregister_netdevice(peer)` (without `free_netdev()`) if a later step fails. `vxcan_xmit()` must hold `rcu_read_lock()` across `rcu_dereference(priv->peer)`, `netif_rx()`, and stats updates, consuming `oskb` via `consume_skb()` or freeing it via `kfree_skb()` on every path. [F353, F355, F373]

## API Contracts

- When `idx < priv->echo_skb_max` (0-based; subtract `get_mb_tx_first(priv)` in `at91_can` and `priv->msg_obj_tx_first` in `c_can`), `can_put_echo_skb()` always consumes or frees `skb`, so `ndo_start_xmit` callers must finish reading `skb`/`cf` and any `NETDEV_TX_BUSY` early returns before calling it. Every path that consumes or frees an echo slot (`__can_get_echo_skb()`, `can_free_echo_skb()`, `can_flush_echo_skb()`) must clear `priv->echo_skb[idx] = NULL` and use `dev_kfree_skb_any()`/`dev_consume_skb_any()`, while `can_skb_set_owner()` must use `refcount_inc_not_zero(&sk->sk_refcnt)`. [F1, F6, F7, F36, F42, F75, F149, F180]
- `can_rx_offload_queue_timestamp()` and `can_rx_offload_queue_tail()` unconditionally take ownership of `skb` and free it via `dev_kfree_skb_any(skb)` on `-ENOBUFS`, so callers must never free `skb` on error. `can_rx_offload::mailbox_read` callbacks (`flexcan_mailbox_read`, `ti_hecc_mailbox_read`) must return `NULL` when empty, a valid `sk_buff *` on success, and an `ERR_PTR` after acknowledging/unlocking the hardware mailbox when `drop` is true, overrun occurs, or SKB allocation fails. [F3, F30, F129, F252, F349]
- Every `ndo_open` must call `open_candev()`, and every `ndo_stop` (and `ndo_open` unwind) must call `close_candev()` and set `can.state = CAN_STATE_STOPPED`. In NAPI poll callbacks, every RX or error SKB passed to `netif_receive_skb()` must increment `work_done` against `quota`, and `napi_complete_done()` and IRQ re-enabling must only run when `work_done < quota`. Do not add `cf->len` to `rx_bytes`/`tx_bytes` when `CAN_RTR_FLAG` or `CAN_ERR_FLAG` is set. [F165, F172, F173, F235]
- In `kvaser_usb`, buffers passed to `kvaser_usb_send_cmd()` or `kvaser_usb_send_cmd_async()` must be heap-allocated; `kvaser_usb_send_cmd_async()` takes ownership of `cmd` only when returning `0` (callers must `kfree(cmd)` on error). In `peak_usb`, `dev_restart_async` takes ownership of `urb` and `buf` only when returning `0`. In `ucan_ctrl_command_out()` and `pcan_usb_pro_send_req()`, positive byte counts from `usb_control_msg()` must be clamped to `0`. [F356, F386, F396, F465, F495]

## Error Handling

- `alloc_can_err_skb()` sets `*cf = NULL` on failure, and `can_change_state()` accepts `cf == NULL`: error handlers (`c_can_handle_bus_err`, `ifi_canfd_handle_lec_err`, `at91_irq_err_frame`, `gs_usb_receive_bulk_callback`, `pcan_usb_fd_decode_status`, `pcan_usb_decode_error`) must still update `can_change_state()`, `can_bus_off()`, `tx_errors`/`rx_errors`/`rx_over_errors`, and hardware error counters when `alloc_can_err_skb()` returns `NULL`, and when `skb` is non-NULL must finish all writes to `*cf` before calling `netif_rx(skb)`. [F33, F51, F182, F233, F506]
- `can_priv::do_set_mode` may be `NULL`, so `can_restart()`, `can_restart_now()`, and `can_changelink()` (`IFLA_CAN_RESTART_MS` / `IFLA_CAN_RESTART`) must check `priv->do_set_mode != NULL`; manual `can_restart_now()` requires `dev->flags & IFF_UP`, `priv->restart_ms == 0`, and `priv->state == CAN_STATE_BUS_OFF`. Disabling `CAN_CTRLMODE_FD` must zero `data_bittiming` and `tdc` and clear `CAN_CTRLMODE_FD_TDC_MASK`, and a `can_tdc_changelink()` error must clear `tdc_mask` from `priv->ctrlmode`. [F38, F43, F176]

## Known Pitfalls

- 64-bit arithmetic & shifts: `can_calc_bittiming()`, `can_fixup_bittiming()`, `softing_initialize_timestamp()`, `softing_raw2ktime()`, and `kvaser_usb_ticks_to_ktime()` must widen operands to `u64` and use `do_div()`, `div_u64()`, or `DIV_U64_ROUND_CLOSEST()` (never `/`, with `card->pdat->freq ?: 16` in `softing` and `if (bitrate)` in `flexcan_chip_freeze()`). Mailbox masks in `flexcan`/`can_rx_offload` (`up to 64`), timestamp shifts by `ts_used_bits` (`32`) in `peak_usb`, and `u16` shifts (`<< 16`, `<< 32`) in `kvaser_usb_timestamp48_to_ktime()` must use `BIT_ULL()`, `GENMASK_ULL()`, or `(u64)` casts. [F101, F102, F108, F285, F444, F445, F446]
- In `c_can` and `flexcan`, hardirq/NAPI paths (`c_can_handle_state_change()`, `flexcan_irq_state()`) must call `__c_can_get_berr_counter()` / `__flexcan_get_berr_counter()` rather than the runtime-PM-sleeping `c_can_get_berr_counter()` / `flexcan_get_berr_counter()`. In `at91_can` and `flexcan`, IRQ loops calling `can_rx_offload_irq_offload_timestamp()` must `break` when it returns `0`. [F89, F150]
