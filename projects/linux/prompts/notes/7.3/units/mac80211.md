# MAC80211

`net/mac80211` implements the Linux IEEE 802.11 software MAC stack, bridging `cfg80211`/`nl80211` requests with hardware driver callbacks while managing virtual interfaces, MLO links, channel contexts, stations, keys, MLME state machines, scanning, rate control, and packet RX/TX paths.

## Architecture & Data Flow
- `NL80211_IFTYPE_AP_VLAN` interfaces are never added to the driver; `drv_sta_*`, `drv_set_key`, `drv_ampdu_action`, `drv_flush*`, and `drv_net_*` must call `get_bss_sdata(sdata)` before `check_sdata_in_driver(sdata)`. AP `link->conf->chanreq` updates must use `ieee80211_link_update_chanreq()`, and AP `crypto_tx_tailroom_needed_cnt` changes must propagate to `sdata->u.ap.vlans` via `update_vlan_tailroom_need_count()`. [F45, F55, F568]
- `sdata->bss` is only non-NULL while an `AP` is open or an `AP_VLAN` is attached to a running AP; check `sdata->bss` before `container_of(sdata->bss, ..., u.ap)`. In `ieee80211_set_vif_encap_ops()`, an `AP_VLAN` must read `vif.type` and `vif.offload_flags` from its parent `bss` while reading `wdev.use_4addr` and setting `dev->netdev_ops` on `sdata`. [F551, F630]
- During `local->in_reconfig`, `_ieee80211_link_use_channel()` must skip releasing the channel, `ieee80211_assign_link_chanctx()` must skip unassigning `curr_ctx` and adding `assigned_chanctx_list`, and `drv_wake_tx_queue()` must set `IEEE80211_TXQ_DIRTY`. `ctx->driver_present` must stay synced with the driver across `drv_add_chanctx()`, `drv_remove_chanctx()`, and `drv_switch_vif_chanctx()`, gating `ieee80211_iter_chan_contexts_*()`, `drv_change_chanctx()`, and `_ieee80211_recalc_chanctx_min_def()`. [F70, F73, F135]
- `WLAN_STA_AUTH`, `WLAN_STA_ASSOC`, and `WLAN_STA_AUTHORIZED` must only be updated by `_sta_info_move_state()` (never `set_sta_flag()`/`clear_sta_flag()`). For MLO stations (`sta->sta.valid_links && sta->sta.mlo`), `__ieee80211_sta_recalc_aggregates()` must write minimum A-MSDU lengths into `sta->cur` and set `sta->sta.cur = &sta->cur` rather than mutating `sta->sta.deflink.agg`, and in `_ieee80211_set_active_links()` it must be called again after `drv_change_sta_links()`. [F383, F385, F572]
- In `ieee80211_check_fast_rx()`, every exit path must reach `clear:` so `WLAN_STA_DECAP_OFFLOAD`, `drv_sta_set_decap_offload()`, and `sta->fast_rx` stay synced; `fast_rx` must be disabled if `AMPDU_AGGREGATION` lacks `SUPPORTS_REORDERING_BUFFER`, if station PS uses `PS_NULLFUNC_STACK` or lacks `SUPPORTS_DYNAMIC_PS`, or on AP/AP_VLAN without `AP_LINK_PS`. [F389, F477]
- `link_sta_info->pcpu_rx_stats` is allocated only when `USES_RSS` is set (`fast_rx->uses_rss`); all accessors must check `pcpu_rx_stats != NULL` before `per_cpu_ptr()`/`this_cpu_ptr()`, `ieee80211_rx_8023()` must update `pcpu_rx_stats` instead of `rx_stats_avg` when `uses_rss` is true, and `sta_info.c` readers must sum `rx_stats` and all CPUs of `pcpu_rx_stats`. [F365, F374, F400]
- When populating `struct cfg80211_mbssid_elems`, `struct cfg80211_rnr_elems`, or `local->hw_scan_req` in `__ieee80211_start_scan()`, the count (`dst->cnt` or `req.n_channels`) must be assigned before accessing the `__counted_by` flexible array (`dst->elem[]` or `req.channels[]`). [F74, F419]
- In `ieee80211_rx_h_decrypt()`, `rx->key = NULL` must be reset on entry (as `ieee80211_rx_handlers()` reuses `rx` across SKBs), and `mmie_keyidx >= 0 && ieee80211_is_beacon(fc)` must precede the general `mmie_keyidx >= 0` check so beacon BIGTK indices (`6..7`) are not dropped as `RX_DROP_U_BAD_MGMT_KEYIDX`. [F431, F432, F595]

## Synchronization
- Updates to RCU-protected pointers—AP frames on `link->u.ap`, `sdata->qos_map`, `pubsta->rates` in `rate_control_set_rates()`, and `sta->fast_rx` under `spin_lock_bh(&sta->lock)`—must fully populate the new object before `rcu_assign_pointer()` and free the old object via `kfree_rcu()`. [F26, F193, F485]
- Driver callbacks `ieee80211_csa_finish()`, `ieee80211_color_change_finish()`, `ieee80211_obss_color_collision_notify()`, and `ieee80211_request_smps()` may run without `wiphy->mtx`; they must check `link_id < IEEE80211_MLD_MAX_NUM_LINKS`, hold `rcu_read_lock()`, use RCU accessors (`rcu_dereference()`, `for_each_sdata_link_rcu()`), and keep RCU locked until `wiphy_work_queue()`/`wiphy_delayed_work_queue()` finishes. Work handlers `ieee80211_csa_finalize_work()` and `ieee80211_color_change_finalize_work()` must recheck `csa_active`/`color_change_active` and `ieee80211_sdata_running(sdata)`. [F31, F32, F80, F139, F682]
- `ieee80211_sta_bcn_mon_timer()` and `ieee80211_sta_conn_mon_timer()` run in timer softirq without `wiphy->mtx`, so `ieee80211_is_csa_in_progress()` and `ieee80211_latest_active_link_conn_timeout()` must use `guard(rcu)()` and RCU-safe accessors (`for_each_link_data_rcu()`, `sta_info_get()`, `rcu_dereference()`). [F322]
- `local->queue_stop_reason_lock` and `local->ack_status_lock` must use `spin_lock_irqsave()`/`spin_unlock_irqrestore()`; in `ieee80211_do_stop()`, SKBs unlinked from `local->pending[i]` must be passed to `ieee80211_free_txskb()` only after `spin_unlock_irqrestore()`. [F143, F320, F672]
- In `sta_ps_end()` and `ieee80211_sta_block_awake()`, `WLAN_STA_PS_DELIVER` must be set before clearing `WLAN_STA_PS_STA` or `WLAN_STA_PS_DRIVER`, and cleared in `ieee80211_sta_ps_deliver_wakeup()` under `spin_lock_bh(&sta->ps_lock)` after splicing `tx_filtered` and `ps_tx_buf` (`spin_lock_irqsave()` nested inside `sta->ps_lock`). While `WLAN_STA_PS_DRIVER` is set, delivery is deferred to `sta_deliver_ps_frames()`, which must wrap delivery calls in `local_bh_disable()`/`local_bh_enable()`. [F361, F475, F491, F492]
- `tid_agg_rx->reorder_lock` must protect all accesses to `reorder_buf`, `reorder_time`, `reorder_buf_filtered`, `head_seq_num`, and `stored_mpdu_num`, and must be dropped before calling `ieee80211_rx_handlers()`. `ieee80211_release_reorder_timeout()` must be called under `rcu_read_lock()`. [F362, F483]
- Per-STA `rate_control_ops` callbacks and `minstrel_ht_update_rates()` run under `spin_lock_bh(&sta->rate_ctrl_lock)` (nested inside `rcu_read_lock()` in `rate_init`/`rate_update`) and must use `GFP_ATOMIC`. `WLAN_STA_RATE_CONTROL` must be set only after `ref->ops->rate_init()` completes. [F194, F315, F497]
- Whenever `local->dynamic_ps_timer` is stopped with `timer_delete_sync()`, `local->dynamic_ps_enable_work` must also be cancelled via `wiphy_work_cancel()`. `ifocb->incomplete_lock` and `ifibss->incomplete_lock` are taken in RX softirq, so process-context callers must use `spin_lock_bh()` and drain `incomplete_stations` with `while (!list_empty(...))`, unlinking the first entry and dropping the lock before `sta_info_free()` or `ieee80211_{ocb,ibss}_finish_sta()`. [F206, F312, F622]
- In `ieee80211_ba_session_work()`, `fq->lock` nests inside `sta->lock`; if `!skb_queue_empty(&txqi->frags)`, both spinlocks must be dropped before `synchronize_net()` and re-queuing `work`. AQM and airtime handlers must hold `spin_lock_bh()` on `local->fq.lock` or `local->active_txq_lock[ac]` and keep `GFP_KERNEL` allocations and user copies outside the lock. [F145, F538]

## Object Lifetimes
- Channel contexts on `local->chanctx_list` are RCU-traversed and must use `list_add_rcu()` and `list_del_rcu()` + `kfree_rcu()`. Freeing either context of a replacement pair in `ieee80211_link_unreserve_chanctx()` or `ieee80211_vif_use_reserved_switch()` must reset the peer's `replace_ctx` and `replace_state`, and unreserving a zero-refcount `IEEE80211_CHANCTX_REPLACES_OTHER` context must free it via `list_del_rcu()`/`kfree_rcu()` without calling `ieee80211_free_chanctx()`. [F3, F69, F147]
- `ieee80211_link_copy_chanctx_to_vlans(link, true)` must be called before `ieee80211_link_release_channel(link)` so `AP_VLAN` interfaces never reference a freed channel context. In `ieee80211_stop_ap()`, `ieee80211_num_beaconing_links(sdata) <= 1` must be checked before `RCU_INIT_POINTER(link->u.ap.beacon, NULL)`, and `skb_queue_len(&sdata->u.ap.ps.bc_buf)` must be subtracted from `local->total_ps_buffered` before `ieee80211_purge_tx_queue()`. [F12, F18, F24, F102]
- Because `sdata->deflink.debugfs_dir` and `sta->deflink.debugfs_dir` alias `sdata->vif.debugfs_dir` and `sta->debugfs_dir` in non-MLO mode, `ieee80211_link_debugfs_remove()` and `ieee80211_link_sta_debugfs_remove()` must check for equality with the parent `debugfs_dir` and only clear the pointer without calling `debugfs_remove_recursive()`. [F15]
- When removing MLO links, `ieee80211_del_intf_link()` must not clear `BIT(link_id)` in `wdev->valid_links` before `ieee80211_vif_set_links()`; `ieee80211_vif_update_links()` must `RCU_INIT_POINTER` removed `sdata->link[link_id]` and `sdata->vif.link_conf[link_id]` to `NULL` and `ieee80211_tear_down_links()` must call `synchronize_rcu()` before freeing keys/links. [F17, F516, F536]
- `ieee802_11_parse_elems_full()` returns `&elems_parse->elems` at offset 0 of a heap allocation that callers must `kfree()` on every exit or `goto again` path. In `ieee80211_assoc_config_link()`, when element pointers are copied from `bss_elems` into `elems`, `bss_ies` must stay allocated until `elems` is freed and pointers into `bss_elems->scratch[]` must not outlive `kfree(bss_elems)`. [F176, F252, F271, F294]
- Two-phase station teardown requires `__sta_info_destroy_part1()` to stop BA sessions, call `drv_sync_rx_queues()`, unhash/unlink `sta`, and call `drv_sta_pre_rcu_remove()`, followed by `synchronize_net()` before `__sta_info_destroy_part2()` frees keys and moves driver state to `IEEE80211_STA_NOTEXIST`. Key removal in `ieee80211_free_keys_iface()` and `ieee80211_remove_link_keys()` must unlink keys and wait for `synchronize_net()`/`synchronize_rcu()` before `__ieee80211_key_destroy()`. [F468, F621]
- `sdata` is heap-allocated with `kzalloc()` only when `sdata->dev == NULL` (`P2P_DEVICE`, `NAN`, `local->monitor_sdata`); when `sdata->dev != NULL`, `sdata` and `to_txq_info(sdata->vif.txq)` live inside `netdev_priv(sdata->dev)` and must never be passed to `kfree()`. `sta->sta.txq[]` is a single `kcalloc` block at `sta->sta.txq[0]` freed via `kfree(to_txq_info(sta->sta.txq[0]))`. [F416, F642]

## API Contracts
- `sta_info_insert()` and `sta_info_insert_rcu()` consume `sta` and free it on any error (`sta_info_free()` may only be called before insertion is attempted). `sta_info_insert_rcu()`, `ieee80211_ocb_finish_sta()`, `ieee80211_ibss_add_sta()`, and `ieee80211_ibss_finish_sta()` (`__acquires(RCU)`) must be called without `rcu_read_lock()` held and always return with `rcu_read_lock()` acquired even on failure. [F221, F313, F470, F489, F685]
- `ieee80211_key_alloc()` returns an `ERR_PTR()` (never `NULL`), and unlinked keys must be freed via `ieee80211_key_free_unused()` (not `kfree_sensitive()`); `ieee80211_key_link()` consumes `key` and frees it on all non-zero error returns (and `ieee80211_add_key()` must convert `-EALREADY` to `0`). [F174, F511, F544]
- In `ieee80211_add_link_station()`, a link from `ieee80211_sta_allocate_link()` must be freed with `ieee80211_sta_free_link()` if `sta_link_apply_parameters()` fails, whereas `ieee80211_sta_activate_link()` consumes the link and frees it on `drv_change_sta_links()` failure. [F9, F473]
- `ieee80211_link_or_deflink()`, `ieee80211_new_chanctx()`, `ieee80211_replace_chanctx()`, and `ieee80211_determine_chan_mode()` return `ERR_PTR()` (`IS_ERR()`), whereas `ieee80211_find_chanctx()`, `ieee80211_find_reservation_chanctx()`, `ieee80211_alloc_chanctx()`, and `ieee802_11_parse_elems_full()` return `NULL`. When `link_id` can be `-1`, never index `sdata->link[link_id]`, `sta->link[link_id]`, or `BIT(link_id)` directly without `ieee80211_link_or_deflink()`, clamping `< 0` to `0`, or checking `link_id >= 0`. [F39, F42, F52, F81, F212, F378, F602, F635]
- `ieee80211_vif_cfg_change_notify()` only accepts `BSS_CHANGED_VIF_CFG_FLAGS`, `ieee80211_link_info_change_notify()` rejects `BSS_CHANGED_VIF_CFG_FLAGS`, and `ieee80211_bss_info_change_notify()` must only be called when `!ieee80211_vif_is_mld(&sdata->vif)`. `ieee80211_hw_config()` must never be called with `IEEE80211_CONF_CHANGE_{CHANNEL,POWER,SMPS}`. [F562, F563]
- `RX_QUEUED` (`SKB_NOT_DROPPED_YET`) must never be passed to `kfree_skb_reason()`; handlers in `ieee80211_rx_handlers()` must return `RX_QUEUED` whenever they free, enqueue, or deliver `rx->skb`, and return `RX_DROP` or a drop-reason code only when `rx->skb` remains unfreed. [F44, F371]

## Error Handling
- Non-standard return codes: `ieee80211_set_probe_resp()` returns `< 0` on error, `0` when installed, and `1` when absent; `drv_hw_scan()` returning `1` in `__ieee80211_start_scan()` triggers software-scan fallback (after clearing `hw_scan_req`, `scanning`, `scan_req`, and `scan_sdata` before `goto again`); `drv_suspend()` returning `1` in `__ieee80211_suspend()` requests cfg80211 disconnect (and any non-zero return must wake `IEEE80211_QUEUE_STOP_REASON_SUSPEND` queues); and `ieee80211_vif_use_reserved_switch()` returning `-EAGAIN` in `ieee80211_link_use_reserved_context()` is non-fatal. [F40, F43, F192, F329, F370, F435]
- When `sta_info_insert_drv_state()` fails on a non-IBSS vif, it must unwind prior `drv_sta_state()` transitions back down to `IEEE80211_STA_NOTEXIST`, and `sta_info_insert_finish()` must unhash `sta->deflink` and `sta`, remove `sta->list`, decrement `local->num_sta`, and call `synchronize_net()` before `cleanup_single_sta(sta)`. [F339, F340]

## External Contracts
- When `fips_enabled` is true, `drv_set_key()` must return `-EOPNOTSUPP`, `drv_set_rekey_data()` must be a no-op, `ieee80211_add_key()` must reject WEP and TKIP with `-EINVAL`, and `IEEE80211_HW_SW_CRYPTO_CONTROL` registration must be rejected. [F162, F578, F662]
- Before calling `IEEE80211_DEV_TO_SUB_IF(dev)` in netdev or inet/inet6 notifiers, verify `dev->ieee80211_ptr != NULL` and that its `wiphy` belongs to mac80211; in `ieee80211_ifa_changed()`, also check `wdev->registered` before `mutex_lock_nested(&local->hw.wiphy->mtx, 1)`. [F647, F674]

## Known Pitfalls
- In `rx.c`, cached pointers into `skb->data` (such as `hdr`) become invalid after cipher decrypt in `ieee80211_rx_h_decrypt()`, `skb_linearize()` in `ieee80211_rx_h_defragment()`, and `skb_copy()` in `ieee80211_prepare_and_rx_handle()` (which must also copy `skb_hwtstamps(skb)->hwtstamp`). In `ieee80211_add_rx_radiotap_header()` and `ieee80211_mesh_xmit_fast()`, data in `skb->data` must be saved before `skb_push()`/`memset()`/`memcpy()` overwrites it. [F391, F399, F501, F580]
- Avoid 32-bit shift/integer overflows: use `BIT_ULL()` on `u64` masks (`tid_ampdu_rx::reorder_buf_filtered`, `color_bitmap` in `ieee80211_rx_check_bss_color_collision()`, and `1ULL << id` with `id < 64` on `params->filter`), multiply `cfg80211_calculate_bitrate()` by `100000ULL` and cast `s8` `signal_avg`/`noise` to `(u8)` in `ieee80211_get_stats()`, and store `u16` link masks or `u64` changed flags into `unsigned long` / `BITMAP_FROM_U64()` before `for_each_set_bit()`. [F110, F111, F279, F440, F442, F639, F651]
- In `cfg80211_beacon_dup()`, `mbssid_ies` and `rnr_ies` are separate allocations that `ieee80211_free_next_beacon()` must `kfree()` before freeing `link->u.ap.next_beacon`, whereas `struct beacon_data` in `ieee80211_assign_beacon()` is a single allocation. In `__ieee80211_channel_switch()`, `ieee80211_color_change_abort()` must run before `ieee80211_set_csa_beacon()` overwrites `next_beacon`. [F7, F59]
- In `ieee80211_assoc_config_link()`, `ieee80211_determine_ap_chan()`, `ieee80211_add_link_elems()`, and `ieee80211_mgd_get_ap_ht_vht_capa()`, checks requiring or emitting VHT IEs when `conn.mode >= IEEE80211_CONN_MODE_VHT` must also check `is_5ghz` / `sband->vht_cap.vht_supported` and `band != NL80211_BAND_6GHZ`. [F272, F295]
- 16-bit fields at variable offsets in IEs and action frames must use `get_unaligned_le16()`, and when comparing `ssize_t` from `cfg80211_defragment_element()` against `sizeof()`, cast `sizeof()` to `ssize_t` or check `len < 0` first. In `ieee80211_rx_mgmt_beacon()`, `ieee80211_mgd_check_cross_link_csa()` defragments per-STA profiles in place inside `elems->ml_basic`, so `elems->ml_basic` must not be re-parsed afterwards. [F236, F254, F278, F420]
