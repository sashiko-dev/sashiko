# SPARC + UltraSPARC (sparc/sparc64)

This component implements core SPARC and UltraSPARC (`sparc32`/`sparc64`) architecture services in `arch/sparc/kernel/`, including Sun4v Machine Description (MDESC) DAG parsing and hotplug notifications, OpenBoot PROM (OBP) device tree building and address/IRQ translation, PCI host bridge/PBM controller drivers (Psycho, Sabre, Schizo/Tomatillo, Fire, Sun4v virtual PCI/IOMMU/ATU, and 32-bit PCIC) with MSI queue handling, performance counter (PCR) and pseudo-NMI watchdog support, ELF module relocation/instruction patching, and 32/64-bit process and thread lifecycle management.

## Architecture & Data Flow

- When a `struct dev_archdata` field (`iommu`, `stc`, `host_controller`, `numa_node`) is added or initialized for PCI devices, `pci_init_dev_archdata()`, `of_create_pci_dev()`, `of_propagate_archdata()` (for EBus children), and `pcibios_device_add()` (for SR-IOV VFs) must all propagate it in lockstep. [F75]
- In `pci_sun4v.c`, `iommu_batch_flush()` must advance `p->entry` by the number of pages mapped and reset `p->npages` to 0 after draining `p->pglist`, because `iommu_batch_new_entry()` checks `p->entry + p->npages == entry` for IOTSB contiguity; `iommu_batch_add()` and `iommu_batch_end()` assert `BUG_ON(p->npages >= PGLIST_NENTS)` (`PAGE_SIZE / sizeof(u64)`), so `iommu_batch_add()` must call `iommu_batch_flush()` whenever `p->npages == PGLIST_NENTS`; and when `vpci_major < 2`, `iommu_batch_flush()` must mask protection flags to `HV_PCI_MAP_ATTR_READ | HV_PCI_MAP_ATTR_WRITE`. [F61, F84, F136]
- In `pci_sun4v_pbm_init()`, `pci_sun4v_atu_init()` must run after `pci_sun4v_scan_bus()` because `pci_sun4v_atu_alloc_iotsb()` calls `dma_4v_iotsb_bind()` to iterate over `pbm->pci_bus->devices`. In `dma_4v_map_page()` and `dma_4v_unmap_page()`, `npages` must be computed as `(IO_PAGE_ALIGN(addr + sz) - (addr & IO_PAGE_MASK)) >> IO_PAGE_SHIFT` before masking `addr` to `IO_PAGE_MASK`. [F118, F131]
- In `pci_msi.c`, hardware MSI numbers and queue IDs are offset by `pbm->msi_first` and `pbm->msiq_first`, whereas `pbm->msi_bitmap`, `pbm->msi_irq_table`, and `pbm->msiq_irq_cookies` are 0-based arrays of size `pbm->msi_num` and `pbm->msiq_num`, so all accesses must subtract or add `msi_first`/`msiq_first`. In `sparc64_teardown_msi_irq()`, `pbm->msi_irq_table[i]` must be cleared to `~0U` and `pbm->msi_ops->msi_teardown()` must succeed before `free_msi()` clears the bit in `pbm->msi_bitmap`. [F60, F82]
- Controller-level error handlers `psycho_ue_intr()` and `schizo_check_iommu_error()` must inspect both `pbm` and `pbm->sibling` (when non-NULL). In `psycho_pbm_strbuf_init()` and `schizo_pbm_strbuf_init()`, `pbm->stc.strbuf_flushflag` must be 64-byte aligned within `pbm->stc.__flushflag_buf` with `strbuf_flushflag_pa = __pa(pbm->stc.strbuf_flushflag)`. On Tomatillo (`PBM_CHIP_TYPE_TOMATILLO`), `pbm->stc` pointers are uninitialized (`pbm->stc.strbuf_enabled == 0`), so `pbm->stc.strbuf_enabled` must be checked before calling `__schizo_check_stc_error_pbm()`. [F52, F67, F158]
- In `of_device_32.c` and `of_device_64.c`, `of_bus_pci_match()` must return `0` when a PCI node lacks `"ranges"` (or has model `"SUNW,simba"` on 64-bit) so `of_match_bus()` does not select `of_bus_pci_map()`. In 64-bit `build_device_resources()` and `scan_one_device()`, `num_reg` and `op->archdata.num_irqs` must be clamped to `PROMREG_MAX` and `PROMINTR_MAX`, and `of_address_to_resource()`, `of_iomap()`, and `irq_of_parse_and_map()` must reject indices `>=` those counts. [F87, F92]
-In `nmi.c`, `nmi_active` is `> 0` for active CPUs, `0` when disabled, and `-1` when permanently unusable (`nmi_init()`/`check_nmi_watchdog()` failure must set `-1`). Every transition of per-CPU `wd_enabled` between 0 and 1 in `start_nmi_watchdog()`, `stop_nmi_watchdog()`, and `report_broken_nmi()` must be paired with an atomic increment or decrement of `nmi_active` (unless forced to `-1` after stopping all CPUs). [F54, F59]
- In `process_64.c`, `t->reg_window[]`, `t->rwbuf_stkptrs[]`, and `wsaved` must be updated in lockstep: `synchronize_user_stack()` must shift both arrays down via `shift_window_buffer()` and decrement `wsaved` on each copied window, and `fault_in_user_windows()` must set `wsaved = window + 1` if `copy_to_user()` fails. Also, `copy_thread()` and `clone_stackframe()` must mask `sp`, `regs->u_regs[UREG_FP]`, and `fp + STACK_BIAS` with `0xffffffffUL` when `TIF_32BIT` is set. [F65, F108]
- In `record_one_cpu()` (`prom_64.c`), `set_cpu_possible(cpuid, true)` must be guarded by `num_possible_cpus() < nr_cpu_ids` rather than `cpuid < nr_cpu_ids` because physical CPU IDs can be sparse. When `!CONFIG_SMP`, `fill_in_one_cpu()` in `mdesc.c` and `prom_64.c` must skip any CPU with `cpuid != real_hard_smp_processor_id()` and reset `cpuid = 0` before indexing `cpu_data(cpuid)` or `trap_block[cpuid]`. [F77, F78]

## Synchronization

- In `mdesc.c`, `mdesc_mutex` must be held across `client_list` registration and `client->add` calls in `mdesc_register_notifier()`, and across the entire `mdesc_update()` sequence; `mdesc_lock` must be acquired via `spin_lock_irqsave()` around `cur_mdesc`, `hp->refcnt`, and `mdesc_zombie_list` updates, and `mdesc_update()` must drop `mdesc_lock` before calling `mdesc_notify_clients(orig_hp, hp)` (which allocates with `GFP_KERNEL`) while keeping `orig_hp->refcnt` pinned until `mdesc_lock` is reacquired. [F19, F20, F152]
- In `pci_sun4v.c`, `per_cpu(iommu_batch, i).pglist` must be allocated for all possible CPUs in `pci_sun4v_probe()` before `pci_sun4v_pbm_init()` scans the bus, and local interrupts must be disabled via `local_irq_save()` across the entire `iommu_batch_start()`, `iommu_batch_new_entry()`, `iommu_batch_add()`, `iommu_batch_flush()`, and `iommu_batch_end()` sequence. [F22, F23]
- In `process_64.c`, `arch_trigger_cpumask_backtrace()` and `pmu_snapshot_all_cpus()` must hold `global_cpu_snapshot_lock` via `spin_lock_irqsave()` and zero the shared `global_cpu_snapshot` union before issuing cross-calls; in `__global_reg_self()`, `rp->thread = tp` must be written last because `__global_reg_poll()` polls `gp->thread` with a bounded 100-iteration loop without further locking. [F26, F104]
- In `pcr_arch_init()`, `register_perf_hsvc()` and `pcr_ops` setup must complete before calling `nmi_init()`. In `nmi.c`, `nmi_init_done` is set only at the end of `nmi_init()`, `watchdog_hardlockup_enable()` must verify both `atomic_read(&nmi_active) != -1` and `nmi_init_done`, and `stop_nmi_watchdog()` must clear per-CPU `wd_enabled` in addition to calling `pcr_ops->pcr_nmi_disable` because `perfctr_irq()` re-arms PCR NMI whenever `__this_cpu_read(wd_enabled)` is non-zero. [F28, F29, F30]
- `perfctr_irq()` (`nmi.c`) runs at PIL 15 (above PIL 14 IRQ-off), so it must execute inside `nmi_enter()`/`nmi_exit()` on the hardirq stack (`set_hardirq_stack()`/`restore_hardirq_stack()`) and defer work requiring IRQ-safe locks to `deferred_pcr_work_irq()` at `PIL_DEFERRED_PCR_WORK` via `arch_irq_work_raise()`. [F150]
- In `schizo_check_iommu_error_pbm()` and `__schizo_check_stc_error_pbm()` (and `psycho_check_stc_error()`), `spin_lock_irqsave(&iommu->lock, flags)` must be held outside `spin_lock(&stc_buf_lock)`, and while `SCHIZO_STRBUF_CTRL_DENAB` or `PSYCHO_STRBUF_CTRL_DENAB` is set, all 128 error status entries and all 16 tag and line entries must be cleared to `0UL` before restoring `strbuf_control`. In `psycho_scan_bus()`, `sabre_scan_bus()`, and `schizo_scan_bus()`, `pbm->pci_bus` must be initialized by `pci_scan_one_pbm()` before registering PCI error interrupt handlers. [F32, F143, F157]
- In `arch_cpu_idle()` (`process_64.c`), on sun4v (`tlb_type == hypervisor`), `PSTATE_IE` must be cleared in `%pstate` across the `need_resched()`/`cpu_is_offline()` check and `sun4v_cpu_yield()`, and `scheduler_poke()` must be called after `sun4v_cpu_yield()` before restoring `PSTATE_IE`. [F148]

## Object Lifetimes

- Pointers returned by `mdesc_get_property()` and `mdesc_node_name()` point into `struct mdesc_handle` and are only valid between `mdesc_grab()` and `mdesc_release()`, so callers retaining them past `mdesc_release()` must copy the data. `mdesc_open()` must store `mdesc_grab()` in `file->private_data` (releasing via `mdesc_release()` in `mdesc_close()`) rather than reading `cur_mdesc` directly in `mdesc_read()`/`mdesc_llseek()`. [F1, F170]
- Both `mdesc_memblock_free()` and `mdesc_kfree()` enforce `BUG_ON(refcount_read(&hp->refcnt) != 0)` and `BUG_ON(!list_empty(&hp->list))`; in `mdesc_update()`, a newly allocated `hp` on error must have `hp->refcnt` decremented to 0 before `mdesc_free(hp)`, and `orig_hp` must only be freed via `mdesc_free()` if `refcount_dec_and_test(&orig_hp->refcnt)` succeeds under `mdesc_lock` (otherwise queued on `mdesc_zombie_list` for `mdesc_release()`). [F2, F135]
- When `pci_sun4v_atu_init(pbm)` fails in `pci_sun4v_pbm_init()`, `pbm->iommu->atu` must be both freed with `kfree()` and reset to `NULL` so `iommu_use_atu(iommu, mask)` falls back to `&iommu->tbl`. [F9]
- In 64-bit `copy_thread()` (`process_64.c`), `t->utraps[0]` must only be incremented after all fallible steps (`clone_stackframe()`) succeed, and `exit_thread()` must decrement `t->utraps[0]` when `>= 2` and call `kfree(t->utraps)` only when `< 2`. On 32-bit `!CONFIG_SMP` (`process_32.c`), when `exit_thread()` or `flush_thread()` saves FPU state for `last_task_used_math`, it must clear `last_task_used_math = NULL`. [F16, F17]
- In `of_set_property()` (`prom_common.c`), `kmemdup(val, len, GFP_KERNEL)` must precede lock acquisition, `of_set_property_mutex` must be acquired outside `raw_spin_lock_irqsave(&devtree_lock, flags)`, and when replacing `prop->value`, `kfree(old_val)` must be called only if `OF_IS_DYNAMIC(prop)` is true, followed by `OF_MARK_DYNAMIC(prop)`. [F71, F154]

## API Contracts

- In `mdesc.c`, `handle_size` must be `sizeof(struct mdesc_handle) - sizeof(struct mdesc_hdr) + mdesc_size` because `mdesc_size` includes the embedded `struct mdesc_hdr`; `&hp->mdesc` must be 16-byte aligned (`BUG_ON(((unsigned long)&hp->mdesc) & (16UL - 1))`), so `mdesc_kmalloc()` over-allocates by 15 bytes and saves the unaligned base in `hp->self_base` for `kfree(hp->self_base)` in `mdesc_kfree()`; and `sun4v_mach_desc(__pa(&hp->mdesc), len, &real_len)` callers must check both `status != HV_EOK` and `real_len > len`. [F48, F79, F121]
- In `of_device_64.c`, `of_ioremap()` reserves the range via `request_mem_region()` or `request_region()` according to `res->flags & IORESOURCE_MEM` and returns `res->start + offset`, so callers must unmap via `of_iounmap()` with the matching `struct resource *` and `size` rather than `iounmap()`. [F6]
- In `pci_sun4v.c`, `pci_sun4v_iommu_map()` returns a signed `long` (positive mapped page count or `< 0` negated HV status), whereas `pci_sun4v_iotsb_map()` returns an unsigned status (`HV_EOK` on success) and writes the count to `*mapped`. `iommu_tbl_range_alloc()` returns `IOMMU_ERROR_CODE` (`~(unsigned long)0`) on failure (`0` is a valid index), and passing `IOMMU_ERROR_CODE` to `iommu_tbl_range_free()` derives the index from `dma_addr`. [F39, F40]
- In `pci_sun4v.c`, when `dma_4v_map_sg()` merges segments such that `outcount < incount`, it must set `sg_next(outs)->dma_length = 0` so `dma_4v_unmap_sg()` stops at the sentinel; and DMA unmap/free paths (`dma_4v_free_coherent()`, `dma_4v_unmap_page()`, `dma_4v_unmap_sg()`, `dma_4v_iommu_demap()`) must choose between `&iommu->tbl` and `&atu->tbl` by testing whether the mapped DMA address exceeds `DMA_BIT_MASK(32)`, not by reading `dev->dma_mask`. [F176, F177]
- For `sparc64_msiq_ops`: `msiq_build_irq` (`pci_sun4v_msiq_build_irq`, `pci_fire_msiq_build_irq`) must convert a `0` return from `sun4v_build_irq()`/`build_irq()` into `-ENOMEM` because `bringup_one_msi_queue()` checks `irq < 0`; `dequeue_msi` must return `0` when the entry at `*head` has a zero type field, `< 0` on error, or clear the type field, advance `*head` modulo queue size, and return `1` on success; and `*head` is a byte offset scaled by `sizeof(struct pci_sun4v_msiq_entry)` in `pci_sun4v_dequeue_msi()` but an entry index in `pci_fire_dequeue_msi()`. [F42, F45, F103, F123]
- `pcr_ops` is `NULL` when `pcr_arch_init()` fails (e.g., Spitfire CPUs), and `pcr_ops->read_pcr(reg_num)`/`read_pic(reg_num)` only accept `reg_num != 0` (`0..3`) when `tlb_type == hypervisor && sun4v_chip_type >= SUN4V_CHIP_NIAGARA4`. Callers of `nmi_adjust_hz(new_hz)` must pass a non-zero `new_hz < (1U << 30)` so `nmi_hz` and `nmi_hz << 2` divisors in `pcr_ops->nmi_picl_value()` are non-zero. [F55, F116]

## Error Handling

- In `dma_4v_alloc_coherent()`, `dma_4v_map_page()`, and `dma_4v_map_sg()` (`pci_sun4v.c`), any failure after `local_irq_save(flags)` and `iommu_tbl_range_alloc()` must call `local_irq_restore(flags)` and `iommu_tbl_range_free()`; in `dma_4v_map_sg()`, `dev->archdata.iommu` and `nelems` must be validated before dereferencing `iommu->atu`, selecting `iommu->atu` for masks above 32 bits must use `iommu_use_atu(iommu, mask)`, and `outs->dma_length` must be initialized to 0 and only set after allocation and `iommu_batch_add()` succeed so `iommu_map_failed` rollback only frees mapped segments. [F7, F8, F37, F38]
- In `sparc64_pbm_msi_init()`, failure in `msi_bitmap_alloc()`, `msi_table_alloc()`, `ops->msiq_alloc()`, or `sparc64_bringup_msi_queues()` must unwind prior allocations in reverse order, reset `pbm->msiq_num = 0`, and leave `pbm->setup_msi_irq = NULL`. In `sparc64_setup_msi_irq()`, failure after `irq_alloc()` and `alloc_msi()` must call `free_msi(pbm, msi)`, `irq_set_chip(*irq_p, NULL)`, `irq_free(*irq_p)`, and reset `*irq_p = 0`. [F10, F133]
- In `pcr_arch_init()`, if `setup_sun4v_pcr_ops()` fails or `tlb_type` is unsupported after `register_perf_hsvc()` succeeds, the error path must call `unregister_perf_hsvc()`. In `mdesc.c`, `md_node_ops.rel_info` callbacks (such as `rel_vdev_port_node_info()`) must reset freed pointer fields in `union md_node_info` to `NULL` so repeated calls in `mdesc_get_node()` are idempotent. [F14, F47]

## Known Pitfalls

- In `mdesc.c`, node and arc indices are 0-based indices into `node_block(&hp->mdesc)` in 16-byte `struct mdesc_elem` units with exclusive bound `last_node = hp->mdesc.node_sz / 16` and sentinel `MDESC_NODE_NULL` (`~(u64)0`), whereas `mdesc->node_sz`, `mdesc->name_sz`, `ep->name_offset`, and `ep->d.data.data_offset` are byte offsets added to `void *`/`char *` pointers; and inside `mdesc_for_each_arc(arc, hdl, node, type)`, the loop cursor `arc` must never be overwritten with `mdesc_arc_target(hdl, arc)`. [F80, F102, F122]
- In `apply_relocate_add()` (`module.c`), the relocation type switch must mask `ELF_R_TYPE(rel[i].r_info)` with `& 0xff` because 64-bit `R_SPARC_OLO10` packs a secondary addend into the upper 24 bits; `R_SPARC_32`, `R_SPARC_UA32`, `R_SPARC_64`, and `R_SPARC_UA64` must be written byte-by-byte in big-endian order through `u8 *location` rather than dereferencing `u32 *`/`u64 *`; and on `CONFIG_SPARC64`, `location` must fit in 32 bits (`((u64)location >> 32) == 0`). [F85, F95]
- In `of_scan_pci_bridge()` (`pci.c`), 8-cell (`32`-byte) OF `ranges` entries with `size >> 32 == 0xffffffff` must be skipped to avoid overflowing `region.start + size - 1` on empty PCIe bridges. In `pci_parse_of_flags()`, `addr0 & 0x02000000` must be tested before `else if (addr0 & 0x01000000)` because 64-bit memory space sets `0x03000000` (using `addr0 & 0x01000000` inside the `0x02000000` branch for `IORESOURCE_MEM_64`, which populates `pbm->mem64_space`). [F90, F93, F139]
- In `build_one_device_irq()`, after walking `dp` and `pp` up the OF tree to find the IRQ translator `ip`, `ip->irq_trans->irq_build` must be called with `op->dev.of_node` (the original child node) rather than `dp` or `ip`. In `build_device_resources()`, each upward step must call `of_match_bus(pp)`, `pbus->count_cells(dp, ...)`, and `build_one_resource(dp, dbus, pbus, addr, dna, dns, pna)` before updating `dna = pna; dns = pns; dbus = pbus;`. [F105, F106]
