# INFINIBAND SUBSYSTEM

The InfiniBand and RDMA subsystem headers define the kernel Verbs API, device and driver operation tables (`struct ib_device_ops`), resource tracking (`restrack`), user-space verbs ioctl/write parsing (`uverbs`), user memory registration (`ib_umem`, ODP, dmabuf), protocol wire formats, connection and datagram management (`rdma_cm`, `ib_cm`, `iw_cm`, `ib_mad`, `ib_sa`), and the software RDMA Verbs Transport library (`rdmavt`).

## Architecture & Data Flow

- `struct ib_umem` may be a base allocation, `struct ib_umem_odp`, or `struct ib_umem_dmabuf`: check `umem->is_odp` before `to_ib_umem_odp()`, `umem->is_dmabuf` before `to_ib_umem_dmabuf()`, and `!umem_odp->is_implicit_odp` before `ib_umem_odp_map_dma_and_lock()`. In `ib_umem_odp`, `notifier.interval_tree.last` is inclusive while `ib_umem_end(umem_odp)` is exclusive (`last + 1`), so range lengths and `ib_umem_odp_num_pages()` must subtract `ib_umem_start()` from `ib_umem_end()`. [F47, F77]
- In `struct ib_umem`, `umem->sgt_append.sgt.orig_nents` counts scatterlist entries populated with pages (for `ib_umem_copy_from()` and unpinning), whereas `sgt.nents` holds the DMA-mapped segment count from `ib_dma_map_sgtable_attrs()` (for `__rdma_umem_block_iter_start()`). `ib_umem_num_dma_blocks()` must align `umem->iova + umem->length` up and `umem->iova` down to `pgsz` in `u64` and cast their difference to `size_t` before dividing by `pgsz`. [F60, F104]
- Non-init net namespaces use standalone `struct ib_core_device` instances in `ib_device->compat_devs`, and `struct device dev` must remain the first member of `struct ib_core_device`. Sysfs callbacks reachable in non-init namespaces must obtain `struct ib_device *` via `rdma_device_to_ibdev(dev)` rather than `container_of(dev, struct ib_device, dev)`. [F50, F114]
- In `rvt_update_sge()`, advance `sge->vaddr`, `sge->length`, and `sge->sge_length` by at most `rvt_get_sge_length(sge, length)`. When `sge->sge_length == 0`, call `rvt_put_mr(sge->mr)` if `release` is true and copy `*ss->sg_list++` into `ss->sge` if `--ss->num_sge` is non-zero. When `sge->length == 0` while `sge->sge_length > 0`, reload from `sge->mr->map[sge->m]->segs[sge->n]` only if `sge->mr->lkey != 0` (`dma_mr` has `mapsz == 0`), wrapping `sge->n` at `RVT_SEGSZ`. [F56, F57]
- On `struct rvt_qp`, update `qp->log_pmtu = ilog2(qp->pmtu)` when `qp->pmtu` changes, update `qp->timeout_jiffies = rvt_timeout_to_jiffies(qp->timeout)` when `qp->timeout` changes, and set `RVT_S_TIMER` in `qp->s_flags` under `qp->s_lock` in `rvt_mod_retry_timer_ext()`. Compute `struct rvt_rq` counts via `rvt_get_rq_count()` (`if ((s32)count < 0) count += rq->size;`) and wrap send WQE indices at `qp->s_size` via `rvt_qp_swqe_incr()`. [F58, F78]
- `ib_update_fast_reg_key()` must update the lower 8 user-key bits of both `mr->lkey` and `mr->rkey` in lockstep while preserving the upper 24 driver-owned bits (`0xffffff00`); `rvt_fast_reg_mr()` rejects keys whose upper 24 bits differ from `mr->mr.lkey` and synchronizes `mr->mr.lkey`, `ibmr->lkey`, and `ibmr->rkey`. [F70]
- `struct ib_port_attr.port_cap_flags` must only store IBA PortInfo `CapabilityMask` bits; set RoCE IP-based GID support in `ib_port_attr.ip_gids`. `rdma_cap_roce_gid_table()` requires `rdma_protocol_roce()` and both `ib_device_ops.add_gid` and `del_gid` (`query_gid` is unused on RoCE). [F65, F139]
- 64-bit fields in `__packed` IB wire structs (`ib_reth`, `ib_atomic_eth`, `ib_ehdrs.at`, `ib_sa_hdr`, `ib_sa_mad`) are only 4-byte aligned; keep those structs `__packed` and access their `__be64` fields via `ib_u64_get`/`put`, `get`/`put_ib_reth_vaddr`, `get`/`put_ib_ateth_*`, or `_iba_get64`/`_iba_set64`. [F82]

## Synchronization

- `ib_umem_odp_map_dma_and_lock()` acquires `umem_odp->umem_mutex` and returns with it locked only when its return value is `>= 0` (including `0` pages mapped); on `< 0` `umem_mutex` is not held, and callers of `ib_umem_odp_unmap_dma_pages()` must hold `umem_odp->umem_mutex`. [F11]
- In `struct ib_uverbs_file`, accessing `uobjects` requires holding `hw_destroy_rwsem` for write, or holding both `hw_destroy_rwsem` for read and `uobjects_lock`; hold `hw_destroy_rwsem` across any `ib_uobject` HW destruction, and access `ufile->ucontext` only via `ib_uverbs_get_ucontext_file()` or under `ufile->ucontext_lock`. [F25, F26]
- In `rvt_qp_complete_swqe()`, `rvt_qp_wqe_unreserve()`, `rvt_put_qp_swqe()`, and reading `wqe->wr.wr_id` and `wqe->length` must complete before `smp_store_release(&qp->s_last, last)`, because advancing `qp->s_last` immediately allows `rvt_qp_is_avail()` on the post-send path to overwrite `*wqe`. [F55]
- In `rdmavt`, `rvt_mod_retry_timer*`, `rvt_add_retry_timer*`, `rvt_add_rnr_timer`, `rvt_stop_rc_timers`, `rvt_rc_credit_avail`, and `rvt_driver_provided.schedule_send` require holding `qp->s_lock` with IRQs disabled, whereas `schedule_send_no_lock` must be called without `qp->s_lock` and `rvt_del_timers_sync()` must be called without `qp->r_lock`, `qp->s_hlock`, or `qp->s_lock`. [F30, F145, F146]
- In `struct rvt_driver_provided`, `flush_qp_waiters` and `notify_qp_reset` run with `qp->r_lock`, `qp->s_hlock`, and `qp->s_lock` held (and must not sleep), whereas `stop_send_queue` and `quiesce_qp` run after those spinlocks are dropped; invoke `qp_priv_init` only after all `struct rvt_qp` fields are initialized. Access user-mmap'ed `rvt_cq_wc` and `rvt_rwq` `head`/`tail` via `RDMA_READ_UAPI_ATOMIC` and `RDMA_WRITE_UAPI_ATOMIC`. [F20, F126, F153]
- Inside an `rdma_cm_event_handler` callback (where the `rdma_cm_id` handler mutex is already held), call `rdma_connect_locked()` instead of `rdma_connect()`. Never hold `device->client_data_rwsem` across `ib_client->remove()` callbacks (use `ib_client.uses` and `uses_zero`). [F31, F33]
- `ib_dispatch_event()` must update `device->port_data[port].cache` via `ib_cache_event_task()` before notifying `event_handler_list` on port/LID/PKey/GID/client-reregister events. `ib_cq` `wr_cqe->done` handlers must not sleep under `IB_POLL_SOFTIRQ`. Hold `rcu_read_lock()` across `rdma_read_gid_attr_ndev_rcu()` and all uses of the returned `net_device *`. [F63, F143, F151]

## Object Lifetimes

- Callers of `uobj_get_destroy()` or `rdma_assign_uobject()` must release the `struct ib_uobject` via `uobj_put_destroy()` (`UVERBS_LOOKUP_DESTROY`) rather than `uobj_put_write()`, keeping `uobj->usecnt` write-locked after IDR removal so concurrent RCU lookups cannot double-destroy it. [F1]
- In `struct uverbs_obj_type_class`, `alloc_commit` (`rdma_alloc_commit_uobject()`) consumes the caller's `kref` on `struct ib_uobject`, whereas `alloc_abort` and `destroy_hw` do not (`rdma_alloc_abort_uobject()` drops it after `alloc_abort`); once a `write()` handler calls `uobj_finalize_uobj_create()`, the uverbs core owns committing or aborting `uobj`, so never call `uobj_alloc_abort()` afterwards. [F2, F4]
- Memory from `_uverbs_alloc()`, `uverbs_alloc()`, `uverbs_zalloc()`, or `uverbs_kcalloc()` is owned by `struct uverbs_attr_bundle`, freed when the syscall ends, and returns `ERR_PTR()` on failure (never `NULL`); check `IS_ERR(ptr)` and never `kfree()` or persist it. [F16]
- `ib_set_flow()` increments `qp->usecnt` (if `qp` is non-NULL) and transfers ownership of `struct ib_uflow_resources *uflow_res` into `uflow->resources`; do not call `ib_uverbs_flow_resources_free(uflow_res)` on error paths after `ib_set_flow()`, and decrement `ibflow->qp->usecnt` on flow destruction. [F5]
- Each active SGE in `struct rvt_sge_state` holds a `percpu_ref` on `sge->mr` (`rvt_get_mr()`), which must be dropped via `release == true` in `rvt_update_sge()` / `rvt_skip_sge()` or via `rvt_put_ss()` before resetting `ss`. Never call `rvt_free_rq()` after `rvt_create_mmap_info()` wraps `rq->wq` in `ip->obj` (which `ip->ref` frees). [F7, F8]
- `ib_init_ah_attr_from_wc()` and `rdma_move_grh_sgid_attr()` populate `ah_attr->grh.sgid_attr` with a held reference that must be released via `rdma_destroy_ah_attr()` (or `rdma_replace_ah_attr()` / `rdma_move_ah_attr()`); `rdma_ah_set_grh()` overwrites `grh->sgid_attr = NULL` without putting it, so never call `rdma_ah_set_grh()` or `rdma_copy_ah_attr()` on an initialized `rdma_ah_attr` without destroying it first. [F9]
- `struct ib_umem` accounts pinned memory against `umem->owning_mm` rather than `current`'s PID or `current->mm`, and `ib_umem_release()` releases standard, `is_dmabuf`, and `is_odp` regions. Drop `rdma_user_mmap_entry_get*()` refs with `rdma_user_mmap_entry_put()`, remove entries with `rdma_user_mmap_entry_remove()`, and `kfree()` them only in `ib_device_ops::mmap_free`. Free `ib_mad_recv_wc` via `ib_free_recv_mad()` and `ib_create_send_mad()` buffers via `ib_free_send_mad()`. [F10, F15, F19]
- When `ib_device_ops.dealloc_driver` is set, `ib_unregister_device*()` and `ib_unregister_driver()` call `ib_dealloc_device()` automatically, so drivers must only call `ib_dealloc_device()` on error unwind before `ib_register_device()` succeeds; drivers using `ib_unregister_device_queued()` must set `dealloc_driver` and call `ib_unregister_driver()` before module unload. [F122, F123]
- For core-allocated objects (`ib_pd`, `ib_cq`, `ib_qp`, `ib_srq`, `ib_ah`, `ib_mw`, `ib_dmah`, `ib_ucontext`, `ib_xrcd`, `ib_rwq_ind_table`, `ib_counters`, `rdma_counter`), drivers must register sizes via `INIT_RDMA_OBJ_SIZE(ib_struct, drv_struct, member)` with `member` at offset 0, and must neither allocate nor `kfree()` `drv_struct`. [F113, F129, F167]
- `ib_device_ops::get_netdev` and `ib_client::get_net_dev_by_params` must call `dev_hold()` on the returned `net_device *` (caller calls `dev_put()`), and `get_netdev` must return `NULL` before `NETDEV_UNREGISTER` completes; never call `ib_get_client_data()` after `ib_client->remove()` returns. [F13, F128]

## API Contracts

- Event callbacks (`rdma_cm_event_handler`, `ib_cm_handler`, `ib_sa_multicast.callback`, and `ib_qp_init_attr.event_handler`) must never call the synchronous destroy function (`rdma_destroy_id`, `ib_destroy_cm_id`, `ib_sa_free_multicast`, or `ib_destroy_qp`/`ib_close_qp`) on the passed-in object from within the callback. [F32]
- Unlike `uverbs_attr_get*()` which return `ERR_PTR(-ENOENT)` when absent, `uverbs_attr_get_uobjs_arr()` catches `IS_ERR(attr)`, sets `*arr = NULL`, and returns `0`; use `uverbs_attr_ptr_get_array_size()` and `uverbs_kcalloc()` on user array attributes. Read extensible `UVERBS_ATTR_STRUCT()` attributes with `uverbs_copy_from_or_zero()`. [F38, F39, F73]
- `rdma_udata_to_drv_context()` returns `NULL` when `udata` is `NULL`; callbacks reachable from both kernel and user paths must check `if (udata)` (not `ucontext`) before dereferencing `udata` or the driver context, and must never pass a standalone stack `struct ib_udata` to `rdma_udata_to_drv_context()` or `rdma_udata_to_uverbs_attr_bundle()`. [F42, F117]
- `ib_req_notify_cq()` requires `IB_CQ_SOLICITED` or `IB_CQ_NEXT_COMP` in `flags` and returns `< 0` on error, `0` on success, and `> 0` (when `IB_CQ_REPORT_MISSED_EVENTS` is set) to require re-polling `ib_poll_cq()` rather than treating `> 0` as an error. [F44]
- Set `rdma_ah_attr.type` (e.g., via `rdma_ah_find_type()`) before calling `rdma_ah_set_dlid()`, `rdma_ah_set_path_bits()`, `rdma_ah_set_make_grd()`, or `rdma_ah_retrieve_dmac()`. Omit `RDMA_CREATE_AH_SLEEPABLE` and `RDMA_DESTROY_AH_SLEEPABLE` in atomic contexts, and `create_ah`/`destroy_ah` callbacks must not sleep when those flags are absent. [F48, F142]
- `ib_device->port_data[]` is indexed by `rdma_start_port(dev)..rdma_end_port(dev)` (`0` on switches, `1..phys_port_cnt` on CAs; iterate with `rdma_for_each_port()`), whereas `rdmavt`'s `rdi->ports[]` is 0-indexed (`0..nports - 1`) and requires `rdi->ports[qp->port_num - 1]` (`rvt_to_iport(qp)`). [F51]
- Preset `dev_addr->net` before `rdma_translate_ip()` / `rdma_resolve_ip()`; preset `qp_attr->qp_state` before `ib_cm_init_qp_attr()` / `rdma_init_qp_attr()`; pass `>= sizeof(struct sockaddr_in6)` bytes to `rdma_gid2ip()`. Call `rdma_restrack_no_track()` on objects without a unique HW ID at `rdma_restrack_add()` time; implement `ib_client.rename` if deriving sysfs names from `ibdev->name`. [F53, F54, F62, F64, F110]
- Use `ib_dma_*` wrappers instead of `ib_device.dma_device` directly (and only map lowmem direct-mapped pages, never `vmalloc`/highmem, due to `ib_uses_virt_dma()`), and use `ib_pd->local_dma_lkey` rather than checking `IBK_LOCAL_DMA_LKEY`. Check `CAP_NET_RAW` via `rdma_uattrs_has_raw_cap()` or `rdma_dev_has_raw_cap()`, and compare `rdmavt` 24-bit MSNs via `rvt_cmp_msn(a, b)`. [F106, F133, F136, F155, F162]

## Error Handling

- In `struct uverbs_obj_idr_type`, if `destroy_object` fails during `RDMA_REMOVE_DESTROY`, it must leave the `struct ib_uobject`, sibling `usecnt` counters, and driver state completely unchanged. [F3]
- Store the return value of `uverbs_attr_get_len()` and `uverbs_attr_ptr_get_array_size()` in a signed `int` or `ssize_t` (never `size_t` or `u32`) before testing `< 0` or `<= 0`. Check `IS_UVERBS_COPY_ERR(ret)` rather than `if (ret)` after `uverbs_copy_to*()` on optional (`UA_OPTIONAL`) output attributes, which return `-ENOENT` when omitted. [F37, F40]
- User-object teardown must call and propagate the `int` return of `ib_dealloc_pd_user()`, `rdma_destroy_ah_user()`, `ib_destroy_srq_user()`, `ib_destroy_cq_user()`, `ib_destroy_wq_user()`, and `ib_dealloc_xrcd_user()`; the non-`_user` variants are for kernel objects only. Check `IS_ERR(qp->priv)` (not `!qp->priv` or `IS_ERR_OR_NULL()`) after `rvt_driver_provided.qp_priv_alloc()`. [F43, F52]

## External Contracts

- In kernel enums that cross the UAPI boundary (`enum ib_wr_opcode`, `enum ib_wc_opcode`, `enum ib_qp_type`, `enum ib_qp_create_flags`, `enum ib_srq_type`), shared enumerators must be explicitly assigned to `IB_UVERBS_*` constants and kernel-only enumerators placed at non-overlapping values. Set `IB_TM_CAP_RNDV_RC` in `ib_tm_caps.flags` only when hardware/firmware support both base tag matching and RC rendezvous offload. [F84, F135]

## Known Pitfalls

- `uverbs_get_const*()` overwrites `*(_to)` with an uninitialized local `_val` when the attribute is absent (`-ENOENT`); always check the return value or use `uverbs_get_const_default()`. `uverbs_copy_from*()` uses `sizeof(*to)` as destination length, so use `_uverbs_copy_from*()` with an explicit byte count when `to` is a `void *`, array pointer, or dynamic buffer. [F41, F107]
- Never index `qp->s_wq[n]` or `rq->kwq->curr_wq[n]` directly because `struct rvt_swqe` and `struct rvt_rwqe` have runtime-sized trailing SGE arrays; use `rvt_get_swqe_ptr(qp, n)` and `rvt_get_rwqe_ptr(rq, n)`. Verify `wr->opcode` (or QP type for `ud_wr`) before calling `rdma_wr()`, `atomic_wr()`, `ud_wr()`, or `reg_wr()`. [F79, F116]
- `sa_convert_path_opa_to_ib()` and `sa_convert_path_ib_to_opa()` require distinct `dest` and `src` pointers and a matching `src->rec_type`. `rdma_core_cap_opa_port()` must test `(core_cap_flags & RDMA_CORE_PORT_INTEL_OPA) == RDMA_CORE_PORT_INTEL_OPA`. Convert `__be16` `IB_MULTICAST_LID_BASE` with `be16_to_cpu()` (never `be32_to_cpu()`) and only pass 16-bit LIDs to `ib_lid_cpu16()` / `ib_lid_be16()`. [F68, F83, F89]
