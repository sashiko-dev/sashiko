# USB NETWORKING DRIVERS

This unit contains `usbnet`-based USB Ethernet minidrivers (`aqc111`, `asix`, `ax88179_178a`, `ch9200`, `cx82310_eth`, `gl620a`, `huawei_cdc_ncm`, `int51x1`, `kalmia`, `lg-vl600`, `mcs7830`, `net1080`, `smsc95xx`, `sr9700`, `sr9800`, `zaurus`) and standalone USB network drivers (`catc`, `cdc-phonet`, `ipheth`, `kaweth`, `pegasus`), bridging the Linux network stack with USB pipes, PHYs, and packet aggregation.

## Architecture & Data Flow

- Private structs overlaid onto `struct usbnet::data` (`unsigned long data[5]`)—`struct asix_data`, `struct mcs7830_data`, `struct sr_data`, and `struct huawei_cdc_ncm_state`—must not exceed `sizeof(unsigned long[5])` (20 bytes on 32-bit); `sr_set_multicast()` and `sr_set_mac_address()` must pass persistent `sr_data` buffers (`multi_filter`, `mac_addr`) to async control writes, and `struct huawei_cdc_ncm_state` must keep `struct cdc_ncm_ctx *ctx` at offset 0 for `cdc_ncm_*` callbacks. [F83, F125, F230]
- In `aqc111_rx_fixup()` and `ax88179_rx_fixup()`, trailer bounds (`skb->len >= sizeof(desc_hdr)`, `start_of_descs == desc_offset`, and `pkt_count * 2 + desc_offset < skb_len` in `aqc111`; `pkt_cnt * 4 + hdr_off <= skb->len` in `ax88179`) must be verified, `skb_trim()` must truncate `skb` to `desc_offset`/`hdr_off`, and `pkt_desc_ptr`/`pkt_hdr` must be initialized from `skb->data` before `skb_pull()`. In `aqc111_rx_fixup()`, `pkt_total_offset` (`(pkt_len + 7) & 0x7FFF8`) must be `<= desc_offset` (`== desc_offset` when `pkt_count == 0`), and `pkt_len <= dev->hard_mtu + AQ_RX_HW_PAD`. [F76, F77, F78, F129]
- In `smsc95xx_rx_fixup()`, after pulling `4 + NET_IP_ALIGN` (matching `EVENT_NO_IP_ALIGN` and `HW_CFG_RXDOFF_`), `size` must be checked against `skb->len` and `ETH_FRAME_LEN + 12`; on `RX_STS_ES_`, the loop must still `skb_pull()` `size` and `align_count` to process later sub-frames. When `NETIF_F_RXCSUM` is set, `smsc95xx_rx_csum_offload()` must run before stripping the 4-byte FCS and read `skb_tail_pointer(skb) - 2` via `get_unaligned()`. [F234, F255, F305, F309]
- In `sr_rx_fixup()` (`sr9800.c`), 11-bit `size` (`header & 0x7ff`) must match `(~header >> 16) & 0x07ff`, satisfy `size <= dev->net->mtu + ETH_HLEN + VLAN_HLEN` and `size + offset <= skb->len`, and advance `offset` by `(size + 1) & 0xfffe` to reach exact `skb->len`. Similarly, `cx82310_rx_fixup()` must pull `(len + 1) & ~1` bytes and reject `len > CX82310_MTU` before saving partial packets into `dev->partial_data`. [F114, F132, F243]
- In `ipheth`, `ipheth_enable_ncm()` must precede `ipheth_alloc_urbs()` and update `dev->rx_buf_len` and `dev->rcvbulk_callback` together. `ipheth_rcvbulk_callback()` must skip `dev->rcvbulk_callback(urb)` and jump to `rx_submit` on 0-byte or 4-byte `0x00, 0x01` URBs; `ipheth_rcvbulk_callback_ncm()` must check `urb->actual_length >= IPHETH_NCM_HEADER_SIZE`, `wNdpIndex == cpu_to_le16(sizeof(struct usb_cdc_ncm_nth16))`, and bound `dpe16` iteration to `IPHETH_NDP16_MAX_DPE`. [F69, F80, F104]
- In `pegasus.c:read_bulk_callback()`, `count` (`urb->actual_length`) must be `>= 4` before indexing `buf[count - 4..count - 2]`, `pkt_len <= PEGASUS_MTU` before `skb_put()`, and the RX error mask on `buf[count - 2]` must be `0x1c` (excluding `0x02` so 802.1Q VLAN frames pass). `pegasus_resume()` must zero `status` and `actual_length` on `rx_urb` and `intr_urb` before invoking their callbacks. [F73, F91, F97]
- `ax88179_status()` must defer link-up handling to `ax88179_link_reset()` via `usbnet_link_change()`, which checks `GMII_PHY_PHYSR_LINK` and updates `AX_RX_BULKIN_QCTRL` and `dev->rx_urb_size` in lockstep. Every `driver_info` with `.stop = ax88179_stop` must set `.reset = ax88179_net_reset`, which checks hardware `GMII_PHY_PHYSR` (running `ax88179_reset()` if 0, or setting `AX_MEDIUM_RECEIVE_EN`). [F59, F60, F140]
- In `aqc111.c`, `aqc111_set_features()` must keep `aqc111_data->rx_checksum` and `SFR_RXCOE_CTL` in lockstep, and `aqc111_set_rx_mode()`/`link_reset()` must keep `aqc111_data->rxctl` in lockstep with `SFR_RX_CTL` (`aqc111_suspend()` modifies `SFR_RX_CTL` via a temporary variable so `aqc111_resume()` restores `aqc111_data->rxctl`). In `smsc95xx.c`, `smsc95xx_set_multicast()` must clear the other two mode bits among `MAC_CR_PRMS_`, `MAC_CR_MCPAS_`, and `MAC_CR_HPFILT_` in `pdata->mac_cr` and mask the `smsc95xx_hash()` shift with `0x1F`, while `smsc95xx_mac_update_fullduplex()` toggles `MAC_CR_FDPX_` and `MAC_CR_RCVOWN_` inversely. [F64, F65, F247, F248, F261]

## Synchronization

- `.ndo_set_rx_mode` callbacks (`aqc111_set_rx_mode()`, `asix_set_multicast()`, `ax88172_set_multicast()`, `ax88179_set_multicast()`, `mcs7830_set_multicast()`, `int51x1_set_multicast()`, `pegasus_set_multicast()`) run in atomic BH context under `netif_addr_lock_bh` and must use async USB helpers (`usbnet_write_cmd_async()`, `update_eth_regs_async()`), never sleeping control calls. [F156, F167]
- Interrupt URB `driver_info->status` callbacks, `rx_fixup`, and `ipheth_sndbulk_callback()` run in atomic/URB context: `status` callbacks (`smsc95xx`, `sr9700`, `sr9800`) must verify `urb->actual_length` before reading `transfer_buffer` and defer sleeping work via `usbnet_defer_kevent()`, `usbnet_link_change()`, or `schedule_delayed_work()`; `cx82310_rx_fixup()` must use `schedule_work(&priv->reenable_work)` and `nc_ensure_sync()` must use `usbnet_write_cmd_async()`. [F158, F159, F168, F246]
- Multi-step indirect PHY, MDIO, and EEPROM register sequences must hold `dev->phy_mutex`: `__asix_mdio_read()`/`write()` (polling `asix_check_host_enable()` and restoring `asix_set_hw_mii()`), `sr_mdio_read()`/`write()` in `sr9800.c` (bracketing with `sr_set_sw_mii()`/`sr_set_hw_mii()`), `mcs7830_read_phy()`/`write_phy()`, `smsc95xx_mdio_read()`/`write()`/`reset()`, and `sr9700.c`'s `sr_share_read_word()`/`write_word()`. [F21, F137, F231, F298]
- In `asix_devices.c`, `ax88772_bind()` holds `pm_runtime_get_noresume(&intf->dev)` balanced by `pm_runtime_put(&intf->dev)` in `ax88772_unbind()` to prevent an `rtnl_lock` deadlock between `ndo_open()` and `ax88772_resume()`. Calls to `phylink_suspend()`, `phylink_resume()`, and `phylink_disconnect_phy()` in USB callbacks (`ax88772_suspend()`, `ax88772_resume()`, `ax88772_init_phy()`, `ax88772_unbind()`) must acquire `rtnl_lock()`. [F152, F153]
- PM callbacks must route register accesses to `_nopm` USB helpers: `smsc95xx_suspend()`, `smsc95xx_resume()`, and `smsc95xx_reset_resume()` must set `pdata->pm_task = current` on entry and reset `pdata->pm_task = NULL` on all exit paths; `ax88179_suspend()` and `ax88179_resume()` must bracket device commands with `ax88179_set_pm_mode(dev, true)` and `false`. [F155, F209]
- In `smsc95xx.c`, `dev->driver_priv = pdata` and `spin_lock_init(&pdata->mac_cr_lock)` must precede `smsc95xx_reset()` in `smsc95xx_bind()`. Runtime updates to `pdata->mac_cr` must take `spin_lock_irqsave(&pdata->mac_cr_lock, flags)` and unlock before `smsc95xx_write_reg*()`, and `smsc95xx_status()` must wrap `generic_handle_domain_irq()` in `local_irq_save()`/`restore()`. [F202, F295, F297]

## Object Lifetimes

- In `asix_devices.c`, `ax88772_bind()` uses `devm_kzalloc()`, manually allocates/registers `priv->mdio` and `priv->phylink` (never `devm_mdiobus_*` on `&dev->udev->dev`, which outlives interface unbind), connects the PHY, and takes `pm_runtime_get_noresume()`; `ax88772_unbind()` and bind error paths must unwind these in reverse order (holding `rtnl_lock()` around `phylink_disconnect_phy()`). `ax88178_bind()` uses `kzalloc()` without phylink/mdio and must pair with `ax88178_unbind()`. [F1, F2, F46, F134]
- In `smsc95xx_bind()` error paths and `smsc95xx_unbind()`, resources must be released in reverse order: `phy_disconnect()`, `mdiobus_unregister()`, `mdiobus_free()`, `irq_dispose_mapping()`, `irq_domain_remove()`, `irq_domain_free_fwnode()`, and `kfree(pdata)`. `smsc95xx_info` pairs `.reset = smsc95xx_reset`, `.check_connect = smsc95xx_start_phy` (`phy_start()`), and `.stop = smsc95xx_stop` (`phy_stop()`). [F192, F198, F274]
- Multi-URB RX reassembly SKBs (`rx->ax_skb` in `asix_rx_fixup_internal()` and `s->current_rx_buf` in `vl600_rx_fixup()`) must be cleared to `NULL` when passed to `usbnet_skb_return()` or freed on framing errors, and freed on unbind. If `netdev_alloc_skb_ip_align()` fails in `asix_rx_fixup_internal()`, `rx->remaining` must still be set to `size` and the loop must advance with `if (rx->ax_skb)` guards. [F3, F4, F42, F101]
- `huawei_cdc_ncm_bind()` must check `IS_ERR(subdriver)` before assigning `drvstate->subdriver` and clear `usbnet_dev->status = NULL`; `huawei_cdc_ncm_unbind()` must call `drvstate->subdriver->disconnect(ctx->control)` before `cdc_ncm_unbind()`. In `zaurus.c`, any `driver_info` with `.bind = zaurus_bind` must set `.unbind = usbnet_cdc_unbind`. [F8, F45, F193]
- Stop URBs/work/tasklets before freeing memory: `ipheth_disconnect()` must call `unregister_netdev()` and `ipheth_kill_urbs()` before `ipheth_free_urbs()` and `kfree(dev->ctrl_buf)`; `pegasus_close()` must call `tasklet_kill(&pegasus->rx_tl)` before `unlink_all_urbs()`, and `pegasus_disconnect()` must set `PEGASUS_UNPLUG` and unlink URBs before `dev_kfree_skb(pegasus->rx_skb)`. [F12, F15, F166]
- `.tx_fixup` callbacks (`smsc95xx`, `sr9700`, `sr9800`, `zaurus`) must unshare/expand `skb` (`skb_cow_head()` or `!skb_cloned(skb)` + `skb_copy_expand()`) using the caller's `gfp_t flags` (never `GFP_KERNEL`) before mutating `skb->data` or pushing headers, and must call `dev_kfree_skb_any(skb)` whenever returning `NULL`. [F300, F308]

## API Contracts

- In `usbnet` minidrivers, `rx_fixup` and `tx_fixup` must match `FLAG_MULTI_PACKET`: when set (`aqc111`, `asix_devices`, `ax88172a`, `sr9800`), `rx_fixup` must pass every valid frame to `usbnet_skb_return()` and `tx_fixup` must call `usbnet_set_skb_tx_stats()`; when unset (`smsc95xx`, `sr9700`), the final frame is trimmed in-place in `skb` and returned with non-zero. Sub-frames must be copied into fresh `netdev_alloc_skb_ip_align()` SKBs (never `skb_clone()` or manual `skb->truesize` edits), and `rx_fixup` must verify `skb->len` against header/trailer sizes. [F95, F170, F173, F190, F191, F302, F304]
- Direct callers of `usb_control_msg()` or `usb_bulk_msg()` (`__aqc111_write_cmd()`, `ch9200.c`, `cx82310_cmd()`, `kalmia`, `catc_probe()`) must pass heap-allocated buffers, never stack variables, and `catc_ctrl_async()` callers must pass persistent buffers `<= 64` bytes. Reinitializing coherent-buffer URBs with `usb_fill_bulk_urb()`/`usb_fill_int_urb()` in `ipheth` or `kaweth` requires restoring `URB_NO_TRANSFER_DMA_MAP` before `usb_submit_urb()`. [F127, F163, F169]
- Return conventions: `smsc95xx_read_reg()`/`write_reg()` and `sr_read*()`/`sr_write*()` return positive byte counts on success (not `0`), so callers must test `ret < 0` and polling/setup functions must return `0` or a negative errno rather than `ret`; `asix_read_phy_addr()` returns `< 0` on error (check in signed `int` and mask with `0x1f` before `BIT()`); `mii_phy_probe()` (`pegasus.c`) returns unsigned `0xff` on failure. [F39, F41, F116, F212]
- `ax88179_read_cmd()`/`write_cmd*()` cast `data` to `u16 *` for `size == 2` (`u32 *` for `size == 4`) and byte-swap in-place; use `__ax88179_read_cmd()` for raw byte pairs. Helpers using `% dev->maxpacket` (`ax88178_change_mtu()`, `*_tx_fixup()`) must not be called from `.bind`. When `NETIF_F_SG` is enabled, `ax88179_tx_fixup()` (always) and `aqc111_tx_fixup()` (when `!dev->can_dma_sg`) must call `skb_linearize(skb)`. [F117, F123, F175]

## Error Handling

- Synchronous USB read/write wrappers (`aqc111_read_cmd*()`, `mcs7830_get_reg()`, `control_read()` in `ch9200.c`, `smsc95xx_read_reg()`, `sr_read*()`, `sr_write*()`) must convert non-negative short transfers (`0 <= ret < size`) to `-ENODATA` or `-EINVAL`, and callers (plus `ax88179_read_cmd()` callers with `size != 2 && size != 4` and `usb_bulk_msg()` callers reading `act_len`/`actual_len` in `kalmia` and `cx82310_cmd()`) must check for errors before reading uninitialized output buffers. `aqc111_suspend()` must `memset(&wol_cfg, 0, sizeof(wol_cfg))` before `aqc111_write_cmd()`. [F34, F36, F37, F38, F48, F49, F210]
- Every `driver_info.bind` callback must check and propagate errors from `usbnet_get_endpoints()`. In `smsc95xx_bind()`, because `ret` holds `0` or `4` after earlier register calls, null/zero failure checks (`irq_create_mapping()`, `phy_find_first()`) must set `ret` to a negative errno before jumping to a cleanup label. [F213, F214]
- Null guards and PM rollback: `asix_suspend()`/`resume()` must check both `priv` and `priv->suspend`/`resume`; AX88772 callbacks must check `!priv->embd_phy` before dereferencing `priv->phydev_int`; `smsc95xx_set_pauseparam()`/`ioctl()` must guard `ndev->phydev`. On multi-layer PM failure, `huawei_cdc_ncm_suspend()`/`resume()` must roll back the first layer, and `smsc95xx_suspend()` must call `usbnet_resume(intf)` on autosuspend failure (`PMSG_IS_AUTO(message)`) and always `kfree(filter_mask)`. [F9, F43, F44, F195, F217, F278]

## External Contracts

- `smsc95xx_bind()` must only advertise `NETIF_F_IP_CSUM` and never `NETIF_F_IPV6_CSUM` or `NETIF_F_HW_CSUM` (hardware does not convert a `0` UDP checksum to `0xffff`). When hardware TX checksum offload is used in `smsc95xx_tx_fixup()`, the 4-byte `csum_preamble` is pushed before `tx_cmd_a`/`tx_cmd_b` and both command lengths must be incremented by 4. [F237, F306]

## Known Pitfalls

- `rx_fixup` loop/return traps: in `aqc111_rx_fixup()`, any `continue` inside `while (pkt_count--)` must advance both `skb_pull(skb, pkt_len_with_padd)` and `pkt_desc_ptr++`; in `ax88179_rx_fixup()`, `pkt_len == 0` dummy headers `continue` without pulling, whereas dropping a non-zero packet must call `skb_pull(skb, pkt_len_plus_padd)`; in `vl600_rx_fixup()`, when the final packet (`count == 0`) comes from `s->current_rx_buf`, pass `buf` to `usbnet_skb_return()`, clear `s->current_rx_buf = NULL`, and return `0` (not `1`). [F99, F100, F108]
- In `smsc95xx_tx_fixup()`, `skb_cow_head()` must precede any checksum write or `skb_push()`, and `tx_cmd_b`, `smsc95xx_can_tx_checksum(skb)` (rejecting `skb->len <= 45` or `csum_offset` in the last 4 bytes so it falls back to software `csum_partial()`), and `smsc95xx_calc_csum_preamble(skb)` (truncating offsets to `u16` before `(high_16 << 16) | low_16`) must be evaluated before `skb_push()`. In `asix`, `gl620a`, `int51x1`, `kalmia`, `lg-vl600`, `net1080`, and `sr9800` `tx_fixup`, shifting an uncloned SKB to `skb->head + hdr_len` must use `memmove()` followed by `skb_set_tail_pointer()`. [F128, F226, F229, F236, F265, F307]
- Wire/register traps: use `get_unaligned*()`/`put_unaligned*()` for multi-byte wire fields in `smsc95xx` and `sr9800`; cast 16-bit MSS/VLAN fields to `u64` before shifting by `0x20`/`0x30` in `aqc111_tx_fixup()`; check L3/L4 checksum error bits before protocol bits in `aqc111_rx_checksum()`/`ax88179_rx_checksum()`; in `asix`/`ax88179` EEPROM access, size `eeprom_buff` as `last_word - first_word + 1`, index by `i - first_word`, and pre-read boundary words on odd offsets/lengths; restore PHY page 0 (`GMII_PHY_PAGE_SELECT`) before returning; and clear `PM_CTL_SUS_MODE_ | PM_CTL_WUPS_ | PM_CTL_PHY_RST_` when updating `PM_CTRL` in `smsc95xx`. [F62, F84, F98, F111, F115, F118, F283, F301]
