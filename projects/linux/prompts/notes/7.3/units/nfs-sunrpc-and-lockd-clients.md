# NFS, SUNRPC, AND LOCKD CLIENTS

This unit implements the Linux NFS client (`fs/nfs/`), including shared client/server/superblock lifecycle management, VFS file/directory/namespace operations, buffered and direct/swap I/O engines, NFSv4 delegations and callbacks, fscache/netfs integration, localio bypass, and the pNFS core and block/file/flexfile layout drivers.

## Architecture & Data Flow
- Setting `NFS4CLNT_DELEGRETURN`, `NFS4CLNT_DELEGRETURN_DELAYED`, or `NFS4CLNT_DELEGATION_EXPIRED` on `clp->cl_state` requires setting the matching `NFS4SERV_*` bit on `server->delegation_flags`. `server->nr_active_delegations` is decremented only when `NFS_DELEGATION_REVOKED` is newly set in `nfs_mark_delegation_revoked()`, and incremented when attaching a delegation or clearing `NFS_DELEGATION_REVOKED`. [F59, F61]
- `nfs_set_cache_invalid()` requires `inode->i_lock` on live inodes (`!I_NEW`); when setting `NFS_INO_INVALID_DATA`, it must call `nfs_fscache_invalidate()` and, if `nrpages == 0` or `NFS_INO_INVALID_DATA` stays set, `nfs_ooo_clear()`. `nfs_post_op_update_inode_force_wcc_locked()` must call `nfs_ooo_record()` before stripping `NFS_ATTR_FATTR_PRECHANGE` when WCC fails, and `nfs_inode_attach_open_context()` must invalidate data if `open_files` was empty and `nfs_ooo_test(nfsi)`. [F206, F246, F249, F250]
- In `pnfs_layout_remove_lseg()`, removing the last segment from `lo->plh_segs` sets `NFS_LAYOUT_INVALID_STID` when `lo->plh_outstanding == 0` unless `NFS_LSEG_LAYOUTRETURN` is on `lseg->pls_flags` or `NFS_LAYOUT_RETURN_REQUESTED` / `NFS_LAYOUT_RETURN` is on `lo->plh_flags`. `pnfs_layoutreturn_free_lsegs()` must call `pnfs_reset_return_info(lo)` after `pnfs_set_layout_stateid()`. `pnfs_layout_set_fail_bit()` takes a `plh_refcount` ref that must be dropped via `pnfs_layout_clear_fail_bit()`. [F414, F416, F417]
- `lo->plh_stateid.seqid` is `__be32`, whereas `lo->plh_barrier`, `lo->plh_return_seq`, and `lseg->pls_seq` are host `u32` compared via `pnfs_seqid_is_newer()` (`(s32)(s1 - s2) > 0`), requiring `be32_to_cpu()`/`cpu_to_be32()` at boundaries. Delegation stateid seqids must be compared with `nfs4_stateid_is_newer()` or `nfs4_stateid_match_or_older()`. [F133, F442]
- Under `NFS_I(cinfo->inode)->commit_mutex` and request lock (`PG_BUSY`), `nfs_request_add_commit_list_locked()` and `nfs_request_remove_commit_list()` must update `PG_CLEAN`, commit-list membership, and `cinfo->mds->ncommit` in lockstep (with `nfs_clear_request_commit()` calling `nfs_folio_clear_commit()`), while pNFS DS commit helpers must keep `cinfo->ds->nwritten`, `cinfo->ds->ncommitting`, `PG_COMMIT_TO_DS`, and bucket lists synchronized. [F383, F424, F430]
- In `nfs_direct_write_completion()`, set `dreq->flags = NFS_ODIRECT_DO_COMMIT` only if `!dreq->flags` so `NFS_ODIRECT_RESCHED_WRITES` is preserved. In `nfs_direct_write_schedule_work()`, sample and reset `dreq->flags = 0` before calling `nfs_direct_commit_schedule()` or `nfs_direct_write_reschedule()`, which must call `nfs_clear_pnfs_ds_commit_verifiers(&dreq->ds_cinfo)` under `rcu_read_lock()`. [F77, F118, F338]
- In `ext_tree_try_encode_commit()`, verify all `EXTENT_WRITTEN` extents fit in `buffer_size` (via `ext_tree_layoutupdate_size(bl, *count)`) before tagging any extent `EXTENT_COMMITTING` or zeroing `bl->bl_lwb`; `ext_tree_prepare_commit()` must reset `count = 0` before `ext_tree_encode_commit()`. `ext_tree_mark_committed()` sets `be_state = PNFS_BLOCK_READWRITE_DATA` or reverts `be_tag = EXTENT_WRITTEN` on error. [F68, F96, F104]
- In `filelayout_write_done_cb()` and `ff_layout_write_done_cb()`, clear `hdr->fattr.valid = 0` before `nfs_writeback_update_inode(hdr)` so DS attributes do not update the MDS inode, and pass `end_offs = 0` to `pnfs_set_layoutcommit()` / `ff_layout_set_layoutcommit()` when `hdr->res.verf->committed == NFS_UNSTABLE`. [F238, F239]

## Synchronization
- `nfs_mark_client_ready()` executes `smp_wmb()` before storing `clp->cl_cons_state`, paired with `smp_rmb()` in `nfs_found_client()`. In `nfs_match_client()`, when `clp->cl_cons_state > NFS_CS_READY`, pin `clp->cl_count`, drop `nn->nfs_client_lock`, call `nfs_wait_client_init_complete(clp)`, put `clp`, re-lock `nn->nfs_client_lock`, and `goto again`. [F15, F122]
- Setting `dentry->d_fsdata = NFS_FSDATA_BLOCKED` in `block_revalidate()` requires `dentry->d_lock` (and freeing old `d_fsdata`), and `unblock_revalidate()` must use `store_release_wake_up(&dentry->d_fsdata, NULL)` to pair with `wait_var_event()` / `smp_load_acquire()` in `__nfs_lookup_revalidate()`. `nfs_lookup_revalidate()` and `nfs4_lookup_revalidate()` must call `__nfs_lookup_revalidate()` first, and `nfs_unlink()` / `nfs_rename()` must skip `DCACHE_NFSFS_RENAMED` dentries and always unblock. [F26, F54, F79]
- Inode lock rules: acquire `nfs_access_lru_lock` before `inode->i_lock` (`nfs_access_get_cached_locked()` must drop `i_lock` before `nfs_access_zap_cache()`); `nfs_vmtruncate()` is entered and exited with `inode->i_lock` held but drops it across `truncate_pagecache()`; `nfs_force_lookup_revalidate()`, `nfs_set_inode_stale_locked()`, and `nfs_zap_caches_locked()` require `i_lock`. [F25, F29, F211, F328]
- `nfsi->open_files` is RCU-protected and holds `nfs_open_context` on `S_ISREG` and `nfs_open_dir_context` on `S_ISDIR` (verify `S_ISDIR` before walking as dir contexts); mutations require `inode->i_lock`, RCU list helpers, and `kfree_rcu()`. In `nfs_delegation_claim_opens()`, pin `ctx` before dropping `rcu_read_lock()`, hold `sp->so_delegreturn_mutex` across `nfs4_open_delegation_recall()` and `nfs_delegation_claim_locks()`, put `ctx`, and restart the walk. [F24, F137, F163, F337]
- `nfs_file_block_o_direct()` requires exclusive `inode->i_rwsem` (and must precede `nfs_sync_inode()` in `nfs_setattr()`); if the `down_read_killable(&inode->i_rwsem)` check of `NFS_INO_ODIRECT` fails in `nfs_start_io_read()` or `nfs_start_io_direct()`, drop `i_rwsem`, take `down_write_killable()`, re-test `NFS_INO_ODIRECT`, and `downgrade_write()`. [F209, F210]
- Attaching `req` to `folio->private` in `nfs_inode_add_request()` requires locking `req` first and holding `mapping->i_private_lock`. Detaching `folio->private` in `nfs_inode_remove_request()` and checking `head == folio->private` in `nfs_lock_and_join_requests()` require `nfs_page_group_lock(head)`, followed by `nfs_cancel_remove_inode(head, inode)`. `nfs_page_group_lock_subreq()` must drop `nfs_page_group_unlock(head)` before `nfs_wait_on_request(subreq)` and call `nfs_unroll_locks()` on error. [F360, F361, F378, F393, F486]
- Workqueue and atomic-context rules: blocklayout `bl_end_io_*` / `bl_end_par_io_*` must defer `ext_tree_mark_written()` and `pnfs_ld_*_done()` to `hdr->task.u.tk_work`, and `extent_tree.c` must use `GFP_ATOMIC` under `bl->bl_ext_lock` and call `__ext_put_deviceids()` after unlocking; `nfs_direct_write_complete()` must queue `dreq->work` onto `nfsiod_workqueue` and serialize `dreq` fields under `dreq->lock`; `nfs_client/server_return_marked_delegations()` must pass `issync = 0` and not call `nfs_wb_all()`. [F32, F147, F148, F149, F157]
- RCU pathwalk (`MAY_NOT_BLOCK` in `nfs_permission()` / `nfs_do_access()` or `dentry == NULL` in `nfs_get_link()`) must never sleep or issue RPCs, returning `-ECHILD` on cache miss. In `nfs_readdir_folio_array_append()`, call `nfs_readdir_copy_name()` (`GFP_KERNEL`) before `kmap_local_folio()`. In `nfs_vm_page_mkwrite()`, lock `folio` and verify `folio->mapping == inode->i_mapping` before `nfs_folio_length(folio)`, unlocking `folio` unless returning `VM_FAULT_LOCKED`. [F151, F165, F167, F480]
- pNFS synchronization: link `lo` onto `server->layouts` under `clp->cl_lock` before `LAYOUTGET`; call `pnfs_free_lseg()` / `pnfs_free_lseg_list()` outside `inode->i_lock`; follow wait-bit clears in `nfs_layoutget_end()`, `pnfs_clear_layoutreturn_waitbit()` (under `i_lock` like `pnfs_wait_on_layoutreturn()`), `pnfs_clear_first_layoutget()`, and `pnfs_clear_layoutcommitting()` with `smp_mb__after_atomic()` before `wake_up_bit()`; `pnfs_prepare_layoutreturn()` only defers for `plh_outstanding != 0` when `lo->plh_return_seq == 0`; `flo->error_list` and `ff_layout->mirrors` take `inode->i_lock` outer to `mirror->lock`. [F222, F379, F386, F450, F489, F491]

## Object Lifetimes
- Once `nfs_get_client()` links `clp` onto `nn->nfs_client_list`, `init_client` must call `nfs_mark_client_ready(clp, error)` before `nfs_put_client(clp)` on failure so `nfs_client_active_wq` waiters wake. `nfs_free_server()` must call `nfs_server_remove_lists()` (`synchronize_rcu()`) before `server->destroy()`, shutting down RPC clients, or `call_rcu(&server->rcu, delayed_free)`. In `nfs4_callback_compound()`, call `nfs4_cb_free_slot(&cps)` before `nfs_put_client(cps.clp)`. [F1, F7, F19]
- `nfs_detach_delegation_locked()` (and wrappers) transfers the initial `delegation->refcount` reference to the caller on non-NULL return. `nfs_delegation_find_inode()` and `nfs_layout_find_inode()` return `ERR_PTR` (never `NULL`), require `nfs_sb_active(server->super)` and `igrab()` under `rcu_read_lock()` (dropping `rcu_read_unlock()` before `nfs_sb_deactive()` on failure), and must be released via `nfs_iput_and_deactive()`. [F3, F48, F160, F372]
- `nfs_direct_req_alloc()` sets `dreq->kref` to 2 (caller + `nfs_direct_complete()`), so any exit in `nfs_file_direct_read/write()` before scheduling I/O (or scheduling 0 bytes) must call `nfs_direct_req_release(dreq)` twice and balance `inode_dio_begin/end()`. `nfs_direct_read/write_schedule_iovec()` and `nfs_direct_write_reschedule()` must hold `get_dreq(dreq)` through `nfs_pageio_complete(&desc)` before `put_dreq(dreq)`, and only set `dreq->iocb` when `!is_sync_kiocb(iocb)`. [F6, F33, F139]
- Every `nfs_cache_array_entry.name` in a readdir folio is allocated by `nfs_readdir_copy_name()` with `kmemdup_nul()` and `kmemleak_not_leak()`, so reinitializing or freeing a readdir folio must call `nfs_readdir_clear_array()` first. In `nfs_readdir_folio_filler()`, only call `nfs_readdir_folio_unlock_and_put(folio)` when `folio != *arrays` so the caller's lock and ref on `*arrays` are preserved. [F12, F112, F136]
- Folio lock ownership: in `nfs_write_begin()`, `nfs_flush_incompatible()` failure requires both `folio_unlock()` and `folio_put()`, whereas `nfs_read_folio()` unlocks the folio so only `folio_put()` is called afterward; `nfs_read_add_folio()` always consumes the caller's folio lock, and `nfs_return_empty_folio()`, `nfs_readpage_release()`, and `nfs_read_add_folio()` error paths must only call `folio_unlock(folio)` when `nfs_netfs_folio_unlock(folio)` returns non-zero. [F14, F347, F358, F403]
- pNFS and context lifetimes: `pnfs_generic_layout_insert_lseg()` takes a `lo` ref dropped in `pnfs_layout_remove_lseg()`, so `pnfs_put_lseg()` must hold an extra `lo` ref across removal and `spin_unlock(&inode->i_lock)`; `pnfs_read_resend_pnfs()` must call `pnfs_put_lseg(hdr->lseg)` and set `hdr->lseg = NULL` before `nfs_pageio_resend()`; `nfs_file_set_open_context()` takes its own ref, so callers of `alloc_nfs_open_context()` must still call `put_nfs_open_context(ctx)`; release `nfsd_file *` from `nfs_local_open_fh()` via `nfs_local_file_put()`. [F185, F189, F368, F369]

## API Contracts
- `ext_tree_insert(bl, new)` takes ownership of `new` and `new->be_device` when returning `0`, but leaves both caller-owned on negative error. In `ext_tree_mark_written/committed()`, assign `be = ext_try_to_merge_left(root, be)` because merging frees `be`. In `struct pnfs_block_extent`, `be_f_offset`, `be_length`, and `be_v_offset` are in 512-byte sectors (`SECTOR_SHIFT`) while XDR/map offsets are in bytes; `list_del(&be->be_list)` must precede `ext_tree_insert()` and `rb_erase(&be->be_node, root)` must precede `list_add_tail(&be->be_list, tmp)`. [F10, F43, F102, F125, F142]
- In blocklayout, `bl_alloc_lseg()` must set `NFS_LSEG_UNAVAILABLE` and return `lseg` (not `ERR_PTR(-ENODEV)`) when `bl_find_get_deviceid()` returns `-ENODEV`; `bl_find_get_deviceid()` must call `nfs4_mark_deviceid_unavailable(node)` if `bl_register_dev()` fails and never reuse unavailable nodes. When `pnfs_add_commit_array(fl_cinfo, new, lseg)` returns `array != new`, free `new` via `pnfs_free_commit_array(new)`. Pre-RPC error paths in `filelayout/ff_layout_initiate_commit()` must call `pnfs_generic_prepare_to_resend_writes(data)` and `pnfs_generic_commit_release(data)`. [F41, F67, F204, F365]
- Partial folio invalidation in `nfs_invalidate_folio()` must call `nfs_wb_folio()` rather than `nfs_wb_folio_cancel()` (which must call `folio_cancel_dirty(folio)`); `nfs_migrate_folio()` returns `-EBUSY` if `PG_private` or `PG_private_2` stays set, and `nfs_fscache_release_folio()` returns `false` without waiting when `current_is_kswapd()` or `!(gfp & __GFP_FS)`. `nfs_path()` builds backwards from `buffer + buflen_in` with signed `ssize_t buflen`, returning a pointer inside `buffer` while callers free the original `buffer`. [F166, F272, F310, F348, F504, F506]

## Error Handling
- `nfs_alloc_client()` and `nfs_alloc_server()` initialize `clp->cl_rpcclient`, `server->client`, and `server->client_acl` to `ERR_PTR(-EINVAL)`, so check `!IS_ERR()` before dereferencing or shutting them down; `nfs_init_server()` error paths after `server->nfs_client = clp` must reset `server->nfs_client = NULL` before `nfs_put_client(clp)`. `nfs_alloc_server()` returns `NULL` on error whereas `nfs_alloc_client()` / `nfs_create_server()` return `ERR_PTR`; `nfs4_label_alloc()` returns `NULL` when unsupported and `ERR_PTR(-ENOMEM)` on error; `nfs_lock_and_join_requests()` returns a locked `nfs_page *`, `NULL`, or `ERR_PTR`. [F44, F45, F47, F235, F402]
- In `nfs4_callback_sequence()`, always assign `cps->clp = clp` and free `args->csa_rclists` on every exit path, update `slot->seq_nr` only after all slot/referring checks succeed, and on `NFS4ERR_RETRY_UNCACHED_REP` save it in `cps->drc_status` and return `0`. In pNFS `pg_init` callbacks, if `pnfs_update_layout()` returns `IS_ERR(pgio->pg_lseg)`, copy `PTR_ERR(pgio->pg_lseg)` to `pgio->pg_error` and reset `pgio->pg_lseg = NULL`; in `pnfs_layout_process()`, convert a `NULL` return from `alloc_lseg()` to `ERR_PTR(-ENOMEM)`. [F51, F78, F395, F398]
- `nfs4_ff_layout_prepare_ds()` and `ff_layout_choose_*_ds_for_read()` return `ERR_PTR` on failure (never `NULL`; pass `fail_return = false` on reads and `true` on writes/commits, and reset `ds = ERR_PTR(-EINVAL)` before `continue` in `ff_layout_choose_ds_for_read()`); `ff_layout_read/write_pagelist()` must test `nfs_error_is_fatal(PTR_ERR(ds))` so fatal errors return `PNFS_NOT_ATTEMPTED`. Because `mirror_ds` can be `NULL` (lazy, treated as available in `ff_read/rw_layout_has_available_ds()`) or `ERR_PTR(-ENODEV)`, other callers must check `IS_ERR_OR_NULL()`. [F225, F227, F229, F240, F282, F288]
- In `nfs_direct_wait()` and `nfs_direct_complete()`, a positive `dreq->count` takes precedence over `dreq->error`. In `nfs_readpage_retry()` and `nfs_writeback_result()`, a short I/O with `resp->count == 0` must fail with `-EIO` instead of restarting; when `!task->tk_ops`, set `hdr->pnfs_error = -EAGAIN` instead of `rpc_restart_call_prepare()`, and re-test `hdr->pnfs_error` after `rpc_call_done()`. In `nfs_get_tree_common()`, call `nfs_free_server(server)` if `sget_fc()` fails or reuses a superblock, or `deactivate_locked_super(s)` once `s->s_fs_info == server`. [F57, F373, F401, F460]

## Known Pitfalls
- Use `div_u64()` / `div_u64_rem()` / `do_div()` for 64-bit stripe divisions (guarding `stripe_unit == 0` when `dss_count == 1`); guard unsigned subtraction/loops in `bl_register_dev()` (`while (i > 0)`), `bl_mark_devices_unavailable()`, `pnfs_generic_pg_test()` (`req_start >= seg_end`), `nfs_read_completion()` (`bytes > hdr->good_bytes`), and `nfs_grow_file()` (`i_size > 0`); use `pnfs_calc_offset_end()` for range ends and avoid `PAGE_ALIGN(NFS4_MAX_UINT64)`. Wrap `RCA4_TYPE_MASK_*` and `PNFS_FF_RCA4_TYPE_MASK_*` bit indices in `BIT()` in `nfs4_callback_recallany()`. [F49, F93, F95, F127, F293, F294, F295, F436, F437, F448, F464]
