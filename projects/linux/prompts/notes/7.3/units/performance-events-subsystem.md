# PERFORMANCE EVENTS SUBSYSTEM

Provides the Linux kernel Performance Events subsystem (`kernel/events/`, `include/linux/perf_event.h`, `include/uapi/linux/perf_event.h`), architecture CPU PMU drivers and callchain unwinders, and core `tools/perf/util/` userspace libraries.

## Architecture & Data Flow
- When `__pmu_detach_event()` revokes an event (`event->state <= PERF_EVENT_STATE_REVOKED`), it sets `event->pmu = NULL`, `event->pmu_ctx = NULL`, and `event->destroy = NULL`; operations on existing events must check `event->state > PERF_EVENT_STATE_REVOKED` before accessing `event->pmu` or `event->pmu_ctx`. [F194]
- Every `PERF_SAMPLE_*` field written by `perf_output_sample()` must be accounted in `__perf_event_header_size()`, `perf_event__id_header_size()`, or `data->dyn_size`. Save helpers (`perf_sample_save_callchain`, `perf_sample_save_raw_data`, `perf_sample_save_brstack`) must check the bit in `data->sample_flags` is unset, set it, and add the exact byte size to `data->dyn_size` (`perf_sample_save_brstack()` adds `sizeof(u64)` plus `sizeof(u64)` only if `branch_sample_hw_index(event)` is true, never `sizeof(struct perf_branch_stack)`). [F62, F105, F229]
- In `perf_prepare_sample()`, `PERF_SAMPLE_REGS_USER` must test `(sample_type & ~data->sample_flags) & PERF_SAMPLE_REGS_USER` (not `filtered_sample_type`). Because `PERF_SAMPLE_STACK_USER` and `PERF_SAMPLE_AUX` clamp dump sizes to the remaining `u16` budget (`USHRT_MAX`/`U16_MAX` minus current sample size, 8-byte aligned), any new dynamic-size sample field must update `data->dyn_size` before them. [F235, F236, F252, F279]
- Because `__perf_effective_state()` treats all group siblings as `OFF` when `leader->state <= PERF_EVENT_STATE_OFF`, transitions between `<= OFF` and `>= INACTIVE` must use `perf_event_set_state()` to update event and sibling times. `perf_remove_from_context()` forces `PERF_EVENT_STATE_OFF`, so `move_group` and `__perf_pmu_install_event()` must reinitialize `event->state` before `perf_install_in_context()`, and `inherit_event()` must initialize `child_event->state` from `parent_state` (and copy `hw.sample_period` when `attr.freq`). [F208, F224, F225]
- `event_sched_in()` and `event_sched_out()` must update `event->oncpu`, `event->state`, `cpc->active_oncpu`, `ctx->nr_freq`, `epc->nr_freq`, and `cpc->exclusive` in lockstep (reverting `state` to `INACTIVE` and `oncpu` to `-1` if `pmu->add()` fails). In `group_sched_in()`, if any sibling or `pmu->commit_txn()` fails, `group_event` and all already-scheduled siblings must be rolled back via `event_sched_out()` before `pmu->cancel_txn()`. [F212, F213]
- `perf_group_attach()` and `perf_group_detach()` must update `group_leader->nr_siblings` and `group_generation` and call `perf_event__header_size()` for all group members; `perf_event_validate_size()` must verify `__perf_event_read_size() <= 16*1024` across the group before attaching. `list_add_event()` and `list_del_event()` must update `PERF_ATTACH_CONTEXT`, `ctx`/`pmu_ctx` event counts, the group rb-tree, and `ctx->generation` in lockstep. [F209, F211, F273]
- `perf_event_throttle()` and `perf_event_unthrottle()` must return early when `event->state != PERF_EVENT_STATE_ACTIVE` (inactive siblings have `hw.idx == -1`). `perf_event_throttle()` must set `hw.interrupts = MAX_INTERRUPTS` before `pmu->stop(event, 0)` so `perf_swevent_cancel_hrtimer()` skips `hrtimer_cancel()`. When `event->event_limit` hits 0 in `__perf_event_overflow()`, it must call `pmu->stop(event, 0)` alongside `perf_event_disable_inatomic(event)`, and `event_sched_out()` / `__perf_pending_disable()` must clear `pending_disable = 0`. [F215, F216, F268, F300]
- `perf_callchain_entry__sizeof()` must reserve `sysctl_perf_event_max_stack + sysctl_perf_event_max_contexts_per_stack` elements in `entry->ip[]`; `perf_callchain_store()` (checking `!ctx->contexts_maxed` and `ctx->nr < ctx->max_stack`) and `perf_callchain_store_context()` both append to `entry->ip[entry->nr++]`. [F65, F84]
- In `tools/perf/util/map.c` and `maps.c`, only `map__new2()` and `map__clone()` allocate a trailing `struct kmap` when `dso__kernel(dso)` is true (checked by `map__kmap()`), and every path inserting into `maps_by_address` must call `map__set_kmap_maps()`. After inserting maps with `end < start` (`ends_broken`), `maps__fixup_end()` must be called once all kernel/module/extra maps are added. [F369, F378, F383]

## Synchronization
- Modifying `perf_event::sibling_list`, `perf_event_context::event_list`, or `perf_event_pmu_context` lists requires holding both `ctx->mutex` and `ctx->lock`; reading or iterating them (including `for_each_sibling_event()`) requires `ctx->mutex`, `ctx->lock`, or local IRQs disabled (with `event->ctx != NULL`, as `lockdep_assert_event_ctx()` dereferences `event->ctx->mutex`). Calling `perf_iterate_ctx()` requires `rcu_read_lock()` / `scoped_guard(rcu)`. [F19, F256, F308]
- `pmus_lock` nests inside `pmus_srcu`: `perf_pmu_unregister()` must drop `pmus_lock` before `synchronize_srcu(&pmus_srcu)`, all callers of `perf_event_alloc()` must hold `pmus_srcu` across allocation and installation, and iterating `pmus` under `pmus_lock` alone (e.g. `perf_event_clear_cpumask()`) must use `list_for_each_entry()` rather than `list_for_each_entry_rcu()`. [F310, F311]
- `event->child_mutex` nests inside `ctx->mutex` (`perf_event_release_kernel()` must pin `child->ctx`, drop `child_mutex`, lock `ctx->mutex` then `child_mutex`, and recheck `child_list`). `rb->aux_mutex` nests inside `event->mmap_mutex` (`perf_mmap_close()` detaching `rb->event_list` must pin `event->refcount` under `rcu_read_lock()`, drop RCU, lock `mmap_mutex`, and recheck `event->rb == rb`). `__pmu_detach_event()` must lock/unlock `event->mmap_mutex` after setting `PERF_EVENT_STATE_REVOKED`, paired with `perf_mmap()` checking `state <= PERF_EVENT_STATE_REVOKED` under `mmap_mutex`. [F182, F185, F186, F187]
- `event_sched_in()` must write `event->oncpu` and issue `smp_wmb()` before `event->state = PERF_EVENT_STATE_ACTIVE`, pairing with `smp_rmb()` in lockless readers (`perf_event_read()`, `perf_event_stop()`, `__perf_event_stop()`). `perf_install_in_context()` must publish `event->ctx` via `smp_store_release()` (paired with `smp_load_acquire(&event->ctx)` in `perf_iterate_sb_cpu()`) and issue `smp_mb()` before `task_function_call()`, rechecking `task_curr(task)` under `ctx->lock` if the IPI misses. [F177, F178, F179]
- In `perf_lock_task_context()`, `local_irq_save()` must precede `rcu_read_lock()`, and after locking `ctx->lock` it must recheck `ctx == rcu_dereference(task->perf_event_ctxp)`, `ctx->task != TASK_TOMBSTONE`, and `refcount_inc_not_zero(&ctx->refcount)`. When `perf_event_exit_task_context()` drops `task`, it sets `WRITE_ONCE(ctx->task, TASK_TOMBSTONE)` under `ctx->lock`; `put_ctx()` must check `ctx->task != TASK_TOMBSTONE` before `put_task_struct()` and issue `smp_mb__after_atomic()` when `refcount_dec_and_test(&ctx->refcount)` is false before testing `TASK_TOMBSTONE`. [F169, F172, F176]
- `callchain_mutex` serializes `nr_callchain_events` in `get_callchain_buffers()`, `put_callchain_buffers()`, and `perf_event_max_stack_handler()` (returning `-EBUSY` if `nr_callchain_events != 0`). `alloc_callchain_buffers()` must allocate `entries` and all `entries->cpu_entries[cpu]` (freeing all on failure) before `rcu_assign_pointer(callchain_cpus_entries, entries)`, `release_callchain_buffers()` frees via `call_rcu()`, and `get_callchain_entry()` / `get_perf_callchain()` callers must stay in RCU/NMI/non-preemptible context while using the entry. [F1, F2, F16, F17, F131]
- In `tools/perf/util/maps.c`, when a reader under `down_read(maps__lock(maps))` finds `maps_by_address_sorted` or `maps_by_name_sorted` false, it must drop `down_read`, sort under `down_write`, and re-verify the sorted flag and recompute indices/pointers (such as `first_after_` in `maps__merge_in()`) after re-locking. `maps__copy_from(dest, parent)` locks `dest` for write then `parent` for read, requiring `!maps__equal(dest, parent)`. [F350, F351, F355]

## Object Lifetimes
- An inherited child `struct perf_event` (`event->parent != NULL`) shares its parent's `addr_filters`, `fasync`, `ns`, and `id`; callers must use `perf_event_addr_filters(event)`, `perf_event_fasync(event)`, and walk `if (event->parent) event = event->parent` in `perf_event_pid_type()` / `primary_event_id()`. In `inherit_event()`, any exit after setting `child_event->parent` before `atomic_long_inc_not_zero(&parent_event->refcount)` succeeds must call `free_event(child_event)` (not `put_event()`), and `perf_child_detach()` must not clear `event->parent` or drop `parent_event->refcount`. [F8, F155, F156, F321]
- `_free_event()` must call `irq_work_sync()` on `pending_irq` and `pending_disable_irq`, but never wait synchronously for `pending_task` (which holds `event->refcount`, incremented with `pending_work` and `nr_no_switch_fast` only after `task_work_add(..., in_nmi() ? TWA_NMI_CURRENT : TWA_RESUME)` returns 0). In `__free_event()`, `event->destroy(event)` must precede `put_task_struct(event->hw.target)` and `put_pmu_ctx(event->pmu_ctx)` must precede `put_ctx(event->ctx)`. Pre-install failures after `find_get_pmu_context()` must call `put_pmu_ctx()` and clear `event->pmu_ctx = NULL`. [F158, F163, F180, F302, F315]
- In `tools/perf/util/`, `map_symbol__copy()`, `addr_map_symbol__copy()`, and `memcpy()` of `callchain_cursor_node` must balance `maps__get()`/`map__get()` with `map_symbol__exit()` before overwriting a destination or splicing to `free_lists`. In `struct maps`, when `maps_by_name` is non-NULL, every entry holds its own `map__get()` reference independent of `maps_by_address`. `machine__find*_thread()` and `machine__findnew_guest_code()` return a `struct thread *` that must be released with `thread__put()`. [F330, F331, F332, F339]

## API Contracts
- `struct pmu::event_init` must return `-ENOENT` when `event` does not target that PMU or another negative errno when invalid; in `perf_try_init_event()`, any failure after `pmu->event_init(event)` returns 0 must jump to `err_destroy` so `event->destroy(event)` runs. `struct pmu` callbacks `add()`, `del()`, `start()`, and `stop()` run with local IRQs and the PMU disabled (`start()`/`stop()` may run in NMI), whereas `addr_filters_validate()` runs in `ioctl()` process context. `->del()` must stop with `PERF_EF_UPDATE`, `->stop()` must check `PERF_HES_STOPPED` and `PERF_HES_UPTODATE` independently, and `->commit_txn()` on error must leave `txn_flags` set and the PMU disabled until `->cancel_txn()`. [F7, F21, F28, F51, F293]
- `for_each_sibling_event(sibling, event)` only iterates `event->sibling_list` when `event->group_leader == event` and does not visit the leader itself. `unclone_ctx()` must be called under `ctx->lock` and returns `parent_ctx` for the caller to pass to `put_ctx()` after unlocking `ctx->lock`. `perf_callchain()` must return `&__empty_callchain` (never `NULL`). `perf_sample_data_init()` initializes only `sample_flags`, `period`, and `dyn_size = 0`; `perf_arch_fetch_caller_regs(regs, __ip)` must initialize processor mode fields so `user_mode(regs)` is false. [F31, F39, F85, F164, F192]
- In `tools/perf/util/`, `dso__set_nsinfo()` (called under `dso__lock(dso)` in `map__new()`, with `need_setns` cleared on a copied `nsi` for vDSO maps) takes ownership of `nsi` without `nsinfo__get()`; `parse_events_error__handle()` takes ownership of heap `str` and `help`; and `parse_events__set_default_name()` consumes its heap `name` argument. `map__new()` takes a byte length `len` (`start + len`), whereas `map__init()` and `map__set_end()` take an exclusive `end` address, and `map__load(map)` must succeed before `map__map_ip()`, `map__for_each_symbol()`, or `dso__data_write_cache_addr()` in `machine__process_text_poke()`. [F336, F344, F346, F370, F371, F464, F477]

## Error Handling
- In `get_callchain_entry(int *rctx)`, if `rcu_dereference(callchain_cpus_entries)` is `NULL` after `get_recursion_context()` succeeds (`*rctx != -1`), `put_recursion_context()` must be called before returning `NULL`, and callers receiving a non-`NULL` entry must release `*rctx` via `put_callchain_entry(rctx)`. Similarly, `perf_trace_run_bpf_submit()` and `perf_tp_event()` must release a non-negative `rctx` from `perf_swevent_get_recursion_context()` via `perf_swevent_put_recursion_context(rctx)` on every exit path, and `perf_tp_event()` / `__perf_tp_event_target_task()` must call `perf_sample_data_init()` inside the event loop before each event. [F35, F193, F201]
- `inherit_event()` returns `ERR_PTR()` on failure, `NULL` when `parent_event` is revoked or orphaned (`is_orphaned_event()`), and a valid pointer on success; callers like `inherit_group()` must check `IS_ERR()` first and treat `NULL` as non-error. In `perf_event_alloc()`, no fallible check may be placed between `perf_init_event(event)` (which sets `PERF_ATTACH_TASK_DATA`) and `attach_perf_ctx_data(event)`. [F160, F191]

## External Contracts
- In `struct perf_event_mmap_page`, `offsetof(struct perf_event_mmap_page, data_head) == 1024` must be preserved; `index` (from `pmu->event_idx()`) is 1-based (`0` when inactive/stopped, `hwc->idx + 1` when active), and `perf_event_update_userpage()` must subtract `local64_read(&event->hw.prev_count)` from `userpg->offset` only when `userpg->index != 0`. Ring-buffer consumers must issue `smp_rmb()` after reading `data_head`/`aux_head` and `smp_mb()` before writing `data_tail`/`aux_tail`. `perf_mmap_vmops` must set `.may_split = perf_mmap_may_split` (`-EINVAL`), `perf_mmap_rb()` requires `nr_pages - 1` to be 0 or a power of two, and `perf_mmap_aux()` requires power-of-two `nr_pages` at `aux_offset >= perf_data_size(rb) + PAGE_SIZE`. [F23, F48, F231, F244, F246, F316]

## Known Pitfalls
- Because CPU-wide events can interrupt a task in `do_exit()` after `exit_mm()` clears `current->mm`, `perf_sample_ustack_size()` and `perf_callchain()` must check `current->mm != NULL`, and `perf_get_page_size()` must fall back to `&init_mm`. In `get_callchain_entry()`, `entries->cpu_entries[cpu]` must be cast to `void *` before adding `*rctx * perf_callchain_entry__sizeof()`. In `perf_output_sample_regs()`, a `u64 mask` must be converted via `bitmap_from_u64(_mask, mask)` before `for_each_set_bit()`. In `perf_event_bpf_emit_ksymbols()`, subprogram iteration `prog->aux->func[i]` must start at `i = 1`, and `__perf_event_overflow()` / `perf_event_free_bpf_prog()` must distinguish `BPF_PROG_TYPE_PERF_EVENT` from tracing BPF programs (`perf_event_is_tracing(event)`). [F103, F195, F196, F202, F285]
- In `tools/perf/util/`, `DECLARE_RC_STRUCT` types (`map`, `maps`, `nsinfo`, `mem_info`) must be allocated/copied using `sizeof(RC_STRUCT(<type>))` and unwrapped with `RC_CHK_ACCESS()`. `maps__for_each_map()` must reload `maps__nr_maps(maps)` and `maps__maps_by_address(maps)` on every iteration; in `maps__remove_maps()` and `__maps__fixup_overlap_and_insert()`, the loop index `i` must not be incremented when `__maps__remove()` shifts entries down; and `map__start_cmp()`/`map__addr_cmp()` must use relational operators rather than 32-bit subtraction. [F354, F414, F427, F434]
