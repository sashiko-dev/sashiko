# MEMORY MANAGEMENT - SWAP

Manages swap devices and files (`swapon`/`swapoff`), swap slot allocation and reference counting (`swap_map`, clusters, and count continuations), the per-cluster RCU-protected swap cache (`swap_table`), swap-in readahead (cluster-based and VMA-based), page-level swap I/O (`mm/page_io.c`) over block devices or filesystem `swap_rw` operations, and non-present PTE swap-entry encodings (`swp_entry_t`).

## Architecture & Data Flow

- `si->bdev` can be `NULL` for regular swapfiles on filesystems with `i_sb->s_bdev == NULL`, and `si->global_cluster` is only allocated when `!(si->flags & SWP_SOLIDSTATE)`; always check `si->bdev` (or `SWP_BLKDEV`) before dereferencing `si->bdev` and `!(si->flags & SWP_SOLIDSTATE)` before dereferencing `si->global_cluster`. [F50]
- In `swap_writeout()`, when writing out a non-zero-filled folio, `swap_zeromap_folio_clear(folio)` must be called before `zswap_store()` or `__swap_writepage()` so stale `sis->zeromap` bits from prior zero-filled writes to the same slots are cleared before storing new data. [F168]
- Both `swap_zeromap_folio_set()` and `swap_read_folio_zeromap()` must account `folio_nr_pages(folio)` to `SWPOUT_ZERO` or `SWPIN_ZERO` via both `count_vm_events()` and, when `get_obj_cgroup_from_folio(folio)` is non-NULL, `count_objcg_events()` followed by `obj_cgroup_put()`. [F72]
- Software flags on swap PTEs/PMDs (`exclusive`, `soft_dirty`, `uffd_wp`) must be stripped by `pte_swp_clear_flags()` in `pte_to_swp_entry()` and `pte_same_as_swp()` and by `pmd_to_swp_entry()`, and must be transferred from `old_pte` to `new_pte` and `rmap_flags` in `unuse_pte()`. [F83]
- `relocate_cluster()` must return early if `cluster_is_discard(ci)` is true, and must verify that `ci->flags` does not already equal `CLUSTER_FLAG_FREE`, `CLUSTER_FLAG_FRAG`, or `CLUSTER_FLAG_FULL` before calling `free_cluster()` or `move_cluster()`. [F111]
- `free_cluster()` must check `(si->flags & (SWP_WRITEOK | SWP_PAGE_DISCARD)) == (SWP_WRITEOK | SWP_PAGE_DISCARD)` before calling `swap_cluster_schedule_discard()`, falling back to `__free_cluster()` otherwise. Broken by: testing `si->flags & (SWP_WRITEOK | SWP_PAGE_DISCARD)` as a boolean or omitting `SWP_WRITEOK`. [F110]
- In `SYSCALL_DEFINE2(swapon)`, `setup_swap_extents()` must run before allocating `swap_map`, `zeromap`, and `cluster_info` (`setup_clusters()`), and `maxpages` must be refreshed from `si->max` afterwards because extent activation (`generic_swapfile_activate()`) can shrink `si->max` and `si->pages`. [F63]
- In `read_swap_header()`, converting the inclusive on-disk `last_page` index to the exclusive `maxpages` bound (`last_page + 1`) must guard against 32-bit `unsigned int` wraparound (`if ((unsigned int)maxpages == 0) maxpages = UINT_MAX;`) before storing into `unsigned int si->max`. [F90]
- Swap slot 0 is reserved for the swap header (`SWAP_ENTRY_INVALID`): `setup_swap_map()` marks `swap_map[0] = SWAP_MAP_BAD`, `setup_clusters()` increments cluster 0's count for page 0, `discard_swap()` skips the first block of `first_se(si)`, and `swap_cluster_readahead()` clamps `start_offset == 0` to `1`. [F91]
- `SWP_TYPE_SHIFT` is `BITS_PER_XA_VALUE - MAX_SWAPFILES_SHIFT` (leaving the top bit of `swp_entry_t.val` zero for 5-bit swap types) so `swp_to_radix_entry()` (`xa_mk_value(entry.val)`) can left-shift `entry.val` by 1 bit without truncating `swp_type`. [F99]
- `SWAP_RA_VAL(addr, win, hits)` packs `hits` and `win` into the low `PAGE_SHIFT` bits of `vma->swap_readahead_info` below `PAGE_MASK`, so `swap_update_readahead()` must clamp `hits` to `SWAP_RA_HITS_MAX` and `swap_vma_ra_win()` must cap `max_win` using `SWAP_RA_ORDER_CEILING`. [F102]
- In `folio_swapcache_freeable()`, swap cache folios (`folio_free_swap()`, `__try_to_reclaim_swap()`) must not have their swap slots freed while `folio_test_writeback(folio)` is true or while `pm_suspended_storage()` is true during hibernation image creation. [F184]
- In `sys_swapon()`, `claim_swapfile()` must reject zoned block devices (`bdev_is_zoned(si->bdev)`), and under `inode_lock(inode)` `sys_swapon()` must reject `d_unlinked(dentry)`, `cant_mount(dentry)`, `IS_SWAPFILE(inode)`, `mapping_min_folio_order(mapping) > 0`, and missing `mapping->a_ops->read_folio` before reading the header. [F179]

## Synchronization

- `cluster_alloc_range()` must verify `si->flags & SWP_WRITEOK` while holding `ci->lock` before committing an allocation to `si->swap_map`, and `swapoff()` must call `wait_for_allocation()` after clearing `SWP_WRITEOK` and before `try_to_unuse()`, advancing `offset` by `SWAPFILE_CLUSTER` once per iteration from `0` to `ALIGN(si->max, SWAPFILE_CLUSTER)` to lock and unlock every cluster via `swap_cluster_lock()`. [F21, F120]
- `swap_range_free()` must execute `smp_wmb()` after clearing `si->zeromap`, invalidating zswap/arch state, invoking `swap_slot_free_notify`, and calling `__swap_cache_clear_shadow()` before `swap_usage_sub()` decrements `si->inuse_pages`, pairing with `smp_mb()` in `try_to_unuse()` before `swapoff` tears down device structures. [F22]
- `enable_swap_info()` must complete `setup_swap_info()` and release `si->lock` and `swap_lock` before calling `percpu_ref_resurrect(&si->users)` and `_enable_swap_info()`, pairing with `smp_rmb()` after `percpu_ref_tryget_live(&si->users)` in `get_swap_device_info()` so readers observe initialized `swap_info_struct` fields. [F18]
- `ci->table` is RCU-protected and writers (`__swap_table_set()`, `__swap_table_xchg()`, `swap_cluster_free_table()`) must hold `ci->lock`; `isolate_lock_cluster()` allocates `ci->table` via `swap_cluster_alloc_table()`, `__free_cluster()` resets `ci->order = 0` and calls `swap_cluster_free_table(ci)` only when `cluster_is_empty(ci)` and all `SWAPFILE_CLUSTER` entries are null, and `swap_table_free()` defers reclamation via `call_rcu(..., swap_table_free_folio_rcu_cb)` (when `SWP_TABLE_USE_PAGE` is true) or `SLAB_TYPESAFE_BY_RCU`. [F32, F66, F157]
- `swap_cache_get_folio()` uses `folio_try_get()` on a lockless `swap_table_get()` lookup because both the folio and a `SLAB_TYPESAFE_BY_RCU` swap table can be freed and reused concurrently; callers must lock the folio and verify `folio_matches_swap_entry(folio, entry)` rather than comparing `folio->swap.val == entry.val` (since a large folio stores its `folio_nr_pages(folio)`-aligned base entry in `folio->swap` while every covered `ci->table` slot points to `folio`). [F61, F158]
- Swap cluster lock helpers (`__swap_cluster_lock`, `swap_cluster_lock`, `swap_cluster_get_and_lock`, `swap_cluster_get_and_lock_irq`) must only be called in task context (`in_task()`) while the swap device is pinned (`!percpu_ref_is_zero(&si->users)`), never from hardirq or softirq completion handlers. [F145]
- In `unuse_mm()`, after acquiring `mmap_read_lock(mm)`, `check_stable_address_space(mm)` must be checked before walking VMAs with `for_each_vma(vmi, vma)`. [F38]

## Object Lifetimes

- During the `init_mm.mmlist` walk in `try_to_unuse()`, `prev_mm` holds an active `mmget()` reference transferred to each `mm` acquired via `mmget_not_zero(mm)` after dropping `mmlist_lock`; `mmput(prev_mm)` must be called both on normal loop exit and when `unuse_mm()` returns an error. [F10]
- In `unuse_pte()`, the original swapcache folio must be saved in `swapcache = folio` before `folio = ksm_might_need_to_copy(folio, vma, addr)`, restored via `folio = swapcache` if `folio == ERR_PTR(-EHWPOISON)` before dereferencing `folio`, and unlocked/put at `out:` only when `folio != swapcache`; if `folio == ERR_PTR(-EHWPOISON)` or `PageHWPoison(page)` or `!folio_test_uptodate(folio)`, `unuse_pte()` must install `make_hwpoison_entry(page)` or `make_poisoned_swp_entry()` respectively, decrement `MM_SWAPENTS`, and call `swap_free(entry)`. [F40, F123, F183]

## API Contracts

- An empty free swap cluster has `ci->table == NULL` until isolated by `isolate_lock_cluster()`, so lockless RCU readers (under `rcu_read_lock()`) must use `swap_table_get()` (which null-checks `rcu_dereference(ci->table)`) rather than `__swap_table_get()`, which dereferences `ci->table` unconditionally. [F47]
- `__try_to_reclaim_swap()` returns positive `nr_pages` when the swapcache folio is reclaimed, negative `-nr_pages` when a folio of `nr_pages` is present but cannot be reclaimed, or `0` when no folio is cached; callers must test `> 0` for reclaim success and use `abs()` or `-nr` to advance across unreclaimed folios. [F41]
- In `swap_read_folio_zeromap()`, `swap_zeromap_batch(folio->swap, nr_pages, &is_zeromap) != nr_pages` must be checked before `!is_zeromap`, returning `true` without calling `folio_mark_uptodate(folio)` if a multi-page folio has mixed `sis->zeromap` bits. [F106]
- `MAX_SWAPFILES` must subtract every special swap-entry type count (`SWP_DEVICE_NUM`, `SWP_MIGRATION_NUM`, `SWP_HWPOISON_NUM`, `SWP_PTE_MARKER_NUM`) from `1 << MAX_SWAPFILES_SHIFT` so `non_swap_entry(entry)` (`swp_type(entry) >= MAX_SWAPFILES`) matches all non-swap entries; because `__swap_type_to_info()` and `__swap_entry_to_info()` index `swap_info[type]` without bounds checking, callers decoding a swap PTE must check `!non_swap_entry(entry)` or use `swap_entry_to_info()` / `get_swap_device()` first. [F97, F162]
- Swap writeout and runtime cluster discard paths (`swap_writepage_fs`, `swap_writepage_bdev_async`, `discard_swap_cluster`) must use `GFP_NOIO` (not `GFP_KERNEL`) for memory and BIO allocations to avoid recursing into filesystem or swap I/O during reclaim. [F148]
- In `is_folio_zero_filled()`, each page of the folio must be mapped individually via `kmap_local_folio(folio, i * PAGE_SIZE)` and unmapped with `kunmap_local(data)` before returning or advancing to the next page index. [F161]
- `struct swap_extent` stores `start_page`, `nr_pages`, and `start_block` in `PAGE_SIZE` units (`generic_swapfile_activate()` right-shifts filesystem block numbers by `PAGE_SHIFT - blkbits`), whereas block-layer callers (`swap_folio_sector()`, `discard_swap()`, `discard_swap_cluster()`) must widen `pgoff_t` offsets and counts to `sector_t` (`u64`) before left-shifting by `PAGE_SHIFT - 9`. [F62, F127]

## Error Handling

- In `SYSCALL_DEFINE1(swapoff)`, when `security_vm_enough_memory_mm(current->mm, p->pages)` returns 0 it has accounted `p->pages` to `vm_committed_as`, so `swapoff` must immediately call `vm_unacct_memory(p->pages)` to undo that reservation, and if `try_to_unuse()` fails it must restore `p` via `reinsert_swap_info(p)`. [F14]

## External Contracts

- Both `sys_swapon()` and `sys_swapoff()` require `capable(CAP_SYS_ADMIN)` (never `ns_capable()`), and `sys_swapon()` must reject any `swap_flags` bits outside `SWAP_FLAGS_VALID` with `-EINVAL`; when `SWAP_FLAG_DISCARD` is set without `SWAP_FLAG_DISCARD_ONCE` or `SWAP_FLAG_DISCARD_PAGES`, both `SWP_AREA_DISCARD` and `SWP_PAGE_DISCARD` must be enabled. [F104, F182]
- `union swap_header.magic.magic` is a 10-byte non-NUL-terminated array (`"SWAPSPACE2"`) at the end of the `PAGE_SIZE` swap header; `read_swap_header()` must bound comparisons to 10 bytes (`memcmp("SWAPSPACE2", swap_header->magic.magic, 10)`) and never pass `magic.magic` to unbounded string functions. [F143]

## Known Pitfalls

- Extracting a PFN from a PFN swap entry (`is_pfn_swap_entry(entry)`) must use `swp_offset_pfn(entry)` (`swp_offset(entry) & SWP_PFN_MASK`) rather than raw `swp_offset(entry)` because migration entries pack `SWP_MIG_YOUNG` and `SWP_MIG_DIRTY` at bits `SWP_PFN_BITS` and `SWP_PFN_BITS + 1`; when `MAX_PHYSMEM_BITS` is undefined, `SWP_PFN_BITS` must be `min_t(int, sizeof(phys_addr_t) * 8 - PAGE_SHIFT, SWP_TYPE_SHIFT)` rather than `BITS_PER_LONG - PAGE_SHIFT` so 32-bit targets with 64-bit `phys_addr_t` do not truncate high PFN bits. [F98, F125]
- In `swap_vma_ra_win()`, `left` can underflow when subtracting the readahead window from `faddr`, so `right` must be computed before clamping `left` (`if ((long)left < 0) left = 0;`), and `[start, end)` must be clamped to `[faddr & PMD_MASK, (faddr & PMD_MASK) + PMD_SIZE)` so `swap_vma_readahead()`'s `pte++` loop stays within `vmf->pmd`. [F96]
- `swap_dev_pos()` in `mm/swap.h` must cast `swp_offset(entry)` (`pgoff_t`, i.e. `unsigned long`) to 64-bit `loff_t` before left-shifting by `PAGE_SHIFT` so swap file byte offsets at or above 4 GiB do not overflow on 32-bit architectures. [F126]
- In `unuse_mm()`, the VMA iteration loop must check both `vma->anon_vma` and `!is_vm_hugetlb_page(vma)` before calling `unuse_vma(vma, type)`. [F112]
