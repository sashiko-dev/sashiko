# GENERIC STRING LIBRARY

The Generic String Library provides architecture-independent C string and raw memory primitives (`sized_strscpy`, `memcpy`, `memcmp`, `memchr_inv`), higher-level formatting, escaping, parsing, and allocation helpers (`string_get_size`, `string_escape_mem`, `string_unescape`, `kstrdup_quotable`, `sysfs_streq`), compile-time bounds-checked copy macros (`strscpy`, `strtomem`, `memtostr`), and `FORTIFY_SOURCE` runtime overflow reporting.

## Architecture & Data Flow

- In `sized_strscpy()`, when `CONFIG_DCACHE_WORD_ACCESS` is enabled, word-at-a-time reads must use `load_unaligned_zeropad(src+res)` rather than `read_word_at_a_time(src+res)`. Each full-word iteration must decrement `count` and `max` and advance `res` by `sizeof(unsigned long)` in lockstep; if `count` reaches 0 on a word boundary without a NUL byte, the final byte in memory order must be masked to NUL via `ALLBUTLAST_BYTE_MASK` (`~255ul` on big-endian, `~0ul >> 8` on little-endian) before storing the word and returning `-E2BIG` prior to the byte-at-a-time tail loop. [F30, F39, F41]
- In `sized_strscpy_pad()`, when `__wrote = sized_strscpy(__dst, __src, __count)` satisfies `0 <= __wrote < __count`, `memset()` must start at `__dst + __wrote + 1` with length `__count - __wrote - 1` because `sized_strscpy()` already wrote `'\0'` at `__dst[__wrote]`. Broken by: passing `__count - __wrote` as the `memset()` length, overflowing `__dst` by 1 byte. [F81]
- In `strtomem()` and `strtomem_pad()`, the `strnlen()` bound on `src` must be clamped to `min(_src_len, _dest_len)` (where `_src_len` is `__builtin_object_size(src, 1)`) so `strnlen()` never reads past a source object smaller than `dest`. In `memtostr()` and `memtostr_pad()`, `_copy_len` must be bounded to `min(_dest_len - 1, _src_chars)` with non-zero compile-time `_dest_len` and `_src_len`, reserving `dest[_copy_len]` for `'\0'`. [F75, F76]
- `memcpy_and_pad()` must check `dest_len > count` before subtracting `dest_len - count` for `memset()`; when `dest_len <= count`, it must copy only `dest_len` bytes without padding. [F55]
- `memset_after()` and `memset_startat()` must cast `obj` to a byte pointer (`u8 *__ptr = (u8 *)(obj)`) before adding `offsetofend()` or `offsetof()` so the address calculation uses byte stride rather than scaling by `sizeof(*(obj))`. [F82]
- In `string_escape_mem()`, the passthrough filter checks (`only`, `ESCAPE_NAP`, `ESCAPE_NP`, `ESCAPE_NA`) must run before any conversion branch, and the catch-all `ESCAPE_OCTAL` and `ESCAPE_HEX` branches must run after all specific character-class checks (`ESCAPE_SPACE`, `ESCAPE_SPECIAL`, `ESCAPE_NULL`), with `ESCAPE_OCTAL` ordered before `ESCAPE_HEX` (so passing `ESCAPE_OCTAL | ESCAPE_HEX` or `ESCAPE_ANY | ESCAPE_HEX` causes `ESCAPE_HEX` to be ignored). [F22, F58, F59]
- In `string_unescape()`, helpers `unescape_space()`, `unescape_octal()`, `unescape_hex()`, and `unescape_special()` must parse via local pointers and only write `**dst` and advance `*src` and `*dst` after matching a valid escape sequence, preserving in-place safety (`src == dst`) and allowing a literal `'\\'` fallback on mismatch. `unescape_octal()` must enforce `num < 32` in its loop condition before `num <<= 3` and `num += (*q++) & 7` so a 3-digit octal sequence cannot overflow `u8 num`. [F28, F73]
- `string_get_size()` must set `size = 0` when `blk_size == 0` and jump to `out` when `size == 0` before the reduction and `sf_cap * 10 < 1000` loops so `sf_cap` is non-zero and `j <= 2` stays within `rounding[]`. It must mask `units` with `STRING_UNITS_MASK` before indexing `divisor[]` and `units_str[]`, and bounds-check the exponent `i` against `ARRAY_SIZE(units_2)` (falling back to `"UNK"`) before indexing `units_str[units_base][i]`. [F47, F69]
- In `string_get_size()`, 64-bit `blk_size` and `size` must each be reduced via `do_div()` only while `blk_size >> 32` or `size >> 32` is non-zero before `size *= blk_size`, and `size` must be reduced below `divisor[units_base]` (`<= 1024`) before formatting `(u32)size` with `"%u"`. When `units_base == STRING_UNITS_2`, `remainder` must be scaled via `remainder *= 1000; remainder >>= 10;` before adding `rounding[j]`, and `remainder >= 1000` must subtract 1000 and carry `1` into `size` so `remainder < 1000` and `j <= 2` when formatting `".%03u"` into `char tmp[12]`. [F68, F70, F85]
- `kstrdup_quotable_cmdline()` must pass `PAGE_SIZE - 1` to `get_cmdline(task, buffer, PAGE_SIZE - 1)`, explicitly set `buffer[res] = '\0'`, and keep `res` as a signed `int` in `while (--res >= 0 && buffer[res] == '\0')` before replacing inter-argument NULs up to index `res`. [F50]
- In `memcmp()`, the `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` word loop must only skip equal words, decrementing `count` by `sizeof(unsigned long)` and updating `cs = u1` and `ct = u2` on exit so the byte loop determines the sign from the first differing byte. `strncasecmp()`, `strcmp()`, `strncmp()`, and `memcmp()` must read and compare bytes as `unsigned char` so values `>= 0x80` do not sign-extend on signed-`char` architectures. [F31, F74]
- In `memchr_inv()`, when `start` is not 8-byte aligned (`prefix != 0`), `start` must be advanced by `prefix = 8 - ((unsigned long)start % 8)` and `bytes` decremented by `prefix` after `check_bytes8()` succeeds and before computing `words = bytes / 8`. [F32]
- `strim()` must check for an empty string (`!size`) and return `s` immediately before computing `end = s + size - 1` and scanning backward with `while (end >= s && isspace(*end)) end--`. [F52]
- `__fortify_report()` clamps `func` with `umin(func, FORTIFY_FUNC_UNKNOWN)` to index `fortify_func_name[]` and passes `!write` to `str_read_write()` because `FORTIFY_READ` is 0 and `str_read_write(true)` returns `"read"`. Broken by: adding an entry after `UNKNOWN` in `EACH_FORTIFY_FUNC` or passing `write` to `str_read_write()`. [F108]

## Synchronization

- In `sized_strscpy()`, the word-at-a-time loop must load each source word once into local variable `c` via `load_unaligned_zeropad()` or `read_word_at_a_time()` and mask and write that same `c` value to `dest + res` without re-reading `src + res`. Broken by: re-reading `*(unsigned long *)(src + res)` after `has_zero(c, &data, &constants)`. [F8]
- Callers of `kstrdup_quotable()` must ensure `src` is not concurrently modified during the call, because it scans `src` twice with `string_escape_mem()` and triggers `WARN_ON()` if the escaped output length changes between sizing and copying. [F9]
- `kstrdup_quotable_cmdline()` unconditionally allocates its temporary `PAGE_SIZE` buffer with `GFP_KERNEL` and reads target process memory via `get_cmdline()`, and `kstrdup_quotable_file()` (when `file` is non-NULL) unconditionally allocates its temporary `PATH_MAX + 11` buffer with `GFP_KERNEL`, regardless of the caller's `gfp_t gfp` argument; both require sleeping context. [F90, F91]

## API Contracts

- `kmemdup_array()`, `memdup_array_user()`, and `vmemdup_array_user()` are annotated with `__realloc_size(2, 3)` and take element count `n` as the second argument and element `size` as the third. `memdup_array_user()` and `vmemdup_array_user()` must validate `n * size` with `check_mul_overflow(n, size, &nbytes)` and return `ERR_PTR(-EOVERFLOW)` on overflow. Memory from `memdup_array_user()` is physically contiguous and freed with `kfree()`, whereas memory from `vmemdup_array_user()` may be vmalloc memory and must be freed with `kvfree()`. [F5, F10, F35]
- `string_escape_mem()` and its `escape_*()` helpers must guard every byte write to `dst` with `out < end` (`end = dst + osz`), always advance the output cursor `out` even when `out >= end`, and never NUL-terminate `dst`. It returns the total escaped byte count that would be produced for `src` (even when `dst` is NULL and `osz` is 0), so `dst` has room for a trailing NUL if and only if the return value is strictly less than `osz`. [F14, F49]
- `string_unescape()` always writes a trailing `'\0'` to `dst`, returns the number of unescaped characters written excluding `'\0'`, and treats `size == 0` as unlimited capacity (`SIZE_MAX`) for `string_unescape_inplace()`. It must reserve 1 byte for `'\0'` by pre-decrementing `--size` in its main loop (after converting `0` to `SIZE_MAX`) and checking `size > 1` before consuming a backslash escape sequence. Broken by: passing a dynamically computed `size` that can be 0 expecting 0 bytes written, or post-decrementing `size--`. [F15, F48]
- `strtomem()` and `strtomem_pad()` copy into a `__nonstring` byte array without NUL-terminating it (`strtomem()` leaves trailing bytes untouched; `strtomem_pad()` fills them with `pad`), whereas `memtostr()` and `memtostr_pad()` copy from a `__nonstring` array into a C string and always NUL-terminate `dest` (`memtostr_pad()` zeroes all trailing bytes). [F21]
- `memset_startat(obj, v, member)` starts writing at `offsetof(typeof(*(obj)), member)` and leaves alignment padding before `member` untouched, whereas `memset_after(obj, v, member)` starts at `offsetofend(typeof(*(obj)), member)` and must be used when clearing padding immediately following `member`. [F20]
- When the searched byte `c` is not found, `strchr()`, `strnchr()`, `strrchr()`, and `memchr()` return `NULL`, whereas `strchrnul()` returns a pointer to the trailing NUL byte, `strnchrnul()` returns a pointer to the trailing NUL or `s + count`, and `memscan()` returns `addr + size` (one byte past the buffer). `strchr()`, `strnchr()`, and `strrchr()` must test `*s == (char)c` before stopping on `'\0'` so searching for `c == '\0'` matches the NUL terminator. [F19, F66]
- `strim()` mutates `s` in place by writing a NUL byte at the first trailing whitespace character and returns an interior pointer from `skip_spaces(s)` rather than shifting characters to the start of `s`. Broken by: passing a read-only string literal to `strim()`, or passing its return value directly to `kfree()`. [F33]
- `strlcat(dest, src, count)` requires `count` to be the total size of `dest` (not remaining space) and calls `BUG_ON(dsize >= count)` if `strlen(dest)` is already `>= count`. [F24]
- `match_string()` and `__sysfs_match_string()` stop scanning upon hitting either the `n`-th element or the first `NULL` entry in `array` (allowing `n = -1` for NULL-terminated arrays) and return the matched 0-based `int` index or `-EINVAL`. [F17]
- `bcmp()` only guarantees a return value of 0 when buffers are identical and non-zero otherwise; unlike `memcmp()`, the sign of a non-zero `bcmp()` result has no defined meaning. [F25]
- `memset16()`, `memset32()`, `memset64()`, `memset_l()`, and `memset_p()` take their count/`n` parameter as the number of multi-byte elements to store, not the byte size. [F77]
- `memset()` and `memcpy()` must not be used on MMIO or I/O space (`__iomem`); callers must use `memset_io()`, `memcpy_toio()`, or `memcpy_fromio()`. [F89]

## Error Handling

- `sized_strscpy()`, `strscpy()`, and `strscpy_pad()` return a signed `ssize_t` equal to the number of copied characters (excluding `'\0'`) or `-E2BIG` when `count == 0`, `count > INT_MAX`, or `src` is truncated. `sized_strscpy()` NUL-terminates `dest` without warning when truncating into `1 <= count <= INT_MAX`, but leaves `dest` untouched when `count == 0` (no warning) or `count > INT_MAX` (triggers `WARN_ON_ONCE()`). Callers must keep the return value signed and check `ret >= 0` before indexing `dst + ret`. [F11, F105]
- `kstrdup_quotable_file()` does not return `NULL` when `file` is `NULL`, its temporary buffer allocation fails, or `file_path()` returns an error pointer; instead it calls `kstrdup()` on `"<unknown>"`, `"<no_memory>"`, or `"<too_long>"`, returning `NULL` only if the final `kstrdup()` or `kstrdup_quotable()` allocation fails. [F13]

## External Contracts

- `sysfs_streq()` must treat a trailing `'\n'` followed immediately by `'\0'` on either `s1` or `s2` (`!s1[1]` / `!s2[1]`) as equivalent to `'\0'` so sysfs inputs ending with a single newline match NUL-terminated kernel strings. [F53]
- `lib/string.c` must be compiled with `__NO_FORTIFY` defined and only contain routines that may be overridden by `<asm/string.h>` (guarded by `#ifndef __HAVE_ARCH_*`) or overloaded by `FORTIFY_SOURCE`, while non-overloaded helpers belong in `lib/string_helpers.c`. [F97]

## Known Pitfalls

- In `memzero_explicit()` (and any inline helper that scrubs sensitive memory at the end of a scope), `memset(s, 0, count)` must be followed by a compiler memory barrier (`barrier_data(s)` or `barrier()`) rather than `OPTIMIZER_HIDE_VAR(s)`, which only hides the pointer value and allows the compiler to eliminate the dead store. [F110]
