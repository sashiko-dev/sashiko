# AMD XGBE DRIVER

Implements the core AMD 10 Gigabit Ethernet (`amd-xgbe`) network driver, including PCI probing, `net_device` lifecycle, DMA descriptor rings and channels, MAC/MTL/DMA programming, MDIO/PCS auto-negotiation, I2C, PTP timestamping, DCB, ethtool, and debugfs.

## Architecture & Data Flow

- Access `struct xgbe_ring_desc` fields (`desc0`..`desc3`) only with `cpu_to_le32()`, `le32_to_cpu()`, `XGMAC_GET_BITS_LE()`, or `XGMAC_SET_BITS_LE()`, never native-endian bit macros. `ring->cur` and `ring->dirty` wrap at `UINT_MAX`: compute occupancy via `ring->cur - ring->dirty`, test `ring->dirty != cur`, index power-of-two rings via `XGBE_GET_DESC_DATA()`, and in `xgbe_wrapper_tx/rx_descriptor_init()` reset `cur = 0`, `dirty = 0`, and `memset(&ring->tx, 0, sizeof(ring->tx))`. [F67, F90, F116]
- `ring->packet_data` is reused across packets while `xgbe_packet_info()` and `xgbe_dev_read()` only set individual bitfields; `xgbe_xmit()` and `xgbe_rx_poll()` must `memset(packet, 0, sizeof(*packet))` first. `xgbe_unmap_rdata()` must clear `rdata->mapped_as_page = 0`, `rdata->rx`, `rdata->tx`, `rdata->state_saved`, and `rdata->state`. [F48, F49, F66]
- In `xgbe_map_tx_skb()`, assign `rdata->skb` only to `XGBE_GET_DESC_DATA(ring, cur_index - 1)` after all fragments are mapped, so the `err_out` loop `while (start_index < cur_index)` can unmap `[start_index, cur_index)` via `xgbe_unmap_rdata()` without freeing `skb` before `xgbe_xmit()` frees it. [F102]
- In `xgbe_dev_read()`, if `LD` in `rdesc->desc3` is 0 on a normal Rx descriptor, return 0 before setting `RX_PACKET_ATTRIBUTES_LAST`, reading `PL` (`rdata->rx.len`), or checking `ES`/`ETLT`. [F98]
- In `xgbe_rx_poll()`, while `!last || context_next` holds, `read_again` must keep draining descriptors even after `error` is set (saving `skb`, `len`, and `error` into `rdata->state` at `ring->cur` if `dev_read()` stops mid-packet). Validate `buf2_len <= rdata->rx.buf.dma_len` before `skb_add_rx_frag()` (setting `error = 1` on overflow), and before `napi_gro_receive()` check `skb->len <= max_len` (`netdev->mtu + ETH_HLEN`, plus `VLAN_HLEN` when `!NETIF_F_HW_VLAN_CTAG_RX` and `skb->protocol == htons(ETH_P_8021Q)`). [F79, F80, F100]
- `xgbe_one_poll()` downcasts `napi` to `struct xgbe_channel` while `xgbe_all_poll()` downcasts to `struct xgbe_prv_data`, so `xgbe_napi_enable()`, `xgbe_napi_disable()`, and `xgbe_tx_timer()` must use `&channel->napi` when `pdata->per_channel_irq` is set and `&pdata->napi` otherwise. In `xgbe_all_poll()`, clamp `ring_budget` to `budget - processed` and stop when `processed == last_processed`. [F105, F127]
- Single-IRQ fallback in `xgbe_config_irqs()` sets `ecc_irq`, `i2c_irq`, and `an_irq` equal to `pdata->dev_irq`, so `xgbe_request_irqs()`, `xgbe_free_irqs()`, `xgbe_i2c_start/stop()`, and `xgbe_phy_start/stop()` must check `pdata->dev_irq != pdata->{ecc,i2c,an}_irq`. Per-channel DMA IRQ updates in `xgbe_enable/disable_int()` must update `channel->curr_ier` before writing `DMA_CH_IER` and save/restore `channel->saved_ier` on `XGMAC_INT_DMA_ALL`. [F45, F60]
- `xgbe_set_channels()` forbids having both `rx_count` and `tx_count` non-zero, so `tx_ring` and `rx_ring` form contiguous prefixes of `pdata->channel[]` (relied on by loops that `break` on the first NULL ring). Applying `new_tx/rx_ring_count` in `xgbe_alloc_memory()` must set `pdata->tx_q_count = pdata->tx_ring_count` and clear `new_*_ring_count = 0`. Update `pdata->rx_buf_size` via `xgbe_calc_rx_buf_size()` before Rx ring init, and schedule `pdata->restart_work` when toggling `NETIF_F_RXCSUM` in `xgbe_set_features()`. [F55, F56, F84, F103, F174]
- `pdata->ets` and `pdata->pfc` are NULL until set by DCB ops; callers of `xgbe_is_pfc_queue()` and `xgbe_calculate_dcb_fifo()` must check `pdata->pfc && pdata->ets`. `xgbe_config_queue_mapping()` must populate `pdata->q2tc_map[]` in contiguous ascending TC order (`0 .. tc_cnt - 1`) and `pdata->prio2q_map[]`. In `xgbe_enable/disable_tx_flow_control()`, `xgbe_get_fc_queue_count()` must return `XGMAC_MAX_FLOW_CONTROL_QUEUES` when `MAC_VR.SNPSVER >= 0x30`. [F43, F77, F136]
- In `xgbe_phy_status()`, if `link_status(pdata, &an_restart)` sets `an_restart`, call `xgbe_phy_config_aneg(pdata)` and jump to `adjust_link`; if `pdata->phy.link` is non-zero and `xgbe_phy_status_result(pdata)` returns `true` (mode changed), return immediately without `netif_carrier_on()` or `xgbe_phy_adjust_link()`. In `xgbe_phy_adjust_link()`, copy `pdata->phy.tx/rx_pause` to `pdata->tx/rx_pause` before `config_tx/rx_flow_control()`. [F58, F70, F78]
- In `xgbe_an73_state_machine()`, terminal states (`pdata->an_state >= XGBE_AN_COMPLETE`) must copy `an_state` to `pdata->an_result` and reset `an_state = XGBE_AN_READY`, `kr_state = XGBE_RX_BPA`, `kx_state = XGBE_RX_BPA`, and `an_start = 0`. In `xgbe_an73_incompat_link()`, set the current mode's Rx state to `XGBE_RX_ERROR` and return `XGBE_AN_NO_LINK` unless the alternate mode is advertised and its Rx state is `XGBE_RX_BPA`. [F68, F106]
- `xgbe_config_mmc()` sets `MMC_CR.ROR = 1` (reset-on-read), so MMC readers must accumulate (`+=`) into `pdata->mmc_stats` (and `xgbe_read_mmc_stats()` must freeze `MMC_CR.MCF`). In `xgbe_mmc_read()`, `MMC_RXRUNTERROR`, `MMC_RXJABBERERROR`, `MMC_RXUNDERSIZE_G`, `MMC_RXOVERSIZE_G`, and `MMC_RXWATCHDOGERROR` are always 32-bit, whereas `MMC_*OCTETCOUNT_G*_LO` are always 64-bit. All `xgbe_gstring_stats[]` fields must be `u64`, and `xgbe_get_strings()`, `xgbe_get_ethtool_stats()`, and `xgbe_get_sset_count()` must stay in sync. [F75, F76, F91, F137]

## Synchronization

- In `xgbe_open()` and `xgbe_start()`, workqueues (`dev_workqueue`, `an_workqueue`), work items, and `xgbe_napi_enable(pdata, 1)` must be ready before `xgbe_request_irqs()` and `phy_if->phy_start()`. In `xgbe_stop()`, call `netif_carrier_off()` right after `netif_tx_stop_all_queues()`, and finish `xgbe_stop_timers()`, `flush_workqueue(pdata->dev_workqueue)`, `hw_if->disable_tx/rx()`, `phy_if->phy_stop()`, `xgbe_free_irqs()`, and `xgbe_napi_disable(pdata, 1)` before unmapping/freeing rings. Queue `stopdev_work` and `restart_work` on `system_wq` (never `dev_workqueue`) and take `rtnl_lock()`. [F20, F21, F23, F156]
- In `xgbe_dev_xmit()`, set `TX_NORMAL_DESC3_OWN` on subsequent descriptors before `dma_wmb()` and setting `OWN` on `start_index`, then `smp_wmb()` before `ring->cur = cur_index + 1` and `wmb()` before `DMA_CH_TDTR_LO`. In `xgbe_rx_desc_reset()` and `xgbe_rx_refresh()`, use `dma_wmb()` before setting `RX_NORMAL_DESC3.OWN`, then `dma_wmb()` and `wmb()` before `DMA_CH_RDTR_LO`; `xgbe_dev_read()` must run `dma_rmb()` after seeing `OWN` cleared. [F32, F161]
- When `pdata->per_channel_irq` is set and `pdata->channel_irq_mode == 0`, `xgbe_dma_isr()` and `xgbe_tx_timer()` must use `disable_irq_nosync(channel->dma_irq)` (never `disable_irq()`), paired with `enable_irq()` in `xgbe_one_poll()`. `xgbe_isr_bh_work()` and `xgbe_tx_timer()` must call `__napi_schedule()`, never `__napi_schedule_irqoff()`. [F148, F159]
- Hold `spin_lock_irqsave(&pdata->xpcs_lock, flags)` in `xgbe_read/write_mmd_regs_v1/v2()` across window-select and data MMIO. Hold `pdata->an_mutex` in `__xgbe_phy_config_aneg()` (with `disable_irq`/`enable_irq(pdata->an_irq)` around state resets) and `xgbe_an_state_machine()`, and call `flush_work(&pdata->an_work)` before `queue_work()` in `xgbe_an_irq_work()`. Hold `pdata->i2c_mutex` in `xgbe_i2c_xfer()` and `pdata->rss_mutex` (process context) in `xgbe_write_rss_reg()`. [F24, F150, F152, F153, F154]

## Object Lifetimes

- Unwind resources in reverse order: in `xgbe_pci_probe()` (which must `pci_dev_put(rdev)` before any `goto err_pci_enable`) and `xgbe_pci_remove()`, call `xgbe_deconfig_netdev()`, `pci_free_irq_vectors()`, then `xgbe_free_pdata()`; in `xgbe_open()` / `xgbe_close()`, call `xgbe_stop()`, `xgbe_free_memory()` (`free_ring_resources()` before `xgbe_free_channels()`), `clk_disable_unprepare(ptpclk)`, `clk_disable_unprepare(sysclk)`, `destroy_workqueue(an_workqueue)`, then `destroy_workqueue(dev_workqueue)`. [F2, F3, F5, F6]
- `xgbe_start()` and `xgbe_stop()` must maintain `XGBE_STOPPED` in `pdata->dev_state` and unwind `phy_start`, IRQs, NAPI, and `hw_if->init` in reverse order, explicitly calling `devm_free_irq()` and `irq_set_affinity_hint(..., NULL)` in `xgbe_free_irqs()`, `xgbe_phy_stop()`, and `xgbe_i2c_stop()`. Clear `pdata->channel[i] = NULL` and `channel_count = 0` in `xgbe_free_channels()`, null ring pointers in `xgbe_free_ring()`, and restore `set_dev_node(dev, cur_node)` in `xgbe_dma_alloc_node()`. [F7, F8, F9, F11, F19]
- `xgbe_set_buffer_data()` takes `get_page(pa->pages)` in `bd->pa` and moves `*pa` to `bd->pa_unmap` on the last slice; `xgbe_unmap_rdata()` must `put_page()` on both, and `xgbe_rx_poll()` must set `rdata->rx.buf.pa.pages = NULL` upon `skb_add_rx_frag()`. Unmap Tx buffers with `dma_unmap_page()` when `mapped_as_page == 1` and `dma_unmap_single()` otherwise. Under `pdata->tstamp_lock` in `xgbe_prep_tx_tstamp()`, clear the PTP bit if `tx_tstamp_skb` is busy or save `skb_get(skb)` for `xgbe_tx_tstamp()`. [F15, F165, F173, F176]

## API Contracts

- `xgbe_tx_complete()` returns `1` when CPU-owned (`!OWN`) and `0` when DMA-owned, whereas `xgbe_dev_read()` returns `0` when CPU-owned and `1` when DMA-owned. Unlike `XGMAC_IOWRITE_BITS()` (which shifts `_val` by `_INDEX`), `XMDIO_WRITE_BITS()` and `XMDIO_READ_BITS()` take a pre-shifted `_mask` and do not shift `_val` or the return value. [F38, F50]
- `xgbe_alloc_pages()` runs in NAPI (`xgbe_rx_refresh()`) and must use `GFP_ATOMIC`; `xgbe_create_skb()` and `xgbe_rx_poll()` must call `dma_sync_single_range_for_cpu(..., DMA_FROM_DEVICE)` on `rdata->rx.hdr` and `rdata->rx.buf` before reading. `xgbe_rx_poll()` counts only completed packets toward `budget`, and `xgbe_one/all_poll()` must call `napi_complete_done()` only when `processed < budget`. [F149, F164, F172]
- In `xgbe_prep_tso()`, call `skb_cow_head(skb, 0)` and adjust `packet->tx_packets` and `tx_bytes` for `gso_segs`. Balance `netdev_tx_sent_queue()` in `xgbe_xmit()` with `netdev_tx_completed_queue()` in `xgbe_tx_poll()` and `netdev_tx_reset_queue()` in `xgbe_stop()`. If `xgbe_maybe_stop_tx_queue()` stops a queue while `ring->tx.xmit_more` is set, it must call `hw_if.tx_start_xmit()`. [F169, F170, F171]
- `phy_impl.link_status` implementations must set `*an_restart = 0` before any non-negative return. `xgbe_an37_init()` must clear `MDIO_AN_CTRL1_ENABLE` and `xgbe_an37_set()` must set `XGBE_VEND2_MAC_AUTO_SW`; `xgbe_check_link_timeout()` in `XGBE_MODE_KR` must wait `XGBE_AN_MS_TIMEOUT` from `kr_start_time` before restarting AN. [F47, F143, F144]
- In `xgbe_config_dcb_pfc()`, when `!test_bit(XGBE_DOWN, &pdata->dev_state)`, stop Tx queues and call `hw_if.disable_rx()` before `xgbe_config_rx_fifo_size()` and `xgbe_config_flow_control()`. `xgbe_exit()` must call `__xgbe_exit()` twice. In `xgbe_i2c_abort()`, set `IC_ENABLE.EN = 1` before `ABORT = 1`, and disable I2C before writing `IC_TAR`. [F71, F73, F131]

## Error Handling

- Check `IS_ERR()` on `xgbe_alloc_pdata()` and `ptp_clock_register()` (before assigning `pdata->ptp_clock`). Store `XMDIO_READ()`, `phy_impl.link_status()`, and `xgbe_read_ext_mii_regs()` in a signed `int` and check `< 0`. Return `-ENOMEM` explicitly when `dma_mapping_error()` is true in `xgbe_alloc_pages()`, and check `rx_frames`/`tx_frames != 0` before `%` in `xgbe_rx_desc_reset()` and `xgbe_dev_xmit()`. [F34, F35, F36, F39, F44, F113]

## External Contracts

- `xgbe_dcb_setdcbx()` returns `u8` (`0` success, `1` failure). `xgbe_get_link_ksettings()` must report `SPEED_UNKNOWN`/`DUPLEX_UNKNOWN` when `!netif_carrier_ok(netdev)`. `xgbe_common_read/write()` in debugfs must check `*ppos != 0`, validate `count`, and NUL-terminate `workarea[len]`. [F40, F166, F180]

## Known Pitfalls

- `GET_BITS*`/`SET_BITS*` use `(0x1 << (_width)) - 1` on a 32-bit signed `int`, requiring `_WIDTH < 31`. Timeout loops testing `if (!count)` in `__xgbe_exit()`, `xgbe_flush_tx_queues()`, `xgbe_update_tstamp_addend()`, and `xgbe_set_tstamp_time()` must pre-decrement (`while (--count && ...)`), and `jiffies` checks must use `time_before()`/`time_after()`. [F96, F112, F118]
- In `xgbe_dev_read()`, `etlt == 0x09` means a stripped C-TAG VLAN when `!err || !etlt`, but a VXLAN checksum error when `err && etlt && tnp`; L4 `switch (l34t)` cases must end with `break`. Widen 32-bit PTP seconds to `u64` before `* NSEC_PER_SEC`, and use `div_u64()` in `xgbe_init_ptp()`. Use `xgbe_change_mode()` for `XGBE_MODE_SFI` in `xgbe_phy_config_fixed()`, and verify `netdev->netdev_ops == xgbe_get_netdev_ops()` in `xgbe_netdev_event()`. [F69, F97, F99, F109, F111, F128]
