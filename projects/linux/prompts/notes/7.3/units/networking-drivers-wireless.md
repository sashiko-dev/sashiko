# NETWORKING DRIVERS (WIRELESS)

This component contains three wireless networking drivers: the `at76c50x-usb` hardware USB driver for Atmel AT76C503/AT76C505 802.11b devices, the `mac80211_hwsim` software radio simulator for testing `mac80211` and `cfg80211`, and the `virt_wifi` RTNL link wrapper that presents an Ethernet `net_device` as a virtual `cfg80211` wireless station.

## Architecture & Data Flow

- In `at76_set_card_command`, `cmd_buf->size` must be initialized with `cpu_to_le16(buf_size)` before `memcpy(cmd_buf->data, buf, buf_size)`, because `struct at76_command::data` is annotated with `__counted_by_le(size)`. [F93]
- `at76_alloc_urbs()` must allocate `priv->bulk_out_buffer` with `sizeof(struct at76_tx_buffer) + MAX_PADDING_SIZE` bytes because `at76_mac80211_tx()` adds up to `MAX_PADDING_SIZE` (53) bytes of padding from `at76_calc_padding(skb->len)` to `AT76_TX_HDRLEN + skb->len` when submitting `priv->tx_urb`. [F114]
- Every `enum board_type` value (1-based `BOARD_503_ISL3861` through `BOARD_505AMX`) must have a matching entry at that index in `firmwares[]` (with index 0 reserved as a dummy entry), because `at76_load_firmware` indexes `&firmwares[board_type]` directly without a bounds check. [F64]
- In `at76_get_reg_domain`, `fd_tab[]` must keep its fallback unknown-domain entry as the last element and the lookup loop must stop at `ARRAY_SIZE(fd_tab) - 1`, so an unrecognized `code` returns `&fd_tab[ARRAY_SIZE(fd_tab) - 1]` instead of out-of-bounds `&fd_tab[ARRAY_SIZE(fd_tab)]`. [F65]
- In `at76_usbdfu_download`, `STATE_DFU_DOWNLOAD_SYNC` and `STATE_DFU_MANIFEST_SYNC` must update `*dfu_state = dfu_stat_buf->state` and set `need_dfu_state = 0`, whereas `STATE_DFU_DOWNLOAD_BUSY` and `STATE_DFU_IDLE` (including `STATE_DFU_DOWNLOAD_IDLE` fallthrough) must set `need_dfu_state = 1`. [F79]
- When `at76_startup_device` reinitializes the adapter on start, it must clear transient session state (`eth_zero_addr(priv->bssid)` and `priv->scanning = false`) after `CMD_STARTUP` while applying preserved configuration (`priv->channel`, `priv->wep_*`, thresholds, preamble, and `priv->pm_mode`). [F58]
- In `at76_wait_completion`, command polling loop termination against `timeout` (`jiffies + CMD_COMPLETION_TIMEOUT`) must use `time_after(jiffies, timeout)` rather than direct relational comparison on `jiffies`. [F92]
- `virt_wifi_event` must verify `netif_is_virt_wifi_dev(lower_dev)` (which checks `rcu_access_pointer(dev->rx_handler) == virt_wifi_rx_handler`) before dereferencing `lower_dev->rx_handler_data` as `struct virt_wifi_netdev_priv *`. [F105]
- In `virt_wifi_newlink`, if `tb[IFLA_MTU]` is provided, `dev->mtu > priv->lowerdev->mtu` must be rejected with `-EINVAL` (and otherwise defaulted to `priv->lowerdev->mtu`), because `virt_wifi_start_xmit` transmits upper-device `skb`s directly on `priv->lowerdev` without fragmentation. [F75]

## Synchronization

- `at76_mac80211_stop()` must cancel `priv->dwork_hw_scan`, `priv->work_join_bssid`, and `priv->work_set_promisc` before acquiring `priv->mtx`, because `at76_dwork_hw_scan()`, `at76_work_join_bssid()`, and `at76_work_set_promisc()` all acquire `priv->mtx`. [F109]
- All callers that populate `priv->mib_buf` and invoke `at76_set_mib(priv, &priv->mib_buf)` must hold `priv->mtx`. Atomic `ieee80211_ops` callbacks like `at76_configure_filter()` must not sleep, lock `priv->mtx`, or call `at76_set_mib` directly, instead queuing `priv->work_set_promisc`, and `at76_configure_filter()` must set `*total_flags` to `AT76_SUPPORTED_FILTERS` before returning early on `priv->device_unplugged`. [F25, F139]
- In `at76_load_firmware`, `fw_mutex` must be held continuously across checking `fwe->loaded`, calling `request_firmware(&fwe->fw, ...)`, validating `struct at76_fw_header`, populating `fwe->intfw` and `fwe->extfw` in `firmwares[board_type]`, and setting `fwe->loaded = 1`. [F26]
- In `virt_wifi`, `virt_wifi_scan_result` and `virt_wifi_connect_complete` must never acquire `rtnl_lock()`, because `virt_wifi_cancel_scan` and `virt_wifi_cancel_connect` invoke `cancel_delayed_work_sync` on `priv->scan_result` and `priv->connect` while `rtnl_lock()` is held. [F133]
- `virt_wifi_rx_handler` executes in an RCU read-side packet RX critical section from `netif_receive_skb`, so it must dereference `skb->dev->rx_handler_data` with `rcu_dereference`, pass `GFP_ATOMIC` to `skb_share_check`, and never sleep. [F132]

## Object Lifetimes

- Because `at76_delete_device` frees `struct at76_priv` via `ieee80211_free_hw(priv->hw)`, `at76_disconnect` must not dereference `priv` (such as `priv->udev` or `priv->hw->wiphy`) after calling `at76_delete_device(priv)` and must obtain the `usb_device` from `interface_to_usbdev(interface)` for `usb_put_dev`. [F1]
- In `at76_delete_device`, `priv->device_unplugged = 1` must be set and `tasklet_kill(&priv->rx_tasklet)` plus `ieee80211_unregister_hw(priv->hw)` must complete before `priv->tx_urb` and `priv->rx_urb` are killed and freed, `priv->bulk_out_buffer` and `priv->rx_skb` are freed, and `ieee80211_free_hw(priv->hw)` is called. [F19]
- In `at76_rx_tasklet`, handing `priv->rx_skb` to `ieee80211_rx_irqsafe` transfers SKB ownership to mac80211, so `priv->rx_skb` must be cleared to `NULL` before calling `at76_submit_rx_urb(priv)` (which otherwise reuses a non-NULL `priv->rx_skb`) or `at76_delete_device` (which calls `kfree_skb(priv->rx_skb)`). [F2]
- `at76_mac80211_tx` takes ownership of `skb` from mac80211: early return paths before `priv->tx_skb = skb` must free `skb` via `dev_kfree_skb_any(skb)`, whereas once `priv->tx_urb` is submitted, `at76_mac80211_tx_callback` must pass `priv->tx_skb` to `ieee80211_tx_status_irqsafe` and reset `priv->tx_skb = NULL` before `ieee80211_wake_queues`. [F3]
- In `at76_mod_init()`, `led_trigger_register_simple()` must only be called when `usb_register(&at76_driver)` succeeds, and `at76_mod_exit()` must call `usb_deregister(&at76_driver)` before releasing `firmwares` entries and calling `led_trigger_unregister_simple()`. [F106]
- In `virt_wifi`, `dev->ieee80211_ptr` must not be freed in `virt_wifi_dellink`; once `virt_wifi_newlink` sets `dev->priv_destructor = virt_wifi_net_device_destructor`, freeing `dev->ieee80211_ptr` is deferred to `virt_wifi_net_device_destructor` after `dellink` so `nl80211` can react to the device deletion. Broken by: calling `kfree(dev->ieee80211_ptr)` in `virt_wifi_dellink` or setting `dev->priv_destructor` before the `free_wireless_dev` error path in `virt_wifi_newlink`. [F12]
- Because all `virt_wifi` netdevs share `common_wiphy`, when `virt_wifi_cancel_scan` or `virt_wifi_cancel_connect` cancels delayed work (`priv->scan_result` or `priv->connect`) before completion, any pending request must be completed via `cfg80211_scan_done` or `cfg80211_connect_result` (when `cancel_delayed_work_sync(&priv->connect)` returns `true`), and any path calling `cfg80211_scan_done` (`virt_wifi_scan_result` or `virt_wifi_cancel_scan`) must immediately set `priv->scan_request = NULL`. [F13, F60]
- In `virt_wifi_cleanup_module` and the `virt_wifi_init_module` rollback path, `rtnl_link_unregister(&virt_wifi_link_ops)` must run before `virt_wifi_destroy_wiphy(common_wiphy)` and `unregister_netdevice_notifier(&virt_wifi_notifier)` so all `virt_wifi` netdevs depending on `common_wiphy` are deleted before `common_wiphy` is unregistered and freed. [F14]

## API Contracts

- In `at76c50x-usb.c`, `at76_get_cmd_status()` and `at76_wait_completion()` return negative errnos on USB/timeout failure and non-negative firmware status codes (`CMD_STATUS_*`) otherwise, where success is `CMD_STATUS_COMPLETE` (`0x01`) rather than `0` (`CMD_STATUS_IDLE`) and firmware errors like `CMD_STATUS_SCAN_FAILED` (`0xf0`) are positive; callers must check `ret != CMD_STATUS_COMPLETE`. [F38]
- `at76_set_mib()` and its wrappers (`at76_set_pm_mode()`, `at76_set_preamble()`, `at76_set_frag()`, `at76_set_rts()`, `at76_set_autorate_fallback()`, and `at76_set_wep()`) return `CMD_STATUS_COMPLETE` (`1`) on success and `-EIO` or a negative USB errno on failure, so callers must check `ret < 0` rather than `ret != 0`. [F39]
- `at76_get_mib()`, `at76_get_hw_config()`, and `at76_set_card_command()` return the positive number of USB control bytes transferred on success and a negative errno on failure, so callers must check `ret < 0` for errors rather than testing for non-zero. [F40]
- `at76_set_radio()` returns `< 0` on USB command error, `0` when `priv->radio_on` already matches `enable` (no command sent), and `1` when `CMD_RADIO_ON` or `CMD_RADIO_OFF` was sent, so callers like `at76_startup_device()` must only call `at76_wait_completion()` when `at76_set_radio()` returns `1`. [F41]
- Callers of `at76_set_mib()` must set `priv->mib_buf.size` to the exact byte size of the populated `priv->mib_buf.data` union member and `priv->mib_buf.index` to the target field's `offsetof()` within the MIB structure, because `at76_set_mib()` sends `offsetof(struct set_mib_buffer, data) + buf->size` bytes. [F45]
- All transfer buffers passed to `usb_control_msg` in `at76c50x-usb` (including 1-byte buffers in `at76_get_op_mode` and `at76_usbdfu_download`, status buffers in `at76_get_cmd_status`, and firmware blocks in `at76_load_external_fw`) must be heap-allocated via `kmalloc` rather than stack variables or `request_firmware` vmalloc pointers (`fwe->intfw`, `fwe->extfw`). [F124]
- `at76_load_firmware` caches loaded firmware in the global `firmwares[board_type].fw` table under `fw_mutex` and returns a borrowed `struct fwentry *`; callers (`at76_probe`, `at76_disconnect`) must not call `release_firmware` on it, as all `firmwares[i].fw` entries are released only in `at76_mod_exit` after `usb_deregister(&at76_driver)`. [F4]
- `at76_rx_tasklet` must call `skb_pull(priv->rx_skb, AT76_RX_HDRLEN)` and `skb_trim(priv->rx_skb, le16_to_cpu(buf->wlength))` before calling `at76_guess_freq(priv)`, because `at76_guess_freq` casts `priv->rx_skb->data` directly to `struct ieee80211_hdr *` and uses `priv->rx_skb->len` as the 802.11 frame length. [F97]
- When `at76_mac80211_tx()` receives an `IEEE80211_STYPE_AUTH` frame whose `mgmt->bssid` differs from `priv->bssid`, it must copy `mgmt->bssid` into `priv->bssid`, queue `priv->work_join_bssid` to send `CMD_JOIN` via `at76_join()`, free the SKB, and return without submitting `priv->tx_urb`. [F115]
- In `at76_load_internal_fw()`, when `at76_is_505a(fwe->board_type)` is true (`BOARD_505A`, `BOARD_505AMX`), the driver must skip `at76_remap()` and pass a `2 * HZ` `manifest_sync_timeout` to `at76_usbdfu_download()` instead of `0`. [F110]
- In `virt_wifi_rx_handler`, `skb_share_check(skb, GFP_ATOMIC)` consumes the original `skb` when cloning or failing; if it returns `NULL`, `virt_wifi_rx_handler` must return `RX_HANDLER_CONSUMED`, and if it succeeds, `*pskb = skb` must be updated before returning `RX_HANDLER_ANOTHER`. [F15]
- In `virt_wifi_connect_complete()`, `priv->connect_requested_ssid` and `priv->connect_requested_ssid_len` must be verified against `VIRT_WIFI_SSID` and `VIRT_WIFI_SSID_LEN` before passing `WLAN_STATUS_SUCCESS` to `cfg80211_connect_result()`, because `cfg80211` looks up the BSS by SSID and triggers `WARN_ON` if no matching BSS exists. [F134]
- Although `virt_wifi_make_wiphy()` sets `wiphy->signal_type = CFG80211_SIGNAL_TYPE_MBM` and `virt_wifi_inform_bss()` passes signal strength in mBm via `DBM_TO_MBM(-50)`, `virt_wifi_get_station()` must populate `sinfo->signal` in dBm (`-50`) and `sinfo->txrate.legacy` in 100 kbit/s units (`10`). [F47]
- In `virt_wifi_newlink()`, the lower `net_device` specified by `IFLA_LINK` must be resolved in `rtnl_newlink_link_net(params)` via `__dev_get_by_index()`, rather than in `dev_net(dev)`, to support cross-netns RTNL link creation. [F138]

## Error Handling

- When `at76_probe()` downloads internal DFU firmware via `at76_load_internal_fw()`, it returns `0` before allocating `struct at76_priv` or calling `usb_set_intfdata()`, so `at76_disconnect()` must check `if (!priv) return;` after `usb_get_intfdata(interface)`. [F43]

## External Contracts

- In `at76_load_external_fw`, the block download loop must be a `do { ... } while (bsize > 0)` loop rather than `while (size > 0)` so that after `size` reaches 0, one final iteration executes with `bsize == 0` to send an empty block via `at76_load_ext_fw_block` before terminating. [F84]

## Known Pitfalls

- In `at76_load_firmware`, `struct at76_fw_header *fwh` must be cast to a byte pointer (`char *` or `u8 *`) before adding `str_offset`, `int_fw_offset`, or `ext_fw_offset`, because those header fields are byte offsets from the start of the firmware image. [F96]
- Before downloading external firmware in `at76_probe()`, `at76_get_mib(udev, MIB_FW_VERSION, ...)` must only be called if `fwe->fw_version.major > 0 || fwe->fw_version.minor >= 100` or `op_mode == OPMODE_NORMAL_NIC_WITH_FLASH`; older firmwares without flash (`OPMODE_NORMAL_NIC_WITHOUT_FLASH` with version `< 0.100`) must set `need_ext_fw = 1` without querying the MIB. [F112]
- In `virt_wifi_get_station`, flags in the 64-bit `sinfo->filled` mask must be constructed with `BIT_ULL(NL80211_STA_INFO_*)` rather than `BIT()`, because `struct station_info::filled` is a `u64` whose `enum nl80211_sta_info` shifts can exceed 31 bits. [F91]
- In `virt_wifi_inform_bss`, converting the 64-bit nanosecond timestamp from `ktime_get_boottime_ns()` into a microsecond `u64` TSF must use `div_u64()` rather than the `/` operator. [F90]
