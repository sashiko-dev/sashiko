# X86 MCE INFRASTRUCTURE

The x86 Machine Check Exception (MCE) infrastructure handles hardware error detection, severity grading, recovery, polling, thresholding, and logging across Intel, AMD, Hygon, Zhaoxin, and legacy x86 processors. It processes synchronous `#MC` exceptions (including broadcast Monarch/Subject rendezvous and local MCEs), asynchronous APIC interrupts for corrected error thresholding and deferred errors, and periodic bank polling, queuing records locklessly via a `gen_pool`-backed `llist` for process-context dispatch to decoder chains, APEI/ERST, `memory_failure()`, `/dev/mcelog`, sysfs, and debugfs injection.

## Architecture & Data Flow
- In `noinstr` `#MC` functions (`do_machine_check()`, `mce_start()`, `mce_end()`, `mce_panic()`, `mce_gather_info()`, `mce_rdmsrq()`, `mce_wrmsrq()`, `error_context()`), calls to instrumented helpers must be wrapped in `instrumentation_begin()`/`instrumentation_end()`, and code outside them must use `raw_atomic_*` and `arch_*` bitops. `mce_rdmsrq()` and `mce_wrmsrq()` must annotate inline `rdmsr`/`wrmsr` with `_ASM_EXTABLE_TYPE(1b, 2b, EX_TYPE_RDMSR_IN_MCE)` and `EX_TYPE_WRMSR_IN_MCE` so `#GP` faults invoke `ex_handler_msr_mce()` and panic [F152, F153].
- In `__mc_scan_banks()`, `toclear` must be cleared at the start of each bank iteration and set only after skipping `MCE_KEEP_SEVERITY` and `MCE_UCNA_SEVERITY` (when `!no_way_out`), sparing corrected/UCNA errors for `machine_check_poll()`. At the end of `__mc_scan_banks()`, `*err = *final` must copy the highest-severity record to the caller's stack `err` before `mce_end()` runs, because `mce_reign()` zeroes `per_cpu(hw_errs_seen, cpu)` (`*final`) across all CPUs [F91, F92].
- When `machine_check_poll()` runs without `MCP_UC`, `should_log_poll_error()` must reject uncorrected errors (`MCI_STATUS_UC`) unless `mca_cfg.ser` is set and `ser_should_log_poll_error()` matches an unenabled (`!MCI_STATUS_EN`) or UCNA (`!MCI_STATUS_PCC && !MCI_STATUS_S`) error [F89].
- In `severities[]`, narrower rules (`MCACOD_DATA`/`MCACOD_INSTR` and `MCG_STATUS_SEAM_NR`-qualified `KERNEL` rules) must precede broader catch-all rules (`MCI_UC_SAR` and `MCI_STATUS_UC`), the table must end with an unconditional catch-all (`BITSET(0)`), and `BANK_RANGE(l, h)` rules require `bank_lo > 0` because `mce_severity_intel()` tests `if (s->bank_lo && ...)`. In `error_context()`, `is_copy_from_user(regs)` must be evaluated before switching on `fixup_type` from `ex_get_fixup_type(m->ip)` [F77, F87, F88].
- `queue_task_work()` must only populate `current->mce_addr`, `mce_kflags`, `mce_ripv`, `mce_whole_page`, and `mce_kill_me.func` and call `task_work_add()` when `++current->mce_count == 1`, and every `mce_kill_me` callback (`kill_me_now`, `kill_me_maybe`, `kill_me_never`) must reset `p->mce_count = 0` [F65].
- In `mcheck_cpu_init()`, `__mcheck_cpu_init_vendor()` must run after `__mcheck_cpu_cap_init()` sets `mce_banks_array` defaults (`ctl = -1ULL`, `init = true`) and before `__mcheck_cpu_init_prepare_banks()` writes `b->ctl` to `MCA_CTL` MSRs for banks with `b->init` set. When `mce_restart()` runs `mce_cpu_restart()` across all CPUs, it must call `mce_schedule_work()` afterward to drain records queued with `MCP_QUEUE_LOG` [F56, F120].
- Hardware bank counts from `MSR_IA32_MCG_CAP` (`cap & MCG_BANKCNT_MASK`) must be capped to `MAX_NR_BANKS` (64) before storing in `mce_num_banks` or indexing per-bank arrays/bitmaps. In `amd.c`, per-CPU `bank_map` must be manipulated as a `u64` using `BIT_ULL(bank)` rather than 32-bit `BIT(bank)` or `1 << bank` [F73, F102].
- In `smca_extract_err_addr()` and `mce_read_aux()`, the recoverable address LSB from `m->status`, `m->addr`, or `m->misc` must be masked with `0x3f` (0..63) before shifting `m->addr` or passing `lsb` to `GENMASK_ULL()`. On non-SMCA systems (`!mce_flags.smca`), `amd_mce_usable_address()` must evaluate bank 4 (`legacy_mce_is_memory_error(m)` returning `true`, any other `m->bank == 4` returning `false`) before testing `m->status & MCI_STATUS_POISON` [F93, F105].
- Every `enum smca_bank_types` value before `N_SMCA_BANK_TYPES` must have a non-NULL entry in `smca_names[]`, and `get_name()` on SMCA systems must fall back to formatting `"th_block_%u"` and `"th_bank_%u"` into `buf_mcatype` rather than returning `NULL`. `default_attrs[]` in `amd.c` must retain two trailing `NULL` entries at indices 2 and 3 because `allocate_threshold_blocks()` overwrites `default_attrs[2]` [F68, F78, F95].
- When arming `mce_timer` outside of storm mode (`mce_timer_fn()`, `mce_start_timer()`), `should_enable_timer(iv)` (`!mca_cfg.ignore_ce && iv`) must be checked before updating `mce_next_interval` and calling `__start_timer()`. In `mce_disable_cpu()`, `mce_reenable_cpu()`, and `mce_cpu_dead()`, `cmci_clear()`, `cmci_reenable()`, and `cmci_rediscover()` must only be called when `!cpuhp_tasks_frozen` [F55, F138].

## Synchronization
- `mce_log()` must not invoke `x86_mce_decoder_chain` or `printk()` directly; it must enqueue records locklessly via `mce_gen_pool_add()` (`gen_pool_alloc()` + `llist_add()` to `mce_event_llist`) and queue `mce_irq_work` so `mce_gen_pool_process()` runs the blocking decoder chain and `gen_pool_free()` in workqueue context [F33].
- In `mce_start()`, each CPU entering broadcast `#MC` rendezvous must update `global_nwo` via `raw_atomic_add()` before incrementing `mce_callin` via `raw_atomic_inc_return()`, and must issue `smp_rmb()` after waiting for `mce_callin == num_online_cpus()` before reading `global_nwo`. In `mce_end()`, Subject CPUs (`order > 1`) wait for `atomic_read(&mce_executing) != 0` and return without resetting global state, while the Monarch (`order == 1`) runs `mce_reign()` and resets `global_nwo`, `mce_callin`, and `mce_missing_cpus` before `barrier()` and `atomic_set(&mce_executing, 0)` [F26, F27].
- All read-modify-write operations on `MSR_IA32_MCx_CTL2(bank)` and updates to `mce_banks_owned` (`cmci_discover()`, `cmci_set_threshold()`, `cmci_clear()`, `cmci_disable_bank()`) must be serialized under `cmci_discover_lock`, and `cmci_set_threshold()` must preserve `MCI_CTL2_CMCI_EN`. When CMCI is unsupported or disabled on Intel/Zhaoxin, periodic polling must use `cmci_mc_poll_banks()` holding `cmci_poll_lock` around `machine_check_poll()` [F21, F134].
- In `threshold_create_bank()` and `mce_threshold_create_device()`, `bp[bank]` and per-CPU `threshold_banks` must only be assigned after all kobjects and `threshold_block` lists are initialized, and `mce_threshold_remove_device()` must clear `threshold_banks` to `NULL` before `__threshold_remove_device()` frees them [F17].
- In `mce_cpu_pre_down()`, `mce_disable_cpu()` and `timer_delete_sync(t)` must execute before `mce_threshold_remove_device(cpu)` and `mce_device_remove(cpu)`. `mce_timer_delete_all()` must never be called from IRQ/atomic context because it calls `timer_delete_sync()`, and sysfs callers (`mce_restart()`, `set_ignore_ce()`) must serialize under `mce_sysfs_mutex` [F23, F24].
- `mce_chrdev_read_mutex` must be held across all reads, writes, and resets of `mcelog->next`, `mcelog->entry[]`, and `mce_apei_read_done` in `dev_mce_log()` and `mce_chrdev_read()`, whereas `mcelog->flags` must be updated with atomic `set_bit()` (`< 32`) and consumed via 32-bit `xchg(&mcelog->flags, 0)` because `mce_chrdev_ioctl()` does not take the mutex [F22, F116].
- `inject_mce()` must clear `i->finished = 0` and issue `mb()` before writing `per_cpu(injectm, m->extcpu)`, and issue `mb()` before setting `i->finished = 1` last. `raise_mce()` must hold `mce_inject_mutex` and `cpus_read_lock()`, and pass `wait = 0` to `smp_call_function_many(mce_inject_cpumask, mce_irq_ipi, NULL, 0)`. In `do_inject()`, `cpus_read_lock()` and `cpu_online(cpu)` must guard `toggle_hw_mce_inject()`, `prepare_msrs()`, and `smp_call_function_single()` [F28, F29, F32].

## Object Lifetimes
- Once `kobject_init_and_add(&b->kobj, &threshold_ktype, ...)` is called on a `struct threshold_block`, `allocate_threshold_blocks()` and `threshold_remove_bank()` must free `b` solely via `kobject_put(&b->kobj)`, whereas a `struct threshold_bank` requires both `kobject_put(bank->kobj)` and `kfree(bank)`. `mce_device_remove()` must check `cpumask_test_cpu(cpu, mce_device_initialized)` before teardown and clear both `mce_device_initialized` and `per_cpu(mce_device, cpu)` after `device_unregister(dev)` [F3, F7].
- Both `mce_gen_pool_prepare_records()` and `mce_gen_pool_process()` must iterate the detached `mce_event_llist` chain with `llist_for_each_entry_safe()`, and `mce_gen_pool_process()` must return each dequeued node to `mce_evt_pool` via `gen_pool_free()` after invoking `x86_mce_decoder_chain` [F9, F99].
- When `__cmci_disable_bank()` releases a bank with `CMCI_STORM_THRESHOLD`, it must call `cmci_storm_end(bank)`, and when `cmci_claim_bank()` claims a bank with `CMCI_STORM_THRESHOLD`, it must call `mce_inherit_storm(bank)` and `cmci_storm_begin(bank)` [F11].
- `inject_exit()` must unregister `inject_nb` and `mce_raise_notify` and remove `dfs_inj` before `free_cpumask_var(mce_inject_cpumask)`. Cross-CPU IPI calls passing stack pointers—`smp_call_function_single(b->cpu, threshold_restart_block, &tr, 1)` and `on_each_cpu(__mce_disable_bank, &bank, 1)`—must pass `wait = 1` [F12, F118].

## API Contracts
- `mce_severity()`, `error_context()`, and `is_copy_from_user()` accept nullable `struct pt_regs *regs` and `char **msg`, so neither may be dereferenced without a NULL check. `mce_severity_amd()` only writes `*msg` when `panic_msg` is non-NULL, so callers passing `&msg` (`do_machine_check()`, `mce_reign()`, `mce_no_way_out()`) must initialize `msg` beforehand. Before calling `mce_severity()` or `mce_panic()` during a bank scan, `m->bank` and `m->status` must be populated on `struct mce` [F40, F41, F42].
- In `uc_decode_notifier()`, `kill_me_maybe()`, and `kill_me_never()`, `set_mce_nospec(pfn)` must only be called when `memory_failure()` returns `0`, and `pfn` must be computed after masking `addr` with `MCI_ADDR_PHYSADDR` (`(addr & MCI_ADDR_PHYSADDR) >> PAGE_SHIFT`) [F39].
- `smca_get_bank_type()` returns the sentinel `N_SMCA_BANK_TYPES` (not a negative errno) when `bank >= MAX_NR_BANKS` or `smca_banks[bank].hwid` is `NULL`, and callers (`get_name()`, `smca_get_name()`) must check `bank_type < N_SMCA_BANK_TYPES` before indexing `smca_names` or `smca_bank_counts` [F36].
- `msr_to_offset()` must only return byte offsets of 64-bit (`__u64`) fields within `struct mce` or `-1` on mismatch, and `mce_rdmsrq()`/`mce_wrmsrq()` must store its result in a signed `int` and check `offset >= 0` before casting `(char *)this_cpu_ptr(&injectm) + offset` to `u64 *` [F37, F109].
- `MSR_IA32_MCG_EXT_CTL` must only be accessed after `lmce_supported()` returns `true`. In `cmci_claim_bank()`, after writing `MCI_CTL2_CMCI_EN` to `MSR_IA32_MCx_CTL2(bank)`, the MSR must be read back to verify `MCI_CTL2_CMCI_EN` stuck before adding the bank to `mce_banks_owned` or clearing it from `mce_poll_banks`. Writing read-only MCA registers on AMD CPUs requires setting `McStatusWrEn` (`BIT(18)` in `MSR_K7_HWCR`) beforehand and restoring it afterward [F126, F130, F133].
- Userspace MCE injection entry points (`mce_chrdev_write()`, `inj_extcpu_set()`) must verify the target CPU is within bounds and `cpu_online()` before indexing `per_cpu(injectm, ...)` or invoking cross-CPU helpers. `inj_bank_set()` must reject `val >= (cap & MCG_BANKCNT_MASK)` read on `m->extcpu` (and on SMCA, reject non-SW injections when `MSR_AMD64_SMCA_MCx_IPID(val) == 0`). `flags_write()` must reject `!cnt` and `cnt > MAX_FLAG_OPT_SIZE` before writing `buf[cnt - 1] = 0` [F70, F84, F85].

## Error Handling
- In `kill_me_maybe()`, `-EHWPOISON` and `-EOPNOTSUPP` from `memory_failure()` must be treated as non-fatal handled outcomes that return without calling `kill_me_now()`, whereas any other non-zero return must fall through to `kill_me_now()` to deliver `SIGBUS` [F38].
- `apei_read_mce()` returns `sizeof(struct mce)` on a valid read, `0` when no records remain, and a negative errno on ERST failure (jumping to `retry:` on `-ENOENT` from `erst_read_record()`, and always exiting through `out:` to call `erst_get_record_id_end()`). `__mce_read_apei()` translates `-ENODEV` from `apei_read_mce()` into `0` without advancing `*ubuf`, so `mce_chrdev_read()` must check both `err` and `buf != ubuf` [F34, F35, F98].
- `threshold_create_bank()` requires `this_cpu_read(mce_device)` to be non-NULL (`-ENODEV` otherwise), so `mce_cpu_online()` must call `mce_device_create(cpu)` before `mce_threshold_create_device(cpu)`, and `mce_cpu_pre_down()` must call `mce_threshold_remove_device(cpu)` before `mce_device_remove(cpu)` [F47].
- Model-specific non-architectural MSRs configured during CPU init (`MSR_ERROR_CONTROL` in `intel_imc_init()`) must be accessed with `rdmsrq_safe()`/`wrmsrq_safe()`. Hot-path MCE logging and notification (`mce_gen_pool_add()`, `mce_notify_irq()`, `print_mce()`) must rate-limit console messages and never use `WARN_ON()` [F127, F165].

## External Contracts
- Existing field offsets in `struct mce` and `struct mce_hw_err` must not be changed: vendor-specific fields must be appended only to `struct mce_hw_err::vendor`, and new shared fields in `struct mce` only at the end. `__print_mce()` must preserve existing `HW_ERR` field names and ordering for `mcelog --ascii` parsers. `dev-mcelog.c` `mce_chrdev_ioctl()` and `mce_chrdev_write()` must require `capable(CAP_SYS_ADMIN)` [F81, F82, F161].

## Known Pitfalls
- Both `machine_check_poll()` and `__mc_scan_banks()` must reset `m->misc = 0`, `m->addr = 0`, and `m->bank = i` on every bank-loop iteration before calling `mce_read_aux()`, which only writes `m->misc` and `m->addr` when `MCI_STATUS_MISCV` or `MCI_STATUS_ADDRV` is set. `machine_check_poll()` must only clear per-bank `MCA_STATUS` registers via `clear_bank()` and never clear `MSR_IA32_MCG_STATUS`. `mce_prep_record_common()` must use `__ktime_get_real_seconds()` instead of `ktime_get_real_seconds()` because it runs in `#MC` context [F90, F136, F139].
- Because `mce_bank_devs` is a single global array registered on every per-CPU `mce_device`, sysfs handlers `show_bank()` and `set_bank()` must index `per_cpu(mce_banks_array, s->id)` and `per_cpu(mce_num_banks, s->id)` using `s->id` rather than `smp_processor_id()`. In `intel_apply_cpu_quirks()`, bank 0 on CPUs with `c->x86_vfm < INTEL_NEHALEM_EP` must be quirked by setting `mce_banks_array[0].init = false` rather than `ctl = 0` so polling and `#MC` scans still read bank 0 [F63, F129].
- In `get_block_address()`, SMCA block 0 maps to `MSR_AMD64_SMCA_MCx_MISC(bank)` (`MISC0`), whereas blocks `1` through `NR_BLOCKS - 1` must pass `block - 1` to `MSR_AMD64_SMCA_MCx_MISCy(bank, block - 1)` only when `low & MASK_BLKPTR_LO` is non-zero [F75].
- In `mce_start()` and `mce_end()`, 32-bit `mca_cfg.monarch_timeout` must be cast to `u64` before multiplying by `NSEC_PER_USEC`, and `mce_timed_out()` must check `(s64)*t < SPINUNIT` before subtracting `SPINUNIT`. In `mce_track_storm()`, non-storm history shift is `(delta + HZ) / HZ` and `history << shift` must only be evaluated when `shift < NUM_HISTORY_BITS` (64). `mce_gen_pool_create()` must size `mce_poolsz` as `mce_numrecords * (1 << order)` where `order = order_base_2(sizeof(struct mce_evt_llist))` [F103, F104, F111].
