# NETFILTER

The Netfilter subsystem provides packet filtering and mangling hooks, `nf_tables`, connection tracking, NAT, flowtables, `nf_queue`, `nf_log`, IP sets, and Xtables.

## Architecture & Data Flow

- `nf_tables` allocates registers in 4-byte (`NFT_REG32_SIZE`) units where `regs->verdict` aliases `regs->data[0..3]`. Sub-word or variable-length writes to `regs->data` must zero trailing bytes of the last 32-bit slot (`nft_reg_store8/16`, `nft_data_copy`, `strscpy_pad`, or `dest[len / NFT_REG32_SIZE] = 0` before `skb_copy_bits`/`memcpy`), and 64-bit accesses must use `nft_reg_load64()`/`nft_reg_store64()`. [F36, F49, F67, F175, F210]
- In `nf_tables` objects and `struct nft_set_ext`, a set bit in `genmask` marks the entry *inactive*, so active checks (`nft_is_active`, `nft_set_elem_active`) must test `!(genmask & mask)`. In `nft_pipapo_lookup` and `nft_pipapo_avx2_lookup`, dataplane lookups on `priv->match` must pass `0` as `genmask` because uncommitted entries exist only in `priv->clone`. [F79, F182]
- Every `nft_set` element struct (`nft_bitmap_elem`, `nft_rhash_elem`, `nft_hash_elem`, `nft_rbtree_elem`, `nft_pipapo_elem`) must place `struct nft_elem_priv priv` at offset 0 and `struct nft_set_ext ext` (aligned to `BITS_PER_LONG / 8` with `genmask` at offset 0 for atomic bitops in `nft_set_elem_dead`) as its last member, with `ops.elemsize = offsetof(..., ext)`. `nft_set_ext_add_length` must reject aligned `tmpl->len > U8_MAX`. [F92, F97, F114, F264]
- `__nft_set_elem_expired` must check both `nft_set_ext_exists(ext, NFT_SET_EXT_TIMEOUT)` and `nft_set_ext_timeout(ext)->timeout != 0` before `time_after_eq64`. Control-plane set operations (`.insert`, `.deactivate`, and sync GC `pipapo_gc`/`nft_rbtree_gc`) must check expiration against `nft_net_tstamp(net)`, whereas dataplane `.lookup`/`.update`/`.get` use live jiffies. [F93, F194]
- Before a multi-field PIPAPO lookup, `pipapo_resmap_init()` must set `res_map[0 .. m->f->bsize - 1]` to `ULONG_MAX` and (like `pipapo_resmap_init_avx2()`) zero `res_map[m->f->bsize .. m->bsize_max - 1]`. In `pipapo_refill()`, when `!match_only`, every scanned `map[k]` word must be zeroed (including on `-1` return) before `res_map` and `fill_map` swap. [F164, F234]
- `union nft_pipapo_map_bucket` in `f->mt` stores `{ .to, .n }` rule ranges on intermediate fields (`i < m->field_count - 1`) and `struct nft_pipapo_elem *e` only on the last field. In `pipapo_drop`, deleting `rulemap[i].n` rules at `rulemap[i].to` must cut bits from `f->lt` (`bitmap_cut`), compact `f->mt` via `pipapo_unmap` (using `memmove` and subtracting `rulemap[i + 1].n` from `mt[].to` only on non-last fields), and decrement `f->rules`. [F166, F187, F259]
- In `struct nf_conn`, `nf_conntrack_alloc` only zeroes fields after `__nfct_init_offset` (and `proto` must remain last), and `nf_ct_tuplehash_to_ctrack` requires `tuplehash[hash->tuple.dst.dir]` with hashed fields before `__nfct_hash_offsetend`. `ct->timeout` holds a relative duration when `!nf_ct_is_confirmed(ct)` and an absolute `nfct_time_stamp` expiration once confirmed. [F43, F55, F102]
- `struct flow_offload_tuple` must be zero-initialized before lookup/insertion because `flow_offload_hash` and `flow_offload_hash_cmp` cover all bytes up to `offsetof(..., __hash)`. Flowtable expiration and lifetime checks (`nf_flow_has_expired`, `flow_offload_fixup_ct` with signed `s32 timeout` clamped at `>= 0`, `nf_flow_offload_stats`) must use `nf_flow_timeout_delta()`. [F436, F462, F501, F502]
- In `nf_nat_packet` and `nf_nat_icmp[v6]_reply_translation`, `statusbit` (`IPS_SRC_NAT` or `IPS_DST_NAT`) must be inverted via `statusbit ^= IPS_NAT_MASK` when `dir == IP_CT_DIR_REPLY`. In `nf_nat_icmp[v6]_reply_translation`, the inner packet is translated first with `!manip` and `&ct->tuplehash[!dir].tuple`, then the ICMP checksum is updated, and finally the outer packet is translated with `manip`. [F630, F646]

## Synchronization

- `nf_hook_slow()` and `nf_hook_slow_list()` require standard `rcu_read_lock()` across the call (so `nf_hook_egress()` must wrap `nf_hook_slow()` in `rcu_read_lock()`/`rcu_read_unlock()` even under `rcu_read_lock_bh()`). `nf_hook_ingress()` must be called under `rcu_read_lock()` and recheck that `rcu_dereference(skb->dev->nf_hooks_ingress)` is non-NULL. [F17, F18, F320]
- `__nf_register_net_hook` and `__nf_unregister_net_hook` must hold `nf_hook_mutex` in sleepable process context. In `nf_remove_net_hook`, `old->hooks[i].hook` and `orig_ops[i]` must be overwritten in-place with `accept_all` and `&dummy_ops` using `WRITE_ONCE` while leaving `old->hooks[i].priv` intact for concurrent RCU readers and failed shrinks. [F318, F330, F373]
- Lockless conntrack callers (`nf_ct_should_gc()`, `nf_flow_table_extend_ct_timeout()`, `ct_seq_show()`) must call `nf_conntrack_get_ht()` under `rcu_read_lock()`, acquire a reference via `refcount_inc_not_zero(&ct->ct_general.use)`, and execute `smp_acquire__after_ctrl_dep()` before reading `ct->status` (`nf_ct_is_confirmed(ct)`) or `ct->timeout` (`nf_ct_is_expired(ct)`). [F109, F110, F413]
- Once `nf_ct_is_confirmed(ct)` is true, updates and multi-field reads of `ct->proto.tcp`, `ct->proto.sctp`, and `nf_conn_seqadj` (including in `flow_offload_fixup_tcp`, `nlattr_to_tcp/sctp`, and `nf_ct_seqadj_set`) must hold `spin_lock_bh(&ct->lock)`. `flow_offload_teardown()` must gate `flow_offload_fixup_ct(flow)` behind `!test_and_set_bit(NF_FLOW_TEARDOWN, &flow->flags)`. [F412, F524]
- `nft_rule_expr_deactivate()` and `nf_tables_deactivate_set()` require `commit_mutex`, and `nf_tables_rule_destroy()`/`nf_tables_chain_destroy()` must run in sleepable context only after `synchronize_rcu()`. Control-plane RCU list walks in `nft_bitmap_elem_find/walk` and `nft_hash_walk` must pass `lockdep_is_held(&nft_pernet(net)->commit_mutex)` to `*_for_each_entry_rcu()`. [F116, F275]
- In `nft_rhash_gc()`, `nft_net->gc_seq` must be sampled with `READ_ONCE()` and rechecked per element (aborting via `nft_trans_gc_destroy(gc)` if changed), elements matching the non-zero `priv->wq_gc_seq` must be skipped and stamped, and `nft_trans_gc_catchall_async()` must run before `rhashtable_walk_stop(&hti)`. `nft_rhash_destroy()` must call `cancel_delayed_work_sync(&priv->gc_work)` before destroying `priv->ht`. [F157, F226, F278]
- In `pipapo_get_slow()` and `pipapo_get_avx2()` (which requires `local_bh_disable()` and `irq_fpu_usable()` from callers), `m->scratch` must be dereferenced (`*raw_cpu_ptr(m->scratch)`), checked for `NULL`, aligned via `NFT_PIPAPO_LT_ALIGN`, and on every exit path `scratch->map_index = map_index`, `kernel_fpu_end()` (in AVX2), and `__local_unlock_nested_bh(&scratch->bh_lock)` (plus `local_bh_enable()` in slow) must run. [F145, F153, F163, F256]
- In `nft_set_do_lookup()`, `base_seq = nft_base_seq(net)` must be sampled inside the loop before `__nft_set_do_lookup()`, retrying on `NULL` while `nft_lookup_should_retry(net, base_seq)` is true. Active generation bitmask reads must use `nft_genmask_cur(net)` (`READ_ONCE(net->nft.gencursor)`). [F23, F238]

## Object Lifetimes

- `nf_ct_get()` returns a borrowed `struct nf_conn *` without incrementing `ct->ct_general.use`, so callers must not pass it to `nf_ct_put()` without first taking a reference. After `__nf_conntrack_confirm(skb)` returns `NF_ACCEPT` in `nf_conntrack_confirm()`, `ct` must be reloaded from `skb_nfct(skb)` because clash resolution may replace and free the losing `ct`. [F4, F53]
- `nf_ct_expect_alloc()` initializes `exp->use = 1` and `nf_ct_expect_related_report()` takes its own internal references on success, so callers must always call `nf_ct_expect_put()` after `nf_ct_expect_related[_report]()` on both success and failure. [F5]
- `nf_tproxy_sk_is_transparent(sk)` calls `sock_gen_put(sk)` when returning `false`, and when `true`, `nf_tproxy_assign_sock(skb, sk)` transfers ownership of `sk` to `skb->sk`, so callers must not call `sock_gen_put(sk)` in either case. [F9]
- When `nft_data_init()` succeeds with `NFT_DATA_VERDICT`, it increments `chain->use` for `NFT_JUMP`/`NFT_GOTO`, so any later init failure or teardown must call `nft_data_release(data, desc.type)`. In `nft_objref_deactivate()`, `nft_use_dec(&obj->use)` must be skipped when `phase == NFT_TRANS_COMMIT` because `NFT_TRANS_PREPARE` already decremented it. [F11, F148]
- In `nft_pipapo_destroy()`, when `priv->clone` is non-NULL, `nft_set_pipapo_match_destroy()` must be called *only* on `priv->clone` (never on both `priv->clone` and `priv->match`, which share `struct nft_pipapo_elem` pointers), and both `nft_set_pipapo_match_destroy()` and `nft_pipapo_do_walk()` must skip consecutive last-field rules where `f->mt[r + 1].e == f->mt[r].e`. [F183, F233]
- For `NF_FLOW_HW` flows, `nf_flow_offload_gc_step()` must not call `flow_offload_del()` (which unlinks both directions and frees `flow` via `kfree_rcu` while `cls_flow->cookie` points to `&flow->tuplehash[dir].tuple`) until `nf_flow_offload_del()` sets `NF_FLOW_HW_DYING` and `flow_offload_work_del()` sets `NF_FLOW_HW_DEAD`. `nf_flow_table_free()` must run `nf_flow_table_offload_flush_cleanup()` after `nf_flow_table_gc_run()` before `rhashtable_destroy()`. [F391, F408, F515, F529]
- In `ip_route_me_harder` and `ip6_route_me_harder`, `skb_dstref_steal(skb)` must detach `dst` before `xfrm_lookup`. In `ip6_route_me_harder` and `__nf_ip6_route`, `ip6_route_output` always returns a referenced `dst_entry *`, so if `dst->error != 0` callers must call `dst_release(dst)`. In `nf_xfrm_me_harder`, `skb_dst_drop(skb)` must only be called after `xfrm_lookup` returns `!IS_ERR(dst)`. [F313, F314, F603]

## API Contracts

- `nf_hook()` returns `1` when the packet passes, and `0` or `-ERRNO` when consumed/dropped (caller must not free `skb` or call `okfn`). `nf_hook_ingress()` converts `0` from `nf_hook_slow()` into `-1`, so `< 0` means consumed/dropped and `>= 0` means continue. `nf_hook_egress()` returns `skb` on pass or `NULL` when consumed (setting `*rc` to `NET_XMIT_DROP` or `NET_XMIT_SUCCESS`). [F3, F26, F29]
- `NF_DROP_REASON(skb, reason, err)` requires a positive 16-bit `err <= 0xffff`, frees `skb` immediately, and returns `((err << 16) | NF_STOLEN)`. Conversely, `NF_DROP_ERR(x)` does not free `skb` and requires a parenthesized negative errno `x` in `[-0x7fff, -1]` (used by `nf_nat_ipv[46]_out/local_fn` on reroute errors). [F27, F361, F604]
- `nf_ct_ext_add()` and `nf_conntrack_alter_reply()` (including in `nf_nat_setup_info`) must only be called when `!nf_ct_is_confirmed(ct)`. Because `nf_ct_ext_add()` calls `krealloc(ct->ext)`, any pointers previously obtained from `nf_ct_ext_find()`, `nfct_help(ct)`, or `nfct_nat(ct)` become stale across `nf_ct_ext_add()`. [F54, F582]
- `nfct_help_data(ct)` unconditionally dereferences `nf_ct_ext_find(ct, NF_CT_EXT_HELPER)` (a 32-byte buffer requiring `NF_CT_HELPER_BUILD_BUG_ON(sizeof(priv))`), so callers must check `nfct_help(ct)` for `NULL` first. Likewise, callers of `nf_ct_nat_ext_add(ct)` and `nfct_nat(ct)` must check for `NULL`, and `nf_ct_seqadj_set()` must check `nfct_seqadj(ct)` before setting `IPS_SEQ_ADJUST_BIT`. [F44, F104, F434, F596]
- Across `nft_set_ops` backends, `->get()` must return `ERR_PTR(-ENOENT)` (never `NULL`) on a miss, whereas `->lookup()` and `->deactivate()` must return `NULL` (never `ERR_PTR`). When `->insert()` returns `-EEXIST`, it must store the existing element's `struct nft_elem_priv *` into `*elem_priv`. `.walk` must not pre-filter by `nft_set_elem_active()`, and `.activate` must call `nft_clear(net, &ext)`. [F171, F172, F195]

## Error Handling

- L4 conntrack packet/error handlers (`nf_conntrack_*_packet`, `nf_conntrack_inet_error`) must return negated Netfilter verdicts (`-NF_ACCEPT`, `-NF_REPEAT`) or `NF_DROP` (`0`), never negative `-ERRNO` values (which `nf_conntrack_in` negates into positive verdicts). `nf_nat_sip_hooks` callbacks must return `NF_ACCEPT` (`1`) or `NF_DROP` (`0`), and `nf_nat_setup_info` / `nf_nat_icmp[v6]_reply_translation` return `0` (`NF_DROP`) on failure and `1` (`NF_ACCEPT`) on success. [F425, F428, F593, F601]
- `nf_ct_seq_adjust()` and `nf_ct_sack_adjust()` return `1` on success and `0` on failure (unlike `skb_ensure_writable` which returns `< 0` on error), and must re-derive `tcph` from `skb->data + protoff` after `skb_ensure_writable()` succeeds. [F429, F540]
- Because `nft_expr_inner_parse()` selects `type->inner_ops` directly without calling `type->select_ops()`, `inner_ops->init` callbacks (`nft_payload_inner_init`, `nft_meta_inner_init`) must explicitly check all mandatory `tb[]` attributes for `NULL`, and `inner_ops->eval` is `NULL` (callers invoke 4-argument `nft_*_inner_eval` after copying per-CPU `nft_inner_tun_ctx` to stack with BH disabled). [F117, F174, F263]
- On the last field in `pipapo_get_slow()` and `pipapo_get_avx2()`, if `e = f->mt[ret].e` fails `__nft_set_elem_expired(&e->ext, tstamp)` or `!nft_set_elem_active(&e->ext, genmask)`, lookup must loop back (`goto next_match`) to call `pipapo_refill()` again rather than returning `e` or aborting early. [F165]

## Known Pitfalls

- Header pointers derived from `skb->data` or `skb_network_header(skb)` must be reloaded after any call that may reallocate `skb->head`, including `pskb_may_pull()` (`nf_ip6_check_hbh_len`, `nf_flow_tuple_ip/ipv6`), `skb_ensure_writable()`/`enlarge_skb()` (`__nf_nat_mangle_tcp_packet`, `nf_nat_mangle_udp_packet`), `l4proto_manip_pkt` / `nf_nat_ipv[46]_manip_pkt`, and `process_sip_msg` NAT hooks (`sip_help_tcp`). [F196, F448, F452, F619, F620]
- When updating checksums incrementally, the old header/payload value must be sampled *before* overwriting packet bytes in `nf_nat_ipv[46]_manip_pkt` (`l4proto_manip_pkt` must precede L3 address writes), `nft_payload_set_eval` (`fsum = skb_checksum` before `skb_store_bits`, while `nft_payload_csum_sctp` runs after), `nf_ct_seq_adjust`/`nf_ct_sack_block_adjust`, and `nf_flow_snat/dnat_*` (converting a `0` UDP checksum to `CSUM_MANGLED_0`). In `nft_payload_l4csum_update`, `CHECKSUM_COMPLETE` packets must update both the L4 header checksum and `skb->csum`. [F198, F297, F460, F461, F618]
- `nft_rule_for_each_expr()` advances via `expr->ops->size` to `nft_expr_last(rule)` without checking `expr->ops`, so cleanup/unwind paths that can see partially initialized rules (`nft_rule_expr_deactivate`, `nf_tables_rule_destroy`) must use `while (nft_expr_more(rule, expr))`, and `nft_set_elem_expr::size` must only be incremented as each expression in `nft_setelem_expr_foreach` succeeds. [F81, F82]
- `NF_INVF(ptr, flag, boolean)` uses bitwise `^` without `!!`, so `boolean` must be a normalized `0`-or-`1` expression. `NF_CT_STATE_BIT(ctinfo)` and `XT_STATE_BIT(ctinfo)` alias `IP_CT_UNTRACKED` (7) to `IP_CT_RELATED`, so callers must check `ct != NULL` (`ctinfo != IP_CT_UNTRACKED`) first. [F78, F363]
- In `nf_nat_proto.c`, `ipv6_addr_cmp()` returns non-zero when addresses *differ*, whereas `nf_inet_addr_cmp()` returns non-zero when addresses are *equal* (and compares all 16 bytes of `union nf_inet_addr`, so IPv4 callers must zero the full union before setting `.ip`). [F648, F674]
- Bitops (`test_bit`, `set_bit`, `clear_bit`, `test_and_set_bit`) on `ct->status` and `flow->flags` take bit indices (`IPS_*_BIT`, `NF_FLOW_*`), whereas bitwise `&`/`|` on `ct->status` or `flowtable->flags` take shifted masks (`IPS_*`, `NF_FLOWTABLE_*`); in `nf_flow_rule_match`, `match->dissector.used_keys` is `u64` and requires `BIT_ULL()`. [F498, F520]
