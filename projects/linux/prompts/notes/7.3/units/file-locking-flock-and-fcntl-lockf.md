# FILE LOCKING (flock() and fcntl()/lockf())

This unit implements the `fcntl()` and `flock()` system calls, asynchronous I/O signal notification (`fasync` and `f_owner`), and VFS file locking in `fs/fcntl.c` and `fs/locks.c`. It manages BSD (`flock`), POSIX byte-range, Open File Description (`FL_OFDLCK`), and file lease/delegation/layout locks attached to inodes via `struct file_lock_context`, handling conflict resolution, range splitting/merging, deadlock detection, and `/proc/locks` reporting.

## Architecture & Data Flow

- When `flock_lock_inode()` or `posix_lock_inode()` copies `request` into `new_fl` via `locks_copy_lock()`, it must call `locks_move_blocks(new_fl, request)`, which after `list_splice_init(&fl->c.flc_blocked_requests, &new->c.flc_blocked_requests)` must iterate over `&new->c.flc_blocked_requests` (not the emptied `&fl->c.flc_blocked_requests`) to update `f->c.flc_blocker = &new->c`. [F37, F75]
- In `posix_lock_inode()`, when splitting an existing lock (`left == right`), `locks_copy_lock(left, right)` must copy `right` into `new_fl2` before `right->fl_start` is mutated to `request->fl_end + 1`, and `locks_wake_up_blocks()` must be called on both `right` and `left` after shrinking their ranges; in the `!added` branch after `list_for_each_entry_safe_from()`, `locks_insert_lock_ctx(&new_fl->c, &fl->c.flc_list)` must be followed by `fl = new_fl` so a subsequent split inserts `left` (`new_fl2`) before `new_fl`. [F38, F69]
- Because `__break_lease()` can set `FL_UNLOCK_PENDING` on a lease that already has `FL_DOWNGRADE_PENDING` set, `target_leasetype()` must test `FL_UNLOCK_PENDING` before `FL_DOWNGRADE_PENDING`, and `lease_clear_pending()` must fall through from `case F_UNLCK:` to `case F_RDLCK:` to clear both flags; when `lease_modify()` changes `flc_type`, it must call `lease_clear_pending()` and `locks_wake_up_blocks()`, and on `F_UNLCK` must also reset `f_delown(filp)`, `file_f_owner(filp)->signum = 0`, and `fl->fl_fasync` via `fasync_helper()` before `locks_delete_lock_ctx()`. [F36, F64]
- When `__locks_insert_block()` adds a waiter to `blocker->flc_blocked_requests`, it must insert `waiter` into `blocked_hash` via `locks_insert_global_blocked()` only if `(blocker->flc_flags & (FL_POSIX|FL_OFDLCK)) == FL_POSIX`, and `__locks_unlink_block()` must remove `waiter` from both `blocked_hash` and `flc_blocked_member`. [F35]
- Every loop over `&ctx->flc_lease` that can unlink entries via `locks_delete_lock_ctx()` or `lease_modify(..., F_UNLCK, ...)` (`time_out_leases()`, `__break_lease()`, `locks_remove_lease()`) must use `list_for_each_entry_safe()`; because `past_time()` treats `0` as never expiring, `__break_lease()` must increment `break_time` whenever `jiffies + lease_break_time * HZ` or `break_time - jiffies` evaluates to `0`. [F58, F68]
- In `locks_show()`, when backtracking up `cur = cur->flc_blocker` in `while (tmp == NULL && cur->flc_blocker != NULL)`, traversal must advance via `tmp = get_next_blocked_member(cur)` (returning `NULL` when `node->flc_blocker == NULL` or at list end) and assign `cur = tmp` rather than re-entering `cur->flc_blocked_requests`. [F74]

## Synchronization

- Lock operations in `fs/locks.c` must obey the hierarchy `file_rwsem` -> `ctx->flc_lock` -> `{ blocked_lock_lock, fll->lock }`; every lock or lease added to or removed from a `file_lock_context` list via `locks_insert_lock_ctx()` or `locks_unlink_lock_ctx()` must in lockstep call `locks_insert_global_locks()` or `locks_delete_global_locks()` (using `flc->flc_link_cpu`, not `this_cpu_ptr()`) while holding both `file_rwsem` (read-locked) and `ctx->flc_lock`. [F34, F99]
- In `__locks_wake_up_blocks()` and `__locks_delete_block()`, `waiter->flc_blocker` must be cleared via `smp_store_release(&waiter->flc_blocker, NULL)` only after unlinking and waking `waiter`, and `waiter` must never be accessed afterward because `__locks_delete_block()` checks `smp_load_acquire(&waiter->flc_blocker)` locklessly before freeing `waiter`; in `__locks_wake_up_blocks()`, `waiter->flc_flags & (FL_POSIX | FL_FLOCK)` must be checked before downcasting `file_lock(waiter)` to access `fl->fl_lmops` (as `flc_blocked_requests` also holds `struct file_lease` breakers), and `lm_notify()` runs under `blocked_lock_lock` so it must not sleep or call `locks_delete_block()`. [F21, F84, F92]
- Callers sleeping on `flc_wait` after a lock or lease blocks (`posix_lock_inode_wait()`, `flock_lock_inode_wait()`, `do_lock_file_wait()`, and `__break_lease()`) must use `list_empty(&fl->c.flc_blocked_member)` as the wait condition (not `!fl->c.flc_blocker`) and call `locks_delete_block()` / `__locks_delete_block()` upon waking. [F22]
- Inserting into `blocker->flc_blocked_requests` via `__locks_insert_block()` requires holding both `ctx->flc_lock` and `blocked_lock_lock` (whereas removal requires only `blocked_lock_lock`, so `locks_wake_up_blocks()` must recheck `list_empty()` after taking `blocked_lock_lock`); in `posix_lock_inode()`, `__locks_wake_up_blocks(&request->c)`, `posix_locks_deadlock(request, fl)`, and `__locks_insert_block(&fl->c, &request->c, posix_locks_conflict)` must execute within a single `blocked_lock_lock` critical section under `ctx->flc_lock`. [F23, F25]
- Callers removing locks or leases under `ctx->flc_lock` and `file_rwsem` must pass a non-NULL `dispose` list head to `locks_delete_lock_ctx()` (or `lease_modify()` / `time_out_leases()`) and drain it via `locks_dispose_list(&dispose)` only after dropping `ctx->flc_lock` and `file_rwsem` (including before sleeping in `__break_lease()`); moreover, because `struct file_lock` and `struct file_lease` use separate slab caches, passing `dispose == NULL` to `locks_delete_lock_ctx()` is only valid for `struct file_lock` nodes and never for `struct file_lease`. [F9, F83]
- In `posix_lock_inode()`, any dereference of `request` (including `trace_posix_lock_inode(inode, request, error)`) must occur before `spin_unlock(&ctx->flc_lock)` because `request` may have been reassigned to an entry on `ctx->flc_posix` that another task can free once `ctx->flc_lock` is dropped. [F26]
- `fasync_insert_entry()` and `fasync_remove_entry()` must acquire `filp->f_lock` before `fasync_lock` and update `FASYNC` in `filp->f_flags` under both locks, while `setfl()` must exclude `FASYNC` from `SETFL_MASK` and recompute `filp->f_iocb_flags = iocb_flags(filp)` under `filp->f_lock` whenever `filp->f_flags` changes. [F4, F31]
- Because `kill_fasync_rcu()`, `send_sigio()`, and `send_sigurg()` can run in hardirq or softirq context and take `fa->fa_lock` and `fown->lock` with `read_lock_irqsave()`, all process-context acquisitions of `fa->fa_lock` and `f_owner->lock` must disable IRQs (`_irq` or `_irqsave`) and never copy to user memory while holding the lock. [F94]

## Object Lifetimes

- `locks_release_private()` requires `fl->c` to be unlinked from all waitqueues, lists, and hashes, must clear `fl->fl_ops = NULL`, `flc->flc_owner = NULL`, and `fl->fl_lmops = NULL` after calling `fl_release_private` and `lm_put_owner` so repeated calls or `locks_free_lock()` are idempotent, and must be called before scope exit even on stack-allocated `struct file_lock` instances (e.g., in `sys_flock()`). [F6, F47]
- `locks_copy_conflock()` acquires an `lm_get_owner` reference and `locks_copy_lock()` requires `new->fl_ops == NULL` before copying `fl_ops` and calling `fl_copy_lock`, so any destination `struct file_lock` of either helper must be released with `locks_release_private()` or `locks_free_lock()`. [F7]
- `fasync_insert_entry()` consumes `new` and returns `NULL` only when no entry for `filp` exists on `*fapp`, and otherwise updates and returns the existing entry without consuming `new`, requiring `fasync_add_entry()` to free `new` via `fasync_free()` and `lease_setup()` to leave `*priv` non-NULL for its caller to free; `fasync_free()` must only be used on unlinked entries, whereas linked entries must be removed by `fasync_remove_entry()`, which clears `fa->fa_file = NULL` under `write_lock_irq(&fa->fa_lock)` and frees via `kfree_rcu(fa, fa_rcu)`. [F2, F3]
- `posix_lock_inode()` must pre-allocate `new_fl` and `new_fl2` before taking `file_rwsem` and `ctx->flc_lock`, set each local pointer to `NULL` when inserted into `ctx->flc_posix` so `out:` frees only unused locks, and abort with `-ENOLCK` if `right && left == right && !new_fl2` before modifying `left` or `right`. [F10]
- When `fl_lmops->lm_lock_expirable` returns `true` in `posix_test_lock()` or `posix_lock_inode()`, `fl_lmops->lm_expire_lock` must also be non-NULL, and the caller must copy `lm_mod_owner` and `lm_expire_lock` into locals and call `__module_get(owner)` before dropping `ctx->flc_lock` (and `file_rwsem` in `posix_lock_inode()`), then invoke `(*func)()`, `module_put(owner)`, and retry. [F11, F109]
- Standard POSIX locks set `flc_owner = current->files` whereas `FL_OFDLCK` locks set `flc_owner = filp`; in `fcntl_setlk()` and `fcntl_setlk64()`, after `do_lock_file_wait()` succeeds, close-race recovery must run only when `!(file_lock->c.flc_flags & FL_OFDLCK)` and `flc_type != F_UNLCK`, verifying `files_lookup_fd_locked(files, fd) == filp` under `spin_lock(&files->file_lock)` (not RCU) and calling `locks_remove_posix(filp, files)` with `-EBADF` on mismatch. [F12, F43]
- When `generic_add_lease()` finds an existing lease (`my_fl != NULL`), it must set `lease = my_fl` before jumping to `out_setup:` so `lm_setup()` runs on the existing lease, and only clear `*flp = NULL` when `!error && !my_fl` so the caller frees the unused `*flp`. [F76]
- In `f_setown()` and `f_setown_ex()`, `rcu_read_lock()` must span both `find_vpid()` and `__f_setown()` so the `struct pid` cannot be freed before `__f_setown()` calls `get_pid(pid)` under `f_owner->lock`, and sleeping calls like `file_f_owner_allocate()` must occur outside `rcu_read_lock()`. [F97]

## API Contracts

- In `__f_setown()`, `f_owner->pid`, `pid_type`, `uid`, and `euid` (captured from `current_cred()`) and `security_file_set_fowner(filp)` must be updated inside `write_lock_irq(&f_owner->lock)` only when `force || !f_owner->pid` holds (with `security_file_set_fowner`, `uid`, and `euid` updated only when `pid` is non-NULL); `lease_setup()` must pass `force = 0` so acquiring a lease does not overwrite an existing `F_SETOWN` owner, and `sigio_perm()` must check those saved `f_owner` UIDs rather than `current_cred()`. [F16, F45, F127]
- In `generic_setlease()`, `kernel_setlease()`, and `vfs_setlease()`, any `F_RDLCK`/`F_WRLCK` lease in `*flp` must provide non-NULL `fl_lmops->lm_break` and `fl_lmops->lm_change`, and `void **priv` is overloaded by command: for `F_UNLCK`, `priv` must be non-NULL with `*priv` holding the `flc_owner` pointer for `generic_delete_lease()`, whereas for `F_RDLCK`/`F_WRLCK` with `lease_setup()`, `*priv` must point to a `struct fasync_struct *`. [F89, F107]
- In `vfs_lock_file()`, a filesystem `.lock` callback may return `FILE_LOCK_DEFERRED` only if `fl->fl_lmops->lm_grant` is set and `FOP_ASYNC_LOCK` is in `file_operations.fop_flags`, and must not call `->lm_grant()` synchronously before returning `FILE_LOCK_DEFERRED`; `.lock` does not receive `@conf`, so callers must not read `@conf` uninitialized. [F108]
- File locking, lease, and `fcntl` operations on a `struct file *` must resolve the inode via `file_inode(filp)` (not `filp->f_path.dentry->d_inode`) and map inode UIDs through `file_mnt_idmap(filp)` via `i_uid_into_vfsuid()` or `inode_owner_or_capable()` (not raw `inode->i_uid`). [F112, F126]

## Error Handling

- In `f_owner_sig()`, when `setsig` is true (`F_SETSIG`), `valid_signal(signum)` must be checked before calling `file_f_owner_allocate(filp)` or writing `f_owner->signum`; in `send_sigio_to_task()`, `fown->signum` must be read once via `READ_ONCE(fown->signum)` into a local variable used across `sigio_perm()`, `sig_specific_sicodes()`, `si.si_signo`, and `do_send_sig_info()`, and if `signum != 0` (`default:`) and `do_send_sig_info()` returns non-zero, execution must fall through to `case 0:` to send `SIGIO`. [F48, F62, F67]

## External Contracts

- For `F_OFD_GETLK`, `F_OFD_SETLK`, and `F_OFD_SETLKW` (which must be rejected in 32-bit `fcntl` and require `fcntl64`), `fcntl_getlk*()` and `fcntl_setlk*()` must reject `flock->l_pid != 0` with `-EINVAL` and set `FL_OFDLCK` with `flc_owner = filp`; `fcntl_setlk*()` must normalize `cmd` to `F_SETLK*`/`F_SETLKW*` before `do_lock_file_wait()` and fall through from `F_OFD_SETLKW` to set `FL_SLEEP`; `fcntl_getlk*()` must allow `l_type == F_UNLCK` only for `F_OFD_GETLK`, and `posix_test_locks_conflict()` must check `lock_is_unlock(caller_fl)` before `posix_locks_conflict()`. [F65, F66, F121]
- On 32-bit architectures, `posix_lock_to_flock()` must return `-EOVERFLOW` if `fl_start` or a finite `fl_end` exceeds `OFFT_OFFSET_MAX`; in `do_compat_fcntl64()`, `fixup_compat_flock()` (returning `-EOVERFLOW` if `l_start > COMPAT_OFF_T_MAX` and clamping `l_len`) must only be called for 32-bit `F_GETLK` (`struct compat_flock`) and never for `F_GETLK64` or `F_OFD_GETLK`. [F56, F118]
- In `locks_translate_pid()`, a positive `fl->flc_pid` (non-`FL_OFDLCK`) with `ns == &init_pid_ns` must return `fl->flc_pid` directly without `find_pid_ns()` so locks of exited tasks keep their PID in `init_pid_ns`; when `locks_translate_pid()` returns `0`, `lock_get_status()` must still format the lock with PID `0`, `%02x:%02x:%lu` for `dev_t`/`i_ino`, and `EOF` for `fl_end == OFFSET_MAX` (for `/proc/<pid>/fdinfo/<fd>`), whereas `locks_show()` skips top-level `/proc/locks` entries with PID `0`. [F59, F124]
- In `do_fcntl()`, `F_GETOWN` must call `force_successful_syscall_return()` after `f_getown(filp)` because process group owners (`PIDTYPE_PGID`) return a negative PID; in `f_getowner_uids()`, `f_owner->uid` and `f_owner->euid` must be translated via `from_kuid(current_user_ns(), ...)` before copying to userspace. [F105, F128]

## Known Pitfalls

- `flock64_to_posix_lock()` bounds `l->l_start` and positive `l->l_len - 1` against `OFFSET_MAX - fl->fl_start` (`-EOVERFLOW`) and rejects negative `fl_start` (`-EINVAL`) so `0 <= fl_start <= fl_end <= OFFSET_MAX`; when testing adjacent ranges in `posix_lock_inode()`, always compare using `fl_start - 1` rather than `fl_end + 1` because `fl_end == OFFSET_MAX` overflows signed `loff_t` on `+ 1`. [F79, F80]
- Any change to lock acquisition, `FL_OFDLCK` handling, or close-race recovery in `fcntl_setlk()` or `fcntl_getlk()` must be mirrored in `fcntl_setlk64()` or `fcntl_getlk64()` under `#if BITS_PER_LONG == 32`. [F49]
- Stack structs copied to userspace in `fs/fcntl.c` (`struct compat_flock` in `put_compat_flock()`, `struct compat_flock64` in `put_compat_flock64()`, `struct f_owner_ex` in `f_getown_ex()`, and `kernel_siginfo_t` in `send_sigio_to_task()`) must be zero-initialized before field assignment and `copy_to_user()`. [F88]
