# NETWORKING [MPTCP]

Implements Multipath TCP (MPTCP v1, RFC 8684) for IPv4 and IPv6, multiplexing a single user-facing stream socket (`struct mptcp_sock`) across multiple underlying TCP subflow sockets (`struct mptcp_subflow_context`) via TCP Upper Layer Protocol (ULP) hooks. It handles MPTCP options, SHA-256/HMAC-SHA256 handshakes, connection token hashing, SYN-cookie state, data sequence mapping/retransmission, pluggable schedulers, socket option/diag synchronization, and in-kernel/userspace Path Managers (PM) via Generic Netlink and sysctl.

## Architecture & Data Flow

- A closed initial subflow (`msk->first`) stays on `msk->conn_list`, while `__mptcp_close_ssk()` unlinks `subflow->node` whenever `msk->free_first || ssk != msk->first`. Any `msk->conn_list` loop calling `mptcp_close_ssk()` or `__mptcp_close_ssk()` must use `mptcp_for_each_subflow_safe()`, `mptcp_close_ssk()` must guard one-shot accounting with `subflow->close_event_done`, and `mptcp_pm_rm_addr_or_subflow()` must skip subflows in `TCPF_FIN_WAIT1 | TCPF_FIN_WAIT2 | TCPF_CLOSING | TCPF_CLOSE`. [F8, F98]
- Because `__mark_subflow_endp_available()` and `mptcp_pm_nl_rm_addr()` do not decrement `msk->pm.local_addr_used` or `msk->pm.add_addr_accepted` for ID 0, kernel PM subflow creation must not increment `local_addr_used` when `local.addr.id == msk->mpc_endpoint_id` or `add_addr_accepted` when `remote.id == 0`. [F9]
- In `mptcp_pm_create_subflow_or_signal_addr()` and `fill_local_addresses_vec_c_flag()`, `__clear_bit(local.addr.id, msk->pm.id_avail_bitmap)` must execute immediately after `select_local_address()` and before any `continue` path so rejected endpoints are not re-selected in an infinite loop. [F106]
- Address ID bitmaps (`id_bitmap`, `id_avail_bitmap`, `unavail_id`) must be sized `MPTCP_PM_MAX_ADDR_ID + 1` (256 bits), and `subflow->local_id` (`s16`, init `-1`) must be converted via `subflow_get_local_id()` before indexing a bitmap. [F82]
- `msk->first_pending` must point to the first unsent `mptcp_data_frag` in `msk->rtx_queue` (or `NULL`), so `__mptcp_clean_una()` must advance `msk->first_pending` before `dfrag_clear()` when `dfrag == msk->first_pending` during `msk->recovery` (and clamp `dfrag->already_sent` up to `delta` before subtracting `delta` if `delta > dfrag->already_sent`), while `__mptcp_retransmit_pending_data()` must reset `first_pending` and zero `already_sent`. [F62, F85]
- Every path populating a new `SKB_EXT_MPTCP` (`struct mptcp_ext`) must `memset(mpext, 0, sizeof(*mpext))` first because `mptcp_ext_matches()` uses `memcmp()` across bitfields/padding. `mptcp_skb_ext_copy()` must mark `from_ext->frozen = 1` on TX clone, and `mptcp_sendmsg_frag()` must check `mptcp_skb_can_collapse_to()` (`!mpext->frozen`) and set `TCP_SKB_CB(skb)->eor = 1` when collapsing is disallowed. [F122, F160]
- Because `opts->addr` and `opts->ahmac` alias `opts->ext_copy` in `struct mptcp_out_options`, `mptcp_established_options_add_addr()` must stage the address in a local `struct mptcp_addr_info` and only write `opts->addr` (and zero `opts->ahmac` if `drop_other_suboptions`) after confirming `OPTION_MPTCP_ADD_ADDR` fits. [F57]
- In `get_mapping_status()`, `mpext->data_seq` must be expanded via `mptcp_expand_seq(READ_ONCE(msk->ack_seq), mpext->data_seq, mpext->dsn64)`, and for `!mpext->dsn64`, `data_fin_seq = mpext->data_seq + data_len - 1` must be masked with `GENMASK_ULL(31, 0)` before `mptcp_update_rcv_data_fin()`. When `mpext->data_fin == 1` and `data_len > 1`, `subflow->map_data_len` stores `data_len - 1`, so `__mptcp_make_csum()` must be passed `subflow->map_data_len + subflow->map_data_fin`. [F244, F245, F269]
- In `get_mapping_status()`, installing a new mapping (`subflow->map_valid = 1`) must reset `subflow->map_csum_len = 0` and `subflow->map_data_csum = csum_unfold(mpext->csum)`. Once `SKB_EXT_MPTCP` is accepted/merged (including a pure `DATA_FIN` with `data_len == 1` while `subflow->map_valid` is set, which returns `MAPPING_OK`), call `skb_ext_del(skb, SKB_EXT_MPTCP)`. When `mptcp_subflow_get_map_offset(subflow) >= subflow->map_data_len` in `mptcp_subflow_data_available()` or `mptcp_subflow_discard_data()`, reset `subflow->map_valid = 0`. [F230, F231, F232, F256]
- In `struct mptcp_subflow_context`, transient per-connection fields belong inside `struct_group(reset, ...)` while persistent socket backpointers, callbacks, and list nodes (`node`, `delegated_node`, `tcp_sock`, `conn`, `icsk_af_ops`, `tcp_state_change`, `tcp_error_report`) stay outside it for `mptcp_subflow_ctx_reset()`. Before overwriting `icsk->icsk_af_ops` in `subflow_ulp_init()` or `mptcpv6_handle_mapped()`, save the old pointer to `subflow->icsk_af_ops`, and restore all overridden callbacks/ops in `subflow_ulp_fallback()`. [F65, F228, F229]
- `sockopt_seq_inc()` must preserve `(u32)sk->sk_state << 24u` in the upper 8 bits of `msk->setsockopt_seq` via `sockopt_seq_reset()`. In `mptcp_sol_socket_sync_intval()` and `sync_socket_options()`, updating `ssk->sk_sndbuf` under `SOCK_SNDBUF_LOCK` must update `mptcp_subflow_ctx(ssk)->cached_sndbuf`, updating `ssk->sk_mark` must call `sk_dst_reset(ssk)` if changed, and `ssk->sk_rcvlowat = 0` and `tcp_sk(ssk)->notsent_lowat = UINT_MAX` must be kept on subflows. [F222, F223, F224, F265]
- Unlinking from `token_bucket` chains (`mptcp_token_accept()`, `mptcp_token_destroy_request()`, `mptcp_token_destroy()`) must use `hlist_nulls_del_init_rcu()` or `__sk_nulls_del_node_init_rcu()`. `mptcp_token_accept()` moves `req` to `msk` without changing `bucket->chain_len`, and hashing/unhashing `msk` in `msk_chain` must pair with `sock_prot_inuse_add(sock_net(sk), sk->sk_prot, 1/-1)` and `msk->token = 0` on destroy. [F172, F221, F257]

## Synchronization

- PM helpers entered with `msk->pm.lock` held (`mptcp_pm_send_ack()`, `mptcp_pm_rm_addr_or_subflow()`, `mptcp_pm_create_subflow_or_signal_addr()`, `mptcp_pm_nl_add_addr_received()`) must `spin_unlock_bh(&msk->pm.lock)` before locking/connecting/closing a subflow and re-acquire `msk->pm.lock` before returning. Callers of `mptcp_pm_addr_send_ack()`, `mptcp_pm_remove_addr()`, `mptcp_pm_remove_anno_addr()`, `mptcp_pm_remove_addr_entry()`, and `mptcp_pm_rm_subflow()` must hold `lock_sock(sk)` on `msk`. [F17, F24]
- All lookups, modifications, and removals on `msk->pm.userspace_pm_local_addr_list` (`mptcp_userspace_pm_lookup_addr*()`, `mptcp_userspace_pm_delete_local_addr()`) must hold `spin_lock_bh(&msk->pm.lock)` continuously across the lookup and mutation. [F25]
- `__mptcp_finish_join()`, `mptcp_finish_join()`, `__mptcp_retrans()`, `mptcp_pm_mp_fail_received()`, and `__mptcp_try_fallback()` must hold `spin_lock_bh(&msk->fallback_lock)` across checking and updating `msk->allow_subflows`, `msk->allow_infinite_fallback`, and `MPTCP_FALLBACK_DONE` (and `mptcp_disconnect()` must restore `allow_subflows = true` and `allow_infinite_fallback = true` when zeroing `msk->flags`). [F21, F53]
- Callers of `mptcp_sendmsg_frag()` holding a BH spinlock (`mptcp_data_lock(sk)` or `msk->fallback_lock`) must set `info.data_lock_held = true` so `mptcp_alloc_tx_skb()` uses `GFP_ATOMIC`. Likewise, `mptcp_try_fallback()` must temporarily override `ssk->sk_allocation = GFP_ATOMIC` around `tcp_shutdown(ssk, SEND_SHUTDOWN)`, and `subflow_ulp_clone()` must pass its `gfp_t priority` parameter to `subflow_create_ctx()`. [F136, F137, F294]
- `mptcp_pm_nl_append_new_local_addr()` calls `synchronize_rcu()` when replacing an implicit endpoint, so `mptcp_pm_nl_get_local_id()` (called in atomic/RCU RX path) must pass `replace = false`. [F138]
- Mutations to `token_bucket` (`req_chain`, `msk_chain`, `chain_len`) require `spin_lock_bh(&bucket->lock)`, and `msk->token` must be set with `WRITE_ONCE()` before `__sk_nulls_add_node_rcu()`. Lockless RCU lookups (`mptcp_token_exists()`, `mptcp_token_get_sock()`, `mptcp_token_iter_next()`) must restart if `get_nulls_value(pos) != (token & token_mask)`, use `refcount_inc_not_zero(&sk->sk_refcnt)`, and revalidate `sock_net(sk)` and `READ_ONCE(msk->token)` (calling `sock_put(sk)` and retrying on mismatch). [F186, F187, F188, F189]
- `mptcp_subflow_queue_clean()` must splice `queue->rskq_accept_head/tail` under `queue->rskq_lock` and `release_sock(listener_ssk)` before locking each child's `msk` and calling `mptcp_cancel_work(sk)`, then re-lock `listener_ssk` and restore the queue. `mptcp_diag_fill_info()` must call `unlock_sock_fast(sk, slow)` before acquiring `mptcp_data_lock(sk)`. [F184, F199]

## Object Lifetimes

- Every `struct mptcp_sock *` from `mptcp_userspace_pm_get_sock()` or `mptcp_token_get_sock()` carries a reference that must be released via `sock_put((struct sock *)msk)` on all exit paths (including `subflow_token_join_request()` on error). In `subflow_syn_recv_sock()`, transferring `subflow_req->msk` to `ctx->conn` must clear `subflow_req->msk = NULL` to prevent a double `sock_put()`. [F1, F173, F175]
- `mptcp_close_ssk()` and `__mptcp_close_ssk()` can free `subflow` and drop `ssk`, so callers must read needed `subflow`/`ssk` fields beforehand. `mptcp_subflow_reset()` must hold an extra `sock_hold(sk)` on `sk = subflow->conn` across `tcp_done(ssk)` and `mptcp_schedule_work(sk)` because `tcp_done(ssk)` calls `subflow_ulp_release(ssk)`, dropping `ctx->conn`. [F6, F178]
- `inet_csk(sk)->icsk_ulp_data` (`struct mptcp_subflow_context`) must be assigned/cleared with `rcu_assign_pointer()` and freed via `kfree_rcu(ctx, rcu)`. In `subflow_ulp_release()`, if `ctx->conn` is non-NULL, free `ctx` only when `ctx->disposable || list_empty(&ctx->node)`; otherwise schedule `MPTCP_WORK_CLOSE_SUBFLOW` on `ctx->conn`. After `mptcp_sock_graft(ssk, sk->sk_socket)` in `__mptcp_subflow_connect()`, discard `sf` with `iput(SOCK_INODE(sf))`, not `sock_release(sf)`. [F180, F181, F292]
- `mptcp_schedule_work(sk)` calls `sock_hold(sk)` when `schedule_work(&msk->work)` succeeds; that ref is dropped by `sock_put(sk)` in `mptcp_worker()` or `__sock_put(sk)` in `mptcp_cancel_work()` when `cancel_work_sync()` returns `true`. When `mptcp_subflow_delegate()` sets `BIT(MPTCP_DELEGATE_SCHEDULED)`, it calls `sock_hold(ssk)`; only `mptcp_napi_poll()` may dequeue `subflow`, clear `MPTCP_DELEGATE_SCHEDULED`, and call `sock_put(ssk)`. [F11, F12]
- `msk->pm.userspace_pm_local_addr_list` entries (`sock_kmemdup()`) must be freed with `sock_kfree_s(sk, entry, sizeof(*entry))` (or `kfree_rcu_mightsleep()` + `atomic_sub(sizeof(*match), &sk->sk_omem_alloc)`). `pernet->endp_list` must be traversed with `list_for_each_entry_rcu()` under `rcu_read_lock()` or `pernet->lock`, unlinked entries require `synchronize_rcu()` before `__mptcp_pm_release_addr_entry()`, and `mptcp_pm_nl_append_new_local_addr(..., replace = false)` frees `entry` internally on non-negative return when matching an implicit endpoint (leaving `entry` for the caller to free on `< 0`). [F41, F131, F146]

## API Contracts

- `mptcp_sk(sk)` is only valid on `IPPROTO_MPTCP` sockets and `tcp_sk(sk)` / `mptcp_subflow_ctx(sk)` only on `IPPROTO_TCP` subflows (use `mptcp_sk(mptcp_subflow_ctx(sk)->conn)` from a subflow). Before treating an arbitrary `sk` as an MPTCP subflow in BPF/diag, verify `sk_fullsock(sk)`, `sk->sk_protocol == IPPROTO_TCP`, and `sk_is_mptcp(sk)`. In `mptcp_set_rcvlowat()`, reject `sk->sk_protocol == IPPROTO_TCP` before `mptcp_sk(sk)`. In `subflow_syn_recv_sock()` and `subflow_ulp_clone()`, check `tcp_rsk(req)->is_mptcp` before `mptcp_subflow_rsk(req)`. [F51, F126, F275, F276]
- `mptcp_pm_get_local_id()`, `mptcp_pm_nl_get_local_id()`, `mptcp_userspace_pm_get_local_id()`, `mptcp_pm_*_append_new_local_addr()`, `mptcp_get_subflow_data()`, and `mptcp_get_full_info()` return `>= 0` on success (including `0`) and `< 0` on error; callers must store the result in a signed `int` and test `< 0`. [F40, F201]
- `mptcp_crypto_hmac_sha()` and `subflow_generate_hmac()` write `SHA256_DIGEST_SIZE` (32) bytes, so callers must pass a `>= 32`-byte buffer even for 20- or 8-byte HMACs, and `subflow_generate_hmac()` takes sender `(key1, nonce1)` first and receiver `(key2, nonce2)` second. [F47, F215]
- `mptcp_get_options()` only zeroes `*(u32 *)&mp_opt->status = 0`, so `mptcp_parse_option()` must initialize all fields read for any set `suboptions` flag (`mp_opt->addr.port = 0`, `mp_opt->ahmac = 0`). `mptcp_propagate_state()` must guard `mp_opt` dereferences with `if (mp_opt)`. [F125, F211]

## Error Handling

- After `mptcp_alloc_tx_skb()` entails a new `skb` onto `ssk`, any early exit in `mptcp_sendmsg_frag()` before attaching payload must call `tcp_remove_empty_skb(ssk)`. In `mptcp_connect()`, if subflow connect fails after `mptcp_token_new_connect(ssk)`, call `mptcp_token_destroy(msk)` and `mptcp_set_state(sk, TCP_CLOSE)`. In `subflow_v4/v6_route_req()`, call `dst_release(dst)` if `subflow_check_req()` fails. In `subflow_syn_recv_sock()` (`dispose_child`), set `tcp_rsk(req)->drop_req = true`, call `tcp_done(child)`, and still return non-NULL `child`. [F15, F19, F174, F177]
- In `mptcp_incoming_options()`, zero-length packets (`seq == end_seq`) must process `DATA_FIN` and return before `skb_ext_add(skb, SKB_EXT_MPTCP)`, whereas if `skb_ext_add()` returns NULL for a payload packet, return `false` to drop it. Because `subflow_ulp_fallback()` clears `icsk_ulp_data` and unaccepted `msk` sockets have `!sk->sk_socket`, check `sk_is_mptcp(ssk)`, `ctx`, and `ctx->conn` in subflow teardown paths and `sk->sk_socket` in `mptcp_subflow_create_socket()` / `subflow_error_report()`. Always run `subflow_init_req()` on new/cookie `mptcp_subflow_request_sock` objects (`SLAB_TYPESAFE_BY_RCU`, not zeroed). [F35, F162, F207, F209, F213]

## External Contracts

- `mptcp_pm_nl_add_addr_doit()` must reject `MPTCP_PM_ADDR_FLAG_IMPLICIT`, reject `SIGNAL | FULLMESH`, and reject `addr.port != 0` unless `address_use_port()` is true (`SIGNAL && !SUBFLOW`); `mptcp_pm_nl_set_flags()` must reject `FULLMESH` when `entry->flags` has `SIGNAL` or `IMPLICIT`. `mptcp_diag_fill_info()`, `mptcp_get_sub_addrs()`, and `mptcp_getsockopt_full_info()` must `memset()` output structs to zero before any early return or partial write, and `mptcp_get_subflow_data()` / `mptcp_get_full_info()` must reject user `u32` sizes `> INT_MAX` and non-zero kernel-output fields. [F73, F74, F93, F214, F310]

## Known Pitfalls

- In `mptcp_write_options()`, `ptr` is `__be32 *` (4-byte stride), so advance `ptr` in 32-bit words (`+ 1` per 4B, `+ 2` per 8B, `+ 4` per IPv6, `+ 5` for 20B HMAC), unlike `const unsigned char *ptr` in `mptcp_parse_option()`. `struct mptcp_addr_info::port` is `__be16` (convert `MPTCP_PM_ADDR_ATTR_PORT` with `htons()`/`ntohs()`). [F84, F123]
- Compare 32-bit sequence numbers with `before()`/`after()` and 64-bit DSNs with `before64(ack_seq, old_ack)` (clamping `old_ack - ack_seq` to `u32 avail_len` before narrowing), check `tp->copied_seq - TCP_SKB_CB(skb)->seq <= skb->len` before subtracting from `skb->len` in `skb_is_fully_mapped()` / `mptcp_subflow_discard_data()`, and check `skb_queue_is_last(&ssk->sk_receive_queue, skb)` before `skb = skb->next` in `validate_data_csum()`. [F112, F246, F258, F271, F272]
