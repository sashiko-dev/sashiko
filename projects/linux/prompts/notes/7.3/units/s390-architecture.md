# S390 ARCHITECTURE

This unit provides core s390 architecture headers (`arch/s390/include/asm/`), UAPI definitions (`arch/s390/include/uapi/asm/`), and early/core kernel implementations (`arch/s390/kernel/`), covering lowcore prefix pages, MMU/ASCE context switching, page table allocation, TLB flushing, `mvcos` user-space memory access, TOD clock/timers, Ultravisor calls, zPCI/CLP/QDIO/SCSW/SCLP interfaces, DIAG 0x320 certificate store management (`cert_store.c`), 31-bit compat syscalls/signals, CPU cache topology (`cache.c`), runtime alternatives (`alternative.c`), and absolute lowcore mapping (`abs_lowcore.c`).

## Architecture & Data Flow
- `switch_mm_irqs_off()` must unconditionally reload `get_lowcore()->user_asce` from `next->context.asce` (or `s390_invalid_asce` for `init_mm`), set `cpu` in `next->context.cpu_attach_mask`, and clear CR1/CR7 even when `prev == next`, while clearing `cpu` from `prev->context.cpu_attach_mask` only when `prev != next`. Broken by: early `if (prev == next) return;` or unconditionally clearing `prev`'s mask. [F38]
- In `init_new_context()`, `mm->context.asce_limit` must be updated in lockstep with both the `_ASCE_TYPE_REGION*` bits in `mm->context.asce` and the `_REGION*_ENTRY_EMPTY` value passed to `crst_table_init((unsigned long *)mm->pgd, init_entry)`. The `default` branch of `switch (mm->context.asce_limit)` is valid only for `0` (`exec`), where it asserts `VM_BUG_ON(mm->context.asce_limit)`, sets `asce_limit = _REGION2_SIZE`, and falls through to `case _REGION2_SIZE`. [F37, F77]
- In `call_on_stack()` and `call_nodat()`, `CALL_FMT_0..5` and `CALL_CLOBBER_0..5` must mark all parameter registers (`%r2`–`%r6`) as modified (`+&d` / `=&d` operands or clobbers) across the `brasl`/`lpswe` call so the compiler does not assume arguments survive the call. [F134]
- `local_mcck_restore(mflags)` must sample the live PSW mask via `__extract_psw()`, clear `PSW_MASK_MCHECK`, and OR in `mflags` before calling `__load_psw_mask()`, rather than restoring a full PSW mask snapshot taken at `local_mcck_save()` time. [F53]
- In `raw_copy_from_user()`, `raw_copy_to_user()`, and `__clear_user()`, `osize = size` must be saved at the start of every `while (1)` iteration before `mvcos`, and the loop must return `osize - size` when `CC_TRANSFORM(cc) == 0` before decrementing `size` by 4096. [F83]
- `on_stack()` must check `addr + len < addr` for unsigned wrap and check the upper bound with `addr + len <= info->end` (inclusive), because objects like `struct pt_regs` sit at the top of a stack where `addr + len == info->end`. [F57]
- In `__apply_alternatives()` and `runtime_const_fixup()`, relative offsets (`a->instr_offset`, `a->repl_offset`, and `*start`) are signed byte offsets relative to the address of the offset field itself, requiring the field pointer to be cast to `u8 *` or `void *` before addition. `__apply_alternatives()` must scan `struct alt_instr` entries in forward order from `start` to `end` via `s390_kernel_write()` so later entries can overwrite earlier ones. [F103, F138]
- `current_stack_pointer` in `arch/s390/include/asm/processor.h` must expand to `(__current_stack_pointer())` reading `%r15` via inline assembly, not a global `register ... asm("r15")` variable or bare function identifier. [F136]
- `populate_cache_leaves()` must set `this_cpu_ci->cpu_map_populated = true` after `ci_leaf_init()` so generic cacheinfo code does not overwrite each leaf's `shared_cpu_map`. [F43]
- Synthetic zPCI pseudo-MMIO addresses from `ZPCI_ADDR(idx)` must start at `ZPCI_IOMAP_ADDR_BASE` (`1UL << 62`) and remain below `1UL << 63` so they do not overlap hardware MIO addresses in `iomem_resource`. [F131]
- CLP response structures in `pci_clp.h` (e.g., `struct clp_rsp_set_pci`, `struct clp_rsp_query_pci`) must include trailing fields written by newer firmware (such as `struct mio_info mio`) even when unused, because CLP rejects response buffers shorter than firmware's response length. [F69]
- In `struct os_info`, `entry[OS_INFO_MAX]` and `reserved` must be adjusted in lockstep so `sizeof(struct os_info)` remains `PAGE_SIZE` (4096 bytes). In `struct tpi_info`, the 32-bit word after `schid` and `intparm` must preserve exact bitfield widths including the two `:12` padding fields (`adapter_IO:1`, `directed_irq:1`, `isc:3`, `:12`, `type:3`, `:12`) to match `lowcore.tpi_info` (`0x00b8`). [F54, F56]
- In `arch/s390/include/asm/physmem_info.h`, `reserved_range.chain` stores a physical address that must be converted with `__va(range->chain)` when advancing in `for_each_physmem_reserved_type_range()` and `__physmem_reserved_next()`. [F86]
- In `arch/s390/include/asm/scsw.h`, `scsw_cmd_is_solicited()` and `scsw_tm_is_solicited()` require exact equality `stctl != (SCSW_STCTL_STATUS_PEND | SCSW_STCTL_ALERT_STATUS)` when `cc == 0`, whereas `scsw_cmd_is_valid_ectl()` and `scsw_tm_is_valid_ectl()` allow primary/secondary bits if `SCSW_STCTL_INTER_STATUS` is clear. [F87]
- In `cert_store.c`, `get_key_description()` and `cert_store_key_describe()` must keep the first `VC_NAME_LEN_BYTES` (64) bytes of `key->description` as fixed-width EBCDIC CP 500 `vc_name` followed immediately at offset `VC_NAME_LEN_BYTES` by the ASCII `:%05u:%010u` suffix (`u16 vc_index`, `u32 cs_token`), allocating `sizeof(vc_name) + 1 + 5 + 1 + 10 + 1` bytes and formatting with `snprintf()`. [F64, F106]

## Synchronization
- `finish_arch_post_lock_switch()` must spin while `atomic_read(&mm->context.flush_count)` is non-zero (with preemption disabled) before setting `smp_processor_id()` in `mm_cpumask(mm)` and calling `__tlb_flush_mm_lazy(mm)`. Both `switch_mm_irqs_off()` and the CR1/CR7 loads (`kernel_asce`/`user_asce`) in `finish_arch_post_lock_switch()` must execute with local IRQs disabled. [F39, F127]
- `__tlb_flush_mm_lazy()` must hold `mm->context.lock` across checking `mm->context.flush_mm`, clearing it to 0, and executing `__tlb_flush_mm(mm)`. [F12]
- Callers of `__get_tod_clock_monotonic()` must run with preemption disabled (or use `get_tod_clock_monotonic()`) because the TOD clock and `tod_clock_base` are updated via `stop_machine`. Callers of `test_cpu_flag_of(flag, cpu)` must prevent CPU hotplug on `cpu` (e.g., by disabling preemption) before reading `per_cpu(pcpu_devices, cpu).flags`. [F17, F126]
- In `cert_store.c`, `cs_refresh_lock` must be held across `fill_cs_keyring()` (including retries up to `DIAG_MAX_RETRIES` when `get_sevcb()` returns `-EAGAIN` on `DIAG320_RC_CS_NOMATCH` or `remaining_vc_count != 0`) and updating `cs_status_val` in `refresh_store()`. `fill_cs_keyring()` must purge any existing `cert_store` keyring via `cleanup_cs_keys()` both before `create_cs_keyring()` and on every error path; if `invalidate_keyring_keys()` fails in `cleanup_cs_keys()`, `key_type_cert_store_key` must be unregistered and re-registered in `create_cs_keyring()`. [F19, F49, F114]

## Object Lifetimes
- When `abs_lowcore_map()` fails part-way through mapping `LC_PAGES` pages, it must only unmap already-mapped pages via `vmem_unmap_4k_page()` if `alloc` is true, and must leave page tables mapped when `alloc` is false because `vmem_unmap_4k_page()` may sleep while `alloc == false` callers run in atomic context. [F1]
- In `arch/s390/include/asm/pgalloc.h`, `pmd_alloc_one_noprof()` must call `crst_table_free(mm, table)` if `pagetable_pmd_ctor()` fails, and `p4d_free()`, `pud_free()`, `pmd_free()`, and `pgd_free()` must call `pagetable_dtor(virt_to_ptdesc(...))` before `crst_table_free()` (unless folded). [F7]
- `get_user_session_keyring()` and `find_cs_keyring()` drop the key reference acquired during lookup (`key_ref_put()` or `key_put()`) before returning, so callers must not release the returned borrowed `struct key *` with `key_put()`. [F2]
- In `cert_store_init()`, debugfs views (`cert_store_dbf`, `cert_store_hexdump`) and `cert_store_kobj` must be created before `sysfs_create_files()` and `register_key_type(&key_type_cert_store_key)`, and any failure must unwind `cert_store_kobj` and unregister both debugfs areas. [F113]

## API Contracts
- Any s390 `get_unmapped_area` implementation that can return `[addr, addr + len)` up to `TASK_SIZE` must pass the range through `check_asce_limit(mm, addr, len)` so `crst_table_upgrade()` upgrades page table levels when `addr + len > mm->context.asce_limit`. [F147]
- Functions invoked via `call_nodat()` execute at a physical address with `PSW_MASK_DAT` cleared and without a valid DAT-off stack pointer in `%r15`, so `fn` must not access the stack via `%r15`, and `psw_leave` must remain `__aligned(16)` so `lpswe 0(7)` never crosses a page boundary. In `call_on_stack()` and `call_nodat()`, each `tN, aN` pair must specify the exact parameter type `tN` expected by `fn` so `CALL_LARGS_N` casts `(long)(tN)(aN)` to sign-/zero-extend narrow arguments into `%r2`–`%r6`. [F97, F135]
- `unwind_recover_ret_addr()` must pass `(void *)state->sp` (not `NULL`) as the stack pointer argument to `ftrace_graph_ret_addr()`. [F23]
- `READ_ONCE_ALIGNED_128(x)` requires `x` to be 16-byte aligned in memory in addition to `sizeof(x) == 16`, because `lpq` faults on unaligned addresses. [F72]
- `__get_user_<type>_noinstr()` and `__put_user_<type>_noinstr()` must not call `instrument_get_user()`, `instrument_put_user()`, or `might_fault()`. In `arch/s390/include/asm/string.h`, `memset16/32/64()` take an element count, whereas `__memset16/32/64()` take a byte count. [F99, F124]
- For memory regions that may exceed 8TB, callers must use `__set_memory_*` `(void *start, void *end)` (`unsigned long numpages`) rather than `set_memory_*` `(unsigned long addr, int numpages)`. When `ARCH_HAS_SET_DIRECT_MAP` is enabled, `set_memory.h` must declare `set_direct_map_invalid_noflush()`, `set_direct_map_default_noflush()`, and `kernel_page_present()`. [F93, F141]
- Variables shared between the decompressor and vmlinux must use `__bootdata(var)` (`.init`-scoped) or `__bootdata_preserved(var)` (retained after init), which emit `.boot.data.<var>` or `.boot.preserved.data.<var>` subsections so linker sorting matches in both binaries. [F118]
- `stsi()` returns the configuration level (`(unsigned int)r0 >> 28`) when `fc == 0`, `0` on success when `fc != 0`, or `-EOPNOTSUPP` on `cc == 3` (check `< 0` for errors). `__pcpu_sigp()` only updates `*status` when `status` is non-NULL and `____pcpu_sigp()` returns `SIGP_CC_STATUS_STORED` (`cc == 1`). [F33, F34]
- `struct pci_dev` is not embedded in `struct zpci_dev`; `to_zpci()` and `to_zpci_dev()` read `struct zpci_bus *zbus = pdev->sysdata` and index `zbus->function[pdev->devfn]` (which can be `NULL`). Per-device zPCI MIO via `zpci_use_mio()` requires both `have_mio` and `zdev->mio_capable` to be true. [F105, F111]
- `zpci_get_max_io_size()` must bound transfers by `min3(len, ZPCI_BOUNDARY_SIZE - offset, max)` so `dst` never crosses a 4K boundary, allow block sizes above 8 bytes only when `src`, `dst`, and `size` are all 8-byte aligned, and otherwise cap transfers at 8 bytes or `rounddown_pow_of_two(size)`. [F109]
- In `cert_store.c`: `get_user_session_keyring()` returns `ERR_PTR(-ENOKEY)` on failure, whereas `find_cs_keyring()` and `create_cs_keyring()` return `NULL`; `get_key_description()` returns a caller-owned `kmalloc()` buffer, and `create_key_from_vce()` must call `key_ref_put(newkey)` on success and `kfree(desc)` on all paths; `add_certificates_to_keyring()` must seal the keyring with `keyring_restrict()` after adding all VCE keys; and before issuing `DIAG320_STORAGE` or `DIAG320_CERT_BLOCK`, `fill_cs_keyring()` must verify `sclp.has_diag320` and `test_bit_inv(1, ism)` / `test_bit_inv(2, ism)`. [F5, F21, F112, F148]

## Error Handling
- `__get_user_*_noinstr()` must zero `*to = 0` on access exception before returning `-EFAULT` in both `asm goto` and non-`asm goto` paths. `zpci_read_u64/u32/u16/u8()` must return all-ones (`(RETTYPE)-1ULL`) whenever `zpci_load()` returns a non-zero condition code. [F25, F110]
- In `share()` (`arch/s390/include/asm/uv.h`), if `addr` is not page-aligned (`addr & ~PAGE_MASK`) it must trigger `BUG_ON()`, and if `uv_call()` fails for `UVC_CMD_SET_SHARED_ACCESS` or `UVC_CMD_REMOVE_SHARED_ACCESS` it must call `panic()` rather than returning an error code. [F155]
- In `fill_cs_keyring()`, `rc` must be set to `-ENOMEM` before calling `create_cs_keyring()` and jumping to `cleanup_keys` on `NULL`, because preceding calls overwrite `rc` with `0`. In `add_certificates_to_keyring()`, VCEs must be iterated with 1-based indices `1..vcssb->total_vc_index_count`, and the single-entry VCB buffer and `vcb_hdr.vcb_input_length` must be page-aligned via `get_4k_mult_vcb_size(vcssb)`; `-EAGAIN` from `create_key_from_sevcb()` must abort the loop immediately whereas other errors must be skipped. [F20, F62, F82]

## External Contracts
- In `struct lowcore`, field offsets in `0x0e00`–`0x0f00` (`ipib` at `0x0e00`, `ipib_checksum` at `0x0e08`, `vmcore_info` at `0x0e0c`, `os_info` at `0x0e18`) must never change because dump/re-IPL tools read them at fixed offsets. To prevent leaking KASLR addresses via BEAR, `struct lowcore` must keep fixed-address `return_lpswe` and `return_mcck_lpswe` trampolines and `INIT_THREAD` must set `thread_struct.last_break = 1`. [F137, F144]
- Under `CONFIG_NUMA`, `arch/s390/include/asm/topology.h` must not override `node_distance()` to return `0` and must rely on `<asm-generic/topology.h>` (`LOCAL_DISTANCE`). [F142]

## Known Pitfalls
- `init_idle_preempt_count(p, cpu)` in `arch/s390/include/asm/preempt.h` must remain a no-op that does not write to `get_lowcore()->preempt_count`, because `get_lowcore()` accesses the calling CPU's lowcore rather than `cpu`'s lowcore (allocated at CPU bringup). [F42]
- Hardware/firmware bitmaps in `unsigned long` words—such as `uv_info.uv_feature_indications` in `uv_has_feature()` and DIAG 0x320 `ism` in `query_diag320_subcodes()`—use big-endian MSB-0 bit numbering and must be queried with `test_bit_inv()` after bounds-checking the bit index. Also, `uv_cb_qui.max_guest_cpu_id` and `uv_info.max_guest_cpu_id` store the 0-based maximum guest CPU ID (`N - 1`), not the 1-based VCPU count (`N`). [F59, F61]
- In `struct vce`, `vce_hdr.vc_offset` and `vce_hdr.vc_hash_offset` are byte offsets from `(u8 *)vce`, not from `vce->cert_data_buf`. Also, `vce_hdr.vc_name` is a 64-byte un-terminated EBCDIC field; converting it to a C string requires a `VC_NAME_LEN_BYTES + 1` buffer, `EBCASC_500(..., VC_NAME_LEN_BYTES)`, and NUL-termination. [F63, F107]
- In `struct physmem_info`, only the first `MEM_INLINED_ENTRIES` (255) online ranges reside in `physmem_info.online[]` while indices `n >= MEM_INLINED_ENTRIES` reside in `online_extended[n - MEM_INLINED_ENTRIES]`; always use `__get_physmem_range()`. [F71]
- In `cache.c`, `ecag()` and `ct.ci[level]` use 0-based cache levels `[0, CACHE_MAX_LEVEL)` while `this_leaf->level` stores 1-based `level + 1`, and a `CACHE_TYPE_SEPARATE` level populates two `this_leaf` entries (`CACHE_TYPE_DATA` and `CACHE_TYPE_INST`). [F74]
- `zpci_memset_io()` calls `kmalloc(count, GFP_KERNEL)` before `zpci_memcpy_toio()`, so it may sleep and must not be called from atomic contexts. [F123]
- In `tod_to_ns()`, `todval` must be split into `((todval >> 9) * 125) + (((todval & 0x1ff) * 125) >> 9)` rather than `(todval * 125) >> 9`. In `__runtime_fixup_shift()`, the shift amount `val` patched into the `srl` `D2` field (`insn &= 0xfffff000`) must be masked with `val & 63`. [F94, F98]
