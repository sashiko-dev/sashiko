# BTRFS FILE SYSTEM

Implements the Btrfs copy-on-write filesystem, including B-tree operations, extent and backref management, buffered/direct/encoded I/O, compression, subvolumes, snapshots, send/receive, qgroups/squota, multi-device volume/chunk management, RAID56 parity, and zoned block device support.

## Architecture & Data Flow
- Any change to slot 0's key in a B-tree leaf or node (`btrfs_set_item_key_safe()`, `btrfs_truncate_item()`, `setup_items_for_insert()`, `btrfs_del_ptr()`, `btrfs_del_items()`, `__push_leaf_left()`, `split_leaf()`) must call `fixup_low_keys()` while ancestor nodes in `path` are still write-locked, before `btrfs_unlock_up_safe()`. [F71, F690]
- `btrfs_delayed_ref_root::head_refs` and `dirty_extents` XArrays must be indexed by `(bytenr >> fs_info->sectorsize_bits)`, rejecting `bytenr >= MAX_LFS_FILESIZE` on 32-bit and widening the `unsigned long` index to `u64` before left-shifting in `btrfs_qgroup_account_extents()`. [F81, F928, F952]
- Every `btrfs_delayed_ref_node` in `head->ref_tree` must be on `head->ref_add_list` iff `action == BTRFS_ADD_DELAYED_REF` (including across action flips in `insert_delayed_ref()` and removal in `drop_delayed_ref()`), and under `delayed_refs->lock`, `num_heads` counts `tracked` heads while `num_heads_ready` counts `tracked && !processing` heads. [F62, F64]
- On subpage metadata filesystems (`btrfs_meta_is_subpage(fs_info)`), `folio_get_private(folio)` is `struct btrfs_folio_state *` (where `eb_refs` and `nr_locked` share a union for metadata vs data folios, and `eb_refs` requires `i_private_lock`) rather than `struct extent_buffer *`, and `extent_buffer::addr` is `NULL` for discontiguous/cloned buffers. [F393, F474, F1010, F1034]
- In `struct extent_map`, `disk_bytenr` is a disk address only when `< EXTENT_MAP_LAST_BYTE` (`EXTENT_MAP_HOLE`/`EXTENT_MAP_INLINE` must keep `offset == 0` and `disk_num_bytes == 0`); `add_extent_mapping()` and `remove_em()` on fstrees must update `fs_info->evictable_extent_maps`, and removal must call `RB_CLEAR_NODE(&em->rb_node)` and skip `list_del_init(&em->list)` if `EXTENT_FLAG_LOGGING` is set. [F392, F406, F407]
- In `struct btrfs_inode`, `delalloc_bytes`, `new_delalloc_bytes`, and `csum_bytes` share unions with directory-only fields (`first_dir_index_to_log`, `last_dir_index_offset`, `index_cnt`, so `btrfs_alloc_inode()` must zero `new_delalloc_bytes`), and `set_bit()`/`test_bit()` may only target `unsigned long runtime_flags`, never 32-bit `flags`/`ro_flags`. [F529, F562, F631]
- For tree-block extent items, `struct btrfs_tree_block_info` follows `struct btrfs_extent_item` (`ei + 1`) only for non-skinny `BTRFS_EXTENT_ITEM_KEY`, whereas for `BTRFS_METADATA_ITEM_KEY` inline refs start at `ei + 1`; downcasting `btrfs_extent_inline_ref` requires checking `btrfs_get_extent_inline_ref_type()` (`&iref->offset` for data/owner refs vs `iref + 1` for shared data refs). [F394, F395, F509]

## Synchronization
- Callers must release any locked `btrfs_path` before calling `btrfs_release_delayed_node()`, `btrfs_is_data_extent_shared()` (in `btrfs_swap_activate()` and `extent_fiemap()`, which clones the leaf first), `btrfs_filldir()` (in `btrfs_real_readdir()`), or blocking on `head->mutex` in `btrfs_cross_ref_exist()`, `btrfs_lookup_extent_info()`, and `check_ref_exists()`. [F29, F357, F381, F579, F658]
- In `btrfs_search_slot()` and `setup_nodes_for_search()`, if a node requires a higher `write_lock_level` or `read_block_for_search()` must read from disk (`!p->skip_locking`), upper locks and the path must be released (`btrfs_release_path()`) before reading or restarting from the root; child extent buffers must call `btrfs_maybe_reset_lockdep_class()` before locking. [F23, F25, F147]
- `root->node` replacements (`btrfs_force_cow_block()`, `balance_level()`, `insert_new_root()`) must log the tree mod and increment `cow->refs` before `rcu_assign_pointer(root->node, cow)`; `btrfs_root_node()` must use `rcu_read_lock()` + `refcount_inc_not_zero()`, and `btrfs_lock_root_node()` / `btrfs_read_lock_root_node()` must reverify `eb == root->node` after locking. [F21, F156, F689]
- Delayed-ref locking: `btrfs_delete_ref_head()` requires `delayed_refs->lock` then `head->lock` (so `cleanup_ref_head()` must drop `head->lock`, acquire `delayed_refs->lock` then `head->lock`, and recheck `ref_tree` and `extent_op`); `btrfs_delayed_ref_lock()` must pin `head->refs` before dropping `delayed_refs->lock` to sleep on `head->mutex` and recheck `head->tracked` after relocking. [F34, F35, F376]
- `fs_info->buffer_tree` XArray lock must always use IRQ-disabling variants (`xa_lock_irq` / `xas_lock_irqsave`) because `end_bbio_meta_write()` clears marks from IRQ context; `try_release_subpage_extent_buffer()` must iterate under `rcu_read_lock()`, acquire `eb->refs_lock` before `rcu_read_unlock()`, and `folio->mapping->i_private_lock` must be released before `release_extent_buffer()` (which consumes `eb->refs_lock`). [F318, F347, F365, F478, F479, F481, F482]
- Direct and encoded I/O extent locking: `btrfs_dio_iomap_begin()` must call `btrfs_check_data_free_space()` before `lock_extent_direct()`, which locks `EXTENT_DIO_LOCKED` before `EXTENT_LOCKED` and unlocks `EXTENT_LOCKED` before waiting on ordered extents; similarly, `btrfs_lock_and_flush_ordered_range()`, `btrfs_encoded_read()`, and `btrfs_do_encoded_write()` must drop `EXTENT_LOCKED` before waiting on ordered extents and recheck after relocking. [F179, F197, F543, F699]
- Inode and delalloc locks: `inode->io_tree.lock` nests outside `inode->lock` and `root->delalloc_lock` (`btrfs_set_delalloc_extent()`, `btrfs_clear_delalloc_extent()`), whereas `inode->file_extent_tree->lock` and `btrfs_update_inode_bytes()` run inside `inode->lock`; `btrfs_alloc_extent_map()` (`GFP_NOFS`) and `btrfs_lock_extent()` must be called before `write_lock(&inode->extent_tree.lock)`. [F487, F570, F639, F640]
- Interrupt-safe spinlocks: `fs_info->delayed_iput_lock` and `btrfs_folio_state::lock` must always use `spin_lock_irqsave()` / `spin_lock_irq()` (and `run_delayed_iput_locked()` must unlock before `iput()`); in `zstd.c`, process-context callers must use `spin_lock_bh(&zwsm->lock)` because `zstd_reclaim_timer_fn()` runs in softirq timer context. [F537, F1136, F1196]
- Volume and device replace lock hierarchy: `sb->s_umount` -> `uuid_mutex` (`btrfs_get_tree_super()` must drop `uuid_mutex` with `btrfs_fs_devices_inc_holding()` before `sget_fc()`) -> `dev_replace->lock_finishing_cancel_unmount` -> `fs_devices->device_list_mutex` -> `fs_info->chunk_mutex` (`btrfs_remove_chunk()` must call `btrfs_free_dev_extent()` before `chunk_mutex`) -> `dev_replace->rwsem` and `zone_active_bgs_lock` -> `block_group->lock`. [F203, F313, F1146, F1186, F1304, F1310, F1332]

## Object Lifetimes
- Before calling `btrfs_free_tree_block()` on a dirtied extent buffer (on error in `create_subvol()` or when emptying a block in `insert_new_root()`, `balance_level()`, or `btrfs_del_items()`), `btrfs_clear_buffer_dirty()` must be called; in `btrfs_del_leaf()`, `refcount_inc(&leaf->refs)` must be taken before `btrfs_free_tree_block()` and paired with `free_extent_buffer_stale(leaf)` so `path->nodes[0]` stays valid until `btrfs_release_path()`. [F1, F5, F670]
- Root references: `btrfs_global_root()`, `btrfs_extent_root()`, and `btrfs_csum_root()` return borrowed pointers (`NULL` if missing), whereas `btrfs_get_global_root()`, `btrfs_lookup_fs_root()` (`NULL` if missing; uses `btrfs_grab_root()` under `fs_roots_radix_lock`), `btrfs_get_fs_root()`, and `btrfs_get_fs_root_commit_root()` (`ERR_PTR` on error) return a reference that must be released with `btrfs_put_root()`. [F184, F230, F320]
- `btrfs_remove_extent_mapping()` and `replace_extent_mapping()` do not decrement the removed `extent_map`'s refcount, so callers must call `btrfs_free_extent_map()`; when `btrfs_add_extent_mapping()` handles `-EEXIST`, it frees the caller's `*em_in` and updates `*em_in` to the existing map (or `NULL` on failure). [F354, F355]
- In qgroups, `add_qgroup_rb()`, `__add_relation_rb()`, and `btrfs_qgroup_account_extent()` (`@old_roots` and `@new_roots`) unconditionally consume/free their pointer arguments on all paths, whereas `btrfs_qgroup_trace_extent_nolock()` consumes `@record` only when returning `0` (requiring `xa_release()` and `kfree(record)` when returning `!= 0`). [F16, F838, F839, F840]
- `btrfs_add_chunk_map()` consumes the initial ref from `btrfs_alloc_chunk_map()`, so callers must use `btrfs_free_chunk_map()` on failure before/during `btrfs_add_chunk_map()` and `btrfs_remove_chunk_map()` on rollback afterwards; detaching a live `btrfs_device` from `fs_devices->devices` requires `btrfs_assign_next_active_device()` under `device_list_mutex`, `list_del_rcu()`, and `synchronize_rcu()` before `btrfs_free_device()`. [F1165, F1177, F1224]

## API Contracts
- On success, `btrfs_force_cow_block()` (and `btrfs_cow_block()` when it COWs) consumes `buf` via `free_extent_buffer_stale(buf)`, unlocks `buf` if `*cow_ret == buf`, and returns the new write-locked buffer in `*cow_ret`; on error, `buf` remains locked and referenced by the caller. [F2]
- `btrfs_search_slot()` requires `p->nodes[0] == NULL` on entry (`cow != 0` if `ins_len != 0`; `!cow && !time_seq` if `p->nowait`; `p->skip_locking = 1` if `p->search_commit_root`; `ins_len >= sizeof(struct btrfs_item)` if `ins_len > 0 && !p->search_for_extension`), and releases `p` on `< 0` error unless `p->skip_release_on_error` is set, EXCEPT `btrfs_insert_empty_items()` / `btrfs_insert_empty_item()` returns `-EEXIST` with `path` still populated and write-locked. [F3, F45, F46, F47, F138, F154]
- `btrfs_add_delayed_tree_ref()`, `btrfs_add_delayed_extent_op()`, and `btrfs_lru_cache_store()` take ownership of `extent_op` / `new_entry` only on `0` return (callers must free on `< 0`); `btrfs_select_ref_head()` returns a locked head, `NULL`, or `ERR_PTR(-EAGAIN)` and must be released via `btrfs_unselect_ref_head()` or `btrfs_delete_ref_head()`. [F15, F17, F49, F668]
- In `btrfs_delalloc_release_metadata()`, `btrfs_delalloc_release_space()`, and `btrfs_delayed_inode_release_metadata()`, `@qgroup_free` must be `true` on error/cancellation rollback (and `btrfs_qgroup_free_data()` used for data) and `false` on normal completion (where `btrfs_qgroup_release_data()` clears `EXTENT_QGROUP_RESERVED` while keeping `BTRFS_QGROUP_RSV_DATA` until commit). [F58, F846]
- Range conventions: all `extent_io_tree` helpers, `btrfs_drop_extent_map_range()`, `fiemap_process_hole()`, `btrfs_lock_and_flush_ordered_range()`, and `btrfs_try_lock_ordered_range()` take inclusive `[start, end]`, whereas `btrfs_lookup_ordered_range()`, `btrfs_wait_ordered_range()`, `btrfs_finish_ordered_extent()`, `btrfs_cleanup_ordered_extents()`, and `btrfs_lookup_extent_mapping()` take `(start, len)`. [F293, F403, F546, F715]
- When `current->journal_info != NULL` (open transaction), callers must not invoke `try_flush_qgroup()`, `btrfs_truncate_block()`, `btrfs_wait_ordered_roots()` in `shrink_delalloc()`, or space reservations with `BTRFS_RESERVE_FLUSH_ALL*`, `BTRFS_RESERVE_FLUSH_EVICT`, or `BTRFS_RESERVE_FLUSH_DATA`; inode eviction must use `BTRFS_RESERVE_FLUSH_EVICT` and `btrfs_join_transaction()`. [F152, F538, F653, F972, F1138, F1139]
- Extent buffer offsets: `btrfs_item_ptr()` returns an extent-buffer byte offset cast to a pointer (never dereference directly, and cast to `char *` or `unsigned long` before byte-offset arithmetic); `memmove_leaf_data()` / `copy_leaf_data()` take offsets relative to `btrfs_item_nr_offset(leaf, 0)` whereas `read_extent_buffer()`, `write_extent_buffer()`, and `memmove_extent_buffer()` (required instead of `memcpy_extent_buffer()` when `dst_offset > src_offset` overlaps) take full `eb` byte offsets. [F135, F137, F298, F404, F472, F630]

## Error Handling
- Delalloc error cleanup in `cow_file_range()`, `nocow_one_range()`, and `run_delalloc_nocow()` must split ranges that already allocated ordered extents (`btrfs_cleanup_ordered_extents()`, without passing `EXTENT_DO_ACCOUNTING` or `EXTENT_CLEAR_META_RESV` to `extent_clear_unlock_delalloc()`) from unallocated ranges; in `btrfs_truncate_block()`, when `only_release_metadata` is true, errors must call `btrfs_delalloc_release_metadata()` instead of `btrfs_delalloc_release_space()`. [F514, F517, F567, F611]
- Fallible calls assigned directly to `root->node` (`read_tree_block()`), `fs_info->fs_root` (`open_ctree()`), or `trans` (`btrfs_start_transaction()` in `btrfs_finish_one_ordered()`, `btrfs_link()`, `btrfs_truncate()`) must be reset to `NULL` after extracting `PTR_ERR()` before jumping to cleanup labels, whereas `sctx->parent_root` in `btrfs_ioctl_send()` must be guarded with `!IS_ERR_OR_NULL(sctx->parent_root)`. [F219, F555, F1043]

## Known Pitfalls
- Leaf item data grows downward from `BTRFS_LEAF_DATA_SIZE(fs_info)` toward the item headers (`start <= end` means `btrfs_item_offset(leaf, start) >= btrfs_item_offset(leaf, end)`): `split_item()` must copy the original payload out before adjusting offsets, `btrfs_truncate_item()` with `!from_end` on inline extents must shift `BTRFS_FILE_EXTENT_INLINE_DATA_START` before `memmove_leaf_data()` and call `fixup_low_keys()` if `slot == 0`, and `setup_inline_extent_backref()` must recompute `ei` and `iref` after `btrfs_extend_item()`. [F72, F73, F84, F469]
- In `btrfs_clear_extent_bit_changeset()`, `set_extent_bit()`, and `btrfs_convert_extent_bit()`, `state->end` must be saved into `last_end` before `clear_state_bit()` or `merge_state()` (which may free/merge `state`); in `btrfs_drop_extent_map_range()`, `drop_all_extent_maps_fast()`, `btrfs_scan_inode()`, `btrfs_free_ref_tree_range()`, and `qgroup_unreserve_range()`, the next rbtree node must be saved before erasing/modifying the current node (and re-looked up if `cond_resched_rwlock_write()` rescheduled). [F251, F279, F451, F943, F951]
- 32-bit shift and division hazards: cast `SZ_16K` in `btrfs_sb_offset()`, `high_crc` in `hash_extent_data_ref()`, `ULONG_MAX` in `BTRFS_32BIT_MAX_FILE_SIZE`, stripe counts (`btrfs_stripe_nr_to_offset()`), and zone numbers (`zone_start_physical()`, `zone_start_sector()`) to `u64`/`sector_t` before left-shifting; use `div_u64()`/`div64_u64()` (`count_max_extents()`, `btrfs_csum_bytes_to_leaves()`) instead of `/` or `%` on `u64` values; and use `rounddown()` (not power-of-two `round_down()`) for `devs_increment` and `nr_data_stripes(map)`. [F129, F290, F462, F618, F784, F1280, F1281, F1287, F1288]
- When inspecting `struct btrfs_file_extent_item` (`fiemap_find_last_extent_offset()`, `extent_fiemap()`, `btrfs_exclude_logged_extents()`, `__btrfs_mod_ref()`), callers must check `btrfs_file_extent_type(leaf, ei) == BTRFS_FILE_EXTENT_INLINE` before reading `btrfs_file_extent_disk_bytenr(leaf, ei)` or treating `disk_bytenr == 0` as a hole; in `qgroup.c`, every list populated with `qgroup_iterator_add()` must be cleaned with `qgroup_iterator_clean()` under `qgroup_lock`, and ancestor loops over `btrfs_qgroup::iterator` must walk `groups` on the loop cursor variable. [F442, F938, F939]
