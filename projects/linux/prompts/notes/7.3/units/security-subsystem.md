# SECURITY SUBSYSTEM

The SECURITY SUBSYSTEM implements the core Linux Security Module (LSM) framework (`security/security.c`, `include/linux/lsm_hooks.h`, `include/linux/lsm_hook_defs.h`, `include/linux/security.h`), dispatching security mediation and lifecycle hooks via static calls and managing composite per-object security blobs. It also provides the LSM userspace syscalls (`security/lsm_syscalls.c`, `include/uapi/linux/lsm.h`), `securityfs` (`security/inode.c`), LSM audit helpers (`security/lsm_audit.c`), the device cgroup controller (`security/device_cgroup.c`), the `vm.mmap_min_addr` sysctl (`security/min_addr.c`), and Rust wrappers for Binder LSM hooks and security contexts (`rust/kernel/security.rs`).

## Architecture & Data Flow
- When adding or modifying an LSM hook, update `LSM_HOOK(RET, DEFAULT, NAME, ...)` in `include/linux/lsm_hook_defs.h`, its `security_*()` wrapper in `security/security.c`, and both the `CONFIG_SECURITY*` prototype and `#else` inline stub in `include/linux/security.h` under matching Kconfig guards, keeping identical return and parameter types (including enums and `const` pointers) across all of them and every `LSM_HOOK_INIT(NAME, ...)` callback. [F61, F103]
- `lsm_set_blob_size(need, lbs)` aligns `*lbs` up to `sizeof(void *)`, sets `*lbs = offset + *need`, and overwrites `*need` with `offset` (making `needed->lbs_*` a byte offset, not a size, afterwards); for `lbs_inode`, `lsm_set_blob_sizes()` must reserve `sizeof(struct rcu_head)` at offset `0` of `blob_sizes.lbs_inode` before assigning any LSM's offset. [F70]
- Per-association SCTP LSM hooks (`security_sctp_assoc_request()`, `security_sctp_sk_clone()`, `security_sctp_assoc_established()`) must pass `struct sctp_association *asoc` so per-association security state is isolated from the shared `struct sock` across multiplexed associations. [F59]
- In `devcgroup_update_access()`, granting access (`DEVCG_ALLOW`) must be checked against the parent via `may_allow_all()`, `parent_allows_removal()`, or `parent_has_perm()` (where `verify_new_ex()` takes the parent as `dev_cgroup` and the child's `childcg->behavior` as `behavior`), while revoking access (`DEVCG_DENY`) or removing an allow rule must call `propagate_exception()` so online descendants update their list and run `revalidate_active_exceptions()`. [F47, F89, F145]
- In `security/device_cgroup.c`, `match_exception()` requires every requested `access` bit to be in `ex->access` (`!(access & ~ex->access)`) and treats `~0` as a wildcard only on `ex`, whereas `match_exception_partial()` matches if any bit overlaps (`access & ex->access`) and treats `~0` on either `ex` or the query as a wildcard. [F85]
- `lockdown_reasons[]` in `security/security.c` is indexed directly by `enum lockdown_reason` without bounds checks, so every enumerator up to `LOCKDOWN_CONFIDENTIALITY_MAX` in `include/linux/security.h` must have a matching entry in `lockdown_reasons[]`; similarly, every `LSM_ATTR_*` constant in `include/uapi/linux/lsm.h` (except `LSM_ATTR_UNDEF`) must have a name mapping in `lsm_name_to_attr()` in `security/lsm_syscalls.c`. [F63, F77]

## Synchronization
- In `lsm_static_call_init()`, a hook slot's static call target and `security_hook_list` pointer must be initialized via `__static_call_update()` and `scall->hl = hl` before `static_branch_enable(scall->active)` enables the static key checked by `__CALL_STATIC_VOID` and `__CALL_STATIC_INT`. [F18]
- In `propagate_exception()`, `devcgroup_mutex` must be held, and `css_for_each_descendant_pre()` requires `rcu_read_lock()` on every step and normal loop exit: `continue` branches (including skipping `!is_devcg_online(devcg)`) must precede `rcu_read_unlock()`, `rcu_read_lock()` must be re-acquired before the loop advances or exits, and error returns after `rcu_read_unlock()` must return directly without unlocking RCU again. [F48, F88]
- Modifications to a live `dev_cgroup->exceptions` list in `dev_exception_add()`, `dev_exception_rm()`, and `__dev_exception_clean()` must use `list_add_tail_rcu()`, `list_del_rcu()`, and `kfree_rcu(ex, rcu)` for concurrent RCU readers in `devcgroup_legacy_check_permission()` and `devcgroup_seq_show()`; any loop unlinking or freeing `dev_exception_item` entries (including `dev_exceptions_move()`, `dev_exceptions_copy()` cleanup, and `revalidate_active_exceptions()`) must use `_safe` list iterators. [F22, F86]
- `common_lsm_audit()` allocates its `audit_buffer` with `GFP_ATOMIC` and neither it, `dump_common_audit_data()`, `audit_log_lsm_data()`, nor any `pre_audit`/`post_audit` callback may sleep; when `audit_log_lsm_data()` logs an `AF_UNIX` socket for `LSM_AUDIT_DATA_NET` without holding `unix_sk(sk)->lock`, it must load `unix_sk(sk)->addr` via `smp_load_acquire(&u->addr)`. [F26, F27]
- Callers of `security_inode_killpriv()`, `security_inode_notifysecctx()`, and `security_inode_setsecctx()` must hold `inode_lock()` (`inode->i_rwsem`), and callers of `security_file_set_fowner()` must hold `file->f_owner.lock`. [F28]

## Object Lifetimes
- `security_inode_free()` runs `inode_free_security` hooks synchronously but defers `inode_free_security_rcu` hooks and `kmem_cache_free(lsm_inode_cache, ...)` of `inode->i_security` via `call_rcu(..., inode_free_by_rcu)`; LSM state read by `security_inode_permission()` during RCU path walks must only be freed in `inode_free_security_rcu`. [F8]
- `security_inode_init_security()` allocates `new_xattrs` with `blob_sizes.lbs_xattr_count + 1` zeroed elements (for the `initxattrs()` terminator); hooks claim slots only via `lsm_get_xattr_slot()` up to their reserved `lbs_xattr_count` (keeping `xattr_count == 0` when `new_xattrs` is `NULL`) and transfer ownership of kmalloc'd `xattr->value` pointers to `security_inode_init_security()`, which must `kfree()` all `new_xattrs[0..xattr_count-1].value` and `new_xattrs` on both success and error paths. [F12, F71]
- `security_dentry_init_security()` sets `*xattr_name` to a static string that the caller must not `kfree()`, while `@lsmctx` must be released via `security_release_secctx()`; `security_release_secctx()` zeroes `*cp`, and `security_free_mnt_opts()` sets `*mnt_opts = NULL` after freeing a non-`NULL` `*mnt_opts`. [F13, F14]
- In `dev_exception_add()`, when a matching `dev_exception_item` already exists in `dev_cgroup->exceptions`, its `access` mask is updated in place and the pre-allocated `excopy` must be freed with `kfree(excopy)` and set to `NULL` so it is not appended via `list_add_tail_rcu()`. [F6]
- In `security/inode.c`, `securityfs_create_dentry()` pins the mount via `simple_pin_fs()` only when `parent == NULL` (calling `simple_release_fs()` on error if `pinned` is true), and `remove_one()` in `securityfs_remove()` must call `simple_release_fs()` only when `victim->d_parent == victim->d_sb->s_root`. [F55]
- In `rust/kernel/security.rs`, `SecurityCtx::from_secid()` must zero-initialize `bindings::lsm_context` before `bindings::security_secid_to_secctx()` and check `to_result()` before constructing `SecurityCtx` (since `Drop::drop` releases `self.ctx`), and `SecurityCtx::as_bytes()` must return `&[]` without calling `slice::from_raw_parts()` when `self.ctx.context` is null. [F40, F107]

## API Contracts
- Cross-process/async hooks (`security_binder_*`, `security_post_notification`, `security_dentry_create_files_as`) must mediate using the explicitly passed `struct cred *` rather than `current_cred()` or a target `task_struct`'s credentials; credential-transition hooks (`bprm_creds_for_exec`, `bprm_creds_from_file`, `task_fix_setuid/gid/groups`) must only mutate the staged `@bprm->cred` or `@new` and never `current->cred`. [F143, F144]
- In `security_vm_enough_memory_mm()` and its `!CONFIG_SECURITY` stub, `vm_enough_memory` hooks (including `cap_vm_enough_memory`) return `0` to grant `CAP_SYS_ADMIN` overcommit and negative errno to deny it, whereas `__vm_enough_memory()` takes a boolean `cap_sys_admin` flag (`1` if all hooks returned `>= 0`, `0` if any returned `< 0`). [F32]
- In `security_mmap_file(file, prot, flags)`, the `mmap_file` hook must receive the application-requested `prot` as `reqprot` first and the kernel-adjusted `mmap_prot(file, prot)` (which adds `PROT_EXEC` under `READ_IMPLIES_EXEC`) as `prot` second. [F44]
- In `security_inode_rename()`, when `flags & RENAME_EXCHANGE` is set, `inode_rename` must be called twice: first with `(new_dir, new_dentry, old_dir, old_dentry)` and, if that returns `0`, with `(old_dir, old_dentry, new_dir, new_dentry)`; in `security_inode_setxattr()` and `security_inode_removexattr()`, `cap_inode_setxattr()`/`cap_inode_removexattr()` must run before `inode_setxattr`/`inode_removexattr` whenever `call_int_hook(inode_xattr_skipcap, name)` returns `0`. [F45, F91]
- LSM allocators and hooks taking a `gfp_t` (`security_inode_alloc`, `security_cred_alloc_blank`, `security_prepare_creds`, `security_sk_alloc`, `security_xfrm_policy_alloc`, `security_audit_rule_init`, `lsm_inode/cred/sock_alloc`) must propagate that `gfp_t` instead of using `GFP_KERNEL`; `security_inode_init_security()` and its hooks run inside filesystem transactions and must use `GFP_NOFS`; hooks under `security_sock_rcv_skb()`, `security_file_send_sigiotask()`, `security_task_free()`, and `security_file_set_fowner()` must never sleep. [F114, F115, F116]
- Any `xfrm_decode_session` hook must return `0` when `ckall == 0` because `security_skb_classify_flow()` asserts `BUG_ON(rc)`; `file_ioctl`, `file_ioctl_compat`, and `file_fcntl` hooks must never dereference or `copy_from_user()` `@arg`; `securityfs_create_symlink()` with `target == NULL` requires a non-`NULL` `iops` implementing `.readlink` and `.get_link`. [F131, F135, F139]
- `ipv4_skb_to_auditdata()` and `ipv6_skb_to_auditdata()` require a non-`NULL` `ad->u.net`, treat `proto` as nullable, and return `0` (with `sport`/`dport` unset) when L4 headers cannot be read: `ipv4_skb_to_auditdata()` must return `0` on non-initial fragments (`ntohs(ih->frag_off) & IP_OFFSET`), and `ipv6_skb_to_auditdata()` must use `ipv6_skip_exthdr()` and `skb_header_pointer()` rather than direct L4 pointer casts. [F41, F133]

## Error Handling
- In `include/linux/lsm_hook_defs.h`, any `int`-returning `LSM_HOOK` where `0` means a handled operation or populated out-parameter rather than a no-op must use a negative error sentinel (e.g., `-EOPNOTSUPP`, `-ENOPROTOOPT`, `-ENOPARAM`, `-EINVAL`) as its `DEFAULT` argument so `call_int_hook()` does not treat `0` as unhandled. [F30]
- Multi-LSM hooks where `0` is a non-default success return but all active LSMs must run must use `lsm_for_each_hook()` instead of `call_int_hook()`: `security_fs_context_parse_param()` continues on `0` (setting `rc = 0`) or `-ENOPARAM` and aborts on other values; `security_task_prctl()` ignores `-ENOSYS` (`LSM_RET_DEFAULT(task_prctl)`), sets `rc = thisrc`, and breaks only when `thisrc != 0`; `security_inode_init_security()` ignores `-EOPNOTSUPP` (normalizing it to `0`) and jumps to `out` to free `new_xattrs` only on other non-zero returns. [F31, F80, F81, F82]
- When `devcgroup_update_access()` handles `DEVCG_ALLOW` for `'a'` with a non-`NULL` `parent`, it must back up `devcgroup->exceptions` into `tmp_devcgrp.exceptions` before `dev_exception_clean(devcgroup)`, restore it via `dev_exceptions_move()` if `dev_exceptions_copy(&devcgroup->exceptions, &parent->exceptions)` fails, and set `devcgroup->behavior = DEVCG_DEFAULT_ALLOW` only on success; `dev_exceptions_copy()` must `list_del()` and `kfree()` all entries already added to `dest` if any `kmemdup()` fails. [F4, F5]
- `security_cred_free()`, `security_bdev_free()`, and `security_free_mnt_opts()` must return early when their blob pointer (`cred->security`, `bdev->bd_security`, `*mnt_opts`) is `NULL`; `securityfs_create_file/dir/symlink()` always return `ERR_PTR(-errno)` on failure (never `NULL`), and `securityfs_remove()` accepts `IS_ERR_OR_NULL(dentry)`. [F38, F39]

## External Contracts
- LSM syscalls and helpers (`sys_lsm_get_self_attr`, `sys_lsm_set_self_attr`, `sys_lsm_list_modules`, `security_getselfattr`, `security_setselfattr`, `lsm_fill_user_ctx`, and `getselfattr`/`setselfattr` hooks) must use `u32` (never `size_t`) for buffer sizes and size pointers; `lsm_fill_user_ctx()` must align total length to `sizeof(void *)` (`ALIGN(struct_size(nctx, ctx, val_len), sizeof(void *))`), always update `*uctx_len` to that aligned size even on `-E2BIG` or when `uctx == NULL`, and zero-fill padding via `kzalloc()` before `copy_to_user()`. [F137, F140]
- In `security_setselfattr()`, `size` must be within `[sizeof(struct lsm_ctx), PAGE_SIZE]` before `memdup_user()`, and the copied `lctx` must satisfy `size >= lctx->len`, `!check_add_overflow(sizeof(*lctx), lctx->ctx_len, &required_len)`, and `lctx->len >= required_len`; in `security_getselfattr()`, non-zero `flags` must equal `LSM_FLAG_SINGLE` with non-`NULL` `uctx` and `lctx.id != LSM_ID_UNDEF`; in `sys_lsm_list_modules()`, `flags` must be `0`, `total_size = lsm_active_cnt * sizeof(*ids)` must be written to `*size` before returning `-E2BIG`, and success returns `lsm_active_cnt`. [F64, F67, F68]
- 32-bit compat ioctl paths must call `security_file_ioctl_compat()` rather than `security_file_ioctl()`, and any LSM registering `file_ioctl` must also register `file_ioctl_compat` to mediate compat ioctls. [F138]
- In `security/min_addr.c`, `min_addr_sysctl_table` (`vm.mmap_min_addr`) must bind `.data` to `&dac_mmap_min_addr` (not `&mmap_min_addr`), require `CAP_SYS_RAWIO` on writes in `mmap_min_addr_handler()`, and call `update_mmap_min_addr()` so `mmap_min_addr` is clamped to at least `CONFIG_LSM_MMAP_MIN_ADDR`. [F142]

## Known Pitfalls
- In `security_getselfattr()`, each hook's destination pointer must advance by byte offset `(struct lsm_ctx __user *)(base + total)` rather than array indexing, and when a hook returns `-E2BIG`, `left` must be set to `0` (not decremented by `entrysize`, which would underflow unsigned `u32 left`) while still adding `entrysize` to `total`. [F66]
- In `audit_log_lsm_data()`, for `AF_UNIX` sockets without `u->path.dentry`, pathname addresses (`*p != '\0'`) use `audit_log_untrustedstring(ab, p)`, whereas abstract addresses (`*p == '\0'`) must use `audit_log_n_hex(ab, p, len)` with `len = addr->len - sizeof(short)`; in `kernel_load_data_id_str()`, `enum kernel_load_data_id` must be cast to `unsigned` before comparing `>= LOADING_MAX_ID` so negative values fall back to `kernel_load_data_str[LOADING_UNKNOWN]`. [F76, F95]

## Other
- `static_calls_table` in `security/security.c` must remain aligned to `sizeof(u64)` (`__aligned(sizeof(u64))`) despite `struct lsm_static_calls_table` being `__packed`, because early LSMs access `static_calls_table` before architecture unaligned-access fault handlers are initialized. [F122]
