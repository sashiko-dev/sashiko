# ARM SMMU DRIVERS

This unit implements the Linux IOMMU subsystem drivers for ARM System MMU architectures (SMMUv1, SMMUv2, and SMMUv3) along with the CPU-agnostic ARM LPAE (v7/v8 long-descriptor, stage-1/stage-2, and Mali) and ARMv7s (short-descriptor) I/O page table allocators. It manages DMA address translation, stream tables (STEs) and stream mapping groups (SMRs/S2CRs), context descriptors (CDs) and context banks, hardware command/event/PRI queues, TLB/ATC invalidations, fault reporting (IOPF), and IOMMUFD nested virtualization (vSMMU).

## Architecture & Data Flow
- In `arm_smmu_attach_commit()`, `arm_smmu_remove_master_domain()` for `state->old_domain` must precede updating `master->ats_enabled = state->ats_enabled` so it inspects the prior `ats_enabled` state to decrement `smmu_domain->nr_ats_masters`. Because `arm_smmu_attach_prepare()` adds the new `arm_smmu_master_domain` to `smmu_domain->devices` first, `arm_smmu_find_master_domain()` must match `master`, `domain`, `ssid`, and `nested_ats_flush`, and `arm_smmu_remove_master_domain()` must unlink only that single entry. [F3, F123]
- In `arm_smmu_write_cd_entry()`, `master->cd_table.used_ssids` must be incremented or decremented only when `ssid != IOMMU_NO_PASID` and the `CTXDESC_CD_0_V` bit of `cdptr->data[0]` differs from `target->data[0]`. Broken by: changing `used_ssids` unconditionally in `arm_smmu_set_pasid()`, for `IOMMU_NO_PASID`, or when replacing a valid CD with a valid faulting CD (such as `arm_smmu_mm_release()`). [F9]
- In SMMUv3, every bit set in `target` by `arm_smmu_make_*_ste()` or `arm_smmu_make_*_cd()` must be marked in `target_used` by `arm_smmu_get_ste_used()` or `arm_smmu_get_cd_used()` or `arm_smmu_entry_qword_diff()` warns and breaks hitless updates. In `arm_smmu_get_ste_used()`, the stage-1 (`cfg & BIT(0)`) and stage-2 (`cfg & BIT(1)`) checks must remain independent `if` statements so `STRTAB_STE_0_CFG_NESTED` (`0b111`) marks both. Whenever `arm_smmu_install_ste_for_dev()` installs an STE, `master->cd_table.in_ste` and `master->ste_ats_enabled` must be updated in lockstep. [F73, F111, F116]
- In SMMUv3, `to_smmu_domain()` is valid only for paging and SVA domains; `IOMMU_DOMAIN_NESTED` uses `to_smmu_nested_domain()`, identity/blocked domains are bare `struct iommu_domain`, and paths accepting arbitrary domains must use `to_smmu_domain_devices()`. In SMMUv1/v2, `smmu_domain->smmu`, `pgtbl_ops`, and `flush_ops` remain NULL after `arm_smmu_domain_alloc_paging()` until `arm_smmu_init_domain_context()` succeeds in `arm_smmu_attach_dev()`, so domain callbacks (`arm_smmu_map_pages()`, `arm_smmu_iotlb_sync()`) must null-check them. [F55, F58]
- In SMMUv3, `struct arm_smmu_ctx_desc_cfg` is a union (`.linear` vs `.l2`) discriminated by `cd_table->s1fmt` and accessed only when `arm_smmu_cdtab_allocated(cd_table)` is true. `struct arm_smmu_strtab_cfg` is a union (`.linear` vs `.l2`) discriminated by `smmu->features & ARM_SMMU_FEAT_2_LVL_STRTAB`, and `arm_smmu_sid_in_range()` must verify `arm_smmu_strtab_l1_idx(sid) < l2.num_l1_ents` or `sid < linear.num_ents` before `arm_smmu_init_sid_strtab()` or `arm_smmu_get_step_for_sid()` indexes the table. [F56, F57, F97]
- In SMMUv1/v2 (`arm-smmu.c`), `smmu->smrs` is NULL when hardware uses stream indexing (`!(ARM_SMMU_FEAT_STREAM_MATCH)`), so any access to `smmu->smrs` must check `smmu->smrs != NULL`, and `arm_smmu_probe_device()` must validate every `fwspec->ids[i]` against `smmu->streamid_mask` and `smmu->smr_mask_mask` before `arm_smmu_find_sme()` indexes `smmu->s2crs` directly. In `arm_smmu_device_cfg_probe()`, `smmu->s2crs` entries must be initialized to `s2cr_init_val` (`S2CR_TYPE_FAULT` or `S2CR_TYPE_BYPASS`), never zeroed, because `type == 0` is `S2CR_TYPE_TRANS`. [F59, F65, F98]
- In SMMUv3 `arm_smmu_gerror_handler()`, active errors are `(gerror ^ gerrorn) & GERROR_ERR_MASK` and must be acknowledged by writing the read `gerror` value (not `active`) to `ARM_SMMU_GERRORN`. In `arm_smmu_evtq_thread()` and `arm_smmu_priq_thread()`, after `queue_remove_raw()` drains `q->llq`, the outer loop must call `queue_sync_prod_in(q)` and recheck `!queue_empty(llq)` before `queue_sync_cons_ovf(q)`. [F131, F173]
- Because a stage-2 LPAE PGD can concatenate up to `ARM_LPAE_S2_MAX_CONCAT_PAGES` pages at `data->start_level`, `__arm_lpae_map()` and `__arm_lpae_unmap()` must cap contiguous leaf operations with `arm_lpae_max_entries()` to a single table page, while `__arm_lpae_free_pgtable()` and `__arm_lpae_iopte_walk()` must use `ARM_LPAE_PGD_SIZE(data)`. [F106]

## Synchronization
- `arm_smmu_asid_lock` must be held continuously across `arm_smmu_attach_prepare()`, STE/CD installation, and `arm_smmu_attach_commit()`, and all acquisitions of `smmu_domain->devices_lock` must use `spin_lock_irqsave()`/`spin_unlock_irqrestore()` because `arm_smmu_atc_inv_domain()` acquires it in atomic/IRQ-disabled contexts. In `arm_smmu_set_pasid()`, `CTXDESC_CD_0_ASID` in `cd->data[0]` must be rewritten from `smmu_domain->cd.asid` after acquiring `arm_smmu_asid_lock` and before `arm_smmu_write_cd_entry()`. [F30, F32, F180]
- When disabling ATS during attachment (`!state->ats_enabled && master->ats_enabled`), `arm_smmu_attach_prepare()` must call `pci_disable_ats()` and `wmb()` before STE `EATS` is cleared; when enabling ATS, `arm_smmu_attach_commit()` must call `arm_smmu_enable_ats()` only after the STE with `EATS` enabled is installed. In `arm_smmu_atc_inv_domain()`, `smp_mb()` must run after main TLB invalidations and before `atomic_read(&smmu_domain->nr_ats_masters)` to pair with `atomic_inc(&smmu_domain->nr_ats_masters)` in `arm_smmu_attach_prepare()`. [F29, F31]
- In `arm_smmu_write_entry()`, because SMMUv3 hardware only guarantees 64-bit atomicity on 8-qword descriptors, any update where `arm_smmu_entry_qword_diff()` reports in-use changes in multiple qwords must first zero qword 0 (`V=0`) via `entry_set()`, then write qwords 1..7 and sync, and finally write qword 0 (`V=1`) and sync. In `arm_smmu_alloc_cd_ptr()`, after writing a new L1 CD descriptor with `arm_smmu_write_cd_l1_desc()`, `arm_smmu_sync_cd(master, ssid, false)` must be called to invalidate any cached invalid L1 CD. [F27, F28]
- In `arm_smmu_cmdq_issue_cmdlist()` and `arm_smmu_cmdq_exclusive_trylock_irqsave()`, local IRQs must stay disabled via `local_irq_save()` while holding `CMDQ_PROD_OWNED_FLAG` or `cmdq->lock` (restoring IRQs before `arm_smmu_cmdq_poll_until_not_full()`). `dma_wmb()` must precede `arm_smmu_cmdq_set_valid_map()`, the queue owner must call `arm_smmu_cmdq_poll_valid_map()` and `writel_relaxed(prod, cmdq->q.prod_reg)` before releasing `cmdq->owner_prod` via `atomic_set_release()`, and `__arm_smmu_cmdq_poll_until_consumed()` must use non-relaxed `readl(cmdq->q.cons_reg)` before `arm_smmu_cmdq_shared_tryunlock()`. [F24, F25, F179]
- `smmu->streams_mutex` protects both the `smmu->streams` RB-tree and `master->vmaster` (`arm_smmu_find_master()`, `arm_smmu_attach_commit_vmaster()`, `arm_vmaster_report_event()`). Per-master `master->cd_table` and `master->iopf_refcount` are protected by the device's IOMMU group mutex (`iommu_group_mutex_assert(master->dev)`), which must be held when calling `arm_smmu_alloc_cd_ptr()`, `arm_smmu_enable_iopf()`, `arm_smmu_disable_iopf()`, or `arm_smmu_attach_prepare_vmaster()`. [F34, F35]
- In `arm_smmu_sva_set_dev_pasid()`, `mmget_not_zero(domain->mm)` must be acquired before `arm_smmu_make_sva_cd()` and `arm_smmu_set_pasid()` and released with `mmput(domain->mm)` afterwards to prevent `arm_smmu_mm_release()` from concurrently invalidating the CD. In `arm_vsmmu_vsid_to_sid()`, `xa_lock(&vsmmu->core.vdevs)` must be held across both `iommufd_viommu_find_dev()` and reading `master->streams[0].id` from `dev_iommu_priv_get(dev)`. [F36, F38]
- In SMMUv1/v2 (`arm-smmu.c`), `smmu->stream_map_mutex` must be held whenever accessing `smmu->smrs`, `smmu->s2crs` reference counts and group pointers, or `cfg->smendx` (and `arm_smmu_device_group()` must unlock on every return path and call `iommu_group_ref_get(group)` when returning a cached group). `smmu_domain->cb_lock` must be held across `arm_smmu_tlb_sync_context()` and `ATS1PR`/`ATSR`/`PAR` accesses in `arm_smmu_iova_to_phys_hard()`, while `smmu->global_sync_lock` serializes `arm_smmu_tlb_sync_global()`. [F15, F42, F44]
- In `arm_lpae_install_table()` and `arm_v7s_install_table()`, `dma_wmb()` must precede `cmpxchg64_relaxed()`/`cmpxchg_relaxed()`, and if `cmpxchg` loses a race in `__arm_lpae_map()` or `__arm_v7s_map()`, the caller must free its table and use the winning PTE. When `!cfg->coherent_walk`, `__arm_lpae_alloc_pages()` and `__arm_v7s_alloc_table()` must DMA-map tables with `dma_map_single(..., DMA_TO_DEVICE)` and reject `dma != virt_to_phys(pages)`, PTE writes must call `__arm_lpae_sync_pte()`/`__arm_v7s_pte_sync()`, and any thread observing an LPAE table PTE without `ARM_LPAE_PTE_SW_SYNC` must call `__arm_lpae_sync_pte()` before walking it. [F45, F46, F192]

## Object Lifetimes
- Once `arm_smmu_attach_prepare()` succeeds, the caller must complete the sequence by installing the STE/CD and calling `arm_smmu_attach_commit()`, which consumes `state->vmaster` and removes `state->old_domain` from `smmu_domain->devices`. When attaching an identity or blocked domain in `arm_smmu_attach_dev_identity()` or `arm_smmu_attach_dev_blocked()`, `arm_smmu_master_clear_vmaster()` (or `arm_smmu_attach_commit_vmaster()` with `state->vmaster == NULL`) must free `master->vmaster` and set it to `NULL` under `smmu->streams_mutex`. [F2, F6]
- In `arm_smmu_enable_iopf()`, `master->iopf_refcount` is incremented and `master_domain->using_iopf` is set to `true` only when `master->stall_enabled` is true, and `arm_smmu_disable_iopf()` must only decrement `master->iopf_refcount` and call `iopf_queue_remove_device()` when `master_domain->using_iopf` is true. [F8]
- `acpi_smmu_dsdt_probe_tegra241_cmdqv()` acquires a reference on `smmu->impl_dev` via `acpi_dev_get_first_match_dev()` that is transferred to `tegra241_cmdqv_probe()` in `arm_smmu_impl_probe()`, so no error return may occur between them without `put_device(smmu->impl_dev)`. Likewise, `arm_smmu_decode_event()` acquires `get_device(master->dev)` under `smmu->streams_mutex`, which `arm_smmu_evtq_thread()` must release via `put_device(event.dev)` on every iteration. [F11, F12]
- Per-master context descriptor tables (`master->cd_table`) in SMMUv3 must be allocated with non-devres `dma_alloc_coherent(smmu->dev, ...)` and `kcalloc()` in `arm_smmu_alloc_cd_tables()`/`arm_smmu_alloc_cd_ptr()` and freed in `arm_smmu_free_cd_tables()` during `arm_smmu_release_device()`, never with `dmam_alloc_coherent(smmu->dev, ...)`. In `arm_smmu_sva_domain_free()`, `arm_smmu_tlb_inv_asid()` must run before `xa_erase(&arm_smmu_asid_xa, smmu_domain->cd.asid)` and the domain must be freed via `mmu_notifier_put()`, while `arm_smmu_driver_unregister()` must call `arm_smmu_sva_notifier_synchronize()` before `platform_driver_unregister()`. [F37, F162]
- In `arm-smmu.c`, every post-probe function that accesses SMMU registers (`arm_smmu_attach_dev()`, `arm_smmu_iova_to_phys_hard()`, `arm_smmu_destroy_domain_context()`) must pair a successful `arm_smmu_rpm_get(smmu)` with `arm_smmu_rpm_put(smmu)` on every exit path. When `__arm_lpae_unmap()` or `__arm_v7s_unmap()` replaces or unmaps a non-leaf table PTE, it must clear and DMA-sync the parent PTE (`__arm_lpae_clear_pte()` / `__arm_v7s_set_pte()`) and flush walk caches via `io_pgtable_tlb_flush_walk()` before freeing the child table. [F19, F21]

## API Contracts
- In SMMUv3, `arm_smmu_domain_alloc()` returns an `ERR_PTR` (`ERR_PTR(-ENOMEM)`) on failure rather than `NULL`, so callers must check `IS_ERR()` and propagate via `ERR_CAST()`. Implementation probe hooks called by `arm_smmu_impl_probe()` (such as `tegra241_cmdqv_probe()`) must return `ERR_PTR(-ENODEV)` for a non-fatal fallback to standard SMMUv3, a `devm_krealloc`'d `arm_smmu_device` pointer on match (with `struct arm_smmu_device` at offset 0), or another `ERR_PTR` to abort probing. [F48, F49, F145]
- In `arm_lpae_map_pages()` and `arm_v7s_map_pages()`, intermediate table allocations in `__arm_lpae_alloc_pages()` and `__arm_v7s_alloc_table()` must use the caller-supplied `gfp` flags rather than `GFP_KERNEL`, return `-EINVAL` when neither `IOMMU_READ` nor `IOMMU_WRITE` is set in `prot`, and advance `*mapped` on each mapped page or block. In `arm_lpae_map_pages()` and `arm_lpae_unmap_pages()`, upper IOVA bits must be checked via `long iaext = (s64)iova >> cfg->ias` with `iaext = ~iaext` when `IO_PGTABLE_QUIRK_ARM_TTBR1` is set. In `__arm_lpae_unmap()` and `__arm_v7s_unmap()`, `gather` may be NULL and must be queried via `iommu_iotlb_gather_queued(gather)`. [F60, F99, F178, F195]

## Error Handling
- `arm_smmu_find_sme()` and `arm_smmu_alloc_context_bank()` return a non-negative index on success or a negative errno (`-ENOSPC`, `-EINVAL`) on failure, so callers must store the return value in a signed `int` and check `< 0` before narrowing to `u8 cbndx` or `s16 smendx`. In both SMMUv1/v2 and SMMUv3 `arm_smmu_attach_dev()`, validation failures (such as `smmu_domain->smmu != smmu`) after a prior call set `ret = 0` must explicitly assign or return a negative errno (`-EINVAL`) rather than returning `ret`. [F50, F62]
- `arm_smmu_handle_event()` must capture and return the status of `iommu_report_device_fault()` and `arm_vmaster_report_event()` (or a negative errno for unhandled events) so `arm_smmu_evtq_thread()` dumps unhandled events via `arm_smmu_dump_event()`. [F51]

## External Contracts
- In `arm-smmu-v3-iommufd.c`, `arm_smmu_validate_vste()` and `arm_vsmmu_alloc_domain_nested()` must reject any set bits outside `STRTAB_STE_0_NESTING_ALLOWED` and `STRTAB_STE_1_NESTING_ALLOWED` with `-EIO` and clear `STRTAB_STE_1_EATS` from `ste[1]` so physical `EATS` is controlled solely by `state.ats_enabled`. In `arm_smmu_handle_event()` and `arm_vmaster_report_event()`, only non-stage-2 (`!event->s2`) events for a master with a `vmaster` may be forwarded via `iommufd_viommu_report_event()`, and `arm_vmaster_report_event()` must overwrite `EVTQ_0_SID` with `vmaster->vsid` under `smmu->streams_mutex`. [F94, F202]

## Known Pitfalls
- In `drivers/iommu/arm/arm-smmu-v3/`, all `STRTAB_STE_*` and `CTXDESC_CD_*` bitmask constants except `STRTAB_STE_0_NESTING_ALLOWED` and `STRTAB_STE_1_NESTING_ALLOWED` are CPU-endian, so masking or setting `__le64` STE/CD words requires `cpu_to_le64()` (and `FIELD_GET()` requires `le64_to_cpu()`). Also, `event_str[]` is a sparse table indexed by 8-bit `event->id`, so `ARM_SMMU_EVT_KNOWN()` must check both `(e)->id < ARRAY_SIZE(event_str)` and `event_str[(e)->id]` before `ARM_SMMU_LOG_EVT_STR()` dereferences it. [F108, F109]
- During LPAE page table allocation (`arm_64_lpae_alloc_pgtable_s1`/`s2`, `arm_mali_lpae_alloc_pgtable`, `arm_lpae_concat_mandatory`, `__arm_lpae_alloc_pages`), configuration fields must be read from the `cfg` and `cookie` arguments rather than `data->iop.cfg` or `data->iop.cookie`. In `io-pgtable-arm.c`, `iopte_writeable_dirty()` must mask with `ARM_LPAE_PTE_AP_WR_CLEAN_MASK` (`ARM_LPAE_PTE_AP_RDONLY | ARM_LPAE_PTE_DBM`) and compare equal to `ARM_LPAE_PTE_DBM`, because clean writeable dirty-tracked PTEs have both `DBM` and `AP_RDONLY` set. [F63, F114]
- When `arm_lpae_init_pte()` or `arm_v7s_init_pte()` unmaps an existing next-level table before overwriting `ptep[i]` with a block PTE, it must subtract the current level's index (`tblp = ptep - ARM_LPAE_LVL_IDX(iova, lvl, data)` or `ptep - ARM_V7S_LVL_IDX(iova, lvl, cfg)`) and pass `tblp` (not `ptep`) to `__arm_lpae_unmap()` or `__arm_v7s_unmap()`. Also, `ARM_LPAE_PGD_SIZE(data)` and `ARM_LPAE_GRANULE(data)` evaluate to byte sizes rather than PTE counts, so advancing `arm_lpae_iopte *ptep` requires casting to `(void *)` and computing entry counts requires dividing by `sizeof(arm_lpae_iopte)`. [F133, F151]
