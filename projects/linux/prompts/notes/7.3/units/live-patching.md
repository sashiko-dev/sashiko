# LIVE PATCHING

The LIVE PATCHING subsystem applies and reverts function-level patches to a running Linux kernel (`vmlinux`) and loadable modules without rebooting. It redirects patched functions via ftrace (`klp_ftrace_handler`), enforces per-task consistency using reliable stack traces and thread flags (`TIF_PATCH_PENDING`) during transitions, resolves deferred ELF livepatch relocations (`.klp.rela.*` / `SHN_LIVEPATCH`) across module load/unload, and provides shadow variables (`klp_shadow_*`) and system state tracking (`klp_state`).

## Architecture & Data Flow
- For a NOP `struct klp_func` (`func->nop == true`), `func->new_func` is `NULL` while the target object is unloaded and is set to `func->old_func` only in `klp_init_object_loaded()`; code inspecting `func->new_func` before object load or in `klp_ftrace_handler()` must check `func->nop` first. [F33]
- When `func->transition` is true and `current->patch_state == KLP_TRANSITION_UNPATCHED`, `klp_ftrace_handler()` advances `func` to `list_entry_rcu(func->stack_node.next, struct klp_func, stack_node)` and must jump to `unlock` if `&func->stack_node == &ops->func_stack` before reading `func->nop` or `func->new_func`. [F67]
- Every transition pass updating or checking `patch_state` or `TIF_PATCH_PENDING` (`klp_init_transition`, `klp_start_transition`, `klp_try_complete_transition`, `klp_complete_transition`, `klp_reverse_transition`, `klp_force_transition`) must iterate `idle_task(cpu)` via `for_each_possible_cpu()` alongside `for_each_process_thread()`; `klp_try_complete_transition()` must call `klp_try_switch_task()` on every task and online idle task without breaking early, call `wake_up_if_idle(cpu)` when an online idle task cannot switch, and directly switch offline CPUs' idle tasks under `cpus_read_lock()`. [F43, F73]
- When `nops_only` is true in `__klp_unpatch_object()` and `__klp_free_objects()`, only `klp_func` entries with `func->nop` set may be unpatched and freed, and `obj->patched` and `obj` itself must only be cleared or freed if `obj->dynamic` is true. [F47]
- Because `klp_init_patch()` appends `new_patch` to the tail of `klp_patches`, `klp_unpatch_replaced_patches()` and `klp_free_replaced_patches_async()` must `return` immediately (not `continue`) upon reaching `old_patch == new_patch` so they only process prior patches. [F69]
- In `klp_write_section_relocs()`, when `apply` is true, `klp_resolve_symbols()` must resolve every `SHN_LIVEPATCH` symbol's address into `sym->st_value` before `apply_relocate_add()`, and must reject `vmlinux` symbols in module-specific `.klp.rela.*` sections. [F55]
- In `klp_match_callback()`, when `args->pos == 0`, the callback must return `0` on the first match (`args->count == 1`) to continue scanning and only return `1` when `args->count > 1`, so `klp_find_object_symbol()` detects duplicate symbols and rejects `sympos == 0` with `-EINVAL`. [F64]

## Synchronization
- `klp_ftrace_handler()` must be marked `notrace` and disable preemption via `ftrace_test_recursion_trylock()` before reading `ops->func_stack`, and `klp_update_patch_state()` must wrap `test_and_clear_tsk_thread_flag(task, TIF_PATCH_PENDING)` and `task->patch_state = READ_ONCE(klp_target_state)` in `preempt_disable_notrace()` / `preempt_enable_notrace()` (with `task` being `current` or inactive unless in `klp_force_transition()`), so `klp_synchronize_transition()` (`schedule_on_each_cpu(klp_sync)`) waits for both even when RCU is not watching. [F24, F84, F90]
- In `klp_init_transition()`, `klp_target_state` and every task's `patch_state` (including idle tasks) must be initialized followed by `smp_wmb()` before setting `func->transition = true`, and in `__klp_enable_patch()`, `klp_init_transition()` and a second `smp_wmb()` must precede `klp_patch_object()`; both pair with `smp_rmb()` in `klp_ftrace_handler()` so `func->transition` is seen as `true` and `patch_state` is never `KLP_TRANSITION_IDLE`. [F16, F17]
- In `__klp_disable_patch()` and `klp_reverse_transition()`, `smp_wmb()` must precede `klp_start_transition()` (ordering `func->transition = true` or inverted `klp_target_state` before `TIF_PATCH_PENDING`), pairing with `test_and_clear_tsk_thread_flag()` in `klp_update_patch_state()`; in `klp_reverse_transition()`, clearing `TIF_PATCH_PENDING` on all tasks/idle threads and calling `klp_synchronize_transition()` must precede inverting `klp_transition_patch->enabled` and `klp_target_state`. [F18, F23]
- In `klp_complete_transition()`, when `klp_target_state == KLP_TRANSITION_UNPATCHED`, `klp_unpatch_objects()` and `klp_synchronize_transition()` must precede clearing `func->transition = false`; when `KLP_TRANSITION_PATCHED`, clearing `func->transition = false` and calling `klp_synchronize_transition()` must precede resetting `task->patch_state = KLP_TRANSITION_IDLE`. [F21, F22]
- Every `for_each_process_thread()` loop in `kernel/livepatch/transition.c` must hold `read_lock(&tasklist_lock)` to serialize against `klp_copy_process()` during `fork()`, and `klp_try_complete_transition()` must release `tasklist_lock` before acquiring `cpus_read_lock()` (a sleeping lock) to inspect CPUs' `idle_task(cpu)`. [F29, F93]
- In `klp_copy_process()`, both `child->patch_state` and `child`'s `TIF_PATCH_PENDING` flag must be explicitly synchronized with `current` (setting or clearing `TIF_PATCH_PENDING` to match `current`), because a transition may have mutated `current` after `setup_thread_stack()`. [F42]
- `klp_check_and_switch_task()` and `klp_check_stack()` must run with preemption disabled (`lockdep_assert_preemption_disabled()`) to protect per-CPU `klp_stack_entries` (`MAX_STACK_ENTRIES`), invoking `klp_check_and_switch_task()` via `task_call_func()` when `task != current` so the task is pinned inactive; `klp_check_stack_func()` checks stack addresses against `[func_addr, func_addr + func_size)` using `func->new_func`/`func->new_size` when `KLP_TRANSITION_UNPATCHED`, `func->old_func`/`func->old_size` when patching a singular `ops->func_stack`, and `prev->new_func`/`prev->new_size` (`prev = list_next_entry(func, stack_node)`) when stacked. [F28, F61, F74]
- Sysfs store handlers (`enabled_store()`, `force_store()`) and `klp_transition_work_fn()` must hold `klp_mutex` continuously while checking `klp_transition_patch` and calling transition functions, and every error path in `klp_enable_patch()` after `mutex_lock(&klp_mutex)` (including `!klp_is_patch_compatible(patch)` or `!try_module_get(patch->mod)`) must unlock `klp_mutex`. [F4, F26]
- `klp_find_object_module()` must hold `rcu_read_lock()` (`guard(rcu)()`) while calling `find_module(obj->name)` and reading `mod->klp_alive`, and only assign `obj->mod` when `mod->klp_alive` is true (updated by `klp_module_coming()`/`klp_module_going()` under `klp_mutex`). [F27]
- `klp_shadow_get()` traverses `klp_shadow_hash` under `rcu_read_lock()`, while mutations hold `spin_lock_irqsave(&klp_shadow_lock, flags)`; `__klp_shadow_get_or_alloc()` runs `kzalloc()` unlocked after an initial `klp_shadow_get()`, then under `klp_shadow_lock` re-checks `klp_shadow_get(obj, id)`, initializes `new_shadow`, and runs `ctor` in atomic context before `hash_add_rcu()`, while `klp_shadow_free_struct()` runs `dtor` under `klp_shadow_lock`, unlinks via `hash_del_rcu()`, and frees via `kfree_rcu()`. [F30, F85, F86]

## Object Lifetimes
- Every `klp_free_patch_start(patch)` call (under `klp_mutex`) must be paired with `klp_free_patch_finish(patch)` outside `klp_mutex`, either directly on synchronous failure in `klp_enable_patch()` or via `patch->free_work` in `klp_free_patch_async()`; `klp_free_patch_async()` and `klp_free_replaced_patches_async()` must be called from `klp_try_complete_transition()`, not `klp_complete_transition()` (which `klp_cancel_transition()` also calls when `klp_enable_patch()` frees synchronously). [F1, F12]
- `klp_free_patch_finish()` must call `wait_for_completion(&patch->finish)` (completed by `klp_kobj_release_patch()`) before `module_put(patch->mod)`, must not access `patch` afterwards except to read `patch->forced` and `patch->mod`, and must skip `module_put(patch->mod)` whenever `patch->forced` is true (set by `klp_force_transition()` on `klp_transition_patch` when unpatching or on all prior patches when `klp_transition_patch->replace` is set). [F2, F3]
- Once `klp_alloc_object_dynamic()` or `klp_alloc_func_nop()` calls `klp_init_object_early()` or `klp_init_func_early()`, ownership transfers to its `kobject` and it must only be freed by `klp_kobj_release_object()` or `klp_kobj_release_func()` via `kobject_put()`, never by direct `kfree()`, `klp_free_object_dynamic()`, or `klp_free_func_nop()`. [F5]
- When completing a `replace` transition to `KLP_TRANSITION_PATCHED` in `klp_complete_transition()`, `klp_unpatch_replaced_patches(klp_transition_patch)` must run before `klp_discard_nops(klp_transition_patch)` so each NOP `klp_func` is the sole remaining entry in `ops->func_stack` when `klp_unpatch_func()` unpatches and frees it. [F6]
- In `klp_patch_func()`, a new `struct klp_ops` must have `ops->node` and `func->stack_node` linked into `klp_ops` and `ops->func_stack` before `register_ftrace_function(&ops->fops)`, and if registration fails, the filter from `ftrace_set_filter_ip()` must be cleared (`ftrace_set_filter_ip(&ops->fops, ftrace_loc, 1, 0)`) before unlinking and freeing `ops`. [F7]
- Because `klp_find_ops()` identifies a shared `struct klp_ops` via `list_first_entry(&ops->func_stack, struct klp_func, stack_node)->old_func`, `klp_unpatch_func()` must only unlink `func->stack_node` when `ops->func_stack` has multiple entries, and when `list_is_singular(&ops->func_stack)` it must call `unregister_ftrace_function(&ops->fops)` and `ftrace_set_filter_ip(&ops->fops, ftrace_loc, 1, 0)` before `list_del_rcu(&func->stack_node)` and `kfree(ops)`. [F8, F48]
- `klp_find_object_module()` and `klp_module_coming()` store a borrowed `struct module *` in `obj->mod` without a module refcount, and `klp_free_object_loaded()` must clear `obj->mod = NULL`, `func->old_func = NULL`, and (for `func->nop`) `func->new_func = NULL` on module unload. [F9]
- `klp_post_unpatch_callback(obj)` only invokes `obj->callbacks.post_unpatch` when `obj->callbacks.post_unpatch_enabled` is true (set by a successful `klp_pre_patch_callback(obj)`) and must clear `post_unpatch_enabled = false` afterwards. [F11]
- `copy_module_elf()` allocates `mod->klp_info`, `sechdrs`, and `secstrings` and redirects `mod->klp_info->sechdrs[symndx].sh_addr` to `mod->core_kallsyms.symtab` (since the init symtab copy is freed after `do_init_module()`), freeing them in reverse order on error and in `free_module_elf()`. [F15]

## API Contracts
- A `klp_object` targets `vmlinux` when `obj->name == NULL` and a module when `obj->name != NULL`: callers must check `klp_is_module(obj)` (or `objname != NULL`) before passing `obj->name` to string functions, `klp_module_coming()` rejects any module named `"vmlinux"`, and ELF relocation helpers translate `"vmlinux"` to a `NULL` `objname` for `klp_find_object_symbol()`. [F32, F99]
- Static arrays require zeroed sentinels: `patch->objs` ends where `!obj->funcs && !obj->name` (`klp_for_each_object_static`; testing only `obj->name` breaks on `vmlinux`), `obj->funcs` where `!func->old_name && !func->new_func && !func->old_sympos` (`klp_for_each_func_static`), and non-NULL `patch->states` where `!state->id` (`klp_for_each_state`). [F60]
- `klp_shadow_get*()` and `klp_shadow_alloc()` return a borrowed pointer to `shadow->data` (not the outer `struct klp_shadow`, allocated at `size + sizeof(*new_shadow)` bytes and zero-initialized) without refcounting; `ctor`/`dtor` receive `shadow->data`, and if `ctor` returns non-zero, allocation frees `new_shadow` and returns `NULL` (never `ERR_PTR`). [F13, F38, F77]
- `klp_get_prev_state()` requires `klp_transition_patch != NULL` and must scan `klp_patches` until `patch == klp_transition_patch` without returning on the first match so the latest prior patch's `klp_state` is returned; in `klp_is_patch_compatible()`, a `patch->replace` patch must provide a `klp_state` with `state->version >= old_state->version` for every state in `klp_patches`, whereas non-cumulative patches only check states they list. [F53, F75, F101]
- Callers of `klp_check_and_switch_task()` (directly or via `task_call_func()`) must pass a non-NULL `const char **` as `void *arg` because `klp_check_stack()` writes `*oldname = func->old_name` only when returning `-EADDRINUSE` (`klp_try_switch_task()` must not read `old_name` on other return codes). [F39, F83]
- `klp_module_going()` must accept `mod->state == MODULE_STATE_COMING` as well as `MODULE_STATE_GOING`, because `prepare_coming_module()` calls `klp_module_going()` while `mod->state == MODULE_STATE_COMING` if coming notifiers fail after `klp_module_coming()`. [F76]
- In `struct klp_func` and `klp_find_object_symbol()`, `old_sympos` / `sympos` uses `0` to require a unique symbol and `> 0` as a 1-based kallsyms match index, whereas sysfs naming in `klp_init_func()` maps `old_sympos == 0` to `1`. [F37]

## Error Handling
- `klp_init_patch_early()`, `klp_init_object_early()`, and `klp_init_func_early()` must initialize `kobj` and link every static and dynamic `klp_object` and `klp_func` into `patch->obj_list` and `obj->func_list` before any fallible step in `klp_init_patch()`, because `klp_free_patch_start()` unconditionally calls `list_del()` and `kobject_put()` on all entries. [F34]
- In `klp_module_coming()`, jumping to `err:` is only valid inside `klp_for_each_object(patch, obj)` after `obj->mod = mod` is set; `err:` dereferences `patch->mod->name` and `obj->mod->name`, runs `klp_post_unpatch_callback(obj)` if `klp_patch_object(obj)` failed after `klp_pre_patch_callback(obj)`, clears `mod->klp_alive = false` and `obj->mod = NULL`, and calls `klp_cleanup_module_patches_limited(mod, patch)` to revert only prior patches. [F10, F71]
- `__klp_unpatch_object()` must unpatch every function with `func->patched == true` even when `obj->patched` is `false`, because `klp_patch_object()` calls `klp_unpatch_object(obj)` to roll back partially patched functions before `obj->patched = true` is set. [F72]
- In `klp_init_object_loaded()`, `klp_find_object_symbol()` returns `0` on success and negative errno on error, whereas `kallsyms_lookup_size_offset()` returns non-zero on success and `0` on failure (which must be converted to `-ENOENT`). [F35]

## External Contracts
- In `enabled_store()`, after rejecting `patch->enabled == enabled` with `-EINVAL`, `if (patch == klp_transition_patch)` (calling `klp_reverse_transition()`) must precede `else if (!enabled)` (calling `__klp_disable_patch()`, which returns `-EBUSY` when `klp_transition_patch != NULL`), and re-enabling a disabled idle patch must return `-EINVAL`; in `force_store()`, writing `false` is a no-op while `true` requires `patch == klp_transition_patch` under `klp_mutex`. [F63, F105, F106]

## Known Pitfalls
- `klp_shadow_free_all()` iterates `klp_shadow_hash` with `hash_for_each()` (not `hash_for_each_safe()`) while calling `klp_shadow_free_struct()`, which is only safe because `klp_shadow_free_struct()` unlinks via `hash_del_rcu()` and defers freeing via `kfree_rcu()` under `klp_shadow_lock`. [F70]
- In `arch/powerpc/include/asm/livepatch.h`, `klp_init_thread_info()` computes `end_of_stack(p) + 1` using typed `unsigned long *` pointer arithmetic so `livepatch_sp` advances by one `unsigned long` word past `STACK_END_MAGIC`. Broken by: adding `sizeof(unsigned long)` to `end_of_stack(p)` without casting to a byte pointer, or casting to `void *`/`char *` while adding `1`. [F79]
