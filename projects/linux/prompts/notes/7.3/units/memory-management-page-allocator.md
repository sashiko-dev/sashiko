# MEMORY MANAGEMENT - PAGE ALLOCATOR

This component implements the zoned buddy page allocator, per-CPU page (PCP) caches, and page fragment allocator (`mm/page_alloc.c`, `mm/page_frag_cache.c`), along with memory compaction (`mm/compaction.c`), pageblock isolation (`mm/page_isolation.c`), per-page metadata extensions (`mm/page_ext.c`), hypervisor free-page reporting (`mm/page_reporting.c`), and page tracking (`mm/page_owner.c`).

## Architecture & Data Flow

- Under `zone->lock`, buddy freelist mutations (`__add_to_free_list`, `move_to_free_list`, `__del_page_from_free_list`) must update `area->nr_free`, `NR_FREE_PAGES_BLOCKS` (for non-isolate `order >= pageblock_order`), and `account_freepages()` in lockstep. In `move_freepages_block()` and `__move_freepages_block_isolate()`, `move_to_free_list()` must run while the pageblock still holds `old_mt` before updating pageblock migratetype or isolate flags. [F68, F70]
- When freeing to PCP in `__free_frozen_pages()` and `free_unref_folios()`, `migratetype >= MIGRATE_PCPTYPES` must never index `pcp->lists` directly: `MIGRATE_ISOLATE` must bypass PCP to `free_one_page()`, while `MIGRATE_CMA` and `MIGRATE_HIGHATOMIC` must be remapped to `MIGRATE_MOVABLE`. In `free_frozen_page_commit()`, `free_high` requires `pcp->free_count >= (batch + pcp->high_min / 2)` alongside `PCPF_PREV_FREE_HIGH_ORDER`, and must clear `PCPF_PREV_FREE_HIGH_ORDER` on order-0 or costly-order frees. [F79, F82]
- In `rmqueue_buddy()`, `ALLOC_HIGHATOMIC` tries `__rmqueue_smallest(zone, order, MIGRATE_HIGHATOMIC)` before `__rmqueue()`, whereas `ALLOC_OOM` or `ALLOC_NON_BLOCK` only fall back to `MIGRATE_HIGHATOMIC` after `__rmqueue()` fails. In `reserve_highatomic_pageblock()` and `unreserve_highatomic_pageblock()`, `order >= pageblock_order` pages must update all `1 << (order - pageblock_order)` pageblocks via `change_pageblock_range()` and adjust `zone->nr_reserved_highatomic` by `max(pageblock_nr_pages, 1UL << order)`. [F69, F106]
- In `free_tail_page_prepare()`, `case 2:` (second tail page) must unconditionally check `!list_empty(&folio->_deferred_list)` and report `bad_page()` before `out:` clears `page->mapping = NULL` (which aliases `folio->_deferred_list`). Checking `page->mapping == TAIL_MAPPING` is only valid for tail indices `page - head_page >= 4` (or `>= 3` when `!CONFIG_HUGETLB_PAGE`), because tail pages 1, 2, and (under `CONFIG_HUGETLB_PAGE`) 3 overlay `struct folio` fields on `page->mapping`. [F103, F113]
- In `isolate_migratepages_block()` and `has_unmovable_pages()`, advancing `low_pfn` or `pfn` past an isolated or skipped `PageHuge` / `PageTransCompound` `folio` starting from `page` must subtract `folio_page_idx(folio, page)` from `folio_nr_pages(folio)` because `page` can be a tail page. After the scanning loop in `isolate_freepages_block()` and `isolate_migratepages_block()`, `blockpfn` or `low_pfn` must be clamped to `end_pfn` because skipping a high-order page can advance past `end_pfn`. [F100, F110]
- Because `compact_node()` and `kcompactd_do_work()` reuse a single `struct compact_control` across zones, `compact_zone()` must reinitialize `total_migrate_scanned`, `total_free_scanned`, `nr_migratepages`, `nr_freepages`, `cc->freepages[]`, and `cc->migratepages` before any early return. When `compact_zone()` releases leftover free pages via `release_free_list(cc->freepages)`, it must update `cc->zone->compact_cached_free_pfn` to `pageblock_start_pfn(free_pfn)` only if `free_pfn > cc->zone->compact_cached_free_pfn`. [F57, F77]
- In `get_page_from_freelist()` and `__alloc_pages_slowpath()`, every `goto retry` branch that relaxes `ALLOC_NOFRAGMENT` or `skip_kswapd_nodes` must verify the flag/condition is currently active and clear it (`alloc_flags &= ~ALLOC_NOFRAGMENT` or `skip_kswapd_nodes = false`) before jumping to `retry`. [F109]
- Each `page_ext` entry has runtime stride `page_ext_size` rather than `sizeof(struct page_ext)`, so pointer arithmetic and table sizing must cast to `void *` and scale by `page_ext_size`. Under `CONFIG_SPARSEMEM`, `section->page_ext` stores `(void *)base - page_ext_size * (pfn & PAGE_SECTION_MASK)` (plus bit 0 `PAGE_EXT_INVALID` when invalidated); `lookup_page_ext()` must test `page_ext_invalid(page_ext)`, and both `lookup_page_ext()` and `__free_page_ext()` must strip `PAGE_EXT_INVALID` and pass the full `pfn` to `get_entry()`. [F53, F132, F134]
- `struct page_frag_cache::encoded_page` packs the page virtual address (`PAGE_MASK`), page order (`PAGE_FRAG_CACHE_ORDER_MASK`), and `pfmemalloc` bit (`PAGE_FRAG_CACHE_PFMEMALLOC_BIT`) into one `unsigned long`, so callers must strip metadata bits with `encoded_page_decode_virt()` (`encoded_page & PAGE_MASK`) before adding `offset`. [F101]
- `page_reporting_cycle()` fills the `PAGE_REPORTING_CAPACITY`-entry `sgl` from the end by decrementing `*offset` before `sg_set_page(&sgl[*offset], ...)`, so `page_reporting_process_zone()` must pass `&sgl[offset]` (not `sgl`) to `prdev->report()` and `page_reporting_drain()` when flushing `leftover = PAGE_REPORTING_CAPACITY - offset` pages. [F98]

## Synchronization

- When reading a `PageBuddy(page)` or compound page's order without holding `zone->lock` to advance a PFN scanner (as in `isolate_freepages_block()`, `isolate_migratepages_block()`, `pagetypeinfo_showmixedcount_print()`, `read_page_owner()`, and `init_pages_in_zone()`), callers must use `buddy_order_unsafe(page)` or `compound_order(page)` and check `order <= MAX_PAGE_ORDER` before shifting (`1UL << order`). In `isolate_freepages_block()`, after acquiring `cc->zone->lock`, `PageBuddy(page)` must be rechecked before calling `buddy_order(page)` and `__isolate_free_page()`. [F37, F44, F120]
- In `isolate_migratepages_block()`, `folio_get_nontail_page(page)` must pin `folio` before `folio_test_clear_lru(folio)` clears `PG_lru`, and whenever `lruvec->lru_lock` is newly acquired, `skip_isolation_on_order(folio_order(folio), cc->order)` must be rechecked under `lru_lock` (restoring `folio_set_lru(folio)` if skipped). When `!(cc->gfp_mask & __GFP_FS)`, compaction must skip folios with a non-NULL `folio_mapping(folio)` and must not scale down `inactive` and `active` counts by `>> 3` in `too_many_isolated()`. [F40, F155]
- In `__free_unaccepted()` and `__accept_page()`, adding or removing a `MAX_PAGE_ORDER` page on `zone->unaccepted_pages` must update `account_freepages(zone, +/-MAX_ORDER_NR_PAGES, MIGRATE_MOVABLE)`, `NR_UNACCEPTED`, and `PageUnaccepted(page)` together under `zone->lock`, and `__accept_page()` must unlock `zone->lock` before calling `accept_memory()` and `__free_pages_ok()`. [F35, F73]
- In `zone_pcp_disable()`, `pcp_batch_high_lock` must be held and `__zone_set_pageset_high_and_batch(zone, 0, 0, 1)` must zero the PCP high limits before calling `__drain_all_pages(zone, true)`, and `pcp_batch_high_lock` must remain held until `zone_pcp_enable()` restores them. [F27]
- `NR_PAGEBLOCK_BITS` (`roundup_pow_of_two(__NR_PAGEBLOCK_BITS)`) must remain a power-of-two divisor of `BITS_PER_LONG` so a pageblock's bit group never straddles two `unsigned long` words. In `__get_pfnblock_flags_mask()` and `__set_pfnblock_flags_mask()`, multi-bit pageblock flags (`MIGRATETYPE_AND_ISO_MASK`) in `*bitmap_word` must be read with `READ_ONCE(*bitmap_word)` and modified with an atomic `try_cmpxchg(bitmap_word, &word, ...)` loop. [F43, F142]
- `lookup_page_ext()`, `page_ext_lookup()`, `page_ext_iter_begin()`, and `page_ext_iter_next()` must be called within an RCU read-side critical section (`rcu_read_lock_held()`), and callers of `page_ext_get()` must not sleep before `page_ext_put()`. In `offline_page_ext()`, every section in the range must first have `ms->page_ext` marked with `PAGE_EXT_INVALID` via `__invalidate_page_ext()` and wait for `synchronize_rcu()` before `__free_page_ext()` frees the storage. [F158, F159]
- In `mm/page_owner.c`, `init_page_owner()` must initialize and link `dummy_stack`, `failure_stack`, and `stack_list` before `static_branch_enable(&page_owner_inited)`. Internal allocations in `save_stack()` and `add_stack_record_to_list()` must be guarded by `set_current_in_page_owner()` / `unset_current_in_page_owner()` and `gfp_nested_mask()`, and `__reset_page_owner()` must pass `__GFP_NOWARN` (no reclaim flags) to `save_stack()` so `stack_depot_save()` does not spin during page freeing. [F22, F160, F161]
- In `page_reporting_register()`, `prdev->state` and `prdev->work` must be initialized before `rcu_assign_pointer(pr_dev_info, prdev)` publishes `prdev`, and in `page_reporting_unregister()`, `RCU_INIT_POINTER(pr_dev_info, NULL)` and `synchronize_rcu()` must complete before `cancel_delayed_work_sync(&prdev->work)`. [F24]

## Object Lifetimes

- In `___free_pages()`, `PageHead(page)` and `pgalloc_tag_get(page)` must be sampled before `put_page_testzero(page)` because a concurrent `put_page()` can free the page immediately after `put_page_testzero(page)` decrements the refcount. When `put_page_testzero(page)` returns false for a non-compound (`!head`) high-order page, `___free_pages()` must call `pgalloc_tag_sub_pages(tag, (1 << order) - 1)`, `clear_page_tag_ref()`, and `__free_frozen_pages()` on each trailing power-of-two subpage. [F1, F2]
- In `__page_frag_alloc_align()`, when a fragment does not fit in the cached page and `page_ref_sub_and_test(page, nc->pagecnt_bias)` reaches zero, a `pfmemalloc` page (`encoded_page_decode_pfmemalloc(encoded_page)`) must be freed via `free_frozen_pages()` and refilled rather than recycled in-place with `set_page_count()`. Refilling `nc` with a freshly allocated page from `__page_frag_cache_refill()` must add the reference bias via atomic `page_ref_add(page, PAGE_FRAG_CACHE_MAX_SIZE)` rather than `set_page_count()`. [F13, F42]
- When `__folio_copy_owner(newfolio, old)` copies `old_page_owner->handle` to `newfolio`, it must also assign `migrate_handle` (`new_page_owner->handle`) to `old_page_owner->handle` across all `1 << new_page_owner->order` pages of `old` via `__update_page_owner_handle()` so freeing `old` after migration decrements the migration stack rather than the original allocation stack. [F18]

## API Contracts

- `__page_frag_alloc_align()` expects `align_mask` to be a negated power-of-two mask (`-align`, or `~0u` for unaligned) and aligns `nc->offset` using `__ALIGN_KERNEL_MASK(nc->offset, ~align_mask)` before checking `offset + fragsz > size` (whereas `page_frag_alloc_align()` takes a positive power-of-two `align` and negates it). If `offset + fragsz > size` and `fragsz > PAGE_SIZE`, `__page_frag_alloc_align()` must return `NULL` immediately without draining or refilling `nc->encoded_page`. [F65, F102]
- `alloc_pages_exact_noprof()` and `alloc_pages_exact_nid_noprof()` take a byte `size` (not a page order), forbid `__GFP_COMP` and `__GFP_HIGHMEM`, and return individual order-0 refcounted pages that must be freed with `free_pages_exact(virt, size)`. `make_alloc_exact()` must compute the retained page count `nr` with ceiling division `DIV_ROUND_UP(size, PAGE_SIZE)` to match the `PAGE_ALIGN(size)` span freed by `free_pages_exact()`. [F67, F128]
- `get_pfnblock_bit()`, `set_pfnblock_bit()`, and `clear_pfnblock_bit()` only accept standalone bits satisfying `is_standalone_pb_bit(pb_bit)` (`pb_bit >= PB_compact_skip && pb_bit < __NR_PAGEBLOCK_BITS`), whereas migratetype bits (`MIGRATETYPE_AND_ISO_MASK`) must be modified via `__set_pfnblock_flags_mask()` (and isolation via `set_pageblock_isolate()`, never `set_pageblock_migratetype(page, MIGRATE_ISOLATE)`). [F95]
- `__pageblock_pfn_to_page()` and `pageblock_pfn_to_page()` take `end_pfn` as an exclusive one-past-the-end bound `[start_pfn, end_pfn)` and `__pageblock_pfn_to_page()` decrements `end_pfn` before checking `pfn_valid(end_pfn)` and comparing `page_zone_id(start_page)` with `page_zone_id(pfn_to_page(end_pfn))`. [F97]
- Callers of `__update_page_owner_handle()` must pass `(page, handle, order, gfp_mask, last_migrate_reason, ts_nsec, pid, tgid, comm)` with `ts_nsec` before `pid` and `tgid`, whereas `__update_page_owner_free_handle()` takes `(page, handle, order, pid, tgid, free_ts_nsec)` with `pid` and `tgid` before `free_ts_nsec`. [F60]
- Contiguous range isolation and allocation must synchronize with hugetlb pool and deferred freeing: `alloc_contig_range_noprof()` must call `replace_free_hugepage_folios(start, end)` after migration, and `test_pages_isolated()` must call `wait_for_freed_hugetlb_folios()` before checking `PageBuddy(page)`. [F175]
- `alloc_pages_bulk_noprof()` must bypass the PCP batch loop and fall back to `__alloc_pages_noprof()` when `memcg_kmem_online() && (gfp & __GFP_ACCOUNT)` is true or when `static_branch_unlikely(&page_owner_inited)` is enabled. [F180]
- When `cpusets_enabled()` is true, `prepare_alloc_pages()` must only bind `ac->nodemask` to `&cpuset_current_mems_allowed` when `in_task() && !ac->nodemask`, and `gfp_to_alloc_flags()` must clear `ALLOC_CPUSET` for non-blocking `__GFP_HIGH` allocations (`!(gfp_mask & __GFP_DIRECT_RECLAIM)` and `alloc_flags & ALLOC_MIN_RESERVE`). [F182]

## Error Handling

- Because `start_isolate_page_range()` isolates the first (`isolate_start`) and last (`isolate_end - pageblock_nr_pages`) pageblocks before looping over interior pageblocks, a failure at interior `pfn` must call both `undo_isolate_page_range(isolate_start, pfn)` and `unset_migratetype_isolate(pfn_to_page(isolate_end - pageblock_nr_pages))`. [F11]
- In `isolate_freepages_block()`, when `strict` is true and scanning stops before `end_pfn`, the function returns `0` even if it already isolated pages onto `freelist`; callers using `strict` mode such as `isolate_freepages_range()` must call `release_free_list(cc->freepages)` on early loop termination (`pfn < end_pfn`). [F46]
- In `isolate_migratepages_block()`, a negative return from `isolate_or_dissolve_huge_folio()` must be reset to `0` when `ret == -EBUSY` before jumping to `isolate_fail` so `-EBUSY` is not propagated, whereas `ret == -ENOMEM` must break out of the PFN loop immediately and return `-ENOMEM`. In `alloc_contig_range_noprof()`, when `__alloc_contig_migrate_range()` returns `-EBUSY`, `ret` must be overwritten by `test_pages_isolated()` across the fallthrough. [F47, F48]
- `PageHWPoison(page)` pages must not be treated as kernel bugs: `check_new_page_bad()` must return without calling `bad_page()` (clearing `PageBuddy` if set), and `free_pages_prepare()` must intercept order-0 `PageHWPoison(page)` pages before `free_page_is_bad()`, call `clear_page_tag_ref(page)`, and return `false`. [F183]
- Because `prepare_alloc_pages()` resolves `ac.preferred_zoneref` via `first_zones_zonelist()` while concurrent cpuset updates can empty `current->mems_allowed`, `zonelist_zone(ac.preferred_zoneref)` may be `NULL`; callers must check for `NULL` or iterate via `for_next_zone_zonelist_nodemask()` before dereferencing the zone. [F51]

## Known Pitfalls

- In `fast_find_migrateblock()`, calling `move_freelist_tail(freelist, freepage)` during `list_for_each_entry(freepage, freelist, buddy_list)` reorders `freelist` by splicing up to `freepage` to the tail and must only be called immediately before `break`ing out of the loop. In `fast_isolate_freepages()`, if `!page && high_pfn` selects `page = pfn_to_page(high_pfn)` after the reverse loop, `freepage` must be updated to `page` before calling `move_freelist_head(freelist, freepage)` and before `__isolate_free_page(page, order)` unlinks `page`. [F115, F116]
- In `include/linux/page_ext.h`, `page_ext_iter_next()` may only advance `iter->page_ext` by `page_ext_size` (`page_ext_next()`) when `page_ext_iter_next_fast_possible(pfn)` is true (`pfn % PAGES_PER_SECTION != 0` on `CONFIG_SPARSEMEM`), and must call `page_ext_lookup(pfn)` at section boundaries. [F135]
- When iterating over a PFN range `[pfn, end)` in steps of `1 << order` in `split_large_buddy()`, the loop must check `if (pfn == end) break;` before calling `pfn_to_page(pfn)` so that `pfn_to_page()` is never called on the one-past-the-end PFN `end`. [F96]
