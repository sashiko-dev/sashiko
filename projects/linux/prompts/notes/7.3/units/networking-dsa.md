# NETWORKING [DSA]

The Distributed Switch Architecture (DSA) subsystem (`net/dsa`) manages hardware Ethernet switches connected to a host CPU network interface (the conduit) and exposes individual switch ports as Linux user `net_device` instances. It coordinates multi-switch tree topologies, phylink/PHY integration, devlink representations, and hardware offloading of bridging, VLANs, FDB/MDB tables, LAG, HSR, MRP, and TC actions via switchdev notifiers, along with modular frame tagging and untagging drivers to multiplex per-port traffic over the shared conduit.

## Architecture & Data Flow
- In `struct dsa_port`, `dp->conduit` and `dp->user` share a union discriminated by `dp->type`; code on a user or DSA port must obtain the conduit via `dsa_port_to_conduit(dp)` (which checks `dp->cpu_port_in_lag` and `dp->cpu_dp`), never `dp->conduit` or `dp->cpu_dp->conduit` directly. [F47]
- In `struct dsa_db`, the `dp`, `lag`, and `bridge` union is discriminated by `db.type` (`DSA_DB_PORT`, `DSA_DB_LAG`, `DSA_DB_BRIDGE`), so `dsa_db_equal()` and `dsa_db_print()` must switch on `db->type` first. When `!dp->ds->fdb_isolation`, `dsa_port_{fdb,mdb,lag_fdb,bridge_host_fdb,bridge_host_mdb}_{add,del}()` must force `db.bridge.num = 0`. [F49, F77]
- In tree-wide/broadcast notifier handlers in `net/dsa/switch.c` (`dsa_switch_bridge_{join,leave}`, `dsa_switch_lag_{change,join,leave}`), `ds->ops->port_*` must only be called with `info->dp->index` when `info->dp->ds == ds`, while `info->dp->ds != ds` must call `ds->ops->crosschip_*`. Because `dst->ports` lists every port in the tree, per-switch operations must use `dsa_tree_notify()` or guard with `ds->setup`. [F74, F121]
- When `ds->vlan_filtering_is_global` is set, `dsa_port_vlan_filtering()` must update `ds->vlan_filtering` and call `dsa_user_manage_vlan_filtering()` on every registered user port of `ds`, and `dsa_port_reset_vlan_filtering()` must not disable VLAN filtering if any port on `ds` remains enslaved to any VLAN-aware bridge (`br && br_vlan_enabled(br)`). [F65, F66]
- `struct dsa_lag::id` and `dsa_lag_by_id(dst, id)` use 1-based IDs (`1 .. dst->lags_len`, `0` unmapped) while `dst->lags` is indexed at `id - 1` (0-based hardware trunk IDs in `dsa_rcv_ll()` must pass `trunk_id + 1`). `dsa_bridge_num_get()` also returns 1-based numbers (`0` when `!max` or exhausted), so `dsa_tag_8021q_bridge_vid()` passes `bridge_num` directly and `dsa_xmit_ll()` uses `dst->last_switch + bridge_num`. [F94, F95]
- In `dsa_switch_setup()`, `ds->phys_mii_mask` and `dsa_switch_devlink_alloc(ds)` must precede `ds->ops->setup(ds)`, whereas `dsa_switch_devlink_register(ds)` runs after `ds->ops->setup(ds)`, tag protocol setup, and `mdiobus_register()` succeed. `dsa_user_ports()` and `dsa_cpu_ports()` build `u32` masks with `BIT(dp->index)`, requiring port indices `< 32`. [F19, F133]
- `dsa_switch_change_tag_proto()` must update `cpu_dp->rcv` and `cpu_dp->tag_ops` via `dsa_port_set_tag_protocol()` on every CPU port of `ds`, and refresh `p->xmit`, headroom/tailroom, features, and conduit MTU via `dsa_user_setup_tagger()` and `dsa_user_change_mtu()` on every user port. When `user->needed_tailroom > 0`, `dsa_user_setup_tagger()` must clear `NETIF_F_SG | NETIF_F_FRAGLIST` and `dsa_user_xmit()` must pad via `eth_skb_pad()`. [F61, F179]
- In `dsa_conduit_lag_leave()`, when a physical DSA conduit leaves a `lag_dev` that still has another lower DSA conduit (`new_cpu_dp`), both `dp->cpu_dp` on all user ports using `lag_dev` and `lag_dev->dsa_ptr` must be updated to `new_cpu_dp` before `dsa_conduit_lag_teardown()` clears `conduit->dsa_ptr->lag`. [F63]
- In `dsa_8021q_rcv()`, non-`vid_is_dsa_8021q(tmp_vid)` tags must be restored via `__vlan_hwaccel_put_tag()`, and matching tags must only update `*source_port` and `*switch_id` when `tmp_vbid == 0` and their value is `-1`. In `dsa_tag_8021q_find_user()`, checking `(source_port != -1 && switch_id != -1)` must precede `vbid >= 1` and `vid` lookups. [F81, F109]
- Every `DSA_TAG_PROTO_*` enumerator in `enum dsa_tag_protocol` must have a matching `#define DSA_TAG_PROTO_*_VALUE` macro so `MODULE_ALIAS_DSA_TAG_DRIVER()` expands to the numeric ID expected by `dsa_tag_driver_get_by_id()`. [F85]

## Synchronization
- Work items on `dsa_owq` (`dsa_user_switchdev_event_work()`, `dsa_user_standalone_event_work()`) and their callees (`dsa_port_bridge_host_fdb_{add,del}()`) must never acquire `rtnl_lock()` or call helpers requiring `RTNL` (such as `dev_uc_add(conduit, addr)` when `!(conduit->priv_flags & IFF_UNICAST_FLT)`, which falls back to `__dev_set_promiscuity()`). [F27]
- `dsa2_mutex` nests outside `rtnl_lock()`. In sysfs `tagging_store()` -> `dsa_tree_change_tag_proto()`, `rtnl_trylock()` (returning `restart_syscall()` on failure) must be used instead of `rtnl_lock()` because `dsa_conduit_teardown()` removes the sysfs group under `rtnl_lock()`, and all tree user and conduit netdevices must be verified down (`!(flags & IFF_UP)`) under `rtnl_lock` before changing `tag_ops`. [F29, F166]
- In `struct dsa_port`, `dp->vlans` (on CPU/DSA ports) is serialized by mutex `dp->vlans_lock`, while `dp->user_vlans` (on user ports) is serialized by `netif_addr_lock_bh(dev)`. In `dsa_user_{sync,unsync}_ha()` and `dsa_user_vlan_rx_{add,kill}_vid()`, work queued under `netif_addr_lock_bh(dev)` in `dsa_user_schedule_standalone_work()` must use `GFP_ATOMIC`, and `dsa_flush_workqueue()` must only be called after `netif_addr_unlock_bh(dev)`. [F162, F163]
- On CPU and DSA ports, `dp->addr_lists_lock` protects `dp->fdbs` and `dp->mdbs` across lookup, `ds->ops->port_{fdb,mdb}_{add,del}`, and list updates, and must be held when calling `dsa_{fdb,mdb}_present_in_other_db()`. [F24]
- `dsa_user_switchdev_event()` runs under `rcu_read_lock()` (requiring `GFP_ATOMIC` in `dsa_user_fdb_event()`), whereas `dsa_user_switchdev_blocking_event()` does not, so `dsa_port_vlan_filtering()` and `dsa_user_vlan_add()` must acquire `rcu_read_lock()` around RCU upper-device walks. [F165]
- In `dsa_conduit_setup()`, `cpu_dp->rcv`, `cpu_dp->tag_ops`, and `cpu_dp->dst` must be initialized and ordered by `wmb()` before `dev->dsa_ptr = cpu_dp`, and `dsa_conduit_teardown()` must clear `dev->dsa_ptr = NULL` before `wmb()`. Non-atomic bitfields in `struct dsa_port` and `struct dsa_switch` must only be modified at probe time or under `rtnl_lock()`. [F17, F171]
- In `dsa_tag_driver_get_by_{name,id}()`, `request_module()` must precede `dsa_tag_drivers_lock`, which must be held across list traversal and `try_module_get()`. In `dsa_devlink_resource_*()`, `devl_lock(ds->devlink)` must be held around `devl_resource_*()` calls. [F31, F33]

## Object Lifetimes
- `dsa_tree_setup()` and `dsa_tree_teardown()` must maintain strict LIFO ordering across `routing_table`, `cpu_ports`, `switches`, `ports`, `conduit`, and `lags`; any failure after `dsa_tree_setup_routing_table()` must call `dsa_tree_teardown_routing_table(dst)` so `dst->rtable` retains no dangling `dsa_link` pointers. `dsa_tree_setup_ports()` sets up shared (`DSA`, `CPU`) before non-shared (`USER`, `UNUSED`) ports, and `dsa_tree_teardown_ports()` must tear down non-shared ports and call `dsa_flush_workqueue()` before tearing down shared ports. [F7, F149]
- When unoffloading a bridge port in `dsa_port_pre_bridge_leave()` or on `dsa_port_bridge_join()` rollback, `switchdev_bridge_port_unoffload()` must be followed by `dsa_flush_workqueue()` before `dsa_port_bridge_{leave,destroy}()` clears `dp->bridge` and frees `struct dsa_bridge`. In `dsa_port_{bridge,lag}_leave()`, the `dsa_bridge`/`dsa_lag` must be copied by value into the notifier info struct and destroyed (`dp->bridge = NULL` / `dp->lag = NULL`) before emitting `DSA_NOTIFIER_{BRIDGE,LAG}_LEAVE`. [F13, F14]
- Because `dsa_register_switch()` drops the initial `dsa_tree_touch()` reference via `dsa_tree_put(ds->dst)`, `dsa_switch_probe()` must take a second reference with `dsa_tree_get(dst)` before `dsa_tree_setup(dst)` and call `dsa_switch_release_ports(ds)` on any probe failure after `dsa_switch_touch_ports()`. [F6]
- A `dsa_switch_tree` holds at most one module reference on `dst->tag_ops` (released in `dsa_tree_free()`): `dsa_port_parse_cpu()` must call `dsa_tag_driver_put(tag_ops)` when `dst->tag_ops` is already set, and `tagging_store()` must drop `new_tag_ops` on failure or `old_tag_ops` on success/no-op. [F4]
- Tagger `.disconnect` callbacks (`sja1105_disconnect()`, `qca_tag_disconnect()`) freeing `ds->tagger_data` must clear `ds->tagger_data = NULL` (never `ds->priv`), and `dsa_switch_connect_tag_proto()` must call `tag_ops->disconnect(ds)` if `ds->ops->connect_tag_protocol()` fails. [F5]
- When a pointer on `struct dsa_port` is set before a fallible call or torn down—`port->user` in `dsa_user_create()` / `dsa_port_teardown()`, or `dp->hsr_dev` in `dsa_port_hsr_join()`—it must be reset to `NULL` on failure or teardown because callers test `dp->user` for `NULL`. [F12, F52]
- In `dsa_port_change_conduit()`, all host objects on the old CPU port (bridge, VLAN filtering, addresses) must be torn down before `dsa_port_assign_conduit()` updates `dp->cpu_dp`, and restored in reverse order if new conduit bringup fails. [F15]
- Every `struct device_node *` acquired via OF phandle or child-node iterators in `dsa_shared_port_validate_of()`, `dsa_port_setup_routing_table()`, and `dsa_switch_parse_ports_of()` must be released with `of_node_put()` on all return paths. [F157]

## API Contracts
- `dsa_port_from_netdev()` returns `ERR_PTR(-ENODEV)` (not `NULL`) on failure, so callers must check `IS_ERR(dp)`. Outside `dsa_user_netdev_ops`/`dsa_user_ethtool_ops`, callers must verify `dsa_user_dev_check(dev)` before calling `dsa_user_to_port(dev)` or `netdev_priv(dev)`. [F39, F134]
- When `dsa_switch_rcv()` calls `cpu_dp->rcv(skb, dev)`, `skb->data` is `skb_mac_header(skb) + ETH_HLEN` (`dsa_etype_header_pos_rx(skb)` is `skb->data - 2`), and `cpu_dp->rcv()` must return with `skb->data` right after the inner Ethernet header. In `.rcv` callbacks, `pskb_may_pull(skb, len)` must cover the full header length beyond `ETH_HLEN`, trailer taggers must call `skb_linearize(skb)` before reading `skb_tail_pointer(skb)`, `dsa_alloc_etype_header()` must follow `skb_push()`, and `dsa_strip_etype_header()` must follow `skb_pull_rcsum()`. [F86, F87, F180]
- `dsa_routing_port(ds, device)` and `dsa_switch_upstream_port(ds)` return `ds->num_ports` when no route or port exists, whereas `dsa_to_port(ds, p)` returns `NULL` for `p >= ds->num_ports`; callers must check `port == ds->num_ports` before passing it to `dsa_to_port()` or `BIT(port)`. [F97]
- `dsa_bridge_num_get()` returns `0` both when `!ds->max_num_bridges` and when IDs are exhausted, so `dsa_port_bridge_create()` must fail on `!bridge->num` only when `ds->max_num_bridges` is non-zero, and `dsa_port_bridge_destroy()` must call `dsa_bridge_num_put()` only when `bridge->num` is non-zero. [F42]
- `dsa_user_change_mtu()` adds `dsa_tag_protocol_overhead(cpu_dp->tag_ops)` when setting the conduit `net_device` MTU, but passes the unadjusted L2 MTU (`largest_mtu`, or `old_conduit_mtu - overhead` on rollback) to `dsa_port_mtu_change(cpu_dp, ...)` and `ds->ops->port_change_mtu()`. [F132]

## Error Handling
- `dsa_tree_notify()` decodes handler returns via `notifier_to_errno(err)`, so callers of `dsa_port_*`, `dsa_tree_notify()`, and `dsa_broadcast()` must check for `-EOPNOTSUPP` (not `EOPNOTSUPP` or `NOTIFY_BAD`). Optional `dsa_switch_ops` callers (`dsa_port_set_state_now()`, `dsa_user_changeupper()`) must treat `-EOPNOTSUPP` as non-fatal, and broadcast notifier handlers (`dsa_switch_tag_8021q_vlan_{add,del}()`, cross-chip `dsa_switch_bridge_join()`) must return `0` when a switch lacks the callback or context. [F40, F112, F187]
- In `dsa_port_do_{fdb,mdb,vlan,tag_8021q_vlan}_del()` and `dsa_switch_do_lag_fdb_del()`, if `refcount_dec_and_test()` reaches zero and the driver callback fails, `refcount_set(&entry->refcount, 1)` must restore the refcount without freeing the entry. In `dsa_port_do_{mdb,fdb}_add()` and `dsa_switch_do_lag_fdb_add()`, `a->db = db` must be initialized for `dsa_mac_addr_find()`. [F54, F68]
- `dsa_port_to_bridge_port(dp)` returns `NULL` when `!dp->bridge`, so callers (`dsa_port_pre_bridge_leave()`, `dsa_port_notify_bridge_fdb_flush()`) must NULL-check `brport_dev`. When a user port joins a software LAG, `dp->lag` stays `NULL`, so `dsa_port_lag_{change,leave}()` and `dsa_user_lag_{pre,}changeupper()` must check `if (!dp->lag)` first. [F45, F46]
- `dsa_tag_driver_get_by_{name,id}()` return `ERR_PTR(-ENOPROTOOPT)` (not `NULL`) on failure, so callers like `dsa_port_parse_cpu()` must check `IS_ERR(tag_ops)` and reset `tag_ops = NULL` before fallback. In `dsa_port_can_apply_vlan_filtering()` and `dsa_user_check_8021q_upper()`, `br_vlan_get_info()` returning `0` means a conflicting VID exists on the bridge (`-EBUSY`). [F38, F41]
- When a per-port loop in `dsa_hw_port_list_set_mtu()`, `dsa_user_dcbnl_ieee_global_dscp_setdel()`, or `dsa_conduit_lag_join()` fails mid-iteration, rollback must use `*_continue_reverse` from the failed cursor, and rollback calls must not overwrite `err`. In `dsa_user_xmit()`, `memset(skb->cb, 0, sizeof(skb->cb))` must precede `dsa_skb_tx_timestamp()` and `p->xmit()`. [F50, F56, F114]

## External Contracts
- For `ETH_SS_STATS` on user ports, `dsa_user_get_sset_count()`, `dsa_user_get_strings()`, and `dsa_user_get_ethtool_stats()` must all keep the `+ 4` software-stat offset synchronized. In `dsa_user_port_fdb_do_dump()`, `ndm->ndm_pad1`, `ndm_pad2`, and `ndm_type` must be zeroed, `nlmsg_cancel()` must be called if `nla_put*()` fails, and `dump->idx` must be incremented for every visited entry except on `-EMSGSIZE`. [F104, F120, F185]

## Known Pitfalls
- In `sja1110_rcv_inband_control_extension()`, `pskb_trim_rcsum(skb, start_of_padding - ETH_HLEN)` must precede `skb_pull_rcsum()`, and `skb_set_mac_header(skb, -ETH_HLEN)` must follow `dsa_strip_etype_header()`. In `sja1105_pvid_tag_control_pkt()`, `skb_vlan_eth_hdr(skb)` must be fetched after `__vlan_hwaccel_push_inside(skb)`. `dsa_8021q_xmit()` takes host-order `u16 tpid`, whereas `dsa_tag_8021q_register()` takes `__be16 proto`. [F71, F72, F89, F107]
- In `dsa_rcv_ll()`, tagged header conversion (`dsa_header[0] & 0x20`) must build `new_header[4]` to update `skb->csum` before `memcpy(dsa_header, new_header, DSA_HLEN)`, and the `DSA_CMD_FORWARD` trunk check must mask `dsa_header[1]` with `4` (bit 2). [F83, F111]
- Functions with a target `dp` that also iterate over ports (`dsa_port_{reset_,}vlan_filtering()`, `dsa_user_change_mtu()`) must use a distinct loop cursor (`other_dp`). In `dsa_switch_host_fdb_{add,del}()`, test `dsa_port_is_cpu(dp)` on local `dp`, test `info->dp->cpu_port_in_lag` on target `info->dp`, and pass `dp->lag` to `dsa_switch_do_lag_fdb_{add,del}()`. [F122, F123]
- Safe iteration and bounds: `dsa_switch_release_ports()` must use `*_safe` list iterators; `dsa_tag_driver_get_by_id()` must check `found` before dereferencing the cursor; `dsa_skb_defer_rx_timestamp()` must check `skb_headroom(skb) >= ETH_HLEN`; `dsa_switch_parse_ports_of()` must check `reg < ds->num_ports`; and `dsa_user_dcbnl_add_dscp_prio()` must reject `dscp >= 64`. [F99, F100, F101, F115, F116]
