# FUNCTION HOOKS (FTRACE)

Provides the core function tracer (`kernel/trace/ftrace.c`), function graph tracer (`kernel/trace/fgraph.c`), public interface (`include/linux/ftrace.h`), and per-architecture backends (`arch/*/kernel/ftrace.c`, `arch/*/include/asm/ftrace.h`) for dynamic callsite patching, trampolines, per-ops filter/notrace hashes, direct calls, kprobes-on-ftrace, and per-task shadow return stacks (`ret_stack`).

## Architecture & Data Flow

- In `ftrace_get_addr_new()` and `ftrace_get_addr_curr()`, `rec->flags` checks must order direct calls (`FTRACE_FL_DIRECT` with `ftrace_rec_count(rec) == 1`, or `FTRACE_FL_DIRECT_EN`) before custom trampolines (`FTRACE_FL_TRAMP`/`_EN`), and trampolines before `FTRACE_FL_REGS`/`_EN`. Around `ftrace_run_update_code()`, `ops->old_hash` must hold pre-change hashes with `FTRACE_OPS_FL_MODIFYING` or `FTRACE_OPS_FL_REMOVING` (`removed_ops = ops`) set; `ftrace_find_tramp_ops_curr()` must check `removed_ops->old_hash` first, skip `FTRACE_OPS_FL_ADDING`, and use `&op->old_hash` when `FTRACE_OPS_FL_MODIFYING` is set. [F221, F240, F247]
- `struct dyn_ftrace.flags` packs the refcount in bits `0..18` (`FTRACE_REF_MAX`) and `FTRACE_FL_*` flags as `1UL` shifts at or above `FTRACE_REF_MAX_SHIFT` (bit 19). `__ftrace_hash_rec_update()` must bound `ftrace_rec_count(rec)` against `FTRACE_REF_MAX` and `0`, and `ftrace_check_record()` disabling a record (`!flag` with `update` true) must preserve `FTRACE_NOCLEAR_FLAGS` (`FTRACE_FL_DISABLED | FTRACE_FL_TOUCHED | FTRACE_FL_MODIFIED`) when `ftrace_rec_count(rec) == 0` or clear only `*_EN` flags when `> 0`. [F89, F216, F255]
- With `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, every path in `ftrace_init_nop()`, `ftrace_make_nop()`, and `ftrace_replace_code()` that initializes or converts a callsite to a NOP must call `ftrace_rec_set_nop_ops(rec)`. On arm64 and riscv, `ftrace_rec_set_ops()` must compute the pre-function `ftrace_ops` slot as `ALIGN_DOWN(rec->ip - 12, 8)` (handling 4-byte `BTI` shifts), and on riscv `patch_text_nosync()` must take `&ops` and `sizeof(ops)`, not `ops` or `sizeof(*ops)`. [F43, F65, F98]
- In `add_first_hash()` and `add_next_hash()`, a manager `ftrace_ops` must keep `notrace_hash` set to `EMPTY_HASH` whenever its aggregated `filter_hash` is non-empty (subtracting each subop's `notrace_hash` via `remove_hash()`), and only populate `notrace_hash` via `intersect_hash()` when `filter_hash` is `EMPTY_HASH`. `ftrace_startup_subops()` must canonicalize any `NULL` `filter_hash` or `notrace_hash` to `EMPTY_HASH` before calling `add_next_hash()`. [F190, F214]
- Updating a hash in `ftrace_hash_move_and_update_ops()` on an `ftrace_ops` with `FTRACE_OPS_FL_SUBOP` or sharing `func_hash` with an enabled subop on `op->subop_list` must route through `ftrace_hash_move_and_update_subops()`. Modifying an `ops` with `ops->func_hash == &global_ops.local_hash` in `ftrace_hash_rec_update_modify()` or `ftrace_ops_update_code()` must walk `ftrace_ops_list` to update all enabled `ftrace_ops` sharing `&global_ops.local_hash`. [F206, F208]
- `__register_ftrace_function()` and `register_ftrace_graph()` must save the callback in `saved_func` before PID wrapping (restoring `ops->func` on unregister). Toggling `op->func` for `FTRACE_OPS_FL_PID` requires `ftrace_update_trampoline()` and `update_ftrace_function()`; toggling `gops->entryfunc` in `fgraph_update_pid_func()` requires `static_call_update(fgraph_func, gops->entryfunc)` when `ftrace_graph_active == 1`. `register_ftrace_graph()` / `unregister_ftrace_graph()` must call `ftrace_graph_enable_direct()` / `ftrace_graph_disable_direct()` as `ftrace_graph_active` crosses 1. [F203, F204, F205, F300]
- In `ftrace_partial_regs()` and `arch_ftrace_fill_perf_regs()`, backends must set the kernel mode field in `struct pt_regs` (`pstate = PSR_MODE_EL1h` on arm64, `cs = __KERNEL_CS` on x86, `psw.mask = 0` on s390, `msr` on powerpc) so `user_mode(regs)` is false, and bound `memcpy()` by the source array size (`sizeof(afregs->regs)` on arm64, `sizeof(afregs->args)` on riscv). On arm64, `sizeof(struct __arch_ftrace_regs)` must be a 16-byte multiple; on riscv (`CONFIG_DYNAMIC_FTRACE_WITH_ARGS`), it must include `t2`–`t6` under `CONFIG_CC_IS_CLANG`. [F33, F96, F99, F127]

## Synchronization

- Lock ordering is `trace_types_lock` -> `ops->func_hash->regex_lock` -> `ftrace_lock`, and `direct_mutex` -> `ftrace_lock`. Drop `ftrace_lock` before `cleanup_direct_functions_after_ipmodify()`, `clear_mod_from_hashes()`, `clear_func_from_hashes()`, or `match_records()`. In `ops_func`, `FTRACE_OPS_CMD_ENABLE_SHARE_IPMODIFY_SELF` holds `direct_mutex` and `ftrace_lock`, while `*_PEER` holds only `direct_mutex`. `ftrace_rec_iter_start()` / `ftrace_rec_iter_next()` share a static `ftrace_rec_iter` and require `ftrace_lock`. [F17, F171, F173, F183]
- A static `struct ftrace_ops` registered on `ftrace_ops_list` must never be freed or have `ops->next` modified even after `unregister_ftrace_function()`, because lockless readers traverse `ftrace_ops_list` without a grace period (stopping at `&ftrace_list_end`). In `ftrace_modify_all_code()`, when `FTRACE_UPDATE_TRACE_FUNC` is set, `update_ftrace_func(ftrace_ops_list_func)` must run before `ftrace_replace_code()`, and `function_trace_op` must be published with `smp_wmb()` (and `ftrace_sync_ipi` if IRQs are enabled) before `update_ftrace_func(ftrace_trace_function)`. [F16, F59, F182]
- Callers of `function_graph_enter_regs()` and `function_graph_enter()` (`ftrace_graph_func()`, `prepare_ftrace_return()`) must NOT acquire `ftrace_test_recursion_trylock()`, because `function_graph_enter_regs()` and `__ftrace_return_to_handler()` acquire and release it internally around `entryfunc` and `retfunc`. Conversely, every `kprobe_ftrace_handler()` must acquire `ftrace_test_recursion_trylock(ip, parent_ip)` before calling `get_kprobe()` or touching `current_kprobe`, reset `current_kprobe = NULL`, and call `ftrace_test_recursion_unlock(bit)` on all exit paths. [F5, F29, F279]
- `register_ftrace_graph()` must not assign `fgraph_array[i] = gops` until `ftrace_startup_subops(&graph_ops, &gops->ops, command)` succeeds, because `fgraph_lru_alloc_index()` already set bit `i` in `fgraph_array_bitmask`. Lockless readers in `function_graph_enter_regs()` and `__ftrace_return_to_handler()` must use `READ_ONCE(fgraph_array[i])` and check against `&fgraph_stub` before dereferencing `gops`. [F164, F165]
- In `ftrace_push_return_trace()` and `fgraph_reserve_data()`, descriptor `val` must be written at the new top of `current->ret_stack`, ordered by `barrier()`, before advancing `current->curr_ret_stack`, and written a second time after `barrier()` to recover if an interrupt clobbered the first write. In `__ftrace_return_to_handler()`, `current->curr_ret_stack` must not be decremented until after all `retfunc` callbacks finish, separated by `barrier()`. [F167, F168]
- Because ftrace hooks can run where RCU is not watching, hot-path hash lookups (`ftrace_find_profiled_func()`, `__ftrace_lookup_ip()`) must use `hlist_for_each_entry_rcu_notrace()` under `preempt_disable_notrace()`. `function_profile_call()` and `profile_graph_return()` must use `guard(preempt_notrace)()` before accessing `ftrace_profile_stats`, and `ftrace_profile_alloc()` must serialize against NMI recursion via `atomic_inc_return(&stat->disabled) != 1` and re-check `ftrace_find_profiled_func()`. [F277, F280]
- On x86, `ftrace_arch_code_modify_prepare()` locks `text_mutex` and sets `ftrace_poke_late = 1`, and `ftrace_arch_code_modify_post_process()` must call `smp_text_poke_batch_finish()` and reset `ftrace_poke_late = 0` before unlocking `text_mutex`. `create_trampoline()` and `arch_ftrace_update_trampoline()` must hold `text_mutex` while writing the `CALL` instruction, and `create_trampoline()` must call `set_memory_rox()` only after all writes complete. [F3, F21, F119]
- When `mod` is `NULL`, `ftrace_find_callable_addr()` (arm64, LoongArch), `ftrace_lookup_module_stub()` (powerpc), and `ftrace_lookup_module()` (ppc64) must call `__module_text_address()` inside an RCU read-side critical section while holding `ftrace_lock`. In `ftrace_replace_code()`, `cond_resched()` is only allowed when `mod_flags & FTRACE_MODIFY_MAY_SLEEP_FL` (never inside `stop_machine()`), whereas process-context `do_for_each_ftrace_rec()` loops doing kallsyms lookups or schedulable patching must call `cond_resched()`. [F11, F38, F239, F294]

## Object Lifetimes

- If `ftrace_hash_ipmodify_enable()` fails in `ftrace_startup()`, roll back `__unregister_ftrace_function()`, `ftrace_start_up--`, `FTRACE_OPS_FL_ENABLED`, and `ftrace_trampoline_free()`. On `ftrace_shutdown()`, `FTRACE_OPS_FL_DYNAMIC` ops must run both `synchronize_rcu_tasks_rude()` and `synchronize_rcu_tasks()` before `ftrace_trampoline_free()`; non-dynamic ops with `ops->private` must run `schedule_on_each_cpu()` after unregistering before freeing `ops->private`. `ftrace_trampoline_free()` must emit unregister perf events and call `ftrace_remove_trampoline_from_kallsyms()` before `arch_ftrace_trampoline_free()` (which on x86 must check `FTRACE_OPS_FL_ALLOC_TRAMP` and zero `ops->trampoline = 0`). [F2, F15, F47, F153, F154]
- Because `EMPTY_HASH` points to the static `empty_hash` sentinel, `ftrace_hash` objects must only be freed via `free_ftrace_hash()` or `free_ftrace_hash_rcu()`, and `ftrace_free_filter()` must reset freed pointers to `EMPTY_HASH`. Rebuilding manager hashes (`ftrace_startup_subops()`, `rebuild_hashes()`, `ftrace_shutdown_subops()`, `ftrace_hash_move_and_update_subops()`) must free intermediate/replaced hashes and roll back `subops->list` on error. [F150, F152]
- `register_ftrace_graph()` must create `fgraph_stack_cachep` before registering `fgraph_cpu_init` or calling `start_graph_tracing()`, release `fgraph_lru_alloc_index()` via `fgraph_lru_release_index()` and clear `gops->saved_func = NULL` on error, and `unregister_ftrace_graph()` must set `fgraph_array[gops->idx] = &fgraph_stub` (never `NULL`). `ftrace_graph_init_task()` must set `t->ret_stack = NULL` before allocation; before assigning `t->ret_stack`, `ret_stack_init_task_vars()` must zero `SHADOW_STACK_TASK_VARS` and set `t->curr_ret_stack = 0` and `t->curr_ret_depth = -1` prior to `smp_wmb()`; `ftrace_graph_exit_task()` must set `t->ret_stack = NULL` and `barrier()` before `kmem_cache_free()`. [F146, F148, F199, F276]
- In `ftrace_process_locs()`, `ftrace_release_mod()`, and `ftrace_free_mem()`, removed `ftrace_page` structures must be unlinked from `ftrace_pages_start` under `ftrace_lock`, updating `ftrace_number_of_pages` (by `1 << pg->order`), `ftrace_number_of_groups`, and `ftrace_update_tot_cnt`, and freed only after unlocking `ftrace_lock` and calling `synchronize_rcu()`. `ftrace_release_mod()` must unlink `mod_map` from `ftrace_mod_maps` and schedule `call_rcu(&mod_map->rcu, ftrace_free_mod_map)` before checking `ftrace_disabled`. [F162, F163, F209, F265]

## API Contracts

- Attribute flags in `ops->flags` (`FTRACE_OPS_FL_SAVE_REGS*`, `RECURSION`, `STUB`, `IPMODIFY`) must not change while `ops` is registered. `ftrace_ops_get_func()` must route `FTRACE_OPS_FL_RCU` or `FTRACE_OPS_FL_RECURSION` ops through `ftrace_ops_assist_func()`, and dispatchers must check `!(op->flags & FTRACE_OPS_FL_RCU) || rcu_is_watching()`. Under `CONFIG_DYNAMIC_FTRACE_WITH_REGS`, `ftrace_ops_test()` must return `0` when `regs == NULL && (ops->flags & FTRACE_OPS_FL_SAVE_REGS)`. Direct-call `MULTI_FLAGS` must use `#ifdef CONFIG_HAVE_DYNAMIC_FTRACE_WITH_REGS` (with `CONFIG_`). [F14, F278, F297, F298]
- Under `CONFIG_HAVE_DYNAMIC_FTRACE_WITH_ARGS`, `arch_ftrace_get_regs()` / `ftrace_get_regs()` must return `NULL` unless full `pt_regs` were saved. `ftrace_regs_get_argument()` on arm64/riscv must return `0` for `n >= 8`; `ftrace_regs_get_kernel_stack_nth()` must verify `stackp + nth` has the same `~(THREAD_SIZE - 1)` base as `stackp`; `ftrace_regs_set_instruction_pointer()` must write the saved PC (not the return-value register); and `arch_ftrace_set_direct_caller()` must write `addr` to the arch exit-path slot (`direct_tramp`, `t1`, `regs[13]`, `orig_ax`, `orig_gpr2`, `orig_gpr3`). [F32, F34, F57, F62, F130]
- In `ftrace_graph_func()` and `prepare_ftrace_return()`, `retp` passed to `function_graph_enter_regs()` / `function_graph_enter()` must match the stack/frame pointer passed by the unwinder to `ftrace_graph_ret_addr()`. `ftrace_graph_ret_addr()` must pass its `task` parameter (never `current`) to `get_ret_stack()`, start scanning at `i = *idx ? : task->curr_ret_stack` after checking `idx != NULL`, and update `*idx = i` on match. [F35, F243]
- In `append_hash()`, `*hash == NULL` means unallocated (triggering `alloc_ftrace_hash()`), whereas non-NULL `ftrace_hash_empty(*hash)` (`EMPTY_HASH`) means trace-all and returns `0` immediately. `alloc_ftrace_hash(size_bits)` takes a shift exponent (`1 << size_bits`), so callers computing from an entry count must call `fls()` before clamping to `FTRACE_HASH_MAX_BITS`. Callers of `add_hash_entry()` must check `ftrace_lookup_ip()` / `__ftrace_lookup_ip()` first to avoid duplicate IPs. [F184, F191, F213]

## Error Handling

- `function_graph_enter()` and `function_graph_enter_regs()` return `0` on success and `-EBUSY` when rejected; callers must only redirect the return address to `return_to_handler` on `0`, and architectures overwriting `*parent` before `function_graph_enter()` (ARM, MIPS, SuperH, MicroBlaze) must restore `*parent = old` on non-zero return. Inside `function_graph_enter_regs()`, `current->curr_ret_stack` must be saved before each `entryfunc` and restored if it returns `0`, and if `bitmap == 0` after all callbacks, both the pushed frame (`FGRAPH_FRAME_OFFSET + 1`) and `current->curr_ret_depth` must be rolled back. Shadow stack exhaustion in `ftrace_push_return_trace()` must only increment `current->trace_overrun` and return `-EBUSY` (never `ftrace_graph_stop()` or `WARN`). [F9, F36, F147, F310]

## Known Pitfalls

- Despite the inverted kernel-doc comment in `include/linux/ftrace.h`, `ftrace_need_init_nop()` must return nonzero (`true`) when `ftrace_init_nop()` needs to be called and `0` (`false`) otherwise. In `ftrace_replace_code()`, `ftrace_get_addr_curr(rec)` must be called before `ftrace_update_record(rec, enable)` because `ftrace_update_record()` mutates the `FTRACE_FL_*_EN` flags read by `ftrace_get_addr_curr()`. On x86, all records in `ftrace_replace_code()` must pass `ftrace_verify_code()` before any record is queued or updated, and `ftrace_expected` must be reset to `NULL` after `ftrace_bug()`. [F31, F45, F46, F103]
- `do_for_each_ftrace_rec(pg, rec)` expands to a nested `for` loop over pages and records, so `break` only exits the inner page loop; use `goto` or `return` to terminate the full scan. In `ftrace_free_mem()`, removing a record from a non-empty page must `memmove()` trailing records and `goto again` to re-run `bsearch()` on the same page, while emptying `pg->index` must unlink `pg` and rewind `pg = container_of(last_pg, struct ftrace_page, next)` before `continue`. When unlinking the tail page in `ftrace_release_mod()`, updating `ftrace_pages = next_to_ftrace_page(last_pg)` requires `pg != ftrace_pages_start`. [F238, F246, F267]
- `ftrace_ops_set_global_filter(ops)` is a no-op if `FTRACE_OPS_FL_INITIALIZED` is set, so it must be called before `ftrace_ops_init(ops)` or registration. `ftrace_hash_key()` must check `hash->size_bits > 0` and return `0` when `size_bits == 0` before calling `hash_long(ip, hash->size_bits)`. [F193, F253]
