# READ-COPY UPDATE (RCU)

This unit implements the Linux kernel's Read-Copy Update (RCU) synchronization subsystem, including hierarchical Tree RCU, Tiny RCU, Tasks/Rude/Trace RCU, no-CBs (NOCB) callback offloading and lazy batching, segmented callback lists, priority boosting of preempted readers, CPU/task stall detection, and public C and Rust RCU APIs.

## Architecture & Data Flow

- NOCB GP state (`nocb_gp_lock`, `nocb_defer_wakeup`, `nocb_timer`, `nocb_gp_sleep`, `nocb_gp_wq`, `nocb_head_rdp`, `nocb_toggling_rdp`) must only be manipulated on the leader `rdp->nocb_gp_rdp`, never on a non-leader `rdp`. Whenever `timer_delete(&rdp_gp->nocb_timer)` runs in `__wake_nocb_gp()` or `nocb_gp_wait()`, `rdp_gp->nocb_defer_wakeup` must be reset to `RCU_NOCB_WAKE_NOT` under `rdp_gp->nocb_gp_lock`. [F54, F55]
- In `wake_nocb_gp_defer()`, `RCU_NOCB_WAKE_LAZY` only arms `rdp_gp->nocb_timer` when `nocb_defer_wakeup == RCU_NOCB_WAKE_NOT`, whereas `RCU_NOCB_WAKE_BYPASS` unconditionally overrides any deferral and higher wake types upgrade when `< waketype`. In `nocb_gp_wait()`, `RCU_NOCB_WAKE_LAZY` may be scheduled only when `lazy && !bypass`; if `bypass` is true on any child `rdp`, `RCU_NOCB_WAKE_BYPASS` must be scheduled. [F81, F82]
- `rdp->cblist.len` counts both `rdp->cblist` and `rdp->nocb_bypass` (call `rcu_segcblist_inc_len()` on new enqueue, never re-add on bypass flush). `rdp->lazy_len` counts only lazy callbacks in `nocb_bypass`, so `rcu_nocb_do_flush_bypass()` must enqueue a new lazy `rhp` onto `nocb_bypass` and set `rhp = NULL` before calling `rcu_cblist_flush_enqueue()` (which replaces `srclp` in place without `rcu_cblist_init()` when `rhp` is non-NULL) and zeroing `lazy_len`. [F56, F57, F210]
- In `struct rcu_segcblist`, `RCU_DONE_TAIL` is bounded by `[head, *tails[0])` and `seg > 0` by `[*tails[seg - 1], *tails[seg])`; `rcu_segcblist_segempty()` compares `tails` pointers while `rcu_segcblist_restempty()` dereferences `*tails[seg]`. `RCU_WAIT_TAIL` must never be left empty while `RCU_NEXT_READY_TAIL` is non-empty when `rcu_segcblist_advance()` shifts segments, and `rcu_segcblist_extract_done_cbs()` must iterate backwards from `RCU_CBLIST_NSEGS - 1` to `RCU_DONE_TAIL` when resetting `tails[i]`. [F208, F232, F248, F276]
- `get_state_synchronize_rcu_full()` snapshots `rgosp->rgos_norm` from `rcu_state.gp_seq`, whereas `poll_state_synchronize_rcu_full()` tests it against the root `rnp->gp_seq` via `rcu_seq_done_exact()`. When `rcu_poll_gp_seq_end()` ends a polled GP (`*snap && *snap == rcu_state.gp_seq_polled`), it must zero both `gp_seq_polled_snap` and `gp_seq_polled_exp_snap` under the root `rnp->lock`. [F204, F213]
- At GP completion, `rcu_future_gp_cleanup()` must advance `rnp->gp_seq_needed` to `rnp->gp_seq` when `!ULONG_CMP_LT(rnp->gp_seq, rnp->gp_seq_needed)`, and `rcu_exp_wait_wake()` must advance `rnp->exp_seq_rq` to `s` when `ULONG_CMP_LT(rnp->exp_seq_rq, s)`. Waitqueue arrays `rnp->nocb_gp_wq[2]` and `rnp->exp_wq[4]` must be indexed after shifting via `rcu_seq_ctr()`, never with raw `seq & 0x1` or `s & 0x3`. [F94, F237, F272]
- `rcu_preempt_check_blocked_tasks()` must run under `rnp->lock` before advancing `rnp->gp_seq`, setting `rnp->gp_tasks = rnp->blkd_tasks.next` when `rcu_preempt_has_tasks(rnp)` and `(rnp->qsmaskinit || rnp->wait_blkd_tasks)` hold. In `rcu_preempt_ctxt_queue()`, `t->rcu_node_entry` may be inserted after `rnp->exp_tasks` / `rnp->gp_tasks` only when `RCU_EXP_TASKS` / `RCU_GP_TASKS` is set. In `rcu_report_qs_rnp()`, `(!(rnp->qsmask & mask) && mask)` must keep `&& mask` so `mask == 0` propagates blocked-task QSs on all-offline leaf nodes. [F62, F86, F259]
- In `struct rcu_tasks`, `rtp->rtpcp_array` is a dense array indexed by `rtpcp->index`, whereas `rtp->rtpcpu` is indexed by sparse CPU IDs (`rtpcp->cpu < rcu_task_cpu_ids`) bounded by `percpu_dequeue_lim`. When shrinking queues in `rcu_tasks_need_gpcb()`, set `percpu_enqueue_lim = 1` and snapshot `percpu_dequeue_gpseq` first, lowering `percpu_dequeue_lim` to 1 only after that GP completes and CPUs > 0 have zero callbacks. [F223, F238]
- `rcu_state.srs_next` mixes `struct rcu_synchronize` requests with dummy nodes from `rcu_state.srs_wait_nodes[]`; any traversal must test `rcu_sr_is_wait_head(node)` before calling `rcu_sr_normal_complete()` or `rcu_sr_put_wait_head()`. In `kernel/rcu/sync.c`, `rcu_sync_func()` must check `if (rsp->gp_count)` before `GP_REPLAY`, and `rcu_sync_exit()` when `--rsp->gp_count == 0` in `GP_EXIT` must set `gp_state = GP_REPLAY` instead of calling `rcu_sync_call()`. [F239, F249]

## Synchronization

- Every `struct rcu_node` (and `struct rcu_tasks_percpu`) `->lock` must use `raw_spin_lock*_rcu_node()` / `raw_spin_unlock*_rcu_node()` with IRQs disabled, and all `rcu_node` locks must be released before calling `rcu_gp_kthread_wake()`. Lock-consuming helpers (`rcu_report_qs_rnp()`, `rcu_report_unblock_qs_rnp()`, `__rcu_report_exp_rnp()`, `rcu_report_exp_cpu_mult()`, `rcu_initiate_boost()`, `rcu_print_task_stall()`, `rcu_nocb_unlock_irqrestore()`) unlock and restore IRQ `flags` on all return paths in both `#ifdef` and `#else` variants; `rcu_preempt_ctxt_queue()` unlocks `rnp->lock` leaving hard IRQs disabled; `rcu_start_this_gp()` returns with `rnp_start->lock` still held. [F9, F12, F66, F145, F146, F296, F300]
- Lock ordering: `rcu_state.ofl_lock` (IRQs disabled) -> `rcu_state.barrier_lock` -> `rdp->nocb_lock` -> `rdp->nocb_bypass_lock` (`rcu_nocb_do_flush_bypass()` requires both held and releases `nocb_bypass_lock`), and `barrier_lock` -> `rdp->nocb_lock` -> leaf `rnp->lock` -> parent/root `rnp->lock` (`rcu_check_gp_start_stall()` must lock leaf `rnp` before `rnp_root` and unlock both before `show_rcu_gp_kthreads()`). Never call `wake_nocb_gp()` or `__call_rcu_nocb_wake()` while holding `rnp->lock`. [F34, F117, F298, F299]
- Calling `rcu_rdp_is_offloaded(rdp)` requires holding `barrier_mutex`, CPU hotplug lock, `rdp->nocb_lock`, or `nocb_mutex`, or running on `rdp`'s CPU with preemption/softirq disabled or on `rdp`'s NOCB kthreads. `rcu_nocb_lock_irqsave()` must disable local IRQs before testing `rcu_segcblist_is_offloaded(&rdp->cblist)`. `rcu_gp_cleanup()` must not call `rcu_accelerate_cbs(rnp, rdp)` when `rcu_rdp_is_offloaded(rdp)` is true because it lacks `rdp->nocb_lock`. [F23, F168, F173]
- Toggling NOCB offload must synchronize `SEGCBLIST_OFFLOADED` on `rdp->cblist` and `rdp->nocb_entry_rdp` in `rdp_gp->nocb_head_rdp` under `rdp->nocb_lock`, and `rcu_nocb_mask` under `rcu_state.nocb_mutex`. When `rdp_gp->nocb_gp_kthread` is running, only `nocb_gp_wait()` via `nocb_gp_toggle_rdp()` may modify `nocb_head_rdp` while `rcu_nocb_rdp_offload()` / `rcu_nocb_rdp_deoffload()` queue `rdp` in `nocb_toggling_rdp` and wait on `rdp->nocb_state_wq`. [F25, F58, F84]
- In `rcu_boost()`, recheck `rnp->exp_tasks` and `rnp->boost_tasks` and call `rt_mutex_init_proxy_locked(&rnp->boost_mtx.rtmutex, t)` under `rnp->lock`, then unlock `rnp->lock` and restore IRQs before `rt_mutex_lock(&rnp->boost_mtx)`. In `rcu_preempt_deferred_qs_irqrestore()`, snapshot `rt_mutex_owner(&rnp->boost_mtx.rtmutex) == t` and `sync_rcu_exp_done(rnp)` under `rnp->lock` before unlocking to report QSs or call `rt_mutex_futex_unlock()`. [F31, F60]
- In `rcu_print_task_stall()`, tasks on `rnp->blkd_tasks` must be pinned via `get_task_struct(t)` under `rnp->lock`, and `rnp->lock` must be unlocked before calling `task_call_func(t, check_slow_task, &rscr)` and `put_task_struct(t)` via `while (i) { t = ts[--i]; ... }` so `ts[0]` is not skipped. [F33, F76]
- In `__rcu_read_unlock()`, a compiler `barrier()` must precede `rcu_preempt_read_exit()`, and when it returns `0`, another `barrier()` must order the `rcu_read_lock_nesting` decrement before reading `READ_ONCE(t->rcu_read_unlock_special.s)`. In `rcu_read_unlock_special()`, if `in_nmi()` is true on entry, return immediately without touching locks, IRQs, or softirqs. [F37, F109]
- In `rcu_gp_init()`, `rcu_sr_normal_gp_init()` and `rcu_seq_start(&rcu_state.gp_seq)` must run under the root `rnp->lock` in that order before scanning leaf `qsmaskinitnext` masks. In `rcu_sr_normal_gp_cleanup()`, increment `srs_cleanups_pending` before `queue_work()` (decrementing if `queue_work()` returns `false`), access `srs_done_tail` with release-acquire semantics, and keep the `done` wait-head dummy node in place (`done->next = NULL`) in `rcu_sr_normal_gp_cleanup_work()`. [F152, F171, F175]
- Under `rcu_state.ofl_lock` and `rnp->lock`, `rcutree_report_cpu_starting()` must set `rnp->qsmaskinitnext` before `rcu_report_qs_rnp()`, whereas `rcutree_report_cpu_dead()` must call `rcu_report_qs_rnp()` before clearing `rnp->qsmaskinitnext`. `rnp->expmaskinitnext` is never cleared on CPU offline, and `rcu_state.ncpus` is only incremented when `!(rnp->expmaskinitnext & mask)`. [F217, F218]
- In `rcu_exp_wait_wake()`, hold `rcu_state.exp_wake_mutex` across `rcu_exp_gp_seq_end()`, all `rnp->exp_seq_rq` updates, and `wake_up_all(&rnp->exp_wq[...])`. In `sync_rcu_exp_select_cpus()`, reset `rnp->exp_need_flush = false` on each leaf node and set it to `true` only when `rnp->rew.rew_work` is queued onto `rnp->exp_kworker` (never onto `rcu_exp_gp_kworker`). [F176, F262]
- In `call_rcu_tasks_generic()`, never acquire `rtp->cbs_gbl_lock` inside `rtpcp->lock`, and keep queue selection and `rcu_segcblist_enqueue()` inside `rcu_read_lock()`. When `rcu_tasks_postscan()` drops `rtpcp->lock` across `cond_resched()` on `rtpcp->rtp_exit_list`, it must anchor an on-stack `struct list_head tmp` after `t` and refresh `t1` from `tmp.next` after relocking; no other code may traverse `rtp_exit_list` concurrently. [F178, F224, F284]

## Object Lifetimes

- `rcu_nocb_rdp_deoffload()` must call `rcu_barrier()` and `kthread_park(rdp->nocb_cb_kthread)` before clearing `SEGCBLIST_OFFLOADED`, `nocb_cb_wait()` must only call `kthread_parkme()` when `rdp->nocb_cb_sleep` is true (with `rcu_segcblist_n_cbs(&rdp->cblist) == 0` under `rcu_nocb_lock_irqsave`), and `rcu_nocb_rdp_offload()` must wait for `SEGCBLIST_OFFLOADED` before `kthread_unpark(rdp->nocb_cb_kthread)`. [F7, F21]
- When removing `t` from `rnp->blkd_tasks` in `rcu_preempt_deferred_qs_irqrestore()`, under `rnp->lock` compute `np = rcu_next_node_entry(t, rnp)`, unlink `t->rcu_node_entry`, clear `t->rcu_blocked_node = NULL`, and advance any of `rnp->gp_tasks`, `rnp->exp_tasks`, or `rnp->boost_tasks` matching `&t->rcu_node_entry` to `np`. In Classic RCU Tasks, `rcu_tasks_postscan()` must check `list_empty(&t->rcu_tasks_holdout_list)` before `rcu_tasks_pertask()` pins `t` with `get_task_struct(t)`, and `check_holdout_task()` must call `put_task_struct(t)` after `list_del_init()`. [F10, F158]
- `rcu_segcblist_extract_done_cbs()` does not decrement `cblist.len`; `rcu_do_batch()` and `rcu_tasks_invoke_cbs()` must reinsert uninvoked callbacks via `rcu_segcblist_insert_done_cbs()` and subtract the invoked count via `rcu_segcblist_add_len()`. `rcutree_migrate_callbacks()` must merge all callbacks via `rcu_segcblist_merge()` before calling `rcu_segcblist_disable()`. [F147, F154]
- On-stack waiter & sync lifetimes: both loops in `__wait_rcu_gp()` must use identical `checktiny` and deduplication checks so `init_rcu_head_on_stack()` and `init_completion()` pair with `wait_for_completion_state()` and `destroy_rcu_head_on_stack()`. Read `rcu->next` and `rs->oldstate` before `complete(&rs->completion)` in `rcu_sr_normal_complete()`, and read `rewp->rew_s` before `rcu_exp_sel_wait_wake()` in `wait_rcu_exp_gp()`. `rcu_sync_dtor()` requires sleepable context with `gp_count == 0`, sets `GP_REPLAY` to `GP_EXIT` under `rsp->rss_lock`, and calls `rcu_barrier()` after unlocking if `gp_state != GP_IDLE`. [F67, F131, F182, F282, F283, F309]

## API Contracts

- When `rcu_nocb_try_bypass()` returns `false`, `rhp` is not enqueued and `rdp->nocb_lock` is held (if offloaded) for the caller to enqueue and unlock via `__call_rcu_nocb_wake()`; when `true`, `rhp` is enqueued and `rdp->nocb_lock` is unlocked. `rcu_nocb_do_flush_bypass()` / `rcu_nocb_flush_bypass()` always return `true` when `rhp` is `NULL`, and return `false` only when `rhp` is non-NULL and `nocb_bypass` was empty (caller must then enqueue `rhp` onto `rdp->cblist`). [F3, F41]
- `exp_funnel_lock()` returns `true` with `rcu_state.exp_mutex` unlocked when `s` is already done, and returns `false` with `exp_mutex` held and `rcu_exp_gp_seq_start()` called when the caller must drive the GP. `force_qs_rnp()` callbacks (`rcu_watching_snap_save()`, `rcu_watching_snap_recheck()`) return a signed tri-state `int`: `> 0` for QS, `< 0` for `resched_cpu()`, `0` for no action. [F189, F190]
- `rcuref_t` biases counts by `-1`: `rcuref_get()` requires RCU/memory stability and its `__must_check` boolean return must be verified; `rcuref_put_rcusafe()` requires `rcu_read_lock()` or atomic context (use `rcuref_put()` in preemptible context); object deconstruction must check the boolean return of `rcuref_put*()` or `rcuref_is_dead()`, never `rcuref_read() == 0`. [F183, F192, F273, F307]
- Read-side, callback & list contracts: sleeping, `synchronize_rcu*()`, or `rcu_softirq_qs()` inside `rcu_read_lock*()` or RCU callbacks (which run with BHs disabled) is illegal. `rcu_dereference_protected()` is illegal under `rcu_read_lock()` alone without the update lock. `list_del_rcu()`/`list_replace_rcu()` et al. require an RCU GP before freeing; `__list_splice_init_rcu()` must use `INIT_LIST_HEAD_RCU()` and `sync()` before updating `last->next`; `list_bidir_prev_rcu()` lists must use `list_bidir_del_rcu()`. [F184, F187, F203, F294, F306, F315]

## Error Handling

- Kthread & NULL checks: in `rcu_spawn_cpu_nocb_kthread()`, `rcu_spawn_one_boost_kthread()`, `rcu_spawn_exp_par_gp_kworker()`, and `rcu_start_exp_gp_kworker()`, check `kthread_create*()` / `kthread_run*()` with `IS_ERR()` / `IS_ERR_OR_NULL()` before assigning task/worker pointers (rolling back via `rcu_nocb_rdp_deoffload()` and `cpumask_clear_cpu(cpu, rcu_nocb_mask)` under `nocb_mutex` if `rcu_spawn_cpu_nocb_kthread()` fails). Guard `rdp->nocb_gp_rdp`, `nocb_cb_kthread`, `nocb_gp_kthread`, and `rcu_state.gp_kthread` against `NULL` before dereferencing or waking. [F8, F39, F40, F44, F45, F52, F188]
- Shrinker, barrier & stall error paths: `lazy_rcu_shrink_count()` and `lazy_rcu_shrink_scan()` must return `0` when `!cpumask_available(rcu_nocb_mask)` or `!mutex_trylock(&rcu_state.nocb_mutex)`, and return `SHRINK_EMPTY` / `SHRINK_STOP` respectively on a completed pass with `count == 0`. If `rcu_segcblist_entrain()` returns `false` in `rcu_barrier_entrain()`, call `debug_rcu_head_unqueue(&rdp->barrier_head)` without incrementing `barrier_cpu_count`. Only read `rscr` when `task_call_func(t, check_slow_task, &rscr) == 0`, only read `j`/`buf` when `rcu_is_rcuc_kthread_starving()` returns `true`, and check `kvm_check_and_clear_guest_paused()` before recording/printing stalls in `check_cpu_stall()`. [F30, F43, F48, F50, F100, F137, F148]

## Known Pitfalls

- `rcu_nocb_mask` is unallocated if no CPUs are offloaded at boot and can contain nonexistent CPUs from `rcu_nocb_setup()`: `rcu_init_nohz()` must intersect it with `cpu_possible_mask` before indexing `rcu_data`, and any path not guaranteed to run after `rcu_state.nocb_is_setup` must check `cpumask_available(rcu_nocb_mask)` first. `rcu_segcblist_empty()` returns `true` while extracted callbacks run in `rcu_do_batch()`, so `rcu_barrier()` and `rcu_segcblist_entrain()` must check `rcu_segcblist_n_cbs()` instead. [F71, F106, F197]
- Bitmasks & cursors: `rnp->qsmask` / `expmask` must use `1UL << (cpu - rnp->grplo)` or `leaf_node_cpu_bit(rnp, cpu)` (never 32-bit `1 << ...` or `BIT(cpu)`), and `rcu_find_next_bit(rnp, cpu, mask)` takes a `grplo`-relative offset while `for_each_leaf_node_cpu_mask()` yields a global `cpu` ID. Seed blocked-task stall loops with `list_entry(rnp->gp_tasks->prev, ...)` (or `exp_tasks->prev`) before `list_for_each_entry_continue()`. Use `list_first_or_null_rcu()` for lockless first-entry reads and test `!is_a_nulls()` in `hlist_nulls` loops. [F88, F92, F234, F244, F246, F251, F261]
