# MEMORY MANAGEMENT - THP (TRANSPARENT HUGE PAGE)

This unit implements Transparent Huge Page (THP) and multi-size THP (mTHP) management in the Linux kernel, covering PMD/PUD page faults, copy-on-write, zapping, protection changes, moving, and migration entries. It also provides uniform and non-uniform splitting of large folios and huge PMDs/PUDs (including a deferred split shrinker for partially mapped or underused folios), as well as collapsing PTE-mapped pages and pagecache folios into huge pages via the background `khugepaged` kernel thread or synchronous `MADV_COLLAPSE`.

## Architecture & Data Flow

- Anonymous folios cannot be allocated at or split to order 1 (`THP_ORDERS_ALL_ANON` excludes `BIT(0) | BIT(1)`, `uniform_split_supported()` and `non_uniform_split_supported()` reject `new_order == 1` for anon folios, and `deferred_split_folio()` ignores `folio_order(folio) <= 1`) because `folio->_deferred_list` resides in subpage 2. Broken by: enabling order-1 anon folios, removing the `split_order == 1` skip in `__split_unmapped_folio()`, or queueing order-1 folios on `_deferred_list`. [F88]
- In `__folio_split()`, when splitting a file-backed or shmem folio, sub-folios with `new_folio->index >= end` (where `end` is the EOF page index `DIV_ROUND_UP(i_size_read(mapping->host), PAGE_SIZE)`, adjusted by `shmem_fallocend()` for shmem) must not be stored into `mapping->i_pages` via `__xa_store()` and must instead be removed and uncharged. [F97]
- When `huge_zero_folio` is installed in `get_huge_zero_folio()` or freed in `shrink_huge_zero_folio_scan()`, `huge_zero_pfn` must be updated in lockstep to `folio_pfn(zero_folio)` or reset to `~0UL` via `WRITE_ONCE()`, because `is_huge_zero_pfn()` and `is_huge_zero_pmd()` identify huge zero PMDs by comparing against `huge_zero_pfn`. [F65]
- In `__thp_vma_allowable_orders()`, `vma_is_dax(vma)` must be checked before testing `vm_flags & VM_NO_KHUGEPAGED`, and `VM_NO_KHUGEPAGED` must only reject the VMA when `!in_pf && !smaps`. [F103]
- `struct mthp_stat` only allocates `stats` entries up to index `PMD_ORDER` (`ilog2(MAX_PTRS_PER_PTE) + 1`), so `mod_mthp_stat()` must guard updates with `if (order <= 0 || order > PMD_ORDER) return;` and `sum_mthp_stat()` must only be called for `thpsize` objects with `1 <= order <= PMD_ORDER`. [F91]
- `insert_pmd()` and `insert_pud()` must check the discriminator `fop.is_folio` on `struct folio_or_pfn` before accessing `fop.folio` or `fop.pfn`, and callers inserting a folio (`vmf_insert_folio_pmd()` and `vmf_insert_folio_pud()`) must initialize `.is_folio = true`. [F52]

## Synchronization

- In `__split_huge_pmd_locked()`, `__split_huge_zero_page_pmd()`, and `zap_huge_pmd()`, `pgtable_trans_huge_withdraw()` (or `zap_deposited_table()`) and `pmd_populate()` must only be called after the PMD entry has been marked invalid or cleared via `pmdp_invalidate()`, `pmdp_huge_clear_flush()`, or `pmdp_huge_get_and_clear_full()`. In `__split_huge_pmd_locked()`, `is_pmd_migration_entry(*pmd)` must also be checked before calling `pmdp_invalidate()`. [F38, F134]
- In `change_huge_pmd()` and `change_huge_pud()`, the PMD or PUD entry must be invalidated in place via `pmdp_invalidate_ad()` or `pudp_invalidate()` rather than cleared to zero with `pmdp_huge_get_and_clear()` or `pudp_huge_get_and_clear()` before writing the updated entry via `set_pmd_at()` or `set_pud_at()`. [F37]
- In `collapse_file()`, all page data must be copied or zeroed into `new_folio`, and `folio_mark_uptodate(new_folio)` and `folio_ref_add(new_folio, HPAGE_PMD_NR - 1)` must be called before publishing `new_folio` into `mapping->i_pages` via `xas_store(&xas, new_folio)`. [F28]
- In `do_huge_pmd_wp_page()`, if `folio_trylock(folio)` fails while holding `vmf->ptl`, `folio_get(folio)` must be called before dropping `vmf->ptl` to call `folio_lock(folio)`, and after reacquiring `vmf->ptl`, both `pmd_same(*vmf->pmd, orig_pmd)` and `PageAnonExclusive(page)` must be rechecked. [F41]
- In `do_huge_pmd_numa_page()`, after dropping `vmf->ptl` to call `migrate_misplaced_folio()`, if migration fails, `vmf->ptl` must be reacquired and `pmd_same(pmdp_get(vmf->pmd), vmf->orig_pmd)` verified; if the PMD changed, it must unlock `vmf->ptl` and return immediately without restoring the PMD or calling `task_numa_fault()`. [F42]
- In `__discard_anon_folio_pmd_locked()`, after `pmdp_huge_clear_flush()`, `smp_mb()` must precede reading `folio_ref_count(folio)` and `folio_mapcount(folio)`, and `smp_rmb()` must precede checking `folio_test_dirty(folio)` before deciding whether to restore `orig_pmd` via `set_pmd_at()`. [F43]
- In `__collapse_huge_page_copy_succeeded()`, `spin_lock(ptl)` must be held around `clear_ptes()` and `folio_remove_rmap_ptes()` even though the PTE page table is already unlinked from the PMD. [F145]

## Object Lifetimes

- In `do_huge_pmd_anonymous_page()`, `__do_huge_pmd_anonymous_page()`, `insert_pmd()`, and `copy_huge_pmd()`, a preallocated `pgtable_t` from `pte_alloc_one()` must either be deposited via `pgtable_trans_huge_deposit()` (with `mm_inc_nr_ptes(mm)`) or freed via `pte_free()` on every abort path. [F11]

## API Contracts

- `thp_vma_allowable_orders()` and `__thp_vma_allowable_orders()` accept and return a bitmask of orders (where bit N represents order N, e.g., `BIT(order)`), whereas `thp_vma_allowable_order()` and `thp_vma_suitable_order()` accept a single integer order index. [F62]
- Because `highest_order(orders)` returns `fls_long(orders) - 1` (`-1` when `orders` is 0), every caller of `highest_order()` or `next_order()` (e.g., `thp_vma_suitable_order()`, `thpsize_create()`) must verify `orders != 0` before using the returned order as a shift exponent in `PAGE_SIZE << order` or `BIT(order)`. [F119]
- `thp_vma_suitable_order(vma, addr, order)` requires `ALIGN_DOWN(addr, PAGE_SIZE << order)` to lie within `[vma->vm_start, vma->vm_end - (PAGE_SIZE << order)]`, and for non-anonymous VMAs also requires `IS_ALIGNED((vma->vm_start >> PAGE_SHIFT) - vma->vm_pgoff, 1 << order)`. [F98]
- `split_huge_pmd_locked()` and `unmap_huge_pmd_locked()` require their virtual address argument to be aligned to `HPAGE_PMD_SIZE` (`VM_WARN_ON_ONCE(!IS_ALIGNED(address, HPAGE_PMD_SIZE))`), whereas `__split_huge_pmd()` masks its address argument with `HPAGE_PMD_MASK` before calling `split_huge_pmd_locked()`. [F64]
- In `insert_pmd()` and `insert_pud()`, normal refcounted folios (`fop.is_folio && !is_huge_zero_folio(fop.folio)`) must be mapped via `folio_mk_pmd()`/`folio_mk_pud()` with `folio_get()`, file rmap addition, and `mm_counter_file()` updates, and must never be marked special or devmap with `pmd_mkspecial()`, `pmd_mkdevmap()`, `pud_mkspecial()`, or `pud_mkdevmap()`. [F151]
- `vmf_insert_folio_pmd()` and `vmf_insert_folio_pud()` require `folio_order(folio)` to equal `PMD_ORDER` and `PUD_ORDER` respectively (returning `VM_FAULT_SIGBUS` with `WARN_ON_ONCE` otherwise), and `insert_pmd()` / `insert_pud()` require the aligned `addr` (`vmf->address & PMD_MASK` or `PUD_MASK`) to fall within `[vma->vm_start, vma->vm_end)`. [F99]
- When `thp_underused()` checks whether subpages of a large folio match `ZERO_PAGE(0)`, it must use `pages_identical(folio_page(folio, i), ZERO_PAGE(0))` rather than raw byte comparison (`memchr_inv()` or `memcmp()`). [F155]

## Error Handling

- In `collapse_file()`, each isolated folio on `pagelist` holds `2 + folio_nr_pages(folio)` references (lookup pin, LRU isolation, and page cache); on success, all `2 + folio_nr_pages(folio)` refs are dropped via `folio_put_refs()`, whereas on `rollback:`, each folio is unlocked, returned via `folio_putback_lru()`, and given a single `folio_put()` without dropping page-cache references. [F18]
- In `collapse_file()`, if `alloc_charge_folio(&new_folio, mm, cc)` fails, it sets `new_folio = NULL` and must jump directly to `out:` (where `trace_mm_khugepaged_collapse_file()` guards `folio_pfn(new_folio)` with `new_folio ? ... : -1`), because `rollback:` requires a valid locked `new_folio`. [F57]
- In `collapse_pte_mapped_thp()`, if the step-2 loop aborts after clearing `nr_mapped_ptes > 0` PTEs and removing their rmap entries, `abort:` must call `flush_tlb_mm(mm)`, `folio_ref_sub(folio, nr_mapped_ptes)`, and `add_mm_counter(mm, mm_counter_file(folio), -nr_mapped_ptes)` before unlocking and putting `folio`. Broken by: jumping to `unlock:` or `drop_folio:` instead of `abort:`. [F21]
- In `__collapse_huge_page_isolate()`, large folios are deduplicated onto `compound_pagelist` rather than released per-PTE; consequently, `release_pte_pages()` and `__collapse_huge_page_copy_succeeded()` must skip `folio_test_large(folio)` during the PTE loop and call `release_pte_folio()` once per large folio when draining `compound_pagelist`. [F17]
- Scan and collapse functions in `mm/khugepaged.c` return non-negative `enum scan_result` codes (where `SCAN_FAIL` is 0 and `SCAN_SUCCEED` is 1), which `madvise_collapse()` must translate into negative errno values via `madvise_collapse_errno()` when `thps != ((hend - hstart) >> HPAGE_PMD_SHIFT)`. [F49]
- In `__collapse_huge_page_copy()` and `collapse_file()`, `copy_mc_user_highpage()` and `copy_mc_highpage()` return a positive residual byte count (`> 0`) on machine-check memory poison, which must be checked with `> 0` (not `< 0`) and mapped to `SCAN_COPY_MC`. [F51]

## External Contracts

- `max_ptes_none_store()`, `max_ptes_swap_store()`, and `max_ptes_shared_store()` in `mm/khugepaged.c` must reject values `> HPAGE_PMD_NR - 1` with `-EINVAL`, and `pages_to_scan_store()` must reject `0` with `-EINVAL` because `khugepaged_scan_mm_slot()` asserts `VM_BUG_ON(!pages)`. [F92]
- `setup_thp_anon()` must validate `strlen(str) + 1 <= PAGE_SIZE` before copying into `str_dup`, and for each parsed `<start>-<end>:<policy>` range must verify `start >= 0`, `end >= 0`, and `start <= end` (against `THP_ORDERS_ALL_ANON`) before calling `bitmap_set()` or `bitmap_clear()` with `nr = end - start + 1`. [F100]
- In `split_huge_pages_write()`, user input copied into `input_buf[MAX_INPUT_BUF_SZ]` is bounded to `min_t(size_t, count, MAX_INPUT_BUF_SZ)` and must have `input_buf[MAX_INPUT_BUF_SZ - 1] = '\0'` enforced before string parsing (`strsep`, `sscanf`, `strlen`); when parsing a `'/'`-prefixed command, `input_len = strlen(input_buf)` must be recorded before `strsep(&tok_buf, ",")` overwrites the comma delimiter with NUL. [F101, F128]
- THP sysfs mode-selection show handlers (`enabled_show()`, `defrag_show()`, `anon_enabled_show()`) must format all supported options as a single space-separated line with the active option in square brackets (`[option]`), and `single_hugepage_flag_store()` must reject values `> 1` with `-EINVAL`. [F102]

## Known Pitfalls

- Before passing `folio->mapping` to `address_space` helpers such as `mapping_large_folio_support()`, `mapping_min_folio_order()`, or `shmem_mapping()`, functions in `mm/huge_memory.c` (e.g., `uniform_split_supported()`, `non_uniform_split_supported()`) must first verify `!folio_test_anon(folio)` because anonymous folios store an `anon_vma` pointer in `folio->mapping`. [F53]
- In `release_pte_pages(pte, _pte, compound_pagelist)`, `_pte` is an exclusive upper bound iterated backward with `while (--_pte >= pte)` (so callers such as `__collapse_huge_page_copy_failed()` must pass one past the last isolated PTE), and each PTE must be checked with `!pte_none(pteval)` and `!is_zero_pfn(pte_pfn(pteval))` before calling `pfn_folio(pfn)`. [F55, F95]
- In `collapse_file()`, because `xas_unlock_irq(&xas)` is dropped during each iteration of the page-cache scan loop, each iteration must refresh the cursor with `xas_set(&xas, index)` before `xas_load(&xas)`, and post-relock assertions must use `xa_load(xas.xa, index)` rather than mutating `xas`. [F75]
- When batching PTEs of a large folio in `__collapse_huge_page_copy_succeeded()` and `collapse_pte_mapped_thp()`, `folio_pte_batch()` must be bounded by `max_nr_ptes = (end - addr) >> PAGE_SHIFT` (where `end = haddr + HPAGE_PMD_SIZE`) so the batch never crosses the PMD page table boundary. [F96]
- In `__split_folio_to_order()`, `new_folio` is cast from `struct page *new_head = &folio->page + i` while `PageTail(new_head)` is still set, so `new_folio` must not be passed to `folio_*` helpers before `clear_compound_head(new_head)` (and `prep_compound_page()` when `new_order > 0`) clears the tail state. [F123]
- In `copy_huge_pmd()`, `pmd_special(pmd)` must only be evaluated after `pmd_present(pmd)` is confirmed true. [F105]
- In `split_huge_pages_pid()` and `split_huge_pages_in_file()`, user-supplied `in_folio_offset` must be bounds-checked against `[0, folio_nr_pages(folio))` before calling `folio_page(folio, in_folio_offset)` (falling back to uniform `split_folio_to_order()` otherwise); `split_huge_pages_pid()` must advance `addr` by `PAGE_SIZE` (not folio size), and `split_huge_pages_in_file()` must reset `nr_pages = 1` before `if (IS_ERR(folio)) continue;`. [F90, F114, F115]
- Sysfs attribute callbacks that downcast `kobj` via `to_thpsize(kobj)` (`anon_enabled_show()`, `anon_enabled_store()`, and `DEFINE_MTHP_STAT_ATTR()` handlers) must only be registered on `struct thpsize` kobjects created by `thpsize_create()`, never in `hugepage_attr_group` or `khugepaged_attr_group`. [F130]
- In `khugepaged_should_wakeup()`, `jiffies` must be compared against `khugepaged_sleep_expire` using `time_after_eq(jiffies, khugepaged_sleep_expire)` (not `jiffies >= khugepaged_sleep_expire`) unless `khugepaged_sleep_expire` is explicitly reset to 0 by sysfs sleep-interval stores paired with `wake_up_interruptible(&khugepaged_wait)`. [F122]
