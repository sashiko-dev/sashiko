# SLAB ALLOCATOR

The SLAB ALLOCATOR unit (`mm/slub.c`, `mm/slab_common.c`, `mm/mempool.c`, `mm/failslab.c`) implements the kernel's object-caching heap allocator (SLUB), generic slab cache management, batched RCU-delayed freeing (`kvfree_rcu`), emergency memory pools (`mempool`), and slab fault injection, along with KASAN/KFENCE/memcg hooks and sysfs/procfs/debugfs introspection.

## Architecture & Data Flow

- When `slab_want_init_on_free(s)` is true and `!freeptr_outside_object(s)`, `maybe_wipe_obj_freeptr(s, obj)` must zero the `sizeof(void *)` bytes at `obj + s->offset` upon allocation because freelist linkage overwrote those zeroed bytes while free. Broken by: dequeuing an object in `slab_alloc_node()`, `kmalloc_nolock_noprof()`, or `__kmem_cache_alloc_bulk()` without calling `maybe_wipe_obj_freeptr()`. [F54]
- Every slab deallocation path (`slab_free_hook()`, `slab_free_freelist_hook()` paired with `build_detached_freelist()`, and `__kmem_cache_free_bulk()`) must intercept KFENCE objects via `is_kfence_address()` and `kfence_free()` before writing freepointers (`set_freepointer()`) or calling `do_slab_free()`. [F84]
- `SLAB_TYPESAFE_BY_RCU` delays freeing empty slab pages via `call_rcu(&slab->rcu_head, rcu_free_slab)` in `free_slab()` while allowing immediate object reuse; therefore `calculate_sizes()` disables `__OBJECT_POISON` and places `s->offset` outside the object (unless `use_freeptr_offset` without `ctor`), and `init_on_free` (`slab_want_init_on_free`) is disabled. [F165]
- Within each SLUB object slot, post-object metadata starts at `object + get_info_end(s)` (`s->inuse + sizeof(void *)` if `freeptr_outside_object(s)`, else `s->inuse`), followed by `2 * sizeof(struct track)` (`SLAB_STORE_USER`), `sizeof(unsigned int)` (`orig_size`), and `kasan_metadata_size(s, false)`. Broken by: offsetting `struct track`, `orig_size`, or padding bytes from `s->object_size` or `s->inuse` instead of `get_info_end(s)`. [F94]
- When `SLAB_RED_ZONE` is enabled, object pointers are offset by `s->red_left_pad` via `fixup_red_left()`, so alignment and bounds checks against `slab_address(slab)` and `s->size` in `check_valid_pointer()` and `__kmem_obj_info()` must first subtract `s->red_left_pad` via `restore_red_left()`. [F141]
- In `__check_heap_object()`, for non-KFENCE objects with `SLAB_RED_ZONE`, `offset < s->red_left_pad` must be rejected before subtracting `s->red_left_pad`, and the usercopy range check must test `offset >= s->useroffset`, `offset - s->useroffset <= s->usersize`, and `n <= s->useroffset - offset + s->usersize`. Broken by: subtracting `s->red_left_pad` first or checking `offset + n <= s->useroffset + s->usersize` with potential unsigned wrap. [F88]
- In `slab_free_freelist_hook()`, `old_tail = *tail` must be saved before resetting `*head` and `*tail` to `NULL`, and `next = get_freepointer(s, object)` must be read before calling `slab_free_hook()` and `set_freepointer()` in the `do { ... } while (object != old_tail)` loop. [F115]
- In `build_detached_freelist()`, whenever a lookahead object at `p[size]` matches `df->slab`, `same` must be decremented and `p[size]` swapped with `p[same]` before continuing without decrementing `lookahead`, and the function must return `same` (not `size`). [F116]
- When `alloc_debug_processing()` aborts an allocation on a consistency check failure and marks all objects used (`slab->inuse = slab->objects` and `slab->freelist = NULL`), it must also set `slab->frozen = 1` so `check_slab()` rejects later frees to that unlinked slab. [F65]
- In `on_freelist()`, traversal of `slab->freelist` must be bounded by `nr <= slab->objects`; exceeding `slab->objects` must abort the walk, clear `slab->freelist = NULL`, and set `slab->inuse = slab->objects`. [F120]
- In `validate_slab_cache()` and `slab_debug_trace_open()`, the dynamic `obj_map` bitmap is sized to `oo_objects(s->oo)` bits via `bitmap_alloc()`, and `validate_slab()` must run `check_slab()` and `on_freelist()` before calling `__fill_map(obj_map, s, slab)` so `slab->objects` and freelist pointers are bounds-checked before indexing `obj_map`. [F147]
- `calculate_sizes()` must initialize `s->reciprocal_size = reciprocal_value(size)` after final alignment of `s->size` and before `s->oo` is calculated or any slab objects are indexed via `__obj_to_index()` / `obj_to_index()`. [F128]
- `calculate_order()` must cap the slab order so `order_objects(order, size)` never exceeds `MAX_OBJS_PER_PAGE` (32767), because `struct slab::objects` is a 15-bit unsigned bitfield and `struct kmem_cache_order_objects` packs object count in `OO_MASK` (low 16 bits). [F125]
- `__kmalloc_minalign()` and `calculate_alignment()` must clamp the returned alignment to at least `arch_slab_minalign()` via `max(..., arch_slab_minalign())`. [F89]
- In `setup_kmalloc_cache_index_table()`, the loop patching `kmalloc_size_index[]` for `i < KMALLOC_MIN_SIZE` must stop when `size_index_elem(i) >= ARRAY_SIZE(kmalloc_size_index)` (24, for 192 bytes), because `KMALLOC_MIN_SIZE` can be up to 256 bytes. [F91]
- In `kmem_buckets_create()` and `new_kmalloc_cache()`, indices mapping to the same `aligned_idx = __kmalloc_index(size, false)` must share the single `kmem_cache` at `aligned_idx`, and `kmem_buckets_create()` rollback must only call `kmem_cache_destroy()` once per unique bit in `unsigned long mask` (which requires `ARRAY_SIZE(kmalloc_caches[KMALLOC_NORMAL]) <= BITS_PER_LONG`). [F77, F148]
- A `kmem_cache` with `s->refcount > 1` must not have `SLAB_FAILSLAB` modified via `failslab_store()`, and any flag in `SLAB_MERGE_SAME` permitted on mergeable caches must be encoded into the sysfs name by `create_unique_id()`. [F78]
- Because `kmem_cache_init()` sizes the `kmem_cache` slab to `offsetof(struct kmem_cache, node) + nr_node_ids * sizeof(struct kmem_cache_node *)`, `s->node[]` must never be indexed at `>= nr_node_ids` (use `for_each_kmem_cache_node`) and `bootstrap()` must copy `kmem_cache->object_size` bytes rather than `sizeof(struct kmem_cache)`. [F98]
- Every `struct slab_sheaf` allocation in `alloc_empty_sheaf()` and `kmem_cache_prefill_sheaf()` must size the trailing `objects[]` flexible array with `struct_size(sheaf, objects, ...)` for `s->sheaf_capacity` or `size` elements, and bulk `memcpy()` on `sheaf->objects` must scale the element count by `sizeof(void *)`. [F139]
- In `mm/slab_common.c`, every mutation of `kfree_rcu_cpu->bulk_head[i]` or `kfree_rcu_cpu->head` under `krcp->lock` must update the paired `krcp->bulk_count[i]` or `krcp->head_count` (and grace-period snapshot `bnode->gp_snap`, `krcp->head_gp_snap`, or `krwp->head_free_gp_snap`) in lockstep. [F72]
- `struct kvfree_rcu_bulk_data` is allocated as a single page (`PAGE_SIZE`), so `add_ptr_to_bulk_krc_lock()` must allocate or fetch a new block whenever `!bnode || bnode->nr_records == KVFREE_BULK_MAX_ENTR` before incrementing `bnode->nr_records` and writing `bnode->records[bnode->nr_records - 1]`. [F100]
- In `mempool_init_node()`, `pool->elements` must be allocated with `max(1, min_nr)` slots and prefilled while `pool->curr_nr < max(1, pool->min_nr)`, and `mempool_free()` must handle `pool->min_nr == 0 && READ_ONCE(pool->curr_nr) == 0` so zero-minimum pools have a 1-element buffer to store an element via `add_element()` and wake waiters. [F99]

## Synchronization

- Lock ordering is `cpus_read_lock` / `mem_hotplug_lock` -> `slab_mutex` -> `kernfs_mutex`: `kmem_cache_destroy()` must drop `slab_mutex` and `cpus_read_unlock()` before calling `sysfs_slab_unlink()` or `kmem_cache_release()`, and `show_slab_objects()` must not take `mem_hotplug_lock`. [F150]
- When recording stack traces with `SLAB_STORE_USER`, `___slab_alloc()` must mask `__GFP_DIRECT_RECLAIM` out of `gfpflags` passed to `set_track()` while preemption is disabled, and `free_to_partial_list()` must call `set_track_prepare(__GFP_NOWARN)` before acquiring `n->list_lock` rather than inside it. [F152]
- Work items in `flush_all_cpus_locked()`, `flush_all_rcu_sheaves()`, `kvfree_rcu_queue_batch()`, and `__schedule_delayed_monitor_work()` must be queued on `WQ_MEM_RECLAIM` workqueues (`flushwq` and `rcu_reclaim_wq`), never `system_wq` or `system_unbound_wq`, because callers in `WQ_MEM_RECLAIM` context flush them. [F153]
- `add_ptr_to_bulk_krc_lock(&krcp, &flags, ptr, can_alloc)` acquires `*krcp = krc_this_cpu_lock(flags)` and must return with `(*krcp)->lock` held on both `true` and `false` paths (re-locking after any unlocked `__get_free_page()` call), and `kvfree_call_rcu()` must call `krc_this_cpu_unlock()` before `synchronize_rcu()`. [F19]
- All manipulations of `kfree_rcu_cpu->bkvcache` and `kfree_rcu_cpu->nr_bkv_objs` (`get_cached_bnode()`, `put_cached_bnode()`, `drain_page_cache()`) must be serialized by `krcp->lock` even though `bkvcache` is a `struct llist_head`. [F37]
- In `kvfree_rcu_queue_batch()`, a batch `krwp` in `krcp->krw_arr` may only have channels detached into it and `queue_rcu_work(rcu_reclaim_wq, &krwp->rcu_work)` called when `need_wait_for_krwp_work(krwp)` is false under `krcp->lock`. [F38]
- When draining `llist_head` queues in `free_deferred_objects()` and `drain_page_cache()`, the list detached by `llist_del_all()` must be traversed with `llist_for_each_safe()` because each iteration overwrites or frees the node. [F114]
- In `mempool_resize()`, after dropping and re-acquiring `pool->lock` to allocate `new_elements` or `element`, it must recheck `new_min_nr <= pool->min_nr` and `pool->curr_nr < pool->min_nr` before replacing `pool->elements` or calling `add_element(pool, element)`, freeing the unused allocation outside `pool->lock` if a racing resize or free satisfied the target. [F21]
- `__kvmalloc_node_noprof()` must check `gfpflags_allow_blocking(flags)` before falling back to `__vmalloc_node_range_noprof()`, `slab_out_of_memory()` must suppress OOM logging if `gfpflags & __GFP_NOWARN` is set or `__ratelimit(&slub_oom_rs)` is false, and `dump_unreclaimable_slab()` must acquire `slab_mutex` via `mutex_trylock(&slab_mutex)` rather than `mutex_lock()` to avoid sleeping in OOM context. [F169, F184]

## Object Lifetimes

- In `kmem_cache_destroy()`, if `__kmem_cache_shutdown(s)` returns non-zero (`err != 0`), it must return after unlinking sysfs/debugfs without calling `kmem_cache_release(s)`; when `err == 0` on a `SLAB_TYPESAFE_BY_RCU` cache, it must call `rcu_barrier()` before `kmem_cache_release(s)`. [F3]

## API Contracts

- Two-argument `kvfree_call_rcu(head, ptr)` is safe in atomic contexts under `raw_spinlock_t` `krcp->lock`, whereas headless `kvfree_call_rcu(NULL, ptr)` (single-argument `kvfree_rcu(ptr)`) requires `might_sleep()` context because it drops `krcp->lock` to allocate a page with `GFP_KERNEL` and falls back to `synchronize_rcu()`. [F164]
- Allocation entry points and helpers suffixed with `_noprof` (`mempool_create_node_noprof()`, `mempool_alloc_slab()`, `mempool_kmalloc()`, `krealloc_node_align_noprof()`) must call `_noprof` allocation primitives so profiling attributes the charge to the outer caller. [F62]
- In the `slab-kvfree-rcu` MM shrinker, `kfree_rcu_shrink_count()` must return `SHRINK_EMPTY` (not `0`) when the total object count is zero, and `kfree_rcu_shrink_scan()` must return `SHRINK_STOP` (not `0`) when `freed == 0`. [F180]
- In the BPF kfunc `bpf_get_kmem_cache(u64 addr)`, `virt_addr_valid((void *)(long)addr)` must be checked before calling `virt_to_slab()`. [F186]
- Comparison callbacks passed to `sort()`, such as `cmp_loc_by_count()` in `mm/slub.c`, must return `0` when the compared keys are equal (using `cmp_int(loc2->count, loc1->count)`). [F64]

## Error Handling

- `create_cache()` returns `ERR_PTR(err)` on failure whereas `__kmem_cache_create_args()` must return `NULL` (or panic if `SLAB_PANIC` is set), so `__kmem_cache_create_args()` must check `IS_ERR(s)`, extract `PTR_ERR(s)`, free `cache_name`, and return `NULL`. [F40]
- `calculate_order()` returns a negative errno (`-ENOSYS`) when the object size cannot fit within `MAX_PAGE_ORDER`, so `calculate_sizes()` must cast its `unsigned int order` variable to signed `(int)order < 0` before packing `order` into `s->oo`. [F45]
- In `__kmem_cache_create_args()`, usercopy region bounds must be validated without unsigned underflow by checking `object_size < args->usersize || object_size - args->usersize < args->useroffset` (and rejecting `!args->usersize && args->useroffset`), failing closed by zeroing both `args->usersize` and `args->useroffset`. [F87]
- In `object_err()`, `print_trailer(s, slab, object)` must only be called when `object` is non-NULL and passes `check_valid_pointer(s, slab, object)`, because `print_trailer()` dereferences object metadata and redzones. [F50]
- In `should_failslab()`, fault injection must be skipped when `s == kmem_cache` or `gfpflags & __GFP_NOFAIL`, and `FAULT_NOWARN` must be passed to `should_fail_ex()` whenever `gfpflags & __GFP_NOWARN` is set. [F183]

## External Contracts

- In `remote_node_defrag_ratio_store()`, userspace input parsed via `kstrtouint()` is a percentage that must be validated as `<= 100` (returning `-ERANGE` otherwise) before multiplying by 10 to store in `s->remote_node_defrag_ratio` (and `remote_node_defrag_ratio_show()` divides by 10). [F101]
- In `cache_show()`, `struct slabinfo` must be zero-initialized before `get_slabinfo()` and formatted with the `/proc/slabinfo` 2.1 `: tunables` and `<sharedavail>` columns, and `kmem_cache_sanity_check()` warns on duplicate cache names or names containing spaces. [F102]
- In `sysfs_slab_add()`, `create_unique_id()` must return `ERR_PTR(-ENOMEM)` on `kmalloc()` failure, and `do_kmem_cache_create()` must log and ignore `sysfs_slab_add()` errors so fallible sysfs registration does not abort cache creation. [F170]

## Known Pitfalls

- In `check_object()`, when checking free-object poison bytes after KASAN free metadata (`kasan_meta_size`), `kasan_meta_size < s->object_size - 1` must be checked before computing `s->object_size - kasan_meta_size - 1` for `check_bytes_and_report()` (`POISON_FREE`) to avoid unsigned underflow. [F96]
- In `calculate_order()`, `max_objects` must be clamped to at least `1U` via `max(order_objects(slub_max_order, size), 1U)` before `min_objects = min(min_objects, max_objects)` so `get_order(min_objects * size)` is never called with 0 when `size > (PAGE_SIZE << slub_max_order)`. [F126]
- In `slab_debugfs_start()`, `slab_debugfs_next()`, and `slab_debugfs_show()`, the `loff_t` position must be stored in `struct loc_track::idx` and read from `t->idx` rather than casting the `void *v` (`loff_t *`) iterator pointer to a narrower integer pointer, and `slab_debugfs_show()` must use `div_u64(l->sum_time, l->count)` (with `l->count` guaranteed non-zero by `add_location()`) rather than `/`. [F97, F129]
- `__schedule_delayed_monitor_work()` must compute `delay_left = krcp->monitor_work.timer.expires - jiffies` in a signed `long` before comparing `if (delay < delay_left)` to handle `jiffies` wrap-around. [F132]
- `create_boot_cache()` must only be called with a non-zero `size` when `flags & SLAB_KMALLOC` is set, because it computes `1U << (ffs(size) - 1)` where `ffs(0) - 1` evaluates to `-1`. [F133]
- Preprocessor feature macros tested with `__is_defined()`, such as `SLAB_SUPPORTS_SYSFS` in `kmem_cache_release()`, must be defined to `1` rather than an empty expansion. [F107]
