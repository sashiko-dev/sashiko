# GENERIC PM DOMAINS

This unit provides the public header definitions for the Linux Generic Power Domain (genpd) framework (`include/linux/pm_domain.h`) and vendor-specific SoC power domain controller drivers under `drivers/pmdomain/` (MediaTek SCPSYS, Airoha, Qualcomm RPM/RPMh, Rockchip PMU, Samsung Exynos, Allwinner PPU/PCK-600, NVIDIA Tegra BPMP, and Xilinx ZynqMP). These drivers register Device Tree power domain providers and implement power sequencing, performance-state scaling, clock/regulator/reset coordination, bus protection, and QoS register save/restore.

## Architecture & Data Flow

- In `mtk-pm-domains.c`, `rockchip/pm-domains.c`, `rpmhpd.c`, and `rpmpd.c`, the domain pointer arrays (`pd_data.domains`, `genpd_data.domains`, `desc->rpmhpds`, `desc->rpmpds`) are sparse and indexed by hardware domain ID; any loop over `num_domains` or `num_pds` must check for `NULL` before dereferencing or calling `to_scpsys_domain()`/`to_rockchip_pd()`. Similarly, `scpsys->soc_data->domains_data` is sparse where unpopulated slots have `sta_mask == 0`, so `scpsys_add_one_domain()` must check both `id < scpsys->soc_data->num_domains` and `domain_data->sta_mask != 0`. [F35, F36]
- Every `bus_prot_block` and `bus_prot_sta_block` in `scpsys_domain_data::bp_cfg` must be `< BUS_PROT_BLOCK_COUNT` and listed in `scpsys_soc_data::bus_prot_blocks` (or legacy DT properties), because `scpsys_bus_protect_get_regmap()` and `scpsys_bus_protect_get_sta_regmap()` index `scpsys->bus_prot[scpsys->bus_prot_index[block]]` directly. [F64]
- In `scpsys_ctl_pwrseq_on()`, `SCPSYS_RTFF_TYPE_GENERIC` and `SCPSYS_RTFF_TYPE_PCIE_PHY` domains must only run the `PWR_RTFF_NRESTORE` sequence if `PWR_RTFF_SAVE_FLAG` is set in `pd->data->ctl_offs` (set by `scpsys_ctl_pwrseq_off()`, cleared on restore), whereas `SCPSYS_RTFF_TYPE_STOR_UFS` must always run `PWR_RTFF_NRESTORE`. [F49]
- In `drivers/pmdomain/rockchip/pm-domains.c`, all mask arguments to `DOMAIN*` macros must be pre-shifted bitmasks (`BIT(n)`), and `pwr`, `req`, and `g_mask` on HIWORD_UPDATE SoCs (`DOMAIN_M*`) must fit in bits `0..15` because `pwr_w_mask`, `req_w_mask`, and `clk_ungate_w_mask` shift them left by 16. [F43]
- In `rockchip_pd_power()`, while `pd->clks` are enabled and `rockchip_pmu_ungate_clk(pd, true)` is active under `pmu->mutex`, `rockchip_pmu_save_qos(pd)` must run before `rockchip_pmu_set_idle_request(pd, true)` on power-off, and `rockchip_pmu_restore_qos(pd)` must run after `rockchip_pmu_set_idle_request(pd, false)` succeeds on power-on. `pd->qos_save_regs` must be indexed as `qos_save_regs[reg_idx][qos_idx]` with `reg_idx < MAX_QOS_REGS_NUM` outer and `qos_idx < pd->num_qos` inner. [F54, F69]
- In `rockchip_do_pmu_set_power_domain()`, when powering on (`on == true`) a domain with a non-zero `pd->info->mem_status_mask`, `rockchip_pmu_domain_is_mem_on(pd)` must be sampled before writing the power-on command to `pmu->info->pwr_offset + pd_pwr_offset` so `rockchip_pmu_domain_mem_reset(pd)` runs if memory was already on. After polling `rockchip_pmu_domain_is_on()` confirms the hardware state matches `on`, the driver must invoke `arm_smccc_smc(ROCKCHIP_SIP_SUSPEND_MODE, ROCKCHIP_SLEEP_PD_CONFIG, ...)` whenever `arm_smccc_1_1_get_conduit() != SMCCC_CONDUIT_NONE`. [F53, F55]
- In `rockchip_pm_add_one_domain()`, if `pmu->genpd_data.domains[id]` is already non-NULL, the function must return `0` without reallocating or reinitializing so shared child domains with multiple DT parents reuse the existing `generic_pm_domain`. Domains must also set `GENPD_FLAG_NO_STAY_ON` in `pd->genpd.flags` because `rockchip_pd_regulator_enable()` lazily acquires `pd->supply` via `devm_of_regulator_get()` on power-on rather than during probe. [F56, F116]
- In `rpmhpd_aggregate_corner()` and `rpmpd_aggregate_corner()`, before `pd->state_synced` is set, the domain's active and sleep corners must be clamped to maximum (`pd->level_count - 1` or `pd->max_state - 1`). In `rpmhpd_aggregate_corner()`, when `peer && peer->enabled`, the peer corner passed to `to_active_sleep()` must be `max(peer->corner, peer->enable_corner)`, and after `rpmhpd_send_corner(pd, RPMH_ACTIVE_ONLY_STATE, active_corner, ...)` succeeds, both `pd->active_corner` and `pd->peer->active_corner` (if `pd->peer`) must be updated under `rpmhpd_lock`. [F44, F45, F47]
- In `drivers/pmdomain/qcom/rpmhpd.c`, `rpmhpd_set_performance_state()` must decrement `i` when the lookup loop over `pd->level_count` ends with `i == pd->level_count`, and when `pd->enabled` is true it must clamp `i` to at least `pd->enable_corner` before calling `rpmhpd_aggregate_corner()`. [F84]
- In `drivers/pmdomain/qcom/rpmhpd.c`, each SoC `*_rpmhpds[]` table that includes a paired active+sleep and active-only domain must use `struct rpmhpd` instances whose `.peer` pointers reference each other and whose `.parent` pointers reference `generic_pm_domain` instances present in that same `*_rpmhpds[]` table. Broken by: pairing `cx_w_mx_parent` with `cx_ao`, or `mmcx_w_cx_parent` alongside `cx_w_mx_parent`. [F46]
- In `drivers/pmdomain/qcom/rpmpd.c`, `rpmpd_set_performance()` must skip `rpmpd_aggregate_corner()` when `!pd->enabled` unless `pd->key` is `cpu_to_le32(KEY_FLOOR_CORNER)` or `cpu_to_le32(KEY_FLOOR_LEVEL)`. [F86]
- In `drivers/pmdomain/tegra/powergate-bpmp.c`, `max_id` from `tegra_bpmp_powergate_get_max_id()` is an inclusive bound requiring `max_id + 1` allocated entries and `id <= max_id` iteration, and powergate IDs must be resolved via `tegra_powergate_xlate()` rather than indexing `genpd->domains[id]` directly because unnamed holes are compacted out. [F70]
- In `drivers/pmdomain/xilinx/zynqmp-pm-domains.c`, `zynqmp_gpd_probe()` must allocate all `ZYNQMP_NUM_DOMAINS` `struct zynqmp_pm_domain` instances as a single contiguous array and assign `domains[i] = &pd->gpd` in index order because `zynqmp_gpd_xlate()` derives the array base from `to_zynqmp_pm_domain(genpd_data->domains[0])` and indexes `pd[i]`. [F92]
- In `drivers/pmdomain/sunxi/sun20i-ppu.c`, `sun20i_ppu_pd_set_power()` must poll `PD_STATUS_REG` until `!(status & PD_STATUS_BUSY)` before writing `PD_COMMAND_REG`, poll until `FIELD_GET(PD_STATUS_STATE, status) == state && (status & PD_STATUS_COMPLETE)`, and then write `status` back to `PD_STATUS_REG` to clear `PD_STATUS_COMPLETE`. [F88]

## Synchronization

- In `drivers/pmdomain/rockchip/pm-domains.c`, `dmc_pmu_mutex` always nests outside `struct rockchip_pmu::mutex` (code holding `pmu->mutex` must never acquire `dmc_pmu_mutex`). On a successful return (`0`), `rockchip_pmu_block()` leaves `dmc_pmu_mutex` held—and when `dmc_pmu` is non-NULL, also leaves `dmc_pmu->mutex` held and every non-NULL domain's `pd->clks` bulk-enabled—so callers must pair every successful `rockchip_pmu_block()` call with `rockchip_pmu_unblock()`. [F1, F125]
- In `rockchip_pm_domain_probe()`, `dmc_pmu_mutex` must be held across domain registration (`rockchip_pm_add_one_domain()`, `rockchip_pm_add_subdomain()`), `of_genpd_add_provider_onecell()`, and the publication of `dmc_pmu = pmu` (after all domains and the OF provider are initialized). [F24]
- In `rockchip_pmu_set_idle_request()`, `rockchip_pmu_domain_mem_reset()`, and `rockchip_do_pmu_set_power_domain()`, a write memory barrier `wmb()` must follow each PMU request or power `regmap_write()`/`regmap_update_bits()` before polling hardware ACK or status registers with `readx_poll_timeout_atomic()`. In `sunxi_pck600_pd_set_power()`, a readback `readl(pd->base + PPU_PWPR)` must follow `writel(reg, pd->base + PPU_PWPR)` before `readl_poll_timeout_atomic(pd->base + PPU_PWSR, ...)`. [F26, F27]
- In `drivers/pmdomain/qcom/rpmhpd.c` and `rpmpd.c`, `rpmhpd_lock` must be held across `rpmhpd_aggregate_corner()` and any read or update of runtime state (`enabled`, `corner`, `active_corner`, `state_synced`) on `struct rpmhpd` or its `pd->peer`, but `of_genpd_sync_state()` in `rpmhpd_sync_state()` and `rpmpd_sync_state()` must be called outside `rpmhpd_lock` and `rpmpd_lock` because it synchronously invokes `power_off` callbacks that acquire those same mutexes. [F19, F126]
- In `rpmhpd.c`, `rpmhpd_send_corner()` must use synchronous `rpmh_write()` when `sync` is true (`active_corner > pd->active_corner` in `rpmhpd_aggregate_corner()`, i.e., when increasing the active performance state), and `rpmh_write_async()` otherwise. [F109]

## Object Lifetimes

- In `rockchip/pm-domains.c`, `rockchip_pm_add_one_domain()` acquires `pd->clks` via `of_clk_get()` and prepares them once via `clk_bulk_prepare()`, so `rockchip_pd_power()` must hold `pmu->mutex` throughout and use `clk_bulk_enable()` (not `clk_bulk_prepare_enable()`), and `rockchip_pm_remove_one_domain()` must call `clk_bulk_unprepare()` and `clk_bulk_put()` on `pd->clks` and then zero `pd->num_clks` under `pd->pmu->mutex` so concurrent traversals do not touch released clock pointers. [F4, F25, F117]
- Because `tegra_bpmp_init_powergates()` frees `powergates` and every `powergates[i].name` before returning, `tegra_powergate_add()` must duplicate `info->name` via `kstrdup()` into `powergate->genpd.name`, and both `tegra_powergate_remove()` and the `pm_genpd_init()` failure path must `kfree(genpd->name)`. [F10]
- During driver teardown (such as in `airoha_cpu_pmdomain_remove()`), `of_genpd_del_provider()` must be called before `pm_genpd_remove()`, and if `of_genpd_add_provider_simple()` fails during probe (`airoha_cpu_pmdomain_probe()`), `pm_genpd_remove()` must be called to roll back `pm_genpd_init()`. [F12]
- In `zynqmp-pm-domains.c`, `zynqmp_gpd_attach_dev()` and `zynqmp_gpd_detach_dev()` must only request or release `pd->node_id` (and update `pd->requested`) when `domain->device_count == 0`, and `zynqmp_gpd_power_off()` must return `0` without calling `zynqmp_pm_set_requirement()` if `!pd->requested`. [F122]

## API Contracts

- All `GENPD_FLAG_*` configuration flags on `struct generic_pm_domain` (`genpd->flags`) must be set before calling `pm_genpd_init()`, which consumes `genpd->flags` to initialize lock operations, `stay_on`, PM clock callbacks, CPU masks, and IDA IDs. When `GENPD_FLAG_IRQ_SAFE` is set on a domain, every parent domain linked via `pm_genpd_add_subdomain()` must also set `GENPD_FLAG_IRQ_SAFE`. [F13, F133]
- Every `genpd_xlate_t` implementation (such as `tegra_powergate_xlate` and `zynqmp_gpd_xlate`) must return an `ERR_PTR(...)`—never `NULL`—when domain lookup fails, because the genpd core checks `!IS_ERR(genpd)` and dereferences a returned `NULL` pointer. [F28]
- When a genpd OF provider `platform_driver` defines a custom `.driver.sync_state` callback (`rpmhpd_sync_state` or `rpmpd_sync_state`), that callback must invoke `of_genpd_sync_state(dev->of_node)` because `of_genpd_add_provider_onecell()` does not override an existing driver `sync_state` pointer. [F141]
- Because `rockchip_pm_add_one_domain()` sets `GENPD_FLAG_PM_CLK` on every `pd->genpd`, `rockchip_pd_attach_dev()` must initialize the attached device's PM clock list via `pm_clk_create(dev)` and `pm_clk_add_clk()` (cleaning up with `clk_put()` and `pm_clk_destroy(dev)` on error), and `rockchip_pd_detach_dev()` must call `pm_clk_destroy(dev)`. [F143]
- In `mtk-pm-domains.h` and `scpsys_add_one_domain()`, a `scpsys_domain_data` entry must not set both `MTK_SCPD_KEEP_DEFAULT_OFF` and `MTK_SCPD_ALWAYS_ON` in `caps`, because `GENPD_FLAG_ALWAYS_ON` requires the domain to be powered on and initialized with `is_off = false` in `pm_genpd_init()`. [F137]
- In `mtk-scpsys.c`, `init_scp()` must convert `-ENODEV` from `devm_regulator_get_optional()` into `scpd->supply = NULL` while propagating other `ERR_PTR` values (such as `-EPROBE_DEFER`), because `scpsys_regulator_enable()` and `scpsys_regulator_disable()` treat only `NULL` as an absent optional supply. [F139]
- In `include/linux/pm_domain.h`, any change to declarations or return conventions under `#ifdef CONFIG_PM_GENERIC_DOMAINS`, `CONFIG_PM_GENERIC_DOMAINS_SLEEP`, `CONFIG_PM_GENERIC_DOMAINS_OF`, or `CONFIG_PM` must update the `#else` stub in lockstep. When disabled, `dev_gpd_data()` and `dev_to_genpd_dev()` return `ERR_PTR`, `genpd_dev_pm_attach_by_id()`/`by_name()` and `dev_pm_domain_attach_by_id()`/`by_name()` return `NULL`, and `simple_qos_governor`/`pm_domain_always_on_gov` expand to `(*(struct dev_power_governor *)(NULL))` (only take their address `&`, never read by value). [F61, F134, F135]

## Error Handling

- When `clk_bulk_enable()` fails at domain index `i` inside `rockchip_pmu_block()`, the error path must disable clocks for indices `i - 1` down to `0` and unlock `pmu->mutex` and `dmc_pmu_mutex` in reverse acquisition order. In `rockchip_pd_power()`, once `clk_bulk_enable()` and `rockchip_pmu_ungate_clk(pd, true)` have been called, every exit path must pass through `out:` to re-gate and disable clocks. [F2, F6]
- In `rockchip_pd_regulator_enable()` and `rockchip_pd_regulator_disable()`, `pd->supply` must be tested with `IS_ERR_OR_NULL(pd->supply)` rather than `!pd->supply`, because `rockchip_pd_regulator_enable()` lazily assigns `devm_of_regulator_get()` directly to `pd->supply` and leaves an `ERR_PTR` stored there on failure. [F33]
- During probe rollback in `scpsys_remove_one_domain()` and `rockchip_pm_remove_one_domain()`, a failure from `pm_genpd_remove()` must only be logged with `dev_err()` and must not abort the remaining per-domain clock/power teardown or overwrite the original probe error. [F140]
- In `scpsys_probe()` (`mtk-pm-domains.c`) and `rockchip_pm_domain_probe()` (`rockchip/pm-domains.c`), `ret`/`error` must be initialized to `-ENODEV` immediately before `for_each_available_child_of_node*` so that a controller DT node with no available child domain nodes fails with `-ENODEV` instead of registering an empty provider. Broken by: inserting a fallible call that sets `ret = 0` or `error = 0` before the loop. [F37]
- In `drivers/pmdomain/mediatek/mtk-scpsys.c`, `scpsys_domain_is_on()` returns `true` (`1`) when both status bits are set, `false` (`0`) when both are clear, and `-EINVAL` when only one is set; callers must store the result in a signed `int` and poll for `tmp > 0` on power-on and `tmp == 0` on power-off. Broken by: storing in `bool` or polling `tmp != 0`. [F29]
- Every Tegra BPMP powergate MRQ helper (`tegra_bpmp_powergate_set_state`, `tegra_bpmp_powergate_get_state`, `tegra_bpmp_powergate_get_max_id`, `tegra_bpmp_powergate_get_name`) must zero-initialize its `request`, `response`, and `msg` structs and check both `tegra_bpmp_transfer() < 0` and `msg.rx.ret < 0`. [F30]

## External Contracts

- In `drivers/pmdomain/qcom/rpmpd.c`, `struct rpmpd_req` payloads sent via `qcom_rpm_smd_write()` must encode `nbytes` and `value` with `cpu_to_le32()` and use little-endian ASCII fourcc values for `key` and `res_type`, and any comparison against `pd->key` must use `cpu_to_le32()`. [F68]

## Known Pitfalls

- In `struct rockchip_pm_domain`, `num_clks` and `num_qos` are populated from `of_clk_get_parent_count()` and `of_count_phandle_with_args()`, which return negative errnos when the DT property is absent; `num_clks` must be clamped to `0` before `clk_bulk_*()` calls, and `num_qos` and its loop counters in `rockchip_pmu_save_qos()`/`rockchip_pmu_restore_qos()` must remain signed `int`. [F32]
- In `drivers/pmdomain/mediatek/mtk-pm-domains.c`, `scpsys_bus_protect_clear()` must poll `(val & sta_mask) == sta_mask` when `bpd->bus_prot_sta_block == BUS_PROT_BLOCK_INFRA_NAO` and `(val & sta_mask) == 0` for all other bus protection blocks. [F76]
- In `drivers/pmdomain/mediatek/mtk-pm-domains.c`, `scpsys_add_one_domain()` counts `clock-names` without `'-'` into `pd->num_clks` and those with `'-'` into `pd->num_subsys_clks`, then fetches indices `0 .. pd->num_clks - 1` into `pd->clks` and `clk_ind .. clk_ind + pd->num_subsys_clks - 1` into `pd->subsys_clks`. Broken by: ordering a non-hyphenated clock after a hyphenated subsystem clock in DT, or resetting `clk_ind` before the `pd->num_subsys_clks` loop. [F80]
