# SCTP PROTOCOL

This unit (`net/sctp/protocol.c`, `proc.c`, `primitive.c`, `outqueue.c`, `sm_make_chunk.c`, `sm_sideeffect.c`) implements core SCTP protocol infrastructure, including module/per-netns setup, IPv4 protocol glue and UDP encapsulation, `/proc/net/sctp` dumps, ULP primitives, outbound chunk queueing/SACK/retransmission, chunk/cookie/ASCONF/RECONF construction and parameter parsing, and the state-machine command interpreter and timer handlers.

## Architecture & Data Flow
- Data chunks on `q->out_chunk_list` must also be linked via `ch->stream_list` into `SCTP_SO(&q->asoc->stream, stream)->ext->outq` and accounted in `q->out_qlen` (`sctp_outq_head_data()`/`sctp_outq_tail_data()`/`sctp_sched_dequeue_common()`). Moving an unacked (`!chunk->tsn_gap_acked`) chunk from `transport->transmitted` to `q->retransmit` or `q->abandoned` in `sctp_retransmit_mark()` must subtract `sctp_data_size(chunk)` from `transport->flight_size` and `q->outstanding_bytes`, add it to `q->asoc->peer.rwnd`, and if `chunk->rtt_in_progress` is set, zero `rtt_in_progress` and `transport->rto_pending`. [F61, F62, F63]
- In `sctp_check_transmitted()`, each entry dequeued from `transmitted_queue` via `sctp_list_dequeue()` must be re-linked into `q->abandoned`, `q->sacked`, or local `tlist` (spliced back after the loop), and newly-acked checks (`!tchunk->tsn_gap_acked`, e.g., `sctp_transport_update_rto()` and `transport->cacc.cacc_saw_newack = 1`) must run before `tchunk->tsn_gap_acked = 1`. [F60, F94]
- Host-order 32-bit TSNs must be compared with `TSN_lt()`/`TSN_lte()`: `sctp_insert_list()` orders `q->retransmit` and `q->abandoned` via `TSN_lt(ntsn, ltsn)`; `sctp_outq_sack()`, `sctp_check_transmitted()`, and `sctp_do_ecn_ecne_work()` use `TSN_lt()`/`TSN_lte()` for watermarks, `next_tsn_at_change`, and `last_cwr_tsn`; and `sctp_generate_fwdtsn()` only advances `adv_peer_ack_point` while `TSN_lte(tsn, asoc->adv_peer_ack_point + 1)`, deduplicating ordered streams via `sctp_get_skip_pos()` and stopping at `nskips == 10` or a TSN gap. [F99, F100, F102, F103]
- In `sctp_outq_flush_ctrl()`, every chunk type on `q->control_chunk_list` needs an explicit `switch` case (`default:` calls `BUG()`, and `SCTP_CID_ABORT`/response chunks fall through to set `one_packet = 1`). Every transmitted control chunk (bundled or via `sctp_packet_singleton()`) must increment `ctx->asoc->stats.octrlchunks`, and transmitting `SCTP_CID_FWD_TSN`/`SCTP_CID_I_FWD_TSN` must call `sctp_transport_reset_t3_rtx(ctx->transport)` and set `ctx->transport->last_time_sent = jiffies`. [F54, F65, F92]
- In `__sctp_outq_flush_rtx()`, if `sctp_packet_append_chunk()` returns `SCTP_XMIT_PMTU_FULL` when `!pkt->has_data && !pkt->has_cookie_echo`, transmit `pkt` and `goto redo` before checking `rtx_timeout || fast_rtx`. When flushing for `rtx_timeout` or `fast_rtx`, reset `q->fast_rtx = 0` and transition all `SCTP_NEED_FRTX` chunks (both sent and left in `q->retransmit`) to `SCTP_DONT_FRTX`. [F64, F93]
- `sctp4_rcv()` and `sctp_udp_rcv()` must never overwrite `SCTP_INPUT_CB(skb)->header`; `sctp_udp_rcv()` sets `SCTP_INPUT_CB(skb)->encap_port = udp_hdr(skb)->source` and pulls `sizeof(struct udphdr)` before `sctp_rcv()`, while `sctp4_rcv()` zeroes `encap_port`. [F55, F142]
- In `sctp_make_init_ack()` and `sctp_make_cookie_ack()`, look up `retval->transport` on `asoc` via `sctp_assoc_lookup_paddr(asoc, &chunk->transport->ipaddr)` instead of copying `chunk->transport`. In `sctp_process_init()`, call `sctp_assoc_update_frag_point(asoc)` after `sctp_stream_init()` sets `asoc->stream.si`. [F58, F59]
- `sctp_verify_asconf()` must verify a single IPv4/IPv6 address parameter at `addip + 1` (none in ASCONF-ACK), check parameter lengths, and confirm `param.v == chunk->chunk_end`. In `sctp_process_asconf()` and `sctp_process_asconf_ack()`, `all_param_pass` and `no_err` latch to false on the first failed TLV; when `SCTP_PARAM_ADD_IP`/`SCTP_PARAM_DEL_IP` updates `asoc->base.bind_addr` in `sctp_asconf_param_success()`, call `sctp_transport_dst_release()` on all transports in `asoc->peer.transport_addr_list`. [F67, F74, F95]
- In `sctp_copy_local_addr_list()`, copy `AF_INET` entries from `net->sctp.local_addr_list` (`sin_port == 0`) only when `copy_flags` has both `SCTP_ADDR4_ALLOWED` and `SCTP_ADDR4_PEERSUPP`, setting `laddr` `sin_port = htons(bp->port)` before `sctp_bind_addr_state(bp, &laddr)`. [F51, F87]
- In `sctp_do_8_2_transport_strike()` and `sctp_cmd_t1_timer_update()`, compare `transport->error_count` against `transport->pf_retrans`, `transport->pathmaxrxt`, and `transport->ps_retrans` (not `asoc` fields), and clamp doubled `transport->rto` and `asoc->timeouts[timer]` to `transport->asoc->rto_max` and `asoc->max_init_timeo`. [F88, F108]
- In `sctp_pack_cookie()` and `sctp_unpack_cookie()`, compute `hmac_sha256()` over `bodysize` bytes at `cookie->c` (`headersize` uses `sctp_paramhdr` in pack, `sctp_chunkhdr` in unpack, plus `sizeof(sctp_signed_cookie) - sizeof(sctp_cookie)`), use `ktime_get_real()` for `cookie->c.expiration`, and verify `cookie->mac` with `crypto_memneq()`. [F52, F113, F151]
- In `sctp_make_sack()`, if `++asoc->peer.sack_generation` wraps to `0`, zero `trans->sack_generation` across `transport_addr_list` and set `asoc->peer.sack_generation = 1`. Check `epb->type == SCTP_EP_TYPE_ASSOCIATION` before calling `sctp_assoc(epb)` (e.g., `sctp_seq_dump_local_addrs()`), and keep `SCTP_MIB_*` in `include/net/sctp/sctp.h` in lockstep with `sctp_snmp_list` in `net/sctp/proc.c`. [F70, F98, F119]

## Synchronization
- Unlocked readers of `bind_addr.address_list` (`sctp_seq_dump_local_addrs()`, `sctp_v4_get_dst()`) must use `list_for_each_entry_rcu()` under `rcu_read_lock()` (also covering `__ip_dev_find(..., false)` in `sctp_v4_get_dst()`) and check `laddr->valid`; socket-locked writers in `sctp_asconf_param_success()` must wrap updates and `sctp_del_bind_addr()` in `local_bh_disable()`/`local_bh_enable()`. [F29, F128]
- In `sctp_outq_flush_transports()` (under the socket lock), comparing `__sk_dst_get(sk)` against non-NULL `t->dst` and calling `dst_hold(t->dst)` and `sk_setup_caps(sk, t->dst)` before `sctp_packet_transmit()` must happen under `rcu_read_lock()` so `sk_route_caps` matches `t->dst` without pinning a dst on `net->sctp.ctl_sock`. [F35, F140]
- Acquire `net->sctp.addr_wq_lock` with `spin_lock_bh()` (including before `sctp_addr_wq_lookup()`), nesting inside `net->sctp.local_addr_lock` (`sctp_addr_wq_mgmt()`) and outside `bh_lock_sock(sk)` (`sctp_addr_wq_timeout_handler()`). [F126]
- Under `rcu_read_lock()`, `sctp_v4_copy_ip_options()` and `sctp_v4_ip_options_len()` must read `inet->inet_opt` via `rcu_dereference()`, and `sctp_v4_copy_ip_options()`, `sctp_copy_local_addr_list()`, and `sctp_v4_copy_addrlist()` must allocate with `GFP_ATOMIC` (even if passed `gfp`). Lockless reads of `sk->sk_wmem_queued`, `sysctl_ip_nonlocal_bind`, and `inet_sk(sk)->tos` must use `READ_ONCE()`. [F37, F125, F127]

## Object Lifetimes
- Before `sctp_chunk_put()` or `sctp_chunk_free()` can drop `refcnt` to 0, unlink `chunk->list` with `list_del_init(&chunk->list)` (`sctp_chunk_destroy()` has `BUG_ON(!list_empty(&chunk->list))`). In `sctp_outq_flush_ctrl()`, `sctp_packet_singleton()` consumes `chunk`, whereas if `sctp_packet_transmit_chunk()` returns `!= SCTP_XMIT_OK`, re-add `chunk` to `ctx->q->control_chunk_list`. [F10, F11]
- After `sctp_outq_dequeue_data(q)`, callers must either call `sctp_sched_dequeue_done(q, chunk)` or push it back via `sctp_outq_head_data(q, chunk)`. `sctp_prsctp_prune_unsent()` must wrap its prune loop in `q->sched->unsched_all()` / `sched_all()`, clearing `asoc->stream.out_curr = NULL` if its last fragment is freed. [F9, F21]
- `sctp_control_set_owner_w()` (when `chunk->auth` is set) holds `chunk->shkey` via `sctp_auth_shkey_hold()` and sets `skb->destructor = sctp_control_release_owner`; do not overwrite `skb->destructor` on control chunks. [F12]
- In `sctp_v4_get_dst()`, check `!IS_ERR(rt)` after `ip_route_output_key()`, release any superseded `dst` or rejected `&rt->dst` via `dst_release()`, and set `t->dst = NULL` if no route remains. `sctp_v4_xmit()` consumes `skb` and must pass `dst_clone(t->dst)` to `skb_dst_set()` or `udp_tunnel_xmit_skb(dst_rtable(dst), ...)`. [F6, F18, F42]
- `sctp_process_asconf_ack()` must unlink `asconf->transmitted_list`, call `sctp_chunk_free(asconf)`, and clear `asoc->addip_last_asconf = NULL` (and `kfree` + NULL `asoc->asconf_addr_del_pending` on `SCTP_PARAM_DEL_IP`). Free existing `asoc->peer.{cookie,peer_random,peer_hmacs,peer_chunks}` with `kfree()` before overwriting in `sctp_process_param()`, and set `asoc->peer.cookie = NULL` when freeing it in `sctp_cmd_new_state()`. [F14, F15]
- In `sctp_cmd_interpreter()`: if `local_cork` is set, call `sctp_outq_uncork(&asoc->outqueue, gfp)` and reset `local_cork = 0` before replacing/clearing `asoc` (`NEW_ASOC`, `DELETE_TCB`, `SET_ASOC`) and on exit; restore `asoc->peer.retran_path = t` after `SCTP_CMD_FORCE_PRIM_RETRAN`; and keep `SCTP_CMD_PROCESS_CTSN`'s dummy `struct sctp_sackhdr sackh` (with `num_gap_ack_blocks = 0`) in outer function scope. [F22, F23, F117]
- Pending `asoc->timers[]`, `hb_timer`, and `T3_rtx_timer` timers own a reference to their `asoc` or `sctp_transport`: hold the object when arming a non-pending timer and put it iff `timer_delete()` returns true. In `sctp_exit()`, call `rcu_barrier()` before `kmem_cache_destroy()` on `sctp_chunk_cachep` and `sctp_bucket_cachep`. [F20, F131]

## API Contracts
- `sctp_outq_tail()` takes ownership of `chunk` without `sctp_chunk_hold()`, so callers of `sctp_primitive_SEND()` must call `sctp_datamsg_free(msg)` (not `sctp_datamsg_put()`) if it fails before `SCTP_CMD_SEND_MSG` runs. [F8]
- In `_sctp_make_chunk()`, `SCTP_PAD4(sizeof(*chunk_hdr) + paylen)` must not exceed `SCTP_MAX_CHUNK_LEN`. Because `sctp_addto_chunk()` 4-byte-aligns the prior chunk length on every call, `paylen` for multiple `sctp_addto_chunk()` calls must sum `SCTP_PAD4()` of each segment, whereas continuing an unaligned TLV parameter or error cause must use `sctp_addto_param()`. [F106, F109, F110]
- Check `sctp_init_cause() == 0` before `sctp_addto_chunk()` on bounded error chunks (`sctp_make_op_error_limited()`). Before `sctp_make_strreset_req()`, validate that `sizeof(outreq/inreq) + stream_num * sizeof(__u16)` fits in `SCTP_MAX_CHUNK_LEN - sizeof(struct sctp_reconf_chunk)` and pass `__be16` `stream_list`. Pass the composite chunk header pointer (e.g., `struct sctp_init_chunk *`, not `sctp_chunkhdr *` or `sctp_chunk *`) to `sctp_walk_params(pos, chunk)`. [F73, F77, F114]
- `sctp_user_addto_chunk()` and `sctp_make_abort_user()` (`paylen > 0`) sleep (`GFP_KERNEL`, user copy), while `sctp_pack_cookie()` and state-machine chunk builders in `sm_make_chunk.c` must use `GFP_ATOMIC`. In `sctp_process_asconf_param()`, `SCTP_PARAM_ADD_IP` and `SCTP_PARAM_SET_PRIMARY` must resolve wildcard `addr` to `asconf->source` before `security_sctp_bind_connect()`. [F135, F149]
- In `net/sctp/protocol.c`, `sctp_v4_available()` and `sctp_v4_get_dst()` must scope lookups to `sk->sk_bound_dev_if` and `l3mdev_fib_table_by_index()`; when UDP encapsulation is active, `sctp_v4_xmit()` must set `SKB_GSO_UDP_TUNNEL_CSUM` on GSO skbs, `skb->encapsulation = 1`, and reset inner headers/`ipproto = IPPROTO_SCTP`. [F141, F143]

## Error Handling
- In `sctp_cmd_interpreter()`, `SCTP_CMD_GEN_COOKIE_ECHO` must free `cmd->obj.chunk` via `sctp_chunk_free()` if `sctp_make_cookie_echo()` fails, or pass it to `SCTP_CMD_REPLY`; on any non-zero `error`, drain `commands` via `sctp_next_cmd()` and `sctp_chunk_free(cmd->obj.chunk)` on all queued `SCTP_CMD_REPLY`s. Transmit errors in `sctp_outq_tail()`/`sctp_outq_flush()` are recorded in `sk->sk_err = -error` and not returned by `sctp_cmd_send_msg()` or `sctp_cmd_interpreter()`. [F5, F40, F96]
- `sctp_verify_param()` and `sctp_process_unk_param()` return positive `enum sctp_ierror`, while `sctp_verify_init()`, `sctp_process_init()`, and `sctp_process_param()` return 1 on success and 0 on failure. Before assigning a fatal chunk to `*errp` in `sctp_verify_init()` helpers, free any existing `*errp` via `sctp_chunk_free(*errp)`; if `sctp_process_init()` fails (`goto clean_up`), remove all non-`SCTP_ACTIVE` transports via `sctp_assoc_rm_peer()`. [F16, F17, F39]
- OOTB-reachable chunk helpers (`_sctp_make_chunk()`, `sctp_control_set_owner_w()`, `sctp_make_op_error_limited()`, `sctp_make_abort()`, `sctp_make_shutdown_complete()`) must NULL-check `asoc`, and wire parameter handlers must NULL-check `sctp_get_af_specific(param_type2af(...))`. Use `SCTP_DISPOSITION_VIOLATION` or `SCTP_DISPOSITION_DISCARD` (never `SCTP_DISPOSITION_BUG`) for peer protocol violations. [F41, F46, F150]

## External Contracts
- Zero all padding and `sin_zero` bytes in wire structures (`sctp_pack_cookie()`, `sctp_make_heartbeat()`) and `struct sockaddr_in` instances (`sctp_v4_from_addr_param()`, `sctp_v4_addr_to_user()`, `sctp_inet_msgname()`). In `/proc/net/sctp/{assocs,remaddr}`, `sctp_transport_seq_*` and `*_seq_show` hold RCU across `show` (covering `sctp_seq_dump_remote_addrs()`), must check `v != SEQ_START_TOKEN` before casting or calling `sctp_transport_put(v)`, and must preserve the fixed column layout. [F44, F85, F86, F122, F123]

## Known Pitfalls
- In `sctp_v4_get_dst()`, populate a local scratch `struct flowi _fl` and `memcpy(fl, &_fl, sizeof(_fl))` only when storing `rt->dst` into `t->dst`, and when `saddr` is non-NULL, set `fl4->fl4_sport = saddr->v4.sin_port` only if `!fl4->fl4_sport`. [F56, F57]
- SACK Gap Ack `start`/`end` are 16-bit offsets from `cum_tsn_ack` for `[cum_tsn_ack + start, cum_tsn_ack + end]`; check `TSN_lte(tsn, ctsn)` in `sctp_acked()` before subtracting `tsn - ctsn`. In `sctp_outq_sack()`, clamp `asoc->peer.rwnd = sack_a_rwnd - q->outstanding_bytes` to 0 when `outstanding >= sack_a_rwnd`, and set `sackh.a_rwnd = htonl(asoc->peer.rwnd + asoc->outqueue.outstanding_bytes)` with `__be32` `cum_tsn_ack` on synthetic `sctp_sackhdr`s. [F79, F83, F101, F107]
- `sctp_walk_params()` stops early on malformed parameters and only checks `>= sizeof(struct sctp_paramhdr)`, so verifiers must check `param.v == chunk->chunk_end` and subtype minimum lengths; disabled optional extensions in `sctp_verify_param()` must `goto unhandled`. `SCTP_PARAM_*` and `SCTP_ERROR_*` are already `__be16` (do not `htons()`/`ntohs()`), and ADD-IP handlers must pass the inner `addr_param->p.type` (at `+ sizeof(struct sctp_addip_param)`) to `param_type2af()`. [F75, F80, F89, F90]
- Inbound `chunk->skb->data` (`sctp_process_asconf()`, `sctp_get_asconf_response()`) starts at `struct sctp_addiphdr`, whereas cached outbound `asoc->addip_last_asconf->skb->data` starts at `struct sctp_addip_chunk`. Capture `err_hdr` from `chunk->skb->data` before `sctp_ulpevent_make_remote_error()` pulls `chunk->skb`, and advance `addrs` in `sctp_make_asconf_update_ip()` by `af->sockaddr_len` rather than `sizeof(*addrs)`. [F111, F115, F116]
- In `sctp_cmd_interpreter()`, match the `cmd->obj` union member width to the `SCTP_*` constructor (`u16` for `SCTP_PERR()`/`SCTP_U16()`, `u8` for `SCTP_U8()`), and only dereference `chunk` (`event_arg`) when `event_type == SCTP_EVENT_T_CHUNK` or after `SCTP_CMD_INIT_CHOOSE_TRANSPORT`. [F78, F118]
