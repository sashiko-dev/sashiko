# BLOCK LAYER

The Linux block layer manages `block_device` (`bdev`) lifecycles and claims, `bio` allocation, splitting, cloning, and submission, multiqueue (`blk-mq`) request scheduling, tag management, DMA/scatterlist mapping, queue limits, inline encryption (`blk-crypto`), data integrity (`blk-integrity`), zoned write plugging, QoS/writeback throttling (`blk-wbt`), cgroup accounting, TCG Opal (`sed-opal`), and virtual/platform block drivers.

## Architecture & Data Flow
- `__bio_advance()` must advance integrity (`bio_integrity_advance()`) and inline encryption DUN (`bio_crypt_advance()`) alongside `bio->bi_iter`; shrinking `bi_iter.bi_size` in `bio_split()`/`bio_trim()` must call `bio_integrity_trim()` after updating `bi_size`; and `bio_integrity_init()`/`free()`/`finish()` must toggle `REQ_INTEGRITY` on `bio->bi_opf` in lockstep with `bio->bi_integrity`. [F69, F70, F71]
- `bio_truncate()` must only reduce `bio->bi_iter.bi_size` without modifying `bi_io_vec` or `bi_vcnt` so `bio_for_each_segment_all()` releases all attached pages; in `__bio_release_pages()`, folio `nr_pages` must be `(fi.offset + fi.length - 1) / PAGE_SIZE - fi.offset / PAGE_SIZE + 1`. [F98, F141]
- In `__submit_bio_noacct()`, move `bio_list_on_stack[0]` to `[1]` before `__submit_bio()`, partition queued bios into `lower` and `same` queue lists, and merge `lower`, `same`, then `[1]`; in `submit_bio_noacct_nocheck()`, when `current->bio_list` is active and `split` is true, queue the remainder at the head via `bio_list_add_head()`. [F119, F197]
- `bio_crypt_ctx.bc_dun` is a little-endian array of `u64` limbs: `bio_crypt_dun_increment()` and `bio_crypt_dun_is_contiguous()` must propagate carry across all limbs (rejecting merges if final `carry != 0`), and `blk_crypto_dun_to_iv()` must convert limbs via `cpu_to_le64()`. Front-merge must update `req->crypt_ctx->bc_dun` via `bio_crypt_do_front_merge()`, while back-merge/append calls `bio_crypt_free_ctx(bio)`. [F60, F74, F107, F142]
- Flush requests entering `blk_insert_flush()` must have a single bio (`rq->bio == rq->biotail`) so `blk_flush_restore_request()` can restore `rq->bio`, `rq->__sector`, and `rq->end_io`. `rq->flush.seq` must only set bits from `REQ_FSEQ_ACTIONS` (pre-setting `REQ_FSEQ_PREFLUSH` for `REQ_FSEQ_DATA | REQ_FSEQ_POSTFLUSH`). In `flush_end_io()`, toggle `fq->flush_running_idx ^= 1` before `list_for_each_entry_safe()` unlinks each `rq->queuelist`. [F77, F79, F121, F122, F137]
- `blk_update_request()` partial completions must update `req->__data_len`, `req->__sector`, `REQ_FAILFAST_MASK` (when `RQF_MIXED_MERGE`), and `req->nr_phys_segments` (unless `RQF_SPECIAL_PAYLOAD`). `blk_rq_prep_clone()` must copy `nr_phys_segments`, `nr_integrity_segments`, and `RQF_SPECIAL_PAYLOAD`. `__blk_mq_requeue_request()` on a started request must reset `rq->state = MQ_RQ_IDLE` and clear `RQF_TIMED_OUT`; `blk_mq_finish_request()` must clear `RQF_USE_SCHED` after `ops.finish_request(rq)`. [F277, F294, F295, F296, F297]
- In `struct blk_mq_tags`, `rqs[]` and `static_rqs[]` map `[0, nr_reserved_tags)` to `breserved_tags` and `[nr_reserved_tags, nr_tags)` to `bitmap_tags` (offset `bitmap_tags` indices by `nr_reserved_tags`). `hctx->ctxs[]` and `hctx->ctx_map` are indexed by `ctx->index_hw[hctx->type]`, not `ctx->cpu`, and unmapped hctxs (`!blk_mq_hw_queue_mapped(hctx)`) have `hctx->tags == NULL`. [F275, F315, F316]
- `disk_zone_wplug_add_bio()` takes an extra `q->q_usage_counter` ref that must be consumed by new request allocation in `blk_mq_submit_bio()` or dropped via `blk_queue_exit(q)` on merge, abort, cached-rq reuse, or bio-based submit. Emulated `REQ_OP_ZONE_APPEND` sets `BIO_EMULATES_ZONE_APPEND` with `REQ_OP_WRITE | REQ_NOMERGE` and restores `REQ_OP_ZONE_APPEND` in `blk_zone_write_plug_bio_endio()`. [F299, F300, F301]
- `blk_validate_limits()` recomputes derived limits and clears `BLK_FEAT_FUA` if `!BLK_FEAT_WRITE_CACHE`; `blk_validate_atomic_write_limits()` must zero all derived `atomic_write_*` fields on any invalid limit; `blk_apply_bdi_limits()` must never shrink `bdi->ra_pages`; `blk_set_queue_depth()` must call `rq_qos_queue_depth_changed(q)`; and `rq_qos_del()`/`rq_qos_exit()` must clear `QUEUE_FLAG_QOS_ENABLED` when `q->rq_qos` is empty. [F220, F303, F305, F306, F307, F383]

## Synchronization
- `q->queue_lock` nests outside `ioc->lock`, so `put_io_context()` must defer non-empty `ioc->icq_list` teardown to `ioc_release_fn()`. Never call `blk_mq_freeze_queue()` or `elevator_set_none()` while `QUEUE_FLAG_QUIESCED` is set (`blk_mq_freeze_queue()` must precede `blk_mq_quiesce_queue()`), and while frozen never acquire `fs_reclaim` or `cpu_hotplug_lock` (`static_branch_inc()`/`dec()`). [F15, F192, F390]
- `fq->mq_flush_lock` nests outside `q->requeue_lock` with IRQs disabled; in `blk_kick_flush()`, set `flush_rq->end_io` before `smp_wmb()` and `req_ref_set(flush_rq, 1)`. `_badblocks_set()`, `_badblocks_clear()`, and `ack_all_badblocks()` must use `write_seqlock_irq*(&bb->lock)` because `badblocks_check()` runs in IRQ context. [F25, F34, F188]
- `profile->lock` nests outside `profile->idle_slots_lock` (IRQs disabled on `idle_slots_lock`). `blk_crypto_hw_enter()` must call `pm_runtime_get_sync()` before `down_write(&profile->lock)`, whereas `blk_crypto_reprogram_all_keys()` must not call `pm_runtime_get_sync()`. In `blk_crypto_get_keyslot()`, recheck `blk_crypto_find_and_grab_keyslot()` and `!list_empty(&profile->idle_slots)` after each `blk_crypto_hw_enter()`, and call `blk_crypto_hw_exit()` before `wait_event()`. [F33, F92, F162, F181]
- `blk_queue_enter()` and `__bio_queue_enter()` must execute `smp_rmb()` after a failed `blk_try_enter_queue()` before `wait_event(q->mq_freeze_wq, ...)`. Because `bio` slabs use `SLAB_TYPESAFE_BY_RCU`, `iocb_bio_iopoll()` must hold `rcu_read_lock()` around `bio_poll()`, which must use `READ_ONCE()` on `bi_cookie`/`bi_bdev` and `percpu_ref_tryget(&q->q_usage_counter)`. [F41, F42]
- Request dispatch must run inside `__blk_mq_run_dispatch_ops()` (`srcu_read_lock` if `BLK_MQ_F_BLOCKING`, else `rcu_read_lock`). In `blk_mq_run_hw_queue()`, a false lockless `blk_mq_hw_queue_need_run()` must be rechecked under `q->queue_lock`. `blk_mq_hctx_stopped()` requires `smp_mb()` before retesting `BLK_MQ_S_STOPPED`, and `blk_mq_dispatch_rq_list()` requires `smp_mb()` after splicing to `hctx->dispatch` before `blk_mq_sched_needs_restart()`. [F250, F251, F263, F264]
- In `blk_mq_mark_tag_wait()`, acquire `wq->lock` before `hctx->dispatch_wait_lock` and run `smp_mb()` between `__add_wait_queue()` and `blk_mq_get_driver_tag()`. In `blk_mq_get_tag()`, reload `data->ctx`/`hctx`/`tags`/`bt` after `io_schedule()` (waking `bt_prev` if changed) and release the tag if `BLK_MQ_S_INACTIVE` is set. In `bt_iter()`/`bt_tags_iter()`, `blk_mq_find_and_get_req()` must verify `rq->tag == bitnr`, `req_ref_inc_not_zero(rq)`, and `rq->q == q`. [F258, F260, F262]
- `blk_mq_timeout_work()` must use `percpu_ref_tryget(&q->q_usage_counter)` (never `blk_queue_enter()`), call `blk_mq_wait_quiesce_done(q->tag_set)` after `blk_mq_check_expired()`, and reset `expired.next = 0` before `blk_mq_handle_expired()`. [F254, F338]
- In `rq_qos_wake_function()`, `list_del_init_careful(&curr->entry)` must be the final operation after `data->got_token = true` and `default_wake_function()`; in `rq_qos_wait()`, if the first waiter gets a token via `acquire_inflight_cb()`, it must check `data.got_token` after `finish_wait()` and call `cleanup_cb()` if both succeeded. [F221, F366]
- `queue_limits_start_update(q)` acquires `q->limits_lock`, and `queue_limits_commit_update*()` always unlocks it on both success and failure (requiring a frozen queue on live queues); call `queue_limits_cancel_update(q)` only when aborting before commit. `bdev_freeze()`, `bdev_thaw()`, and `bdev_mark_dead()` acquire `bdev->bd_holder_lock`, which the `bd_holder_ops` callback must release before returning. [F190, F225, F405]
- `bio_integrity_unmap_user()` runs in `bi_end_io` (possibly IRQ context when `!BIP_COPY_USER`), so `bio_integrity_unpin_bvec()` must only call `unpin_user_page()` and never `set_page_dirty_lock()`. Direct-I/O reads must call `bio_set_pages_dirty()` before submit and `bio_check_pages_dirty()` on completion (which consumes `@bio`, overwrites `bi_private`, and calls `bio_release_pages()` + `bio_put()`). [F10, F170, F171]

## Object Lifetimes
- In `bdev_file_open_by_dev()`, after `alloc_file_pseudo_noaccount()`, take `ihold(BD_INODE(bdev))` and on `bdev_open()` failure set `bdev_file->private_data = ERR_PTR(ret)` before `fput(bdev_file)` so `bdev_release()` only calls `blkdev_put_no_open()`. In `bdev_fput()`, set `bdev_file->private_data = BDEV_I(bdev_file->f_mapping->host)` (never `NULL`) under `disk->open_mutex` so `bdev_unclaimed()` prevents double yield. Every successful `bd_prepare_to_claim()` must pair with `bd_finish_claiming()` or `bd_abort_claiming()`. [F3, F4, F5, F149]
- Caller-allocated bios initialized with `bio_init()`/`bio_init_inline()` (on-stack or `bio_kmalloc()`) and failed `__bio_clone()` targets must call `bio_uninit()` before freeing, as `bio_put()` requires `bio->bi_pool != NULL`. `bio_reset()` calls `bio_uninit()` and zeroes only `BIO_RESET_BYTES` (`offsetof(struct bio, bi_max_vecs)`). `bioset_exit()` must call `bio_alloc_cache_destroy(bs)` and `destroy_workqueue(bs->rescue_workqueue)` before exiting `bio_pool`, `bvec_pool`, and `bio_slab`. [F6, F40, F51, F80]
- `blk_start_plug_nr_ios()` must not overwrite a non-NULL `current->plug`, and `blk_finish_plug(plug)` must only flush and clear `current->plug` when `plug == current->plug`; `__submit_bio_noacct*()` must reset `current->bio_list = NULL` before returning. [F13, F161]
- `attempt_merge()` transfers `next->bio` to `req`, calls `blk_crypto_rq_put_keyslot(next)`, sets `next->bio = NULL`, and returns `next` for the caller to free. In `blk_complete_request()` and `blk_update_request()`, release the keyslot (`blk_crypto_rq_put_keyslot()`) before the `bio_endio()` loop, and read `bio->bi_next` before calling `bio_endio(bio)`. `__blk_crypto_evict_key()` must unconditionally delete `slot->hash_node` and clear `slot->key = NULL` even on error. [F18, F22, F232, F334]
- `blk_free_queue()` must defer `percpu_ref_exit(&q->q_usage_counter)` and `kmem_cache_free()` to `blk_free_queue_rcu()`. `blk_unregister_queue()` must clear `QUEUE_FLAG_REGISTERED` under `q->sysfs_lock` and remove child sysfs kobjects before `elevator_set_none(q)`. `blk_mq_destroy_queue()` requires `!blk_queue_registered(q)`, runs `blk_sync_queue()` and `blk_mq_cancel_work_sync()` before `blk_mq_exit_queue()` (where `blk_mq_exit_hw_queues()` must precede `blk_mq_del_queue_tag_set()`), and leaves `blk_put_queue()` to the caller. [F14, F43, F217, F246, F373, F376]
- `blk_mq_free_rqs()` and `blk_mq_exit_hctx()` must clear stale pointers in `drv_tags->rqs[]` via `blk_mq_clear_rq_mapping()` / `blk_mq_clear_flush_rq_mapping()` before `blk_mq_free_tags()` defers page freeing via `call_srcu(&set->tags_srcu, ...)`, and `blk_mq_free_tag_set()` must call `srcu_barrier(&set->tags_srcu)` before `cleanup_srcu_struct()`. [F228, F397]

## API Contracts
- `bio_split()` returns `ERR_PTR` without ending `@bio`, whereas `bio_submit_split_bioset()` calls `bio_endio(bio)` and returns `NULL` on failure. `bio_split_io_at()` returns `< 0` on error, `0` if no split, or `> 0` sector count (converted to `-EREMOTEIO` by `blk_rq_append_bio()`). `bio_split()` and `bio_trim()` take 512-byte sectors (`bio_trim()` must check `offset <= BIO_MAX_SECTORS && size <= BIO_MAX_SECTORS && offset + size <= bio_sectors(bio)` before `<< 9`), whereas `bio_advance()` and `bio_integrity_advance()` take bytes. [F49, F50, F56, F132]
- `__blk_mq_alloc_disk()`, `blk_mq_alloc_queue()`, `blk_mq_alloc_request()`, and `blk_mq_alloc_request_hctx()` (requiring `BLK_MQ_REQ_NOWAIT | BLK_MQ_REQ_RESERVED`) return `ERR_PTR`, whereas `blk_mq_alloc_disk_for_queue()`, `__blk_mq_alloc_requests()`, and `blk_mq_alloc_cached_request()` return `NULL`. `blk_mq_get_tag()` returns unsigned `BLK_MQ_NO_TAG` (`-1U`) on failure. [F267, F268, F269, F285]
- `blk_crypto_get_keyslot()` returns `BLK_STS_OK` with `*slot_ptr = NULL` when `profile->num_slots == 0` (check `blk_crypto_rq_has_keyslot(rq)`). `blk_crypto_profile_init()` zeroes `*profile` with `memset()` (call before setting fields), and `devm_blk_crypto_profile_init()` profiles must not be passed to `blk_crypto_profile_destroy()`. `bio_crypt_set_ctx()` requires `__GFP_DIRECT_RECLAIM` in `gfp_mask`. [F59, F163, F164, F178]
- `blk_rq_map_user()` and `blk_rq_integrity_map_user()` must set `iov_iter` direction to `rq_data_dir(rq)`; `bio_alloc_map_data()` must deep-copy `iter_iov(data)` into `bmd->iov` when `iter_is_iovec(data)`; `blk_rq_unmap_user()` must be called in process context with the original saved `rq->bio`, unmapping the entire `bi_next` chain while preserving the first error (and `bio_uncopy_user()` must check `current->mm`). Read bios mapped via `bio_add_vmalloc*()` require `invalidate_kernel_vmap_range()` on completion. [F62, F63, F150, F174, F175]
- Callers of `__blk_rq_map_sg(rq, sglist, last_sg)` must initialize `*last_sg = NULL` and size `sglist` to at least `blk_rq_nr_phys_segments(rq)`. `blk_mq_run_hw_queue(hctx, false)` must never be called in IRQ context or in atomic context when `BLK_MQ_F_BLOCKING` is set. Dispatch loops must call `blk_mq_commit_rqs()` on leftover requests, `ret != BLK_STS_OK`, or `hctx` switch. Passthrough requests (`blk_rq_is_passthrough(rq)`) and `REQ_OP_FLUSH` bypass `q->elevator` and skip `rq_qos_done()`. [F284, F318, F327, F331, F392, F427]

## Known Pitfalls
- In `blk_crypto_fallback_decrypt_endio()`, restore `bio->bi_private` and `bio->bi_end_io` from `f_ctx->bi_private_orig` and `f_ctx->bi_end_io_orig` before initializing `f_ctx->work` and `f_ctx->bio` (which share a union). `blk_mq_rq_ctx_init()` reuses `tags->static_rqs[tag]` without `memset()`, so new `struct request` fields must be initialized in both `blk_mq_rq_ctx_init()` and `blk_rq_init()`. `I_BDEV()` and `BDEV_I()` may only be called on `blockdev_superblock` pseudo-inodes (`bdev_file->f_mapping->host`), never on VFS `/dev` inodes. [F23, F148, F362]
- `bio_endio()` must handle `bio->bi_end_io == bio_chain_endio` iteratively via `bio = __bio_chain_endio(bio); goto again;`. `blk_mq_use_cached_rq()` must pop `rq` from `plug->cached_rqs` before `rq_qos_throttle()`, and `blk_mq_flush_plug_list()` must zero `plug->rq_count` upfront, because sleeping in `throttle()`/`queue_rq()` invokes `schedule()` which recursively flushes `current->plug`. [F120, F261]
- In `get_max_segment_size()`, compare `lim->seg_boundary_mask - (lim->seg_boundary_mask & paddr)` against `(unsigned long)lim->max_segment_size - 1` before adding `1`. Widen 32-bit/16-bit values to 64-bit before shifting/multiplying (`blk_apply_bdi_limits()`, `QUEUE_SYSFS_LIMIT_SHOW_SECTORS_TO_BYTES`, `check_shl_overflow()` in `blk_stack_atomic_writes_chunk_sectors()`, `mb_to_sects()`, `mtip_hw_get_capacity()`, `response_parse_short()`), and use `DIV_ROUND_UP_SECTOR_T()` in `__blkdev_sectors_to_bio_pages()`. [F134, F140, F344, F345, F347, F536, F540, F726]
- In `blk_mq_get_hctx_type()`, test `opf & REQ_POLLED` before `REQ_OP_READ`; in `blk_throtl_activated()`, check both `q->td != NULL` and `blkcg_policy_enabled(q, &blkcg_policy_throtl)`; in `xen-blkfront`, always use `get_rinfo()`/`for_each_rinfo()` instead of `info->rinfo[i]`. [F241, F328, F698]
