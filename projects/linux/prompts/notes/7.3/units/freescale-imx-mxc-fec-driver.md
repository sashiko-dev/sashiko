# FREESCALE IMX / MXC FEC DRIVER

This driver manages the Freescale/NXP Fast Ethernet Controller (FEC) and Enhanced Network (ENET) MAC IP blocks on ColdFire, i.MX, Vybrid (MVF600), and S32V234 SoCs. It implements a multi-queue Ethernet `net_device` with up to 3 TX/RX hardware rings, NAPI polling, `page_pool` RX buffers, XDP, software TSO with hardware checksum/VLAN offload, C22/C45 MDIO management, and an IEEE 1588 PTP Hardware Clock (PHC) with PPS/PEROUT support.

## Architecture & Data Flow

- `struct bufdesc` (8B) and `struct bufdesc_ex` (32B) share `struct bufdesc *` ring pointers and use arch-dependent endianness (`__le*` on ARM/ARM64 vs `__be*` on ColdFire) with swapped `cbd_datlen`/`cbd_sc` order: traverse rings only by `bd->dsize` via `fec_enet_get_nextdesc()`/`fec_enet_get_prevdesc()`, compute indices via `fec_enet_get_bd_index()` (`>> bd->dsize_log2`), and access fields only via `cpu_to_fec16()`/`fec16_to_cpu()` and `cpu_to_fec32()`/`fec32_to_cpu()`. [F68, F73]
- When recycling TX or RX descriptors (`fec_enet_txq_submit_skb()`, `fec_enet_txq_submit_frag_skb()`, `fec_enet_txq_put_data_tso()`, `fec_enet_txq_put_hdr_tso()`, `fec_enet_txq_xmit_frame()`, `fec_enet_rx_queue()`), mask `bdp->cbd_sc` with `~BD_ENET_TX_STATS` or `~BD_ENET_RX_STATS` rather than zeroing it so `BD_SC_WRAP` is preserved. [F59]
- `txq->dirty_tx` starts at `txq->bd.last` and always points to the descriptor immediately preceding the next slot to reclaim; `fec_enet_get_free_txdesc_num()` computes `(((const char *)txq->dirty_tx - (const char *)txq->bd.cur) >> txq->bd.dsize_log2) - 1` in a signed `int` (wrapping by adding `txq->bd.ring_size` when `< 0`) so `bd.cur` never catches `dirty_tx`. [F70, F102]
- For multi-descriptor `FEC_TXBUF_T_SKB` frames, `txq->tx_buf[index].buf_p` stores `skb` only at the final descriptor (`NULL` on earlier slots): `fec_enet_txq_submit_skb()` keeps `bdp` at `txq->bd.cur` to set `BD_ENET_TX_READY` on the first descriptor while using `last_bdp` for `index` and advancing `txq->bd.cur`, and `fec_enet_txq_submit_tso()` keeps `index` from the final inner `while (data_left > 0)` iteration before the outer loop's extra `fec_enet_get_nextdesc()` advances `txq->bd.cur`. [F71, F86, F92]
- In SKB TX submission paths, any buffer with low address bits set in `fep->tx_align` (`0xf` on ARM/ARM64, `0x3` on ColdFire, `0` with `FEC_QUIRK_HAS_MULTI_QUEUES`) or when `FEC_QUIRK_SWAP_FRAME` is set must be copied into `txq->tx_bounce[index]` (and byte-swapped there via `swap_buffer()`, never in-place on `skb->data`) before `dma_map_single()`. [F74]
- Gate all PTP and `struct bufdesc_ex` operations on `fep->bufdesc_ex` (forced `false` in `fec_probe()` if `devm_clk_get(..., "ptp")` fails). When `fep->bufdesc_ex` is true, any `fec_ctrl_reset()` in `fec_restart()` or `fec_stop()` must be bracketed by `fec_ptp_save_state(fep)` beforehand and by re-setting `FEC_ECR_EN1588` in `FEC_ECNTRL`, `fec_ptp_start_cyclecounter(ndev)`, and `fec_ptp_restore_state(fep)` (clearing `fep->pps_enable = 0` under `fep->tmreg_lock` before `fec_ptp_enable_pps(fep, 1)`) afterward. [F48, F49, F117]
- `fec_probe()` must call `fec_ptp_init()` before `fec_enet_init()`, and `fec_ptp_init()` must replace a zero `clk_get_rate(fep->clk_ptp)` with `NSEC_PER_SEC` in `fep->cycle_speed` before computing `fep->ptp_inc` or calling `fec_ptp_start_cyclecounter()`. Mask every timestamp written to `FEC_ATIME`, `FEC_TCCR`, or `fep->next_counter` with `fep->cc.mask` (`CLOCKSOURCE_MASK(31)`). [F96, F98]
- Toggling `NETIF_F_RXCSUM` via `fec_enet_set_netdev_features()` must update `FLAG_RX_CSUM_ENABLED` in `fep->csum_flags` in lockstep, and when `netif_running(netdev)` is true, `fec_set_features()` must stop and restart the MAC to reprogram `FEC_RACC`. [F52]
- `fec_probe()` sizes flexible array `fep->ethtool_stats[]` to `FEC_STATS_SIZE` (`ARRAY_SIZE(fec_stats) * sizeof(u64)`); `fec_enet_close()` must call `fec_enet_update_ethtool_stats(ndev)` before `fec_enet_clk_enable(ndev, false)`, and `fec_enet_get_sset_count()`, `fec_enet_get_strings()`, and `fec_enet_get_ethtool_stats()` must emit `fec_stats`, `XDP_STATS_TOTAL`, and `page_pool` stats in identical order while advancing `u64 *data` by element counts (`FEC_STATS_SIZE / sizeof(u64)`). [F54, F80, F105]
- Gate optional features on `fep->quirks`: C45 MDIO (`fec_enet_mdio_read_c45`/`write_c45`) requires `FEC_QUIRK_HAS_MDIO_C45`, `FEC_R_BOUND`/`FEC_R_FSTART` require `FEC_QUIRK_HAS_FRREG`, `FEC_RACC`/`FEC_FTRL` require `FEC_QUIRK_HAS_RACC`, and `FEC_TXIC1`..`FEC_RXIC2` require `FEC_QUIRK_HAS_COALESCE` and `FEC_QUIRK_HAS_MULTI_QUEUES`. `fec_dt_ids[].data` must point to `const struct fec_devinfo`, and runtime quirks like `FEC_QUIRK_ERR006687` must be ORed into `fep->quirks` without mutating shared `fec_devinfo`. [F119, F121, F122]

## Synchronization

- When acquiring both `fep->ptp_clk_mutex` and `fep->tmreg_lock` (`fec_ptp_gettime()`, `fec_ptp_settime()`, `fec_ptp_enable()`, `fec_time_keep()`), lock `fep->ptp_clk_mutex` outer to `fep->tmreg_lock` and verify `fep->ptp_clk_on` before touching `fep->tc` or PTP registers. Because `fec_restart()` and `fec_stop()` run under `netif_tx_lock_bh()`, functions on their call paths (`fec_enet_bd_init()`, `fec_ptp_save_state()`, `fec_ptp_restore_state()`, `fec_ptp_start_cyclecounter()`) must use `spin_lock_irqsave(&fep->tmreg_lock, ...)` and `dev_kfree_skb_any()`, never `fep->ptp_clk_mutex` or sleeping calls. [F18, F134]
- In `fec_ptp_enable_pps()`, acquire `fep->tmreg_lock` with `spin_lock_irqsave()` before reading `fep->pps_enable` and hold it continuously until `fep->pps_enable` is updated and `FEC_TCSR`, `FEC_TCCR`, and `FEC_ATIME_CTRL` are programmed. [F16]
- When `netif_running(ndev)` is true, callers of `fec_restart()` or `fec_stop()` (`fec_enet_timeout_work()`, `fec_enet_adjust_link()`, `fec_enet_set_pauseparam()`, `fec_set_features()`, `fec_enet_bpf()`, `fec_resume()`) must disable NAPI (`napi_disable(&fep->napi)`) and stop/lock TX queues (`netif_tx_lock_bh()` or `netif_tx_disable()`); in `fec_enet_adjust_link()`, `netif_stop_queue(ndev)` must precede `napi_disable(&fep->napi)` and `netif_tx_lock_bh(ndev)`. [F20, F137]
- When submitting TX descriptors (`fec_enet_txq_submit_skb()`, `fec_enet_txq_submit_frag_skb()`, `fec_enet_txq_xmit_frame()`) or recycling RX descriptors (`fec_enet_rx_queue()`), write descriptor fields and `tx_buf` before a `wmb()`/`dma_wmb()` that precedes setting `BD_ENET_TX_READY` or `BD_ENET_RX_EMPTY` in `bdp->cbd_sc`. Lockless TX ring coordination also requires `wmb()`/`dma_wmb()` between writing `bdp->cbd_sc` and updating `txq->bd.cur`, and in `fec_enet_tx_queue()` an `rmb()` between `READ_ONCE(txq->bd.cur)` and `READ_ONCE(bdp->cbd_sc)` plus a `wmb()` before updating `txq->dirty_tx`. [F140, F141]
- When acknowledging interrupts in `fec_enet_collect_events()` and `fec_restart()`, mask out `FEC_ENET_MII` (`& ~FEC_ENET_MII`) from the value written to write-1-to-clear `FEC_IEVENT` so `fec_enet_mdio_wait()` can poll and clear `FEC_ENET_MII` itself. [F125]
- Synchronous cancellations in `fec_drv_remove()` (`cancel_work_sync(&fep->tx_timeout_work)`) and `fec_ptp_stop()` (`cancel_delayed_work_sync(&fep->time_keep)` and `hrtimer_cancel(&fep->perout_timer)`) must run outside `rtnl_lock()`, `fep->ptp_clk_mutex`, and `fep->tmreg_lock`, which those callbacks acquire. [F145]

## Object Lifetimes

- Every TX ring cleanup path (`fec_enet_tx_queue()`, `fec_enet_bd_init()`, `fec_enet_free_buffers()`) must release `txq->tx_buf[i].buf_p` according to `txq->tx_buf[i].type` (`FEC_TXBUF_T_SKB`, `FEC_TXBUF_T_XDP_NDO`, `FEC_TXBUF_T_XDP_TX`), clear `buf_p` to `NULL`, and reset `type` to `FEC_TXBUF_T_SKB` because SKB/TSO submit paths do not write `tx_buf[index].type`. [F2]
- In `fec_enet_create_page_pool()` and `fec_enet_free_buffers()`, clear `rxq->page_pool` to `NULL` on `page_pool_create()` error or after `page_pool_destroy()`, after releasing all `rxq->rx_skb_info[i].page` entries via `page_pool_put_full_page()` (not `page_pool_release_page()`) and unregistering `rxq->xdp_rxq`. [F5]
- Queues and TSO headers from `fec_enet_alloc_queue()` are not devres-managed and must be freed via `fec_enet_free_queue(ndev)` if `fec_enet_init()` fails before `netif_napi_add()`, and via `fec_enet_deinit(ndev)` on post-`fec_enet_init()` failure in `fec_probe()` and in `fec_drv_remove()`. Call `free_netdev(ndev)` last after all `ndev`/`fep` accesses (`cancel_work_sync()`, `fec_ptp_stop()`, `unregister_netdev()`, `fec_enet_mii_remove()`, `regulator_disable()`, `of_node_put()`, clock disables, `fec_enet_deinit()`). [F7, F8]
- `fec_runtime_suspend()`/`fec_runtime_resume()` manage `clk_ahb` and `clk_ipg`, while `fec_enet_clk_enable()` manages `clk_enet_out`, `clk_ptp` (`fep->ptp_clk_on`), `clk_ref`, and `clk_2x_txclk`. Gate `pm_runtime_force_suspend()`/`resume()` on `fep->rpm_active` in `fec_suspend()`/`fec_resume()`, and in `fec_drv_remove()` disable `clk_ahb` and `clk_ipg` only if `pm_runtime_get_sync(&pdev->dev) >= 0` while calling `pm_runtime_put_noidle()` and `pm_runtime_disable()` unconditionally. [F9, F131]
- Balance OF node references, PHY lookups, and fixed-link registrations in `fec_probe()`, `fec_enet_mii_init()`, `fec_enet_init_stop_mode()`, and `fec_enet_phy_reset_after_clk_enable()` with `of_phy_deregister_fixed_link()`, `of_node_put()`, and `put_device(&phy_dev->mdio.dev)` (checking `phy_dev` is non-NULL after `of_phy_find_device(fep->phy_node)`). [F12, F31]
- In `fec_ptp_init()`, initialize `fep->tmreg_lock`, `fep->cc`, `fep->tc`, `fep->time_keep`, and `fep->perout_timer` before requesting `fec_pps_interrupt`, calling `ptp_clock_register()`, and scheduling `fep->time_keep`. In `fec_ptp_stop()`, call `fec_ptp_enable_pps(fep, 0)`, `cancel_delayed_work_sync(&fep->time_keep)`, and `hrtimer_cancel(&fep->perout_timer)` before unregistering `fep->ptp_clock` or freeing `ndev`. [F15, F27]
- In `fec_suspend()` on a running interface, complete `phy_stop()`, `napi_disable()`, `netif_device_detach()` (under `netif_tx_lock_bh()`), `fec_stop()` (setting `FEC_WOL_FLAG_SLEEP_ON` beforehand if `FEC_WOL_FLAG_ENABLE`), and IRQ masking before `fec_enet_clk_enable(ndev, false)`; when `FEC_WOL_FLAG_ENABLE` is active, pair `disable_irq(fep->wake_irq)`/`enable_irq_wake()`, `fec_enet_stop_mode(fep, true)`, and keeping `fep->reg_phy` on with `fec_resume()` (which must also clear `FEC_ECR_MAGICEN | FEC_ECR_SLEEP` and `FEC_WOL_FLAG_SLEEP_ON` before `fec_restart()`). [F30, F65, F130]
- In `fec_enet_bpf()`, call `xdp_features_clear_redirect_target(dev)` before disabling NAPI/TX queues and calling `fec_restart(dev)` when removing an XDP program, and call `xdp_features_set_redirect_target(dev, false)` only after `fec_restart(dev)` and queue re-enable complete when installing one. On `FEC_QUIRK_SINGLE_MDIO` platforms, secondary instances reuse `fec0_mii_bus` and increment `mii_cnt`, and `fec_enet_mii_remove()` must only unregister/free `fep->mii_bus` when `--mii_cnt == 0`. [F113, F114]

## API Contracts

- When `fec_enet_txq_xmit_frame()` fails (`-EBUSY` or `-ENOMEM`), it must not free `frame`, leaving ownership with the caller (`fec_enet_run_xdp()` calling `page_pool_put_page()` on `XDP_TX` failure, or `fec_enet_xdp_xmit()` stopping on the first negative error and returning exact `sent_frames` so `ndo_xdp_xmit` callers free unsent `xdp_frame`s). [F1, F34]
- `fec_enet_txq_submit_frag_skb()` advances `bdp` from `txq->bd.cur` via `fec_enet_get_nextdesc()` before mapping each fragment and returns the last mapped `struct bufdesc *` or `ERR_PTR(-ENOMEM)` (checked via `IS_ERR()`, not NULL). On DMA mapping error, it must reset `bdp = txq->bd.cur` and advance `bdp` before unmapping each `i < frag` without freeing `skb` or unmapping `txq->bd.cur`, leaving `fec_enet_txq_submit_skb()` to unmap the linear head buffer and call `dev_kfree_skb_any(skb)`. [F4, F36, F88]
- In TX submission paths from `fec_enet_start_xmit()` (`fec_enet_txq_submit_skb()`, `fec_enet_txq_submit_tso()`, `fec_enet_txq_put_data_tso()`, `fec_enet_txq_put_hdr_tso()`), any error path that frees `skb` with `dev_kfree_skb_any()` must return `NETDEV_TX_OK` (`0`), never `NETDEV_TX_BUSY`. Before DMA-mapping an SKB, call `fec_enet_clear_csum()`, which when `skb->ip_summed == CHECKSUM_PARTIAL` must call `skb_cow_head(skb, 0)` before zeroing `ip_hdr(skb)->check` and the L4 checksum. [F148, F149]
- In `fec_enet_select_queue()` with `FEC_QUIRK_HAS_AVB`, check `eth_type_vlan(skb->protocol)` before reading `skb_vlan_eth_hdr(skb)->h_vlan_TCI` and otherwise check `skb_vlan_tag_present(skb)` before reading `skb->vlan_tci`. In `fec_enet_rx_queue()`, when `fep->bufdesc_ex` and `BD_ENET_RX_VLAN` are set, call `fec_enet_rx_vlan()` before `eth_type_trans(skb, ndev)`. In TX paths, gate hardware TX timestamping (`BD_ENET_TX_TS`, `SKBTX_IN_PROGRESS`, `skb_tstamp_tx()`) on both `fep->hwts_tx_en` and `fep->bufdesc_ex`. [F150, F151, F157]
- Guard callbacks when the interface is down: `fec_set_mac_address()` must check `netif_running(ndev)` before `fec_set_hw_mac_addr()`, `fec_enet_get_regs()` must use `pm_runtime_resume_and_get()`, and `fec_enet_get_eee()`/`fec_enet_set_eee()` must return `-ENETDOWN` when `!netif_running(ndev)`. `fec_netdev_ops` must omit `.ndo_poll_controller` and never call sleeping functions like `disable_irq()` from netpoll paths. [F147, F161]

## Error Handling

- When fallible acquisitions for `rxq->page_pool`, `fep->stop_gpr.gpr`, `fep->clk_2x_txclk`, `fep->clk_ptp`, `fep->reg_phy`, or `fep->ptp_clock` return an `IS_ERR()` pointer, reset the field to `NULL` so downstream NULL checks in teardown, runtime, and stats paths do not dereference an `ERR_PTR`. [F41]
- In `fec_get_mac()`, if `of_get_mac_address(np, tmpaddr)` returns `-EPROBE_DEFER`, return `-EPROBE_DEFER` immediately so `fec_enet_init()` and `fec_probe()` defer probing. In `fec_enet_get_regs()`, pre-zero the buffer with `memset(buf, 0, regs->len)` before populating `buf[off]` from `reg_list`. In TX/RX hot paths, rate-limit error logs with `netdev_err_once()` or `net_ratelimit()`. [F44, F45, F165]

## Known Pitfalls

- In `fec_enet_rx_queue()`, `status` is XORed with `BD_ENET_RX_LAST` before error checking so a missing hardware `BD_ENET_RX_LAST` bit tests nonzero in `status & (... | BD_ENET_RX_LAST | ...)` while a valid `BD_ENET_RX_LAST` bit is cleared before writing `status` back to `bdp->cbd_sc`. [F81]
- In `fec_ptp_adjfine()`, return early when `ppb == 0`, widen `rhs = (u64)ppb * (u64)fep->ptp_inc` and accumulate `lhs` as `u64` to avoid 32-bit overflow, and call `div_u64(lhs, rhs)` only inside the `1 <= i <= fep->ptp_inc` loop. Use `div_u64()` (not `/` or `%`) for all 64-bit divisions (`fec_ptp_adjfine()`, `fec_ptp_enable()`) to support 32-bit ColdFire and ARM targets. [F93, F94, F95]
- In `fec_enet_mii_init()`, compute `mii_speed` and `holdtime` with `DIV_ROUND_UP()` rather than truncating division, and clear `FEC_MII_DATA` (`MMFR`) to `0` before writing `FEC_MII_SPEED` (`MSCR`) only when `fep->quirks & FEC_QUIRK_CLEAR_SETUP_MII` is set.Respect silicon errata guards: in `fec_enet_txq_submit_skb()` and `fec_enet_txq_submit_tso()` with `FEC_QUIRK_ERR007885`, poll `readl(txq->bd.reg_desc_active)` up to four times and write `0` only if a read returns `0`; in `fec_ptp_read()` with `FEC_QUIRK_BUG_CAPTURE`, wait `udelay(1)` before reading `FEC_ATIME`. [F97, F120, F126, F127]
