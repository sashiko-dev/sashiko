# ARM/LPC32XX SOC SUPPORT

This component provides architecture support and core peripheral drivers for NXP LPC32xx (and related PNX4008) ARM SoCs, including early static I/O mapping, IRAM detection, UART initialization and errata workarounds, suspend-to-RAM via IRAM execution, DMA request multiplexing (`lpc32xx-dmamux`), I2C (`i2c-pnx`), Ethernet (`lpc_eth`), OHCI USB (`ohci-nxp`), and watchdog/reset (`pnx4008_wdt`).

## Architecture & Data Flow

- In `lpc_eth`, `__lpc_eth_init` must reset `pldat->num_used_tx_buffs = 0` alongside `pldat->last_tx_idx = readl(LPC_ENET_TXCONSUMEINDEX(pldat->net_base))`. `lpc_eth_hard_start_xmit` increments `num_used_tx_buffs` per queued packet and must cap in-flight descriptors at `ENET_TX_DESC - 1` (`num_used_tx_buffs >= ENET_TX_DESC - 1`) so `LPC_ENET_TXPRODUCEINDEX` never wraps onto `LPC_ENET_TXCONSUMEINDEX`, while `__lpc_handle_xmit` decrements `num_used_tx_buffs` for each slot advanced by `last_tx_idx`. [F8, F55]
- `__va_to_pa` in `lpc_eth.c` computes `(addr - pldat->dma_buff_base_v) + pldat->dma_buff_base_p`, requiring all descriptor rings, status arrays, and packet buffers to reside within `[dma_buff_base_v, dma_buff_base_v + dma_buff_size)`. `__lpc_txrx_desc_setup` must recompute all interior pointers (`tx_desc_v`, `tx_stat_v`, `tx_buff_v`, `rx_desc_v`, `rx_stat_v`, `rx_buff_v`), descriptor `.packet` physical addresses via `__va_to_pa`, and MAC base registers together during `__lpc_eth_init`. [F49, F77]
- In `__lpc_handle_recv`, if `prxstat->statusinfo` has `RXSTATUS_ERROR` set and `RXSTATUS_RANGE` is the only bit set within `RXSTATUS_STATUS_ERROR`, `RXSTATUS_ERROR` must be cleared before checking `ethst & RXSTATUS_ERROR`. Every receive loop iteration—including hardware RX errors and `dev_alloc_skb` failures—must advance `rxconsidx` modulo `ENET_RX_DESC`, write `LPC_ENET_RXCONSUMEINDEX`, and increment `rx_done`. [F63, F64]
- Whenever `lpc_handle_link_change` updates `pldat->speed`, `pldat->duplex`, or `pldat->link` under `pldat->lock` (resetting `speed = 0` and `duplex = -1` when `!phydev->link`), it must call `__lpc_params_setup(pldat)` to reprogram `LPC_ENET_MAC2`, `LPC_ENET_COMMAND`, `LPC_ENET_IPGT`, and `LPC_ENET_SUPP`. [F48]
- In `lpc_eth_drv_suspend`, when `netif_running(ndev)` is true, after calling `netif_device_detach(ndev)`, `__lpc_eth_shutdown(pldat)`, and `clk_disable_unprepare(pldat->clk)`, `__lpc_eth_reset(pldat)` must be called a second time so that `EMC_MDC` is held down. [F95]
- In `__lpc_set_mac` and `__lpc_get_mac`, the 6-byte MAC address maps across station address registers in descending order (`mac[0..1]` in `LPC_ENET_SA2`, `mac[2..3]` in `LPC_ENET_SA1`, `mac[4..5]` in `LPC_ENET_SA0`), with even-indexed bytes in bits `0..7` and odd-indexed bytes in bits `8..15`. [F58]
- In `lpc_eth_set_multicast_list`, the 6-bit multicast CRC index `hash_val` (`(ether_crc(6, ha->addr) >> 23) & 0x3F`) must be split at 32 between `hashlo` (`1 << hash_val`) and `hashhi` (`1 << (hash_val - 32)`) for `LPC_ENET_HASHFILTERL` and `LPC_ENET_HASHFILTERH` so 32-bit shifts stay in `0..31`. [F73]
- In `lpc_mdio_read` and `lpc_mdio_write`, busy-wait loops polling `LPC_MIND_BUSY` must check deadline expiration with `time_after(jiffies, timeout)` rather than direct relational comparison on `jiffies`. [F75]
- In `lpc_eth.c`, `platform_set_drvdata(pdev, ndev)` stores `struct net_device *` while `pldat->mii_bus->priv = pldat` stores `struct netdata_local *`; callers of `platform_get_drvdata` / `dev_get_drvdata` must retrieve `struct net_device *` first and pass it to `netdev_priv`. [F81]
- `i2c_pnx_master_rcv` tracks dummy TX writes in `alg_data->mif.order` separately from RX bytes in `alg_data->mif.len`. When `I2C_REG_STS` has `mstatus_rfe` (RX FIFO empty) set, it must only write a dummy byte to `I2C_REG_TX`, decrement `mif.order` (if non-zero), and return without reading `I2C_REG_RX` or decrementing `mif.len`; when `mif.order == 1`, it must set `stop_bit` on the dummy write and switch `I2C_REG_CTL(alg_data)` from `mcntrl_drmie` to `mcntrl_rffie | mcntrl_daie`. [F45, F65]
- In `i2c_pnx_master_xmit`, a zero-length message (`alg_data->mif.len == 0`) must still be handled by calling `i2c_pnx_stop`, masking `mcntrl_afie | mcntrl_naie | mcntrl_drmie` in `I2C_REG_CTL`, and calling `complete(&alg_data->mif.complete)`. [F66]
- Because entering LPC32xx direct-run and halt modes stops DDR clocks and puts DRAM in self-refresh, `lpc32xx_pm_enter` must back up `TEMP_IRAM_AREA`, copy `lpc32xx_sys_suspend_sz` bytes from `&lpc32xx_sys_suspend` to `TEMP_IRAM_AREA`, call `flush_icache_range` and `flush_cache_all` before invoking it, and restore IRAM afterward. All code, literals, and `tmp_stack` used by `lpc32xx_sys_suspend` in `suspend.S` must be PC-relative and precede `ENTRY(lpc32xx_sys_suspend_sz)`. [F80, F101]
- In `pnx4008_wdt_start`, under `io_lock`, the driver must write `RESET_COUNT` to `WDTIM_CTRL(wdt_base)` and spin until `readl(WDTIM_COUNTER(wdt_base))` reaches 0 before writing `WDTIM_MCTRL`, `WDTIM_MATCH0`, and `COUNT_ENAB | DEBUG_EN` to `WDTIM_CTRL(wdt_base)`. [F51]
- In `lpc32xx_serial_init`, `LPC32XX_UARTCTL_CLKMODE` must be written only after every UART in `uartinit_data` has its clock enabled and pre-divider (`pdiv_clk_reg`) set, and `LPC32XX_UART_U5_ROUTE_TO_USB` in `LPC32XX_UARTCTL_CTRL` must be cleared so USB can operate. [F92]

## Synchronization

- Because hardirq handler `__lpc_eth_interrupt` acquires `pldat->lock` (`struct netdata_local::lock`), any non-hardirq context acquiring `pldat->lock` must disable local IRQs (`spin_lock_irq` or `spin_lock_irqsave`). In `lpc_eth_hard_start_xmit`, `spin_lock_irq(&pldat->lock)` must be held across checking/incrementing `pldat->num_used_tx_buffs`, populating the TX descriptor and buffer, writing `LPC_ENET_TXPRODUCEINDEX`, and calling `netif_stop_queue`. [F20, F97]
- In `lpc_eth_poll`, when `rx_done < budget`, `napi_complete_done(napi, rx_done)` must be called before re-enabling MAC interrupts via `lpc_eth_enable_int(pldat->net_base)`. [F21]
- On every transfer completion or error path in `i2c_pnx_interrupt`, `i2c_pnx_master_xmit`, and `i2c_pnx_master_rcv`, master interrupt enable bits in `I2C_REG_CTL(alg_data)` must be cleared and any `alg_data->mif.ret` error stored before calling `complete(&alg_data->mif.complete)`. [F17]
- `i2c_pnx_interrupt`, `i2c_pnx_master_xmit`, `i2c_pnx_master_rcv`, and `i2c_pnx_stop` execute in hardirq context and must never call `del_timer_sync` or sleeping functions. In `i2c_pnx_stop`, the poll for `mstatus_active` to clear in `I2C_REG_STS(alg_data)` must bound its spin to at most 1 ms using `udelay(1)` rather than `wait_timeout`. [F90, F96]
- `dmamux->lock` (`struct lpc32xx_dmamux_data::lock`) must be held across checking and updating `mux->busy`, setting `mux->muxval`, and calling `regmap_update_bits` in `lpc32xx_dmamux_reserve`, and across clearing `mux->busy` in `lpc32xx_dmamux_release`. [F15]

## Object Lifetimes

- `lpc_eth_hard_start_xmit` must leave `skb` unfreed when returning `NETDEV_TX_BUSY`, and on `NETDEV_TX_OK` must copy `skb->data` into `pldat->tx_buff_v` and call `dev_kfree_skb(skb)` immediately because `__lpc_handle_xmit` does not retain or free `sk_buff` pointers. [F7]
- In `lpc_eth_open`, `phy_resume(ndev->phydev)` must precede `__lpc_eth_reset` and `__lpc_eth_init`. In `lpc_eth_close`, `napi_disable(&pldat->napi)` and `netif_stop_queue(ndev)` must complete before `__lpc_eth_reset(pldat)` (under `pldat->lock`) and clearing `LPC_ENET_MAC1`/`LPC_ENET_MAC2`, which must complete before `phy_stop(ndev->phydev)`, which must precede `clk_disable_unprepare(pldat->clk)`. [F22, F83]
- In `lpc_eth_drv_remove`, `unregister_netdev(ndev)` must be called before freeing DMA coherent memory, freeing `ndev->irq`, unmapping `pldat->net_base`, unregistering `pldat->mii_bus`, or disabling `pldat->clk`. [F23]
- In `i2c_pnx_xfer`, each loop iteration must reinitialize `alg_data->mif` (`buf`, `len`, `order`, `mode`, `ret`, `complete`) and set `alg_data->last = (i == num - 1)` before enabling master interrupts and calling `i2c_pnx_start`, and must `break` on `rc < 0`. Before returning on any path, `i2c_pnx_xfer` must call `bus_reset_if_active(alg_data)` and reset `mif.buf = NULL`, `mif.len = 0`, and `mif.order = 0`. [F12, F67]
- Because `i2c_pnx_probe` enables `alg_data->clk` via `clk_prepare_enable`, every subsequent error path must jump to `out_clock` (`clk_disable_unprepare(alg_data->clk)`), and `i2c_pnx_remove` must call `i2c_del_adapter(&alg_data->adapter)` before `clk_disable_unprepare(alg_data->clk)`. [F13]
- In `lpc32xx_dmamux_probe`, `dmamux->reg`, `dmamux->lock`, `platform_set_drvdata(pdev, dmamux)`, and `dmamux->dmarouter` (`dev` and `route_free`) must be initialized before `of_dma_router_register` publishes the router to `lpc32xx_dmamux_reserve` and `lpc32xx_dmamux_release`. [F14]
- Device Tree `device_node` pointers acquired via `of_parse_phandle` (in `ohci_hcd_nxp_probe` or `lpc32xx_dmamux_reserve`) or `of_get_child_by_name` (in `lpc_mii_init`) must be balanced with `of_node_put` once handed off or on error (such as `-EBUSY`). [F84]

## API Contracts

- In `arch/arm/mach-lpc32xx/common.c`, `lpc32xx_return_iram` accepts `NULL` for `mapbase` and `dmaaddr` (used when querying IRAM size only) and must guard `*mapbase` and `*dmaaddr` writes with null checks. When `iram_size == 0` and the words at `LPC32XX_IRAM_BASE` and `LPC32XX_IRAM_BASE + LPC32XX_IRAM_BANK_SIZE` match, the probe write of `savedval2 + 1` to `iramptr2` must restore `savedval2` to `iramptr2` before returning. [F26, F39]
- `lpc32xx_set_phy_interface_mode` and `lpc32xx_loopback_set` must update `LPC32XX_CLKPWR_MACCLK_CTRL` and `LPC32XX_UARTCTL_CLOOP` via read-modify-write of only the target field (`LPC32XX_CLKPWR_MACCTRL_PINS_MSK` or `(1 << bit)`). `lpc32xx_loopback_set` only accepts physical addresses `LPC32XX_HS_UART1_BASE`, `LPC32XX_HS_UART2_BASE`, and `LPC32XX_HS_UART7_BASE`, and must warn and return early for any other `mapbase`. [F41, F69]
- Declarations and `!CONFIG_ARCH_LPC32XX` inline stubs in `include/linux/soc/nxp/lpc32xx-misc.h` must stay in sync with the exported definitions of `lpc32xx_return_iram`, `lpc32xx_set_phy_interface_mode`, and `lpc32xx_loopback_set` in `arch/arm/mach-lpc32xx/common.c` and `serial.c`. [F52]
- `IO_ADDRESS()` and `io_p2v()` in `arch/arm/mach-lpc32xx/lpc32xx.h` require physical addresses whose bits 20–23 are zero and that fall within the static `MT_DEVICE` regions mapped by `lpc32xx_map_io` (`lpc32xx_io_desc`). [F102]
- `lpc32xx_get_uid(u32 devid[4])` in `arch/arm/mach-lpc32xx/common.c` unconditionally writes `devid[0..3]`, so callers (such as `lpc32xx_check_uid`) must pass a buffer of at least four `u32` words. [F82]
- In `i2c-pnx.c`, `i2c_pnx_algo_data.timeout` is stored in jiffies (for `wait_for_completion_timeout`), so millisecond polling helpers `wait_timeout` and `wait_reset` must convert `data->timeout` with `jiffies_to_msecs` and return non-zero (`timeout <= 0`) on timeout. [F30]
- `i2c_pnx_xfer` and `i2c_pnx_start` only support unshifted 7-bit slave addresses (rejecting `I2C_M_TEN` or `slave_addr & ~0x7f` with `-EINVAL`). `i2c_pnx_start` requires `alg_data->mif.mode` to be `I2C_SMBUS_READ` (1) or `I2C_SMBUS_WRITE` (0) because it shifts `slave_addr` left by 1 and ORs `mif.mode` as `rw_bit` into `I2C_REG_TX`; `i2c_pnx_xfer` must return `num` on full completion or `rc < 0 ? rc : -EREMOTEIO`. [F32, F107]
- In `lpc_eth.c`, hardware descriptor counts (`LPC_ENET_TXDESCRIPTORNUMBER`, `LPC_ENET_RXDESCRIPTORNUMBER`) and descriptor control lengths (`txrx_desc_t.control`) use `count - 1` / `len - 1` encoding, whereas RX status length in `rx_status_t.statusinfo` requires adding 1 (`(prxstat->statusinfo & RXSTATUS_SIZE) + 1`). [F36]
- In `pnx4008_wdt.c`, `pnx4008_restart_handler` must check that `cmd` (`boot_cmd`) is non-NULL before reading `boot_cmd[0]`. `pnx4008_wdt_start` (which also serves as the keepalive ping callback because `pnx4008_wdt_ops.ping` is unset) must convert `wdd->timeout` from seconds (bounded to `1..MAX_HEARTBEAT` = 60, avoiding 32-bit overflow past 330s) to 13 MHz ticks via `wdd->timeout * WDOG_COUNTER_RATE` when writing `WDTIM_MATCH0(wdt_base)`. [F38, F109]

## Error Handling

- In `lpc_eth.c`, all paths that enable `pldat->clk` before accessing MAC registers (`lpc_eth_open`, `lpc_eth_drv_probe`, `lpc_eth_drv_resume`) must check the return value of `clk_enable` / `clk_prepare_enable` and abort on error before calling `__lpc_eth_reset` or `__lpc_eth_init`. [F34]
- In `lpc_mii_init`, any fallible call after `of_mdiobus_register` that jumps to `err_out_unregister_bus` (such as `lpc_mii_probe`) must assign its negative return code to `err`, because `of_mdiobus_register` leaves `err == 0` and `err_out_unregister_bus` returns `err`. [F33]
- In `lpc_mii_probe`, `pldat->phy_node` may be `NULL` (selecting `of_phy_find_device` vs `phy_find_first`); the lookup result must be checked for `NULL`, whereas the subsequent `phy_connect` result must be checked with `IS_ERR` and converted with `PTR_ERR`. [F35]

## Known Pitfalls

- Because `lpc32xx_return_iram` unconditionally populates `*mapbase` when non-NULL, `lpc_eth_drv_probe` must reset `pldat->dma_buff_base_v = NULL` when `pldat->dma_buff_size > lpc32xx_return_iram(&pldat->dma_buff_base_v, &dma_handle)` so it falls back to `dma_alloc_coherent`. Both `lpc_eth_drv_probe` (`err_out_dma_unmap`) and `lpc_eth_drv_remove` must guard `dma_free_coherent` with `!use_iram_for_net(...) || pldat->dma_buff_size > lpc32xx_return_iram(NULL, NULL)` so the static IRAM mapping is never freed. [F6, F27]
- In `__lpc_txrx_desc_setup`, `tx_desc_v`, `tx_buff_v`, `rx_stat_v`, and `rx_buff_v` are aligned via `PTR_ALIGN(..., 16)` inside `pldat->dma_buff_base_v`, relying on `lpc_eth_drv_probe` sizing `pldat->dma_buff_size` with `sizeof(struct rx_status_t)` (8 bytes) instead of `sizeof(u32)` (4 bytes) per TX status slot to cover the alignment padding. [F57]
- In `lpc_eth.c`, `pldat->tx_buff_v` and `pldat->rx_buff_v` are `void *` pointers addressed by byte offset (`+ idx * ENET_MAXF_SIZE`), whereas `tx_desc_v`, `tx_stat_v`, `rx_desc_v`, and `rx_stat_v` are typed pointers indexed by `[idx]`. `lpc_eth_hard_start_xmit` copies `skb->len` bytes into the `ENET_MAXF_SIZE` (1536-byte) slot at `tx_buff_v + txidx * ENET_MAXF_SIZE`, so `ndev->max_mtu` must not allow frames exceeding `ENET_MAXF_SIZE` unless the slot stride and `dma_buff_size` are enlarged. [F78, F79]
