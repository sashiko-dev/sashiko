# NETWORKING [GENERAL]

Core Linux networking infrastructure (`include/linux/`, `include/net/`, `net/core/`, `net/kcm/`, `net/l2tp/`, `net/l3mdev/`, `net/mpls/`), covering `sk_buff`, `net_device`, NAPI/GRO/GSO, sockets, FIB/dst routing, Netlink/Generic Netlink, Qdisc/TC, and tunnels.

## Architecture & Data Flow
- `skb_dst(skb)` may point to a routing `dst_entry` or `struct metadata_dst` (`DST_METADATA`); routing paths must check `skb_valid_dst(skb)` and downcast via `skb_metadata_dst(skb)` while checking `md_dst->type`. `skb->_skb_refdst` encodes `SKB_DST_NOREF` in bit 0 (mask with `SKB_DST_PTRMASK`), and `dst->_metrics` encodes `DST_METRICS_FLAGS` in bits 0..1 (read via `DST_METRICS_PTR()`, write via `dst_metrics_write_ptr()` / `dst_metric_set()`). [F795, F796, F797, F821]
- Attaching a `dst_entry` or `nf_conntrack` to an `sk_buff` must set `skb->slow_gro |= !!val`. `skb->hash`, `skb->sw_hash`, and `skb->l4_hash` must be updated together via `__skb_set_hash()`, `skb_clear_hash()`, or `skb_copy_hash()`. `skb->inner_protocol` and `skb->inner_ipproto` share a union discriminated by `skb->inner_protocol_type` (`skb_set_inner_protocol()` / `skb_set_inner_ipproto()`). `skb->extensions` is only valid when `skb->active_extensions != 0` (`skb_ext_exist()` / `skb_ext_find()`). [F799, F810, F815, F816]
- `skb->napi_id` and `skb->sender_cpu` share a union where `0` is unset, `1..NR_CPUS` is 1-based `sender_cpu` (subtract 1 when indexing CPU arrays or `XPS_CPUS` maps), and `>= MIN_NAPI_ID` (`NR_CPUS + 1`) are valid NAPI IDs (`napi_id_valid()`). `__skb_mark_napi_id()` must check `!napi_id_valid(skb->napi_id)` before writing. [F464, F826]
- Downcasting `struct fib_nh_common *` (e.g., `res->nhc`) to `struct fib_nh *` requires `nhc->nhc_family == AF_INET` because IPv6 nexthops embed `nh_common` in `struct fib6_nh`. In `struct ip_tunnel_info`, `key.u.ipv4` vs `u.ipv6` is discriminated by `ip_tunnel_info_af(info)`, and `ip_tunnel_info_opts_set()` must set `info->options_len = len` before copying into `__counted_by(options_len)` `info->options`. Updating an INET socket's IPv4 address (`sk_daddr_set()`, `sk_rcv_saddr_set()`, `inet_reset_saddr()`) must update the paired IPv6 address when `IS_ENABLED(CONFIG_IPV6)`, and changing `sk_rcv_saddr` on a bound socket requires `inet_bhash2_update_saddr()`. [F45, F48, F74, F78]
- In `__netif_receive_skb_core()`, `ptype_all` taps run before protocol handlers (except `pfmemalloc` SKBs, which skip taps and drop unless `skb_pfmemalloc_protocol(skb)` is true), any deferred `pt_prev` must be flushed via `deliver_skb()` and cleared before `sch_handle_ingress()`, `nf_ingress()`, `vlan_do_receive()`, or `rx_handler(&skb)` can mutate or consume `skb`, and `*ppt_prev != NULL` requires `*pskb != NULL`. [F436, F483, F574]
- Datapath queue selectors (`netdev_pick_tx()`, `netdev_core_pick_tx()`, `__get_xps_queue_idx()`, `netif_get_rxqueue()`, `get_rps_cpu()`) must bound indices against `dev->real_num_tx/rx_queues`, whereas teardown/reset paths iterate up to `dev->num_tx/rx_queues`. In `__netdev_update_features()`, when `NETIF_F_RX_UDP_TUNNEL_PORT` or `NETIF_F_HW_VLAN_CTAG/STAG_FILTER` changes, assign `dev->features` before `*_get_rx_*_info(dev)` when enabling, but after `*_drop_rx_*_info(dev)` when disabling. Query attached XDP programs via `dev_xdp_prog(dev, mode)` rather than `dev->xdp_state[mode].prog`. [F437, F445, F465]

## Synchronization
- `netdev_lock_ops()` only acquires `dev->lock` when `netdev_need_ops_lock(dev)` is true; `dev->request_ops_lock`, `dev->queue_mgmt_ops`, and `dev->netdev_ops->net_shaper_ops` must not change between lock and unlock, and calling a function requiring `netdev_assert_locked(dev)` from an ops-locked section requires `netdev_lock_ops_to_full()` / `netdev_unlock_full_to_ops()`. Locking multiple `net_device`s simultaneously via `netdev_lock()` requires holding `rtnl_lock`. [F195, F205, F333]
- RCU pointers serialized by `dev->lock` must use `netdev_lock_dereference(p, dev)` when holding `dev->lock` outside RCU, whereas `rtnl_dereference(p)` requires `rtnl_lock` (use `rcu_dereference_rtnl(p)` under RCU). Lockless lookups returning a locked `net_device` (`__netdev_put_lock()`, `netdev_napi_by_id_lock()`, `netdev_get_by_index_lock()`, `netdev_xa_find_lock()`) must take `dev_hold()` under `rcu_read_lock()`, drop RCU before `netdev_lock(dev)`, and verify `dev->reg_state <= NETREG_REGISTERED`, `!dev->moving_ns`, and `net_eq(dev_net(dev), net)`. [F335, F546, F783]
- `NETDEV_REGISTER`, `NETDEV_UP`, and `NETDEV_CHANGE` notifiers run with `netdev_lock_ops(dev)` held, so callers emitting them must hold the ops lock and callbacks must call unlocked `netif_*` helpers (e.g., `netif_xdp_propagate()`, `netif_set_promiscuity()`, `netif_state_change()`) rather than locking `dev_*`/`netdev_*` wrappers. Propagating features to lower devices (`netdev_sync_lower_features()`, `netif_disable_lro()`) requires `netdev_lock_ops(lower)` around each lower device. [F408, F409]
- Before `netif_txq_try_stop()`, `netif_txq_maybe_stop()`, or `__netif_txq_completed_wake()`, drivers must update descriptor ring indexes, and `@get_desc` must re-evaluate free descriptors on each read rather than using a cached variable; the stop macros may only be called from `ndo_start_xmit`. [F208, F322]
- Enqueuing or splicing `softnet_data.output_queue` and `completion_queue` requires local hardirqs disabled (`local_irq_save`/`disable`), and detaching `sd->output_queue = NULL` must reset `sd->output_queue_tailp = &sd->output_queue`. `____napi_schedule()` requires hardirqs disabled (`__napi_schedule_irqoff()` falls back to `__napi_schedule()` on `CONFIG_PREEMPT_RT`), and `napi_complete_done()` must atomically check `NAPIF_STATE_MISSED` via `try_cmpxchg(&n->state, ...)` and call `__napi_schedule(n)` if set. [F414, F447, F551, F555]
- Lockless readers of `sk->sk_state` must use `inet_sk_state_load()` paired with `inet_sk_state_store()`. Calling `ip_select_ident*()` on a connected TCP socket requires owning the socket lock (`sock_owned_by_me(sk)`). `fib6_lookup()`, `fib6_table_lookup()` (through `fib6_select_path()`), `fib6_get_cookie_safe()`, and `ip/ip6_dst_mtu_maybe_forward()` (using `dst_dev_rcu()` and `dev_net_rcu()`) require `rcu_read_lock()`. `fib6_add/remove_gc_list()` and `fib6_set/clean_expires()` on table-inserted routes require `tb6_lock`. `dst_cache_get/set*()` require local BH disabled, and invalidating a live `dst_cache` must use `dst_cache_reset()`. [F24, F29, F31, F32, F76, F146, F150, F778, F779]

## Object Lifetimes
- Replacing an `sk_buff` destination via `skb_dst_set()`, `skb_dst_set_noref()`, or `skb_dstref_restore()` requires calling `skb_dst_drop(skb)` first. When `skb_dst_is_noref(skb)` is true, `skb_dst()` requires RCU/RCU-BH protection and `skb_dst_force()` must be called before leaving RCU. Releasing extensions on a live `sk_buff` must use `skb_ext_reset(skb)` (not `skb_ext_put(skb)`), and copying extensions/conntrack onto an `sk_buff` that may already hold one must use `skb_ext_copy()` / `nf_copy()`. [F753, F759, F760, F913]
- `fib_lookup()` always sets `FIB_LOOKUP_NOREF`, returning a borrowed RCU reference in `res->fi` unless held with `fib_info_hold()`. `__inet_lookup*()`, `__inet6_lookup*()`, and `skb_steal_sock()` set `*refcounted = false` for un-refcounted sockets (e.g., listeners); callers must check `*refcounted` before `sock_put(sk)` and use `refcount_inc_not_zero(&sk->sk_refcnt)` if pinning outside RCU. [F13, F23, F188]
- `___neigh_lookup_noref()` and `__neigh_lookup_noref()` return borrowed RCU pointers, whereas `neigh_lookup()`, `neigh_create()`, `__neigh_lookup()`, and `__neigh_lookup_errno()` return refcounted pointers requiring `neigh_release()`. Acquiring a ref under RCU on `neighbour`, `inet6_ifaddr` (`in6_ifa_hold_safe()`), `ipv6_txoptions` (`txopt_get()`), or `struct net` (`maybe_get_net()`) requires `refcount_inc_not_zero()`. `qdisc_replace()` and `dev_graft_qdisc()` return the old `struct Qdisc *` with its reference intact (requiring `qdisc_put()`), and `Qdisc_ops::enqueue` must defer drops onto `*to_free` via `qdisc_drop*()` rather than `kfree_skb()`. [F158, F191, F200, F201, F338, F923]
- `__dev_get_by_name/index()` and `dev_get_by_name/index_rcu()` return borrowed pointers, whereas `dev_get_by_name/index()`, `netdev_get_by_name/index()`, and `mana_get_primary_netdev()` acquire a reference. In `free_netdev()`, if `dev->reg_state == NETREG_UNREGISTERING`, set `dev->needs_free_netdev = true` and return; `mutex_destroy(&dev->lock)` must run after `netif_free_rx_queues(dev)` and `netdev_napi_exit(dev)`; and `NETREG_UNREGISTERED` devices must be freed via `put_device(&dev->dev)` rather than `kvfree(dev)`. [F329, F377, F381, F526, F527]

## API Contracts
- `skb_share_check()`, `skb_unshare()`, `skb_pad()`, `skb_padto()`, `skb_put_padto()`, `neigh_output()`, `neigh_hh_output()`, `nlmsg_unicast()`, and `nlmsg_multicast*()` always consume or free the passed `sk_buff` on both success and error paths, so callers must never free `skb` after calling them. `skb_unclone*()`, `skb_header_unclone()`, `skb_share_check()`, and `skb_unshare()` call `might_sleep_if(gfpflags_allow_blocking(pri))`, so atomic/RCU/softirq callers must pass `GFP_ATOMIC`. [F194, F202, F755, F756, F919]
- Before accessing paged fragments in `__skb_datagram_iter()`, `zerocopy_fill_skb_from_iter()`, or `skb_checksum_help()`, callers must check `skb_frags_readable(skb)` (`__netmem_to_page()` / `__netmem_address()` require page-backed netmem, not `NET_IOV` where `skb_frag_page()` / `skb_frag_address()` return `NULL`). Per-page mappings (`kmap_local_page()`) on fragments must iterate with `skb_frag_foreach_page()`, and TX-to-RX injection paths must use `skb_orphan_frags_rx()`. [F230, F542, F800, F916, F936]
- `sk_to_full_sk()`, `sk_const_to_full_sk()`, and `skb_to_full_sk()` return `NULL` for `TCP_TIME_WAIT` sockets even when input `sk` is non-NULL; `inet_csk(sk)` in generic paths requires `inet_test_bit(IS_ICSK, sk)`; `inet_reqsk(sk)` requires `sk->sk_state == TCP_NEW_SYN_RECV`; and `sk_validate_xmit_skb()` / `psp_sk_get_assoc_rcu()` must distinguish `sk_fullsock(sk)`, `TCP_TIME_WAIT` (`inet_twsk(sk)`), and `TCP_NEW_SYN_RECV`. [F46, F232, F306, F520]
- Before calling any `flow_rule_match_*()` extractor, callers must verify `flow_rule_match_key(rule, FLOW_DISSECTOR_KEY_*)`, and before calling `flow_action_first_entry_get(action)`, callers must verify `flow_action_has_entries(action)`. In `struct nla_policy`, index `0` is reserved and both `policy[]` and `tb[]` must have size `maxtype + 1`; `NLA_NESTED*` `.len` must be `ARRAY_SIZE(nested_policy) - 1`; and Netlink privilege checks must use `netlink_ns_capable()` / `netlink_net_capable()` / `netlink_capable()` rather than `ns_capable()` or `capable()`. [F43, F44, F262, F309, F943]

## Error Handling
- `ip6_route_output*()`, `ip6_route_lookup()`, and `fib6_rule_lookup()` never return `NULL` or `ERR_PTR` (check `dst->error` instead), whereas `ip6_dst_lookup_flow()` and `ip6_sk_dst_lookup_flow()` return `ERR_PTR`. `neigh_lookup()`, `__neigh_lookup()`, and `dst_neigh_lookup*()` return `NULL` on failure, whereas `neigh_create()`, `__neigh_create()`, `__neigh_lookup_errno()`, and `ip_neigh_gw6()` return `ERR_PTR`. `fl6_sock_lookup()`, `inet/inet6_steal_sock()`, `tun_dst_unclone()`, and `l2tp_session_create()` can return `ERR_PTR`. [F37, F42, F111, F224, F622, F788, F790]
- `__INET_ECN_decapsulate()` and `IP/IP6_ECN_decapsulate()` return `0` (ok), `1` (log anomaly, do not drop), or `2` (drop packet), and callers of `__INET_ECN_decapsulate()` must initialize `bool set_ce = false`. `skb_get_dsfield()` returns `0..255` or `-1` (store in signed `int`). `nla_strscpy()` returns `-E2BIG` on truncation (store in signed `ssize_t`). `netif_txq_maybe_stop()` and `__netif_txq_completed_wake()` return `0` (changed), `1` (enabled), or `-1` (race/unchanged). `NL_REQ_ATTR_CHECK()` returns `1` when missing (do not return `1` as an errno). `skb_checksum_validate*()` and `skb_checksum_complete()` return `0` when valid and non-zero `__sum16` when invalid. [F39, F40, F110, F228, F229, F791, F792]
- `Qdisc_ops::init` error paths that free private resources must NULL their pointers in `qdisc_priv(sch)` because `qdisc_create*()` still invokes `Qdisc_ops::destroy`. When `scm_send()` returns `0`, the caller must call `scm_destroy()` on subsequent error paths. When `ethtool_ops::begin` returns `0`, the core always calls `ethtool_ops::complete` even if the callback fails. In `__skb_datagram_iter()`, failing with `-EFAULT` after partial progress must call `iov_iter_revert(to, offset - start_off)`. [F198, F199, F427, F896]

## Known Pitfalls
- Pointers into `skb->head` (`skb->data`, `skb_network_header(skb)`, `skb_shinfo(skb)`) and GRO header pointers become stale across `pskb_may_pull()`, `pskb_expand_head()`, `skb_cow()`, `skb_try_make_writable()`, `skb_gro_header_slow()`, `skb_gro_remcsum_process()`, and `l2tp_v3_ensure_opt_in_linear()`, and in `netif_receive_generic_xdp()`, `netif_skb_check_for_xdp(pskb, ...)` can replace `*pskb` itself. [F131, F451, F663, F814]
- In `struct sk_buff`, `skb->tail` and `skb->end` are offsets on 64-bit (`sk_buff_data_t`), requiring `skb_tail_pointer()` / `skb_end_pointer()`; `transport_header` and `mac_header` use `~0U` (`0xffff`) as unset (`skb_transport/mac_header_was_set()`, and untrusted offsets require `skb_reset_transport_header_careful()`); `skb->csum_start` is relative to `skb->head` (not `skb->data`); and `skb_record_rx_queue()` stores `rx_queue + 1` (requiring `skb_rx_queue_recorded()` before `skb_get_rx_queue()`). [F805, F809, F850, F851, F947]
- `skb_queue_walk()` leaves `skb` pointing to `(struct sk_buff *)(queue)` (not `NULL`) on normal loop termination, and any loop unlinking or freeing elements must use `skb_queue_walk_safe()` or `skb_rbtree_walk_from_safe()`. In `struct qdisc_skb_head`, `skb->prev` is undefined, so non-GSO-list SKBs passed to `qdisc_drop_all()` must have `skb->prev = NULL`. [F284, F854, F855, F857]
- `nla->nla_type` includes `NLA_F_NESTED` / `NLA_F_NET_BYTEORDER` in upper bits, so switches must use `nla_type(nla)`; `NLA_STRING` is not guaranteed NUL-terminated (use `NLA_NUL_STRING` or `nla_strscpy()`/`nla_strdup()`/`nla_strcmp()`); `rem` in `nla_for_each_*()` and `nlmsg_for_each_msg()` must be a signed `int`; `NLA_POLICY_RANGE/MIN/MAX()` bounds are `s16` (use `NLA_POLICY_FULL_RANGE*()` outside `[-32768, 32767]`); and 64-bit attributes must be written with `nla_put_64bit()` / `nla_reserve_64bit()` (sized with `nla_total_size_64bit()`) and read with `nla_get_u64/s64/be64()` (or `nla_get_uint/sint()` for `NLA_UINT`/`NLA_SINT`). `genlmsg_end()` and `genlmsg_cancel()` require the user-header pointer returned by `genlmsg_put*()`. [F55, F263, F266, F267, F286, F301, F310, F312]
- `flow_dissector->used_keys` requires `1ULL << key_id` (`BIT_ULL`); `ip_tunnel_flags_*()` and `gre_build_header()` require `IP_TUNNEL_DECLARE_FLAGS()` bitmaps; `key32_to_tunnel_id()` / `tunnel_id_to_key32()` convert `__be32` keys and `__be64` tunnel IDs; `inet_csk_rto_backoff()`, `reqsk_timeout()`, `psched_l2t_ns()`, and `psched_pkt2t_ns()` must widen 32-bit operands to `u64` before shifting/multiplying; `netdev_stats_to_stats64()` must cast `atomic_long_read()` to `unsigned long` before `u64`; `__inet6_lookup()` takes `hnum` in host byte order (`u16`) whereas `__inet_lookup()` takes `dport` in `__be16`; and `%pNF` requires `&features`. [F57, F89, F114, F115, F140, F297, F495, F523]
