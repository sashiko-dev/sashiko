# SOUNDWIRE SUBSYSTEM

`drivers/soundwire` implements the MIPI SoundWire bus core, Cadence IP library, and Intel (cAVS/ACE1.x/ACE2.x) and AMD (ACP) Manager drivers, handling Master/Slave lifecycles, MIPI DisCo ACPI/DT properties, command/BPT transfers, dynamic bandwidth/bank switching, IRQ domains, and ASoC DAI streams.

## Architecture & Data Flow
- In `sdw_program_device_num()`, initialize `*programmed = false` before any early return, reset `found = false` each outer `do { ... } while` pass, and `return 0` immediately if a matched slave has `status != SDW_SLAVE_UNATTACHED`. In `sdw_handle_slave_status()`, `status[0] == SDW_SLAVE_ATTACHED` returns early only if `id_programmed` is `true`, and `SDW_SLAVE_ATTACHED` from `prev_status == SDW_SLAVE_ALERT` must break without calling `sdw_initialize_slave()`. [F50, F96, F97, F98, F99]
- In `_sdw_compute_port_params()`, skip `m_rt` entries with `stream->state` outside `[SDW_STREAM_CONFIGURED, SDW_STREAM_DISABLED]`. In `sdw_compute_group_params()`, accumulate `payload_bw` for target `stream` only in `SDW_STREAM_CONFIGURED` and other streams in `ENABLED`, `PREPARED`, or `DISABLED`, using ceiling division `(sel_col * payload_bw + full_bw - 1) / full_bw` for `hwidth`. [F93, F94, F113]
- `prop->lane_maps[]` only stores manager lanes in `1..SDW_MAX_LANES - 1`, and lane 0 reserves column 0 (`column_needed <= sel_col - 1`). When `get_manager_lane()` assigns lane `l > 0`, add `required_bandwidth` to `bus->lane_used_bandwidth[l]` and subtract it from `bus->params.bandwidth`; `sdw_compute_bus_params()` relies on `m_rt` at `out:` still pointing to the `goto out` entry to update `lane`. In `sdw_compute_slave_ports()`, reset `port_bo = t_data->block_offset` for the next slave only when `m_rt->direction == SDW_DATA_DIR_TX && m_rt->ch_count == slave_total_ch`. [F68, F80, F104, F105]
- `slave->prop.src_dpn_prop` and `sink_dpn_prop` are dense arrays of length `hweight32(ports)`—always look up ports via `sdw_get_slave_dpn_prop()` rather than indexing by port number. In `sdw_handle_slave_alerts()`, port interrupts map to `0..14` via `FIELD_GET(SDW_SCP_INT1_PORT0_3, buf)`, `bit + 4` (`INTSTAT2_PORT4_10`), and `bit + 11` (`INTSTAT3_PORT11_14`). In `sdw_handle_dp0_interrupt()` and `sdw_handle_port_interrupt()`, keep `SDW_DP0_SDCA_CASCADE` cleared in `clear` and intersect `status &= status2` on retry. [F69, F78, F79]
- On Intel links, device numbers `1..5` (`< SDW_INTEL_DEV_NUM_IDA_MIN`) are for non-wake-capable slaves and `6..11` (`intel_peripheral_ida`) for wake-capable slaves. In `sdw_cdns_config_stream()`, `pdi->num` 0 and 1 both map to DataPort 0 for BPT/BRA, and `pdi->intel_alh_id` adds `+ 2` when `pdi->num >= 2`. In `cdns_port_params()` / `cdns_transport_params()`, when `target_num == cdns->pdi_loopback_target && cdns->pdi_loopback_source != -1`, copy banked registers directly from `pdi_loopback_source` without applying `p_params`/`t_params`. [F71, F75, F81]
- Keep `cdns->msg_count` synced with `CDNS_MCP_FIFOLEVEL` across `sdw_cdns_init()`, `_cdns_xfer_msg()`, and `cdns_program_scp_addr()`. Size `cdns->response_buf` at `CDNS_MCP_CMD_LEN + 2` and clamp `CDNS_MCP_FIFOSTAT & CDNS_MCP_RX_FIFO_AVAIL` to `ARRAY_SIZE(cdns->response_buf)`. In `cdns_fill_msg_resp()`, check `if (nack)` (`CDNS_MCP_RESP_NACK`) independently and before `if (no_ack)`. [F63, F76, F92]
- In `sdw_cdns_copy_write_data()` and `sdw_cdns_prepare_write_pd0_buffer()`, interleave bytes at `dma_buffer[(2 * i) - (i & 1)]` with big-endian `start_register` in `header[2..5]`, `dma_buffer[3]` set to `BIT(7) | (frame_counter & GENMASK(3, 0))`, `last_byte[0]` set to `BIT(6)`, and mask the rolling counter in `sdw_cdns_check_{write,read}_response()` with `GENMASK(3, 0)` on each increment so 15 wraps to 0. [F83, F116]
- In `sdw_intel_ctx` and `sdw_amd_ctx`, `ldev[i]` and `pdev[i]` are only populated where `ctx->link_mask & BIT(i)` is set. In `amd_manager.c`, updates to shared `acp_mmio` (`ACP_EXTERNAL_INTR_CNTL`, `AMD_SDW_DEVICE_STATE`) and shared port registers (`frame_fmt_reg`, `lane_ctrl_ch_en_reg`) must use masked read-modify-write, and `AMD_SDW_MCP_SLAVE_STATUS_8TO_11` must use `GENMASK_ULL(15, 0)` before shifting left by 32. [F47, F70, F111]

## Synchronization
- Lock acquisitions must follow `cdns->status_update_lock` -> `bus->bus_lock` -> `slave->sdw_dev_lock` -> `bus->msg_lock` -> `sdw->link_res->shim_lock`. In `sdw_master_rt_alloc()`, insert `sdw_master_runtime` nodes into `stream->master_list` in ascending `bus->id` order so `sdw_acquire_bus_lock()` and `do_bank_switch()` lock multiple buses in a global order. [F27, F152]
- Every bus path invoking `struct sdw_slave_ops` callbacks (`clk_stop`, `interrupt_callback`, `update_status`, `port_prep`, `bus_config`) must hold `slave->sdw_dev_lock`, verify `slave->probed` is true, and resolve `drv->ops` inside that critical section. Dispatch `handle_nested_irq(slave->irq)` from process/workqueue context (`sdw_handle_slave_alerts()`) outside `slave->sdw_dev_lock`. [F24, F159]
- Under `bus->bus_lock`: `sdw_modify_slave_status()` updates `slave->status` and calls `reinit_completion()` (on `SDW_SLAVE_UNATTACHED`, where `sdw_clear_slave_status()` also resets `first_interrupt_done = false`) or `complete_all()` (never `init_completion()`/`complete()`) on `enumeration_complete` and `initialization_complete`; `sdw_get_device_num()` sets `bus->assigned` while keeping `slave->dev_num == 0` until `sdw_write_no_pm(slave, SDW_SCP_DEVNUMBER, ...)` succeeds. [F33, F34, F36, F61]
- In `do_transfer_defer()`, initialize `bus->defer_msg.msg`, `length`, and `init_completion(&bus->defer_msg.complete)` under `bus->msg_lock` before `xfer_msg_defer(bus)`. In `do_bank_switch()`, hold `bus->msg_lock` continuously across `pre_bank_switch()`, `sdw_bank_switch()`, `post_bank_switch()`, and `sdw_ml_sync_bank_switch()`, freeing and clearing `bus->defer_msg.msg = NULL` before unlocking. [F19, F29]
- In `sdw_cdns_irq()`, mask `CDNS_MCP_INT_SLAVE_MASK` in `CDNS_MCP_INTMASK` and defer to `cdns->work` only if `cdns->interrupt_enabled` is true. `cdns_update_slave_status_work()` must clear `CDNS_MCP_INTSTAT` and `CDNS_MCP_SLAVE_INTSTAT0/1` before `cdns_update_slave_status()` (never inside the retry loop). `sdw_cdns_enable_interrupt()` must clear stale `SLAVE_INTSTAT0/1` on enable and set `interrupt_enabled = false` + `cancel_work_sync(&cdns->work)` before zeroing masks on disable, and all `sdw_handle_slave_status()` calls in `cadence_master.c` must hold `cdns->status_update_lock`. [F31, F35, F132, F154]
- Slave initialization, enumeration, alert, and clock-stop helpers invoked along runtime PM or `sdw_handle_slave_status()` paths (`sdw_slave_set_frequency()`, `sdw_initialize_slave()`, `sdw_slave_clk_stop_prepare()`) must use `_no_pm` register accessors to avoid runtime PM deadlocks. [F149]

## Object Lifetimes
- Once `device_register()` is called in `sdw_master_device_add()` or `sdw_slave_add()`, failure paths must call `put_device()` (and unlink `slave->node` under `bus->bus_lock` in `sdw_slave_add()`) rather than `kfree()`. In `intel_link_dev_register()`, call `kfree(ldev)` if `auxiliary_device_init()` fails, or `auxiliary_device_uninit()` if `auxiliary_device_add()` fails. [F1, F2, F3]
- `sdw_bus_master_add()` registers lockdep keys (`msg_lock_key`, `bus_lock_key`) and calls `sdw_irq_create()` before enumerating slaves. `sdw_bus_master_delete()` must unregister all child slaves via `sdw_delete_slave()` (which clears non-zero `slave->dev_num` in `bus->assigned` and calls `put_device_num` under `bus->bus_lock`) and call `sdw_irq_delete(bus)` before `sdw_master_device_del(bus)`. `sdw_drv_probe()` allocates `slave->index` from `bus->slave_ida` before `drv->probe()` and frees it on error and in `sdw_drv_remove()`. [F6, F7, F8, F18, F126]
- In `sdw_nread()`, `sdw_nwrite()`, `sdw_handle_slave_alerts()`, `sdw_slave_reg_show()`, and `cmd_go()`, `pm_runtime_*` calls must target `&slave->dev` (never `slave->bus->dev`); if `pm_runtime_get_sync(&slave->dev)` returns a negative error other than `-EACCES`, call `pm_runtime_put_noidle(&slave->dev)` before returning, whereas `-EACCES` proceeds and balances at normal exit. [F11, F101]
- In `intel_link_power_up()` / `intel_link_power_down()`, active links are tracked in `*sdw->link_res->shim_mask` under `shim_lock`, and `intel_link_power_down()` must set `sdw->cdns.link_up = false` under `shim_lock` before switching I/O control or clearing CPA. In `intel_post_bank_switch()`, call `sdw_intel_sync_go_unlocked(sdw)` only if `sdw_intel_sync_check_cmdsync_unlocked(sdw)` is true under `shim_lock`. [F12, F23, F107]
- Errors after `sdw_intel_link_power_up(sdw)` in `intel_link_startup()`, `intel_resume()`, or `intel_resume_runtime()` must call `sdw_intel_link_power_down(sdw)`. In `intel_stop_bus()` and `intel_link_remove()`, `cancel_delayed_work_sync(&cdns->attach_dwork)` and `sdw_cdns_enable_interrupt(cdns, false)` must precede link power-down or bus deletion. In `amd_suspend()` and `amd_sdw_manager_remove()`, `cancel_work_sync(&amd_manager->amd_sdw_work)` must precede stopping the clock, disabling IRQs, or deleting the bus. [F13, F21, F22]
- When `!ldev->link_res.clock_stop_quirks`, balance parent `pm_runtime_get_noresume()` in `sdw_intel_startup_controller()` with `pm_runtime_put_noidle()` in `sdw_intel_cleanup()`. `intel_suspend()` must call `pm_runtime_disable(dev)` before checking `pm_runtime_status_suspended(dev)`, and `intel_resume()` must call `pm_runtime_set_active(dev)` before `pm_runtime_enable(dev)`. [F14, F140]
- In `intel_ace2x_bpt_open_stream()`, unwind errors in reverse order (`hda_sdw_bpt_close()`, `sdw_deprepare_stream()`, `sdw_stream_remove_master()`, `sdw_stream_remove_slave()`, `sdw_release_stream()`, `cdns->bus.bpt_stream = NULL`). DAI `.hw_params` must not cache the stack `snd_pcm_hw_params *` in `dai_runtime`, and `sdw_transfer_defer()` callers must keep `msg` and `msg->buf` valid until `bus->defer_msg.complete` completes. [F16, F117, F119]

## API Contracts
- Single-byte reads (`sdw_read*()`, `sdw_bread_no_pm*()`) return a signed `int` that must be checked `< 0` before truncating to `u8`. In `sdw_update*()`, `cdns_updatel()`, `cdns_ip_updatel()`, and `amd_updatel()`, `val` is ORed directly into `(tmp & ~mask) | val` and must be pre-shifted and masked. [F39, F53]
- `sdw_fill_msg()` must `memset(msg, 0, sizeof(*msg))`, reject `addr >= SDW_REG_MAX`, and require a non-NULL `slave` with `prop.paging_support` and `dev_num` not `SDW_ENUM_DEV_NUM`/`SDW_BROADCAST_DEV_NUM` for paged addresses (`>= SDW_REG_NO_PAGE`). Multi-byte transfers must split at 32KB boundaries (`(SDW_REGADDR + 1) - (addr & SDW_REGADDR)`), and `sdw_nread*()`/`sdw_nwrite*()`/`sdw_update*()` are not atomic across pages or across read-modify-write. [F37, F51, F72, F73]
- `sdw_master_ops.xfer_msg` returns `enum sdw_command_response`, mapped by `find_response_code()` to `0`, `-ENODATA` (`SDW_CMD_IGNORED`), `-ETIMEDOUT`, or `-EIO`. `cdns_xfer_msg()` chunks transfers into batches of `<= CDNS_MCP_CMD_LEN` (8), while `cdns_xfer_msg_defer()` rejects `msg->len > 1` with `-ENOTSUPP`. [F44, F77]
- `sdw_cdns_bpt_find_buffer_sizes()` takes `command = 0` for write and `1` for read (opposite of `SDW_MSG_FLAG_READ`/`WRITE`), requires `sdw_cdns_bra_actual_data_size(bpt_bytes) > 0` (`>= 10` bytes/frame), sizes all write frames at `actual_bpt_bytes`, and sizes the final read PDI1 frame at `sdw_cdns_read_pdi1_buffer_size(data_bytes % actual_bpt_bytes)`. In `intel_ace2x_bpt_wait()`, `hda_sdw_bpt_wait()` and `sdw_disable_stream()` must finish before checking responses in `dmab_rx_bdl.area`, and `intel_ace2x_bpt_close_stream()` must run after. [F54, F82, F114, F160]
- Check `is_sdw_slave(dev)` before `dev_to_sdw_dev(dev)` in `sdw_bus_type` callbacks. `sdw_handle_slave_status()` requires `status[SDW_MAX_DEVICES + 1]`. `sdw_fill_xport_params()` takes `port_bo` as `off1` and `port_bo >> 8` as `off2`. In `sdw_drv_probe()`, `drv->ops->read_prop(slave)` must precede `sdw_irq_create_mapping(slave)` and `sdw_slave_sysfs_dpn_init(slave)`. ASoC `.get_stream` returns `ERR_PTR(-EINVAL)` when `dai_runtime` is NULL, and `.set_stream` rejects duplicate non-NULL or duplicate NULL calls with `-EINVAL`. [F45, F55, F74, F165, F167]
- On multi-link Intel controllers, `intel_start_bus*()` must call `sdw_intel_sync_arm()` before `sdw_cdns_init()` and `sdw_intel_sync_go()` between `sdw_cdns_config_update()` and `sdw_cdns_config_update_set_wait()`. On AMD managers, wake IRQs are enabled in `amd_suspend_runtime()` and disabled in `amd_suspend()`, and `AMD_SDW_POWER_OFF_MODE` must call `amd_sdw_clock_stop()` before `amd_deinit_sdw_manager()`. [F137, F142]

## Error Handling
- `do_transfer()`, `do_transfer_defer()`, and `sdw_transfer_unlocked()` must neither retry `-ENODATA` (`SDW_CMD_IGNORED`) responses nor log them with `dev_err()`, and `sdw_ntransfer_no_pm()` ignores negative `sdw_transfer()` returns when `slave->is_mockup_device` is true. In `sdw_drv_probe()`, errors from `sdw_slave_sysfs_dpn_init()` or `drv->ops->update_status()` must only log `dev_warn()`. In `sdw_{intel,amd}_probe_controller()`, if an error occurs after registering at loop index `i`, increment `i++` before jumping to the `while (i--)` unwind label `err:`. [F88, F171, F172, F173]
- In `sdw_handle_slave_alerts()`, always clear `SDW_SCP_INT1_PARITY`, but log `dev_err()` only when set in `slave->prop.scp_int1_mask` and `!(!slave->first_interrupt_done && (slave->prop.quirks & SDW_SLAVE_QUIRKS_INVALID_INITIAL_PARITY))`. Use `dev_err_ratelimited()` / `dev_dbg_ratelimited()` for error/status logs in `cdns_fill_msg_resp()`, `sdw_cdns_irq()`, and `amd_sdw_fill_msg_resp()`. [F174, F175]

## External Contracts
- Debugfs write handlers mutating hardware or bus state must call `add_taint(TAINT_USER, LOCKDEP_STILL_OK)`. Debugfs dump helpers (`sdw_sprintf`, `cdns_sprintf`, `intel_sprintf`) must use `scnprintf(buf + ret, RD_BUF - ret, ...)`, and `cmd_go()` must initialize `fw = NULL` before any `goto out`, read `start_t`/`finish_t` only before `out:`, and validate `start_addr <= SDW_REG_MAX`, `num_bytes` in `1..MAX_CMD_BYTES`, and `fw->size >= num_bytes`. [F58, F89, F169, F170]

## Known Pitfalls
- In `amd_sdw_send_cmd_get_resp()`, clear W1C bit `AMD_SDW_IMM_RES_VALID` in `ACP_SW_IMM_CMD_STS` by writing `AMD_SDW_IMM_RES_VALID` and polling until cleared; because `amd_sdw_send_cmd_get_resp()` returns a `u64` sign-extending `-ETIMEDOUT` (`0xffffffffffffff92`, which has `BIT(1)` / `AMD_SDW_MCP_RESP_NACK` set), callers must check `response == -ETIMEDOUT` before testing `AMD_SDW_MCP_RESP_NACK`. [F110, F134]
- Read MIPI DisCo boolean properties in `mipi_disco.c` with `mipi_fwnode_property_read_bool()` or `mipi_device_property_read_bool()` (which read a `u8`), never `fwnode_property_read_bool()` or `device_property_read_bool()`. In `intel_pm_prepare()`, when both the link auxiliary device and parent PCI device are runtime-suspended with clock-stop enabled, runtime-resume the link device and its probed attached child slaves before `intel_suspend()` runs. [F86, F141]
- In `sdw_bus_exit_clk_stop()` and `sdw_bus_prep_clk_stop()`, do not dereference `slave` after `list_for_each_entry(slave, &bus->slaves, node)` finishes (log via `bus->dev`). Copy narrower bitmasks (`u8` status in `sdw_handle_slave_alerts()`, `int ports` in `sdw_slave_read_dpn()`) to an `unsigned long` before `for_each_set_bit()`. [F95, F125]
