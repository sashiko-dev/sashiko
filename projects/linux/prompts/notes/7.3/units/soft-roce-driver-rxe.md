# SOFT-ROCE DRIVER (rxe)

The Soft-RoCE (`rxe`) driver (`drivers/infiniband/sw/rxe`) is a pure software implementation of the RDMA over Converged Ethernet (RoCE v2) transport protocol in the Linux InfiniBand subsystem, encapsulating RDMA BTH packets over UDP tunnels (port 4791) and exposing InfiniBand verbs, user-mapped lockless queues, Memory Regions/Windows, and On-Demand Paging (ODP).

## Architecture & Data Flow

- MR and MW keys encode the pool XArray index in bits 31..8 (`key >> 8`) and an 8-bit key in bits 7..0 (`key & 0xff`). Lookups in `mr_pool` or `mw_pool` via `rxe_pool_get_index()` must pass `key >> 8` and verify the full 32-bit `key` against `mr->lkey`/`mr->rkey` or `mw->rkey` (calling `rxe_put()` on mismatch; in `rxe_invalidate_mr()`, checking `mr->rkey` if `RXE_ACCESS_REMOTE` else `mr->lkey`, plus `IB_MR_TYPE_MEM_REG` and `atomic_read(&mr->num_mw) == 0`), while `rxe_reg_fast_mr()` and `rxe_do_bind_mw()` must preserve the upper 24 bits (`~0xff`). [F56, F77, F92]
- `lookup_mr()` and `rxe_lookup_mw()` must check access permissions with `((access & mr->access) != access)` and `((access & mw->access) != access)` so multi-bit masks require all flags and `access == 0` succeeds. [F106]
- Kernel DMA and fast-reg MRs have `mr->umem == NULL`: code must check `is_odp_mr(mr)` rather than dereferencing `mr->umem->is_odp`, and check `mr->ibmr.type == IB_MR_TYPE_DMA` before accessing `mr->page_list`. Every MR operation with an ODP split (`rxe_mr_init_user`, `rxe_mr_copy`, `rxe_flush_pmem_iova`, `rxe_mr_do_atomic_op`, `rxe_mr_do_atomic_write`) must have a matching implementation in `rxe_odp.c` and `!CONFIG_INFINIBAND_ON_DEMAND_PAGING` stubs in `rxe_loc.h`. [F44, F82]
- `rxe_check_pagefault()` must test each `umem_odp->map.pfn_list[idx]` entry against `HMM_PFN_VALID` rather than a caller permission mask that can be zero for read-only pagefaults (`RXE_PAGEFAULT_RDONLY`). [F103]
- In `rxe_resp.c`, `get_req()` routes any packet to `RESPST_READ_REPLY` whenever `qp->resp.res` is non-NULL; single-packet responder operations that set `qp->resp.res` (`send_atomic_ack()` and `send_read_response_ack()`) and completed `read_reply()` flows must clear `qp->resp.res = NULL`. [F74]
- When `qp->srq` is set, `get_srq_wqe()` must verify `wqe->dma.num_sge <= srq->rq.max_sge` before copying `sizeof(*wqe) + wqe->dma.num_sge * sizeof(struct rxe_sge)` bytes into `qp->resp.srq_wqe` (where `srq_wqe.sge[RXE_MAX_SGE]` must immediately follow `srq_wqe.wqe`), set `qp->resp.wqe = &qp->resp.srq_wqe.wqe`, and advance the SRQ consumer under `srq->rq.consumer_lock`; `do_complete()` must only advance `qp->rq.queue` when `!qp->srq`. [F69, F133]
- When `rxe_completer()` clears a requester stall flag (`qp->req.wait_fence`, `qp->req.wait_psn`, `qp->req.need_rd_atomic`) or sets `qp->req.need_retry = 1`, it must also set `qp->req.again = 1`. When scheduling `qp->rnr_nak_timer` in `COMPST_RNR_RETRY`, it must set `qp->req.wait_for_rnr_timer = 1`; `rxe_requester()` must not call `req_retry()` while `wait_for_rnr_timer` is set, and `rnr_nak_timer()` and QP reset paths must clear it. [F63, F64]
- Every path in `rxe_requester()` that jumps to `err:` (including `IB_QPS_ERR` flush and `rxe_do_local_ops()` failures) must set `wqe->status` to a non-`IB_WC_SUCCESS` status before `err:` marks `wqe->state = wqe_state_error`. [F65]
- In `rxe_qp_from_attr()`, `IB_QP_SQ_PSN` must mask `attr->sq_psn` with `BTH_PSN_MASK` and update `qp->attr.sq_psn`, `qp->req.psn`, and `qp->comp.psn` together; `IB_QP_RQ_PSN` must update `qp->attr.rq_psn` and `qp->resp.psn`; and `IB_QP_MAX_QP_RD_ATOMIC` must set `qp->attr.max_rd_atomic` and `qp->req.rd_atomic` to the same power-of-two rounded value. [F58, F59]
- 24-bit PSNs stored in `u32` fields must be masked with `BTH_PSN_MASK` after arithmetic and compared only via `psn_compare()`. In `update_wqe_psn()` and `rxe_prepare_res()`, packet counts must use ceiling division by `qp->mtu` clamped to at least 1 so zero-length operations consume 1 PSN. [F122, F124]
- Packet builders (`finish_packet()` and `read_reply()`) must zero `bth_pad(pkt)` trailing bytes at `payload_addr(pkt) + payload` before `rxe_xmit_packet()` computes the ICRC, and `execute()` must zero `hdr.reserved` in `union rdma_network_hdr` before copying IPv4 UD/GSI headers into the receive WQE. [F54]

## Synchronization

- `qp->state_lock`, `task->lock`, `cq->cq_lock`, `qp->sq.sq_lock`, `rq->producer_lock`, and `rq->consumer_lock` must always use `spin_lock_irqsave()`/`spin_unlock_irqrestore()` (never `spin_lock()` or `spin_lock_bh()`), and lock order is `qp->state_lock` before `task->lock`. `rxe->mcg_lock` and `port->port_lock` must use `spin_lock_bh()`/`spin_unlock_bh()`, keeping `GFP_KERNEL` allocations and `rxe_mcast_add()`/`rxe_mcast_del()` outside `rxe->mcg_lock`. [F151, F152, F153]
- In `rxe_cq_post()`, checking `queue_full()`, writing the CQE, advancing the producer index, testing/clearing `cq->notify`, and calling `cq->ibcq.comp_handler()` must all occur under a single `cq->cq_lock` critical section. Conversely, `comp_check_sq_drain_done()`, `req_check_sq_drain_done()`, `rxe_cq_post()`, and `get_srq_wqe()` must release their spinlock (`qp->state_lock`, `cq->cq_lock`, or `srq->rq.consumer_lock`) after clearing the one-shot trigger before invoking `event_handler`. [F26, F33]
- Pool objects looked up by index (`rxe_ah`, `rxe_qp`, `rxe_mr`, `rxe_mw`) reserve an XArray slot with `NULL` in `__rxe_add_to_pool()` and must not be published via `rxe_finalize()` until all fields, locks, tasks, and keys are initialized. [F17]
- In `rxe_qp_do_cleanup()` (run in process context via `execute_in_process_context()`), `qp->valid` must be cleared under `qp->state_lock`, RC timers stopped with `timer_delete_sync()`, and `recv_task`/`send_task` drained via `rxe_cleanup_task()` before calling `rxe_sender()`/`rxe_receiver()` directly and freeing queues or references. In `rxe_qp_reset()`, `recv_task` and `send_task` must be drained via `rxe_disable_task()` before resetting queues and `qp->req`/`qp->resp`, and re-enabled via `rxe_enable_task()` afterward. [F22, F23, F157]
- After enqueuing `skb` onto `qp->resp_pkts` (`rxe_comp_queue_pkt()`) or `qp->req_pkts` (`rxe_resp_queue_pkt()`), the caller must not dereference `skb` or `SKB_TO_PKT(skb)`. [F25]
- `rxe_odp_do_pagefault_and_lock()` locks `umem_odp->umem_mutex` on non-negative return (`>= 0`) and leaves it unlocked on error; any access to `umem_odp->map.pfn_list` must hold `umem_odp->umem_mutex` via `rxe_odp_map_range_and_lock()` and call `mutex_unlock(&umem_odp->umem_mutex)` on every path after success. [F14, F30]
- `do_mmap_info()` must complete `copy_to_user()` before taking `rxe->pending_lock` and adding `ip->pending_mmaps` to `rxe->pending_mmaps`. `rxe_queue_resize()` must allocate the new queue buffer and call `do_mmap_info()` before acquiring `consumer_lock` then `producer_lock` to copy elements and swap `*q` and `*new_q` in `resize_finish()`. [F19, F32]
- `queue_get_producer()` and `queue_get_consumer()` must read peer-owned ring indices from `q->buf` with `smp_load_acquire()`, paired with `smp_store_release()` in `queue_advance_producer()` and `queue_advance_consumer()`. For user-shared queues (`QUEUE_TYPE_FROM_CLIENT` and `QUEUE_TYPE_TO_CLIENT`), the driver must maintain its own index in `q->index` rather than reading `q->buf`, and mask peer indices with `q->index_mask` (`queue_addr_from_index()`). [F34, F163]
- In `rxe_bind_mw()` and `rxe_invalidate_mw()`, state validation (`rxe_check_bind_mw()`, `rxe_check_invalidate_mw()`) and updates (`rxe_do_bind_mw()`, `rxe_do_invalidate_mw()`) must run together under `spin_lock_bh(&mw->lock)`. [F37]
- Responder atomic operations (`rxe_mr_do_atomic_op()`, `rxe_odp_do_atomic_op()`, `rxe_mr_do_atomic_write()`, `rxe_odp_do_atomic_write()`) must validate `mr->state == RXE_MR_STATE_VALID`, `mr_check_range(mr, iova, sizeof(u64))`, and 8-byte alignment (`!(page_offset & 0x7)`, returning `RESPST_ERR_MISALIGNED_ATOMIC`) before indexing `u64 *va` as `va[page_offset >> 3]`. Compare-swap/fetch-add must hold `atomic_ops_lock`; atomic write must use `smp_store_release(&va[page_offset >> 3], value)`; and `process_flush()` must issue `wmb()` before advancing `qp->resp.psn`. [F78, F95, F138, F167]

## Object Lifetimes

- Once `rxe_send()` or `rxe_loopback()` sets `skb->destructor = rxe_skb_tx_dtor`, takes `sock_hold(sk)` and `rxe_get(pkt->qp)`, and increments `pkt->qp->skb_out`, any subsequent error path calling `kfree_skb(skb)` must not manually release `qp`, `sk`, or `skb_out`. [F1]
- Every `sk_buff` queued on `qp->req_pkts` or `qp->resp_pkts` holds both `rxe_get(qp)` and `ib_device` (`qp->ibqp.device`) references that must be released alongside `kfree_skb(skb)` when dequeued (`cleanup()`, `drain_req_pkts()`, `free_pkt()`, `drain_resp_pkts()`). In `rxe_rcv_mcast_pkt()`, non-final entries in `mcg->qp_list` receive an `skb_clone()` while the original `skb` goes only to the final entry (`skb = NULL`) so the post-loop check frees `skb` and drops `&rxe->ib_dev` if the last entry is skipped. [F3, F113]
- `__rxe_cleanup()` must erase `elem->index` from `pool->xa` and call `__rxe_put(elem)` before waiting on `elem->complete`, and must wait for completion before calling `pool->cleanup(elem)`. Unlike core-allocated verbs objects, `struct rxe_mr` is driver-allocated with `kzalloc()` and must be freed via `kfree(mr)` on init failure and `kfree_rcu_mightsleep(mr)` in `rxe_dereg_mr()` after `rxe_cleanup(mr)`. [F8, F20, F189]
- Whenever `qp->resp.mr` is released (`read_reply()`, `cleanup()`, `do_class_d1e_error()`, `rxe_qp_reset()`), it must be set to `NULL` to prevent `WARN_ON_ONCE(qp->resp.mr)` in `check_rkey()` and double-puts. [F9]
- Every MW bind/unbind on `mw->mr` must pair `rxe_get(mr)`/`rxe_put(mr)` with `atomic_inc(&mr->num_mw)`/`atomic_dec(&mr->num_mw)` and clear `mw->mr = NULL` on unbind; QP `rcq`/`scq` binding in `rxe_qp_from_init()` and `rxe_qp_do_cleanup()` must similarly pair `rxe_get(cq)`/`rxe_put(cq)` with `atomic_inc(&cq->num_wq)`/`atomic_dec(&cq->num_wq)`. [F10, F60]
- `resize_finish()` swaps `*q` and `*new_q` in place (`swap(*q, *new_q)`) and `rxe_queue_resize()` unconditionally calls `rxe_queue_cleanup(new_q)`; callers must not cache `q->buf` or element pointers across resize. `rxe_queue_cleanup()` releases `q->ip->ref` when `q->ip` is set (after `do_mmap_info()`) and calls `vfree(q->buf)` directly only when `q->ip` is NULL. [F7, F50, F139]
- `rxe_get_dev_from_net(ndev)` must be paired with `ib_device_put(&rxe->ib_dev)` and `rxe_ib_device_get_netdev(ibdev)` with `dev_put(ndev)`. Once `ib_register_device()` succeeds in `rxe_register_device()`, `rxe` must not be dereferenced. [F12, F144]
- Under `task->lock`, `__reserve_if_idle()` sets `TASK_STATE_BUSY`, increments `task->num_sched`, and calls `rxe_get(task->qp)`; `do_task()` must increment `task->num_done` and call `rxe_put(task->qp)` on all exit paths. [F16]

## API Contracts

- `rxe_xmit_packet()` always consumes `skb`, so callers (`rxe_requester()`, `read_reply()`, `send_common_ack()`) must never free `skb` after calling it, even on error. [F2]
- `rxe_get_av(pkt, ahp)` returns a borrowed `struct rxe_av *` when `ah_num == 0`, but when `ah_num != 0` on UD/GSI WQEs it acquires a pool reference on `*ahp` (when `ahp` is non-NULL) that the caller must release with `if (ah) rxe_put(ah)`. [F11, F178]
- `rxe_pool_get_index()`, `lookup_mr()`, `rxe_lookup_mw()`, `rxe_recheck_mr()`, and `rxe_lookup_mcg()` return `NULL` (never `ERR_PTR`) on failure; callers must test `!ptr` rather than `IS_ERR(ptr)`. [F38]
- `rxe_mr_do_atomic_op()`, `rxe_mr_do_atomic_write()`, `rxe_odp_atomic_op()`, and `rxe_odp_do_atomic_write()` return `enum resp_states` (`RESPST_NONE` or `RESPST_ERR_*`), never negative errnos. Task callbacks (`rxe_sender()`, `rxe_requester()`, `rxe_completer()`, `rxe_receiver()`) return `0` to continue and `-EAGAIN` when idle. [F41, F43]
- For zero-length RDMA Read/Write (`reth_len(pkt) == 0`), `check_rkey()` leaves `qp->resp.mr = NULL`, whereas `rxe_flush_pmem_iova()` requires a non-NULL `mr`. Because `rxe_odp_map_range_and_lock()` rejects `length < 1`, `rxe_mr_copy()`, `rxe_odp_mr_copy()`, and `rxe_flush_pmem_iova()` must return `0` when `length == 0` before checking `!mr` (in `rxe_mr_copy()`) or calling ODP mapping helpers. [F45, F110]
- `rxe_create_ah()` and `rxe_destroy_ah()` can run in atomic context and must pass `RDMA_CREATE_AH_SLEEPABLE` / `RDMA_DESTROY_AH_SLEEPABLE` via `rxe_add_to_pool_ah()` and `rxe_cleanup_ah()`. `do_mmap_info()` and `rxe_create_mmap_info()` must only be called when `outbuf != NULL`. [F136, F156]

## Error Handling

- Because `rxe_create_qp()` calls `rxe_cleanup(qp)` when `rxe_qp_from_init()` fails midway, `rxe_qp_do_cleanup()`, `flush_send_queue()`, and `flush_recv_queue()` must NULL-check optional/partially initialized fields (`sq.queue`, `rq.queue`, `srq`, `scq`, `rcq`, `pd`, `sk`, timers, tasks). On `err_cleanup:` paths, callers must store the return value of `rxe_cleanup()` in `cleanup_err` so `0` does not overwrite `err`. [F46, F51]
- In `rxe_ib_advise_mr_prefetch()`, if `lookup_mr()` fails at index `i`, the `err:` loop must call `rxe_put(work->frags[i].mr)` for all prior indices `0..i-1` before `kvfree(work)`. [F15]
- In `rxe_resp_check_length()`, the combined `RXE_START_MASK && RXE_END_MASK` check must precede individual `RXE_START_MASK`/`RXE_END_MASK` branches; MTU checks apply only to RC/UC QPs; and for UD/GSI QPs it must verify `payload_size(pkt) + sizeof(union rdma_network_hdr)` fits in the recv WQE SGEs before `execute()`. [F90, F105]
- Wire/user error paths must use ratelimited `rxe_dbg*`/`rxe_err*` macros (not `WARN_ON`/`pr_err`), and `rxe_dbg_<obj>()`/`rxe_err_<obj>()` must never be called on a NULL pointer or before `rxe_add_to_pool()` and `mr->ibmr.device` initialization. [F49, F190]

## External Contracts

- In `rxe_post_send()`, `rxe_post_send_kernel()`, `rxe_post_recv()`, and `rxe_post_srq_recv()`, any WR failure (other than `!qp->valid`) must set `*bad_wr = wr`, and `rxe_post_send_kernel()` must still call `rxe_sched_task(&qp->send_task)` whenever `good > 0`. [F66, F188]
- CQE builders (`make_send_cqe()`, `flush_send_wqe()`, `do_complete()`, `flush_recv_wqe()`) must zero `cqe` and populate `cqe.uibwc` when `qp->is_user`/`qp->rcq->is_user` or `cqe.ibwc` when kernel-space. [F186]
- In `rxe_ib_invalidate_range()`, if `!mmu_notifier_range_blockable(range)`, return `false` without taking `umem_odp->umem_mutex`; otherwise lock `umem_odp->umem_mutex`, call `mmu_interval_set_seq(mni, cur_seq)` before `ib_umem_odp_unmap_dma_pages()`, and return `true`. [F179]

## Known Pitfalls

- `struct rxe_pkt_info` in `skb->cb` already uses all 48 bytes on 64-bit builds and must not grow. `SKB_TO_PKT()` and `PKT_TO_SKB()` must only be used on received packets because transmit paths allocate `rxe_pkt_info` on the stack while `prepare_ipv4_hdr()`/`prepare_ipv6_hdr()` overwrite `skb->cb` with `IPCB(skb)`. [F83, F134]
- `queue_producer_addr()` and `queue_consumer_addr()` do not mask by `q->index_mask` and must never be called with a user-owned index (`QUEUE_TYPE_FROM_CLIENT` for producer, `QUEUE_TYPE_TO_CLIENT` for consumer); use `queue_addr_from_index()`, scaling by `q->log2_elem_size` rather than `q->elem_size` or `sizeof`. SQ/RQ/SRQ `rxe_queue_init()`/`rxe_queue_resize()` callers must add the flexible `dma.sge`/inline tail size to `sizeof` the WQE struct. [F84, F131, F132]
- Flags in `enum rxe_hdr_mask` (`RXE_PAYLOAD_MASK`, `RXE_START_MASK`, etc.) must be tested against `pkt->mask`, never `pkt->opcode`. `rxe_check_bind_mw()` must validate `wqe->wr.wr.mw` fields (`access`, `addr`, `length`) rather than `mw` fields. In `__rxe_lookup_mcg()`, post-loop code must test `if (node)` (not `if (mcg)`) before `kref_get(&mcg->ref_cnt)`. [F104, F112, F120]
- During device init (`rxe_add()`, `rxe_init()`), `rxe_init_device_param()` must run before `rxe_init_ports()` and `rxe_register_device()` (to set `rxe->raw_gid`), and must read MAC info from `ndev` rather than calling `rxe_ib_device_get_netdev(&rxe->ib_dev)` before `ib_device_set_netdev()`. [F141, F142]
