# HMM - Heterogeneous Memory Management

Provides Heterogeneous Memory Management (HMM) address-space mirroring (`hmm_range_fault`) and DMA mapping helpers (`hmm_dma_map_*`) in `mm/hmm.c`, alongside the `lib/test_hmm.c` pseudo-device test driver (`hmm_dmirror*`) that exercises range faulting, `mmu_interval_notifier` invalidation, `migrate_vma_*` migration (`MEMORY_DEVICE_PRIVATE` and `MEMORY_DEVICE_COHERENT`), and `make_device_exclusive`.

## Architecture & Data Flow

- Every path in `mm/hmm.c` returning `-EBUSY` (`hmm_vma_fault()`, `hmm_vma_handle_pte()`, `hmm_vma_walk_pmd()`) must set `hmm_vma_walk->last` to the first address not yet written in `range->hmm_pfns`, because `hmm_range_fault()` restarts at `last` expecting entries `>= last` to still hold their input flags. Broken by: overwriting `range->hmm_pfns` at or after `last` before returning `-EBUSY`. [F34]
- Every path in `mm/hmm.c` writing output to `range->hmm_pfns` (`hmm_pfns_fill()`, `hmm_vma_handle_pmd()`, `hmm_vma_handle_pte()`, `hmm_vma_handle_absent_pmd()`, `hmm_vma_walk_pud()`, `hmm_vma_walk_hugetlb_entry()`) must preserve sticky input flags by masking with `HMM_PFN_INOUT_FLAGS`, which must include all sticky `enum hmm_pfn_flags`. [F48]
- In `hmm_pte_need_fault()`, `HMM_PFN_REQ_FAULT` must be checked on the effective request flags (`(pfn_req_flags & range->pfn_flags_mask) | range->default_flags`) before `HMM_PFN_REQ_WRITE`, returning 0 when `HMM_PFN_REQ_FAULT` is unset so write faults are never triggered without `HMM_PFN_REQ_FAULT`. [F70]
- In `enum hmm_pfn_flags`, every `HMM_PFN_*` bit flag must be shifted from `1UL` at a bit position `>= HMM_PFN_ORDER_SHIFT + 5` so `HMM_PFN_FLAGS` masks all flags and the 5-bit order field while keeping flags disjoint from `(hmm_pfn >> HMM_PFN_ORDER_SHIFT) & 0x1F` in `hmm_pfn_to_map_order()`. [F82]
- In `struct hmm_dma_map`, `map->dma_list` is allocated by `hmm_dma_map_alloc()` only when `!dma_use_iova(&map->state) && dma_need_unmap(dev)` and is NULL otherwise; `hmm_dma_map_pfn()` and `hmm_dma_unmap_pfn()` must check both conditions before indexing `map->dma_list`. [F38]
- In `lib/test_hmm.c`, `BACKING_PAGE(page)` must be used to obtain the CPU-accessible storage page for a ZONE_DEVICE page (`page->zone_device_data` when `is_device_private_page(page)`, or `page` itself for `MEMORY_DEVICE_COHERENT`), and in `dmirror_devmem_free()`, `__free_page(rpage)` must only be called when `rpage != page`. [F43]
- In `dmirror_interval_invalidate()`, `MMU_NOTIFY_MIGRATE` invalidations may only be ignored when `range->owner == dmirror->mdevice`; events from other owners must still erase `dmirror->pt` entries so sibling `dmirror` instances do not keep stale mappings to pages migrated to another device. [F56]
- `dmirror_min_ops` (`dmirror_interval_invalidate()`) downcasts `struct mmu_interval_notifier *` to `struct dmirror`, whereas `dmirror_mrn_ops` (`dmirror_snapshot_invalidate()`) downcasts to `struct dmirror_interval`; each ops table must only be registered with its matching container type. [F94]
- In `dmirror_range_fault()` and `dmirror_range_snapshot()`, the `hmm_range_fault()` / `mmu_interval_read_retry()` loop must check `time_after(jiffies, timeout)` on every iteration and abort with `-EBUSY` once `HMM_RANGE_DEFAULT_TIMEOUT` expires, and must only retry `hmm_range_fault()` errors when `ret == -EBUSY`. [F80]
- In `lib/test_hmm.c`, `dmirror_fault()`, `dmirror_snapshot()`, `dmirror_migrate_to_system()`, and `dmirror_migrate_to_device()` must clamp each iteration's subrange `end` to `addr + (ARRAY_SIZE(pfns) << PAGE_SHIFT)` (and to `vma->vm_end` in migration loops) before calling into HMM or `migrate_vma_setup()` to avoid overflowing the 32-element stack arrays. [F63]
- In `dmirror_do_read()` and `dmirror_do_write()`, `bounce->ptr` must be offset by `(start - bounce->addr) & PAGE_MASK` and `bounce->cpages` must accumulate across `-ENOENT` fault retries so `dmirror_read()` and `dmirror_write()` resume at `cmd->addr + (bounce.cpages << PAGE_SHIFT)`. [F65]
- In `lib/test_hmm_uapi.h` and `lib/test_hmm.c`, `zone_device_type` values must remain non-zero (starting at `HMM_DMIRROR_MEMORY_DEVICE_PRIVATE = 1`) because `hmm_dmirror_exit()` checks `if (dmirror_devices[id].zone_device_type)` to identify initialized `DMIRROR_NDEVICES` slots. [F67]

## Synchronization

- `hmm_range_fault()` does not pin pages; after it succeeds and `mmap_lock` is released, callers must acquire their notifier `user_lock` (e.g., `dmirror->mutex`), check `!mmu_interval_read_retry(range->notifier, range->notifier_seq)`, and hold that lock while calling `hmm_pfn_to_page()` or `hmm_pfn_to_map_order()` on entries with `HMM_PFN_VALID` set and consuming `range->hmm_pfns`. [F4, F17]
- `dmirror->mutex` must not be held while calling `mmap_read_lock(mm)` or `hmm_range_fault()` in `dmirror_range_fault()` and `dmirror_range_snapshot()`, because `hmm_range_fault()` can trigger MMU notifier invalidations (`dmirror_interval_invalidate()` or `dmirror_snapshot_invalidate()`) that acquire `dmirror->mutex`. [F18]
- `mmu_interval_notifier_ops.invalidate` callbacks (`dmirror_interval_invalidate()`, `dmirror_snapshot_invalidate()`) must use `mutex_trylock(&dmirror->mutex)` and return `false` when `!mmu_notifier_range_blockable(range)` and the lock is contended, and must call `mmu_interval_set_seq(mni, cur_seq)` under `dmirror->mutex`. [F120]
- Because `hmm_vma_walk_pmd()` reads PMD entries locklessly via `pmdp_get_lockless(pmdp)` without `pmd_lock`, it must re-read `pmdp_get_lockless(pmdp)` after observing `pmd_trans_huge(pmd)` or when `pte_offset_map()` returns `NULL` and restart at `again` if the PMD changed. [F107]
- In `struct dmirror_device`, `mdevice->devmem_lock` protects `devmem_chunks`, `devmem_count`, and `devmem_capacity`, while `mdevice->lock` nests inside `mdevice->devmem_lock` to protect `free_pages`, `calloc`, `cfree`, and `devmem->remove`. [F28]
- In `dmirror_range_snapshot()`, `notifier.dmirror = dmirror` must be initialized before `mmu_interval_notifier_insert(range->notifier, ...)`, and `mmu_interval_notifier_remove(range->notifier)` must be called on all exit paths after a successful insert before the stack-allocated `struct dmirror_interval notifier` goes out of scope. [F26]
- In `dmirror_allocate_chunk()`, `devmem->mdevice = mdevice` must be assigned before linking the chunk's `struct page` entries into `mdevice->free_pages` or returning `*ppage`. [F30]

## Object Lifetimes

- In `hmm_vma_handle_pte()`, every non-zero return path must call `pte_unmap(ptep)` before sleeping or returning, whereas the zero return path (`out`) must leave `ptep` mapped so `hmm_vma_walk_pmd()` can continue iterating and unmap via `pte_unmap(ptep - 1)`. [F1]
- In `hmm_dma_map_pfn()`, if `pfns[idx]` already has `HMM_PFN_DMA_MAPPED` set without `HMM_PFN_P2PDMA_BUS`, it must return the existing IOVA (`state->addr + offset`) or `dma_addrs[idx]` when `dma_use_iova(state)` or `dma_need_unmap(dev)` is true instead of calling `dma_iova_link()` or `dma_map_phys()` again. [F5]
- In `lib/test_hmm.c`, functions operating on `dmirror->notifier.mm` (`dmirror_fault()`, `dmirror_exclusive()`, `dmirror_migrate_to_system()`, `dmirror_migrate_to_device()`, `dmirror_snapshot()`) must acquire `mmget_not_zero(mm)` before `mmap_read_lock(mm)` and call `mmap_read_unlock(mm)` before `mmput(mm)`. [F9]
- In `dmirror_exclusive()`, after a successful `make_device_exclusive(mm, addr, NULL, &folio)` call under `mmap_read_lock(mm)`, the caller must map the page (`dmirror_atomic_map()`) while `folio` is locked and then call both `folio_unlock(folio)` and `folio_put(folio)`. [F127]
- In `dmirror_device_remove_chunks()`, each `devmem` chunk must have `devmem->remove = true` and `dmirror_remove_free_pages(devmem)` executed under `mdevice->lock` before `dmirror_device_evict_chunk(devmem)` and `memunmap_pages(&devmem->pagemap)` so `dmirror_devmem_free()` does not return evicted pages to `mdevice->free_pages`. [F11]
- `dmirror_device_remove_chunks()` must reset `mdevice->devmem_count`, `mdevice->devmem_capacity`, `mdevice->free_pages`, and `mdevice->devmem_chunks` to zero/NULL under `mdevice->devmem_lock` after freeing `mdevice->devmem_chunks`, as it can be invoked by both `HMM_DMIRROR_RELEASE` and `dmirror_device_remove()`. [F12]
- In `dmirror_allocate_chunk()` and `dmirror_device_remove_chunks()`, `release_mem_region()` must only be called when `devmem->pagemap.type == MEMORY_DEVICE_PRIVATE`, because `MEMORY_DEVICE_COHERENT` chunks use module-parameter addresses (`spm_addr_dev0`/`spm_addr_dev1`) not reserved via `request_free_mem_region()`. [F13]
- In `dmirror_fops_mmap()`, each page allocated with `alloc_page()` must be freed with `__free_page(page)` if `vm_insert_page()` fails, or have its initial allocation reference dropped with `put_page(page)` after `vm_insert_page()` succeeds. [F15]

## API Contracts

- `hmm_range_fault()` indexes `range->hmm_pfns` by `(addr - range->start) >> PAGE_SHIFT` and populates one `unsigned long` entry per `PAGE_SIZE` page across `[range->start, range->end)`, so callers must size `hmm_pfns` for `(range->end - range->start) >> PAGE_SHIFT` base pages, and high-order handlers (`hmm_vma_handle_pmd()`, `hmm_vma_handle_absent_pmd()`, `hmm_vma_walk_pud()`, `hmm_vma_walk_hugetlb_entry()`) must fill every subpage entry across `[addr, end)` with its incrementing PFN, protection, and `hmm_pfn_flags_order()` flags. [F50, F88]
- `hmm_walk_ops` must leave `.pte_entry` unset and handle both transparent huge PMDs and PTE directories inside `hmm_vma_walk_pmd()`, while `hmm_vma_walk_pud()` must set `walk->action = ACTION_CONTINUE` unless descending into a non-leaf PUD (`walk->action = ACTION_SUBTREE`), so `walk_page_range()` does not split huge PUDs or PMDs. [F114]
- `hmm_vma_walk_test()` must permit `VM_MIXEDMAP` VMAs (rejecting only `VM_IO | VM_PFNMAP` or `!VM_READ`), and `hmm_vma_handle_pte()` must identify non-struct-page mappings via `!vm_normal_page(walk->vma, addr, pte) && !is_zero_pfn(pte_pfn(pte))` rather than `pte_special(pte)`. [F116]
- Callers of `hmm_dma_map_alloc()` must guarantee that `dma_entry_size` is non-zero and `nr_entries * PAGE_SIZE >= dma_entry_size`, because `hmm_dma_map_alloc()` immediately evaluates `WARN_ON_ONCE(!(nr_entries * PAGE_SIZE / dma_entry_size))` without checking for a zero divisor. [F84]

## Error Handling

- On an unwalkable VMA (`hmm_vma_walk_test()`), VMA hole (`hmm_vma_walk_hole()`), bad PMD (`hmm_vma_walk_pmd()`), absent non-owned PMD (`hmm_vma_handle_absent_pmd()`), or non-normal non-zero PTE (`hmm_vma_handle_pte()`), `mm/hmm.c` must return `-EFAULT` only when a fault was requested and otherwise fill `hmm_pfns` with `HMM_PFN_ERROR` (or `0`) and succeed. [F124]
- In `lib/test_hmm.c`, every `xa_store(&dmirror->pt, ...)` call (`dmirror_do_fault()`, `dmirror_atomic_map()`, `dmirror_migrate_finalize_and_map()`) must check `xa_is_err(entry)` and return `xa_err(entry)`, while readers (`dmirror_do_read()`, `dmirror_do_write()`) must call `xa_untag_pointer(entry)` before dereferencing the page. [F40]
- In `dmirror_device_evict_chunk()`, the `src_pfns`, `dst_pfns`, and destination `struct page` allocations must use `__GFP_NOFAIL` because chunk eviction runs during device teardown (`dmirror_device_remove_chunks()`) and has no failure return path. [F42]

## External Contracts

- `dmirror_fops_unlocked_ioctl()` must validate that `cmd.addr` is page-aligned (`cmd.addr & ~PAGE_MASK`) and that `cmd.addr + (cmd.npages << PAGE_SHIFT)` is strictly greater than `cmd.addr` before dispatching any command, and each range handler must also check `end >= start` after truncation to `unsigned long`. [F62]
- In `dmirror_mkentry()`, the high nibble of the `HMM_DMIRROR_PROT_*` byte encodes mutually exclusive page types (`0x10`..`0x50`) while the low nibble holds bitwise-ORable flags (`READ`, `WRITE`, `PMD`, `PUD`), and `*perm` must be initialized with `=` before any `|=` since `dmirror_snapshot()` passes an uninitialized stack buffer. [F69]

## Known Pitfalls

- In `hmm_vma_handle_pte()`, when a present PTE has `!vm_normal_page(walk->vma, addr, pte) && !is_zero_pfn(pte_pfn(pte))`, it must re-call `hmm_pte_need_fault(hmm_vma_walk, pfn_req_flags, 0)` with `cpu_flags = 0` so fault requests fail with `-EFAULT` instead of succeeding with `HMM_PFN_ERROR` because `HMM_PFN_VALID` was set in `cpu_flags`. [F72]
- Page mapping orders encoded into `hmm_pfns` entries must be shifted through `hmm_pfn_flags_order()` (which widens `order` to `unsigned long` before shifting by `HMM_PFN_ORDER_SHIFT`) and must fit within 5 bits (`order <= 0x1F`). Broken by: shifting a 32-bit `int`/`unsigned int` order directly by `HMM_PFN_ORDER_SHIFT`. [F83]
- Unlike virtual address ranges in `lib/test_hmm.c` which have an exclusive `end`, `struct dmirror_chunk`'s `pagemap.range` is a `struct range` with an inclusive `end` address, so PFN counts must be computed via `range_len(&devmem->pagemap.range) >> PAGE_SHIFT` or `end_pfn - start_pfn + 1`. [F64]
- In `hmm_dmirror_init()`, the loop counter `id` must be a signed integer type because the `err_chrdev` unwind loop uses `while (--id >= 0)` to call `dmirror_device_remove()` in reverse order. [F68]
