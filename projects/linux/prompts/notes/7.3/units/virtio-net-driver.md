# VIRTIO NET DRIVER

The Virtio Network Driver (`virtio_net`) implements the Linux kernel network device driver over the paravirtualized virtio transport, together with shared header conversion helpers (`include/linux/virtio_net.h`) and UAPI wire/control definitions (`include/uapi/linux/virtio_net.h`). It supports multiqueue RX/TX virtqueues, small/big/mergeable RX buffers using `page_pool`, GSO/CSUM and UDP tunnel offloads, XDP and AF_XDP zero-copy (`xsk_buff_pool`), RSS/hash reporting, dynamic interrupt moderation (DIM), device statistics via the control virtqueue, and standby failover.

## Architecture & Data Flow
- Because `virtnet_set_big_packets()` sets `vi->big_packets` when `mtu > ETH_DATA_LEN` or guest GSO is negotiated even if `vi->mergeable_rx_bufs` is true, RX paths (`receive_buf()`, `try_fill_recv()`, `page_to_skb()`, `virtnet_create_page_pools()`, `virtnet_find_vqs()`) must check `vi->mergeable_rx_bufs` before `vi->big_packets`. In `receive_buf()` and `virtnet_rq_free_buf()`, `void *buf` is a `struct page *` when `vi->big_packets && !vi->mergeable_rx_bufs` (`!rq->page_pool`), and a `char *` virtual address in small or mergeable modes. [F38, F88]
- RX pointer offsets must match between submission and consumption: in small mode, `add_recvbuf_small()` advances by `VIRTNET_RX_PAD + xdp_headroom` and `receive_small()` must subtract it; in mergeable mode, `add_recvbuf_mergeable()` advances by `headroom` and encodes `len + room` (`room = SKB_DATA_ALIGN(headroom + tailroom)`) as `truesize` in `mergeable_len_to_ctx()` so `truesize >= room` in `check_mergeable_len()`, while `page_to_skb()` and `virtnet_build_xdp_buff_mrg()` must subtract `headroom` (`XDP_PACKET_HEADROOM`). [F110, F118, F119]
- In non-mergeable big-packet RX mode, `virtnet_set_big_packets()` computes `vi->big_packets_num_skbfrags` via `DIV_ROUND_UP(mtu, PAGE_SIZE)` when `!guest_gso`. `add_recvbuf_big()` puts `vi->hdr_len` at offset 0 of page 0 and payload at `sizeof(struct padded_vnet_hdr)`, so `receive_big()` and `page_to_skb()` must advance page 0 data by `sizeof(struct padded_vnet_hdr)` while subtracting `vi->hdr_len` from `len`, and `receive_big()` must bound `len <= (vi->big_packets_num_skbfrags + 1) * PAGE_SIZE - sizeof(struct padded_vnet_hdr) + vi->hdr_len`. [F70, F113, F120]
- RX buffer bounds checks: every mergeable buffer dequeued in `receive_mergeable()`, `xdp_linearize_page()`, and `virtnet_build_xdp_buff_mrg()` must pass `check_mergeable_len(dev, ctx, len)`; `virtnet_build_xdp_buff_mrg()` must reject `*num_buf > MAX_SKB_FRAGS + 1`; `xdp_linearize_page()` must check `page_off + len + tailroom <= PAGE_SIZE` (`tailroom = SKB_DATA_ALIGN(sizeof(struct skb_shared_info))`) on all buffers; and `buf_to_xdp()` must bound `bufsize` to `xsk_pool_get_rx_frame_size(rq->xsk_pool)` when `first_buf` is true and add `vi->hdr_len` only when `!first_buf`. [F71, F72, F73, F74]
- In `receive_buf()` and `virtnet_receive_xsk_buf()`, `hdr.flags` must be saved into a local variable before running XDP or building the SKB and restored into `skb_vnet_common_hdr(skb)->hdr.flags` in `virtnet_receive_done()` before `virtio_net_handle_csum_offload()`. In AF_XDP RX paths (`virtnet_add_recvbuf_xsk()`, `virtnet_receive_xsk_buf()`, `virtnet_receive_xsk_merge()`, `virtnet_xdp_rx_hash()`), the virtio header is at `xdp->data - vi->hdr_len` and `flags` and `hdr->num_buffers` must be read before `virtnet_xdp_handler()` or `xsk_construct_skb()`. [F130, F172]
- TX virtqueue tokens pack `enum virtnet_xmit_type` in the low 2 bits (`VIRTNET_XMIT_TYPE_MASK`): `SKB`, `SKB_ORPHAN`, and `XDP` are 4-byte-aligned pointers unpacked by `virtnet_xmit_ptr_unpack(&ptr)`, while `VIRTNET_XMIT_TYPE_XSK` encodes `(desc->len << VIRTIO_XSK_FLAG_OFFSET)` and must never be dereferenced. Only `VIRTNET_XMIT_TYPE_SKB` is accounted to BQL (`__netdev_tx_sent_queue()`, `netdev_tx_completed_queue()`); `VIRTNET_XMIT_TYPE_SKB_ORPHAN` only updates `stats->packets` and `stats->bytes`. Whenever uncompleted TX buffers are flushed via `virtnet_sq_free_unused_buf()`, `netdev_tx_reset_queue()` must run immediately afterwards via `virtnet_sq_free_unused_buf_done()`. [F2, F54, F84]
- `vi->sq` indices `[curr_queue_pairs - xdp_queue_pairs, curr_queue_pairs)` are per-CPU XDP TX queues when `curr_queue_pairs > nr_cpu_ids` (else `xdp_queue_pairs == 0` and `virtnet_xdp_get_sq()` wraps via `cpu % curr_queue_pairs`). Queues where `is_xdp_raw_buffer_queue(vi, q)` is true must be skipped in `virtnet_poll_tx()`, `virtnet_poll_cleantx()`, and `check_sq_full_and_disable()`. `vi->curr_queue_pairs` must always remain `>= 1`. `xsk_hdr` is shared and DMA-mapped (`DMA_TO_DEVICE`) module-wide and must never be mutated in place. [F65, F80, F106, F112]
- RSS and coalescing: in `struct virtnet_info`, `TRAILING_OVERLAP(struct virtio_net_rss_config_trailer, rss_trailer, hash_key_data, u8 rss_hash_key_data[NETDEV_RSS_KEY_LEN];)` must remain the final member; `vi->rss_key_size` in `virtnet_probe()` must be clamped to `NETDEV_RSS_KEY_LEN`; in `virtnet_rss_hdr_size()`, `indir_table_size` must be `1` when `!vi->has_rss`; and `virtnet_set_queues()` must update `vi->rss_trailer.max_tx_vq = cpu_to_le16(queue_pairs)` when `vi->has_rss`. `virtnet_tx_resize()` must reject `ring_num <= MAX_SKB_FRAGS + 2`, `virtnet_set_ringparam()` must re-apply `vi->intr_coal_{tx,rx}` after resize (ignoring `-EOPNOTSUPP`), and `virtnet_send_{tx,rx}_notf_coal_cmds()` must update all `0..vi->max_queue_pairs - 1` queues. [F50, F56, F57, F75, F76, F78, F125]
- Queue pre-fill, frag chaining, and stats: `virtnet_open()` and `virtnet_rx_resume_all()` enable NAPI on all `vi->max_queue_pairs` queues, but RX pre-filling (`try_fill_recv()`) must be restricted to `i < vi->curr_queue_pairs`. In `virtnet_skb_append_frag()`, fragments attach to `curr_skb`, and when `curr_skb != head_skb`, `len`, `data_len`, and `truesize` must also be added to `head_skb` and `pp_recycle` tested on `head_skb`. `VIRTIO_NET_STATS_TYPE_*` bitmaps must be `u64` (`VIRTIO_NET_STATS_TYPE_CVQ` is `1ULL << 32`), and `virtnet_get_stats_string()`, `virtnet_stats_ctx_init()`, and `virtnet_fill_stats()` must traverse descriptor tables in the exact same order. [F104, F105, F107, F128]

## Synchronization
- In `virtnet_send_command_reply()` and `virtnet_send_command()`, all accesses to `vi->ctrl` and `vi->cvq` require `mutex_lock(&vi->cvq_lock)`, and the poll loop must check `!virtqueue_is_broken(vi->cvq)` and call `cond_resched()`. Callers must run in sleepable process context and release BH/spinlocks first: in `virtnet_rx_mode_work()`, `netif_addr_unlock_bh(dev)` must precede `virtnet_send_command()`, and error paths must unlock `netif_addr_unlock_bh(dev)` and `rtnl_unlock()`. Per-RX-queue `rq->dim_enabled` and `rq->intr_coal` require `rq->dim_lock` (nesting outside `vi->cvq_lock`, locked one queue at a time). [F21, F30, F31, F100, F146]
- TX locking: in `virtnet_tx_pause()`, disable TX NAPI and set `sq->reset = true` and `netif_stop_subqueue()` under `__netif_tx_lock_bh(txq)` before resetting/resizing `sq->vq`, and `virtnet_poll_cleantx()` must abort if `sq->reset` is true under `__netif_tx_trylock(txq)`. In `virtnet_poll_tx()`, `virtqueue_disable_cb(sq->vq)` and `virtqueue_enable_cb_prepare(sq->vq)` require `__netif_tx_lock(txq, raw_smp_processor_id())`. Shared XDP TX queues (`curr_queue_pairs <= nr_cpu_ids`) require `__netif_tx_lock(txq, cpu)`. [F32, F33, F37]
- RCU, RTNL, BH, and stats: `rq->xdp_prog` is RCU-protected; `virtnet_xdp_set()` must disable all RX/TX NAPIs before updating `xdp_prog` or `vi->xdp_queue_pairs` and call `synchronize_net()` when clearing `prog`. In `virtnet_probe()`, `rtnl_lock()` must be held across `register_netdevice()`, `virtio_device_ready()`, and initial CVQ commands, with `vi->guest_offloads{,_capable}` initialized before `register_netdevice()`. `rq->stats` and `sq->stats` require `u64_stats_update_begin{,_irqsave}()` (irqsave in `try_fill_recv()`). `virtqueue_napi_schedule()` outside softirq/hardirq requires `local_bh_disable()` / `local_bh_enable()`. `virtnet_set_affinity()` outside hotplug requires `cpus_read_lock()` and must precede `virtnet_napi_tx_enable()`. [F24, F34, F36, F133, F148, F158]

## Object Lifetimes
- In `start_xmit()`, when `!use_napi`, `skb_orphan_frags()` must run before `xmit_skb()`, and `skb_orphan()`, `skb_dst_drop()`, and `nf_reset_ct()` must run after, because queued SKBs remain in `sq->vq` until a later transmit calls `free_old_xmit()`. [F1]
- Every `sk_buff` built from `page_pool` pages (`receive_small*()`, `receive_mergeable*()`, and `nskb` in `virtnet_skb_append_frag()` when `head_skb->pp_recycle` is set) must call `skb_mark_for_recycle()`, whereas `receive_big()` and `xsk_construct_skb()` SKBs must never call it. `rq->page_pool` must be reset to `NULL` on `IS_ERR()` or `page_pool_destroy()`. `get_a_page()` must clear `p->private = 0`, and `add_recvbuf_big()` must return failed chains via `give_pages()`. [F11, F12, F174]
- AF_XDP, XDP, and RSS lifetimes: in `virtnet_rq_bind_xsk_pool()`, `rq->xsk_pool` is updated only after `virtqueue_reset()` and before `virtnet_rx_resume()` (and cleared with `rq->xsk_rxq_info` unregistered if `virtqueue_reset()` fails). In `virtnet_rx_resize()`, when `rq->xsk_pool` is active and `virtqueue_get_vring_size(rq->vq) > old_ring_num`, `tmp_xsk_buffs` must be swapped into `rq->xsk_buffs` before `virtnet_rx_resume()` even if `virtqueue_resize()` failed. `xdp_prog` refcounts span all `vi->max_queue_pairs` queues (`bpf_prog_add(prog, vi->max_queue_pairs - 1)`). In `__virtnet_xdp_xmit_one()`, `xdpf->headroom` and `xdpf->data` must both be decremented by `vi->hdr_len`, and `xdpf` must not be freed on `-ENOSPC`. `vi->rss_hdr` `devm_kzalloc()` / `devm_kfree()` calls must use `&vi->vdev->dev` and roll back `old_rss_hdr` / `old_rss_trailer` on `virtnet_commit_rss_command()` failure in `virtnet_set_queues()`. [F13, F15, F16, F17, F132, F169]
- Teardown ordering: in `virtnet_close()`, `virtio_config_driver_disable(vi->vdev)` must precede `cancel_work_sync(&vi->config_work)` and `netif_carrier_off(dev)`, and `virtnet_disable_queue_pair()` must precede `virtnet_cancel_dim()`. In `virtnet_remove()` and `virtnet_freeze()`, `virtnet_cpu_notif_remove(vi)` and `disable_rx_mode_work(vi)` / `flush_work()` for `config_work` and `rx_mode_work` must run without `rtnl_lock` before closing/unregistering `vi->dev` and calling `remove_vq_common(vi)`. In `remove_vq_common()` and `virtnet_restore_up()`, `virtio_reset_device()` and `free_unused_bufs()` must precede `virtnet_destroy_page_pools()` and `virtnet_del_vqs()`. `virtnet_free_queues()` must call `synchronize_net()` between `__netif_napi_del()` and `kfree(vi->rq)` / `kfree(vi->sq)`. [F19, F27, F28, F29]

## API Contracts
- RX builder ownership: `xsk_construct_skb()` unconditionally frees `xdp` via `xsk_buff_free(xdp)` on both success and `napi_alloc_skb()` failure, so callers (`virtnet_receive_xsk_small()`, `virtnet_receive_xsk_merge()`) must not free `xdp` after calling it. Conversely, `virtnet_skb_append_frag()` and `page_to_skb()` consume `page` (and `page_to_skb()` returns unused chained `page->private` pages) only when returning non-NULL, leaving `page` and its chain for the caller to release when returning `NULL`. [F4, F5, F6]
- Header helpers: `virtio_net_hdr_from_skb()` only zeroes `sizeof(struct virtio_net_hdr)` (10 bytes), so TX paths formatting larger headers must zero trailing fields (`hash_hdr.*`, `num_buffers`). In `virtio_net_hdr_tnl_from_skb()`, `tnl_gso_type` masked out of `skb_shinfo(skb)->gso_type` must be restored on both success and error paths, and `__virtio_net_set_{,tnl_}hdrlen()` must run after `virtio_net_hdr_from_skb()` when `feature_hdrlen && hdr->hdr_len`. Callers of `virtio_net_hdr_{,tnl_}to_skb()` must set `skb->dev` and `skb->network_header` first; when configuring GSO (`skb->len - nh_off > gso_size`), `__virtio_net_hdr_to_skb()` must set `SKB_GSO_DODGY`, zero `gso_segs`, clamp TCP `gso_size >= TCP_MIN_GSO_SIZE`, and reject `GSO_BY_FRAGS`. [F23, F39, F68, F86, F159, F160, F161]
- Queue indices, NAPI, and DMA: `virtnet_fill_stats()` and `virtnet_get_hw_stats()` take a raw virtqueue index `qid` (`rxq2vq(q) = 2*q`, `txq2vq(q) = 2*q + 1`), whereas `virtnet_get_queue_stats_{rx,tx}()` take queue-pair index `i`; `vq2txq(vq)` and `vq2rxq(vq)` map `vq` to `vi->sq[]` and `vi->rq[]`. In `virtnet_poll_tx()` and `virtnet_poll_cleantx()`, pass `in_napi = !!budget` to `free_old_xmit()`. `virtnet_poll()` disables `rq->vq` cb when `budget != 0`, `virtnet_receive()` returns `budget` when `!try_fill_recv()`, `virtnet_add_recvbuf_xsk()` returns `0` when `xsk_uses_need_wakeup(pool)`, and `virtnet_poll_tx()` passes `0` to `napi_complete_done()` unless `xsk_done >= budget` (return `budget` without completing). When `rq->use_page_pool_dma` is true, call `page_pool_dma_sync_for_cpu()` on every RX dequeue before reading `buf`. CVQ buffers must be heap-allocated, and fallback TX headers must use `skb_vnet_common_hdr(skb)`. [F48, F103, F129, F145, F156, F167, F168]
- Features and stats: `VIRTIO_NET_F_GUEST_UDP_TUNNEL_GSO{,_CSUM}` (65, 66) use mapped bits 46 and 47 in `vi->guest_offloads` and require `virtio_offload_to_feature()` before `virtio_has_feature()`. `virtnet_features_check()` must clear `NETIF_F_CSUM_MASK` when `skb->encapsulation && (!skb_is_gso(skb) || netif_needs_gso(skb, features))`. `virtnet_get_base_stats()` may only zero-initialize `netdev_queue_stats_{rx,tx}` fields supported by `vi->device_stats_cap`. [F47, F166, F181]

## Error Handling
- In mergeable RX multi-buffer loops (`receive_mergeable()`, `xdp_linearize_page()`, `virtnet_build_xdp_buff_mrg()`, `xsk_append_merge_buffer()`), `num_buf` must be pre-decremented (`--num_buf`) before each dequeue so `mergeable_buf_free()` and `xsk_drop_follow_bufs()` drain the exact remaining buffers, and `virtnet_build_xdp_buff_mrg()` must check `if (!*num_buf) return 0;` before `while (--*num_buf > 0)`. In `receive_mergeable_xdp()`, any failure or drop after `virtnet_build_xdp_buff_mrg()` must call `put_xdp_frags(rq, &xdp)` in addition to freeing the head page and draining remaining buffers. [F8, F96, F97]
- In `virtnet_xsk_pool_{enable,disable}()`, XSK resources must be torn down in reverse order, saving `pool = rq->xsk_pool` before unbinding clears `rq->xsk_pool`. On batch-submit failure at index `i` in `virtnet_add_recvbuf_xsk()` or `virtnet_xsk_xmit_batch()`, release the unsubmitted tail `[i, num)` via `xsk_buff_free()` or `xsk_tx_completed()`. `virtnet_send_command*()` requires `vi->ctrl->status = ~0` before submission and returns `bool` (`true` on `VIRTIO_NET_OK` (`0`)). If `virtnet_commit_rss_command()` fails in `virtnet_probe()`, clear `NETIF_F_RXHASH` and `vi->has_rss{,_hash_report}`. `virtnet_xdp_xmit()` callers must free unqueued frames when `err <= 0`. [F14, F43, F49, F52, F98]

## External Contracts & Known Pitfalls
- In `virtio_net_hdr_tnl_to_skb()`, reject `gso_tunnel_type == VIRTIO_NET_HDR_GSO_UDP_TUNNEL` and `gso_inner_type` equal to `0` or `VIRTIO_NET_HDR_GSO_UDP`, and verify `outer_th >= ETH_HLEN + virtio_l3min(outer_isv6)`, `inner_nh >= outer_th + sizeof(struct udphdr)`, and `inner_th >= inner_nh + inner_l3min` before calling `__virtio_net_hdr_to_skb()` or reading `skb->data + inner_nh`. In `__virtio_net_hdr_to_skb()`, gate TCP `csum_offset` check on `skb->ip_summed == CHECKSUM_PARTIAL`, require `VIRTIO_NET_HDR_F_NEEDS_CSUM` and no ECN for `SKB_GSO_UDP_L4`, return `0` without setting GSO when `skb->len - nh_off <= gso_size`, and in the `SKB_GSO_UDP` `goto retry` fallback require `skb->protocol == htons(ETH_P_IP)` and mutate it to `htons(ETH_P_IPV6)`. `virtnet_xdp_rx_hash()` must bound `hash_report < VIRTIO_NET_HASH_REPORT_MAX_TABLE`. [F69, F77, F90, F91, F92, F102]
- In `xmit_skb()` when `can_push` is true, `__skb_push(skb, hdr_len)` must happen after `virtio_net_hdr_tnl_from_skb()` and `__skb_pull(skb, hdr_len)` after `skb_to_sgvec()`. In `__virtio_net_hdr_to_skb()`, widen 16-bit `csum_start` and `csum_offset` to `u32` before addition, and verify `pskb_may_pull(skb, p_off)` before `skb->len - p_off` or `skb->len - nh_off`. Struct assignments on `virtio_net_rss_config_{hdr,trailer}` do not copy their flexible arrays. In `virtnet_fill_stats_qstat()`, divide `desc[i].qstat_offset` by `sizeof(*ctx->data)` when indexing `u64 *ctx->data`. [F41, F115, F116, F126, F127]
