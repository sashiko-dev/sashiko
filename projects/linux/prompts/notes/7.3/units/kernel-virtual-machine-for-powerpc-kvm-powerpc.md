# KERNEL VIRTUAL MACHINE FOR POWERPC (KVM/powerpc)

This component (`arch/powerpc/kvm`) implements Book3S Problem State (PR) guest execution, PAPR hypercalls, paired-single floating-point emulation, and HPTE MMU caching; BookE guest execution and instruction/SPR emulation; Ultravisor secure guest memory management (`uvmem`) using `ZONE_DEVICE` private pages; and Book3S virtual interrupt controllers (XICS, XICS-on-XIVE, XIVE native mode) and RTAS token/hcall handling.

## Architecture & Data Flow
- In `struct kvmppc_uvmem_slot`, `pfns[gfn - base_pfn]` ORs `KVMPPC_GFN_FLAG_MASK` (upper 3 bits) with the device PFN, so `kvmppc_gfn_is_uvmem_pfn()` must mask with `KVMPPC_GFN_PFN_MASK`. Also, `kvmppc_uv_migrate_mem_slot()`'s `while (kvmppc_next_nontransitioned_gfn(...))` loop never increments `gfn` directly; every non-breaking iteration must set a `KVMPPC_GFN_FLAG_MASK` bit via `kvmppc_svm_page_in()` / `kvmppc_uvmem_get_page()`. [F99, F107]
- In `kvmppc_share_page()`, drop `kvm->arch.uvmem_lock` before `gfn_to_page(kvm, gfn)` (which triggers `kvmppc_uvmem_migrate_to_ram()` and takes `uvmem_lock`). Any jump to `retry:` (e.g., if the GFN is Secure again after re-acquiring `uvmem_lock`) must hold `uvmem_lock`, release `page` via `kvm_release_page_unused(page)`, and set `pvt->skip_page_out = true` and `pvt->remove_gfn = false` on the current `uvmem_page`. [F5, F108]
- `kvmppc_xics_find_ics()` and `kvmppc_xive_find_source()` split guest IRQs into `irq >> KVMPPC_XICS_ICS_SHIFT` and `irq & KVMPPC_XICS_SRC_MASK` and must verify block ID `<= KVMPPC_XICS_MAX_ICS_ID` (1023). Because `xics->max_icsid` and `xive->max_sbid` are inclusive (init 0), loops must use `<= max_icsid` / `<= max_sbid` (and `max_icsid + 1` in `icp_check_resend()`), and `kvmppc_xive_find_source()` callers must check `state->valid` before `kvmppc_xive_select_irq()`. [F44, F89, F90]
- `kvmppc_xive_select_irq()` tests `state->pt_number` to choose between passthrough (`state->pt_data`) and IPI (`&state->ipi_data`), so `kvmppc_xive_set_mapped()` and `kvmppc_xive_clr_mapped()` must update or clear `state->pt_number` and `state->pt_data` together under `sb->lock`. [F45]
- `kvmppc_xive_push_vcpu()` must verify `local_paca->kvm_hstate.xive_tima_virt` and `vcpu->arch.xive_cam_word` are non-zero before writing TIMA and setting `xive_pushed = 1`; `kvmppc_xive_cleanup_vcpu()` and `kvmppc_xive_native_cleanup_vcpu()` must zero `xive_cam_word` when disabling the VP. On guest exit, `kvmppc_xive_pull_vcpu()` must reset `xive_saved_state.lsmfb = 0`, `ack = 0xff`, and `xive_pushed = 0` after reading `TM_QW1_OS`. [F46, F67]
- In `xive_set_source()`, if `KVM_XICS_PENDING` is set, set `state->old_q = true` and keep `state->old_p = false` (even with `KVM_XICS_PRESENTED`) so `xive_finish_unmask()` sets PQ to 11 and performs an EOI. Also, `xive_set_source()` must only increment `xive->src_count` when `!state->valid`, so `xive_get_source()` runs `xive_pre_save_scan()` at `saved_src_count == 0` and `xive_post_save_scan()` at `++saved_src_count == src_count`. [F61, F63]
- In `xive_vm_scan_interrupts()`, check `prio`, `cppr`, `pipr`, and `xc->mfrr` `< 8` before `1 << prio` or `xc->queues[prio]`. The `hirq == XICS_IPI || (prio == 0 && !qpage)` branch must only jump to `skip_ipi:` if `hirq != 0` (else clear `pending &= ~(1 << prio)`), and `if (prio >= xc->mfrr && xc->mfrr < xc->cppr)` must precede updating `q->idx` and `q->toggle`. On `scan_fetch`, if `xc->cppr != xc->hw_cppr`, update `xc->hw_cppr` and TIMA `TM_CPPR`. [F65, F112, F113, F132]
- When reading XIVE queues (`__xive_read_eq()`, `xive_vm_scan_for_rerouted_irqs()`), `__be32` entry `qpage[idx]` is valid iff `(be32_to_cpup(qpage + idx) >> 31) != toggle`, advancing `idx = (idx + 1) & msk` and flipping `toggle ^= 1` on wrap to 0. In `xive_vm_scan_for_rerouted_irqs()`, skip paths in `for (;;)` must `goto next` (not `continue`), and overwriting `qpage[idx]` with `XICS_DUMMY` must preserve `entry & 0x80000000`. [F92, F114]
- When retargeting in `xive_target_interrupt()`, `kvmppc_xive_select_target()` uses `xive_try_pick_queue()` to cap `q->count` at `(q->msk + 1) - XIVE_Q_GAP` via `atomic_add_unless()`; if `state->act_priority != MASKED`, `xive_inc_q_pending()` must increment the old queue's `q->pending_count` so `xive_vm_scan_interrupts()` drains it from `q->count`. [F17, F94]
- In `kvmppc_xive_vcpu_id_valid()` and `kvmppc_xive_compute_vp_id()`, pack the guest CPU ID with `kvmppc_pack_vcpu_id(xive->kvm, cpu)` and check `< xive->nr_servers` before calling `kvmppc_xive_vp()`. `kvmppc_xive_set_nr_servers()` must reject `0` or `> KVM_MAX_VCPU_IDS`, clamp `> KVM_MAX_VCPUS` to `KVM_MAX_VCPUS`, and return `-EBUSY` under `xive->lock` once `xive->vp_base != XIVE_INVALID_VP`. [F86, F87]
- In `book3s_pr.c`: call `kvmppc_recalc_shadow_msr()` whenever guest MSR or `guest_owned_ext` changes; `kvmppc_copy_from_svcpu()` must return immediately if `!svcpu->in_use` before copying registers, adding timebase deltas, and clearing `svcpu->in_use`; and when `BOOK3S_HFLAG_SPLIT_HACK` is set, `kvmppc_unfixup_split_real()` must strip `SPLIT_HACK_MASK` from PC/LR and clear the flag before `kvmppc_inject_interrupt_pr()`, `kvmppc_core_vcpu_put_pr()`, or leaving split-real mode in `kvmppc_set_msr_pr()`. [F71, F72, F73]

## Synchronization
- In `book3s_hv_uvmem.c`, lock ordering is `kvm->srcu` -> `kvm->mm->mmap_lock` -> `kvm->arch.uvmem_lock` -> `kvmppc_uvmem_bitmap_lock`, and `kvm->arch.uvmem_lock` must be held whenever reading or modifying `kvm->arch.uvmem_pfns` or per-slot `pfns[]` entries. [F27]
- In `book3s_mmu_hpte.c`, `kvmppc_mmu_hpte_cache_map()` and `invalidate_pte()` must insert/remove each `struct hpte_cache` across all `vcpu3s->hpte_hash_*` lists and update `hpte_cache_count` in lockstep under `vcpu3s->mmu_lock`. Because readers use `hlist_for_each_entry_rcu()` under `rcu_read_lock()` without a safe cursor, `invalidate_pte()` must recheck `hlist_unhashed(&pte->list_pte)` under `mmu_lock`, unlink via `hlist_del_init_rcu()`, and free via `kfree_rcu()`. [F26, F70, F109]
- Initialize all fields and order with `smp_wmb()` before publishing `xics->ics[icsid]` under `kvm->lock` in `kvmppc_xics_create_ics()` or `xive->src_blocks[bid]` under `xive->lock` in `kvmppc_xive_create_src_block()`. In `xive_check_provisioning()`, provision all vCPU queues via `xive_provision_queue()` and execute `mb()` under `xive->lock` before setting `xive->qmap |= (1 << prio)`. [F19, F20, F21]
- In `book3s_xics.c`, bracket `arch_spin_lock(&ics->lock)` with `local_irq_save()` / `local_irq_restore()`, keeping `get_user()` / `put_user()` outside `ics->lock`. In `book3s_xive.c` and `book3s_xive_native.c`, sleeping `xive->lock` ranks outside `arch_spin_lock(&sb->lock)` and must never be taken while holding `sb->lock`. [F166, F167]
- In `book3s_xics.c`, `icp_try_update()` must only enqueue (never dequeue) `BOOK3S_INTERRUPT_EXTERNAL` when `new.out_ee` is true; only the target vCPU may dequeue it before the `cmpxchg64(&icp->state.raw, ...)` loop. When `icp_try_to_deliver()` fails in `icp_deliver_irq()`, order `state->resend = 1` before `set_bit(ics->icsid, icp->resend_map)` with `smp_wmb()` (paired with `smp_rmb()` in `icp_check_resend()`), followed by `smp_mb()` and a `!icp->state.need_resend` retry check. [F32, F33]
- In `xive_vm_h_eoi()`, order `state->in_eoi = true` before reading `state->guest_priority` with `smp_mb()`, and place `mb()` between `xive_vm_source_eoi()` and `state->in_eoi = false`. This pairs with `sb->lock` retry loops in `xive_lock_for_unmask()` and `xive_lock_and_mask()`; if `state->in_eoi` is true in `xive_lock_and_mask()`, restore `state->guest_priority = old_prio` before dropping `sb->lock`. [F34, F115]
- In `book3s_xive.c`: `xive_vm_h_ipi()` requires `mb()` between writing `xc->mfrr` and reading `xc->cppr`, pairing with `smp_mb()` after `xc->cppr` updates in `xive_vm_h_cppr()` and `xive_vm_h_eoi()`; `xive_vm_ack_pending()` must bracket the 16-bit read of `xive_tima + TM_SPC_ACK_OS_REG` with `eieio()` and `mb()`; and `xive_vm_scan_interrupts()` must snapshot `READ_ONCE(q->qpage)` once for both `__xive_read_eq()` and `(prio == 0 && !qpage)`. [F35, F36, F147]
- For XIVE single escalation: `kvmppc_xive_push_vcpu()` must only clear `vcpu->arch.xive_esc_on` if `XIVE_ESB_SET_PQ_01` returns `!(pq & XIVE_ESB_VAL_P)`; if `xive_esc_on` is still set in `kvmppc_xive_rearm_escalation()`, set `XIVE_ESB_SET_PQ_10` (not 00) and return `false`; and before `free_irq()` in vCPU cleanup, `xive_cleanup_single_escalation()` must synchronize `xd->stale_p` with `xive_esc_on` via `smp_mb()` paired with `smp_wmb()` in `xive_esc_irq()`. [F23, F37]
- In `book3s_xive_native.c`, clear `xive->mapping` under `xive->mapping_lock` in `kvmppc_xive_native_release()`, and bracket all memslot accesses (`kvm_host_page_size()`, `gfn_to_page()`, `mark_page_dirty()`) with `srcu_read_lock(&kvm->srcu)` / `srcu_read_unlock(&kvm->srcu)`. [F25, F160]
- In `book3s_pr.c` and `book3s_paired_singles.c`: bracket `struct kvmppc_book3s_shadow_vcpu` accesses with `svcpu_get(vcpu)` and `svcpu_put(svcpu)`; run `load_fp_state()` / `load_vr_state()` under `preempt_disable()` and `enable_kernel_fp()` / `enable_kernel_altivec()`; and in `kvmppc_emulate_paired_single()`, call `kvmppc_giveup_ext(vcpu, MSR_FP)`, `preempt_disable()`, and `enable_kernel_fp()` before host FP helpers and undo them before returning. [F162, F163, F164]

## Object Lifetimes
- In `kvmppc_get_secmem_size()` and `kvmppc_uvmem_init()`, call `of_node_put(np)` on `"ibm,uv-firmware"`. Allocate `kvmppc_uvmem_bitmap` only after `request_free_mem_region()` and `memremap_pages(&kvmppc_uvmem_pgmap, NUMA_NO_NODE)` succeed (returning 0 if size is 0). `kvmppc_uvmem_free()` must return immediately if `!kvmppc_uvmem_bitmap`, and otherwise call `memunmap_pages()` before `release_mem_region()`. [F1, F156, F157]
- `__kvmppc_uvmem_memslot_create()` runs `kvmppc_memslot_page_merge(kvm, memslot, false)`, `kvmppc_uvmem_slot_init()`, and `uv_register_mem_slot()`; error rollback and `__kvmppc_uvmem_memslot_delete()` must undo these in reverse order. Once `migrate_vma_setup(&mig)` succeeds in `__kvmppc_svm_page_out()` or `kvmppc_svm_page_in()`, every exit must reach `migrate_vma_finalize(&mig)`, unlocking and freeing `dpage` first if `__kvmppc_svm_page_out()` aborts after `lock_page(dpage)`. [F2, F3]
- In `kvmppc_xive_create()`, `kvmppc_xive_native_create()`, and `kvmppc_xics_create()`, assign `kvm->arch.xive` / `xics` only after all fallible steps succeed. In `kvmppc_xics_release()`, `kvmppc_xive_release()`, and `kvmppc_xive_native_release()`, tear down per-vCPU state under `vcpu->mutex` before clearing `kvm->arch.xics`/`xive` and freeing source blocks and `xive->vp_base`. [F10, F11]
- In `kvmppc_xive_connect_vcpu()` and `kvmppc_xive_native_connect_vcpu()`, call `xive_native_enable_vp()` before configuring queues or escalation IRQs, and skip queue 7 when `kvmppc_xive_has_single_escalation(xive)` is true. In `kvmppc_xive_cleanup_vcpu()` and `kvmppc_xive_native_cleanup_vcpu()`, set `xc->valid = false`, disable vCPU interrupts, free escalation IRQs (`free_irq()` before `irq_dispose_mapping()` and `kfree()`), disable the VP, and zero `xive_cam_word` before disabling queues and freeing `q->qpage`. [F14, F15, F152]
- In `kvmppc_xive_native_set_queue_config()`, validate `kvm_host_page_size()` before `gfn_to_page()`, call `put_page(virt_to_page(qpage_prev))` in `kvmppc_xive_native_configure_queue()`, and call `kvmppc_xive_native_cleanup_queue()` on later errors. In `kvmppc_xive_free_sources()`, passthrough IRQs (`state->pt_number`) must only be masked via `kvmppc_xive_cleanup_irq()` and never unmapped or freed. [F12, F16]

## API Contracts
- In `book3s_hv_uvmem.c`: `kvmppc_send_page_to_uv()` returns `RESUME_GUEST` (0) or `-EFAULT` (not `H_*`); `__kvmppc_svm_page_out()` must set `mig.pgmap_owner = &kvmppc_uvmem_pgmap` and `dst_pfn = 0` before `migrate_vma_setup(&mig)`; `uv_page_in()` / `uv_page_out()` take byte addresses (`pfn << page_shift`, `gpa`), whereas `kvmppc_gfn_*` helpers take frame numbers; and `kvmppc_memslot_page_merge()` must use `vma_start_write(vma)` under `mmap_write_lock(kvm->mm)` and pass a local copy of `vma->vm_flags` to `ksm_madvise()`. [F40, F41, F42, F177]
- In XIVE: `xive_native_configure_queue()` takes byte shift `xive->q_order` while `__get_free_pages()` / `free_pages()` take page order `xive->q_page_order`; `kvmppc_xive_push_vcpu()` / `pull_vcpu()` must only access `tima + TM_QW1_OS` when `!kvmppc_xive_vcpu_has_save_restore(vcpu)` (reading `TM_SPC_PULL_OS_CTX` before `TM_QW1_OS` on pull); and `kvmppc_xive_native_supported()` requires `xive_native_has_queue_state_support()`. [F52, F145, F150]

## Error Handling
- Check `gfn_to_hva()` with `kvm_is_error_hva(hva)` in `book3s_hv_uvmem.c`; initialize `new_state.raw = 0` before setting fields of `union kvmppc_icp_state` in `kvmppc_xics_set_icp()`; initialize and compare `xive->vp_base` against `XIVE_INVALID_VP` (`0xffffffff`); and in `kvmppc_xive_native_connect_vcpu()`, set `vcpu->arch.xive_vcpu = xc` and `vcpu->arch.irq_type = KVMPPC_IRQ_XIVE` before any OPAL call that jumps to `bail`. [F39, F47, F49, F54]

## External Contracts
- In `kvmppc_rtas_hcall()`, check `be32_to_cpu(args.nargs) < ARRAY_SIZE(args.args)`, redirect `args.rets = &args.args[be32_to_cpu(args.nargs)]`, and restore `args.rets = orig_rets` before `kvm_write_guest()`. Each handler must verify `nargs` and `nret` before accessing `args[]` or `rets[1..]`, and compare token names with `rtas_name_matches()` (`strncmp`). [F53, F84, F139]
- `kvmppc_h_svm_page_in()` / `out()` must enforce `page_shift == PAGE_SHIFT` (`H_P3`), valid flags (`H_P2`), and `vma->vm_start <= start && vma->vm_end >= end`. When `xisr == 0` in `KVM_REG_PPC_ICP_*`, `pending_pri` must be `0xff`. [F88, F101]

## Known Pitfalls
- In `book3s_xive.c`: clamp `xive->q_page_order` to 0 when `xive->q_order < PAGE_SHIFT`; widen `prio` to `u64` before `<< KVM_XICS_PRIORITY_SHIFT` (32) in `xive_get_source()` and `xics_get_source()`; index `xc->queues[j]` (not outer vCPU index `i`) in `xive_pre_save_scan()`; read `TM_PIPR` via 64-bit `__raw_readq(xive_tima + TM_QW1_OS)` in `xive_vm_h_ipoll()`; and in `xive_vm_esb_load()`, OR `XIVE_ESB_LD_ST_MO` into `XIVE_ESB_SET_PQ_10` when `XIVE_IRQ_FLAG_STORE_EOI` is set and shift `__raw_readq()` right by 56 on `__LITTLE_ENDIAN__`. [F110, F128, F131, F146, F148]
- In `book3s_hv_uvmem.c`, store the matched `list_for_each_entry()` element in a separate `NULL`-initialized pointer in `kvmppc_next_nontransitioned_gfn()`, and scale `const __be32 *prop` offsets by `__be32` elements (`prop + (i * 4) + 2`) in `kvmppc_get_secmem_size()`. [F106, F137]
