# INTEL DRM DISPLAY FOR XE AND I915 DRIVERS

This unit implements core display pipeline subsystems for Intel i915 and Xe drivers, covering atomic plane management (`intel_plane.c`, `intel_plane_initial.c`), Panel Self Refresh and Panel Replay (`intel_psr.c`), Panel Power Sequencing (`intel_pps.c`), Punit PM Demand (`intel_pmdemand.c`), PCH detection and refclk/transcoder/FDI control (`intel_pch*.c`, `intel_sbi.c`), panel fitting (`intel_pfit.c`), pipe CRC capture (`intel_pipe_crc.c`), DSC QP tables (`intel_qp_tables.c`), and hardware quirks (`intel_quirks.c`).

## Architecture & Data Flow

- `struct intel_global_state base` must remain the first member of `struct intel_pmdemand_state` (freed via `kfree(state)` in `intel_pmdemand_destroy_state()`), and `struct drm_framebuffer base` must remain the first member of `struct intel_framebuffer` (freed via `kfree(&plane_config->fb->base)` in `plane_config_fini()`). [F127, F128]
- In `skl_crtc_planes_update_arm()`, plane arming must be ordered by repeatedly calling `skl_next_plane_to_commit()`, which skips planes whose new `plane_ddb` or `plane_ddb_y` overlaps another uncommitted plane's old DDB entry, clears `BIT(plane_id)` in `*update_mask`, and updates `ddb[plane_id]` and `ddb_y[plane_id]`. [F107]
- When `crtc_state->enable_psr2_sel_fetch` is set, `intel_psr2_sel_fetch_update()` must compute both `psr2_man_track_ctl` and `pipe_srcsz_early_tpt`, and both `intel_psr2_program_trans_man_trk_ctl()` and `intel_psr2_panic_force_full_update()` must write `PIPE_SRCSZ_ERLY_TPT` alongside `PSR2_MAN_TRK_CTL` when `enable_psr2_su_region_et` is set. [F74]
- Per-connector VBT PSR support (`connector->panel.vbt.psr.enable`) must be checked in `psr_global_enabled()` when `intel_dp->psr.debug` is `I915_PSR_DEBUG_DEFAULT`; `intel_psr_init()` must never overwrite the device-wide `display->params.enable_psr`. [F78]
- When `intel_num_pps(display) > 1`, `pps_initial_setup()` must check if `intel_dp->pps.pps_idx` (from `connector->panel.vbt.backlight.controller`) is `>= intel_num_pps(display)` and reset out-of-range values to `-1` before probing hardware via `bxt_initial_pps_idx()`. [F81]
- In `intel_pmdemand_update_active_non_tc_phys()`, for each modesetting connector, `intel_pmdemand_update_connector_phys()` must be called with `(old_conn_state, false)` before `(new_conn_state, true)`, looking up `old_crtc_state` when `set_bit` is false and `new_crtc_state` when `set_bit` is true; `intel_pmdemand_atomic_check()` and `intel_pmdemand_update_max_ddiclk()` must convert kHz to MHz via `DIV_ROUND_UP(..., 1000)` and clamp `active_dbufs`/pre-Xe3 `active_pipes` to `3` and `active_phys`/`plls` to `7`. [F104, F121]
- Enumerators in `enum intel_pch` must be ordered by south display engine compatibility—real PCHs in ascending order (`PCH_IBX` through `PCH_ADP`) and fake on-die south display PCHs starting at `PCH_DG1 = 1024`—inserting any new PCH whose south display is not inherited from the last entry immediately after its parent PCH; in descending `INTEL_PCH_TYPE(display) >= ...` chains like `intel_num_pps()`, higher-numbered enums (`PCH_MTL`) must precede lower-numbered ones (`PCH_DG1`, `PCH_ICP`). [F89, F97]
- On `DISPLAY_VER(display) < 9`, `intel_pch_pfit_check_dst_window()` must reject `crtc_state->pch_pfit.dst` rectangles where `x == 1`, where `adjusted_mode->crtc_hdisplay != 2 * x + width` or `crtc_vdisplay != 2 * y + height`, or where `y` or `height` is odd on an interlaced mode; in `pch_panel_fitting()` under `DRM_MODE_SCALE_ASPECT`, scaled `width` and `height` must be rounded up to even integers before centering. [F85, F122]

## Synchronization

- `intel_pps_lock()` must get the `POWER_DOMAIN_DISPLAY_CORE` wakeref before locking `display->pps.mutex`, and `intel_pps_unlock()` must unlock `display->pps.mutex` before putting that wakeref; power domain reset hooks (`vlv_pps_reset_all()`, `bxt_pps_reset_all()`) must never lock `display->pps.mutex`. [F10]
- `cancel_delayed_work_sync(&intel_dp->pps.panel_vdd_work)` in `intel_pps_vdd_off_sync()` must be called without holding `display->pps.mutex` (callers holding `pps.mutex` like `intel_pps_vdd_on_unlocked()` must use `cancel_delayed_work()`); `edp_panel_vdd_schedule_off()` must not queue `panel_vdd_work` while `intel_dp->pps.initializing` is true (set in `intel_pps_init()` and cleared in `intel_pps_init_late()`). [F27, F154]
- `intel_psr_lock()` and `intel_psr_wait_for_idle_locked()` acquire the sleeping `intel_dp->psr.lock` mutex and perform sleeping MMIO waits (`intel_psr_wait_for_idle_locked()` requires `psr.lock` held), so vblank evasion paths must call them before `local_irq_disable()` and call `intel_psr_unlock()` only after `local_irq_enable()`. [F33, F158]
- Because `__psr_wait_for_idle_locked()` temporarily drops `intel_dp->psr.lock` while waiting for PSR idle, `intel_psr_work()` must re-verify `enabled`, `!pause_counter`, `!busy_frontbuffer_bits`, and `!active` after re-acquiring `psr.lock` before calling `intel_psr_activate()`. [F17]
- `intel_psr_disable()` and `intel_psr_pause()` must update `psr.enabled` or `psr.pause_counter` under `intel_dp->psr.lock` and release `psr.lock` before calling `cancel_work_sync(&psr->work)` and `cancel_delayed_work_sync(&psr->dc3co_work)`. [F28]
- In hardirq context, `intel_psr_irq_handler()` must not acquire `intel_dp->psr.lock` or perform DP AUX transactions; on a PSR error interrupt (`psr_irq_psr_error_bit_get`), it must mask the error bit in `psr_imr_reg`, set `psr.irq_aux_error = true`, and queue `intel_dp->psr.work`. [F157]
- In `intel_psr2_program_trans_man_trk_ctl()`, `dsb` is nullable: when `dsb` is `NULL` (CPU MMIO path), `intel_dp->psr.lock` must be held, whereas when `dsb` is non-null (DSB command buffer path), `psr.lock` is not required. [F48]
- All accesses to `XELPDP_INITIATE_PMDEMAND_REQUEST` in `intel_pmdemand_init_pmdemand_params()`, `intel_pmdemand_program_dbuf()`, and `intel_pmdemand_program_params()` must hold `display->pmdemand.lock` and verify via `intel_pmdemand_check_prev_transaction()` that no prior request is active; `intel_pmdemand_pre_plane_update()` must program `max3(old_val, new_val, current_val)` (reading `current_val` from hardware when `!serialized`), and `intel_pmdemand_post_plane_update()` passes `old = NULL` to program `max(new_val, current_val)`. [F142, F144]

## Object Lifetimes

- In `intel_prepare_plane_fb()`, any failure after `intel_plane_pin_fb()` succeeds must jump to `unpin_fb` to call `intel_plane_unpin_fb(new_plane_state)`, and `intel_cleanup_plane_fb()` must call both `intel_display_rps_mark_interactive(display, state, false)` and `intel_plane_unpin_fb(old_plane_state)` when `obj` is non-NULL. [F4]
- Enabling `EDP_FORCE_VDD` in `intel_pps_vdd_on_unlocked()` or adopting BIOS-enabled VDD in `pps_vdd_init()` must hold an `intel_aux_power_domain(dig_port)` wakeref in `intel_dp->pps.vdd_wakeref` until VDD is cleared and `fetch_and_zero(&intel_dp->pps.vdd_wakeref)` is released in `intel_pps_vdd_off_sync_unlocked()` or `intel_pps_off_unlocked()`. [F131]
- When `vlv_power_sequencer_kick()` temporarily enables a disabled pipe DPLL (`!pll_enabled`), it must call `vlv_force_pll_off(display, pipe)` after toggling `DP_PORT_EN` and, if `release_cl_override` is true, call `chv_phy_powergate_ch(display, phy, ch, false)`. [F11]
- When disabling PSR1 in `intel_psr_exit()`, `intel_dmc_start_pkgc_exit_at_start_of_undelayed_vblank(display, intel_dp->psr.pipe, false)` must only be called when `intel_dp->psr.pkg_c_latency_used` is true (in addition to the platform check), matching `hsw_activate_psr1()`. [F15]
- In `intel_crtc_set_crc_source()`, any exit after `intel_display_power_get_if_enabled()` must jump to `out` to release `wakeref` via `intel_display_power_put()`; in `intel_pch_detect()`, `intel_pch_fake_for_south_display()` must be checked before probing PCI devices, and the `pci_get_class(PCI_CLASS_BRIDGE_ISA << 8, pch)` loop must call `pci_dev_put(pch)` on exit. [F19, F147]

## API Contracts

- Callers of `enc_to_intel_dp(encoder)` must first verify that `encoder` is a DP or DP MST encoder (via `intel_encoder_is_dp(encoder)`, `encoder->type == INTEL_OUTPUT_DP_MST`, `for_each_intel_dp()`, or `for_each_intel_encoder_with_psr()`), because `enc_to_intel_dp()` unconditionally evaluates `&enc_to_dig_port(encoder)->dp`. [F44]
- `intel_plane_data_rate()` and `intel_plane_relative_data_rate()` must return `0` if `!plane_state->uapi.visible` before dereferencing `plane_state->hw.fb->format`; in `.check_plane()`, `intel_plane_check_clipping()` must precede `intel_plane_check_src_coordinates()`, which truncates 16.16 fixed-point `uapi.src` via `>> 16` and `<< 16` without rounding up and rejects unaligned coordinates with `-EINVAL` and `drm_dbg_kms()`. [F45, F55, F169]
- Callers of `intel_adjusted_rate()` must pass `src` dimensions in 16.16 fixed-point (`<< 16`) and `dst` in integer pixels, and `intel_adjusted_rate()` must use `mul_u32_u32(rate, src_w * src_h)` and `DIV_ROUND_UP_ULL()` to avoid 32-bit overflow, truncation, or division by zero. [F110, F111]
- In `intel_plane_update_noarm()` and `intel_plane_update_arm()`, `plane->update_noarm` and `plane->async_flip` are optional and must be null-checked before invocation (whereas `plane->update_arm` and `plane->disable_arm` are mandatory). [F46]
- `intel_pmdemand_update_params()` accepts a nullable `old` pointer (`old ? old->params.<field> : 0`), and `intel_pmdemand_program_dbuf()` takes `dbuf_slices` as a slice bitmask (`hweight8(dbuf_slices)`), whereas `pmdemand_state->params.active_dbufs` stores the slice count directly. [F47, F60]
- On `DISPLAY_VER(display) >= 12`, `TRANS_PSR_IMR` and `TRANS_PSR_IIR` use unshifted `TGL_PSR_*` bits (via `psr_irq_*_bit_get()`), whereas pre-12 `EDP_PSR_IMR`/`IIR` shift bits by `_EDP_PSR_TRANS_SHIFT(trans)`; per-port `PORT_ALPM_CTL(port)` and `PORT_ALPM_LFPS_CTL(port)` are indexed by `enum port`, whereas `PR_ALPM_CTL`, `ALPM_CTL`, and `ALPM_CTL2` take `enum transcoder`. [F56, F57]
- In `intel_psr_disable_locked()`, DPCD `DP_PSR_EN_CFG` and `DP_RECEIVER_ALPM_CONFIG` must only be cleared when `!intel_dp->psr.panel_replay_enabled`, whereas source ALPM must be disabled via `intel_alpm_disable(intel_dp)` when `panel_replay_enabled && intel_dp_is_edp(intel_dp)`; `intel_psr_needs_aux_io_power()` must require both `intel_crtc_has_type(crtc_state, INTEL_OUTPUT_EDP)` and `intel_encoder_can_psr(encoder)`. [F137, F138]
- In `intel_pps_have_panel_power_or_vdd()` and `intel_pps_check_power_unlocked()`, eDP AUX power requires `edp_have_panel_power(intel_dp) || edp_have_panel_vdd(intel_dp)`; before `lpt_program_iclkip()` runs during modeset enable, compute-config must quantize `adjusted_mode.crtc_clock = lpt_iclkip(crtc_state)`. [F99, F174]
- Any change to declarations in `intel_pch_display.h`, `intel_pch_refclk.h` (`#ifdef I915`), or `intel_pipe_crc.h` (`#ifdef CONFIG_DEBUG_FS`) must update the `#else` stubs in lockstep; under `#ifndef CONFIG_DEBUG_FS`, `intel_crtc_set_crc_source`, `intel_crtc_verify_crc_source`, and `intel_crtc_get_crc_sources` must be `NULL` macros so `INTEL_CRTC_FUNCS` leaves them unset. [F79, F165]

## Error Handling

- In `intel_psr.c`, `drm_dp_dpcd_readb()` returns `1` on success, so callers (such as `psr_get_status_and_error_status()`) must check `ret == 1` or `ret != 1`; in `intel_psr2_sel_fetch_pipe_alignment()` and `intel_psr2_sel_fetch_update()`, DSC slice alignment and `psr2_su_area.y1 == -1` fallback must not emit `drm_warn()`, using `drm_info_once()` with `full_update = true` when `y1 == -1`. [F39, F173]
- `intel_atomic_get_pmdemand_state()` and `intel_plane_alloc()` return `ERR_PTR()` on failure (`IS_ERR()`), whereas `intel_atomic_get_old_pmdemand_state()`, `intel_atomic_get_new_pmdemand_state()`, `intel_plane_duplicate_state()`, and `intel_pmdemand_duplicate_state()` return `NULL`. [F40, F42]

## External Contracts

- `intel_psr_debug_set()` must reject `val` with `-EINVAL` before modifying `intel_dp->psr.debug` if any bit outside `I915_PSR_DEBUG_IRQ | I915_PSR_DEBUG_SU_REGION_ET_DISABLE | I915_PSR_DEBUG_PANEL_REPLAY_DISABLE | I915_PSR_DEBUG_MODE_MASK` is set or if `val & I915_PSR_DEBUG_MODE_MASK` exceeds `I915_PSR_DEBUG_ENABLE_SEL_FETCH`. [F94]

## Known Pitfalls

- Every `intel_framebuffer.panic_tiling` callback in `intel_plane.c` (`intel_ytile_get_offset`, `intel_4tile_get_offset`, returned by `intel_get_tiling_func`) must take parameters in `(unsigned int width, unsigned int x, unsigned int y)` order, even though `struct intel_framebuffer` names them `(x, y, width)`. [F123]
- `psr2_man_trk_ctl_calc()` and `psr2_pipe_srcsz_early_tpt_calc()` must bail out when `full_update` is true or `crtc_state->psr2_su_area.y1 == -1` before passing coordinates into `REG_FIELD_PREP()`; when active, `psr2_man_trk_ctl_calc()` must encode bounds as 0-based `y1` and inclusive `y2 - 1` lines on ADL-P and `DISPLAY_VER >= 14`, but as 1-based 4-line block indices `y1 / 4 + 1` and `y2 / 4 + 1` on earlier platforms. [F86, F115]
- `hsw_activate_psr2()` must encode `EDP_PSR2_CTL` wake lines as `8 - lines` on `DISPLAY_VER` 9–11, as `lines - 5` on `DISPLAY_VER >= 12`, and via `map[lines - 5]` on ADL-P `< STEP_E0`; on `DISPLAY_VER >= 20`, `_psr_invalidate_handle()` and `_psr_flush_handle()` must call `intel_psr_exit()` (and queue `psr.work` on flush) instead of `intel_psr_configure_full_frame_update()`/`intel_psr_force_update()`; `intel_psr_wait_for_idle_locked()` and `intel_psr_wait_for_idle_dsb()` must return early when Panel Replay is active. [F88, F135, F136]
- `pps_init_delays_bios()` must cache initial hardware timings in `intel_dp->pps.bios_pps_delays` before `pps_init_delays()` sets `backlight_on = 1` / `backlight_off = 1` and rounds `power_cycle` up to `msecs_to_pps_units(100)` (`pps_units_to_msecs()` uses `DIV_ROUND_UP(val, 10)`); `wait_panel_power_cycle()` must compute `panel_power_cycle_delay - panel_power_off_duration` in signed `s64` clamped with `max(0, ...)`. [F70, F117, F119]
- In `intel_pps_off_unlocked()`, turning off panel power must clear `PANEL_POWER_ON`, `PANEL_POWER_RESET`, `EDP_FORCE_VDD`, and `EDP_BLC_ENABLE` in `PP_CONTROL` in a single write followed by `wait_panel_off()`; on VLV/CHV, `vlv_find_free_pps()` must check `vlv_pps_pipe` and `vlv_active_pipe` against `INVALID_PIPE` before `1 << pipe`, and `vlv_power_sequencer_kick()` must preserve `DP_DETECTED`, ensure the pipe DPLL is enabled, and pulse `DP_PORT_EN`. [F120, F132, F133]
- `struct intel_pmdemand_state` and `struct pmdemand_params` must be zero-initialized (`kzalloc`, `kmemdup`, or `memset`) because `intel_pmdemand_state_changed()` uses `memcmp()`; `intel_pmdemand_program_params()` must only trigger `XELPDP_PMDEMAND_REQ_ENABLE` when request registers changed, and on `DISPLAY_VER(display) == 20` `intel_pmdemand_wait()` must poll via `intel_pmdemand_poll()` instead of waiting on `pmdemand.waitqueue`. [F95, F143]
- `ilk_pfit_disable()` must return without writing registers when `!old_crtc_state->pch_pfit.enabled`, and `i9xx_pfit_enable()`/`disable()` must only program `PFIT_CONTROL` while `cpu_transcoder` is disabled; in `intel_init_dpcd_quirks()`, `sink_oui` requires an exact 3-byte match whereas all-zero `sink_device_id` (`SINK_DEVICE_ID_ANY`) acts as a wildcard. [F93, F149]
