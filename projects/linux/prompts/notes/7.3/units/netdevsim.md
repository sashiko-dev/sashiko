# NETDEVSIM

NETDEVSIM is a simulated networking device driver and virtual bus (`netdevsim`) used for kernel selftests of networking, devlink, ethtool, BPF/XDP offload, FIB/nexthop offload, hardware stats, psample, IPsec, MACsec, PSP, and UDP tunnel port offload subsystems. It exposes sysfs attributes on `/sys/bus/netdevsim` to dynamically create/delete simulated bus devices, add/delete PF and SR-IOV VF ports, and link peer netdevs across network namespaces, while providing extensive debugfs knobs to inject errors and inspect offloaded state.

## Architecture & Data Flow

- Only PF ports (`nsim_dev_port_is_pf()`) run `nsim_init_netdevsim()` to allocate `ns->rq`, `ns->phc`, `dev->udp_tunnel_nic_info`, and BPF/MACsec/IPsec offloads; VF ports (`nsim_dev_port_is_vf()`) run `nsim_init_netdevsim_vf()` (`nsim_vf_netdev_ops`) without `ns->rq`. `nsim_destroy()` must gate PF-only teardown on `nsim_dev_port_is_pf()`, and `netdev_is_nsim()` must check `dev->netdev_ops == &nsim_netdev_ops` so `link_device_store()` rejects VFs. [F69, F152]
- Per-netdev debugfs directories and files (`nsim_ethtool_init()`, `nsim_bpf_init()`, `nsim_udp_tunnels_info_create()`, `nsim_ipsec_init()`, `nsim_psp_init()`, `nsim_create()`) must be created under `ns->nsim_dev_port->ddir`, not the shared device directory `ns->nsim_dev->ddir`. [F66]
- Before dereferencing `prog->aux->offload->dev_priv` as `struct nsim_bpf_bound_prog *` in `nsim_prog_set_loaded()` or `nsim_setup_prog_hw_checks()`, verify `bpf_prog_is_offloaded(prog->aux)` rather than `prog->aux->offload != NULL`, because device-bound non-offloaded programs also set `prog->aux->offload`. [F50]
- `ns->bpf_offloaded` is shared between TC BPF and XDP hardware offload (`nsim_xdp_offload_active(ns)`): `nsim_bpf_disable_tc()` must only return `-EBUSY` when `ns->bpf_offloaded && !nsim_xdp_offload_active(ns)`, `nsim_xdp_offload_prog()` must return `-EBUSY` when `!nsim_xdp_offload_active(ns) && bpf->prog && ns->bpf_offloaded`, and `nsim_bpf_offload()` must keep `ns->bpf_offloaded`, `ns->bpf_offloaded_id`, and `state->is_loaded` synchronized on both old and new programs. [F74, F106]
- `nsim_fib4_prepare_event()` and `nsim_fib6_prepare_event()` pre-increment `fib.num` on `FIB_EVENT_ENTRY_REPLACE` (never on `FIB_EVENT_ENTRY_APPEND`, since multipath IPv6 routes extend `nh_list` on one `nsim_fib6_rt`). Thus `nsim_fib4_rt_replace()`, `nsim_fib6_rt_replace()`, and `rhashtable_insert_fast()` error paths in `nsim_fib4_rt_add()`/`nsim_fib6_rt_add()` must decrement `fib.num` via `nsim_fib_account(..., false)`. [F19, F111]
- Every `struct nsim_fib_rt_key` must be zeroed across `sizeof(struct nsim_fib_rt_key)` before setting fields because `nsim_fib_rt_ht_params` hashes padding and unused `addr` bytes. `key.family` discriminates `container_of()` downcasts to `struct nsim_fib4_rt` (`AF_INET`) vs `struct nsim_fib6_rt` (`AF_INET6`), `fib_event->family` discriminates `fen_info` vs `fib6_event` in `struct nsim_fib_event`, and host-order IPv4 `dst`/`key.addr` must be converted with `cpu_to_be32()` for `struct fib_rt_info.dst`. [F54, F56, F94, F135]
- Because `nsim_start_peer_tx_queue()` only wakes stopped TX queues while `dev->real_num_tx_queues == peer_dev->num_rx_queues` on a linked peer, both `unlink_device_store()` and `nsim_set_channels()` (when `ns->peer` is set) must call `synchronize_net()` and wake all TX queues on both devices via `nsim_wake_queues()`. [F68]
- `nsim_qreset_write()` must validate `queue < ns->netdev->real_num_rx_queues` and set/reset `ns->rq_reset_mode` back to `0` under `netdev_lock(ns->netdev)` around `netdev_rx_queue_restart()`; `nsim_queue_mem_alloc()` (which rejects `rq_reset_mode > 3`), `nsim_queue_stop()`, `nsim_queue_start()`, and `nsim_queue_mem_free()` branch on `ns->rq_reset_mode` to coordinate NAPI and `page_pool` ownership. [F77, F102]
- Any code extracting a 0-based `ipsec->sa[]` index from `xs->xso.offload_handle` must mask out `NSIM_IPSEC_VALID` (`~NSIM_IPSEC_VALID`) and, on packet paths like `nsim_ipsec_tx()`, reject `sa_idx >= NSIM_IPSEC_MAX_SA_COUNT`. In `struct nsim_sa`, IPv4 addresses occupy `sa.ipaddr[3]` (copied unconditionally in `nsim_ipsec_add_sa()` for both `IN` and `OUT`, while `sa.rx = true` is `IN`-only) and IPv6 occupies all of `sa.ipaddr[4]`. [F87, F105, F136]
- VF devlink ports store `port_index` offset by `NSIM_DEV_VF_PORT_INDEX_BASE` (128), so any code indexing `nsim_dev->vfconfigs[]` from a VF `nsim_dev_port->port_index` must subtract `NSIM_DEV_VF_PORT_INDEX_BASE` via `nsim_dev_port_index_to_vf_index()`. [F89]

## Synchronization

- Lock hierarchy across bus, devlink, and netdev: `nsim_bus_dev_numvfs_store()` holds `device_lock(dev)` around `dev_get_drvdata(dev)` and `nsim_drv_configure_vfs()`, establishing `device_lock(dev)` -> `devl_lock(devlink)` -> `rtnl_lock()`. `nsim_bus_dev_set_vfs()` holds both `devl_lock()` and `rtnl_lock()` to update `nsim_bus_dev->num_vfs` (so `nsim_dev_get_vfs()` callers may hold either), and `nsim_bus_dev_max_vfs_write()` holds `devl_lock()` while checking `nsim_dev_get_vfs()` and swapping `nsim_dev->vfconfigs`. [F34, F35]
- `nsim_drv_probe()` and `nsim_drv_remove()` must hold `devl_lock(devlink)` across `devl_register()`/`devl_unregister()` and all `nsim_dev` subcomponent init/teardown, and all mutations or traversals of `nsim_dev->port_list` (`nsim_drv_probe()`, `nsim_drv_remove()`, `nsim_drv_port_add()`, `nsim_drv_port_del()`, `nsim_drv_configure_vfs()`, `nsim_dev_reload_down()`/`up()`, `nsim_devlink_eswitch_mode_set()`, `nsim_dev_trap_report_work()`) must hold `devl_lock()`. [F36, F146]
- Because `nsim_dev_traps_exit()` calls `cancel_delayed_work_sync(&nsim_dev->trap_data->trap_report_dw)` under `devl_lock(devlink)`, `nsim_dev_trap_report_work()` must use `devl_trylock()` and re-queue with a non-zero delay (`1` jiffy, not `0`) on contention. Workqueue loops over `nsim_dev->port_list` in `nsim_dev_trap_report_work()` and `fib_event_queue` in `nsim_fib_event_work()` must call `cond_resched()` per entry. [F37, F103, F104]
- `nsim_dev_trap_report()` must hold `nsim_trap_data->trap_lock` across the trap iteration and nest `spin_lock_bh(&nsim_dev->fa_cookie_lock)` inside `trap_lock` around `nsim_dev->fa_cookie` access and `devlink_trap_report()`. `nsim_dev_trap_fa_cookie_read()` and `nsim_dev_trap_fa_cookie_write()` must never access user memory or do `GFP_KERNEL` allocations while holding `fa_cookie_lock`. [F38, F158]
- In `nsim_init_netdevsim()`, `rtnl_lock()` is released after `register_netdevice()` so `nsim_psp_init()` can run unlocked; if `nsim_psp_init()` fails, `err_unregister_netdev` must re-acquire `rtnl_lock()` before unlinking `ns->peer`, unregistering `ns->netdev`, and running RTNL-protected teardown labels prior to `rtnl_unlock()`. [F6]
- All updates to `struct netdevsim::peer` (`link_device_store()`, `unlink_device_store()`, `nsim_init_netdevsim()`, `nsim_destroy()`) must hold `rtnl_lock()`, and readers not holding `rtnl_lock()` (`nsim_start_xmit()`, `nsim_start_peer_tx_queue()`, `nsim_get_iflink()`, `nsim_wake_queues()`) must dereference `ns->peer` inside `rcu_read_lock()`. [F27]
- `nsim_open()`, `nsim_stop()`, `nsim_queue_start()`, and `nsim_queue_stop()` execute under the netdev instance lock (`netdev_assert_locked(dev)`) and must use locked NAPI helpers (`netif_napi_add_config_locked()`, `netif_napi_del_locked()`, `__netif_napi_del_locked()`, `napi_enable_locked()`, `napi_disable_locked()`). [F163]
- `nsim_bus_init()` sets `nsim_bus_enable` via `smp_store_release(&nsim_bus_enable, true)` only after registering `nsim_bus` and `nsim_driver` and initializing `nsim_bus_devs`; `new_device_store()` and `del_device_store()` must check `smp_load_acquire(&nsim_bus_enable)` under `nsim_bus_dev_list_lock`. Similarly, `nsim_bus_dev->init` is set `false` before `device_register()`/`device_unregister()`, set `true` via `smp_store_release()` in `new_device_store()` after probe, and checked via `smp_load_acquire()` in `new_port_store()` and `del_port_store()`. [F24, F25]
- In `fib.c`, `data->fib_event_queue` must be protected by `spin_lock_bh(&data->fib_event_queue_lock)`, and `nsim_fib_event_work()` must splice `data->fib_event_queue` onto a local list and drop `fib_event_queue_lock` before acquiring `mutex_lock(&data->fib_lock)` to mutate `data->fib_rt_ht` and `data->fib_rt_list`. [F40]

## Object Lifetimes

- `nsim_bus_dev->initial_net` is an unreferenced `struct net *` pointer valid only during synchronous device probe in `nsim_drv_probe()`; all post-probe code must obtain the device netns via `nsim_dev_net(nsim_dev)` (`devlink_net()`) so it tracks devlink netns reloads. [F3]
- In `nsim_bus_dev_new()`, if `device_register(&nsim_bus_dev->dev)` fails, cleanup must call `put_device(&nsim_bus_dev->dev)` and set `nsim_bus_dev = NULL` before falling through to `kfree(nsim_bus_dev)`, because `put_device()` invokes `nsim_bus_dev_release()`. In `nsim_bus_exit()`, after clearing `nsim_bus_enable`, dropping the initial `nsim_bus_devs` ref, and deleting all devices under `nsim_bus_dev_list_lock`, it must wait on `wait_for_completion(&nsim_bus_devs_released)` before `driver_unregister()` and `bus_unregister()`. [F4, F167]
- Because `link_device_store()` links `nsim_a->peer` and `nsim_b->peer` without taking `net_device` refcounts, `nsim_destroy()` and `nsim_init_netdevsim()` error unwind must clear both `peer->peer` and `ns->peer` under `rtnl_lock()` before `unregister_netdevice()`, and `unregister_netdevice()` must complete before `nsim_queue_uninit()` frees `ns->rq` or `nsim_udp_tunnels_info_destroy()` removes `ns->udp_ports.ddir` and frees `dev->udp_tunnel_nic_info`. [F7, F29]
- In `nsim_init_napi()` and `nsim_del_napi()`, every `page_pool_destroy(ns->rq[i]->page_pool)` must be paired with `ns->rq[i]->page_pool = NULL`, and `nsim_del_napi()` must disable all RX queue NAPIs, delete them via `__netif_napi_del_locked()`, and call `synchronize_net()` before destroying their `page_pool`s. [F9]
- `nsim_pp_hold_write()` must hold `rtnl_lock()`, check `!netif_running(ns->netdev) && val` before the `val == true` allocation from `ns->rq[0]->page_pool`, and keep the `val == false` release path reachable when stopped. Releasing `ns->page` in `nsim_pp_hold_write()` or `nsim_destroy()` (after `unregister_netdevice()` and before `free_netdev()`) must obtain the pool via `pp_page_to_nmdesc(ns->page)->pp`—never `ns->rq[0]->page_pool`—and set `ns->page = NULL`. [F8, F33, F109, F150]
- `nsim_dev_reload_destroy()` must return immediately when `devlink_is_reload_failed(devlink)` is true, because a failed `nsim_dev_reload_create()` has already unwound all reload-scoped resources. During normal reload, `nsim_dev_reload_destroy()` must remove `nsim_dev->take_snapshot` via `debugfs_remove()` before `nsim_dev_dummy_region_exit()`, and `nsim_dev_reload_create()` must recreate `take_snapshot` only after `nsim_dev_dummy_region_init()` succeeds. [F16, F39]
- Teardown ordering for delayed-work subsystems: `nsim_dev_hwstats_exit()` must call `cancel_delayed_work_sync(&hwstats->traffic_dw)`, `debugfs_remove_recursive(hwstats->ddir)`, and `unregister_netdevice_notifier_net()` before `nsim_dev_hwsdev_list_wipe()` (which releases each `hwsdev->netdev` ref via `nsim_dev_hwsdev_fini()`) and `mutex_destroy()`. Likewise, `nsim_dev_psample_disable()` and `nsim_dev_psample_exit()` must `cancel_delayed_work_sync(&psample->psample_dw)` (and remove `psample->ddir` in `exit`) before `psample_group_put(psample->group)` and `kfree(psample)`. [F21, F45, F46]
- Because `nmap->entry[idx].key != NULL` marks an occupied slot in `struct nsim_bpf_bound_map`, `nsim_map_alloc_elem()` must free `nmap->entry[idx].key` and set it to `NULL` if allocating `nmap->entry[idx].value` fails, and `nsim_map_delete_elem()` must zero `nmap->entry[idx]` after freeing `key` and `value`. [F23]
- Every loop over `nsim_dev->port_list` calling `__nsim_dev_port_del()` (`nsim_esw_legacy_enable()`, `nsim_esw_switchdev_enable()` error unwind, `nsim_dev_port_del_all()`) and every route flush loop over `data->fib_rt_list` (`nsim_fib_dump_inconsistent()`, `nsim_fib_flush_work()`) must use `list_for_each_entry_safe()`, removing `fib_rt->ht_node` via `rhashtable_remove_fast()` before `nsim_fib_rt_free()` unlinks `fib_rt->list`. [F113, F114]

## API Contracts

- In `nsim_get_ringparam()`, current HDS configuration must be read from `dev->cfg->hds_config` rather than `kernel_ring->tcp_data_split`, because `kernel_ring` is an unpopulated out-parameter when called from `ethtool_set_ringparam()`. [F49]
- `nsim_bpf_string_fops` (`nsim_bpf_string_show()`) and `nsim_dev_rate_parent_fops` (`nsim_dev_rate_parent_read()`) expect debugfs `private_data` to be a `char **` / `const char **` pointing to a dynamically updated string pointer field (`&state->state` or `&nsim_dev_port->parent_name`), not a direct `char *`. [F131]
- In `nsim_dev_devlink_ops`, devlink rate leaf callbacks (`nsim_leaf_tc_bw_set()`, `nsim_leaf_tx_share_set()`, `nsim_leaf_tx_max_set()`, `nsim_rate_leaf_parent_set()`) receive `struct nsim_dev_port *` in `priv`/`priv_child`, whereas rate node callbacks (`nsim_node_*()`, `nsim_rate_node_del()`, `nsim_rate_node_parent_set()`, and `priv_parent` in parent_set callbacks) receive `struct nsim_rate_node *`. [F132]

## Error Handling

- `nsim_queue_free()` must cancel `rq->napi_timer` via `hrtimer_cancel(&rq->napi_timer)` before purging `rq->skb_queue` and freeing `rq`, and must only call `dev_dstats_rx_dropped_add()` (wrapped in `local_bh_disable()`/`local_bh_enable()`) when `rq->skb_queue.qlen` is non-zero, because `nsim_queue_uninit()` can run during `nsim_init_netdevsim()` error rollback before `register_netdevice()` allocates `dev->dstats`. [F31, F48]
- In `nsim_init_netdevsim()`, if `register_netdevice_notifier_dev_net()` fails, `ns->nb.notifier_call` must be reset to `NULL`, because `nsim_destroy()` checks `ns->nb.notifier_call != NULL` before calling `unregister_netdevice_notifier_dev_net()`. [F61]

## Known Pitfalls

- Debugfs write handlers using `copy_from_user()` into a stack buffer (`nsim_bus_dev_max_vfs_write()`, `nsim_nexthop_bucket_activity_write()`, `nsim_qreset_write()`) must reject `size > sizeof(buf) - 1` and NUL-terminate `buf` before calling string parsers (`sscanf()`, `kstrtouint()`). `nsim_dev_health_break_write()` must reject `count == 0 || count > PAGE_SIZE` with `-EINVAL` before calling `memdup_user_nul()` and indexing `break_msg[count - 1]`. [F86, F126]
- In `struct netdevsim`, `udp_ports.ports` is a row pointer (`u32 (*ports)[NSIM_UDP_TUNNEL_N_PORTS]`) aliasing `__ports[2][NSIM_UDP_TUNNEL_N_PORTS]`, so operations across both tables (like `memset()` in `nsim_udp_tunnels_info_reset_write()`) must use `sizeof(ns->udp_ports.__ports)`, not `sizeof(ports)` or `sizeof(*ports)`. [F130]
