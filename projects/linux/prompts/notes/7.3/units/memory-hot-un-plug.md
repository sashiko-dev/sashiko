# MEMORY HOT(UN)PLUG

This unit manages the dynamic addition, onlining, offlining, and removal of physical memory and `ZONE_DEVICE` mappings in the Linux kernel. It coordinates SPARSEMEM section and vmemmap population (including self-hosted vmemmap via `altmap`), zone and NUMA node span resizing, page isolation and migration during offlining, and per-page reference tracking for device memory (`memremap_pages`). It also exposes memory block devices and global hotplug policies through `/sys/devices/system/memory/` and module parameters.

## Architecture & Data Flow

- In `mm/memremap.c`, a `struct dev_pagemap` range's `[PHYS_PFN(range->start), PHYS_PFN(range->end)]` span includes `vmem_altmap` metadata pages on range 0, so `pgmap_pfn_valid()` and `pageunmap_range()` must use `pfn_first(pgmap, range_id)` to skip the `vmem_altmap_offset()` prefix. Broken by: passing `pfn_to_page(PHYS_PFN(range->start))` to `page_zone()` in `pageunmap_range()`. [F75]
- `memremap_pages()` must reject `pgmap->vmemmap_shift > MAX_FOLIO_ORDER` before mapping ranges because `pgmap_vmemmap_nr()` evaluates `1 << pgmap->vmemmap_shift` on a 32-bit signed `int` literal and `pfn_len()` right-shifts the range page count by `pgmap->vmemmap_shift`. [F103]
- In `memremap_pages()`, `params.pgprot` (initialized to `PAGE_KERNEL`) must be updated via `pgprot_decrypted()` for `MEMORY_DEVICE_FS_DAX` and `pgprot_noncached()` for `MEMORY_DEVICE_PCI_P2PDMA`. In `pagemap_range()` and `pageunmap_range()`, `MEMORY_DEVICE_PRIVATE` uses `add_pages()` and `__remove_pages()` without `kasan_add_zero_shadow()` / `kasan_remove_zero_shadow()`, whereas all other `enum memory_type` variants pair `kasan_add_zero_shadow()` / `arch_add_memory()` with `arch_remove_memory()` / `kasan_remove_zero_shadow()`. [F91, F142]
- In `online_pages()`, after `move_pfn_range_to_zone()` initializes pageblocks as isolated (`isolate_pageblock = true`), `zone->nr_isolate_pageblock` must be incremented by `nr_pages / pageblock_nr_pages` under `zone->lock` before calling `online_pages_range()` and `undo_isolate_page_range()`. In `offline_pages()`, once `__offline_isolated_pages()` marks sections offline, `zone->nr_isolate_pageblock` must be decremented directly under `zone->lock`; `undo_isolate_page_range()` is only for the `failed_removal_isolated` rollback while sections remain online. [F56, F57]
- In `do_migrate_range()`, when `folio_contain_hwpoisoned_page(folio)` is true, the code must skip non-hugetlb large folios (`folio_test_large(folio) && !folio_test_hugetlb(folio)`), isolate any LRU folio via `folio_isolate_lru(folio)`, and hold `folio_lock(folio)` around `unmap_poisoned_folio(folio, pfn, false)`. [F150]
- A `struct memory_block`'s `zone` pointer must be set when `memory_block_online()` succeeds and cleared to `NULL` when `memory_block_offline()` succeeds (or when `memory_block_add_nid_early()` detects multiple zones or nodes); `memory_block_offline()` must reject `!mem->zone`. In `early_node_zone_for_memory_block()`, the loop over `MAX_NR_ZONES` must continue scanning after finding the first populated intersecting zone (`matching_zone`) and reset `matching_zone = NULL` if a second one is found. [F68, F92]
- In `memory_subsys_online()`, `mem->online_type` is a transient parameter for `memory_block_change_state(mem, MEM_ONLINE, MEM_OFFLINE)` that defaults to `MMOP_ONLINE` if currently `MMOP_OFFLINE` and must always be reset to `MMOP_OFFLINE` before returning. [F67]
- `memory_block_memmap_on_memory_pages()` must compute the vmemmap page count with ceiling division `PFN_UP(memory_block_memmap_size())` and round it up with `pageblock_align()` when `memmap_mode == MEMMAP_ON_MEMORY_FORCE` so self-hosted vmemmap pages cover the entire memmap and align to full pageblocks. [F106]

## Synchronization

- Lock acquisition order is `device_hotplug_lock` -> `mem->dev.mutex` (via `device_online()` / `device_offline()`) -> `cpus_read_lock` -> `mem_hotplug_lock` (`mem_hotplug_begin()` acquires `cpus_read_lock()` before `percpu_down_write(&mem_hotplug_lock)` and `mem_hotplug_done()` releases them in reverse). `add_memory_resource()` must call `mem_hotplug_done()` before `online_memory_block()` calls `device_online(&mem->dev)`. Broken by: acquiring `cpus_read_lock()` after `get_online_mems()` or calling `device_online()` / `device_offline()` while holding `mem_hotplug_lock`. [F28, F131]
- `online_pages()` and `offline_pages()` must be called in process context with `mem_hotplug_lock` held in write mode (via `mem_hotplug_begin()` in `memory_block_online()` / `memory_block_offline()`), and they invoke blocking notifier chains (`memory_notify`, `node_notify`) while holding `mem_hotplug_lock`. `set_online_page_callback()` and `restore_online_page_callback()` must acquire `get_online_mems()` before locking `online_page_callback_lock`. [F133, F134]
- `offline_pages()` must call `zone_pcp_disable(zone)` and `lru_cache_disable()` before `start_isolate_page_range()`, and re-enable them in reverse order via `lru_cache_enable()` and `zone_pcp_enable(zone)` both after `__offline_isolated_pages()` and on the `failed_removal_pcplists_disabled` error path. When offlining the last present pages of a node (`node_arg.nid >= 0`), `node_clear_state(node, N_MEMORY)` must precede `build_all_zonelists(NULL)`. [F32, F136]
- `get_dev_pagemap()` must perform both the `xa_load(&pgmap_array, ...)` lookup and `percpu_ref_tryget_live_rcu(&pgmap->ref)` inside a single `rcu_read_lock()` / `rcu_read_unlock()` critical section, returning `NULL` when `percpu_ref_tryget_live_rcu()` fails. [F137]
- In `pagemap_range()` and `pageunmap_range()`, `mem_hotplug_begin()` / `mem_hotplug_done()` must wrap page/mapping addition and removal, KASAN zero-shadow updates, and zone span changes (`move_pfn_range_to_zone()` / `remove_pfn_range_from_zone()`), while `memmap_init_zone_device()` runs after `mem_hotplug_done()`. [F140]

## Object Lifetimes

- In `__add_memory_block()`, `device_register(&memory->dev)` initializes the device refcount, so failure of `device_register()` must call `put_device(&memory->dev)` (freeing `memory` via `memory_block_release()`), whereas failure of `xa_store()` after registration must call only `device_unregister(&memory->dev)`. Broken by: calling `kfree(mem)` in `add_memory_block()` when `__add_memory_block()` fails, or calling `put_device()` after `device_unregister()` on `xa_store()` failure. [F1]
- Before unregistering a `struct memory_block` that uses an `altmap`, `remove_memory_blocks_and_altmaps()` must clear `mem->altmap = NULL` before calling `remove_memory_block_devices()` and must pass `altmap` to `arch_remove_memory()` before calling `kfree(altmap)`. [F4]
- A `struct memory_group` allocated by `memory_group_register()` can only be unregistered and freed by `memory_group_unregister()` when `group->memory_blocks` is empty (`-EBUSY` otherwise), and `add_memory_block()` must only link `mem->group_next` after `__add_memory_block()` succeeds. [F5]
- `add_memory_resource()` does not free `res` on failure—so `__add_memory()` and `add_memory_driver_managed()` must call `release_memory_resource(res)` when it returns `< 0`—and when `MHP_MERGE_RESOURCE` is set, callers must not dereference `res` after a successful call because `merge_system_ram_resource(res)` may free it. [F12]
- For `MEMORY_DEVICE_PRIVATE` and `MEMORY_DEVICE_COHERENT`, `pgmap->ref` is acquired per page in `zone_device_page_init()` (`percpu_ref_tryget_live()`) and dropped in `free_zone_device_folio()` (`put_dev_pagemap()`), whereas other `enum memory_type` values bulk-get `pfn_len()` refs in `pagemap_range()` and bulk-put them in `memunmap_pages()`. [F17]
- In `memremap_pages()`, `init_completion(&pgmap->done)` and `percpu_ref_init(&pgmap->ref, ...)` must precede `pagemap_range()` inserting `pgmap` into `pgmap_array`. In `memunmap_pages()`, `percpu_ref_kill(&pgmap->ref)`, the initial `percpu_ref_put_many()`, and `wait_for_completion(&pgmap->done)` must complete before `pageunmap_range()`, and all ranges must be deleted from `pgmap_array` and RCU-synchronized via `pgmap_array_delete()` before `percpu_ref_exit(&pgmap->ref)`. [F19, F22, F125]
- A `dev_pagemap` mapped via `devm_memremap_pages()` is registered with devres (`devm_memremap_pages_release`) and must be manually unmapped before device unbind only via `devm_memunmap_pages(dev, pgmap)`, never by calling `memunmap_pages(pgmap)` directly. [F123]

## API Contracts

- `pfn_to_online_page()` must check `pfn_to_section_nr(pfn) < NR_MEM_SECTIONS` before `__nr_to_section(nr)`, and returns a `struct page *` only when the section is online, `pfn_section_valid()` is true, and `get_dev_pagemap()` returns `NULL` (dropping any non-NULL `dev_pagemap` via `put_dev_pagemap()`). Sub-section `ZONE_DEVICE` additions in `move_pfn_range_to_zone()` must set `SECTION_TAINT_ZONE_DEVICE` via `section_taint_zone_device()` on unaligned boundary sections so `pfn_to_online_page()` checks `online_device_section()`. [F39, F55, F84]
- `arch_get_mappable_range()` and `mhp_get_pluggable_range()` return a `struct range` with inclusive byte bounds `[start, end]`, bounded by `DIRECT_MAP_PHYSMEM_END`. `mhp_range_allowed(start, size, need_mapping)` must check `start < end` (`end = start + size`) and `(end - 1) <= mhp_range.end`. Broken by: comparing `start + size <= mhp_range.end` (fails when `mhp_range.end == U64_MAX`) or using `(1ULL << MAX_PHYSMEM_BITS) - 1`. [F78, F141]
- `memremap_pages()`, `devm_memremap_pages()`, and `register_memory_resource()` return `ERR_PTR` on failure and never `NULL`, whereas `release_memory_resource()` only guards against `NULL`; callers must check `IS_ERR()` before using the result or passing `res` to `release_memory_resource()`. [F33, F34]
- `pgmap->altmap` in `struct dev_pagemap` is valid only when `PGMAP_ALTMAP_VALID` is set in `pgmap->flags` (obtain via `pgmap_altmap(pgmap)` rather than `&pgmap->altmap`). `range` and `ranges` share an anonymous union in `struct dev_pagemap`, so callers with `nr_range > 1` must allocate trailing space for additional `struct range` elements. [F40, F113]
- `add_memory()`, `remove_memory()`, `offline_and_remove_memory()`, `create_memory_block_devices()`, `remove_memory_block_devices()`, and `walk_memory_blocks()` take byte addresses/sizes, whereas `add_pages()`, `__remove_pages()`, `online_pages()`, `offline_pages()`, `move_pfn_range_to_zone()`, `memory_group_register_static()`, and `memory_group_register_dynamic()` take PFNs and page counts. [F49, F154]
- `online_pages()` and `offline_pages()` require `nr_pages != 0`, `pageblock_aligned(start_pfn)`, and `IS_ALIGNED(start_pfn + nr_pages, PAGES_PER_SECTION)`. `MHP_MEMMAP_ON_MEMORY` is only a hint: `add_memory_resource()` must also verify `mhp_supports_memmap_on_memory()` (which checks `pageblock_aligned(memmap_pages)`, `memmap_mode`, and `arch_supports_memmap_on_memory()`), and System RAM `struct mhp_params` must set `.pgprot = pgprot_mhp(PAGE_KERNEL)`. [F77, F126, F149]
- When `MHP_NID_IS_MGID` is set in `mhp_flags`, `add_memory_resource()` interprets `nid` as a memory group ID and must resolve it via `memory_group_find_by_id(nid)` to `group->nid` before checking `node_possible(nid)`. In `struct memory_group`, `group->is_dynamic` discriminates between `group->s.max_pages` and `group->d.unit_pages`, and `memory_group_unregister(int mgid)` must reject `mgid < 0` with `-EINVAL`. [F42, F51, F83]

## Error Handling

- `pagemap_range()` sets up `xa_store_range()` on `pgmap_array`, `pfnmap_track()`, `kasan_add_zero_shadow()` (when `!is_private`), and `add_pages()`/`arch_add_memory()`; failure must unwind completed steps in reverse order. `memremap_pages()` resets `pgmap->nr_range` to 0 and increments it per succeeded `pagemap_range()` so `memunmap_pages(pgmap)` unwinds only succeeded ranges on error, then restores `pgmap->nr_range` before returning. [F15, F45]
- `memory_notify()` and `node_notify()` return raw `NOTIFY_*` codes that must be converted via `notifier_to_errno()`. In `online_pages()` and `offline_pages()`, `node_arg.nid` must be initialized to `NUMA_NO_NODE` and set to `nid` only when `NODE_ADDING_FIRST_MEMORY` or `NODE_REMOVING_LAST_MEMORY` is sent, so error cleanup sends `NODE_CANCEL_*` only when `node_arg.nid != NUMA_NO_NODE`. [F35, F46]
- `__add_pages()` must validate `altmap->base_pfn == pfn` and `vmem_altmap_offset(altmap) <= nr_pages` and zero `altmap->alloc` before populating sections, because teardown warns if `altmap->alloc` is non-zero after removal. [F47]
- `do_migrate_range()` must release `folio_try_get(folio)` via `folio_put(folio)` on every iteration path (`goto put_folio`), return unmigrated isolated folios via `putback_movable_pages(&source)` when `migrate_pages()` fails, and gate failure `pr_warn`/`dump_page` calls with `__ratelimit(&migrate_rs)` without `WARN_ON()`. [F10, F151]

## External Contracts

- `soft_offline_page_store()` and `hard_offline_page_store()` require `capable(CAP_SYS_ADMIN)` (`-EPERM` otherwise) and parse a physical byte address from userspace that must be shifted right by `PAGE_SHIFT` before calling `soft_offline_page()` or `memory_failure()`. [F152]

## Known Pitfalls

- In `memory_block_online()` and `memory_block_offline()`, when `mem->altmap` sets `nr_vmemmap_pages = mem->altmap->free`, `online_pages()` and `offline_pages()` receive `[start_pfn + nr_vmemmap_pages, nr_pages - nr_vmemmap_pages)` while `mhp_init_memmap_on_memory()` / `mhp_deinit_memmap_on_memory()` receive `[start_pfn, nr_vmemmap_pages)` (passing `ALIGN_DOWN(end_pfn, PAGES_PER_SECTION)` to `online_mem_sections()` / `offline_mem_sections()` when `nr_pages >= PAGES_PER_SECTION`). When `nr_vmemmap_pages == 0`, `memory_block_offline()` must not access `pfn_to_page(start_pfn)` because `start_pfn` may be an uninitialized hole before `offline_pages()` checks `walk_system_ram_range()`. [F44, F100, F107]
- In `__add_pages()`, `remove_pfn_range_from_zone()`, and `__remove_pages()`, the per-section step size must be `min(end_pfn - pfn, SECTION_ALIGN_UP(pfn + 1) - pfn)` using `pfn + 1` so `cur_nr_pages` is non-zero when `pfn` is section-aligned. In `online_pages_range()`, `pfn` must be checked to be non-zero before calling `__ffs(pfn)` (using `MAX_PAGE_ORDER` when `pfn == 0`). [F98, F101]
- In `update_pgdat_span()`, empty zones (`!zone->spanned_pages`) must be skipped and `node_start_pfn` / `node_end_pfn` seeded from the first non-empty zone (`if (!node_end_pfn)`) before comparing `zone->zone_start_pfn < node_start_pfn`. In `do_migrate_range()`, `node_states[N_MEMORY]` must be copied into a local `nodemask_t` before calling `node_clear(mtc.nid, nmask)`. [F94, F118]
- `auto_movable_can_online_movable()` must check `nid == NUMA_NO_NODE` before evaluating `NODE_DATA(nid)`, and check `kernel_early_pages <= group_stats.req_kernel_early_pages` before subtracting to avoid `unsigned long` underflow. `auto_movable_stats_account_group()` must snapshot `READ_ONCE(auto_movable_ratio)`, return early if zero before dividing, and hold the result in a signed `long pages`. [F74, F104, F105]
- `set_memmap_mode` and `get_memmap_mode` must access `kp->arg` (`memmap_mode`) as `*(int *)kp->arg` rather than calling `param_get_bool()` / `param_set_bool()`. Runtime hotplug functions and data (`hotplug_memory_notifier`, `resize_zone_range()`, `resize_pgdat_range()`) must use `__meminit` / `__meminitdata` rather than `__init` / `__initdata`. [F73, F129]
