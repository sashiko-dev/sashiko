# NILFS2 FILESYSTEM

This unit implements the core superblock, mount lifecycle, segment usage management (`sufile`), log-structured segment constructor (`segctord`), sysfs hierarchy, and UAPI/on-disk format definitions for NILFS2.

## Architecture & Data Flow

- Superblock buffer heads `ns_sbh[0..1]` and interior pointers `ns_sbp[0..1]` must be swapped, fallen back, replaced, or released in lockstep (`nilfs_swap_super_block()`, `nilfs_fall_back_super_block()`, `nilfs_release_super_block()`, `nilfs_move_2nd_super()`), and because `ns_sbh[1]`/`ns_sbp[1]` can be `NULL`, every access to index 1 requires a non-NULL check. [F43, F57]
- `nilfs->ns_writer` is `NULL` on read-only mounts and after `nilfs_detach_log_writer()`, and `sci->sc_task` is `NULL` before `kthread_create()` succeeds and after `nilfs_segctor_thread()` exits; callers must check both before dereferencing or calling `kthread_stop()` / `add_timer(&sci->sc_timer)`. [F44]
- Because a `super_block` is shared between the current checkpoint (`s->s_root`) and snapshot mounts (`ctx->cno != 0`), `nilfs_get_tree()` must never overwrite `s->s_root` with a snapshot dentry and must only call `nilfs_reconfigure()` on an existing `s->s_root` when `!nilfs_tree_is_busy(s->s_root)`. [F69]
- In `nilfs_segctor_do_construct()`, `sci->sc_stage.flags` must only clear `NILFS_CF_HISTORY_MASK` across loop iterations so `NILFS_CF_NODE` is preserved when `-E2BIG` interrupts a file between data and node collection; also, when `nilfs->ns_blocksize_bits != PAGE_SHIFT`, `nilfs_segctor_wait(sci)` must run after every `nilfs_segctor_write()` iteration even before `NILFS_ST_DONE`. [F90, F149]
- In `nilfs_segctor_complete_write()`, completing a super-root segment (`update_sr`) must reset `nilfs->ns_flushed_device = 0`, call `nilfs_set_last_segment()` with `nilfs->ns_cno++`, clear `NILFS_SC_HAVE_DELTA` and `NILFS_SC_DIRTY`, set `NILFS_SC_SUPER_ROOT`, and call `nilfs_segctor_clear_metadata_dirty(sci)`. [F70]
- In `nilfs_segctor_flush_mode()`, `SC_FLUSH_FILE` is returned only when `!(sci->sc_flush_request & ~FLUSH_FILE_BIT)` and `SC_FLUSH_DAT` only when `!(sci->sc_flush_request & ~FLUSH_DAT_BIT)`, falling back to `SC_LSEG_SR` if multiple bits are set; when `nilfs_segctor_notify()` finishes a non-`SC_LSEG_SR` flush with `NILFS_SEGCTOR_COMMIT` set, `sci->sc_task` alive, and `time_before(jiffies, sci->sc_timer.expires)`, it must re-add `sci->sc_timer`. [F68, F95]
- On-disk `struct nilfs_inode` entries in `struct nilfs_super_root` have variable stride `nilfs->ns_inode_size` (access via `NILFS_SR_*_OFFSET(inode_size)` and `NILFS_SR_BYTES(inode_size)`), and `sufile` entries have variable stride `NILFS_MDT(sufile)->mi_entry_size` (never advance with `su++` or `sizeof(*su)`). [F75, F76]
- `segnum` is 0-based, but block 0 of `sufile` starts with `struct nilfs_sufile_header`, so `nilfs_sufile_get_blkoff()` and `nilfs_sufile_get_offset()` must add `NILFS_MDT(sufile)->mi_first_entry_offset` to `segnum` before dividing. Also, segment 0 starts at `nilfs->ns_first_data_block` while `segnum > 0` starts at `(sector_t)nilfs->ns_blocks_per_segment * segnum`; callers must use `nilfs_get_segment_range()` or `nilfs_get_segment_start_blocknr()`. [F77, F78]
- Every mutation to a segment usage entry's clean/dirty state in `fs/nilfs2/sufile.c` must update `NILFS_SUI(sufile)->ncleansegs` and on-disk `sh_ncleansegs` (and `sh_ndirtysegs` when dirty state changes) in lockstep under `NILFS_MDT(sufile)->mi_sem`, and mark both buffers and `sufile` dirty. Updates to `nilfs->ns_nsegments` must use `nilfs_set_nsegments(nilfs, nsegs)` so `nilfs->ns_nrsvsegs` is updated in lockstep. [F53, F56]

## Synchronization

- Lock hierarchy: `nilfs->ns_segctor_sem` nests outside `nilfs->ns_sem` (`nilfs_segctor_construct()` takes `down_write(&nilfs->ns_sem)` under `ns_segctor_sem`). Code holding `nilfs->ns_sem` must never acquire `ns_segctor_sem` (or call `nilfs_construct_segment()`), must never acquire any metadata file's `mi_sem` (e.g., in `nilfs_count_free_blocks()`), and `init_nilfs()` must not hold `ns_sem` across `sb_min_blocksize()` or `sb_set_blocksize()`. [F29, F128, F131]
- Callers of `nilfs_prepare_super()`, `nilfs_commit_super()`, `nilfs_set_log_cursor()`, `nilfs_cleanup_super()`, `nilfs_setup_super()`, and `nilfs_move_2nd_super()` must hold `down_write(&nilfs->ns_sem)`, and runtime readers of `nilfs->ns_sbp` (such as sysfs show handlers and `nilfs_reconfigure()`) must hold `nilfs->ns_sem` for read. [F28]
- `nilfs_transaction_begin()`, `nilfs_transaction_commit()`, and `nilfs_transaction_abort()` acquire/release `sb_start_intwrite(sb)` and `ns_segctor_sem` only on the outermost call (`ti->ti_count == 0`). `nilfs_transaction_commit()` must release `ns_segctor_sem` and restore `current->journal_info` before calling `nilfs_construct_segment(sb)` (which deadlocks if `current->journal_info` holds a `NILFS_TI_MAGIC` transaction). [F10, F130]
- In `nilfs_relax_pressure_in_lock()`, after setting `NILFS_SC_PRIOR_FLUSH`, dropping `up_read(&nilfs->ns_segctor_sem)`, and acquiring `down_write(&nilfs->ns_segctor_sem)`, both `sci->sc_flush_request` and `test_bit(NILFS_SC_PRIOR_FLUSH, &sci->sc_flags)` must be rechecked before calling `nilfs_segctor_do_immediate_flush(sci)`. [F33]
- `sci->sc_task` and `sci->sc_timer` must be initialized before `wake_up_process(sci->sc_task)` in `nilfs_attach_log_writer()`. `sci->sc_timer` must only be armed (`add_timer`) or deleted (`timer_delete_sync`) after verifying `sci->sc_task != NULL` under `sci->sc_state_lock`; `nilfs_segctor_thread()` must clear `sci->sc_task` and call `timer_shutdown_sync(&sci->sc_timer)` under `sci->sc_state_lock` on exit, so `nilfs_construction_timeout()` must never acquire `sci->sc_state_lock`. [F19, F20, F137]
- In `nilfs_segctor_sync()`, incrementing `sci->sc_seq_request` and queuing `wait_req.wq` onto `sci->sc_wait_request` must happen atomically under `sci->sc_state_lock`, and `set_current_state(TASK_INTERRUPTIBLE)` must precede checking `sci->sc_task` and `wait_req.done` in the wait loop. [F21]
- In `nilfs_prepare_write_logs()`, payload folios (`fs_folio`) must enter writeback via `nilfs_begin_folio_io()` before `nilfs_add_checksums_on_logs()` computes CRCs, and backing-device folios (`bd_folio`) for segment summary or super-root buffers must call `folio_wait_writeback(bd_folio)` under `folio_lock(bd_folio)` before `folio_clear_dirty_for_io()` and `folio_start_writeback()`. [F144, F147]
- In `nilfs_lookup_dirty_data_buffers()`, `folio_lock(folio)` must be held continuously while verifying `folio->mapping == mapping` and iterating `folio_buffers(folio)` to take `get_bh(bh)` references. In `nilfs_segctor_collect_dirty_files()`, `nilfs_segctor_drop_written_files()`, and `nilfs_dispose_list()`, `nilfs->ns_inode_lock` must be dropped before calling sleeping functions like `nilfs_ifile_get_inode_block()` or `iput()`. [F27, F136]
- `nilfs_sufile_mark_dirty()` must acquire `NILFS_MDT(sufile)->mi_sem` and call `nilfs_segment_usage_set_dirty(su)` on the mapped entry in addition to `mark_buffer_dirty(bh)` and `nilfs_mdt_mark_dirty(sufile)`. When shrinking in `nilfs_sufile_resize()`, `sui->allocmax` and `sui->allocmin` must be updated immediately after `nilfs_sufile_truncate_range()` under `mi_sem`, whereas expansion in `nilfs_resize_fs()` must delay `nilfs_sufile_set_alloc_range()` until after `nilfs_move_2nd_super()` and `nilfs_commit_super()`. [F54, F55]
- At runtime, `ns_last_pseg`, `ns_last_seq`, `ns_last_cno`, `ns_prot_seq`, and `ns_prev_seq` must be accessed under `nilfs->ns_last_segment_lock`; in `nilfs_put_root()`, decrementing `root->count` and erasing `root->rb_node` must use `refcount_dec_and_lock(&root->count, &nilfs->ns_cptree_lock)`; and in `nilfs_flush_device()` / `nilfs_commit_super()`, `nilfs->ns_flushed_device = 1` must be ordered before the flush by `smp_wmb()`. [F25, F36, F37]

## Object Lifetimes

- `nilfs_sysfs_create_device_group()` must be called only after `nilfs_load_super_root()` initializes `ns_dat`, `ns_cpfile`, and `ns_sufile`, and `nilfs_sysfs_delete_device_group()` must be called before `iput()` releases those metadata inodes. Tearing down `nilfs->ns_dev_kobj` requires `kobject_del()` followed by `kobject_put()` before freeing `nilfs->ns_dev_subgroups`, and any failed `kobject_init_and_add()` in `sysfs.c` must call `kobject_put()`. [F1, F2]
- In `nilfs_attach_log_writer()`, once `nilfs_segctor_new(sb, root)` assigns `nilfs->ns_writer`, any error starting `segctord` must clean up via `nilfs_detach_log_writer(sb)` (not `kfree(sci)`) so `nilfs_segctor_destroy()` drops `sci->sc_root` and clears `nilfs->ns_writer`. When `nilfs_detach_log_writer()` disposes remaining dirty inodes after `ns_writer` is destroyed, `set_nilfs_purging(nilfs)` (`THE_NILFS_PURGING`) must bracket `nilfs_dispose_list()`, and `__nilfs_mark_inode_dirty()` must return early when `nilfs_purging(nilfs)` is true. [F3, F24]
- In `nilfs_segctor_drop_written_files()` and force-disposal in `nilfs_dispose_list()`, `ii->i_bh` must be released with `brelse()` and cleared to `NULL`, and `iput()` must be deferred via `sci->sc_iput_queue` / `sci->sc_iput_work` whenever `!ii->vfs_inode.i_nlink` or `!(sci->sc_super->s_flags & SB_ACTIVE)`. [F17]
- In `nilfs_segctor_update_payload_blocknr()`, `bh_org` must be pinned with `get_bh(bh_org)` before `nilfs_bmap_assign()` and released with `brelse(bh_org)` after `nilfs_list_replace_buffer(bh_org, bh)` because `nilfs_bmap_assign()` may drop the bmap's reference to `bh_org`. [F9]
- `nilfs_attach_checkpoint()` returns a refcounted `struct nilfs_root` via `*rootp` on success, and `nilfs_fill_super()` and `nilfs_attach_snapshot()` must call `nilfs_put_root()` once `nilfs_get_root_dentry()` and `nilfs_attach_log_writer()` hold their own references. In `nilfs_get_root_dentry()`, `d_make_root()` and `d_obtain_root()` consume the `inode` reference on both success and failure, whereas when `d_find_alias()` succeeds or validation fails early, `iput(inode)` must be called explicitly. [F12, F13]

## API Contracts

- `nilfs_segctor_apply_buffers()` unlinks and calls `brelse()` on every `buffer_head` in `listp` (draining `listp` when `collect` is `NULL` or fails), so `nilfs_segctor_scan_file()` must drain `node_buffers` via `nilfs_segctor_apply_buffers(sci, inode, &node_buffers, NULL)` if applying `data_buffers` fails after `nilfs_lookup_dirty_node_buffers()`. [F8]
- `nilfs_sufile_updatev()` must set `*ndone` (when non-NULL) to the number of processed segments (`0` on early failure, or `seg - segnumv` on mid-loop failure) on every return path; when `nilfs_sufile_freev()` fails midway in `nilfs_free_segments()`, `nilfs_sufile_cancel_freev(nilfs->ns_sufile, segnumv, ndone, NULL)` must roll back the `ndone` freed segments. [F7, F49]
- On-disk checkpoint numbers (`cno`) are 1-based, whereas `NILFS_CPTREE_CURRENT_CNO` (`0`) keys the current mount in `nilfs->ns_cptree`; `nilfs_attach_checkpoint()` must key `ns_cptree` with `NILFS_CPTREE_CURRENT_CNO` when `curr_mnt` is true while passing `cno` to `nilfs_ifile_read()`. [F50]

## Error Handling

- In `nilfs_segctor_do_construct()`, any error after the construction loop starts must jump to `failed` or `failed_to_write` to call `nilfs_redirty_inodes(&sci->sc_dirty_files)` (when `mode == SC_LSEG_SR` and stage `>= NILFS_ST_IFILE`), redirty `sc_gc_inodes` if `nilfs_doing_gc()`, and call `nilfs_segctor_abort_construction()`. [F5]
- In `nilfs_attach_log_writer()`, the return value `t` of `kthread_create()` must be checked with `IS_ERR(t)` before assigning `sci->sc_task = t`, so `nilfs_detach_log_writer()` -> `nilfs_segctor_destroy()` does not pass an `ERR_PTR` to `kthread_stop()`. [F46]
-When reading `sufile` blocks with `create == 0`, `-ENOENT` must be translated to `-EIO` or `-EINVAL` where a block is required (`nilfs_sufile_get_header_block()`, `nilfs_sufile_mark_dirty()`, `nilfs_free_segments()`), but skipped as a clean hole in range scans (`nilfs_sufile_truncate_range()`, `nilfs_sufile_get_suinfo()`, `nilfs_sufile_trim_fs()`). [F41]

## Known Pitfalls

- Because `segbuf->sb_super_root` is appended to `segbuf->sb_payload_buffers` as a block-device buffer rather than a file buffer, loops over `sb_payload_buffers` in `nilfs_segctor_update_payload_blocknr()`, `nilfs_prepare_write_logs()`, `nilfs_abort_logs()`, and `nilfs_segctor_complete_write()` must break when `bh == segbuf->sb_super_root`. [F92]
- In `nilfs_prepare_write_logs()`, `nilfs_abort_logs()`, and `nilfs_segctor_complete_write()`, folios can span multiple segment buffers, so the final `fs_folio` and `bd_folio` must be started or completed after the outer `segbuf` loop finishes; also, because B-tree node buffers of one folio can be non-contiguous, `nilfs_begin_folio_io()` must return early if `folio_test_writeback(folio)` is already set and `nilfs_end_folio_io()` must tolerate repeated calls on `buffer_nilfs_node()` folios. [F93, F148]
- In `nilfs_segctor_collect_blocks()`, when `nilfs_segctor_scan_file()` fails on an entry `ii` in `sc_gc_inodes` or `sc_dirty_files`, `gc_inode_ptr` or `dirty_file_ptr` must be saved as `list_entry(ii->i_dirty.prev, ...)` so `list_prepare_entry()` + `list_for_each_entry_continue()` re-visits `ii` on retry. [F89]
- In `nilfs_sufile_trim_fs()`, `kaddr` must be unmapped with `kunmap_local(kaddr)` before sleeping in `blkdev_issue_discard()` and remapped afterward using the current `segnum`'s offset via `nilfs_sufile_segment_usage_offset(sufile, segnum, su_bh)`; also, any branch in the outer `while (segnum <= segnum_end)` loop that skips the inner `for` loop (such as `-ENOENT`) must advance `segnum += n` before `continue`. [F60, F98]
- In `nilfs_sufile_set_suinfo()`, `BIT(NILFS_SEGMENT_USAGE_ACTIVE)` must be masked off `sup->sup_sui.sui_flags` and the prior `nilfs_segment_usage_clean(su)` / `nilfs_segment_usage_dirty(su)` states must be sampled before writing `su->su_flags`. Also, callers of `nilfs_sufile_mod_counter()` passing conditional negative deltas (like `nilfs_sufile_do_scrap()` and `nilfs_sufile_do_free()`) must cast `-1` to `u64` (not `clean ? -1 : 0U`, which zero-extends `0xffffffffU`). [F59, F106]
