# BONDING DRIVER

The Linux Ethernet Channel Bonding driver aggregates multiple network interfaces (slaves) into a single logical master virtual `net_device` (`bond%d`) across seven modes (balance-rr, active-backup, balance-xor, broadcast, 802.3ad, balance-tlb, balance-alb), handling enslavement, link monitoring, hardware offloads (VLAN, IPsec, TLS, XDP), and configuration via rtnetlink, sysfs, ioctl, procfs, and debugfs.

## Architecture & Data Flow

- `BOND_ALB_INFO(bond).tx_hashtbl` is allocated only while open (`bond_open` to `bond_close`), so paths that run while down (`__tlb_clear_slave`) must check `tx_hashtbl != NULL`. Because `0` is a valid bucket in `tx_hashtbl` and `rx_hashtbl`, index links must use `TLB_NULL_INDEX`/`RLB_NULL_INDEX` (`0xffffffff`), and list deletions (`__tlb_clear_slave`, `rlb_purge_src_ip`, `rlb_clear_vlan`) must save the next index before calling `tlb_init_table_entry()` or `rlb_delete_table_entry()`. [F58, F99, F123]
- In `rx_hashtbl[i]`, `src_first` heads entries whose `ip_src` hashes to `i`, independent of the client whose `ip_dst` hashes to `i`; `rlb_delete_table_entry()` must only call `rlb_init_table_entry_dst()` and `rlb_src_unlink()` without resetting `entry->src_first`. In `bond_alb_deinit_slave()`, reset `bond->alb_info.rx_slave = NULL` before `rlb_clear_slave()`. In `BOND_MODE_TLB` (`!rlb_enabled`), save and restore `slave->dev->dev_addr` via `dev_addr_set()` around `dev_set_mac_address()` in `alb_set_mac_address()` and `bond_alb_handle_active_change()`. [F87, F94, F100]
- `rlb_choose_channel()` hashes `arp->ip_dst` and matches `ip_src == arp->ip_src && ip_dst == arp->ip_dst` on outbound ARPs, while `rlb_update_entry_from_arp()` hashes `arp->ip_src` and matches `ip_src == arp->ip_dst && ip_dst == arp->ip_src` on inbound replies. `rlb_arp_xmit()` must verify `bond_slave_has_mac_rcu(bond, arp->mac_src)` and reject if `ip_dev_find()` is a bridge master (`netif_is_any_bridge_master(dev)`) before rewriting `arp->mac_src`. [F130, F195]
- In `bond_3ad.c`, `__update_selected()` and `__record_pdu()` compare/copy `lacpdu->actor_*` against `port->partner_oper`, whereas `__choose_matched()` and `__update_ntt()` compare `lacpdu->partner_*` against `port->actor_*`. `ad_periodic_machine()` must gate LACPDU TX on `LACP_STATE_LACP_ACTIVITY` in `port->actor_oper_port_state` or `port->partner_oper.port_state` (not `bond->params.lacp_active`), and `ad_rx_machine()` must not set `LACP_STATE_LACP_ACTIVITY` on `partner_oper.port_state` in `AD_RX_EXPIRED`. Updates to `lacp_active`, `lacp_fast`, `ad_actor_sys_prio`, `ad_actor_system`, or slave `port_priority` must call `bond_3ad_update_*()` under `spin_lock_bh(&bond->mode_lock)`. [F80, F81, F129]
- In `bond_miimon_inspect()`, initialize `ignore_updelay = false`, set it via `!rcu_dereference(bond->curr_active_slave)` in `BOND_MODE_ACTIVEBACKUP` and `usable_slaves && usable_slaves->count == 0` in other modes, and clear it once the first `BOND_LINK_BACK` slave becomes `BOND_LINK_UP`; `BOND_LINK_UP` must fall through to `BOND_LINK_FAIL` and `BOND_LINK_DOWN` to `BOND_LINK_BACK`. In `bond_miimon_commit()` and `bond_ab_arp_commit()`, defer `bond_select_active_slave()` via `do_failover = true` until `bond_for_each_slave` finishes (including when `slave->prio > active->prio`). [F67, F117, F118, F119]
- In `bond_arp_rcv()` and `bond_na_rcv()`, when a backup slave validates a probe because `curr_active_slave` received traffic after `last_link_up`, pass `tip, sip` or `daddr, saddr` in reversed order to `bond_validate_arp()`/`bond_validate_na()`. `arp_targets` and `ns_targets` are dense zero-terminated arrays; `bond_option_arp_ip_target_rem()` must compact each slave's `target_last_arp_rx` before compacting `arp_targets` because the slave loop tests `targets[i+1]`. [F98, F114, F233]
- Because a bond master can be enslaved to another bond, `bond_netdev_event()` must check `IFF_MASTER` and `IFF_SLAVE` with independent `if` statements, `bond_enslave()` must reject any `IFF_MASTER` device that is `!netif_is_bond_master(slave_dev)`, and `__bond_release_one()` / `bond_enslave()` error cleanup must only clear `IFF_BONDING` if `!netif_is_bond_master(slave_dev)`. In `bond_enslave()`, randomizing a slave MAC under `BOND_FOM_FOLLOW` and `BOND_MODE_ACTIVEBACKUP` when `slave_dev->dev_addr` matches `bond_dev->dev_addr` must be guarded by `bond_has_slaves(bond)`. [F116, F131, F149]
- `bond_neigh_setup()` must check `if (parms->dev == dev)` before setting `parms->neigh_setup = bond_neigh_init` so upper VLAN devices do not downcast `netdev_priv(n->dev)` to `struct bonding *`. Slave selection in round-robin and 3AD/XOR modes is duplicated across SKB and XDP paths (`bond_xmit_roundrobin_slave_get` vs `bond_xdp_xmit_roundrobin_slave_get`, `bond_xmit_hash` vs `bond_xmit_hash_xdp`) and must stay in sync. [F96, F150]

## Synchronization

- `bond_for_each_slave`, `bond_first_slave`, `bond_last_slave`, `bond_slave_has_mac`, and `bond_slave_get_rtnl` require `rtnl_lock()`; lockless callers must hold `rcu_read_lock()` across all uses of borrowed pointers and use `*_rcu` variants (or `bond_3ad_get_active_agg_info` instead of `__bond_3ad_get_active_agg_info`). RTNL-only paths (`bond_miimon_commit`, `bond_ab_arp_commit`, `bond_change_active_slave`, `bond_select_active_slave`, `bond_slave_netdev_event`) must use `rtnl_dereference()` or `bond_slave_get_rtnl()`, while dual-context helpers (`bond_should_notify_peers`, `bond_option_active_slave_get_rcu`) must use `rcu_dereference_rtnl()`. [F166, F167, F211, F212, F215, F216, F219]
- `bond_update_slave_arr()` must be called under `RTNL` (serializing `bond->slave_cnt` for `struct_size(..., arr, bond->slave_cnt)`) and without `bond->mode_lock` held (it allocates with `GFP_KERNEL` and takes `spin_lock_bh(&bond->mode_lock)` in 802.3ad mode); callers holding `mode_lock` without RTNL must defer via `bond_slave_arr_work_rearm()`. In 802.3ad mode, if `bond_3ad_get_active_agg_info()` fails, `bond_reset_slave_arr()` must clear both `usable_slaves` and `all_slaves` to `NULL`. [F30, F76, F140]
- `bond->mode_lock` serializes all `struct port` and `struct aggregator` transitions after `bond_3ad_bind_slave()` in 802.3ad mode, and all `tx_hashtbl`/`rx_hashtbl` accesses in TLB/ALB modes. ALB helpers calling `dev_set_mac_address()` or `dev_set_promiscuity()` (`alb_swap_mac_addr`, `alb_fasten_mac_swap`, `alb_change_hw_addr_on_detach`, `bond_alb_deinit_slave`, `rlb_teach_disabled_mac_on_primary`) require `RTNL` with `mode_lock` and `rcu_read_lock()` not held. In `bond_alb_handle_active_change()`, update `curr_active_slave` via `rcu_assign_pointer()` and call `tlb_clear_slave()` on `swap_slave` and `new_slave` before swapping MACs. [F37, F38, F39, F40]
- In `bond_ipsec_add_sa_all()` and `bond_ipsec_del_sa_all()`, hold both `mutex_lock(&bond->ipsec_lock)` and `spin_lock_bh(&ipsec->xs->lock)` while checking `ipsec->xs->km.state != XFRM_STATE_DEAD`, updating `xs->xso.real_dev`, and calling `xdo_dev_state_delete`. `bond_ipsec_del_sa()` runs in atomic context with `xs->lock` held and must not take `bond->ipsec_lock` or mutate `bond->ipsec_list`; list removal and `kfree(ipsec)` are deferred to `bond_ipsec_free_sa()` under `bond->ipsec_lock`. [F26, F27]
- In `bond_get_stats()`, acquire `bond->stats_lock` inside `rcu_read_lock()` via `spin_lock_nested(&bond->stats_lock, bond_get_lowest_level_rcu(bond_dev))`. Hold `netif_addr_lock_bh(bond->dev)` around `dev_uc_sync*`/`dev_mc_sync*` in `bond_hw_addr_swap()` and `bond_enslave()`. When `__bond_release_one()` runs with `unregister == true`, restore MTU via `__netif_set_mtu()` inside `netdev_lock_ops(slave_dev)`. [F41, F47, F179]
- `bond_set_active_slave`, `bond_set_backup_slave`, and `bond_set_slave_state`/`bond_commit_link_state` with `BOND_SLAVE_NOTIFY_NOW` require `rtnl_lock()`; callers without RTNL must pass `BOND_SLAVE_NOTIFY_LATER`. Lockless runtime accesses must use `READ_ONCE(bond->recv_probe)` in `bond_handle_frame()`, `rcu_dereference(tls_get_ctx(skb->sk)->netdev)` read once into a local variable in `bond_tls_device_xmit()`, `READ_ONCE`/`WRITE_ONCE` for `slave->queue_id`, `slave_last_tx()`/`slave_update_last_tx()` for `slave->last_tx`, and `READ_ONCE(bond->slave_cnt)`. [F46, F168, F217, F220, F221]

## Object Lifetimes

- In `bonding_init()`/`bonding_exit()`, `bond_create_debugfs()` must precede `register_pernet_subsys()` and `bond_netlink_init()`, and `bond_destroy_debugfs()` must run after `bond_netlink_fini()` and `unregister_pernet_subsys()`. In `bond_newlink()`, `register_netdevice()` and `bond_work_init_all()` must precede `bond_changelink()`, unwinding on error with `bond_work_cancel_all()` then `unregister_netdevice()`. [F1, F2]
- During `bond_enslave()`, initialize `new_slave->perm_hwaddr` before `bond_alb_init_slave()`, initialize `bond_dev->dev_addr` before `bond_3ad_initialize()`, and call `bond_3ad_bind_slave()` and `bond_alb_init_slave()` before `netdev_rx_handler_register()` and `bond_master_upper_dev_link()`. Call `bond_slave_ns_maddrs_add()` before `bond_select_active_slave()` in `bond_enslave()`, and `bond_slave_ns_maddrs_del()` after `bond_change_active_slave(bond, NULL)` in `__bond_release_one()`, keeping backup/active NS multicast MACs synced across role, target, and `arp_validate` changes. [F8, F36, F72, F78, F157]
- During `__bond_release_one()` and `bond_enslave()` error unwind, bracket slave release and active-slave failover with balanced `block_netpoll_tx()`/`unblock_netpoll_tx()`. `netdev_rx_handler_unregister()`, `bond_upper_dev_unlink()`, `bond_update_slave_arr()`, and clearing RCU pointers (`current_arp_slave`, `primary_slave`, `curr_active_slave`) must precede `synchronize_rcu()`, which must precede `slave_disable_netpoll()`, `dev_close()`, `bond_sysfs_slave_del()`, `bond_3ad_unbind_slave()`, and `kobject_put(&slave->kobj)`. `slave_kobj_release()` must call `cancel_delayed_work_sync(&slave->notify_work)` before freeing `SLAVE_AD_INFO(slave)` and `slave`. [F20, F43, F176, F177, F223]
- Multi-slave propagation in `bond_change_mtu`, `bond_set_mac_address`, `alb_set_mac_address`, `bond_vlan_rx_add_vid`, and `bond_xdp_set` must roll back preceding slaves up to the failing `slave` without overwriting the original error. Whenever `dev_xdp_propagate()` succeeds with non-NULL `prog`, call `bpf_prog_inc(prog)`; when `bond_xdp_set()` clears `old_prog`, call `bpf_prog_put(old_prog)` and `static_branch_dec(&bpf_master_redirect_enabled_key)`. [F17, F18]
- In `bond_ipsec_add_sa*`, `bond_ipsec_del_sa_all`, and `bond_ipsec_free_sa`, set `xs->xso.real_dev = real_dev` only after `xdo_dev_state_add` succeeds, and clear `xs->xso.real_dev = NULL` before `xdo_dev_state_delete` or `xdo_dev_state_free`. Balance references on all exit paths: `netdev_hold`/`dev_hold` on `curr_active_slave->dev` before `rcu_read_unlock()` in `bond_ipsec_add_sa()` and `bond_ethtool_get_ts_info()`; `dev_put(dev)` after `ip_dev_find()` in `rlb_arp_xmit()`; `ip_rt_put(rt)` / `dst_release(dst)` in `bond_arp_send_all()` / `bond_ns_send_all()`; and `kfree(tags)` after `!IS_ERR_OR_NULL(tags)` from `bond_verify_device_path()`. [F12, F13, F14, F15, F16]
- In `bond_handle_frame()`, if `bond->recv_probe` returns `RX_HANDLER_CONSUMED`, call `consume_skb(skb)` because `recv_probe` callbacks do not free `skb`. Conversely, `bond_handle_vlan()` returns `false` only when `vlan_insert_tag_set_proto()` already freed `skb`, and `bond_tx_drop()` frees `skb` and increments `tx_dropped`, so callers must not free `skb` again. [F22, F52, F311]

## API Contracts

- Changing or clearing `bond->curr_active_slave` in modes using a primary/active slave must go through `bond_change_active_slave()`. When enslaving a first slave whose `slave_dev->type != bond_dev->type`, `bond_enslave()` must fire `NETDEV_PRE_TYPE_CHANGE`, flush UC/MC lists, update geometry via `bond_setup_by_slave()` (closing/reopening `bond_dev` if `IFF_UP`) or `bond_ether_setup()` (preserving `IFF_MASTER | (flags & (IFF_SLAVE | IFF_UP))` and clearing `IFF_TX_SKB_SHARING`), and fire `NETDEV_POST_TYPE_CHANGE`. [F73, F92, F163, F200]
- Before calling `bond_slave_get_rtnl()` on a device looked up by name/ifindex, verify `netif_is_bond_slave(slave_dev)` and `bond->dev == netdev_master_upper_dev_get(slave_dev)`. Callers of `bond_slave_get_rcu/rtnl`, `bond_first/last_slave`, `bond_first_slave_rcu`, `bond_option_active_slave_get_rcu` (NULL when `!bond_uses_primary(bond)`), and `bond_3ad_get_active_agg_info` (check return `== 0`) must check for NULL/error. Readers of `usable_slaves` or `all_slaves` must check both `slaves != NULL` and `READ_ONCE(slaves->count) != 0` before `hash % count`. [F59, F107, F148, F229, F232, F272]
- `__bond_opt_init()` uses `optval->value = ULLONG_MAX` as the sentinel to select `string`/`extra` parsing over numeric parsing (never sign-extend `-1` to `ULLONG_MAX`), and `bond_opt_slave_initval(optval, &slave_dev, value)` requires the address `&slave_dev`. In `BOND_OPTFLAG_RAWVAL` setters (`bond_option_arp_ip_targets_set`, `bond_option_slaves_set`), verify `strlen(newval->string) >= 1` before indexing `newval->string + 1`. `struct bond_option.unsuppmodes` must be `unsigned long` with `BIT(BOND_MODE_*)` masks. [F70, F71, F97, F154, F230, F277]
- `bond_option_mode_set()` must reject mode changes with `-EOPNOTSUPP` when `bond->xdp_prog` is set and `!bond_xdp_check(bond, newval->value)`. `bond_xdp_set_features()` must clear XDP features when `!bond_xdp_check()` or `!bond_has_slaves(bond)`, and otherwise intersect slave `xdp_features` while masking out `NETDEV_XDP_ACT_XSK_ZEROCOPY`. `bond_xdp_xmit()` must return negative errno only if `nxmit == 0` and `nxmit` otherwise; `bond_xdp_get_xmit_slave()` must rate-limit unsupported-mode errors with `net_ratelimit()` without `WARN_ON_ONCE()`. [F84, F161, F189, F190]
- Verify `real_dev->xfrmdev_ops`, the callback pointer, and `!netif_is_bond_master(real_dev)` before calling slave `xfrmdev_ops`. Convert unicast `ns_targets` via `addrconf_addr_solict_mult()` before `ndisc_mc_map()`/`ndisc_send_skb()`, and mask `bond_xmit_hash()` with `& 0xFF` for `tlb_choose_channel()`. [F69, F101, F162]

## Known Pitfalls

- Re-anchor `data` and re-derive `eth_hdr()`, `ip_hdr()`, or `ipv6_hdr()` after any `pskb_may_pull()`, `pskb_network_may_pull()`, or `bond_pull_data()`. In `bond_handle_frame()`, write `skb_share_check()` back to `*pskb`, and in `BOND_MODE_ALB` on a bridge port, call `skb_cow_head()` before mutating `eth_hdr(skb)->h_dest`. [F85, F86, F144]
- On TX (`ndo_start_xmit`), `skb->mac_header` is unset and `skb->data` is at the MAC header: pass `mhoff = 0` in `bond_xmit_hash()`, call `skb_reset_mac_header(skb)` before `eth_hdr(skb)` in `bond_xmit_tlb/alb_slave_get()`, and use `skb_mac_header_len(skb)` in `bond_should_broadcast_neighbor()`. On RX (`bond_na_rcv`, `rlb_arp_recv`, `bond_3ad_lacpdu_recv`), `skb->data` is at the network header, so `skb_header_pointer()` uses offset `0`; in `bond_arp_rcv()`, check `arp->ar_hln == bond->dev->addr_len` and `arp->ar_pln == 4` and copy `sip`/`tip` via `memcpy()`. [F108, F109, F191]
- MAC buffers passed to `bond_slave_has_mac*`, `MAC_ADDRESS_EQUAL`, or `ether_addr_equal_64bits` need 2 bytes of trailing padding (`ETH_ALEN + 2`, as in `ad_actor_system`), while copying/serializing `ad_actor_system` must use `ETH_ALEN` (6) and `nla_get_u64` for `BOND_OPT_AD_ACTOR_SYSTEM`. Zero-initialize `fl6` (without setting `flowi6_oif`) in `bond_ns_send_all()` and `parms` in `bond_neigh_init()`, and cache `old_flags`/`old_features` at `__bond_release_one()` entry. [F65, F66, F93, F142, F147, F281]
