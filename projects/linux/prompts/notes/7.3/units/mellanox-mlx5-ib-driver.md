# MELLANOX MLX5 IB driver

This unit implements the `mlx5_ib` InfiniBand/RDMA driver (QPs, SRQs, UMR, WR posting, restrack, and uverbs ioctls) and shared `include/linux/mlx5/` core headers for PRM bit-level command/descriptor layouts (`mlx5_ifc.h`, `mlx5_ifc_vdpa.h`) and subsystem APIs.

## Architecture & Data Flow
- When `qp->type == IB_QPT_RAW_PACKET` or `qp->flags & IB_QP_CREATE_SOURCE_QPN`, `create_user_qp()` and `destroy_qp_common()` must select `&qp->raw_packet_qp.rq.base` instead of `&qp->trans_qp.base`. In `__mlx5_ib_qp_set_counter()`, `IB_QPT_RAW_PACKET` QPs must bind counters on `qp->raw_packet_qp.rq` via `__mlx5_ib_qp_set_raw_qp_counter()` and `mlx5_core_modify_rq()`, not `MLX5_CMD_OP_RTS2RTS_QP` on `trans_qp.base`. [F46, F47]
- Every active `mlx5_ib_qp_base` (`trans_qp.base`, `raw_packet_qp.sq.base`, `raw_packet_qp.rq.base`) must set `container_mibqp = qp` for `to_mibqp()`, whereas `mlx5_ib_rwq::core_qp` must use `to_mibrwq()`. `struct mlx5_core_rsc_common common` must remain the first member of `struct mlx5_core_qp` and `struct mlx5_core_srq`. [F131, F132]
- In `qpc.c`, `qp_table.tree` keys for QPs, RQs, and SQs must be encoded as `rsn = qpn | (rsc_type << MLX5_USER_INDEX_LEN)` (masking `qpn` to 24 bits in `rsc_event_notifier()`), whereas DCTs live in `qp_table.dct_xa` indexed by 24-bit `dctn` alone. [F91]
- In hardware QPC/SRQC contexts (`srq.c`, `qp.c`, `srq_cmd.c`), `log_rq_stride` and `mlx5_srq_attr.wqe_shift` store `wqe_shift - 4` (16B units), whereas WQC `log_wq_stride` in `set_wq()` and `create_raw_packet_qp_rq()` stores the full byte-shift (`in->wqe_shift + 4` or `log_rq_stride + 4`). [F95]
- During send WQE construction (`mlx5r_begin_wqe()`, `handle_post_send_edge()`, `mlx5r_memcpy_send_wqe()`, `mlx5r_finish_wqe()`), `size` (`wqe_sz`) is in 16B octowords (DS) while `sq->cur_post` and `sq->wqe_cnt` are in 64B WQEBBs (`MLX5_SEND_WQE_BB`). `mlx5r_memcpy_send_wqe()` must round the final chunk (`!n`) with `ALIGN(copysz, 16)`, and `mlx5r_finish_wqe()` must advance `qp->sq.cur_post` by `DIV_ROUND_UP(size * 16, MLX5_SEND_WQE_BB)`. [F59, F125, F126]
- Hardware producer counters `qp->sq.cur_post` (`u16`), `srq->wqe_ctr` (`u16`), and `qp->rq.head & 0xffff` written to `ctrl->opmod_idx_opcode` and `db.db` wrap modulo `2^16` (never masked with `wqe_cnt - 1`), while buffer slot lookups mask with `wqe_cnt - 1`. In `mlx5r_wq_overflow()`, occupancy must use unsigned subtraction `cur = wq->head - wq->tail` tested with `cur + nreq >= wq->max_post`. [F127, F128]
- Kernel SRQs maintain an in-buffer free list via `mlx5_wqe_srq_next_seg`: `mlx5_ib_post_srq_recv()` pops `srq->head` via `be16_to_cpu(next->next_wqe_index)` (stopping at `srq->head == srq->tail`), and `mlx5_ib_free_srq_wqe()` links freed `wqe_index` at `srq->tail`. When `wr->num_sge` is less than `srq->msrq.max_avail_gather` or `qp->rq.max_gs`, `scat[i]` must set `byte_count = 0`, `addr = 0`, and `lkey = dev->mkeys.terminate_scatter_list_mkey` (already `__be32`, never queried from firmware in loops). [F73, F93, F114]
- When `__mlx5_ib_modify_qp()` transitions a kernel non-`IB_QPT_XRC_TGT` QP to `IB_QPS_RESET`, it must clean `recv_cq` and `send_cq` via `mlx5_ib_cq_clean()`, zero `rq.head`, `rq.tail`, `sq.head`, `sq.tail`, `sq.cur_post`, `sq.last_poll`, and `db.db`, and reset `qp->sq.cur_edge = get_sq_edge(&qp->sq, 0)`. [F61]
- `set_qpc_atomic_flags()` uses cached `qp->trans_qp.atomic_rd_en` and `qp->trans_qp.resp_depth` when `IB_QP_ACCESS_FLAGS` or `IB_QP_MAX_DEST_RD_ATOMIC` is omitted; `__mlx5_ib_modify_qp()` must update those shadow fields only after `mlx5_core_qp_modify()` succeeds, apply/clear `qp->counter_pending` on entering `IB_QPS_RTS`, and cache `attr->alt_port_num` in `qp->trans_qp.alt_port` for `mlx5_ib_qp_event()` on `MLX5_EVENT_TYPE_PATH_MIG`. [F62, F63, F65]
- Validate 1-based `port_num` against `1 <= port_num <= dev->num_ports` (not `MLX5_CAP_GEN(dev->mdev, num_ports)`) before indexing `dev->port[port_num - 1]`. In `validate_rd_atomic()`, check `MLX5_IB_QPT_DCI` against `log_max_ra_res_dc` and `log_max_ra_req_dc`. In `mlx5_ib_create_srq()`, check `max_wr < (1 << MLX5_CAP_GEN(dev->mdev, log_max_srq_sz))` and `max_sge <= max_wqe_sz_rq / sizeof(struct mlx5_wqe_data_seg)` before `roundup_pow_of_two(max_wr + 1)`. [F84, F85, F86]
- In `struct mlx5_ifc_*_bits` (`mlx5_ifc.h`, `mlx5_ifc_vdpa.h`), each `u8` element is 1 bit (`offsetof` is the bit offset): resizing or adding fields requires adjusting adjacent `reserved_at_*` arrays by the exact opposite bit count, and fields accessed via `MLX5_SET`/`MLX5_GET` must be `<= 32` bits and never cross a 32-bit (`0x20`) boundary. `__mlx5_mask()` must shift `1ull << __mlx5_bit_sz(typ, fld)` because bit size can be 32. New `enum mlx5_cap_type` values must be `< MLX5_CAP_NUM` and added to `types[]` in `mlx5_hca_caps_alloc()`. [F97, F118, F224, F225]

## Synchronization
- Spinlock hierarchy: `dev->reset_flow_resource_lock` -> `qp->sq.lock` / `qp->rq.lock` -> `cq->lock` -> `srq->lock`. When linking/unlinking QPs in `dev->qp_list` and CQ lists, take `dev->reset_flow_resource_lock` before `mlx5_ib_lock_cqs(send_cq, recv_cq)`, which locks distinct CQs in ascending `mcq.cqn` order via `spin_lock_nested(..., SINGLE_DEPTH_NESTING)`. `mlx5r_wq_overflow()` is called under `qp->sq.lock` or `qp->rq.lock` with IRQs disabled and takes `cq->lock`. [F12, F29, F30, F164]
- Because `mlx5_get_rsc()`, `dct_event_notifier()`, and `srq_event_notifier()` run in atomic EQ interrupt context, process-context accesses to `qp_table.lock`, `qp_table.dct_xa`, and `srq_table.array` must disable IRQs (`spin_lock_irq*` or `xa_*_irq*`). `srq->lock` protects `srq->head`, `srq->tail`, `srq->wqe_ctr`, and `next_wqe_index` (callers of `mlx5_ib_free_srq_wqe()` must disable IRQs); `qp->mutex` protects `qp->state`, `qp->counter_pending`, `ibqp->counter`, and raw-packet SQ/RQ state. [F27, F40, F160]
- In `mlx5r_ring_db()`, `mlx5_write64()` and `bf->offset ^= bf->buf_size` must run under `qp->sq.lock` after `wmb()` barriers separating WQE writes and `qp->db.db[MLX5_SND_DBR]` updates. In `mlx5_ib_post_recv()`, `mlx5_ib_post_srq_recv()`, and `mlx5_cq_arm()`, a `wmb()` must separate writing WQE scatter segments or `*cq->arm_db` from updating `*qp->db.db` / `*srq->db.db` (under `qp->rq.lock` / `srq->lock`) or calling `mlx5_write64()`. [F32, F33, F162, F163]
- In `mlx5r_umr_post_send_wait()`, pair `down(&umrc->sem)` with `up(&umrc->sem)` on all paths and release `umrc->lock` before `wait_for_completion()`, `usleep_range()`, or `mlx5r_umr_recover()`. `mlx5r_umr_recover()` must set `MLX5_UMR_STATE_RECOVER` under `umrc->lock` and await a barrier WR before resetting `umrc->qp`. [F21, F76]
- In `handle_drain_completion()`, when `mdev->state == MLX5_DEVICE_STATE_INTERNAL_ERROR` on a non-`IB_POLL_DIRECT` CQ, test and set `mcq->mcq.reset_notify_added` under `dev->reset_flow_resource_lock`, and if already set, synchronously drain `cq->iop` or `cq->work` after unlocking before calling `mcq->mcq.comp()`. [F39]

## Object Lifetimes
- `mlx5_core_destroy_qp()` and `mlx5_core_destroy_sq_tracked()` must call `destroy_resource_common()` (removing from `qp_table.tree`, dropping the ref via `mlx5_core_put_rsc()`, and waiting on `common.free`) before firmware `DESTROY_QP`/`DESTROY_SQ`. Conversely, `mlx5_core_destroy_rq_tracked()` must set `rq->common.invalid` via `modify_resource_common_state(dev, rq, true)` before `destroy_rq_tracked()`, revert to `false` on error, and call `destroy_resource_common()` only after `destroy_rq_tracked()` succeeds. [F23, F24]
- For `MLX5_IB_QPT_DCT`, the hardware DCT is created in `mlx5_ib_modify_dct()` on `IB_QPS_RTR`; `mlx5_ib_destroy_dct()` must call `mlx5_core_destroy_dct()` only when `mqp->state == IB_QPS_RTR` and free `mqp->dct.in` only after it succeeds. In `mlx5_core_destroy_dct()`, unless in `MLX5_DEVICE_STATE_INTERNAL_ERROR`, `mlx5_core_drain_dct()` and `wait_for_completion(&dct->drained)` must finish while `dct` is still in `qp_table.dct_xa` before `xa_cmpxchg_irq()` and `_mlx5_core_destroy_dct()`. [F17, F25]
- In `destroy_qp_common()`, transition non-RSS QPs to reset, unlink from `dev->qp_list` and CQ lists under `reset_flow_resource_lock` and CQ locks, and destroy in firmware before `destroy_qp()` frees buffers/doorbells. Only call `mlx5_ib_free_bfreg()` when `bfregn != MLX5_IB_INVALID_BFREG`. [F13, F143]
- In `create_raw_packet_qp()` and `destroy_raw_packet_qp()`, create SQ resources in order TIS then SQ (teardown SQ then TIS) and RQ resources in order RQ then TIR (teardown TIR then RQ). In `modify_raw_packet_qp()`, if `modify_raw_packet_qp_sq()` fails, delete the new rule from `create_flow_rule_vport_sq()` (checking `IS_ERR` then `if (flow_rule)`) and only replace `sq->flow_rule` on success. [F11, F15, F49]
- Set `MLX5_IB_WQ_FLAGS_DELAY_DROP` in `rwq->create_flags` only after `set_delay_drop()` succeeds, and call `destroy_user_rq()` in `mlx5_ib_destroy_wq()` only after `mlx5_core_destroy_rq_tracked()` succeeds. In `mlx5_ib_create_srq()`, free `in.pas` from `create_srq_kernel()` via `kvfree(in.pas)` right after `mlx5_cmd_create_srq()` (and on early errors). [F14, F18]

## API Contracts
- `rsc_event_notifier()` transfers the `common.refcount` ref from `mlx5_get_rsc()` to `qp->event()` (`MLX5_RES_QP`, `MLX5_RES_RQ`, `MLX5_RES_SQ`), which must call `mlx5_core_res_put()`. In contrast, `srq->event()` (`mlx5_ib_srq_event()`) borrows the ref from `srq_event_notifier()` and must NOT call `mlx5_core_res_put(&srq->common)`. Callers of `mlx5_core_res_hold()`, `mlx5_cmd_get_srq()`, and `mlx5_ib_get_native_port_mdev()` must release their returned reference. [F5, F6, F19, F22]
- `_mlx5r_umr_zap_mkey()` returns a signed `int` status and outputs the block count via `size_t *nblocks`. `mlx5r_ib_rate()`, `get_ts_format()`, `get_rq_ts_format()`, `get_sq_ts_format()`, `get_qp_ts_format()`, and `calc_sq_size()` return `< 0` on error and must be checked in a signed `int`. Check `if (!page_size)` on `mlx5_umem_find_best_quantized_pgoff()` before `order_base_2()`. [F43, F44, F50, F51, F120]
- `mlx5_rsc_dump_next()` sleeps, DMA-maps `page` for `key->size` bytes, and returns `< 0` on error, `1` when more pages remain, and `0` on the final populated page; `dump_rsc()` must process `page` on both `0` and `1` (checking `size + offset <= MAX_DUMP_SIZE`) and always clean up `cmd` and `page`. [F20, F96, F199, F265]
- In `qpc`, `srqc`, `xrc_srqc`, and `wq`, `log_page_size` and `log_wq_pg_sz` subtract `MLX5_ADAPTER_PAGE_SHIFT` (12), whereas in UMR `mkc` (`struct mlx5_mkey_seg`), `log_page_size` is the unshifted `page_shift`. [F57]
- Capability checks: `mlx5_get_roce_state()` checks `MLX5_CAP_GEN(dev, roce)` if `roce_rw_supported` is set, else `mlx5_is_roce_on(dev)`. `mlx5_get_qp_default_ts()` checks `mlx5_get_roce_state(dev)` before `MLX5_CAP_ROCE(dev, qp_ts_format)`, falling back to `MLX5_CAP_GEN(dev, sq_ts_format)`. UMR `MLX5_MKEY_MASK_PAGE_SIZE_5` must accompany `MLX5_MKEY_MASK_PAGE_SIZE` when `umr_log_entity_size_5` is set, and `relaxed_ordering_read` in `mlx5r_umr_set_access_flags()` checks `MLX5_CAP_GEN(dev->mdev, relaxed_ordering_read) || pcie_relaxed_ordering_enabled(dev->mdev->pdev)`. [F145, F146, F147, F248]

## Error Handling
- In `mlx5_ib_post_send()`, `mlx5_ib_post_recv()`, and `mlx5_ib_post_srq_recv()`, every error path must set `*bad_wr = wr`, and if `nreq > 0` WRs were already written, jump to `out:` / `break` so the doorbell is rung and queue indices advance by `nreq`. In `mlx5_ib_drain_sq()` and `mlx5_ib_drain_rq()`, ignore `ib_modify_qp()` failure when `mdev->state == MLX5_DEVICE_STATE_INTERNAL_ERROR` so drain WRs are still posted. [F54, F112, F184]
- Guard `mlx5r_umr_cleanup()` on `dev->umrc.pd != NULL` and `mlx5r_umr_resource_cleanup()` on `dev->umrc.state != MLX5_UMR_STATE_UNINIT`. Call `nla_nest_cancel()` on netlink put errors after `nla_nest_start()` in `fill_stat_mr_entry()` and `fill_res_mr_entry()`, and roll back rules via `mlx5_macsec_del_roce_rule()` on error in `mlx5_macsec_add_roce_rule()`. [F45, F171, F191]

## External Contracts
- Uverbs ABI & security: `process_udata_size()` and `check_ucmd_data()` accept `udata->inlen` down to `offsetof(struct mlx5_ib_create_qp, ece_options)` and verify zeroed trailing bytes from `offsetof(..., reserved)` with `ib_is_udata_cleared()`. `mlx5_ib_query_qp()` must `memset` `qp_attr` and `qp_init_attr` and hide `qp_context` (reporting `0` for `max_send_wr`/`max_send_sge`) when `ibqp->uobject != NULL`. `IB_WQ_FLAGS_DELAY_DROP` requires `capable(CAP_SYS_RAWIO)`, `IB_QPT_SMI` send requires `has_smi`, and opcodes in `[MLX5_CMD_OP_GENERAL_START, MLX5_CMD_OP_GENERAL_END)` (`0xb00..0xd00`) are whitelisted for untrusted userspace in `devx_is_general_cmd()`. [F88, F178, F179, F180, F266]
- In `process_vendor_flags()` and `process_create_flags()`, clear each handled bit via `process_vendor_flag()` / `process_create_flag()` (`SCATTER_CQE` / `ALLOW_SCATTER_CQE` must be cleared without error even without `sctr_data_cqe`), and match mutually exclusive pairs (`DCT | DCI`, `UAR_PAGE_INDEX | BFREG_INDEX`) in a `switch` on the combined mask. [F104, F106, F107]
- WQE segment layouts: `mlx5_wqe_inline_seg::byte_count` requires `cpu_to_be32(len | MLX5_INLINE_SEG)`. In `struct mlx5_wqe_eth_seg`, `swp_*_offset` is in 2-byte words, `sizeof(*eseg)` includes the 2-byte `inline_hdr.start` (copy > 2B to `inline_hdr.data` and subtract `sizeof(eseg->inline_hdr.start)` from size math), `inline_hdr.sz` aliases `trailer` (use `|=`), and `IB_QP_CREATE_IPOIB_UD_LSO` requires a 16B `mlx5_wqe_eth_pad` before `eseg`. [F181, F205, F206, F243, F267]

## Known Pitfalls
- PRM macros and buffer sizes: `MLX5_SET*`/`MLX5_GET*` dereference `p` as aligned `__be32 *`/`__be64 *`/`__be16 *`, and `MLX5_SET`/`MLX5_GET` only work on single 32-bit dwords (cast split fields like `icm_address_*` to `u64` before shifting `>= 32`). Because `mlx5_ifc_*_bits` uses `u8` per bit, byte allocations and `inlen`/`ptys_size` parameters must use `MLX5_ST_SZ_BYTES` (adding `count * sizeof(u64)` for PAS or `count * sizeof(u32)` for RQT, and starting reformat copies at `reformat_data`), while `u32 *` pointer offsets must use `MLX5_ST_SZ_DW`. [F98, F99, F117, F129, F137, F245, F246]
- UMR XLT handling: callers of `mlx5r_umr_create_xlt()` that shrink `sg.length` for the final WQE (`_mlx5r_umr_update_mr_pas()`, `mlx5r_umr_update_xlt()`) must restore `sg.length = orig_sg_length` before `mlx5r_umr_unmap_free_xlt()`. Align XLT DMA lengths and byte offsets to 64B (`MLX5_UMR_FLEX_ALIGNMENT`), add `idx & page_mask` to `npages` before rounding `idx` down in `mlx5r_umr_update_xlt()`, and when flushing a chunk in `_mlx5r_umr_update_mr_pas()`, advance `offset += sg.length`, call `mlx5r_umr_update_offset()`, reset `cur_ksm`/`cur_mtt = entry`, and sync DMA. Convert `wqe->ctrl_seg.mkey_mask` (`__be64`) with `cpu_to_be64()`/`be64_to_cpu()`, and keep `struct mlx5r_umr_context` and `struct mlx5_ib_umr_context` layouts identical. [F9, F87, F92, F111, F123, F124, F134, F155]
- WQE construction & QP modify math: `mlx5r_begin_wqe()` must zero `*(uint32_t *)(*seg + 8) = 0` (`cseg->trailer`) for reused SQ ring entries; `*seg` must stay 16B-aligned and call `handle_post_send_edge()` whenever reaching `*cur_edge` (align unaligned starts before `mlx5r_memcpy_send_wqe()`); `IB_WR_REG_MR_INTEGRITY` in `handle_qpt_rc()` must jump to `skip_psv`; and `set_pi_umr_wr()` requires and clears `sig_mr->sig->sig_status_checked`. Use `1UL << ...` for page size shifts, `DIV_ROUND_UP()` in `get_pas_size()`, `fls(val - 1)` (not `ilog2()`) for non-zero `log_sra_max`/`log_rra_max` in `__mlx5_ib_modify_qp()`, and check `qp->type == IB_QPT_GSI` for software GSI before mapping `MLX5_IB_QPT_HW_GSI` to `IB_QPT_GSI`. [F55, F71, F90, F108, F113, F115, F116, F119, F122, F244]
