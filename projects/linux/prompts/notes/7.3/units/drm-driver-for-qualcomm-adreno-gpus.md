# DRM DRIVER for Qualcomm Adreno GPUs

`drivers/gpu/drm/msm/adreno` implements generation-specific hardware backends (A2xx through A7xx) for Qualcomm Adreno GPUs in the MSM DRM subsystem, covering GPU initialization, microcode loading, ringbuffer submission, preemption context switching, Graphics Management Unit (GMU) power/frequency control, and crash state capture.

## Architecture & Data Flow

- When `adreno_has_gmu_wrapper(adreno_gpu)` is true, `a6xx_gmu_wrapper_init()` does not initialize `gmu->vm`, GMU BOs (`hfi`, `log`, `debug`), `gmu->gmu_irq`, `gmu->hfi_irq`, or GMU firmware; `a6xx_gmu_remove()`, `a6xx_gpu_state_get()`, `hw_init()`, `a6xx_irq()`, and `fenced_write()` must check `adreno_has_gmu_wrapper()` before accessing them or GMU OOB/fence handshakes. [F42]
- In `a6xx_gmu_init()`, `gmu->gxpd` and `gmu->qmp` may hold `NULL` or a non-deferral `ERR_PTR()`, so `a6xx_gmu_resume()`, `a6xx_gmu_stop()`, `a6xx_gmu_remove()`, `a6xx_gmu_acd_probe()`, and error teardown in `a6xx_gmu_init()` must check `!IS_ERR_OR_NULL()` before using or releasing them. [F41]
- In `a6xx_pm_suspend()`, `a6xx_gmu_pm_suspend()`, `hw_init()`, and `a5xx_hw_init()`, accesses to `shadow[]` must be guarded by `shadow_bo != NULL` rather than `hw_apriv` or `has_whereami`. Suspending in `a6xx_gmu_pm_suspend()`, `a6xx_pm_suspend()`, and `a5xx_pm_suspend()` must zero `shadow[i]` and increment `gpu->suspend_count` (directly on A6xx/A7xx or via `msm_gpu_pm_suspend()` on A5xx). [F39, F59]
- In `a6xx_gmu_set_freq()`, if `suspended` is true, only `gmu->current_perf_index` and `gmu->freq` may be updated without touching hardware or OPPs; when active on non-legacy GMUs, `dev_pm_opp_set_opp()` is called only if `!bw_index`, and `dev_pm_opp_set_opp(&gpu->pdev->dev, NULL)` must be called in `a6xx_gmu_stop()` and `a6xx_pm_suspend()`. In `a6xx_gmu_set_initial_freq()`, `gmu->freq` must be reset to `0` before calling `a6xx_gmu_set_freq(gpu, gpu_opp, false)` so a frequency cached while suspended is programmed on resume. [F63, F148]
- In `a6xx_gmu_pwrlevels_probe()` and `a6xx_gmu_rpmh_votes_init()`, GMU CX tables/votes (`gmu_freqs`, `cx_arc_votes`, `"cx.lvl"`) must query OPPs on `gmu->dev`, whereas GPU GX tables/votes (`gpu_freqs`, `gpu_bw_table`, `gx_arc_votes`, `"gfx.lvl"`) must query `&gpu->pdev->dev`. In `a6xx_gmu_build_freq_table()` and `a6xx_gmu_build_bw_table()`, slot 0 is reserved for `0` ('off'), OPP entries are capped at `size - 1`, and `freq` / `bandwidth` must be post-incremented (`freq++` / `bandwidth++`) when stored so the next `dev_pm_opp_find_*_ceil()` searches higher. [F84, F105, F106]
- During command submission in `a2xx_submit()` through `a7xx_submit()`, `ring->cur_ctx_seqno` must not be updated to `submit->queue->ctx->seqno` before the `MSM_SUBMIT_CMD_CTX_RESTORE_BUF` loop completes, and must be reset to `0` on `hw_init`. In `a5xx_submit()`, `a6xx_submit()`, and `a7xx_submit()`, the command loop must increment `ibs` per emitted IB and call `update_shadow_rptr(gpu, ring)` whenever `(ibs % 32) == 0`; on A6xx/A7xx, `submit->cmd[i].size` in `CP_INDIRECT_BUFFER` must be masked with `A5XX_CP_INDIRECT_BUFFER_2_IB_SIZE()`. [F62, F74, F100]
- In `preempt_init_ring()`, shared preemption records must be initialized with `A5XX_PREEMPT_RECORD_MAGIC`, `A6XX_PREEMPT_RECORD_MAGIC`, or `GEN7_CP_SMMU_INFO_MAGIC`. In `a5xx_preempt_hw_init()`, reinitializing preemption must reset `a5xx_gpu->cur_ring` to `gpu->rb[0]`, zero CP-mutated fields (`data`, `info`, `wptr`, `rptr`), and refresh `rbase` and `rptr_addr` in every `a5xx_gpu->preempt[i]` while preserving `magic`, `cntl`, and `counter`. [F56, F93]
- In `a5xx_preempt_init()` and `a5xx_ucode_load()`, if preemption ring allocation fails or PFP microcode lacks `CP_WHERE_AM_I` (`!a5xx_gpu->has_whereami`), `a5xx_preempt_fini(gpu)` must be called and `gpu->nr_rings` set to `1` in lockstep. In `a6xx_ucode_load()`, `a6xx_ucode_check_version()` must validate SQE firmware and unpin/put/NULL `a6xx_gpu->sqe_bo` with `-EPERM` on failure. [F64, F135]
- In `hw_init()` (`a6xx_gpu.c`), `a7xx_patch_pwrup_reglist()` must run only after all initial GPU registers (UBWC, HWCG, UCHE, APRIV) are written to hardware and before `a7xx_cp_init()` sends `pwrup_reglist_iova` in `CP_ME_INIT`; inside `a7xx_patch_pwrup_reglist()`, `u32 *dest = (u32 *)&lock->regs[0]` must advance continuously across both the `ifpc_reglist` and `pwrup_reglist` loops without resetting. [F67, F102]
- Static catalog tables must obey bounds and sentinels: `adreno_info.chip_ids` ends with `0` (`ADRENO_CHIP_IDS`), `speedbins` with `{SHRT_MAX, 0}` (`ADRENO_SPEEDBINS`), `a6xx_info.hwcg` with `{}` (`offset == 0`), `a6xx_info.bcms` has at most `GMU_MAX_BCMS` (3) active entries ending with `{.name = NULL}` if shorter, and non-sentinel BCMs with `.fixed = false` must have non-zero `.buswidth` (for `do_div(peak, bcm->buswidth)`). Every `struct adreno_protect` table in `a6xx_catalog.c` must have `count <= count_max` in `__build_asserts()`, and `a6xx_set_cp_protect()` must write the final infinite-range entry `protect->regs[protect->count - 1]` into `REG_A6XX_CP_PROTECT(protect->count_max - 1)`. [F75, F80, F81, F82, F101, F116, F137]
- In `a5xx_gpu_state_get()` and `a6xx_gpu_state_get()`, the GPU crashdumper must only run when the SMMU is not stalled on a fault (`REG_A5XX_RBBM_STATUS3` `BIT(24)` or `REG_A6XX_RBBM_STATUS3` `A6XX_RBBM_STATUS3_SMMU_STALLED_ON_FAULT`) and, on A6xx/A7xx, when `!gpu->needs_hw_init` and `a6xx_gmu_sptprac_is_on()` hold. Every crashdumper script in `dumper->ptr` must end with `CRASHDUMP_FINI(in)`, and in `a6xx_gpu_state.c` readers must check `WARN_ON(datasize > A6XX_CD_DATA_SIZE)` before writing to `dumper->iova + A6XX_CD_DATA_OFFSET`. [F48, F69, F88]
- In `a6xx_gpu_state.c`, every capture helper that populates a state array in `struct a6xx_gpu_state` (such as `a6xx_get_indexed_registers()` and `a7xx_get_indexed_registers()`) must set its companion `nr_*` counter in lockstep on all return paths after allocation, and `a6xx_show()` must skip any `a6xx_gpu_state_obj` where `obj->handle` is `NULL`. [F55, F110]

## Synchronization

- All accesses to `ring->cur`, `get_wptr(ring)`, and `ring->restore_wptr` in `a5xx_flush()`, `a6xx_flush()`, `update_wptr()`, `get_next_ring()`, and `a5xx_preempt_trigger()` must be serialized under `ring->preempt_lock` using `spin_lock_irqsave()` / `spin_unlock_irqrestore()`. In `a6xx_flush()`, `ring->preempt_lock` must be held continuously across advancing `ring->cur = ring->next`, checking `!a6xx_in_preempt(a6xx_gpu)` and `a6xx_gpu->cur_ring == ring`, and either writing `REG_A6XX_CP_RB_WPTR` or setting `ring->restore_wptr = true`. [F22, F153]
- In `a5xx_preempt.c`, unconditional writes to `gpu->preempt_state` must use `set_preempt_state()` (wrapping `atomic_set()` with `smp_mb__before_atomic()` and `smp_mb__after_atomic()`), while conditional transitions must use `try_preempt_state()` (`atomic_cmpxchg()`). In `a5xx_preempt_trigger()`, `a5xx_gpu->preempt_start_lock` must be held continuously across `try_preempt_state(a5xx_gpu, PREEMPT_NONE, PREEMPT_START)`, `get_next_ring(gpu)`, and the abort path. [F16, F21]
- When `a5xx_preempt_trigger()` aborts because `!ring || (a5xx_gpu->cur_ring == ring)`, it must transition `preempt_state` to `PREEMPT_ABORT` before calling `update_wptr(gpu, a5xx_gpu->cur_ring)` and only then set `PREEMPT_NONE`, while `a5xx_flush()` executes `mb()` before checking `!a5xx_in_preempt(a5xx_gpu)`. In `a5xx_preempt_irq()`, after updating `cur_ring`, calling `update_wptr()`, and setting `PREEMPT_NONE`, `a5xx_preempt_trigger(gpu)` must be re-invoked. [F17, F18]
- Before writing a register that triggers the CP to read WC-mapped shared memory (`REG_A5XX_CP_CONTEXT_SWITCH_CNTL` in `a5xx_preempt_trigger()` or `REG_A6XX_CP_CRASH_DUMP_CNTL` in `a6xx_crashdumper_run()`), a `wmb()` must be executed; in `a5xx_preempt_trigger()`, `preempt[ring->id]->wptr`, `REG_A5XX_CP_CONTEXT_SWITCH_RESTORE_ADDR_LO`, `next_ring`, `preempt_timer`, and `set_preempt_state(a5xx_gpu, PREEMPT_TRIGGERED)` must all be set before the `wmb()` and `REG_A5XX_CP_CONTEXT_SWITCH_CNTL` write. [F20, F159]
- On A5xx and A7xx, `last_seqno[ring->id]` must be updated to `submit->seqno` before flushing and triggering preemption, and `get_next_ring()` must treat `cur_ring` as empty under `ring->preempt_lock` when `ring->memptrs->fence == a5xx_gpu->last_seqno[i]`. [F19]
- In `a6xx_gmu_pm_suspend()`, `a6xx_pm_suspend()`, `a6xx_gmu_pm_resume()`, and `a6xx_pm_resume()`, `msm_devfreq_suspend(gpu)` and `msm_devfreq_resume(gpu)` must be called outside `a6xx_gpu->gmu.lock`, with `msm_devfreq_suspend(gpu)` before `a6xx_gmu_stop()` and `msm_devfreq_resume(gpu)` after `a6xx_gmu_resume()`. [F25]
- GMU interrupts (`gmu->hfi_irq` and `gmu->gmu_irq`) must be requested with `IRQF_NO_AUTOEN` in `a6xx_gmu_get_irq()`, enabled in `a6xx_gmu_resume()` only after clocks and firmware/HFI start, and synchronously disabled via `a6xx_gmu_irq_disable()` before stopping RPMh and clocks in `a6xx_gmu_shutdown()` or `a6xx_gmu_force_off()`. [F28]
- On non-GMU-wrapper A6xx/A7xx targets, `a6xx_irq()` must assert `a6xx_gpu_keepalive_vote(gpu, true)` and wait for `irq_poll_fence(gpu)` to observe `REG_A6XX_GMU_AO_AHB_FENCE_CTRL == 0` via `gmu_poll_timeout_atomic()` before reading `REG_A6XX_RBBM_INT_0_STATUS` or any GPU register, and clear the keepalive vote on exit. In `a5xx_fault_detect_irq()` and `a6xx_fault_detect_irq()`, if stalled on an SMMU fault, the handler must return immediately without deleting `gpu->hangcheck_timer` or queueing `gpu->recover_work`. [F29, F151]
- In `fenced_write()` and `fence_status_check()`, `mb()` must be executed after `gpu_write(gpu, offset, value)` before polling `REG_A6XX_GMU_AHB_FENCE_STATUS` (never a posted `gpu_read()`), and `fence_status_check()` must re-issue `gpu_write(gpu, offset, value)` followed by `mb()` whenever `status & mask` is non-zero because writedropped writes must be re-issued. [F30, F103]

## Object Lifetimes

- Firmware GEM BOs whose CPU vmap reference was already dropped via `msm_gem_put_vaddr()` (`pm4_bo`, `pfp_bo`, and `gpmu_bo` in `a5xx_gpu`, and `sqe_bo` in `a6xx_gpu`) must be released with `msm_gem_unpin_iova()` followed by `drm_gem_object_put()`, never with `msm_gem_kernel_put()`. In `a5xx_debugfs.c:reset_set()`, releasing `adreno_gpu->fw[ADRENO_FW_PM4/PFP]` must be paired with unpinning, freeing, and NULL-clearing `pm4_bo` and `pfp_bo` and setting `gpu->needs_hw_init = true`. [F5, F65]
- In `a6xx_gmu_stop()`, `a6xx_pm_suspend()`, `a6xx_gmu_resume()`, and `a6xx_pm_resume()`, the GX power domain (`gmu->gxpd`) and clocks must be powered down/released before `gmu->dev` (CX) is put via `pm_runtime_put_sync()` or `pm_runtime_put()`, and `gmu->dev` must be resumed before `gmu->gxpd`. [F9]
- In `a6xx_gmu_memory_free()`, all GMU GEM BOs (`hfi`, `debug`, `icache`, `dcache`, `dummy`, `log`) must be released via `msm_gem_kernel_put(..., gmu->vm)` before calling `mmu->funcs->detach(mmu)` and `drm_gpuvm_put(gmu->vm)`. If `msm_gem_vm_create()` fails in `a2xx_create_vm()`, `mmu->funcs->destroy(mmu)` must be called directly when `!IS_ERR(mmu)`. [F11, F165]
- In `a6xx_gpu_state_get()`, when `a6xx_crashdumper_init(gpu, &_dumper)` succeeds (`dumper != NULL`), `dumper->bo` must be released with `msm_gem_kernel_put(dumper->bo, gpu->vm)` after reading shader and cluster state. `state_kcalloc()` and `state_kmemdup()` return pointers inside `struct a6xx_state_memobj` on `a6xx_state->objs` that must never be passed to `kfree()`/`kvfree()`, whereas `msm_gpu_state_bo.data` (in `a6xx_snapshot_gmu_bo()`) must be allocated with `kvzalloc()`. [F13, F120]

## API Contracts

- `a6xx_gmu_wait_for_idle()` and `spin_usecs()` return `0` on success and `-ETIMEDOUT` on timeout, whereas `a2xx_idle()` through `a6xx_idle()`, `a6xx_gmu_isidle()`, `a6xx_gmu_gx_is_on()`, and `a6xx_gmu_sptprac_is_on()` return `bool` (`true` when idle/powered). [F38]
- `msm_gem_vm_create()` takes the VA range size in bytes (`va_size`) as its fifth argument, whereas `msm_gem_get_and_pin_iova_range()` takes the end address (`range_end = iova + size`) as its fifth argument. `a6xx_gmu_set_oob()` and `a6xx_gmu_clear_oob()` require `gmu->lock` to be held and only support `GMU_OOB_BOOT_SLUMBER` and `GMU_OOB_DCVS_SET` when `gmu->legacy` is true. [F49, F52]
- `gmu_read()`, `gmu_write()`, `gmu_rmw()`, `gmu_read64()`, `gmu_read_rscc()`, `gmu_write_rscc()`, `a6xx_llc_*()`, `cxdbg_*()`, and `pdc_write()` all scale their register offset by `<< 2` on `void __iomem *`, so callers must pass 32-bit dword register indices. `A6XX_PROTECT_NORDWR(_reg, _len)` and `A6XX_PROTECT_RDONLY(_reg, _len)` encode `_len` as a zero-based count (`_len + 1` registers), whereas `ADRENO_PROTECT_RW(_reg, _len)` on A5xx encodes `ilog2(_len)` for a power-of-two `_len` and aligned `_reg`. [F119, F125]
- In `a6xx_gpu_state.c`, `CRASHDUMP_READ()` takes a register count in 32-bit dwords, whereas the target IOVA `out` and byte size passed to `state_kmemdup()` and checked against `A6XX_CD_DATA_SIZE` must be scaled by `sizeof(u32)`. `print_ascii85()` takes `len` in bytes, so callers must shift dword counts by `<< 2` and quadword counts (`a6xx_debugbus_block::count`, allocated with `sizeof(u64)`) by `<< 3`. [F122, F123, F174]

## Error Handling

- `adreno_fw_create_bo()`, `msm_gem_get_vaddr()`, and `msm_gem_kernel_new()` return an `ERR_PTR()` on failure rather than `NULL`: callers (`a5xx_submit_in_rb()`, `a5xx_ucode_check_version()`, `a6xx_ucode_check_version()`, `a5xx_ucode_load()`, `a6xx_ucode_load()`) must check `IS_ERR()`/`IS_ERR_OR_NULL()`, and `a5xx_ucode_load()` / `a6xx_ucode_load()` must reset `pm4_bo`, `pfp_bo`, or `sqe_bo` to `NULL` on `IS_ERR()` so teardown functions (`a5xx_destroy()`, `reset_set()`, `a6xx_destroy()`) do not unpin/put an `ERR_PTR`. [F34, F35]
- In `a3xx_gpu_init()` and `a4xx_gpu_init()`, `devm_of_icc_get()` returns an `ERR_PTR()` tested with `IS_ERR()` and extracted with `PTR_ERR()`; when the optional `"ocmem"` interconnect returns `-ENODATA`, `ocmem_icc_path` must be reset to `NULL` before calling `icc_set_bw()`. In `a6xx_gmu_init()` and `a6xx_gmu_wrapper_init()`, the return value of `of_dma_configure(gmu->dev, node, true)` must be checked and propagated before enabling runtime PM or mapping resources. [F36, F37]
- In `a5xx_hw_init()` and `a6xx_gpu.c:hw_init()`, when `a5xx_zap_shader_init()` or `a6xx_zap_shader_init()` returns `-ENODEV`, the driver falls back to writing `0` to `RBBM_SECVID_TRUST_CNTL` (and resets `ret = 0` in `hw_init()`), whereas any other non-zero error must be propagated without touching `RBBM_SECVID_TRUST_CNTL`. [F46]

## Known Pitfalls

- In `a6xx_gpu_state.c`, A7xx snapshot table selectors (`a7xx_get_dbgahb_clusters()`, `a7xx_get_clusters()`, `a7xx_get_shaders()`, `a7xx_get_registers()`, `a7xx_get_debugbus_blocks()`) must branch on exact `adreno_gpu->info->family` values (`ADRENO_7XX_GEN1`, `ADRENO_7XX_GEN2`, `ADRENO_7XX_GEN3`) rather than `adreno_is_a740_family()`, which matches both GEN2 and GEN3. Similarly, `adreno_is_a330v2()` must be tested before `adreno_is_a330()` in `a3xx_hw_init()`, and `adreno_is_a619_holi()` before `a6xx_has_gbif()` in `a6xx_gpu.c:hw_init()`. [F94, F96, F97]
- In `a6xx_gpu_state.c`, A7xx register capture helpers (`a7xx_get_crashdumper_registers()`, `a7xx_get_ahb_gpu_registers()`) must store the `UINT_MAX`-terminated `const u32 *` (`regs->regs`) in `obj->handle`, whereas A6xx helpers store `const struct a6xx_registers *`. When programming `struct gen7_reg_list` selectors (`regs->sel`), CPU AHB reads in `a7xx_get_ahb_gpu_reglist()` must write `regs->sel->host_reg`, whereas crashdumper scripts in `a7xx_get_crashdumper_registers()` must write `regs->sel->cd_reg`. [F70, F109]
- On GPUs with `ADRENO_QUIRK_IFPC`, `a6xx_progress()` must return `true` without reading GX-domain CP registers (`REG_A6XX_CP_IB1_BASE`, `REG_A6XX_CP_ROQ_AVAIL_IB1`), and `a6xx_get_rptr()` must read `a6xx_gpu->shadow[ring->id]` instead of `REG_A6XX_CP_RB_RPTR`. On A5xx and A6xx/A7xx, `shadow` is a `uint32_t *` indexed by `ring->id`, whereas `shadow_iova` is a GPU byte address offset by `ring->id * sizeof(uint32_t)` via `shadowptr()`. [F126, F141]
