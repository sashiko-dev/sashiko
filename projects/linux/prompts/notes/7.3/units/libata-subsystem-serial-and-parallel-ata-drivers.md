# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers)

This unit implements the core libata framework (`libata-core.c`, `libata-eh.c`, `libata-sata.c`, `libata-pmp.c`, `libata-pata-timings.c`, `libata-acpi.c`), the common AHCI library (`libahci.c`), PCI SATA/PATA drivers (`ahci.c`, `acard-ahci.c`, `ata_piix.c`, `ata_generic.c`), and SoC platform AHCI drivers. It manages host/port/link/device/command lifecycles, DMA and MMIO programming, ACPI integration, Port Multipliers, and multi-stage Error Handler (EH) recovery.

## Architecture & Data Flow

- `ata_qc_issue()` marks `qc` active (`ATA_QCFLAG_ACTIVE`, `ap->qc_active`, `ap->nr_active_links`, `link->sactive`/`link->active_tag`) at entry, so every subsequent error path must complete `qc` via `ata_qc_complete()` or `ata_link_abort()` rather than returning or calling `ata_qc_free()`. `ap->nr_active_links` is incremented/decremented on every non-NCQ command, but for NCQ only when `link->sactive` transitions between zero and non-zero. [F195, F235]
- `ata_exec_internal()` assigns `qc->tag = ATA_TAG_INTERNAL` (bit 32 in 64-bit `ap->qc_active`) while setting `qc->hw_tag = 0`; `ata_qc_get_active()` shifts bit 32 to bit 0 and `ata_qc_complete_multiple()` shifts bit 0 back to `1ULL << ATA_TAG_INTERNAL`. Never compare or XOR 32-bit hardware active-tag registers directly with `ap->qc_active`. [F264]
- When FIS-based switching (`pp->fbs_enabled`) is active, `pp->active_link` is invalid; completion/RTF paths (`ahci_qc_complete()`, `ahci_qc_fill_rtf()`, `ahci_qc_ncq_fill_rtf()`) must not use `pp->active_link` and must offset `pp->rx_fis` by `qc->dev->link->pmp * AHCI_RX_FIS_SZ` (256 bytes, requiring `AHCI_PORT_PRIV_FBS_DMA_SZ` in `ahci_port_start()` when `pp->fbs_supported`), or `ACARD_AHCI_RX_FIS_SZ` (128) on ACard. `ahci_enable_fbs()` must set `pp->fbs_last_dev = -1`, and command issue paths writing a new PMP to `PORT_FBS` must update `pp->fbs_last_dev` and clear `PORT_FBS_DEC`. [F61, F62, F93, F126, F127]
- In `ahci_handle_port_interrupt()`, `PORT_IRQ_BAD_PMP` (when `ATA_PFLAG_RESETTING`) and `PORT_IRQ_PHYRDY` (when `sata_lpm_ignore_phy_events(&ap->link)`) must be masked out of `status` before testing `status & PORT_IRQ_ERROR`. In `ahci_error_intr()`, `SCR_ERROR` must be read and written back to clear write-1-to-clear bits; `pmp = fbs >> PORT_FBS_DWE_OFFSET` must be checked against `ap->nr_pmp_links`; `if (!link) link = &ap->link;` must run before dereferencing `link`; and link-specific PMP/FBS errors go to `&link->eh_info` while port-wide/hotplug errors go to `&ap->link.eh_info`. [F95, F106, F110, F117, F153]
- Changes to per-port enabled interrupts in `libahci.c` must update `pp->intr_mask` so `ahci_thaw()` restores them, and `ahci_pmp_attach()`/`ahci_pmp_detach()` must not write `pp->intr_mask` to `PORT_IRQ_MASK` when `ata_port_is_frozen(ap)` is true. [F63]
- Before `ahci_init_controller()` sets `HOST_IRQ_EN`, each non-dummy port must be stopped via `ahci_deinit_port()` and cleared via `ahci_port_clear_pending_irq()`. Hardreset paths calling `sata_link_hardreset()` with `ahci_check_ready` must first call `ahci_port_clear_pending_irq(ap)` and write `tf.status = ATA_BUSY` into `pp->rx_fis + RX_FIS_D2H_REG`, assigning `*class` only when `online` is true. [F52, F136, F137]
- In `ata_qc_complete()`, scheduling EH for a non-error command (`!(qc->flags & ATA_QCFLAG_EH)`) requires both `ATA_QCFLAG_HAS_CDL` and `qc->result_tf.status & ATA_SENSE`, setting `SCMD_FORCE_EH_SUCCESS`, `ATA_QCFLAG_EH_SUCCESS_CMD`, `ATA_EH_GET_SUCCESS_SENSE`, and `ATA_PFLAG_EH_PENDING` before `ata_qc_schedule_eh()`; EH must then call `ata_eh_decide_disposition()`. When `ata_eh_get_ncq_success_sense()` reads `ATA_LOG_SENSE_NCQ` (validating version `1`, address `0x0f`, and `sense_valid & BIT(tag)`), it must copy `nsect`, `lbal`/`lbam`/`lbah`, their HOBs, and `auxiliary` into `qc->result_tf`. [F240, F266, F277, F366]
- When `ata_eh_analyze_ncq_error()` identifies the offending command from log page 10h (requiring `!(buf[0] & 0x80)` and `link->sactive & BIT(tag)`), it must clear `ATA_ERR` from `qc->result_tf.status`, zero `qc->result_tf.error`, set `ATA_QCFLAG_RETRY` on all other non-successful EH commands on that physical link, and clear `AC_ERR_DEV` from `ehc->i.err_mask`. [F241, F265]
- In `ata_eh_autopsy()`, link autopsy must run on `EDGE` links and `ap->slave_link` before `&ap->link` when `sata_pmp_attached(ap)` is true. In `ata_eh_reset()`, hardresetting `ap->slave_link` after the master link must pass `clear_classes = false` to `ata_do_reset()`, and any successful reset must set `link->lpm_policy = ATA_LPM_UNKNOWN`. In `ata_eh_revalidate_and_attach()`, the first loop (revalidate/IDENTIFY) must iterate `ALL_REVERSE` before cable detection, while the second (`ata_dev_configure()`) iterates `ALL`. [F250, F284, F291, F292]
- During revalidation (`ata_dev_reread_id()`, `sata_pmp_revalidate()`), new IDENTIFY or GSCR data must be read into `dev->sector_buf` and verified via `ata_dev_same_device()` or `sata_pmp_same_pmp()` before overwriting `dev->id` or `dev->gscr`. `ata_dev_configure()` must call `ata_clear_log_directory(dev)` before querying logs (`dev->gp_log_dir`), and `ata_read_log_directory()` must clear `dev->gp_log_dir` on error. [F244, F253]
- Every enabled `ATA_DEV_*` class constant must have its `*_UNSUP` constant at `class + 1` because `ata_eh_dev_disable()` executes `dev->class++`. Every `enum ata_quirks` bit (`< __ATA_QUIRK_MAX <= 32`) must have a matching `ATA_QUIRK_*` mask and non-NULL `ata_quirk_names[]` entry. In `struct ata_port_operations`, `inherits` must be the final member, all preceding members must be pointers, and overriding an ancestor callback to `NULL` requires `ATA_OP_NULL`. [F256, F257, F356]

## Synchronization

- `ap->lock` (aliased to `&ap->host->lock` unless `AHCI_HFLAG_MULTI_MSI` is set, where `ahci_port_start()` initializes `pp->lock` and sets `ap->lock = &pp->lock`) is used in hardirq and timer (`ap->fastdrain_timer`) contexts; process/workqueue/sysfs callers must use `spin_lock_irqsave()`. `ap->scsi_scan_mutex` and `ap->host->eh_mutex` nest outside `ap->lock`: never acquire them or call sleeping SCSI routines (`scsi_remove_device()`, `scsi_change_queue_depth()`), `sata_link_hardreset()`, or `ata_port_wait_eh()` while holding `ap->lock`. [F23, F39, F205, F218, F340, F345, F365]
- All mutations to `ap->qc_active`, `ap->nr_active_links`, `ap->excl_link`, `link->active_tag`, `link->sactive`, and `qc->flags` during command issue/completion must hold `ap->lock`. In `__ata_eh_qc_complete()`, setting `qc->scsidone = ata_eh_scsidone` and calling `__ata_qc_complete(qc)` must occur under `ap->lock`, whereas `scsi_eh_finish_cmd()` runs unlocked. [F206, F219]
- In `ata_port_freeze()`, `__ata_port_freeze(ap)` must precede `ata_port_abort(ap)` under `ap->lock`. In `ata_scsi_cmd_error_handler()`, after `ata_sff_flush_pio_task(ap)`, `ap->lock` must be held continuously across `ap->ops->lost_interrupt(ap)`, marking timed-out commands with `ATA_QCFLAG_EH`, and calling `__ata_port_freeze(ap)`. [F207, F208]
- In `ata_scsi_port_error_handler()`, `timer_delete_sync(&ap->fastdrain_timer)` must run outside `ap->lock` at the start of each EH pass before copying/zeroing `link->eh_info`, setting `ATA_PFLAG_EH_IN_PROGRESS`, and clearing `ATA_PFLAG_EH_PENDING` under `ap->lock`; at the end of EH, checking `ATA_PFLAG_EH_PENDING`, clearing `link->eh_info`, and calling `ap->ops->end_eh(ap)` must occur in the same `ap->lock` critical section before `ata_eh_release(ap)`. [F209, F210]
- `ata_exec_internal()` must save and zero `link->active_tag`, `link->sactive`, `ap->qc_active`, and `ap->nr_active_links` under `ap->lock`, call `ata_eh_release(ap)` before `wait_for_completion_timeout(&wait)`, call `ata_eh_acquire(ap)` and `ata_sff_flush_pio_task(ap)` afterward, freeze the port under `ap->lock` if timed out to complete the on-stack `wait`/`sgl`, and restore the preempted fields under `ap->lock` after `ata_qc_free(qc)`. [F197, F211]
- In `ahci_single_level_irq_intr()` and `ahci_thunderx_irq_handler()`, `&host->lock` must be held across `ahci_handle_port_intr(host, irq_masked)` and writing the unmasked `irq_stat` to `HOST_IRQ_STAT` afterward; in `xgene_ahci_irq_intr()`, `HOST_IRQ_STAT` is written under `&host->lock` before `xgene_ahci_handle_broken_edge_irq()`. [F25, F26, F161]
- In `ahci_deinit_port()`, `hpriv->stop_engine(ap)` must precede `ahci_stop_fis_rx(ap)`, whereas `ahci_start_port()` calls `ahci_start_fis_rx(ap)` before `hpriv->start_engine(ap)`. Modifying `PORT_FBS_EN` in `PORT_FBS` or programming `PORT_DEVSLP` requires stopping the DMA engine first and restarting it afterward. [F31, F65]

## Object Lifetimes

- `ata_host_alloc()` registers `ata_devres_release` via `devres_add(dev, dr)` before allocating ports in `host->ports[]`: failures before `devres_add()` must call `kfree(host)`, failures after must only call `devres_release_group(dev, NULL)`, and `ata_devres_release()`/`ata_host_release()` must null-check `host->ports[i]` and free each port via `ata_port_free()` (never `kfree(ap)` directly). [F187, F220, F308, F325]
- `ata_host_start()` must pre-allocate the `ata_host_stop` devres node, call `ata_finalize_port_ops()`, unwind started ports in reverse (`while (--i >= 0)`) and free `start_dr` if any `->port_start()` fails, and only call `devres_add()` and set `ATA_HOST_STARTED` after all ports start and are frozen. `ata_host_register()` requires `ATA_HOST_STARTED` and unwinds `ata_tport_add()` in reverse via `ata_tport_delete()` on error; `ata_host_activate()` must call `devm_free_irq()` if `ata_host_register()` fails. [F189, F190, F200, F327]
- `ahci_port_resume()` (and `ahci_port_start()`) acquires a runtime PM reference via `ahci_rpm_get_port(ap)` that must be balanced by `ahci_rpm_put_port(ap)` in `ahci_port_suspend()` and `ahci_port_stop()`. Any AHCI MMIO access outside EH/command paths (sysfs attributes and `ahci_transmit_led_message()`) must be bracketed by `ahci_rpm_get_port(ap)` and `ahci_rpm_put_port(ap)`. [F5, F158]
- `ata_dev_init()` zeroes `struct ata_device` from `ATA_DEVICE_CLEAR_BEGIN` (`n_sectors`) to `ATA_DEVICE_CLEAR_END` (`ering`) and clears only `ATA_DFLAG_INIT_MASK` (while `ata_dev_configure()` clears only `ATA_DFLAG_CFG_MASK`), and `ata_link_init()` zeroes `struct ata_link` from `ATA_LINK_CLEAR_BEGIN` (`active_tag`) to `ATA_LINK_CLEAR_END` (`device[0]`). Persistent fields must remain outside those ranges, and heap pointers inside them must be freed in `ata_dev_free_resources()`. [F249, F310, F311]
- `sata_pmp_init_links()` must allocate and register all `SATA_PMP_MAX_PORTS` elements in `ap->pmp_link`, and `sata_pmp_attach()`/`sata_pmp_detach()` must update `ap->nr_pmp_links` (and reset `link->pmp = 0` on detach/failure) under `ap->lock` only after `ap->pmp_link` is initialized, keeping `ap->pmp_link` allocated until `ata_port_free()`. [F246, F309, F314, F354]

## API Contracts

- `ata_exec_internal()` and internal command wrappers (`ata_do_dev_read_id()`, `ata_dev_set_feature()`, `ata_read_log_page()`, `sata_pmp_read()`/`write()`, `atapi_eh_tur()`, `atapi_eh_request_sense()`), as well as `.read_id` callbacks (`brcm_ahci_read_id()`, `ceva_ahci_read_id()`, `xgene_ahci_read_id()`), return an `unsigned int` `AC_ERR_*` bitmask (`0` on success), never a negative errno. [F43, F221]
- Any buffer passed to `ata_exec_internal()` with `dma_dir != DMA_NONE` is DMA-mapped via `sg_init_one()`/`dma_map_sg()` and must reside in cacheline-aligned DMA-safe memory (`dev->id`, `dev->gp_log_dir`, `dev->sector_buf`, or `kmalloc()`), never on the stack. `ata_read_log_page()` takes `sectors` in `ATA_SECT_SIZE` (512-byte) units, whereas `ata_exec_internal()` takes `buflen` in bytes; variable-length GP log pages must size allocations from `ata_log_supported()`. `ata_sg_setup()` must save `qc->orig_n_elem` before `dma_map_sg()` overwrites `qc->n_elem`, and `ata_sg_clean()` must pass `qc->orig_n_elem` to `dma_unmap_sg()`. [F196, F260, F307, F353]
- Return value conventions: `sata_link_hardreset()` and `sata_std_hardreset()` return `-EAGAIN` (with `*online = true`) on an online link needing a follow-up softreset; `ata_qc_complete_multiple(ap, qc_active)` takes the bitmask of commands still active in hardware and returns completed count (`>= 0`) or `-EINVAL`; `sata_set_spd()` returns `0` (unchanged), `1` (`SCR_CONTROL` updated), or `< 0` on error; `ata_xfer_mask2mode()` and `ata_timing_cycle2mode()` return `0xff` when no mode matches (and require packed `xfer_mask` from `ata_pack_xfermask()`). [F223, F227, F228, F229, F233]
- `ata_port_operations` command-path and EH-scheduling callbacks (`qc_defer`, `check_atapi_dma`, `qc_prep`, `qc_issue`, `qc_fill_rtf`, `qc_ncq_fill_rtf`, `freeze`, `thaw`, `sched_eh`, `end_eh`, `lost_interrupt`), `qc->complete_fn`, and host-link `scr_read`/`scr_write` must be atomic-safe (`ap->lock` held, IRQs disabled), whereas PMP fan-out link (`!ata_is_host_link(link)`) `sata_scr_read()`/`write()` use `ata_exec_internal()` and require EH process context. [F341, F343]
- `ata_qc_for_each()` and `ata_qc_for_each_with_internal()` execute the loop body for every tag even when `ata_qc_from_tag()` returns `NULL` (callers must check `if (qc)`), and `ata_qc_from_tag()` hides slots with `ATA_QCFLAG_EH` set; EH routines inspecting EH-owned commands must use `ata_qc_for_each_raw()` and filter on `ATA_QCFLAG_EH`. [F280, F281]

## Error Handling

- Per-link recovery helpers in `ata_eh_recover()` taking `struct ata_device **r_failed_dev` (`ata_eh_revalidate_and_attach()`, `ata_eh_set_mode()`, `ata_set_mode()`, `ap->ops->set_mode`, `ata_eh_link_set_lpm()`) must set `*r_failed_dev` on any non-zero error. Because `ata_eh_handle_dev_fail()` does not decrement `ehc->tries[dev->devno]` when `err == -EAGAIN`, any helper returning `-EAGAIN` must mutate state to bound retries. [F226, F286]

## External Contracts

- `ata_dev_read_id()` swaps `dev->id` into native `u16` words in-place, so strings require `ata_id_string()` (even `len`) or `ata_id_c_string()` (odd `len` and 16-bit word offset `ofs`), whereas `.read_id` overrides modify raw `__le16 *id` using `cpu_to_le16()`. Conversely, GP Log pages from `ata_read_log_page()` remain raw little-endian bytes (`get_unaligned_le16`/`32`/`64`), and 64-bit QWords in `ATA_LOG_IDENTIFY_DEVICE` require `BIT_ULL(63)` to be valid. [F102, F222, F262, F263]

## Known Pitfalls

- 64-bit / bit-width hazards: `ap->qc_active` and `done_mask` in `ahci_qc_ncq_fill_rtf()` are `u64` (including bit 32, `ATA_TAG_INTERNAL`), requiring `1ULL << tag`, `BIT_ULL(tag)`, and `__ffs64()`, and `done_mask &= ~(1ULL << tag)` must run on every loop iteration in `ahci_qc_ncq_fill_rtf()`. `tf->hob_lbah`/`hob_lbam`/`hob_lbal` must be cast to `(u64)` before shifting by 40/32/24; `u32` port masks (`hpriv->port_map`, `saved_port_map`) must be copied to an `unsigned long` local before `for_each_set_bit()`; and byte offsets into `void *` `pp->cmd_tbl`/`pp->rx_fis` must be added before casting to typed pointers. [F115, F119, F128, F131, F297, F321]
- When matching a command or device to a physical `ata_link` in EH autopsy, sense retrieval, or reporting, compare `ata_dev_phys_link(dev) == link` rather than `dev->link == link` (slave-link devices have `dev->link == &ap->link`). Similarly, `SATA_PMP_MAX_PORTS`-sized arrays (`ap->pmp_link`, `link_tries`) must only be indexed by `link->pmp` when iterating `EDGE` links (on the host link, `link->pmp` can be `SATA_PMP_CTRL_PORT == 15`). [F267, F282]
- Because `ata_identify_page_supported()` overwrites `dev->sector_buf` with page 0 of `ATA_LOG_IDENTIFY_DEVICE`, callers using `dev->sector_buf` for another log page must call `ata_identify_page_supported()` before reading their log page into `dev->sector_buf`. In `ata_dev_config_cpr()`, `cpr_log->nr_cpr = nr_cpr` must be set before indexing `cpr_log->cpr[]` (`__counted_by(nr_cpr)`). [F245, F306]
