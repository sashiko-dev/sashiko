# BROADCOM ASP 2.0 ETHERNET DRIVER

Linux platform and network device driver for the Broadcom STB ASP 2.0/3.0 Ethernet controller (`brcm,asp-v2.1`, `brcm,asp-v2.2`, `brcm,asp-v3.0`). `bcmasp.c` manages shared controller resources—clocks, top-level L2 and Wake-on-LAN interrupts, MAC destination address (MDA) filters, and ethtool RX network wake filters—while `bcmasp_intf.c` and `bcmasp_ethtool.c` implement per-port network interfaces (`struct bcmasp_intf`) with UniMAC, RGMII/EPHY, TX SPB DMA, RX EDPKT DMA rings, and ethtool operations.

## Architecture & Data Flow

- Each wake filter spans an even-indexed pair of hardware slots (`hw_index` and `hw_index + 1`). `bcmasp_netfilt_get_init` must require an even index with both slots unclaimed and set `claimed` and `wake_filter` on both, `bcmasp_netfilt_release` must zero both slots, and per-port scans of `priv->net_filters` (`bcmasp_netfilt_suspend`, `bcmasp_netfilt_get_all_active`, `bcmasp_netfilt_get_active`) must skip odd indices `i` when `priv->net_filters[i].wake_filter && priv->net_filters[i - 1].wake_filter` because `port` is left 0 on `open_index + 1`. [F38, F61]
- Wake filter specs in `priv->net_filters` are written to hardware only at suspend (`bcmasp_netfilt_suspend` -> `bcmasp_netfilt_wr_to_hw`, which first zeroes hardware match/mask registers via `bcmasp_netfilt_reset_hw`). On resume, `bcmasp_core_init_filters` must disable `ASP_RX_FILTER_NET_CFG(i)` in hardware without clearing `priv->net_filters[i]`. [F50]
- Network filter pattern/mask registers only accept 4-byte aligned accesses within `MAX_WAKE_FILTER_SIZE` (256). `bcmasp_netfilt_wr_m_wake` must check `(offset + size) <= MAX_WAKE_FILTER_SIZE`, dereference `match` and `mask` as unsigned `u8 *` before shifting by `shift = (3 - (offset % 4)) * 8` (avoiding sign-extension of bytes `>= 0x80`), read-modify-write via `bcmasp_netfilt_rd` at `ALIGN_DOWN(offset, 4)` when unaligned or `size < 3`, and reset `first_byte = true` whenever a word is flushed (`!size || ((offset % 4) == 3)`). [F68, F78, F86]
- `priv->mda_filters` reserves indices `0 .. bcmasp_total_res_mda_cnt(priv) - 1` for per-interface `ASP_RX_FILT_MDA(intf, ...)` slots. `bcmasp_disable_all_filters` and `bcmasp_set_en_mda_filter` must start at `bcmasp_total_res_mda_cnt(intf->parent)` and only modify or combine enabled filters matching `priv->mda_filters[i].port == intf->port`. [F46]
- In `bcmasp_set_rx_mode`, when `bcmasp_set_en_mda_filter` fails due to filter exhaustion and jumps to `set_promisc`, the fallback must both enable the port's reserved promiscuous filter (`bcmasp_set_promisc(intf, 1)`) and call `bcmasp_disable_all_filters(intf)` to release dynamic MDA filters claimed earlier in the loop. [F52]
- Every loop, bounds check, and ethtool table-size report for `priv->mda_filters` and `priv->net_filters` must use `priv->num_mda_filters` and `priv->num_net_filters` rather than `NUM_MDA_FILTERS` or `NUM_NET_FILTERS`. [F60]
- Supported ethtool RX flow types (`ETHER_FLOW`, `IP_USER_FLOW`, `TCP_V4_FLOW`, `UDP_V4_FLOW`, `TCP_V6_FLOW`, `UDP_V6_FLOW`) are dispatched in parallel across `bcmasp_flow_insert`, `bcmasp_netfilt_check_dup`, and `bcmasp_netfilt_wr_to_hw`; adding a flow type requires updating all three switch statements in lockstep. [F57]
- Hardware DMA ring `_END` and `_VALID` registers (`TX_SPB_DMA_END`/`VALID`, `RX_EDPKT_DMA_END`/`VALID`, `RX_EDPKT_RING_BUFFER_END`/`VALID`) store inclusive last-byte DMA addresses (initialized to `base + size - 1` and advanced with `incr_last_byte`), whereas `_BASE`, `_READ`, and `_WRITE` registers store first-byte DMA addresses advanced with `incr_first_byte`. [F63]
- Because `bcmasp_tx_reclaim()` and `bcmasp_clean_txcb()` only clear software `intf->tx_cbs` entries and leave `intf->tx_spb_cpu` hardware descriptors intact, `bcmasp_xmit()` must zero each `struct bcmasp_desc` before OR-ing `DESC_SOF`, `DESC_EPKT_CMD`, `DESC_EOF`, or `DESC_INT_EN` into `desc->flags`. [F26]
- `struct bcmasp_desc::buf` packs a 40-bit DMA address in bits 39:0 (`DESC_ADDR`) and hardware flags in bits 63:40 (`DESC_FLAGS`), and rings are sized by `DESC_RING_SIZE` (`DESC_RING_COUNT * DESC_SIZE`). Therefore, the DMA mask in `bcmasp_probe` must not exceed `DMA_BIT_MASK(40)`, all `buf` flag/mask macros (`DESC_CHKSUM`, `DESC_CRC_ERR`, `DESC_RX_SYM_ERR`, `DESC_NO_OCT_ALN`, `DESC_PKT_TRUC`) must use `BIT_ULL`/`GENMASK_ULL`, and `sizeof(struct bcmasp_desc)` must equal `DESC_SIZE`. [F84, F92, F119]
- Because `bcmasp_init_rx` sets `RX_EDPKT_CFG_CFG0_EFRM_STUF` and `bcmasp_netif_init` caches `intf->crc_fwd` from `UMC_CMD_CRC_FWD`, `bcmasp_rx_poll` must `skb_pull(skb, 2)` (`len -= 2`) and, when `intf->crc_fwd` is set, `skb_trim(skb, len - ETH_FCS_LEN)` (`len -= ETH_FCS_LEN`) before `eth_type_trans` and `rx_bytes` accounting. [F54]
- `umac_reset()` must leave `UMC_CMD_SW_RESET` set in `UMC_CMD`, and `umac_enable_set()` must return early while `UMC_CMD_SW_RESET` is set. `bcmasp_netif_init` (on open and resume) calls `umac_reset` and resets `intf->old_duplex = -1`, `intf->old_link = -1`, and `intf->old_pause = -1` so `bcmasp_adj_link()` detects a change, clears `UMC_CMD_SW_RESET`, and sets `UMC_CMD_TX_EN | UMC_CMD_RX_EN | UMC_CMD_PROMISC` once `phydev->link` is up (or `bcmasp_suspend_to_wol()` clears it). [F51, F94]
- In `bcmasp_init_tx()`, `TX_PAUSE_MAP_VECTOR` must be written with `1 << (intf->channel + 8)` when `intf->parent->tx_chan_offset` is non-zero (ASP v2.1/v2.2) and skipped when `tx_chan_offset` is 0 (ASP v3.0). [F95]
- Internal EPHY mode (`intf->internal_phy`, set when `intf->phy_interface == PHY_INTERFACE_MODE_INTERNAL`) is only valid on `intf->port == 1`, and `bcmasp_enable_phy_irq()` and `dev->phydev->irq = PHY_MAC_INTERRUPT` must only be used when `intf->internal_phy` is true. [F101]
- `priv->eee_fixup` is only populated in `v22_plat_data` (`brcm,asp-v2.2`) and is `NULL` on v2.1 and v3.0, and `ndev->phydev` is `NULL` when the interface is not open; both pointers must be checked before invoking `intf->parent->eee_fixup`. [F27]
- Runtime code reads hardware-revision parameters and callbacks from `struct bcmasp_priv` rather than `struct bcmasp_plat_data`; any field added to `struct bcmasp_plat_data` (`v21_plat_data`, `v22_plat_data`, `v30_plat_data`) must also be added to `struct bcmasp_priv` and copied in `bcmasp_set_pdata`. [F56]
- `bcmasp_update_mib_counters` and `bcmasp_get_ethtool_stats` access `intf->mib` via `(char *)(&intf->mib) + (i * sizeof(u32))` for each index `i` in `bcmasp_gstrings_stats`. `bcmasp_gstrings_stats` and `struct bcmasp_mib_counters` must stay in matching order with 32-bit `u32` fields, and `bcmasp_update_mib_counters` must `continue` on `BCMASP_STAT_SOFT` entries before `put_unaligned(val, (u32 *)p)` so software counters are not overwritten. [F76, F90]

## Synchronization

- Runtime callers of `bcmasp_set_promisc`, `bcmasp_set_allmulti`, `bcmasp_set_broad`, `bcmasp_set_oaddr`, `bcmasp_set_en_mda_filter`, and `bcmasp_disable_all_filters` (such as `bcmasp_set_rx_mode`) must hold `intf->parent->mda_lock` via `spin_lock_bh`, and neither `bcmasp_set_rx_mode` nor those helpers may sleep or perform blocking allocations. [F12, F112]
- All modifications to `ASP_CTRL_CLOCK_CTRL` in `bcmasp_core_clock_set_ll` must be serialized under `priv->clk_lock` (`spin_lock_irqsave`) and mirrored to `ASP_CTRL_SCRATCH_0`. `bcmasp_core_clock_set_intf` must read `ASP_CTRL_SCRATCH_0` under `priv->clk_lock` to verify all `ASP_CTRL_CLOCK_CTRL_ASP_RGMII_MASK` bits are set before disabling shared TX/RX clocks. [F13, F102]
- Runtime lookups, duplicate checks, allocations, and releases in `intf->parent->net_filters` (`bcmasp_netfilt_check_dup`, `bcmasp_netfilt_get_init`, `bcmasp_netfilt_release`, `bcmasp_netfilt_get_active`, `bcmasp_netfilt_get_all_active`) must hold `intf->parent->net_lock` continuously across the entire check-and-update sequence. [F15]
- Updates to `struct bcmasp_intf_stats64` counters in `bcmasp_tx_reclaim` and `bcmasp_rx_poll` must be bracketed by `u64_stats_update_begin` and `u64_stats_update_end` on `intf->stats64.syncp`, paired with the `u64_stats_fetch_begin` / `u64_stats_fetch_retry` loop in `bcmasp_get_stats64`. [F18]

## Object Lifetimes

- In `bcmasp_xmit`, `NETDEV_TX_BUSY` is returned without freeing `skb` when `tx_spb_ring_full` is true before modifying the packet; every subsequent failure path returns `NETDEV_TX_OK` and must consume `skb` (via `skb_put_padto` on pad failure, or `dev_kfree_skb(skb)` after `bcmasp_clean_txcb` rollback on `dma_mapping_error`). [F1]
- In `bcmasp_xmit`, every fragment's `struct bcmasp_tx_cb` stores `txcb->skb = skb`, but only the final fragment (`i == nr_frags`) sets `txcb->last = true` (with `DESC_EOF`). `bcmasp_tx_reclaim` must call `dev_consume_skb_any(txcb->skb)` and increment `stats->tx_packets`/`stats->tx_bytes` only when `txcb->last` is true. [F128]
- In `bcmasp_netif_init` and `bcmasp_netif_start`, TX/RX rings (`bcmasp_init_tx`, `bcmasp_init_rx`) and NAPI instances (`netif_napi_add_tx(&intf->tx_napi)`, `netif_napi_add(&intf->rx_napi)`, `napi_enable`) must be initialized and enabled before unmasking interrupts via `bcmasp_enable_rx_irq`, `bcmasp_enable_tx_irq`, and `bcmasp_enable_phy_irq`, and both NAPI instances must be deleted with `netif_napi_del` in `bcmasp_netif_deinit` (and on any error path after registration). [F5, F20]
- In `bcmasp_probe()`, all `bcmasp_intf` instances must be created and added to `priv->intfs` before any `register_netdev()` call because `bcmasp_total_res_mda_cnt()` computes the reserved MDA filter boundary from `list_count_nodes(&priv->intfs)`. [F98]
- `bcmasp_remove_intfs` must iterate `priv->intfs` with `list_for_each_entry_safe` and unlink `&intf->list` before calling `bcmasp_interface_destroy(intf)` (which frees `intf->ndev`). When `bcmasp_interface_create()` registers a fixed-link PHY via `of_phy_register_fixed_link(ndev_dn)`, `bcmasp_interface_destroy()` must call `of_phy_deregister_fixed_link(intf->ndev_dn)` after `unregister_netdev(intf->ndev)` (if `NETREG_REGISTERED`) and before `free_netdev(intf->ndev)`. [F77, F107]
- `bcmasp_enable_wol` tracks per-port WoL state in `priv->wol_irq_enabled_mask` under `priv->wol_lock` so `enable_irq_wake(priv->wol_irq)` and `device_set_wakeup_enable(dev, 1)` are called only when the mask transitions from 0 to non-zero, and `disable_irq_wake` / `device_set_wakeup_enable(dev, 0)` only when it returns to 0. [F10]
- During `bcmasp_resume`, `bcmasp_core_init` and `bcmasp_core_init_filters` must run before `bcmasp_interface_resume` iterates over `priv->intfs`, because `bcmasp_core_init_filters` clears all `priv->mda_filters[i].en` states and hardware MDA registers that `bcmasp_interface_resume` subsequently reprograms. [F22]

## API Contracts

- `bcmasp_netfilt_get_init()` always returns an `ERR_PTR` (`-EINVAL` or `-EBUSY`) on failure and never `NULL` (despite its comment), so callers must check `IS_ERR()`. Its user-supplied `loc` parameter must be an unsigned `u32` and, when not `RX_CLS_LOC_ANY`, must be checked against `priv->num_net_filters` before indexing `priv->net_filters[loc]` or starting the search loop. [F23, F58]
- `bcmasp_flow_insert` must assign `cmd->fs.location = nfilter->hw_index` before copying `cmd->fs` into `nfilter->fs` so `nfilter->fs.location` stores the hardware index rather than `RX_CLS_LOC_ANY`. In `bcmasp_netfilt_get_all_active`, the capacity check `j == *rule_cnt` (returning `-EMSGSIZE`) must be evaluated only after confirming `priv->net_filters[i]` is an active non-companion filter for `intf->port` and immediately before writing `rule_locs[j++]`. [F59, F133]
- In `struct ethtool_rx_flow_spec`, `fs->flow_type` may include `FLOW_EXT` and `FLOW_MAC_EXT` flag bits; code inspecting the base protocol and accessing the `h_u`/`m_u` union must mask `fs->flow_type & ~(FLOW_EXT | FLOW_MAC_EXT)` and compare only the active union variant's size rather than `sizeof(fs->h_u)`. [F33]
- `bcmasp_csum_offload()` leaves `*csum_hw` unmodified on early return or software-checksum fallback, so callers must initialize `csum_hw = false`. When `skb->ip_summed == CHECKSUM_PARTIAL`, it must verify IPv4/IPv6 TCP/UDP and call `skb_cow_head(skb, sizeof(*offload))` before `skb_push` (falling back to `skb_checksum_help(skb)` on failure or unsupported protocols), and `bcmasp_xmit` must set `DESC_EPKT_CMD` on the first TX descriptor (`!i`, with `DESC_SOF`) if and only if `csum_hw` is true. [F25, F124, F125]
- `struct bcmasp_intf` uses `intf->index` (0-based sequential index) for reserved MDA filter slots in `ASP_RX_FILT_MDA`, `intf->port` (DT `reg`) for UniMAC/RGMII/filter port selection and WoL bitmasks, and `intf->channel` (DT `brcm,channel`) for DMA ring offsets and `ASP_INTR2_*` interrupt bit shifts. [F30]
- In `ASP_CTRL_CLOCK_CTRL` and `ASP_CTRL_SCRATCH_0`, set bits disable clocks (`ASP_CTRL_CLOCK_CTRL_ASP_*_DISABLE`); `bcmasp_core_clock_set(priv, clr, set)` and `bcmasp_core_clock_set_ll(priv, clr, set)` take clock masks in `clr` to enable clocks and in `set` to disable clocks. [F31]
- `bcmasp_tx_poll` (registered via `netif_napi_add_tx`) must reclaim all completed TX descriptors, call `napi_complete(&intf->tx_napi)`, re-enable TX IRQs, and return `0`, whereas `bcmasp_rx_poll` must process at most `budget` descriptors, call `napi_complete_done` and `bcmasp_enable_rx_irq` only when `processed < budget`, and return `processed`. [F129]

## Error Handling

- Hot-path error logging for TX ring exhaustion in `bcmasp_xmit` and RX frame CRC/symbol errors (`DESC_CRC_ERR | DESC_RX_SYM_ERR`) in `bcmasp_rx_poll` must be guarded by `net_ratelimit()`. [F134]

## External Contracts

- Lookup arrays `bcmasp_rmon_ranges` (returned via `*ranges` in `bcmasp_get_rmon_stats`), `bcmasp_of_match`, and `bcmasp_mdio_of_match` must terminate with a zeroed `{}` sentinel entry. [F72]

## Known Pitfalls

- In `bcmasp_xmit` and `bcmasp_csum_offload`, `skb_cow_head` and `skb_put_padto` can reallocate `skb->head`. `total_bytes` (`txcb->bytes_sent`) must be sampled from `skb->len` before `bcmasp_csum_offload` pushes `sizeof(struct bcmasp_pkt_offload)`, `ip_hdr`/`ipv6_hdr`/`tcp_hdrlen` and `skb_push` must run after `skb_cow_head`, and fragment 0's `size` and `skb->data` DMA mapping must be sampled from `skb_headlen(skb)` after `bcmasp_csum_offload` and refreshed to `skb->len` after `skb_put_padto`. [F44, F93]
- In `bcmasp_csum_offload`, the 12-bit L3 header length is split across `struct bcmasp_pkt_offload::header` (bits 3:0 via `PKT_OFFLOAD_HDR_SIZE_2((len >> 8) & 0xf)`) and `header2` (bits 31:24 via `PKT_OFFLOAD_HDR2_SIZE_2(len & 0xff)`); callers must shift and mask both halves. [F88]
- 6-byte MDA filter addresses/masks (`bcmasp_addr_to_uint` in `bcmasp_set_mda_filter`) and UniMAC SecureOn passwords (`bcmasp_suspend_to_wol`) pack bytes 0..1 into the high/MS 32-bit register and bytes 2..5 into the low/LS 32-bit register, whereas UniMAC station addresses in `umac_set_hw_addr` pack bytes 0..3 into `UMC_MAC0` and bytes 4..5 into `UMC_MAC1`. [F69]
- In `bcmasp_suspend()`, `ret` from the `bcmasp_interface_suspend()` loop is unconditionally overwritten by `ret = clk_prepare_enable(priv->clk)`; any change allowing `bcmasp_interface_suspend()` to return a non-zero error must return or preserve `ret` before calling `clk_prepare_enable()`. [F34]
