# EXT4 FILE SYSTEM

This unit implements the ext4 filesystem: superblock lifecycle, mount/remount, JBD2 journal integration, multi-block allocation (`mballoc`), HTree and casefolded directories, extent migration/defragmentation, Multi-Mount Protection (MMP), orphan tracking, buffered I/O with fscrypt/fs-verity, online resize, extended attributes, sysfs/procfs interfaces, tracepoints, and UAPI ioctls.

## Architecture & Data Flow

- In `mballoc.c`, per-order arrays (`s_mb_largest_free_orders`, `s_mb_avg_fragment_size`, `s_mb_offsets`, `s_mb_maxs`, `bb_counters`) and `ext4_group_info` slabs have `MB_NUM_ORDERS(sb)` (`s_blocksize_bits + 2`) elements, so orders must be clamped below `MB_NUM_ORDERS(sb)`. When `bb_fragments` drops to 0 in `mb_update_avg_fragment_size()`, set `new = -1` and still erase from `s_mb_avg_fragment_size[old]` (`old >= 0`). In `mb_set_largest_free_order()`, erase from `s_mb_largest_free_orders[old]` unconditionally even if `MB_OPTIMIZE_SCAN` is clear. [F72, F73, F100, F160]
- In `mb_free_blocks()`, update `bb_free`, `bb_first_free`, and `bb_fragments` only after `mb_test_and_clear_bits()` returns `-1`. When freeing clusters in `ext4_free_data_in_buddy()` or `ext4_mb_clear_bb()`, call `EXT4_MB_GRP_CLEAR_TRIMMED()` unconditionally. When `ext4_free_blocks()` adjusts `(block, count)` for partial clusters or `ext4_mb_clear_bb()` splits across a group boundary (`do_more:`), clear `EXT4_FREE_BLOCKS_VALIDATED` from `flags`. [F74, F75, F127]
- Check orphan status with `ext4_inode_orphan_tracked(inode)` rather than `list_empty(&ei->i_orphan)` alone because orphans may use `EXT4_STATE_ORPHAN_FILE`. When dropping or clearing `i_nlink` on a new inode in error paths before `ext4_orphan_add()` (`ext4_add_nondir()`, `ext4_symlink()`, `ext4_rename()`), call `ext4_mark_inode_dirty()` because `ext4_orphan_file_add()` only journals the orphan file block. [F83, F85]
- For in-inode xattrs, `e_value_offs` and `s.base` are relative to `IFIRST(header)`; for xattr blocks, they are relative to `BHDR(bh)`. `ext4_expand_extra_isize_ea()` must shift in-inode xattrs and adjust non-external `e_value_offs` via `ext4_xattr_shift_entries()`, then call `ext4_find_inline_data_nolock()`. `ext4_xattr_make_inode_space()` must never move `system.data` to an external block. In `ext4_xattr_inode_dec_ref_all()`, zero `e_value_inum` and `e_value_size` in the same transaction that decrements `ea_inode`'s refcount, re-running `ext4_xattr_restart_fn()` and `ext4_journal_get_write_access()` if `ext4_journal_ensure_credits_fn() > 0`. [F293, F303, F359, F404]

## Synchronization

- In `mballoc.c`, `ei->i_prealloc_lock` and `lg->lg_prealloc_lock` nest inside `ext4_lock_group(sb, group)` and must be dropped before `ext4_mb_load_buddy_gfp()` or `ext4_lock_group()`. Unlinking from or iterating `grp->bb_prealloc_list` requires `ext4_lock_group()`. Under `ext4_lock_group()`, `xa_insert()` into `s_mb_largest_free_orders` or `s_mb_avg_fragment_size` must use `GFP_ATOMIC` without `__GFP_NOFAIL`. `ext4_mb_group_or_file()` must cache `raw_cpu_ptr(sbi->s_locality_groups)` in `ac->ac_lg` and `ext4_mb_release_context()` must unlock `ac->ac_lg->lg_mutex`. [F42, F179, F181, F183]
- For `MB_GROUP_PA`, `ext4_mb_use_group_pa()` must not update `pa_pstart`, `pa_lstart`, `pa_free`, or `pa_len`; update them only in `ext4_mb_release_context()` under `pa->pa_lock` after `ext4_mb_mark_diskspace_used()`. When searching `ei->i_prealloc_node` (`ext4_mb_use_preallocated()`, `ext4_mb_pa_adjust_overlap()`), descend by immutable `pa_lstart` without checking `pa_deleted`, then walk `rb_prev()`/`rb_next()` past `pa_deleted != 0` entries; in `ext4_mb_use_preallocated()`, hold `tmp_pa->pa_lock` continuously across `pa_deleted == 0`, range checks, `atomic_inc(&pa_count)`, and `ext4_mb_use_inode_pa()`. [F40, F41, F123, F124]
- `sbi->s_group_info`, `sbi->s_group_desc`, `sbi->s_flex_groups`, and `sbi->s_qf_names[]` are RCU-protected: copy existing entries before `rcu_assign_pointer()` / `rcu_replace_pointer()`, free old arrays/strings via `ext4_kvfree_array_rcu()` or `kfree_rcu_mightsleep()`, and read under `rcu_read_lock()` (`sbi_array_rcu_deref()`). In `ext4_update_super()`, order new group descriptors and superblock counts with `smp_wmb()` before incrementing `sbi->s_groups_count` (paired with `smp_rmb()` in `ext4_get_groups_count()`). [F47, F243, F248, F375]
- In `ext4_end_bio()`, `ext4_put_io_end_defer()`, and `ext4_put_io_end()`, use `ext4_io_end_defer_completion(io_end)` consistently: if true, `ext4_end_bio()` must link `bio` into `io_end->bio` via `xchg(&io_end->bio, bio)` before `ext4_put_io_end_defer(io_end)`; otherwise call `ext4_put_io_end_defer(io_end)` before `ext4_finish_bio(bio)`. Serialize `ei->i_rsv_conversion_list` with `spin_lock_irqsave(&ei->i_completed_io_lock, flags)`, checking `list_empty()` and queueing `i_rsv_conversion_work` in the same critical section as `list_add_tail()`. [F30, F31, F94]
- Lock two inodes' `i_data_sem` (`ext4_double_down_write_data_sem()`) or folios (`mext_folio_double_lock()`) in ascending `struct inode *` address order. `ext4_ext_migrate()` and `ext4_ind_migrate()` must hold `ext4_writepages_down_write()` across the entire migration (outside `ext4_journal_start()`/`stop()`). `ext4_ext_migrate()` sets `EXT4_STATE_EXT_MIGRATE` under `i_data_sem` before scanning unlocked, and `ext4_ext_swap_inode_data()` must reverify it under `down_write(&i_data_sem)`. `__ext4_remount()` must hold `ext4_writepages_down_write()` both when calling `ext4_apply_options()` and in `restore_opts`. [F32, F34, F187, F242]
- Because `ext4_xattr_set_credits()` drops `xattr_sem` before starting the handle, `ext4_xattr_set_handle()` must re-read the xattr block and reverify `jbd2_handle_buffer_credits(handle) >= credits` after `ext4_write_lock_xattr()`. Before modifying (`h_refcount == 1`) or freeing an xattr block, delete its `ea_block_cache` entry via `mb_cache_entry_delete_or_get()` under `lock_buffer(bh)` (waiting via `mb_cache_entry_wait_unused()` or cloning if busy), and toggle `MBE_REUSABLE_B` when `h_refcount` crosses `EXT4_XATTR_REFCOUNT_MAX`. [F256, F298, F299]
- In `ext4_xattr_release_block()` when `h_refcount > 1`, call `ext4_handle_dirty_metadata()` before `unlock_buffer(bh)` if `ext4_handle_valid(handle)` is true, and after `unlock_buffer(bh)` if false. In `ext4_xattr_block_set()`, call `ext4_xattr_inode_lookup_create()` before `lock_buffer(bs->bh)`; `ext4_xattr_inode_iget()` must reject `parent->i_ino == ea_ino` and set EA lockdep subclasses via `ext4_xattr_inode_set_class()`. [F258, F259]
- `ext4_handle_error()` must set `EXT4_FLAGS_EMERGENCY_RO` (never `SB_RDONLY`), check `!system_going_down()` before panicking, and schedule `s_sb_upd_work` only when `continue_fs && journal && !ext4_test_mount_flag(sb, EXT4_MF_JOURNAL_DESTROY)` (paired with `ext4_journal_destroy()` setting `EXT4_MF_JOURNAL_DESTROY` before `ext4_force_commit()` and `flush_work(&sbi->s_sb_upd_work)`). [F240, F398]
- In `ext4_quota_operations`, start the JBD2 handle before calling `dquot_commit()`, `dquot_acquire()`, `dquot_release()`, or `dquot_commit_info()`; in `ext4_release_dquot()`, take `sb_start_intwrite()` only when `!ext4_journal_current_handle()` and still call `dquot_release()` if `ext4_journal_start()` fails. `ext4_truncate_failed_write()` must hold `filemap_invalidate_lock()` across `truncate_inode_pages()` and `ext4_truncate()`. [F228, F395, F400]

## Object Lifetimes

- `make_indexed_dir()` always consumes the caller's `bh` reference, so callers must set `bh = NULL`. In `dx_release()`, copy `info->indirect_levels` into a local variable before `brelse(frames[0].bh)` in the loop because `info` points into `frames[0].bh->b_data`. `ext4_mark_iloc_dirty()` unconditionally consumes `iloc.bh` from `ext4_reserve_inode_write()` (even on error), so callers with a shared `brelse(iloc.bh)` cleanup (`ext4_xattr_set_handle()`, `add_new_gdb()`) must set `iloc.bh = NULL`, and paths skipping `ext4_mark_iloc_dirty()` (`ext4_orphan_add()`, `ext4_orphan_del()`) must call `brelse(iloc.bh)`. [F2, F11, F133, F230]
- When `ext4_mb_free_metadata()` inserts into an empty `db->bb_free_root` (`!*n`), it pins `bd_buddy_folio` and `bd_bitmap_folio` with `folio_get()`, which `ext4_free_data_in_buddy()` drops with `folio_put()` when `rb_erase()` empties the tree. `ext4_mb_use_best_found()` must pin `bd_bitmap_folio` and `bd_buddy_folio` in `ac` until `ext4_mb_release_context()` (after `ext4_mb_mark_diskspace_used()`). [F20, F38]
- In `ext4_prealloc_space`, `u.pa_tmp_list` and `u.pa_rcu` share union `u`, and `pa_node`/`pa_node_lock` are discriminated by `pa_type`: `MB_GROUP_PA` is unlinked via `list_del_rcu()` under `lg_lock` and freed via `call_rcu(&pa->u.pa_rcu, ext4_mb_pa_callback)` after `list_del(&pa->u.pa_tmp_list)`, whereas `MB_INODE_PA` is freed synchronously via `ext4_mb_pa_free()`. In `ext4_mb_release()`, `flush_work(&sbi->s_discard_work)` before freeing `s_group_info` or `s_buddy_cache`; in `ext4_exit_mballoc()`, call `rcu_barrier()` before destroying `ext4_pspace_cachep`. [F24, F45, F170]
- In `ext4_xattr_inode_cache_find()` and `ext4_xattr_block_cache_find()`, `mb_cache_entry_find_next()` consumes `ce`, so call `mb_cache_entry_put()` only on early loop exit (including `ext4_sb_bread()` failure) when not returning `*pce = ce`; in `ext4_xattr_block_set()`, release and NULL `ce` and `new_bh` on retry or cleanup. In `ext4_resize_fs()`, release and NULL `resize_inode` and `flex_gd` before jumping to `retry:`. [F231, F236, F340]

## API Contracts

- On success, `ext4_add_nondir()` consumes `*inodep` via `d_instantiate_new()` and sets `*inodep = NULL`; on failure it drops `i_nlink`, orphans and unlocks the inode, and leaves `*inodep` non-NULL for the caller to `iput(*inodep)` after `ext4_journal_stop()`. `do_split()` may replace `*bh` with `bh2` and on any error calls `brelse(*bh)` and `brelse(bh2)` and sets `*bh = NULL`. [F1, F3]
- `ext4_mb_new_blocks()` and `ext4_mb_new_blocks_simple()` must assign `*errp` on every return path (including success) and set `ar->len = 0` on failure. `ext4_mb_mark_context()` sets `*ret_changed = changed` once in-memory bitmap/descriptor updates occur, so callers (`ext4_mb_mark_diskspace_used()`, `ext4_mb_clear_bb()`, `ext4_group_add_blocks()`) must skip in-core updates only when `err && changed == 0`. [F50, F55]
- In `ext4_free_extent` and `ext4_prealloc_space`, `fe_logical`/`pa_lstart` and `pa_pstart` are in blocks, whereas `fe_start`, `fe_len`, `pa_len`, and `pa_free` are in clusters (`EXT4_C2B()` / `EXT4_NUM_B2C()`). In `mballoc.c`, bit operations on buddy/block bitmaps must use `mb_*_bit()` and `mb_find_next_*_bit()` wrappers rather than `ext4_*_bit()` because `mb_find_buddy()` returns non-long-aligned pointers. [F56, F159]
- `ext4_sb_bread*()` always returns `ERR_PTR(-errno)` and never `NULL`. By contrast, `__ext4_read_dirblock()`, `ext4_bread()`, and `ext4_getblk()` return `ERR_PTR` on error and `NULL` on an unmapped hole (for `EITHER`/`DIRENT` at `block > 0` or symlinks), so callers must check both `IS_ERR(bh)` and `!bh`. [F57, F261, F262]
- Callers dropping an `ext4_io_end_t` from `ext4_end_bio()` or while holding a JBD2 `handle_t` must call `ext4_put_io_end_defer()`, never `ext4_put_io_end()`. `ext4_orphan_del()` and `ext4_orphan_file_del()` accept `handle == NULL` and must still unlink `i_orphan` and clear `EXT4_STATE_ORPHAN_FILE` in memory. [F69, F176]
- `__ext4_error*`, `save_error_info()`, `ext4_error_err()`, `EXT4_ERROR_INODE_ERR()`, and `ext4_abort()` take a positive `errno`, whereas `ext4_decode_error()` and `__ext4_std_error()` take a negative `-errno`. `ext4_journal_ensure_credits_fn()` and `ext4_resize_ensure_credits_batch()` return `< 0` on error, `0` if unchanged/extended, and `1` if restarted (requiring callers to re-call `ext4_journal_get_write_access()`). [F265, F273]

## Error Handling

- In `ext4_dx_add_entry()`, any error path jumping to `journal_error` while `bh2` is live must call `brelse(bh2)`. In `ext4_rename()`, if `ext4_whiteout_for_rename()` succeeded and rename later fails, `end_rename` must restore `old`'s dirent via `ext4_resetent()`, drop `whiteout` link count, mark it dirty, orphan and unlock it, stop `handle`, and `iput(whiteout)`. Callers of `ext4_new_inode_start_handle()` must fetch `ext4_journal_current_handle()` and stop it if non-NULL even when `IS_ERR(inode)`. [F4, F6, F61]
- In `ext4_mb_new_blocks()`: if `ac->ac_pa` was allocated by `ext4_mb_pa_alloc()` but not linked to `grp->bb_prealloc_list`, call `ext4_mb_pa_put_free(ac)`; on error, run `ext4_discard_allocated_blocks(ac)` before `errout` zeroes `ac_b_ex.fe_len = 0` (preventing `ext4_mb_release_context()` from consuming `MB_GROUP_PA`); and at `out:`, refund `inquota - ar->len` via `dquot_free_block()` and subtract `reserv_clstrs` from `s_dirtyclusters_counter` when `ar->len == 0` (if `!EXT4_MB_DELALLOC_RESERVED`). [F21, F22, F23]
- `ext4_get_group_info()` can return `NULL`, so callers (`ext4_mb_good_group()`, `ext4_mb_good_group_nolock()`, `ext4_mb_clear_bb()`) must check `if (!grp)` before dereferencing or calling `EXT4_MB_GRP_BBITMAP_CORRUPT(grp)`. `dx_probe()`, `ext4_dx_find_entry()`, and `ext4_dx_add_entry()` return `ERR_BAD_DX_DIR` on HTree corruption, which callers must intercept or translate to `-EFSCORRUPTED`. [F51, F58]
- Reset `buffer_head *` variables (`bs->bh`, `new_bh`, `dind`, `primary[res]`, `bh`) to `NULL` after extracting `PTR_ERR()` from `ext4_sb_bread*()` / `ext4_xattr_block_cache_find()`, and reset `ea_inode` / `old_ea_inode` to `NULL` after `ext4_xattr_inode_iget()` / `ext4_xattr_inode_lookup_create()` fails before jumping to shared `brelse()` / `iput()` cleanup labels. When stopping a journal handle on a cleanup path, do not overwrite an existing non-zero `err`. Where a metadata read failure would trigger `ext4_error*()`, use `ext4_sb_bread_nofail()` or filter `-ENOMEM`. [F263, F264, F274, F388]

## Known Pitfalls

- 64-bit arithmetic and casts: use `extent_logical_end()` / `pa_logical_end()` (`loff_t`) so logical ends at `0x100000000` do not wrap 32-bit `ext4_lblk_t`; cast `fe_logical` / `EXT4_C2B(sbi, fe_len)` to `loff_t` before `<< bsbits` in `ext4_mb_normalize_request()`; cast `orig_page_offset` to `loff_t` before `<< PAGE_SHIFT` in `move_extent_per_page()`; cast `group`/`n_group` to `ext4_fsblk_t` before multiplying by `EXT4_BLOCKS_PER_GROUP(sb)`; cast `inode_peek_iversion_raw()` to `u32` in `ext4_xattr_inode_get_ref()`; and use `do_div()` / `div64_u64()` / `div_u64()` instead of `/` or `%` on 64-bit values. [F141, F142, F143, F153, F349, F351, F356, F435]
- HTree and dirents: in `ext4_dx_add_entry()`, when splitting an upper index node or adding a root level (`add_level == 1`), release `bh`/`frames` and `goto again` to re-run `dx_probe()`; when splitting an immediate parent (`!add_level`) with `at - entries >= icount1`, rebase `frame->at` and `frame->entries` into `entries2` and swap `frame->bh = bh2` before `do_split()`. In `dx_move_dirents()` and `ext4_generic_delete_entry()`, zero from `&de->name_len` (preserving `de->rec_len`), and in `dx_pack_dirents()`, compute `ext4_next_entry()` before modifying `to->rec_len` or calling `memmove()`. In `ext4_rename()`, `ext4_rename_delete()` and `ext4_resetent()` must re-verify or re-lookup `old.de`. [F87, F88, F164, F165, F167]
- In `xattr.c`: `ext4_xattr_make_inode_space()` must restart from `IFIRST(header)` after each `ext4_xattr_move_to_block()`; when `ext4_xattr_block_set()` clones a shared block, it must rebase `s->first`, `s->here`, and `s->end` in a local `s_copy` and zero `s->here->e_value_inum` and `e_value_size`; on `-ENOSPC` fallback in `ext4_xattr_set_handle()` when `!is.s.not_found`, call `ext4_xattr_block_find()` if `i_file_acl && !bs.s.base`; and `e_name` must be copied and NUL-terminated before passing as `ext4_xattr_info.name`. [F294, F297, F334, F364]
