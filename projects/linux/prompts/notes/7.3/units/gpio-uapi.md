# GPIO UAPI

This component implements the Linux GPIO character device userspace ABI (both v2 and deprecated v1) in `drivers/gpio/gpiolib-cdev.c` and `include/uapi/linux/gpio.h`, along with utilities under `tools/gpio/`. It exposes `/dev/gpiochipN` devices and anonymous inode file descriptors (`gpio-line`, `gpio-linehandle`, `gpio-event`) to inspect chip/line metadata, watch line state changes, request and configure lines, read/write values, and monitor hardware or software-debounced edge events.

## Architecture & Data Flow

- In `linereq_set_config()`, `line->edflags` must only be updated to the new `edflags` after `edge_detector_stop()` or `edge_detector_update()` finishes, as both read the old `line->edflags` to detect changes and release `line->hdesc` when `GPIO_V2_LINE_FLAG_EVENT_CLOCK_HTE` was active; `edge_detector_stop()` must reset `line->irq`, `line->sw_debounced`, `line->edflags`, and `line->desc->debounce_period_us` to 0. [F46, F50]
- `line->level` and `line->raw_level` store physical (raw) pin levels from `gpiod_get_raw_value_cansleep()` or HTE; `process_hw_ts_thread()`, `debounce_work_func()`, and `debounced_value()` must invert the level when `ACTIVE_LOW` is set before computing `line_event_id()` or returning the logical line value. [F112]
- For software-debounced HTE lines, `process_hw_ts()` must increment `line->total_discard_seq` and save `line->last_seqno = ts->seq`, and `debounce_work_func()` must decrement `line->total_discard_seq` by 1 and set `line->line_seqno` to `line->last_seqno - line->total_discard_seq`. [F89]
- In `linereq_create()`, `linereq_set_config()`, `linehandle_create()`, `linehandle_set_config()`, and `debounce_setup()`, direction and debounce setup must use `gpiod_direction_output_nonotify()`, `gpiod_direction_input_nonotify()`, and `gpio_do_set_config()` (falling back to software debounce in `debounce_setup()` only on `-ENOTSUPP` when `debounce_period_us` is non-zero) so `gpiod_line_state_notify()` is emitted once. [F56, F110]
- When adding or modifying line configuration flags in `enum gpio_v2_line_flag` or `GPIOD_FLAG_*`, `GPIO_V2_LINE_VALID_FLAGS`, `gpio_v2_line_flags_validate()`, `gpio_v2_line_config_flags_to_desc_flags()`, and `gpio_desc_to_lineinfo()` (plus `gpio_v2_line_info_to_v1()` for v1-exposed flags) must be updated in lockstep. [F57]
- When `lr->events` is full, `linereq_put_event()` overwrites the oldest event via `kfifo_skip(&lr->events)` before `kfifo_in(&lr->events, le, 1)` under `lr->wait.lock`, whereas `lineevent_irq_thread()` and `lineinfo_changed_func()` drop the newest event when `kfifo_in_spinlocked*()` returns 0. [F72]
- In `linereq_create()`, `lr->num_lines` must be set to `ulr.num_lines` immediately after `kvzalloc()` and before indexing `lr->lines` (which is `__counted_by(num_lines)`), and `lr->event_buffer_size` must default to `ulr.num_lines * 16` when 0 and be capped at `GPIO_V2_LINES_MAX * 16` before `edge_detector_fifo_init()` calls `kfifo_alloc()`. [F70, F90]

## Synchronization

- Every `file_operations` `open`, `unlocked_ioctl`, `read`, and `poll` handler in `gpiolib-cdev.c` must hold a read lock on `gdev->srcu` and verify `rcu_access_pointer(gdev->chip)` is non-NULL before accessing `gpio_chip` (returning `-ENODEV`, or `EPOLLHUP | EPOLLERR` in `poll`, if NULL); paths that dereference `gdev->chip` (`lineinfo_changed_func()`, `gpiolib_cdev_register()`) must use `srcu_dereference(gdev->chip, &gdev->srcu)` rather than `rcu_dereference()`. [F109, F120]
- `lr->wait.lock` and `le->wait.lock` are acquired without disabling IRQs in `linereq_put_event()`, `linereq_read()`, `linereq_poll()`, `lineevent_irq_thread()`, and `lineevent_poll()`, so hardirq/HTE callbacks (`edge_irq_handler()`, `debounce_irq_handler()`, `lineevent_irq_handler()`, `process_hw_ts()`) must never lock `wait.lock` or push events directly. [F115]
- `lineinfo_changed_notify()` runs in atomic context under `read_lock_irqsave(&desc->gdev->line_state_lock)`, so it must allocate `struct lineinfo_changed_ctx` with `GFP_ATOMIC` and pass `atomic = true` to `gpio_desc_to_lineinfo()`, deferring sleeping `pinctrl_gpio_can_use_line()` calls to `lineinfo_changed_func()` on `gdev->line_state_wq`. [F113]
- `edge_detector_stop()` must not clear or modify `line->level` when stopping software debounce because `linereq_get_values()` reads `line->sw_debounced` and calls `debounced_value()` without holding `lr->config_mutex`. [F18]
- In `linereq_set_config()` and `linereq_set_values()`, `lr->config_mutex` must be held across descriptor flag updates, direction changes, edge detector reconfiguration, and output value writes. [F21]
- In `linereq_read()`, `lineevent_read()`, and `lineinfo_watch_read()`, `wait.lock` must be held continuously across `kfifo_is_empty()`, `wait_event_interruptible_locked()`, and `kfifo_out()`, and dropped before `copy_to_user()`; in `lineinfo_watch_read()`, `cdev->watch_abi_version` and `count < event_size` must only be checked after verifying `cdev->events` is non-empty. [F22, F23]
- `linehandle_flags_to_desc_flags()` and `gpio_v2_line_config_flags_to_desc_flags()` must stage updates to `desc->flags` in a local `unsigned long` initialized via `READ_ONCE(*flagsp)`, modify only config bits via `assign_bit()`/`set_bit()`/`clear_bit()` (preserving `GPIOD_FLAG_REQUESTED`, and changing `GPIOD_FLAG_IS_OUT` only if `GPIO_V2_LINE_FLAG_OUTPUT` or `GPIO_V2_LINE_FLAG_INPUT` is set), and publish with `WRITE_ONCE(*flagsp, flags)`, paired with `READ_ONCE(desc->flags)` in `gpio_desc_to_lineinfo()`. [F25, F53, F77]
- `edge_irq_thread()` and `lineevent_irq_thread()` must handle `line->timestamp_ns == 0` (and `le->timestamp == 0`) by capturing the timestamp and incrementing `lr->seqno` in the thread handler, and `edge_irq_thread()` must reset `line->timestamp_ns = 0` after consuming it. [F116]

## Object Lifetimes

- In `debounce_setup()`, `edge_detector_setup()`, and `lineevent_create()`, `request_irq()` / `request_threaded_irq()` must be passed a dedicated label from `make_irq_label()` (checking `IS_ERR(label)` since `NULL` is valid, and calling `free_irq_label(label)` on failure), and `line->irq` or `le->irq` must only be assigned after IRQ registration succeeds (`edge_detector_stop()` resets `line->irq = 0`). [F2, F3, F28]
- `edge_detector_stop()` must release the IRQ (`free_irq()`) and HTE descriptor (`hte_ts_put()`) before `cancel_delayed_work_sync(&line->work)`, and `linereq_free()` / `lineevent_free()` must stop edge detection / free the IRQ before calling `gpiod_free()`, `kfifo_free()`, `kfree(label)`, and `kvfree(lr)`. [F5, F91]
- In `edge_detector_setup()` and `edge_detector_update()`, when `edflags & GPIO_V2_LINE_EDGE_FLAGS` is non-zero, `edge_detector_fifo_init(line->req)` must allocate `lr->events` before `debounce_setup()`, `hte_edge_setup()`, or `request_threaded_irq()` enables event callbacks or `edflags` is published. [F19]
- `lineinfo_changed_notify()` must acquire references to both `desc->gdev` (`gpio_device_get()`) and `cdev->fp` (`get_file()`) before queueing `ctx->work` onto `gdev->line_state_wq`, and `lineinfo_changed_func()` must release them via `gpio_device_put(ctx->gdev)` and `fput(ctx->cdev->fp)` after finishing all accesses to `ctx->gdev` and `ctx->cdev`. [F7]
- When `watch` is true in `lineinfo_get()` or `lineinfo_get_v1()`, `lineinfo_ensure_abi_version()` must succeed (returning `0`; a positive return value indicates a version mismatch and must return `-EPERM`) before `test_and_set_bit()` marks the offset in `cdev->watched_lines`, and a subsequent `copy_to_user()` failure must roll back the bit with `clear_bit()`. [F8, F33]

## API Contracts

- In `linereq_set_config()`, any line whose resolved flags do not set `GPIO_V2_LINE_DIRECTION_FLAGS` must be skipped via `continue` before modifying `desc->flags`, stopping/updating the edge detector, or changing direction; similarly, `linehandle_set_config()` must verify `gcnf.flags & GPIOHANDLE_REQUEST_DIRECTION_FLAGS` before `linehandle_flags_to_desc_flags()` modifies `desc->flags` on any line. [F49, F76]
- In `linereq_set_config()`, when reconfiguring a line to `GPIO_V2_LINE_FLAG_OUTPUT`, `edge_detector_stop(line)` must be called before `gpiod_direction_output_nonotify(desc, val)`. [F104]
- When configuring edge triggers in `edge_detector_setup()`, `hte_edge_setup()`, and `lineevent_create()`, logical rising and falling edge flags must be inverted to falling and rising hardware triggers respectively whenever `GPIOD_FLAG_ACTIVE_LOW` is set in `desc->flags`. [F111]
- In `struct gpio_v2_line_values` and `struct gpio_v2_line_config_attribute`, bit `i` of `mask`, `bits`, and `attr.values` indexes `lr->lines[i]` (`0 <= i < lr->num_lines`) and in `linereq_get_values()` / `linereq_set_values()` must be tested/set with `BIT_ULL()` and translated to/from the `DECLARE_BITMAP(vals, GPIO_V2_LINES_MAX)` bitmap (never cast to `unsigned long *`), whereas `gpio_v2_line_event.offset` and `gpio_v2_line_info.offset` store `gpio_chip_hwgpio(desc)`. [F63, F93]
- In the `do-while` loops of `linereq_read()`, `lineevent_read()`, and `lineinfo_watch_read()`, when `kfifo_is_empty()` is true, `if (bytes_read) return bytes_read;` must be checked before returning `-EAGAIN` for `O_NONBLOCK` or sleeping in `wait_event_interruptible_locked()`. [F82]
- Event sequence numbers `line->line_seqno` and `lr->seqno` are 1-based: initialized to 0 and incremented before each emitted event, with `le.seqno` set equal to `le.line_seqno` without touching `lr->seqno` when `lr->num_lines == 1`. [F71]
- In `tools/gpio/gpio-utils.c`, `gpiotools_request_line()` returns a non-negative file descriptor on success (including `0`) or `-errno` on failure, so callers must check `ret < 0` rather than `if (ret)`. [F45]

## Error Handling

- Because `linereq_create()` sets `lr->num_lines` and `linehandle_create()` sets `lh->num_descs` before requesting all descriptors, `linereq_free()`, `edge_detector_stop()`, and `linehandle_free()` must check that each `desc` pointer is non-NULL before dereferencing it or passing it to `gpiod_free()`. [F30]
- `gpiod_get_raw_value_cansleep()` and `gpiod_get_value_cansleep()` return `0`, `1`, or a negative errno, so callers (`debounce_work_func`, `debounce_setup`, `lineevent_ioctl`) must store the return value in a signed `int` and check `< 0` before storing it into `line->level` (`unsigned int`) or `ghd.values[0]` (`__u8`). [F31]

## External Contracts

- Userspace hardware line offsets in `linereq_create()`, `linehandle_create()`, `lineevent_create()`, `lineinfo_get()`, `lineinfo_get_v1()`, and `lineinfo_unwatch()` must be validated against `cdev->gdev->ngpio` (via `gpio_device_get_desc()` or an explicit bounds check) before indexing `gdev->descs` or `cdev->watched_lines`. [F94, F127]
- `linereq_create()` and `linehandle_create()` must reject `num_lines` (or `lines`) `== 0` or `> GPIO_V2_LINES_MAX` (`GPIOHANDLES_MAX`) with `-EINVAL` before validating config, allocating `struct linereq`, or indexing `offsets`; `gpio_v2_line_config_validate()` must verify `lc->num_attrs <= GPIO_V2_LINE_NUM_ATTRS_MAX` before calling `gpio_v2_line_config_*()` helpers. [F59, F60]
- In `struct gpio_v2_line_attribute`, the union of `flags`, `values`, and `debounce_period_us` is discriminated by `id`; `gpio_v2_line_config_debounced()`, `gpio_v2_line_config_debounce_period()`, `gpio_v2_line_config_flags()`, and `gpio_v2_line_config_output_value()` must scan `lc->attrs` from `0` to `lc->num_attrs - 1`, verify both `attr.id` and `mask & BIT_ULL(line_idx)`, and return on the first match. [F37, F79]
- Stack-allocated UAPI output and event structs must be zeroed with `memset()` before field assignment and `copy_to_user()` / `kfifo` insertion; ABI v2 input structs with `padding` arrays (`lc->padding`, `ulr.padding`, `lineinfo.padding`) must be checked with `mem_is_zero()` and rejected with `-EINVAL` if non-zero. [F41, F125]
- All ABI v2 UAPI structs in `include/uapi/linux/gpio.h` must maintain 8-byte size alignment without implicit padding holes (using `__aligned_u64` and explicit `padding` arrays, with `GPIO_MAX_NAME_SIZE` a multiple of 8 and `GPIO_V2_LINES_MAX` at most 64 and a multiple of 2). [F58, F129]
- In `lineevent_read()`, when `compat_need_64bit_alignment_fixup()` is true, `ge_size` must be `sizeof(struct compat_gpioeevent_data)` (12 bytes) rather than `sizeof(struct gpioevent_data)` (16 bytes); under `CONFIG_GPIO_CDEV_V1`, `lineinfo_watch_read()` must size and copy `struct gpioline_info_changed` converted via `gpio_v2_line_info_changed_to_v1()` whenever `cdev->watch_abi_version != 2`. [F66, F98]
- `linereq_create()`, `linehandle_create()`, and `lineevent_create()` must acquire lines via `gpiod_request_user()` rather than `gpiod_request()` so internal `-EPROBE_DEFER` errors are mapped to `-ENODEV`; in `gpio_v2_line_flags_validate()`, requesting `GPIO_V2_LINE_FLAG_EVENT_CLOCK_HTE` when `!CONFIG_HTE` must return `-EOPNOTSUPP` rather than `-EINVAL`. [F124, F137]

## Known Pitfalls

- In `lineevent_irq_thread()`, the dual-edge condition `(le->eflags & GPIOEVENT_REQUEST_RISING_EDGE && le->eflags & GPIOEVENT_REQUEST_FALLING_EDGE)` must precede the single-edge `else if` branches so dual-edge requests sample `gpiod_get_value_cansleep(le->desc)`; in `debounce_work_func()`, unmonitored edges must be filtered by comparing `eflags` (`edflags & GPIO_V2_LINE_EDGE_FLAGS`) with `==` rather than `&`. [F73, F75]
- All bit shifts indexing 64-bit ABI v2 line masks (`lv.mask`, `lv.bits`, `lc->attrs[i].mask`, `lc->attrs[i].attr.values`) in `gpiolib-cdev.c` and `tools/gpio/gpio-utils.h` must use 64-bit `BIT_ULL()` or `_BITULL()` rather than `BIT()` or `1UL << n`, and `gpio_v2_line_config_output_value()` and `gpiotools_test_bit()` must normalize the 64-bit bitwise AND result with `!!` before returning `int`. [F87, F88]
- In `gpio_ioctl()` and `linereq_ioctl()`, large command-specific UAPI structs (`gpiochip_info`, `gpioline_info`, `gpio_v2_line_info`, `gpio_v2_line_request`, `gpio_v2_line_config`) must be allocated on the stack of per-command helper functions rather than declared together in the top-level ioctl dispatcher. [F130]
