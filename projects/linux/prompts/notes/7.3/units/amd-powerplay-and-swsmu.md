# AMD POWERPLAY AND SWSMU

This unit provides the Dynamic Power Management (DPM) dispatch layer, user-space telemetry/control interfaces (sysfs, hwmon, debugfs), legacy Kaveri/Kabini SMU7 DPM support, common SWSMU helpers (`smu_cmn.c`), and the SMU v14.0 backend (`smu_v14_0*.c`).

## Architecture & Data Flow
- On APU SMU v14.0.0, `smu->clock_map`, `pwr_src_map`, `workload_map`, and `smu_dpm.dpm_context` are NULL; `smu_v14_0_0_ppt_funcs` cannot use `smu_v14_0.c` helpers that dereference `dpm_context` (`smu_v14_0_set_performance_level`) or require `CMN2ASIC_MAPPING_CLK` (`smu_v14_0_set_soft_freq_limited_range`, `smu_v14_0_get_dpm_ultimate_freq`). [F33]
- In `smu_v14_0_0_ppt.c`, `smu_table.clocks_table` holds `DpmClocks_t_v14_0_1` on `IP_VERSION(14, 0, 1)` and `DpmClocks_t` otherwise (allocate with `max(sizeof(...))` and branch on IP version before casting). In both structs, `MemPstateTable` is ordered highest frequency at index `0` to lowest at `NumMemPstatesEnabled - 1`; `SMU_MCLK`/`SMU_UCLK` queries must use `0` for max, `NumMemPstatesEnabled - 1` for min, and `count - i - 1` when printing ascending levels. [F66, F67]
- In SMU v14.0.2 OverDrive (`smu_v14_0_2_od_edit_dpm_table`, `smu_v14_0_2_restore_user_od_settings`, `smu_v14_0_2_set_default_od_settings`), `OverDriveTable.FeatureCtrlMask` must be saved across `PP_OD_RESTORE_DEFAULT_TABLE` copies from `boot_overdrive_table` (which falls through to `PP_OD_COMMIT_DPM_TABLE`, unlike `smu_v14_0_od_edit_dpm_table`), skipped via `(u8 *)` + `offset_of_voltageoffset` when updating `user_overdrive_table`, and zeroed after upload; on suspend with `user_od` set, `user_od_table` is refreshed from `boot_od_table` and restored from `user_od_table_bak`. [F53, F54, F77, F98]
- In `smu_v14_0_2_ppt.c` OverDrive fan control, user-visible fan curve points are restricted to indices `0..NUM_OD_FAN_MAX_POINTS - 2` (5 points, though `OverDriveTable_t` arrays have 6); editing `PP_OD_EDIT_FAN_CURVE` must set `FanMode = FAN_MODE_MANUAL_LINEAR` and `BIT(PP_OD_FEATURE_FAN_CURVE_BIT)` in `FeatureCtrlMask`, while acoustic/target/min-PWM edits and fan restores must set `FanMode = FAN_MODE_AUTO`. [F55, F70]
- In `smu_v14_0_set_irq_state()`, `smu_v14_0_check_fw_status()`, and `smu_v14_0_load_microcode()`, MP1 register offsets differ between APU and dGPU and must branch on `smu->is_apu`. In `smu_v14_0_irq_process()`, `SMU_IH_INTERRUPT_ID_TO_DRIVER` must set `MP1_SMN_IH_SW_INT_CTRL__INT_ACK = 1`, and updating `DIG_THERM_INTH` in `regTHM_THERMAL_INT_CTRL` must clear `THM_THERMAL_INT_CTRL__THERM_TRIGGER_MASK_MASK`. [F113, F115]
- In `smu_v14_0_baco_set_armd3_sequence()` and `smu_v14_0_baco_set_state()`, update `smu->smu_baco.state` only after `SMU_MSG_ArmD3`, `SMU_MSG_EnterBaco`, or `SMU_MSG_ExitBaco` succeeds, and clear VBIOS scratch registers `adev->bios_scratch_reg_offset + 6` and `+ 7` on `SMU_MSG_ExitBaco`. In `smu_v14_0_2_baco_enter()`/`exit()`, use `smu_v14_0_baco_set_armd3_sequence()` when `adev->in_runpm && smu_cmn_is_audio_func_enabled(adev)`. [F49, F117]
- In `smu_v14_0_0_system_features_control()`, send `SMU_MSG_PrepareMp1ForUnload` only when `!en && !adev->in_s0ix`. In `smu_v14_0_set_{vcn,jpeg}_enable()`, skip harvested instances (`harvest_config & (1 << i)`), and send `SMU_MSG_Power{Up,Down}Jpeg1` on APUs only on `IP_VERSION(14, 0, 1)`. In `smu_v14_0_{enable,disable}_thermal_alert()`, skip `amdgpu_irq_get()`/`put()` when `smu->irq_source.num_types == 0`. [F116, F119, F120]
- In `smu_v14_0_2_i2c_xfer()`, the request loop must clear `CMDCONFIG_RESTART_MASK` when setting `CMDCONFIG_STOP_MASK` on the final byte of the last or any `I2C_M_STOP` message, and the response loop must advance `c += msg[i].len` before `continue` on write messages (`!(msg[i].flags & I2C_M_RD)`). [F75, F76]
- Before casting `adev->powerplay.pp_handle` in `amdgpu_dpm.c`, verify `is_support_sw_smu(adev)` for `struct smu_context *`, and verify both `!is_support_sw_smu(adev)` and `!amdgpu_dpm_is_legacy_dpm(adev)` for `struct pp_hwmgr *`. [F256]
- In `amdgpu_dpm_change_power_state_locked()`, sync `adev->pm.dpm.state = adev->pm.dpm.user_state` only when both `thermal_active` and `uvd_active` are false; when `thermal_active` is true, save and restore `adev->pm.dpm.forced_level` around `pp_funcs->force_performance_level(adev, AMD_DPM_FORCED_LEVEL_LOW)`. [F154, F188]
- In `amdgpu_set_pp_od_clk_voltage()` and `amdgpu_distribute_custom_od_settings()`, `PP_OD_COMMIT_DPM_TABLE` via `amdgpu_dpm_odn_edit_dpm_table()` must be followed by `amdgpu_dpm_dispatch_task(adev, AMD_PP_TASK_READJUST_POWER_STATE, NULL)`. In `amdgpu_dpm_set_{sclk,mclk}_od()`, if that task returns `-EOPNOTSUPP`, reset `adev->pm.dpm.current_ps = adev->pm.dpm.boot_ps` before `amdgpu_dpm_compute_clocks(adev)`. [F189, F194]
- In `amdgpu_parse_extended_power_table()`, verify `le16_to_cpu(power_info->pplib.usTableSize) >= sizeof(struct _ATOM_PPLIB_POWERPLAYTABLE3/4/5)` and non-zero offsets before accessing `pplib3`/`4`/`5` sub-tables, clamp `num_of_vce_states` to `AMD_MAX_VCE_LEVELS`, and check `platform_caps & ATOM_PP_PLATFORM_CAP_EVV` before selecting the `vddc1`/`2`/`3` vs `vddc`/`leakage` union in `amdgpu_cac_leakage_table`. [F180, F205, F207]
- In `kv_dpm.c`: `kv_dpm_enable()` must run `kv_process_firmware_header()` before uploading DPM tables and `kv_set_thermal_temperature_range()` before `amdgpu_irq_get()`; `kv_update_{current,requested}_ps()` must copy both `*rps` and `*kv_get_ps(rps)` and rebind `ps_priv` and `adev->pm.dpm.{current,requested}_ps`; `kv_dpm_suspend()` must reset `current_ps` and `requested_ps` to `boot_ps`; `vddc_dependency_on_sclk` is optional (`count == 0` falls back to `pi->sys_info` tables); and `kv_enable_didt()` must bracket register writes with `amdgpu_gfx_rlc_{enter,exit}_safe_mode(adev, 0)`. [F182, F196, F197, F243, F248, F249]

## Synchronization
- Lock ordering and `adev->pm.mutex`: `adev->pm.stable_pstate_ctx_lock` -> `adev->pm.mutex` -> `smu->message_lock`. `amdgpu_set_power_dpm_force_performance_level()` holds `stable_pstate_ctx_lock` across `amdgpu_dpm_force_performance_level()` and clears `stable_pstate_ctx = NULL` on success; `smu_v14_0_2_i2c_xfer()` holds `adev->pm.mutex` around `smu_cmn_update_table()`; `amdgpu_dpm_compute_clocks()` drains fences (`amdgpu_fence_wait_empty`) before acquiring `adev->pm.mutex`, whereas `amdgpu_legacy_dpm_compute_clocks()` and `amdgpu_dpm_change_power_state_locked()` require `adev->pm.mutex` held; and `amdgpu_show_powershift_percent()` must release `mgpu_info.mutex` before calling `amdgpu_pm_get_sensor_generic()`. [F19, F153, F164, F253, F266]
- Interrupt/atomic handlers (`smu_v14_0_irq_process()`, `kv_dpm_process_interrupt()`, `kv_dpm_set_interrupt_state()`) must never sleep, acquire `adev->pm.mutex`, or send SMU mailbox messages; defer work to `smu->swctf_delayed_work` or `adev->pm.dpm.thermal.work` (which must be initialized before `kv_dpm_hw_init()` and drained via `cancel_work_sync()`/`flush_work()` outside `adev->pm.mutex` before `kv_dpm_fini()`). [F20, F161, F162, F264, F272]

## Object Lifetimes
- In `smu_v14_0_setup_pptable()`, `smu_v14_0_2_setup_pptable()`, and `smu_v14_0_2_check_powerplay_table()`, `smu_table->power_play_table` and `smu->od_settings` (`&powerplay_table->overdrive_table`) are borrowed pointers and must never be `kfree()`d in `smu_v14_0_fini_smc_tables()` or teardown. [F4, F5]
- `smu_v14_0_2_init_smc_tables()` must call `smu_v14_0_2_tables_init()` before `smu_v14_0_init_smc_tables()`, and `smu_table->gpu_metrics_table` must be sized to at least the `struct gpu_metrics_v*` passed to `smu_cmn_init_soft_gpu_metrics()`. Reset `smu_table->metrics_time = 0` when `metrics_table` is allocated or freed, update it only after `smu_cmn_update_table()` succeeds, and check expiry with `!smu_table->metrics_time || time_after(jiffies, smu_table->metrics_time + msecs_to_jiffies(1))`. [F34, F44, F91, F97]
- In `smu_v14_0_2_i2c_control_init()`, initialize `smu_i2c` fields, `control->algo`, `control->quirks`, and `i2c_set_adapdata(control, smu_i2c)` before `devm_i2c_add_adapter(adev->dev, control)`; `smu_v14_0_2_i2c_control_fini()` must only null `ras_eeprom_i2c_bus` and `fru_eeprom_i2c_bus` without calling `i2c_del_adapter()`. [F10, F21]
- `smu_cmn_is_audio_func_enabled()` must call `pci_dev_put(p)` when `pci_get_domain_bus_and_slot()` returns non-NULL. `smu_v14_0_init_microcode()` must call `amdgpu_ucode_release(&adev->pm.fw)` on error; when `load_type == AMDGPU_FW_LOAD_PSP`, `ucode[AMDGPU_UCODE_ID_SMC].fw` borrows `adev->pm.fw` and both `SMC` and `PPTABLE` entries must add `ALIGN(..., PAGE_SIZE)` to `adev->firmware.fw_size`. [F2, F14, F45]
- Each `struct od_kobj` on `adev->pm.od_kobj_list` is freed by `od_kobj_release()` via `kobject_put(&container->kobj)`; `amdgpu_od_set_fini()` must remove and `kfree()` every `struct od_attribute` before `kobject_put()` and never `kfree(container)` directly. Every `dyn_state` table allocated in `amdgpu_parse_extended_power_table()` must be freed in `amdgpu_free_extended_power_table()`. [F147, F149]

## API Contracts
- `smu_v14_0_{0,2}_get_gpu_metrics()` return `ssize_t`: they must call `smu_cmn_init_soft_gpu_metrics()` on the typed `gpu_metrics_v*` buffer before populating fields, return negative `errno` without modifying `*table` on `smu_cmn_get_metrics_table()` failure, and assign `*table = smu_table->gpu_metrics_table` and return positive byte size on success. In `smu_v14_0_2_ppt.c`, `SMU_TABLE_SMU_METRICS` and `SMU_TABLE_ACTIVITY_MONITOR_COEFF` require passing `SmuMetricsExternal_t` and `DpmActivityMonitorCoeffIntExternal_t` to `smu_cmn_get_metrics_table()`/`smu_cmn_update_table()`. [F27, F28, F32]
- Parameter encoding mismatches: `smu_cmn_feature_is_supported()`, `is_enabled()`, `set_enabled()`, and `disable_all_features_with_exception()` take an `enum smu_feature_mask` bit index, whereas `smu_cmn_feature_update_enable_state()` and `smu_cmn_set_pp_feature_mask()` take a 64-bit mask (`1ULL << feature_id`); in `smu_v14_0_2_ppt.c`, `smu_v14_0_2_is_od_feature_supported()` takes a `PP_OD_FEATURE_*_BIT` bit index, whereas `smu_v14_0_2_get_od_setting_limits()` takes a `PP_OD_FEATURE_*` enum selector (`0..11`). [F36, F40]
- Unit conversions: `smu_table.boot_values` clocks and `AMDGPU_PP_SENSOR_GFX_{MCLK,SCLK}` are in 10 kHz (divide by `100` for MHz in DPM tables/`get_dpm_ultimate_freq`/debugfs, multiply `SmuMetrics_t` MHz by `100` in `read_sensor`, multiply by `10000` for Hz in hwmon); `AMDGPU_PP_SENSOR_GPU_{AVG,INPUT}_POWER` use 8-bit fixed-point watts (`(query >> 8) * 1000000 + (query & 0xff) * 1000` uW); hwmon power caps convert uW<->Watts (`1000000`) and pack `limit_type << 24` into `amdgpu_dpm_set_power_limit()`; `smu->thermal_range` uses millidegrees C except `software_shutdown_temp*` in whole degrees C. [F38, F39, F280, F281]
- `smu_cmn_to_asic_specific_index()` returns `-ENOTSUPP` for unmapped `CMN2ASIC_MAPPING_WORKLOAD` entries (unlike `-EINVAL` for others), which `smu_v14_0_2_get_power_profile_mode()` relies on to `continue` past unsupported profiles. `amdgpu_dpm_get_uclk_dpm_states()` is declared as `enum pp_smu_status` but returns `0` or negative `errno` (store in `int` before translating). [F78, F168]
- Pass GPU `mc_address` (not `cpu_addr`) to SMU shared-table messages (`smu_v14_0_set_{driver,tool}_table_location`, `notify_memory_pool_location`). Every `amdgpu_dpm_enable_*` helper calling `amdgpu_dpm_set_powergating_by_smu()` (and `kv_update_{uvd,samu,acp}_dpm` calling `kv_enable_*_dpm`) must invert the boolean (`!enable`/`!gate`), and `amdgpu_dpm_is_baco_supported()` must return `0` when `adev->in_s3` is true. [F128, F220, F257]
- `kv_dpm_read_sensor()` requires `*size >= 4` on entry, so `amdgpu_dpm_read_sensor()` callers must initialize `*size` to the buffer capacity (`>= 4`). Sysfs callers of `amdgpu_dpm_get_temp_metrics()` must first pass `table = NULL` to get `size` and verify `size > 0 && size < PAGE_SIZE` before passing `buf`. When an `.attr_update` callback downgrades an `amdgpu_device_attr` to read-only, it must both clear write bits in `dev_attr->attr.mode` and set `dev_attr->store = NULL`. [F237, F238, F284]

## Error Handling
- In `amdgpu_dpm_force_performance_level()`, `amdgpu_dpm_enter_umd_state()` and `amdgpu_dpm_exit_umd_state()` must be called outside `adev->pm.mutex`; if `pp_funcs->force_performance_level()` fails, unlock `adev->pm.mutex` and call the inverse UMD state helper to roll back. [F152]

## External Contracts
- `smu_v14_0_get_dpm_freq_by_index()` must mask the `SMU_MSG_GetDpmFreqByIndex` response with `0x7fffffff` because PMFW uses bit 31 (`0x80000000`) for fine-grained DPM status. [F69]
- Kaveri SMU7 SRAM (`SMU7_Fusion_DpmTable`) is big-endian: convert multi-byte fields with `cpu_to_be16`/`cpu_to_be32` before `amdgpu_kv_copy_bytes_to_smc()` (which performs 4-byte-aligned big-endian read-modify-write for unaligned start/tail bytes) and `be32_to_cpu` when read; `amdgpu_kv_read_smc_sram_dword()` requires 4-byte alignment. In `amdgpu_kv_send_msg_to_smc_with_parameter()` and `amdgpu_kv_notify_message_to_smu()`, write `mmSMC_MSG_ARG_0` before `mmSMC_MESSAGE_0` and poll `mmSMC_RESP_0` bounded by `adev->usec_timeout`. [F181, F198, F261, F273]
- User-space validation in `amdgpu_pm.c`: `amdgpu_read_mask()` must reject `level > 31` before `1 << level`; `amdgpu_set_pp_force_state()` must clamp `idx < ARRAY_SIZE(data.states)` with `array_index_nospec` and skip `POWER_STATE_TYPE_INTERNAL_BOOT` and `DEFAULT`; `amdgpu_hwmon_set_{pwm1,fan1_target}()` must verify `pwm_mode == AMD_FAN_CTRL_MANUAL`; and multi-char prefixes in `amdgpu_set_pp_od_clk_voltage()` (`"vc"`, `"vo"`) must precede matching single-char `*buf ==` branches and advance `tmp_str` past all prefix chars. [F214, F219, F278, F282]

## Known Pitfalls
- Callback pointer recovery: in `smu_v14_0_2_ppt.c`, I2C callbacks receiving `struct amdgpu_smu_i2c_bus *` from `i2c_get_adapdata()` must use `smu_i2c->adev` (never `to_amdgpu_device(smu_i2c)`); in `amdgpu_pm.c`, sysfs callbacks on `adev->dev` must pass `dev_get_drvdata(dev)` through `drm_to_adev()`, `hwmon_attributes` callbacks on `adev->pm.int_hwmon_dev` cast `dev_get_drvdata(dev)` directly to `struct amdgpu_device *`, and `od_feature_ops` callbacks on `struct od_kobj` must use `container_of(kobj, struct od_kobj, kobj)->priv` (never `kobj_to_dev(kobj)`). [F103, F245, F246]
- Bounds, bitmask, and division guards: `pcie_gen_to_speed()` indexes a 6-element array with `gen - 1` without upper-bound checks, so callers must bound-check `metrics->PcieRate` (and use `DECODE_GEN_SPEED`/`DECODE_LANE_WIDTH` when comparing `smu_14_0_pcie_table` against `SmuMetrics_t`); `smu_v14_0_{0,2}_force_clk_levels()` must check `mask != 0` before `ffs(mask) - 1` / `fls(mask) - 1`; `smu_v14_0_0_get_smu_metrics_data()` must check `StapmOpnLimit > 0` and `StapmCurrentLimit > StapmOpnLimit` before dividing; and in `smu_v14_0_0_set_watermarks_table()`, `WM_DCFCLK` and `WM_SOCCLK` swap `drain_clk` and `fill_clk`. [F63, F64, F82, F87, F92]
- Kaveri (`kv_dpm.c`) and VBIOS pitfalls: `kv_patch_voltage_values()` mutates `uvd`/`vce`/`samu`/`acp` dependency table `.v` fields in place from 8-bit VID indices to mV during `kv_dpm_init()` while leaving `vddc_dependency_on_sclk` as raw 8-bit VID indices (inversely proportional to voltage: `6200 - (v * 25)`, requiring `kv_convert_8bit_index_to_voltage()` before comparing against `pi->high_voltage_t`); reverse DPM level loops with unsigned `u32` counters must stop at `i > 0` (`i >= 0` requires signed `int`); and VCE/UVD/SAMU/ACP VBIOS tables start with a 1-byte `revid` (`+ 1`) followed by variable-length sub-tables. [F191, F210, F235, F242]
