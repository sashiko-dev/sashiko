# FREESCALE ENETC ETHERNET DRIVERS

This unit implements the NXP ENETC and NETC (v4.1+) PCIe Integrated Endpoint Ethernet drivers, covering Physical Functions (PF v1 and v4), Virtual Functions (VF), MDIO controllers, IERB/NETC block control, and the NTMP library. It supports DMA buffer descriptor rings with NAPI, XDP, PTP hardware timestamping, RSS/RFS, SR-IOV VF-PF mailbox messaging, and TSN/QoS offloads (802.1Qbv taprio, 802.1Qav CBS, 802.1Qci PSFP, 802.1Qbu frame preemption, and ETF txtime).

## Architecture & Data Flow
- `enetc_vf_probe()` passes `sizeof_priv == 0` to `enetc_pci_probe()`, leaves `si->hw.port` and `si->hw.global` unmapped, and leaves `priv->phylink` as `NULL`. Shared code reachable from VFs must check `enetc_si_is_pf(si)` (`!!si->hw.port`) before calling `enetc_si_priv(si)` or accessing port/global registers, and must check `priv->phylink` before calling `phylink_*()` helpers. [F36, F37]
- In PF port registers (`ENETC_PSIPMAR0(n)`, `ENETC_PSICFGR0(n)`, `ENETC_PSIVLANR(n)`, `ENETC4_PSICFGR0(a)`), SI index 0 is the PF and VFs use 1-based indices (`vf + 1`), whereas `pf->vf_state`, `pf->rxmsg`, `ENETC_PSIVMSGRCVAR0(n)`, and `ENETC_PSIMSGRR_MR(n)` use 0-based VF indices (`0 .. pf->num_vfs - 1`). [F82]
- In `struct enetc_int_vector`, `v->tx_ring[j]` (`0 <= j < v->count_tx_rings`) is densely indexed, but each ring's hardware BDR index `v->tx_ring[j].index` is interleaved (`priv->bdr_int_num * j + i`) and tracked in `v->tx_rings_map`; register offsets from `v->tbier_base` and `ENETC_SIMSITRV()` must use the hardware ring index, not `j`. [F85]
- A TX extension BD (`ENETC_TXBD_FLAGS_EX`) consumes a separate ring slot and increments the BD count, so TX space checks must reserve room for both the extension BD and the 1-BD full gap via `ENETC_TXBDS_NEEDED()` or `enetc_lso_count_descs()`. When `rx_ring->ext_en` is true (toggled via `enetc_reconfigure()` in `enetc_hwtstamp_set()`), `enetc_alloc_rx_resource()` doubles `res->bd_size` while keeping `rx_ring->bd_count` and `rx_swbd` at the logical count, so RX BDs must be indexed via `enetc_rxbd()`, `enetc_rxbd_next()`, and `enetc_rxbd_ext()`. [F66, F78, F125]
- In `enetc_map_tx_buffs()` and `enetc_lso_map_data()`, each TX BD is staged in `temp_bd`/`txbd_tmp` and committed to `*txbd` only when advancing or after the loop finishes, so `ENETC_TXBD_FLAGS_F`, `is_eof`, and `skb` are set on the final BD before committing. In `enetc_map_tx_tso_hdr()` and `enetc_lso_map_hdr()`, `tx_swbd->dma` must remain `0` even though `txbd_tmp.addr` points into `tx_ring->tso_headers_dma`, so `enetc_unmap_tx_buff()` does not unmap coherent memory. [F97, F168]
- `enetc_unmap_tx_buff()` requires `tx_swbd->is_dma_page` and `tx_swbd->is_xdp_tx` to match the mapping: both `0` for `dma_map_single()`, `is_dma_page = 1` for `skb_frag_dma_map()`, and both set for `XDP_TX` pages (unmapped with `PAGE_SIZE`). Because `skb` and `xdp_frame` share a union in `struct enetc_tx_swbd`, cleanup paths must use `enetc_tx_swbd_get_skb()` / `enetc_tx_swbd_get_xdp_frame()` and read `tx_swbd->page` only when `is_xdp_tx` is set. [F38, F169]
- In `enetc_clean_tx_ring()`, `do_twostep_tstamp` and `tstamp` are captured on the frame's first BD (`tx_swbd->check_wb`) and consumed on the last BD (`tx_swbd->skb`), after which `do_twostep_tstamp` must be reset to `false`; every completed `tx_swbd` must be zeroed with `memset(tx_swbd, 0, sizeof(*tx_swbd))` because TX mapping functions do not clear all `tx_swbd` fields on slot reuse. [F5, F99]
- In `union enetc_tx_bd`, the final 32-bit word overlays `l3_aux0`/`l3_aux1`/`l4_aux`/`flags` with `__le32 txstart`, so TX checksum offload cannot be used when `tx_ring->tsd_enable` is active, and `enetc_txbd_set_tx_start()` must pack `flags` at `ENETC_TXBD_FLAGS_OFFSET` (bits 24..31). [F91]
- `priv->xdp_tx_ring` points at `&priv->tx_ring[priv->num_tx_rings - num_possible_cpus()]`, and `enetc_rx_ring_from_xdp_tx_ring()` recovers the RX ring index via pointer subtraction, requiring `XDP_TX` on `rx_ring` to use `priv->xdp_tx_ring[rx_ring->index]`. `enetc_setup_xdp_prog()` must return `-EBUSY` if `priv->min_num_stack_tx_queues + num_xdp_tx_queues > priv->num_tx_rings`, and `enetc_reconfigure_xdp_cb()` must update `netif_set_real_num_tx_queues()` (reverting `priv->xdp_prog` on error) and each RX ring's `xdp.prog` and `buffer_offset` in lockstep. [F57, F86, F186]
- In `enetc_check_bd_errors_and_consume()`, `enetc_build_skb()`, and `enetc_build_xdp_buff()`, after advancing past the first RX BD, `while (!(bd_status & ENETC_RXBD_LSTATUS_F))` must consume all remaining BDs of the frame. RX byte stats in `enetc_clean_rx_ring()` must add `skb->len + ETH_HLEN`, and both RX clean paths must add `VLAN_HLEN` when `bd_status & ENETC_RXBD_FLAG_VLAN` is set. [F100, F178]
- Port MAC writes that apply to both express and preemptible MACs must use `enetc_port_mac_wr()` rather than `enetc_port_wr()` so `reg + si->drvdata->pmac_offset` is updated when `ENETC_SI_F_QBU` is set. `enetc_mm_commit_preemptible_tcs()` must only program `priv->preemptible_tcs` into `ENETC_PTCFPR(0..7)` when `ENETC_MMCSR_ME` is enabled and either `ENETC_MMCSR_VDIS` is set or `enetc_mm_wait_tx_active()` confirms `VSTS == 3` (programming `0` otherwise). [F68, F69]
- Programming TX ring priority via `enetc_set_bdr_prio()` in `enetc_setup_tc_mqprio()` or `enetc_reset_tc_mqprio()` must also update `tx_ring->prio` so `enetc_setup_txbdr()` restores it across reconfigurations. `enetc_taprio_destroy()` must disable `ENETC_PTGCR_TGE`, reset `ENETC_PTCMSDUR`, clear `ENETC_F_QBV`, call `enetc_reset_tc_mqprio()`, and zero `stats.win_drop` via `enetc_reset_taprio_stats()`. [F60, F61]
- In `enetc_vlan_rx_del_vid()`, `enetc_refresh_vlan_ht_filter()` must rebuild `pf->vlan_ht_filter` from `pf->active_vlans`. In `struct enetc_mac_filter`, `mac_addr` and `mac_hash_table` share a union and cannot be used together. On `ENETC_REV1`, `ENETC_PSIUMHFR0`/`ENETC_PSIMMHFR0` must be indexed with `si->errata & ENETC_ERR_UCMCSWP` and `enetc_pf_set_vf_vlan()` must return `-EOPNOTSUPP`. In `struct enetc_pf_ops`, `create_pcs`, `destroy_pcs`, and `enable_psfp` are `NULL` in `enetc4_pf_ops` and must be checked before calling. [F39, F70, F129, F144]

## Synchronization
- Fast-path MMIO accessors (`enetc_rd_reg_hot()`, `enetc_wr_reg_hot()`, `enetc_rd_hot()`, `enetc_wr_hot()`) assert `lockdep_assert_held(&enetc_mdio_lock)` when `enetc_has_err050089` is enabled and must be bracketed by `enetc_lock_mdio()` and `enetc_unlock_mdio()`. Because `enetc_lock_mdio()` takes `read_lock(&enetc_mdio_lock)` in hardirq (`enetc_msix`) and softirq (`enetc_poll`) without disabling IRQs, code inside `enetc_lock_mdio()` must never sleep, allocate with `GFP_KERNEL`, or call MDIO accessors, and MDIO writers (`_enetc_rd_mdio_reg_wa`, `_enetc_wr_mdio_reg_wa`) must use `write_lock_irqsave()`. [F149, F155, F157]
- In `enetc_stop()`, `ENETC_TX_DOWN` must be set in `priv->flags` at the start (and cleared only at the end of `enetc_start()`) and checked before enqueueing in `enetc_xdp_xmit()`, `XDP_TX` in `enetc_clean_rx_ring_xdp()`, and subqueue wakeup in `enetc_clean_tx_ring()`. `enetc_disable_rx_bdrs()`, `enetc_wait_bdrs()`, and `enetc_disable_tx_bdrs()` must run before `disable_irq()`, `napi_synchronize()`, and `napi_disable()` so NAPI drains `rx_ring->xdp.xdp_tx_in_flight` to zero. [F19, F20]
- `enetc_xdp_xmit()` and `enetc_clean_rx_ring_xdp()` access `priv->xdp_tx_ring` without TX queue locks, so whenever `priv->xdp_prog` is set, the last `num_possible_cpus()` TX rings must be excluded from `netif_set_real_num_tx_queues()` via `enetc_num_stack_tx_queues()`. [F165]
- One-step PTP Sync packets (`ENETC_F_TX_ONESTEP_SYNC_TSTAMP`) must acquire `ENETC_TX_ONESTEP_TSTAMP_IN_PROGRESS` via `test_and_set_bit_lock()` in `enetc_start_xmit()` rather than `enetc_xmit()`, and the `enetc_tx_onestep_tstamp()` worker must hold `netif_tx_lock_bh()` / `netif_tx_unlock_bh()` when clearing that bit and retransmitting from `priv->tx_skbs`. [F21, F159]
- `enetc_send_cmd()` runs in atomic contexts (`enetc_pf_set_rx_mode()` under `netif_addr_lock_bh` and `remove_one_chain()` under `spin_lock(&epsfp.psfp_lock)`) and must busy-wait with `udelay()`, never sleep. In `enetc_psfp_parse_clsflower()`, `enetc_psfp_hw_set()` must run before taking `epsfp.psfp_lock`, and `!enable` teardown paths called under `epsfp.psfp_lock` must not sleep or call `enetc_cbd_alloc_data_mem()`. [F160, F163]
- `enetc_get_ts_info()` and `enetc_get_phc_index*()` run under `rcu_read_lock()` and must use `pci_get_domain_bus_and_slot()`, not sleeping `pci_get_slot()`. MAC Merge registers and `ENETC_F_QBU` in `enetc_get_mm()`, `enetc_set_mm()`, and `enetc_mm_link_state_update()` require `priv->mm_lock`. `enetc_reconfigure()` requires `rtnl_lock()` (`ASSERT_RTNL()`) and must run `cb` only while stopped between `enetc_stop()`/`enetc_free_rxtx_rings()` and `enetc_start()`. [F22, F31, F158]

## Object Lifetimes
- When `enetc_xdp_tx()` succeeds for `XDP_TX` in `enetc_clean_rx_ring_xdp()`, add `xdp_tx_bd_cnt` to `rx_ring->xdp.xdp_tx_in_flight` and clear `rx_ring->rx_swbd[orig_i].page = NULL` across `[orig_i, i)` so `enetc_refill_rx_ring()` cannot reuse pages before `enetc_recycle_xdp_tx_buff()` runs. [F7]
- In `enetc_close()` and `enetc_reconfigure()`, `enetc_stop()` and `enetc_free_rxtx_rings()` must precede `enetc_assign_rx_resources()` and `enetc_assign_tx_resources()`. Teardown must stop NAPI and work items before freeing state: `netif_napi_del(&v->napi)` and `cancel_work_sync(&v->rx_dim.work)` before `kfree(v)` in `enetc_int_vector_destroy()`, `cancel_work_sync(&pf->msg_task)` in `enetc_msg_psi_free()`, and `destroy_workqueue(si->workqueue)` before `enetc4_pf_free()`. [F9, F29, F154]
- `enetc_pci_probe()` allocates `struct enetc_si` and `struct enetc_pf` in one buffer aligned to `ENETC_SI_ALIGN` (padding in `si->pad`); use `enetc_si_priv(si)` and free via `enetc_kfree_si(si)`, never `kfree(si)`. `pf->vf_state` must be allocated in `enetc_pf_probe()` before `register_netdev()` and freed in `enetc_pf_remove()`. In `enetc_mdiobus_destroy()`, `enetc_mdio_remove()` only calls `mdiobus_unregister(pf->mdio)` (devm-allocated), whereas `enetc_imdio_remove()` calls `destroy_pcs()`, `mdiobus_unregister(pf->imdio)`, and `mdiobus_free(pf->imdio)`. [F15, F96, F134]
- In `enetc_psfp_parse_clsflower()`, when `sfi_overwrite == 1`, pass `NULL` for `sfi` to `enetc_psfp_hw_set()` so rollback does not disable the shared filter, and call `remove_one_chain(priv, old_filter)` only after updating new `fmi`/`sgi`/`sfi` refcounts. `enetc_setup_irqs()` must pass `get_cpu_mask()` (not a stack `cpumask_t`) to `irq_set_affinity_hint()` and clear it with `NULL` before `free_irq()`. Balance `clk_prepare_enable(priv->ref_clk)` in `enetc_open()` with `clk_disable_unprepare()`, and balance `of_*` and `pci_get_domain_bus_and_slot()` lookups with `of_node_put()`, `put_device()`, and `pci_dev_put()`. [F17, F127, F147, F153]

## API Contracts
- In `enetc_map_tx_buffs()`, `enetc_map_tx_tso_buffs()`, and `enetc_lso_hw_offload()`, `tx_swbd->skb` must only be set on the final BD after all DMA mappings succeed so error unwinding does not double-free `skb` when `enetc_start_xmit()` frees it on `count == 0`. In `enetc_start_xmit()`, linearize non-GSO SKBs with `nr_frags > priv->max_frags`, and use `enetc_lso_hw_offload()` for GSO only when `ENETC_F_LSO` is set and payload (`skb->len - lso->hdr_len`) `<= ENETC_LSO_MAX_DATA_LEN` (256 KiB). [F3, F92, F177]
- `enetc_xdp_drop()` must only recycle RX BDs via `enetc_put_rx_buff()` without incrementing `xdp_drops`. On `XDP_PASS` in `enetc_clean_rx_ring_xdp()`, build the SKB via `xdp_build_skb_from_buff()`. `enetc_rx_swbd_to_xdp_tx_swbd()` requires `rx_ring_first != rx_ring_last` and `<= ENETC_MAX_SKB_FRAGS` BDs. In `enetc_xdp_xmit()`, call `enetc_update_tx_ring_tail()` when `XDP_XMIT_FLUSH` is set or when the loop stops early (`k != xdp_tx_frm_cnt`). [F59, F81, F172, F180]
- Port-wide Qbv (`ENETC_PTGCR_TGE`) in `enetc_setup_taprio()` and per-ring TSD (`tsd_enable`) in `enetc_setup_tc_txtime()` are mutually exclusive (`-EBUSY`). `enetc_taprio_queue_stats()` must report `priv->tx_ring[queue_stats->queue]->stats.win_drop` directly. In `enetc_setup_tc_cbs()`, `cbs->queue` is compared directly against `prio_top = tc_nums - 1` and `prio_next = tc_nums - 2` (not `netdev_get_prio_tc_map()`), and `prio_top` must be enabled before and disabled after `prio_next`. [F54, F111, F112, F182]
- Check `enetc_pf_to_port() < 0` before using `port` as a shift or index. Run `enetc_configure_port()` or `enetc4_pf_init()` before `enetc_get_si_caps()`. Configure IERB before PF FLR or child device creation (`enetc_pf_register_with_ierb()` before `enetc_psi_create()`, and `netcmix_init()` + `netc_ierb_init()` before `of_platform_populate()`). Request ring IRQs with `IRQF_NO_AUTOEN` and enable them in `enetc_start()` after `napi_enable()`. Toggle `enetc_has_err050089` only for `ENETC_MDIO_DEV_ID` (`0xee01`). Reject VF MAC mailbox overrides when `ENETC_VF_FLAG_PF_SET_MAC` is set. [F75, F119, F133, F136, F137, F145, F188]

## Error Handling
- Callers of `enetc_unwind_tx_frame()` (`enetc_map_tx_buffs()` and `enetc_map_tx_tso_buffs()`) must pass the exact `count` of populated BDs (including extension and TSO header BDs) and rewind `i` if `enetc_bdr_idx_inc()` ran before a failed `enetc_map_tx_tso_data()`. When `enetc_xdp_tx()` returns `false` in `enetc_xdp_xmit()`, the caller must `enetc_unmap_tx_buff()` all `xdp_tx_bd_cnt` BDs mapped by `enetc_xdp_frame_to_xdp_tx_swbd()` (which returns `-1` on error). [F2, F34]
- After `enetc_pci_probe()`, `enetc_pf_probe()` and `enetc_vf_probe()` error paths must unwind to `enetc_pci_remove()`, whereas `enetc4_pf_probe()` uses `devm_add_action_or_reset()` for `enetc4_pci_remove()` and must not call `enetc_pci_remove()` manually. Check `enetc_psi_create()`, `enetc_alloc_tx_resources()`, `enetc_alloc_rx_resources()`, and `enetc_hw_alloc()` with `IS_ERR()`, not `!ptr`. [F13, F32]
- `enetc_reconfigure()` must not call `enetc_assign_tx_resources()` or `enetc_assign_rx_resources()` until `cb(priv, ctx)` succeeds so `out_restart` can restore old rings on failure. `enetc_setup_rxbdr()` must set `ENETC_RBPIR = 0` and `ENETC_RBCIR = 1` before `enetc_refill_rx_ring()`. Zero-initialize `struct enetc_cbd` before `enetc_send_cmd()` (which overwrites `*cbd` on writeback), and check `enetc_get_free_index(priv) < 0` in a signed `int` in `enetc_psfp_parse_clsflower()`. [F42, F49, F50, F106]

## External Contracts
- TX/RX/Control BD ring DMA addresses must be 128-byte aligned, TX/RX `bd_count` a multiple of 64, and external CBD/NTMP buffers in `enetc_cbd_alloc_data_mem()` / `ntmp_alloc_data_mem()` allocated via `dma_alloc_coherent()` over-allocated by 64B (`ENETC_CBD_DATA_MEM_ALIGN`) or 32B (`NTMP_DATA_ADDR_ALIGN`), passing aligned addresses to hardware and unaligned base pointers to `dma_free_coherent()`. VSI mailbox buffers (`enetc_msg_vsi_write_msg()`) must be 32-byte aligned and a 32-byte multiple `<= 1024`. [F95, F152, F166]
- Hardware RSS commands (`enetc_cmd_rss_table()`, `ntmp_rsst_update_entry()`, `ntmp_rsst_query_entry()`) require all 64 entries (`RSST_ENTRY_NUM`), and `ntmp_rsst_query_entry()` reads groups at offset `NTMP_ENTRY_ID_SIZE + RSST_STSE_DATA_SIZE(count)`. In `enetc_set_cls_entry()` (`struct enetc_cmd_rfse`), swap MACs with `ether_addr_copy_swap()`, keep IPv4 as `__be32`, and convert ports/EtherType with `ntohs()`. [F90, F94]

## Known Pitfalls
- In `enetc_get_tx_tstamp()` and `enetc_get_rx_tstamp()`, decrement `hi` (`ENETC_SICTR1`) by 1 when `lo <= tstamp_lo` (`ENETC_SICTR0`) and cast to `u64` before `<< 32`. On 32-bit builds without `ioread64`, `_enetc_rd_reg64()` must loop reading `high`/`low` until `high == ioread32(reg + 4)` without `le64_to_cpu()`. Use `do_div()` in `enetc_update_ptp_sync_msg()`, `div_u64()` with `u64` casts in `enetc_setup_tc_cbs()` (after checking `bw_sum + bw >= 100`), `enetc_cycles_to_usecs()`, `enetc_usecs_to_cycles()`, and `enetc_flowmeter_hw_set()`, and negate positive bitmasks (`~ENETC_PM0_IFM_IFMODE_MASK`) in `enetc_mac_config()`. [F107, F113, F115, F116, F117, F118, F150]
