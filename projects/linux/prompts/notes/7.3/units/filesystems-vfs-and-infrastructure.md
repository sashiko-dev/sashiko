# FILESYSTEMS (VFS and infrastructure)

This unit implements VFS pathname resolution (`fs/namei.c`), mount namespaces and propagation (`fs/namespace.c`, `fs/pnode.c`, `fs/mount.h`), file opening (`fs/open.c`), pseudo-filesystem helpers (`fs/libfs.c`, `fs/nsfs.c`, `fs/pidfs.c`), pipes (`fs/pipe.c`), POSIX ACLs (`fs/posix_acl.c`), multi-page BIO and xattr caching (`fs/mpage.c`, `fs/mbcache.c`), early boot rootfs/initramfs (`init/do_mounts*.c`, `init/initramfs.c`), and VFS C/Rust headers (`include/linux/fs*.h`, `rust/kernel/fs*.rs`).

## Architecture & Data Flow
- `struct mount::mnt_ns` can be `NULL`, `MNT_NS_INTERNAL` (`ERR_PTR(-EINVAL)`), or a `struct mnt_namespace *`, so check `is_mounted()` (`!IS_ERR_OR_NULL(mnt->mnt_ns)`) before dereferencing it. `struct mount::mnt_pprev_for_sb` steals bit 0 for `WRITE_HOLD`, must stay `__aligned(1)`, and must not be dereferenced while `WRITE_HOLD` is set. [F138, F238]
- In `attach_recursive_mnt()`, for each `child` in `tree_list`, any preexisting mount `q` at `child->mnt_mountpoint` must be looked up via `__lookup_mnt()` and `commit_tree(child)` must run before `mnt_change_mountpoint()` reparents `q` onto `topmost_overmount(child)`, and `lock_mnt_tree(child)` must run before reparenting `q` so `q` does not get `MNT_LOCKED`. Cross-`user_ns` copies in `attach_recursive_mnt()` and `copy_mnt_ns()` must call `lock_mnt_tree()`. [F252, F285, F349]
- In `fs/pnode.c`, `propagation_next()` and `next_group()` must only skip `mnt_slave_list` on `IS_MNT_NEW(m)` mounts, whereas `is_anon_ns(m->mnt_ns)` mounts must only be skipped as secondary copy targets in `need_secondary()`. `propagate_mnt()`, `bulk_make_private()`, and `propagate_umount()` must clear transient `T_MARKED` and `T_UMOUNT_CANDIDATE` flags in `mnt->mnt_t_flags` before returning, and `propagate_umount()` must only call `reparent(m->overmount)` when `!will_be_unmounted(over)`. [F250, F257, F288]
- `terminate_walk()` drops `nd->root` and clears `ND_ROOT_GRABBED` while preserving `ND_ROOT_PRESET` across retries, and `complete_walk()` must not clear `nd->root.mnt` before `try_to_unlazy()` when `ND_ROOT_PRESET` or `LOOKUP_IS_SCOPED` is set. `vfs_rename()` must call `take_dentry_name_snapshot(&old_name, old_dentry)` before `i_op->rename()`, `d_move()`, or `d_exchange()`, passing `&old_name.name` to `fsnotify_move()` (and `&old_dentry->d_name` for the exchanged target's old name under `RENAME_EXCHANGE`). [F83, F87, F185]
- A pipe's `ring_size` must be a power of two `<= (pipe_index_t)-1u` (rejected with `-EINVAL` in `pipe_resize_ring()`), and occupancy checks must cast `(pipe_index_t)(head - tail)` via `pipe_occupancy()`, `pipe_empty()`, and `pipe_full()`. `pipe_resize_ring()` linearizes occupied slots to index `0` (`tail = 0`, `head = n`) under `pipe->rd_wait.lock`, and `pipe_set_size()`/`free_pipe_info()` must account against `pipe->user` (not `current_user()`). [F263, F278, F305, F306, F358]
- Cached `struct posix_acl` objects on an inode store IDs in `inode->i_sb->s_user_ns` (applying `mnt_idmap` only in `vfs_set_acl_idmapped_mnt()`, `vfs_posix_acl_to_xattr()`, and `posix_acl_permission()`) and are shared across readers, so `__posix_acl_create()`, `__posix_acl_chmod()`, and `posix_acl_create()` must `posix_acl_clone()` before mutating in place. [F266, F360]
- `file_dentry(file)` requires `d_inode(file->f_path.dentry) == file_inode(file)`; backing files (`f->f_mode & FMODE_BACKING`, embedded in `struct backing_file`) must use `file_user_path(f)` / `file_user_inode(f)`. Rust `File`, `LocalFile`, and `SeqFile` must remain `#[repr(transparent)]` wrappers around `Opaque<bindings::file>` / `Opaque<bindings::seq_file>`. [F413, F452, F457]

## Synchronization
- Lock ordering when mounting: `inode_lock(dentry->d_inode)` nests outside `namespace_lock()` (`namespace_sem`), which nests outside `mount_lock`. `do_lock_mount()` must evaluate `where_to_mount()` and pin `m->mnt` and `dentry` under `read_seqlock_excl(&mount_lock)` before taking `inode_lock` and `namespace_lock()`, revalidate under `mount_lock` afterwards, and `__unlock_mount()` must release `inode_unlock()` and `unpin_mountpoint()` before `namespace_unlock()`. [F213, F214]
- Code that unmounts (`umount_tree()`, `umount_mnt()`) or sets `emptied_ns` must use `namespace_lock()`/`namespace_unlock()` (`guard(namespace_excl)`) rather than raw `down_write`/`up_write(&namespace_sem)`. Callers holding `namespace_sem` (like `do_statmount()`, `do_listmount()`) must not call `path_put()` until after `namespace_sem` is released unless the path stays pinned with a non-zero refcount. [F193, F325]
- `__lookup_mnt()` requires holding `mount_lock`'s spinlock (`read_seqlock_excl` or `write_seqlock`) or `rcu_read_lock()` with `read_seqbegin(&mount_lock)` and retry/fallback on `read_seqretry()`. `path_overmounted()` requires `namespace_sem` (at least shared) and must never be called under `lock_mount_hash()` (`write_seqlock(&mount_lock)`). Walking `mnt_mounts` or `mnt_parent` requires `mount_lock` or `namespace_sem` on a pinned mount, and mount propagation state requires exclusive `namespace_lock()` taken before `lock_mount_hash()`. [F211, F216, F218, F327]
- `mnt_get_write_access()` and `mnt_put_write_access()` must disable preemption around per-CPU `mnt_writers` updates; `mnt_get_write_access()` needs `smp_mb()` before spinning on `__test_write_hold(READ_ONCE(mnt->mnt_pprev_for_sb))` and `smp_rmb()` before `mnt_is_readonly()`, while `mnt_hold_writers()` and `mnt_unhold_writers()` require `smp_mb()`/`smp_wmb()` under `mount_lock`. [F208, F209, F328]
- Under `LOOKUP_RCU`: in `__follow_mount_rcu()` and `follow_dotdot_rcu()`, target `dentry->d_seq` must be sampled via `read_seqcount_begin()` before `read_seqretry(&mount_lock, nd->m_seq)` or `read_seqcount_retry(&old->d_seq, nd->seq)`; `nd_alloc_stack()` must use `GFP_ATOMIC`; `may_lookup()` must pass `MAY_NOT_BLOCK` to `inode_permission()` (where `i_op->permission` and `ACL_DONT_CACHE` `get_inode_acl(..., true)` must not sleep, and `check_acl()` uses `get_cached_acl_rcu()`); and `generic_ci_d_compare()` must read `d_parent`/`d_inode` with `READ_ONCE()`, copy inline `d_shortname.string` to the stack with `barrier()`, and never use `GFP_KERNEL`. [F39, F146, F147, F164, F341, F463, F466]
- Outside `pipe->mutex`, `pipe->head` and `pipe->tail` must be read together via `READ_ONCE(pipe->head_tail)` into `union pipe_index`. For `watch_queue` pipes, `anon_pipe_read()` must read `pipe->head` via `smp_load_acquire()`, and `pipe_update_tail()` and `pipe_resize_ring()` must hold `spin_lock_irq(&pipe->rd_wait.lock)`. `fifo_open()` must call `alloc_pipe_info()` outside `inode->i_lock`, recheck `inode->i_pipe` after re-acquiring `inode->i_lock`, and `put_pipe_info()` must call `free_pipe_info()` only after dropping `inode->i_lock`. [F220, F222, F224, F338]
- `struct file` is `SLAB_TYPESAFE_BY_RCU`, so lockless RCU readers must use `get_file_rcu()` or `get_file_active()` (never `get_file()`), and `file->f_lock` is non-IRQ-safe (never acquire in hardirq context). `i_size_write()` callers must hold an exclusive lock (such as `inode->i_rwsem`) to serialize `i_size_seqcount` updates on 32-bit SMP. [F467, F468, F474]

## Object Lifetimes
- `__legitimize_path()` must null out `path->mnt` only when `__legitimize_mnt()` returns `> 0` and always null out `path->dentry` on any failure, because `__legitimize_mnt() < 0` means the mount reference was acquired and must be dropped by a subsequent `path_put()`. When `d_alloc_parallel()` returns an in-lookup dentry (`d_in_lookup(dentry)`), `d_lookup_done(dentry)` must be called after `i_op->lookup` or `i_op->atomic_open` and before `dput(dentry)`. [F5, F13]
- Because `mntput_no_expire()` uses an RCU fastpath when `READ_ONCE(mnt->mnt_ns)` is non-NULL, clearing `mnt->mnt_ns` to `NULL` (`mnt_make_shortterm()`, `umount_tree()`) requires an RCU grace period before the final `mntput()`. `cleanup_mnt()` for non-`MNT_INTERNAL` mounts must be deferred to process context, `free_vfsmnt()` in `cleanup_mnt()` must use `call_rcu(&mnt->mnt_rcu, delayed_free_vfsmnt)`, and `mnt_ns_tree_remove()` must defer `mnt_ns_release` via `call_rcu()`. [F215, F333, F334]
- In `move_from_ns()` (`fs/mount.h`), before `rb_erase(&mnt->mnt_node, &ns->mounts)`, `ns->mnt_last_node` and `ns->mnt_first_node` must be updated to `rb_prev`/`rb_next` if they point to `&mnt->mnt_node`, and `RB_CLEAR_NODE(&mnt->mnt_node)` must follow `rb_erase()` so `mnt_ns_attached(mnt)` becomes false. Every caller populating a local `struct pinned_mountpoint` must call `unpin_mountpoint()` before returning. [F22, F324]
- Because `pipe_resize_ring()` reallocates `pipe->bufs` and resets `head`/`tail`, any pipe operation that drops and reacquires `pipe->mutex` must re-read `pipe->head`, `pipe->tail`, and `pipe_buf(pipe, ...)`. In `FileDescriptorReservation::fd_install`, both `self` and `file` (`ARef<File>`) must be passed to `core::mem::forget` after `bindings::fd_install`, and `<PollCondVar as PinnedDrop>::drop` must call `__wake_up_pollfree` before `synchronize_rcu()`. [F321, F362, F364]

## API Contracts
- Ownership-consuming vs non-consuming helpers: `nd_jump_link()` always consumes `@path` (even on error); `scan_positives()` and `find_next_child()` always `dput()` `@last`/`@prev`; `mb_cache_entry_find_next()` always drops `@entry`, while `mb_cache_entry_delete_or_get()` returns `NULL` if deleted/absent or a referenced entry when `e_refcnt > 2`; `mount_subtree(m, name)` always consumes `@m` and returns a dentry with `s_active` held and `s_umount` write-locked; `__posix_acl_create()` and `__posix_acl_chmod()` always consume `*acl` (unlike `set_cached_acl()` and `vfs_set_acl()`); and `finish_no_open(file, dentry)` consumes non-`ERR_PTR` `dentry` while `finish_open()` does not. [F6, F15, F20, F194, F206, F355]
- Paired write and freeze protection helpers must not be mixed: `mnt_want_write()` pairs with `mnt_drop_write()`, `mnt_want_write_file()` pairs with `mnt_drop_write_file()`, `mnt_get_write_access()` pairs with `mnt_put_write_access()`, `mnt_get_write_access_file()` pairs with `mnt_put_write_access_file()`, `kiocb_start_write()` pairs with `kiocb_end_write()` (never `sb_end_write()`/`file_end_write()`), and `exe_file_deny_write_access()` pairs with `exe_file_allow_write_access()`. [F197, F347, F414, F470]
- `lock_rename()` and `lock_rename_child()` return `ERR_PTR(-EXDEV)` with all locks already released when directories have no common ancestor, `NULL` with locks held when neither is an ancestor, or a non-error `struct dentry *` trap with locks held when one is an ancestor (requiring `unlock_rename()`). `do_lock_mount()` and `lock_mount_exact()` store `ERR_PTR(err)` in `res->parent` with locks already released on failure, so callers and `unlock_mount()` must check `IS_ERR(mp.parent)`. [F47, F240]
- Special return conventions: `d_op->d_revalidate()` and `d_weak_revalidate()` return `> 0` when valid, `0` when stale (translate to `-ESTALE`/invalidate), and `< 0` on error; `d_op->d_manage()` and `follow_automount()` return `-EISDIR` to stop traversal and use the current path as success (`0`/`true`), while `LOOKUP_NO_XDEV` requires returning `-EXDEV` (`false` in `__follow_mount_rcu()`) before invoking them; and `posix_acl_equiv_mode()` / `posix_acl_create_masq()` return `< 0` on error, `0` when fully mode-equivalent, and `1` when non-equivalent ACL entries remain. [F50, F51, F168, F233]
- `kernel_tmpfile_open()` and `kernel_file_open()` allocate via `alloc_empty_file_noaccount()` and must never be passed to `fd_install()`. `replace_fops(f, fops)` drops the old module ref without taking a new one (`BUG_ON(!fops)`) and must only be called in `->open()` on an already-pinned `fops`. A `file_operations` table must not set both `.mmap` and `.mmap_prepare`, and `can_mmap_file()` must return `false` without `WARN_ON_ONCE` when neither is set. [F182, F356, F368, F388, F481]
- Before downcasting `file->private_data` or `inode->i_private`, callers must verify file/dentry ops (`get_pipe_info()`, `pidfd_pid()`, `proc_ns_file(file)`, or `dentry->d_op == &ns_dentry_operations` plus `ns->ops`). `FS_ALLOW_IDMAP` filesystems and `fs/namei.c` permission helpers must map UIDs/GIDs via `struct mnt_idmap *` helpers, `->set_acl()` for `ACL_TYPE_ACCESS` must call `posix_acl_update_mode()`, `alloc_inode` callbacks must use `alloc_inode_sb()`, and `.setattr` must test `ia_valid & ATTR_FILE` (not `ia_file != NULL`). [F180, F246, F249, F262, F361, F372, F488, F489]
- In Rust VFS wrappers, `File::from_raw_file` and `LocalFile::from_raw_file` borrow without incrementing `f_ref` and require no active unlocked `fdget_pos` reference, `Kiocb<'a, T>::from_raw` requires non-null `kiocb` with `ki_filp->private_data` matching `<T as ForeignOwnable>`, and `PollTable` must tolerate a null `self.table` pointer. [F363, F458, F459, F462]

## Error Handling
- Because `mnt_hold_writers(m)` sets `WRITE_HOLD` before checking `mnt_get_writers(m)` and leaves `WRITE_HOLD` set when returning `-EBUSY`, `mount_setattr_prepare()` must advance `m = next_mnt(m, mnt)` before breaking on error so the rollback loop calls `mnt_unhold_writers(m)`. [F241]
- `ACL_NOT_CACHED` (`(void *)-1`), `ACL_DONT_CACHE` (`(void *)-3`), and `uncached_acl_sentinel(task)` (`(void *)task + 1`) all have bit 0 set (`is_uncached_acl(acl)`), so ACL consumers must check sentinel values rather than only `acl != NULL` or `IS_ERR(acl)`. `address_space_operations` callbacks can return positive `AOP_WRITEPAGE_ACTIVATE` (page stays locked) or `AOP_TRUNCATED_PAGE` (page unlocked; drop ref and retry). [F390, F391]

## Known Pitfalls
- Opposite or non-obvious conventions: `generic_ci_d_compare()` returns `0` on match and `1` on mismatch, whereas `generic_ci_match()` returns `1` on match and `0` on mismatch; `simple_read_from_buffer(to, count, ppos, from, available)` and `simple_write_to_buffer(to, available, ppos, from, count)` swap `count` and `available`; `generic_fh_to_dentry()` and `generic_fh_to_parent()` measure `fh_len` in 4-byte (`__u32`) words despite comments saying bytes; and `skip_mnt_tree(p)` returns the last descendant of `p` (`for (...; p = next_mnt(p, root))` uses `p = skip_mnt_tree(p); continue;`, while `while` loops use `next_mnt(skip_mnt_tree(p), root)`). [F62, F69, F94, F290]
- Rename, permission, and bit-width pitfalls: in `do_renameat2()`, `lock_rename(new_path.dentry, old_path.dentry)` passes `new_path` first (`old_dentry == trap` is `-EINVAL`; `new_dentry == trap` is `-ENOTEMPTY`, or `-EINVAL` under `RENAME_EXCHANGE`); in `acl_permission_check()`, the owner UID check must precede `IS_POSIXACL(inode)` and `mask &= 7` must follow `check_acl()`; `inode_state_wait_address()`/`inode_bit_waitqueue()`/`inode_wake_up_bit()` take `enum inode_state_bits` (`0..3`), never shifted `I_*` masks; `FMODE_FSNOTIFY_NONE(mode)` must check `(mode & FMODE_FSNOTIFY_MASK) == FMODE_NONOTIFY`; and `is_zero_ino()` must test `(u32)ino == 0`. [F116, F125, F430, F438, F449]
