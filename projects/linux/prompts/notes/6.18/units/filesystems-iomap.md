# FILESYSTEMS [IOMAP]

The iomap subsystem provides a generic extent-based file I/O framework for Linux filesystems, replacing legacy `buffer_head` block mapping. Filesystems supply `struct iomap_ops` extent mapping callbacks while iomap handles buffered reads/readahead, buffered writes, sub-folio block state tracking (`struct iomap_folio_state`), writeback with bio chaining and ioend merging, synchronous and asynchronous direct I/O, page faults (`page_mkwrite`), FIEMAP, `SEEK_HOLE`/`SEEK_DATA`, and swapfile activation.

## Architecture & Data Flow

- `struct iomap` `addr`, `offset`, and `length` are in bytes; `iomap_sector()` computes `(iomap->addr + pos - iomap->offset) >> SECTOR_SHIFT` unless `IOMAP_F_ANON_WRITE` is set. All `IOMAP_F_*` flags in `u16 flags` must use distinct bits. [F104, F149]
- `iomap_iter()` must sample `IOMAP_F_STALE` before `iomap_iter_reset_iomap()` zeroes `status`, `iomap`, and `srcmap`, and continue even when `advanced == 0` if `stale` is true. Because `srcmap` resets to `IOMAP_HOLE` (`0`), callers must use `iomap_iter_srcmap(iter)` or test `srcmap.type != IOMAP_HOLE`, except `iomap_want_unshare_iter()`, which must check `iter->srcmap.type == IOMAP_MAPPED` directly so it does not fall back to `&iter->iomap`. [F47, F64, F117]
- `ifs_alloc()` sizes `ifs->state[]` via `struct_size(ifs, state, BITS_TO_LONGS(2 * nr_blocks))`, packing uptodate bits at `[0, blks_per_folio)` and dirty bits at `[blks_per_folio, 2 * blks_per_folio)`. Dirty-bit helpers must offset indices by `blks_per_folio`, while `ifs_is_fully_uptodate()` tests only `[0, blks_per_folio)`. [F80, F129]
- In `__iomap_write_begin()`, the whole-folio fast-path skipping `ifs_alloc()` and reading/zeroing must be bypassed when `iter->flags & IOMAP_UNSHARE` is set; its loop must check `if (plen == 0) break;` before `continue`; and after zeroing or reading `[poff, poff + plen)`, it must call `iomap_set_range_uptodate(folio, poff, plen)`. [F59, F106, F157]
- In `iomap_write_iter()`, when `iomap_write_end()` returns `written == 0`, both `iomap_write_failed(iter->inode, pos, bytes)` and `iov_iter_revert(i, copied)` must run before retrying. In `iomap_zero_range()`, if the source mapping is `IOMAP_HOLE` or `IOMAP_UNWRITTEN` and `range_dirty` is true, `iomap_zero_iter_flush_and_stale()` must flush `[iter.pos, iter.pos + iter.len - 1]` and set `IOMAP_F_STALE` instead of advancing. [F63, F65]
- Every non-error path in `iomap_readpage_iter()` (`IOMAP_INLINE`, `plen == 0`, `iomap_block_needs_zeroing()`) must call `iomap_iter_advance()` so `iomap_read_folio_iter()` / `iomap_readahead_iter()` do not loop forever. When a read spans `i_size` (`orig_pos <= isize && orig_pos + orig_plen > isize`), `iomap_adjust_read_range()` must truncate `plen` at the end of the block containing `isize - 1`. [F87, F101]
- In `iomap_writeback_folio()`, `iomap_clear_range_dirty(folio, 0, folio_size(folio))` must run even if `iomap_writeback_range()` fails. `iomap_alloc_ioend()` must reset `wpc->nr_folios = 0`. In `iomap_add_to_ioend()`, `ioend->io_size` must be clamped so `ioend->io_offset + ioend->io_size <= end_pos`; `IOMAP_IOEND_DONTCACHE` must be set when `folio_test_dropbehind(folio)` is true and stay in `IOMAP_IOEND_NOMERGE_FLAGS`; and `IOMAP_IOEND_BOUNDARY` is set only at `pos == wpc->iomap.offset` and checked only on the second/incoming ioend. [F60, F74, F75, F78, F110]
- `iomap_ioend_can_merge()` must check sector contiguity via `ioend->io_sector + (ioend->io_size >> SECTOR_SHIFT) == next->io_sector` (not `io_bio.bi_iter.bi_sector`), and `iomap_ioend_try_merge()` must add `next->io_size` to `ioend->io_size`. In `struct iomap_ioend`, `io_bio` must remain the last field so `iomap_ioend_bioset`'s inline `bio_vec` array follows it. [F76, F127]
- `dio->flags` (public low bits, private bits 25..31) and `dio_flags` are separate namespaces. In `iomap_dio_bio_iter()`: exit paths after `iov_iter_truncate()` must call `iov_iter_reexpand(dio->submit.iter, orig_count - copied)` (reverting `copied` to 0 on `dio->error`); if `REQ_FUA` is not used on a write, `IOMAP_DIO_WRITE_THROUGH` must be cleared; `IOMAP_DIO_CALLER_COMP` must be cleared on `need_zeroout`, writes at/beyond `i_size`, non-FUA sync, or `iomap_finish_ioend_direct()`; and DIO reads past `dio->i_size` must revert `iomi.pos - dio->i_size` and clamp `ret`. [F54, F69, F71, F72, F97]
- `iomap_file_unshare()`, `iomap_seek_hole()`, and `iomap_seek_data()` must reject `pos < 0 || pos >= i_size_read(inode)` and clamp `iter.len` to `i_size_read(inode) - pos`. In `iomap_write_delalloc_release()`, `scan_end_byte` must be clamped to `min(i_size_read(inode), end_byte)` while the final punch extends to `end_byte`. [F85, F86]

## Synchronization

- Every `ifs->state_lock` acquisition must disable IRQs (`spin_lock_irqsave` / `spin_lock_irq`) because `iomap_finish_folio_read()` takes it in IRQ bio completion. Under `ifs->state_lock`: `iomap_set_range_uptodate()` and `iomap_finish_folio_read()` must update uptodate bits and test `ifs_is_fully_uptodate()` before `folio_mark_uptodate()` / `folio_end_read()`; `ifs_set_range_dirty()` and `ifs_clear_range_dirty()` must modify dirty bits; and `iomap_readpage_iter()` must add `plen` to `ifs->read_bytes_pending` before submitting any prior `ctx->bio`. [F18, F19, F21, F133]
- `ifs_alloc()` must initialize `ifs->state_lock` and the initial uptodate and dirty bitmaps from `folio_test_uptodate(folio)` and `folio_test_dirty(folio)` before `folio_attach_private(folio, ifs)` publishes `ifs`. [F20]
- In `iomap_writeback_folio()`, `folio_start_writeback(folio)` must precede `iomap_writeback_range()`. For multi-block folios (`i_blocks_per_folio(inode, folio) > 1`), `iomap_writeback_folio()` must add a +1 bias to `ifs->write_bytes_pending` via `iomap_start_folio_write()` before `folio_start_writeback()` and drop it via `atomic_dec_and_test(&ifs->write_bytes_pending)` only after all ranges are submitted and `iomap_clear_range_dirty()` finishes. [F22, F23]
- In `iomap_write_iter()`, user pages must be faulted in via `fault_in_iov_iter_readable()` before `iomap_write_begin()` locks the folio, and copied with `copy_folio_from_iter_atomic()` while locked. `write_ops->iomap_valid()` must be checked after `__iomap_get_folio()` locks the folio. On a short copy (`copied < len`) when `!folio_test_uptodate(folio)`, `__iomap_write_end()` must return `false` without marking the range uptodate or dirty. [F24, F25, F27]
- When `iter->flags & IOMAP_NOWAIT` is set: `iomap_get_folio()` must use `FGP_NOWAIT | FGP_NOFS`; `ifs_alloc()` must use `GFP_NOWAIT`; `__iomap_write_begin()` must return `-EAGAIN` if `ifs_alloc()` fails on a multi-block folio or an unaligned non-uptodate block needs a read; and `iomap_write_iter()` must pass `BDP_ASYNC` to `balance_dirty_pages_ratelimited_flags()`. [F134, F135]
- `iomap_page_mkwrite()` locks `folio = page_folio(vmf->page)`, must call `folio_mkwrite_check_truncate()` before `iomap_iter()`, and must either call `folio_wait_stable(folio)` and return `VM_FAULT_LOCKED` with `folio` locked or call `folio_unlock(folio)` on every error path. [F17, F36]
- `iomap_write_delalloc_release()` requires `inode->i_mapping->invalidate_lock` held in write mode, and its `iomap_punch_t` callback must never acquire `folio_lock()` because `iomap_write_delalloc_scan()` holds `folio_lock()` while invoking `punch`. [F138]
- For sync DIO (`dio->wait_for_completion`), `dio->submit.waiter` is set to `current` before bio submission, cleared via `WRITE_ONCE(dio->submit.waiter, NULL)` in `iomap_dio_done()` before `blk_wake_io_task()`, and waited on under `TASK_UNINTERRUPTIBLE` until `!READ_ONCE(dio->submit.waiter)`. `iomap_finish_ioend_direct()` may only set `IOMAP_DIO_INLINE_COMP | IOMAP_DIO_NO_INVALIDATE` when `!dio->iocb->ki_filp->f_mapping->nrpages`, otherwise punting to `s_dio_done_wq`. [F31, F143]
- In `iomap_dio_bio_iter()`, sub-block direct writes to `IOMAP_UNWRITTEN`/`IOMAP_F_NEW`, at/beyond `i_size`, or after `bio_iov_iter_get_pages()` failure must zero unwritten head/tail blocks via `iomap_dio_zero()`. [F168]

## Object Lifetimes

- Callers of `iomap_iter()` must loop until `iomap_iter()` returns `<= 0` rather than breaking or returning from the loop body, because `iomap_iter()` calls `ops->iomap_end()` on the next call when `iter->iomap.length` is non-zero. [F1]
- In `iomap_read_folio()` and `iomap_readahead()`, `ctx.cur_folio_in_bio = true` transfers folio unlock responsibility to `iomap_read_end_io()` / `iomap_finish_folio_read()`; if `!ctx.cur_folio_in_bio`, the submitter must call `folio_unlock()`. `ifs_free()` may only detach and free `ifs` when the folio is clean, `read_bytes_pending == 0`, `write_bytes_pending == 0`, and `ifs_is_fully_uptodate() == folio_test_uptodate()`. [F5, F6]
- In `iomap_writeback_folio()` and `iomap_finish_ioend_buffered()`, `mapping_set_error()` must be called on `inode->i_mapping`, not `folio->mapping`, which can become NULL once writeback ends. When `wpc->wb_ctx` is non-NULL in `iomap_writepages()`, `wpc->ops->writeback_submit(wpc, error)` must always be called even on error, and `iomap_ioend_writeback_submit()` must complete failed ioends via `bio_endio(&ioend->io_bio)` (not `bio_put()`). [F8, F9]
- `bio_put(&ioend->io_bio)` frees `struct iomap_ioend`, so all `ioend` fields (including `ioend->io_list` in `iomap_finish_ioends()`) must be read or detached beforehand. For split ioends, `iomap_finish_ioend()` frees the child via `bio_put(&ioend->io_bio)` and only completes `ioend->io_parent` when `atomic_dec_and_test(&ioend->io_remaining)` is true. [F10, F11]
- `__iomap_dio_rw()` sets `dio->ref = 1`, `iomap_dio_submit_bio()` increments `dio->ref` before each bio submission, and `__iomap_dio_rw()`, `iomap_dio_bio_end_io()`, and `iomap_finish_ioend_direct()` must finish accessing `dio->wait_for_completion`, `dio->flags` (caching `IOMAP_DIO_DIRTY`), and `dio->error` before `atomic_dec_and_test(&dio->ref)`. [F30, F33]
- Because `dio->submit` and `dio->aio` share a union, `dio->aio.work` may only be initialized in `iomap_dio_done()` after `atomic_dec_and_test(&dio->ref)` when `!dio->wait_for_completion`. In `iomap_dio_complete()`, `dops->end_io()` must precede `kiocb_invalidate_post_direct_write()`, and `inode_dio_end()` and `kfree(dio)` must run on all paths. [F14, F132]

## API Contracts

- Every `ops->iomap_begin()` mapping must satisfy `iomap.offset <= iter->pos`, `iomap.length > 0`, and `iomap.offset + iomap.length > iter->pos`; when `srcmap.type != IOMAP_HOLE`, `iomap_length_trim()` clamps length to `srcmap`. Inside `iomap_iter()` loops, callers must advance via `iomap_iter_advance(iter, count)` (requiring `*count <= iomap_length(iter)` and overwriting `*count` with remaining `iomap_length(iter)`) or set `IOMAP_F_STALE`; leaving `iter->pos` unadvanced with `status == 0` ends iteration, and `iter->status > 0` triggers `WARN_ON_ONCE` and `-EIO`. [F89, F90, F100]
- `write_ops`, `dops`, and each callback inside `struct iomap_write_ops`, `struct iomap_dio_ops`, and `ops->iomap_end` are optional and must be null-checked. Whenever `get_folio` / `__iomap_get_folio()` succeeds, `__iomap_put_folio()` must run on all exit paths, and custom `put_folio` callbacks must both unlock and `folio_put()` the folio. Callers of `iomap_write_begin()` must initialize in-out `*plen` to a positive bound or `0`. [F2, F45, F52]
- `iomap_is_partially_uptodate()` must clamp `count` to `min(folio_size(folio) - from, count)`. `iomap_write_delalloc_release()` and its helpers take half-open `[start_byte, end_byte)` intervals, whereas `iomap_punch_t` takes `(inode, offset, length, iomap)` and VFS range helpers take inclusive end offsets (`start + len - 1`). `DEFINE_RANGE_EVENT` tracepoints require file byte offsets (`folio_pos(folio) + offset`). [F53, F56, F83]
- `wpc->ops->writeback_range()` must return a positive byte count `<= rlen` or a negative errno. `iomap_split_ioend()` requires `ioend->io_bio` to still be `REQ_OP_WRITE` (switching to `REQ_OP_ZONE_APPEND` only after splitting), rounds `sector_offset` down to `i_blocksize(ioend->io_inode)`, updates `io_parent`, `io_remaining`, `io_offset`, `io_size`, and `io_sector` (advancing `ioend->io_sector` only when `!is_append`), and returns `NULL` (no split), `ERR_PTR`, or the split ioend. [F41, F77, F94, F113, F165]
- `__iomap_dio_rw()` returns `NULL` (no I/O), `ERR_PTR(-EIOCBQUEUED)`, `ERR_PTR(ret)`, or a valid `struct iomap_dio *` for `iomap_dio_complete()`. Custom `dops->submit_io` handlers calling `iomap_init_ioend()` / `iomap_ioend_from_bio()` must set `.bio_set = &iomap_ioend_bioset`, and custom DIO `bi_end_io` callbacks must finish via `iomap_dio_bio_end_io(bio)` or `iomap_finish_ioend_direct()`. `iomap_bmap()` must return `0` on any error or non-`IOMAP_MAPPED` extent. [F40, F42, F128, F152]

## Error Handling

- `iomap_iter()` only propagates a negative return from `ops->iomap_end()` if `iter->pos` did not advance (`!advanced`); if it advanced, `iomap_end()` errors are ignored unless `iter->status < 0`. In `iomap_file_buffered_write()` and `iomap_write_iter()`, errors after partial progress (`iter.pos != iocb->ki_pos` or `total_written > 0`) must be suppressed so `iocb->ki_pos` advances and the short write count is returned. [F38, F39]
- Recording errors into `dio->error` (`iomap_dio_set_error()`) or `ioend->io_error` (`iomap_finish_ioend()`) must use `cmpxchg(..., 0, error)`. In `__iomap_dio_rw()`, `-ENOTBLK` (and `-EFAULT` when `dio->size > 0` and `dio_flags & IOMAP_DIO_PARTIAL`) must be cleared to `0` before `iomap_dio_set_error()` and force `wait_for_completion = true` (unless `IOCB_NOWAIT` on `-EFAULT`). [F49, F51]
- For `mapping_seek_hole_data(mapping, start, end, whence)`, callers must check `offset < 0` (`-ENXIO`) for `SEEK_DATA` "not found", but `offset == end` for `SEEK_HOLE`. [F44]

## Known Pitfalls

- When `write_ops->iomap_valid()` returns `false` in `iomap_write_begin()`, it releases the folio via `__iomap_put_folio()`, sets `IOMAP_F_STALE`, and returns `0` without setting `*foliop`; callers must check `iter->iomap.flags & IOMAP_F_STALE` before touching `folio`. [F3]
- In `ifs_find_dirty_range()`, `end_blk` must use `min_not_zero(offset_in_folio(folio, range_end) >> inode->i_blkbits, i_blocks_per_folio(inode, folio))` because `offset_in_folio(folio, range_end)` wraps to `0` at the end of the folio. Converting `[off, off + len)` or `[start_byte, end_byte)` to inclusive `[first_blk, last_blk]` must compute `last_blk` from the inclusive last byte (`(off + len - 1) >> blkbits`). [F81, F82]
- In `iomap_writeback_handle_eof()`, testing if a folio is at/beyond `isize` must use `folio->index > end_index || (folio->index == end_index && poff == 0)`, not `folio->index >= end_index + 1` (which overflows 32-bit `pgoff_t` at 16TB). Clamping `dirty_len` in `iomap_add_to_ioend()` (`min_t(u64, ...)`) and `plen` in `iomap_adjust_read_range()` (`min_t(loff_t, ...)`) must use 64-bit arithmetic before narrowing. [F91, F121, F122]
- In `iomap_write_iter()`, `bytes = iov_iter_count(i)` must be set before `retry:` so a short-copy retry (`bytes = copied; goto retry;`) is not overwritten, and fault-in `chunk` must be bounded by `mapping_max_folio_size(mapping)`. [F102, F103]
