# KERNEL VIRTUAL MACHINE FOR RISC-V (KVM/riscv)

Implements the RISC-V architecture backend for KVM using the Hypervisor ('H') extension to manage guest VMs and vCPUs. It provides G-stage page table management, VMID allocation, HFENCE/TLB flushing, trap/MMIO/CSR emulation, SBI extensions with optional Nested Acceleration (NACL), per-vCPU Sstc/hrtimer timers, PMU emulation via `perf_events`, FP/Vector context switching, and Advanced Interrupt Architecture (AIA) APLIC and IMSIC emulation.

## Architecture & Data Flow

- `vcpu->arch.aia_context.imsic_state` is only allocated when `aia_init()` sets `kvm->arch.aia.initialized = true`, and `kvm->arch.aia.aplic_state` remains `NULL` when `nr_sources == 0`; check `kvm_riscv_aia_initialized(kvm)` before IMSIC ops and `aplic_state != NULL` before APLIC ops. [F50]
- APLIC IRQs (`aplic->nr_irqs = nr_sources + 1`), IMSIC MSIs (`[1, imsic->nr_msis)` where `nr_msis = nr_ids + 1`), and HGEI slots (`[1, kvm_riscv_aia_nr_hgei]`, `vsfile_hgei <= 0` unassigned, `msi_va`/`msi_pa` at `ret * IMSIC_MMIO_PAGE_SZ`) are 1-based; reject ID `0` and `>= nr_irqs`/`nr_msis`, keep bit 0 of `EIP0`/`EIE0` and `free_bitmap` zero/skipped, and size words via `DIV_ROUND_UP(nr_irqs, 32)` and `BITS_TO_U64(nr_msis)`. [F94, F95, F97, F127]
- In `aia_imsic.c`, per-EIX bitmaps (`eip`, `eie`, `eipend`) must be `unsigned long[BITS_PER_TYPE(u64) / BITS_PER_LONG]` for 0..63 bitops on `CONFIG_32BIT`. On RV64 (`!CONFIG_32BIT`), reject odd `isel` values for `ISELECT_IPRIO0..15`, `IMSIC_EIP0..63`, and `IMSIC_EIE0..63`. Accessing hardware VS-file `CSR_VSISELECT`/`CSR_VSIREG` in `imsic_vsfile_local_*()` must run on `vsfile_cpu`, set `HSTATUS_VGEIN` in `CSR_HSTATUS` to `hgei`, and restore `CSR_HSTATUS` and `CSR_VSISELECT`. [F96, F138, F152]
- In `aplic_update_irq_range()` and `kvm_riscv_aia_aplic_inject()`, check `(irqd->state & APLIC_IRQ_STATE_ENPEND) == APLIC_IRQ_STATE_ENPEND`. In `aplic_write_pending()`, ignore updates when `SM_INACTIVE`, and ignore setting pending in `LEVEL_HIGH`/`LEVEL_LOW` unless `APLIC_IRQ_STATE_INPUT` matches active polarity. In `aplic_read_input()`, return `false` if `APLIC_SOURCECFG_D` or `SM_INACTIVE`, else XOR `INPUT` with `SM_LEVEL_LOW`/`SM_EDGE_FALL`. [F71, F72, F119]
- In `kvm_arch_vcpu_load/put()` and `kvm_riscv_vcpu_aia_load/put()`, every CSR accessed on `csr_write/read()` must also be updated in the `nacl_csr_write/read()` branch; NACL writes/swaps check `kvm_riscv_nacl_sync_csr_available()` and set `SBI_NACL_SHMEM_DBITMAP_OFFSET`, while reads check `kvm_riscv_nacl_available()`. [F81, F151]
- On VM exit, `kvm_riscv_vcpu_sync_interrupts()` must call `kvm_riscv_vcpu_timer_sync()` when `sstc_enabled`. On vCPU put/load with Sstc, `kvm_riscv_vcpu_timer_save()` sets `CSR_VSTIMECMP[H] = -1UL` and arms `t->hrt` if blocking, and `timer_restore()` restores `CSR_VSTIMECMP[H]` and cancels `t->hrt`. `hrtimer_start()` and `t->next_set = true` must run even when `delta_ns == 0`. [F65, F109, F155]
- Firmware PMU counters have `pmc->cinfo.type == SBI_PMU_CTR_TYPE_FW` (`pmc->perf_event == NULL`), while hardware paths must check `pmc->perf_event != NULL`. In `kvm_riscv_vcpu_pmu_ctr_stop()` with `SBI_PMU_STOP_FLAG_RESET`, call `kvm_pmu_release_perf_event()` without adding `perf_event_read_value()` to `pmc->counter_val`, and clear `pmc->event_idx`, `pmc_in_use`, `pmc_overflown`, and `sdata->ctr_overflow_mask`. [F52, F70]
- `snapshot_addr` and `vcpu->arch.sta.shmem` use `INVALID_GPA` (not `0`) when unconfigured and reset to `INVALID_GPA` on vCPU reset or `SBI_SHMEM_DISABLE` (`-1UL` in low/high regs); `kvm_sbi_sta_steal_time_set_shmem()` must enforce 64-byte alignment (`SZ_64 - 1`) on `shmem_phys_lo`. [F53, F91]
- `gstage_pte_index()` widens the root mask (`level == kvm_riscv_gstage_pgd_levels - 1`) by `1UL << kvm_riscv_gstage_pgd_xbits`. `kvm_riscv_gstage_get_leaf()` must always update `*ptep_level = current_level`, and `kvm_riscv_gstage_unmap/wp_range()` must compute `page_size` from `ptep_level` before jumping to `next:` on `!found_leaf`. [F103, F118]
- G-stage leaf PTEs in `kvm_riscv_mmu_ioremap()` and `kvm_riscv_gstage_map_page()` require user `PAGE_*` protections (not `PAGE_KERNEL_IO`) and `pte_mkdirty()`. With dirty logging on a writable memslot, `kvm_riscv_mmu_map()` must force `vma_pagesize = PAGE_SIZE`, `writable = false` on `!is_write`, and `mark_page_dirty_in_slot()` on writes. [F170, F193]
- Local VVMA flushes (`kvm_riscv_local_hfence_vvma_*`) must swap `CSR_HGATP` to `vmid << HGATP_VMID_SHIFT` around `HFENCE.VVMA`/`HINVAL.VVMA` and restore it. `kvm_riscv_gstage_vmid_update()` must raise `KVM_REQ_UPDATE_HGATP` on all vCPUs when allocating a `vmid`, and `kvm_riscv_gstage_vmid_sanitize()` must flush local G-stage TLBs when `last_exit_cpu != vcpu->cpu`. [F77, F78]
- Modifying `vcpu->arch.isa` must filter through `kvm_riscv_vcpu_isa_enable/disable_allowed()`, preserve `~KVM_RISCV_BASE_ISA_MASK` in `isa[0]`, and call `kvm_riscv_vcpu_fp_reset(vcpu)`. Enabling `SVADU` or disabling `SVADE` requires `arch_has_hw_pte_young()`, and `ENVCFG_ADUE` is set only when `SVADU && !SVADE`. [F73, F140, F150]
- Field order of `kvm_cpu_context` (to `t6`), `kvm_vcpu_csr`, `kvm_vcpu_aia_csr`, and `kvm_vcpu_smstateen_csr` must match UAPI structs, and `ONE_REG` handlers must validate `KVM_REG_SIZE(reg->id)` before `copy_from/to_user()`. CSR, MMIO, and SBI exits must clear `return_handled = 0` on setup and check/set `1` in `*_return()` before advancing `sepc`. `kvm_riscv_vcpu_trap_redirect()` must set `SR_SPP` in `guest_context.sstatus`. [F69, F80, F83, F85]

## Synchronization

- In `kvm_arch_vcpu_ioctl_run()`, blocking helpers (`KVM_REQ_SLEEP`, `kvm_riscv_vcpu_wfi()`) must drop/re-acquire `vcpu->kvm->srcu`. After `local_irq_disable()`, `vcpu->mode = IN_GUEST_MODE` and `smp_mb__after_srcu_read_unlock()` must precede `kvm_riscv_vcpu_flush_interrupts()`, `kvm_riscv_gstage_vmid_ver_changed()`, and `kvm_request_pending()`, then `kvm_riscv_gstage_vmid_sanitize()`; aborting entry must restore `OUTSIDE_GUEST_MODE`, IRQs, preemption, and SRCU. [F7, F8, F39]
- `__kvm_riscv_[nacl_]switch_to()` must stay in `noinstr` `kvm_riscv_vcpu_enter_exit()` between `guest_state_enter/exit_irqoff()` with IRQs disabled, saving `CSR_HTVAL`, `CSR_HTINST`, `CSR_SCAUSE`, `CSR_STVAL`, and `sepc` before `local_irq_enable()`, and transiently enabling/disabling IRQs after `kvm_riscv_vcpu_sync_interrupts()` before `guest_timing_exit_irqoff()`. `kvm_riscv_reset_vcpu()` must bracket put/reset/load with `get_cpu()`/`put_cpu()`. [F6, F157, F158, F159]
- `kvm_riscv_vcpu_set/unset_interrupt()` must update `irqs_pending`, run `smp_mb__before_atomic()`, and `set_bit(irq, irqs_pending_mask)`, pairing with `xchg_acquire(&irqs_pending_mask[i], 0)` on flush. Guest `CSR_HVIP` sync only updates `irqs_pending` if `!test_and_set_bit(irq, irqs_pending_mask)`. ONE_REG `sip` reads must call `kvm_riscv_vcpu_flush_interrupts()`, and `sip`/`siph` writes must zero `irqs_pending_mask[0/1]`. [F37, F38, F74]
- In `kvm_riscv_vcpu_aia_imsic_update()`, clear the new slot's `CSR_HGEIE` bit, zero its VS-file (`imsic_vsfile_local_clear()`), and map G-stage MMIO (`kvm_riscv_mmu_ioremap()`) before publishing `vsfile_*` under `write_lock_irqsave(&imsic->vsfile_lock)`. `imsic_has_interrupt()`, `imsic_put()`, and `imsic_inject()` must hold `read_lock_irqsave(&imsic->vsfile_lock, flags)` while checking `vsfile_cpu >= 0` and accessing the VS-file or `CSR_HGEIP`/`CSR_HGEIE`. [F21, F27]
- Callers of `imsic_vsfile_read/rw()` must drop `imsic->vsfile_lock` and restore IRQs beforehand, and pass `wait = 1` to `on_each_cpu_mask()` (stack buffers). In `kvm_riscv_aia_disable()`, drop `hgctrl->lock` around `kvm_riscv_vcpu_aia_imsic_release(vcpu)`. On blocking, `imsic_put()` sets `BIT(vsfile_hgei)` in `CSR_HGEIE`, and `hgei_interrupt()` / `kvm_riscv_aia_disable()` must clear `CSR_HGEIE` and call `kvm_vcpu_kick()`. [F31, F32, F137, F156]
- While `vsfile_cpu < 0`, active `imsic->swfile` accesses require `imsic_mrif_atomic_*` and atomic bitops; `imsic_swfile_extirq_update()` must hold `raw_spin_lock_irqsave(&imsic->swfile_extirq_lock, flags)` across reading `eidelivery`/`imsic_mrif_topei()` and updating `IRQ_VS_EXT`. In `aplic_update_irq_range()` and `kvm_riscv_aia_aplic_inject()`, check `ENPEND`, clear `PENDING`, and snapshot `target` under `raw_spin_lock_irqsave(&irqd->lock, flags)`, releasing it before `aplic_inject_msi()`. [F28, F33, F41]
- In `kvm_riscv_mmu_map()`, sample `mmu_invalidate_seq` after `vma_lookup()` and before `mmap_read_unlock()` and `__kvm_faultin_pfn()`, and revalidate via `mmu_invalidate_retry()` under `kvm->mmu_lock`. Recheck `kvm_riscv_gstage_vmid_ver_changed(vmid)` under `vmid_lock` in `vmid_update()`. In `make_xfence_request()`, if `vcpu_hfence_enqueue()` returns `false` (queue occupancy tracked via `.type != 0`), use `fallback_req`. [F35, F36, F40, F102]
- In `kvm_sbi_hsm_vcpu_start()`, hold `target_vcpu->arch.mp_state_lock` across `kvm_riscv_vcpu_stopped()`, `kvm_riscv_vcpu_sbi_request_reset()`, and `__kvm_riscv_vcpu_power_on()`. In `kvm_riscv_vcpu_pmu_ctr_cfg_match()`, set `perf_event_attr.disabled = true` before `kvm_pmu_create_perf_event()`. [F20, F29]

## Object Lifetimes

- Call `kvm_exit()` before `kvm_riscv_teardown()` in `riscv_kvm_exit()`. In `kvm_arch_vcpu_create()`, call `kvm_riscv_vcpu_sbi_init()` after ISA, PMU, and AIA init and before `kvm_riscv_reset_vcpu()`. `kvm_riscv_vcpu_sbi_deinit()` must call `ext->deinit(vcpu)` whenever `ext_status[idx] != UNAVAILABLE` (including `DISABLED`). Preserve `cntx->vector.datap` across zeroing `guest_context` in `kvm_riscv_vcpu_context_reset()`. [F1, F3, F4, F5]
- `kvm_riscv_mmu_free_pgd()` must hold `kvm->mmu_lock` while unmapping and clearing `kvm->arch.pgd = NULL`, and MMU notifiers must check `if (!kvm->arch.pgd)`. In `kvm_riscv_gstage_op_pte()` (`GSTAGE_OP_CLEAR`), clear the parent PTE and recursively clear child PTEs before `put_page()`. Once `__kvm_faultin_pfn()` succeeds in `kvm_riscv_mmu_map()`, call `kvm_release_faultin_page()` under `kvm->mmu_lock` on all exit paths. [F9, F10, F12]
- In `kvm_riscv_vcpu_aia_imsic_release()`, reset `vsfile_cpu` and `vsfile_hgei` to `-1` under `vsfile_lock` and call `kvm_riscv_mmu_iounmap()` before reading/clearing the VS-file into `swfile` and calling `kvm_riscv_aia_free_hgei()`. If `kvm_riscv_mmu_ioremap()` fails in `imsic_update()`, free `new_vsfile_hgei` without altering `imsic->vsfile_hgei` or freeing the old HGEI. [F14, F15]
- `kvm_pmu_create_perf_event()` must call `kvm_pmu_release_perf_event(pmc)` (which zeroes `pmc->perf_event`) before creating a new event. `kvm_pmu_clear_snapshot_area()` must only free `kvpmu->sdata`, set `sdata = NULL`, and reset `snapshot_addr = INVALID_GPA` without writing to guest memory. [F17, F18]

## API Contracts

- `KVM_RUN` loop helpers return `> 0` to resume guest, `0` after setting `run->exit_reason` for userspace exit, or `< 0` on error. In-kernel `csr_funcs[]` callbacks return `KVM_INSN_CONTINUE_NEXT_SEPC` without advancing `sepc` or writing `RD`. [F42, F183]
- Every `kvm_vcpu_sbi_extension::handler` must explicitly set `retdata->err_val` on unsupported branches (as `sbi_ret.err_val` starts at `0`) and return `0` for guest SBI errors, traps, or userspace exits (returning `< 0` only to abort `KVM_RUN`); `perf_event_create_kernel_counter()` failure logs with `pr_debug()` and sets `SBI_ERR_NOT_SUPPORTED`. In `kvm_sbi_fwft_feature`, `.set` touches hardware CSRs only when `!one_reg_access`. [F43, F104, F180, F182]
- `vcpu->arch.isa` uses `RISCV_ISA_EXT_*` (`kvm_isa_ext_arr[kvm_ext]`), whereas `kvm_riscv_vcpu_isa_enable/disable_allowed()` take UAPI `KVM_RISCV_ISA_EXT_*`; `riscv_vcpu_get_isa_ext_single()` and `copy_isa_ext_reg_indices()` must check `kvm_riscv_vcpu_isa_check_host()` (mapping guest `SMNPM` to host `SSNPM`). `ext_status[]` and `riscv_vcpu_get_sbi_ext()` take `enum KVM_RISCV_SBI_EXT_ID` (`< KVM_RISCV_SBI_EXT_MAX`), whereas `kvm_vcpu_sbi_find_ext()` takes `SBI_EXT_*`. [F60, F61, F149]
- Static vCPU config writes return `-EBUSY` once `ran_atleast_once` is true (after checking if `reg_val` is unchanged in `set_reg_config()`), and AIA attribute writes return `-EBUSY` once `kvm_riscv_aia_initialized(kvm)` is true. `kvm_riscv_vcpu_copy_reg_indices()` helpers must tolerate `uindices == NULL` and return the `u64` element count. [F82, F110, F134]
- PMU counter index `1` (`CSR_TIME`) is reserved and rejected in `pmu_ctr_read()`, `pmu_fw_ctr_read_hi()`, and `kvm_riscv_vcpu_pmu_ctr_info()`. Call `kvm_pmu_validate_counter_mask()` before `__ffs`/`__fls` or indexing `pmc[]` in `ctr_start/stop/cfg_match()`. Guest PMU requires host `SSCOFPMF` and sets `exclude_host = true`, `exclude_hv = true`, and `config1 = RISCV_PMU_CONFIG1_GUEST_EVENTS`. [F64, F126, F195]
- Pass `in_atomic = true` to `kvm_riscv_mmu_ioremap()` when preemption is disabled, and `may_block = false` to `kvm_riscv_gstage_unmap_range()` in `kvm_riscv_mmu_iounmap()`. `kvm_arch_prepare_memory_region()` must reject GPA overflow (`-EFAULT`), writable memslots on non-`VM_WRITE` VMAs (`-EPERM`), and `VM_PFNMAP` with dirty logging (`-EINVAL`), calling `kvm_riscv_mmu_iounmap()` on error when `change != KVM_MR_FLAGS_ONLY`. [F11, F162, F163, F190]

## Error Handling

- Zero-initialize `struct kvm_cpu_trap` before `kvm_riscv_vcpu_unpriv_read()` (IRQs disabled, `.option norvc`) and check `trap->scause != 0` afterward. On `KVM_PFN_ERR_HWPOISON` in `kvm_riscv_mmu_map()`, call `send_sig_mceerr()` and return `0`. On AIA init failure, reset `aplic_state`/`imsic_state` to `NULL` before freeing and unwind only `< idx` without setting `aia.initialized`. [F13, F47, F55, F175, F192]

## External Contracts

- `kvm_riscv_vcpu_sbi_forward()` must set `return_handled = 0`, `ret[0] = SBI_ERR_NOT_SUPPORTED`, and `ret[1] = 0`; `kvm_riscv_vcpu_sbi_system_reset()` must zero `run->system_event` with `memset()`. In `kvm_sbi_ext_rfence_handler()`, both `(a2 == 0 && a3 == 0)` and `a3 == -1UL` trigger a full flush. Truncate 32-bit SBI args via `lower_32_bits()`/`u32`. Use little-endian conversions on `sbi_sta_struct` and NACL `shmem`, and `__swab32()` on 4-byte aligned `APLIC_SETIPNUM_BE`/`IMSIC_MMIO_SETIPNUM_BE`. [F57, F62, F92, F93, F123, F154, F189]

## Known Pitfalls

- `KVM_DEV_RISCV_AIA_GRP_ADDR` uses `kvm_get_vcpu(kvm, idx)`, whereas `GRP_IMSIC` uses `kvm_get_vcpu_by_id(kvm, vcpu_id)`. Guard `GENMASK_ULL` in `aia_imsic_ppn/hart_index` on non-zero `nr_hart_bits`/`nr_group_bits`. In cross-vCPU SBI/HSM/IPI handlers, operate on `tmp`/`target_vcpu` (checking `stopped` before `blocking` in `get_status`), and when `hbase != -1UL` in IPI/xfence, check `vcpu_id >= hbase`, `hart_bit < __riscv_xlen`, and `hmask ^ sentmask`. [F63, F98, F105, F106, F121, F122]
- In PMU `ctr_start/stop()`, index `sdata->ctr_values` and `ctr_overflow_mask` by bit offset `i` and `pmc[]`/`pmc_in_use`/`pmc_overflown` by `i + ctr_base`; set `.count = 32` in `KVM_RISCV_VCPU_HPMCOUNTER_CSR_FUNCS`; guard `(-pmc->counter_val) & mask` on `counter_val != 0` in `kvm_pmu_get_sample_period()`. Unmatched CSRs in `csr_insn()` trap as illegal unless in `csr_funcs[]`. In `kvm_riscv_vcpu_vreg_addr()`, reject `datap` (`-ENOENT`) and check `reg_size == vlenb`. [F101, F107, F113, F129, F133]
- In NACL helpers, `SBI_NACL_SHMEM_*` and `__offset` are byte offsets on `void *shmem`, while `__count` and `CSR_INDEX` are word indices. Guard `irqs_pending[1]`/`irqs_pending_mask[1]` with `#ifdef CONFIG_32BIT`, widen GPA/PA shifts/masks to 64-bit on RV32, and check `cycles_now < cycles` in `kvm_riscv_delta_cycles2ns()`. Use `__page_val_to_pfn()` in `gstage_pte_page_vaddr()`, `PMD_SIZE`/`PUD_SIZE` for hugepages, `csr_set/clear()` on `CSR_HIE`/`CSR_HVIEN` (gating `IRQ_PMU_OVF` on `SSCOFPMF`), and never clear `CSR_HGATP` in `kvm_arch_vcpu_put()`. [F124, F128, F136, F139, F144, F171, F172, F174]
