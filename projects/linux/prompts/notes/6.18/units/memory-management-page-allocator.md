# MEMORY MANAGEMENT - PAGE ALLOCATOR

This component implements the Linux kernel's zoned buddy page allocator, per-CPU page (PCP) caches, and page fragment allocator (`mm/page_alloc.c`, `mm/page_frag_cache.c`), along with memory compaction (`mm/compaction.c`) and pageblock isolation (`mm/page_isolation.c`) for contiguous allocations, CMA, and hotplug. It also provides per-page metadata extensions (`mm/page_ext.c`), hypervisor free-page reporting (`mm/page_reporting.c`), and tracking facilities (`mm/page_owner.c`, `mm/page_poison.c`).

## Architecture & Data Flow

- Under `CONFIG_TRANSPARENT_HUGEPAGE`, the high-order PCP slot in `order_to_pindex()`, `pindex_to_order()`, and `pcp_allowed_order()` is strictly `HPAGE_PMD_ORDER` (never `pageblock_order`), mapped to `NR_LOWORDER_PCP_LISTS + (migratetype == MIGRATE_MOVABLE)`. When freeing to PCP in `__free_frozen_pages()` and `free_unref_folios()`, `MIGRATE_ISOLATE` must bypass PCP to `free_one_page()`, and `MIGRATE_CMA` / `MIGRATE_HIGHATOMIC` must map to `MIGRATE_MOVABLE`. [F62, F78, F79]
- Buddy freelist mutations under `zone->lock` (`__add_to_free_list`, `move_to_free_list`, `__del_page_from_free_list`) must update `area->nr_free`, `NR_FREE_PAGES_BLOCKS` (for non-isolate `order >= pageblock_order`), and `account_freepages()` in lockstep. In `move_freepages_block()` and `__move_freepages_block_isolate()`, `move_to_free_list()` must run while the pageblock still holds `old_mt` before updating pageblock flags. [F68, F70]
- Every page freed to PCP in `free_frozen_page_commit()` or directly to buddy via `free_one_page()` (including deferred `zone->trylock_free_pages` drains) must increment `PGFREE` by `1 << order` once. In `free_frozen_page_commit()`, `free_high` requires `pcp->free_count >= (batch + pcp->high_min / 2)` alongside `PCPF_PREV_FREE_HIGH_ORDER`, clearing `PCPF_PREV_FREE_HIGH_ORDER` on order-0 or costly-order frees. [F72, F82]
- In `rmqueue_bulk()` and `__rmqueue()`, `enum rmqueue_mode` (`rmqm`) persists across loop iterations under `zone->lock`, resetting to `RMQUEUE_NORMAL` only when `__rmqueue_claim()` succeeds. In `__rmqueue_claim()`, top-down iteration must `break` if `find_suitable_fallback(..., true)` returns `-2` and return `NULL` if `try_to_claim_block()` cannot claim the whole block. [F107, F108]
- `ALLOC_HIGHATOMIC` requires `!(gfp_mask & __GFP_DIRECT_RECLAIM)`, `!(gfp_mask & __GFP_NOMEMALLOC)`, `order > 0`, and `alloc_flags & ALLOC_MIN_RESERVE`. In `rmqueue_buddy()`, `ALLOC_HIGHATOMIC` tries `MIGRATE_HIGHATOMIC` before `__rmqueue()`, whereas `ALLOC_OOM` and `ALLOC_NON_BLOCK` fall back to `MIGRATE_HIGHATOMIC` only after `__rmqueue()` fails. In `reserve_highatomic_pageblock()` / `unreserve_highatomic_pageblock()`, `order >= pageblock_order` pages must update all `1 << (order - pageblock_order)` pageblocks via `change_pageblock_range()`. [F69, F105, F106]
- In `get_page_from_freelist()` and `__alloc_pages_slowpath()`, any `goto retry` that relaxes `ALLOC_NOFRAGMENT` or `skip_kswapd_nodes` must verify the condition is active and clear it first. In `__alloc_pages_slowpath()`, whenever `check_retry_cpuset()` or `check_retry_zonelist()` triggers or `ac->nodemask` is cleared, `ac->preferred_zoneref` must be recalculated via `first_zones_zonelist()`. [F76, F109]
- In `free_unref_folios()`, the first pass compacts `folios->folios[]` in-place (setting `folios->nr = j`) and stashes each folio's order in `folio->private`; the second pass must clear `folio->private = NULL` and drop `pcp` whenever `zone != locked_zone || is_migrate_isolate(migratetype)`. In `free_tail_page_prepare()`, `case 2:` must check `!list_empty(&folio->_deferred_list)` before `out:` clears `page->mapping = NULL`. [F113, F118]
- `compact_zone()` must reinitialize `cc` scan/page counters and `cc->freepages[]` / `cc->migratepages` on entry before any early return, and on exit update `cc->zone->compact_cached_free_pfn` only if `free_pfn > cc->zone->compact_cached_free_pfn`. In `isolate_migratepages_block()` and `has_unmovable_pages()`, advancing a PFN cursor past a `PageHuge` / `PageTransCompound` folio must subtract `folio_page_idx(folio, page)` from `folio_nr_pages(folio)`, and scan loops must clamp the final PFN cursor to `end_pfn`. [F57, F77, F100, F110]
- Each `page_ext` entry has runtime stride `page_ext_size` (not `sizeof(struct page_ext)`). Under `CONFIG_SPARSEMEM`, `section->page_ext` stores `(void *)base - page_ext_size * (pfn & PAGE_SECTION_MASK)` (plus `PAGE_EXT_INVALID`), so `lookup_page_ext()` and `__free_page_ext()` must strip `PAGE_EXT_INVALID` and pass the full `pfn` to `get_entry()`. In `online_page_ext()`, rollback after `fail = true` must set `end = pfn - PAGES_PER_SECTION`. [F53, F119, F132, F134]

## Synchronization

- `zone->lock` nests inside `pcp->lock` with local IRQs disabled; never acquire `pcp->lock` while holding `zone->lock`. `pcp_spin_lock()` / `pcp_spin_trylock()` require `pcpu_task_pin()` / `pcpu_task_unpin()`, and `pcp_spin_trylock()` sections require `pcp_trylock_prepare()` / `pcp_trylock_finish()`. With `FPI_TRYLOCK`, `free_frozen_page_commit()` skips `free_pcppages_bulk()`, and `free_one_page()` uses `spin_trylock_irqsave(&zone->lock, flags)` (deferring to `add_page_to_zone_llist()`) and skips draining `zone->trylock_free_pages`. [F146, F147, F148, F149]
- In `zone_pcp_disable()`, `pcp_batch_high_lock` must be held and `__zone_set_pageset_high_and_batch(zone, 0, 0, 1)` must zero PCP high limits before `__drain_all_pages(zone, true)` until `zone_pcp_enable()`. In `drain_pages_zone()`, `pcp->count` must be read inside `spin_lock(&pcp->lock)` on every loop iteration. [F27, F28]
- In `__free_unaccepted()` and `__accept_page()`, `zone->unaccepted_pages`, `account_freepages(zone, +/-MAX_ORDER_NR_PAGES, MIGRATE_MOVABLE)`, `NR_UNACCEPTED`, and `PageUnaccepted(page)` must be updated under `zone->lock`. Release `zone->lock` before `accept_memory()` or `__free_pages_ok()` in `__accept_page()`, before `accept_page()` or `dump_page()` in `set_migratetype_isolate()`, and before `__alloc_contig_pages()` in `alloc_contig_pages_noprof()`. [F35, F73, F151, F153]
- Lockless PFN scanners reading `PageBuddy(page)` order without `zone->lock` must use `buddy_order_unsafe(page)`, and lockless `compound_order(page)` or `buddy_order_unsafe(page)` reads must verify `order <= MAX_PAGE_ORDER` before shifting `1UL << order`. In `isolate_freepages_block()`, after acquiring `cc->zone->lock`, `PageBuddy(page)` must be rechecked before calling `buddy_order(page)` and `__isolate_free_page()`. [F37, F44, F120]
- In `isolate_migratepages_block()`, save `compound_order(page)` before `isolate_or_dissolve_huge_folio()`; pin `folio` with `folio_get_nontail_page(page)` before `folio_test_clear_lru(folio)`; recheck `skip_isolation_on_order()` whenever `lruvec->lru_lock` is newly acquired; and release `lruvec->lru_lock` before calling `isolate_or_dissolve_huge_folio()`, `isolate_movable_ops_page()`, `folio_put()`, or `putback_movable_pages()`. [F38, F40, F156]
- When `!(cc->gfp_mask & __GFP_FS)`, `isolate_migratepages_block()` must skip folios with non-NULL `folio_mapping(folio)` and `too_many_isolated()` must not scale down `inactive`/`active` by `>> 3`. Inspecting `mapping->a_ops->migrate_folio` or `mapping_inaccessible(mapping)` requires `folio_trylock(folio)` and re-reading `folio_mapping(folio)`. In `has_unmovable_pages()`, inspecting a `PageHuge(page)` folio without `hugetlb_lock` requires `size_to_hstate(folio_size(folio))` and a `NULL` check. [F39, F155, F172]
- `lookup_page_ext()`, `page_ext_lookup()`, `page_ext_iter_begin()`, and `page_ext_iter_next()` require `rcu_read_lock_held()`, and callers of `page_ext_get()` must not sleep before `page_ext_put()` (`read_page_owner()` must call `page_ext_put()` before `print_page_owner()`). `offline_page_ext()` must mark sections with `PAGE_EXT_INVALID` and call `synchronize_rcu()` before `__free_page_ext()`. [F158, F159, F177]
- In `mm/page_owner.c`, `init_page_owner()` must initialize `dummy_stack`, `failure_stack`, and `stack_list` before `static_branch_enable(&page_owner_inited)`. Internal allocations in `save_stack()` and `add_stack_record_to_list()` must set `current->in_page_owner` and filter `gfp_mask` with `gfp_nested_mask()`, while `__reset_page_owner()` must pass `__GFP_NOWARN` (no reclaim flags) to `save_stack()`. [F22, F160, F161]

## Object Lifetimes

- In `___free_pages()`, `PageHead(page)` and `pgalloc_tag_get(page)` must be sampled before `put_page_testzero(page)`. If `put_page_testzero(page)` returns false on a non-compound (`!head`) high-order page, `___free_pages()` must still call `pgalloc_tag_sub_pages(tag, (1 << order) - 1)`, `clear_page_tag_ref()`, and `__free_frozen_pages()` on each trailing power-of-two subpage. [F1, F2]
- In `free_pages_prepare()`, `kernel_poison_pages()`, `kasan_poison_pages()`, and `kernel_init_pages()` must run before `arch_free_page()` and `debug_pagealloc_unmap_pages()`. Conversely, in `post_alloc_hook()`, `arch_alloc_page()`, `debug_pagealloc_map_pages()`, and `kernel_unpoison_pages()` must run before `tag_clear_highpage()`, `kasan_unpoison_pages()`, or `kernel_init_pages()`. [F4, F5]
- Splitting a non-compound high-order page into order-0 pages in `split_page()` or `make_alloc_exact()` must call `split_page_owner(page, order, 0)`, `pgalloc_tag_split(page_folio(page), order, 0)`, and `split_page_memcg(page, order)` alongside `set_page_refcounted()`, with `make_alloc_exact()` computing `nr` via `DIV_ROUND_UP(size, PAGE_SIZE)`. [F7, F128]
- Pages isolated via `__isolate_free_page()` have `PageBuddy` cleared and refcount 0: `release_free_list()` must call `mark_allocated(page, order, __GFP_MOVABLE)` before `__free_pages(page, order)`, and `page_reporting_cycle()` / `page_reporting_process_zone()` must return all isolated pages in `sgl` under `zone->lock` via `page_reporting_drain(prdev, sgl, ..., !err)` even when `prdev->report()` fails. [F10, F20]
- In `alloc_contig_range_noprof()`, once `start_isolate_page_range(start, end, mode)` succeeds, every exit path must call `undo_isolate_page_range(start, end)`, and when `!(gfp_mask & __GFP_COMP)`, extra pages in `[outer_start, start)` and `[end, outer_end)` must be freed via `free_contig_range()`. [F12]
- In `__page_frag_alloc_align()`, refilling `nc` with a fresh page must add the refcount bias via atomic `page_ref_add(page, PAGE_FRAG_CACHE_MAX_SIZE)`, whereas `set_page_count()` is only valid after `page_ref_sub_and_test(page, nc->pagecnt_bias)` reaches zero on a non-`pfmemalloc` page (`encoded_page_decode_pfmemalloc(encoded_page)` pages must be freed via `free_frozen_pages()`). [F13, F42]
- `__set_page_owner()` and `__reset_page_owner()` must adjust `stack_record->count` by `1 << order` (skipping `early_handle` in `__reset_page_owner()`). In `__folio_copy_owner(newfolio, old)`, after copying `old_page_owner->handle` to `newfolio`, `old`'s handle across all `1 << new_page_owner->order` subpages must be overwritten with `new_page_owner->handle`. [F17, F18]

## API Contracts

- `__alloc_frozen_pages_noprof()` and `alloc_frozen_pages_nolock_noprof()` (which rejects `!pcp_allowed_order(order)`, sets `__GFP_NOWARN`, and skips `should_fail_alloc_page()`) return frozen pages (`_refcount == 0`); if `__memcg_kmem_charge_page()` fails, they must free the page with `free_frozen_pages()` (or `__free_frozen_pages(page, order, FPI_TRYLOCK)` in the nolock path), never `__free_pages()`. [F6, F85, F186]
- `alloc_contig_range_noprof()` with `__GFP_COMP` requires `end - start` to be a power of two with `ilog2(end - start) <= MAX_FOLIO_ORDER` and `[outer_start, outer_end)` equal to `[start, end)`. It must call `replace_free_hugepage_folios(start, end)` after migration, and `test_pages_isolated()` must call `wait_for_freed_hugetlb_folios()` before checking `PageBuddy(page)`. [F66, F84, F175]
- `set_pageblock_migratetype()` and `init_pageblock_migratetype()` must never be passed `MIGRATE_ISOLATE`, and `get_pfnblock_bit()` / `set_pfnblock_bit()` / `clear_pfnblock_bit()` only accept standalone bits (`is_standalone_pb_bit(pb_bit)`), whereas multi-bit `MIGRATETYPE_AND_ISO_MASK` flags require `READ_ONCE()` and `try_cmpxchg()` in `__get_pfnblock_flags_mask()` / `__set_pfnblock_flags_mask()`. [F43, F64, F95]
- `__page_frag_alloc_align()` expects a negated power-of-two `align_mask` (`-align` or `~0u`) and aligns `nc->offset` before checking `offset + fragsz > size`; if `offset + fragsz > size` and `fragsz > PAGE_SIZE`, it must return `NULL` without draining or refilling `nc`. Callers must decode `nc->encoded_page` with `encoded_page_decode_virt()` before adding `offset`. [F65, F101, F102]

## Error Handling

- Because `start_isolate_page_range()` isolates the first (`isolate_start`) and last (`isolate_end - pageblock_nr_pages`) pageblocks before looping over interior pageblocks, an interior failure at `pfn` must call both `undo_isolate_page_range(isolate_start, pfn)` and `unset_migratetype_isolate(pfn_to_page(isolate_end - pageblock_nr_pages))`. [F11]
- `find_suitable_fallback()` returns a non-negative `enum migratetype` on success, `-1` when no fallback has pages, and `-2` when `claimable` is true and `should_try_claim_block()` rejects the order; callers must store the result in a signed `int` and test `>= 0`. In `isolate_freepages_block()`, `strict` callers such as `isolate_freepages_range()` must call `release_free_list(cc->freepages)` on failure. [F45, F46]
- In `isolate_migratepages_block()`, `-EBUSY` from `isolate_or_dissolve_huge_folio()` must be reset to `0` before `isolate_fail`, whereas `-ENOMEM` must break out and return `-ENOMEM`. In `alloc_contig_range_noprof()`, `-EBUSY` from `__alloc_contig_migrate_range()` must be overwritten by `replace_free_hugepage_folios()` and `test_pages_isolated()`. [F47, F48]
- `zonelist_zone(ac.preferred_zoneref)` after `prepare_alloc_pages()`, and any `struct stack_record *` from `__stack_depot_get_stack_record()` or `stack->stack_record` in `mm/page_owner.c`, can be `NULL` and must be checked before dereferencing. `free_pages_prepare()` must intercept order-0 `PageHWPoison(page)` pages before `free_page_is_bad()`, call `clear_page_tag_ref(page)`, and return `false`. [F51, F52, F183]

## Known Pitfalls

- In `split_large_buddy()`, the loop over `[pfn, end)` must check `if (pfn == end) break;` before `pfn_to_page(pfn)`. On `CONFIG_SPARSEMEM`, `page_ext_iter_next()` must call `page_ext_lookup(pfn)` whenever `!page_ext_iter_next_fast_possible(pfn)` (`pfn % PAGES_PER_SECTION == 0`). [F96, F135]
- In `page_reporting_cycle()`, `list_for_each_entry_safe(page, next, list, lru)` must reset `next = list_first_entry(list, struct page, lru)` after relocking `zone->lock`, and set `next = page` before breaking on `budget < 0` or `!__isolate_free_page()`. In `fast_find_migrateblock()`, `move_freelist_tail()` must only run immediately before `break`, and in `fast_isolate_freepages()`, `move_freelist_head(freelist, freepage)` must run before `__isolate_free_page()`. [F114, F115, F116]
