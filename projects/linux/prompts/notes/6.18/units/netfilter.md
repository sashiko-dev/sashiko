# NETFILTER

The Netfilter subsystem provides the Linux kernel's packet filtering, network address translation (NAT), connection tracking (`nf_conntrack`), flowtable hardware/software offload (`nf_flow_table`), `nf_tables` (expressions, objects, and set backends), IP sets, Xtables, packet logging, queueing, and SYNPROXY infrastructure across IPv4, IPv6, ARP, bridge, and netdev families.

## Architecture & Data Flow

- `nf_tables` allocates registers in 4-byte (`NFT_REG32_SIZE`) units where `regs->verdict` aliases `regs->data[0..3]`. Writes not a multiple of 4 bytes must zero the trailing bytes of the last 32-bit slot (`nft_reg_store8/16`, `nft_data_copy`, or `dest[len / NFT_REG32_SIZE] = 0` before `skb_copy_bits`/`memcpy`), string writes must use `strscpy_pad()`, and 64-bit register accesses must use `nft_reg_load64()`/`nft_reg_store64()`. [F36, F49, F67, F175, F210]
- In `nf_tables` objects and `struct nft_set_ext`, a set bit in `genmask` marks the entry as *inactive* in that generation, so active checks (`nft_is_active`, `nft_set_elem_active`) must test `!(genmask & mask)`. In `nft_pipapo_lookup` and `nft_pipapo_avx2_lookup`, dataplane lookups on `priv->match` must pass `0` as `genmask` to `pipapo_get_slow`/`pipapo_get_avx2` because new-generation entries exist only in `priv->clone` until `nft_pipapo_commit`. [F79, F182]
- Set element containers (`nft_bitmap_elem`, `nft_rhash_elem`, `nft_hash_elem`, `nft_rbtree_elem`, `nft_pipapo_elem`) must place `struct nft_elem_priv priv` at offset 0 and `struct nft_set_ext ext` last (aligned to `BITS_PER_LONG / 8` with `genmask` at offset 0 for atomic bitops in `nft_set_elem_dead`/`is_dead`), and set `ops.elemsize = offsetof(..., ext)`. Optional `nft_set_ext_*` accessors require `nft_set_ext_exists(ext, id)` first. [F97, F114, F264]
- Set element expiration in control-plane transactional operations (`.insert`, `.deactivate`, `pipapo_gc`, `nft_rbtree_gc`) must be evaluated against `nft_net_tstamp(net)` via `__nft_set_elem_expired()`, whereas dataplane `.lookup`/`.update`/`.get` use live jiffies. `__nft_set_elem_expired` must check both `NFT_SET_EXT_TIMEOUT` existence and `nft_set_ext_timeout(ext)->timeout != 0` (`0` marks permanent elements). [F93, F194]
- In `struct nf_conn`, `nf_conntrack_alloc` only zeroes fields after `__nfct_init_offset` via `memset_after`, and `union nf_conntrack_proto proto` must remain the last member. `ct->timeout` holds a relative duration while `!nf_ct_is_confirmed(ct)` and an absolute `nfct_time_stamp` expiration once confirmed. [F43, F55]
- Every `struct flow_offload_tuple` passed to `flow_offload_lookup` or inserted into `flow_table->rhashtable` must be zero-initialized and keep all key fields before `__hash` (`flow_offload_hash`/`flow_offload_hash_cmp` cover up to `offsetof(..., __hash)`). Flowtable expiration checks (`nf_flow_has_expired`, `flow_offload_fixup_ct` with signed `s32 timeout` clamped to `>= 0`, `nf_flow_offload_stats`) must use signed difference `nf_flow_timeout_delta(timeout)`. [F436, F462, F501, F502]
- In `__nft_set_pktinfo_ipv4_validate()` and `__nft_set_pktinfo_ipv6_validate()`, packet/payload length checks against `skb_len` must subtract `skb_network_offset(pkt->skb)` from `pkt->skb->len` before adding `skb_network_offset(pkt->skb)` to `pkt->thoff`, and IPv6 `thoff` from `ipv6_find_hdr()` must be checked against `U16_MAX` before storing into `u16 pkt->thoff`. [F62, F63]
- In `nft_set_pipapo`, `pipapo_resmap_init[_avx2]()` must zero `res_map[m->f->bsize .. m->bsize_max - 1]`, and `pipapo_refill()` (when `!match_only`) must zero every scanned word `map[k]` before `res_map` and `fill_map` swap. `union nft_pipapo_map_bucket` in `f->mt` stores `{ .to, .n }` on intermediate fields and `struct nft_pipapo_elem *e` only on the last field; `pipapo_drop` must cut rule bits via `bitmap_cut`, compact `f->mt` via `pipapo_unmap` (using `memmove` and subtracting `rulemap[i + 1].n` from `mt[].to` only on non-last fields), and decrement `f->rules`. [F164, F166, F187, F234, F259]
- In `nft_set_rbtree.c`, `NFT_SET_ELEM_INTERVAL_END` nodes carry no timeout extension, so GC of an expired start node in `nft_rbtree_gc_elem` or `nft_rbtree_gc` must also find, deactivate, and erase its preceding end node (using `NFT_GENMASK_ANY` in `nft_rbtree_gc_elem`). In `__nft_rbtree_lookup()`, descending left (`d < 0`) must only set `interval = rbe` if `rbe` is active, unexpired, and not an interval-end sharing the same key as an already recorded start `interval`. [F189, F224]
- Incremental checksum rules: `inet_proto_csum_replace*()` takes `pseudohdr = true` for L3 addresses and `false` for L4 ports or TCP seq/SACK numbers, and header fields must be read before being overwritten in place. UDP checksum updates (`nf_flow_nat_*_udp`, `__udp_manip_pkt`) must rewrite a `0` result to `CSUM_MANGLED_0` and skip updating unchecksummed UDP (`uh->check == 0`, unlike UDPLite). In `nft_payload_set_eval()`, `fsum = skb_checksum()` (after checking `offset + priv->len <= skb->len`) runs before `skb_store_bits()`, whereas `nft_payload_csum_sctp()` runs after; in `nft_payload_l4csum_update()`, `CHECKSUM_COMPLETE` packets must also update `skb->csum`. [F198, F208, F240, F297, F460, F461, F544, F692]

## Synchronization

- `nf_hook_slow` and `nf_hook_slow_list` require standard `rcu_read_lock()` across the entire call so `struct nf_hook_entries` is not freed via `call_rcu`; `nf_hook_egress` must wrap `nf_hook_slow` in `rcu_read_lock()`/`rcu_read_unlock()` even when `rcu_read_lock_bh()` is held, and `nf_hook_ingress` must run under `rcu_read_lock()` and recheck `rcu_dereference(skb->dev->nf_hooks_ingress) != NULL`. `__nf_register_net_hook` and `__nf_unregister_net_hook` must hold `nf_hook_mutex` in sleepable context, and `nf_remove_net_hook` must overwrite removed entries in-place with `accept_all` and `&dummy_ops` using `WRITE_ONCE` while leaving `priv` intact. [F17, F18, F318, F320, F373]
- Lockless conntrack inspection (`nf_ct_should_gc`, `nf_flow_table_extend_ct_timeout`, `ct_seq_show`) must first acquire `refcount_inc_not_zero(&ct->ct_general.use)` and execute `smp_acquire__after_ctrl_dep()` before reading `ct->status` (`nf_ct_is_confirmed(ct)`) or `ct->timeout` (`nf_ct_is_expired(ct)`), and `nf_flow_table_extend_ct_timeout()` must update `ct->timeout` with `cmpxchg()`. Once `nf_ct_is_confirmed(ct)` is true, updates and multi-field reads of `ct->proto.tcp`, `ct->proto.sctp`, and `nf_conn_seqadj` must hold `spin_lock_bh(&ct->lock)`. [F110, F413, F414, F524]
- In `nf_tables`, dataplane set lookups in `nft_set_do_lookup()` must sample `base_seq = nft_base_seq(net)` inside the `do { ... } while` loop before `__nft_set_do_lookup()` and retry on `NULL` while `nft_lookup_should_retry(net, base_seq)` is true; active generation bitmask checks must use `nft_genmask_cur(net)` (`READ_ONCE(net->nft.gencursor)`). `nft_rule_expr_deactivate()` and `nf_tables_deactivate_set()` require `commit_mutex`, and `nf_tables_rule_destroy()`/`nf_tables_chain_destroy()` must run in sleepable context only after `synchronize_rcu()`. [F23, F116, F238]
- In `nft_set_pipapo`, control-plane mutations must operate on `priv->clone`, published to `priv->match` in `nft_pipapo_commit()` via `rcu_replace_pointer()` with the old match freed via `call_rcu(&old->rcu, pipapo_reclaim_match)`. Callers of `pipapo_get_avx2()` must call `local_bh_disable()` and check `irq_fpu_usable()`, and every exit in `pipapo_get_slow()` and `pipapo_get_avx2()` after `__local_lock_nested_bh(&scratch->bh_lock)` must save `scratch->map_index = map_index`, call `kernel_fpu_end()` (in AVX2), and unlock `scratch->bh_lock` (plus `local_bh_enable()` in slow). [F145, F153, F281]
- In `nft_set_rbtree.c`, mutations to `priv->root` must hold `write_lock_bh(&priv->lock)` and `write_seqcount_begin(&priv->count)` (and synchronous `nft_rbtree_gc_elem()` inside `__nft_rbtree_insert()` must use `GFP_ATOMIC` and return `-EAGAIN` if `removed_end` equals cached `rbe_le` or `rbe_ge`). In `nft_set_hash.c`, `nft_rhash_destroy()` must call `cancel_delayed_work_sync(&priv->gc_work)` before `rhashtable_free_and_destroy()`; in `nft_rhash_gc()`, `nft_net->gc_seq` must be checked with `READ_ONCE()` (aborting via `nft_trans_gc_destroy(gc)` if changed) and `nft_trans_gc_catchall_async()` called before `rhashtable_walk_stop(&hti)`. [F157, F160, F190, F278, F279]
- In `nf_nat_core.c`, `nf_ct_nat_ext_add` and `nf_nat_setup_info` must only mutate `ct->ext`, `ct->tuplehash[IP_CT_DIR_REPLY].tuple`, and `ct->status` while `!nf_ct_is_confirmed(ct)`, and `ct->nat_bysource` insertions/deletions in `nf_nat_bysource[h]` must hold `spin_lock_bh(&nf_nat_locks[h % CONNTRACK_LOCKS])` where `h = hash_by_src(&ct->tuplehash[IP_CT_DIR_ORIGINAL].tuple)`. [F580, F582]

## Object Lifetimes

- `nf_ct_get()` returns a borrowed `struct nf_conn *` without incrementing `ct->ct_general.use`, so callers must not pass it to `nf_ct_put()` without first taking a reference. In `nf_conntrack_confirm()`, after `__nf_conntrack_confirm(skb)` returns `NF_ACCEPT`, local `ct` must be reloaded from `skb_nfct(skb)` because clash resolution can replace `skb->_nfct` and free the losing `nf_conn`. [F4, F53]
- `nf_ct_expect_alloc()` sets `exp->use = 1` and `nf_ct_expect_related_report()` takes its own internal references on success, so callers must call `nf_ct_expect_put()` after `nf_ct_expect_related[_report]()` on both success and failure. In NAT helpers (`nf_nat_ftp`, `nf_nat_irc`, `nf_nat_sip_expect`, `nf_nat_sdp_media`), if packet mangling or a paired expectation fails after `nf_nat_exp_find_port` or `nf_ct_expect_related` succeeds, the inserted expectation must be removed with `nf_ct_unexpect_related` before returning `NF_DROP`. [F5, F575]
- `nft_data_init()` with `NFT_DATA_VERDICT` increments `chain->use` for `NFT_JUMP`/`NFT_GOTO`, requiring `nft_data_release(data, desc.type)` on subsequent init failure or teardown. `nft_trans_gc_queue_async()` and `nft_trans_gc_queue_sync()` may queue a full batch and return a new `struct nft_trans_gc *` (or `NULL`), which callers must assign back to `gc` and complete with `*_done()`; in `pipapo_gc()` and `nft_rbtree_gc()`, `nft_trans_gc_queue_sync()` must succeed before deactivating and unlinking each expired element. [F11, F12, F146]
- Both `nft_pipapo_commit()` and `nft_pipapo_abort()` must reset `priv->clone = NULL`. In `nft_pipapo_destroy()`, when `priv->clone` is non-NULL, `nft_set_pipapo_match_destroy()` must be called only on `priv->clone` (never on both `priv->clone` and `priv->match`, which share `nft_pipapo_elem` pointers), and `nft_pipapo_do_walk()`/`nft_set_pipapo_match_destroy()` must skip consecutive rules where `f->mt[r + 1].e == f->mt[r].e`. [F142, F183, F233]
- `flow_offload_alloc(ct)` increments `ct->ct_general.use`, `flow_offload_route_init()` consumes `route->tuple[dir].dst` and sets it to `NULL`, and `flow_offload_add()` does not free `flow` on failure, so callers must free `flow` via `flow_offload_free(flow)` (which drops `flow->ct`, releases `FLOW_OFFLOAD_XMIT_NEIGH`/`XFRM` `dst_cache`, and calls `kfree_rcu(flow, rcu_head)` after `flow_offload_del()` unlinks both tuplehashes). For `NF_FLOW_HW` flows, `nf_flow_offload_gc_step()` must not call `flow_offload_del()` until `NF_FLOW_HW_DYING` and `NF_FLOW_HW_DEAD` are set. [F7, F389, F390, F408, F432, F529]

## API Contracts

- Hook return conventions: `nf_hook()` returns `1` to pass (caller runs `okfn`) and `0` or negative `-ERRNO` when consumed (only supports `NFPROTO_IPV4/IPV6/ARP/BRIDGE`; `NF_HOOK_LIST()` only supports `IPV4/IPV6`). `nf_hook_ingress()` returns `< 0` when consumed/dropped and `>= 0` (`0` no hooks, `1` pass) when `skb` continues. `nf_hook_egress()` returns `skb` on pass or `NULL` when consumed (setting `*rc` to `NET_XMIT_DROP` or `NET_XMIT_SUCCESS`). `NF_DROP_REASON(skb, reason, err)` frees `skb` and requires a positive 16-bit `err`, whereas `NF_DROP_ERR(x)` does not free `skb` and requires a parenthesized negative errno in `[-0x7fff, -1]`. [F3, F26, F27, F29, F80, F361]
- `nf_ct_ext_add()` and `nf_conntrack_alter_reply()` require `!nf_ct_is_confirmed(ct)`, and because `nf_ct_ext_add()` reallocates `ct->ext` via `krealloc()`, any prior pointers from `nf_ct_ext_find()` (`nfct_help(ct)`, `nfct_nat(ct)`) become stale. `nfct_help_data(ct)` dereferences `nf_ct_ext_find(ct, NF_CT_EXT_HELPER)` unchecked (requiring `NF_CT_HELPER_BUILD_BUG_ON` on private size), and `nf_ct_nat_ext_add`/`nfct_nat` can return `NULL`. `nf_ct_set_tcp_be_liberal(ct)` and `nf_conntrack_tcp_established(ct)` require `nf_ct_protonum(ct) == IPPROTO_TCP`, and `nf_ct_seqadj_set` requires `nfct_seqadj(ct) != NULL` before setting `IPS_SEQ_ADJUST_BIT`. [F44, F54, F104, F129, F434, F596]
- Across `nft_set_ops` backends, `->get()` must return `ERR_PTR(-ENOENT)` on a miss, `->lookup()` and `->deactivate()` must return `NULL` on a miss, and `->insert()` returning `-EEXIST` must store the existing `struct nft_elem_priv *` into `*elem_priv`. `.walk()` implementations must not pre-filter elements by `nft_set_elem_active()` (so abort walks can restore deactivated elements with `nft_clear()`), and callers of `.walk()` must initialize `iter.type` (`NFT_ITER_READ` or `NFT_ITER_UPDATE`), `genmask`, `skip`, `count`, `err`, and `fn`. [F169, F171, F172, F195]

## Error Handling

- Verdict and return conventions: L4 conntrack packet/error handlers (`nf_conntrack_*_packet`, `nf_conntrack_inet_error`) must return negated verdicts (`-NF_ACCEPT`, `-NF_REPEAT`) or `NF_DROP` (`0`), never negative errnos; NAT hooks (`nf_nat_ipv[46]_out`, `nf_nat_ipv[46]_local_fn`) must wrap negative errnos from `*_route_me_harder`/`nf_xfrm_me_harder` with `NF_DROP_ERR(err)`; callers of `nf_nat_setup_info` and `__nf_nat_alloc_null_binding` that return errnos must map `NF_DROP` (`0`) to `-ENOMEM` and `NF_ACCEPT` (`1`) to `0`. `nf_ct_seq_adjust`, `nf_ct_sack_adjust`, and `nf_nat_icmp[v6]_reply_translation` return `1` on success and `0` on failure. [F425, F429, F593, F601, F604]
- Because `nft_expr_inner_parse()` selects `type->inner_ops` directly without calling `type->select_ops()`, `inner_ops->init` callbacks (`nft_payload_inner_init()`, `nft_meta_inner_init()`) must explicitly check all mandatory `tb[]` attributes for `NULL`. In `nft_set_pipapo`, `m->scratch` is `struct nft_pipapo_scratch * __percpu *` (dereference `*raw_cpu_ptr(m->scratch)` before NULL-checking), and on the last field in `pipapo_get_slow()`/`pipapo_get_avx2()`, if `e = f->mt[ret].e` is expired or inactive for `genmask`, `pipapo_refill()` must loop (`goto next_match`) rather than returning `e`. [F163, F165, F174]

## Known Pitfalls

- Packet header pointers (`iph`, `ip6h`, `nh`, `tcph`, `udph`, `inside`, `dptr`) derived from `skb->data` must be recomputed after any call that may reallocate `skb->head` (`pskb_may_pull`, `skb_ensure_writable`, `skb_try_make_writable`, `enlarge_skb`, `l4proto_manip_pkt`, `nf_nat_ipv[46]_manip_pkt`, `process_sip_msg`). In `nf_nat_ipv4_manip_pkt` and `nf_nat_ipv6_manip_pkt`, `l4proto_manip_pkt` must be called *before* overwriting `iph->saddr`/`daddr` or `ipv6h->saddr`/`daddr` because `nf_csum_update` reads the pre-NAT L3 addresses from the packet header. [F196, F448, F452, F540, F618, F619, F620]
- `NF_CT_STATE_BIT(ctinfo)`, `XT_CONNTRACK_STATE_BIT(ctinfo)`, and `XT_STATE_BIT(ctinfo)` map `IP_CT_UNTRACKED` (7) to `1 << 2` (aliasing `IP_CT_RELATED`), so callers must check `ct != NULL` (`ctinfo != IP_CT_UNTRACKED`) first. Bitops (`test_bit`, `set_bit`, `clear_bit`) on `ct->status` and `flow->flags` require `IPS_*_BIT` / `enum nf_flow_flags` indices, whereas `&`/`|` require shifted `IPS_*` / `NF_FLOWTABLE_*` masks. `nft_rule_for_each_expr()` advances unconditionally until `nft_expr_last(rule)`, so cleanup paths on partially initialized rules (`nft_rule_expr_deactivate`, `nf_tables_rule_destroy`) must use `nft_expr_more(rule, expr)`. [F81, F363, F520]
