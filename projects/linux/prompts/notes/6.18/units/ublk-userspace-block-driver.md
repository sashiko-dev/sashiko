# UBLK USERSPACE BLOCK DRIVER

The ublk driver exposes a `blk-mq` block device (`/dev/ublkbN`) whose I/O requests are forwarded to a userspace daemon via `io_uring` passthrough commands (`uring_cmd`) on a companion character device (`/dev/ublkcN`). Device lifecycle, parameter configuration, and recovery are controlled through `uring_cmd` operations on `/dev/ublk-control`, while data transfer supports user buffer mapping, `pread`/`pwrite` user copy, and `io_uring` registered `bvec` zero-copy.

## Architecture & Data Flow

- In `struct ublk_io`, `io->cmd` and `io->req` share an anonymous union discriminated by `UBLK_IO_FLAG_ACTIVE` and `UBLK_IO_FLAG_OWNED_BY_SRV`; callers must sample the old member before overwriting the union and flipping those flags in `__ublk_prep_compl_io_cmd()` or `ublk_fill_io_cmd()`. [F53]
- `ublk_need_map_io()` / `ublk_dev_need_map_io()` and `ublk_need_req_ref()` / `ublk_dev_need_req_ref()` are mutually exclusive and must check the exact same feature flags (`UBLK_F_USER_COPY`, `UBLK_F_SUPPORT_ZERO_COPY`, `UBLK_F_AUTO_BUF_REG`) on both `ubq->flags` and `ub->dev_info.flags`. [F65]
- Because on-daemon buffer registrations increment `io->task_registered_buffers` (capped below `UBLK_REFCOUNT_INIT` in `ublk_daemon_register_io_buf()`) instead of `io->ref`, `ublk_sub_req_ref()` must subtract `UBLK_REFCOUNT_INIT - io->task_registered_buffers` and zero `io->task_registered_buffers`, while `ublk_io_release()` decrements it only when `current == io->task`. [F66]
- In `ublk_queue_rq()`, `ublk_prep_req()` must be called with `check_cancel = false` and `ubq->canceling` checked after `ubq->fail_io` and `ubq->force_abort`, so requests reach `__ublk_abort_rq()` without blocking `del_gendisk()`. In `ublk_queue_rqs()`, when `ublk_prep_req(this_q, req, true)` fails, `req` must move to `requeue_list` via `continue` without updating cursor `io` or flushing `submit_list`, and `*rqlist = requeue_list` must be set on exit. [F84, F93]
- On `/dev/ublkcN` release in `ublk_ch_release_work_fn()`, `ublk_reset_ch_dev(ub)` must reset `ub->mm = NULL`, `ub->nr_io_ready = 0`, `ub->unprivileged_daemons = false`, `ub->ublksrv_tgid = -1`, and reinitialize queues before `clear_bit(UB_STATE_OPEN, &ub->state)`. `ublk_queue_reinit()` must preserve `UBLK_IO_FLAG_CANCELED` while clearing other `UBLK_IO_FLAG_*` bits; `ublk_reset_io_flags()` clears `UBLK_IO_FLAG_CANCELED` and `ubq->fail_io` (which shadows `UBLK_S_DEV_FAIL_IO` across all queues) once all slots are fetched. [F50, F59, F60]
- In `ublk_ch_uring_cmd_local()`, once `READ_ONCE(io->task) == current` and `UBLK_IO_FLAG_OWNED_BY_SRV` are verified, `(!!(io->flags & UBLK_IO_FLAG_NEED_GET_DATA)) ^ (_IOC_NR(cmd_op) == UBLK_IO_NEED_GET_DATA)` must be enforced before the command switch. [F90]
- Because `struct ublk_queue` ends with flexible array `struct ublk_io ios[]` of length `queue_depth` (up to 4096), `ub->queue_size` must be `unsigned int` (not `u16`), and `ub->__queues` must be allocated/freed with `kvcalloc()`/`kvfree()` and indexed only via `ublk_get_queue(ub, qid)` with `qid < nr_hw_queues`. Each `ubq->io_cmd_buf` must use `__get_free_pages()`/`free_pages()` so `ublk_ch_mmap()` can map it with `virt_to_phys()` and `remap_pfn_range()`. [F76, F98, F106, F109]
- `io->task` can be `NULL` for unstarted or quiesced slots, and `ub->ub_disk` can be `NULL` before `ublk_ctrl_start_dev()` or after `ublk_detach_disk()`; both must be checked for `NULL` before dereferencing or releasing. [F38]

## Synchronization

- Neither `ublk_uring_cmd_cancel_fn()` nor `ublk_ch_release_work_fn()` may acquire `ub->mutex` until `ublk_set_canceling(ub, true)` has been set under `ub->cancel_mutex` and all inflight requests have been aborted via `ublk_abort_queue()`. `ub->canceling` and `ubq->canceling` must only be modified via `ublk_set_canceling()` under `ub->cancel_mutex`, and setting `canceling` to `true` on a live disk with an open daemon (`ublk_start_cancel()`, `ublk_ctrl_quiesce_dev()`) requires quiescing the request queue across the call. [F21, F132]
- In `ublk_stop_dev()`, if `ublk_nosrv_dev_should_queue_io(ub)` is true on a non-dead device, `ublk_force_abort_dev()` must quiesce the queue, wait for started requests to idle (`ublk_wait_tagset_rqs_idle()`) when live, set `ubq->force_abort`, unquiesce, and kick the requeue list before `del_gendisk()`, and `ublk_cancel_dev()` must run after `del_gendisk()` returns. [F24]
- `ublk_ctrl_start_dev()` and `ublk_ctrl_end_recovery()` must wait on `ub->completion` outside `ub->mutex` before `add_disk()` or setting `UBLK_S_DEV_LIVE` and kicking the requeue list, because `ublk_mark_io_ready()` completes `ub->completion` under `ub->mutex`. [F16]
- In `ublk_ch_release()`, teardown must be deferred to `ub->exit_work` (`ublk_ch_release_work_fn`) and rescheduled until `ublk_check_and_reset_active_ref(ub)` observes every slot's `ref + task_registered_buffers` is `0` or `UBLK_REFCOUNT_INIT` and resets them to `0`. [F19]
- On `UBLK_IO_COMMIT_AND_FETCH_REQ` in `ublk_ch_uring_cmd_local()`, `io->res`, `ublk_fill_io_cmd(io, cmd)`, and `ublk_config_io_buf()` must update `struct ublk_io` before `ublk_need_complete_req()`, `io_buffer_unregister_bvec()`, or `__ublk_complete_rq()` drops the request reference or ends `req`. [F18]
- In `ublk_dispatch_req()`, when `ublk_need_req_ref(ubq)` is true and `UBLK_IO_FLAG_NEED_GET_DATA` is not taken, `ublk_prep_auto_buf_reg()` must initialize `io->ref` to `UBLK_REFCOUNT_INIT` before `ublk_complete_io_cmd()` sets `UBLK_IO_FLAG_OWNED_BY_SRV`, assigns `io->req`, and completes `io->cmd`. [F17]
- `ublk_cancel_cmd()` must not complete an active `io_uring_cmd` if `req && blk_mq_request_started(req) && req->tag == tag`, and must atomically test-and-set `UBLK_IO_FLAG_CANCELED` under `ubq->cancel_lock` before calling `io_uring_cmd_done()`. [F22]
- `ublk_get_disk()` must read `ub->ub_disk` and call `get_device(disk_to_dev(disk))` under `ub->lock` to synchronize with `ublk_detach_disk()`, which sets `ub->dev_info.state = UBLK_S_DEV_DEAD`, `ub->dev_info.ublksrv_pid = -1`, and `ub->ub_disk = NULL` under `ub->lock` before `put_disk(disk)`. `ublk_ch_release_work_fn()` must recheck `ub->ub_disk` after acquiring `ub->mutex`. [F26, F52]
- `ublk_get_device_from_id()` must hold `ublk_idr_lock` across both `idr_find()` and `ublk_get_device()`, and `ublk_ctl_mutex` must be held when modifying `unprivileged_ublks_added` or testing/setting `UB_STATE_DELETED` in `ublk_ctrl_del_dev()`. [F29]
- In `ublk_fetch()`, all error paths after locking `ub->mutex` must jump to `out` to unlock it, and `get_task_struct(current)` and `ublk_mark_io_ready(ub)` must only be called after `ublk_config_io_buf()` succeeds. [F11]
- When `issue_flags & IO_URING_F_UNLOCKED` is set (and `IO_URING_F_CANCEL` is not), `ublk_ch_uring_cmd()` must defer to `io_uring_cmd_complete_in_task(cmd, ublk_ch_uring_cmd_cb)` and return `-EIOCBQUEUED`. In `ublk_ch_uring_cmd_local()`, `UBLK_IO_COMMIT_AND_FETCH_REQ` and `UBLK_IO_NEED_GET_DATA` require `READ_ONCE(io->task) == current`, and `UBLK_IO_NEED_GET_DATA` must run `ublk_get_data()` synchronously. [F128, F131]
- SQE fields on `/dev/ublkcN` (`q_id`, `tag`, `result`, `addr` in `ublk_ch_uring_cmd_local()`, and `cmd->sqe->addr` in `ublk_set_auto_buf_reg()`) must be read once via `READ_ONCE()` before validation. [F30]
- `ublk_belong_to_same_batch()` in `ublk_queue_rqs()` requires both `io_uring_cmd_ctx_handle(io->cmd)` and `io->task` to match across a `submit_list`. In `ublk_timeout()`, `find_vpid()`, `pid_task()`, and `send_sig()` must run inside `rcu_read_lock()` / `rcu_read_unlock()`. [F64, F139]

## Object Lifetimes

- In `__ublk_check_and_get_req()` and `ublk_check_and_get_req()`, `ublk_get_req_ref(io)` (`refcount_inc_not_zero(&io->ref)`) must be acquired before checking `blk_mq_request_started(req)` and `req->tag == tag`, and every validation failure or post-operation exit path (including in `ublk_register_io_buf()`) must release it via `ublk_put_req_ref(io, req)`. [F7]
- In `ublk_ctrl_start_dev()`, `ublk_get_device(ub)` must be called before `ublk_revalidate_disk_zones()` and `add_disk(disk)`, and on failure of either, must unwind via `ublk_detach_disk(ub)`, `ublk_put_device(ub)`, and `put_disk(disk)`, since `ublk_free_disk()` owns that reference once `add_disk()` succeeds. [F119]
- `ublk_ctrl_del_dev()` must call `ublk_put_device(ub)` and set `*p_ub = NULL` before waiting on `ublk_idr_wq` for `ublk_idr_freed(idx)`, but leave `*p_ub` intact if `mutex_lock_killable(&ublk_ctl_mutex)` fails. [F2]
- In `ublk_remove()` and `ublk_exit()`, `ublk_stop_dev(ub)` must run before `cdev_device_del()`, `ub->dev_info.flags & UBLK_F_UNPRIVILEGED_DEV` must be read before `ublk_put_device(ub)` when decrementing `unprivileged_ublks_added` (incremented in `ublk_add_chdev()` only after `cdev_device_add()` succeeds), and `ublk_exit()` must remove all IDR devices before unregistering `ublk_chr_class` and `ublk_misc`. [F5, F123]
- In `ublk_report_zones()`, stack-allocated `desc` inserted via `ublk_zoned_insert_report_desc(req, &desc)` must be removed with `ublk_zoned_erase_report_desc(req)` on every exit path, including `blk_rq_map_kern()` failure. In `ublk_copy_io_pages()`, `pg_buf` must be unmapped with `kunmap_local()` before `bv_buf`, and `ublk_copy_user_pages()` must `put_page()` all pinned pages. [F14, F110]

## API Contracts

- In `ublk_ch_uring_cmd_local()` and `ublk_ch_uring_cmd_cb()`, an `io_uring_cmd` armed via `ublk_prep_cancel()` must return `-EIOCBQUEUED`; any other return value completes it immediately via `io_uring_cmd_done()`. All `io_uring_cmd_done()` callers must forward `issue_flags`, and `ublk_cancel_queue()` must pass `IO_URING_F_UNLOCKED`. [F33, F129]
- In `ublk_dispatch_req()`, if `current != io->task` or `current->flags & PF_EXITING`, the driver must abort/requeue `req` via `__ublk_abort_rq()` and return without mapping user pages or completing `io->cmd`. [F150]
- On every `UBLK_IO_FETCH_REQ`, `ublk_mark_io_ready()` must check `capable(CAP_SYS_ADMIN)` and set `ub->unprivileged_daemons = true` if any task lacks privilege, so `ublk_ctrl_start_dev()` sets `GD_SUPPRESS_PART_SCAN` before `add_disk()`. [F143]
- `ublk_check_and_get_req()` must require `UBLK_F_USER_COPY` and `user_backed_iter(iter)`, validate `ublk_check_ubuf_dir(req, dir)`, and hold `io->ref` across `ublk_copy_user_pages()`, whereas `ublk_register_io_buf()` and `ublk_daemon_register_io_buf()` must require `UBLK_F_SUPPORT_ZERO_COPY`. [F85, F155]
- Under `ub->mutex`, `ublk_ctrl_set_params()` must reject updates with `-EACCES` if `UB_STATE_USED` is set, mask `ub->params.types` with `UBLK_PARAM_TYPE_ALL`, and reset `ub->params.types = 0` if `ublk_validate_params(ub)` fails. `ublk_validate_params()` requires `UBLK_PARAM_TYPE_BASIC` (`9 <= logical_bs_shift <= PAGE_SHIFT`, `logical_bs_shift <= physical_bs_shift`), rejects `UBLK_PARAM_TYPE_DEVT`, and for zoned devices rejects `p->chunk_sectors == 0` before `ublk_dev_param_zoned_validate()` / `ublk_get_nr_zones()`. [F74, F101, F126]

## Error Handling

- Once `ublk_add_chdev(ub)` calls `device_initialize(&ub->cdev_dev)` (`dev->release = ublk_cdev_rel`), its failure path calls `put_device(dev)` which frees tag set, queues, dev number, and `ub`; `ublk_ctrl_add_dev()` must jump to `out_unlock` on `ublk_add_chdev()` failure. [F39]
- On `UBLK_IO_NEED_GET_DATA` in `ublk_ch_uring_cmd_local()`, `ublk_fill_io_cmd()` and `ublk_config_io_buf()` must run before `ublk_get_data()`, and `__ublk_prep_compl_io_cmd()` must only run if `ublk_get_data()` returns `true`. [F54]
- In `__ublk_complete_rq()`, requests other than `REQ_OP_READ`, `REQ_OP_WRITE`, or `REQ_OP_DRV_IN` must jump directly to `blk_mq_end_request(req, res)` without calling `ublk_unmap_io()` or `blk_update_request()`. [F91]
- Validation failures in `ublk_ch_uring_cmd_local()` (including `ublk_check_fetch_buf()` and `ublk_check_commit_and_fetch()`) jumping to `out:` after `ublk_check_cmd_op()` sets `ret = 0` must set a negative errno. `ublk_setup_iod()`, `ublk_setup_iod_zoned()`, `ublk_prep_req()`, and `ublk_queue_rq()` return `blk_status_t`, while `ublk_alloc_dev_number()` returns `< 0` on error and `>= 0` on success. [F31, F34, F42]

## External Contracts

- In `ublk_ctrl_add_dev()`, `queue_depth` (`1..UBLK_MAX_QUEUE_DEPTH`), `nr_hw_queues` (`1..UBLK_MAX_NR_QUEUES`), and `header->dev_id == info.dev_id` (`U32_MAX` or `< UBLK_MAX_UBLKS`) must be validated before allocation. `ub->dev_info.flags` must be masked with `UBLK_F_ALL` and stripped of `UBLK_F_NEED_GET_DATA` when user-copy, zero-copy, or auto-buf-reg is set, before `ublk_init_queues()` caches `ubq->flags`. [F71, F72, F124]
- In `ublk_ctrl_add_dev()`, `UBLK_F_UNPRIVILEGED_DEV` must clear `UBLK_F_USER_RECOVERY` and `UBLK_F_USER_RECOVERY_REISSUE` and reject `UBLK_F_USER_COPY`, `UBLK_F_SUPPORT_ZERO_COPY`, and `UBLK_F_AUTO_BUF_REG` with `-EINVAL`, while `ublk_dev_is_zoned(ub)` requires `CONFIG_BLK_DEV_ZONED` and `UBLK_F_USER_COPY` or `UBLK_F_SUPPORT_ZERO_COPY`. [F125]
- In `ublk_ch_uring_cmd_local()`, `UBLK_IO_UNREGISTER_IO_BUF` must be dispatched before checking `q_id`, `tag`, or `io->task`, and `UBLK_IO_FETCH_REQ` before checking `READ_ONCE(io->task) != current`. [F89]
- In `ublk_check_fetch_buf()` and `ublk_check_commit_and_fetch()`, when `!ublk_dev_need_map_io(ub)`, non-zero `addr` must be rejected except on `UBLK_IO_COMMIT_AND_FETCH_REQ` for `REQ_OP_ZONE_APPEND`; when `ublk_dev_need_map_io(ub)` is true, `buf_addr == 0` is allowed only if `ublk_dev_need_get_data(ub)` is enabled and `req_op(io->req) != REQ_OP_READ` on commit. [F81, F87]
- UAPI validation (`ublk_check_cmd_op()`, `ublk_ctrl_uring_cmd()`, `ublk_ctrl_quiesce_dev()`, `ublk_ctrl_start_dev()`, `ublk_dev_param_zoned_validate()`) must return `-EOPNOTSUPP` (not `-ENOTSUPP`), and `ublk_check_cmd_op()` must reject `_IOC_TYPE(cmd_op) != 'u'` (allowing `0` only if `CONFIG_BLKDEV_UBLK_LEGACY_OPCODES`). [F32, F86]
- For unprivileged control commands (or `UBLK_CMD_GET_DEV_INFO2`), `ublk_ctrl_uring_cmd_permission()` must verify via `ublk_char_dev_permission()` that `header->addr` is a char device with `stat.rdev == ub->cdev_dev.devt` and `inode_permission()` before stripping `dev_path_len`. In `ublk_open()`, `UBLK_F_UNPRIVILEGED_DEV` requires `CAP_SYS_ADMIN` or matching `owner_uid`/`owner_gid` from `ublk_store_owner_uid_gid()`. [F145, F146]
- `ublk_ch_mmap()` must reject `VM_WRITE`, require `current->mm == ub->mm`, and verify `sz == ublk_queue_cmd_buf_size(ub)` and `phys_off` bounds. On `pread`/`pwrite`, `ki_pos - UBLKSRV_IO_BUF_OFFSET` packs `buf_off`, `tag`, and `q_id`, which must be bounded against `nr_hw_queues`, `queue_depth`, and `blk_rq_bytes(req)`. [F78, F153]

## Known Pitfalls

- Any `switch (_IOC_NR(cmd_op))` or `_IOC_NR(cmd_op)` comparison in `ublk_ctrl_uring_cmd()`, `ublk_ctrl_uring_cmd_permission()`, and `ublk_ch_uring_cmd_local()` must match raw command numbers (`_IOC_NR(UBLK_U_...)` or `UBLK_CMD_*` / `UBLK_IO_*`), not 32-bit `UBLK_U_*` constants. [F44]
- In `ublk_handle_auto_buf_reg()`, `io->buf.index` must be saved to `*buf_idx` (only if `io->buf_ctx_handle == io_uring_cmd_ctx_handle(cmd)`) and `UBLK_IO_FLAG_AUTO_BUF_REG` cleared before `ublk_set_auto_buf_reg()` overwrites `io->buf`. [F57]
- In `ublk_cmd_list_tw_cb()`, `rq->rq_next` must be saved and cleared to `NULL` before `ublk_dispatch_req()`. `ublk_dev_ready()` must cast `nr_hw_queues` to `u32` before multiplying by `queue_depth`, and `ublk_auto_buf_reg_to_sqe_addr()` must cast `flags`, `reserved0`, and `reserved1` to `__u64` before shifting. [F92, F99, F100]
