# INTEL TOUCH HOST CONTROLLER (THC) DRIVER

The Intel Touch Host Controller (THC) driver subsystem provides PCI and hardware abstraction layers for touch devices connected over Intel's THC controller using HID-over-I2C (QuickI2C) and HID-over-SPI (QuickSPI) protocols. It consists of a shared hardware/DMA core module (`intel-thc`) managing MMIO regmap access, PIO transfers, scatter-gather PRD table DMA rings, interrupt handling, and Wake-on-Touch (WoT), paired with two PCI client drivers (`intel-quicki2c` and `intel-quickspi`) that implement protocol state machines and register `hid_ll_driver` interfaces.

## Architecture & Data Flow
- RxDMA/SwDMA ring pointers (`TPCRP`, `TPCWP`) store a wraparound bit in `THC_POINTER_WRAPAROUND` (`0x80`) and the 7-bit table index in `THC_POINTER_MASK` (`GENMASK(6, 0)`). `is_dma_buf_empty()` requires masked indices to match while raw pointers differ, so `dma_set_start_bit()` must set `TPCWP` to `0x80` after `thc_reset_dma_settings()` resets `TPCRP` to 0, `thc_dma_read()` must mask `write_ptr` with `THC_POINTER_MASK`, and `update_write_pointer()` must wrap `0x10` (`THC_WRAPAROUND_VALUE_ODD`) to `0x80` and `0x90` (`THC_WRAPAROUND_VALUE_EVEN`) to `0` (`PRD_TABLES_NUM` = 16). [F51, F90, F91]
- In `thc_dma_read()`, after `read_dma_buffer()` copies from `read_config->sgls[prd_table_index]`, `thc_copy_one_sgl_to_prd()` must reinitialize `read_config->prd_tbls[prd_table_index]` (restoring lengths and clearing `hw_status` and `end_of_prd`) before `update_write_pointer()` advances the hardware write pointer. [F50]
- In `thc_copy_one_sgl_to_prd()` and `write_dma_buffer()`, every populated `struct thc_prd_entry` must store `sg_dma_address(sg) >> THC_ADDRESS_SHIFT` in `dest_addr` and set `end_of_prd = 1` on the final entry (0 on preceding entries); `write_dma_buffer()` rewrites `write_config->prd_tbls[0].entries` in place for `buf_len` and updates the 0-based hardware entry count via `dma_set_prd_control(dev, i, 0, write_config)`. [F53, F92, F122]
- Scatterlist entries per PRD table must not exceed `PRD_ENTRIES_NUM` (`16`), and every `struct thc_prd_entry` except the last (`end_of_prd = 1`) must have `len` as a multiple of `SZ_4K`: `dma_set_max_packet_size()` must round `max_packet_size` up with `ALIGN(size, SZ_4K)` before `setup_dma_buffers()`, and `calc_prd_entries_num()` must enforce `DIV_ROUND_UP(mes_len, THC_MIN_BYTES_PER_SG_LIST_ENTRY) <= PRD_ENTRIES_NUM`. [F70, F88, F129]
- A `struct thc_dma_configuration` channel has `is_enabled == false` and NULL `prd_tbls`/`sgls` unless `thc_dma_set_max_packet_sizes()` set a non-zero packet size before `thc_dma_allocate()`; per-channel DMA helpers must check `config->is_enabled`, and `dma_set_prd_base_addr()` must program `prd_tbls_dma_handle` (never the virtual address `prd_tbls`). [F36, F130]
- `thc_swdma_read_start()` must quiesce interrupts (`thc_interrupt_quiesce()`), pause `THC_RXDMA1`/`THC_RXDMA2` (`thc_wait_for_dma_pause()`), call `thc_reset_dma_settings()`, and disable I2C Rx max-size and interrupt-delay features while saving their states in `dev->dma_ctx->rx_max_size_en` and `rx_int_delay_en`; `thc_swdma_read_completion()` must pause `THC_SWDMA`, reset DMA settings, restore both features from `dev->dma_ctx`, restart `THC_RXDMA2`, and unquiesce interrupts. [F4, F52]
- `qcdev->ddata` is NULL for Lunar Lake PCI IDs in `quicki2c_pci_tbl`, so any access to `qcdev->ddata` or call to `quicki2c_dma_adv_enable()` / `quicki2c_dma_adv_disable()` must check `if (qcdev->ddata)`. Also, `qsdev->driver_data` and `qcdev->ddata` point to shared static structs, so per-device ACPI overrides must be stored in `qsdev->spi_packet_size`, `qcdev->i2c_max_frame_size`, and `qcdev->i2c_int_delay`. [F33, F59]
- In `thc_i2c_subip_init()`, `THC_I2C_IC_ENABLE_ENABLE` in `THC_I2C_IC_ENABLE_OFFSET` must be cleared before programming `THC_I2C_IC_TAR_OFFSET` / `THC_I2C_IC_CON_OFFSET` and re-enabled afterward, and `THC_I2C_IC_ENABLE_OFFSET` must remain the last entry of `i2c_subip_regs` so `thc_i2c_subip_regs_restore()` enables the controller last. [F54]
- In `quickspi_probe()` and `quickspi_restore()`, `reset_tic()` must run after `thc_interrupt_config()` sets `THC_BITMASK_INVALID_TYPE_DATA` and before `thc_dma_configure()` sets `THC_BITMASK_INTERRUPT_TYPE_DATA`; inside `reset_tic()`, `thc_int_trigger_type_select(qsdev->thc_hw, false)` must set level-triggered mode before `acpi_tic_reset()` and restore edge-triggered mode (`true`) before `thc_tic_pio_read()` drains the reset response. [F56, F57]
- `qcdev->state` must be set to `QUICKI2C_ENABLED` and `qsdev->state` to `QUICKSPI_ENABLED` only after `quicki2c_hid_probe()` or `quickspi_hid_probe()` sets `hid_dev`, and `qsdev->state` must be restored to `QUICKSPI_ENABLED` at the end of `quickspi_restore()` after `reset_tic()` sets `QUICKSPI_RESET`. [F105]
- In `handle_input_report()`, `pkt->len` from `struct hidi2c_report_packet` must be checked for zero (and skipped as a reset response) before evaluating `HIDI2C_DATA_LEN(le16_to_cpu(pkt->len))` to avoid underflowing `sizeof(__le16)`. [F74]

## Synchronization
- Every synchronous bus transfer entry point (`thc_tic_pio_read()`, `thc_tic_pio_write()`, `thc_tic_pio_write_and_read()`, `thc_i2c_subip_pio_read()`, `thc_i2c_subip_pio_write()`, `thc_swdma_read()`, and `thc_dma_write()`) must acquire `dev->thc_bus_lock` via `mutex_lock_interruptible()` and unlock it on all return paths; `thc_dma_write()` must hold it across `write_dma_buffer()`, `wait_event_interruptible_timeout(dev->write_complete_wait, ...)`, and `thc_dma_write_completion()`. [F5, F15]
- `thc_interrupt_handler()`, `quicki2c_irq_thread_handler()`, and `quickspi_irq_thread_handler()` must never acquire `dev->thc_bus_lock` before waking `dev->swdma_complete_wait` or `dev->write_complete_wait`, because `thc_swdma_read()` and `thc_dma_write()` sleep on those waitqueues while holding `dev->thc_bus_lock`. [F16]
- `quicki2c_irq_quick_handler()` and `quickspi_irq_quick_handler()` must disable global THC interrupts via `thc_interrupt_enable(thc_hw, false)` before returning `IRQ_WAKE_THREAD`, and the threaded handlers must re-enable them after `thc_interrupt_handler()` clears status bits; `thc_regmap_cfg` must keep `.fast_io = true` and `thc_regmap_read()`/`thc_regmap_write()` must not sleep because `thc_interrupt_enable()` runs in hardirq context. [F123, F126]
- `quicki2c_reset()` must set `qcdev->reset_ack = false` and `qcdev->state = QUICKI2C_RESETING` before calling `write_cmd_to_txdma(qcdev, HIDI2C_RESET, ...)`; in QuickSPI, `reset_tic()` must set `qsdev->state = QUICKSPI_RESETING` and `qsdev->reset_ack = false` before `thc_interrupt_quiesce(qsdev->thc_hw, false)` and transition `qsdev->state` to `QUICKSPI_RESET` before `quickspi_get_device_descriptor()`. [F19, F20]
- `quickspi_suspend()` must call `quickspi_set_power(qsdev, HIDSPI_SLEEP)` before quiescing/disabling interrupts and unconfiguring DMA, and `quickspi_resume()` must re-enable interrupts (`thc_interrupt_enable()`), configure DMA (`thc_dma_configure()`), and unquiesce interrupts (`thc_interrupt_quiesce()`) before calling `quickspi_set_power(qsdev, HIDSPI_ON)`. [F24]

## Object Lifetimes
- During DMA teardown and error rollback (`quicki2c_dma_deinit()`, `quickspi_dma_init()`, `quickspi_dma_deinit()`), `thc_dma_unconfigure()` must be called before `thc_dma_release()` so DMA engines are stopped and PRD base registers cleared before unmanaged scatterlists (`sgl_alloc()`, `dma_map_sg()`) and coherent PRD tables (`dma_alloc_coherent()`) are freed. [F1, F109]
- In `quicki2c_remove()`, `quickspi_remove()`, `quicki2c_shutdown()`, and `quickspi_shutdown()`, the HID device must first be unregistered (in remove, via `*_hid_remove()`), then DMA stopped via `*_dma_deinit()`, and finally hardware deinitialized via `*_dev_deinit()` (which in `quicki2c_dev_deinit()` must call both `thc_interrupt_enable(qcdev->thc_hw, false)` and `thc_interrupt_quiesce(qcdev->thc_hw, true)`). [F9, F106, F108]
- Every `pm_runtime_resume_and_get()` call in `quicki2c_irq_thread_handler()`, `quickspi_irq_thread_handler()`, `quicki2c_hid_raw_request()`, and `quickspi_hid_raw_request()` must be paired with `pm_runtime_mark_last_busy()` and `pm_runtime_put_autosuspend()` on all paths after a zero return; `quicki2c_probe()` and `quickspi_probe()` must call `pm_runtime_put_noidle()` and `pm_runtime_put_autosuspend()` only after all failable steps succeed, balanced by `pm_runtime_get_noresume()` in `*_remove()`. [F6, F7]
- `thc_i2c_subip_init()` must succeed before `thc_i2c_subip_regs_save()` or `thc_i2c_subip_regs_restore()` is called, because both unconditionally dereference `dev->i2c_subip_regs` allocated at the end of `thc_i2c_subip_init()`. [F11]

## API Contracts
- Despite kernel-doc comments claiming NULL on failure, `thc_dev_init()`, `quicki2c_dev_init()`, and `quickspi_dev_init()` return `ERR_PTR`-encoded errors; callers must check `IS_ERR()`, and `*_probe()` must jump to `disable_pci_device` before `pci_set_drvdata()` or `*_dev_deinit()`. Conversely, `thc_dma_init()` and `devm_kzalloc()` in `thc_i2c_subip_init()` return NULL on failure and must be checked for `!ptr` (returning `-ENOMEM`), never passed to `PTR_ERR()`. [F27, F28, F29]
- `read_dma_buffer()` returns positive `mes_len` on success or negative errno on failure; `thc_dma_read()` must store it in a signed `int`, treat `status <= 0` as `-EIO`, guard `*read_finished` with `if (read_finished)`, and leaves `*read_len` unmodified when `is_dma_buf_empty()` is true on entry (so callers like `quicki2c_get_report()` must initialize `read_len`). Because `thc_rxdma_read()` reads at most one PRD table per call, callers must loop on `while (!read_finished)` and break immediately on error. [F31, F35, F39, F79]
- `quicki2c_get_report()`, `quicki2c_set_report()`, `quickspi_get_report()`, and `quickspi_set_report()` are returned directly from `hid_ll_driver.raw_request` and must return the positive transferred byte count (`buf_len` or `qsdev->report_len`) on success and a negative errno on failure. [F30]
- `thc_interrupt_handler()` returns a positive bitmask of `BIT(enum thc_int_type)` flags (setting `BIT(THC_UNKNOWN_INT)` when no status bit matched) rather than 0 or a negative errno, and only returns early on `THC_NONDMA_INT`, `THC_TXN_ERR_INT`, or `THC_FATAL_ERR_INT` (falling through on all DMA/PIO bits). [F32, F81]
- In `thc_swdma_read()` and `thc_swdma_read_start()`, `prd_tbl_len` may be NULL (when `THC_M_PRT_RPRD_CNTRL_SW_THC_SWDMA_I2C_RX_DLEN_EN` is used), so `thc_swdma_read_start()` must check `if (prd_tbl_len)` before dereferencing; also `write_len` must be at most `2 * sizeof(u32)` (8 bytes) to fit `DATA0` and `DATA1`. [F34, F72]
- `thc_i2c_rx_max_size_enable()` and `thc_i2c_rx_int_delay_enable()` return `-EOPNOTSUPP` if `dev->i2c_max_rx_size` or `dev->i2c_int_delay_us` is 0, so callers must first call `thc_i2c_set_rx_max_size()` or `thc_i2c_set_rx_int_delay()`; `thc_i2c_set_rx_int_delay()` takes microseconds (dividing by 10), so `quicki2c_dma_adv_enable()` must multiply `qcdev->i2c_int_delay` (10-us units from ACPI `ISUB.INDV`) by 10. [F40, F41]
- `thc_spi_read_config()` and `thc_spi_write_config()` expect `spi_rd_mps` and `spi_wr_mps` in 16-byte hardware units (`qsdev->spi_packet_size`, unlike `thc_dma_set_max_packet_sizes()` which takes bytes), and `thc_spi_write_config()` expects `perf_limit` in 10-us units because `thc_ensure_performance_limitations()` multiplies `dev->perf_limit` by 10 for `udelay()`. [F42, F43]
- Because `THC_PORT_TYPE_SPI` is 0, a new `struct thc_device` defaults to SPI mode; for I2C devices, `thc_port_select(dev, THC_PORT_TYPE_I2C)` must be called before `thc_interrupt_config()` or `thc_tic_pio_*()`. Also, all `thc_*_pio_*()` helpers take `u32 *buffer` but expect their size arguments in bytes. [F46, F100]
- Callers of `quicki2c_acpi_get_dsm_property()`, `quicki2c_acpi_get_dsd_property()`, and `thc_acpi_get_property()` must pass the address of a `u32` as `prop_buf` when `type == ACPI_TYPE_INTEGER` (since they write `*(u32 *)prop_buf`), and a buffer at least as large as `obj->buffer.length` when `type == ACPI_TYPE_BUFFER` (since they `memcpy()` without a destination size bound); `*_dsm_property()` and `thc_acpi_get_property()` must free `obj` with `ACPI_FREE(obj)`. [F10, F64, F98]
- In `quicki2c_get_report()`, `HIDI2C_DATA_LEN(le16_to_cpu(rpt->len))` must equal `buf_len` and `rpt->data[0]` must equal `reportnum` before `memcpy(buf, rpt->data, buf_len)`; in `quicki2c_init_write_buf()`, total encoded frame length `buf_len` (including headers) must not exceed `write_buf_len` (`qcdev->report_len`). [F140, F141]

## Error Handling
- In `setup_dma_buffers()`, `config->sgls` and `config->sgls_nent` must be zeroed with `memset()` before the `sgl_alloc()` loop, and `thc_copy_sgls_to_prd()` must zero `config->prd_tbls` before populating entries, so `release_dma_buffers()` skips unallocated scatterlists on error and unused PRD fields are 0. [F38]

## External Contracts
- `struct quicki2c_subip_acpi_parameter` and `struct quicki2c_subip_acpi_config` must retain their trailing `u8 reserved` padding (and `__packed` on `quicki2c_subip_acpi_parameter`) so their sizes cover the full `ICRS` and `ISUB` ACPI buffers copied by `quicki2c_acpi_get_dsd_property()`, which must pass NULL for `external_params` to `acpi_evaluate_object()`. [F63, F115]
- In `quickspi_set_report()`, `buf + 1` and `buf_len - 1` must be passed to `write_cmd_to_txdma()` because `output_hdr.content_id` carries `buf[0]`, whereas `quickspi_handle_input_data()` must add `sizeof(body_hdr->content_id)` to `input_len` and start at `input_body->content - sizeof(body_hdr->content_id)`. In HID-over-I2C, wire `len` includes its own 2-byte `HIDI2C_LENGTH_LEN`, so `quicki2c_init_write_buf()` adds `HIDI2C_LENGTH_LEN` and readers subtract it via `HIDI2C_DATA_LEN()`. [F96, F97]

## Known Pitfalls
- In `struct quicki2c_device`, `qcdev->report_len` holds the allocated capacity of `qcdev->report_buf` set in `quicki2c_alloc_report_buf()` and must never be overwritten with per-transfer lengths, whereas in `struct quickspi_device`, `qsdev->report_len` holds the transient received report length set in `quickspi_handle_input_data()` for `quickspi_get_report()`. [F60]
- In `thc_i2c_subip_regs_save()` and `thc_i2c_subip_regs_restore()`, the file-scope array `i2c_subip_regs[i]` holds register offsets while `dev->i2c_subip_regs[i]` holds saved register values; do not swap the `address` and `buffer` arguments passed to `thc_i2c_subip_pio_read()` or `thc_i2c_subip_pio_write()`. [F86]
- `quicki2c_alloc_report_buf()` must size `input_buf` to `max(max_input_len, SZ_4K)` and replace a zero `dev_desc.max_output_len` with `cpu_to_le16(SZ_4K)` before `quicki2c_dma_init()`; `quickspi_alloc_report_buf()` must size `qsdev->input_buf` to `max(rep_desc_len, max_input_len)` because `quickspi_irq_thread_handler()` reads both report descriptors and input reports into `qsdev->input_buf`. [F102, F113]
