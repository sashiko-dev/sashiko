# USER DATAGRAM PROTOCOL (UDP)

Implements the User Datagram Protocol (UDP) and shared UDP-Lite transport layer over IPv4 and IPv6. It manages socket port allocation, 1-tuple/2-tuple/4-tuple socket hash tables (`udp_table`), lockless and corked datagram transmission (`udp_sendmsg`, `udpv6_sendmsg`), NUMA-aware lockless producer queueing and split receive queues (`reader_queue` and `sk_receive_queue`), early demux, UDP tunnel encapsulation hooks, GSO/GRO segmentation and checksum offloads, and `/proc/net/udp[6]` plus BPF socket iterators.

## Architecture & Data Flow
- `udp_table_init()` and `udp_pernet_table_alloc()` allocate `hash`, `hash2`, and `hash4` as one contiguous block (`slot_size` includes `udp_hash4_slot_size()`) with `>= UDP_HTABLE_SIZE_MIN_PERNET` (128) slots (`log >= 7` so `snum >> udptable->log < PORTS_PER_CHAIN`), and must set `table->hash2` and `table->mask` before `udp_table_hash4_init()` derives `table->hash4` via `table->hash2 + (table->mask + 1)` and sets each `hash4[i].nulls_head` marker to `i`. [F88, F122, F126]
- `UDP_HSLOT_MAIN()` casts `struct udp_hslot *` to `struct udp_hslot_main *` (`hslot` must be first), so `udp_has_hash4()`, `udp_hash4_inc()`, and `udp_hash4_dec()` only accept `table->hash2` slots; `struct inet_sock inet` must also remain first in `struct udp_sock` for direct `struct sock *` casts. [F127, F128]
- Adding or removing `udp_sk(sk)->udp_lrpa_node` in `udptable->hash4` (`udp_lib_hash4()`, `udp_unhash4()`) must update both `hslot4->count` under `hslot4->lock` and `UDP_HSLOT_MAIN(hslot2)->hash4_cnt` under `hslot2->lock`; in `udp_lib_rehash()`, `if (udp_hashed4(sk))` 4-tuple updates must run even when `hslot2 == nhslot2`. [F55, F56]
- Shared `udp_lib_*` helpers must resolve tables via `udp_get_table_prot(sk)`; because `udp_set_table()` can alias `net->ipv4.udp_table` to `&udp_table`, `udp_pernet_table_free()` must skip `&udp_table`, bucket walks must check `net_eq(sock_net(sk), net)`, and `__udp{4,6}_lib_lookup()` must only run BPF `sk_lookup` when `udptable == net->ipv4.udp_table` and only when destination-address `lookup2` did not return a `TCP_ESTABLISHED` socket (before wildcard `lookup2`). [F68, F69, F103]
- In `udp_lib_get_port()`, `snum`, `first`, and `last` must be 16-bit `unsigned short` with `rand = (rand | 1) * (udptable->mask + 1)`, and when `snum != 0` on the fast `hash2` path (`hslot->count > 10 && hslot->count >= hslot2->count`), `udp_lib_lport_inuse2()` must also check `hash2_nulladdr` if `hash2_nulladdr != slot2`. [F113, F123]
- In `__udp_enqueue_schedule_skb()`, `udp_rmem_release()`, `udp_destruct_common()`, and `[__]first_packet_length()`, `rmem`, `rcvbuf`, `truesize` sums, and `amt = (size + sk->sk_forward_alloc - partial) & ~(PAGE_SIZE - 1)` must be `unsigned int` to prevent signed `INT_MAX` overflow, and `size` must be reloaded from `skb->truesize` after `skb_condense(skb)` before `udp_set_dev_scratch()` and `atomic_add()`. [F117, F118]
- `struct udp_dev_scratch` caches `len`, `is_linear`, and `csum_unnecessary` only on 64-bit builds (`csum_unnecessary` only set when `!skb_shared(skb)`), and ORs `UDP_SKB_IS_STATELESS` into `_tsize_state`, so readers must use `udp_skb_truesize(skb)` (which masks `~UDP_SKB_IS_STATELESS`) and `udp6_skb_len(skb)` in IPv6 RX paths (which bypasses 16-bit `len` on `inet6_is_jumbogram(skb)`). [F79, F121, F148]
- When `sk->sk_rcvbuf` is set in `udp_lib_init_sock()` or `SO_RCVBUF[FORCE]` in `udp_lib_setsockopt()`, update `udp_sk(sk)->forward_threshold` to `sk->sk_rcvbuf >> 2` (under `sockopt_lock_sock()`); changes to `sk->sk_peek_off` must go through `udp_set_peek_off()` to keep `peeking_with_offset` in sync for `skb_consume_udp()`. [F59, F60]
- In `udp_send_skb()` and `udp_v6_send_skb()`, when `cork->gso_size` is set, use payload `datalen` (`len - sizeof(*uh)`) for `cork->gso_size * UDP_MAX_SEGMENTS`, `hlen + min(datalen, cork->gso_size) > cork->fragsize`, and `DIV_ROUND_UP(datalen, cork->gso_size)`, and only set `SKB_GSO_UDP_L4` / jump to `csum_partial` when `datalen > cork->gso_size`. [F80, F116, F124, F152]
- In `udp{,v6}_queue_rcv_skb()`, `udp_unexpected_gso()` must force software segmentation when `udp_sk(sk)->encap_rcv` is set without `SKB_GSO_UDP_TUNNEL[_CSUM]`; segmentation requires `__skb_push(skb, -skb_mac_offset(skb))` before `udp_rcv_segment()` (which rejects `SKB_GSO_UDP` UFO packets), and `__skb_pull(skb, skb_transport_offset(skb))` plus `udp_post_segment_fix_csum(skb)` on each segment. [F76, F149, F150]
- In `udp_v6_{flush,push}_pending_frames()`, delegate to `udp_{flush,push}_pending_frames()` when `up->pending == AF_INET`, and reset both `up->len = 0` and `WRITE_ONCE(up->pending, 0)` on all flush/push paths; in `udpv6_destroy_sock()`, call `static_branch_dec(&udpv6_encap_needed_key)`, `udp_encap_disable()`, and `udp_tunnel_cleanup_gro(sk)` when `ENCAP_ENABLED` is set. [F58, F61]
- In `__udp_disconnect()`, only call `inet_reset_saddr(sk)` (and `rehash(sk)` if `SOCK_BINDPORT_LOCK`) when `!(sk->sk_userlocks & SOCK_BINDADDR_LOCK)`, and only call `unhash(sk)` with `inet->inet_sport = 0` when `!(sk->sk_userlocks & SOCK_BINDPORT_LOCK)`. [F72]
- `udp_v{4,6}_early_demux()` must pass `skb_transport_offset(skb) + sizeof(struct udphdr)` to `pskb_may_pull()`; `__udp{4,6}_lib_demux_lookup()` must only match connected sockets on the first entry in `hslot2`, and `__udp4_lib_mcast_demux_lookup()` must return `NULL` if `hslot->count > 10` or multiple sockets match. [F94, F168]
- In `__udp6_lib_rcv()`, replace `ulen == 0` with `skb->len` when `proto == IPPROTO_UDP` before checking `ulen < sizeof(*uh)`; in `udpv6_sendmsg()`, set `fl6->flowi6_mark = ipc6.sockc.mark` after `ip6_datagram_send_ctl()`; in `compute_score()`, only add the device-match bonus when `sk->sk_bound_dev_if != 0`; keep `udp{,v6}_init_sock()` and `__udp{,v6}_queue_rcv_skb()` updated in lockstep. [F75, F78, F93, F101]

## Synchronization
- Primary bucket lock `spin_lock_bh(&hslot->lock)` must be held outside `hslot2->lock` and `hslot4->lock` whenever modifying `hslot2`/`hslot4` membership, `hash4_cnt`, or `sk->sk_reuseport_cb`; when moving between two `hslot2` or two `hslot4` buckets, release the old inner bucket lock before acquiring the new one while keeping `hslot->lock` held. [F25, F26]
- In UDP RX paths (`__skb_recv_udp()`, `first_packet_length()`, `udp_rmem_release()`), acquire `udp_sk(sk)->reader_queue.lock` with BH disabled before `sk->sk_receive_queue.lock`, and pass `rx_queue_lock_held = true` to `udp_rmem_release()` (or use `udp_skb_dtor_locked()`) iff `sk_receive_queue.lock` is held. [F27]
- Forward-allocated RX memory (`sk->sk_forward_alloc`, `udp_rmem_schedule()`, `__sk_mem_reduce_allocated()`) is serialized by `sk->sk_receive_queue.lock`; in `__udp_enqueue_schedule_skb()`, packets rejected by `udp_rmem_schedule()` must be placed on `to_drop` and freed via `sk_skb_reason_drop()` only after unlocking `sk_receive_queue.lock`, where `sk->sk_data_ready` is also called once per `nb` enqueued packet if `!sock_flag(sk, SOCK_DEAD)`. [F28, F29, F144]
- Revalidate lockless `READ_ONCE(up->pending)` checks under `lock_sock(sk)` in `udp{,v6}_sendmsg()` and `udp{,v6}_splice_eof()` before accessing cork state, and write `up->pending` with `WRITE_ONCE()` under `lock_sock(sk)`; `udp{,v6}_destroy_sock()` must set `SOCK_DEAD` and flush pending frames under `lock_sock(sk)`, and `udp_abort()` must check `sock_flag(sk, SOCK_DEAD)` under `lock_sock(sk)` before modifying `sk`. [F30, F31]
- `__udp{4,6}_lib_lookup()` require `rcu_read_lock()` and return an unreferenced `SOCK_RCU_FREE` socket (pin with `refcount_inc_not_zero(&sk->sk_refcnt)` before `rcu_read_unlock()`); inside `udp{4,6}_lib_lookup4()`, restart at `begin:` if `get_nulls_value(node) != slot`, and fall back to `udp{4,6}_lib_lookup1()` if 4-tuple and `hslot2` lookups miss. [F32, F140]
- Locklessly accessed fields (`up->encap_type`, `up->encap_rcv`, `up->gso_size`, `up->pcslen`, `up->pcrlen`, `up->forward_threshold`, `up->peeking_with_offset`, `sk->sk_uid`) require `READ_ONCE()`/`WRITE_ONCE()` (or `sk_uid(sk)`), `up->udp_flags` requires atomic bitops, `sk->sk_rx_dst` requires `udp_sk_rx_dst_set()`, `inet->inet_opt` in lockless `udp_sendmsg()` must be copied into `opt_copy` under `rcu_read_lock()`, and `UDP_ENCAP`/`UDP_GRO`/`gro_receive` mutations must hold `sockopt_lock_sock(sk)` and call `udp_tunnel_update_gro_rcv(sk, false)` first. [F34, F35, F57, F143]
- In the BPF UDP iterator, before dropping `hslot2->lock` across `bpf_iter_udp_seq_stop()` or a `GFP_USER` `bpf_iter_udp_realloc_batch()`, `bpf_iter_udp_put_batch()` must convert unvisited `iter->batch` entries to `sock_gen_cookie()` and `sock_put(sk)`; `bpf_iter_udp_seq_show()` must run outside `hslot2->lock` and recheck `sk_unhashed(sk)` under `lock_sock(sk)`; `/proc/net/udp[6]` `udp_get_next()` and `udp_seq_stop()` must unlock `udptable->hash[state->bucket].lock` when `state->bucket <= udptable->mask`. [F36, F66, F147]

## Object Lifetimes
- `udp{,_v6}_send_skb()` always consume `skb`; `udp_read_skb()` transfers `skb` ownership to `recv_actor(sk, skb)` after `skb_set_owner_sk_safe()` and must not free `skb` afterward; `__skb_recv_udp()` reclaims non-peeked `skb` memory via `udp_skb_destructor()`/`udp_skb_dtor_locked()`, whereas `MSG_PEEK` SKBs stay in `reader_queue` and require `__sk_queue_drop_skb(..., udp_skb_destructor)` if dropped. [F3, F4, F5]
- In `__udp_enqueue_schedule_skb()`, `atomic_add(size, &udp_prod_queue->rmem_alloc)` before `llist_add()` must be balanced by summing `total_size += size` for every `skb` popped by `llist_del_all()` (including drops) and subtracting `total_size` from `udp_prod_queue->rmem_alloc`; in `udp_destruct_common()`, splice `sk_receive_queue` into `up->reader_queue`, sum `truesize` across all freed SKBs, call `udp_rmem_release(sk, total, 0, true)` (`partial = 0`), and `kfree(up->udp_prod_queue)`. [F6, F7]
- In `udp_lib_get_port()`, set `SOCK_RCU_FREE` and initialize `inet_num`, `udp_port_hash`, and `udp_portaddr_hash` before `udp_reuseport_add_sock(sk, hslot)` and `sk_add_node_rcu()`; if `udp_reuseport_add_sock()` fails, reset `inet_num` and `udp_port_hash` to `0` and restore `udp_portaddr_hash ^= snum` before unlocking `hslot->lock`. [F12, F23]
- In `udp{,v6}_queue_rcv_one_skb()` and `__udp{4,6}_lib_rcv()`, call `nf_reset_ct(skb)` immediately after `xfrm{4,6}_policy_check()` succeeds; extract `skb->sk` via `inet{,6}_steal_sock()` (checking `IS_ERR(sk)` and `if (refcounted) sock_put(sk)`); in `__udp{4,6}_lib_mcast_deliver()`, preserve `first` across `goto start_lookup`, clone `skb` for extra matches, `consume_skb()` when `udp{,v6}_queue_rcv_skb() > 0`, and `kfree_skb(skb)` if `!first`. [F8, F14, F107, F156]

## API Contracts
- When `udp_sock.encap_rcv` returns `<= 0` (`0` consumed/dropped, `< 0` resubmit as protocol `-ret`), `udp{,v6}_queue_rcv_one_skb()` returns `-ret` (`> 0` resubmit, `0` consumed, `-1` dropped); `udp_unicast_rcv_skb()` must negate `ret > 0` for IPv4, `udp6_unicast_rcv_skb()` must return `ret > 0` directly for IPv6, and `__udp{4,6}_lib_mcast_deliver()` must `consume_skb()` when `ret > 0`. [F38, F161]
- Outgoing checksum paths (`udp{,_v6}_send_skb()`, `udp4_hwcsum()`, `udp6_hwcsum_outgoing()`, `udp_set_csum()`) must zero `uh->check` first, replace computed `0` with `CSUM_MANGLED_0`, and only use `CHECKSUM_PARTIAL` in `udp4_hwcsum()`/`udp6_hwcsum_outgoing()` when `!skb_has_frag_list(skb)`. [F50, F154]
- `udp{,6}_ehashfn()` require host-order `lport` (`u16`) and network-order `fport` (`__be16`), with RX destination as `(laddr, lport)` and source as `(faddr, fport)`, and `udp6_ehashfn()` must pass `udp6_ehash_secret + net_hash_mix(net)` to `__inet6_ehashfn()`; GRO lookups `udp{4,6}_lib_lookup_skb()` must use `skb->data + NAPI_GRO_CB(skb)->network_offsets[skb->encapsulation]` and `inet{,6}_get_iif_sdif()`. [F53, F115, F155]
- In `__udp{4,6}_lib_err()`, when `tunnel` is true, do not report errors via `ip{,v6}_icmp_error()`, `sk->sk_err`, or `sk_error_report()`; instead invoke `udp_sk(sk)->encap_err_rcv` if non-NULL; in `udp_rmem_release()`, pass page units (`amt >> PAGE_SHIFT`) to `__sk_mem_reduce_allocated()` while keeping socket fields in bytes. [F157, F162]

## Error Handling
- In `udp{,v6}_sendmsg()`, reject oversized `len` (`> 0xFFFF` in IPv4; `> INT_MAX - sizeof(struct udphdr)` in IPv6) before adding `sizeof(struct udphdr)` to `int ulen`, and only clear `connected` / run IP cmsg handlers when `udp_cmsg_send() > 0`; in `udp{,_v6}_send_skb()` and `udpv6_sendmsg()`, clear `-ENOBUFS` and `err > 0` to `0` unless `RECVERR[6]` is set. [F37, F125, F169]
- In `udp{,v6}_sendmsg()`, reset `rt = NULL` or `dst = NULL` when route lookup returns an `ERR_PTR` before `goto out`; in `udpv6_sendmsg()`, jump to `out_no_dst:` before `dst` lookup or after `ip6_make_skb()` steals `dst`, set `dst = NULL` on the corked `do_append_data:` path, restore `msg->msg_name = sin6` and `msg->msg_namelen = addr_len` after `do_udp_sendmsg`, and only free options when `free` is set (`udp_sendmsg`) or via `txopt_put(sk, opt_to_free)` (`udpv6_sendmsg`). [F17, F46, F47, F48]
- `__udp{4,6}_lib_err_encap()` must restore `skb` `network_offset` and `transport_offset` at `out:`, treat a `NULL` `up->encap_err_lookup` as a match only when the caller passed `sk != NULL`, and return valid `sk`, `NULL` (`ERR_PTR(0)` when consumed), or `ERR_PTR` (callers must check `!sk` before `IS_ERR(sk)`). [F20, F42, F43]
- `udp{4,6}_lib_lookup2()` can return an `ERR_PTR` from `inet{,6}_lookup_reuseport()`, so `__udp{4,6}_lib_lookup()` must check `!IS_ERR_OR_NULL(result)` and convert `IS_ERR(result)` to `NULL` at `done:`; inside `lookup2`, when `reuseport_has_conns(sk)` is true, check `IS_ERR(result)` before `goto rescore`, pass `need_rescore ? result : sk` to `compute_score()`, and `continue` when `need_rescore` is true; on `csum_copy_err:` in `udp{,v6}_recvmsg()`, clear `msg->msg_flags &= ~MSG_TRUNC` before `goto try_again`. [F41, F51, F102]

## External Contracts
- Every option in `udp_lib_setsockopt()` needs a matching `case` in `udp_lib_getsockopt()`; `udp_lib_getsockopt()` must check signed `len < 0` before `min_t(unsigned int, ...)` and return `0` for `UDPLITE_{SEND,RECV}_CSCOV` on UDP sockets, while `udp_lib_setsockopt()` returns `-ENOPROTOOPT` for them on UDP sockets and clamps non-zero coverage to `[8, USHRT_MAX]`; `UDP_SEGMENT` requires `cmsg_len == CMSG_LEN(sizeof(__u16))` and `0 <= val <= USHRT_MAX`. [F82, F95, F96, F97, F114]
- Validate `addr_len` in `udp{,v6}_pre_connect()` before cgroup connect BPF hooks; in `udpv6_sendmsg()`, accept `addr_len >= SIN6_LEN_RFC2133` (24) and only read `sin6_scope_id` when `addr_len >= sizeof(struct sockaddr_in6)` (28); after `BPF_CGROUP_RUN_PROG_UDP{4,6}_SENDMSG_LOCK`, re-validate non-zero destination port (and reject `ipv6_addr_v4mapped()` in `udpv6_sendmsg()` with `-ENOTSUPP`) and reload destination address/port; in `udp{,v6}_recvmsg()`, zero `sin_zero`/`sin6_flowinfo` (and `sin6_scope_id` for v4-mapped) before cgroup recvmsg BPF hooks. [F89, F90, F99, F164]

## Known Pitfalls
- In `__udp{4,6}_lib_rcv()`, re-fetch `uh = udp_hdr(skb)` (and `saddr`/`daddr` from `ipv6_hdr(skb)`) after `pskb_may_pull()` and `pskb_trim_rcsum()`; in `__udp{4,6}_lib_mcast_deliver()`, switch the `sk_for_each_entry_offset_rcu()` offset from `sk_node` to `__sk_common.skc_portaddr_node` when switching `hslot` to `udptable->hash2`; in `bpf_iter_udp_batch()`, do not modify `state->bucket` before `goto again` on `resizes == 1`, and reset `resizes = 0` at `next_bucket`. [F63, F109, F129]
