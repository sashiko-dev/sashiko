# EROFS FILE SYSTEM

EROFS (Enhanced ROM File System) is a read-only Linux filesystem supporting uncompressed and compressed data layouts across block devices, DAX, file-backed mounts (fileio), and fscache/netfs backends.

## Architecture & Data Flow

- Because `EROFS_FEATURE_INCOMPAT_FRAGMENTS` and `EROFS_FEATURE_INCOMPAT_DEDUPE` share bit `0x00000020`, `erofs_sb_has_fragments(sbi)` does not imply `sbi->packed_inode` is non-NULL; callers like `z_erofs_read_fragment()` must check `sbi->packed_inode != NULL`. In `erofs_xattr_prefixes_init()`, when `!erofs_sb_has_plain_xattr_pfx(sbi)`, check `erofs_sb_has_metabox(sbi)` first, then `sbi->packed_inode`, falling back to `erofs_init_metabuf(&buf, sb, false)`. [F42, F180]
- When `fe->mode < Z_EROFS_PCLUSTER_FOLLOWED`, file-backed folios must not be used for in-place I/O or `fe->candidate_bvpage` in `z_erofs_scan_folio()` and `z_erofs_attach_page()`. When `z_erofs_bind_cache()` finds all compressed pages in `MNGD_MAPPING` or `z_erofs_pcluster_begin()` handles an inline `pcl->from_meta` pcluster, set `fe->mode = Z_EROFS_PCLUSTER_FOLLOWED_NOINPLACE`. [F37, F73]
- In `z_erofs_do_decompressed_bvec()`, a `z_erofs_bvec` may populate `be->decompressed_pages` only if `bvec->offset + be->pcl->pageofs_out` is page-aligned and `bvec->end == PAGE_SIZE || bvec->offset + bvec->end == be->pcl->length`; otherwise set `be->keepxcpy = true` and use `decompressed_secondary_bvecs`. [F104]
- Before a stream decompressor writes to `rq->out[dctx->no]`, `z_erofs_stream_switch_bufs()` must copy the active input into `dctx->bounce` if `rq->out[dctx->no] == rq->in[dctx->ni]` and replace any future aliasing `rq->in[j]` (`j > dctx->ni`) with a copied short-lived page. [F67]
- In `z_erofs_lz4_prepare_dstpages()`, `rq->out[i - lz4_max_distance_pages]` may be pushed onto `availables[]` only when `!rq->fillgaps` and `test_bit(j, bounced)` is true after a full window round (`sbi->lz4.max_distance_pages <= LZ4_MAX_DISTANCE_PAGES`); after that check, non-NULL `rq->out[i]` calls `__clear_bit(j, bounced)` and NULL `rq->out[i]` calls `__set_bit(j, bounced)`. Because this reuses bounce pages across `rq->out[]`, `z_erofs_decompress_pcluster()` must deduplicate them for LZ4 before `erofs_pagepool_add()`. [F69, F97, F113]
- `z_erofs_alloc_pcluster()` is sized by `pageofs_in + map->m_plen`, and `pcl->pageofs_in` and `pcl->pclustersize` must keep the same `z_erofs_pclusterpages(pcl)` value until `z_erofs_free_pcluster()` looks up the `pcluster_pool` cache. [F143]
- In `z_erofs_map_blocks_iter()`, every `EROFS_MAP_ENCODED` extent must pass `z_erofs_map_sanity_check()`. Fragment extents must set `map->m_flags = EROFS_MAP_FRAGMENT` without `EROFS_MAP_ENCODED`, and `z_erofs_pcluster_readmore()` must check `map->m_flags & EROFS_MAP_ENCODED` in both `backmost` branches. [F81, F102, F103]
- In `z_erofs_scan_folio()`, each reverse-scan iteration must shorten `map->m_llen` to `offset + cur - map->m_la` and clear `EROFS_MAP_FULL_MAPPED` from `map->m_flags` before reusing `f->map`. In `z_erofs_submit_queue()`, `bvec.bv_page = NULL` must precede `drain_io:` so jumping to `drain_io` when `bio_add_page()` fails preserves `bvec`. In `erofs_fileio_scan_folio()`, reset `attached = 0` whenever `io->rq` is newly allocated (or across an unmapped segment). [F80, F114, F115]
- Extra devices get 0-based IDs in `sbi->devs->tree`, while `m_deviceid` uses 0 for `sbi->dif0` and 1-based IDs for extra devices (`idr_find(&devs->tree, map->m_deviceid - 1)`). In `erofs_fill_from_devinfo()`, check both `dif->file != NULL` and `S_ISBLK(file_inode(dif->file)->i_mode)` before `file_bdev(dif->file)`. [F43, F89]

## Synchronization

- Lock hierarchy: `xa_lock(&sbi->managed_pslots)` precedes `pcl->lockref.lock`, and `folio_lock()` precedes `pcl->lockref.lock`. Thus `z_erofs_put_pcluster()` (holding `pcl->lockref.lock`) must use `xa_trylock(&sbi->managed_pslots)` and defer release via `erofs_global_shrink_cnt` on contention, while `erofs_try_to_free_all_cached_folios()` (holding `xa_lock` and `pcl->lockref.lock`) must only use `folio_trylock()` and return `-EBUSY` on contention. [F27, F28]
- In `z_erofs_pcluster_begin()`, `xa_load(&sbi->managed_pslots, ...)` must run under `rcu_read_lock()` and pin `pcl` via `z_erofs_get_pcluster()` before `rcu_read_unlock()`, retrying if `__lockref_is_dead(&pcl->lockref)`. In `z_erofs_register_pcluster()`, `pcl->lockref` (1), `pcl->next = fe->head`, and `mutex_trylock(&pcl->lock)` must be set before `__xa_cmpxchg()` publishes `pcl`. An existing `pcl` may be linked to `fe->head` only if `cmpxchg(&fe->pcl->next, NULL, fe->head)` succeeds under `fe->pcl->lock`; otherwise set `fe->mode = Z_EROFS_PCLUSTER_INFLIGHT`. [F18, F35, F36]
- Multi-field accesses to `pcl->compressed_bvecs[]` across `z_erofs_bind_cache()`, `z_erofs_attach_page()`, `z_erofs_fill_bio_vec()`, and `z_erofs_cache_release_folio()` require `pcl->lockref.lock`. In `z_erofs_fill_bio_vec()`, after locking a managed-cache folio, verify `folio->private == pcl` and fall back to a short-lived page (`tocache = false`) if another pcluster owns it. [F25, F34]
- `pcl->length`, `pcl->vcnt`, `pcl->bvset`, `pcl->partial`, and `pcl->besteffort` are protected by `pcl->lock`. In `z_erofs_decompress_pcluster()`, non-managed `pcl->compressed_bvecs[]` pages must be processed and cleared before `erofs_onlinefolio_end()` unlocks output folios (while `z_erofs_endio()` may only unlock `erofs_folio_is_managed()` folios), and those `pcl` fields must be reset before `WRITE_ONCE(pcl->next, NULL)` and `mutex_unlock(&pcl->lock)`. [F26, F72, F184]
- In `erofs_shrink_scan()`, iterating `erofs_sb_list` under `erofs_sb_list_lock` must acquire `sbi->umount_mutex` via `mutex_trylock()` and drop `erofs_sb_list_lock` before `z_erofs_shrink_scan()`; advance `p = p->next` only after re-acquiring `erofs_sb_list_lock` and before `list_move_tail(&sbi->list, &erofs_sb_list)` and unlocking `umount_mutex`, and increment `shrinker_run_no` skipping `0` on wrap-around. [F29, F109, F138]
- In `z_erofs_submit_queue()`, `pending_bios` starts at 0, each BIO completion in `z_erofs_endio()` calls `z_erofs_decompress_kickoff(q, -1)`, and `z_erofs_submit_queue()` calls `z_erofs_decompress_kickoff(q[JQ_SUBMIT], nr_bios)` after submitting all BIOs; at the end of `z_erofs_submit_queue()`, `if (memstall) psi_memstall_leave(&pflags);` must run outside `if (bio)`. [F13, F39]
- In `z_erofs_decompress_kickoff()`, if `!io->sync && z_erofs_in_atomic()`, queue work to `z_erofs_pcpu_workers` (keeping both the dereference and `kthread_queue_work()` inside `rcu_read_lock()`, paired with `synchronize_rcu()` before `kthread_destroy_worker()` in `erofs_cpu_offline()`) or `z_erofs_workqueue`. [F161, F162]
- Callers of `z_erofs_get_gbuf()` hold `migrate_disable()` and `gbuf->lock` and must call `z_erofs_put_gbuf()` on the same CPU without sleeping. `z_erofs_gbuf_growsize()`, `z_erofs_load_lzma_config()`, and `z_erofs_load_zstd_config()` must never shrink global sizes, must update `gbuf` fields under `gbuf_resize_mutex` and `gbuf->lock` before `vunmap(old_ptr)`, and must hold `lzma_resize_mutex` / `zstd_resize_mutex` to isolate all streams before resizing workspaces. [F30, F31, F74]
- In `z_erofs_fill_inode()` and `erofs_init_inode_xattrs()`, lazy initialization under `EROFS_I_BL_Z_BIT` or `EROFS_I_BL_XATTR_BIT` must execute `smp_mb()` before setting `EROFS_I_Z_INITED_BIT` or `EROFS_I_EA_INITED_BIT`, paired with `smp_mb()` after `test_bit()` on the fast path. [F19]

## Object Lifetimes

- In `erofs_fileio_scan_folio()` and `z_erofs_scan_folio()`, `erofs_onlinefolio_init()` sets `folio->private` to 1 before attaching sub-requests, `erofs_onlinefolio_split(folio)` must run only after `bio_add_folio()` or `z_erofs_attach_page()` succeeds, and `erofs_onlinefolio_end()` runs after the scan loop. [F2, F38]
- Any temporary page from `erofs_allocpage()` or `__erofs_allocpage()` placed into `rq->out[]`, `rq->in[]`, `pcl->compressed_bvecs[]`, or `bvset->nextpage` must have `set_page_private(page, Z_EROFS_SHORTLIVED_PAGE)`. In `z_erofs_decompress_pcluster()`, read `page = be->compressed_pages[i]` (where `z_erofs_stream_switch_bufs()` places bounced pages) while clearing `pcl->compressed_bvecs[i].page = NULL`. [F3, F119]
- `erofs_global_shrink_cnt` counts only live pclusters in `managed_pslots` with `pcl->lockref.count == 0`, incremented in `z_erofs_put_pcluster()` and decremented in `z_erofs_get_pcluster()` (0-to-1) or `erofs_try_to_release_pcluster()`. `__erofs_try_to_release_pcluster()` must detach cached folios via `erofs_try_to_free_all_cached_folios()`, erase `pcl` from `sbi->managed_pslots`, and call `lockref_mark_dead(&pcl->lockref)` under `pcl->lockref.lock` before `call_rcu()`. [F8, F168]
- In `z_erofs_pcluster_end()`, call `z_erofs_put_pcluster()` only when `fe->mode < Z_EROFS_PCLUSTER_FOLLOWED_NOINPLACE`; otherwise ownership transfers to `fe->head` for `z_erofs_decompress_pcluster()`. A pcluster with `pcl->from_meta == true` is not in `sbi->managed_pslots` and must release `pcl->compressed_bvecs[0].page` with `folio_put()` and free `pcl` with `z_erofs_free_pcluster()`. [F9, F50]
- In `z_erofs_decompress_queue()` and `z_erofs_submit_queue()`, read `next = READ_ONCE(pcl->next)` before `z_erofs_decompress_pcluster()` or `z_erofs_move_to_bypass_queue()`. When `force_fg` is true, `q[JQ_SUBMIT]` aliases on-stack `io[JQ_SUBMIT]` (`q->sync = true`), so `z_erofs_submit_queue()` must call `z_erofs_decompress_kickoff()` and `z_erofs_runqueue()` must call `wait_for_completion_io(&io[JQ_SUBMIT].u.done)`. [F110, F152]
- Superblock teardown: in `erofs_fc_fill_super()`, register shrinker, xattr prefixes, and sysfs only after `sb->s_root = d_make_root(inode)` succeeds. In `erofs_put_super()`, `erofs_unregister_sysfs()` and `erofs_shrinker_unregister()` (looping `z_erofs_shrink_scan(sbi, ~0UL)` under `umount_mutex` until `xa_empty(&sbi->managed_pslots)`) must complete before `erofs_drop_internal_inodes()`. Helpers shared by `erofs_put_super()` and `erofs_kill_sb()` must never see `IS_ERR` pointers and must clear `sbi` pointers to NULL. [F10, F11, F20, F21]
- `erofs_bread()` and `erofs_read_metabuf()` unmap `buf->base` when advancing to a different page, so callers must copy data before re-reading on the same `erofs_buf`. In `erofs_find_target_block()`, `diff < 0` or `!ndirents` must release `&buf`, whereas updating `candidate` or exiting when `!IS_ERR(candidate)` must release `target`. [F64, F122, F146]

## API Contracts

- Initialize every `struct erofs_buf` with `__EROFS_BUF_INITIALIZER` (or zeroed). `erofs_bread()` returns `NULL` on success when `!need_kmap`, so check `IS_ERR(ptr)` rather than `!ptr` or `IS_ERR_OR_NULL(ptr)`. Callers of `z_erofs_map_blocks_iter()` must initialize `map->buf` and call `erofs_put_metabuf(&map->buf)` when done. In `erofs_iomap_begin()`, set `iomap->private = buf.base` (not `iomap->inline_data` or `&buf`) for `erofs_iomap_end()`. [F46, F48, F62, F151]
- Callers of `z_erofs_stream_switch_bufs()` must initialize `dctx.no = -1`, `dctx.ni = 0`, and `dctx.avail_out = 0`, and `__z_erofs_deflate_decompress()` and `z_erofs_zstd_decompress()` must set `rq->fillgaps = true`. Callers of `erofs_onlinefolio_end()` that write via CPU mappings must pass `dirty = true` so `flush_dcache_folio()` runs. [F51, F52, F159]
- `erofs_fileio_bio_alloc()` and `erofs_fscache_bio_alloc()` must leave `bio->bi_bdev` NULL so `z_erofs_endio()` does not call `bio_put(bio)`. In fileio mode, `erofs_init_metabuf()` sets `buf->file = sbi->dif0.file` (when `!in_metabox`), `erofs_fc_fill_super()` assigns `sb->s_blocksize` directly instead of `sb_set_blocksize()`, backing files require `S_ISREG()` (`fput()` on error), and `erofs_fileio_rq_submit()` sets `IOCB_DIRECT` only when `DIRECT_IO && FMODE_CAN_ODIRECT` under `override_creds(rq->iocb.ki_filp->f_cred)`. [F77, F174, F175, F176, F177]

## Error Handling

- In `erofs_init_device()`, convert `ERR_PTR(-ENOTBLK)` from `bdev_file_open_by_path()` to `-EINVAL` so `erofs_fc_get_tree()` does not mistake an extra-device failure for a fileio mount. In non-block bio completions (`erofs_fileio_ki_complete()`, `erofs_fscache_bio_endio()`, `erofs_fscache_submit_bio()`), set `bio->bi_status = errno_to_blk_status(ret)` on negative `ret` before `bio->bi_end_io`. [F40, F41]
- Initialize `int err = 0;` in `z_erofs_scan_folio()` and `erofs_fileio_scan_folio()`. In `z_erofs_read_folio()`, `z_erofs_runqueue()`, and `z_erofs_decompress_queue()`, combine errors with `new_err ?: err`. In `z_erofs_parse_in_bvecs()`, extract `PTR_ERR(page)` and reset `bvec->page = NULL` before `pcl->lock` is released. [F45, F49, F58]
- In `z_erofs_gbuf_growsize()`, `out:` cleanup must check `i < z_erofs_gbuf_count` before freeing `tmp_pages`, and skip `__free_page(tmp_pages[j])` when `j < gbuf->nrpages && tmp_pages[j] == gbuf->pages[j]`. [F75, F111]

## Known Pitfalls

- Because `EROFS_MAP_FRAGMENT` is `EROFS_MAP_MAPPED | __EROFS_MAP_FRAGMENT`, test `__EROFS_MAP_FRAGMENT` rather than `EROFS_MAP_FRAGMENT` when checking if a mapped extent is a fragment. [F101]
- `kmap_local` hazards: in `z_erofs_bvset_flip()`, read `iter->bvset->nextpage` before `z_erofs_bvec_iter_end(iter)` unmaps `iter->bvset`; in `z_erofs_stream_switch_bufs()`, when switching input pages while `dctx->kout` is mapped, unmap `kout` before `kin`, remap `kin` then `kout` (LIFO), recompute `*dst`, and reset `dctx->bounced` and `dctx->inbuf_pos`. [F65, F66]
- In `z_erofs_decompress_pcluster()`, `be->decompressed_pages` and `be->compressed_pages` share `be->onstack_pages` at `be->onstack_used`, so zero `be->decompressed_pages` when on-stack and skip `kvfree(be->compressed_pages)` when within `be->onstack_pages`. In `z_erofs_transform_plain()`, use `memmove()` on `kin` when `rq->out[no] == rq->in[ni]`. [F140, F144]
- Integer and offset pitfalls: cast split high fields (`blocks_hi`, `startblk_hi`, `h_extents_hi`, `pstart_hi`, `lstart_hi`) to `u64` before `<< 32`; compute 64-bit file offset differences in 64-bit types before narrowing to `unsigned int`; keep `z_erofs_bvec::offset` and `z_erofs_load_compact_lcluster()` index `i` as signed `int`; in `z_erofs_map_blocks_ext()`, keep `lstart` in bytes and only OR `map->m_pa << 32` into `vi->z_fragmentoff` when `recsz > offsetof(struct z_erofs_extent, pstart_lo)`. [F83, F123, F127, F130, F131]
