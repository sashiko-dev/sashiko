# SLAB ALLOCATOR

Implements the kernel's SLUB object-caching allocator, generic slab cache management, batched RCU-delayed freeing (`kvfree_rcu`), deadlock-free emergency memory pools (`mempool`), and slab fault injection (`failslab`), providing the primary heap allocation APIs (`kmalloc`, `kmem_cache_alloc`, `kvmalloc`, `kfree`, `krealloc`, and bulk/nolock variants) with KASAN, KFENCE, memcg, and introspection hooks.

## Architecture & Data Flow

- Under `CONFIG_SLAB_OBJ_EXT`, `allocate_slab()` must zero `slab->obj_exts` via `init_slab_obj_exts(slab)` before `account_slab()`. `slab->obj_exts` stores `OBJEXTS_FLAGS_MASK` bits (`OBJEXTS_NOSPIN_ALLOC`, `MEMCG_DATA_OBJEXTS`) or `OBJEXTS_ALLOC_FAIL`, so readers must use `slab_obj_exts(slab)` (whose `CONFIG_MEMCG` `VM_BUG_ON_PAGE()` must exempt `OBJEXTS_ALLOC_FAIL`). [F48, F53, F104]
- `alloc_slab_obj_exts()` must clear `OBJCGS_CLEAR_MASK`, set `__GFP_NO_OBJ_EXT`, use `kmalloc_nolock()` tagged with `OBJEXTS_NOSPIN_ALLOC` when `!gfpflags_allow_spinning(gfp)`, and on failure set `OBJEXTS_ALLOC_FAIL` via `mark_failed_objexts_alloc(slab)` so a later `alloc_slab_obj_exts()` runs `handle_failed_objexts_alloc()`. [F68, F174]
- Within a SLUB slot, post-object metadata starts at `object + get_info_end(s)` (`s->inuse + sizeof(void *)` if `freeptr_outside_object(s)`, else `s->inuse`), followed by `2 * sizeof(struct track)`, `orig_size`, and `kasan_metadata_size(s, false)`. [F94]
- When `SLAB_RED_ZONE` is set, pointers are offset by `s->red_left_pad` (`fixup_red_left()`), so `check_valid_pointer()` and `__kmem_obj_info()` must subtract it via `restore_red_left()`, and `__check_heap_object()` must reject `offset < s->red_left_pad` before subtracting it and test `offset >= s->useroffset`, `offset - s->useroffset <= s->usersize`, and `n <= s->useroffset - offset + s->usersize`. [F88, F141]
- When `slab_want_init_on_free(s)` and `!freeptr_outside_object(s)`, allocation paths must call `maybe_wipe_obj_freeptr(s, obj)` to zero `sizeof(void *)` bytes at `obj + s->offset`. In `slab_free_hook()`, zeroing on free must sample `orig_size = get_orig_size(s, x)` first, zero `orig_size` bytes at `x` and `[inuse, s->size - rsize)` in metadata, and restore `set_orig_size(s, x, orig_size)`. [F54, F82]
- In `slab_post_alloc_hook()`, if `kmem_cache_debug_flags(s, SLAB_STORE_USER | SLAB_RED_ZONE)` is set on a `SLAB_KMALLOC` cache, `zero_size` must be capped to `orig_size` and `kasan_init` forced to `false` when `__slub_debug_enabled()` so initialization does not overwrite the right redzone. [F56]
- Before `__do_krealloc()` reuses `p` in place, it must verify `new_size <= ks`, `IS_ALIGNED((unsigned long)p, align)`, and `nid == page_to_nid(virt_to_page(p))` (when `flags & __GFP_THISNODE` and `nid != NUMA_NO_NODE`), and sample `orig_size = get_orig_size(s, (void *)p)` before zeroing spare bytes and calling `set_orig_size()`. `slab_ksize()` must return `s->object_size` when `SLAB_RED_ZONE`, `SLAB_POISON`, or `SLAB_KASAN` is set, and `s->inuse` (not `s->size`) when `SLAB_TYPESAFE_BY_RCU` or `SLAB_STORE_USER` is set. [F83, F95]
- Every transition of a `struct slab` onto or off `n->partial` under `n->list_lock` must update `n->nr_partial` and `SL_partial` (`slab_set_node_partial()` / `slab_clear_node_partial()`) in lockstep. In `free_to_partial_list()`, when an empty slab is selected (`slab_free = slab`), `dec_slabs_node(s, slab_nid(slab_free), slab_free->objects)` must be called while still holding `n->list_lock` before unlocking and calling `free_slab()`. [F16, F66]
- Every slab deallocation path (`slab_free_hook()`, `slab_free_freelist_hook()` with `build_detached_freelist()`, and `__kmem_cache_free_bulk()`) must intercept KFENCE objects via `is_kfence_address()` / `kfence_free()` before writing freepointers or calling `do_slab_free()`. In `slab_free_freelist_hook()`, `old_tail = *tail` must be saved before clearing `*head` and `*tail`, and `next = get_freepointer(s, object)` read before `slab_free_hook()` and `set_freepointer()` in the `do { ... } while (object != old_tail)` loop. [F84, F115]
- When `memcg_slab_post_charge()` charges a large kmalloc folio (`!folio_test_slab(folio)`) via `__memcg_kmem_charge_page()`, it must subtract `folio_size(folio)` from `NR_SLAB_UNRECLAIMABLE_B` via `node_stat_mod_folio()` and add it via `lruvec_stat_mod_folio()` to match `free_large_kmalloc()`. `new_kmalloc_cache()` must set `SLAB_NO_MERGE` on `KMALLOC_NORMAL` caches under `CONFIG_MEMCG`, and `memcg_slab_post_charge()` must skip `is_kmalloc_normal(s)` caches. [F8, F175]
- `defer_free()` queues objects onto `df->objects` using the byte-offset address `head + s->offset`, so `free_deferred_objects()` must clear `*(void **)x = NULL` at that offset and subtract `s->offset` from `x` before calling `__slab_free()`. [F142]

## Synchronization

- Lock ordering is `cpus_read_lock` / `mem_hotplug_lock` -> `slab_mutex` -> `kmem_cache_node->list_lock` -> `s->cpu_slab->lock` -> `slab_lock(slab)` (`SL_locked` bit spinlock) -> `object_map_lock` (and `slab_mutex` -> `kernfs_mutex`). `kmem_cache_destroy()` must drop `slab_mutex` and `cpus_read_unlock()` before `sysfs_slab_unlink()` or `kmem_cache_release()`, `show_slab_objects()` must not take `mem_hotplug_lock`, and `deactivate_slab()` / `__put_partials()` must not be called while holding `s->cpu_slab->lock`. [F22, F150]
- `alloc_kmem_cache_cpus()` must align `s->cpu_slab` to `2 * sizeof(void *)`. Lockless fastpaths in `__slab_alloc_node()` and `do_slab_free()` must read `c = raw_cpu_ptr(s->cpu_slab)` and `tid = READ_ONCE(c->tid)` followed by `barrier()` before reading `c->freelist` or `c->slab`. Whenever `c->slab` or `c->freelist` is modified in slowpath or flush operations (`___slab_alloc()`, `flush_slab()`, `__flush_cpu_slab()`, `__kmem_cache_alloc_bulk()`), `c->tid` must be advanced via `next_tid(c->tid)` before unlocking `s->cpu_slab->lock`. [F23, F159]
- In `___slab_alloc()`, `c->slab` and `slub_percpu_partial(c)` read outside `s->cpu_slab->lock` must be revalidated after `local_lock_cpu_slab(s, flags)`. When dropping per-CPU pinning around `new_slab()` via `slub_put_cpu_ptr(s->cpu_slab)`, `c = slub_get_cpu_ptr(s->cpu_slab)` must be re-fetched afterwards and `retry_load_slab` must check under `local_lock_cpu_slab()` if `c->slab` was concurrently populated and flush it. [F25, F26]
- In `__kmem_cache_alloc_bulk()`, before calling `___slab_alloc()` the loop must bump `c->tid` and call `local_unlock_irqrestore(&s->cpu_slab->lock, irqflags)`, and on `NULL` the `error:` path must call `slub_put_cpu_ptr(s->cpu_slab)` before `__kmem_cache_free_bulk()`. [F13]
- In `__slab_free()`, when freeing to a non-frozen slab makes it empty (`!new.inuse`) or transitions it from full (`!prior && !kmem_cache_has_cpu_partial(s)`), `n->list_lock` must be acquired and `slab_test_node_partial(slab)` sampled before `slab_update_freelist()` succeeds; if it retries, unlock `n->list_lock` and reset `n = NULL`, and every exit path after the loop with `n != NULL` must unlock `n->list_lock`. `__slab_update_freelist()` requires IRQs disabled when `USE_LOCKLESS_FAST_PATH()` is true; otherwise use `slab_update_freelist()`. [F15, F32, F160]
- Because `s->cpu_sheaves->lock` does not disable IRQs, IRQ-reachable paths (`alloc_from_pcs`, `free_to_pcs`, `alloc_from_pcs_bulk`, `free_to_pcs_bulk`, `__kfree_rcu_sheaf`, `sheaf_flush_main`) must use `local_trylock(&s->cpu_sheaves->lock)` and reload `this_cpu_ptr(s->cpu_sheaves)` on relock. `__pcs_replace_empty_main()` and `__pcs_replace_full_main()` require `s->cpu_sheaves->lock` held and return with it held on the returned `pcs`'s CPU, or unlocked on `NULL`. In `__kfree_rcu_sheaf()`, `call_rcu()` must precede `local_unlock()`. [F12, F31, F162]
- `kmalloc_nolock_noprof()` must return `NULL` in NMI or hardirq on `CONFIG_PREEMPT_RT` and skip `__slab_alloc_node()` when `in_nmi() && local_lock_is_locked(&s->cpu_slab->lock)`. When `!gfpflags_allow_spinning(gfpflags)`, `__slab_alloc()` returns `ERR_PTR(-EBUSY)` if `s->cpu_slab->lock` is locked (which `kmalloc_nolock_noprof()` must retry or convert to `NULL`), and SLUB must use `alloc_frozen_pages_nolock()`, `spin_trylock_irqsave(&n->list_lock, flags)`, `defer_deactivate_slab()`, and skip `kmemleak_alloc_recursive()`. [F42, F156, F157]
- `defer_free()` and `defer_deactivate_slab()` must disable preemption with `guard(preempt)()` before calling `this_cpu_ptr(&defer_free_objects)` and queueing `df->work` via `irq_work_queue()`. [F151]
- `add_ptr_to_bulk_krc_lock(&krcp, &flags, ptr, can_alloc)` acquires `*krcp = krc_this_cpu_lock(flags)` and must return with `(*krcp)->lock` held on both `true` and `false` paths (re-locking after `__get_free_page()`), and `kvfree_call_rcu()` must call `krc_this_cpu_unlock()` before `synchronize_rcu()`. All accesses to `krcp->bkvcache` and `krcp->nr_bkv_objs` must be serialized by `krcp->lock`, and `kvfree_rcu_queue_batch()` may only populate and queue `krwp` when `need_wait_for_krwp_work(krwp)` is false under `krcp->lock`. [F19, F37, F38]
- `mempool_resize()`, `mempool_alloc_noprof()`, and `mempool_free()` must unlock `pool->lock` before calling `pool->alloc()` or `pool->free()`, and `mempool_alloc_noprof()` must return `NULL` without waiting on `pool->wait` if `!(gfp_mask & __GFP_DIRECT_RECLAIM)`. In `mempool_resize()`, after re-acquiring `pool->lock` following an allocation, recheck `new_min_nr <= pool->min_nr` and `pool->curr_nr < pool->min_nr` and free unused allocations outside `pool->lock`. [F21, F166]
- In `mempool_alloc_noprof()` and `mempool_alloc_preallocated()`, `smp_wmb()` must execute after `remove_element(pool)` and unlocking `pool->lock`, paired with `smp_rmb()` before `READ_ONCE(pool->curr_nr)` in `mempool_free()`. [F35]

## Object Lifetimes

- In `do_kmem_cache_create()`, any failure after allocating per-cache resources (`s->cpu_sheaves`, `s->random_seq`, `s->node[]`, `s->cpu_slab`, or `pcs->main`) must jump to `out:` and call `__kmem_cache_release(s)`, which only calls `lockdep_unregister_key(&s->lock_key)` when `s->cpu_slab` is non-NULL. [F1]
- `kmem_cache_destroy()` must call `kvfree_rcu_barrier()`, `rcu_barrier()` (for `CONFIG_SLUB_RCU_DEBUG` with `SLAB_TYPESAFE_BY_RCU`), and `defer_free_barrier()` before locking `slab_mutex`, and `__kmem_cache_shutdown(s)` must call `flush_all_cpus_locked(s)` and `rcu_barrier()` (if `s->cpu_sheaves`) before freeing slabs. If `__kmem_cache_shutdown(s)` returns non-zero, `kmem_cache_destroy()` must return after unlinking sysfs/debugfs without calling `kmem_cache_release(s)`; when `err == 0` on a `SLAB_TYPESAFE_BY_RCU` cache, it must call `rcu_barrier()` before `kmem_cache_release(s)`. [F3, F4]
- Before `__free_slab()` returns a slab folio to `free_frozen_pages()`, it must clear `SL_pfmemalloc` (`__slab_clear_pfmemalloc()`), `folio->mapping`, `PG_slab` (`__folio_clear_slab()`), and call `unaccount_slab()`, which must unconditionally call `free_slab_obj_exts(slab)` (regardless of `mem_alloc_profiling_enabled()`) to free `obj_exts` with `kfree_nolock()` when `OBJEXTS_NOSPIN_ALLOC` is set or `kfree()` otherwise and clear `slab->obj_exts = 0`. [F6, F80]
- Objects allocated by `__kmem_cache_alloc_bulk()` or `alloc_from_pcs_bulk()` before `slab_post_alloc_hook()` runs (including objects in a `slab_sheaf`) must be freed via `__kmem_cache_free_bulk()`, whereas `memcg_slab_post_alloc_hook()` itself frees `p` on memcg charge failure and sets `*p = NULL` when `size == 1`. [F9]

## API Contracts

- Downcasting a `struct folio *` via `folio_slab()` requires `folio_test_slab(folio)` (`virt_to_slab()`, `kfree()`, `__ksize()`, `__do_krealloc()`, `kvfree_rcu_cb()`, `build_detached_freelist()`), and `bpf_get_kmem_cache(u64 addr)` must check `virt_addr_valid((void *)(long)addr)` first. Large kmalloc allocations (`___kmalloc_large_node()`) must use `__GFP_COMP`, set `__folio_set_large_kmalloc()`, and account `PAGE_SIZE << order` to `NR_SLAB_UNRECLAIMABLE_B` via `lruvec_stat_mod_folio()`, all reversed by `free_large_kmalloc()`. [F143, F179, F186]
- `kfree_nolock()` rejects non-slab (`large_kmalloc`) folios, skips lock-taking debug/kmemleak/kfence hooks and KASAN quarantine (`skip_quarantine = true`), and is the sole caller passing `cnt == 0` to `do_slab_free()` to signal `!allow_spin`, which restores `cnt = 1` on the fastpath or calls `defer_free()` if `slab != c->slab` or `(in_nmi() || !USE_LOCKLESS_FAST_PATH()) && local_lock_is_locked(&s->cpu_slab->lock)`. [F63, F158]
- In `krealloc_node_align_noprof()` and `kvrealloc_node_align_noprof()`, a 0 size frees `p` and returns `ZERO_SIZE_PTR`, while a non-zero size frees `p` only when reallocation succeeds at a new untagged address (`kasan_reset_tag(p) != kasan_reset_tag(ret)`), leaving `p` valid on `NULL`. When `kmem_cache_refill_sheaf()` replaces `*sheafp` because `size > (*sheafp)->capacity`, it must allocate the new sheaf via `kmem_cache_prefill_sheaf(s, gfp, size)` before calling `kmem_cache_return_sheaf(s, gfp, *sheafp)`, leaving `*sheafp` intact on `-ENOMEM`. [F10, F11]

## Error Handling

- In `do_kmem_cache_create()`, `err` must be explicitly set to a negative errno before jumping to `out:` whenever a boolean/zero-returning helper (`alloc_percpu()`, `calculate_sizes()`, `init_kmem_cache_nodes()`, `alloc_kmem_cache_cpus()`) fails after `err` was overwritten. `create_cache()` returns `ERR_PTR(err)`, which `__kmem_cache_create_args()` must test with `IS_ERR(s)`, freeing `cache_name` and returning `NULL` (or panicking on `SLAB_PANIC`). In `calculate_sizes()`, `unsigned int order = calculate_order(size)` must be tested as `(int)order < 0` to catch `-ENOSYS`. [F40, F45, F51]
- In `init_kmem_cache_nodes()` and `slab_mem_going_online_callback()`, if allocating `n` fails after `barn` was allocated (`s->cpu_sheaves != NULL`), `kfree(barn)` must be called before returning because `s->node[node]` is still NULL. Unlike `barn_replace_empty_sheaf()` (which returns `NULL`), `barn_replace_full_sheaf()` returns `ERR_PTR(-E2BIG)` or `ERR_PTR(-ENOMEM)`, so callers must check `IS_ERR(empty)`. [F2, F43]

## Known Pitfalls

- When accessing slab metadata, redzones, or spare object memory outside tagged bounds (`__do_krealloc()`, `slab_free_hook()`, `set_orig_size()`, `get_orig_size()`), strip the pointer tag with `kasan_reset_tag()`. In `kvfree_rcu_cb()`, `struct rcu_head *head` may be at a non-zero offset (`< PAGE_SIZE`), so align `obj` down with `PAGE_ALIGN_DOWN()` for vmalloc/large-kmalloc or reconstruct the object start via `__obj_to_index()` and `fixup_red_left()` for slab objects. [F135, F145]
- `__alloc_tagging_slab_alloc_hook()` and `__alloc_tagging_slab_free_hook()` must return early when `s->flags` has `SLAB_NO_OBJ_EXT` or `SLAB_NOLEAKTRACE` (or `flags & __GFP_NO_OBJ_EXT`) to avoid kmemleak recursion, and `mark_objexts_empty()` must clear the codetag on `slab_obj_exts(virt_to_slab(obj_exts))`, not on elements of `obj_exts`. [F121, F154]
