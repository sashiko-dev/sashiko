# PERFORMANCE EVENTS SUBSYSTEM

Provides the core Linux kernel Performance Events subsystem (`kernel/events/core.c`, `kernel/events/callchain.c`), kernel and UAPI headers (`include/linux/perf_event.h`, `include/uapi/linux/perf_event.h`), architecture-specific CPU PMU drivers and callchain unwinders, and core userspace utilities for the `perf` tool (`tools/perf/util/`).

## Architecture & Data Flow

- Every `PERF_SAMPLE_*` field in `perf_output_sample()` must be accounted in `__perf_event_header_size()`, `perf_event__id_header_size()`, or `data->dyn_size` via `perf_sample_save_*` (`perf_sample_save_brstack` adds `sizeof(u64)` plus `sizeof(u64)` only if `branch_sample_hw_index(event)`). In `perf_prepare_sample()`, check `(sample_type & ~data->sample_flags) & PERF_SAMPLE_REGS_USER` (not `filtered_sample_type`), and account new dynamic fields before `PERF_SAMPLE_STACK_USER`/`PERF_SAMPLE_AUX` clamp to `U16_MAX`. [F62, F105, F229, F235, F236, F252, F279]
- In `__perf_remove_from_context()`, call `perf_cgroup_event_disable()` while `event->state > PERF_EVENT_STATE_OFF` before `perf_event_set_state()`, and call `perf_event_set_state(event, min(event->state, state))` (ordered `DETACH_EXIT` -> `DETACH_REVOKE` -> `DETACH_DEAD`) after `event_sched_out()` and before `perf_child_detach()` so `sync_child_event()` sees updated times. `perf_event_set_state()` must update event and sibling times when crossing `< 0` (`<= OFF`). [F206, F207, F208, F253]
- `__pmu_detach_event()` sets `event->state = PERF_EVENT_STATE_REVOKED` and nulls `event->pmu`, `event->pmu_ctx`, and `event->destroy`; callers must check `event->state > PERF_EVENT_STATE_REVOKED` before dereferencing `pmu` or `pmu_ctx`. Re-installing an event in `move_group` or `__perf_pmu_install_event()` after `perf_remove_from_context()` (which forces `STATE_OFF`) must reinitialize `event->state` first. [F194, F224]
- When `perf_group_detach()` detaches a leader, each sibling is promoted to singleton leader, added via `add_event_to_groups()` and `get_event_list()` if active, or forced into `PERF_EVENT_STATE_ERROR` if `PERF_EV_CAP_SIBLING` is set (which `_perf_event_enable()` must keep in `STATE_ERROR`). `perf_group_attach()`/`detach()` must update `nr_siblings`, `group_generation`, and `perf_event__header_size()` for all members. [F209, F210, F255]
- `event_sched_in()`/`event_sched_out()` must update `event->oncpu`, `event->state`, `cpc->active_oncpu`, `ctx->nr_freq`, `epc->nr_freq`, and `cpc->exclusive` in lockstep (reverting `state = INACTIVE` and `oncpu = -1` if `pmu->add()` fails). In `group_sched_in()`, if any sibling or `pmu->commit_txn()` fails, all scheduled siblings and `group_event` must be rolled back via `event_sched_out()` before `pmu->cancel_txn()`. [F212, F213]
- In `__perf_event_overflow()`, when `event->event_limit` hits zero, call `event->pmu->stop(event, 0)` immediately alongside `pending_kill = POLL_HUP` and `perf_event_disable_inatomic()`. Both `event_sched_out()` and `__perf_pending_disable()` must clear `event->pending_disable = 0` when setting `STATE_OFF`. Check `event->prog->type == BPF_PROG_TYPE_PERF_EVENT` before `bpf_overflow_handler()` and `perf_event_is_tracing(event)` in `perf_event_free_bpf_prog()`. [F195, F215, F216]
- `perf_event_throttle()` and `perf_event_unthrottle()` must return early if `event->state != PERF_EVENT_STATE_ACTIVE` (inactive siblings have `hw.idx == -1`), and `__perf_event_period()` must call `perf_event_unthrottle_group(event, true)` when restarting an `ACTIVE` event with `hw.interrupts == MAX_INTERRUPTS`. [F217, F268]
- In `tools/perf/util/maps.c`, every insertion into `maps_by_address` must call `map__set_kmap_maps()`. Splitting a map `pos` in `__maps__fixup_overlap_and_insert()` must advance `after`'s page offset by `map__end(new) - map__start(pos)` via `map__add_pgoff()`, and index-based removal loops (`maps__remove_maps`, `__maps__fixup_overlap_and_insert`) must not increment `i` after `__maps__remove()` shifts entries with `memmove()`. [F378, F380, F414]
- In `parse_events_add_pmu()`, `const_parsed_terms` must be deep-copied via `parse_events_terms__copy()` before `fix_raw()`, `config_attr()`, and `perf_pmu__check_alias()` mutate terms in place; accessing or freeing `term->val.str` requires checking `term->type_val == PARSE_EVENTS__TERM_TYPE_STR`. In `resolve_metric()`, matched sub-metrics must be collected into `pending` during `hashmap__for_each_entry()` and only deleted via `expr__del_id()` and expanded via `add_metric()` after the loop. [F368, F391, F394]

## Synchronization

- Modifying `sibling_list`, `ctx->event_list`, or `perf_event_pmu_context` lists requires holding both `ctx->mutex` and `ctx->lock`; reading them (e.g. `for_each_sibling_event()`) requires `ctx->mutex`, `ctx->lock`, or IRQs disabled, while `perf_iterate_ctx()` requires RCU read lock. `event->child_mutex` nests inside `ctx->mutex`: `perf_event_release_kernel()` must pin `child->ctx`, drop `child_mutex`, lock `ctx->mutex` then `child_mutex`, and reverify `child` on `child_list`. [F19, F182, F308]
- `pmus_lock` nests inside `pmus_srcu`: `perf_pmu_unregister()` must drop `pmus_lock` before `synchronize_srcu(&pmus_srcu)`, and `perf_event_alloc()` callers must hold `pmus_srcu` across allocation and installation. Migrating `event->ctx` (`perf_pmu_migrate_context()`) requires holding both contexts' `mutex` (`mutex_lock_double()`) and calling `synchronize_rcu()` between removal and re-installation. [F174, F310]
- In `perf_lock_task_context()`, call `local_irq_save()` before `rcu_read_lock()`, and after locking `ctx->lock` reverify `ctx == rcu_dereference(task->perf_event_ctxp)`, `ctx->task != TASK_TOMBSTONE`, and `refcount_inc_not_zero(&ctx->refcount)`. In `put_ctx()`, when `refcount_dec_and_test(&ctx->refcount)` is false, issue `smp_mb__after_atomic()` before testing `ctx->task == TASK_TOMBSTONE` and calling `wake_up_var(&ctx->refcount)`. [F172, F176]
- `event_sched_in()` must write `event->oncpu` and issue `smp_wmb()` before setting `event->state = PERF_EVENT_STATE_ACTIVE`, pairing with `smp_rmb()` in lockless readers (`perf_event_read()`, `perf_event_stop()`). `perf_install_in_context()` must publish `event->ctx` via `smp_store_release()` (pairing with `smp_load_acquire()` in `perf_iterate_sb_cpu()`), and execute `smp_mb()` before `task_function_call()` (rechecking `task_curr(task)` under `ctx->lock` if the IPI misses). [F177, F178, F179]
- In `perf_cgroup_switch()`, after the lockless `READ_ONCE(cpuctx->cgrp)` check and acquiring `perf_ctx_lock()`, reverify `READ_ONCE(cpuctx->cgrp) != NULL` before asserting `nr_cgroups` or scheduling, and update `cpuctx->cgrp` strictly between `ctx_sched_out()` and `ctx_sched_in()`. [F171, F214]
- `rb->aux_mutex` nests inside `event->mmap_mutex`. When `perf_mmap_close()` detaches events on `rb->event_list`, it must pin `event->refcount` under `rcu_read_lock()`, drop RCU, lock `event->mmap_mutex`, and recheck `event->rb == rb`. `__pmu_detach_event()` must lock/unlock `event->mmap_mutex` after setting `PERF_EVENT_STATE_REVOKED`, pairing with `perf_mmap()` checking `state <= PERF_EVENT_STATE_REVOKED` under `event->mmap_mutex`. [F185, F186, F187]
- `perf_event_throttle()` must set `event->hw.interrupts = MAX_INTERRUPTS` before calling `event->pmu->stop(event, 0)`, and `perf_swevent_cancel_hrtimer()` must skip `hrtimer_cancel()` when `hwc->interrupts == MAX_INTERRUPTS`. `perf_event_update_userpage()` must run under `preempt_disable()`, bracket `rb->user_page` writes with `++userpg->lock` and `barrier()`, and use NMI-safe `calc_timer_values()`. [F300, F304]
- In `tools/perf/util/maps.c`, when a reader under `down_read(maps__lock(maps))` finds `maps_by_address_sorted` or `maps_by_name_sorted` false, it must drop `down_read`, sort under `down_write`, and re-check the sorted flag and recompute indices (e.g. in `maps__merge_in`) after re-locking. `maps__copy_from(dest, parent)` locks `dest` for write then `parent` for read, requiring `!maps__equal(dest, parent)`. [F350, F351, F355]

## Object Lifetimes

- In `inherit_event()`, any error/orphan exit after `perf_event_alloc()` sets `child_event->parent` but before `atomic_long_inc_not_zero(&parent_event->refcount)` succeeds must use `free_event(child_event)` rather than `put_event()` (which drops `event->parent`). `perf_child_detach()` must not clear `event->parent` or drop `parent->refcount`; in `perf_event_exit_event()`, `put_event(event)` for a child must only run if `PERF_ATTACH_CHILD` was set before `perf_remove_from_context()`. [F155, F156, F166]
- `_free_event()` must drain `pending_irq` and `pending_disable_irq` via `irq_work_sync()`, but must never wait synchronously for `pending_task` (`task_work`), which holds its own `event->refcount` acquired in `__perf_event_overflow()` only after `task_work_add()` returns 0 (using `TWA_NMI_CURRENT` if `in_nmi()`). In `__free_event()`, `event->destroy(event)` must precede `put_task_struct(event->hw.target)`, and `put_pmu_ctx(event->pmu_ctx)` must precede `put_ctx(event->ctx)`. [F163, F180, F302, F315]
- Inherited child events (`event->parent != NULL`) share their parent's `addr_filters`, `fasync`, PID namespace (`ns`), and primary `id`; resolve them via `perf_event_addr_filters()`, `perf_event_fasync()`, `perf_event_pid_type()`, and `primary_event_id()`. [F8, F321]
- In `tools/perf/util/`, `map_symbol__copy` and `addr_map_symbol__copy` increment `maps`/`map` refcounts without dropping existing ones in `dst`, so callers overwriting an initialized destination or `callchain_cursor_node` must call `map_symbol__exit()` first. `dso__set_nsinfo(dso, nsi)` takes ownership of `nsi` without `nsinfo__get` (and must run under `dso__lock(dso)`). In `ordered_events`, when `oe->copy_on_queue` is true, all removal/teardown paths must call `free_dup_event()`. [F330, F331, F336, F341, F464]

## API Contracts

- `struct pmu` callbacks `add()`, `del()`, `start()`, and `stop()` run with local IRQs and the PMU disabled, whereas `addr_filters_validate()` runs in process context without serialization. `->del()` must stop the event with `PERF_EF_UPDATE`, `->stop()` must check `PERF_HES_STOPPED` and `PERF_HES_UPTODATE` independently, and `->commit_txn()` must only clear `txn_flags` and re-enable the PMU on success. [F7, F21, F51]
- `for_each_sibling_event(sibling, event)` only iterates `sibling_list` when `event->group_leader == event`, does not visit the leader itself, and must never be called when `event->ctx == NULL`. `unclone_ctx()` must be called under `ctx->lock` and returns `parent_ctx` to be passed to `put_ctx()` after unlocking `ctx->lock`. `perf_callchain()` must return `&__empty_callchain` (never `NULL`). [F85, F164, F192, F256]
- In `tools/perf/util/`, `maps__find*` and `machine__find*_thread` return refcounted pointers, and `maps__find_symbol(maps, addr, &map)` sets `*mapp = map` with a refcount even when returning `NULL`. `map__load(map)` must succeed before `map__map_ip()`, `map__for_each_symbol()`, or `dso__data_write_cache_addr()` in `machine__process_text_poke()`. `parse_events_error__handle()` and `parse_events__set_default_name()` take ownership of their heap string arguments. [F333, F334, F339, F344, F346, F370, F477]

## Error Handling

- `struct pmu::event_init` must return `-ENOENT` when `event` does not target that PMU and another negative errno when invalid. In `perf_try_init_event()`, any failure after `pmu->event_init(event)` succeeds must jump to `err_destroy` to call `event->destroy(event)`. If `sys_perf_event_open()` or `perf_event_create_kernel_counter()` fails after `find_get_pmu_context()` before `perf_install_in_context()`, call `put_pmu_ctx(event->pmu_ctx)` and set `event->pmu_ctx = NULL`. [F28, F158, F293]
- In `perf_mmap()`, `perf_mmap_rb()`/`perf_mmap_aux()` must succeed before setting `vma->vm_ops` or calling `pmu->event_mapped()`, and if `map_range()` fails afterward, call `perf_mmap_close(vma)`. In `perf_mmap_aux()`, failure after `refcount_inc_not_zero(&rb->mmap_count)` on `!rb_has_aux(rb)` must call `refcount_dec(&rb->mmap_count)` without setting `rb->aux_mmap_count`. [F161, F162]
- In `tools/perf/util/`, `lzma_is_compressed()` returns `bool` and must return `false` (never `-1`) on error. `add_callchain_ip()`, `resolve_lbr_callchain_sample()`, and `parse_events__sort_events_and_fix_groups()` return `1` for non-error conditions and `< 0` on error, while `perf_mmap__push()` returns `1` on `-EAGAIN`. In `__parse_events()` and `metricgroup__add_metric()`, splice the temporary parsed list into the caller's list even on error. [F361, F364, F365, F366, F375]

## External Contracts

- In `struct perf_event_mmap_page` (`offsetof(..., data_head) == 1024`), consumers reading `data_head`/`aux_head` must issue `smp_rmb()` before reading data and `smp_mb()` before writing `data_tail`/`aux_tail`. `index` is 1-based (`0` when inactive/stopped, `hwc->idx + 1` when active), and `perf_event_update_userpage()` must only subtract `prev_count` from `userpg->offset` when `userpg->index != 0`. [F23, F48, F244, F246]
- `perf_copy_attr()` treats `uattr->size == 0` as `PERF_ATTR_SIZE_VER0`, writes `sizeof(*attr)` to `uattr->size` on `-E2BIG`, and rejects non-zero reserved fields or unknown flag bits with `-EINVAL`. Ring-buffer records must have 8-byte aligned `header.size` with zero-padded tails (and `data->cpu_entry.reserved = 0`). `__perf_read()` returns `0` on `PERF_EVENT_STATE_ERROR` and `-ENOSPC` if `count < event->read_size`. [F203, F233, F234, F240, F247]

## Known Pitfalls

- CPU-wide events can interrupt a task in `do_exit()` after `exit_mm()` clears `current->mm`, so `perf_sample_ustack_size()` and `perf_callchain()` must check `current->mm != NULL` (and `get_perf_callchain()` must skip `perf_callchain_user()` when `crosstask` or `PF_KTHREAD | PF_USER_WORKER` is set), while `perf_get_page_size()` falls back to `&init_mm`. [F133, F196]
- Cast `entries->cpu_entries[cpu]` to `void *` before adding `*rctx * perf_callchain_entry__sizeof()` in `get_callchain_entry()`. In `perf_output_sample_regs()`, convert `u64 mask` via `bitmap_from_u64()` for `for_each_set_bit()`. In `perf_event_bpf_emit_ksymbols()`, start the `prog->aux->func[i]` loop at `i = 1`. In `perf_event_cgroup()` and `perf_event_mmap_event()`, pass `PATH_MAX - sizeof(u64)` to `cgroup_path()`/`file_path()`. [F103, F202, F241, F285]
- In `tools/perf/util/`, `DECLARE_RC_STRUCT` types (`map`, `maps`, `nsinfo`, `mem_info`) must be allocated/copied with `sizeof(RC_STRUCT(<type>))` and unwrapped with `RC_CHK_ACCESS()`. `maps__for_each_map` must reload `maps__nr_maps(maps)` and `maps__maps_by_address(maps)` every iteration because callbacks in single-threaded mode may `realloc` the array. `map__start_cmp()` and `map__addr_cmp()` must use relational operators returning `-1`/`0`/`1`. [F354, F427, F434]
