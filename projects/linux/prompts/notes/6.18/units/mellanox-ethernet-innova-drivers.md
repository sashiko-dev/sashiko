# MELLANOX ETHERNET INNOVA DRIVERS

`drivers/net/ethernet/mellanox/mlx5/core` (`en_accel/` and `fpga/`) implements ConnectX/Innova hardware network acceleration—control-plane offload callbacks, flow-steering tables, ASO state updates, and TX/RX WQE/CQE datapath processing for IPsec (XFRM), kTLS, MACsec, PSP, and Geneve/UDP GSO—plus Innova FPGA core/SDK device, I2C, event, and SBU QP/CQ management.

## Architecture & Data Flow
- Hardware ASO event arm bits (`esn_event_arm`, `soft_lft_arm`, `hard_lft_arm`, `epn_event_arm`) are cleared by hardware when triggered, so `mlx5e_ipsec_handle_event()`, `mlx5e_ipsec_handle_limits()`, and `macsec_async_event()` must test `!arm`. In `mlx5e_ipsec_update_esn_state()` and `macsec_epn_update()`, increment `esn_msb`/`epn_msb` and set `overlap = 0` only when `mode_param < 0x80000000L` (`*_SCOPE_MID`)—else set `overlap = 1`—modify the FW object, and re-arm via `BIT_ULL(54)` at `*_ASO_REMOVE_FLOW_PKT_CNT_OFFSET`. [F69, F106, F129]
- When `sa_entry->esn_state.esn_msb == 0` (including non-ESN SAs), `mlx5e_xfrm_add_state()` and `mlx5e_ipsec_update_esn_state()` must initialize `sa_entry->esn_state.esn` to at least 1, and `mlx5e_ipsec_packet_setup()` must program it into `ipsec_aso` `mode_parameter` on `XFRM_DEV_OFFLOAD_OUT` even when `!attrs->replay_esn.trigger`. Conversely, `replay_window` validation and `MLX5_IPSEC_ASO_REPLAY_PROTECTION` configuration apply only when `dir == XFRM_DEV_OFFLOAD_IN`. [F56, F110]
- `sa_entry->work->data` is a `struct mlx5e_ipsec_sa_entry *` shadow for `XFRM_DEV_OFFLOAD_CRYPTO` (`mlx5e_ipsec_modify_state`), where `mlx5e_xfrm_advance_esn_state()` builds updated ESN attributes before `mlx5_accel_esp_modify_xfrm()` updates `sa_entry->attrs` after `mlx5_modify_ipsec_obj()` succeeds; for `XFRM_DEV_OFFLOAD_PACKET` (`mlx5e_ipsec_handle_netdev_event`), it is a `struct mlx5e_ipsec_netevent_data *`, so `MLX5E_IPSEC_TUNNEL_SA` must only mark packet-offload tunnel SAs. [F75, F136]
- In `mlx5e_accel_ipsec_fs_modify()`, replacement flow rules must be installed into a zeroed stack `sa_entry_shadow.ipsec_rule` via `mlx5e_accel_ipsec_fs_add_rule(&sa_entry_shadow)` before calling `mlx5e_accel_ipsec_fs_del_rule(sa_entry)` and copying `sa_entry_shadow` over `*sa_entry`; thus `mlx5e_accel_ipsec_fs_add_rule()` and its callees (`tx_add_rule`, `rx_add_rule`) must never persist `sa_entry` or initialize self-referential fields. [F74, F137]
- In `ipsec_rx()`, `ipsec_tx()`, and `ipsec_fs_get_ns()`, the E-Switch path (`rx_esw`, `tx_esw`, `MLX5_FLOW_NAMESPACE_FDB`) is selected only when both `ipsec->is_uplink_rep` and `type == XFRM_DEV_OFFLOAD_PACKET` hold. For NIC RX SAs (`rx != ipsec->rx_esw`), `rx_add_rule()` writes `sa_entry->ipsec_obj_id | BIT(31)` (24-bit ID matching `MLX5_IPSEC_METADATA_HANDLE`) to `METADATA_REG_B`/`C_2` and `MLX5_IPSEC_ASO_SW_CRYPTO_OFFLOAD` to `METADATA_REG_C_4`, and `rx->ft.status` pass rules must match both `ipsec_syndrome == 0` and `metadata_reg_c_4`. [F77, F95, F104, F146]
- In `rx_add_rule()` and `setup_fte_spi()`, UDP-encapsulated SAs (`attrs->encap` true) must match `misc_parameters.inner_esp_spi` and omit `setup_fte_esp(spec)`, whereas non-encapsulated SAs match `outer_esp_spi` and call `setup_fte_esp(spec)`. In `tx_add_rule()`, outer IP, SPI, ESP, and `metadata_reg_a` matches apply only to `XFRM_DEV_OFFLOAD_CRYPTO`, while `XFRM_DEV_OFFLOAD_PACKET` matches `attrs->reqid` in `metadata_reg_c_4` via `setup_fte_reg_c4()`. [F108, F145]
- Accessing `key`, `salt`, or `rec_seq` in `union mlx5e_crypto_info` or `struct tls_crypto_info *` must dispatch on `cipher_type` (`TLS_CIPHER_AES_GCM_128` vs `256`). In `tx_post_resync_params()`, `rec_seq` must be compared against `cpu_to_be64(rcd_sn)` and updated in place when they differ so `mlx5e_ktls_tx_post_param_wqes()` sets `skip_static_post = false` iff it changed. Any new WQEs posted before a kTLS TX packet WQE must be accounted for in `mlx5e_ktls_get_stop_room()`. [F80, F84, F139]
- In `fpga/conn.c`, `mlx5_fpga_conn_create_qp()` must `roundup_pow_of_two` `conn->qp.rq.size` and `conn->qp.sq.size` because ring accesses mask with `size - 1`. In `mlx5_fpga_conn_rq_cqe()`, `mlx5_fpga_conn_unmap_buf()` must run before setting `buf->sg[0].size = be32_to_cpu(cqe->byte_cnt)` for `conn->recv_cb`, and `buf->sg[0].size` must be reset to `MLX5_FPGA_RECV_SIZE` before `mlx5_fpga_conn_post_recv()`. [F87, F135]

## Synchronization
- `mlx5e_ipsec_update_esn_state()` and `mlx5e_ipsec_aso_query()` are entered with `sa_entry->x->lock` held (`spin_lock_bh` in `mlx5e_ipsec_handle_event()`). `mlx5e_ipsec_update_esn_state()` must drop `sa_entry->x->lock` across `mlx5_accel_esp_modify_xfrm()` and re-acquire it before `mlx5e_ipsec_aso_update()`. `mlx5e_ipsec_aso_query()` must always zero `aso->ctx`, post the WQE, and poll `mlx5_aso_poll_cq()` under `spin_lock_bh(&aso->lock)` (nested inside `sa_entry->x->lock`) with a bounded `time_is_after_jiffies` + `udelay()` loop. [F13, F18, F70, F118]
- All `ipsec->sadb` mutations (`xa_insert_bh`, `xa_erase_bh`, `xa_lock_bh`/`xa_unlock_bh` around `__xa_set_mark`) must disable BH because `mlx5e_xfrm_del_state()` can run in softirq context. In `mlx5e_xfrm_add_state()`, `sa_entry` must not be published into `ipsec->sadb` or marked `MLX5E_IPSEC_TUNNEL_SA` until its work items, hardware SA context, and flow rules are initialized. In `mlx5e_ipsec_handle_sw_limits()`, under `spin_lock_bh(&x->lock)`, verify `x->km.state == XFRM_STATE_VALID` before `xfrm_state_check_expire(x)`. [F17, F21, F155]
- In `ktls_rx.c`, `priv_rx->lock` serializes `priv_rx->crypto_info` and `priv_rx->list` and must nest inside `ktls_resync->lock` (`resync_handle_seq_match()`) and inside `c->async_icosq_lock` (`mlx5e_ktls_rx_handle_resync_list()`); `ktls_resync->lock` and `c->async_icosq_lock` must never nest. Callers outside NAPI poll (`post_rx_param_wqes`, `resync_post_get_progress_params`, `resync_handle_seq_match`) must use `spin_lock_bh(&c->async_icosq_lock)`. [F28, F163]
- In `ktls_tx.c`, `mlx5e_tls_tx_pool` operations (`create_work`, `destroy_work`, `pool_push`, `pool_pop`) must hold `pool->lock` while accessing `pool->list` and `pool->size`, and drop `pool->lock` across `mlx5e_tls_priv_tx_init()` and `mlx5e_tls_priv_tx_list_cleanup()`. `mlx5e_bulk_async_cleanup()` (`mlx5_cmd_cleanup_async_ctx()`) must drain `create_tis_callback`/`destroy_tis_callback` before splicing `local_list` into `pool->list` in `create_work()` or returning from `mlx5e_tls_priv_tx_list_cleanup()`. [F30, F31]
- In `tx_sync_info_get()`, `spin_lock_irqsave(&tx_ctx->lock, flags)` must be held continuously across `tls_get_record()` and copying `record->frags[i]` while calling `page_ref_inc(skb_frag_page(frag))`. In `mlx5e_ktls_handle_tx_skb()`, `tls_ctx->netdev` must be read via `rcu_dereference_bh(tls_ctx->netdev)`, allowing `NULL` without warning or dropping the SKB. [F32, F33]
- In `macsec.c`, all mutations and lookups of `macsec_device_list_head`, `tx_sa`, `rx_sc`, and `rx_sa` across `macsec_offload_ops` and `macsec_async_event()` must hold `macsec->lock`, and `macsec_aso_query()` / `macsec_aso_set_arm_event()` must hold `aso->aso_lock` (nested inside `macsec->lock`). EQ event callbacks (`mlx5e_ipsec_event`, `macsec_obj_change_event`, `mlx5_fpga_event`) run in atomic context and must use `GFP_ATOMIC` and defer sleeping/mutex/ASO work to workqueues. [F34, F172]

## Object Lifetimes
- In `mlx5e_xfrm_add_state()` (when `!XFRM_DEV_OFFLOAD_FLAG_ACQ`), acquire `mlx5_eswitch_block_ipsec()`, `mlx5_eswitch_block_mode()`, and `mlx5e_ipsec_fs_tunnel_allowed()` in order; release encap and mode before returning 0 or on error, and unblock ipsec in `mlx5e_xfrm_free_state()`. Pair every `mlx5e_ipsec_block_tc_offload()` (which must hold `mlx5_esw_lock(esw)` around checking `num_block_ipsec` and incrementing `num_block_tc`) in `mlx5e_accel_ipsec_fs_add_rule()` / `add_pol()` with `mlx5e_ipsec_unblock_tc_offload()` on error and deletion. [F1, F4, F19]
- In `mlx5e_xfrm_free_state()`, non-NULL `sa_entry->work->work` and `sa_entry->dwork->dwork` must be drained with `cancel_work_sync()` and `cancel_delayed_work_sync()` before calling `mlx5e_accel_ipsec_fs_del_rule()`, `mlx5_ipsec_free_sa_ctx()`, or `kfree(sa_entry)`. In `mlx5e_ipsec_cleanup()` and `mlx5e_accel_ipsec_fs_cleanup()`, guard teardown of `ipsec->netevent_nb.notifier_call`, `ipsec->aso`, and `ipsec->roce` by checking those pointers rather than `mlx5_ipsec_device_caps()`. [F5, F22, F51]
- In `mlx5e_ipsec_offload_handle_rx_skb()`, after `secpath_set(skb)`, any failure to populate `sp->xvec` must call `secpath_reset(skb)` before returning, while success must call `xfrm_state_hold(sa_entry->x)` under `rcu_read_lock()`. [F12]
- In `mlx5e_ktls_add_tx()`, `pool_pop(pool)` recycles `priv_tx` with its `tisn`, so `crypto_info`, `dek`, `expected_seq`, `tx_ctx`, and `ctx_post_pending = true` must be reset; any failure after `pool_pop()` must call `pool_push(pool, priv_tx)` (never `kfree`), and `mlx5e_ktls_del_tx()` must call `mlx5_ktls_destroy_key()` before `pool_push()`. In `mlx5e_ktls_tx_handle_ooo()`, if `tx_post_resync_dump()` fails on chunk `n` of fragment `i`, call `page_ref_add(skb_frag_page(f), n - 1)` and jump to `err_out` without incrementing `i` so unposted fragments get `page_ref_dec()`. [F2, F7, F79, F116]
- In `mlx5e_ktls_del_rx()`, before destroying the flow rule, TIR, and DEK, set `MLX5E_PRIV_RX_FLAG_DELETING`, clear the socket RX context, call `synchronize_net()`, wait on `priv_rx->rule.work` (or `priv_rx->add_ctx` if `cancel_work_sync()` is false—every path after `post_rx_param_wqes()` must signal `complete(&priv_rx->add_ctx)` if `rule.work` isn't queued or when it finishes), and drain `resync.work`. `resync_queue_get_psv()` must call `mlx5e_ktls_priv_rx_get()` before `queue_work()`, paired with `mlx5e_ktls_priv_rx_put()` on queue/cancel/post failure or CQE completion. [F9, F27, F144]
- In `macsec.c`, updating TX SA or SecY state (`mlx5e_macsec_upd_txsa`, `mlx5e_macsec_upd_secy`, `macsec_upd_secy_hw_address`) must only tear down and recreate flow rules via `mlx5e_macsec_cleanup_sa_fs()` / `mlx5e_macsec_init_sa_fs()`, preserving `sa->macsec_obj_id`. `mlx5e_macsec_offload_handle_rx_skb()` must hold `rcu_read_lock()` across `xa_load(&macsec->sc_xarray, fs_id)` and `dst_hold(&rx_sc->md_dst->dst)`, and `macsec_del_rxsc_ctx()` must remove RX SA rules, call `list_del_rcu()` and `xa_erase()`, and free `rx_sc` via `kfree_rcu_mightsleep()`. [F35, F64]
- In `mlx5e_macsec_cleanup()`, `mlx5_notifier_unregister(mdev, &macsec->nb)` and `destroy_workqueue(macsec->wq)` must run in that order before `mlx5e_macsec_aso_cleanup()` and `kfree(macsec)`. `mlx5_fpga_conn_destroy()` must set `conn->qp.active = false`, disable `conn->cq.tasklet`, and call `synchronize_irq(conn->cq.mcq.irqn)` before destroying the QP/CQ, and `mlx5_fpga_conn_destroy_qp()` must execute `MLX5_CMD_OP_DESTROY_QP` before unmapping/freeing RQ/SQ buffers. [F36, F142]

## API Contracts
- TX SKB offload handlers called by `mlx5e_accel_tx_begin()` (`mlx5e_ktls_handle_tx_skb`, `mlx5e_psp_handle_tx_skb`, `mlx5e_ipsec_handle_tx_skb`, `mlx5e_macsec_handle_tx_skb`) must consume/free `skb` before returning `false`, and return `true` when `skb` remains valid. Any TX offload writing inline trailer data into `inlseg` in `mlx5e_accel_tx_finish()` (`state->ipsec.tailen` or `state->psp_st.tailen`) must return that exact length from `mlx5e_accel_tx_ids_len()`. [F43, F83]
- SWP offset fields in `struct mlx5_wqe_eth_seg` (`swp_outer_l3_offset`, `swp_outer_l4_offset`, `swp_inner_l3_offset`, `swp_inner_l4_offset`) are in 2-byte units, so `mlx5e_ipsec_set_swp()` and `mlx5e_psp_set_swp()` must divide SKB byte offsets by 2, and each `case IPPROTO_UDP:` branch must `fallthrough;` to `case IPPROTO_TCP:`. [F61, F111]
- In `mlx5e_ipsec_xfrmdev_ops`, `.xdo_dev_state_delete` (`mlx5e_xfrm_del_state`) and `.xdo_dev_policy_free` (`mlx5e_xfrm_free_policy`) must not sleep, flush workqueues, or issue blocking firmware/flow-steering commands; work cancellation and hardware teardown belong in `mlx5e_xfrm_free_state()` and `mlx5e_xfrm_del_policy()`. When `XFRM_DEV_OFFLOAD_FLAG_ACQ` is set, `mlx5e_xfrm_add_state()` must use `GFP_ATOMIC` and all XFRM callbacks must skip hardware/SADB operations. [F156, F182]
- Before issuing `MLX5_CMD_OP_MODIFY_GENERAL_OBJECT` in `mlx5_modify_ipsec_obj()` or `mlx5e_macsec_modify_obj()`, query with `MLX5_CMD_OP_QUERY_GENERAL_OBJECT` and verify `modify_field_select` has both overlap and MSB bits set. When calling `mlx5_eswitch_block_encap(mdev, from_fdb)`, pass `rx == ipsec->rx_esw` or `tx == ipsec->tx_esw` as `from_fdb`. `ipsec_chains_get_table()` / `put_table()` pass `prio + 1`, so `mlx5e_xfrm_validate_policy()` must reject `x->priority == U32_MAX`. [F58, F62, F149]

## Error Handling
- `mlx5_eswitch_block_ipsec()` and `mlx5_eswitch_block_encap()` return `bool` (`true` on success), whereas `mlx5_eswitch_block_mode()` returns `int` (`0` on success). At `err_xfrm:` in `mlx5e_xfrm_add_state()`, use `NL_SET_ERR_MSG_WEAK_MOD` so specific `extack` messages are preserved. In `mlx5e_ipsec_remove_trailer()` (called only when `!skb_is_gso(skb)`), propagate `skb_copy_bits()` and `pskb_trim()` errors before subtracting `trailer_len` from IP header lengths. [F46, F48, F54, F180]
- In `ktls_tx.c`, when async `MLX5_CMD_OP_CREATE_TIS` fails, `create_tis_callback()` must set `priv_tx->create_err = 1` so `mlx5e_tls_priv_tx_cleanup()` skips `MLX5_CMD_OP_DESTROY_TIS`. If the allocation loop in `create_work()` breaks early at `i`, pass `i` (never `MLX5E_TLS_TX_POOL_BULK`, and always `size >=` list length) to `mlx5e_tls_priv_tx_list_cleanup(pool->mdev, &local_list, i)`. [F55, F115, F134]

## External Contracts
- In `mlx5e_xfrm_update_stats()`, packet-offload SA lifetime counters (`x->curlft.packets` and `x->curlft.bytes`) must subtract `auth`, `trailer`, and `replay` drop counter packets/bytes as well as outer Ethernet and IP header bytes per succeeded packet from `ipsec_rule->fc`. In `mlx5e_psp_offload_handle_rx_skb()`, if `MLX5_PSP_METADATA_SYNDROME` is not `DECRYPTED` or `psp_dev_rcv()` fails, call `kfree_skb(skb)` and return `true`; on success set `skb->decrypted = 1` and return `false`. [F71, F184]
- A `struct mlx5_fpga_dma_buf` passed to `mlx5_fpga_sbu_conn_sendmsg()` remains caller-owned and must not be freed by the driver; on TX completion or flush (`mlx5_fpga_conn_sq_cqe`, `mlx5_fpga_conn_flush_send_bufs`), unmap it via `mlx5_fpga_conn_unmap_buf()` and invoke `buf->complete()`. [F14]

## Known Pitfalls
- `ipsec_fs_init_counters()` aliases `ipsec->rx_ipv6->fc = ipsec->rx_ipv4->fc`, so `ipsec_fs_destroy_counters()` and `mlx5e_accel_ipsec_fs_read_stats()` must only destroy or query `ipsec->rx_ipv4->fc`. In `tx_add_policy()`, call `setup_modify_header()` only for `XFRM_POLICY_ALLOW` (with non-zero `reqid`), never `XFRM_POLICY_BLOCK`. In `mlx5e_ipsec_policy_mask()`, guard `word_to_mask()` IPv6 calls with `sel->prefixlen_s != 32 * i` and `sel->prefixlen_d != 32 * i` because `word_to_mask(0)` returns `0xFFFFFFFF`. [F76, F126, F147]
- In `mlx5e_macsec_upd_txsa()`, set `tx_sa->active = ctx_tx_sa->active` before `if (tx_sa->assoc_num != tx_sc->encoding_sa) goto out;`, and in `macsec_rx_sa_active_update()`, revert `rx_sa->active = false` if `mlx5e_macsec_init_sa()` fails. In `mlx5e_macsec_create_object()`, when `epn_enabled` is true, copy the 12-byte `attrs->salt` in reversed 4-byte word order (`2 - i`). `mlx5_wqe_ctrl_seg::tis_tir_num` takes `cpu_to_be32(tis_tir_num << 8)`, whereas `mlx5_wqe_tls_progress_params_seg::tis_tir_num` in `fill_progress_params()` is unshifted. [F66, F98, F102, F107]
