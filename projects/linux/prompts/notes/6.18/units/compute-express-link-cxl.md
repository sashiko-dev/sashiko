# COMPUTE EXPRESS LINK (CXL)

This subsystem implements the CXL core and device drivers, including PCI Type-3 memory expander enumeration (`cxl_pci`), memory device and port topology attachment (`cxl_mem`, `cxl_port`), persistent memory integration with libnvdimm (`cxl_pmem`, `security.c`), register block probing/mapping (`core/regs.c`), and system physical address region management (`core/region.c`).

## Architecture & Data Flow
- An endpoint decoder with a valid `cxled->dpa_res` can still have `cxled->cxld.region == NULL`, so callers inspecting `cxled->cxld.region` or calling `cxl_dpa_to_region()` must check for `NULL`. Optional mapped registers `cxlds->regs.ras` and `dport->regs.rcd_pcie_cap` can also remain `NULL` after probing and must be checked before MMIO access. [F49, F50]
- In `cxl_region_setup_targets()`, `cxl_region_teardown_targets()`, and `cxl_region_decode_reset()`, when an endpoint's `cxlds->rcd` is true (RCH topology), there are no intermediate switch/host-bridge `cxl_port` levels with `cxl_ep` or `cxl_region_ref` entries between the endpoint and root ports, so walking intermediate ports must be skipped. [F52]
- For `CXL_REGION_F_AUTO` regions in `cxl_region_attach()`, `pos` must be `< 0`: endpoints are appended by `cxl_region_attach_auto()`, and once `p->nr_targets == p->interleave_ways`, `cxl_region_sort_targets()` must compute `cxled->pos` via `cxl_calc_interleave_pos()` for every target (without breaking early on error) and sort `p->targets` before `cxl_region_attach_position()` runs. [F60, F69, F91]
- In `cxl_port_setup_targets()`, when `is_cxl_root(parent_port)` is true, `parent_ig` must come from `p->interleave_granularity` (not the root decoder or `cxl_rr_load()`), and if the root's `interleave_ways` is 3, 6, or 12, `parent_iw` must be divided by 3 before computing `parent_ig * parent_iw` for `granularity_to_eig()`. For `CXL_REGION_F_AUTO`, `cxld->interleave_granularity != ig` must only be rejected when `iw > 1`. [F102, F103, F123]
- In `cxl_port_setup_targets()`, switch target count `iw` (`cxl_rr->nr_targets`) must be a power of two with `iw <= 8` and `iw <= cxlsd->nr_targets`. When `cxl_rr->nr_targets_set` is non-zero, peer `distance` must be computed by multiplying `cxl_rr_iter->nr_targets` across all ancestor `cxl_port` levels up to the root and then by `cxlrd->cxlsd.cxld.interleave_ways`, and `check_last_peer()` must reject `pos < distance` with `-ENXIO` before indexing `p->targets[pos - distance]`. [F67, F85, F92]
- In `cxl_region_attach_position()`, validating that root `dport` matches position `pos` must index `cxlrd->cxlsd.target[pos % iw]`, not XOR/address arithmetic. In `cxl_dpa_to_hpa()`, if `has_hpa_to_spa(cxlrd)` is true, `cxlrd->ops->hpa_to_spa(cxlrd, hpa)` must be applied before range validation and `cxl_is_hpa_in_chunk()` must be skipped. [F90, F99]
- When `cxl_extended_linear_cache_resize()` shifts `res->start` down by `cxlrd->cache_size`, it must verify `resource_size(res) == cache_size` and `res->start - cache_size >= cxlrd->res->start`, and set `p->cache_size = cache_size` so `region_res_match_cxl_range()`, `cxl_region_attach()`, `cxl_dpa_to_hpa()`, and `validate_region_offset()` (which rejects `offset < p->cache_size` or `>= resource_size(p->res)`) offset the CXL range. [F71, F88]
- Once `cxl_region_probe()` succeeds (`CXL_CONFIG_COMMIT`), any path lowering `cxlr->params.state` below `CXL_CONFIG_COMMIT` (`commit_store()`, `cxl_decoder_detach()`) must call `device_release_driver(&cxlr->dev)`. In `cxl_region_decode_reset()`, `CXL_REGION_F_NEEDS_RESET` must be set as each decoder is reset and cleared only after all decoders are torn down, while `cxl_region_can_probe()` rejects probing when it is set. [F62, F65]
- When tearing down targets in `cxl_port_reset_targets()` or detaching in `__cxl_decoder_detach()`, `cxl_rr->nr_targets_set` must be reset to `0` and `cxld->hpa_range` to `{ .start = 0, .end = -1 }` alongside clearing `p->targets[cxled->pos]` and decrementing `p->nr_targets`. Downstream-port state (`dport->gpf_dvsec`, `dport->rcrb`, `dport->regs.rcd_pcie_cap`) belongs on `struct cxl_dport`, and `cxl_switch_port_probe()` must reset `port->nr_dports = 0` on rebind. [F68, F72, F75]

## Synchronization
- Lock ordering: `cxlrd->range_lock` (held across `cxl_find_region_by_range()` and `construct_region()` in `cxl_add_to_region()`) nests outside `cxl_rwsem.region`, and `cxl_rwsem.region` must be acquired before `cxl_rwsem.dpa` whenever both are held (`__attach_target()`, `region_offset_to_dpa_result()`, poison inject/clear). All accesses to a registered `cxl_region`'s `params`, `port->regions`, and `cxlsd->target[]` outside driver-bound callbacks or post-`device_del()` teardown require `cxl_rwsem.region`. [F28, F166, F172]
- `device_release_driver(&cxlr->dev)` and `device_attach(&cxlr->dev)` must be called outside `cxl_rwsem.region`. In `cxl_decoder_detach()`, `__cxl_decoder_detach()` must take `get_device(&cxlr->dev)` under `cxl_rwsem.region` and drop it after `device_release_driver()`. In `commit_store()`, `p->state` must be set to `CXL_CONFIG_RESET_PENDING` under `cxl_rwsem.region`, the lock dropped for `device_release_driver()`, and `p->state == CXL_CONFIG_RESET_PENDING` reverified after re-acquiring `cxl_rwsem.region` before `cxl_region_decode_reset()`. [F25, F26]
- In `cxl_pci_mbox_irq()`, non-sanitize background command completions must wake `cxl_mbox->mbox_wait` via `rcuwait_wake_up()` without acquiring `cxl_mbox->mbox_mutex` (which `__cxl_pci_mbox_send_cmd()` holds while sleeping), whereas scheduling `mds->security.poll_dwork` for `CXL_MBOX_OP_SANITIZE` must hold `cxl_mbox->mbox_mutex` and check `if (mds->security.sanitize_node)`. [F21, F164]
- `cxl_pci_setup_mailbox()` must wait for `CXLMDEV_MBOX_IF_READY` and `cxl_pci_mbox_wait_for_doorbell()`, set `cxl_mbox->payload_size` (clamped to `SZ_1M` and `>= 256`), and initialize `mds->security.poll_dwork` before requesting `cxl_pci_mbox_irq` and enabling `CXLDEV_MBOX_CTRL_BG_CMD_IRQ`. In `cxl_event_config()`, `cxl_mem_alloc_event_buf()` must precede `cxl_event_irqsetup()` and `cxl_mem_get_event_records()`. [F31, F32, F83]
- Device-lock discipline: `cxl_mem_probe()` must hold `device_lock(endpoint_parent)` while checking `endpoint_parent->driver` and calling `devm_cxl_add_endpoint()`; `cxl_reset_done()` must hold `device_lock(&cxlmd->dev)` around `cxlmd->endpoint`; `rcd_pcie_cap_emit()` must hold `device_lock(root->uport_dev)` while verifying `root_dev->driver`; `cxl_handle_cper_event()` must hold `device_lock(&pdev->dev)` while verifying `pdev->driver == &cxl_pci_driver`; and `detach_nvdimm()` must drop `device_lock(dev)` before `device_release_driver(dev)`. [F36, F39, F41, F154, F162, F170]

## Object Lifetimes
- `__create_region()` must validate `mode` before `memregion_alloc()`, use `atomic_cmpxchg(&cxlrd->region_id, id, rc)`, and call `memregion_free(rc)` if `atomic_cmpxchg()` fails. `cxl_region_alloc()` consumes ownership of `id` on entry and transfers `cxlr->id` and `get_device(dev->parent)` on the root decoder to `cxl_region_release()`, which recycles `cxlr->id` into `cxlrd->region_id` via `atomic_try_cmpxchg()` (freeing the displaced `id`) before `put_device(dev->parent)`. [F1, F2, F42, F161]
- `__construct_region()` must call `get_device(&cxlr->dev)` on success so `construct_region()` returns a reference-counted `struct cxl_region *` matching `cxl_find_region_by_range()` for `__free(put_cxl_region)` in `cxl_add_to_region()`. Unlike `cxl_port_find_switch_decoder()` and `cxl_find_root_decoder()`, which return a reference-counted decoder requiring `put_device()`, `cxl_port_pick_region_decoder()` drops its reference and returns a borrowed pointer pinned by `cxl_rwsem.region`. [F3, F7]
- In `cxl_port_attach_region()`, `cxl_port_detach_region()`, and `cxl_rr_ep_add()`, `cxl_rr->nr_eps`, `cxl_rr->nr_targets`, `cxl_rr->endpoints`, and `cxld->region` (with its `get_device(&cxlr->dev)` reference) must be updated in lockstep and balanced in `cxl_rr_free_decoder()` when `nr_eps == 0`. In `cxl_region_attach()`, once `cxl_region_attach_position()` succeeds, a failure in `cxl_region_setup_targets()` must not clear `p->targets[pos]` or `cxled->pos` without detaching port region references. [F8, F10, F70]
- `cxl_region_decode_commit()` commits decoders bottom-up from endpoint to root for each target `0..nr_targets-1`; if `commit_decoder()` fails at `iter` on target `i`, it must reset target `i`'s committed decoders top-down from `iter` to `cxled` (guarding the loop with `ep && iter` before `iter = ep->next`) and then call `cxl_region_decode_reset(cxlr, i)`. `cxl_region_decode_reset()` must use a signed loop counter `for (i = count - 1; i >= 0; i--)` and reset all `count` targets without aborting early if `cxl_region_invalidate_memregion()` fails. [F11, F12, F94, F106]
- In `cxl_pmem_region_alloc()`, `cxlr_pmem` (allocated with `struct_size(cxlr_pmem, mapping, p->nr_targets)` and `nr_mappings = p->nr_targets` under `cxl_rwsem.region`) must be guarded by `__free(kfree)` until `device_initialize()` and `no_free_ptr()` transfer ownership and per-mapping `get_device(&cxlmd->dev)` references to `cxl_pmem_region_release()`. `cxlr_pmem_unregister()` must hold `device_lock(&cxl_nvb->dev)` and clear `cxlr->cxlr_pmem = NULL` and `cxlr_pmem->cxlr = NULL` before `device_unregister()`. [F4, F5, F130]
- `cxl_region_iomem_release()` must check `if (p->res->parent)` before `remove_resource(p->res)` and set `p->res = NULL` after `kfree(p->res)`. `cxl_setup_regs()` must unconditionally call `cxl_unmap_regblock(map)` after `cxl_probe_regs()`, and `cxl_rcrb_to_aer()`, `cxl_rcrb_to_linkcap()`, and `__rcrb_to_component()` must release their `SZ_4K` `request_mem_region()`/`ioremap()` window on all return paths. [F6, F19, F20]
- Probe ordering: in `cxl_pci_probe()`, host all `devm_*` actions on `&pdev->dev` (not `&cxlmd->dev`) and call `devm_cxl_sanitize_setup_notifier()` after `cxl_pci_setup_mailbox()` and `devm_cxl_add_memdev()`; in `cxl_mem_probe()`, call `devm_cxl_add_nvdimm()` before `devm_cxl_add_endpoint()` and `cxl_mem_active_inc()` only immediately before `devm_add_action_or_reset(dev, enable_suspend, NULL)`; in `cxl_endpoint_port_probe()`, call `get_device(&cxlmd->dev)` before `devm_add_action_or_reset(&port->dev, schedule_detach, cxlmd)`. [F15, F16, F138, F139, F140]

## API Contracts
- `cxl_count_regblock()` returns a non-negative count (`0` when none exist) or a negative errno, so callers must store it in a signed `int` and check `< 0`. Resource-address helpers `cxl_rcd_component_reg_phys()`, `__rcrb_to_component()`, and `cxl_rcrb_to_linkcap()` return `CXL_RESOURCE_NONE` (`(resource_size_t)-1`) on failure rather than `0`, which `devm_cxl_iomap_block()` rejects with `WARN_ON_ONCE`. [F45, F46]
- Downcast safety: in generic `struct device` iteration callbacks (`bus_for_each_dev`, `device_for_each_child`, `device_find_child`), callers must check `is_cxl_region()`, `is_endpoint_decoder()`, `is_switch_decoder()`, or `is_cxl_nvdimm()` before calling `to_cxl_*()`. `to_cxl_root(port)` must be gated by `is_cxl_root(port)`, and `to_cxl_memdev_state(cxlds)` returns `NULL` for `CXL_DEVTYPE_DEVMEM` (Type-2) devices and must be checked for `NULL`. [F131, F132, F133]
- Before committing or resetting HDM decoders (`__commit()` and `cxl_region_decode_reset()`), `cxl_region_invalidate_memregion()` must flush CPU caches. When attaching or setting up targets (`cxl_port_attach_region()`, `cxl_region_attach()`, `cxl_port_setup_targets()`), callers must verify `cxl_rr->nr_targets <= cxlsd->nr_targets` and `check_interleave_cap()`. Signature changes to `#ifdef CONFIG_CXL_REGION` helpers or `DECLARE_TESTABLE()` functions must update their `!CONFIG_CXL_REGION` stubs and `tools/testing/cxl/` wrappers. [F80, F81, F158, F160]

## Error Handling
- In `__cxl_pci_mbox_send_cmd()`, a non-zero device status in `mbox_cmd->return_code` still returns `0` without reading output payload registers, so callers of `cxl_mbox->mbox_send` must check both the return value and `mbox_cmd->return_code == CXL_MBOX_CMD_RC_SUCCESS` (or use `cxl_internal_send_cmd()`). In `drivers/cxl/core/region.c`, `cxl_find_region_by_name()` and `construct_region()` return `ERR_PTR()` on failure, whereas `cxl_find_region_by_range()` and `__cxl_decoder_detach()` return `NULL`. [F44, F48]
- In `cxl_pci_probe()` and `cxl_mem_probe()`, non-fatal helpers (`cxl_pci_ras_unmask()`, `devm_cxl_setup_features()`, `devm_cxl_setup_fwctl()`, `devm_cxl_memdev_edac_register()`) and missing component/RAS registers must not fail probe or leave a non-zero `rc`, whereas missing `status`, `mbox`, or `memdev` device registers must fail `cxl_probe_regs()` with `-ENXIO`. [F54, F152]
- `cxl_probe_component_regs()` and `cxl_probe_device_regs()` must zero-initialize `*map` at entry before checking capability headers. `cxl_decode_regblock()` must verify `offset <= pci_resource_len(pdev, bar)` before populating `map`, and `__cxl_find_regblock_instance()` must reset `map->resource = CXL_RESOURCE_NONE` if the target instance is not found. [F55, F56, F86, F108]

## External Contracts
- In `drivers/cxl/pmem.c`, `cxl_pmem_ctl()` must initialize `*cmd_rc = 0` and return `-ENOTTY` if `!nvdimm` or `cmd` is not in `nvdimm_cmd_mask(nvdimm)`. `cxl_pmem_get_config_data()` and `cxl_pmem_set_config_data()` must validate `buf_len` against `sizeof(*cmd)` and `struct_size()` (plus 4 status bytes for set) before writing `0` to `cmd->status` or `&cmd->in_buf[cmd->in_length]`, and `cxl_pmem_get_security_flags()` must return `0` on failure or map flags via `set_bit(NVDIMM_SECURITY_*, ...)`. [F57, F84, F176, F177]

## Known Pitfalls
- 64-bit arithmetic on 32-bit builds: cast `SZ_256M` to `u64` before multiplying by `p->interleave_ways` in `alloc_hpa()`; use `div64_u64_rem()`, `do_div()`, and `div64_u64()` instead of `/` or `%` on 64-bit HPA/DPA offsets; use `GENMASK_ULL()` or `~((u64)GENMASK(...))` for 64-bit masks (`CXL_DPA_MASK`, `CXL_POISON_START_MASK`); and cast `reg_hi`/`bar1` to `u64` before `<< 32`. [F117, F118, F119, F120, F124]
- Flags used with `test_bit()`/`set_bit()` (`CXL_FW_CANCEL`, `CXL_REGION_F_*`, `*_cmd_enabled_bits`) must be unshifted bit indices, whereas `cxl_map_component_regs()` takes `BIT(CXL_CM_CAP_CAP_ID_*)`. In `cxl_dpa_to_hpa()`, check `if (!cxled || cxlmd != cxled_to_memdev(cxled))` after the `p->targets` loop because `cxled` stays pointing at the last target when the loop exhausts `p->nr_targets`. [F59, F100]
