# AMD DISPLAY CORE

AMD Display Core (`amdgpu_dm` and `dc`) bridges Linux DRM/KMS atomic modesetting, the AMDGPU IP lifecycle, and the OS-agnostic Display Core engine, managing atomic commits, VRR/PSR/Panel Replay, DP MST/DSC, color management, HDCP, two-tier IRQs, DMUB notifications, VBIOS parsing (`dc/bios`), and display clocks (`dc/clk_mgr`).

## Architecture & Data Flow

- Connector type safety: `SIGNAL_TYPE_VIRTUAL` links use `struct amdgpu_dm_wb_connector`, so connector loops must exclude `DRM_MODE_CONNECTOR_WRITEBACK` before calling `to_amdgpu_dm_connector()`. `struct drm_connector base` must stay at offset 0 of `struct amdgpu_dm_connector` for debugfs casts, and both connector types must use `amdgpu_dm_connector_funcs_reset` and `amdgpu_dm_connector_atomic_duplicate_state` so `to_dm_connector_state` is valid. [F70, F112, F160, F296]
- Cursor modes and zpos: when any non-cursor plane on a CRTC is in `drm_atomic_state`, `amdgpu_dm_atomic_check()` must add all other non-cursor planes in `crtc->state->plane_mask` before `drm_atomic_normalize_zpos()`, and call `drm_atomic_add_affected_planes()` if `dm_crtc_get_cursor_mode()` selects `DM_CURSOR_OVERLAY_MODE`. `__get_next_zpos()` orders by `(new_plane_state->zpos, plane->base.id)` (not `normalized_zpos`), and `dm_crtc_get_cursor_mode()` must `break` once `entire_crtc_covered` is true and select `DM_CURSOR_OVERLAY_MODE` if it finishes false. [F57, F85, F99]
- Cursor fallback and disable: if enabling a cursor plane in `DM_CURSOR_OVERLAY_MODE` fails with `-EINVAL` in `dm_update_plane_state()`, it validates `dm_check_native_cursor_state()` and resets `cursor_mode` to `DM_CURSOR_NATIVE_MODE`, which `amdgpu_dm_atomic_check()` must re-validate against `dm_crtc_get_cursor_mode()`. `amdgpu_dm_commit_planes()` must disable the native cursor before plane updates if `dm_old_crtc_state->cursor_mode` was `DM_CURSOR_NATIVE_MODE` and `cursor_mode` becomes `DM_CURSOR_OVERLAY_MODE` or `active_planes` becomes 0. [F58, F59]
- Suspend/resume and GPU reset: before `drm_atomic_helper_resume()` in `dm_destroy_cached_state()`, `dm->cached_state` must set every CRTC's `active_changed` and `color_mgmt_changed` to true, reset freesync config, and release/null `stream` and `dc_state`. On S3/S4 resume, `dm_resume()` must release and recreate `dm_state->context` via `dc_state_create()`; during GPU reset, it must call `link_enc_cfg_copy(adev->dm.dc->current_state, dc_state)` on `dm->cached_dc_state` and force full stream/plane updates. [F53, F54, F55]
- Self-refresh (PSR / Panel Replay) gating: `amdgpu_dm_enable_self_refresh()` must decrement `aconn->sr_skip_count` on `UPDATE_TYPE_FAST`, set `allow_sr_entry = !aconn->sr_skip_count`, and gate entry on `allow_sr_entry`, `!vrr_active`, and the 500ms `psr_dirty_rects_change_timestamp_ns` delay. In `amdgpu_dm_crtc_set_panel_sr_feature()`, entry requires `allow_sr_entry && !vrr_active && !is_sr_active && !is_crc_window_active`, and `else if (vblank_enabled)` must precede PSR enable so PSR1 is disabled and PSR is never enabled while vblank is on. [F52, F235, F274]
- Backlight state: `aconnector->bl_idx` starts at `-1` and must be checked (`>= 0`) before indexing `dm->backlight_dev`, `backlight_caps`, `backlight_link`, or `brightness`. `amdgpu_dm_commit_streams()` only restores backlight when `dm->restore_backlight` is true (then clears it); `amdgpu_dm_backlight_set_level()` only updates `dm->actual_brightness[bl_idx]` on success; and setting `caps->aux_support = true` in `update_connector_ext_caps()` must set `dc_link->backlight_control_type = BACKLIGHT_CONTROL_AMD_AUX`. [F48, F49, F50, F71]
- MST DSC and color management: in `compute_mst_dsc_configs_for_link()` and `set_dsc_configs_from_fairness_vars()`, `params` is indexed `0..count-1` while shared `vars` is indexed `vars[i + k]` (`k = *link_vars_start_index`, advanced by `count` per link), and all streams on `stream->link` must be marked in `computed_streams[]`. When `drm_dp_mst_atomic_check()` fails in `increase_dsc_bpp()`/`try_disable_dsc()`, `vars[next_index].pbn` must be restored and `drm_dp_atomic_find_time_slots()` called again. `amdgpu_dm_update_plane_color_mgmt()` resets `in_transfer_func` to `TF_TYPE_BYPASS` and rejects (`-EINVAL`) setting both plane and CRTC degamma; `amdgpu_dm_verify_lut3d_size()` requires `dpp.hw_3d_lut && mpc.preblend` and validates `lut3d_size == 4913`. [F237, F239, F252, F261, F279, F308]
- DCE clocks and VBIOS parsers: `dce_clk_mgr_construct()` sets `base->clks.max_supported_dispclk_khz` from `max_clks_by_state[DM_PP_CLOCKS_STATE_PERFORMANCE].display_clk_khz` after `construct_integrated_info()` sorts `disp_clk_voltage[]` ascending by `max_supported_clk`, and `dce_update_clocks()` clamps `patched_disp_clk` via `MIN(max_disp_clk, ...)` and updates `clks.dispclk_khz` before `dce*_pplib_apply_display_requirements()`. `BP_FROM_DCB` must never be used in shared helpers (`bios_parser_helper.c`) because `bios_parser` layouts differ between v1 and v2; VBIOS record loops must stop on `LAST_RECORD_TYPE`/`ATOM_RECORD_END_TYPE` or `!record_size`, verify `sizeof(record) <= header->record_size`, and advance `offset` by `record_size` before any `continue`. [F382, F385, F389, F397, F411, F431, F432, F435]

## Synchronization

- Atomic check and modeset locks: on full updates (`lock_and_validation_needed`), `amdgpu_dm_atomic_check()` must call `dm_atomic_get_state()`, `do_aquire_global_lock()` (holding `crtc->commit_lock` while taking `drm_crtc_commit_get()` on the head of `crtc->commit_list` and dropping it before waiting on `hw_done`/`flip_done`), and `drm_dp_mst_atomic_check()` after `dm_update_mst_vcpi_slots_for_dsc()` and before `dc_validate_global_state()`. Callers of `dm_restore_drm_connector_state()`/`dm_force_atomic_commit()` must hold `drm_modeset_lock_all(dev)`. [F25, F92, F147, F148]
- `dm->dc_lock`, vblank workqueue, and GPU reset: `amdgpu_dm_commit_planes()` and `amdgpu_dm_commit_streams()` must flush `dm->vblank_control_workqueue` outside `dm->dc_lock` before disabling PSR/Replay or programming DC. During GPU reset (`amdgpu_in_reset(adev)`), `dm_suspend()` returns with `dm->dc_lock` held and `dm_resume()` unlocks it after `dm_gpureset_commit_state()` and `amdgpu_dm_irq_resume_late()` before calling `amdgpu_dm_backlight_set_level()` (which locks `dc_lock` and toggles `dc_allow_idle_optimizations(false/true)` when `idle_allowed` is set). [F23, F132, F144]
- Two-tier IRQs, VRR, and vblank atomic context: `amdgpu_dm_irq_handler()` calls `dc_interrupt_ack()` before dispatching. High-context handlers (`irq_handler_list_high_tab`) run under `irq_handler_list_table_lock` (`spin_lock_irqsave`) and must not sleep or call `amdgpu_dm_irq_register_interrupt()` (`GFP_KERNEL`), while `amdgpu_dm_irq_schedule_work()` uses `GFP_ATOMIC`. `amdgpu_dm_crtc_set_vblank()` runs under vblank/event spinlocks, so it allocates `vblank_control_work` with `GFP_ATOMIC` and defers `dc_lock`/PSR/idle-optimization updates to `amdgpu_dm_crtc_vblank_control_worker`. In `dm_pflip_high_irq()`, when `vrr_active && vpos >= v_blank_start`, it must append the event to `vblank_event_list` under `event_lock` for `dm_vupdate_high_irq()` instead of sending/putting vblank directly. [F30, F247, F314, F321, F322, F323, F325]
- Secure display, DMUB, HPD, and HDCP locks: `event_lock` and `crtc_ctx->crc_info.lock` require IRQ-disabling spinlocks; `crc_win_update_set()` locks `dc_lock` before `event_lock`, and `amdgpu_dm_crtc_handle_crc_window_irq()` defers `LEGACY_MODE` work to `forward_roi_work`/`notify_ta_work` (which drop `event_lock` before locking `mode_config.mutex`, `dc_lock`, or `securedisplay_context.mutex`). `dc_enable_dmub_outbox()` follows DMUB completion/wq/callback init; `dm_dmub_outbox1_low_irq()` `kmemdup`s (`GFP_ATOMIC`) HPD notifications onto `delayed_hpd_wq`; and DPIA AUX holds `dpia_aux_lock` through `reinit_completion(&dmub_aux_transfer_done)`. `dm_suspend()` calls `amdgpu_dm_irq_suspend()` before `hpd_rx_irq_work_suspend()`; `hdcp_w->mutex` nests inside `connection_mutex`; and `dm.audio_lock` unlocks before `amdgpu_dm_audio_eld_notify()` and nests outside `eld_mutex`. [F16, F21, F26, F27, F117, F141, F191, F192, F200, F201, F327, F329, F330]

## Object Lifetimes

- Sinks, streams, and planes: `create_stream_for_sink()` must retain `aconnector->dc_sink` (or call `create_fake_sink()`) before `dc_create_stream_for_sink(sink)` and unconditionally call `dc_sink_release(sink)` before returning. In `amdgpu_dm_update_connector_after_detect()`, `sink` uses `__free(sink_release)`, so storing `sink` or `dc_em_sink` into `aconnector->dc_sink` requires releasing any prior `dc_sink` and calling `dc_sink_retain()`. `dm_update_crtc_state()`, `amdgpu_dm_crtc_duplicate_state()`, and `amdgpu_dm_crtc_destroy_state()` must pair `dc_stream_retain/release()`. In `dm_update_plane_state()`, `dc_new_plane_state` must be released on error before assigning `dm_new_plane_state->dc_state`; in the `!enable` pass, removing a plane/stream from `dm_state->context` must release it and set `dc_state`/`stream` to `NULL`. [F1, F2, F4, F5, F6, F175]
- Modeset IRQs, events, VRR, and runtime PM: `amdgpu_dm_commit_streams()` calls `manage_dm_interrupts(adev, acrtc, NULL)`, releases `dm_old_crtc_state->stream`, and calls `pm_runtime_get_noresume()` only when `dm_new_crtc_state->stream` is non-NULL; `amdgpu_dm_atomic_commit_tail()` retains `dm_new_crtc_state->stream` for `acrtc->dm_irq_params.stream`, enables interrupts afterward, and calls `pm_runtime_put_autosuspend()` only for CRTCs transitioning from `active` to `!active`. Transferring `state->event` to `acrtc_attach->event` in `amdgpu_dm_commit_planes()` must clear `state->event = NULL`. `amdgpu_dm_handle_vrr_transition()` pairs `amdgpu_dm_crtc_set_vupdate_irq(crtc, true/false)` with `drm_crtc_vblank_get/put(crtc)`, while `dm_gpureset_toggle_interrupts()` uses `dc_interrupt_set()` rather than `amdgpu_irq_get/put()`. [F8, F9, F10, F13, F138]
- Workqueues, connectors, VBIOS, and clock managers: `schedule_dc_vmin_vmax()` and `amdgpu_dm_crtc_set_vblank()` retain `stream` before queuing work, and their workers release `stream` and `kfree()` the work. In `dm_hw_fini()`, `amdgpu_dm_hpd_fini()` and `amdgpu_dm_irq_fini()` (flushing `irq_handler_list_low_tab` unlocked before `unregister_all_irq_handlers()`) precede `amdgpu_dm_fini()`. `hdcp_destroy()` calls `cancel_delayed_work_sync()` on per-link works without `hdcp_work[i].mutex`; `hdcp_w->aconnector[conn_index]` pairs `drm_connector_get/put()`. `bios_get_image()`/`GET_IMAGE()` return borrowed pointers into `init->bios` that must never be `kfree()`d. Every ASIC clock manager struct must embed `struct clk_mgr_internal base` at offset 0 for `dc_destroy_clk_mgr()` and pair `clk_mgr_exit_optimized_pwr_state()` with `clk_mgr_optimize_pwr_state()` in LIFO order. [F14, F120, F171, F174, F189, F307, F333, F355, F357, F359]

## API Contracts

- Atomic check, IRQs, and backlight: `dm_atomic_get_state()` is only valid during `atomic_check` (commit paths use `dm_atomic_get_new_state()`). `amdgpu_dm_crtc_helper_atomic_check()` rejects (`-EINVAL`) enabling a CRTC without `crtc->primary` in `plane_mask`, or `async_flip` when `update_type != UPDATE_TYPE_FAST`, `lock_and_validation_needed`, or memory type changed. `dm_vupdate_high_irq()` and `dm_crtc_high_irq()` must null-check `acrtc->dm_irq_params.stream`, and `dm_crtc_high_irq()` only calls `amdgpu_dm_crtc_handle_vblank()` when `!vrr_active`. In `manage_dm_interrupts()`, `config.offdelay_ms` must be positive (`1`), never `0`, when `disable_immediate = true`. `convert_brightness_from/to_user()` widens millinit AUX bounds to `u64` with `DIV_ROUND_CLOSEST_ULL()`. [F33, F38, F100, F145, F156, F158, F163, F343, F344]
- MST, DSC, and VBIOS: `dm_encoder_helper_atomic_check()` and `add_affected_mst_dsc_crtcs()` must null-check `mst_output_port && mst_root` (resetting `aconnector = NULL` on `continue`). `drm_dp_calc_pbn_mode()` takes `bpp << 4`, DSC bandwidth takes `bpp * 16`, and `dm_update_mst_vcpi_slots_for_dsc()` uses `DIV_ROUND_UP(pbn, pbn_div)` after checking `pbn_div != 0`. `EXEC_BIOS_CMD_TABLE()` takes the struct lvalue directly and returns `true` on success; DCN and DCE60/SI code in `clk_mgr.c` and command table helpers require `CONFIG_DRM_AMD_DC_FP` and `CONFIG_DRM_AMD_DC_SI` guards. [F46, F47, F98, F106, F229, F372, F429, F448, F450]

## Error Handling

- Divisors, LUTs, AUX, and VBIOS: `dm_get_plane_scale()` checks `plane_src_w && plane_src_h`; FreeSync helpers check `timing.h_total && timing.v_total`; `dm_vupdate_high_irq()` checks `frame_duration_ns > 0` before `ktime_divns()`; and `dce_adjust_dp_ref_freq_for_ss()` checks `dprefclk_ss_divider != 0`. LUT sizes must be validated via `amdgpu_dm_verify_lut_sizes()`/`amdgpu_dm_verify_lut3d_size()` before `__is_lut_linear()` or `__drm_lut_to_dc_gamma()`. `dm_dp_aux_transfer()` rejects `msg->size > 16` (`-E2BIG`) and logs transient errors with `drm_dbg_dp()`. `dm_cache_state()` resets `cached_state = NULL` on `IS_ERR()`; `compute_mst_dsc_configs_for_link()` falls through to DSC on `-ENOSPC`; and `dc_bios->integrated_info` and `bp->cmd_tbl.*` must be null-checked. [F36, F104, F105, F108, F230, F251, F260, F282, F337, F370, F371, F424]

## Known Pitfalls

- 64-bit arithmetic and loop hazards: `mmhub_read_system_context()`, `dm_mst_get_pbn_divider()`, `kbps_to_peak_pbn()`, `bpp_x16_from_pbn()`, `kbps_from_pbn()`, `adjust_display_pll_v2/v3()`, and `dce11_pplib_apply_display_requirements()` must widen to 64-bit and use `div_u64`/`div64_u64`/`div64_s64`/`DIV64_U64_ROUND_UP`. `dc_state->stream_status[k]` is indexed with `k`; `amdgpu_dm_commit_zero_streams()` copies streams to `del_streams[]` before removal; `remove_irq_handler()` checks `handler_removed`; `amdgpu_dm_commit_planes()` increments `planes_count` before `continue` when `!plane_needs_flip` and polls vblank via `(int)(target_vblank - amdgpu_get_vblank_counter_kms(pcrtc)) > 0`; `dm_dmub_outbox1_low_irq()` calls `dc_stat_get_dmub_notification()` at the start of every pass; and raw EDID size is `(edid->extensions + 1) * EDID_LENGTH`. [F86, F89, F94, F95, F102, F109, F270, F287, F288, F300, F423, F427]
