# BROADCOM B53/SF2 ETHERNET SWITCH DRIVER

This unit implements DSA drivers for Broadcom RoboSwitch (B53) and Starfighter 2 (`bcm_sf2`) Ethernet switches. `b53_common.c` provides core switch logic (VLANs, ARL FDB/MDB tables, bridge offload, mirroring, MIB stats, EEE, and phylink), backed by MDIO (`b53_mdio.c`), MMIO (`b53_mmap.c`), SPI (`b53_spi.c`), and SRAB (`b53_srab.c`) register glue and SerDes PCS (`b53_serdes.c`). `bcm_sf2.c` and `bcm_sf2_cfp.c` layer on `b53_common` for Starfighter 2 SoC switches, adding GPHY/MDIO, crossbar/ACB/WoL control, and CFP TCAM `rxnfc` flow classification.

## Architecture & Data Flow

- `b53_vlan_add()` and `b53_vlan_del()` must always update software shadows `dev->vlans[vlan->vid]` and `dev->ports[port].pvid` before returning early when `!dev->vlan_filtering`, and only program hardware VLAN entries and `B53_VLAN_PORT_DEF_TAG` when `dev->vlan_filtering` is true. When `b53_vlan_add()` is called without `BRIDGE_VLAN_INFO_PVID` on a VLAN where `vlan->vid == dev->ports[port].pvid`, it must reset `dev->ports[port].pvid` to `b53_default_pvid(dev)`, write `B53_VLAN_PORT_DEF_TAG(port)` if `dev->vlan_filtering` is enabled on a non-CPU port, and fast-age `old_pvid`. [F44, F45]
- Code accessing the default untagged VLAN in `dev->vlans[]` (`b53_configure_vlan()`, `b53_setup()`, `b53_br_join()`, `b53_br_leave()`) must index by `b53_default_pvid(dev)` rather than `0` (BCM5325/5365 use 1; others use 0). When `dev->vlan_filtering` is true, `b53_br_join()` must clear `BIT(port)` and `b53_br_leave()` must set `BIT(port)` in `dev->vlans[b53_default_pvid(dev)]` and hardware (and in `B53_JOIN_ALL_VLAN_EN` on `is58xx(dev)`), preserving the CPU port bit and `vl->untag`. [F47, F63]
- Per-port bridge forwarding masks in `B53_PVLAN_PORT_MASK(port)` must be shadowed in `dev->ports[port].vlan_ctl_mask` by `b53_br_join()`/`b53_br_leave()` (and `b53_br_leave()` must guard `pvlan &= ~BIT(i)` with `if (port != i)`). `b53_enable_port()` must OR `vlan_ctl_mask` with `BIT(port)` and call `b53_imp_vlan_setup()`, and must never reset standalone port attributes (flooding, learning, `b53_set_eap_mode()`), which belong in `b53_setup_port()`/`b53_br_join()`/`b53_br_leave()`. [F48, F49, F95]
- `bcm_sf2_sw_set_wol()` must keep `BIT(cpu_port)` set in `priv->wol_ports_mask` whenever at least one user port has WoL enabled and clear it when the last user port is cleared. When a port's bit is set in `priv->wol_ports_mask`, `bcm_sf2_port_disable()` must only set `BIT(port)` in `CORE_DIS_LEARN` and return without disabling the port, GPHY, or TXQ memory, `bcm_sf2_sw_mac_link_down()` must return early, and `bcm_sf2_sw_suspend()`/`bcm_sf2_sw_resume()` must keep `priv->clk` enabled (`!priv->wol_ports_mask` gates `clk_disable_unprepare`/`clk_prepare_enable`). [F8, F56, F118]
- In `bcm_sf2_cfp.c`, CFP TCAM index `0` is permanently reserved in `priv->cfp.used` and `priv->cfp.unique` (`DECLARE_BITMAP(..., CFP_NUM_RULES)` of 256, so `priv->num_cfp_rules <= CFP_NUM_RULES`), making valid user rule locations `1 .. bcm_sf2_cfp_rule_size(priv)`. In `bcm_sf2_cfp_ipv6_rule_set()`, slice 0 (`rule_index[0]`) is marked only in `used` while chained slice 1 (`rule_index[1]`, returned in `fs->location`) is marked in both `used` and `unique`, and `bcm_sf2_cfp_rule_remove()` must follow `CHAIN_ID_MASK` in `CORE_CFP_DATA_PORT(6)` to delete both slices. [F59, F72, F109]
- In `bcm_sf2_cfp_rule_get_all()`, `for_each_set_bit_from(index, priv->cfp.unique, priv->num_cfp_rules)` must start at `index = 1` while indexing `rule_locs[rules_cnt]` with `rules_cnt = 0`. In `bcm_sf2_cfp_get_ethtool_stats()`, the output index into `data` must be `iter = (i - 1) * s + j` (not `iter++`) because the loop skips indices `i` where `bcm_sf2_cfp_rule_find()` is `NULL`. `struct cfp_rule::fs` in `priv->cfp.rules_list` must keep un-inverted flow masks, so `bcm_sf2_cfp_rule_get()` must copy `rule->fs` into `nfc->fs` before calling `bcm_sf2_invert_masks(&nfc->fs)`. [F61, F93, F94]
- When scanning ARL bins in `b53_arl_read()` and `b53_arl_read_25()`, each bin must be checked for validity first (recording invalid bins in `free_bins`), then MAC equality, and when `dev->vlan_enabled` is true, VID equality, returning `0` immediately on match or `-ENOENT`/`-ENOSPC` with `*idx` set to `find_first_bit(free_bins, ...)`. After `b53_flush_arl()` polls until `FAST_AGE_DONE` clears on `B53_FAST_AGE_CTRL`, it must write `FAST_AGE_DYNAMIC` back to `B53_FAST_AGE_CTRL`. [F51, F86]
- In `b53_switch_init()`, `dev->num_ports` and `dev->ports` must be sized using `fls(dev->enabled_ports)` rather than `hweight16(dev->enabled_ports)` because `dev->ports` is indexed by physical port number across sparse bitmasks. In `bcm_sf2.c`, port loops calling `dsa_to_port()`, `dsa_is_cpu_port()`, or `dsa_is_user_port()` must bound `port` by `ds->num_ports` (or `priv->hw_params.num_ports`), not `DSA_MAX_PORTS`, and `priv->port_sts[port].enabled` must be updated before calling `bcm_sf2_recalc_clock(ds)`. [F55, F66, F106]

## Synchronization

- Switch register accesses via `struct b53_io_ops` must go through `b53_read*`/`b53_write*` wrappers that hold the sleeping mutex `dev->reg_mutex` (so `b53_io_ops` callbacks must never call `b53_read*`/`b53_write*`), and all `b53_read*`/`b53_write*` callers (such as `b53_port_event()`) must only execute in process context, never from hardirq handlers. All ARL helpers (`b53_arl_op`, `b53_arl_rw_op`, `b53_arl_op_wait`, `b53_arl_read`, `b53_arl_read_25`, `b53_arl_search_wait`, `b53_arl_search_rd`) must be called with `dev->arl_mutex` held, which nests outside `dev->reg_mutex`. [F17, F130, F132]
- In `bcm_sf2`, 64-bit accesses to `priv->core` must use `core_readq`/`core_writeq` (which take `priv->indir_lock` via `spin_lock`) to serialize the shared `REG_DIR_DATA_READ` and `REG_DIR_DATA_WRITE` upper-word latch registers with paired 32-bit `core_readl`/`core_writel`, and must not be called from hard IRQ context. `intrl2_0_mask_clear`/`intrl2_1_mask_clear` must clear bits in `priv->irq0_mask`/`priv->irq1_mask` before writing `INTRL2_CPU_MASK_CLEAR`, while `intrl2_*_mask_set` must write `INTRL2_CPU_MASK_SET` before setting `irq*_mask`. [F19, F21]
- In `bcm_sf2_cfp.c`, `priv->cfp.lock` must be held across all runtime accesses to CFP indirect registers (`CORE_CFP_ACC`, `CORE_CFP_DATA_PORT`, `CORE_CFP_MASK_PORT`) and CFP rule state (`priv->cfp.used`, `priv->cfp.unique`, `priv->cfp.rules_list`), and must be released before calling the conduit device's `p->ethtool_ops->get_rxnfc` or `p->ethtool_ops->set_rxnfc`. [F20]
- MDIO bus accesses inside `b53_mdio_ops` (`b53_mdio.c`) and `bcm_sf2_sw_mdio_{read,write}` (`bcm_sf2.c`) must use `mdiobus_read_nested` and `mdiobus_write_nested` because they execute beneath slave `user_mii_bus` callbacks that already hold `user_mii_bus->mdio_lock`. [F135]

## Object Lifetimes

- In `bcm_sf2_sw_probe()`, `bcm_sf2_gphy_enable_set(priv->dev->ds, true)` must power on the GPHY before `bcm_sf2_mdio_register(ds)` (`bcm_sf2_sw_shutdown()` must also call it when `priv->hw_params.num_gphy == 1`), and `bcm_sf2_intr_disable(priv)` must precede `devm_request_irq()`. Teardown in `bcm_sf2_sw_probe()` error paths and `bcm_sf2_sw_remove()` must call `bcm_sf2_intr_disable()`, `dsa_unregister_switch()`, and `bcm_sf2_cfp_exit()` before `bcm_sf2_mdio_unregister(priv)`, then `clk_disable_unprepare(priv->clk_mdiv)`, and finally `clk_disable_unprepare(priv->clk)`. [F6, F29, F112, F113]
- In `bcm_sf2_mdio_register()`, `dn` from `of_find_compatible_node()` must be released with `of_node_put(dn)`, any `phydev` from `of_phy_find_device(child)` to be unregistered requires both `phy_device_remove(phydev)` and `phy_device_free(phydev)`, and `priv->master_mii_bus->dev` (`of_mdio_find_bus()`) and `priv->user_mii_bus` must be released in `bcm_sf2_mdio_unregister()` and error paths. In `bcm_sf2_sw_probe()`, `of_node_get(dn)` must precede `of_find_node_by_name(dn, "ports")`, and `ports` must be released with `of_node_put(ports)`. [F3, F4, F114]
- Across all B53/SF2 bus drivers (`b53_mdio`, `b53_mmap`, `b53_spi`, `b53_srab`, `bcm_sf2`), `.shutdown` must clear device drvdata to `NULL` after `b53_switch_shutdown()`/`dsa_switch_shutdown()`, and both `.remove` and `.shutdown` must return early if drvdata is `NULL`. In `b53_srab.c`, every `b53_srab_read*`/`write*` accessor calling `b53_srab_request_grant(dev)` must call `b53_srab_release_grant(dev)` on all paths (including errors), and `b53_srab_irq_disable()` must check `p->irq_enabled` before `free_irq()` and clearing `p->irq_enabled = false`. [F5, F9, F10]
- In `bcm_sf2_cfp_ipv6_rule_set()`, `rule_index[1]` is reserved with `set_bit(rule_index[1], priv->cfp.used)` before searching for companion `rule_index[0]`, and must be rolled back with `clear_bit(rule_index[1], priv->cfp.used)` on every subsequent error path. `bcm_sf2_cfp_rule_remove()` only invalidates the hardware TCAM entry and bitmaps for `bcm_sf2_cfp_resume()`, whereas `bcm_sf2_cfp_rule_del()` and `bcm_sf2_cfp_exit()` (using a `_safe` list iterator) also `list_del(&rule->next)` and `kfree(rule)`. [F11, F12, F89]

## API Contracts

- `b53_read*`/`b53_write*` take `(dev, page, reg, ...)` with page second and offset third. In `bcm_sf2`, `core_writel`, `reg_writel`, `intrl2_*_writel`, `fcb_writel`, `acb_writel`, and `core_writeq` take `(priv, val, off)` with value second and offset third. `reg_readl`/`reg_writel` take an `enum bcm_sf2_reg_offs` index into `priv->reg_offsets[]` (never a raw byte offset), and because 7445/7278 offset tables omit BCM4908-only entries, per-port RGMII/LED indices must use `bcm_sf2_reg_rgmii_cntrl()`/`bcm_sf2_reg_led_base()` or check `priv->type`. [F25, F26, F69]
- In `bcm_sf2.c`, `ds->priv` points to `struct b53_device` (whose `dev->priv` is `struct bcm_sf2_priv`, accessed via `bcm_sf2_to_priv(ds)`), whereas `pdev->dev` drvdata (`dev_get_drvdata`/`platform_get_drvdata`) points directly to `struct bcm_sf2_priv`, unlike `b53_mmap.c`, `b53_srab.c`, `b53_mdio.c`, and `b53_spi.c` where device drvdata stores `struct b53_device *`. [F105]
- On `BCM5325_DEVICE_ID` and `BCM5365_DEVICE_ID`, the CPU port has DSA port index `B53_CPU_PORT_25` (5), which must be remapped to hardware port index `B53_CPU_PORT` (8) when accessing `B53_PVLAN_PORT_MASK`, `B53_PORT_CTRL`, `B53_IEEE_UCAST_DLF`, `B53_IEEE_MCAST_DLF`, or (on 5365) `B53_MIB_PAGE`. ARL packing/unpacking on BCM5325 and BCM5365 must use `b53_arl_to_entry_25()`/`b53_arl_from_entry_25()` on the single 64-bit `B53_ARLTBL_MAC_VID_ENTRY(n)` register, whereas other chips use `b53_arl_to_entry()`/`b53_arl_from_entry()` with `B53_ARLTBL_DATA_ENTRY(n)`. [F41, F79]
- `b53_vlan_prepare()` must reject `vlan->vid >= dev->num_vlans` (`-ERANGE`) and `vlan->vid == 0` on BCM5325/5365 (`-EOPNOTSUPP`), and `b53_vlan_add()`/`b53_vlan_del()` must ignore `vlan->vid == 0` without touching `dev->vlans[0]`, `pvid`, or hardware. `b53_vlan_add()` must force `untagged = false` on CPU ports (and `b53_vlan_port_needs_forced_tagged()` returns true on CPU ports when `DSA_TAG_PROTO_NONE`). On `BCM7278_DEVICE_ID`, port 7 must be rejected with `-EINVAL` in `b53_br_join()` and in `b53_vlan_prepare()` if `!(vlan->flags & BRIDGE_VLAN_INFO_UNTAGGED)`. [F46, F64, F137, F138, F143]
- In `b53_mmap.c`, `b53_mmap_phy_enable()`/`disable()` must check `if (priv->phy_info)` (as `priv->gpio_ctrl` can be an `ERR_PTR`), and `bcm63xx_ephy_set()` callers must check `BIT(port) & priv->phy_info->ephy_port_mask` before indexing `ephy_offset[port]` (and only disable `BIT(info->ephy_bias_bit)` when no other EPHY ports remain enabled). `b53_mmap_read48()`/`write48()` require `reg % 2 == 0` and must split into 16-bit at `reg` + 32-bit at `reg + 2` when `reg % 4 != 0`, or 32-bit at `reg` + 16-bit at `reg + 4` when `reg % 4 == 0`. [F37, F75, F77, F126]

## Error Handling

- `b53_change_mtu()` must return `0` before calling `b53_set_jumbo()` when `is5325(dev) || is5365(dev)` or `!dsa_is_cpu_port(ds, port)`, because `b53_set_jumbo()` unconditionally returns `-EINVAL` on BCM5325 and BCM5365. [F28]
- In `bcm_sf2_get_rxnfc()` and `bcm_sf2_set_rxnfc()`, `-EOPNOTSUPP` returned by the conduit device's `p->ethtool_ops->get_rxnfc` or `set_rxnfc` callback must be normalized to `0`, while any other error from `p->ethtool_ops->set_rxnfc` must roll back the switch rule via `bcm_sf2_cfp_rule_del()` under `priv->cfp.lock`. [F33]

## External Contracts

- `b53_get_max_mtu()` and `b53_change_mtu()` operate on L3 payload MTU in bytes (comparing `mtu > ETH_DATA_LEN` and subtracting `ETH_HLEN + VLAN_HLEN + ETH_FCS_LEN` from the maximum frame size), whereas `dev->jumbo_size_reg` in `b53_set_jumbo()` is programmed with full frame sizes (`JMS_MIN_SIZE` or `JMS_MAX_SIZE`). [F27]
- Callers of `bcm_sf2_cfp_rule_addr_set()` on user-supplied rule indices (`bcm_sf2_cfp_rule_set()`, `bcm_sf2_cfp_ipv4_rule_set()`, `bcm_sf2_cfp_ipv6_rule_set()`, `bcm_sf2_cfp_rule_del()`) must check `index <= bcm_sf2_cfp_rule_size(priv)` before calling `bcm_sf2_cfp_rule_addr_set()`. In `bcm_sf2_cfp_rule_insert()`, after validating `port_num = ring_cookie / SF2_NUM_EGRESS_QUEUES < priv->hw_params.num_ports` and calling `port_vlan_add()`, `port_num` must be decremented by 1 when `port_num >= 7` before calling `bcm_sf2_cfp_act_pol_set()` because port 6 has no bit in `DST_MAP_IB`. [F74, F145]

## Known Pitfalls

- In `b53_arl_from_entry`, `b53_arl_from_entry_25`, and `b53_set_eap_mode`, narrower `u16` or `int` fields (`ent->vid`, `ent->port`, `mode`) must be cast to `u64` before shifting left by >= 32 bits (`ARLTBL_VID_S`, `ARLTBL_DATA_PORT_ID_S_25`, `ARLTBL_VID_S_65`, `EAP_MODE_SHIFT_63XX`, `EAP_MODE_SHIFT`). Similarly, in 48-bit and 64-bit split register readers (`b53_mmap_read48/64`, `b53_srab_read48/64`, `SF2_IO64_MACRO`), the 16-bit or 32-bit upper word must be cast to `u64` before shifting left by 16 or 32 bits. [F96, F97]
- In `bcm_sf2_cfp_rule_find()`, a matching `struct cfp_rule *` must be returned directly from inside `list_for_each_entry()` and `NULL` returned after the loop. In `bcm_sf2_cfp_rule_cmp()`, `ret` must be reset to `1` at the start of every `list_for_each_entry` iteration before any `continue`, `fs_size` must be set to `sizeof(struct ethtool_tcpip4_spec)` or `sizeof(struct ethtool_tcpip6_spec)` (not `sizeof(fs->h_u)`), and the loop must `break` immediately when `ret == 0`. [F88, F90, F111]
- In `b53_vlan_add()`, when a non-CPU port's default VLAN changes (`new_pvid != old_pvid`), the second `b53_fast_age_vlan()` call after updating `B53_VLAN_PORT_DEF_TAG(port)` to `new_pvid` must pass `old_pvid` rather than `vlan->vid` or `new_pvid`. [F84]
- When modifying `B53_PD_MODE_CTRL_25` on BCM5325 in `b53_setup_port()`, only ports 1..4 may be toggled and `PD_MODE_POWER_DOWN_PORT(0)` (`BIT(0)`) must be cleared because bit 0 powers down the entire switch. In `bcm_sf2_port_intr_enable()`/`disable()`, ports 0 and 7 must use `P0_IRQ_OFF` and `P7_IRQ_OFF` rather than `P_IRQ_OFF(port)` (`(6 - (port)) * P_NUM_IRQ`), which is only valid for `1 <= port <= 6`. [F52, F101]
- In `bcm_sf2_sw_rst()`, `BCM7278_DEVICE_ID` must be reset via `priv->rcdev` (`reset_control_assert`/`deassert`) rather than `CORE_WATCHDOG_CTRL`. In `b53_switch_reset()`, `B53_SOFTRESET` must only be used on `BCM58XX_DEVICE_ID` or `BCM583XX_DEVICE_ID` (never `is58xx(dev)`). On `BCM63xx` (`is63xx(dev)`), RGMII setup in `b53_phylink_mac_config()`, `b53_phylink_get_caps()`, and `b53_adjust_63xx_rgmii()` must be restricted to `in_range(port, B53_63XX_RGMII0, 4)` (never port 8) and clear `RGMII_CTRL_DLL_RXC | RGMII_CTRL_DLL_TXC`. [F117, F119]
