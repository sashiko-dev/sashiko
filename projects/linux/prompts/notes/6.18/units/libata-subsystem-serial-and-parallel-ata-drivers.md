# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers)

This subsystem implements the core libata framework (`libata-core.c`), Error Handler (`libata-eh.c`), SATA link/NCQ/Port Multiplier helpers (`libata-sata.c`, `libata-pmp.c`), PATA timing calculations (`libata-pata-timings.c`), ACPI integration (`libata-acpi.c`), the common AHCI library (`libahci.c`), and PCI/platform SATA and PATA controller drivers (`ahci.c`, `ata_piix.c`, `acard-ahci.c`, and SoC AHCI drivers).

## Architecture & Data Flow
- `ata_qc_issue()` marks `qc` active (`ATA_QCFLAG_ACTIVE`, `ap->qc_active`, `ap->nr_active_links`, and `link->sactive` or `link->active_tag`) on entry, so any subsequent error path must complete `qc` via `ata_qc_complete()` (or `ata_link_abort()`) rather than returning or calling `ata_qc_free()`. `ap->nr_active_links` is adjusted on every non-NCQ command, but for NCQ only when `link->sactive` transitions between zero and non-zero. [F195, F235]
- `ata_exec_internal()` uses `qc->tag = ATA_TAG_INTERNAL` (32) in `ap->qc_active` (`1ULL << 32`) with `qc->hw_tag = 0`; `ata_qc_get_active()` shifts bit 32 to bit 0 and `ata_qc_complete_multiple()` shifts bit 0 back to bit 32. Because `ap->qc_active` and `done_mask` are `u64`, all shifts/scans on them (including `ahci_qc_ncq_fill_rtf()`'s unconditional `done_mask &= ~(1ULL << tag)`) must use 64-bit ops (`1ULL << tag`, `BIT_ULL(tag)`, `__ffs64()`). [F115, F119, F264, F321]
- When FIS-based switching (`pp->fbs_enabled`) is active, `pp->active_link` is invalid (only valid when `!pp->fbs_enabled && ap->qc_active`), and `ahci_qc_complete()`, `ahci_qc_fill_rtf()`, and `ahci_qc_ncq_fill_rtf()` must index `pp->rx_fis` by `qc->dev->link->pmp * AHCI_RX_FIS_SZ` (256 bytes, requiring `AHCI_PORT_PRIV_FBS_DMA_SZ` in `ahci_port_start()` when `pp->fbs_supported`), whereas `acard_ahci_qc_fill_rtf()` strides by `ACARD_AHCI_RX_FIS_SZ` (128 bytes). [F62, F93, F126, F127]
- `ahci_enable_fbs()` must set `pp->fbs_enabled = true` and `pp->fbs_last_dev = -1`; writing a new PMP index to `PORT_FBS` in `ahci_qc_issue()` or `ahci_exec_polled_cmd()` must clear `PORT_FBS_DEC` and update `pp->fbs_last_dev`. In `ahci_error_intr()`, when `pp->fbs_enabled` and `fbs & PORT_FBS_SDE`, `pmp = fbs >> PORT_FBS_DWE_OFFSET` must be verified `< ap->nr_pmp_links` before indexing `ap->pmp_link[pmp]`. [F61, F95]
- In `ahci_handle_port_interrupt()`, `PORT_IRQ_BAD_PMP` (when `ATA_PFLAG_RESETTING`) and `PORT_IRQ_PHYRDY` (when `sata_lpm_ignore_phy_events(&ap->link)`) must be masked out of `status` before testing `status & PORT_IRQ_ERROR`. In `ahci_error_intr()`, `SCR_ERROR` must be read and written back to clear it, a NULL `link` must fall back to `&ap->link`, link-specific errors go to `active_ehi` (`&link->eh_info`), and bus/hotplug errors go to `host_ehi` (`&ap->link.eh_info`). [F106, F110, F117, F153]
- Per-port interrupt mask changes in `libahci.c` must update `pp->intr_mask` for `ahci_thaw()`, and `ahci_pmp_attach()` / `ahci_pmp_detach()` must not write `pp->intr_mask` to `PORT_IRQ_MASK` while `ata_port_is_frozen(ap)`. Before calling `sata_link_hardreset()` with `ahci_check_ready`, `pp->rx_fis + RX_FIS_D2H_REG` must be initialized with `tf.status = ATA_BUSY` via `ata_tf_to_fis()`, and `*class` must only be written when `online` is true. [F52, F63]
- In `ata_qc_complete()`, scheduling EH for a non-error completion via `ata_qc_schedule_eh()` requires both `ATA_QCFLAG_HAS_CDL` and `qc->result_tf.status & ATA_SENSE`, and must set `SCMD_FORCE_EH_SUCCESS`, `ATA_QCFLAG_EH_SUCCESS_CMD`, `ATA_EH_GET_SUCCESS_SENSE`, and `ATA_PFLAG_EH_PENDING` (with EH calling `ata_eh_decide_disposition()`). `ata_eh_get_ncq_success_sense()` must verify log `0x0f` version `1` and `sense_valid & BIT(tag)`, and copy `nsect`, LBA/HOBs, and `auxiliary` into `qc->result_tf`. [F240, F266, F277, F366]
- When `ata_eh_analyze_ncq_error()` identifies the offending tag from log 10h (`ata_eh_read_log_10h()` must reject `buf[0] & 0x80`, mask `*tag = buf[0] & 0x1f`, and verify `link->sactive & BIT(tag)` before indexing `__ata_qc_from_tag()`), it must clear `ATA_ERR` from `result_tf.status`, zero `result_tf.error`, and set `ATA_QCFLAG_RETRY` on all other non-successful EH commands on that physical link, and clear `AC_ERR_DEV` from `ehc->i.err_mask`. [F241, F265]
- In `ata_eh_autopsy()`, link autopsy must run on `EDGE` links and `ap->slave_link` before `&ap->link` when `sata_pmp_attached(ap)` is true. In `ata_eh_reset()`, resetting `ap->slave_link` after the master link must pass `clear_classes = false` to `ata_do_reset()` to preserve `ehc->classes[0]`, and any successful reset must set `link->lpm_policy = ATA_LPM_UNKNOWN` so `ata_eh_recover()` re-applies `ap->target_lpm_policy`. [F250, F291, F292]
- `ata_dev_init()` clears only `ATA_DFLAG_INIT_MASK` (and zeroes `[ATA_DEVICE_CLEAR_BEGIN, ATA_DEVICE_CLEAR_END)`), while `ata_link_init()` zeroes `[ATA_LINK_CLEAR_BEGIN, ATA_LINK_CLEAR_END)`; persistent fields and live pointers must stay outside those ranges. `ata_dev_configure()` clears only `ATA_DFLAG_CFG_MASK` and must call `ata_clear_log_directory(dev)`. `ata_dev_reread_id()` and `sata_pmp_revalidate()` must read into `dev->sector_buf` and validate via `ata_dev_same_device()` / `sata_pmp_same_pmp()` before overwriting `dev->id` or `dev->gscr`. [F244, F249, F253, F310, F311]
- Non-host, non-slave links must reside in `ap->pmp_link[0 .. ap->nr_pmp_links - 1]` (allocated to `SATA_PMP_MAX_PORTS` in `sata_pmp_init_links()`) for `ata_link_next()`, and `SATA_PMP_MAX_PORTS`-sized arrays must only be indexed by `link->pmp` on `EDGE` links (not the host link where `link->pmp == SATA_PMP_CTRL_PORT == 15`). `sata_pmp_attach()` sets `link->pmp = SATA_PMP_CTRL_PORT` before reading GSCRs (resetting to `0` on failure), and `sata_pmp_detach()` resets `ap->nr_pmp_links = 0` and `link->pmp = 0` under `ap->lock`. [F246, F267, F309, F314]

## Synchronization
- `ap->lock` (aliased to `&ap->host->lock`, or redirected to per-port `&pp->lock` initialized in `ahci_port_start()` when `AHCI_HFLAG_MULTI_MSI` is set) is shared with hardirq handlers and `ap->fastdrain_timer`, so process/workqueue/timer/sysfs callers must use `spin_lock_irqsave()`. `ap->scsi_scan_mutex` and `ap->host->eh_mutex` (`ata_eh_acquire()`) nest outside `ap->lock`: never acquire them or call sleeping SCSI helpers (`scsi_remove_device()`, `scsi_change_queue_depth()`) while holding `ap->lock`. [F23, F340, F345, F365]
- All mutations to `ap->qc_active`, `ap->nr_active_links`, `ap->excl_link`, `link->active_tag`, `link->sactive`, `qc->flags`, `ap->pflags`, `link->eh_info`, and `ap->nr_pmp_links` must occur under `ap->lock`. In `ata_port_freeze()`, `__ata_port_freeze(ap)` must precede `ata_port_abort(ap)` under `ap->lock`. In `__ata_eh_qc_complete()`, setting `qc->scsidone = ata_eh_scsidone` and calling `__ata_qc_complete(qc)` must occur under `ap->lock` before calling `scsi_eh_finish_cmd()` unlocked. [F205, F206, F208, F219, F354]
- In `ata_scsi_cmd_error_handler()`, after `ata_sff_flush_pio_task(ap)`, `ap->lock` must be held continuously across `ap->ops->lost_interrupt(ap)`, setting `ATA_QCFLAG_EH` on timed-out QCs, and calling `__ata_port_freeze(ap)`. In `ata_scsi_port_error_handler()`, `timer_delete_sync(&ap->fastdrain_timer)` must run outside `ap->lock` before copying/zeroing `link->eh_info` under `ap->lock`, and at the end of EH, checking `ATA_PFLAG_EH_PENDING`, clearing `link->eh_info`, and calling `ap->ops->end_eh(ap)` must happen in one `ap->lock` section. [F207, F209, F210]
- `ata_exec_internal()` must save and zero `link->active_tag`, `link->sactive`, `ap->qc_active`, and `ap->nr_active_links` under `ap->lock`, release EH ownership (`ata_eh_release(ap)`) before `wait_for_completion_timeout(&wait)`, reacquire it (`ata_eh_acquire(ap)`) and flush PIO (`ata_sff_flush_pio_task(ap)`) afterward, freeze the port via `ata_port_freeze(ap)` under `ap->lock` if `ATA_QCFLAG_ACTIVE` is still set on timeout (before on-stack `wait`/`sgl` go out of scope), and restore the saved active fields under `ap->lock` after `ata_qc_free(qc)`. [F197, F211, F349]
- `ata_msleep()` (when `ap && ap->host->eh_owner == current`) releases EH ownership via `ata_eh_release(ap)` before sleeping and reacquires it via `ata_eh_acquire(ap)`. Therefore, in `ahci_start_port()`, retrying `ap->ops->transmit_led_message` on `-EBUSY` must use `msleep(1)` rather than `ata_msleep(ap, 1)` so EH ownership is not dropped while the host-wide EM Transmit bit is busy. [F30, F214]
- Callers of `ahci_handle_port_intr()` must hold `&host->lock` with IRQs disabled; `ahci_single_level_irq_intr()` and `ahci_thunderx_irq_handler()` must clear `HOST_IRQ_STAT` with unmasked `irq_stat` under `&host->lock` after `ahci_handle_port_intr()` clears `PORT_IRQ_STAT`, whereas `xgene_ahci_irq_intr()` must write `irq_stat` to `HOST_IRQ_STAT` under `&host->lock` before `xgene_ahci_handle_broken_edge_irq()`. [F25, F26, F161]
- `ahci_deinit_port()` must stop the DMA engine (`hpriv->stop_engine(ap)`) before `ahci_stop_fis_rx(ap)`, while `ahci_start_port()` must call `ahci_start_fis_rx(ap)` before `hpriv->start_engine(ap)`. Modifying `PORT_FBS_EN` (`ahci_enable_fbs()`, `ahci_disable_fbs()`) or `PORT_DEVSLP` timings/`PORT_DEVSLP_ADSE` (`ahci_set_aggressive_devslp()`) requires stopping the DMA engine first and restarting it afterward; `xgene_ahci_restart_engine()` must poll `PORT_CMD_ISSUE` to `0x0` before `hpriv->stop_engine(ap)`. [F31, F34, F65]
- Before `ahci_init_controller()` sets `HOST_IRQ_EN`, each non-dummy port must be stopped via `ahci_deinit_port()` and pending `PORT_SCR_ERR`, `PORT_IRQ_STAT`, and `HOST_IRQ_STAT` bits cleared via `ahci_port_clear_pending_irq()` (also required before `sata_link_hardreset()` in `ahci_do_hardreset()`). PCI AHCI suspend paths must clear/flush `HOST_IRQ_EN` in `HOST_CTL` before suspending. [F36, F136, F137]

## Object Lifetimes
- `ata_host_alloc()` allocates `host->ports[]` via `ata_port_alloc()`, which must be freed via `ata_port_free()` (never `kfree(ap)` directly) while handling `NULL` `host->ports[i]` entries in `ata_devres_release()` / `ata_host_release()`. In `ata_host_alloc()`, errors before `devres_add()` must `kfree(host)` directly, while errors after `devres_add()` must only call `devres_release_group(dev, NULL)`. [F187, F220, F308, F325]
- `ata_host_start()` must pre-allocate the `ata_host_stop` devres node, finalize `port_ops` via `ata_finalize_port_ops()`, unwind started ports in reverse (`while (--i >= 0)`) and free the devres node on `->port_start()` failure, freeze ports, and set `ATA_HOST_STARTED` before `ata_host_register()` (or per-port MSI `devm_request_irq()` in `ahci_host_activate_multi_irqs()`, which must `disable_irq()` dummy `!pp` ports). `ata_host_register()` must unwind `ata_tport_add()` on failure via `ata_tport_delete()`; `ata_host_activate()` must `devm_free_irq()` if `ata_host_register()` fails. [F24, F189, F190, F200, F327]
- In `ata_port_detach()`, drain async probing and EH, remove `dev->sdev` via `scsi_remove_device()` under `ap->scsi_scan_mutex` (with `ap->lock` dropped), and await the `ATA_PFLAG_UNLOADING` EH run via `ata_port_wait_eh()` before canceling `ap->hotplug_task` and `ap->scsi_rescan_task` (`cancel_delayed_work_sync()`, outside `ap->lock` and `ap->scsi_scan_mutex`) or deleting `ap->pmp_link`, `ap->scsi_host`, and `ap->tdev`. `ata_port_suspend()` must also cancel `ap->scsi_rescan_task` before `ata_port_request_pm()`. [F191, F202, F338, F346]
- In `ahci_init_one()`, call `pm_runtime_put_noidle(&pdev->dev)` only after `ahci_host_activate()` succeeds (balanced by `pm_runtime_get_noresume()` in `ahci_remove_one()`), remove `dev_attr_remapped_nvme` on error and remove, call `pcim_pin_device(pdev)` if `pcim_request_all_regions()` returns `-EBUSY` (also in `acard_ahci_init_one()`), and in `ahci_init_irq()` call `pci_free_irq_vectors(pdev)` if multi-MSI allocation succeeds but `HOST_MRSM` is set. Balance `ahci_rpm_get_port(ap)` / `ahci_rpm_put_port(ap)` across port start/resume and stop/suspend, and around all sysfs/LED MMIO accesses in `libahci.c`. [F2, F3, F4, F5, F140, F158]

## API Contracts
- `ata_exec_internal()`, internal command helpers, and `.read_id` callbacks return `unsigned int` (`0` or `AC_ERR_*` mask, translating negative errnos to `AC_ERR_OTHER`, and callers returning `int` must translate `AC_ERR_*` to `-errno`). `sata_link_hardreset()` and `sata_std_hardreset()` return `-EAGAIN` (`*online = true`) when a follow-up softreset is needed; `sata_set_spd()` returns `0`, `1` (updated), or `< 0`; `ata_qc_complete_multiple(ap, qc_active)` takes the still-active mask and returns `-EINVAL` or completed count; `ata_xfer_mask2mode()` / `ata_timing_cycle2mode()` return `0xff` on failure. [F43, F221, F223, F227, F228, F229]
- `ata_link_online()` and `ata_link_offline()` both return `false` when `SCR_STATUS` cannot be read (so `!ata_link_online()` is not `ata_link_offline()`) and must not be called on `ap->slave_link`; `ata_eh_link_established()` must return `true` when `sata_scr_read()` fails. `ata_sg_setup()` saves `qc->orig_n_elem` for `ata_sg_clean()`; buffers passed to `ata_exec_internal()` with `dma_dir != DMA_NONE` must be DMA-safe/cacheline-aligned (never on stack); `ata_read_log_page()` takes `sectors` in 512-byte units. [F196, F224, F307, F331, F353]
- `ata_port_operations` command/EH-scheduling callbacks (`qc_prep`, `qc_issue`, `qc_fill_rtf`, `freeze`, `thaw`, `lost_interrupt`, etc.) and host-link `scr_read`/`scr_write` run under `ap->lock` with IRQs disabled and must not sleep, whereas PMP `sata_scr_read()`/`write()` use `ata_exec_internal()` in EH context. In `struct ata_port_operations`, `inherits` must be last, all preceding fields must be pointers, overriding an inherited callback to `NULL` requires `ATA_OP_NULL`, and tables must be finalized via `ata_finalize_port_ops()` before use. [F313, F341, F343, F356]
- `ata_qc_for_each()` and `ata_qc_for_each_with_internal()` visit all tags even when `qc` is `NULL` (check `if (qc)`) and hide `ATA_QCFLAG_EH` QCs (use `ata_qc_for_each_raw()` in EH). `ata_id_string()` requires an even length (no NUL), while `ata_id_c_string()` requires an odd length (`len + 1`) and 16-bit word offset; `dev->*_mask` must be packed via `ata_pack_xfermask()` before `ata_xfer_mask2mode()`. [F222, F233, F280, F281]

## Error Handling
- Per-link recovery helpers in `ata_eh_recover()` taking `struct ata_device **r_failed_dev` (`ata_eh_revalidate_and_attach()`, `ata_eh_set_mode()`, `ata_set_mode()`, `ap->ops->set_mode`, `ata_eh_link_set_lpm()`) must set `*r_failed_dev` on any non-zero error. Because `ata_eh_handle_dev_fail()` does not decrement `ehc->tries` on `-EAGAIN`, any EH helper returning `-EAGAIN` (and any `retry:` jump in `ata_dev_read_id()`, or DMA log retry in `ata_read_log_page()` which must set `ATA_QUIRK_NO_DMA_LOG` and check `!ata_port_is_frozen()`) must mutate state so retries cannot loop indefinitely. [F226, F285, F286, F287]

## External Contracts
- Unlike `dev->id` (native `u16` after `swap_buf_le16()`, whereas `.read_id` overrides modify `__le16 *id` via `cpu_to_le16()`), `ata_read_log_page()` buffers are raw little-endian, 64-bit QWords in `ATA_LOG_IDENTIFY_DEVICE` require `BIT_ULL(63)`, and variable-length logs like `ATA_LOG_CONCURRENT_POSITIONING_RANGES` must size reads from `ata_log_supported()` (setting `cpr_log->nr_cpr` before indexing `cpr[]`). [F102, F260, F262, F263, F306]

## Known Pitfalls
- `pp->cmd_tbl` and `pp->rx_fis` are `void *`, so byte offsets (`AHCI_CMD_TBL_*`, `RX_FIS_*`) must be added before casting to typed pointers. `ata_identify_page_supported()` overwrites `dev->sector_buf`, so callers using `dev->sector_buf` must call it before reading their own log page. In EH autopsy/sense/reporting, match physical links via `ata_dev_phys_link(dev) == link` rather than `dev->link == link` (for `ap->slave_link`). `u32` `port_map`/`saved_port_map` must be copied to an `unsigned long` local before `for_each_set_bit()`. [F128, F131, F245, F282]
