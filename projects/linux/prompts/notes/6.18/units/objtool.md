# OBJTOOL

Objtool is a compile-time userspace ELF binary analysis and transformation tool paired with kernel headers (`include/linux/objtool.h`, `include/linux/objtool_types.h`) that emit `.discard.*` annotations. It decodes x86, LoongArch, and PowerPC instructions, simulates control flow and stack frame state (CFI), validates kernel invariants (frame pointers, `noinstr`, SMAP/uaccess, retpoline/rethunk, IBT/ENDBR, SLS, unret), and generates or rewrites ELF sections (`.orc_unwind`, `.static_call_sites`, `.retpoline_sites`, `.return_sites`, `__mcount_loc`).

## Architecture & Data Flow

- In `decode_sections()`, `read_annotate(file, __annotate_early)` must run before `add_special_section_alts()` and `read_unwind_hints()` (which read `insn->ignore_alts` and `insn->noendbr`); `add_special_section_alts()` must run before `add_jump_destinations()` (setting `insn->sym = orig_insn->sym` on `.altinstr_replacement` insns); and `add_call_destinations()` must run after `__annotate_ifc` and before `__annotate_late`. Every `ANNOTYPE_*` in `objtool_types.h` needs a `case` in `__annotate_late()`, which fails on `default:`. [F41, F42, F43, F74]
- In `check()`, `validate_unrets()` must run after `validate_functions()`, `validate_unwind_hints()`, `validate_reachable_instructions()`, and `validate_noinstr_sections()`, because `validate_unret()` sets `VISITED_UNRET` (`0x04`) in `insn->visited` while earlier passes test `!insn->visited` as a boolean. [F68]
- `struct cfi_state` objects pointed to by `insn->cfi` (`init_cfi`, `func_cfi`, `force_undefined_cfi`, and `cfi_hash` entries) are shared across instructions and `alt_group->cfi` and must never be mutated in place; modify a local copy and intern it via `cfi_hash_find_or_add()`. Any `struct cfi_state` passed to `cficmp()`, `cfi_key()`, or `cfi_hash_find_or_add()` must have `hash` as its first field and be zero-initialized (or copied from `init_cfi`) before `init_cfi_state()`. [F19, F30]
- In `read_unwind_hints()`, `UNWIND_HINT_TYPE_SAVE` must clear `insn->hint = false` and set `insn->save = true` (leaving `insn->cfi` NULL), so `validate_branch()` records `insn->cfi` from incoming control flow rather than dereferencing a NULL `insn->cfi` in `validate_unwind_hint()`. [F13]
- In `validate_branch()`, `insn->alts` must be validated with the pre-instruction `struct insn_state` before `handle_insn_ops()` mutates `state`, whereas `insn->jump_dest` branches must be validated after `handle_insn_ops()` with `state` passed by value. `insn->visited` tracks `VISITED_BRANCH << state.uaccess`; when `insn->visited & VISITED_BRANCH_MASK` is non-zero, check `insn_cfi_match()` before returning `0` only if `insn->visited & visited` is already set. [F11, F67]
- Control-flow walkers (`validate_branch()`, `validate_unret()`) must advance via `next_insn_to_validate(file, insn)` rather than `next_insn_same_sec(file, insn)` so reaching `alt_group->last_insn` in a replacement group transitions through `alt_group->nop` back to the instruction after `alt_group->orig_group->last_insn`. [F78]
- In `struct alt_group`, `orig_group` is NULL on the original group and non-NULL only on replacements. `orig_alt_group->cfi` is allocated in `handle_group_alt()` with `special_alt->orig_len` entries (after `arch_handle_alternative()` maximizes `orig_len`) and shared with `new_alt_group->cfi`. When `new_len < orig_len`, attach a synthetic `INSN_NOP` (`alt_group->nop`, length `orig_len - new_len`; if `new_len == 0`, `last_insn` is NULL and `first_insn` is `nop`) so `propagate_alt_cfi()` records post-last-insn CFI within `orig_len`. [F23, F49, F59]
- In `validate_branch()` and `validate_unret()`, `INSN_SYSCALL` must `break` to continue to the next instruction (unless `insn->dead_end`), whereas `INSN_SYSRET` must `return 0`. In `validate_unret()`, `INSN_JUMP_UNCONDITIONAL` and `INSN_JUMP_CONDITIONAL` must check `if (!is_sibling_call(insn))` and fall through to `case INSN_CALL:` when `is_sibling_call(insn)` is true so sibling calls follow `insn_call_dest(insn)`. [F71, F72]
- Before any `INSN_RETURN`, `validate_branch()` requires `state.instr <= 0` (if `state.noinstr`), `!state.df`, `state.uaccess == func_uaccess_safe(func)`, and `!has_modified_stack_frame(insn, state)` (if `func`). Before `INSN_CALL`/`INSN_CALL_DYNAMIC`, `opts.stackval` must exempt `is_special_call(insn)` (`dest->fentry` or `dest->embedded_insn`). In `sec->noinstr` sections while `state->instr <= 0`, calls may only target `noinstr` sections, `static_call` trampolines, `__ubsan_handle_*`, or clean `pv_ops` slots. [F12, F109, F113]
- Functions in `uaccess_safe_builtin[]` must only call other `uaccess_safe` functions, must not directly execute `CLAC` (unless restoring `PUSHF` flags in an alternative), and must return with `UACCESS` enabled. On every path from `ANNOTATE_UNRET_BEGIN` (`insn->unret`), `validate_unret()` requires a `retpoline_safe` `INSN_NOP` (`UNTRAIN_RET`), `INSN_SYSRET`, or `dead_end` before any `INSN_RETURN` or dynamic branch. With `opts.cfi`, every call in `file->retpoline_call_list` in a `!sym->nocfi` function must follow an `INSN_BUG` (`ud2`). [F108, F114, F115]
- When patching an instruction via `elf_write_insn()` in `annotate_call_site()` or `handle_jump_alt()`, set its relocation to `R_NONE`, update `insn->type` to `INSN_NOP` or `INSN_RETURN`, and set `insn->retpoline_safe = true` when replacing a tail-call with `RET; INT3`. Because `struct instruction` has a single `call_node` list head, `annotate_call_site()` must return immediately after linking `insn->call_node` into `static_call_list`, `retpoline_call_list`, or `mcount_loc_list` so it is not also added to `file->call_list`. [F39, F40]
- When checking if two instructions or jump targets belong to the same function (`jump_is_sibling_call()`, `add_jump_table()`), compare `sym->pfunc` rather than `sym` so `.cold` subfunctions match their parent. When setting `func->ignore = true` in `add_ignores()`, also set `func->cfunc->ignore = true` if `func->cfunc` exists. In `__dead_end_function()`, stop recursive sibling-call resolution and return `false` at `recursion == 5`. [F38, F70, F81]
- In `add_jump_table_alts()`, `mark_func_jump_tables()` must mark all jump table head relocations in a function with `set_jump_table()` before `add_func_jump_tables()` calls `add_jump_table()`, which stops at `if (reloc != table && is_jump_table(reloc)) break;`. Every read-only data section prefix holding switch or C jump tables (`.rodata`, `.data.rel.ro` / `C_JUMP_TABLE_SECTION`) must be matched in `mark_rodata()`. [F48, F80]
- `elf_update_symbol()` requires contiguous symbol indices and, when over-allocating `.symtab`/`.symtab_shndx`, must set `sec->truncate = true` and `mark_sec_changed(elf, sec, true)` while `__elf_create_symbol()` advances `sh_size` by one entry. When `__elf_create_symbol()` inserts an `STB_LOCAL` symbol by moving the symbol at `symtab->sh.sh_info` to `sec_num_entries(symtab)` and incrementing `sh_info`, it must update `elf->symbol_hash`, `symtab`/`symtab_shndx`, `old->relocs` (`elf_update_sym_relocs()`), and `old->group_sec->sh.sh_info` in lockstep. [F31, F32, F61, F82]
- Every `struct reloc` in `rsec` must reside within `rsec->relocs` (`sec_num_entries(rsec)` elements) because `reloc_idx()` uses `reloc - reloc->sec->relocs`. Initialize `reloc->sec` and `set_reloc_offset()` before `elf_hash_add(reloc, &reloc->hash, reloc_hash(reloc))`. Because `sec_offset_hash()` masks offsets with `OFFSET_STRIDE_MASK` (`~15UL`), `file->insn_hash` and `elf->reloc_hash` must use `sec_offset_hash()`, and `find_reloc_by_dest_range()` must iterate `for_offset_range()`. [F34, F55, F58]
- Relocation addends in `reloc_addend()`, `set_reloc_addend()`, `elf_init_reloc()`, and `elf_init_reloc_data_sym()` must use `s64` (`PRIx64`) rather than `int` or `long`. Multi-byte integers in `SHT_PROGBITS` buffers (`sec->data->d_buf`), such as `hint->sp_offset`, annotation `type`, and `orc->sp_offset`/`orc->bp_offset` in `write_orc_entry()`, must use `bswap_if_needed()`. [F50, F86]
- Architecture decoding: on x86 `arch_decode_instruction()`, opcodes `0x80`..`0x83` with `op1 & 2` must sign-extend `u64 imm` via `(s64)imm` shifts before negating for `SUB`. On LoongArch, `decode_insn_reg*` must call `sign_extend64()` on immediate bitfields, and `arch_jump_table_sym_offset()` must subtract `reloc_offset(reloc) - reloc_offset(table)` for `R_LARCH_{32,64}_PCREL`. On PowerPC, `arch_jump_destination()` must sign-extend `ins & 0x3fffffc` and mask off `AA` (`insn->immediate & ~2`). [F90, F91, F92, F97]

## Object Lifetimes

- `elf_add_string()` stores the caller's `char *str` pointer directly into `Elf_Data::d_buf` without copying it; callers must pass a heap-allocated string that lives until `elf_write()` completes. In `decode_sections()`, `init_pv_ops(file)` must run before `decode_instructions(file)` because x86 `arch_decode_instruction()` calls `objtool_pv_add()`, which fails when `opts.noinstr` is set and `file->pv_ops` is unallocated. [F1, F6]
- `mark_endbr_used()` must remove referenced `INSN_ENDBR` instructions from `file->endbr_list` with `list_del_init(&insn->call_node)` (not `list_del()`), and `validate_ibt()` (which must not skip `.discard.ibt_endbr_noseal`) must run before `create_ibt_endbr_seal_sections()` so an `INSN_ENDBR` can be referenced by multiple relocations and only unreferenced entries are sealed. [F9, F116]
- `decode_instructions()` allocates `struct instruction` in `INSN_CHUNK_SIZE` chunks indexed by `u8 idx` (`0..INSN_CHUNK_MAX`, so `INSN_CHUNK_BITS <= 8`); `next_insn_same_sec()`/`prev_insn_same_sec()` step within a chunk via pointer arithmetic, and `free_insns()` frees every `insn` in `file->insn_hash` with `insn->idx == 0` without unlinking from `file->insn_hash` or `file->*_list`. Never insert single-element instructions (like `alt_group->nop`) into `file->insn_hash` with `idx == 0`, and never access instructions after `free_insns(file)`. [F45, F95, F100]

## API Contracts

- `struct reloc::_sym_next_reloc` packs the next `struct reloc *` in `sym->relocs` with `RELOC_JUMP_TABLE_BIT` in bit 0; always use `sym_next_reloc()`, `set_sym_next_reloc()`, `is_jump_table()`, and `set_jump_table()`. `struct instruction::_call_dest` and `_jump_table` share a union discriminated by `insn->type` (`INSN_JUMP_DYNAMIC`/`INSN_CALL_DYNAMIC` vs static); always use `insn_call_dest()`, `insn_jump_table()`, and `insn_jump_table_size()`. [F15, F37]
- For a `struct reloc *reloc`, `reloc->sec` is the `SHT_RELA`/`SHT_REL` section, `reloc->sec->base` is the section modified at `reloc_offset(reloc)`, and `reloc->sym->sec` is the target symbol's section; diagnostics and site lookups must use `reloc->sec->base`. `elf_init_reloc_text_sym()` and `elf_init_reloc_data_sym()` take the base section `sec` (created via `elf_create_section_pair()` so `sec->rsec` exists); `elf_init_reloc_text_sym()` requires `SHF_EXECINSTR` on `insn_sec`, while `elf_init_reloc_data_sym()` rejects executable `sec` when `sym->sec` is set. [F21, F22]
- Raw relocation entries in `rsec->data->d_buf` must be accessed via `is_32bit_reloc()`, `__get_reloc_field()`, `__set_reloc_field()`, `set_reloc_sym()`, and `set_reloc_type()`, and any mutation to a section header, `Elf_Data` buffer, or relocation entry must call `mark_sec_changed(elf, sec, true)`. `bswap_if_needed(elf, val)` dispatches on `sizeof(val)`, so `val` must have the exact 2-, 4-, or 8-byte ELF field type before any widening promotion. [F25, F33, F56]
- On x86, 32-bit PC-relative relocations (`R_X86_64_PC32`, `R_X86_64_PLT32`) encode an addend biased by `-4`, so `arch_dest_reloc_offset(addend)` adds `4`; only apply `arch_dest_reloc_offset()` (or `+ 4` in `validate_ibt_insn()` and `arch_find_switch_table()`) to PC-relative relocations, and use `reloc_addend(reloc)` directly for absolute or data relocations. [F26, F96]
- In `init_orc_entry(orc, cfi, insn)`, `cfi` can be NULL; do not dereference `cfi` before `if (!cfi)`. `prev_insn_same_sec()`, `prev_insn_same_sym()`, `next_insn_same_sec()`, and `next_insn_same_func()` return NULL at boundaries and must be NULL-checked. `find_symbol_hole_containing()` returns `0` inside a symbol, `-1` for a hole to section end, or a positive length (store in signed `int`). `elf_add_string()` returns `-1` on failure. Functions omitting only frame-pointer setup must use `STACK_FRAME_NON_STANDARD_FP`, not `STACK_FRAME_NON_STANDARD`. [F17, F20, F24, F28, F107]

## Error Handling

- In `check()`, fatal setup or section-generation errors must set a negative `ret` and `goto out`, whereas validation findings must accumulate into `warnings` so remaining passes run and `check()` returns `0` (allowing `elf_write()`) unless `opts.werror` upgrades `warnings` to `ret = 1`. `elf_alloc_hash()` and `cfi_hash_alloc()` must clamp bit widths with `max(10, ilog2(size))` and convert `mmap()`'s `(void *)-1L` (`MAP_FAILED`) to `NULL`. [F18, F27, F94]

## External Contracts

- Non-local C functions that never return must be annotated `__noreturn` across all Kconfig configurations and listed in `tools/objtool/noreturns.h` (and Rust panicking functions matched in `is_rust_noreturn()`) in lockstep with any addition or rename. In `include/linux/objtool.h`, `VALIDATE_UNRET_BEGIN` must expand to `ANNOTATE_UNRET_BEGIN` when `CONFIG_NOINSTR_VALIDATION` is enabled with either `CONFIG_MITIGATION_UNRET_ENTRY` or `CONFIG_MITIGATION_SRSO`. [F46, F106]
- Changes to `.discard.unwind_hints` or `.discard.annotate_insn` must update `include/linux/objtool.h` (`UNWIND_HINT`, `__ASM_ANNOTATE`, `ANNOTATE`), `include/linux/objtool_types.h` (`struct unwind_hint`), and `read_unwind_hints()` / `read_annotate()` in lockstep: assembly `UNWIND_HINT` must end with `.balign 4` after its 9 bytes of fields to match the 12-byte `sizeof(struct unwind_hint)`, and each `.discard.annotate_insn` entry must be 8 bytes (`sh_entsize = 8`) with a relocation at offset 0 and the 32-bit type at offset +4. [F47, F51, F52]
- For every non-empty `.text` section, `orc_create()` must append an `ORC_TYPE_UNDEFINED` terminator at `sec->sh.sh_size` and emit matching entry counts `nr` to `.orc_unwind` (`sizeof(struct orc_entry)`) and `.orc_unwind_ip` (`sizeof(int)`). [F64]

## Known Pitfalls

- In `validate_branch()`, fallthrough detection (`func && insn_func(insn) && func != insn_func(insn)->pfunc`) must compare `func` against `insn_func(insn)->pfunc` (not `insn_func(insn)`), and must return `0` without warning when `func->name` has a `__cfi_`, `__pfx_`, `__pi___cfi_`, or `__pi___pfx_` prefix. [F69]
- Because `for_each_reloc()` and `for_each_reloc_from()` bound the loop with `__i < sec_num_entries(rsec)` while stepping `reloc++`, any loop body that also increments `reloc++` (`get_rodata_table_size_by_table_annotate()`) must check `reloc_idx(reloc) + 1 == sec_num_entries(rsec)` to avoid overrun, skip relocations with `reloc->sym->sec->rodata` or `strcmp(insn->sec->name, reloc->sym->sec->name)`, and reset `table_list` via `list_del_init(&table_list)` across section boundaries. [F75, F76]
- Loops calling `find_reloc_by_dest_range(elf, sec, off, len)` (`add_pv_ops()`, `validate_ibt_insn()`) must advance `off` to `reloc_offset(reloc) + 1` and shrink `len` each iteration so the same lowest-offset relocation is not returned infinitely. In `orc_create()`, after `sec_for_each_insn()` processes an `alt_group->cfi` array, set `insn = alt_group->last_insn` so `next_insn_same_sec()` advances to the instruction after `alt_group`. [F77, F79]
- In `elf_add_symbol()`, zero-length symbols (`!sym->len`) must be removed from `sym->sec->symbol_tree` via `__sym_remove()` right after linking `sym->list` into `sym->sec->symbol_list`, because `__sym_last(s)` computes `s->offset + s->len - 1`. In `add_jump_destinations()`, when `find_insn()` returns `NULL`, check `sym && sym->embedded_insn` and `file->ignore_unreachables` at `func->offset + func->len` before erroring; in `get_alt_entry()`, subtract `0x7ffffff0` when `alt->new_off >= 0x7ffffff0` to strip the x86 `_ASM_EXTABLE_EX` bias. [F83, F84, F98]
