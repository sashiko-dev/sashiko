# VFIO PDS PCI DRIVER

The VFIO PDS PCI driver (`pds-vfio-pci`) is a VFIO PCI variant driver for AMD/Pensando DSC Ethernet Virtual Functions (PCI vendor `0x1dd8`, device `0x1003`). It extends `vfio_pci_core_device` with live migration support (`STOP_COPY` and `P2P` states via anonymous inode save/restore files) and DMA dirty-page logging (`vfio_log_ops` using a sequence/ack bitmap protocol), communicating with the Physical Function (`pds_core`) over the PDS admin queue and notification chain.

## Architecture & Data Flow
- Each `struct pds_vfio_region` indexes `host_seq` and `host_ack` from byte offset 0, whereas the device concatenates all regions' bitmaps into a single byte buffer; `pds_vfio_dirty_seq_ack()` must add `offset` to `seq_ack_bmp` before adding `region->dev_bmp_offset_start_byte` to `offset` for `pds_vfio_dirty_seq_ack_cmd()`. [F45]
- In `pds_vfio_dirty_sync()`, `iova` is an absolute address within `[region->start, region->start + region->size)`, so `region->start` must be subtracted from `iova` both when validating `(iova - region->start + length) > region->size` and when computing the region-relative `bmp_offset`. [F44]
- Because `region->sgl` is DMA-mapped once in `pds_vfio_dirty_alloc_sgl()` and rewritten in place on every `pds_vfio_dirty_seq_ack()` call, `pds_vfio_dirty_seq_ack()` must bracket `pds_vfio_dirty_seq_ack_cmd()` with `dma_sync_single_for_device()` and `dma_sync_single_for_cpu()` on `region->sgl_addr`. [F43]
- `region->num_sge` in `struct pds_vfio_region` holds the allocated SGL capacity (`max_sge = DIV_ROUND_UP(page_count, PAGE_SIZE * 8)`) used by `__pds_vfio_dirty_free_sgl()` to unmap `region->sgl_addr`; `pds_vfio_dirty_seq_ack()` must use a local `num_sge = sg_table.nents` for partial syncs without modifying `region->num_sge`. [F49]
- `pds_vfio_dirty_disable(pds_vfio, true)` must send `pds_vfio_send_host_vf_lm_status_cmd(pds_vfio, PDS_LM_STA_NONE)` whenever `send_cmd` is true even if `pds_vfio_dirty_is_enabled(pds_vfio)` is false, pairing with `PDS_LM_STA_IN_PROGRESS` sent in `pds_vfio_dma_logging_start()` and on `RUNNING -> RUNNING_P2P`. [F38]
- In `pds_vfio_get_file_page()`, `lm_file->last_offset` must store `cur_offset` (the start byte offset of `last_offset_sg`), the iterator must reset to `(sg_table.sgl, 0, 0)` when `offset < lm_file->last_offset || !lm_file->last_offset_sg`, and pages within a multi-page SG entry must be indexed via `sg_page(sg) + (offset - cur_offset) / PAGE_SIZE`. [F51]
- In `pds_vfio_get_lm_file()`, `npages` and `page_mem` must be sized by rounding `size` up to `PAGE_SIZE` (`DIV_ROUND_UP_ULL(size, PAGE_SIZE)` and `ALIGN(size, PAGE_SIZE)`) so `pages`, `page_mem`, and `lm_file->alloc_size` cover any trailing partial page. [F64]
- In `pds_vfio_set_device_state()`, the `while` loop must check `pds_vfio->state != VFIO_DEVICE_STATE_ERROR` before calling `vfio_mig_get_next_state()`, because `VFIO_DEVICE_STATE_ERROR` can only be exited via `VFIO_DEVICE_RESET` and passing it to `vfio_mig_get_next_state()` triggers a `WARN_ON()`. [F54]

## Synchronization
- `pds_vfio_step_device_state_locked()`, `pds_vfio_reset()`, `pds_vfio_put_save_file()`, `pds_vfio_put_restore_file()`, and `pds_vfio_dirty_disable()` require the caller to hold `pds_vfio->state_mutex` and must never release it. [F9]
- Because `pds_vfio_put_save_file()` and `pds_vfio_put_restore_file()` acquire `lm_file->lock` while the caller holds `pds_vfio->state_mutex`, no path holding `lm_file->lock` (such as `pds_vfio_save_read()`, `pds_vfio_restore_write()`, or `pds_vfio_release_file()`) may acquire `pds_vfio->state_mutex`. [F14]
- Callers of `pds_vfio_reset()`, `pds_vfio_put_save_file()`, `pds_vfio_put_restore_file()`, and `pds_vfio_dirty_disable()` must execute in sleepable process context and never hold a spinlock, because `pds_vfio_put_lm_file()` acquires `lm_file->lock` and calls `kvfree()`, and `pds_vfio_dirty_disable()` calls `vfree()` and `pdsc_adminq_post()`. [F86]
- `pds_vfio_get_lm_file()` must take a second reference via `get_file(lm_file->filep)` beyond the reference transferred to userspace by `vfio_ioct_mig_return_fd()`. `pds_vfio_put_lm_file()` must set `lm_file->disabled = true` and free `lm_file->sg_table`, `lm_file->page_mem`, and `lm_file->pages` under `lm_file->lock` before calling `fput(lm_file->filep)` (leaving `kfree(lm_file)` to `pds_vfio_release_file()`), and `pds_vfio_save_read()` and `pds_vfio_restore_write()` must check `!lm_file->disabled` under `lm_file->lock` and fail with `-ENODEV` before accessing backing pages. [F36, F99]

## Object Lifetimes
- `pds_vfio->state_mutex` must be initialized in `pds_vfio_init_device()` and destroyed in `pds_vfio_release_device()`, rather than in `pds_vfio_open_device()` and `pds_vfio_close_device()`, because reset callbacks can acquire `state_mutex` while the VFIO device is closed. [F10]
- `pds_vfio_put_save_file()` and `pds_vfio_put_restore_file()` must clear `pds_vfio->save_file` and `pds_vfio->restore_file` to `NULL` after calling `pds_vfio_put_lm_file()` so that repeated calls across state transitions, resets, and device close remain idempotent. [F3]
- `pds_vfio_reset()` must unconditionally release both `pds_vfio->restore_file` and `pds_vfio->save_file` via `pds_vfio_put_restore_file()` and `pds_vfio_put_save_file()` before updating `pds_vfio->state`, regardless of the previous or target migration state. [F32]
- Per-region dirty bitmaps (`region->host_seq` and `region->host_ack`) and `dirty->regions` are allocated with `vzalloc()` and `vcalloc()` (and mapped via `vmalloc_to_page()` in `pds_vfio_dirty_seq_ack()`), so they must be freed with `vfree()` across all error and teardown paths. Broken by: freeing with `kfree()`/`bitmap_free()` or switching to `kzalloc()` without updating `vmalloc_to_page()`. [F4]
- `pds_vfio_dirty_free_sgl()` and `pds_vfio_dirty_free_bitmaps()` iterate `dirty->regions` using `dirty->num_regions` and therefore must always be called before `pds_vfio_dirty_free_regions()` frees `dirty->regions` and zeroes `dirty->num_regions`. [F5]
- `pds_vfio_pci_probe()` acquires resources in the order `vfio_alloc_device()`, `vfio_pci_core_register_device()`, `pds_vfio_register_client_cmd()`, and `pds_vfio_pci_register_event_handler()`, and both probe error paths and `pds_vfio_pci_remove()` must tear them down in strict reverse order. [F8]

## API Contracts
- All host DMA mappings and synchronizations for PDS AdminQ commands (`pds_vfio_get_lm_state_cmd()`, `pds_vfio_set_lm_state_cmd()`, `pds_vfio_dirty_alloc_sgl()`, `__pds_vfio_dirty_free_sgl()`, `pds_vfio_dirty_enable()`, `pds_vfio_dirty_seq_ack()`, `pds_vfio_print_guest_region_info()`) must use the PF device `&pci_physfn(pdev)->dev`, never the VF `&pdev->dev`. [F88]
- When polling firmware in `pds_vfio_suspend_wait_device_cmd()`, the `PDS_LM_CMD_SUSPEND_STATUS` AdminQ command must populate `cmd.lm_suspend_status.type` with the same suspend `type` (`PDS_LM_SUSPEND_RESUME_TYPE_FULL` or `PDS_LM_SUSPEND_RESUME_TYPE_P2P`) that `pds_vfio_suspend_device_cmd()` sent in `PDS_LM_CMD_SUSPEND`. [F19]
- Before enabling dirty tracking in `pds_vfio_dirty_enable()`, `pds_vfio_dirty_status_cmd()` must be called to verify that `comp.lm_dirty_status.bmp_type_mask` has `BIT(PDS_LM_DIRTY_BMP_TYPE_SEQ_ACK)` set (returning `-EOPNOTSUPP` if unset), that `num_regions == 0` (`-EEXIST`), and that `max_regions != 0` (`-EOPNOTSUPP`); `pds_vfio_dirty_enable_cmd()` must then pass the unshifted enum `PDS_LM_DIRTY_BMP_TYPE_SEQ_ACK` in `cmd.lm_dirty_enable.bmp_type`. [F25, F81]
- `pds_vfio_dirty_status_cmd()` reads `*max_regions` as the input `cmd.lm_dirty_status.max_regions` buffer capacity before overwriting `*max_regions` from the completion, so callers probing capability with `regions_dma == 0` (such as `pds_vfio_dirty_enable()`) must initialize `max_regions = 0` before calling it. [F23]
- When `nnodes > max_regions` in `pds_vfio_dirty_enable()`, `vfio_combine_iova_ranges(ranges, nnodes, max_regions)` must be called and `num_ranges` clamped to `max_regions` before sizing each inclusive `[node->start, node->last]` range as `node->last - node->start + 1`. [F48]
- In `pds_vfio_pci_notify_handler()`, the `void *data` argument (`union pds_core_notifyq_comp *event`) must only be accessed as `event->reset` when `ecode == PDS_EVENT_RESET`, and `pds_vfio_recovery()` must only be called when `event->reset.state == 1` (ignoring `state == 0` pending resets). [F29]
- `pds_vfio_step_device_state_locked()` must return a non-NULL `struct file *` only on transitions whose destination `next` is the terminal target state `new_state` (`VFIO_DEVICE_STATE_STOP_COPY` or `VFIO_DEVICE_STATE_RESUMING`), because `pds_vfio_set_device_state()` triggers `WARN_ON(res && new_state != pds_vfio->state)`. [F97]
- `pds_vfio_ops` in `drivers/vfio/pci/pds/vfio_dev.c` must populate all four IOMMUFD callbacks (`bind_iommufd`, `unbind_iommufd`, `attach_ioas`, `detach_ioas`) so `__vfio_register_dev()` does not `WARN_ON` and fail with `-EINVAL` under `CONFIG_IOMMUFD`, and must set `.match_token_uuid = vfio_pci_core_match_token_uuid` alongside `.match = vfio_pci_core_match` to enforce SR-IOV VF token validation and avoid a NULL dereference in `vfio_pci_core_match()`. [F91, F92]
- `pds_vfio_open_device()` must call `vfio_pci_core_enable()`, initialize `pds_vfio->state = VFIO_DEVICE_STATE_RUNNING`, and then call `vfio_pci_core_finish_enable()`, pairing with `vfio_pci_core_close_device()` in `pds_vfio_close_device()`. [F95]

## Error Handling
- When `pds_vfio_reset()` transitions `pds_vfio->state` to `VFIO_DEVICE_STATE_ERROR`, it must call `pds_vfio_dirty_disable(pds_vfio, false)` (`send_cmd = false`) to free host dirty-tracking memory and DMA mappings without sending AdminQ disable or status commands, whereas normal teardown passes `send_cmd = true`. [F84]
- In `pds_vfio_dirty_enable()`, if host region allocation (`pds_vfio_dirty_alloc_regions()`) fails after `pds_vfio_dirty_enable_cmd()` has succeeded, the error path must call `pds_vfio_dirty_disable_cmd()` (`out_dirty_disable`) to roll back dirty tracking on the device. [F6]
- Because `pds_vfio_dirty_alloc_regions()` sets `dirty->num_regions = num_regions` upfront and jumps to `out_free_regions` on mid-loop failure, `pds_vfio_dirty_free_sgl()` must check `if (region->sgl)` before calling `__pds_vfio_dirty_free_sgl()` so unallocated region SGLs are not DMA-unmapped. [F30]
- `pds_vfio_dirty_disable_cmd()` must check both the `pds_vfio_client_adminq_cmd()` return value and `comp.lm_dirty_status.num_regions != 0`, returning `-EIO` if the AdminQ command succeeds (`err == 0`) but firmware still reports non-zero active dirty regions. [F24]
- `pds_vfio_get_lm_file()` must check `anon_inode_getfile()` with `IS_ERR()` rather than a `NULL` check, and on any failure during file or page setup must clean up and return `NULL` so callers (`pds_vfio_get_save_file()` and `pds_vfio_get_restore_file()`) only test `!lm_file` and never store an `ERR_PTR` in `save_file` or `restore_file`. [F18]
- `pds_vfio_register_client_cmd()` must store the return value of `pds_client_register()` in a signed `int` and check for `< 0` before assigning it to `pds_vfio->client_id` (`u16`), because `pds_client_register()` returns a positive client ID on success or a negative errno on failure. [F20]
- All callers of `pdsc_get_pf_struct()` (`pds_vfio_client_adminq_cmd()`, `pds_vfio_register_client_cmd()`, and `pds_vfio_unregister_client_cmd()`) must test the returned `struct pdsc *` with `IS_ERR()` before use, because `pdsc_get_pf_struct()` returns `ERR_PTR()` on failure rather than `NULL`. [F21]
- If `pdsc_register_notify(&pds_vfio->nb)` fails in `pds_vfio_pci_register_event_handler()`, `nb->notifier_call` must be reset to `NULL`, because `pds_vfio_pci_unregister_event_handler()` tests `if (pds_vfio->nb.notifier_call)` to determine whether the notifier block is registered. [F28]
- `pds_vfio_step_device_state_locked()` returns a valid `struct file *` when entering `STOP_COPY` or `RESUMING`, `NULL` on other successful steps, and `ERR_PTR()` on failure; `pds_vfio_set_device_state()` must check `IS_ERR(res)` for step errors and set `res = ERR_PTR(-EIO)` if `pds_vfio->state == VFIO_DEVICE_STATE_ERROR`. [F22]
- `pds_vfio_suspend_wait_device_cmd()` must retry `pds_vfio_client_adminq_cmd()` only when `err == -EAGAIN` and `time_before(jiffies, time_limit)`, breaking immediately on `0` or any other error and setting `err = -ETIMEDOUT` if `time_after_eq(time_done, time_limit)`. [F59]
- In the `while (len)` loops of `pds_vfio_save_read()` and `pds_vfio_restore_write()`, a `NULL` return from `pds_vfio_get_file_page()` must set `done = -EINVAL` only when `done == 0`, preserving the accumulated byte count `done` when earlier loop iterations already copied data. [F58]

## External Contracts
- Because the device may size-align `region_info[i].page_count` in-place via DMA during `pds_vfio_dirty_enable_cmd()`, `pds_vfio_dirty_alloc_regions()` must read `le32_to_cpu(ri->page_count)` after `pds_vfio_dirty_enable_cmd()` to size bitmaps, SGLs, and `region->size`, and verify `dev_bmp_offset_byte % BITS_PER_BYTE == 0`. [F46]
- `pds_vfio_recovery()` must only call `pds_vfio_reset(pds_vfio, VFIO_DEVICE_STATE_ERROR)` when `pds_vfio->state` is neither `VFIO_DEVICE_STATE_RUNNING` nor `VFIO_DEVICE_STATE_ERROR`, or when `pds_vfio->state == VFIO_DEVICE_STATE_RUNNING` and `pds_vfio_dirty_is_enabled(pds_vfio)` is true. [F34]
- `pds_vfio_save_read()` and `pds_vfio_restore_write()` must reject non-NULL `pos` (`pread`/`pwrite`) with `-ESPIPE`, clamp each per-page copy to `min_t(size_t, len, PAGE_SIZE - page_offset)` around `kmap_local_page()`, and `pds_vfio_save_read()` must check `*pos > lm_file->size` before clamping `len` to `lm_file->size - *pos`. [F52]

## Known Pitfalls
- In `pds_vfio_client_adminq_cmd()`, copying the 64-byte `union pds_core_adminq_cmd *req` into the wrapped `struct pds_core_client_request_cmd` must use `sizeof(cmd.client_request.client_cmd)` (60 bytes) rather than `sizeof(*req)`, and any `pds_lm_*_cmd` struct sent through it must not define fields past byte 60. [F69]
- Although `region->host_seq` and `region->host_ack` in `struct pds_vfio_region` are typed as `unsigned long *`, offsets passed to `pds_vfio_dirty_seq_ack()` and `pds_vfio_dirty_process_bitmaps()` are byte offsets (`u32`) and must be added after casting the base pointer to a byte-addressed type (`u64` or `u8 *`). [F72]
- When populating a `struct page *` array for `sg_alloc_table_from_pages()`, `pds_vfio_dirty_seq_ack()` and `pds_vfio_get_lm_file()` must align the buffer pointer down by subtracting `offset_in_page()`, `pds_vfio_dirty_seq_ack()` must add `page_offset` when computing `npages = DIV_ROUND_UP_ULL(bmp_bytes + page_offset, PAGE_SIZE)` and pass `page_offset` to `sg_alloc_table_from_pages()`, and page lookup must use `vmalloc_to_page(p)` when `is_vmalloc_addr(p)` is true (or for `vzalloc()` bitmaps) and `kmap_to_page((void *)p)` otherwise for `kvzalloc()` pages. [F50, F90]
- When building hardware SGLs from a DMA-mapped `sg_table` in `pds_vfio_dma_map_lm_file()` and `pds_vfio_dirty_seq_ack()`, iteration must use `for_each_sgtable_dma_sg` and `sg_table.nents`, whereas CPU page lookup in `pds_vfio_get_file_page()` must iterate `sg_table.sgl` up to `sg_table.orig_nents` with `for_each_sg`. [F57]
- In `pds_vfio_dirty_alloc_regions()` and `pds_vfio_dirty_process_bitmaps()`, `page_count` and `abs_bit_i` must be multiplied by 64-bit page sizes (`u64 region_page_size` and `u64 page_size`) so `region_size` and dirty IOVA `addr` calculations do not truncate to 32 bits on regions >= 4 GiB. [F66]
