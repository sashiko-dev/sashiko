# MEMORY MANAGEMENT - CORE

This unit defines core memory management public headers (`include/linux`) and architecture-independent page table, fault handling, highmem (`kmap`/`kmap_local`), MMU notifier, and nofault access implementations (`mm/memory.c`, `mm/mmu_notifier.c`, `mm/highmem.c`, `mm/maccess.c`, `mm/debug.c`, `include/linux/pgtable.h`).

## Architecture & Data Flow

- Compound flags in `FOLIO_SECOND_PAGE` (`PG_large_rmappable`, `PG_partially_mapped`, `PG_has_hwpoisoned`) must be in `PAGE_FLAGS_SECOND`, avoid bits 0–7 (`0xffUL`, used by `folio_large_order()` in `folio->_flags_1`), and use atomic `FOLIO_FLAG(..., FOLIO_SECOND_PAGE)`. `PG_waiters` must stay at bit 7 alongside `PG_locked`, and `folio_xor_flags_has_waiters()` requires the folio lock and a `mask` affecting only bits 0–6. [F23, F98, F99]
- Because HVO fake head pages have `PG_head` set, `PageHead(page)` must check `test_bit(PG_head, &page->flags.f) && !page_is_fake_head(page)` and `PageTail(page)` must check `(READ_ONCE(page->compound_head) & 1) || page_is_fake_head(page)`. `page_fixed_fake_head()` must verify both `IS_ALIGNED((unsigned long)page, PAGE_SIZE)` and `test_bit(PG_head, &page->flags.f)` before reading `page[1].compound_head`. [F107, F117]
- Each `mm_id_t` in `folio->_mm_id[0..1]` must fit in `MM_ID_BITS` (`<= MM_ID_MAX`), leaving `FOLIO_MM_IDS_LOCK_BITNUM` and `FOLIO_MM_IDS_SHARED_BITNUM` reserved. In `folio_maybe_mapped_shared()`, small and hugetlb folios must return `mapcount > 1` first, and large folios must return `false` if `mapcount <= 1` before testing `FOLIO_MM_IDS_SHARED_BITNUM`. [F93, F126]
- `folio->pgmap` unions with `folio->lru` and `folio->mlock_count`, so `page_pgmap(page)` requires `is_zone_device_page(page)`. In `lruvec_init()`, `lruvec->lists[LRU_UNEVICTABLE]` must be poisoned via `list_del()` after `INIT_LIST_HEAD` because unevictable folios store `mlock_count` in `lru`. [F42, F267]
- `__pagetable_ctor()` and `pagetable_dtor()` must keep `PGTY_table` and node `NR_PAGETABLE` (`+/-ptdesc_nr_pages(ptdesc)`) synchronized, and `pagetable_pte/pmd_ctor()` must skip split-ptlock init when `mm == &init_mm`. If `pagetable_pte_ctor()` or `pagetable_pmd_ctor()` returns `false`, free the `ptdesc` with `pagetable_free()`, not `pagetable_dtor()` or `pagetable_dtor_free()`. [F9, F73]
- Device-exclusive swap entries retain their folio rmap mapcount and reference while non-present: `restore_exclusive_pte()` must not add to the folio rmap count, and `zap_nonpresent_ptes()` must call `folio_remove_rmap_pte()` and `folio_put()` for both device-private and device-exclusive entries. [F196]
- In `do_wp_page()`, clearing uffd-wp in place on an async uffd-wp PTE (`userfaultfd_wp_async(vma)`) via `set_pte_at()` must update `vmf->orig_pte` before CoW handling. In `do_page_mkwrite()`, save and restore `vmf->flags` around setting `FAULT_FLAG_WRITE | FAULT_FLAG_MKWRITE` for `vm_ops->page_mkwrite(vmf)`. In `do_swap_page()`, `arch_swap_restore(folio_swap(entry, folio), folio)` must precede `swap_free_nr()` and `folio_free_swap()`. [F253, F254, F259]
- In `can_swapin_thp()`, before `alloc_swap_folio()` allocates a large folio for direct swapin, verify that `swap_pte_batch()`, `swap_zeromap_batch()`, and `non_swapcache_batch()` all equal `nr_pages`. In `handle_pte_marker()`, test `PTE_MARKER_POISONED` (`VM_FAULT_HWPOISON`) and `PTE_MARKER_GUARD` (`VM_FAULT_SIGSEGV`) before `pte_marker_entry_uffd_wp(entry)`. [F290, F292]
- Adding a member to `struct vm_area_struct` requires updating `vm_area_init_from()`. VMA flag bits (`VM_HIGH_ARCH_BIT_0`..`6`, `VM_UFFD_MINOR_BIT`, etc.) must never collide under any Kconfig combination, and `struct mm_struct` ends with flexible array `cpu_bitmap[]` (initialized to `CPU_BITS_NONE` in `init_mm`), so no field may follow it. [F67, F68, F94, F313]

## Synchronization

- `pte_offset_map()` and `pte_offset_map_lock()` enter an RCU read-side critical section; callers must not sleep while mapped and must unlock `ptl` before `pte_unmap()`. `folio_walk_start()` returns a borrowed folio cleaned up via `folio_walk_end(fw, vma)`. `follow_pfnmap_start(args)` returns with `args->lock` held and pairs with `follow_pfnmap_end(args)` under `mmap_lock`; in `generic_access_phys()`, re-run `follow_pfnmap_start()` after `ioremap_prot()` to reverify `pgprot`, `pfn`, and `writable` across `memcpy_toio()`/`fromio()`. [F7, F167, F203, F224]
- Before publishing a new page table page (`pgd/p4d/pud/pmd_populate*`), execute `smp_wmb()` after initializing the table and its lock. Before mapping a newly zeroed or copied user folio with `set_ptes()` or `set_pte_at()`, call `__folio_mark_uptodate()` after writing page contents. `__apply_to_page_range()` must use `*_alloc_track()` helpers and call `arch_sync_kernel_mappings()` when `mask & ARCH_PAGE_TABLE_SYNC_MASK` is non-zero. [F211, F337, F342]
- Commit `ptep_modify_prot_start()`/`modify_prot_start_ptes()` transactions with `ptep_modify_prot_commit()`/`modify_prot_commit_ptes()` before releasing `ptl`. In `copy_pte_range()`, lock `dst_ptl` first and `src_ptl` second via `spin_lock_nested(src_ptl, SINGLE_DEPTH_NESTING)`. [F329, F336]
- Because `struct vm_area_struct` uses `SLAB_TYPESAFE_BY_RCU`, unstable RCU readers before stabilizing `vm_refcnt` and `vm_lock_seq` may only read `vm_mm`, `vm_refcnt`, and `READ_ONCE(vma->vm_lock_seq)`. Modifying `vma->vm_flags` on a linked VMA requires write-locking the VMA (`vm_flags_set/clear/mod()` or before `vm_flags_reset*()`). `vma->vm_lock_seq` is written via `WRITE_ONCE()` only under both write `mmap_lock` and the VMA lock (`VMA_LOCK_OFFSET`). [F32, F38, F170]
- Under `FAULT_FLAG_VMA_LOCK`, fault handlers must drop the lock via `release_fault_lock(vmf)` (not `mmap_read_unlock()`), and use `vmf_anon_prepare()` rather than `anon_vma_prepare()`. In `__do_fault()`, preallocate `vmf->prealloc_pte` before `vma->vm_ops->fault(vmf)` or `folio_lock()`. [F16, F223, F338]
- `wp_can_reuse_anon_folio()` must reverify `!folio_test_ksm(folio)` and `folio_ref_count(folio) == 1` under `folio_trylock(folio)`; `__wp_can_reuse_large_anon_folio()` must reverify `!test_bit(FOLIO_MM_IDS_SHARED_BITNUM, &folio->_mm_ids)` and `folio_large_mapcount(folio) == folio_ref_count(folio)` under `folio_lock_large_mapcount(folio)`. In `zap_pte_range()`, breaking early to drop `ptl` must set `direct_reclaim = false`. [F218, F219, F220]
- `folio_needs_cow_for_dma()` requires holding `ptl` inside a `write_protect_seq` write critical section. In `copy_page_range()`, if `is_cow_mapping(src_vma->vm_flags)` is true, write-lock `src_vma` and bracket the copy with `mmu_notifier_invalidate_range_start()`/`end()` and `raw_write_seqcount_begin()`/`end(&src_mm->write_protect_seq)`. [F35, F227]
- Lockless `page_folio(page)` callers must recheck `page_folio(page) == folio` after `folio_try_get(folio)`. In `page_ref_add_unless()`, `page_count_writable(page, u)` (checking `atomic_read_acquire(&page->_refcount) == u` before `page_fixed_fake_head(page) == page`) and `atomic_add_unless()` must run under `rcu_read_lock()`. `remove_device_exclusive_entry()` must pin the folio with `folio_try_get(folio)` before `folio_lock_or_retry()`. [F36, F168, F340]
- In MMU notifiers, `arch_invalidate_secondary_tlbs()` and `free_notifier()` must never sleep, and `invalidate_range_start()`/`invalidate()` must not sleep when `!mmu_notifier_range_blockable(range)`. `mmu_interval_set_seq()` and `mmu_interval_read_retry()` require the same user lock, which must not be held during `mmu_interval_notifier_remove()` or `mmu_interval_read_begin()`. [F26, F162, F216]
- While `mn_itree_is_invalidating(subscriptions)` is true (odd `invalidate_seq`), `itree` insert/remove must defer to `deferred_list` (drained in `mn_itree_inv_end()` with `hlist_for_each_entry_safe()` under `subscriptions->lock`), and `mmu_interval_notifier_remove()` must wait on `subscriptions->wq` before `mmdrop(mm)`. [F210, F300, F304]
- `GFP_ATOMIC` and `GFP_NOWAIT` set `__GFP_KSWAPD_RECLAIM` (`gfpflags_allow_spinning()`) and cannot be used in NMI or `raw_spinlock_t` contexts (use `alloc_pages_nolock()`). `folio_put()`, `folio_put_refs()`, `folios_put()`, and `put_page()` must not be called in NMI context. [F156, F169]

## Object Lifetimes

- `get_page()` and `put_page()` must check `folio_test_slab(folio)` and `folio_test_large_kmalloc(folio)` and leave their frozen zero refcount untouched. Never pass `FOLL_PIN` to `get_user_pages*()`, and always release `pin_user_pages*()` pages with `unpin_user_page*()`/`unpin_folio*()`, never `put_page()`/`folio_put()`. `folio_alloc_gigantic()` requires `order > 0` and `__GFP_COMP` and must be freed with `folio_put()`, not `free_contig_range()`. [F1, F14, F56, F190]
- `folio_release_kmap()` must call `kunmap_local(addr)` before `folio_put(folio)`. In `fault_dirty_shared_page()`, sample `folio_raw_mapping(folio)` before `folio_unlock(folio)`. In `wp_page_copy()`, `ptep_clear_flush()` and `set_pte_at()` must complete under `vmf->ptl` before `folio_remove_rmap_pte(old_folio, ...)`, and `old_folio` is put after `mmu_notifier_invalidate_range_end()`. [F5, F204, F255]
- In `handle_mm_fault()`, never dereference `vma` after `hugetlb_fault()` or `__handle_mm_fault()`. Clear `vmf->prealloc_pte = NULL` when consumed by `pmd_install()` or `deposit_prealloc_pte()`. In `copy_present_page()`, clear `*prealloc = NULL` only after `copy_mc_user_highpage()` succeeds; `copy_pte_range()` must `folio_put()` and zero any leftover `prealloc` after each step and on exit. [F199, F200, F222]
- `mn_hlist_release()` and `mmu_notifier_unregister()` must unlink `subscription->hlist` with `hlist_del_init_rcu()` under `subscriptions->lock` and call `synchronize_srcu(&srcu)` before `mmdrop(mm)`. Modules using `mmu_notifier_put()` must call `mmu_notifier_synchronize()` in `__exit`. [F208, F214, F349]

## API Contracts

- `finish_fault()` consumes the caller's locked folio reference only when returning `0`; on non-zero `VM_FAULT_*`, the caller must unlock and `folio_put()` it. For large folios (`nr_pages > 1`), `finish_fault()` requires `!userfaultfd_armed(vma)` and bounds within the VMA and PMD table, and if `!pte_range_none(vmf->pte, nr_pages)` under `ptl`, it must `pte_unmap_unlock()` and retry at `fallback` with `nr_pages = 1` instead of returning `VM_FAULT_NOPAGE`. [F201, F288, F361]
- Callers of `folio_pte_batch_flags()`, `folio_pte_batch()`, and `swap_pte_batch()` must bound `max_nr >= 1` to the VMA and single PMD table; `folio_pte_batch_flags()` must also clamp `max_nr` to `folio_pfn(folio) + folio_nr_pages(folio) - pte_pfn(pte)`, return `min(nr, max_nr)`, and take a local `pte_t` copy in `@ptentp`. `modify_prot_start_ptes()` and `get_and_clear_full_ptes()` must merge `pte_dirty` and `pte_young` across the batch, and `modify_prot_commit_ptes()` must advance both `old_pte` and `pte` via `pte_next_pfn()`. [F248, F265, F268, F269]
- Use `folio_mk_pte/pmd/pud()` for refcounted folios instead of `*_mkspecial()`. `vm_insert_page(s)()` requires `VM_MIXEDMAP` (or write `mmap_lock` with `!VM_PFNMAP`) and a refcounted, non-anon, untyped folio. `vmf_insert_pfn*()` requires `VM_PFNMAP ^ VM_MIXEDMAP`, forbids COW on `VM_PFNMAP`, and forbids `pfn_valid(pfn)` on `VM_MIXEDMAP`. In `insert_pages()`, cap `pages_to_write_in_pmd` at `PTRS_PER_PTE - pte_index(addr)` and subtract `pte_idx` from `remaining_pages_total` on mid-batch error. [F177, F272, F299, F356, F357, F358]
- `mm->mm_mt` and `mmu_notifier` interval trees store inclusive `[start, end - 1]`, so VMA iterator helpers and `mn_itree_inv_start_range()`/`next()` must subtract 1 from exclusive `end`. In `free_pgd/p4d/pud/pmd_range()`, compare `end - 1 > ceiling - 1` and return early if masked `ceiling` is `0`. In `unmap_mapping_pages()`/`range()`, `nr == 0` (`holelen == 0`) or wrap must clamp `last_index` to `ULONG_MAX`. [F95, F273, F274, F275]
- Call `folio_batch_remove_exceptionals()` before `folios_put()` or `folio_batch_release()` if the batch may hold shadow/swap/DAX entries, and use `folio_batch_reinit()` (not `folio_batch_init()`) to preserve `percpu_pvec_drained`. Iterating `page_ext` across PFNs requires `for_each_page_ext()` under `rcu_read_lock()`, not `page_ext_next()`. [F19, F85, F91]
- `kmap_local_folio(folio, byte_offset)` maps only one page when `folio_test_partial_kmap(folio)` is true, and must be unmapped in LIFO order via `kunmap_local()`; pass the return value of `folio_zero_tail(folio, offset, kaddr)` to `kunmap_local()`. `folio_zero_segment(s)()` and `zero_user_segment()` take an exclusive end offset, whereas `folio_zero_range()` and `memzero_page()` take a length. [F50, F51, F147, F159]
- `mm_flags_test/set/clear()` take a bit index (`MMF_*`), whereas `__mm_flags_*_word()` take shifted masks (`MMF_*_MASK`) and only access the first `BITS_PER_LONG` word of 64-bit `mm_flags_t`. `page_mapcount_is_type()` expects `page->_mapcount + 1`; use `page_type_has_type(signed int)` for raw `page_type`/`_mapcount`. [F40, F64, F133, F155]

## Error Handling

- `alloc_anon_folio()` returns a folio, `NULL` (OOM), or `ERR_PTR(-EAGAIN)`; check `IS_ERR(folio)` before `!folio`. In `do_swap_page()`, if `ksm_might_need_to_copy()` returns `NULL` or `ERR_PTR(-EHWPOISON)`, restore `folio = swapcache` before `goto out_page`. `get_user_page_vma_remote()` returns `ERR_PTR` (never `NULL`) on error and rejects `FOLL_NOWAIT`. [F59, F231, F232]
- `copy_mc_user_highpage()`, `copy_mc_highpage()`, and `copy_folio_from_user()` return positive uncopied bytes on error (`0` on success), whereas `copy_from/to_user_nofault()` return `-EFAULT`. In `copy_pte_range()`, `copy_nonpresent_pte()` returning `-ENOENT` must fall through to `copy_present_ptes()` (returning copied PTE count `>= 1` or negative errno). [F52, F233, F244]
- On `remap_pfn_range_internal()` failure, `remap_pfn_range_notrack()` must call `zap_page_range_single()`, and `remap_pfn_range()` must release `ctx` via `kref_put()`. When `vfs_mmap()` fails in `mmap_file()` or after `vma_close()` calls `vm_ops->close()`, set `vma->vm_ops = &vma_dummy_vm_ops` (not `NULL`). [F198, F243]

## External Contracts

- `copy_remote_vm_str()` and `__copy_remote_vm_str()` return `-EFAULT` on error and must write `*(char *)buf = '\0'` when `len > 0` on all failure paths, untag `addr` via `untagged_addr_remote(mm, addr)` under `mmap_lock`, and re-copy `maddr + (PAGE_SIZE - 1)` into `buf + bytes - 1` when `strscpy()` returns `-E2BIG` across pages. Never export `copy_to_kernel_nofault()`. User-facing RSS/swap reporting must use `get_mm_counter_sum()`, not `get_mm_counter()`. [F178, F238, F276, F277, F350]

## Known Pitfalls

- `folio_test_anon()`, `PageAnon()`, `PageAnonNotKsm()`, and `folio_test_ksm()` require `!folio_test_slab(folio)` on arbitrary pages, and distinguishing non-KSM anon from KSM requires masking `folio->mapping` with `FOLIO_MAPPING_FLAGS`. `folio_test_swapcache()` requires `folio_test_swapbacked(folio)`, and `page_has_movable_ops()` requires `PageOffline(page) || PageZsmalloc(page)`. [F41, F115, F116]
- Always use `folio_page(folio, n)` or `folio_next(folio)`, never `folio + n` or `folio++` (`sizeof(struct folio) == 4 * sizeof(struct page)`). On `!CONFIG_64BIT`, order-1 folios lack `__page_2`, so use `folio_entire_mapcount()` and `folio_has_pincount()`. Lockless `compound_order()` callers must bound the order before shifting, and `folio_maybe_dma_pinned()`/`folio_ref_zero_or_close_to_overflow()` must cast `folio_ref_count()` to `unsigned int`. [F134, F135, F145, F146]
- Functions iterating a `pte_t *` cursor (`copy/zap/remap/apply_to_pte_range()`, `insert_pages()`) must pass the initial mapped `pte_t *` to `pte_unmap_unlock()`, not the incremented cursor; in `apply_to_pte_range()`, keep `pte++` in the `while` condition; in `zap_pmd_range()`, execute `pmd--` if `zap_pte_range()` returns `addr != next`; under `CONFIG_HIGHPTE`, `__pte_map()` must cast `kmap_local_page()` to `pte_t *` before adding `pte_index(address)`. [F289, F296, F317, F318]
- Use `mmu_notifier_range_init_owner()` for `MMU_NOTIFY_MIGRATE` and `MMU_NOTIFY_EXCLUSIVE`, and only read `range->owner` on those events. VMA flags at bit `>= 31` must use `BIT()`. In `vma_soft_dirty_enabled()`, check `IS_ENABLED(CONFIG_MEM_SOFT_DIRTY)` before `!(vma->vm_flags & VM_SOFTDIRTY)`. Printk `%pGp`, `%pGg`, and `%pGv` take a pointer to the flags variable. [F58, F130, F153, F293]
