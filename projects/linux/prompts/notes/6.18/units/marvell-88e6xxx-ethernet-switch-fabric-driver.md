# MARVELL 88E6XXX ETHERNET SWITCH FABRIC DRIVER

`drivers/net/dsa/mv88e6xxx` implements the DSA driver for Marvell Link Street 88E6xxx Ethernet switches over SMI/MDIO, managing switch probing/resets, Global 1/2 registers, ATU/VTU/STU tables, Cross-chip Port VLAN Tables (PVT), cascaded IRQ domains, Phylink MAC/PCS, PTP timestamping, and Devlink regions.

## Architecture & Data Flow

- `mv88e6xxx_has_stu()` must check `chip->info->max_sid > 0` and non-NULL `stu_loadpurge`/`stu_getnext` ops, and all STU entry points (`mv88e6xxx_stu_setup()`, `mv88e6xxx_mst_get()`, `mv88e6xxx_mst_put()`, `mv88e6xxx_vlan_msti_set()`) must gate STU access on it. Chips using split VTU/STU ops (`mv88e6352_g1_vtu_*` or `mv88e6390_g1_vtu_*`) must define `.max_sid > 0`, `.stu_getnext`, and `.stu_loadpurge`. [F36, F69]
- `mv88e6xxx_stu_setup()` must run after `mv88e6xxx_vtu_setup()` (whose `FLUSH_ALL` flushes both VTU and STU) to load STU `sid = 0` as valid, `mv88e6xxx_sid_get()` must pre-set bit 0 and reject `*sid >= mv88e6xxx_max_sid(chip)`, and `mv88e6xxx_mst_put()` must never purge `sid == 0`. Similarly, `chip->fid_bitmap` must track VTU/ATU FIDs: `mv88e6xxx_atu_new()` selects a zero bit and checks `*fid < mv88e6xxx_num_databases(chip)`, `mv88e6xxx_port_vlan_join()` sets it, `mv88e6xxx_port_vlan_leave()` clears it when `!vlan.valid`, and `mv88e6xxx_g1_vtu_flush()` zeroes it. [F50, F51, F80]
- `mv88e6xxx_setup_port()` must join `MV88E6XXX_VID_STANDALONE` before `MV88E6XXX_VID_BRIDGED` so `mv88e6xxx_atu_new()` assigns them `MV88E6XXX_FID_STANDALONE` (0) and `MV88E6XXX_FID_BRIDGED` (1), and `mv88e6xxx_port_db_get()` must map `vid == 0` to `MV88E6XXX_FID_BRIDGED`. `mv88e6xxx_port_commit_pvid()` must be called under `chip->reg_lock` whenever bridge membership, VLAN filtering, or `chip->ports[port].bridge_pvid` changes. [F53, F62]
- In the PVT, physical switches occupy `dev = 0 .. dst->last_switch` and virtual bridges map at `dev = bridge_num + dst->last_switch` (`ds->max_num_bridges = MV88E6XXX_MAX_PVT_SWITCHES - ds->dst->last_switch - 1`). On PVT-capable chips, local and cross-chip bridge join/leave must call `mv88e6xxx_map_virtual_bridge_to_pvt()` alongside `mv88e6xxx_bridge_map()` or `mv88e6xxx_pvt_map()`. [F54, F76]
- In `mv88e6xxx_pvt_map()`, a remote port in a LAG (`dp && dp->lag`) must be remapped to `dev = MV88E6XXX_G2_PVT_ADDR_DEV_TRUNK` and `port = dsa_port_lag_id_get(dp) - 1`, and `mv88e6xxx_crosschip_lag_join()` / `leave()` must call `mv88e6xxx_pvt_map()` alongside `mv88e6xxx_lag_sync_masks_map()`. [F55]
- Hardware LAG hash distribution supports at most 8 ports per LAG and indexes `mv88e6xxx_lag_mask_table[num_tx - 1][nth]` (`1 <= num_tx <= 8`, `nth < num_tx`). In `mv88e6xxx_lag_sync_masks()`, the second `dsa_lag_foreach_port()` pass must skip `!dp->lag_tx_enabled` before `nth++`, but must increment `nth` for every TX-enabled port in `ds->dst` even when `dp->ds != ds`. [F75, F96]
- In `mv88e6xxx_port_db_load_purge()`, removing a port from an ATU entry (`!state`) must only clear `BIT(port)` from `entry.portvec`, setting `entry.state = 0` only when `entry.portvec` becomes zero. When clearing a policy (`MV88E6XXX_POLICY_ACTION_NORMAL`) in `mv88e6xxx_policy_apply()`, `port_set_policy()` must be skipped if any remaining entry in `chip->policies` has the same `port` and `mapping` with a non-normal action. [F63, F64]
- `mv88e6xxx_set_egress_port()` must update `chip->ingress_dest_port` or `chip->egress_dest_port`, and `mv88e6xxx_port_mirror_add()` / `del()` must check `mirror_ingress` / `mirror_egress` across all ports to reject active destination changes (`-EBUSY`) and reset the destination to `dsa_upstream_port()` when none remain. [F56]
- In `mv88e6xxx_g1_vtu_vid_read()` / `write()`, bit 12 (`0x1000`) of a 13-bit VID must map to `MV88E6390_G1_VTU_VID_PAGE` (`0x2000`) because bit 12 is `MV88E6XXX_G1_VTU_VID_VALID`, and chips supporting it (6390/6393 families, including `MV88E6361`) must set `.max_vid = 8191`. In `mv88e6xxx_g1_atu_op()` and `mv88e6xxx_g1_atu_fid_read()`, `mv88e6xxx_num_databases(chip)` thresholds (`> 256`, `> 64`, `> 16`) must be tested in descending order, always combining `fid & 0xf` when `<= 256`. [F86, F97, F127]
- Each `mv88e6xxx_info` in `mv88e6xxx_table` must set `1 <= num_ports <= 16` (or `highest_port + 1` with unrouted ports in `invalid_port_mask`), non-zero `age_time_coeff` (with `mv88e6xxx_g1_atu_set_age_time()` checking `msecs` in `[0x01 * coeff, 0xff * coeff]`), and `.atu_move_port_mask` matching the hardware ATU PortVec width (`0xf`, `0x1f`, or `0`). [F72, F103, F104, F125]
- Internal PHY indices (`mv88e6xxx_phy_is_internal()`, `mv88e6xxx_mdio_register()`, `mv88e6xxx_g2_irq_mdio_setup()`) must be offset by `internal_phys_offset` and MDIO bus PHY addresses (`bus->phy_mask`, `bus->irq[]`) by `phy_base_addr`. In `mv88e6xxx_mdio_register()`, the internal bus (`!external`) must use `list_add()` at the head of `chip->mdios` while external buses use `list_add_tail()`. [F73, F123]
- `.phylink_get_caps` must match the C_Mode encoding of `.port_get_cmode` (`mv88e6xxx_translate_cmode` for `mv88e6352_port_get_cmode`, `mv88e6185_phy_interface_modes` for `mv88e6185_port_get_cmode`), checking `cmode < ARRAY_SIZE(...)` and a non-zero entry before `__set_bit()`. When `mv88e63xx_get_port_serdes_cmode()` clears `MV88E6XXX_PORT_STS_PHY_DETECT` to read SERDES `CMODE`, it must restore the original `MV88E6XXX_PORT_STS` value. [F67, F71, F128]
- In `mv88e6xxx_g1_atu_prob_irq_thread_fn()`, indexing `chip->ports[spid]` with `spid = entry.state` on `MV88E6XXX_G1_ATU_OP_FULL_VIOLATION` must be guarded by `spid < ARRAY_SIZE(chip->ports)`. [F70]
- In `mv88e6xxx_setup_port()`, user ports must start with `mv88e6xxx_port_set_map_da(chip, port, false)`, `MV88E6XXX_PORT_CTL2_8021Q_MODE_DISABLED`, and `MV88E6XXX_PORT_ASSOC_VECTOR = 0` (CPU/DSA ports enable all three). In `mv88e6xxx_change_mtu()`, chip-wide `set_max_frame_size()` must only be called on CPU ports (`dsa_is_cpu_port()`). [F65, F150]
- VTU and STU devlink regions must size and allocate buffers for `max_vid + 1` and `max_sid + 1` entries, and every devlink `.snapshot` callback must allocate at least the registered region byte size. In `mv88e6xxx_get_rxts()` and `mv88e6xxx_txtstamp_work()`, raw 32-bit PTP timestamps must be converted via `timecounter_cyc2time(&chip->tstamp_tc, ...)` under `chip->reg_lock`, and `seq_match()` / `mv88e6xxx_port_txtstamp()` must convert `__be16` `hdr->sequence_id` with `ntohs()` or `be16_to_cpu()`. [F78, F82, F102, F109]

## Synchronization

- Every call to `mv88e6xxx_read()`, `mv88e6xxx_write()`, `mv88e6xxx_wait_mask()`, or `mv88e6xxx_wait_bit()` must run in sleepable context with `chip->reg_lock` held. `chip->fid_bitmap`, `chip->policies`, and `chip->gpio_data` must only be accessed under `chip->reg_lock`, and multi-step indirect hardware accesses (ATU/VTU/STU getnext/loadpurge, `mv88e6xxx_devlink_atu_bin_get()`, `mv88e6xxx_g2_avb_read()`/`write()`, G2 scratch accesses) must hold `chip->reg_lock` continuously. [F29, F30, F68, F136]
- `irq_chip` `.irq_mask` and `.irq_unmask` callbacks run in atomic context and must only update `g1_irq.masked` or `g2_irq.masked`, deferring SMI writes to `.irq_bus_sync_unlock`. `mv88e6xxx_g1_irq_thread_work()` and `mv88e6xxx_g2_irq_thread_fn()` must drop `chip->reg_lock` before `handle_nested_irq()`, and `mv88e6xxx_g1_atu_prob_irq_thread_fn()` must drop `chip->reg_lock` before `mv88e6xxx_handle_miss_violation()`. [F137, F138, F144]
- `request_threaded_irq()`, `free_irq()`, `kthread_cancel_delayed_work_sync()`, and all `mv88e6xxx_setup_devlink_*` / `teardown_devlink_*` functions must be called without `chip->reg_lock` held (`devlink_lock -> chip->reg_lock`), and devlink `.snapshot` callbacks must allocate `GFP_KERNEL` buffers before taking `chip->reg_lock`. `mv88e6xxx_g1_irq_setup()` must call `irq_set_lockdep_class()` on `chip->irq` before requesting it. [F139, F140, F141, F142]
- `mv88e6xxx_port_vlan_del()` must call `dsa_flush_workqueue()` before acquiring `chip->reg_lock` and calling `mv88e6xxx_port_vlan_leave()` so pending deferred FDB deletions complete while the VLAN's FID is still in the VTU. [F61]
- `mv88e6xxx_set_hwtstamp_config()` must clear `MV88E6XXX_HWTSTAMP_ENABLED` before reconfiguring hardware, update `chip->enable_count` with `ptp_ops->global_enable`/`disable` under `chip->reg_lock`, and set `MV88E6XXX_HWTSTAMP_ENABLED` afterward. [F59]
- `mv88e6xxx_port_txtstamp()` must acquire `MV88E6XXX_HWTSTAMP_TX_IN_PROGRESS` via `test_and_set_bit_lock()` (freeing the `skb_clone_sk()` clone on contention), `mv88e6xxx_txtstamp_work()` must clear `ps->tx_skb = NULL` and `clear_bit_unlock()` before `skb_complete_tx_timestamp()`, and `mv88e6xxx_get_rxts()` must splice `rx_queue` under `spin_lock_irqsave(&rxq->lock, flags)` and drop `rxq->lock` before taking `chip->reg_lock` or calling `netif_rx()`. [F147, F156]

## Object Lifetimes

- In `mv88e6xxx_probe()` and `mv88e6xxx_remove()`, G1/G2 IRQ domains must be set up before `mv88e6xxx_register_switch()` and torn down in reverse order (`mv88e6xxx_unregister_switch()`, G1/G2 sub-IRQs, `g2_irq`, `g1_irq`/`irq_poll`), formatting IRQ names into the persistent `char[64]` buffers in `struct mv88e6xxx_chip`. [F23, F118]
- `mv88e6xxx_mdio_register()` borrows `np`, so `mv88e6xxx_mdios_register()` must call `of_node_put(child)` after `of_get_child_by_name()` and on loop error exit, and call `mv88e6xxx_mdios_unregister(chip)` on failure. In `mv88e6xxx_setup_port()`, `ports_fwnode` and `phy_handle` must be released via `fwnode_handle_put()` and `of_node_put()` on all paths. [F6, F7]
- In `mv88e6xxx_vlan_msti_set()`, `mv88e6xxx_mst_get()` takes a ref on `new_sid` (even if `new_sid == old_sid`); if `new_sid != old_sid` and `mv88e6xxx_vtu_loadpurge()` fails, call `mv88e6xxx_mst_put(chip, new_sid)`, whereas on success (including `new_sid == old_sid`) call `mv88e6xxx_mst_put(chip, old_sid)`. [F9]
- In `mv88e6xxx_policy_insert()`, a policy allocated with `devm_kzalloc()` and added via `idr_alloc_u32()` must be rolled back with `idr_remove()` and `devm_kfree()` if `mv88e6xxx_policy_apply()` fails, and freed with `devm_kfree()` on deletion in `mv88e6xxx_set_rxnfc()`. [F11]
- Once `mv88e6xxx_port_rxtstamp()` queues an `skb` to `ps->rx_queue`/`rx_queue2` and returns `true`, `mv88e6xxx_get_rxts()` must pass every dequeued `skb` to `netif_rx(skb)` even if its sequence ID does not match or register reads fail. Devlink `.snapshot` callbacks must allocate `*data` with `kmalloc_array()`/`kcalloc()` (matching `.destructor = kfree`) and `kfree()` it on error. [F155, F157]

## API Contracts

- `mv88e6xxx_wait_bit()`, `mv88e6xxx_g1_wait_bit()`, and `mv88e6xxx_g2_wait_bit()` take a bit index (`__bf_shf(MASK)`) and target `0`/`1`, whereas `mv88e6xxx_wait_mask()` and `mv88e6xxx_g1_wait_mask()` take a shifted 16-bit mask and value. DSA LAG IDs (`lag.id`, `dsa_port_lag_id_get(dp)`) are 1-based while hardware trunk IDs and PVT trunk indices are 0-based; callers must subtract 1. [F46, F47]
- `mv88e6xxx_g1_is_eeprom_done()` returns 0 when done, `-EBUSY` while resetting (`0xffff`) or busy, and other negative errnos on failure; callers must loop only on `-EBUSY`. `mv88e6352_g2_scratch_port_has_serdes()` and `mv88e63xx_get_port_serdes_cmode()` return negative errnos on failure and non-negative values on success, so callers must store the return in a signed `int` and check `< 0`. [F33, F34]
- `mv88e6xxx_port_setup_mac()` must force the link down (`LINK_FORCED_DOWN`) via `port_set_link()` before changing speed, duplex, pause, RGMII delay, or cmode, and restore `link` on both normal and error paths. [F66]
- `mv88e6xxx_get_max_mtu()` must subtract `VLAN_ETH_HLEN + EDSA_HLEN + ETH_FCS_LEN` from hardware max (10240 or 1632), `mv88e6xxx_change_mtu()` must add `EDSA_HLEN` on CPU/DSA ports, and `mv88e6185_g1_set_max_frame_size()` must add `ETH_HLEN + ETH_FCS_LEN`. `mv88e6xxx_g2_avb_read()` must reject `len > 4` with `-E2BIG`. [F48, F81]

## Error Handling

- `mv88e6xxx_mdio_read_c45()` must return `-ENODEV` (not `-EOPNOTSUPP`) when `phy_read_c45` is NULL. In port/MAC setup (`mv88e6xxx_port_config_interface()`, `mv88e6xxx_port_setup_mac()`, `mv88e6xxx_setup_port()`, `mv88e6xxx_setup_upstream_port()`), `-EOPNOTSUPP` from per-port callbacks must be ignored. [F32, F35]
- Callers (`mv88e6xxx_mac_select_pcs()`, `mv88e6xxx_port_setup()`, `mv88e6xxx_port_teardown()`) must check `chip->info->ops->pcs_ops != NULL`. Devlink region setup must check `IS_ERR(region)` before assigning to `chip->regions[i]` or `chip->ports[port].region`, and `mv88e6xxx_teardown_devlink_regions_global()` must check `chip->regions[i] != NULL` before `dsa_devlink_region_destroy()`. [F37, F38, F39]
- In `mv88e6xxx_port_lag_leave()` and `mv88e6xxx_crosschip_lag_leave()`, both cleanup steps must run unconditionally with separate error variables (`err_sync ? : err_trunk`/`err_pvt`). When `refcount_dec_and_test(&mst->refcnt)` hits 0 in `mv88e6xxx_mst_put()`, `mv88e6xxx_stu_loadpurge()` must purge the STU entry before unlinking/freeing `mst`, restoring `refcount_set(&mst->refcnt, 1)` on failure. [F41, F52]
- `mv88e6xxx_change_tag_protocol()` must set `chip->tag_protocol` before `mv88e6xxx_setup_port_mode()` and restore `old_protocol` before reverse-unwinding on error. `mv88e6xxx_port_fdb_add()` and `mv88e6xxx_port_mdb_add()` must verify the loaded ATU entry with `mv88e6xxx_port_db_find()` under `chip->reg_lock` and return `-ENOSPC` if missing. [F57, F133]
- `mv88e6xxx_vtu_get()` must `memset(entry, 0, sizeof(*entry))` before `vtu_getnext` because chip-specific ops (`mv88e6185_g1_vtu_getnext()`) omit fields like `sid` and `policy`. [F42]

## External Contracts

- `mv88e6xxx_port_check_hw_vlan()` (when a VID is used by another bridge) and `mv88e6xxx_port_vlan_leave()` (when the VTU entry is invalid or the port is non-member) must return `-EOPNOTSUPP` for software VLAN fallback. In `mv88e6xxx_setup_port()`, `MV88E6XXX_PORT_CTL0_IGMP_MLD_SNOOP` must only be set on user ports (`dsa_is_user_port()`). [F149, F152]

## Known Pitfalls

- Because `vtu_getnext`/`stu_getnext` write the starting ID only when `!entry->valid` and return the next ID, `mv88e6xxx_vtu_get()` must set `entry->vid = vid ? vid - 1 : mv88e6xxx_max_vid(chip)` with `valid = false`, and full walks must start at `max_vid`/`max_sid` with `valid = false`. Similarly, `atu_getnext` writes `entry->mac` only when `!entry->state`, so `mv88e6xxx_port_db_get()` must zero `entry->state` and call `eth_addr_dec(entry->mac)`, while full ATU walks start at broadcast and stop at `is_broadcast_ether_addr()`. [F77, F79]
- In `mv88e6xxx_hardware_reset()`, `hardware_reset_pre` and `hardware_reset_post` must wrap pulsing `chip->reset`, and no read of `MV88E6XXX_G1_STS` may occur before `mv88e6xxx_g1_wait_eeprom_done()`. In `mv88e6xxx_mst_get()` and `mv88e6xxx_port_mst_state_set()`, `BR_STATE_DISABLED` on user ports must map to `MV88E6XXX_PORT_CTL0_STATE_BLOCKING` (`STATE_DISABLED` is only for CPU/DSA ports). [F134, F161]
- In `mv88e6xxx_port_vlan()`, `list_for_each_entry()` searches must track a `found` boolean before dereferencing `dp`. In `mv88e6xxx_policy_apply()`, target `policy` fields must be copied to locals before `idr_for_each_entry(&chip->policies, policy, id)` overwrites `policy`. Narrow bitmasks (`atu_move_port_mask`) must be widened to `unsigned long` before `bitmap_weight()`. [F92, F93, F117]
