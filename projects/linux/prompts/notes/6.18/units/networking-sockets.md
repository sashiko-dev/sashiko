# NETWORKING [SOCKETS]

This unit implements the core Linux socket layer (`net/socket.c`, `net/core/sock.c`, `include/net/sock.h`, `net/core/scm.c`, `net/core/sock_reuseport.c`, `net/core/request_sock.c`, and `sock_diag`), bridging VFS `sockfs` file operations and syscalls with transport sockets (`struct socket` and `struct sock`), dual process/BH socket locking, memory accounting, ancillary control messages, `SO_REUSEPORT` scaling, TFO queues, and Netlink diagnostics.

## Architecture & Data Flow

- `sk->sk_flags` (`__sk_common.skc_flags`) shares a union in `struct sock_common` with `skc_listener` and `skc_tw_dr`; paths that may see `TCP_TIME_WAIT` or `TCP_NEW_SYN_RECV` sockets must verify `sk_fullsock(sk)` before calling `sock_flag()` or accessing full-socket fields. [F51]
- `sk->sk_socket` and `sk->sk_wq` are `NULL` on un-grafted or orphaned sockets (after `sock_orphan()`). `sk_user_ns(sk)` and `sk_ns_capable(sk, ...)` unconditionally dereference `sk->sk_socket->file` and must only be called when attached to an open file, while async/wakeup paths must null-check them. [F56]
- `sk->sk_user_data` encodes flags (`SK_USER_DATA_NOCOPY`, `SK_USER_DATA_BPF`, `SK_USER_DATA_PSOCK`) in its low bits; readers must mask with `SK_USER_DATA_PTRMASK`, and `__locked_read_sk_user_data_with_flags()` / `__rcu_dereference_sk_user_data_with_flags()` must test `(sk_user_data & flags) == flags`. [F54, F116]
- `sock_copy()` must skip `sk_dontcopy_begin..sk_dontcopy_end` and preserve `nsk->sk_security` before `security_sk_clone()`. `sk_clone_lock()` must clear `newsk->sk_user_data` if `sk_user_data_is_nocopy(newsk)`, mask `~SOCK_BINDPORT_LOCK` on `sk_userlocks`, and reset `sk_reuseport_cb`, `sk_memcg`, `sk_wq`, and `sk_socket` to `NULL`. [F79, F80]
- When allocating `struct sock` from `prot->slab`, `sk_prot_alloc()` must strip `__GFP_ZERO` and zero via `sk_prot_clear_nulls()` so `sk->sk_node.next` (`sk->sk_nulls_node.next`) is preserved for `SLAB_TYPESAFE_BY_RCU` caches. [F60]
- `sk_set_socket()` must keep `sk->sk_ino` and `sk->sk_uid` synchronized with `sk->sk_socket` (writing `SOCK_INODE(sock)->i_uid` and `i_ino` on bind, and clearing `sk_ino` to 0 via `WRITE_ONCE()` on `NULL`), and `sockfs_setattr()` with `ATTR_UID` must update `WRITE_ONCE(sock->sk->sk_uid, iattr->ia_uid)`. [F70, F71]
- Replacing or clearing `sk->sk_dst_cache` (`__sk_dst_set()`, `sk_dst_set()`, `__sk_dst_check()`) must also call `sk_tx_queue_clear(sk)` and `WRITE_ONCE(sk->sk_dst_pending_confirm, 0)`. Mutating `sk_bound_dev_if`, `sk_mark`, or `SOCK_LOCALROUTE` must call `sk_dst_reset(sk)` (and `sk->sk_prot->rehash(sk)` for `sk_bound_dev_if`). [F72, F73]
- `scm_fp_copy()` uses `kmalloc()` and must initialize all `struct scm_fp_list` metadata fields and enforce both `num <= SCM_MAX_FD` and `fpl->count + num <= fpl->max`. `scm_fp_dup()` allocates only `fpl->count` slots via `kmemdup()`, sets `new_fpl->max = new_fpl->count` (forbidding appends), and must reset `inflight = false`, `edges = NULL`, and `vertices`. [F63, F92, F98, F139]
- `struct msghdr` unions `msg_control` and `msg_control_user` discriminated by `msg_control_is_user`; kernel buffer replacements must set `msg_control_is_user = false`, and cmsg writers (`put_cmsg()`, `scm_detach_fds()`, compat variants) must advance `msg_control`/`msg_control_user` and decrement `msg_controllen` by `min(CMSG_SPACE(len), msg->msg_controllen)`. [F55, F93]
- In `struct sock_reuseport`, `__reuseport_alloc()` must set `reuse->max_socks` immediately after `kzalloc()` before indexing `reuse->socks[]` (`__counted_by(max_socks)`), which stores active sockets at `[0, num_socks)` and closed sockets at `[max_socks - num_closed_socks, max_socks)`. `reuseport_grow()` (only when `num_socks + num_closed_socks == max_socks`) must preserve this split layout and update `sk_reuseport_cb` for all entries; `reuseport_resurrect()` with `reuse == NULL` must allocate a fresh `sock_reuseport`. [F76, F77, F99, F137]

## Synchronization

- `unlock_sock_fast(sk, slow)` must receive the exact boolean from `lock_sock_fast(sk)`: when `slow` is false, `sk->sk_lock.slock` is held with BH disabled (`sk_lock.owned == 0`, sleeping forbidden); when `slow` is true, `slock` is dropped, BH is enabled, and `sk_lock.owned == 1`. [F20]
- All mutations to `sk->sk_backlog` must hold `sk->sk_lock.slock`. In `__sk_receive_skb()`, BH context must hold `bh_lock_sock()` and queue via `sk_add_backlog()` whenever `sock_owned_by_user(sk)` is true; `__sk_add_backlog()` and `__sock_queue_rcv_skb()` must call `skb_dst_force(skb)` before leaving RCU. `__release_sock()` must detach `sk_backlog.head`/`tail` and drop `spin_unlock_bh(&sk->sk_lock.slock)` before calling `sk_backlog_rcv()`, keeping `sk_backlog.len` non-zero until the drain loop finishes. [F29, F156, F161]
- `sk_setsockopt()` and helpers reachable from BPF must use `sockopt_lock_sock()`, `sockopt_release_sock()`, `sockopt_ns_capable()`, and `sockopt_capable()` because BPF callers (`has_current_bpf_ctx()`) already hold `sk_lock` and may run in BH. In `sk_setsockopt()`, `SO_PEEK_OFF` must be handled before `sockopt_lock_sock(sk)` (with `sk->sk_peek_off` accessed via `READ_ONCE()`/`WRITE_ONCE()`), and every case in the second switch (after `sockopt_lock_sock(sk)`) must set `ret` and `break` rather than returning directly. [F35, F115, F155]
- In `sock_init_data_uid()` and `sk_clone_lock()`, `smp_wmb()` must precede `refcount_set(&sk->sk_refcnt, ...)` for `SLAB_TYPESAFE_BY_RCU` readers. In `__reuseport_add_sock()`, storing `reuse->socks[reuse->num_socks]` must precede incrementing `reuse->num_socks` via `smp_wmb()`, paired with `READ_ONCE(reuse->num_socks)` and `smp_rmb()` in `reuseport_select_sock()` and `reuseport_migrate_sock()`. [F22, F24]
- All acquisitions of `reuseport_lock` must use `spin_lock_bh(&reuseport_lock)`, and allocations under it (`__reuseport_alloc()`, `ida_alloc()`) must use `GFP_ATOMIC`. Because `sk_destruct()` destroys sockets with `SOCK_RCU_FREE` or non-NULL `sk->sk_reuseport_cb` via `call_rcu(&sk->sk_rcu, __sk_destruct)`, `sk_setsockopt()` must restrict `SO_REUSEPORT` to `sk_is_inet(sk)` sockets so sleeping destructors never run in RCU callbacks. [F151, F157]
- Because `sk_free()` / `__sk_free()` can run in hardirq or BH context, `sock_diag_broadcast_destroy()` must allocate `struct broadcast_sk` with `GFP_ATOMIC` and defer `GFP_KERNEL` Netlink work and `sk_destruct(sk)` to `sock_diag_broadcast_destroy_work()`. Per-CPU `prot_inuse` updates in `sock_prot_inuse_add()` and `sock_inuse_add()` must use BH-safe `this_cpu_add()`. [F154, F159]
- Mutations to `sk->sk_wq`, `sk->sk_socket`, or `sk->sk_user_data` (`sock_orphan()`, `sock_graft()`) must hold `write_lock_bh(&sk->sk_callback_lock)`, whereas `sock_i_ino()` and `sk_uid()` must read `sk->sk_ino` and `sk->sk_uid` locklessly via `READ_ONCE()`. Socket wake-up callbacks (`sock_def_readable()`, `sock_def_write_space()`, `sock_def_wakeup()`, `sock_def_error_report()`) must dereference `sk->sk_wq` under `rcu_read_lock()` and check `skwq_has_sleeper(wq)` (or `smp_mb__after_atomic()` in `sock_def_write_space_wfree()`). [F37, F43, F158]
- Because `sk->sk_prot` can be replaced concurrently via `sock_replace_proto()`, unlocked callers (`sk_is_readable()`, `sock_common_getsockopt()`, `sock_common_setsockopt()`) must load `READ_ONCE(sk->sk_prot)` into a local variable. [F41]
- When replacing or clearing `sk->sk_dst_cache`, the pointer must be updated before calling `dst_release()`, and lockless readers in `sk_dst_get()` must use `rcuref_get(&dst->__rcuref)` under `rcu_read_lock()`. In `sk_setup_caps()` and `sk_dst_gso_max_size()`, `dst->dev` and device GSO fields must be read under `rcu_read_lock()` using `dst_dev_rcu(dst)` and `READ_ONCE()`. [F44, F163]
- In `__sock_release()`, when `inode` is non-NULL, `inode_lock(inode)` must be held across `ops->release(sock)` and clearing `sock->sk = NULL` to serialize with `sockfs_setattr()`. In `reqsk_fastopen_remove()`, `spin_lock_bh(&fastopenq->lock)` must protect `fastopenq->qlen`, `tfo_listener`, `req->sk`, and `rskq_rst_head`/`tail`, and the listener socket lock must never be acquired while holding the child socket lock. [F31, F34]

## Object Lifetimes

- `__sock_release()` calls `iput(SOCK_INODE(sock))` only when `sock->file == NULL` and otherwise sets `sock->file = NULL`, because once `sock_alloc_file()` binds a `struct file`, VFS owns the `sockfs` inode and drops it after `sock_close()`. [F2]
- `__sock_create()` pins `pf->owner` via `try_module_get()` before `pf->create()`, acquires `sock->ops->owner` before `module_put(pf->owner)`, and clears `sock->ops = NULL` if `try_module_get(sock->ops->owner)` fails so `__sock_release()` does not `module_put()` an unreferenced module. `sock_unregister()` must clear `net_families[family]` under `net_family_lock` and call `synchronize_rcu()`. [F4, F28]
- `__sk_destruct()` must pass `sk->sk_prot_creator` (not `sk->sk_prot`) to `sk_prot_free()`. `sock_lock_init_class_and_name()` records `THIS_MODULE` in `sk->sk_owner` via `sk_owner_set()`, which must remain held until `sk_prot_free()` calls `sk_owner_put(sk)`. [F5, F6]
- Sockets with `sk->sk_net_refcnt == 1` hold an active netns ref (`get_net_track()`) and `+1` `sock_inuse_add()`, while kernel sockets (`sk_net_refcnt == 0`) hold a passive ref (`net_passive_inc()` and `__netns_tracker_alloc(..., false, ...)`). `__sk_destruct()` and `sk_net_refcnt_upgrade()` must keep both balanced. [F7]
- `sk_alloc()` and `sk_clone_lock()` bias `sk->sk_wmem_alloc` by 1, and `sk_free()` only calls `__sk_free()` when `refcount_dec_and_test(&sk->sk_wmem_alloc)` hits 0. In `sock_wfree()`, when `!sock_flag(sk, SOCK_USE_WRITE_QUEUE)`, `sk->sk_write_space(sk)` must either run under `rcu_read_lock()` (when `SOCK_RCU_FREE` and `sock_def_write_space`) or retain 1 unit of `sk_wmem_alloc` until `sk_write_space(sk)` returns before subtracting the final 1 and calling `__sk_free(sk)`. [F8, F9]
- In `sk_common_release()`, `sk->sk_prot->unhash(sk)` must precede `sock_orphan(sk)` and `sock_put(sk)`. `sk_reset_timer()` calls `sock_hold(sk)` only when `mod_timer()` returns 0, and `sk_stop_timer()` / `sk_stop_timer_sync()` call `__sock_put(sk)` only when `timer_delete*()` returns non-zero (requiring the caller to hold another reference on `sk`). [F11, F25]
- When `reuseport_grow()` replaces `reuse` with `more_reuse`, it transfers `reuse->prog` and `reuse->reuseport_id` and must free the old struct with `kfree_rcu(reuse, rcu)` rather than `reuseport_free_rcu()`. In `reqsk_fastopen_remove()`, `req` is only released (`reqsk_put(req)` or queued onto `rskq_rst_head`) if `req->sk == NULL`. In `sock_diag_lock_handler()` and `sock_diag_rcv_msg()`, handlers must be dereferenced and pinned via `try_module_get(owner)` inside `rcu_read_lock()`. [F17, F19, F40]

## API Contracts

- `sock_alloc_file()` consumes `@sock` and calls `sock_release(sock)` on `alloc_file_pseudo()` failure, so callers (`sock_map_fd()`, `__sys_socketpair()`, `do_accept()`) must not call `sock_release(sock)` on `IS_ERR()` return. [F1]
- `__sk_receive_skb()` always consumes `@skb` and, when `@refcounted` is true, always drops one `@sk` reference via `sock_put(sk)` on every path. `sk_add_backlog()` rejects `skb_pfmemalloc(skb)` SKBs unless `SOCK_MEMALLOC` is set, and `sk_backlog_rcv()` must dispatch `pfmemalloc` SKBs via `__sk_backlog_rcv()` under `memalloc_noreclaim_save()`. [F12, F177]
- `reuseport_select_sock()` returns a borrowed `struct sock *` without incrementing `sk_refcnt`, whereas `reuseport_migrate_sock()` increments `nsk->sk_refcnt` via `refcount_inc_not_zero()` under `rcu_read_lock()` and transfers a `+1` reference (or returns `NULL`). [F18]
- `__sk_mem_schedule()`, `sk_mem_charge()`, `sk_mem_uncharge()`, and `__sk_mem_reclaim()` take byte counts (rounding up via `sk_mem_pages()` on schedule/reserve and rounding down to whole pages on reclaim/release), whereas `__sk_mem_raise_allocated()` and `__sk_mem_reduce_allocated()` take page counts (`PAGE_SIZE` quanta). `__sk_mem_schedule()` must roll back `sk_forward_alloc` if `__sk_mem_raise_allocated()` returns 0. [F13, F66, F132]
- `copy_from_sockptr*()` and `copy_to_sockptr*()` return 0 on success or positive uncopied bytes on fault (callers must convert non-zero to `-EFAULT`), and `copy_from_sockptr()` does not check `optlen` (use `copy_safe_from_sockptr()` or check `optlen` first). [F45, F100]
- `put_cmsg()` returns 0 and sets `MSG_CTRUNC` when `msg_control` is NULL or `msg_controllen` is too small; callers committing side effects like installing fds (`scm_pidfd_recv()`) must pre-check `msg_controllen` or use `put_cmsg_notrunc()`. `for_each_cmsghdr()` loops must check `CMSG_OK(msg, cmsg)` and `cmsg->cmsg_len` against `CMSG_LEN(...)` before reading `CMSG_DATA(cmsg)`. [F49, F95]
- `sock_enable_timestamp()` takes an unshifted `enum sock_flags` bit index, whereas `sock_disable_timestamp()` takes a shifted bitmask (`1UL << flag`). Callers of `sock_tx_timestamp()`, `_sock_tx_timestamp()`, and `__sock_tx_timestamp()` must initialize `*tx_flags` to 0 beforehand. `sk->sk_err` stores positive errnos while `sock_error(sk)` returns negative errnos. [F48, F64, F65]
- `sock_sendmsg()`, `kernel_bind()`, and `kernel_connect()` copy caller sockaddrs into a stack `struct sockaddr_storage` without bounds-checking `addrlen` (callers must ensure `0 <= addrlen <= sizeof(struct sockaddr_storage)`), and `sock_sendmsg()` must save and restore both `msg_name` and `msg_namelen`. Buffers from `sock_kmalloc()` / `sock_kmemdup()` must be freed via `sock_kfree_s()` / `sock_kzfree_s()` with the exact charged size. [F91, F110, F140]

## Error Handling

- `sk_clone_lock()` returns `newsk` with `bh_lock_sock(newsk)` held and `sk_refcnt == 2`; on failure at `free:`, it must clear `newsk->sk_filter = NULL` if `sk_filter_charge()` failed, clear `newsk->sk_destruct = NULL`, call `bh_unlock_sock(newsk)`, and call `sk_free(newsk)`. [F10]
- In `scm_fp_copy()`, any `struct file` from `fget_raw()` failing validation (`io_is_uring_fops(file)`) must be released immediately via `fput(file)` before incrementing `fpl->count`. `scm_replace_pid()` only assigns `scm->pid = pid` on success, so `__scm_send()` must call `put_pid(pid)` on error. After `pidfd_prepare()`, any copy failure in `scm_pidfd_recv()` or `SO_PEERPIDFD` must call both `put_unused_fd(pidfd)` and `fput(pidfd_file)`. [F14, F15, F16]
- In `reuseport_migrate_sock()`, `bpf_run_sk_reuseport()` can return an `ERR_PTR`, so after the `select_by_hash` fallback `nsk` must be checked with `IS_ERR_OR_NULL(nsk)` and reset to `NULL` before `refcount_inc_not_zero(&nsk->sk_refcnt)`. [F59]

## Known Pitfalls

- In `__sock_cmsg_send()`, 64-bit payloads like `SCM_TXTIME` must be read from `CMSG_DATA(cmsg)` via `get_unaligned()` because `CMSG_ALIGN()` only guarantees 4-byte alignment on 32-bit architectures. In `sk_setsockopt()`, options accepting `optlen < sizeof(int)` (like `SO_BINDTODEVICE`) must be handled before the `if (optlen < sizeof(int)) return -EINVAL` prologue. [F96, F114]
- In `sock_devmem_dontneed()`, netmem entries batched in `netmems[]` under `xa_lock_bh(&sk->sk_user_frags)` must be released via `napi_pp_put_page()` after dropping the lock both when the batch fills (resetting `netmem_num = 0`) and after exiting the loop on any path (including `goto frag_limit_reached`). [F123]
- Prevent integer overflows in socket limits: check seconds against `MAX_SCHEDULE_TIMEOUT / HZ` before multiplying by `HZ` in `sock_set_timeout()`, `sock_set_sndtimeo()`, and `SO_LINGER`; store `alloc` as `u64` before multiplying by `sk_mem_pages()` in `__sk_mem_raise_allocated()`; widen `reuse->max_socks` to `u32` and check `<= U16_MAX` in `reuseport_grow()`; and cast `size` to `unsigned int` when comparing against `optmem_max` in `sock_kmalloc()`. [F130, F133, F134, F135]
