# RXRPC SOCKETS (AF_RXRPC)

`net/rxrpc` implements AF_RXRPC sockets over UDP/IPv4 and UDP/IPv6, providing userspace and in-kernel RPC call framing, transmission and reception queues, peer and connection management, RTT/RTO estimation, path MTU discovery, procfs/sysctl interfaces, security classes (RxKAD and YFS RxGK), and the `rxperf` in-kernel test server.

## Architecture & Data Flow
- In `rxrpc_prepare_data_packet()` and `rxrpc_prepare_data_subpacket()`, clear `RXRPC_REQUEST_ACK` from `txb->flags` and mask with `RXRPC_TXBUF_WIRE_FLAGS`. Only the terminal subpacket (`subpkt == req->n - 1`) may set `RXRPC_REQUEST_ACK` (never when `last && rxrpc_sending_to_client(txb)`) or its `tq->rtt_samples` bit, while earlier subpackets set `RXRPC_JUMBO_PACKET`. Test `RXRPC_CALL_BEGAN_RX_TIMER` for `start_tlp` before `test_and_set_bit()` arms `call->expect_rx_by`. [F68, F70, F96]
- In `rxrpc_prepare_data_packet()`, clearing `ix` in `tq->segment_lost` must decrement `call->tx_nr_lost`, and each subpacket must either set `ix` in `tq->segment_retransmitted` (and `tq->ever_retransmitted`) while incrementing `call->tx_nr_resent` (`req->retrans`), or increment `call->tx_nr_sent` (`!req->retrans`). [F67]
- In `rxrpc_send_data_packet()`, when `seq == call->tx_transmitted + 1`, run the Don't Fragment check against `call->peer->max_data` before advancing `call->tx_transmitted = seq + req->n - 1`. In `rxrpc_queue_packet()`, when `RXRPC_LAST_PACKET` is set, set `RXRPC_CALL_TX_NO_MORE`, call `rxrpc_notify_end_tx()`, and clear `call->send_queue = NULL` right after advancing `call->send_top`. [F61, F69]
- `rxrpc_alloc_txqueue()` must set `tq->xmit_ts_base = KTIME_MIN`, all `tq->segment_xmit_ts[i] = UINT_MAX`, and on a call's first queue set `tq->nr_reported_acks = 1` and `tq->segment_acked = 1UL` (seq 0 hard-acked). `RXRPC_NR_TXQUEUE` equals `BITS_PER_LONG` so per-segment bitmasks in `struct rxrpc_txqueue` fit in single `unsigned long` words. [F60, F127]
- In `rxrpc_recvmsg_data()`, call `rxrpc_verify_data(call, skb)` only when `rx_pkt_offset == 0` and before reading `sp->offset` and `sp->len`; under `MSG_PEEK`, neither call `rxrpc_rotate_rx_window(call)` nor write back `call->rx_pkt_offset` and `call->rx_pkt_len`. [F73]
- Pass `retrans = true` to `rxrpc_get_rto_backoff()` only on actual retransmission (incrementing `call->backoff` only if `timo_us * 2 <= RXRPC_RTO_MAX`), clamp `call->rto_us` via `rxrpc_bound_rto()` to `[200000, RXRPC_RTO_MAX]`, and reset `call->backoff = 0` in `rxrpc_ack_update_rtt()` only on a non-negative RTT sample. `rxrpc_call_add_rtt()` must write `call->srtt_us / 8` to `peer->recent_srtt_us` alongside `call->rto_us` to `recent_rto_us`. [F65, F66, F111]
- When `rxrpc_adjust_mtu()` reduces `peer->max_data`, clamp `peer->pmtud_good <= max_data` and `peer->pmtud_bad <= max_data + 1`. When `rxrpc_input_probe_for_pmtud()` finishes a probe, update `peer->pmtud_jumbo`, clear `conn->pmtud_probe = 0`, and reset `peer->pmtud_lost = false`. [F71]
- `rxrpc_get_next_serial()` and `rxrpc_get_next_serials()` must check for 0 or 32-bit wrap across `n` serials (`serial + n <= n`) and reset `serial` to 1. In `rxgk_get_key()` and `rxgk_rekey()`, compare 16-bit `*specific_key_number` against `(u16)(current_key +/- 1)` while reconstructing the 32-bit `key_number` and rejecting rekey at `UINT_MAX`. [F118, F121]
- `rxrpc_init_client_call_security()` must set both `call->security` and `call->security_ix` on all success paths (defaulting to `rxrpc_no_security`). Connection-wide security failures in `rxrpc_get_incoming_security()` must use `rxrpc_direct_conn_abort()` (`RXRPC_SKB_MARK_REJECT_CONN_ABORT`), and `rxrpc_reject_packet()` must set `whdr.callNumber = 0` for it. [F63, F64]
- Bounds-check untrusted packet/token lengths before subtraction: `len >= sizeof(struct rxgk_header)` and `ntohl(hdr.data_len) <= len` in `rxgk_verify_packet_encrypted()`; `sp->len >= 8` and `data_size <= sp->len` in `rxkad_verify_packet_1/2()`; `ticket_len >= 10 * sizeof(__be32)` in `rxgk_yfs_decode_ticket()`; and `token_len >= sizeof(container)` in `rxgk_extract_token()`. When advancing `__be32 *` pointers past variable XDR fields, divide `xdr_round_up(len)` by 4. [F79, F87, F88, F117, F125]
- `rxrpc_send_response()` must check `nr_sg <= ARRAY_SIZE(conn->local->bvec)` after `skb_to_sgvec()`, and `rxkad_verify_packet_2()` must size its scatterlist to at least `skb_shinfo(skb)->nr_frags + 1` (linear head plus frags). [F80, F122, F133]

## Synchronization
- `rxrpc_new_client_call_for_sendmsg()` and `rxrpc_do_sendmsg()` must always call `release_sock(&rx->sk)`, and when `rxrpc_new_client_call_for_sendmsg()` returns a call, `call->user_mutex` is locked and a call ref is held for the caller to unlock and put. `call->user_mutex` is taken under `lock_sock(&rx->sk)`, and `release_sock(&rx->sk)` must precede `rxrpc_send_data()` or `rxrpc_recvmsg_data()`. [F1, F144]
- Check `test_bit(RXRPC_CALL_RELEASED, &call->flags)` in `rxrpc_notify_socket()` before taking `rx->recvmsg_lock` and queuing onto `rx->recvmsg_q`, and in `rxrpc_recvmsg()` both under `rx->recvmsg_lock` and again after acquiring `call->user_mutex` and dropping `rx->sk` lock. [F21, F22]
- In `rxrpc_send_data()`, after `wait_for_space` drops and re-acquires `call->user_mutex`, jump to `reload:` to detach any new `call->tx_pending` into `txb`, re-validate `sk->sk_shutdown`, `rxrpc_call_state(call)`, and `call->tx_total_len`, and save any unqueued `txb` to `call->tx_pending` on exit. [F72]
- Process-context readers of `call->error` or `call->completion` must first observe `RXRPC_CALL_COMPLETE` via `rxrpc_call_is_complete(call)` (`smp_load_acquire(&call->_state)`), pairing with `smp_store_release(&call->_state, state)` in `rxrpc_set_call_state()`. [F24]
- Order stores published to the I/O thread: `smp_store_release(&call->send_top, seq)` in `rxrpc_queue_packet()` after setting `sq->bufs[ix] = txb` and `send_queue->next`; `smp_store_release(&call->send_abort, abort_code)` in `rxrpc_propose_abort()` after writing `send_abort_why/err/seq`; and `smp_wmb()` in `rxrpc_begin_rtt_probe()` after writing `rtt_serial/sent_at` before setting the pending bit in `call->rtt_avail`. [F25, F26, F29]
- When hard IRQs are enabled, `rxnet->peer_hash_lock` must use `spin_lock_bh()`/`spin_unlock_bh()` (`rxrpc_put_peer()` runs in RCU softirq), whereas `rxrpc_new_incoming_peer()` runs with hard IRQs disabled and must use plain `spin_lock()`. `rxrpc_assess_MTU_size()` must only run with hard IRQs enabled (route lookups call `local_bh_enable()`). [F134, F135, F136]
- In `rxrpc_lookup_peer()`, fully initialize `candidate` before taking `spin_lock_bh(&rxnet->peer_hash_lock)` and re-run `__rxrpc_lookup_peer_rcu()` + `rxrpc_get_peer_maybe()` under the lock before `hash_add_rcu()`. In `rxrpc_peer_keepalive_dispatch()`, pin `peer` and `peer->local` (`__rxrpc_use_local()`) before dropping `peer_hash_lock`, and never call `rxrpc_send_keepalive()`, `rxrpc_unuse_local()`, or `rxrpc_put_peer()` under `peer_hash_lock`. [F30, F32, F137]
- `rx->recvmsg_lock`, `call->notify_lock`, `peer->lock`, and `conn->state_lock` must use `spin_lock_irq()`/`spin_unlock_irq()` when IRQs are enabled. `call->notify_rx` runs under `rcu_read_lock()` and `spin_lock_irq(&call->notify_lock)`, so callbacks like `rxperf_notify_rx()` must defer blocking work to a workqueue. [F142, F143]
- In `rxrpc_init_client_conn_security()`, run `init_connection_security()` under `conn->security_lock`, and recheck `conn->state == RXRPC_CONN_CLIENT_UNSECURED` under nested `spin_lock_irq(&conn->state_lock)` when setting `RXRPC_CONN_CLIENT`. In `rxrpc_look_up_server_security()`, hold `read_lock(&conn->local->services_lock)` while reading `conn->local->service` and `rx->securities`. [F34, F35]
- `rxgk_get_key()` holds `read_lock(&conn->security_use_lock)` while incrementing `gk->usage`. After dropping it, `rxgk_rekey()` must hold `conn->security_lock` across `rxgk_generate_transport_key()`, re-read `key_number` and re-check `keys[key_number & mask]`, and nest `write_lock(&conn->security_use_lock)` when updating `key_number` and `keys[]`. [F36, F77]
- `rxkad_decrypt_response()` must hold `rxkad_ci_mutex` while using `rxkad_ci` and `rxkad_ci_req`, whereas `rxkad_secure_packet()` and `rxkad_verify_packet()` must copy `call->conn->rxkad.csum_iv` into a local `struct rxrpc_crypt iv`. [F74]
- Use `sk->sk_allocation` in `rxrpc_send_data()` and `rxrpc_alloc_txqueue()`, and `GFP_NOFS`/`GFP_NOIO` (never `GFP_KERNEL`) in packet security/verification callbacks. `proc.c` `.show` callbacks run under `rcu_read_lock()` or `read_lock(&rxnet->conn_lock)` and must never sleep or dereference `local`/`peer` on preallocated calls/conns (`RXRPC_CONN_SERVICE_PREALLOC`). [F57, F139, F150]

## Object Lifetimes
- In `rxrpc_send_data()`, load `txb` from `call->tx_pending` (and clear `call->tx_pending`) at `reload:` before any jump to `maybe_error:` or `out:`. Every path after detaching or allocating `txb` must either queue it via `rxrpc_queue_packet()` (`txb = NULL`), free it via `rxrpc_put_txbuf()` at `call_terminated:`, or save it back to `call->tx_pending` at `out:`. [F3, F44]
- Release every `struct rxgk_context *` from `rxgk_get_key()` with `rxgk_put()` across all error paths, helper callees, and `RXRPC_SECURITY_PLAIN`/`default` switch arms. In `rxgk_rekey()`, detach `conn->rxgk.keys[(current_key - 2) & mask]` into `dead` under `write_lock(&conn->security_use_lock)` and call `rxgk_put(dead)` only after dropping both locks. [F4, F5]
- In `rxgk_set_up_ciphers()`, check `IS_ERR()` in a local variable before storing transforms into `gk`, and clean up partial allocations in `rxgk_generate_transport_key()` via `rxgk_put(gk)` (never `kfree(gk)`). In `rxgk_extract_token()`, bracket reading `server_key->payload.data[2]` and `rxgk_set_up_token_cipher()` with `down_read`/`up_read(&server_key->sem)` + `key_put(server_key)`, and free `token_enc` right after `rxgk_decrypt_skb()`. [F17, F18, F39, F46]
- Clear transferred pointers before shared cleanup labels: set `response = NULL` right after `rxrpc_post_response(conn, response)` in `rxgk_construct_response()` and `rxkad_respond_to_challenge()`, and set `conn->key = key; key = NULL;` before `out:` in `rxgk_verify_response()`. [F6, F11]
- Cache tracepoint fields (`debug_id`, `call_debug_id`, `seq`) in locals before dropping a ref on `rxrpc_call`, `rxrpc_peer`, or `rxrpc_txbuf` (and before unlocking `call->user_mutex` + `rxrpc_put_call()` in `rxrpc_recvmsg()`). At `error_requeue_call:` in `rxrpc_recvmsg()`, re-queue non-peeked calls onto `rx->recvmsg_q` and call `rxrpc_put_call()` on `MSG_PEEK` calls. [F8, F9]
- `rxrpc_send_ACK()` must always call `rxrpc_free_ack(call)` after `rxrpc_alloc_ack()` without overwriting `call->local->kvec[0..1].iov_base`, and `rxrpc_send_data_packet()` transfers `whdr` ownership to `rxrpc_prepare_data_packet()` (`page_frag_free(whdr)`). [F14, F15]
- In `rxperf_deliver_to_call()`, `call_complete:` must call `rxrpc_kernel_shutdown_call()`, `rxrpc_kernel_put_call()`, and `cancel_work(&call->work)` before `kfree(call)`. In `rxperf_close_socket()` and `rxperf_exit()`, stop the socket (`kernel_listen(..., 0)`, `kernel_sock_shutdown()`) before `flush_workqueue()` and `sock_release()`, and call `rcu_barrier()` after `destroy_workqueue()`. [F20, F40]

## API Contracts
- `rxrpc_alloc_data_txbuf()` and all `security->alloc_txbuf` callbacks return `NULL` on failure (never `ERR_PTR`), and `rxrpc_alloc_data_txbuf()` requires a non-zero power-of-two `data_align`. Conversely, `rxgk_get_key()`, `rxgk_rekey()`, and `rxrpc_look_up_server_security()` always return an `ERR_PTR` on failure and never `NULL`. [F41, F42, F47, F48]
- `rxrpc_recvmsg_data()` (`msg` may be NULL) and `rxrpc_kernel_recv_data()` (`_service` may be NULL) return `0` when more data remains, `1` when the final DATA packet is consumed, `-EAGAIN`, or negative errnos. `rxrpc_kernel_recv_data()` must return `-EBADMSG` if `ret == 1 && iov_iter_count(iter) > 0`, `-EMSGSIZE` if `!want_more && ret == 0`, or `0` (not `1`) if `want_more && ret == 1`. Callers must zero-initialize `*_abort = 0` before `rxrpc_kernel_recv_data()`, and pass `msg_name == NULL && msg_control == NULL` to `rxrpc_kernel_send_data()`. [F49, F51, F104, F162, F163]
- `rxrpc_kernel_get_call_peer()` returns a new ref via `rxrpc_get_peer()` that the caller must put, whereas `rxrpc_kernel_remote_srx()` and `rxrpc_kernel_remote_addr()` return borrowed pointers into `peer->srx` (or `rxrpc_null_addr` if `peer` is NULL). [F12, F58]
- In `struct rxrpc_security`, `challenge_to_recvmsg` and `*_server_key` callbacks are optional and must be NULL-checked. For `key_type_rxrpc_s` server keys, `payload.data[1]` is reserved for `const struct rxrpc_security *`, with cipher/enctype in `data[0]` and inline key material at `&data[2]`. [F56, F126, F158]

## Error Handling
- Callers of `rxgk_decrypt_skb()` and `rxgk_verify_mic_skb()` that pass `*_error_code` to `rxrpc_abort_eproto()` or `rxrpc_abort_conn()` must zero-initialize it before the call and abort on any negative return other than `-ENOMEM`. [F43]
- `call->error` and `conn->error` store negative errnos (negated to positive for `RXRPC_NET_ERROR`/`RXRPC_LOCAL_ERROR` cmsgs). `rxrpc_recvmsg()` on a non-listening socket with no calls or queued items must return `-EAGAIN`, `rxrpc_send_data()` must test `sk->sk_shutdown & SEND_SHUTDOWN` for `-EPIPE` (not `sk->sk_err`), and `rxrpc_do_sendmsg()` must allow `RXRPC_CMD_SEND_ABORT` in `CLIENT_AWAIT_CONN` and `SERVER_RECV_REQUEST` states. [F55, F106, F152, F153]

## External Contracts
- `rxrpc_reject_packet()` must return immediately if `sp->hdr.type == RXRPC_PACKET_TYPE_ABORT`; `rxrpc_fill_out_ack()` must set `ack->bufferSpace = htons(0)` and split the `ackr_sack_table` `memcpy` when `sack + ack->nAcks > RXRPC_SACK_SIZE`; and `rxrpc_input_error()` must call `rxrpc_adjust_mtu()` and skip `rxrpc_store_error()` on both IPv4 `ICMP_FRAG_NEEDED` and IPv6 `ICMPV6_PKT_TOOBIG`. [F82, F85, F98, F100]
- `RXRPC_USER_CALL_ID` cmsgs use `sizeof(u32)` under `MSG_CMSG_COMPAT` and `sizeof(unsigned long)` otherwise; `RXRPC_SET_CALL_TIMEOUT` must check `!(len & 3) && len >= 4 && len <= 12` (`hard` in seconds `<= INT_MAX / HZ`, `idle`/`normal` in ms `<= 60 * 60 * 1000`); and `do_udp_sendmsg()` must check `socket->sk->sk_family == AF_INET6` before `udpv6_sendmsg()`. [F91, F92, F151, F160]

## Known Pitfalls
- `rxrpc_alloc_data_txbuf()` reserves space before `txb->data` only for `struct rxrpc_jumbo_header`, while `rxrpc_send_data_packet()` allocates a separate `rxrpc_wire_header` in `kvec[0]` per send so retransmissions do not mutate in-flight `MSG_SPLICE_PAGES` headers. Security `alloc_txbuf` callbacks must adjust `txb->offset` (never `txb->data`), `rxkad_secure_packet_*()` zero-padding at `txb->data + txb->offset` requires `txb->offset == shdr + txb->len`, and security encoders must zero any unused gap up to `txb->alloc_size` (and XDR padding in `rxgk_pad_out()`). [F62, F123, F124, F161]
- Save and zero `response->encrypted.checksum = 0` before calling `rxkad_calc_response_checksum(response)` in `rxkad_verify_response()`. Check `if (i >= req->n) break;` before `!(seq & RXRPC_TXQ_MASK)` advances `tq = tq->next` in `rxrpc_prepare_data_packet()`. Evaluate `skb = skb_peek_next(skb, &call->recvmsg_queue)` before `rxrpc_rotate_rx_window(call)` in `rxrpc_recvmsg_data()`. Call `rxrpc_local_dont_fragment(conn->local, false)` before sending in `rxrpc_send_response()`. [F76, F97, F99, F102]
- SKBs in `net/rxrpc/peer_event.c` come from `sk->sk_error_queue` and store `struct sock_exterr_skb` in `skb->cb` (`SKB_EXT_ERR(skb)`), never `rxrpc_skb(skb)`. [F128]
- Compare wrapping `rxrpc_seq_t`/`rxrpc_serial_t` via `before()`, `before_eq()`, `after()`, `after_eq()`, or `call->send_top - tx_bottom < 256`, and compare `u8 cursor` vs `stop` via `(s8)(cursor - stop) < 0` in `rxrpc_peer_keepalive_worker()`. [F119, F120]
- Avoid integer UB: widen `call->rto_us` to `u64` in `rxrpc_get_rto_backoff()`; in `rxgk_generate_transport_key()`, only shift `1LL << key->bytelife` for `1 ... 62` and clamp `key->lifetime` with `min_t(u64, ..., INT_MAX / HZ)` before `* HZ`; cast `(u32)check << 16` in `rxkad_secure_packet_*()`; and use `do_div(conn->rxgk.start_time, 100)` in `rxgk_init_connection_security()`. [F110, F112, F113, F114, F115]
