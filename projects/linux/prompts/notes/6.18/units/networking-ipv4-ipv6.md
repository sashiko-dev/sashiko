# NETWORKING [IPv4/IPv6]

This unit implements the core TCP receive, transmit, timer, minisock, metrics, authentication (MD5/TCP-AO), ULP, and congestion control engines, UDP/TCP GSO/GRO and tunnel NIC offloads, and the IPv6 protocol suite including address autoconfiguration, Neighbour Discovery, FIB radix routing, multicast/MLD/PIMv6, extension headers (SRv6, RPL, IOAM, MIPv6), ILA, and IPv6 tunneling.

## Architecture & Data Flow

- On established sockets, advancing `tp->snd_una` or `tp->rcv_nxt` must use `tcp_snd_una_update()` or `tcp_rcv_nxt_update()` (and `twsk_rcv_nxt_update()` in `TCP_FIN_WAIT2` timewait) so `tp->bytes_acked`/`tp->bytes_received` and TCP-AO SNE counters (`ao->snd_sne`/`ao->rcv_sne`) update on 32-bit wraparound; SNE wraparound must be detected using direct `<` rather than `before()`. [F79, F125]
- When `tcp_fragment()` or `__tcp_retransmit_skb()` recomputes `tcp_set_skb_tso_segs()` (which must use `DIV_ROUND_UP(skb->len, mss_now)`) on an already-sent segment, `tcp_adjust_pcount()` must be called with old minus new pcount; splitting in `tcp_fragment()`/`tso_fragment()` must also clear `TCPHDR_FIN`, `TCPHDR_PSH`, and `eor` on the first segment and transfer them only to `buff`. [F246, F247, F299]
- Both `fib6_select_path()` and `rt6_multipath_rebalance()` must resolve the first ECMP sibling from `fn->leaf` (`rt6_multipath_first_sibling_rcu()`/`rt6_multipath_first_sibling()`); `rt6_multipath_hash()` must right-shift by 1 (`>> 1`) into `[0, 2^31 - 1]`, `fib6_select_path()` must compare `fl6->mp_hash` as a signed `int` against `fib_nh_upper_bound` and stop at the first nexthop with `hash <= nh_upper_bound`, and `fib6_ifup()`/`fib6_ifdown()` must rebalance inline-nexthop multipath routes on flag changes. [F945, F979, F980, F989, F990]
- In `struct fib6_info`, `fib6_nh[]` is only allocated when `with_fib6_nh` is true (`f6i->nh == NULL`, including `fib6_null_entry` in `ip6_route_net_init()`) and `fib6_siblings` unions with `nh_list`, so code must check `f6i->nh` before touching `f6i->fib6_nh` or `f6i->fib6_siblings`. [F594, F998]

## Synchronization

- Even with the socket lock held, TCP receive paths (`tcp_data_queue_ofo()`, `tcp_queue_rcv()`, `tcp_collapse()`, `tcp_try_coalesce()`) must update `sk->sk_rmem_alloc` atomically via `skb_set_owner_r()` or `atomic_add()` because `sock_queue_err_skb()` modifies `sk->sk_rmem_alloc` without the socket lock. [F17]
- Under `bh_lock_sock(sk)`, when `sock_owned_by_user(sk)` is true: `tcp_v4_err()`, `tcp_v6_err()`, and `tcp_ld_RTO_revert()` must not mutate retransmit queues, routes, or socket state (`dst->ops->redirect`, `tcp_done_with_error`, `sk_error_report`), and `tcp_v4_err()`/`tcp_v6_err()` (`ICMP_FRAG_NEEDED`/`ICMPV6_PKT_TOOBIG`), `tcp_write_timer()`, `tcp_delack_timer()`, `tcp_compressed_ack_kick()`, and `tcp_tsq_handler()` must defer work by setting the matching `*_DEFERRED` bit in `sk->sk_tsq_flags` via `test_and_set_bit()` and calling `sock_hold(sk)` if newly set. [F27, F214, F1055, F1073]
- `tcp_add_backlog()` must be called with `bh_lock_sock(sk)` held; returning `false` leaves the lock held and `skb` owned/freed by the backlog, whereas returning `true` has already called `bh_unlock_sock(sk)` and leaves `skb` for the caller to drop. `tcp_child_process()` requires `bh_lock_sock(child)` and a `child` ref on entry, queues to `__sk_add_backlog()` if `sock_owned_by_user(child)`, and unconditionally unlocks and puts `child`. [F7, F33]
- Memory barriers on TCP state transitions: `WRITE_ONCE(tp->copied_seq, tp->rcv_nxt)` and `smp_mb()` must precede transitioning `sk->sk_state` to `TCP_ESTABLISHED` in `tcp_rcv_synsent_state_process()` and `tcp_rcv_state_process()`; `WRITE_ONCE(sk->sk_err, err)` and `smp_wmb()` must precede `tcp_done(sk)` in `tcp_done_with_error()`; `smp_mb()` must precede testing `SOCK_NOSPACE` in `tcp_check_space()`; and `set_bit(TSQ_THROTTLED, &sk->sk_tsq_flags)` in `tcp_small_queue_check()`/`skb_still_in_host_queue()` must be followed by `smp_mb__after_atomic()` and re-testing the condition. [F20, F21, F22, F215]
- All IPv6 FIB radix tree mutations and walks (`fib6_add()`, `fib6_del()`, `fib6_walk()`, `fib6_walk_continue()`, `rt6_select()` updating `fn->rr_ptr`, and route expiry/GC list updates in `cleanup_prefix_route()`, `addrconf_prefix_rcv()`, `modify_prefix_route()`, `ndisc_router_discovery()`, and `rt6_route_rcv()`) must hold `spin_lock_bh(&table->tb6_lock)` and use `GFP_ATOMIC`, pairing `fib6_set_expires()`/`fib6_clean_expires()` with `fib6_add_gc_list()`/`fib6_remove_gc_list()`. Lock hierarchy: `fib6_gc_lock` -> `table->tb6_lock` -> `fib6_walker_lock` / `rt->nh->lock`, and `table->tb6_lock` nests outside `rt6_exception_lock`. [F443, F574, F575, F689, F690, F761, F911, F915, F946]
- `ip6_output()`, `ip6_xmit()`, `ip6_fragment()`'s fraglist fastpath, `ipv6_sock_ac_join()`, `ip6_mc_find_dev()`, `ndisc_send_skb()`, `__ip6_rt_update_pmtu()`, `ip6_default_advmss()`, and `rt6_do_redirect()` must hold `rcu_read_lock()` and read the route's device/netns via `dst_dev_rcu()` or `dst_dev_net_rcu()` rather than `dst_dev()`. [F528, F682, F685, F853, F1011]
- In `net/ipv6/route.c`, `ip6_pol_route()` must call `rt6_get_pcpu_route()` and `rt6_make_pcpu_route()` under both `rcu_read_lock()` and `local_bh_disable()`; clearing `nh->rt6i_pcpu` slots in `rt6_get_pcpu_route()` and `fib6_nh_release_dsts()` must use `xchg(..., NULL)` before `dst_dev_put()` and `dst_release()`; and after `rt6_make_pcpu_route()` publishes `pcpu_rt` via `cmpxchg`, it must check `res->f6i->fib6_destroying` (set with a barrier in `fib6_drop_pcpu_from()`) and if set, `xchg(&pcpu_rt->from, NULL)` and `fib6_info_release()`. [F560, F912, F1013, F1014]
- In `ioam6_output()`, `ila_output()`, `seg6_input_core()`, `seg6_output_core()`, `rpl_input()`, and `rpl_output()`, all `dst_cache_get()`/`dst_cache_set_ip6()` calls must be bracketed by `local_bh_disable()`/`local_bh_enable()`, `skb_dst_drop(skb)` must precede `skb_dst_set()`, `orig_dst->lwtstate` must be saved before `ip6_route_input(skb)`, and `dst` must not be cached directly when `orig_dst->lwtstate == dst->lwtstate` (using `&ilwt->null_dst` in `ioam6_output()` or skipping). [F553, F554, F584, F902, F918, F1038]

## Object Lifetimes

- Socket references obtained from `__inet_lookup_established()`, `__inet6_lookup_established()`, `__inet_lookup_skb()`, or the TCP ehash table may be `TCP_TIME_WAIT` or `TCP_NEW_SYN_RECV` minisocks: callers must check `sk->sk_state` or `sk_fullsock(sk)` before downcasting (`tcp_sk`, `inet_sk`, `tcp_inet6_sk`), locking (`lock_sock`, `bh_lock_sock`), or reading full-socket fields (`sk_mark`, `sk_uid`), and must release references via `sock_gen_put(sk)` (or state-specific `inet_twsk_put`/`reqsk_put`/`sock_put` as in `tcp_v6_err()`). [F1, F50, F136, F173, F1054, F1065, F1133]
- Before `tcp_rtx_queue_unlink_and_free()` removes and frees an SKB from `sk->tcp_rtx_queue` (in `tcp_shifted_skb()`, `tcp_clean_rtx_queue()`, or `tcp_collapse_retrans()`), callers must update `tp->retransmit_skb_hint` and `tp->highest_sack` (`tcp_advance_highest_sack()` or `tcp_highest_sack_replace()`) if either references that SKB. If an unqueued SKB from `tcp_stream_alloc_skb()` is freed early, `tcp_skb_tsorted_anchor_cleanup()` must be called before `kfree_skb()`/`consume_skb()`. [F66, F249, F250]
- Because `tcp_create_openreq_child()` clones `newsk` from the listener with BH socket lock held and `sk_refcnt == 2`, it must zero/reinitialize listener-owned pointers (`md5sig_info`, `ao_info`, `fastopen_req`, `fastopen_rsk`, `tsq_node`, `tsorted_sent_queue`, `sk_user_frags`), `tcp_v6_syn_recv_sock()` must repoint `inet_sk(newsk)->pinet6` and null `newnp` pointer fields (`ipv6_mc_list`, `ipv6_ac_list`, `ipv6_fl_list`, `pktoptions`, `opt`), and any pre-hash abort path must call `inet_csk_prepare_forced_close(newsk)` before `tcp_done(newsk)`. [F4, F73, F1094]
- Socket option/filter objects allocated via `sock_kmalloc()`/`sock_kmemdup()` (`struct tcp_md5sig_key` in `tcp_md5_do_del()`/`tcp_clear_md5_list()`, sticky `ipv6_txoptions` `np->opt` in `inet6_cleanup_sock()`/`ipv6_update_options()`, `ipv6_mc_socklist`, and `ip6_sf_socklist` sized via `struct_size(psl, sl_addr, psl->sl_max)`) are freed via `kfree_rcu()`/`kfree()`/`txopt_put()` rather than `sock_kfree_s()`, so every removal path must manually subtract their exact allocated size from `sk->sk_omem_alloc`. [F130, F389, F725, F727, F844]
- In `net/ipv6/addrconf.c`, `ipv6_del_addr()` and `addrconf_dad_stop()` always consume one `ifp` reference via `in6_ifa_put(ifp)`, while `inet6_ifa_finish_destroy()` only frees `ifp` if `ifp->state == INET6_IFADDR_STATE_DEAD` (set under `spin_lock_bh(&ifp->lock)` in `ipv6_del_addr()`); similarly, `idev->dead = 1` must be set before `in6_dev_finish_destroy()` (without calling `netdev_put(dev)` in `addrconf_ifdown()`), and `ifp->dad_work` / `idev->rs_timer` must only be scheduled or cancelled via `addrconf_mod/del_dad_work()` and `addrconf_mod/del_rs_timer()`. [F377, F380, F381, F382, F405, F411]
- `ip6_del_rt()` consumes one reference to its `fib6_info *` argument, so callers holding a single ref (`addrconf_get_prefix_route()` callers, `ndisc_router_discovery()`, and paths deleting `ifp->rt`) must set `rt = NULL` / `ifp->rt = NULL` after `ip6_del_rt()` to prevent a double `fib6_info_release()`, whereas `__ip6_ins_rt()` does not consume the caller's ref on `rt` and callers (`ip6_route_add()`, `ip6_route_multipath_add()`) must always call `fib6_info_release(rt)` afterward. [F384, F385, F743, F892]

## API Contracts

- `tcp_timewait_state_process()` consumes the caller's reference on `tw` when returning `TCP_TW_SUCCESS`, but leaves the reference held for the caller to release on `TCP_TW_ACK`, `TCP_TW_ACK_OOW`, `TCP_TW_RST`, or `TCP_TW_SYN` (and in `tcp_v6_rcv()`, when `TCP_TW_SYN` replaces `sk` with `sk2` from `inet6_lookup_listener()`, it must call `inet_twsk_deschedule_put(tw)` and set `refcounted = false`). [F5, F1117]
- Every successful `tcp_sigpool_start(id, &hp)` call (in `tcp_v4_md5_hash_hdr/skb`, `tcp_v6_md5_hash_hdr/skb`, `tcp_v6_ao_calc_key`) must be paired with `tcp_sigpool_end(&hp)` on all exit paths, whereas a failed `tcp_sigpool_start()` must not call `tcp_sigpool_end(&hp)`; `tcp_v4/v6_md5_hash_hdr/skb()` and `tcp_sigpool_hash_skb_data()` return `0` on success and `1` on failure (zeroing the 16-byte `md5_hash` buffer on every MD5 error path), and `tcp_sigpool_alloc_ahash()` returns `< 0` on error. [F48, F148, F186, F227, F228, F907, F1056, F1080]
- `tcp_make_synack()` (for `dst`), `ip6_blackhole_route()` (for `dst_orig`), `ndisc_send_skb()` (for `skb` and its attached `dst`), `ip6mr_cache_unresolved()` (for `skb`), `__ip6_tnl_rcv()` (for `skb` and `tun_dst`), `addrconf_dad_failure()` (for `ifp`), and `ip6_parse_tlv()` plus its TLV callbacks (for `skb` when returning `false`) unconditionally consume their argument; callers must never free or release it afterward. [F222, F393, F739, F741, F742, F765, F899]
- In `tcp_gro_receive()` and `udp_gro_receive_segment()`, when `is_flist` is set, `skb_set_network_header(skb, skb_gro_receive_network_offset(skb))` must precede `skb_gro_receive_list(p, skb)`. For `SKB_GSO_FRAGLIST` packets in `tcp4_gso_segment()`, `tcp6_gso_segment()`, and `__udp_gso_segment()`, the `*gso_segment_list()` fastpath may only be used when the head SKB payload length equals `skb_shinfo(skb)->gso_size` (otherwise resetting `CHECKSUM_PARTIAL` and falling back to standard segmentation, linearizing first in UDP), and `__udp_gso_segment_list()`/`__tcpv6_gso_segment_list_csum()` must propagate head NAT header/checksum changes to all list segments. [F160, F164, F361, F362, F363, F1122, F1123]

## Error Handling

- On error paths where cleanup labels release pointers unconditionally, `ERR_PTR` or transferred pointers must be nulled first: `rt = NULL` in `tcp_v4_connect()` after `ip_route_newports()` `ERR_PTR` or `sk_setup_caps()`; `f6i = NULL` in `ipv6_add_addr()` after `addrconf_f6i_alloc()` `ERR_PTR`; `flowlabel` before `out:` in `ip6_datagram_dst_update()` on `fl6_sock_lookup()` `ERR_PTR`; `dst = NULL` in `icmpv6_route_lookup()` after `xfrm_lookup()` `ERR_PTR(-EPERM)`; `fn = NULL` in `fib6_add()` after `fib6_add_1()` `ERR_PTR`; and jumping to `free: kfree(rt)` instead of `fib6_info_release(rt)` in `ip6_route_info_create()` if `ip_fib_metrics_init()` returns `ERR_PTR`. [F53, F425, F426, F588, F598, F927]
- `ip6_route_info_create_nh()` consumes and frees `rt` on failure (so callers must not release `rt`), whereas `rt6_insert_exception()` takes ownership of `nrt` only when returning `0` (requiring `dst_release_immediate(&nrt->dst)` on error). When `fib6_nh_init()` fails, `out:` must release `idev`, call `fib_nh_common_release()`, clear `nhc_pcpu_rth_output` and `fib_nh_lws` to `NULL`, and call `netdev_put()`. [F890, F891, F897]

## External Contracts

- Adding or changing Netlink attributes in `inet6_fill_ifla6_attrs()`, `inet6_fill_ifaddr()`, `inet6_fill_prefix()`, `inet6_netconf_fill_devconf()`, `ip6addrlbl_fill()`, `rt6_fill_node()`, or `seg6_action_params` (`seg6_local_fill_encap()`) requires updating their paired size calculation helpers (`inet6_ifla6_size()`, `inet6_ifaddr_msgsize()`, `inet6_prefix_nlmsg_size()`, `inet6_netconf_msgsize_devconf()`, `ip6addrlbl_msgsize()`, `rt6_nlmsg_size()`/`rt6_nh_nlmsg_size()`, `seg6_local_get_encap_size()`). [F462, F959, F1049]

## Known Pitfalls

- Cached pointers into `skb->head` (`th`, `iph`, `hdr`, `ipv6h`, `srh`, `guehdr`, `mlh2`, `pkt_md`, `oldhdr`) must be reloaded from `skb` after any helper that may unshare or reallocate the SKB header (`pskb_may_pull`, `pskb_inet_may_pull`, `skb_checksum_init`, `tcp_filter`, `pskb_expand_head`, `skb_ensure_writable`, `skb_cow`, `skb_cow_head`, `skb_realloc_headroom`, `skb_checksum_help`, `__iptunnel_pull_header`, `iptunnel_pull_header`, `ip6_tnl_parse_tlv_enc_lim`), and in-place overlapping header shifts (`ipv6_rpl_srh_rcv`, `ioam6_do_inline`, `ipv6_gro_complete`, `ip6_err_gen_icmpv6_unreach`, `__seg6_do_srh_inline`, `seg6_pop_srh`, `seg6_next_csid_advance_arg`, `udp6_ufo_fragment`) must use `memmove()` rather than `memcpy()`. [F69, F455, F458, F509, F614, F620, F635, F673, F676, F762, F787, F792, F796, F966, F1003, F1041, F1042, F1101, F1112]
- `tcp_v4_fill_cb()` and `tcp_v6_fill_cb()` overwrite `IPCB(skb)` / `IP6CB(skb)` by moving it into `TCP_SKB_CB(skb)->header.h4/h6`: in `tcp_v6_rcv()`, `tcp_v6_fill_cb()` must run only after `xfrm6_policy_check()` and be followed by `skb->dev = NULL`; before `tcp_v6_fill_cb()` (e.g., `tcp_v6_early_demux()`, `tcp_v6_err()`), ingress interfaces must be read via `inet6_iif()`/`inet6_sdif()` rather than `tcp_v6_iif()`/`tcp_v6_sdif()`; and jumping back to `lookup` in `tcp_v4_rcv()`/`tcp_v6_rcv()` requires `tcp_v4_restore_cb()`/`tcp_v6_restore_cb()`. [F88, F1153, F1155, F1167]
- `__rt6_find_exception_spinlock()` and `__rt6_find_exception_rcu()` advance the caller's `*bucket` pointer in place (`*bucket += hval`), so any retry lookup on the same nexthop (such as `find_ex:` in `rt6_find_cached_rt()`) must re-fetch the base pointer via `fib6_nh_get_excptn_bucket()` (which also masks off `FIB6_EXCEPTION_BUCKET_FLUSHED`). [F910, F981]
- When unlinking entries from singly-linked lists through a pointer-to-pointer or trailing cursor (`tcp_metrics_flush_all`, `tcp_metrics_nl_cmd_del`, `fib6_add_rt2node`, `ip6_fl_gc`, `ip6_fl_purge`, `add_grec`, `mld_clear_zeros`, `mld_send_cr`), the cursor (`pp`, `ins`, `flp`, `psf_prev`, `pmc_prev`) must only advance on iterations that retain the current entry and never when the current entry is unlinked. [F104, F649, F828]
