# RNBD BLOCK DRIVERS

The RDMA Network Block Device (RNBD) subsystem consists of a client block driver (`rnbd-client`) and a server target module (`rnbd-server`) that export local block devices over RDMA using the RTRS transport layer. The client exposes remote devices locally as `blk-mq` gendisks (`/dev/rnbd*`) configured via sysfs and multiplexes I/O and administrative requests over shared or dedicated RTRS sessions with per-CPU requeue lists and optional polling queues. The server listens for RTRS connections and protocol messages (`SESS_INFO`, `OPEN`, `CLOSE`, `IO`), opens local block devices, enforces read-only/read-write/migration access permissions, and translates RDMA requests into local `bio` submissions.

## Architecture & Data Flow

- In `struct rnbd_iu`, `dev` and `sess` share a union (`iu->sess` is only valid in `msg_sess_info_conf()`; `msg_io_conf()`, `msg_open_conf()`, and `msg_close_conf()` must read `iu->dev` and pass `iu->dev->sess` to `rnbd_put_iu()`). `first_sgl[]` must remain the last member: `setup_mq_tags()` sets `tag_set->cmd_size` to `sizeof(struct rnbd_iu) + RNBD_RDMA_SGL_SIZE` for `sg_alloc_table_chained()`, while admin IUs from `rnbd_get_iu()` are `sizeof(*iu)` and use `sg_alloc_table()` / `sg_free_table()`. [F70, F105]
- In `msg_open_conf()`, `from_map = (dev->dev_state == DEV_STATE_INIT)` must be sampled before `process_msg_open_rsp(dev, rsp)` (which sets `DEV_STATE_MAPPED`), and `msg_open_conf()` must only free `rsp` (`iu->buf`) when `!from_map`, because `rnbd_clt_map_device()` reads `rsp` in `rnbd_client_setup_device()` and frees it. Thus `send_msg_open()` must never be called on a `DEV_STATE_INIT` device, and `remap_devs()` / `rnbd_clt_remap_device()` must skip or reject `DEV_STATE_INIT`. [F38, F55]
- `rnbd_get_iu()` must initialize `iu->comp.errno = INT_MAX` because `send_usr_msg()` waits on `wait_event(iu->comp.wait, iu->comp.errno != INT_MAX)` until `wake_up_iu_comp()` sets the status (`0` on success). [F44]
- In `rnbd_queue_rq()` and `rnbd_client_xfer_request()`, even when `sg_cnt == 0` (`REQ_OP_DISCARD` / `REQ_OP_WRITE_ZEROES` or zero physical segments), `sg_alloc_table_chained()` must be called with `blk_rq_nr_phys_segments(rq) ? : 1` and `sg_mark_end(&iu->sgt.sgl[0])` must be called when `sg_cnt == 0`. [F45]
- In `rnbd_rerun_if_needed()`, the per-CPU cursor `*cpup` (`sess->cpu_rr`) must be set to `cpu_q->cpu` when a queue list is found rather than incremented, because `rnbd_get_cpu_qlist()` wraps to the first set bit in `sess->cpu_queues_bm`. [F53]
- In `setup_mq_tags()`, `rnbd_rdma_map_queues()`, and `init_dev()`, `HCTX_TYPE_DEFAULT` and `HCTX_TYPE_READ` share `num_online_cpus()` queues at `queue_offset` 0 while `HCTX_TYPE_POLL` uses `sess->nr_poll_queues` queues at `queue_offset = num_online_cpus()`, so `dev->hw_queues` needs at least `nr_cpu_ids + nr_poll_queues` elements. A session with `nr_poll_queues > 0` cannot be shared in `find_and_get_or_create_sess()`: fail with `-EINVAL` if `nr_poll_queues > 0` on `!first` or if `sess->nr_poll_queues > 0`. [F60, F82]
- On the server, `srv_dev->open_write_cnt` is incremented under `srv_dev->lock` in `rnbd_srv_check_update_open_perm()` for non-`RNBD_ACCESS_RO` opens and must be decremented under `srv_dev->lock` both on `process_msg_open()` failure after `rnbd_srv_get_or_create_srv_dev()` (`srv_dev_put`) and in `rnbd_destroy_sess_dev()` when `!sess_dev->readonly`. [F62]
- In `process_msg_open()`, `find_srv_sess_dev(srv_sess, open_msg->dev_name)` must be checked under `srv_sess->lock` before opening the block device or calling `rnbd_srv_get_or_create_srv_dev()`, jumping directly to `rnbd_srv_fill_msg_open_rsp()` if already open on `srv_sess`. [F64]
- Every `enum rnbd_access_mode` value must have an entry at its numeric index in `rnbd_access_modes[]` and be handled in `rnbd_clt_parse_map_options()`, `rnbd_srv_check_update_open_perm()`, and `show_rnbd_access_mode()`. On the server, `open_msg->access_mode` must be validated by `rnbd_srv_check_update_open_perm()` before indexing `rnbd_access_modes[access_mode].str` or storing it in `rnbd_srv_sess_dev`. [F66, F75]
- In `process_rdma()`, after adding the `datalen` RDMA buffer to `bio`, any request with `bio_has_data(bio)` must have `bio->bi_iter.bi_size == le32_to_cpu(msg->bi_size)` or be rejected with `-EINVAL` before `submit_bio()`. [F74]
- `process_msg_open()` and `rnbd_srv_get_full_path()` must reject `open_msg->dev_name` with `-EINVAL` if it contains `".."` or if the formatted path with `dev_search_path` reaches `PATH_MAX`. In `rnbd_srv_get_full_path()`, `snprintf()` into `full_path` must include at least one `'/'`, and the slash-compaction loop must initialize `a` and `b` to `strchr(full_path, '/')`, advance only `b` when `*b == '/' && *a == '/'`, pre-increment `a` (`a++; *a = *b;`) otherwise, and increment `a` once more after the loop before writing `'\0'`. [F76, F95, F107]

## Synchronization

- Client lock order is `sess_lock` -> `sess->lock` -> `dev->lock` (`rnbd_clt_unmap_device()` must drop `dev->lock` before `delete_dev(dev)` acquires `sess->lock`). Server `srv_dev->lock` (protecting `open_write_cnt`, `sess_dev_list`, and `dev_kobj.state_in_sysfs`) must always nest inside `srv_sess->lock`. [F20, F29]
- In `__find_and_get_sess()`, `if (sess->rtrs_ready && IS_ERR_OR_NULL(sess->rtrs)) continue;` must precede `rnbd_clt_get_sess()` and `wait_for_rtrs_disconnection()` (which returns immediately without dropping `sess_lock` if `sess->rtrs` is NULL/ERR_PTR, spinning on `goto again` and deadlocking `free_sess()`). `sess_lock` must be dropped before `wait_for_rtrs_connection()` / `wait_for_rtrs_disconnection()`, and the `sess_list` scan must restart (`goto again`) after reacquiring `sess_lock` if the session is dying or failed to connect. [F28, F84]
- In `find_and_get_or_create_sess()` and `close_rtrs()`, `rtrs_clt_open()` and `rtrs_clt_query()` must set `sess->queue_depth` and `sess->nr_poll_queues` before `setup_mq_tags(sess)`, and `wake_up_rtrs_waiters(sess)` (`sess->rtrs_ready = true`) must only be called after `rtrs_clt_query()`, `setup_mq_tags()`, and `send_msg_sess_info()` succeed, or after `sess->rtrs` is set to `NULL` (via `close_rtrs(sess)` if `rtrs_clt_open()` succeeded) or an `ERR_PTR` before `rnbd_clt_put_sess(sess)`. [F6, F58, F110]
- Every `rtrs_permit` from `rnbd_get_permit()` increments `sess->busy` and must be released via `rnbd_put_permit()`, which decrements `sess->busy`, issues `smp_mb__after_atomic()`, and calls `rnbd_rerun_all_if_idle(sess)` to loop calling `rnbd_rerun_if_needed(sess)` until `sess->busy != 0` or `sess->cpu_queues_bm` is empty. `rnbd_clt_dev_add_to_requeue()` sets `cpu_q->cpu` in `sess->cpu_queues_bm`, issues `smp_mb__before_atomic()`, and if `sess->busy == 0` aborts by clearing `cpu_q->cpu` only if `need_set` and clearing bit 0 of `q->in_list` under `cpu_q->requeue_lock`. [F3, F24, F52, F135]
- In `rnbd_queue_rq()`, permits must use `RTRS_PERMIT_NOWAIT` and scatterlists must use `sg_alloc_table_chained()` without sleeping. `cpu_q->requeue_lock` must always use `spin_lock_irqsave()` / `spin_trylock_irqsave()`, `sess->cpu_queues` and `sess->cpu_rr` must be accessed between `get_cpu_ptr()` and `put_cpu_ptr()`, and `rnbd_clt_dev_requeue()` must call `blk_mq_run_hw_queue(q->hctx, true)` (`async = true`). [F122, F125, F126, F127]
- `msg_conf()` must defer `msg_open_conf`, `msg_close_conf`, and `msg_sess_info_conf` via `schedule_work(&iu->work)`, and `remap_devs()` and `msg_open_conf()` must pass `RTRS_PERMIT_NOWAIT` to `send_msg_sess_info()`, `send_msg_open()`, and `send_msg_close()`. [F123, F124]
- On the server, once `rnbd_srv_create_dev_session_sysfs(sess_dev)` succeeds, closing `sess_dev` in `destroy_sess()`, `process_msg_close()`, or `rnbd_srv_sess_dev_force_close()` must be serialized under `sess_dev->sess->lock` via `rnbd_srv_destroy_dev_session_sysfs(sess_dev)` (whose release callback `rnbd_srv_sess_dev_release()` calls `rnbd_destroy_sess_dev()`). `rnbd_srv_sess_dev_force_close()` must use `mutex_trylock(&sess->lock)` (never `mutex_lock()`) and set `sess_dev->keep_id = true` only after `mutex_trylock()` succeeds. [F17, F18, F114, F131]
- In `rnbd_srv_find_or_add_srv_dev()`, lookup/insertion in `dev_list` must hold `dev_lock`, initialize `new_dev` before `list_add()`, and use `kref_get_unless_zero(&dev->kref)` when matching `dev->name`, using `continue` (not `break`) if it returns 0 so dying devices not yet removed by `destroy_device()` are skipped. [F21, F94]
- `rnbd_get_sess_dev()` must hold `rcu_read_lock()` across `xa_load(&srv_sess->index_idr, dev_id)` and `kref_get_unless_zero(&sess_dev->kref)`. When removing `sess_dev` from `index_idr` in `rnbd_destroy_sess_dev()` (`xa_cmpxchg()` to `NULL` when `keep_id` is true so `device_id` is not reused, or `xa_erase()` otherwise) or in `process_msg_open()` error rollback (`xa_erase()`), `synchronize_rcu()` must run before waiting on `sess_dev->destroy_comp` (after `rnbd_put_sess_dev()`), calling `fput(sess_dev->bdev_file)`, or `kfree(sess_dev)`. [F11, F13, F50, F133]
- When destroying a kobject from its own sysfs `.store` callback (`destroy_sysfs()` from `rnbd_clt_unmap_dev_store()`, or `rnbd_srv_sess_dev_force_close()`), `sysfs_remove_file_self()` must be called before `kobject_del()` or `rnbd_srv_destroy_dev_session_sysfs()`, and in `rnbd_srv_sess_dev_force_close()` all accesses to `sess_dev` (such as reading `sess_dev->sess` or setting `sess_dev->keep_id`) must precede `rnbd_srv_destroy_dev_session_sysfs(sess_dev)`. [F10, F115]

## Object Lifetimes

- An admin `struct rnbd_iu` from `rnbd_get_iu()` starts with `iu->refcount = 2`, and `send_usr_msg()` callers must pin `dev` or `sess` beforehand and heap-allocate `rsp` into `iu->buf` (for `send_msg_open()` / `send_msg_sess_info()`). Callers must distinguish the `send_usr_msg()` return value from out-parameter `errno`: only when `send_usr_msg()` returns non-zero (`msg_conf` was not scheduled) does the caller drop the confirmation `iu` ref (calling `rnbd_put_iu()` twice total), drop `dev`/`sess`, and `kfree(rsp)`. [F1, F26, F37, F106]
- In `rnbd_queue_rq()`, once `rnbd_get_permit()` and `sg_alloc_table_chained()` succeed, any failure in `rnbd_client_xfer_request()` must call `sg_free_table_chained(&iu->sgt, RNBD_INLINE_SG_CNT)` and `rnbd_put_permit()`, matching `rnbd_softirq_done_fn()`. [F4]
- `rnbd_clt_map_device()` holds a transient session reference from `find_and_get_or_create_sess()` in addition to the device's reference from `init_dev()` (`rnbd_clt_get_sess`), and must drop it via `rnbd_clt_put_sess(sess)` on both success and failure. Also in `rnbd_clt_map_device()`, `RNBD_MSG_OPEN` (`send_usr_msg()` and `process_msg_open_rsp()`, setting `dev->device_id` and `DEV_STATE_MAPPED`) must finish before `rnbd_client_setup_device()`, where `rnbd_init_mq_hw_queues(dev)` must initialize `hctx->driver_data` before `rnbd_clt_setup_gen_disk()` calls `add_disk(dev->gd)`. [F5, F108, F109]
- In `rnbd_clt_unmap_device()`, `was_mapped = (dev->dev_state == DEV_STATE_MAPPED)` must be sampled under `dev->lock` before setting `DEV_STATE_UNMAPPED`, and `delete_dev(dev)`, `destroy_sysfs()`, and `destroy_gen_disk(dev)` must run before `send_msg_close()` (called only if `was_mapped && sess->rtrs`) and `rnbd_clt_put_dev(dev)`. [F57, F111]
- In `rnbd_clt_unmap_dev_store()` and `rnbd_clt_remove_dev_symlink()`, `try_module_get(THIS_MODULE)` must be acquired before `rnbd_clt_unmap_device()` or `sysfs_remove_link()` and balanced with `module_put(THIS_MODULE)`: `dev` must not be dereferenced after `rnbd_clt_unmap_device()` returns 0, and `rnbd_clt_remove_dev_symlink()` must always `kfree(dev->blk_symlink_name)` and set it to `NULL` even if `try_module_get()` fails. [F16, F116]
- In `rnbd_destroy_sessions()`, `rnbd_clt_destroy_sysfs_files()` runs first; then for each session in `sess_list` where `rnbd_clt_get_sess(sess)` succeeds, call `close_rtrs(sess)` before queueing `dev->unmap_on_rmmod_work` on `rnbd_clt_wq`, and `rnbd_clt_put_sess(sess)` before `flush_workqueue(rnbd_clt_wq)` (which must finish before `rnbd_client_exit()` unregisters `rnbd_client_major` and `index_ida`). [F9, F31]
- On the server, `process_msg_close()` must drop the `rnbd_get_sess_dev()` reference via `rnbd_put_sess_dev(sess_dev)` before `rnbd_srv_destroy_dev_session_sysfs(sess_dev)`. `destroy_device()` must call `rnbd_srv_destroy_dev_sysfs(dev)` if `dev->dev_kobj.state_in_sysfs` is set or `kfree(dev)` directly otherwise, and `rnbd_srv_cleanup_module()` must call `rtrs_srv_close(rtrs_ctx)` before `rnbd_srv_destroy_sysfs_files()`. [F12, F15, F117]

## API Contracts

- In `rnbd_srv_rdma_ev()`, non-IO handlers (`RNBD_MSG_OPEN`, `RNBD_MSG_CLOSE`, `RNBD_MSG_SESS_INFO`) call `rtrs_srv_resp_rdma(id, ret)` and return 0, whereas `RNBD_MSG_IO` returns `process_rdma()` directly so synchronous errors return non-zero to RTRS and async completions call `rtrs_srv_resp_rdma()` in `rnbd_dev_bi_end_io()`. [F36]
- Callers of `find_or_create_sess(sessname, &first)` must initialize `first = false` beforehand because `find_or_create_sess()` only writes `*first = true` when allocating a new session. [F43]
- In `rnbd_client_xfer_request()`, the transfer length passed to `rtrs_clt_request()` must be `rnbd_clt_get_sg_size(iu->sgt.sgl, sg_cnt)` rather than `blk_rq_bytes(rq)` (`msg.bi_size`). In `rnbd_queue_rq()`, `rnbd_clt_dev_kick_mq_queue()` takes `RNBD_DELAY_IFBUSY` (`-1`) only when `rnbd_get_permit()` fails; failures after permit acquisition must release the permit and pass a positive millisecond delay. [F46, F51]

## Error Handling

- In `rnbd-clt.c`, `alloc_sess()`, `find_or_create_sess()`, `find_and_get_or_create_sess()`, `init_dev()`, and `rnbd_clt_map_device()` return `ERR_PTR()` (never `NULL`), whereas `__find_and_get_sess()`, `rnbd_get_permit()`, and `rnbd_get_iu()` return `NULL`. In `rnbd-srv.c`, `rnbd_get_sess_dev()` returns `ERR_PTR(-ENXIO)` while `find_srv_sess_dev()` returns `NULL`. Furthermore, `sess->rtrs` can be `NULL` or `ERR_PTR`, so `close_rtrs()`, `wait_for_rtrs_connection()`, `wait_for_rtrs_disconnection()`, and `__find_and_get_sess()` must check `IS_ERR_OR_NULL(sess->rtrs)`. [F32, F33, F34]
- Callers of `rtrs_clt_query()` must check its integer return value before reading `struct rtrs_attrs`. When the server opens a device but the client fails in `process_msg_open_rsp()` / `msg_open_conf()` or `rnbd_client_setup_device()`, the client must call `send_msg_close()` with `rsp->device_id`. In `rnbd_clt_add_dev_symlink()`, if `kzalloc()` of `dev->blk_symlink_name` fails return `-ENOMEM` immediately, and on later error (`out_err`) both `kfree(dev->blk_symlink_name)` and set it to `NULL`. [F35, F41, F56]

## External Contracts

- `rnbd_dev_class.name` must remain `"rnbd-client"` and `"rnbd-server"`, and `state_show()` must emit `"open\n"` for `DEV_STATE_MAPPED` and `"closed\n"` for `DEV_STATE_MAPPED_DISCONNECTED`. Wire structures in `rnbd-proto.h` must keep their exact sizes (4, 36, 36, 264, 8, and 56 bytes), padding, and `__le*` types, and `process_rdma()` must only read `msg->prio` when `srv_sess->ver >= RNBD_PROTO_VER_MAJOR` and `usrlen >= sizeof(struct rnbd_msg_io)`. [F68, F69, F73, F80]
