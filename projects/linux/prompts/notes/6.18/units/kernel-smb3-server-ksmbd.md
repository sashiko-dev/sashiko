# KERNEL SMB3 SERVER (KSMBD)

This unit implements the core SMB1/SMB2/SMB3 protocol data unit (PDU) parsing, command dispatch, and response generation for `ksmbd`, alongside Windows Security Descriptor / POSIX ACL translation and the Generic Netlink IPC transport to the userspace `ksmbd.mountd` daemon.

## Architecture & Data Flow
- In `is_chained_smb2_message()` and `init_chained_smb2_rsp()`, advancing to a chained command (`next_cmd > 0`) requires 64-bit checks against `get_rfc1002_len(work->request_buf)` and `work->response_sz` (`+ MAX_CIFS_SMALL_BUFFER_SIZE`). Save `work->next_smb2_rsp_hdr_off` in `work->curr_smb2_rsp_hdr_off` before advancing so `smb2_set_sign_rsp()` / `smb3_set_sign_rsp()` sign via `ksmbd_resp_buf_curr(work)`, and pad chained responses with `ALIGN(len, 8)` while adding padding to both `work->iov[work->iov_idx].iov_len` and `inc_rfc1001_len(work->response_buf, ...)`. [F58, F59, F82]
- In `init_chained_smb2_rsp()`, `req` and `rsp` point to the completed command's headers, whereas `rcv_hdr` and `rsp_hdr` point to the upcoming command's headers. Set `rsp->NextCommand` (not `rsp_hdr->NextCommand`), and if `rcv_hdr->Flags` (not `req->Flags`) lacks `SMB2_FLAGS_RELATED_OPERATIONS`—or when `smb2_close()` closes a compound FID—reset both `work->compound_fid` and `work->compound_pfid` to `KSMBD_NO_FID`. [F60, F112]
- In `smb2_sess_setup()`, set `conn->binding = false` for new (`!req->hdr.SessionId`) or reauthenticated non-binding sessions, and `true` only on validated `SMB2_SESSION_REQ_FLAG_BINDING` requests; when `conn->binding` is true on `SMB311_PROT_ID`, `generate_preauth_hash()` and `smb3_preauth_hash_rsp()` must update `preauth_sess->Preauth_HashValue` from `ksmbd_preauth_session_lookup()` rather than `sess->Preauth_HashValue`. Also free and NULL `conn->mechToken` before returning, and keep `ntlm_authenticate()` and `krb5_authenticate()` post-auth state updates in lockstep. [F61, F62, F63, F74]
- In `smb2_open()`, a newly allocated `struct ksmbd_file` must remain in `FP_NEW` until all open checks, oplock/lease grants, and metadata setups succeed, transitioning to `FP_INITED` via `ksmbd_update_fstate()` only immediately before pinning the response. Before calling `ksmbd_vfs_set_sd_xattr()` in `smb2_open()` or `set_info_sec()`, all changes to the target inode's POSIX ACLs (`set_posix_acl()`, `ksmbd_vfs_inherit_posix_acl()`, `ksmbd_vfs_set_init_posix_acl()`) and UID/GID/mode (`notify_change()`) must already be committed. [F18, F148]
- Because `XATTR_USER_PREFIX` is shared across client EAs, streams (`STREAM_PREFIX`), and DOS attributes (`DOS_ATTRIBUTE_PREFIX`), `smb2_get_ea()` must skip `STREAM_PREFIX` and `DOS_ATTRIBUTE_PREFIX` (and zero `prev_eainfo->NextEntryOffset`, not `eainfo->NextEntryOffset`, after the loop), while `smb2_remove_smb_xattrs()` must only delete `XATTR_USER_PREFIX` + `STREAM_PREFIX`. In `smb2_set_ea()`, validate `buf_len >= sizeof(struct smb2_ea_info) + eabuf->EaNameLength + le16_to_cpu(eabuf->EaValueLength)` and `EaNameLength <= XATTR_NAME_MAX - XATTR_USER_PREFIX_LEN` on each step. [F88, F109, F157]
- In `smb3_decrypt_req()`, verify `pdu_length = get_rfc1002_len(buf)` is `>= sizeof(struct smb2_transform_hdr) + sizeof(struct smb2_hdr)` and `pdu_length - sizeof(struct smb2_transform_hdr) >= le32_to_cpu(tr_hdr->OriginalMessageSize)` before decrypting; afterwards, shift the PDU to `buf + 4` with `memmove()` and set `*(__be32 *)buf = cpu_to_be32(buf_data_size)`. In `smb2_check_sign_req()` and `smb3_check_sign_req()`, copy `hdr->Signature` to a local buffer before zeroing `hdr->Signature` in place. [F69, F70, F95]
- In `parse_sec_desc()`, sample `pntsd->type` into `pntsd_type` before overwriting `pntsd->type = cpu_to_le16(DACL_PRESENT)` in place, so `DACL_PROTECTED` and `DACL_AUTO_INHERITED` (only when both `DACL_AUTO_INHERITED | DACL_AUTO_INHERIT_REQ` are set together in `pntsd_type`) can be restored onto `pntsd->type` before `set_info_sec()` writes `pntsd` to the xattr. [F71, F99]
- In `parse_sec_desc()`, `acl_len` and non-zero SID/DACL offsets must be `>= sizeof(struct smb_ntsd)`. In `parse_dacl()`, `smb_inherit_dacl()`, `smb_check_perm_dacl()`, `build_sec_desc()`, and `set_ntacl_dacl()`, check `dacloffset + sizeof(struct smb_acl)` with `check_add_overflow()`, cast 32-bit wire offsets to `u64` when validating against `pntsd_alloc_size`, bound `num_aces` by `pdacl->size`, and check `ace->size <= aces_size` on each step. [F92, F93, F115, F116]
- Widen base offsets or `sizeof` expressions to `u64` before adding 32-bit wire lengths in `session_user()`, `smb2_create_link()`, `set_rename_info()`, and `smb2_write_pipe()`. In `smb2_lock()`, check `lock_start > U64_MAX - lock_length` for wrap-around and clamp `flock->fl_end` to `OFFSET_MAX`; when `vfs_lock_file()` returns `FILE_LOCK_DEFERRED` and `smb_lock->llist` is placed on `rollback_list`, call `list_del(&smb_lock->llist)` before `goto retry;` or freeing `smb_lock`. [F108, F118, F119]
- In `transport_ipc.c`, size `ksmbd_nl_policy` as `KSMBD_EVENT_MAX + 1` and reject `type > KSMBD_EVENT_MAX` in `handle_generic_event()` before indexing `info->attrs[type]`. `ksmbd_ipc_init()` must run `ksmbd_nl_init_fixup()` and `INIT_DELAYED_WORK(&ipc_timer_work, ipc_timer_heartbeat)` before `genl_register_family(&ksmbd_genl_family)`, and `ksmbd_ipc_release()` must call `cancel_delayed_work_sync(&ipc_timer_work)`. [F22, F76]

## Synchronization
- In `setup_async_work()`, initialize `work->asynchronous`, `work->async_id`, `work->cancel_fn`, and `work->cancel_argv` before linking `work->async_request_entry` into `conn->async_requests` under `spin_lock(&conn->request_lock)`, and in `release_async_work()`, unlink it under `conn->request_lock` before freeing `cancel_argv` or `async_id`. Any `cancel_fn` callback (such as `smb2_remove_blocked_lock()`) must not sleep or acquire `conn->request_lock`, because `smb2_cancel()` invokes `iter->cancel_fn(iter->cancel_argv)` while holding `spin_lock(&conn->request_lock)`. [F19, F20]
- Hold `startup_lock` across daemon startup and reset transitions in `handle_startup_event()`, `__ipc_heartbeat()`, and `ksmbd_ipc_soft_reset()` when updating `ksmbd_tools_pid` and cancelling `ipc_timer_work`. Because `ksmbd_ipc_soft_reset()` calls `cancel_delayed_work_sync(&ipc_timer_work)` under `mutex_lock(&startup_lock)`, `__ipc_heartbeat()` must exit early when `!ksmbd_server_running()` before acquiring `startup_lock` and must never reschedule `ipc_timer_work` after setting `SERVER_STATE_RESETTING`. [F23, F145]
- In `smb2_session_logoff()`, release `ksmbd_conn_lock(conn)` after setting `KSMBD_SESS_NEED_RECONNECT` and before calling `ksmbd_close_session_fds(work)` and `ksmbd_conn_wait_idle(conn)`. In `smb2_tree_connect()` and `smb2_tree_disconnect()`, serialize transitions of `tcon->t_state` to `TREE_CONNECTED` and check-and-update to `TREE_DISCONNECTED` (with `atomic_dec_and_test(&tcon->refcount)`) under `write_lock(&sess->tree_conns_lock)`. [F24, F25]
- In `smb2_lock()`, scanning `conn->lock_list` across connections requires `down_read(&conn_list_lock)` with `spin_lock(&conn->llist_lock)` nested inside, and mutating `smb_lock->clist` or `smb_lock->flist` requires `spin_lock(&conn->llist_lock)`. When `vfs_lock_file()` returns `FILE_LOCK_DEFERRED`, queue `work->fp_entry` on `fp->blocked_works` under `spin_lock(&fp->f_lock)` during `ksmbd_vfs_posix_lock_wait(flock)`, remove it under `fp->f_lock` after waking, and check `work->state != KSMBD_WORK_ACTIVE` before retrying. [F26, F27]
- In `smb20_oplock_break_ack()` and `smb21_lease_break_ack()`, once `opinfo` is validated as breaking, all exit paths (including `err_out`) must reset `opinfo->op_state = OPLOCK_STATE_NONE`, wake `opinfo->oplock_q` (and decrement `opinfo->breaking_cnt` and wake `opinfo->oplock_brk` for leases), and call `opinfo_put(opinfo)`. [F28]
- In `set_info_sec()`, `set_file_basic_info()`, and `set_ntacl_dacl()`, `inode_lock(inode)` is required around `notify_change(idmap, dentry, &attrs, NULL)` and must NOT be held across `set_posix_acl()` or `ksmbd_vfs_*_xattr()` calls. In `get_file_alternate_info()`, hold `spin_lock(&dentry->d_lock)` while passing `dentry->d_name.name` to `ksmbd_extract_shortname()`, which runs in atomic context and must not sleep. [F30, F139, F143]
- In `smb2_open()`, initialize `fp->daccess`, `fp->saccess`, `fp->attrib_only`, and `fp->stream` before acquiring `down_write(&fp->f_ci->m_lock)` to add `fp->node` to `fp->f_ci->m_fp_list`. In `ksmbd_smb_check_shared_mode()`, hold `down_read(&curr_fp->f_ci->m_lock)` while iterating `curr_fp->f_ci->m_fp_list`; when `ksmbd_stream_fd(prev_fp)` and `!ksmbd_stream_fd(curr_fp)`, run the `FILE_SHARE_DELETE_LE` / `FILE_DELETE_LE` check before `continue`. [F31, F96, F141]
- In `smb2_create_link()`, keep the parent directory's `i_rwsem` and mount write access from `ksmbd_vfs_kern_path_locked()` held across `ksmbd_vfs_remove_file()` and release via `ksmbd_vfs_kern_path_unlock()` before `ksmbd_vfs_link()`. In `smb2_query_dir()`, `__query_dir()` runs under the directory's `i_rwsem` and must only buffer names via `reserve_populate_dentry()`, deferring `lookup_one_unlocked()` and `ksmbd_vfs_fill_dentry_attrs()` to `process_query_dir_entries()`. [F137, F138]

## Object Lifetimes
- `ipc_msg_send_request()` helpers (`ksmbd_rpc_read()`, `ksmbd_rpc_write()`, `ksmbd_rpc_ioctl()`) return a `kvzalloc()` buffer owned by the caller; do not `kvfree(rpc_resp)` before fallible calls like `ksmbd_iov_pin_rsp_read()` when `out:` also frees it. `ipc_msg_send_request()` must insert and `hash_del()` stack `entry` in `ipc_msg_table` under `down_write(&ipc_msg_table_lock)` before returning or freeing `handle`. In `ipc_msg_send()`, never call `nlmsg_free(skb)` after `genlmsg_unicast()`. [F3, F21, F159]
- In `smb2_sess_setup()`, any error path that calls `ksmbd_user_session_put(sess)` before `out_err` must set `sess = NULL`, and when `out_err` puts `sess` on failure (`rc < 0`), it must also clear `work->sess = NULL`. In `smb2_tree_disconnect()`, set `work->tcon = NULL` after `ksmbd_tree_conn_disconnect(sess, tcon)`. `smb2_check_user_session()` and `smb2_get_ksmbd_tcon()` must only look up and acquire references when `work->next_smb2_rcv_hdr_off == 0`, reusing existing references on chained commands. [F6, F7, F8]
- In `smb2_open()`, drop `dh_info.fp` via `ksmbd_put_durable_fd()` if reconnect fails before `fp = dh_info.fp` or once reconnect finishes. For new opens, keep `file_present` and `created` `false` until `ksmbd_vfs_kern_path()` or `smb2_creat()` succeeds; after `path_put(&path)` (once `fp` is on `m_fp_list`), jump to `err_out1` instead of `err_out`. `ksmbd_open_fd(work, filp)` takes `filp` ownership only on success (closed via `ksmbd_fd_put()` at `err_out2`); on `ERR_PTR`, call `fput(filp)` and set `fp = NULL` before `err_out`. [F11, F12, F13, F47]
- Both `ksmbd_acls_fattr()` and `parse_sec_desc()` populate `fattr->cf_acls` and `fattr->cf_dacls` with reference-counted `struct posix_acl` objects that callers must release via `posix_acl_release()` on all exit paths. In `smb2_lock()`, free `flock` from `smb_flock_init()` with `locks_free_lock(flock)` if validation or `smb2_lock_init()` fails before linking onto `lock_list`, and jump to `out` (not `out2`) on errors after adding locks to `lock_list` or `rollback_list`. [F10, F14]

## API Contracts
- `ksmbd_iov_pin_rsp_read()` takes ownership of `aux_payload_buf` only when returning 0 with non-zero `aux_size`; on error or earlier RDMA free, the caller must call `kvfree(aux_payload_buf)` and set `aux_payload_buf = NULL` (and `nbytes = 0`). `setup_async_work(work, fn, arg)` requires a `kmalloc()`-allocated `arg` and takes ownership of `arg` and `work->async_id` only when returning 0; on failure, the caller must `kfree(arg)` directly, whereas after success `release_async_work(work)` frees both. [F2, F5, F130]
- `__ksmbd_override_fsids()` and `ksmbd_override_fsids()` store `current`'s credentials in the single-slot `work->saved_cred` (`WARN_ON(work->saved_cred)` if non-NULL); never nest them across helpers that call `ksmbd_override_fsids()` internally (`ksmbd_vfs_remove_file()`, `ksmbd_vfs_link()`, `ksmbd_vfs_rename()`) and always pair with `ksmbd_revert_fsids(work)`. [F146]
- `smb2_check_user_session()` and `smb2_get_ksmbd_tcon()` return `< 0` on error, `0` when exempt (skipping `get_ksmbd_tcon()`), and `1` when matched. `smb2_check_sign_req()` and `smb3_check_sign_req()` return `1` when valid and `0` on failure (inverting `ksmbd_sign_smb*_pdu()`, which return `0` on success). `compare_sids()` returns `0` on match. `ksmbd_lookup_dialect_by_id()`, `ksmbd_lookup_dialect_by_name()`, and `ksmbd_negotiate_smb_dialect()` return `BAD_PROT_ID` (`0xFFFF`) on failure; `ksmbd_lookup_protocol_idx()` returns `-1`. [F32, F33, F34, F35]
- Before `parse_sec_desc()` in `set_info_sec()`, zero `fattr` and set `cf_uid = INVALID_UID`, `cf_gid = INVALID_GID`, and `cf_mode = inode->i_mode`. `set_info_sec()` and `smb2_set_ea()` must forward `get_write` to all inner `ksmbd_vfs_*xattr()` calls, and `set_info_sec()` only exits early on `!(le16_to_cpu(pntsd->type) & DACL_PRESENT)` when `type_check` is `true` (`smb2_create_sd_buffer()`, not `smb2_set_info_sec()`). [F49, F50, F51]
- On idmapped mounts, `sid_to_id()` maps wire RIDs into `kuid_t`/`kgid_t` via `from_vfsuid()`/`from_vfsgid()`, while `ksmbd_acls_fattr()`, `find_file_posix_info()`, and `posix_acl_*_translate()` map inode/ACL IDs via `i_uid_into_vfsuid()`/`make_vfsuid()` before `from_kuid()`. [F150]
- `set_smb2_rsp_status()` must zero `work->iov_idx`, `work->iov_cnt`, and `work->next_smb2_rcv_hdr_off` and write `err` to `work->response_buf` before `smb2_set_err_rsp()`. Callers of `fill_transform_hdr()` (`smb3_encrypt_resp()`) must allocate `tr_buf` with `kzalloc()` and store it in `work->tr_buf`. Variable-length IPC builders (`ksmbd_ipc_spnego_authen_request()`, `ksmbd_rpc_write()`, `ksmbd_rpc_ioctl()`) must reject `blob_len`/`payload_sz > KSMBD_IPC_MAX_PAYLOAD` before `ipc_msg_alloc()`. Check `smb2_find_context_vals()` for both `!IS_ERR()` and non-NULL. [F15, F40, F57, F77]

## Error Handling
- In `parse_dacl()`, tear down `acl_state`, `default_acl_state`, and `ppace` in reverse order on failure. Because `get_inode_acl()` returns `NULL` or `ERR_PTR`, callers in `smbacl.c` (`smb_check_perm_dacl()`) must check `!IS_ERR_OR_NULL(posix_acls)`. `smb_strndup_from_utf16()` and `smb2_get_name()` return `ERR_PTR` (never `NULL`), so check `IS_ERR()` and guard `kfree()` with `!IS_ERR()` or reset to `NULL`. Check `ksmbd_alloc_work_struct()` for `NULL` in `smb2_send_interim_resp()`. [F9, F37, F39, F41]
- `ksmbd_acquire_id(&ipc_ida)` and `ksmbd_ipc_id_alloc()` return negative errnos on failure; `ksmbd_rpc_id_free()` does not guard against negative IDs and must only be called when `handle >= 0`. In `smb2_get_info_filesystem()` and `smb2_get_info_file()`, guard post-switch `rc = buffer_check_err(...)` with `if (!rc)` so switch errors are not overwritten. In `smb2_tree_connect()`, initialize `share = NULL` and check `share != NULL` and `status.ret == KSMBD_TREE_CONN_STATUS_OK` at `out_err1:`. [F36, F44, F46]

## Known Pitfalls
- Loops that update offsets or pointers at the bottom of the body must not use `continue;`: in `deassemble_neg_contexts()`, `pctx` advances at the top and `offset = (ctxt_len + 7) & ~0x7` is recomputed at the bottom; in `smb2_set_ea()`, skipping an entry in `do { ... } while (next != 0)` must use `goto next;`; and in `smb_inherit_dacl()`, skipping a parent ACE must use `goto pass;` so `parent_aces` advances by `pace_size`. [F105, F106, F107]
- Because `struct smb_sid` has a fixed 15-element `sub_auth` array, `sizeof(struct smb_sid)` (68) and `sizeof(struct smb_ace)` (76) are maximum in-memory sizes; DACL parsers/builders in `smbacl.c` must advance ACE pointers by `(char *)ace + le16_to_cpu(ace->size)` rather than `ace++`. In `decode_preauth_ctxt()`, validate `ctxt_len` against `sizeof(struct smb2_neg_context) + MIN_PREAUTH_CTXT_DATA_LEN` rather than `sizeof(struct smb2_preauth_neg_context)` because `Salt` is variable-length. [F85, F126]
