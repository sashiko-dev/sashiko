# LANDLOCK SECURITY MODULE

The Landlock Linux Security Module (LSM) enables unprivileged tasks to sandbox themselves by creating rulesets (`landlock_create_ruleset`), adding filesystem and TCP port rules (`landlock_add_rule`), and stacking immutable domains onto their own credentials (`landlock_restrict_self`). It enforces access control and IPC scoping across VFS paths, open files, device ioctls, TCP sockets, abstract UNIX sockets, signals, and ptrace via LSM hooks, while logging audit events. It is closely coupled with the VFS `ioctl` dispatcher (`fs/ioctl.c`) for device ioctl filtering (`is_masked_device_ioctl`).

## Architecture & Data Flow

- `union landlock_key` stores either `struct landlock_object *` (`object`) or `uintptr_t` (`data`) without a tag; `key.object` must only be dereferenced or passed to `landlock_get_object()`/`landlock_put_object()` when `is_object_pointer(key_type)` is true (`LANDLOCK_KEY_INODE`). All `enum landlock_key_type` dispatches in `ruleset.c` (`is_object_pointer()`, `get_root()`, `merge_ruleset()`, `inherit_ruleset()`, `free_ruleset()`, `landlock_init_layer_masks()`) must handle all enabled key types in lockstep, guarding `LANDLOCK_KEY_NET_PORT` with `#if IS_ENABLED(CONFIG_INET)`. [F29, F61]
- In `struct landlock_layer`, `layer->level` is `0` for unmerged rulesets and 1-based (`1..domain->num_layers`) for merged domains (`merge_tree()`), whereas `domain->access_masks[]` and `layer_mask_t` bits are 0-indexed (`0..num_layers - 1`), so `landlock_unmask_layers()` must compute `layer_bit` as `BIT_ULL(layer->level - 1)`. [F67]
- `landlock_upgrade_handled_access_masks()` must OR `_LANDLOCK_ACCESS_FS_INITIALLY_DENIED` (`LANDLOCK_ACCESS_FS_REFER`) into `access_masks.fs` only when `access_masks.fs` is non-zero, whereas `landlock_get_fs_access_mask()` unconditionally ORs `_LANDLOCK_ACCESS_FS_INITIALLY_DENIED`. `add_rule_path_beneath()` must validate `allowed_access` against `ruleset->access_masks[0].fs` directly, while `landlock_append_fs_rule()` must OR in `LANDLOCK_MASK_ACCESS_FS & ~landlock_get_fs_access_mask(ruleset, 0)` so `LANDLOCK_ACCESS_FS_REFER` is never implicitly granted. [F53, F54]
- In `hook_file_open()`, whenever `landlock_file(file)->allowed_access` is populated from `layer_masks`, `landlock_file(file)->deny_masks` must be updated in lockstep via `landlock_get_deny_masks()` for `_LANDLOCK_ACCESS_FS_OPTIONAL`. `get_layer_deny_mask()` and `get_layer_from_deny_masks()` must pack and unpack `deny_masks_t` using the exact same bit-index ordering over `_LANDLOCK_ACCESS_FS_OPTIONAL` and 4-bit width (`HWEIGHT(LANDLOCK_MAX_NUM_LAYERS - 1)`), storing the 0-based youngest denying layer (`__fls(mask)`). [F45, F46]
- Operations on opened files (`hook_file_truncate`, `hook_file_ioctl_common`, `hook_file_send_sigiotask`) must authorize access and attribute audit records using `struct landlock_file_security` (`file->f_cred`, `allowed_access`, `deny_masks`, `fown_subject`) rather than `current_cred()`. `hook_file_ioctl_common()` must check `is_device(file)` and return `0` for non-device files because `hook_file_open()` only requests `LANDLOCK_ACCESS_FS_IOCTL_DEV` in `optional_access` when `is_device(file)` is true. [F83, F142]
- `is_masked_device_ioctl()` and `is_masked_device_ioctl_compat()` in `security/landlock/fs.c` must classify every command handled in `do_vfs_ioctl()` and `compat_sys_ioctl` (`fs/ioctl.c`) identically between native and compat modes, including `CONFIG_X86_64` `FS_IOC_*_32` preallocation commands and `FS_IOC32_GETFLAGS`/`FS_IOC32_SETFLAGS`. [F130]
- In `is_access_to_paths_allowed()`, when a dual-path refer check (`is_dom_check == true`) satisfies `no_more_access()`, it must clear `is_dom_check = false`, downgrade `access_masked_parent1` and `access_masked_parent2` to the requested masks, and call `scope_to_request()` on both `layer_masks_parent1` and `layer_masks_parent2`. In `no_more_access()`, directory-only rights (bits not in `ACCESS_FILE`) are checked for `parent2` against `child1` only when `child1_is_directory` is true, and for `parent1` against `child2` only when `child2_is_directory` is true. [F57, F79]
- In `current_check_refer_path()`, `get_mode_access()` uses `old_dentry`'s mode for `access_request_parent2` (destination) and, on exchange, `new_dentry`'s mode for `access_request_parent1` (source), whereas `maybe_remove()` uses `old_dentry` for `access_request_parent1` and `new_dentry` for `access_request_parent2`. When `is_access_to_paths_allowed()` fails for a cross-directory refer, `request1.audit.u.path.dentry` must be overwritten with `old_parent` and `request2.audit.u.path.dentry` with `new_dir->dentry` before calling `landlock_log_denial()`. [F92, F93]
- In `get_denied_layer()` and `get_layer_from_deny_masks()`, finding an access bit denied at a strictly higher layer (`layer > youngest_layer`) must overwrite `missing` with `BIT(access_bit)` rather than ORing it, so `*access_request` only reports blockers from the single youngest denying layer. [F89]
- When `insert_rule()` matches an existing `struct landlock_rule` node (`this->key.data == id.key.data`) during a domain merge (`(*layers)[0].level != 0`), it must replace `this` via `rb_replace_node()` and `free_rule()` without incrementing `ruleset->num_rules`. [F44]
- In `sys_landlock_restrict_self()`, `prev_log_subdomains = !new_llcred->log_subdomains_off` must be sampled before `new_llcred->log_subdomains_off` is updated, and `new_dom->hierarchy->log_status` must check `!prev_log_subdomains` so `LANDLOCK_RESTRICT_SELF_LOG_SUBDOMAINS_OFF` only disables logging for future nested domains. It must also set `BIT(new_dom->num_layers - 1)` in `new_llcred->domain_exec`, while `hook_bprm_creds_for_exec()` must reset `landlock_cred(bprm->cred)->domain_exec = 0` on `execve()`. [F48, F49]
- `current_check_access_socket()` must verify `addrlen >= offsetofend(typeof(*address), sa_family)` before reading `sa_family`, `addrlen >= sizeof(struct sockaddr_in)` for `AF_UNSPEC`/`AF_INET`, and `addrlen >= SIN6_LEN_RFC2133` for `AF_INET6`, while `is_abstract_socket()` must check `addr->len >= offsetof(struct sockaddr_un, sun_path) + 1`. `landlock_append_net_rule()` must convert host-endian `u16 port` via `(__force uintptr_t)htons(port)` in `id.key.data` to match the `__be16` port looked up by `current_check_access_socket()`. [F72, F73]

## Synchronization

- `landlock_object_underops.release` (`release_inode()`) is invoked by `landlock_put_object()` with `object->lock` held after `refcount_dec_and_lock(&object->usage, &object->lock)` succeeds and must unlock `object->lock` before returning or calling sleeping `iput()`. Both `release_inode()` and `hook_sb_delete()` must clear `object->underobj = NULL` under `object->lock` before `rcu_assign_pointer(landlock_inode(inode)->object, NULL)` and `iput(inode)`. [F1, F50]
- In `release_inode()`, `landlock_superblock(sb)->inode_refs` must be incremented before `spin_unlock(&object->lock)` and decremented with a conditional `wake_up_var()` only after `iput(inode)` completes, so `hook_sb_delete()` waits via `wait_var_event()` for in-flight `iput()` calls. In `hook_sb_delete()`, while iterating `sb->s_inodes` under `sb->s_inode_list_lock`, `inode->i_lock` must be held to check `!(inode->i_state & (I_FREEING | I_WILL_FREE | I_NEW))` and call `__iget(inode)`, and `sb->s_inode_list_lock` must be dropped before `iput(prev_inode)`. [F15, F16]
- `get_inode_object()` must look up `inode_sec->object` under `rcu_read_lock()` using `rcu_dereference()` and `refcount_inc_not_zero(&object->usage)` (spinning on `object->lock` and retrying if zero), and when installing a new object under `inode->i_lock` must recheck `rcu_access_pointer(inode_sec->object)` and publish it with `rcu_assign_pointer()`. If `inode_sec->object` is found non-NULL under `inode->i_lock`, the unpublished `new_object` must be freed with `kfree(new_object)` (not `landlock_put_object()`) and `rcu_read_lock()` must be re-acquired before `goto retry`. [F5, F90, F127]
- Rule insertions (`insert_rule()`) and tree copies (`merge_tree()`, `inherit_tree()`) must hold `ruleset->lock`, and `merge_ruleset()` / `inherit_ruleset()` must lock the newly allocated unshared ruleset (`dst` or `child`) before locking `src` or `parent` with `mutex_lock_nested(..., SINGLE_DEPTH_NESTING)`. [F18]
- Reads and updates of `landlock_file(file)->fown_subject` and `fown_layer` in `hook_file_set_fowner()` and `hook_file_send_sigiotask()` must be serialized by `file->f_owner->lock` (`fown->lock`). `hook_file_set_fowner()` must update `fown_subject` and `fown_layer` together under `fown->lock` (resetting both to zero when `control_current_fowner()` is false or `LANDLOCK_SCOPE_SIGNAL` is not handled) and release `prev_dom` via `landlock_put_ruleset_deferred()`. `control_current_fowner()` must hold `rcu_read_lock()` across `pid_task(fown->pid, fown->pid_type)`. [F21, F47]
- `landlock_get_task_domain()` dereferences `__task_cred(task)` without taking a credential reference and must only be called within an RCU read-side critical section; any returned domain or credential security pointer must not be used after `rcu_read_unlock()`. Abstract UNIX socket scoping (`sock_is_scoped()`) must resolve the peer socket's domain from `other->sk_socket->file->f_cred` while holding `unix_sk(other)->lock`, and `hook_unix_may_send()` must allow datagram sends when `unix_peer(sock->sk) == other->sk`. [F118, F140]
- `landlock_log_denial()` and `log_domain()` must allocate audit buffers with `GFP_ATOMIC | __GFP_NOWARN` in `audit_log_start()` because `landlock_log_denial()` is called under RCU read locks or spinlocks. Once a domain is published via `commit_creds()`, `hierarchy->log_status` must be accessed with `READ_ONCE()`/`WRITE_ONCE()`, and `log_domain()` must set `LANDLOCK_LOG_RECORDED` only after emitting the `status=allocated` audit record. [F23, F117]

## Object Lifetimes

- In `struct landlock_object`, `rcu_free` and `underops` share an anonymous union. In `landlock_put_object()`, dropping the final `object->usage` reference must use `refcount_dec_and_lock(&object->usage, &object->lock)`, invoke `object->underops->release(object)` (which unlocks `object->lock`) before touching `object->rcu_free`, and free `object` via `kfree_rcu(object, rcu_free)`. [F2, F17]
- In `struct landlock_ruleset`, `work_free` shares an anonymous union with `lock`, `usage`, `num_rules`, `num_layers`, and `access_masks[]`. Dropping a ruleset reference from non-sleeping or RCU/spinlock contexts (`hook_cred_free()`, `hook_file_set_fowner()`, `hook_file_free_security()`) must use `landlock_put_ruleset_deferred()`, `work_free` may only be initialized after `refcount_dec_and_test(&ruleset->usage)` succeeds, and `free_ruleset()` must never access union-aliased fields and must traverse `root_inode` and `root_net_port` with `rbtree_postorder_for_each_entry_safe()`. [F7, F34, F86]

## API Contracts

- `landlock_insert_rule()` and `insert_rule()` require the caller to hold a reference to `id.key.object` for `LANDLOCK_KEY_INODE` rules and never consume that caller reference; `create_rule()` takes its own reference via `landlock_get_object()` when allocating a rule node. [F6]
- A `struct landlock_request` passed to `landlock_log_denial()` must satisfy `is_valid_request()`: set either 1-based `layer_plus_one` (`1..LANDLOCK_MAX_NUM_LAYERS`, so callers add 1 and `landlock_log_denial()` subtracts 1 before `get_hierarchy()`) or `access` (never both), and when `access` is non-zero set either `layer_masks` (with `layer_masks_size = ARRAY_SIZE(*layer_masks)`, never `sizeof()`) or `all_existing_optional_access` (never both). `get_layer_deny_mask()` and `get_blocker()` take a 0-based bit index `access_bit`, not a shifted mask. [F32, F33, F69, F106]
- `get_current_exe()` returns the base `buffer` pointer for `kfree()` on success, `ERR_PTR(-errno)` on failure, or `NULL` when the task has no executable file without writing `*exe_str` or `*exe_size`; because `d_path()` writes into the tail of `buffer`, it sets `*exe_size = buffer + buffer_size - exe` (checking `size > 0`) and `*exe_str = exe`. Callers like `get_current_details()` must pre-initialize both out-parameters to fallback values, test `IS_ERR()` rather than `!buffer`, copy from `*exe_str`, and `kfree(buffer)`. [F26, F74]

## Error Handling

- In `sys_landlock_restrict_self()`, `new_llcred->domain` must not be replaced or put until after `landlock_merge_ruleset()` is checked for `IS_ERR(new_dom)` and `abort_creds(new_cred)` is called on failure, because `abort_creds()` triggers `hook_cred_free()` which calls `landlock_put_ruleset_deferred()` on `landlock_cred(cred)->domain`. [F37]

## External Contracts

- When reparenting is denied in `current_check_refer_path()`, it must check `is_eacces()` on both parent layer masks (testing denied bits in `access_request & ~LANDLOCK_ACCESS_FS_REFER`) and return `-EACCES` before returning `-EXDEV`. Signal scoping in `hook_task_kill()` (when `cred == NULL`) and `control_current_fowner()` must check `same_thread_group(p, current)` and always allow intra-process signals. [F36, F141]
- In `current_check_access_socket()`, `AF_UNSPEC` must be handled before rule lookup by returning `0` for `LANDLOCK_ACCESS_NET_CONNECT_TCP` and validating `skc_family == AF_INET` and `sin_addr.s_addr == htonl(INADDR_ANY)` for `LANDLOCK_ACCESS_NET_BIND_TCP`, while non-`AF_UNSPEC` families must match `skc_family` or return `-EINVAL`. [F84]

## Known Pitfalls

- Callers of `collect_domain_accesses()` (`current_check_refer_path()`) must zero-initialize `layer_masks_dom` (`= {}`) because early returns on `is_nouser_or_private(dir)` skip `landlock_init_layer_masks()`. Every `struct landlock_request` passed to `is_access_to_paths_allowed()` must also be zero-initialized (`= {}`) because `log_request_parent1`/`log_request_parent2` are only populated when that parent is denied, and callers test `request.access` before calling `landlock_log_denial()`. [F27, F28]
- Because `for_each_set_bit()` and `for_each_clear_bit()` read `unsigned long` words, functions iterating over a 16-bit `access_mask_t` (`landlock_unmask_layers()`, `landlock_init_layer_masks()`, `scope_to_request()`, `log_blockers()`) must copy the mask into an `unsigned long` local variable before passing its address. [F68]
- In `is_access_to_paths_allowed()`, `collect_domain_accesses()`, and `current_check_refer_path()` (when resolving `old_parent`), upward dentry traversal within a mount must check mount boundaries (`dentry == mnt_root`) in addition to `IS_ROOT()` before dereferencing `d_parent` or calling `dget_parent()`, because `dget_parent()` on a root dentry returns itself and a cloned mount root can have `dentry == mnt_root` while `!IS_ROOT(dentry)`. [F91, F144]
- In `create_rule()`, `new_rule` must be allocated for `new_num_layers` elements and have `new_rule->num_layers` set to `new_num_layers` before `memcpy()`, while `memcpy()` must copy only `flex_array_size(new_rule, layers, num_layers)` bytes from `layers`. LSM blob accessors (`landlock_cred()`, `landlock_file()`, `landlock_inode()`, `landlock_superblock()`, `hook_inode_free_security_rcu()`) must add `landlock_blob_sizes.lbs_*` to the `void *` security pointer before casting to the struct pointer. [F107, F109]
