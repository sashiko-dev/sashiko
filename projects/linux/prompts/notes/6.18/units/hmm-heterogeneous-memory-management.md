# HMM - Heterogeneous Memory Management

Provides Heterogeneous Memory Management (HMM) address-space mirroring (`hmm_range_fault()`) and DMA mapping helpers (`hmm_dma_map_*`) in `mm/hmm.c`, along with the `test_hmm` pseudo-device driver (`lib/test_hmm.c`) exercising range faulting, `mmu_interval_notifier` invalidation, `migrate_vma_*` device memory migration (`MEMORY_DEVICE_PRIVATE` and `MEMORY_DEVICE_COHERENT`), and `make_device_exclusive()`.

## Architecture & Data Flow

- Every path in `mm/hmm.c` returning `-EBUSY` (`hmm_vma_fault()`, `hmm_vma_handle_pte()`, `hmm_vma_walk_pmd()`) must set `hmm_vma_walk->last` to the first address not yet written in `range->hmm_pfns`, because `hmm_range_fault()` restarts at `last` expecting entries `>= last` to still hold their input flags. [F34]
- Every path in `mm/hmm.c` writing output values to `range->hmm_pfns` (`hmm_pfns_fill()`, `hmm_vma_handle_pmd()`, `hmm_vma_handle_pte()`, `hmm_vma_handle_absent_pmd()`, `hmm_vma_walk_pud()`, `hmm_vma_walk_hugetlb_entry()`) must preserve sticky input flags by masking with `HMM_PFN_INOUT_FLAGS`, which must list all sticky `enum hmm_pfn_flags`. [F48]
- In `enum hmm_pfn_flags`, every `HMM_PFN_*` bit flag must be shifted from `1UL` at a bit position `>= HMM_PFN_ORDER_SHIFT + 5` so `HMM_PFN_FLAGS` masks all flags and the 5-bit order field while keeping flags disjoint from `(hmm_pfn >> HMM_PFN_ORDER_SHIFT) & 0x1F` in `hmm_pfn_to_map_order()`. [F82]
- In `hmm_vma_walk_pmd()`, `thp_migration_supported() && is_pmd_migration_entry(pmd)` must be checked before `!pmd_present(pmd)`, because PMD migration entries are non-present and `hmm_vma_handle_absent_pmd()` rejects non-device-private entries with `-EFAULT` or `HMM_PFN_ERROR` instead of waiting on migration and returning `-EBUSY`. [F73]
- In `hmm_vma_handle_pte()` and `hmm_vma_handle_absent_pmd()`, a non-present `is_device_private_entry()` swap entry may only be populated as `HMM_PFN_VALID` without faulting when `pgmap->owner == range->dev_private_owner`; entries with a different owner must be faulted via `hmm_vma_fault()` when `required_fault` is non-zero. [F49]
- In `hmm_pte_need_fault()`, `HMM_PFN_REQ_FAULT` must be checked on the effective request flags (`(pfn_req_flags & range->pfn_flags_mask) | range->default_flags`) before `HMM_PFN_REQ_WRITE`, returning 0 when `HMM_PFN_REQ_FAULT` is unset so write faults are never triggered without `HMM_PFN_REQ_FAULT`. [F70]
- `map->dma_list` in `struct hmm_dma_map` is allocated by `hmm_dma_map_alloc()` only when `!dma_use_iova(&map->state) && dma_need_unmap(dev)` and is `NULL` otherwise; `hmm_dma_map_pfn()` and `hmm_dma_unmap_pfn()` must check both conditions before indexing `map->dma_list`. [F38]
- In `dmirror_migrate_alloc_and_copy()`, `migrate_pfn_to_page(*src)` can return `NULL` even when `*src & MIGRATE_PFN_MIGRATE` is set (for `pte_none()` or read-only zero pages), so `spage` must be null-checked before calling `is_zone_device_page(spage)` or `copy_highpage(rpage, spage)`. [F41]
- In `lib/test_hmm.c`, `BACKING_PAGE(page)` obtains the CPU-accessible storage page for a `ZONE_DEVICE` page (`page->zone_device_data` when `is_device_private_page(page)`, or `page` itself for `MEMORY_DEVICE_COHERENT`). `dmirror_devmem_free()` must only call `__free_page(rpage)` when `rpage != page`, and for `MEMORY_DEVICE_PRIVATE`, `dmirror_migrate_alloc_and_copy()` and `dmirror_devmem_fault()` must access `struct dmirror *` via `rpage->zone_device_data` rather than `dpage->zone_device_data`. [F43, F81]
- In `dmirror_interval_invalidate()`, `MMU_NOTIFY_MIGRATE` invalidations may only be ignored when `range->owner == dmirror->mdevice`; events from other owners must still erase `dmirror->pt` entries so sibling `dmirror` instances do not keep stale mappings. [F56]
- `dmirror_min_ops` (`dmirror_interval_invalidate()`) downcasts `struct mmu_interval_notifier *` to `struct dmirror`, whereas `dmirror_mrn_ops` (`dmirror_snapshot_invalidate()`) downcasts to `struct dmirror_interval`; each ops table must only be registered with its matching container type. [F94]
- In `dmirror_range_fault()` and `dmirror_range_snapshot()`, the `hmm_range_fault()` / `mmu_interval_read_retry()` loop must check `time_after(jiffies, timeout)` on every iteration and abort with `-EBUSY` after `HMM_RANGE_DEFAULT_TIMEOUT`, and must only retry `hmm_range_fault()` errors when `ret == -EBUSY`. [F80]
- `dmirror_fault()`, `dmirror_snapshot()`, `dmirror_migrate_to_system()`, and `dmirror_migrate_to_device()` must clamp each iteration's subrange `end` to `addr + (ARRAY_SIZE(pfns) << PAGE_SHIFT)` (and to `vma->vm_end` in migration loops) to avoid overflowing fixed 32-element stack arrays. [F63]

## Synchronization

- `hmm_range_fault()` does not take page references on output PFNs. After it succeeds and `mmap_lock` is released, the caller must acquire its notifier `user_lock` (e.g., `dmirror->mutex`), verify `!mmu_interval_read_retry(range->notifier, range->notifier_seq)` (after `mmu_interval_read_begin()`), and keep that lock held while calling `hmm_pfn_to_page()` or `hmm_pfn_to_map_order()` on `HMM_PFN_VALID` entries and consuming `range->hmm_pfns`. [F4, F17]
- `dmirror->mutex` must not be held while calling `mmap_read_lock(mm)` or `hmm_range_fault()` in `dmirror_range_fault()` and `dmirror_range_snapshot()`, because `hmm_range_fault()` can trigger `dmirror_interval_invalidate()` or `dmirror_snapshot_invalidate()` which acquire `dmirror->mutex`. [F18]
- `mmu_interval_notifier_ops.invalidate` callbacks (`dmirror_interval_invalidate()`, `dmirror_snapshot_invalidate()`) must use `mutex_trylock(&dmirror->mutex)` and return `false` when `!mmu_notifier_range_blockable(range)` and contended, and must call `mmu_interval_set_seq(mni, cur_seq)` under `dmirror->mutex`. [F120]
- Because `hmm_vma_walk_pmd()` reads PMDs locklessly via `pmdp_get_lockless(pmdp)` without `pmd_lock`, it must re-read `pmdp_get_lockless(pmdp)` after observing `pmd_trans_huge(pmd)` or when `pte_offset_map()` returns `NULL` and restart at `again` if the PMD changed. [F107]
- Once `pud_trans_huge_lock()` returns a non-NULL `ptl` in `hmm_vma_walk_pud()`, `spin_unlock(ptl)` must be called before delegating to `hmm_vma_walk_hole()` or `hmm_vma_fault()` and before returning. [F3]
- When `hmm_vma_walk_hugetlb_entry()` needs to fault a page, it must unlock `ptl` via `spin_unlock(ptl)` and drop `hugetlb_vma_unlock_read(vma)` before calling `hmm_vma_fault()`, then re-acquire `hugetlb_vma_lock_read(vma)` before returning. [F103]
- In `struct dmirror_device`, `mdevice->devmem_lock` protects `devmem_chunks`, `devmem_count`, and `devmem_capacity`, while `mdevice->lock` nests inside `mdevice->devmem_lock` to protect `free_pages`, `calloc`, `cfree`, and `devmem->remove`. [F28]
- In `dmirror_fops_open()`, `dmirror->mdevice`, `dmirror->mutex`, and `dmirror->pt` must be initialized before `mmu_interval_notifier_insert()`, and in `dmirror_fops_release()`, `mmu_interval_notifier_remove(&dmirror->notifier)` must precede `xa_destroy(&dmirror->pt)` and `kfree(dmirror)`. Similarly, in `dmirror_range_snapshot()`, `notifier.dmirror = dmirror` must be set before `mmu_interval_notifier_insert(range->notifier, ...)`, and `mmu_interval_notifier_remove(range->notifier)` must be called on all exit paths before the stack-allocated `struct dmirror_interval notifier` goes out of scope. [F25, F26]
- In `dmirror_allocate_chunk()`, `devmem->mdevice = mdevice` must be assigned before linking the chunk's `struct page` entries into `mdevice->free_pages` or returning `*ppage`. [F30]

## Object Lifetimes

- In `hmm_vma_handle_pte()`, every non-zero return path must call `pte_unmap(ptep)` before sleeping or returning, whereas the zero return path (`out`) must leave `ptep` mapped so `hmm_vma_walk_pmd()` can continue iterating and unmap via `pte_unmap(ptep - 1)`. [F1]
- In `dmirror_device_remove_chunks()`, each `devmem` chunk must have `devmem->remove = true` and `dmirror_remove_free_pages(devmem)` executed under `mdevice->lock` before `dmirror_device_evict_chunk(devmem)` and `memunmap_pages(&devmem->pagemap)` so `dmirror_devmem_free()` does not return evicted pages to `mdevice->free_pages`; after freeing `mdevice->devmem_chunks`, `devmem_count`, `devmem_capacity`, `free_pages`, and `devmem_chunks` must be reset to zero/NULL under `mdevice->devmem_lock` (as both `HMM_DMIRROR_RELEASE` and `dmirror_device_remove()` call it). [F11, F12]
- In `dmirror_allocate_chunk()` and `dmirror_device_remove_chunks()`, `release_mem_region()` must only be called when `devmem->pagemap.type == MEMORY_DEVICE_PRIVATE`, because `MEMORY_DEVICE_COHERENT` chunks use `spm_addr_dev0`/`spm_addr_dev1` module parameters not reserved via `request_free_mem_region()`. [F13]
- Functions in `lib/test_hmm.c` using `dmirror->notifier.mm` (`dmirror_fault()`, `dmirror_exclusive()`, `dmirror_migrate_to_system()`, `dmirror_migrate_to_device()`, `dmirror_snapshot()`) must acquire `mmget_not_zero(mm)` before `mmap_read_lock(mm)` and call `mmap_read_unlock(mm)` before `mmput(mm)`. [F9]
- In `dmirror_exclusive()`, after `make_device_exclusive(mm, addr, NULL, &folio)` succeeds under `mmap_read_lock(mm)`, the caller must call `dmirror_atomic_map()` while `folio` is locked and then release both `folio_unlock(folio)` and `folio_put(folio)`. [F127]
- In `dmirror_fops_mmap()`, each page from `alloc_page()` must be freed with `__free_page(page)` if `vm_insert_page()` fails, or have its allocation reference dropped with `put_page(page)` after `vm_insert_page()` succeeds. [F15]

## API Contracts

- Callers of `hmm_range_fault()` must hold `range->notifier->mm->mmap_lock` (at least in read mode, asserted via `mmap_assert_locked(mm)`), and must size `range->hmm_pfns` for `(range->end - range->start) >> PAGE_SHIFT` `PAGE_SIZE` entries because `hmm_range_fault()` indexes `hmm_pfns` by `(addr - range->start) >> PAGE_SHIFT` even across PMD, PUD, or HugeTLB huge pages. [F88, F105]
- When populating `range->hmm_pfns` for a high-order mapping in `hmm_vma_handle_pmd()`, `hmm_vma_handle_absent_pmd()`, `hmm_vma_walk_pud()`, or `hmm_vma_walk_hugetlb_entry()`, every `PAGE_SIZE` entry across `[addr, end)` must be filled with its incrementing subpage PFN and the same protection and `hmm_pfn_flags_order()` flags. [F50]
- `hmm_walk_ops` must leave `.pte_entry` unset (handling both THP PMDs and PTE tables in `hmm_vma_walk_pmd()`), and `hmm_vma_walk_pud()` must set `walk->action = ACTION_CONTINUE` unless descending into a non-leaf PUD (`ACTION_SUBTREE`), so `walk_page_range()` does not split huge PUDs or PMDs. [F114]
- `hmm_vma_walk_test()` must permit `VM_MIXEDMAP` VMAs (rejecting only `VM_IO | VM_PFNMAP` or `!VM_READ`), and `hmm_vma_handle_pte()` must identify non-struct-page mappings via `!vm_normal_page(walk->vma, addr, pte) && !is_zero_pfn(pte_pfn(pte))` rather than `pte_special(pte)`. [F116]
- `hmm_dma_map_alloc()` requires callers to pass a non-zero `dma_entry_size` with `nr_entries * PAGE_SIZE >= dma_entry_size` (avoiding division by zero in `WARN_ON_ONCE(!(nr_entries * PAGE_SIZE / dma_entry_size))`), must return `-EOPNOTSUPP` when `dma_addressing_limited(dev)` or `CONFIG_DMA_NEED_SYNC && !dev->dma_skip_sync`, and must size `pfn_list`/`dma_list` to `nr_entries` elements while sizing the IOVA allocation to `nr_entries * PAGE_SIZE` bytes. [F84, F122]
- In `hmm_dma_map_pfn()` and `hmm_dma_unmap_pfn()`, `idx` is an element index into `map->pfn_list` and `map->dma_list`, whereas IOVA calls (`dma_iova_link()`, `dma_iova_sync()`, `dma_iova_unlink()`, `state->addr + offset`) must take the byte offset `idx * map->dma_entry_size`. [F90]
- In `hmm_dma_map_pfn()` and `hmm_dma_unmap_pfn()`, `hmm_dma_map_pfn()` must return the existing `state->addr + offset` or `dma_addrs[idx]` when `HMM_PFN_DMA_MAPPED` is already set without `HMM_PFN_P2PDMA_BUS` (and `dma_use_iova(state)` or `dma_need_unmap(dev)` holds); `hmm_dma_unmap_pfn()` must verify `HMM_PFN_VALID | HMM_PFN_DMA_MAPPED` and clear `HMM_PFN_DMA_MAPPED | HMM_PFN_P2PDMA | HMM_PFN_P2PDMA_BUS`; `HMM_PFN_P2PDMA_BUS` entries must skip IOVA/DMA linking, cached-address return on resync, and `dma_iova_unlink()`/`dma_unmap_phys()`; and `HMM_PFN_P2PDMA` entries must pass `DMA_ATTR_MMIO` on both map and unmap. [F5, F7, F123]
- When populating migration `dst` PFNs in `lib/test_hmm.c`, newly allocated system pages (`dmirror_devmem_fault_alloc_and_copy()`, `dmirror_device_evict_chunk()`) must be locked with `lock_page(dpage)`, whereas `ZONE_DEVICE` pages from `dmirror_devmem_alloc_page()` are already locked by `zone_device_page_init(dpage)`. [F126]

## Error Handling

- On an unwalkable VMA (`hmm_vma_walk_test()`), VMA hole (`hmm_vma_walk_hole()`), bad PMD (`hmm_vma_walk_pmd()`), absent non-owned PMD (`hmm_vma_handle_absent_pmd()`), non-normal non-zero PTE (`hmm_vma_handle_pte()`), or migration entry (`is_migration_entry()`, `is_pmd_migration_entry()`), `mm/hmm.c` must return `-EFAULT` (or wait/fault on migration) only when a fault was requested and otherwise fill `hmm_pfns` with `HMM_PFN_ERROR` or `0` (preserving `HMM_PFN_INOUT_FLAGS`) and return `0`. [F33, F124]
- In `hmm_dma_map_pfn()`, if IOVA linking, IOVA syncing, or `dma_map_phys()` fails after `PCI_P2PDMA_MAP_THRU_HOST_BRIDGE` sets `HMM_PFN_P2PDMA` on `map->pfn_list[idx]`, the error path must unlink any linked IOVA range, clear `HMM_PFN_P2PDMA`, leave `HMM_PFN_DMA_MAPPED` unset, and return `DMA_MAPPING_ERROR`. [F39]
- In `lib/test_hmm.c`, every `xa_store(&dmirror->pt, ...)` (`dmirror_do_fault()`, `dmirror_atomic_map()`, `dmirror_migrate_finalize_and_map()`) must check `xa_is_err(entry)` and return `xa_err(entry)`, while readers (`dmirror_do_read()`, `dmirror_do_write()`) must call `xa_untag_pointer(entry)` before dereferencing the page. [F40]
- In `dmirror_device_evict_chunk()`, the `src_pfns`, `dst_pfns`, and destination `struct page` allocations must use `__GFP_NOFAIL` because chunk eviction runs during device teardown (`dmirror_device_remove_chunks()`) and has no failure return path. [F42]
- In `dmirror_devmem_fault()` (`dev_pagemap_ops.migrate_to_ram` returning `vm_fault_t`), a non-zero error from `migrate_vma_setup(&args)` must be translated to `VM_FAULT_SIGBUS` rather than returning the negative errno directly. [F45]

## External Contracts

- `dmirror_fops_unlocked_ioctl()` must validate that `cmd.addr` is page-aligned (`cmd.addr & ~PAGE_MASK`) and `cmd.addr + (cmd.npages << PAGE_SHIFT) > cmd.addr` before dispatching any command, and each range handler must also check `end >= start` after truncation to `unsigned long`. [F62]
- In `dmirror_mkentry()`, the high nibble of the `HMM_DMIRROR_PROT_*` byte encodes mutually exclusive page types (`0x10`..`0x50`) while the low nibble holds bitwise-ORable flags (`READ`, `WRITE`, `PMD`, `PUD`), and `*perm` must be initialized with `=` before any `|=` because `dmirror_snapshot()` passes an uninitialized stack buffer. [F69]

## Known Pitfalls

- In `hmm_vma_handle_pte()`, when a present PTE has `!vm_normal_page(walk->vma, addr, pte) && !is_zero_pfn(pte_pfn(pte))`, it must re-call `hmm_pte_need_fault(hmm_vma_walk, pfn_req_flags, 0)` with `cpu_flags = 0` so fault requests fail with `-EFAULT` instead of succeeding with `HMM_PFN_ERROR`. [F72]
- Page mapping orders encoded into `hmm_pfns` entries must be shifted via `hmm_pfn_flags_order()` (which widens `order` to `unsigned long` before shifting by `HMM_PFN_ORDER_SHIFT`) and must fit in 5 bits (`order <= 0x1F`). Broken by: shifting a 32-bit `int`/`unsigned int` order directly by `HMM_PFN_ORDER_SHIFT`. [F83]
- Unlike virtual address ranges in `lib/test_hmm.c` (exclusive `end`), `struct dmirror_chunk`'s `pagemap.range` is a `struct range` with an inclusive `end`, so PFN counts must be computed via `range_len(&devmem->pagemap.range) >> PAGE_SHIFT` or `end_pfn - start_pfn + 1`. [F64]
