# X86 ARCHITECTURE (32-BIT AND 64-BIT)

This unit provides x86 host-side confidential computing support for AMD SEV-SNP (`arch/x86/virt/svm/`) and Intel TDX (`arch/x86/virt/vmx/tdx/`), PCI/framebuffer primary display detection (`arch/x86/video/video-common.c`), and user-space ELF relocation build tools (`arch/x86/tools/`). It initializes hardware security tables (RMP and TDMR/PAMT), manages private encryption KeyIDs and memory transitions, and exports SEAMCALL and RMP manipulation primitives.

## Architecture & Data Flow

- Before donating any host page (`tdr_page`, `tdvpr_page`, `tdcs_page`, `tdcx_page`, SEPT page, or TD private page) to the TDX module via SEAMCALL (`tdh_mng_create()`, `tdh_vp_create()`, `tdh_mng_addcx()`, `tdh_vp_addcx()`, `tdh_mem_sept_add()`, `tdh_mem_page_add()`, `tdh_mem_page_aug()`), wrappers must call `tdx_clflush_page()`. [F47]
- Stack `struct tdx_module_args` for SEAMCALLs must be zero-initialized via `{}` or designated initializers because `__seamcall*` loads all input registers (`rcx`, `rdx`, `r8`–`r11`). Similarly, `rmpupdate()` callers (`rmp_make_private()`, `rmp_make_shared()`) must `memset(&state, 0, sizeof(state))` on `struct rmp_state` so `rsvd` and unset fields passed to `RMPUPDATE` are zero. [F31, F32]
- Because `struct tdmr_info` ends with flexible array `reserved_areas`, elements in `tdmr_info_list.tdmrs` must be sized via `tdmr_size_single()` and indexed via `tdmr_entry()` using `tdmr_list->tdmr_sz`, never `sizeof(struct tdmr_info)` or pointer arithmetic. `alloc_tdmr_list()` must allocate with `__GFP_ZERO` so `fill_out_tdmrs()` sees `tdmr->size == 0` for unused slots and zeroed padding for `TDH.SYS.CONFIG`. [F33, F88]
- `tdmr_get_pamt_sz()` must `ALIGN(pamt_sz, PAGE_SIZE)` per page level before `tdmr_set_up_pamt()` sums `pamt_size[pgsz]` and shifts by `PAGE_SHIFT`. `TDX_PS_4K`, `TDX_PS_2M`, and `TDX_PS_1G` PAMTs are allocated as one contiguous range starting at `tdmr->pamt_4k_base`, which `tdmr_get_pamt()` and `tdmr_free_pamt()`/`free_pamt()` use with the sum of the three sizes to free the range. [F4, F86]
- Each `struct tdmr_reserved_area` added via `tdmr_add_rsvd_area()` must have `PAGE_SIZE`-aligned `offset` (relative to `tdmr->base`) and `size`, no overlaps, and be sorted before `TDH_SYS_CONFIG`. `tdmr_populate_rsvd_pamts()` must iterate over every consumed `tmp` in `tdmr_list`, clamp `tmp`'s PAMT range to `[tdmr->base, tdmr_end(tdmr))`, and append via the shared `rsvd_idx` cursor after `tdmr_populate_rsvd_holes()`. [F61, F73]
- In `config_tdx_module()`, `tdmr_pa_array` passed to `TDH_SYS_CONFIG` must have its allocation size rounded up to a power of two and clamped to at least `TDMR_INFO_PA_ARRAY_ALIGNMENT` (512 bytes) so `kzalloc()` returns a 512-byte-aligned physical address. [F62]
- TDX private KeyIDs start at `_nr_mktme_keyids + 1` with the first reserved as `tdx_global_keyid`; `tdx_guest_keyid_alloc()` allocates from inclusive `[tdx_guest_keyid_start, tdx_guest_keyid_start + tdx_nr_guest_keyids - 1]`. In `tdx_init()`, host TDX (`X86_FEATURE_TDX_HOST_PLATFORM`) must abort if `nr_tdx_keyids < 2` or `hibernation_available()` is true, and must set `acpi_suspend_lowlevel = NULL` when `CONFIG_ACPI` and `CONFIG_SUSPEND` are enabled. [F63, F106]
- In `paddr_is_tdx_private()`, `switch (args.rcx)` on `TDH_PHYMEM_PAGE_RDMD` page type must handle `PT_RSVD` by returning `is_pamt_page(phys)`, rather than `false` (`PT_NDA`) or `true` (`default`). [F76]
- In `get_tdx_sys_info_td_conf()`, `sysinfo_td_conf->num_cpuid_config` read from TDX metadata must be validated against `ARRAY_SIZE(sysinfo_td_conf->cpuid_config_leaves)` and `ARRAY_SIZE(sysinfo_td_conf->cpuid_config_values)` before populating those arrays. [F58]
- `struct rmpentry_raw` bitfields are only valid when `!cpu_feature_enabled(X86_FEATURE_RMPREAD)`. In that fallback, `get_rmpentry()` must zero-initialize `struct rmpentry *e` and shift `e_raw->gpa << PAGE_SHIFT` to match the `RMPREAD` byte-address format; when `X86_FEATURE_RMPREAD` is enabled, `get_rmpentry()` must use `RMPREAD` and `rmpentry_raw` may only be accessed via `lo` and `hi`. [F27, F43]
- In `get_raw_rmpentry()`, `rst_index` and `segment_index` derived from `pfn` must be bounds-checked against `rst_max_index` and `desc->max_index` (`segment_size / sizeof(*desc->rmp_entry)`, whereas `desc->size` is the byte length for `memset()`) and clamped with `array_index_nospec()`. Because `rmp_segment_table[i]` below `rst_max_index` can be `NULL`, all traversals (`get_raw_rmpentry()`, `free_rmp_segment_table()`, `snp_rmptable_init()`) must null-check `desc`. [F26, F52, F93]
- `set_rmp_segment_info()` must always be used to set `rmp_segment_shift` so `rmp_segment_size` (`1ULL << rmp_segment_shift`, using 64-bit `1ULL`) and `rmp_segment_mask` update in lockstep. For non-segmented RMP, `probe_contiguous_rmptable_info()` must set `rst_max_index = 1` and pass `RMPTABLE_NON_SEGMENTED_SHIFT` (52) so `RST_ENTRY_INDEX(paddr)` always resolves to 0. [F40, F81, F83]
- The first `RMPTABLE_CPU_BOOKKEEPING_SZ` (`0x4000`) bytes at `probed_rmp_base` are reserved for CPU bookkeeping, so contiguous RMP entries and the segmented `RST_SIZE` table must be mapped at `probed_rmp_base + RMPTABLE_CPU_BOOKKEEPING_SZ`. When reading RST entries in `fixup_e820_tables_for_segmented_rmp()` and `setup_segmented_rmptable()`, `RST_ENTRY_MAPPED_SIZE(rst[i]) << 30` must be clamped to `rmp_segment_size` before computing `PHYS_PFN(mapped_size) << 4`. [F53, F55]
- In `snp_probe_rmptable_info()`, `MSR_AMD64_RMP_CFG` must only be read if `cpu_feature_enabled(X86_FEATURE_SEGMENTED_RMP)`, and `probe_segmented_rmptable_info()` must verify `MSR_AMD64_RMP_SEGMENT_SHIFT(rmp_cfg)` against `cpuid_eax(0x80000025)` bounds. RMP coverage checks against `max_pfn` in `setup_contiguous_rmptable()` (using `PFN_UP(rmp_end)`) and `setup_segmented_rmptable()` must occur in `snp_rmptable_init()`, not early boot. [F96, F97]
- Before executing `RMPUPDATE`, `rmpupdate()` must call `adjust_direct_map(pfn, level)` to split overlapping 2MB+ direct-map entries when `level == PG_LEVEL_4K`, and retry while `RMPUPDATE` returns `RMPUPDATE_FAIL_OVERLAP`. In `adjust_direct_map()`, the `rmp_level == PG_LEVEL_2M` alignment and end-PFN check (`!IS_ALIGNED(pfn, PTRS_PER_PMD) || !pfn_valid(pfn + PTRS_PER_PMD - 1)`) must run before the `if (rmp_level == PG_LEVEL_2M) return 0;` early return. [F66, F99]
- When `init_sev_config()` parses `sev=nosnp` on bare metal (`!cpu_feature_enabled(X86_FEATURE_HYPERVISOR)`), it must clear both `X86_FEATURE_SEV_SNP` via `setup_clear_cpu_cap()` and `CC_ATTR_HOST_SEV_SNP` via `cc_platform_clear()`. [F44]
- In `arch/x86/tools/relocs.c`, `print_absolute_relocs()` and `walk_relocs()` must both skip sections where `!(sec_applies->shdr.sh_flags & SHF_ALLOC)` or `sec_applies->shdr.sh_type == SHT_NOTE`. In `do_reloc64()` and `do_reloc32()`, `shn_abs` must be `(sym->st_shndx == SHN_ABS) && !is_reloc(S_REL, symname)`. In `sym_index()`, `xsymtab` (`SHT_SYMTAB_SHNDX`) entries require `elf32_to_cpu(xsymtab[index])`, unlike `SHT_SYMTAB` entries byte-swapped in `read_symtabs()`. [F51, F64, F78]

## Synchronization

- Callers of `tdx_enable()` must hold `cpu_hotplug_lock` (`cpus_read_lock()`), establishing lock order `cpu_hotplug_lock` -> `tdx_module_lock` -> `mem_hotplug_lock` (`get_online_mems()` in `init_tdx_module()`). `init_tdx_module()` must hold `get_online_mems()` across both `build_tdx_memlist(&tdx_memlist)` and `free_tdx_memlist(&tdx_memlist)` on error rollback before `put_online_mems()`, synchronizing with `tdx_memory_notifier()` and `is_tdx_memory()`. [F12, F109]
- `tdx_sysinfo` and `tdx_module_status` are protected by `tdx_module_lock`: `init_tdx_module()` populates `tdx_sysinfo` before `__tdx_enable()` sets `tdx_module_status = TDX_MODULE_INITIALIZED` (or `TDX_MODULE_ERROR` on failure so later calls under `tdx_module_lock` fail with `-EINVAL` without retrying), and `tdx_get_sysinfo()` must hold `tdx_module_lock` while verifying `tdx_module_status == TDX_MODULE_INITIALIZED`. [F8, F14]
- `construct_tdmrs()` must execute `smp_wmb()` after populating `tdx_tdmr_list` and its PAMTs/reserved areas, and `is_pamt_page()` must execute a paired `smp_rmb()` before reading `tdmr_list->nr_consumed_tdmrs` and `tdmr_entry()`, because `tdx_dump_mce_info()` reads `tdx_tdmr_list` locklessly from #MC context. [F11]
- `tdx_cpu_enable()` must be called with interrupts disabled (`lockdep_assert_irqs_disabled()`) and must complete `try_init_module_global()` (which serializes one-time `TDH_SYS_INIT` and `sysinit_done`/`sysinit_ret` under `sysinit_lock`) before running `TDH_SYS_LP_INIT` and setting `tdx_lp_initialized`. [F15]
- `config_global_keyid()` must flush caches via `wbinvd_on_all_cpus()` before configuring the global KeyID, and must invoke `do_global_key_config` sequentially one physical package at a time via `smp_call_on_cpu(..., true)` using the `packages` bitmap. [F16]
- On CPUs with `X86_BUG_TDX_PW_MCE`, `tdx_quirk_reset_paddr()` and `tdx_quirk_reset_page()` must overwrite former TDX private memory in 64-byte steps using `movdir64b()` followed by `mb()`. On error rollback in `init_tdx_module()` after `config_tdx_module()` succeeds (`err_reset_pamts`), `wbinvd_on_all_cpus()` and `tdmrs_quirk_reset_pamt_all(&tdx_tdmr_list)` must run before `tdmrs_free_pamt_all()`. [F17, F102]
- In `snp_rmptable_init()`, when `MSR_AMD64_SYSCFG_SNP_EN` is not yet set, zeroing the RMP bookkeeping area and all `rmp_segment_table` entries must be followed by `wbinvd_on_all_cpus()`, then `on_each_cpu(mfd_enable, NULL, 1)`, and only then `on_each_cpu(snp_enable, NULL, 1)`. [F18]
- `snp_leaked_pages_list` and `snp_nr_leaked_pages` are protected by `snp_leaked_pages_list_lock`. In `__snp_leak_pages()`, the `while (npages--)` loop under that lock must advance `pfn++` and `page++` on every iteration while only linking `page->buddy_list` when `!PageCompound(page)` or `(PageHead(page) && compound_nr(page) <= npages)`. [F19, F70]

## Object Lifetimes

- `free_rmp_segment_table()` must unmap every populated `desc->rmp_entry`, free each `struct rmp_segment_desc`, free the `rmp_segment_table` page, and set `rmp_segment_table = NULL` so subsequent `get_raw_rmpentry()` calls return `ERR_PTR(-ENODEV)`. In `setup_segmented_rmptable()`, `rst_max_index` must not be narrowed to `max_index + 1` until after all segment allocations and `ram_pa_max > ram_pa_end` validation succeed so error cleanup covers all allocated indices. [F5, F6]

## API Contracts

- Internal TDX bring-up helpers (`seamcall_prerr()`, `seamcall_prerr_ret()`) convert SEAMCALL status codes to `int` (`0` or negative errnos), whereas exported `tdh_*` wrappers return raw 64-bit SEAMCALL status codes as `u64` (bit 63 is `TDX_ERROR`). `tdh_mem_sept_add()`, `tdh_mem_page_aug()`, `tdh_mem_range_block()`, and `tdh_mem_page_remove()` OR `level` directly into `args.rcx` (`gpa | level`), requiring a 0-based level from `pg_level_to_tdx_sept_level()`, not 1-based `enum pg_level`. [F23, F34]
- Helpers accepting `sc_func_t` (`__seamcall_dirty_cache()`, `sc_retry()`, `sc_retry_prerr()`) must be `__always_inline`, not `static inline`. `tdh_vp_enter()` is `noinstr` and must only call `noinstr`/`__always_inline` helpers (`__seamcall_dirty_cache`, `__seamcall_saved_ret`) and read precalculated `td->tdvpr_pa` rather than calling `page_to_phys()` or `seamcall_saved_ret()`. [F90, F113]
- `tdx_guest_keyid_alloc()` returns a positive KeyID or negative errno from `ida_alloc_range()`, so callers must store the result in a signed `int` and check `< 0`. `tdx_cpu_flush_cache_for_kexec()` must be called with preemption disabled (`lockdep_assert_preemption_disabled()`) after all SEAMCALLs on the local CPU have ceased. [F24, F118]
- Once `tdx_memlist` is populated (`!list_empty(&tdx_memlist)`), `tdx_memory_notifier()` must return `NOTIFY_BAD` on `MEM_GOING_ONLINE` whenever the range is not contained within `tdx_memlist` (`!is_tdx_memory(...)`). [F130]
- Host SEV-SNP paths in `arch/x86/virt/svm/sev.c` (`__mfd_enable`, `__snp_enable`, `snp_rmptable_init`, `__snp_lookup_rmpentry`, `psmash`, `rmpupdate`, `kdump_sev_callback`) must check `cc_platform_has(CC_ATTR_HOST_SEV_SNP)` rather than `X86_FEATURE_SEV_SNP`. [F95]
- `psmash()` returns negative kernel errnos and positive hardware `PSMASH` codes (e.g., `PSMASH_FAIL_INUSE`) in the same `int` (callers must not check only `< 0`), whereas `rmp_make_private()` and `rmp_make_shared()` translate all `RMPUPDATE` failures into negative errnos. `rmp_make_private(pfn, gpa, level, asid, immutable)` takes `pfn` as a PFN but `gpa` as an unshifted byte physical address. [F21, F35]
- In `__snp_lookup_rmpentry()`, after reading the target PFN's RMP entry into `e`, `*level` must be derived from a second `get_rmpentry(pfn & PFN_PMD_MASK, &e_large)` call (`RMP_TO_PG_LEVEL(e_large.pagesize)`), not from `e->pagesize`. In `alloc_rmp_segment_desc(segment_pa, segment_size, pa)`, `segment_pa` is the RMP segment table physical base to `memremap()`, whereas `pa` is the covered system memory base for `RST_ENTRY_INDEX(pa)`. [F37, F68]
- In `video_is_primary_device()`, `dev` must be checked with `dev_is_pci(dev)` before `to_pci_dev(dev)`, and checked with `pci_is_display(pdev)` before checking `vga_default_device()` or `screen_info_resources()`. [F107]

## Error Handling

- `construct_tdmrs()` calls `tdmrs_free_pamt_all(tdmr_list)` internally on failure, so `init_tdx_module()` must jump to `err_free_tdmrs` (not `err_free_pamts`) when `construct_tdmrs()` fails, and cleanup steps at `err_reset_pamts`..`err_free_tdxmem` must not overwrite `ret`. Because `tdmrs_free_pamt_all()` iterates over all `nr_consumed_tdmrs` on partial failure, `tdmr_do_pamt_func()` must keep `if (!pamt_size) return;`. [F3, F29, F30]
- `get_raw_rmpentry()` returns an `ERR_PTR`-encoded error (`-ENODEV` or `-EFAULT`) rather than `NULL` on failure, so callers (`get_rmpentry()`, `dump_rmpentry()`) must check `IS_ERR()` before dereferencing. [F22]

## External Contracts

- `check_features()` in `init_tdx_module()` must reject any TDX module whose `tdx_features0` lacks `TDX_FEATURES0_NO_RBP_MOD` so SEAMCALLs cannot clobber `RBP`. In `do_reloc64()` and `emit_relocs()`, 64-bit relocation offsets must fit in `int32_t` (`(int32_t)offset == (int64_t)offset`), and non-realmode tables (`relocs64`, `relocs32`) must be preceded by a `0` sentinel word (`write_reloc(0, stdout)`), whereas `--realmode` tables are preceded by their `count`. [F65, F114]

## Known Pitfalls

- In `init_tdmr()`, `struct tdx_module_args args` must be re-initialized inside the `do { ... } while` loop on every `TDH_SYS_TDMR_INIT` call with `.rcx = tdmr->base`, because `seamcall_prerr_ret()` overwrites `args` in place with output registers (`args.rdx` receives `next`). [F49]
- In `snp_rmptable_init()`, if `MSR_AMD64_SYSCFG_SNP_EN` is already set (e.g., on kexec boot), the kernel must still map the RMP table via `setup_rmptable()` and register the CPU hotplug callback, but must skip `clear_rmptable_bookkeeping()` and zeroing `desc->rmp_entry`. In `setup_segmented_rmptable()`, the 32-bit `unsigned int` index `i` must be cast to `u64` before shifting (`pa = (u64)i << rmp_segment_shift`). [F42, F80]
- In `arch/x86/tools/relocs.c`, `add_reloc()` reallocates `r->offset` via `realloc()`, so callers must never retain interior pointers into `relocs16.offset`, `relocs32.offset`, or `relocs64.offset` across `add_reloc()` calls. Format strings for `Elf_Ehdr`, `Elf_Shdr`, `Elf_Sym`, and `Elf_Rel` fields must use the `ELF_BITS`-conditional `FMT` macro or `ELF_BITS`-selected `PRIx64`/`PRIx32` specifiers. [F50, F92]
