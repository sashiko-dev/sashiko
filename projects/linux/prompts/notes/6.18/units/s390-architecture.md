# S390 ARCHITECTURE

This unit provides core s390 architecture headers (`arch/s390/include/asm/`), UAPI definitions (`arch/s390/include/uapi/asm/`), and core kernel implementations (`arch/s390/kernel/`), covering lowcore prefix pages, MMU/ASCE context switching, TLB flushing, user-space memory access (`mvcos`), preemption, TOD clock, Ultravisor calls, zPCI/CLP/SCSW hardware interfaces, DIAG 0x320 certificate store keyring management, 31-bit compat syscalls/signals, CPU cache topology, and runtime instruction alternatives.

## Architecture & Data Flow

- In `init_new_context()`, `mm->context.asce_limit` must be updated in lockstep with `_ASCE_TYPE_REGION*` in `mm->context.asce` and `_REGION*_ENTRY_EMPTY` passed to `crst_table_init((unsigned long *)mm->pgd, init_entry)`; the `default` branch is valid only when `asce_limit == 0` (`VM_BUG_ON(mm->context.asce_limit)`), setting `_REGION2_SIZE` and falling through. Under `CONFIG_PGSTE`, `init_new_context()` must set `allow_cow_sharing = 1` while clearing `has_pgste`, `uses_skeys`, `uses_cmm`, and `allow_gmap_hpage_1m`. [F36, F37, F77]
- `switch_mm_irqs_off()` must unconditionally reload `get_lowcore()->user_asce` from `next->context.asce` (or `s390_invalid_asce` for `init_mm`), set `cpu` in `next->context.cpu_attach_mask`, and clear CR1/CR7 even when `prev == next`, while clearing `cpu` from `prev->context.cpu_attach_mask` only when `prev != next`. Broken by: early `if (prev == next) return;` or unconditionally clearing `cpu` from `prev`. [F38]
- In `__tlb_flush_mm()`, if `cpu_has_idte()` is true and `READ_ONCE(mm->context.gmap_asce) != -1UL`, both `gmap_asce` (if non-zero) and `mm->context.asce` must be flushed via `__tlb_flush_idte()`; `gmap_asce == -1UL` requires falling back to `__tlb_flush_global()`. [F40]
- `get_lowcore()->preempt_count` stores `PREEMPT_NEED_RESCHED` (`0x80000000`) with inverted polarity (set when reschedule is not needed, cleared by `set_preempt_need_resched()`); `preempt_count_set()` must preserve `old & PREEMPT_NEED_RESCHED` via `arch_try_cmpxchg()` and `preempt_count()` must mask it out. [F41]
- In `compat_signal.c`, `store_sigregs()` must flush live ACR/FPU regs into `current->thread` before `save_sigregs32()`/`save_sigregs_ext32()`. On `compat_sys_sigreturn`/`compat_sys_rt_sigreturn`, `save_user_fpu_regs()` must precede `restore_sigregs32()`, which must run before `restore_sigregs_ext32()` (since `restore_sigregs32()` zero-extends 64-bit `regs->gprs[i]` while `restore_sigregs_ext32()` writes the high 32-bit half and `vxrs[i].low` in place), followed by `load_sigregs()`. [F45, F46]
- `restore_sigregs32()` must preserve non-user bits in `regs->psw.mask` (like `PSW_MASK_PER`) by masking with `~(PSW_MASK_USER | PSW_MASK_RI)`, reject `PSW32_MASK_RI` when `!is_ri_task(current)`, and rewrite `PSW_ASC_HOME` to `PSW_ASC_PRIMARY`. `setup_frame32()` and `setup_rt_frame32()` must subtract `sizeof(__reserved)` from `frame_size` and, when `!cpu_has_vx()`, also subtract `sizeof(vxrs_low) + sizeof(vxrs_high)` and omit `UC_VXRS` from `uc_flags`, matching `save_sigregs_ext32()`. [F47, F48]
- `local_mcck_restore(mflags)` must sample the live PSW mask via `__extract_psw()`, clear `PSW_MASK_MCHECK`, and OR in `mflags` before `__load_psw_mask()`, rather than restoring a full PSW mask snapshot from `__local_mcck_save()` / `local_mcck_save()`. [F53]
- In `raw_copy_from_user()`, `raw_copy_to_user()`, and `__clear_user()`, `osize = size` must be saved at the start of every `while (1)` iteration before `mvcos`, returning `osize - size` when `CC_TRANSFORM(cc) == 0` before decrementing `size` by 4096. [F83]
- In `__apply_alternatives()` and `runtime_const_fixup()`, `a->instr_offset`, `a->repl_offset`, and `*start` are signed byte offsets relative to the offset field's own address (cast field pointer to `u8 *` or `void *` before adding). `__apply_alternatives()` must scan `struct alt_instr` entries in forward order from `start` to `end` via `s390_kernel_write()` so later entries can overwrite earlier ones. [F103, F138]
- In `call_on_stack()` and `call_nodat()`, `CALL_FMT_0..5` and `CALL_CLOBBER_0..5` must mark all parameter registers (`%r2`–`%r6`) as modified (`+&d`/`=&d` or clobbers) across `brasl`/`lpswe`, and `CALL_LARGS_N` must cast `(long)(tN)(aN)` using the exact parameter type `tN` to sign- or zero-extend narrow arguments. [F97, F134]
- `on_stack()` must check `addr + len < addr` for unsigned wrap and then test `addr + len <= info->end` (inclusive, as `struct pt_regs` sits at `addr + len == info->end`). [F57]
- In `struct os_info`, `entry[OS_INFO_MAX]` and `reserved` must be adjusted in lockstep by `sizeof(struct os_info_entry)` (20 bytes) so `sizeof(struct os_info)` remains `PAGE_SIZE` (4096). CLP response structs (`struct clp_rsp_set_pci`, `struct clp_rsp_query_pci`) must retain trailing firmware fields like `struct mio_info mio`. [F54, F69]

## Synchronization

- `__tlb_flush_mm()` must disable preemption and keep `mm->context.flush_count` incremented across copying `mm->context.cpu_attach_mask` into `mm_cpumask(mm)`, a compiler `barrier()`, reading `mm->context.gmap_asce` with `READ_ONCE()`, and the IDTE/global flush. `__tlb_flush_mm_lazy()` must hold `mm->context.lock` across checking `mm->context.flush_mm`, clearing it to 0, and calling `__tlb_flush_mm(mm)`. [F12, F13]
- `finish_arch_post_lock_switch()` must spin while `atomic_read(&mm->context.flush_count)` is non-zero (with preemption disabled) before setting `smp_processor_id()` in `mm_cpumask(mm)` and calling `__tlb_flush_mm_lazy(mm)`. Both `switch_mm_irqs_off()` and the CR1/CR7 loads in `finish_arch_post_lock_switch()` must run with local IRQs disabled. [F39, F127]
- Callers of `__get_tod_clock_monotonic()` must run with preemption disabled (or use `get_tod_clock_monotonic()`, which wraps it in `preempt_disable_notrace()`/`preempt_enable_notrace()`) because `tod_clock_base` is updated via `stop_machine`. Callers of `test_cpu_flag_of(flag, cpu)` must prevent CPU hotplug on `cpu` (e.g., by disabling preemption). [F17, F126]
- In `cert_store.c`, `cs_refresh_lock` must be held in `refresh_store()` across `fill_cs_keyring()` (retrying up to `DIAG_MAX_RETRIES` times when `get_sevcb()` returns `-EAGAIN` on `DIAG320_RC_CS_NOMATCH` or `remaining_vc_count != 0`) and updating `cs_status_val`. Every failed or refreshed attempt in `fill_cs_keyring()` and `create_cs_keyring()` must purge prior keys via `cleanup_cs_keys()`; if `invalidate_keyring_keys()` fails in `cleanup_cs_keys()`, `key_type_cert_store_key` must be unregistered and re-registered in `create_cs_keyring()`. [F19, F49, F114]

## Object Lifetimes

- When `abs_lowcore_map()` fails part-way through mapping `LC_PAGES` pages, it must only unmap already-mapped pages via `vmem_unmap_4k_page()` if `alloc` is true, and leave page tables mapped when `alloc` is false because `vmem_unmap_4k_page()` may sleep while `alloc == false` callers run in atomic context. [F1]
- In `pgalloc.h`, `pmd_alloc_one_noprof()` must call `crst_table_free(mm, table)` if `pagetable_pmd_ctor()` fails, and `p4d_free()`, `pud_free()`, `pmd_free()`, and `pgd_free()` must call `pagetable_dtor(virt_to_ptdesc(...))` before `crst_table_free()` (unless folded). [F7]
- `get_user_session_keyring()` (which returns `ERR_PTR(-ENOKEY)` on failure) and `find_cs_keyring()` (which translates `IS_ERR()` from `request_key()` to `NULL`, as `create_cs_keyring()` does for `keyring_alloc()`) drop their lookup reference (`key_ref_put()`/`key_put()`) before returning, so callers receive a borrowed `struct key *` and must not call `key_put()` on it. [F2, F21]
- `get_key_description()` allocates a `kmalloc()` buffer of `sizeof(vc_name) + 1 + 5 + 1 + 10 + 1` bytes, keeping the 64-byte (`VC_NAME_LEN_BYTES`) EBCDIC `vc_name` followed at offset `VC_NAME_LEN_BYTES` by `snprintf(..., ":%05u:%010u", ...)` (which `cert_store_key_describe()` reads at `&key->description[VC_NAME_LEN_BYTES]`). `create_key_from_vce()` must call `key_ref_put(newkey)` on success and `kfree(desc)` on all paths. [F5, F64, F106]

## API Contracts

- `cmpxchg_user_key()` returns `0` whenever `cmpxchg` executed (even on comparison mismatch), `-EFAULT` on access exception (setting `*uval = 0`), or `-EAGAIN` when byte/short retries are exhausted; callers must also check `*uval == old` and pass an aligned `ptr`. `__get_user_<type>_noinstr()` and `__put_user_<type>_noinstr()` must not call `instrument_get_user()`/`instrument_put_user()`/`might_fault()`, and `__get_user_*_noinstr()` must zero `*to = 0` on fault in both `asm goto` and non-`asm goto` paths. [F24, F25, F124]
- `uv_call()` and `uv_call_sched()` loop while `__uv_call()` returns `> 1` (`UVC_CC_BUSY` or `UVC_CC_PARTIAL`), and `uv_call_sched()` calls `cond_resched()` so it (and callers like `uv_cmd_nodata()` and `uv_list_secrets()`) must only run in sleepable context. `uv_cmd_nodata()` unconditionally dereferences `rc` and `rrc` and returns `-EINVAL` on non-zero CC, whereas `uv_list_secrets()` allows `NULL` `rc`/`rrc` and returns the raw UVC `cc`. [F26, F116]
- `zpci_get_max_io_size()` must bound transfers by `min3(len, ZPCI_BOUNDARY_SIZE - offset, max)` so `dst` never crosses a 4K boundary, allow block sizes `> 8` only when `src`, `dst`, and `size` are 8-byte aligned, and otherwise cap at 8 bytes or `rounddown_pow_of_two(size)`. `zpci_use_mio()` requires both `static_branch_likely(&have_mio)` and `zdev->mio_capable`. `struct pci_dev` is not embedded in `struct zpci_dev`; `to_zpci()`/`to_zpci_dev()` index `((struct zpci_bus *)pdev->sysdata)->function[pdev->devfn]`, which can be `NULL`. [F105, F109, F111]
- Functions called via `call_nodat()` run at a physical address with `PSW_MASK_DAT` clear and without a valid DAT-off stack pointer in `%r15`, so `fn` must not access the stack via `%r15`, and `psw_leave` must remain `__aligned(16)` so `lpswe 0(7)` never crosses a page boundary. [F135]
- Any s390 `get_unmapped_area` callback returning `[addr, addr + len)` up to `TASK_SIZE` must call `check_asce_limit(mm, addr, len)` so `crst_table_upgrade()` upgrades page table levels when `addr + len > mm->context.asce_limit`. For memory attribute changes on regions that may exceed 8TB, use `__set_memory_*` `(void *start, void *end)` (`unsigned long numpages`) instead of `set_memory_*` (`int numpages`). [F93, F147]
- Under `CONFIG_COMPAT`, when `test_tsk_thread_flag(task, TIF_31BIT)` is set, `syscall_get_error()` must sign-extend `regs->gprs[2]` via `(long)(int)` before `IS_ERR_VALUE()`, and `syscall_get_arguments()` must mask argument registers with `0xffffffff`. [F154]
- `READ_ONCE_ALIGNED_128(x)` requires `x` to be 16-byte aligned in memory in addition to `sizeof(x) == 16` (`lpq` specification exception). `memset16()`, `memset32()`, and `memset64()` take an element count, whereas `__memset16()`, `__memset32()`, and `__memset64()` take a byte count. [F72, F99]

## Error Handling

- In `fill_cs_keyring()`, verify `sclp.has_diag320` and subcodes 1 and 2 via `test_bit_inv(1, ism)` and `test_bit_inv(2, ism)`, and explicitly set `rc = -ENOMEM` before calling `create_cs_keyring()` and jumping to `cleanup_keys` on `NULL`, because `query_diag320_subcodes()` and `get_vcssb()` overwrite `rc` with `0`. [F20, F112]
- In `add_certificates_to_keyring()`, iterate 1-based VCE indices `1..vcssb->total_vc_index_count` (with VCB buffer and `vcb_hdr.vcb_input_length` rounded up to `PAGE_SIZE` via `get_4k_mult_vcb_size(vcssb)`), abort the loop immediately on `-EAGAIN` from `create_key_from_sevcb()` while skipping other errors, and seal the keyring with `keyring_restrict()`. [F62, F82, F148]
- `zpci_read_u64()`, `zpci_read_u32()`, `zpci_read_u16()`, and `zpci_read_u8()` must return all-ones (`(RETTYPE)-1ULL`) when `zpci_load()` returns a non-zero condition code. In `share()` (`uv.h`), unaligned `addr` (`addr & ~PAGE_MASK`) must trigger `BUG_ON()`, and `uv_call()` failure for `UVC_CMD_SET_SHARED_ACCESS` or `UVC_CMD_REMOVE_SHARED_ACCESS` must call `panic()`. [F110, F155]

## External Contracts

- In 31-bit compat code, `__SC_COMPAT_CAST` and `A()` must mask pointer values with `0x7fffffff` (`0x7FFFFFFFUL`) while casting `long` and `unsigned long` via `(s32)` and `(u32)`. In `s390_pread64`, `s390_pwrite64`, `s390_read`, and `s390_write`, `compat_size_t count` must be rejected with `-EINVAL` if `(compat_ssize_t)count < 0` before widening to `size_t`. [F90, F92]
- `s390_old_mmap` requires `!(a.offset & ~PAGE_MASK)` and passes `a.offset >> PAGE_SHIFT` to `ksys_mmap_pgoff()`, whereas `s390_mmap2` passes `a.offset` unshifted. In `s390_fadvise64` and `s390_fadvise64_64`, `advise` values `4` and `5` must be translated to `POSIX_FADV_DONTNEED` and `POSIX_FADV_NOREUSE`. In `cp_stat64()`, `struct stat64_emu31 tmp` must be zeroed with `memset(&tmp, 0, sizeof(tmp))` so padding fields do not leak stack bytes. [F32, F150, F151]
- In `struct lowcore`, fields in `0x0e00`–`0x0f00` (`ipib` at `0x0e00`, `ipib_checksum` at `0x0e08`, `vmcore_info` at `0x0e0c`, `os_info` at `0x0e18`) must never shift offset (used by dump/re-IPL tools), and fixed-address `return_lpswe`/`return_mcck_lpswe` trampolines plus `INIT_THREAD` setting `thread_struct.last_break = 1` must remain to avoid leaking KASLR addresses via BEAR. [F137, F144]

## Known Pitfalls

- `init_idle_preempt_count(p, cpu)` and `init_task_preempt_count(p)` in `preempt.h` must remain no-ops that do not write `get_lowcore()->preempt_count`, because `get_lowcore()` accesses the calling CPU's lowcore rather than `cpu`'s lowcore. [F42]
- Hardware/firmware bitmaps in `unsigned long` words—such as `uv_info.uv_feature_indications` in `uv_has_feature()`, `uv_info.inst_calls_list`, and DIAG 0x320 `ism` in `query_diag320_subcodes()`—use big-endian MSB-0 bit numbering and must be tested with `test_bit_inv()` after bounds-checking. `uv_cb_qui.max_guest_cpu_id` and `uv_info.max_guest_cpu_id` store the 0-based maximum guest CPU ID (`N - 1`), not the VCPU count `N`. [F59, F61]
- In `struct vce`, `vce_hdr.vc_offset` and `vce_hdr.vc_hash_offset` are byte offsets from `(u8 *)vce`, not from `vce->cert_data_buf`. `vce_hdr.vc_name` is a 64-byte (`VC_NAME_LEN_BYTES`) non-NUL-terminated EBCDIC field; converting it to ASCII requires a `VC_NAME_LEN_BYTES + 1` buffer, `EBCASC_500(..., VC_NAME_LEN_BYTES)`, and NUL termination. [F63, F107]
- In `compat_linux.c` syscalls with split 64-bit args (`s390_truncate64`, `s390_ftruncate64`, `s390_pread64`, `s390_readahead`, `s390_sync_file_range`, `s390_fallocate`), cast the `high` word to 64 bits before `<< 32` and combine with an unsigned `u32` `low` word. [F91]
- In `struct physmem_info`, only the first `MEM_INLINED_ENTRIES` (255) online ranges are in `online[]` while `n >= MEM_INLINED_ENTRIES` are in `online_extended[n - MEM_INLINED_ENTRIES]`; always use `__get_physmem_range()`. In `cache.c`, `ecag()` and `ct.ci[level]` use 0-based levels `[0, CACHE_MAX_LEVEL)` while `this_leaf->level` is 1-based (`level + 1`), and `CACHE_TYPE_SEPARATE` populates two `this_leaf` entries (`CACHE_TYPE_DATA` and `CACHE_TYPE_INST`). [F71, F74]
- `zpci_memset_io()` calls `kmalloc(count, GFP_KERNEL)` and must not be called from atomic context. [F123]
