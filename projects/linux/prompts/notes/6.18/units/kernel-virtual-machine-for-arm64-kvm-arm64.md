# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64)

This unit implements the host-side kernel infrastructure and EL2 hypervisor engine for KVM on arm64 (`arch/arm64/kvm/` and `arch/arm64/include/`), managing VM/vCPU lifecycles, system registers, timers, nested Stage-1 (`AT`) emulation, VHE/nVHE world switches, Stage-1/Stage-2 page tables, and Protected KVM (pKVM) isolation, PSCI relay, and FF-A proxying.

## Architecture & Data Flow
- In `enum vcpu_sysreg`, `kvm_sysreg_masks::mask` is indexed by `r - __SANITISED_REG_START__` while `kvm_cpu_context::vncr_array` is indexed by `r - __VNCR_START__`; registers after `MARKER(__VNCR_START__)` must use `VNCR(r)`. `IDREG_IDX(id)` only indexes `kvm_arch::id_regs` for `1 <= crm < 8` (`CRm == 0` or `CTR_EL0` must use `__vm_id_reg()`). [F77, F78, F81]
- Optional Stage-1 registers (`SYS_TCR2`, `SYS_PIR`, `SYS_PIRE0`, `SYS_POR`, `SYS_POR_EL0`, `SCTLR2_EL1`) and `HCRX_EL2` bits in `__kvm_at_s1e01_fast()`, `vcpu_set_hcrx()`, and `sysreg-sr` must check per-VM `kvm_has_*()` / `ctxt_has_*()` helpers, not just host CPU caps. [F137, F320, F347]
- In `vcpu->arch.iflags`, `INCREMENT_PC` overlaps `EXCEPT_MASK`, making `kvm_incr_pc()` and `kvm_pend_exception()` mutually exclusive; `kvm_arch_vcpu_ioctl_run()` must invoke `__kvm_adjust_pc` before `vcpu_put()`, and `__kvm_adjust_pc()` must clear `PENDING_EXCEPTION`/`EXCEPT_MASK` or `INCREMENT_PC`. [F69, F263]
- Because `to_hw_pstate()` maps virtual `PSR_MODE_EL2t/h` to `PSR_MODE_EL1t/h`, `__compute_hcr()` sets `VCPU_IN_HYP_CONTEXT` and `fixup_guest_exit()` must restore `PSR_MODE_EL2*` before exit handlers check `is_hyp_ctxt(vcpu)`. When `vcpu_has_nv(vcpu)` and `is_hyp_ctxt(vcpu)` hold, `__compute_hcr()` must only merge RES1 bits from `kvm_vcpu_apply_reg_masks(vcpu, HCR_EL2, 0)` (`~NV_HCR_GUEST_EXCLUDE`), never raw `__vcpu_sys_reg(vcpu, HCR_EL2)`. [F252, F253]
- For physical timers or when `has_broken_cntvoff()` is true, `timer_save_state()` must subtract `timer_get_offset(ctx)` from `CVAL` and zero `cntpoff`/`cntvoff`, while `timer_restore_state()` writes `offset` (or `0` for broken `cntvoff`) and `cval + offset`, with `isb()` between `CVAL` and `CTL` writes and between disabling `CTL` and zeroing the offset. [F61, F139, F140]
- In `timer_emulate()`, `kvm_timer_update_irq()` must not return early before `kvm_timer_update_status()` and `soft_timer_start()`. In `kvm_timer_sync_nested()`, when `!cpus_have_final_cap(ARM64_HAS_ECV)`, only `map.emul_vtimer` and `map.emul_ptimer` from `get_timer_map()` may be canceled and re-emulated. Runtime loops over `timer_cpu.timers` must bound by `nr_timers(vcpu)`, and `TIMER_REG_TVAL` uses `lower_32_bits()` on read and `(s32)val` on write. [F59, F60, F89, F90]
- In nVHE `__kvm_vcpu_run()`, `__debug_save_host_buffers_nvhe()` + `dsb(nsh)` must precede guest MMU/`mdcr_el2` loads, and `__debug_restore_host_buffers_nvhe()` must follow `__sysreg_restore_state_nvhe(host_ctxt)`. `__sysreg32_restore_state(vcpu)` must precede 64-bit sysreg restore (and `__load_stage2()` in nVHE), and on nVHE with `ARM64_WORKAROUND_SPECULATIVE_AT`, `TCR_EPD*` must disable Stage-1 walks with `SCTLR_ELx_M` on across Stage-2 switches. [F322, F323, F324]
- When `guest_owns_fp_regs()` and `vcpu_has_sve(vcpu)` hold, `fpsimd_lazy_switch_to_{guest,host}()` must eagerly switch `SYS_ZCR` at EL1/EL2, while nVHE `__hyp_sve_*` helpers clamp `SYS_ZCR_EL2` to `kvm_host_sve_max_vl` or `vcpu_sve_max_vq(vcpu)`. `__activate_cptr_traps()` must dynamically write `cptr_el2`/`cpacr_el1`, and `isb()` must follow `__deactivate_cptr_traps()`/`__deactivate_traps()` before touching FP/SVE/FPMR/`FPEXC32_EL2`. [F250, F251, F268, F346]
- In `__vgic_v3_activate_traps()`, check `!(cpu_if->vgic_hcr & ICH_HCR_EL2_En)` before `!cpu_if->vgic_sre`; when `!cpu_if->vgic_sre` (GICv2 MMIO mode), clear `ICC_SRE_EL1` with `isb()` before writing `ICH_VMCR_EL2` and calling `__vgic_v3_restore_state()`, and bracket `ICH_LR*`/`ICH_VMCR_EL2`/`ICH_ELRSR_EL2` accesses with `dsb(sy)` + `isb()` on save and `isb()` + `dsb(sy)` on restore. [F289, F326, F327]
- In pKVM, `host_stage2_set_owner_locked()` must update both `host_mmu.pgt` owner annotations and `hyp_vmemmap` state under `host_mmu.lock`; `host_stage2_force_pte_cb()` must force PTE mappings for non-default protections; `__pkvm_host_{share,unshare}_guest()` must update `host_share_guest_count`, `set_host_state()`, and guest Stage-2 PTEs in lockstep; and `flush_hyp_vcpu()`/`handle___pkvm_vcpu_load()` must only copy `HCR_TWI | HCR_TWE` from `host_vcpu->arch.hcr_el2` while syncing debug state. [F249, F255, F256, F257, F267]

## Synchronization
- Host lock order is `kvm->lock` -> `vcpu->mutex` -> `kvm->arch.config_lock`. `config_lock` serializes `__kvm_vcpu_set_target()`, `kvm_arm_timer_set_attr()` (rejecting changes with `-EBUSY` once `KVM_ARCH_FLAG_TIMER_PPIS_IMMUTABLE` is set), and `kvm->arch.mpidr_data` updates (`rcu_assign_pointer()`/`synchronize_rcu()`, paired with `rcu_read_lock()`/`rcu_dereference()` in `kvm_mpidr_to_vcpu()`). [F21, F32, F154, F185]
- pKVM EL2 lock order is `vm_table_lock` -> `host_lock_component()` (`host_mmu.lock`) -> `hyp_lock_component()` (`pkvm_pgd_lock`) or `guest_lock_component(vm)` (`vm->lock`). `vm_table_lock` guards `vm_table`, `hyp_vm` refcounts, `loaded_hyp_vcpu`, and `hyp_vm->vcpus[]`; `host_mmu.lock` guards `__host_state` and `host_share_guest_count`; `pkvm_pgd_lock` guards `pkvm_pgtable`, `__io_map_base`, and `__hyp_state_comp`; `guest_lock_component(vm)` sets per-CPU `current_vm` and must bracket any `vm->pgt` walk using `vm->mm_ops`. [F198, F214, F215, F217, F218, F220]
- In `kvm_arch_vcpu_ioctl_run()`, set `vcpu->mode = IN_GUEST_MODE` via `smp_store_mb()` after `local_irq_disable()` and before `kvm_vcpu_exit_request()`; keep `kvm_arm_vcpu_enter_exit()` `noinstr`; and on exit (IRQs off), run `kvm_pmu_sync_hwstate()` -> `kvm_vgic_sync_hwstate()` -> `kvm_timer_sync_{user,nested}()` before `local_irq_enable()`. [F19, F146, F156]
- `vcpu->arch.{cflags,iflags,sflags}` use non-atomic RMW with preemption disabled and must only be mutated by the owning vCPU. Cross-CPU `HCR_VI`/`HCR_VF` changes in `vcpu_interrupt_line()` require atomic `test_and_{set,clear}_bit()` on `*vcpu_hcr(vcpu)` plus `KVM_REQ_IRQ_PENDING` and `kvm_vcpu_kick()`. `vcpu->arch.mp_state` writes require `mp_state_lock` and `WRITE_ONCE()` (paired with `READ_ONCE()`), and `kvm_vcpu_sleep()` requires `smp_rmb()` after `rcuwait_wait_event()`. [F22, F23, F24, F25]
- Pair `kvm_pgtable_walk_begin()` with `kvm_pgtable_walk_end()` to balance the RCU read lock for `KVM_PGTABLE_WALK_SHARED` (forbidden in EL2 hyp context). When installing valid PTEs in `hyp_map_walker*` or `stage2_make_pte()`, child table init, cache maintenance (after `stage2_try_break_pte()`), and `mm_ops->get_page(ctx->ptep)` must precede `smp_store_release(ctx->ptep, new)`. [F14, F158, F211, F223, F349]
- In `at.c`, hardware `AT` in `__kvm_at_s1e01_fast()`/`__kvm_at_s1e2()` must hold `write_lock_irqsave(&vcpu->kvm->mmu_lock)` and restore `HCR_HOST_VHE_FLAGS` before `__mmu_config_restore()`, while `walk_s1()` in `handle_at_slow()` requires sleepable context under `srcu_read_lock(&vcpu->kvm->srcu)`. On Stage-2 faults, `kvm_fault_lock()` must take `kvm->mmu_lock` for write when `is_protected_kvm_enabled()` is true. [F33, F38, F70, F159]
- `timer_{save,restore}_state()` must disable local IRQs (`local_irq_save()`), and `kvm_arm_timer_{read,write}_sysreg()` must wrap them in `preempt_disable()`. On VHE, `__vcpu_{load_activate,put_deactivate}_traps()` and `{enter,exit}_vmid_context()` (clearing/restoring `HCR_TGE` with `isb()`) must disable local IRQs. In `kvm_arch_timer_handler()`, check `if (!vcpu)` before dereferencing `*dev_id`. [F27, F149, F344, F345]
- In pKVM `ffa.c`, hold `host_buffers.lock` across `memcpy()` from `host_buffers.tx` to `hyp_buffers.tx`, parsing, `ffa_host_share_ranges()`, and the SMC; set `has_version_negotiated` via `smp_store_release()` under `version_lock` (paired with `smp_load_acquire()` in `kvm_host_ffa_handler()`). Snapshot shared `host_kvm`/`host_vcpu` fields in EL2 with `READ_ONCE()`. [F208, F219, F224, F258]

## Object Lifetimes
- In `kvm_arch_vcpu_load()`, `kvm_vcpu_load_hw_mmu()` must precede reading `vcpu->arch.hw_mmu` (cleared by `kvm_vcpu_put_hw_mmu()` after `kvm_vcpu_put_vhe()`), `kvm_arm_vmid_update()` and `__kvm_flush_cpu_context` must precede `kvm_vcpu_load_vhe()`, `kvm_timer_vcpu_load()` must precede `kvm_vgic_load()`, and `kvm_vcpu_load_debug()` must precede `kvm_vcpu_load_vhe()`. In `kvm_vcpu_wfi()`, set `IN_WFI` and call `kvm_vgic_put()` before `kvm_vcpu_halt()`, then clear `IN_WFIT`/`IN_WFI` and call `kvm_vgic_load()` on wakeup. [F7, F8, F16, F74, F143, F155]
- `stage2_pte_is_counted()` counts valid and non-zero invalid PTEs, so Stage-2 PTE updates must balance `get_page()`/`put_page()` on `ctx->ptep` (and `put_page(childp)` if `stage2_try_break_pte()` fails). In `nvhe/page_alloc.c`, all `hyp_page` refcount/buddy updates require `pool->lock`, non-head pages have `order == HYP_NO_ORDER`, high-order allocations require `hyp_split_page()` before `hyp_put_page()`, and `guest_s2_zalloc_page()` must zero pages from `kvm_hyp_memcache` and set `refcount = 1, order = 0`. [F191, F199, F239, F265, F306]
- `get_pkvm_hyp_vm()`, `get_np_pkvm_hyp_vm()`, and `pkvm_load_hyp_vcpu()` take a `hyp_vm` refcount under `vm_table_lock` (released by `put_pkvm_hyp_vm()`/`pkvm_put_hyp_vcpu()`), whereas `get_vm_by_handle()` (which must reject `RESERVED_ENTRY`) and `pkvm_get_loaded_hyp_vcpu()` return borrowed pointers. In `__pkvm_teardown_vm()`, under `vm_table_lock`, verify `hyp_page_count(hyp_vm) == 0`, flush VMID TLBs, and remove the handle before unlocking, keeping `host_kvm` pinned until all pages/memcaches and `teardown_donated_memory()` (`pkvm_get_hyp_vm_size()`) finish. [F192, F195, F212, F232, F310]
- `host_data_ptr(host_ctxt)->__hyp_running_vcpu` must be set to `vcpu` before loading guest sysregs/traps or passing `host_ctxt` to `sysreg-sr.h` helpers (since `ctxt_to_vcpu(ctxt)` uses `container_of` when NULL) and cleared to `NULL` after restoring host state. Mutated host trap registers (`PMUSERENR_EL0`, `SYS_HCRX_EL2`, FGT, MPAM) must be saved in `host_ctxt` and restored on deactivation. [F206, F207, F315, F321]

## API Contracts
- `__vcpu_sys_reg()`, `__vcpu_assign_sys_reg(vcpu, reg, val)`, and `ctxt_sys_reg()` only access memory, whereas `vcpu_read_sys_reg()` and `vcpu_write_sys_reg(vcpu, val, reg)` (reversed `(val, reg)` order) must be used when a guest register may be live on the CPU (`SYSREGS_ON_CPU`). [F66, F243]
- `kvm_vcpu_get_fault_ipa()` returns `INVALID_GPA` when `HPFAR_EL2_NS` is clear and a 4KB-aligned IPA otherwise; callers of `__get_fault_info()` must also check `fault.hpfar_el2 & HPFAR_EL2_NS` before reading `HPFAR_EL2_FIPA`. In `kvm_is_write_fault()`, check `kvm_vcpu_abt_iss1tw(vcpu)` before `dabt_iswrite()`, treating `S1PTW` faults as writes only on permission faults. [F55, F98, F240]
- `kvm_pgtable_stage2_{wrprotect,test_clear_young}()` do not flush TLBs, `kvm_pgtable_stage2_relax_perms()` rejects `KVM_PTE_LEAF_ATTR_HI_SW` bits with `-EINVAL`, `kvm_pgtable_stage2_free_unlinked()` drops the root `pgtable` page ref itself, and `kvm_pgtable_stage2_split()` requires `mc == &mmu->split_page_cache`. For TLB invalidation, pass `TLBI_TTL_UNKNOWN` when the leaf level is unknown or when zapping a table PTE, shift `ipa >>= 12` for `__tlbi_level(ipas2e1*, ...)` but pass an unshifted byte IPA to `__flush_s2_tlb_range_op()`, and guard `{enter,exit}_vmid_context()` with `if (mmu)` in `vhe/tlb.c:__kvm_tlbi_s1e2()`. [F187, F190, F234, F245, F246, F316, F359]

## Error Handling
- On init/create error paths: `kvm_arch_init_vm()` must unreserve the pKVM handle after `pkvm_init_host_vm()`; `kvm_arch_vcpu_create()` must call `kvm_vgic_vcpu_destroy()` after `kvm_vgic_vcpu_init()`; `__pkvm_init_vm()` must call `insert_vm_table_entry()` last and unwind `unmap_donated_memory()`/`hyp_unpin_shared_mem()`; `__pkvm_init_vcpu()` must unwind `unpin_host_vcpu()` and `unmap_donated_memory(hyp_vcpu, ...)` with no further dereference; and `pkvm_create_stack()` must restore `__io_map_base = prev_base`. [F3, F6, F193, F194, F201]
- In `ffa.c`, `do_ffa_rxtx_{map,unmap}()` must unpin before unsharing `tx`/`rx`, NULL `host_buffers.tx`/`rx`, and call `ffa_unmap_hyp_buffers()`; `__ffa_host_{share,unshare}_ranges()` return the `u32` count of processed ranges for exact rollback; `do_ffa_mem_frag_tx()`/`__do_ffa_mem_xfer()` must roll back with `ffa_host_unshare_ranges()`/`ffa_mem_reclaim()`; `do_ffa_mem_reclaim()` must call `ffa_rx_release(res)` on all error exits after `ffa_retrieve_req()`/`ffa_mem_frag_rx()`; and `ffa_to_smccc_res(res, ret)` must only run when `ret != 0`. [F202, F203, F204, F230, F235]
- Non-standard returns: `kvm_pgtable_hyp_unmap()` returns unmapped bytes (`!= size` on error, or `0` if `mm_ops->page_count` is NULL); `kvm_vcpu_exit_request(vcpu, &ret)` leaves `ret` unchanged on kernel re-entry requests (initialize `ret > 0`); `__vgic_v2_perform_cpuif_access()` returns `1`, `0`, or `-1` (SError); `kvm_arm_timer_get_reg()` returns `(u64)-1` on unknown `regid`; and `handle_host_mem_abort()` treats `!__get_fault_info()` or `-EAGAIN` from `host_stage2_idmap()` as a benign race. [F44, F48, F225, F226, F356, F367]
- In `kvm_arch_irq_bypass_{add,del}_producer()` and `kvm_arch_update_irqfd_routing()`, check `irq_entry->type == KVM_IRQ_ROUTING_MSI` before reading `irq_entry->msi`, and never call sleeping `kvm_vgic_v4_set_forwarding()` inside spinlock-context `kvm_arch_update_irqfd_routing()`. Null-check `get_timer_map()` pointers when `!vcpu_has_nv(vcpu)`. [F42, F43, F148]

## Known Pitfalls
- Signed ID register fields must be sign-extended in `idreg_feat_match()`, `kvm_cmp_feat()` (comparing inside `kvm_cmp_feat_{signed,unsigned}()` to avoid `?:` unsigned promotion), and `get_restricted_features()` (using `max(sys_val, pvm_max)` when a sign bit is set, and widening to `u64` before shifting). [F93, F109, F290, F302]
- Cast 32-bit fields (`TCR_EL2_PS_MASK`, VMID masks, `range->pg_cnt` in `ffa.c`, `pfn` in `hyp_pfn_to_phys()`) to 64-bit before shifting >= 32 or multiplying by page size; use signed `s8`/`int` for page-table `level` variables; and copy `__u32` `init->features[0]`, `u32` `timer_get_ctl()`, and `u64` MPIDR masks into `unsigned long` locals before bitops/bitmap calls. [F111, F127, F128, F129, F300, F301, F303]
- In EL2 nVHE and `include/hyp/`, translate pointers in host-shared structs (`vcpu->kvm`, `hw_mmu`, `mmu->arch`, `sve_state`, timer offsets) with `kern_hyp_va()`; access `_EL12`-aliased EL1 registers (`SYS_PMSCR`, `SYS_TRFCR`, `SYS_BRBCR`, `SYS_SCTLR`, `SYS_TCR`) via `{read,write}_sysreg_el1()`; and cast symbols to `unsigned long` in `per_cpu_ptr_nvhe_sym()`. [F122, F319, F340]
- Use `kvm_s2_mmu_to_kvm(mmu)` rather than `container_of(mmu, struct kvm, arch.mmu)` (for `nested_mmus[]`). In `__kvm_pgtable_visit()`, reload `ctx.old = READ_ONCE(*ptep)` and recompute `table` after `kvm_pgtable_visitor_cb()`. In `stage2_try_break_pte()`, align `ctx->addr` down to `kvm_granule_size(ctx->level)` before `kvm_tlb_flush_vmid_range()`. [F126, F259, F342]
- In `config.c`, registers using `NEEDS_FEAT_FIXED` must call `compute_reg_fixed_bits()` in `get_reg_fixed_bits()`, and `NEEDS_FEAT_RES0` is only valid in `reg_feat_map_desc.feat_map`, never `bit_feat_map`. Generated sysreg `*_MASK` constants are pre-shifted. `CNTHCTL_EL1PCEN`/`CNTHCTL_EL1PCTEN` are negative-polarity enable bits and shift left by 10 under VHE/`has_hvhe()`, and nVHE `TCR_EL2_*` masks in `cpu_prepare_hyp_mode()` require `!cpus_have_final_cap(ARM64_KVM_HVHE)`. [F97, F103, F125, F136, F244, F334]
