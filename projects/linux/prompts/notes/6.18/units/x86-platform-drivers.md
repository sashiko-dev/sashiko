# X86 PLATFORM DRIVERS

This unit contains x86 and OLPC platform drivers across `drivers/platform/`, `drivers/platform/x86/`, and `include/linux/platform_data/x86/`, bridging vendor firmware interfaces (ACPI, WMI, SMBIOS, EC, TPMI, P2SB, and MSRs) with kernel subsystems including backlight, hwmon, rfkill, input, power_supply, leds, regulator, platform_profile, and vga_switcheroo.

## Architecture & Data Flow

- In `intel/ifs/`, `ifs_devices[]` sets `.test_msrs = NULL` for `IFS_TYPE_ARRAY_BIST`, so `ifs_get_test_msrs(dev)` returns `NULL` and must never be dereferenced in paths shared with array BIST; in `doscan()` and `ifs_test_core()`, `union ifs_scan` and `union ifs_status` must select `.gen2` when `ifsd->generation != 0` and `.gen0` when `0` (clearing `activate.gen0.rsvd = 0`). [F51, F52]
- In `ifs_load_firmware()`, `ifsd->loaded = (ret == 0)` must be updated on every exit path so failed loads after `current_batch_store()` updates `ifsd->cur_batch` do not leave `ifsd->loaded` true; in `find_meta_data()`, the `struct metadata_header` loop must stop on `MC_HEADER_META_TYPE_END`, `blk_size == 0`, or `meta_size >= total_meta`. [F66, F91]
- In `dell-smbios-base.c`, `parse_da_table()` must ignore DMI `0xda` records with `dm->length < 17` and append `(dm->length - 11) / sizeof(struct calling_interface_token) - 1` tokens; `build_tokens_sysfs()` must only run after `dmi_walk()` finishes reallocating `da_tokens`, and because it skips `tokenID == 0` entries while compacting `token_attrs`, `location_show()`/`value_show()` must use `container_of(attr, struct token_sysfs_data, ...)->token`. [F65, F78, F79]
- In `apple-gmux.c`, `gmux_probe()` must gate backlight registration on `acpi_video_get_backlight_type()` (as must `dell_uart_bl_pdev_probe()` and `oaktrail_init()`), cap `props.max_brightness` to `GMUX_MAX_BRIGHTNESS` (or hardcode `MMIO_GMUX_MAX_BRIGHTNESS` and `iolen = 16` on `APPLE_GMUX_TYPE_MMIO`), and mask `GMUX_PORT_BRIGHTNESS` with `GMUX_BRIGHTNESS_MASK` in `gmux_get_brightness()`. On MMIO gmux, 32-bit accesses must use `ioread32be()`/`iowrite32be()`, and `gmux_clear_interrupts()` must call ACPI `"GMSP"` with `0`. [F115, F137, F138, F139]
- In `hp-wmi.c`, Omen and Victus profile setters must update `active_platform_profile` under `active_platform_profile_lock`, and `platform_profile_omen_get()` must return it rather than reading the EC; on `has_omen_thermal_profile_ec_timer` boards, `platform_profile_omen_set_ec()` must zero the EC timer and update EC flags after `omen_thermal_profile_set()`; `victus_s_gpu_thermal_profile_set()` must populate `gpu_slowdown_temp` via `victus_s_gpu_thermal_profile_get()`. [F68, F69, F70]
- In `olpc_ec_suspend()` and `olpc_xo175_ec_suspend()`, pre-suspend EC commands must run before setting `suspended = true`, and resume must clear `suspended` before sending EC commands. In `olpc_ec_mask_write()` and `olpc_ec_sci_query()`, 2-byte big-endian `EC_WRITE_EXT_SCI_MASK`/`EC_EXT_SCI_QUERY` require `ec->version >= 0x5f`. [F61, F140]
- In `tpmi_power_domains.c`, `tpmi_power_domain_mask` and `domain_die_map` are sized by `topology_max_packages() * MAX_POWER_DOMAINS`; `tpmi_get_logical_id()` must use `topology_logical_package_id(cpu)` (not physical) and callers must check `pkg_id < topology_max_packages()` and `domain_id < MAX_POWER_DOMAINS` before indexing. [F77]
- In `p2sb.c`, `p2sb_get_devfn()` defaults to `P2SB_DEVFN_DEFAULT` and uses `P2SB_DEVFN_GOLDMONT` on Goldmont/Goldmont Plus (where `p2sb_scan_and_cache()` scans only `devfn` and `SPI_DEVFN_GOLDMONT`); `p2sb_cache_resources()` must allow `PCI_POSSIBLE_ERROR(class)` or `PCI_CLASS_MEMORY_OTHER`, `p2sb_read_bar0()` must zero `@mem` and copy only `start`, `end`, `flags`, and `desc` (never pointers), and `p2sb_read_from_cache()` must verify `cache->bus_dev_id == bus->dev.id` and `p2sb_valid_resource(&cache->res)`. [F202, F222, F244, F261]

## Synchronization

- In `intel/ifs/`, callers of `do_core_test()` and `ifs_load_firmware()` must hold `ifs_sem` before `do_core_test()` or `scan_chunks_sanity_check()` acquires `cpus_read_lock()`, and every exit path after `cpus_read_lock()` must jump to `out:` to call `cpus_read_unlock()`. [F5, F31]
- In `intel/ifs/runtest.c`, `ifs_test_core()`, `ifs_array_test_core()`, and `ifs_sbaf_test_core()` must reset `scan_cpus_in`, `array_cpus_in`, or `sbaf_cpus_in` to `0` via `atomic_set()` before each `stop_core_cpuslocked()` retry; `doscan()` and `dosbaf()` must synchronize SMT siblings via `wait_for_sibling_cpu()` before all threads write `MSR_ACTIVATE_SCAN`/`MSR_ACTIVATE_SBAF`, whereas only `cpumask_first(cpu_smt_mask(cpu))` records scan results or writes `MSR_ARRAY_BIST` in `do_array_test()`. [F67, F146]
- In `copy_hashes_authenticate_chunks_gen2()`, `wrmsrq(msrs->copy_chunks, ...)` must run under `local_irq_disable()` and retry up to `IFS_AUTH_RETRY_CT` times on `AUTH_INTERRUPTED_ERROR`. [F148]
- In `olpc-ec.c`, `ec->cmd_q_lock` (`spin_lock_irqsave()`) protects `ec->cmd_q` and must be released before `olpc_ec_worker()` acquires `ec->cmd_lock` to call `ec_driver->ec_cmd()`; in `olpc_xo175_ec_probe()`, `priv->cmd_state_lock`, `priv->cmd_done`, `priv->xfer`, and `olpc_ec_driver_register()` must be initialized before registering the `olpc-ec` platform device and calling `olpc_xo175_ec_set_event_mask()`. [F23, F25]
- In `apple-gmux.c`, all indexed and MMIO port accessors (`gmux_index_read/write8/32`, `gmux_mmio_read/write8/32`) must hold `gmux_data->index_lock` across the entire multi-register transaction; `init_completion(&gmux_data->powerchange_done)` must precede `gmux_enable_interrupts()` in `gmux_probe()`, and `reinit_completion(&gmux_data->powerchange_done)` must precede writing `GMUX_PORT_DISCRETE_POWER` in `gmux_set_discrete_state()`. [F26, F27]
- In `tpmi_power_domains.c`, `tpmi_lock` protects `tpmi_cpu_hash` and `tpmi_power_domain_mask`, and `tpmi_exit()` must call `cpuhp_remove_state(tpmi_hp_state)` before freeing `tpmi_power_domain_mask` and `domain_die_map`. In `turbo_max_3.c`, `itmt_legacy_cpu_online()` must defer `sched_set_itmt_support()` via `schedule_work(&sched_itmt_work)`. [F33, F35]
- In `p2sb.c`, `p2sb_cache_resources()` must hold `pci_lock_rescan_remove()` while unhiding `P2SBC`, scanning/removing the device, and re-hiding with `P2SBC_HIDE`, whereas `p2sb_bar()` must read `p2sb_resources` (populated at `fs_initcall_sync(p2sb_fs_init)`) without acquiring `pci_lock_rescan_remove()` to avoid deadlocking during sysfs PCI rescans. [F190, F191]

## Object Lifetimes

- In `cht_int33fe_typec.c`, `cht_int33fe_add_nodes()` must set `fusb302_mux_refs[0].node` before `software_node_register_node_group()`, and teardown must `i2c_unregister_device()` (`battery_fg`, `fusb302`, `pi3usb30532`) in reverse order before `cht_int33fe_remove_nodes()` unregisters `node_group`, puts/clears `fusb302_mux_refs[0].node`, and clears `data->dp->secondary = NULL`. [F11, F73]
- In `amd_isp4.c`, `isp_i2c_bus_notify()` must clear `isp4_platform->i2c_dev = NULL` under `isp4_platform->lock` on `BUS_NOTIFY_REMOVED_DEVICE` (after `i2c_verify_client()`/`i2c_verify_adapter()`), and `amd_isp_remove()` must unregister `i2c_nb` and `i2c_dev` before `software_node_unregister_node_group()`; in `tink-board.c` and `sel3350-platform.c`, `tink_swnodes` and `sel3350_leds_table`/`sel3350_gpios_table` must be registered before and unregistered after their child platform devices. [F12, F122, F184, F197]
- In `olpc_ec_cmd()`, `struct ec_cmd_desc desc` is allocated on the caller's stack and queued on `ec->cmd_q`, so it must wait uninterruptibly via `wait_for_completion(&desc.finished)` until `olpc_ec_worker()` completes it. [F7]
- In `dell-smbios-base.c`, `dell_smbios_register_device()` and `dell_smbios_unregister_device()` must modify `smbios_device_list` and balance `get_device()`/`put_device()` under `smbios_mutex`, and `dell_smbios_call()` must hold `smbios_mutex` across backend selection (saved in `selected`, never dereferencing the `list_for_each_entry()` cursor after the loop) and `selected->call_fn(buffer)`. [F106, F135]
- In `dell_uart_bl_pdev_probe()` and `serial-base-instantiate.c`, `get_serdev_controller()` must call `get_device(acpi_get_first_physical_node(adev))` before `acpi_dev_put(adev)`, `get_serdev_controller_from_parent()` must call `put_device(ctrl_dev)` on each intermediate parent, `dell_uart_bl_pdev_probe()` must call `put_device(ctrl_dev)` after `serdev_device_alloc()`, and once `serdev_device_add(serdev)` succeeds, teardown must call `serdev_device_driver_unregister()` then `serdev_device_remove(serdev)` (not `serdev_device_put()`). [F15, F262]
- In `gmux_remove()`, `gmux_fini_debugfs()`, `vga_switcheroo_unregister_handler()`, `gmux_disable_interrupts()`, `acpi_disable_gpe()`, `acpi_remove_notify_handler()`, and `backlight_device_unregister()` must complete before unmapping `iomem_base`, releasing I/O regions, clearing `apple_gmux_data`, and freeing `gmux_data`. In `huawei-wmi.c`, init rollback and `huawei_wmi_exit()` must unregister the platform device and driver before `kfree(huawei_wmi)`. [F9, F28]
- In `crystal_cove_charger_probe()`, `charger->irq_domain`, `charger->charger_irq`, chip/handler setup, initial `MCHGRIRQ_REG` masking, and `devm_add_action_or_reset(..., crystal_cove_charger_rm_irq_domain, ...)` must all complete before `devm_request_threaded_irq()`, so the IRQ is freed before the domain. [F21, F38]
- In `p2sb.c`, when `p2sb_hidden_by_bios` is false, `p2sb_cache_resources()` must not call `p2sb_scan_and_cache()`, and `p2sb_bar()` must read BAR0 from the live device via `p2sb_read_from_dev()` (`pci_get_slot()`/`pci_dev_put()`). [F258]

## API Contracts

- In `dell-smbios`, `dell_smbios_find_token()` returns an unreferenced pointer into `da_tokens` that must not be freed or used after module exit; `dell_smbios_call()` returns only transport status without checking `buffer->output[0]`, so callers must use `dell_send_request()` or `dell_smbios_error(buffer->output[0])`; backends must pass priority via `dell_smbios_register_device(d, priority, call_fn)` (not `dev->id`) with `call_fn` typed as `int (*)(struct calling_interface_buffer *)`. [F3, F46, F64, F120]
- `dell_smbios_call_filter()` and `dell_smbios_class_is_supported()` must reject `class > 30` before `da_supported_commands & (1 << class)`, and `dell_smbios_call_filter()` must check `token_blacklist`/`token_whitelist` before `call_whitelist` and before `capable(CAP_SYS_RAWIO)`. [F80, F100, F166]
- In `hp-wmi.c`, `hp_wmi_perform_query()` requires a caller `buffer` of at least `max(insize, outsize)` bytes with `outsize <= 4096` (allocating `max(insize, 128)` for `args->data`) and returns `0`, a negative errno, or a positive `bios_return->return_code`, which callers returning kernel errnos must map to negative errnos; `hp_wmi_hwmon_read()`/`write()` must invert hwmon PWM values (`0` full speed, `2` auto) to HP WMI max-fan states (`1` max, `0` auto) and reject other values with `-EINVAL`. [F44, F84, F168]
- In `huawei-wmi.c`, `huawei_wmi_cmd()` copies response bytes into `buf` even when `buf[0] != 0` returns `-ENODEV`, so callers must check the return value and read payload starting at `buf[1]`: `huawei_wmi_battery_get()` scans down to `i > 2`, `huawei_wmi_fn_lock_get()` scans `i = 1` to `i < 0xff`, and `huawei_wmi_battery_set()` must validate `0 <= start <= 100` and `0 <= end <= 100`. [F47, F81, F83]
- Every `struct platform_profile_ops.profile_get` callback (`platform_profile_omen_get()`, `platform_profile_victus_get()`, `hp_wmi_platform_profile_get()`, `inspur_platform_profile_get()`) must write the profile to `*profile` and return `0`, never returning the enum value. [F163]
- In `intel/ifs/`, `validate_ifs_metadata()` requires `ifs_test_image_ptr` (`(u64)ifs_meta + sizeof(union meta_data)`) to be 256-byte (`IFS_CHUNK_ALIGNMENT`) aligned (so low 8 bits are zero for `linear_addr |= i` in `copy_hashes_authenticate_chunks()`) and `starting_chunk` to be a multiple of non-zero `chunks_per_stride`; `scan_chunks_sanity_check()` must use `INIT_WORK_ONSTACK(&local_work.w, ...)`. [F53, F90, F165]
- In `intel/int0002_vgpio.c`, `int0002_probe()` must request `parent_irq` with `IRQF_ONESHOT | IRQF_SHARED`, `int0002_irq()` runs in hardirq context and must use `generic_handle_domain_irq_safe()` and `pm_wakeup_hard_event()` without sleeping, and `int0002_suspend()`/`resume()` must only call `enable_irq_wake()`/`disable_irq_wake()` when `!pm_suspend_via_firmware()` and `wake_enable_count > 0`. In Intel SoC PMIC child drivers, `platform_get_irq(pdev, 0)` is already a translated vIRQ and must not be passed to `regmap_irq_get_virq()`. [F143, F144, F156]

## Error Handling

- In `dell_smbios_init()`, `build_tokens_sysfs()` indexes `da_tokens`/`token_entries` by `i` and `token_attrs` by `j`, freeing all of its own partial allocations on error (including freeing `location_name` before `out_unwind_strings` if `value_name` fails), so `fail_sysfs` must not call `free_group()`. [F2, F101]
- In `ifs_load_firmware()`, every failure path after `request_firmware_direct()` succeeds must jump to `release:` to call `release_firmware(fw)`; in `ifs_test_core()` and `ifs_sbaf_test_core()`, `union ifs_status`/`ifs_sbaf_status` must be zero-initialized (`= {}`) before the polling loop. [F4, F40]
- In `olpc_ec_probe()`, any failure after `ec_priv = ec` must jump to `error:` to reset `ec_priv = NULL` and `kfree(ec)`. In `ec_dbgfs_cmd_write()`, `char cmdbuf[64] = ""` must be zero-initialized before `simple_write_to_buffer()` and `sscanf()`, and if `sscanf()` parses `< 2` items or `ec_dbgfs_resp_bytes > EC_MAX_CMD_REPLY`, `ec_dbgfs_resp_bytes` must be reset to `0` under `ec_dbgfs_lock`. [F6, F43, F62]
- In `huawei-wmi.c` and `intel-rst.c`, sequential `device_create_file()` calls in `huawei_wmi_battery_add()` and `irst_add()` must remove the first file if the second fails; in `huawei-wmi.c`, `acpi_status` returns must be checked with `ACPI_FAILURE()` and mapped to negative errnos (never returned directly or combined with `||`), and `union hwmi_arg` must assign `arg.cmd` before setting `arg.args[2]`/`arg.args[3]`. [F8, F42, F48]
- In `tpmi_init()`, any `kcalloc()` failure after `rdmsrq_safe()` sets `ret = 0` must set `ret = -ENOMEM` before jumping to cleanup; in `tpmi_cpu_online()` and `itmt_legacy_cpu_online()`, MSR/priority lookup errors must return `0` so CPU bringup is not aborted. [F39, F54]
- In `gmux_probe()`, if `acpi_evaluate_integer(..., "GMGP", ...)` fails, `gmux_data->gpe` must be set to `-1` and checked with `gmux_data->gpe >= 0`; in `gmux_selected_port_data_write()`, non-zero `copy_from_user()` returns must be mapped to `-EFAULT`, and writes with `*ppos != 0` or size other than `1` or `4` bytes must return `-EINVAL`. [F41, F55, F177]

## Known Pitfalls

- In `hp-wmi.c`, `IS_HWBLOCKED(x)` must check `((x & HPWMI_POWER_FW_OR_HW) != HPWMI_POWER_FW_OR_HW)`; `hp_wmi_get_fan_speed()` must cast `char fan_data[2..3]` to `u8` before shifting; `zero_if_sup(tmp)` uses `sizeof(tmp)` and must not be passed a pointer; and `hp_wmi_driver` must keep `__refdata` while referencing `__exit_p(hp_wmi_bios_remove)`. [F99, F108, F117, F142]
- In `intel/ifs/load.c`, `ifs_header_ptr`, `meta_header`, and `ifs_meta` are typed pointers and must be cast to `void *` or `u64` before adding byte offsets like `meta_header->blk_size` or `sizeof(union meta_data)`. In `turbo_max_3.c`, `get_oc_core_priority()` must use `u64` shifts and `BIT_ULL(MSR_OC_MAILBOX_BUSY_BIT)`. In `plr_tpmi.c`, `plr_print_bits()` must use `BITMAP_FROM_U64(val)` rather than casting `&val` to `unsigned long *`. [F113, F119, F124]
- In `silicom-platform.c`, `OFFSET_BIT_TO_CHANNEL(off, bit)` in `u8` arrays requires `off <= 0x0b` and `bit <= 7`, and `silicom_gpio_set()` must pass `!value` to active-low `silicom_mec_port_set()`. In `pmc_atom.c`, `pmc_power_off()` must invert `~SLEEP_TYPE_MASK` when clearing `PM1_CNT`, and `pmc_sleep_tmr_show()` must cast `pmc_reg_read()` to `u64` before `<< PMC_TMR_SHIFT`. [F236, F240, F242, F248]
