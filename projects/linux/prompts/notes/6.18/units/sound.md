# SOUND

The SOUND unit covers core ALSA headers (`include/sound`), Realtek and Si3054 HD-Audio codec drivers (`sound/hda/codecs`), and USB audio PCM, mixer, power, and device quirks (`sound/usb`), defining the shared data structures, locking and runtime PM rules, kcontrol/PCM state machines, hardware quirk tables, and UAC1/2/3 descriptor protocols.

## Architecture & Data Flow

- `struct snd_kcontrol` allocations must size `vd[]` with `struct_size(..., vd, count)` and set `kctl->count = count` before indexing `kctl->vd[]`. Once added to a `snd_card`, renaming a control must use `snd_ctl_rename()` or `snd_ctl_rename_id()` to keep `card->ctl_hash` and `card->ctl_numids` XArray entries synchronized. [F44, F97]
- In `struct snd_pcm_runtime`, `status->hw_ptr` and `control->appl_ptr` wrap modulo `runtime->boundary` (not `runtime->buffer_size`), so `snd_pcm_playback_avail()` and `snd_pcm_capture_avail()` must adjust `< 0` or `>= runtime->boundary` differences by `runtime->boundary`. Updating or clearing a substream's DMA buffer must use `snd_pcm_set_runtime_buffer()`. [F46, F63]
- `struct alc_spec` must keep `struct hda_gen_spec gen` at offset 0. Fixups enabling `AC_PINCTL_VREF_*` on an output pin at `HDA_FIXUP_ACT_INIT` must set `spec->gen.keep_vref_in_automute = 1`, and fixups registering `vref_mute_led_set` / `vref_micmute_led_set` must set `spec->mute_led_nid` / `cap_mute_led_nid` and `codec->power_filter = led_power_filter`. [F188, F222, F229]
- In `alc_update_headset_mode()`, transitioning to `ALC_HEADSET_MODE_UNPLUGGED` must reset `spec->current_headset_type = ALC_HEADSET_TYPE_UNKNOWN`, and `ALC_HEADSET_MODE_MIC` must skip the post-switch `snd_hda_set_pin_ctl_cache()` block. On S3/S4 resume, `alc_fixup_headset_mode` (`HDA_FIXUP_ACT_INIT`) must reset `current_headset_mode` and `current_headset_type` to `UNKNOWN`, and `alc269_resume()` must rewrite non-zero `spec->gpio_data` via `alc_write_gpio_data(codec)`. [F184, F214, F261]
- In `snd_pci_quirk` tables, specific `SND_PCI_QUIRK` / narrower `SND_PCI_QUIRK_MASK` entries must precede `SND_PCI_QUIRK_VENDOR` (`subdevice == 0`) for the same `subvendor` and end with `{}`. In `alc269.c`, `SND_PCI_QUIRK_VENDOR` entries belong in `alc269_fixup_vendor_tbl` (not `alc269_fixup_tbl`), and `alc269_fallback_pin_fixup_tbl` may have at most one `SND_HDA_PIN_QUIRK` per `(codec, subvendor)` pair. [F86, F208, F209, F210]
- For multi-channel `struct usb_mixer_elem_info` controls (`cval->cmask != 0`), bit `c` (`BIT(c)`) in `cmask` and `ch_readonly` maps to 1-based USB `channel = c + 1` and `BIT(c + 1)` in `cval->cached`, while `cval->cache_val[index]` is indexed by the dense 0-based count of set bits in `cmask`. In `snd_usb_mixer_notify_id()` and `snd_usb_mixer_interrupt_v2()`, affected `info->cached` bits must be cleared before `snd_ctl_notify()`. [F331, F350]
- Raw USB Audio Class descriptors must be validated with `snd_usb_validate_audio_desc(p, protocol)`. To prevent infinite recursion on cyclic descriptors, `check_input_term()` must clear `state->termbitmap` and `__check_input_term()` must check `test_and_set_bit(id, state->termbitmap)`, while `snd_usb_mixer_controls()` and `parse_audio_unit()` must mark visited units in `state->unitbitmap`. [F347, F362, F364]
- In `sound/usb/pcm.c`, `urb_ctx_queue_advance()` must take the PCM DMA buffer bytes consumed (excluding DSD DoP marker bytes or packet headers) so `ctx->queued`, `subs->inflight_bytes`, and `subs->hwptr_done` advance together, and `retire_capture_urb()` / `copy_to_urb()` must split transfers where `hwptr_done + bytes > subs->buffer_bytes` into two `memcpy` calls around `subs->buffer_bytes`. [F345, F354]

## Synchronization

- `snd_pcm_start()`, `snd_pcm_stop()`, `snd_pcm_drain_done()`, `__snd_pcm_set_state()` (which updates both `runtime->state` and `runtime->status->state`), and `snd_pcm_period_elapsed_under_stream_lock()` require the PCM substream lock (`snd_pcm_stream_lock*`), whereas `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` acquire `pcm_stream_lock_irqsave` internally and must be called unlocked. [F16, F18, F125]
- When `substream->pcm->nonatomic` is false, `snd_pcm_ops` callbacks under `snd_pcm_stream_lock*` (`trigger`, `pointer`, `get_time_info`, `ack`) run under spinlock `substream->self_group.lock` with IRQs disabled and must not sleep; when `pcm->nonatomic` is true, `snd_pcm_stream_lock*` acquires `substream->self_group.mutex`, so `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` sleep and cannot be called from atomic/IRQ context. [F122, F123]
- In the control subsystem, `snd_power_ref_and_wait(card)` must be called before locking `card->controls_rwsem`; `card->controls_rwlock` nests inside `card->controls_rwsem`, and `snd_ctl_file.read_lock` nests inside `card->controls_rwlock`. `snd_ctl_find_numid()`, `snd_ctl_find_id()`, and `snd_ctl_find_id_mixer()` return unreferenced pointers that require holding `card->controls_rwsem`. `snd_ctl_notify()` is atomic-safe, whereas `snd_ctl_notify_one()` takes sleeping `snd_ctl_layer_rwsem`. [F15, F128, F129, F130]
- `snd_hdac_stream_release_locked()` and `snd_hdac_ext_stream_decouple_locked()` require `bus->reg_lock`, whereas `snd_hdac_stream_assign()`, `snd_hdac_stream_release()`, and `snd_hdac_ext_stream_decouple()` acquire `bus->reg_lock` internally. `coef_mutex_lock()` / `coef_mutex_unlock()` must call `snd_hda_power_up_pm(codec)` outside `spec->coef_mutex`, and callers holding `guard(coef_mutex)(codec)` must use `__alc_*_coefex_idx()`. [F134, F153]
- In `sound/usb/pcm.c`, `subs->lock` protects `subs->hwptr_done`, `transfer_done`, `inflight_bytes`, `last_frame_number`, and `period_elapsed_pending` (and must be held across reading `hwptr_done` and `snd_usb_pcm_delay()` in `snd_usb_pcm_pointer()`), and must be released before calling `snd_pcm_period_elapsed*()`. `snd_usb_pcm_playback_ack()` must pass `in_stream_lock = true` to `snd_usb_queue_pending_output_urbs()`. [F299, F300, F301, F302]
- `start_endpoints()` and `stop_endpoints()` must track `SUBSTREAM_FLAG_DATA_EP_STARTED` and `SUBSTREAM_FLAG_SYNC_EP_STARTED` on `subs->flags` (clearing the flag and calling `stop_endpoints(subs, false)` if `snd_usb_endpoint_start()` fails), and callers closing or restarting stopped endpoints must call `sync_pending_stops(subs)` first. `chip->mutex` protects `subs->opened` and `subs->cur_audiofmt` and must be released before calling `snd_usb_lock_shutdown(chip)`, `snd_usb_autoresume()`, or `snd_usb_autosuspend()`. [F286, F304, F305, F408]

## Object Lifetimes

- `snd_ctl_add()`, `snd_ctl_replace()`, `snd_usb_mixer_add_list()`, and `snd_usb_mixer_add_control()` consume ownership of `kcontrol` and call `snd_ctl_free_one(kcontrol)` automatically on failure; callers must set `kctl->private_free` beforehand and never free `kcontrol` or its `private_data` after calling them. [F2, F289]
- Every `snd_power_ref(card)` or `snd_power_ref_and_wait(card)` must be paired with `snd_power_unref(card)` even when `snd_power_ref_and_wait()` returns `-ENODEV`. Similarly, `snd_hda_power_up()` / `snd_hda_power_up_pm()` increment usage even on error, so callers not using `CLASS(snd_hda_power*, pm)` must call `snd_hda_power_down*()` on failure, while `CLASS(snd_hda_power*, pm)` users must check `pm.err` and never manually call `snd_hda_power_down*()` inside the scope. [F3, F7, F37]
- `snd_card_ref()` and `snd_lookup_minor_data()` acquire a `card->card_dev` reference that must be released with `snd_card_unref(card)`. When a driver uses `snd_devm_card_new()` and later allocates devres resources accessed by `card->private_free` or `snd_device` `.dev_free`, any probe error before `snd_card_register()` must call `snd_card_free()` or `snd_card_free_on_error()`. [F4, F107]
- Active HDA PCM streams must be refcounted on `codec->pcm_ref` via `snd_hda_codec_pcm_get()` / `snd_hda_codec_pcm_put()` on all close and open-error paths, and codec unbind must wait on `codec->remove_sleep` for `codec->pcm_ref == 0`. [F10, F21]
- In every Realtek `hda_codec_ops.probe` function (`alc260_probe`, `alc269_probe`, `alc662_probe`, `alc882_probe`), any error after `alc_alloc_spec()` must call `snd_hda_gen_remove(codec)` (or `alc269_remove(codec)`), and `alc269_remove()` must call `hda_component_manager_free(&spec->comps, &comp_master_ops)` before `snd_hda_gen_remove(codec)`. [F156, F269]
- Arrays passed to `snd_hda_add_verbs()` (`struct hda_verb`) or assigned to `spec->gen.preferred_dacs` must be `static const` and zero-terminated because only the raw pointer is stored. In `snd_usb_mixer_disconnect()` and `snd_usb_mixer_free()`, `mixer->urb` and `mixer->rc_urb` must be stopped via `usb_kill_urb()` before `mixer->private_free(mixer)` or freeing `mixer->id_elems` and URB buffers. [F230, F231, F306]

## API Contracts

- Multi-element `struct snd_kcontrol` callbacks (`count > 1`) must compute the 0-based offset via `snd_ctl_get_ioff*()`. A `snd_kcontrol_info_t` callback must leave `uinfo->access == 0` (`snd_BUG_ON(info->access)`). In `snd_ctl_apply_vmaster_followers()`, `vfollower` is the vmaster wrapper (`vfollower->put` updates cache) while `follower` is the driver's original control (`snd_kcontrol_chip(follower)` is driver data). [F56, F85, F137]
- In `struct snd_pcm_hardware`, `formats` is a 64-bit `SNDRV_PCM_FMTBIT_*` bitmask (`pcm_format_to_bits()`), and `buffer_bytes_max`/`period_bytes_*` are in bytes, whereas `snd_pcm_runtime.buffer_size`/`period_size` and `params_buffer_size()`/`params_period_size()` are in frames (use `params_buffer_bytes()` / `params_period_bytes()` for bytes). `bytes_to_samples()`, `bytes_to_frames()`, and `frame_aligned()` must only be called after `hw_params` initializes `runtime->sample_bits`, `frame_bits`, and `byte_align`. [F36, F92, F145]
- Before calling `hw_param_mask*()` / `constrs_mask()` or `hw_param_interval*()` / `constrs_interval()`, callers must verify `hw_is_mask(var)` or `hw_is_interval(var)`. Variadic calls to `snd_pcm_hw_rule_add()` must end `dep, ...` with `-1` and pass at most 4 non-negative dependency IDs. Use `snd_pcm_running(substream)` (which includes `SNDRV_PCM_STATE_DRAINING`) to test active DMA, and pass `(s, substream)` in that order to `snd_pcm_trigger_done()`. [F60, F61, F80, F81, F82]
- HDA codec suspend/resume callbacks must bracket execution with `snd_hdac_enter_pm()` and `snd_hdac_leave_pm()`, and paths reachable during codec PM (including `alc_update_vref_led()`) must use `snd_hdac_power_up_pm()` / `CLASS(snd_hda_power_pm, pm)` rather than `snd_hdac_power_up()`. 8-bit/16-bit MMIO on `hdac_bus` or `hdac_stream` must use `snd_hdac_reg_readb/w`/`writeb/w` or `snd_hdac_chip_*`/`snd_hdac_stream_*_poll` helpers for `bus->aligned_mmio`. [F112, F114, F266]
- Realtek fixup stage contracts: `snd_hda_gen_add_mute_led_cdev()` and `snd_hda_gen_add_micmute_led_cdev()` must run at `HDA_FIXUP_ACT_PRE_PROBE`; `rename_ctl()` and `spec->gen.pcm_rec` changes (`alc_fixup_bass_chmap`, dual-codec Capture renames) must run at `HDA_FIXUP_ACT_BUILD`; custom `automute_hook` / `hp_automute_hook` combined with `alc_fixup_headset_mode` must be installed at `HDA_FIXUP_ACT_PROBE` after `alc_fixup_headset_mode` without pre-setting `cap_sync_hook`; and dual-codec fixups (`alc_fixup_dual_codecs`) must configure flags at `HDA_FIXUP_ACT_PRE_PROBE`. [F191, F275, F276, F277]
- In `snd_usb_hw_params()` and `snd_usb_pcm_prepare()`, `snd_usb_pcm_change_state(subs, UAC3_PD_STATE_D0)` must run before configuring/preparing endpoints, and when `subs->sync_endpoint` is present, `snd_usb_endpoint_set_params()`, `snd_usb_endpoint_prepare()`, `stop_endpoints()`, and `sync_pending_stops()` must operate on `subs->sync_endpoint` before `subs->data_endpoint`. When opening `subs->sync_endpoint` via `snd_usb_endpoint_open()`, `is_sync_ep` must be `fmt == sync_fmt`. [F329, F397, F398]
- Buffers passed to `usb_fill_int_urb()` or `usb_fill_control_urb()` must be kmalloc/kzalloc heap memory (stack buffers must use `snd_usb_ctl_msg()`), and any buffer passed as `data` (`size > 0`) to `snd_usb_ctl_msg()` or `snd_us16x08_send_urb()` must be writable (never `const` `.rodata`) because `snd_usb_ctl_msg()` unconditionally executes `memcpy(data, buf, size)` even on `USB_DIR_OUT`. [F376, F411]
- Callers of `snd_usb_mixer_add_list()` with a bare `struct usb_mixer_elem_list` (such as `add_single_ctl_with_resume()`) must pass `is_std_info = false` and never use callbacks like `snd_usb_mixer_vol_tlv()` that cast `kctl->private_data` to `struct usb_mixer_elem_info *`, while `for_each_mixer_elem` loops must check `list->is_std_info` before calling `mixer_elem_list_to_info(list)`. [F351, F378]

## Error Handling

- `snd_hdac_read_parm()`, `snd_hdac_read_parm_uncached()`, `snd_hdac_codec_read()`, and `snd_hda_param_read()` return `(int)-1` (`0xffffffff` in unsigned types) on error rather than a negative errno, whereas `_snd_hdac_read_parm()` returns `0` or a negative errno. `snd_hda_codec_device_init()` returns an `ERR_PTR`, whereas `snd_hda_codec_pcm_new()`, `snd_ctl_new1()`, and `snd_devm_alloc_pages()` return `NULL`. [F27, F28]
- `snd_pcm_format_signed()`, `snd_pcm_format_unsigned()`, and `snd_pcm_format_*_endian()` are tri-state (`1` true, `0` false, `-EINVAL` invalid) and must not be tested as booleans; `snd_pcm_format_width()`, `snd_pcm_format_physical_width()`, `params_width()`, `params_physical_width()`, and `snd_pcm_format_size()` also return `-EINVAL` on variable/unknown formats. `snd_kcontrol_put_t` callbacks return `0` when unchanged, `1` when changed, and `< 0` on error. [F33, F34, F41]
- `alc_parse_auto_config()` returns `1` on success and `< 0` on error, so `.probe` callers must check `err < 0` and explicitly `return 0` at the end of probe. `alc_subsystem_id()` returns `1` on valid SKU and `0` on failure (requiring a 4-element `ports` array), whereas `alc_auto_parse_customize_define()` returns `0` on success and `-1` on failure. `codec->bus->pci`, `snd_hda_find_mixer_ctl()`, `alc_get_hp_pin()`, and `alc_find_ext_mic_pin()` can return `NULL`/`0` and must be checked before use. [F167, F168, F169, F170, F172, F181]
- Because `filter_error(cval, err)` and `snd_us16x08_recv_urb()` can return `0` on USB transfer failure, callers must initialize output values/buffers beforehand. [F316, F319]

## Known Pitfalls

- `snd_hdac_chip_update*`, `snd_hdac_update*`, `snd_hdac_stream_update*`, and `alc_update_coef*_idx` evaluate `(read & ~mask) | val` without masking `val` by `mask`. Bitshifts for `SNDRV_PCM_RATE_*` must use `1U << n`, `_SNDRV_PCM_FMTBIT` / `pcm_format_to_bits()` and `spec->gen.mute_bits` must use `1ULL << n`, and 8-bit values shifted by 24 into `unsigned long private_value` (`SND_DJM_DEVICE_SHIFT`, `snd_ni_control_init_val`) must be cast to `unsigned long` before `<< 24`. [F77, F89, F90, F177, F224, F370]
- The suffix in `alc_fixup_gpio1()`..`alc_fixup_gpio4()` is the hex GPIO mask (`0x01`..`0x04`), so `alc_fixup_gpio3` drives GPIO0+GPIO1 (`0x03`) and `alc_fixup_gpio4` drives GPIO2 (`0x04`). In `struct hda_fixup` tables, setting `.chain_id` has no effect unless `.chained = true` or `.chained_before = true` is also set. Because `__check_input_term()` overwrites `struct usb_audio_term *term` during recursion, callers must assign `term->id` and `term->type` after `__check_input_term()` returns. [F180, F211, F335]
