# FUSE: FILESYSTEM IN USERSPACE

`fs/fuse` implements the kernel side of the Filesystem in Userspace (FUSE) and Character device in Userspace (CUSE) subsystems, bridging VFS file, directory, dentry, ACL, and DAX operations to userspace daemons over `/dev/fuse` (via read/write, splice, and io_uring), alongside optional backing-file passthrough and the `fusectl` control filesystem.

## Architecture & Data Flow

- Every `struct fuse_req` incrementing `fc->num_waiting` must set `FR_WAITING` so the final `fuse_put_request()` calls `fuse_drop_waiting(fc)`. Ending a request before reader dequeue requires clearing `FR_PENDING` before `fuse_request_end()`; `fuse_resend()` re-queuing from `fpq->processing` to `fiq->pending` must set `FR_PENDING`, clear `FR_SENT`, and set `FUSE_UNIQUE_RESEND`. [F11, F71, F72]
- Updating `fc->max_background` or `fc->num_background` under `fc->bg_lock` requires recalculating `fc->blocked` in lockstep and waking `fc->blocked_waitq` when unblocked. In `fuse_uring_req_end()`, check `FR_BACKGROUND` to decrement `queue->active_background` and call `fuse_uring_flush_bg(queue)` before `fuse_request_end(req)` clears `FR_BACKGROUND`. [F73, F74]
- Cloned `/dev/fuse` fds (`FUSE_DEV_IOC_CLONE`) share `fc` and `fc->iq` but own separate `fud->pq` queues; `fuse_dev_release()` must always end `fud->pq.processing` requests and only call `fuse_abort_conn(fc)` when `atomic_dec_and_test(&fc->dev_count)` is true. [F79]
- `fuse_get_unique_locked()` steps by `FUSE_REQ_ID_STEP` (2), reserving `FUSE_INT_REQ_BIT` (bit 0) for `FUSE_INTERRUPT`; `fuse_req_hash()` and `fuse_request_find()` must mask `~FUSE_INT_REQ_BIT`. In `fuse_dev_do_write()`, dispatch `!oh.unique` to `fuse_notify()` before checking `oh.error > 0`, and on `oh.unique & FUSE_INT_REQ_BIT` jump to `copy_finish` without ending `req`. [F99, F114]
- In `struct fuse_inode`, regular-file writeback fields share an anonymous union with directory `rdc`, so `fuse_set_nowrite()`, `fuse_release_nowrite()`, and `fuse_flush_writepages()` must only be called on `S_ISREG` inodes; `fuse_do_statx()` and `fuse_do_getattr()` may only pass `ff->fh` with `FUSE_GETATTR_FH` when `S_ISREG(inode->i_mode)` is true. [F54, F149]
- In read/write/splice handlers, `FUSE_IS_DAX(inode)` takes precedence over `ff->open_flags & FOPEN_DIRECT_IO`, which takes precedence over `fuse_file_passthrough(ff)`. In `fuse_dax_write_iter()`, `file_extending_write(iocb, from)` must fall back to `fuse_dax_direct_write()` rather than `dax_iomap_rw()`. [F109, F194]
- Before server-side range ops (`fuse_file_fallocate()` punch/zero range and `__fuse_copy_file_range()`), `fuse_writeback_range()` must flush dirty pages from `start` through `LLONG_MAX` (never `end` or `-1`) via `filemap_write_and_wait_range()` and call `fuse_sync_writes(inode)`. [F60, F182]
- Folio loops in `fuse_retrieve()` and `fuse_fill_write_pages()` must check `ap->num_folios < max_folios` as well as remaining bytes `num`. Folio loops in `fuse_get_user_pages()`, `fuse_send_write_pages()`, `fuse_notify_store()`, and `fuse_retrieve()` must reset sub-page `start`/`offset` to `0` after the first folio, and `fuse_get_user_pages()` must add `folio_page_idx(folio, pages[i]) << PAGE_SHIFT` to `ap->descs[i].offset`. [F88, F124, F180]

## Synchronization

- Lock ordering: `fc->lock` nests outside `fc->bg_lock`, `fpq->lock` (outside `req->waitq.lock`), and `fiq->lock`; `queue->lock` nests outside `fc->bg_lock`. Drop `fc->lock` before `fuse_dev_end_requests()` and `fuse_uring_abort()`, and drop `queue->lock` before `fuse_dev_end_requests()`, `fuse_request_end()`, or `io_uring_cmd_done()`. [F31, F169]
- Once a `struct fuse_req` is queued or shared, update `req->flags` only with atomic bitops (`set_bit()`, `clear_bit()`, `test_and_set_bit()`). When `fuse_abort_conn()` sees `FR_LOCKED` on `fpq->io`, it sets `FR_ABORTED` in place, leaving `fuse_dev_do_read()`/`fuse_dev_do_write()` to clear `FR_LOCKED`, unlink `req->list` if `!FR_PRIVATE`, and call `fuse_request_end(req)`. [F10, F24]
- When re-acquiring `fiq->lock` or `fpq->lock` to queue requests (`fuse_resend()`, `fuse_dev_do_read()`), recheck `fiq->connected` or `fpq->connected`; if disconnected, clear `FR_PENDING` and end the requests. In `fuse_block_alloc()`, waiting for `fuse_uring_ready(fc)` must also check `fc->connected`. [F34, F39]
- In `request_wait_answer()`, canceling a killed pending request must test `FR_PENDING` and unlink `req->list` under `queue->lock` via `fuse_uring_remove_pending_req()` when `FR_URING` is set (set alongside `req->ring_queue = queue` under `queue->lock` when queuing), or under `fiq->lock` via `fuse_remove_pending_req()` otherwise. [F23, F85]
- `fuse_set_initialized()` runs `smp_wmb()` before `fc->initialized = 1`, paired with `smp_rmb()` in `fuse_get_req()` before `fuse_adjust_compat()`. `fuse_uring_create()` initializes `ring` before `smp_store_release(&fc->ring, ring)`, paired with `smp_load_acquire()` in `fuse_uring_register()`. In `fuse_uring_do_register()`, `fuse_uring_prepare_cancel()` precedes queuing `ent` on `ent_avail_queue`, `fiq->ops = &fuse_io_uring_ops` precedes `ring->ready = true`, and request copies must run via `io_uring_cmd_complete_in_task(cmd, fuse_uring_send_in_task)`. [F18, F19, F20, F103, F160]
- `fuse_send_writepage()` is entered and must return with spinlock `fi->lock` held: try `fuse_simple_background(fm, args, GFP_ATOMIC)` first, and only drop `fi->lock` to retry with `GFP_NOFS | __GFP_NOFAIL` or to call `fuse_writepage_free(wpa)` on error (after decrementing `fi->writectr` and calling `fuse_writepage_finish(wpa)` under `fi->lock`), reacquiring `fi->lock` before returning. [F17, F159]
- `fuse_set_nowrite()` requires `inode_lock(inode)`, and `truncate_pagecache()` or `invalidate_inode_pages2()` in `fuse_open()` and `fuse_do_setattr()` must only run after `fuse_release_nowrite()` clears `FUSE_NOWRITE`. `fuse_file_fallocate()` must unconditionally take `inode_lock(inode)`. [F26, F163]
- Size-modifying ops (`fuse_do_setattr`, `fuse_perform_write`, `fuse_file_fallocate`, `__fuse_copy_file_range`) must bracket requests with `FUSE_I_SIZE_UNSTABLE` on `fi->state`, while reply attribute/size updates must snapshot `fuse_get_attr_version(fc)` before the request and compare against `fi->attr_version` under `fi->lock`. [F42, F68]
- Before sending a request that instantiates or splices a dentry (`fuse_lookup`, `fuse_create_open`, `create_new_entry`), sample `atomic_read(&fc->epoch)` and store it into `d_time` on `entry` (or on the non-NULL alias returned by `d_splice_alias()`, along with `fuse_change_entry_timeout()`). On 32-bit, `fuse_dentry_release()` must free `dentry->d_fsdata` via `kfree_rcu(fd, rcu)`. [F69, F126, F177]
- Non-blocking VFS walks: `__fuse_get_acl()` must return `ERR_PTR(-ECHILD)` when `rcu` is true; `fuse_dentry_revalidate()` under `LOOKUP_RCU` must use `d_inode_rcu(entry)` and return `-ECHILD` if `FUSE_LOOKUP` is needed or `FUSE_I_INIT_RDPLUS` is set; `fuse_perm_getattr()` must return `-ECHILD` on `MAY_NOT_BLOCK`. [F156, F157, F158]
- DAX locking: reclaim takes `filemap_invalidate_lock()` before `fi->dax->sem` (and `fcd->lock` inside `fi->dax->sem`), whereas `fuse_dax_inode_cleanup()` in `evict_inode()` must not take `fi->dax->sem`. After dropping `fi->dax->sem` or `fcd->lock` (with `refcount_inc(&dmap->refcnt)` in `fuse_iomap_begin()`, or `igrab(pos->inode)` in `try_to_free_dmap_chunks()`), re-lookup `start_idx` in `fi->dax->tree` and recheck `dmap->writable` or `dmap->refcnt > 1` under `down_write(&fi->dax->sem)`. [F36, F37, F77, F164, F166]
- Hold `fc->killsb` for read in `fuse_ilookup()`, `fuse_reverse_inval_inode()`, `fuse_reverse_inval_entry()`, and `fuse_try_prune_one_inode()`. Hold `fuse_mutex` for `fuse_ctl_add_conn()`, `fuse_ctl_remove_conn()`, and `fuse_ctl_file_conn_get()`. Hold `rcu_read_lock()` in `fuse_writepage_add_to_bucket()` and `fuse_sync_bucket_dec()`. [F27, F28, F30]

## Object Lifetimes

- Every exit path in `fuse_dev_do_write()` after `fuse_copy_one(cs, &oh, sizeof(oh))`—including `!oh.unique` (`fuse_notify()`) and all errors—must call `fuse_copy_finish(cs)`. In `fuse_dev_splice_read()`, initialize `page_nr = 0` and post-increment in `add_to_pipe(pipe, &bufs[page_nr++])` before checking `ret < 0` so `out:` only puts unconsumed pages. [F1, F118]
- `fuse_readahead()` must obtain folios via `__readahead_folio(rac)` so each holds a ref until `fuse_readpages_end()` calls `folio_put()`, and must clean up any leftover `folio` after the outer loop with `folio_end_read(folio, false)` and `folio_put(folio)`. [F2, F123]
- In `fuse_try_move_folio()`, `folio_get(newfolio)` and reading `buf->flags & PIPE_BUF_FLAG_LRU` must precede `pipe_buf_release(cs->pipe, buf)`, and `folio_clear_uptodate(newfolio)` must precede `folio_end_read()`. In `fuse_copy_folio()`, when `cs->req->args->user_pages` is true, copy via `fuse_copy_fill(cs)` instead of `fuse_ref_folio()`. [F3, F4, F179]
- `fuse_queue_forget()` and `fuse_dev_queue_forget()` consume `forget`, so callers must never `kfree(forget)` afterward. In `fuse_read_batch_forget()`, the `while (head)` loop must advance and `kfree(forget)` every dequeued node even after `fuse_copy_one()` fails. [F7, F117]
- In `fuse_create_open()`, pre-reply failures after `fuse_file_alloc()` jump to `out_free_ff` (`fuse_file_free(ff)` and `kfree(forget)`), whereas post-reply failures must use `fuse_sync_release()`. `fuse_file_put()` (`sync = false` in `fuse_file_release()`) frees `ff` and transfers `ff->args` (`ra`) to `fuse_release_end()` to call `iput(ra->inode)` and `kfree(ra)`. In `fuse_release()`, `write_inode_now(inode, 1)` when `fc->writeback_cache` is set must precede `fuse_release_common()`. [F6, F8, F161, F183]
- Because `__fuse_simple_request()` points `req->args` at caller stack variables, `request_wait_answer()` may only return early on a fatal signal if `req` is removed while `FR_PENDING` is set, and otherwise must wait uninterruptibly for `FR_FINISHED`. In `fuse_direct_IO()`, copy `io->blocking` to a local before `fuse_aio_complete()`, and hold an extra `kref_get(&io->refcnt)` when waiting on stack `wait`. [F146, F147]
- `fuse_uring_entry_teardown()` (and `fuse_uring_stop_list_entries()`, using `list_for_each_entry_safe()`) must move `ent` to `queue->ent_released` (`FRRS_RELEASED`) instead of `kfree(ent)`, deferring free to `fuse_uring_destruct()`. `fuse_backing_free()` must use `kfree_rcu(fb, rcu)` (paired with `rcu_read_lock()` and `fuse_backing_get()` in `fuse_backing_lookup()`). `fuse_dax_conn_free()` must set `fc->dax = NULL`. [F5, F12, F15, F29, F119]
- In `cuse_channel_open()`, after `fuse_dev_alloc_install()` and `fuse_conn_put(&cc->fc)`, `fuse_dev_free(fud)` frees both `fud` and `cc`. In `cuse_process_init_reply()`, free `dev` via `put_device(dev)` after `device_initialize(dev)`, and suppress uevents until `cdev_add()` and `list_add(&cc->list, ...)` complete. `cuse_channel_release()` must unlink `cc->list` and call `device_unregister(cc->dev)` before `fuse_dev_release()`. [F16, F152, F153, F154]

## API Contracts

- `fuse_simple_background()` does not call `args->end` on queuing failure, so callers must clean up when it returns non-zero. `__fuse_simple_request()` returns `< 0` on error, `0` when `!args->out_argvar`, or the positive last output arg size when `args->out_argvar` is true. [F9, F43]
- Never dereference `/dev/fuse` `file->private_data` directly (it may be `FUSE_DEV_SYNC_INIT`): `fuse_get_dev()` waits and returns `ERR_PTR()`, while `__fuse_get_dev()` returns `NULL`. `fuse_dev_ioctl_clone()` must check `fd_file(f)->f_op == file->f_op`, and `cuse_channel_fops.unlocked_ioctl` must be `NULL`. [F44, F143, F155]
- `alloc_dax_mapping()` and `fuse_file_alloc()` return `NULL` on failure, whereas `alloc_dax_mapping_reclaim()` and `fuse_file_open()` return `ERR_PTR()`. `fuse_try_move_folio()` returns `0` on steal, `< 0` on error, and `1` to fall back to copy. `create_new_nondir()` is only valid for `!S_ISDIR(mode)`. [F45, F46, F47, F48]
- `stat` may be `NULL` in `fuse_do_statx()`, `fuse_do_getattr()`, and `fuse_update_get_attr()`; `fi` may be `NULL` in `fuse_sync_release()` and `fuse_prepare_release()` (which must not `igrab()` when `sync` is true); `ff->args` may be `NULL` and is a union with `open_outarg`, so `fuse_prepare_release()` must check `ff->args` and `memset()` it to zero first. [F50, F52, F53]
- When `args->in_pages` or `args->out_pages` is true, `struct fuse_args` must be embedded in `struct fuse_args_pages` with the folio payload as the last arg, and `struct fuse_in_arg` and `struct fuse_arg` must keep identical layouts. Headerless opcodes with payload in `args->in_args[1..]` must call `fuse_set_zero_arg0(args)`. [F58, F140, F141]
- File-modifying ops must call `kiocb_modified()`, `file_modified()`, or `file_remove_privs()` under `inode_lock(inode)`. Only inode-creating ops (`fuse_create_open`, `create_new_entry`, `fuse_rename2` with `RENAME_WHITEOUT`) pass `mnt_idmap` via `fuse_simple_idmap_request()`; others must pass `&invalid_mnt_idmap`. Whole-file `fuse_dax_break_layouts()` calls must pass `0, -1` (`ULLONG_MAX`). [F59, F185, F186]

## Error Handling

- Write/copy completions (`fuse_aio_complete_req`, `fuse_send_write`, `fuse_send_write_pages`, `__fuse_copy_file_range`) must reject replies where reported bytes exceed requested bytes with `-EIO`. `fuse_dev_do_write()` and `fuse_uring_out_header_has_err()` must reject `oh.error <= -512` or `> 0` with `-EINVAL`. [F89, F90]
- In `fuse_dentry_revalidate()`, `-ENOMEM` or `-EINTR` from `fuse_simple_request()` must jump to `out` (returning errno) rather than `invalid` (`0`), whereas `fuse_unlink()`, `fuse_rmdir()`, and `fuse_rename_common()` must call `fuse_invalidate_entry()` on `-EINTR`. In `fuse_update_get_attr()`, reset `err = 0` when `fuse_do_statx()` returns `-ENOSYS` before `goto retry`. [F110, F111]

## External Contracts

- In `fuse_uring_cmd()`, dispatch `IO_URING_F_CANCEL` to `fuse_uring_cancel()` before any `IO_URING_F_SQE128` or connection checks; validate `qid < ring->nr_queues`, `sqe->len == FUSE_URING_IOV_SEGS` (2), `iov[0].iov_len >= sizeof(struct fuse_uring_req_header)`, and `iov[1].iov_len >= ring->max_payload_sz`. [F97, F98, F115]
- Validate userspace inputs and namespaces: `size >= sizeof(outarg)` before subtraction and NUL-termination in `fuse_notify_*()`; zero `[nr_bytes, folio_size(folio))` in `fuse_notify_store()` on partial EOF folios; scramble `fl_owner_t` with `fuse_lock_owner_id()`; translate PIDs via `fc->pid_ns`; enforce `!fc->posix_acl` in `fuse_get_inode_acl()`, `fuse_no_acl()`, and `fuse_set_acl()`; require `CAP_SYS_ADMIN`, 1-based IDs, zero `flags`/`padding`, and `d_is_reg()` in `fuse_backing_open()`. [F57, F93, F94, F100, F187, F189, F190, F191]

## Known Pitfalls

- `fuse_folios_alloc()` and `fuse_retrieve()` allocate `folios` and `descs` in one compound buffer: `fuse_pages_realloc()` must update both pointers before freeing old `ap->folios`, and callers must never `kfree(ap->descs)` (or `kfree(ra->ap.folios)`). `extend_arg()` uses `krealloc()`, invalidating interior pointers. [F75, F138, F139]
- `fi->inval_mask` is a `u32`, so atomic updates must use `set_mask_bits(&fi->inval_mask, ...)`, never `set_bit()`/`clear_bit()`. Use `time_before64(..., get_jiffies_64())` for 64-bit `fuse_dentry_time()` and `fi->i_time`. Decrement read length by 1 in `fuse_do_readfolio()`/`fuse_send_readpages()` when `pos + (len - 1) == LLONG_MAX`; check `attr->blksize != 0` before `ilog2()` in `fuse_fillattr()`; use `DIV_ROUND_UP(ret + start, PAGE_SIZE)` in `fuse_get_user_pages()`; clamp highmem `fuse_copy_folio()` to `PAGE_SIZE - offset_in_page(offset)`. [F129, F131, F132, F134, F151, F176]
