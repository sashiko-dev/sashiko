# ATMEL MACB ETHERNET DRIVER

The Atmel/Cadence MACB/GEM Ethernet driver supports Cadence MACB (10/100 EMAC), AT91RM9200 EMAC, and Cadence GEM (Gigabit/10G Ethernet MAC) controllers across platform and PCI buses. It manages multi-queue DMA descriptor rings, NAPI RX/TX polling, phylink/PCS/MDIO link management, IEEE 1588 PTP hardware timestamping and clock adjustment, ethtool n-tuple RX flow steering, and IEEE 802.1Qbv (TAPRIO/ENST) scheduled traffic offload.

## Architecture & Data Flow

- `macb_init_buffers()` writes a single shared `RBQPH` and `TBQPH` (`upper_32_bits(bp->queues[0].*_ring_dma)`) while per-queue `RBQP`/`TBQP` hold only `lower_32_bits`; `macb_alloc_consistent()` must reject TX/RX ring allocations where `upper_32_bits(dma) != upper_32_bits(dma + size - 1)`. [F104]
- Clearing `MACB_BIT(TE)` in `NCR` (`macb_mac_link_down()`, `macb_hresp_error_task()`) resets the hardware TX pipeline and queue pointers, so non-EMAC paths must call both `bp->macbgem_ops.mog_init_rings(bp)` and `macb_init_buffers(bp)` before re-enabling `MACB_BIT(RE) | MACB_BIT(TE)`. [F57]
- Hardware sets `MACB_BIT(TX_USED)` only on a frame's first descriptor and `tx_skb->skb` is set only on its last descriptor, so `macb_tx_complete()` and `macb_tx_error_task()` must test `TX_USED` on the first descriptor and advance `tail` until `tx_skb->skb` is non-NULL. [F91]
- For LSO (`gso_size != 0`), `macb_start_xmit()` puts headers (`skb_transport_offset` for UDP, `skb_tcp_all_headers` for TCP) in the first TX descriptor (`i == queue->tx_head`), `macb_tx_map()` sets `MSS_MFS` only on later descriptors, and `desc_cnt` uses `DIV_ROUND_UP(..., bp->max_tx_length)` plus 1 if `is_lso && skb_headlen(skb) > hdrlen`. `bp->max_tx_length` and non-final UFO buffers in `macb_features_check()` (checking `skb_is_nonlinear` before `nr_frags--`) must align to `MACB_TX_LEN_ALIGN` (8). [F79, F111, F112, F171]
- Because GEM shares RX descriptor bits 22:23 between `GEM_RX_TYPEID_MATCH` and `GEM_RX_CSUM` and cannot offload RX checksums in promiscuous mode, `GEM_BIT(RXCOEN)` in `NCFGR` must be enabled iff `(dev->features & NETIF_F_RXCSUM) && !(dev->flags & IFF_PROMISC)` across `macb_init_hw()`, `macb_set_rx_mode()`, and `macb_set_rxcsum_feature()`. [F59]
- In `gem_rx_refill()`, `queue->rx_prepared_head` must only be incremented after the SKB and DMA mapping are stored in `queue->rx_skbuff[entry]` and written to the descriptor with `RX_USED` cleared. In `macb_rx()`, `first_frag` must be reset to `-1` after `RX_EOF`, any unclosed `first_frag != -1` discarded via `discard_partial_frame()` on a new `RX_SOF`, and `queue->rx_tail` set to `first_frag` when `first_frag != -1` (else `tail`). [F54, F92]
- `macb_64b_desc()` and `macb_ptp_desc()` must cast `desc` to a byte pointer before adding `sizeof(struct macb_dma_desc)` (plus `sizeof(struct macb_dma_desc_64)` in `macb_ptp_desc()` when `bp->hw_dma_cap == HW_DMA_CAP_64B_PTP`). In `macb_probe()`, `bp->hw_dma_cap` must be set before computing `bp->rx_bd_rd_prefetch` and `bp->tx_bd_rd_prefetch`, and `GEM_BFEXT(RXBD_RDBUFF/TXBD_RDBUFF, ...)` must be checked for non-zero (`if (val)`) before evaluating `(2 << (val - 1)) * macb_dma_desc_get_size(bp)`. [F107, F117, F119]
- Before `MACB_CAPS_MACB_IS_GEM` is set by `macb_configure_caps()`, `macb_probe()` and `macb_probe_queues()` must call `hw_is_gem()` rather than `macb_is_gem(bp)`. Shared code accessing the `bp->hw_stats` union must check `macb_is_gem(bp)`, and `macb_update_stats()`/`gem_update_stats()` iterate `macb_stats`, `gem_stats`, and `queue_stats` via pointer arithmetic, so their fields must match `MACB_PFR..MACB_TPF`, `gem_statistics[]`, and `queue_statistics[]`. [F46, F83, F142]
- Every `struct macb_config` without `MACB_CAPS_USRIO_DISABLED` must populate a non-NULL `.usrio`, and any `USRIO` register access must check `!(bp->caps & MACB_CAPS_USRIO_DISABLED)`. Similarly, `bp->rx_ring_tieoff` is allocated only when `!(bp->caps & MACB_CAPS_QUEUE_DISABLE)`, which `macb_init_tieoff()` and `macb_suspend()` must check before accessing `bp->rx_ring_tieoff`. [F36, F45, F139]
- `macb_init()` must call `INIT_LIST_HEAD(&bp->rx_fs_list.list)` unconditionally even when `bp->max_tuples == 0`. Under `bp->rx_fs_lock`, `bp->rx_fs_list.list` must be kept sorted by `fs.location` with `bp->rx_fs_list.count` updated in lockstep, validating `fs->location < bp->max_tuples = min(SCR2CMP / 3, T2SCR)` and `fs->ring_cookie < bp->num_queues`. [F35, F69, F84]
- PTP one-step sync packets (`ptp_one_step_sync(skb) == true`) must be excluded from software FCS in `macb_pad_and_fcs()`, `MACB_BIT(TX_NOCRC)` in `macb_tx_map()`, and `gem_ptp_do_txstamp()` in `macb_tx_complete()`. [F162]

## Synchronization

- When both `queue->tx_ptr_lock` and `bp->lock` are needed, `queue->tx_ptr_lock` must be acquired first with `spin_lock_irqsave()` before `bp->lock` (`macb_start_xmit()`, `macb_tx_restart()`), and `bp->lock` must never be held when acquiring `queue->tx_ptr_lock`. Hold `queue->tx_ptr_lock` with `spin_lock_irqsave()` across ring space checks, `tx_head`/`tx_tail` updates, BQL reporting, and subqueue stop/wake calls in `macb_start_xmit()`, `macb_tx_complete()`, `macb_tx_restart()`, and `macb_tx_complete_pending()`. [F20, F144]
- Call `napi_disable()` outside `bp->lock` in `macb_tx_error_task()`, `macb_close()`, and `macb_suspend()`. In `macb_tx_error_task()`, after `napi_disable(&queue->napi_tx)` and acquiring `bp->lock`, call `netif_tx_stop_all_queues()` and `macb_halt_tx(bp)` (using `read_poll_timeout_atomic` on `MACB_TSR` for `MACB_BIT(TGO)` to clear, or clearing `MACB_BIT(TE)` in `MACB_NCR` on timeout) before draining the TX ring and writing `TBQP`. [F21, F133, F148]
- Call `napi_enable()` on all queues before initializing hardware and starting phylink in `macb_open()`/`macb_resume()`, and `napi_disable()` before hardware reset or ring free in `macb_close()`/`macb_suspend()`. Inside `macb_interrupt()` under `bp->lock`, check `netif_running(dev)` each iteration—disabling interrupts via `IDR` and breaking if false—paired with `macb_close()` holding `bp->lock` around `macb_reset_hw(bp)`. [F22, F23]
- In `macb_rx_poll()` and `macb_tx_poll()`, after `napi_complete_done()` returns true and `IER` is written, recheck `macb_rx_pending(queue)` or `macb_tx_complete_pending(queue)` and, if true, write `IDR` (and `ISR` if `MACB_CAPS_ISR_CLEAR_ON_WRITE`) and call `napi_schedule(napi)`. In `macb_interrupt()`, setting `queue->txubr_pending = true` on `MACB_BIT(TXUBR)` requires `wmb()` before scheduling `napi_tx`, paired with `rmb()` in `macb_tx_poll()` after `macb_tx_complete()`. [F25, F29]
- When reading descriptors (`gem_rx`, `macb_rx`, `gem_ptp_txstamp`), check `RX_USED` or `TX_USED`/`DMA_TXVALID` after `rmb()`, then `dma_rmb()` before reading `ctrl` or `ts_1`/`ts_2`. When refilling RX descriptors (`gem_rx_refill`, `macb_set_addr`), clear `ctrl` and write `addrh` before `dma_wmb()` precedes `addr` (clearing `RX_USED`). In `macb_tx_map()`, set `TX_USED` on the sentinel at new `tx_head` first, then fill descriptors in reverse with `wmb()` before `ctrl`. [F26, F27, F28]
- Serialize `bp->hw_stats`/`bp->ethtool_stats` under `bp->stats_lock` with IRQs disabled; TSU clock registers (`gem_tsu_get_time()`, `gem_tsu_set_time()`, `gem_tsu_incr_set()`) under `spin_lock_irqsave(&bp->tsu_clk_lock, ...)`; flow filter list and `SCRT2`/compare registers under `spin_lock_irqsave(&bp->rx_fs_lock, ...)`; and ENST registers (`macb_taprio_setup_replace()`, `macb_taprio_destroy()`) under `spin_lock_irqsave(&bp->lock, ...)`. [F19, F30, F31, F32, F146]
- `bp->hresp_err_bh_work` (`macb_hresp_error_task()`) runs on `system_bh_wq` in BH context and must never sleep, and `macb_mac_link_up()` must call `macb_set_tx_clk()` after unlocking `bp->lock`. In `macb_suspend()`/`macb_resume()`, use `rcu_dereference(idev->ifa_list)` for `WAKE_ARP` and unlock `bp->lock` on `devm_request_irq()` failure when swapping queue 0's WoL IRQ handler. [F16, F147, F151, F159]

## Object Lifetimes

- In `macb_free_consistent()`, call `bp->macbgem_ops.mog_free_rx_buffers(bp)` before freeing `bp->queues[0].rx_ring` and clearing `queue->rx_ring`, and free the contiguous multi-queue ring buffers at `bp->queues[0].tx_ring` and `bp->queues[0].rx_ring` using sizes computed with `macb_tx_ring_size_per_queue()` and `macb_rx_ring_size_per_queue()` (including prefetch bytes). [F5, F118]
- Clear `queue->rx_skbuff[entry] = NULL` in `gem_rx()` when detaching a received SKB, and in `macb_tx_complete()`/`macb_tx_error_task()` finish reading `skb` fields and TX timestamps (`gem_ptp_do_txstamp()`) before `macb_tx_unmap()` frees `tx_skb->skb`. [F6, F168]
- In `macb_remove()`, `unregister_netdev(dev)` must precede `phy_exit(bp->sgmii_phy)`, `mdiobus_unregister(bp->mii_bus)`, `phylink_destroy(bp->phylink)`, and `cancel_work_sync(&bp->hresp_err_bh_work)` (both before `free_netdev(dev)`), and do not call `macb_clks_disable()` manually because `device_set_wakeup_enable(&bp->pdev->dev, 0)` before `pm_runtime_disable()` lets `macb_runtime_suspend()` disable clocks. [F24, F129, F130]
- Pair failed `pm_runtime_get_sync()` with `pm_runtime_put_noidle()` in C45 MDIO ops (C22 uses `pm_runtime_resume_and_get()`), and in `macb_suspend()`/`macb_resume()` when `!device_may_wakeup(&bp->dev->dev)`, call `phy_exit(bp->sgmii_phy)` and `phy_init(bp->sgmii_phy)` before the early return on `!netif_running(netdev)`. [F12, F135]

## API Contracts

- In `macb_tx_map()`, set every mapped fragment's `tx_skb->skb = NULL` before advancing `tx_head` and set `tx_skb->skb = skb` only on the last fragment; set `mapped_as_page = false` for `dma_map_single()` and `true` for `skb_frag_dma_map()`. On DMA error, `macb_tx_map()` unmaps `[queue->tx_head, tx_head)` via `macb_tx_unmap(bp, tx_skb, 0)` and returns `0` without freeing `skb` (freed by `macb_start_xmit()`); non-NAPI callers of `macb_tx_unmap()` must pass `budget = 0`. [F3, F40, F150, F154]
- In `macb_clear_csum()`, call `skb_cow_head(skb, 0)` when `skb->ip_summed == CHECKSUM_PARTIAL` before zeroing the checksum field. In `macb_pad_and_fcs()`, check `skb_is_nonlinear(*skb)` alongside `skb_cloned(*skb)` and `skb_header_cloned(*skb)` to force `skb_copy_expand(*skb, 0, padlen, GFP_ATOMIC)` before `skb_put_zero()`/`skb_put_u8()`, consuming the old `*skb` via `dev_consume_skb_any()` on success and leaving `*skb` untouched on `-ENOMEM` for `macb_start_xmit()` to free. [F4, F160, F167]
- Wrap ring indices with `macb_tx_ring_wrap()`/`macb_rx_ring_wrap()` before scaling with `macb_adj_dma_desc_idx()` when indexing `tx_ring`/`rx_ring` (leaving `tx_skb`/`rx_skbuff` unscaled); express `GEM_DMACFG.RXBS` and `queue->RBQS` in units of `RX_BUFFER_MULTIPLE` (64 bytes); and wrap `GEM_IP4SRC_CMP`/`GEM_IP4DST_CMP`/`GEM_PORT_CMP` in `T2CMP_OFST()` when accessing `T2CMPW0`/`T2CMPW1` (unlike `SCRT2`). [F48, F49, F50]
- Write `GEM_PCSCNTRL` in `macb_mac_config()` only after setting `GEM_BIT(PCSSEL)` in `GEM_NCFGR`; downcast `phylink_pcs` via `phylink_usx_pcs` (`macb_phylink_usx_pcs_ops`) or `phylink_sgmii_pcs` (`macb_phylink_pcs_ops`); write 1s to `ISR` when `MACB_CAPS_ISR_CLEAR_ON_WRITE` is set; and pass `struct macb_queue *` as IRQ `dev_id` for `macb`/`gem` handlers. Across suspend/resume when `netif_running(netdev)`, save/restore `pm_data.usrio` and `pm_data.scrt2` with `macb_restore_features()`, and clear `TE | RE` in `NCR` before modifying `RBQP` on WoL suspend. [F70, F125, F128, F137, F140, F141]

## Error Handling

- On `macb_open()` failure after enabling NAPI and hardware, unwind in reverse: `phy_power_off(bp->sgmii_phy)`, `macb_reset_hw(bp)`, `napi_disable()` on all queues, `macb_free_consistent(bp)`, and `pm_runtime_put_sync(&bp->pdev->dev)`; `macb_open()` and `at91ether_open()` must explicitly `return 0;` before error labels. [F7, F95]
- Check `*pclk`/`*hclk` with `IS_ERR_OR_NULL()` and `*tx_clk`/`*rx_clk`/`*tsu_clk` with `IS_ERR()` in `macb_clk_init()`; in `fu540_c000_clk_init()`, clear `*tx_clk = NULL` if `clk_prepare_enable()` fails before `macb_clks_disable()`. Gate `sgmii_phy` init and `zynqmp_pm_set_gem_config()` in `init_reset_optional()` on `PHY_INTERFACE_MODE_SGMII` (and `zynqmp_pm_is_function_supported() == 0`), calling `phy_exit()` on error; in `macb_probe()`, abort on `-EPROBE_DEFER` from `of_get_ethdev_address()` and fall back to `macb_get_hwaddr(bp)` on other errors. [F8, F42, F43, F44, F136]
- Check `if (bp->ptp_info)` before invoking `bp->ptp_info` callbacks, and in `gem_ptp_init()` reset `bp->ptp_clock = NULL` when `IS_ERR(bp->ptp_clock)` is true. In `macb_rx_frame()`, return `0` on delivery, `1` on SKB allocation failure (no ring reset), and `-1` on length inconsistency (`offset + frag_len > len` when `frag != last_frag`, freeing `skb`) so `macb_rx()` resets the ring. [F37, F38, F39, F80]

## External Contracts

- In `macb_set_wol()`, call `phylink_ethtool_set_wol()` first and return any error except `-EOPNOTSUPP`; in `macb_get_wol()`, call `phylink_ethtool_get_wol()` before OR-ing `WAKE_MAGIC | WAKE_ARP` and `bp->wolopts`. Define `.pcs_config` in both PCS ops, return non-NULL from `macb_mac_select_pcs()` only for `10GBASER`/`SGMII`, and set `mac_managed_pm = true` in `macb_mii_probe()` (calling `phylink_stop()` in `macb_suspend()` without `netif_carrier_off()`). Balance BQL (`netdev_tx_sent/completed/reset_queue`) and round ring sizes with `roundup_pow_of_two()`. [F33, F34, F164, F165, F169, F172]

## Known Pitfalls

- `bp->queue_mask` is a sparse bitmask of hardware queues (`hw_q`), whereas `bp->queues[0..bp->num_queues-1]` is dense (`q`); `GEM_ISR`/`IER`/`IDR`/`IMR`/`TBQP`/`RBQP`/`RBQS` take `(hw_q - 1)` for `hw_q > 0`, `GEM_ENST_*` takes `hw_q`, and `platform_get_irq()` takes `q`. [F77]
- Fetch `skb` header pointers in `macb_start_xmit()` only after `macb_clear_csum()` and `macb_pad_and_fcs()` return, use `skb_copy_expand()` (never shifting into `skb_headroom()`) when `skb_tailroom(*skb) < padlen` in `macb_pad_and_fcs()`, and extract RX descriptor DMA addresses via `macb_get_addr()` (which strips `RX_USED`, `RX_WRAP`, and `DMA_RXVALID`). [F58, F153, F161]
- Never use 32-bit `MACB_BF*`/`GEM_BF*` macros on 32-bit (`GEM_TSL`) or 64-bit fields; cast upper 32-bit words (`addrh`, `sech`, `GEM_OCTTXH`/`GEM_OCTRXH`) to `u64` before `<< 32`; and use `u64` with `div_u64`/`div_u64_rem` for `<< GEM_SUBNSINCR_SIZE` and `scaled_ppm * word` in `gem_ptp_adjfine()`/`gem_ptp_init_timer()`. [F102, F103, F105]
- In `gem_tsu_get_time()`, read `TN` before and after `TSL`/`TSH` and retry if `first > second`; in `gem_tsu_set_time()`, write `0` to `TN` before `TSH`/`TSL`/`TN`; in `gem_tsu_incr_set()`, write `GEM_TISUBN` (splitting `SUBNSINCRL` [31:24] and `SUBNSINCRH` [15:0]) before `GEM_TI`; and in `gem_hw_timestamp()`, subtract `GEM_DMA_SEC_TOP` when `GEM_DMA_SEC_TOP >> 1` is set in `ts->tv_sec` and clear in `tsu.tv_sec`. [F51, F113, F114]
- Return early in `macb_set_tx_clk()` when `bp->caps & MACB_CAPS_CLK_HW_CHG` is set; use `phy_interface_mode_is_rgmii(bp->phy_interface)` for RGMII checks; pass `&bp->pdev->dev` (not `&bp->dev->dev`) to `device_may_wakeup()` in runtime PM callbacks and `dev_get_drvdata()` for `struct net_device *`; index `mc_filter` as 32-bit words (`mc_filter[bitnr >> 5] |= 1 << (bitnr & 31)`) in `macb_sethashtable()`; and test signed `conf->base_time < 0` in `macb_taprio_setup_replace()`. [F89, F97, F100, F101, F126, F127]
