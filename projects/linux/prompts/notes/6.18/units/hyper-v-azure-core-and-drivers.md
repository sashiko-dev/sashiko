# Hyper-V/Azure CORE AND DRIVERS

This unit provides Hyper-V guest and root-partition (`mshv`) infrastructure—hypercall/MSR access, synthetic timers, VMBus channel/ring-buffer management, confidential VM paravisor/isolation support, and integration services (`hv_balloon`, `hv_kvp`, `hv_snapshot`, `hv_util`, `hid-hyperv`)—along with paravirtualized networking (`hv_netvsc`), virtual PCIe pass-through (`pci-hyperv`), SCSI/FC storage (`storvsc`), UIO (`uio_hv_generic`), `AF_VSOCK` (`hyperv_transport`), and userspace daemons (`tools/hv`).

## Architecture & Data Flow

- Every path through `vmbus_onoffer()` and `vmbus_process_offer()` must decrement `vmbus_connection.offer_in_progress` once (under `channel_mutex` when inserting into `chn_list`, `sc_list`, or `channels[]`), then queue `vmbus_add_channel_work` onto `handle_primary_chan_wq` (primary) or `handle_sub_chan_wq` (sub-channel). [F8, F185]
- `vmbus_devs[]` must match `enum vmbus_device_type` indices, and `channel_message_table[]` must match `enum vmbus_channel_message_type` indices with `min_payload_len` at least the size of the struct cast by each `message_handler`; when `hv_is_isolation_supported()`, `vmbus_connect()` must reject versions `< VERSION_WIN10_V5_2` and `vmbus_is_valid_offer()` must reject non-hvsock offers without `.allowed_in_isolated = true`. [F87, F88, F89, F166]
- In `hv_balloon`, `alloc_balloon_pages()` splits higher-order allocations into order-0 pages and marks them `PageOffline`, so `balloon_up()` error paths and `balloon_down()` must release them via `free_balloon_pages()`; in `hv_mem_hot_add()`, `has->ha_end_pfn` and `has->covered_end_pfn` must be advanced under `dm_device.ha_lock` before `add_memory()` and rolled back under `ha_lock` on failure, and `hv_page_online_one()` must mark `!has_pfn_is_backed()` PFNs with `__SetPageOffline()` without calling `generic_online_page()`. [F16, F73, F564]
- On a `struct vmbus_channel`, `primary_channel` is `NULL` on primary channels and non-NULL on subchannels (where `device_obj` is `NULL`), so callbacks invoked on both (`storvsc_on_channel_callback`, `hv_uio_channel_cb`) must resolve `hv_device` via `chan->primary_channel ? chan->primary_channel->device_obj : chan->device_obj`. [F429]
- In `hv_netvsc`, `netvsc_switch_datapath()` must clear `data_path_is_vf = false` before sending `NVSP_MSG4_TYPE_SWITCH_DATA_PATH` when switching to synthetic, and set `data_path_is_vf = true` only after `wait_for_completion(&nv_dev->channel_init_wait)` when switching to VF; both `netvsc_xmit()` and `netvsc_ndoxdp_xmit()` must check `vf_netdev && netif_running(vf_netdev) && netif_carrier_ok(vf_netdev) && !netpoll_tx_running(ndev) && ndev_ctx->data_path_is_vf` under RCU-bh before transmitting on `vf_netdev`, passing `vf_netdev` to any delegated VF ops. [F251, F272, F307]
- In `netvsc_receive()` and `rndis_filter_receive_data()`, `buflen <= net_device->recv_section_size` must be verified before copying into `nvchan->recv_buf`, `nvchan->rsc.cnt` must be reset to `0` on any validation/receive error, non-RSC packet, `RNDIS_PKTINFO_1ST_FRAG`, or completed RSC packet (`!rsc_more`), and `nvchan->rsc.{vlan,csum_info,hash_info}` must only be read when their bit in `nvchan->rsc.ppi_flags` is set. [F244, F277, F301]
- In `pci-hyperv`, `_hv_pcifront_read_config()` and `_hv_pcifront_write_config()` range checks `where >= START && where + size <= END` must use the next register's offset as `END` and precede the general `where + size <= CFG_PAGE_SIZE` MMIO branch; in `hv_compose_msi_msg()`, existing `data->chip_data` (`struct tran_int_desc`) must only be reused when `multi_msi` is true (where secondary IRQs keep `int_desc->vector_count = 0`), and freed via `hv_int_desc_free()` for single-MSI and MSI-X. [F274, F293, F305, F347]

## Synchronization

- Callers using per-CPU hypercall pages (`hyperv_pcpu_input_arg`, `hyperv_pcpu_output_arg`, or `post_msg_page`), including `hv_post_message()`, `hv_call_deposit_pages()`, `hv_call_get_vp_registers()`, `hv_irq_retarget_interrupt()`, and `hv_pci_read_mmio()`/`hv_pci_write_mmio()` (where `out` must be offset by `sizeof(*in)`), must disable local interrupts with `local_irq_save()`; in `hv_call_add_logical_proc()` and `hv_call_create_vp()`, each retry after `hv_call_deposit_pages()` must re-disable IRQs, re-fetch `*this_cpu_ptr(hyperv_pcpu_input_arg)`, and re-populate all fields. [F79, F178, F263]
- All accesses to `vmbus_connection.chn_msg_list` require `spin_lock_irqsave(&vmbus_connection.channelmsg_lock, flags)`, and in `__vmbus_establish_gpadl()`, `__vmbus_open()`, and `vmbus_teardown_gpadl()`, `msginfo` must be added to `chn_msg_list` and `channel->rescind` checked under `channelmsg_lock` before `vmbus_post_msg()` and `wait_for_completion(&msginfo->waitevent)`. [F21, F197]
- `cpus_read_lock()` must be acquired outside `vmbus_connection.channel_mutex`, and `send_modifychannel_with_ack()` (called with `channel_mutex` held) must unlock `channel_mutex` around `wait_for_completion(&info->waitevent)` and re-acquire it before returning so `vmbus_onoffer_rescind()` can make progress. [F7, F184]
- `vmbus_add_channel_work()` must set `newchannel->probe_done = true` on both success and failure paths (waited on by `vmbus_onoffer_rescind()` after `vmbus_rescind_cleanup()`), and `vmbus_reset_channel_cb()` must disable the `callback_event` tasklet and clear `channel->onchannel_callback` under `spin_lock_irqsave(&channel->sched_lock, flags)` before `vmbus_close_internal()` tears down the ring buffer or `vmbus_onoffer_rescind()` sets `channel->rescind`. [F28, F186]
- `hv_get_bytes_to_read()` and `hv_get_bytes_to_write()` must use `READ_ONCE()` on `write_index` and `read_index`; `hv_begin_read()`, `hv_end_read()`, and `uio_hv_generic`'s `set_event()` must issue `virt_mb()` after writing `ring_buffer->interrupt_mask`; and in `vmbus_on_event()`, when `HV_CALL_BATCHED` sees `hv_end_read(&channel->inbound) != 0`, it must call `hv_begin_read()` and `tasklet_schedule(&channel->callback_event)` rather than looping in place. [F113, F423, F424, F538]
- In `hv_kvp.c` and `hv_snapshot.c`, `kvp_respond_to_host()` and `vss_respond_to_host()` must only be called if `cancel_delayed_work_sync()` on `kvp_timeout_work` / `vss_timeout_work` returns `true`, and `kvp_transaction.state` / `vss_transaction.state` must not be reset to `HVUTIL_READY` until after `*_respond_to_host()` finishes mutating the shared `recv_buffer`. [F41, F76, F78]
- In `hv_netvsc`, `netvsc_probe()` must hold `rtnl_lock()` continuously across `rndis_filter_device_add()`, scheduling `nvdev->subchan_work`, `register_netdevice()`, and adding to `netvsc_dev_list`; workqueue handlers (`netvsc_subchan_work`, `netvsc_vf_setup`, `netvsc_vfns_work`, `netvsc_link_change`) must use `rtnl_trylock()` and re-validate pointers after locking; `netvsc_send()` requires `rcu_read_lock_bh()` and `netvsc_dma_map()` must use `GFP_ATOMIC`. [F216, F220, F353, F356]
- `hv_compose_msi_msg()` runs with IRQ locks held, so it must use `GFP_ATOMIC`, `tasklet_disable_in_atomic(&channel->callback_event)`, and poll `try_wait_for_completion()` while calling `hv_pci_onchannelcallback(hbus)` under `spin_lock_irqsave(&channel->sched_lock, flags)` when `channel->onchannel_callback != NULL`; if a stack-allocated `struct pci_packet` aborts or times out, it must remove `trans_id` via `vmbus_request_addr_match()` (and `hv_pci_onchannelcallback()` must invoke `completion_func()` under `lock_requestor()`). [F30, F365, F366]
- In `storvsc_drv.c`, `stor_device->stor_chns[]` and `alloced_cpus` updates require `spin_lock_irqsave(&stor_device->lock, flags)` (`WRITE_ONCE` paired with `READ_ONCE` in `storvsc_do_io()`, which re-checks `stor_chns[q_num]` under `lock` before `get_og_chn()`); `storvsc_dev_remove()` and `storvsc_suspend()` must set `destroy = true` + `wmb()` and call `storvsc_wait_to_drain()` before `vmbus_close()`; and `storvsc_handle_error()`/`storvsc_queuecommand()`/`storvsc_do_io()` must use `GFP_ATOMIC` and defer scans/removals to `handle_error_wq`. [F410, F413, F414, F533, F544, F545]
- In `hyperv_transport.c`, `hvs_open_connection()` must hold `lock_sock(sk)` after `vsock_find_bound_socket()` and complete `set_per_channel_state()` and `sock_hold()` on `conn_from_host ? new : sk` before `vmbus_set_chn_rescind_callback(chan, hvs_close_connection)`; `hvs_do_close_lock_held()` (under `lock_sock(sk)`) must use `cancel_delayed_work(&vsk->close_work)` rather than `cancel_delayed_work_sync()` because `hvs_close_timeout()` acquires `lock_sock(sk)`. [F401, F420, F421, F422, F489, F549]

## Object Lifetimes

- `vmbus_device_register()` consumes ownership of `newchannel->device_obj` and frees it on failure, so `vmbus_add_channel_work()` must not `kfree(newchannel->device_obj)`; before `newchannel->kobj` is initialized in `vmbus_add_channel_work()`, early-exit paths (`vmbus_process_offer()`, `vmbus_onoffer()`) must call `kfree(newchannel)` rather than `free_channel()`. [F1, F2]
- `vmbus_disconnect_ring()` must close and remove all sub-channels on `channel->sc_list` (using `list_for_each_entry_safe()`, waiting on `rescind_event` if `rescind` is set, and calling `hv_process_channel_removal()` under `channel_mutex`) before closing the primary channel; `vmbus_close_internal()` must first call `vmbus_reset_channel_cb()` and only call `vmbus_free_requestor()` and allow `vmbus_free_ring()` when both `CHANNELMSG_CLOSECHANNEL` and `vmbus_teardown_gpadl()` succeed. [F5, F6, F116]
- Whenever `set_memory_decrypted()` or `set_memory_encrypted()` fails in `hv_synic_alloc()`, `hv_synic_free()`, `vmbus_connect()`, `vmbus_disconnect()`, `__vmbus_establish_gpadl()`, or `vmbus_teardown_gpadl()`, the pages must be leaked rather than freed: `gpadl->decrypted` must be set to `true` before `set_memory_decrypted()`, cleared only if `set_memory_encrypted()` succeeds, and checked (`!gpadl.decrypted`) before freeing pages in `vmbus_free_ring()`, `free_netvsc_device()`, and `hv_uio_cleanup()` / `hv_uio_probe()`. [F69, F82, F181, F198, F557]
- In `netvsc_device_remove()`, `RCU_INIT_POINTER(net_device_ctx->nvdev, NULL)` must precede `napi_disable()` / `netif_queue_set_napi(..., NULL)` (called only for `i < ndev->real_num_rx_queues`) and `netif_napi_del()` (for all `i < net_device->num_chn`), `netvsc_revoke_recv_buf()`/`netvsc_revoke_send_buf()` must run before `vmbus_close()`, GPADL teardown must run before `vmbus_close()` when `vmbus_proto_version < VERSION_WIN10` and after when `>= VERSION_WIN10`, and `net_device` must be freed via `free_netvsc_device_rcu()`. [F199, F200, F222]
- In `storvsc_command_completion()`, `cmd_request->payload` and `cmd_request->payload_sz` must be saved to locals before `scsi_done(scmnd)` and `kfree(payload)` called only when `payload_sz > sizeof(struct vmbus_channel_packet_multipage_buffer)`; in `storvsc_queuecommand()`, `scsi_dma_unmap(scmnd)` must be called if `storvsc_do_io()` fails after `scsi_dma_map(scmnd)`. [F392, F393]

## API Contracts

- `hyperv_pcpu_input_arg` and `hyperv_pcpu_output_arg` are `void * __percpu *` variables: callers must pass the dereferenced `*this_cpu_ptr(...)` page pointer (or any non-stack, non-`vmalloc`, 8-byte-aligned buffer suitable for `virt_to_phys()`) to `hv_do_hypercall()`, check `hv_output_page_exists()` before reading `hyperv_pcpu_output_arg`, and use `virt_to_hvpfn()` (which handles `is_vmalloc_addr()`) rather than `__pa()` for GPADL buffers. [F46, F47, F168, F559]
- `vmbus_alloc_ring()` and `vmbus_open()` require `send_size` and `recv_size` to be multiples of guest `PAGE_SIZE` (in `netvsc_drv_init()`, `netvsc_ring_bytes` must multiply `ring_size` by `4096` and align with `VMBUS_RING_SIZE()`); `vmbus_connect()` must allocate `int_page` and `monitor_pages` with `__get_free_page()` (`PAGE_SIZE`), whereas `hv_uio_probe()` must expose `INT_PAGE_MAP` and `MON_PAGE_MAP` with size `HV_HYP_PAGE_SIZE` and `TXRX_RING_MAP` with `ringbuffer_pagecount << PAGE_SHIFT`. [F93, F176, F234, F578]
- `netvsc_send()` consumes previously batched `msdp->skb` packets (or frees `msd_skb` and its `send_buf_index` on flush failure) but leaves the current `skb` unfreed when returning non-zero to `netvsc_xmit()`; `netvsc_xdp_xmit()` callers must call `skb_record_rx_queue()` first and pass `xdp_tx = true` so `netvsc_send()` bypasses `nvchan->msd` batching; and `netvsc_poll()` must only call `napi_complete_done()` when `work_done < budget` and return `min(work_done, budget)`. [F201, F377, F382]

## Error Handling

- Hypercall helpers (`hv_do_hypercall`, `hv_do_rep_hypercall`, `hv_ghcb_hypercall`, `hv_tdx_hypercall`) return a 64-bit status where low 16 bits (`hv_result`) hold the status and bits [43:32] (`hv_repcomp`) hold completed reps (non-zero on rep success): callers must test `hv_result_success(status)` and convert errors via `hv_result_to_errno(status)`; `hv_post_message()` returns `-EMSGSIZE` or positive `hv_result(status)`, whereas `vmbus_post_msg()` retries transient errors and returns negative errno. [F44, F45, F112, F494]
- Pages decrypted with `set_memory_decrypted()` in `vmbus_connect()`, `hv_common_cpu_init()`, and `hv_synic_alloc()` must be zeroed with `memset()` after decryption succeeds, and in `hv_common_cpu_init()`, `*this_cpu_ptr(hyperv_pcpu_input_arg)` must remain `NULL` until after `set_memory_decrypted()` and `memset()` finish (callers like `hv_free_page_report()` must NULL-check it and never call `disable_page_reporting()` directly from the callback). [F48, F52, F562]
- `rndis_filter_receive()`, `rndis_filter_receive_data()`, and `netvsc_recv_callback()` return NVSP wire codes `NVSP_STAT_SUCCESS` (1) or `NVSP_STAT_FAIL` (2) (never `0` or `-errno`); `netvsc_device_add()` and `rndis_filter_device_add()` return `ERR_PTR(-errno)` (checked with `IS_ERR()`, while `ndev_ctx->nvdev` is NULL when detached); and in `netvsc_send_tx_complete()`, `cmd_rqst == 0` (`skb == NULL`) is a valid control packet completion that must still decrement `nvchan->queue_sends` (only `VMBUS_RQST_ERROR` is invalid). [F238, F239, F241]

## Known Pitfalls

- In `hv_netvsc`, incoming `data` in `rndis_filter_receive()` lives in the host-shared GPADL `recv_buf`, so RNDIS headers, `rndis_packet`, and PPIs must be copied into `nvchan->recv_buf` before validating/reading fields; `RNDIS_HEADER_SIZE` and `RNDIS_MESSAGE_SIZE(struct_type)` must be used instead of `sizeof(struct rndis_message)`; and `struct rndis_device::link_state` is `false` when link is up and `true` when link is down. [F269, F291, F321]
- In `netvsc_xmit()`, `skb_linearize()`, `skb_cow_head(skb, RNDIS_AND_PPI_SIZE)`, and `ETH_P_8021Q` `__skb_vlan_pop()` + length updates must precede computing `rndis_msg = (struct rndis_message *)skb->head` and `init_page_array()` (where `hv_page_buffer.offset < HV_HYP_PAGE_SIZE` and PFN counts use `HVPFN_UP(offset + len)`, as in `storvsc_queuecommand()`); `netvsc_send_pkt()` must set `packet->dma_range = NULL` before checking `page_buf_cnt`, and `netvsc_free_send_slot()` (`sync_change_bit`) must run once per valid `index`. [F242, F261, F312, F334, F384, F508]
- In `pci-hyperv`, iterating `hpdev->probed_bar[i]` in `survey_child_resources()` and `prepopulate_bars()` must increment `i` an extra time on every path for 64-bit BARs (`PCI_BASE_ADDRESS_MEM_TYPE_64`), cast `probed_bar[i + 1]` to `u64` before `<< 32` (or OR `0xffffffff00000000ULL` for 32-bit BARs) before calling `get_bar_size()`, and check `low_mmio_space` / `high_mmio_space` non-zero before `1ULL << (63 - __builtin_clzll(...))`; in `hv_compose_msi_msg()`, `vector` must be `u32` and `vector_count` must be `u16`. [F298, F308, F309, F310]
