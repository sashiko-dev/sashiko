# MEDIATEK T7XX 5G WWAN MODEM DRIVER

The MediaTek T7xx driver supports PCIe-connected 5G WWAN modems by managing PCIe MAC/ATR configuration, Modem Host Cross-Core Interface (MHCCIF) interrupts, power management, and modem state transitions via a finite state machine (FSM). It provides two primary host interface (HIF) DMA engines: CLDMA for control, AT, MBIM, MIPC, fastboot, and trace ports multiplexed via CCCI headers and exposed through the Linux WWAN subsystem and debugfs relay, and DPMAIF for high-speed IP network data paths exposed as CCMNI netdevices.

## Architecture & Data Flow
- In `t7xx_pci_probe()`, `t7xx_pcie_mac_atr_init()` must run before `t7xx_pci_infracfg_ao_calc()`, `t7xx_mhccif_init()`, and `t7xx_md_init()` to set `pcie_dev_reg_trsl_addr` and BAR 2 translation tables; MSI-X handlers must populate `t7xx_dev->intr_handler[i]` before `t7xx_interrupt_init()` requests IRQs; and `t7xx_setup_msix()` must pass a power-of-two `EXT_INT_NUM` to `pci_alloc_irq_vectors()` and `t7xx_pcie_set_mac_msix_cfg()`. [F136, F137, F139]
- In `t7xx_mhccif_clear_interrupts()`, `t7xx_cldma_hw_tx_done()`, and `t7xx_cldma_hw_rx_done()`, W1C writes to BAR 2 (`REG_EP2RC_SW_INT_ACK`, `REG_CLDMA_L2TISAR0`, `REG_CLDMA_L2RISAR0`) must be flushed with a readback before clearing BAR 0 L1 MSI-X status. In `t7xx_dpmaif_hw_get_intr_cnt()` and `t7xx_cldma_irq_work_cb()`, mask out `L2TIMR0`/`L2RIMR0` bits before W1C-clearing, and in `t7xx_dpmaif_hw_check_rx_intr()`, clear `DP_DL_INT_Q0_DONE`/`Q1_DONE` from `intr_status` if `t7xx_mask_dlq_intr()` fails. [F98, F140, F141]
- In `struct cldma_ctrl`, `gpd_dmapool`, `tx_ring`/`rx_ring`, and `tr_done` pointers are only populated when `t7xx_cldma_late_init()` sets `is_late_init = true` (checked by `t7xx_cldma_start()`, `t7xx_cldma_stop()`, and `t7xx_cldma_late_release()`). In `t7xx_cldma_switch_cfg()`, `t7xx_cldma_late_release()` must free old rings before `t7xx_cldma_adjust_config()` mutates `pkt_size`, and `t7xx_cldma_late_init()` must reallocate rings and call `t7xx_cldma_txq_init()`/`t7xx_cldma_rxq_init()`. [F54, F68]
- Whenever CLDMA TX queues are stopped, started, suspended, or lose their UL start address in `t7xx_cldma_hw_start_send()`, `md_ctrl->txq_started` must be cleared so the next transmit calls `t7xx_cldma_hw_start_queue()` instead of `t7xx_cldma_hw_resume_queue()`. In `t7xx_cldma_suspend()`, `t7xx_cldma_resume()`, and `t7xx_cldma_exception()`, device-wide operations (`t7xx_mhccif_mask_set()`/`_clr()` for `D2H_SW_INT_MASK` and `t7xx_cldma_hw_reset()`) must be gated on `md_ctrl->hif_id == CLDMA_ID_MD`. [F70, F114]
- `dpmaif_bat_request.bat_skb` points to `struct dpmaif_bat_page` entries when `bat_req->type == BAT_TYPE_FRAG` (`PKT_BUF_FRAG`) and `struct dpmaif_bat_skb` when `BAT_TYPE_NORMAL`; callers must check `bat_req->type` before casting or unmapping. In DPMAIF RX payload PITs (`struct dpmaif_pit`), the 16-bit buffer ID is split across `header` (`PD_PIT_BUFFER_ID`) and `pd.footer` (`PD_PIT_H_BID`) and must be reconstructed via `t7xx_normal_pit_bid()` and bounds-checked via `t7xx_bat_cur_bid_check()` or `t7xx_frag_bat_cur_bid_check()`. [F52, F85]
- In `t7xx_dpmaif_rx_start()`, `rxq->rx_data_info` (`skb_info`) accumulates multi-PIT state across NAPI calls: do not zero it on entry, gate `recv_skb_cnt >= budget` on `!skb_info->msg_pit_received`, and zero `skb_info` (freeing `cur_skb` on `err_payload`) at `!PD_PIT_CONT` and in `t7xx_dpmaif_stop_rxq()`. In `t7xx_dpmaif_napi_rx_poll()`, if `try_wait_for_completion(&t7xx_dev->sleep_lock_acquire)` returns 0, set `rxq->sleep_lock_pending = true` before rescheduling NAPI without calling `t7xx_pci_enable_sleep()` or `pm_runtime_put_autosuspend()`. [F74, F77, F108]
- Each DPMAIF TX SKB consumes `skb_shinfo(skb)->nr_frags + 2` contiguous `struct dpmaif_drb` entries (`t7xx_skb_drb_cnt()`), and `t7xx_dpmaif_add_skb_to_ring()` must notify `DMPAIF_TXQ_STATE_FULL` when `txq->tx_budget <= MAX_SKB_FRAGS + 2`. In `t7xx_hif_dpmaif_tx.c`, `t7xx_txq_drb_wr_available()` must pass `txq->drb_release_rd_idx` (not `txq->drb_rd_idx`) to `t7xx_ring_buf_rd_wr_count()`. [F84, F113]
- Optional callbacks in `struct port_ops` and `struct md_pm_entity` must be null-checked before invocation. `t7xx_port_proxy_set_cfg()` must run `t7xx_port_proxy_uninit()` before updating `port_conf`/`port_count` (`for_each_proxy_port`) and calling `t7xx_proxy_init_all_ports()`. `port->seq_nums[MTK_RX]` must be initialized/reset to `INVALID_SEQ_NUM` (`0xffff`) and incremented via `(seq_num + 1) & FIELD_MAX(CCCI_H_SEQ_FLD)` in `t7xx_port_next_rx_seq_num()`. [F50, F51, F58, F79, F93, F123]

## Synchronization
- `cldma_ctrl::cldma_lock` nests inside `cldma_queue::ring_lock` (never the reverse), and both must use `spin_lock_irqsave()` because `t7xx_cldma_isr_handler()` runs in hardirq context. Callers of `t7xx_cldma_alloc_and_map_skb()` holding `ring_lock` must pass `GFP_ATOMIC`; `t7xx_cldma_send_skb()` must drop `ring_lock` before `t7xx_pci_sleep_disable_complete()`; and `t7xx_cldma_gpd_handle_tx_request()` must write the GPD data pointer/length before `cldma_lock` and set `GPD_FLAGS_HWO` under `cldma_lock` only when `txq_active & BIT(queue->index)`. [F69, F153, F154, F155]
- In `t7xx_cldma_stop()` and `t7xx_cldma_reset()`, `rxq_active` and `txq_active` must be cleared and CLDMA IRQs disabled before calling `flush_work()` or `cancel_work_sync()` on `cldma_work` outside `cldma_lock`, prior to `md_cd_queue_struct_reset()` and `t7xx_cldma_late_release()`. During `HIF_EX_CLEARQ_DONE` in `t7xx_md_exception()`, both CLDMA instances must complete `t7xx_cldma_stop()` and `t7xx_cldma_clear_all_qs()` before triggering `H2D_CH_EXCEPTION_CLEARQ_ACK`. [F28, F156]
- `t7xx_dpmaif_napi_rx_poll()` must set `rxq->rx_processing = 1` and `smp_mb()` before checking `rxq->que_started` (paired with `t7xx_dpmaif_rx_stop()` polling `rx_processing == 0` and `smp_mb()` before clearing `que_started`). `t7xx_dpmaif_add_skb_to_ring()` must check `txq->que_started`, set `txq->tx_processing = 1`, and `smp_mb()` before modifying the DRB ring (paired with `t7xx_dpmaif_tx_stop()` clearing `que_started`, `smp_mb()`, and spinning on `tx_processing == 0`). Both must reset `rx_processing`/`tx_processing` to `0` on every exit path. [F33, F34, F161]
- In `t7xx_ccmni_md_state_callback()` on `MD_STATE_EXCEPTION`/`MD_STATE_STOPPED`, `t7xx_ccmni_pre_stop()` must run before `t7xx_dpmaif_md_state_callback()`, and `t7xx_ccmni_post_stop()` must run after it, preserving `ccmni->usage` and `ctlb->napi_usr_refcnt` for `t7xx_ccmni_start()`. In `t7xx_ccmni_wwan_newlink()`/`dellink()`, `ctlb->ccmni_inst[if_id]` must be published with `WRITE_ONCE()` after initializing `t7xx_ccmni` and cleared with `WRITE_ONCE()` before `unregister_netdevice(dev)`, paired with `READ_ONCE()` in RX/TX paths. [F35, F40, F81]
- `dpmaif_bat_request::mask_lock` (bounding bit searches to `bat_req->bat_size_cnt`) and `t7xx_dev->md_pm_lock` (`t7xx_pci_disable_sleep()`, `t7xx_pci_enable_sleep()`) are shared between NAPI softirq and workqueue/process contexts and must always use `spin_lock_irqsave()`. [F133, F160, F165]
- In `t7xx_pci_pm_init_late()`, `D2H_INT_DS_LOCK_ACK` and suspend/resume ACK interrupts must be unmasked via `t7xx_mhccif_mask_clr()` before setting `md_pm_state = MTK_PM_RESUMED`. All accesses to `t7xx_modem::exp_id` in `t7xx_pci_mhccif_isr()` and `t7xx_md_event_notify()` must hold `md->exp_lock`, testing `D2H_INT_EXCEPTION_INIT` before `D2H_INT_PORT_ENUM` or handshake bits. [F29, F37, F100]
- `t7xx_fsm_broadcast_state()` must update `ctl->md_state` and call `t7xx_port_proxy_md_status_notify()` before `fsm_state_notify()`. `fsm_state_notify()` must drop `ctl->notifier_lock` around `notifier->notifier_fn()` (which may sleep) and re-acquire it before advancing, so `notifier_fn` must never call `t7xx_fsm_notifier_unregister()`. In `t7xx_fsm_append_cmd()` with `FSM_CMD_FLAG_WAIT_FOR_COMPLETION`, initialize `cmd->done` and increment `cmd->refcnt` before queuing under `ctl->command_lock`, and set `cmd->result` before `complete_all(&cmd->done)`. [F31, F44, F106, F158]

## Object Lifetimes
- Every `port_ops.recv_skb` callback must consume/free `skb` when returning `0`, and leave `skb` unfreed on negative errno so `t7xx_port_proxy_recv_skb()` can `skb_push(skb, sizeof(*ccci_h))` without updating `port->seq_nums[MTK_RX]` and `t7xx_cldma_gpd_rx_from_q()` can retry. `t7xx_cldma_gpd_rx_from_q()` must unmap and zero `req->mapped_buff` before `queue->recv_skb()`, and only clear `req->skb = NULL` and advance `tr_done`/`rx_refill` after `queue->recv_skb()` returns `0`. [F2, F71, F167]
- In `t7xx_dpmaif_release_tx_buffer()` and `t7xx_dpmaif_tx_free_drb_skb()`, unmap DMA only when `!drb_skb->is_msg` and free `drb_skb->skb` only on the last DRB (`!DRB_HDR_CONT` or `drb_skb->is_last`). When attaching or unmapping a DPMAIF RX buffer, clear `bat_skb->skb` or `page_info->page` to `NULL`; resolve `netdev_alloc_frag()` buffers via `virt_to_head_page()`; and free shared `bat_req`/`bat_frag` in `t7xx_dpmaif_bat_free()` only when `atomic_dec_and_test(&bat_req->refcnt)` is true. [F6, F10, F11, F172]
- `t7xx_cldma_rx_done()`/`tx_done()` must retain the `pm_runtime_get()` reference from `t7xx_cldma_irq_work_cb()` when re-queuing `cldma_work`, calling `pm_runtime_put_autosuspend()` only on final return. Callers scheduling DPMAIF RX NAPI (`t7xx_dpmaif_irq_rx_done()`, `t7xx_ccmni_enable_napi()`) must acquire a runtime PM reference first, dropped via `pm_runtime_put_autosuspend()` in `t7xx_dpmaif_napi_rx_poll()`. `t7xx_pci_pm_init_late()`, `t7xx_pci_pm_reinit()`, and `t7xx_pci_reprobe_early()` must balance `pm_runtime_put_noidle()` and `pm_runtime_get_noresume()`. [F16, F135, F146]
- Teardown order: `t7xx_cldma_late_release()` must call `t7xx_cldma_ring_free()` before `dma_pool_destroy(gpd_dmapool)` and clear `gpd_dmapool` and `is_late_init`; `t7xx_dpmaif_sw_release()` must stop `tx_thread` and `bat_release_wq` before freeing queues (`t7xx_dpmaif_txq_free()` destroys `txq->worker` before `t7xx_dpmaif_tx_drb_buf_rel()`); `t7xx_ccmni_exit()` must unregister the FSM notifier and WWAN ops before `t7xx_uninit_netdev_napi()` and `t7xx_dpmaif_hif_exit()`; and `t7xx_fsm_uninit()`/`port_ctl_uninit()` must call `kthread_stop()` before flushing queues. [F17, F19, F20, F43]
- `t7xx_port_trace_md_state_notify()` must call `wwan_put_debugfs_dir()` on every exit path, and `t7xx_trace_port_uninit()` must call `relay_close()` before `debugfs_remove_recursive()` and clear `port->log.relaych = NULL`. `t7xx_acpi_reset()` must `kfree(buffer.pointer)` from `ACPI_ALLOCATE_BUFFER`, and `t7xx_reset_device()` must save/restore PCI state around reset. [F22, F150]

## API Contracts
- `t7xx_ccmni_start_xmit()` must free `skb` with `dev_kfree_skb()` when returning `NETDEV_TX_OK` on an early drop (`skb->len > dev->mtu` or `skb_headroom(skb) < sizeof(struct ccci_header)`), whereas `t7xx_dpmaif_tx_send_skb()` must leave `skb` unconsumed when returning `-EBUSY` so `t7xx_ccmni_start_xmit()` can return `NETDEV_TX_BUSY`. [F4, F91]
- Before accessing CLDMA or DPMAIF hardware in D0, callers must call `t7xx_pci_disable_sleep()`, wait for `sleep_lock_acquire` completion, and pair with `t7xx_pci_enable_sleep()`. `t7xx_pci_sleep_disable_complete()` returns `0` on timeout failure and positive jiffies on success. [F45, F145]
- `t7xx_dpmaif_release_bat_entry()` returns `<= 0` when empty or on error; callers must check `if (ret <= 0)` before allocating BAT buffers, and `t7xx_dpmaif_start()` must pass `bat_size_cnt - 1`. Callers of `t7xx_dpmaif_hw_get_intr_cnt()` must zero `para->intr_cnt = 0`; `t7xx_dpmaif_irq_rx_done()`/`tx_done()` expect `BIT(qno)` (not `qno`); and `t7xx_dpmaif_ul_update_hw_drb_cnt()`/`update_drb_size()` expect counts multiplied by `DPMAIF_UL_DRB_SIZE_WORD` (`4`), whereas `t7xx_dpmaif_ul_get_rd_idx()` already returns an entry index. [F48, F56, F60, F62, F120]
- SKBs passed to `t7xx_port_send_ctl_skb()` must be allocated with `t7xx_ctrl_alloc_skb()` (reserving `ccci_header` + `ctrl_msg_header`); `ctrl_msg_h->data_length` is the payload length, and `ccci_h->packet_header` must be `CCCI_HEADER_NO_DATA` when `msg_len == 0`. Non-fastboot WWAN ports must set `caps.headroom_len = sizeof(struct ccci_header)` and `caps.frag_len = mtu - sizeof(struct ccci_header)` in `t7xx_port_wwan_create()`. [F59, F89, F92]
- `t7xx_mhccif_h2d_swint_trigger()` takes a 0-based `H2D_CH_*` index, whereas `t7xx_mhccif_mask_set()`/`_clr()` take pre-shifted `D2H_INT_*` bitmasks. `t7xx_cldma_hw_resume_queue()`, `t7xx_cldma_hw_set_start_addr()`, and `t7xx_cldma_tx_addr_is_set()` accept only a single 0-based queue index (not `CLDMA_ALL_Q`). Atomic/spinlock-held callers of `t7xx_fsm_append_cmd()` must pass `FSM_CMD_FLAG_IN_INTERRUPT`, and `FSM_CMD_EXCEPTION` callers must encode `FIELD_PREP(FSM_CMD_EX_REASON, reason)`. [F63, F65, F95]

## Error Handling
- Error rollback loops unwinding 0-based indexed allocations (`t7xx_dpmaif_rx_buf_alloc()`, `t7xx_request_irq()`, `t7xx_cldma_late_init()`, `t7xx_dpmaif_add_skb_to_ring()`) must use post-decrement `while (i--)` so index `0` is released. On `dma_map_single()` failure in `t7xx_dpmaif_add_skb_to_ring()`, unmap `wr_cnt` buffers in reverse order and restore `txq->drb_wr_idx` to `drb_wr_idx_backup` without decrementing `txq->tx_budget` or unlinking `skb` from `txq->tx_skb_head`. [F8, F75]
- In CLDMA/DPMAIF paths that can run before `t7xx_pci_pm_init_late()` enables runtime PM, `pm_runtime_resume_and_get()` returning `-EACCES` is not an error. When `__t7xx_pci_pm_suspend()` aborts, resume only `md_pm_entities` preceding the failed `entity_id`, send `H2D_CH_RESUME_REQ` if `H2D_CH_SUSPEND_REQ_AP` failed after `H2D_CH_SUSPEND_REQ`, re-enable `ENABLE_ASPM_LOWPWR` and `SAP_RGU_INT`, and restore `md_pm_state = MTK_PM_RESUMED`. [F47, F78]

## Known Pitfalls
- In `struct cldma_gpd`, 64-bit DMA pointers store the upper 32 bits (`_h`) before the lower 32 bits (`_l`), whereas 64-bit MMIO registers (`REG_CLDMA_UL_START_ADDRL_0`, `REG_CLDMA_DL_START_ADDRL_0`, ATR registers) are 32-bit aligned low-word-first pairs and must use `ioread64_lo_hi()` / `iowrite64_lo_hi()`, never `ioread64()` / `iowrite64()`. [F86, F134]
- `t7xx_pcie_mac_clear_int()` masks (disables) a host MSI-X interrupt and `t7xx_pcie_mac_set_int()` unmasks (enables) it—the inverse of `t7xx_mhccif_mask_set()`/`_clr()` and `L2TIMSR0`/`L2TIMCR0`. `t7xx_dpmaif_ul_idle_check()` and `t7xx_dpmaif_dl_idle_check()` return `true` when busy and `false` when idle. [F96, F138]
- In `REG_CLDMA_L2TISAR0`/`L2RISAR0`, bit indices `>= CLDMA_TXQ_NUM` (bits 8..15, `EMPTY_STATUS_BITMASK`) in `t7xx_cldma_irq_work_cb()` must be offset by `CLDMA_TXQ_NUM` before indexing `txq[]`/`rxq[]`. In `t7xx_dpmaif_hw_get_intr_cnt()`, masked DL queue-done interrupts must be filtered by testing `DPMAIF_DL_INT_DLQ0_QDONE`/`DLQ1_QDONE` (bits 8-9) in `rx_intr_qdone` and clearing `DP_DL_INT_Q0_DONE`/`Q1_DONE` (bits 13-14) from `rx_intr_status`, never `rx_intr_status &= ~rx_intr_qdone`. [F87, F99]
- `t7xx_port_proxy_find_port()` must match both `queue->md_ctrl->hif_id == port_conf->path_id` and the full 16-bit `channel == port_conf->rx_ch`. CCMNI netdevices must retrieve `struct t7xx_ccmni *` via `wwan_netdev_drvpriv(dev)`, never `netdev_priv(dev)`. In `t7xx_dpmaif_set_frag_to_skb()`/`set_data_to_skb()`, widen `le32_to_cpu(pkt_info->pd.data_addr_h)` to 64 bits before `<< 32`, and cast `void *` DMA ring bases (`bat_base`, `pit_base`, `drb_base`, `drb_skb_base`) to typed pointers before `+ idx`. [F88, F115, F129, F131]
