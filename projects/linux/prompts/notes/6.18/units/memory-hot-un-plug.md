# MEMORY HOT(UN)PLUG

This unit manages dynamic addition, onlining, offlining, and removal of physical memory and `ZONE_DEVICE` mappings, coordinating SPARSEMEM/vmemmap population (including `vmem_altmap`), zone/node span resizing, page isolation/migration, `memremap_pages()`, and `/sys/devices/system/memory/`.

## Architecture & Data Flow

- In `online_pages()`, after `move_pfn_range_to_zone()` sets `isolate_pageblock = true`, `zone->nr_isolate_pageblock` must be incremented by `nr_pages / pageblock_nr_pages` under `zone->lock` before `online_pages_range()` and `undo_isolate_page_range()`. In `offline_pages()`, once `__offline_isolated_pages()` marks sections offline, `zone->nr_isolate_pageblock` must be decremented directly under `zone->lock`; `undo_isolate_page_range()` is only for `failed_removal_isolated` while sections remain online. [F56, F57]
- When `move_pfn_range_to_zone()` adds a `ZONE_DEVICE` range whose `start_pfn` or `start_pfn + nr_pages` is not aligned to `PAGES_PER_SECTION`, it must set `SECTION_TAINT_ZONE_DEVICE` via `section_taint_zone_device()` so `pfn_to_online_page()` queries `get_dev_pagemap()` via `online_device_section()`. [F55]
- In `mm/memremap.c`, range 0's `[PHYS_PFN(range->start), PHYS_PFN(range->end)]` includes `vmem_altmap` metadata pages, so `pgmap_pfn_valid()` and `pageunmap_range()` must use `pfn_first(pgmap, range_id)` to skip `vmem_altmap_offset()`. [F75]
- In `pagemap_range()` and `pageunmap_range()`, `MEMORY_DEVICE_PRIVATE` uses `add_pages()` / `__remove_pages()` without `kasan_{add,remove}_zero_shadow()`, whereas all other `enum memory_type` variants pair `kasan_add_zero_shadow()` / `arch_add_memory()` with `arch_remove_memory()` / `kasan_remove_zero_shadow()`. [F91]
- `free_zone_device_folio()` must call `mem_cgroup_uncharge()`, clear `PG_anon_exclusive` on page 0 if `folio_test_anon(folio)`, and reset `folio->mapping = NULL` for every `pgmap->type` except `MEMORY_DEVICE_FS_DAX` and `MEMORY_DEVICE_GENERIC` before calling `pgmap->ops->page_free`. [F148]
- In `memremap_pages()`, `params.pgprot` (`PAGE_KERNEL`) must be updated via `pgprot_decrypted()` for `MEMORY_DEVICE_FS_DAX` and `pgprot_noncached()` for `MEMORY_DEVICE_PCI_P2PDMA`, and `pgmap->vmemmap_shift > MAX_FOLIO_ORDER` must be rejected before `pagemap_range()` / `pgmap_vmemmap_nr()` / `pfn_len()`. [F103, F142]
- With `MHP_MEMMAP_ON_MEMORY`, `create_altmaps_and_memory_blocks()` must allocate a separate `struct vmem_altmap` and call `arch_add_memory()` and `create_memory_block_devices()` per individual memory block (`memory_block_size_bytes()`). `memory_block_memmap_on_memory_pages()` must use `PFN_UP(memory_block_memmap_size())` and round up with `pageblock_align()` when `memmap_mode == MEMMAP_ON_MEMORY_FORCE`. [F70, F106]
- `mem->zone` must be set when `memory_block_online()` succeeds and cleared to `NULL` when `memory_block_offline()` succeeds or when `memory_block_add_nid_early()` / `early_node_zone_for_memory_block()` finds multiple populated intersecting zones/nodes (continuing the `MAX_NR_ZONES` scan after the first match); `memory_block_offline()` must reject `!mem->zone`. [F68, F92]
- In `do_migrate_range()`, when `folio_contain_hwpoisoned_page(folio)` is true, skip non-hugetlb large folios (`folio_test_large(folio) && !folio_test_hugetlb(folio)`), isolate any LRU folio via `folio_isolate_lru(folio)`, and hold `folio_lock(folio)` around `unmap_poisoned_folio(folio, pfn, false)`. [F150]
- `try_offline_node(nid)` must only call `node_set_offline(nid)` and `unregister_one_node(nid)` when `node_spanned_pages(nid) == 0`, `for_each_memory_block(&nid, check_no_memblock_for_node_cb)` finds no `memory_block` devices, and `check_cpu_on_node(nid)` finds no present CPUs. [F128]
- In `memory_subsys_online()`, `mem->online_type` defaults to `MMOP_ONLINE` if `MMOP_OFFLINE` and must always be reset to `MMOP_OFFLINE` before returning. In `default_zone_for_pfn()`, an existing zone is inherited only when `in_kernel ^ in_movable`. In `struct memory_group`, check `group->is_dynamic` before reading `group->s.max_pages` or `group->d.unit_pages`. [F42, F67, F89]

## Synchronization

- Lock order is `device_hotplug_lock` -> `mem->dev.mutex` (`device_online()` / `device_offline()`) -> `cpus_read_lock` -> `mem_hotplug_lock` (`mem_hotplug_begin()`), and `get_online_mems()` -> `online_page_callback_lock` in `{set,restore}_online_page_callback()`. `add_memory_resource()` must call `mem_hotplug_done()` before `online_memory_block()` calls `device_online(&mem->dev)`. [F28, F131, F134]
- `find_memory_block_by_id()`, `find_memory_block()`, `{create,remove}_memory_block_devices()`, and `walk_memory_blocks()` require `device_hotplug_lock` (except in `memory_dev_init()`), and `find_memory_block*()` callers must drop the returned `get_device(&mem->dev)` ref. [F144]
- In `memory_block_{online,offline}()`, `mhp_{init,deinit}_memmap_on_memory()`, `adjust_present_page_count()`, and `{online,offline}_pages()` must run inside `mem_hotplug_begin()` / `mem_hotplug_done()`. `{online,offline}_pages()` call `memory_notify()` / `node_notify()` under `mem_hotplug_lock`, so notifier callbacks must not call `mem_hotplug_begin()`. [F24, F133]
- In `pagemap_range()` and `pageunmap_range()`, `mem_hotplug_begin()` / `mem_hotplug_done()` must wrap `{add,__remove}_pages()`, `arch_{add,remove}_memory()`, KASAN shadow updates, and `{move,remove}_pfn_range_{to,from}_zone()`, while `memmap_init_zone_device()` runs outside `mem_hotplug_begin()`. [F140]
- `get_dev_pagemap()` must perform both `xa_load(&pgmap_array, ...)` and `percpu_ref_tryget_live_rcu(&pgmap->ref)` inside one `rcu_read_lock()` critical section. [F137]
- `offline_pages()` must call `zone_pcp_disable(zone)` and `lru_cache_disable()` before `start_isolate_page_range()`, and re-enable them in reverse order (`lru_cache_enable()`, `zone_pcp_enable(zone)`) on both success and `failed_removal_pcplists_disabled`. When offlining a node's last present pages (`node_arg.nid >= 0`), `node_clear_state(node, N_MEMORY)` must precede `build_all_zonelists(NULL)`. [F32, F136]
- In `do_migrate_range()`, after `folio = page_folio(page)` and `folio_try_get(folio)`, revalidate `page_folio(page) == folio` before calling `folio_test_large(folio)` or `folio_nr_pages(folio)`. [F30]

## Object Lifetimes

- In `__add_memory_block()`, `device_register(&memory->dev)` initializes the refcount, so `device_register()` failure must call `put_device(&memory->dev)` (freeing `memory` via `memory_block_release()`), whereas `xa_store()` failure after registration must call only `device_unregister(&memory->dev)` (callers must not `kfree(mem)`). `remove_memory_block()` consumes its caller's `find_memory_block_by_id()` ref via `put_device(&memory->dev)` before `device_unregister(&memory->dev)` and unlinks `memory->group_next`. [F1, F2]
- In `remove_memory_blocks_and_altmaps()`, clear `mem->altmap = NULL` before `remove_memory_block_devices()` and pass `altmap` to `arch_remove_memory()` before `kfree(altmap)`. Always run `arch_add_memory()` before `create_memory_block_devices()`, and `remove_memory_block_devices()` before `arch_remove_memory()`. [F4, F121]
- `memory_group_unregister()` only frees a `struct memory_group` when `list_empty(&group->memory_blocks)` (`-EBUSY` otherwise), and `add_memory_block()` must only link `mem->group_next` after `__add_memory_block()` succeeds. [F5]
- `add_memory_resource()` does not free `res` on error (callers must call `release_memory_resource(res)` when `< 0`), and when `MHP_MERGE_RESOURCE` is set, callers must not dereference `res` after success because `merge_system_ram_resource(res)` may free it. [F12]
- In `memremap_pages()`, `init_completion(&pgmap->done)` and `percpu_ref_init(&pgmap->ref, ...)` must precede `pagemap_range()`. In `memunmap_pages()`, `percpu_ref_kill(&pgmap->ref)`, initial `percpu_ref_put_many()`, and `wait_for_completion(&pgmap->done)` must precede `pageunmap_range()`, and `pgmap_array_delete()` (with `synchronize_rcu()`) must complete before `percpu_ref_exit(&pgmap->ref)`. [F19, F22, F125]
- `MEMORY_DEVICE_PRIVATE` and `MEMORY_DEVICE_COHERENT` get `pgmap->ref` per page in `zone_device_page_init()` and drop it in `free_zone_device_folio()` (`put_dev_pagemap()`), whereas other types bulk-get `pfn_len()` refs in `pagemap_range()` and bulk-put in `memunmap_pages()`. A `pgmap` mapped via `devm_memremap_pages()` must be manually unmapped only via `devm_memunmap_pages(dev, pgmap)`, never `memunmap_pages(pgmap)`. [F17, F123]

## API Contracts

- `walk_memory_blocks()` holds a ref from `find_memory_block_by_id()` only across `func(mem, arg)`, so callbacks must not call `put_device(&mem->dev)` or `remove_memory_block(mem)` without taking an extra ref. [F3]
- `pfn_to_online_page(pfn)` must check `pfn_to_section_nr(pfn) < NR_MEM_SECTIONS` before `__nr_to_section(nr)`, and returns a `struct page *` only when the section is online, `pfn_section_valid()` is true, and `get_dev_pagemap()` returns `NULL` (if non-NULL, it must call `put_dev_pagemap()` and return `NULL`). [F39, F84]
- `memremap_pages()` and `devm_memremap_pages()` return `ERR_PTR` on failure (never `NULL`). `MEMORY_DEVICE_PRIVATE` requires `CONFIG_DEVICE_PRIVATE`, `owner`, `ops->migrate_to_ram`, and `ops->page_free`; `MEMORY_DEVICE_COHERENT` requires `owner` and `ops->page_free`. Access `pgmap->altmap` only via `pgmap_altmap(pgmap)` (`PGMAP_ALTMAP_VALID`), and allocate trailing `struct range` space when `pgmap->nr_range > 1`. [F33, F40, F113, F145]
- `{add,remove}_memory()`, `offline_and_remove_memory()`, `{create,remove}_memory_block_devices()`, and `walk_memory_blocks()` take byte addresses/sizes; `{add,__remove,online,offline}_pages()`, `move_pfn_range_to_zone()`, and `memory_group_register_{static,dynamic}()` take PFNs/page counts (`unit_pages` must be a power of 2 `>= PHYS_PFN(memory_block_size_bytes())`). `zone_for_pfn_range()` and its helpers must type PFNs/counts as `unsigned long`, not `unsigned int`. [F49, F102, F154]
- `{online,offline}_pages()` require `nr_pages != 0`, `pageblock_aligned(start_pfn)`, and `IS_ALIGNED(start_pfn + nr_pages, PAGES_PER_SECTION)`. `add_memory_resource()` must check both `MHP_MEMMAP_ON_MEMORY` and `mhp_supports_memmap_on_memory()` (which requires `pageblock_aligned(memmap_pages)`) before `create_altmaps_and_memory_blocks()`. [F77, F126]
- `arch_get_mappable_range()` and `mhp_get_pluggable_range()` return inclusive bounds `[start, end]` capped by `DIRECT_MAP_PHYSMEM_END`, so `mhp_range_allowed(start, size, need_mapping)` must check `start < end` (`end = start + size`) and `(end - 1) <= mhp_range.end`. [F78, F141]
- When `MHP_NID_IS_MGID` is set, `add_memory_resource()` must resolve `group = memory_group_find_by_id(nid)` and set `nid = group->nid` before `node_possible(nid)`. `memory_group_unregister(int mgid)` must reject `mgid < 0` with `-EINVAL` before `xa_load()`. `__try_online_node()` returns `1` (new node), `0` (already online), or `< 0` (error). [F36, F51, F83]
- System RAM `struct mhp_params` must use `.pgprot = pgprot_mhp(PAGE_KERNEL)`. `add_memory_driver_managed()` requires `resource_name` matching `"System RAM (*)"` (`IORESOURCE_SYSRAM_DRIVER_MANAGED`, omitted from `firmware_map_add_hotplug()`). [F149, F153]

## Error Handling

- Under `mem_hotplug_begin()`, `memory_block_online()` returns `-EHWPOISON` (no `WARN`) if `memblk_nr_poison(mem) != 0`, sends `MEM_PREPARE_ONLINE`, runs `mhp_init_memmap_on_memory()` and `online_pages()`, and only then calls `adjust_present_page_count()` for `nr_vmemmap_pages` and sets `mem->zone`; on failure it unwinds and sends `MEM_FINISH_OFFLINE`. `remove_memory_block_devices()` calls `num_poisoned_pages_sub(-1UL, memblk_nr_poison(mem))`. [F6, F157]
- Under `mem_hotplug_begin()`, `memory_block_offline()` must subtract `nr_vmemmap_pages` via `adjust_present_page_count()` before `offline_pages()`—restoring it if `offline_pages()` fails—and only on success call `mhp_deinit_memmap_on_memory()`, clear `mem->zone = NULL`, and send `MEM_FINISH_OFFLINE`. [F7]
- In `{online,offline}_pages()`, initialize `node_arg.nid = NUMA_NO_NODE` and set it to `nid` only when `NODE_ADDING_FIRST_MEMORY` / `NODE_REMOVING_LAST_MEMORY` is sent; if `node_notify()` or `memory_notify(MEM_GOING_ONLINE, ...)` fails after `move_pfn_range_to_zone()`, send `MEM_CANCEL_ONLINE`, send `NODE_CANCEL_ADDING_FIRST_MEMORY` only if `node_arg.nid != NUMA_NO_NODE`, and call `remove_pfn_range_from_zone()`. Convert `memory_notify()` / `node_notify()` returns with `notifier_to_errno()`. [F8, F35, F46]
- Under `mem_hotplug_begin()`, `add_memory_resource()` must call `node_set_online()` and `register_one_node()` before creating memory blocks, and on failure roll back `arch_add_memory()`, `node_set_offline()` / `unregister_one_node()` (if `new_node`), and `memblock_remove()`. `register_memory_resource()` returns `ERR_PTR`, whereas `release_memory_resource()` only guards against `NULL`, so check `IS_ERR(res)` first. [F11, F34]
- `try_remove_memory()` must pair `mem_hotplug_begin()` / `mem_hotplug_done()`. In `offline_and_remove_memory()`, `online_types` is pre-filled with `MMOP_OFFLINE`, `try_offline_memory_block()` stores `online_type` only when `device_offline() == 0` while advancing `(*online_types)++` on every block, and rollback resets `tmp = online_types` before `try_reonline_memory_block()`. [F13, F95]
- `pagemap_range()` unwinds `kasan_remove_zero_shadow()`, `pfnmap_untrack()`, and `pgmap_array_delete()` in reverse order on error. `memremap_pages()` zeroes `pgmap->nr_range` and increments it per succeeded `pagemap_range()` so `memunmap_pages(pgmap)` unwinds only succeeded ranges before restoring `pgmap->nr_range`. `__add_pages()` must check `altmap->base_pfn == pfn` and `vmem_altmap_offset(altmap) <= nr_pages` and set `altmap->alloc = 0`. [F15, F45, F47]
- `do_migrate_range()` must release `folio_try_get(folio)` via `folio_put(folio)` on every path, ratelimit `pr_warn` / `dump_page` via `__ratelimit(&migrate_rs)` without `WARN`, and call `putback_movable_pages(&source)` when `migrate_pages()` fails. [F10, F151]

## External Contracts

- `soft_offline_page_store()` and `hard_offline_page_store()` require `capable(CAP_SYS_ADMIN)` (`-EPERM` otherwise) and shift the parsed byte address right by `PAGE_SHIFT` before `soft_offline_page()` or `memory_failure()`. [F152]

## Known Pitfalls

- When `mem->altmap` sets `nr_vmemmap_pages = mem->altmap->free`, `{online,offline}_pages()` take `[start_pfn + nr_vmemmap_pages, nr_pages - nr_vmemmap_pages)` while `mhp_{init,deinit}_memmap_on_memory()` take `[start_pfn, nr_vmemmap_pages)` and pass `ALIGN_DOWN(end_pfn, PAGES_PER_SECTION)` to `{online,offline}_mem_sections()` when `nr_pages >= PAGES_PER_SECTION`. `memory_block_offline()` must not call `pfn_to_page(start_pfn)` when `nr_vmemmap_pages == 0` because `start_pfn` may be a hole before `offline_pages()` checks `walk_system_ram_range()`. [F44, F100, F107]
- In `__add_pages()`, `remove_pfn_range_from_zone()`, and `__remove_pages()`, step by `min(end_pfn - pfn, SECTION_ALIGN_UP(pfn + 1) - pfn)` using `pfn + 1`. In `online_pages_range()`, guard `pfn == 0` before `__ffs(pfn)`. In `scan_movable_pages()` and `do_migrate_range()`, use PFN arithmetic rather than `struct page *` subtraction/comparison across SPARSEMEM sections. [F98, F101, F111]
- In `scan_movable_pages()`, check `page_has_movable_ops(page)` before `PageOffline(page) && page_count(page)`. In `do_migrate_range()`, copy `node_states[N_MEMORY]` to a local `nodemask_t` before `node_clear(mtc.nid, nmask)`. [F88, F118]
- In `auto_movable_can_online_movable()`, check `nid == NUMA_NO_NODE` before `NODE_DATA(nid)`, and check `kernel_early_pages <= group_stats.req_kernel_early_pages` before subtracting. `auto_movable_stats_account_group()` must `READ_ONCE(auto_movable_ratio)`, return if `0` before dividing, and use signed `long pages`. [F74, F104, F105]
- `{set,get}_memmap_mode` must access `kp->arg` as `*(int *)kp->arg`, not `param_{get,set}_bool()`. `update_pgdat_span()` must skip `!zone->spanned_pages` and seed `node_start_pfn` / `node_end_pfn` on `if (!node_end_pfn)`. `memory_group_register()` must call `INIT_LIST_HEAD(&new_group->memory_blocks)` after `*new_group = group`. Runtime hotplug code/data must use `__meminit` / `__meminitdata` (or `__ref`), not `__init` / `__initdata`. [F73, F94, F115, F129]
