# WANGXUN ETHERNET DRIVER

`libwx` provides shared Tx/Rx ring management, NAPI polling, page pool allocation, interrupt schemes, SR-IOV mailbox protocols, PTP timestamping, MAC/VLAN filtering, and ethtool support for Beijing WangXun PCIe Ethernet controllers (`ngbe`/`ngbevf` for 1GbE WX1860; `txgbe`/`txgbevf` and `pcs-xpcs-wx.c` for 10/25/40GbE Sapphire `wx_mac_sp` and Amber Lite `wx_mac_aml`/`wx_mac_aml40`).

## Architecture & Data Flow

- Every `net_device` using `libwx` callbacks must allocate `sizeof(struct wx)` private space so `netdev_priv(netdev)` points directly to `struct wx`, attaching driver-specific state via `wx->priv`. Shared helpers or early probe calls (`txgbe_sw_init`, `txgbe_reset_hw`, `txgbe_validate_eeprom_checksum`, `txgbe_init_service`, `txgbe_test_hostif`) must never dereference `wx->priv`, which is `NULL` before `txgbe` allocation in `txgbe_probe` and always `NULL` in `txgbevf`. [F125, F268]
- `struct wx_ring` instances are embedded in `q_vector->ring[]` (allocated in `wx_alloc_q_vector` with `struct_size(q_vector, ring, txr_count + rxr_count)`) and linked via `ring->next`. Thus `wx_set_ring` must stage new allocations in `temp_ring[]` (sized in `txgbe_set_ringparam` to `max(num_tx_queues, num_rx_queues)` of full `sizeof(struct wx_ring)`) and only free old resources and `memcpy` into `wx->tx_ring[i]`/`wx->rx_ring[i]` after all succeed; when `!netif_running`, `txgbe_set_ringparam` must also update each `wx->tx_ring[i]->count` and `wx->rx_ring[i]->count`. [F56, F121, F229, F264]
- On `wx_mac_aml40`, `wx->phylink` and `txgbe->misc.domain` are never created, and `txgbe_setup_misc_irq` skips `txgbe_request_gpio_irq` on `wx_mac_sp` (though `wx->misc_irq_domain = true` on all MACs); callers must branch on `wx_mac_aml40` and only free `txgbe->gpio_irq` on `wx_mac_aml`. Also, `txgbe->pcs` (`NULL` on `wx_mac_aml` and copper `wx_mac_sp`), `wx->ptp_setup_sdp` (`NULL` on `wx_mac_sp`), and `wx->b4_addr` (`NULL` on VFs without BAR4 in `wx_reset_hw_vf`) must be NULL-checked before use. [F38, F39, F204, F205, F281]
- Queue MSI-X vectors occupy indices `0..num_q_vectors - 1` (`TXGBE_INTR_QALL(wx)`) with the misc IRQ at `num_q_vectors` (`TXGBE_INTR_MISC(wx)`), except on `wx_mac_em` with `num_vfs == 7` where `__wx_enable_sriov` sets `WX_FLAG_IRQ_VECTOR_SHARED` (cleared in `wx_sriov_clear_data`) so misc and queue 0 share vector 0. In MSI/INTx fallback, `wx->msix_q_entries` and `wx->msix_entry` are `NULL`, so interrupt/channel helpers must check `pdev->msix_enabled` or `wx->msix_q_entries` first. [F40, F77, F136, F240]
- In `txgbe_misc_irq_handle`, snapshot `wx_misc_isb(wx, WX_ISB_MISC)` into `txgbe->eicr` and, when `!wx->pdev->msix_enabled`, clear `wx->isb_mem[WX_ISB_VEC0] = 0` before returning `IRQ_WAKE_THREAD`. In `ngbe_up` and `wxvf_up_complete`, `wx_napi_enable_all` and clearing `WX_PX_IC(0)`/`WX_PX_MISC_IC`/`WX_VXICR` must precede enabling interrupts. [F130, F228]
- Reading `WX_VXMAILBOX` clears hardware read-to-clear bits `WX_VXMAILBOX_R2C_BITS` (`RSTD`, `PFSTS`, `PFACK`), so VF code must read it via `wx_read_v2p_mailbox` to latch those bits in `wx->mbx.mailbox` and clear only the checked bit via `wx_check_for_bit_vf`. `wx_set_vf_multicasts` must clamp `msgbuf[0]` count to `WX_MAX_VF_MC_ENTRIES` (30), and `wx_get_queues_vf` must clamp `max_tx_queues`/`max_rx_queues` to `1..4`, `*num_tcs <= max_rx_queues`, and `*default_tc < max_tx_queues`. [F64, F73, F74]
- When `WX_FLAG_SRIOV_ENABLED` is set, `wx_rss_indir_tbl_entries(wx)` returns 64 instead of 128 (`WX_MAX_RETA_ENTRIES`), which must bound all PF loops on `wx->rss_indir_tbl`. If `WX_FLAG_MULTI_64_FUNC` is also set, `wx_store_reta`, `wx_store_rsskey`, `wx_config_rss_field`, and `wx_enable_rss` must program per-pool registers indexed by `wx->num_vfs` (`WX_RDB_VMRSSTBL`, `WX_RDB_VMRSSRK`, `WX_RDB_PL_CFG`), and `wx_setup_mrqc` must not abort when `WX_FLAG_VMDQ_ENABLED` is set. [F63, F82, F91]
- In the 64-entry VLVF table (`WX_PSR_VLAN_SWC_IDX`), index 0 is reserved for VLAN 0, so non-zero VLAN loops must start at index 1. `wx_vlan_promisc_disable` must call `wx_scrub_vfta`, and `wx_write_mc_addr_list` must call `wx_restore_vf_multicasts` when `WX_FLAG_SRIOV_ENABLED` is set because `wx_update_mc_addr_list` zeroes `wx->mac.mta_shadow` and overwrites `WX_PSR_MC_TBL`. [F53, F54, F79]
- Transmit PTP registers (`WX_TSC_1588_*`) must be accessed via `rd32ptp`/`wr32ptp`, and `wx_ptp_rx_hwtstamp`/`wx_ptp_tx_hwtstamp` must read `STMPL` before `STMPH` because reading `STMPH` unlocks the timestamp latch. [F67, F145]
- In `wx_clean_rx_irq`, call `wx_is_non_eop` before any `continue` so `rx_ring->next_to_clean` always advances, and in `wx_poll`, only call `napi_complete_done` and `wx_intr_enable` when `clean_complete` is true across all Tx/Rx rings. Extended Rx status/error bits reside in `rx_desc->wb.upper.status_error` and must be tested via `wx_test_staterr` (`cpu_to_le32`). [F85, F104, F105]
- Whenever the MAC is reset/reconfigured during link-up (`txgbe_mac_link_up_aml`, `txgbe_mac_finish`, `txgbe_up_complete` for `wx_mac_aml40`), call `txgbe_enable_sec_tx_path(wx)`, and save/restore `WX_MAC_WDG_TIMEOUT` and `WX_MAC_RX_FLOW_CTRL` in `txgbe_reconfig_mac`. Do not clear `WX_MAC_RX_CFG_RE`/`WX_MAC_TX_CFG_TE` in `wx_disable_rx`/`txgbe_disable_device` when `WX_NCSI_SUP` or `WX_WOL_SUP` is set, and disable/flush all Tx/Rx queues before `wx_disable_pcie_master` in `wx_stop_adapter`. [F148, F149, F226, F284, F288]
- In `txgbe`, zero-initialize `union txgbe_atr_input` and local `union txgbe_atr_hash_dword` variables (`input`, `common` in `txgbe_atr`, after NULL-checking `ring->q_vector`). Keep `txgbe->fdir_filter_list` sorted by ascending `rule->sw_idx` (checking `rule != NULL` after `hlist_for_each_entry_safe`), and in `txgbe_add_ethtool_fdir_entry` only update `txgbe->fdir_mask` when `fdir_filter_list` is empty while bounding `fsp->location < (1024 << TXGBE_FDIR_PBALLOC_64K) - 2`, `vf <= wx->num_vfs`, and `ring < wx->num_rx_queues_per_pool`. [F210, F211, F219, F236, F248, F261]

## Synchronization

- `wx_host_interface_command` (and `wx_set_pps`, `wx_read_ee_hostif*`) and `txgbe_xpcs_switch_mode` sleep (`wx_sw_sync_lock` mutex, `read_poll_timeout`) and must only run in process context. Conversely, `wx_msg_task` and PF SR-IOV mailbox handlers run in hardirq context, `txgbe_fdir_check_cmd_complete` runs in softirq (`txgbe_atr`) or under `txgbe->fdir_perfect_lock` (`read_poll_timeout_atomic`), and VF mailbox callers must hold `spin_lock_bh(&wx->mbx.mbx_lock)` with `readx_poll_timeout_atomic`. [F150, F154, F155, F289, F298]
- `wx_acquire_sw_sync`/`wx_release_sw_sync` must hold `wx_sw_sync_lock` and modify only the caller's mask bits in `WX_MNG_SWFW_SYNC`. `wx_host_interface_command_s` must release `WX_MNG_SWFW_SYNC_SW_MB` on every exit, `wx_host_interface_command_r` must increment `wx->swfw_index` and clear `WX_STATE_SWFW_BUSY` on every exit, and `wx_read_ee_hostif*` must hold `WX_MNG_SWFW_SYNC_SW_FLASH` across both command and mailbox data reads. PF/VF mailbox memory (`WX_PXMBMEM`, `WX_VXMBMEM`) requires `wx_obtain_mbx_lock_pf`/`_vf` first. [F13, F24, F31, F61]
- All updates to `wx->hw_tc` and `wx->hw_cc` (including `timecounter_read(&wx->hw_tc)`) must hold `write_seqlock_irqsave(&wx->hw_tc_lock, flags)`, while `wx_ptp_timecounter_cyc2time` uses `read_seqbegin`/`read_seqretry`. Never call `wx->ptp_setup_sdp` while holding `wx->hw_tc_lock` or from `wx_ptp_check_pps_event` hardirq (it acquires `hw_tc_lock` and sleeps in `wx_set_pps`). Serialize `wx->ptp_tx_skb` with `WX_STATE_PTP_TX_IN_PROGRESS` (`test_and_set_bit_lock` before assignment, `clear_bit_unlock` after clearing `ptp_tx_skb = NULL`). [F20, F22, F151]
- Memory barriers: `wx_tx_map` executes `wmb()` before setting `first->next_to_watch = tx_desc` and writing `tx_ring->tail` (paired with `smp_rmb()` in `wx_clean_tx_irq`); `wx_clean_rx_irq` executes `dma_rmb()` after observing `WX_RXD_STAT_DD`; `wx_alloc_rx_buffers` executes `wmb()` before writing `rx_ring->tail`; and `wx_maybe_stop_tx` executes `smp_mb()` after `netif_stop_subqueue` and rechecks `wx_desc_unused(tx_ring) < size` (paired with `smp_mb()` in `wx_clean_tx_irq`). [F26, F27, F28]
- `wx_napi_enable_all` must `INIT_WORK` on `q_vector->rx.dim.work` and `tx.dim.work` before `napi_enable`, and `wx_napi_disable_all` must call `napi_disable` before `disable_work_sync`. `txgbe_disable_device` and `txgbe_down` must stop Tx queues and call `wx_irq_disable`, `wx_napi_disable_all`, and `timer_delete_sync(&wx->service_timer)` before flushing hardware Tx queues and cleaning rings. [F16, F201]

## Object Lifetimes

- In `wx_build_skb`, when `size <= WX_RXBUFFER_256`, `rx_buffer->page` is recycled immediately via `page_pool_put_full_page`; otherwise `skb_mark_for_recycle(skb)` and `skb_add_rx_frag` attach the page, so `wx_dma_sync_frag` and `wx_put_rx_buffer` must not call `page_pool_put_full_page`. `wx_clean_rx_ring` must sync each buffer for CPU before `page_pool_put_full_page(..., false)`, and `wx_free_rx_resources` must call `wx_clean_rx_ring` before freeing `page_pool`, `desc`, or `rx_buffer_info`. [F1, F5, F162]
- `wx_setup_resources` allocates `wx->isb_mem` once via `wx_setup_isb_resources`, while `wx_free_resources` only frees ring resources; `wx_free_isb_resources(wx)` must only be called after `wx_free_irq(wx)` (in `ngbe_open` rollback and `ngbe_close`, and in `txgbe_remove` after `unregister_netdev`, never in `txgbe_close`). [F3, F182]
- `wx_free_irq` skips `free_irq` on `pdev->irq` and `wx->msix_entry->vector` when `wx->misc_irq_domain` is true, and skips unused `msix_q_entries`. Thus in `txgbe_open` rollback and `txgbe_close`, `wx_free_irq(wx)` must precede `txgbe_free_misc_irq(wx->priv)` (which clears `wx->misc_irq_domain = false` and must free nested `gpio_irq`/`link_irq` and parent `misc.irq` before `txgbe_del_irq_domain`). In `wx_reset_interrupt_capability`, check `pdev->msix_enabled` and free/null `msix_q_entries`/`msix_entry` before `pci_free_irq_vectors` clears `msix_enabled`. [F4, F6, F179, F181]
- In `wx_free_q_vector`, clear `wx->tx_ring` and `wx->rx_ring` pointers to `NULL` and call `netif_napi_del` before `kfree_rcu(q_vector, rcu)` (matching `rcu_read_lock()`/`READ_ONCE` readers in `wx_get_stats64`). Similarly, `wx_sriov_clear_data` must set `wx->num_vfs = 0` before freeing and nulling `wx->vfinfo` and `wx->mv_list`. [F14, F17]
- In `ngbe_remove`, `wxvf_remove`, and `txgbe_remove`, `cancel_work_sync(&wx->service_task)`, `wx_disable_sriov`, and `unregister_netdev` must precede `phylink_destroy` / `txgbe_remove_phy`, freeing `rss_key`/`mac_table`/`vfinfo`, or `wx_clear_interrupt_scheme`. Non-copper `wx_mac_sp` PHY teardown must follow LIFO order (`sfp_dev`, `i2c_dev`, `clock`/`clk`, `phylink`, `pcs`, `nodes.group`), and copper `wx_mac_sp` must call `phylink_disconnect_phy` before `phylink_destroy`. Devres-managed `netdev`, `wx->hw_addr`, and `mii_bus` must not be manually freed. [F131, F132, F183, F184, F200]

## API Contracts

- On DMA mapping failure, `wx_tx_map` unmaps all fragments in reverse order (checking `if (tx_buffer == first) break;` before wrapping `if (i == 0) i += tx_ring->count;` and `i--`), frees `first->skb`, clears `first->skb = NULL`, and restores `tx_ring->next_to_use`, so `wx_xmit_frame_ring` must jump to `cleanup_tx_tstamp` (skipping `out_drop`). [F7, F84]
- `wx_add_mac_filter` returns the non-negative RAR slot index on success and negative errno on failure, so callers must test `ret < 0` or `ret >= 0`, not `if (ret)`. `wx_tso` returns `< 0` on `skb_cow_head(skb, 0)` failure, `1` when TSO was emitted, and `0` otherwise, so `wx_xmit_frame_ring` must drop on `tso < 0` and call `wx_tx_csum` only when `tso == 0`. [F35, F36, F169]
- `wx_host_interface_command` requires `length` in `1..256` and aligned to `u32`, and converts each dword with `cpu_to_le32` (unconditionally checking `0x80` unknown-command status after `read_poll_timeout` with `timeout * 1000` us); thus `wx_hic_read_shadow_ram` callers must use `cpu_to_be32`/`cpu_to_be16` and pass 16-bit word offsets/counts to `wx_read_ee_hostif*`. In `WX_VF_SET_MACVLAN`, `msgbuf[0]` filter index is 1-based (`0` clears all without adding, `1` clears and adds first, `> 1` appends). [F45, F71, F80, F86, F142, F263]
- `txgbe_atr_compute_perfect_hash` masks `input->dword_stream` in place and writes `input->formatted.bkt_hash`, so call it with `input_mask->formatted.bkt_hash == 0` before checking duplicates, programming hardware, or saving the rule. `rule->action` stores raw `ring_cookie`, whereas `txgbe_fdir_write_perfect_filter` requires `queue` mapped to hardware `reg_idx`. [F220, F302]
- In `txgbe_phy.c`, MDIO (`mii_bus->priv`), GPIO (`gpiochip_get_data`), and I2C regmap (`context`) callbacks store and cast `struct wx *`, whereas in `txgbe_irq.c` the misc `irq_domain` `host_data` and `misc.irq`/`link_irq`/`gpio_irq` handlers store and cast `struct txgbe *`. In `pcs-xpcs-wx.c`, `txgbe_write_pma` and `txgbe_modify_pma` add `TXGBE_PMA_MMD` (`0x8020`) automatically, so pass only relative offsets (`0x11`..`0x76`). [F216, F269]

## Error Handling

- `wx_sw_init` and `txgbevf_sw_init` free their internal allocations (`rss_key`, `mac_table`, `vfinfo`) on failure, so `ngbe_probe`, `txgbe_probe`, and `txgbevf_probe` must jump to `err_pci_release_regions` when `*_sw_init` fails (avoiding double-free) and unwind through `err_free_mac_table` / `err_free_sw_init` on later errors. In `wx_sw_init`, the OEM `wx_flash_read_dword` branch must only return early when `err < 0`. [F2, F90, F177, F178]
- For `ERR_PTR`-returning allocators (`page_pool_create`, `ptp_clock_register` after `seqlock_init(&wx->hw_tc_lock)`, `xpcs_create_pcs_mdiodev`, `phylink_create`, `clk_register_fixed_rate`, `devm_regmap_init`, `platform_device_register_full`), extract `PTR_ERR` / check `IS_ERR` before resetting or storing into struct fields so `ERR_PTR` values never remain in fields checked for non-NULL on teardown. Conversely, `page_pool_dev_alloc_pages` returns `NULL` and must be NULL-checked before `page_pool_get_dma_addr`. [F11, F32, F33, F206]

## Known Pitfalls

- `wx->rss_key` is a `u32 *` pointer; always pass `WX_RSS_KEY_SIZE` (40), never `sizeof(wx->rss_key)`. In `txgbe_reset`, copy `wx->mac_table[0].addr` into a temporary buffer before `wx_flush_sw_mac_table(wx)` zeroes `wx->mac_table` in place. VF mailbox callers must mask off `WX_VT_MSGTYPE_CTS` from `msgbuf[0]` before comparing against `OPCODE | WX_VT_MSGTYPE_ACK` or `NACK`, and in `wx_set_vf_macvlan`, check `if (!entry || !entry->free)` after `list_for_each`. [F66, F98, F119, F224]
- Widen 32-bit upper register reads to `u64` before `<< 32` in `rd64` and PTP reads (bracketing `SYSTIML` between two reads of `SYSTIMH` in `wx_ptp_readtime`); use `1ULL << pool` for `wx->mac_table[i].pools` (`u64`); and widen ns values to `u64` before `<< cc->shift` and use `div_u64`/`div_u64_rem` in `wx_ptp.c`. [F109, F110, F111, F118]
- In `txgbe_fdir.c`, widen `ntohs(dst_port)`/`ntohs(flex_bytes)` to `u32` before `<< 16`; in `union txgbe_atr_input`, IP/port/VLAN/flex fields are big-endian, whereas `formatted.bkt_hash` is stored in host byte order via `(__force __be16)` and read without byte-swapping. [F238, F259]
- In `txgbe_xpcs_switch_mode`, check `if (xpcs->interface == interface && !txgbe_xpcs_mode_quirk(xpcs))` before assigning `xpcs->interface = interface`. In `txgbe_gpio_irq_handler_aml`, mask `WX_GPIO_INTMASK`, write handled bits to `WX_GPIO_EOI`, and unmask. In `txgbe_calc_eeprom_checksum`, replace `[0x580, 0x800)` with `0xffff` on `wx_mac_aml`, skip `sw_region_offset + TXGBE_EEPROM_CHECKSUM`, allow wrapping `u16` arithmetic in `TXGBE_EEPROM_SUM - *checksum`, and `kvfree(eeprom_ptrs)` on all exits. [F187, F244, F250, F258, F274]
