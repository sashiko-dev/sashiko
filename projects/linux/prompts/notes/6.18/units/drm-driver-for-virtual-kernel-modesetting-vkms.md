# DRM DRIVER FOR VIRTUAL KERNEL MODESETTING (VKMS)

VKMS is a software-only Virtual Kernel Modesetting DRM driver for headless display emulation and DRM/KMS API testing without physical hardware. It emulates planes (primary, overlay, cursor), CRTCs with hrtimer-driven vblanks and gamma LUTs, encoders, virtual connectors, and writeback connectors. An asynchronous workqueue-based line-by-line pixel composer blends planes in 16-bit ARGB, computes frame CRCs, and populates writeback framebuffers, backed by a dynamic configuration layer (`vkms_config`) and KUnit test suites.

## Architecture & Data Flow
- Every format in `vkms_formats` (`vkms_plane.c`) must have a case in `get_pixel_read_line_function()`, and every format in `vkms_wb_formats` (`vkms_writeback.c`) must have a case in `get_pixel_write_function()`, because `vkms_plane_atomic_update()` and `vkms_wb_atomic_commit()` resolve formats unconditionally through these helpers, which call `BUG()` in `default:`. [F40, F41, F68]
- `struct pixel_argb_u16` stores `a`, `r`, `g`, `b` in CPU endianness (`sizeof == 8`, no padding), while 16-bit DRM formats (`ARGB16161616`, `XRGB16161616`, `ABGR16161616`, `XBGR16161616`, `RGB565`, `BGR565`) must convert between `__le16` and CPU endianness. `compose_active_planes()` and `blend()` accumulate `crc32_le(*crc32, ...)` over raw `output_buffer->pixels` bytes without zeroing `*crc32` (callers must init `crc32 = 0`), and `compose_active_planes()` must multiply `line_buffer.n_pixels` by `sizeof(struct pixel_argb_u16)` for `kvmalloc()` and `row_size`. [F35, F62, F92]
- Before `blend()` runs, `compose_active_planes()` must validate `iosys_map_is_null(&plane_state[i]->frame_info->map[0])` and `planes[i]->pixel_read_line` across every entry `i` in `crtc_state->active_planes` (`num_active_planes`), plus `active_wb->pixel_write` when `active_wb` is non-NULL. Broken by: checking only the first or primary plane. [F73]
- In `vkms_crtc_atomic_check()`, `drm_atomic_add_affected_planes()` must run before iterating `crtc_state->plane_mask` with `drm_atomic_get_existing_plane_state()`, and both passes must use the identical `!plane_state->visible` filter with `i` reset to `0` between them. [F75]
- Every `struct drm_plane_state` on a VKMS plane is embedded in `struct vkms_plane_state.base.base` (via `struct drm_shadow_plane_state`), so `vkms_plane_reset()` and `vkms_plane_duplicate_state()` must allocate `struct vkms_plane_state` so `to_vkms_plane_state()` and `to_drm_shadow_plane_state()` remain valid. Broken by: using `drm_gem_reset_shadow_plane()` or `drm_atomic_helper_plane_reset()`. [F95]
- `vkms_plane_atomic_check()` must pass `DRM_PLANE_NO_SCALING` to `drm_atomic_helper_check_plane_state()` because `blend_line()` assumes unscaled `src`/`dst` dimensions. `vkms_wb_atomic_check()` must reject writeback framebuffers where `fb->width != mode->hdisplay` or `fb->height != mode->vdisplay`, and `vkms_writeback_row()` must clamp written pixels to `min_t(size_t, drm_rect_width(&frame_info->dst), src_buffer->n_pixels)`. [F63, F64]
- In `apply_lut_to_channel_value()`, when `drm_fixp2int(lut_index) == lut->lut_length - 1`, `ceil_lut_value` must be set to `floor_lut_value` instead of indexing `lut->base[drm_fixp2int_ceil(lut_index)]`. Also, `enum lut_channel` (`LUT_RED`, `LUT_GREEN`, `LUT_BLUE`, `LUT_RESERVED`) must match `struct drm_color_lut` field order (`sizeof(__u16) * 4`, no padding) because `(__u16 *)&lut->base[...]` is indexed by `channel`. [F54, F55]
- In `Rx_read_line()` (`DRM_FORMAT_R1`, `DRM_FORMAT_R2`, `DRM_FORMAT_R4`), pixels within a byte are extracted MSB-first starting at `bit_offset = (8 - bits_per_pixel) - rem_x * bits_per_pixel`, advancing `src_pixels` by `step` on horizontal reads only when `bit_offset < 0 || 8 <= bit_offset`. In `READ_LINE_YUV_SEMIPLANAR()` and `planar_yuv_read_line()`, chroma pointers start at `(x_start / hsub, y_start / vsub)` and advance by `step` only when `(i + get_subsampling_offset(...) + 1) % subsampling == 0`. [F60, F61]
- `get_conversion_matrix_to_argb_u16()` must call `swap_uv_columns(matrix)` for YVU/CrCb formats (`YVU420`, `YVU422`, `YVU444`, `NV21`, `NV61`, `NV42`). In `vkms_formats.c`, 8-bit channels and YUV offsets scale to 16-bit by `* 257`, 16-bit scales to 8-bit via `DIV_ROUND_CLOSEST(..., 257)`, and 32.32 fixed-point channels in `argb_u16_from_RGB565()`, `argb_u16_from_yuv161616()`, and `lerp_u16()` must convert via `drm_fixp2int_round()`, not `drm_fixp2int()`. [F39, F66, F80, F82]
- `vkms_config->dev` is only non-NULL while a `vkms_device` is instantiated, so `vkms_config` validation helpers must null-check `config->dev` before passing `&config->dev->drm` to `drm_info()`. In `vkms_create()`, `dma_coerce_mask_and_coherent()`, `drm_vblank_init()`, `vkms_modeset_init()`, and `vkms_config_register_debugfs()` must complete before `drm_dev_register()`, and `drm_client_setup()` must run only after `drm_dev_register()` succeeds. [F50, F104]

## Synchronization
- `vkms_crtc_atomic_begin()` acquires `vkms_output->lock` (`spin_lock_irq()`) and `vkms_crtc_atomic_flush()` updates `vkms_output->composer_state` and releases it (`spin_unlock_irq()`), holding it across plane updates to block `vkms_vblank_simulate()`. `crtc->dev->event_lock` nests inside `vkms_output->lock` in `vkms_crtc_atomic_flush()`, whereas `vkms_output->lock` and `vkms_output->composer_lock` never nest inside each other. [F9, F110]
- `vkms_vblank_simulate()` must bracket execution with `dma_fence_begin_signalling()` and `dma_fence_end_signalling(fence_cookie)`, release `output->lock` before acquiring `output->composer_lock` or calling `queue_work()`, and call `hrtimer_forward_now(&output->vblank_hrtimer, output->period_ns)` before `drm_crtc_handle_vblank(crtc)` because `vkms_get_vblank_timestamp()` locklessly reads `READ_ONCE(output->vblank_hrtimer.node.expires)` and subtracts `output->period_ns`. [F16, F25]
- `drm_crtc_vblank_put()` and `drm_crtc_vblank_off()` must never be called under `vkms_output->lock`, because `vkms_disable_vblank()` calls `hrtimer_cancel(&out->vblank_hrtimer)`, which waits for `vkms_vblank_simulate()` (which takes `vkms_output->lock`). `vkms_set_composer()` must call `drm_crtc_vblank_get(&out->crtc)` before acquiring `out->lock` when `enabled` is true, swap `out->composer_enabled` under `spin_lock_irq(&out->lock)`, and call `drm_crtc_vblank_put()` after unlocking only if `old_enabled` was true. [F24, F109]
- Accesses to `vkms_crtc_state` fields `crc_pending`, `wb_pending`, `frame_start`, and `frame_end` across `vkms_vblank_simulate()`, `vkms_composer_worker()`, and `vkms_wb_atomic_commit()` require `vkms_output->composer_lock` (`spin_lock_irq()` in process/workqueue contexts). `vkms_vblank_simulate()` updates `state->frame_start` only when `!state->crc_pending`, and `vkms_composer_worker()` must snapshot those fields and clear `crc_pending` under `out->composer_lock` before running `compose_active_planes()`. [F22, F23]
- Every `struct vkms_crtc_state` allocated in `vkms_atomic_crtc_duplicate_state()` or `vkms_atomic_crtc_reset()` must call `INIT_WORK(&vkms_state->composer_work, vkms_composer_worker)`. In `vkms_atomic_commit_tail()`, `drm_atomic_helper_commit_planes()` (publishing `output->composer_state` in `vkms_crtc_atomic_flush()`) must run before `drm_atomic_helper_commit_modeset_enables()` (where `vkms_wb_atomic_commit()` dereferences `output->composer_state`). [F17, F21]

## Object Lifetimes
- `vkms_plane_helper_funcs` must map plane framebuffers via `drm_gem_fb_vmap()` in `vkms_prepare_fb()` and unmap via `drm_gem_fb_vunmap()` in `vkms_cleanup_fb()`, and `vkms_atomic_commit_tail()` must call `flush_work(&vkms_state->composer_work)` on every old `vkms_crtc_state` after `drm_atomic_helper_wait_for_flip_done()` and before `drm_atomic_helper_cleanup_planes()`. Broken by: using `DRM_GEM_SHADOW_PLANE_HELPER_FUNCS` or cleaning up planes before flushing `composer_work`. [F5, F44]
- In `vkms_init()`, `vkms_create()` does not consume `config` on failure, so `vkms_init()` must call `vkms_config_destroy(config)` when `vkms_create()` fails and set `default_config = config` only on success. `struct vkms_config` must outlive `struct vkms_device` (`vkms_destroy(config)` before `vkms_config_destroy(config)`), and `vkms_config_get_device_name()` returns a borrowed pointer to `config->dev_name` valid only while `config` lives. [F1, F15, F103]
- `vkms_create()` must create `fdev` via `faux_device_create()` and open its devres group via `devres_open_group(&fdev->dev, NULL, GFP_KERNEL)` before `devm_drm_dev_alloc()`, unwinding on error with `devres_release_group(&fdev->dev, NULL)` before `faux_device_destroy(fdev)`. In `vkms_destroy()`, `fdev = config->dev->faux_dev` must be saved and `drm_dev_unregister()` then `drm_atomic_helper_shutdown()` must run before `devres_release_group(&fdev->dev, NULL)` and `faux_device_destroy(fdev)`, then `config->dev = NULL`. [F2, F3]
- Because modesetting objects (`vkms_plane`, `vkms_output`, `composer_workq`, `drm_encoder`, `vkms_connector`, `wb_connector`) use `drmm_*` helpers, error/teardown paths in `vkms_output_init()` and `vkms_destroy()` must not call `drm_*_cleanup()` or `destroy_workqueue()`. Also, `plane_cfg->plane`, `crtc_cfg->crtc`, `encoder_cfg->encoder`, and `connector_cfg->connector` are temporary pointers valid only during `vkms_output_init()` and must never be trusted or freed by `vkms_config` helpers. [F99, F102]
- When `new_state->crtc` and `new_state->fb` are non-NULL, `vkms_plane_atomic_update()` sets `frame_info->fb = fb` with `drm_framebuffer_get()`, which `vkms_plane_destroy_state()` releases with `drm_framebuffer_put()`. Because `vkms_plane_reset()` does not allocate `frame_info` (and must set `plane->state = NULL` right after `vkms_plane_destroy_state()` before `kzalloc()`), `vkms_plane_destroy_state()` and uncommitted-state paths must guard `frame_info` dereferences on `vkms_state->base.base.crtc` or `frame_info` being non-NULL. [F6, F7, F43]
- `vkms_crtc_atomic_check()` must return early if `vkms_state->active_planes` is already non-NULL to avoid leaking prior `kcalloc()` allocations. In `vkms_crtc_atomic_flush()`, when `crtc->state->event` is non-NULL, it must be armed (`drm_crtc_arm_vblank_event()` if `drm_crtc_vblank_get(crtc) == 0`) or sent (`drm_crtc_send_vblank_event()`) under `crtc->dev->event_lock`, and `crtc->state->event` must be set to `NULL`. [F8, F10]
- When `job->fb` is non-NULL, `vkms_wb_prepare_job()` allocates `vkmsjob`, maps `job->fb` via `drm_gem_fb_vmap()` (freeing `vkmsjob` on error), and calls `drm_framebuffer_get()`; `vkms_wb_cleanup_job()` must call `drm_gem_fb_vunmap()`, `drm_framebuffer_put()`, `vkms_set_composer(vkms_output, false)`, and `kfree(vkmsjob)`. [F12]

## API Contracts
- `vkms_config_create()`, `vkms_config_default_create()`, `vkms_config_create_*()`, `vkms_plane_init()`, `vkms_crtc_init()`, and `vkms_connector_init()` return `ERR_PTR`/`ERR_CAST` on failure and never `NULL`, whereas `vkms_config_crtc_primary_plane()`, `vkms_config_crtc_cursor_plane()`, `vkms_atomic_crtc_duplicate_state()`, and `vkms_plane_duplicate_state()` return `NULL` when not found or on allocation failure. [F26, F27]
- XArrays `possible_crtcs` and `possible_encoders` in `vkms_config_*` must be initialized with `xa_init_flags(..., XA_FLAGS_ALLOC)` for `xa_alloc()`. `vkms_config_plane_attach_crtc()`, `vkms_config_encoder_attach_crtc()`, and `vkms_config_connector_attach_encoder()` must reject cross-`vkms_config` objects with `-EINVAL` and duplicate attachments with `-EEXIST`. [F34, F48]
- In `blend_line()`, `dst_line.x1`/`x2` must be clamped to `[0, crtc_x_limit]` (returning early if `x2 <= x1`) before converting `frame_info->src` with `drm_rect_fp_to_int()`, inverse-transforming `src_line`, and clamping to `[0, fb->width)` and `[0, fb->height)` via `clamp_line_coordinates()`. Before calling `pixel_read_line()`, `src_x_start` (`READ_RIGHT_TO_LEFT`) or `src_y_start` (`READ_BOTTOM_TO_TOP`) must be incremented by `pixel_count - 1`, passing `&stage_buffer->pixels[dst_x_start]`. [F36, F56, F57, F122]
- `packed_pixels_addr_1x1()` (and `READ_LINE()`) may only be used for format planes where `drm_format_info_block_width()` and `drm_format_info_block_height()` are both 1; multi-pixel block formats (`DRM_FORMAT_R1`, `DRM_FORMAT_R2`, `DRM_FORMAT_R4` in `Rx_read_line()`) must use `packed_pixels_addr()` to obtain `rem_x` and `rem_y`. [F91]

## Error Handling
- In `vkms_plane_atomic_update()`, both `new_state->crtc` and `new_state->fb` must be checked for non-`NULL` before dereferencing `fb->format` or populating `vkms_plane_state->frame_info`. [F28]

## External Contracts
- In `vkms_output_init()`, `vkms_config_is_valid(vkmsdev->config)` must be checked first (enforcing object counts in `[1, 31]`, valid possible CRTC/encoder links, and each CRTC having a possible encoder, one primary plane, and at most one cursor plane), and loops must run in order: planes, CRTCs with writeback, plane `possible_crtcs`, encoders, then connectors. Every `drm_encoder` and `wb_encoder` must include its own `drm_encoder_mask()` in `possible_clones`, and non-writeback and writeback encoders sharing a `possible_crtc` must mutually include each other's mask. [F78, F115, F125]

## Known Pitfalls
- Because `vkms_config_for_each_plane`, `vkms_config_for_each_crtc`, `vkms_config_for_each_encoder`, and `vkms_config_for_each_connector` expand to `list_for_each_entry`, any loop calling `vkms_config_destroy_*()` must use `list_for_each_entry_safe()` instead. [F76]
- In `vkms_wb_atomic_commit()`, `conn_state` (`wb_conn->base.state`) and `connector_state` (`drm_atomic_get_new_connector_state(state, conn)`) alias the same state, so `connector_state->writeback_job->fb` and `conn_state->writeback_job->priv` must be read before `drm_writeback_queue_job(wb_conn, connector_state)` clears `writeback_job` to `NULL`. [F77]
- Fixed-point arithmetic on `s64` values in `vkms_formats.c` and `vkms_composer.c` must use `<drm/drm_fixed.h>` helpers (`drm_fixp_div()`, `drm_fixp_mul()`) rather than raw 64-bit `/` or `%`. In `argb_u16_from_yuv161616()`, the `s64` values from `drm_fixp2int_round()` must be clamped to `[0, 0xffff]` with `clamp()` before assigning to `u16`. [F79, F81]
- `get_block_step_bytes()` must cast `fb->pitches[plane_index]` to signed `int` before negating for `READ_BOTTOM_TO_TOP` and return a signed `step` stored in a signed variable in callers (`READ_LINE`, `Rx_read_line`, `READ_LINE_YUV_SEMIPLANAR`, `planar_yuv_read_line`). Similarly, in `clamp_line_coordinates()`, `fb->width` and `fb->height` (`unsigned int`) must be cast to `int` before subtracting `*src_x_start` or `*src_y_start` inside `max(0, ...)`. [F83, F87]
- In `vkms_crtc_atomic_check()`, `vkms_state->active_planes` must be allocated with `sizeof(*vkms_state->active_planes)` (`struct vkms_plane_state *`), not `sizeof(plane)` or `sizeof(struct vkms_plane_state)`. Also, when logging FourCC codes with `%p4cc` in `get_pixel_read_line_function()` and `get_pixel_write_function()`, pass `&format` rather than `format` by value. [F88, F96]
