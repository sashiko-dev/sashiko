# CPU HOTPLUG

This unit implements the Linux kernel's core CPU hotplug state machine (`kernel/cpu.c`), per-CPU hotplug kthreads (`kernel/smpboot.c`), global CPU bitmasks, SMT control, CPU vulnerability mitigation command-line parsing, and Rust CPU bindings (`rust/kernel/cpu.rs`). It coordinates sequential and parallel CPU bringup and teardown across PREPARE (control CPU), STARTING/DYING (target CPU with IRQs disabled), and ONLINE (per-CPU `cpuhp/%u` kthread) phases under `cpu_add_remove_lock` and `cpu_hotplug_lock`.

## Architecture & Data Flow
- `cpuhp_is_ap_state()` and `cpuhp_is_atomic_state()` classify states by numeric position in `enum cpuhp_state`: IRQ-disabled STARTING/DYING steps must lie in `[CPUHP_AP_IDLE_DEAD, CPUHP_AP_ONLINE)` (with `CPUHP_AP_DUMMY_TIMER_STARTING` after all other `*_TIMER_STARTING` states), AP kthread steps above `CPUHP_TEARDOWN_CPU`, and BP prepare steps below `CPUHP_BRINGUP_CPU` (with `CPUHP_TIMERS_PREPARE` / `timers_dead_cpu` above `CPUHP_BLK_MQ_DEAD`). [F70, F115, F116]
- `cpuhp_next_state()` pre-increments `st->state` on bringup and post-decrements on teardown; `cpuhp_reset_state()` must adjust `st->state` (`--` on bringup, `++` on teardown) only when `st->last == NULL` so partial multi-instance rollback re-runs the failed state up to `st->last`. In `cpuhp_invoke_callback()`, multi-instance transitions with non-NULL `lastp` must record the failing node in `*lastp` and stop at `node == *lastp` before clearing `*lastp = NULL`; `cpuhp_invoke_ap_callback()` must reset `st->node = st->last = NULL` before returning. [F42, F79, F92]
- `__cpuhp_state_add_instance_cpuslocked()` must run `cpuhp_issue_call(cpu, state, true, node)` on all present CPUs at or above `state` (and roll back on failure) before `hlist_add_head()`, and `__cpuhp_state_remove_instance()` must complete teardown calls before `hlist_del(node)`. [F65]
- Whenever `cpuhp_set_state()` or `cpuhp_reset_state()` sets or inverts `st->bringup`, it must take `cpu` as an explicit parameter and update `set_cpu_dying(cpu, !bringup)` whenever `cpu_dying(cpu) != !bringup`. [F43, F55]
- `cpuhp_state.fail` must be initialized and reset to `CPUHP_INVALID` (`-1`, not `0` which is `CPUHP_OFFLINE`), and `cpuhp_invoke_callback()` must reset `st->fail = CPUHP_INVALID` when matching `st->fail == state` before returning `-EAGAIN`. [F44, F63]
- When `_cpu_up()` brings up a CPU from `CPUHP_OFFLINE`, it must call `scs_task_reset(idle)` and `kasan_unpoison_task_stack(idle)` on the recycled `idle_thread_get(cpu)` before starting the CPU. [F61]
- `cpu_smt_set_num_threads()` must run after full CPU identification; in `cpu_bootable()`, `cpu_smt_control` must be checked against `CPU_SMT_NOT_IMPLEMENTED` and `CPU_SMT_NOT_SUPPORTED` before `topology_is_primary_thread(cpu)`, and when SMT is disabled it must return `true` for unbooted secondary threads (`!cpus_booted_once_mask`) so they run `notify_cpu_starting()` before `bringup_wait_for_ap_online()` cancels with `-ECANCELED`. [F86, F132]
- `cpuhp_smt_enable()` must check `topology_is_core_online(cpu)` alongside `!cpu_online(cpu)`, `node_online(cpu_to_node(cpu))`, and `cpu_smt_thread_allowed(cpu)` before calling `_cpu_up()`. [F87]
- Setting `cpu_smt_control != CPU_SMT_ENABLED` in `cpu_smt_disable()` or `cpu_smt_set_num_threads()` must set `cpu_smt_num_threads = 1`; in `__store_smt_control()`, `else if (num_threads < orig_threads || force_off)` must include `force_off` so `CPU_SMT_DISABLED` -> `CPU_SMT_FORCE_DISABLED` calls `cpuhp_smt_disable()`, and every `enum cpuhp_smt_control` value must have an entry in `smt_states[]`. [F59, F72, F89]
- In `smpboot_thread_fn()`, `ht->cleanup()` must only run when `td->status != HP_THREAD_NONE` and `ht->park()` only when `td->status == HP_THREAD_ACTIVE` (setting `HP_THREAD_PARKED`); `smpboot_park_threads()` must iterate `hotplug_threads` in reverse (`list_for_each_entry_reverse`) under `smpboot_threads_lock`. [F66, F127]

## Synchronization
- Lock hierarchy: `lock_device_hotplug()` -> `cpu_maps_update_begin()` (`cpu_add_remove_lock`) -> `cpus_write_lock()` / `cpus_read_lock()` (`cpu_hotplug_lock`) -> `cpuhp_state_mutex`, `smpboot_threads_lock`, and `irq_lock_sparse()`. External callers must use `add_cpu()` / `remove_cpu()` (not `cpu_device_up()` / `down()`), and `cpuhp_smt_enable()` / `disable()` (under `cpu_maps_update_begin()`) must call `cpuhp_online_cpu_device()` / `cpuhp_offline_cpu_device()` instead of `device_online()` / `offline()`. [F124, F149]
- `cpu_add_remove_lock` (`cpu_maps_update_begin()` / `done()`) must be held across all accesses to `cpu_hotplug_disabled` and `cpu_hotplug_offline_disabled` and all calls to `_cpu_up()`, `_cpu_down()`, and `cpu_down_maps_locked()`. Under `cpus_write_lock()`, `_cpu_up()` must revalidate `cpu_present(cpu)` and check `st->state >= target`. [F20, F34]
- `__cpuhp_setup_state_cpuslocked()`, `__cpuhp_remove_state_cpuslocked()`, `__cpuhp_state_add_instance_cpuslocked()`, and `__cpuhp_state_remove_instance()` must hold both `cpu_hotplug_lock` and `cpuhp_state_mutex` continuously across the `for_each_present_cpu` callback loop, rollback, and `cpuhp_hp_states` / `sp->list` updates. [F23]
- `smpboot_register_percpu_thread()` and `smpboot_unregister_percpu_thread()` must hold both `cpus_read_lock()` and `smpboot_threads_lock` while creating/unparking or destroying per-CPU threads and modifying `hotplug_threads`. In `__smpboot_create_thread()`, `tsk` must be marked per-CPU (`kthread_set_per_cpu()`), parked (`kthread_park()`), refcounted (`get_task_struct()`), stored in `*per_cpu_ptr(ht->store, cpu)`, and confirmed parked via `wait_task_inactive(tsk, TASK_PARKED)` before `ht->create(cpu)`. [F35, F36]
- In `__cpuhp_kick_ap()`, updates to `struct cpuhp_cpu_state` must be ordered by `smp_mb()` before setting `st->should_run = true`, paired with `smp_mb()` in `cpuhp_thread_fun()` immediately after checking `st->should_run` and before reading `st->single`, `st->cb_state`, or `st->target`. `cpuhp_thread_fun()` must also bracket AP callbacks with `lockdep_acquire_cpus_lock()` / `cpuhp_lock_acquire(bringup)` and release calls. [F24, F141]
- `cpuhp_ap_update_sync_state()` must use `atomic_xchg()` (not `atomic_set()`); `cpuhp_wait_for_sync_state()` must poll with `arch_cpuhp_sync_state_poll()` for `NSEC_PER_MSEC` before `usleep_range()`, leaving `ap_sync_state` unchanged on timeout (using `10ULL * NSEC_PER_SEC`), and `cpuhp_bp_sync_dead()` must not overwrite `SYNC_STATE_DEAD` with `SYNC_STATE_SHOULD_DIE`. [F25, F101, F135]
- In `cpuhp_bringup_cpus_parallel()`, when `cpuhp_smt_aware()` is true, primary threads (`cpuhp_get_primary_thread_mask()`, stored in `static struct cpumask tmp_mask __initdata`) must reach both `CPUHP_BP_KICK_AP` and `CPUHP_ONLINE` before secondary SMT sibling threads are kicked to `CPUHP_BP_KICK_AP`. [F109, F133]
- `cpuhp_online_idle()` runs in the upcoming AP's idle task and must call `stop_machine_unpark(smp_processor_id())` and set `st->state = CPUHP_AP_ONLINE_IDLE` before `complete_ap_thread(st, true)`; it must not call `kthread_unpark(st->thread)` (done by `bringup_wait_for_ap_online()` on the control CPU). [F28, F142]
- `bringup_cpu()`, `cpuhp_bringup_ap()`, and `takedown_cpu()` must hold `irq_lock_sparse()` across low-level AP bringup (until `bringup_wait_for_ap_online()`) and AP takedown. In `takedown_cpu()`, the control CPU must park `st->thread`, acquire `irq_lock_sparse()`, run `stop_machine_cpuslocked(take_cpu_down, ...)` (releasing `irq_unlock_sparse()` and unparking `st->thread` if it fails), and wait via `wait_for_ap_thread(st, false)` before `irq_unlock_sparse()`, `__cpu_die(cpu)`, `cpuhp_bp_sync_dead(cpu)`, and `rcutree_migrate_callbacks(cpu)`. [F9, F29, F120, F146]
- In `take_cpu_down()`, `__cpu_disable()` must succeed before `cpuhp_invoke_callback_range_nofail()` runs `DYING` callbacks and `stop_machine_park()`. In `cpuhp_report_idle_dead()`, after `rcutree_report_cpu_dead()`, the dying CPU must delegate `complete_ap_thread()` via `smp_call_function_single()` to an online CPU (`cpuhp_complete_idle_dead`). [F119, F145]
- `set_cpu_online()` must use atomic `cpumask_test_and_set_cpu` / `clear_cpu` and `atomic_inc()` / `dec()` for concurrent IPI/NMI callers; readers of `num_online_cpus()` or `cpu_online_mask` needing hotplug stability must hold `cpus_read_lock()` or `cpu_maps_update_begin()`. [F37, F153]
- In `smpboot_thread_fn()`, `HP_THREAD_NONE` and `HP_THREAD_PARKED` cases must set `td->status = HP_THREAD_ACTIVE` and `continue` to recheck stop/park with preemption disabled; `ht->thread_should_run(td->cpu)` runs with preemption disabled and `TASK_INTERRUPTIBLE`, whereas other `ht` callbacks run after `TASK_RUNNING` and `preempt_enable()`. [F91, F143]

## Object Lifetimes
- In `__smpboot_create_thread()`, `td` ownership transfers to `smpboot_thread_fn()` once `kthread_create_on_cpu()` succeeds (post-creation failure paths must use `kthread_stop_put(tsk)`, not `kfree(td)`). `smpboot_destroy_threads()` must iterate `for_each_possible_cpu()`, call `kthread_stop_put()`, and reset `*per_cpu_ptr(ht->store, cpu) = NULL`. [F1, F2]
- `bus_get_dev_root(&cpu_subsys)` returns a refcounted `struct device *` requiring `put_device()`, whereas `get_cpu_device()` returns an unreferenced nullable pointer (callers must NULL-check and never `put_device()`). In `rust/kernel/cpu.rs`, `from_cpu()` must remain `unsafe` and NULL-check `get_cpu_device()` before `Device::from_raw()`, as the `&'static Device` is invalidated on hot-unplug. [F17, F18, F50, F113]
- `cpu_down_maps_locked()` passes stack-allocated `struct cpu_down_work work` to `__cpu_down_maps_locked()`, so it must dispatch synchronously via `work_on_cpu()` on an online `housekeeping_cpumask(HK_TYPE_DOMAIN)` CPU other than `work.cpu` (returning `-EBUSY` if none exists). [F108, F138]
- `freeze_secondary_cpus()` must increment `cpu_hotplug_disabled` under `cpu_maps_update_begin()` even on `_cpu_down()` or `pm_wakeup_pending()` failure (and abort on `pm_wakeup_pending()`, unlike `smp_shutdown_nonboot_cpus()`), because `thaw_secondary_cpus()` unconditionally calls `__cpu_hotplug_enable()`. `finish_cpu()` must clear `idle->active_mm = NULL` and call `mmdrop_lazy_tlb(mm)`. [F97, F136, F154]

## API Contracts
- Atomic state callbacks (`CPUHP_AP_IDLE_DEAD <= state < CPUHP_AP_ONLINE`) run on the target CPU with local IRQs disabled and must never sleep or fail; `notify_cpu_starting()` (which must call `rcutree_report_cpu_starting(cpu)` first with IRQs disabled) and `take_cpu_down()` must use `cpuhp_invoke_callback_range_nofail()`, and teardown callbacks in `cpuhp_issue_call(..., false, ...)` must also return `0`. [F11, F46, F139, F140]
- Explicit states must only be added to `enum cpuhp_state` for `STARTING` callbacks or ordering constraints; otherwise callers must use `CPUHP_BP_PREPARE_DYN` or `CPUHP_AP_ONLINE_DYN` and pass the returned positive state ID (not `*_DYN`) to `__cpuhp_remove_state*()`. [F114, F161]
- `cpuhp_cb_check()` enforces `(CPUHP_OFFLINE, CPUHP_ONLINE)`. Multi-instance states require `cpuhp_setup_state_multi()`, all instances on `sp->list` must be removed before `__cpuhp_remove_state_cpuslocked()`, and callback invocation must branch on `step->multi_instance` (`.multi(cpu, node)` vs `.single(cpu)`). [F75, F106, F162]
- `struct smp_hotplug_thread` requires non-NULL `store`, `thread_should_run`, `thread_fn`, and `thread_comm` (with at most one `%u`-compatible format specifier for `unsigned int cpu`). [F110, F163]
- In `rust/kernel/cpu.rs`, `CpuId::from_i32_unchecked(id)` and `from_u32_unchecked(id)` require `0 <= id < nr_cpu_ids()`, and `CpuId::current()` calls `raw_smp_processor_id()` without disabling preemption. [F54, F157]

## Error Handling
- On bringup failure in `cpuhp_up_callbacks()` or `cpuhp_bringup_mask()`, rollback via `cpuhp_invoke_callback_range(false, ...)` must be gated by `can_rollback_cpu(st)`. In `bringup_wait_for_ap_online()`, if `!cpu_online(cpu)` after `wait_for_ap_thread(st, true)`, warn with `WARN_ON_ONCE()` and return `-ECANCELED` without unparking `st->thread`. [F6, F167]
- On teardown failure in `cpuhp_down_callbacks()`, `cpuhp_reset_state()` increments `st->state` back to the failed step, so rollback in `cpuhp_down_callbacks()` and AP re-kick in `_cpu_down()` must only run if `st->state < prev_state` (and `st->state == CPUHP_TEARDOWN_CPU` for AP re-kick). `cpuhp_kick_ap()` and `cpuhp_invoke_ap_callback()` must save `st->result` before calling `__cpuhp_kick_ap(st)` for rollback (which zeroes `st->result`). [F10, F41]
- In `__cpuhp_setup_state_cpuslocked()`, on startup failure, `cpuhp_rollback_install()` must run before `cpuhp_store_callbacks(state, NULL, ...)` clears the step. [F14]
- `idle_init()` must not store an `ERR_PTR` from `fork_idle()` into `idle_threads`, `_cpu_up()` must check `IS_ERR(idle)` on `idle_thread_get()`, and `__smpboot_create_thread()` must check `IS_ERR(tsk)` on `kthread_create_on_cpu()` and free `td` before writing `*per_cpu_ptr(ht->store, cpu) = tsk`. [F47, F48]

## External Contracts
- `fail_store()` and `target_store()` must reject states outside `[CPUHP_OFFLINE, CPUHP_ONLINE]` before calling `cpuhp_get_step()`; `target_store()` must also reject non-endpoint states when `!CONFIG_CPU_HOTPLUG_STATE_CONTROL` or steps with `!sp->name` or `sp->cant_stop`, and only call `cpu_down()` when `st->state > target` strictly holds. [F74, F88, F165]
- `__store_smt_control()` must reject writes with `-EPERM` when `cpu_smt_control == CPU_SMT_FORCE_DISABLED` and validate thread counts with `cpu_smt_num_threads_valid()`. [F82, F166]

## Known Pitfalls
- Every dynamic state range (`CPUHP_AP_ONLINE_DYN`, `CPUHP_BP_PREPARE_DYN`) must be handled in `cpuhp_reserve_state()`, `cpuhp_store_callbacks()` (which must only call `cpuhp_reserve_state()` when `name != NULL`), and `dynstate` in `__cpuhp_setup_state_cpuslocked()` (evaluated before `state = ret`, resetting `ret = 0`). [F64, F69, F100]
- `cpuhp_bringup_mask()` does `if (!--ncpus) break;`, so callers must verify `ncpus > 0` first. [F78]
- In `clear_tasks_mm_cpumask()` (called only after `cpu` is offline), `arch_clear_mm_cpumask_cpu()` and `task_unlock()` must use `t` from `find_lock_task_mm(p)`, not `p`. In `cpu_down_maps_locked()`, `for_each_cpu_and(cpu, ...)` overwrites `cpu`, so use `work.cpu` afterwards. [F98, F99, F147]
- `global_mitigations` (scanned via `ARRAY_SIZE`) must have no `NULL` sentinel and list `"auto,nosmt"` before `"auto"`, whereas `vector_mitigations` (`match_token()`) must end with `{ NR_VECTOR_PARAMS, NULL }`. [F80]
