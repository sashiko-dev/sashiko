# QCOM AUDIO (ASoC) DRIVERS

Qualcomm ASoC audio subsystem covering WCD/PMIC codecs (MSM8916/PM8916, PM4125, WCD9335, WCD934x, WCD937x, WCD938x, WCD939x), WSA881x/883x/884x SoundWire speaker amplifiers, shared Class-H (`wcd-clsh-v2`) and Multi-Button Headset Control (`wcd-mbhc-v2`) libraries, Low-Power Audio Subsystem (LPASS) CPU/DMA/HDMI/CDC-DMA platform drivers, QDSP6 APR (`q6afe`, `q6adm`) and GPR (`audioreach`) IPC stacks, and machine sound card helpers.

## Architecture & Data Flow

- SoundWire port numbers (`port_idx`, `ch_info->port_num`, `prepare_ch->num`) are 1-based while channel IDs (`ch_id`) are 0-based: index `port_config[]`, `port_enable[]`, and `port_prepared[]` at `port_num - 1`, populate `pdev->m_port_map` starting at `&pdev->m_port_map[1]`, convert 1-based DT channel indices via `BIT(ch_idx - 1)` (`PM4125/WCD937X_SWRM_CH_MASK`), and set `sink_ports` / `source_ports` for an N-element `dpn_prop` array to `GENMASK(N - 1, 0)` (never `GENMASK(N, 0)`). [F36, F81, F184, F236, F237, F279, F302]
- In SoundWire codecs (`pm4125`, `wcd937x`, `wcd938x`, `wcd939x`), `*_connect_port()` must update `port_config[port_idx - 1].ch_mask` and `master_channel_map[sdev->m_port_map[port_num]]` in lockstep and be called whenever `port_enable[]`, `comp1_enable`, or `comp2_enable` changes. Every `*_sdw_hw_params()` and `wsa88{1,3,4}x_hw_params()` must reset `active_ports = 0` (and `sconfig.ch_count = 1` on WCD) before compacting only ports with non-zero `ch_mask` into `port_config[active_ports++]` for `sdw_stream_add_slave()`. [F48, F72, F167, F168, F284, F285, F300, F464]
- In `pm4125-sdw`, `wcd937x-sdw`, `wcd938x-sdw`, and `wcd939x-sdw`, only the TX slave (`is_tx == true`) allocates `regmap` (`regmap` is `NULL` on RX slaves, so shared remove/PM/status callbacks must guard `if (regmap)`). TX `regmap` (and `wsa884x->regmap`) must start in `regcache_cache_only(regmap, true)` at probe, mark cache-only and `regcache_mark_dirty()` on runtime suspend / `SDW_SLAVE_UNATTACHED`, and disable cache-only + `regcache_sync()` only on `SDW_SLAVE_ATTACHED` or runtime resume. [F32, F96, F210, F211, F272, F295, F486]
- `MIC_BIAS_1..4` are 1-based: validate `micb_num` and use `micb_index = micb_num - 1` (DAPM micbias widgets must store 1-based `MIC_BIAS_*` in `w->shift`). Under `micb_lock`, `MICB_PULLUP_ENABLE` must only write pull-up bits when `micb_ref[i] == 0 && pullup_ref[i] > 0`, and `MICB_DISABLE` reaching `micb_ref[i] == 0` must switch to pull-up mode (and skip `PRE/POST_MICBIAS_2_OFF` on WCD938x/939x) whenever `pullup_ref[i] > 0`. [F57, F109, F174, F186, F306, F314]
- In `wcd9335` and `wcd934x`, `tx_chs[]` and `rx_chs[]` are shared across DAIs: `slim_tx_mixer_put` and `slim_rx_mux_put` must use `list_del_init()` (never `list_del()`) and check `list_empty()` / `tx_port_value[port_id]` before adding to `dai[].slim_ch_list`. `rx_chs` stores `ch->port` offset by `WCD9335/WCD934X_RX_START` (16..28) and `ch->shift` as 0..12, so RX array and `SLIM_PGD_PORT_INT_EN0` indexing must subtract `*_RX_START`. [F7, F60, F136, F170, F187]
- In `wcd934x/937x/938x/939x_wcd_mbhc_calc_impedance()`, `ANA_MBHC_BTN5..7`, `MBHC_CTL_CLK`, `MBHC_NEW_ZDET_ANA_CTL`, and `ANA_MBHC_ELECT` `FSM_EN` must be saved before running ramps and restored along with `ANA_MBHC_MECH` at `zdet_complete` on every exit path; if left-channel `z1L` is `ZDET_FLOATING_IMPEDANCE` or `> ZDET_VAL_100K`, reset `zdet_param_ptr = &zdet_param[1]` and `d1 = d1_a[1]` before the right-channel ramp. [F176, F196, F290, F316]
- In LPASS runtime ops: playback and capture on the same MI2S DAI share `LPAIF_I2SCTL_REG(v, id)`, so playback ops must only touch `spken/spkmode/spkmono`, capture ops must only touch `micen/micmode/micmono`, and `lpass_cpu_daiops_hw_params()` must downgrade multi-line SD modes only in a local `mode` variable without overwriting `drvdata->mi2s_{playback,capture}_sd_mode[id]`. Shared `IRQEN`/`IRQCLEAR` updates must mask to `LPAIF_IRQ_ALL(ch)`, and `lpass_dma_interrupt_handler()` must check `PER`, `XRUN`, and `ERR` with separate `if` statements (not `else if`). [F420, F424, F455, F458]

## Synchronization

- In `wcd-mbhc-v2.c`, `wcd_cancel_hs_detect_plug()` (`wcd_mbhc_cancel_pending_work()`), `wcd_mbhc_report_plug()`, `wcd_mbhc_adc_detect_plug_type()`, and `wcd_schedule_hs_detect_plug()` require `mbhc->lock` held. `mbhc_plug_detect_fn()` must set `mbhc->in_swch_irq_handler = true` before `wcd_mbhc_cancel_pending_work()` drops `mbhc->lock` and read `mbhc->current_plug` only after it re-acquires `mbhc->lock`; `wcd_btn_long_press_fn()` must never acquire `mbhc->lock`, and disabling `mbhc_hs_ins/rem_intr` inside MBHC handlers must use `disable_irq_nosync()`. [F2, F13, F16, F113, F114]
- Because `wcd934x/937x_micbias_control()` calls `wcd_mbhc_event_notify()` while holding `micb_lock`, no `wcd_mbhc_cb` callback reachable from `wcd_mbhc_event_notify()` may acquire `micb_lock`. In `wcd934x.c`, `sysclk_mutex` must never nest with `micb_lock`, and `swclk_gate_enable/disable` must be wired to process-context `.prepare/.unprepare` (never atomic `.enable/.disable`). [F146, F227, F230, F231]
- In `pm4125`, `wcd937x`, `wcd938x`, and `wcd939x`, `*_soc_codec_probe()` must wait on `tx_sdw_dev->initialization_complete` and call `pm_runtime_resume_and_get(dev)` (balanced with `pm_runtime_put(dev)` on all paths) before any register/efuse I/O or `*_io_init()`, and `*_bind()` must initialize `regmap`, `virq`/`irq_chip`, and `sdw_priv[]->slave_irq` before `snd_soc_register_component()`. [F22, F149, F215, F255, F336]
- In `wsa883x_get_temp()` and `wsa884x_get_temp()`, `sp_lock` must be held via `guard(mutex)`: when `pa_on` is true, return cached `temperature * 1000` without touching hardware; when `!pa_on`, balance `pm_runtime_resume_and_get()` with `pm_runtime_put_autosuspend()`, restore `TADC_VALUE_CTL` and clear `PA_FSM_BYP`/`PA_FSM_BYP0` to `0x0` before any exit, guard against `d1 == d2` before dividing by `d2 - d1`, and only update `temperature` (stored in °C, scaled by 1000 for `*temp`) when `in_range(val, LOW_TEMP_THRESHOLD, range)`. [F251, F298, F308, F368, F385, F426, F465, F466, F499]
- In `q6afe.c` and `q6adm.c`: `port_list` and `copps_list`/`copp_bitmap` must be accessed under `spin_lock_irqsave(&port_list_lock / &copps_list_lock)` (`q6adm_alloc_copp()` runs under `copps_list_lock` and must use `GFP_ATOMIC`); `q6afe_find_port()` and `q6adm_find_*copp()` must store matches in a separate `ret` pointer (never the loop cursor) and call `kref_get()` before unlocking; and `kref_put(..., q6afe_port_free / q6adm_free_copp)` must never be called while holding the list spinlock. [F387, F388, F390, F391, F461, F501, F502, F503]
- Synchronous DSP command senders (`afe_apr_send_pkt`, `q6adm_apr_send_copp_pkt`, `q6adm_matrix_map`, `audioreach_send_cmd_sync`) must hold their command mutex (`afe->lock`, `adm->lock`, `graph->lock`) across zeroing `result->opcode` and `result->status`, sending the APR/GPR packet, and waiting on `wait_event_timeout()`. APR callbacks (`q6afe_callback`, `q6adm_callback`) must never acquire `afe->lock` or `adm->lock`, and callers of `audioreach_graph_send_cmd_sync()` must release `graph->lock` first. [F389, F392, F393, F463]

## Object Lifetimes

- In `wcd9335_trigger()` and `wcd934x_trigger()`, `STOP`, `SUSPEND`, and `PAUSE_PUSH` must call `slim_stream_disable(dai_data->sruntime)` before `slim_stream_unprepare(dai_data->sruntime)`. In `wcd9335/934x_slim_set_hw_params()`, error paths after allocating `cfg->chs` must both `kfree(cfg->chs)` and set `cfg->chs = NULL`. [F1, F8, F132, F157]
- `wcd_mbhc_init()` must initialize `mbhc->lock` and work structs before requesting the 7 MBHC IRQs with non-devm `request_threaded_irq()` (and non-devm `kzalloc()`), and `wcd_mbhc_deinit()` must `free_irq()` all 7 IRQs before cancelling work and freeing `mbhc`. `wcd_clsh_ctrl_alloc()` uses non-devres `kzalloc()` and returns `ERR_PTR(-ENOMEM)`: callers must check `IS_ERR()` and explicitly call `wcd_clsh_ctrl_free()` on probe error and in `.remove`. [F5, F17, F92, F216, F242]
- In `pm4125`, `wcd937x`, `wcd938x`, and `wcd939x`: `component_match_add_release(..., component_release_of, ...)` takes ownership of `rxnode`/`txnode` (never call `of_node_put()`); `*_bind()` must add `DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME` links with `txdev` supplying `rxdev`/`dev` (and `rxdev` supplying `dev`), and unwind `device_link_remove()`, `put_device()`, and `component_unbind_all()` in reverse order on error and unbind. `wcd9390_probe` uses non-devres `regmap_init_sdw()` freed via `regmap_exit()` after `component_del()`. [F11, F97, F214, F241, F245, F337]
- In `audioreach.c`, packets from `__audioreach_alloc_pkt()` / `audioreach_alloc_*_pkt()` are `kzalloc`-allocated and not freed by `audioreach_*_send_cmd_sync()` or `gpr_send_port_pkt()`, so every caller must `kfree(pkt)`. `audioreach_graph_free_buf()` must hold `graph->lock` while zeroing `num_periods`, freeing `port->buf`, and setting `port->buf = NULL`. [F379, F380]

## API Contracts

- `drvdata` contracts: in `pm4125`, `wcd937x`, `wcd938x`, and `wcd939x`, the master device stores `struct *_priv *` while SoundWire slaves (`rxdev`, `txdev`, `&slave->dev`) store `struct *_sdw_priv *`; in `wcd934x`, `pdev->dev` stores `wcd934x_codec *` while `dev->parent` stores `wcd934x_ddata *`; in `q6afe`/`q6adm`, `q6afe/q6adm *` lives on `dev->parent` (`apr_device`), so exported APIs taking a child `dev` must use `dev_get_drvdata(dev->parent)`; and `wcd939x_typec_{mux,switch}_unregister` take `typec_{mux,switch}_dev *`. [F86, F207, F208, F330, F332, F477]
- In `pm4125`, `wcd9335`, `wcd934x`, and `wcd937x`, `*_get_channel_map()` callers may pass `NULL` for the unused direction's pointers, so playback DAIs must only validate/write `rx_num`/`rx_slot` and capture DAIs must only validate/write `tx_num`/`tx_slot`; `wcd934x_set_channel_map()` must reject `tx_num > WCD934X_TX_MAX` or `rx_num > WCD934X_RX_MAX`. [F39, F160, F189]
- In `wcd_mbhc`: `wcd_mbhc_start()` must assign `mbhc->cfg` and `mbhc->jack` before `wcd_mbhc_initialise()` and requires non-zero `cfg->micb_mv` whenever `hs_thr` or `hph_thr` is non-zero; `get_micbias_val` must store a positive millivolt value into `*mb` (used as a divisor); optional `mbhc_cb` callbacks must be null-checked and `fields[]` accessed only via `wcd_mbhc_read/write_field()`; and `set_btn_thr` implementations must guard `num_btn <= WCD_MBHC_DEF_BUTTONS` (8). [F18, F31, F59, F78, F79, F307]
- SoundWire `regmap_config` structures (`wcd939x`, `wsa881x`, `wsa883x`) must never set `.can_multi_write = true` because `regmap-sdw` misprograms multi-register writes. Cross-module headers (`wcd-mbhc-v2.h`, `pm4125.h`, `wcd937x.h`, `wcd938x.h`, `wcd939x.h`) must keep `#if IS_ENABLED(...)` declarations and `#else` static inline stubs in lockstep. [F54, F240, F301, F363]

## Error Handling

- Return-value conventions: `pm4125_sdw_device_get()`, `q6afe_find_port()`, `q6adm_find_*copp()`, and `platform_get_resource_byname()` return `NULL` on failure (never `IS_ERR()`), whereas `wcd_clsh_ctrl_alloc()`, `wcd_mbhc_init()`, `__audioreach_alloc_pkt()` / `audioreach_alloc_*_pkt()`, `q6afe_port_get_from_id()`, `q6adm_alloc_copp()`, `q6adm_open()`, and `devm_platform_ioremap_resource_byname()` return `ERR_PTR`. `wcd934x_mbhc_init()` must reset `wcd->mbhc = NULL` on `IS_ERR(wcd->mbhc)`, while `wcd93{8,9}x_mbhc_init()` must propagate `PTR_ERR()`. [F28, F153, F265, F397, F398, F401]
- Signedness and tri-state returns: `wcd_measure_adc_once()`, `wcd_get_micb_vout_ctl_val()`, and `wcd93{8,9}x_get_adc_mode()` return negative errnos on failure and must be stored in signed `int`s and checked `< 0`; `wcd_check_cross_conn()` returns `< 0` on error/active PA, `0` when not cross-connected, and `1` when cross-connected (test `< 0` separately from `> 0`); and `q6adm_apr_send_copp_pkt()` / `q6adm_matrix_map()` return positive remaining jiffies on success, so callers must test `ret < 0` rather than `if (ret)`. [F29, F268, F269, F399]
- In `qcom_snd_wcd_jack_setup()`, `qcom_snd_dp_jack_setup()`, `apq8016_dai_init()`, and `msm_snd_hw_params()`, `-ENOTSUPP` from `snd_soc_component_set_jack()`, `snd_soc_component_set_sysclk()`, or `snd_soc_dai_get/set_channel_map()` must be treated as success. In `lpass-cdc-dma.c`, `__lpass_get_dmactl_handle()` leaves `*dmactl` unmodified on unknown `dai_id`, so callers must initialize `dmactl = NULL` and check `if (!dmactl)`. [F400, F409]

## External Contracts

- In `audioreach.c`: `audioreach_alloc_{apm_}cmd_pkt()` includes `GPR_HDR_SIZE + APM_CMD_HDR_SIZE` while `audioreach_alloc_{apm_}pkt()` includes only `GPR_HDR_SIZE`; compound APM payloads must `ALIGN(..., 8)` each parameter section and set `param_data->param_size` to aligned size minus `APM_MODULE_PARAM_DATA_SIZE`; `audioreach_map_memory_regions()` must `ALIGN(buf_sz, 4096)` and split `ab->phys` via `lower/upper_32_bits()`; and `audioreach_mfc_set_media_format()` must copy `u8 channel_map[]` into `uint16_t channel_mapping[]` element-by-element (never `memcpy`). [F441, F442, F443, F476]

## Known Pitfalls

- `snd_soc_component_write_field()` and `wcd_mbhc_write_field()` shift `val` left by `__ffs(mask)` and require unshifted field values (such as `WCD937X_MICB_ENABLE`, `ldo_ctl`, `wcd939x_set_swr_clk_rate`), whereas `snd_soc_component_update_bits()` and `regmap_update_bits()` require pre-shifted values (such as `zdet_param->btn5/6/7`, `wcd938x_set_swr_clk_rate`, `wsa881x_put_pa_gain`). [F80, F163, F281]
- In `wcd9335`, `wcd934x`, and `msm8916-wcd-digital`, DAPM widget handlers parse `w->name` directly: `*_codec_enable_dec` copies 15 bytes, splits on the first space with `strsep()`, and passes `strpbrk(..., "012345678")` to `kstrtouint()`; `*_enable_dmic` passes `strpbrk(w->name, ...)` to `kstrtouint()` (so any digit in `name_prefix` or trailing non-digit breaks parsing); and `__wcd9335_codec_enable_micbias` uses `strnstr(w->name, "MIC BIAS1", sizeof("MIC BIAS1"))`, forbidding any prefix. [F88, F89, F90, F165]
- In `wcd_mbhc_initialise()` and `wcd_correct_swch_plug()`, which proceed when runtime PM returns `-EACCES` and unconditionally call `pm_runtime_put_autosuspend()` on exit, runtime PM must be acquired with `pm_runtime_get_sync()` (and `pm_runtime_put_noidle()` on `ret < 0 && ret != -EACCES`), never `pm_runtime_resume_and_get()`. [F94]
- In `wcd93{4,7,8,9}x_mbhc_get_result_params()`, `denom = (x1 * d1) - (1 << (14 - noff))` must be evaluated as a signed 32-bit integer and checked for `denom > 0` before dividing (floating impedances rely on `denom <= 0`), and ramp polling loops must be bounded by `*_ZDET_NUM_MEASUREMENTS`. Before calling `*_wcd_mbhc_qfuse_cal()`, ramp impedance must be converted from milliohms to ohms (`/ 1000`), and in `wcd93{8,9}x_wcd_mbhc_qfuse_cal()` EFUSE byte `q1` is sign-magnitude where `BIT(7)` selects subtraction and `q1 & 0x7F` is the magnitude. [F200, F201, F226, F310, F317, F323]
- In `lpass-platform.c` and `lpass-cdc-dma.c`, `regmap_fields_write()` on WRDMA (`*wr_dmactl`) must use 0-based `dma_ch - v->*wrdma_channel_start` from `__lpass_get_id()` / `__lpass_get_dmactl_handle()`, whereas `LPAIF_DMA*_REG`, `LPAIF_IRQ_ALL()`, and `drvdata->*substream[]` use raw `dma_ch`. In `lpass-cpu.c`, `lpass_data` per-port arrays (`mi2s_*`, `LPASS_MAX_PORTS >= DISPLAY_PORT_RX_7 + 1`) are indexed by `variant->dai_driver[i].id` (`dai_driver` must be non-const writable), while `dai_*_clk_names` use loop index `i`. [F421, F435, F436, F520]
- In `q6afe-dai.c`, `dai->id & 0x1` distinguishes TX (odd) from RX (even) only for SLIMbus and TDM DAI IDs; Codec DMA, MI2S, and DisplayPort DAI IDs do not follow even/odd parity and must use explicit case labels. In `audioreach.c`, `struct audioreach_module_priv_data` fields (like `module->data->size`) are `__le32` from topology binaries and must be converted with `le32_to_cpu()`. [F440, F459]
