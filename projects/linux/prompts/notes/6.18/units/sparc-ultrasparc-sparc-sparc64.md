# SPARC + UltraSPARC (sparc/sparc64)

This component implements core SPARC and UltraSPARC (`sparc32`/`sparc64`) architecture services, including Sun4v Machine Description (MDESC) DAG parsing and hotplug notification, OpenBoot PROM (OBP) device tree building and address/IRQ translation, OF platform device instantiation, PCI host bridge/PBM controller drivers (Psycho, Sabre, Schizo/Tomatillo, Fire, Sun4v virtual PCI/IOMMU/ATU, and 32-bit PCIC), MSI queue handling, performance counter (PCR) and pseudo-NMI watchdog support, ELF module relocation/patching, and 32/64-bit process and thread lifecycle management.

## Architecture & Data Flow

- In `pci_sun4v.c`, each CPU's `iommu_batch.pglist` holds `PGLIST_NENTS` (`PAGE_SIZE / sizeof(u64)`) entries, so `iommu_batch_add()` must call `iommu_batch_flush()` when `p->npages == PGLIST_NENTS`. `iommu_batch_flush()` must advance `p->entry` by the pages mapped, reset `p->npages = 0`, and when `vpci_major < 2` mask protection flags to `HV_PCI_MAP_ATTR_READ | HV_PCI_MAP_ATTR_WRITE`. In `dma_4v_map_page()` and `dma_4v_unmap_page()`, `npages` must be computed as `(IO_PAGE_ALIGN(addr + sz) - (addr & IO_PAGE_MASK)) >> IO_PAGE_SHIFT` before masking `addr` to `IO_PAGE_MASK`. [F61, F84, F118, F136]
- In `pci_sun4v_pbm_init()`, `pci_sun4v_atu_init()` must run after `pci_sun4v_scan_bus()` because `pci_sun4v_atu_alloc_iotsb()` calls `dma_4v_iotsb_bind()` to iterate over `pbm->pci_bus->devices`. [F131]
- In `pci_msi.c`, hardware MSI numbers and queue IDs are offset by `pbm->msi_first` and `pbm->msiq_first`, whereas `pbm->msi_bitmap`, `pbm->msi_irq_table`, and `pbm->msiq_irq_cookies` are 0-based, so all accesses must subtract (or add) `msi_first` or `msiq_first`. `sparc64_teardown_msi_irq()` must clear `pbm->msi_irq_table[i]` to `~0U` and succeed in `pbm->msi_ops->msi_teardown()` before calling `free_msi()`. `unsigned long *` bitmaps (`pbm->msi_bitmap` and `iommu->tbl.map`) must round byte sizes up to `sizeof(unsigned long)`. [F60, F82, F127]
- When a `struct dev_archdata` field (`iommu`, `stc`, `host_controller`, `numa_node`) is added or initialized for PCI devices, `pci_init_dev_archdata()`, `of_create_pci_dev()`, `of_propagate_archdata()`, and `pcibios_device_add()` (for SR-IOV VFs) must all propagate it in lockstep. [F75]
- Controller error handlers `psycho_ue_intr()` and `schizo_check_iommu_error()` must check both `pbm` and `pbm->sibling`. On Tomatillo (`PBM_CHIP_TYPE_TOMATILLO`), `pbm->stc.strbuf_enabled` is 0 and `pbm->stc` pointers are uninitialized, so `pbm->stc.strbuf_enabled` must be checked before calling `__schizo_check_stc_error_pbm()`. In `__schizo_check_stc_error_pbm()` and `psycho_check_stc_error()`, while in diagnostic mode (`*_STRBUF_CTRL_DENAB`) under `stc_buf_lock`, all 128 error entries and all 16 tag/line entries must be zeroed before restoring `strbuf_control`. [F52, F67, F143]
- On sun4v (`tlb_type == hypervisor`), `pci_determine_mem_io_space()` and 64-bit `build_device_resources()` must clear the top 4 bits of translated root physical addresses (`parent_phys_hi &= 0x0fffffff` and `result &= 0x0fffffffffffffffUL`). On 32-bit `build_device_resources()` (`of_device_32.c`), the 64-bit `result` from `of_read_addr()` must store `result & 0xffffffff` in `r->start` and OR `(result >> 32ULL) & 0xffUL` into `r->flags`. [F110, F111]
- In `of_device_32.c` and `of_device_64.c`, `of_bus_pci_match()` must return `0` when a PCI node lacks `"ranges"` (or has model `"SUNW,simba"` on 64-bit) so `of_match_bus()` does not select `of_bus_pci_map()`. In `of_device_64.c`, `build_device_resources()` and `scan_one_device()` must clamp `num_reg` to `PROMREG_MAX` and `num_irqs` to `PROMINTR_MAX`, and resource/IRQ accessors must reject indices `>=` those counts. [F87, F92]
- In `mdesc_memblock_alloc()` and `mdesc_kmalloc()`, `handle_size` is `sizeof(struct mdesc_handle) - sizeof(struct mdesc_hdr) + mdesc_size`. `mdesc_handle_init()` asserts `&hp->mdesc` is 16-byte aligned, so `mdesc_kmalloc()` must over-allocate by 15 bytes, align `hp` up to 16 bytes, and save the unaligned base in `hp->self_base` for `mdesc_kfree()`. Both `mdesc_memblock_free()` and `mdesc_kfree()` enforce `BUG_ON(refcount_read(&hp->refcnt) != 0)` and `BUG_ON(!list_empty(&hp->list))`. [F2, F79, F121]
- In `record_one_cpu()` (`prom_64.c`), `set_cpu_possible(cpuid, true)` must be guarded by `num_possible_cpus() < nr_cpu_ids` rather than `cpuid < nr_cpu_ids` because OF CPU IDs can be sparse. When `!CONFIG_SMP`, `fill_in_one_cpu()` (`mdesc.c`, `prom_64.c`) must skip `cpuid != real_hard_smp_processor_id()` and reset `cpuid = 0` before indexing `cpu_data(cpuid)` or `trap_block[cpuid]`. [F77, F78]
- In `nmi.c`, `nmi_active` is `> 0` for active CPUs, `0` when disabled, and `-1` when permanently unusable (`nmi_init()`/`check_nmi_watchdog()` failure paths must set `-1`). Every transition of per-CPU `wd_enabled` between 0 and 1 in `start_nmi_watchdog()`, `stop_nmi_watchdog()`, and `report_broken_nmi()` must be paired with an atomic increment/decrement of `nmi_active`. In `pcr.c`, `register_perf_hsvc()` and `setup_sun4v_pcr_ops()` must handle the exact same `sun4v_chip_type` values. [F54, F59, F74]
- In `process_64.c`, `t->reg_window[]`, `t->rwbuf_stkptrs[]`, and `wsaved` must update in lockstep via `shift_window_buffer()` in `synchronize_user_stack()`, and `fault_in_user_windows()` must set `wsaved = window + 1` on `copy_to_user()` failure. In `copy_thread()` and `clone_stackframe()`, 32-bit compat stack/frame pointers (`sp`, `regs->u_regs[UREG_FP]`, `fp + STACK_BIAS`) must be masked with `0xffffffffUL` when `TIF_32BIT` is set. [F65, F108]

## Synchronization

- In `mdesc.c`, `mdesc_mutex` must be held across `client_list` registration and `client->add` calls in `mdesc_register_notifier()`, and across `mdesc_update()`. `mdesc_lock` (`spin_lock_irqsave()`) protects `cur_mdesc`, `hp->refcnt`, and `mdesc_zombie_list`, and must be dropped in `mdesc_update()` before calling `mdesc_notify_clients(orig_hp, hp)` (which allocates with `GFP_KERNEL`), keeping `orig_hp->refcnt` pinned until `mdesc_notify_clients()` returns. [F19, F20, F152]
- In `pci_sun4v.c`, `per_cpu(iommu_batch, i).pglist` must be allocated for all possible CPUs in `pci_sun4v_probe()` before `pci_sun4v_pbm_init()` scans the bus, and local IRQs must be disabled via `local_irq_save()` across the entire `iommu_batch` lifecycle (`iommu_batch_start()` through `iommu_batch_end()`). [F22, F23]
- In `nmi.c`, `perfctr_irq()` runs at PIL 15 (above PIL 14 IRQ-off), so it must execute inside `nmi_enter()`/`nmi_exit()` on the hardirq stack and defer work requiring IRQ-safe locks to `deferred_pcr_work_irq()` via `arch_irq_work_raise()`. `stop_nmi_watchdog()` must clear per-CPU `wd_enabled` in addition to `pcr_ops->pcr_nmi_disable`, because `perfctr_irq()` re-enables PCR NMI whenever `__this_cpu_read(wd_enabled)` is non-zero. [F30, F150]
- In `pcr_arch_init()` (`pcr.c`), `register_perf_hsvc()` and `pcr_ops` setup must complete before `nmi_init()`. `nmi_init_done` is set only at the end of `nmi_init()`, and `watchdog_hardlockup_enable()` must check `atomic_read(&nmi_active) != -1` and `nmi_init_done` before calling `start_nmi_watchdog()`. [F28, F29]
- In `process_64.c`, `arch_trigger_cpumask_backtrace()` and `pmu_snapshot_all_cpus()` must hold `global_cpu_snapshot_lock` via `spin_lock_irqsave()` and zero `global_cpu_snapshot` before cross-calls, and `__global_reg_self()` must write `rp->thread = tp` last because `__global_reg_poll()` polls `gp->thread`. In `arch_cpu_idle()` on sun4v, `PSTATE_IE` must be cleared across `need_resched()`/`cpu_is_offline()` and `sun4v_cpu_yield()`, calling `scheduler_poke()` before restoring `PSTATE_IE`. [F26, F104, F148]
- In `psycho_scan_bus()`, `sabre_scan_bus()`, and `schizo_scan_bus()`, `pbm->pci_bus` must be set by `pci_scan_one_pbm()` before registering error handlers. In `schizo_check_iommu_error_pbm()`, `spin_lock_irqsave(&iommu->lock, flags)` must be acquired outside `spin_lock(&stc_buf_lock)`. In `of_set_property()` (`prom_common.c`), `kmemdup(val, len, GFP_KERNEL)` must run before locking, and `of_set_property_mutex` must be acquired outside `raw_spin_lock_irqsave(&devtree_lock, flags)`. [F32, F154, F157]

## Object Lifetimes

- Pointers from `mdesc_get_property()` and `mdesc_node_name()` point into `struct mdesc_handle` and are only valid between `mdesc_grab()` and `mdesc_release()`. `mdesc_open()` must store `mdesc_grab()` in `file->private_data` and `mdesc_close()` must call `mdesc_release()`. When `mdesc_update()` replaces `cur_mdesc`, `orig_hp` is freed via `mdesc_free()` only if `refcount_dec_and_test(&orig_hp->refcnt)` succeeds under `mdesc_lock`; otherwise it is queued on `mdesc_zombie_list` for `mdesc_release()`. [F1, F135, F170]
- When `pci_sun4v_atu_init(pbm)` fails in `pci_sun4v_pbm_init()`, `pbm->iommu->atu` must be freed with `kfree()` and reset to `NULL`, and all DMA paths selecting `iommu->atu` for a mask above `DMA_BIT_MASK(32)` must check `iommu_use_atu(iommu, mask)` (`iommu->atu && mask > DMA_BIT_MASK(32)`). [F9, F37]
- In `pci_psycho.c`, sibling `pci_pbm_info` instances share a single `struct iommu`, so `psycho_probe()` must allocate, initialize, and `kfree(pbm->iommu)` on error only when `!pbm->sibling`, whereas in `pci_schizo.c` each PBM owns a separate `struct iommu`. [F66]
- In 64-bit `copy_thread()` (`process_64.c`), `t->utraps[0]` must only be incremented after fallible steps (`clone_stackframe()`) succeed, and `exit_thread()` must decrement `t->utraps[0]` when `>= 2` and `kfree(t->utraps)` only when `< 2`. On 32-bit `!CONFIG_SMP` (`process_32.c`), `exit_thread()` and `flush_thread()` must clear `last_task_used_math = NULL` when saving FPU state. In `of_set_property()`, `kfree(old_val)` is called only if `OF_IS_DYNAMIC(prop)` is true, followed by `OF_MARK_DYNAMIC(prop)`. [F16, F17, F71]

## API Contracts

- On 64-bit SPARC (`of_device_64.c`), `of_ioremap()` reserves regions via `request_mem_region()` or `request_region()` according to `res->flags & IORESOURCE_MEM`, so callers must unmap via `of_iounmap()` with matching `struct resource *` and `size` rather than `iounmap()`. [F6]
- In `pci_sun4v.c`, `pci_sun4v_iommu_map()` returns a signed `long` (page count or `< 0` negated HV status), whereas `pci_sun4v_iotsb_map()` returns an unsigned status (`HV_EOK` on success) and writes the mapped count to `*mapped`. `iommu_tbl_range_alloc()` returns `IOMMU_ERROR_CODE` (`~(unsigned long)0`) on failure (since `0` is a valid index), and passing `IOMMU_ERROR_CODE` to `iommu_tbl_range_free()` derives the index from `dma_addr`. [F39, F40]
- In `pci_sun4v.c`, DMA unmap/free paths (`dma_4v_free_coherent()`, `dma_4v_unmap_page()`, `dma_4v_unmap_sg()`, `dma_4v_iommu_demap()`) must choose between `&iommu->tbl` and `&atu->tbl` by testing whether the mapped DMA address exceeds `DMA_BIT_MASK(32)` rather than reading `dev->dma_mask`. When `dma_4v_map_sg()` merges segments (`outcount < incount`), it must set `sg_next(outs)->dma_length = 0`. [F176, F177]
- `sparc64_msiq_ops.msiq_build_irq` must convert a `0` return from `sun4v_build_irq()` or `build_irq()` into `-ENOMEM`. `sparc64_msiq_ops.dequeue_msi` must return `0` when the entry at `*head` has a zero type field, `< 0` on error, and on a valid entry clear the type field, advance `*head` modulo queue size (as a byte offset in `pci_sun4v_dequeue_msi()` or an entry index in `pci_fire_dequeue_msi()`), and return `1`. On Fire (`fire_irq_build()`, `pci_fire_msiq_build_irq()`), `inofixup` passed to `build_irq()` must be `((portid << 6) | ino) - int_ctrlr`. [F42, F45, F57, F103, F123]
- When fetching MDESC via `sun4v_mach_desc(__pa(&hp->mdesc), len, &real_len)`, `&hp->mdesc` must be 16-byte aligned and the caller must check both `status == HV_EOK` and `real_len <= len`. MDESC node accessors must reject `node == MDESC_NODE_NULL || node >= hp->mdesc.node_sz / 16`. [F48, F80]
- In 64-bit `clone_stackframe()` (`process_64.c`), when `test_thread_64bit_stack(psp)` is true, `STACK_BIAS` (`2047`) must be subtracted from `rval` only on the success branch so `0` is returned on fault. `pcr_ops` is `NULL` when `pcr_arch_init()` fails (e.g., Spitfire), and `pcr_ops->read_pcr/pic(reg_num)` only accept `reg_num != 0` on Niagara4+ (`sun4v_chip_type >= SUN4V_CHIP_NIAGARA4`). [F50, F55]

## Error Handling

- In `dma_4v_alloc_coherent()`, `dma_4v_map_page()`, and `dma_4v_map_sg()` (`pci_sun4v.c`), failure after `local_irq_save(flags)` and `iommu_tbl_range_alloc()` must call `local_irq_restore(flags)` and `iommu_tbl_range_free()`, using ratelimited logging. `dma_4v_map_sg()` must check `dev->archdata.iommu` is non-NULL (and `nelems != 0`) before dereferencing `iommu->atu`, and must initialize `outs->dma_length = 0` before each segment and set it only after allocation and batching succeed so rollback only frees entries with `s->dma_length != 0`. [F7, F8, F38, F178]
- In `sparc64_setup_msi_irq()`, failure after `irq_alloc()` and `alloc_msi()` must call `free_msi(pbm, msi)`, `irq_set_chip(*irq_p, NULL)`, `irq_free(*irq_p)`, and reset `*irq_p = 0`. In `sparc64_pbm_msi_init()`, failure in any allocation or queue bringup step must unwind prior allocations, reset `pbm->msiq_num = 0`, and leave `pbm->setup_msi_irq = NULL`. [F10, F133]
- Because `copy_thread()` overwrites the parent's `regs->u_regs[UREG_I1]` (`%o1`) with 0, `sparc_fork()`, `sparc_vfork()`, and `sparc_clone()` must save `regs->u_regs[UREG_I1]` before `kernel_clone()` and restore it whenever `(unsigned long)ret >= -ERESTART_RESTARTBLOCK`. [F15]
- In `scan_one_device()` (`of_device_64.c`, `of_device_32.c`), if `of_device_register(op)` fails after `dev_set_name(&op->dev, ...)`, it must call `put_device(&op->dev)` before `kfree(op)`. In `pcr_arch_init()`, failure after `register_perf_hsvc()` must call `unregister_perf_hsvc()`. In `mdesc.c`, `md_node_ops.rel_info` callbacks must reset freed pointers in `union md_node_info` to `NULL`. [F5, F14, F47]

## Known Pitfalls

- In `apply_relocate_add()` (`module.c`), the relocation switch must mask `ELF_R_TYPE(rel[i].r_info)` with `& 0xff` because 64-bit `R_SPARC_OLO10` packs a secondary addend in the upper 24 bits. `R_SPARC_32`/`UA32` and `R_SPARC_64`/`UA64` must be written byte-by-byte through `u8 *location`, and on `CONFIG_SPARC64` `((u64)location >> 32)` must be 0. [F85, F95]
- In `pci_parse_of_flags()`, `if (addr0 & 0x02000000)` must precede `else if (addr0 & 0x01000000)` because 64-bit PCI memory space encodes `0x03000000` (which must also populate `pbm->mem64_space` and set `IORESOURCE_MEM_64 | PCI_BASE_ADDRESS_MEM_TYPE_64`). In `of_scan_pci_bridge()`, 8-cell OF `ranges` entries with `size >> 32 == 0xffffffff` must be skipped to avoid overflowing `region.start + size - 1`. [F90, F93, F139]
- In `mdesc_for_each_arc(arc, hdl, node, type)`, `arc` holds the `struct mdesc_elem` index from `mdesc_next_arc()` and must never be overwritten with `mdesc_arc_target(hdl, arc)`. `node` and `arc` index `node_block(&hp->mdesc)` in 16-byte `struct mdesc_elem` units, whereas `node_sz`, `name_sz`, `name_offset`, and `data_offset` are byte offsets. [F102, F122]
- In `build_device_resources()` (`of_device_32.c`, `of_device_64.c`), each upward translation step must call `of_match_bus(pp)`, `pbus->count_cells(dp, ...)`, and `build_one_resource(dp, dbus, pbus, ...)` before updating `dna = pna; dns = pns; dbus = pbus;`. In `build_one_device_irq()`, `ip->irq_trans->irq_build()` must be passed `op->dev.of_node` rather than `dp` or `ip`. [F105, F106]
- In `copy_thread()` (`process_32.c`, `process_64.c`), `args->flags` from `struct kernel_clone_args` must be stored in a `u64` (`clone_flags`) rather than `unsigned long` so upper 32-bit clone flags are not truncated on 32-bit SPARC. [F107]
