# HWPOISON MEMORY FAILURE HANDLING

This unit (`mm/memory-failure.c` and `mm/hwpoison-inject.c`) implements hardware memory failure (hwpoison) recovery, page soft-offlining, software unpoisoning, and debugfs fault injection. It isolates corrupted or suspicious pages from the buddy allocator, LRU lists, swap cache, or page cache, unmaps affected user-space PTEs, and signals mapped processes with `SIGBUS` (`BUS_MCEERR_AR` or `BUS_MCEERR_AO`), including specialized handling for Hugetlb folios, THPs, KSM pages, and `ZONE_DEVICE` (fsdax/devdax) pages.

## Architecture & Data Flow

- In `has_extra_refcount()`, when `extra_pins` is true (folio remains in page/swap cache), decrement `count` by `folio_nr_pages(page_folio(p))` rather than 1, besides subtracting 1 for `memory_failure()`'s reference. [F11]
- `unmap_poisoned_folio()` must clear `TTU_HWPOISON` from `ttu` when `folio_test_swapcache(folio)` is true, or when `!must_kill && !folio_test_dirty(folio) && mapping && mapping_can_writeback(mapping)` and `folio_mkclean(folio)` returns 0, so `try_to_unmap()` does not install hwpoison swap entries. [F62]
- `folio_clear_hugetlb_hwpoison()` and `folio_free_raw_hwp(folio, true)` must not clear `PG_hwpoison` or free the `raw_hwp_page` list while `folio_test_hugetlb_vmemmap_optimized(folio)` is true. If `kmalloc()` fails in `folio_set_hugetlb_hwpoison()`, set `folio_set_hugetlb_raw_hwp_unreliable(folio)` and call `__folio_free_raw_hwp(folio, false)`, after which `folio_free_raw_hwp()` and `folio_clear_hugetlb_hwpoison()` must refuse to unpoison. [F48, F49]
- In `action_result()`, call `num_poisoned_pages_inc()` and `update_per_node_mf_stats()` only when `type != MF_MSG_ALREADY_POISONED`. `folio_set_hugetlb_hwpoison()` only calls `num_poisoned_pages_inc()` when `ret != 0` (`action_result()` counts the first error), and `unpoison_memory()` skips `num_poisoned_pages_sub()` when `huge` is true (`__folio_free_raw_hwp()` decrements per node). [F12, F46]
- In `try_memory_failure_hugetlb()`, if `hwpoison_filter(p)` rejects a page after `get_huge_page_for_hwpoison()`, call `folio_clear_hugetlb_hwpoison(folio)` and, if `migratable_cleared` is true, restore `folio_set_hugetlb_migratable(folio)` before unlocking and putting `folio`. [F52]
- In `__get_huge_page_for_hwpoison()`, when `ret = -EBUSY` on the final pass (`flags & MF_NO_RETRY`), still call `folio_set_hugetlb_hwpoison(folio, page)` before returning so `PG_hwpoison` is set for `action_result()`. [F53]
- Because `take_page_off_buddy()` sets `SetPageHWPoisonTakenOff(page)`, `__get_unpoison_page()` must check `PageHWPoisonTakenOff(page)` before `get_page_unless_zero(page)` and return `-EHWPOISON` so `unpoison_memory()` calls `put_page_back_buddy(p)`. [F54]
- `HWPoisonHandlable()` must reject `PageSlab(page)` first and include both `PageLRU(page)` and `is_free_buddy_page(page)` so `__get_hwpoison_page()` returns `-EBUSY` for slab pages and `0` for free buddy pages. [F74]
- In `delete_from_lru_cache()`, when `folio_isolate_lru(folio)` succeeds, call `folio_clear_active(folio)`, `folio_clear_unevictable(folio)`, and `mem_cgroup_uncharge(folio)` before `folio_put(folio)` because a poisoned folio may never reach refcount 0. [F55]
- In `memory_failure()`, once a large folio (`folio_test_large(folio)`) is pinned and passes `hwpoison_filter()`, set `folio_set_has_hwpoisoned(folio)` before `try_to_split_thp_page(p, false)` and do not clear it if splitting fails. [F60]
- When `memory_failure()` runs without `MF_SW_SIMULATED`, it latches `hw_memory_failure = true` under `mf_mutex`; `unpoison_memory()` must fail with `-EOPNOTSUPP` when `hw_memory_failure` is true (under `mf_mutex`) or when `is_huge_zero_folio(folio)` is true (before touching `PageHWPoison(p)` or refcounts). [F51, F75]
- In `error_states[]`, specific flag masks (`PG_reserved`, `PG_head`, `PG_swapcache`, `PG_mlocked`, `PG_unevictable`) must precede general `PG_lru` entries, and `{ 0, 0, MF_MSG_UNKNOWN, me_unknown }` must be last. [F72]
- Every `enum mf_result` and `enum mf_action_page_type` passed to `action_result()` needs entries in `action_name[]`, `action_page_types[]`, and `update_per_node_mf_stats()` (which must verify `nid >= 0 && nid < MAX_NUMNODES` on `pfn_to_nid(pfn)` before indexing `NODE_DATA(nid)->mf_stats`). [F63, F68]

## Synchronization

- In `__page_handle_poison()`, never hold `zone_pcp_disable()` across `dissolve_free_hugetlb_folio()`: `zone_pcp_disable()` holds `pcp_batch_high_lock` while `dissolve_free_hugetlb_folio()` may take `cpu_hotplug_lock`, causing a deadlock. [F18]
- In `__get_hwpoison_page()` and `__get_unpoison_page()`, after `get_hwpoison_hugetlb_folio(folio, &hugetlb, ...)` sets `hugetlb == true`, revalidate `folio == page_folio(page)` and call `folio_put(folio)` if `ret > 0` on mismatch. For non-hugetlb pages in `__get_hwpoison_page()`, check `HWPoisonHandlable(&folio->page, flags)` before `folio_try_get(folio)`, then revalidate `folio == page_folio(page)` (putting `folio` on mismatch). [F22, F23]
- In `__get_huge_page_for_hwpoison()`, resolving `page_folio()`, testing `folio_test_hugetlb()`, pinning the folio, and calling `folio_set_hugetlb_hwpoison()` (using `GFP_ATOMIC`) must all run under a single `hugetlb_lock` critical section. [F27]
- In `unmap_poisoned_folio()`, take `hugetlb_folio_mapping_lock_write(folio)` and pass `TTU_RMAP_LOCKED` to `try_to_unmap()` on a shared (`!folio_test_anon(folio)`) hugetlb folio, and never on anonymous hugetlb folios. [F24]
- DAX pages do not use the folio lock: `mf_generic_kill_procs()` must hold `dax_lock_folio(folio)` and `mf_dax_kill_procs()` must hold `dax_lock_mapping_entry(mapping, index, &page)` across `SetPageHWPoison()`, process collection, and `unmap_and_kill()`, and pass the returned non-zero `cookie` to `dax_unlock_folio()` / `dax_unlock_mapping_entry()` on every exit path (even if `page == NULL` or `hwpoison_filter()` fails). [F13, F26]
- In `collect_procs_anon()`, `collect_procs_file()`, and `collect_procs_fsdax()`, acquire `folio_lock_anon_vma_read()` or `i_mmap_lock_read()` outside `rcu_read_lock()`. Hold `rcu_read_lock()` across all `task_early_kill()` and `find_early_kill_thread()` iterations, and use `GFP_ATOMIC` in `__add_to_kill()`. [F20, F100]
- Evaluate `hwpoison_filter(p)` under `folio_lock(folio)` in `memory_failure()` and `try_memory_failure_hugetlb()` (and under `dax_lock_folio(folio)` in `mf_generic_kill_procs()`), and hold `mf_mutex` when traversing `raw_hwp_list_head(folio)` in `is_raw_hwpoison_page_in_hugepage()`. [F28, F30]
- Protect `mf_cpu->fifo` in `memory_failure_queue()` and `memory_failure_work_func()` with `raw_spin_lock_irqsave(&mf_cpu->lock, proc_flags)`, releasing it before calling `soft_offline_page()` or `memory_failure()`. [F32]
- `hwpoison_filter_func` must be published via `rcu_assign_pointer()`, read via `rcu_dereference()` under `rcu_read_lock()`, and cleared via `RCU_INIT_POINTER(..., NULL)` plus `synchronize_rcu()` in `hwpoison_filter_unregister()` (along with `debugfs_remove_recursive(hwpoison_dir)` in `pfn_inject_exit()`). [F17, F19]
- Release PTE mappings with `pte_unmap_unlock(mapped_pte, ptl)` before `cond_resched()` or returning in `hwpoison_pte_range()` (and pair `pte_offset_map()` with `pte_unmap()` in `dev_pagemap_mapping_shift()`), and hold `mmap_read_lock(p->mm)` across `walk_page_range()` in `kill_accessing_process()`. [F108, F109]

## Object Lifetimes

- When `MF_COUNT_INCREASED` is set, `memory_failure()` and `soft_offline_page()` own the caller's page reference and must call `put_ref_page(pfn, flags)` or `put_page()` on every early return before `get_hwpoison_page()`. In `soft_offline_page()`, `get_hwpoison_page()` consumes `MF_COUNT_INCREASED` when `ret <= 0`, so later error paths only call `put_page(page)` if `ret > 0`, and `retry` must clear `MF_COUNT_INCREASED`. [F1, F2]
- `soft_offline_in_use_page()` consumes the caller's folio reference across all paths (`try_to_split_thp_page(page, true)` on split failure, `folio_put(folio)` if already poisoned or right after `isolate_folio_to_list()`, or `page_handle_poison(page, false, true)` on invalidation). [F3]
- In `__get_huge_page_for_hwpoison()`, if `count_increased` is set, jumping to `out` on `-EHWPOISON` must call `folio_put(folio)`, while the non-hugetlb exit (`ret = 2`) must leave `MF_COUNT_INCREASED` intact. [F5]
- In `unpoison_memory()`, when `get_hwpoison_page(p, MF_UNPOISON)` returns `ghp > 0`, release its extra reference with `folio_put(folio)` both when `folio_free_raw_hwp(folio, false)` returns `0` and before dropping the poison reference under `TestClearPageHWPoison(p)`. [F6]
- `memory_failure_dev_pagemap()` owns the `pgmap` reference from `get_dev_pagemap(pfn)` and must call `put_dev_pagemap(pgmap)` on all exit paths. [F8]
- Every `struct to_kill` node added by `__add_to_kill()` holds `get_task_struct(tk->tsk)` and must be cleaned up by `kill_procs()` (even when `forcekill` is 0), which must use `list_for_each_entry_safe()`, `list_del(&tk->nd)`, `put_task_struct(tk->tsk)`, and `kfree(tk)`. [F9, F77]

## API Contracts

- Every `struct page_state` `.action` callback (`me_*`) is entered with `p`'s folio locked and must unlock it before returning; callers of `identify_page_state()` must not unlock afterward. [F7]
- `__get_huge_page_for_hwpoison()` returns `2` for non-hugetlb, `1` for in-use hugepage, `0` for free hugepage, `-EBUSY`, or `-EHWPOISON`. In `try_memory_failure_hugetlb()`, initialize `bool migratable_cleared = false` before `get_huge_page_for_hwpoison()`, and when it returns `2`, set `*hugetlb = 0` and return `0`. [F35, F44]
- `__add_to_kill()` and `kill_procs()` use `addr == -EFAULT` as a sentinel for `SIGKILL`: `add_to_kill_anon_file()` must drop `-EFAULT` entries, `dev_pagemap_mapping_shift()` must never be called with `-EFAULT`, `__add_to_kill()` must check `tk->addr == -EFAULT` before `else if (tk->size_shift == 0)`, and `unmap_and_kill()` must guard `1UL << tk->size_shift` with `if (tk->size_shift)`. [F43, F76, F85]
- `memory_failure_dev_pagemap()` must verify `pgmap_pfn_valid(pgmap, pfn)` before calling `pgmap->ops->memory_failure()` or `mf_generic_kill_procs()`, and only call `pgmap->ops->memory_failure()` if `pgmap_has_memory_failure(pgmap)` is true, falling back to `mf_generic_kill_procs()` if absent or returning `-EOPNOTSUPP`. [F66, F94]
- `unpoison_memory()` and `soft_offline_page()` must use `pfn_to_online_page(pfn)` (not `pfn_valid()` + `pfn_to_page()`) to reject offline or `ZONE_DEVICE` pages. `memory_failure()` requires process context with IRQs enabled and no spinlocks held (atomic callers must use `memory_failure_queue()`). [F65, F97]
- Callers of `unmap_poisoned_folio()` must split non-hugetlb large folios first. In `unmap_and_kill()`, cast `pgoff_t index` to `loff_t` before `<< PAGE_SHIFT` (`((loff_t)index << PAGE_SHIFT) & ~(size - 1)`) to avoid 32-bit overflow. [F84, F113, F115]
- `num_poisoned_pages_sub(pfn, i)` treats `pfn == -1UL` as a sentinel to skip `memblk_nr_poison_sub(pfn, i)` (`num_poisoned_pages_inc()` has no such guard). `hwpoison_walk_ops` must set `.test_walk = hwpoison_test_walk` returning `0` to scan `VM_PFNMAP` VMAs. [F45, F110]

## Error Handling

- `__page_handle_poison()` returns `1` only when the page is both dissolved and taken off buddy (`0` or `< 0` otherwise); callers must check `> 0` before calling `page_ref_inc(p)` and reporting `MF_RECOVERED`. [F33]
- In `unpoison_memory()`, initialize `ret = -EBUSY` and store `get_hwpoison_page(p, MF_UNPOISON)` in `ghp` so jumps to `unlock_mutex` do not return `1`, and log via ratelimited `unpoison_pr_info(..., &unpoison_rs)`. [F34, F127]
- In `soft_offline_in_use_page()`, store `migrate_pages()` in `long ret` and convert `ret > 0` to `-EBUSY` after `putback_movable_pages(&pagelist)`. In `soft_offline_page()`, if `get_hwpoison_page()` returns `0` and `page_handle_poison(page, true, false)` fails with `!try_again`, set `ret = -EBUSY`. [F36, F37]
- In `get_any_page()`, when retrying after `count_increased == true` fails `PageHuge(p) || HWPoisonHandlable(p, flags)`, call `put_page(p)`, `shake_page(p)`, and reset `count_increased = false`. On `ret == -EIO`, log with `pr_err()` rather than `dump_page(p)`. [F79, F126]
- Check `p->mm` / `tsk->mm` is non-NULL in `kill_accessing_process()` and `task_early_kill()`. In `kill_accessing_process()`, only call `kill_proc()` when `walk_page_range()` returns `ret == 1 && priv.tk.addr`, returning `ret > 0 ? -EHWPOISON : 0`. In `mf_dax_kill_procs()`, reset `page = NULL` each iteration and skip `SetPageHWPoison()` / `collect_procs_fsdax()` if `page == NULL`. [F38, F39, F42]

## External Contracts

- In `mm/hwpoison-inject.c`, `hwpoison_inject()` and `hwpoison_unpoison()` must check `capable(CAP_SYS_ADMIN)` and validate `pfn_valid(pfn)` before `pfn_to_page(pfn)`; `hwpoison_filter_dev_major` and `hwpoison_filter_dev_minor` use `~0U` as wildcard sentinels. [F71, F124]

## Known Pitfalls

- Before calling `folio_mapped(folio)` in `unpoison_memory()` or `hwpoison_user_mappings()`, exclude `folio_test_slab(folio)`, `folio_test_pgtable(folio)`, `folio_test_reserved(folio)`, and `folio_test_offline(folio)`. [F41]
- In `hwpoison_user_mappings()`, sample `mlocked = folio_test_mlocked(folio)` and call `collect_procs()` before `unmap_poisoned_folio()`, then evaluate `forcekill` and call `shake_folio(folio)` (if `mlocked`) after `unmap_poisoned_folio()`. Snapshot `page_flags = folio->flags.f` before `hwpoison_user_mappings()` so `identify_page_state()` can OR in live `p->flags.f & (1UL << PG_dirty)` and fall back to pre-unmap flags. [F58, F59, F73]
- In `collect_procs*()`, get `mapping` and `anon_vma` from `folio`, but pass the subpage `page` (not `&folio->page`) and the thread `t = task_early_kill(tsk, force_early)` (not `tsk`) to `page_pgoff()`, `page_mapped_in_vma()`, `page_address_in_vma()`, and `add_to_kill_anon_file()`. [F83, F116]
- Pass the subpage `p`/`page` to `try_to_split_thp_page()` and refresh `folio = page_folio(p)` on success; in `unpoison_memory()`, use `PageHWPoison(p)` / `TestClearPageHWPoison(p)` on `p` rather than `folio_test_hwpoison(folio)`. [F117, F118]
- In `memory_failure()`, do not skip `folio_wait_writeback(folio)` unless both `!folio_test_lru(folio)` and `!folio_test_writeback(folio)` hold, and before `goto try_again` on `take_page_off_buddy(p)` failure, call `ClearPageHWPoison(p)` and set `retry = false`. [F80, F120]
- Verify `pfn <= hwp->pfn && hwp->pfn < pfn + HPAGE_PMD_NR` before `(hwp->pfn - pfn) << PAGE_SHIFT` in `check_hwpoisoned_pmd_entry()`, pass `mapped_pte` (not `ptep`) to `pte_unmap_unlock()` in `hwpoison_pte_range()`, and pass `&page->flags.f` (a pointer) to `%pGp`. [F86, F87, F90]
