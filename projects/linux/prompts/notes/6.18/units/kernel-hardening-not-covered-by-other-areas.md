# KERNEL HARDENING (not covered by other areas)

This unit provides core kernel self-protection primitives and KUnit tests, covering hardened usercopy bounds validation (`mm/usercopy.c`, `include/linux/ucopysize.h`), kernel stack erasing/STACKLEAK (`kernel/kstack_erase.c`, `include/linux/kstack_erase.h`), per-syscall kernel stack offset randomization (`include/linux/randomize_kstack.h`), and type-safe overflow arithmetic and flexible-array sizing macros (`include/linux/overflow.h`), along with usercopy and structure layout randomization KUnit tests (`lib/tests/usercopy_kunit.c`, `lib/tests/randstruct_kunit.c`).

## Architecture & Data Flow

- In `mm/usercopy.c`, `check_bogus_address()` must test address-space wraparound using the inclusive end address `ptr + (n - 1) < ptr` rather than `ptr + n < ptr`, relying on `__check_object_size()` returning early when `n == 0` so `n - 1` cannot underflow. [F32]
- In `mm/usercopy.c`, `overlaps()` treats `[ptr, ptr + n)` and `[low, high)` as half-open intervals and must use non-strict comparisons (`check_low >= high || check_high <= low`) so regions immediately adjacent to `[_stext, _etext)` or its linear alias are not aborted as overlapping. [F33]
- In `check_kernel_text_object()`, when `lm_alias(_stext) != (unsigned long)_stext`, the secondary linear mapping `[lm_alias(_stext), lm_alias(_etext))` must be checked for overlap in addition to `[_stext, _etext)`. [F68]
- In `mm/usercopy.c`, `check_stack_object()` must first return `NOT_STACK` when `[obj, obj + len)` lies completely outside `[stack, stackend)` (`obj + len <= stack || stackend <= obj`) before rejecting `obj < stack || stackend < obj + len` as `BAD_STACK`, and must reject accesses beyond `current_stack_pointer`. [F34]
- In `mm/usercopy.c`, `check_heap_object()` must validate copy length `n` against the remaining bytes from `ptr` to the end of a kmap page, `vmap_area`, or large folio using subtraction (`n > PAGE_SIZE - offset`, `n > area->va_end - addr`, `n > folio_size(folio) - offset`) after confirming `ptr` lies within that region, avoiding unsigned addition overflow in `addr + n` or `offset + n`. [F35]
- `stackleak_task_low_bound(tsk)` must cast `end_of_stack(tsk)` to `unsigned long` before adding `sizeof(unsigned long)` to skip `STACK_END_MAGIC` by one word rather than scaling by `unsigned long *` stride; `stackleak_task_high_bound(tsk)` must stop at `task_pt_regs(tsk)`, and `CONFIG_KSTACK_ERASE_TRACK_MIN_SIZE` must not exceed `KSTACK_ERASE_SEARCH_DEPTH` (128 bytes). [F61, F81]
- `stackleak_task_init()` must reset `t->lowest_stack` to `stackleak_task_low_bound(t)` and, when `CONFIG_KSTACK_ERASE_METRICS` is enabled, `t->prev_lowest_stack` to `t->lowest_stack` so a newly forked task does not inherit its parent's stack pointers and poisons its full stack on first erase. [F27]
- In `__stackleak_erase()`, `erase_low` must be computed from `current->lowest_stack`, saved to `current->prev_lowest_stack`, and poisoned up to `erase_high` before `current->lowest_stack` is reset to `task_stack_high` for the next syscall. [F26]
- `stackleak_find_top_of_poison(low, high)` scans `[low, high)` downward in `sizeof(unsigned long)` steps with `while (sp > low && poison_count < depth)`, requiring `low` and `high` (including `current->lowest_stack`) to be `sizeof(unsigned long)`-aligned and `low <= high`; every non-poison word (`*(unsigned long *)sp != KSTACK_ERASE_POISON`) must reset `poison_count = 0` and update `poison_high = sp` after decrementing `sp`. [F38, F49]
- In `stack_erasing_sysctl()`, the static key `stack_erasing_bypass` has inverted polarity relative to `state`: enabling stack erasing (`state != 0`) must call `static_branch_disable(&stack_erasing_bypass)` and disabling it must call `static_branch_enable(&stack_erasing_bypass)`. [F48]
- `add_random_kstack_offset()` must use `__builtin_alloca_uninitialized` (when compiler-supported) via `__kstack_alloca` rather than `__builtin_alloca`, so `CONFIG_INIT_STACK_ALL` does not zero-initialize the padding or emit an implicit `memset()` call in `noinstr` syscall entry code. [F23]
- In `include/linux/randomize_kstack.h`, `KSTACK_OFFSET_MAX(x)` must cap the alloca size in `add_random_kstack_offset()` to 10 bits and clear the low word/stack alignment bits (`0b1111110000` on `CONFIG_64BIT`, `0b1111111100` on 32-bit). [F43]
- `choose_random_kstack_offset()` must rotate the existing per-CPU `kstack_offset` value via `ror32()` before XORing in `rand` so entropy diffuses across all 32 bits and into the bit range extracted by `KSTACK_OFFSET_MAX()`. [F86]
- In `check_shl_overflow(a, s, d)`, the value to shift must be widened to `unsigned long long` (`_a_full`) and the shift count clamped to `[0, 8 * sizeof(*d))` before shifting; the macro must reject negative inputs, negative results, out-of-range shift counts, and values where `(*_d >> _to_shift) != _a` (right-shifting `*_d` rather than `_a_full` so truncation into `*_d` is detected). [F50, F52]

## Synchronization

- In `check_heap_object()`, `find_vmap_area()` must only be called for `is_vmalloc_addr(ptr)` when `!pagefault_disabled()`, because `find_vmap_area()` acquires a spinlock that can deadlock in atomic usercopy contexts (such as `copy_from_user_nofault()` in NMI, kprobe, or BPF handlers). [F65]
- `__sanitizer_cov_stack_depth()` must not update `current->lowest_stack` when `current_stack_pointer` is below `stackleak_task_low_bound(current)` (such as when executing on a separate IRQ or exception stack located below the task stack). [F13]
- `add_random_kstack_offset()` and `choose_random_kstack_offset()` access the per-CPU `kstack_offset` variable via `raw_cpu_read()` and `raw_cpu_write()` without disabling preemption or interrupts, so callers must invoke them only during syscall entry/exit while interrupts and preemption are disabled. [F70]

## Object Lifetimes

- In `include/linux/overflow.h`, `__DEFINE_FLEX()` initializes the pointer `name` to the address of the local on-stack union `name##_u`, so `name` must not be returned or stored in any location that outlives the declaring lexical scope. [F59]
- In `lib/tests/usercopy_kunit.c`, kernel buffers and userspace mappings allocated in `usercopy_test_init()` and test cases must use KUnit-managed allocators (`kunit_kzalloc`, `kunit_kmalloc`, `kunit_vm_mmap`) so resources are automatically freed when a `KUNIT_ASSERT_*` aborts the test early. [F7]

## API Contracts

- `check_add_overflow()`, `check_sub_overflow()`, `check_mul_overflow()`, and `check_shl_overflow()` return `true` on overflow or invalid shift and `false` on success while always writing the attempted result to `*d`; callers must not use `*d` from `check_shl_overflow()` when it returns `true`. [F15]
- `size_mul()`, `size_add()`, and `size_sub()` saturate to `SIZE_MAX` on overflow, and `size_sub(minuend, subtrahend)` also returns `SIZE_MAX` if either operand equals `SIZE_MAX` (preventing saturated `SIZE_MAX` inputs from being subtracted into a small valid-looking size); callers must store results in a `size_t` lvalue to avoid implicit truncation of `SIZE_MAX`. [F16, F83]
- `range_overflows(start, size, max)` and `range_end_overflows(start, size, max)` take `(start, size, max)` where `max` is an exclusive upper bound on `[0, max)`; `range_overflows()` rejects `start == max` even when `size == 0`, whereas `range_end_overflows()` allows `start == max` with `size == 0`. [F25]
- In `include/linux/ucopysize.h`, `check_copy_size()` must validate compile-time object size via `__builtin_object_size(addr, 0)` and reject `bytes > INT_MAX` before calling `check_object_size(addr, bytes, is_source)`, and `check_object_size(ptr, n, to_user)` must skip `__check_object_size()` whenever `__builtin_constant_p(n)` is true. [F36, F79]
- When validating vmalloc-range addresses in `check_heap_object()`, `find_vmap_area()` must be used instead of `find_vm_area()` because `vm_map_ram()` mappings allocate a `struct vmap_area` without an associated `struct vm_struct`. [F66]
- In `check_heap_object()`, page-allocator bounds checking (`n > folio_size(folio) - offset`) must only run when `folio_test_large(folio)` is true, leaving non-slab order-0 (`!folio_test_large(folio)`) folios unchecked so multi-page allocations made without `__GFP_COMP` are not rejected. [F76]
- `stackleak_erase_on_task_stack()` must only be called while executing on the current task's stack (poisoning up to `current_stack_pointer`), whereas `stackleak_erase_off_task_stack()` must only be called from a separate stack when the task stack is no longer in use (poisoning up to `task_pt_regs(current)`). [F73]
- `stackleak_erase()`, `stackleak_erase_on_task_stack()`, and `stackleak_erase_off_task_stack()` must be marked `noinstr`, and all helpers they call (`__stackleak_erase()`, `__stackleak_poison()`, `stackleak_find_top_of_poison()`, `stackleak_task_low_bound()`, `stackleak_task_high_bound()`) must be `__always_inline`. [F74]
- `stack_erasing_sysctl()` must copy `const struct ctl_table *table` to a stack-local `struct ctl_table` with `.data = &state` before calling `proc_dointvec_minmax()`, and must only toggle `stack_erasing_bypass` and log `pr_warn()` when `write` is non-zero, `proc_dointvec_minmax()` returns 0, and `!!state != prev_state`. [F82]
- Under `CONFIG_RANDSTRUCT`, structures whose members are all function pointers are randomized automatically without `__randomize_layout`, so vtable structures that require a fixed ABI layout must be annotated with `__no_randomize_layout`. [F85]

## Error Handling

- In `check_heap_object()`, `find_vmap_area(addr)` can return `NULL` for an `is_vmalloc_addr(ptr)` address and must be checked for `NULL` before dereferencing `area->va_end` or `area->va_start`, and `virt_to_folio(ptr)` must only be called after `virt_addr_valid(ptr)` succeeds. [F20]
- `check_copy_size()` must report compile-time object size overflows (`sz >= 0 && sz < bytes`) and `bytes > INT_MAX` by warning (`copy_overflow()` or `WARN_ON_ONCE()`) and returning `false` without calling `__check_object_size()`, whereas `__check_object_size()` violations must terminate execution in `usercopy_abort()` via `BUG()` (not `do_group_exit()`) so lock-breaking and per-architecture Oops handling run. [F69, F78]

## External Contracts

- `parse_hardened_usercopy()` must return `1` regardless of whether `kstrtobool(str, &enable_checks)` succeeds or returns a negative errno, because `__setup()` handlers return `1` when the boot option is recognized and `0` when it should be passed to `init`'s environment. [F14]
- In `kernel/kstack_erase.c`, the `/proc/sys/kernel/stack_erasing` sysctl entry in `stackleak_sysctls` must validate userspace writes via `proc_dointvec_minmax` with `.extra1 = SYSCTL_ZERO` and `.extra2 = SYSCTL_ONE` (`maxlen = sizeof(int)`), rejecting integer inputs outside `[0, 1]`. [F44]
- `__sanitizer_cov_stack_depth()` must be marked `noinstr` and `__no_caller_saved_registers` because compiler-inserted stack-depth instrumentation invokes it from arbitrary kernel contexts (including via raw inline `call` instructions without saving caller-saved registers). [F75]
- As tested in `lib/tests/usercopy_kunit.c`, `copy_struct_from_user(dst, ksize, src, usize)` must zero-fill trailing `ksize - usize` bytes when `usize < ksize` and return `-E2BIG` if trailing user bytes are non-zero when `usize > ksize`, and failed `copy_from_user()`/`get_user()` must zero `dst`. [F80]

## Known Pitfalls

- In `check_shl_overflow(a, s, d)`, `a` and `s` must be sampled into local temporaries (`_a`, `_s`) before assigning `*_d = (_a_full << _to_shift)` so in-place calls where `d` aliases `a` or `s` do not corrupt the post-shift check `(*_d >> _to_shift) != _a`. [F30]
- `__type_half_max(type)` and `__type_max(T)` must compute a signed type's maximum via `((type)1 << (8*sizeof(type) - 1 - is_signed_type(type)))` rather than shifting 1 into the sign bit, and `__type_min(T)` must cast its operands to `T` before subtracting (`(T)((T)-type_max(T)-(T)1)`). [F53]
- In `include/linux/overflow.h`, `DEFINE_FLEX()` and `DEFINE_RAW_FLEX()` declare `name` as a pointer (`type *name`) to an on-stack union rather than a struct variable, so callers must use `__struct_size(name)`, `__member_size(name->member)`, or `STACK_FLEX_ARRAY_SIZE(name, member)` instead of `sizeof(name)` or `sizeof(*name)`. [F57]
- On-stack flexible-array structures whose flexible array member has a `__counted_by` attribute must be defined with `DEFINE_FLEX(TYPE, NAME, MEMBER, COUNTER, COUNT)` rather than `DEFINE_RAW_FLEX()`, because `DEFINE_RAW_FLEX()` zero-initializes `COUNTER` and causes `__struct_size(NAME->MEMBER)` to report 0 bytes. [F42]
- In `check_copy_size(addr, bytes, is_source)`, the signed `int` result `sz` of `__builtin_object_size(addr, 0)` must be verified non-negative (`sz >= 0`) before comparing `sz < bytes` against the unsigned `size_t` parameter `bytes`. [F55]
- In `check_heap_object()`, `is_kmap_addr(ptr)` and `is_vmalloc_addr(ptr)` must be checked before `virt_addr_valid(ptr)` and `virt_to_folio(ptr)`, because `virt_addr_valid()` rejects kmap and vmalloc addresses and passing `kmap()`ed highmem pointers to `virt_to_folio()` triggers `CONFIG_DEBUG_VIRTUAL` BUGs. [F67]
- In `check_stack_object()`, `arch_within_stack_frames()` returns `NOT_STACK` (`0`) when frame checking is unsupported or inconclusive, so `check_stack_object()` must only return `ret` when `ret != 0` and otherwise fall through to the stack-depth check and return `GOOD_STACK`. [F47]
- In `add_random_kstack_offset()`, the pointer returned by `__kstack_alloca()` must be passed as an `"r"(ptr)` input constraint to `asm volatile("" :: "r"(ptr) : "memory")` rather than an output constraint (`"=o"(*ptr)` or `"=r"(ptr)`) so the compiler does not eliminate the stack allocation as a dead store. [F72]
- In `usercopy_test_check_nonzero_user()`, the quadratic `(start, end)` loop bound `size` must be capped to a 1024-byte window across the page boundary rather than running over the full `priv->size` (`2 * PAGE_SIZE`) buffer. [F51]
