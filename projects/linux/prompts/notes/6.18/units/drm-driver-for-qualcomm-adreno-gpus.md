# DRM DRIVER for Qualcomm Adreno GPUs

`drivers/gpu/drm/msm/adreno` implements generation-specific hardware backends (A2xx through A7xx) for Qualcomm Adreno GPUs within the MSM DRM subsystem, covering GPU initialization, microcode loading, ringbuffer submission, preemption, Graphics Management Unit (GMU) power/frequency control, and crash state capture.

## Architecture & Data Flow
- In `a6xx_gpu.c`, keep common callbacks synchronized across `funcs`, `funcs_gmuwrapper`, and `funcs_a7xx`, and apply PM state transitions (zeroing `shadow[i]` when `shadow_bo != NULL` and incrementing `gpu->suspend_count`) in both `a6xx_gmu_pm_suspend()`/`resume()` and `a6xx_pm_suspend()`/`resume()`. Guard `shadow[]` accesses in suspend and `hw_init()` by checking `shadow_bo != NULL`, not `hw_apriv` or `has_whereami`. [F39, F59, F72]
- When `adreno_has_gmu_wrapper(adreno_gpu)` is true, `a6xx_gmu_wrapper_init()` does not initialize `gmu->vm`, GMU BOs (`hfi`, `log`, `debug`), `gmu_irq`, `hfi_irq`, or GMU firmware; `a6xx_gmu_remove()`, `a6xx_gpu_state_get()`, `hw_init()`, `a6xx_irq()`, and `fenced_write()` must check `adreno_has_gmu_wrapper()` before using them. In `a6xx_gmu_init()`, `gmu->gxpd` and `gmu->qmp` may be `NULL` or a non-deferral `ERR_PTR()`, so check `!IS_ERR_OR_NULL()` before using or releasing them. [F41, F42]
- In `a6xx_llc_slices_init()`, `a6xx_gpu->llc_mmio` is `ERR_PTR(-EINVAL)` on failure and `NULL` when `a6xx_gpu->have_mmu500` is true; `a6xx_llc_activate()` must check `IS_ERR(a6xx_gpu->llc_mmio)` and only call `a6xx_llc_write()`/`a6xx_llc_rmw()` when `!a6xx_gpu->have_mmu500`. [F43]
- In `a2xx_submit()` through `a7xx_submit()`, reset `ring->cur_ctx_seqno = 0` in `hw_init` and only update it to `submit->queue->ctx->seqno` after the `MSM_SUBMIT_CMD_CTX_RESTORE_BUF` loop; in `a5xx_submit()`, `a6xx_submit()`, and `a7xx_submit()`, increment `ibs` per emitted IB and call `update_shadow_rptr(gpu, ring)` when `(ibs % 32) == 0`, masking `submit->cmd[i].size` with `A5XX_CP_INDIRECT_BUFFER_2_IB_SIZE()` on A6xx/A7xx. [F62, F74, F100]
- In `a6xx_set_pagetable()`, write both the 64-bit `ttbr0` and `ctx->seqno` into `ring->memptrs->ttbr0` (and adjacent `context_idr`) via `CP_MEM_WRITE` for preemption restore. In `preempt_init_ring()`, initialize records with `A5XX_PREEMPT_RECORD_MAGIC`, `A6XX_PREEMPT_RECORD_MAGIC`, or `GEN7_CP_SMMU_INFO_MAGIC`; in `a5xx_preempt_hw_init()`, reset `cur_ring` to `gpu->rb[0]`, zero `data`, `info`, `wptr`, and `rptr`, and refresh `rbase` and `rptr_addr` while preserving `magic`, `cntl`, and `counter`. [F54, F56, F93]
- In `a5xx_preempt_init()` and `a5xx_ucode_load()`, if preemption allocation fails or `!a5xx_gpu->has_whereami` when `gpu->nr_rings > 1`, call `a5xx_preempt_fini(gpu)` and set `gpu->nr_rings = 1` in lockstep. In `a6xx_ucode_load()`, if `a6xx_ucode_check_version()` fails, unpin, put, and NULL `a6xx_gpu->sqe_bo` and return `-EPERM`. [F64, F135]
- In `a6xx_gpu.c:hw_init()`, call `a7xx_patch_pwrup_reglist()` only after writing all initial GPU registers (UBWC, HWCG, UCHE, APRIV) and before `a7xx_cp_init()`. Populate the 62 `uint64_t` slots in `struct cpu_gpu_lock->regs` contiguously via a single advancing `dest` pointer (`ifpc_reglist` then `pwrup_reglist`), storing pair counts (not dword/byte counts) in `ifpc_list_len` and `preemption_list_len`. [F67, F85, F102]
- Copy the shared `const` UBWC config from `qcom_ubwc_config_get_data()` into `adreno_gpu->_ubwc_config` before mutating it in `a5xx_gpu_init()` and `a6xx_calc_ubwc_config()`, keeping `highest_bank_bit >= 13` (`BUG_ON(highest_bank_bit < 13)`) before subtracting 13 in `a5xx_hw_init()` and `a6xx_set_ubwc_config()`. [F57, F87]
- Before GPU power-down or reset, halt bus transactions and poll `(gpu_read(...) & mask) == mask` on multi-bit halt ack masks in `a6xx_bus_clear_pending_transactions()` and `a5xx_pm_suspend()`, then clear `REG_A6XX_GBIF_HALT` / `REG_A6XX_VBIF_XIN_HALT_CTRL0` to `0x0` (including in `hw_init()`). On A6xx with an explicit `hwcg` table (except `adreno_is_a610_family()` and `adreno_is_a7xx()`), clear bit 0 of `REG_A6XX_GPU_GMU_GX_SPTPRAC_CLOCK_CONTROL` before writing `hwcg` and set it back to 1 before `REG_A6XX_RBBM_CLOCK_CNTL`. [F98, F143, F145]
- In `a6xx_gmu_shutdown()`, if `adreno_gpu->base.needs_hw_init` is true, do a dummy `GMU_OOB_GPU_SET` set/clear handshake before `a6xx_gmu_notify_slumber()`. In `a6xx_gmu_rpmh_off()`, poll RSCC `TCS0..TCS3_DRV0_STATUS` for bit 0, and when `adreno_is_a740_family(adreno_gpu)` is true, apply `seqmem_off = 4` and also poll `REG_A7XX_RSCC_TCS4_DRV0_STATUS..TCS9`. [F144, F147]
- In `a6xx_gmu_set_initial_freq()`, clear `gmu->freq = 0` before calling `a6xx_gmu_set_freq(gpu, gpu_opp, false)`. In `a6xx_gmu_set_freq()`, when `suspended` is true, only update `gmu->current_perf_index` and `gmu->freq`; when active on non-legacy GMUs, call `dev_pm_opp_set_opp()` only if `!bw_index`, and clear `dev_pm_opp_set_opp(&gpu->pdev->dev, NULL)` in `a6xx_gmu_stop()` and `a6xx_pm_suspend()`. [F63, F148]
- In `a6xx_gmu_pwrlevels_probe()` and `a6xx_gmu_rpmh_votes_init()`, query CX OPPs on `gmu->dev` and GX OPPs on `&gpu->pdev->dev`. `a6xx_gmu_build_freq_table()` and `a6xx_gmu_build_bw_table()` reserve index 0 for `0` and post-increment `freq++`/`bandwidth++` on each `dev_pm_opp_find_*_ceil()` hit; thus `a6xx_gmu_acd_probe()` must iterate `gmu->gpu_freqs` from `i = 1`, pack `cmd->data[cmd_idx++]` densely, and set `BIT(i)` in `cmd->enable_by_level`, while `a6xx_gmu_set_freq()` requires `gmu->nr_gpu_bws > 1` before dividing by `gpu_bw_table[nr_gpu_bws - 1]`. [F84, F105, F106, F107, F117]
- Catalog tables: `chip_ids` ends with `0`, `speedbins` with `{SHRT_MAX, 0}`, nullable `a6xx_info.hwcg` with `{}`, nullable `a6xx_info.bcms` with `{.name = NULL}` and `<= GMU_MAX_BCMS` (3) active entries (requiring `.buswidth != 0` when `!bcm->fixed`), legacy `registers` with `~0`, and A7xx register ranges with `UINT_MAX`. Every `adreno_protect` table needs `BUILD_BUG_ON(count > count_max)` in `__build_asserts()`, and `a6xx_set_cp_protect()` must write the final infinite-range entry `regs[count - 1]` to `REG_A6XX_CP_PROTECT(count_max - 1)`. [F44, F75, F80, F81, F82, F83, F101, F116, F137]
- In `a5xx_gpu_state_get()` and `a6xx_gpu_state_get()`, only run the crashdumper when the SMMU is not stalled (`RBBM_STATUS3` fault bit clear) and, on A6xx/A7xx, `!gpu->needs_hw_init && a6xx_gmu_sptprac_is_on()`. Terminate scripts in `dumper->ptr` with `CRASHDUMP_FINI(in)`, write output to `dumper->iova + A6XX_CD_DATA_OFFSET` after `WARN_ON(datasize > A6XX_CD_DATA_SIZE)`, set `a6xx_state->nr_*` in lockstep with array allocations, and skip NULL `obj->handle` entries in `a6xx_show()`. [F48, F55, F69, F88, F110]

## Synchronization
- Serialize all accesses to `ring->cur`, `get_wptr(ring)`, and `ring->restore_wptr` in `a5xx_flush()`, `a6xx_flush()`, `update_wptr()`, `get_next_ring()`, and `a5xx_preempt_trigger()` under `ring->preempt_lock` with `spin_lock_irqsave()`. In `a6xx_flush()`, hold `ring->preempt_lock` across advancing `ring->cur = ring->next`, checking `!a6xx_in_preempt(a6xx_gpu)` and `a6xx_gpu->cur_ring == ring`, and writing `REG_A6XX_CP_RB_WPTR` or setting `ring->restore_wptr = true`. [F22, F153]
- In `a5xx_preempt.c`, use `set_preempt_state()` for unconditional state writes and `try_preempt_state()` for conditional transitions. Hold `preempt_start_lock` in `a5xx_preempt_trigger()` across `try_preempt_state(..., PREEMPT_NONE, PREEMPT_START)`, `get_next_ring(gpu)`, and the abort path; when aborting, set `PREEMPT_ABORT` before `update_wptr()` and then `PREEMPT_NONE`, pairing with `mb()` before `!a5xx_in_preempt(a5xx_gpu)` in `a5xx_flush()`. [F16, F17, F21]
- In `a5xx_preempt_trigger()`, set `preempt[ring->id]->wptr`, `RESTORE_ADDR_LO`, `next_ring`, `preempt_timer`, and `PREEMPT_TRIGGERED`, then execute `wmb()` before writing `REG_A5XX_CP_CONTEXT_SWITCH_CNTL` (and execute `wmb()` before `REG_A6XX_CP_CRASH_DUMP_CNTL` in `a6xx_crashdumper_run()`). In `a5xx_preempt_irq()`, re-invoke `a5xx_preempt_trigger(gpu)` after setting `PREEMPT_NONE`. On A5xx/A7xx, update `last_seqno[ring->id] = submit->seqno` before flushing/preempting, and treat `cur_ring` as empty in `get_next_ring()` when `ring->memptrs->fence == last_seqno[i]`. [F18, F19, F20, F159]
- In `a6xx_gmu_remove()`, unlock `gmu->lock` immediately after clearing `gmu->initialized` (before `pm_runtime_force_suspend()` or `dev_pm_domain_detach()`). Call `msm_devfreq_suspend(gpu)` before `a6xx_gmu_stop()` and `msm_devfreq_resume(gpu)` after `a6xx_gmu_resume()` outside `gmu.lock`, and in `a6xx_gmu_sysprof_setup()` call `pm_runtime_get_if_active(&gpu->pdev->dev)` before locking `gmu->lock` and `pm_runtime_put()` after unlocking. [F24, F25, F26]
- During `a6xx_recover()`, hold `gpu->active_lock` while saving/zeroing `gpu->active_submits`, registering `gmu->pd_nb` on `gmu->cxpd` after `reinit_completion(&gmu->pd_gate)`, cycling runtime PM to collapse CX, removing `gmu->pd_nb`, and restoring `gpu->active_submits`. Request `gmu_irq` and `hfi_irq` with `IRQF_NO_AUTOEN`, enable them in `a6xx_gmu_resume()` only after clocks and HFI start, and disable them via `a6xx_gmu_irq_disable()` before stopping RPMh/clocks. [F27, F28]
- On non-GMU-wrapper A6xx/A7xx, `a6xx_irq()` must assert `a6xx_gpu_keepalive_vote(gpu, true)` and poll `REG_A6XX_GMU_AO_AHB_FENCE_CTRL == 0` via `irq_poll_fence(gpu)` (`gmu_poll_timeout_atomic()`) before reading any GPU register, clearing the vote on exit. In `fenced_write()` and `fence_status_check()`, execute `mb()` (not a posted `gpu_read()`) after `gpu_write()` before polling `REG_A6XX_GMU_AHB_FENCE_STATUS`, and re-issue `gpu_write()` + `mb()` whenever `status & mask` is non-zero. [F29, F30, F103]
- In `a5xx_fault_detect_irq()` and `a6xx_fault_detect_irq()`, if `RBBM_STATUS3` indicates the SMMU is stalled on a fault, return immediately without deleting `gpu->hangcheck_timer` or queueing `gpu->recover_work`. [F151]

## Object Lifetimes
- In `a6xx_gpu_init()`, call `mutex_init(&a6xx_gpu->gmu.lock)` before `adreno_gpu_init()`. Error paths before `adreno_gpu_init()` must call `a6xx_llc_slices_destroy(a6xx_gpu)` and `kfree(a6xx_gpu)` rather than `a6xx_destroy()`, whereas error paths at or after `adreno_gpu_init()` must call `a6xx_destroy(&a6xx_gpu->base.base)`. [F1, F2]
- In `a6xx_gmu_init()`, roll back `gxpd`, `gmu->qmp`, the `cxpd` `device_link`, `cxpd`, MMIO/IRQs (calling `iounmap(gmu->rscc)` only if the `"rscc"` `IORESOURCE_MEM` resource exists, both here and in `a6xx_gmu_remove()`), `a6xx_gmu_memory_free()`, and `put_device(gmu->dev)` (also required on `a6xx_gmu_wrapper_init()` failure and in `a6xx_gmu_remove()`, with `of_node_put(node)` in `a6xx_gpu_init()`) in reverse order. Power down `gmu->gxpd` and clocks before putting `gmu->dev`, and resume `gmu->dev` before `gmu->gxpd`. [F3, F9, F132, F133]
- Release firmware GEM BOs whose vmap was dropped via `msm_gem_put_vaddr()` (`pm4_bo`, `pfp_bo`, `gpmu_bo`, `sqe_bo`) with `msm_gem_unpin_iova()` and `drm_gem_object_put()`, never `msm_gem_kernel_put()` (in `reset_set()`, pair freeing/NULLing `fw[]` with unpinning/putting/NULLing `pm4_bo` and `pfp_bo`). In `a6xx_gmu_memory_free()`, release all GMU BOs with `msm_gem_kernel_put(..., gmu->vm)` before `mmu->funcs->detach(mmu)` and `drm_gpuvm_put(gmu->vm)` (or `mmu->funcs->destroy(mmu)` on `a2xx_create_vm()` failure), and release `dumper->bo` in `a6xx_gpu_state_get()`. [F5, F11, F13, F65, F165]
- Never pass `state_kcalloc()` or `state_kmemdup()` pointers to `kfree()`/`kvfree()`; allocate `msm_gpu_state_bo.data` in `a6xx_snapshot_gmu_bo()` with `kvzalloc()`. Generation `gpu_state_get` callbacks must call `adreno_gpu_state_get(gpu, state)` and custom state destructors must call `adreno_gpu_state_destroy(state)` before `kfree()`. [F120, F167]

## API Contracts
- `a6xx_gmu_wait_for_idle()` and `spin_usecs()` return `0` on idle and `-ETIMEDOUT` on timeout, whereas `a2xx_idle()`..`a6xx_idle()`, `a6xx_gmu_isidle()`, `a6xx_gmu_gx_is_on()`, and `a6xx_gmu_sptprac_is_on()` return `bool`. `msm_gem_vm_create()` takes `va_size` as its 5th parameter, whereas `msm_gem_get_and_pin_iova_range()` takes `range_end` (`iova + size`). [F38, F49]
- `a6xx_gmu_set_oob()` and `a6xx_gmu_clear_oob()` require `gmu->lock` to be held and only support `GMU_OOB_BOOT_SLUMBER` and `GMU_OOB_DCVS_SET` when `gmu->legacy` is true. `A6XX_PROTECT_NORDWR()`/`RDONLY()` take a 0-based count (`_len + 1` registers), whereas A5xx `ADRENO_PROTECT_RW(_reg, _len)` takes a power-of-two `_len` and `_len`-aligned `_reg`. [F52, F119]
- `gmu_read*()`, `gmu_write*()`, `gmu_rmw()`, `a6xx_llc_*()`, `cxdbg_*()`, and `pdc_write()` take 32-bit dword register offsets (scaling by `<< 2`), while `gmu_write_bulk()` takes `offset` in dwords and `size` in bytes. In `a6xx_gpu_state.c`, `CRASHDUMP_READ()` takes a dword count while `out` and `state_kmemdup()` sizes use bytes (`* sizeof(u32)`), and `print_ascii85()` takes `len` in bytes (`<< 2` for dword counts, `<< 3` for quadword `a6xx_debugbus_block::count`). [F122, F123, F124, F125, F174]

## Error Handling
- `a6xx_gmu_get_mmio()`, `adreno_fw_create_bo()`, `msm_gem_get_vaddr()`, `msm_gem_kernel_new()`, and `devm_of_icc_get()` return `ERR_PTR()` on failure: check `IS_ERR()`/`IS_ERR_OR_NULL()`, guard `iounmap()` with `!IS_ERR_OR_NULL()` on `NULL`-initialized locals, reset `pm4_bo`/`pfp_bo`/`sqe_bo` to `NULL` if `adreno_fw_create_bo()` fails, and reset `ocmem_icc_path = NULL` on `-ENODATA` in `a3xx_gpu_init()`/`a4xx_gpu_init()`. Propagate negative returns from `of_dma_configure(gmu->dev, node, true)` in `a6xx_gmu_init()` and `a6xx_gmu_wrapper_init()`. [F33, F34, F35, F36, F37]
- In `a6xx_set_supported_hw()`, `-ENOENT` from `adreno_read_speedbin()` returns `0`, while `UINT_MAX` from `fuse_to_supp_hw()` falls back to `supp_hw = BIT(0)` for `devm_pm_opp_set_supported_hw()`. On `-ENODEV` from `a5xx_zap_shader_init()`/`a6xx_zap_shader_init()`, write `0` to `RBBM_SECVID_TRUST_CNTL` (and set `ret = 0` in `hw_init()`), propagating any other error. [F45, F46]

## External Contracts
- On A7xx, `a6xx_set_pagetable()` must run on `CP_SET_THREAD_BR` after `CP_WAIT_TIMESTAMP` and context reset, followed by `CP_THREAD_CONTROL_0_SYNC_THREADS | CP_SET_THREAD_BR` and `CACHE_INVALIDATE` after `CP_SMMU_TABLE_UPDATE`. [F161]

## Known Pitfalls
- In `a6xx_gpu_init()`, `adreno_gpu->info` is `NULL` until `adreno_gpu_init()`, so read `config->info` before that point. Guard GX register reads in `a6xx_gpu_state_get()` and `a6xx_get_gmu_registers()` with `a6xx_gmu_gx_is_on()` (testing `A7XX_*_GX_HM_*` on A7xx vs `A6XX_*` on A6xx) and halt SQE (`REG_A6XX_CP_SQE_CNTL = 3`) before indexed/crashdumper reads; when `ADRENO_QUIRK_IFPC` is set, `a6xx_progress()` must return `true` without reading GX registers and `a6xx_get_rptr()` must read `shadow[ring->id]`. [F31, F104, F138, F141]
- Branch ordering and state handles: in `a6xx_gpu_state.c`, A7xx table selectors must branch on exact `info->family` (`ADRENO_7XX_GEN1`/`GEN2`/`GEN3`) rather than `adreno_is_a740_family()`, store `const u32 *` (`regs->regs`) in `obj->handle` on A7xx vs `const struct a6xx_registers *` on A6xx, and write `regs->sel->host_reg` for AHB reads vs `regs->sel->cd_reg` for crashdumper reads. Check `adreno_is_a330v2()` before `adreno_is_a330()` in `a3xx_hw_init()`, and `adreno_is_a619_holi()` before `a6xx_has_gbif()` in `hw_init()`. [F70, F94, F96, F97, F109]
- 64-bit math, bitops, and indexing: cast `reg` to `u64` before `<< 44` in `CRASHDUMP_WRITE()`/`READ()`, cast high MMIO reads to `u64` before `<< 32` in `gmu_read64()` and `read_gmu_ao_counter()` (looping until pre/post `_H` reads match), cast `bw` to `u64` and use `do_div()` for bandwidth votes in `a6xx_gmu.c`, keep `GMU_STATUS_*` as bit indices (`0..2`), and offset `shadow_iova` by `ring->id * sizeof(uint32_t)` (`shadowptr()`). [F111, F112, F113, F114, F115, F126, F129]
