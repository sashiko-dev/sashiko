# MELLANOX MLX5 IB driver

This unit implements Queue Pair (QP), Shared Receive Queue (SRQ), User-Mode Memory Registration (UMR), Work Request (WR) posting, resource tracking (`restrack`), and uverbs ioctl operations for `mlx5_ib`, alongside shared `include/linux/mlx5/` PRM bit-level command/descriptor layouts (`mlx5_ifc.h`, `mlx5_ifc_vdpa.h`) and core subsystem headers for capabilities, doorbells, completion/event queues, e-switch, flow steering, and transport objects.

## Architecture & Data Flow

- In `struct mlx5_ifc_*_bits`, each `u8` is 1 bit (`offsetof` is the bit offset); adding/resizing fields requires adjusting adjacent `reserved_at_*` arrays by the exact bit count, and any scalar field used with `MLX5_SET`/`MLX5_GET` must be `<= 32` bits and never cross a 32-bit boundary. `MLX5_GENERAL_OBJ_TYPES_CAP_*` / `MLX5_HCA_CAP_GENERAL_OBJECT_TYPES_*` must use `BIT_ULL`, and `MLX5_HCA_CAP_2_GENERAL_OBJECT_TYPES_*` must subtract `0x40` before `BIT_ULL`. [F224, F225, F236, F237]
- `struct mlx5_core_rsc_common common` must remain the first member of `struct mlx5_core_qp` and `struct mlx5_core_srq`. Every active `mlx5_ib_qp_base` (`trans_qp.base`, `raw_packet_qp.sq.base`, `raw_packet_qp.rq.base`) must set `container_mibqp = qp` for `to_mibqp()`, whereas `mlx5_ib_rwq::core_qp` uses `to_mibrwq()`. [F131, F132]
- For `IB_QPT_RAW_PACKET` QPs (or when `IB_QP_CREATE_SOURCE_QPN` is set in `create_user_qp()` / `destroy_qp_common()`), use `&qp->raw_packet_qp.rq.base` instead of `&qp->trans_qp.base`, and in `__mlx5_ib_qp_set_counter()`, bind counters on `qp->raw_packet_qp.rq` via `__mlx5_ib_qp_set_raw_qp_counter()` and `mlx5_core_modify_rq()` rather than `MLX5_CMD_OP_RTS2RTS_QP`. [F46, F47]
- In `qpc.c`, `qp_table.tree` keys for QPs, RQs, and SQs must be encoded as `qpn | (rsc_type << MLX5_USER_INDEX_LEN)` (masking `qpn` to 24 bits in `rsc_event_notifier()`), whereas DCTs use `qp_table.dct_xa` indexed by the 24-bit `dctn`. [F91]
- During SQ WQE construction (`mlx5r_begin_wqe()`, `handle_post_send_edge()`, `mlx5r_memcpy_send_wqe()`, `mlx5r_finish_wqe()`), `size` (`wqe_sz`) is in 16B octowords (DS) while `sq->cur_post` and `sq->wqe_cnt` are in 64B WQEBBs (`DIV_ROUND_UP(size * 16, MLX5_SEND_WQE_BB)`). `*seg` must stay 16B-aligned (rounding the final chunk in `mlx5r_memcpy_send_wqe()` with `ALIGN(copysz, 16)`) and wrap via `handle_post_send_edge()`. [F59, F90, F113, F125, F126]
- Hardware producer counters `qp->sq.cur_post` (`u16`), `srq->wqe_ctr` (`u16`), and `qp->rq.head & 0xffff` written to `ctrl->opmod_idx_opcode` and `db.db` wrap modulo `2^16` (only buffer slot lookups mask with `wqe_cnt - 1`). In `mlx5r_wq_overflow()`, compute occupancy via unsigned `cur = wq->head - wq->tail` tested with `cur + nreq >= wq->max_post`. [F127, F128]
- Kernel SRQs use an in-buffer free list (`mlx5_wqe_srq_next_seg`): `mlx5_ib_post_srq_recv()` pops `srq->head` (until `head == tail`) and sets `srq->head = be16_to_cpu(next->next_wqe_index)`, while `mlx5_ib_free_srq_wqe()` links freed `wqe_index` at `srq->tail`. When `wr->num_sge` is less than `max_avail_gather` or `qp->rq.max_gs`, terminate `scat[i]` with `byte_count = 0`, `addr = 0`, and cached `lkey = dev->mkeys.terminate_scatter_list_mkey` (already `__be32`). [F73, F93, F114]
- QPC/SRQC `log_rq_stride` and `mlx5_srq_attr.wqe_shift` store `wqe_shift - 4` (16B units), whereas WQC `log_wq_stride` (`set_wq()`, `create_raw_packet_qp_rq()`) stores the full byte shift (`wqe_shift + 4` or `log_rq_stride + 4`). In `qpc`, `srqc`, `xrc_srqc`, and `wq`, `log_page_size` / `log_wq_pg_sz` subtract `MLX5_ADAPTER_PAGE_SHIFT` (12), whereas UMR `mkc` (`mlx5_mkey_seg`) uses unshifted `page_shift`. [F57, F95]
- UMR translation DMA lengths (`sg.length`) and byte offsets in `mlx5r_umr_update_offset()` must be aligned to `MLX5_UMR_FLEX_ALIGNMENT` / `MLX5_IB_UMR_XLT_ALIGNMENT` (64B) before dividing by 16B (`mlx5r_umr_get_xlt_octo()`, using `u64` for 48-bit offsets). In `mlx5r_umr_update_xlt()`, add `idx & page_mask` to `npages` before rounding `idx` down and `pages_to_map` up. [F92, F123, F124]
- In `__mlx5_ib_modify_qp()`, resetting a kernel non-`IB_QPT_XRC_TGT` QP to `IB_QPS_RESET` must call `mlx5_ib_cq_clean()`, zero `rq`/`sq` indices and `db.db`, and reset `qp->sq.cur_edge = get_sq_edge(&qp->sq, 0)`. Moving to `IB_QPS_RTS` with `qp->counter_pending` set must call `__mlx5_ib_qp_set_counter()` and clear `counter_pending = 0`. Update shadow `atomic_rd_en` and `resp_depth` (used by `set_qpc_atomic_flags()`) only after `mlx5_core_qp_modify()` succeeds. [F61, F62, F63]
- Validate 1-based IB `port_num` against `1 <= port_num <= dev->num_ports` (not `MLX5_CAP_GEN(dev->mdev, num_ports)`) before indexing `dev->port[port_num - 1]`. In `validate_rd_atomic()`, `MLX5_IB_QPT_DCI` uses `log_max_ra_res_dc` / `log_max_ra_req_dc`. New `enum mlx5_cap_type` values must be `< MLX5_CAP_NUM` and added to `types[]` in `mlx5_hca_caps_alloc()`. [F85, F86, F97]

## Synchronization

- Lock hierarchy: `dev->reset_flow_resource_lock` -> `qp->sq.lock` / `qp->rq.lock` -> `cq->lock` -> `srq->lock`. Linking/unlinking QPs on `dev->qp_list` and CQ lists (`create_dci()`, `create_user_qp()`, `create_kernel_qp()`, `destroy_qp_common()`) must acquire `dev->reset_flow_resource_lock` before `mlx5_ib_lock_cqs(send_cq, recv_cq)`, which locks distinct CQs in ascending `mcq.cqn` order (`SINGLE_DEPTH_NESTING`) and a shared CQ once. `mlx5r_wq_overflow()` runs under IRQ-disabled `sq.lock`/`rq.lock` and takes `cq->lock`. [F12, F29, F30, F164]
- Because `rsc_event_notifier()`, `dct_event_notifier()`, and `srq_event_notifier()` run in atomic EQ interrupt context, process-context accesses to `qp_table.lock`, `qp_table.dct_xa`, and `srq_table.array` must disable IRQs (`spin_lock_irq*` / `xa_*_irq*`). `mlx5_ib_qp_event()` must allocate `mlx5_ib_qp_event_work` with `GFP_ATOMIC` and defer sleeping work to `mlx5_ib_qp_event_wq`. [F158, F160]
- `srq->lock` (with IRQs disabled in `mlx5_ib_free_srq_wqe()`) protects `srq->head`, `tail`, `wqe_ctr`, and `next_wqe_index`; `srq->mutex` serializes `mlx5_cmd_arm_srq()`. `qp->mutex` protects `qp->state`, `counter_pending`, `ibqp->counter`, and raw-packet SQ/RQ state across `mlx5_ib_modify_qp()`, `mlx5_ib_query_qp()`, and `mlx5_ib_qp_set_counter()`. [F27, F40]
- A `wmb()` must separate writing WQE descriptors or `*cq->arm_db` from writing doorbell records (`*qp->db.db`, `*srq->db.db` under `rq.lock`/`srq->lock`) or `MLX5_CQ_DOORBELL` in `mlx5_cq_arm()`. In `mlx5r_ring_db()`, `wmb()` barriers, `mlx5_write64()`, and `bf->offset ^= bf->buf_size` must execute under `qp->sq.lock`. [F32, F33, F162, F163]
- In `mlx5r_umr_resource_init()`, initialize `cq`, `sem`, `lock`, and `state = MLX5_UMR_STATE_ACTIVE` under `umrc.init_lock` before assigning `dev->umrc.qp`. In `mlx5r_umr_post_send_wait()`, pair `down(&umrc->sem)` with `up(&umrc->sem)` on all paths and release `umrc->lock` before sleeping or calling `mlx5r_umr_recover()` (which must set `MLX5_UMR_STATE_RECOVER` under `umrc->lock` and await a barrier WR completion before resetting `umrc->qp`). [F21, F35, F76]
- When `mlx5r_umr_alloc_xlt()` falls back to `xlt_emergency_page`, it returns with `xlt_emergency_page_mutex` held; callers of `mlx5r_umr_alloc_xlt()` / `mlx5r_umr_create_xlt()` must free via `mlx5r_umr_free_xlt()` / `mlx5r_umr_unmap_free_xlt()`, restoring `sg.length = orig_sg_length` first if shrunk for the final WQE. [F9, F38]

## Object Lifetimes

- `mlx5_core_res_hold()`, `mlx5_get_rsc()`, and `mlx5_cmd_get_srq()` increment `common.refcount` and transfer ownership to the caller (`mlx5_core_res_put()`). `rsc_event_notifier()` transfers its reference to `qp->event()` (`mlx5_ib_qp_event()` / `mlx5_ib_handle_qp_event()` must call `mlx5_core_res_put(&qp->common)`), whereas `srq_event_notifier()` releases the reference itself after `srq->event()` returns (`mlx5_ib_srq_event()` must NOT call `mlx5_core_res_put()`). [F5, F6, F22]
- `mlx5_core_destroy_qp()` and `mlx5_core_destroy_sq_tracked()` must call `destroy_resource_common()` before firmware `DESTROY_QP`/`DESTROY_SQ`. Conversely, `mlx5_core_destroy_rq_tracked()` must set `rq->common.invalid = true` via `modify_resource_common_state()` under `qp_table.lock` before `destroy_rq_tracked()`, revert it to `false` on failure, and call `destroy_resource_common()` only on success. [F23, F24]
- In `mlx5_core_destroy_dct()` (after draining DCT while still in `dct_xa` unless `MLX5_DEVICE_STATE_INTERNAL_ERROR`) and `mlx5_cmd_destroy_srq()`, replace the `dct_xa` / `srq_table.array` entry with `XA_ZERO_ENTRY` via `xa_cmpxchg_irq()` before firmware destroy, restore it on error, and call `xa_erase_irq()` (plus `mlx5_core_res_put()` and `wait_for_completion(&srq->common.free)` for SRQs) only on success. [F25, F78, F142]
- For `MLX5_IB_QPT_DCT`, `create_dct()` only allocates `qp->dct.in` while firmware creation happens in `mlx5_ib_modify_dct()` at `IB_QPS_RTR`; `mlx5_ib_destroy_dct()` must call `mlx5_core_destroy_dct()` only when `mqp->state == IB_QPS_RTR` and free `mqp->dct.in` only after it succeeds. [F17]
- In `destroy_qp_common()`, non-RSS QPs must transition to `2RST_QP`, unlink from `dev->qp_list` and CQ lists under `reset_flow_resource_lock` and CQ locks, and destroy the firmware QP before `destroy_qp()` frees buffers/doorbells. Call `mlx5_ib_free_bfreg()` only when `bfregn != MLX5_IB_INVALID_BFREG`. [F13, F143]
- Raw packet QP sub-resources must be created TIS then SQ (destroyed SQ then TIS) and RQ then TIR (destroyed TIR then RQ). In `modify_raw_packet_qp()`, `create_flow_rule_vport_sq()` returns `NULL`, `ERR_PTR`, or a valid handle; delete any non-NULL new `flow_rule` via `mlx5_del_flow_rules()` if `modify_raw_packet_qp_sq()` fails, and only call `destroy_flow_rule_vport_sq(sq)` after `modify_raw_packet_qp_sq()` succeeds. [F11, F15, F49]

## API Contracts

- In `fill_multiport_info()`, release non-NULL `mdev` from `mlx5_ib_get_native_port_mdev()` via `mlx5_ib_put_native_port_mdev()` on all exit paths. `mlx5_rsc_dump_cmd_create()` returns `ERR_PTR` (never `NULL`); in `dump_rsc()`, always clean up with `mlx5_rsc_dump_cmd_destroy(cmd)` and `__free_page(page)` (checking `size + offset > MAX_DUMP_SIZE` per segment), and process `page` on both `1` and `0` (final page) returns from `mlx5_rsc_dump_next()`. [F19, F20, F96, F198, F199, F265]
- `_mlx5r_umr_zap_mkey()`, `mlx5r_ib_rate()`, `get_ts_format()` / `get_*_ts_format()`, and `calc_sq_size()` return negative errnos on error and non-negative values on success; store results in signed `int` and check `< 0`. `transobj.h` creation/query helpers leave output pointers untouched on error, and `inlen` / `ptys_size` take byte counts (`MLX5_ST_SZ_BYTES`). [F43, F44, F50, F51, F202, F246]
- UMR XLT update functions sleep even with `MLX5_IB_UPD_XLT_ATOMIC` and require process context; `umr_check_mkey_mask()` must verify `mkey_mask` against HCA caps before posting. Callers of `mlx5_umem_find_best_quantized_pgoff()` must check `page_size != 0` before `order_base_2(page_size)` or `ib_umem_num_dma_blocks()`. [F120, F151, F165]
- Check `mlx5_get_roce_state(dev)` (using `MLX5_CAP_GEN(dev, roce)` if `roce_rw_supported`, else `mlx5_is_roce_on(dev)`) before reading `MLX5_CAP_ROCE(dev, qp_ts_format)` in `mlx5_get_qp_default_ts()`. `_mlx5_fs_is_outer_ipv_flow()` requires full `fte_match_param` base pointers, must check `MLX5_CAP_FLOWTABLE_NIC_RX(mdev, ft_field_support.outer_ip_version)` before matching `ip_version`, and must verify both `headers_c` mask and `headers_v` value. [F147, F233, F247, F248, F249]

## Error Handling

- In `mlx5_ib_post_send()`, `mlx5_ib_post_recv()`, and `mlx5_ib_post_srq_recv()`, every error path must set `*bad_wr = wr`, and if `nreq > 0` WRs were already written before a mid-list error, must still ring the doorbell and advance `qp->sq.head`, `qp->rq.head`, or `srq->wqe_ctr` by `nreq`. In `mlx5_ib_drain_sq()` / `mlx5_ib_drain_rq()`, ignore `ib_modify_qp()` errors when `mdev->state == MLX5_DEVICE_STATE_INTERNAL_ERROR`. [F54, F112, F184]
- `mlx5r_umr_dmabuf_update_pgsz()` must call `_mlx5r_umr_zap_mkey()` to zap initial blocks at `max_page_shift` before loading tail blocks with `MLX5_IB_UPD_XLT_KEEP_PGSZ`, calling `mlx5r_umr_update_mr_page_shift()`, and populating zapped blocks; both functions must restore `mr->page_shift = old_page_shift` on error. [F42, F75]
- `modify_raw_packet_qp_sq()` must add the new rate via `mlx5_rl_add_rate()` before `mlx5_core_modify_sq()`, roll it back on error, and remove `old_rl` via `mlx5_rl_remove_rate()` only on success. `mlx5r_umr_cleanup()` must check `dev->umrc.pd != NULL` and `mlx5r_umr_resource_cleanup()` must check `dev->umrc.state != MLX5_UMR_STATE_UNINIT`. [F45, F66]

## External Contracts

- In `process_udata_size()` / `check_ucmd_data()`, accept `udata->inlen >= offsetof(struct mlx5_ib_create_qp, ece_options)` and verify bytes from `offsetof(..., reserved)` are zero via `ib_is_udata_cleared()`. In `mlx5_ib_modify_qp()`, `udata->inlen < offsetofend(typeof(ucmd), ece_options)` returns `-EINVAL`, while non-zero trailing bytes, unknown `comp_mask` bits, or non-zero `burst_info.reserved` return `-EOPNOTSUPP`. [F88, F177]
- In `process_vendor_flags()` and `process_create_flags()`, clear each handled bit via `process_vendor_flag()` / `process_create_flag()` so residual bits fail, except `MLX5_QP_FLAG_SCATTER_CQE` and `MLX5_QP_FLAG_ALLOW_SCATTER_CQE` which clear without error even when `sctr_data_cqe` is false. Match mutually exclusive flags (`TYPE_DCT | TYPE_DCI` and `UAR_PAGE_INDEX | BFREG_INDEX`) in a `switch` on the combined mask. [F104, F106, F107]

## Known Pitfalls

- `MLX5_SET*` and `MLX5_GET*` dereference aligned `__be32 *`, `__be64 *`, or `__be16 *` pointers directly, and `MLX5_SET`/`MLX5_GET` only access a single 32-bit dword (`__mlx5_mask` must use `1ull << __mlx5_bit_sz`). Use `MLX5_SET64`/`MLX5_GET64` or split dwords for 64-bit fields, and cast 32-bit `MLX5_GET` results (`icm_address_39_32`, `icm_address_63_40`) to `u64` before shifting `>= 32`. [F98, F99, F117, F118]
- Use `MLX5_ST_SZ_BYTES` / `MLX5_FLD_SZ_BYTES` (plus `count * sizeof(u64)` for PAS or `count * sizeof(u32)` for RQT) for byte allocations and `mlx5_cmd_exec()` sizes, and `MLX5_ST_SZ_DW` for `u32` array bounds and `u32 *` pointer offsets. Shift `1UL` (not `1`) when computing `page_size` for `ib_umem_num_dma_blocks()` or `mlx5_ib_populate_pas()`. [F119, F129, F137]
- In `mlx5r_begin_wqe()`, zero `*(uint32_t *)(*seg + 8) = 0` (`signature` and `rsvd` in `mlx5_wqe_ctrl_seg`), and address `&cseg->trailer` for bulk operations on the second 8 bytes. In `mlx5_wqe_eth_seg`, `sizeof` includes the 2-byte `inline_hdr.start` (subtract it from WQE size math and copy multi-byte headers to `inline_hdr.data`), and `eseg->trailer` unions with `eseg->inline_hdr.sz` (use `|=`). [F55, F243, F244, F267]
- `wqe->ctrl_seg.mkey_mask` is `__be64`: convert `MLX5_MKEY_MASK_*` with `cpu_to_be64()` when modifying it, and `be64_to_cpu()` when calling `umr_check_mkey_mask()`. UMR XLT buffers must be dynamically allocated pages synced with `dma_sync_single_for_cpu()` / `dma_sync_single_for_device()` when reused across WQEs, and `struct mlx5r_umr_context` and `struct mlx5_ib_umr_context` must keep identical layouts. [F87, F134, F155]
- In `mlx5_ib_modify_qp()`, check `qp->type == IB_QPT_GSI` before mapping `MLX5_IB_QPT_HW_GSI` to `qp_type = IB_QPT_GSI` for `ib_modify_qp_is_ok()` and `validate_rd_atomic()`. In `__mlx5_ib_modify_qp()`, compute `log_sra_max` / `log_rra_max` from non-zero `max_rd_atomic` / `max_dest_rd_atomic` with `fls(val - 1)`, not `ilog2()`. [F115, F116]
