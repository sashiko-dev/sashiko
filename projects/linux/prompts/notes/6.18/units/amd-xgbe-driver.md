# AMD XGBE DRIVER

Implements the core AMD 10 Gigabit Ethernet (`amd-xgbe`) network driver in `drivers/net/ethernet/amd/xgbe`, covering PCI probing, `net_device` lifecycle, DMA descriptor ring and channel management, MAC/MTL/DMA register programming, MDIO/PCS auto-negotiation, I2C transfers, IEEE 1588 timestamping, DCB, ethtool, and debugfs.

## Architecture & Data Flow
- `xgbe_ring` indices `cur` and `dirty` are free-running unsigned integers wrapping at `UINT_MAX` on power-of-two rings: compute occupancy via `ring->cur - ring->dirty`, test completion with `ring->dirty != cur`, and index `ring->rdata` via `XGBE_GET_DESC_DATA()`. In `xgbe_wrapper_{tx,rx}_descriptor_init()`, reset `cur` and `dirty` to `0` and zero `ring->tx` before `hw_if->{tx,rx}_desc_init()`. [F67, F116]
- All `struct xgbe_ring_desc` (`desc0`..`desc3`) accesses must use `cpu_to_le32()`, `le32_to_cpu()`, `XGMAC_GET_BITS_LE()`, or `XGMAC_SET_BITS_LE()`, never native-endian `XGMAC_GET_BITS()`/`XGMAC_SET_BITS()`. [F90]
- `ring->packet_data` is reused across packets while `xgbe_packet_info()` and `xgbe_dev_read()` only set individual bitfields in `attributes` and `errors`; `xgbe_xmit()` and `xgbe_rx_poll()` must `memset(packet, 0, sizeof(*packet))` first. [F48]
- In `xgbe_dev_read()`, if a normal Rx descriptor has `RX_NORMAL_DESC3.LD == 0`, return `0` before setting `RX_PACKET_ATTRIBUTES_LAST`, reading `PL` (`rdata->rx.len`), or evaluating `ES`/`ETLT` errors. [F98]
- In `xgbe_rx_poll()`, while `!last || context_next` holds, `read_again` must keep consuming descriptors even after `error` is set; if `dev_read()` stops mid-packet, save `skb`, `len`, and `error` into `XGBE_GET_DESC_DATA(ring, ring->cur)->state` (`state_saved = 1`). `xgbe_unmap_rdata()` must clear `state_saved`, `state`, `mapped_as_page`, `rdata->rx`, and `rdata->tx`. [F49, F66, F100]
- In `xgbe_rx_poll()`, if `buf2_len > rdata->rx.buf.dma_len`, set `error = 1` before `skb_add_rx_frag()` so partial `skb` is freed after draining descriptors; before `napi_gro_receive()`, free `skb` if `skb->len > max_len` (`netdev->mtu + ETH_HLEN`, plus `VLAN_HLEN` when `!NETIF_F_HW_VLAN_CTAG_RX` and `skb->protocol == htons(ETH_P_8021Q)`). [F79, F80]
- In `xgbe_map_tx_skb()`, assign `rdata->skb` only to `XGBE_GET_DESC_DATA(ring, cur_index - 1)` after all mappings succeed, so on `err_out` `[start_index, cur_index)` unmaps via `xgbe_unmap_rdata()` without double-freeing `skb`. [F102]
- `xgbe_one_poll()` downcasts `napi` to `xgbe_channel` while `xgbe_all_poll()` downcasts to `xgbe_prv_data`: use `&channel->napi` when `pdata->per_channel_irq` is set and `&pdata->napi` otherwise. In `xgbe_all_poll()`, clamp `ring_budget` to `budget - processed` and stop when `processed == last_processed`. [F105, F127]
- Single-IRQ fallback in `xgbe_config_irqs()` sets `ecc_irq`, `i2c_irq`, and `an_irq` equal to `pdata->dev_irq`; requesting or freeing them in `xgbe_request/free_irqs()`, `xgbe_i2c_start/stop()`, and `xgbe_phy_start/stop()` must check `pdata->dev_irq != pdata->{ecc,i2c,an}_irq`. [F45]
- `xgbe_set_channels()` forbids both `rx_count` and `tx_count` non-zero, so `tx_ring` and `rx_ring` form contiguous prefixes of `pdata->channel[]` (which loops breaking on NULL rely on). When `xgbe_alloc_memory()` applies `new_{tx,rx}_ring_count`, it must set `pdata->tx_q_count = pdata->tx_ring_count` and zero `new_{tx,rx}_ring_count`. [F55, F84, F103]
- Update `pdata->rx_buf_size` via `xgbe_calc_rx_buf_size()` before allocating/reinitializing RX rings in `xgbe_alloc_memory()` or `xgbe_change_mtu()`. Toggling `NETIF_F_RXCSUM` in `xgbe_set_features()` must update split-header (`enable_sph`/`disable_sph`), VXLAN, and Rx checksum offload and schedule `pdata->restart_work`. [F56, F174]
- Callers of `xgbe_is_pfc_queue()` and `xgbe_calculate_dcb_fifo()` must check `pdata->pfc && pdata->ets` (both start `NULL`). `xgbe_config_queue_mapping()` must populate `pdata->q2tc_map[]` in contiguous ascending TC order (`0 .. tc_cnt - 1`) and `pdata->prio2q_map[]`. [F43, F77]
- In `xgbe_enable/disable_tx_flow_control()`, use `xgbe_get_fc_queue_count()` (`XGMAC_MAX_FLOW_CONTROL_QUEUES` when `SNPSVER >= 0x30`, else `min(tx_q_count, max_q_count)`). In `xgbe_set_promiscuous_mode()`, toggling `MAC_PFR.PR` must disable RX VLAN filtering on entry and restore it on exit if `NETIF_F_HW_VLAN_CTAG_FILTER` is set. [F59, F136]
- `xgbe_enable_int()` and `xgbe_disable_int()` must update `channel->curr_ier` before writing `DMA_CH_IER`, and `XGMAC_INT_DMA_ALL` must save/restore `channel->saved_ier`. [F60]
- In `xgbe_phy_status()`, return early without `netif_carrier_on()` or `xgbe_phy_adjust_link()` if `pdata->phy.link` is set and `xgbe_phy_status_result()` returns `true`; if `an_restart` is set, call `xgbe_phy_config_aneg()` and jump to `adjust_link`. In `xgbe_phy_adjust_link()`, copy `pdata->phy.{tx,rx}_pause` to `pdata->{tx,rx}_pause` before `config_{tx,rx}_flow_control()`. [F58, F70, F78]
- In `xgbe_an73_state_machine()`, when `an_state >= XGBE_AN_COMPLETE`, copy `an_state` to `an_result` and reset `an_state = XGBE_AN_READY`, `kr_state = kx_state = XGBE_RX_BPA`, and `an_start = 0`. In `xgbe_an73_incompat_link()`, set the current mode's state to `XGBE_RX_ERROR` and return `XGBE_AN_NO_LINK` unless the alternate mode is advertised and in `XGBE_RX_BPA`. [F68, F106]
- Because `MMC_CR.ROR = 1`, `xgbe_read_mmc_stats()` and `xgbe_{tx,rx}_mmc_int()` must accumulate (`+=`) into `pdata->mmc_stats`, with `xgbe_read_mmc_stats()` bracketing reads with `MMC_CR.MCF = 1`/`0`. In `xgbe_mmc_read()`, `MMC_RX{RUNTERROR,JABBERERROR,UNDERSIZE_G,OVERSIZE_G,WATCHDOGERROR}` are always 32-bit, whereas `MMC_*OCTETCOUNT_G*_LO` are always 64-bit. [F75, F137]
- Keep `xgbe_get_strings()`, `xgbe_get_ethtool_stats()`, and `xgbe_get_sset_count()` synchronized, and ensure all `xgbe_mmc_stats`/`xgbe_ext_stats` fields in `xgbe_gstring_stats[]` are `u64`. In `xgbe-phy-v1.c`, the six `xgbe_phy_*` default arrays must have at least `XGBE_SPEEDS` elements. [F76, F91, F121]

## Synchronization
- In `xgbe_dev_xmit()`, set `OWN` on subsequent descriptors before `dma_wmb()` and setting `OWN` on `start_index`, then `smp_wmb()` before `ring->cur = cur_index + 1` and `wmb()` in `xgbe_tx_start_xmit()` before writing `DMA_CH_TDTR_LO`. In `xgbe_rx_desc_reset()` and `xgbe_rx_refresh()`, order buffer addresses with `dma_wmb()` before `RX_NORMAL_DESC3.OWN`, then `dma_wmb()` and `wmb()` before `DMA_CH_RDTR_LO`; `xgbe_dev_read()` needs `dma_rmb()` after seeing `OWN == 0`. [F32, F161]
- In `xgbe_open()`/`xgbe_start()`, initialize workqueues/work items and call `xgbe_napi_enable(pdata, 1)` before `xgbe_request_irqs()` and `phy_if->phy_start()`. In `xgbe_stop()`, call `netif_carrier_off()` right after `netif_tx_stop_all_queues()`, and finish stopping timers, flushing `dev_workqueue`, disabling DMA/PHY, freeing IRQs, and disabling NAPI before unmapping/freeing rings. [F20, F21, F23]
- `stopdev_work` and `restart_work` must run on `system_wq` (never `pdata->dev_workqueue`, which `xgbe_stop()` flushes under RTNL) and hold `rtnl_lock()`. In `xgbe_stop_timers()`, call `timer_delete_sync(&pdata->service_timer)` before `timer_delete_sync(&channel->tx_timer)`, and keep `xgbe_service_timer()` arming `tx_timer` when `tx_usecs && !tx_timer_active`. [F33, F156, F157]
- `xgbe_isr_bh_work()` and `xgbe_tx_timer()` must use `__napi_schedule()` (not `_irqoff`). When `per_channel_irq` is set: `xgbe_isr_bh_work()` must clear `TI` and `RI` before writing `DMA_CH_SR`; when `channel_irq_mode == 0`, `xgbe_dma_isr()` and `xgbe_tx_timer()` must use `disable_irq_nosync(channel->dma_irq)` on `napi_schedule_prep()`, paired with `enable_irq()` in `xgbe_one_poll()`. [F104, F148, F159]
- `__xgbe_phy_config_aneg()` and `xgbe_an_state_machine()` must hold `pdata->an_mutex` (with `__xgbe_phy_config_aneg()` also calling `disable_irq`/`enable_irq(pdata->an_irq)` around mode/state resets), and `xgbe_an_irq_work()` must `flush_work(&pdata->an_work)` before `queue_work()`. Hold `xpcs_lock` via `spin_lock_irqsave()` in `xgbe_{read,write}_mmd_regs_v1/v2()`, `i2c_mutex` across `xgbe_i2c_xfer()`, and `rss_mutex` in process context in `xgbe_write_rss_reg()`. [F24, F150, F152, F153, F154]

## Object Lifetimes
- Unwind in reverse order: `xgbe_mod_init/exit()` (`xgbe_platform_exit()` then `unregister_netdevice_notifier()`); `xgbe_pci_probe/remove()` (`pci_dev_put(rdev)` before `err_pci_enable`, and on remove: `xgbe_deconfig_netdev()`, `pci_free_irq_vectors()`, `XP_INT_EN = 0`, `xgbe_free_pdata()`, while `xgbe_pci_resume()` writes `0x1fffff` to `XP_INT_EN`); `xgbe_open/close()` (`xgbe_stop()`, `xgbe_free_memory()`, `ptpclk`, `sysclk`, `an_workqueue`, `dev_workqueue`). [F1, F2, F3, F5, F130]
- `xgbe_start()` and `xgbe_stop()` must maintain `XGBE_STOPPED` in `pdata->dev_state` and unwind `phy_start`, IRQs, NAPI, and `hw_if->init`/`exit`. `xgbe_free_irqs()`, `xgbe_phy_stop()`, and `xgbe_i2c_stop()` must explicitly call `devm_free_irq()` and clear affinity hints. [F9, F11]
- `xgbe_free_memory()` must call `free_ring_resources()` before `xgbe_free_channels()`; `xgbe_free_channels()` must zero `pdata->channel[i]` and `channel_count`, and `xgbe_free_ring()` must null `rdata`, `rx_hdr_pa.pages`, `rx_buf_pa.pages`, and `rdesc`. `xgbe_dma_alloc_node()` must restore `set_dev_node(dev, cur_node)`. [F6, F7, F8, F19]
- `xgbe_set_buffer_data()` takes `get_page(pa->pages)` in `bd->pa` and moves `*pa` to `bd->pa_unmap` (clearing `*pa`) when remaining space `< len`; `xgbe_rx_poll()` must set `rdata->rx.buf.pa.pages = NULL` after `skb_add_rx_frag()`; `xgbe_unmap_rdata()` must unmap `mapped_as_page == 1` with `dma_unmap_page()` and `0` with `dma_unmap_single()`. In `xgbe_prep_tx_tstamp()`, hold `tstamp_lock` to either clear the PTP bit if `tx_tstamp_skb` is busy or set `tx_tstamp_skb = skb_get(skb)` and `SKBTX_IN_PROGRESS`. [F15, F165, F173, F176]

## API Contracts
- `xgbe_tx_complete()` returns `1` when CPU-owned (`!OWN`) and `0` when DMA-owned, whereas `xgbe_dev_read()` returns `0` when CPU-owned and `1` when DMA-owned. `XMDIO_READ/WRITE_BITS()` take a pre-shifted `_mask` and do not shift `_val` or the return value, unlike `XGMAC_IOWRITE_BITS()`. [F38, F50]
- `phy_impl.link_status` implementations must set `*an_restart = 0` before any non-negative return; only `an_pre/post`, `kr_training_pre/post`, `module_info`, and `module_eeprom` in `xgbe_phy_impl_if` are optional (null-checked). [F47, F126]
- `xgbe_alloc_pages()` runs in NAPI Rx refill and must use `GFP_ATOMIC`; `xgbe_create_skb()` and `xgbe_rx_poll()` must call `dma_sync_single_range_for_cpu(..., DMA_FROM_DEVICE)` on `rdata->rx.hdr` and `rdata->rx.buf`. [F149, F164]
- In `xgbe_prep_tso()`, call `skb_cow_head(skb, 0)` and adjust `tx_packets`/`tx_bytes` for `gso_segs`; balance `netdev_tx_sent_queue()` with `netdev_tx_completed_queue()` and `netdev_tx_reset_queue()`; kick `tx_start_xmit()` in `xgbe_maybe_stop_tx_queue()` if stopping while `ring->tx.xmit_more` is set. `xgbe_rx_poll()` counts only completed packets toward `budget`, and `napi_complete_done()` runs only when `processed < budget`. [F169, F170, F171, F172]
- Call `xgbe_prepare_tx_stop()` before disabling TX queues/DMA, and disable `MAC_RCR.RE` + call `xgbe_prepare_rx_stop()` before disabling RX queues/DMA; in `xgbe_config_dcb_pfc()`, stop TX and disable RX while `!XGBE_DOWN` around `xgbe_config_rx_fifo_size()`; `xgbe_exit()` must call `__xgbe_exit()` twice. `fifo[]` values in `xgbe-dev.c` are 0-based 256B (`XGMAC_FIFO_UNIT`) increments. [F53, F71, F72, F131]
- Set `IC_ENABLE.EN = 1` before `IC_ENABLE.ABORT = 1` in `xgbe_i2c_abort()`, and disable I2C before setting `IC_TAR` in `xgbe_i2c_xfer()`. Clear `MDIO_AN_CTRL1_ENABLE` in `xgbe_an37_init()` and set `XGBE_VEND2_MAC_AUTO_SW` in `xgbe_an37_set()`. In `xgbe_check_link_timeout()` (`XGBE_MODE_KR` + `AUTONEG_ENABLE`), wait `XGBE_AN_MS_TIMEOUT` from `kr_start_time` before restarting AN. [F73, F143, F144]
- `xgbe_setup_tc()` must accept any qdisc handle for `TC_SETUP_QDISC_MQPRIO`, set `TC_MQPRIO_HW_OFFLOAD_TCS`, and cap `num_tc <= tc_cnt`. When `hw_feat.vxn` is set, `xgbe_fix_features()` must keep `NETIF_F_GSO_UDP_TUNNEL` and `NETIF_F_RX_UDP_TUNNEL_PORT` paired and enable `NETIF_F_GSO_UDP_TUNNEL_CSUM` iff IP/IPv6 CSUM is set. [F168, F175]

## Error Handling
- `xgbe_alloc_pdata()` returns `ERR_PTR(-ENOMEM)` (use `IS_ERR()`); `xgbe_ptp_register()` must check `IS_ERR(clock)` before setting `pdata->ptp_clock`; `xgbe_alloc_pages()` must free pages and return `-ENOMEM` when `dma_mapping_error()` is true. [F34, F36, F44]
- `XMDIO_READ()`, `phy_impl.link_status()`, and `xgbe_read_ext_mii_regs*()` can return negative errnos; store in signed `int` and check `< 0`. Check `rx_frames`/`tx_frames != 0` before `%` in `xgbe_rx_desc_reset()` and `xgbe_dev_xmit()`. Use `dev_warn_once()` and disable SEC/DED interrupts on ECC threshold in `xgbe_ecc_sec/ded()`. [F35, F39, F113, F182]

## External Contracts
- `xgbe_dcb_setdcbx()` returns `u8` (`0` success, `1` failure). `xgbe_dcb_ieee_setets()` requires TC `< tc_cnt`, TSA in `{STRICT, ETS}`, and ETS weights summing to 100; `setpfc()` requires `pfc_en` within `(1 << tc_cnt) - 1`. [F40, F177]
- `xgbe_get_link_ksettings()` reports `SPEED_UNKNOWN`/`DUPLEX_UNKNOWN` when `!netif_carrier_ok()`. `xgbe_set_coalesce()` clamps non-zero `rx_coalesce_usecs` to `rx_riwt >= 1` and rejects `tx_usecs == 0` or out-of-range values. `xgbe_common_read/write()` in debugfs must check `*ppos != 0`, bounds-check `count`, and NUL-terminate `workarea[len]`. [F166, F179, F180]

## Known Pitfalls
- `GET_BITS*`/`SET_BITS*` require `_WIDTH < 31`. Widen 32-bit seconds/frequency to `u64` before multiplying by `NSEC_PER_SEC` or `<< 32`, and use `div_u64()` in `xgbe_init_ptp()`. Timeout loops testing `if (!count)` must pre-decrement (`while (--count && ...)`), and `jiffies` comparisons must use `time_before/after()`. [F96, F109, F111, F112, F118]
- In `xgbe_dev_read()`, `etlt == 0x09` is a C-TAG VLAN when `!err || !etlt` and a VXLAN checksum error when `err && etlt && tnp`; L4 `switch (l34t)` cases must end with `break`. Use `xgbe_change_mode()` for `XGBE_MODE_SFI` in `xgbe_phy_config_fixed()`, shift `mmd_address` in XPCS helpers (`<< 1` for V2/V3 with `offset % 4` word select on V3, `<< 2` on V1), and check `netdev->netdev_ops == xgbe_get_netdev_ops()` in `xgbe_netdev_event()`. [F69, F97, F99, F119, F128]
