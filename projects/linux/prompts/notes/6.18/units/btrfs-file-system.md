# BTRFS FILE SYSTEM

Implements the Btrfs copy-on-write filesystem, including B-tree traversal and delayed updates, extent and multi-device chunk allocation across RAID and zoned profiles, pagecache/subpage and direct I/O, compression, snapshots, send/receive, reflinks, and qgroup/squota accounting.

## Architecture & Data Flow
- Modifying slot 0 of any B-tree leaf or node (`btrfs_set_item_key_safe()`, `btrfs_truncate_item()`, `setup_items_for_insert()`, `btrfs_del_ptr()`, `btrfs_del_items()`, `__push_leaf_left()`, `split_leaf()`) requires calling `fixup_low_keys()` while ancestor nodes in `path` remain write-locked. [F71]
- Setting, clearing, or starting writeback on `EXTENT_BUFFER_DIRTY` (`set_extent_buffer_dirty()`, `btrfs_clear_buffer_dirty()`, `lock_extent_buffer_for_io()`) must update `fs_info->buffer_tree` `PAGECACHE_TAG_DIRTY`/`PAGECACHE_TAG_WRITEBACK` marks, `fs_info->dirty_metadata_bytes`, and folio dirty bits in lockstep. [F416]
- Every `btrfs_delayed_ref_node` in `btrfs_delayed_ref_head::ref_tree` must be linked on `ref_add_list` iff `action == BTRFS_ADD_DELAYED_REF`. Under `delayed_refs->lock`, `num_heads` tracks `tracked == true` heads and `num_heads_ready` tracks those with `!processing`. [F62, F64]
- When `tree->owner == IO_TREE_INODE_IO`, `set_state_bits()`, `clear_state_bit()`, `split_state()`, `merge_prev_state()`, `merge_next_state()`, and `insert_state()` must call the `btrfs_*_delalloc_extent()` helper on `tree->inode` and `add_extent_changeset()` before mutating `state->state`, `start`, or `end`. `EXTENT_LOCK_BITS | EXTENT_BOUNDARY` states must never merge, and clearing `EXTENT_DELALLOC` must also clear `EXTENT_NORESERVE`. [F208, F239, F240, F243]
- In `struct extent_map`, `disk_bytenr` is a logical disk address only when `< EXTENT_MAP_LAST_BYTE` (`(u64)-4`); for `EXTENT_MAP_HOLE` and `EXTENT_MAP_INLINE`, `offset` and `disk_num_bytes` must stay `0`. `btrfs_extent_map_end()`, `range_end()`, and `extent_map_block_end()` must clamp `u64` addition overflow to `(u64)-1`. [F392, F460]
- Adding or removing an `extent_map` on an fstree root (`add_extent_mapping()`, `remove_em()`) must update `fs_info->evictable_extent_maps` in lockstep (unlike `replace_extent_mapping()`). `btrfs_remove_extent_mapping()` and `replace_extent_mapping()` must call `RB_CLEAR_NODE(&em->rb_node)` and only `list_del_init(&em->list)` if `!(em->flags & EXTENT_FLAG_LOGGING)`. [F406, F407]
- In `fs/btrfs/subpage.c`, `btrfs_subpage_set_uptodate()` and `btrfs_subpage_set_checked()` set the VFS folio flag only when all sector bits are set (`subpage_test_bitmap_all_set()`), whereas dirty, writeback, and ordered bitmaps set the VFS flag on any bit and clear it only when `subpage_test_bitmap_all_zero()` holds. `btrfs_subpage_set_writeback()` must keep `PAGECACHE_TAG_TOWRITE` while `folio_test_dirty(folio)`. [F1045, F1046, F1047]
- In `fs/btrfs/space-info.c`, queued `reserve_ticket` entries add `ticket.bytes` to `space_info->reclaim_size` under `space_info->lock`; `remove_ticket()` must be called before zeroing `ticket->bytes`, and granting a ticket (`btrfs_try_granting_tickets()`, `steal_from_global_rsv()`) must increment `space_info->tickets_id`. [F1049, F1051]
- Inserting or removing a `btrfs_chunk_map` in `fs_info->mapping_tree` (`btrfs_add_chunk_map()`, `btrfs_remove_chunk_map()`) must update `CHUNK_ALLOCATED` (and clear `CHUNK_TRIMMED` on add) in each stripe device's `alloc_state` under `mapping_tree_lock`, and `BTRFS_BLOCK_GROUP_SYSTEM` chunk changes must update `super_copy->sys_chunk_array` via `btrfs_add_system_chunk()` / `btrfs_del_sys_chunk()` under `chunk_mutex`. [F1222, F1223]

## Synchronization
- Callers must release any locked `btrfs_path` (`btrfs_release_path()` / `btrfs_free_path()`) before calling `btrfs_release_delayed_node()`, `btrfs_is_data_extent_shared()`, `btrfs_iget()` (in `btrfs_search_path_in_tree_user()`), `btrfs_filldir()`, or `add_qgroup_item()`, and before copying to userspace in `extent_fiemap()` or `btrfs_encoded_read*()`. [F29, F364, F381, F579, F642, F658, F826, F866]
- In `btrfs_search_slot()` and `setup_nodes_for_search()`, if a node at `level` needs a write lock at `level` or `level + 1` and `write_lock_level` is lower, raise `write_lock_level`, call `btrfs_release_path(p)`, and restart from root. When `read_block_for_search()` reads from disk with `!p->skip_locking`, unlock above `parent_level`, read-lock `tmp`, release `p`, read, and return `-EAGAIN`. [F23, F25]
- Replacements of `root->node` (`btrfs_force_cow_block()`, `balance_level()`, `insert_new_root()`) must log the root replacement, increment `cow->refs`, and use `rcu_assign_pointer()`. `btrfs_root_node()` reads `root->node` under `rcu_read_lock()` with `refcount_inc_not_zero(&eb->refs)`, and `btrfs_*lock_root_node()` must reverify `eb == root->node` after locking `eb`. [F21, F156, F689]
- `btrfs_select_ref_head()` sets `head->processing = true`, decrements `num_heads_ready`, and locks `head->mutex` via `btrfs_delayed_ref_lock()` (which pins `head->refs` before dropping `delayed_refs->lock` and checks `head->tracked` after relocking); callers must release it via `btrfs_unselect_ref_head()` or `btrfs_delete_ref_head()` (requiring `delayed_refs->lock` -> `head->lock`). [F17, F34, F35, F376]
- Pagecache/delalloc lock order is `folio_lock()` (in ascending offset order, skipping `locked_folio`) -> `folio_wait_writeback()` -> `btrfs_lock_extent(&inode->io_tree, ...)` -> `write_lock(&inode->extent_tree.lock)`. Inside `inode->io_tree.lock`, `btrfs_*_delalloc_extent()` nests `inode->lock` or `root->delalloc_lock` -> `fs_info->delalloc_root_lock`. [F19, F351, F485, F487, F639]
- In `lock_extent_direct()`, acquire `EXTENT_DIO_LOCKED` before `EXTENT_LOCKED` on `inode->io_tree`, unlock `EXTENT_LOCKED` before waiting on `btrfs_start_ordered_extent()` (or return `-ENOTBLK`/`-EAGAIN` on DIO read if `!BTRFS_ORDERED_DIRECT`), and unlock `EXTENT_DIO_LOCKED` on error. In `btrfs_lock_and_flush_ordered_range()`, unlock `io_tree` before `btrfs_start_ordered_extent()` and relock in a loop. [F179, F196, F699]
- `fs_info->buffer_tree.xa_lock`, `fs_info->delayed_iput_lock`, `btrfs_inode::ordered_tree_lock`, `btrfs_root::ordered_extent_lock`, and `btrfs_folio_state::lock` are acquired in IRQ bio endio context and must always be taken with interrupts disabled (`*_irq` / `*_irqsave`); never take `eb->refs_lock` inside `buffer_tree.xa_lock`. Drop `ordered_tree_lock` before `btrfs_queue_ordered_fn()` and `delayed_iput_lock` before `iput()`. [F318, F365, F478, F537, F693, F776, F804, F807, F1136]
- Lock hierarchies: `dev_replace->lock_finishing_cancel_unmount` / `sb->s_umount` -> `uuid_mutex` -> `fs_devices->device_list_mutex` -> `fs_info->chunk_mutex` -> `dev_replace->rwsem` (or `zone_active_bgs_lock` -> `block_group->lock`); `space_info->lock` -> `block_group->lock` / `block_rsv->lock` -> `treelog_bg_lock` -> `relocation_bg_lock` -> `ctl->tree_lock`; in `raid56.c`, `table->cache_lock` -> `h->lock` -> `rbio->bio_list_lock`. Never call `btrfs_free_dev_extent()` under `chunk_mutex`. [F313, F490, F874, F1141, F1186, F1304, F1310, F1332]
- When `current->journal_info != NULL` (open transaction), callers must not use `BTRFS_RESERVE_FLUSH_ALL*`, `BTRFS_RESERVE_FLUSH_EVICT`, or `BTRFS_RESERVE_FLUSH_DATA` in `__reserve_bytes()`, call `try_flush_qgroup()` or `btrfs_qgroup_reserve_*` with `!noflush`, call `btrfs_wait_ordered_roots()` in `shrink_delalloc()`, or call `btrfs_truncate_block()`. Inode eviction (`evict_refill_and_join()`) must use `BTRFS_RESERVE_FLUSH_EVICT` and `btrfs_join_transaction()`. [F152, F538, F653, F972, F1138, F1139]

## Object Lifetimes
- Before freeing a dirtied tree block with `btrfs_free_tree_block()` (`insert_new_root()`, `balance_level()`, `btrfs_del_items()`, `create_subvol()`), `btrfs_clear_buffer_dirty()` must be called. In `btrfs_del_leaf()`, `refcount_inc(&leaf->refs)` must be taken before `btrfs_free_tree_block()` + `free_extent_buffer_stale(leaf)` so `path->nodes[0]` retains a valid reference until `btrfs_release_path()`. [F1, F5, F670]
- `release_extent_buffer(eb)` requires `eb->refs_lock` held on entry and unconditionally unlocks it on all return paths; mapped buffers are freed via `call_rcu()` so lockless `fs_info->buffer_tree` lookups under `rcu_read_lock()` can use `refcount_inc_not_zero(&eb->refs)`. In `eb_batch` iteration (`btree_write_cache_pages()`), references are owned by `eb_batch_release()`. [F345, F347, F479]
- `btrfs_submit_compressed_read()` and `btrfs_submit_compressed_write()` consume the caller's `bbio` and `compressed_folios`. In `btrfs_finish_compressed_write_work()`, `btrfs_finish_ordered_extent()` must run before `end_compressed_writeback()`, and `cb->bbio.inode` must never be dereferenced after `end_compressed_writeback()` clears folio writeback. [F6, F7, F161]
- Before clearing `folio_extent_mapped` on a subpage folio in `__btrfs_release_folio()` or `btrfs_invalidate_folio()`, `wait_subpage_spinlock(folio)` must run after `folio_wait_writeback(folio)` (and before checking `Ordered` bits in `btrfs_invalidate_folio()`) so concurrent bio endio handlers finish releasing `bfs->lock` before `folio->private` is freed. [F533, F534]
- `btrfs_remove_ordered_extent()` unlinks an ordered extent from `inode->ordered_tree` (clearing `ordered_tree_last` if equal) and `root->ordered_extents` without dropping `entry->refs`; `btrfs_put_ordered_extent()` requires `rb_node`, `root_extent_list`, and `log_list` to be empty. In `btrfs_finish_one_ordered()`, COW error/full-truncation paths before extent insertion must free the reserved disk extent and `qgroup_rsv` before removing and double-putting `ordered_extent`. [F524, F665, F695]
- `btrfs_qgroup_release_data()` clears `EXTENT_QGROUP_RESERVED` in `inode->io_tree` while keeping `BTRFS_QGROUP_RSV_DATA` for delayed-ref commit once an ordered/file extent is created, whereas `btrfs_qgroup_free_data()` (or `btrfs_qgroup_free_refroot(..., BTRFS_QGROUP_RSV_DATA)` if `alloc_ordered_extent()` / `insert_prealloc_file_extent()` fails after `btrfs_qgroup_release_data()`) must be used on error or invalidation. [F522, F664, F846]

## API Contracts
- `btrfs_search_slot()` requires `p->nodes[0] == NULL`, `cow != 0` when `ins_len != 0`, `cow == 0` when `p->nowait`, and `p->skip_locking == 1` when `p->search_commit_root` (required by `p->need_commit_sem`). It returns `< 0` (releasing `p` unless `p->skip_release_on_error`), `0` (found), or `> 0` (not found). `btrfs_insert_empty_items()` converts `0` into `-EEXIST` while leaving `path` populated and write-locked. [F3, F45, F46, F47, F154, F556]
- On success, `btrfs_force_cow_block()` (and `btrfs_cow_block()` when it COWs) consumes the caller's `buf` reference via `free_extent_buffer_stale(buf)`, unlocks `buf` if `*cow_ret == buf`, and returns the new write-locked buffer in `*cow_ret`; on error, `buf` remains locked and referenced by the caller. `btrfs_drop_subtree()` consumes the caller's lock and ref on `node` while preserving `parent`'s. [F2, F361]
- Ownership transfers: `btrfs_add_delayed_tree_ref()`, `btrfs_add_delayed_extent_op()`, `btrfs_lru_cache_store()`, and `btrfs_qgroup_trace_extent_nolock()` consume their input pointer only on `0` return; `lock_stripe_add(rbio)` consumes `rbio` on `1`; `add_qgroup_rb()`, `__add_relation_rb()`, `btrfs_add_qgroup_relation()`, `btrfs_qgroup_account_extent()`, and `btrfs_balance()` (`bctl`/exclop) consume unconditionally. [F15, F668, F675, F676, F838, F839, F840, F850, F1174]
- Range conventions: all `extent_io_tree` helpers, `extent_clear_unlock_delalloc()`, `btrfs_drop_extent_map_range()`, `fiemap_process_hole()`, `btrfs_lock_and_flush_ordered_range()`, and `btrfs_try_lock_ordered_range()` take an inclusive `[start, end]` byte range, whereas `btrfs_cleanup_ordered_extents()`, `btrfs_lookup/wait_ordered_range()`, `btrfs_finish_ordered_extent()`, `btrfs_lookup/search/split_extent_map*()`, `btrfs_unpin_extent_cache()`, and `extent_fiemap()` take `(start, len)`. [F293, F403, F546, F715]
- `btrfs_remove_extent_mapping()` and `replace_extent_mapping()` do not decrement the removed `extent_map`'s refcount; callers must call `btrfs_free_extent_map()`. In `btrfs_add_extent_mapping()`, on `-EEXIST` merge or failure it may free and replace or NULL out `*em_in`, so callers must use `*em_in`. [F354, F355]

## Error Handling
- When a fallible call assigned to a pointer cleaned up at an `out:` label (`root->node`, `fs_info->fs_root`, `trans` in `btrfs_finish_one_ordered()`/`btrfs_link()`/`btrfs_truncate()`, `root`/`ipath`/`bargs` in `ioctl.c`, or `fs_root` in `btrfs_get_subvol_name_from_objectid()`) returns `IS_ERR()`, reset the pointer to `NULL` before jumping to cleanup (or guard with `!IS_ERR_OR_NULL()` as for `sctx->parent_root`). [F219, F555, F719, F1030, F1043]
- On error in `cow_file_range()`, `out_unlock` must split cleanup into `[orig_start, start - 1]` (`btrfs_cleanup_ordered_extents()` without `EXTENT_DO_ACCOUNTING`), `[start, start + cur_alloc_size - 1]` (`EXTENT_CLEAR_META_RESV` without `EXTENT_CLEAR_DATA_RESV`), and `[start + cur_alloc_size, end]` (adding `EXTENT_CLEAR_DATA_RESV`). If `btrfs_reloc_clone_csums(ordered)` fails, advance `start += cur_alloc_size` and zero `cur_alloc_size` first. [F517, F518, F567]

## Known Pitfalls
- `btrfs_item_ptr()` returns an extent-buffer byte offset cast to a typed pointer, never a kernel virtual address: access it only via `extent_buffer` helpers (`read/write/memzero_extent_buffer()`), cast to `char *` or `unsigned long` before byte-offset arithmetic, and recompute leaf item pointers (`ei`, `iref`, `di`) after `btrfs_extend_item()`, `btrfs_truncate_item()`, or `btrfs_delete_one_dir_name()`. `memmove_leaf_data()`/`copy_leaf_data()` take offsets relative to `btrfs_item_nr_offset(leaf, 0)`, not `btrfs_item_ptr_offset()`. [F135, F137, F298, F469, F630, F1229]
- XArray indexing and 32-bit limits: `delayed_refs->head_refs` and `dirty_extents` are indexed by `bytenr >> fs_info->sectorsize_bits` (widening `index` to `u64` before `<< sectorsize_bits` in `btrfs_qgroup_account_extents()`), whereas `fs_info->buffer_tree` is indexed by `bytenr >> fs_info->nodesize_bits`. On 32-bit (`BITS_PER_LONG == 32`), `add_delayed_ref_head()`, `btrfs_qgroup_trace_extent_nolock()`, `alloc_extent_buffer()`, and `check_32bit_meta_chunk()` must reject `bytenr >= MAX_LFS_FILESIZE` with `-EOVERFLOW`. [F81, F158, F465, F928, F952, F1214, F1256]
- 64-bit arithmetic and 32-bit shifts: use `div_u64()`/`div64_u64()`/`DIV_ROUND_UP_ULL()` (such as `count_max_extents()` and `btrfs_csum_bytes_to_leaves()`) instead of `/` or `%` on `u64` dividends; widen 32-bit values to `u64` before shifting (`SZ_16K` in `btrfs_sb_offset()`, `high_crc << 31` in `hash_extent_data_ref()`, `ULONG_MAX` in `BTRFS_32BIT_MAX_FILE_SIZE`, `stripe_nr` via `btrfs_stripe_nr_to_offset()`, `zone_number` in `zoned.c`) or multiplying (`outstanding_extents * nodesize`, `kbps_limit * SZ_1K`). [F122, F129, F290, F291, F462, F618, F784, F1280, F1281, F1288]
- When inspecting a `struct btrfs_file_extent_item`, check `btrfs_file_extent_type(leaf, ei) == BTRFS_FILE_EXTENT_INLINE` before reading `btrfs_file_extent_disk_bytenr(leaf, ei)` (which aliases the inline payload) or treating `disk_bytenr == 0` as a hole, and use `btrfs_file_extent_inline_start(ei)` / `btrfs_file_extent_calc_inline_size()` rather than `ei + 1`. [F442, F626, F935]
- In `btrfs_clear_extent_bit_changeset()`, `set_extent_bit()`, and `btrfs_convert_extent_bit()`, `state->end` must be saved into `last_end` before calling `clear_state_bit()` or `merge_state()`, and loop progress must check `last_end >= end` and advance `start = last_end + 1` rather than reading `state->end`. [F279]
- Every function that populates a list with `qgroup_iterator_add()` or `qgroup_iterator_nested_add()` must empty it with `qgroup_iterator_clean()` or `qgroup_iterator_nested_clean()` under `fs_info->qgroup_lock`, because the add helpers silently skip any `btrfs_qgroup` whose iterator `list_head` is non-empty. [F938]
