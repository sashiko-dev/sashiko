# GENERIC INCLUDE/ASM HEADER FILES

Provides architecture-independent fallback implementations, default macros, inline primitives, linker script templates, and UAPI ABI definitions under `include/asm-generic/` and `include/uapi/asm-generic/`. Architectures include or inherit these headers for MMIO and port I/O accessors, memory barriers, atomic/non-atomic bitops, queued/ticket spinlocks, per-CPU operations, page table allocation, user-memory access, 64-bit division, and standard syscall/signal/ioctl UAPI definitions.

## Architecture & Data Flow
- `pmd_alloc_one_noprof()`, `__pud_alloc_one_noprof()`, `__p4d_alloc_one_noprof()`, and `__pgd_alloc_noprof()` must switch from `GFP_PGTABLE_USER` to `GFP_PGTABLE_KERNEL` when `mm == &init_mm`; `__pte_alloc_one_kernel_noprof()`, `__pud_alloc_one_noprof()`, `__p4d_alloc_one_noprof()`, and `__pgd_alloc_noprof()` must strip `__GFP_HIGHMEM` before `pagetable_alloc_noprof()` since they return direct kernel virtual addresses via `ptdesc_address()`. [F4, F121]
- In `include/asm-generic/vmlinux.lds.h`, `DATA_DATA` must place `*(.data..do_once)` outside `[__start_once, __end_once]` (which bounds `*(.data..once)`) so `clear_warn_once` does not reset `DO_ONCE()` state, and must include `*(.data..decrypted)` and `*(.data..shared_aligned)` so `!CONFIG_SMP` per-CPU variables (`PER_CPU_BASE_SECTION == ".data"`) land in `.data`. [F37, F127]
- In `include/asm-generic/vmlinux.lds.h`, `BOUNDED_SECTION_{PRE,POST}_LABEL()` must place only `KEEP(*(_sec_))` between labels (use `HEADERED_SECTION_*_LABEL()` for `.gnu.linkonce.` headers), `NOINSTR_TEXT` must keep `*(.noinstr.text)` and `*(.cpuidle.text)` within `[__noinstr_text_start, __noinstr_text_end]`, `SCHED_DATA` must keep scheduler classes in descending priority (`__stop`, `__dl`, `__rt`, `__fair`, `__ext`, `__idle`), and `TEXT_TEXT` must place specific `.text.<subsec>` matches before `*(TEXT_MAIN .text.fixup)`. [F69, F126, F130, F144]
- In `include/asm-generic/vmlinux.lds.h`, `_OF_TABLE_1(name)` must follow `KEEP(*(__<name>_of_table))` with `KEEP(*(__<name>_of_table_end))` in `INIT_DATA` while `.pci_fixup` and `FW_LOADER_BUILT_IN_DATA` stay in `RO_DATA`; `NOTES` must `/DISCARD/` `*(.note.GNU-stack)` and `*(.note.gnu.property)` before `.notes`; `SANITIZER_DISCARDS` must cover `CONFIG_GCOV_KERNEL`, `CONFIG_KASAN_GENERIC`, and `CONFIG_KCSAN`. [F111, F128, F142]
- In 32-bit `do_div(n, base)` (`include/asm-generic/div64.h`), `is_power_of_2(__base)` must precede `__builtin_constant_p(__base) && __base != 0` because `__div64_const32()` divides by zero when `___b` is a power of two, and runtime dividends with `(n >> 32) != 0` must dispatch to `__div64_32(&(n), __base)`. [F78, F89]
- In `include/asm-generic/cmpxchg-local.h`, `__generic_cmpxchg_local()` must mask `old` and `new` to `0xffu`/`0xffffu`/`0xffffffffu` in 1/2/4-byte cases before comparing against `prev` and reject `size == 8` when `sizeof(unsigned long) != 8` via `wrong_size_cmpxchg(ptr)`. In `include/asm-generic/mmiowb.h`, `mmiowb_set_pending()` must only set `ms->mmiowb_pending` when `ms->nesting_count` is non-zero, and `mmiowb_spin_unlock()` must clear `ms->mmiowb_pending = 0` before calling `mmiowb()`. [F36, F84]
- Under `CONFIG_UACCESS_MEMCPY` (`include/asm-generic/uaccess.h`), `__get_user_fn()`, `__put_user_fn()`, and `__{get,put}_kernel_nofault()` must use `{get,put}_unaligned()` for multi-byte transfers; in `include/asm-generic/flat.h`, `flat_{get,put}_addr_*_rp()` must use `copy_{from,to}_user()` when `!CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`; in `include/asm-generic/cacheflush.h`, `copy_to_user_page()` must call `flush_icache_user_page()` after `memcpy()`. [F61, F62, F122]
- Under `CONFIG_FLATMEM` (`memory_model.h`), `pfn_valid(pfn)` must check `pfn >= ARCH_PFN_OFFSET` before `(pfn - ARCH_PFN_OFFSET) < max_mapnr`; in `fixmap.h`, `virt_to_fix(vaddr)` requires `vaddr` in `[FIXADDR_START, FIXADDR_TOP)` and indices grow downward from `FIXADDR_TOP`; in `sections.h`, generic code must not reference `_text`/`_data`, `__is_kernel()` must check both `[_stext, _end)` and `[__init_begin, __init_end)`, and `memory_intersects()` must test `virt < end && vend > begin`. [F53, F54, F55, F129]

## Synchronization
- In `qspinlock_types.h` and `qrwlock_types.h`, sub-word union fields (`locked`, `pending`, `locked_pending`, `tail`, `wlocked`) must reverse byte order between `#ifdef __LITTLE_ENDIAN` and `#else` so `locked`/`wlocked` alias bits 0..7; `queued_spin_unlock()` and `queued_write_unlock()` must only store `0` to `lock->locked`/`lock->wlocked` via `smp_store_release()`, `queued_spin_is_locked()` must test the full 32-bit `atomic_read(&lock->val)`, and `queued_spin_is_contended()` must test `atomic_read(&lock->val) & ~_Q_LOCKED_MASK`. [F39, F40, F67, F79]
- In `include/asm-generic/qrwlock.h`, after atomically adding `_QR_BIAS`, `queued_read_trylock()` and `queued_read_lock()` must test `!(cnts & _QW_WMASK)` (checking both `_QW_LOCKED` and `_QW_WAITING`), where `queued_read_trylock()` subtracts `_QR_BIAS` on failure while `queued_read_lock()` calls `queued_read_lock_slowpath(lock)` without subtracting `_QR_BIAS` first because the slowpath decrements the speculative reader bias. [F6, F80]
- In `include/asm-generic/ticket_spinlock.h`, `ticket_spin_lock()`'s contended path must emit `smp_mb()` after `atomic_cond_read_acquire()` for RCsc ordering, `ticket_spin_unlock()` must update only the low 16-bit serving half via `u16 *ptr = (u16 *)lock + IS_ENABLED(CONFIG_CPU_BIG_ENDIAN)` and `smp_store_release(ptr, (u16)val + 1)`, and `ticket_spin_is_contended()` must cast `(val >> 16) - (val & 0xffff)` to `s16` before comparing `> 1`. [F15, F41, F94]
- In `include/asm-generic/bitops/`, `arch_test_and_{set,clear,change}_bit()` must unconditionally run `raw_atomic_long_fetch_*()` without an early `READ_ONCE()` short-circuit; `arch___clear_bit_unlock()` and `__clear_bit_unlock()` are non-atomic RMWs and require no concurrent updates to other bits in the same word; `generic_test_bit()` must keep `const volatile unsigned long *` on `addr` and both `generic_test_bit()` and `generic_test_bit_acquire()` must mask `nr` with `(BITS_PER_LONG - 1)`. [F8, F9, F10, F90]
- In `include/asm-generic/barrier.h`, `smp_mb__after_switch_mm()` must default to `smp_mb()`, `virt_*` barriers (`virt_mb()`, `virt_rmb()`, `virt_wmb()`, `virt_store_mb()`, `virt_mb__{before,after}_atomic()`, `virt_store_release()`, `virt_load_acquire()`) must expand to `__smp_*` even when `!CONFIG_SMP`, and `smp_cond_load_relaxed(ptr, cond_expr)` must cache `ptr` once in `__PTR` outside the loop and load `READ_ONCE(*__PTR)` into `VAL`. [F12, F13, F81]
- In `include/asm-generic/percpu.h`, `this_cpu_generic_read()` may use `preempt_disable_notrace()` only when `__native_word(pcp)` is true while non-native reads and all `this_cpu_generic_*` RMW macros must use `raw_local_irq_save()`. In `include/asm-generic/rwonce.h`, `read_word_at_a_time()` and `__read_once_word_nocheck()` must be `__no_sanitize_or_inline`, and `read_word_at_a_time()` must check 1 byte via `kasan_check_read(addr, 1)` and `kcsan_check_read(addr, 1)` before `*(unsigned long *)addr` (not `READ_ONCE()`). [F11, F17, F124]

## Object Lifetimes
- In `pte_free_kernel()`, `pte_free()`, `pmd_free()`, `__pud_free()`, `__p4d_free()`, and `__pgd_free()`, constructed page tables must be freed with `pagetable_dtor_free()`, whereas if `pagetable_pte_ctor()` or `pagetable_pmd_ctor()` returns `false` in `__pte_alloc_one_kernel_noprof()`, `__pte_alloc_one_noprof()`, or `pmd_alloc_one_noprof()`, the unconstructed `ptdesc` must be freed with `pagetable_free(ptdesc)` before returning `NULL`. [F1, F2]

## API Contracts
- In `include/asm-generic/pgalloc.h`, `__pte_alloc_one_noprof()` and `pte_alloc_one_noprof()` return `pgtable_t` (`struct page *`) via `ptdesc_page()` for `pte_free()`, whereas `__pte_alloc_one_kernel_noprof()` and `pmd_alloc_one_noprof()` return virtual addresses via `ptdesc_address()`; when page-table levels are folded (`pgtable-no{p4d,pud,pmd}.h`), `{p4d,pud,pmd}_alloc_one()` evaluate to `NULL` while `pgd_present()` is `1` (`pgd_none()`/`pgd_bad()` are `0`), and `p4d_free()` must guard `__p4d_free()` with `!mm_p4d_folded(mm)`. [F23, F24]
- In `include/asm-generic/uaccess.h`, `put_user()`, `get_user()`, and `clear_user()` invoke `might_fault()` (sleepable context only, unlike `__*` variants), `put_user()`/`get_user()` must cast `void __user *__p` back to `(__typeof__(*(ptr)) __user *)__p` so `__put_user()`/`__get_user()` dispatch on `sizeof(*(ptr))` (1, 2, 4, or 8 bytes), and `__get_user_fn(size, from, to)` and `__put_user_fn(size, to, from)` take the `__user` pointer second and kernel pointer third (whereas `raw_copy_{from,to}_user(to, from, n)` take `(dst, src, n)`). [F22, F98, F113]
- In `include/asm-generic/io.h`, `read{b,w,l,q}()` and `write{b,w,l,q}()` convert little-endian MMIO to/from CPU endianness with `__io_{br,ar,bw,aw}()` barriers (`_relaxed` omits barriers), both must guard `log_{read,post_read,write,post_write}_mmio()` with `rwmmio_tracepoint_enabled()`, `_in{b,w,l}()` must return `u8`/`u16`/`u32` from `PCI_IOBASE + addr` with `__io_{pbr,par}()`, and generic `ioremap_np()`/`ioremap_uc()` return `NULL` so portable `ioremap_np()` callers must fall back to `ioremap()`. [F105, F106, F108, F110]
- All bitops in `include/asm-generic/bitops/` (including `*_bit_le()` in `le.h`, which must XOR `nr` with `BITOP_LE_SWIZZLE`) index `addr + BIT_WORD(nr)` as `unsigned long *`, requiring `sizeof(unsigned long)`-aligned/sized buffers; `ffs()`, `fls()`, and `fls64()` return 0 on 0 and 1-based positions otherwise, whereas `__ffs()` and `__fls()` return 0-based indices and are undefined on 0 (`ffz(x)` is undefined on `~0UL`), and `sched_find_first_bit()` requires a 100-bit bitmap with at least one bit set. [F25, F59, F100, F101]
- `get_order(size)` (`getorder.h`) is undefined when `size == 0` and must subtract 1 from `size` before shifting by `PAGE_SHIFT`; in `delay.h`, `ndelay()`, `udelay()`, and `mdelay()` are the only atomic-context delays (`mdelay()` required above `MAX_UDELAY_MS`), and `udelay()`/`ndelay()` require constants `< DELAY_CONST_MAX` (`20000`) and must dispatch to their respective `UDELAY_*`/`__udelay`/`__bad_udelay` vs `NDELAY_*`/`__ndelay`/`__bad_ndelay` helpers. [F26, F27, F92, F112]
- Callers of `atomic_try_cmpxchg_acquire()` in `qspinlock.h`/`qrwlock.h` must declare the expected-value temporary as initialized signed `int`; `raw_cpu_generic_try_cmpxchg()` and `__cpu_fallback_try_cmpxchg()` (`percpu.h`) must sample `*(ovalp)` into a local temporary once and update `*(ovalp)` only on failure; in `word-at-a-time.h`, both endianness branches of `has_zero(val, data, c)` must return `unsigned long` and store `*data`, which callers must pass through `prep_zero_mask()` and `create_zero_mask()` before `find_zero()`/`zero_bytemask()`. [F28, F35, F43, F45]
- In `hugetlb.h`, `huge_ptep_get()` must use `ptep_get(ptep)` rather than `READ_ONCE(*ptep)`, and `__HAVE_ARCH_HUGE_*` fallbacks (`huge_pte_clear()`, `set_huge_pte_at()`, `huge_ptep_get_and_clear()`) must keep parameter lists (including `unsigned long sz`) in lockstep with arch headers; in `compat.h`, `compat_arg_u64()` and `compat_arg_u64_dual()` must order `(lo, hi)` on little-endian and `(hi, lo)` on `CONFIG_CPU_BIG_ENDIAN`; in `uapi/asm-generic/fcntl.h`, `struct flock`/`flock64` must remain inside `#ifndef HAVE_ARCH_STRUCT_FLOCK`. [F47, F49, F120, F138]
- `do_div(n, base)` updates 64-bit lvalue `n` with the quotient and returns the 32-bit remainder; `csum_partial()` requires even `len` on non-final fragments and `ip_fast_csum(iph, ihl)` takes `ihl` in 32-bit words; `xor_{8,32}regs_*()` require `@bytes` to be a positive multiple of `8 * sizeof(long)`; `may_use_simd()` returns `!in_interrupt()`; `__local{,64}_{inc,dec,add,sub}()` require preemption disabled and no IRQ access; `set_irq_regs()` returns the previous `pt_regs *` to be restored on IRQ exit. [F29, F33, F104, F114, F117, F119]

## Error Handling
- In `include/asm-generic/uaccess.h`, `raw_copy_{from,to}_user()`, `__clear_user()`, and `clear_user()` return uncopied/uncleared byte counts (`0` on success), whereas `__{get,put}_user_fn()` must convert non-zero residuals to `-EFAULT`, and `get_user(x, ptr)` / `__get_user(x, ptr)` must zero-initialize `x` on every failure path (both `access_ok()` failure and `__get_user_fn()` failure in any 1, 2, 4, or 8-byte case). [F20, F83]
- In `include/asm-generic/bug.h`, `WARN_ON_SMP(x)` expands to `({0;})` without evaluating `x` when `!CONFIG_SMP`, `!CONFIG_BUG` `WARN(cond, fmt...)` must pass `fmt` to `no_printk(fmt)`, `void __warn(...)` must stay outside `#ifdef CONFIG_BUG`, `__WARN_printf()` must bracket `warn_slowpath_fmt()`/`__warn_printk()` and `__WARN_FLAGS()` with `instrumentation_{begin,end}()`, `WARN*()` must never be used for user input or transient errors (`ENOMEM`), and `BUG*()` is only for unrecoverable corruption. [F34, F102, F125, F131, F132, F133]

## External Contracts
- In `uapi/asm-generic/unistd.h`, `__NR_*`, `__SYSCALL()`, and `__NR_syscalls` must stay in lockstep with `scripts/syscall.tbl` (no arch-only syscalls), and compat/signed-`long` syscalls must use `__SC_COMP()`/`__SC_COMP_3264()`; in `siginfo.h`, `union __sifields` must avoid 64-bit/>4B-aligned types on 32-bit and `_sigfault._addr_{bnd,pkey}` must keep `_dummy_{bnd,pkey}[__ADDR_BND_PKEY_PAD]`; in 32-bit `{sem,msq,shm}id64_ds` and `compat_*64_ds`, low `*_time` must precede `*_time_high` even on big-endian. [F48, F63, F64, F66, F135]
- In `uapi/asm-generic/fcntl.h`, `O_SYNC` is `(__O_SYNC | O_DSYNC)` and `O_TMPFILE` is `(__O_TMPFILE | O_DIRECTORY)` (never use `__O_SYNC`/`__O_TMPFILE` alone); in `ioctl.h`, `_IOC()` requires `sizeof(t) < (1 << _IOC_SIZEBITS)` with `_IOR` = user reads and `_IOW` = user writes; in `access_ok.h`, `__access_ok(ptr, size)` must check `(size <= limit) && (addr <= (limit - size))` against a constant `TASK_SIZE_MAX`; in `vmlinux.lds.h`, `ORC_UNWIND_TABLE` must emit `.orc_header` and size `.orc_lookup` with `+ 1` sentinel entry. [F71, F137, F140, F141]

## Known Pitfalls
- In `include/asm-generic/io.h`, repeated string I/O helpers (`reads{b,w,l,q}()`, `writes{b,w,l,q}()`, `ins{b,w,l}()`, `outs{b,w,l}()`, and `ioread/iowrite*_rep()`) take `@count` as an element count (unlike byte-sized `memset_io()` and `memcpy_{from,to}io()`), must guard `do { ... } while (--count);` with `if (count)`, and must advance only `buf++` at a fixed FIFO `addr` (use `memcpy_{from,to}io()` for contiguous MMIO ranges). [F82, F99, F109]
- In `percpu.h`, inner macros `raw_cpu_generic_try_cmpxchg()` and `__this_cpu_generic_read_*()` must use three-underscore locals (`___old`, `___ret`, `___flags`) to avoid shadowing outer macros; in `pgalloc.h`, each alloc/free helper must use its own `#ifndef __HAVE_ARCH_*` guard; in `topology.h`, unused macro args cast to `(void)` in comma expressions must be parenthesized as `(void)(arg)`. [F75, F76, F77]
- In `include/asm-generic/vmlinux.lds.h`, `FTRACE_STUB_HACK` must only alias `ftrace_stub_graph = ftrace_stub` when `!CONFIG_ARCH_SUPPORTS_CFI` (avoiding KCFI prototype-mismatch traps), and `{TEXT,DATA,SDATA,BSS,SBSS}_MAIN` must match subsections with `.[0-9a-zA-Z_]*` and explicit `..L*`/`..compoundliteral*` patterns rather than bare `.*` so kernel double-dot sections (like `.data..percpu` or `.bss..page_aligned`) are not absorbed. [F96, F143]
