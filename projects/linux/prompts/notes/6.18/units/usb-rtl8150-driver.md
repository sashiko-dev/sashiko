# USB RTL8150 DRIVER

The USB RTL8150 driver (`drivers/net/usb/rtl8150.c`) supports Realtek RTL8150-based USB 1.1 Fast Ethernet controllers. It bridges the Linux networking stack (`net_device_ops`, `ethtool_ops`) with the USB core (`usb_driver`), using synchronous and asynchronous USB control transfers for register and MII access, bulk URBs for packet RX/TX, an interrupt URB for link and TX error status, and a tasklet-backed SKB pool (`dev->rx_skb_pool`) for RX buffer replenishment.

## Architecture & Data Flow
- In `read_bulk_callback` and `rx_fixup`, `RX_URB_FAIL` in `dev->flags` must be set only when `usb_submit_urb(dev->rx_urb, GFP_ATOMIC)` fails after `dev->rx_skb` and `dev->rx_urb` are populated, and cleared on successful submission, because `rx_fixup` skips `pull_skb` and reuses `dev->rx_skb` whenever `RX_URB_FAIL` is set. Broken by: setting `RX_URB_FAIL` when `pull_skb` returns `NULL` after `netif_rx(dev->rx_skb)`. [F23]
- Whenever `dev->rx_skb` is replaced with a new buffer from `pull_skb` (in `rtl8150_open`, `read_bulk_callback`, or `rx_fixup`), `pull_skb` must first check for `NULL` and clear the `dev->rx_skb_pool[i] = NULL` slot (so `fill_skb_pool` refills it and `free_skb_pool` does not double-free it), and the caller must re-initialize `dev->rx_urb` via `usb_fill_bulk_urb` with `dev->rx_skb->data` before calling `usb_submit_urb`. [F18, F24, F25]
- `fill_skb_pool` must allocate each RX `sk_buff` with at least `RTL8150_MTU + 2` bytes when reserving 2 bytes via `skb_reserve(skb, 2)`, because `rtl8150_open`, `read_bulk_callback`, and `rx_fixup` configure `dev->rx_urb` to DMA up to `RTL8150_MTU` bytes into `dev->rx_skb->data`. [F46]
- Because `enable_net_traffic` sets bit 7 (`0x80`) of `RCR` (`0x9e`) to append 4 bytes of RX status to each frame, `read_bulk_callback` must check `urb->actual_length < 4` before subtracting 4 for `pkt_len`; when `urb->status == 0`, `dev->rx_skb != NULL`, and `urb->actual_length < 4`, it must jump to `goon` to resubmit `dev->rx_urb` with the existing `dev->rx_skb` (which `rtl8150_resume` relies on when calling `read_bulk_callback` with `actual_length = 0`). [F40, F60]
- `rtl8150_start_xmit` must stop the transmit queue via `netif_stop_queue(netdev)` before storing `dev->tx_skb` and submitting `dev->tx_urb`, and only wake or restart the queue in `write_bulk_callback` (after `dev_kfree_skb_irq(dev->tx_skb)`) or when `usb_submit_urb` fails with a non-`-ENODEV` error. [F27]
- In `rtl8150_set_multicast`, the `netdev->flags & IFF_PROMISC` branch must precede the `!netdev_mc_empty(netdev) || (netdev->flags & IFF_ALLMULTI)` branch because the `else if` branch masks off bit 0 (`rx_creg &= 0xfffe`), which is the promiscuous mode bit set by `rx_creg |= 0x0001`. [F39]
- `rtl8150_probe` must verify that bulk IN/OUT and interrupt IN endpoints exist via `usb_check_bulk_endpoints` and `usb_check_int_endpoints` with zero-terminated `bulk_ep_addr` (`RTL8150_USB_EP_BULK_IN`, `RTL8150_USB_EP_BULK_OUT`) and `int_ep_addr` (`RTL8150_USB_EP_INT_IN`) arrays before allocating URBs, resetting hardware, or registering `netdev`, and those endpoint numbers must stay in lockstep with `usb_rcvbulkpipe` (1), `usb_sndbulkpipe` (2), and `usb_rcvintpipe` (3). [F31, F51]
- `rtl8150_table` must remain a `const` `struct usb_device_id` array terminated by an empty `{}` sentinel entry and exported via `MODULE_DEVICE_TABLE(usb, rtl8150_table)`. [F56]

## Synchronization
- `get_registers` and `set_registers` perform synchronous, sleeping USB control transfers via `usb_control_msg_recv` and `usb_control_msg_send` with `GFP_NOIO`, so they must only be called from process context; atomic contexts (such as `rtl8150_set_multicast`, `rtl8150_start_xmit`, `rtl8150_tx_timeout`, `rx_fixup`, or URB callbacks) must use `async_set_registers`. [F64]
- While RX is active, `dev->rx_skb_pool` is shared between `read_bulk_callback` and the `rx_fixup` tasklet (`dev->tl`), so runtime calls to `pull_skb` and `fill_skb_pool` must hold `dev->rx_pool_lock` with local IRQs disabled (`spin_lock_irqsave` or `spin_lock_irq`) and use atomic allocations (`dev_alloc_skb`), and `read_bulk_callback`/`rx_fixup` must release `dev->rx_pool_lock` before checking `skb`, jumping to `resched`/`tlsched`, or calling `usb_submit_urb`. [F8, F66]
- `rtl8150_tx_timeout` runs in atomic watchdog timer context and must cancel `dev->tx_urb` asynchronously with `usb_unlink_urb`, whereas process-context teardown paths (`unlink_all_urbs` in `rtl8150_close` and `rtl8150_disconnect`, `rtl8150_suspend`, and `rtl8150_open` error cleanup) use sleeping `usb_kill_urb`. [F65]
- `write_bulk_callback` executes in USB URB completion (interrupt/softirq) context and must free `dev->tx_skb` using `dev_kfree_skb_irq` rather than process-context `dev_kfree_skb`. [F67]
- In `rtl8150_suspend`, `netif_device_detach(dev->netdev)` must be called before `usb_kill_urb(dev->rx_urb)` and `usb_kill_urb(dev->intr_urb)` so that concurrent `read_bulk_callback` and `write_bulk_callback` executions observe `!netif_device_present` and do not resubmit URBs or wake the TX queue. [F13]

## Object Lifetimes
- In `rtl8150_disconnect`, `set_bit(RTL8150_UNPLUG, &dev->flags)` must precede `tasklet_kill(&dev->tl)` and `unregister_netdev(dev->netdev)`, `unlink_all_urbs(dev)` must complete before freeing resources, and in both `rtl8150_disconnect` and `rtl8150_probe` error paths, `free_netdev` must be called last after `free_all_urbs`, `free_skb_pool`, `dev_kfree_skb(dev->rx_skb)`, and `kfree(dev->intr_buff)` because `rtl8150_t` resides in `netdev_priv(netdev)`. [F5, F11]
- Because `rtl8150_close` only unlinks URBs without freeing `dev->rx_skb`, `rtl8150_open` only calls `pull_skb(dev)` when `dev->rx_skb == NULL`, and `rtl8150_disconnect` frees `dev->rx_skb` alongside `free_skb_pool(dev)`. Broken by: unconditionally overwriting `dev->rx_skb = pull_skb(dev)` in `rtl8150_open`, or freeing `dev->rx_skb` in `rtl8150_close` without setting it to `NULL`. [F4]
- `async_set_registers` transfers ownership of the `kmalloc`-allocated `struct async_req` (used as both setup packet `req->dr` and data buffer `req->rx_creg`) and `async_urb` to `async_set_reg_cb` upon URB submission, freeing `req` immediately if `usb_alloc_urb` fails, and `async_set_reg_cb` must call `kfree(req)` and `usb_free_urb(urb)`. [F6]
- `rtl8150_probe` must initialize `dev->tl`, `dev->rx_pool_lock`, URBs (`alloc_all_urbs`), hardware reset (`rtl8150_reset`), the RX SKB pool (`fill_skb_pool`), the MAC address (`set_ethernet_addr`), and `usb_set_intfdata` before calling `register_netdev`, and unwind them in reverse order on error. [F52]
- `rtl8150_open` must pull `dev->rx_skb` and successfully submit both `dev->rx_urb` and `dev->intr_urb` (calling `usb_kill_urb(dev->rx_urb)` if `dev->intr_urb` submission fails) before calling `enable_net_traffic`, `set_carrier`, and `netif_start_queue`. [F54]

## API Contracts
- Return conventions differ across helpers: `rtl8150_reset` and `alloc_all_urbs` return boolean truth values (`1` on success, `0` on failure); `read_mii_word` and `write_mii_word` return `0` on success and `1` on timeout; `get_registers` and `set_registers` wrap `usb_control_msg_recv`/`usb_control_msg_send` and return `0` on success or negative errno on failure (not the transferred byte count). [F15, F38]
- Flags in `dev->flags` (`RTL8150_HW_CRC`, `RX_REG_SET`, `RTL8150_UNPLUG`, `RX_URB_FAIL`) are 0-based bit indices passed to `set_bit`, `clear_bit`, and `test_bit`, whereas hardware status macros (`CSCR_LINK_STATUS`, `TSR_*`, `RSR_*`, `MSR_*`) are pre-shifted bitmasks tested with `&`. [F22]
- All USB transfers must use heap- or SKB-allocated buffers (`usb_control_msg_recv`/`usb_control_msg_send`, `kmalloc`-allocated `struct async_req`, `dev->intr_buff`, or `skb->data`) and never stack memory; in `async_set_registers`, all fields of `req->dr` and `req->rx_creg` (`u16`) must be explicitly initialized with `size <= sizeof(req->rx_creg)` (2 bytes) and `req->dr.wValue`, `req->dr.wLength`, and `req->rx_creg` converted via `cpu_to_le16()`. [F21, F36, F68]
- In `rtl8150_resume`, when `netif_running(dev->netdev)` holds, `netif_device_attach(dev->netdev)` must be called and both `status` and `actual_length` on `dev->rx_urb` and `dev->intr_urb` must be reset to `0` before invoking `read_bulk_callback` and `intr_callback`. [F26]
- `rtl8150_set_mac_address` must reject changes with `-EBUSY` when `netif_running(netdev)` is true, and must update both `netdev->dev_addr` (via `eth_hw_addr_set`) and the hardware `IDR` register (`set_registers(dev, IDR, ...)`). [F29]

## Error Handling
- `alloc_all_urbs` frees any already-allocated URBs before returning `0` on allocation failure, so callers (`rtl8150_probe`) must not call `free_all_urbs` when `alloc_all_urbs` fails. [F2]
- In `rtl8150_get_link_ksettings`, stack out-parameters `bmcr` and `lpa` must be initialized before passing them to `get_registers`, because `get_registers` leaves `data` unmodified on USB failure and its return value is not checked. [F17]
- Whenever `usb_submit_urb` returns `-ENODEV` (in `async_set_registers`, `read_bulk_callback`, `intr_callback`, `rx_fixup`, `rtl8150_start_xmit`, or `rtl8150_open`), the caller must invoke `netif_device_detach(dev->netdev)` rather than re-queuing the URB, scheduling `dev->tl`, or waking the TX queue. [F63]

## External Contracts
- `rtl8150_start_xmit` pads the USB bulk transfer length `count` to at least 60 bytes and increments `count` by 1 whenever `count` is an exact multiple of 64 (`!(count & 0x3f)`), while still accounting `netdev->stats.tx_bytes` using the original `skb->len`. [F72]
- `read_mii_word` and `write_mii_word` must poll `PHYCNT` after asserting `PHY_GO` (`0x40`) until `PHY_GO` clears or `MII_TIMEOUT` iterations elapse, and callers such as `rtl8150_siocdevprivate` must mask the register index with `0x1f` so `PHY_WRITE` (`0x20`) and `PHY_GO` are not clobbered. [F58]
- In `rtl8150_siocdevprivate`, the `SIOCDEVPRIVATE` case must set `data[0] = dev->phy` and fall through to `SIOCDEVPRIVATE + 1` so that a single `SIOCDEVPRIVATE` ioctl both populates the PHY address and reads the MII register specified by `data[1] & 0x1f` into `data[3]`. [F41]
- When `EEPROM_WRITE` is enabled in `rtl8150_set_mac_address`, writes to `IDR_EEPROM` must be split into 2-byte word-sized `set_registers` calls while bit `0x20` (`WEPROM`) is set in `CR`, and bit `0x20` (`cr &= 0xdf`) must be cleared in `CR` immediately afterward. [F57]
