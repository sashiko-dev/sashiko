# FREESCALE SOC SOUND DRIVERS

This component provides ALSA SoC (ASoC) CPU DAI drivers (SAI, S/PDIF, SSI for I2S/AC97, and XCVR for eARC/ARC/SPDIF), PCM platform drivers (DMA, ARM FIQ with hrtimers, and Cortex-M RPMSG IPC), the i.MX AUDMUX routing driver, common clock/DT helpers, and machine drivers for Freescale/NXP i.MX and PowerPC SoCs.

## Architecture & Data Flow

- When a SAI stream `dir` is clocked by the opposite direction `adir` (`fsl_sai_dir_is_synced(sai, adir)`), provider-mode clock/frame settings in `fsl_sai_set_bclk()` and `fsl_sai_hw_params()` must be programmed into `FSL_SAI_xCR2/4/5(!tx, ofs)`. In `fsl_sai_trigger()`, starting a synced stream must also set `FSL_SAI_CSR_TERE` in `FSL_SAI_xCSR(!tx, ofs)`, and stopping must only call `fsl_sai_config_disable()` if the opposite direction's `FSL_SAI_CSR_FRDE` bit is clear. [F54, F55]
- In `fsl_sai_check_version()`, return early without reading `FSL_SAI_VERID` (`0x00`) when `FSL_SAI_TCSR(ofs) == FSL_SAI_VERID` (`reg_offset == 0`), and in `fsl_sai_probe()`, only write `FSL_SAI_MCTL` (`0x100`) when `sai->soc_data->max_register >= FSL_SAI_MCTL`. In `fsl_ssi`, i.MX21 hardware (`ssi->soc->imx21regs == true`) lacks `REG_SSI_SACCST/SACCEN/SACCDIS` (`0x50`–`0x58`), so `fsl_ssi_probe()` must cap `regconfig.max_register` at `REG_SSI_SRMSK` and `fsl_ssi_tx_ac97_saccst_setup()` must skip writing them. [F122, F123]
- In `fsl_ssi_config_disable()`, when the opposite stream `adir` is active (`ssi->streams & BIT(adir)`), bits shared with `ssi->regvals[adir]` must be excluded via `ssi_excl_shared_bits()` when clearing `REG_SSI_SCR/SIER/SRCR/STCR`. When `ssi->soc->offline_config` is true, `fsl_ssi_config_enable()` and `fsl_ssi_config_disable()` must only modify `REG_SSI_SRCR/STCR/SIER` when no other stream is active (`!ssi->streams` on enable, `!aactive` on disable) by programming or clearing the bitwise OR of both `RX` and `TX` `regvals` at once. [F59, F130]
- Because `REG_SSI_SFCSR` and `REG_SSI_SACNT` are volatile in `fsl_ssi_volatile_reg()`, `fsl_ssi_suspend()` must save them to `ssi->regcache_sfcsr`/`regcache_sacnt` before `regcache_cache_only()`, and `fsl_ssi_resume()` must restore `SSI_SFCSR_*WM*` and `REG_SSI_SACNT` before `regcache_sync()`. Likewise, `REG_SPDIF_SRPC` is volatile in `fsl_spdif_volatile_reg()`, so `fsl_spdif_runtime_suspend()` must save it to `spdif_priv->regcache_srpc` and `fsl_spdif_runtime_resume()` must restore `SRPC_CLKSRC_SEL_MASK | SRPC_GAINSEL_MASK` before `regcache_sync()`. [F61, F62]
- Static `snd_soc_dai_driver` templates (`fsl_sai_dai_template`, `fsl_ssi_dai_template`, `fsl_ssi_ac97_dai`, `fsl_spdif_dai`) must be copied into per-instance `cpu_dai_drv` before mutating per-device fields (`name`, `formats`, `symmetric_*`), and `struct fsl_sai`'s `cpu_dai_drv[3]` must have at least `ARRAY_SIZE(fsl_sai_dai_template)` elements. [F50, F114]
- In `fsl_ssi.c`, `fsl_ssi_probe()` must only request `ssi->irq` (`fsl_ssi_isr`) when `ssi->use_dma` is true (when false, `imx_pcm_fiq_init()` routes `ssi->irq` to FIQ via `mxc_set_irq_fiq()`). In `_fsl_ssi_set_dai_fmt()`, `SND_SOC_DAIFMT_I2S` must set `SSI_SxCCR_DC` in `REG_SSI_STCCR/SRCCR` using `ssi->slots ? : 2`. In `fsl_ssi_set_bclk()`, forcing `slot_width` to 32 requires both `channels == 2` and `(ssi->i2s_net & SSI_SCR_I2S_MODE_MASK) == SSI_SCR_I2S_MODE_MASTER` after applying `ssi->slot_width`. [F57, F82, F152]
- In `fsl_xcvr.c`, the 20 KiB RAM is paged in 2 KiB (`FSL_XCVR_REG_OFFSET`) windows at `xcvr->ram_addr`, so `fsl_xcvr_load_firmware()` must reject firmware over 16384 bytes (pages 0..7) and Data RAM accesses (`FSL_XCVR_CAP_DATA_STR`, `FSL_XCVR_RX_CS_CTRL_0`) must select `FSL_XCVR_EXT_CTRL_PAGE(8)`. On stop in `fsl_xcvr_trigger()`, `FSL_XCVR_MODE_SPDIF` must break when `xcvr->soc_data->spdif_only` is true instead of falling through to `FSL_XCVR_MODE_EARC` (where `FSL_XCVR_ISR_CLR` is not writeable). [F76, F88]
- In `imx-pcm-rpmsg.h`, `struct rpmsg_head`, `struct param_s`, and `struct param_r` must remain `__packed` with 32-bit `unsigned int` fields, `imx_rpmsg_pcm_new()` must enforce `DMA_BIT_MASK(32)` so `dma_addr` fits in `param_s.buffer_addr`, and `s_msg` (`struct rpmsg_s_msg`) must remain at offset 0 of `struct rpmsg_msg` for direct `memcpy()` calls in `imx-pcm-rpmsg.c`. [F73, F106]
- `IMX_SSI_DMABUF_SIZE` (and `snd_imx_hardware.buffer_bytes_max`) must not exceed `64 * 1024` bytes because `snd_imx_pcm_prepare()` packs `iprtd->period * iprtd->periods - 1` into the upper 16 bits (`<< 16`) of 32-bit `regs.ARM_r8`/`regs.ARM_r9` and `snd_hrtimer_callback()` masks the byte offset with `& 0xffff`. [F102]

## Synchronization

- In `fsl_xcvr.c`, `xcvr->lock` (`spin_lock_irqsave`) must be held across all `FSL_XCVR_EXT_CTRL` DMA and datapath reset updates in `fsl_xcvr_trigger()` and `reset_rx_work()`, and `reset_rx_work()` must verify `!(ext_ctrl & FSL_XCVR_EXT_CTRL_DMA_RD_DIS)` under `xcvr->lock` before toggling RX DMA and reset bits. [F24]
- In `imx-pcm-rpmsg.c`, `imx_rpmsg_pcm_send_message()` must hold `info->msg_lock` continuously across `reinit_completion(&info->cmd_complete)`, `rpmsg_send()`, `wait_for_completion_timeout()`, and copying `info->r_msg`. In `imx_rpmsg_pcm_work()` and `imx_audio_rpmsg_cb()`, `info->lock[TX]` and `info->lock[RX]` must be released before calling `info->send_message()` or `info->callback[TX/RX]` (`imx_rpmsg_pcm_dma_complete`). [F26, F27, F28]
- In `imx-pcm-rpmsg.c`, `info->work_write_index` must be initialized to `1` (differing from `work_read_index == 0`) in `imx_rpmsg_pcm_probe()`, and `imx_rpmsg_pcm_work()` must advance `info->work_read_index` under `info->wq_lock` only after `info->send_message(&work_of_rpmsg->msg, info)` completes. [F29]
- In `fsl_ssi.c`, AC97 register accesses in `fsl_ssi_ac97_read()` and `fsl_ssi_ac97_write()` must be serialized by `fsl_ac97_data->ac97_reg_lock`, which must be initialized along with `fsl_ac97_data` before `snd_soc_set_ac97_ops_of_reset()` and destroyed only after `snd_soc_set_ac97_ops(NULL)`. [F33]

## Object Lifetimes

- When an ASoC machine driver in `sound/soc/fsl/` acquires a clock from a foreign CPU DAI or CODEC device during `probe`, it must bind devres to its own `&pdev->dev` (via `devm_get_clk_from_child()`) or pair `clk_get()` with `clk_put()`—never call `devm_clk_get()` on the foreign `dev`. [F119]
- In `imx_card_parse_of()`, after `of_node_put()` is called on `cpu`, `codec`, and `platform` at the end of each `for_each_child_of_node_scoped()` iteration, all three pointers must be reset to `NULL` so a later jump to `err:` does not double-put them. [F1]
- In `fsl_sai.c`, enabling `sai->mclk_clk[sai->mclk_id[tx]]` in `fsl_sai_hw_params()` and disabling in `fsl_sai_hw_free()` must be gated on `!sai->is_consumer_mode[tx]` and tracked in `sai->mclk_streams`, and `fsl_sai_set_dai_sysclk()` must not call `fsl_sai_set_mclk_rate()` when `sai->mclk_streams != 0`. In `fsl_ssi.c`, `ssi->baudclk` enable/disable in `fsl_ssi_hw_params()`/`fsl_ssi_hw_free()` must be gated on `fsl_ssi_is_i2s_clock_provider(ssi)` and tracked in `ssi->baudclk_streams`, and `fsl_ssi_set_bclk()` must not call `clk_set_rate()` when the opposite stream bit is set. [F5, F7]
- In `spdif_reparent_rootclk()` and `fsl_xcvr_en_aud_pll()`, because `spdif_priv->txclk[STC_TXCLK_SPDIF_ROOT]` and `xcvr->phy_clk` are already enabled by runtime resume, they must be disabled with `clk_disable_unprepare()` before calling `fsl_asoc_reparent_pll_clocks()` and re-enabled with `clk_prepare_enable()` afterward. [F135]
- In `fsl_ssi.c`, when `!ssi->has_ipg_clk_name`, `fsl_ssi_imx_probe()` manually enables `ssi->clk` (`devm_regmap_init_mmio()` is used instead of `devm_regmap_init_mmio_clk()`), so both `error_pcm:` and `fsl_ssi_imx_clean()` must call `clk_disable_unprepare(ssi->clk)` gated on `!ssi->has_ipg_clk_name`. [F8]
- In `imx-pcm-fiq.c`, `claim_fiq(&fh)` and `mxc_set_irq_fiq(params->irq, 1)` in `imx_pcm_fiq_init()` must be rolled back via `failed_register:` on `devm_snd_soc_register_component()` failure, and otherwise are released in `.pcm_destruct` (`snd_imx_pcm_free()`). `snd_imx_pcm_trigger()` must set `iprtd->playing`/`capturing` to 1 via `atomic_set()` before `hrtimer_start()`, and `snd_imx_close()` must call `hrtimer_cancel(&iprtd->hrt)` before `kfree(iprtd)`. [F10, F11, F32]
- In `fsl_xcvr.c`, `fsl_xcvr_remove()` must call `cancel_work_sync(&xcvr->work_rst)` before `pm_runtime_disable(&pdev->dev)`. In `fsl_xcvr_startup()`/`fsl_xcvr_shutdown()`, `xcvr->streams` tracks active substreams (`BIT(substream->stream)` after `fsl_xcvr_constr()`), and `fsl_xcvr_activate_ctl()` must be bracketed by `down_read`/`up_read(&card->snd_card->controls_rwsem)` with re-activation only when `!xcvr->streams`. [F15, F25]

## API Contracts

- In machine drivers using `snd_soc_pm_ops` (`imx-card.c`, `imx-audmix.c`, `imx-rpmsg.c`, `imx-hdmi.c`, `imx-sgtl5000.c`), device drvdata holds `struct snd_soc_card *` while driver private data is stored via `snd_soc_card_set_drvdata()` and retrieved via `snd_soc_card_get_drvdata()`. Every machine driver in this component must also set `card.owner = THIS_MODULE` before `devm_snd_soc_register_card()`. [F110, F156]
- In CPU DAI probes (`fsl_sai_probe()`, `fsl_spdif_probe()`, `fsl_ssi_probe()`, `fsl_xcvr_probe()`), the PCM platform component (`imx_pcm_dma_init()`, `imx_pcm_fiq_init()`, or `devm_snd_dmaengine_pcm_register()`) must be registered before `devm_snd_soc_register_component()` registers the CPU DAI. In `fsl_ssi_probe()`, `platform_device_register_data()` for `ssi->card_pdev` must pass `NULL` as `parent` when `fsl_ssi_is_ac97(ssi)` is true so ASoC does not inherit the SSI DT node for the AC97 CODEC and bypass `fsl_ssi_dai_probe()`. [F118, F157]
- Before calling `fsl_asoc_get_dma_channel()`, the caller must allocate `dai->platforms` and point `dai->platforms->name` to a writable buffer of at least `DAI_NAME_SIZE` (32) bytes because `fsl_asoc_get_dma_channel()` casts it to `char *` and writes into it with `snprintf()`. Callers of `fsl_asoc_constrain_rates()` must pass a non-stack `target_rates` buffer with at least `original_constr->count` elements (`FAL_SAI_NUM_RATES` / `SPDIF_NUM_RATES`). [F43, F104]
- In `fsl_sai.h`, `FSL_SAI_CR4_FRSZ(x)`, `FSL_SAI_CR4_SYWD(x)`, `FSL_SAI_CR5_WNW(x)`, and `FSL_SAI_CR5_W0W(x)` subtract 1 internally, whereas `FSL_SAI_CR5_FBT(x)` does not and requires 0-based `word_width - 1` (or `0`). In `fsl_ssi_set_dai_tdm_slot()`, `REG_SSI_STMSK` and `REG_SSI_SRMSK` use `1` bits to disable slots and require `SSI_SCR_SSIEN` set while writing `~tx_mask` and `~rx_mask`; `slot_width` must be an even integer in `[8, 24]` and `slots >= 2` when `ssi->i2s_net` is active; and in `fsl_ssi_set_bclk()`, `freq * 5` must not exceed `clk_get_rate(ssi->clk)`. [F47, F49, F101]
- All `snd_kcontrol_new` controls in `fsl_spdif.c` (`fsl_spdif_ctrls`, `fsl_spdif_ctrls_rcm`) and `fsl_xcvr.c` (`fsl_xcvr_mode_kctl`, `fsl_xcvr_arc_mode_kctl`, `fsl_xcvr_earc_capds_kctl`, `fsl_xcvr_tx_ctls`, `fsl_xcvr_rx_ctls`) must be registered via `snd_soc_add_dai_controls()` because their callbacks cast `snd_kcontrol_chip()` to `struct snd_soc_dai *`; any control looked up via `snd_soc_card_get_kcontrol()` must set `.iface = SNDRV_CTL_ELEM_IFACE_MIXER`. [F116, F154]
- In `imx-pcm-rpmsg.c`, `imx_rpmsg_pcm_send_message()` (`info->send_message`) sleeps on `info->msg_lock` and `info->cmd_complete`, so atomic callbacks (`imx_rpmsg_pcm_trigger()`, `imx_rpmsg_pcm_ack()`, `imx_rpmsg_timer_callback()`) must defer messages via `imx_rpmsg_insert_workqueue()`. In `fsl_sai.c`, `fsl_sai_config_disable()` is called from atomic `fsl_sai_trigger()` and must use `udelay()` when polling `FSL_SAI_CSR_TERE`. [F143, F153]
- RPMSG device/drvdata contracts: `imx_audio_rpmsg_probe()` must register `data->rpmsg_pdev` with `&rpdev->dev` as parent and pass `strlen(rpdev->id.name) + 1` as `platform_data` size for `data->card_pdev` (`"imx-audio-rpmsg"`); `imx_rpmsg_pcm_probe()` must store `struct rpmsg_info *` as `rpmsg_pdev` drvdata; and any CPU DAI bound with `imx_rpmsg_soc_component` must store `struct fsl_rpmsg *` as `cpu_dai->dev` drvdata. [F107, F108, F109]
- In `imx-pcm-fiq.c`, `snd_imx_pcm_prepare()` must call `get_fiq_regs(&regs)` before updating `regs.ARM_r8`/`ARM_r9` and calling `set_fiq_regs(&regs)` so preparing one stream does not clobber the opposite stream. In `snd_imx_pcm_new()`, `imx_ssi_fiq_base`, `imx_ssi_fiq_tx_buffer`, and `imx_ssi_fiq_rx_buffer` must be set before `set_fiq_handler()` copies `[imx_ssi_fiq_start, imx_ssi_fiq_end)`, and `imx_ssi_fiq_start`/`imx_ssi_fiq_end` must keep 1-byte type (`unsigned char`) so pointer subtraction yields byte length. [F103, F140, F141]

## Error Handling

- Unlike `fsl_asoc_get_pll_clocks()`, `fsl_sai_probe()`, and `imx_audmux_probe()` which normalize failed `devm_clk_get()` pointers to `NULL`, `fsl_spdif_probe()` and `fsl_ssi_imx_probe()` leave `spdif_priv->spbaclk` and `ssi->baudclk` as `ERR_PTR` values, so every consumer of those two fields must check `!IS_ERR()` before use. [F40]
- In `fsl_xcvr`, `xcvr->regmap_phy` and `xcvr->regmap_pll` are only allocated when `xcvr->soc_data->use_phy` is true, and `xcvr->soc_data->fw_name` is `NULL` on SoCs without M0+ firmware (e.g. i.MX93), so all accesses to `regmap_phy`/`regmap_pll` must be gated by `use_phy` and firmware/RAM CS accesses by `fw_name`. [F41]

## Known Pitfalls

- In `fsl_sai.h` and `fsl_sai.c`, `RX` is `0` and `TX` is `1` (opposite to `SNDRV_PCM_STREAM_PLAYBACK == 0` / `CAPTURE == 1`), so per-direction arrays (`sai->mclk_id`, `sai->slots`, `sai->slot_width`, `sai->is_consumer_mode`, `dl_cfg->*`) must be indexed by `tx`, whereas `sai->mclk_streams` uses `BIT(substream->stream)`. [F78]
- In `fsl_sai_config_disable()`, `fsl_sai_dai_probe()`, and `fsl_sai_runtime_resume()`, asserting/clearing `FSL_SAI_CSR_SR` must use `regmap_update_bits()` (not `regmap_write()`) and run in both producer and consumer modes. When `sai->soc_data->mclk_with_tere && sai->mclk_direction_output` is true, `fsl_sai_config_disable()` must keep `FSL_SAI_CSR_BCE` set in `FSL_SAI_xCSR`, and `fsl_sai_hw_params()` in provider mode must clear `FSL_SAI_CR4_FSD_MSTR` before updating `FSL_SAI_xCR4/5` word width and re-enable it after. [F127, F128]
- In `fsl_sai_isr()`, `xcsr` must be masked with `~FSL_SAI_CSR_xF_MASK` before ORing in `flags & FSL_SAI_CSR_xF_W_MASK` to acknowledge W1C flags. In `fsl_sai_set_dai_fmt_tr()`, `sai->is_pdm_mode` and `sai->is_dsp_mode[tx]` must be reset to `false` before evaluating `fmt & SND_SOC_DAIFMT_FORMAT_MASK`. In `fsl_sai_hw_free()`, both `FSL_SAI_xMR(tx)` and `FSL_SAI_CR3_TRCE_MASK` in `FSL_SAI_xCR3(tx, ofs)` must be cleared to `0`. [F51, F52, F129]
- In `fsl_ssi_hw_params()`, stream-specific overrides to I2S/Network mode bits (mono or 16-bit `BC_FP`) must be computed in a local copy of `ssi->i2s_net`, keeping `ssi->i2s_net` intact. In `fsl_ssi_set_bclk()`, iteration `i == 0` (`PM(1)`) is excluded via `!(i == 0)`, so the early-exit check must test `savesub == 0` rather than `sub == 0`. `ssi_excl_shared_bits()` and `_ssi_xor_shared_bits()` multiply `avals` by `aactive`, so callers like `fsl_ssi_config_disable()` must pass `aactive` as a boolean (`0` or `1`), not an unnormalized bitmask. [F58, F83, F85]
- In `spdif_softreset()`, because `REG_SPDIF_SCR` is cached (`REGCACHE_FLAT`) and `SCR_SOFT_RESET` self-clears in hardware, `regcache_cache_bypass(regmap, true)` must be enabled before writing `SCR_SOFT_RESET` and polling `REG_SPDIF_SCR`, then disabled before calling `regcache_mark_dirty()` and `regcache_sync()`. [F133]
- In `imx-pcm-rpmsg.c` and `imx-audio-rpmsg.c`, `MSG_TYPE_C` commands (`TX_PERIOD_DONE == 0x0`, `RX_PERIOD_DONE == 0x1`) must index `info->msg` at `cmd + MSG_TYPE_A_NUM`. In `imx_es8328_probe()`, `platform_set_drvdata(pdev, data)` overwrites drvdata without `snd_soc_card_set_drvdata()`, so `imx_es8328_dai_init()` must use `container_of(rtd->card, struct imx_es8328_data, card)` and `imx_es8328_driver` cannot use `snd_soc_pm_ops`. [F74, F111]
