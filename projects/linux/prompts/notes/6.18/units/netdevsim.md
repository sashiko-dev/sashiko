# NETDEVSIM

NETDEVSIM is a simulated networking device driver and virtual bus (`netdevsim`) used for kernel selftests of networking, devlink, ethtool, BPF/XDP offload, FIB/nexthop offload, hardware stats, psample, IPsec, MACsec, PSP, and UDP tunnel port offload subsystems. It exposes sysfs attributes on `/sys/bus/netdevsim` to dynamically create/delete simulated bus devices, add/delete PF and SR-IOV VF ports, and link peer netdevs across network namespaces, while providing extensive debugfs knobs to inject errors and inspect offloaded state.

## Architecture & Data Flow
- Only PF ports (`nsim_dev_port_is_pf()`) run `nsim_init_netdevsim()` to allocate `ns->rq`, `ns->phc`, `dev->udp_tunnel_nic_info`, and BPF/MACsec/IPsec offloads; VF ports (`nsim_dev_port_is_vf()`) run `nsim_init_netdevsim_vf()` with `nsim_vf_netdev_ops` and no `ns->rq`. `nsim_destroy()` must gate PF-only teardown on `nsim_dev_port_is_pf()`, and `netdev_is_nsim()` must check `dev->netdev_ops == &nsim_netdev_ops` so `link_device_store()` rejects VFs. [F69, F152]
- Per-netdev debugfs files (`nsim_ethtool_init()`, `nsim_bpf_init()`, `nsim_udp_tunnels_info_create()`, `nsim_ipsec_init()`, `nsim_psp_init()`, `nsim_create()`) must be created under `ns->nsim_dev_port->ddir` rather than the shared `ns->nsim_dev->ddir`, which collides on multi-port devices. [F66]
- Because `nsim_start_peer_tx_queue()` only wakes stopped TX queues while `dev->real_num_tx_queues == peer_dev->num_rx_queues` on a linked peer, both `unlink_device_store()` and `nsim_set_channels()` (when `ns->peer` is set) must call `synchronize_net()` and wake all TX queues on both `dev` and `peer->netdev`. [F68]
- VF devlink ports store `port_index` offset by `NSIM_DEV_VF_PORT_INDEX_BASE` (128); code indexing `nsim_dev->vfconfigs[]` from a VF port must use `nsim_dev_port_index_to_vf_index()`. `nsim_bus_dev_max_vfs_write()` must cap `max_vfs` at `NSIM_DEV_VF_PORT_INDEX_MAX - NSIM_DEV_VF_PORT_INDEX_BASE` and reject updates with `-EBUSY` while `nsim_dev_get_vfs(nsim_dev)` is non-zero. [F89, F90]
- In `nsim_prog_set_loaded()` and `nsim_setup_prog_hw_checks()`, check `bpf_prog_is_offloaded(prog->aux)` rather than `prog->aux->offload != NULL` before dereferencing `prog->aux->offload->dev_priv`. Because `ns->bpf_offloaded` is shared between TC and XDP (`nsim_xdp_offload_active(ns)`), `nsim_bpf_disable_tc()` returns `-EBUSY` only when `ns->bpf_offloaded && !nsim_xdp_offload_active(ns)`, and `nsim_xdp_offload_prog()` returns `-EBUSY` when `!nsim_xdp_offload_active(ns) && bpf->prog && ns->bpf_offloaded`. [F50, F106]
- Every `struct nsim_fib_rt_key` must be zeroed across `sizeof(struct nsim_fib_rt_key)` before setting fields because `nsim_fib_rt_ht_params` hashes padding and unused `addr` bytes. `key.family` discriminates the `container_of()` type (`nsim_fib4_rt` for `AF_INET`, `nsim_fib6_rt` for `AF_INET6`), and `fib_event->family` discriminates `fen_info` vs `fib6_event` in `struct nsim_fib_event`. [F54, F56, F135]
- `nsim_fib4_prepare_event()` and `nsim_fib6_prepare_event()` pre-increment `fib.num` on `FIB_EVENT_ENTRY_REPLACE` (never on `FIB_EVENT_ENTRY_APPEND`), so `nsim_fib4_rt_replace()`, `nsim_fib6_rt_replace()`, and `rhashtable_insert_fast()` error paths in `nsim_fib4_rt_add()` / `nsim_fib6_rt_add()` must call `nsim_fib_account(..., false)`. `fib6_rt->nhs` must track the entry count on `fib6_rt->nh_list` because `nsim_fib6_rt_remove()` compares `fib6_event->nrt6 != fib6_rt->nhs`. [F19, F80, F111]
- Code extracting an `ipsec->sa[]` index from `xs->xso.offload_handle` must mask out `NSIM_IPSEC_VALID` (`~NSIM_IPSEC_VALID`) and reject `sa_idx >= NSIM_IPSEC_MAX_SA_COUNT`. In `struct nsim_sa`, IPv6 addresses use `ipaddr[4]` (`%pI6c`) while IPv4 uses `ipaddr[3]` (`%pI4`). In `macsec.c`, because `nsim_macsec_find_secy()` / `find_rxsc()` match only `.sci == sci`, `nsim_macsec_del_secy()` / `del_rxsc()` must `memset()` the deleted entry. [F81, F87, F136]
- When `psp_dev_rcv()` succeeds in `nsim_do_psp()`, it must refcount `skb->extensions` into `*psp_ext` so `nsim_forward_skb()` restores it via `nsim_psp_handle_ext()` after `__dev_forward_skb()`; when decapsulation is skipped, `nsim_do_psp()` must recompute `uh->check` and set `skb->ip_summed = CHECKSUM_NONE`. [F83]

## Synchronization
- Lock order is `device_lock(dev)` -> `devl_lock(devlink)` -> `rtnl_lock()`. `nsim_bus_dev_numvfs_store()` holds `device_lock(dev)`. `nsim_bus_dev_set_vfs()` holds both `devl_lock()` and `rtnl_lock()` so `nsim_dev_get_vfs()` callers may hold either lock. `nsim_drv_probe()`, `nsim_drv_remove()`, and all mutations or traversals of `nsim_dev->port_list` must hold `devl_lock(priv_to_devlink(nsim_dev))`. [F34, F35, F36, F146]
- Because `nsim_dev_traps_exit()` calls `cancel_delayed_work_sync(&nsim_dev->trap_data->trap_report_dw)` under `devl_lock()`, `nsim_dev_trap_report_work()` must use `devl_trylock()` and re-queue with a `1`-jiffy delay on contention. `nsim_dev_trap_report()` holds `trap_lock` and nests `spin_lock_bh(&nsim_dev->fa_cookie_lock)` inside it; `fa_cookie` debugfs read/write must not access user memory or do `GFP_KERNEL` allocations under `fa_cookie_lock`. [F37, F38, F103, F158]
- `nsim_bus_enable` is set via `smp_store_release()` after bus/driver registration and checked via `smp_load_acquire()` under `nsim_bus_dev_list_lock` in `new_device_store()` / `del_device_store()`. `nsim_bus_dev->init` is cleared before `device_register()` / `device_unregister()`, set via `smp_store_release()` after probe, and checked via `smp_load_acquire()` in `new_port_store()` and `del_port_store()`. [F24, F25]
- In `nsim_init_netdevsim()`, `rtnl_lock()` is dropped after `register_netdevice()` so `nsim_psp_init()` runs unlocked; if `nsim_psp_init()` fails, `err_unregister_netdev` must re-acquire `rtnl_lock()` before unlinking `ns->peer`, unregistering `ns->netdev`, and running RTNL-protected teardown labels before `rtnl_unlock()`. [F6]
- All updates to `struct netdevsim::peer` (`link_device_store()`, `unlink_device_store()`, `nsim_init_netdevsim()`, `nsim_destroy()`) must hold `rtnl_lock()`, and readers not holding `rtnl_lock()` (`nsim_start_xmit()`, `nsim_start_peer_tx_queue()`, `nsim_get_iflink()`, `nsim_wake_queues()`) must dereference `ns->peer` inside `rcu_read_lock()`. [F27]
- `nsim_open()`, `nsim_stop()`, `nsim_queue_start()`, and `nsim_queue_stop()` run under `netdev_lock(dev)` and must use `*_locked` NAPI helpers. `nsim_qreset_write()` must hold `netdev_lock(ns->netdev)`, validate `queue < ns->netdev->real_num_rx_queues`, and set/reset `ns->rq_reset_mode` around `netdev_rx_queue_restart()` (`nsim_queue_mem_alloc()` rejects `rq_reset_mode > 3`). [F77, F102, F163]
- `nsim_queue_free()` must call `hrtimer_cancel(&rq->napi_timer)` before purging `rq->skb_queue` and freeing `rq`, and when `rq->skb_queue.qlen` is non-zero, wrap `dev_dstats_rx_dropped_add()` in `local_bh_disable()` / `local_bh_enable()` (skipping it when `qlen == 0` because `nsim_queue_uninit()` can run before `register_netdevice()` allocates `dev->dstats`). [F31, F48]
- `nsim_fib_event_nb()` runs in atomic context, so `nsim_fib_event_schedule_work()` and `nsim_fib6_event_init()` must use `GFP_ATOMIC` and queue onto `data->fib_event_queue` under `spin_lock_bh(&data->fib_event_queue_lock)`. `nsim_fib_event_work()` splices the queue, drops the spinlock, and takes `mutex_lock(&data->fib_lock)` to mutate `fib_rt_ht` and `fib_rt_list` (both `nsim_fib_event_work()` and `nsim_dev_trap_report_work()` must call `cond_resched()` per entry). Direct updates to `rt->trap` in `nsim_fib6_rt_append()` require `WRITE_ONCE()`. [F40, F43, F104, F154]
- All `nsim_bpf_map_ops` callbacks must hold `mutex_lock(&nmap->mutex)` across any lookup, allocation, modification, or freeing of `nmap->entry`. [F47]

## Object Lifetimes
- Once `nsim_start_xmit()` calls `nsim_forward_skb()`, `skb` is consumed on both `NET_RX_SUCCESS` and `NET_RX_DROP` paths, so `nsim_start_xmit()` must read `skb->len` beforehand and jump to `out_drop_cnt` (skipping `kfree_skb_reason()`) on `NET_RX_DROP`. In `nsim_rcv()`, save `skb->len` before `do_xdp_generic()` or `netif_receive_skb()`, and call `skb_checksum_help(skb)` if `skb->ip_summed == CHECKSUM_PARTIAL` before `do_xdp_generic()`. [F1, F172]
- Because `link_device_store()` links `peer` pointers without `net_device` refcounts, `nsim_destroy()` and `nsim_init_netdevsim()` error unwind must clear `peer->peer` and `ns->peer` under `rtnl_lock()` and finish `unregister_netdevice()` before `nsim_queue_uninit()` frees `ns->rq`, `nsim_udp_tunnels_info_destroy()` removes `ns->udp_ports.ddir` and frees `dev->udp_tunnel_nic_info`, or `ns->page` and `dev` are freed. [F7, F29, F150]
- In `nsim_init_napi()` and `nsim_del_napi()`, every `page_pool_destroy(ns->rq[i]->page_pool)` must set `ns->rq[i]->page_pool = NULL`, and `nsim_del_napi()` must disable all RX queue NAPIs, delete them via `__netif_napi_del_locked()`, and call `synchronize_net()` before destroying their `page_pool`s. [F9]
- `nsim_pp_hold_write()` must hold `rtnl_lock()` and check `!netif_running(ns->netdev) && val` before the `val == true` branch that allocates from `ns->rq[0]->page_pool`, keeping `val == false` reachable when stopped; both `nsim_pp_hold_write()` and `nsim_destroy()` must release `ns->page` via `pp_page_to_nmdesc(ns->page)->pp` (never `ns->rq[0]->page_pool`) and set `ns->page = NULL`. [F8, F33, F109]
- `nsim_bus_dev->initial_net` is an unreferenced `struct net *` valid only during `nsim_drv_probe()`; post-probe code must use `nsim_dev_net(nsim_dev)` (`devlink_net()`). In `nsim_bus_dev_new()`, if `device_register()` fails, call `put_device(&nsim_bus_dev->dev)` (which frees `nsim_bus_dev` via `nsim_bus_dev_release()`) and set `nsim_bus_dev = NULL` before `kfree(nsim_bus_dev)`. [F3, F4]
- `nsim_dev_reload_destroy()` must return immediately if `devlink_is_reload_failed(devlink)` is true, and must remove `nsim_dev->take_snapshot` via `debugfs_remove()` before `nsim_dev_dummy_region_exit()` (while `nsim_dev_reload_create()` creates `take_snapshot` after `nsim_dev_dummy_region_init()`). In `nsim_dev_take_snapshot_write()`, balance `devlink_region_snapshot_id_get()` with `_put()` and `kfree(dummy_data)` if `devlink_region_snapshot_create()` fails. [F11, F16, F39]
- In `nsim_fib_destroy()`, `unregister_fib_notifier()` and `unregister_nexthop_notifier()` must precede `cancel_work_sync(&data->fib_flush_work)` and then `flush_work(&data->fib_event_work)` before `rhashtable_free_and_destroy()`. When flushing `data->fib_rt_list` in `nsim_fib_dump_inconsistent()` and `nsim_fib_flush_work()`, use `list_for_each_entry_safe()` and call `rhashtable_remove_fast()` before `nsim_fib_rt_free()`. [F42, F114]
- `struct nsim_fib_event` and stored routes (`nsim_fib4_rt` / `nsim_fib6_rt_nh`) hold independent `fib_info`/`fib6_info` references. `nsim_nexthop_account()` must subtract `i` (not `occ`) on partial failure at index `i`, and `nsim_nexthop_replace()` must reserve `nexthop->occ` before `rhashtable_replace_fast()`, rolling back `nexthop->occ` on error or releasing `nexthop_old->occ` and `nexthop_old` on success. [F18, F20]
- `nsim_dev_hwstats_exit()` must call `cancel_delayed_work_sync(&hwstats->traffic_dw)`, `debugfs_remove_recursive(hwstats->ddir)`, and `unregister_netdevice_notifier_net()` before `nsim_dev_hwsdev_list_wipe()` (which calls `nsim_dev_hwsdev_fini()` to `dev_put()` and `kfree()` entries on `l3_list`). `nsim_dev_psample_disable()` and `nsim_dev_psample_exit()` must call `cancel_delayed_work_sync(&psample->psample_dw)` before `psample_group_put()`. [F21, F45, F46]
- Because `nmap->entry[idx].key != NULL` marks an occupied slot in `struct nsim_bpf_bound_map`, `nsim_map_alloc_elem()` must free `key` and set it to `NULL` if allocating `value` fails, and `nsim_map_delete_elem()` must zero `nmap->entry[idx]` after freeing `key` and `value`. Every loop over `nsim_dev->port_list` calling `__nsim_dev_port_del()` must use `list_for_each_entry_safe()`. [F23, F113]

## API Contracts
- In `nsim_queue_start()`, when `ns->rq_reset_mode` is `2` or `3`, `netif_napi_del_locked(&ns->rq[idx]->napi)` and `netif_napi_add_config_locked(dev, &qmem->rq->napi, ...)` must run before `ns->rq[idx] = qmem->rq`, and `nsim_queue_mem_free()` must only call `netif_napi_del_locked(&qmem->rq->napi)` when `!ns->rq_reset_mode`. [F112]
- In `nsim_rcv()`, the dequeue loop must be bounded by `budget` and count packets consumed by `do_xdp_generic()` (`ret != XDP_PASS`) toward `done`, so `nsim_poll()` only calls `napi_complete_done(napi, done)` when `done < budget`. In `nsim_get_ringparam()`, read HDS state from `dev->cfg->hds_config`, never the unpopulated out-parameter `kernel_ring->tcp_data_split`. [F49, F117]
- In `nsim_dev_devlink_ops`, rate leaf callbacks receive `struct nsim_dev_port *` in `priv`/`priv_child`, whereas rate node callbacks receive `struct nsim_rate_node *`. `psp_assoc_drv_data(pas)` returns inline `void **` storage, so `psp.c` callers must dereference `*(struct netdevsim **)psp_assoc_drv_data(pas)`. In `fib.c`, `nsim_fib4_rt_create()` returns `NULL` on failure, whereas `nsim_fib6_rt_create()`, `nsim_nexthop_create()`, and `nsim_fib_create()` return `ERR_PTR()`. [F57, F132, F133]
- `nsim_bpf_string_fops` and `nsim_dev_rate_parent_fops` expect debugfs `private_data` to be a `char **` / `const char **` pointing to a string pointer field (`&state->state`, `&nsim_dev_port->parent_name`), not a `char *`. Every debugfs `struct file_operations` table must set `.owner = THIS_MODULE`, and write-only debugfs files must use mode `0200`. [F97, F131, F170]

## Error Handling
- In `nsim_init_netdevsim()`, if `register_netdevice_notifier_dev_net()` fails, reset `ns->nb.notifier_call = NULL` because `nsim_destroy()` checks `ns->nb.notifier_call != NULL`. Because `nsim_psp_rereg_write()` assigns `psp_dev_create()` directly to `ns->psp.dev`, `nsim_psp_uninit()` must check `!IS_ERR(ns->psp.dev)` before `psp_dev_unregister()`. [F60, F61]
- In `nsim_dev_debugfs_init()`, any failure after creating `nsim_dev->ddir` or `ports_ddir` must unwind them via `debugfs_remove_recursive()`. In `nsim_dev_resources_register()`, any `devl_resource_register()` failure must call `devl_resources_unregister(devlink)`. In multi-step init loops (`nsim_bpf_map_alloc()`, `nsim_fib6_rt_create()`, `nsim_fib6_rt_append()`, `nsim_init_napi()`, `nsim_queue_init()`), error unwind loops must pre-decrement signed `i` (`--i >= 0` or `i--`). [F13, F14, F115]

## Known Pitfalls
- In `nsim_start_xmit()`, the target RX queue index `rxq` must be clamped modulo `peer_dev->num_rx_queues` (not `dev->num_rx_queues`), selected from `peer_ns->rq[rxq]`, and checked against `peer_dev->cfg` for HDS linearization. [F118]
- Debugfs write handlers using `copy_from_user()` into a stack buffer (`nsim_bus_dev_max_vfs_write()`, `nsim_nexthop_bucket_activity_write()`, `nsim_qreset_write()`) must reject `size > sizeof(buf) - 1` and NUL-terminate `buf` before parsing. In `struct netdevsim`, `udp_ports.ports` is a row pointer (`u32 (*ports)[NSIM_UDP_TUNNEL_N_PORTS]`), so full-table operations like `memset()` in `nsim_udp_tunnels_info_reset_write()` must use `sizeof(ns->udp_ports.__ports)`. [F126, F130]
