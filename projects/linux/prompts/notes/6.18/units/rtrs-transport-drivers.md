# RTRS TRANSPORT DRIVERS

The RTRS (RDMA Transport) subsystem implements a reliable, high-speed, multipath RDMA transport layer (used primarily by RNBD) consisting of `rtrs-core`, `rtrs-client`, and `rtrs-server`. It manages RDMA CM connections, protection domains, fast memory registration/invalidation, heartbeats, multipath routing policies, automatic reconnection/failover, and sysfs management.

## Architecture & Data Flow
- On a server `rdma_cm_id`, `cm_id->context` points to `struct rtrs_srv_ctx` until `create_con()` sets `cm_id->context = &con->c` during `RDMA_CM_EVENT_CONNECT_REQUEST`; `rtrs_srv_rdma_cm_handler()` must handle `RDMA_CM_EVENT_CONNECT_REQUEST` before casting `cm_id->context` to `struct rtrs_con`. [F46]
- For client IO connections (`cid > 0`), `create_con_cq_qp()` allocates `con->rsp_ius` only when `clt_path->flags & RTRS_MSG_NEW_RKEY_F` is set; `post_recv_io()` and `rtrs_clt_rdma_done()` must check `RTRS_MSG_NEW_RKEY_F` before indexing `con->rsp_ius` or calling `rtrs_clt_recv_done()`/`rtrs_clt_rkey_rsp_done()`. Always test `clt_path->flags` and `rd_msg->flags` against `RTRS_MSG_NEW_RKEY_F` or `RTRS_MSG_NEED_INVAL_F` with bitwise `&`, never `==` or `!=`. [F43, F85]
- In `struct rtrs_srv_mr`, `srv_mr->iu` is allocated by `map_cont_bufs()` only when `always_invalidate` is true, so `rdma_write_sg()`, `send_io_resp_imm()`, and `unmap_cont_bufs()` must guard `srv_mr->iu` accesses on `always_invalidate`. When `RTRS_MSG_NEW_RKEY_F` (`always_invalidate=true`) is negotiated, the server sends `RTRS_MSG_RKEY_RSP` with the new `srv_mr->mr->rkey` via `IB_WR_SEND_WITH_IMM` after `IB_WR_REG_MR`, and `rtrs_clt_rkey_rsp_done()` must update `clt_path->rbufs[buf_id].rkey` before completing the IO request. [F44, F71]
- In `struct rtrs_srv_op`, `id->rd_msg` is assigned only in `process_read()` and is NULL or stale in `process_write()`, so `rtrs_srv_resp_rdma()` and `send_io_resp_imm()` must check `id->dir` before dereferencing `id->rd_msg`. [F45]
- In `init_conns()`, `cid == 0` must be created and established before `cid > 0` because `create_con_cq_qp()` for `cid > 0` relies on `clt_path->s.dev`, `clt_path->queue_depth`, and `clt_path->flags` populated by `cid == 0`. `rtrs_path::signal_interval` must be initialized on `cid == 0` via `min_not_zero(queue_depth, SERVICE_CON_QUEUE_DEPTH)` because send helpers divide by it with `%`. [F67, F106]
- Connection `0` is admin/heartbeat (`RTRS_ADMIN_CON`), `1 .. path->irq_con_num - 1` are IRQ IO connections, and `>= path->irq_con_num` are direct-polled; `rtrs_permit_to_clt_con()` and `rtrs_clt_rdma_cq_direct()` must offset IO indices by `+1`, and `alloc_path()` requires `con_num >= 1` (`irq_con_num >= 2`) to avoid modulo-by-zero in `(permit->cpu_id % (clt_path->s.irq_con_num - 1)) + 1`. [F55, F107]
- Selectively signaled send helpers (`rtrs_post_rdma_write_imm_empty()`, `rtrs_post_send_rdma()`, `rtrs_post_rdma_write_sg()`, `rdma_write_sg()`, `send_io_resp_imm()`) must increment `con->wr_cnt` and set `IB_SEND_SIGNALED` every `path->signal_interval` WRs to match `s->signal_interval` credits added to `con->c.sq_wr_avail` in `rtrs_srv_rdma_done()`. Chained `IB_WR_REG_MR` WRs must set `wr.send_flags = 0`, never `IB_SEND_SIGNALED`. [F64, F138]
- `rtrs_clt_init_req()` snapshots `clt_path->clt->mp_policy` into `req->mp_policy` and copies the user message into the first `req->usr_len` bytes of `req->iu->buf`; all `clt_path->stats->inflight` updates must check `req->mp_policy == MP_POLICY_MIN_INFLIGHT` (not `clt->mp_policy`), and `rtrs_clt_write_req()`/`rtrs_clt_read_req()` must write the RTRS header at `req->iu->buf + req->usr_len`. [F60, F61]
- `clt->permits` is byte-strided with element size `permit_size(clt) = sizeof(struct rtrs_permit) + clt->pdu_sz`; always index it via `get_permit(clt, idx)` and never via `(struct rtrs_permit *)` pointer arithmetic. [F80]
- When reconnecting a client path in `rtrs_rdma_conn_established()` on `cid == 0`, if `clt_path->queue_depth` is non-zero and differs from `msg->queue_depth`, set `clt_path->reconnect_attempts = -1` and fail with `-ECONNRESET`. Session limits `clt->max_io_size` and `clt->max_segments` must be clamped to the minimum across all paths, never overwritten. [F65, F66]

## Synchronization
- In `rtrs_clt_stop_and_destroy_conns()`, `clt_path->state` must not be `RTRS_CLT_CONNECTED`, `clt_path->init_mutex` must be cycled, and `synchronize_rcu()` and `rtrs_stop_hb()` must precede `stop_cm()`; `fail_all_outstanding_reqs()` must run after `stop_cm()` drains QPs and before `rtrs_clt_path_down()` and `destroy_con_cq_qp()`. In `init_path()`, `rtrs_start_hb()` must run only after `init_conns()`, `rtrs_send_path_info()`, and `rtrs_clt_path_up()` succeed. [F19, F26]
- In `rtrs_clt_remove_path_from_arr()`, `list_del_rcu(&clt_path->s.entry)` and `synchronize_rcu()` must precede decrementing `clt->paths_num` and replacing any per-CPU `clt->pcpu_path` entries pointing to `clt_path`, followed by a second `synchronize_rcu()` if any per-CPU entry was replaced. [F8]
- In `get_or_create_srv()` and `rtrs_ib_dev_find_or_add()`, initialize `srv->chunks`/`srv->refcount` and `dev->ref`/`dev->ib_pd`/`pool->ops->init(dev)` before acquiring `ctx->srv_mutex` or `pool->mutex` and inserting into the list; lookups of existing list entries under those mutexes must use `refcount_inc_not_zero(&srv->refcount)` and `kref_get_unless_zero(&dev->ref)`. [F21, F22, F145]
- All transitions of `clt_path->state` must use `rtrs_clt_change_state()` under `clt_path->state_wq.lock`, and `srv_path->state` transitions must use `rtrs_srv_change_state()` under `srv_path->state_lock` with `spin_lock_irqsave()`/`spin_unlock_irqrestore()`. [F31, F140]
- In `rtrs-srv.c`, `ctx->srv_mutex` is outer to `srv->paths_mutex` (never call `put_srv()` under `srv->paths_mutex`), and `con->rsp_wr_wait_lock` must be unlocked before calling `rtrs_srv_resp_rdma()` in `rtrs_rdma_process_wr_wait_list()`. Hold `con->con_mutex` across `create_con_cq_qp()` and `destroy_con_cq_qp()`, and hold `paths_ev_mutex` across `paths_up` updates and `link_ev()` calls. [F30, F32, F33, F34]
- Pass `can_wait = false` to `complete_rdma_req()` when called from CQ context (`process_io_rsp()`, `rtrs_clt_inv_rkey_done()`), and pass `wait = false` to `rtrs_clt_close_conns()` when called from `rtrs_clt_reconnect_work()` or `rtrs_clt_rdma_cm_handler()`. [F141, F148]
- In `rtrs_clt_remove_path_from_sysfs()`, loop calling `rtrs_clt_close_conns(clt_path, true)` and `rtrs_clt_change_state_get_old(clt_path, RTRS_CLT_DEAD, &old_state)` until `changed || old_state == RTRS_CLT_DEAD`, unlinking and freeing the path only when `changed` is true. [F90]
- Sync persistently mapped `rtrs_iu` buffers and `srv_path->dma_addr` chunks with `ib_dma_sync_single_for_device()` before posting/reposting WRs and `ib_dma_sync_single_for_cpu()` before CPU reads. On the server, when `always_invalidate` is true, `rtrs_srv_rdma_done()` must post `IB_WR_LOCAL_INV` via `rtrs_srv_inv_rkey()` on `RTRS_IO_REQ_IMM` and defer `process_io_req()` until `rtrs_srv_inv_rkey_done()`. [F152, F153]

## Object Lifetimes
- In `rtrs_iu_alloc()`, if `ib_dma_map_single()` fails at index `i`, `kfree(iu->buf)` must be called before jumping to `err` because `rtrs_iu_free(ius, dma_dev, i)` only frees indices `< i`; always pass the base array pointer and exact allocated count to `rtrs_iu_free()`. [F1, F117]
- In `dev_free()`, call `pool->ops->deinit(dev)` before `ib_dealloc_pd(dev->ib_pd)` and `kfree(dev)`. [F2]
- `rtrs_cq_qp_destroy()` must call `rdma_destroy_qp(con->cm_id)` and clear `con->qp = NULL` before `destroy_cq()`. Pair `ib_alloc_cq()`/`ib_free_cq()` when `is_pollqueue(con)` (`con->cid >= con->path->irq_con_num`) and `ib_cq_pool_get()`/`ib_cq_pool_put(con->cq, con->nr_cqe)` otherwise. [F3, F127]
- In `destroy_con_cq_qp()`, run `rtrs_cq_qp_destroy(&con->c)` and `rtrs_iu_free(con->rsp_ius, ...)` before decrementing `clt_path->s.dev_ref` and calling `rtrs_ib_dev_put()`, clearing `clt_path->s.dev = NULL` when `dev_ref` hits 0; if `create_con_cq_qp(con)` fails after allocating `clt_path->s.dev` or `con->rsp_ius`, still call `destroy_con_cq_qp(con)` under `con->con_mutex`. [F4, F129]
- In `rtrs_send_path_info()`, set local `rx_iu` and `tx_iu` to NULL as soon as `rtrs_iu_post_recv()` and `rtrs_iu_post_send()` succeed, because completion callbacks take ownership. [F5]
- In `alloc_path_reqs()`, reset `req->mr = NULL` if `ib_alloc_mr()` returns `ERR_PTR` so `free_path_reqs()` does not pass `ERR_PTR` to `ib_dereg_mr()`; `free_path_reqs()` must set `clt_path->reqs = NULL`. [F6]
- Before `rtrs_clt_create_path_files()` succeeds, error cleanup after `alloc_path()` must call `free_percpu(clt_path->stats->pcpu_stats)` and `kfree(clt_path->stats)` before `free_path(clt_path)`; once `rtrs_clt_create_path_files()` succeeds, release them only via `kobject_put(&clt_path->kobj)` and `kobject_put(&clt_path->stats->kobj_stats)`. [F9, F123]
- After `device_initialize(&clt->dev)`, release `clt` only via `put_device(&clt->dev)` or `device_unregister(&clt->dev)` (never `kfree(clt)` directly). Call `free_permits(clt)` only in `rtrs_clt_close()`, never in `free_clt()`. [F10, F120]
- Add a new `rtrs_clt_path` to `clt->paths_list` in `RTRS_CLT_CONNECTING` state before calling `init_path(clt_path)`. On teardown, `rtrs_clt_close()` must call `rtrs_clt_destroy_sysfs_root(clt)` before iterating `clt->paths_list`, and `rtrs_clt_close_conns(clt_path, true)` plus `rtrs_clt_remove_path_from_arr(clt_path)` must finish before `rtrs_clt_destroy_path_files()`. [F25, F122, F126]
- `process_read()` and `process_write()` take an in-flight ref via `rtrs_srv_get_ops_ids(srv_path)` before `ctx->ops.rdma_ev()`; if `rdma_ev()` returns 0, `rtrs_srv_resp_rdma()` drops it, otherwise the caller sends the error reply and calls `rtrs_srv_put_ops_ids(srv_path)`. [F14]
- In `rtrs_rdma_connect()`, call `put_srv(srv)` if `__find_path()` finds an existing `srv_path` or `__alloc_path()` fails. Return non-zero if `create_con()` fails (so RDMA CM destroys `cm_id`), but if `rtrs_rdma_do_accept()` fails after `create_con()` stored `cm_id`, queue `close_path(srv_path)` and return 0. [F15, F16]
- In `rtrs_srv_close_work()`, call `rtrs_srv_destroy_path_files()`, `rtrs_srv_path_down()`, `unmap_cont_bufs()`, and `rtrs_srv_free_ops_ids()` only after draining QPs, killing `ids_inflight_ref`, and waiting on `srv_path->complete_done`. In `rtrs_srv_destroy_path_files()`, when `srv_path->kobj.state_in_sysfs` is true, remove `rtrs_srv_path_attr_group`, call `kobject_put(&srv_path->kobj)` without `kobject_del()`, and call `rtrs_srv_destroy_once_sysfs_root_folders(srv_path)`. [F17, F24]
- Stack-allocated WRs and `struct ib_sge` entries linked into a send WR chain (e.g., in `send_io_resp_imm()` or `rtrs_clt_write_req()`) must remain in scope through `ib_post_send()`. [F112]

## API Contracts
- Callers of `path_it_init(&it, clt)` must hold `rcu_read_lock()` and call `path_it_deinit(&it)` before leaving the scope. [F11]
- Initialize `con->cid`, `con->path`, and `con->path->irq_con_num` before calling `rtrs_cq_qp_create()`, because `create_cq()` calls `is_pollqueue(con)` before `rtrs_cq_qp_create()` assigns `con->path`. [F53]
- `rtrs_ib_dev_find_or_add()` and `rtrs_iu_alloc()` return NULL on error, whereas `alloc_clt()`, `alloc_path()`, `get_or_create_srv()`, `__alloc_path()`, and `rtrs_srv_cm_init()` return `ERR_PTR`. [F39]
- After `ib_dma_map_sg()`, pass its returned coalesced count to DMA consumers (`ib_alloc_mr()`, `ib_map_mr_sg()`, `rtrs_map_sg_fr()`, `rtrs_post_rdma_write_sg()`, `for_each_sg()`), and pass the original `req->sg_cnt` or `sgt->nents` to `ib_dma_unmap_sg()`. [F151]
- `rtrs_addr_to_sockaddr()` sets `addr->src = NULL` when no `,` or `@` delimiter exists (check `path->src` before copying), and passes an un-terminated source slice of length `d - str` to `rtrs_str_to_sockaddr()`, which must bound all reads to `len`. [F47, F119]

## Error Handling
- If posting the WR in `rtrs_clt_write_req()` or `rtrs_clt_read_req()` fails after `rtrs_clt_update_all_stats()`, decrement `clt_path->stats->inflight` (if `req->mp_policy == MP_POLICY_MIN_INFLIGHT`), clear `req->mr->need_inval`, unmap SG, and clear `req->in_use = false` in the caller; `complete_rdma_req()` must return early without `WARN_ON()` when `!req->in_use`. [F12, F62, F167]
- `con->cm_err` is `0` while connecting, `1` on `RDMA_CM_EVENT_ESTABLISHED` (`flag_success_on_conn`), and `< 0` on error; `rtrs_clt_rdma_cm_handler()` must capture `rtrs_rdma_conn_established()` in local `cm_err`, and on `RDMA_CM_EVENT_DEVICE_REMOVAL` call `rtrs_clt_close_conns(clt_path, false)` and return `0` without `rtrs_rdma_error_recovery()`. [F38, F134]
- In `init_conns()`, reset `cid = clt_path->s.con_num - 1` after the creation loop before any step that can `goto destroy` (`for (i = 0; i <= cid; i++)`). In `rtrs_clt_open()`, if `init_path()` or `rtrs_clt_create_path_files()` fails, unlink and free that `clt_path` before jumping to `close_all_path`. [F84, F93]
- In `map_cont_bufs()`, errors inside the loop after `sg_alloc_table()` must unwind the current `srv_path->mrs[srv_path->mrs_num]` before calling `unmap_cont_bufs()`. Callers of `ib_map_mr_sg()` must check `nr != count` and return `nr < 0 ? nr : -EINVAL`. [F42, F95]

## External Contracts
- `rtrs_to_io_rsp_imm()` / `rtrs_from_io_rsp_imm()` pack `msg_id` in 19 bits and negated `errno` in 9 bits, so status values passed to `rtrs_srv_resp_rdma()` and `send_io_resp_imm()` must be `<= 0` with magnitude `<= 511`. On `RTRS_IO_REQ_IMM`, `rtrs_srv_rdma_done()` must verify `msg_id < srv->queue_depth` and `off < max_chunk_size` before indexing `srv_path->mrs` or `srv->chunks`, and `rtrs_clt_info_rsp_done()` must validate `wc->byte_len` against `sizeof(*msg)` and `msg->sg_cnt` before reading `msg->desc[]`. [F81, F104, F166]

## Known Pitfalls
- Allocate any `IB_WR_RDMA_WRITE_WITH_IMM` or `IB_WR_RDMA_WRITE` work request as `struct ib_rdma_wr`, never bare `struct ib_send_wr`, even when `num_sge == 0`. Every WR posted to a QP—including unsignaled chained WRs—must set `wr_cqe` to a valid `struct ib_cqe` with a non-NULL `done` callback. [F50, F111]
- `alloc_path_reqs()` allocates `req->sge` with only 2 elements (`max_send_sge = 2`), so `rtrs_post_rdma_write_sg()` must be called with `fr_en = true` whenever mapped `count > 1`, and both branches of `if (fr_en)` must leave `i` at the final SGE slot (`1` or `count`) for `req->iu`. [F97, F114]
- In `rdma_write_sg()` and `send_io_resp_imm()`, `if (need_inval && always_invalidate)` must precede `else if (always_invalidate)` and `else if (need_inval)`. In `rtrs_clt_rdma_done()` under `IB_WC_RECV_RDMA_WITH_IMM`, `RTRS_HB_MSG_IMM`/`RTRS_HB_ACK_IMM` must early-return via `rtrs_clt_recv_done(con, wc)` when `RTRS_MSG_NEW_RKEY_F` is set. [F87, F88]
- Use 32-bit types (`u32`/`int`, not `u16`) for WR/CQ depths (`max_send_wr`, `max_recv_wr`, `cq_num`, `nr_cqe`), initialize `min_latency` to `KTIME_MAX` in `get_next_path_min_latency()`, use `1ull << mr_page_shift` and `do_div()` in `query_fast_reg_mode()`, and cast `le16_to_cpu(msg->errno)` to `s16` in `rtrs_rdma_conn_rejected()`. [F100, F101, F102, F103]
