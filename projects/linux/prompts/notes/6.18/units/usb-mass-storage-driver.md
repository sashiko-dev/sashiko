# USB MASS STORAGE DRIVER

This component implements the core lifecycle, USB transfer engine, and transport protocols (Bulk-Only, Control/Bulk, and Control/Bulk/Interrupt) for the Linux USB Mass Storage driver, along with device quirk tables, UAS capability detection, and subdrivers for Shuttle USBAT bridges and Sierra Wireless TRU-Install modems.

## Architecture & Data Flow

- `us_unusual_dev_list` (`usb.c`) and `usb_storage_usb_ids` (`usual-tables.c`)—and `usbat_unusual_dev_list` / `usbat_usb_ids` (`shuttle_usbat.c`)—must expand `UNUSUAL_DEV`, `COMPLIANT_DEV`, and `USUAL_DEV` in identical 1-to-1 order because probe indexes via `(id - *_usb_ids)`. In `unusual_devs.h`, device-specific entries must precede class-wide `USUAL_DEV` entries, any `unusual_uas.h` `US_FL_IGNORE_UAS` device matching an earlier `unusual_devs.h` entry must also set `US_FL_IGNORE_UAS` there, and subdriver `unusual_*.h` headers must be in `ignore_ids[]`. [F45, F46, F47, F79]
- In `uas_use_uas_driver()` and `get_device_info()`, `usb_stor_adjust_quirks()` must be called after initializing flags from `id->driver_info` and applying descriptor-based quirks, and before testing `US_FL_IGNORE_UAS` or `US_FL_IGNORE_DEVICE`. Any `US_FL_*` flag added to the switch in `usb_stor_adjust_quirks()` must also be added to `mask` so `*fflags = (*fflags & ~mask) | f` clears the static table bit when omitted from `quirks`. [F48, F115]
- The runtime PM reference from `usb_autopm_get_interface_no_resume()` in `usb_stor_probe2()` is tracked by `US_FLIDX_SCAN_PENDING` after `scsi_add_host()` succeeds: `usb_stor_scan_dwork()` must call `usb_autopm_put_interface()` before clearing `US_FLIDX_SCAN_PENDING`, and `quiesce_and_remove_host()` drops it if `US_FLIDX_SCAN_PENDING` remains set after `cancel_delayed_work_sync()`. [F5]
- `us->max_lun` stores the inclusive maximum 0-based LUN number (bounded by `US_BULK_MAX_LUN_LIMIT = 15` in `usb_stor_Bulk_max_lun()` and checked via `srb->device->lun > us->max_lun`), whereas `Scsi_Host->max_lun` stores the exclusive LUN count (`us->max_lun + 1`). [F69]
- In `usb_stor_invoke_transport()`, `scsi_eh_restore_cmnd(srb, &ses)` must be called immediately after `us->transport(us->srb, us)` before any `goto Retry_Sense`, error exit, or inspection of `srb` fields because `scsi_eh_prep_cmnd()` overwrites `srb` in place. When disabling `US_FL_SANE_SENSE` after an oversized auto-sense times out or fails, `usb_stor_invoke_transport()` must also set `US_FL_BAD_SENSE` in `us->fflags`. [F49, F50]
- In `usb_stor_Bulk_transport()`, `bcb` (`struct bulk_cb_wrap *`) and `bcs` (`struct bulk_cs_wrap *`) alias `us->iobuf`, so receiving the CSW into `bcs` overwrites `bcb`; status-stage checks must use saved state in `us->tag`, `transfer_length`, and `srb->cmnd` rather than reading `bcb` after the CSW read. When `usb_stor_clear_halt()` clears `USB_ENDPOINT_HALT`, it must also call `usb_reset_endpoint(us->pusb_dev, endp)` on success. [F60, F106]
- In `get_pipes()`, `usb_find_int_in_endpoint()` is required only when `us->protocol == USB_PR_CBI`; for other protocols `ep_int` can be NULL and must be checked before setting `us->recv_intr_pipe` and `us->ep_bInterval`, and `usb_stor_CB_transport()` must call `usb_stor_intr_transfer()` only when `us->protocol == USB_PR_CBI`. In `uas_find_endpoints()`, `USB_DT_PIPE_USAGE` descriptors are parsed only while `extralen >= 3`, and 1-based `pipe_id` at `extra[2]` must be in `1..4` before indexing `eps[pipe_id - 1]`. [F28, F68]
- In `last_sector_hacks()`, `us->last_sector_retries` must be preserved via early return when `++us->last_sector_retries < 3` on a failed last-sector `READ_10`/`WRITE_10`, and must not be reset at `done:` when `srb->cmnd[0] == TEST_UNIT_READY`. Both `usbat_info->sectors` and `sdkp->capacity` store total sector counts, whereas SCSI `READ_CAPACITY` and `READ_10`/`WRITE_10` LBAs use 0-based sector numbers (last sector is `capacity - 1` / `info->sectors - 1`). [F76, F82]
- In `shuttle_usbat.c`, `init_usbat()` must call `usbat_set_transport()` before `usbat_get_device_type(us)`, and `usbat_flash_check_media()` / `usbat_flash_transport()` must set `info->sense_key`, `sense_asc`, and `sense_ascq` when returning `USB_STOR_TRANSPORT_FAILED`. In `usbat_hp8200e_rw_block_test()` and `usbat_multiple_write()`, `command[]` and `data[]` alias the 64-byte `us->iobuf`, so `num_registers <= 32`, `data[]` must be filled after `usbat_execute_command()`, and retries (`i > 0`) in `usbat_hp8200e_rw_block_test()` must set `cmdlen = 8`. [F62, F63, F90, F100]

## Synchronization

- When both locks are held, `us->dev_mutex` must be acquired before `scsi_lock(host)` (`host->host_lock`), and both locks must be released in `usb_stor_control_thread()` before calling `scsi_done_direct(srb)`. [F15]
- `usb_stor_invoke_transport()` is entered with `us->dev_mutex` held and must unlock `us->dev_mutex` before `usb_stor_port_reset(us)` and re-lock it afterward, because `usb_stor_port_reset()` triggers `usb_stor_pre_reset()` and `usb_stor_post_reset()`. `usb_stor_pre_reset()` locks `us->dev_mutex` and leaves it held until `usb_stor_post_reset()` unlocks it, and `usb_stor_suspend()` / `usb_stor_resume()` must hold `us->dev_mutex` around `us->suspend_resume_hook()`. [F11, F124]
- In `usb_stor_invoke_transport()`, `Handle_Errors` must hold `scsi_lock(us_to_host(us))` while setting `US_FLIDX_RESETTING` and clearing `US_FLIDX_ABORTING` in `us->dflags` before releasing `us->dev_mutex`. `scsi_lock(us_to_host(us))` must also be held around `usb_stor_report_device_reset(us)`, whereas `usb_stor_reset_resume()` and `usb_stor_post_reset()` must not hold `scsi_lock` when calling `usb_stor_report_bus_reset(us)`. [F52, F127]
- In `usb_stor_msg_common()` and `usb_stor_bulk_transfer_sglist()`, `US_FLIDX_URB_ACTIVE` and `US_FLIDX_SG_ACTIVE` must be set only after `usb_submit_urb()` or `usb_sg_init()` succeeds, after which `US_FLIDX_ABORTING` must be rechecked and cancellation guarded by `test_and_clear_bit()` on the active flag. Under `scsi_lock(host)` in `usb_stor_control_thread()`, test `US_FLIDX_TIMED_OUT` in `us->dflags` (not `srb->result == DID_ABORT << 16`) to decide whether to call `complete(&us->notify)` and clear `US_FLIDX_ABORTING` and `US_FLIDX_TIMED_OUT`. [F17, F19]
- After blocking in `usb_lock_device_for_reset()` in `usb_stor_port_reset()` or `wait_event_interruptible_timeout(us->delay_wait, ...)` in `usb_stor_reset_common()`, `US_FLIDX_DISCONNECTING` must be rechecked before calling `usb_reset_device()` or `usb_stor_clear_halt()`. [F21]
- In `usb_stor_probe1()`, `us->dev_mutex` (with `us_set_lock_class(&us->dev_mutex, intf)`), `us->cmnd_ready`, `us->notify`, `us->delay_wait`, and `us->scan_dwork` must be initialized before `associate_dev()`, and `usb_stor_acquire_resources()` must allocate `us->current_urb` and run `us->unusual_dev->initFunction` before starting `us->ctl_thread`. In `usb_stor_scan_dwork()`, calling `usb_stor_Bulk_max_lun(us)` and updating `max_lun` must be serialized under `us->dev_mutex` before `scsi_scan_host()`. [F12, F22, F136]
- URB submissions in `usb_stor_msg_common()`, scatter-gather initializations in `usb_stor_bulk_transfer_sglist()`, and command-path allocations in `shuttle_usbat.c` must use `GFP_NOIO` rather than `GFP_KERNEL`. [F129]

## Object Lifetimes

- During disconnect, `quiesce_and_remove_host()` must cancel `us->scan_dwork`, call `scsi_remove_host()`, and set `US_FLIDX_DISCONNECTING` before `release_everything()` stops `us->ctl_thread`, frees `us->extra`, `us->current_urb`, `us->cr`, and `us->iobuf`, and calls `scsi_host_put()`. `usb_stor_release_resources()` calls `us->extra_destructor(us->extra)` and then unconditionally `kfree(us->extra)`, so `extra_destructor` must not `kfree(us->extra)` itself. [F4, F104]
- In `usb_stor_control_thread()`, after processing a command, `us->srb` must be cleared to NULL under `scsi_lock(host)` before releasing `scsi_lock(host)` and `us->dev_mutex`, and `scsi_done_direct()` must be skipped when `srb->result == DID_ABORT << 16`. On loop exit, the thread must sleep until `kthread_should_stop()` returns true before returning, because `usb_stor_release_resources()` unconditionally calls `kthread_stop(us->ctl_thread)`. [F6, F7]
- In `usb_stor_msg_common()`, `us->current_urb->context` points to stack-allocated `urb_done`, so once `usb_submit_urb()` succeeds, `usb_stor_msg_common()` must wait for completion or call synchronous `usb_kill_urb(us->current_urb)` on timeout/signal before returning. [F8]

## API Contracts

- `usb_stor_control_msg()` returns transferred bytes (`>= 0`) or `-Exxx` errno, whereas `usb_stor_ctrl_transfer()` returns a non-negative `USB_STOR_XFER_*` status (`0..4`) via `interpret_urb_result()`. The severity order `USB_STOR_XFER_GOOD` (0) through `USB_STOR_XFER_ERROR` (4) in `transport.h` must be preserved because `usb_stor_CB_transport()` tests `result > USB_STOR_XFER_STALLED`. [F23, F84]
- `usb_stor_msg_common()` sets `URB_NO_TRANSFER_DMA_MAP` with `transfer_dma = us->iobuf_dma` iff `transfer_buffer == us->iobuf`; callers must pass `us->iobuf` at offset 0 or a DMA-mappable heap buffer, never `srb->cmnd` or `us->iobuf + offset`. In `usb_stor_bulk_transfer_sg()`, `void *buf` is a `struct scatterlist *` when `use_sg != 0` and a contiguous buffer when `use_sg == 0`. [F41, F42]
- `struct us_data` must be allocated via `scsi_host_alloc(sht, sizeof(*us))` in `usb_stor_probe1()` (rejecting `!hcd_uses_dma(hcd)` or `hcd->localmem_pool` on `CONFIG_HIGHMEM`) and freed via `scsi_host_put()`. `usb_stor_probe2()` must verify `us->transport` and `us->proto_handler` are non-NULL (`-ENXIO` otherwise) before `get_pipes()`, and `uas_use_uas_driver()` must return `0` (never a negative errno) when UAS is unsupported and `1` only when UAS should bind. [F27, F29, F103, F134]
- `fill_inquiry_response()` requires `data_len >= 36` with `data[0..7]` pre-populated, writes space-padded non-NUL-terminated vendor (`data+8`, 8B) and product (`data+16`, 16B) fields, and dereferences `us->unusual_dev->vendorName` and `productName` with `strlen()` whenever `!(data[0] & 0x20)`. [F105]
- In `sierra_ms.c`, `sierra_get_swoc_info()` performs DMA via `usb_control_msg()` into `swocInfo` and converts `LinuxSKU`/`LinuxVer` via `le16_to_cpu()` in place, so callers (`truinst_show()`, `sierra_ms_init()`) must `kmalloc()` `swocInfo`, check `result >= 0` before reading it, and not byte-swap again. Any `sierra_ms_init()` path that calls `sierra_set_ms_mode()` must return `-EIO` so `usb_stor_probe2()` aborts binding. [F25, F39, F64, F133]

## Error Handling

- `us->transport` callbacks must return `USB_STOR_TRANSPORT_FAILED` for command failures diagnosable via `REQUEST_SENSE` and reserve `USB_STOR_TRANSPORT_ERROR` for fatal transport failures (which skip auto-sense and trigger a reset). When auto-sense succeeds after `result != USB_STOR_TRANSPORT_GOOD` on a non-ATA-passthru command but normalized sense has `sense_key == 0`, `asc == 0`, `ascq == 0`, and `fm_ili == 0`, `usb_stor_invoke_transport()` must set `srb->result = DID_ERROR << 16` and `HARDWARE_ERROR` in `srb->sense_buffer`. [F149, F150]
- `usb_stor_invoke_transport()` must call `scsi_set_resid(srb, 0)` before `us->transport(srb, us)` and again before auto-`REQUEST_SENSE`. In `usb_stor_bulk_transfer_sglist()`, the `usb_stor_xfer_error` path must zero `*act_len` when `act_len` is non-NULL because callers unconditionally subtract `partial` from the requested length. [F37, F38]
- In `usb_stor_Bulk_transport()`, `bcb->CDB` must be zeroed with `memset()` before `memcpy(bcb->CDB, srb->cmnd, bcb->Length)` and `us->iobuf[31]` zeroed when `US_FL_BULK32` is set. When reading the CSW, `if (result == USB_STOR_XFER_STALLED)` must remain a sequential `if` after the `if (result == USB_STOR_XFER_SHORT && cswlen == 0)` retry rather than an `else if`. [F36, F86]
- `usb_stor_Bulk_max_lun()` must return `0` whenever `usb_stor_control_msg()` returns `<= 0` or `us->iobuf[0] > US_BULK_MAX_LUN_LIMIT`, never a negative errno, because its return value is assigned to `u8 us->max_lun`. In `init_usbat()`, non-zero `USB_STOR_XFER_*` / `USB_STOR_TRANSPORT_*` statuses must be translated to `-EIO` before returning. [F24, F26]
- In `usb_stor_reset_common()`, `usb_stor_clear_halt()` on `recv_bulk_pipe` and `send_bulk_pipe` must use separate variables (`result`, `result2`), overwriting `result` with `result2` only when `result >= 0`. In `usb_stor_acquire_resources()`, `th = kthread_run(...)` must be checked with `IS_ERR(th)` before assigning `us->ctl_thread = th` so `usb_stor_release_resources()` never passes an `ERR_PTR` to `kthread_stop()`. [F33, F34]
- In `last_sector_hacks()`, both `disk = scsi_cmd_to_rq(srb)->q->disk` and `sdkp = scsi_disk(disk)` can be NULL and must be checked before dereferencing `sdkp->capacity`. In `usbat_hp8200e_handle_read10()`, `srb->transfersize` must be defaulted to `2048` when `0` before dividing by it. [F32, F95]

## External Contracts

- In `usb_stor_Bulk_transport()`, `bcb->Signature`, `bcb->DataTransferLength`, and `bcs->Residue` use `__le32`, whereas `bcb->Tag` and `bcs->Tag` use native host endianness (`us->tag`), and `bcs->Residue` must be clamped to `min(residue, transfer_length)` before updating `scsi_resid`. [F73]

## Known Pitfalls

- `us->dflags` is an `unsigned long` using atomic bitops with `US_FLIDX_*` indices, whereas `us->fflags` is a `u64` bitmask of `US_FL_*` flags initialized from `usb_device_id::driver_info` (`kernel_ulong_t`, 32-bit on 32-bit platforms); never put a `US_FL_*` flag above bit 31 in `UNUSUAL_DEV()` or mix `US_FLIDX_*` and `US_FL_*`. Probe functions on drivers without `.no_dynamic_id = 1` must bounds-check `id` against the static `usb_device_id` table before indexing `unusual_dev_list`, falling back to `for_dynamic_ids`. [F66, F107]
- For shared USB bridge VID:PIDs where only specific models have broken UAS, set `US_FL_IGNORE_UAS` conditionally in `uas_use_uas_driver()` (with NULL checks on `udev->manufacturer`/`product`) rather than in `unusual_uas.h`, and ensure `uas_find_endpoints(alt, eps)` succeeds before dereferencing `eps[1]->ss_ep_comp`. [F91, F114]
- In `usb_stor_invoke_transport()`, store the auto-sense `us->transport()` return in `temp_result` (not `result`), and when an 18B (`US_SENSE_SIZE`) auto-sense returns `0x70..0x73` with `srb->sense_buffer[7] > US_SENSE_SIZE - 8`, clamp `srb->sense_buffer[7]` to `US_SENSE_SIZE - 8` before `scsi_normalize_sense()` or `scsi_sense_desc_find()`. [F72, F81]
- In `usb_stor_Bulk_transport()`, if data-in is skipped and returns a 13B CSW (`US_BULK_CS_WRAP_LEN`) during the data stage, copy it from `srb` into `bcs` via `usb_stor_access_xfer_buf()` and set `scsi_set_resid(srb, transfer_length)` before `goto skipped_data_phase`. [F85]
- In `shuttle_usbat.c`, initialize `sg = NULL` and `sg_offset = 0` once outside the chunking loops of `usbat_flash_read_data()`, `usbat_flash_write_data()`, and `usbat_hp8200e_handle_read10()`; cast the high byte to `u32` before `<< 24` when assembling sector counts/LBAs into `unsigned long`; and keep `status == 0xA1` in `if (status == 0xA1 || !(status & 0x01))` in `usbat_identify_device()`. [F88, F89, F93]
- `parse_delay_str()` must check `n > 0`, `n >= l` before suffix subtraction, and `n + n2 <= sizeof(buf) - 1` before copying into the 16-byte `buf`; `format_delay_ms()` must use `do_div()` rather than `/` or `%` with `int_pow(10, ndecimals)` on `u64` values. [F78, F96]
