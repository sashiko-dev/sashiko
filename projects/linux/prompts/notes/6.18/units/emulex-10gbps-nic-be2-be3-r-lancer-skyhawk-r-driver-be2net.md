# EMULEX 10Gbps NIC BE2, BE3-R, Lancer, Skyhawk-R DRIVER (be2net)

This unit implements the PCI and `net_device` lifecycle, TX/RX/event queue management, NAPI polling, SR-IOV virtual function provisioning, hardware error recovery, and `ocrdma` RoCE registration for Emulex OneConnect/BladeEngine 10Gbps NICs (BE2, BE3-R, Lancer, and Skyhawk-R).

## Architecture & Data Flow
- `AMAP_GET_BITS` and `AMAP_SET_BITS` operate on host-endian `u32` dwords: DMA completions and stats must be swapped with `be_dws_le_to_cpu()` before reading fields, TX header WRBs swapped with `be_dws_cpu_to_le()` in `be_tx_setup_wrb_hdr()` must only be mutated afterward with `cpu_to_le32()` masks (as in `be_xmit_flush()`), and in `be_rx_compl_get()` `rxcp->vlan_tag` must be byte-swapped with `swab16()` on `!lancer_chip(adapter)` before masking with `VLAN_VID_MASK`, testing `adapter->vids`, or calling `__vlan_hwaccel_put_tag()`. [F74, F78]
- In `be_xmit_enqueue()`, `be_tx_setup_wrb_hdr()` must only record `txo->sent_skb_list[head]`, `txq->used`, `txo->last_req_hdr`, `txo->last_req_wrb_cnt`, and `txo->pend_wrb_cnt` after all fragment DMA mappings succeed so `be_xmit_restore()` can roll back failed mappings; on `!lancer_chip(adapter)`, when `be_xmit_flush()` pads an odd `txo->pend_wrb_cnt` with a dummy WRB, it must increment `txq->head`, `txq->used`, `txo->pend_wrb_cnt`, and `TX_HDR_WRB_NUM` at `txo->last_req_hdr` before notifying hardware and zeroing `txo->pend_wrb_cnt`. [F55, F56]
- `adapter->pmac_id` has `be_max_uc(adapter)` entries (`pmac_id[0]` for primary `adapter->dev_mac`, `pmac_id[1..uc_macs]` for `adapter->uc_list[0..uc_macs-1]`, giving secondary unicast capacity `be_max_uc(adapter) - 1`). `be_dev_mac_add()` and `be_uc_mac_add()` must alias `pmac_id[0]` and `pmac_id[uc_idx + 1]` when primary and secondary MACs match, and `be_dev_mac_del()` / `be_uc_mac_del()` must skip `be_cmd_pmac_del()` while the other slot still references that `pmac_id`. [F51, F66]
- `adapter->dev_mac` must strictly mirror the primary MAC programmed in hardware (`adapter->pmac_id[0]`), updated only after hardware activation in `be_mac_addr_set()`, `be_enable_if_filters()`, or BE3 VF `be_mac_setup()`, and zeroed on deletion in `be_disable_if_filters()`. Broken by: updating `adapter->dev_mac` in `be_mac_addr_set()` when `!netif_running(netdev)` or not zeroing it in `be_disable_if_filters()`. [F50]
- In `be_map_pci_bars()`, `SLI_INTF_REG_OFFSET` must be read to populate `adapter->sli_family` and `adapter->virtfn` before calling `be_physfn()`, `be_virtfn()`, or `db_bar()`. `csr` is mapped only when `BEx_chip(adapter) && be_physfn(adapter)`, and `pcicfg` is populated only when `skyhawk_chip(adapter) || BEx_chip(adapter)` (where VFs alias `adapter->db + SRIOV_VF_PCICFG_OFFSET` with `pcicfg_mapped = false`), so `be_unmap_pci_bars()` must check `adapter->pcicfg && adapter->pcicfg_mapped`. [F40, F121]
- RSS RX queues occupy `adapter->rx_obj[0 .. adapter->num_rss_qs - 1]` (`for_all_rss_queues`) while `default_rxo(adapter)` is at `adapter->rx_obj[adapter->num_rx_qs - 1]`. Per-EQ RX/TX processing in `be_poll()` and `be_get_new_eqd()` must iterate with `for_all_rx_queues_on_eq` and `for_all_tx_queues_on_eq` (stepping by `adapter->num_evt_qs` from `eqo->idx`), and `be_rx_qs_create()` must post at most `RX_Q_LEN - 1` fragments so `rxq->head` does not wrap to equal `rxq->tail`. [F70, F71, F97]
- In `be_rxq_notify()`, `be_txq_notify()`, `be_eq_notify()`, and `be_cq_notify()`, the doorbell `iowrite32()` to `adapter->db` must be skipped if `be_check_error(adapter, BE_ERROR_HW)` is true, and `be_rxq_notify()` and `be_txq_notify()` must execute `wmb()` before `iowrite32()`. [F129]
- In `be_get_wrb_params_from_skb()`, `skb_is_gso(skb)` must be mutually exclusive (`else if`) with `skb->ip_summed == CHECKSUM_PARTIAL` so GSO packets only set `LSO`/`LSO6` and never `IPCS`, `TCPCS`, or `UDPCS` in `wrb_params->features`. [F85]
- `be_vid_config()` copies every set bit in `adapter->vids` into a 64-element stack array `vids[BE_NUM_VLANS_SUPPORTED]` when `adapter->vlans_added <= be_max_vlans(adapter)`, so `be_vlan_add_vid()` and `be_vlan_rem_vid()` must keep `adapter->vlans_added` equal to the bitmap weight of `adapter->vids`. [F113]
- `be_update_queues()` must not call `be_msix_disable()` when `adapter->num_msix_roce_vec` is non-zero because those MSI-X vectors are shared with `ocrdma` via `_be_roce_dev_add()`. [F61]

## Synchronization
- `be_set_rx_mode()` runs in atomic context under `netif_addr_lock_bh` and must defer `__be_set_rx_mode()` to `be_wq` via `be_alloc_work()` (`GFP_ATOMIC`). `adapter->rx_filter_lock` must be held across all updates to `vids`, `vlans_added`, `uc_list`, `uc_macs`, `mc_list`, `mc_count`, and `pmac_id` in `be_mac_addr_set()`, `be_vlan_add_vid()`, `be_vlan_rem_vid()`, and `__be_set_rx_mode()`; in `be_set_mc_list()` and `be_set_uc_list()`, `netif_addr_lock_bh(netdev)` must wrap `__dev_mc_sync`/`__dev_uc_sync` and address copying, and be released before firmware commands. [F20, F21, F135]
- `be_ndo_bridge_getlink()` is invoked under `rcu_read_lock()`, so neither it nor `be_cmd_get_hsw_config()` and its MCC command path may sleep or acquire a sleeping mutex. When `be_process_mcc(adapter)` is called from process/workqueue context (such as `be_worker()`), callers must wrap it in `local_bh_disable()` / `local_bh_enable()` because it acquires `adapter->mcc_cq_lock` with `spin_lock()`. [F29, F136]
- `be_setup_queues()` and `be_update_queues()` call `netif_set_real_num_rx_queues()` and `netif_set_real_num_tx_queues()` without taking `rtnl_lock()`, so non-RTNL callers (`be_setup()`, `be_pci_sriov_configure()`) must hold `rtnl_lock()` while `be_update_queues()` must not unlock it. In `be_update_queues()`, when `netif_running(netdev)` holds, `netif_carrier_off(netdev)` must run inside `netif_tx_lock_bh()` / `netif_tx_unlock_bh()` before `be_close()`; in `be_cleanup()`, `rtnl_lock()` must wrap `netif_device_detach()` and `be_close()` and be released before `be_clear()`. [F17, F27, F34]
- In `be_close()`, `flush_workqueue(be_wq)` must precede `be_disable_if_filters()`, `napi_disable()` and `be_async_mcc_disable()` must precede `netif_tx_disable()` and `be_tx_compl_clean()`, and all EQs must be synchronized (`synchronize_irq()`) and cleaned (`be_eq_clean()`) after `be_rx_qs_destroy()` and before `be_irq_unregister()`. In `be_clear()`, `be_cancel_worker(adapter)` and `flush_workqueue(be_wq)` must run before `be_vf_clear()`, `be_if_destroy()`, `be_clear_queues()`, and `be_msix_disable()`. [F25, F26]
- `be_adapter_list_lock` must be held across all accesses to `ocrdma_drv`, `be_adapter_list`, `adapter->entry`, and `adapter->ocrdma_dev` in `be_roce.c`, including while invoking `ocrdma_drv->add`, `ocrdma_drv->remove`, and `ocrdma_drv->state_change_handler`. [F22]
- In `be_rx_compl_get()`, `be_tx_compl_get()`, and `events_get()`, after observing a non-zero valid/event bit, an `rmb()` must execute before reading or byte-swapping (`be_dws_le_to_cpu()`) the entry's fields, and the valid/event bit must be zeroed before advancing the queue tail. In `be_intx()`, `events_get(eqo)` and `__napi_schedule(&eqo->napi)` must only be called if `napi_schedule_prep(&eqo->napi)` returns true; otherwise `be_eq_notify()` must be called with `num_popped = 0`. [F23, F130]
- `be_post_rx_frags()` must receive `GFP_ATOMIC` from NAPI (`be_process_rx()`) and `GFP_KERNEL` from process context (`be_rx_qs_create()`, `be_rx_qs_destroy()`, `be_worker()`). When `be_post_rx_frags()` fails to post any buffers and `atomic_read(&rxq->used) == 0`, it sets `rxo->rx_post_starved = true`; while set, `be_process_rx()` must not call `be_post_rx_frags()`, leaving `be_worker()` as the sole producer. [F31, F138]

## Object Lifetimes
- `be_xmit_workarounds()`, `be_lancer_xmit_workarounds()`, and `be_insert_vlan_in_pkt()` consume and free `skb` before returning `NULL` (so `be_xmit()` must not free `skb` on `NULL`), whereas `be_xmit_enqueue()` unmaps fragments via `be_xmit_restore()` and returns `0` without freeing `skb` (so `be_xmit()` must call `dev_kfree_skb_any(skb)` on `0`). When `be_send_pkt_to_bmc()` returns true, `be_xmit()` must call `skb_get(skb)` only if the second (`OS2BMC`) `be_xmit_enqueue()` succeeds, using atomic-safe SKB APIs throughout. [F1, F2, F139, F160]
- `be_tx_setup_wrb_hdr()` asserts `BUG_ON(txo->sent_skb_list[head])` and stores `skb` only at its header WRB index. In `be_tx_compl_process()` (up to inclusive `last_index`), each non-NULL `sent_skbs[txq->tail]` frees the prior `skb` (`dev_consume_skb_any()`), clears `sent_skbs[txq->tail] = NULL`, and skips the header WRB, freeing the final `skb` after the loop; in `be_tx_compl_clean()`, cleaning unnotified WRBs must pass `index_adv(txq->tail, atomic_read(&txq->used) - 1)`, zero `txo->pend_wrb_cnt`, and reset `txq->head` and `txq->tail` to `notified_idx`. [F13, F57, F67, F68, F93]
- Every consumer of `get_rx_page_info()` (`skb_fill_rx_data()`, `be_rx_compl_process_gro()`, `be_rx_compl_discard()`, `be_rxq_clean()`) must clear `page_info->page = NULL` because `be_post_rx_frags()` stops posting at the first non-NULL `page_info->page`. When coalescing RX fragments in `skb_fill_rx_data()` and `be_rx_compl_process_gro()`, any fragment with `page_offset != 0` (after the first fragment) merged into the preceding `skb_frag_t` via `skb_frag_size_add()` must drop its page reference with `put_page(page_info->page)`. [F11, F12]
- In `be_setup_queues()`, `be_mcc_queues_create()` must run after `be_evt_queues_create()` and `be_tx_qs_create()`, and `be_clear_queues()` must destroy MCC, RX CQ, and TX queues before `be_evt_queues_destroy()`. In `be_rx_qs_destroy()`, for each `q->created`, on `lancer_chip(adapter)` the driver must first call `be_rx_cq_clean(rxo)` and (if `atomic_read(&q->used) == 0`) `be_post_rx_frags(rxo, GFP_KERNEL, MAX_RX_POST)`, then on all chips call `be_cmd_rxq_destroy()` and `be_rx_cq_clean()` before `be_rxq_clean()` and `be_queue_free()`. [F7, F8, F96, F119]
- In `be_roce.c`, `ocrdma_drv` and `adapter->ocrdma_dev` are nullable; `_be_roce_dev_remove()` and `be_roce_dev_shutdown()` must check `ocrdma_drv`, `adapter->ocrdma_dev`, and the callback pointer. `_be_roce_dev_remove()` must clear `adapter->ocrdma_dev = NULL` after `ocrdma_drv->remove(adapter->ocrdma_dev)`, and neither `_be_roce_dev_remove()` nor `be_roce_unregister_driver()` may unlink `adapter->entry` from `be_adapter_list` (only `be_roce_dev_remove()` calls `list_del(&adapter->entry)`). [F15, F42, F89]

## API Contracts
- `be_post_rx_frags()` maps each `adapter->big_page_size` page once with `dma_map_page()` and sets `last_frag = true` with `page_dmaaddr` in `bus` only on the last posted fragment of that page (`frag_dmaaddr` on earlier fragments), so `get_rx_page_info()` calls `dma_unmap_page()` when `last_frag` is true and `dma_sync_single_for_cpu()` otherwise. `be_xmit_enqueue()` maps linear SKB data with `dma_map_single()` and paged fragments with `skb_frag_dma_map()`, so `unmap_tx_frag()` must pass `unmap_single = true` only for the first data WRB when `skb_headlen(skb) > 0`. [F149, F150]
- `NETIF_F_GSO_UDP_TUNNEL` is set once in `be_netdev_init()`, while `be_vxlan_set_port()` / `be_vxlan_unset_port()` must sync `BE_FLAGS_VXLAN_OFFLOADS`, `vxlan_port`, and `hw_enc_features` without touching `hw_features` or `features`. In `be_features_check()`, encapsulated packets with `BE_FLAGS_VXLAN_OFFLOADS` must strip `NETIF_F_CSUM_MASK | NETIF_F_GSO_MASK` unless UDP `ETH_P_TEB` matches `vxlan_port`; GSO packets must clear `NETIF_F_TSO6` on `!skyhawk_chip && is_ipv6_ext_hdr`, and `NETIF_F_GSO_MASK` on `lancer_chip` if `gso_size < 256` or `gso_segs == 1`. [F54, F153, F154, F155]
- In SR-IOV code, `adapter->vf_cfg[vf]` and NDO VF callbacks use 0-based `vf` (`0 <= vf < adapter->num_vfs`) validated with `sriov_enabled(adapter)` before dereferencing `vf_cfg`, whereas firmware commands take `0` for the PF and `vf + 1` for VF `vf` (except `be_cmd_get_if_id()`, which takes 0-based `vf`). Because `be_cmd_set_hsw_config()` treats `pvid == 0` and `spoofchk == 0` as no-ops, `be_clear_vf_tvt()` must pass `BE_RESET_VLAN_TAG_ID` (`0xFFFF`) as `pvid` and `be_set_vf_spoofchk()` must pass `ENABLE_MAC_SPOOFCHK` (`0x2`) or `DISABLE_MAC_SPOOFCHK` (`0x3`). [F48, F69]

## Error Handling
- Firmware command helpers (`be_cmd_*`) return positive MCC completion codes as well as negative errnos, so kernel callbacks (`be_set_vf_mac`, `be_set_vf_vlan`, `be_set_vf_tx_rate`, `be_set_vf_link_state`, `be_set_vf_spoofchk`, `be_pci_sriov_configure`) must convert non-zero `status` via `be_cmd_status(status)`. [F35]
- In `be_process_rx()`, an RX completion with `rxcp->num_rcvd == 0` is a flush completion that consumes no `rxo->q` descriptors, whereas a completion with `rxcp->num_rcvd != 0` and `rxcp->pkt_size == 0` must call `be_rx_compl_discard(rxo, rxcp)` to pop and free `rxcp->num_rcvd` RX ring fragments before skipping packet assembly. [F73]

## Known Pitfalls
- `be_insert_vlan_in_pkt()` must unshare cloned SKBs via `skb_share_check(skb, GFP_ATOMIC)` and clear the hwaccel tag with `__vlan_hwaccel_clear_tag(skb)` before calling `vlan_insert_tag_set_proto()`, and because this can reallocate `skb` or `skb->head`, callers (`be_lancer_xmit_workarounds()` and `be_send_pkt_to_bmc()`) must not dereference cached header pointers (`veh`, `eh`, `ip`) afterward without re-fetching them. [F114, F159]
- Because `be_rx_compl_get()` parses each RX completion into the persistent per-queue `rxo->rxcp` without zeroing it and `be_parse_rx_compl_v0()`/`v1()` only write `rxcp->qnq` and `rxcp->vlan_tag` when `rxcp->vlanf` is set, callers must check `rxcp->vlanf` before reading `rxcp->qnq` or `rxcp->vlan_tag`. [F44]
- Multi-bit flag and stage checks must compare against the full mask (`(val & MASK) == MASK`) rather than a non-zero bitwise AND: this applies to `BE_IF_FLAGS_ALL_PROMISCUOUS` on `adapter->if_flags` (in `be_in_all_promisc()` and `__be_set_rx_mode()`) and to `POST_STAGE_FAT_LOG_START`, `POST_STAGE_ARMFW_UE`, and `POST_STAGE_RECOVERABLE_ERR` on `be_POST_stage_get(adapter)`. [F82, F83]
