# ISDN/mISDN SUBSYSTEM

`drivers/isdn/mISDN` provides the core mISDN protocol stack infrastructure: hardware D/B-channel queuing (`hwchannel.c`), Layer 1 S0 state machines (`layer1.c`), Layer 2 LAPD/LAPB and TEI management (`layer2.c`, `tei.c`), per-device routing kthreads (`stack.c`), `PF_ISDN` sockets (`socket.c`), a userspace timer device (`timerdev.c`), and the Layer-1-over-IP virtual tunnel (`l1oip_core.c`, `l1oip_codec.c`).

## Architecture & Data Flow

- In `struct layer2`, `l2->tm` is `NULL` for LAPB (`ISDN_P_B_X75SLP`) and non-`NULL` only for LAPD; shared Layer 2 paths must guard `l2_tei()` and `TEIrelease()` with `if (l2->tm)` or `test_bit(FLG_LAPD, &l2->flag)`. In NT mode, `free_teimanager()` clears `mgr->up` and every active `l2->up` to `NULL` when `!OPTION_L2_CLEANUP`, so upstream paths (`l2up`, `l2up_create`, `l2_send`, `mgr_send`) must check `l2->up` or `mgr->up` before calling `->send()` or `teiup_create()`. [F36, F37]
- For Layer-1 `PF_ISDN` sockets (`ISDN_P_TE_S0`, `ISDN_P_NT_S0`, `ISDN_P_TE_E1`, `ISDN_P_NT_E1`), `data_sock_bind()` must unlink `sk` from `data_sockets` before `connect_layer1()` adds `sk->sk_node` to `dev->D.st->l1sock.head` (relinking on error), and `data_sock_release()` must unlink from `data_sockets` only when `sk->sk_state != MISDN_BOUND`. [F59]
- In `layer2.c`, `l2->sow` must stay synchronized with `l2->va` as the circular start-of-window index into `l2->windowar[0..l2->window - 1]`, advancing by `(l2->sow + 1) % l2->window` in `setva()` and resetting to `0` whenever `l2->va`, `l2->vs`, and `l2->vr` reset in `l2_start_multi()`, `l2_restart_multi()`, and `l2_connected()`. [F53]
- `DL_UNITDATA_REQ` `sk_buff`s passed to `l2_send` (`tx_ui`) or `mgr_send` (`dl_unit_data`) must have at least 3 bytes of headroom because `tx_ui` and `dl_unit_data` call `skb_push` directly. When `mgr_bcast` sends `DL_INTERN_MSG` to `l2_send`, the original `struct mISDNhead` must be saved at `mISDN_HEAD_P(skb) + 1` in `skb->cb` so `l2_send` can restore `*hh = *(hh + 1)`. [F106, F108]
- `mISDN_ctrl_bchannel(MISDN_CTRL_RX_BUFFER)` must write new RX bounds only to `bch->next_maxlen` and `bch->next_minlen` until `bchannel_get_rxbuf()` updates `bch->maxlen` and `bch->minlen` on new `bch->rx_skb` allocation. `mISDN_clear_bchannel()` must clear only transient flags (`FLG_TX_BUSY`, `FLG_TX_NEXT`, `FLG_ACTIVE`, `FLG_FILLEMPTY`, `FLG_TX_EMPTY`, `FLG_RX_OFF`) and restore active/next `minlen`/`maxlen` from `init_minlen`/`init_maxlen` without zeroing `ch->Flags`. [F49, F50]
- In `layer1.c`, `layer2.c`, and `tei.c`, each FSM's state/event enum, `*_COUNT` macro, and `str*State`/`str*Event` array must be updated in lockstep. U-frame checks (`IsUI`, `IsUA`, `IsDM`, `IsDISC`, `IsFRMR`, `IsSABME`, `ph_data_ind`, `check_data`) must mask out the P/F bit (`0x10`), `IsSFrame` (after `d &= 0xf` when `!FLG_MOD128`) must require `(d & 0xf3) == 1 && (d & 0x0c) != 0x0c`, and `ph_data_ind` in `tei.c` must verify `skb->len >= 8` before indexing `&skb->data[4]`. [F51, F75, F81, F82]
- In `tei.c`, `get_free_id` allocates 1-based `l2->ch.nr` (`1..63`) by rejecting `l2->ch.nr > 63` before `__set_bit` and searching from bit 1 via `find_next_zero_bit(ids, 64, 1)`; `get_free_tei` maps dynamic TEIs (`64..127`) into `ids` by skipping `i < 64`, subtracting `64` before `__set_bit`, and adding `64` to `find_first_zero_bit(ids, 64)`. [F76, F77]
- In `l1oip`, per-channel 4-bit compression state must be kept in `hc->chan[channel].codecstate` (`0x100 + *data` when a byte is buffered) and reset to `0` on `PH_ACTIVATE_REQ` in `handle_bmsg()`. `l1oip_timeout()` must reset `hc->timeout_on = 0` because `l1oip_socket_parse()` skips `mod_timer(&hc->timeout_tl, ...)` when `hc->timeout_on` is set. [F61, F62]
- In `l1oip_socket_parse`, multiframe (`m == 1`) length `mlen == 0` encodes `256` bytes, and `len > mlen + 3` (`len >= 2` when `m == 0`) must be verified before reading `timebase` and advancing `buf`/`len`. `l1oip_socket_recv()` must reject `channel < 1 || channel > 127` (`0` is reserved; `hc->d_idx` at `3` or `16` is skipped in `init_card`), and expanding 16-bit `timebase` into `rx_counter` must test `((s16)(timebase - rx_counter)) >= 0` before adjusting upper 16 bits by `0x10000`. [F70, F71, F96]

## Synchronization

- Callers of `dchannel_senddata` and `bchannel_senddata` must hold the hardware driver lock across the call to serialize `FLG_TX_BUSY`, `tx_skb`, `tx_idx`, `next_skb`, and `squeue` against interrupt-driven `get_next_dframe` and `get_next_bframe`. [F19]
- In `mISDNStackd`, after `skb_dequeue(&st->msgq)` returns `NULL` and `test_and_clear_bit(mISDN_STACK_WORK, &st->status)` clears the flag, `mISDNStackd` must re-check `skb_dequeue(&st->msgq)` and re-set `mISDN_STACK_WORK` if non-empty. `st->lmutex` protects `st->layer2`: `__add_layer2` requires `st->lmutex` held (e.g., `create_new_tei` under `send_layer2`), whereas unlocked callers must use `add_layer2`. [F25, F26]
- In `tei.c`, `mgr->lock` is taken in softirq timer `da_timer` (`read_lock_irqsave`), so writers on `mgr->layer2` (`create_new_tei`, `create_teimgr`, `TEIrelease`) must use `write_lock_irqsave` and allocations under `mgr->lock` (`mgr_bcast`) must use `GFP_ATOMIC`. Never hold `mgr->lock` across `l2->ch.ctrl(&l2->ch, CLOSE_CHANNEL, NULL)` because `TEIrelease` acquires `write_lock_irqsave(&tm->mgr->lock, flags)`. [F27, F129]
- Every `struct mISDN_sock_list` (`st->l1sock`, `data_sockets`, `base_sockets`) requires `write_lock_bh` around `sk_add_node`/`sk_del_node_init` and `read_lock`/`read_lock_bh` around `sk_for_each`; `send_socklist` must use `GFP_ATOMIC` for `skb_copy` under `read_lock(&sl->lock)`. [F29, F131]
- In `timerdev.c`, `dev->lock` is taken in softirq `dev_expire_timer`, so process callers must use `spin_lock_irq(&dev->lock)` and never call `put_user`, `GFP_KERNEL` allocs, or `timer_shutdown_sync(&timer->tl)` under it. `misdn_del_timer()` must call `list_del_init(&timer->list)` and set `timer->id = -1` before dropping `dev->lock` for `timer_shutdown_sync()`, whereas `mISDN_close()` must drop `dev->lock` for `timer_shutdown_sync()`, re-acquire `spin_lock_irq(&dev->lock)` before `list_del(&timer->list)`, and re-fetch `list_first_entry(&dev->pending, ...)`. [F24, F60, F132]
- Softirq timers must defer work: `l2_timeout` (`EV_L2_T200`, `EV_L2_T203`) must allocate with `GFP_ATOMIC` and queue `DL_TIMER200_IND`/`DL_TIMER203_IND` to `l2->ch.st->own.recv`, and `l1oip_keepalive` (`hc->keep_tl`) must schedule `hc->workq` (`l1oip_send_bh`) instead of calling `l1oip_socket_send` (`kernel_sendmsg`). [F128, F134]

## Object Lifetimes

- `get_next_dframe` and `get_next_bframe` overwrite `tx_skb` without freeing the old buffer (and `get_next_bframe` clears `bch->next_skb = NULL`), so callers must free `tx_skb` first. `recv_Dchannel`/`recv_Echannel` always consume and `NULL` out `rx_skb`, whereas `recv_Bchannel` leaves `bch->rx_skb` non-`NULL` when `FLG_TRANSPARENT`, `bch->rx_skb->len < bch->minlen`, and `!force`; `bchannel_get_rxbuf` must flush any lingering `bch->rx_skb` via `recv_Bchannel(bch, 0, true)` before overwriting it. [F3, F4]
- `mISDN_freebchannel` must call `cancel_work_sync(&ch->workq)` before `mISDN_clear_bchannel(ch)` purges `ch->rqueue`, and `mISDN_clear_bchannel` must set `tx_skb`, `rx_skb`, and `next_skb` to `NULL` after freeing them. `mISDN_initdchannel()` runs `INIT_LIST_HEAD(&ch->dev.bchannels)` and must precede linking any `bchannel` into `dch->dev.bchannels`. [F5, F117]
- `release_l1` (`CLOSE_CHANNEL`) must delete `l1->timerX` and `l1->timer3`, clear `l1->dch->l1 = NULL`, and call `module_put(THIS_MODULE)` before freeing `l1`. `create_stack` and `delete_stack` pass a stack `struct completion` in `st->notify` and must wait on it when `mISDNStackd` is running; `mISDNStackd` must clear `st->notify = NULL` after each `complete(st->notify)` and `st->thread = NULL` before final completion. [F6, F7]
- Slots in `l2->windowar` must be set to `NULL` when freed in `freewin`, moved in `setva`, or requeued in `invoke_retransmission`. `l2_pull_iqueue` must send `nskb = skb_realloc_headroom(skb, i)` to Layer 1 while keeping the unpushed `skb` in `l2->windowar[p1]`, and requeue `skb` at the head of `l2->i_queue` if `skb_realloc_headroom` fails. [F12, F13]
- In `release_l2`, when `FLG_LAPD` is set, `TEIrelease(l2)` and `l2->ch.st->dev->D.ctrl(&l2->ch.st->dev->D, CLOSE_CHANNEL, NULL)` must precede `kfree(l2)`. In `send_socklist` and `mgr_bcast`, `cskb` must be reset to `NULL` only when `sock_queue_rcv_skb` or `ch->st->own.recv` returns `0` so rejected clones are reused or freed after the loop. [F14, F88]
- `l1oip_socket_send` sets `hc->socket = NULL` under `hc->socket_lock` during `kernel_sendmsg` and restores it after; `l1oip_socket_thread` must wait until `hc->socket` is non-`NULL` and clear `hc->socket = NULL` under `hc->socket_lock` before `sock_release`. `release_card` must set `hc->shutdown = true` and stop `keep_tl`, `timeout_tl`, `workq`, and `socket_thread` before unregistering and freeing `dch`, `bch`, and `hc`. `l1oip_4bit_free` must reset `table_com`/`table_dec` to `NULL`, and `l1oip_4bit_alloc` must use `vzalloc()` and call `l1oip_4bit_free` on failure. [F16, F17, F18, F41]

## API Contracts

- `dchannel_senddata` and `bchannel_senddata` consume `skb` on return `0` or `1`, leave `skb` unconsumed on `< 0`, and require `PH_DATA_REQ` handlers to convert `1` to `0`. Unlike `bchannel_senddata()`, `dchannel_senddata()` does not call `confirm_Dsend()` on return `1`, so D-channel `PH_DATA_REQ` handlers must queue `PH_DATA_CNF` themselves when it returns `1`. [F2, F31]
- `bchannel_get_rxbuf()` returns tailroom or `< 0` errno; callers must check `< 0` in a signed int before using `bch->rx_skb`. `recv_Dchannel`/`recv_Echannel` must drop frames with `rx_skb->len < 2` before `get_sapi_tei`, and `recv_Echannel` must read/clear `ech->rx_skb` while queuing and scheduling `FLG_RECVQUEUE` on `dch`. [F32, F78, F94]
- `mISDN_initdchannel()` only sets `FLG_HDLC` in `ch->Flags`, so callers must zero-allocate `struct dchannel` first; `phf` is invoked by `dchannel_bh` as `void (*)(struct dchannel *)`. `l1->dcb` (`create_l1`) runs in softirq/spinlock contexts and must not sleep. [F43, F109, F127]
- `setva` and `invoke_retransmission` require `legalnr(l2, nr)` to be true first. In `create_l2entity` (`stack.c`), after `dev->teimgr->ctrl(..., OPEN_CHANNEL, &rq)` succeeds, `ISDN_P_LAPD_NT` must check `!rq.ch` before `add_layer2(rq.ch, ...)` because `create_teimgr` sets `crq->ch = NULL` when `tei == 127`. [F83, F92]
- D/B-channel `CONTROL_CHANNEL` handlers take `struct mISDN_ctrl_req *` and must set supported bits on `MISDN_CTRL_GETOP`, whereas `dev->teimgr->ctrl` (`ctrl_teimanager`) expects `int val[2]`. `connect_layer1` and `delete_channel` use `container_of(ch, struct mISDN_sock, ch)` and require `ch` to be embedded in `struct mISDN_sock`. [F110, F111, F122]
- `set_channelmap`/`clear_channelmap` require `nr <= MISDN_MAX_CHANNEL` (127) and `u_char channelmap[]` must never be passed to `unsigned long *` bitops. B-channel protocol IDs (`0x21..0x28`) must be masked with `ISDN_P_B_MASK` (`0x1f`) before shifting (`1 << (protocol & ISDN_P_B_MASK)`). [F44, F114]
- `l1oip_socket_send` callers must bound chunk `len` to `MAX_DFRAME_LEN_L1` (300). `l1oip_law_to_4bit` requires `(len + 1) / 2` output bytes, and `l1oip_4bit_to_law` (`remotecodec == 3`) requires `skb_put(..., len << 1)` bytes. [F68, F69, F104]

## Error Handling

- In `connect_Bstack` (`stack.c`), `bp->create(&rq2)` updates `rq2.ch`/`rq2.protocol`; if `dev->D.ctrl(&dev->D, OPEN_CHANNEL, &rq)` (using `rq.protocol = rq2.protocol`) fails, call `rq2.ch->ctrl(rq2.ch, CLOSE_CHANNEL, NULL)`, else link `ch` to `rq2.ch`, cross-link `rq2.ch` and `rq.ch`, and set `ch->nr = rq.ch->nr`. In `create_new_tei` and `create_teimgr`, once `l2->list` is in `mgr->layer2`, clean up on failure via `l2->ch.ctrl(&l2->ch, CLOSE_CHANNEL, NULL)` instead of `kfree(l2)`. [F8, F15, F95]
- `l2_send()` requires `mISDN_FsmEvent()`, `ph_data_indication()`, and `ph_data_confirm()` to return non-zero when `skb` is unconsumed and `0` when consumed/freed. Primitives with `(hh->prim & MISDN_LAYERMASK) == 0x8` must go via `l2->up->send` (`l2up`/`l2up_create`), not `st->msgq`. [F34, F150]
- In `l1oip_init()`, link `hc` onto `l1oip_ilist` and `INIT_WORK(&hc->workq, ...)` before `init_card()`, and set `hc->registered` only after `mISDN_register_device()` succeeds. In `l1oip_socket_open()`, reset `hc->socket_thread = NULL` if `kthread_run()` returns `ERR_PTR`. [F38, F119]

## External Contracts

- `ISDN_P_BASE` sockets require `SOCK_RAW` and `capable(CAP_NET_RAW)` and allow `IMSETDEVNAME`; data sockets require `SOCK_DGRAM` and forbid `IMSETDEVNAME`. Zero stack `struct mISDN_devinfo` with `memset()` (`IMGETDEVINFO`), null-terminate `mISDN_devrename.name` (`IMSETDEVNAME`), and use `copy_safe_from_sockptr()` in `data_sock_setsockopt`. [F42, F64, F145]
- `mISDN_sock_sendmsg()` must reject `len < MISDN_HEADER_LEN` and set `mISDN_HEAD_ID(skb)` only after copying and `skb_pull`-ing `MISDN_HEADER_LEN` bytes. `mISDN_sock_recvmsg()` must check `len < skb->len + MISDN_HEADER_LEN` before `skb_push`, restoring `skb` (or dropping `MSG_PEEK` ref) and returning `-ENOSPC` if too small. [F58, F65, F66]
- In `timerdev.c`, `misdn_add_timer()` keeps `dev->next_id >= 1` and returns `0` (`timeout == 0`), `>= 1`, or `-ENOMEM`, so `mISDN_ioctl(IMADDTIMER)` treats only `id < 0` as error. `mISDN_read()` must reject `count < sizeof(int)` with `-ENOSPC` before dequeuing from `dev->expired`. [F48, F79, F102]

## Known Pitfalls

- `create_l2()` and `create_new_tei()` take `(tei, sapi)`, whereas `set_channel_address()` takes `(sapi, tei)` (`sapi | (tei << 8)`) and must be called when `l2->tei` is assigned in `l2_got_tei()` or opened in `l2_ctrl(OPEN_CHANNEL)`. [F45, F54]
- In `struct layer2`, `vs`, `va`, `vr`, and `nr` must be unsigned for modulo-8/128 arithmetic, and `signed char` `sapi`/`tei` must stay in `0..127` (`GROUP_TEI = 127` when unassigned). In `get_channel4id` and `findtei`, reset the `list_for_each_entry` cursor to `NULL` after the loop and use `goto` on match. [F85, F97, F100]
