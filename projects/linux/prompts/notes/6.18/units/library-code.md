# LIBRARY CODE

The `lib/` subsystem provides core kernel data structures (`assoc_array.c`, `btree.c`, `timerqueue.c`), lockless memory pools (`genalloc.c`), reference counting (`rcuref.c`, `refcount.c`, `ref_tracker.c`), scatterlist and DMA/page iteration (`scatterlist.c`, `sg_pool.c`, `sg_split.c`), stack storage (`stackdepot.c`), ASN.1/BCH/decompression codecs, safe usercopy helpers, text search (`textsearch.c`, `ts_*.c`), devres I/O mapping (`devres.c`), CPU affinity reverse-mapping (`cpu_rmap.c`), and dynamic queue limits (`dynamic_queue_limits.c`).

## Architecture & Data Flow

- In `lib/assoc_array.c`, `assoc_array_delete()` must keep `edit->ops_for_excised_subtree = NULL` when collapsing a subtree (surviving leaves are copied into `new_n0` without new refs; only `edit->dead_leaf` is freed) and clear `array->root` and `edit->adjust_count_on` to `NULL` when deleting the final leaf (`nr_leaves_on_tree == 1`). `assoc_array_rcu_cleanup()` must clear `excised_subtree`'s root `back_pointer` to `NULL` before `assoc_array_destroy_subtree()`. [F7, F52, F53, F54]
- In `assoc_array_gc()`, if any child could not be folded (`retained == true`) yet `new_n->nr_leaves_on_branch <= ASSOC_ARRAY_FAN_OUT`, it must jump to `retry_compress`, and folding `new_n->slots[slot]` must clear the slot and rewind `next_slot = slot` if `slot < next_slot`. In `assoc_array_insert_into_terminal_node()`, `all_leaves_cluster_together` must recompute `edit->segment_cache[0..ASSOC_ARRAY_FAN_OUT]` at the shortcut's `skip_to_level` before `do_split_node`. [F86, F87, F88]
- In `lib/genalloc.c`, `gen_pool_chunk::end_addr` is inclusive (`virt + size - 1`), so `chunk_size()` is `end_addr - start_addr + 1` and range checks must use `<= chunk->end_addr`. Chunk bitmap capacity rounds down (`size >> order`) with `chunk->bits` sized as `BITS_TO_LONGS(nbits) * sizeof(long)` bytes, whereas alloc/free requests round up (`(size + (1UL << order) - 1) >> order`) and adjust `chunk->avail` by `nbits << pool->min_alloc_order` rather than raw `size`. [F47, F77, F106, F115]
- In `lib/dynamic_queue_limits.c`, wrapping `unsigned int` counters (`num_queued`, `num_completed`, `prev_num_queued`, `adj_limit`) must be compared via signed differences (`POSDIFF`, `AFTER_EQ`, `dql_avail()`), requiring `dql_queued()` to reject `count > DQL_MAX_OBJECT` and `dql_completed()` to clamp `limit` to `dql->max_limit <= DQL_MAX_LIMIT` and reset `ovlimit = 0` whenever clamped `limit != dql->limit`. [F50, F81, F107]
- In `lib/stackdepot.c`, `handle_parts::pool_index_plus_1` is 1-based (handle `0` is empty, `stack_max_pools < (1LL << DEPOT_POOL_INDEX_BITS)`), so `depot_fetch_stack()` must subtract 1 into `u32 pool_index` and reject `pool_index >= pools_num_cached`. `depot_pop_free_pool()` requires `size` aligned via `depot_stack_record_size()`. Because `stack_record::entries` unions with `free_list`/`rcu_state`, records on `free_stacks` must have `count == 0` and `STACK_DEPOT_FLAG_GET` allocations must use `CONFIG_STACKDEPOT_MAX_FRAMES`. [F220, F221, F231, F262, F263]
- In `lib/scatterlist.c` and `lib/sg_split.c`, `sg_append_table` counts only page-populated entries in `sgt.orig_nents`/`sgt.nents` while tracking total allocated entries in `total_nents` (`sg_free_append_table()`). `__sg_page_iter_next()`/`__sg_page_iter_dma_next()` must use a `while` loop to skip zero-length entries. In `sg_split()`, `sg_split_phys()` must run before `sg_calculate_split(..., true)` and `sg_split_mapped()`, adjusting `offset`/`length` by `skip_sg0` only on `!j` and zeroing `dma_address`/`dma_length`. [F212, F217, F218, F250]
- In `lib/seq_buf.c`, overflow sets `s->len = s->size + 1` (`seq_buf_set_overflow()`), so readers must bound valid bytes with `seq_buf_used(s)`. String writers (`seq_buf_puts()`, `seq_buf_vprintf()`, `seq_buf_bprintf()`) require room for a trailing NUL (`s->len + text_len < s->size`) without counting it in `s->len`, whereas raw byte writers (`seq_buf_putmem()`, `seq_buf_putc()`) allow `s->len == s->size` and require `seq_buf_str()` before string use. [F225, F235]

## Synchronization

- In `lib/assoc_array.c`, `assoc_array_find()` and `assoc_array_iterate()` require `rcu_read_lock()` (or writer lock), internal walks must use `READ_ONCE()`, and `assoc_array_subtree_iterate()` must scan each node in two passes (all leaves before metadata slots). Mutations (`insert`, `delete`, `clear`, `gc`) require sleepable context and an exclusive lock held until `assoc_array_apply_edit()` (which orders pointer updates with `smp_wmb()` before `call_rcu()`) or `assoc_array_cancel_edit()`, whereas `assoc_array_destroy()` frees immediately without RCU deferral. [F15, F16, F85, F135, F136]
- In `lib/stackdepot.c`, `pool_lock` (`raw_spinlock_t`) protects `stack_pools`, `new_pool`, `pools_num`, `pool_offset`, and `free_stacks`, while `depot_fetch_stack()` must never hold `pool_lock` and pairs `READ_ONCE(pools_num)` with `depot_init_pool()` setting `stack_pools[pools_num] = new_pool` before `WRITE_ONCE(pools_num, pools_num + 1)`. In `stack_depot_save_flags()`, when `in_nmi()` or `!gfpflags_allow_spinning(alloc_flags)`, `pool_lock` must use `raw_spin_trylock_irqsave()` and skip page allocation, and `find_stack()` must be re-run under `pool_lock` after a lockless miss. `find_stack()` uses `rcu_read_lock_sched_notrace()` and `refcount_inc_not_zero()`, and `depot_free_stack()`/`depot_pop_free()` gate reuse from `free_stacks` on `get_state_synchronize_rcu()`/`poll_state_synchronize_rcu()`. [F185, F186, F187, F188, F189, F291]
- In `lib/ref_tracker.c`, `ref_tracker_dir_exit()` must mark `debugfs_dentries`/`debugfs_symlinks` `REF_TRACKER_DIR_DEAD` and schedule `debugfs_reap_worker` before taking `dir->lock`, while `ref_tracker_debugfs_show()` must verify `debugfs_dentries` under `xa_lock_irqsave()` and acquire `dir->lock` before dropping `xa_lock`. `__ref_tracker_dir_pr_ostream()`, `ref_tracker_dir_print_locked()`, and `ref_tracker_get_stats()` require `dir->lock` held and must use `GFP_NOWAIT` (as must `stack_depot_save()` in `ref_tracker_free()`), freeing evicted `dir->quarantine` entries after unlocking `dir->lock`. [F183, F223, F297, F298]
- `_atomic_dec_and_lock*()` (`lib/dec_and_lock.c`) and `refcount_dec_and_*lock*()` (`lib/refcount.c`) acquire `@lock` when decrement-not-one fails and unlock (restoring IRQ flags in `_irqsave` variants) if `dec_and_test` returns false, leaving `@lock` held iff they return `true`. In `rcuref_put_slowpath()`, the `RCUREF_NOREF` to `RCUREF_DEAD` `atomic_try_cmpxchg_release()` transition must be followed by `smp_acquire__after_ctrl_dep()`. [F151, F169, F179]
- In `lib/genalloc.c`, `gen_pool_add_owner()` runs in sleepable context (`vzalloc_node()`) and must initialize all `gen_pool_chunk` fields before taking `pool->lock` and calling `list_add_rcu()`. In `lib/dynamic_queue_limits.c`, `dql_queue_stall()` must zero reused `dql->history` slots and issue `smp_wmb()` before `WRITE_ONCE(dql->history_head, now_hi)`, pairing with `smp_rmb()` and a post-scan retry check in `dql_check_stall()`. [F18, F20, F140]

## Object Lifetimes

- In `lib/cpu_rmap.c`, `irq_cpu_rmap_add()` must run in process context before `request_irq()` and initialize `glue->notify`, `glue->rmap`, `cpu_rmap_get(rmap)`, and `glue->index = cpu_rmap_add(rmap, glue)` before `irq_set_affinity_notifier()`. `free_irq_cpu_rmap()` must run in process context before `free_irq()`. Both `irq_cpu_rmap_release()` and `irq_cpu_rmap_add()`'s `err_set` rollback must clear `rmap->obj[glue->index] = NULL` before `cpu_rmap_put(glue->rmap)`. [F1, F23, F123, F124]
- In `lib/scatterlist.c`, `__sg_free_table()` must use the same `max_ents` and `nents_first_chunk` passed to `__sg_alloc_table()` (including on partial allocation failure), reading `next = sg_chain_ptr(&sgl[curr_max_ents - 1])` before `free_fn(sgl, alloc_size)` and skipping `free_fn` on the first chunk when `nents_first_chunk != 0`; `sg_free_table_chained()` must normalize `nents_first_chunk == 1` to `0`. Any `sg_mapping_iter` advanced by `sg_miter_next()` must be unmapped by `sg_miter_stop()` using the matching `SG_MITER_ATOMIC`/`SG_MITER_LOCAL`/default unmap and calling `flush_dcache_page()` when `SG_MITER_TO_SG` is set. [F162, F163, F165, F166, F249, F301]
- In `lib/genalloc.c`, `of_gen_pool_get()` returns a borrowed `struct gen_pool *` and must drop transient `of_node_put(parent)`, `put_device(&pdev->dev)`, and `of_node_put(np_pool)` references before returning. All allocations from a `gen_pool` (including `devm_gen_pool_create()` pools) must be freed before `gen_pool_destroy()`, which triggers `BUG_ON(bit < end_bit)` if any bit remains set. [F2, F128]
- In `lib/btree.c`, `btree_destroy()` only frees `head->node` and `head->mempool`, so populated trees must be emptied via `btree_grim_visitor()` or `btree_remove()` first; `btree_merge()` into an empty `target` must reset `victim` with `__btree_init(victim)`. In `lib/stackdepot.c`, unused `prealloc` pages in `stack_depot_save_flags()` must be freed via `free_pages_nolock()` when `!allow_spin` and `free_pages()` otherwise. In `lib/textsearch.c`, `textsearch_prepare()` must call `module_put(ops->owner)` if `ops->init()` fails. [F8, F9, F172, F174, F295]

## API Contracts

- In `lib/assoc_array.c`, `assoc_array_cancel_edit()` and `assoc_array_insert_set_object()` never free `edit->leaf`; `assoc_array_delete()` and `assoc_array_clear()` return `NULL` when no edit is needed, a valid edit pointer, or `ERR_PTR(-ENOMEM)`; and `assoc_array_gc()`'s `iterator` callback must increment a retained leaf's refcount before returning `true` because `ops->free_object()` is called on all leaves in both the excised tree and `enomem` rollback subtree. [F5, F6, F35]
- In `lib/devres.c`, `devm_ioremap_resource*()` and `devm_of_iomap()` return `IOMEM_ERR_PTR()` on failure (and claim the region exclusively via `devm_request_mem_region()`, failing with `-EBUSY` on shared overlaps), whereas `devm_ioremap*()` and `devm_ioport_map()` return `NULL`; `devm_iounmap()`/`devm_ioport_unmap()` only accept devm-mapped addresses. In `lib/genalloc.c`, `devm_gen_pool_create()` returns `ERR_PTR(-EINVAL)` on duplicate `pool->name` on `dev` or `ERR_PTR(-ENOMEM)`, whereas `gen_pool_create()`, `gen_pool_get()`, and `of_gen_pool_get()` return `NULL`; `gen_pool_virt_to_phys()` returns `(phys_addr_t)-1` on failure while `gen_pool_alloc_algo_owner()` returns `0`; and `genpool_algo_t` callbacks run under `rcu_read_lock()` (must not sleep) and return `>= size` (`end_bit`) on failure because bit `0` is valid. [F30, F31, F32, F34, F49, F125, F127, F141]
- In `lib/scatterlist.c`, `pages_are_mergeable(a, b)` takes the next page as `a` and preceding page as `b`. `sg_alloc_append_table_from_pages()` rejects `max_segment < PAGE_SIZE` or non-zero `offset` when `sgt_append->prv != NULL` with `-EINVAL` and only calls `sg_mark_end()` when `left_pages == 0`. `extract_iter_to_sg()` pins pages only for `ITER_UBUF`/`ITER_IOVEC`, updates `sgtable->nents` without calling `sg_mark_end()`, and in `extract_folioq_to_sg()`/`extract_xarray_to_sg()` uses `folio_page(folio, 0)` with `offset_in_folio()` (under `rcu_read_lock()` with `xas_retry()` in `extract_xarray_to_sg()`). `sgl_alloc_order()` must mask `~GFP_DMA` for `kmalloc_array()`. [F193, F242, F302, F303, F315, F316]
- In `lib/rcuref.c`, `__rcuref_put()` (`rcuref_put_rcusafe()`) requires preemption disabled or `rcu_read_lock()`, and callers may deconstruct the object only when `rcuref_put_slowpath()` returns `true`. In `lib/ref_tracker.c`, `ref_tracker_alloc()` only adds `__GFP_NOFAIL` when `gfp & __GFP_DIRECT_RECLAIM` is set, treats `trackerp == NULL` as untracked (`dir->no_tracker`), and on `-ENOMEM` sets `*trackerp = NULL` and increments `dir->untracked` (balanced when `ref_tracker_free()` sees `*trackerp == NULL`). [F168, F207, F208, F296]
- Usercopy helpers (`check_zeroed_user()`, `strncpy_from_user()`, `strnlen_user()`) must bracket `unsafe_get_user()` with `user_read_access_begin()` (or `masked_user_access_begin()`) and `user_read_access_end()` on all exit paths, and when `!can_do_masked_user_access()`, strip tags via `untagged_addr()`, check `src_addr < TASK_SIZE_MAX`, and clamp `max` to `min(TASK_SIZE_MAX - src_addr, count)`. `strnlen_user()` returns `0` on fault and `> count` on truncation; `check_zeroed_user()` returns `1` if all zero, `0` if non-zero, or `-EFAULT`. [F201, F202, F307, F312]

## Error Handling

- In `gen_pool_alloc_algo_owner()`, if `bitmap_set_ll(chunk->bits, start_bit, nbits)` fails partway with non-zero `remain`, it must roll back `nbits - remain` bits via `bitmap_clear_ll()` before `retry`. In `__devm_ioremap_resource()`, if `__devm_ioremap()` fails after `devm_request_mem_region()`, it must call `devm_release_mem_region()` immediately. [F4, F11]
- In `lib/scatterlist.c`, `get_next_sg()` returns `ERR_PTR(-ENOMEM)` (not `NULL`), and `sg_alloc_append_table_from_pages()` must check `IS_ERR(s)` and restore `sgt_append->prv->length = prv_len` on failure. In `lib/sg_split.c`, `sg_split()` allows `out_mapped_nents == NULL` when `in_mapped_nents == 0`, writes `out[]`/`out_mapped_nents[]` only after all split calculations succeed, and frees `splitters[i].out_sg` on error. [F197, F209]

## Known Pitfalls

- Bounds and integer overflow traps: `sgl_alloc_order()` must check `length > (nent << (PAGE_SHIFT + order))` after narrowing `nent`; `sg_page_count()`/`sg_dma_page_count()`/`extract_user_to_sg()` must round `offset + length` up to `PAGE_SIZE` before dividing; `refcount_dec_not_one()` must keep `val` and `new = val - 1` as `unsigned int` so decrementing from `0` triggers `new > val`; `devmem_is_allowed()` must use `PFN_PHYS(pfn)`; and `cmp_ex_sort()`/`cmp_ex_search()` must compare `unsigned long` addresses with `>`/`<` instead of subtracting into `int`. [F98, F109, F266, F269, F270]
- Memory layout and loop-state traps: `btree_insert_level()` must jump to `retry` after splitting a full node, and `btree_get_prev()` must clear `retry_key = NULL` before `goto retry`; `extract_user_to_sg()` must abort on `res <= 0` from `iov_iter_extract_pages()` (and requires `sgtable->nents + sg_max` contiguous `sgl` entries for trailing `struct page *` scratch space), while `extract_bvec_to_sg()`/`extract_kvec_to_sg()` must reset `start = 0` after the first extracted segment; and `check_zeroed_user()`/`do_strnlen_user()` must mask aligned leading/trailing bytes with `aligned_byte_mask()` and stop the word loop when remaining size `<= sizeof(unsigned long)`. [F55, F91, F237, F246, F247, F258, F282]
