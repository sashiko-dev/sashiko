# FIREWIRE SUBSYSTEM

The FireWire (IEEE 1394) subsystem provides core bus topology, Config ROM/CSR management, asynchronous transactions, isochronous DMA streaming, and the `/dev/fw*` UAPI (`firewire-core`), along with the PCI OHCI controller driver (`firewire-ohci`), SBP-2 SCSI storage initiator (`firewire-sbp2`), IPv4/IPv6 networking (`firewire-net`), and PCILynx sniffer (`nosy`).

## Architecture & Data Flow

- `struct fw_device` and `struct fw_unit` share `fw_bus_type` (`&fw_device_type` vs `&fw_unit_type`), so `struct device *` callbacks (`fw_unit_match()`, `show_immediate()`, `show_text_leaf()`, `update_unit()`, `compare_configuration_rom()`) must check `is_fw_unit()` or `is_fw_device()` first. Likewise, `client->resource_xa` stores heterogeneous `struct client_resource` objects that must be checked via `resource->release` before `to_*_resource()` downcasts. [F45, F46]
- `fw_transaction.callback` must be selected via `t->with_tstamp` on every completion path (`close_transaction()`, `split_transaction_timeout_callback()`, `fw_core_handle_response()`, `__fw_send_request()`), and `core-cdev.c` completion callbacks must switch on `.without_tstamp.type` when accessing `outbound_transaction_event.rsp` or `outbound_phy_packet_event.phy_packet` unions. [F47, F48]
- Structs passed to `queue_event()` must keep `struct event` at offset 0 (`dequeue_event()`/`fw_device_op_release()` pass `&e->event` to `kfree()`). Similarly, `struct sbp2_orb base` must be at offset 0 of `sbp2_management_orb` and `sbp2_command_orb` (`free_orb()` `kfree`s the `container_of` pointer), and `struct sbp2_target` must reside at `shost->hostdata[0]` of `scsi_host_alloc()`. [F127, F278, F279]
- Removing a `struct fw_transaction` from `card->transactions.list` must clear `1ULL << t->tlabel` in `card->transactions.tlabel_mask` under `card->transactions.lock`; all `tlabel_mask` ops (`tlabel` 0..63) and 64-bit isochronous channel masks (`ohci->ir_context_channels`, `r->channels`, `channels_mask`) must shift `1ULL`. [F65, F117, F118]
- `context_append(ctx, d, z, extra)` requires `z` to be the hardware-executed descriptor count in `branch_address` (`d_bus | z`) and `extra` to be trailing out-of-line slots (`driver_data` or `header_z`), advancing `used` by `(z + extra) * sizeof(*d)`. In `context_retire_descriptors()`, `ctx->current_bus = address` must precede `ctx->callback(ctx, d, last)`, and `old_desc` is only recycled (`used = 0`, moved to `buffer_list` tail) and `ctx->last` updated if `ctx->callback` returns non-zero. [F57, F72, F113]
- `find_branch_descriptor()` places `branch_address` in `d[0]` when `z == 2` and `DESCRIPTOR_BRANCH_ALWAYS` is set on `d[0]` (`OUTPUT_LAST_IMMEDIATE`), and in `d[z - 1]` otherwise. In `at_context_queue_packet()`, `struct driver_data` is overlaid onto `&d[3]` with `inline_data` at offset 0 (`sizeof(struct driver_data) <= sizeof(struct descriptor)`). [F89, F137]
- `ar_context_init()` maps `AR_WRAPAROUND_PAGES` alias pages after `AR_BUFFERS` in `ctx->buffer`; `handle_ar_packet()` must abort if `p.payload_length > MAX_ASYNC_PAYLOAD` before reading `buffer[length]`, and `ohci_ar_context_work()` must subtract `AR_BUFFERS * PAGE_SIZE` from `p` when wrapping past `buffer_end`. [F70, F87]
- In `fwnet_incoming_packet()`, fragments must satisfy `len > RFC2374_FRAG_HDR_SIZE` and `fg_off + len <= dg_size`, discarding any `fwnet_partial_datagram` if `pd->datagram_size != dg_size` or `fwnet_frag_overlap(pd, fg_off, len)`; every `fwnet_pd_new()` and `fwnet_pd_delete()` on `peer->pd_list` must adjust `peer->pdg_size` under `dev->lock`. [F79, F96]
- `sbp2_status_write()` must verify `tcode == TCODE_WRITE_BLOCK_REQUEST` and `8 <= length <= sizeof(struct sbp2_status)` and zero-initialize `status.data` before copying `length - 8` bytes; the `lu->orb_list` search must store a match into a separate `orb` pointer (initialized to `NULL`). Likewise, `close_transaction()` and `fw_core_handle_response()` must only unlink `iter` and set `t = iter` when `try_cancel_split_timeout(iter)` returns non-zero, checking `t` rather than `iter` after the loop. [F110, F248, F261]

## Synchronization

- `__fw_send_request()` can run in atomic context and synchronously invokes `handle_local_request()` -> `fw_core_handle_request()` -> `fw_address_callback_t` for local destinations; inbound request paths (`allocate_request()`, `handle_fcp_region_request()`, `handle_request()`, `fwnet_receive_packet()`) must not sleep and must use `GFP_ATOMIC`. [F155]
- `card->transactions.lock`, `card->split_timeout.lock`, `card->topology_map.lock`, `phy_receiver_list_lock`, `ohci->lock`, and `sbp2_target.lock` (`tgt->lock`) are acquired in IRQ or softirq contexts, so non-IRQ callers must use `spin_lock_irq` or `spin_lock_irqsave`. Never call out of `ohci.c` (`packet->callback`, `fw_core_handle_*`) under `ohci->lock`, and never invoke `iso_callback`/`iso_mc_callback` (which use `GFP_KERNEL`) from IRQ context or under a spinlock. [F156, F159, F160, F306]
- `read_phy_reg()`, `write_phy_reg()`, `update_phy_reg()`, and `read_paged_phy_reg()` in `ohci.c` sleep via `msleep(1)` and require holding `ohci->phy_reg_mutex` (via `ohci_read_phy_reg()` / `ohci_update_phy_reg()`), except during serialized `ohci_enable()`. [F161]
- Writers updating `node_id` (and `tgt->address_high` in `sbp2_login()`/`sbp2_reconnect()`) and `generation` on `fw_card`, `fw_device`, or `sbp2_logical_unit` must store `node_id`/`address_high` before `smp_wmb()` and `generation`; lockless readers (`fw_device_enable_phys_dma()`, `read_rom()`, `sbp2_scsi_queuecommand()`, `sbp2_send_management_orb()` callers) must read `generation` before `smp_rmb()` and `node_id`/`address_high` (using `device->node_id`, not `tgt->node_id`, for management ORBs). [F22, F214, F266]
- In `sbp2_login()`, after `__scsi_add_device()` returns `sdev`, the worker must execute `smp_rmb()` and verify `generation == device->card->generation` before setting `lu->has_sdev = true` and calling `sbp2_allow_block(tgt)`; if a bus reset intervened or `__scsi_add_device()` failed, it must remove/put `sdev`, log out, and reset `lu->workfn = sbp2_login`. [F215, F237]
- In `handle_selfid_complete_event()`, `ohci->self_id[0]` must be read before `rmb()`, followed by copying `ohci->self_id[]` to `ohci->self_id_buffer[]`, a second `rmb()`, and verifying `OHCI1394_SelfIDCount` still matches. Before dropping `ohci->lock` for `at_context_flush()`, set `ohci->generation = -1` and stop both AT contexts; only after flushing set `ohci->generation = generation` and clear `OHCI1394_busReset` in `OHCI1394_IntEventClear`. [F25, F73, F146]
- When linking DMA descriptors in `ar_context_link_page()` and `context_append()`, all descriptor fields (`res_count`, `transfer_status`, cleared `branch_address` Z bits) must be written before a `wmb()` that precedes setting the previous descriptor's `branch_address` Z bit and updating `ctx->last_buffer_index`. In `ar_search_last_active_buffer()`, `READ_ONCE()` reads of `res_count` must be separated by `rmb()` with a final `rmb()` before reading DMA data. [F27, F28, F71]
- `fw_iso_context_flush_completions()`, `fw_iso_context_stop()`, `at_context_flush()`, and `ohci_cancel_packet()` must check `current_work() == &ctx->work` and return early before calling `disable_work_sync(&ctx->work)` or `cancel_work_sync(&ctx->work)`. [F29]
- Under `tgt->lock` in `sbp2.c`, `sbp2_conditionally_block()` calls `scsi_block_requests(shost)` while holding `tgt->lock` when `++tgt->blocked == 1` (only if `tgt->dont_block == 0`), whereas `sbp2_conditionally_unblock()` and `sbp2_unblock()` must call `scsi_unblock_requests(shost)` after releasing `tgt->lock`. `sbp2_status_write()` and `complete_transaction()` must also drop `lu->tgt->lock` before calling `orb->callback`. [F198, F199, F207]

## Object Lifetimes

- In `create_units()`, `fw_device_get(device)` must precede `device_register(&unit->device)`, and failure must call `put_device(&unit->device)` rather than `kfree(unit)`. Conversely, `struct fw_device` in `fw_device_init()` does not call `device_initialize()` until Config ROM reading finishes, so early failures must call `fw_device_release(&device->device)` directly; on rediscovery, `device->node` and `reused->node` must be swapped via `fw_node_set_device()` under `card->lock` before `fw_device_release()`. [F4, F5, F6]
- Because `fw_unit.directory` points into `device->config_rom`, `fw_device_refresh()` must unregister all child `fw_unit` devices via `shutdown_unit()` before `read_config_rom()` replaces and `kfree`s `old_rom` under `down_write(&fw_device_rwsem)`. Readers outside `fw_unit` lifetime (sysfs, `ioctl_get_info()`, `compare_configuration_rom()`) must hold `fw_device_rwsem` for read. [F34, F63, F218]
- In `fw_card_add()`, `card->isoc_wq` and `card->async_wq` (`__free(workqueue_destroy)`) must be assigned before `card->driver->enable()`, reset to `NULL` if `enable()` fails, and passed to `retain_and_null_ptr()` on success. In `fw_core_remove_card()`, `card` must be unlinked from `card_list` under `card_mutex` before binding `dummy_driver` (preserving `free_iso_context`/`stop_iso`), and `isoc_wq`/`async_wq` destroyed only after `fw_destroy_nodes()`, `fw_card_put()`, and `wait_for_completion(&card->done)`. [F7, F8, F139]
- In `fw_device_op_release()`, `client->iso_context` must be destroyed before `client->buffer`, and `client->in_shutdown = true` must be set under `client->lock` before waiting on `client->tx_flush_wait` and draining `client->resource_xa` and `client->event_list`. [F12]
- In `ohci.c`, coherent DMA buffers allocated with `dmam_alloc_coherent()` must be freed with `dmam_free_coherent()`. In `handle_selfid_complete_event()`, when promoting `ohci->next_config_rom` to `ohci->config_rom` and clearing `ohci->next_config_rom = NULL`, the old `ohci->config_rom` must only be freed if `ohci->next_config_rom != ohci->config_rom` (`ohci_enable()` aliases them on `pci_resume()` when `config_rom == NULL`). [F16, F49, F142]
- Because `fw_send_request()` can complete synchronously, `fwnet_send_packet()`, `fwnet_transmit_packet_done()`, and `fwnet_transmit_packet_failed()` coordinate `ptask` lifetime under `dev->lock` via `ptask->outstanding_pkts` and `ptask->enqueued`, calling `dec_queued_datagrams()` and `fwnet_free_ptask()` only when the last user finishes. In `fwnet_incoming_packet()`, `skb = skb_get(pd->skb)` must precede `fwnet_pd_delete(pd)`. [F19, F20]
- `sbp2_send_orb()` must set `orb->lu`, append `orb->link` to `lu->orb_list` under `lu->tgt->lock`, and take two `kref_get(&orb->kref)` references before `fw_send_request()`. Only the path that unlinks `orb` (`sbp2_status_write()` setting `RCODE_COMPLETE`, `complete_transaction()` when `orb->rcode != RCODE_COMPLETE`, or `sbp2_cancel_orbs()` when `fw_cancel_transaction() != 0` on a local `list_for_each_entry_safe` splice) may call `orb->callback(orb, status)` and drop the callback `kref`. [F193, F208, F221, F262]
- In `sbp2_send_management_orb()`, after `wait_for_completion_timeout()`, `sbp2_cancel_orbs(lu)` must be called before unmapping `orb->base.request_bus`/`orb->response_bus` and dropping `orb->base.kref` (`sbp2_cancel_orbs()` returns `0` if an ORB had to be canceled and `-ENOENT` if all completed). In `sbp2_map_scatterlist()`, `orb->page_table_bus` is mapped and `COMMAND_ORB_PAGE_TABLE_PRESENT` set only when `scsi_dma_map()` returns `n > 1`, so `sbp2_unmap_scatterlist()` must check `COMMAND_ORB_PAGE_TABLE_PRESENT` before unmapping. [F196, F209, F220]
- `__scsi_add_device()` in `sbp2_login()` and `scsi_device_lookup()` in `sbp2_remove()` return `sdev` with an extra reference that must be released via `scsi_device_put(sdev)` even after `scsi_remove_device(sdev)`. `sbp2_remove()` must call `sbp2_unblock(tgt)` first, then per-`lu` `cancel_delayed_work_sync()`, `scsi_remove_device()`/`scsi_device_put()`, `SBP2_LOGOUT_REQUEST` (if `lu->login_id != INVALID_LOGIN_ID`), `fw_core_remove_address_handler()`, and `kfree(lu)` before `scsi_remove_host()` and `scsi_host_put()`. [F197, F201, F226]

## API Contracts

- When `release_client_resource()` is called with a non-NULL `return_resource`, it erases the handle from `client->resource_xa` and drops the XArray's `client` reference, but skips `resource->release()` and transfers ownership of the resource and its inner references (`r->request`, `r->card`) to the caller. [F3]
- Callers of `__fw_send_request()`, `fw_send_request()`, `fw_send_request_with_tstamp()`, and `fw_run_transaction()` must: pass extended lock tcodes (`TCODE_LOCK_MASK_SWAP`..`TCODE_LOCK_VENDOR_DEPENDENT`, not `TCODE_LOCK_REQUEST`); encode `TCODE_STREAM_DATA` `destination_id` via `fw_stream_packet_destination_id()`; pass >= 4 valid bytes of `payload` for `TCODE_WRITE_QUADLET_REQUEST`; pass a streaming-DMA-mappable buffer (not stack/vmalloc) valid until callback completion when `length > 8` to a remote node; and allow the callback to run synchronously without retaining its `data` pointer. [F53, F54, F55, F168, F217]
- Every `sbp2_orb.callback` (`complete_management_orb()`, `complete_command_orb()`) must handle `status == NULL`, any non-NULL `response` buffer passed to `sbp2_send_management_orb()` must be at least `sizeof(orb->response)` (16 bytes), and `sbp2_scsi_queuecommand()` must return `SCSI_MLQUEUE_HOST_BUSY` (not a negative errno) on pre-submission failure. [F223, F234, F280]

## Error Handling

- `fw_run_transaction()`, `read_rom()`, `reread_config_rom()`, and `read_config_rom()` return `RCODE_COMPLETE` (`0`) on success and positive `RCODE_*` constants (or negative errnos in `read_config_rom()`) on failure; callers (`fw_device_init()`, `fw_device_refresh()`) must check `!= RCODE_COMPLETE` rather than `< 0`. [F42]
- `read_phy_reg()`, `write_phy_reg()`, `update_phy_reg()`, and `read_paged_phy_reg()` return a negative errno on failure, so callers (`detect_initiated_reset()`, `get_status_for_port()`) must check `< 0` in a signed `int` before bitmasking or converting to `bool`. [F39]
- `fw_iso_context_create()` and `fw_card_driver.allocate_iso_context()` return an `ERR_PTR` (never `NULL`); callers (`ioctl_create_iso_context()`, `fwnet_broadcast_start()`, `fw_iso_mc_context_create()`) must test `IS_ERR()` before storing into `client->iso_context` or `dev->broadcast_rcv_context`, and `__fwnet_broadcast_stop()` only unmaps/destroys `broadcast_rcv_buffer` when `broadcast_state != FWNET_BROADCAST_ERROR`. [F21, F40]
- `fw_iso_resource_manage()` returns `void`, sets `*channel` to `0..63` or a negative errno, and overwrites `*bandwidth` with `0` on failure; if `allocate` is true, channel allocation succeeds (`c >= 0`), and `manage_bandwidth()` fails (`ret < 0`), it must roll back via `deallocate_channel(card, irm_id, generation, c)` and set `*channel = ret`. [F14, F43]

## External Contracts

- In `core-cdev.c`, `dispatch_ioctl()` must validate `_IOC_SIZE(cmd) <= sizeof(union ioctl_arg)` and `memset(&buffer, 0, sizeof(buffer))` before `copy_from_user()`. All `__u64` user pointers must use `u64_to_uptr()`/`uptr_to_u64()`, `ioctl_get_info()` must copy 36 bytes (not `sizeof(struct fw_cdev_event_bus_reset)`) to `a->bus_reset`, and `ioctl_send_response()` must reject non-FCP responses where `a->length != fw_get_response_length(r->request)`. [F94, F186, F187]

## Known Pitfalls

- Because `fw_csr_iterator_next()` post-increments `ci->p`, callers resolving a relative quadlet offset `value` from the current directory entry (`search_directory()`, `search_leaf()`, `units_show()`, `create_units()`) must compute `ci.p - 1 + value`. [F85]
- Because `RCODE_COMPLETE` is `0`, `sbp2_scsi_queuecommand()` must initialize `orb->base.rcode = -1` on a zero-allocated `sbp2_command_orb` before `sbp2_send_orb()`. In `sbp2_map_scatterlist()`, `COMMAND_ORB_DATA_SIZE` takes byte length `sg_dma_len(sg)` when `n == 1` (without `COMMAND_ORB_PAGE_TABLE_PRESENT`), takes segment count `n` when `n > 1` (mapping `sizeof(orb->page_table)` bytes), and always sets `data_descriptor.high = cpu_to_be32(lu->tgt->address_high)`. [F222, F281, F298]
