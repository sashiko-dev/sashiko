# BPF [GENERAL] (Safe Dynamic Programs and Tools)

This unit implements core and networking BPF infrastructure, including the NMI-safe per-CPU memory allocator, resilient queued spinlocks, arena range trees, BPF tokens, program streams, ELF build-ID parsing, iterators, hardware offload, tracing/probe attachments, classic-to-eBPF socket filter conversion, networking helpers/kfuncs, XDP redirect/flush, and `BPF_PROG_TEST_RUN`.

## Architecture & Data Flow

- In `kernel/bpf/memalloc.c`, non-percpu allocations include an `LLIST_NODE_SZ` (8B) header inside `unit_size` storing `struct bpf_mem_cache *`, whereas percpu allocations use a two-pointer header (`LLIST_NODE_SZ + sizeof(void *)`) without adding `LLIST_NODE_SZ` to `size`/`unit_size` (`obj[1]` holds the `__alloc_percpu_gfp()` pointer); callers receive `ptr + LLIST_NODE_SZ`. When `__llist_add()` to `c->free_by_rcu` returns true, `c->free_by_rcu_tail` must be set and copied to `c->waiting_for_gp_tail` when moving to `c->waiting_for_gp`. [F63, F80, F133, F134]
- In `kernel/bpf/range_tree.c`, `struct range_node` uses an inclusive upper bound `rn_last = start + len - 1` (splitting adjacent ranges at `start - 1` and `last + 1`). Any mutation to `rn_start` or `rn_last` must remove `rn` from both `rt->it_root` and `rt->range_size_root` via `range_it_remove()` before mutating and reinsert via `range_it_insert()`; in `range_tree_clear()`, the two-sided overlap check (`rn_start < start && rn_last > last`) must precede the single-sided branches. [F64, F89, F106]
- In `kernel/bpf/offload.c`, device-bound-only programs (`BPF_F_XDP_DEV_BOUND_ONLY`) have `ondev->offdev == NULL`, so `offload->offdev->ops` must only be accessed when `bpf_prog_is_offloaded(prog->aux)` holds. In `__bpf_offload_dev_netdev_unregister()`, migrating `ondev->progs` and `ondev->maps` to `altdev` must update every element's `netdev = altdev->netdev` and use `list_splice_init()`, while destroying them when `!altdev` must use `list_for_each_entry_safe()`. [F48, F67, F111]
- In `kernel/trace/bpf_trace.c`, `bpf_kprobe_multi_link_attach()` must co-sort `cookies[]` with `us.syms[]` (`symbols_swap_r`) and then with `link->addrs[]` (`bpf_kprobe_multi_cookie_swap`) so `bpf_kprobe_multi_cookie()` can index by `addr - link->addrs`. Helpers and kfuncs downcasting `current->bpf_ctx` to `bpf_kprobe_multi_run_ctx`, `bpf_uprobe_multi_run_ctx`, or `bpf_session_run_ctx` must only be exposed to programs whose `expected_attach_type` guarantees that active `run_ctx` (`is_kprobe_multi()`, `is_uprobe_multi()`, or session checks). [F72, F119, F142]
- Every `struct sk_buff` helper that reallocates, linearizes, or shifts `skb->data` or `skb->len` must call `bpf_compute_data_pointers(skb)` to refresh `data_meta` and `data_end`. In `bpf_skb_net_grow()`, `skb->mac_header`, `network_header`, and `transport_header` must be sampled before `bpf_skb_net_hdr_push()` when `encap` is true; on GSO skbs, `bpf_skb_net_grow()`/`shrink()` must set `SKB_GSO_DODGY`, reset `gso_segs = 0`, and update `gso_size`; and IPv4/IPv6 L3 protocol changes must use `bpf_skb_change_protocol()` to drop cached `skb_dst(skb)`. [F257, F264, F265, F266]
- In `struct sk_msg`, scatterlist ring indices (`start`, `curr`, `end`) wrap modulo `NR_MSG_FRAG_IDS` (`MAX_MSG_FRAGS + 1`). Every helper modifying scatterlist entries (`bpf_msg_pull_data()`, `bpf_msg_push_data()`, `bpf_msg_pop_data()`) must call `sk_msg_reset_curr(msg)` (setting `curr` to the element before `end` and `copybreak` to its `length` when `msg->sg.size > 0`) and recompute `msg->data` and `msg->data_end`. In `bpf_msg_push_data()`, if the search loop ends with `i == msg->sg.end`, `i` must step back via `sk_msg_iter_var_prev(i)`. [F258, F259, F280, F282]
- Networking context validators in `net/core/filter.c` must reject `off % size != 0`, and `bpf_skb`, `xdp`, and `flow_dissector` validators must reject `info->is_ldsx` on 32-bit packet pointers (`data`, `data_end`, `data_meta`). Validators with permissive defaults (`bpf_skb`, `sock_ops`, `bpf_sock`) must match 64-bit fields with `bpf_ctx_range*` and explicitly reject padding ranges, while `sock_addr`, `sk_msg`, `flow_dissector`, `sk_reuseport`, and `sk_lookup` must return `false` in `default:`. [F278, F301, F302, F303, F315]
- In `net/core/filter.c`, downcasting `struct sock *` to full-socket types (`tcp_sock`, `tcp6_sock`, `udp6_sock`, `unix_sock`) or calling `__bpf_setsockopt`/`__bpf_getsockopt` requires `sk_fullsock(sk)`. Downcasting to `tcp_timewait_sock` or `tcp_request_sock` requires `sk->sk_prot` to be `&tcp_prot` or `&tcpv6_prot` and `sk->sk_state` to be `TCP_TIME_WAIT` or `TCP_NEW_SYN_RECV`. In `bpf_sock_ops_get_syn()`, when `syn_skb` is NULL, `sk->sk_state == TCP_NEW_SYN_RECV` selects `inet_reqsk(sk)->saved_syn` over `tcp_sk(sk)->saved_syn`. [F241, F242, F332]

## Synchronization

- In `kernel/bpf/memalloc.c`, `bpf_mem_alloc*()`, `bpf_mem_free*()`, and `bpf_mem_cache_*()` require migration disabled. In `unit_alloc()`, `unit_free()`, and `unit_free_rcu()`, non-atomic `__llist_del_first()`/`__llist_add()` on `c->free_llist` or `c->free_by_rcu` require IRQs disabled and `local_inc_return(&c->active) == 1` (using atomic `llist_add()` on `free_llist_extra*` when `active != 1`), and `local_irq_restore(flags)` must occur after `irq_work_raise(c)`. On `CONFIG_PREEMPT_RT`, `inc_active()`/`dec_active()` must also save/restore local IRQs. [F153, F154, F155, F156]
- In `resilient_queued_spin_lock_slowpath()` (`kernel/bpf/rqspinlock.c`), when `in_nmi()` or `idx >= _Q_MAX_NODES`, waiters must fall back to the `queued_spin_trylock(lock)` timeout loop. When MCS queueing, `barrier()` must follow `rqnodes[0].mcs.count++` before initializing `node->locked`/`next`, and `smp_wmb()` must precede `xchg_tail()`. On timeout/deadlock, a pending waiter must call `clear_pending(lock)`, and an MCS waiter must either `try_cmpxchg_tail(lock, tail, 0)` or wait for `node->next` and set `WRITE_ONCE(next->locked, RES_TIMEOUT_VAL)` before decrementing `count`. [F35, F36, F161]
- In `kernel/bpf/task_iter.c`, whenever `task_vma_seq_get_next()` or `task_vma_seq_stop()` drops `mmap_lock`, it must save `prev_vm_start`/`prev_vm_end` (`prev_vm_start = ~0UL` in `task_vma_seq_stop()` when `v != NULL`) and re-lookup via `find_vma(curr_mm, info->prev_vm_end - 1)` after relocking instead of dereferencing `info->vma`. When `irqs_disabled()`, VMA lookups must test the boolean return of `bpf_mmap_unlock_get_irq_work(&work)` (not `!work`) before `mmap_read_trylock(mm)` and unlock via `bpf_mmap_unlock_mm(work, mm)`. [F28, F45, F159]
- In `kernel/bpf/reuseport_array.c`, `spin_lock_bh(&reuseport_lock)` must always be acquired before `write_lock_bh(&sk->sk_callback_lock)`. In `bpf_fd_reuseport_array_update_elem()`, `reuseport_array_update_check()` must be re-run after acquiring both locks, and `nsk->sk_callback_lock` must be unlocked before locking `free_osk->sk_callback_lock`. In `bpf_sk_reuseport_detach()`, both `WRITE_ONCE(sk->sk_user_data, NULL)` and `RCU_INIT_POINTER(*socks, NULL)` must run inside `write_lock_bh(&sk->sk_callback_lock)` while holding `reuseport_lock`. [F32, F164, F165]
- In `kernel/bpf/stream.c`, each `bpf_stream_elem` must be bump-allocated within a single order-0 page-aligned `struct bpf_stream_page` (`alloc_pages_nolock()`/`free_pages_nolock()`) under `local_trylock_irqsave(&stream_local_lock, *flags)` because `bpf_stream_page_from_elem()` uses `PAGE_ALIGN_DOWN`. `bpf_stream_page` starts with `refcount_set(&ref, 1)`, increments via `bpf_stream_page_get()` per reserved element, and decrements via `bpf_stream_page_put()` on page replacement and element free; backlog draining and `bpf_stream_read()` require `stream->lock`. [F12, F37, F135, F168]
- In `kernel/trace/bpf_trace.c`, all accesses to `event->prog` and `event->tp_event->prog_array` in perf_event attach/detach/query paths require `bpf_event_mutex`. In `perf_event_detach_bpf_prog()`, even if `old_array` is NULL or `bpf_prog_array_copy()` fails (falling back to `bpf_prog_array_delete_safe()`), `event->prog` must be cleared to NULL and `bpf_prog_put(prog)` called after unlocking `bpf_event_mutex` and calling `synchronize_rcu_tasks_trace()`. [F7, F40, F50]
- In `kernel/trace/bpf_trace.c`: `bpf_send_signal_common()` must check `!(task->flags & (PF_KTHREAD | PF_EXITING))`, `nmi_uaccess_okay()`, and `!is_global_init(task)`, and when `preempt_count() != 0 || irqs_disabled()`, defer to `send_signal_work` (`-EBUSY` if busy) after `get_task_struct(task)`. `bpf_probe_write_user()` must return `-EPERM` if `in_interrupt()`, `PF_KTHREAD | PF_EXITING`, or `!nmi_uaccess_okay()`, using `copy_to_user_nofault()`. Non-sleepable dynptr user reads must use `copy_user_*_nofault`. [F39, F170, F171, F176]

## Object Lifetimes

- In `bpf_mem_alloc_destroy()` (`kernel/bpf/memalloc.c`), each per-CPU `bpf_mem_cache` must set `WRITE_ONCE(c->draining, true)`, call `irq_work_sync(&c->refill_work)`, and call `drain_mem_cache(c)` before checking `call_rcu_in_progress`/`call_rcu_ttrace_in_progress` and waiting on `rcu_barrier()` and `rcu_barrier_tasks_trace()` in `free_mem_alloc()`. Callers of `bpf_mem_cache_raw_free(ptr)` must ensure `ptr` has already passed an `rcu_tasks_trace` grace period. [F11, F25]
- `task_vma_seq_get_next()` must hold references on `info->task` and `info->mm` (`mm_users`) plus `mmap_read_lock(info->mm)` whenever returning a non-NULL VMA, and must release all three and clear `info->task`, `info->mm`, and `info->vma` to NULL whenever returning NULL. [F17]
- In `kernel/trace/bpf_trace.c`, `bpf_kprobe_multi_link_lops` and `bpf_uprobe_multi_link_lops` must use `.dealloc_deferred`. In `bpf_uprobe_multi_link_attach()`, `link->task` (resolved under `rcu_read_lock()` via `PIDTYPE_TGID`), `link->link`, and `uprobes[i]` must be initialized before `uprobe_register()`; on failure at `i`, `link->cnt = i` must be set before `bpf_uprobe_unregister()`. In `bpf_kprobe_multi_link_attach()`, after `bpf_link_prime()` and setting `link->addrs`/`cookies`, errors must call `bpf_link_cleanup(&link_primer)`. [F41, F58, F59, F174, F175]
- In `kernel/bpf/offload.c`, all post-init accesses to `prog->aux->offload` and post-alloc accesses to `offmap->netdev`/`offmap->dev_ops` must hold `bpf_devs_lock` and verify `prog->aux->offload != NULL` or `offmap->netdev != NULL`. `__bpf_prog_offload_destroy()` must call `offload->offdev->ops->destroy(prog)` only if `offload->dev_state` is set. All port `net_device` instances must be unregistered from `offdev` before `bpf_offload_dev_destroy()`. [F146, F148, F149, F150]
- Socket filter lifecycle (`net/core/filter.c`): `bpf_prepare_filter()` and `bpf_migrate_filter()` consume `fp` and call `__bpf_prog_release(fp)` on error (if `bpf_prog_realloc(old_fp, ...)` returns NULL, restore `fp = old_fp`). `__sk_attach_prog(prog, sk)` requires the socket lock, takes `prog` ownership only on success, charges `sk_omem_alloc` via `__sk_filter_charge()`, and sets `refcount_set(&fp->refcnt, 1)` before `rcu_assign_pointer(sk->sk_filter, fp)` (uncharging `old_fp` via `sk_filter_uncharge()`, which defers release via `call_rcu()`). [F205, F206, F207, F219, F221, F347, F376]
- Socket lookup/assignment (`net/core/filter.c`): in `sk_lookup()`, `__bpf_sk_lookup()`, and `bpf_sk_lookup()`, if `sk_to_full_sk(sk)` returns `sk2 != sk`, `sock_gen_put(sk)` must be called on `sk`, and any unreferenced socket returned must have `sock_flag(sk, SOCK_RCU_FREE)`. `bpf_sk_assign()` must check `!sk_unhashed(sk)` and `refcount_inc_not_zero(&sk->sk_refcnt)` before `skb_orphan(skb)` and `skb->sk = sk`; `bpf_sk_lookup_assign()` must reject `sk_is_refcounted(sk)`, and `sk_select_reuseport()` error paths must `sock_put()` refcounted `selected_sk`. [F215, F217, F218, F230, F231]

## API Contracts

- In `lib/buildid.c`, `freader_get_folio()` must reject `secretmem_mapping(r->file->f_mapping)` with `-EFAULT` before `kmap_local_folio()`, and when `!r->may_fault` it must not call `filemap_invalidate_lock_shared()` or `read_cache_folio()`. Every `freader_fetch()` on a file-backed `freader` must request `sz <= MAX_FREADER_BUF_SZ` (64B). `parse_build_id()` must zero-pad `build_id` from `desc_sz` to `BUILD_ID_SIZE_MAX` and only write `*size = desc_sz` if `size != NULL`. [F54, F85, F169, F177]
- Redirect contracts (`net/core/filter.c`): `bpf_redirect()` and `bpf_clone_redirect()` must reject `flags & (~(BPF_F_INGRESS) | BPF_F_REDIRECT_INTERNAL)`. `__xdp_do_redirect_frame()` and `xdp_do_generic_redirect()` must reset `ri->map_id`, `ri->flags`, and `ri->map_type` on entry (and `WRITE_ONCE(ri->map, NULL)` on `BPF_F_BROADCAST`), while `ifindex` XDP redirects (`bpf_xdp_redirect`, `xdp_master_redirect` when `slave != xdp->rxq->dev`) must set `ri->map_id = INT_MAX` and `ri->map_type = BPF_MAP_TYPE_UNSPEC`. [F213, F300, F305, F337]

## Error Handling

- Callbacks passed to `__bpf_dynptr_copy()` (`copy_user_data_sleepable`) must return `0` on success and negative errno on failure (converting positive residual counts from `copy_from_user` or short reads from `access_process_vm` to `-EFAULT`). String callbacks passed to `__bpf_dynptr_copy_str()` must NUL-terminate `dst` within `size` and return the count including the NUL byte, while `__bpf_dynptr_copy_str()` advances `off` by `chunk_sz - 1` (stopping when `cnt < chunk_sz || chunk_sz == 1`). [F43, F99, F141]
- Constructor kfuncs for open-coded iterators (`bpf_iter_task_vma_new`, `bpf_iter_css_task_new`, `bpf_iter_task_new`) and networking dynptrs (`bpf_dynptr_from_skb`, `bpf_dynptr_from_skb_meta`, `bpf_dynptr_from_xdp`) must set their internal state pointer to `NULL` (`bpf_dynptr_set_null(ptr)`, where `bpf_dynptr_from_skb_meta` also sets `bpf_dynptr_set_rdonly(ptr)` if `skb_cloned(skb)`) on every error path before returning. [F46, F249, F370]
- Destination buffers on read failure: probe/perf-event read helpers taking `ARG_PTR_TO_UNINIT_MEM` (`bpf_probe_read_user*_common`, `bpf_probe_read_kernel_str_common`, `bpf_perf_event_read_value`, `bpf_perf_prog_read_value`) and `__queue_map_get()`/`__stack_map_get()` on an empty map must `memset` the entire output buffer to `0` on failure; `bpf_skb_get_tunnel_key()` and `bpf_skb_get_xfrm_state()` must zero `&remote_ipv6[1]` and `&local_ipv6[1]` (`sizeof(__u32) * 3`) when writing IPv4 addresses. [F55, F56, F251]

## Known Pitfalls

- In `lib/buildid.c`, `parse_build_id()`, `get_build_id_32()`, and `get_build_id_64()` must copy ELF/note header fields (`e_phnum`, `e_phoff`, `p_offset`, `p_filesz`, `n_namesz`, `n_descsz`) into local variables with `READ_ONCE()` before calling `freader_fetch()` again, because `freader_fetch()` invalidates previously returned pointers. [F83]
- Networking helper pitfalls (`net/core/filter.c`): packet-writing helpers (`bpf_skb_store_bytes`, `bpf_l3_csum_replace`, `bpf_l4_csum_replace`, `bpf_lwt_seg6_*`) must re-fetch pointers derived from `skb->data` after `bpf_try_make_writable()`, `skb_cow_head()`, or header push/pop. In `bpf_msg_pop_data()`, the `while (pop)` loop must not advance `i` after `sk_msg_shift_left(msg, i)`. In `bpf_xdp_copy_buf()`, `if (!len || next_frag == end_frag) break;` must precede dereferencing `next_frag`, and `__bpf_skb_change_head()` must check `new_len < skb->len` even on GSO skbs. [F306, F310, F322, F328]
