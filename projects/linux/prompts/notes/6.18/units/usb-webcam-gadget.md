# USB WEBCAM GADGET

Implements the USB Video Class (UVC) gadget function (`f_uvc`) and legacy composite webcam driver (`g_webcam`), enabling a Linux device with a USB Device Controller (UDC) to present itself as a UVC video source to a USB host. It exposes a V4L2 video output device (`VFL_DIR_TX`) and custom V4L2 events/ioctls so a userspace daemon can handle UVC control requests and stream uncompressed, MJPEG, or frame-based video frames via videobuf2 (`dma-sg` or `vmalloc`) over isochronous or bulk USB endpoints, with descriptors configured via configfs.

## Architecture & Data Flow

- In `struct uvc_video`, `video->ureqs` links `struct uvc_request` via `ureq->list`, whereas `video->req_free` and `video->req_ready` link `struct usb_request` via `req->list`; converting a `struct usb_request *` to its owning `struct uvc_request *` must use `req->context` rather than `container_of()`. [F104]
- `video->max_payload_size` must remain `0` for isochronous endpoints and non-zero only for bulk endpoints, because `uvcg_video_enable()`, `uvcg_video_pump()`, `uvcg_video_hw_submit()`, and `uvcg_video_usb_req_queue()` test `video->max_payload_size` as a boolean to select bulk vs isochronous encoding and queueing paths. [F46]
- In `uvcg_video_pump()`, exits from `while (true)` before dequeueing a `usb_request` from `video->req_free` must `return`, whereas exits after `list_del(&req->list)` and before `uvcg_video_usb_req_queue()` succeeds must `break` so post-loop cleanup returns `req` to `video->req_free` or frees it. [F76]
- In `uvcg_video_usb_req_queue()`, interrupt throttling must use `DIV_ROUND_UP(video->uvc_num_requests, 4)` rather than truncating division so the divisor passed to `min(..., UVCG_REQ_MAX_INT_COUNT)` and `%` is at least 1 even when `video->uvc_num_requests < 4` on bulk endpoints. [F88]
- `uvcg_queue_init()` sets `queue->use_sg = 1` with `vb2_dma_sg_memops` when `cdev->gadget->sg_supported` is true (using `vb2_vmalloc_memops` otherwise); `buf->sgt` and `buf->sg` are populated only when `queue->use_sg` is set (leaving `buf->mem` NULL), and `buf->mem` only when `queue->use_sg` is false, so `uvc_buffer_prepare()`, `uvcg_video_enable()`, and encoding paths must branch on `queue->use_sg`. [F33, F134]
- When `queue->use_sg` is set, `uvc_buffer_prepare()` must reset `buf->sg = buf->sgt->sgl` on every preparation because `uvc_video_encode_isoc_sg()` advances `buf->sg` with `sg_next(buf->sg)` to `NULL`. In `uvc_video_encode_isoc_sg()`, segment bounds and `sg_set_page()` must use `buf->sg->length` (not `sg_dma_len(buf->sg)`), `ureq->sgt.sgl[0]` holds `ureq->header` while the payload loop iterates `for_each_sg(sg_next(ureq->sgt.sgl), iter, ureq->sgt.nents - 1, i)`, `req->num_sgs` must be set to `i + 1`, and `buf->sg` advanced only when `part == buf->sg->length - buf->offset`. [F45, F80, F130]
- When an encode callback (`uvc_video_encode_bulk()`, `uvc_video_encode_isoc()`, or `uvc_video_encode_isoc_sg()`) finishes a `uvc_buffer`, it must under `queue->irqlock` reset `video->queue.buf_used = 0` (and `buf->offset = 0` for SG), set `buf->state = UVC_BUF_STATE_DONE`, unlink `buf->queue`, toggle `video->fid`, and set `ureq->last_buf = buf`. `uvcg_queue_cancel()` and `uvcg_queue_enable()` must also reset `queue->buf_used = 0` so the next buffer encoded by `uvcg_video_pump()` starts at offset `0`. [F39, F42]
- In `uvc_video_complete()`, a missed isochronous transfer (`req->status == -EXDEV`) must set `UVC_QUEUE_DROP_INCOMPLETE` on `queue->flags` only when `req->length != 0`, and `uvcg_complete_buffer()` must clear `UVC_QUEUE_DROP_INCOMPLETE` when completing the affected buffer. [F81]
- `uvc_video_prep_requests()` and `uvc_buffer_prepare()` must use `DIV_ROUND_UP()` when dividing `video->interval` by `interval_duration` and total frame bytes (including `reqs_per_frame * UVCG_REQUEST_HEADER_LEN`) by `nreq` or `reqs_per_frame`, and both `buf->req_payload_size` and `video->req_size` must be at least `UVCG_REQUEST_HEADER_LEN` (12 bytes) so subtracting the header length in `uvc_video_encode_isoc_sg()` and `uvc_video_alloc_requests()` never underflows. [F68, F89]
- `uvc_function_setup()` must reject USB control requests with `(ctrl->bRequestType & USB_TYPE_MASK) != USB_TYPE_CLASS` or `le16_to_cpu(ctrl->wLength) > UVC_MAX_REQUEST_SIZE` (64) with `-EINVAL` before recording `uvc->event_length` and normalize the low byte of `uvc_event->req.wIndex` to `0` (`UVC_STRING_CONTROL_IDX`) or `UVC_STRING_STREAMING_IDX` (`1`), while `uvc_function_ep0_complete()` must clamp the copy into `uvc_event->data.data` with `min_t(unsigned int, req->actual, sizeof(uvc_event->data.data))` (60 bytes). [F57, F58, F138]
- `uvc_v4l2_enum_format()` and `uvc_v4l2_enum_framesizes()` must bounds-check the 0-based V4L2 `index` against `uvc->header->num_fmt` and `uformat->num_frames` and pass `index + 1` to `find_format_by_index()` and `find_frame_by_index()` (which match 1-based UVC indices), whereas `uframe->dw_frame_interval` is a 0-based C array of length `uframe->frame.b_frame_interval_type` that `uvc_v4l2_enum_frameintervals()` must index directly with `fival->index < uframe->frame.b_frame_interval_type`. [F63, F86]
- Every descriptor pointer array consumed or returned by `uvc_copy_descriptors()` must be `NULL`-terminated. Every descriptor and extension unit copied in the second pass of `uvc_copy_descriptors()` must be counted in the first pass in `n_desc`, `bytes`, and `control_size` or `streaming_size` (with `uvc_control_desc[0]` and `uvc_streaming_cls[0]` placed first), and dynamic header fields (`wTotalLength`, `bInCollection`, `baInterfaceNr[0]`, `bEndpointAddress`) must be patched on the newly allocated `mem` copy rather than on the source `uvc->desc` arrays. [F54, F66, F82]
- Every configfs item or group struct whose `config_item_type` uses `uvcg_config_item_release()` (`uvcg_control_header`, `uvcg_streaming_header`, `uvcg_frame`, `uvcg_format`, `uvcg_uncompressed`, `uvcg_mjpeg`, `uvcg_framebased`) must keep its `config_item`, `config_group`, or `uvcg_format` member at offset 0. Before downcasting a `struct uvcg_format` via `to_uvcg_*()`, callers must check `uformat->type`, and every configfs `allow_link` callback in `uvc_configfs.c` must verify `target->ci_parent` before downcasting `target`. [F101, F102, F103]
- In `struct uvcg_streaming_header`, `struct uvc_input_header_descriptor desc` must remain the final member because it ends with flexible array `bmaControls[]`, and because `uvcg_streaming_header` is allocated with `kzalloc(sizeof(*h))` without trailing space, per-format `bmaControls` must be stored in each `struct uvcg_format` and only appended after `sizeof(h->desc)` when `__uvcg_fill_strm()` serializes `UVCG_HEADER`. [F71, F96]
- In `__uvcg_cnt_strm()` and `__uvcg_fill_strm()`, the fixed frame descriptor header size before `dwFrameInterval` is `sizeof(frm->frame) - 4`, and `UVCG_FRAMEBASED` frames must be serialized with `__uvcg_copy_framebased_desc()` because `struct uvc_frame_framebased` omits `dwMaxVideoFrameBufferSize`. [F70]
- Descriptor GUID fields (`guidFormat` and `guidExtensionCode`) are 16-byte raw binary arrays with embedded zero bytes and no NUL terminator, so they must be accessed with fixed-length `memcpy()` rather than string functions, and `uvcg_uncompressed_guid_format_store()` must validate `uvc_format_by_guid()` on a temporary buffer while `ch->fmt.linked` and `opts->refcnt` are zero before overwriting `ch->desc.guidFormat`. [F55, F106]

## Synchronization

- `video->req_lock` and `queue->irqlock` are shared across UDC interrupt callbacks (`uvc_video_complete`), workers (`uvcg_video_pump`, `uvcg_video_hw_submit`), and V4L2 process context, so both must always be acquired with `spin_lock_irqsave()` and must never be nested: `uvc_video_complete()`, `uvcg_video_pump()`, and `uvcg_video_disable()` must drop `video->req_lock` before calling `cancel_work_sync(&video->pump)`, `uvcg_queue_cancel()`, `uvcg_complete_buffer()`, or acquiring `queue->irqlock`. [F16, F17, F120, F122]
- Whenever the video stream may be active, accesses to `video->req_free`, `video->req_ready`, `video->ureqs`, and `video->req_int_count`, and calls to `uvcg_video_usb_req_queue()` and `uvc_video_free_request()`, must hold `video->req_lock`. Because `video->req_lock` disables interrupts, `uvcg_video_ep_queue()` must call `usb_ep_queue()` with `GFP_ATOMIC`. [F18, F121]
- After dropping and re-acquiring `video->req_lock` in `uvc_video_complete()` or `uvcg_video_pump()`, the caller must recheck `video->is_enabled` and call `uvc_video_free_request()` instead of returning `req` to `video->req_free` or queueing `video->pump` if `video->is_enabled` is `false`. [F19]
- `uvcg_video_usb_req_queue()` must only pass `queue_to_ep = true` from a single thread per endpoint type under `video->req_lock`: `uvcg_video_pump()` when `video->max_payload_size` is non-zero (bulk) and `uvcg_video_hw_submit()` when `video->max_payload_size` is zero (isoc). [F26]
- `uvcg_complete_buffer()`, `uvcg_queue_head()`, and `video->encode()` (`uvc_video_encode_bulk`, `uvc_video_encode_isoc`, `uvc_video_encode_isoc_sg`) must only be called while holding `queue->irqlock`. In `uvc_buffer_queue()` and `uvcg_queue_cancel()`, checking or setting `UVC_QUEUE_DISCONNECTED` in `queue->flags` and mutating `queue->irqqueue` must happen atomically within the same `queue->irqlock` critical section. [F20, F123]
- In `uvc_function_unbind()`, `kthread_cancel_work_sync(&video->hw_submit)` and `destroy_workqueue(video->async_wq)` must run before unregistering V4L2 devices, and `uvc->control_req` and `uvc->control_buf` must not be freed until waiting on `uvc->func_connected_queue` finishes. [F23]
- In `uvc_configfs.c`, callbacks that navigate the configfs hierarchy (`ci_parent` or `config_group_find_item()`) and access `struct f_uvc_opts` must acquire `cg_subsys->su_mutex` before `opts->lock`. [F127]

## Object Lifetimes

- `uvcg_video_usb_req_queue()` must not free `req->context` or add `req` to any list when returning a negative error code; ownership of `req` remains with the caller (`uvcg_video_pump()` or `uvcg_video_hw_submit()`) on failure. [F1]
- `uvcg_video_disable()` must unlink `video->ureqs` with `list_del_init(&ureq->list)` (so `uvc_video_free_request()` sees `list_empty(&ureq->list)`) and only free `uvc_request` instances on `video->req_free` or `video->req_ready`, leaving in-flight endpoint requests to be freed by `uvc_video_complete()` when `video->is_enabled` is false. [F3, F44]
- `uvcg_video_enable()` must call `uvcg_queue_enable(&video->queue, 1)`, `uvc_video_alloc_requests()`, and assign `video->encode` before queueing `video->hw_submit` and `video->pump`; `uvcg_video_disable()` must set `video->is_enabled = false` and move non-NULL `ureq->last_buf` from `video->ureqs` to `inflight_bufs` under `video->req_lock`, then cancel `video->pump` and `video->queue` and complete `inflight_bufs` via `uvcg_complete_buffer()` before `uvcg_queue_enable(&video->queue, 0)`. [F13, F110, F111]
- Because `(*class_array)[0]` owns the contiguous buffer backing all descriptors in `*class_array`, `uvcg_streaming_class_allow_link()` must `kfree(data_save)` (not the advanced `data` cursor) on failure, and `uvcg_streaming_class_drop_link()` must `kfree(**class_array)` before `kfree(*class_array)` and setting `*class_array = NULL`. [F7]

## API Contracts

- Both `uvc->vdev.lock` and `uvc->video.queue.queue.lock` use `&uvc->video.mutex`, and `uvc_v4l2_release()` must explicitly acquire `video->mutex` around `uvc_v4l2_disable()` because V4L2 core invokes `.release` without holding `vdev.lock`. [F132]
- `uvcg_queue_enable()` calls `vb2_streamon()` / `vb2_streamoff()` and must never be called from interrupt context; interrupt callbacks such as `uvc_video_complete()` must call `uvcg_queue_cancel()` instead. [F125]
- In `uvc_video_alloc_requests()`, `sg_alloc_table()` must allocate at least `DIV_ROUND_UP(video->req_size - UVCG_REQUEST_HEADER_LEN, PAGE_SIZE) + 2` scatterlist entries per `uvc_request` to fit 1 UVC header entry plus a page-unaligned payload spanning up to `DIV_ROUND_UP(..., PAGE_SIZE) + 1` pages. [F90]
- In `struct f_uvc_opts`, `opts->header` must be `NULL` for configfs-composed gadgets and non-NULL only for legacy gadgets (`webcam_bind()`), because `uvc_alloc()` skips configfs lookup when `opts->header` is set and `uvc_free()` only calls `config_item_put(&uvc->header->item)` when `opts->header` is `NULL`. [F141]

## Error Handling

- In `uvc_function_bind()`, if `uvc_copy_descriptors()` returns an `ERR_PTR` for `f->fs_descriptors`, `f->hs_descriptors`, `f->ss_descriptors`, or `f->ssp_descriptors`, that field must be reset to `NULL` before jumping to `error:` where `usb_free_all_descriptors(f)` is called. [F6]
- `to_uvc_format()` returns an `ERR_PTR` (such as `ERR_PTR(-EINVAL)`) rather than `NULL` on failure, so callers must check `IS_ERR()` before dereferencing the returned `uvc_format_desc` pointer. [F27]
- In `uvc_send_response()`, the signed `data->length < 0` check must precede `min_t(unsigned int, uvc->event_length, data->length)` and `data->length < uvc->event_length` so negative `s32` lengths halt `ep0` instead of converting to large `unsigned int` values. [F92]
- When `usb_ep_queue()` fails in `uvcg_video_ep_queue()`, `usb_ep_set_halt(video->ep)` must only be called if `video->ep->desc` is non-NULL and `usb_endpoint_xfer_bulk(video->ep->desc)` is true, because isochronous endpoints cannot be halted. [F144]

## External Contracts

- In UVC streaming descriptor arrays (`uvc_fs_streaming_cls`, `uvc_hs_streaming_cls`, `uvc_ss_streaming_cls` in `webcam.c` and `__uvcg_iter_strm_cls()` in `uvc_configfs.c`), a `uvc_color_matching_descriptor` must be placed immediately after the frame descriptors of each format. [F72]
- When `uvc_function_set_alt()` switches `uvc->streaming_intf` to alt 1 (from `UVC_STATE_CONNECTED`) or alt 0 (from `UVC_STATE_STREAMING`), it queues `UVC_EVENT_STREAMON` or `UVC_EVENT_STREAMOFF` and returns `USB_GADGET_DELAYED_STATUS`, which must be completed via `uvc_function_setup_continue()` in `uvc_v4l2_streamon()` or `uvc_v4l2_streamoff()`. [F119]

## Known Pitfalls

- Callers of `__uvcg_iter_item_entries()` with `__uvcg_fill_item_entries` and `__uvcg_iter_strm_cls()` with `__uvcg_fill_strm` must pass the address of a disposable cursor copy (such as `&tmp`, `&iter`, or `&data` and `&cl_arr`) rather than the base allocation pointer, because the fill callbacks advance the pointer in place. In `__uvcg_iter_item_entries()`, bounds checks on the dynamically allocated `char *buf` must use `bufsize` rather than `sizeof(buf)`. [F84, F98]
- In `uvc_video_encode_header()`, `ts.tv_sec` must be cast to `u64` before multiplying by `USEC_PER_SEC` and `48`, and `ts.tv_nsec / NSEC_PER_USEC` must divide the `long` nanosecond field of `struct timespec64` rather than a `u64` timestamp so 32-bit builds avoid 64-bit division link errors and 32-bit truncation before the `u32` cast. [F87]
