# MEMORY MANAGEMENT - MGLRU (MULTI-GEN LRU)

Implements page reclaim, LRU list management, workingset refault detection, and the Multi-Gen LRU (MGLRU) framework across per-CPU folio batches, per-node/per-memcg `lruvec`s, and page table walkers (`mm/vmscan.c`, `mm/swap.c`, `mm/workingset.c`).

## Architecture & Data Flow

- On `lrugen->folios[]`, `lru_gen_add_folio()` keeps `PG_active` clear and encodes `gen + 1` in `LRU_GEN_MASK`; `lru_gen_del_folio()` clears `LRU_GEN_MASK` and restores `PG_active` when `!reclaiming && lru_gen_is_active(lruvec, gen)`. When `lru_gen_change_state()` toggles `lruvec->lrugen.enabled`, it must migrate all evictable folios between `lruvec->lists[]` and `lruvec->lrugen.folios[]` via `fill_evictable()` or `drain_evictable()` under `lruvec->lru_lock`. [F61, F69]
- `folio_lru_refs()` returns `0` when `PG_referenced` is clear. Setting `PG_referenced` on an unreferenced folio (`lru_gen_inc_refs()`, `folio_update_gen()`, `lru_gen_set_refs()`) or isolating an unreferenced folio in `isolate_folio()` must clear `LRU_REFS_MASK`, and promoting via `folio_update_gen()`, `lru_gen_set_refs()`, or `folio_inc_gen()` must clear `LRU_REFS_FLAGS`. In `sort_folio()` and `inc_min_seq()`, a folio in the oldest generation with `refs + workingset == BIT(LRU_REFS_WIDTH) + 1` is lazily promoted via `folio_inc_gen()` without incrementing `lrugen->protected`. [F66, F87, F167]
- Before `inc_max_seq()` increments `lrugen->max_seq`, it must adjust active/inactive LRU sizes via `__update_lru_size()` by `lrugen->nr_pages[prev][type][zone] - lrugen->nr_pages[next][type][zone]` for every `(type, zone)` and call `reset_ctrl_pos(lruvec, type, false)` under `lruvec->lru_lock`. Advancing `lrugen->min_seq[type]` in `inc_min_seq()` or `try_to_inc_min_seq()` must first call `reset_ctrl_pos(lruvec, type, true)` under `lruvec->lru_lock`. [F62, F65]
- Because `lrugen->nr_pages[gen][type][zone]` can be transiently negative before `reset_batch_size()`, readers summing into an `unsigned long` (`lruvec_is_sizable()`, `should_run_aging()`, `lru_gen_seq_show()`) must clamp each read with `max(..., 0L)`. In `evict_folios()`, after `shrink_folio_list()`, `walk->lruvec = lruvec` and `reset_batch_size(walk)` must be called under `lruvec->lru_lock` whenever `walk && walk->batched` is non-zero. [F64, F121]
- `lru_gen_eviction()` packs `min_seq` and 0-based `max(refs - 1, 0)` into a shadow `token` truncated to `EVICTION_MASK`, so `lru_gen_test_recent()` must mask `lruvec->lrugen.max_seq` with `EVICTION_MASK >> LRU_REFS_WIDTH` before comparing with `*token >> LRU_REFS_WIDTH`. In `workingset_test_recent()`, unpacked `eviction` is shifted left by `bucket_order` and subtracted from `refault` under `EVICTION_MASK` (`(refault - eviction) & EVICTION_MASK`). [F88, F127]
- In `__remove_mapping()`, a shadow entry from `workingset_eviction()` is stored only when `reclaimed && !mapping_exiting(mapping)` (and `folio_is_file_lru(folio) && !dax_mapping(mapping)` for non-swapcache folios). Adding/removing an `xa_node` on `shadow_nodes` must update `WORKINGSET_NODES` in lockstep. In `workingset_refault()` and `lru_gen_refault()`, `folio` must be locked and `WORKINGSET_REFAULT_BASE` accounted to `folio_lruvec(folio)` (`lru_gen_refault()` aborts if the shadow's `lruvec` differs). [F73, F168, F174]
- During MGLRU page table and rmap walks (`get_pte_pfn()`, `get_pmd_pfn()`, `walk_pte_range()`, `walk_pmd_range_locked()`, `lru_gen_look_around()`), `!pte_young()` or `!pmd_young()` entries must not be skipped when `mm_has_notifiers(vma->vm_mm)` is true, and leaf young bits must be cleared with `{ptep,pmdp}_clear_young_notify()`. [F82]
- Mutating `pgdat->memcg_lru.fifo[gen][bin]` under `pgdat->memcg_lru.lock` (`lru_gen_online_memcg()`, `lru_gen_rotate_memcg()`, `lru_gen_release_memcg()`) must update `lruvec->lrugen.gen` and `pgdat->memcg_lru.nr_memcgs[gen]`, and increment `pgdat->memcg_lru.seq` when the oldest generation becomes empty. `shrink_many()` only calls `lru_gen_rotate_memcg()` when `shrink_one()` returns non-zero `op` (`MEMCG_LRU_HEAD`/`OLD` to head, `TAIL`/`YOUNG` to tail). `MEMCG_NR_GENS` must be >= 3. [F68, F104, F129]
- In `struct cpu_fbatches`, `folio_batch` members using `cpu_fbatches.lock` must precede `lock_irq`, and IRQ-disabled batches must follow `lock_irq` (selected via `offsetof` in `folio_batch_add_and_move()`). `__folio_batch_add_and_move()` must immediately drain via `folio_batch_move_lru()` whenever `!folio_may_be_lru_cached(folio)`, `lru_cache_disabled()`, or the batch is full. [F74, F89]
- Classic LRU (`shrink_inactive_list()`, `shrink_node()`) and MGLRU (`evict_folios()`, `sort_folio()`, `scan_folios()`, `try_to_shrink_lruvec()`) must both update `PGDEMOTE_KSWAPD + reclaimer_offset(sc)` by `stat.nr_demoted` (never guarded by `CONFIG_NUMA_BALANCING`), zero `sc->nr` in `shrink_node()`, and call `wakeup_flusher_threads(WB_REASON_VMSCAN)` only when `sc->nr.unqueued_dirty && sc->nr.unqueued_dirty == sc->nr.file_taken` (never in `try_to_inc_max_seq()`). [F70, F165, F166]
- In `shrink_folio_list()`, splitting a large folio (`nr_pages > 1`) via `split_folio_to_list()` or `pageout()` must adjust `sc->nr_scanned -= (nr_pages - 1)` and `nr_pages = 1`. `pageout()` must never write dirty regular filesystem folios (`!shmem_mapping(mapping) && !folio_test_anon(folio)` returns `PAGE_ACTIVATE`), and `shrink_folio_list()` must set `PG_reclaim` and activate dirty file-LRU folios unless `current_is_kswapd()`, `folio_test_reclaim(folio)`, and `PGDAT_DIRTY` are all set. [F170, F172]
- `LRUVEC_NODE_CONGESTED` on the root `lruvec` is only set/cleared by `kswapd` (`shrink_node()`, `clear_pgdat_congested()`), whereas cgroup reclaim in `do_try_to_free_pages()` only clears `LRUVEC_CGROUP_CONGESTED`. `flush_reclaim_state()` credits `current->reclaim_state->reclaimed` to `sc->nr_reclaimed` only when `root_reclaim(sc)` is true. In `do_try_to_free_pages()`, each `goto retry` fallback must reset `sc->priority = initial_priority` and clear its trigger flag (`skipped_deactivate` or `memcg_low_skipped`). [F78, F79, F173]

## Synchronization

- `move_folios_to_lru()` is entered and exited with `lruvec->lru_lock` held and IRQs disabled; it must call `folio_set_lru(folio)` under `lru_lock` before `folio_put_testzero(folio)` (and `__folio_clear_lru_flags(folio)` before unlocking if refcount hits zero), and must drop and re-acquire `spin_lock_irq(&lruvec->lru_lock)` around `folio_putback_lru()` and `mem_cgroup_uncharge_folios()` / `free_unref_folios()`. [F6, F7]
- Moving an on-LRU folio between LRU lists in `folio_batch_move_lru()` (`move_fn != lru_add`) or `check_move_unevictable_folios()` requires `folio_test_clear_lru(folio)` before `folio_lruvec_relock_irqsave()` / `folio_lruvec_relock_irq()` and `folio_set_lru(folio)` before unlocking. In `folios_put_refs()`, before `free_zone_device_folio()` or `free_huge_folio()`, any held `lruvec` lock must be released with `unlock_page_lruvec_irqrestore(lruvec, flags)` and `lruvec = NULL`. [F8, F22]
- `__lru_cache_activate_folio()` must only scan the local CPU's `cpu_fbatches.lru_add` under `local_lock(&cpu_fbatches.lock)`. `lru_add_drain_all()` must not be called under `cpus_read_lock()`; `__lru_add_drain_all()` requires `smp_mb()` and `smp_load_acquire(&lru_drain_gen)` before `lock`, paired with `WRITE_ONCE(lru_drain_gen, lru_drain_gen + 1)` and `smp_mb()` inside `lock`; and `lru_cache_disable()` must call `synchronize_rcu_expedited()` after `atomic_inc(&lru_disable_count)` before draining. [F24, F25, F152]
- `inc_min_seq()`, `fill_evictable()`, and `drain_evictable()` must stop and return `false` at `MAX_LRU_BATCH` so callers drop `lruvec->lru_lock` and `cond_resched()`. When `inc_max_seq()` drops `lruvec->lru_lock` to `cond_resched()`, it must `goto restart` to recheck `seq == lrugen->max_seq` and `get_nr_gens(lruvec, type) == MAX_NR_GENS`, and must publish `lrugen->max_seq` via `smp_store_release()` only after updating LRU sizes, `reset_ctrl_pos()`, and `lrugen->timestamps[next]`. [F28, F29, F116]
- `lru_gen_change_state()` must acquire `cgroup_lock()`, `cpus_read_lock()`, `get_online_mems()`, and `mutex_lock(&state_mutex)` in that order and release them in reverse order. `lru_gen_migrate_mm(mm)` requires `mm->owner->alloc_lock` held and must return early if `!mm->lru_gen.memcg`. [F18, F33]
- All acquisitions of `pgdat->memcg_lru.lock` must disable IRQs (`spin_lock_irqsave` / `spin_lock_irq`) because `lru_gen_rotate_memcg()` is called from softirq. In `shrink_many()`, `hlist_nulls_for_each_entry_rcu` runs under `rcu_read_lock()`, must pin `memcg` with `mem_cgroup_tryget(memcg)` before dropping `rcu_read_lock()` for `shrink_one()`, and must re-acquire `rcu_read_lock()` afterwards. [F142, F150]
- `walk_pte_range()` must verify `pmd_same(pmdval, pmdp_get_lockless(pmd))` after `pte_offset_map_rw_nolock()` and `spin_trylock(ptl)` (unmapping/unlocking on failure), and `walk_pte_range()`, `walk_pmd_range_locked()`, and `lru_gen_look_around()` must pair `arch_enter_lazy_mmu_mode()` with `arch_leave_lazy_mmu_mode()` before unlocking `ptl`. `mm_tlb_flush_pending()` / `mm_tlb_flush_nested()` require `ptl` held; in `shrink_folio_list()`, `try_to_unmap_flush_dirty()` is required before `pageout()` and `try_to_unmap_flush()` before `free_unref_folios()`. [F19, F31, F41, F154, F157]
- `workingset_update_node()` requires `node->array->xa_lock`. Because `shadow_nodes` `lru->lock` nests inside `i_pages.xa_lock` which nests inside `mapping->host->i_lock`, `shadow_lru_isolate()` must use trylocks (`xa_trylock`, `spin_trylock`) and on `LRU_RETRY`/`LRU_REMOVED_RETRY` unlock everything and restore IRQs before `cond_resched()`. In `__remove_mapping()`, non-swapcache folios must lock `mapping->host->i_lock` before `xa_lock_irq(&mapping->i_pages)` and unlock `i_pages` before `inode_add_lru()`. [F10, F37, F159]
- In `workingset_test_recent()` and `lru_gen_refault()`, `mem_cgroup_from_id()` requires `rcu_read_lock()`, and `workingset_test_recent()` must pin `eviction_memcg` with `mem_cgroup_tryget()` before `rcu_read_unlock()` to call `mem_cgroup_flush_stats_ratelimited()` outside RCU. In `__remove_mapping()`, `folio_ref_freeze(folio, refcount)` must precede `folio_test_dirty(folio)`. [F38, F102]

## Object Lifetimes

- When freeing a zero-refcount folio (`__folio_put()`, `folios_put_refs()`, `shrink_folio_list()`, `move_folios_to_lru()`), `folio_unqueue_deferred_split(folio)` must precede `mem_cgroup_uncharge()` / `mem_cgroup_uncharge_folios()`. In `__remove_mapping()` on a swapcache folio, `workingset_eviction()` and `__swap_cache_del_folio()` must precede `memcg1_swapout(folio, swap)`. [F1, F2]
- When isolating a folio without an existing caller reference in `isolate_lru_folios()` or `isolate_folio()`, `folio_try_get(folio)` must succeed before `folio_test_clear_lru(folio)`, calling `folio_put(folio)` if `folio_test_clear_lru(folio)` fails. [F5]
- `lru_gen_del_mm(mm)` must advance any node's `mm_state->head` (`prev`) and `mm_state->tail` (`next`) pointing to `&mm->lru_gen.list` before `list_del_init()` under `mm_list->lock`, then call `mem_cgroup_put(mm->lru_gen.memcg)` and set `mm->lru_gen.memcg = NULL`. `iterate_mm_list()` flushes `walk->mm_stats` via `reset_mm_stats()` under `mm_list->lock` and calls `mmput_async(*iter)` after unlocking. [F11, F12]
- `set_mm_walk()` requires `current->reclaim_state`, returns `&pgdat->mm_walk` for `kswapd` and a `kzalloc()` buffer (or `NULL`) otherwise, and must be paired with `clear_mm_walk()` before clearing `reclaim_state`. All deltas in `walk->nr_pages` and `walk->mm_stats` must be flushed before `clear_mm_walk()`, which only calls `kfree(walk)` when `!current_is_kswapd()`. [F13, F52, F56]

## API Contracts

- `__remove_mapping()` freezes refcount to 0 on success and calls `folio_ref_unfreeze()` on dirty abort; callers retaining the folio (like `remove_mapping()`) must call `folio_ref_unfreeze(folio, 1)`. `lru_note_cost_unlock_irq()` consumes the caller's IRQ-disabled `lruvec->lru_lock` and returns with all `lru_lock`s unlocked and IRQs enabled. [F4, F9]
- `mem_cgroup_calculate_protection()` is stateful and must only be called during a top-down `mem_cgroup_iter()` walk (`lru_gen_age_node()` after `set_initial_priority()`, or `shrink_node_memcgs()`), never in `shrink_one()`. `mem_cgroup_below_min()`, `mem_cgroup_below_low()`, `mem_cgroup_protection()`, and `mem_cgroup_calculate_protection()` take `sc->target_mem_cgroup` first and `memcg` second. [F57, F162]
- `lru_gen_update_size()` takes `-1` for `old_gen` on add, `-1` for `new_gen` on delete, and `0 <= gen < MAX_NR_GENS` for both on promotion (never demoting active to inactive in-place). In `shrink_folio_list()`, `try_to_unmap()` on a large folio requires `TTU_SYNC` (and `TTU_SPLIT_HUGE_PMD` if PMD-mappable). `pte_install_uffd_wp_if_needed()` requires `ptl` held and `pte_none(ptep_get(pte))`, skipping anon or non-`userfaultfd_wp` VMAs. [F58, F171, F175]

## Error Handling

- Callers of `get_pte_pfn()` and `get_pmd_pfn()` must check `pfn != -1` (`~0UL`) before `get_pfn_folio()`, and MGLRU walks (`lru_gen_look_around()`, `should_skip_vma()`) must skip `VM_SPECIAL` VMAs. `get_nr_to_scan()` returns signed `long` (`> 0` scan, `0` stop, `-1` stop and rotate to `MEMCG_LRU_YOUNG`). In `folio_check_references()`, `referenced_ptes == -1` must be checked first to return `FOLIOREF_KEEP`. [F43, F44, F46, F163]
- `shadow_lru_isolate()` must check `mapping->host != NULL` (swapcache has `NULL` host) before locking `i_lock` or calling `inode_add_lru()`. `workingset_eviction()` must pass `lruvec_memcg(lruvec)` (not nullable `target_memcg`) to `mem_cgroup_id()`. `test_bloom_filter()` returns `true` and `update_bloom_filter()` returns early when `mm_state->filters[gen]` is `NULL`; callers of `get_mm_state()` / `get_mm_list()` outside `CONFIG_LRU_GEN_WALKS_MMU` must check for `NULL`. [F48, F49, F50, F51]

## Known Pitfalls

- In `shrink_folio_list()`, `PAGE_SUCCESS` from synchronous `pageout()` when clean and not writeback must re-acquire `folio_trylock()`, re-verify clean/non-writeback, reload `mapping`, and fall through to `PAGE_CLEAN`; `demote_folio_list()` results must use `+=` into `nr_reclaimed` and `stat->nr_demoted` with `do_demote_pass = false` before `goto retry`; and `folio_contain_hwpoisoned_page()` must skip `folio_test_large(folio)` before `unmap_poisoned_folio()`. [F103, F110, F161]
- In `walk_pte_range()`, `walk_pmd_range_locked()`, and `lru_gen_look_around()`, coalescing into `last` must reset `dirty = false` after flushing `last` via `walk_update_folio()`, and flush `last` after the loop. `walk_pmd_range_locked()` sets `__set_bit(i - 1, bitmap)` for offsets `1 <= i <= MIN_LRU_BATCH` from `*first` and flushes on `addr = -1`. `lru_gen_look_around()` rewinds `pte_t *pte` by `(addr - start) / PAGE_SIZE`. [F91, F112, F139]
- In `evict_folios()`, surviving folios in `list` require `list_for_each_entry_safe_reverse()`, and retrying `clean` folios must not decrement `sc->nr_scanned` (and must retry once via `shrink_folio_list()` before `move_folios_to_lru()`). In `shrink_many()`, `!is_a_nulls(pos)` must be checked after the RCU loop before `get_nulls_value(pos)`. Encoding `LRU_GEN_PGOFF` or `LRU_REFS_PGOFF` into `folio->flags.f` requires widening to `1UL`, and `get_next_mm()` must index `mm->lru_gen.bitmap` by `pgdat->node_id % BITS_PER_TYPE(mm->lru_gen.bitmap)`. [F40, F95, F105, F106, F119, F137]
