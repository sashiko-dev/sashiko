# KCONFIG

KCONFIG (`scripts/kconfig/`) is the host-side build configuration engine and user-interface suite (`conf`, `mconf`/`lxdialog`, `nconf`, `gconf`, `qconf`) for the Linux kernel. It preprocesses and parses `Kconfig` files into an in-memory tree of menus, symbols, properties, and dependency expressions, evaluates symbol visibility and values, and reads and writes configuration, header, and dependency files.

## Architecture & Data Flow

- Choice blocks use `struct symbol` instances with `sym->name == NULL` (`sym_is_choice(sym)`). Any code dereferencing `sym->name` on a general symbol (e.g., from `for_all_symbols()` or `menu->sym`) must check `sym->name` is non-NULL first. [F24]
- In `struct expr`, `left` and `right` (`union expr_data`) are discriminated by `e->type`: `E_OR`/`E_AND` use `left.expr` and `right.expr`; `E_NOT` uses `left.expr` (`right` is `NULL`); `E_SYMBOL` uses `left.sym` (`right` is `NULL`); relational/range types (`E_EQUAL`..`E_GEQ`, `E_RANGE`) use `left.sym` and `right.sym`. [F21]
- When `expr_lookup()` allocates a `struct expr` via `xmalloc()`, it must initialize `e->val_is_valid = false` along with `e->type`, `e->left._initdata`, and `e->right._initdata` before inserting into `expr_hashtable`, because `expr_calc_value()` skips evaluation when `val_is_valid` is true. [F20]
- After `SYMBOL_VALID` is cleared on `modules_sym` (via `sym_clear_all_valid()` or `conf_read()`), `sym_calc_value(modules_sym)` must run before calculating other symbols so `modules_val` is updated for `sym_get_type()` and `sym_calc_visibility()`. [F36]
- In `sym_calc_value()`, `newval.tri` must be initialized to `no` before switching on `sym->type`: `S_INT`, `S_HEX`, and `S_STRING` only set `newval.val`, while expression evaluation reads `sym->curr.tri` and `memcmp(&oldval, &sym->curr, sizeof(oldval))` compares the full `struct symbol_value`. When a symbol without `SYMBOL_DEF_USER` (`!sym_has_value(sym)`) gets its default from a `prop` whose `prop_get_symbol(prop)` has `SYMBOL_TRANS` and `sym_has_value()`, both `sym->def[S_DEF_USER] = newval` and `SYMBOL_DEF_USER` must be set on `sym`. [F23, F37]
- Static constant symbols `symbol_yes`, `symbol_mod`, and `symbol_no` in `symbol.c` must initialize `.type = S_TRISTATE` and `.flags = SYMBOL_CONST | SYMBOL_VALID` so `expr_parse_string()` in `__expr_calc_value()` parses them as numeric tristates (`0`, `1`, `2`) instead of comparing strings lexicographically. [F22]
- In `sym_set_string_value()`, the new `sym->def[S_DEF_USER].val` buffer must be allocated and populated from `newval` before `free((void *)oldval)` because callers like `conf_string()` pass `sym_get_string_value(sym)` (aliasing `oldval`) as `newval`. If an `S_HEX` `newval` lacks a `"0x"`/`"0X"` prefix, `size` must include 2 extra bytes and `sym->def[S_DEF_USER].val` must store the base pointer before `val` is advanced past `"0x"` for `strcpy()`. [F46, F89]
- In `symbol.c` (`sym_get_range_val()`, `sym_validate_range()`, `sym_string_within_range()`), `S_INT` and `S_HEX` values must be parsed and compared as 64-bit `long long` via `strtoll` (not `long`/`strtol`). In `expr.c` (`expr_parse_string()`, `__expr_calc_value()`), `S_HEX` must use `unsigned long long` (`k_unsigned`, `strtoull`), `S_INT` must use `signed long long` (`k_signed`, `strtoll`), and relational comparisons must use `(a > b) - (a < b)` on `lval.u`/`rval.u` if either is `k_unsigned` or `lval.s`/`rval.s` if both are `k_signed` (avoiding 64-bit subtraction overflow). [F83, F84]
- Every `dep_stack_insert()` in `sym_check_deps()`, `sym_check_sym_deps()`, `sym_check_choice_deps()`, and `sym_check_print_recursive()` must be paired with `dep_stack_remove()` before returning, clearing `SYMBOL_CHECK` while keeping `SYMBOL_CHECKED` set. In `sym_check_sym_deps()`, `stack.expr` must be `NULL` before iterating `sym->prop` and reset to `NULL` after each `P_DEFAULT` check so subsequent `prop->visible.expr` cycles report as visibility dependencies. [F47, F75]
- When `_menu_finalize()` iterates over `menu->sym->prop` for a child menu node, it must skip properties where `prop->menu != menu` so location-specific `basedep` and `select`/`imply` reverse dependencies are only propagated for properties defined at that menu node. [F77]
- In `menu_is_visible()`, if a menu's own prompt visibility is `no`, it must still return `true` when `menu->sym` is non-NULL, `sym_get_tristate_value(menu->sym) != no`, and any child in `menu->list` is recursively visible. [F71]
- User-specified choice values in `choice_set_value()` and `conf_read_simple()` must move to the head of `choice->choice_members` via `list_move()`, whereas random selections in `randomize_choice_values()` must move to the tail via `list_move_tail()`, matching `sym_calc_choice()`'s forward scan for `'y'` and reverse scan for least-prioritized `'n'`. [F79]
- `S_DEF_*` enum values (`S_DEF_USER`, `S_DEF_AUTO`, `S_DEF_DEF3`, `S_DEF_DEF4`) in `expr.h` must remain 0-based consecutive integers matching `SYMBOL_DEF << def` (`SYMBOL_DEF_USER`, `SYMBOL_DEF_AUTO`, `SYMBOL_DEF3`, `SYMBOL_DEF4`) used by `conf_read_simple()`. [F52]
- In `conf_read_simple()`, any fallback opening an alternate file (e.g., from `KCONFIG_DEFCONFIG_LIST`) must update `name` before jumping to `load:` so `conf_filename = name`, `conf_lineno = 0`, and `conf_warnings = 0` match the stream. [F41]
- `conf_write()` must track emitted symbols with `SYMBOL_WRITTEN` and clear `SYMBOL_WRITTEN` across all symbols via `for_all_symbols()` before returning, without clearing `SYMBOL_WRITE` or calling `sym_clear_all_valid()` in `conf_write_autoconf()`. [F39]
- Before calling `conf_read_simple(name, S_DEF_AUTO)` or `conf_touch_dep()`, `conf_touch_deps()` must initialize `depfile_prefix_len` and `depfile_path` with the directory prefix of `conf_get_autoconfig_name()` after verifying `depfile_prefix_len + 1 <= sizeof(depfile_path)`. `conf_touch_dep()` overwrites `depfile_path + depfile_prefix_len` in place and must first verify `depfile_prefix_len + strlen(name) + 1 <= sizeof(depfile_path)`. [F44, F57]
- In `eval_clause()`, numeric argument references are 1-based (`n > 0 && n <= argc`) indexing `argv[n - 1]`. Every append to `new_argv[new_argc++]` (inside the comma-splitting loop and for the trailing token) must first check `new_argc >= FUNCTION_MAX_ARGS` and abort via `pperror()`, and `new_argv[0]` is consumed as `name` before shifting the remaining `new_argc - 1` arguments down. [F54, F55]
- In `get_prompt_str()`, the menu walk into `submenu[8]` must bound `i < 8`, start at `prop->menu`, and stop at `menu != &rootmenu` so `jump->target` is never `&rootmenu` (`parent == NULL`). It must store `jump->offset = strlen(r->s)` as a byte offset (not a `char *` into `r->s`, which `str_append()` may `xrealloc()`) for `handle_search_keys()` to match against `[start, end)`. In `search_conf()`, `jump_key_char` must be reset to `0` before `get_relations_str(sym_arr, &head)`. [F26, F48, F68, F91]
- In `nconf.c`, mutating `k_menu_items[index].str` after `item_make()` (as in `item_add_str()`) requires freeing and recreating `curses_menu_items[index]` with `new_item()` and `set_item_userptr()`, and `show_menu()` must call `set_menu_format(curses_menu, maxy, 1)` after `set_menu_items()`. [F49]
- Every `attr_*` global attribute in `nconf.gui.c` and `nconf.h` must have an entry in both `color_theme_params[]` and `no_color_theme_params[]`, both arrays must end with a zeroed `{ /* sentinel */ }` (`p->attr == NULL`) for `set_colors()`, and `btn_dialog()` must set `btns[btn_num] = NULL` before calling `new_menu(btns)`. [F53, F64]

## Object Lifetimes

- Every `struct gstr` allocated by `str_new()` or returned by `get_relations_str()` (except the process-global `autoconf_cmd`) must be released with `str_free()` before its owning scope returns. [F1]
- In `variable_add()`, redefining an existing `struct variable` with `flavor != VAR_APPEND` frees the old `v->value` and takes ownership of `new_value`, whereas `flavor == VAR_APPEND` reallocates `v->value`, appends `new_value`, and frees `new_value`. [F7]
- `env_write_dep()` consumes and destroys `env_list` by unlinking and freeing every `struct env` node via `env_del()`, so `env_list` entries do not survive after `env_write_dep()` runs. [F6]
- `sym_re_search()` must `free(sym_match_arr)` and `regfree(&re)` on all paths after `regcomp()` succeeds (including allocation failures), while returning a `NULL`-terminated `struct symbol **` array (`(cnt + 1)` elements with `sym_arr[cnt] = NULL`) that the caller must iterate until `NULL` and `free()`. [F11, F87]
- In `zconf_nextfile()` and `zconf_endfile()` (`lexer.l`), `source` inclusion pushes a heap-allocated `struct buffer` onto `current_buf` and switches `YY_CURRENT_BUFFER`; `zconf_endfile()` must `fclose(yyin)`, `yy_delete_buffer(YY_CURRENT_BUFFER)`, restore `current_buf->state`, and `free()` the popped `struct buffer`. [F18]
- In `mconf.c`, `conf()` and `search_conf()` link a stack-allocated `struct subtitle_part` onto the global `trail` list via `list_add_tail(&stpart.entries, &trail)` and must unlink it via `list_del(trail.prev)` before returning (and in `search_conf()`, before `str_free(&sttext)` frees `stpart.text`). [F13]
- In `lxdialog` (`dialog_checklist()`, `dialog_menu()`, `dialog_textbox()`), the child subwindow created with `subwin(dialog, ...)` (`list`, `menu`, or `box`) must be destroyed with `delwin()` before the parent `delwin(dialog)` on every return and `KEY_RESIZE` path. [F16]
- In `nconf.c` (`reset_menu()` / `clean_items()`) and `nconf.gui.c` (`btn_dialog()`), `unpost_menu()` (and `free_menu()` when destroying a menu) must be called before freeing attached `ITEM *` elements with `free_item()`, and `clean_items()` must zero `curses_menu_items` and `items_num` afterward. [F17]

## API Contracts

- `escape_string_value()`, `expand_dollar()`, `expand_one_token()`, `expand_string_with_args()`, `eval_clause()`, `env_expand()`, `variable_expand()`, and `function_expand()` (`preprocess.c`) return newly heap-allocated strings that the caller owns and must `free()`. Every built-in handler in `function_table` (`struct function::func`) must return a heap-allocated string (e.g., `xstrdup("")` when empty) and never `NULL`, because `function_expand()` uses `NULL` to signal an unknown function name to `eval_clause()`. [F4, F5, F19]
- `sym_lookup()` copies a non-NULL `name` with `xstrdup()` (leaving the caller to free its `name` argument), whereas `menu_add_prompt()` takes ownership of `prompt` without copying and advances `prompt` past leading whitespace before storing it in `prop->text`. [F8]
- `file_lookup()` and `expr_lookup()` intern entries in `file_hashtable` and `expr_hashtable` for the life of the process; callers must never `free()` the `const char *` returned by `file_lookup()` or `struct expr *` nodes replaced during simplification (`expr_transform()`, `expr_eliminate_dups()`, `expr_eliminate_eq()`). [F9]
- `prop_get_symbol()` returns `NULL` whenever `prop->expr` is `NULL` or `prop->expr->type != E_SYMBOL`; callers inspecting `P_DEFAULT` properties must check for a non-NULL return before dereferencing. [F25]
- In `menu_next(menu, root)`, ascending the parent chain when `!menu->next` must stop at `menu == root` and return `NULL` before accessing `menu->next` so `menu_for_each_sub_entry(menu, root)` stays within `root`'s subtree. [F78]
- When `conf_read_simple()` is called with `def != S_DEF_USER` (such as `S_DEF_AUTO` from `conf_touch_deps()`), it must only clear and populate `sym->def[def]` and `SYMBOL_DEF << def` without clearing `SYMBOL_VALID`, calling `expr_invalidate_all()`, calling `conf_set_changed(true)`, or reordering `choice->choice_members`. [F40]
- Callbacks registered via `conf_set_changed_callback()` must read their `bool` parameter rather than calling `conf_get_changed()`, because `conf_set_changed()` invokes `conf_changed_callback(val)` before updating `conf_changed = val`. [F42]
- When a non-NULL `struct list_head *head` is passed to `get_relations_str()` (which forwards it to `get_prompt_str()`), `get_prompt_str()` allocates `struct jump_key` nodes with `xmalloc()` and appends them to `head`, transferring ownership to the caller to `free()`. [F14]
- `get_line()` in `nconf.gui.c` returns a pointer into a multi-line buffer where lines are separated by `'\n'` rather than NUL-terminated; callers operating on a single line (`fill_window()`, `btn_dialog()`) must bound reads with `get_line_length(line)` (e.g., `"%.*s"`) instead of `"%s"` or `strlen()`. [F96]

## Error Handling

- In `conf_write_autoconf_cmd()` and `__conf_write_autoconf()`, every `snprintf()` formatting a derived filename into a `PATH_MAX` buffer must verify `ret < sizeof(buf)` and return `-1` on truncation, and the temporary output `FILE *` must be flushed (`fflush()`), checked (`ferror()`), and closed (`fclose()`) before returning `-1` on write error or calling `rename()`. [F2, F58]

## External Contracts

- In `conf_write_autoconf()`, writing `conf_get_autoconfig_name()` (`include/config/auto.conf`) via `__conf_write_autoconf()` must be the final step after `conf_write_autoconf_cmd()`, `conf_touch_deps()`, `conf_get_autoheader_name()`, and `conf_get_rustccfg_name()` succeed. [F3]
- `print_symbol_for_autoconf()` formats `include/config/auto.conf` with unescaped `S_STRING` values (`escape_string = false`) and omits `=n` symbols (`OUTPUT_N_NONE`), so `conf_set_sym_val()` must skip quote-stripping and backslash-unescaping when `def == S_DEF_AUTO`. `print_symbol_for_c()` and `print_symbol_for_rustccfg()` must both omit `=n` symbols and prefix `S_HEX` values with `"0x"` when `0x`/`0X` is absent, while `print_symbol_for_rustccfg()` must pass every value through `escape_string_value()`. [F59, F60]

## Known Pitfalls

- In `sym_check_deps()`, `SYMBOL_CHECK` must be tested in `sym->flags` before `SYMBOL_CHECKED` because entering a symbol's dependency check sets `SYMBOL_CHECK | SYMBOL_CHECKED` simultaneously and only clears `SYMBOL_CHECK` upon completion. [F72]
- When `switch` cases group relational expression types (such as `E_LEQ` with `E_LTH` or `E_GEQ` with `E_GTH` in `expr_print()` and `expr_transform()`), any inner ternary on `e->type` must test an enum variant belonging to that case. [F73]
- In-place character removals and insertions in `strip()` (`conf.c`), `conf_set_sym_val()` (`confdata.c`), and `dialog_inputbox()` (`nconf.gui.c`) shift overlapping slices of the same buffer and must use `memmove()` with a length that includes the NUL terminator. [F92]
- `nconf.gui.c:dialog_inputbox()` requires `*resultp` to be `NULL` (`*result_len == 0`) or a heap buffer of `*result_len` bytes. It must reallocate `*resultp` whenever `strlen(init) + 1 > *result_len` before copying `init` and whenever `len + 2 > *result_len` before shifting with `memmove()` to insert a character, updating `*resultp`, local `result`, and `*result_len` together; callers (`nconf.c:search_conf()`) must compute interior pointers like `dialog_input` only after `dialog_inputbox()` returns. [F33, F50, F65]
- In `lxdialog/util.c`, `item_reset()` must free all `item_head` nodes, set `item_head = NULL`, and set `item_cur = &item_nil` (never `NULL`), and `item_add_str()` must bound `vsnprintf()` to `sizeof(item_cur->node.str) - strlen(item_cur->node.str)`. Because `item_foreach()` leaves `item_cur` as `NULL` when the loop runs to completion, callers must reposition `item_cur` via `item_set()` or `item_activate_selected()` (checking its return value) before calling `item_data()`, `item_tag()`, `item_str()`, or `item_set_*()`. [F15, F51, F66]
