# AMAZON ETHERNET DRIVERS

This unit implements the Linux kernel network device driver for the Amazon Elastic Network Adapter (ENA) PCIe NIC family, split into a hardware/firmware communication layer (`ena_com`, `ena_eth_com`) for admin, AENQ, and I/O queues (including LLQ device-memory push mode) and an OS integration layer (`ena_netdev`, `ena_ethtool`, `ena_devlink`, `ena_phc`, `ena_debugfs`).

## Architecture & Data Flow

- XDP TX rings (`ENA_IS_XDP_INDEX(adapter, i)`) have `ena_napi->rx_ring == NULL` and store `xdpf` (not `skb`) in `struct ena_tx_buffer`. Loops over `num_io_queues + xdp_num_queues` must guard `rx_ring` access with `!ENA_IS_XDP_INDEX()`; `ena_free_tx_bufs()` must check `ENA_IS_XDP_INDEX()` to call `xdp_return_frame()` vs `dev_kfree_skb_any()`; and `ena_unmask_interrupt()` must set `rx_interval = tx_ring->smoothed_interval` before `if (rx_ring)`. [F48, F59, F82]
- `io_sq->qid` and `io_cq->qid` must equal the array index in `ena_dev->io_sq_queues[]` / `io_cq_queues[]` (`ENA_IO_TXQ_IDX(q)` or `ENA_IO_RXQ_IDX(q)`) for `container_of()` in `ena_com_io_sq_to_ena_dev()`. `adapter->irq_tbl[0]` is the management IRQ, so I/O queue `q` maps to `adapter->ena_napi[q]` but `adapter->irq_tbl[ENA_IO_IRQ_IDX(q)]` (`1 + q`). [F80, F83]
- Every `q_depth`, `ring_size`, and `buffers_num` must be a power of two. `ena_ring` indices (`next_to_use`, `next_to_clean`) stay pre-masked via `ENA_TX_RING_IDX_NEXT` / `ENA_RX_RING_IDX_NEXT`, whereas `ena_com_io_sq`/`io_cq` counters (`tail`, `next_to_comp`, `head`) are free-running `u16` values masked with `& (q_depth - 1)` on access and subtracted as `u16` in `ena_com_free_q_entries()`. [F79, F118, F119]
- Address CQ entries in `io_cq->cdesc_addr.virt_addr` by scaling the masked index by `io_cq->cdesc_entry_size_in_bytes` on a byte pointer. In `ena_com_rx_pkt()`, exit the loop via `if (++i >= nb_hw_desc) break;` before advancing `cdesc` so `cdesc` points to the last descriptor when `ena_com_rx_set_flags()` runs. [F99, F131]
- In `ena_com_cdesc_rx_pkt_get()`, if `ena_com_get_next_rx_cdesc()` returns `NULL` before `ENA_ETH_IO_RX_CDESC_BASE_LAST_MASK`, save `io_cq->cur_rx_pkt_cdesc_count = count` (without updating `cur_rx_pkt_cdesc_start_idx`) and set `*num_descs = 0`. `ena_com_rx_pkt()` must validate `nb_hw_desc <= ena_rx_ctx->max_bufs` and `cdesc->req_id < io_cq->q_depth` before returning. [F77, F102]
- In `ena_clean_rx_irq()`, when `xdp_verdict != ENA_XDP_PASS`, return all `ena_rx_ctx.descs` IDs to `rx_ring->free_ids` and account `ena_bufs[0].len` and `res_budget` before `continue`. `ena_xdp_handle_buff()` must drop `num_descs > 1` with `ENA_XDP_DROP` before `xdp_prepare_buff()`, and on `ENA_XDP_PASS` update `rx_info->buf_offset` and `ena_bufs[0].len` from `xdp->data`/`data_end`. [F68, F177]
- In `ena_alloc_rx_buffer()`, reset `rx_info->buf_offset = rx_ring->rx_headroom` before returning early on a reused `rx_info->page`. All RX page DMA mappings and lengths must use `ENA_PAGE_SIZE` (capped at `SZ_16K`) rather than `PAGE_SIZE` so 64 KiB pages never overflow `u16` length fields. [F66, F113]
- In `ena_com_prepare_tx()`, `ena_tx_ctx->ena_bufs[0]` shares the `ena_eth_io_tx_desc` allocated before the `for (i = 0; i < num_bufs; i++)` loop, so `ena_com_sq_update_tail()` and `get_sq_desc()` inside the loop must only run when `i != 0`. When `io_sq->disable_meta_caching` is true, `ena_com_create_and_store_tx_meta_desc()` must call `ena_com_create_meta()` even when `meta_valid` is `0`. [F93, F98]
- In LLQ mode (`ENA_ADMIN_PLACEMENT_POLICY_DEV`), `ena_set_queues_placement_policy()` requires `BIT(ENA_ADMIN_LLQ)`, non-NULL `mem_bar`, and `ena_com_config_dev_mode()` success. When `is_llq_max_tx_burst_exists(io_sq)` is true, `ena_xmit_common()` must check `ena_com_is_doorbell_needed()` (using `DIV_ROUND_UP()`) and call `ena_ring_tx_doorbell()` before `ena_com_prepare_tx()`. [F76, F117, F144]
- `ena_update_queue_count()` must call `ena_com_rss_destroy()`, update `xdp_first_ring` / `xdp_num_queues` if XDP is active, and call `ena_init_io_rings()`. `ena_set_channels()` must reject `count` with `-EINVAL` if `!ena_xdp_legal_queue_count(adapter, count)` while XDP is loaded, and toggle `netdev->xdp_features`. [F61, F187]
- Propagate adapter settings to rings: `ena_set_rx_copybreak()` updates `rx_ring[i].rx_copybreak`; `ena_set_coalesce()` updates `smoothed_interval` on all TX/RX rings; and `ena_restore_device()` holds `ENA_FLAG_ONGOING_RESET` until after `ena_up()` and refreshes each TX/XDP ring's `tx_mem_queue_type` and `tx_max_header_size`. [F62, F64, F70]
- All stats structs must contain only `u64` fields (`stat_offset` is a `u64` index). `ena_get_sw_stats_count()` / `ena_get_hw_stats_count()`, `ena_get_strings()`, and `ena_get_stats()` must stay in lockstep: check `ENA_ADMIN_CUSTOMER_METRICS` before `else if (ENA_ADMIN_ENI_STATS)`, advance `(*data)` even on admin command failure, and keep `ENA_ADMIN_CUSTOMER_METRICS_SUPPORT_MASK` matched with `ena_hw_stats_strings`. [F74, F107, F123, F126]
- In `ena_io_poll()`, when `budget == 0` (netpoll), skip `ena_clean_rx_irq()` and keep strict `budget > rx_work_done`. `ena_update_ring_numa_node()` must only run after `napi_complete_done()`, tracking `numa_node` separately from `cpu`. `ena_devlink_alloc()` stores a pointer, so devlink callbacks must use `ENA_DEVLINK_PRIV(devlink)`, never `devlink_priv(devlink)` directly. [F55, F65, F106]

## Synchronization

- `ena_destroy_device()` and `ena_restore_device()` require `rtnl_lock()`; async callers (`ena_fw_reset_device()`, `ena_devlink_reload_up()`) must recheck `ENA_FLAG_TRIGGER_RESET` or `ENA_FLAG_DEVICE_RUNNING` after locking. `__ena_shutoff()` must call `timer_delete_sync()` and `cancel_work_sync(&adapter->reset_task)` before `rtnl_lock()`, and `rtnl_unlock()` before `unregister_netdev()`. `ena_timer_service()` must never acquire `rtnl_lock()` or wait on `reset_task`. [F17, F24, F162]
- When polling completion or AENQ descriptors, read the phase bit with `READ_ONCE()` followed by `dma_rmb()` before reading other fields. Issue `wmb()` before `__iowrite64_copy()` in `ena_com_write_bounce_buffer_to_dev()`, and `mb()` before `writel_relaxed()` to `ENA_REGS_AENQ_HEAD_DB_OFF` in `ena_com_aenq_intr_handler()`. [F33, F37]
- `ena_start_xmit()` must execute `smp_mb()` after `netif_tx_stop_queue()` before rechecking `ena_com_sq_have_enough_space()`, and `ena_clean_tx_irq()` must execute `smp_mb()` after `ena_com_comp_ack()`, then take `__netif_tx_lock()` and recheck `netif_tx_queue_stopped()`, `above_thresh`, and `ENA_FLAG_DEV_UP`. [F34]
- `ena_intr_msix_io()` must execute `WRITE_ONCE(ena_napi->interrupts_masked, true)` and `smp_wmb()` before `napi_schedule_irqoff()`, and `ena_io_poll()` must check `READ_ONCE(ena_napi->interrupts_masked)` after `napi_complete_done()`, issue `smp_rmb()`, and `WRITE_ONCE(ena_napi->interrupts_masked, false)` before `ena_unmask_interrupt()`. `ena_intr_msix_mgmnt()` must only call `ena_com_aenq_intr_handler()` when `ENA_FLAG_DEVICE_RUNNING` is set. [F35, F137]
- Serialize XDP TX (`ena_xdp_xmit_frame()`, `ena_ring_tx_doorbell()`) in `ena_xdp_execute()` and `ena_xdp_xmit()` under `xdp_tx_lock` (`spin_lock()` in BH-disabled context). In `ena_reset_device()`, write `adapter->reset_reason` before `smp_mb__before_atomic()` and `set_bit(ENA_FLAG_TRIGGER_RESET, &adapter->flags)`. Balance `get_cpu()` with `put_cpu()` on all paths in `ena_update_ring_numa_node()`. [F18, F36, F159]
- `ena_com_reg_bar_read32()` must hold `spin_lock_irqsave(&mmio_read->lock, flags)`. PHC timestamp reads nest `phc_info->lock` (outer) outside `ena_dev->phc.lock` (inner). Both `ena_com_reg_bar_read32()` and `ena_com_phc_get_timestamp()` must invalidate `resp->req_id` (`seq_num + 0xDEAD` or `phc->req_id + ENA_PHC_REQ_ID_OFFSET`) before issuing the request so polling `READ_ONCE(resp->req_id) == req_id` cannot match a stale wrapping `u16` ID. [F29, F30, F121]

## Object Lifetimes

- `ena_xdp_tx_map_frame()` and `ena_xdp_xmit_frame()` must never free `xdpf` on error (callers retain ownership), and `ena_xdp_xmit_frame()` must unmap DMA buffers and set `tx_info->xdpf = NULL` on failure. In `ena_start_xmit()`, if `ena_tx_map_skb()` or `ena_xmit_common()` fails, unmap DMA buffers via `ena_unmap_tx_buff()`, set `tx_info->skb = NULL`, and free `skb` in `ena_start_xmit()`. [F1, F2]
- On `ENA_XDP_FORWARDED` in `ena_clean_rx_irq()`, unmap with `ena_unmap_rx_buff_attrs(..., DMA_ATTR_SKIP_CPU_SYNC)` and set `rx_buffer_info[req_id].page = NULL`; on `ENA_XDP_DROP`, keep `page` mapped. In `ena_rx_skb()`, page reuse (`ena_try_rx_buf_page_reuse()`) requires `!is_xdp_loaded` and `page_ref_inc(rx_info->page)`; otherwise unmap with `DMA_ATTR_SKIP_CPU_SYNC` and clear `rx_info->page = NULL`. `adapter->xdp_bpf_prog` owns the sole XDP prog ref: update RX rings before `bpf_prog_put()`. [F3, F4, F16, F153, F178]
- In `ena_down()`, clear `ENA_FLAG_DEV_UP`, disable TX and NAPI, cancel `dim.work`, and synchronize/free IRQs and NAPI before freeing rings/buffers. `ena_napi_enable_in_range()` calls `napi_enable()` before `netif_queue_set_napi()`; `ena_napi_disable_in_range()` clears `netif_queue_set_napi(..., NULL)` before `napi_disable()`, only for `!ENA_IS_XDP_INDEX()`. `ena_free_io_irq()` must clear `irq_set_affinity_hint(..., NULL)` and `netif_napi_set_irq(..., -1)` before `free_irq()`, and precede `ena_del_napi_in_range()`. [F5, F7, F25, F94]
- Ranged TX setup helpers must unwind only `[first_index, i)` on error. RX queue teardown must call `cancel_work_sync(&adapter->ena_napi[i].dim.work)` and `ena_xdp_unregister_rxq_info()`. `ena_com_create_io_queue()` creates CQ before SQ; `ena_com_destroy_io_queue()` destroys SQ before CQ and `ena_com_io_queue_free()`. [F8, F9, F10]
- `ena_com_mmio_reg_read_request_init()` must precede any register reads or `ena_com_dev_reset()`; `ena_com_dev_reset()` must call `ena_com_mmio_reg_read_request_write_dev_addr()` after writing `ENA_REGS_DEV_CTL_DEV_RESET_MASK` and before `wait_for_reset_state()`; and `ena_com_mmio_reg_read_request_destroy()` must zero `ENA_REGS_MMIO_RESP_LO_OFF`/`HI_OFF` before freeing `read_resp`. [F13, F147]
- `ena_device_init()` must keep `ena_com_set_admin_polling_mode(ena_dev, true)` until `ena_request_mgmnt_irq()` succeeds. Before `ena_com_admin_destroy()`, reset the device, free the mgmnt IRQ, and call `ena_com_abort_admin_commands()` and `ena_com_wait_for_abort_completion()`. Explicitly free `devm_kzalloc()` buffers (`comp_ctx`, `bounce_buf_ctrl.base_buffer`, `host_rss_ind_tbl`) with `devm_kfree()` and set to `NULL` on teardown. [F136, F140, F142]
- `ena_destroy_device()` must call `ena_phc_destroy()` before clearing `ENA_FLAG_TRIGGER_RESET` (preserving the PTP clock index across resets), and `ena_suspend()` must clear `ENA_FLAG_TRIGGER_RESET` before `ena_destroy_device()`. In `ena_probe()`, set the `ENA_MAX_PHYS_ADDR_SIZE_BITS` DMA mask and call `ena_devlink_alloc()` before `ena_device_init()`, and call `ena_devlink_register()` last after `register_netdev()`. [F14, F15, F133]

## API Contracts

- All 32-bit `reg_bar` reads must use `ena_com_reg_bar_read32()` and check for `ENA_MMIO_READ_TIMEOUT`. `ena_com_get_dev_attr_feat()` must query `ENA_ADMIN_DEVICE_ATTRIBUTES` first to populate `supported_features`. Convert combined RX queue `q` to `ENA_IO_RXQ_IDX(q)` before `ena_com_indirect_table_fill_entry()` and back via `ENA_IO_RXQ_IDX_TO_COMBINED_IDX()`; call `ena_com_indirect_table_set()` only after RX SQs exist. `ena_com_get_hash_function()` uses `ffs() - 1`, and `ena_com_fill_hash_function()` sets `hash_init_val` even when `key` is `NULL`. [F50, F51, F52, F72, F143, F146]
- `intr_moder_tx_interval` and `intr_moder_rx_interval` are scaled by `intr_delay_resolution` (initialize to `1` and check for `0` before dividing). `ena_update_hints()` must preserve `ENA_HW_HINTS_NO_TIMEOUT` (`0xFFFF`) unconverted. In `struct ena_com_tx_meta`, `l4_hdr_len` is in 32-bit words (`tcp_hdr(skb)->doff`), while `l3_hdr_len`/`l3_hdr_offset` are in bytes. On RX, if `ena_rx_ctx->frag` is set, set `CHECKSUM_NONE` and `PKT_HASH_TYPE_NONE`. [F53, F54, F56, F115, F181]
- In `ena_clean_rx_irq()`, call `dma_sync_single_for_cpu()` on the first RX buffer before XDP or `ena_rx_skb()`, `dma_sync_single_for_device()` when recycling a copybreak buffer, and `xdp_do_flush()` on all exit paths (including `error:`) if `xdp_flags & ENA_XDP_REDIRECT`. `ena_xdp_exchange_program_rx_in_range(adapter, prog, first, count)` treats `count` as an exclusive end index (`i < count`). `ena_dump_stats_ex()` runs from softirq timer context and must use `GFP_ATOMIC` and `hw_stats_needed = false`. [F104, F152, F155, F160, F175]

## Error Handling

- Do not mix return conventions: `ena_com_get_dma_width()` returns positive width or negative errno (store in signed `int`, check `< 0`); `ena_calc_max_io_queue_num()` returns `u32` `0` on failure (never negative errno); `get_comp_ctxt()` returns `NULL` (check `admin_queue->comp_ctx` for `NULL`), whereas `ena_com_submit_admin_cmd()` and `ena_alloc_map_page()` return `ERR_PTR` (check `IS_ERR()`); and `ena_phc_register()` must reset `phc_info->clock = NULL` if `IS_ERR(phc_info->clock)`. [F40, F41, F42, F43, F44]
- `ena_com_tx_comp_req_id_get()` returns `-EAGAIN` when empty and `-EINVAL` on bad `req_id`, whereas `ena_com_rx_pkt()` returns `0` with `descs = 0` when empty and negative errnos only on fatal errors. An out-of-bounds `req_id` or `NULL` buffer slot (`skb`, `xdpf`, or `page`) on completion must increment `bad_req_id` and call `ena_reset_device()` / `handle_invalid_req_id()`. [F45, F69]
- `ena_xmit_common()` treats `-ENOMEM` from `ena_com_prepare_tx()` as a non-fatal full queue and resets the device on any other error. `ena_xdp_execute()` must return `enum ENA_XDP_ACTIONS` bitmask flags (`ENA_XDP_DROP` on frame conversion or redirect failure), never raw `enum xdp_action`. RSS helpers must return `0` for `ena_get_rxfh_key_size()` when `rss->hash_key` is `NULL` and ignore `-EOPNOTSUPP` from hash function/ctrl queries. [F46, F47, F145]

## Known Pitfalls

- In `ena_rx_skb()`, sample `rx_info->page_offset` (and `dma_unmap_addr(&rx_info->ena_buf, paddr)`) into local variables before `ena_try_rx_buf_page_reuse()`, which advances them in place. In `ena_tx_map_skb()`, when LLQ copies `delta` bytes from paged frags, skip fragments where `delta >= frag_len` (subtracting `frag_len` from `delta`) before mapping `frag_len - delta`. [F67, F87]
- Avoid overflow and size mismatches: cast `u16` `buffer_size` to `size_t` before `* buffers_num`; use `1ULL << log_size` for RSS table sizes; cast `u32` high words to `u64` before `<< 32`; clamp `exp` to `ENA_MAX_BACKOFF_DELAY_EXP` before `1U << exp`; copy `host_rss_ind_tbl` (`u16`) to `ind_tbl` (`u32`) element-by-element (not `memcpy`); multiply `key_parts` by `sizeof(u32)` for `memcpy`; and advance `u64 **data` by `supported_metrics_count` while passing `supported_metrics_count * sizeof(u64)` to `ena_com_get_customer_metrics()`. [F108, F109, F110, F114, F125, F129, F130]
- In `check_for_missing_completions()`, cap the scan loop at `min_t(u32, io_queue_count, ENA_MONITORED_TX_QUEUES)` and advance `qid = (qid + 1) % io_queue_count` before inspecting each queue. Pass unrounded jiffies deadlines to `time_is_before_jiffies()`, using `round_jiffies()` only when scheduling `adapter->timer_service`. [F84, F120]
