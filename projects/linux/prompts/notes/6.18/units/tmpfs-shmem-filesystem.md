# TMPFS (SHMEM FILESYSTEM)

Implements the swap-backed virtual memory filesystem (`tmpfs`/`shmem`), in-memory user/group quota tracking, and `memfd_create` with file sealing. It serves both as a user-mountable filesystem supporting THP/mTHP, xattrs, ACLs, quotas, and casefolding, and as the internal backing store (`shm_mnt`) for shared anonymous `mmap`, POSIX/SysV shared memory, userfaultfd atomic PTE installation, and DRM/GEM buffer objects.

## Architecture & Data Flow

- `__shmem_get_inode()` zeroes `struct shmem_inode_info` via `memset(info, 0, (char *)inode - (char *)info)`, so `vfs_inode` must remain the final member and any new shmem-specific fields must be placed before `vfs_inode`. [F49]
- `shmem_recalc_inode()` reconciles `info->alloced` against `info->swapped + inode->i_mapping->nrpages` after `mapping->nrpages` is updated, except in `shmem_writeout()` where `swapped > 0` (`nr_pages`) is passed before `shmem_delete_from_page_cache()` lowers `nrpages`. When `shmem_set_folio_swapin_error()` installs a poisoned swap entry, it must call `shmem_recalc_inode(inode, -nr_pages, -nr_pages)` and `swap_free_nr()` so `i_blocks` reaches zero on eviction. [F17, F58]
- Whenever a folio is added, removed, or replaced in the shmem page or swap cache (`shmem_add_to_page_cache()`, `shmem_delete_from_page_cache()`, `shmem_replace_folio()`), `shmem_update_stats()` must update `NR_FILE_PAGES`, `NR_SHMEM`, and (when `folio_test_pmd_mappable(folio)`) `NR_SHMEM_THPS` in lockstep. When replacing swap entries (`expected != NULL`) of `nr` pages in `shmem_add_to_page_cache()`, `xas_for_each_conflict()` must verify every slot matches contiguous swap values (`iter.val - nr == swap.val`) or fail with `-EEXIST`. [F60, F158]
- In `shmem_swapin_folio()`, if the XArray swap entry has a larger order than `folio_order(folio)`, `shmem_split_large_entry()` must split it before adding the folio, and if `shmem_replace_folio(&folio, ...)` runs, the local `folio` pointer must be updated. In `shmem_swap_alloc_folio()`, when `order > 0` and `non_swapcache_batch(entry, nr_pages) != nr_pages`, it must fall back to order 0 before allocation, advancing `entry.val` by `index - round_down(index, nr_pages)` and resetting `order = 0` and `nr_pages = 1`. [F68, F105]
- In `shmem_get_folio_gfp()`, `SGP_FALLOC` must zero and mark uptodate an already-cached `!uptodate` folio, but for a newly allocated folio it must convert `sgp` to `SGP_WRITE` before `clear:` so the new folio stays `!uptodate` and will be freed by `shmem_undo_range(..., true)` if `shmem_fallocate()` fails. In `shmem_undo_range()`, when `unfalloc` is true, it must skip swap entries and uptodate folios and jump directly to `whole_folios` without calling `truncate_inode_partial_folio()`. [F53, F107]
- During `FALLOC_FL_PUNCH_HOLE`, `shmem_fallocate()` publishes a stack `struct shmem_falloc` in `inode->i_private` with `nr_falloced` and `nr_unswapped` uninitialized, so readers under `inode->i_lock` must check `!shmem_falloc->waitq` in `shmem_writeout()` and `shmem_falloc->waitq` in `shmem_falloc_wait()`. When `shmem_writeout()` declines to swap out an `!uptodate` folio overlapping an active fallocate range, it must increment `shmem_falloc->nr_unswapped` by `folio_nr_pages(folio)` (not 1) under `inode->i_lock`. [F47, F64]
- When splitting or swapping out a large folio at EOF in `shmem_unused_huge_shrink()` or `shmem_writeout()`, the effective end index must be computed via `shmem_fallocend(inode, DIV_ROUND_UP(i_size, PAGE_SIZE))` so `FALLOC_FL_KEEP_SIZE` reservations beyond `i_size` are preserved. In `shmem_evict_inode()`, `mapping_set_exiting(inode->i_mapping)` must be called before `shmem_truncate_range(inode, 0, (loff_t)-1)`. [F67, F161]
- In `shmem_undo_range()` (`whole_folios`), `index` must be rewound to `indices[i]` when `shmem_free_swap()` returns 0 or `folio_mapping(folio) != mapping`, and reset to `start` when `truncate_inode_partial_folio()` splits a large folio or when full truncation (`end == -1`) finishes a non-empty pass. In `shmem_find_swap_entries()`, `indices[]` must be indexed by `folio_batch_count(fbatch)` before `folio_batch_add(fbatch, folio)`. [F103, F108]
- `memfd_tag_pins()` and `memfd_wait_for_pins()` reuse `PAGECACHE_TAG_TOWRITE` (`MEMFD_TAG_PINNED`) on `mapping->i_pages`, so tmpfs/hugetlbfs must never use `PAGECACHE_TAG_TOWRITE` for writeback. `memfd_wait_for_pins()` must call `xas_set(&xas, 0)` before each scan and, on `scan == LAST_SCAN` (even after a fatal signal in `schedule_timeout_killable()`), clear `MEMFD_TAG_PINNED` from every marked entry before returning `-EBUSY`. [F109, F174]

## Synchronization

- `shmem_unuse()` must increment `info->stop_eviction` under `shmem_swaplist_lock` before dropping the lock for `shmem_unuse_inode()`; after re-acquiring `shmem_swaplist_lock`, it must jump to `start_over` if `list_empty(&info->swaplist)` is true and otherwise refresh `next` via `list_next_entry(info, swaplist)`. `shmem_evict_inode()` must wait until `atomic_read(&info->stop_eviction)` is zero and recheck it under `shmem_swaplist_lock` before unlinking `info->swaplist` (never replace `stop_eviction` with `igrab()`, which does not block unmount eviction). [F21, F62]
- `shmem_charge()` must increment `mapping->nrpages` under `xa_lock_irq(&mapping->i_pages)` before calling `shmem_recalc_inode(inode, pages, 0)`. In `shmem_recalc_inode()` and `shmem_alloc_and_add_folio()`, `info->alloced - info->swapped - READ_ONCE(mapping->nrpages)` must be stored in a signed `long freed`, and `info->lock` must be released before calling `shmem_inode_unacct_blocks()` (only when `freed > 0`) because quota operations may sleep. [F29, F122]
- `shmem_swapin_folio()` must pin the swap device with `get_swap_device(index_entry)` before `shmem_confirm_swap()`, and after `folio_lock(folio)` it must revalidate `(!skip_swapcache && !folio_test_swapcache(folio)) || shmem_confirm_swap(mapping, index, swap) < 0 || folio->swap.val != swap.val` before adding the folio to page cache. [F30]
- In `mm/shmem_quota.c` (`shmem_get_next_id()`, `shmem_acquire_dquot()`, `shmem_release_dquot()`), `((struct rb_root *)info->dqi_priv)->rb_node` must never be read or have its address taken before acquiring `dqopt->dqio_sem`. Lock nesting order is `mutex_lock(&dquot->dq_lock)` -> `down_write(&dqopt->dqio_sem)` -> `spin_lock(&dquot->dq_dqb_lock)`, and allocations in quota callbacks (`shmem_acquire_dquot()`, `shmem_read_file_info()`) must use `GFP_NOFS`. [F27, F147]
- In `shmem_acquire_dquot()`, `dquot->dq_dqb` limits and `DQ_FAKE_B` must be initialized under `dquot->dq_dqb_lock` and ordered with `smp_mb__before_atomic()` before setting `DQ_ACTIVE_B` in `dquot->dq_flags`; `shmem_release_dquot()` must check `dquot_is_busy(dquot)` under `dquot->dq_lock` before modifying the quota rbtree or clearing `DQ_ACTIVE_B`. [F28]
- In `shmem_fallocate()` and `shmem_falloc_wait()`, `inode->i_lock` must be held when setting or clearing `inode->i_private` and across `prepare_to_wait()`, `wake_up_all()`, and `finish_wait()` on the stack-allocated `shmem_falloc_waitq` with `synchronous_wake_function`. [F25]
- In `shmem_mfill_atomic_pte()`, `copy_from_user()` must run under `pagefault_disable()` / `pagefault_enable()` (caller holds read `mmap_lock`), followed by `flush_dcache_folio(folio)` (or `clear_user_highpage(&folio->page, dst_addr)` for zero-filled folios) before `mfill_atomic_install_pte()`. If `copy_from_user()` fails, the allocated `folio` must be returned unlocked in `*foliop` with `-ENOENT`; if `shmem_inode_acct_blocks()` fails on retry, `*foliop` must be freed and nulled. [F33, F134]
- Because `shmem_file_read_iter()` and `shmem_file_splice_read()` run without `i_rwsem`, they must re-read `i_size_read(inode)` after `shmem_get_folio(..., SGP_READ)` returns an uptodate folio, and if `mapping_writably_mapped(mapping)` is true, call `flush_dcache_folio(folio)` (or `flush_dcache_page(page)` on the hwpoison fallback path) before reading or splicing. [F79, F135]
- In `memfd_add_seals()`, `inode_lock(inode)` must be held across seal checks and updates, and when adding `F_SEAL_WRITE`, `mapping_deny_writable(file->f_mapping)` must succeed before `memfd_wait_for_pins(file->f_mapping)` is called and be reverted via `mapping_allow_writable()` if `memfd_wait_for_pins()` fails. [F34]
- Updates and mark modifications on `mapping->i_pages` in `mm/shmem.c` and `mm/memfd.c` must use IRQ-safe XArray locks (`xa_lock_irq()`, `xas_lock_irq()`, `xa_cmpxchg_irq()`), and loops in `memfd_tag_pins()` and `memfd_wait_for_pins()` must call `xas_pause()` before `xas_unlock_irq()` and `cond_resched()`. In `shmem_partial_swap_usage()`, the `xas_for_each()` loop under `rcu_read_lock()` must break when `xas.xa_index == max` (`end - 1`) before `cond_resched_rcu()`, as single-page lookups can hold a PTE spinlock. [F136, F146]
- `shmem_unused_huge_shrink()` must acquire the folio lock with `folio_trylock(folio)` and move the inode back to `sbinfo->shrinklist` if contended, never blocking with `folio_lock(folio)`. In the second pass (`whole_folios`) of `shmem_undo_range()`, each locked folio must be checked with `folio_test_large(folio)` and handled via `truncate_inode_partial_folio(folio, lstart, lend)` rather than unconditional `truncate_inode_folio()`. [F24, F160]

## Object Lifetimes

- In `__shmem_file_setup()`, all fallible precondition checks must precede `shmem_acct_size()`, and `shmem_unacct_size()` must be called directly only if `shmem_get_inode()` fails, because once `inode->i_size` is set, `iput(inode)` unaccounts `inode->i_size` via `shmem_evict_inode()`. [F1]
- In `shmem_writeout()`, `shmem_recalc_inode(inode, 0, nr_pages)` and insertion onto `shmem_swaplist` must occur before `shmem_delete_from_page_cache()`; if `swap_writeout()` returns `AOP_WRITEPAGE_ACTIVATE`, `shmem_recalc_inode(inode, 0, -nr_pages)` and `swap_free_nr()` must run only if `shmem_add_to_page_cache()` succeeds. [F10]
- In `memfd_alloc_folio()`, a hugetlb allocation must reserve space via `hugetlb_reserve_pages()` and consume it with `alloc_hugetlb_folio_reserve()` (after right-shifting the `PAGE_SIZE` page index `idx >>= huge_page_order(h)`), unlocking the folio after `hugetlb_add_to_page_cache()` on success or calling `folio_put()` and `hugetlb_unreserve_pages()` on failure. Both hugetlb and shmem (`shmem_read_folio_gfp()`) paths must return the folio unlocked. [F3, F56]
- Because `shmem_destroy_inode()` only calls `mpol_free_shared_policy()` for `S_ISREG` inodes, `__shmem_get_inode()` must pass `NULL` to `mpol_shared_policy_init()` for `S_IFLNK` inodes and never populate `info->policy`'s rbtree on non-regular inodes. When transferring `ctx->mpol` to `sbinfo->mpol` in `shmem_fill_super()` or `shmem_reconfigure()` (or replacing `ctx->mpol` in `shmem_parse_one()`), `ctx->mpol` must be set to `NULL` and any replaced policy freed with `mpol_put()` so `shmem_free_fc()` does not double-free it. [F6, F13]
- In `shmem_unused_huge_shrink()`, every inode moved onto the local `list` must have `info->shrinklist` either deleted with `list_del_init()` or moved back to `sbinfo->shrinklist` under `sbinfo->shrinklist_lock` before calling `iput(inode)`, and `shmem_get_folio_gfp()` must test `list_empty_careful(&info->shrinklist)` under `sbinfo->shrinklist_lock`. [F23]
- In `shmem_file_splice_read()`, after splicing and calling `folio_put(folio)` in the loop, `folio` must be reset to `NULL` so the post-loop `if (folio) folio_put(folio)` does not double-put. [F15]

## API Contracts

- `shmem_get_folio_gfp()` and `shmem_get_folio()` return `0` without populating `*foliop` on `SGP_READ` holes or userfaultfd faults and can return early errors without touching `*foliop`, so callers must initialize `folio = NULL` and check `folio != NULL` even after a `0` return. Conversely, `shmem_swapin_folio()` requires `*foliop` on entry to hold a non-NULL XArray swap value entry (`xa_is_value(*foliop)`), immediately resets `*foliop = NULL`, and only populates `*foliop` with a locked folio on `0` return. [F40, F41]
- In `shmem_writeout()`, if `swap_writeout()` returns any value other than `AOP_WRITEPAGE_ACTIVATE`, `swap_writeout()` has already unlocked `folio` and `shmem_writeout()` must return that status directly without touching `folio`; on every path returning `AOP_WRITEPAGE_ACTIVATE`, `shmem_writeout()` must mark `folio` dirty and return with `folio` locked. [F43]
- `shmem_truncate_range()` and `shmem_undo_range()` take an inclusive byte end offset `lend` (where `lend == -1` means EOF), so callers on `[offset, offset + len)` must pass `offset + len - 1`—and `shmem_fallocate()` must guard its error rollback with `if (index > start)` so failure at `index == 0` never passes `((loff_t)index << PAGE_SHIFT) - 1 == -1` as `lend`. By contrast, `shmem_partial_swap_usage()` takes page indices `[start, end)` where `end` is exclusive (`max = end - 1`). [F55, F118]
- In `mm/memfd.c`, `memfd_file_seals_ptr()` must check `shmem_file(file)` before `SHMEM_I(file_inode(file))` and `is_file_hugepages(file)` before `HUGETLBFS_I(file_inode(file))`, and every caller of `memfd_file_seals_ptr()` (`memfd_add_seals()`, `memfd_get_seals()`, `memfd_check_seals_mmap()`, `alloc_file()`) must NULL-check the returned pointer before dereferencing it. [F45, F128]
- In `shmem_replace_folio()`, memcg association must be transferred via `mem_cgroup_replace_folio(old, new)` (under `swap_cluster_get_and_lock_irq`) rather than `mem_cgroup_migrate(old, new)`. [F159]

## Error Handling

- In `shmem_swapin_folio()`, `shmem_split_large_entry()` must be passed `index_entry` (not `swap`), error paths before `folio_lock(folio)` must jump to `failed_nolock` (resetting `folio = NULL` if `ERR_PTR` and passing `folio->swap` to `swapcache_clear()`), every exit after `get_swap_device()` and `shmem_confirm_swap()` succeed must call `put_swap_device(si)`, and on failure `shmem_confirm_swap(mapping, index, swap) < 0` must override `error = -EEXIST` before checking `if (error == -EIO)`. [F2, F52, F110]
- In `shmem_get_inode()`, if `dquot_initialize()` or `dquot_alloc_inode()` fails, the error path must call `dquot_drop(inode)` (when `dquot_initialize()` succeeded) and set `S_NOQUOTA` on `inode->i_flags` before `iput(inode)` so `shmem_evict_inode()` does not uncharge unallocated quota. [F5]
- `shmem_inode_acct_blocks()` must report `shmem_acct_blocks()` overcommit failure as `-ENOSPC` rather than propagating `-ENOMEM`, so page-fault allocation failure on a sparse tmpfs mapping delivers `SIGBUS` instead of triggering the OOM killer. [F44]

## Known Pitfalls

- In `shmem_get_orders_within_size()` and `shmem_suitable_orders()`, aligning `index` across an order bitmap must pass `1 << order` (not `order`) to `round_up()` / `round_down()` and store the result in `aligned_index` without clobbering `index`; `shmem_get_orders_within_size()` must compute `round_up(index + 1, 1 << order)` so an index at the start of an aligned block rounds to the exclusive end. When checking if a large folio extends past `i_size` (or `fallocend`), `DIV_ROUND_UP(i_size_read(inode), PAGE_SIZE)` must be compared directly against `folio_next_index(folio)` (not `folio_next_index(folio) - 1`). [F54, F83, F84]
- In `shmem_get_folio_gfp()` and `shmem_fallocate()`, `pgoff_t` variables (`index`, `start`) must be cast to `loff_t` before `<< PAGE_SHIFT` to avoid 32-bit overflow. In `shmem_fallocate()`, after `index = folio_next_index(folio)`, `if (!index) index--;` must clamp 32-bit `pgoff_t` wraparound before updating `nr_falloced` or `shmem_falloc.next`, and on the `FALLOC_FL_PUNCH_HOLE` path `unmap_start` and `unmap_end` must be cast to `u64` before `>> PAGE_SHIFT` or comparison (`(u64)unmap_end > (u64)unmap_start`). [F112, F113, F117]
