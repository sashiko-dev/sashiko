# SCSI SUBSYSTEM

This unit comprises the core SCSI midlayer host lifecycle management (`drivers/scsi/hosts.c`) and four low-level SCSI host adapter drivers: ATTO ExpressSAS R6xx SAS/SATA RAID (`esas2r`), NCR53C9x/FAS/ESP core (`esp_scsi`), Future Domain TMC-16x0/TMC-3260 ISA/PCI (`fdomain`), and Amiga Zorro GVP Series II WD33C93 (`gvp11`).

## Architecture & Data Flow

- `class_to_shost()` must only be used on `shost_class` devices (`shost_dev`); `scsi_bus_type` devices (`shost_gendev`, as in `scsi_host_dev_release()`) must use `dev_to_shost()`. `scsi_host_lookup()` and `__scsi_host_match()` must pass and dereference `hostnum` as `unsigned int` (matching `Scsi_Host::host_no`), not `unsigned short`. In `scsi_remove_host()`, `scsi_host_set_state()` for `SHOST_CANCEL` and `SHOST_DEL` must fall back to `SHOST_CANCEL_RECOVERY` and `SHOST_DEL_RECOVERY` when the host is in recovery. [F101, F115, F133]
- On reselection during selection (`ESP_INTR_RSEL | ESP_INTR_FDONE`) in `esp_finish_select()`, the driver must unmap DMA (or sense DMA), free the LUN tag, clear `ESP_TGT_NEGO_SYNC | ESP_TGT_NEGO_WIDE` and `cmd_bytes_ptr`/`cmd_bytes_left`, requeue `ent` on `esp->queued_cmds`, and clear `esp->active_cmd`. Because a requeued `ESP_CMD_FLAG_AUTOSENSE` command keeps its LUN tag and data DMA mapping, `find_and_prep_issuable_command()` and `esp_maybe_execute_command()` must check `ESP_CMD_FLAG_AUTOSENSE` and call `esp_autosense()` before `esp_alloc_lun_tag()` or `esp_map_dma()`. [F67, F106]
- In `find_and_prep_issuable_command()`, when `spi_populate_tag_msg(&ent->tag[0], cmd)` returns `0`, `ent->tag[0]` and `ent->tag[1]` must be zeroed before copying to `ent->orig_tag` (`esp_alloc_lun_tag()`/`esp_free_lun_tag()` test `ent->orig_tag[0]`). When `esp_advance_dma()` advances `p->cur_sg`, it must save the old SG pointer in `p->prv_sg` (and `esp_save_pointers()`/`esp_restore_pointers()` must preserve `saved_prv_sg`) for `IGNORE_WIDE_RESIDUE` rewind in `esp_msgin_process()`. [F50, F66]
- Writes to `ESP_CFG3`, `ESP_SOFF`, or `ESP_STP` must update `esp->prev_cfg3`, `esp->prev_soff`, or `esp->prev_stp` in lockstep. `esp_data_bytes_sent()` subtracts both `ecount` and `esp->send_cmd_residual` from `esp->data_dma_len`, so PIO `send_dma_cmd` callbacks like `esp_send_pio_cmd()` must store untransferred bytes in `esp->send_cmd_residual`. [F64, F65]
- In `esp_msgin_wdtr()`, `spi_period(tp->starget)` and `spi_offset(tp->starget)` must be reset to `0` before `esp_need_to_nego_sync(tp)`. In `esp_reset_cleanup()`, all `esp->active_cmds` must be released via `esp_reset_cleanup_one()` before calling `esp_clear_hold()`, and each target's `esp_period`, `esp_offset`, and wide/fast `esp_config3` bits must be cleared with `ESP_TGT_CHECK_NEGO` set. [F68, F69]
- In `fdomain_work()`, `fdomain_read_data()` and `fdomain_write_data()` must run before `fdomain_finish_cmd(fd)` even when `COMMAND_COMPLETE` sets `done` so residual FIFO data is drained, and `fdomain_write_data()` must use `FIFO_Size = 0x800` for `tmc18c30` (`0x2000` otherwise) and clamp `len` to `scsi_bufflen(cmd) - offset`. [F98, F110]
- `esas2r_probe()` must pass `sizeof(struct esas2r_adapter) + (num_requests + 1) * sizeof(struct esas2r_request)` to `scsi_host_alloc()` for the trailing request array at `(struct esas2r_request *)((u8 *)(a + 1))`. `clear_vda_request()` must preserve `rq->vrq->scsi.handle` across `memset(rq->vrq, 0, sizeof(*rq->vrq))` and separately zero `rq->data_buf` (`ESAS2R_DATA_BUF_LEN`). [F123, F125]
- Target DB mutators (`esas2r_targ_db_add_raid()`, `esas2r_targ_db_add_pthru()`, `esas2r_targ_db_remove()`) must update only `t->target_state` and leave `t->buffered_target_state` unchanged so `esas2r_targ_db_report_changes()` detects changes once `AF_DISC_PENDING` clears. Because `esas2r_targ_db_add_pthru()` reuses `a->targetdb` entries and updates `t->virt_targ_id`, virtual target IDs must be looked up via `esas2r_targ_db_find_by_virt_id()`, not `a->targetdb[virt_id]`. [F74, F86]
- In `esas2r_process_vda_ioctl()`, `vi->function < ARRAY_SIZE(esas2r_vdaioctl_versions)` must be checked before indexing, and in-place `esas2r_nuxi_mgt_data()` on `vi->cmd.mgt.data` must be paired with `esas2r_nuxi_mgt_data()` in `esas2r_complete_vda_ioctl()`. In `esas2r_read_mem_block()`, each chunk must map the `MW_DATA_WINDOW_SIZE`-aligned base via `esas2r_map_data_window()` (which flushes `MVR_PCI_WIN1_REMAP` via `esas2r_flush_register_dword()` and updates `a->window_base`) and clamp `len` to `MW_DATA_WINDOW_SIZE - offset`. [F73, F88, F93, F153]

## Synchronization

- In `scsi_add_host_with_dma()`, `scsi_mq_setup_tags()`, `kref_init(&shost->tagset_refcnt)`, and `init_completion(&shost->tagset_freed)` must precede `device_add(&shost->shost_gendev)` and `scsi_host_set_state(shost, SHOST_RUNNING)`. In `scsi_remove_host()`, `shost->scan_mutex` is acquired outside `shost->host_lock`; `host_lock` must be dropped before `scsi_autopm_get_host()`, `flush_workqueue(shost->tmf_work_q)`, or `scsi_forget_host()`; and `scan_mutex` must be dropped before waiting on `shost->tagset_freed`. [F23, F26]
- In `esp_scsi.c`, `esp->host->host_lock` protects `esp->queued_cmds`, `esp->active_cmds`, `esp->esp_cmd_pool`, `esp->active_cmd`, `esp->flags`, and ESP registers. Scatterlist PIO transfers in `esp_data_bytes_sent()` and `fdomain_read_data()`/`fdomain_write_data()` run under `host_lock` with IRQs disabled and must use `scsi_kmap_atomic_sg()`/`scsi_kunmap_atomic_sg()`. [F30, F162]
- In `fdomain_create()`, `fd->base`, `fd->chip`, and `INIT_WORK(&fd->work, fdomain_work)` must precede `request_irq()` and `scsi_add_host()`. In `gvp11_probe()`, `hdata->regs` and `wd33c93_init()` must precede `request_irq()` and setting `GVP11_DMAC_INT_ENABLE` in `regs->CNTR`, and `gvp11_remove()` must clear `hdata->regs->CNTR = 0`, `scsi_remove_host()`, and `free_irq()` before `scsi_host_put()`. [F32, F35]
- In `esas2r`, `a->queue_lock` must be held while searching/unlinking `a->defer_list` and `a->active_list` or formatting an abort request in `esas2r_eh_abort()` and `esas2r_check_active_queue()`, and released before `esas2r_start_request()`, `msleep()`, `esas2r_complete_request()`, or `esas2r_comp_list_drain()` (dequeue to a local `comp_list` and drain after unlocking). [F38, F164]
- `a->fw_event_lock` protects `a->fw_event_list`, `a->fw_events_off`, and `a->fw_event_q`. `esas2r_queue_fw_event()` runs in atomic context and must use `GFP_ATOMIC` and defer `scsi_add_device()`/`scsi_remove_device()` to `esas2r_firmware_event_work()`. `esas2r_targ_db_remove_all()` and `esas2r_targ_db_report_changes()` must hold `a->mem_lock` (`spin_lock_irqsave`) when updating `t->target_state` or `t->buffered_target_state`, and release it before `esas2r_target_state_changed()` (which takes `a->fw_event_lock`). [F40, F165, F166]
- `buffered_ioctl_semaphore` must be held in `handle_buffered_ioctl()` across reallocating `esas2r_buffered_ioctl`, waiting on `a->buffered_ioctl_waiter`, and copying results; `a->fm_api_mutex` and `a->fs_api_mutex` must be held in `do_fm_api()` and `esas2r_read_fs()` (`off == 0`) across the request, wait, and DMA buffer cleanup; and `spin_lock_irqsave(&event_buffer_lock, flags)` must protect `event_buffer` in `esas2r_log_master()`. [F42, F43, F168]

## Object Lifetimes

- `scsi_proc_host_rm(shost)` and `scsi_proc_hostdir_rm(shost->hostt)` must be called synchronously in `scsi_remove_host()`. In `scsi_host_dev_release()`, `scsi_proc_hostdir_rm(shost->hostt)` and `kfree(dev_name(&shost->shost_dev))` must be called iff `shost->shost_state == SHOST_CREATED`, while `put_device(parent)` must be called iff `shost->shost_state != SHOST_CREATED`. [F1, F25]
- In `scsi_remove_host()`, `kref_put(&shost->tagset_refcnt, scsi_mq_free_tags)` and `wait_for_completion(&shost->tagset_freed)` must finish before setting `SHOST_DEL` and unregistering `shost_dev`/`shost_gendev`. In `scsi_host_dev_release()`, `rcu_barrier()` must precede destroying workqueues, stopping `shost->ehandler`, or freeing `shost`. `scsi_add_host_with_dma()` must balance `pm_runtime_get_noresume()` with `scsi_autopm_put_host()` on success or `pm_runtime_put_noidle()` after `pm_runtime_disable()` on failure. [F5, F141, F142]
- Every path calling `esp_put_ent(esp, ent)` must first `list_del(&ent->list)` from `esp->queued_cmds` or `esp->active_cmds`. When `ESP_FLAG_NO_DMA_MAP` is set, `esp_unmap_dma()` and `esp_unmap_sense()` must skip DMA unmapping, and `esp_unmap_sense()` must always clear `ent->sense_ptr = NULL`. `esp_target_destroy()` must clear `tp->starget = NULL` and `esp_sdev_destroy()` must `kfree(dev->hostdata)` and set `dev->hostdata = NULL`. [F6, F8, F10, F52]
- In `esp_eh_abort_handler()` and `esp_eh_bus_reset_handler()`, stack completion pointers `ent->eh_done` and `esp->eh_reset` must be cleared to `NULL` under `esp->host->host_lock` even on timeout. In `esas2r_eh_abort()` and `esas2r_dev_targ_reset()`, `rq->task_management_status_ptr` points to stack variable `task_management_status`, so they must not return while `task_management_status == RS_PENDING`. [F9, F135]
- `fdomain_destroy()` must call `cancel_work_sync(&fd->work)` before `scsi_remove_host()`, `free_irq()`, and `scsi_host_put()`, and before callers release I/O regions; `fdomain_finish_cmd()` must clear `fd->cur_cmd = NULL` under `sh->host_lock` right after `scsi_done()`. In `gvp11.c`, `dma_stop()` must unmap only when `wh->dma_buffer_pool == BUF_SCSI_ALLOCED`, free `wh->dma_bounce_buffer` via `kfree()` (`BUF_SCSI_ALLOCED`) or `amiga_chip_free()` (`BUF_CHIP_ALLOCED`), clear `wh->dma_bounce_buffer = NULL`, and copy only `scsi_pointer->this_residual` bytes. [F11, F12, F14, F138]
- `esas2r_free_request(a, rq)` must call `esas2r_rq_destroy_request(rq, a)` (splicing `rq->sg_table_head` to `a->free_sg_list_head` under `a->sg_list_lock` and clearing `a->req_table[LOWORD(rq->vrq->scsi.handle)] = NULL`) before returning `rq` to `a->avail_request`. `esas2r_initmem_free()` must pass unaligned `mem_desc->esas2r_data`, `esas2r_param`, and `phys_addr - ((u8 *)virt_addr - (u8 *)esas2r_data)` to `dma_free_coherent()`, and clear `virt_addr = NULL`. `esas2r_add_device()`/`esas2r_remove_device()` must balance `scsi_device_lookup()` with `scsi_device_put()`. [F15, F17, F20]

## API Contracts

- `scsi_host_lookup()` takes a `shost_gendev` ref via `scsi_host_get()`, drops `cdev` via `put_device(cdev)`, and returns the `scsi_host_get()` ref for `scsi_host_put()`. `scsi_add_host_with_dma()` requires `shost->can_queue > 0` and clamps `shost->cmd_per_lun` (`short`) to `shost->can_queue` (`int`) via `min_t(int, ...)`. A `scsi_host_template` with non-zero `virt_boundary_mask` must have `max_segment_size` of `0` or `UINT_MAX`. [F4, F47, F100, F170]
- In `esp_driver_ops.send_dma_cmd` and `esp_send_pio_cmd()`, `write` is `1` for SCSI-to-host (`ESP_EVENT_DATA_IN`) and `0` for host-to-SCSI (`ESP_EVENT_DATA_OUT`, command, `ESP_EVENT_MSGOUT`); using `esp_send_pio_cmd()` requires `ESP_FLAG_NO_DMA_MAP` and `esp->fifo_reg`. In `esp_process_event()`, returning `0` immediately re-invokes `esp_process_event(esp)` in `__esp_interrupt()`, so any path returning `0` must advance `esp->event` toward a state that returns `1`. [F51, F103, F176]
- Callers of `scsi_kmap_atomic_sg()` must add the updated `offset` out-parameter to the returned page base pointer before accessing data, and pass the unadjusted base pointer to `scsi_kunmap_atomic_sg()`. In `gvp11.c`, `wh->dma_xfer_mask` and `gvp11_zorro_tbl[].driver_data` represent *disallowed* address bits and must be inverted via `TO_DMA_MASK(m)` for `dma_set_mask_and_coherent()`. [F129, F177]
- When `esas2r_send_task_mgmt()` returns `true` (`AF_FLASHING`), `esas2r_dev_targ_reset()` must free `rq`; when `false`, `complete_task_management_request()` frees `rq`. `esas2r_targ_db_add_raid()` must reject zero `dc->interleave` or `dc->block_size` before dividing. `do_fm_api()` requires `fi` to be `&a->firmware.header` or `a->firmware.data`. `csmi_ioctl_tunnel()` and `ATTO_FUNC_SCSI_PASS_THRU` must hook `rq->comp_cb` (chaining via `rq->aux_req_cb`), not `rq->interrupt_cb`. [F18, F61, F128, F131]

## Error Handling

- In `scsi_host_alloc()`, if `kthread_run()` fails for `shost->ehandler`, it must be reset to `NULL` before `put_device(&shost->shost_gendev)`. In `scsi_add_host_with_dma()`, any failure after `device_add(&shost->shost_gendev)` and `get_device(&shost->shost_gendev)` must call `put_device(&shost->shost_dev)` and `device_del(&shost->shost_gendev)`. [F44, F140]
- `esp_data_bytes_sent()` returns signed `int` (`-1` on `ESP100` sync FIFO error), which `esp_process_event()` must check `< 0` before calling `esp_advance_dma()`. `esp_check_spur_intr()` returns `-1` (spurious/error), `0` (normal), or `1` (reset), so `__esp_interrupt()` must check `finish_reset < 0` before `if (finish_reset)`. `fdomain_create()` returns `NULL` on failure, so `fdomain_pci_probe()` must preset `err = -ENODEV`. In `esas2r_queuecommand()`, SGL build failure after `scsi_dma_map(cmd)` must call both `scsi_dma_unmap(cmd)` and `esas2r_free_request(a, rq)`. [F19, F48, F49, F53]

## External Contracts

- In `esas2r_ioctl_handler()`, `EXPRESS_IOCTL_GET_CHANNELS` must precede validating `ioctl->header.channel` (`0xFF` or `< MAX_ADAPTERS` with non-NULL `esas2r_adapters[]`). When `off == 0`, `esas2r_write_fw()` must check `count` against `4` and the versioned header size and cap `header->length <= 1024 * 1024`, and `esas2r_write_fs()` must override `length` to `offsetof(struct esas2r_ioctl_fs, data)` for `ESAS2R_FS_CMD_BEGINW`. In `ATTO_TRC_TF_UPLOAD`, `len` must be clamped to `total_len` and `offset >= total_len` checked before `offset + len > total_len`. [F81, F82, F83, F85]
- In `csmi_ioctl_callback()` and `hba_ioctl_callback()`, 8-byte LUN arrays (`sas_lun`, `spt->lun`) store the single-level LUN at `[1]` and must be validated with `check_lun()`. In `ATTO_FUNC_GET_DEV_ADDR` and `ATTO_FUNC_GET_DEV_INFO`, `t = a->targetdb + (u16)target_id` must be resolved after checking `target_id < ESAS2R_MAX_TARGETS` and before `esas2r_targ_db_find_next_present()` overwrites `target_id`. [F84, F113]

## Known Pitfalls

- In `__esp_interrupt()`, `ESP_STATUS` and `ESP_SSTEP` must be read before `ESP_INTRPT` (reading `ESP_INTRPT` clears them). On `FASHME`, `ESP_FDATA` FIFO accesses are 16-bit paired (`hme_read_fifo()` writes `0` before reading an odd `ESP_STAT2_F1BYTE` byte; `ESP_EVENT_MSGOUT` follows each message byte with `0`). In `esp_set_clock_params()`, `ESP_NEG_DEFP()` and `ESP_TICK()` must use unencoded `ccf` (`2..8`), not `esp->cfact` (`0` when `ccf == 8`). [F70, F119, F149]
- In `esp_process_event()`, `write = 0` must be reset at `again:` before `switch (esp->event)`, and in `ESP_EVENT_MSGIN`, `if (esp->event == ESP_EVENT_RESET) return 0;` must be checked immediately after `esp_msgin_process(esp)`. `esp_cmd_priv::cur_residue` and `tot_residue` must remain signed `int`. In `esp_maybe_execute_command()`, `esp->msg_out` must be shifted backward using signed `int i` from `esp->msg_out_len - 1` down to `0` (`msg_out_len <= ESP_MAX_MSG_SZ - 2`). [F94, F95, F104, F105, F130]
- `fdomain_identify()` must write `0` back to `port + REG_CFG2` after probing `CFG2_32BIT`, and `fdomain_read_data()`/`fdomain_write_data()` must transfer an odd byte (`len & 1`) via `inb`/`outb` on `REG_FIFO` before `insw`/`outsw`. `check_wd33c93()` (`gvp11.c`) must save and restore `*sasr_3393` when probing fails. In `esas2r_process_vda_ioctl()` (`VDA_FUNC_MGT`), `cmdcurr_offset` must be saved before building `payld_sge`, which must precede `mgt.sge`. [F72, F78, F80, F151]
