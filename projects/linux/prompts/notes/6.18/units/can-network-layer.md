# CAN NETWORK LAYER

Implements the `PF_CAN` socket protocol family core (`af_can.c`, `proc.c`), CAN frame receive filter dispatching, transmission (`can_send`), and per-netns procfs statistics, along with built-in CAN protocols: Raw sockets (`raw.c`), Broadcast Manager (`bcm.c`), ISO 15765-2 ISO-TP (`isotp.c`), RTNetlink CAN frame gateway (`gw.c`), and the `em_canid` traffic control ematch classifier (`net/sched/em_canid.c`).

## Architecture & Data Flow
- Every locally allocated TX `sk_buff` passed to `can_send()` must call `can_skb_reserve()` (where trailing `struct can_frame cf[]` in `struct can_skb_priv` keeps `skb->data` 8-byte aligned for `get_u64()` in `bcm.c` and `*(u64 *)cf->data` in `gw.c`) and set `can_skb_prv(skb)->skbcnt = 0` and `ifindex`. `can_receive()` assigns `skbcnt` only when 0 (looping past 0 on `skbcounter` wrap), and `can_send()` sets `skb->ip_summed = CHECKSUM_UNNECESSARY`, which `can_can_gw_rcv()` requires to use `skb->csum_start` (`cgw_hops(skb)`) as the hop counter. [F41, F82, F114, F151]
- `struct can_frame`, `struct canfd_frame`, and `struct canxl_frame` share `skb->data` with overlapping offsets, and every CAN XL frame must have `CANXL_XLF` (`0x80`) set in `canxl_frame::flags` (aliasing `can_frame::len` and `canfd_frame::len`). Code must verify `skb->len` against header/MTU bounds before reading `len` or `flags` and discriminate variants via `can_is_can_skb()`, `can_is_canfd_skb()`, `can_is_canxl_skb()`, or `can_skb_get_len_val()`. [F44, F74, F78]
- `can_rx_register()` and `can_rx_unregister()` must both pass `&can_id` and `&mask` to `can_rcv_list_find()` to normalize them in-place and update `dev_rcv_lists->entries` and `rcv_lists_stats->rcv_entries` under `net->can.rcvlists_lock`. `can_rcv_list_find()` must check `CAN_ERR_FLAG` in `*mask` first (clearing `*mask &= CAN_ERR_MASK` for `rx[RX_ERR]`), extract `CAN_INV_FILTER` from `*can_id` before `*can_id &= *mask`, and only route to `rx_sff` or `rx_eff` when `*mask` includes `CAN_EFF_FLAG | CAN_RTR_FLAG` and `!(*can_id & CAN_RTR_FLAG)`. [F52, F73, F91]
- In `can_rcv_filter()`, error frames (`can_id & CAN_ERR_FLAG`) must only traverse `dev_rcv_lists->rx[RX_ERR]` and return immediately. SFF CAN IDs and masks must be masked with `CAN_SFF_MASK` (`0x7FFU`) before indexing `dev_rcv_lists->rx_sff` or the `cm->match_sff` bitmap in `struct canid_match`. [F80, F93]
- Because `raw_notifier_list`, `bcm_notifier_list`, and `isotp_notifier_list` are global across namespaces while `ifindex` is per-netns, `raw_notify()`, `bcm_notify()`, and `isotp_notify()` must check `net_eq(dev_net(dev), sock_net(sk))` before matching `dev` or `ifindex`. When `bcm_notify()` resets `bo->bound = 0` on `NETDEV_UNREGISTER`, it must also remove `bo->procname` from `sock_net(sk)->can.bcmproc_dir` and set `bo->bcm_proc_read = NULL`. [F62, F159]
- In `raw_setsockopt()`, `ro->fd_frames` must stay enabled whenever `ro->xl_frames` is enabled, `raw_check_txframe()` must accept CAN FD frames on both `CANFD_MTU` and `can_is_canxl_dev_mtu(mtu)` devices, and updating `ro->raw_vcid_opts` under `CAN_RAW_XL_VCID_OPTS` must recompute `ro->tx_vcid_shifted`, `ro->rx_vcid_shifted`, and `ro->rx_vcid_mask_shifted`. In `raw_rcv()`, per-CPU `ro->uniq` deduplication must match both `skb == oskb` and `skbcnt == can_skb_prv(oskb)->skbcnt`, and `ro->join_filters` suppresses delivery until `join_rx_count == ro->count`. [F56, F57, F99]
- In `net/can/bcm.c`, `op->frames` and `op->last_frames` point to inline `op->sframe` and `op->last_sframe` only when created with `nframes <= 1`. Updates in `bcm_tx_setup()` or `bcm_rx_setup()` must reject `msg_head->nframes > op->nframes` with `-E2BIG` (and reset `op->currframe = 0` under `op->bcm_tx_lock` if `op->nframes` changes or `TX_RESET_MULTI_IDX` is set), so `bcm_free_op_rcu()` must test `!= &op->sframe` and `!= &op->last_sframe` rather than `op->nframes > 1`. [F58, F84]
- In `net/can/bcm.c`, when `op->nframes > 1` in an RX `bcm_op`, `op->frames[0]` holds the 64-bit MUX mask while filter frames and `op->last_frames` state use indices `1 .. op->nframes - 1` (up to `MAX_NFRAMES + 1` in `bcm_rx_setup()`). Updating an RX `bcm_op` with `msg_head->nframes > 0` or firing `bcm_rx_timeout_handler()` with `RX_ANNOUNCE_RESUME` must `memset()` `op->last_frames` to zero, and `bcm_send_to_user()` must mask `firstframe->flags &= BCM_CAN_FLAGS_MASK` when `head->nframes == 1` so upper-nibble internal flags do not leak. [F60, F61, F83]
- In `net/can/isotp.c`, `so->rx.buf` and `so->tx.buf` start at inline `sbuf` (`DEFAULT_MAX_PDU_SIZE`), may be replaced with a heap buffer only while updating `buflen = max_pdu_size` in lockstep, and must be checked against `!= sbuf` before `kfree()` in `isotp_release()`. `struct tpcon` fields `len` and `idx` must remain `unsigned int` so 32-bit `FF_DL` lengths cannot wrap negative, `isotp_rcv_ff()` must verify `so->rx.len <= so->rx.buflen` and `so->rx.len + ae + off + ff_pci_sz >= so->rx.ll_dl`, and `isotp_rcv_cf()` must break its copy loop when `so->rx.idx >= so->rx.len`. [F64, F88, F108]
- In `isotp.c`, `isotp_bind()`, `isotp_release()`, and `isotp_notify()` must register/unregister `isotp_rcv_echo` on `so->txid` when `so->bound`, and `isotp_rcv` on `so->rxid` only if `isotp_register_rxid(so)` holds, while rejecting `isotp_bind()` or `isotp_setsockopt_locked()` when `so->bound`. Echo-tracked TX paths must set `so->tx.state = ISOTP_SENDING`, `so->cfecho = *(u32 *)cf->data`, and arm `so->txtimer`; transitions to `ISOTP_IDLE` must wake `so->wait` (and `isotp_poll()` masks `EPOLLOUT | EPOLLWRNORM` when `!= ISOTP_IDLE`). [F65, F66, F67]
- In `gw.c`, `struct cf_mod` and `struct can_can_gw` must be zeroed with `memset()` and populated via `canframecpy()`/`canfdframecpy()` for `memcmp()`, and `cgw_parse_attr()` must pack callbacks contiguously from `mod->modfunc[0]` and only parse `CGW_CS_CRC8`, `CGW_CS_XOR`, and `CGW_MOD_UID` when `modidx > 0`. Classical CAN DLC modifiers must use `mod_retrieve_ccdlc()`/`mod_store_ccdlc()` for `len8_dlc`, `can_can_gw_rcv()` must check `cf->len <= max_len` before `mod->csumfunc`, and relative checksums must abort if `calc_idx(idx, cf->len) < 0`. [F49, F71, F85, F105]

## Synchronization
- All `can_rx_register()` callbacks (`raw_rcv`, `bcm_rx_handler`, `isotp_rcv`, `isotp_rcv_echo`, `can_can_gw_rcv`) run in softirq context under `rcu_read_lock()`; they must not sleep and must use `GFP_ATOMIC` (or `gfp_any()`). `raw_rcv()` accesses per-CPU `ro->uniq` via `this_cpu_ptr()`/`this_cpu_inc()` without preemption disabling, relying on `NET_RX_SOFTIRQ` context with BH disabled. [F129, F134]
- In `can_rx_register()`, `rcv_cache` must be allocated with `GFP_KERNEL` before acquiring `spin_lock_bh(&net->can.rcvlists_lock)`, and all `struct receiver` fields must be initialized before `hlist_add_head_rcu(&rcv->list, rcv_list)` under `rcvlists_lock`. In `af_can.c`, `can_get_proto()` must call `try_module_get()` inside `rcu_read_lock()`, and `can_proto_unregister()` must clear `proto_tab[proto]` under `proto_tab_lock` and call `synchronize_rcu()` before `proto_unregister()`. [F21, F133, F145]
- Functions in `raw.c` (`raw_release()`, `raw_bind()`, `raw_setsockopt()`) taking both `rtnl_mutex` and the socket lock must acquire `rtnl_lock()` before `lock_sock(sk)`. In `raw_setsockopt()`, under both locks, if `ro->bound` and `ro->dev` are set, `ro->dev->reg_state != NETREG_REGISTERED` must be rejected with `-ENODEV` before registering filters. [F27, F135]
- In `raw.c`, `bcm.c`, and `isotp.c`, the notifier spinlock (`*_notifier_lock`) must be dropped with `*_busy_notifier` set before calling `*_notify()`, and `*_release()` must wait while `*_busy_notifier` points to the closing socket before calling `list_del()`. [F28]
- In `net/can/bcm.c`, updates to `op->currframe`, `op->count`, and `op->nframes` shared between `bcm_tx_setup()` and `bcm_can_tx()` must be serialized with `spin_lock_bh(&op->bcm_tx_lock)`. Removals of `struct bcm_op` on a live socket must unlink `op->list` with `list_del_rcu()`, and lockless readers like `bcm_proc_show()` must use `list_for_each_entry_rcu()` under `rcu_read_lock()`. [F132, F140]
- In `isotp_sendmsg()`, exclusive ownership of the TX buffer and state machine must be claimed via `cmpxchg(&so->tx.state, ISOTP_IDLE, ISOTP_SENDING) == ISOTP_IDLE` in a loop that rechecks `MSG_DONTWAIT` and `so->tx.state == ISOTP_SHUTDOWN` before waiting on `so->wait`. In `isotp_rcv()`, `spin_lock(&so->rx_lock)` must be held across the `CAN_ISOTP_HALF_DUPLEX` check and all frame-type handlers. [F32, F35]

## Object Lifetimes
- `can_skb_set_owner()` must acquire the socket reference via `refcount_inc_not_zero(&sk->sk_refcnt)` before setting `skb->destructor = sock_efree` and `skb->sk = sk`, because `sk->sk_refcnt` may already be 0 if userspace closed the socket while TX skbs are in flight. [F3]
- In `can_create()`, if `sk->sk_prot->init(sk)` fails after `sock_init_data(sock, sk)`, it must call `sock_orphan(sk)`, `sock_put(sk)`, and set `sock->sk = NULL` without calling `sock_prot_inuse_add()`, while always calling `can_put_proto(cp)`. [F6]
- When `can_rx_unregister()` unlinks a `struct receiver` with a non-NULL `rcv->sk`, it must call `sock_hold(rcv->sk)` before `call_rcu(&rcv->rcu, can_rx_delete_receiver)` and drop it via `sock_put(sk)` inside `can_rx_delete_receiver()`. [F22]
- In `can_exit()` and `cgw_module_exit()`, `rcu_barrier()` must be called after all handlers, sockets, notifiers, and pernet subsystems are unregistered and before `kmem_cache_destroy()` destroys `rcv_cache` or `cgw_cache`. In `can_pernet_exit()`, `can_remove_proc(net)` and `timer_delete_sync(&net->can.stattimer)` must run before freeing `rx_alldev_list`, `pkg_stats`, and `rcv_lists_stats`. [F24, F25]
- Storing `ro->dev` in `raw_bind()` requires a tracked reference via `netdev_hold(ro->dev, &ro->dev_tracker, GFP_KERNEL)` that must be released via `netdev_put()` when unbinding or in `raw_bind()`, `raw_notify()`, and `raw_release()`. [F9]
- When `bcm_rx_unreg()` unregisters a device-bound `bcm_op` filter, it must clear `op->rx_reg_dev = NULL`, and `bcm_delete_rx_op()` and `bcm_release()` must check `op->rx_reg_dev != NULL` before calling `bcm_rx_unreg()`. In `bcm_release()`, `remove_proc_entry()` must run before freeing any ops with `bcm_remove_op()`, and all `bo->rx_ops` filters must be unregistered and followed by `synchronize_rcu()` before calling `bcm_remove_op(op)` (with `op->flags |= RX_NO_AUTOTIMER` set before `can_rx_unregister()` in `bcm_delete_rx_op()`). [F13, F30, F31]
- In `isotp_release()`, after waiting for `so->tx.state == ISOTP_IDLE` and setting `so->tx.state = ISOTP_SHUTDOWN` and `so->rx.state = ISOTP_IDLE`, `can_rx_unregister()` and `synchronize_rcu()` must complete before canceling `so->txfrtimer`, `so->txtimer`, and `so->rxtimer` and freeing `so->rx.buf` and `so->tx.buf`. [F34]
- Removing a `struct cgw_job` must unlink `gwj->list`, call `cgw_unregister_filter(net, gwj)`, and defer freeing `gwj->cf_mod` and `gwj` via `call_rcu(&gwj->rcu, cgw_job_free_rcu)`, while replacing `gwj->cf_mod` in-place in `cgw_create_job()` must use `rcu_assign_pointer()` and `kfree_rcu_mightsleep()`. [F19]

## API Contracts
- Both `can_create_echo_skb()` and `can_send()` unconditionally consume or free their input `skb` on every return path; callers must never free `skb` after calling them. `can_send()` must never be called from hardirq context and must use `GFP_ATOMIC` when cloning loopback buffers. [F2, F42, F130]
- A `can_rx_register()` callback (`rcv->func`) must neither free the input `skb` nor mutate `skb->data` or `struct can_skb_priv` in-place; it must call `skb_clone()` to retain the packet or `skb_copy()` before modifying bytes. The `ident` string passed to `can_rx_register()` is stored directly in `receiver::ident` and read under RCU, so it must remain valid until after the receiver's RCU grace period. [F43, F126]
- `cgw_parse_attr()` must allow `ccgw->src_idx == 0 && ccgw->dst_idx == 0` (used by `cgw_remove_job()` to flush all jobs) while rejecting a single zero interface index, whereas `cgw_create_job()` must reject `!ccgw.src_idx || !ccgw.dst_idx`. Both `cgw_create_job()` and `cgw_remove_job()` must check `netlink_capable(skb, CAP_NET_ADMIN)` rather than `capable(CAP_NET_ADMIN)`. [F106, F161]

## Error Handling
- Before accessing a netdevice's `can_ml_priv` receive lists in `can_rx_register()`, `can_rx_unregister()`, or packet handlers (`can_rcv()`, `canfd_rcv()`, `canxl_rcv()`), code must verify `dev->type == ARPHRD_CAN`, `net_eq(net, dev_net(dev))`, and `can_get_ml_priv(dev) != NULL`. Invalid frames in `can_rcv()`, `canfd_rcv()`, and `canxl_rcv()` must be logged with `pr_warn_once()` and dropped via `kfree_skb_reason()` returning `NET_RX_DROP`. [F40, F160, F166]
- `raw_enable_filters()` and `raw_enable_allfilters()` must roll back already-registered filters on `can_rx_register()` failure (using `while (--i >= 0)` in `raw_enable_filters()` so the failed index `i` is not unregistered), and `raw_bind()` and `raw_setsockopt()` must enable new filters before disabling old filters. [F10, F98]
- When copying CAN frames from userspace with `memcpy_from_msg()` (`bcm_tx_setup()`, `raw_sendmsg()`), its negative error return must be checked before reading frame fields like `cf->len` or overwriting `err`. When populating `struct sockaddr_can` in `skb->cb` or `getname`, the destination must first be zeroed with `memset()`, and address length checks/assignments in `raw.c`, `bcm.c`, and `isotp.c` must use `CAN_REQUIRED_SIZE(struct sockaddr_can, ...)` rather than `sizeof(struct sockaddr_can)`. [F45, F54, F79]
- Every `isotp` TX path (`isotp_send_fc()`, `isotp_send_cframe()`, `isotp_sendmsg()`) must allocate frame data with `skb_put_zero(skb, so->ll.mtu)` and set `cf->flags = so->ll.tx_flags`. `isotp_recvmsg()` and `isotp_sendmsg()` must check `so->bound` (and `so->tx.state != ISOTP_SHUTDOWN` in `isotp_sendmsg()`) and return `-EADDRNOTAVAIL` before blocking. When `isotp_sendmsg()` waits in `wait_event_interruptible()`, it must abort via `err_event_drop` on signal interruption and, if `wait_tx_done` is enabled, check `sock_error(sk)` afterwards. [F46, F47, F48]

## Known Pitfalls
- In `isotp_rcv_cf()`, the payload copy loop breaks when `so->rx.idx >= so->rx.len` before incrementing `i`, so `check_pad()` on the final Consecutive Frame must be called with `start_index` set to `i + 1`, not `i`. In `isotp_rcv_fc()`, `so->txfc.stmin` in reserved ranges `0x80..0xF0` and `0xFA..0xFF` must be clamped to `0x7F` before computing `(so->txfc.stmin - 0xF0) * 100000` to prevent signed underflow into `ktime_add_ns()`. User `struct bcm_timeval` inputs in `bcm.c` must be validated by `bcm_is_invalid_tv()` before `bcm_timeval_to_ktime()`. [F103, F109, F110]
- In `net/can/bcm.c`, `bcm_op::frames` and `bcm_op::last_frames` are untyped `void *` buffers with element size `op->cfsiz` (`CAN_MTU` or `CANFD_MTU`), so indexing frame `i` must use byte-scaled pointer arithmetic (`op->frames + op->cfsiz * i`) rather than typed array indexing. Conversely, in `net/sched/em_canid.c`, `cm->rules_raw` is typed `struct can_filter[]`, so pointer arithmetic must use rule counts (`eff_rules_count`, `sff_rules_count`) while `nla_put_nohdr()` in `em_canid_dump()` requires `cm->rules_count * sizeof(struct can_filter)`. [F116, F125]
