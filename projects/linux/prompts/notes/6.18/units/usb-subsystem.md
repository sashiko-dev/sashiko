# USB SUBSYSTEM

This unit contains USB Device Controller (UDC) peripheral drivers (`lpc32xx_udc`, `m66592-udc`, `max3420_udc`, `net2280`, `omap_udc`), the `usbmon` URB snooping subsystem (`drivers/usb/mon/`), and miscellaneous USB host, hub, firmware, and test drivers (`drivers/usb/misc/`).

## Architecture & Data Flow

- In `net2280`, `queue_dma()` swaps `ep->dummy`/`ep->td_dma` with `req->td`/`req->td_dma` without clearing `dmacount`: `net2280_free_request()` must free whatever `req->td` points to, `net2280_remove()` must free `dev->ep[1..4].dummy` before `dma_pool_destroy()`, and paths completing aborted DMA requests before hardware clears `VALID_BIT` (`net2280_dequeue()`, `handle_ep_small()`) must set `req->td->dmacount = 0` before `dma_done()`. [F6, F62]
- In `net2280` on `PLX_PCIE` (USB338x) in `enhanced_mode`, IN/OUT endpoints of the same number share `ep->cfg` while IN `ep->regs` is offset by `0xC0`: always access `ep_cfg` via `ep->cfg->ep_cfg` while preserving the sibling direction's bits, keep the 9-element lookup arrays (`ep_info_adv`, `ep_bit`, `ep_key`, `ne`, `ep_reg_addr`, `ep_pl`, `ep_enhanced`) in lockstep, and guard `dev->usb_ext`, `dev->llregs`, and `dev->plregs` on `dev->quirks & PLX_PCIE`. [F65, F66, F76, F132]
- In `net2280_dequeue()`, when unlinking the queue head (`ep->queue.next == &req->queue`), reset `req = NULL` after completing it so `if (req) done(...)` is skipped and DMA restarts via `start_dma()` on the new head. In `net2280_queue()`, when an IN DMA request's ZLP/short-packet need differs from `ep->in_fifo_validate`, pass `valid = 0` to `queue_dma()` so `restart_dma()` reprograms `DMA_FIFO_VALIDATE` in `ep->dma->dmactl`. [F63, F89]
- In `omap_udc`, `ep0_irq()` speculatively writes `UDC_DEV_CFG` to `UDC_SYSCON2` and sets `udc->ep0_set_config = 1` before `udc->driver->setup()`; if `setup()` fails or `omap_ep_set_halt()` stalls `ep0`, write `UDC_CLR_CFG` to `UDC_SYSCON2`. In `read_fifo()`, EP0 (`!ep->bEndpointAddress`) must `break` before `if (is_last) done(...)` so `ep0_irq()` deselects EP0 (`omap_writew(0, UDC_EP_NUM)`) before calling `done()`. [F68, F97]
- In `omap_udc`, `udc->ep[32]` is indexed by `addr & 0xf` for EP0/OUT and `16 + (addr & 0xf)` for IN, while `ep->dma_channel` is 1-based (`1..3`, `0` unassigned); callers of `dma_channel_release()` (`omap_ep_dequeue()`, `omap_ep_set_halt()`, `nuke()`) must check `ep->dma_channel != 0` (not `ep->has_dma`) before shifting by `4 * (ep->dma_channel - 1)`. [F79, F100]
- In `mon_bin.c`, `rp->b_vec` pages are not virtually contiguous (`CHUNK_SIZE` = `PAGE_SIZE`), so copies must chunk at `CHUNK_SIZE` boundaries (`mon_copy_to_buff()`, `copy_from_buf()`), allocations/frees must align to `PKT_ALIGN` (64 = `PKT_SIZE`), payload data starts at `rp->b_out + PKT_SIZE`, and multi-slot offset advances must wrap by subtracting `rp->b_size` (not resetting to `0`). When `rp->mmap_active` is set, `mon_bin_event()` must use `mon_buff_area_alloc_contiguous()`. [F224, F236, F238, F265, F283]
- In `mon_text_get_data()` and `mon_bin_get_data()`, use `urb->transfer_buffer` when `urb->num_sgs == 0`, and otherwise iterate `urb->sg` via `sg_virt(sg)` only when `!PageHighMem(sg_page(sg))` (and `!(urb->transfer_flags & URB_DMA_SG_COMBINED)` in `mon_bin_get_data()`). Because `mon_dissolve()` clears `mbus->u_bus = NULL` while readers hold `mbus->ref`, `mon_stop()` and `mon_bin_open()` must check `mbus->u_bus != NULL` (for `mbus != &mon_bus0`) and keep `ubus->monitored = 1` iff `mbus->nreaders || mon_bus0.nreaders`. [F209, F219, F220]
- In `usb3503` and `usb4604`, `switch_mode()` must not overwrite `hub->mode` when entering `STANDBY` so resume restores the prior mode; because `usb3503` binds to both I2C and platform devices (`hub->regmap` is `NULL` on platform), never downcast `hub->dev` with `to_i2c_client()`/`to_platform_device()` and guard regmap calls in `usb3503_connect()` with `if (hub->regmap)`. [F207, F231, F288]

## Synchronization

- When completing requests in `lpc32xx_udc`, `net2280`, `omap_udc` (`done()`), and `m66592-udc` (`transfer_complete()`), hold the controller spinlock on entry and drop it around `usb_gadget_giveback_request()`, `driver->disconnect()`, and `driver->setup()`: `net2280` and `omap_udc` must save `ep->stopped`, set `ep->stopped = 1` before unlocking, and restore it after relocking; `m66592` `transfer_complete()` must re-read `ep->queue.next` and check `ep->ep.desc` after relocking; and `nuke()`/`m66592_disable()` must loop with `while (!list_empty(&ep->queue))`. [F13, F87, F139, F147]
- In `omap_udc.c`, runtime calls selecting an endpoint via `UDC_EP_NUM` (`use_ep()`) must hold `udc->lock`, any path setting `UDC_EP_SEL` must call `deselect_ep()` before unlocking, `ep0_irq()` must bracket unlocked `udc->driver->setup()` with `udc->ep0_setup = 1` and `0` so synchronous EP0 OUT `omap_ep_queue()` calls jump to `irq_wait`, and `omap_udc_enable_clock()` (called under `udc->lock`) must only use `clk_enable()`/`clk_disable()`, never `clk_prepare_enable()`/`clk_disable_unprepare()`. [F21, F32, F138]
- In `net2280`, `fill_dma_desc()` must execute `wmb()` after writing `td->dmaaddr`/`td->dmadesc` before writing `td->dmacount` with `BIT(VALID_BIT)`, paired with `rmb()` in `scan_dma_completions()` before reading `req->td->dmacount`. Under `ep->dev->lock`, `net2280_dequeue()` on a DMA endpoint must set `ep->stopped = 1`, call `stop_dma(ep->dma)`, and run `scan_dma_completions(ep)` before searching `ep->queue`. Once `ep0_start()` runs, `get_idx_reg()`, `set_idx_reg()`, and `set_max_speed()` require `dev->lock`. [F22, F23, F24]
- In `max3420_udc.c`, `spi_*()` helpers call blocking `spi_sync()`, so IRQ handlers and `usb_ep_ops`/`usb_gadget_ops` must never call them (instead setting `udc->todo`/`ep->todo` under spinlock and waking `udc->thread_task`), `udc->lock`/`ep->lock` must never be held across `spi_*()` or `max3420_req_done()`, and `max3420_irq_handler()` may only call `disable_irq_nosync(spi->irq)` when `(udc->todo & ENABLE_IRQ) == 0` and set `ENABLE_IRQ` under `udc->lock` (cleared before `enable_irq()` in `max3420_thread()`). [F16, F29, F144]
- In `lpc32xx_udc.c`, `lpc32xx_stop()` and the `!udc->driver` branch of `lpc32xx_vbus_session()` must drop `udc->lock` and wait on `udc->ep_disable_wait_queue` until `atomic_read(&udc->enabled_ep_cnt) == 0` (woken by `lpc32xx_ep_disable()`) before relocking and calling `udc_clk_set(udc, 0)`. Callers of `isp1301_pullup_enable()` in atomic context or holding `udc->lock` (`stop_activity()`, `pullup()`) must pass `block = 0` to defer I2C writes to `udc->pullup_job`. [F8, F27, F55]
- In `usbmon`, `mon_bus_lookup()` and `mon_buses` access require `mon_lock`; `mon_reader_add()`/`mon_reader_del()` require `mon_lock` and take `mbus->lock` (`spin_lock_irqsave`) around `mbus->nreaders`/`mbus->r_list` while updating `mbus->ref` outside `mbus->lock`. `mon_reader` callbacks (`rnf_submit`, `rnf_error`, `rnf_complete`) run under `mbus->lock` with IRQs disabled and must not sleep, use `GFP_KERNEL`, or relock `mbus->lock`; `mon_text_fetch()` must hold `mbus->lock` when accessing `rp->e_list` and `rp->nevents`. [F185, F186, F226, F316, F317]
- In `mon_bin.c`, `mon_bin_vma_fault()` must hold `rp->b_lock` across bounds-checking `rp->b_size`, indexing `rp->b_vec`, and `get_page()`. `mon_bin_ioctl(MON_IOCT_RING_SIZE)` must fail with `-EBUSY` if `rp->mmap_active` is non-zero and hold both `rp->fetch_lock` and `rp->b_lock` when replacing `rp->b_vec`/`rp->b_size` and zeroing ring indices. Retiring packets via `mon_buff_area_free()` requires both `rp->fetch_lock` and `rp->b_lock` and resetting `rp->b_read = 0` under `rp->fetch_lock`. [F189, F221, F223]
- In `drivers/usb/misc/`: character device `.release` callbacks (`ld_usb_release`, `adu_release`, `iowarrior_release`, `idmouse_release`) must use uninterruptible `mutex_lock()`; `adutux` lock order is `adutux_mutex` -> `dev->mtx` -> `dev->buflock`, and `adu_write()` signal/timeout paths after `mutex_unlock(&dev->mtx)` must jump to `exit_onqueue`; and `yurex_write()` must use `mutex_lock_interruptible(&dev->io_mutex)` and call `usb_kill_urb(dev->cntl_urb)` before unlocking. [F166, F169, F172, F190, F326, F327]

## Object Lifetimes

- In UDC drivers: `m66592_probe()` must set `m66592->ep0_req = NULL` after `m66592_free_request()` at `err_add_udc`, and `m66592_remove()` must call `usb_del_gadget_udc()` and `timer_shutdown_sync(&m66592->timer)` before `iounmap()`/`kfree()`; `max3420_probe()` failures after `usb_add_gadget_udc()` must jump to `del_gadget`; `net2280_remove()` must call `usb_put_gadget(&dev->gadget)` last because `gadget_release()` frees `dev`; and `omap_udc_remove()` must await `udc->done` after `usb_del_gadget_udc()` before `release_mem_region()`. [F1, F2, F5, F7, F31]
- In `lpc32xx_udc`, `net2280`, and `omap_udc`, removing a request from `ep->queue` must use `list_del_init(&req->queue)` (never `list_del()`). In `omap_udc.c`, `dma_channel_release()` must clear `ep->dma_channel = 0` and `ep->lch = -1` but leave `ep->has_dma` set until `nuke()` finishes `done()`, because `done()` gates `usb_gadget_unmap_request()` on `use_dma && ep->has_dma`. In `lpc32xx_udc`, non-EP0 `done()` must call `udc_dd_free()` and `usb_gadget_unmap_request()`, and `lpc32xx_udc_remove()` must call `udc_clk_set(udc, 1)` before `udc_disable(udc)`. [F3, F9, F10, F17]
- In USB character drivers (`adutux`, `idmouse`, `iowarrior`, `ldusb`, `usblcd`, `yurex`), per-device structs and buffers can outlive `.disconnect` while a file is open and must not use `devm_*`: pin `udev`/`interface` (`usb_get_dev`/`usb_get_intf`) until final delete (`yurex_delete()`, `iowarrior_delete()`, `adu_delete()`, `ld_usb_delete()`), poison URBs on disconnect (`yurex_disconnect()`, `ld_usb_disconnect()`, `lvs_rh_disconnect()` before `flush_work()`), and kill URBs / free coherent buffers before `usb_put_intf()`/`usb_put_dev()`. [F164, F165, F170, F171, F178, F192, F194, F297]
- In `lcd_write()` and `iowarrior_write()`, a successful `usb_submit_urb()` transfers ownership of coherent `buf` and `dev->limit_sem` or `dev->write_busy` to the completion callback, whereas submission failure must unanchor the URB, free `buf` and the URB, and release `up(&dev->limit_sem)` or `atomic_dec(&dev->write_busy)`. In `uss720`, `submit_async_request()` must link `rq->asynclist`, increment `priv->ref_count`, and call `kref_get(&rq->ref_count)` before `usb_submit_urb()`, while callers drop their ref via `kref_put(&rq->ref_count, destroy_async)`. [F168, F174, F175, F199]

## API Contracts

- In `lpc32xx_udc`, `udc_ep0_in_req()`/`udc_ep0_out_req()` return `1` on completion and `0` when more data remains, so `lpc32xx_ep_queue()` must return `(status < 0) ? status : 0`; `uda_enable/disable/clear_devint()` take pre-shifted masks whereas `uda_enable/disable/clear_hwepint()` and `udc_ep_dma_enable/disable()` take unshifted `hwep` (`0..31`). In `omap_udc`, `write_fifo()`/`read_fifo()` return `1` when complete (already calling `done()` for non-EP0), so `omap_ep_queue()` must set `req = NULL` on `1` to avoid queuing a completed request. [F37, F38, F50]
- In `m66592-udc`, `m66592_mdfy(m66592, val, pat, offset)` takes bits to set (`val`) second and bits to clear (`pat`) third (`(tmp & ~pat) | val`), and `setup_packet()` returns `1` to delegate to `driver->setup` and `0` when handled internally. In `max3420_udc`, `spi_rd_buf()`/`spi_wr_buf()` require `len <= MAX3420_EP_MAX_PACKET` (64). In `mon_bin.c`, `mon_buff_area_alloc*()` return an `unsigned int` offset (`0` is valid, `~0` on failure), and `mon_bin_get_data()` returns the uncopied residual byte count for `mon_buff_area_shrink()`. [F42, F43, F74, F202, F203]
- In `drivers/usb/misc/`, `usb_control_msg()` requires a DMA-capable heap buffer (never stack or `firmware->data` pointers unless `usb_control_msg_send()`/`recv()` is used), timeouts for `usb_control_msg*()`/`usb_bulk_msg()` are in milliseconds (not `* HZ`), and `bRequestType` direction (`USB_DIR_IN`/`OUT`) must match the pipe (`usb_rcvctrlpipe`/`usb_sndctrlpipe`). `emi26_probe()` and `emi62_probe()` must return `-EIO` after firmware load so the audio driver can claim the reset device, and `create_lvs_device()` devices must be freed via `destroy_lvs_device()`. [F179, F215, F216, F290, F341]

## Error Handling

- In `lpc32xx_ep_*()` and `net2280_*()` ep ops, do not dereference `ep->udc` or `ep->dev->pdev->dev` (e.g. `goto print_err`) before verifying `!_ep`, and in `lpc32xx_ep_dequeue()`, `max3420_ep_dequeue()`, `net2280_dequeue()`, and `omap_ep_dequeue()`, save a `list_for_each_entry` match into a separate `NULL`-initialized pointer before `break` rather than testing the loop cursor after the loop. In `omap_udc.c`, `udc->transceiver` holds the raw `usb_get_phy()` result, so always check `!IS_ERR_OR_NULL(udc->transceiver)`. [F35, F46, F51, F86]
- In `usbtest`, `usbtest_ioctl()` must check `if (retval < 0)` (as `ctrl_out()` returns a positive byte count on success); `ctrl_complete()` must restore `status = ctx->status` after reusing `status` for `usb_unlink_urb()` so a `0` unlink return does not trigger resubmission; and `usbtest_do_ioctl()`/`test_queue()`/`test_ctrl_queue()` must validate `sglen <= MAX_SGLEN`, `sglen > 0`, and `iterations <= UINT_MAX / sglen`. In `appledisplay` and `cypress_cy7c63`, 2-byte `usb_control_msg()` reads must check `retval < 2`. [F200, F204, F211, F243]

## External Contracts

- In `mon_bin.c`, `mon_bin_mmap()` must reject `VM_WRITE` with `-EPERM` and clear `VM_MAYWRITE` via `vm_flags_mod(vma, VM_DONTEXPAND | VM_DONTDUMP, VM_MAYWRITE)`; every ring buffer header slot must be zeroed with `memset(ep, 0, PKT_SIZE)` and `dp->_pad = 0` set in `mon_bin_get_isodesc()`; and 64-bit pointer ioctls (`MON_IOCX_GET`, `MON_IOCX_GETX`, `MON_IOCX_MFETCH`, `MON_IOCG_STATS`) must keep matching `compat_ptr()` handlers in `mon_bin_compat_ioctl()`. [F212, F332, F337]

## Known Pitfalls

- In `m66592-udc`: internal control transfers without a queued request (`clear_feature()`, `set_feature()`) must call `control_end(m66592, 1)` to set `ep[0].internal_ccpl`; `get_pipectr_addr(pipenum)` is only valid for `pipenum` in `1..M66592_MAX_NUM_PIPE - 1` (`0` uses `M66592_DCPCTR`), and `pipenum2ep` is indexed by `ep->pipenum` whereas `epaddr2ep` is indexed by USB endpoint number; and `m66592_read_fifo()` uses ceiling division `(len + 3) / 4` or `(len + 1) / 2` whereas `m66592_write_fifo()` uses truncating division and writes tail bytes via `iowrite8()`. [F57, F72, F73, F92, F102, F103]
- In `lpc32xx_udc`, `udc->ep[]` is indexed by logical endpoint `0..NUM_ENDPOINTS - 1` whereas `udca_v_base[]`, protocol engine commands, and bitmasks use `ep->hwep_num` (`0..31`); `udc_pop_fifo()`/`udc_stuff_fifo()` unaligned byte loops must shift by `i * 8` (not `n * 8`) with `bl` capped to `4`; and hardware register polling loops in `lpc32xx_udc` and `m66592-udc` must combine the unreached state check and timeout countdown with `&&` (not `||`). In `omap_udc`, RMW of `UDC_TXDMA_CFG`/`UDC_RXDMA_CFG` must OR `UDC_DMA_REQ` back in. [F67, F83, F84, F94]
- In `net2280`, `handle_stat0_irqs()` `USB_RECIP_ENDPOINT` requests must pass target `e = get_ep_by_addr(dev, w_index)` to `clear_halt()`, `set_halt()`, `restart_dma()`, and `abort_dma()`, but pass `ep` (`&dev->ep[0]`) to `allow_status()` and `set_fifo_bytecount()`. In `max3420_udc`, `spi_max3420_enable()`/`stall()` must return early for `ep->id == 0`, clear the 2-bit `ENABLE_EP`/`STALL_EP` mask before setting `ep->todo`, and test `todo` with `==` (not `&`). In `mon_text.c`, `mon_text_read_u()` must check `ep->type == 'E'` before branching on `ep->xfertype`. [F75, F85, F98, F213]
