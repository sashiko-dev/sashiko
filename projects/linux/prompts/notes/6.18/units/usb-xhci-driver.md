# USB XHCI DRIVER

Core xHCI host controller driver (`xhci.c`, `xhci-ring.c`), sideband audio/offload interrupter management (`xhci-sideband.c`), tracepoints (`xhci-trace.h`, `xhci-trace.c`), and SoC glue for NVIDIA Tegra (`xhci-tegra.c`) and Renesas RZ/V2M & RZ/G3E (`xhci-rzv2m.c`). It implements the USB `hc_driver` lifecycle, URB enqueue/dequeue, TRB ring management, command and event ring processing, device slot and endpoint context configuration, bandwidth management, and power management.

## Architecture & Data Flow

- Event rings (`TYPE_EVENT`) have no Link TRBs; command and transfer rings reserve `seg->trbs[TRBS_PER_SEGMENT - 1]` for a Link TRB. `xhci_clear_command_ring()` must only `memset` the first `TRBS_PER_SEGMENT - 1` TRBs of each segment and must clear `TRB_CYCLE` on `seg->trbs[TRBS_PER_SEGMENT - 1].link.control` before `xhci_initialize_ring_info()` and `xhci_set_cmd_ring_deq()`. [F64, F88, F131]
- Because `inc_enq()` parks `ring->enqueue` on a Link TRB when `!chain && !more_trbs_coming`, `xhci_num_trbs_free()` and `xhci_ring_expansion_needed()` must treat `trb_is_link(ring->enqueue)` with `ring->enq_seg->next->trbs == ring->dequeue` as an empty ring, `xhci_ring_expansion_needed()` must check `trbs_past_seg < 0` (using `TRBS_PER_SEGMENT - 1`), and `prepare_ring()` must call `inc_enq_past_link()` before queueing. [F86, F106]
- In `xhci_queue_bulk_tx()`, `xhci_queue_ctrl_tx()`, and `xhci_queue_isoc_tx()`, `prepare_transfer()` must run before capturing `start_trb` and `start_cycle` (as `prepare_ring()` may cross a Link TRB); the first TRB of a multi-TRB TD must be written with `!start_cycle` and handed to hardware via `giveback_first_trb()` with the saved `start_trb` and `start_cycle` only after all TRBs are queued. [F76, F134]
- In `xhci_queue_bulk_tx()`, test `first_trb || enqd_len < full_len` so zero-length URBs enqueue one TRB, and pass `more_trbs_coming | need_zero_pkt` to `queue_trb()` so `inc_enq()` crosses any Link TRB before the zero-packet TD. For `TRB_IDT`, copying `urb->transfer_buffer` into a `u64` stack variable must be gated by `xhci_urb_suitable_for_idt(urb)` (`<= 8` bytes) and converted via `le64_to_cpus()`. [F97, F113, F139]
- `xhci_get_endpoint_index()` returns a 0-based `ep_index` (`0..30`, `< EP_CTX_PER_DEV`) for `vdev->eps[]`, `sb->eps[]`, and `xhci_get_ep_ctx()`. Hardware TRB Endpoint IDs (`TRB_TO_EP_ID`), Doorbell targets (`DB_VALUE`), `add_flags`/`drop_flags`, and `LAST_CTX()` use 1-based indices (`ep_index + 1`, bit 0 `SLOT_FLAG`, bit 1 `EP0_FLAG`); event/command handlers must subtract 1 and validate via `xhci_get_virt_ep()`. [F89, F90]
- Stream ID 0 is reserved: `xhci_virt_ep_to_ring()` uses `ep->ring` when `!(ep->ep_state & EP_HAS_STREAMS)` or validates `ep->stream_info && 0 < stream_id < ep->stream_info->num_streams`. Port IDs (`GET_PORT_ID`), `udev->portnum`, `xhci_find_raw_port_number()`, and hub `wIndex` are 1-based, whereas `xhci->hw_ports[]`, `rhub->ports[]`, `xhci->rh_bw[]`, `hcd_portnum`, and `hw_portnum` are 0-based; in `xhci-tegra.c`, bound `rhub->ports[]` by `rhub->num_ports`, not SoC PHY counts. [F53, F87, F92, F93, F184]
- In `xhci_move_dequeue_past_td()`, stage the target dequeue in `ep->queued_deq_seg` and `ep->queued_deq_ptr` with `SET_DEQ_PENDING` set (only committing to `ep_ring->deq_seg`/`dequeue` in `xhci_handle_cmd_set_deq()` on `COMP_SUCCESS`); walk from `ep_ring->dequeue` until both `hw_dequeue_found` and `td_last_trb_found` are true, breaking before `next_trb()` if `hw_dequeue` is found after `td->end_trb` and toggling `new_cycle` across Link TRBs only after `td_last_trb_found`. [F78, F107]
- In `xhci_invalidate_cancelled_tds()`, at most one cancelled TD per endpoint may be selected as `cached_td` (`TD_CLEARING_CACHE`) for `xhci_move_dequeue_past_td()` while other cached TDs on different streams are marked `TD_CLEARING_CACHE_DEFERRED`, and `cached_td` must still be converted via `td_to_noop(td, false)`. In `xhci_urb_dequeue()`, do not queue Stop Endpoint if `EP_STOP_CMD_PENDING`, `EP_HALTED`, or `SET_DEQ_PENDING` is set; if `EP_CLEARING_TT` is set, call `xhci_process_cancelled_tds(ep)` immediately instead. [F66, F67]
- In `handle_tx_event()`: normal TD completion must return before `check_endpoint_halted:`; on non-halting `TRB_DATA`/`TRB_NORMAL` in `process_ctrl_td()` or mid-TD isoc error (`td->error_mid_td` with `ep_trb != td->end_trb`) in `process_isoc_td()`, set `td->urb_length_set = true` and return before `finish_td()`; in the `ep->skip` loop, return early on `COMP_STOPPED_LENGTH_INVALID` and skip at most one TD on `ring_xrun_event`; on `xhci_spurious_success_tx_event()`, reset `ep_ring->old_trb_comp_code = 0`. [F65, F103, F104, F111]
- In `handle_cmd_completion()`, `COMP_COMMAND_RING_STOPPED` must call `complete_all(&xhci->cmd_ring_stop_completion)` and return early before `xhci_trb_virt_to_dma()` checks `cmd_dma` or `xhci->cmd_list` is accessed. In `xhci_handle_events()`, each `unhandled_event_trb()` iteration must call `inc_deq()` before breaking on an error from `xhci_handle_event_trb()`, which returns `-ENODEV` if `XHCI_STATE_DYING` is set after dispatch. [F101, F112]
- In `xhci_configure_endpoint()`, under `XHCI_EP_LIMIT_QUIRK`, `xhci_reserve_host_resources()` adds new endpoints before command submission, `xhci_free_host_resources()` subtracts them on failure, and `xhci_finish_resource_reservation()` subtracts dropped endpoints only on success; under `XHCI_SW_BW_CHECKING`, call `xhci_reserve_bandwidth()` only when `!ctx_change`. [F17, F69]

## Synchronization

- `xhci_irq()` takes `xhci->lock` in hardirq context (`spin_lock(&xhci->lock)`), so all non-IRQ paths must use `spin_lock_irqsave()` or `spin_lock_irq()`. Sleeping mutexes `xhci->mutex` and `sb->mutex` nest outside `xhci->lock`, and callers waiting on `command->completion` or `xhci->cmd_ring_stop_completion` must drop `xhci->lock` before `wait_for_completion*()`. [F165, F170, F171]
- `xhci_urb_enqueue()` may run in atomic context: allocations before `xhci->lock` must use `mem_flags`, and allocations or ring expansions under `xhci->lock` (`xhci_queue_ctrl_tx()`, `xhci_queue_bulk_tx()`, `xhci_queue_intr_tx()`, `xhci_queue_isoc_tx_prepare()`) must use `GFP_ATOMIC`. [F166]
- In `xhci_abort_cmd_ring()` (entered with `xhci->lock` held), call `reinit_completion(&xhci->cmd_ring_stop_completion)` under `xhci->lock` before writing `CMD_RING_ABORT` and dropping `xhci->lock` for `wait_for_completion_timeout()`, and re-acquire `xhci->lock` before returning. In `xhci_handle_command_timeout()`, verify `xhci->current_cmd && !delayed_work_pending(&xhci->cmd_timer)` under `xhci->lock` before aborting. [F22, F34, F35]
- When `TRB_DISABLE_SLOT` completes with `COMP_SUCCESS`, `xhci_handle_cmd_disable_slot()` must clear `xhci->dcbaa->dev_context_ptrs[slot_id]` and `xhci->devs[slot_id]` under `xhci->lock` before waking the waiter; callers (`xhci_free_dev()`, `xhci_disable_and_free_slot()`) must save `xhci->devs[slot_id]` locally before `xhci_disable_slot()` and pass it to `xhci_free_virt_device()`. [F25, F26]
- `xhci_invalidate_cancelled_tds()` must return early if `SET_DEQ_PENDING` is set, and `xhci_handle_cmd_set_deq()` must always execute `cleanup:` (even if `!ep_ring` or on error) to clear `SET_DEQ_PENDING`, `ep->queued_deq_seg`, and `ep->queued_deq_ptr` before re-running `xhci_invalidate_cancelled_tds()` and `xhci_giveback_invalidated_tds()` if `ep->cancelled_td_list` is non-empty. [F15, F27]
- `xhci_ring_ep_doorbell()` must not ring the doorbell if `EP_STOP_CMD_PENDING`, `SET_DEQ_PENDING`, `EP_HALTED`, or `EP_CLEARING_TT` is set. In `xhci_endpoint_reset()`, all modifications to `ep->ep_state` (`EP_HARD_CLEAR_TOGGLE`, `EP_SOFT_CLEAR_TOGGLE`) must be under `xhci->lock`, and once `EP_SOFT_CLEAR_TOGGLE` is set, every exit path must reach `cleanup:` to clear it under `xhci->lock` and free `stop_cmd`. [F23, F28, F32]
- In `queue_trb()` and `inc_enq_past_link()`, execute `wmb()` after writing TRB payload/chain bits and before writing/toggling `TRB_CYCLE`. In `xhci_handle_event_trb()`, execute `rmb()` after `unhandled_event_trb()` matches `TRB_CYCLE` and before reading event fields. [F29, F31]
- In `xhci_urb_dequeue()`, call `usb_hcd_check_unlink_urb()` and `usb_hcd_unlink_urb_from_ep()` under `xhci->lock`, and release `xhci->lock` before `usb_hcd_giveback_urb()` on `err_giveback`. In `xhci_endpoint_disable()`, if `EP_CLEARING_TT` is set, drop `xhci->lock`, sleep, and jump to `rescan:` to re-validate `host_ep->hcpriv`, `udev->slot_id`, and `xhci->devs[udev->slot_id]` under `xhci->lock`. [F36, F115]
- In `xhci-tegra.c`, `tegra_xhci_id_notify()` is an atomic notifier and must defer sleeping calls to `tegra_xhci_id_work()`, which must hold `pm_runtime_get_sync(tegra->dev)` across port/mailbox access. `tegra_xusb_suspend()` and `tegra_xusb_runtime_suspend()` must call `synchronize_irq(tegra->mbox_irq)` before taking `tegra->lock` to enter ELPG, and `tegra_xusb_mbox_thread()` must abort under `tegra->lock` if `pm_runtime_suspended(tegra->dev) || tegra->suspended`. [F159, F162, F168]

## Object Lifetimes

- For `xhci_command`: if `cmd->completion == NULL`, `queue_command()` transfers ownership to `xhci->cmd_list`, so the caller frees it via `xhci_free_command()` only if `queue_command()` fails; if `cmd->completion != NULL`, the caller retains ownership and must free it on all exit paths. When `command->in_ctx` borrows an external context (e.g. `virt_dev->in_ctx`), free `command->completion` and `command` with `kfree()` instead of `xhci_free_command()` (which frees `command->in_ctx`). In `xhci_free_streams()`, `command` is owned by `stream_info` and must not be freed directly. [F1, F2, F3, F4]
- In `xhci_urb_enqueue()`, allocate `urb_priv` via `struct_size(urb_priv, td, num_tds)` and set `urb_priv->num_tds = num_tds` before indexing `urb_priv->td[]` (`__counted_by(num_tds)`); on error, call `xhci_urb_free_priv(urb_priv)` and clear `urb->hcpriv = NULL` under `xhci->lock`. [F5, F129]
- In `xhci_urb_dequeue()`, check `td_on_ring(&urb_priv->td[0], ep_ring)` under `xhci->lock` before touching `td->td_list` or queueing Stop Endpoint; if the ring was reallocated, only unlink `td->cancelled_td_list` and give back the URB. Loops unlinking/completing TDs on `cancelled_td_list` or `ring->td_list` must use `list_for_each_entry_safe()`, and `xhci_giveback_invalidated_tds()` must abort if `XHCI_STATE_DYING` is set. [F14, F109]
- `xhci_endpoint_init()` stages a new ring in `eps[ep_index].new_ring`; `xhci_check_bandwidth()` frees old `ring`, promotes `new_ring` to `ring`, and clears `new_ring = NULL`, while `xhci_reset_bandwidth()` frees and clears `new_ring = NULL` on failure, and both must call `xhci_zero_in_ctx(xhci, virt_dev)`. [F12, F60]
- When `xhci_map_temp_buffer()` maps an SG URB (`urb->num_sgs > 0`), it checks `kzalloc_node()` for `NULL` (`-ENOMEM`), frees `temp` without setting `URB_DMA_MAP_SINGLE` if `dma_mapping_error()` fails, and otherwise sets `urb->transfer_buffer` and `URB_DMA_MAP_SINGLE`; `xhci_queue_bulk_tx()` and `xhci_unmap_urb_for_dma()` (which calls `xhci_unmap_temp_buf()` to unmap, free, and clear `urb->transfer_buffer = NULL`) must check `URB_DMA_MAP_SINGLE` even when `urb->num_sgs > 0`. [F7, F55, F176]
- `__xhci_sideband_remove_endpoint()` must clear `ep->sideband = NULL` and `sb->eps[ep->ep_index] = NULL` under `sb->mutex`; `xhci_sideband_unregister()` must clear `sb->xhci = NULL` and `sb->vdev->sideband = NULL` under `xhci->lock` before `kfree(sb)`. `xhci_sideband_remove_interrupter()` must call `xhci_remove_secondary_interrupter()`, clear `sb->ir = NULL`, and call `usb_offload_put(udev)` under `sb->mutex`. [F16, F19]

## API Contracts

- `xhci_check_args()` returns `1` for valid non-roothub devices, `0` for roothubs, and `< 0` on error; callers disallowing roothubs (`xhci_urb_enqueue()`, `xhci_check_streams_endpoint()`) must map `0` to `-EINVAL`. `xhci_alloc_dev()` returns `1` on success and `0` on failure, so internal callers must test `ret == 1`. [F44, F45]
- Always use `hcd_to_xhci(hcd)` instead of casting `hcd->hcd_priv` directly when `hcd` may be `xhci->shared_hcd`. All DMA operations must use `hcd->self.sysdev`, not `hcd->self.controller`. Before freeing an endpoint ring that may be offloaded, synchronously call `xhci_sideband_notify_ep_ring_free(ep->sideband, ep_index)` before `xhci_free_endpoint_ring()`, and `notify_client()` must not retain stack-allocated `&evt` or `evt.evt_data`. [F40, F135, F138, F173]

## Error Handling

- `xhci_irq()` must return `IRQ_NONE` only when `!(status & STS_EINT)` (after verifying `status != ~(u32)0`), and `IRQ_HANDLED` on early returns for `status == ~(u32)0`, `STS_HCE`, or `STS_FATAL`. [F46]
- In `xhci_handle_cmd_stop_ep()` on `COMP_CONTEXT_STATE_ERROR`: if `GET_EP_CTX_STATE(ep_ctx)` is `EP_STATE_RUNNING`, unconditionally re-queue Stop Endpoint without the 100ms `ep->stop_time` timeout; if `EP_STATE_STOPPED`, only fall through to `EP_STATE_RUNNING` if `!(ep->ep_state & EP_HALTED)` and `!time_is_before_jiffies(ep->stop_time + msecs_to_jiffies(100))`. [F102, F157]
- In `xhci_endpoint_reset()`, verify `udev->slot_id != 0` and `vdev = xhci->devs[udev->slot_id]` is non-NULL (plus `vdev->udev == udev` for ep0) before dereferencing `vdev`. When `xhci_setup_device()` reallocates a slot via `xhci_alloc_dev()` after `COMP_USB_TRANSACTION_ERROR`, it must immediately call `xhci_setup_addressable_virt_dev(xhci, udev)`. [F51, F68]
- In `xhci_queue_isoc_tx()`, if `prepare_transfer()` or length validation fails when `i > 0`, jump to `cleanup:` to unlink `urb_priv->td[0..i-1]`, call `td_to_noop(&urb_priv->td[0], true)`, restore `ep_ring` state, and call `usb_hcd_unlink_urb_from_ep()`. In `xhci_resume()`, if `power_lost` and `XHCI_STATE_REMOVING` is set, return `-ENODEV` instead of calling `xhci_reset()`. [F57, F146]

## Known Pitfalls

- Because `next_trb()` does not skip Link TRBs, `trb_to_noop()` must check `trb_is_link(trb)` and only clear `TRB_CHAIN` on Link TRBs, while on non-Link TRBs it zeroes `field[0..2]` and preserves only `TRB_CYCLE` in `field[3]`. Before `prepare_ring()` advances `ep_ring->enqueue` past a Link TRB, test segment end on `ep_ring->enqueue + 1` with `last_trb_on_seg()`, not `trb_is_link()`. [F61, F85, F108]
- Register RMW hazards: `xhci_enable_interrupter()` and `xhci_disable_interrupter()` must clear RW1C `IMAN_IP` (`iman &= ~IMAN_IP`); `xhci_disable_hub_port_wake()` must filter `portsc` through `xhci_port_state_to_neutral()` and only set `PORT_CSC` when neither `PORT_CSC` nor `PORT_CONNECT` is set; `xhci_abort_cmd_ring()` must OR `CMD_RING_ABORT` with the next non-link TRB DMA address (`crcr | CMD_RING_ABORT`) and poll `CMD_RING_RUNNING` via `xhci_handshake()`. [F143, F149, F151]
- Quirk and pointer pitfalls: in `xhci_handle_stopped_cmd_ring()`, check `if (cur_cmd)` before `xhci_mod_cmd_timer()`; in `handle_cmd_completion()` for `TRB_RESET_DEV`, read `slot_id` from `cmd_trb->generic.field[3]`, not `event->flags`; `xhci_log_free_virt_dev` must not dereference `vdev->udev` or `vdev->rhub_port`; `xhci_endpoint_reset()` may only use `container_of(host_ep, struct usb_device, ep0)` for control `ep_index == 0` (using `host_ep->hcpriv` otherwise); pass `unsigned long` (never `u32` fields or locals) to `set_bit`/`for_each_set_bit`. [F49, F52, F91, F137, F141, F142]
