# DRM DRIVER for Qualcomm display hardware

This unit (`drivers/gpu/drm/msm/disp/dpu1`) implements the Qualcomm Snapdragon DPU display driver, covering SoC catalogs, performance/bandwidth/clock voting (`dpu_core_perf`), CRTC and virtual/physical encoders, interrupt dispatch (`dpu_hw_interrupts`), pixel formats (`dpu_formats`), and MMIO block drivers (`dpu_hw_*`).

## Architecture & Data Flow
- Any non-mode state change that alters resource reservation in `dpu_crtc_get_topology()` or `dpu_encoder_update_topology()` (e.g. writeback YUV format toggling `num_cdm` or clone mode toggling `cwb_enabled`) must be mirrored in `dpu_encoder_needs_modeset()` and `dpu_crtc_check_mode_changed()` to set `new_crtc_state->mode_changed = true`. In `dpu_crtc_get_topology()`, the `topology.num_intf == 2` branch setting `topology.num_lm = 2` must be guarded with `!topology.cwb_enabled`. [F58, F83]
- In `dpu_crtc_atomic_check()`, early returns for inactive/disabled CRTCs (`!crtc_state->enable || !drm_atomic_crtc_effectively_active(crtc_state)`) must zero `cstate->new_perf` (copied by `kmemdup` in `dpu_crtc_duplicate_state()`). When `mode_changed || connectors_changed`, `dpu_crtc_assign_resources()` must populate `cstate->mixers` and `num_mixers` before `_dpu_crtc_check_and_setup_lm_bounds()` computes `cstate->lm_bounds`. [F48, F57]
- In `dpu_crtc_assign_resources()` and `dpu_encoder_virt_atomic_mode_set()`, `num_ctl` (`DPU_HW_BLK_CTL`) can be smaller than `num_lm` or `dpu_enc->num_phys_encs`, so `hw_ctl` indexing must clamp to `num_ctl - 1` or `hw_ctl[0]`. [F71]
- In `dpu_crtc_atomic_begin()`, `dpu_encoder_trigger_kickoff_pending()` must run before `_dpu_crtc_blend_setup()` and `_dpu_crtc_setup_cp_blocks()` stage new pending flush bits on the CTL blocks. [F118]
- In `dpu_encoder_prepare_for_kickoff()`, if any physical encoder has `enable_state == DPU_ENC_ERR_NEEDS_HW_RESET`, `dpu_encoder_helper_hw_reset()` must run on all `dpu_enc->phys_encs[i]` in a second pass after `DPU_ENC_RC_EVENT_KICKOFF`. On command/writeback kickoff timeouts (`_dpu_encoder_phys_cmd_handle_ppdone_timeout`, `_dpu_encoder_phys_wb_handle_wbdone_timeout`), decrement `pending_kickoff_cnt`, set `enable_state = DPU_ENC_ERR_NEEDS_HW_RESET`, and increment the timeout counter (reset to 0 on success). [F87, F189]
- In `dpu_encoder_phys_vid_enable()`, set `enable_state = DPU_ENC_ENABLING` and defer `hw_intf->ops.enable_timing(..., 1)` and `DPU_ENC_ENABLED` until `dpu_encoder_phys_vid_handle_post_kickoff()` after CTL flush. `dpu_encoder_phys_cmd_enable_helper()` calls `update_pending_flush_intf()` for both master and slave, whereas `dpu_encoder_phys_vid_enable()` skips slave INTF flush only when `dpu_encoder_phys_vid_needs_single_flush(phys_enc)` is true. [F190, F253]
- When clearing blend stages on a `dpu_hw_ctl` (`_dpu_crtc_blend_setup()`, `dpu_encoder_helper_reset_mixers()`, `dpu_hw_ctl_reset_intf_cfg_v1()`), `set_active_fetch_pipes(ctl, NULL)` and `set_active_pipes(ctl, NULL)` (plus `set_active_lms(ctl, NULL)` on mixer/intf reset) must be called alongside `clear_all_blendstages`. `dpu_hw_ctl_intf_cfg_v1()` must read-modify-write `CTL_*_ACTIVE`, `dpu_hw_ctl_reset_intf_cfg_v1()` must mask off only `cfg`-specified `CTL_*_ACTIVE` bits, and every `dpu_hw_ctl_update_pending_flush_*_v1` helper must set both `ctx->pending_*_flush_mask` and `BIT(*_IDX)` in `ctx->pending_flush_mask`. [F54, F183, F184, F185]
- `dpu_encoder_helper_phys_cleanup()` must unbind/disable all optional features on shared blocks (`hw_wb`, `hw_intf`, `hw_pp` dither, `hw_cwb`, `merge_3d`, `hw_cdm`, `hw_dsc`) and set `dpu_enc->dsc = NULL` before flushing `ctl`. Any `dpu_encoder_virt` fields cleared during disable/cleanup (`connector`, `dsc`, `enabled`) must be re-initialized in `dpu_encoder_virt_atomic_enable()`, not `atomic_mode_set()`. [F55, F56]
- Optional pointers must be NULL-checked: `dpu_encoder_phys` has either `hw_intf` or `hw_wb` (never both), optional `hw_cdm`, and optional `hw_pp->merge_3d` (only set `merge_3d` in `intf_cfg` / `update_pending_flush_merge_3d()` when both `dpu_encoder_helper_get_3d_blend_mode()` and `hw_pp->merge_3d` are non-zero); `dpu_crtc_mixer.hw_dspp` and `dpu_plane_state.r_pipe.sspp` are optional. `to_dpu_encoder_phys_cmd` and `to_dpu_encoder_phys_wb` must only be used on `INTF_MODE_CMD` and `INTF_MODE_WB_LINE` encoders because `dpu_encoder_phys_vid_init()` allocates only `sizeof(struct dpu_encoder_phys)`. [F40, F41, F42, F173, F239, F249]
- Tearcheck ops live on `dpu_hw_pingpong` for `core_major_ver < 5` and `dpu_hw_intf` (`INTF_DSI` only) for `core_major_ver >= 5` (checked via `phys_enc->has_intf_te`). `dpu_hw_intf_disable_autorefresh()` and `dpu_hw_pp_disable_autorefresh()` must disconnect external TE, clear autorefresh, poll `wr_ptr_line_count` until `0 < wr_ptr_line_count < vdisplay` is false, and reconnect TE. [F254, F255]
- Shared MMIO registers require read-modify-write: `SSPP_MULTIRECT_OPMODE`, `SSPP_SRC_YSTRIDE0`, and `SSPP_SRC_YSTRIDE1` when `pipe->multirect_index != DPU_SSPP_RECT_SOLO` (`dpu_hw_sspp_setup_multirect`, `dpu_hw_sspp_setup_sourceaddress`), and `LM_OP_MODE` on DPU < 12 between `dpu_hw_lm_setup_out()` and `dpu_hw_lm_setup_color3()`. Because `DPU_REG_WRITE()` uses `writel_relaxed()`, IRQ writes in `dpu_hw_interrupts.c`, `dpu_hw_setup_wd_timer()`, and `dpu_hw_setup_misr()` require an explicit `wmb()`. [F192, F195, F245]
- `irq_idx` in `dpu_hw_interrupts` and catalog `intr_*` fields are 1-based unsigned values (`0` = no IRQ): `DPU_IRQ_IDX` adds 1, `DPU_IRQ_REG`/`DPU_IRQ_BIT`/`dpu_core_irq_get_entry()` subtract 1, `dpu_core_irq()` must use `bit - 1` from `ffs(irq_status)` on every loop path, and `dpu_encoder_helper_wait_for_irq()` must test `irq_idx == 0` (not `< 0`). Catalog `dpu_ctl_cfg` on DPU >= 5.0 must not set `BIT(DPU_CTL_SPLIT_DISPLAY)`, and `dpu_perf_cfg` must set non-zero `.max_bw_high` and `.min_prefill_lines`. [F66, F67, F107, F108, F196, F211]

## Synchronization
- Lock hierarchy: `dpu_enc->enc_lock` (protects `dpu_enc->enabled`, `phys_encs[]`, and enable/disable/restore) -> `dpu_enc->rc_lock`; `phys_enc->vblank_ctl_lock` -> `dpu_kms->hw_intr->irq_lock` -> `phys_enc->enc_spinlock`; `dpu_enc->enc_spinlock` (protects `dpu_enc->crtc` in `dpu_encoder_assign_crtc()` and `dpu_encoder_vblank_callback()`) -> `crtc->dev->event_lock`. `irq_lock` and both `enc_spinlock`s run in hardirq context and require `spin_lock_irqsave()`. Never call `dpu_core_irq_*` or `phys->ops.control_vblank_irq()` while holding `enc_spinlock`, and never acquire `dpu_enc->enc_spinlock` while holding `event_lock`. [F25, F28, F130, F131, F158, F160, F265]
- In `dpu_encoder_resource_control()`, call `cancel_delayed_work_sync(&dpu_enc->delayed_off_work)` before acquiring `dpu_enc->rc_lock`. Process-context events (`KICKOFF`, `PRE_STOP`, `STOP`, `ENTER_IDLE`) must hold `rc_lock`, whereas hardirq `DPU_ENC_RC_EVENT_FRAME_DONE` must not. Under `ENTER_IDLE`, revalidate `rc_state == DPU_ENC_RC_STATE_ON` and `frame_busy_mask[0] == 0` after locking `rc_lock`. [F29, F30, F127]
- In `_dpu_encoder_kickoff_phys()`, hold `dpu_enc->enc_spinlock` across setting `frame_busy_mask` (only for `phys->split_role != ENC_ROLE_SLAVE`), `_dpu_encoder_trigger_flush()`, and `_dpu_encoder_trigger_start(dpu_enc->cur_master)`. `dpu_encoder_start_frame_done_timer()` must only be called after `dpu_encoder_kickoff()` sets `frame_busy_mask` (in clone mode, kick off `wb_encoder` before `rt_encoder`, then start both timers). Hardirq `dpu_encoder_frame_done_callback()` zeroes `frame_done_timeout_ms` before non-blocking `timer_delete()`, whereas `dpu_encoder_virt_atomic_disable()` uses `timer_delete_sync()` under `enc_lock`; `dpu_encoder_frame_done_timeout()` must check `frame_busy_mask[0]`, `dpu_enc->crtc`, and `atomic_xchg(&dpu_enc->frame_done_timeout_ms, 0) != 0`. [F18, F32, F81, F86, F124, F134]
- `dpu_encoder_phys_vid_vblank_irq()` must hold `phys_enc->enc_spinlock` while verifying `!(get_flush_register(hw_ctl) & get_pending_flush(hw_ctl))` and decrementing `pending_kickoff_cnt`. In `dpu_encoder_phys_vid_disable()`, after clearing `enable_timing(..., 0)` under `enc_spinlock`, a master encoder must call `dpu_encoder_phys_inc_pending()` and `dpu_encoder_phys_vid_wait_for_tx_complete()` before `dpu_encoder_helper_phys_cleanup()`. [F162, F163]
- `dpu_crtc_frame_event_cb()` runs in hardirq/softirq context: ignore `DPU_ENCODER_FRAME_EVENT_IDLE` before dequeuing from `frame_event_list` under `spin_lock_irqsave(&dpu_crtc->spin_lock, ...)`, and defer `dpu_core_perf_crtc_release_bw()` to `dpu_crtc_frame_event_work()`, which must return `fevent` to `frame_event_list` under `dpu_crtc->spin_lock` on all paths. [F80, F129]

## Object Lifetimes
- Clear `crtc->state->event` or `dpu_crtc->event` to `NULL` under `dev->event_lock` when transferring in `dpu_crtc_atomic_flush()` or sending in `_dpu_crtc_complete_flip()` / `dpu_crtc_disable()`. [F2]
- In `dpu_crtc_enable()`, call `dpu_encoder_assign_crtc(encoder, crtc)` before `drm_crtc_vblank_on(crtc)` when `!old_crtc_state->self_refresh_active` (and skip assignment when `old_crtc_state->self_refresh_active` is true). In `dpu_crtc_disable()`, call `drm_crtc_vblank_off(crtc)` before `dpu_encoder_assign_crtc(encoder, NULL)` (skipped only when entering `crtc->state->self_refresh_active`). [F4, F17]
- `dpu_crtc_assign_resources()` and `dpu_crtc_reassign_planes()` must call `dpu_rm_release()` / `dpu_rm_release_all_sspp()` before `if (!crtc_state->enable) return 0;`. In `dpu_encoder_virt_atomic_mode_set()`, clear unused `dpu_enc->hw_pp[i >= num_pp]` and `cur_master->hw_cdm` to `NULL`, and call `phys->ops.atomic_mode_set()` after assigning `phys->hw_pp` and `phys->hw_ctl`. [F6, F13, F16]
- `_dpu_encoder_resource_enable()` gets runtime PM before enabling IRQs, and `_dpu_encoder_resource_disable()` disables IRQs before putting runtime PM. In `dpu_encoder_resource_control()`, video mode keeps runtime PM active in `IDLE` (`ENTER_IDLE` only disables IRQs), so `KICKOFF` and `PRE_STOP` from `IDLE` only enable IRQs and `PRE_STOP` enters `PRE_OFF` so `STOP` calls `_dpu_encoder_resource_disable()`. [F8, F9]
- In `dpu_crtc_disable()`, `_dpu_crtc_wait_for_frame_done()` must finish before setting `dpu_crtc->enabled = false`, releasing `frame_pending` / `bandwidth_ref`, calling `dpu_core_perf_crtc_update(crtc, 0)`, and putting runtime PM (`INTF_MODE_VIDEO` holds an extra `bandwidth_ref` between `dpu_crtc_enable()` and `dpu_crtc_disable()`). Under `enc_lock`, `dpu_encoder_virt_atomic_disable()` must call `dpu_encoder_wait_for_tx_complete()`, `DPU_ENC_RC_EVENT_PRE_STOP`, `phys->ops.disable()`, `timer_delete_sync(&dpu_enc->frame_done_timer)`, and `DPU_ENC_RC_EVENT_STOP`. [F19, F20, F33]
- Once `drm_writeback_queue_job()` runs in `dpu_encoder_phys_wb_prepare_for_kickoff()`, both `dpu_encoder_phys_wb_done_irq()` and `_dpu_encoder_phys_wb_handle_wbdone_timeout()` must call `drm_writeback_signal_completion()`, and `dpu_encoder_phys_wb_cleanup_wb_job()` must call `msm_framebuffer_cleanup()` and clear `wb_job`/`wb_conn`. `dpu_crtc`, `dpu_encoder_virt`, `dpu_encoder_phys_*`, and `dpu_hw_*` are `drmm_*`-allocated and must never be `kfree()`d. [F125, F145, F270, F271]

## API Contracts
- `dpu_rm_get_assigned_resources()` takes `blks_size` as an element count (`ARRAY_SIZE`, never `sizeof`), only writes `0 .. num_blks - 1`, and returns `struct dpu_hw_blk *` pointers that must be downcast with the matching `to_dpu_hw_*` macro. Resource reservation in `dpu_crtc_atomic_check()` / `dpu_crtc_assign_resources()` must trigger on `mode_changed || connectors_changed` (never `active_changed`) and reserve whenever `crtc_state->enable` is true. [F45, F96, F100, F136]
- In `dpu_core_perf_crtc_update()`, update bus BW (`_dpu_core_perf_crtc_update_bus()`, which must guard `if (!kms->num_paths) return;` and convert `bw_ctl` from Bps to kBps) before clock rate (`dev_pm_opp_set_rate()`), only increasing votes when `params_changed != 0` and only decreasing when `params_changed == 0`. Zero-initialize structs passed to `dpu_core_perf_aggregate()`, `dpu_encoder_update_topology()`, and `ctl->ops.{setup,reset}_intf_cfg()`. [F34, F44, F47, F91, F140, F177]
- In `struct dpu_hw_intf_cfg`, `intf`, `intf_master`, `wb`, and `merge_3d` take 1-based enum IDs while `cwb` and `dsc` take bitmasks (`BIT(idx - *_0)`), whereas all `dpu_hw_ctl_update_pending_flush_*_v1()` and `bind_pingpong_blk` callbacks take 1-based enum IDs. Generation-specific ops (`ctl->ops.{clear_all_blendstages,setup_blendstage}` on DPU < 12; `ctl->ops.set_active_{pipes,lms}` and `lm->ops.{setup_blendstage,clear_all_blendstages}` on DPU >= 12; `ctl->ops.{reset_intf_cfg,update_pending_flush_*}` on DPU >= 5) must be NULL-checked before calling, and passing a `NULL` cfg to `setup_dither`, `setup_dspp_pcc`, `setup_blendstage`, or `set_active_*` disables the feature. [F171, F172, F174, F179, F180, F200]
- `dpu_hw_lm_init()` and `dpu_hw_intf_init()` can return `NULL` (`PINGPONG_NONE`/`INTF_NONE`) as well as `ERR_PTR`; `dpu_hw_clk_force_ctrl()` returns `true` only if the bit was previously `0`; `dpu_format_populate_plane_sizes()` must succeed before `dpu_format_populate_addrs()` is called. [F165, F168, F175]

## Error Handling
- `dpu_encoder_helper_wait_for_irq()` and `dpu_encoder_wait_for_commit_done()` return negative `int` error codes (`-EWOULDBLOCK` when disabled, `-ETIMEDOUT` on hardware timeout); store the result in a signed `int` and only trigger timeout recovery / `msm_disp_snapshot_state()` (gated to the first occurrence) when `ret == -ETIMEDOUT`. [F36, F143, F166]
- NULL-check both `drm_atomic_get_new_connector_for_encoder()` and `drm_atomic_get_new_connector_state()` in `dpu_encoder_update_topology()` / `dpu_encoder_needs_modeset()`, and check `if (!irq_entry->cb) return;` in `dpu_core_irq_callback_handler()`. Check `IS_ERR(enc)` and `num_phys_encs` bounds in `dpu_encoder_virt_add_phys_encs()`, and reject mixer widths `> max_mixer_width` with `-E2BIG` in `_dpu_crtc_check_and_setup_lm_bounds()`. [F38, F43, F68, F75, F167]

## External Contracts
- DRM format arrays in `dpu_hw_catalog.c` (`plane_formats`, `plane_formats_yuv`, `wb2_formats_rgb_yuv`) must not contain duplicate `DRM_FORMAT_*` entries. [F268]

## Known Pitfalls
- Use `old_crtc_state->encoder_mask` in `dpu_crtc_disable()` and `crtc->dev->mode_config.encoder_list` in `dpu_crtc_vblank()` (never `crtc->state->encoder_mask`), and initialize `rt_encoder = NULL` / `wb_encoder = NULL` in `dpu_crtc_kickoff_clone_mode()`. [F46, F82]
- Cast to `u64` before `mode->vtotal * mode->hdisplay * drm_mode_vrefresh(mode)` in `_dpu_core_perf_calc_clk()`, keep `creq_lut` as `u64` in `_dpu_hw_setup_qos_lut()`, mask signed fields in `dpu_hw_scaler3*`, `dpu_hw_pixel_ext`, and `dpu_hw_csc_setup()` (`& 0x1FFF`) before shifting/ORing, and check `pp >= PINGPONG_CWB_0` before `else if (pp)` in `dpu_hw_{cdm,wb}_bind_pingpong_blk()`. [F89, F212, F221, F222, F223, F224]
- Use `drm_dsc_get_bpp_int(dsc)` when scaling `timing->width` in `drm_mode_to_intf_timing_params()`, and only halve `data_width` in `dpu_hw_intf_setup_timing_engine()` when `p->wide_bus_en && !dp_intf`. In `dpu_hw_setup_scaler3()`, `!scaler3_cfg->enable` must `goto end;` (not `return;`), and in `_dpu_hw_setup_scaler3*_lut()`, copy `u32 lut_flag` to an `unsigned long` local before `test_bit()`. [F215, F227, F228, F237]
