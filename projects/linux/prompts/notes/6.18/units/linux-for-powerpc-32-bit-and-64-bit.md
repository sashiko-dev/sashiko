# LINUX FOR POWERPC (32-BIT AND 64-BIT)

This unit provides PowerPC architecture headers and core kernel subsystems, including interrupt/syscall entry and exit, 64-bit lazy IRQ soft-masking, IOMMU TCE management and DMA mapping, Firmware-Assisted Dump (fadump), Machine Check Exception (MCE) handling, ELF module relocation, NVRAM/pstore, hardware breakpoints, kprobes, CPU feature discovery, cacheinfo sysfs, and alignment emulation.

## Architecture & Data Flow

- In `cpu_setup_power.c`, every SPR initialization in `__setup_cpu_power{7,8,9,10}()` must be mirrored in `__restore_cpu_power{7,8,9,10}()`, and both must verify `MSR_HV` before accessing hypervisor-privileged SPRs. In `dt_cpu_ftrs.c`, callbacks modifying `LPCR`, `HFSCR`, `FSCR`, or `PCR` must run before `cpufeatures_setup_finished()`, `feat_enable_dscr()` must set `f->fscr_bit_nr = -1` before `feat_enable()`, and `feat_enable()` must check `-1` and `*_SUPPORT_NONE` sentinels before shifting. [F36, F102, F196, F215, F301]
- In `cpu_specs_*.h`, specific `pvr_mask` entries must precede broader family entries (`pvr_mask = 0` last); in `cpufeatures_cpu_quirks()`, `0xffffefff` POWER9 DD2.0–2.3 checks must precede `(version & 0xffff0000) == 0x004e0000`; and in `update_tlbie_feature_flag()`, the 3-bit Nimbus check (`(pvr & 0xe000) == 0`) must precede the 2-bit Cumulus check (`(pvr & 0xc000) == 0`). [F67, F240, F241]
- When `syscall_exit_restart()` or `interrupt_exit_user_restart()` restarts a user exit after `interrupt_exit_user_prepare_main()`, it must restore `AMR_KUAP_BLOCKED` and call `trace_hardirqs_off()`, `user_exit_irqoff()`, and `account_cpu_user_entry()`. In `interrupt_exit_user_prepare_main()`, math register state must be checked via `(regs->msr & mathflags) != mathflags`. [F210, F245]
- In `mce.c`, `save_mce_event()` increments `mce_nest_count` even when `index >= MAX_MC_EVT`, so `get_mce_event()` (`release == true`) must decrement `mce_nest_count` whenever `index >= 0`. `machine_check_ue_event()`/`machine_check_queue_event()` must decrement `mce_ue_count`/`mce_queue_count` when `index >= MAX_MC_EVT`, and `machine_process_ue_event()`/`machine_check_process_queued_event()` must decrement on every iteration including `ignore_event`. [F153, F154]
- In `mce_handle_derror()`, the loop over `table[]` must continue after the first matching `dsisr_value` to flush all affected hardware structures (SLB, ERAT, TLB), while using `found` to populate `mce_err` and `*addr` only from the first match (requiring uncorrectable errors to be ordered first in `mce_p*_derror_table`). [F258]
- In `iommu.c`, `tbl->it_map` and `struct iommu_pool` (`start`, `end`, `hint`) use 0-based indices relative to `tbl->it_offset`, whereas hardware TCE callbacks (`tbl->it_ops->set`, `clear`, `get`) take absolute TCE indices (`entry = bitmap_index + tbl->it_offset`). [F221]
- In `module_64.c` and `module_32.c`, every `SHT_RELA` section must be sorted with `sort(..., relacmp, NULL)` before `count_relocs()`/`count_pcpu_relocs()`. In `module_64.c`, `get_got_size()` must start with `relocs = 1` to zero-terminate `.mygot`; `.stubs` allocations in `stub_for_addr()` and `setup_ftrace_ool_stubs()` must check and advance `me->arch.stub_count` (rounding `ool_stubs` up to `sizeof(struct ppc64_stub_entry)`); and `struct ppc64_stub_entry` must keep 8-byte alignment with `offsetof(..., funcdata) == 32`. [F227, F228, F229, F251, F274]
- In `fadump_add_mem_range()`, adjacent memory ranges must not be folded when `start < fw_dump.boot_mem_top`, and if `mrange_info->is_static` is true, reaching `max_mem_ranges` must return `-ENOSPC` instead of calling `fadump_alloc_mem_ranges()`. In `fadump_free_mem_ranges()`, when `is_static` is true it must only reset `mem_range_cnt = 0` without freeing `mem_ranges` or clearing `name`. [F203, F233]
- When a thread's PC changes while any `bp_per_reg` slot has `perf_single_step` set, `thread_change_pc()` must clear `MSR_SE`, call `__set_breakpoint(i, info)`, and clear `info->perf_single_step = false`. In `hw_breakpoint_validate_len()` and `set_dawr()`, `hw->hw_len` is the byte length `[start_addr, end_addr)` (checking `ALIGN_DOWN(start_addr, SZ_512) == ALIGN_DOWN(end_addr - 1, SZ_512)` on pre-ISA v3.1), while DAWRX `MRD` encodes `((brk->hw_len + 7) >> 3) - 1`. [F212, F235]

## Synchronization

- In `prep_irq_for_enabled_exit()`, `exit_must_hard_disable()` must be evaluated once into a local boolean and reused across `__hard_EE_RI_disable()` and the `lazy_irq_pending_nocheck()` recovery path; `trace_hardirqs_on()` must run before `__hard_EE_RI_disable()` clears `MSR_RI`, and on recovery `PACA_IRQ_HARD_DIS` must be set and `__hard_RI_enable()` called before `trace_hardirqs_off()`. [F163, F308]
- In `interrupt_exit_kernel_prepare()`, `kuap_get_and_assert_locked()` must be read before `prep_irq_for_enabled_exit()` and restored via `kuap_kernel_restore()` at the end; `PACA_IRQ_HARD_DIS` must only be cleared when `!arch_irq_disabled_regs(regs)` and `prep_irq_for_enabled_exit()` succeeds, and pending IRQs on enabled exit must be drained via `hard_irq_disable()` and `replay_soft_interrupts()` rather than `local_irq_enable()`. [F309, F310]
- In `arch_local_irq_restore()`, testing `local_paca->irq_happened == 0` and storing `IRQS_ENABLED` to `local_paca->irq_soft_mask` must execute within an `asm goto` block registered with `RESTART_TABLE`. `replay_soft_interrupts_irqrestore()` must be bracketed by `irq_enter()`/`irq_exit()` and jump back to `again` if `local_paca->irq_happened != PACA_IRQ_HARD_DIS` after `irq_exit()`, while `__replay_soft_interrupts()` must keep `PACA_IRQ_REPLAYING` set and use `local_paca`. [F166, F169, F312]
- `iommu_range_alloc()` must take `spin_lock_irqsave(&pool->lock, flags)` and, when switching pools, unlock the old `pool->lock` and lock the new `pool->lock` with IRQs kept disabled. In `__iommu_free()`, `tbl->it_ops->clear(tbl, entry, npages)` must clear hardware TCEs before `bitmap_clear()` under `pool->lock`, and after setting TCEs in `iommu_alloc()`, `ppc_iommu_map_sg()`, or `iommu_flush_tce()`, `tbl->it_ops->flush(tbl)` (if present) followed by `mb()` must be called. [F170, F171, F298]
- `machine_check_early()` runs in NMI real-mode where `printk` and blocking calls are forbidden: console logging must be deferred via `mce_irq_work_queue()`, and `mce_notifier_list` / `memory_failure()` deferred to `machine_process_ue_event()`. In `mce_power.c`, real-mode handlers must skip host flushes, page-table walks, and UE recovery when `mce_in_guest()` is true, and guard `addr_to_pfn()` / `mce_find_instr_ea_and_phys()` with `get_paca()->in_mce < MAX_MCE_DEPTH`. [F317, F318]
- `fadump_mutex` must be held across checking `fw_dump.dump_active` or `fw_dump.dump_registered` and invoking `fadump_cleanup()`, `register_fadump()`, `fadump_unregister()`, or `fadump_region_show()`. In `fadump_process()`, `fw_dump.ops->fadump_process()` must succeed before publishing `elfcorehdr_addr`, while `release_mem_store()` and `fadump_free_elfcorehdr_buf()` must call `vmcore_cleanup()` and set `elfcorehdr_addr = ELFCORE_ADDR_ERR` before freeing buffers or dump memory. [F175, F176]
- `ppc_after_tlbiel_barrier()` must execute `ptesync` followed by `PPC_CP_ABORT` on `CPU_FTR_ARCH_31` (POWER10+). For VAS user windows, `vas_user_win_add_mm_context()` must issue `PPC_CP_ABORT` after `mm_context_add_vas_window()`, and all accesses to `struct vas_user_win_ref.vma` across `mmap()` and DLPAR close/reopen paths must be serialized by `mmap_mutex`. [F15, F16, F17]

## Object Lifetimes

- In `cacheinfo.c`, every `struct cache` from `new_cache()` must be torn down via `release_cache()` under the CPU hotplug lock only when `shared_cpu_map` is empty across `next_local`. `cacheinfo_create_index_dir()` must set `index_dir->cache` before `kobject_init_and_add()`. During `cacheinfo_cpu_offline()`, `remove_cache_dir()` must remove sysfs (saving `next = index->next` before `kobject_put(&index->kobj)`) and clear `cache_dir_pcpu` before `cache_cpu_clear()` walks `next_local` (saving `next = cache->next_local` before `release_cache()`). [F1, F4, F5, F9, F31, F72, F73, F121]
- `iommu_tce_table_get()` must use `kref_get_unless_zero(&tbl->it_kref)`, and `iommu_table_free()` must call `iommu_debugfs_del(tbl)` before freeing `tbl->it_map` and `tbl`. Conversely, `iommu_init_table()` must allocate `tbl->it_map`, reserve page 0 and `[res_start, res_end)`, initialize pool spinlocks, and run `iommu_table_clear()` before `iommu_debugfs_add()`. In `iommu_alloc_coherent()` and `iommu_free_coherent()`, TCE mappings must be freed via `iommu_free()` before `free_pages()`, and `free_pages()` must be called if `iommu_alloc()` fails. [F146, F174, F287]
- `arch_prepare_kprobe()` must only allocate `p->ainsn.insn` via `get_insn_slot()` after all validations succeed, and `arch_remove_kprobe()` must call `free_insn_slot(p->ainsn.insn, 0)` and set `p->ainsn.insn = NULL`. In `kprobe_handler()`, once `preempt_disable()` and `set_current_kprobe()` run (saving any running kprobe via `save_previous_kprobe(kcb)`), every exit path not entering `prepare_singlestep()` must restore/reset `current_kprobe` and call `preempt_enable()`. [F149, F150, F213]
- `hw_breakpoint_handler()` must hold `rcu_read_lock()` while accessing per-CPU `bp_per_reg` slots, wrap `__get_user_instr()` in `wp_get_instr_detail()` with `pagefault_disable()`/`pagefault_enable()`, and use `perf_event_disable_inatomic()` on error paths; whenever a breakpoint in `bp[i]` is disabled, one-shot, or single-stepped, `bp[i]` must be set to `NULL` before `goto reset`. `arch_uninstall_hw_breakpoint()` and `flush_ptrace_hw_breakpoint()` must clear `bp_per_reg[i]` and `t->ptrace_bps[i]` to `NULL`. [F152, F198, F319, F320]

## API Contracts

- Callers of `unsafe_get_user()`, `unsafe_put_user()`, and `unsafe_copy_{from,to}_user()` must open KUAP with `user_*_access_begin()` and close it with `user_*_access_end()` on both normal and fault paths. `get_user(x, ptr)` and `__get_user_size_allowed()` must zero `x` (including both words of a 64-bit load on 32-bit PowerPC) on fault or `access_ok()` failure, and callers of `__get_user_atomic_128_aligned(kaddr, uaddr, err)` must call `enable_kernel_vmx()` and initialize `err = 0` beforehand. [F24, F25, F52]
- In `asm/syscall.h`, `syscall_get_arguments()` and `syscall_set_arguments()` must access argument 0 in both `regs->orig_gpr3` and `regs->gpr[3]`, `syscall_get_arguments()` and `syscall_get_arch()` must test `is_tsk_32bit_task(task)` (not `is_32bit_task()`) to mask arguments with `0xffffffffUL`, and `syscall_get_nr()` must return `int` so a 32-bit `0xffffffff` in `regs->gpr[0]` sign-extends to `-1`. [F59, F66, F133]
- `prep_irq_for_idle()` and `prep_irq_for_idle_irqsoff()` must call `__hard_irq_disable()` and set `PACA_IRQ_HARD_DIS` before checking `lazy_irq_pending()`, returning `false` with IRQs hard-disabled if pending; when `prep_irq_for_idle_irqsoff()` returns `true`, the caller must pair it with `fini_irq_for_idle_irqsoff()` on wakeup. In `irq_set_pending_from_srr1()`, `IRQ_SYSTEM_RESET` must be dispatched immediately via `replay_system_reset()` with `in_nmi = 1` (`srr1_to_lazyirq[0]` must remain `0`), and `PACA_IRQ_DBELL` must call `ppc_msgclr(PPC_DBELL_MSGTYPE)`. [F160, F238, F305, F314]
- In `iommu.c`, TCE page counts must use `IOMMU_PAGE_SIZE(tbl)` / `IOMMU_PAGE_ALIGN(size, tbl)` and mask addresses with `IOMMU_PAGE_MASK(tbl)`; callers of `iommu_range_alloc()`, `iommu_alloc()`, `iommu_init_table()`, and `iommu_table_reserve_pages()` must right-shift byte-level DMA masks and reserved ranges (`res_start`, `res_end`) by `tbl->it_page_shift`; optional `tbl->it_ops` callbacks (`flush`, `get`, `free`, `tce_kill`) must be NULL-checked; and DMA/IOMMU callbacks must check `dev_is_pci(dev)` before `to_pci_dev(dev)`. [F182, F183, F199, F262, F325]
- In `module_64.c` and `module_32.c`, `stub_for_addr()`, `got_for_addr()`, and `do_plt_call()` return `0` on failure (not negative errno), which callers (`apply_relocate_add()`, `module_finalize_ftrace()`) must translate to `-ENOENT` or `-EFAULT`, whereas `get_stubs_size()` and `get_got_size()` return an `unsigned long` byte size and must treat `__patchable_function_entries` as optional rather than returning a negative errno. [F191, F248]
- Before dereferencing `kprobe->ainsn.insn` (such as via `ppc_inst_read()` in `arch_prepare_kprobe()`), callers must check `!kprobe_ftrace(prev)` because ftrace-based kprobes do not allocate an instruction slot in `ainsn.insn`. [F179]

## Error Handling

- `fix_alignment()` and `emulate_spe()` must return `1` when an unaligned instruction is emulated, `-EFAULT` on instruction fetch or user operand access fault, and `0` or a negative errno (`-EIO`/`-EINVAL` without kernel `WARN` for unaligned copy/paste or LARX/STCX) when not emulated; because `emulate_dcbz()` and `emulate_loadstore()` return `0` on success, `fix_alignment()` must translate their `0` return to `1`. [F21, F70, F140]
- In `ppc_iommu_map_sg()`, `outs->dma_length` of the first scatterlist entry must be initialized to `0` before the loop, each failed segment's `s->dma_length` reset to `0` on rollback, and when `outcount < incount` on success the entry after the last output segment must have `dma_length = 0` to terminate `ppc_iommu_unmap_sg()`. [F184]
- In `fadump_alloc_mem_ranges()`, if `krealloc(mrange_info->mem_ranges, new_size, GFP_KERNEL)` returns `NULL`, `fadump_free_mem_ranges(mrange_info)` must be called to free the existing `mrange_info->mem_ranges` buffer and zero its tracking fields, and any caller caching `mrange_info->mem_ranges` (such as `fadump_add_mem_range()`) must reload the pointer after `fadump_alloc_mem_ranges()`. [F156, F202]

## External Contracts

- `syscall_get_error()` and `syscall_set_return_value()` must branch on `trap_is_scv(regs)`: `scv` syscalls encode errors as negative `IS_ERR_VALUE` values in `regs->gpr[3]`, whereas non-`scv` syscalls set `0x10000000UL` (`SO`) in `regs->ccr` with a positive error code in `regs->gpr[3]`. On 32-bit/compat (`asm/syscalls.h`), 64-bit syscall arguments must be split into two 32-bit parameters with a dummy padding parameter when starting in an even GPR (`r4`, `r6`, `r8`), and `asm/syscall_wrapper.h` must use the `sys_` prefix. [F26, F62, F113]

## Known Pitfalls

- In `asm/uaccess.h`, 64-bit non-prefixed inline assembly for `std` and `ld` (`__put_user_asm2_goto`, `__get_user_asm2_goto`) must use `DS_FORM_CONSTRAINT` (`"YZ<>"` on GCC, `"Z<>"` on Clang) rather than `"m<>"` so displacements are 4-byte-aligned. In `simple_spinlock.h`, 4-operand `lwarx` must pass `IS_ENABLED(CONFIG_PPC64)` as the 4th (`eh`) operand rather than `1`. In `call_do_irq()` and `call_do_softirq()`, `[sp]` must use constraint `"b"` (excluding `r0`). [F108, F111, F316]
- In `iommu.c`, `iommu_table_reserve_pages()` must use an `unsigned long` loop counter over `[tbl->it_reserved_start, tbl->it_reserved_end)` to avoid 32-bit signed overflow on DDW offsets; `ppc_iommu_map_sg()` and `iommu_map_page()` must guard `PAGE_SHIFT - tbl->it_page_shift` with `tbl->it_page_shift < PAGE_SHIFT`; `dma_iommu_dma_supported()` must call `get_iommu_table_base(dev)` only after `dma_iommu_bypass_supported()` returns false; and `fail_iommu_setup()` must use separate `notifier_block` structs for `pci_bus_type` and `vio_bus_type`. [F204, F206, F261, F264]
- In `apply_relocate_add()` (`module_64.c`), `R_PPC64_TOC16_HA` and `R_PPC64_REL16_HA` must compute `(value + 0x8000) >> 16`. In `module_32.c`, `module_trampoline_target()` must subtract `0x10000` when bit `0x8000` of the `ADDI` immediate is set, and `patch_location_16()` must align the target pointer down via `PTR_ALIGN_DOWN(loc, sizeof(u32))` and preserve the upper 16 bits before calling `patch_instruction()`. [F230, F268, F269]
- `addr_to_pfn()` returns `ULONG_MAX` (not `0`) on failure, so `save_mce_event()` and `mce_handle_error()` must use `ULONG_MAX` as the unmapped physical address sentinel. In `hmi_exception_realmode()`, the return value of `hmi_handle_debugtrig()` must be stored in a signed variable and early-return only when `ret >= 0` (`-1` means unhandled causes remain). In `wp_get_instr_detail()`, `*ea` from `analyse_instr()` must be masked with `0xffffffffUL` when `!(regs->msr & MSR_64BIT)`. [F188, F190, F270]
