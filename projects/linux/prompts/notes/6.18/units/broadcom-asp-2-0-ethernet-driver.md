# BROADCOM ASP 2.0 ETHERNET DRIVER

Linux platform and network device driver for the Broadcom STB ASP 2.0/3.0 Ethernet controller (`brcm,asp-v2.1`, `brcm,asp-v2.2`, `brcm,asp-v3.0`). `bcmasp.c` manages shared clocks, L2/WoL interrupts, MAC destination address (MDA) filters, and ethtool RX network wake filters; `bcmasp_intf.c` and `bcmasp_ethtool.c` implement per-port interfaces (`struct bcmasp_intf`) with UniMAC, RGMII/EPHY, TX SPB DMA, RX EDPKT DMA rings, and ethtool support.

## Architecture & Data Flow
- `struct bcmasp_desc::buf` packs a 40-bit DMA address in bits 39:0 (`DESC_ADDR`) and flags in bits 63:40 (`DESC_FLAGS`). `bcmasp_probe` must not exceed `DMA_BIT_MASK(40)`, `buf` flag macros (`DESC_CHKSUM`, `DESC_CRC_ERR`, `DESC_RX_SYM_ERR`, `DESC_NO_OCT_ALN`, `DESC_PKT_TRUC`) must use `BIT_ULL`/`GENMASK_ULL`, and `bcmasp_rx_poll` must mask `DESC_ADDR(desc->buf)` before computing `data`, `dma_sync_single_for_cpu`, or `bcmasp_intf_rx_buffer_write`. [F84, F85, F119]
- DMA ring `_END` and `_VALID` registers (`TX_SPB_DMA_END/VALID`, `RX_EDPKT_DMA_END/VALID`, `RX_EDPKT_RING_BUFFER_END/VALID`) store inclusive last-byte addresses (`base + size - 1`) advanced via `incr_last_byte`, while `_BASE`, `_READ`, and `_WRITE` store first-byte addresses advanced via `incr_first_byte`. `sizeof(struct bcmasp_desc)` must equal `DESC_SIZE`. [F63, F92]
- `bcmasp_tx_reclaim` and `bcmasp_clean_txcb` only clear `intf->tx_cbs` and not `intf->tx_spb_cpu`, so `bcmasp_xmit` must zero each `struct bcmasp_desc` before OR-ing `DESC_SOF`, `DESC_EPKT_CMD`, `DESC_EOF`, or `DESC_INT_EN` into `desc->flags`; `DESC_EPKT_CMD` is set on the first descriptor (`!i`, with `DESC_SOF`) iff `bcmasp_csum_offload` set `csum_hw = true`. [F26, F125]
- `bcmasp_tx_reclaim` must unmap DMA, clear `intf->tx_cbs[intf->tx_spb_clean_index]` via `bcmasp_clean_txcb`, and advance `tx_spb_clean_index` (`incr_ring`) and `tx_spb_dma_read` (`incr_first_byte`) in lockstep until `tx_spb_dma_read` reaches `bcmasp_intf_tx_read(intf)`. [F40]
- In `bcmasp_rx_poll`, `RX_EDPKT_CFG_CFG0_EFRM_STUF` (`bcmasp_init_rx`) and `intf->crc_fwd` (`UMC_CMD_CRC_FWD`) require `skb_pull(skb, 2)` (`len -= 2`) and, when `intf->crc_fwd` is set, `skb_trim(skb, len - ETH_FCS_LEN)` (`len -= ETH_FCS_LEN`) before `eth_type_trans` and `rx_bytes` accounting; however, every path (including drops via `goto next`) must pass the unadjusted `DESC_ADDR(desc->buf) + desc->size` to `bcmasp_intf_rx_buffer_write` and advance `rx_edpkt_dma_read` (`incr_first_byte`) and `rx_edpkt_index` (`incr_ring`) in lockstep before `bcmasp_intf_rx_desc_write`. [F41, F54, F89]
- Each wake filter spans an even-indexed pair of slots (`hw_index`, `hw_index + 1`) in `priv->net_filters` where `bcmasp_netfilt_get_init` leaves `port = 0` on `hw_index + 1`: allocation requires an even index with both slots unclaimed and marks both `claimed` and `wake_filter`, `bcmasp_netfilt_release` zeroes both, and per-port scans (`bcmasp_netfilt_suspend`, `bcmasp_netfilt_get_all_active`, `bcmasp_netfilt_get_active`) must skip odd indices `i` when `priv->net_filters[i].wake_filter && priv->net_filters[i - 1].wake_filter`. [F38, F61]
- Wake filters are written to hardware at suspend (`bcmasp_netfilt_suspend` -> `bcmasp_netfilt_wr_to_hw`, which first zeroes registers via `bcmasp_netfilt_reset_hw`), and `bcmasp_core_init_filters` on resume must disable `ASP_RX_FILTER_NET_CFG(i)` in hardware without clearing `priv->net_filters[i]`. [F50]
- Network filter registers require 4-byte aligned accesses within `MAX_WAKE_FILTER_SIZE` (256): `bcmasp_netfilt_wr_m_wake` must check `(offset + size) <= MAX_WAKE_FILTER_SIZE`, read `match`/`mask` as unsigned `u8 *` before `<< ((3 - (offset % 4)) * 8)`, preload via `bcmasp_netfilt_rd` at `ALIGN_DOWN(offset, 4)` when `first_byte` is true and (`offset % 4 != 0` or `size < 3`), and reset `first_byte = true` whenever a 4-byte word is flushed (`!size || ((offset % 4) == 3)`). [F68, F78, F86]
- `priv->mda_filters` reserves indices `0 .. bcmasp_total_res_mda_cnt(priv) - 1` for `ASP_RX_FILT_MDA`, so `bcmasp_disable_all_filters` and `bcmasp_set_en_mda_filter` must start at `bcmasp_total_res_mda_cnt(intf->parent)` and only touch enabled filters for `intf->port`; on filter exhaustion in `bcmasp_set_rx_mode` (`set_promisc`), it must call both `bcmasp_set_promisc(intf, 1)` and `bcmasp_disable_all_filters(intf)`. All MDA and net-filter loops/checks must use `priv->num_mda_filters` and `priv->num_net_filters` rather than `NUM_MDA_FILTERS`/`NUM_NET_FILTERS`. [F46, F52, F60]
- `umac_reset` leaves `UMC_CMD_SW_RESET` set in `UMC_CMD` and `umac_enable_set` returns early while it is set; `bcmasp_netif_init` calls `umac_reset` and sets `old_duplex = -1`, `old_link = -1`, and `old_pause = -1` so only `bcmasp_adj_link` (when link is up) or `bcmasp_suspend_to_wol` clears `UMC_CMD_SW_RESET` and sets `UMC_CMD_TX_EN | UMC_CMD_RX_EN | UMC_CMD_PROMISC`. [F51, F94]
- `priv->eee_fixup` is only set in `v22_plat_data` and `ndev->phydev` is `NULL` when closed (null-check both before calling `eee_fixup`); `priv->wol_irq` is `0` if absent/unregistered in `bcmasp_init_wol` (guard `ASP_WAKEUP_INTR2` accesses and `free_irq` with `priv->wol_irq > 0`); `bcmasp_init_tx` writes `TX_PAUSE_MAP_VECTOR` with `1 << (intf->channel + 8)` iff `intf->parent->tx_chan_offset != 0` (v2.1/v2.2, not v3.0); and `intf->internal_phy` (`PHY_INTERFACE_MODE_INTERNAL`) is only valid on `intf->port == 1` and guards `bcmasp_enable_phy_irq` and `PHY_MAC_INTERRUPT`. [F27, F28, F95, F101]
- `bcmasp_update_mib_counters` and `bcmasp_get_ethtool_stats` index `intf->mib` via `(char *)(&intf->mib) + (i * sizeof(u32))`, so `bcmasp_gstrings_stats` and `struct bcmasp_mib_counters` must match in order with `u32` fields, and `bcmasp_update_mib_counters` must `continue` on `BCMASP_STAT_SOFT` entries before `put_unaligned(val, (u32 *)p)`. [F76, F90]
- Fields added to `struct bcmasp_plat_data` (`v21_plat_data`, `v22_plat_data`, `v30_plat_data`) must be added to `struct bcmasp_priv` and copied in `bcmasp_set_pdata`; new ethtool RX flow types (`ETHER_FLOW`, `IP_USER_FLOW`, `TCP_V4_FLOW`, `UDP_V4_FLOW`, `TCP_V6_FLOW`, `UDP_V6_FLOW`) must be added in lockstep to `bcmasp_flow_insert`, `bcmasp_netfilt_check_dup`, and `bcmasp_netfilt_wr_to_hw`. [F56, F57]

## Synchronization
- Callers of `bcmasp_set_promisc`, `bcmasp_set_allmulti`, `bcmasp_set_broad`, `bcmasp_set_oaddr`, `bcmasp_set_en_mda_filter`, and `bcmasp_disable_all_filters` (e.g. `bcmasp_set_rx_mode`) must hold `spin_lock_bh(&intf->parent->mda_lock)` and never sleep; `intf->parent->net_filters` helpers (`bcmasp_netfilt_check_dup`, `bcmasp_netfilt_get_init`, `bcmasp_netfilt_release`, `bcmasp_netfilt_get_active`, `bcmasp_netfilt_get_all_active`) must hold `intf->parent->net_lock` across the entire operation. [F12, F15, F112]
- All updates to `ASP_CTRL_CLOCK_CTRL` and shadow `ASP_CTRL_SCRATCH_0` in `bcmasp_core_clock_set_ll` must hold `priv->clk_lock` (`spin_lock_irqsave`) and mirror changes to `ASP_CTRL_SCRATCH_0`, which `bcmasp_core_clock_set_intf` reads under `priv->clk_lock` to check `ASP_CTRL_CLOCK_CTRL_ASP_RGMII_MASK` before disabling shared TX/RX clocks. [F13, F102]
- In `bcmasp_xmit`, all fragment descriptors in `tx_spb_cpu` and entries in `tx_cbs` must be populated and ordered with `wmb()` before advancing `tx_spb_index` (`incr_ring`) and `tx_spb_dma_valid` (`incr_last_byte`) and calling `bcmasp_intf_tx_write`; on `dma_mapping_error` at fragment `i`, `bcmasp_clean_txcb` rolls back the `i` entries from `tx_spb_index`. In `bcmasp_rx_poll`, after `valid != intf->rx_edpkt_dma_read`, `rmb()` must precede reading `desc->buf`/`desc->size`, and `dma_sync_single_for_cpu` on `DESC_ADDR(desc->buf)` must precede reading `rx_ring_cpu`. [F16, F17, F39]
- Process-context callers of `bcmasp_tx_reclaim` (`bcmasp_netif_deinit`) must call `napi_disable(&intf->tx_napi)` first and `bcmasp_tx_reclaim` must use `dev_consume_skb_any`; `intf->stats64` updates in `bcmasp_tx_reclaim` and `bcmasp_rx_poll` must use `u64_stats_update_begin(&stats->syncp)` / `u64_stats_update_end(&stats->syncp)`. [F18, F120]

## Object Lifetimes
- In `bcmasp_xmit`, `NETDEV_TX_BUSY` is returned without freeing `skb` only when `tx_spb_ring_full` is true upfront; later failures return `NETDEV_TX_OK` and consume `skb` (`skb_put_padto` frees on error; `dma_mapping_error` calls `dev_kfree_skb(skb)` after `bcmasp_clean_txcb`). Every fragment sets `txcb->skb = skb`, but only `i == nr_frags` sets `txcb->last = true` (with `DESC_EOF`), and `bcmasp_tx_reclaim` consumes `txcb->skb` and updates `tx_packets`/`tx_bytes` only when `txcb->last` is true. [F1, F128]
- Ring memory (`rx_ring_cpu`, `rx_edpkt_cpu`, `tx_spb_cpu`, `tx_cbs`, allocated in `bcmasp_alloc_buffers` and unwound in reverse order on error or in `bcmasp_reclaim_free_buffers`) and `dev->phydev` persist from `bcmasp_open` to `bcmasp_stop` across suspend/resume: `bcmasp_netif_deinit` only calls `phy_stop(dev->phydev)` (only `bcmasp_stop` calls `phy_disconnect` and `bcmasp_reclaim_free_buffers`), and `bcmasp_interface_resume` passes `phy_connect = false` to `bcmasp_netif_init`. [F4, F6, F131]
- In `bcmasp_netif_init` and `bcmasp_netif_start`, interface clocks (`bcmasp_core_clock_set_intf`) and EPHY (`bcmasp_ephy_enable_set`) or RGMII (`bcmasp_rgmii_mode_en_set`) must be enabled before `bcmasp_configure_port`, `of_phy_connect`, or UniMAC/DMA accesses; TX/RX rings and NAPI (`netif_napi_add_tx`, `netif_napi_add`, `napi_enable`) must be initialized before unmasking IRQs (`bcmasp_enable_rx_irq`, `bcmasp_enable_tx_irq`, `bcmasp_enable_phy_irq`); and every `netif_napi_add*` must be paired with `netif_napi_del` in `bcmasp_netif_deinit` and error paths. [F5, F20, F99]
- On teardown (`bcmasp_stop`, `bcmasp_netif_deinit`), `netif_tx_disable` and `napi_disable`/`netif_napi_del` on `tx_napi` and `rx_napi` must run, and after `bcmasp_enable_tx(intf, 0)`, the driver must set `TX_SPB_DMA_FIFO_FLUSH` in `TX_SPB_DMA_FIFO_CTRL`, poll `TX_SPB_DMA_FIFO_STATUS` until it clears, and clear `TX_SPB_DMA_FIFO_CTRL` before `bcmasp_tx_reclaim` and `bcmasp_reclaim_free_buffers`. [F21, F108]
- `bcmasp_probe` must enable `priv->clk`, internal clocks (`bcmasp_core_clock_set`), and main clock (`priv->core_clock_select(priv, false)`) before MMIO accesses, add all `bcmasp_intf` instances to `priv->intfs` before calling `register_netdev` on any interface (so `bcmasp_total_res_mda_cnt` sees the full `list_count_nodes(&priv->intfs)`), and disable internal clocks and `priv->clk` before `register_netdev`. [F97, F98]
- `bcmasp_remove_intfs` must use `list_for_each_entry_safe` and unlink `&intf->list` before `bcmasp_interface_destroy(intf)`, which calls `of_phy_deregister_fixed_link(intf->ndev_dn)` (if fixed-link) after `unregister_netdev` (if `NETREG_REGISTERED`) and before `free_netdev`. [F77, F107]
- In `bcmasp_resume`, `bcmasp_core_init` and `bcmasp_core_init_filters` must precede `bcmasp_interface_resume` (as `bcmasp_core_init_filters` clears `priv->mda_filters[i].en` and MDA registers that `bcmasp_interface_resume` reprograms); in `bcmasp_enable_wol`, `enable_irq_wake(priv->wol_irq)` / `device_set_wakeup_enable` must be gated by `priv->wol_irq_enabled_mask` transitions between 0 and non-zero under `priv->wol_lock`. [F10, F22]

## API Contracts
- Despite its comment, `bcmasp_netfilt_get_init` returns `ERR_PTR` (`-EINVAL` or `-EBUSY`) and never `NULL` (check `IS_ERR()`); its `loc` parameter must be an unsigned `u32` checked against `priv->num_net_filters` (when not `RX_CLS_LOC_ANY`) before indexing `priv->net_filters[loc]`. [F23, F58]
- `bcmasp_flow_insert` must set `cmd->fs.location = nfilter->hw_index` before copying `cmd->fs` to `nfilter->fs`, and `bcmasp_netfilt_get_all_active` must check `j == *rule_cnt` (returning `-EMSGSIZE`) only after confirming `priv->net_filters[i]` is an active non-companion filter for `intf->port` right before `rule_locs[j++]`. [F59, F133]
- `bcmasp_csum_offload` only sets `*csum_hw = true` when pushing `struct bcmasp_pkt_offload`, so callers must initialize `csum_hw = false`; when `skb->ip_summed == CHECKSUM_PARTIAL`, it must verify IPv4/IPv6 TCP/UDP and call `skb_cow_head(skb, sizeof(*offload))` before `skb_push`, falling back to `skb_checksum_help(skb)` without setting `*csum_hw` on failure. [F25, F124]
- `struct bcmasp_intf` uses `intf->index` for reserved MDA slots in `ASP_RX_FILT_MDA`, `intf->port` (DT `reg`) for UniMAC/RGMII/filter ports and WoL bitmasks, and `intf->channel` (DT `brcm,channel`) for DMA ring offsets and `ASP_INTR2_*` shifts; in `ASP_CTRL_CLOCK_CTRL`/`ASP_CTRL_SCRATCH_0`, set bits disable clocks (`ASP_CTRL_CLOCK_CTRL_ASP_*_DISABLE`), so `bcmasp_core_clock_set` and `bcmasp_core_clock_set_ll` enable clocks via `clr` and disable via `set`. [F30, F31]
- `struct ethtool_rx_flow_spec` users must mask `fs->flow_type & ~(FLOW_EXT | FLOW_MAC_EXT)` and compare only the active `h_u`/`m_u` union member's size; `bcmasp_netif_init` sets `phydev->mac_managed_pm = true` so suspend/resume use `phy_stop`/`phy_start` rather than `phy_suspend`/`phy_resume`; `bcmasp_tx_poll` (`netif_napi_add_tx`) reclaims all TX descriptors, calls `napi_complete` and `bcmasp_enable_tx_irq`, and returns `0`, while `bcmasp_rx_poll` calls `napi_complete_done` and `bcmasp_enable_rx_irq` only when `processed < budget` and returns `processed`. [F33, F96, F129]

## Error Handling
- `bcmasp_interface_create` returns `NULL` on failure, so `bcmasp_probe` must set `ret` to a negative errno before `goto of_put_exit`. [F24]

## External Contracts
- `bcmasp_rmon_ranges`, `bcmasp_of_match`, and `bcmasp_mdio_of_match` must end with `{}`; `bcmasp_get_wol` must zero `wol->sopass` and copy `intf->sopass` only when `wol->wolopts & WAKE_MAGICSECURE` is set. [F72, F132]

## Known Pitfalls
- Because `skb_cow_head` and `skb_put_padto` can reallocate `skb->head` and `bcmasp_csum_offload` prepends `sizeof(struct bcmasp_pkt_offload)`: `total_bytes` (`txcb->bytes_sent`) must be sampled from `skb->len` before `bcmasp_csum_offload`, header pointers and `skb_push` evaluated after `skb_cow_head`, fragment 0 `size` sampled from `skb_headlen(skb)` after `bcmasp_csum_offload` and updated to `skb->len` after `skb_put_padto`, and `dma_map_single` on `skb->data` called last. [F44, F93]
- `bcmasp_csum_offload` splits the 12-bit L3 header length across `PKT_OFFLOAD_HDR_SIZE_2((len >> 8) & 0xf)` and `PKT_OFFLOAD_HDR2_SIZE_2(len & 0xff)`; `bcmasp_addr_to_uint` and `bcmasp_suspend_to_wol` (`UMC_PSW_*`) pack bytes 0..1 into high/MS and 2..5 into low/LS registers, whereas `umac_set_hw_addr` packs bytes 0..3 into `UMC_MAC0` and 4..5 into `UMC_MAC1`. [F69, F88]
- In `bcmasp_netif_init`, `bcmasp_configure_port` must program `RGMII_PORT_CNTRL` and `RGMII_OOB_CNTRL` from raw `intf->phy_interface` before `_RGMII`/`_TXID` are remapped to `_ID`/`_RXID` for `of_phy_connect`; in `bcmasp_suspend`, `ret` from `bcmasp_interface_suspend` is overwritten by `ret = clk_prepare_enable(priv->clk)`. [F34, F100]
