# NETWORKING [ETHTOOL]

`net/ethtool` implements the core ethtool subsystem, including Generic Netlink (`ethtool` family), the legacy `SIOCETHTOOL` ioctl dispatcher (`dev_ethtool`), bitset/string helpers, and transceiver CMIS CDB firmware flashing.

## Architecture & Data Flow

- Command structs for `ethnl_request_ops` must embed `ethnl_req_info` or `ethnl_reply_data` at offset 0 (`req_info_size`/`reply_data_size` set to container sizes), and `orig_req_info` in `ethnl_notify()` must match. Because `reply_data` is `kmalloc()`ed and reused across dump iterations, `ethnl_init_reply_data()` must zero it and set `reply_data->dev` before each `ops->prepare_data()`, which must read `reply_base->dev` (not `req_base->dev`, which is `NULL` in non-per-PHY dumps). [F45, F69, F136]
- `ethnl_reply_header_size()` must reserve `IFNAMSIZ` rather than `strlen(dev->name)` so a rename after `ethnl_default_doit()` drops `rtnl_lock()` cannot overflow the SKB in `ethnl_fill_reply_header()`. Every `fill_reply` callback and `ethnl_fill_reply_header()` must never write more bytes than `reply_size` or `ethnl_reply_header_size()` estimated. [F21, F80]
- When `ethnl_request_ops` defines `.parse_request` for both GET and SET, both GET and SET `nla_policy` arrays must be sized to at least the highest attribute index read by `.parse_request` (marking SET-unsupported attributes `NLA_REJECT` or `NLA_UNSPEC`) because `ethnl_default_parse()` invokes `.parse_request` for both. [F82]
- Custom RSS contexts in `dev->ethtool->rss_ctx` use 1-based IDs in `XA_LIMIT(1, (ops->rxfh_max_num_contexts ?: U32_MAX) - 1)`, while context 0 is never in `rss_ctx` and must bypass `xa_load()`. After `ops->create_rxfh_context()` or `ops->modify_rxfh_context()` succeeds, the `ethtool_rxfh_context` entry must be updated in lockstep (`rss_set_ctx_update()`); for non-default contexts, `__rss_prepare_ctx()` sets `data->no_key_fields = !ops->rxfh_per_ctx_key` and `ethtool_get_rxfh()` zeros `rxfh_dev.key_size` when `!ops->rxfh_per_ctx_key`. [F63, F64, F91]
- Modifying context 0's RSS indirection table in `ethnl_rss_set()`, `ethtool_set_rxfh()`, or `ethtool_set_rxfh_indir()` must clear `IFF_RXFH_CONFIGURED` in `dev->priv_flags` on reset (`user_size == 0` or `rxfh.indir_size == 0`) and set it otherwise. New configurable fields in `struct ethtool_rxfh` must be copied to `useraddr` in `ethtool_get_rxfh()` and have their `*_NO_CHANGE` sentinel checked in `ethtool_set_rxfh()`, skipping the all-`NO_CHANGE` rejection when `create` (`rxfh.rss_context == ETH_RXFH_CONTEXT_ALLOC`) is true. [F62, F78, F111]
- Every `ETHTOOL_A_FLOW_*` in `1 .. __ETHTOOL_A_FLOW_CNT - 1` (`0` is `ETHTOOL_A_FLOW_UNSPEC`) must have matching entries in `ethtool_rxfh_ft_nl2ioctl[]` and `ethnl_rss_flows_policy[]`, and new hashable flow types in `ioctl.c` must be in `flow_type_hashable()`/`flow_type_v6()`; loops over `ethtool_rxfh_ft_nl2ioctl` and `data->flow_hash` must start at index 1 and use `-1` for unsupported types. [F79, F92]
- `ethtool_ringparam_get_cfg()` must overwrite `kparam->tcp_data_split` and `kparam->hds_thresh` from `dev->cfg->hds_config` and `dev->cfg->hds_thresh` after `ops->get_ringparam()`, and `ethtool_set_ringparam()` and `ethnl_set_rings()` must call `ethtool_ringparam_get_cfg()`. Whenever `ethnl_set_features()`, `ethtool_set_features()`, `ethtool_set_one_feature()`, or `__ethtool_set_flags()` modifies `dev->wanted_features`, it must call `__netdev_update_features(dev)`, and if `dev->features` changed, `netdev_features_change(dev)`. [F60, F67]
- In `coalesce.c`, `attr_to_mask()` maps `ETHTOOL_A_COALESCE_RX_USECS .. __ETHTOOL_A_COALESCE_CNT - 1` via `BIT(attr_type - ETHTOOL_A_COALESCE_RX_USECS)`, so `ETHTOOL_A_COALESCE_*` and `ETHTOOL_COALESCE_*` bits must stay 1-to-1 aligned. In `ethtool_rxnfc_copy_from_user()` and `ethtool_rxnfc_copy_to_user()`, copying `struct ethtool_rxnfc` and computing the `rule_locs` offset must branch on `compat_need_64bit_alignment_fixup()`. [F94, F99]

## Synchronization

- Across ethtool netlink and ioctl paths, locks must be acquired in strict order `rtnl_lock()` -> `netdev_lock_ops(dev)` -> `dev->ethtool->rss_lock` (or `phydev->lock`) and released in reverse. In `ethnl_request_ops`, `parse_request` and `set_validate` run unlocked with only a netdev reference held, `prepare_data` and `set` run under `rtnl_lock()` and `netdev_lock_ops(dev)`, and `reply_size`, `fill_reply`, and `cleanup_data` in `ethnl_default_doit()` and `ethnl_default_dump_one()` run after both locks are released. [F156, F157]
- `ethnl_ops_begin(dev)` must be called with `netdev_lock_ops(dev)` held and reject `!netif_device_present(dev) || dev->reg_state >= NETREG_UNREGISTERING`, balancing `pm_runtime_get_sync()` with `pm_runtime_put()` on failure so netlink ops do not touch destroyed locks after unregistration begins. `ethtool_op_get_link()` must call `__linkwatch_sync_dev(dev)` rather than `linkwatch_sync_dev(dev)` because callers already hold `rtnl_lock()` and `netdev_lock_ops(dev)`. [F19, F28]
- `ethnl_notify()` and `ethtool_notify()` require the caller to hold both `rtnl_lock()` and `netdev_lock_ops(dev)`. Callers of `ethtool_rss_notify()` with `ETHTOOL_MSG_RSS_NTF` or `ETHTOOL_MSG_RSS_CREATE_NTF` must release `dev->ethtool->rss_lock` beforehand because `rss_prepare_data()` acquires `rss_lock`. Callers of `ethtool_rxfh_context_lost()` must hold either `rtnl_lock()` or `dev->ethtool->rss_lock`. [F24, F33, F34]
- `ethnl_req_get_phydev()` must be called under `rtnl_lock()`, which must remain held while accessing the returned `phy_device`. In `linkstate_get_sqi()`, `linkstate_get_sqi_max()`, `get_phy_tunable()`, and `set_phy_tunable()`, `mutex_lock(&phydev->lock)` must be held while checking `phydev->link` and invoking `phydev->drv` callbacks. [F25, F41]
- `dev->irq_moder->rx_profile` and `tx_profile` must be updated under `rtnl_lock()` in `ethnl_update_profile()` via `rtnl_dereference()`, `rcu_assign_pointer()`, and `kfree_rcu()`, and read in `coalesce_fill_reply()` under `rcu_read_lock()` via `rcu_dereference()`. In `__ethtool_get_ts_info()`, `rcu_read_lock()` must be held across `rcu_dereference(dev->hwprov)` and the entire `ethtool_get_ts_info_by_phc(dev, info, &hwprov->desc)` call. [F35, F36]
- While `dev->ethtool->module_fw_flash_in_progress` is set, `ethnl_netdev_event()` must reject `NETDEV_PRE_UP` with `NOTIFY_BAD` and module/reset entry points (`module_get_power_mode()`, `ethnl_set_module_validate()`, `get_module_eeprom_by_page()`, `ethtool_get_module_info_call()`, `ethtool_get_module_eeprom_call()`, `ethtool_reset()`) must return `-EBUSY`. Because `module_flash_fw_work()` runs `ethtool_cmis_fw_update()` in workqueue context unlocked, `cmis_fw_update_reset()` must explicitly acquire and release `netdev_lock_ops(dev)` around `dev->ethtool_ops->reset()`. [F39, F40]

## Object Lifetimes

- Every `net_device` reference acquired by `ethnl_parse_header_dev_get()` is tracked in `req_info->dev_tracker` and must be released via `ethnl_parse_header_dev_put(req_info)` (or `netdev_put(req_info->dev, &req_info->dev_tracker)`), including in `ethnl_default_parse()` if `parse_request()` fails (resetting `req_info->dev = NULL`). Conversely, in `ethnl_default_notify()`, `req_info->dev` is a borrowed pointer under `ASSERT_RTNL()` and `netdev_ops_assert_locked(dev)` and must never allocate a tracker or call `netdev_put()`. [F1, F2, F4]
- Netlink dump `.start()` callbacks (`ethnl_default_start()`, `ethnl_perphy_start()`, `ethnl_rss_dump_start()`) must drop any `req_info->dev` reference from header parsing and set `req_info->dev = NULL`, saving at most `dev->ifindex`. In `ethnl_default_dumpit()` and `ethnl_perphy_dump_all_dev()`, `for_each_netdev_dump()` under `rcu_read_lock()` must pin `dev` via `netdev_hold(dev, &dev_tracker, GFP_ATOMIC)` before `rcu_read_unlock()` to call the sleeping dump helper, and re-acquire `rcu_read_lock()` before `netdev_put()`. [F26, F27]
- In `ethnl_default_set_doit()`, `dev->cfg_pending` is allocated with `kmemdup(dev->cfg, ...)` before `ops->set()`, swapped with `dev->cfg` only if `ops->set()` returns `>= 0`, and on every exit path after allocation `dev->cfg_pending` must be freed and reset to `dev->cfg` before `netdev_unlock_ops(dev)`. [F7]
- In `ethnl_rss_create_doit()` and `ethtool_set_rxfh()`, `ctx` is inserted into `dev->ethtool->rss_ctx` under `rss_lock` before `ops->create_rxfh_context()`, so if `create_rxfh_context()` fails, it must be erased with `xa_erase()` and freed. When deleting an RSS context in `ethnl_rss_delete_doit()` or `ethtool_set_rxfh()`, `ethtool_check_rss_ctx_busy()` and `ops->remove_rxfh_context()` must succeed under `rss_lock` before `xa_erase()` and `kfree(ctx)`. [F9, F11]
- In `struct rss_reply_data`, `data->indir_table` and `data->hkey` (`indir_size * sizeof(u32)` bytes into the buffer) share a single allocation starting at `data->indir_table`, so `rss_get_data_free()` must only call `kfree(data->indir_table)`. [F131]

## API Contracts

- In `ethnl_request_ops`, `.set_validate` and `.set` return negative errno on failure, `0` for no-op (`0` from `.set_validate` skips `.set`; `0` from `.set` suppresses `ethnl_notify()`), and `1` when valid/modified. In `ethnl_update_*()` helpers, `*mod` is only set to `true` and never cleared, so callers must initialize `mod = false`. [F42, F116]
- `ethnl_req_get_phydev()` returns `struct phy_device *`, `NULL`, or `ERR_PTR(-ENODEV)`; callers must check `IS_ERR()` and pass `tb` (`info->attrs`) and `header` separately without indexing `tb[header]` beforehand because `tb` is `NULL` during `ethnl_default_notify()`. `ethtool_rx_flow_rule_create()` and `ethtool_cmis_cdb_init()` return `ERR_PTR(-errno)` on failure (never `NULL`) after internal cleanup; callers must check `IS_ERR()` and free valid pointers with `ethtool_rx_flow_rule_destroy()` or `ethtool_cmis_cdb_fini()`. [F18, F43, F57]
- Driver stats structs (`ethtool_link_ext_stats`, `ethtool_fec_stats`, `ethtool_fec_hist::values`, `ethtool_pause_stats`) use `ETHTOOL_STAT_NOT_SET` (`~0ULL`) for unpopulated `u64` fields; initialize them via `ethtool_stats_init((u64 *)s, sizeof(*s) / 8)` and check `!= ETHTOOL_STAT_NOT_SET` before emitting. [F51]
- `ethnl_bitset_size()`, `ethnl_put_bitset()`, `ethnl_update_bitset()`, `ethnl_parse_bitset()`, `load_link_ksettings_from_user()`, and `store_link_ksettings_for_user()` take `unsigned long *` bitmaps and must convert via `bitmap_to_arr32()`/`bitmap_from_arr32()` on 64-bit big-endian, whereas `ethnl_bitset32_*()` take `u32 *` bitmaps, all with `nbits` in bits and compact word counts sized via `DIV_ROUND_UP(nbits, 32)`. [F53, F98, F125]
- `ethtool_sprintf()` and `ethtool_puts()` write at most `ETH_GSTRING_LEN` bytes into `*data` and advance `*data += ETH_GSTRING_LEN`. Strings in `ethnl_string_array_t` (`const char [][ETH_GSTRING_LEN]`) may lack a NUL terminator, so `ethnl_strz_size()`, `ethnl_put_strz()`, and `ethnl_name_to_idx()` must bound reads to `ETH_GSTRING_LEN` via `strnlen()`/`strncmp()`. [F135, F137]
- Kernel buffers for driver dumps/strings must be allocated to the full driver-reported size before clamping: `ethnl_get_priv_flags_info()` must allocate `nflags * ETH_GSTRING_LEN` from `ops->get_sset_count(dev, ETH_SS_PRIV_FLAGS)` for `ops->get_strings()` before clamping `nflags` to 32; `ethtool_get_dump_data()` must `vzalloc(tmp.len)` from `ops->get_dump_flag()` while capping `dump.len` to `min(tmp.len, dump.len)`; `ethtool_get_regs()` must allocate `ops->get_regs_len(dev)` and copy `min(regs.len, reglen)`. [F83, F84, F85]

## Error Handling

- In `ethnl_default_doit()`, `ethnl_default_dump_one()`, and `ethnl_default_notify()`, `ops->cleanup_data(reply_data)` is only called when `ops->prepare_data()` returns `>= 0`, so any `prepare_data` implementation that allocates memory must free it before returning a negative error. [F6]
- In `ethnl_default_dumpit()` and `ethnl_perphy_dump_all_dev()`, `ret` must be reset to `0` at the end of each `for_each_netdev_dump()` iteration after ignoring `-EOPNOTSUPP`, and any other negative error must return `skb->len` when `skb->len > 0` so already-dumped messages are not discarded. [F109]
- In `ethtool_get_ts_info_by_phc()`, both `-ENODEV` and `-EOPNOTSUPP` from `ethtool_net_get_ts_info_by_phc()` must fall back to `ethtool_phy_get_ts_info_by_phc()`, whose returned `struct phy_device *` is an `ERR_PTR` on failure (never `NULL`) and must be checked with `IS_ERR()`. In `ethtool_set_rxfh_fields()`, validation via `ops->get_rxfh` must only run when `ops->get_rxfh` is non-NULL. [F46, F48]

## External Contracts

- In `__dev_ethtool()`, `ns_capable(net->user_ns, CAP_NET_ADMIN)` is required for every `SIOCETHTOOL` command (checking `sub_cmd` at `useraddr + sizeof(ethcmd)` for `ETHTOOL_PERQUEUE`) except whitelisted `ETHTOOL_G*` queries. In `ethtool_genl_ops`, all `*_SET`/`*_ACT` ops plus `ETHTOOL_MSG_WOL_GET` and `ETHTOOL_MSG_MODULE_EEPROM_GET` must set `GENL_UNS_ADMIN_PERM`, scoping lookups and notifications to the socket/device netns. [F177, F178]
- Both `ethnl_set_features()` and `ethtool_set_features()` must reject with `-EINVAL` any mask with bits in `~NETIF_F_ETHTOOL_BITS` and restrict `dev->wanted_features` updates to `dev->hw_features`. In `ethtool_rxnfc_copy_struct()`, `ETHTOOL_GRXFH` and `ETHTOOL_SRXFH` must initially copy only `offsetof(struct ethtool_rxnfc, data) + sizeof(info->data)` bytes, and only copy `sizeof(struct ethtool_rxnfc)` if `info->flow_type & FLOW_RSS` is set (re-verifying `info->flow_type & FLOW_RSS` after the second copy). [F100, F186]

## Known Pitfalls

- Because `ethtool_rxnfc_copy_struct()` populates an uninitialized `struct ethtool_rxnfc` (and copies only up to `data` for non-`FLOW_RSS` `ETHTOOL_{G,S}RXFH`), `ethtool_set_rxnfc()` must gate accesses to `info.fs` on `cmd == ETHTOOL_SRXCLSRLINS`, and ntuple flow classification rules (`ETHTOOL_SRXCLSRLINS`/`ETHTOOL_GRXCLSRULE`) must read `FLOW_RSS` from `info.fs.flow_type` rather than top-level `info.flow_type`. In `ethtool_rxnfc_copy_to_user()`, `copy_to_user()` must receive `rxnfc` directly, not `&rxnfc`. [F47, F107, F129]
- In `ethnl_update_bitset32_verbose()`, an `ETHTOOL_A_BITSET_NOMASK` request must snapshot `bitmap` into `saved_bitmap` before clearing `bitmap`, skip setting `*mod` in the per-bit loop, and set `*mod = true` afterward only if `!ethnl_bitmap32_equal(saved_bitmap, bitmap, nbits)`. On 64-bit big-endian, `ethnl_update_bitset()` must pass a local `u32_mod = false` to `ethnl_update_bitset32()` and only call `bitmap_from_arr32()` and set `*mod = true` if `u32_mod` is true. [F65, F66]
- In `bitset.c`, `ethnl_lower_bits(n)` shifts by `32 - n % 32` (undefined when `n % 32 == 0`), so every caller must guard it with `if (n % 32)` or `if (nbits < 32)`. In `ethnl_bitmap_to_features()` and `ethtool_set_features()`, each word must be cast to `netdev_features_t` before left-shifting by `i * BITS_PER_LONG` or `32 * i`. [F96, F121]
- In `ethtool_set_rxfh()`, the userspace byte offset of the RSS hash key within `rss_config[]` is `rss_cfg_offset + user_indir_len`, where `user_indir_len` is `indir_bytes` only when `rxfh.indir_size != 0 && rxfh.indir_size != ETH_RXFH_INDIR_NO_CHANGE` (and 0 otherwise). In `ethtool_check_xfrm_rxfh()`, `ethtool_check_flow_types()`, and `ethtool_set_rxfh()`, any bitmask test on `input_xfrm` must first check `input_xfrm != RXH_XFRM_NO_CHANGE` (`0xff`). [F89, F106]
- In `ethtool_cmis_cdb_compose_args()`, the `u8` field `args->read_write_len_ext` must be populated exclusively via `ethtool_cmis_get_max_lpl_size(read_write_len_ext)` (at most 128) and never with an EPL max payload size that can exceed 255. In `ethtool_cmis_module_poll()`, pass `sizeof(*rpl)` (never `sizeof(rpl)`) to `ethtool_cmis_page_init()`. [F119, F128]
- `ethtool_forced_speed_maps_init()` mutates the passed `struct ethtool_forced_speed_map` array in place, so drivers must pass a non-`const` array during module init. [F155]
