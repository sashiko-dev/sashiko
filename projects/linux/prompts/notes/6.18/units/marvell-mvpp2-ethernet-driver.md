# MARVELL MVPP2 ETHERNET DRIVER

Core driver for the Marvell PPv2 (PPv2.1, PPv2.2, and PPv2.3) network packet processor on Armada 375 and Armada 7K/8K/CN913x SoCs, managing Buffer Manager pools, TX/RX queues, TCAM/SRAM header parser, C2/RSS classifiers, phylink MAC/PCS, XDP, and PTP timestamping.

## Architecture & Data Flow

- When `priv->percpu_pools` is non-zero, `port->pool_long` and `port->pool_short` are `NULL` and `priv->page_pool[]` is used; when zero, `priv->page_pool[]` is `NULL`, so callers must check `priv->percpu_pools` before dereferencing either. BM pool loops in `mvpp2_bm_init()`, `mvpp2_bm_pools_init()`, `mvpp2_bm_switch_buffers()`, and `mvpp2_remove()` must iterate up to `mvpp2_get_nrxqs(priv) * 2` (or `port->nrxqs * 2`) when `priv->percpu_pools` is enabled, and `MVPP2_BM_POOLS_NUM` otherwise. [F5, F45]
- Because `priv->page_pool[]` is shared across all ports, its DMA direction must be `DMA_BIDIRECTIONAL` whenever any port in `priv->port_list[]` has `port->xdp_prog` set and `DMA_FROM_DEVICE` otherwise, enforced via `mvpp2_check_pagepool_dma()` in `mvpp2_xdp_setup()`. XDP requires `port->priv->percpu_pools`, `port->dev->mtu <= MVPP2_MAX_RX_BUF_SIZE`, and `port->ntxqs >= num_possible_cpus() * 2` (the upper half `thread + port->ntxqs / 2` is dedicated to XDP TX). [F75, F98]
- In `mvpp2_rx()`, every iteration of `while (rx_done < rx_todo)` must either refill the BM pool via `mvpp2_rx_refill()` or jump to `err_drop_frame` to return the buffer, matching `mvpp2_rxq_status_update(port, rxq->id, rx_done, rx_done)`. In `mvpp2_poll()`, clear `1 << rxq->logic_rxq` from `cause_rx` only when `budget > 0` after `mvpp2_rx()`, and save remaining `cause_rx` into `qv->pending_cause_rx`. [F107, F112]
- `struct mvpp2_tx_desc` and `struct mvpp2_rx_desc` must remain 32 bytes (`MVPP2_DESC_ALIGNED_SIZE`). `bm_pool->virt_addr` is `u32 *`, but DMA alloc/free in `mvpp2_bm_pool_create()`/`destroy()` must use `bm_pool->size_bytes` (`2 * sizeof(u32) * size` on `MVPP21`, `2 * sizeof(u64) * size` on `MVPP22`/`23`). On PPv2.2/2.3, `dma_set_coherent_mask(&pdev->dev, DMA_BIT_MASK(32))` is required because all BM pools share `MVPP22_BM_POOL_BASE_ADDR_HIGH_REG` for the high 32 bits of their coherent rings. [F120, F121, F137]
- Every frame size constant passed to `MVPP2_RX_MAX_PKT_SIZE()` (`MVPP2_BM_SHORT_FRAME_SIZE`, `MVPP2_BM_LONG_FRAME_SIZE`, `MVPP2_BM_JUMBO_FRAME_SIZE`) must exceed `MVPP2_SKB_HEADROOM + MVPP2_SKB_SHINFO_SIZE` across all architectures (704 bytes when `L1_CACHE_BYTES` is 256). [F82]
- Whenever a parser TCAM entry is written via `mvpp2_prs_hw_write()` or invalidated via `mvpp2_prs_hw_inv()` under `priv->prs_spinlock`, `priv->prs_shadow[index].valid` (and `.lu` via `mvpp2_prs_shadow_set()` on write) must be updated in lockstep. [F63]
- In `[MVPP2_PE_FIRST_FREE_TID, MVPP2_PE_LAST_FREE_TID]`, double-VLAN entries (`mvpp2_prs_double_vlan_add()`) must be allocated low-to-high and kept strictly below single/triple-VLAN entries (`mvpp2_prs_vlan_add()`), which are allocated high-to-low. Double-VLAN AI IDs in `priv->prs_double_vlans[]` must be allocated starting at index 1 via `mvpp2_prs_double_vlan_ai_free_get()`, as AI 0 (`MVPP2_PRS_SINGLE_VLAN_AI`) is reserved for single-VLAN entries. [F96, F97]
- Per-port VLAN filter searches/removals (`mvpp2_prs_vid_range_find()`, `mvpp2_prs_vid_entry_add()`, `mvpp2_prs_vid_remove_all()`, `mvpp2_dbgfs_port_vid_show()`) must iterate only over `MVPP2_PRS_VID_PORT_FIRST(port->id)..MVPP2_PRS_VID_PORT_LAST(port->id)`. `mvpp2_prs_mac_del_all()` must only remove entries in `MVPP2_PE_MAC_RANGE_START..END` where `test_bit(port->id, &pmap)` is set, skipping broadcast and `port->dev->dev_addr`. [F64, F66]
- In `mvpp2_cls_c2_write()`, `MVPP22_CLS_C2_TCAM_DATA4` must be written last because writing `DATA4` flushes `TCAM_DATA0..4` and `TCAM_INV` into hardware. In `mvpp2_cls_c2_build_match()`, fields must be packed in packet-header order; when `FLOW_DISSECTOR_KEY_VLAN` is present, `vlan_id` is at `offs`, `vlan_priority` at `offs + 13`, and `offs` must advance by 16 bits before L4 ports. [F53, F59]
- In `cls_flows[]`, entries sharing a `flow_id` must be contiguous (`for_each_cls_flow_id` deduplicates against `cls_flows[i - 1].flow_id`), more specific entries (untagged masking `MVPP2_PRS_RI_VLAN_MASK` before tagged omitting it; L4 TCP/UDP before L3 IP and `MVPP22_FLOW_ETHERNET`) must precede less specific ones, `MVPP2_FL_*_TAG` entries must include `MVPP22_CLS_HEK_TAGGED`, and fragmented flows with `MVPP2_PRS_IP_MASK` in `ri_mask` must set `MVPP2_PRS_RI_IP_FRAG_TRUE` in `ri`. [F58, F101, F102, F103]
- In `mvpp2_ethtool_cls_rule_ins()`/`del()`, `port->rfs_rules[loc]`, `port->n_rfs_rules`, the C2 TCAM entry, and `MVPP2_CLS_FLT_C2_RFS` entries must be updated in lockstep, removing any existing rule at `efs->rule.loc` first. `mvpp22_port_rss_ctx_delete()` must delete active `FLOW_RSS` rules referencing `port_ctx` and clear `priv->rss_tables[rss_ctx] = NULL` and `port->rss_ctx[port_ctx] = -1`. In `mvpp2_rss_port_c2_enable()`/`disable()`, toggling `MVPP22_CLS_C2_ATTR2_RSS_EN` must update `c2.attr[0]` to the RSS context ID or `port->first_rxq`. [F70, F71, F72]

## Synchronization

- All accesses to Header Parser TCAM/SRAM indirect registers and `priv->prs_shadow` must hold `priv->prs_spinlock` via `spin_lock_bh()`/`spin_unlock_bh()`; `mvpp2_prs_hw_write()`, `__mvpp2_prs_init_from_hw()`, and `__mvpp2_prs_mac_promisc_set()` require the caller to hold it. In `mvpp2_prs_hw_write()`, all SRAM words (`MVPP2_PRS_SRAM_DATA_REG`) must be written before TCAM words (`MVPP2_PRS_TCAM_DATA_REG`), as writing TCAM clears `MVPP2_PRS_TCAM_INV_MASK` and activates the entry. [F22, F145]
- CM3 SRAM flow-control updates (`mvpp2_rxq_enable_fc()`, `mvpp2_rxq_disable_fc()`, `mvpp2_bm_pool_update_fc()`) must be gated on `priv->global_tx_fc` (or `port->tx_fc`, since `priv->cm3_base` is NULL when resource 2 is absent) and hold `port->priv->mss_spinlock` via `spin_lock_irqsave()` while clearing `FLOW_CONTROL_ENABLE_BIT` in `MSS_FC_COM_REG` before modifying registers and restoring it with `FLOW_CONTROL_UPDATE_COMMAND_BIT`. [F23, F140]
- In `mvpp2_bm_pool_put()`, `get_cpu()`/`put_cpu()` must pin the CPU for `thread = mvpp2_cpu_to_thread(port->priv, get_cpu())`, and if `test_bit(thread, &port->priv->lock_map)` is set, `port->bm_lock[thread]` must be held via `spin_lock_irqsave()`. Similarly, in `mvpp2_tx()`, when `test_bit(thread, &port->priv->lock_map)` is set, `port->tx_lock[thread]` must be held via `spin_lock_irqsave()` across descriptor allocation, `txq_pcpu`/`aggr_txq` updates, TX trigger, and timer/cleanup handling. [F24, F25]
- Execute `wmb()` before `mvpp2_aggr_txq_pend_desc_add()` in `mvpp2_tx()`/`mvpp2_xdp_finish_tx()` and before `mvpp2_rxq_status_update()` in `mvpp2_rx()`. Bit 0 of `port->state` must be set in `mvpp2_stop_dev()` and cleared only at the end of `mvpp2_start_dev()` (`mvpp2_xdp_xmit()` checks `test_bit(0, &port->state)`). In `mvpp2_xdp_setup()`, when `port->xdp_prog` transitions between NULL and non-NULL while `running && reset`, call `mvpp2_stop()` before `xchg(&port->xdp_prog, prog)` and `mvpp2_open()` after, while `mvpp2_rx()` uses `READ_ONCE()`. [F29, F30, F32]

## Object Lifetimes

- When `MVPP2_RXD_BUF_HDR` is set in `mvpp2_rx()`, the drop path must call `mvpp2_buff_hdr_pool_put()` to return the entire `mvpp2_buff_hdr` chain. When `pp` is non-NULL in `mvpp2_rx()`, call `skb_mark_for_recycle(skb)` without `dma_unmap_single_attrs()`; when NULL, unmap with `DMA_ATTR_SKIP_CPU_SYNC`. In `mvpp2_run_xdp()`, if the action is not `XDP_PASS` and not consumed by `xdp_do_redirect()` or `mvpp2_xdp_xmit_back()`, call `page_pool_put_page(pp, virt_to_head_page(xdp->data), sync, true)` and refill the BM pool in `mvpp2_rx()`. [F2, F13, F165]
- In multi-descriptor TX paths (`mvpp2_tx()`, `mvpp2_tx_frag_process()`, `mvpp2_tx_tso()`), `mvpp2_txq_inc_put()` must pass `NULL` for intermediate descriptors and pass `skb` only on the final descriptor (`MVPP2_TXD_L_DESC`), and rollback on mapping failure must unmap and put all prior descriptors via `tx_desc_unmap_put()`. [F10]
- In `mvpp2_txq_bufs_free()` and `tx_desc_unmap_put()`, skip `dma_unmap_single()` for coherent TSO headers (`IS_TSO_HEADER(txq_pcpu, dma)`) and `MVPP2_TYPE_XDP_TX` buffers. `mvpp2_txq_bufs_free()` must hold `rcu_read_lock()` across `xdp_return_frame_bulk()`/`xdp_flush_frame_bulk()` and use `dev_kfree_skb_any()`. In `mvpp2_tx_hw_tstamp()`, free any unconsumed skb in `queue->skb[i]` via `dev_kfree_skb_any()` before storing `skb_get(skb)`, and clear `queue->skb[id] = NULL` and free `skb` in `mvpp2_isr_handle_ptp_queue()`. [F11, F12, F155]
- Destroyed `priv->page_pool[i]` entries must be set to `NULL` (`mvpp2_check_pagepool_dma()` tests `priv->page_pool[0]`). `mvpp2_bm_switch_buffers()` must stop running ports, destroy active BM pools via `mvpp2_bm_pool_destroy()`, and `devm_kfree(priv->bm_pools)` before reinitializing pools and reopening ports. [F4, F14]
- In `mvpp2_rxq_deinit()`/`mvpp2_txq_deinit()`, call `mvpp2_rxq_drop_pkts()` and `xdp_rxq_info_unreg()` before freeing RX rings, and set `rxq->descs`, `txq->descs`, and `txq_pcpu->tso_headers` to `NULL` after freeing. `mvpp2_stop()` must stop NAPI/IRQs, disconnect phylink, free IRQs (`mvpp2_irqs_deinit()` calls `irq_set_affinity_hint(qv->irq, NULL)` before `kfree(qv->mask)` and sets `qv->mask = NULL`), cancel `tx_done_timer`, clean up queues, and call `cancel_delayed_work_sync(&port->stats_work)`. [F15, F16, F17, F18]
- In `mvpp2_remove()`, remove all ports via `mvpp2_port_remove()` and destroy `priv->stats_queue` before destroying `priv->bm_pools` and `priv->aggr_txqs`, skipping `clk_disable_unprepare()` on ACPI (`!dev_of_node(&pdev->dev)`). [F136]

## API Contracts

- Global registers paired with a per-thread selector (`MVPP2_RXQ_NUM_REG`, `MVPP2_TXQ_NUM_REG`, `MVPP2_BM_VIRT_ALLOC_REG`, `MVPP2_BM_VIRT_RLS_REG`) must be accessed via `mvpp2_thread_write()`/`mvpp2_thread_read()` on the same `thread` with preemption disabled (`get_cpu()`/`put_cpu()`), not `mvpp2_write()`. In `mvpp2_tx_pkts_coal_set()`, `MVPP2_TXQ_NUM_REG` and `MVPP2_TXQ_THRESH_REG` must be written across all threads (`0..MVPP2_MAX_THREADS - 1`) via `mvpp2_thread_write()`. [F143, F144]
- `MVPP2_TXQ_SCHED_REFILL_REG(q)`, `MVPP2_TXQ_SCHED_TOKEN_SIZE_REG(q)`, and `MVPP2_TXQ_SCHED_TOKEN_CNTR_REG(q)` take logical `txq->log_id`, whereas `MVPP2_TXQ_NUM_REG`, `MVPP2_TXQ_SENT_REG()`, `MVPP2_TXQ_RSVD_REQ/CLR_REG`, and `mvpp2_txdesc_txq_set()` take physical `txq->id`. Likewise, `mvpp2_rxq_long/short_pool_set()` and `xdp_rxq_info_reg()` take logical `rxq->logic_rxq`, while `mvpp2_rxq_offset_set()`, `mvpp2_rxq_received()`, `mvpp2_rxq_status_update()`, `MVPP2_RXQ_CONFIG_REG()`, `MVPP2_RXQ_NUM_REG`, and `MVPP2_ISR_RX_THRESHOLD_REG()` take physical `rxq->id`. [F54, F55, F162]
- `__mvpp2_prs_init_from_hw()` returns positive `MVPP2_PRS_TCAM_ENTRY_INVALID` (`1`) when `MVPP2_PRS_TCAM_INV_MASK` is set, `-EINVAL` if `tid` is out of range, and `0` when valid; when updating a shared parser TCAM entry for a single port, if `priv->prs_shadow[tid].valid` is true, read it via `__mvpp2_prs_init_from_hw()` before calling `mvpp2_prs_tcam_port_set()`. `mvpp2_prs_vid_entry_remove(port, vid)` takes a 12-bit VLAN ID, whereas `mvpp2_prs_hw_inv(priv, tid)` takes a TCAM index `tid`. [F36, F56, F65]
- `mvpp2_tx_tso()` returns positive descriptor count on success and `0` (never negative) on failure. `mvpp2_xdp_submit_frame()` and `mvpp2_xdp_xmit_back()` return `MVPP2_XDP_TX` (`BIT(1)`) or `MVPP2_XDP_DROPPED` (`BIT(0)`) without freeing `xdpf`. `mvpp2_bm_bufs_add()` returns the count allocated (`0..buf_num`), so callers must check `num != pkts_num`. [F38, F39, F40]
- During phylink mode changes (`port->phy_interface != interface`), `mvpp2_mac_prepare()` must call `mvpp22_gop_mask_irq(port)` before `port->phy_interface` changes and run `mvpp22_mode_reconfigure()` with the target `interface` (as it asserts MAC resets), while `mvpp2_mac_finish()` must update `port->phy_interface = interface` before `mvpp22_gop_unmask_irq(port)`. Live reconfigurations (`mvpp2_change_mtu()`, `mvpp2_xdp_setup()`, `mvpp2_ethtool_set_ringparam()`, `mvpp2_bm_switch_buffers()`) must gate stopping/starting dev or port on `netif_running(dev)`. [F74, F76, F134]
- Classifier flow macros (`MVPP2_CLS_FLT_*`) require `flow->flow_id` (`>= MVPP2_FL_START`), never a `cls_flows[]` index. Validate `fs.location < MVPP2_N_RFS_ENTRIES_PER_FLOW` and `rss_context < MVPP22_N_RSS_TABLES` (with mapped context in `[0, MVPP22_N_RSS_TABLES - 1]`). [F80, F81, F91]

## Error Handling

- In `mvpp2_rx()`, if `mvpp2_rx_refill()` fails after `build_skb()`/`slab_build_skb()`, free `skb` via `dev_kfree_skb_any(skb)` before jumping to `err_drop_frame`. When `mvpp2_ethtool_set_ringparam()` fails `mvpp2_setup_rxqs()`/`txqs()`, restore `prev_rx_ring_size`/`prev_tx_ring_size` and retry. [F3, F19]
- Optional pointers (`priv->cm3_base`, `priv->sysctrl_base`, `port->comphy`, `port->phylink`) must never hold an `ERR_PTR` (`mvpp2_get_sram()` checks `IS_ERR(base)`), and callers must null-check `port->phylink` and `priv->sysctrl_base`; `port->pcs_gmac.ops` and `port->pcs_xlg.ops` must be initialized unconditionally before `!mvpp2_use_acpi_compat_mode(port_fwnode)` in `mvpp2_port_probe()`. [F41, F43, F141]

## Known Pitfalls

- On PPv2.2/2.3, `buf_dma_addr_ptp`, `buf_dma_addr_key_hash`, and `buf_cookie_misc` pack metadata/PTP bits in bits 63:40 and the 40-bit address/cookie in `MVPP2_DESC_DMA_MASK` (bits 39:0), so accessors must mask with `MVPP2_DESC_DMA_MASK` and preserve upper bits. `mvpp2_txq_inc_put()` must add `mvpp2_txdesc_offset_get()` to `mvpp2_txdesc_dma_addr_get()` when saving `tx_buf->dma`, and PPv2.2/2.3 ring addresses in `MVPP2_AGGR_TXQ_DESC_ADDR_REG` and `MVPP2_RXQ_DESC_ADDR_REG` must be right-shifted by 8 bits (unlike `MVPP2_TXQ_DESC_ADDR_REG`). [F83, F84, F85, F86]
- In `struct mvpp2_prs_entry`, the 8-bit AI field at `MVPP2_PRS_SRAM_AI_OFFS` (bit 90) spans `pe->sram[2]` and `pe->sram[3]` and must use `mvpp2_prs_sram_ai_update()`/`get()`. In `mvpp2_prs_sram_shift_set()` and `mvpp2_prs_sram_offset_set()`, negative values must be negated with the sign bit set, and the shift in `mvpp2_prs_sram_shift_set()` must be ORed (`|=`) so the sign bit is preserved. In `mvpp2_prs_vlan_add()` and `mvpp2_prs_double_vlan_add()`, re-zero `pe` with `memset(&pe, 0, sizeof(pe))` after the `tid_aux` scan loop. [F52, F67, F95, F117]
- Cast 8/16-bit keys/masks to `u64` before `<< offs` in `mvpp2_cls_c2_build_match()` and 8-bit high address fields to `u64` before `<< 32` in `mvpp2_bm_bufs_get_addrs()`/`mvpp2_buff_hdr_pool_put()`; use `bitmap_set(&priv->lock_map, 0, nbits)` instead of `bitmap_fill()`; store local bitmasks passed to `test_bit()`/`for_each_set_bit()` in `unsigned long`; and only downcast `pcs_gmac` via `mvpp2_pcs_gmac_to_port()` and `pcs_xlg` via `mvpp2_pcs_xlg_to_port()`. [F113, F115, F127, F128, F129]
