# MODULE SUPPORT

Implements the Linux kernel loadable module subsystem, including ELF parsing and validation, decompression (gzip/xz/zstd), PKCS#7 signature verification, section layout, execmem/per-CPU memory allocation, symbol resolution, relocation, strict RWX enforcement, and module unloading. It also provides the usermode helper auto-loader (`__request_module`) with duplicate request suppression, RCU-safe address lookups via latch RB-trees and kallsyms, and userspace observability through `/proc/modules`, `/sys/module`, and `/sys/kernel/debug/modules`.

## Architecture & Data Flow
- `module_sig_check()` must precede `elf_validity_cache_copy()` in `load_module()`. `mod_verify_sig()` must `memcpy()` `struct module_signature` and check `modlen > sizeof(ms)` and `mod_check_sig()` before subtracting `be32_to_cpu(ms.sig_len) + sizeof(ms)` from `info->len`. [F84]
- `elf_validity_cache_sechdrs()` and `validate_section_offset()` must check `e_shoff >= info->len` before `e_shnum * sizeof(Elf_Shdr) > info->len - e_shoff` and `secend < shdr->sh_offset` before `secend > info->len`, while keeping `info->sechdrs[0]` zeroed (`SHT_NULL`, `sh_size == 0`, `sh_addr == 0`). `elf_validity_cache_secstrings()` and `elf_validity_cache_strtab()` must verify `sh_size != 0` before indexing `sh_size - 1` and validate every `sh_name`/`st_name` against `sh_size`. `elf_validity_cache_index_versions()` must verify `__version_ext_names` holds a NUL-terminated string within `remaining_len` for each of the `sh_size / sizeof(u32)` CRCs in `__version_ext_crcs`. [F77, F78, F107, F166]
- In `__layout_sections()`, `core_m_to_mem_type` and `init_m_to_mem_type` must match the length of `masks` and map every reachable pass to a valid `enum mod_mem_type` (not `MOD_INVALID`), with `SHF_RO_AFTER_INIT | SHF_ALLOC` preceding `SHF_WRITE | SHF_ALLOC`. [F66]
- `layout_symtab()` (after `layout_sections()`) and `add_kallsyms()` must use the identical symbol filter (`i == 0 || is_livepatch_module(mod) || is_core_symbol(...)`), keeping symbol 0 (`i == 0`) as the not-found sentinel for `find_kallsyms_symbol()`. In `mod->mem[MOD_DATA]`, `mod->core_kallsyms.strtab` must immediately precede `info->core_typeoffs`, and `strscpy()` must receive the remaining `strtab_size` (`core_typeoffs - stroffs`, decremented by `ret + 1`) rather than `KSYM_NAME_LEN` so word-at-a-time writes cannot overflow `typetab`. [F79, F99, F113]
- `module_memory_alloc()` must `PAGE_ALIGN()` and store back `mod->mem[type].size`, because `module_set_memory()` passes `mod_mem->size >> PAGE_SHIFT` as page count (returning 0 when `!mod_mem->base`), whereas `execmem_restore_rox()` in `module_enable_text_rox()` takes `mem->size` in bytes. [F55, F109]
- Because `layout_and_allocate()` clears `SHF_ALLOC` on `info->sechdrs[info->index.pcpu]`, `apply_relocations()` must exempt a non-zero `infosec == info->index.pcpu` when skipping non-`SHF_ALLOC` target sections. In `load_module()`, `flush_module_icache(mod)` must run after `post_relocation()` and before `ftrace_module_init(mod)`, `complete_formation(mod)`, and `parse_args()`. [F93, F148]
- `module_unload_init()` sets `mod->refcnt` to `MODULE_REF_BASE` plus 1 for init, so `do_init_module()` must call `module_put(mod)` on both success and `fail` paths, and `try_release_module_ref()` must restore `MODULE_REF_BASE` via `atomic_add_unless(&mod->refcnt, MODULE_REF_BASE, 0)` if `atomic_sub_return()` is non-zero. [F10]
- `resolve_symbol()` and `inherit_taint()` forbid combining `GPL_ONLY` symbols with `TAINT_PROPRIETARY_MODULE` owners in either order by setting `mod->using_gplonly_symbols = true` before `inherit_taint()`. `mod->taints` stores `TAINT_*` bit indices for `set_bit()`/`test_bit()`, never pre-shifted bitmasks. `try_add_tainted_module()` must return early when `!mod->taints`. [F95, F162, F164]

## Synchronization
- `add_unformed_module()` must set `mod->state = MODULE_STATE_UNFORMED` and call `mod_update_bounds(mod)` under `module_mutex` before `list_add_rcu(&mod->list, &modules)` and `mod_tree_insert(mod)`, keeping `MODULE_STATE_UNFORMED` until `complete_formation()` sets `MODULE_STATE_COMING` under `module_mutex`. `free_module()` resets `mod->state = MODULE_STATE_UNFORMED` under `module_mutex` after `mod_sysfs_teardown(mod)` while keeping `mod` on `modules` during `module_arch_cleanup()`, `module_unload_free()`, and `destroy_params()`. Readers of `modules` or `mod_tree` (unless `even_unformed = true`) must skip `MODULE_STATE_UNFORMED`. [F26, F28, F49]
- All `mod_tree` updates (`mod_tree_insert()`, `mod_tree_remove_init()`, `mod_tree_remove()`, `mod_update_bounds()`) require `module_mutex`. Before `do_init_module()` queues `freeinit` onto `init_free_list`, it must under `module_mutex` switch `mod->kallsyms` to `&mod->core_kallsyms` via `rcu_assign_pointer()`, call `mod_tree_remove_init(mod)` and `trim_init_extable(mod)`, capture `freeinit`, and only then zero `mod->mem[type].base` and `size` for `init` types. [F24, F59, F138]
- `find_symbol()`, `find_module_all()`, `find_module()`, `__module_address()`, and `__module_text_address()` require `module_mutex` or an RCU read-side critical section (even if holding a module refcount, as in `symbol_put_addr()`); RCU callers (`__symbol_get()`, `__symbol_put()`) must get/put the module ref before `rcu_read_unlock()`. Reads of `mod->kallsyms` outside `module_mutex` must use `rcu_dereference(mod->kallsyms)` under RCU. `module_address_lookup()`, `module_kallsyms_lookup_name()`, and `print_modules()` must use `guard(rcu)()` and never take `module_mutex` or sleep. [F32, F38, F136, F137]
- `resolve_symbol()` must hold `module_mutex` continuously across `find_symbol(&fsa)`, `ref_module(mod, fsa.owner)`, and copying `module_name(fsa.owner)` into `ownername[]`. All mutations and non-RCU traversals of `mod->source_list` and `mod->target_list` (`add_module_usage()`, `ref_module()`, `module_unload_free()`, `add_usage_links()`, `del_usage_links()`, `delete_module()`) require `module_mutex`. [F29, F30]
- `module_patient_check_exists()` must drop `module_mutex` to wait on `module_wq` only if `old->state` is `MODULE_STATE_COMING` or `MODULE_STATE_UNFORMED` (never `MODULE_STATE_GOING`), and must re-lookup `old` via `find_module_all()` after relocking `module_mutex`. [F23]
- `module_notify_list`, `mod->init()`, `mod->exit()`, `klp_module_coming()`, `klp_module_going()`, `ftrace_release_mod()`, and `async_synchronize_full()` must run outside `module_mutex`. `do_init_module()` (when `!mod->async_probe_requested`) and `delete_module()` must call `async_synchronize_full()` before freeing `.init` or calling `free_module(mod)`, so synchronous `request_module()` (`wait == true`) must never run from an async worker (`current_is_async()`). [F34, F134, F145]
- Because `struct idempotent` is on-stack in `idempotent_init_module()`, `idempotent()` must initialize `u->ret = -EINTR`, `u->cookie`, and `init_completion(&u->complete)` before taking `idem_lock` and hashing `&u->entry`. `idempotent_complete()` must unlink with `hlist_del_init(&pos->entry)` under `idem_lock`, and `idempotent_wait_for_completion()` must lock `idem_lock` and call `hlist_del(&u->entry)` if `!hlist_unhashed(&u->entry)` when interrupted. [F17, F22]
- `kmod_dup_request_exists_wait()` must never insert into `dup_kmod_reqs` when `wait == false`. When `wait == true` inserts an entry, `call_modprobe()` must call `kmod_dup_request_announce()` on every return path (including `-ENOMEM`), and `kmod_dup_request_delete()` must call `list_del_rcu()` under `kmod_dup_mutex` and `synchronize_rcu()` before `kfree(kmod_req)`. [F36, F153]

## Object Lifetimes
- When unlinking `mod` in `free_module()` or `load_module()` error paths, `list_del_rcu(&mod->list)`, `mod_tree_remove(mod)`, and `module_bug_cleanup(mod)` must run under `module_mutex` followed by `synchronize_rcu()` before `lockdep_free_key_range()` and freeing memory. `free_mod_mem()` must skip `MOD_DATA` during `for_each_mod_mem_type()`, free `mod->mem[MOD_DATA]` last (since `struct module` lives in `MOD_DATA`), and be the final operation on `mod`. [F65, F141]
- Because `mod->mkobj.kobj` is embedded in `struct module`, `mod_sysfs_init()`, `mod_sysfs_setup()`, and `mod_sysfs_fini()` must release it via `mod_kobject_put()` to wait on `kobj_completion` before `mod` is freed. `do_init_module()` must not emit `kobject_uevent(&mod->mkobj.kobj, KOBJ_ADD)` until `do_one_initcall(mod->init)` succeeds and `mod->state` is `MODULE_STATE_LIVE`. [F119, F128]
- In `module_memory_alloc()` and `kmemleak_load_module()`, `kmemleak_not_leak()` and `kmemleak_no_scan()` must only be called on `mod->mem[type].base` when `!mod->mem[type].is_rox`, and `module_memory_alloc()` must use `kmemleak_not_leak()` (not `kmemleak_ignore()`) so writable data sections remain scanned. [F4]
- `ref_module()` must acquire a ref on `b` via `strong_try_module_get(b)` before `add_module_usage(a, b)` links `struct module_use`, and call `module_put(b)` if `add_module_usage()` fails. [F9]
- In `init_module_from_file()` with `MODULE_INIT_COMPRESSED_FILE`, `vfree(buf)` must free the `kernel_read_file()` buffer right after `module_decompress()`, while `info->hdr` and `info->pages` are freed by `module_decompress_cleanup(info)` or `free_copy()`. In `call_modprobe()`, once `call_usermodehelper_setup()` succeeds, `free_modprobe_argv()` owns `argv` and `module_name` (`argv[3]`); if it returns `NULL`, `call_modprobe()` must `kfree` both directly. [F14, F16]
- Before `rewrite_section_headers()` populates `sh_addr`, helpers reading `info->hdr` sections (`get_next_modinfo()`, `elf_validity_cache_secstrings()`, `elf_validity_cache_strtab()`) must use `(void *)info->hdr + shdr->sh_offset` instead of `shdr->sh_addr`. `add_kallsyms()` must set `kallsyms->strtab` from `(void *)info->sechdrs[info->index.str].sh_addr` and never `info->strtab`, which `free_copy()` frees before `do_init_module()`. [F62, F114]
- `add_notes_attrs()` must use the exact same `!sect_empty(&info->sechdrs[i])` filter as `add_sect_attrs()` after `mod->sect_attrs` is created, and `remove_notes_attrs()` must precede `remove_sect_attrs()`, because `add_notes_attrs()` borrows `mod->sect_attrs->attrs[loaded].attr.name`. Both `grp.bin_attrs` pointer arrays (`gattr`) must be allocated with `kcalloc(count + 1, sizeof(*gattr), GFP_KERNEL)` for a trailing `NULL` sentinel. [F68, F124]

## API Contracts
- Because `do_init_module()` frees `MOD_INIT_*` asynchronously via `init_free_wq` (`do_free_init()`), callers requiring module init memory and W+X mappings to be torn down synchronously must call `flush_module_init_free_work()`. [F25]
- `try_module_get()` requires `mod->state != MODULE_STATE_GOING` and `atomic_inc_not_zero(&module->refcnt) != 0` (under RCU, `module_mutex`, an existing ref, or kernfs active protection) and returns `bool`, whereas `strong_try_module_get()` returns `0` on success, `-EBUSY` if `MODULE_STATE_COMING`, and `-ENOENT` if `try_module_get()` fails. [F48, F143]
- `resolve_symbol()` and `resolve_symbol_wait()` return a valid `struct kernel_symbol *`, `NULL` when absent or blocked by `inherit_taint()`, or an `ERR_PTR` when `check_version()`, `verify_namespace_is_imported()`, or `ref_module()` fails. When `find_symbol()` returns `true`, `fsa->owner` is `NULL` for core kernel symbols, so callers must check `fsa.owner` or use NULL-safe helpers (`module_name()`, `inherit_taint()`, `ref_module()`). `__symbol_get()` only resolves `GPL_ONLY` symbols. [F43, F44, F156]
- `__request_module()` returns `0` on helper completion, negative errno on kernel failure, or a positive modprobe exit code, and callers must still verify the requested service registered. [F46]
- `layout_sections()` initializes `sh_entsize` to `~0UL`, and `module_get_offset_and_type()` / `__layout_sections()` pack `enum mod_mem_type` into the upper `SH_ENTSIZE_TYPE_BITS` bits (casting `type` to `unsigned long` and masking with `SH_ENTSIZE_TYPE_MASK` before `<< SH_ENTSIZE_TYPE_SHIFT`) and the offset into `SH_ENTSIZE_OFFSET_MASK`, which `move_module()` and `is_core_symbol()` must unpack. [F54, F104]
- Code classifying ELF sections by name to match `within_module_init()` must call `module_init_layout_section()` rather than `module_init_section()`, because when `!CONFIG_MODULE_UNLOAD` it folds `module_exit_section()` into `MOD_INIT_*`. [F67]

## Error Handling
- In `move_module()`, `t` must be initialized to `MOD_MEM_NUM_TYPES` before the allocation loop, set to `type` only when `module_memory_alloc()` fails, and unwound with `while (t--)` after `module_memory_restore_rox(mod)` on `out_err`. Both `module_deallocate()` and `move_module()`'s `out_err` path (if `codetag_section_found`) must call `codetag_free_module_sections(mod)` before freeing `mod->mem`. [F2, F3]
- In `load_module()`, errors before `layout_and_allocate()` sets `module_allocated = true` must jump to `free_copy:` so `audit_log_kern_module()` and `mod_stat_bump_becoming()` run. `codetag_load_module(mod)` must be checked before `free_copy(info, flags)` (jumping to `sysfs_cleanup` on error), and `free_copy(info, flags)` must run before tail-calling `do_init_module(mod)`. [F7, F50]
- In `do_init_module()`, once `do_one_initcall(mod->init)` succeeds and `mod->state` is `MODULE_STATE_LIVE`, a non-zero return from `module_enable_rodata_ro_after_init(mod)` must only warn and must not jump to `fail`. [F6]
- `add_sect_attrs()` and `add_notes_attrs()` must return negative errnos on failure, and `mod_sysfs_setup()` must unwind prior sysfs state. Every `modinfo_attrs[]` entry with a `.free` callback (e.g., `free_modinfo_version`) must reset its `mod` pointer field to `NULL`, because error paths invoke `attr->free(mod)` in both `module_remove_modinfo_attrs()` and `free_modinfo()`. [F51, F69]
- `module_get_next_page()` returns an `ERR_PTR` and never `NULL`, so callers in `kernel/module/decompress.c` must test `IS_ERR(page)`. `find_any_unique_sec()` returns a positive index if unique, `0` if absent, or negative `-count` if duplicated, requiring a signed `int` check (`< 0` vs `== 0`). `check_version()`, `check_modstruct_version()`, and `same_magic()` return `1` on success and `0` on failure (`!check_version(...)`). [F41, F45, F47]

## Known Pitfalls
- `move_module()` copies `.gnu.linkonce.this_module` from `info->mod` into `mod->mem[MOD_DATA]` and updates all `SHF_ALLOC` `sechdrs[i].sh_addr` fields, so code after `move_module()` must use the returned `mod` and updated `sh_addr` rather than `info->mod`. In `apply_relocations()`, `SHF_RELA_LIVEPATCH` must be tested before `sh_type == SHT_RELA` so livepatch relocations route to `klp_apply_section_relocs()`. [F64, F94]
- Section alignment in `module_get_offset_and_type()` and `layout_symtab()` must use `sh_addralign ?: 1` before `ALIGN()`. `module_decompress()` must compute initial `n_pages` with `DIV_ROUND_UP(size, PAGE_SIZE) * 2` so `info->max_pages` is non-zero for `0 < size < PAGE_SIZE`. `module_next_tag_pair()` must test `(*secsize)-- <= 1` rather than `--(*secsize) == 0` when `infosec->sh_size == 0`. [F106, F110, F112]
