# CLOCKSOURCE, CLOCKEVENT DRIVERS

`drivers/clocksource` provides the core Device Tree and ACPI timer probing infrastructure (`timer-probe.c`, `timer-of.c`) alongside hardware-specific clocksource, clockevent, `sched_clock`, delay timer, and watchdog drivers for ARM, RISC-V, and MIPS SoCs.

## Architecture & Data Flow

- On TI OMAP timers with `OMAP_TIMER_ERRATA_I103_I767`, `OMAP_TIMER_CTRL_POSTED` must not be enabled if the counter register is ever read: `__omap_dm_timer_enable_posted()` forces `OMAP_TIMER_NONPOSTED`, and `dmtimer_clkevt_init_common()` enables posted mode only because clockevents never read `t->counter`. [F120]
- When stopping a running TI OMAP2+ dmtimer by clearing `OMAP_TIMER_CTRL_ST` in `__omap_dm_timer_stop()` or `dmtimer_clockevent_shutdown()`, the driver must read back the control register to flush the posted write and wait `udelay(3500000 / rate + 1)` before clearing `OMAP_TIMER_INT_OVERFLOW`. [F129]
- In `timer-ti-dm.c`, `omap_dm_timer_write_counter()` must update `timer->context.tcrr = value` alongside writing `OMAP_TIMER_COUNTER_REG`, because `omap_timer_save_context()` does not read `OMAP_TIMER_COUNTER_REG` while `omap_timer_restore_context()` writes `timer->context.tcrr`. At the end of `omap_dm_timer_cap_counter()`, clearing capture bits in `OMAP_TIMER_CTRL_REG` must preserve `OMAP_TIMER_CTRL_ST` (`l &= ~(0xffff) | 0x1`). [F61, F63]
- In `timer-ti-dm-systimer.c`, `dmtimer_systimer_setup()` adds `OMAP_TIMER_V2_FUNC_OFFSET` (`0x14`) to V2 functional register offsets (`pend`, `load`, `counter`, `ctrl`, `wakeup`, `ifctrl`), while `sysc`, `irq_stat`, and `irq_ena` remain direct `io_base` offsets. In `timer-ti-32k.c`, `ti_32k_timer_init()` must call `ti_32k_timer_module_init()` to enable parent `ti,sysc` clocks before reading `OMAP2_32KSYNCNT_REV_OFF`, and offset `ti_32k_timer.counter` by `OMAP2_32KSYNCNT_CR_OFF_HIGH` (`0x30`) if `OMAP2_32KSYNCNT_REV_SCHEME` is set or `OMAP2_32KSYNCNT_CR_OFF_LOW` (`0x10`) otherwise. [F73, F123]
- In `timer-nxp-stm.c`, `stm_timer->cs` and `stm_timer->ced` share the STM counter and `STM_CR` (`STM_ENABLE_MASK`), so module enable/disable must be refcounted via `nxp_stm_module_get()` and `nxp_stm_module_put()` (`stm_timer->refcnt`) while clockevent state changes only toggle `STM_CCR_CEN` in `STM_CCR0`. [F56]
- In `stm32_timer_init()`, `to->private_data` must be allocated before `stm32_timer_set_width()`, which must run before `stm32_timer_set_prescaler()`, `stm32_clocksource_init()`, and `stm32_clockevent_init()`. When programming the prescaler in `stm32_timer_set_prescaler()` or `stm32_clkevent_lp_set_prescaler()`, cached `rate`, `period`, and (for LPTIM) `priv->psc` must be updated in lockstep, and 16-bit timers in `stm32_timer_set_prescaler()` must clamp `prescaler` to `TIM_PSC_MAX` (`USHRT_MAX`) before writing `prescaler - 1` to `TIM_PSC` and dividing `to->of_clk.rate`. [F45, F57, F78]
- In `timer-stm32-lp.c`, `stm32_clkevent_lp_set_timer()` must branch on `priv->version == STM32_LPTIM_VERR_23`: v2.3 (`stm32mp25_clkevent_lp_set_evt()`) sets `STM32_LPTIM_ENABLE` (`udelay(63)`) before writing `STM32_LPTIM_ARR`/`STM32_LPTIM_IER` and polling `STM32_LPTIM_ISR` until `(val & STM32_LPTIM_DIEROK_ARROK) == STM32_LPTIM_DIEROK_ARROK` before clearing `STM32_LPTIM_DIEROKCF_ARROKCF`, whereas older versions write `IER` while `STM32_LPTIM_CR` is 0. [F80, F121]
- In `timer-sun4i.c` and `timer-sun5i.c`, `sun4i_clkevt_sync()` and `sun5i_clkevt_sync()` busy-wait until down-counter timer 1 advances by `TIMER_SYNC_TICKS` using `u32` modular subtraction (`(old - readl(...)) < TIMER_SYNC_TICKS`). Timer 1 must be enabled before `sun4i_clkevt_time_stop()` or `sun5i_clkevt_time_stop()` is ever called and must never be disabled, and `clockevents_config_and_register()` must set `min_delta >= TIMER_SYNC_TICKS`. [F88, F101]
- In `timer-pxa.c`, `ckevt_pxa_osmr0` must be registered with `max_delta <= 0x7fffffff` because `pxa_osmr0_set_next_event()` checks `(signed)(next - oscr) <= MIN_OSCR_DELTA`. In `pxa_timer_resume()`, if `osmr[0] - oscr < MIN_OSCR_DELTA`, `osmr[0]` must be advanced by `MIN_OSCR_DELTA` before writing `OSMR0` and `OSCR`. [F59, F100]
- In `timer-tegra186.c`, `tegra186_wdt_set_timeout()` must call `tegra186_wdt_disable(wdt)` before updating `wdt->base.timeout` and `tegra186_wdt_enable(wdt)` afterwards when `watchdog_active(&wdt->base)` is true. `tegra186_wdt_disable()` must write `WDTUR_UNLOCK_PATTERN` to `WDTUR` before `WDTCMDR_DISABLE_COUNTER`, and when `wdt->locked` is set (`WDTCR_LOCAL_INT_ENABLE` set in `tegra186_wdt_create()`), `tegra186_wdt_enable()` must skip writing `WDTCR`. [F55, F122]
- In `timer-riscv.c`, when `riscv_sstc_available` is enabled, `riscv_clock_event_stop()` and `riscv_clock_next_event()` must program both `CSR_STIMECMP` and `CSR_STIMECMPH` on `CONFIG_32BIT` builds. [F77]

## Synchronization

- In `riscv_timer_init_common()`, `riscv_clock_event_irq`, `riscv_timer_cannot_wake_cpu`, and the `riscv_sstc_available` static branch must be initialized and enabled before `cpuhp_setup_state()` is called, because `cpuhp_setup_state()` immediately invokes `riscv_timer_starting_cpu()`. [F14]
- Before calling `sched_clock_register()`, the global pointer and hardware counter read by the `notrace` callback (`stm_sched_clock`, `sched_clkevt`, `stm32_timer_cnt`, and `dmtimer_sched_clock_counter`) must be initialized and started (including `stm32_timer_start(to)` in `stm32_clocksource_init()`). [F27]
- In `nxp_stm_clockevent_set_next_event()`, `stm32_clock_event_set_next_event()`, and `pxa_osmr0_set_next_event()`, after writing the compare target to the free-running timer's comparator, the hardware counter must be re-read to return `-ETIME` if the counter wrapped or advanced past the target before the write completed. [F28]
- In `timer-ti-dm.c`, all accesses to `omap_timer_list` and `timer->reserved` in `_omap_dm_timer_request()`, `omap_dm_timer_modify_idlect_mask()`, `omap_dm_timer_probe()`, and `omap_dm_timer_remove()` must hold `dm_timer_lock`, while `omap_dm_timer_prepare()` (which invokes synchronous runtime PM) must be called after dropping `dm_timer_lock`. `__omap_dm_timer_stop()` must use cached `timer->fclk_rate` rather than calling sleeping `clk_get_rate()`. [F139, F140]
- In `timer-ti-dm.c`, `omap_dm_timer_runtime_suspend()` must clear `timer->enabled` before `omap_timer_save_context()` and `omap_dm_timer_runtime_resume()` must set `timer->enabled` after `omap_timer_restore_context()`, because `omap_timer_context_notifier()` gates context save/restore on `atomic_read(&timer->enabled)`. [F25]
- In `timer-orion.c`, all modifications to `timer_base + TIMER_CTRL` (`orion_clkevt_next_event()`, `orion_clkevt_shutdown()`, `orion_clkevt_set_periodic()`, and `orion_timer_init()`) must use `atomic_io_modify()` with only the target timer's bits masked so they do not race with `orion_wdt` or clobber the sibling timer. [F51]
- In `timer-pistachio.c`, `pistachio_clocksource_read_cycles()` must acquire `pcs->lock` with `raw_spin_lock_irqsave()` and read `TIMER_CURRENT_OVERFLOW_VALUE` before `TIMER_CURRENT_VALUE` to refresh `TIMER_CURRENT_VALUE`. In `timer-tegra186.c`, `tegra186_timer_tsc_read()` must loop re-reading `TKETSC0` and `TKETSC1` until `TKETSC1` matches its prior snapshot before combining `((u64)hi << 32 | lo)`. [F76, F97, F130]
- `nxp_stm_timer_probe()` must hold `stm_instances_lock` across the entire probe path to serialize `stm_instances`, `per_cpu(stm_timers, cpu)` assignment, and `cpuhp_setup_state()`. `stm32mp25_clkevent_lp_set_evt()` runs from atomic `clock_event_device` callbacks and must use `udelay()` and `regmap_read_poll_timeout_atomic()`. [F144, F148]

## Object Lifetimes

- When `timer_of_init()` succeeds, the caller must release `TIMER_OF_BASE`, `TIMER_OF_CLOCK`, and `TIMER_OF_IRQ` on subsequent init failure via `timer_of_cleanup()`, whereas a failing `timer_of_init()` unwinds its own partial stages using its local `flags` bitmask. In `timer_of_clk_init()`, a `clk_prepare_enable()` failure must call `clk_put(of_clk->clk)`, and a zero `clk_get_rate()` must call `clk_disable_unprepare()` before `clk_put()`. [F1, F2, F31]
- In `tegra_init_timer()`, `timer_of_init()` runs only on `this_cpu_ptr(&tegra_to)`, so the per-CPU loop must populate `cpu_to->of_base.base` (`timer_reg_base + base`), `cpu_to->of_clk.rate`, and `cpu_to->of_clk.period` for every CPU. On `request_irq()` failure, `cpu_to->clkevt.irq` must be disposed and cleared to `0`, and `out_irq` must restore `to->of_base.base = timer_reg_base` before calling `timer_of_cleanup(to)`. [F4, F32, F54]
- In `_omap_dm_timer_request()`, `timer->reserved` must be reset to `0` when a candidate is superseded in `REQUEST_BY_CAP` mode or when `omap_dm_timer_prepare(timer)` fails. `omap_dm_timer_start()` and `omap_dm_timer_enable()` hold a `pm_runtime_resume_and_get()` reference until `omap_dm_timer_stop()` or `omap_dm_timer_disable()` calls `pm_runtime_put_sync()`, whereas one-shot helpers like `omap_dm_timer_prepare()` must call `pm_runtime_put_sync()` before returning. [F11, F12]
- In `omap_dm_timer_remove()`, non-`OMAP_TIMER_ALWON` timers must unregister `timer->nb` (`cpu_pm_unregister_notifier()`), remove `timer->node` from `omap_timer_list` under `dm_timer_lock` (breaking immediately after `list_del()` when using `list_for_each_entry()`), and call `pm_runtime_disable()`. [F13, F84]
- In `timer-tegra186.c` (`tegra->tsc`, `tegra->osc`, `tegra->usec`) and `timer-sun5i.c` (`st->clksrc`), clocksources are registered with non-devres `clocksource_register_hz()` while driver state and MMIO are devres-managed, so probe error paths and `.remove()` must manually call `clocksource_unregister()`. In `timer-stm32-lp.c`, `priv->clk` is borrowed from `ddata->clk`, so probe error paths and suspend/resume must balance `clk_prepare_enable()` with `clk_disable_unprepare(priv->clk)` without calling `clk_put()`. [F9, F116, F118]
- In `timer-riscv.c`, `riscv_clock_event_stop()` must run before `clockevents_config_and_register()` and `enable_percpu_irq()` in `riscv_timer_starting_cpu()`, and before `disable_percpu_irq()` in `riscv_timer_dying_cpu()`. In `timer-tegra.c`, `tegra_init_timer()` must set `IRQ_NOAUTOEN` before `request_irq()`, and `tegra_timer_setup()` must clear `TIMER_PTV` and `TIMER_PCR` before `enable_irq()`. [F113, F115]
- Every `struct device_node *` returned by `of_find_compatible_node()` / `of_find_matching_node()` or held when breaking early out of `for_each_matching_node()` must be released with `of_node_put()` or `__free(device_node)`. [F124]

## API Contracts

- Every callback registered with `sched_clock_register()` and its non-inline helpers (`pistachio_clocksource_read_cycles`, `ti_32k_read_cycles`) must be marked `notrace`. [F137]
- `timer_of_irq_init()` passes `&to->clkevt` (`struct clock_event_device *`) as `void *dev_id` to `request_irq()`, so any `of_irq.handler` registered with `TIMER_OF_IRQ` must use `to_timer_of(dev_id)` to recover `struct timer_of *`. [F105]
- In `timer-ti-dm.c`, `_omap_dm_timer_request(int req_type, void *data)` dereferences `*(int *)data` for `REQUEST_BY_ID` and `*(u32 *)data` for `REQUEST_BY_CAP`, but casts `(struct device_node *)data` directly for `REQUEST_BY_NODE`. `omap_dm_timer_read_status()`, `omap_dm_timer_write_status()`, and `omap_dm_timer_read_counter()` do not call runtime PM and require `atomic_read(&timer->enabled)` to be non-zero. `omap_dm_timer_set_int_disable()` must write `dmtimer_read(timer, timer->irq_ena) & ~mask` on revision 1, but write `mask` directly to `timer->irq_dis` on revision 2. [F65, F106, F158]
- In `timer-ti-dm-systimer.c`, `dmtimer_clkevt_init_common()` must set `dev->set_state_oneshot_stopped` to `dmtimer_clockevent_shutdown`. In `timer-riscv.c`, `riscv_clocksource.mask` must be `CLOCKSOURCE_MASK(64)` and `sched_clock_register()` must pass 64 bits (not `BITS_PER_LONG`). In `timer-sun5i.c`, `sun5i_rate_cb()` must unregister `cs->clksrc` on `PRE_RATE_CHANGE` and re-register `cs->clksrc`, call `clockevents_update_freq()`, and update `cs->ticks_per_jiffy` on `POST_RATE_CHANGE`. [F149, F150, F161]
- In `timer-tegra186.c`, `tegra186_wdt_set_timeout()`, `tegra186_wdt_get_timeleft()`, `tegra186_timer_suspend()`, and `tegra186_timer_resume()` must check `watchdog_active(&wdt->base)`. `tegra186_wdt_get_timeleft()` must reject `WDTSR_CURRENT_EXPIRATION_COUNT > 4`, add `(wdt->base.timeout * (USEC_PER_SEC / 5)) * (4 - expiration)` to `TMRSR_PCV`, and divide by `USEC_PER_SEC`, folding `(USEC_PER_SEC / 5)` at compile time in 32-bit `u32` arithmetic. [F34, F95, F156]

## Error Handling

- In `timer_of_base_init()`, `of_base->base` must be checked with `IS_ERR_OR_NULL()` and mapped to `-ENOMEM` when `NULL`. In `timer_of_irq_init()`, the signed return of `of_irq_get_byname()` must be checked for `< 0` before checking `!of_irq->irq`. Timer init/probe paths must check that `clk_get_rate()` is non-zero before dividing by it, and `timer_probe()` / `timer_of_clk_init()` must suppress `pr_err()` on `-EPROBE_DEFER`. [F29, F30, F98, F162]
- In `timer-ti-dm.c`, `timer->fclk` is `ERR_PTR(-ENODEV)` on OMAP1, so callers must check `!IS_ERR(timer->fclk)` rather than `timer->fclk != NULL`; `omap_dm_timer_runtime_suspend()` and `omap_dm_timer_runtime_resume()` must check `timer->func_base` before saving/restoring context. In `dmtimer_systimer_init_clock()` and `ti_32k_timer_enable_clock()`, `ERR_PTR(-EINVAL)` from `of_clk_get_by_name()` for optional `"ick"` must be treated as non-fatal. [F35, F36, F41]
- In `timer-sp804.c`, `sp804_of_init()` must reset `clk1`/`clk2` from `IS_ERR()` to `NULL` so `sp804_get_clock_rate()` falls back to `clk_get_sys()`, and callers must store its return in a signed `long` and check `rate < 0`. [F43]

## External Contracts

- In `timer-ti-dm.c`, `omap_dm_timer_probe()` must store the matched `struct dmtimer_platform_data` (`.timer_ops = &dmtimer_ops`) into `dev->platform_data` for DT consumers. In `timer-ti-dm-systimer.c`, `"ti,no-reset-on-init"`, `"ti,no-idle"`, `"fck"`, and `"ick"` must be queried on `np->parent` (`"ti,sysc"`), and `dmtimer_is_preferred()` must reject nodes lacking `"ti,no-reset-on-init"`/`"ti,no-idle"`, having `"ti,timer-dsp"`/`"ti,timer-pwm"`, or (when not `"ti,timer-secure"`) lacking `"assigned-clocks"`/`"assigned-clock-parents"`. [F93, F127, F157]
- In `timer-stm32-lp.c`, `stm32_clkevent_lp_probe()` must read the IRQ and `"wakeup-source"` from `pdev->dev.parent` and call `device_set_wakeup_capable()` + `dev_pm_set_wake_irq()` rather than `device_init_wakeup()`. [F125]

## Known Pitfalls

- In timer IRQ handlers that disarm oneshot timers in software (`riscv_timer_interrupt`, `nxp_stm_module_interrupt`, `stm32_clock_event_handler`, `sprd_timer_interrupt`, `pxa_ost0_interrupt`, `zevio_timer_interrupt`), the timer must be disarmed before calling `clkevt->event_handler(clkevt)`. [F152]
- In 32-bit downward-counting clocksource and `sched_clock` readers (`pistachio_clocksource_read_cycles`, `sun5i_clksrc_read`, `sun4i_timer_sched_read`, `orion_read_sched_clock`, `sp804_read`, `sprd_suspend_timer_read`), `~` must be applied to a 32-bit `u32` before widening to `u64` or masked with `cs->mask`. [F104]
- Because `dmtimer_read()` and `dmtimer_write()` index from `timer->func_base` using `(reg & 0xff)` and `(reg >> WPSHIFT)`, `__omap_dm_timer_init_regs()` must subtract `OMAP_TIMER_V2_FUNC_OFFSET` (`0x14`) from V2 interrupt register offsets (`irq_stat`, `irq_ena`, `irq_dis`). Because Tegra timers fire after `n + 1` ticks, `tegra_timer_set_next_event()` and `tegra_timer_set_periodic()` must write `cycles - 1` and `period - 1` to `TIMER_PTV`. [F68, F72]
