# RISC-V ARCHITECTURE

This unit provides the core RISC-V kernel architecture headers, CPU feature/errata discovery and runtime code patching, trap and signal handling, context switching and vector/FPU state management, MMU page table primitives, SMP/IPI and SBI firmware interfaces, ELF module relocation, and vector crypto glue drivers.

## Architecture & Data Flow

- Vector status bits in `pt_regs->status` must be modified/queried via `__riscv_v_vstate_or` and `__riscv_v_vstate_check` so `SR_VS_THEAD` is used when `has_xtheadvector()` is true instead of `SR_VS`. In `__vstate_csr_save`/`restore`, `has_xtheadvector()` requires setting `SR_FS_DIRTY` before accessing `CSR_VXSAT`/`CSR_VXRM` and restoring `CSR_STATUS` if `SR_FS` was not dirty. [F36, F37]
- `riscv_v_vstate_discard` must mark `regs->status` dirty after clobbering vector registers, while `riscv_v_vstate_save`/`restore` mark it clean. `riscv_v_vstate_set_restore` must set both `TIF_RISCV_V_DEFER_RESTORE` and `INITIAL` vector status via `riscv_v_vstate_on(regs)`. [F38, F39]
- In `__switch_to_vector`, if `riscv_preempt_v_started(prev)` and `riscv_v_is_on()` hold, call `riscv_v_disable()` and set `RISCV_PREEMPT_V_IN_SCHEDULE`; when switching to `next` with `RISCV_PREEMPT_V_IN_SCHEDULE` set, clear that flag and call `riscv_v_enable()` instead of `riscv_preempt_v_set_restore(next)`. [F40]
- `riscv_v_vsize` stores the total byte size of all 32 vector registers (`32 * vlenb`), so single-register `vlenb` is `riscv_v_vsize / 32` and bit length `riscv_vector_vlen()` is `riscv_v_vsize / 32 * 8`. In `riscv_v_setup_vsize()`, `thead_vlenb_of` overrides `CSR_VLENB`, and reading `CSR_VLENB` requires `riscv_v_enable()`/`disable()`. [F102, F294]
- Under `CONFIG_RISCV_ISA_SUPM`, `mm->context.pmlen` is non-zero only when `PR_TAGGED_ADDR_ENABLE` is enabled, while user pointer masking length is in `task->thread.envcfg & ENVCFG_PMM`. `init_new_context` clears `MM_CONTEXT_LOCK_PMLEN`, `activate_mm` resets `next->context.pmlen = 0`, `envcfg_update_bits` writes `CSR_ENVCFG` when `task == current`, and `__untagged_addr_remote()` sign-extends via `(long)(addr << pmlen) >> pmlen` on `CONFIG_MMU`. [F41, F48, F56, F209]
- In page-table selectors (`PGDIR_SHIFT`, `P4D_SHIFT`, `VA_BITS`), test `pgtable_l5_enabled` before `pgtable_l4_enabled` (which stays true under Sv57). Under `CONFIG_TRANSPARENT_HUGEPAGE`, `pmd_present()` must check `_PAGE_LEAF` alongside `_PAGE_PRESENT | _PAGE_PROT_NONE`. On T-Head with `CONFIG_ERRATA_THEAD_MAE`, `pfn_pgd/pmd/pte` and `pte_modify` must apply `ALT_THEAD_PMA`. [F49, F74, F139]
- In `pgd_alloc`, `sync_kernel_mappings` copies kernel PGD entries from `init_mm.pgd` at unscaled `+ USER_PTRS_PER_PGD` with byte length `(PTRS_PER_PGD - USER_PTRS_PER_PGD) * sizeof(pgd_t)`. On RV64, `flush_cache_vmap` on `is_vmalloc_or_module_addr` sets all `new_vmalloc` entries to `-1ULL`. `vmemmap` must be biased by `vmemmap_start_pfn`, not `ARCH_PFN_OFFSET`. [F45, F46, F59, F103]
- `struct thread_info` must stay at offset 0 of `struct task_struct`, `asm_per_cpu` must load `TASK_TI_CPU_NUM(tp)` with 32-bit `lw`, and `__switch_to` fields indexed off `a3`/`a4` must use relative `TASK_THREAD_*_RA` offsets. Under `CONFIG_SHADOW_CALL_STACK`, `gp` holds `scs_sp`, so `load_global_pointer` is a no-op. [F52, F58, F128, F206]
- `__ALT_PTR(a, f)` and `runtime_const_fixup()` must use byte-scaled pointer arithmetic (`(void *)&(a)->f + (a)->f` and `*start + (void *)start`). In `__runtime_fixup_32()`, when `upper_immediate & 0xfffff000` is 0 (`lui_insn == RISCV_INSN_NOP4`), the `addi` branch must still run even if `lower_immediate & 0x00000fff` is 0 so `addi` becomes `li rd, 0` instead of a second `nop`. [F69, F73, F95, F96]
- Relocation types in `module.c` emitting PLT/GOT entries must be in both `rela_needs_plt_got_entry()` and `count_max_entries()`, with `plt` and `got_plt` sized in lockstep. `module_frob_arch_sections()` must sort a `scratch` copy rather than `SHT_RELA` in place so `HI20`/`LO12` pairs stay adjacent. HI20/LO12 relocations must add `0x800` before masking `hi20` and validate offsets via `riscv_insn_valid_32bit_offset()`. [F202, F203, F204, F253, F271]

## Synchronization

- Under `CONFIG_SMP`, `ptep_get_and_clear`, `pmdp_huge_get_and_clear`, `pudp_huge_get_and_clear`, `pmdp_establish`, and `pudp_establish` must use `atomic_long_xchg()` or `xchg()`. In `__set_pte_at()`, `flush_icache_pte(mm, pteval)` must precede `set_pte()` when `pte_present(pteval) && pte_exec(pteval)`. [F9, F130]
- Non-relaxed MMIO `read*`/`write*` must use `__io_ar` after reads and `__io_bw` + `__io_aw` (`mmiowb_set_pending()`) around writes, paired with `mmiowb()` (`RISCV_FENCE(o, w)`), and `smp_mb__after_spinlock()` must use `RISCV_FENCE(iorw, iorw)`. Fully ordered `arch_xchg()`/`arch_cmpxchg()` must pair `sc.w/d.rl` with a trailing `RISCV_FULL_BARRIER` on the successful SC path. [F17, F18, F123]
- `may_use_simd()` must return `false` when `in_hardirq() || in_nmi()`, and in non-preemptible mode require `!irqs_disabled() && !(riscv_v_flags() & RISCV_KERNEL_MODE_V)`. `get/put_cpu_vector_context()` must disable softirqs/preemption while `RISCV_KERNEL_MODE_V` is set. `riscv_preempt_v_clear_dirty()` and `riscv_preempt_v_set_restore()` require a preceding `barrier()`, and `riscv_v_flags()` requires `READ_ONCE()`. [F14, F112, F169]
- In `riscv_v_start_kernel_context()`, non-nested preemptible entry must set `RISCV_PREEMPT_V | RISCV_PREEMPT_V_DIRTY` before saving `vstate` and clear `DIRTY` after; nested trap entry must call `get_cpu_vector_context()`, save dirty `kernel_vstate`, clear `DIRTY`, and call `riscv_preempt_v_set_restore()`. `riscv_v_context_nesting_start/end()` require IRQs disabled, and `kernel_fpu_begin/end()` require `preempt_disable()`. [F170, F171, F173, F212]
- Text patching must hold `text_mutex`, disable preemption while `FIX_TEXT_POKE0/1` are mapped, and flush local icache before `patch_unmap()`. In `patch_text_cb()`, the last CPU must call `patch_insn_write()` then `atomic_inc_return_release(&patch->cpu_count)` before all CPUs flush icache. [F122, F155, F167]
- `sbi_cpu_start()` requires `smp_mb()` before writing `bdata` and before `sbi_hsm_hart_start()`; `cpu_update_secondary_bootdata()` requires `smp_mb()` before `WRITE_ONCE()` to `__cpu_spinwait_*`. `smp_callin()` must enable IPIs, set the CPU online, and flush icache/TLB before `complete(&cpu_running)`. `__cpu_disable()` must set the CPU offline and disable IPIs before migrating IRQs. [F174, F175, F176, F177]
- User-mode trap handlers in `traps.c` (`DO_ERROR_INFO`, `do_trap_insn_illegal`, `do_trap_misaligned`, `do_trap_break`) must call `local_irq_enable()` after `irqentry_enter_from_user_mode()` and `local_irq_disable()` before exit. `setup_singlestep()` must clear `SR_SPIE` in `regs->status` and restore it after single-step. `untagged_addr_remote(mm, addr)` requires `mm->mmap_lock`. [F11, F183, F304]

## Object Lifetimes

- `pud_free` and `__pud_free_tlb` must only free/remove descriptors when `pgtable_l4_enabled` is true, and `__p4d_free_tlb` only when `pgtable_l5_enabled` is true. Pages from `get_safe_page()` in `hibernate.c` are freed by the hibernation core and must not be freed in `swsusp_arch_resume()`. [F3, F161]
- `arch_dup_task_struct()` must save `src`'s FPU state before `*dst = *src` and zero `dst->thread.vstate`, zero `kernel_vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE` so `dst` does not alias `datap`. `flush_thread()` must reset vector control, turn off `SR_VS`, free `vstate.datap`, zero `vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE`. [F207, F208]
- In `riscv64_aes_cbc_cts_crypt` and `riscv64_aes_xts_crypt`, call `skcipher_walk_abort(&walk)` before switching to a subrequest walk. Conditional algorithm registrations in `riscv64_aes_mod_init`/`exit` (gated by `ZVKB` and `riscv64_aes_xts_supported()`, requiring `vlen < 2048`) must use identical predicates in reverse order on rollback/exit. [F1, F2, F68]
- In `module.c`, `relocation_hashtable` must use `kvmalloc_array()`/`kvfree()`, and `process_accumulated_relocations()` must use `_safe` list/hlist iterators across all three nested levels. Release every `acpi_get_table()` with `acpi_put_table()` and every `of_*` node with `of_node_put()` on all loop and early-exit paths. [F156, F250, F279, F297]

## API Contracts

- In `__riscv_v_vstate_save/restore/discard`, bracket vector ops with `riscv_v_enable()`/`disable()`, and address `v0`, `v8`, `v16`, `v24` in the four `M8` stores/loads. In `arch/riscv/crypto/*-glue.c`, bracket vector assembly with `kernel_vector_begin()`/`end()` with no sleep or early return between them, and check `crypto_simd_usable()` in synchronous cipher/shash callbacks. [F5, F8, F113, F117]
- `aes_ecb/cbc_*_zvkned()` and `ghash_zvkg()` require a non-zero multiple-of-16 length. `riscv64_aes_cbc_cts_crypt()` and `riscv64_aes_xts_crypt()` must reject `cryptlen < AES_BLOCK_SIZE` with `-EINVAL` and pass at least the final full block plus partial tail block together on split walks. `riscv64_aes_setkey()` must use generic `aes_expandkey()`. [F65, F66, F132]
- When `!CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` and `__gu_ptr` is unaligned, `__get/put_user_nocheck()` must fall back to `__asm_copy_from/to_user_sum_enabled()`. `copy_code()` in `dump_instr()` must use `get_kernel_nofault()` or `copy_from_user_nofault()`, whereas `traps_misaligned.c` user accesses must use fault-capable `copy_from/to_user()` and `get_user()`. `unwind_user_frame()` must use `__copy_from_user_inatomic()`. [F57, F305, F306, F322]
- `syscall_get_nr()` must return signed `int` (truncating `regs->a7` to 32 bits), and syscall arg 0 accessors/rollback must use `regs->orig_a0` rather than `regs->a0`. `__patch_insn_set/write()` return `-EINVAL` if `len + offset_in_page(addr) > 2 * PAGE_SIZE`, so arbitrary-length callers must use `patch_insn_set/write()`. [F90, F145, F200]
- Accessing `CSR_ENVCFG` requires checking `RISCV_ISA_EXT_SUPM` or `RISCV_ISA_EXT_XLINUXENVCFG` (and any `riscv_isa_ext[]` entry implying `CSR_ENVCFG` must include `riscv_xlinuxenvcfg_exts`). `cpu_suspend()` and `swsusp_arch_suspend()` must save/restore CSRs on all paths, and `swsusp_arch_suspend()` on resume must flush all TLBs/icaches and reset `in_suspend = 0` and `sleep_cpu = -EINVAL`. [F292, F293, F302, F303]

## Error Handling

- Callers of `sbi_ecall()` must check `sbiret.error` and translate non-zero SBI errors via `sbi_err_map_linux_errno()` rather than returning `ret.error` directly (`sbi_debug_console_write/read()` map `SBI_ERR_FAILURE` to `-EIO` first, and `sbi_probe_extension()` returns `0` on error/unsupported). [F20, F191, F192]
- `__get_user*()` and `get_user()` must zero the destination variable `x` on fault and return `-EFAULT`. `__asm_copy_to/from_user_sum_enabled()` and `raw_copy_from/to_user()` return a residual byte count (non-zero on fault). Inline assembly using `_ASM_EXTABLE_UACCESS_ERR*` without `asm_goto_output` must initialize the error register to `0` and use `"+r"`. [F23, F24, F26]
- `riscv64_ghash_update()` (`CRYPTO_AHASH_ALG_BLOCK_ONLY`) must pass `round_down(srclen, GHASH_BLOCK_SIZE)` to `riscv64_ghash_blocks()` and return the remainder `srclen - round_down(srclen, GHASH_BLOCK_SIZE)`. Stack `struct kexec_buf` must be zero-initialized (`= {}`) and reset `kbuf.mem = KEXEC_BUF_MEM_UNKNOWN` before reuse, and `elf_kexec_load()`/`image_load()` return `NULL` on success or `ERR_PTR(ret)`. [F31, F185, F186]
- Check `of_get_cpu_hwid()` against `~0UL` (`INVALID_HARTID`), and store `riscv_hartid_to_cpuid()` in a signed `int` checking `< 0` before indexing per-CPU arrays. In `__setup_additional_pages()`, convert a failed `vdso_base` via `ERR_PTR(vdso_base)` and reset `mm->context.vdso = NULL` on `up_fail`. User-mode traps/sigreturn faults must not call `die()`/`WARN*()`. [F196, F199, F337]

## External Contracts

- Adding a `RISCV_HWPROBE_KEY_*` requires updating `RISCV_HWPROBE_MAX_KEY`, `hwprobe_one_pair()`, and `hwprobe_key_is_bitmask()` (for bitmasks), using `1ULL << n` for flags at bit >= 31, and guarding kernel-dependent extensions (e.g., `has_vector()`, `CONFIG_RISCV_ISA_SUPM`) before `EXT_KEY()`. Unknown hwprobe keys must set `pair->key = -1` and continue without error. [F62, F82, F249, F327, F329]
- `struct user_regs_struct` must remain an exact prefix of `struct pt_regs` (bounding signal copies by `sizeof(sc->sc_regs)`). `uc_mcontext` must stay last in `struct ucontext`, `sc_extdesc.reserved` and `sc_fpregs->q.reserved[]` must be zeroed on setup and rejected with `-EINVAL` if non-zero on sigreturn, and `restore_sigcontext()` must validate `RISCV_V_MAGIC`, `size == riscv_v_sc_size`, and active vector state before `__restore_v_state()`. [F64, F142, F225, F227, F278, F332, F333]

## Known Pitfalls

- Vector crypto assembly `aes_encrypt/decrypt_zvkned()` and `sm4_crypt_zvksed_zvkb()` take `(key, src, dst)` (input before output), whereas scalar C fallbacks `aes_encrypt/decrypt()` and `sm4_crypt_block()` take `(key, dst, src)` (output before input). In `riscv64_aes_ctr_crypt()`, use `DIV_ROUND_UP` for `nblocks` on the final chunk and split encryption across 32-bit `ctr32` wraps with `crypto_inc(req->iv, 12)`. [F29, F77, F87]
- On RV64, 32-bit `lr.w` sign-extends bit 31 to 64 bits, so `futex_atomic_cmpxchg_inatomic()` must cast `oldval` via `(long)(int)oldval` and the 4-byte case of `_arch_cmpxchg()` must cast `__old` via `(long)(int)(long)`. In `__arch_cmpxchg128()`, `amocas.q` requires even-odd register pairs `t3`/`t4` (`"+&r"`) and `t1`/`t2` (`"rJ"`). [F80, F81, F125]
- Splitting a 32-bit value across `lui`/`auipc` and `addi`/`jalr` (`riscv_insn_insert_utype_itype_imm()`, `__runtime_fixup_32()`) must add `0x1000` to the upper 20 bits when bit 11 is set. When combining 16-bit instruction parcels, cast the high parcel to `u32` before `<< 16` and mask the low parcel with `GENMASK(15, 0)` in `get_insn()`. Cast extracted immediates in `simulate-insn.c` to `s32`. [F84, F266, F272, F273]
- Slot 0 of `struct pt_regs` is `epc` (not `x0`), so code indexing `(unsigned long *)regs` by register number (`rv_insn_reg_get/set_val()`, `get_step_address()`) must treat index 0 as zero. In `simulate_jalr()`, read `rs1_index` before writing `rd_index`. In `riscv_insn_is_c_jr/c_jalr()`, check `(code & RVC_INSN_J_RS1_MASK) != 0`. In `kprobes.c`, cast `u32 *` instruction pointers to `(void *)` before adding byte lengths. [F75, F219, F229, F280]
- In `uaccess.h`, `__put_user(x, ptr)` must evaluate `x` before `__enable_user_access()`, `__put_user_nocheck()` must name its temporary `___val` (three underscores) to avoid shadowing, 32-bit `__get/put_user_8()` must cast via `(__typeof__((x) - (x)))`, and multi-statement case macros must use `do { ... } while (0)`. [F71, F92, F121, F146]
- In `__switch_to`, mask `TASK_THREAD_SUM_RA(a4)` with `SR_SUM` before `csrs CSR_STATUS, s0`. In `copy_thread()`, store `args->flags` in a `u64`. When copying/zeroing `struct __riscv_v_ext_state` metadata, use `offsetof(struct __riscv_v_ext_state, datap)` so `datap` is not overwritten. [F205, F264, F277]
- Never pass vmalloc or `DEFINE_PER_CPU()` addresses directly to `__pa()` for SBI calls (`sbi_cpu_start()`, `sbi_debug_console_*()`); use `page_to_phys(vmalloc_to_page(addr)) + offset_in_page(addr)` for vmalloc. Under `CONFIG_RISCV_ISA_SVNAPOT`, `pte_pfn(pte)` must strip the lowest set PFN bit (`res & (res - 1UL)`). In `THEAD_CMO_OP()` and `ALT_CMO_OP()`, align `_start` with `~((_cachesize) - 1UL)`. [F88, F140, F314]
