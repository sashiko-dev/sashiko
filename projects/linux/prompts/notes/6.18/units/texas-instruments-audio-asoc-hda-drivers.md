# TEXAS INSTRUMENTS AUDIO (ASoC/HDA) DRIVERS

This unit comprises Texas Instruments HDA side-codec and ASoC audio codec and smart amplifier drivers, including the PCM1681/1789/179x/186x/3008/3060/3168a/5102a/512x series, TAS2552/2562/2764/2770/2780/2781/2783 amplifiers (and shared TAS2781 I2C/firmware libraries), and TLV320 series codecs/ADCs. It manages multi-device book/page regmap access, SoundWire SDCA and CCF clock providers, binary DSP/RCA/calibration firmware loading, DAPM routing, and hardware fault/thermal monitoring.

## Architecture & Data Flow
- `tasdevice_regmap` must keep `.cache_type = REGCACHE_NONE` because one `regmap` is shared across multiple I2C addresses (`tasdev->dev_addr`) and `TASDEVICE_BOOKCTL_REG` is outside `tasdevice_ranges`. In `tasdevice_change_chn_book()` and `tasdev_chn_switch()`, changing `client->addr` must immediately write `0` to `TASDEVICE_PAGE_SELECT`, and `tasdev->cur_book` must only update after writing `TASDEVICE_BOOKCTL_REG` succeeds [F51, F52, F53].
- `tasdevice_init()` and `tas2781_system_resume()` must reset `tas_priv->tasdevice[i]` `cur_book`, `cur_prog`, and `cur_conf` to `-1` before hardware reset or DSP load. In `tasdevice_select_tuningprm_cfg()` and `tasdevice_prmg_load()`, setting `is_loading = true` must also reset `cur_conf = -1`, and `tasdev_load_calibrated_data()` must run after `tasdevice_load_data(tas_priv, &(conf->dev_data))` so config writes do not overwrite calibration [F39, F206, F283].
- In `tas2781_hda_i2c.c`, both `tasdevice_dspfw_init()` and `tas2781_system_resume()` must check `tas_priv->rcabin.init_profile_id >= 0` after `tasdevice_prmg_load()` and apply `TASDEVICE_BIN_BLK_PRE_POWER_UP` via `tasdevice_select_cfg_blk()`. When `fw_state == TASDEVICE_RCA_FW_OK`, `tas_priv->fmw` is `NULL` (freed via `tasdevice_dsp_remove()` if DSP parse fails in `tasdevice_fw_ready()`), so `tasdevice_tuning_switch()` and `tasdevice_startup()` must allow playback in both states and check `tas_priv->fmw != NULL` [F55, F191, F209, F285].
- In `tas2764.c`, `tas2770.c`, and `tas2562.c`, `PWR_CTRL` mode bits encode both `dac_powered` and `unmuted` and must be updated via `*_update_pwr_ctrl()`. `tas2764_mute()` must step through `TAS2764_PWR_CTRL_MUTE` (sleeping 6-7 ms on mute before `dac_powered = false`). `tas2764`/`tas2770` suspend must not clear `dac_powered`/`unmuted` and resume must call `*_update_pwr_ctrl()` before `regcache_sync()`, while `sense_event()` (`tas2770.c`) must cycle `TAS2770_PWR_CTRL_MASK` through `SHUTDOWN` on `PRE_REG` and restore on `POST_REG` [F60, F61, F62, F100].
- In `tas2764_set_bitwidth()`, `tas2780_set_bitwidth()`, and `tas2562_set_bitwidth()`, TDM sense bits (`VSNS_ENABLE`/`ISNS_ENABLE`) must be set only when active-low `VSENSE_POWER_EN`/`ISENSE_POWER_EN` in `PWR_CTRL` is `0`. In `tas2764`/`tas2770`/`tas2780` `set_dai_tdm_slot()`, every branch extracting `left_slot` or `right_slot` must clear that bit in `tx_mask` before the trailing validation check [F63, F87].
- Because `pcm512x_probe()` only fails on `-EPROBE_DEFER` from `devm_clk_get()`, `pcm512x->sclk` can be an `ERR_PTR`; all `clk_*` calls on `sclk` must check `!IS_ERR(pcm512x->sclk)` and `pcm512x_dai_startup_master()` must reject `IS_ERR(pcm512x->sclk)`. Also, `pcm512x_i2c_probe()` must copy `pcm512x_regmap` locally before setting `read_flag_mask`/`write_flag_mask = 0x80`, and `pcm3168a_probe()` must copy `pcm3168a_dais` into `pcm3168a->dai_drv` because `pcm3168a_update_fixup_pcm_stream()` mutates `dai->driver` in place [F32, F66, F69, F116].
- In `tas2781-fmwlib.c`, `tasdev_blk_data::dev_idx` and `tasdev_blk::dev_idx & 0x3F` use `0` as a broadcast sentinel for all `ndev` channels and `1..ndev` as 1-based indices (subtract 1 before indexing `tasdevice[]`), while `dev_idx & 0xC0` tags RCA (`0x00`), DSP program (`0x80`), and DSP coeff/pre (`0xC0`) blocks in `map_dev_idx()`. Signed indices (`prm_no`, `cfg_no`, `rca_conf_no`, `conf_no`) can be `-1` and must be checked `>= 0` before indexing [F220, F221, F222].
- In `tas2783-sdw.c`, `tas_update_status()` must set `hw_init = false` on `SDW_SLAVE_UNATTACHED` and on `SDW_SLAVE_ATTACHED` exit cache-only mode, sync regcache, and run `tas_io_init()` (resetting `fw_dl_task_done` and `fw_dl_success` to `false`) before `hw_init = true`. In `tas2783_sdca_dev_resume()`, if `slave->unattach_request` is set, it must wait on `slave->initialization_complete` before `regcache_cache_only(false)`. Every regmap register must have a size entry in `tas2783_sdca_mbq_size()` [F212, F235, F289].
- In paged regmaps (`aic32x4`, `aic31xx`, `adc3xxx`), adding a higher-paged register requires updating both `regmap_config.max_register` and `regmap_range_cfg.range_max`. In `tlv320aic31xx.c`, DAC-only variants (`codec_type & DAC31XX_BIT`) must skip ADC controls/widgets/routes/DAI; `aic31xx_power_on()` must call `aic31xx_set_jack()` after `regcache_sync()` because `AIC31XX_HSDETECT` is volatile; and `aic31xx_setup_pll()` must verify `sysclk` and `p_div` are non-zero before dividing and only assign `rate_div_line = match` when `match != -1` [F214, F217, F237, F264, F295].

## Synchronization
- In `tas2781_hda_i2c.c` and `tas2781-i2c.c`, `tas_priv->codec_lock` must be held for all post-probe amplifier register accesses, `tas2781-fmwlib.c` parser/loader calls, calibration kcontrols, `tasdev_chn_switch()`, and `acoustic_ctl_write()`, because `tasdevice_change_chn_book()` mutates shared `i2c_client->addr`, `TASDEVICE_PAGE_SELECT`, and `cur_book`. In `tas2781_hda_i2c.c`, callers must invoke `pm_runtime_get_sync()` before locking `codec_lock` and unlock before `pm_runtime_put_autosuspend()` [F18, F19, F177, F180].
- In `tascodec_init()`, `tas_priv->codec_lock` must be held while initializing `tas_priv->codec` and calling `request_firmware_nowait()`, and `tas_priv->codec` must be assigned before `request_firmware_nowait()` because `tasdev_fw_ready()` reads it before locking `codec_lock`. Firmware-dependent kcontrols in `tasdevice_dspfw_init()` and `tasdevice_fw_ready()` must only be registered after their respective RCA or DSP parser succeeds [F16, F17, F21, F178].
- In `tas2783-sdw.c`, `tas_io_init()` must not hold `pde_lock` or `calib_lock` while waiting on `fw_wait`, and `tas2783_fw_ready()` must use `sdw_nwrite_no_pm()` because `tas_update_status()` blocks on `fw_wait` during slave attachment while `tas2783_fw_ready()` acquires `pde_lock` and `calib_lock`. `tas_sdw_hw_params()` and `tas_sdw_pcm_hw_free()` must hold `pde_lock` when toggling `TAS2783_SDCA_ENT_PDE23` power state [F288, F301, F302].
- In `pcm512x.c`, `pcm512x_digital_playback_switch_get()`, `pcm512x_digital_playback_switch_put()`, and `pcm512x_mute()` must hold `pcm512x->mutex` while accessing `pcm512x->mute` (`0x1` stream, `0x2` right, `0x4` left) and `PCM512x_MUTE`, and `pcm512x_mute()` must poll volatile `PCM512x_ANALOG_MUTE_DET` via `regmap_read_poll_timeout()` for `(~pcm512x->mute >> 1) & 0x3` [F9, F89, F132].
- `tas2764_irq()` and `aic31xx_irq()` perform sleeping I2C regmap calls and must be registered as threaded IRQs (`IRQF_ONESHOT`). In `tas2764_codec_probe()`, `tas2764->component` assignment, `tas2764_reset()`, `regmap_reinit_cache()`, and `TAS2764_INT_MASK0..4` programming (`0` = unmask, `1` = mask) must complete before `devm_request_threaded_irq()`. `aic31xx_irq()` must check `if (aic31xx->jack)` before `snd_soc_jack_report()`, and `pcm1789_trigger()` must defer soft-reset writes to `pcm1789_work_queue()` [F25, F26, F123, F142, F143, F186, F306].

## Object Lifetimes
- Async firmware callbacks must clean up on every exit path: `tasdev_fw_ready()` must unlock `codec_lock`, call `release_firmware(fmw)`, and call `pm_runtime_put_autosuspend()`; `tasdevice_fw_ready()` must unlock `codec_lock` and call `release_firmware(fmw)`; `tas2783_fw_ready()` must unlock `pde_lock` if held, set `fw_dl_task_done = true`, call `wake_up(&tas_dev->fw_wait)`, and call `release_firmware(fmw)`; `tas2781_load_calibration()` must initialize `fw_entry = NULL` and release it at `out:` [F3, F161, F162, F166, F190].
- In `tas2781-fmwlib.c`, `tasdevice_rca::cfg_info` and `tasdevice_config_info::blk_data` are pointer arrays of individually `kzalloc`-allocated elements (bounded by `rca->ncfgs` and `real_nblocks`) that `tasdevice_config_info_remove()` must `kfree` individually before freeing the outer arrays. Conversely, `tasdevice_fw` `programs`, `configs`, `calibrations`, and `dev_blks` are contiguous `kcalloc` struct arrays where teardown must only `kfree` each `block->data` and the array base pointer [F248, F268, F269].
- In `tas2781_hda_unbind()`, `comp->playback_hook`, `comp->dev`, and `comp->name` must be cleared, `tas2781_hda_remove_controls()` must remove card kcontrols, and `fw_state` must be reset to `TASDEVICE_DSP_FW_PENDING` before `tasdevice_config_info_remove()` and `tasdevice_dsp_remove(tas_hda->priv)` free firmware state (which must always set `tas_dev->fmw = NULL`); `tasdevice_dspfw_init()` must also call `tasdevice_dsp_remove()` before reloading firmware [F20, F58, F120, F151].
- In `tas2781_hda_i2c_probe()`, `tas2781_read_acpi()` must release `put_device(physdev)` and `acpi_dev_put(adev)` on all exit paths, and any failure after `tasdevice_init()` must jump to `err:` so `tas2781_hda_remove()` calls `tasdevice_remove()` (after `component_del()` and `pm_runtime_disable()`) to destroy `codec_lock`. In `tas2781-i2c.c`, `tasdev[i].cali_data_backup` (`kmemdup`) must be `kfree`d in `tasdevice_deinit()`, whereas `devm_*`-allocated kcontrols and `ext_cali_data`/`ext_cali_start` must not be manually freed or stack-allocated [F6, F7, F22, F167, F278].
- In `tlv320aic32x4.c`, `aic32x4_setup_regulators()` and `aic32x4_disable_regulators()` must guard optional `supply_ldo`, `supply_dv`, and `supply_av` with `!IS_ERR(...)` and unwind in reverse order. `aic32x4_register_clocks()` must run after reset and before `devm_snd_soc_register_component()`; `clk_bulk_data` arrays passed to `devm_clk_bulk_get()` must remain `static` (never stack-allocated); and in `aic32x4_set_bias_level()`, `SND_SOC_BIAS_STANDBY` must skip `clk_bulk_disable_unprepare()` when coming from `SND_SOC_BIAS_OFF` [F170, F171, F172, F277, F299].

## API Contracts
- Callers of `tascodec_init()` must pass their own `THIS_MODULE`. Because `tas2781-comlib-i2c.c` and `tas2781-fmwlib.c` are shared between HDA (`drvdata` is `struct tas2781_hda *`, `codec` is `struct hda_codec *`) and ASoC (`drvdata` is `struct tasdevice_priv *`, `codec` is `struct snd_soc_component *`), shared library code must never call `dev_set_drvdata()`/`dev_get_drvdata()` on `tas_priv->dev` or downcast `tas_priv->codec`, and HDA callers/kcontrols must pass `tas_hda->priv` (`struct tasdevice_priv *`) rather than `tas_hda` or `tas_hda->hda_priv` [F1, F54, F109, F110, F111, F112, F275].
- `tasdevice_dev_read()`, `tasdevice_dev_bulk_read()`, `tasdevice_dev_write()`, `tasdevice_dev_bulk_write()`, and `tasdevice_dev_update_bits()` must check `chn < tas_priv->ndev`, select `TASDEVICE_BOOK_ID(reg)` via `change_chn_book()`, and pass `TASDEVICE_PGRG(reg)` to `regmap`. `tasdev_chn_switch()` must return `1` when changing `client->addr`, `0` when unchanged, and negative errno on `regmap_write` failure [F27, F77].
- Every `snd_soc_dai_ops` whose `.mute_stream` mutes playback without checking `direction` (`tas2764`, `tas2770`, `tas2780`, `tas2552`, `tas2562`, `pcm3168a`) must set `.no_capture_mute = 1`. All `*_set_dai_tdm_slot()` callbacks must verify `tx_mask != 0` before calling `__ffs()`/`__fls()` (including after clearing `1 << left_slot`), and `tas2562`, `tas2770`, and `pcm3168a` `set_tdm_slot` must accept `slot_width == 0` [F91, F107, F145].

## Error Handling
- `tasdevice_add_config()` never clears `*status` on success and returns a non-NULL partially populated struct on failure (stored in `rca->cfg_info[i]` after incrementing `rca->ncfgs`), so callers must initialize `*status = 0`, check `*status` rather than NULL, and call `tasdevice_config_info_remove()` if `tasdevice_rca_parser()` fails. In `tasdev_load_calibrated_data()`, both `cali_data_fmw` and `cal_fmw->calibrations` must be checked for non-NULL [F163, F189, F192].
- `tasdevice_amp_putvol()` and `tasdevice_digital_putvol()` must clamp `ucontrol->value.integer.value[0]` to `[0, mc->max]` via `tasdevice_clamp()`, attempt all `tas_priv->ndev` channels counting failures in `err_cnt`, and return `(err_cnt == tas_priv->ndev) ? 0 : 1`. `tas2781_get_i2c_res()` must ignore `sb->slave_address == tas_priv->global_addr`, stop at `TASDEVICE_MAX_CHANNELS`, and always return `1` [F28, F29, F76, F150].
- On `regcache_sync()` failure, `pcm186x_power_on()` and `aic31xx_power_on()` must restore `regcache_cache_only(regmap, true)` and call `regulator_bulk_disable()`; `tas2770_codec_suspend()` must restore `regcache_cache_only(false)` and `regcache_sync()` if `snd_soc_component_update_bits()` fails when `sdz_gpio` is NULL. In `tas2764_parse_dt()` and `tas2770_parse_dt()`, non-`-EPROBE_DEFER` errors from `devm_gpiod_get_optional()` must reset `sdz_gpio = NULL` [F35, F36, F37, F173].

## External Contracts
- In `tas2563_save_calibration()`, `efi_rt_services_supported(EFI_RT_SUPPORTED_GET_VARIABLE)` must be checked before `efi.get_variable()`; `efi_name` must be zeroed on every inner loop iteration with `k` bounded by `sizeof(var8)`; UEFI variable names use 1-based `i + 1`, whereas `cd->data` stores `p->ndev` records of `1 + cali_dat_sz_per_dev` bytes (0-based index `i` followed by big-endian `__be32` values). In `tas2783_fw_ready()`, payload writes must use `hdr.length - FW_FL_HDR` (12) because `read_header()` already advances `offset` by 12 [F31, F41, F44, F114, F234].

## Known Pitfalls
- Unlike `tasdevice_dev_*()`, `tasdev_chn_switch()` does not check `chn < tas_priv->ndev`, and `tasdev_multibytes_chksum()` must reject `(reg + len - 1) > 127` before reading into `nBuf1[128]`. In `tas2781-i2c.c` calibration, `cali_reg_update()` and `partial_cali_data_update()` must match against immutable `tas2781_cali_start_reg[j].reg` (not `p[j].reg`), `sngl_calib_start()` must read existing registers into `cali_data_backup` (`bulk_reg_val::val` >= 4 bytes) before writing start values, and protected test registers must set `is_locked = true` [F78, F210, F211, F228, F272, F282].
- 64-bit/divider math: `pcm512x_find_sck()` and `pcm512x_pllin_dac_rate()` return `0` on error (`unsigned long`), which `pcm512x_set_dividers()` must check before dividing; `pcm512x_find_pll_coeff()` must reset `R = 1` before checking `num > 0xffffffffUL / 10000` and use `u64` with `DIV_ROUND_CLOSEST_ULL()`/`DIV_ROUND_DOWN_ULL()` in `fallback:`; `clk_aic32x4_pll_calc_muldiv()` (returns signed `int`) and `clk_aic32x4_pll_calc_rate()` (returns `unsigned long`) must cast rates to `u64` and use `DIV_ROUND_UP_ULL()`/`do_div()` [F30, F95, F101, F102, F198, F261].
- In `tas2764` and `tas2770`, deasserting `sdz_gpio`/`reset_gpio` or writing `SW_RST` requires `usleep_range(1000, 2000)` before register access, and software reset in codec probe must be followed by `regmap_reinit_cache()`. In `tas2764`, `TAS2764_INT_LTCH0..4`, `TAS2764_INT_CLK_CFG`, and pages `0xf0..0xff` must remain volatile, `tas2764_irq()` (`IRQF_SHARED`) must return `IRQ_NONE` when `latched[0] == 0` and set `TAS2764_INT_CLK_CFG_IRQZ_CLR` when non-zero, and hidden page `0xfd` sequences must bracket accesses with `TAS2764_REG(0xfd, 0x0d) = 0xd` and `0x0` [F59, F64, F122, F124, F125, F155].
