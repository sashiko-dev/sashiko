# INTEL ASoC DRIVERS

This unit implements ALSA SoC (ASoC) machine drivers, shared board and topology helpers, and ACPI match tables for Intel platforms from Bay Trail/Cherry Trail through Sound Open Firmware (SOF), HDA-DSP, and SoundWire systems, alongside the Wildcat Point / Lynx Point AudioDSP (`catpt`) platform driver.

## Architecture & Data Flow
- In `sof_board_helpers.c`, `calculate_num_links()` and the `link_order` loop in `sof_intel_board_set_dai_link()` must count and populate the exact same enabled BE links (`idx == num_links`). Each 4-bit nibble in `ctx->link_id_overwrite` (`SOF_LINK_IDS`) must be `<= 0xF` and aligned 1:1 with `link_order`, and `SOF_LINK_NONE` (`0`) may only appear in trailing arguments of `SOF_LINK_ORDER()`. [F37, F81, F82]
- When creating iDisp HDMI DAI links in `sof_board_helpers.c`, `sof_es8336.c`, and `sof_pcm512x.c`, the HDMI index `i` (`hdmi_id`) is 1-based (`1..hdmi_num`) for formatting `"iDisp%d"`, `"iDisp%d Pin"`, and `"intel-hdmi-hifi%d"`, while `idisp_components` is indexed 0-based as `idisp_components[i - 1]`. [F61]
- In `sof_sdw.c:sof_card_dai_links_create()`, `card->codec_conf` and `card->dai_link` must be assigned before calling `create_*_dailinks()` because those helpers advance the local pointers in place. Each link must allocate its own `snd_soc_dai_link_component *platform` rather than sharing a static array, and `asoc_sdw_dmic_init` / `sof_sdw_hdmi_init` must only be passed on the first DMIC (`"dmic01"`) and HDMI (`i == 0`) link. [F175, F215, F227]
- In `sof_sdw.c`, `dmic_num` (DAI link count) must not overwrite `mach_params->dmic_num` (mic channel count for `cfg-mics:%d`), which must be `0` when `ctx->ignore_internal_dmic` is true. In `sof_sdw_get_tplg_files()`, `tplg_mask` must test and set `BIT(tplg_dev)` to deduplicate function types across `for_each_card_prelinks()`, indexing `(*tplg_files)` by `tplg_num++` rather than the link cursor `i`. [F174, F212]
- In `snd_soc_acpi_intel_*_sdw_machines` tables, `.links` arrays must end with a `{}` sentinel, and entries with more active links in `.link_mask`, more devices in `.links`, or a `.machine_check` callback must precede subset entries. In I2S `snd_soc_acpi_mach` tables, `.machine_quirk` entries must precede generic entries for the same codec, and amp-only boards must be placed at the end. In `soc-acpi-intel-ssp-common.c`, dual-role codec/amps (like `RT5650`) must be in both `codecs[]` and at the end of `amps[]`. [F178, F181, F198, F199]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `sof_es8336.c`, software node properties on `codec_dev` must be registered after quirk resolution and before `devm_snd_soc_register_card()`, and `MAX_NO_PROPS` must exceed the maximum `props[cnt++]` assignments on any path by at least 1 for the zeroed sentinel. [F42, F64]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `bytcr_wm5102.c`, `log_quirks()` must validate multi-bit routing fields (which `quirk_override` can set to any `int`) and reset unrecognized values to defaults before probe indexes `map_name`, `mic_name`, or `out_map_name`. In `byt_rt5640_quirk_table[]`, specific DMI entries (`T100TAF`) must precede prefix matches (`T100TA`), with the generic Insyde catch-all last. [F55, F57]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, and `cht_bsw_rt5645.c`, SSP0/SSP2 and AIF1/AIF2 quirk flags must update the BE link `dai_name` in probe, SSP-to-AIF DAPM routes in init, and 16-bit (SSP0) vs 24-bit (SSP2) TDM slot width in `be_hw_params_fixup` in lockstep. [F53]
- In `max_98373_hw_params()`, `max_98390_hw_params()`, and `rt1011_hw_params()`, the codec loop index `i` from `for_each_rtd_codec_dais()` must be bounds-checked against `ARRAY_SIZE` of the TDM mask table, and `max_98373_hw_params()` must check `fls(tx_mask) <= tdm_slots` and `fls(rx) <= tdm_slots`. In `sof_cirrus_common.c`, `cs35l41_compute_codec_conf()` indexes `cs35l41_components[sz]` by `sz` but `cs35l41_name_prefixes[uid]` by ACPI UID (`0..3`). [F56, F59]
- In `catpt`, `catpt_sram_init()` sets inclusive bounds `[start, start + size - 1]`. Whenever `cdev->dram` or `cdev->iram` regions are requested or released after boot, `catpt_dsp_update_srampge()` must be called; because `VDRTCTL0` bits are active-low (`0` = powered, `1` = gated), busy block masks must be inverted (`~(new << __ffs(mask)) & mask`) and enabled blocks iterated with `for_each_clear_bit_from()`. [F166, F194, F214]
- In `catpt/pcm.c`, inactive stream kcontrol changes cached in `kcontrol->private_value` must be applied in `catpt_dai_hw_params()` via `catpt_dai_apply_usettings()` after `catpt_ipc_alloc_stream()`, checking `!list_entry_is_head()` after `list_for_each_entry()`. `catpt_stream_volume()` and `catpt_mixer_volume()` must clamp `channel >= CATPT_CHANNELS_MAX` to `0`, `ctlvol_to_dspvol()` must clamp `value > DSP_VOLUME_STEP_MAX` (30) to `0`, and `dspvol_to_ctlvol()` must check `volume > DSP_VOLUME_MAX` and `volume != 0` before `__fls(volume)`. [F171, F188, F206, F219]

## Synchronization
- In `catpt_dsp_do_send_msg()`, `catpt_ipc_msg_init()` and `catpt_dsp_send_tx()` must run together under `spin_lock_irqsave(&ipc->lock, flags)` after verifying `request.size` and `reply->size` do not exceed `ipc->config.outbox_size`. In `catpt_dsp_irq_handler()` and `catpt_dsp_irq_thread()`, `catpt_dsp_copy_rx()` and `catpt_dsp_process_response()` must finish reading the mailbox and signaling completions before clearing `CATPT_IPCC_DONE` or setting `CATPT_IPCD_DONE` and unmasking `CATPT_IMC_IPCCD`/`CATPT_IMC_IPCDB`. [F141, F144, F187]
- `catpt_dsp_send_msg()`, `catpt_ipc_*` wrappers, and `catpt_dsp_process_response()` sleep or allocate with `GFP_KERNEL`/`vzalloc()`, so `CATPT_ISC_IPCDB` must be masked in `catpt_dsp_irq_handler()` and processed in `catpt_dsp_irq_thread()`. `cdev->list_lock` uses non-IRQ-saving `spin_lock()`, so `catpt_stream_find()` and `cdev->stream_list` must never be accessed from hardirq context. [F254, F255, F256]
- DAI links using `sof_es8336_ops`, `max_98373_ops`, `sdw_ops` in `sof_sdw.c`, `catpt_fe_dai_ops`, and BYT/CHT front-end DPCM links on `"sst-mfld-platform"` must all use `nonatomic = true` because their trigger/stream ops sleep. [F110, F111, F112, F149, F257]

## Object Lifetimes
- Every `struct acpi_device *adev` from `acpi_dev_get_first_match_dev()` must remain held until all uses (`acpi_dev_name()`, `acpi_get_first_physical_node()`, `acpi_dev_gpio_irq_get()`, `acpi_fwnode_handle()`) complete, and then be released with `acpi_dev_put(adev)` on all paths. [F1, F139]
- `acpi_get_first_physical_node()` returns a borrowed `struct device *` whereas `bus_find_device_by_name()` returns an owned reference; drivers storing `priv->codec_dev` from `acpi_get_first_physical_node()` must call `get_device()` and release it with `put_device()` on probe error and in `.remove` (including when `byt_rt5640_add_codec_device_props()` or `byt_rt5651_add_codec_device_props()` fails). [F2, F5]
- When attaching software nodes to `codec_dev` via `fwnode_create_software_node()` and `device_add_software_node()`, callers must unconditionally call `fwnode_handle_put(fwnode)` immediately and call `device_remove_software_node(priv->codec_dev)` before `put_device(priv->codec_dev)` on probe failure and in `.remove`. [F3, F96]
- Non-devm GPIO descriptors acquired on `codec_dev` (`spkvdd_en_gpio` in `bytcr_wm5102.c`, `speaker_en_gpio` in `bytcht_es8316.c`, `gpio_speakers` in `sof_es8336.c`) must not use `devm_gpiod_get(codec_dev, ...)` and must be released with `gpiod_put()` on probe failure and in `.remove`. In `sof_es8336_remove()`, `cancel_delayed_work_sync(&priv->pcm_pop_work)` must precede `gpiod_put(priv->gpio_speakers)`, `device_remove_software_node()`, and `put_device()`. [F6, F7]
- Codec DAI link `.exit` callbacks (`sof_es8316_exit`, `sof_rt5682_codec_exit`, `da7219_codec_exit`, `sof_cs42l42_exit`, `sof_nau8825_codec_exit`) must clear the card-owned jack via `snd_soc_component_set_jack(component, NULL, NULL)`. Strings assigned to `snd_soc_dai_link_component.name` or `snd_soc_card` `.name`/`.long_name`/`.components` must reside in static or `devm_*` storage, never stack buffers. [F10, F93]
- Before calling `clk_set_rate()` on platform MCLK in codec `.init` callbacks, drivers must call `clk_prepare_enable()` and immediately `clk_disable_unprepare()`. In `platform_clock_control()` DAPM callbacks for codecs using PLL off MCLK (`bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `cht_bsw_rt5645.c`, `cht_bsw_rt5672.c`), the codec sysclk/FLL must be switched away from MCLK before `clk_disable_unprepare()` disables `mclk`. [F12, F13]
- In `sof_sdw.c`, `mc_probe()` must reset `codec_info_list[i].amp_num = 0` before `sof_card_dai_links_create()` and call `asoc_sdw_mc_dailink_exit_loop(card)` on `devm_snd_soc_register_card()` failure and in `mc_remove()`. `sof_card_dai_links_create()` must `kfree()` temporary `sof_ends` and `sof_dais` arrays on both success and all error paths. [F137, F138, F162]
- In `catpt`, `catpt_dsp_power_up()` must put the device in D0 before `catpt_dmac_probe()`, and `catpt_dmac_remove()` must precede `catpt_dsp_power_down()` on probe error and in `catpt_acpi_remove()` (which must call `pm_runtime_disable()` before `catpt_dmac_remove()`). In `catpt_suspend()`, DSP stall, DMA context saves, and `dma_release_channel(chan)` must complete before `catpt_dsp_power_down()`. [F126, F127, F129]
- In `catpt`, every SRAM child `struct resource` from `catpt_request_region()` or `__request_region()` must be unlinked with `release_resource(res)` and freed with `kfree(res)` (saving `res->sibling` first in `catpt_sram_free()`). In `catpt_dai_shutdown()`, `stream->node` must be unlinked from `cdev->stream_list` under `cdev->list_lock` before freeing `stream->persistent`, updating SRAM power gating, freeing `stream->pgtbl` and `stream`, and clearing DAI `dma_data`. [F131, F132, F207]

## API Contracts
- `sof_intel_board_get_ctx()` returns `NULL` (not `ERR_PTR`) on allocation failure, and driver-specific `board_quirk` flags passed to it must stay within bits `0..7` (bits `8..31` are reserved for `SOF_SSP_*`, `SOF_NUM_IDISP_HDMI_MASK`, and `SOF_BT_OFFLOAD_PRESENT`). `SOF_SSP_PORT_CODEC()`, `SOF_SSP_PORT_AMP()`, and `SOF_SSP_PORT_BT_OFFLOAD()` take a 0-based port index (`0..7`), whereas `SOF_SSP_MASK_HDMI_CAPTURE()` takes a 6-bit port bitmask. [F21, F31, F83]
- `sof_intel_board_set_dai_link()` leaves `codecs` and `num_codecs` unpopulated on `ctx->codec_link` and `ctx->amp_link` for the caller to initialize. Drivers calling `sof_intel_board_card_late_probe()` or using `sof_intel_board_set_dai_link()` HDMI links must store `struct sof_card_private *` in `card->drvdata`, whereas `sof_sdw.c` and `sof_sdw_hdmi.c` store `struct asoc_sdw_mc_private *` in `card->drvdata` and `struct intel_mc_ctx *` in `ctx->private`. [F15, F92, F229]
- `sof_dai_get_mclk()`, `sof_dai_get_bclk()`, and `sof_dai_get_tdm_slots()` return a negative errno on error or `0` when unconfigured; callers must store the result in a signed `int` and reject values `<= 0`. Machine drivers wiring `CODEC_MAX98373` via `max_98373_dai_link()` must call `max_98373_set_codec_conf(card)` and disable `'Left Spk'` and `'Right Spk'` in `card->late_probe` before `sof_intel_board_card_late_probe()`. [F22, F46, F68]
- In `sof_sdw.c`, `num_devs` and `num_ends` must be initialized to `0` before `asoc_sdw_count_sdw_endpoints()`, and `sof_dais` must be allocated with `kcalloc(num_ends + 1, ...)` for the zeroed sentinel. `intel_ctx->sdw_pin_index[i]` must be initialized to `SOC_SDW_INTEL_BIDIR_PDI_BASE`, and 1-hot `sof_end->link_mask` converted to a 0-based index via `ffs(sof_end->link_mask) - 1`. [F160, F161]
- In `catpt`, `catpt_dma_request_config_chan()` returns an `ERR_PTR` on failure and an owned `struct dma_chan *` on success that callers must release with `dma_release_channel()`. `catpt_coredump()` transfers ownership of the `vzalloc()` buffer to `dev_coredumpv()` and must not call `vfree()`. Header-only IPC helpers in `catpt/messages.c` must zero-initialize `struct catpt_ipc_msg request = { {0}}`. [F128, F135, F151]
- In `catpt`, host DRAM offsets sent to the DSP in `catpt_ipc_alloc_stream()` must use `catpt_to_dsp_offset()`, while DSP offsets in `cdev->dx_ctx.meminfo[i].offset` must use `catpt_to_host_offset()`. In `catpt_dsp_update_srampge()`, `catpt_dsp_power_down()`, and `catpt_dsp_power_up()`, core clock gating (`CATPT_VDRTCTL2_DCLCGE` in `VDRTCTL2`) must be disabled before modifying `VDRTCTL0`, `PMCS`, or SHIM/SSP power registers and re-enabled afterward. [F156, F238]

## Error Handling
- When scanning a `snd_soc_dai_link` array containing `COMP_DUMMY()` links (`byt_rt5640_dais`, `byt_rt5651_dais`, `byt_cht_es8316_dais`, `byt_wm5102_dais`, `cht_dailink`), code must check `num_codecs != 0` before dereferencing `codecs->name`. Card `late_probe` callbacks must check `idisp_codec` is true before calling `hda_dsp_hdmi_build_controls()` (which must release `snd_hdac_display_power(..., false)` even on error). [F11, F20, F26]
- In `sof_sdw.c`, `sof_end->codec_info->add_sidecar` and `sof_end->dai_info->init` must be checked for `NULL` before invocation in `create_sdw_dailink()`, `current_be_id` must be initialized to `0` before each `create_sdw_dailink()` call, and every `devm_kasprintf()` call in `sof_sdw.c` and `sof-function-topology-lib.c` must be checked for `NULL`. `sof_sdw_get_tplg_files()` must call `release_firmware(fw)` when `firmware_request_nowarn()` succeeds and return `0` (not negative errno) when a sub-topology file is missing. [F140, F157, F158, F159, F163]
- In `catpt`, `catpt_dsp_send_msg()` and `catpt_ipc_*` wrappers return either a negative errno or a positive `enum catpt_reply_status`; callers returning kernel errnos must check `if (ret)` and wrap non-zero values with `CATPT_IPC_ERROR(ret)`. In `catpt_dma_memcpy()`, `dmaengine_submit(desc)` must be checked with `dma_submit_error()` before `dma_wait_for_async_tx()`, still clearing `CATPT_HMDC_HDDA` on failure. [F150, F153]

## External Contracts
- Every `snd_soc_acpi_mach.drv_name` in `sound/soc/intel/common/soc-acpi-intel-*-match.c` and its matching `platform_device_id.name` must be `<= PLATFORM_NAME_SIZE - 1` (23) characters. When a `platform_driver` sets `.id_table` (`board_ids`, `ehl_board_ids`), it must include an entry matching `.driver.name` and end with `{ }`. In `sof_sdw.c:mc_probe()`, tokens formatted into `card->components` must be space-delimited (including leading space), and CS35L56 `snd_soc_acpi_adr_device` entries must use `"AMPn"` prefixes. [F99, F183, F184, F233]

## Known Pitfalls
- When deriving a 0-based SSP index from an NHLT link mask via `fls(mask) - 1` (`sof_es8336_probe()`, `skl_hda_get_board_quirk()`), verify `mask != 0` first to avoid underflowing to `-1`. In drivers with a signed `int quirk_override = -1` module parameter (`bytcht_es8316.c`, `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `sof_es8336.c`), quirk flags must not use `BIT(31)` or higher, and `pdev->id_entry->driver_data` must be read before `dmi_check_system()`. [F84, F85, F98]
- In `catpt_dmac_probe()`, the DMA mask must be `DMA_BIT_MASK(31)` because `catpt_dma_memcpy_todsp()`/`fromdsp()` set bits `31:20` (`CATPT_DMA_DSP_ADDR_MASK`) and `catpt_arrange_page_table()` packs 19-bit PFNs into 20-bit slots. When `catpt_dsp_set_srampge()` power-ungates SRAM blocks in `VDRTCTL0`, wait `udelay(60)` and do a 4-byte dummy `memcpy_fromio()` per block; cast `fw`/`mod`/`basefw` to `(u8 *)` before adding byte offsets in `catpt/loader.c`; and stage `img->data` via `dma_alloc_coherent()`. [F216, F226, F237, F259, F262]
