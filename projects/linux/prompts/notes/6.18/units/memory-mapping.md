# MEMORY MAPPING

The MEMORY MAPPING subsystem manages virtual memory areas (VMAs) and address space layout for user processes on MMU and no-MMU architectures, implementing VMA lifecycle, maple/interval tree indexing, merging, splitting, and page table manipulation for `mmap`, `munmap`, `brk`, `mremap`, `mprotect`, `mlock`, `mincore`, `msync`, and `mseal`.

## Architecture & Data Flow

- `vma_merge_existing_range()` and `vma_merge_new_range()` must verify `can_merge_remove_vma()` (`!vma->vm_ops || !vma->vm_ops->close`) on any VMA to be deleted (`middle` or `next`) because `vma_complete()` frees `vp->remove`/`vp->remove2` without `vma_close()`; if `vmg->__remove_next` holds but `!can_merge_remove_vma(next)` in a 3-way merge, it must degrade to a left-only merge (`merge_right = false; merge_both = false;`) with `if (merge_left) vmg->target = prev;` after `if (merge_right) vmg->target = next;`. [F4, F101, F159]
- In `can_vma_merge_right()`, when `can_merge_left` holds after `can_vma_merge_before(vmg)` succeeds, it must also check `!prev->anon_vma || !next->anon_vma || prev->anon_vma == next->anon_vma`; in `is_mergeable_anon_vma()`, when only one of `src_anon` or `tgt_anon` is non-NULL, `vma_had_uncowed_parents()` must be checked on whichever VMA (`src` or `tgt`) owns that `anon_vma`. [F99, F100]
- In `__mmap_region()`, `update_ksm_flags(&map)` must run before `vma_merge_new_range()` when `can_set_ksm_flags_early(&map)` holds (anonymous, `f_op->mmap_prepare`, or `shmem_file(file)`), whereas legacy `f_op->mmap` mappings must defer `update_ksm_flags(&map)` until after `__mmap_new_file_vma()`, and `khugepaged_enter_vma()` must only run when `!vma_is_anonymous(vma)`. [F77, F157]
- `vms_gather_munmap_vmas()` stores detached VMAs into `mas_detach` at indices `[0, vms->vma_count - 1]`; `vms_clear_ptes()` must position `mas_detach` at index 1 before passing `vms->vma` (index 0) to `unmap_vmas()` and `free_pgtables()`, whereas `vms_complete_munmap_vmas()` and `reattach_vmas()` start at index 0. [F88]
- In `move_normal_pmd()` and `move_normal_pud()`, `uffd_supports_page_table_move(pmc)` must check `!vma_has_uffd_without_event_remap()` on both `pmc->old` and `pmc->new` before checking `pmd_none(*new_pmd)` or `pud_none(*new_pud)`; when `move_ptes()` moves from a VMA where `vma_has_uffd_without_event_remap(vma)` holds, it must clear uffd-wp PTE markers via `pte_clear()` and strip uffd-wp bits via `pte_clear_uffd_wp()` and `pte_swp_clear_uffd_wp()`. [F62, F63]
- In `change_pte_range()` (`MM_CP_TRY_CHANGE_WRITABLE`), `commit_anon_folio_batch()` in private VMAs (`!(vma->vm_flags & VM_SHARED)`) must check `PageAnonExclusive()` on every `struct page` in a large folio batch (starting from `first_page` returned by `vm_normal_page()`, not `folio_page(folio, 0)`), and `can_change_shared_pte_writable()` in `VM_SHARED` VMAs must require `pte_dirty(pte)`. [F79, F167, F168]
- In `mlock_pte_range()`, `allow_mlock_munlock()` must skip mlocking a large folio (`vma->vm_flags & VM_LOCKED`) unless `folio_within_range(folio, vma, start, end)` holds and `step == folio_nr_pages(folio)`; `munlock_folio()` must leave clearing `PG_mlocked` to `__munlock_folio()`, which decrements `folio->mlock_count` under the lruvec lock, calls `folio_test_clear_mlocked()` only at zero, and checks `folio_evictable()` afterward. [F66, F96]

## Synchronization

- When `unlock` is `true`, `do_vmi_munmap()` and `do_vmi_align_munmap()` release `mm->mmap_lock` only when returning `0`; on any non-zero error return, `mm->mmap_lock` remains write-locked and must be unlocked by the caller. [F13]
- `expand_stack(mm, addr)` (in `mm/mmap.c` and `mm/nommu.c`) must be called with `mm->mmap_lock` read-locked; when returning a non-NULL VMA, `mm->mmap_lock` is held for reading (via `mmap_write_downgrade()`), whereas when returning `NULL`, it has already dropped `mm->mmap_lock`. [F14]
- Before inserting a VMA into `mm->mm_mt` (`vma_iter_store_new()`, `vma_iter_store_gfp()`), linking it via `vma_link_file()`, or cloning `anon_vma` via `dup_anon_vma(dst, src, ...)`, the caller must write-lock the VMA via `vma_start_write()`. [F22, F23]
- Before mutating an attached VMA's `vm_start`, `vm_end`, or `vm_pgoff` (or calling `vma_adjust_trans_huge()` and `hugetlb_split()` in `__split_vma()`), the caller must hold `mmap_write_lock`, `vma_start_write()` (on both `vma` and `new` in `__split_vma()`), `i_mmap_lock_write()`, and `anon_vma_lock_write()` via `vma_prepare(&vp)`, update interval tree nodes, and unlock via `vma_complete()`. [F24, F25]
- `mm_take_all_locks(mm)` requires `mm->mmap_lock` write-locked until `mm_drop_all_locks(mm)`, serializes via `mm_all_locks_mutex`, and locks in order: `vma_start_write()`, hugetlb `i_mmap_rwsem`, regular `i_mmap_rwsem`, and `anon_vma->root->rwsem` (where `vm_unlock_anon_vma()` must clear bit 0 of `rb_root.rb_root.rb_node` via `__test_and_clear_bit()` before `anon_vma_unlock_write()`). [F26, F92]
- In `__mmap_prepare()`, `vms_clean_up_area()` must unmap PTEs (`vms_clear_ptes()`) and invoke `vma_close()` on overlapping VMAs while still in `mm->mm_mt`, before `vma_merge_new_range()` or `__mmap_new_vma()` overwrites the range; in `exit_mmap()`, `mmu_notifier_release(mm)` must precede `mmap_read_lock(mm)` for `unmap_vmas()`, and `MMF_OOM_SKIP`, `mmap_write_lock(mm)`, `mt_clear_in_rcu(&mm->mm_mt)`, and `vma_mark_detached(vma)` must precede `remove_vma(vma)`. [F27, F39]
- In `sys_msync()` and `SYSCALL_DEFINE5(remap_file_pages)`, `vfs_fsync_range()` and `security_mmap_file()` must run outside `mm->mmap_lock` after `get_file(vma->vm_file)`; after reacquiring `mmap_lock`, the VMA must be re-looked up (`find_vma()`) and revalidated (`vma->vm_flags == vm_flags && vma->vm_file == file` in `remap_file_pages`) before `fput(file)`. [F31, F154]
- Whenever `vma->vm_flags` is updated on an established VMA (`mprotect_fixup()`, `__mmap_complete()`), `vma_set_page_prot()` must recompute `vma->vm_page_prot` and publish it via `WRITE_ONCE()`; `reusable_anon_vma()` must load `READ_ONCE(old->anon_vma)` into a local variable once before `list_is_singular(&old->anon_vma_chain)`; and `mlock_vma_pages_range()` must temporarily set `VM_IO` with `VM_LOCKED` via `vm_flags_reset_once()` during `walk_page_range()`. [F32, F33, F34, F61]
- `move_page_tables()` must call `flush_cache_range()` and bracket the move loop with `mmu_notifier_invalidate_range_start()`/`_end()` after `try_realign_addr()`; `take_rmap_locks(pmc->old)` must be held for `NORMAL_PMD`/`NORMAL_PUD` (`should_take_rmap_locks()`) and when `pmc->need_rmap_locks` holds; `new_ptl` must be locked via `spin_lock_nested(new_ptl, SINGLE_DEPTH_NESTING)` only when `new_ptl != old_ptl` and TLBs flushed before unlocking; and `move_normal_pmd()` must re-read `*old_pmd` under lock, aborting if `!pmd_present(pmd) || pmd_leaf(pmd)`. [F36, F37, F144, F146]
- In `mm/nommu.c`, `nommu_region_tree` and `struct vm_region` fields are protected by `nommu_region_sem` (nesting outside `i_mmap_rwsem`); linked regions must be removed via `delete_nommu_region()` and reinserted via `add_nommu_region()` under `nommu_region_sem` write lock when mutating bounds, and `__put_nommu_region(region)` requires `nommu_region_sem` held for writing and always drops it via `up_write(&nommu_region_sem)`. [F19, F42, F78]

## Object Lifetimes

- All VMA teardown and rollback paths (`remove_vma()`, `vms_clean_up_area()`, `copy_vma()`, `delete_vma()`) must call `vma_close(vma)` rather than `vma->vm_ops->close(vma)` directly, because `vma_close()` resets `vma->vm_ops` to `&vma_dummy_vm_ops` to prevent double `.close()`. [F1]
- Every successful `vma_iter_prealloc(vmi, ...)` in `__split_vma()`, `__mmap_new_vma()`, `expand_upwards()`, and `expand_downwards()` not consumed by a store/clear must call `vma_iter_free(vmi)`; when preallocating for `vma_iter_clear(vmi)` (`vma_shrink()`, `delete_vma_from_mm()`), the second argument to `vma_iter_prealloc()` must be `NULL`. [F8, F48]
- Stack-allocated `mt_detach` trees (`do_vmi_align_munmap()`, `__mmap_prepare()`) populated via `vms_gather_munmap_vmas()` must be destroyed on all paths via `vms_complete_munmap_vmas()`, `reattach_vmas()`, or `vms_abort_munmap_vmas()`; once `vms_clean_up_area()` clears `vms->clear_ptes`, `vms_abort_munmap_vmas()` must not call `reattach_vmas()`, but instead store `NULL` with `GFP_KERNEL|__GFP_NOFAIL` and call `vms_complete_munmap_vmas()`. [F6, F132]
- `vm_area_dup()` shallow-copies `vm_file`, `vm_policy`, and `anon_vma` without taking references, so callers (`__split_vma()`, `copy_vma()`, `dup_mmap()`) must separately acquire and on error unwind `vma_dup_policy()`, `anon_vma_clone()`/`anon_vma_fork()`, and `get_file()` before `vm_area_free()`. [F10]
- In `mmap_region()`, when `file && is_shared_maywrite(vm_flags)` holds, `mapping_map_writable(file->f_mapping)` must be unconditionally released by `mapping_unmap_writable(file->f_mapping)` after `__mmap_region()` returns; callers of `copy_vma()` and `vma_modify_flags*()` must refresh their VMA pointer from the return value or `*vmap` because merging can free the original `vm_area_struct`. [F7, F129]
- In `unmap_source_vma()`, when `(vma->vm_flags & VM_ACCOUNT) && !(vrm->flags & MREMAP_DONTUNMAP)` holds, `VM_ACCOUNT` must be cleared before `do_vmi_munmap()`, re-charged via `vm_acct_memory()` on failure, and restored on remaining prefix/suffix VMAs on success by testing `vm_start < addr` (`vma_prev(&vmi)`) and `vm_end > end` (`vma_next(&vmi)`) rather than using `vm_start` as a boolean. [F12, F107]

## API Contracts

- `vma_modify()` and its wrappers (`vma_modify_flags*()`, `vma_modify_name()`, `vma_modify_policy()`) return `IS_ERR()` on failure and never `NULL`, whereas `vma_merge_new_range()`, `vma_merge_existing_range()`, `vma_merge_extend()`, and `copy_vma()` return `NULL` on non-merge or OOM, requiring callers that cannot ignore OOM to check `vmg_nomem(vmg)` unless `vmg->give_up_on_oom` is set. [F43, F44]
- `do_mmap()`, `mmap_region()`, `__get_unmapped_area()`, and `do_mremap()` return an `unsigned long` checked via `IS_ERR_VALUE()`, and `do_mmap()` must initialize `*populate = 0` at entry before any error return; `vma_iter_config()`, `vma_iter_area_lowest()`, `vma_iter_area_highest()`, and `find_vma_intersection()` take an exclusive upper bound, whereas `mas_set_range()` and `__mas_set_range()` take an inclusive bound (`vm_end - 1`). [F55, F58, F59]
- After `__split_vma()` calls `vma_complete()`, it must reposition `vmi` onto the remaining `vma` via `vma_next(vmi)` when `new_below` is non-zero and `vma_prev(vmi)` when zero; in `vms_gather_munmap_vmas()`, `vms->vmi` must be rewound to `vms->start` via `vma_iter_prev_range(vms->vmi)` before returning `0`; and when `vmg->just_expand` is set for `vma_merge_new_range()`, `vmg->vmi` must start at `vmg->prev` and advance via `vma_iter_next_range(vmi)` if the merge fails with `vma` non-NULL. [F67, F71, F110]
- In `__get_unmapped_area()`, `pgoff` must be forced to `0` when `!file`, and `thp_get_unmapped_area_vmflags()` must only run after checking `get_area` and when `!file && !addr && IS_ALIGNED(len, PMD_SIZE)`; `set_vma_from_desc()` must use `vma_set_file()` and `vm_flags_set()` when updating `vma->vm_file` or `vma->vm_flags`. [F49, F97, F156]

## Error Handling

- File-backed VMA setup (`__mmap_new_file_vma()`, `do_mmap_shared_file()`, `do_mmap_private()`) must call `mmap_file()` rather than `vfs_mmap()` so `vma->vm_ops` is reset to `&vma_dummy_vm_ops` on failure; when `mmap_file()` fails in `__mmap_new_file_vma()`, it must call `fput(vma->vm_file)`, set `vma->vm_file = NULL`, and call `unmap_region(&vmi->mas, vma, map->prev, map->next)`. [F2, F3]
- When `dup_anon_vma()` clones `src->anon_vma` into `dst` with `dst->anon_vma == NULL` (recording `dst` in `*dup`), any failure in `commit_merge()` inside `vma_merge_existing_range()` or `vma_expand()` must call `unlink_anon_vmas(anon_dup)`, and `vma_merge_existing_range()` must restore `vmg->vmi` to `start` via `vma_iter_set()` and `vma_iter_load()`. [F5, F68]
- In `copy_vma_and_data()`, if `move_page_tables(&pmc)` is incomplete or `vma->vm_ops->mremap(new_vma)` fails, it must move `moved_len` bytes back to `vma` with `pmc_revert.need_rmap_locks = true` and set `vrm->vma = new_vma`, `vrm->old_len = vrm->new_len`, and `vrm->addr = vrm->new_addr`; when `copy_vma_and_data()` returns an error with `new_vma != NULL`, `move_vma()` must still call `vrm_stat_account()` and `unmap_source_vma()`; and `expand_vma_in_place()`/`copy_vma_and_data()` must not overwrite `vrm->vma` with `NULL` before `vrm_uncharge(vrm)`. [F11, F46, F56]
- In `dup_mmap()`, `mt_clear_in_rcu()` must be called after `__mt_dup()` and `mt_set_in_rcu()` re-enabled only on success; on error in `for_each_vma(vmi, mpnt)`, it must store `XA_ZERO_ENTRY` at `mpnt` (after `mpnt = vma_next(&vmi)` if `tmp` was stored) and set `MMF_OOM_SKIP` and `MMF_UNSTABLE` before unlocking so `exit_mmap()` stops at `xa_is_zero(vma)`. [F16, F38]
- In `vms_gather_munmap_vmas()`, every fallible call (`__split_vma()`, `mas_store_gfp()`, `userfaultfd_unmap_prep()`, `vma_is_sealed()`) must preserve its exact negative errno and call `reattach_vmas(mas_detach)` if any VMA was detached; `mlock_fixup()` writes `vma` (even `ERR_PTR`) to `*prev` at `out:`, so callers continuing on error (`apply_mlockall_flags()`) must reset `prev = vma`; and `mincore_page()`/`mincore_swap()` must check `xa_is_value(folio)` before `folio_test_uptodate()` or `folio_put()`. [F45, F50, F53]

## External Contracts

- In `do_mmap()`, `MAP_SHARED` must mask `flags &= LEGACY_MAP_MASK` and fall through into `MAP_SHARED_VALIDATE` (which rejects unknown flags with `-EOPNOTSUPP` and requires `FOP_MMAP_SYNC` for `MAP_SYNC`) and `MAP_PRIVATE`, then call `memfd_check_seals_mmap(file, &vm_flags)` before `mmap_region()`; in `do_mprotect_pkey()`, `VM_ACCESS_FLAGS | VM_FLAGS_CLEAR` must be cleared before ORing `calc_vm_prot_bits()`, and `(newflags & ~(newflags >> 4)) & VM_ACCESS_FLAGS` must fail with `-EACCES`. [F98, F160, F173]

## Known Pitfalls

- Because `vma_merge_existing_range()` mutates `vmg->start`, `vmg->end`, and `vmg->pgoff` before `commit_merge()` can fail with `-ENOMEM`, `vma_modify()` must snapshot `vmg->start` and `vmg->end` beforehand and return `ERR_PTR(-ENOMEM)` on `vmg_nomem(vmg)`; in `copy_vma()`, `vmg.skip_vma_uprobe = true` must be set when `vma->vm_file` is non-NULL so `vma_complete()` does not install a uprobe PTE that `move_page_tables()` will overwrite. [F9, F69]
- Per-CPU `mlock_fbatch.fbatch` accesses must hold `local_lock(&mlock_fbatch.lock)` (except `mlock_drain_remote()` on offline CPUs), drain immediately when `!folio_may_be_lru_cached(folio)`, and in `mlock_folio_batch()` strip `LRU_FOLIO | NEW_FOLIO` and write the untagged pointer back to `fbatch->folios[i]` before `__mlock_folio()`, `__mlock_new_folio()`, or `folios_put()`. [F54, F135, F155]
- In `change_pud_range()`, `pud_leaf(pud)` must not fall through to `change_pmd_range()`; in `change_pmd_range()`, `change_pmd_prepare()` must be re-run after `__split_huge_pmd()`; `pte_unmap()`/`pte_unmap_unlock()` after a PTE loop must pass `pte - 1` (or `start_pte`); and `do_mprotect_pkey()` must advance `nstart = vma_iter_end(&vmi)` after `mprotect_fixup()` and reset `prot = reqprot`. [F103, F104, F105, F127]
- In `mm/mremap.c`, `pmc_progress()` must return `0` when `pmc->old_addr < pmc->old_end - pmc->len_in` (after `try_realign_addr()`); `get_extent()` must use unsigned subtraction `next - old_addr` and `next - new_addr`; and `mremap_folio_pte_batch()` must check `max_nr == 1` and `pte_batch_hint(ptep, pte) == 1` before `vm_normal_folio()`. [F85, F102, F117]
- `expand_downwards()` must verify `grow <= vma->vm_pgoff` and `expand_upwards()` must check `vm_pgoff` addition wrap; `file_mmap_ok()` must check `len > maxsize` then `pgoff > (maxsize - len) >> PAGE_SHIFT` on `u64 maxsize`; `do_mmap()`, `vm_brk_flags()`, and `do_mseal()` must check `!len` after `PAGE_ALIGN()`; and `do_mlock()`/`__do_sys_munlock()` must add `offset_in_page(start)` to `len` before `PAGE_ALIGN()`, while `count_mm_mlocked_page_nr()` clamps `end` when `ULONG_MAX - len < start`. [F90, F93, F118, F122, F123]
