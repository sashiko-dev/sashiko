# HIGH-RESOLUTION TIMERS, TIMER WHEEL, CLOCKEVENTS

This component implements the Linux kernel's timer and clock event subsystems, including high-resolution timers (`hrtimer`), the jiffy-based hierarchical timer wheel (`timer_list`), migratable timer hierarchies (`tmigr`) for idle CPUs, clock event device management (`clock_event_device`), and task sleep/timeout APIs (`schedule_timeout`, `msleep`, `usleep_range`, `nanosleep`).

## Architecture & Data Flow

- `__hrtimer_get_next_event()` and `hrtimer_update_next_event()` update `next_timer` and `softirq_next_timer` (`softirq_expires_next`), but must never write `cpu_base->expires_next` (written only by `hrtimer_reprogram()`, `hrtimer_force_reprogram()`, and `hrtimer_interrupt()`). `__hrtimer_reprogram()` skips `tick_program_event()` while `cpu_base->hang_detected` is set. In `hrtimer_run_softirq()`, `softirq_activated` must be cleared before `hrtimer_update_softirq_timer()`, which calls `hrtimer_reprogram()` when `expires != KTIME_MAX`. [F63, F65, F148]
- In `hrtimer_interrupt()`, `entry_time` is captured once before `retry:` while `now` is refreshed via `hrtimer_update_base()`, and `in_hrtirq = 1` and `expires_next = KTIME_MAX` are set at `retry:` and restored before unlocking `cpu_base->lock`. `retrigger_next_event()` must always call `hrtimer_update_base()` first. When `!hrtimer_base_is_online(this_cpu_base)`, `this_cpu_base` must never be selected, and `__hrtimer_start_range_ns()` must kick `new_cpu_base->cpu` via `smp_call_function_single_async()` if `first`. [F64, F66, F105]
- `cpu_base->clock_base[]` is indexed by `enum hrtimer_base_type` (via `hrtimer_clockid_to_base()` or `base->index`), not `clockid_t`; `hrtimer_update_base()` must mirror updated `HRTIMER_BASE_REALTIME`, `BOOTTIME`, and `TAI` offsets into their `*_SOFT` bases. `enqueue_hrtimer()` and `__remove_hrtimer()` must maintain `cpu_base->active_bases` (`1 << base->index`) in lockstep with `base->active` and `timer->state`, and per-CPU runtime fields of `hrtimer_cpu_base` must be reset in `hrtimers_cpu_starting()`, not only `hrtimers_prepare_cpu()`. [F61, F62, F70, F87]
- `hrtimer_wakeup()` must clear `t->task = NULL` before `wake_up_process(task)` because `schedule_hrtimeout_range_clock()` and `do_nanosleep()` inspect `!t->task` to distinguish expiry from early wakeup. In `do_nanosleep()`, `mode` must be overwritten with `HRTIMER_MODE_ABS` after the first iteration before looping on spurious wakeups, and `__run_hrtimer()` must clear `timer->is_rel = false` under `CONFIG_TIME_LOW_RES`. [F12, F71]
- When `detach_if_pending()` / `detach_timer()` runs with `clear_pending == false`, a detached timer retains `entry.pprev` and must be re-enqueued before dropping `base->lock`; `enqueue_timer()` and `detach_if_pending()` must update `vectors[idx]`, `pending_map`, `timer_set_idx()`, and `next_expiry` / `next_expiry_recalc` in lockstep. In `__run_timers()`, `base->clk++` and `timer_recalc_next_expiry()` must run before `expire_timers()`; `__forward_timer_base()` must only advance `base->clk` when `time_after(basej, base->clk)`. [F14, F72, F106, F115]
- Selection and expiration of `timer_bases[BASE_DEF]` for `TIMER_DEFERRABLE` timers must depend solely on `IS_ENABLED(CONFIG_NO_HZ_COMMON)` (never runtime NO_HZ state); `TIMER_DEFERRABLE` overrides `TIMER_PINNED` to select `BASE_DEF`, and `trigger_dyntick_cpu()` must check `TIMER_DEFERRABLE` before `base->is_idle`. In `next_timer_interrupt()`, an empty base (`!base->timers_pending`) advances `base->next_expiry` to `basej + TIMER_NEXT_MAX_DELTA`, so `fetch_next_timer_interrupt()` must check `timers_pending` before writing `tevt->local` or `tevt->global`. [F35, F75, F99, F101]
- Whenever `timer_bases[BASE_LOCAL].is_idle` is set in `__get_next_timer_interrupt()` or cleared in `timer_clear_idle()`, `timer_bases[BASE_GLOBAL].is_idle` must be updated in lockstep on `tick_nohz_full_cpu()` CPUs. In `__get_next_timer_interrupt()`, after `timer_use_tmigr()` runs when `idle_is_possible` is true, if `idle` is non-NULL, `time_after(nextevt, basej + 1)` must be re-checked before setting `base_local->is_idle = true`, and if `!base_local->is_idle && idle_is_possible`, `tmigr_cpu_activate()` must be called. [F76, F77]
- In `calc_wheel_index()`, `delta = expires - clk` must check `(long)delta < 0` to queue past timers at `clk & LVL_MASK` (`*bucket_expiry = clk`), and clamp `delta >= WHEEL_TIMEOUT_CUTOFF` to `clk + WHEEL_TIMEOUT_MAX` before `calc_index()` rounds `expires = (expires >> LVL_SHIFT(lvl)) + 1`. `timer_recalc_next_expiry()` must advance `clk` across levels via `(clk >> LVL_CLK_SHIFT) + ((clk & LVL_CLK_MASK) ? 1 : 0)`. [F89, F121, F122, F123]
- In `tmigr_update_events()`, skipping requeue when `evt->nextevt.expires == nextexp && !ignore` still requires setting `evt->cpu = first_childevt->cpu`. In `tmigr_handle_remote()`, `!tmigr_check_migrator()` may return early only if `READ_ONCE(tmc->wakeup) == KTIME_MAX`. After `tmigr_handle_remote_cpu()` re-locks, if `tmc->online && tmc->idle`, it must call `fetch_next_timer_interrupt_remote()` and `walk_groups(&tmigr_new_timer_up, &data, tmc)` (`data.remote = true`) even if `tevt.global == KTIME_MAX`. [F78, F80, F81]

## Synchronization

- Lock order across `timer_base` and `tmigr` is strict: `BASE_LOCAL` before `BASE_GLOBAL`, `timer_base` locks before any `tmigr` lock, `tmigr_cpu->lock` before `tmigr_group->lock`, and child `tmigr_group->lock` before parent `tmigr_group->lock`. In `tmigr_handle_remote_cpu()`, after dropping `tmc->lock` with `tmc->remote = true` for `timer_expire_remote()`, re-locking must acquire `timer_lock_remote_bases(cpu)` before `tmc->lock`, call `timer_unlock_remote_bases(cpu)` on all paths, and reset `tmc->remote = false` under `tmc->lock`. [F19, F28]
- On `CONFIG_PREEMPT_RT`, `timer_base->expiry_lock` and `hrtimer_cpu_base->softirq_expiry_lock` sit outside raw spinlocks `base->lock` and `cpu_base->lock`: `del_timer_wait_running()` and `hrtimer_cancel_wait_running()` must balance `timer_waiters` around `spin_lock_bh()` on the expiry lock, while `timer_sync_wait_running()` and `hrtimer_sync_wait_running()` must unlock the raw spinlock before dropping the expiry lock and reacquire the expiry lock before the raw spinlock. [F17, F18, F37]
- In `expire_timers()`, `base->running_timer = NULL` must only be cleared after re-acquiring `base->lock`. Timer shutdown (`shutdown=true` in `__timer_delete()`, `__try_to_del_timer_sync()`) must lock `base->lock` even if `!timer_pending(timer)` to set `timer->function = NULL`, and `__mod_timer()` / `add_timer_on()` must abort if `!timer->function` under `base->lock`. Runtime `base->next_expiry` updates use `WRITE_ONCE()` paired with `READ_ONCE()`. `__mod_timer()` reuses `idx` only if `idx != UINT_MAX && clk == base->clk` after base switch/forwarding. [F30, F31, F34, F73]
- In `__run_hrtimer()`, `raw_write_seqcount_barrier(&base->seq)` must bracket `base->running = timer` (before clearing `HRTIMER_STATE_ENQUEUED`) and conditional `enqueue_hrtimer()` (before clearing `base->running = NULL`), `hrtimer_active()` must recheck `base == READ_ONCE(timer->base)` in its seqcount loop, and `__run_hrtimer()` must check `!(timer->state & HRTIMER_STATE_ENQUEUED)` after re-locking `cpu_base->lock`. In `switch_hrtimer_base()`, if `!hrtimer_callback_running(timer)`, set `WRITE_ONCE(timer->base, &migration_base)` before unlocking. [F39, F40, F67]
- `tmigr_connect_child_parent()` must publish `child->parent` via `smp_store_release()` after setting `child->groupmask` (paired with `READ_ONCE(group->parent)` in `__walk_groups()`), and `tmigr_setup_groups()` must run in `CPUHP_TMIGR_PREPARE` on an online CPU (`cpu != raw_smp_processor_id()`). Every `atomic_try_cmpxchg()` on `group->migr_state` must increment `newstate.seq`, `tmigr_inactive_up()` must read `group->migr_state` with `atomic_read_acquire()` before `child->migr_state`, and `tmigr_update_events()` must read `migr_state` under `group->lock`. [F23, F24, F26, F27]
- In `tmigr_requires_handle_remote_up()` and `tmigr_requires_handle_remote()`, `u64` fields `group->next_expiry` and `tmc->wakeup` may be read locklessly with `READ_ONCE()` only under `IS_ENABLED(CONFIG_64BIT)`; 32-bit architectures must hold `group->lock` or `tmc->lock`. In `tmigr_cpu_offline()`, if `__tmigr_cpu_deactivate(tmc, KTIME_MAX)` returns `firstexp != KTIME_MAX`, the offlining CPU must drop `tmc->lock` and call `work_on_cpu(migrator, tmigr_trigger_active, NULL)`. [F93, F169]
- In preemptible contexts, `clock_was_set()` and `__hrtimer_setup()` must use `raw_cpu_ptr(&hrtimer_bases)` rather than `this_cpu_ptr()`, and `timers_dead_cpu()` must use `get_cpu_ptr(&timer_bases[b])` paired with `put_cpu_ptr()`, locking `new_base->lock` before `old_base->lock`. In `print_active_timers()`, `base->cpu_base->lock` must be dropped before `print_timer()` by snapshotting `*timer` under the lock and re-walking from `timerqueue_getnext(&base->active)` on the next iteration. [F20, F85, F149, F150, F167]

## Object Lifetimes

- Because `fn(timer)` may free `timer` (in `__run_hrtimer()` when returning `HRTIMER_NORESTART`, and in `expire_timers()` / `call_timer_fn()`), all needed fields (including `lockdep_copy_map()` on `timer->lockdep_map`) must be read before `fn(timer)` and `timer` must not be dereferenced afterward. `remove_hrtimer()` (`restart == true`) and `migrate_hrtimer_list()` must pass `HRTIMER_STATE_ENQUEUED` to `__remove_hrtimer()`. [F1, F2, F13]
- `struct tmigr_group` and `tmc->tmgroup` persist across CPU offline, so `tmigr_cpu_prepare()` must return early if `tmc->tmgroup` is non-NULL. Under `clockevents_lock` with IRQs disabled, `clockevents_exchange_device(old, new)` requires callers to hold `try_module_get(new->owner)` and `new` in `CLOCK_EVT_STATE_DETACHED`, while dropping `module_put(old->owner)` and moving `old->list` to `clockevents_released` (`clockevents_replace()` must call `module_put(newdev->owner)` when a candidate is superseded). [F7, F9, F139]

## API Contracts

- `schedule_timeout()`, `schedule_hrtimeout_range_clock()`, and `do_nanosleep()` must set `__set_current_state(TASK_RUNNING)` on every exit path that skips `schedule()`. `schedule_timeout()` treats `MAX_SCHEDULE_TIMEOUT` as an unbounded sleep and clamps negative inputs/residuals to `0`. In `schedule_hrtimeout_range_clock()`, `@delta` is a `u64` nanosecond slack, a NULL `expires` sleeps indefinitely (`-EINTR`), and `*expires == 0` returns `0` immediately. [F11, F59, F60, F189]
- `enqueue_timer()` must compare and store `calc_wheel_index()`'s `bucket_expiry` (not `timer->expires`) into `base->next_expiry`, and `fetch_next_timer_interrupt()` callers must preset `tevt->local = tevt->global = KTIME_MAX`. `hrtimer_start_range_ns()` `HRTIMER_MODE_SOFT`/`HARD` bits must match `hrtimer_setup()`, and `hrtimer_sleeper` must use `hrtimer_sleeper_start_expires()`. `__hrtimer_next_event_base()` and `hrtimer_reprogram()` must subtract `base->offset` and clamp `< 0` to `0`. `clock_was_set()` requires sleepable context. [F53, F55, F56, F58, F166]
- Callers of `clockevents_switch_state()`, `clockevents_shutdown()`, or `clockevents_exchange_device()` must disable local IRQs and never pre-set `dev->state_use_accessors` to the target state; in `__clockevents_switch_state()`, `CLOCK_EVT_STATE_DETACHED` must fall through to `CLOCK_EVT_STATE_SHUTDOWN`. `clockevents_update_freq()` must run on the device's CPU with IRQs disabled, trying `tick_broadcast_update_freq()` first. [F83, F100, F144, F161]
- In `struct tmigr_group`, `struct tmigr_cpu`, and `union tmigr_state`, `groupmask`, `childmask`, `active`, and `migrator` store shifted single-bit masks (`BIT(0)`..`BIT(7)`, or `TMIGR_NONE` = `0xFF`), so bit indices from `find_first_bit()` or `num_children` must be converted with `BIT()`. [F57]

## Error Handling

- `hrtimer_try_to_cancel()` and `timer_delete_sync_try()` return `-1` when the callback is running (`0` inactive, `1` cancelled), and `next_pending_bucket()` returns `-1` when none is pending, so callers must test `< 0` / `pos >= 0` on signed `int`. `hrtimer_switch_to_hres()` must abort without setting `hres_active` or `hrtimer_resolution` if `tick_init_highres()` fails. `__run_timers()`'s 0-level `WARN_ON_ONCE` requires `!base->next_expiry_recalc && base->timers_pending`. [F44, F45, F52, F173]
- `tmigr_get_group()` returns `ERR_PTR(-ENOMEM)` rather than `NULL` on failure; in `tmigr_setup_groups()`, if `tmigr_get_group()` fails (`IS_ERR(group)`), the unwind loop must pre-check `while (i > 0)` before reading `stack[--i]` (since level-0 failure leaves `i == 0`), unlink (`list_del(&group->list)`) and `kfree(group)` for each entry, guard post-loop dereferences of `group` with `!err`, and always `kfree(stack)`. [F8, F47, F86]

## Known Pitfalls

- `cpu_base->next_timer` must never be dereferenced (only compared by pointer identity) as remote removal leaves it dangling. In `hrtimer_reprogram()`, when `timer->is_soft` is true, `softirq_*` fields must be updated on `timer_cpu_base` (`timer->base->cpu_base`), not local `cpu_base`, before checking `base->cpu_base != cpu_base`. `for_each_active_base()` clears bits in place, so pass a local copy of `active_bases`. Test relative mode with `mode & HRTIMER_MODE_REL` (not `!= HRTIMER_MODE_ABS`), and clamp `interval >= hrtimer_resolution` in `hrtimer_forward()`. [F49, F97, F107, F108, F110]
- In `union tmigr_state`, `u32 state` is only for atomic ops; access `active`, `migrator`, and `seq` via the struct fields, and widen `u8 active` to a local `unsigned long` bounded by `BIT_CNT` (`8`) before `bitmap_weight()` or `find_first_bit()`. `clockevents_notify_released()` must use `while (!list_empty(&clockevents_released))` rather than `list_for_each_entry_safe()`. In `fetch_next_timer_interrupt()` and `timer_use_tmigr()`, clamp past expiries up to `basej` / `basem` before subtracting, and cast `(nextevt - basej)` to `u64` before `* TICK_NSEC`. [F91, F102, F113, F114, F134]
