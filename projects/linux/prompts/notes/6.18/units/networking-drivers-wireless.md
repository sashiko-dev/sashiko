# NETWORKING DRIVERS (WIRELESS)

This component contains three wireless networking drivers: the USB driver for Atmel AT76C503/AT76C505 802.11b devices (`at76c50x-usb`), the `mac80211_hwsim` software radio simulator used to test `mac80211` and `cfg80211` (supporting multi-channel, MLO, NAN, peer measurement, `wmediumd` Generic Netlink, and virtio transport), and `virt_wifi`, an RTNL link wrapper that presents an Ethernet `net_device` as a virtual `cfg80211` wireless station.

## Architecture & Data Flow

- In `mac80211_hwsim`, `data->channel` and `data->bw` are only populated when `!data->use_chanctx`; when `data->use_chanctx` is true, paths like `mac80211_hwsim_tx` and `mac80211_hwsim_sta_rc_update` must obtain the active channel and width from the link's `bss_conf->chanctx_conf` (or `data->tmp_chan`). In `mac80211_hwsim_tx`, the `vif && vif->type == NL80211_IFTYPE_NAN && !data->tmp_chan` branch must be evaluated before `else if (!data->use_chanctx)`. [F36, F77]
- In `mac80211_hwsim_tx`, MLO header address translation (`hdr->addr1` to `link_sta->addr`, `hdr->addr2` to `bss_conf->addr`, and non-DS `hdr->addr3` from `sta->addr` or `vif->addr` to `link_sta->addr` or `bss_conf->addr`) must only be performed when `sta && sta->mlo && link_sta` is true. [F87]
- In `mac80211_hwsim_tx_frame_no_nl`, radio group compatibility between `data` and `data2` must be tested with bitwise intersection `!(data->group & data2->group)`, whereas namespace group isolation must be tested with integer equality `data->netgroup != data2->netgroup`. [F78]
- Changes to a netns `wmediumd` portid must use `hwsim_register_wmediumd` so both `hwsim_net_set_wmediumd` and `data->wmediumd` on every radio in `hwsim_radios` with `data->netgroup == hwsim_net_get_netgroup(net)` are updated in lockstep under `hwsim_radio_lock`. [F49]
- When `BSS_CHANGED_BEACON_ENABLED` is cleared in `mac80211_hwsim_link_info_changed`, `link_data->beacon_timer` and `link_data->beacon_int` must only be cancelled and zeroed if no active interface on `data->hw` still has `vp->bcn_en` set (`mac80211_hwsim_bcn_en_iter`). Because disabling beacons sets `link_data->beacon_int = 0`, `mac80211_hwsim_config` and `mac80211_hwsim_set_tsf` must only run `do_div(..., bcn_int)` when `link_data->beacon_int != 0`. [F52, F89]
- In `mac80211_hwsim_stop_nan`, the shared `hwsim_nan_cluster_id` must only be zeroed after cancelling `data->nan_timer`, clearing `data->nan_device_vif`, and verifying under `hwsim_radio_lock` that no other radio in `hwsim_radios` still has a non-NULL `nan_device_vif`. [F51]
- In `mac80211_hwsim_new_radio`, each `data->link_data[i].link_id` must be set to `i` and `beacon_timer` initialized before `ieee80211_register_hw(hw)` (as `container_of` uses `link_id`), and when `param->multi_radio` is enabled, `data->radio_range` and `data->radio` must be indexed by `n_bands` rather than `band`. [F17, F82]
- In `hwsim_new_radio_nl`, `HWSIM_ATTR_CIPHER_SUPPORT` must be validated for a `sizeof(u32)`-aligned length, `param.n_ciphers <= ARRAY_SIZE(hwsim_ciphers)`, and membership via `hwsim_known_ciphers`, while `HWSIM_ATTR_REG_CUSTOM_REG` must be bounds-checked against `ARRAY_SIZE(hwsim_world_regdom_custom)` and sanitized with `array_index_nospec`. [F70, F71]
- In `hwsim_cloned_frame_received_nl`, `frame_data_len` from `HWSIM_ATTR_FRAME` must be checked to be `>= sizeof(struct ieee80211_hdr_3addr)` before `mac80211_hwsim_rx`. In `hwsim_virtio_rx_work` / `hwsim_virtio_handle_cmd`, incoming virtio RX `skb`s must have `skb->data` reset to `skb->head`, tail set via `skb_put(skb, len)`, and `skb->len < nlh->nlmsg_len` rejected before `genlmsg_parse`. [F68, F74]
- In `hwsim_dump_radio_nl`, `last_idx` must be initialized to `cb->args[0] - 1`, updated to `data->idx` only after `mac80211_hwsim_get_radio` succeeds, and saved as `cb->args[0] = last_idx + 1` so radio 0 is dumped and overflowed radios are retried. [F83]
- Because all `virt_wifi` netdevs share `common_wiphy`, any path completing `priv->scan_request` via `cfg80211_scan_done` (`virt_wifi_scan_result` or `virt_wifi_cancel_scan`) must clear `priv->scan_request = NULL`. In `virt_wifi_event`, `netif_is_virt_wifi_dev(lower_dev)` must be verified before reading `lower_dev->rx_handler_data`, and `virt_wifi_newlink` must reject `dev->mtu > priv->lowerdev->mtu`. [F60, F75, F105]
- In `at76c50x-usb`, `at76_alloc_urbs()` must allocate `priv->bulk_out_buffer` with `sizeof(struct at76_tx_buffer) + MAX_PADDING_SIZE` bytes for `at76_calc_padding(skb->len)`, and `at76_set_card_command` must set `cmd_buf->size = cpu_to_le16(buf_size)` before `memcpy` into `cmd_buf->data` (`__counted_by_le(size)`). [F93, F114]

## Synchronization

- In `hwsim_del_radio_nl`, `remove_user_radios`, and `hwsim_exit_net`, each radio must be unlinked from `hwsim_radios`, removed from `hwsim_radios_rht`, and `hwsim_radios_generation` incremented under `spin_lock_bh(&hwsim_radio_lock)` before dropping the lock to call `mac80211_hwsim_del_radio`. [F24]
- Process-context callers of `mac80211_hwsim_tx_frame` (`hw_scan_work`, `mac80211_hwsim_assign_vif_chanctx`, `mac80211_hwsim_unassign_vif_chanctx`, and `hwsim_fops_ps_write`) must wrap the call in `local_bh_disable()` / `local_bh_enable()`, while softirq hrtimer callbacks (`mac80211_hwsim_beacon` and `mac80211_hwsim_nan_dw_start`) must use `GFP_ATOMIC`. [F27, F130]
- `mac80211_hwsim_cancel_hw_scan` and `mac80211_hwsim_croc` must call `cancel_delayed_work_sync` on `hwsim->hw_scan`, `hwsim->roc_start`, and `hwsim->roc_done` (canceling `roc_start` before `roc_done`) before acquiring `hwsim->mutex`. [F21]
- `mac80211_hwsim_tx_frame_nl` must store `atomic_inc_return(&data->pending_cookie)` in `info->rate_driver_data[0]` before queueing `my_skb` on `data->pending`, and `hwsim_tx_info_frame_received_nl` must hold `spin_lock_irqsave(&data2->pending.lock, flags)` while walking `data2->pending` and calling `__skb_unlink`. [F18]
- Lockless readers of `data->wmediumd` (`mac80211_hwsim_tx`, `mac80211_hwsim_tx_frame`, `mac80211_hwsim_config_mac_nl`, `mac80211_hwsim_start_pmsr`, `mac80211_hwsim_abort_pmsr`) must load `data->wmediumd` once with `READ_ONCE` and pass that local copy to `mac80211_hwsim_tx_frame_nl` or `hwsim_unicast_netgroup`. [F29]
- `hwsim_virtio_rx_work` must release `hwsim_virtio_lock` before `hwsim_virtio_handle_cmd(skb)` and, upon re-acquiring `hwsim_virtio_lock`, must recheck `hwsim_virtio_enabled` and free `skb` if disabled rather than re-adding it to `hwsim_vqs[HWSIM_VQ_RX]` or rescheduling `hwsim_virtio_rx`. [F22]
- In `mac80211_hwsim_start_nan`, `data->nan_device_vif`, `data->nan_bands`, and `data->nan_curr_dw_band` must be initialized before `hrtimer_start(&data->nan_timer, ...)`. In `mac80211_hwsim_rx`, `ieee80211_find_sta_by_link_addrs` and access to the returned `sta` must stay inside `rcu_read_lock()`. [F16, F131]
- In `virt_wifi`, `virt_wifi_scan_result` and `virt_wifi_connect_complete` must never acquire `rtnl_lock()` because `virt_wifi_cancel_scan` and `virt_wifi_cancel_connect` call `cancel_delayed_work_sync` while holding `rtnl_lock()`. `virt_wifi_rx_handler` runs in RCU read-side context and must use `rcu_dereference` on `rx_handler_data` and `GFP_ATOMIC` in `skb_share_check`. [F132, F133]
- In `at76c50x-usb`, all callers populating `priv->mib_buf` and calling `at76_set_mib` must hold `priv->mtx` (so atomic `at76_configure_filter` must queue `priv->work_set_promisc` instead), and `at76_mac80211_stop()` must cancel `dwork_hw_scan`, `work_join_bssid`, and `work_set_promisc` before acquiring `priv->mtx`. [F25, F109]
- In `at76_load_firmware`, `fw_mutex` must be held continuously across checking `fwe->loaded`, calling `request_firmware`, validating `struct at76_fw_header`, populating `fwe->intfw` / `fwe->extfw` in `firmwares[board_type]`, and setting `fwe->loaded = 1`. [F26]

## Object Lifetimes

- In `at76_delete_device`, `priv->device_unplugged = 1`, `tasklet_kill(&priv->rx_tasklet)`, and `ieee80211_unregister_hw(priv->hw)` must complete before killing/freeing URBs and buffers and calling `ieee80211_free_hw(priv->hw)`. Because this frees `priv`, `at76_disconnect` must not dereference `priv` afterwards and must pass `interface_to_usbdev(interface)` to `usb_put_dev`. [F1, F19]
- In `at76_rx_tasklet`, passing `priv->rx_skb` to `ieee80211_rx_irqsafe` transfers ownership to mac80211, so `priv->rx_skb` must be set to `NULL` before `at76_submit_rx_urb(priv)` or `at76_delete_device`. In `at76_mac80211_tx`, early returns before `priv->tx_skb = skb` must call `dev_kfree_skb_any(skb)`, and `at76_mac80211_tx_callback` must pass `priv->tx_skb` to `ieee80211_tx_status_irqsafe` and clear `priv->tx_skb = NULL` before `ieee80211_wake_queues`. [F2, F3]
- `mac80211_hwsim_del_radio()` and `mac80211_hwsim_new_radio()` rollback must tear down in reverse order: `debugfs_remove_recursive()`, `ieee80211_unregister_hw()`, `device_release_driver()`, `device_unregister()`, and `ieee80211_free_hw()`. Also, `mac80211_hwsim_new_radio` must copy `*param->pmsr_capa` and `param->ciphers` into `data` before pointing `hw->wiphy` at them. [F101, F117]
- In `mac80211_hwsim_beacon_tx`, `__mac80211_hwsim_beacon_tx` consumes each `ema->bcn[i].skb`, so `ema->bcn[i].skb = NULL` must be set before `ieee80211_beacon_free_ema_list(ema)`. [F9]
- In `hwsim_exit_net`, radios with `data->netgroup == hwsim_net_get_netgroup(&init_net)` must be skipped rather than deleted with `mac80211_hwsim_del_radio`, while the exiting netns's ID is freed via `ida_free(&hwsim_netgroup_ida, hwsim_net_get_netgroup(net))`. [F11]
- `hwsim_virtio_remove()` must clear `hwsim_virtio_enabled` and call `cancel_work_sync(&hwsim_virtio_rx)` before `remove_vqs()` resets `vdev`, detaches and frees unused buffers via `nlmsg_free()`, and deletes `hwsim_vqs`. [F119]
- In `virt_wifi`, freeing `dev->ieee80211_ptr` is deferred to `virt_wifi_net_device_destructor` (never freed in `virt_wifi_dellink`), `rtnl_link_unregister(&virt_wifi_link_ops)` must run before `virt_wifi_destroy_wiphy(common_wiphy)`, and cancelled scan/connect work in `virt_wifi_cancel_scan` / `virt_wifi_cancel_connect` must still complete pending requests via `cfg80211_scan_done` or `cfg80211_connect_result`. [F12, F13, F14]

## API Contracts

- In `at76c50x-usb.c`, `at76_get_cmd_status()` and `at76_wait_completion()` return `CMD_STATUS_COMPLETE` (`0x01`) on success, `0` for `CMD_STATUS_IDLE`, positive values for firmware errors, and `< 0` on USB/timeout failure (check `ret != CMD_STATUS_COMPLETE`). `at76_set_radio()` returns `1` only when a command was sent, so `at76_wait_completion()` must only be called when it returns `1`. [F38, F41]
- `at76_set_mib()` (and `at76_set_*()` wrappers), `at76_get_mib()`, `at76_get_hw_config()`, and `at76_set_card_command()` return `> 0` (`CMD_STATUS_COMPLETE` or byte count) on success and `< 0` on failure, so callers must check `ret < 0` rather than `if (ret)`. [F39, F40]
- All `usb_control_msg` transfer buffers in `at76c50x-usb` must be `kmalloc`-allocated (never stack or `request_firmware` pointers), `at76_set_mib()` callers must set both `priv->mib_buf.size` and `priv->mib_buf.index`, and `at76_load_firmware` returns a cached `struct fwentry *` that callers must not pass to `release_firmware` (released only in `at76_mod_exit` after `usb_deregister`). [F4, F45, F124]
- In `at76_mac80211_tx()`, an `IEEE80211_STYPE_AUTH` frame with `mgmt->bssid != priv->bssid` must update `priv->bssid`, queue `work_join_bssid`, free the SKB, and return without submitting `tx_urb`. In `at76_rx_tasklet`, `skb_pull(priv->rx_skb, AT76_RX_HDRLEN)` and `skb_trim` must precede `at76_guess_freq(priv)`. [F97, F115]
- Both `hwsim_tx_virtio` and `hwsim_unicast_netgroup` unconditionally consume the Netlink `skb` passed to them (freeing it on error), so callers (`mac80211_hwsim_tx_frame_nl`, `mac80211_hwsim_start_pmsr`, `mac80211_hwsim_abort_pmsr`) must never call `nlmsg_free(skb)` afterwards. [F8]
- `mac80211_hwsim_new_radio()` returns radio index `idx >= 0` on success and `< 0` on error; it must enable `param->use_chanctx` whenever `channels > 1`, `mlo`, or `multi_radio` is set (selecting `mac80211_hwsim_mlo_ops` for `mlo`), and must only populate `hw->wiphy->iface_combinations` when `data->if_combination.max_interfaces > 1`. [F33, F140, F141]
- In `mac80211_hwsim_tx_frame_no_nl()`, copied `skb`s must be scrubbed with `skb_orphan()`, `skb_dst_drop()`, `skb->mark = 0`, `skb_ext_reset()`, and `nf_reset_ct()`; in `mac80211_hwsim_monitor_rx()` / `monitor_ack()`, `skb->cb` must be zeroed before `netif_rx(skb)`; and in `mac80211_hwsim_rx()`, `memcpy(IEEE80211_SKB_RXCB(skb), rx_status, ...)` must precede `mac80211_hwsim_add_vendor_rtap(skb)`. [F142, F143, F144]
- Generic Netlink radio lookups (`hwsim_del_radio_nl`, `hwsim_get_radio_nl`, `hwsim_dump_radio_nl`) must check `net_eq(wiphy_net(data->hw->wiphy), ...)`, and when `!hwsim_virtio_enabled`, `hwsim_tx_info_frame_received_nl` and `hwsim_cloned_frame_received_nl` must verify both `hwsim_net_get_netgroup(genl_info_net(info)) == data2->netgroup` and `info->snd_portid == data2->wmediumd`. [F145, F146]
- In `virt_wifi_rx_handler`, if `skb_share_check(skb, GFP_ATOMIC)` returns `NULL`, return `RX_HANDLER_CONSUMED`, else update `*pskb = skb` before `RX_HANDLER_ANOTHER`. In `virt_wifi_connect_complete()`, verify `connect_requested_ssid` against `VIRT_WIFI_SSID` before reporting `WLAN_STATUS_SUCCESS`, and in `virt_wifi_newlink()`, resolve `IFLA_LINK` in `rtnl_newlink_link_net(params)`. [F15, F134, F138]

## Error Handling

- In `hwsim_new_radio_nl`, buffers cleaned up at `out_free` via `param` (like `pmsr_capa`) must be assigned into `param` before calling fallible helpers like `parse_pmsr_capa`; `hwsim_ops` handlers must NULL-check `info->attrs[]` entries before accessing them; and `struct cfg80211_pmsr_result` must be zero-initialized before `mac80211_hwsim_parse_pmsr_result()`. [F5, F31, F32]
- Because `at76_probe()` returns `0` after `at76_load_internal_fw()` before allocating `priv`, `at76_disconnect()` must check `if (!priv) return;`. [F43]

## External Contracts

- In `at76_load_external_fw`, the download loop must be `do { ... } while (bsize > 0)` so a final `bsize == 0` empty block is sent via `at76_load_ext_fw_block`. [F84]

## Known Pitfalls

- `mac80211_hwsim_new_radio` overwrites `param->hwname` with `wiphy_name(hw->wiphy)`, so `hwsim_new_radio_nl` must free its `kstrndup` buffer via a separate local `hwname` pointer. Also, `data->alpha2` is a non-NUL-terminated `char[2]` and `HWSIM_ATTR_RADIO_NAME` is an unvalidated `NLA_STRING`, so readers must bound them by length (`2` or `nla_len`/`kstrndup`). [F6, F102, F103]
- In `hwsim_tx_info_frame_received_nl`, do not dereference `skb` after `skb_queue_walk_safe(&data2->pending, skb, tmp)` unless `found` is true (otherwise `skb` is the list head), and check `skb->len >= 16` before `mac80211_hwsim_monitor_ack(channel, hdr->addr2)`. In `mac80211_hwsim_tx_frame_no_nl`, use `data2->tsf_offset`, `data2`, and `nskb` (never `data` or `skb`) for each recipient's `mac80211_hwsim_rx`. [F69, F80, F86]
- Use `do_div()` on a separate `u64` copy for 64-bit TSF remainders in `mac80211_hwsim` and `div_u64()` in `virt_wifi_inform_bss`; widen `u16` link masks to `unsigned long` before `for_each_set_bit` in `mac80211_hwsim_change_vif_links`; use `BIT_ULL()` for `sinfo->filled` in `virt_wifi_get_station`; and cast `struct at76_fw_header *fwh` to `u8 *`/`char *` before adding firmware byte offsets in `at76_load_firmware`. [F88, F90, F91, F96, F104]
