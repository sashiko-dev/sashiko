# INFINIBAND SUBSYSTEM

The InfiniBand and RDMA subsystem (`include/rdma`) defines the core kernel interfaces for RDMA devices and ULPs, including the Verbs API, `struct ib_device_ops`, resource tracking (`restrack`), user-space verbs parsing (`uverbs`), user memory registration (`ib_umem`, ODP, dmabuf), connection and datagram management (`rdma_cm`, `ib_cm`, `ib_mad`, `ib_sa`), wire header packing, and the software RDMA Verbs Transport library (`rdmavt`).

## Architecture & Data Flow

- `struct ib_umem` may be a base allocation, `struct ib_umem_odp`, or `struct ib_umem_dmabuf`: check `umem->is_odp` before `to_ib_umem_odp()`, `umem->is_dmabuf` before `to_ib_umem_dmabuf()`, and `!umem_odp->is_implicit_odp` before `ib_umem_odp_map_dma_and_lock()`. In `ib_umem_odp_alloc_child()`, a child under `root->is_implicit_odp` must inherit `umem.ibdev`, `umem.writable`, `umem.owning_mm`, and `tgid` from `root`. [F47, F61]
- In `struct ib_umem`, `sgt_append.sgt.orig_nents` holds the page-populated SG count (for `ib_umem_copy_from()` and unpinning), while `sgt_append.sgt.nents` holds the DMA-mapped segment count set by `ib_dma_map_sgtable_attrs()` and consumed by `__rdma_umem_block_iter_start()`. In `struct ib_umem_odp`, `notifier.interval_tree.last` is inclusive while `ib_umem_end()` returns `last + 1` (exclusive). [F60, F77]
- `struct device dev` must remain the first member of `struct ib_core_device`. Because non-init net namespaces use standalone `ib_core_device` instances in `ib_device->compat_devs`, sysfs callbacks reachable in non-init namespaces must obtain `struct ib_device *` via `rdma_device_to_ibdev(dev)` rather than `container_of(dev, struct ib_device, dev)`. [F50, F114]
- `rvt_update_sge()` must advance `sge->vaddr`, `sge->length`, and `sge->sge_length` by at most `rvt_get_sge_length(sge, length)`. When `sge->sge_length == 0`, it calls `rvt_put_mr(sge->mr)` if `release` is true and copies `*ss->sg_list++` into `ss->sge` if `--ss->num_sge` is non-zero; when `sge->length == 0` with `sge->sge_length > 0`, it reloads from `sge->mr->map[sge->m]->segs[sge->n]` only if `sge->mr->lkey != 0`. [F56, F57]
- On `struct rvt_qp`, update `qp->log_pmtu = ilog2(qp->pmtu)` when `qp->pmtu` changes, update `qp->timeout_jiffies = rvt_timeout_to_jiffies(qp->timeout)` when `qp->timeout` changes, and set `RVT_S_TIMER` in `qp->s_flags` under `qp->s_lock` in `rvt_mod_retry_timer_ext()`. Compute `rvt_rq` counts via `rvt_get_rq_count()` and advance send WQE indices via `rvt_qp_swqe_incr()`. [F58, F78]
- `struct ib_port_attr.port_cap_flags` must only store hardware IBA `CapabilityMask` bits; RoCE IP-based GID support must be set in `ib_port_attr.ip_gids = true`. On RoCE ports, `rdma_cap_roce_gid_table()` requires both `ib_device_ops.add_gid` and `del_gid` (`query_gid` is unused). [F65, F139]
- 64-bit fields in `__packed` IB wire structs (`ib_reth`, `ib_atomic_eth`, `ib_ehdrs.at`, `ib_sa_hdr`, `ib_sa_mad`) are only 4-byte aligned and must be accessed via `ib_u64_get`/`put`, `get`/`put_ib_reth_vaddr`, `get`/`put_ib_ateth_*`, or `_iba_get64`/`_iba_set64`. [F82]

## Synchronization

- `ib_umem_odp_map_dma_and_lock()` acquires `umem_odp->umem_mutex` and returns with it locked only when its return value is `>= 0` (including `0` pages mapped); on `< 0`, `umem_mutex` is not held. Callers of `ib_umem_odp_unmap_dma_pages()` must hold `umem_odp->umem_mutex`. [F11]
- In `struct ib_uverbs_file`, accessing `uobjects` requires holding `hw_destroy_rwsem` for write, or both `hw_destroy_rwsem` for read and `uobjects_lock`; `hw_destroy_rwsem` must be held across `destroy_hw`. Access `ufile->ucontext` only via `ib_uverbs_get_ucontext_file()` or under `ufile->ucontext_lock`. [F25, F26]
- In `rvt_qp_complete_swqe()`, calling `rvt_qp_wqe_unreserve()`, `rvt_put_qp_swqe()`, and reading `wqe->wr.wr_id` and `wqe->length` must complete before `smp_store_release(&qp->s_last, last)`, which immediately allows `rvt_qp_is_avail()` to reuse `*wqe`. [F55]
- In `rdmavt`, `rvt_mod_retry_timer*()`, `rvt_add_retry_timer*()`, `rvt_add_rnr_timer()`, `rvt_stop_rc_timers()`, `rvt_rc_credit_avail()`, and `schedule_send` require `qp->s_lock` held with IRQs disabled; `schedule_send_no_lock` requires `qp->s_lock` not held, and `rvt_del_timers_sync()` must be called without `qp->r_lock`, `qp->s_hlock`, or `qp->s_lock`. [F30, F145, F146]
- In `struct rvt_driver_provided`, `flush_qp_waiters` and `notify_qp_reset` are called with `qp->r_lock`, `qp->s_hlock`, and `qp->s_lock` held, while `stop_send_queue` and `quiesce_qp` are called after those locks are dropped. `qp_priv_init` must be called only after all `struct rvt_qp` fields and locks are initialized. [F20, F126]
- `rvt_lookup_qpn()` requires `rcu_read_lock()`, looking up QPNs `<= 1` in `rvp->qp[qpn]` (`IB_QPT_SMI`/`IB_QPT_GSI`) and QPNs `> 1` in `rdi->qp_dev->qp_table` via `rcu_dereference()`. Access `head`/`tail` of user-mapped `rvt_cq_wc` and `rvt_rwq` via `RDMA_READ_UAPI_ATOMIC()` and `RDMA_WRITE_UAPI_ATOMIC()`. [F80, F96, F153]
- Inside an `rdma_cm_event_handler` callback (where the `rdma_cm_id` handler mutex is already held), callers must invoke `rdma_connect_locked()` instead of `rdma_connect()`. [F31]
- `struct ib_cq` `wr_cqe->done` handlers run in softirq context for `IB_POLL_SOFTIRQ` (must not sleep), workqueue context for `IB_POLL_WORKQUEUE` / `IB_POLL_UNBOUND_WORKQUEUE`, or caller context for `IB_POLL_DIRECT`. [F143]
- Do not hold `device->client_data_rwsem` across `ib_client->remove()`. For port/LID/PKey/GID/client-reregister events in `ib_dispatch_event()`, `ib_cache_event_task()` must update `device->port_data[port].cache` before notifying `event_handler_list`. [F33, F63]
- Serialize `struct rdma_hw_stats` accesses and `get_hw_stats`/`modify_hw_stat` calls with `stats->lock`. Hold `rcu_read_lock()` across `rdma_read_gid_attr_ndev_rcu()` and throughout any use of the returned `struct net_device *`. [F24, F151]

## Object Lifetimes

- Callers of `uobj_get_destroy()` (or `rdma_assign_uobject()`) must release the `struct ib_uobject` via `uobj_put_destroy()` (`UVERBS_LOOKUP_DESTROY`) rather than `uobj_put_write()`, keeping `uobj->usecnt` write-locked after IDR removal. [F1]
- `rdma_alloc_commit_uobject()` consumes the caller's `kref` on `struct ib_uobject`, whereas `alloc_abort` and `destroy_hw` callbacks must not drop `uobj->ref`. After `uobj_finalize_uobj_create(uobj, attrs)` in a `write()` handler, the uverbs core owns `uobj` and the handler must not call `uobj_alloc_abort()`. [F2, F4]
- Memory from `uverbs_alloc()`, `uverbs_zalloc()`, or `uverbs_kcalloc()` is owned by `struct uverbs_attr_bundle`, returns `ERR_PTR()` on failure (never `NULL`), and is freed when the syscall ends; never `kfree()` it or store it past the syscall. [F16]
- `ib_set_flow()` increments `qp->usecnt` (if `qp` is non-NULL) and transfers ownership of `uflow_res` to `uflow->resources`; do not call `ib_uverbs_flow_resources_free(uflow_res)` on error after `ib_set_flow()`, and decrement `ibflow->qp->usecnt` on flow destruction. [F5]
- `ib_device_ops::create_cq_umem` takes ownership of `struct ib_umem *umem` and must call `ib_umem_release(umem)` on both error returns and `destroy_cq`. In `ib_free_cq()`, `pre_destroy_cq` must stop hardware CQ events without freeing kernel resources before polling is drained, and `post_destroy_cq`/`destroy_cq` frees resources after. [F12, F21]
- `struct ib_umem` accounts pinned memory against `umem->owning_mm` rather than `current`'s PID or `current->mm` at deregistration. `rdma_user_mmap_entry_get*()` references must be dropped with `rdma_user_mmap_entry_put()`, and entries removed via `rdma_user_mmap_entry_remove()` must only be `kfree()`d in `ib_device_ops::mmap_free`. [F10, F15]
- Active SGEs in `struct rvt_sge_state` hold a `percpu_ref` on `sge->mr` that must be dropped via `release == true` in `rvt_update_sge()` / `rvt_skip_sge()` or via `rvt_put_ss()`. Once `rvt_create_mmap_info()` wraps `rq->wq` in `ip->obj`, `ip->ref` owns `rq->wq` and `rvt_free_rq()` must not be called. [F7, F8]
- `ib_init_ah_attr_from_wc()` and `rdma_move_grh_sgid_attr()` hold a `grh.sgid_attr` reference that must be released via `rdma_destroy_ah_attr()` (or moved/replaced), whereas `rdma_ah_set_grh()` and `rdma_copy_ah_attr()` overwrite `grh.sgid_attr` without putting it. [F9]
- When `ib_device_ops.dealloc_driver` is set, `ib_unregister_device*()` and `ib_unregister_driver()` call `ib_dealloc_device()` automatically, so drivers must only call `ib_dealloc_device()` on error before `ib_register_device()` succeeds; users of `ib_unregister_device_queued()` must call `ib_unregister_driver()` before module unload. [F122, F123]
- `ib_device_try_get()` / `ib_device_get_by_*()` acquire a registration reference paired with `ib_device_put()` and fail if unregistered (use `get_device(&dev->dev)` for struct memory lifetime). Never call `ib_get_client_data()` after `ib_client->remove()` returns. [F18, F128]
- `ib_device_ops::get_netdev` and `ib_client::get_net_dev_by_params` must `dev_hold()` the returned `net_device` (and `get_netdev` must return `NULL` before `NETDEV_UNREGISTER` finishes). Drivers must free `add_gid` `*context` memory in `del_gid`, while sysfs core `kfree()`s `rdma_hw_stats` from `alloc_hw_*_stats`. MAD `ib_mad_recv_handler` callbacks must call `ib_free_recv_mad()`, and `ib_create_send_mad()` buffers require `ib_free_send_mad()`. [F13, F14, F19]

## API Contracts

- Drivers implementing callbacks for core-allocated objects (`ib_ah`, `ib_counters`, `ib_cq`, `ib_dmah`, `ib_mw`, `ib_pd`, `ib_qp`, `ib_rwq_ind_table`, `ib_srq`, `ib_ucontext`, `ib_xrcd`, `rdma_counter`) must set `INIT_RDMA_OBJ_SIZE(ib_struct, drv_struct, member)` with `member` at offset 0 of `drv_struct`, and must neither allocate nor `kfree()` `drv_struct` themselves. [F113, F129, F167]
- Event callbacks (`rdma_cm_event_handler`, `ib_cm_handler`, `ib_sa_multicast.callback`, `ib_qp_init_attr.event_handler`) must never call the synchronous destroy function (`rdma_destroy_id`, `ib_destroy_cm_id`, `ib_sa_free_multicast`, `ib_destroy_qp`/`ib_close_qp`) on the passed-in object from inside the callback. [F32]
- Extensible `UVERBS_ATTR_STRUCT()` attributes must be read with `uverbs_copy_from_or_zero()` because `uverbs_copy_from()` leaves trailing bytes uninitialized when `size > attr->ptr_attr.len`. User array attributes must be validated with `uverbs_attr_ptr_get_array_size()` and allocated with `uverbs_kcalloc()`. Unlike `uverbs_attr_get*()` which return `ERR_PTR(-ENOENT)`, `uverbs_attr_get_uobjs_arr()` sets `*arr = NULL` and returns `0` when absent. [F38, F39, F73]
- `rdma_udata_to_drv_context()` returns `NULL` when `udata` is `NULL`; dual kernel/user callbacks must check `if (udata)` (not `ucontext`) before dereferencing `udata` or the context. `ib_umem_find_best_pgsz()` and `ib_umem_find_best_pgoff()` return `0` on failure and update `umem->iova`; callers must check `if (!pgsz)` before passing `pgsz` to `rdma_umem_for_each_dma_block()` or `ib_umem_num_dma_blocks()`. [F42, F46, F59]
- Initialize `attr->type` (e.g., via `rdma_ah_find_type()`) before calling `rdma_ah_set_dlid()`, `rdma_ah_set_path_bits()`, `rdma_ah_set_make_grd()`, or `rdma_ah_retrieve_dmac()` on `struct rdma_ah_attr`. Omit `RDMA_CREATE_AH_SLEEPABLE` / `RDMA_DESTROY_AH_SLEEPABLE` in atomic contexts, and do not sleep in `create_ah`/`destroy_ah` when absent. [F48, F142]
- `ib_req_notify_cq()` requires `IB_CQ_SOLICITED` or `IB_CQ_NEXT_COMP` and returns `< 0` on error, `0` when armed, and `> 0` (if `IB_CQ_REPORT_MISSED_EVENTS` is set) to require re-polling `ib_poll_cq()`. `ib_device->port_data[]` uses `rdma_start_port()..rdma_end_port()` (`rdma_for_each_port()`), while `rdmavt`'s `rdi->ports[]` is 0-indexed (`rvt_to_iport(qp)`). [F44, F51]
- Use `ib_dma_*` wrappers instead of `ib_device.dma_device` (which is `NULL` when `ib_uses_virt_dma()` is true), use `ib_pd->local_dma_lkey` instead of `IBK_LOCAL_DMA_LKEY`, and use `rdma_user_mmap_io()` instead of `io_remap_pfn_range()` in `ib_device_ops.mmap`. Check `CAP_NET_RAW` with `rdma_uattrs_has_raw_cap()` or `rdma_dev_has_raw_cap()` rather than `capable(CAP_NET_RAW)`. [F133, F136, F141, F162]
- Initialize `dev_addr->net` before `rdma_translate_ip()` / `rdma_resolve_ip()`, set `qp_attr->qp_state` before `ib_cm_init_qp_attr()` / `rdma_init_qp_attr()`, and pass a buffer at least `sizeof(struct sockaddr_in6)` to `rdma_gid2ip()`. Use `opa_get_smp_data*()` for `struct opa_smp` payload access. [F53, F54, F88, F110]

## Error Handling

- In `struct uverbs_obj_idr_type`, if `destroy_object` fails on `RDMA_REMOVE_DESTROY`, it must leave `ib_uobject`, sibling `usecnt` counters, and driver state unchanged. User-mode teardown must call `ib_dealloc_pd_user()`, `rdma_destroy_ah_user()`, `ib_destroy_srq_user()`, `ib_destroy_cq_user()`, `ib_destroy_wq_user()`, and `ib_dealloc_xrcd_user()` and propagate their `int` return, never the kernel-only `ib_dealloc_pd()` / `rdma_destroy_ah()` / `ib_destroy_srq()` / `ib_destroy_cq()`. [F3, F43]
- Store the return value of `uverbs_attr_get_len()` and `uverbs_attr_ptr_get_array_size()` in a signed `int` or `ssize_t` (never `size_t` or `u32`) before checking `< 0`. For optional `UVERBS_ATTR_PTR_OUT` attributes, check `uverbs_copy_to*()` with `IS_UVERBS_COPY_ERR(ret)` so `-ENOENT` is ignored. [F37, F40]
- `ib_dma_map_sg*()` returns positive mapped entries on success and `0` on failure, whereas `ib_dma_map_sgtable_attrs()` sets `sgt->nents` and returns `0` on success or negative errno on failure. `rvt_driver_provided.qp_priv_alloc()` returns `ERR_PTR(err)` on error and may return `NULL` on success, so check `IS_ERR(qp->priv)`. [F45, F52]

## External Contracts

- In kernel enums crossing UAPI (`enum ib_wr_opcode`, `enum ib_wc_opcode`, `enum ib_qp_type`, `enum ib_qp_create_flags`, `enum ib_srq_type`), assign shared enumerators to their `IB_UVERBS_*` constants and place kernel-only values at non-overlapping numbers. Only set `IB_TM_CAP_RNDV_RC` in `ib_tm_caps.flags` when both base tag matching and RC rendezvous offload are supported. [F84, F135]

## Known Pitfalls

- `uverbs_get_const*()` overwrites `*(_to)` with an uninitialized local when the attribute is absent (`-ENOENT`); check the return value or use `uverbs_get_const_default()`. `uverbs_copy_from*()` uses `sizeof(*to)`, so pass a typed struct pointer rather than `void *` or a decayed array (use `_uverbs_copy_from()` for byte lengths). [F41, F107]
- Never index `qp->s_wq[n]` or `rq->kwq->curr_wq[n]` directly because `rvt_swqe` and `rvt_rwqe` have runtime-sized trailing SGE arrays; use `rvt_get_swqe_ptr()` and `rvt_get_rwqe_ptr()`. In `rdmavt`, use `rvt_div_round_up_mtu()` for packet counts, `rvt_cmp_msn()` for 24-bit MSN comparisons, and clamp `timeout <= 31` in `rvt_timeout_to_jiffies()`. [F79, F101, F105, F106]
- `rdma_core_cap_opa_port()` must test `(core_cap_flags & RDMA_CORE_PORT_INTEL_OPA) == RDMA_CORE_PORT_INTEL_OPA`. Convert `IB_MULTICAST_LID_BASE` (`__be16`) with `be16_to_cpu()`, not `be32_to_cpu()`. `sa_convert_path_opa_to_ib()` and `sa_convert_path_ib_to_opa()` require distinct `dest` and `src` pointers and a matching `src->rec_type`. [F68, F83, F89]
- Cast `entry->start_pgoff` to `u64` before `<< PAGE_SHIFT` in `rdma_user_mmap_get_offset()`, and use `BIT_ULL(biter->__pg_bit)` in `rdma_block_iter_dma_address()`. Buffers mapped via `ib_dma_*` must be direct-mapped lowmem (never `vmalloc` or highmem). Verify `wr->opcode`/QP type before `rdma_wr()`, `atomic_wr()`, `ud_wr()`, or `reg_wr()`, and bound `ib_device.node_desc` formatting to `%.64s` (`IB_DEVICE_NODE_DESC_MAX`). [F98, F100, F116, F120, F155]
