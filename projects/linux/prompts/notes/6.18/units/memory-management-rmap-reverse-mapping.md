# MEMORY MANAGEMENT - RMAP (REVERSE MAPPING)

Implements physical-to-virtual reverse mapping (rmap) for anonymous, file-backed, KSM, and HugeTLB folios in the Linux memory management subsystem. It manages `anon_vma` and `anon_vma_chain` hierarchies across VMA forks/splits/merges, maintains per-page and per-folio mapcounts (including per-MM large mapcount tracking and `PageAnonExclusive` state), and provides page-table walking (`page_vma_mapped_walk`, `rmap_walk`) to check page references, write-protect/clean mappings, unmap pages for reclaim, convert PTEs to migration entries, or mark pages for device-exclusive access.

## Architecture & Data Flow

- For non-KSM anonymous folios, `folio->mapping` stores `(void *)anon_vma + FOLIO_MAPPING_ANON`; `folio_move_anon_rmap()` and `__folio_set_anon()` must combine pointer and flag before writing via a single `WRITE_ONCE()` (using `vma->anon_vma->root` in `__folio_set_anon()` when `!exclusive`), and `folio_get_anon_vma()` / `folio_lock_anon_vma_read()` must untag by subtracting `FOLIO_MAPPING_ANON`. [F68, F88]
- In `anon_vma` hierarchies (`anon_vma_fork()`, `unlink_anon_vmas()`, `__put_anon_vma()`), `rwsem` and tree-lock `refcount` belong to `anon_vma->root`, `num_children` is tracked on `anon_vma->parent`, and `num_active_vmas` on `vma->anon_vma`. `anon_vma_fork(vma, pvma)` must clear `vma->anon_vma = NULL` before calling `anon_vma_clone(vma, pvma)`, which reuses an `anon_vma` only when `!dst->anon_vma && src->anon_vma && anon_vma->num_children < 2 && anon_vma->num_active_vmas == 0`. [F51, F58, F104]
- Because `anon_vma_chain_link()` inserts at the head via `list_add()`, `anon_vma_clone()` must iterate `src->anon_vma_chain` with `list_for_each_entry_reverse()` to preserve newest-to-oldest order so `unlink_anon_vmas()` frees the root `anon_vma` last. [F99]
- Because `anon_vma_cachep` uses `SLAB_TYPESAFE_BY_RCU` with `anon_vma_ctor()`, `anon_vma_alloc()` must reset `refcount` (1), `num_children` (0), `num_active_vmas` (0), `parent` (`anon_vma`), and `root` (`anon_vma`), but must not call `init_rwsem(&anon_vma->rwsem)` because RCU readers in `folio_lock_anon_vma_read()` may access `rwsem` concurrently. [F52]
- Under `CONFIG_MM_ID`, `folio_mm_id()` and `folio_set_mm_id()` require `idx` in `{0, 1}` and must mask `folio->_mm_id[idx]` with `MM_ID_MASK` to preserve `FOLIO_MM_IDS_LOCK_BITNUM` and `FOLIO_MM_IDS_SHARED_BITNUM` in `folio->_mm_ids`. `folio_mm_id(folio, idx) == MM_ID_DUMMY` must hold iff `folio->_mm_id_mapcount[idx] == -1`. [F60, F80]
- In `__folio_add_rmap()` and `__folio_remove_rmap()`, `folio->_nr_pages_mapped` packs the PTE-mapped subpage count in `FOLIO_PAGES_MAPPED` (`ENTIRELY_MAPPED - 1`) and adds `ENTIRELY_MAPPED` when PMD/PUD-mapped: PTE map/unmap must update `__folio_mod_stat()` only when the updated value is `< ENTIRELY_MAPPED`, and `PGTABLE_LEVEL_PMD`/`PGTABLE_LEVEL_PUD` share `_entire_mapcount` but must set `nr_pmdmapped` only when `level == PGTABLE_LEVEL_PMD`. [F86, F97]
- In `__folio_remove_rmap()`, when unmapping leaves a large anonymous folio partially mapped (`partially_mapped && folio_test_anon(folio) && !folio_test_partially_mapped(folio)`), `deferred_split_folio(folio, true)` must be called. [F70]
- `set_tlb_ubc_flush_pending()` must set `tlb_ubc->flush_required = true`, set `tlb_ubc->writable = true` if `pte_dirty(pteval)`, and advance `mm->tlb_flush_batched` (resetting to `1` via `atomic_try_cmpxchg` when `(batch & TLB_FLUSH_BATCH_PENDING_MASK) > TLB_FLUSH_BATCH_PENDING_LARGE`); `try_to_unmap_flush()` must reset both `flush_required` and `writable` to `false`. [F67, F110]
- When clearing present PTEs in `try_to_unmap_one()`, `try_to_migrate_one()`, or `make_device_exclusive()`, `pte_dirty(pteval)` must be propagated via `folio_mark_dirty(folio)`, and deferred TLB flushes must be flushed via `try_to_unmap_flush_dirty()` before I/O. [F142]
- `folio_unmap_pte_batch()` must bound `max_nr` by `(pmd_addr_end(addr, vma->vm_end) - addr) >> PAGE_SHIFT` before calling `folio_pte_batch()` so `pvmw->pte` accesses in `folio_pte_batch()`, `get_and_clear_ptes()`, and `set_ptes()` never cross a PMD boundary. [F117]
- In `rmap_walk_anon()` and `__rmap_walk_file()`, interval tree bounds must be `[pgoff_start, pgoff_start + nr_pages - 1]`, and VMA start addresses must be computed via `vma_address(vma, pgoff_start, nr_pages)` rather than raw `pgoff_start - vma->vm_pgoff`. [F79]

## Synchronization

- Lock ordering in `mm/rmap.c`: `mm->mmap_lock` -> `folio_lock` -> `mapping->i_mmap_rwsem` / `anon_vma->root->rwsem` -> `mm->page_table_lock` / `pte_lock` -> `swap_lock` / `mmlist_lock`. Never acquire rmap rwsems or `folio_lock` under a PTL, or `folio_lock` under rmap rwsems (outside HugeTLB fault paths). [F123]
- In `page_vma_mkclean_one()`, `try_to_unmap_one()`, `try_to_migrate_one()`, and `make_device_exclusive()`, `mmu_notifier_invalidate_range_start()` must be called before acquiring any PTL, and `mmu_notifier_invalidate_range_end()` must be called after `page_vma_mapped_walk_done()` or `folio_walk_end()` releases the PTL. [F28]
- `anon_vma->rb_root` must only be accessed under `anon_vma->root->rwsem`, and attaching `vma->anon_vma` in `__anon_vma_prepare()` must also hold `mm->page_table_lock` while rechecking `!vma->anon_vma`. In `anon_vma_clone()`, if `anon_vma_chain_alloc(GFP_NOWAIT)` fails while `root` is write-locked, `unlock_anon_vma_root(root)` must be called and `root` reset to `NULL` before retrying with `GFP_KERNEL`. [F21, F29]
- Because `anon_vma_cachep` is `SLAB_TYPESAFE_BY_RCU`, `folio_get_anon_vma()` and `folio_lock_anon_vma_read()` must enter `rcu_read_lock()`, check `folio_mapped(folio)` before and after pinning `refcount` or `root_anon_vma->rwsem`, and drop the ref/lock if unmapped; `anon_vma_free()` must check `rwsem_is_locked(&anon_vma->root->rwsem)` and cycle `anon_vma_lock_write()`/`anon_vma_unlock_write()` before freeing to `anon_vma_cachep`. [F17, F126]
- Callers of `folio_try_dup_anon_rmap_ptes/pte/pmd()` must hold PTL and `src_vma->vm_mm->write_protect_seq`, mapping duplicated entries read-only in both parent and child. Callers of `folio_try_share_anon_rmap_pte/pmd()` and `hugetlb_try_share_anon_rmap()` must hold PTL and clear/invalidate the entry first, with `smp_mb()` before `folio_maybe_dma_pinned()` and `smp_mb__after_atomic()` after `ClearPageAnonExclusive()` under `CONFIG_HAVE_GUP_FAST`. [F26, F35]
- In `try_to_unmap_one()`, before discarding a clean `!folio_test_swapbacked(folio)` (`MADV_FREE`) anonymous folio's cleared PTEs, `smp_mb()` must precede reading `folio_ref_count(folio)` and `folio_mapcount(folio)` (`ref_count != 1 + map_count`), and `smp_rmb()` must precede `folio_test_dirty(folio)`. [F36]
- In `try_to_unmap_one()` and `try_to_migrate_one()`, `huge_pmd_unshare()` must only be called for `!folio_test_anon(folio)` HugeTLB folios with `TTU_RMAP_LOCKED`, and must acquire the hugetlb VMA lock via `hugetlb_vma_trylock_write(vma)`. [F27]
- When `map_pte()` and `page_vma_mapped_walk()` map a PTE table via `pte_offset_map_rw_nolock()`, they must save `ptl` before locking and, after `spin_lock(ptl)`, revalidate `pmd_same(pmde, pmdp_get_lockless(pvmw->pmd))`, calling `pte_unmap_unlock(pvmw->pte, ptl)`, clearing `pvmw->pte = NULL`, and retrying on mismatch. When `PVMW_SYNC` is set, `map_pte()` must use `pte_offset_map_lock()`, and `page_vma_mapped_walk()` must cycle `pmd_lock(mm, pvmw->pmd)` on `!pmd_present(pmde)` for PMD-sized THP ranges. [F33, F65]
- `rmap_walk_file()` requires `folio_test_locked(folio)`; `folio_referenced()` must trylock `!folio_test_anon(folio) || folio_test_ksm(folio)` folios when `!is_locked` before `rmap_walk()` and only call `folio_unlock(folio)` when `we_locked` is `true`; `rmap_walk_anon()` and `__rmap_walk_file()` must only unlock `anon_vma` or `mapping->i_mmap_rwsem` when `locked` is `false`. [F12, F134]
- In `make_device_exclusive()`, after `get_user_page_vma_remote()`, locking the folio, and starting the MMU notifier range, `folio_walk_start()` must re-verify `fw_folio == folio && fw.page == page && fw.level == FW_LEVEL_PTE && pte_write(fw.pte)` under PTL. [F34]

## Object Lifetimes

- Any `while (page_vma_mapped_walk(&pvmw))` loop that exits before `page_vma_mapped_walk()` returns `false` must call `page_vma_mapped_walk_done(&pvmw)` on every early-exit path (`return`, `break`, `goto`) to unmap `pvmw.pte` and unlock `pvmw.ptl`; in `page_vma_mapped_walk_done()`, `pte_unmap(pvmw->pte)` must only be called when `!is_vm_hugetlb_page(pvmw->vma)`. [F1, F121]
- In `__anon_vma_prepare()`, when `!vma->anon_vma` holds under `anon_vma_lock_write(anon_vma)` and `mm->page_table_lock`, ownership of `allocated` and `avc` transfers to `vma` and both local pointers must be set to `NULL` before unlocking. [F5]
- `anon_vma_fork()` must pin `anon_vma->root` via `get_anon_vma(anon_vma->root)` before linking a child `anon_vma`, and `__put_anon_vma()` must call `anon_vma_free(anon_vma)` on the child before dropping `root->refcount`. [F16]
- `__folio_remove_rmap()` must not clear `folio->mapping` when an anonymous folio's mapcount drops to zero, leaving reset to `free_pages_prepare()` so it does not overwrite a racing `folio_add_anon_rmap_*()`. [F14]

## API Contracts

- Before calling `page_vma_mapped_walk(&pvmw)`, `pvmw.pmd`, `pvmw.pte`, and `pvmw.ptl` must be `NULL`, and `pvmw.pgoff` must be initialized when `pvmw.nr_pages > 1`. After splitting a PMD in the walk loop, the caller must call `page_vma_mapped_walk_restart(&pvmw)` to unlock `pvmw.ptl` and clear `ptl`, `pmd`, and `pte` before `continue`. [F50, F100]
- `make_device_exclusive()` must align `addr` down via `PAGE_ALIGN_DOWN(addr)`, reject non-anonymous or HugeTLB folios with `ERR_PTR(-EOPNOTSUPP)`, return an `ERR_PTR` (never `NULL`) on failure without populating `*foliop`, and on success return with `*foliop` locked, referenced, and its rmap mapcount unchanged; on retry/error it must unwind `folio_walk_end()`, `mmu_notifier_invalidate_range_end()`, `folio_unlock()`, and `folio_put()` in reverse order. [F11, F40, F89]
- `__folio_try_dup_anon_rmap()`, `hugetlb_try_dup_anon_rmap()`, `__folio_try_share_anon_rmap()`, and `hugetlb_try_share_anon_rmap()` return `0` or `-EBUSY` (if DMA-pinned), and must check all `nr_pages` subpages before clearing `PageAnonExclusive` or incrementing mapcounts. [F41]
- In `anon_vma_clone(dst, src)`, `anon_vma_fork(vma, pvma)`, and `folio_try_dup_anon_rmap_ptes/pte/pmd(..., dst_vma, src_vma)`, destination precedes source; in `__folio_try_dup_anon_rmap()`, `folio_needs_cow_for_dma()` must test `src_vma` while `folio_add_large_mapcount()` / `folio_inc_large_mapcount()` must take `dst_vma`. [F55, F106]
- `folio_set_large_mapcount()`, `folio_add_return_large_mapcount()`, and `folio_sub_return_large_mapcount()` take a positive 1-based count (`mapcount > 0` or `diff > 0`) and return the 0-based total mapping count (`new_mapcount_val + 1`), while storing `-1`-biased counts in `folio->_large_mapcount` and `folio->_mm_id_mapcount[]`. [F57]
- When walking a HugeTLB VMA in `page_vma_mapped_walk()`, huge page size and page count passed to `hugetlb_walk()`, `huge_pte_lock()`, and `check_pte()` must come from `hstate_vma(vma)` (not `pvmw->nr_pages`), and installing HugeTLB PTEs in `try_to_unmap_one()` / `try_to_migrate_one()` must use `set_huge_pte_at(mm, address, pvmw.pte, ..., huge_page_size(hstate_vma(vma)))`. [F53, F137]
- `page_address_in_vma()` and `page_mapped_in_vma()` return `(unsigned long)-EFAULT` (not `0`) when unmapped; callers must test `addr == -EFAULT`. `folio_referenced()` must initialize `*vm_flags = 0` before any early return (including its `!CONFIG_MMU` stub) and returns signed `int` (`-1` on lock contention or exclusive anon folio in exiting/OOM-reaped `mm`). [F38, F39, F73]
- `folio_mkclean()` requires `folio_test_locked(folio)` and only cleans `VM_SHARED` VMAs; to write-protect `VM_SHARED` PFN ranges without a locked folio, callers must use `mapping_wrprotect_range()`, and `__rmap_walk_file()` / `mapping_wrprotect_range_one()` must not dereference `folio` when `folio == NULL` (reading `struct wrprotect_file_state *` from `rwc->arg`). [F118, F141]

## Error Handling

- On allocation failure in `anon_vma_clone()`, `dst->anon_vma` must be cleared to `NULL` before calling `unlink_anon_vmas(dst)` because `dst->anon_vma` may have been assigned during the loop before `dst->anon_vma->num_active_vmas++` runs at loop completion. [F4]
- In `try_to_unmap_one()`, when aborting the discard of a `!folio_test_swapbacked(folio)` anonymous folio, cleared PTEs must be restored via `set_ptes(mm, address, pvmw.pte, pteval, nr_pages)`, and `folio_set_swapbacked(folio)` must be called iff `folio_test_dirty(folio) && !(vma->vm_flags & VM_DROPPABLE)`. [F71]
- In `try_to_unmap_one()` and `try_to_migrate_one()`, if `swap_duplicate()`, `arch_unmap_one()`, `folio_try_share_anon_rmap_pte()`, or `hugetlb_try_share_anon_rmap()` fails after clearing the PTE, the original `pteval` must be restored and any allocated swap entry freed before aborting without modifying RSS or rmap counts. [F72]

## Known Pitfalls

- When `page_vma_mapped_walk(&pvmw)` returns `true`, `pvmw.pte` is `NULL` for PMD-mapped THPs and `pvmw.pmd` is `NULL` for HugeTLB mappings; when `pvmw.pte != NULL` without `PVMW_MIGRATION`, the PTE may be a non-present device-private or device-exclusive swap entry, so callers must guard `pte_pfn()`, `pte_dirty()`, `pte_write()`, `pte_unused()`, `pte_young()`, `pte_soft_dirty()`, `pte_uffd_wp()`, and cache/TLB flushes with `pte_present(pteval)`, using `swp_offset_pfn(pte_to_swp_entry(pteval))`, `pte_clear()`, `pte_swp_soft_dirty()`, and `pte_swp_uffd_wp()` when non-present. [F43, F44, F45]
- In `page_vma_mapped_walk()`, a non-present `pgd`/`p4d`/`pud`/`pmd` must call `step_forward()` (which clamps wrap-around `0` to `ULONG_MAX`) and `continue`; in `next_pte:`, crossing a PMD boundary (`(pvmw->address & (PMD_SIZE - PAGE_SIZE)) == 0`) or failing `pmd_same()` must unlock `pvmw->ptl`, unmap `pvmw->pte`, clear both to `NULL`, set `PVMW_PGTABLE_CROSSED` (on boundary cross), and jump to `restart:`. [F75, F76, F101, F102]
- In `check_pte()` and `check_pmd()`, PFN overlap checks must use extracted PFNs (never `struct page *` pointer arithmetic across sparsemem sections) and test inclusive upper bounds: `(pfn + pte_nr - 1) < pvmw->pfn` (or `HPAGE_PMD_NR`) and `pfn > (pvmw->pfn + pvmw->nr_pages - 1)`. [F77, F112]
- Operations on `folio->_mm_ids` must pass bit numbers (`FOLIO_MM_IDS_LOCK_BITNUM`, `FOLIO_MM_IDS_SHARED_BITNUM`) to `bit_spin_lock()`, `__bit_spin_unlock()`, and `test_bit()`, but use `FOLIO_MM_IDS_SHARED_BIT` for bitwise `|=` and `&= ~`. In `folio_add_return_large_mapcount()` (on 32-bit) and `folio_sub_return_large_mapcount()`, if `_mm_id_mapcount[idx]` overflows or underflows to `< 0`, it must be clamped to `-1` with `_mm_id[idx]` set to `MM_ID_DUMMY` (and `FOLIO_MM_IDS_SHARED_BIT` set on 32-bit overflow). [F56, F82, F83]
- Because KSM folios set both `FOLIO_MAPPING_ANON` and `FOLIO_MAPPING_KSM` in `folio->mapping`, `rmap_walk()` must test `folio_test_ksm(folio)` before `folio_test_anon(folio)`, and `folio_get_anon_vma()` / `folio_lock_anon_vma_read()` must check `(anon_mapping & FOLIO_MAPPING_FLAGS) != FOLIO_MAPPING_ANON`. [F91]
- In `__folio_dup_file_rmap()`, `__folio_try_dup_anon_rmap()`, and `__folio_add_rmap()`, the per-page loop decrements `nr_pages` to `0`, so `folio_add_large_mapcount()` must be passed `orig_nr_pages`; when adding/subtracting `ENTIRELY_MAPPED` on `folio->_nr_pages_mapped` in `__folio_add_rmap()` / `__folio_remove_rmap()`, the page delta `nr` must be clamped to `0` if `nr < 0` or if `ENTIRELY_MAPPED` raced ahead before calling `__folio_mod_stat()`. [F103, F111]

## Other

- Before clearing or write-protecting present entries in `page_vma_mkclean_one()`, `try_to_unmap_one()`, `try_to_migrate_one()`, or `make_device_exclusive()`, the CPU cache must be flushed with `flush_cache_page()` for single PTEs or `flush_cache_range()` for batched PTEs, PMD THPs (`HPAGE_PMD_SIZE`), and HugeTLB ranges. [F131]
