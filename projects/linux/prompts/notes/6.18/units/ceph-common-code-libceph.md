# CEPH COMMON CODE (LIBCEPH)

Provides the core Ceph client library (libceph) headers and common infrastructure shared by the CephFS filesystem and RBD block device driver. It implements client session lifecycle and mount option parsing, the Ceph messenger core for reliable/lossy TCP communication (v1 and v2 protocols), authentication (none and cephx with AES/HMAC crypto and kernel keyring integration), RADOS object class lock client operations, CRUSH placement mapping algorithms, wire encoding/decoding helpers, and debugfs inspection.

## Architecture & Data Flow

- Generic `struct ceph_connection` handlers in `net/ceph/messenger.c` must check `ceph_msgr2(from_msgr(con->msgr))` before accessing `con->v1` or `con->v2` (an anonymous union). Every `struct ceph_messenger` passed to `ceph_con_init()`, `ceph_messenger_init()`, or `ceph_encode_my_addr()` must be the embedded `msgr` of a `struct ceph_client` (downcast via `from_msgr()`). [F32, F113]
- In `ceph_con_get_out_msg()`, `con->ops->reencode_message(msg)` must only run inside `if (msg->needs_out_seq)` when `msg->hdr.seq` is first assigned, so messages requeued by `con_fault()` are not re-encoded on retry. `ceph_con_discard_requeued()` must stop draining `con->out_queue` upon seeing `msg->needs_out_seq` before comparing `msg->hdr.seq` against `reconnect_seq`. [F50, F92]
- Removing a `struct ceph_msg` from `con->out_queue` or `con->out_sent` must use `list_del_init()` (via `ceph_msg_remove()`), because `ceph_msg_revoke()` tests `list_empty(&msg->list_head)` and `ceph_msg_release()` and `ceph_con_send()` assert it. [F91]
- In `ceph_msg_data_iter_next()` and `ceph_msg_data_iter_advance()`, `cursor->lastlen` tracks bytes pre-advanced by `iov_iter_get_pages2()`; `ceph_msg_data_iter_next()` must revert `cursor->lastlen` when non-zero, and `ceph_msg_data_iter_advance()` must only advance `cursor->iov_iter` by `bytes - cursor->lastlen` when `bytes >= cursor->lastlen`. For `CEPH_MSG_DATA_PAGELIST`, the first page in `pagelist->head` must start at offset 0 and interior pages must be filled to `PAGE_SIZE`. [F94, F146]
- `ceph_compare_options()` compares `struct ceph_options` up to `mon_addr` with `memcmp()`; any pointer, rbtree, or non-trivially-comparable field must be placed at or after `mon_addr` and handled explicitly. Every option emitted in `ceph_print_client_options()` must end with `,` because `m->count` is decremented by one to strip the final comma. [F77, F89]
- In `process_one_ticket()`, hold the newly decoded session key in `new_session_key` until the service ticket blob (decrypted with the existing `th->session_key` when `is_enc` is set) is decoded, before updating `th->session_key`, `th->ticket_blob`, and `xi->have_keys`. In `ceph_x_invalidate_authorizer()`, invalidating `peer_type` must also call `invalidate_ticket(ac, CEPH_ENTITY_TYPE_AUTH)`. [F57, F58]
- In `struct ceph_auth_client_ops`, `update_authorizer`, `add_authorizer_challenge`, `verify_authorizer_reply`, `invalidate_authorizer`, `sign_message`, and `check_message_signature` are `NULL` in `ceph_auth_none_ops` and must be NULL-checked. Authorizer structs must embed `struct ceph_authorizer base` at offset 0, and CRUSH bucket subtypes must keep `struct crush_bucket h` at offset 0 matching `h.alg`. [F41, F111, F112]
- `ceph_has_room()` checks `end >= *p` before `n <= end - *p` (avoiding pointer overflow). `ceph_decode_entity_addr_versioned()` rejects `addr_len > sizeof(addr->in_addr)`, zeroes `addr->in_addr`, and sets `*p = struct_end` to skip unknown trailing fields. RADOS lock encoders (`cls_lock_client.c`) must check that the exact wire size is `<= PAGE_SIZE` (else `-E2BIG`) before allocating a page. [F65, F70, F81]
- In `struct ceph_osdmap`, `osd_state`, `osd_weight`, and `osd_addr` require `0 <= osd < map->max_osd` (`ceph_osd_exists()`), and `struct ceph_osds.primary` is an OSD ID (`-1` when empty), not an index into `osds[]`. [F86]
- In `struct crush_map`, negative IDs identify buckets and index `map->buckets`, `work->work`, and `choose_args` at `-1 - id` (`< map->max_buckets`). For `CRUSH_BUCKET_STRAW2`, `arg->ids` and `arg->weight_set[pos].weights` need `>= bucket->h.size` elements, and `get_choose_arg_weights()` must clamp `position >= arg->weight_set_size` to `arg->weight_set_size - 1`. [F72, F75, F109]
- `struct crush_bucket_tree` maps 0-based item `p` in `h.items` to 1-based `node_weights[crush_calc_tree_node(p)]` and leaf node `n` to `h.items[n >> 1]`. In `bucket_list_choose()`, `bucket_tree_choose()`, and `bucket_straw_choose()`, widen the 32-bit hash to `__u64` before multiplying by the 32-bit weight. [F73, F100]
- `crush_choose_firstn()` and `crush_choose_indep()` must check `in->size != 0` before choosing. In `bucket_perm_choose()`, if `work->perm_n == 0xffff` (from `pr == 0`), a call with `pr > 0` and the same `x` must initialize `work->perm[1..size-1] = i`, `work->perm[work->perm[0]] = 0`, and `work->perm_n = 1`. In `crush_choose_firstn()`, `retry_descent` resets `in = bucket` and `flocal = 0` while keeping `ftotal`. [F95, F96, F103]

## Synchronization

- `ceph_sock_data_ready()`, `ceph_sock_write_space()`, and `ceph_sock_state_change()` run in atomic socket-callback context and must never sleep or take `con->mutex`; `con->ops->get` and `.put` must also be atomic-safe. `con->mutex` ranks inner to `osdc->lock`, `osd->lock`, and `monc->mutex`, so `cancel_con()` in `ceph_con_close()` must use non-blocking `cancel_delayed_work()` under `con->mutex`. [F119, F120, F121]
- In `ceph_tcp_connect()`, call `set_sock_callbacks()` and `con_sock_state_connecting()` before `kernel_connect()`. `ceph_con_close_socket()` must clear `CEPH_CON_F_SOCK_CLOSED` after closing `con->sock`. In `ceph_sock_write_space()`, clear `SOCK_NOSPACE` on `sk->sk_socket->flags` before queueing `con` when `CEPH_CON_F_WRITE_PENDING` and `sk_stream_is_writeable(sk)` hold. [F18, F21, F22]
- `ceph_con_process_message()` must clear `con->in_msg = NULL` before unlocking `con->mutex` for `con->ops->dispatch(con, msg)`, and `dispatch` must not wait synchronously for other messages on `ceph_msgr_wq`. Wrap `sock_create_kern()` in `ceph_tcp_connect()` and `crypto_alloc_sync_skcipher()` in `set_secret()` with `memalloc_noio_save()` / `memalloc_noio_restore()`, and set `sk_allocation = GFP_NOFS`. [F27, F126]
- Use `ceph_try_get_string()` (not `ceph_get_string()`) when reading an RCU-protected `struct ceph_string *` without the update lock. The OSD lock order is `osdc->lock` -> `osd->lock`; searching `osd->o_requests` requires `osd->lock` or `osd->o_requests_lock`, while modifying it requires both. [F29, F31, F125]

## Object Lifetimes

- `ceph_create_client()` takes ownership of `opt` only on success; on error the caller must call `ceph_destroy_options(opt)`. `ceph_destroy_client()` sets `client->msgr.stopping = 1` first, then runs `ceph_osdc_stop()`, `ceph_monc_stop()`, `ceph_messenger_fini()` before `ceph_debugfs_client_cleanup()` and `ceph_destroy_options()`. `ceph_messenger_init()` pins `current->nsproxy->net_ns` into `msgr->net` (used via `read_pnet()` in `ceph_tcp_connect()` and `ceph_compare_options()`). [F1, F2, F134]
- In `ceph_parse_param()`, `Opt_name` steals `param->string` into `opt->name` (after `kfree(opt->name)`) and sets `param->string = NULL`, whereas `Opt_secret` and `Opt_key` destroy and free any old `opt->key` without consuming `param->string`. [F3]
- In `ceph_con_close()`, call `ceph_con_reset_protocol()` before `ceph_con_reset_session()` (which asserts `con->in_msg` and `con->out_msg` are `NULL`). `ceph_con_get_out_msg()` keeps the queue ref on `con->out_sent` and takes a second ref for `con->out_msg`, so stopping `con->out_msg` must call `ceph_msg_put(con->out_msg)` and set `con->out_msg = NULL`. [F8, F12]
- `queue_con_delay()` takes a `con->ops->get(con)` ref before queueing `con->work`, released at the end of `ceph_con_workfn()` or by `cancel_con()` if `cancel_delayed_work()` succeeds. `ceph_con_in_msg_alloc()` drops `con->mutex` across `alloc_msg()`; if `con->state != CEPH_CON_S_OPEN` after re-locking or `ceph_alloc_middle()` fails, it must `ceph_msg_put(msg)` and leave `con->in_msg == NULL`. [F9, F13]
- `ceph_msg_data_destroy()` frees `CEPH_MSG_DATA_PAGES` vectors iff `data->own_pages` is `true`. `ceph_msg_data_iter_next()` calls `put_page()` immediately on the page from `iov_iter_get_pages2()`, so `ceph_msg_data_add_iter()` callers must keep backing pages pinned during I/O. [F15, F16]

## API Contracts

- `ceph_con_send()` always consumes one ref on `@msg` (calling `ceph_msg_put(msg)` immediately if `CEPH_CON_S_CLOSED`). Messages using `ceph_msg_data_add_*()` must be allocated with `ceph_msg_new2()` with sufficient `max_data_items` (not `ceph_msg_new()`). Cursor loops must call `ceph_msg_data_advance(cursor, 0)` while `!cursor->resid && cursor->total_resid > 0` before `ceph_msg_data_next()`. [F11, F43, F93]
- `ceph_con_flag_*()` take a `CEPH_CON_F_*` bit index (`0..4`), not a mask, and `BUG_ON` if invalid; new flags or `CEPH_CON_S_*` states must be added to `con_flag_valid()` or `con_sock_closed()`. `con->ops->alloc_msg(con, hdr, skip)` returns `NULL` both when skipping (`*skip != 0`) and on `-ENOMEM` (`*skip == 0`), and must never return non-NULL with `*skip != 0`. [F37, F45, F90]
- Initialize `struct ceph_object_id` with `CEPH_DEFINE_OID_ONSTACK()` or `ceph_oid_init()` and copy only with `ceph_oid_copy()` (never struct copy/`memcpy()`, as `name` points to `inline_name`). Initialize `struct ceph_object_locator` and `struct ceph_osds` with `ceph_oloc_init()` and `ceph_osds_init()` (empty is `-1`, not `0`). [F34, F35, F114]
- `setup_sgtable()` must use `vmalloc_to_page()` when `is_vmalloc_addr(buf)`, include `off` in `PAGE_ALIGN(off + buf_len)` for `chunk_cnt`, and `teardown_sgtable()` must only call `sg_free_table(sgt)` when `sgt->orig_nents > 1`. [F105, F141]
- Place `ceph_x_encrypt()` plaintext at `ceph_x_encrypt_offset()` in a buffer of `>= ceph_x_encrypt_buflen(len)` bytes. Wipe decoded secrets in `ceph_crypto_key_decode()` and `decode_con_secret()` with `memzero_explicit()`, and free `key->key` with `kfree_sensitive()`. In `handle_reply()`, call `ceph_auth_set_global_id()` as soon as the `AUTH` ticket is processed. [F49, F59, F142]
- `ceph_cls_lock_info()` transfers `*tag` (`kfree()`) and `*lockers` (`ceph_free_lockers()`) ownership only on `0` return. `ceph_extract_encoded_string()` checks bounds before allocating `len + 1` bytes, NUL-terminates, and leaves `*p`/`*lenp` unchanged on error. `ceph_decode_entity_addrvec()` requires marker `2`, decodes all entries, rejects duplicate matches, and leaves `*addr` untouched when empty or all-zero (zero `*addr` beforehand). [F4, F40, F66, F71]
- Call `ceph_wait_for_latest_osdmap()` when the latest monitor `osdmap` epoch is required. Pass `crush_do_rule()` a thread-local workspace of `crush_work_size()` bytes initialized by `crush_init_workspace()` (re-initialized on `crush_map` changes). Compare `ceph_seq_t` with `ceph_seq_cmp(a, b)` against `0`, use `kernel_connect()` in `ceph_tcp_connect()`, check timeout options against `INT_MAX / 1000` before `msecs_to_jiffies(val * 1000)`, and guard bio helpers with `#ifdef CONFIG_BLOCK`. [F30, F106, F132, F137, F143, F147]

## Error Handling

- `ceph_extract_encoded_string()`, `ceph_create_client()`, `ceph_auth_init()`, and `ceph_alloc_page_vector()` return `ERR_PTR()`, whereas `ceph_buffer_new()`, `ceph_msg_new*()`, and `ceph_alloc_options()` return `NULL`. [F36]
- `set_secret()` must reset `key->tfm = NULL` on `crypto_alloc_sync_skcipher()` failure, `ceph_crypto_key_destroy()` must check `if (key->tfm)`, and malformed key payloads must return `-EINVAL` without `WARN_ON()`. `ceph_x_encrypt()` / `ceph_x_decrypt()` return byte length `>= 0` or `-errno` (`ceph_crypt()` returns `0`). `handle_reply()` returns `-EAGAIN` when more auth requests are needed and `0` when done. `decode_lockers()` must use `kcalloc()` so `ceph_free_lockers()` safely sees `NULL` cookies on error. [F33, F38, F39, F48, F139]

## External Contracts

- `ceph_entity_addr.in_addr.ss_family` is little-endian in versioned `entity_addr_t` (`marker == 1`), but big-endian in legacy `entity_addr_t` and msgr1 banners. Check features with `CEPH_HAVE_FEATURE()` / `HAVE_MSGR2_FEATURE()` (not raw `CEPH_FEATURE_*` bits), and encode MDS open flags (`ceph_mds_request_args.open.flags`) with `CEPH_O_*` constants (not kernel `O_*`). [F68, F82, F84]

## Known Pitfalls

- `struct ceph_entity_addr` is `__attribute__((packed))` (at odd offset 9 in `struct ceph_entity_inst`), so `addr->in_addr` fields must be accessed via `get_unaligned()`/`put_unaligned()` or an aligned stack copy. Test read OSD ops with `ceph_osd_op_mode_read(op)` (not `op & CEPH_OSD_OP_MODE_RD`, which is set on `CEPH_OSD_OP_CALL`). `CEPH_OPT_NOSHARE`, `CEPH_OPT_NOCRC`, and `CEPH_OPT_NOMSGSIGN` are set when disabled, whereas `CEPH_OPT_TCP_NODELAY` is set when enabled. [F63, F69, F88]
- In `process_one_ticket()`, decode the service ticket after `if (is_enc)` using `ptp`/`tpend` (and session key using `dp`/`dend`), as `ceph_x_decrypt()` already advances `*p`. In `crush_do_rule()`, when `recurse_to_leaf` is true, copy `c` into `o` before `swap(o, w)`. Pass `crush_ln()` a 16-bit value in `[0, 0xffff]`, and in `bucket_straw2_choose()` guard `div64_s64(ln, weights[i])` with `weights[i] != 0` (`S64_MIN` when zero). [F97, F99, F101, F102]
