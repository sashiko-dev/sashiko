# ARM/NUVOTON NPCM ARCHITECTURE

This unit provides architecture support and SoC peripheral drivers for Nuvoton NPCM Baseboard Management Controller (BMC) families (NPCM7xx Poleg and NPCM8xx Arbel) and the Nuvoton NCT3018Y I2C RTC, covering SMP bringup, clocks, resets, pinctrl/GPIO/SGPIO, I2C, SPI (FIU and PSPI), PWM/fan hwmon, PECI, KCS IPMI, ADC, watchdog, RNG, timers, USB, and SDHCI.

## Architecture & Data Flow

- In `i2c-npcm7xx.c`, Bank 1 is default; any function calling `npcm_i2c_select_bank(bus, I2C_BANK_0)` must restore `I2C_BANK_1` before returning. Because `npcm_i2c_disable()` clears `NPCM_I2CCTL1` and own-slave-address registers, `npcm_i2c_reset()` must save `NPCM_I2CCTL1` beforehand, restore it (masking `~NPCM_I2CCTL1_RWS`) after `npcm_i2c_enable()`, and re-enable `bus->slave->addr` if `bus->slave` is set. [F60, F62]
- On a NACK with `bus->fifo_use`, `npcm_i2c_irq_handle_nack()` and `npcm_i2c_slave_wr_buf_sync()` must read untransmitted bytes from `NPCM_I2CTXF_STS` and rewind `bus->wr_ind` or `bus->slv_wr_ind`/`slv_wr_size` before flushing with `NPCM_I2CFIF_CTS_CLR_FIFO`. `npcm_i2c_data.fifo_size` must be a power of two `<= MAX_I2C_HW_FIFO_SIZE` (32), and `bus->slv_wr_ind` must stay a signed `int`. [F63, F75]
- For SMBus block reads (`bus->read_block_use`), `npcm_i2c_set_fifo()` must override `rxf_ctl` to 1 without `rxf_ctl_last_pec` on byte 0 (`bus->rd_ind == 0`) after checking `nread <= bus->data->fifo_size`, and `npcm_i2c_irq_master_handler_read()` must clamp the wire length byte to `[1, I2C_SMBUS_BLOCK_MAX]`. In `npcm_i2c_master_fifo_read()`, when `rcount <= fifo_bytes`, `npcm_i2c_eob_int(bus, true)` and `npcm_i2c_master_stop(bus)` must precede `npcm_i2c_read_fifo()`. [F76, F86, F87]
- In `npcm_i2c_master_xfer()`, set `bus->dest_addr = i2c_8bit_addr_from_msg(msg0) & ~I2C_M_RD` before `i2c_recover_bus(adap)`. In `npcm_i2c_int_master_handler()`, `NMATCH`, `NEGACK`, `BER`, and `EO_BUSY` must be checked first and return 0, whereas `NPCM_I2CST_STASTR` must be handled before `NPCM_I2CST_SDAST` without returning early so both `npcm_i2c_irq_handle_stall_after_start()` and `npcm_i2c_irq_handle_sda()` can run in one IRQ. [F65, F91]
- In `gpio-npcm-sgpio.c`, `struct gpio_chip chip` must stay at offset 0 of `struct npcm_sgpio`. Outputs are `[0, nout_sgpio)` and inputs `[nout_sgpio, nout_sgpio + nin_sgpio)`, so input callbacks must subtract `gpio->nout_sgpio` before indexing `npcm_sgpio_banks[]` or `gpio->int_type[]` and add it when dispatching IRQs. `npcm_sgpio_set_type()` must cache the trigger in `gpio->int_type[offset]` for `npcm_sgpio_irq_set_mask()` to restore on unmask. [F54, F72, F116]
- In `pinctrl-npcm7xx.c` and `pinctrl-npcm8xx.c`, `npcm7xx_pinmux_set_mux()` and `npcm8xx_pinmux_set_mux()` pass the group selector directly as `mode` to `npcm7xx_setfunc()`/`npcm8xx_setfunc()`, so `fn_*` enums and `npcm7xx_groups[]`/`npcm8xx_pingroups[]` must stay 1:1 aligned via `NPCM7XX_GRPS`/`NPCM8XX_GRPS` with `fn_none` and `fn_gpio` at the end. When `mode` matches `fn_gpio` or any `cfg->fnN`, every non-zero `cfg->regN` for that pin must be updated (setting matching `BIT(cfg->bitN)` and clearing the rest). [F79, F99]
- In `npcm7xx_gpio_of()` and `npcm8xx_gpio_fw()`, `gpio_generic_chip_init()` must run before saving `chip.gc.direction_input`, `direction_output`, and `request` into `pctrl->gpio_bank[id]` and overriding them with `npcmgpio_*`. In `npcm7xx_config_set_one()` and `npcm8xx_config_set_one()`, setting `PIN_CONFIG_INPUT_ENABLE` or `PIN_CONFIG_LEVEL` must update both `GP_N_OEC`/`GP_N_OES` and `GP_N_IEM` (via `bank->direction_input()`/`direction_output()`), and setting pull bias must clear the opposite pull register (`GP_N_PU` vs `GP_N_PD`). [F58, F59]
- In `spi-npcm-fiu.c`, `npcm_fiu_set_drd()` and `npcm_fiu_direct_read()` must keep `fiu->drd_op` synchronized with `NPCM_FIU_DRD_CFG` in non-SPIX mode, and `npcm_fiu_exec_op()` must update `fiu->clkrate = chip->clkrate` only after `clk_set_rate()` succeeds. In `spi-npcm-pspi.c`, any path calling `npcm_pspi_reset_hw()` must set `priv->is_save_param = false`. [F51, F52, F53]
- In `clk-npcm8xx.c`, `npcm8xx_pre_divs[]`, `npcm8xx_divs[]`, and `*_mux_parents[]` reference `npcm8xx_pll_clks[]`, `npcm8xx_muxes[]`, and `npcm8xx_pre_divs[]` by hardcoded indices and rely on `npcm8xx_clk_probe()` copying `*hw` into each parent's static `.hw` field before registering children. `npcm8xx_clk_pll_ops` must only be registered on a `struct clk_hw` embedded in `struct npcm8xx_clk_pll` (via `npcm8xx_clk_register_pll()`), not directly on `&pll_clk->hw`. [F66, F117]
- In `npcm750-pwm-fan.c`, PWM loops and locks must be bounded by `data->pwm_modules` and channel visibility by `data->info->pwm_max_channel` (not `NPCM7XX_PWM_MAX_MODULES`/`MAX_CHN_NUM`). `npcm7xx_pwm_init()` must clamp `prescale_val >= MIN_PRESCALE1` (2) before `prescale_val--`. `npcm7xx_check_cmp()` must check `flag & flag_timeout` before `flag & flag_cap`, and `npcm7xx_read_fan()` must verify `fan_cnt > 0` and `fan_pls_per_rev > 0` before dividing. [F94, F109, F110, F127]
- In `rtc-nct3018y.c`, time registers (`SC=0x00`, `MN=0x02`, `HR=0x04`) are interleaved with alarm registers (`SCA=0x01`, `MNA=0x03`, `HRA=0x05`), so block reads must index `buf[0]`, `buf[2]`, `buf[4]` and `nct3018y_rtc_set_time()` must write `SC`, `MN`, `HR` individually. On `NCT3018Y_REG_PART_NCT3018Y`, if `NCT3018Y_BIT_TWO` is clear in `NCT3018Y_REG_CTRL`, `nct3018y_rtc_set_time()` must set it before writing time registers and clear it afterward. [F81, F102]
- Lookup tables must keep strict descending order: `smb_timing_100khz[]`/`400khz[]`/`1000khz[]` in `i2c-npcm7xx.c` by `core_clk`; `npcm750_SFT_CLK`/`npcm845_SFT_CLK` in `gpio-npcm-sgpio.c` by clock divider; and `clkout_rates[]` (`{ 32768, 1024, 32, 1 }`) in `rtc-nct3018y.c` by frequency matching `NCT3018Y_REG_CLKO_F_MASK`. [F77, F97, F103]
- In `npcm_peci_xfer()`, when `req->tx.len > 0`, `req->tx.buf[0]` goes to `NPCM_PECI_CMD` and `req->tx.buf[i + 1]` to `NPCM_PECI_DAT_INOUT(i)` (`i < req->tx.len - 1`), while RX reads start at `NPCM_PECI_DAT_INOUT(0)`. After completion, check `priv->status != NPCM_PECI_CTRL_DONE` (not `!(priv->status & NPCM_PECI_CTRL_DONE)`) because `npcm_peci_irq_handler()` ORs error bits with `NPCM_PECI_CTRL_DONE`. [F82, F105]
- In `npcm-rng.c`, `npcm_rng_init()` and `npcm_rng_cleanup()` must OR `priv->clkp` into `NPCM_RNGCS_REG` writes. In `npcm7xx_kcs_probe()`, 1-based `kcs_chan` must be validated in `[1, KCS_CHANNEL_MAX]` and decremented by 1 to index `npcm7xx_kcs_reg_tbl[]`. In `reset-npcm.c`, `npcm_reset_xlate()` must validate `args[0]` in `rc->info->ipsrst[]` and `args[1] < NPCM_RC_RESETS_PER_REG`. [F69, F71, F78]

## Synchronization

- In `i2c-npcm7xx.c`, `npcm_i2c_probe_bus()` must init `bus->lock` and `bus->cmd_complete` and call `npcm_i2c_int_enable(bus, false)` before `devm_request_irq()`. In `npcm_i2c_callback()`, all updates to `bus->cmd_err`, `msgs[...].len`, `bus->operation`, and `bus->master_or_slave` must finish before `complete(&bus->cmd_complete)`. `npcm_i2c_master_stop()` and `npcm_i2c_irq_handle_nack()` run in hardirq context and must use atomic `udelay()`/`readx_poll_timeout_atomic()`. [F18, F21, F143]
- In `i2c-npcm7xx.c`, `npcm_i2c_unreg_slave()` must disable slave IRQs, remove the slave address, and set `bus->slave = NULL` under `bus->lock`. In `npcm_i2c_master_xfer()`, each bus-busy poll iteration must hold `bus->lock` when checking `NPCM_I2CCST_BB` and clearing `NPCM_I2CADDR_SAEN` in `NPCM_I2CADDR1` (restoring `(bus->slave->addr & 0x7F) | NPCM_I2CADDR_SAEN` after transfer). Runtime slave helpers must only access Bank-1 `NPCM_I2CADDR1`/`2` and never select `I2C_BANK_0` unlocked. [F7, F19, F20, F64]
- In `peci-npcm.c`, `npcm_peci_xfer()` must hold `priv->lock` across `reinit_completion(&priv->xfer_complete)`, `priv->status = 0`, and setting `NPCM_PECI_CTRL_START_BUSY`, drop `spin_unlock_irq(&priv->lock)` before `wait_for_completion_interruptible_timeout()`, and re-acquire and unlock `priv->lock` around checking `priv->status` and reading RX data (including on error). [F11, F22]
- In `gpio-npcm-sgpio.c`, `gpio->lock` must be a `raw_spinlock_t` acquired with `raw_spin_lock_irqsave()`, and `npcm_sgpio_irq_set_mask()`, `npcm_sgpio_set_type()`, and `npcm_sgpio_irq_ack()` must hold it while writing `EVENT_STS` or toggling `npcm_sgpio_setup_enable(gpio, false/true)` around `EVENT_CFG` updates (including in `npcm_sgpio_setup_irqs()`). [F26, F126, F140]
- In `npcm750-pwm-fan.c`, `npcm7xx_pwm_config_set()` must unlock `data->pwm_lock[module]` on all paths, and `npcm7xx_fan_start_capture()` and `npcm7xx_fan_isr()` must hold `data->fan_lock[fan]` via `spin_lock_irqsave()` when updating `fan_st_flg`, `NPCM7XX_FAN_REG_TIEN`, or `TCKC`. In `npcm_adc.c`, `npcm_adc_read_raw()` must hold `info->lock` across `npcm_adc_read()`. In `reset-npcm.c`, `npcm_rc_setclear_reset()` must hold `rc->lock` via `spin_lock_irqsave()`. [F14, F24, F27, F29]
- In `rtc-nct3018y.c`, `nct3018y_irq` must use `devm_request_threaded_irq()` with `IRQF_ONESHOT` and `nct3018y_clkout_ops` must use sleepable `.prepare`/`.unprepare`/`.is_prepared` (never atomic `.enable`/`.disable`/`.is_enabled`) because they do sleeping SMBus I/O. Reboot handlers `npcm_rc_restart()` and `npcm_wdt_restart()` run in atomic context and must use `mdelay()`/`udelay()`. [F146, F147, F151]

## Object Lifetimes

- In `npcm7xx_clk_init()`, `npcm7xx_init_fail` must pass outer `npcm7xx_clk_data` (not `npcm7xx_clk_data->hws`) to `kfree()`, then call `iounmap(clk_base)` and `of_node_put(clk_np)`. In `reset-npcm.c`, once `auxiliary_device_init()` succeeds in `npcm_clock_adev_alloc()`, `adev->dev.release` owns `struct npcm_clock_adev`, so `auxiliary_device_add()` failure in `npcm8xx_clock_controller_register()` must call `auxiliary_device_uninit(adev)` instead of `kfree(rdev)`. [F1, F3]
- In `npcm_pspi_probe()`, `host` from `spi_alloc_host()` only becomes devres-managed when `devm_spi_register_controller()` succeeds, so all probe error paths must call `spi_controller_put(host)`, while `npcm_pspi_remove()` must not. In `npcm_fiu_probe()`, `devm_spi_alloc_host()` must be used. In `npcm7xx_ehci_hcd_drv_probe()` and `remove()`, `hcd` from `usb_create_hcd()` must be freed via `usb_put_hcd(hcd)` on probe error and after `usb_remove_hcd(hcd)`. [F4, F5, F6]
- In `npcm_rng_probe()` and `npcm_rng_remove()`, call `pm_runtime_disable()` and `pm_runtime_set_suspended()` if `devm_hwrng_register()` fails and after `devm_hwrng_unregister()`. In `npcm_rng_read()`, pair `pm_runtime_get_sync()` with `pm_runtime_put_sync_autosuspend()` on all paths; when `!wait`, check `NPCM_RNG_DATA_VALID` with non-blocking `readb()` instead of `readb_poll_timeout()`, and on timeout/empty data return `retval` if `retval > 0 || !wait` (returning `-EIO` only when `retval == 0 && wait`). [F9, F10, F36, F148]
- In `npcm_adc_probe()`, `npcm_adc_remove()`, and `npcm7xx_kcs_remove()`, unregister the external interface (`iio_device_unregister()` or `kcs_bmc_remove_device()`) before disabling hardware enable bits, regulators, or clocks. `info->vref` from `devm_regulator_get_optional()` is `ERR_PTR(-ENODEV)` when unused, so guard all `info->vref` calls with `!IS_ERR(info->vref)`. [F17, F28, F37]
- In `npcm_i2c_probe_bus()`, initialize `bus->apb_clk` before `__npcm_i2c_init()`, and call `npcm_i2c_init_debugfs()` only after `i2c_add_numbered_adapter()`. In `npcm7xx_pinctrl_probe()` and `npcm8xx_pinctrl_probe()`, `devm_pinctrl_register()` must precede `npcm*xx_gpio_register()`. In `npcm_wdt_probe()`, if `npcm_is_running()` is true, call `npcm_wdt_start()` and set `WDOG_HW_RUNNING` before `devm_watchdog_register_device()`. [F8, F12, F136]

## API Contracts

- In `npcm7xx_config_set_one()` and `npcm8xx_config_set_one()`, `npcm_gpio_set()`, `npcm_gpio_clr()`, and `OEC`/`OES` writes take `BIT(pin % bank->chip.gc.ngpio)`, whereas `bank->direction_input()`, `direction_output()`, and `npcm_set_debounce()` / `debounce_timing_setting()` take unshifted `pin % bank->chip.gc.ngpio` (scaling `PIN_CONFIG_INPUT_DEBOUNCE` by `1000` into ns). [F46, F47]
- `npcm_fiu_uma_read()` and `npcm_fiu_uma_write()` stage `<= 16` bytes (`CHUNK_SIZE`) in `u32 data_reg[4] = {0}` looped to `DIV_ROUND_UP(data_size, 4)`. In `npcm_fiu_manualwrite()`, calls to `npcm_fiu_uma_write()` with `is_address_size = false` must pass `data[0]` as `cmd` and `&data[1]` with length `CHUNK_SIZE - 1` (or `remain_data - 1`). [F42, F73, F96, F107]
- In `rtc-nct3018y.c`, `nct3018y_clkout_determine_rate()` must always set `req->rate` to a rate from `clkout_rates[]` (never `0`); `nct3018y_rtc_read_time()`/`set_time()` must offset `tm_mon` by `-1`/`+1` and `tm_year` by `+100`/`-100`; and `nct3018y_probe()` must clear `RTC_FEATURE_UPDATE_INTERRUPT` and `RTC_FEATURE_ALARM` when `client->irq <= 0`. In `npcm_i2c_slave_get_wr_buf()`, emit `I2C_SLAVE_READ_REQUESTED` only on the first byte when `bus->state == I2C_SLAVE_MATCH` (then setting `I2C_OPER_STARTED`), and `I2C_SLAVE_READ_PROCESSED` thereafter. [F152, F153, F154, F155]

## Error Handling

- In `npcm7xx_gpio_of()` and `npcm8xx_gpio_fw()`, initialize `ret = -ENXIO` before `for_each_gpiochip_node()`; check `fwnode_iomap()` and `devm_kasprintf()` for `NULL` (not `IS_ERR()`); and in `npcm8xx_gpio_fw()`, store `fwnode_irq_get()` in a signed `int` and check `ret < 0`. In `rtc-nct3018y.c`, store every `i2c_smbus_read_byte_data()` result in a signed `int` and check `< 0` before masking. [F31, F32, F33, F35, F43]
- In `npcm_i2c_probe_bus()` and `npcm_usb_reset()`, if `syscon_regmap_lookup_by_phandle()` fails, fall back to `syscon_regmap_lookup_by_compatible("nuvoton,npcm750-gcr")`, and return `PTR_ERR()` (never `IS_ERR()`). In `npcm_i2c_master_xfer()`, if `rxf_ctl_last_pec` stays set in `NPCM_I2CRXF_CTL` after a non-BER error, call `npcm_i2c_reset(bus)`, and always disable `npcm_i2c_stall_after_start()` and `npcm_i2c_eob_int()` after every transfer. [F34, F40, F123]

## External Contracts

- In `npcm_usb_reset_npcm7xx()` and `npcm_usb_reset_npcm8xx()`, assert IPSRST bits for PHYs and controllers (matching each `ipsrstN_bits` to `iprstN` and `NPCM_IPSRSTN`), clear `NPCM_USBXPHYCTL_RS` in GCR, deassert PHY resets (`udelay(50)` on NPCM7xx), set `NPCM_USBXPHYCTL_RS`, and then deassert controller resets. When `fiu->spix_mode` is true in `spi-npcm-fiu.c`, UMA ops return `-EOPNOTSUPP` and direct read/write must use byte-wise `ioread8()`/`iowrite8()`. [F83, F129, F131]

## Known Pitfalls

- In `pinctrl-npcm7xx.c` and `pinctrl-npcm8xx.c`, `GP_N_OES`, `OEC`, `EVENS`, `EVENC`, and `EVST` are write-1-to-set/clear registers written directly with `BIT(gpio)`, whereas RW registers (`PU`, `PD`, `OTYP`, `DBNC`, `EVTYP`, `EVBE`, `POL`, `OSRC`, `ODSC`) must use `npcm_gpio_set()`/`npcm_gpio_clr()`. In `npcm8xx_gpio_request_enable()`, pins 35, 36, and 183–189 must set `mode = pincfg[pin[0]].fn0` instead of `fn_gpio`. [F30, F100, F134]
- In `i2c-npcm7xx.c` and `kcs_bmc_npcm7xx.c`, all 8-bit registers must use 8-bit accessors, never 32-bit MMIO. In `i2c-npcm7xx.c`, any RMW of `NPCM_I2CCTL1` not triggering a bus action must mask `~NPCM_I2CCTL1_RWS`; in `npcm_i2c_callback()`, `I2C_MASTER_DONE_IND` must fall through to `I2C_BLOCK_BYTES_ERR_IND`; and in `npcm_i2c_master_xfer()`, poll with `time_is_after_jiffies(time_left)` and divide `(2 * 9 * USEC_PER_SEC)` by `bus->bus_freq` before multiplying by `(2 + nread + nwrite)`. [F61, F85, F113, F125]
- In `spi-npcm-pspi.c`, 16-bit transfers in `npcm_pspi_send()`/`recv()` must pack/unpack `NPCM_PSPI_DATA` in big-endian byte order. In `npcm7xx_clk_pll_recalc_rate()` and `npcm8xx_clk_pll_recalc_rate()`, cast `parent_rate` to `u64` before `* fbdv` and divide with `do_div()`. In `npcm_sgpio_irq_handler()` and `npcmgpio_irq_handler()`, status words passed to `for_each_set_bit()` must be `unsigned long`. [F74, F106, F119]
