# ACPI

This unit provides core ACPI boot-time table parsing and initrd upgrades (`tables.c`), AML evaluation and device lookup helpers (`utils.c`), thermal zone management (`thermal.c`, `thermal_lib.c`), wakeup handlers (`wakeup.c`), backlight detection (`video_detect.c`), and the tiny power button driver (`tiny-power-button.c`). It also covers x86 platform support (Intel LPSS PM domain/clocks, s2idle LPS0/Modern Standby `_DSM`, CMOS RTC OpRegion, Apple `_DSM` properties, and device quirks) alongside PCI ACPI integration (`pci-acpi.c`), ACPI PCI Hotplug (`acpiphp`), and `pnpacpi` resource parsing/encoding.

## Architecture & Data Flow

- In `acpiphp_glue.c`, an `acpiphp_bridge` on a root bus (`pci_is_root_bus(bridge->pci_bus)`) has `bridge->pci_dev == NULL`, `slot->bus->self == NULL`, `bridge->context == NULL`, and stores `struct acpiphp_root_context` in `adev->hp`; check whether the bus is a root bus or pointers are non-`NULL` before dereferencing or calling `to_acpiphp_context(adev->hp)`. Any walk of `bus->devices` that may remove devices (`disable_slot()`, `trim_stale_devices()`, `acpiphp_check_bridge()`, `acpiphp_sanitize_bus()`) must use `list_for_each_entry_safe_reverse()`. [F41, F98]
- In `drivers/acpi/thermal.c`, `THERMAL_TRIP_CRITICAL` and `THERMAL_TRIP_HOT` entries in `trip_table` have `trip->priv == NULL`, whereas passive/active trips set `trip->priv` to their `struct acpi_thermal_trip`; check `trip->priv` for non-`NULL` before dereferencing, and check `trip->type != THERMAL_TRIP_PASSIVE` before calling `active_trip_index()`, which downcasts `acpi_trip` to `struct acpi_thermal_active`. [F42, F119]
- In `acpi_thermal_get_trip_points()`, `tz->trips.active[0..ACPI_THERMAL_MAX_ACTIVE-1]` are initialized contiguously until the first `acpi_thermal_init_trip()` failure and all subsequent entries must have `temp_dk = THERMAL_TEMP_INVALID` because `acpi_thermal_add()` and `acpi_thermal_resume()` stop at the first invalid entry; conversely, `acpi_thermal_free_thermal_zone()` must iterate across all `ACPI_THERMAL_MAX_ACTIVE` entries unconditionally without breaking on `!acpi_thermal_trip_valid(acpi_trip)`. [F74, F103]
- In `acpi_thermal_trips_update()`, update both `acpi_trip->temp_dk` (`THERMAL_TEMP_INVALID` if `update_trip_devices()` fails) and `trip->temperature` via `thermal_zone_set_trip_temp()` inside `thermal_zone_for_each_trip()` before queuing `tz->thermal_check_work`. When `trip == trip_table` (0 valid trips), `acpi_thermal_add()` and `acpi_thermal_register_thermal_zone()` must still register via `thermal_tripless_zone_device_register()`. [F59, F94]
- `pnpacpi_build_resource_template()` sets `buffer->length = sizeof(struct acpi_resource) * (res_cnt + 1) + 1` while allocating `buffer->length - 1` bytes, which `pnpacpi_encode_resources()` relies on (`res_cnt = (buffer->length - 1) / sizeof(struct acpi_resource) - 1`) while incrementing per-category counters (`irq`, `dma`, `port`, `mem`) rather than indexing `pnp_get_resource()` by `i`. `pnpacpi_allocated_resource()` must preserve `else if (r->flags & IORESOURCE_DISABLED)` after `acpi_dev_resource_interrupt()` and clear `PNP_WRITE` on multi-IRQ `_CRS` descriptors. [F48, F69, F95, F104]
- In `acpi_table_initrd_override()` and `acpi_table_initrd_scan()`, cache `table_length = table->length` before `acpi_os_unmap_memory()`, use `goto next_table` on every skip path so `table_offset += table_length` and `table_index++` advance together, mark consumed tables via `test_and_set_bit(table_index, acpi_initrd_installed)`, and skip `ACPI_SIG_RSDT`/`ACPI_SIG_XSDT` in `acpi_table_initrd_scan()`. [F70, F100, F166]
- In `drivers/acpi/x86/lpss.c`, verify `pdata->mmio_size >= dev_desc->prv_offset + LPSS_CLK_SIZE` before accessing clock registers and `>= prv_offset + LPSS_LTR_SIZE` before exposing LTR sysfs attributes or `acpi_lpss_set_ltr`. For `LPSS_SAVE_CTX_ONCE` devices, call `acpi_lpss_save_ctx()` only in `acpi_lpss_activate()` (never `acpi_lpss_suspend()`), while `acpi_lpss_restore_ctx()` runs in `acpi_lpss_resume()` for both `LPSS_SAVE_CTX` and `LPSS_SAVE_CTX_ONCE`. `lpss_iosf_enter_d3_state()` powers down DMA only when `((~(d3_sts_0 | func_dis)) & pmc_atom_d3_mask) == 0`. [F81, F91, F134]
- In `acpi_extract_package()`, the sizing loop over `format_count` must accumulate `size_required` and `tail_offset` by the exact amounts the extraction loop advances `head` and `tail`. Similarly, in `acpi_extract_apple_properties()`, `newsize` and `free_space` (starting at `&newprops[1 + 3 * numvalid]`) must advance identically (`string.length + 1` for keys/strings, `buffer.length` for buffers, `0` for integers). [F80, F102]

## Synchronization

- In `drivers/pci/hotplug/acpiphp_glue.c`, call `acpiphp_init_context()`, `acpiphp_get_context()`, and `acpiphp_put_context()` only under `acpi_hp_context_lock`. In `acpiphp_grab_context()`, check `context->func.parent->is_going_away` and call `get_bridge(context->func.parent)` before dropping `acpi_hp_context_lock`. Release inner lock `acpi_hp_context_lock` before calling `put_bridge()` (outside `free_bridge()`), `pci_lock_rescan_remove()`, or `bridge_mutex`; in `acpiphp_disable_slot()`, acquire `acpi_scan_lock` outer to `pci_lock_rescan_remove()`. [F30, F31, F158, F159]
- In `acpi_thermal_add()`, initialize `tz->thermal_zone`, `tz->thermal_check_count` (to 3), `tz->thermal_check_lock`, and `tz->thermal_check_work` before `acpi_dev_install_notify_handler()`. In `acpi_thermal_check_fn()`, decrement `tz->thermal_check_count` via `refcount_dec_not_one()` before acquiring `tz->thermal_check_lock` and increment via `refcount_inc()` while still holding `tz->thermal_check_lock`. On teardown, call `acpi_dev_remove_notify_handler()` before `flush_workqueue(acpi_thermal_pm_queue)` before unregistering or freeing `tz`. [F18, F21, F128]
- In `drivers/acpi/x86/lpss.c`, hold `lpss_iosf_mutex` across reading `PMC_D3_STS_0`, checking/updating `lpss_iosf_d3_entered`, and calling `iosf_mbi_modify()`. In `lpss_reg_read()`, hold `dev->power.lock` via `spin_lock_irqsave()` while checking `pm_runtime_suspended(dev)` (returning `-EAGAIN` if suspended) and reading MMIO. When `pdata->dev_desc->resume_from_noirq` is true, `acpi_lpss_suspend_late()` and `acpi_lpss_resume_early()` (and poweroff/restore counterparts) must return 0 so the `noirq` callbacks execute the transition instead. [F27, F156, F172]
- Hold `acpi_wakeup_handler_mutex` when modifying `acpi_wakeup_handler_head`, and hold `acpi_device_lock` in `acpi_wakeup_device_init()` but never in `acpi_enable_wakeup_devices()` or `acpi_disable_wakeup_devices()`. Hold `pci_acpi_companion_lookup_sem` via `down_read()` across checking and calling `pci_acpi_find_companion_hook(pci_dev)`, and `down_write()` when setting/clearing it. Hold `lock_system_sleep()` when mutating `lps0_s2idle_devops_head`, and `spin_lock_irq(&rtc_lock)` in `acpi_cmos_rtc_space_handler()` after verifying `address <= 0xff`. [F23, F34, F132, F153, F157]

## Object Lifetimes

- `acpi_evaluate_dsm()` and `acpi_evaluate_dsm_typed()` return a heap-allocated `union acpi_object *` that the caller must free with `ACPI_FREE()` on all return paths (including in `pci_acpi_preserve_config()`, `acpi_pci_add_bus()`, `pci_acpi_optimize_delay()`, `acpi_check_dsm()`, and `s2idle.c`). In `s2idle.c`, `lpi_constraints_table` is only populated up to `lpi_constraints_table_size` (iterate via `for_each_lpi_constraint`), and pointers into `out_obj` (`dev_info.name`, `info.name`, `info.package`) must not be saved past `ACPI_FREE(out_obj)`. [F1, F124]
- `acpi_dev_get_first_match_dev()` and `acpi_dev_get_next_match_dev()` return a referenced `struct acpi_device *` requiring `acpi_dev_put()`, while `acpi_dev_get_next_match_dev()` unconditionally calls `acpi_dev_put(adev)` on its input `@adev`; `acpi_lpss_find_device()` returns a referenced `struct device *` requiring `put_device()`. Free results of `acpi_handle_path()`, `ibm_slot_from_id()`, and non-`IS_ERR` `acpi_get_subsystem_id()` with `kfree()`. Never zero `list->count` before `acpi_handle_list_free()` or `acpi_handle_list_replace()`. [F2, F3, F6, F17]
- In `acpiphp_enumerate_slots()`, `bridge` pins `pci_dev_get(bus->self)`, `get_device(&bus->dev)`, and (for non-root buses) `acpiphp_get_context(adev)` and `get_bridge(context->func.parent)`, all released in `free_bridge()`; `free_bridge()` must clear `context->bridge = NULL` under `acpi_hp_context_lock` before `acpiphp_put_context(context)`. Add `bridge` to `bridge_list` under `bridge_mutex` before `acpi_walk_namespace(..., acpiphp_add_context, ...)`, and if `acpi_walk_namespace()` fails, call `cleanup_bridge(bridge)` before `put_bridge(bridge)`. [F10, F11, F12]
- In `pci_acpi_scan_root()`, once `root_ops->release_info = pci_acpi_generic_release_info` is set and `acpi_pci_root_create()` is called, `acpi_pci_root_create()` owns `ri`, `root_ops`, and `ri->cfg` and frees them on error; only free them on errors before `acpi_pci_root_create()`. `pci_acpi_cleanup()` must unwind `pci_acpi_setup()` in reverse order (including `adev->wakeup.flags.valid` and `pci_dev->bridge_d3` guards). `acpi_pci_wakeup()` and `acpi_pci_propagate_wakeup()` must both use reference-counted `acpi_pm_set_device_wakeup()`. [F4, F13, F15]
- `acpi_thermal_unregister_thermal_zone()` must unwind registration in reverse (`thermal_zone_device_disable()`, `acpi_thermal_zone_sysfs_remove()`, `thermal_zone_device_unregister()`, `tz->thermal_zone = NULL`) before `acpi_thermal_free_thermal_zone()`. In `acpi_lpss_create_device()`, always call `acpi_dev_free_resource_list(&resource_list)` and clear `adev->driver_data = NULL` before `kfree(pdata)` on error. In `acpi_table_upgrade()`, pair `memblock_phys_alloc_range()` with `arch_reserve_mem_area()` and `kmemleak_ignore_phys()`, and unmap each `early_memremap()` chunk. [F7, F14, F16, F149]

## API Contracts

- In `thermal.c` and `thermal_lib.c`, `tz->temp_dk`, `acpi_thermal_trip.temp_dk`, and `acpi_*_trip_temp()` are in deci-Kelvin, `act`/`crt`/`psv` are in Celsius, and thermal core APIs require millidegrees Celsius via `acpi_thermal_temp()` (returning `THERMAL_TEMP_INVALID` if `<= 0` mC) or `thermal_acpi_*_trip_temp()`. `acpi_trip_temp()` must check 64-bit `temp` is in `[TEMP_MIN_DECIK, TEMP_MAX_DECIK]` before narrowing to `int`. Multiply `_TZP` (`tz->polling_frequency`, `tzp`) and `_TSP` (deci-seconds) by `100` for ms (unlike `_TFP`, already in ms). [F51, F52, F73, F114, F167]
- `acpi_check_dsm()` takes `funcs` as a non-zero 64-bit bitmask (`BIT(func)`), whereas `acpi_evaluate_dsm()` takes a function index (`u64`); `acpi_check_dsm()` requires function 0's mask to satisfy `(mask & 0x1)` and `(mask & funcs) == funcs`. Callers of `acpi_dev_present()`, `acpi_dev_found()`, `acpi_dev_get_first_match_dev()`, and `acpi_dev_get_next_match_dev()` must pass `-1` (not `0`) for `hrv` to skip `_HRV`, and must not call them from `subsys_initcall()` or earlier (before `acpi_bus_scan()`; use `acpi_get_devices()`). [F50, F54, F89, F163]
- Callers of `acpi_extract_package()` must include the trailing NUL byte in `format->length` (`sizeof("NN")`, not `strlen()`), and when `buffer->length != ACPI_ALLOCATE_BUFFER`, `buffer->length` must equal `size_required` exactly. In `acpi_table_initrd_override()` and `acpi_os_table_override()`, zero `*length`, `*address`, and `*new_table` before returning `AE_OK` on non-override paths; `acpi_table_upgrade()` must check `security_locked_down(LOCKDOWN_ACPI_TABLES)` before allocating/copying initrd tables. [F47, F76, F77, F165]
- In `acpi_lpss_activate()` and `acpi_lpss_resume()`, call `acpi_lpss_d3_to_d0_delay(pdata)` after `acpi_dev_resume(dev)` before writing LPSS MMIO; call `lpss_iosf_enter_d3_state()` after `acpi_dev_suspend()` (at `ACPI_STATE_S0`) and `lpss_iosf_exit_d3_state()` before `acpi_dev_resume()`. In `acpi_pci_choose_state()`, check both `pdev->no_d3cold` and `!pdev->d3cold_allowed`. In `acpiphp_glue.c`, bracket bus scans/trims with `pm_runtime_get_sync()`/`pm_runtime_put()`, and skip `acpiphp_register_hotplug_slot()` when `pdev && hotplug_is_native(pdev)`. [F56, F135, F136, F143, F175]

## Error Handling

- In `acpi_evaluate_reference()`, error paths before `list->handles` allocation must not call `kfree(list->handles)`, whereas post-allocation errors (`goto err_free`) must free `list->handles`, set `list->handles = NULL`, and zero `list->count`. Check `acpi_get_subsystem_id()` with `IS_ERR()` (never returns `NULL`). Store `acpi_match_platform_list()` in a signed `int` and check `>= 0` (`-ENODEV` on failure). Keep `lps0_dsm_func_mask` and `lps0_dsm_func_mask_microsoft` (`validate_dsm()`) as signed `int` and check `> 0` before `acpi_sleep_run_lps0_dsm()`. [F5, F36, F37, F38]
- Check `dev->parent` for non-`NULL` before `ACPI_COMPANION(dev->parent)` in `acpi_pci_find_companion()`, and `cfg->parent` before `to_acpi_device(cfg->parent)` in `pcibios_root_bridge_prepare()`. In `acpiphp_add_context()`, reset `slot->slot = NULL` if `acpiphp_register_hotplug_slot()` fails. In `acpi_lpss_create_device()`, return `0` via `out_free` on `!pdata->mmio_base` (clearing `platform_id = 0`) or clock failure, and `1` on success; in `register_device_clock()`, set `prv_base` to `LPSS_CLK_DIVIDER_DEF_MASK` if `readl(prv_base) == 0` for `LPSS_CLK_DIVIDER`. [F39, F40, F43, F45, F111]

## External Contracts

- In `s2idle.c`, `acpi_s2idle_prepare_late()` must run `ACPI_LPS0_MS_ENTRY` (before `ACPI_LPS0_ENTRY`) and `acpi_s2idle_restore_early()` must run `ACPI_LPS0_MS_EXIT` (after `ACPI_LPS0_EXIT`); on non-AMD platforms when both masks are positive, do not clear overlapping bits. In `acpi_pci_set_power_state()`, call `acpi_pci_config_space_access(dev, false)` before `acpi_device_set_power()` for `PCI_D3cold` and `true` after `acpi_device_set_power()` for `PCI_D0`. In `pci_acpi_optimize_delay()`, divide `_DSM` microsecond durations by `1000` for `d3cold_delay`/`d3hot_delay`. [F49, F53, F67, F138]

## Known Pitfalls

- In `acpi_pci_bridge_d3()`, check hotplug capability of `@dev` via cached `dev->is_pciehp` rather than config space, and evaluate fallback wakeup-capability, `_S0W` (when `rpadev != adev`), and `"HotPlugSupportInD3"` property checks on the Root Port's companion (`rpadev`) rather than `adev`. In `pci_set_acpi_fwnode()`, check `!dev_fwnode(&dev->dev)` rather than `!ACPI_COMPANION(&dev->dev)` before `ACPI_COMPANION_SET()`. In `acpi_pci_find_companion()`, reject child devices where `adev->pnp.type.platform_id != 0`, `addr == 0`, and `pci_is_root_bus(pci_dev->bus)`. [F57, F96, F107, F144]
- In `include/acpi/acexcep.h`, exception class macros must test `(((status) & AE_CODE_MASK) == code)` rather than bitwise AND. `acpi_match_device_ids()` returns `0` on match and negative errno on mismatch. Pass instance `2` (not `1`) to `acpi_get_table(ACPI_SIG_MADT, ...)` for the second MADT. In `lps0_device_attach()`, check `if (dev_id->id[0])` rather than `if (dev_id)` after iterating `amd_hid_ids`. In `lpi_device_get_constraints_amd()` and `lpi_device_get_constraints()`, finish the inner loop before validating fields and incrementing `lpi_constraints_table_size`. [F72, F87, F88, F97, F99]
- In `acpi_check_dsm()`, cast `obj->buffer.pointer[i]` to `u64` before shifting by `(i * 8)` and bound `i < 8` in addition to `i < obj->buffer.length`. In `acpi_cmos_rtc_space_handler()`, use `DIV_ROUND_UP(bits, 8)` for byte count. In `byt_i2c_setup()`, verify `uid != 0` before `BIT_LPSS2_F1_I2C1 << (uid - 1)`. In `acpi_lpss_set_ltr()`, return early on negative `s32 val` and clamp/shift `val > LPSS_LTR_MAX_VAL` by `LPSS_LTR_SNOOP_LAT_SHIFT` before `ltr_val |= val`. Never add multi-function AudioDSP `_HID`s (e.g. `"INT3438"`) to `acpi_lpss_device_ids[]`. [F108, F109, F110, F112, F113, F133]
