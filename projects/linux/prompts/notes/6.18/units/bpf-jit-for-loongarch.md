# BPF JIT for LOONGARCH

This unit implements the eBPF Just-In-Time (JIT) compiler and BPF trampoline generator for 64-bit LoongArch. It translates eBPF bytecode into native LoongArch instructions across sizing and emission passes, handles tail calls, subprograms, atomic operations, and BTF exception table fixups, and provides text poking and BPF trampoline preparation for `fentry`, `fexit`, `modify_return`, and `struct_ops` hooks.

## Architecture & Data Flow

- Across the sizing pass (`ctx->image == NULL`), image emission pass, and subprogram `extra_pass`, `build_prologue()`, `build_body()`, `build_insn()`, and `build_epilogue()` must emit the exact same instruction count per BPF instruction so `ctx->offset[]`, `ctx->epilogue_offset`, and `prog_size` stay synchronized. Broken by: conditional emission without a matching `nop` or fixed-length sequence when flags or operands change between passes. [F33]
- `ctx.offset` must be allocated with `prog->len + 1` `u32` entries in `bpf_int_jit_compile()`. Only when `ctx->image == NULL` may `build_body()` write `ctx->offset[i] = ctx->idx` (the starting native instruction index of each BPF instruction `i`, including the second slot when `build_insn()` returns `> 0`, plus the post-body index at `ctx->offset[prog->len]`). [F22, F46]
- During emission and subprog `extra_pass` (which skips pass 1), `bpf2la_offset()` and `emit_bpf_tail_call()` (`tc_ninsn`) must derive branch offsets from `ctx->offset[]` in 4-byte instruction-index units rather than static variables, scaling `ctx.offset[]` in-place by `LOONGARCH_INSN_SIZE` for `i <= prog->len` only immediately before `bpf_prog_fill_jited_linfo(prog, ctx.offset + 1)`. [F35, F77]
- Because `ctx->image` is `NULL` during the sizing pass in `bpf_int_jit_compile()` and `arch_bpf_trampoline_size()`, instruction emission and branch backpatching (`branch` in `invoke_bpf_prog()` and `branches[i]` in `__arch_prepare_bpf_trampoline()`) must check `ctx->image != NULL` before dereferencing. [F20]
- Before starting the code-emission pass at `skip_init_ctx:` in `bpf_int_jit_compile()`, both `ctx.idx` and `ctx.num_exentries` must be reset to `0` while preserving `ctx.offset`, `ctx.epilogue_offset`, and `ctx.stack_size`. Broken by: adding a per-pass counter to `struct jit_ctx` without resetting it at `skip_init_ctx:`, or zeroing `ctx` after the sizing pass. [F61]
- The entry sequence of `build_prologue()`—`LOONGARCH_LONG_JUMP_NINSNS` (5) NOPs followed in main programs by one `addid REG_TCC, $zero, 0` instruction—must stay synchronized with `LOONGARCH_BPF_FENTRY_NBYTES` in `__arch_prepare_bpf_trampoline()` (skipping 5 NOPs) and the tail-call `jirl` offset `6` in `__build_epilogue()` (skipping 5 NOPs plus TCC init). [F39]
- `build_prologue()`, `prepare_bpf_tail_call_cnt()`, `__build_epilogue()`, `emit_bpf_tail_call()`, and `BPF_PSEUDO_CALL` in `build_insn()` must agree on placing `tcc` at `stack_size - 72` and `tcc_ptr` at `BPF_TAIL_CALL_CNT_PTR_STACK_OFF(stack_size)` (`stack_size - 80`) below the 8 saved GPR slots. Broken by: changing saved registers in `build_prologue()`/`__build_epilogue()` without updating `BPF_TAIL_CALL_CNT_PTR_STACK_OFF` and `load_offset` adjustments. [F50]
- Executable buffers in `bpf_int_jit_compile()` and `arch_prepare_bpf_trampoline()` must be pre-filled with `INSN_BREAK` via `jit_fill_hole()` before code emission so `validate_code()` / `validate_ctx()` rejects any image with unwritten slots or `INSN_BREAK` from `larch_insn_gen_beq()`/`larch_insn_gen_bne()`. [F25]
- `add_exception_handler()` must return `0` when `!ctx->image || !ctx->prog->aux->extable`, and in `build_insn()` must be called immediately after emitting the faulting `BPF_LDX` load because it records the faulting PC as `&ctx->image[ctx->idx - 1]`. Both `add_exception_handler()` and `ex_handler_bpf()` must compute exception table offsets using integer casts (`(unsigned long)&ctx->image[ctx->idx - 1] + LOONGARCH_INSN_SIZE` and `(unsigned long)&ex->fixup - offset`) so byte offsets are not scaled by `sizeof(int)`. [F21, F78]
- `invoke_bpf_mod_ret()` must zero `FP - retval_off` before looping over `tl->links` (because `invoke_bpf_prog()` skips storing `retval_off` if `bpf_trampoline_enter()` returns `0`), and `invoke_bpf_prog()` must store `LOONGARCH_GPR_ZERO` to `-run_ctx_off + cookie_off` when `!l->cookie`. [F24]
- `__arch_prepare_bpf_trampoline()` must save `LOONGARCH_GPR_S1` to `FP - sreg_off` in the prologue and restore it before exit because `invoke_bpf_prog()` uses `LOONGARCH_GPR_S1` to hold the `bpf_trampoline_enter()` start timestamp across the `p->bpf_func` call. [F91]
- In `build_insn()`, native instructions must be followed by `emit_zext_32(ctx, dst, is32)` after `extwb`/`extwh` (`BPF_ALU`/`BPF_ALU64 | BPF_MOV | BPF_X` with `off == 8` or `16`) and after 32-bit `BPF_ALU` shifts (`sllw`, `slliw`, `srlw`, `srliw`, `sraw`, `sraiw`), and by `emit_zext_32(ctx, dst, true)` (unconditionally zeroing the upper 32 bits) after `revb2w` in `BPF_ALU | BPF_END | BPF_FROM_BE` and `BPF_ALU64 | BPF_END | BPF_FROM_LE` with `imm == 32`. [F65, F66, F67]
- In `build_insn()` for `BPF_DIV` and `BPF_MOD`, both operands must be extended to 64 bits before emitting 64-bit `divdu`/`moddu` or `divd`/`modd`: using `emit_zext_32()` when `off == 0` and `emit_sext_32()` (after `move_imm(ctx, t1, imm, false)` for `BPF_K`) when `off != 0`. [F68]
- In `emit_atomic()`, 32-bit (`!isdw`) `BPF_FETCH`, `BPF_XCHG`, and `BPF_CMPXCHG` operations must zero-extend the fetched register via `emit_zext_32(..., true)`, and 32-bit `BPF_CMPXCHG` must also zero-extend both `t2` and `r0` before emitting `bne`. [F70]
- In `move_imm()`, `lu32id` can be skipped for a non-32-bit immediate only when bits [51:31] are all zeros or all ones, so the condition guarding `emit_insn(ctx, lu32id, ...)` must test `imm_51_31 != 0 && imm_51_31 != 0x1fffff` with `&&`. [F54]
- In `build_insn()`, `switch (code)` must explicitly handle every valid BPF opcode emitted by the verifier (including no-ops like `BPF_ST | BPF_NOSPEC`), because `default` logs an error and aborts JIT with `-EINVAL`. [F55]

## Synchronization

- `bpf_arch_text_copy()`, `bpf_arch_text_poke()`, and `bpf_arch_text_invalidate()` must hold `text_mutex` across `larch_insn_text_copy()` and release it before returning (and before `kvfree(inst)` in `bpf_arch_text_invalidate()`), so callers such as `arch_prepare_bpf_trampoline()` must not hold `text_mutex` when invoking them. [F8]
- In `bpf_int_jit_compile()`, instruction emission into `ctx.image`, exception table population in `prog->aux->extable`, `validate_ctx()`, and `flush_icache_range()` must all complete before `bpf_jit_binary_lock_ro(header)` is called on the final pass. Broken by: writing to `ctx.image` or `prog->aux->extable` after `bpf_jit_binary_lock_ro(header)`, or publishing `prog->bpf_func` before `flush_icache_range()` and `bpf_jit_binary_lock_ro(header)` succeed. [F11]

## Object Lifetimes

- In `bpf_int_jit_compile()`, when `bpf_jit_blind_constants()` returns a cloned program (`tmp != prog`), the `out:` path must call `bpf_jit_prog_release_other(prog, prog == orig_prog ? tmp : orig_prog)`. Broken by: returning early after `bpf_jit_blind_constants()` succeeds without jumping to `out:`, or without resetting `prog = orig_prog` on failure before jumping to `out:`/`out_offset:`. [F1]
- When compiling a subprogram on its first pass (`prog->is_func && !extra_pass`), `jit_data->ctx`, `jit_data->image`, and `jit_data->header` must be persisted in `prog->aux->jit_data` without calling `bpf_jit_binary_lock_ro(header)` or freeing `ctx.offset` and `jit_data` until `extra_pass`. Whenever `out_offset:` is reached (after single-pass or `extra_pass` completion, or on any error after allocating `jit_data`), it must `kvfree(ctx.offset)`, `kfree(jit_data)`, and set `prog->aux->jit_data = NULL`. [F2, F3]
- On the `out_free:` error path in `bpf_int_jit_compile()`, after `bpf_jit_binary_free(header)`, `prog->bpf_func` must be set to `NULL` and `prog->jited` and `prog->jited_len` reset to `0` before jumping to `out_offset:`. [F4]
- `arch_prepare_bpf_trampoline()` allocates a temporary writable buffer `image` via `kvmalloc()`, copies validated instructions into caller-owned `ro_image` via `bpf_arch_text_copy()`, and must call `kvfree(image)` at `out:` on both success and failure. [F7]

## API Contracts

- In `__build_epilogue()`, non-tail-call returns (`!is_tail_call`) must 32-bit sign-extend `regmap[BPF_REG_0]` (`LOONGARCH_GPR_A5`) into `LOONGARCH_GPR_A0` using `addiw` while leaving `regmap[BPF_REG_0]` unmodified (the C ABI requires 32-bit return values in `A0` to be sign-extended, whereas BPF callers read 64 bits from `A5`). Correspondingly, in `build_insn()` for `BPF_JMP | BPF_CALL`, `LOONGARCH_GPR_A0` must be copied into `regmap[BPF_REG_0]` only when `insn->src_reg != BPF_PSEUDO_CALL`. [F80, F81]
- In `__arch_prepare_bpf_trampoline()`, when `save_ret` is true and `is_struct_ops` (`flags & BPF_TRAMP_F_INDIRECT`) is set, the return value in `LOONGARCH_GPR_A0` must be derived from `regmap[BPF_REG_0]` via `sign_extend()` using `m->ret_size` and `m->ret_flags & BTF_FMODEL_SIGNED_ARG` rather than reloaded from `FP - retval_off`. In `sign_extend()`, 1-byte and 2-byte unsigned values (`!sign && (size == 1 || size == 2)`) must not be sign-extended, whereas signed 1-byte/2-byte and all 4-byte values (with `addiw`) must be sign-extended to 64 bits. [F72, F82]
- `larch_insn_gen_beq()` and `larch_insn_gen_bne()` take a 4-byte-aligned byte offset (computed in `invoke_bpf_prog()` and `__arch_prepare_bpf_trampoline()` via `(void *)(&ctx->image[ctx->idx]) - (void *)branch`), whereas `cond_jmp_offset()`, `emit_cond_jmp()`, `emit_uncond_jmp()`, and `emit_tailcall_jmp()` take offsets in instructions. [F26]
- Because `bpf2la_offset(bpf_insn, off, ctx)` computes `ctx->offset[bpf_insn + 1 + off] - (ctx->offset[bpf_insn + 1] - 1)`, the PC-relative branch `b jmp_offset` emitted by `emit_cond_jmp()` (including `cond_jmp_offs26()`) or `emit_uncond_jmp()` in `build_insn()` must be the final LoongArch instruction emitted for that `BPF_JMP`/`BPF_JMP32` instruction. [F27]
- For two-slot `BPF_LD | BPF_IMM | BPF_DW` instructions, `build_insn()` must return `1` (while all other valid single-slot instructions return `0`) so `build_body()` increments `i`, records `ctx->offset[i] = ctx->idx` for the second slot during the sizing pass, and skips executing `build_insn()` on the second slot. [F57]
- `__arch_prepare_bpf_trampoline()` returns the positive instruction count `ctx->idx` on success or a negative errno on failure, whereas `arch_bpf_trampoline_size()` and `arch_prepare_bpf_trampoline()` must return a positive byte size (`ret * LOONGARCH_INSN_SIZE` or `size`) or a negative errno. [F16]
- `__arch_prepare_bpf_trampoline()` and `arch_prepare_bpf_trampoline()` must not dereference `struct bpf_tramp_image *im` unless `flags & BPF_TRAMP_F_CALL_ORIG` is set (`bpf_struct_ops` passes `NULL`). When `im` is populated, `im->ip_after_call` and `im->ip_epilogue` must be computed from `ctx->ro_image + ctx->idx` rather than the temporary `ctx->image`, because `bpf_arch_text_poke()` later checks `is_bpf_text_address()`. [F32, F94]
- `bpf_arch_text_poke()` must reject any target `ip` where `is_bpf_text_address((unsigned long)ip)` is false with `-ENOTSUPP`, and must verify `memcmp(ip, old_insns, LOONGARCH_LONG_JUMP_NBYTES)` matches the 5-instruction slot before patching `ip` to `new_insns` under `text_mutex`. [F10]
- For function-entry trampolines (`!(flags & BPF_TRAMP_F_INDIRECT)`), the parent return address is in `LOONGARCH_GPR_RA` and the traced function return address is in `LOONGARCH_GPR_T0`, so `emit_jump_or_nops()` (when `is_call` is true) and `__arch_prepare_bpf_trampoline()` must use `LOONGARCH_GPR_T0` for the traced function link and save/restore both frames. [F85]
- Before calling `orig_call` in `__arch_prepare_bpf_trampoline()`, `orig_call` must be advanced by `LOONGARCH_FENTRY_NBYTES` (8 bytes) when `is_kernel_text((unsigned long)orig_call)` is true or by `LOONGARCH_BPF_FENTRY_NBYTES` (20 bytes) when `is_bpf_text_address((unsigned long)orig_call)` is true to skip patched entry instructions. [F86]
- `add_exception_handler()` must pack the positive byte offset `(long)&ex->fixup - (pc + LOONGARCH_INSN_SIZE)` into `BPF_FIXUP_OFFSET_MASK` and the mapped LoongArch GPR `regmap[insn->dst_reg]` (not the unmapped eBPF register index `insn->dst_reg`) into `BPF_FIXUP_REG_MASK`, matching `ex_handler_bpf()`. [F28]

## Error Handling

- `bpf_arch_text_copy()` returns `ERR_PTR(-EINVAL)` rather than `NULL` when `larch_insn_text_copy()` fails, so callers such as `arch_prepare_bpf_trampoline()` must check `IS_ERR()` and extract the error with `PTR_ERR()`. [F17]
- In `__arch_prepare_bpf_trampoline()`, any failure after `kcalloc()` of `branches` for `fmod_ret->nr_links` must jump to `out` before `ret = ctx->idx` is assigned so `kfree(branches)` runs without overwriting the negative error code in `ret`. [F19]
- Program-dependent branch range overflows in `build_insn()` and `emit_bpf_tail_call()` must log via ratelimited `pr_info_once()` and return an error code (`-E2BIG` or `-1`/`-EINVAL`) without kernel warnings, whereas `WARN_ON_ONCE()` is reserved for internal exception-table invariant violations in `add_exception_handler()` and `validate_ctx()`. [F99]

## External Contracts

- `__arch_prepare_bpf_trampoline()` must return `-ENOTSUPP` when `m->nr_args > LOONGARCH_MAX_REG_ARGS`, when any `m->arg_flags[i]` has `BTF_FMODEL_STRUCT_ARG` set, or when `flags` includes `BPF_TRAMP_F_ORIG_STACK` or `BPF_TRAMP_F_SHARE_IPMODIFY`. [F92]

## Known Pitfalls

- When loading addresses that can differ between JIT passes—such as `func_addr` in `BPF_JMP | BPF_CALL`, `bpf_pseudo_func(insn)` in `BPF_LD | BPF_IMM | BPF_DW`, or `struct bpf_tramp_image *im` in `__arch_prepare_bpf_trampoline()`—use fixed 4-instruction `move_addr()` rather than variable-length `move_imm()`. [F34]
- In `build_insn()`, the second instruction slot (`insn + 1`) must only be dereferenced inside the 16-byte `BPF_LD | BPF_IMM | BPF_DW` case (never hoisted to function entry or read in single-slot cases). When constructing `imm64` there, `(insn + 1)->imm` must be cast to `u64` before shifting left by 32 and `insn->imm` must be cast to `u32` before bitwise ORing so negative `s32` values do not sign-extend into bits [63:32]. [F45, F64]
- In `build_insn()`, 32-bit operations that do not write to `src` (`BPF_ALU | BPF_DIV | BPF_X`, `BPF_ALU | BPF_MOD | BPF_X`) and `BPF_JMP32` comparisons (which do not write to `dst` or `src`) must copy mapped BPF registers into temporary registers (`t1`, `t2`) before applying `emit_sext_32()` (when `is_signed_bpf_cond(BPF_OP(code))` is true in `BPF_JMP32`) or `emit_zext_32()`, rather than modifying mapped registers in place. [F42, F69]
- In `emit_atomic()`, fetch/exchange instructions (`BPF_FETCH`, `BPF_XCHG`) must pass `t3` (holding a copy of `src`) as `rk` when `src` is the destination `rd`, and `BPF_CMPXCHG` must save `r0` to `t2` before `lld`/`llw` and reload `t3` from `src` inside the LL/SC loop before `scd`/`scw` (which overwrites `t3` with the status bit). [F41]
- In `__arch_prepare_bpf_trampoline()`, local stack offsets `ip_off` and `tcc_ptr_off` are only initialized when `flags & BPF_TRAMP_F_IP_ARG` and `flags & BPF_TRAMP_F_TAIL_CALL_CTX` are set respectively, so every read of `ip_off` or `tcc_ptr_off` must be guarded by its corresponding flag. [F23]
- In `prepare_bpf_tail_call_cnt()`, the comparison between `REG_TCC` and `MAX_TAIL_CALL_CNT` (`LOONGARCH_GPR_T3`) must use unsigned `BPF_JGT` (not signed `BPF_JSGT`) so a kernel stack pointer in `REG_TCC` (bit 63 set) compares greater than `MAX_TAIL_CALL_CNT`. [F73]
- When emitting `BPF_SUB | BPF_K` via `addid` in `build_insn()`, the 12-bit signed immediate check must test `is_signed_imm12(-imm)` rather than `is_signed_imm12(imm)`. [F53]
