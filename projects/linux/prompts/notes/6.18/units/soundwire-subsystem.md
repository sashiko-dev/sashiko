# SOUNDWIRE SUBSYSTEM

`drivers/soundwire` implements the MIPI SoundWire bus core, Cadence IP library routines, and Intel (cAVS/ACE1.x/ACE2.x) and AMD (ACP) Manager controller drivers. It manages Manager and Peripheral device lifecycles, MIPI DisCo firmware parsing (ACPI/DT), register command and Bulk Register Access (BPT/BRA) transfers, dynamic bandwidth allocation and bank switching, IRQ domain mapping, and ASoC DAI stream integration.

## Architecture & Data Flow

- In `struct sdw_intel_ctx` and `struct sdw_amd_ctx`, `ctx->ldev[i]` and `ctx->pdev[i]` are populated only for links set in `ctx->link_mask`; loops over `0 .. ctx->count - 1` must skip indices where `!(ctx->link_mask & BIT(i))`. In `amd_init.c` and `amd_manager.c`, manager `instance` (`0..1`) indexes 2-element arrays, and 0-based `dai->id` (`0..num_dais - 1`) indexes `acp63_sdw0_dp_reg[6]`, `acp63_sdw1_dp_reg[2]`, or `acp70_sdw_dp_reg[6]` (never 1-based port numbers `1..14`). [F47, F90]
- `slave->prop.src_dpn_prop` and `sink_dpn_prop` are dense arrays of length `hweight32(prop->source_ports)` and `hweight32(prop->sink_ports)` populated in ascending set-bit order of `ports & GENMASK(14, 1)` with `dpn[i].num = bit` (`sdw_slave_read_dpn()`). Never index them directly by port number `1..14`; use `sdw_get_slave_dpn_prop()`. [F78]
- In `sdw_handle_slave_alerts()`, port interrupt bits map to `0..14` in `port_status[15]` and `slave->port_ready[SDW_MAX_PORTS]`: `FIELD_GET(SDW_SCP_INT1_PORT0_3, buf)` maps to `0..3`, `SDW_SCP_INTSTAT2_PORT4_10` maps `bit + 4` to `4..10`, and `SDW_SCP_INTSTAT3_PORT11_14` maps `bit + 11` to `11..14`. In `sdw_handle_dp0_interrupt()` and `sdw_handle_port_interrupt()`, write-back `clear` must keep non-interrupt reserved bits and `SDW_DP0_SDCA_CASCADE` cleared, and retry loops must intersect `status &= status2`. [F69, F79]
- In `sdw_handle_slave_status()`, after handling `SDW_SLAVE_UNATTACHED` in pass 1, `status[0] == SDW_SLAVE_ATTACHED` returns early only if `sdw_program_device_num(bus, &id_programmed)` sets `id_programmed = true`. When transitioning to `SDW_SLAVE_ATTACHED` from `prev_status == SDW_SLAVE_ALERT`, break after `sdw_modify_slave_status()` without calling `sdw_initialize_slave()` or setting `attached_initializing = true`. [F98, F99]
- In `sdw_program_device_num()`, reset `found = false` on each pass of the `do { ... } while` loop before `list_for_each_entry_safe(slave, _s, &bus->slaves, node)`. If the matched `slave` has `slave->status != SDW_SLAVE_UNATTACHED`, return `0` immediately with `*programmed == false` instead of `continue` or `break`. Assemble 6-byte `SDW_SCP_DEVID_0..5` big-endian (casting `buf[0..2]` to `u64` before shifting `>= 24`). [F85, F96, F97]
- On Intel links, `intel_get_device_num_ida()` and `generic_new_peripheral_assigned()` partition device numbers `1..SDW_MAX_DEVICES` into `1..5` for non-wake-capable slaves and `6..11` (`SDW_INTEL_DEV_NUM_IDA_MIN..SDW_MAX_DEVICES`, from `intel_peripheral_ida`) for wake-capable slaves; `intel_put_device_num_ida()` must use matching wake checks. [F75]
- In `_sdw_compute_port_params()`, skip `m_rt` entries with `m_rt->stream->state` outside `[SDW_STREAM_CONFIGURED, SDW_STREAM_DISABLED]` before `sdw_compute_master_ports()`. In `sdw_compute_group_params()`, accumulate `params[i].payload_bw` for the target `stream` only when `stream->state == SDW_STREAM_CONFIGURED` and for other streams only when `m_rt->stream->state` is `SDW_STREAM_ENABLED`, `SDW_STREAM_PREPARED`, or `SDW_STREAM_DISABLED`, computing `params[i].hwidth` with ceiling division `(sel_col * params[i].payload_bw + params[i].full_bw - 1) / params[i].full_bw`. [F93, F94, F113]
- `struct sdw_cdns.response_buf` must be sized at least `CDNS_MCP_CMD_LEN + 2`, and `cdns_read_response()` must clamp `CDNS_MCP_FIFOSTAT & CDNS_MCP_RX_FIFO_AVAIL` to `ARRAY_SIZE(cdns->response_buf)`. `cdns->msg_count` must stay synchronized with `CDNS_MCP_FIFOLEVEL` in `sdw_cdns_init()`, `_cdns_xfer_msg()`, and `cdns_program_scp_addr()`. In `cdns_fill_msg_resp()`, check `CDNS_MCP_RESP_NACK` independently of `!(cdns->response_buf[i] & CDNS_MCP_RESP_ACK)` and evaluate `if (nack)` before `if (no_ack)`. [F63, F76, F92]

## Synchronization

- Lock acquisitions must follow the hierarchy: `cdns->status_update_lock` -> `bus->bus_lock` -> `slave->sdw_dev_lock` -> `bus->msg_lock` -> `sdw->link_res->shim_lock`. In `sdw_master_rt_alloc()`, insert `struct sdw_master_runtime` into `stream->master_list` in ascending `bus->id` order so `sdw_acquire_bus_lock()` and `do_bank_switch()` lock multiple buses in a consistent order. Each `struct sdw_bus` registers unique lockdep keys (`bus->msg_lock_key`, `bus->bus_lock_key`) in `sdw_bus_master_add()` and unregisters them in `sdw_bus_master_delete()`. [F18, F27, F152]
- Every bus path invoking `struct sdw_slave_ops` callbacks (`clk_stop`, `interrupt_callback`, `update_status`, `port_prep`, `bus_config`) must hold `slave->sdw_dev_lock`, check `slave->probed`, and resolve `drv->ops` via `drv_to_sdw_driver(slave->dev.driver)` inside that critical section. `sdw_drv_probe()` and `sdw_drv_remove()` must not hold `slave->sdw_dev_lock` across `drv->probe()` or `drv->remove()`, acquiring it only after `drv->probe()` succeeds to set `slave->probed = true` and before `drv->remove()` to clear `slave->probed = false`. [F24, F25]
- Slave IRQs mapped in `bus->domain` by `sdw_irq_map()` use `irq_set_nested_thread(virq, 1)` and must be dispatched via `handle_nested_irq(slave->irq)` from process/workqueue context (`sdw_handle_slave_alerts()`) outside `slave->sdw_dev_lock`. [F159]
- In `sdw_modify_slave_status()`, `slave->status` updates and `reinit_completion()` (on `SDW_SLAVE_UNATTACHED`) or `complete_all()` (on attachment/initialization) on `slave->enumeration_complete` and `slave->initialization_complete` must run under `bus->bus_lock` (never `init_completion()` or `complete()`); `sdw_clear_slave_status()` must also reset `slave->first_interrupt_done = false`. [F33, F34, F61]
- In `sdw_assign_device_num()` and `sdw_get_device_num()`, setting the allocated bit in `bus->assigned` requires `bus->bus_lock`, and `slave->dev_num` must remain 0 until `sdw_write_no_pm(slave, SDW_SCP_DEVNUMBER, ...)` succeeds. In `sdw_stream_add_master()`, `sdw_stream_remove_master()`, `sdw_stream_add_slave()`, and `sdw_stream_remove_slave()`, runtime alloc/free and updates to `bus->stream_refcount` and `bus->bpt_stream_refcount` require `bus->bus_lock`. [F36, F38]
- In `do_transfer_defer()`, initialize `bus->defer_msg.msg`, `bus->defer_msg.length`, and `init_completion(&bus->defer_msg.complete)` under `bus->msg_lock` before calling `bus->ops->xfer_msg_defer(bus)`. In `do_bank_switch()`, hold `bus->msg_lock` continuously across `pre_bank_switch()`, `sdw_bank_switch()`, `post_bank_switch()`, and `sdw_ml_sync_bank_switch()`, and free and clear `bus->defer_msg.msg = NULL` before unlocking `bus->msg_lock`. [F19, F29]
- In Cadence drivers, every call to `sdw_handle_slave_status(&cdns->bus, status)` must hold `cdns->status_update_lock`. In `sdw_cdns_irq()`, mask `CDNS_MCP_INT_SLAVE_MASK` in `CDNS_MCP_INTMASK` and defer to `cdns->work` (`cdns_update_slave_status_work()`) rather than handling slave status synchronously. `cdns_update_slave_status_work()` must clear `CDNS_MCP_INTSTAT` and `CDNS_MCP_SLAVE_INTSTAT0/1` before `cdns_update_slave_status()`, and must not clear `INTSTAT0/1` again in the device-0 retry loop. [F31, F35, F154]
- `sdw_cdns_enable_interrupt()` must clear stale `CDNS_MCP_SLAVE_INTSTAT0/1` bits before enabling interrupts, and when disabling must set `cdns->interrupt_enabled = false` and call `cancel_work_sync(&cdns->work)` before zeroing interrupt masks (while `sdw_cdns_irq()` checks `cdns->interrupt_enabled` before scheduling `cdns->work`). In `intel_link_power_down()`, clear `sdw->cdns.link_up = false` under `sdw->link_res->shim_lock` before switching I/O control to glue logic or clearing CPA, leaving it false even if polling fails. [F23, F132]
- Slave initialization, enumeration, alert, and clock-stop helpers invoked along runtime PM or `sdw_handle_slave_status()` paths (`sdw_slave_set_frequency()`, `sdw_initialize_slave()`, `sdw_slave_clk_stop_prepare()`) must use `_no_pm` register accessors (`sdw_read_no_pm()`, `sdw_write_no_pm()`, `sdw_update_no_pm()`). [F149]

## Object Lifetimes

- After `device_register(&md->dev)` in `sdw_master_device_add()`, failure paths must call `put_device(&md->dev)` and never `kfree(md)`. In `sdw_slave_add()`, if `device_register(&slave->dev)` fails after `of_node_get()` and linking `slave->node` into `bus->slaves`, unlink `slave->node` under `bus->bus_lock` and call `put_device(&slave->dev)` (never `kfree(slave)`). In `intel_link_dev_register()`, call `kfree(ldev)` if `auxiliary_device_init()` fails, but call `auxiliary_device_uninit(&ldev->auxdev)` if `auxiliary_device_add()` fails. [F1, F2, F3]
- In `sdw_bus_master_add()`, call `sdw_irq_create()` before `sdw_acpi_find_slaves()` / `sdw_of_find_slaves()`, and `sdw_irq_delete()` on discovery failure. In `sdw_bus_master_delete()`, unregister all child slaves via `sdw_delete_slave()` and call `sdw_irq_delete(bus)` before `sdw_master_device_del(bus)`. When `sdw_delete_slave()` removes a slave with non-zero `slave->dev_num`, it must clear `slave->dev_num` in `bus->assigned` and call `bus->ops->put_device_num(bus, slave)` under `bus->bus_lock`. [F6, F7, F126]
- In `sdw_nread()`, `sdw_nwrite()`, `sdw_handle_slave_alerts()`, `sdw_slave_reg_show()`, and `cmd_go()`, pass `&slave->dev` (never `slave->bus->dev`) to `pm_runtime_*` calls; when `pm_runtime_get_sync(&slave->dev)` returns a negative error other than `-EACCES`, call `pm_runtime_put_noidle(&slave->dev)` before returning, whereas `-EACCES` proceeds and balances the reference at normal exit. [F11, F101]
- In `intel_link_power_up()` and `intel_link_power_down()`, track active links in `*sdw->link_res->shim_mask` under `shim_lock`, running shared setup/teardown only on transitions from/to 0. In `intel_link_startup()`, `intel_resume()`, and `intel_resume_runtime()`, if bus start or DAI registration fails after `sdw_intel_link_power_up(sdw)`, call `sdw_intel_link_power_down(sdw)`. [F12, F13]
- In `intel_stop_bus()` and `intel_link_remove()`, run `cancel_delayed_work_sync(&cdns->attach_dwork)` and `sdw_cdns_enable_interrupt(cdns, false)` before `sdw_intel_link_power_down(sdw)` or `sdw_bus_master_delete(bus)`. In `amd_suspend()` and `amd_sdw_manager_remove()`, call `cancel_work_sync(&amd_manager->amd_sdw_work)` before stopping the clock, disabling interrupts, or deleting the bus. [F21, F22]
- DAI `.hw_params` callbacks (`intel_hw_params`) must not store the stack-allocated `struct snd_pcm_hw_params *params` pointer in `struct sdw_cdns_dai_runtime`; `.prepare` (`intel_prepare`) must read `&snd_soc_substream_to_rtd(substream)->dpcm[substream->stream].hw_params`. `sdw_transfer_defer()` stores `msg` in `bus->defer_msg.msg` asynchronously, so `msg` and `msg->buf` must remain valid until `bus->defer_msg.complete` is signaled. [F117, F119]

## API Contracts

- Single-byte register reads (`sdw_read()`, `sdw_read_no_pm()`, `sdw_bread_no_pm()`, `sdw_bread_no_pm_unlocked()`) return a signed `int` (`u8` value or negative errno); store the result in `int` and check `< 0` before casting to `u8`. In `sdw_update()`, `sdw_update_no_pm()`, `cdns_updatel()`, `cdns_ip_updatel()`, and `amd_updatel()`, `val` is ORed directly into `(tmp & ~mask) | val` without shifting or masking, so callers must pass a pre-shifted, masked value. [F39, F53]
- `sdw_nread_no_pm()`, `sdw_nwrite_no_pm()`, `sdw_nread()`, and `sdw_nwrite()` acquire and release `bus->msg_lock` per 32KB register page boundary and are not atomic across pages; `sdw_update()` and `sdw_update_no_pm()` also do not hold `msg_lock` across their read and write. Multi-byte `struct sdw_msg` transfers must be split at 32KB boundaries because `sdw_fill_msg()` computes one `(addr_page1, addr_page2)` pair per message. [F37, F72]
- Both `struct sdw_slave` (`sdw_slave_type`) and `struct sdw_master_device` (`sdw_master_type`) sit on `sdw_bus_type`; bus callbacks like `sdw_bus_match()` must check `is_sdw_slave(dev)` before calling `dev_to_sdw_dev(dev)`. The `status` array passed to `sdw_handle_slave_status()` must have at least `SDW_MAX_DEVICES + 1` (12) elements (`status[0]` for device 0, `status[1..11]` for peripherals). [F45, F74]

## Error Handling

- `sdw_master_ops.xfer_msg` (`cdns_xfer_msg()`, `amd_sdw_xfer_msg()`) returns `enum sdw_command_response` (never negative errno), which `find_response_code()` maps to `0` (`SDW_CMD_OK`), `-ENODATA` (`SDW_CMD_IGNORED`), `-ETIMEDOUT` (`SDW_CMD_TIMEOUT`), or `-EIO`. `do_transfer()`, `do_transfer_defer()`, and `sdw_transfer_unlocked()` must neither retry `-ENODATA` nor log it with `dev_err()`. [F44, F171]
- In `sdw_program_device_num()`, initialize `*programmed = false` before any fallible step or early return because `sdw_handle_slave_status()` ignores the return value and branches on `id_programmed`. In `sdw_intel_probe_controller()` and `sdw_amd_probe_controller()`, `err:` unwinds registered link devices using `while (i--)` (or `while (index--)`), so an error after registering index `i` before loop increment must increment `i++` before `goto err;`. [F50, F88]

## Known Pitfalls

- `sdw_cdns_bpt_find_buffer_sizes()` takes `command = 0` for write and `command = 1` for read—the inverse of `SDW_MSG_FLAG_READ` (0) and `SDW_MSG_FLAG_WRITE` (1)—so callers like `intel_ace2x_bpt_open_stream()` must invert `msg->flags & SDW_MSG_FLAG_WRITE`. [F54]
- Because `amd_sdw_send_cmd_get_resp()` returns `u64` and sign-extends `-ETIMEDOUT` (`0xffffffffffffff92`, which has `BIT(1)` / `AMD_SDW_MCP_RESP_NACK` set), `amd_program_scp_addr()` and `amd_sdw_fill_msg_resp()` must check `response == -ETIMEDOUT` before testing `AMD_SDW_MCP_RESP_NACK`. In `amd_sdw_send_cmd_get_resp()`, clear write-1-to-clear `AMD_SDW_IMM_RES_VALID` in `ACP_SW_IMM_CMD_STS` by writing `AMD_SDW_IMM_RES_VALID` and polling until cleared (never writing 0). [F110, F134]
- Read MIPI DisCo boolean properties in `mipi_disco.c` with `mipi_fwnode_property_read_bool()` or `mipi_device_property_read_bool()` (which read a `u8`), never `fwnode_property_read_bool()`. Copy narrower bitmasks (`u8` status in `sdw_handle_slave_alerts()`, `int ports` in `sdw_slave_read_dpn()`) into an `unsigned long` before passing its address to `for_each_set_bit()`. In `sdw_bus_exit_clk_stop()` and `sdw_bus_prep_clk_stop()`, never dereference `slave` after `list_for_each_entry(slave, &bus->slaves, node)` finishes without breaking; log with `bus->dev`. [F86, F95, F125]
