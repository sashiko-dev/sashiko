# NETWORKING [GENERAL]

Core Linux networking headers (`include/linux/`, `include/net/`) and implementations (`net/core/`, `net/kcm/`, `net/l2tp/`, `net/l3mdev/`, `net/mpls/`) covering `sk_buff` and `netmem_ref` buffer management, `net_device` lifecycle and instance locking, NAPI/GRO/GSO datapaths, Qdisc/TC scheduling, FIB/destination caches, Netlink/Genetlink, BPF socket storage, and KCM/L2TP/MPLS/VRF protocols.

## Architecture & Data Flow
- `skb->_skb_refdst` and `skb_dstref_steal()` encode `SKB_DST_NOREF` (`1UL`) in bit 0; extract pointers via `skb_dst()`/`refdst_drop()` and test unreferenced dsts with `skb_dst_is_noref(skb)` (not `& SKB_DST_NOREF` alone). `skb_dst(skb)` may be a `struct metadata_dst` (`DST_METADATA`), requiring `skb_metadata_dst(skb)`, `md_dst->type` checks, or `skb_valid_dst(skb)` for routes. Attaching a dst or `nf_conntrack` must set `skb->slow_gro |= !!val`. [F795, F796, F810, F864]
- `dst->_metrics` encodes `DST_METRICS_READ_ONLY` and `DST_METRICS_REFCOUNTED` in its low 2 bits: read via `DST_METRICS_PTR(dst)` and write via `dst_metric_set()` or `dst_metrics_write_ptr(dst)` (checking its return for `NULL` if COW fails). Shared tables like `dst_default_metrics` require `dst_init_metrics(..., true)` and must be excluded before decrementing `refcnt` or calling `kfree()` in `ip_fib_metrics_put()`/`ip_dst_metrics_put()`. [F77, F764, F789, F797, F821]
- `skb->napi_id` and `skb->sender_cpu` share a union (`0` unset, `1..NR_CPUS` 1-based `sender_cpu`, `>= MIN_NAPI_ID` NAPI IDs); subtract 1 from `skb->sender_cpu` when indexing CPU/XPS arrays, and gate `__skb_mark_napi_id()` on `!napi_id_valid(skb->napi_id)`. `skb->hash`, `sw_hash`, and `l4_hash` must be updated together via `__skb_set_hash()`/`skb_clear_hash()`, and `skb->inner_protocol`/`inner_ipproto` via `skb_set_inner_protocol()`/`skb_set_inner_ipproto()`. [F464, F815, F816, F826]
- `skb->tstamp` and `skb->tstamp_type` are coupled: `skb_clear_tstamp()` is a no-op when `tstamp_type` is non-zero (`SKB_CLOCK_MONOTONIC`/`TAI`); use `skb_clear_delivery_time()` on ingress and reset `tstamp_type` in `skb_set_delivery_time()` when `kt == 0`. `skb->sk` requires a non-NULL `skb->destructor` (`skb_orphan()` `BUG_ON`s otherwise). [F817, F825]
- In `__netif_receive_skb_core()`, `ptype_all` taps run before protocol handlers (skipped when `skb_pfmemalloc(skb)`, which also drops packets not whitelisted by `skb_pfmemalloc_protocol()`), `*pskb` must remain valid whenever `*ppt_prev != NULL`, and any deferred `pt_prev` must be flushed via `deliver_skb()` and cleared before `sch_handle_ingress()`, `nf_ingress()`, `vlan_do_receive()`, or `rx_handler(&skb)`. [F436, F483, F574]
- `struct fib_nh_common *` (`res->nhc`) may only be downcast to `struct fib_nh *` after checking `nhc->nhc_family == AF_INET` (IPv6 embeds it in `struct fib6_nh`). In `struct fib6_info`, trailing `fib6_nh[]` is allocated only when `!f6i->nh`. In `struct mpls_route`, `rt->rt_nh` entries have variable stride `rt->rt_nh_size` and via offset `rt->rt_via_offset`; access them via `for_nexthops`/`mpls_get_nexthop()` and `mpls_nh_via()`, and validate user labels with `mpls_label_ok()`. [F45, F128, F656, F657]

## Synchronization
- `netdev_lock_ops()` only acquires `dev->lock` when `netdev_need_ops_lock(dev)` is true (`request_ops_lock`, `queue_mgmt_ops`, or `net_shaper_ops`); those fields must not change between lock/unlock, transitioning to full `dev->lock` requires `netdev_lock_ops_to_full()`/`netdev_unlock_full_to_ops()`, locking multiple `dev->lock`s requires `rtnl_lock`, and pointers protected by `dev->lock` must use `netdev_lock_dereference(p, dev)`. [F195, F205, F333, F334, F335]
- `NETDEV_REGISTER`, `NETDEV_UP`, and `NETDEV_CHANGE` notifiers run with `netdev_lock_ops(dev)` held, so callbacks on the same device must use unlocked `netif_*` helpers (`netif_set_promiscuity()`, `netif_state_change()`, `netif_xdp_propagate()`). Propagating features to lower devices in `netdev_sync_lower_features()`/`netif_disable_lro()` requires `netdev_lock_ops(lower)`, and pre-registration helpers must use `netdev_ops_assert_locked_or_invisible(dev)`. [F408, F409, F410]
- Batch close (`unregister_netdevice_many_notify()`) must close ops-locked devices and drop their `dev->lock` before calling `netif_close_many()` on non-ops-locked devices. Unregistration/netns move must call `unlist_netdevice()`, mark `NETREG_UNREGISTERING`/`moving_ns` under `dev->lock`, and `synchronize_net()` before calling `dev_shutdown()` under `netdev_lock_ops(dev)`; `netdev_run_todo()` must drop `rtnl_lock` before `rcu_barrier()`, `linkwatch_sync_dev()`, and `netdev_wait_allrefs_any()`. [F405, F406, F407]
- Lockless lookups returning a locked `net_device` (`__netdev_put_lock()`, `netdev_napi_by_id_lock()`, `netdev_get_by_index_lock()`, `netdev_xa_find_lock()`) must take `dev_hold()` under `rcu_read_lock()`, drop RCU before `netdev_lock(dev)`, and verify `dev->reg_state <= NETREG_REGISTERED`, `!dev->moving_ns`, and `net_eq(dev_net(dev), net)` (always consuming the caller's `dev` ref). [F380, F546]
- `____napi_schedule()` requires hardirqs disabled (`__napi_schedule_irqoff()` must fall back to `__napi_schedule()` on `CONFIG_PREEMPT_RT`). `napi_set_threaded()` must create `napi->thread` and issue `smp_mb__before_atomic()` before setting `NAPI_STATE_THREADED`, and `napi_stop_kthread()` must clear `NAPIF_STATE_THREADED` via `try_cmpxchg()` and wait for `NAPI_STATE_SCHED_THREADED` to clear before `kthread_stop()`. [F402, F403, F555]
- For `!TCQ_F_NOLOCK` Qdiscs, `qdisc_run_begin()`/`qdisc_run_end()` require the root lock, and in `__dev_xmit_skb()` when `contended`, `q->busylock` must be acquired before `qdisc_lock(q)` and dropped before `__qdisc_run(q)`. On `TCQ_F_NOLOCK` Qdiscs, `qdisc_run_end()` requires `smp_mb()` after `spin_unlock(&qdisc->seqlock)` before testing `__QDISC_STATE_MISSED`. `sch_tree_lock(q)` requires `rtnl_lock` in process context unless `TCQ_F_MQROOT`. [F210, F211, F345, F552]
- All `dst_cache_get*`/`dst_cache_set*` helpers and `__SNMP_*` macros require BH disabled; live `dst_cache` invalidation must use `dst_cache_reset()` (never `dst_cache_reset_now()`/`dst_cache_destroy()`). Route MTU helpers (`ip_dst_mtu_maybe_forward()`, `ip6_dst_mtu_maybe_forward()`) and `fib6_lookup()`/`fib6_table_lookup()`/`fib6_select_path()`/`fib6_get_cookie_safe()` must run under `rcu_read_lock()` using `dst_dev_rcu()`/`dev_net_rcu()`. [F32, F146, F150, F350, F778, F779]
- `rtnl_dereference(p)` (`dev_ingress_queue(dev)`) requires `rtnl_lock` and omits `READ_ONCE()`; paths that may hold only `rcu_read_lock()` or `rtnl_lock` must use `rcu_dereference_rtnl(p)` (as in `mpls_route_input_rcu()`, `mpls_dev_get()`, `dev_ingress_queue_rcu()`). `pernet_operations` `init`/`pre_exit`/`exit`/`exit_batch` run without `rtnl_lock`, and RCU `net` lookups must use `maybe_get_net()` rather than `get_net()`. [F217, F338, F712, F783]

## Object Lifetimes
- `skb_dst_set()`, `skb_dst_set_noref()`, and `skb_dstref_restore()` assert no counted dst is held (`skb_dst_check_unset()`); call `skb_dst_drop(skb)` before replacing a dst, and call `skb_dst_force(skb)` under `rcu_read_lock()` before leaving RCU with a noref dst. `__skb_ext_copy()` and `__nf_copy()` do not release existing destination references (use `skb_ext_copy()`/`nf_copy()`), and clearing extensions on a live `skb` requires `skb_ext_reset(skb)` (not `skb_ext_put(skb)`). [F753, F759, F760, F913]
- `skb_fill_page_desc()`/`skb_fill_netmem_desc()` transfer the caller's page/netmem reference without incrementing it (and must use the acc variants to set `skb->unreadable` on `net_iov` and `skb->pfmemalloc` on `pfmemalloc` pages). When `skb_zcopy_managed(skb)` (`SKBFL_MANAGED_FRAG_REFS`) is set, `skb_frag_unref()` is a no-op; call `skb_zcopy_downgrade_managed(skb)` before taking/dropping individual frag refs, and use `skb_orphan_frags_rx()` (not `skb_orphan_frags()`) when looping TX packets to RX. [F757, F819, F936, F937]
- In `free_netdev()`, if `dev->reg_state == NETREG_UNREGISTERING`, it must set `dev->needs_free_netdev = true` and return; `mutex_destroy(&dev->lock)` must run after `netif_free_rx_queues()` and `netdev_napi_exit()`; and `NETREG_UNREGISTERED` devices must be freed via `put_device(&dev->dev)` (`NETREG_RELEASED`) rather than `kvfree(dev)`. In `register_netdevice()`, `NETDEV_REGISTER` notifier failure must set `dev->needs_free_netdev = false` before `unregister_netdevice_queue()`. [F377, F439, F526, F527]
- During Qdisc `enqueue()`, dropped packets must be deferred onto `*to_free` via `qdisc_drop*()`/`__qdisc_drop*()` rather than `kfree_skb()` (and non-GSO-list SKBs passed to `qdisc_drop_all()` must have `skb->prev = NULL`). `qdisc_replace()` and `dev_graft_qdisc()` return the old `struct Qdisc *` with its reference intact, which the caller must release via `qdisc_put()`. [F200, F201, F284]

## API Contracts
- Lookup refcounting: `fib_lookup()` (`FIB_LOOKUP_NOREF`), `__neigh_lookup_noref()`, `ip_neigh_gw6()`, `l3mdev_link_scope_lookup()`, `__in6_dev_get()`, and `*_rcu`/`__dev_get_by_*` netdev helpers return borrowed RCU pointers (do not put); `neigh_lookup()`/`neigh_create()`/`__ipv6_neigh_lookup()`, `in6_dev_get()`, `dev_get_by_*()`/`netdev_get_by_*()`, and `mana_get_primary_netdev()` return refcounted pointers. `__inet_lookup*()` and `skb_steal_sock()` set `*refcounted = false` for listener/syncookie sockets; only call `sock_put(sk)` if `*refcounted` is true. Release `RT6_LOOKUP_F_DST_NOREF` routes with `ip6_rt_put_flags(rt, flags)`. [F13, F23, F181, F188, F191, F192, F259, F329, F381, F716, F784]
- SKB consumption: `skb_share_check()`, `skb_unshare()`, `skb_pad()`, `skb_padto()`, `skb_put_padto()`, `neigh_output()`, `neigh_hh_output()`, `nlmsg_unicast()`, and `nlmsg_multicast*()` always consume/free `skb` on both success and error; callers must never call `kfree_skb()`/`nlmsg_free()` after them. `mpls_xmit()` must return `LWTUNNEL_XMIT_DONE` once `neigh_xmit()` is called. [F194, F202, F632, F755, F756]
- Before accessing or mapping `skb_shinfo(skb)->frags` (e.g., `__skb_datagram_iter()`, `zerocopy_fill_skb_from_iter()`, `skb_checksum_help()`, `validate_xmit_skb()`), check `skb_frags_readable(skb)` because `net_iov` fragments return `NULL` from `skb_frag_page()`/`skb_frag_address()` and must be DMA-mapped via `skb_frag_dma_map()` and converted with `netmem_is_net_iov()` checks. [F230, F542, F563, F800, F917]
- Socket downcasts: `sk_to_full_sk()`/`skb_to_full_sk()` return `NULL` for `TCP_TIME_WAIT` even on non-NULL input; `inet_csk(sk)` requires `inet_test_bit(IS_ICSK, sk)`; `inet_reqsk(sk)` requires `sk->sk_state == TCP_NEW_SYN_RECV`; and `sk_validate_xmit_skb()`/`psp_sk_get_assoc_rcu()` must distinguish `sk_fullsock(sk)` from `TCP_TIME_WAIT` (`inet_twsk(sk)`) and `TCP_NEW_SYN_RECV`. [F46, F232, F306, F520]

## Error Handling
- Return conventions: `ip6_route_output*()`, `ip6_route_lookup()`, and `fib6_rule_lookup()` never return `NULL`/`ERR_PTR` (check `dst->error`), whereas `ip6_dst_lookup_flow()`/`ip6_sk_dst_lookup_flow()` return `ERR_PTR`. `fl6_sock_lookup()` returns `ERR_PTR(-ENOENT)` when exclusive flowlabels are active and `NULL` otherwise; `inet_steal_sock()`/`inet6_steal_sock()` and `devm_framer_optional_get()` can return either `ERR_PTR` or `NULL`. `neigh_create()`, `__neigh_lookup_errno()`, `ip_neigh_gw6()`, `qdisc_alloc()`, `tun_dst_unclone()`, `l2tp_session_create()`, `mpls_rt_alloc()`, and `find_outdev()` return `ERR_PTR`, whereas `neigh_lookup()`, `dst_neigh_lookup*()`, `qdisc_create_dflt()`, `skb_tunnel_info_unclone()`, `maybe_get_net()`, and `get_net_ns_by_id()` return `NULL`. [F37, F42, F111, F224, F225, F226, F622, F634, F635, F787, F788, F790]
- Non-boolean/signed status returns: `skb_checksum_validate*()`/`skb_checksum_complete()` return `0` when valid and non-zero `__sum16` when invalid; `NL_REQ_ATTR_CHECK()` returns `1` when missing (`0` when present); `flow_rule_has_control_flags*()` returns `true` when flags are present (invalid); `INET_ECN_decapsulate()` returns `1` to log and `2` (`> 1`) to drop; `netif_txq_maybe_stop()`/`__netif_txq_completed_wake()` return `0` (changed), `1` (enabled), or `-1` (unchanged/raced); `__netdev_update_features()` returns `1` or `-1` when notification is needed; and `skb_get_dsfield()` and `nla_strscpy()` return negative errors requiring signed `int`/`ssize_t` variables. [F39, F40, F109, F228, F229, F438, F791, F792]
- Teardown on init failure: `qdisc_create*()` calls `Qdisc_ops::destroy` even when `Qdisc_ops::init` fails, and `free_netdev()` calls `netif_free_rx_queues()` after `netif_alloc_rx_queues()` fails, so any resource freed on an init error path (`qdisc_priv(sch)` pointers, `dev->_rx`, `fq->flows`/`fq->flows_bitmap` in `fq_init()`/`fq_reset()`, `napi->thread` in `napi_kthread_create()`, `mdev->sysctl` in `mpls_dev_sysctl_register()`) must be cleared to `NULL`. Conversely, `ethtool_ops::begin` resources must only be released in `ethtool_ops::complete`, and `scm_send()` callers must call `scm_destroy()` only if `scm_send()` returned `0`. [F3, F198, F199, F387, F431, F597, F896]

## Known Pitfalls
- Any pointer into `skb->head` (`skb->data`, `skb_network_header()`, `skb_shinfo()`, GRO headers) or `*pskb` itself in `netif_receive_generic_xdp()` (`netif_skb_check_for_xdp()`) becomes stale across calls that may reallocate or pull (`pskb_may_pull()`, `pskb_expand_head()`, `skb_cow*()`, `skb_gro_header_slow()`, `skb_gro_remcsum_process()`, `l2tp_v3_ensure_opt_in_linear()`) and must be reloaded afterward. Expanding `skb->head` during GSO must use `gso_pskb_expand_head()` to adjust `SKB_GSO_CB(skb)->mac_offset`. [F66, F70, F131, F451, F663, F814]
- Queue and action iterators: unlinking/freeing inside `skb_queue_walk*()` or `skb_rbtree_walk*()` requires the `*_safe` variant; after `skb_queue_walk*()` finishes without `break`, `skb` points to `(struct sk_buff *)queue` (not `NULL`); `skb_queue_next()`/`prev()` `BUG_ON` at the ends of the queue (use `skb_peek_next()`); and `__act` in `flow_action_for_each()` points one past `entries[num_entries]` if the loop finishes normally. [F107, F854, F855, F856, F857]
- Netlink parsing & alignment: `nlmsg_for_each_msg()`/`nla_for_each_attr()` require a signed `int rem` counter; switch/compare on `nla_type(nla)` (not raw `nla->nla_type`); `NLA_STRING` is not guaranteed NUL-terminated (use `NLA_NUL_STRING` or `nla_strscpy()`/`nla_strdup()`); 64-bit attributes must be read with `nla_get_u64()`/`s64()`/`be64()`, written with `nla_put_64bit()`/`nla_reserve_64bit()`, and sized with `nla_total_size_64bit()`; `NLA_UINT`/`NLA_SINT` require `nla_get_uint()`/`sint()`; and `NLA_POLICY_RANGE()` bounds are `s16` (use `NLA_POLICY_FULL_RANGE*()` outside `[-32768, 32767]`). [F263, F266, F267, F286, F301, F310, F312, F472]
- Bitmasks, shifts & offsets: `flow_dissector->used_keys` requires `BIT_ULL(key_id)`; `&napi->state` bit ops take `NAPI_STATE_*` indices while bitwise ops/`try_cmpxchg()` take `NAPIF_STATE_*` masks; `ip_tunnel_flags_*()` requires `IP_TUNNEL_DECLARE_FLAGS()`; `__inet6_lookup()` takes host-order `u16 hnum` while `__inet_lookup()` takes `__be16 dport`; `skb->csum_start` is relative to `skb->head`; `skb->tail`/`end` require `skb_tail_pointer()`/`skb_end_pointer()`; and `skb->mac_header`/`transport_header` use `~0U` as unset (check `skb_*_header_was_set()`, and use `skb_reset_transport_header_careful()` on untrusted offsets). [F57, F114, F140, F420, F809, F850, F851, F947]
