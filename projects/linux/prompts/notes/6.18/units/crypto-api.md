# CRYPTO API

The Linux kernel cryptographic framework manages algorithm registration, lookup, larval probing, template instantiation, spawn graphs, and transform lifecycles across `acomp`, AEAD, `ahash`/`shash`, skciphers, `akcipher`, `kpp`, and DRBG/RNGs. It also provides `AF_ALG` sockets, `NETLINK_CRYPTO` (`crypto_user`), `cryptd`, `crypto_engine`, FIPS mode, and core cipher, mode, MAC, KDF, and checksum implementations.

## Architecture & Data Flow

- Variable-length subrequests must remain the final struct member in `adiantum_request_ctx` (`u`), `adiantum_setkey`'s `data` (`req`), `essiv_aead_request_ctx` (`aead_req`), and `hctr2_request_ctx` (`u`). In `authenc`/`authencesn`, `reqoff` must be `>= 2 * digestsize` and `crypto_aead_set_reqsize()` must add `sizeof(*areq_ctx) + reqoff` to the max subrequest size. In `crypto_akcipher_sync_prep()`, the bounce buffer must start at `(u8 *)(req + 1) + reqsize`. [F120, F121, F122, F274]
- For `CRYPTO_AHASH_ALG_BLOCK_ONLY`, `ahash_prepare_alg()` appends `cra_blocksize + 1` bytes to `cra_reqsize` and `halg.statesize`; `crypto_ahash_*()` store the partial-block length at `ahash_request_ctx(req) + crypto_ahash_reqsize(tfm) - 1` and buffer at `blenp - bs`. When `crypto_ahash_{update,finup}()` prepend `req->sg_head` to `req->src`, `ahash_{update,finup}_finish()` must restore `req->src`, `req->nbytes`, and `req->base.{complete,data}`. [F61, F118]
- Because `struct acomp_req` unions `src`/`svirt` and `dst`/`dvirt`, `acomp_virt_to_sg()` must save `req->base.flags`, `req->svirt`, and `req->dvirt` into `req->chain` before `acomp_request_set_{src,dst}_sg()` overwrite the union and clear `VIRT` bits; `acomp_reqchain_finish()` restores them plus `req->base.{complete,data}` only when `err != -EINPROGRESS`. [F35, F56]
- `crypto_clone_ahash()` must copy `reqsize`/`statesize`, set `nhash->using_shash = true` with the cloned `crypto_shash` if `hash->using_shash`, or clone `crypto_ahash_fb(hash)` into `crypto_ahash_tfm(nhash)->fb` if `crypto_ahash_need_fallback(hash)`. In `crypto_ahash_setkey()`, when `!tfm->using_shash && crypto_ahash_need_fallback(tfm)`, set the key on both `tfm` and `crypto_ahash_fb(tfm)` before clearing `CRYPTO_TFM_NEED_KEY`. [F57, F58]
- `af_alg_alloc_tsgl()` allocates `MAX_SGL_ENTS + 1` entries and `struct af_alg_sgl` embeds `sgl[ALG_MAX_PAGES + 1]` to reserve the trailing slot for `sg_chain()`, so `af_alg_sendmsg()` must cap additions to `MAX_SGL_ENTS - sgl->cur` and `af_alg_get_rsgl()`/`hash_sendmsg()` must populate at most `ALG_MAX_PAGES` entries. [F74, F75]
- In `af_alg_sendmsg()` and `af_alg_pull_tsgl()`, use `ctx->merge` only when `!(msg->msg_flags & MSG_SPLICE_PAGES)` and clear it on `MSG_SPLICE_PAGES` or when `af_alg_pull_tsgl()` drains `ctx->used` to 0. In `af_alg_pull_tsgl()`, increment `dst` index `j` only when `dst` is non-NULL and `dst_offset < plen`; if `sg[i].length` remains non-zero after subtracting `plen`, return without calling `put_page()` or unlinking `sgl`. [F65, F100]
- In `crypto_aegis128_decrypt_{generic,simd}()`, copy the tag from `req->src` before `skcipher_walk_aead_decrypt()` mutates `req->dst` (which may alias `req->src`), and on tag mismatch zero `req->dst` via `crypto_aegis128_wipe_chunk` before returning `-EBADMSG`. In `crypto/gcm.c` and `crypto/ccm.c`, `pctx->dst` (`rctx->dst`) is only initialized when `req->src != req->dst`, so all stages must select `req->src == req->dst ? pctx->src : pctx->dst`. [F70, F289]

## Synchronization

- In `crypto_start_tests()`, call `set_crypto_boot_test_finished()` before taking `crypto_alg_sem`; each iteration must take `crypto_alg_sem`, mark `l->test_started = true` on one larval, drop `crypto_alg_sem` before `crypto_schedule_test(larval)`, and restart the scan. `crypto_start_test()` must likewise recheck and set `larval->test_started = true` under `down_write(&crypto_alg_sem)` and unlock before `crypto_schedule_test()`. [F17, F18, F98]
- When `crypto_larval_wait()` wakes and sees `!alg` or `PTR_ERR(alg) == -EEXIST` from `larval->adult`, it must re-run `crypto_alg_lookup(alg->cra_name, type, mask)` and loop if another larval is returned. In `crypto_larval_lookup()`, only call `crypto_larval_add()` when `!(mask & CRYPTO_ALG_TESTED)`, but always call `crypto_larval_wait()` on an existing larval. [F19, F20]
- In `crypto_grab_spawn()`, after `crypto_find_alg()`, take `down_write(&crypto_alg_sem)` and verify `!crypto_is_moribund(alg)` before linking `spawn->list` into `alg->cra_users` (releasing via `crypto_mod_put(alg)` if moribund). In `crypto_spawn_alg()`, if `crypto_mod_get(alg)` fails under `down_read(&crypto_alg_sem)`, pin `alg` with `crypto_alg_get(alg)` before `up_read(&crypto_alg_sem)` so `crypto_shoot_alg(target)` runs outside the read lock. [F22, F23]
- In `crypto_destroy_instance_workfn()`, traverse `tmpl->dead` under `down_write(&crypto_alg_sem)` and only free instances with `refcount_read(&inst->alg.cra_refcnt) == -1`. In `crypto_unregister_template()` and `crypto_update_alg()`, drop `down_write(&crypto_alg_sem)` before calling `crypto_free_instance()`, `crypto_remove_final()`, or `flush_work(&tmpl->free_work)`. [F24, F25, F252]
- Locking both an `AF_ALG` child socket `sk` and parent `psk = ask->parent` requires `lock_sock(sk)` then `lock_sock_nested(psk, SINGLE_DEPTH_NESTING)`. Under `lock_sock(sk)`, `alg_bind()` must reject rebinding (`-EBUSY`) if `atomic_read(&ask->refcnt) != 0`, and `alg_setsockopt()` must reject changes (`-EBUSY`) if `atomic_read(&ask->refcnt) != atomic_read(&ask->nokey_refcnt)`. [F30, F31]
- Under `lock_sock(sk)`, `af_alg_sendmsg()` must check/set `ctx->write = true` (`-EBUSY` if set) across `af_alg_wait_for_wmem()` and clear it before `release_sock(sk)`. `af_alg_alloc_areq()` must return `-EBUSY` if `ctx->inflight` is true, keeping it true until `af_alg_free_resources()`. Before submitting an async AIO request, pin `sk` with `sock_hold(sk)` and set `areq->{iocb,outlen}`; if it returns `-EINPROGRESS`, return `-EIOCBQUEUED` without freeing `areq` or calling `sock_put(sk)`. [F28, F32, F33]
- Async completion callbacks and continuations (`ahash_op_done`, `crypto_authenc{,_esn}_{genicv,decrypt_tail}`, `async_done_continue`, `hmac_finup_done`, `crypto_ccm_decrypt_done`, `gcm_*_done`) must clear `CRYPTO_TFM_REQ_MAY_SLEEP` from subrequest flags. `algif_skcipher_export()`, `crypto_clone_tfm()`, and `__crypto_alloc_tfmgfp()` must use `GFP_ATOMIC` in atomic paths, and `{adiantum,hctr2}_hash_message()` must pass `SG_MITER_ATOMIC`. [F138, F139, F143, F144, F149, F248, F326]
- `crypto_acomp_lock_stream_bh()` disables BH via `spin_lock_bh(&ps->lock)` and, if the current CPU's `ps->ctx` is NULL, unlocks with non-BH `spin_unlock(&ps->lock)` before locking `cpumask_first(cpu_possible_mask)` so BHs remain disabled. Callers of `acomp_walk_virt()` in atomic context (such as under `crypto_acomp_lock_stream_bh()`) must pass `atomic = true` so `acomp_walk_done_{src,dst}()` do not call `cond_resched()`. [F135, F136]
- In `cryptd.c`, `cryptd_enqueue_request()` and `cryptd_queue_worker()` must disable BH and hold `cpu_queue->bh_lock` across queue ops (and while incrementing `refcnt`, which must be the first member of `cryptd_{skcipher,hash,aead}_ctx`). `cryptd_queue_worker()` must drop `bh_lock` before `crypto_request_complete()`, while worker completions in `cryptd_{skcipher,hash}_complete()` and `cryptd_aead_crypt()` must wrap `*_request_complete()` in `local_bh_disable()`/`local_bh_enable()`. [F192, F193, F321]
- In `crypto_engine.c`, acquire `engine->queue_lock` with `spin_lock_irqsave()` around `engine->{queue,running,busy,cur_req}` and drop it before `op->do_one_request()`, `crypto_request_complete()`, or `msleep()`. In `crypto_pump_requests()`, re-acquire `queue_lock` before `start_request` or `out`, skip `-EINPROGRESS` backlog completion on `-ENOSPC` requeue, and when `!engine->retry_support`, keep `cur_req` set until `crypto_finalize_request()` (in BH-disabled context) clears it under `queue_lock`. `crypto_engine_stop()` must verify `!crypto_queue_len(&engine->queue) && !engine->busy` under `queue_lock` after its wait loop before clearing `engine->running`. [F232, F233, F281, F282, F322, F323]

## Object Lifetimes

- `crypto_create_tfm_node()`, `__crypto_alloc_tfmgfp()`, and `{crypto,aead,ahash,akcipher}_register_instance()` take ownership of `alg` or `inst` only on success; on error, the caller must call `crypto_mod_put(alg)` (which must read `alg->cra_module` before `crypto_alg_put(alg)`) or invoke the instance teardown helper. `crypto_destroy_tfm(mem, tfm)` must receive the outer frontend handle as `mem` and `&frontend->base` as `tfm`. [F1, F2, F5, F113]
- When `frontend->init_tfm(tfm)` fails in `crypto_create_tfm_node()`, `crypto_exit_ops(tfm)` is skipped, so `init_tfm` callbacks (`crypto_{acomp,ahash,ccm,gcm}_init_tfm()`, `hctr2_init_tfm()`, `essiv_{skcipher,aead,}_init_tfm()`) must free any allocated fallback or child transforms before returning an error. [F6, F188]
- Once `af_alg_accept()` calls `sock_init_data(newsock, sk2)`, `newsock` owns `sk2`, so `af_alg_accept()`, `type->accept`, and `hash_accept()` must never call `sock_put(sk2)` on subsequent error paths. In `alg_bind()`, swap `(ask->type, ask->private)` with `(type, private)` under `lock_sock(sk)` when `ask->refcnt == 0` and call `alg_do_release(type, private)` after `release_sock(sk)`. [F8, F16]
- In `af_alg_get_rsgl()` and `hash_sendmsg()`, set `sgl.need_unpin = iov_iter_extract_will_pin(&msg->msg_iter)` before `extract_iter_to_sg()`, and in `af_alg_get_rsgl()` initialize `rsgl->sgl.need_unpin`, `rsgl->sgl.sgt.{sgl,nents}`, and (on failure) `rsgl->sg_num_bytes = 0` whenever `rsgl` is added to `areq->rsgl_list`. In `hash_sendmsg()`, errors before `ctx->sgl` is initialized in the loop must jump to `unlock_free_result`, not `unlock_free`. [F11, F14, F167]
- `crypto_{acomp,ahash}_*` reject `CRYPTO_TFM_REQ_ON_STACK` requests on async transforms unless cloned via `crypto_request_clone()` (which clears `CRYPTO_TFM_REQ_ON_STACK` on heap clone `nreq`, or switches `req->tfm` to `tfm->fb` on failure), and `ahash_request_free()` must not `kfree()` on-stack requests. `acomp_request_clone()` must rebase `nreq->{src,dst}` to `&nreq->chain.{ssg,dsg}` when `req->{src,dst}` point to `req->chain.{ssg,dsg}`. [F55, F116, F117]
- In `cryptd_{enqueue_request,skcipher_complete,hash_complete,aead_crypt}()`, read `ctx->refcnt` before calling `*_request_complete()` (which may free a zero-refcnt `tfm`) and do not decrement it on `-EINPROGRESS`. Because `crypto_engine_alloc_init_and_set()` uses `devm_kzalloc` for `engine` but unmanaged `kthread_run_worker()` for `kworker`, drivers must call `crypto_engine_exit()` before unbind finishes. [F176, F312]

## API Contracts

- For `CRYPTO_AHASH_ALG_BLOCK_ONLY` algorithms (`cbcmac`, `cmac`, `ghash`), `.update` returns the non-negative unconsumed residual byte count (`< bs`) on success or a negative errno. Similarly, `crypto/cbc.c` and `crypto/ecb.c` lskcipher `encrypt`/`decrypt` return residual `rem` when `!(flags & CRYPTO_LSKCIPHER_FLAG_FINAL)` and `-EINVAL` only when `CRYPTO_LSKCIPHER_FLAG_FINAL` is set. [F39, F225, F226]
- `crypto_hash_walk_{first,done}()` return a positive byte count, 0 when finished, or a negative errno; callers must store the result in a signed `int` and pass step errors into `crypto_hash_walk_done()` to unmap `walk->data`. For scatterlist walks (`!(walk->flags & CRYPTO_AHASH_REQ_VIRT)`), `crypto_hash_walk_done()` must subtract `walk->offset` from `walk->data` before `kunmap_local(walk->data)` and, when `walk->entrylen` is non-zero, reset `walk->offset = 0` and increment `walk->pg`. [F40, F102]
- Template `.setkey` callbacks must clear `CRYPTO_TFM_REQ_MASK` on each child transform and copy `parent_flags & CRYPTO_TFM_REQ_MASK` before calling the child's `setkey`. In `hmac_import*` and `cryptd_hash_import`, bind the child transform (`desc->tfm` or `ahash_request_set_tfm()`) before calling the child import function. [F243, F338]

## Error Handling

- In `acomp_do_req_chain()`, call `acomp_save_req()` unconditionally before `acomp_do_one_req()` because `acomp_reqchain_finish()` unconditionally calls `acomp_restore_req()`. In `ahash_do_req_chain()`, verify `crypto_ahash_statesize(tfm) <= HASH_MAX_STATESIZE`, `crypto_ahash_need_fallback(tfm)`, and `!crypto_hash_no_export_core(tfm)` before invoking the sync fallback, and restore `ahash_request_set_tfm(req, tfm)` before returning. [F34, F37]
- `crypto_drop_spawn()` must return immediately if `spawn->alg` is NULL and only call `crypto_mod_put(spawn->alg)` when `!spawn->registered`. When `crypto_create_tfm_node()` or `__crypto_alloc_tfmgfp()` fails in `init_tfm`/`cra_init` with `-EAGAIN`, it must call `crypto_shoot_alg(alg)`. [F45, F103]
- In async continuation callbacks that preserve `CRYPTO_TFM_REQ_MAY_BACKLOG` (`hmac_finup_done`, `crypto_cts_{encrypt,decrypt}_done`, `async_done_continue`), do not complete the parent request when the continuation returns either `-EINPROGRESS` or `-EBUSY`. In `essiv_aead_crypt()`, initialize `rctx->assoc = NULL` and free it synchronously only when `err != -EINPROGRESS && err != -EBUSY`. [F224, F284]

## External Contracts

- In `crypto/crypto_user.c`, verify `type <= CRYPTO_MSG_MAX` before indexing `crypto_msg_min`/`crypto_dispatch` by `type - CRYPTO_MSG_BASE`, check `netlink_capable(skb, CAP_NET_ADMIN)` on mutating handlers, verify `null_terminated()` on `crypto_user_alg` strings, and zero all netlink report structs with `memset()` and `strscpy()` before `nla_put()`. In `crypto_dump_report()`, increment `pos` only after `crypto_report_alg()` succeeds; on `-EMSGSIZE`, break without incrementing `pos`, save `cb->args[0] = pos`, and return `skb->len`. [F53, F260, F263, F276, F290, F339]

## Known Pitfalls

- Normalize `sg->offset` with `offset_in_page()` before `PAGE_SIZE - offset` in `hash_walk_new_entry()` and `shash_ahash_digest()`. Check bounds before subtracting to avoid underflow: `crypto_aead_decrypt()` (`cryptlen >= authsize`), `_aead_recvmsg()` (`aead_sufficient_data()` and `used >= outlen - usedpages`), `{adiantum,hctr2}_crypt()` / `crypto_cts_{encrypt,decrypt}()` / `crypto_cbc_decrypt_inplace()` (`cryptlen >= bsize`), `echainiv_{encrypt,decrypt}()` (`cryptlen >= ivsize`), `essiv_aead_crypt()` (`(int)(req->assoclen - ivsize) >= 0`), `poly_genkey()` (`rctx->assoclen >= 8` when `ivsize == 8`), `crypto_rfc4309/4106_{encrypt,decrypt}()` (`assoclen` 16 or 20), and `crypto_ccm_init_crypt()` (`req->iv[0]` in `1..7`). [F73, F80, F81, F82, F264, F265, F266, F267, F268, F269, F271]
- In `crypto_ccm_req_priv_ctx`, `crypto_gcm_req_priv_ctx`, and `hctr2_request_ctx`, the hash and skcipher subrequests share a union `u`, so stages must be strictly serialized and re-initialized. In `crypto_rfc{4106,4543,4309}_crypt()` and `crypto_cts_reqctx_space()`, offset past `subreq` using the child transform's `reqsize`, never the parent's. [F229, F287]
- Preserve input/IV state before in-place ops overwrite it: `crypto_cts_decrypt()` must save the final IV into `crypto_cts_reqctx_space(req)` before `crypto_skcipher_decrypt(subreq)`; `echainiv_encrypt()` must read `nseqno` before zeroing/overwriting `info`; `crypto_ccm_decrypt()` must copy `req->iv` to `pctx->idata` for CTR so `req->iv` remains intact for `crypto_ccm_auth()`; and `le128_{add,sub}()` must snapshot `v1->b` and `v2->b` before writing `r->b`. [F107, F245, F246, F247]
- In `crypto_acomp_{compress,decompress}()`, `return` the result of `tfm->{compress,decompress}(req)` on the direct branch instead of falling through to `acomp_do_req_chain()`. In `ahash_def_finup_finish1()`, call `crypto_ahash_alg(tfm)->final(req)` directly rather than `crypto_ahash_final(req)`. In `hmac_setkey_ahash()`, bind `HASH_REQUEST_ON_STACK(req, fb)` to `fb = crypto_ahash_fb(tctx->hash)`, not the async child `tctx->hash`. [F92, F93, F292]
