# EDAC-CORE

EDAC-CORE (`drivers/edac/`, `include/linux/edac.h`) provides the core Error Detection and Correction framework for memory controllers (`edac_mc`), generic ECC devices (`edac_device`), PCI parity (`edac_pci`), polling workqueues, debugfs error injection, and RAS sysfs features (scrub, ECS, and memory repair), along with hardware EDAC drivers.

## Architecture & Data Flow

- In `struct edac_dev_sysfs_attribute`, `struct edac_dev_sysfs_block_attribute`, and `struct edac_pci_dev_attribute`, `struct attribute attr` must remain the first member at offset 0 because sysfs handlers cast directly between `struct attribute *` and the outer struct without `container_of()`. [F78]
- In `edac_dev_register()`, the first-pass `attr_gcnt` sum across `ras_features[]` must match the exact number of `attribute_group` pointers populated in the second pass (1 for scrub/mem_repair, `ecs_info.num_media_frus` for ECS), and `ras_attr_groups` must be allocated with `attr_gcnt + 1` entries for the NULL sentinel. [F76]
- In `ecs.c`, `mem_repair.c`, and `scrub.c`, attribute enums, `dev_attr[]` tables, and `*_attr_visible()` switch cases must stay in 1-to-1 correspondence. Descriptor creation must copy attributes into heap-allocated per-instance/per-FRU `edac_*_dev_attr` structs (with `instance`/`fru_id` set and `scrub_attrs` sized to `SCRUB_MAX_ATTRS + 1`), never pointing `group->attrs` at stack memory or plain `device_attribute`s. [F58, F59, F219, F257, F258]
- `edac_mc_alloc_dimms()` and `edac_get_dimm()` must use the same row-major flattening order across `mci->layers[0..n_layers-1]` and keep `mci->dimms[idx]->idx == idx`, because `edac_get_dimm()` checks `mci->dimms[index]->idx != index` and `mci_for_each_dimm()` advances via `(dimm)->idx + 1`. [F61]
- `dynamic_csrow_dimm_attr[]` and `dynamic_csrow_ce_count_attr[]` must be extended in lockstep because `csrow_dev_is_visible()` is shared by both groups and bounds-checks `idx` against `ARRAY_SIZE(dynamic_csrow_ce_count_attr) - 1`. [F57]
- `add_mc_to_global_list()`, `add_edac_dev_to_global_list()`, and `add_edac_pci_to_global_list()` must keep `mc_devices`, `edac_device_list`, and `edac_pci_list` sorted in ascending index order (`mc_idx`, `dev_idx`, `pci_idx`) so stopping at the first `>=` entry detects duplicates. [F100]
- In `skx_common.c`, `skx_dev` is allocated via `struct_size(d, imc, imc_num)` with `d->imc[]` indexed by logical IMC (`0..d->num_imc - 1`). Physical IMC IDs from `adxl_decode()` must be converted via `skx_get_mc_mapping()` (after checking `res->imc >= 0`), and drivers skipping absent IMCs must call `skx_set_mc_mapping(d, pmc, lmc)`. [F208, F226, F252, F254]
- Every constant before `INDEX_MAX` in `skx_common.h` must match `component_names[]`, with optional near-memory components at or after `INDEX_NM_FIRST`. `skx_adxl_decode()` must check `adxl_nm_bitmap` before indexing `adxl_values[]` with `component_indices[INDEX_NM_*]`, and on `GNR` (`skx_res_cfg` set via `skx_set_res_cfg()`) when `err_src == ERR_SRC_2LM_FM` and `adxl_values[component_indices[INDEX_MEMCTRL]] == -1`, switch `err_src` to `ERR_SRC_2LM_NM`. [F215, F228, F265]

## Synchronization

- Callers of `__find_mci_by_dev()` and `add_mc_to_global_list()` must hold `mem_ctls_mutex`; `find_edac_device_by_dev()` and `add_edac_dev_to_global_list()` require `device_ctls_mutex`; `find_edac_pci_by_dev()` and `add_edac_pci_to_global_list()` require `edac_pci_ctls_mutex`. `edac_mc_reset_delay_period()` must hold `mem_ctls_mutex` and verify `mci->op_state == OP_RUNNING_POLL` before calling `edac_mod_work()`. [F26, F154]
- `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` must set `op_state = OP_OFFLINE` and remove the controller from its global list using `list_del_rcu()` + `synchronize_rcu()` before `INIT_LIST_HEAD()` under the subsystem mutex, and must unlock that mutex before calling `edac_stop_work()` / `edac_device_workq_teardown()` (which must finish before sysfs removal). [F10, F20, F23]
- Delayed polling work is initialized only when `edac_check` is non-NULL, after sysfs creation succeeds and `op_state = OP_RUNNING_POLL` is set under the subsystem mutex; drivers must set `edac_check` before registration and never change its nullness before removal. [F25, F44]
- `edac_mc_handle_error()` overwrites the single per-controller `mci->error_desc` buffer and increments non-atomic counters without internal locking; drivers must not invoke it concurrently on the same `struct mem_ctl_info`. [F156]
- In `altera_edac.c`, regmaps used in `irq_chip` callbacks, IRQ handlers, or panic notifiers (`s10_edac_dberr_handler`) must have `.fast_io = true`. In debugfs triggers, `get_user()` and blocking allocations (`priv->alloc_mem`, `dma_alloc_coherent`) must complete before `local_irq_save()`/`local_irq_disable()`. [F158, F159]
- In `pnd2_edac.c`, all hardware configuration registers must be cached during `get_registers()` in `pnd2_probe()`; `ops->rd_reg` (`apl_rd_reg` / `dnv_rd_reg`) must never be called from the MCE notifier path (`pnd2_mce_check_error`). [F193]

## Object Lifetimes

- `mci->dev` is initialized in `edac_mc_alloc()` and owned by the caller until `edac_mc_free()`: `edac_create_sysfs_mci_device()` must not call `put_device(&mci->dev)` if `device_add()` fails, and `edac_remove_sysfs_mci_device()` must call `device_del(&mci->dev)` rather than `device_unregister(&mci->dev)`. [F1]
- `csrow_release()` and `dimm_release()` must remain no-ops because `mci->csrows`, `csr->channels`, and `mci->dimms` are freed in `mci_release()`, and `mci_for_each_dimm()` dereferences `(dimm)->idx` after each loop iteration body. [F3, F91, F117]
- Once `edac_device_register_sysfs_main_kobj()` succeeds in `edac_device_alloc_ctl_info()`, the `struct edac_device_ctl_info` must be freed via `edac_device_free_ctl_info()`, never `__edac_device_free_ctl_info()` or `kfree()`. `dev_ctl->blocks` is a single contiguous allocation across instances, so `__edac_device_free_ctl_info()` must only `kfree(ci->blocks)` and never `kfree(inst->blocks)`. [F6, F116]
- Under `mem_ctls_mutex`, `edac_mc_add_mc_with_groups()` must only set `edac_mc_owner = mci->mod_name` after `add_mc_to_global_list()` and `edac_create_sysfs_mci_device()` succeed, and `edac_mc_del_mc()` must clear `edac_mc_owner = NULL` when `del_mc_from_global_list(mci)` returns true. [F11]
- In `skx_base.c`/`skx_common.c`, `skx_adxl_get()` error paths and `skx_adxl_put()` must reset `adxl_component_count = 0` when freeing `adxl_values`/`adxl_msg`. If `skx_register_mci()` fails after `imc->mci = mci`, it must free `mci->ctl_name`, call `edac_mc_free(mci)`, and reset `imc->mci = NULL`; `skx_unregister_mci()` must call `edac_mc_del_mc()` before `kfree(mci->ctl_name)` and `edac_mc_free(mci)`. [F172, F173, F174]
- When iterating PCI devices with `pci_get_device(..., prev)` in `get_all_munits()` and `skx_get_all_bus_mappings()`, any `pdev` saved into `struct skx_dev` must take an extra reference via `pci_dev_get(pdev)` before `prev = pdev`, and any early loop exit must call `pci_dev_put(pdev)`. [F244]

## API Contracts

- `find_mci_by_dev()` and `edac_mc_find()` return borrowed `struct mem_ctl_info *` pointers, whereas `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` return detached controllers that the caller must free with the matching `*_free*()` helper. [F12]
- `edac_queue_work()`, `edac_mod_work()`, and `round_jiffies_relative()` take jiffies, whereas `edac_device_reset_delay_period()` and `edac_device_workq_setup()` take milliseconds, must convert via `msecs_to_jiffies()`, and must update `edac_dev->poll_msec` and `edac_dev->delay` in lockstep. [F49, F64]
- Work items on `edac-poller` (`edac_check` callbacks) run under `WQ_MEM_RECLAIM` and must not do `GFP_KERNEL` allocations or flush non-`WQ_MEM_RECLAIM` workqueues. `edac_pci_do_parity_check()`, `edac_pci_handle_pe()`, and `edac_pci_handle_npe()` require sleepable context with IRQs enabled because `for_each_pci_dev()` may sleep. [F157, F272]
- In `edac_mc_handle_error()` and `edac_raw_mc_handle_error()`, `page_frame_number` is a PFN, `offset_in_page` is a byte offset, and `e->grain` is a non-zero byte granularity (clamped to `1` before `fls_long(e->grain - 1)`). Direct callers of `edac_raw_mc_handle_error(e)` must pass `&mci->error_desc` with non-NULL `e->msg` and `e->other_detail`. [F45, F107, F168]
- In `struct edac_device_ctl_info`, `sysfs_attributes` must be NULL-terminated (`attr.name == NULL`), whereas `edac_device_block.block_attributes` is bounded by `block->nr_attribs`. `off_val` in `edac_device_alloc_ctl_info()` only offsets sysfs block names; `edac_device_handle_ce/ue*()` always take 0-based `inst_nr` and `block_nr`. [F77, F79]
- Heap-allocated `struct attribute`s in `ecs.c`, `mem_repair.c`, and `scrub.c` must be initialized with `sysfs_attr_init()`, and `edac_scrub_get_desc()` stores a devm-managed `&scrub_ctx->group` in `attr_groups[0]` that callers must not `kfree()`. [F163, F188]
- `GET_BITFIELD(v, lo, hi)` in `skx_common.h` and `pnd2_edac.c` takes `lo` before `hi` (`lo <= hi`, opposite of `GENMASK_ULL`). [F209]

## Error Handling

- For child `dimm_info` and `csrow_info` devices in `edac_mc_sysfs.c`, `edac_create_dimm_object()` and `edac_create_csrow_object()` must call `put_device()` when `device_add()` fails, while post-registration teardown in `edac_create_csrow_objects()`, `edac_delete_csrow_objects()`, and `edac_remove_sysfs_mci_device()` must check `device_is_registered()` and call `device_unregister()`. [F2, F99]
- In `edac_mc_sysfs_init()` and `edac_dev_register()`, if `device_register()` fails on `mci_pdev` or `&ctx->dev`, the error path must call `put_device()` and return without jumping to manual `kfree()` labels (`data_mem_free`), because `mc_attr_release()` and `edac_dev_release()` free the allocations. Errors in `edac_dev_register()` before `device_register(&ctx->dev)` must unwind via `data_mem_free`. [F4, F5, F42]
- `edac_device_create_instance()`, `edac_device_create_block()`, and `edac_pci_create_instance_kobj()` must take a `kobject_get()` reference on the parent controller's main kobject before `kobject_init_and_add()`, because the child kobject's `.release` callback calls `kobject_put()` on it. [F8]
- `edac_device_add_device()` and `edac_pci_add_device()` return `0` on success and positive `1` on failure (callers must check `!= 0` and return a negative errno from probe), whereas `edac_mc_add_mc_with_groups()` returns `0` or a negative errno. `edac_mc_alloc()`, `edac_device_alloc_ctl_info()`, and `edac_pci_alloc_ctl_info()` return `NULL` on failure (not `ERR_PTR`). [F35, F36, F200]
- In drivers using `devres_open_group()` (`fsl_mc_err_probe`, `altr_sdram_probe`, `altr_edac_a10_device_add`, `altr_portb_setup`, `mpc85xx_*_err_probe`), probe failure after registration must delete the EDAC controller and call `devres_release_group()` before `edac_mc_free()`/`edac_device_free_ctl_info()` so devm IRQs referencing `mci`/`dci` are freed first. [F13, F43, F135, F184]
- `skx_get_all_bus_mappings()` returns `< 0` on error, `0` when no sockets are found, and `> 0` on success; callers must treat `<= 0` as failure. In `skx_mce_check_error()`, `res` must be zero-initialized, `res.addr` validated with `pfn_to_online_page() || arch_is_platform_page()`, and both `driver_decode` and `res.dev->imc[res.imc].mci` NULL-checked. [F202, F207, F290]

## Known Pitfalls

- `edac_mc_add_mc_with_groups()` compares `edac_mc_owner != mci->mod_name` by pointer equality, so a driver registering multiple `struct mem_ctl_info` instances must pass the exact same `mod_name` string pointer for every instance. [F166]
- `edac_mc_handle_error()` reuses `mci->error_desc` and must zero it with `memset()` and normalize `e->msg` and `e->other_detail` to `""`. If `n_labels > EDAC_MAX_LABELS`, reset `p = e->label` and `*p = '\0'`. When `edac_get_dimm()` returns `NULL`, `edac_inc_ue_error()` must increment `ue_noinfo_count` and `edac_inc_ce_error()` must increment `ce_noinfo_count`. [F66, F67, F94]
- In `ecs.c`, `mem_repair.c`, and `scrub.c`, sysfs handlers invoke `ops->cb()` without NULL checks, and every read-write attribute in `*_attr_visible()` is gated on its getter before adding `S_IWUSR` if its setter is non-NULL. In `ecs.c` and `mem_repair.c`, `dev_get_drvdata()` must be called on `ras_feat_dev` (`&ctx->dev`), whereas `ops->cb()` takes `ras_feat_dev->parent` and `ctx->ecs.private` or `ctx->mem_repair[inst].private` (not `ctx->private`). [F46, F97, F165]
- In `edac_mc_alloc_dimms()` and `edac_create_csrow_objects()`, the reverse-loop counters `layer` and `i` must remain signed `int` because both loops terminate on `>= 0`. After `list_for_each()` in `edac_mc_find()` or `list_for_each_entry()` in `skx_adxl_decode()`, the loop cursor is non-NULL on miss (`edac_mc_find()` must reset `mci = NULL`; `skx_adxl_decode()` must check `res->dev` before using `d`). [F84, F92, F243]
- `for_each_set_bit()` requires an `unsigned long` bitmap (`bits` in `altr_edac_a10_irq_handler()`, `chan_mask` in `pnd2_edac.c`), never a cast `u32 *` or `u8 *`. Use 64-bit casts/literals (`1ULL`, `U64_LSHIFT()`) before shifts in `fsl_mc_check()` (after checking `bad_data_bit >= 0` / `bad_ecc_bit >= 0`), `i5100_npages()`, `skx_get_dimm_info()`, and `pnd2_edac.c` region calculations. [F106, F111, F113, F248, F249, F264]
- In `i3200_edac`, `i82860_edac`, `i82875p_edac`, and `x38_edac`, `ERRSTS` must be read before (`errsts`) and after (`errsts2`) reading error log registers, re-reading the logs before clearing `ERRSTS` if error bits changed, and testing UE before CE. In `get_pci_parity_status()`, ignore `status == 0xFFFF` if config dword 0 is `0xFFFFFFFF`, and mask `status` to parity/SERR bits before writing it back. [F68, F69, F102, F224]
