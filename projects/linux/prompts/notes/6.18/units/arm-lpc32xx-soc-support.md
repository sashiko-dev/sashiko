# ARM/LPC32XX SOC SUPPORT

This component provides architecture support and core peripheral drivers for NXP LPC32xx and PNX4008 ARM SoCs, including static I/O mapping, IRAM detection, UART setup and errata workarounds, suspend-to-RAM via IRAM execution, DMA request multiplexing (`lpc32xx-dmamux`), I2C bus mastering (`i2c-pnx`), Ethernet MAC/MDIO (`lpc_eth`), OHCI USB host (`ohci-nxp`), and watchdog timer/reset (`pnx4008_wdt`).

## Architecture & Data Flow

- Because entering LPC32xx direct-run and halt modes stops DDR clocks and puts DRAM in self-refresh, `lpc32xx_pm_enter` must back up `TEMP_IRAM_AREA`, copy `lpc32xx_sys_suspend_sz` bytes from `&lpc32xx_sys_suspend`, call `flush_icache_range` and `flush_cache_all`, execute from IRAM, and restore IRAM afterward; all instructions, literal words, and scratch data (`tmp_stack`) must be PC-relative and precede `ENTRY(lpc32xx_sys_suspend_sz)` in `suspend.S`. [F80, F101]
- In `lpc_eth_hard_start_xmit`, in-flight TX descriptors must be capped at `ENET_TX_DESC - 1` (`pldat->num_used_tx_buffs >= (ENET_TX_DESC - 1)`) so `LPC_ENET_TXPRODUCEINDEX` never wraps onto `LPC_ENET_TXCONSUMEINDEX`; `pldat->num_used_tx_buffs` must be reset to `0` with `pldat->last_tx_idx = readl(LPC_ENET_TXCONSUMEINDEX(pldat->net_base))` in `__lpc_eth_init`, incremented once per queued packet, and decremented once per slot advanced by `pldat->last_tx_idx` in `__lpc_handle_xmit`. [F8, F55]
- In `__lpc_handle_recv`, if `prxstat->statusinfo` has `RXSTATUS_ERROR` set and `RXSTATUS_RANGE` is the only bit set within `RXSTATUS_STATUS_ERROR`, `RXSTATUS_ERROR` must be cleared before checking `ethst & RXSTATUS_ERROR` so range-only status reports are treated as valid frames; every loop iteration (including hardware RX errors and `dev_alloc_skb` failures) must advance `rxconsidx` modulo `ENET_RX_DESC`, write `LPC_ENET_RXCONSUMEINDEX`, and increment `rx_done`. [F63, F64]
- In `i2c_pnx_master_rcv`, dummy TX writes (`alg_data->mif.order`) are tracked separately from received RX bytes (`alg_data->mif.len`): when `I2C_REG_STS` has `mstatus_rfe` set, it must only write a dummy byte to `I2C_REG_TX`, decrement `mif.order` if non-zero, and return without reading `I2C_REG_RX` or decrementing `mif.len`; when `mif.order == 1`, it must set `stop_bit` on the dummy write, enable `mcntrl_rffie | mcntrl_daie`, and clear `mcntrl_drmie` in `I2C_REG_CTL(alg_data)`. [F45, F65]
- In `i2c_pnx_master_xmit`, a zero-length message (`alg_data->mif.len == 0`) must still call `i2c_pnx_stop`, mask `mcntrl_afie | mcntrl_naie | mcntrl_drmie` in `I2C_REG_CTL`, and call `complete(&alg_data->mif.complete)`. [F66]
- In `i2c_pnx_xfer`, each loop iteration must reinitialize `alg_data->mif` (`buf`, `len`, `order`, `mode`, `ret`, `complete`) and set `alg_data->last = (i == num - 1)` before enabling master interrupts and calling `i2c_pnx_start`, and must stop iterating as soon as `rc < 0`. [F67]
- In `pnx4008_wdt_start`, under `io_lock`, the driver must write `RESET_COUNT` to `WDTIM_CTRL(wdt_base)` and poll until `readl(WDTIM_COUNTER(wdt_base))` reaches 0 before writing `WDTIM_MCTRL`, `WDTIM_MATCH0`, and `COUNT_ENAB | DEBUG_EN` to `WDTIM_CTRL(wdt_base)`. [F51]
- In `drivers/dma/lpc32xx-dmamux.c`, `lpc32xx_muxes` uses sparse hardware DMA request numbers (`signal` 3, 10, 11, 14, 15), so `lpc32xx_dmamux_reserve` must look up `dma_spec->args[0]` by scanning `lpc32xx_muxes[i].signal` rather than indexing `lpc32xx_muxes` directly. [F53]
- `__lpc_txrx_desc_setup` must recompute all interior ring pointers (`tx_desc_v`, `tx_stat_v`, `tx_buff_v`, `rx_desc_v`, `rx_stat_v`, `rx_buff_v`), descriptor `.packet` physical addresses via `__va_to_pa`, and MAC descriptor base registers together whenever `__lpc_eth_init` initializes the controller. [F49]
- Whenever `lpc_handle_link_change` updates `pldat->speed`, `pldat->duplex`, or `pldat->link` under `pldat->lock` (setting `speed = 0` and `duplex = -1` when `!phydev->link`), it must call `__lpc_params_setup(pldat)` to reprogram `LPC_ENET_MAC2`, `LPC_ENET_COMMAND`, `LPC_ENET_IPGT`, and `LPC_ENET_SUPP`. [F48]
- In `lpc_eth_drv_suspend`, when `netif_running(ndev)` is true, after `netif_device_detach(ndev)`, `__lpc_eth_shutdown(pldat)`, and `clk_disable_unprepare(pldat->clk)`, `__lpc_eth_reset(pldat)` must be called a second time so `EMC_MDC` is held down. [F95]
- In `__lpc_set_mac` and `__lpc_get_mac`, the 6-byte MAC address maps in descending register order (`mac[0..1]` in `LPC_ENET_SA2`, `mac[2..3]` in `LPC_ENET_SA1`, `mac[4..5]` in `LPC_ENET_SA0`), with even-indexed bytes in bits `0..7` and odd-indexed bytes in bits `8..15`. [F58]
- In `lpc_eth_set_multicast_list`, the 6-bit multicast CRC index `hash_val` (`(ether_crc(6, ha->addr) >> 23) & 0x3F`) must be split at 32 between `hashlo` (`1 << hash_val`) and `hashhi` (`1 << (hash_val - 32)`) so each 32-bit shift exponent stays in `0..31`. [F73]
- In `lpc_eth_hard_start_xmit`, `skb->len` bytes are copied into the `ENET_MAXF_SIZE` (1536-byte) slot at `pldat->tx_buff_v + txidx * ENET_MAXF_SIZE`, so `ndev->max_mtu` must not allow frames larger than `ENET_MAXF_SIZE` unless the slot stride and `dma_buff_size` are enlarged. [F79]
- In `lpc_eth.c`, `platform_set_drvdata(pdev, ndev)` stores `struct net_device *` while `pldat->mii_bus->priv = pldat` stores `struct netdata_local *`, so `platform_get_drvdata` / `dev_get_drvdata` callers must retrieve `struct net_device *` first and pass it to `netdev_priv`. [F81]
- In `lpc_mdio_read` and `lpc_mdio_write`, busy-wait loops polling `LPC_MIND_BUSY` must check deadline expiration with `time_after(jiffies, timeout)` rather than direct relational comparison on `jiffies`. [F75]
- In `lpc32xx_return_iram`, when `iram_size == 0` and the words at `LPC32XX_IRAM_BASE` and `LPC32XX_IRAM_BASE + LPC32XX_IRAM_BANK_SIZE` match, the probe write of `savedval2 + 1` to `iramptr2` must be followed by restoring `savedval2` to `iramptr2` before returning. [F39]
- `lpc32xx_set_phy_interface_mode` and `lpc32xx_loopback_set` must update `LPC32XX_CLKPWR_MACCLK_CTRL` and `LPC32XX_UARTCTL_CLOOP` via read-modify-write of only `LPC32XX_CLKPWR_MACCTRL_PINS_MSK` or `(1 << bit)`, preserving clock-enable and sibling UART loopback bits. [F41]
- In `lpc32xx_serial_init`, `LPC32XX_UARTCTL_CLKMODE` must be written only after every UART in `uartinit_data` has its clock enabled and pre-divider (`pdiv_clk_reg`) set, and `LPC32XX_UART_U5_ROUTE_TO_USB` in `LPC32XX_UARTCTL_CTRL` must be cleared so USB can operate. [F92]

## Synchronization

- Because hardirq handler `__lpc_eth_interrupt` acquires `pldat->lock` (`struct netdata_local::lock`), any non-hardirq context acquiring `pldat->lock` must use `spin_lock_irq` or `spin_lock_irqsave`; specifically, `lpc_eth_hard_start_xmit` must hold `spin_lock_irq(&pldat->lock)` across checking `num_used_tx_buffs`, populating the TX descriptor/buffer at `LPC_ENET_TXPRODUCEINDEX`, incrementing `num_used_tx_buffs`, writing `LPC_ENET_TXPRODUCEINDEX`, and calling `netif_stop_queue`. [F20, F97]
- `i2c_pnx_interrupt`, `i2c_pnx_master_xmit`, `i2c_pnx_master_rcv`, and `i2c_pnx_stop` run in hardirq context and must never call `del_timer_sync` or sleeping functions; `i2c_pnx_stop` must bound its `mstatus_active` poll in `I2C_REG_STS(alg_data)` to at most 1 ms using `udelay(1)` rather than `wait_timeout(alg_data)`. [F90, F96]
- On every transfer completion or error path in `i2c_pnx_interrupt`, `i2c_pnx_master_xmit`, and `i2c_pnx_master_rcv`, master interrupt enable bits in `I2C_REG_CTL(alg_data)` must be cleared and any `alg_data->mif.ret` error stored before calling `complete(&alg_data->mif.complete)`. [F17]
- `dmamux->lock` (`struct lpc32xx_dmamux_data::lock`) must be held across checking/updating `mux->busy`, setting `mux->muxval`, and calling `regmap_update_bits` in `lpc32xx_dmamux_reserve`, and across clearing `mux->busy` in `lpc32xx_dmamux_release`. [F15]
- In `lpc_eth_poll` and `__lpc_handle_recv`, polling must stop when `rx_done` reaches `budget`, and `napi_complete_done(napi, rx_done)` must be called before `lpc_eth_enable_int(pldat->net_base)` and only when `rx_done < budget`. [F21, F103]

## Object Lifetimes

- `lpc32xx_dmamux_reserve` returns a borrowed pointer into static `lpc32xx_muxes` with `mux->busy = true` under `dmamux->lock`, and `lpc32xx_dmamux_release` must only set `mux->busy = false` under `dmamux->lock` without calling `kfree(route_data)`. [F2]
- In `lpc32xx_dmamux_probe`, `dmamux->reg`, `dmamux->lock`, `platform_set_drvdata(pdev, dmamux)`, and `dmamux->dmarouter` (`dev` and `route_free`) must be initialized before `of_dma_router_register` publishes the router. [F14]
- Device Tree `device_node` references from `of_parse_phandle` or `of_get_child_by_name` must be balanced with `of_node_put` (such as `lpc_mii_init` on cleanup and `ohci_hcd_nxp_probe` on `isp1301_node`); in `lpc32xx_dmamux_reserve`, any error path after `of_parse_phandle` populates `dma_spec->np` must call `of_node_put(dma_spec->np)`, whereas the success path must leave `dma_spec->np` held for `of_dma_router_xlate`. [F84, F108]
- In `drivers/usb/host/ohci-nxp.c`, `ohci_hcd_nxp_probe` must call `of_node_put(isp1301_node)` right after `isp1301_get_client(isp1301_node)`, configure `isp1301_i2c_client` via `isp1301_configure()`, and call `ohci_nxp_start_hc()` before `usb_add_hcd`, and must reset `isp1301_i2c_client = NULL` on every probe failure path (`fail_disable`) and in `ohci_hcd_nxp_remove` after `usb_remove_hcd` and `ohci_nxp_stop_hc()` complete. [F10, F24]
- In both `lpc_eth_drv_probe` (`err_out_dma_unmap`) and `lpc_eth_drv_remove`, `dma_free_coherent` must be guarded by `!use_iram_for_net(...) || pldat->dma_buff_size > lpc32xx_return_iram(NULL, NULL)` so the static IRAM mapping is never passed to `dma_free_coherent`. [F6]
- `lpc_eth_hard_start_xmit` must leave `skb` unfreed when returning `NETDEV_TX_BUSY`, and on `NETDEV_TX_OK` must copy `skb->data` into `pldat->tx_buff_v` and call `dev_kfree_skb(skb)` immediately because `__lpc_handle_xmit` does not retain or free `sk_buff` pointers. [F7]
- In `lpc_eth_open`, `phy_resume(ndev->phydev)` must precede `__lpc_eth_reset` and `__lpc_eth_init`; in `lpc_eth_close`, `napi_disable(&pldat->napi)` and `netif_stop_queue(ndev)` must precede `__lpc_eth_reset(pldat)` (under `pldat->lock`) and clearing `LPC_ENET_MAC1`/`LPC_ENET_MAC2`, which must precede `phy_stop(ndev->phydev)`, which in turn must precede `clk_disable_unprepare(pldat->clk)`. [F22, F83]
- In `lpc_eth_drv_remove`, `unregister_netdev(ndev)` must be called before freeing DMA coherent memory, freeing `ndev->irq`, unmapping `pldat->net_base`, unregistering `pldat->mii_bus`, or disabling `pldat->clk`. [F23]
- Before returning from `i2c_pnx_xfer` on either normal completion or an early loop `break`, it must call `bus_reset_if_active(alg_data)` and reset `alg_data->mif.buf = NULL`, `alg_data->mif.len = 0`, and `alg_data->mif.order = 0`. [F12]
- In `i2c_pnx_probe`, every error path after `clk_prepare_enable(alg_data->clk)` must jump to `out_clock` (`clk_disable_unprepare(alg_data->clk)`), and `i2c_pnx_remove` must call `i2c_del_adapter(&alg_data->adapter)` before `clk_disable_unprepare(alg_data->clk)`. [F13]

## API Contracts

- In `lpc32xx_return_iram`, both `mapbase` and `dmaaddr` may be `NULL` (when callers query only IRAM size) so `*mapbase` and `*dmaaddr` writes must be null-checked; when `mapbase` is non-NULL it is populated unconditionally, so `lpc_eth_drv_probe` must reset `pldat->dma_buff_base_v = NULL` if `pldat->dma_buff_size` exceeds the returned IRAM size to fall back to `dma_alloc_coherent`. [F26, F27]
- In `lpc32xx_dmamux_reserve`, `mux->muxval` must store the shifted bitmask `BIT(mux->bit)` (or `0`), and before returning `mux` (or an `ERR_PTR` on failure, never `NULL`) it must rewrite `dma_spec->np` to the `"dma-masters"` node, clear `dma_spec->args[2] = 0`, and set `dma_spec->args_count = 2`. [F29]
- In `drivers/i2c/busses/i2c-pnx.c`, `alg_data->timeout` is stored in jiffies (for `wait_for_completion_timeout`), so millisecond polling helpers `wait_timeout` and `wait_reset` must convert `data->timeout` via `jiffies_to_msecs` and return non-zero (`timeout <= 0`) on timeout. [F30]
- `i2c_pnx_xfer` and `i2c_pnx_start` only support unshifted 7-bit slave addresses (rejecting `I2C_M_TEN` or `slave_addr & ~0x7f` with `-EINVAL`): `i2c_pnx_start` requires `alg_data->mif.mode` to be `I2C_SMBUS_READ` (`1`) or `I2C_SMBUS_WRITE` (`0`) to OR directly with `slave_addr << 1` into `I2C_REG_TX`, and `i2c_pnx_xfer` must return `num` on full completion or a negative errno (`rc < 0 ? rc : -EREMOTEIO`) otherwise. [F32, F107]
- In `lpc_eth.c`, hardware descriptor counts (`LPC_ENET_TXDESCRIPTORNUMBER`, `LPC_ENET_RXDESCRIPTORNUMBER`) and descriptor control lengths (`txrx_desc_t.control`) use `count - 1` / `len - 1` encoding, whereas RX status length in `rx_status_t.statusinfo` requires adding 1 (`(prxstat->statusinfo & RXSTATUS_SIZE) + 1`). [F36]
- In `lpc_eth.c`, `__va_to_pa` computes DMA addresses as `(addr - pldat->dma_buff_base_v) + pldat->dma_buff_base_p`, so every descriptor ring, status array, and packet buffer passed to `__va_to_pa` must reside within `[pldat->dma_buff_base_v, pldat->dma_buff_base_v + pldat->dma_buff_size)`. [F77]
- In `pnx4008_wdt.c`, `pnx4008_restart_handler` must check that `cmd` (`boot_cmd`) is non-NULL before reading `boot_cmd[0]`; `wdd->timeout` is stored in seconds (`1..MAX_HEARTBEAT`, 60s) and `pnx4008_wdt_start` (which also acts as the keepalive ping since `pnx4008_wdt_ops.ping` is unset) must multiply `wdd->timeout` by `WDOG_COUNTER_RATE` (13 MHz) when writing `WDTIM_MATCH0(wdt_base)`. [F38, F109]
- `lpc32xx_loopback_set` only accepts physical base addresses `LPC32XX_HS_UART1_BASE`, `LPC32XX_HS_UART2_BASE`, and `LPC32XX_HS_UART7_BASE`, and must warn and return without touching `LPC32XX_UARTCTL_CLOOP` for any other `mapbase`; its signature and those of `lpc32xx_return_iram` and `lpc32xx_set_phy_interface_mode` must stay in sync with the `!CONFIG_ARCH_LPC32XX` stubs in `include/linux/soc/nxp/lpc32xx-misc.h`. [F52, F69]
- `IO_ADDRESS()` and `io_p2v()` in `arch/arm/mach-lpc32xx/lpc32xx.h` require physical addresses with bits 20–23 equal to zero that fall within the four static `MT_DEVICE` regions mapped by `lpc32xx_map_io()` (`lpc32xx_io_desc`). [F102]
- `lpc32xx_get_uid(u32 devid[4])` unconditionally writes `devid[0..3]`, so every caller must pass a buffer of at least four `u32` words. [F82]

## Error Handling

- In `lpc_mii_init`, any fallible call after `of_mdiobus_register` that jumps to `err_out_unregister_bus` (such as `lpc_mii_probe`) must store its negative error code in `err`, because `of_mdiobus_register` leaves `err == 0` and `err_out_unregister_bus` returns `err`. [F33]
- In `lpc_eth.c`, all paths enabling `pldat->clk` before accessing MAC registers (`lpc_eth_open`, `lpc_eth_drv_probe`, `lpc_eth_drv_resume`) must check the return value of `clk_enable` / `clk_prepare_enable` and abort on error before calling `__lpc_eth_reset` or `__lpc_eth_init`. [F34]
- In `lpc_mii_probe`, `pldat->phy_node` must be checked for `NULL` to select `of_phy_find_device` vs `phy_find_first`, the lookup result must be checked for `NULL`, and the subsequent `phy_connect` result must be checked with `IS_ERR` and converted with `PTR_ERR`. [F35]

## Known Pitfalls

- In `__lpc_txrx_desc_setup`, `tx_desc_v`, `tx_buff_v`, `rx_stat_v`, and `rx_buff_v` are aligned with `PTR_ALIGN(..., 16)` inside `pldat->dma_buff_base_v`, which relies on `lpc_eth_drv_probe` sizing `pldat->dma_buff_size` with `sizeof(struct rx_status_t)` (8 bytes) rather than `sizeof(u32)` (4 bytes) per TX status slot to cover alignment padding. [F57]
- In `lpc_eth.c`, `pldat->tx_buff_v` and `pldat->rx_buff_v` are `void *` pointers addressed by byte offset (`+ idx * ENET_MAXF_SIZE`), whereas `tx_desc_v`, `tx_stat_v`, `rx_desc_v`, and `rx_stat_v` are typed pointers indexed by descriptor index (`[idx]`). [F78]
