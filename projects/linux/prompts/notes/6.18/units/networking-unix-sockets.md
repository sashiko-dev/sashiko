# NETWORKING [UNIX SOCKETS]

Implements BSD and abstract `AF_UNIX` (`PF_UNIX`) sockets supporting `SOCK_STREAM`, `SOCK_DGRAM`, and `SOCK_SEQPACKET`, `SCM_RIGHTS` and `SCM_CREDENTIALS`/pidfd passing, out-of-band (`MSG_OOB`) data, Tarjan's SCC garbage collection (`net/unix/garbage.c`), Netlink `SOCK_DIAG` (`net/unix/diag.c`), procfs/BPF iterators, and per-netns sysctls.

## Architecture & Data Flow

- In `net->unx.table.buckets`, `0..UNIX_HASH_MOD` hold unbound (`u->addr == NULL`) and BSD-bound (`u->addr != NULL`, `u->path.dentry != NULL`) sockets, while `UNIX_HASH_MOD + 1..UNIX_HASH_SIZE - 1` hold abstract sockets (`u->addr != NULL`, `u->path.dentry == NULL`, scoped to `sock_net(sk)`). `__unix_find_socket_byname` assumes `u->addr != NULL`. BSD sockets are also linked by VFS inode into global `bsd_socket_buckets` for cross-netns lookup via `unix_find_bsd()`; `unix_release_sock()` must remove `sk` from both (`unix_remove_socket()`, `unix_remove_bsd_socket()`). [F39, F52, F134]
- Partial `SOCK_STREAM` reads and `unix_stream_recv_urg()` advance `UNIXCB(skb).consumed` without decrementing `skb->len`; callers must query unread length via `unix_skb_len(skb)` and read from `UNIXCB(skb).consumed + skip`. In `unix_release_sock()`, checking `sk->sk_receive_queue` for unread data before setting `skpair->sk_err = ECONNRESET` must skip a leading 0-length consumed OOB marker (`!unix_skb_len(skb)`) via `skb_peek_next()`. [F63, F79]
- In `manage_oob()`, on `!unix_skb_len(skb)` it must return `NULL` only when `copied > 0` and `(!u->oob_skb || skb == u->oob_skb)`; when `copied == 0`, it must advance via `skb_peek_next()` (unlinking `skb` only if `!(flags & MSG_PEEK)`) and fall through to `if (skb != u->oob_skb)`. When `skb == u->oob_skb` with `flags & MSG_PEEK` and `!sock_flag(sk, SOCK_URGINLINE)`, it must advance via `skb_peek_next()` without clearing `u->oob_skb` or unlinking if `copied == 0`, or set `skb = NULL` if `copied > 0`. [F85, F86, F87]
- When queuing an `skb` with `UNIXCB(skb).fp` to `other->sk_receive_queue`, `scm_stat_add(other, skb)` must be called under `unix_state_lock(other)` after all error checks. When consuming without `MSG_PEEK`, `scm_stat_del(sk, skb)` must precede `unix_detach_fds()` so `fp->inflight` is cleared before `unix_destroy_fpl()`. `fpl->edges` has `fpl->count_unix` entries (NULL when 0), so `unix_add_edges()` and `unix_del_edges()` must check `if (!fpl->count_unix) goto out;` before looping. [F55, F82]
- In `__unix_gc()`, every `skb` on `hitlist` with `UNIXCB(skb).fp` must have `UNIXCB(skb).fp->dead = true` set before `__skb_queue_purge_reason(&hitlist, ...)`, and `unix_del_edge()` / `unix_del_edges()` must gate `edge->successor` access on `!fpl->dead` rather than `gc_in_progress`. [F56]
- Adding/removing an inflight edge (`unix_add_edge()`, `unix_del_edge()`) or accepting an embryo with `scm_stat.nr_unix_fds != 0` (`unix_update_edges()`) must call `unix_update_graph()` under `unix_gc_lock` to set `unix_graph_maybe_cyclic = true` and `unix_graph_grouped = false` if the target `vertex` is non-NULL. `unix_add_edge()` must initialize `vertex->index` to `unix_vertex_unvisited_index` (swapped between 0 and 1 by `unix_walk_scc()`, while DFS indices start at `UNIX_VERTEX_INDEX_START` = 2). [F58, F83]
- Embryo sockets from `unix_stream_connect()` have `sk_socket == NULL` and `u->listener != NULL` until `unix_accept()` calls `sock_graft()`; peer paths (`unix_maybe_add_creds`, `unix_dgram_sendmsg`, `unix_edge_successor`) must not dereference `other->sk_socket` unconditionally, and both `unix_create()` and `unix_accept()` must set `SOCK_CUSTOM_SOCKOPT` on `sock->flags` / `newsock->flags` for `SOCK_STREAM`. [F40, F74]
- In `unix_dgram_sendmsg()`, if `sock_flag(other, SOCK_DEAD)` is seen, it must never clear `unix_peer(sk)` or set `sk->sk_state = TCP_CLOSE` when `sk->sk_type == SOCK_SEQPACKET` (`SOCK_STREAM` and `SOCK_SEQPACKET` never leave `TCP_ESTABLISHED`/`TCP_LISTEN` until `unix_release_sock()`). If `unix_state_unlock(other)` is dropped to acquire `unix_state_double_lock(sk, other)` on a full queue, it must set `sk_locked = 1` and jump to `restart_locked` to re-validate `unix_may_send()`, `SOCK_DEAD`, `RCV_SHUTDOWN`, `sk_scm_rights`, and `security_unix_may_send()`. [F67, F68]
- `unix_stream_read_generic()` is called with `state->msg == NULL` from `unix_stream_splice_read()`, so it must guard all `msg` dereferences with `if (msg)` and call `scm_destroy(&scm)` in the `else` branch. [F41]

## Synchronization

- Lock hierarchy: `unix_gc_lock` nests inside `unix_state_lock()`, and `sk->sk_receive_queue.lock` nests inside both (`__unix_gc()` must unlock `unix_gc_lock` before purging `hitlist`). Across two sockets, `unix_state_double_lock()` locks in ascending `struct sock *` order (except `unix_stream_connect()` may lock a `TCP_LISTEN` `other` before `sk` if it checks `sk->sk_state == TCP_CLOSE` before and after locking `sk`); `sk_receive_queue.lock` nests from `TCP_LISTEN` listener to embryo; two `net->unx.table.locks` buckets must use `unix_table_double_lock()`. [F22, F23, F25, F119]
- `__unix_set_addr_hash()` must hold `u->bindlock` and `unix_table_double_lock(net, old_hash, new_hash)` to remove `sk` from its old bucket, populate `struct unix_address` and `u->path`, publish `u->addr` with `smp_store_release()` (also required in `unix_stream_connect()`), update `sk->sk_hash`, and re-insert `sk`. Lockless readers (`unix_getname()`, `unix_copy_addr()`, `unix_open_file()`, `sk_diag_dump_name()`) must read `u->addr` with `smp_load_acquire()`. [F18, F51]
- `unix_wait_for_peer(other, timeo)` consumes and releases the caller's `unix_state_lock(other)` before sleeping while keeping the caller's `sock_hold(other)` reference; callers must not unlock `other` after it returns and must still call `sock_put(other)`. [F8]
- `unix_state_lock(sk)` does not serialize `sk->sk_receive_queue` dequeues/unlinks: without `sk->sk_receive_queue.lock`, queue checks must use `skb_queue_len_lockless()`, `unix_recvq_full_lockless()`, or `skb_queue_empty_lockless()`. In `sk_diag_dump_icons()`, `sk->sk_receive_queue.lock` must be held continuously across reading `qlen` for `nla_reserve()` and walking the queue. All `u->inq_len` updates must hold `sk->sk_receive_queue.lock` and use `WRITE_ONCE()`, paired with `READ_ONCE(u->inq_len)` in unlocked readers. [F28, F29, F84]
- Because `af_unix` does not hold `lock_sock(sk)` against `sock_setsockopt()` and reads state outside `unix_state_lock(sk)`, unlocked reads of `sk->sk_state`, `sk->sk_shutdown`, `sk->sk_sndbuf`, and `net->unx.sysctl_max_dgram_qlen` must use `READ_ONCE()`, paired with `WRITE_ONCE()` on updates. [F32]
- In `unix_release_sock()`, `unix_remove_socket()` and `unix_remove_bsd_socket()` must unhash `sk` before acquiring `unix_state_lock(sk)` to set `SOCK_DEAD` via `sock_orphan(sk)`, and `unix_dgram_connect()` / `unix_stream_connect()` must recheck `sock_flag(other, SOCK_DEAD)` after locking `other`. In `unix_stream_connect()`, `newsk` fields, credentials, address, and `sock_hold(newsk)` + `smp_mb__after_atomic()` must complete before `unix_peer(sk) = newsk` is assigned under `unix_state_lock(sk)`. [F19, F20]
- `update_peercred()` and `copy_peercred()` must hold `sk->sk_peer_lock`, and `copy_peercred(sk, peersk)` must also hold `unix_state_lock(peersk)`. `prepare_peercred()`, `drop_peercred()`, and `unix_maybe_add_creds()` may sleep (`pidfs_register_pid()`, `put_pid()`, `put_cred()`) and must only run in process context outside spinlocks; `unix_listen()` must call `drop_peercred(&peercred)` after `unix_state_unlock(sk)` on both success and failure paths. [F10, F31, F115]
- `u->peer_wake.private` holds the peer `struct sock *` on whose `peer_wait` queue `u->peer_wake` is linked (updated under `unix_sk(other)->peer_wait.lock`). `unix_dgram_peer_wake_me(sk, other)` requires holding `unix_state_lock(sk)` and verifying `unix_peer(sk) == other`; `unix_dgram_peer_wake_disconnect()` must precede `sock_put()` on an old peer; `unix_dgram_peer_wake_relay()` runs under `peer_wait.lock` so it must use lockless `__remove_wait_queue()` and never sleep. [F66, F112, F113]
- In `unix_stream_read_generic()` and `unix_stream_recv_urg()`, `unix_state_lock(sk)` and `sk->sk_receive_queue.lock` must be dropped before `state->recv_actor`, while `u->iolock` stays held across blocking copies. [F122]

## Object Lifetimes

- In `unix_scm_to_skb()` and `unix_attach_fds()`, once `too_many_unix_fds()` succeeds, `scm->fp` ownership moves to `UNIXCB(skb).fp` (`scm->fp = NULL`) and `skb->destructor = unix_destruct_scm` must be set even if `unix_prepare_fpl()` fails, so `consume_skb()` cleans up `UNIXCB(skb).fp` and `UNIXCB(skb).pid`. [F1]
- `unix_add_edge()` moves a pre-allocated `struct unix_vertex` from `fpl->vertices` to `unix_unvisited_vertices` only when `edge->predecessor->vertex == NULL`; when `vertex->out_degree` reaches 0, `unix_del_edge()` must clear `edge->predecessor->vertex = NULL` and move `vertex->entry` back to `fpl->vertices` for `unix_destroy_fpl()` rather than freeing under `unix_gc_lock`. [F3]
- `unix_sk(sk)->oob_skb` is a borrowed pointer to an `sk_buff` on `sk->sk_receive_queue` (not an extra ref): it must be cleared to `NULL` under `sk->sk_receive_queue.lock` when consumed in `unix_stream_recv_urg()`, unlinked in `manage_oob()`, or dequeued in `unix_stream_read_skb()` (which decrements `u->inq_len` by `skb->len` and frees an OOB `skb` with `-EAGAIN`), and cleared in `unix_release_sock()`. [F5, F64]
- When `unix_stream_recv_urg()` consumes `oob_skb` without `MSG_PEEK`, it leaves `oob_skb` queued with `UNIXCB(oob_skb).consumed` incremented to 1, and if `oob_skb->prev != (struct sk_buff *)&sk->sk_receive_queue` and `!unix_skb_len(oob_skb->prev)`, it must unlink `oob_skb->prev` under `sk_receive_queue.lock` and free it after unlocking. [F6, F110]
- `unix_find_other()` and `unix_peer_get()` return a `sock_hold()` reference; any retry/error path in `unix_dgram_connect()`, `unix_stream_connect()`, or `unix_dgram_sendmsg()` must unlock and `sock_put(other)` before overwriting `other` or exiting. In `unix_stream_connect()`, `init_peercred(newsk, &peercred)` transfers `peercred` to `newsk` and `skb` is queued on success, while error paths must unwind via `sock_put(other)`, `consume_skb(skb)`, `unix_release_sock(newsk, 0)`, and `drop_peercred(&peercred)`. [F7, F9]
- In `unix_bind_bsd()`, any error after `vfs_mknod()` succeeds (e.g., `mutex_lock_interruptible(&u->bindlock)` or `u->addr != NULL`) must roll back the created node via `vfs_unlink()` before `end_creating_path(&parent, dentry)` and `unix_release_addr(addr)`. [F12]
- In `unix_stream_bpf_update_proto()`, when `!restore && !psock->sk_pair`, it must take `sock_hold(unix_peer(sk))` into `psock->sk_pair` (and not re-increment if already set, nor drop it synchronously when `restore` is true). [F14]
- In the BPF iterator, `bpf_iter_unix_hold_batch()` takes `sock_hold()` on `iter->batch[0..iter->end_sk - 1]` and drops `net->unx.table.locks[bucket]`; `bpf_iter_unix_seq_show()` must acquire `lock_sock_fast(sk)` and skip `sk_unhashed(sk)` sockets, and `bpf_iter_unix_seq_stop()` / `bpf_iter_unix_realloc_batch()` must release unconsumed batch references (`iter->cur_sk..iter->end_sk - 1`) via `bpf_iter_unix_put_batch()`. [F15, F33]

## API Contracts

- Low-level lookups (`__unix_find_socket_byname`, `unix_find_socket_byname`, `unix_find_socket_byinode`, `unix_lookup_by_ino`, `unix_peer_get`) return `NULL` on miss, whereas `unix_find_bsd`, `unix_find_abstract`, `unix_find_other`, and `unix_create1` return an `ERR_PTR` and never `NULL`. [F34]
- `unix_read_skb()` and `unix_stream_read_skb()` transfer ownership of the dequeued `sk_buff` to `recv_actor(sk, skb)` and must not free `skb` afterwards. `struct unix_stream_read_state`'s `recv_actor` must return positive bytes transferred or a negative errno (`unix_stream_read_actor` converts `skb_copy_datagram_msg`'s `0` into `ret ?: chunk`). [F13, F37]
- `unix_inq_len()` returns `-EINVAL` (signed `long`) when `sk->sk_state == TCP_LISTEN` and a non-negative byte count otherwise; callers must check `< 0` (`unix_ioctl`) or exclude `TCP_LISTEN` (`sk_diag_show_rqlen`). [F35]
- `unix_get_socket(filp)` must verify `S_ISSOCK(inode->i_mode) && !(filp->f_mode & FMODE_PATH)` as well as `sk && ops && ops->family == PF_UNIX`, because `O_PATH` fds opened on socket files (`SIOCUNIXFILE`) have `S_ISSOCK` set. [F38]
- Callers of `unix_mkname_bsd()` (`unix_bind_bsd()`, `unix_find_bsd()`) must validate `addr_len <= sizeof(struct sockaddr_un)` via `unix_validate_addr()` and pass a `sunaddr` backed by `struct sockaddr_storage`, and `unix_mkname_bsd()` must NUL-terminate and call `strlen()` via `((struct sockaddr_storage *)sunaddr)->__data`. [F73]

## Error Handling

- Stack `struct unix_peercred` in `unix_listen()` and `unix_stream_connect()` must be zero-initialized (`= {}`) at declaration before any path can reach `drop_peercred(&peercred)`, and stack `struct scm_cookie scm` in `__unix_dgram_recvmsg()`, `unix_stream_read_generic()`, and `unix_destruct_scm()` must be zeroed via `memset(&scm, 0, sizeof(scm))` before any path can reach `scm_recv_unix()` or `scm_destroy()`. [F43, F44]
- In `unix_stream_sendmsg()` and `unix_stream_read_generic()`, accumulated positive bytes take precedence over errors (`return sent ? : err;` / `return copied ? : err;`), and `unix_stream_sendmsg()` only sends `SIGPIPE` when `!sent`. In `unix_accept()`, when `skb_recv_datagram()` returns `NULL` on a listening socket with `RCV_SHUTDOWN` set, `arg->err` is `0` and must be rewritten to `-EINVAL`. [F36, F47]

## External Contracts

- In `unix_stream_read_generic()`, `check_creds` must be armed on the first `skb` when `unix_may_passcred(sk)` holds so subsequent iterations break if `!unix_skb_scm_eq(skb, &scm)`, and the loop must also break after populating `scm.fp` (`unix_detach_fds` / `unix_peek_fds`), preventing coalescing across credential or `SCM_RIGHTS` boundaries. `unix_maybe_add_creds()` must attach `UNIXCB(skb)` credentials when `unix_may_passcred(sk)`, `unix_may_passcred(other)`, or `!other->sk_socket` (embryo), calling `pidfs_register_pid()` first. [F95, F131]
- In `unix_ioctl()`, `SIOCATMARK` must set `answ = 1` both when head `skb == oob_skb` and when `!unix_skb_len(skb) && (!oob_skb || next_skb == oob_skb)`. [F89]

## Known Pitfalls

- In `unix_stream_read_generic()`, the `again:` label must precede `manage_oob()`, and a `NULL` return from `manage_oob()` must break out of the loop immediately only when `copied > 0` (so `copied == 0` falls through to wait/error handling). Also, `skip` must be clamped via `max(sk_peek_offset(sk, flags), 0)` before `while (skip >= unix_skb_len(skb))` because `unix_skb_len()` returns `unsigned int`. [F88, F101]
- In `__unix_walk_scc()` and `unix_walk_scc_fast()`, the stack `struct list_head scc` spliced into the circular `vertex->scc_entry` ring must be unlinked via `list_del(&scc)` before going out of scope, and `list_for_each_entry_reverse()` over `&scc` must use a separate cursor `v` rather than `vertex` (`prev_vertex:` reads `vertex` after the loop). `unix_unvisited_vertices` must be drained with `while (!list_empty(&unix_unvisited_vertices))` and `list_first_entry()`, not `list_for_each_entry_safe()`, because each pass moves an entire multi-vertex SCC. [F60, F90, F92]
- `unix_from_bucket()` uses 1-based intra-bucket offsets (`*pos == 0` is `SEQ_START_TOKEN`), so advancing to a bucket in `unix_get_first()`, `unix_get_next()`, or `bpf_iter_unix_batch()` must use `set_bucket_offset(bucket, 1)`, and `bucket` must be `unsigned long` or `loff_t` because `set_bucket_offset(b, o)` shifts `b` left by `BUCKET_SPACE` (54 bits on 64-bit). [F78, F99]
- `unix_autobind()` must allocate `struct unix_address` with `kzalloc()` and include at least 1 extra byte beyond `addr->len` (`offsetof(struct sockaddr_un, sun_path) + 6`) because `sprintf(addr->name->sun_path + 1, "%05x", ordernum)` relies on `sun_path[0] == 0` and writes a trailing NUL at `sun_path[6]`. Both `lastnum = ordernum & 0xFFFFF` and `ordernum = (ordernum + 1) & 0xFFFFF` must be masked with `0xFFFFF`. [F45, F102, F106]
