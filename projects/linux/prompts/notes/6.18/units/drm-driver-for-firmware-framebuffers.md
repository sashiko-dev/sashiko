# DRM DRIVER FOR FIRMWARE FRAMEBUFFERS

This component registers early-boot system framebuffer platform devices from `screen_info` (`sysfb`), manages aperture ownership hand-off to native GPU drivers (`aperture`), and provides the `drm_sysfb` helper library and four shadow-buffered DRM drivers (`simpledrm`, `efidrm`, `vesadrm`, and `ofdrm`).

## Architecture & Data Flow
- In `efidrm_device_create()`, `vesadrm_device_create()`, `simpledrm_device_create()`, and `ofdrm_device_create()`, `sysfb->fb_format` must be initialized before `drm_mode_config_reset(dev)` (which sets `sysfb_crtc_state->format`), and `drm_mode_config_reset(dev)` must precede `drm_dev_register()`. `drm_sysfb_crtc_atomic_duplicate_state()` must copy `sysfb_crtc_state->format` because `ofdrm` and `vesadrm` CRTC `.atomic_flush` callbacks dereference it during CRTC-only color-management commits. [F21, F43]
- In `vesadrm_primary_plane_helper_atomic_check()`, switching `new_sysfb_crtc_state->format` between `DRM_FORMAT_RGB332` (emulating `DRM_FORMAT_XRGB8888`) and `sysfb->fb_format` (`DRM_FORMAT_C8`) must set `new_crtc_state->color_mgmt_changed = true`, and `vesadrm_fill_palette_lut()` and `vesadrm_crtc_helper_atomic_flush()` must handle both `DRM_FORMAT_C8` and `DRM_FORMAT_RGB332`. [F42, F73]
- In `sysfb_create_simplefb()`, `efidrm_device_create()`, and `vesadrm_device_create()`, resource creation, aperture acquisition, and memory region requests for `screen_info` framebuffers must use the page-aligned visible scanout size (`PAGE_ALIGN(height * stride)`) after verifying it does not exceed advertised VRAM size, rather than `si->lfb_size` or `resource_size(res)`. [F56]
- In `simpledrm_device_init_clocks()`, `simpledrm_device_init_regulators()`, and `simpledrm_device_create()`, when `dev_get_platdata(&pdev->dev)` is non-NULL, the driver must use `struct simplefb_platform_data` and skip parsing `pdev->dev.of_node` properties, clocks, and regulators. [F105]
- In `ofdrm.c`, `sysfb->fb_gamma_lut_size` and `drm_crtc_enable_color_mgmt()` must only be enabled when `odev->cmap_base` is non-NULL, and every `struct ofdrm_device_funcs` with `.cmap_ioremap` must also set `.cmap_write`. `ofdrm_device_fill_gamma()` and `ofdrm_device_load_gamma()` must cover both little-endian and big-endian formats returned by `display_get_validated_format()` (`DRM_FORMAT_RGB565 | DRM_FORMAT_BIG_ENDIAN` and `DRM_FORMAT_BGRX8888` as well as `DRM_FORMAT_RGB565` and `DRM_FORMAT_XRGB8888`). [F51, F72]
- In `ofdrm.c`, `get_cmap_address_of()` must verify `(offset + size) < max_size` against the BAR size before translating the address and calling `devm_ioremap()`. `ofdrm_rage_m3a_cmap_write()` and `ofdrm_rage_m3b_cmap_write()` share palette registers at `cmap_base + 0xb0`/`0xb4` and must read-modify-write bit `0x20` (`PALETTE_ACCESS_CNTL`) in `DAC_CNTL` (`cmap_base + 0x58`) before writing `addr` and `data`. [F50, F62]

## Synchronization
- In `aperture_detach_devices()`, `ap->dev` must be sampled and set to `NULL` and `ap->lh` deleted from `apertures` before calling `ap->detach(dev)` under `apertures_lock`, so the synchronous `devm_aperture_acquire_release()` callback sees `!ap->dev` and returns early without deadlocking on `apertures_lock` or double-deleting `ap->lh`. [F45]
- In `devm_aperture_acquire()`, `apertures_lock` must be held continuously across the `overlap()` check over `apertures` and the `list_add(&ap->lh, &apertures)` insertion, and released before calling `devm_add_action_or_reset()`. [F16]
- `sysfb_disable()` must never be called under `apertures_lock`, and `aperture_remove_conflicting_devices()` and `aperture_remove_conflicting_pci_devices()` must call `sysfb_disable()` before `aperture_detach_devices()`. [F18]
- `aperture_remove_conflicting_devices()` must call `sysfb_disable(NULL)` unconditionally (not guarded by `CONFIG_FB`), and in `sysfb.c`, `disable_lock` must be held across checking `disabled` and registering `pd` in `sysfb_init()`, and across calling `sysfb_unregister()` (which must reset `pd = NULL` after `platform_device_unregister(pd)`) and setting `disabled = true` in `sysfb_disable()`. In `sysfb_disable()`, `sysfb_unregister()` and `disabled = true` must execute when `!parent` (`sysfb_parent_dev(si)` returns `NULL`) as well as when `!dev || dev == parent`. [F4, F17, F48, F66]

## Object Lifetimes
- All four `drm_sysfb` drivers (`efidrm`, `ofdrm`, `simpledrm`, `vesadrm`) must call `drm_dev_unplug()` in `.remove`, and `drm_sysfb_plane_helper_atomic_update()` and `drm_sysfb_plane_helper_atomic_disable()` must guard `sysfb->fb_addr` accesses with `drm_dev_enter()` / `drm_dev_exit()`. In `drm_sysfb_plane_helper_atomic_update()`, once `drm_gem_fb_begin_cpu_access(fb, DMA_FROM_DEVICE)` succeeds, every exit path—including when `drm_dev_enter()` returns false—must call `drm_gem_fb_end_cpu_access(fb, DMA_FROM_DEVICE)` after exiting the `drm_dev_enter()` section. [F7, F98]
- In `sysfb_parent_dev()`, when `screen_info_pci_dev(si)` returns a non-NULL `pdev`, `sysfb_pci_dev_is_enabled(pdev)` must verify `PCI_COMMAND_MEMORY` is set in `PCI_COMMAND` and otherwise call `pci_dev_put(pdev)` and return `ERR_PTR(-ENODEV)`. In `sysfb_init()`, if `IS_ERR(parent)`, set `ret = PTR_ERR(parent)` and jump to `unlock_mutex`; if `parent` is `NULL`, proceed with `parent == NULL`; if non-NULL, call `put_device(parent)` on every exit path, including after `sysfb_create_simplefb()` or `platform_device_add()` succeeds. [F2, F23, F93]
- In `ofdrm_device_init_pci()`, `pcidev` from `display_get_pci_dev_of()` must never be managed with `pcim_*` or `devm_*` helpers on `pcidev`; register `ofdrm_pci_release` (`pci_disable_device(pcidev)`) on `&pdev->dev` via `devm_add_action_or_reset()`. [F99]
- In `simpledrm_device_create()`, `devm_drm_dev_alloc()` must precede `simpledrm_device_init_clocks()` and `simpledrm_device_init_regulators()` so their `devm_add_action_or_reset()` release callbacks run before `drmm_kzalloc()` frees `sdev->clks` and `sdev->regulators` on `drm_device` release. [F108]
- In `simpledrm_device_attach_genpd()` and `simpledrm_device_detach_genpd()`, `sdev->pwr_dom_count <= 1` must be a no-op, and for `pwr_dom_count > 1`, `simpledrm_device_detach_genpd()` must call `device_link_del(sdev->pwr_dom_links[i])` before `dev_pm_domain_detach(sdev->pwr_dom_devs[i], true)` in reverse order. [F107]
- In `efidrm_device_create()` and `vesadrm_device_create()`, `drm_sysfb_get_memory_si()` returns the caller's stack-allocated `resbuf` (which `mem` also aliases when `devm_request_mem_region()` fails), so neither `res` nor `mem` may be stored past probe. In `ofdrm.c`, `display_get_edid_of()` returns its `u8 buf[EDID_LENGTH]` argument directly to be stored in `sysfb->edid`, so callers must pass a device-lifetime buffer (`odev->edid`), not a stack buffer. [F87, F88]
- In `drm_sysfb_crtc_reset()` and `drm_sysfb_crtc_atomic_destroy_state()`, `struct drm_sysfb_crtc_state` must be destroyed via `drm_sysfb_crtc_state_destroy()`, which calls `__drm_atomic_helper_crtc_destroy_state(&sysfb_crtc_state->base)` before `kfree()`. In `drm_sysfb_connector_helper_get_modes()`, free the `struct drm_edid *` from `drm_edid_read_custom()` with `drm_edid_free()` after `drm_edid_connector_update()`. [F8, F9]
- In `ofdrm.c` and `simpledrm.c`, every Device Tree node reference from `of_get_parent()` (in `display_get_model_of()` and `ofdrm_avivo_cmap_ioremap()`) or `of_parse_phandle()` (for `"panel"` in `simpledrm_device_create()`) must be released with `of_node_put()`. [F103]
- `sysfb_init()` must remain at `device_initcall` level (or later) so PCI is initialized before EFI quirks and `screen_info_pci_dev()` run; `sysfb_apply_efi_quirks()` must run before `sysfb_parse_mode()` and `platform_device_add_data()`, while `sysfb_set_efifb_fwnode(pd)` must run between `platform_device_alloc()` and `platform_device_add()`. [F90, F92]

## API Contracts
- `drm_sysfb_get_validated_int()` (which must clamp `u32 max` with `min(max, INT_MAX)`) and `drm_sysfb_get_validated_int0()` (and their `*_si`, `*_pd`, and `*_of` wrappers) return negative errno values on failure, so callers must store results in signed `int` variables and check `< 0` before assigning to unsigned fields. In `simpledrm.c` and `ofdrm.c`, `stride` / `linebytes` must use `drm_sysfb_get_validated_int()` (defaulting 0 to `drm_format_info_min_pitch(format, 0, width)`), whereas `width`, `height`, and `depth` must use `drm_sysfb_get_validated_int0()`. [F26, F57, F79]
- `drm_sysfb_get_stride_si()` must compute the maximum stride with `div64_u64(size, height)` after `drm_sysfb_get_height_si()` validates `height > 0`. All `drm_sysfb_get_*_si` helpers require `CONFIG_SCREEN_INFO`. [F78, F127]
- `drm_sysfb_get_format_si()` (and `efidrm_get_format_si()`, `vesadrm_get_format_si()`) returns `NULL` on failure, whereas `simplefb_get_validated_format()` (and `simplefb_get_format_pd()`, `simplefb_get_format_of()`) and `display_get_validated_format()` return an `ERR_PTR` and never `NULL`. [F27]
- `efidrm`, `vesadrm`, and `ofdrm` store `struct drm_device *` (`&sysfb->dev`) in platform drvdata, whereas `simpledrm` stores `struct simpledrm_device *` (`sdev`) in both platform drvdata and `devm_add_action_or_reset()` data (`simpledrm_device_release_clocks`, `simpledrm_device_release_regulators`, `simpledrm_device_detach_genpd`); callbacks must cast to that exact type. [F40, F80]
- When `simpledrm_device_create()` probes via `of_node`, it must check `simplefb_get_memory_of()` (`"memory-region"`, mapped via `devm_memremap()` and `iosys_map_set_vaddr()`) before falling back to `platform_get_resource(pdev, IORESOURCE_MEM, 0)` (mapped via `devm_ioremap_wc()` and `iosys_map_set_vaddr_iomem()`). [F104]
- `vesadrm`'s `vesa->cmap_write` takes 16-bit color values (`u16`) and shifts right by 8 internally, whereas `ofdrm`'s `odev->funcs->cmap_write` takes 8-bit values (`unsigned char`) already shifted right by 8 in `ofdrm_set_gamma_lut()`. `drm_sysfb_crtc_helper_atomic_check()` rejects a non-NULL `gamma_lut` unless `gamma_lut->length == sysfb->fb_gamma_lut_size * sizeof(struct drm_color_lut)`. [F37, F53]
- Drivers using `drm_sysfb_build_fourcc_list()` must size `formats` with `DRM_SYSFB_PLANE_NFORMATS(num_native)` and pass the returned `nformats` (not `ARRAY_SIZE()`) to `drm_universal_plane_init()`. Planes using `drm_sysfb_plane_helper_atomic_check` or `drm_sysfb_plane_helper_atomic_update` must use `DRM_GEM_SHADOW_PLANE_FUNCS` and `DRM_GEM_SHADOW_PLANE_HELPER_FUNCS`. [F55, F120]
- `drm_sysfb_plane_helper_get_scanout_buffer()` runs from `drm_panic` in atomic/panic context under `dev->mode_config.panic_lock` and must not sleep, allocate memory, or take sleeping locks. [F115]
- Callers determining the firmware video type from `struct screen_info` must call `screen_info_video_type(si)` instead of reading `si->orig_video_isVGA` directly. [F91]

## Error Handling
- In `sysfb_create_simplefb()` and `sysfb_init()`, once `platform_device_alloc()` succeeds, any failure in `platform_device_add_resources()`, `platform_device_add_data()`, or `platform_device_add()` must unwind with `platform_device_put(pd)`. [F3]
- `simplefb_get_memory_of()` returns `NULL` when `"memory-region"` is absent (requiring fallback to `IORESOURCE_MEM`), `ERR_PTR(-ENOMEM)` on allocation failure (aborting probe), or a valid `struct resource *`; initialize `mem = NULL` in `simpledrm_device_create()`. In `efidrm`, `vesadrm`, and `simpledrm`, a `NULL` return from `devm_request_mem_region()` must fall back to `mem = res` rather than failing probe. [F28, F35]
- In `drm_sysfb_plane_helper_atomic_disable()`, `plane_state->crtc` is `NULL`, so read format and pitch from `sysfb->fb_format` and `sysfb->fb_pitch` instead of calling `drm_atomic_get_new_crtc_state()`. In `drm_sysfb_plane_helper_atomic_check()` and `vesadrm_primary_plane_helper_atomic_check()`, `new_plane_state->crtc` and `new_plane_state->fb` may be `NULL` until `drm_atomic_helper_check_plane_state()` succeeds and `new_plane_state->visible` is true. [F29, F30]
- In `simpledrm` clock, regulator, and genpd init, only `-EPROBE_DEFER` aborts probe; other errors log, call `clk_put()` / `regulator_put()`, and continue. Never store `ERR_PTR` in `sdev->clks` (leaving `NULL` holes in `0..clk_count-1`) or `sdev->regulators` (compacted into `sdev->regulator_count`) since release callbacks only test `if (ptr)`, whereas `sdev->pwr_dom_devs[i]` stores `ERR_PTR` and requires `!IS_ERR_OR_NULL()` in `simpledrm_device_detach_genpd()`. [F38, F39, F69, F106]
- In `vesadrm_device_create()`, check `__screen_info_vesapm_info_base(si)` for non-zero before calling `phys_to_virt()`, and only set `sysfb->fb_gamma_lut_size` when `vesa->cmap_write` is non-NULL. In `efidrm_device_create()`, initialize `screen_base = NULL` before the `mem_flags` chain. In `ofdrm_device_create()`, `cmap_ioremap` callbacks and `get_cmap_address_of()` return `IOMEM_ERR_PTR(...)` (not `NULL`), so check `!IS_ERR(cmap_base)` on a local variable before setting `odev->cmap_base`. [F33, F34, F36]

## External Contracts
- In `__aperture_remove_legacy_vga_devices()` and `aperture_remove_conflicting_pci_devices()`, detach conflicting devices and `VGA_FB_PHYS_BASE` via `aperture_detach_devices()` before calling `vga_remove_vgacon(pdev)`. In `sysfb_init()` and `sysfb_create_simplefb()`, pass device ID `0` to `platform_device_alloc(..., 0)`. [F22, F94]
- In `drm_sysfb_get_edid_block()`, `sysfb->edid` holds a single 128-byte `EDID_LENGTH` block; after verifying `block * EDID_LENGTH + len <= EDID_LENGTH` and copying into `buf`, add `buf[126]` to `buf[127]` and zero `buf[126]`. In `vesadrm.c`, `vesa->pmi.PrimaryPalette` is `(u8 *)pmi_addr + pmi_addr[2]`, and `vesadrm_pmi_cmap_write()` must pass `{ blue >> 8, green >> 8, red >> 8, 0x00 }` in `%edi` and `&vesa->pmi.PrimaryPalette` in `%esi` for `call *(%%esi)`. [F54, F65]

## Known Pitfalls
- In `drm_sysfb_plane_helper_atomic_disable()`, shift 16.16 fixed-point `plane_state->src_x`, `src_y`, `src_w`, and `src_h` right by 16 (`>> 16`) when initializing `dst_clip`. In `efidrm_get_mem_flags()`, only allow `EFI_MEMORY_WT` or `EFI_MEMORY_WB` when `efi_enabled(EFI_MEMMAP)` is true, `efi_mem_desc_lookup(start, &md)` succeeds, and `start + len <= md.phys_addr + (md.num_pages << EFI_PAGE_SHIFT)`. [F64, F102]
- In `simpledrm_device_init_regulators()`, both `for_each_property_of_node()` loops must filter with `p = strstr(prop->name, SUPPLY_SUFFIX)` and `p && p != prop->name`, and pass `len = strlen(prop->name) - strlen(SUPPLY_SUFFIX) + 1` to `strscpy(name, prop->name, min(sizeof(name), len))`. Reverse cleanup loops over unsigned `i` in `simpledrm.c` must use `while (i) { --i; ... }` (and `simpledrm_device_detach_genpd()` must return early when `sdev->pwr_dom_count <= 1`). [F58, F59, F89]
- In `ofdrm.c`, raw OF properties from `of_get_property()` (`vendor-id`, `device-id`) and address cells passed to `of_translate_address()` (`io_of_addr` in `ofdrm_qemu_cmap_ioremap()`) are `__be32` and require `be32_to_cpup()` / `cpu_to_be32()`. For SLOF AVIVO displays (`"vga,Display-"`), read `vendor-id`, `device-id`, and BAR 0 colormap addresses from `of_get_parent(of_node)`. [F60, F74]
- In `ofdrm.c`, `odev->cmap_base` is `void __iomem *`, so `ofdrm_gxt2000_cmap_write()` must cast `odev->cmap_base` to `unsigned int __iomem *` before adding `index`. In `display_get_model_of()`, specific `"ATY,"` prefix checks (`"ATY,Rage128"`, `"ATY,RageM3pA"`, `"ATY,RageM3p12A"`, `"ATY,RageM3pB"`, `"ATY,Rage6"`) must precede the catch-all `of_node_name_prefix(of_node, "ATY,")` check for `OFDRM_MODEL_MACH64`. [F85, F109]
