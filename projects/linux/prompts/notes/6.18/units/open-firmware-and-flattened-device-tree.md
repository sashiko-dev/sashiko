# OPEN FIRMWARE AND FLATTENED DEVICE TREE

The Open Firmware and Flattened Device Tree (OF/DT) subsystem parses early-boot FDT blobs and PROM trees into a reference-counted hierarchy of `struct device_node` and `struct property` objects under `/sys/firmware/devicetree`, providing C/Rust APIs (`include/linux/of*.h`, `rust/kernel/of.rs`) for node/property queries, phandles, OF graphs, NUMA/CPU topology, reserved memory, address/DMA/IRQ translation, device instantiation, and runtime changesets/overlays.

## Architecture & Data Flow
- `of_node_release()` only frees a `struct device_node` and its `properties`/`deadprops` when `OF_DETACHED` and `OF_DYNAMIC` are set and, if `OF_OVERLAY` is set, `OF_OVERLAY_FREE_CSET` was set by `__of_changeset_entry_destroy()` when `kref` was `1`. `OF_DETACHED` must be set before `kref` reaches zero, and `of_node_release()` must never format `node` with `%pOF` when `!OF_DETACHED` because `%pOF` calls `of_node_get(node)` on a zero-refcount kobject. [F11, F33]
- `__of_changeset_entry_apply()` on `OF_RECONFIG_UPDATE_PROPERTY` must save the displaced property in `ce->old_prop` via `__of_update_property()`, and `__of_changeset_entry_invert()` must swap `ce->prop` and `ce->old_prop`—or change `rce->action` to `OF_RECONFIG_REMOVE_PROPERTY` when `ce->old_prop` is `NULL`—to revert. [F60]
- `__of_attach_node()` must set `FWNODE_FLAG_NOT_DEVICE` on `np->fwnode.flags`, and `of_platform_notify()` must clear it on `OF_RECONFIG_CHANGE_ADD` before `of_platform_device_create()`. `of_platform_device_create_pdata()` and `of_amba_device_create()` must atomically gate creation with `of_node_test_and_set_flag(np, OF_POPULATED)` and clear it on failure; `of_platform_device_destroy()` and `of_platform_depopulate()` must clear `OF_POPULATED`/`OF_POPULATED_BUS` and check `dev->bus` (`&platform_bus_type` vs `&amba_bustype`) before downcasting. [F57, F62, F129]
- `of_overlay_remove()` refuses removal (`-EBUSY`) if `overlay_removal_is_ok()` finds overlapping nodes in a later overlay on `ovcs_list`, and only zeroes `*ovcs_id` and calls `free_overlay_changeset(ovcs)` after `OF_OVERLAY_PRE_REMOVE` and `__of_changeset_revert_entries()` succeed (`OF_OVERLAY_POST_REMOVE` errors still revert, free `ovcs`, and zero `*ovcs_id`). If rollback fails in `of_overlay_apply()` or `of_overlay_remove()`, `devicetree_state_flags` (`DTSF_APPLY_FAIL`/`DTSF_REVERT_FAIL`) is set permanently so `devicetree_corrupt()` rejects future calls with `-EBUSY`. [F19, F61, F183]
- In `of_translate_one()`, a missing `rprop` on `parent` stops translation unless `rprop` is `"dma-ranges"` or `of_empty_ranges_quirk(parent)` is true; for empty/quirk 1:1 translation, `offset = of_read_number(addr, na)` must be read before mutating `addr` and only cells after `pbus->flag_cells` zeroed (`memset(addr + pbus->flag_cells, 0, (pna - pbus->flag_cells) * 4)`). In `of_parse_phandle_with_args_map()`, each nexus iteration must update both `initial_match_array[i]` and `out_args->args[i]` before `cur = new`. [F64, F65, F141]
- In `__of_address_resource_bounds()`, check `overflows_type(start, r->start)` and set `r->end` via `check_add_overflow(r->start, size - 1, &r->end)` when `size > 0` or `wrapping_sub(typeof(r->end), r->start, 1)` when `size == 0` so `resource_size(r) == 0`. `"nonposted-mmio"` sets `IORESOURCE_MEM_NONPOSTED`, which `of_iomap()` / `of_io_request_and_map()` must map with `ioremap_np()`. `fdt_scan_reserved_mem()` must reserve all static `reg` nodes before dynamic `size` nodes, and `of_reserved_mem_region_to_resource()` must set `res->flags = IORESOURCE_MEM`. [F45, F75, F131, F147]
- Update `action_names[]`, `of_overlay_action_name[]`, and `!CONFIG_OF*` stubs in `include/linux/of.h` and `drivers/of/of_private.h` in lockstep with `drivers/of/` APIs; `!CONFIG_OF` stubs for `of_property_read_variable_u{8,16,32,64}_array()`, `of_property_read_string_helper()`, `__of_parse_phandle_with_args()`, and `of_phandle_iterator_next()` must return negative errnos, not `0`. [F73, F74, F220]

## Synchronization
- `of_mutex` nests outside `devtree_lock` (`raw_spin_lock_irqsave()`). `devtree_lock` protects live hierarchy pointers (`parent`, `child`, `sibling`), `properties`/`deadprops`, and `phandle_cache` (pinning nodes with `of_node_get()` before unlocking), and must be released before calling any `__of_*_sysfs()` helper. Internal `__of_*` lookup helpers do not take `devtree_lock` and require `devtree_lock` held or an `OF_DETACHED` tree. [F23, F24, F29, F187]
- `of_mutex` must be held across all live tree mutations, sysfs updates, and post-boot `aliases_lookup` traversals, and nests inside `of_overlay_phandle_mutex` (`of_overlay_mutex_lock()`). In `__of_detach_node()`, setting `OF_DETACHED` and calling `__of_phandle_cache_inv_entry(np->phandle)` must both happen under `devtree_lock` before `__of_detach_node_sysfs()`. `of_resolve_phandles()` requires an `OF_DETACHED` tree with `of_overlay_phandle_mutex` held across resolution and attachment, and `adjust_overlay_phandles()` must update `overlay->phandle` and `phandle`/`linux,phandle` properties in lockstep. [F16, F27, F56, F68, F190]
- `__of_changeset_apply_notify()` and `__of_changeset_revert_notify()` are entered with `of_mutex` held, must unlock `of_mutex` before calling `__of_changeset_entry_notify()`, and re-lock `of_mutex` before returning. Conversely, `of_overlay_notifier_register()` callbacks run while `of_mutex` is held and must never acquire `of_mutex` or `of_overlay_mutex_lock()`. `of_reserved_mem_device_release()` must drop `of_rmem_assigned_device_mutex` before calling `rd->rmem->ops->device_release()`. [F14, F158, F279]

## Object Lifetimes
- Non-scoped iterative node helpers (`of_find_all_nodes`, `of_find_node_by_*`, `of_find_compatible_node`, `of_find_matching_node_and_match`, `of_find_node_with_property`, `of_get_next_*`, `of_graph_get_next_*`) call `of_node_put()` on `prev`/`from` and `of_node_get()` on the returned node: callers must call `of_node_put()` on early loop exit, and callers passing a borrowed `from` must call `of_node_get(from)` first. Scoped iterators (`for_each_*_scoped`, `for_each_child_of_node_with_prefix`, `for_each_of_graph_port*`) use `__free(device_node)`, so callers must not call `of_node_put()` on break and must use `return_ptr()`/`no_free_ptr()` to keep the node. [F1, F174, F176, F244]
- `__of_find_node_by_path()` increments the returned node's refcount, and `__of_find_node_by_full_path()` consumes the caller's reference on `node` while returning an owned reference. Callers of `of_parse_phandle*()` must call `of_node_put()` on the returned node or `out_args->np`; `of_phandle_iterator_next()` drops the prior `it->node` on each step and on error, so early exits from `of_for_each_phandle()` must `of_node_put(it.node)`. In `of_resolve_phandles()`, `local_fixups`, `tree_symbols`, and each `refnode` must be released on all paths. [F2, F3, F22, F261]
- `of_irq_parse_raw()` increments the resolved `out_irq->np` refcount without dropping the caller's initial `out_irq->np` (so `of_irq_parse_one()` must drop its initial `p` and callers of `of_irq_parse_one()` must `of_node_put(out_irq->np)`), and when a self-referencing `interrupt-map` entry matches (`ipar == newpar`), `of_irq_parse_raw()` must call `of_node_put(ipar)` because `of_irq_parse_imap_parent()` already acquired a second reference in `out_irq->np`. [F4, F5]
- In `of_irq_init()`, each `struct of_intc_desc` on `intc_desc_list` owns references to `desc->dev` and `desc->interrupt_parent`; nodes are initialized parent-first setting `OF_POPULATED` before `desc->irq_init_cb()` and clearing `OF_POPULATED` on error, and if `irq_init_cb()` fails or `intc_parent_list` becomes empty, both `desc->interrupt_parent` and `desc->dev` must be `of_node_put()` before `kfree(desc)`. [F6, F109, F134]
- `__of_remove_property()` and `__of_update_property()` move removed/replaced `struct property` objects to `np->deadprops` until `of_node_release()`. Because `__of_changeset_entry_destroy()` does not free `ce->prop`, `of_changeset_add_prop_helper()` and `of_changeset_update_prop_helper()` must duplicate stack properties via `__of_prop_dup()`, free `new_pp` with `__of_prop_free()` if adding the entry fails, and on success link `new_pp` onto `np->deadprops`. [F9, F10, F130]
- `of_changeset_create_node()` returns a node with both the creation reference and `of_changeset_action()`'s reference held, so callers must call `of_node_put(np)` in addition to `of_changeset_destroy()`. `of_changeset_destroy()` must call `device_link_wait_removal()` before destroying entries with `list_for_each_entry_safe_reverse()` (which `of_overlay_remove_all()` must also use). `of_find_device_by_node()` and `of_find_i2c_device_by_node()` require `platform_device_put()` or `put_device()`. [F12, F104, F181, F265]

## API Contracts
- `of_find_property()`, `of_get_property()`, `__of_find_property()`, and `__of_get_property()` leave `*lenp` unmodified when returning `NULL`. `of_property_read_u{8,16,32,64}*` and `of_property_read_string*` return borrowed pointers into `prop->value` (for strings) and must not modify output parameters on error; `of_property_read_variable_u*_array`, `of_property_read_string_array`, and `of_property_count_strings` return the positive element count or negative errno, whereas `of_property_read_u*_array` (`sz_min = sz, sz_max = 0`) and `of_property_read_string_index` return `0` on success. [F38, F179, F198, F199, F200, F227, F228]
- `of_translate_address()`, `of_translate_dma_address()`, `__of_translate_address()`, and `of_translate_ioport()` return `OF_BAD_ADDR` (`(u64)-1`) on failure, not `<= 0`. In `__of_translate_address()`, an indirect-IO match (`iorange->flags != LOGIC_PIO_CPU_MMIO`) transfers `dev` into `*host = no_free_ptr(dev)`, requiring `of_node_put(host)`. `of_dma_get_range()` must skip `OF_BAD_ADDR` entries, return `-EINVAL` if `!num_ranges`, and `kcalloc(num_ranges + 1, ...)` for a zero-terminated sentinel. [F8, F40, F86]
- `irq_of_parse_and_map()` returns `unsigned int` `0` on failure, whereas `of_irq_get()`, `of_irq_get_byname()`, and `of_irq_to_resource()` return a signed `int` (`< 0` on error including `-EPROBE_DEFER`, `0` on mapping failure, `> 0` on valid IRQ). `of_iomap()` returns `NULL` on failure, whereas `of_io_request_and_map()` returns `IOMEM_ERR_PTR` (`IS_ERR()`). [F42, F196]
- In `of_map_id()`, when `target` is non-NULL, the refcounted node from `of_find_node_by_phandle()` is stored in `*target` only when `*target == NULL`; if `*target` is already non-NULL, `of_map_id()` drops `phandle_node` and only matches `*target`. In `of_fwnode_get_reference_args()`, when `args == NULL` it must call `of_node_put(of_args.np)` before returning `0`, and when `args != NULL` it must zero-fill `args->args[i]` up to `NR_FWNODE_REFERENCE_ARGS`. [F7, F169]
- In `of_supplier_bindings[]`, `.parse_prop` and `.get_con_dev` callbacks must return refcounted `struct device_node *` pointers (with `.parse_prop` returning the first supplier at `index == 0` and `NULL` once `index` is out of bounds); bindings on non-device subnodes (e.g., `"remote-endpoint"`) must set `.get_con_dev` (which `of_link_property()` passes as `con_dev_np`), and standalone `"interrupt-parent"` must never be parsed as a supplier. [F99, F111, F144, F145, F170]
- `struct device_node::_flags` and `struct property::_flags` are `unsigned long` bitmaps accessed via atomic bitops (`of_node_*_flag()`, `of_property_*_flag()`) using bit indices (`OF_DYNAMIC`..`OF_OVERLAY_FREE_CSET`), not shifted masks. New dynamic nodes require `of_node_init()`. Downcasting `fwnode_handle *` to `device_node *` must use `to_of_node()`/`is_of_node()`, and upcasting a possibly-NULL `device_node *` must use `of_fwnode_handle(node)`, not `&node->fwnode`. [F193, F194, F251, F252, F256]

## Error Handling
- `__of_changeset_apply_entries()` applies forward and rolls back in reverse via `list_for_each_entry_continue_reverse()`, while `__of_changeset_revert_entries()` reverts in reverse and rolls back forward via `list_for_each_entry_continue()`; both keep the primary error in `ret` and write rollback errors only to `*ret_revert` / `*ret_apply`, which callers must initialize to `0`. [F13, F48]
- In `of_overlay_fdt_apply()`, validate `overlay_fdt_size >= sizeof(struct fdt_header)`, `!fdt_check_header(overlay_fdt)`, and `overlay_fdt_size >= fdt_totalsize(overlay_fdt)` before copying to `PTR_ALIGN(new_fdt, FDT_ALIGN_SIZE)` while storing the unaligned `kmalloc` pointer in `ovcs->new_fdt`. Initialize `ovcs->notify_state = OF_OVERLAY_INIT` and `of_changeset_init(&ovcs->cset)` when adding `ovcs` to `ovcs_list`; once `of_overlay_apply()` is called, failure must export `*ret_ovcs_id = ovcs->id` for cleanup via `of_overlay_remove()` rather than calling `free_overlay_changeset(ovcs)` directly. [F37, F47, F80, F124]
- `of_match_bus()` returns `NULL` when no `of_busses[]` entry matches, and bus `.match` callbacks must check `of_property_present(np, "#address-cells")` before `of_bus_n_addr_cells(np)`. In `__of_translate_address()` and `fdt_translate_address()`, validate cell counts with `OF_CHECK_COUNTS(na, ns)` before copying `na * 4` bytes into `addr[OF_MAX_ADDR_CELLS]`. [F43, F82]
- In `of_parse_phandle_with_args_map()`, `of_property_read_u32()` overwrites `ret = 0` inside the loop, so every error `goto put` must set `ret` to a negative errno; when advancing past a phandle cell in `of_parse_phandle_with_args_map()` or `of_irq_parse_imap_parent()`, decrement `map_len`/`len` before checking `len >= addrsize + intsize` and `<= MAX_PHANDLE_ARGS`. [F44, F76]

## Known Pitfalls
- Never format a `struct device_node *` with `%pOF` while holding `devtree_lock`, because `%pOF` calls `of_fwnode_get_parent()` -> `of_get_parent()`, which takes `devtree_lock` and deadlocks. When `%pOF` modifiers (such as `%pOFn` in `of_modalias()`) are followed by an alphanumeric literal, emit the literal via `%c` so it is not parsed as a `%pOF` modifier flag. [F25, F127]
- `struct property.value` stores big-endian cells, requiring `be*_to_cpup()`/`of_read_number()` on read and `cpu_to_be32()` on write. `of_read_number()` and `of_read_ulong()` take `size` in 4-byte cells (`sizeof(__be32)`), not bytes, and advancing `const __be32 *` pointers scales by 4 bytes whereas untyped `const void *` buffers must be advanced by `4 * addr_cells` bytes; variable-size properties like `"linux,initrd-start"`/`"linux,initrd-end"` must be read with `of_read_number(prop, len / 4)`. [F50, F78, F92, F120, F121]
- In `of_find_node_opts_by_path()` and `__of_find_node_by_path()`, bound alias and component names by both `'/'` and `':'` (`strcspn(path, "/:")`) so `:options` suffixes are not matched as node names, and always clear `*opts = NULL` when no `':'` is present. [F77, F218]
