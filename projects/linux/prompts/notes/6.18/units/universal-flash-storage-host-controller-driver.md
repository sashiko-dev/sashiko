# UNIVERSAL FLASH STORAGE HOST CONTROLLER DRIVER

`drivers/ufs/core/ufshcd.c` implements the Universal Flash Storage Host Controller Driver (UFSHCD) core, bridging the SCSI mid-layer and blk-mq subsystem with UFSHCI hardware controllers across Legacy Single Doorbell (SDB) and Multi-Circular Queue (MCQ) modes, UniPro/UIC link management, error recovery, and runtime/system power management.

## Architecture & Data Flow
- Code shared between SDB and MCQ modes (`ufshcd_is_ufs_dev_busy()`, `ufshcd_eh_timed_out()`) must check active SCSI commands via `scsi_host_busy(hba->host)`, not `hba->outstanding_reqs`. Shifting by `task_tag`/`tag` (e.g., `1U << task_tag`) and accessing `hba->outstanding_reqs` must only execute when `!hba->mcq_enabled`, as MCQ `task_tag` can exceed 31. [F70, F122]
- `host->can_queue` must be `hba->nutrs - UFSHCD_NUM_RESERVED` and `hba->reserved_slot` must be `hba->nutrs - 1`. When `ufshcd_alloc_mcq()` changes `hba->nutrs` from `old_nutrs`, it must free SDB queues using `old_nutrs` (`ufshcd_release_sdb_queue()`), reallocate via `ufshcd_memory_alloc()`, refresh LRB pointers via `ufshcd_host_memory_configure()`, and on any failure jump to `err:` to restore `hba->nutrs = old_nutrs`. [F60, F92, F130]
- In `ufshcd_hold()`, the switch on `hba->clk_gating.state` must fall through from `REQ_CLKS_OFF` (when `cancel_delayed_work()` fails) to `CLKS_OFF` (queuing `ungate_work`) and `REQ_CLKS_ON`; both `REQ_CLKS_ON` and `CLKS_ON` (when the link is in hibern8) must drop `clk_gating.lock`, `flush_work(&hba->clk_gating.ungate_work)`, relock, and jump to `start`. Setting `CLKS_ON` in `ufshcd_setup_clocks()` requires `hba->clk_gating.is_initialized`, and setting `CLKS_OFF` in `ufshcd_suspend()` requires `ufshcd_is_clkgating_allowed(hba)`. [F72, F108]
- During error-handler task abort (`ufshcd_abort_one()`, `ufshcd_try_to_abort_task()`), never complete aborted commands directly via `ufshcd_release_scsi_cmd()` or `scsi_done()`; `ufshcd_abort_all()` completes them via `ufshcd_complete_requests(hba, false)` so `ufshcd_transfer_rsp_status()` maps `OCS_ABORTED` to `DID_REQUEUE`. [F76]
- Before dispatching any transfer or task management request (`ufshcd_prepare_req_desc_hdr()`, `ufshcd_issue_tm_cmd()`, `ufshcd_exec_raw_upiu_cmd()`), `header.ocs` must be initialized to `OCS_INVALID_COMMAND_STATUS` and, for transfer requests, `lrbp->ucd_rsp_ptr` must be zeroed. In `ufshcd_prepare_utp_query_req_upiu()`, `ucd_req_ptr->header.data_segment_length` must be set to `cpu_to_be16(len)` only for `UPIU_QUERY_OPCODE_WRITE_DESC` and `0` otherwise. [F63, F102]
- Bounds checks: `ufshcd_copy_query_response()` and `ufshcd_issue_devman_upiu_cmd()` must check buffer length >= `be16_to_cpu(lrbp->ucd_rsp_ptr->header.data_segment_length)` on `UPIU_QUERY_OPCODE_READ_DESC`; `ufshcd_read_desc_param()` must check `param_offset < buff_len` (`desc_buf[QUERY_DESC_LENGTH_OFFSET]`) and clamp to `buff_len - param_offset`; `ufshcd_read_string_desc()` must return early if `uc_str->len <= QUERY_DESC_HDR_SIZE`; clamp `sense_data_len` to `UFS_SENSE_SIZE` and `cmd->cmd_len` to `UFS_CDB_SIZE`. [F83, F85, F86, F87, F88]
- In `ufshcd_init()`, `dev_set_drvdata(dev, hba)`, `spin_lock_init(&hba->clk_gating.lock)`, `mutex_init(&hba->pm_qos_mutex)`, and default `hba->rpm_lvl`/`hba->spm_lvl` must execute before `ufshcd_hba_init(hba)` and before registering any callbacks that call `dev_get_drvdata()`. [F25, F140]
- `ufshcd_suspend()` must call `ufshcd_disable_irq()` before disabling clocks/regulators, and `ufshcd_resume()` must restore regulators to HPM and call `ufshcd_setup_clocks(hba, true)` before `ufshcd_enable_irq()`. `ufshcd_setup_clocks(hba, false)` must skip `clki->keep_link_active` clocks while `ufshcd_is_link_active(hba)` is true. [F154, F160]

## Synchronization
- `ufshcd_sl_intr()` runs in both hardirq (`ufshcd_intr()` with MCQ ESI) and threaded IRQ, so its callees (`ufshcd_uic_cmd_compl()`, `ufshcd_check_errors()`, `ufshcd_tmc_handler()`) and `__ufshcd_release()` must acquire `hba->host->host_lock` with `spin_lock_irqsave()`. When nested with `hba->clk_gating.lock`, `clk_gating.lock` is outer and `host_lock` is inner; `ufshcd_hold()` must drop `clk_gating.lock` before `flush_work(&hba->clk_gating.ungate_work)`. [F40, F162]
- `ufshcd_clock_scaling_prepare()` acquires `hba->host->scan_mutex`, quiesces `hba->host->tag_set` (`blk_mq_quiesce_tagset()`), acquires `hba->wb_mutex`, and takes `down_write(&hba->clk_scaling_lock)` before `ufshcd_hold(hba)` (same lock order in `ufshcd_clk_scaling_allow()`); its error path and `ufshcd_clock_scaling_unprepare()` (and `ufshcd_err_handling_unprepare()` for `tag_set`) must unquiesce `tag_set` and unlock in reverse order. [F9, F165, F184]
- `ufshcd_schedule_eh_work(hba)` requires `hba->host->host_lock`. In `ufshcd_err_handler()`, `ufshcd_err_handling_prepare(hba)` must complete before `ufshcd_set_eh_in_progress(hba)`, or `ufshcd_queuecommand()` will block runtime resume. Drop `host_lock` before sleeping recovery helpers (`ufshcd_abort_all()`, `ufshcd_reset_and_restore()`, etc.), and after `ufshcd_err_handling_prepare()` or `ufshcd_quirk_dl_nac_errors()` re-acquire `host_lock` and recheck `ufshcd_err_handling_should_stop(hba)`. [F39, F44, F166, F169]
- When `hba->pm_op_in_progress` or `hba->system_suspending` is true, `ufshcd_uic_pwr_ctrl()`, `ufshcd_err_handler()`, `ufshcd_eh_host_reset_handler()`, and `ufshcd_eh_timed_out()` must call `ufshcd_link_recovery(hba)` directly instead of scheduling/flushing `hba->eh_work` (and `ufshcd_eh_timed_out()` must return `SCSI_EH_RESET_TIMER` or `SCSI_EH_DONE`). [F41, F180]
- In `ufshcd_queuecommand()`, if `UFSHCD_STATE_EH_SCHEDULED_FATAL` and `hba->pm_op_in_progress`, fail immediately with `DID_BAD_TARGET` via `scsi_done(cmd)` and set `hba->force_reset = true`; if `UFSHCD_STATE_EH_SCHEDULED_NON_FATAL`, return `SCSI_MLQUEUE_HOST_BUSY` only when `ufshcd_eh_in_progress(hba)` is true. [F110, F177]
- In MCQ mode, reading `hwq->sq_tail_slot`, copying the UTRD to `hwq->sqe_base_addr + hwq->sq_tail_slot`, and calling `ufshcd_inc_sq_tail(hwq)` require `hwq->sq_lock`. In SDB mode, `hba->outstanding_reqs` and `REG_UTP_TRANSFER_REQ_DOOR_BELL` accesses require `hba->outstanding_lock` with IRQs disabled; when `ufshcd_poll()` runs with `UFSHCD_POLL_FROM_INTERRUPT_CONTEXT`, filter out `REQ_POLLED` requests via `ufshcd_clear_polled()` under `hba->outstanding_lock` before clearing `hba->outstanding_reqs`. [F33, F34, F47]
- In `ufshcd_compl_one_cqe()`, for a device management command (`lrbp->cmd == NULL`) with non-NULL `cqe`, copy `le32_to_cpu(cqe->status) & MASK_OCS` into `lrbp->utr_descriptor_ptr->header.ocs` before `complete(&hba->dev_cmd.complete)` (which must be persistent in `struct ufs_hba`, never on-stack). In SDB mode, if `ufshcd_wait_for_dev_cmd()` times out and calls `ufshcd_clear_cmd()`, check `test_bit(lrbp->task_tag, &hba->outstanding_reqs)` under `hba->outstanding_lock` and, if already cleared by the ISR, jump back to `wait_for_completion_timeout(&hba->dev_cmd.complete, 1)`. [F45, F48, F132]
- UIC command dispatch/wait (`__ufshcd_send_uic_cmd()`, `ufshcd_dispatch_uic_cmd()`, `ufshcd_wait_for_uic_cmd()`, `ufshcd_uic_pwr_ctrl()`) require `hba->uic_cmd_mutex`, and `hba->active_uic_cmd` and `hba->uic_async_done` (an on-stack completion pointer) must be cleared to `NULL` under `hba->host->host_lock` before returning. [F6, F38]
- All accesses to `hba->pm_qos_enabled` and `cpu_latency_qos_*_request(&hba->pm_qos_req, ...)` require `hba->pm_qos_mutex`. Modifying `hba->ee_ctrl_mask`, `hba->ee_drv_mask`, or `hba->ee_usr_mask` and calling `__ufshcd_write_ee_control()` require `hba->ee_ctrl_mutex`; `hba->ee_ctrl_mask` is `hba->ee_drv_mask | hba->ee_usr_mask`, neither mask may be updated if `__ufshcd_write_ee_control()` fails, and `*mask` must still be updated to `new_mask` when `!err` even if `ee_ctrl_mask == hba->ee_ctrl_mask`. [F32, F42, F77, F119]
- `ufshcd_wl_suspend()` holds `down(&hba->host_sem)` until `ufshcd_wl_resume()` calls `up(&hba->host_sem)` (or releases it on error); `__ufshcd_wl_suspend()` takes `ufshcd_hold(hba)` and sets `hba->clk_gating.is_suspended = true`, undoing both on error or in `__ufshcd_wl_resume()`. Because `__ufshcd_wl_suspend()` calls `cancel_delayed_work_sync(&hba->ufs_rtc_update_work)`, `ufshcd_update_rtc()` must use `ufshcd_rpm_get_if_active(hba)` and `ufshcd_rpm_put(hba)`, never `_sync` variants. [F23, F29, F158, F168]

## Object Lifetimes
- Every SCSI command in `ufshcd_queuecommand()` acquires `ufshcd_hold(hba)` before `ufshcd_map_sg()` and `ufshcd_clk_scaling_start_busy(hba)` in `ufshcd_send_command()`, released together in `ufshcd_release_scsi_cmd()` (or `ufshcd_release(hba)` if `ufshcd_map_sg()` fails). In `ufshcd_compl_one_cqe()`, all accesses to `lrbp` (including `ufshcd_release_scsi_cmd()`) must finish before `scsi_done(cmd)`. [F5, F46]
- In `__ufshcd_issue_tm_cmd()`, `req->end_io_data` points to an on-stack completion and `hba->tmf_rqs[req->tag]` exposes `req` to `ufshcd_tmc_handler()`; before returning, clear `hba->tmf_rqs[req->tag] = NULL` and clear `task_tag` from `hba->outstanding_tasks` under `hba->host->host_lock`, then call `ufshcd_release(hba)` and `blk_mq_free_request(req)`. [F7]
- `ufshcd_alloc_host()` registers `ufshcd_devres_release()` via `devm_add_action_or_reset()` to call `scsi_host_put(host)`, so callers must never call `scsi_host_put(hba->host)` manually. In `ufshcd_add_scsi_host()` rollback and `ufshcd_remove()`, destroy `hba->tmf_queue` with `blk_mq_destroy_queue()` then `blk_put_queue()`, call `blk_mq_free_tag_set(&hba->tmf_tag_set)`, and call `scsi_remove_host(hba->host)` if `hba->scsi_host_added`. [F11, F12]
- Schedule `hba->ufs_rtc_update_work` in `ufshcd_add_lus()` only after `ufshcd_scsi_add_wlus()` succeeds, and cancel it with `cancel_delayed_work_sync()` in `ufshcd_remove()` before `scsi_remove_host()`. In `ufshcd_sdev_destroy()`, clear `hba->ufs_device_wlun = NULL` under `host_lock` for the device WLUN; for other LUNs, take `get_device(&hba->ufs_device_wlun->sdev_gendev)` under `host_lock` before `device_link_remove()` and `put_device()` outside the lock. [F15, F18]
- In `ufshcd_read_desc_param()`, when `is_kmalloc` is true, every error path after `kzalloc()` must jump to `out` to `kfree(desc_buf)`. Before reinitializing the device with `init_dev_params = true` (which calls `ufs_get_device_desc()` and overwrites `hba->dev_info.model`), call `ufs_put_device_desc(hba)`. [F1, F3]

## API Contracts
- `ufshcd_wait_for_dev_cmd()` and its callers (`ufshcd_exec_dev_cmd()`, `ufshcd_query_flag()`, `ufshcd_query_attr()`, `ufshcd_read_desc_param()`, `*_retry`), `ufshcd_send_uic_cmd()`, and `ufshcd_uic_pwr_ctrl()` return `0` on success, `< 0` on kernel error, or `> 0` on OCS/UIC status, so callers must check `!= 0`. Conversely, `ufshcd_dev_cmd_completion()` and `ufshcd_copy_query_response()` must only return `0` or `< 0`. `ufshcd_issue_tm_cmd()` returns `0` even if `ocs != OCS_SUCCESS`, so initialize `tm_response` to an invalid sentinel and check both. [F50, F51, F54, F55]
- `ufshcd_utrl_clear()` takes a pre-shifted bitmask (`1U << task_tag`), whereas `ufshcd_utmrl_clear()` takes a 0-based bit position (`pos`) and shifts `1 << pos` internally. [F66]
- Always use `ufshcd_enable_irq()` and `ufshcd_disable_irq()` rather than raw `enable_irq()`/`disable_irq()` to keep `hba->is_irq_enabled` synchronized. Callers of `ufshcd_issue_dev_cmd()` must not call `ufshcd_add_query_upiu_trace()`. In `ufshcd_config_pwr_mode()`, `ufshcd_vops_pwr_change_notify(hba, PRE_CHANGE, ...)` must be paired with `POST_CHANGE` whenever `ufshcd_change_power_mode()` returns `0`. Callers outside devfreq (e.g., `ufshcd_host_reset_and_restore()`) must check `ufshcd_is_clkscaling_supported(hba)` before calling `ufshcd_scale_clks()`. [F69, F82, F152, F153]

## Error Handling
- In `ufshcd_err_handler()`, each pass at `again:` must reset `needs_restore = false`, `needs_reset = false`, and `hba->ufshcd_state = UFSHCD_STATE_RESET` (if not `UFSHCD_STATE_ERROR`), and loop back to `again:` if `ufshcd_state` is neither `OPERATIONAL` nor `ERROR`. In `ufshcd_reset_and_restore()`, each retry must accumulate `hba->saved_err` and `hba->saved_uic_err` into locals and clear `saved_err`, `saved_uic_err`, and `force_reset` under `host_lock` before resetting, restoring the accumulated masks only if all retries fail. [F113, F114]
- Callers of `ufshcd_mcq_req_to_hwq()` that can race with completion (e.g., `ufshcd_mcq_compl_pending_transfer()`) must check that the returned `hwq` is non-NULL. In `ufshcd_devfreq_target()`, initialize `scale_up` and `sched_clk_scaling_suspend_work` to `false` before any `goto out;`. [F56, F62]

## External Contracts
- In `ufshcd_intr()` (with MCQ ESI) and `ufshcd_threaded_intr()`, sample `REG_INTERRUPT_STATUS`, mask with `REG_INTERRUPT_ENABLE`, and write the sampled `intr_status` back to `REG_INTERRUPT_STATUS` before calling `ufshcd_sl_intr(hba, enabled_intr_status)` (bounded to `hba->nutrs` iterations in `ufshcd_threaded_intr()`). `ufshcd_transfer_req_compl()` must ignore the return value of `ufshcd_poll()` and return `IRQ_HANDLED`, and `ufshcd_uic_cmd_compl()` must return `IRQ_NONE` without `WARN_ON_ONCE` when `!hba->active_uic_cmd`. [F120, F145, F172, F174]
- In `ufshcd_transfer_rsp_status()`, call `scsi_set_resid(lrbp->cmd, resid)` only when `resid != 0` and `!(upiu_flags & UPIU_RSP_FLAG_OVERFLOW)`. In `ufshcd_set_dev_pwr_mode()` and `ufshcd_execute_start_stop()`, set `hba->host->eh_noresume = 1` around `START_STOP` and pass `BLK_MQ_REQ_PM` and `SCMD_FAIL_IF_RECOVERING` to `scsi_execute_cmd()`. In `ufshcd_abort()`, never issue task abort on `UFS_UPIU_UFS_DEVICE_WLUN`; set `hba->force_reset = true` and call `ufshcd_schedule_eh_work(hba)`. [F171, F178, F179]

## Known Pitfalls
- `sizeof(struct utp_upiu_rsp)` exceeds 32 bytes, so Query Read Descriptor or EHS payloads in `lrbp->ucd_rsp_ptr` must be addressed at `(u8 *)lrbp->ucd_rsp_ptr + 32` (`GENERAL_UPIU_REQUEST_SIZE` / `EHS_OFFSET_IN_RESPONSE`), never `lrbp->ucd_rsp_ptr + 1`. UCD/PRDT addressing in `ufshcd_init_lrb()`, `ufshcd_sgl_to_prdt()`, and `ufshcd_print_tr()` must step by `ufshcd_get_ucd_size(hba)` and `ufshcd_sg_entry_size(hba)`, and `ufshcd_init_lrb()` must derive `ucd_rsp_dma_addr`/`ucd_prdt_dma_addr` from `utrdlp[i]` offsets rather than `offsetof()`. [F97, F98, F131]
- In `ufshcd_wb_probe()`, read `dev_info->ext_wb_sup` as 16-bit BE at `DEVICE_DESC_PARAM_EXT_WB_SUP` and `ext_ufs_feature` as 32-bit BE at `DEVICE_DESC_PARAM_EXT_UFS_FEATURE_SUP` using `get_unaligned_be*()` (and use `get_unaligned_be64()`/`put_unaligned_be64()` for `utp_upiu_query_v4_0.osf3`), and reset `d_lu_wb_buf_alloc = 0` on every iteration of the LUN scan loop. [F65, F101, F118]
- In `ufshcd_read_string_desc()`, allocate `ascii_len = (uc_str->len - QUERY_DESC_HDR_SIZE) / 2 + 1` bytes and pass `ascii_len - 1` as `maxout` to `utf16s_to_utf8s()` before writing `str[ret++] = '\0'`. Callbacks on `hba->dev` must use `dev_get_drvdata(dev)`, whereas `ufs_dev_wlun_template` callbacks (`ufshcd_wl_*`) receive `&sdev->sdev_gendev` and must use `shost_priv(to_scsi_device(dev)->host)`. Bitmaps passed to `for_each_set_bit`/`test_bit`/`__set_bit`/`__clear_bit` must be `unsigned long`, never cast `u32 *`. [F135, F136, F138]
