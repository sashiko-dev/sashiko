# VFIO DRIVER

`drivers/vfio` exposes direct device access to userspace with IOMMU isolation via `/dev/vfio/vfio` containers, `/dev/vfio/$GROUP` groups, `/dev/vfio/devices/$DEV` cdevs, and `iommufd` bindings, including the core VFIO PCI meta-driver and VirtIO VFIO PCI driver.

## Architecture & Data Flow

- Opened VFIO device files (`vfio_device_fops_cdev_open()`, `vfio_device_open_file()`) must set `filep->f_mapping = device->inode->i_mapping` so `vfio_pci_zap_bars()` unmaps all BAR VMAs. On `struct vfio_group`, `group->opened_file` and `group->cdev_device_open_cnt` are mutually exclusive under `group->group_lock`. [F79, F179]
- In `vfio_pci_core_register_device()`, SR-IOV VFs (`pdev->is_virtfn`) and root-bus devices must get a dedicated per-device `vfio_device_set` keyed on `vdev` (`vfio_assign_device_set()`). Because `0` is valid for BAR0 and INTx, `vdev->msix_bar` must be `0xFF` when MSI-X is absent and `vdev->irq_type` must be `VFIO_PCI_NUM_IRQS` when no IRQ is active. [F50, F63]
- Region handlers (`vfio_pci_ioctl_get_region_info()`, `vfio_pci_rw()`, `vfio_pci_core_mmap()`) must verify `index < VFIO_PCI_NUM_REGIONS + vdev->num_regions`, clamp with `array_index_nospec()`, and subtract `VFIO_PCI_NUM_REGIONS` before indexing `vdev->region[]`. `vfio_pci_core_mmap()` and `vfio_pci_ioeventfd()` must reject `index > VFIO_PCI_BAR5_REGION_INDEX` before indexing `bar_mmap_supported[]`/`barmap[]`, and exclude `[vdev->msix_offset, vdev->msix_offset + vdev->msix_size)` on `vdev->msix_bar` in `vfio_pci_core_do_io_rw()` and `vfio_pci_ioeventfd()`. [F82, F83, F84, F176]
- In `vfio_config_do_rw()`, extended config (`*ppos >= PCI_CFG_SPACE_SIZE`) must check `cap_id <= PCI_EXT_CAP_ID_MAX` before indexing `ecap_perms[]` (else `direct_ro_perms`). `vdev->msi_perm` must be allocated per device in `vfio_msi_cap_len()` via non-`__init` `init_pci_cap_msi_perm()` and freed in `vfio_config_free()`. `alloc_perm_bits()` must `round_up(size, 4)`, `vfio_config_do_rw()` must clamp via `vfio_pci_cap_remaining_dword()`, and `vdev->vconfig` and `perm->virt`/`write` must stay little-endian. [F68, F81, F85, F86]
- Virtual BAR writes in `vfio_basic_config_write()` must set `vdev->bardirty = true`, and reads in `vfio_basic_config_read()` must call `vfio_bar_fixup(vdev)`. In `vfio_bar_fixup()`, `~(pci_resource_len(pdev, bar) - 1)` must be a `u64` mask for `mask >> 32` on 64-bit BARs (`PCI_BASE_ADDRESS_MEM_TYPE_64`), incrementing both `vbar++` and `i++` in the loop body in addition to the `for` header. [F69, F109, F118]
- Virtualized FLR bits (`PCI_EXP_DEVCTL_BCR_FLR`, `PCI_AF_CTRL_FLR`) must always be cleared in `vdev->vconfig` after `vfio_exp_config_write()`/`vfio_af_config_write()`. Devices without writable hardware `PCI_COMMAND_MEMORY` must check `pdev->no_command_memory` (not `pdev->is_virtfn`) in `__vfio_pci_memory_enabled()`, `vfio_basic_config_read()`/`write()`, and `vfio_config_init()`. [F70, F142]
- `vfio_pci_core_enable()` must call `pci_clear_master()` before `pci_save_state()`. When `vdev->nointx` is true, DisINTx must be re-asserted via `pci_intx(pdev, 0)` in `vfio_msi_disable()` and `PCI_COMMAND_INTX_DISABLE` in `vfio_bar_restore()`. `vfio_pci_core_runtime_suspend()` must record `vdev->pm_intx_masked = vfio_pci_intx_mask(vdev)`, and `vfio_pci_core_runtime_resume()` must only call `vfio_pci_intx_unmask(vdev)` if `pm_intx_masked` is true. A PF with VFs (`pci_num_vf(pdev) > 0`) must stay in `PCI_D0`. [F71, F134, F138, F150]
- In `virtiovf_pci_probe()`, admin queue features must only be probed when `pdev->is_virtfn` is true, and `ops = &virtiovf_vfio_pci_lm_ops` must require `sup_lm && !sup_legacy_io` so it does not overwrite `virtiovf_vfio_pci_tran_lm_ops`. Because `virtvdev->state_mutex` and `reset_lock` are only initialized when `virtvdev->migrate_cap` is set, `virtiovf_open_migration()`, `virtiovf_close_migration()`, and `virtiovf_migration_reset_done()` must return early if `!virtvdev->migrate_cap`. [F51, F102, F143]

## Synchronization

- Lock order is `vfio.group_lock` -> `group->group_lock` -> `container->group_lock` -> `vfio.iommu_drivers_lock`, and `group->group_lock` nests outside `device->dev_set->lock` (`vfio_device_block_group()`/`unblock_group()` must not be called under `dev_set->lock`). `vfio_group_set_kvm()` (called under `kvm->lock`) must never take `group_lock` or `dev_set->lock`, synchronizing `group->kvm` via `group->kvm_ref_lock` with `vfio_device_group_get_kvm_safe()`. [F23, F26, F155]
- In `vfio_df_ioctl_bind_iommufd()` and `vfio_df_group_open()`, `df->access_granted` must be set via `smp_store_release(&df->access_granted, true)` under `device->dev_set->lock` only after `vfio_df_open()` and IOAS attach/`out_devid` copy succeed, pairing with `smp_load_acquire()` in `vfio_device_fops`. All helpers in `drivers/vfio/iommufd.c` require `vdev->dev_set->lock`. [F22, F27]
- `vdev->igate` nests outside `vdev->memory_lock`: MSI/MSI-X helpers in `vfio_pci_intrs.c` and `pci_map_rom()` in `vfio_pci_ioctl_get_region_info()` must wrap hardware calls with `vfio_pci_memory_lock_and_enable()`/`unlock_and_restore()`, while holders of `vdev->memory_lock` (`vfio_basic_config_write()`, runtime PM) must drop it before calling `vfio_pci_intx_mask()`/`unmask()`. All accesses to `vdev->err_trigger` and `req_trigger` require `vdev->igate`. [F31, F144, F156]
- INTx mask/unmask requires `vdev->igate` across `is_intx(vdev)` and `spin_lock_irqsave(&vdev->irqlock, flags)` around `ctx->masked` and hardware/IRQ state. `vfio_intx_enable()` must set `ctx->masked` and `vdev->irq_type` before `request_irq()`, and when `!vdev->pci_2_3`, set `IRQ_DISABLE_UNLAZY` and pass `IRQF_NO_AUTOEN` if masked. `vfio_intx_set_signal()` must update `ctx->trigger` via `WRITE_ONCE()` (paired with `READ_ONCE()` in `vfio_send_intx_eventfd()`) and call `synchronize_irq()` and `vfio_virqfd_flush_thread(&ctx->unmask)` before `eventfd_ctx_put(old)`. [F29, F30, F136]
- In atomic `virqfd_wakeup()` context, `vfio_pci_ioeventfd_handler()` must use `down_read_trylock(&vdev->memory_lock)` when `ioeventfd->test_mem` is true (returning `1` on contention for `vfio_pci_ioeventfd_thread()`) and pass `test_mem = false` to `vfio_pci_ioeventfd_do_write()`; `vfio_pci_intx_unmask_handler()` must return `> 0` rather than calling `vfio_send_intx_eventfd()` directly. [F152, F153]
- `vdev->memory_lock` must never be held across `copy_to_user()`/`copy_from_user()` (`vfio_pci_iordwr*()`), as a BAR-mapped user buffer fault takes `down_read(&vdev->memory_lock)` in `vfio_pci_mmap_huge_fault()`. In `vfio_pci_dev_set_hot_reset()`, each `vdev->memory_lock` must be acquired via `down_write_trylock()` under `dev_set->lock`; because `err_undo` uses `list_for_each_entry_from_reverse()`, early breaks must occur before `down_write_trylock()` via `list_prev_entry()` and normal completion must set `vdev = list_last_entry()`. [F32, F34, F105]
- In `vfio_pci_core_sriov_configure()`, `vdev->sriov_pfs_item` must be added to `vfio_pci_sriov_pfs` and `vfio_pci_sriov_pfs_mutex` unlocked before `pci_enable_sriov()`. In `vfio_pci_core_match_token_uuid()` (called under `group->device_lock`), PF lookup must use `vdev->sriov_pf_core_dev` rather than locking `group->device_lock`. [F38, F160]
- In `migrate.c`, `virtiovf_migration_reset_done()` must not block on `virtvdev->state_mutex` (setting `deferred_reset = true` and using `mutex_trylock(&virtvdev->state_mutex)` under `reset_lock`), and all `state_mutex` holders must unlock via `virtiovf_state_mutex_unlock()`. Lock order is `virtvdev->state_mutex` -> `migf->lock` -> `migf->list_lock`, freeing buffer pages outside `migf->list_lock`. [F39, F40]

## Object Lifetimes

- In `vfio_df_group_open()`, `vfio_df_open()` must be called even when `vfio_device_is_noiommu()` is true (with `vfio_df_iommufd_bind()`/`unbind()` returning early) to balance `vfio_df_close()`. In `vfio_df_ioctl_bind_iommufd()`, failure after `vfio_device_block_group()` must unwind `vfio_df_open()`, `vfio_df_get_kvm_safe()`, and `iommufd_ctx_from_fd()` (resetting `df->iommufd = NULL` under `dev_set->lock`) and call `vfio_device_unblock_group()`, while `vfio_df_unbind_iommufd()` only runs if `df->access_granted` is true. [F1, F5, F52]
- `vfio_iommufd_physical_unbind()` must detach and free all PASIDs in `vdev->pasids`, detach `IOMMU_NO_PASID` and clear `vdev->iommufd_attached`, and then call `iommufd_device_unbind()` and clear `vdev->iommufd_device = NULL` under `vdev->dev_set->lock`. [F6, F80]
- `vfio_pci_core_init_dev()` must initialize `dummy_resources_list`, `ioeventfds_list`, `sriov_pfs_item`, and `ctx` during allocation (and custom `vfio_device_ops::init` callbacks must call it). `vfio_pci_core_register_device()` must finish dev_set, VF, VGA, and PM setup before `vfio_register_group_dev()`, and `vfio_pci_core_unregister_device()` must call `vfio_pci_core_sriov_configure(vdev, 0)` and `vfio_unregister_group_dev()` before tearing down VF, VGA, and PM state. [F57, F132, F133]
- `vfio_pci_core_finish_enable()` must only be called after `vfio_pci_core_enable()` and all fallible open steps succeed, as its VF token and EEH state are undone by `vfio_pci_core_close_device()`, not `vfio_pci_core_disable()`. During disable/config teardown (`vfio_pci_core_disable()`, `vfio_config_free()`, `vfio_config_init()`), freed `vdev` pointers (`region`, `vconfig`, `pci_config_map`, `msi_perm`, `barmap[bar]`) and `num_regions` must be reset to `NULL`/`0`. [F9, F54]
- `vfio_pci_set_power_state()` must `kfree(vdev->pm_save)` before overwriting it via `pci_store_saved_state()` on `D3hot` transition (and `vfio_pci_core_release_dev()` frees any remainder). `__vfio_pci_runtime_pm_exit()` must gate `pm_runtime_get_noresume()` and `eventfd_ctx_put(vdev->pm_wake_eventfd_ctx)` on `vdev->pm_runtime_engaged` under `vdev->memory_lock`. In `vfio_msi_disable()`, `vfio_virqfd_disable()` on `ctx->unmask`/`mask` must precede `vfio_msi_set_vector_signal(vdev, i, -1, msix)` because the latter frees `ctx`. [F8, F15, F107]
- Once `anon_inode_getfile()` succeeds in `virtiovf_pci_save_device_data()` or `resume_device_data()`, error paths must call `virtiovf_clean_migf_resources(migf)` and `fput(migf->filp)` (never `kfree(migf)`). Storing `saving_migf`/`resuming_migf` in `virtiovf_pci_step_device_state_locked()` requires `get_file(migf->filp)`, paired with `virtiovf_clean_migf_resources()` and `fput()` in `virtiovf_disable_fds()`. Because `migf->obj_id` can be `0`, `migf->has_obj_id` must guard it, and `virtiovf_pci_get_data_size()` must free temporary `obj_id`s when `!obj_id_exists`. [F17, F18, F21, F49]

## API Contracts

- Ownership transfers only on success: `vfio_device_open_file()` transfers the `vfio_device` registration ref only on success (else `vfio_group_ioctl_get_device_fd()` puts it); `vfio_pci_core_register_dev_region()` takes `data` only on success; and `vfio_intx_enable()`/`vfio_intx_set_signal()` must not put `trigger` on error because `vfio_pci_set_intx_trigger()` puts it when `ret != 0`. [F2, F11, F13]
- `vfio_check_feature()` callers must check `if (ret != 1) return ret;`. `vfio_iommufd_get_dev_id()` returns `> 0` when bound and `-ENOENT` when group-owned by `ictx` (both count as owned). `vfio_iommu_driver_ops::open` can return `NULL` on success (`vfio_noiommu_open()`), so callers must check `IS_ERR(data)` and test `container->iommu_driver` rather than `iommu_data`, and noiommu devices must bypass cdev in `vfio_device_add()`/`del()`. [F41, F42, F48, F173]
- In `struct perm_bits` callbacks, `pos` is the config-space offset (`vdev->vconfig`), whereas `offset` is capability-relative (`perm->virt`/`write`), and `vfio_default_config_read()` requires `count` in `{1, 2, 4}`. All `vfio_pci_regops::rw` and region rw helpers must return signed `ssize_t`, advancing `*ppos` only when `done >= 0`. Before reset or runtime suspend, devices must be transitioned to `PCI_D0` via `vfio_pci_set_power_state()`. [F46, F59, F116, F148]
- `vfio_pci_core_mmap()` must apply `pgprot_noncached()` and `pgprot_decrypted()` to `vma->vm_page_prot` and set `VM_ALLOW_ANY_UNCACHED | VM_IO | VM_PFNMAP | VM_DONTEXPAND | VM_DONTDUMP`. In `vfio_pci_mmap_huge_fault()`, `vmf->address` must be aligned down to `PAGE_SIZE << order` before computing `pgoff`/`pfn`, returning `VM_FAULT_FALLBACK` when `order > 0` if the aligned range exceeds `[vma->vm_start, vma->vm_end]` or `pfn & ((1 << order) - 1)` is non-zero. [F163, F165]

## Error Handling

- Capability-length helpers in `vfio_pci_config.c` and `vfio_config_init()` must convert `pci_read_config_*()` errors with `pcibios_err_to_errno()`, and `vfio_cap_init()`/`vfio_ecap_init()` must return `len` (not `ret`) when `vfio_cap_len()`/`vfio_ext_cap_len()` returns `len < 0`. Optional capability helpers (`vfio_pci_igd_init()`, `vfio_pci_info_zdev_add_caps()`, `vfio_pci_info_atomic_cap()`) return `-ENODEV` when absent, which callers must ignore. [F44, F55, F99]
- In `vfio_group_ioctl_set_container()`, error unwind before `group->iommufd = iommufd` must pass local `iommufd` to `iommufd_ctx_put()`. Unwinding partial `list_for_each_entry()` loops in `__vfio_container_attach_groups()` and `vfio_pci_dev_set_pm_runtime_get()` must use `list_for_each_entry_continue_reverse()`. In `migrate.c`, an `ERR_PTR` from `virtiovf_alloc_data_buffer()` must never be left in `migf->buf` or `buf_header`, and reallocating `migf->buf_header` in `virtiovf_resume_write()` must refresh local `vhca_buf_header`. [F53, F75, F98, F106]

## Known Pitfalls

- Because `vfio_df_close()` calls `vfio_df_device_last_close()` (`ops->close_device()` / `vfio_pci_core_disable()`) before decrementing `device->open_count` from 1 to 0, close paths checking if sibling devices in `dev_set` are open (`vfio_pci_dev_set_needs_reset()`) must check `vfio_device_set_open_count(dev_set) > 1`. [F7]
- In `vfio_pci_core_disable()`, after `pci_load_and_free_saved_state()`, reset must use `pci_dev_trylock()` and `__pci_reset_function_locked()` rather than `pci_try_reset_function()` before `pci_restore_state()`, so current config state is not re-saved over the initial state. [F64]
- On an SR-IOV VF (`vdev->pdev->is_virtfn`), VF token checks in `vfio_pci_core_match_token_uuid()`, `vfio_pci_core_finish_enable()`, and `vfio_pci_core_close_device()` must dereference `vdev->sriov_pf_core_dev->vf_token` rather than `vdev->vf_token`. In `vfio_pci_fill_devs()`, `vfio_iommufd_device_ictx()` takes `fill->vdev` whereas `vfio_iommufd_get_dev_id()` takes the walked `vdev`, and callers of `vfio_pci_for_each_slot_or_bus(..., vfio_pci_count_devs, &count, ...)` must initialize `count = 0`. [F56, F114, F115]
- In `vfio_pci_set_irqs_ioctl()`, every outer `switch (index)` case with a nested action-type `switch` must end with an outer `break`. In `vfio_pci_core_mmap()`, masked `pgoff` must be stored in a `u64` before `pgoff << PAGE_SHIFT` (40-bit region offsets). Partial-register `memcpy` in `vfio_pci_igd_rw()` and `virtiovf_pci_read/write_config()` must cast variable addresses to `(u8 *)`/`(void *)` before adding byte offsets. [F100, F117, F121]
- In `migrate.c`, `virtiovf_alloc_data_buffer()` and `virtiovf_resume_write()` must use `DIV_ROUND_UP_ULL(..., PAGE_SIZE)` for page counts; `virtiovf_add_migration_pages()` must `memset(page_list, 0, filled * sizeof(*page_list))` before each `alloc_pages_bulk()` loop iteration; and `virtiovf_get_migration_page()` must divide `offset - cur_offset` by `PAGE_SIZE` before adding to `sg_page(sg)`. [F119, F122, F123]
