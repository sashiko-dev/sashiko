# HIBERNATION (aka Software Suspend, aka swsusp)

`kernel/power` implements Linux system sleep, hibernation (software suspend / swsusp), opportunistic autosleep, userspace wakelocks, and Power Management Quality of Service (PM QoS). It coordinates task and workqueue freezing, device power state transitions, memory snapshot creation and restoration via radix-tree bitmaps and page backup entries (PBEs), and compressed/uncompressed swap image I/O.

## Architecture & Data Flow

- Every allocated image page (and any unsafe page skipped in `get_image_page()`) must have its PFN set in both `forbidden_pages_map` and `free_pages_map` via `swsusp_set_page_forbidden()` and `swsusp_set_page_free()`, and cleared in `free_unnecessary_pages()` or `free_image_page()`. `create_basic_memory_bitmaps()` must set the two globals only after both bitmaps exist, and `free_basic_memory_bitmaps()` must NULL both globals before calling `memory_bm_free()`. [F47, F62]
- In `swsusp_free()`, the intersection loop over `forbidden_pages_map` and `free_pages_map` must advance whichever of `fb_pfn` or `fr_pfn` is smaller (using unsigned comparisons) until `fb_pfn == fr_pfn`, and advance both cursors after freeing each matched page until `BM_END_OF_MAP` (`~0UL`). When `create_image()` returns in the restored kernel (`!in_suspend`), `clear_or_poison_free_pages()` must run while IRQs and secondary CPUs are still disabled. [F103, F169]
- In `snapshot_write_next()`, `handle->sync_read` must be `(handle->buffer == buffer)` after `handle->buffer` is assigned on each step, and `get_highmem_page_buffer()` must set `last_highmem_page` whenever it returns `buffer` so `copy_last_highmem_page()` flushes it. When the current PFN in `orig_bm` is in `zero_bm` after `handle->cur++`, `handle->buffer` must be zeroed and execution must jump to `next:` so `copy_last_highmem_page()`, `hibernate_restore_protect_page()`, and `get_buffer()` run. [F63, F101]
- In `copy_data_pages()`, `copy_pfn` must only advance via `memory_bm_next_pfn(copy_bm)` when `copy_data_page(copy_pfn, pfn)` returns `false`, reusing `copy_pfn` when a zero page is recorded in `zero_bm`. In `safe_copy_page()`, if `!kernel_page_present(s_page)`, it must map `s_page` with `hibernate_map_page()` before `page_address(s_page)` and unmap with `hibernate_unmap_page()`. [F100, F153]
- `restore_highmem()` must swap `pbe->copy_page` and `pbe->orig_page` in place via `swap_two_pages_data()`, and `resume_target_kernel()` must call `restore_highmem()` a second time if `swsusp_arch_resume()` fails. [F68]
- `unpack_orig_pfns()` must test `buf[j] == BM_END_OF_MAP` (`~0UL`) before masking `ENCODED_PFN_ZERO_FLAG` with `ENCODED_PFN_MASK`, and verify `pfn_valid(decoded_pfn) && memory_bm_pfn_present(bm, decoded_pfn)` before `memory_bm_set_bit()`. `rtree_next_node()` must test `list_is_last()` before advancing `bm->cur.node` or `bm->cur.zone` so cursors never rest on list heads, and `memory_bm_next_pfn()` must clamp `find_next_bit()` to `min(pages - bm->cur.node_pfn, BM_BITS_PER_BLOCK)`. [F82, F96, F118]
- In `load_compressed_image()`, `data[thr].cmp_len` must be verified non-zero and `<= bytes_worst_compress(UNC_SIZE)` before computing `need = DIV_ROUND_UP(data[thr].cmp_len + CMP_HEADER, PAGE_SIZE)` and copying into `data[thr].cmp`, and `data[thr].unc_len` must be verified non-zero, `<= UNC_SIZE`, and `PAGE_SIZE`-aligned. Ring buffer `page[]` must allocate `>= CMP_PAGES` pages and wrap `ring` and `pg` at `ring_size` (setting `ring_size = i` before `goto out_clean` if `page[i]` fails for `i < CMP_PAGES`). [F51, F79, F80, F81]
- Both `load_image()` and `load_compressed_image()` must flush icache (`clean_pages_on_read` / `clean_pages_on_decompress`), call `snapshot_write_finalize()`, and verify `snapshot_image_loaded()` before completing. [F15, F71]
- `mark_swapfiles()` must verify `swsusp_header->sig` is `"SWAP-SPACE"` or `"SWAPSPACE2"` and save it to `orig_sig` before writing `HIBERNATE_SIG`; `swsusp_check()` and `swsusp_unmark()` must verify `HIBERNATE_SIG` and restore `orig_sig` on disk. In `swap_read_page()`, when `++handle->k >= MAP_PAGE_ENTRIES`, the consumed `handle->maps->map` page and node are freed and `handle->cur` must be updated to the new `handle->maps->map` (or NULL via `release_swap_reader(handle)`) with `handle->k = 0`. [F67, F73]
- Because `snapshot_state` is a static singleton, `snapshot_open()` must initialize `handle`, `free_bitmaps`, `frozen`, `ready`, `platform_support`, and `dev` in both `O_RDONLY` and `O_WRONLY` modes, `SNAPSHOT_UNFREEZE` must clear `data->free_bitmaps`, `snapshot_set_swap_area()` must set `snapshot_state.dev = swdev`, and `snapshot_release()` must reset `snapshot_state.dev = 0`. [F64, F173]
- `hibernation_set_ops()` must update `hibernation_mode` with `hibernation_ops` under `lock_system_sleep()` (`HIBERNATION_PLATFORM` when non-NULL, `HIBERNATION_SHUTDOWN` when NULL and mode was `HIBERNATION_PLATFORM`). `entering_platform_hibernation` must be `true` before suspending consoles/devices in `hibernation_platform_enter()` and around `kernel_power_off()` in `power_down()`, and reset to `false` on all exit/error paths. [F60, F133]

## Synchronization

- Lock ordering: `autosleep_lock` -> `system_transition_mutex` -> `lock_device_hotplug()`; `wait_for_device_probe()` must run before acquiring `system_transition_mutex`. Callers of `lock_system_sleep()` must pass its returned `unsigned int` flags to `unlock_system_sleep()`. Every hibernation entry point (`hibernate()`, `hibernate_quiet_exec()`, `software_resume()`) and `/dev/snapshot` session (`snapshot_open()`..`snapshot_release()`) must pair `hibernate_acquire()` and `hibernate_release()`. [F29, F30, F145, F147]
- `pm_restrict_gfp_mask()` and `pm_restore_gfp_mask()` require `system_transition_mutex`, and `pm_restrict_gfp_mask()` must not run while `saved_gfp_mask` is non-zero. When `hibernation_snapshot()` succeeds (`in_suspend && !error`), `gfp_allowed_mask` must stay restricted across `dpm_resume()`/`dpm_complete()`; in `power_down()`, `suspend_devices_and_enter()` for `HIBERNATION_SUSPEND` requires `pm_restore_gfp_mask()` first, and any return path from `power_down()` to `hibernate()` must call `pm_restrict_gfp_mask()` before `swsusp_unmark()`. [F2, F4, F132]
- Because `swsusp_save()` runs in `swsusp_arch_suspend()` on one CPU with local IRQs disabled and `system_state == SYSTEM_SUSPEND`, all allocations in `swsusp_save()` and `swsusp_alloc()` must use non-sleeping GFP flags (`GFP_ATOMIC` or `__GFP_HIGHMEM|__GFP_KSWAPD_RECLAIM`). `mark_free_pages()` must hold `spin_lock_irqsave(&zone->lock, flags)` while scanning `zone->free_area` and call `touch_nmi_watchdog()`. [F151, F152]
- In `kernel/power/swap.c`, kthread handshakes (`compress_threadfn()`, `decompress_threadfn()`, `crc32_threadfn()`) must pair `atomic_set_release()` with `atomic_read_acquire()` on `ready` and `stop` in `cmp_data`, `dec_data`, and `crc_data`. In `save_compressed_image()`, each pass must cap completion waiting at `run_threads = thr` and reset woken workers' `stop` and `crc->stop` to 0 after `wait_event()`. [F20, F102]
- In `hib_submit_io_async()`, `bio->bi_end_io` and `bio->bi_private` must be set and `atomic_inc(&hb->count)` called before `submit_bio(bio)`, and `hib_end_io()` must store `hb->error` before `atomic_dec_and_test(&hb->count)`. When `snapshot->sync_read` is set, `load_image()` must call `hib_wait_io(&hb)` after `swap_read_page()` before the next `snapshot_write_next()`. [F22, F156]
- In `s2idle_enter()`, `s2idle_lock` must be held across `pm_wakeup_pending()` and setting `s2idle_state = S2IDLE_STATE_ENTER`, and after `swait_event_exclusive()`, `wake_up_all_idle_cpus()` must run before resetting `s2idle_state = S2IDLE_STATE_NONE`. In `s2idle_loop()`, `s2idle_ops->wake()` and `s2idle_ops->check()` must run while noirq-suspended; when `s2idle_ops->wake` is present, the loop must break directly on its return value without calling `pm_wakeup_pending()` or `pm_wakeup_clear()`. [F24, F135, F136]
- Callers acquiring `autosleep_lock` must either hold an active `wakeup_source` (`__pm_stay_awake(autosleep_ws)`) or use `pm_autosleep_lock()`. In `try_to_suspend()`, after `pm_get_wakeup_count(&initial_count, true)`, `pm_save_wakeup_count(initial_count)`, `system_state == SYSTEM_RUNNING`, and `autosleep_state != PM_SUSPEND_ON` must be revalidated under `autosleep_lock`. [F25, F26]
- Mutations of `pm_qos_constraints` (`c->list`, `WRITE_ONCE(c->target_value, ...)`) and `pm_qos_flags` (`pqf->list`, `pqf->effective_flags`) must hold `spin_lock_irqsave(&pm_qos_lock, flags)` and recompute `target_value`/`effective_flags` (`PM_QOS_UPDATE_REQ` must remove and fall through to `PM_QOS_ADD_REQ` without clobbering `req`), while `blocking_notifier_call_chain()` in `pm_qos_update_target()` must run after unlocking `pm_qos_lock`. [F31, F69, F93]
- Under `wakelocks_lock`, `wakelock_lookup_add()` and `__wakelocks_gc()` must keep `wakelocks_tree`, `wakelocks_lru_list`, `wl->ws`, and `number_of_wakelocks` synchronized: `wakelock_lookup_add()` must set `wl->ws->last_time = ktime_get()` before linking `wl`, and `__wakelocks_gc()` must iterate `wakelocks_lru_list` with `list_for_each_entry_safe_reverse()`, read `last_time` and `active` under `spin_lock_irq(&wl->ws->lock)`, and unlock `wl->ws->lock` before `wakeup_source_unregister()`. [F32, F70, F98]

## Object Lifetimes

- During teardown (`hibernate()`, `load_image_and_restore()`, `snapshot_release()`), `swsusp_free()` must run before `free_basic_memory_bitmaps()` and call `hibernate_restore_unprotect_page(page_address(page))` before `__free_page(page)`. In `snapshot_ioctl()`, `SNAPSHOT_FREE` must call `thaw_kernel_threads()` after `swsusp_free()`. [F6, F17, F158]
- In `hibernation_snapshot()`, `hibernate_preallocate_memory()` must run before `freeze_kernel_threads()` and `dpm_prepare(PMSG_FREEZE)`, and `shrink_shmem_memory()` must run between `dpm_prepare()` and `console_suspend_all()`/`pm_restrict_gfp_mask()`/`dpm_suspend()`. If `dpm_prepare()` fails in `hibernation_snapshot()` or `hibernate_quiet_exec()`, `dpm_complete()` must still run before thawing kernel threads. [F130, F131]
- In `create_image()`, `hibernate_quiet_exec()`, and `hibernation_platform_enter()`, `platform_finish()` must run before `dpm_resume_start()` whenever `dpm_suspend_end()` succeeded, and after `platform_leave()` on the image creation/restore path; in `create_image()` when `!in_suspend`, `arch_resume_nosmt()` must run between `pm_sleep_enable_secondary_cpus()` and `platform_finish()`. In `resume_target_kernel()`, once `platform_pre_restore()` is called, `platform_restore_cleanup()` must run before `dpm_resume_start(PMSG_RECOVER)` even if `platform_pre_restore()` failed. [F127, F128, F129]
- In `save_compressed_image()` and `load_compressed_image()`, a failed `kthread_run()` on `data[thr].thr` or `crc->thr` must be reset to `NULL` before `goto out_clean`, and `out_clean` must call `kthread_stop()` on all running kthreads before freeing acomp state, `data`, or `crc`. [F13]
- For async swap writes (`hb != NULL`), `write_page()` must copy `buf` into a fresh bounce page (freed by `put_page()` in `hib_end_io()`), and all callers using a stack `struct hib_bio_batch` must drain BIOs via `err2 = hib_wait_io(&hb); if (!ret) ret = err2;` before freeing buffers or returning. In `swap_writer_finish()`, `free_all_swap_pages(root_swap)` must be called if `error` is non-zero or `mark_swapfiles()` fails, and omitted on success. [F14, F48, F120, F174]
- `swsusp_check()` must overwrite `swsusp_header->sig` with `orig_sig` on disk via `REQ_OP_WRITE | REQ_SYNC` before checking `SF_HW_SIG` or loading the image; on failure after opening `hib_resume_bdev_file`, `swsusp_check()` calls `bdev_fput()` without clearing the pointer, so callers must not call `swsusp_close()` when `swsusp_check()` fails. [F50, F176]
- `snapshot_read_next()` must copy `PageHighMem(page)` into `buffer` between `kmap_local_page()` and `kunmap_local()` rather than returning a live kmap in `handle->buffer`. `cpu_latency_qos_remove_request()`, `freq_qos_remove_request()`, and the error path of `freq_qos_add_request()` must clear `req->qos = NULL`. [F19, F155]

## API Contracts

- `hibernation_available()` must gate all hibernation/resume entry points (`hibernate()`, `snapshot_open()`, `software_resume_initcall()`, `disk_store()`, `resume_store()`, `is_hibernate_resume_dev()`). `freeze_kernel_threads()` only calls `thaw_kernel_threads()` on failure, leaving callers responsible for calling `thaw_processes()` from the exact same task that called `freeze_processes()` (`PF_SUSPEND_TASK`). [F5, F161, F166]
- Callers must zero-initialize `struct snapshot_handle` before starting a stream (`handle->cur == 0`), and treat any `snapshot_read_next()`/`snapshot_write_next()` return `< (int)PAGE_SIZE` in `swsusp_write()`/`swsusp_read()` as an error (mapping `>= 0` to `-EFAULT`). Before scanning with `memory_bm_next_pfn(bm)`, callers must call `memory_bm_position_reset(bm)` and not interleave `memory_bm_find_bit()` calls on `bm`. In `prepare_image()`, bitmaps created after `mark_unsafe_pages()` must use `PG_SAFE` and `PG_UNSAFE_CLEAR` (vs `PG_UNSAFE_KEEP` for earlier bitmaps). [F38, F52, F55, F65]
- `hibernation_ops` requires non-NULL `begin`, `end`, `pre_snapshot`, `prepare`, `finish`, `enter`, `pre_restore`, `restore_cleanup`, and `leave` (`leave` and `enter` run on the boot CPU with secondary CPUs and local IRQs disabled). `PM_SUSPEND_TO_IDLE` works when `suspend_ops` is NULL so helpers must null-check `suspend_ops` and optional callbacks. [F46, F126, F163]
- `swsusp_check()` takes `exclusive = true` in `software_resume()` and `exclusive = false` in `HIBERNATION_TEST_RESUME`. `pm_qos_update_target()` and `freq_qos_*()` return `1` on change, `0` if unchanged, and `< 0` on error, and `*_qos_value_invalid()` must allow `PM_QOS_DEFAULT_VALUE` (`-1`). [F43, F54, F92]

## Error Handling

- In `create_image()`, `hibernation_platform_enter()`, `resume_target_kernel()`, and `suspend_enter()`, `syscore_resume()` must only run if `syscore_suspend()` returned 0, while `system_state = SYSTEM_RUNNING` and `local_irq_enable()` must always run. When `pm_notifier_call_chain_robust(val_up, val_down)` fails, callers must not call `pm_notifier_call_chain(val_down)`. [F11, F18]
- `get_buffer()` and `get_highmem_page_buffer()` must convert `__get_safe_page() == NULL` to `ERR_PTR(-ENOMEM)` for `IS_ERR(handle->buffer)` in `snapshot_write_next()`, and `wakelock_lookup_add()` returns `ERR_PTR` (checked with `IS_ERR(wl)`). `hib_wait_io()` must convert `hb->error` (`blk_status_t`) via `blk_status_to_errno()`. [F39, F40, F44]
- In `power_down()`, `HIBERNATION_PLATFORM` must jump to `exit` (`swsusp_unmark()`) only when `hibernation_platform_enter()` returns `-EAGAIN` or `-EBUSY`, falling through to `HIBERNATION_SHUTDOWN` (`kernel_can_power_off()`) otherwise. In `resume_store()`, `lookup_bdev()` failure must reset `error = 0` before the `sscanf()`/`simple_strtoul()` fallbacks. [F94, F99, F168]

## Known Pitfalls

- In `create_image()`, `restore_processor_state()` must immediately follow `swsusp_arch_suspend()` before any per-CPU access (such as `trace_suspend_resume()` or `pr_err()`). In `copy_data_page()`, when copying lowmem `s_page` to highmem `d_page`, `safe_copy_page(buffer, s_page)` must run before `kmap_local_page(d_page)`. [F143, F154]
- In `hibernate_setup()`, `"noresume"` and `"nocompress"` must precede `!strncmp(str, "no", 2)`. `swsusp_header->sig`/`orig_sig` require 10-byte `memcmp()`/`memcpy()`, and `wakelock_lookup_add()` must bound `name` to `len` (`strncmp` + `wl->name[len] == '\0'` + `kstrndup`). [F90, F123, F124]
- `resume_store()` must return `n` when `!hibernation_available()`, and `autosleep_store()` must verify `buf` is `"off"`/`"off\n"` when `decode_state()` returns `PM_SUSPEND_ON`. `snapshot_set_swap_area()` must handle `in_compat_syscall()` (`struct compat_resume_swap_area`) and `new_decode_dev()`, and `snapshot_compat_ioctl()` must only apply `compat_ptr(arg)` to pointer ioctls. [F42, F85, F95, F172]
