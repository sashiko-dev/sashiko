# EXEC & BINFMT API, ELF

This unit implements Linux process creation (`fork`/`clone`/`vfork`/`clone3`), `task_struct` and `mm_struct` lifecycle management, and `execve`/`execveat` program execution. It provides the `linux_binfmt` registration and dispatch framework, early stack VMA setup and relocation (`mm/vma_exec.c`), credential and thread-group transitions during exec, and the built-in loaders and coredump handlers for ELF (standard, compat, and FDPIC), FLAT (uClinux), `#!` scripts, and user-namespace-aware `binfmt_misc`.

## Architecture & Data Flow

- In `begin_new_exec()`, `unshare_files()` must run before `do_close_on_exec(me->files)` and `fd_install()`, `do_close_on_exec()` before `set_dumpable()`, `unshare_sighand(me)` before `flush_signal_handlers(me, 0)`, and `perf_event_exit_task(me)` (when `get_dumpable(me->mm) != SUID_DUMP_USER`) after `commit_creds(bprm->cred)`. [F74, F168]
- While `bprm->mm` is populated before installation, `get_arg_page()` charges stack growth (`vma_pages(vma) - bprm->vma_pages`) to `current->mm`'s `MM_ANONPAGES` via `acct_arg_size()`, which must be reversed via `acct_arg_size(bprm, 0)` before `exec_mmap(bprm->mm)` in `begin_new_exec()` or `mmput(bprm->mm)` in `free_bprm()`. [F60]
- In `exec_binprm()`, when `bprm->interpreter` is set, it moves to `bprm->file`, `bprm->interpreter` is cleared to `NULL`, and the displaced file gets `exe_file_allow_write_access()` and is stashed in `bprm->executable` (if `bprm->have_execfd`) or `fput()`. Setting `bprm->execfd_creds` (`MISC_FMT_CREDENTIALS`) requires `bprm->have_execfd` (`MISC_FMT_OPEN_BINARY`) so `bprm->executable` is populated before `bprm_creds_from_file()`. [F46, F66, F106]
- In `dup_task_struct()`, `tsk->seccomp.filter` must be cleared to `NULL` after `arch_dup_task_struct()` so early fork failure in `free_task()` does not see an unreferenced filter; `copy_seccomp(p)` under `current->sighand->siglock` later copies `current->seccomp` while synchronizing `no_new_privs` and `SECCOMP` syscall work. When `copy_process()` resets CPU timer state, it must call `tick_dep_init_task(p)` and `clear_posix_cputimers_work(p)` alongside `posix_cputimers_init(&p->posix_cputimers)`. [F76, F77]
- In `load_elf_binary()` and `load_elf_interp()`, `total_mapping_size()` must only size the first `PT_LOAD` mapping (and in `load_elf_binary()` only for `ET_DYN`, never `ET_EXEC`), while subsequent `PT_LOAD` segments must pass `total_size = 0` with `MAP_FIXED`. For the first `ET_DYN` `PT_LOAD` in `load_elf_binary()`, the `ELF_ET_DYN_BASE` `load_bias` branch must be selected by `if (interpreter)`, with the `alignment > ELF_MIN_ALIGN` probe mapping only in the `else` branch. [F80, F101, F103]
- In `load_elf_binary()`, for a static PIE (`ET_DYN && !interpreter`) with `CONFIG_ARCH_HAS_ELF_RANDOMIZE` and `!CONFIG_COMPAT_BRK`, `elf_brk` must move to `ELF_ET_DYN_BASE` and `brk_moved = true` even if `PF_RANDOMIZE` is unset, and `brk_moved` requires setting `current->brk_randomized = 1`. [F68]
- In `create_elf_tables()` and `create_elf_fdpic_tables()`, `ARCH_DLINFO` must run before any other `NEW_AUX_ENT()` calls; adding or conditioning `NEW_AUX_ENT()` entries requires updating `AT_VECTOR_SIZE_BASE` (or `AT_VECTOR_SIZE_ARCH`) to bound `mm->saved_auxv`, and in `create_elf_fdpic_tables()` updating `nitems` (or `DLINFO_ITEMS`) under the exact same condition. [F69, F122]

## Synchronization

- `tasklist_lock` (`write_lock_irq(&tasklist_lock)`) nests outside `sighand->siglock` and inside `cgroup_threadgroup_change_begin()`. In `copy_process()`, error paths before acquiring `write_lock_irq(&tasklist_lock)`, calling `sched_core_fork(p)`, and acquiring `spin_lock(&current->sighand->siglock)` must jump to `bad_fork_cancel_cgroup` (or earlier) and never `bad_fork_core_free`; no faultable user access (e.g., `put_user()`) may occur between recording `p->start_time` and acquiring `write_lock_irq(&tasklist_lock)`. [F10, F142, F146]
- In `kernel_clone()`, when `CLONE_VFORK` is set, `p->vfork_done`, `init_completion(&vfork)`, and `get_task_struct(p)` must be initialized before `wake_up_new_task(p)`, and if `wait_for_vfork_done()` is killed by a fatal signal, it must clear `child->vfork_done = NULL` under `task_lock(child)` before returning. [F22]
- `begin_new_exec()` consumes `bprm->mm` (`exec_mmap()`), `bprm->cred` (`commit_creds()`), and `bprm->executable` (`fd_install()`), clearing each to `NULL`, and returns with `current->signal->exec_update_lock` and `current->signal->cred_guard_mutex` held until `setup_new_exec()` unlocks both. `check_unsafe_exec()` sets `current->fs->in_exec = 1` under `read_seqlock_excl(&p->fs->seq)` (with `cred_guard_mutex` held); `in_exec` must be cleared to `0` both after `de_thread()` succeeds in `begin_new_exec()` and in `free_bprm()` when `bprm->cred` is non-NULL. [F3, F73]
- In `exec_mmap()`, `tsk->mm` and `tsk->active_mm` must be updated under `task_lock(tsk)` and `local_irq_disable()` while holding `exec_update_lock` for write and `mmap_read_lock_killable(old_mm)` (if `old_mm`); functions acquiring a `spinlock_t` (such as `lru_gen_add_mm()`) must not be called inside this `local_irq_disable()` region because `spinlock_t` sleeps on `PREEMPT_RT`. [F27, F138]
- In `dup_mm()`, `uprobe_start_dup_mmap()` and `uprobe_end_dup_mmap()` must bracket both `dup_mmap(mm, oldmm)` and the error-path `mmput(mm)` when `dup_mmap()` fails. `set_mm_exe_file()` updates `mm->exe_file` without `mmap_lock` and may only be called when `mm` has no concurrent users (`__mmput()` or `begin_new_exec()` before `exec_mmap()`); on a live `mm`, updates require `mmap_write_lock(mm)` (`replace_mm_exe_file()`) and readers must use `get_mm_exe_file()`. [F17, F149]
- In `__mmdrop()`, `cleanup_lazy_tlbs(mm)` must run before `mm_free_pgd(mm)` and `free_mm(mm)`. `free_signal_struct()` must release `sig->oom_mm` via `mmdrop_async()` rather than synchronous `mmdrop()` because it runs from `__put_task_struct_rcu_cb()` in softirq context. Under `CONFIG_VMAP_STACK`, `alloc_thread_stack_node()` must cache `tsk->stack_vm_area` at allocation time because `free_thread_stack()` can run in interrupt context where `find_vm_area()` is forbidden. [F139, F140, F152]
- In `search_binary_handler()`, `try_module_get(fmt->module)` must succeed before `read_unlock(&binfmt_lock)` is called to invoke `fmt->load_binary(bprm)`, and `read_lock(&binfmt_lock)` must be re-acquired before calling `put_binfmt(fmt)` and advancing the `formats` list cursor. [F104]
- In `elf_core_dump()` and `elf_fdpic_core_dump()`, VMA metadata and extra phdr/data sizes must come from the pre-captured `struct coredump_params *cprm` snapshot (`cprm->vma_meta`, `cprm->vma_count`, `elf_core_extra_phdrs(cprm)`, `elf_core_extra_data_size(cprm)`) rather than walking `current->mm`'s VMA tree directly without `mmap_lock`. [F35]

## Object Lifetimes

- Callers of `open_exec()` and `do_open_execat()` must call `exe_file_allow_write_access()` before `fput()` (or use `do_close_execat()`) when releasing the returned `struct file`, because `do_open_execat()` increments the inode's negative write-deny counter via `exe_file_deny_write_access()`. [F1]
- In `create_init_stack_vma()`, `ksm_execve(mm)` is called under `mmap_write_lock_killable(mm)` before `insert_vm_struct(mm, vma)`; if `insert_vm_struct()` fails, `ksm_exit(mm)` must be called before unlocking `mm` and freeing `vma` because `bprm_mm_init()` cleans up a failed `mm` via `mmdrop()` (after resetting `bprm->mm = NULL`) rather than `mmput()`. [F6, F45]
- In `copy_process()`, if an error occurs after `copy_mm()` succeeds (`bad_fork_cleanup_mm`), `mm_clear_owner(p->mm, p)` must be called before `mmput(p->mm)`. The stack-allocated `struct multiprocess_signals delayed` node added to `current->signal->multiprocess` must be unlinked via `hlist_del_init(&delayed.node)` under `current->sighand->siglock` on both the success and `fork_out` paths. [F9, F133]
- Per-task resources allocated during `dup_task_struct()` or `copy_process()` that are not unwound by `bad_fork_cleanup_*` labels (`bpf_task_storage_free()`, `free_kthread_struct()`, `scs_release()`, `release_user_cpus_ptr()`) must be freed in `free_task()`, not `__put_task_struct()`. [F12]
- On success, `pidfd_prepare()` reserves `pidfd` and allocates `*ret_file` (`pidfile`), which in `copy_process()` must run after `copy_files()` and before `p->start_time` is recorded (along with `put_user(pidfd, args->pidfd)`). If `pidfd_prepare()` fails, `copy_process()` must jump to `bad_fork_free_pid` (not `bad_fork_put_pidfd`, which calls `fput(pidfile)` and `put_unused_fd(pidfd)`), while `fd_install(pidfd, pidfile)` must be deferred until after `write_unlock_irq(&tasklist_lock)`. [F13, F52, F177]
- `set_binfmt(struct linux_binfmt *new)` must only be called after `begin_new_exec()` has installed `bprm->mm` as `current->mm` and while the caller holds a reference on `new->module`. In `get_binfmt_handler()`, `refcount_inc(&e->users)` must be taken under `read_lock(&misc->entries_lock)`, and `bm_register_write()` must initialize `refcount_set(&e->users, 1)` and `e->interp_file` before linking `e->list` under `write_lock(&misc->entries_lock)`. [F33, F164]

## API Contracts

- `mmput()` asserts `might_sleep()` and synchronously runs `__mmput()` -> `exit_mmap()` when `mm->mm_users` drops to zero; callers in atomic context or holding a lock taken inside `__mmu_notifier_release()` callbacks during `exit_mmap()` must call `mmput_async()` instead. [F141]
- In `kernel/fork.c`, `copy_process()` and all helpers testing clone flags (`copy_sighand()`, `copy_mm()`, `copy_fs()`, `copy_files()`, `copy_signal()`, `copy_oom_score_adj()`) must accept `clone_flags` as `u64` rather than `unsigned long` so upper-32-bit `clone3()` flags (`CLONE_CLEAR_SIGHAND`, `CLONE_INTO_CGROUP`) are not truncated on 32-bit targets. [F112]
- In `struct linux_binfmt::load_binary` handlers, all format checks that can return `-ENOEXEC` must run before `begin_new_exec()`, which sets `bprm->point_of_no_return = true` (stopping `search_binary_handler()` even on `-ENOEXEC` and causing `bprm_execve()` to deliver `SIGSEGV`), and `would_dump(bprm, file)` must be called on any mapped binary or interpreter before `exec_mmap()`. [F105, F158, F167]
- After `begin_new_exec()`, binary format loaders must call `SET_PERSONALITY2()` / `set_personality()` before `setup_new_exec()` and `setup_arg_pages()`, and must call `finalize_exec(bprm)` before `START_THREAD()` / `start_thread()`. [F156, F161]
- `setup_arg_pages()` (and `elf_read_implies_exec()`) takes the tri-state enum `EXSTACK_DEFAULT` (0), `EXSTACK_DISABLE_X` (1), or `EXSTACK_ENABLE_X` (2) for `executable_stack`, not a boolean where `1` means executable. Unlike `remove_arg_zero()`, `copy_string_kernel()` only decrements `bprm->p` and copies the string, so callers (`load_script()`, `load_misc_binary()`, `do_execveat_common()`) must increment `bprm->argc` for each added argument. [F40, F64]
- In `fs/binfmt_misc.c`, `Node->flags` stores `Enabled` (0) and `Magic` (1) as bit indices accessed via `test_bit()`/`set_bit()`/`clear_bit()` or `1 << bit`, whereas `MISC_FMT_*` (`1UL << 28`..`31`) are pre-shifted bitmasks accessed via bitwise `&` and `|=`. [F41]

## Error Handling

- In `do_open_execat()`, `path_noexec(&file->f_path)` must be checked before `WARN_ON_ONCE(!S_ISREG(file_inode(file)->i_mode))` so non-regular files on `MNT_NOEXEC` or `SB_I_NOEXEC` mounts fail with `-EACCES` without warning. Both `bprm_change_interp()` and `free_bprm()` must guard `kfree(bprm->interp)` with `if (bprm->interp != bprm->filename)`. [F57, F98]
- Because `dup_mm()` shallow-copies `oldmm` into `mm` via `memcpy()` before `try_module_get(mm->binfmt->module)`, its `free_pt` error path must reset `mm->binfmt = NULL` (and `mm_init_owner(mm, NULL)`) before `mmput(mm)`. `unshare_fd()` must check `IS_ERR(fd)` on `dup_fd()` before writing `*new_fdp`, and callers (`ksys_unshare()`, `unshare_files()`) must initialize their `struct files_struct *` out-parameter to `NULL`. [F39, F78]
- In `load_elf_binary()`, when `BAD_ADDR(x)` is true on `elf_load()` or `load_elf_interp()`, `IS_ERR_VALUE(x)` must be tested and `-EINVAL` substituted when false before assigning `retval`; any error path after `elf_phdata`, `interp_elf_ex`, `interp_elf_phdata`, and `interpreter` are released must jump to `out` (not `out_free_dentry`, `out_free_file`, or `out_free_ph`) because those pointers are not nulled. [F36, F38]
- In `load_elf_fdpic_binary()`, failure paths jumping to `error:` after an earlier `retval`-setting call must set a negative `retval` and reset `interpreter = NULL` if `IS_ERR(interpreter)` or after `fput(interpreter)`. [F37]
- In `elf_core_dump()`, `dump_emit()`, `dump_user_range()`, `write_note_info()`, `elf_core_write_extra_phdrs()`, and `elf_core_write_extra_data()` return `1` on success and `0` on failure, whereas `elf_coredump_extra_notes_write()` returns `0` on success. `fill_files_note()` must check `kvmalloc(size, GFP_KERNEL)` with `ZERO_OR_NULL_PTR(data)` (not `!data`) because `size` is `0` when `cprm->vma_count == 0`. [F42, F43]

## Known Pitfalls

- In `relocate_vma_down()`, the maple tree iterator `vmi` must be rewound via `vma_iter_prev_range(&vmi)` after `vma_next(&vmi)` checks for intervening VMAs before `vma_expand(&vmg)`, and rewound via `vma_prev(&vmi)` after `vma_next(&vmi)` fetches `next` before `vma_shrink()`; when `new_end <= old_start`, `free_pgd_range()` must start from `old_start` rather than `new_end`. [F63, F155]
- Because `arch_dup_task_struct(tsk, orig)` shallow-copies `*orig` into `*tsk`, `dup_task_struct()` must repoint `tsk->cpus_ptr = &tsk->cpus_mask` whenever `orig->cpus_ptr == &orig->cpus_mask` before `dup_user_cpus_ptr()`. [F75]
- In `load_elf_binary()`, `elf_property_phdata` must be reset to `NULL` before scanning `interp_elf_phdata` so `parse_elf_properties(interpreter ?: bprm->file, elf_property_phdata, &arch_state)` does not read the main executable's `PT_GNU_PROPERTY` offset from `interpreter`. [F67]
- Because `fs/compat_binfmt_elf.c` `#include`s `"binfmt_elf.c"`, top-level symbols and KUnit structures in `fs/binfmt_elf.c` must be macro-renamed in `fs/compat_binfmt_elf.c`, and `ELF_PAGESTART(_v)` must cast `(ELF_MIN_ALIGN - 1)` to signed `int` before negation (`~(int)(ELF_MIN_ALIGN - 1)`). [F115, F166]
