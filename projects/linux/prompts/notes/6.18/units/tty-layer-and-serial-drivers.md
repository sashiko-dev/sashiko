# TTY LAYER AND SERIAL DRIVERS

This unit implements the core Linux TTY subsystem (`tty_io.c`, `tty_buffer.c`, `tty_baudrate.c`, `tty_audit.c`), Magic SysRq (`sysrq.c`), the Serial Core and `serial-base` bus layers (`serial_core.c`, `serial_base_bus.c`, `serial_ctrl.c`, `serial_port.c`, `serial_mctrl_gpio.c`), the SyncLink GT TTY/HDLC driver (`synclink_gt.c`), and hardware UART drivers (OMAP, Owl, PCH, PIC32, PowerMac Zilog, PXA, RSCI, SA1100, SB1250, SC16IS7xx, SCCNXP, TXx9, SH-SCI, SiFive, Spreadtrum, STM32, Tegra TCU/UTC, Timberdale, and Xilinx UARTPS).

## Architecture & Data Flow

- `tty_buffer_alloc()` allocates `struct_size(p, data, 2 * size)` bytes for `size` chars and `size` flags, storing `size` in `p->size`; `port->buf.mem_used` tracks only active buffers on `buf->head` (adding `size` even when popping `buf->free` and subtracting `b->size` in `tty_buffer_free()`). If `flags == false`, all `2 * size` bytes hold chars, so `lookahead_bufs()` and `receive_buf()` must check `head->flags` before `flag_buf_ptr()`, and `__tty_buffer_request_room()` must allocate a new buffer when `!b->flags && flags`. [F397, F417, F484]
- In `tty_buffer_flush()` and `flush_to_ldisc()`, `buf->head` may only be freed and advanced when `smp_load_acquire(&buf->head->next)` is non-NULL so `buf->head` and `buf->tail` are never NULL, and `tty_buffer_flush()` must set both `buf->head->read` and `buf->head->lookahead` to `buf->head->commit` on the remaining tail buffer. [F418, F462]
- Under `tty_lock`, `tty->count` must equal open files in `tty->tty_files` plus 1 if `PTY_TYPE_SLAVE` has an open master (`tty->link->count`) plus 1 if `tty_port_kopened(tty->port)` is true (`tty_add_file()`/`tty_del_file()` must match `tty->count`). In `__tty_hangup()`, if any file has `write_iter == redirected_tty_write` (`cons_filp != NULL`), do not set `hung_up_tty_fops` on `cons_filp` and call `tty->ops->close(tty, cons_filp)` `closecount` times instead of `tty->ops->hangup(tty)`. [F420, F421]
- While `uport->rs485.flags & SER_RS485_ENABLED` is set, `uart_update_mctrl()`, `uart_suspend_port()`, `uart_resume_port()`, and `uart_configure_port()` must not call `uport->ops->set_mctrl()`; when `uart_set_rs485_config()` clears `SER_RS485_ENABLED`, it must call `port->ops->set_mctrl(port, port->mctrl)` under `port->lock`. Both `uart_sanitize_serial_rs485()` and `uart_get_rs485_mode()` must sanitize RTS delays via `uart_sanitize_serial_rs485_delays()` and mask `rs485->flags` with `port->rs485_supported.flags` before resolving RTS polarity. [F230, F249, F265]
- Both `uart_shutdown()` and `uart_tty_port_shutdown()` must call `tty_port_set_suspended(port, false)` so `uart_resume_port()` does not restart a port shut down while suspended, and `uart_suspend_port()` must save `uport->mctrl` before zeroing it under `uport->lock` across `ops->shutdown(uport)` and restore `uport->mctrl` afterward. [F232, F233]
- `struct uart_port port` must remain at offset 0 of `struct uart_pmac_port` (`to_pmz()`), `struct uart_pxa_port` (`serial_pxa_pops`), `struct sci_port` (`sci_request_irq()`/`sci_probe()` drvdata), and `struct sprd_uart_port` (`sprd_probe()` drvdata) because callbacks cast between `uart_port *` and the driver struct without `container_of()`. In `serial_base_bus.c`, `serial_ctrl_device` and `serial_port_device` share `serial_base_bus_type` and must be distinguished by checking `dev->type` before downcasting. [F114, F115, F121, F294, F298]

## Synchronization

- In `serial_core.c`, lock order is `tty->termios_rwsem` -> `port_mutex` -> `state->port.mutex` -> `uport->lock`. Paths dereferencing `state->uart_port` without `state->port.mutex` must pin it via `uart_port_ref()`/`uart_port_ref_lock()` and release via `uart_port_deref()`/`uart_port_unlock_deref()` (`uart_port_check()` requires `state->port.mutex`). `uart_port_unlock_deref()` must unlock `uport->lock` before `uart_port_deref(uport)`, and `uart_alloc_xmit_buf()`/`uart_free_xmit_buf()` must never call `free_page()` under `uport->lock`. [F173, F174, F193, F196]
- Serial drivers and core callbacks must lock `uport->lock` via `uart_port_lock*()`/`uart_port_unlock*()`, except `CON_NBCON` `device_lock`/`device_unlock` callbacks and `uart_port_set_cons()` which use `__uart_port_lock_irqsave()`. Legacy console `.write` callbacks must use `uart_port_trylock_irqsave()` when `oops_in_progress` is set (and skip locking when `port->sysrq` is set in `sh-sci`/`sprd`), while `CON_NBCON` write callbacks (`sifive`, `tegra-utc`) must bracket register accesses with `nbcon_enter_unsafe()`/`nbcon_exit_unsafe()`. [F160, F207, F340, F341, F343, F528, F532]
- UART RX interrupt handlers holding `port->lock` must not call `uart_handle_sysrq_char()` or `tty_flip_buffer_push()` while locked; they must either use `uart_prepare_sysrq_char()` under `port->lock` followed by `uart_unlock_and_check_sysrq()` (`cdns_uart_isr()`, `pxa`, `stm32-usart`) or drop `port->lock` around `uart_handle_sysrq_char()` (`tegra_utc_rx_chars()`). [F21, F338, F386]
- In `__tty_buffer_request_room()`, `smp_store_release(&b->commit, b->used)` must precede `smp_store_release(&b->next, n)`, and consumers (`flush_to_ldisc()`, `lookahead_bufs()`) must `smp_load_acquire(&head->next)` before `smp_load_acquire(&head->commit)`. `tty_buffer_alloc()` must use `GFP_ATOMIC | __GFP_NOWARN` without sleeping locks; `tty_buffer_lock_exclusive()`/`tty_buffer_flush()` must increment `port->buf.priority` before locking `port->buf.lock`, and `tty_buffer_unlock_exclusive()` must requeue `port->buf.work` if `head->commit != head->read`. [F372, F374, F514, F550]
- For PTY pairs, `tty->legacy_mutex` nests master-then-slave (`TTY_LOCK_NORMAL` before `TTY_LOCK_SLAVE`), whereas `port->buf.lock` nests slave-then-master (`tty_buffer_set_lock_subclass()`). `tty->write_buf` and `tty->write_cnt` require `tty->atomic_write_lock`; `tty_encode_baud_rate()` and `tty_get_baud_rate()` require `tty->termios_rwsem`; and multithreaded `tty_audit_buf` accesses require `buf->mutex`. [F380, F381, F383, F519]
- `__handle_sysrq()` runs `op_p->handler(key)` inside `rcu_read_lock()`, so handlers must not sleep, `__sysrq_swap_key_ops()` must call `synchronize_rcu()`, and `sysrq_handle_crash()` must call `rcu_read_unlock()` before `panic()`. `do_SAK()` and `tty_hangup()` may run in atomic context and must schedule `tty->SAK_work` and `tty->hangup_work`, whereas `tty_vhangup()` and `tty_vhangup_session()` must call `__tty_hangup()` synchronously. [F384, F516, F523, F541]
- `uart_rs485_config()` and `uart_set_rs485_config()` must call `gpiod_set_value_cansleep()` (and `copy_from_user()`/`copy_to_user()` in RS485/ISO7816 ioctls) outside `scoped_guard(uart_port_lock_irqsave, port)`. Likewise, `sh-sci` (`sci_dma_tx_release()`, `sci_dma_rx_release()`) and `stm32-usart` (`stm32_usart_shutdown()`) must call `cancel_work_sync()`, `dmaengine_terminate_sync()`/`dmaengine_synchronize()`, and `dma_free_coherent()` outside `port->lock`, and `cdns_uart_shutdown()` must call `hrtimer_cancel(&cdns_uart->tx_timer)` before locking `port->lock`. [F325, F327, F335, F339, F531]

## Object Lifetimes

- In `serial_base_bus.c`, `serial_base_device_init()` acquires an `of_node` reference via `device_set_of_node_from_dev()`, so `.release` callbacks must call `of_node_put(dev->of_node)`, and any error after `serial_base_device_init()` must use `put_device()` instead of `kfree()`. `serial_base_port_add()` must free `port->port_id` via `ida_free(&ctrl_dev->port_ida, port->port_id)` on error and in `serial_base_port_device_remove()`, which must be called before `serial_base_ctrl_device_remove()`. [F1, F2, F125, F163]
- `serial_core_register_port()` must set `UPF_DEAD` before `serial_core_port_device_add()` until `serial_core_add_one_port()` configures the port, passing `new_ctrl_dev` (`NULL` if reused) to `serial_base_ctrl_device_remove()` on error. `serial_core_unregister_port()` must read `port->dev`, `port->port_dev`, `ctrl_dev`, and `port->ctrl_id` before `serial_core_remove_one_port()` (which waits on `state->remove_wait` for `state->refcount == 0` under `state->port.mutex` and zeroes `state->uart_port`), removing `ctrl_dev` only if `!serial_core_ctrl_find()`. [F177, F178, F192, F194]
- In `__uart_start()`, `pm_runtime_get(&port_dev->dev)` unconditionally increments the usage count (while `pm_runtime_enabled()` checks parent `port->dev`), so an error (`err < 0 && err != -EINPROGRESS`) must call `pm_runtime_put_noidle(&port_dev->dev)` while success calls `pm_runtime_put_autosuspend(&port_dev->dev)`. `uart_suspend_port()`/`uart_resume_port()` must call `put_device(tty_dev)` after `device_find_child()`, and `uart_line_info()`/`uart_poll_init()` must restore saved `state->pm_state` after `uart_change_pm(state, UART_PM_STATE_ON)`. [F175, F181, F183, F279]
- In `tty_init_dev()`, once `tty_driver_install_tty()` succeeds, error paths must unlock `tty` and call `release_tty(tty, idx)` rather than `free_tty_struct(tty)`. `tty_release_struct()` and `tty_kclose()` must call `tty_ldisc_release(tty)` and `tty_flush_works(tty)` before locking `tty_mutex` and calling `release_tty()`, because `tty_kref_put()` -> `queue_release_one_tty()` reuses `tty->hangup_work` to schedule `release_one_tty()`. [F354, F358, F522]
- `tty_buffer_free_all()` drains `port->buf.head` and `port->buf.free` without locking and warns if `atomic_xchg(&buf->mem_used, 0)` mismatches freed bytes, so it must only be called after `port->buf.work` is canceled and all producers/consumers have stopped; both `tty_buffer_free()` and `tty_buffer_free_all()` must check `b->size > 0` to avoid freeing the embedded `port->buf.sentinel`. [F375, F487]

## API Contracts

- `uart_handle_dcd_change()`, `uart_handle_cts_change()`, `uart_write_wakeup()`, and `uart_update_timeout()` require `uport->lock` held (lockless readers of `port->frame_time` must use `READ_ONCE()`). Callers of `uart_update_timeout()`, `uart_get_divisor()`, and `cdns_uart_calc_baud_divs()` must pass a non-zero `baud` rate, and `uart_update_timeout()` must widen `tty_get_frame_size(cflag)` to `u64` and use `DIV64_U64_ROUND_UP`. [F200, F201, F280, F281, F478]
- `mctrl_gpio_init()` and `mctrl_gpio_init_noauto()` return `ERR_PTR` on error when `CONFIG_GPIOLIB=y` and `NULL` when `CONFIG_GPIOLIB=n`, and all `mctrl_gpio_*` helpers treat `NULL` (not `ERR_PTR`) as a no-op; callers must check `IS_ERR(gpios)` and reset `gpios = NULL` when ignoring non-deferral errors. `mctrl_gpio_set()`/`get()`/`get_outputs()` run under `uart_port_lock_irqsave` and must use non-sleeping `gpiod_*` calls; atomic callers must use `mctrl_gpio_disable_ms_no_sync()`. [F38, F211, F328, F329]
- `tty_init_dev()` and `tty_kopen_exclusive()` return `tty` with `tty_lock(tty)` held, whereas `tty_kopen_shared()` returns `tty` with an incremented kref and without `tty_lock(tty)` held. `tty_driver_lookup_tty()` returns `ERR_PTR`, `NULL`, or a `tty` with an incremented kref, and `tty_open_current_tty()` returns `NULL` only when `device != MKDEV(TTYAUX_MAJOR, 0)` (returning `ERR_PTR` on `/dev/tty` open failure, which `tty_open()` must propagate). [F355, F391, F392]
- `tty_termios_encode_baud_rate(termios, ibaud, obaud)` takes `ibaud` before `obaud`, forces `ibaud = 0` when `obaud == 0`, samples `ibinput` and `BOTHER` before clearing `CBAUD` and `CBAUD << IBSHIFT`, and matches `obaud` (`ofound = i`) before `ibaud` in each loop pass. In `tty_termios_baud_rate()` and `tty_termios_input_baud_rate()`, `cbaud == BOTHER` must be checked before `cbaud & CBAUDEX` (`0x1000`). [F407, F415, F454, F467]

## Error Handling

- In `tty_open()`, `tty_free_file()` may only be used before `tty_add_file()`; once `tty_add_file()` is called, error cleanup must call `tty_release()` and reset `filp->f_op = &tty_fops` if `tty_hung_up_p(filp)` before `retry_open`. In `tty_register_device_attr()`, failure of `device_register(dev)` must only call `put_device(dev)` while failure of `tty_cdev_add()` must call `device_del(dev)` then `put_device(dev)`. [F360, F401]
- In `iterate_tty_read()`, if `copy_to_iter()` copies fewer than `size` bytes while `cookie` is non-NULL, the loop must continue with `count = 0` and `retval = -EFAULT` so `ld->ops->read()` cleans up `cookie` without overwriting `retval`; `iterate_tty_read()` must zero `kernel_buf` via `memzero_explicit()` and `receive_buf()` must zero consumed flip-buffer bytes via `memset(p, 0, n)`. In `iterate_tty_write()`, a partial `ld->ops->write` (`0 < ret < size`) must call `iov_iter_revert(from, size - ret)`. [F402, F403, F469]
- In `tty_ioctl()` and `tty_compat_ioctl()`, `tty_jobctrl_ioctl()` and `tty->ops->ioctl()`/`compat_ioctl()` must return `-ENOIOCTLCMD` when unhandled so dispatch falls through to `ld->ops->ioctl()`, and `tty_ioctl()` translates a final `-ENOIOCTLCMD` to `-ENOTTY`; `case TCFLSH:` must break (not return) after `tty_buffer_flush()`. [F394, F457]
- `serial_port_runtime_suspend()` must return `0` immediately when `!pm_runtime_enabled(dev)` so system suspend via `pm_runtime_force_suspend()` is not aborted with `-EBUSY` on pending TX, and both `serial_port_runtime_resume()` and `serial_port_runtime_suspend()` must only call `port->ops->start_tx(port)` when `!(port->flags & UPF_DEAD)` and `port_dev->tx_enabled` is true under `uart_port_lock_irqsave()`. [F306, F307]

## External Contracts

- In `uart_set_info()`, callers without `capable(CAP_SYS_ADMIN)` may only modify `uport->flags & UPF_USR_MASK` and `uport->custom_divisor` (`-EPERM` otherwise), and changing IRQ or port resources also requires `!security_locked_down(LOCKDOWN_TIOCSSERIAL)`; when `!(uport->flags & UPF_FIXED_PORT)`, `uartclk = new_info->baud_base * 16` must be checked for `0` overflow and `irq < 0 || irq >= irq_get_nr_irqs() || baud_base < 9600` rejected with `-EINVAL`. In `uart_line_info()`, `uart_change_pm()`, `get_mctrl()`, and emitting `icount`/modem status require `capable(CAP_SYS_ADMIN)`. [F255, F347, F348]
- `tiocsti()` must enforce `!tty_legacy_tiocsti && !capable(CAP_SYS_ADMIN)` (`-EIO`) and `(current->signal->tty != tty) && !capable(CAP_SYS_ADMIN)` (`-EPERM`), calling `tty_audit_tiocsti()` before delivering `ch` under `tty_buffer_lock_exclusive()`. `tty_audit_add_data()` must skip `PTY_TYPE_MASTER` and non-echoed canonical input (`icanon && !L_ECHO(tty)` unless `AUDIT_TTY_LOG_PASSWD`), clamp copies to `TTY_AUDIT_BUF_SIZE - buf->valid`, and flush via `tty_audit_buf_push()` when full or when `dev`/`icanon` changes. [F440, F542, F546]

## Known Pitfalls

- Callers of `__tty_buffer_request_room()` (`__tty_insert_flip_string_flags()`, `tty_prepare_flip_string()`) must read `port->buf.tail` only after `__tty_buffer_request_room()` returns because it may replace `port->buf.tail`, and the `*chars` pointer from `tty_prepare_flip_string()` must never be used as a hardware DMA target. In `tty_buffer_space_avail()`, `port->buf.mem_limit - atomic_read(&port->buf.mem_used)` must be evaluated as signed `int` and clamped with `max(space, 0)`. [F482, F486, F515]
- `file_tty_write()` must use its `file` parameter rather than `iocb->ki_filp` (which still points to `/dev/console` under `redirected_tty_write()`). Before calling `file_tty(file)` on an arbitrary `struct file *` (as in `this_tty()` via `iterate_fd()`, which must return `fd + 1` on match), verify `file->f_op->read_iter == tty_read`. [F395, F473, F488]
- Because `serial_core_add_one_port()` sets the TTY class device's drvdata to `struct tty_port *` (`&state->port`), sysfs callbacks in `tty_dev_attrs` and `uport->attr_group` must cast `dev_get_drvdata(dev)` to `struct tty_port *`, and `uart_get_info()` must zero `*retinfo` at entry before checking `!uport` because sysfs `.show` callbacks ignore its return value. [F253, F291]
