# GENERIC PHY FRAMEWORK

The Generic PHY framework defines subsystem-wide API contracts (`struct phy`, `struct phy_ops`, `union phy_configure_opts`), DT bindings, and transceiver/clock/reset provider drivers for Cadence (D-PHY RX/TX, Salvo, Sierra, Torrent), Freescale/NXP i.MX8/i.MX95 (MIPI D-PHY, PCIe, USB, HSIO, LVDS, Samsung HDMI), Socionext UniPhier, STMicroelectronics STM32 USBPHYC, and Texas Instruments (AM654 SERDES, J721E WIZ, OMAP USB2/Control, PIPE3, GMII-SEL, TUSB1210 ULPI, TWL4030 USB).

## Architecture & Data Flow
- In `cdns_torrent_phy_configure_multilink`, when two PCIe subnodes are temporarily set from `TYPE_PCIE` to `TYPE_PCIE_ML` for table lookup, their `phy_type` fields must be restored to `TYPE_PCIE` before returning so `cdns_torrent_phy_on` and `cdns_torrent_phy_resume_noirq` observe `TYPE_PCIE`. In both `cdns_torrent_phy_configure_multilink` and `cdns_sierra_phy_configure_multilink`, the second pass (`protocol == 1` or `node == 1`) must swap `phy_t1`/`phy_t2` (and `ref_clk`/`ref_clk1` in Torrent) before indexing tables. [F48, F74]
- In `phy-cadence-sierra.c`, when `sp->nsubnodes > 1`, shared common CDB registers and `sp->phy_rst` are configured and deasserted once during probe in `cdns_sierra_phy_configure_multilink`, so `cdns_sierra_phy_init` must return early and `cdns_sierra_phy_on` must only deassert `sp->phy_rst` when `sp->nsubnodes == 1`. When `sp->already_configured` is non-zero (`sp->pma_cmn_ready`), `PHY_CLK` and resets (`sp->phy_rst`, `sp->apb_rst`) are not acquired, child PHYs use `noop_ops`, and `cdns_sierra_phy_disable_clocks` must skip `sp->input_clks[PHY_CLK]`. [F45, F47]
- In `phy-cadence-torrent.c`, `base`, `regmap_dptx_phy_reg`, and `phy_reset_ctrl` are only initialized in `cdns_torrent_phy_probe` when a child subnode has `phy_type == TYPE_DP`. In `cdns_torrent_dp_init` and `cdns_torrent_phy_configure_multilink`, `cdns_torrent_dp_get_pll` must populate `cdns_phy->dp_pll` (`DP_PLL0`/`DP_PLL1`) before calling `cdns_torrent_dp_common_init`, `cdns_torrent_dp_pma_cmn_vco_cfg_100mhz`, `cdns_torrent_dp_pma_cmn_rate`, or `cdns_torrent_dp_configure_rate`, and common PLL0/PLL1 registers must only be modified or polled for bits set in `cdns_phy->dp_pll`. [F31, F42, F51]
- In `cdns_torrent_dp_set_rate`, `cdns_torrent_dp_configure_rate` must only run after placing lanes in `POWERSTATE_A3` (`cdns_torrent_dp_set_power_state`) and disabling PLL clocks (`cdns_torrent_dp_set_pll_en`), and must disable `cdns_phy->dp_pll` in `phy_pma_pll_raw_ctrl` before changing VCO settings. In `cdns_torrent_dp_set_voltages`, `TX_DIAG_ACYA_HBDC_MASK` (bit 0 of `TX_DIAG_ACYA`) must be set to 1 on `inst->mlane + lane` before writing `TX_TXCC_CTRL`, `DRV_DIAG_TX_DRV`, `TX_TXCC_MGNFS_MULT_000`, and `TX_TXCC_CPOST_MULT_00`, and cleared to 0 afterward. [F52, F53]
- Every `struct cdns_torrent_vals` entry in `link_cmn_vals_tbl` must have `num_regs >= 1` and store `PHY_PLL_CFG` at `reg_pairs[0]`, because `cdns_torrent_phy_init` and `cdns_torrent_phy_configure_multilink` write `reg_pairs[0].val` to `cdns_phy->phy_pll_cfg` and `reg_pairs[1..num_regs-1]` to `regmap_common_cdb`. In `phy-cadence-sierra.c`, per-link lane regmaps (`regmap_phy_pma_lane_cdb`, `regmap_lane_cdb`) must be indexed by `i + ins->mlane` (`0 <= i < ins->num_lanes`) and link status (`phy_iso_link_ctrl_1`, `pllctrl_lock`) by `ins->mlane`. [F46, F62]
- In `mixel_dphy_priv` (`phy-fsl-imx8-mipi-dphy.c`), `lvds_regmap` and `ipc_handle` are only populated when `devdata->is_combo` is true (`MIXEL_IMX8QXP`), while `devdata` register offsets (`reg_tx_rcal`, `reg_auto_pd_en`, `reg_rxlprp`, `reg_rxcdrp`, `reg_rxhs_settle`) are only populated when `is_combo` is false (`MIXEL_IMX8MQ`). `mixel_dphy_configure_lvds_phy` must update `priv->is_slave` from `opts->lvds.is_slave` alongside `IMX_SC_C_DUAL_MODE`, and `mixel_dphy_power_on_lvds_phy` must skip `DPHY_LOCK` polling when `priv->is_slave` is true. [F29, F54]
- In `phy-fsl-samsung-hdmi.c`, `fsl_samsung_hdmi_phy_configure` must use 8-bit `writeb()`/`readb_poll_timeout()` at 4-byte-strided `PHY_REG(reg)` offsets, update `phy->cur_cfg = cfg`, mirror `cfg->pll_div_regs[2] >> 4` (`REG03_PMS_S_MASK`, `s - 1`) into `REG21_PMS_S_MASK` of `PHY_REG(21)`, and assert `REG33_FIX_DA | REG33_MODE_SET_DONE` in `PHY_REG(33)` only after writing all PLL and lock-detector registers and before polling `PHY_REG(34)` for `REG34_PLL_LOCK`. [F59, F66, F118]
- In `phy-gmii-sel.c`, `phy_gmii_init_phy` must copy each template entry from `soc_data->regfields[port - 1]` into a local `struct reg_field` and add `priv->reg_offset` before `devm_regmap_field_alloc()`, incrementing `*fields++` at every enum position (`PHY_GMII_SEL_PORT_MODE`, `PHY_GMII_SEL_RGMII_ID_MODE`, `PHY_GMII_SEL_RMII_IO_CLK_EN`) even when its `soc_data->features` bit is unset. In `phy_gmii_sel_mode`, `PHY_INTERFACE_MODE_RGMII_RXID` must keep `rgmii_id = 0` (like `RGMII`), and SoCs with `BIT(PHY_GMII_SEL_FIXED_TX_DELAY)` must reject `rgmii_id != 0` with `-EINVAL`. [F199, F226, F233, F255]

## Synchronization
- `struct phy` protects its `struct phy_ops` callbacks with `struct mutex mutex` (initialized with a per-instance `struct lock_class_key lockdep_key` to allow nested upstream `phy_ops` calls), so `phy_ops` callbacks execute in sleeping process context and must not be called from atomic context. Before calling `of_phy_provider_register()` or `devm_of_phy_provider_register()`, drivers must set per-PHY drvdata (`phy_set_drvdata()`) and controller drvdata (`dev_set_drvdata()`) and complete all subnode/multilink initialization (`mixel_lvds_phy_probe`, `cdns_sierra_phy_probe`, `cdns_torrent_phy_probe`). [F14, F21, F158, F159, F274]
- In `phy-cadence-sierra.c`, `phy-cadence-torrent.c`, and `phy-j721e-wiz.c`, regmaps accessed by `clk_ops` `.enable`, `.disable`, or `.is_enabled` callbacks in atomic context (`cdns_sierra_common_cdb_config`, `cdns_torrent_common_cdb_config`, `cdns_torrent_phy_pcs_cmn_cdb_config`, and `wiz_regmap_config` for `wiz_phy_en_refclk_ops`) must remain non-sleeping spinlock-backed (`.fast_io = true` for CDB regmaps). In `cdns_torrent_clk_register`, `cdns_phy->clk_hw_data`, `derived_refclk`, and `received_refclk` must be registered before `cdns_torrent_refclk_driver_register`, and all three before `of_clk_add_hw_provider`. [F18, F19, F282]
- In `phy-fsl-imx8qm-lvds-phy.c`, `mixel_lvds_phy_probe` must initialize `priv->lock` and `dev_set_drvdata` before `pm_runtime_enable` and `mixel_lvds_phy_reset`, and `mixel_lvds_phy_reset` must not hold `priv->lock` across `pm_runtime_resume_and_get` or `pm_runtime_put`. `mixel_lvds_phy_validate` caches `opts->lvds` into `lvds_phy->cfg` under `priv->lock` (`PHY_NUM == 2`, `id` in `{0, 1}` using `priv->phys[lvds_phy->id ^ 1]`), and `mixel_lvds_phy_power_on`/`off` must return 0 immediately when `lvds_phy->cfg.is_slave` is true, leaving the master PHY under `priv->lock` to toggle `priv->phy_ref_clk` and `CH_EN(0) | CH_EN(1)`. [F13, F57, F70, F117]
- In `phy-fsl-imx8mq-usb.c`, `imx95_usb_phy_get_tca` must initialize `tca->base`, `tca->mutex`, and `tca->orientation` before calling `tca_blk_get_typec_switch`. `tca_blk_typec_switch_set` must enable `imx_phy->clk` around `tca_blk_orientation_set`; `tca_blk_orientation_set` must hold `tca->mutex` while programming `TCA_GCFG`, `TCA_TCPC`, and `TCA_SYSMODE_CFG` (asserting `TCA_SYSMODE_TCPC_DISABLE` before changing `TCA_SYSMODE_TCPC_FLIP`) and caching `tca->orientation`; and `tca_blk_init` must not hold `tca->mutex` when re-applying `tca->orientation` after toggling `TCA_CLK_RST_SW`. [F16, F17, F58, F113]
- In `phy-fsl-imx8qm-hsio.c`, `imx_hsio_power_on` and `imx_hsio_power_off` must update `priv->open_cnt` under `priv->lock`, configuring shared misc/clock-pad registers only when `priv->open_cnt` transitions from 0 to 1 and clearing shared misc/ctrl/phy reset bits only when `priv->open_cnt` decrements to 0. [F10]

## Object Lifetimes
- Non-devm clock providers registered via `of_clk_add_hw_provider` or `of_clk_add_provider` in `cdns_sierra_clk_register`, `cdns_torrent_clk_register`, `phy_clk_register` (`phy-fsl-samsung-hdmi.c`), `serdes_am654_probe` (alongside `pm_runtime_disable`), and `wiz_clock_probe` (`wiz_clock_cleanup`, which must also balance `of_get_child_by_name` with `of_node_put` for `clk_mux_sel` and `clk_div_sel` and match the exact `switch (wiz->type)` variants) must be unregistered via `of_clk_del_provider` on probe failure after registration and in `.remove`. [F8, F150, F152, F230]
- In `cdns_sierra_phy_probe` and `cdns_torrent_phy_probe`, subnode link resets (`phys[node].lnk_rst`) are acquired via non-devm `of_reset_control_array_get_exclusive`. Errors inside `for_each_available_child_of_node()` before `of_reset_control_array_get_exclusive()` succeeds must jump to `put_lnk_rst`/`put_control` (releasing `0 .. node - 1`), whereas errors after it succeeds must also release the current `node`'s `lnk_rst` (jumping to `put_child` in Torrent), matching `.remove`. [F3, F26]
- In `phy-stm32-usbphyc.c`, enabling and disabling the shared PLL and `vdda1v1`/`vdda1v8` regulators across PHY ports and `ck_usbo_48m` must go through `stm32_usbphyc_pll_enable()` and `stm32_usbphyc_pll_disable()` (`usbphyc->n_pll_cons`), and `usbphyc_phy->active` must be true iff that port holds a count in `n_pll_cons`. `stm32_usbphyc_remove` must call `stm32_usbphyc_phy_exit` on active ports and `stm32_usbphyc_clk48_unregister` before `clk_disable_unprepare(usbphyc->clk)`. [F165, F195, F271]
- In `wiz_probe` and `wiz_remove` (`phy-j721e-wiz.c`), `child_node = of_get_child_by_name(node, "serdes")` must be released with `of_node_put(child_node)` on all probe exit paths, and `wiz_remove` must destroy `wiz->serdes_pdev` via `of_platform_device_destroy()` before calling `wiz_clock_cleanup()` and disabling runtime PM. In `omap_usb2_probe` and `ti_pipe3_get_sysctrl`, companion devices from `of_find_device_by_node()` must tie `put_device(&control_pdev->dev)` to `devm_add_action_or_reset()`. [F144, F151]
- In `phy-tusb1210.c`, `tusb1210_get_online` must release the `power_supply_get_by_name()` reference via `power_supply_put()` before returning rather than caching it. Any failure in `tusb1210_probe` after `tusb1210_probe_charger_detect(tusb)` must call `tusb1210_remove_charger_detect(tusb)` (which guards cleanup with `!IS_ERR_OR_NULL(tusb->psy)` and unregisters `psy_nb` and cancels `chg_det_work` before `power_supply_unregister(tusb->psy)`), and every path after `TUSB1210_CHG_DET_CONNECTING` in `tusb1210_chg_det_work` must reach `TUSB1210_CHG_DET_FINISH_DET` to call `pm_runtime_put(tusb->dev->parent)`. [F145, F146, F188, F234]

## API Contracts
- In `include/linux/phy/phy.h` and `include/linux/phy/omap_control_phy.h`, any change to exported declarations under `#if IS_ENABLED(CONFIG_GENERIC_PHY)` or `#if IS_ENABLED(CONFIG_OMAP_CONTROL_PHY)` must update the `#else` static inline stubs in lockstep. Optional getters (`devm_phy_optional_get`, `devm_of_phy_optional_get`) return `NULL` when absent or disabled, non-optional getters return `ERR_PTR`, and operation wrapper stubs under `#else` must return `0` when `!phy` before returning `-ENOSYS` or `-ENODEV`. [F169, F170, F211]
- `phy_ops.validate` may adjust `union phy_configure_opts *opts` but must not mutate hardware or `struct phy` state (`cdns_dphy_validate` and `mixel_dphy_validate` must use stack-local config structs without mutating `dphy->cfg` or `priv->cfg`), whereas `.configure` requires `phy_init()` first. In `cdns-dphy.c`, `cdns_dphy_configure` only updates `dphy->cfg` and sets `dphy->is_configured`, while `cdns_dphy_power_on` rejects calls if `!dphy->is_configured || dphy->is_powered` and programs registers and polls `cdns_dphy_wait_for_pll_lock`/`cdns_dphy_wait_for_cmn_ready` after enabling clocks and `DPHY_CMN_SSM_EN`. [F43, F55, F98, F171]
- In `struct phy_configure_opts_dp` (`phy-dp.h`), `link_rate` is in Mb/s, and DisplayPort `.configure` implementations must gate updates on `set_rate`, `set_lanes`, and `set_voltages`, applying `voltage[]`/`pre[]` only to lanes `0 .. lanes - 1` (after `cdns_torrent_dp_verify_config` checks `voltage[i] + pre[i] <= 3`). In `struct phy_configure_opts_mipi_dphy` (`phy-mipi-dphy.h`), `hs_clk_rate` and `lp_clk_rate` are in Hz, `clk_pre` in UI, `init` and `wakeup` in microseconds (`cdns_dphy_config_from_opts` divides `get_wakeup_time_ns()` by 1000), and all other timing fields in picoseconds. [F41, F63, F172, F173, F284]
- In `phy-cadence-sierra.c`, `phy-cadence-torrent.c`, `phy-fsl-imx8qm-lvds-phy.c`, `phy-stm32-usbphyc.c`, and `phy-gmii-sel.c`, `phy_set_drvdata()` stores the per-link/per-port instance on `struct phy`, while `dev_set_drvdata()` stores the parent controller state on `phy->dev.parent`. In Sierra and Torrent, CDB regmaps (`cdns_regmap_write`/`read`) shift the register index by `reg_offset_shift` for 16-bit accesses, whereas Torrent's DPTX regmap uses unshifted byte offsets and 32-bit accesses. [F35, F96, F247]
- In `phy-gmii-sel.c`, port IDs (`if_phy->id`, `args->args[0]`, `main_ports`) are 1-based (`1..num_ports`), must be bounds-checked to `[1, soc_data->num_ports]`, and converted to `id - 1` when indexing `priv->if_phys`, `soc_data->regfields`, or `qsgmii_main_ports` (`PHY_GMII_PORT`). In `phy-j721e-wiz.c`, reset ID 0 in `wiz_phy_reset_assert`/`deassert` controls `wiz->phy_reset_n` (and sleeps when `wiz->gpio_typec_dir` is set), while reset IDs `1..num_lanes` index `id - 1`. [F179, F181, F239, F281]

## Error Handling
- Sentinel/pointer conventions: `imx95_usb_phy_get_tca()` returns `NULL` when resource 1 is absent and `ERR_PTR` on failure (check `IS_ERR` in probe, null-check at runtime/remove), whereas `tca_blk_get_typec_switch` converts `ERR_PTR` to `NULL` on `tca->sw`; optional VBUS regulators (`devm_regulator_get_optional()`) in `stm32_usbphyc_probe` and UniPhier probes must overwrite non-`-EPROBE_DEFER` `IS_ERR` returns with `NULL`; optional syscons (`syscon_regmap_lookup_by_phandle`) in `ti_pipe3_get_sysctrl`, `omap_usb2_probe`, and `wiz_probe` (`"ti,scm"` on non-`J7200_WIZ_10G`) must be cleared to `NULL` on error; and optional clocks in `struct ti_pipe3` (`refclk`, `wkupclk`, `div_clk`) and `struct omap_usb` (`optclk`) hold `ERR_PTR` when absent and must be checked with `!IS_ERR()`. [F9, F23, F177, F182, F183, F184]
- Return value and state preservation: `cdns_dphy_rx_get_band_ctrl()` and `cdns_dphy_tx_get_band_ctrl()` return valid band index `0` or `-EOPNOTSUPP` (check `< 0`); `twl4030_readb()` and `twl4030_usb_read()` return `0..255` or negative errno (check `>= 0`); `cdns_torrent_refclk_driver_register()` checking `IS_ERR_OR_NULL(hw)` must return `IS_ERR(hw) ? PTR_ERR(hw) : -ENOENT`; and in `cdns_sierra_phy_probe`, `cdns_torrent_phy_probe`, `stm32_usbphyc_probe`, and `wiz_probe` (where `devm_ioremap` and `of_platform_device_create` return `NULL`), jumping to a cleanup label after a bounds/NULL check when `ret == 0` requires assigning a negative errno to `ret` first. [F22, F24, F27, F174, F180, F187]

## Known Pitfalls
- Arithmetic and hardware quirks: in `mixel_dphy_config_from_opts`, `dphy_opts->hs_prepare < lp_t` (and `clk_prepare < lp_t`) must be checked before subtracting `lp_t` to avoid 32-bit unsigned underflow; in `fsl_samsung_hdmi_phy_find_pms`, `if (_s > 1 && (_s & 0x01) == 1) _s++;` must precede `if (_s == 14) continue;`; in `cdns_dphy_power_on`, updating `DPHY_CMN_SSM` must preserve `DPHY_CMN_SSM_CAL_WAIT_TIME`; in `phy-cadence-torrent.c`, `CDNS_TORRENT_KEY` packs 3-bit fields (`0..7`), where `TYPE_PCIE_ML` is already 7; in `wiz_probe`, `wiz_init` must be skipped if any lane has `P_ENABLE`/`P_ENABLE_FORCE` set, and `wiz_mode_select` must place all protocol branches before `else continue;`; and in `uniphier_pciephy_set_param` and `uniphier_u3ssphy_set_param`, indirect test register writes must preserve unmasked bits and follow every `writel` to `TEST_I` with two dummy `readl`s from `TEST_O`. [F79, F85, F88, F99, F191, F192, F225, F260, F273]
