# ARM SMMU DRIVERS

This unit implements the Linux IOMMU subsystem drivers for ARM System MMU architectures (SMMUv1, SMMUv2, and SMMUv3) along with the CPU-agnostic ARM LPAE (v7/v8 long-descriptor, stage-1/stage-2, and Mali) and ARMv7s (short-descriptor) I/O page table allocators. It manages DMA address translation, stream tables (STEs) and stream mapping groups (SMRs/S2CRs), context descriptors (CDs) and context banks, hardware command/event/PRI queues, TLB/ATC invalidations, fault reporting (IOPF), and IOMMUFD nested virtualization (vSMMU).

## Architecture & Data Flow

- In `arm_smmu_attach_commit()`, `arm_smmu_remove_master_domain()` for `state->old_domain` must precede updating `master->ats_enabled = state->ats_enabled` so `smmu_domain->nr_ats_masters` is decremented using the old ATS state; because `arm_smmu_attach_prepare()` inserts the new `arm_smmu_master_domain` into `smmu_domain->devices` before commit, `arm_smmu_find_master_domain()` must match `master`, `domain`, `ssid`, and `nested_ats_flush` and unlink only that single entry. [F3, F123]
- In SMMUv3, `to_smmu_domain()` is valid only for paging and SVA domains (`IOMMU_DOMAIN_NESTED` uses `to_smmu_nested_domain()` on `struct arm_smmu_nested_domain`, and identity/blocked domains are bare `struct iommu_domain`); paths accepting arbitrary domains must use `to_smmu_domain_devices()`. [F55]
- In `arm_smmu_write_cd_entry()`, `master->cd_table.used_ssids` must be incremented or decremented only when `ssid != IOMMU_NO_PASID` and the `CTXDESC_CD_0_V` bit of `cdptr->data[0]` differs from `target->data[0]`; whenever an STE is installed via `arm_smmu_install_ste_for_dev()`, `master->cd_table.in_ste` and `master->ste_ats_enabled` must be updated in lockstep from the target STE's `STRTAB_STE_0_CFG` and `STRTAB_STE_1_EATS` fields. [F9, F73]
- In `arm_smmu_entry_qword_diff()`, every bit set in `target` by `arm_smmu_make_*_ste()` or `arm_smmu_make_*_cd()` must be marked in `target_used` by `arm_smmu_get_ste_used()` or `arm_smmu_get_cd_used()`, and in `arm_smmu_get_ste_used()`, `cfg & BIT(0)` (stage-1) and `cfg & BIT(1)` (stage-2) must remain independent `if` statements so `STRTAB_STE_0_CFG_NESTED` (`0b111`) marks both. [F111, F116]
- When invalidating a stage-2 domain with `smmu_domain->nest_parent` set, `arm_smmu_tlb_inv_range_domain()` must also issue `CMDQ_OP_TLBI_NH_ALL` for the VMID, and `arm_smmu_atc_inv_domain()` must flush the entire ATC (`size == 0`, `IOMMU_NO_PASID`) for masters with `nested_ats_flush` set. [F76]
- In SMMUv3, `struct arm_smmu_ctx_desc_cfg` (`.linear` vs `.l2`) must only be accessed when `arm_smmu_cdtab_allocated(cd_table)` is true and discriminated by `cd_table->s1fmt`, while `struct arm_smmu_strtab_cfg` (`.linear` vs `.l2`) is discriminated by `smmu->features & ARM_SMMU_FEAT_2_LVL_STRTAB`; `arm_smmu_sid_in_range()` must verify `sid` against `l2.num_l1_ents` or `linear.num_ents` before `arm_smmu_init_sid_strtab()` or `arm_smmu_get_step_for_sid()` indexes the table. [F56, F57, F97]
- Because bit 31 of `cmdq->q.llq.prod` holds `CMDQ_PROD_OWNED_FLAG`, `arm_smmu_cmdq_issue_cmdlist()` must strip `~CMDQ_PROD_OWNED_FLAG` from `llq.prod`, `head.prod`, and `prod` before indexing entries, updating `cmdq->valid_map`, writing `cmdq->q.prod_reg`, or releasing `cmdq->owner_prod`; `queue_inc_cons()` and `queue_inc_prod_n()` must mask sums to `Q_WRP | Q_IDX` while preserving `Q_OVF`, and `queue_consumed()` must compare `Q_IDX` conditioned on `Q_WRP` equality. [F102, F141]
- In SMMUv1/v2, `smmu_domain->smmu`, `smmu_domain->pgtbl_ops`, and `smmu_domain->flush_ops` remain `NULL` after `arm_smmu_domain_alloc_paging()` until `arm_smmu_init_domain_context()` succeeds, `smmu->smrs` is `NULL` when `!(ARM_SMMU_FEAT_STREAM_MATCH)`, and `smmu->impl` and its callbacks are optional (`NULL` on generic devices); `arm_smmu_probe_device()` must validate `fwspec->ids[i]` against `smmu->streamid_mask` and `smmu->smr_mask_mask`, and `arm_smmu_find_sme()` must check exact/subset SMR match before overlap across all `num_mapping_groups`. [F53, F58, F59, F98, F115]

## Synchronization

- `arm_smmu_asid_lock` must be held continuously across `arm_smmu_attach_prepare()`, STE/CD installation, and `arm_smmu_attach_commit()`, and every acquisition of `smmu_domain->devices_lock` in `arm-smmu-v3.c` must use `spin_lock_irqsave()`/`spin_unlock_irqrestore()`; in `arm_smmu_attach_dev_ste()`, `arm_smmu_clear_cd(master, IOMMU_NO_PASID)` must run after `arm_smmu_attach_commit()` removes the master from the old domain's `devices` list and drops `arm_smmu_asid_lock`. [F30, F33, F180]
- In `arm_smmu_set_pasid()`, `CTXDESC_CD_0_ASID` in `cd->data[0]` must be refreshed from `smmu_domain->cd.asid` after acquiring `arm_smmu_asid_lock` and before `arm_smmu_write_cd_entry()`; in `arm_smmu_sva_set_dev_pasid()`, `mmget_not_zero(domain->mm)` must be held across `arm_smmu_make_sva_cd()` and `arm_smmu_set_pasid()` and released via `mmput()` so `arm_smmu_mm_release()` cannot concurrently invalidate the CD. [F32, F36]
- In `arm_smmu_atc_inv_domain()`, `smp_mb()` must execute after main TLB invalidations and before `atomic_read(&smmu_domain->nr_ats_masters)` to pair with `atomic_inc(&smmu_domain->nr_ats_masters)` in `arm_smmu_attach_prepare()`; when disabling ATS (`!state->ats_enabled && master->ats_enabled`), `arm_smmu_attach_prepare()` must call `pci_disable_ats()` and `wmb()` before clearing STE `EATS`, whereas when enabling ATS, `arm_smmu_attach_commit()` must call `arm_smmu_enable_ats()` only after installing the STE with `EATS` set. [F29, F31]
- In `arm_smmu_write_entry()`, any STE/CD update where `arm_smmu_entry_qword_diff()` reports in-use changes in multiple qwords must zero qword 0 (`V=0`) via `entry_set()`, write qwords 1..7 and sync, then write qword 0 (`V=1`) and sync; in `arm_smmu_alloc_cd_ptr()`, after writing a new L1 CD descriptor via `arm_smmu_write_cd_l1_desc()`, `arm_smmu_sync_cd(master, ssid, false)` must be called to invalidate cached invalid L1 descriptors. [F27, F28]
- In `arm_smmu_cmdq_issue_cmdlist()`, local IRQs must be disabled via `local_irq_save()` while holding `CMDQ_PROD_OWNED_FLAG` or `cmdq->lock` (and temporarily restored before `arm_smmu_cmdq_poll_until_not_full()`); `dma_wmb()` must precede `arm_smmu_cmdq_set_valid_map()`; the owner must call `arm_smmu_cmdq_poll_valid_map()` and `writel_relaxed(prod, cmdq->q.prod_reg)` before `atomic_set_release(&cmdq->owner_prod)`; and when `sync` is true, `arm_smmu_cmdq_shared_lock()` must be held across `arm_smmu_cmdq_poll_until_sync()` with non-relaxed `readl(cmdq->q.cons_reg)`. [F14, F24, F25, F179]
- `smmu->streams_mutex` protects both `smmu->streams` and `master->vmaster` (`arm_smmu_find_master()`, `arm_smmu_attach_commit_vmaster()`, `arm_vmaster_report_event()`, and `arm_smmu_decode_event()`); per-master `master->cd_table` and `master->iopf_refcount` require the device's IOMMU group mutex (`iommu_group_mutex_assert(master->dev)`); and `arm_vsmmu_vsid_to_sid()` must hold `xa_lock(&vsmmu->core.vdevs)` across both `iommufd_viommu_find_dev()` and reading `master->streams[0].id` from `dev_iommu_priv_get(dev)`. [F34, F35, F38]
- In SMMUv1/v2 (`arm-smmu.c`), `smmu->stream_map_mutex` protects `smmu->smrs`, `smmu->s2crs`, and `cfg->smendx` (and in `arm_smmu_device_group()`, must be unlocked on every return path while calling `iommu_group_ref_get(group)` when returning a cached group); `smmu_domain->init_mutex` orders `arm_smmu_write_context_bank()` before requesting the IRQ and assigning `smmu_domain->pgtbl_ops` last; and `smmu_domain->cb_lock` and `smmu->global_sync_lock` serialize context/global TLB syncs. [F15, F40, F42, F44]
- In `arm_lpae_install_table()` and `arm_v7s_install_table()`, `dma_wmb()` must precede `cmpxchg64_relaxed()`/`cmpxchg_relaxed()`, freeing the newly allocated table and using the winning PTE if `cmpxchg` loses a race; when `!cfg->coherent_walk` in `io-pgtable-arm.c`, any thread seeing a table PTE without `ARM_LPAE_PTE_SW_SYNC` must call `__arm_lpae_sync_pte()` before walking it while the installer sets `ARM_LPAE_PTE_SW_SYNC` after syncing. [F45, F46]

## Object Lifetimes

- Once `arm_smmu_attach_prepare()` succeeds, the caller must install the STE/CD and call `arm_smmu_attach_commit()` (consuming `state->vmaster` and removing `state->old_domain` from `smmu_domain->devices`); when attaching an identity or blocked domain, `arm_smmu_master_clear_vmaster()` (or `arm_smmu_attach_commit_vmaster()`) must free and clear `master->vmaster` under `smmu->streams_mutex`. [F2, F6]
- In `arm_smmu_enable_iopf()`, `master->iopf_refcount` is incremented and `master_domain->using_iopf` is set to `true` only when `master->stall_enabled` is true, and `arm_smmu_disable_iopf()` must only decrement `master->iopf_refcount` and call `iopf_queue_remove_device()` when `master_domain->using_iopf` is true. [F8]
- `acpi_smmu_dsdt_probe_tegra241_cmdqv()` acquires a reference on `smmu->impl_dev` transferred to `tegra241_cmdqv_probe()` in `arm_smmu_impl_probe()`, so no error return may occur between them without `put_device(smmu->impl_dev)`; `arm_smmu_decode_event()` calls `get_device(master->dev)` under `smmu->streams_mutex` which `arm_smmu_evtq_thread()` must release via `put_device(event.dev)` on every iteration; and in `arm_smmu_sva_domain_free()`, `arm_smmu_tlb_inv_asid()` must precede `xa_erase(&arm_smmu_asid_xa, smmu_domain->cd.asid)`. [F11, F12, F37]
- In SMMUv1/v2 (`arm-smmu.c`), every post-probe function accessing SMMU registers must pair a successful `arm_smmu_rpm_get(smmu)` with `arm_smmu_rpm_put(smmu)` on all exit paths; `arm_smmu_destroy_domain_context()` must clear `smmu->cbs[cfg->cbndx].cfg = NULL` and call `arm_smmu_write_context_bank()` before freeing the IRQ (when `cfg->irptndx != ARM_SMMU_INVALID_IRPTNDX`), `pgtbl_ops`, and `context_map`; and `arm_smmu_free_sme()` resets `s2crs[idx]` and `smrs[idx].valid` only when `--s2crs[idx].count == 0` while callers set `cfg->smendx[i] = INVALID_SMENDX`. [F17, F18, F19]
- When `__arm_lpae_unmap()` or `__arm_v7s_unmap()` unmaps or replaces a non-leaf table PTE, it must clear and DMA-sync the parent PTE (`__arm_lpae_clear_pte()` / `__arm_v7s_set_pte()`) and flush walk caches via `io_pgtable_tlb_flush_walk()` before freeing the child table via `__arm_lpae_free_pgtable()` or `__arm_v7s_free_table()`. [F21]

## API Contracts

- In SMMUv3, `arm_smmu_domain_alloc()` returns `ERR_PTR(-ENOMEM)` on failure rather than `NULL` (callers must check `IS_ERR()`); `arm_smmu_impl_probe()` hooks must return `ERR_PTR(-ENODEV)` for non-fatal fallback to standard SMMUv3, a `devm_krealloc`'d `arm_smmu_device *` on match, or another `ERR_PTR` to abort; and `arm_vsmmu_convert_user_cmd()` must convert `cmd->ucmd.cmd` (`__le64`) in-place to CPU `u64` and overwrite `CMDQ_TLBI_0_VMID` with `vsmmu->vmid` or translate `CMDQ_CFGI_0_SID` via `arm_vsmmu_vsid_to_sid()`. [F48, F49, F95]
- In SMMUv3, `arm_smmu_iotlb_sync()` must check `if (!gather->pgsize) return;` before calling `arm_smmu_tlb_inv_range_domain()` with inclusive byte size `gather->end - gather->start + 1`; `arm_smmu_atc_inv_to_cmd()` and `arm_smmu_atc_inv_domain()` treat `size == 0` as `ATC_INV_SIZE_ALL` (full ATC flush), whereas `__arm_smmu_tlb_inv_range()` treats `size == 0` as a no-op; and in SMMUv1/v2, callers of `arm_smmu_tlb_inv_range_s1()`/`s2()` must pass a non-zero `size` aligned to `granule`. [F69, F104, F129, F207]
- In `arm_lpae_map_pages()` and `arm_v7s_map_pages()`, calls with neither `IOMMU_READ` nor `IOMMU_WRITE` set must return `-EINVAL` (and advance `*mapped` on success), intermediate table allocations in `__arm_lpae_alloc_pages()` and `__arm_v7s_alloc_table()` must use the caller's `gfp` flags rather than `GFP_KERNEL`, and `arm_lpae_map_pages()`/`arm_lpae_unmap_pages()` must check upper IOVA bits via `long iaext = (s64)iova >> cfg->ias` (inverting `iaext = ~iaext` when `IO_PGTABLE_QUIRK_ARM_TTBR1` is set). [F99, F178, F195]
- In `__arm_lpae_unmap()` and `__arm_v7s_unmap()`, the `struct iommu_iotlb_gather *gather` parameter may be `NULL` (such as when unmapping an overwritten table entry), so its queued state must be queried via `iommu_iotlb_gather_queued(gather)` rather than direct pointer dereference. [F60]

## Error Handling

- In `arm_smmu_attach_prepare()`, resources acquired when `smmu_domain` is non-NULL (`state->vmaster`, `master_domain`, and `arm_smmu_enable_iopf()`) must be unwound in reverse acquisition order via `err_iopf`, `err_free_master_domain`, and `err_free_vmaster`; in `arm_smmu_init_domain_context()` (SMMUv1/v2), failure paths after `smmu_domain->smmu = smmu` must jump to `out_clear_smmu`, and `devm_request_irq()` failure must reset `cfg->irptndx = ARM_SMMU_INVALID_IRPTNDX`. [F1, F61]
- In both SMMUv1/v2 and SMMUv3 `arm_smmu_attach_dev()`, validation failures after a prior call has set `ret = 0` (such as `smmu_domain->smmu != smmu`) must explicitly set or return a negative errno (`-EINVAL`) rather than returning `ret`; `arm_smmu_find_sme()` and `arm_smmu_alloc_context_bank()` return negative errnos on failure, so callers must check `< 0` in a signed `int` before narrowing to `s16 smendx` or `u8 cbndx`; and `arm_smmu_handle_event()` must return the status of fault-reporting helpers so `arm_smmu_evtq_thread()` dumps unhandled events. [F50, F51, F62]

## External Contracts

- Because PCIe forbids changing PASID Enable while ATS is enabled, `arm_smmu_probe_device()` must call `arm_smmu_enable_pasid()` before enabling ATS, and `arm_smmu_release_device()` must attach `&arm_smmu_identity_domain` or `&arm_smmu_blocked_domain` (disabling ATS) before calling `arm_smmu_disable_pasid()`; in `arm-smmu-v3-iommufd.c`, `arm_smmu_validate_vste()` and `arm_vsmmu_alloc_domain_nested()` must reject bits outside `STRTAB_STE_0_NESTING_ALLOWED` and `STRTAB_STE_1_NESTING_ALLOWED` with `-EIO` and clear `STRTAB_STE_1_EATS` from `ste[1]`. [F39, F94]

## Known Pitfalls

- In `drivers/iommu/arm/arm-smmu-v3/`, all `STRTAB_STE_*` and `CTXDESC_CD_*` bitmask constants except `STRTAB_STE_0_NESTING_ALLOWED` and `STRTAB_STE_1_NESTING_ALLOWED` are CPU-endian, so masking or setting `__le64` STE/CD words requires `cpu_to_le64()` (and `FIELD_GET()` requires `le64_to_cpu()`); in `arm_smmu_set_pasid()` and `arm_smmu_blocking_set_dev_pasid()`, RID STE updates must inspect `sid_domain = iommu_get_domain_for_dev(master->dev)`, and `arm_smmu_blocking_set_dev_pasid()` must pass `old_domain` (not `new_domain`) to `to_smmu_domain()`. [F109, F132]
- During LPAE page table allocation (`arm_64_lpae_alloc_pgtable_s1`/`s2`, `arm_mali_lpae_alloc_pgtable`, `arm_lpae_concat_mandatory`, `__arm_lpae_alloc_pages`), configuration fields must be read from the `cfg` and `cookie` arguments rather than `data->iop.cfg` or `data->iop.cookie`; and when `arm_lpae_init_pte()` or `arm_v7s_init_pte()` unmaps an existing next-level table before installing a block PTE, it must subtract the current level's index (`tblp = ptep - ARM_LPAE_LVL_IDX(...)` or `ARM_V7S_LVL_IDX`) and pass `tblp` (not `ptep`) to `__arm_lpae_unmap()` or `__arm_v7s_unmap()`. [F63, F133]
