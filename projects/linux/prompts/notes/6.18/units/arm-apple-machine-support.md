# ARM/APPLE MACHINE SUPPORT

This unit provides the core platform, coprocessor IPC, and peripheral device drivers for Apple Silicon SoCs (M-series and A-series), including the AIC interrupt controller, DART IOMMU, SART DMA filter, Mailbox and RTKit IPC frameworks, MacSMC MFD, ANS NVMe host, BCM4377 PCIe Bluetooth HCI, ADMAC audio DMA, PMGR power/reset domains, CPUFreq, NCO clock, pinctrl/GPIO, I2C, SPI, PWM, NVMEM, and Z2 touchscreen drivers.

## Architecture & Data Flow

- In `apple-dart.c`, `apple_dart_identity_domain` and `apple_dart_blocked_domain` are static `struct iommu_domain` instances, so `to_dart_domain()` must only be called on paging domains from `apple_dart_domain_alloc_paging()`. Paging domains have `dart_domain->pgtbl_ops == NULL` until `apple_dart_finalize_domain()` runs on attach, so `apple_dart_iova_to_phys()` and `apple_dart_map_pages()` must check `pgtbl_ops` for NULL first. [F48, F144]
- In `io-pgtable-dart.c`, `APPLE_DART2` PTEs shift physical addresses right by `APPLE_DART2_PADDR_SHIFT` (4) before masking with `APPLE_DART2_PADDR_MASK` and use `BIT(1)` for `APPLE_DART2_PTE_PROT_NO_CACHE`, so `dart_prot_to_pte()` must only set `APPLE_DART1_PTE_PROT_SP_DIS` (`BIT(1)`) when `data->iop.fmt == APPLE_DART`. `dart_get_last()` and `dart_map_pages()` must reject `tbl >= (1 << data->tbl_bits)` before indexing `data->pgd[tbl]`, and `dart_map_pages()`/`dart_unmap_pages()` must clamp `num_entries` to `DART_PTES_PER_TABLE(data) - dart_get_last_index(data, iova)`. [F82, F83, F84, F145]
- In `apple-dart.c`, `apple_dart_setup_translation()` and `apple_dart_resume()` must write all `DART_TTBR` registers before writing `DART_TCR`, and the second loop `for (; i < stream_map->dart->hw->ttbr_count; ++i)` in `apple_dart_setup_translation()` must continue from `n_ttbrs` without resetting `i = 0` so `apple_dart_hw_clear_ttbr()` clears only unused trailing TTBRs. [F71, F108]
- In `drivers/nvme/host/apple.c`, `q->tcbs` is only allocated when `anv->hw->has_lsq_nvmmu` is true (NULL on T8015) and must be sized in `apple_nvme_queue_alloc()` and zeroed in `apple_nvme_init_queue()` using `anv->hw->max_queue_depth` (not `apple_nvme_queue_depth(q)`, with `reserved_tags = APPLE_NVME_AQ_DEPTH`). All TCB/NVMMU accesses must check `has_lsq_nvmmu`, `apple_nvme_submit_cmd_t8103()` must populate `&q->tcbs[tag]` alongside `&q->sqes[tag]`, and `apple_nvme_handle_cqe()` must call `apple_nvmmu_inval(q, command_id)`. [F46, F63, F114]
- In `drivers/nvme/host/apple.c`, `anv->adminq.is_adminq = true` must be set before any call to `queue_to_apple_nvme()`, and `apple_nvme_alloc()` must pass `NVME_QUIRK_SKIP_CID_GEN | NVME_QUIRK_IDENTIFY_CNS` to `nvme_init_ctrl()`. In `apple_nvme_queue_rq()`, `iod->npages` must be initialized to `-1` and `iod->nents` to `0`, and `apple_nvme_map_data()` must set `iod->dma_len = 0` on the scatterlist path vs `bv->bv_len` in `apple_nvme_setup_prp_simple()` so `apple_nvme_unmap_data()` frees exact resources. [F65, F134, F151]
- In `irq-apple-aic.c`, reading `AIC_EVENT` in `aic_handle_irq()` masks the hardware IRQ, so `aic_irq_eoi()` must call `aic_irq_unmask(d)` whenever `!irqd_irq_masked(d)` (without checking `irqd_irq_disabled(d)`). Guest timer FIQ masking in `aic_fiq_set_mask()` only clears `SYS_IMP_APL_VM_TMR_FIQ_ENA_EL2`, so `aic_fiq_mask()`/`unmask()` must maintain per-CPU `aic_fiq_unmasked` for `aic_fiq_eoi()`, `aic_handle_fiq()` must gate `SYS_CNTP/V_CTL_EL02` with `VM_TMR_FIQ_ENABLE_P/V`, and all EL2 register accesses must be guarded by `is_kernel_in_hyp_mode()`. [F61, F62, F104, F173]
- In `rtkit.c`, `struct apple_rtkit_shmem` may be MMIO (`bfr->iomem`) or RAM (`bfr->buffer`), so callers must use `apple_rtkit_memcpy()`, and `rtk->ops->crashed()` must tolerate `crashlog == NULL`. In `apple_rtkit_common_rx_get_buffer()`, `APPLE_RTKIT_EP_OSLOG` encodes size in bytes and IOVA shifted right by 12, whereas other endpoints encode size shifted right by 12 and IOVA in bytes. `apple_rtkit_is_running()` must mask power states with `0xff` against `APPLE_RTKIT_PWR_STATE_ON`, whereas `apple_rtkit_set_ap/iop_power_state()` must compare unmasked states. [F51, F94, F110]
- In `macsmc.c`, `apple_smc_enter_atomic()` disables `NTAP` notifications and sets `smc->atomic_mode = true` under `smc->mutex`, after which `apple_smc_cmd_locked()` rejects non-atomic commands and `apple_smc_write_atomic()` uses `smc->atomic_pending` (cleared in `apple_smc_rtkit_recv_early()`). `apple_smc_rw_locked()` and `apple_smc_write_atomic()` reject sizes `> SMC_MAX_SIZE` (255), and `apple_smc_rw_locked()` reads replies with `rsize <= 4` from inline `rdata` rather than `smc->shmem.iomem`. [F76, F91]
- In `apple-admac.c`, even channels (`channo % 2 == 0`) are TX and odd are RX; per-channel registers index by `channo`, but `REG_TX/RX_START`, `STOP`, and `INTSTATE` use bit `1 << (channo / 2)`. `admac_alloc_chan_resources()` must allocate an exclusive `SRAM_BLOCK` under `ad->cache_alloc_lock` and program `REG_CHAN_SRAM_CARVEOUT(adchan->no)` (freed in `admac_free_chan_resources()`), and `admac_interrupt()` must read and clear `REG_GLOBAL_INTSTATE(ad->irq_index)` alongside `REG_RX/TX_INTSTATE`. [F57, F59, F147]

## Synchronization

- In `rtkit.c` and `mailbox.c`, `apple_rtkit_rx()` must execute `dma_rmb()` before reading buffers or calling `recv_message_early`, and `apple_rtkit_send_message()` must execute `dma_wmb()` before `apple_mbox_send()`. In `apple_mbox_send()`, atomic callers must pass `atomic = true` (`readl_poll_timeout_atomic` under `mbox->tx_lock`); when `atomic = false` and `mbox->tx_lock` is dropped to sleep on `mbox->tx_empty`, `mbox->tx_lock` must be reacquired and `control_full` rechecked before writing `a2i_send0`/`a2i_send1`. [F21, F22, F174]
- `apple_rtkit_ops.recv_message_early` runs in atomic context under `mbox->rx_lock` (and under `smc->lock` when polled from `apple_smc_write_atomic()`) and must never sleep; in `macsmc.c`, `apple_smc_rtkit_recv_early()` must never acquire `smc->lock` or `smc->mutex` and must return `false` for `SMC_MSG_NOTIFICATION` so `apple_smc_rtkit_recv()` invokes `blocking_notifier_call_chain()` on `rtk->wq`. [F23, F175]
- In `drivers/nvme/host/apple.c`, `anv->lock` must be held around `writel(tag, q->sq_db)` in both `apple_nvme_submit_cmd_t8103()` and `apple_nvme_submit_cmd_t8015()`. `apple_nvme_init_queue()` must zero `q->tcbs` and `q->cqes`, set `q->cq_head = 0`, `q->cq_phase = 1`, `WRITE_ONCE(q->enabled, true)`, and execute `wmb()` before unquiescing the queue. In `apple_nvme_poll_cq()`, after `apple_nvme_cqe_pending(q)` observes a matching phase bit via `READ_ONCE(hcqe->status)`, `dma_rmb()` must execute before `apple_nvme_handle_cqe()` reads CQE fields. [F27, F28, F30]
- In `apple-dart.c` and `io-pgtable-dart.c`, `dart->lock` (`spin_lock_irqsave`) must be held across the entire register write and `readl_poll_timeout_atomic()` sequence in `apple_dart_t8020_hw_stream_command()` and `apple_dart_t8110_hw_tlb_command()`. In `dart_install_table()`, `dma_wmb()` must precede `cmpxchg64_relaxed()`, and `dart_map_pages()` must execute `wmb()` after `dart_init_pte()` and free `cptep` via `iommu_free_pages(cptep)` if `dart_install_table()` returns non-zero. [F9, F32, F33]
- In `irq-apple-aic.c`, `aic_handle_irq()` must read `ic->event + ic->info.event` using non-relaxed `readl()` (never `aic_ic_read()`/`readl_relaxed()`), and `aic_handle_ipi()` must execute `isb()` after writing `IPI_SR_PENDING` to `SYS_IMP_APL_IPI_SR_EL1` before `ipi_mux_process()`. In `pinctrl-apple-gpio.c`, `regmap_config` must set `.use_raw_spinlock = true` for `apple_gpio_irqchip`. [F34, F170]

## Object Lifetimes

- In `rtkit.c`, `apple_rtkit_init()` must initialize all completions, `endpoints`, `mbox->rx`, `mbox->cookie`, and `rtk->wq` before `apple_mbox_start(rtk->mbox)`, and `apple_rtkit_reinit()`/`apple_rtkit_free()` must call `apple_mbox_stop()` and flush/destroy `rtk->wq` before freeing shmem buffers or resetting state. In `apple_rtkit_crashlog_rx()`, `bfr` must not be freed with `kfree(bfr)` until after `rtk->ops->crashed()` returns, and `apple_rtkit_free_buffer()` / `apple_rtkit_common_rx_get_buffer()` error paths must zero `bfr->size`, `bfr->buffer`, and `bfr->iomem`. [F1, F3, F19, F20]
- In `apple-admac.c`, `admac_terminate_all()` must move non-NULL `adchan->current_tx` (removed from `adchan->issued` by `admac_issue_pending()`), `submitted`, and `issued` onto `adchan->to_free` before clearing `current_tx = NULL`, and `admac_synchronize()` must splice `adchan->to_free`, call `tasklet_kill(&adchan->tasklet)`, and free descriptors with `list_for_each_entry_safe()`. [F4, F109]
- Under `apple_dart_groups_lock`, `apple_dart_device_group()` must merge `cfg` via `apple_dart_merge_master_cfg()` when `iommu_group_get_iommudata(group)` is already set (rather than overwriting it with `iommu_group_set_iommudata()`), call `iommu_group_put(group)` on error, and keep `dart->sid2group[sid]` synchronized with `group_master_cfg` so `apple_dart_release_group()` clears all `sid2group[sid]` pointers. [F8, F72]
- In `drivers/nvme/host/apple.c`, if `blk_mq_alloc_queue()` returns an `ERR_PTR` for `anv->ctrl.admin_q` in `apple_nvme_probe()`, `anv->ctrl.admin_q` must be cleared to NULL before `nvme_uninit_ctrl()`/`nvme_put_ctrl()` so `apple_nvme_free_ctrl()` does not pass an `ERR_PTR` to `blk_put_queue()`. When `apple_nvme_reset_work()` schedules `anv->remove_work`, it must take `nvme_get_ctrl(&anv->ctrl)` and drop it via `nvme_put_ctrl()` if `queue_work()` returns false. [F12, F13]
- In `apple_nvme_disable()`, `anv->ioq.enabled` and `anv->adminq.enabled` must be cleared with `WRITE_ONCE`, followed by `mb()`, `nvme_quiesce_admin_queue()`, and force-draining both CQs under `anv->lock` with `apple_nvme_handle_cq(..., true)` before cancelling tagsets; on `shutdown`, it must unquiesce both queues and, if not dead, call `nvme_disable_ctrl(&anv->ctrl, false)` after `nvme_disable_ctrl(&anv->ctrl, shutdown)` while RTKit is still running. [F29, F149]

## API Contracts

- In `macsmc.c`, `apple_smc_read()`, `apple_smc_write()`, `apple_smc_rw()`, `apple_smc_write_atomic()`, and `apple_smc_get_key_info()` return the non-negative byte count on success and negative errno on error, so callers must test `< 0` for failure. `smc_key` values are stored in host-endian natural order (`0xAABBCCDD` for `'ABCD'`), so `apple_smc_get_key_by_index()` must `swab32()` the returned key and printk callers must pass `&key` with `%p4ch` (not `%p4cc`/`%p4cb`). [F37, F92, F141]
- In `apple-dart.c` and `io-pgtable-dart.c`, `apple_dart_iommu_ops` must set `.owner = THIS_MODULE`; when `dart->pgsize > PAGE_SIZE`, `apple_dart_def_domain_type()` must return `IOMMU_DOMAIN_IDENTITY` and `apple_dart_finalize_domain()` must return `-EINVAL`. In `dart_map_pages()`, if `!(iommu_prot & (IOMMU_READ | IOMMU_WRITE))`, it must return `-EINVAL` (not `0`), and `size_t *mapped` must be accumulated via `if (!ret && mapped) *mapped += num_entries * pgsize;`. [F50, F192, F193, F194]
- In `rtkit.c`, `apple_rtkit_crashlog_dump()` requires a RAM shadow copy from `apple_rtkit_memcpy()` because its helpers mutate `bfr` in-place and call `memchr()`. Across this unit, `devm_add_action_or_reset()` callbacks must be `void (*)(void *)` wrappers rather than cast function pointers. `apple_nvme_handle_cqe()` must pass `nvme_req(req)->status != NVME_SC_SUCCESS` to `blk_mq_add_to_batch()`; `bcm4377_enqueue()`/`bcm4377_handle_ack()` must pass `order = 0` to `bitmap_find_free/release_region()`. [F47, F54, F130, F139]

## Error Handling

- In `drivers/nvme/host/apple.c`, `apple_nvme_detach_genpd()` must be called on all error paths in `apple_nvme_alloc()` and `apple_nvme_probe()` and in `apple_nvme_remove()`, must check `anv->pd_count <= 1` before touching `anv->pd_link` or `anv->pd_dev`, and must delete `anv->pd_link[i]` and check `!IS_ERR_OR_NULL(anv->pd_dev[i])` when detaching in reverse order. [F44, F153]
- `apple_soc_cpufreq_get_rate()` must check `cpufreq_cpu_get_raw()` for NULL before dereferencing `policy->driver_data`. Callers of `of_iomap()` (`apple_soc_cpufreq_find_cluster()`, `aic_of_ic_init()`) and `devm_kasprintf()` (`applnco_probe()`, `apple_gpio_pinctrl_probe()`, `apple_mbox_probe()`) must check for NULL rather than `IS_ERR()`, and `aic_of_ic_init()` cleanup must check `irqc->event && irqc->event != irqc->base` before `iounmap(irqc->event)`. [F38, F39, F40, F58]

## Known Pitfalls

- In `irq-apple-aic.c`, `aic_handle_fiq()` must check each FIQ source with an independent `if` statement (never `else if`), test per-core PMU FIQs by masking `SYS_IMP_APL_PMCR0_EL1` with `PMCR0_IMODE | PMCR0_IACT` against `FIELD_PREP(PMCR0_IMODE, PMCR0_IMODE_FIQ) | PMCR0_IACT` (not `PMCR0_IACT` alone), and mask firing uncore PMC FIQs (`UPMCR0_IMODE_FIQ` with `UPMSR_IACT`) to `UPMCR0_IMODE_OFF`. [F103, F105]
- In `apple-dart.c`, `stream_maps[MAX_DARTS_PER_DEVICE]` entries must be packed from index 0 with NULL sentinels, and `for_each_stream_map(i, base, stream_map)` must test `i < MAX_DARTS_PER_DEVICE` before `stream_map->dart` and never dereference `stream_map` after the loop. Fault bits `DART_T8020/T8110_ERROR_*` must remain distinct `BIT()` values. In `apple_dart_free_pgtables()`, cast `dart_iopte *ptep` to `(void *)` before adding `DART_GRANULE(data)` and save `start = ptep` before incrementing `ptep` for `iommu_free_pages(start)`. [F85, F106, F107, F136]
- Split `dma_addr_t` across 32-bit MMIO writes with `lower_32_bits()`/`upper_32_bits()` (never `>> 32`); cast high `u32` reads to `u64` before `<< 32` (`apple_dart_t8020/t8110_irq()`, `admac_drain_reports()`); and widen `u32` fields to `phys_addr_t`/`size_t` before `<< 12` in `sart0/2/3_get_entry()`. Variables passed by address to bitops (`sart->protected_entries`, `sart->used_entries`, `bitmap` in `apple_rtkit_management_rx_epmap()`, `pending` in `apple_gpio_irq_handler()`) must be `unsigned long`, not `u32`. [F118, F119, F120, F143]
- In `apple-admac.c`, `admac_probe()` must not read MMIO registers (`REG_TX/RX_SRAM_SIZE`) while power-gated (deferring to `admac_alloc_sram_carveout()`), and `admac_ring_noccupied_slots()` must compute `(wrslot + 4 - rdslot) % 4`. In `drivers/nvme/host/apple.c`, when `!anv->hw->has_lsq_nvmmu` (T8015), IO SQEs have a 128-byte stride (`1 << APPLE_NVME_IOSQES`) while `q->sqes` is `struct nvme_command *` (64-byte), so `apple_nvme_submit_cmd_t8015()` must index IO SQEs via `(void *)q->sqes + (q->sq_tail << APPLE_NVME_IOSQES)`. [F125, F132, F146]
- In `pinctrl-apple-gpio.c`, `pctl->map` uses `REGCACHE_FLAT`, so `apple_gpio_get()` must read `readl_relaxed(pctl->base + REG_GPIO(offset))` directly when `FIELD_GET(REG_GPIOx_MODE, reg) != REG_GPIOx_OUT`. In `pmgr-pwrstate.c`, every write to `ps->offset` must mask out `APPLE_PMGR_FLAGS`, and `apple_pmgr_reset_assert()`/`deassert()` must sequence `APPLE_PMGR_DEV_DISABLE` outside `APPLE_PMGR_RESET`. In `rtkit-crashlog.c`, `struct apple_rtkit_crashlog_regs` (0x350 bytes) must be accessed by casting `bfr` rather than allocating it on the stack. [F77, F78, F129]
