# CAN NETWORK DRIVERS

This unit provides the SocketCAN network device core (`drivers/net/can/dev/*`), virtual CAN interfaces (`vcan`, `vxcan`), the generic CAN transceiver PHY driver (`phy-can-transceiver`), and hardware drivers for MMIO/PCI/ISA/PCMCIA controllers (`at91_can`, `c_can`/`d_can`, `cc770`, `flexcan`, `grcan`, `ifi_canfd`, `sja1000`, `softing`, `sun4i_can`, `ti_hecc`), SPI controllers (`hi311x`, `mcp251x`), and USB adapters (`ems_usb`, `gs_usb`, `kvaser_usb`, `peak_usb`, `ucan`, `usb_8dev`).

## Architecture & Data Flow

- Every `candev` driver's private struct passed to `alloc_candev_mqs()` must embed `struct can_priv` at offset 0 and pass `sizeof(*priv)` because `can_ml_priv` and `echo_skb` follow it. Virtual drivers (`vcan`, `vxcan`) have no `can_priv` (`vxcan` places `can_ml_priv` at `netdev_priv(dev) + ALIGN(sizeof(struct vxcan_priv), NETDEV_ALIGN)`), so their callbacks (`vcan_tx`, `vxcan_xmit`, `can_dropped_invalid_skb`, `vcan_change_mtu`, `vxcan_change_mtu`) must never cast `netdev_priv` to `can_priv *`; arbitrary netdevs require `safe_candev_priv()`. [F71, F109, F110, F112, F344, F428, F450]
- CAN SKB allocators (`alloc_can_skb()`, `alloc_canfd_skb()`, `alloc_canxl_skb()`) must reserve `sizeof(struct can_skb_priv)` bytes of headroom via `init_can_skb_reserve()` before `skb_put_zero()`, because `can_skb_prv(skb)` casts `skb->head` directly. Code mutating `can_skb_prv(skb)` or `skb->data` on a potentially cloned SKB must unshare via `skb_copy()`, never `skb_clone()`. [F113, F171]
- On RX paths, 4-bit Classical CAN DLCs must be clamped to `CAN_MAX_DLEN` (8) via `can_cc_dlc2len()` or `can_frame_set_cc_len()` (including when `alloc_can_skb()` populates a `struct canfd_frame *` in `kvaser_usb_hydra_rx_msg_ext()` and `pcan_usb_fd_decode_canmsg()`), and drivers advertising `CAN_CTRLMODE_CC_LEN8_DLC` (`sja1000`, `gs_usb`) must use `can_get_cc_dlc()` on TX and `can_frame_set_cc_len()` on RX. [F70, F351, F463]
- In CAN error and overflow handlers (`c_can_handle_bus_err`, `ifi_canfd_handle_lec_err`, `at91_irq_err_frame`, `gs_usb_receive_bulk_callback`, `pcan_usb_fd_decode_status`, `pcan_usb_decode_error`), `tx_errors` (ACK/bit0/bit1), `rx_errors`/`rx_over_errors` (stuff/form/CRC/overload/overflow), hardware error-counter resets, `can_change_state()` (which accepts `cf == NULL`), and `can_bus_off()` must execute even when `alloc_can_err_skb()` returns `NULL`. [F33, F51, F233, F506]
- `flexcan_rx_offload_setup()` must recompute `mb_size`, `mb_count`, `tx_mb_reserved`, `tx_mb_idx`, `tx_mb`, `tx_mask`, and `rx_mask` on every `flexcan_open()`. Mailboxes must only be addressed via `flexcan_get_mb(priv, mb_index)` after `mb_size`/`mb_count` are initialized (never linear `mb[i]` indexing), and `flexcan` (`be32_to_cpup`/`cpu_to_be32` at `mb->data[i / sizeof(u32)]`) and `ti_hecc` (`be32_to_cpu`/`cpu_to_be32` on `HECC_CANMDL`/`HECC_CANMDH`) must convert 32-bit payload words to/from big-endian. [F46, F53, F83, F115, F117, F270]
- In `gs_usb`, `ems_usb`, and `kvaser_usb`, free TX context slots are marked by setting `echo_id` / `echo_index` to the array bound (`GS_MAX_TX_URBS`, `MAX_TX_URBS`, `dev->max_tx_urbs`), never `0` or `-1`. In `ucan`, every TX URB `urb->context` must be an element of `up->context_array` because `echo_skb` indices are computed via `context - up->context_array`. [F231, F359, F457]
- Every `ndo_stop` path must set `can.state = CAN_STATE_STOPPED`, while `flexcan_suspend()`/`flexcan_resume()` must only transition `can.state` to `CAN_STATE_SLEEPING` and `CAN_STATE_ERROR_ACTIVE` when `netif_running(dev)` is true. In `kvaser_usb_hydra_stop_chip()`, `can.state = CAN_STATE_STOPPED` must precede `CMD_STOP_CHIP_REQ` so `kvaser_usb_hydra_update_state()` ignores `STOPPED -> BUS_OFF`, and `kvaser_usb_leaf.c` bus-off restart checks must test `state == CAN_STATE_BUS_OFF` (not `>=`). [F52, F235, F405, F430]

## Synchronization

- In `ndo_start_xmit` (`c_can`, `flexcan`, `grcan`, `ifi_canfd`, `gs_usb`, `ems_usb`), `can_put_echo_skb()` must be called before the register write or `usb_submit_urb()` that triggers transmission so TX completion cannot race ahead of `priv->echo_skb[idx]`; if `usb_submit_urb()` fails, roll back with `can_free_echo_skb()` rather than `dev_kfree_skb()`. [F2, F20, F187]
- `close_candev()` and `can_restart_now()` hold `rtnl_lock` while calling `cancel_delayed_work_sync(&priv->restart_work)` before `can_flush_echo_skb()` or `can_restart()`, so `can_restart_work()`, `can_restart()`, and driver `do_set_mode(..., CAN_MODE_START)` callbacks must never acquire `rtnl_lock`. In `can_restart()`, `netif_carrier_on(dev)` must precede `priv->do_set_mode(dev, CAN_MODE_START)` (reverting on error) so an immediate bus-off IRQ is not overwritten. [F15, F16, F154]
- `can_rx_offload` IRQ helpers enqueue to `offload->skb_irq_queue`, which must be spliced into `offload->skb_queue` under `offload->skb_queue.lock` via `can_rx_offload_irq_finish()` (or `can_rx_offload_threaded_irq_finish()` from threaded IRQs to bracket `napi_schedule()` with `local_bh_disable()`/`enable()`). In `can_rx_offload_napi_poll()`, after `napi_complete_done()` when `work_done < quota`, `!skb_queue_empty(&offload->skb_queue)` must be rechecked to reschedule NAPI. [F17, F18, F147]
- Echo SKB and RX offload helpers (`__can_get_echo_skb`, `can_get_echo_skb`, `can_free_echo_skb`, `can_rx_offload_queue_*`) run in hardirq, softirq, and process contexts and must use `dev_kfree_skb_any()` / `dev_consume_skb_any()`. Hardirq/NAPI paths in `c_can` and `flexcan` must call `__c_can_get_berr_counter()` and `__flexcan_get_berr_counter()` (not the runtime-PM-sleeping `do_get_berr_counter` wrappers), and `peak_usb_restart()` / `dev_restart_async` must use `GFP_ATOMIC` and async `usb_submit_urb()`. [F149, F150, F381]
- In `c_can`, `c_can_start_xmit()` uses `IF_TX` (`1`) while NAPI and `c_can_configure_msg_objects()` use `IF_NAPI` (`0`), and `c_can_tx_busy()`/`c_can_do_tx()` pair `smp_mb()` between queue stop/wake and `tx_ring->tail`. In `grcan.c`, `priv->lock` (`spin_lock_irqsave`) guards `eskbp`, `resetting`, `closing`, `catch_up_echo_skb()`, `grcan_start()`, `netif_wake_queue()`, `grcan_reset_timer()`, and `regs->imr`, and `grcan_close()` sets `closing = true` before dropping `priv->lock` for `timer_delete_sync()`. [F21, F23, F26, F57, F61, F141, F151]
- In `hi311x` and `mcp251x`, all active SPI transactions and shared `spi_tx_buf`/`spi_rx_buf` accesses must hold `priv->hi3110_lock` / `priv->mcp_lock`. In `hi3110_stop()` and `mcp251x_stop()`, `priv->force_quit = 1` and `free_irq(spi->irq, priv)` must run before acquiring that mutex so the threaded IRQ handler does not deadlock, and `mcp251x_hw_wake()` (called under `mcp_lock`) must use `disable_irq_nosync(spi->irq)` around forcing `CANINTE_WAKIE`/`CANINTF_WAKIF`. [F334, F335, F336]
- In `sja1000` and `sun4i_can`, command register writes (`SJA1000_CMR`, `SUN4I_REG_CMD_ADDR`) must use `sja1000_write_cmdreg()` / `sun4i_can_write_cmdreg()` under `spin_lock_irqsave(&priv->cmdreg_lock, flags)`, and multi-step board `read_reg`/`write_reg` callbacks must serialize under an IRQ-saving spinlock nesting inside `cmdreg_lock`. On `SJA1000_QUIRK_RESET_ON_OVERRUN`, `sja1000_reset_interrupt()` must hold `netif_tx_lock(dev)` across `can_free_echo_skb()` and `sja1000_set_mode(dev, CAN_MODE_START)`. [F211, F212, F234]
- In `vxcan`, `priv->peer` is RCU-protected: non-RTNL readers (`vxcan_xmit`, `vxcan_get_iflink`) must hold `rcu_read_lock()` across `rcu_dereference(priv->peer)`, `netif_rx(skb)`, and `peer->stats` updates, and `vxcan_dellink()` must clear `peer` on both endpoints with `RCU_INIT_POINTER(..., NULL)` and unregister both via `unregister_netdevice_queue()`. [F355, F373, F483, F501]

## Object Lifetimes

- Every path that consumes or frees `priv->echo_skb[idx]` must clear `priv->echo_skb[idx] = NULL`. In `grcan_close()`, `close_candev(dev)` (which calls `can_flush_echo_skb()`) must run before clearing `priv->can.echo_skb_max = 0`, `priv->can.echo_skb = NULL`, and `kfree(priv->echo_skb)`. In `can_skb_set_owner()`, socket refcount must be incremented via `refcount_inc_not_zero(&sk->sk_refcnt)`, never `sock_hold()`. [F6, F7, F8]
- Drivers registering NAPI via `can_rx_offload_add_*()` (`flexcan`, `ti_hecc`, `gs_usb`) or `netif_napi_add_weight()` (`c_can`, `grcan`) must call `can_rx_offload_disable()` before stopping hardware in `ndo_stop`, and must call `can_rx_offload_del()` or `netif_napi_del()` (via `free_c_can_dev()` for `c_can`) after `unregister_candev()` and before `close_candev()`/`free_candev()` on teardown and probe/open error unwind. [F10, F13, F195, F196, F348]
- In USB CAN drivers, anchored RX/TX URBs must be killed via `usb_kill_anchored_urbs()` before freeing coherent buffers (`rxbuf` in `ems_usb`, `kvaser_usb`, `usb_8dev`), resetting TX contexts (`gs_usb`, `kvaser_usb`), freeing `up->context_array` (`ucan_close`), or canceling channel work (`kvaser_usb_remove_interfaces`). In `gs_can_close()`, shared `parent->rx_submitted` URBs and `parent->timestamp` work must only be stopped when `--parent->active_channels == 0`. [F205, F206, F358, F372, F377, F407, F493]
- USB URB buffer ownership: in `gs_usb`, setting `URB_FREE_BUFFER` transfers ownership of `hf`/`buf` to `usb_free_urb(urb)`, so error paths must not `kfree()` it; in `ems_usb` and `ucan`, buffers allocated with `usb_alloc_coherent()` and `URB_NO_TRANSFER_DMA_MAP` must be explicitly freed with `usb_free_coherent()` in completion callbacks (whenever not resubmitting in `ucan_read_bulk_callback()`, where submitted `urbs[i]` are set to `NULL` in `ucan_submit_rx_urbs()`) and on TX error paths. [F186, F188, F364, F492]
- In `peak_usb`, `peak_usb_unlink_all_urbs()` must free unsubmitted `tx_contexts[i].urb` (`echo_index == PCAN_USB_MAX_TX_URBS`) with `usb_free_urb()` before `usb_kill_anchored_urbs(&dev->tx_submitted)`, and `peak_usb_write_bulk_callback()` must call `can_get_echo_skb()` and reset `context->echo_index = PCAN_USB_MAX_TX_URBS` whenever `netif_device_present(netdev)` even if `urb->status != 0`. In `vxcan_newlink()`, `free_netdev(peer)` is called only if `register_netdevice(peer)` fails; later errors use `unregister_netdevice(peer)`. [F353, F360, F379]

## API Contracts

- In `ndo_start_xmit`, physical `candev` drivers must call `can_dev_dropped_skb(dev, skb)` first (which checks `CAN_CTRLMODE_LISTENONLY`, validates `ETH_P_CAN`/`ETH_P_CANFD`/`ETH_P_CANXL`, and initializes `can_skb_priv` headroom) and return `NETDEV_TX_OK` without touching `skb` if it returns `true`. When `idx < priv->echo_skb_max`, `can_put_echo_skb()` always consumes or frees `skb`, so all `skb`/`cf` reads and `NETDEV_TX_BUSY` returns (like `grcan_txbug_workaround()` or `usb_8dev` `nofreecontext`) must precede `can_put_echo_skb()`. [F1, F34, F42, F86, F111, F168, F366]
- `can_rx_offload_queue_timestamp()` and `can_rx_offload_queue_tail()` unconditionally take ownership of `skb` and free it via `dev_kfree_skb_any(skb)` on `-ENOBUFS`, so callers must never free `skb` on error. `can_rx_offload::mailbox_read` callbacks (`flexcan_mailbox_read`, `ti_hecc_mailbox_read`) must return `NULL` when empty, a valid `sk_buff *` on read, and `ERR_PTR(-errno)` after acknowledging/unlocking the hardware mailbox when `drop` is true, SKB allocation fails, or `HECC_CANRML` overrun occurs. [F3, F30, F129, F252, F349]
- `can_put_echo_skb()`, `can_get_echo_skb()`, and `can_free_echo_skb()` take a 0-based `idx < priv->echo_skb_max` (validated with `netdev_err()`, never `BUG_ON()`); drivers with offset TX mailboxes (`at91_can`, `c_can`) must subtract `get_mb_tx_first(priv)` or `priv->msg_obj_tx_first`. `__can_get_echo_skb()` requires a non-NULL `len_ptr` while `frame_len_ptr` is optional; RX and TX-echo byte counters must not add `cf->len` when `CAN_RTR_FLAG` or `CAN_ERR_FLAG` is set. [F35, F36, F75, F172, F180]
- Every CAN `net_device_ops` table must set `.ndo_change_mtu = can_change_mtu` (or `vcan_change_mtu`/`vxcan_change_mtu`), `ndo_open` must call `open_candev(dev)`, and `ndo_stop` (plus `ndo_open` error unwind) must call `close_candev(dev)`. Before `register_candev()`, `can_set_static_ctrlmode()` must be called after `priv->ctrlmode_supported` with disjoint bits, `sjw_max` must be non-zero, `bitrate_const` and `bittiming_const` must not both be set, and termination fields must be all set or all unset. [F163, F164, F165, F343, F429]

## Error Handling

- Optional DT/regulator/capability getters: `flexcan_probe()` must convert `ERR_PTR(-ENODEV)` from `devm_regulator_get_optional()` to `NULL` for `priv->reg_xceiver`, whereas `hi311x` and `mcp251x` keep the `ERR_PTR` in `priv->power`/`priv->transceiver` and must test `IS_ERR_OR_NULL()`; `flexcan_setup_stop_mode()` and `can_transceiver_phy_probe()` (`"max-bitrate"`) must treat `-EINVAL` as `0`, and `kvaser_usb_set_bittiming()` must treat `-EOPNOTSUPP` from `dev_get_busparams()` as `0`. [F41, F45, F224, F383, F384, F390]
- In `drivers/net/can/dev/netlink.c`, `can_get_size()` must stay in sync with `can_fill_info()` (using `sizeof(*ptr) * cnt` for pointer-backed constant arrays), `can_tdc_fill_info()` must keep `err` initialized to non-zero so `IFLA_CAN_TDC_TDCV` is only emitted when `tdc_manual` is true or `do_get_auto_tdcv` returns `0`, and disabling `CAN_CTRLMODE_FD` or failing `can_tdc_changelink()` must clear `CAN_CTRLMODE_FD_TDC_MASK`, `priv->fd.data_bittiming`, and `priv->fd.tdc` and update MTU via `can_set_default_mtu()`. [F43, F44, F65, F114, F177]

## Known Pitfalls

- 64-bit arithmetic and bitmasks: `flexcan` (`rx_mask`, `tx_mask`, `FLEXCAN_IFLAG_MB`, `flexcan_read64_mask()`) and `can_rx_offload` (`mb_first`/`mb_last < 64`, `pending`) must use `BIT_ULL()`, `GENMASK_ULL()`, and `(u64)` casts before `<< 32`; `peak_usb` (`ts_used_bits` up to 32) must use `1ULL`/`BIT_ULL()`; `kvaser_usb_timestamp48_to_ktime()` must cast `u16` to `u64` before `<< 16`/`<< 32`; and 64-bit divisions (`can_calc_bittiming`, `softing`, `kvaser_usb`) must use `do_div()`/`div_u64()` and guard against zero divisors. [F74, F101, F102, F108, F285, F444, F445, F446]
- `flexcan` and `can_rx_offload` quirks: sub-32-bit timestamps passed to `can_rx_offload` must be left-shifted to fill `u32` (`<< 16`) and IRQ loops must `break` when `can_rx_offload_irq_offload_timestamp()` returns `0`; `flexcan_read64_mask()`/`flexcan_write64()` take `&regs->iflag1` or `&regs->imask1` (`iflag2`/`imask2` sit at `addr - 4`); `flexcan_ram_init()` must set `FLEXCAN_CTRL2_WRMFRZ` before `FLEXCAN_MCR_FEN`; and Errata ERR005829 requires writing `FLEXCAN_MB_CODE_TX_INACTIVE` twice to `priv->tx_mb_reserved->can_ctrl` in `flexcan_start_xmit()`. [F82, F89, F100, F125, F128]
