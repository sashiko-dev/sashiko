# FUNCTION HOOKS (FTRACE)

Provides the core function tracer (`kernel/trace/ftrace.c`), function graph tracer (`kernel/trace/fgraph.c`), public headers (`include/linux/ftrace.h`), and architecture backends (`arch/*/kernel/ftrace.c`, `arch/*/include/asm/ftrace.h`) for dynamic callsite patching, trampoline management, shadow return stacks, and kprobes-on-ftrace.

## Architecture & Data Flow
- With `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, every path in `ftrace_init_nop()`, `ftrace_make_nop()`, and `ftrace_replace_code()` converting a callsite to a NOP must call `ftrace_rec_set_nop_ops(rec)`, while `ftrace_make_call()`, `ftrace_modify_call()`, and `ftrace_replace_code()` must update the literal via `ftrace_rec_update_ops()` or `ftrace_rec_set_ops()` to `ftrace_find_unique_ops(rec)` when `FTRACE_FL_CALL_OPS_EN` is set (or `&ftrace_list_ops` otherwise); on arm64/riscv, `ftrace_rec_set_ops()` must compute the slot as `ALIGN_DOWN(rec->ip - 12, 8)` (and riscv must pass `&ops` and `sizeof(ops)` to `patch_text_nosync()`). [F43, F44, F65, F98]
- In `ftrace_get_addr_new()` and `ftrace_get_addr_curr()`, `rec->flags` predicates must check direct calls (`FTRACE_FL_DIRECT` with `ftrace_rec_count(rec) == 1`, or `FTRACE_FL_DIRECT_EN`) before custom trampolines (`FTRACE_FL_TRAMP` / `FTRACE_FL_TRAMP_EN`), and custom trampolines before `FTRACE_FL_REGS` / `FTRACE_FL_REGS_EN`. [F240]
- `dyn_ftrace->flags` packs the refcount in bits `0..18` (`FTRACE_REF_MAX`) and `FTRACE_FL_*` flags using `1UL` shifts at or above `FTRACE_REF_MAX_SHIFT` (bit 19); `__ftrace_hash_rec_update()` must bound `ftrace_rec_count(rec)` against `FTRACE_REF_MAX` and `0`, and `ftrace_check_record()` disabling a record must preserve `FTRACE_NOCLEAR_FLAGS` while clearing other flags when refcount is 0 (or only `*_EN` flags when > 0). [F89, F216, F255]
- Around `ftrace_run_update_code()` in `ftrace_run_modify_code()` and `ftrace_shutdown()`, `ops->old_hash` must hold the pre-change hashes while `FTRACE_OPS_FL_MODIFYING` or `FTRACE_OPS_FL_REMOVING` (`removed_ops = ops`) is set; `ftrace_find_tramp_ops_curr()` must check `removed_ops->old_hash` first, skip `FTRACE_OPS_FL_ADDING`, test `&op->old_hash` for `FTRACE_OPS_FL_MODIFYING`, and test `op->func_hash` otherwise. [F221, F247]
- In `add_first_hash()` and `add_next_hash()`, a manager `ftrace_ops` must keep `notrace_hash` set to `EMPTY_HASH` whenever its aggregated `filter_hash` is non-empty (subtracting each subop's `notrace_hash` via `remove_hash()`), and only populate `notrace_hash` via `intersect_hash()` when `filter_hash` is `EMPTY_HASH`; `ftrace_startup_subops()` must canonicalize `NULL` `filter_hash`/`notrace_hash` to `EMPTY_HASH` before `add_next_hash()`. [F190, F214]
- Updating an `ftrace_ops` with `FTRACE_OPS_FL_SUBOP` or sharing `func_hash` with an active subop in `ftrace_hash_move_and_update_ops()` must route through `ftrace_hash_move_and_update_subops()`; modifying an ops with `func_hash == &global_ops.local_hash` in `ftrace_hash_rec_update_modify()` or `ftrace_ops_update_code()` must walk `ftrace_ops_list` to update all enabled ops sharing it. [F206, F208]
- `__register_ftrace_function()` and `register_ftrace_graph()` must save `ops->saved_func` / `gops->saved_func` before PID wrapping; toggling `op->func` in `ftrace_update_pid_func()` must call `ftrace_update_trampoline()` and `update_ftrace_function()`, and toggling `gops->entryfunc` in `fgraph_update_pid_func()` must call `static_call_update(fgraph_func, gops->entryfunc)` when `ftrace_graph_active == 1`. [F203, F204, F300]
- `ftrace_push_return_trace()` and `fgraph_reserve_data()` must reject allocations when `curr_ret_stack` reaches `SHADOW_STACK_MAX_OFFSET` (reserving the top `FGRAPH_ARRAY_SIZE` words for `SHADOW_STACK_TASK_VARS`), and `get_ret_stack()` must validate `offset > 0` and `offs > 0 && offs <= offset` before subtracting `offs`. [F225, F226]
- In `ftrace_partial_regs()` and `arch_ftrace_fill_perf_regs()`, backends must set the kernel-mode state field in `struct pt_regs` (`pstate = PSR_MODE_EL1h` on arm64, `cs = __KERNEL_CS` on x86, `psw.mask = 0` on s390, `msr` on powerpc) so `user_mode(regs)` is false, and on arm64/riscv `memcpy()` in `ftrace_partial_regs()` must be bounded by `sizeof(afregs->regs)` / `sizeof(afregs->args)`. [F33, F99]

## Synchronization
- Lock hierarchy is `trace_types_lock` -> `ops->func_hash->regex_lock` -> `ftrace_lock`, and `direct_mutex` -> `ftrace_lock`: `ftrace_release_mod()` and `ftrace_free_mem()` must drop `ftrace_lock` before `clear_mod_from_hashes()` / `clear_func_from_hashes()`, `process_mod_list()` must drop `ftrace_lock` around `match_records()`, and `unregister_ftrace_function()`, `prepare_direct_functions_for_ipmodify()`, and `cleanup_direct_functions_after_ipmodify()` must release `ftrace_lock` before taking `direct_mutex` or invoking `op->ops_func()` for `PEER` commands. [F17, F171, F172, F173]
- Because ftrace hooks run where RCU may not be watching, hot-path hash lookups in `ftrace_find_profiled_func()` and `__ftrace_lookup_ip()` must use `hlist_for_each_entry_rcu_notrace()` under `preempt_disable_notrace()`, and `function_profile_call()` / `profile_graph_return()` must use `guard(preempt_notrace)()` (with `ftrace_profile_alloc()` serializing against NMI via `atomic_inc_return(&stat->disabled) != 1` and re-checking `ftrace_find_profiled_func()`). [F277, F280]
- `function_graph_enter_regs()` and `__ftrace_return_to_handler()` acquire `ftrace_test_recursion_trylock()` internally around `entryfunc`/`retfunc`, so arch `ftrace_graph_func()` and `prepare_ftrace_return()` callers must NOT wrap `function_graph_enter_regs()` or `function_graph_enter()` in `ftrace_test_recursion_trylock()`; conversely, `kprobe_ftrace_handler()` must acquire `ftrace_test_recursion_trylock()` before touching `get_kprobe()` or `current_kprobe`, resetting `current_kprobe = NULL` and unlocking on all exit paths. [F5, F29, F279]
- In `ftrace_push_return_trace()` and `fgraph_reserve_data()`, descriptor `val` must be written at the new top of `current->ret_stack`, ordered by `barrier()`, before advancing `current->curr_ret_stack`, and written again after `barrier()`; in `__ftrace_return_to_handler()`, `current->curr_ret_stack` must not be decremented until after all `retfunc` callbacks finish, separated by `barrier()`. [F167, F168]
- `register_ftrace_graph()` must not assign `fgraph_array[i] = gops` until `ftrace_startup_subops(&graph_ops, &gops->ops, command)` succeeds, and lockless readers in `function_graph_enter_regs()` and `__ftrace_return_to_handler()` must load `READ_ONCE(fgraph_array[i])` and check against `&fgraph_stub` before dereferencing `gops`. [F164, F165]
- In `ftrace_modify_all_code()`, when `FTRACE_UPDATE_TRACE_FUNC` is set, `update_ftrace_func(ftrace_ops_list_func)` must run before `ftrace_replace_code()`, and `function_trace_op` must be published with `smp_wmb()` (and `ftrace_sync_ipi` if IRQs are enabled) before `update_ftrace_func(ftrace_trace_function)`; in `__modify_ftrace_direct()`, `tmp_ops` must remain registered while updating `direct_functions` and `WRITE_ONCE(ops->direct_call, ...)`. [F181, F182]
- Process-context `do_for_each_ftrace_rec()` loops doing kallsyms lookups or code patching must call `cond_resched()`, except `ftrace_replace_code()` may only call `cond_resched()` when `mod_flags & FTRACE_MODIFY_MAY_SLEEP_FL` (`command & FTRACE_MAY_SLEEP`) is set because default patching runs inside `stop_machine()`. [F239, F294]

## Object Lifetimes
- Static (non-`FTRACE_OPS_FL_DYNAMIC`) `struct ftrace_ops` on `ftrace_ops_list` must never be freed or have `ops->next` modified even after `unregister_ftrace_function()` because lockless readers traverse `ftrace_ops_list` via `do_for_each_ftrace_op()` (stopping at `&ftrace_list_end`), and callers with `ops->private` data must run `schedule_on_each_cpu()` after unregistering before freeing `ops->private`. [F15, F16, F59]
- For `FTRACE_OPS_FL_DYNAMIC`, `ftrace_shutdown()` must run both `synchronize_rcu_tasks_rude()` and `synchronize_rcu_tasks()` before `ftrace_trampoline_free()`; if `ftrace_hash_ipmodify_enable()` fails in `ftrace_startup()`, it must roll back `__unregister_ftrace_function()`, `ftrace_start_up--`, `FTRACE_OPS_FL_ENABLED`, and `ftrace_trampoline_free()`; and `ftrace_trampoline_free()` must call `ftrace_remove_trampoline_from_kallsyms()` before `arch_ftrace_trampoline_free()`. [F153, F154]
- On x86_64, `arch_ftrace_update_trampoline()`, `set_ftrace_ops_ro()`, `arch_ftrace_trampoline_func()`, and `arch_ftrace_trampoline_free()` must require `FTRACE_OPS_FL_ALLOC_TRAMP` in `ops->flags`; `arch_ftrace_trampoline_free()` must clear `ops->trampoline = 0` after `tramp_free()`, and `create_trampoline()` must call `tramp_free()` without setting `FTRACE_OPS_FL_ALLOC_TRAMP` on error. [F2, F47]
- `ftrace_hash` structures must only be freed via `free_ftrace_hash()` or `free_ftrace_hash_rcu()` (which ignore `NULL` and `EMPTY_HASH`), `ftrace_free_filter()` must reset pointers to `EMPTY_HASH`, and intermediate/replaced hashes in `ftrace_startup_subops()`, `rebuild_hashes()`, `ftrace_shutdown_subops()`, and `ftrace_hash_move_and_update_subops()` must be freed with `subops->list` rolled back on error. [F150, F152]
- `ftrace_graph_init_task()` must clear `t->ret_stack = NULL` before allocation; `ftrace_graph_exit_task()` must clear `t->ret_stack = NULL` and issue `barrier()` before `kmem_cache_free()`; `idle_ret_stack` is never freed; and before assigning `t->ret_stack`, `ret_stack_init_task_vars()` must zero `SHADOW_STACK_TASK_VARS`, set `curr_ret_stack = 0` and `curr_ret_depth = -1`, and run `smp_wmb()`. [F148, F199, F292]
- In `ftrace_process_locs()`, `ftrace_release_mod()`, and `ftrace_free_mem()`, removed `ftrace_page` structs must be unlinked under `ftrace_lock` and freed only after unlocking `ftrace_lock` and calling `synchronize_rcu()`; `ftrace_release_mod()` must unlink `mod_map` from `ftrace_mod_maps` and schedule `call_rcu(&mod_map->rcu, ftrace_free_mod_map)` before checking `ftrace_disabled`. [F162, F163, F291]
- `ftrace_regex_open()` must copy `filter_hash`/`notrace_hash` into `iter->hash` under `regex_lock` and clean up `iter->hash`, `iter->parser`, `iter`, and `trace_array_put(tr)` on failure; in `ftrace_regex_release()` and `ftrace_graph_release()`, `file->private_data` is a `struct seq_file *` only when `file->f_mode & FMODE_READ` is set (so `m->private` must be read before `seq_release()`), any loaded `parser` must be flushed before freeing, and `ftrace_graph_release()` must call `synchronize_rcu_tasks_rude()` before freeing `old_hash`. [F157, F158, F175, F195, F305]

## API Contracts
- Attribute flags in `struct ftrace_ops->flags` (`FTRACE_OPS_FL_SAVE_REGS`, `FTRACE_OPS_FL_RECURSION`, `FTRACE_OPS_FL_STUB`, `FTRACE_OPS_FL_IPMODIFY`) must never be modified while registered; `ftrace_ops_get_func()` must route `FTRACE_OPS_FL_RCU` or `FTRACE_OPS_FL_RECURSION` ops through `ftrace_ops_assist_func()` (checking `!(op->flags & FTRACE_OPS_FL_RCU) || rcu_is_watching()`); and under `CONFIG_DYNAMIC_FTRACE_WITH_REGS`, `ftrace_ops_test()` must return `0` if `regs == NULL && (ops->flags & FTRACE_OPS_FL_SAVE_REGS)`. [F14, F278, F297]
- `__ftrace_hash_move()` and `ftrace_hash_move()` leave `@src` allocated so callers must always call `free_ftrace_hash(src)`; `alloc_ftrace_hash(size_bits)` takes a bit-shift exponent (compute `fls()` on entry count before clamping to `FTRACE_HASH_MAX_BITS`); and IP insertions must check `ftrace_lookup_ip()` / `__ftrace_lookup_ip()` first to avoid duplicates. [F151, F191, F213]
- In `append_hash()`, `*hash == NULL` triggers allocation whereas non-NULL `ftrace_hash_empty(*hash)` (`EMPTY_HASH`) means trace-all and returns 0; conversely, `__ftrace_hash_update_ipmodify()` treats `NULL` as match-all (`-EINVAL`) and `EMPTY_HASH` as match-none, so callers must map `ftrace_hash_empty()` filter hashes to `NULL`. [F184, F185]
- With `CONFIG_HAVE_DYNAMIC_FTRACE_WITH_ARGS`, `arch_ftrace_get_regs()` / `ftrace_get_regs()` must return `NULL` unless full `pt_regs` were saved; callers of `ftrace_partial_regs(fregs, regs)` must supply a valid `regs` buffer and use the returned pointer; `ftrace_regs_get_argument()` on arm64/riscv must return `0` for `n >= 8`; and `ftrace_regs_get_kernel_stack_nth()` must verify `stackp + nth` shares the `~(THREAD_SIZE - 1)` base with `stackp`. [F32, F57, F62, F102]
- In `ftrace_graph_func()` and `prepare_ftrace_return()`, `retp` passed to `function_graph_enter_regs()` / `function_graph_enter()` must match the pointer passed by the unwinder to `ftrace_graph_ret_addr()`; `ftrace_graph_ret_addr()` must pass its `task` parameter (never `current`) to `get_ret_stack()`, start at `i = *idx ? : task->curr_ret_stack`, and update `*idx = i` on a match. [F35, F243]
- The `mod` parameter to `ftrace_make_nop()` is non-NULL only during module load and `NULL` at runtime; backends needing `mod` for out-of-range PLTs/stubs must cache `rec->arch.mod` on load (32-bit arm) or call `__module_text_address()` inside an RCU read-side critical section while holding `ftrace_lock` (arm64, loongarch, powerpc). [F11, F38, F53]

## Error Handling
- `function_graph_enter()` and `function_graph_enter_regs()` return `0` on success and `-EBUSY` on failure (shadow-stack exhaustion in `ftrace_push_return_trace()` must only increment `current->trace_overrun` and return `-EBUSY`, never `WARN` or `ftrace_graph_stop()`); callers in `prepare_ftrace_return()` and `ftrace_graph_func()` must only redirect the return address when `0` is returned (restoring `*parent = old` if overwritten beforehand), and inside `function_graph_enter_regs()` a callback returning 0 must restore `current->curr_ret_stack` (and roll back the frame and `curr_ret_depth` if `bitmap == 0`). [F9, F36, F147, F310]
- `FTRACE_WARN_ON` and `FTRACE_WARN_ON_ONCE` call `ftrace_kill()` and must only be used for unrecoverable internal bugs; if `ftrace_disabled` becomes set during `ftrace_startup()`, it must only call `__unregister_ftrace_function(ops)` and return `-ENODEV` without calling `ftrace_trampoline_free()` or rolling back record flags. [F308, F309]

## Known Pitfalls
- In `ftrace_replace_code()`, `ftrace_get_addr_curr(rec)` must be called before `ftrace_update_record(rec, enable)` because `ftrace_update_record()` mutates the `FTRACE_FL_*_EN` flags that `ftrace_get_addr_curr()` reads; and despite the inverted header comment, `ftrace_need_init_nop()` must return nonzero (`true`) when `ftrace_init_nop()` is needed. [F31, F45]
- Because `do_for_each_ftrace_rec(pg, rec)` expands to nested `for` loops over pages and records, `break` inside the body only exits the current page's loop (use `goto` or `return`); and `ftrace_hash_key()` must check `hash->size_bits > 0` and return `0` when `size_bits == 0` before calling `hash_long()`. [F238, F253]
- `ftrace_ops_set_global_filter(ops)` returns early if `FTRACE_OPS_FL_INITIALIZED` is already set, so it must be called before `ftrace_ops_init(ops)` or any filter/registration call; and because `ops->private` (`struct trace_array *tr`) is `NULL` for standalone filters, filter/command callbacks must check `if (!tr)`. [F192, F193]
