# VIRTIO AND VHOST VSOCK DRIVER

Implements the virtio and vhost transport layers for AF_VSOCK stream and seqpacket sockets between host and guest VMs. `net/vmw_vsock/virtio_transport_common.c` provides shared packet framing, flow-control credit accounting, zero-copy SKB construction, and socket state machine logic; `net/vmw_vsock/virtio_transport.c` implements the guest-to-host virtio driver; and `drivers/vhost/vsock.c` implements the host-to-guest `/dev/vhost-vsock` backend driver.

## Architecture & Data Flow
- `virtio_vsock_hdr(skb)` accesses `struct virtio_vsock_hdr` at `skb->head` in the `VIRTIO_VSOCK_SKB_HEADROOM` bytes reserved before `skb->data`, while `skb->data` points to payload and `skb->len` counts only payload bytes. `__virtio_vsock_alloc_skb_with_frags()` does not zero headroom, so `virtio_transport_init_hdr()` must initialize every `virtio_vsock_hdr` field (including zeroing `buf_alloc` and `fwd_cnt`), and `virtio_vsock_rx_fill()` must zero `VIRTIO_VSOCK_SKB_HEADROOM` bytes at `skb->head`. [F56, F118]
- Nonlinear vsock SKBs (`skb_is_nonlinear(skb)`) must contain only `struct virtio_vsock_hdr` in the linear buffer (`skb_headroom(skb) == VIRTIO_VSOCK_SKB_HEADROOM`, no linear payload in `skb->data`) with all payload in `skb_shinfo(skb)->frags` (`<= MAX_SKB_FRAGS`, matching `virtio_vsock::out_sgs[MAX_SKB_FRAGS + 1]`). `virtio_vsock_skb_put()` must set `skb->len = len` directly rather than calling `skb_put()`. [F78, F84]
- Before `virtio_vsock_skb_put()`, `virtio_transport_rx_work()` must verify `len` is in `[sizeof(*hdr), virtio_vsock_skb_len(skb)]` and `le32_to_cpu(hdr->len) <= len - sizeof(*hdr)`, and `vhost_vsock_alloc_skb()` must bound `len = iov_length(vq->iov, out)` within `[VIRTIO_VSOCK_SKB_HEADROOM, VIRTIO_VSOCK_MAX_PKT_BUF_SIZE + VIRTIO_VSOCK_SKB_HEADROOM]` and verify `le32_to_cpu(hdr->len) + sizeof(*hdr) <= len`. `vhost_vsock_handle_tx_kick()` must verify `src_cid == vsock->guest_cid` and `dst_cid == vhost_transport_get_local_cid()` (else `kfree_skb(skb)`). [F79, F80, F163, F164]
- Call `virtio_transport_deliver_tap_pkt(skb)` (which sets `tap_delivered = true`) only after virtqueue queueing or descriptor copy succeeds. When `vhost_transport_do_send_pkt()` splits an SKB across guest RX buffers (`payload_len > iov_len - sizeof(*hdr)`), clear `VIRTIO_VSOCK_SEQ_EOM` and `VIRTIO_VSOCK_SEQ_EOR` from `hdr->flags` before copying the non-final header, then restore those flags and call `virtio_vsock_skb_clear_tap_delivered(skb)` before requeueing. [F70, F160]
- Every SKB with `virtio_vsock_skb_reply(skb)` queued to `send_pkt_queue` increments `queued_replies` (never on `virtio_transport_send_skb_fast_path()`); when fully sent or purged via `virtio_transport_purge_skbs()`, decrement `queued_replies` and restart `tx_vq->poll` or `rx_work` if below the vring size. When `virtio_transport_more_replies()` or `vhost_vsock_more_replies()` is false, jump out (`goto out` / `goto no_more_replies`) bypassing `virtqueue_enable_cb()` / `vhost_enable_notify()`. [F71, F104]
- `virtio_transport_get_credit()` and `virtio_transport_put_credit()` update `vvs->tx_cnt` and `vvs->bytes_unsent` by the same delta under `vvs->tx_lock`, while `virtio_transport_consume_skb_sent()` decrements only `vvs->bytes_unsent` by `skb->len` under `vvs->tx_lock` when `skb->sk != NULL`. In `virtio_transport_send_pkt_info()`, if `pkt_len == 0 && info->op == VIRTIO_VSOCK_OP_RW` after `virtio_transport_get_credit()`, return 0 before the send loop. [F67, F105]
- When `vvs->fwd_cnt != vvs->last_fwd_cnt` after `virtio_transport_stream_do_dequeue()` or `virtio_transport_notify_set_rcvlowat()`, call `virtio_transport_send_credit_update()` if `vvs->rx_bytes` is below `sock_rcvlowat()` / the new `SO_RCVLOWAT` or `free_space < VIRTIO_VSOCK_MAX_PKT_BUF_SIZE`. Compare wrapping `u32` counters `fwd_cnt` and `last_fwd_cnt` only via `!=` or `u32` subtraction (`vvs->fwd_cnt - vvs->last_fwd_cnt`), never `<` or `>`. [F66, F114]
- Whenever an SKB with `VIRTIO_VSOCK_SEQ_EOM` in `le32_to_cpu(hdr->flags)` is enqueued to or dequeued from `vvs->rx_queue` (`virtio_transport_recv_enqueue()`, `virtio_transport_seqpacket_do_dequeue()`, or `virtio_transport_read_skb()`), increment or decrement `vvs->msg_count` in lockstep under `vvs->rx_lock`. `virtio_transport_recv_enqueue()` may coalesce into `last_skb` only if `last_hdr->flags` lacks `VIRTIO_VSOCK_SEQ_EOM`, updating `last_hdr->flags |= hdr->flags` and `le32_add_cpu(&last_hdr->len, len)` with `skb_put()`. [F64, F65]

## Synchronization
- In `struct virtio_vsock`, access `vqs[VSOCK_VQ_TX]`, `tx_run`, `out_sgs`, and `out_bufs` under `tx_lock`; `vqs[VSOCK_VQ_RX]`, `rx_run`, `rx_buf_nr`, and `rx_buf_max_nr` under `rx_lock`; and `vqs[VSOCK_VQ_EVENT]`, `event_run`, and `event_list` under `event_lock`. Virtqueue callbacks (`virtio_vsock_rx_done()`, `virtio_vsock_tx_done()`, `virtio_vsock_event_done()`) run in interrupt context and must only check `vq->vdev->priv` for NULL and queue work onto `virtio_vsock_workqueue` without taking mutexes or sleeping. [F33, F143]
- On active sockets (before `SOCK_DONE`), hold `vvs->tx_lock` via `spin_lock_bh()` for `tx_cnt`, `peer_fwd_cnt`, `peer_buf_alloc`, and `bytes_unsent`, and `vvs->rx_lock` via `spin_lock_bh()` for `fwd_cnt`, `last_fwd_cnt`, `rx_bytes`, `buf_used`, `rx_queue`, and `msg_count` (dropping `rx_lock` before `skb_copy_datagram_iter()` in stream/seqpacket peek and dequeue and keeping it balanced on exit). Also use `spin_lock_bh()` on `send_pkt_queue.lock`. [F23, F36, F37, F141]
- In `virtio_transport_send_pkt()` (under `rcu_read_lock()`), call `virtio_transport_send_skb_fast_path()` only when `skb_queue_empty_lockless(&vsock->send_pkt_queue)` is true; it must acquire `vsock->tx_lock` with `mutex_trylock()` (never `mutex_lock()`) and pass `GFP_ATOMIC` to `virtio_transport_send_skb()`. Similarly, `virtio_transport_build_skb()` runs under `rcu_read_lock()` in `vsock_deliver_tap()` and must allocate with `GFP_ATOMIC`. [F45, F137, F138]
- In `virtio_transport_recv_pkt()`, query `vsock_find_connected_socket()` before `vsock_find_bound_socket()`, verify `skb_set_owner_sk_safe(skb, sk)` before `lock_sock(sk)`, and recheck `!sock_flag(sk, SOCK_DONE)` and (if `sk_state != TCP_LISTEN`) `vsk->transport == &t->transport` under `lock_sock(sk)`. In `virtio_transport_recv_listen()`, check `sk_shutdown == SHUTDOWN_MASK`, use `lock_sock_nested(child, SINGLE_DEPTH_NESTING)`, and verify `vchild->transport == &t->transport` (calling `release_sock(child)` and `sock_put(child)` on error). [F13, F41, F96, F120, F145, F146]
- Mutate `the_virtio_vsock` under `the_virtio_vsock_mutex` (returning `-EBUSY` in `probe`/`restore` if non-NULL), and mutate `vsock->guest_cid` and `vhost_vsock_hash` under `vhost_vsock_mutex` in `vhost_vsock_set_cid()` (calling `hash_del_rcu()` if `guest_cid != 0`). Readers of `rcu_dereference(the_virtio_vsock)` or `vhost_vsock_get()` (which skips `guest_cid == 0`) must hold `rcu_read_lock()` or the mutex and check for `NULL`. [F35, F53, F74, F102, F131, F147]
- In `drivers/vhost/vsock.c`, acquire `vsock->dev.mutex` outer to `vq->mutex`, and never hold `vq->mutex` when calling `vhost_vsock_flush()`. Callbacks passed to `vsock_for_each_connected_socket()` (`vhost_vsock_reset_orphans()`, `virtio_vsock_reset_sock()`) run under `spin_lock_bh(&vsock_table_lock)` and must never call `lock_sock(sk)` or sleep. [F140, F144]

## Object Lifetimes
- `virtio_transport_recv_pkt()` takes ownership of `skb` and must either enqueue it onto `vvs->rx_queue` (for `VIRTIO_VSOCK_OP_RW` in `TCP_ESTABLISHED`) or free it with `kfree_skb(skb)` across every state and error path, while balancing `sk` references with `sock_put(sk)`. Socket-bound SKBs must set `skb->sk` via `skb_set_owner_w()` in `virtio_transport_alloc_skb()` (before `virtio_transport_fill_skb()`) or `skb_set_owner_sk_safe()` in `virtio_transport_recv_pkt()`; when `info->vsk == NULL` (socketless RST), skip `skb_set_owner_w()` and ensure `zcopy` is `false`. [F3, F5, F54]
- In `virtio_transport_close()`, set `sock_hold(sk)` and `vsk->close_work_scheduled = true` under `lock_sock(sk)` before `schedule_delayed_work()`; `virtio_transport_close_timeout()` must take an extra `sock_hold(sk)` around `lock_sock(sk)` and recheck `!sock_flag(sk, SOCK_DONE)`. `virtio_transport_cancel_close_work()` must only clear `close_work_scheduled`, call `virtio_transport_remove_sock(vsk)` (purging `rx_queue`), and drop `sock_put(sk)` if `close_work_scheduled && (!cancel_timeout || cancel_delayed_work(&vsk->close_work))`. [F19, F43, F77]
- `virtio_transport_destruct()` must cancel any pending close work via `virtio_transport_cancel_close_work(vsk, true)`, free `vvs` with `kfree(vvs)`, and set `vsk->trans = NULL` to prevent dangling pointer dereferences. [F14]
- In `virtio_vsock_probe()`, initialize `vdev->priv`, `vsock->seqpacket_allow`, and `vsock->out_sgs[i] = &vsock->out_bufs[i]` before `virtio_vsock_vqs_init()` resets `rx_buf_nr`, `rx_buf_max_nr`, and `queued_replies` to 0, updates `guest_cid`, and calls `virtio_device_ready(vdev)`. In `probe` and `restore`, `rcu_assign_pointer(the_virtio_vsock, vsock)` must precede `virtio_vsock_vqs_start(vsock)`. [F25, F26, F27, F72, F124]
- In `virtio_vsock_vqs_del()`, set `rx_run`, `tx_run`, and `event_run` to `false` under their mutexes before `virtio_reset_device(vdev)`, which must precede `virtqueue_detach_unused_buf()`, `virtio_vsock_skb_queue_purge(&vsock->send_pkt_queue)`, and `vdev->config->del_vqs(vdev)`. `virtio_vsock_remove()` and `virtio_vsock_freeze()` must clear `the_virtio_vsock` and call `synchronize_rcu()` before `virtio_vsock_vqs_del(vsock)`; `remove` also clears `vdev->priv` and flushes all work items after `vqs_del` before `kfree(vsock)`, whereas `freeze` preserves `vdev->priv`. [F126, F127, F132]
- `vhost_vsock_dev_release()` must remove `vsock->hash` under `vhost_vsock_mutex` and call `synchronize_rcu()` before calling `vhost_vsock_reset_orphans()` (skipping sockets whose `remote_addr.svm_cid` still resolves via `vhost_vsock_get()` or have `close_work_scheduled`), stopping and flushing the device, purging `send_pkt_queue`, calling `vhost_dev_cleanup(&vsock->dev)`, `kfree(vsock->dev.vqs)`, and `vhost_vsock_free(vsock)` (`kvfree()`). [F11, F75, F130]

## API Contracts
- `virtio_transport::send_pkt` takes ownership of `skb` and must either queue it and return `skb->len` or call `kfree_skb(skb)` on negative errno (callers free `skb` on error before `send_pkt()`, never after). `virtio_transport_read_skb()` transfers `skb` ownership to `recv_actor(sk, skb)` and must not free `skb`. [F2, F4, F153]
- `virtio_transport_purge_skbs()` must return the count of purged SKBs with `virtio_vsock_skb_reply(skb)` set (not total purged SKBs) for `queued_replies` accounting. `virtio_transport_dec_rx_pkt(vvs, bytes_read, bytes_dequeued)` subtracts `bytes_read` from `vvs->rx_bytes` on partial reads, and subtracts `bytes_dequeued` (`le32_to_cpu(virtio_vsock_hdr(skb)->len)`) from `vvs->buf_used` and adds it to `vvs->fwd_cnt` only when unlinking an SKB. [F49, F60]
- In `virtio_transport_send_pkt_info()`, clear `MSG_ZEROCOPY` if `!sock_flag(sk_vsock(vsk), SOCK_ZEROCOPY)`, and call `virtio_transport_init_zcopy_skb()` only on the final SKB of a `VIRTIO_VSOCK_OP_RW` loop (`skb_len == rest_len`). In `virtio_transport_can_zcopy()`, check `if (t_ops->can_msgzerocopy)` before calling it with `pages_to_send + 1`. [F61, F159]
- Clamp `u64` buffer sizes to `VIRTIO_VSOCK_MAX_BUF_SIZE` (`0xFFFFFFFFUL`) before assigning `u32 vvs->buf_alloc`; in `virtio_transport_seqpacket_enqueue()`, check `size_t len` against `u32 vvs->peer_buf_alloc` before `virtio_transport_stream_enqueue()` narrows `len` to `u32`. Include `VIRTIO_VSOCK_SKB_HEADROOM` in `size` when calling `virtio_vsock_alloc_skb()` or `virtio_vsock_alloc_linear_skb()`. [F112, F113, F115]
- `VIRTIO_VSOCK_F_SEQPACKET` is a bit index (`1`): pass it directly to `virtio_has_feature()`, but shift as `1ULL << VIRTIO_VSOCK_F_SEQPACKET` in `VHOST_VSOCK_FEATURES` and `vhost_vsock_set_features()`. [F58]

## Error Handling
- In `virtio_transport_send_pkt_info()`, if a loop iteration fails after earlier iterations sent bytes (`rest_len != pkt_len`), return the unused `rest_len` credit via `virtio_transport_put_credit()` and return `pkt_len - rest_len`. Similarly, in `virtio_transport_stream_do_peek()` and `virtio_transport_stream_do_dequeue()`, if `skb_copy_datagram_iter()` fails when `total > 0`, return `total`. [F47, F48]
- `virtio_transport_stream_do_dequeue()` must inspect with `skb_peek(&vvs->rx_queue)` and only advance `offset`, decrement `rx_bytes`, and unlink/free `skb` after `skb_copy_datagram_iter()` succeeds; `virtio_transport_fill_skb()` must use `skb_copy_datagram_from_iter_full()` so `msg_iter` reverts on fault. In `virtio_transport_seqpacket_do_dequeue()`, if `skb_copy_datagram_iter()` fails, set `dequeued_len = err` and continue dequeuing/freeing fragments until `VIRTIO_VSOCK_SEQ_EOM`. [F22, F62, F68]
- Store `vhost_get_vq_desc()` in a signed `int head`, checking `head < 0` and `head == vq->num` (and verifying `iov_len >= sizeof(*hdr)` before `iov_len - sizeof(*hdr)` on RX); when descriptors are unavailable in `vhost_transport_do_send_pkt()` or `virtio_transport_send_pkt_work()`, requeue `skb` at the head via `virtio_vsock_skb_queue_head(&vsock->send_pkt_queue, skb)`. If `vhost_vsock_start()` fails on a virtqueue, clear `vhost_vq_set_backend(vq, NULL)` under `vq->mutex` on the failing and all prior virtqueues. [F12, F24, F50, F81]

## External Contracts
- In `vhost_add_used(vq, head, len)`, pass `len = 0` on `VSOCK_VQ_TX` in `vhost_vsock_handle_tx_kick()` (device-readable `out` buffers), and `len = sizeof(*hdr) + payload_len` on `VSOCK_VQ_RX` in `vhost_transport_do_send_pkt()`. Wire and config CID fields (`virtio_vsock_hdr::src_cid`, `dst_cid`, `virtio_vsock_config::guest_cid`) are `__le64` and must use `le64_to_cpu()` / `cpu_to_le64()`, even though in-memory CIDs are `u32`. [F57, F87]
- `virtio_transport_recv_connected()` must handle `VIRTIO_VSOCK_OP_CREDIT_REQUEST` by calling `virtio_transport_send_credit_update(vsk)` and freeing `skb`, while `VIRTIO_VSOCK_OP_RW` must return directly after `virtio_transport_recv_enqueue()` without falling through to `kfree_skb(skb)`. Both `virtio_transport_reset()` and `virtio_transport_reset_no_sock()` must check if an incoming `skb` already has `le16_to_cpu(hdr->op) == VIRTIO_VSOCK_OP_RST` and return 0 without sending a reply RST. [F97, F98]

## Known Pitfalls
- Listener sockets (`sk->sk_state == TCP_LISTEN`) and child sockets whose `vsock_assign_transport()` failed have `vsk->transport == NULL` and `vsk->trans == NULL`: never call `virtio_transport_send_pkt_info()` or `virtio_transport_reset()` on them (use `virtio_transport_reset_no_sock(t, skb)`), check `virtio_transport_get_ops(vsk)` and `t` for `NULL`, and in `virtio_transport_recv_listen()` pass `child`/`vchild` (not `sk`/`vsk`) to `virtio_transport_space_update()`, `virtio_transport_send_response()`, and `vsock_insert_connected()`. [F51, F52, F107]
- `vhost_vsock_dev_open()` allocates `struct vhost_vsock` with `kvmalloc()` (not `kvzalloc()`), so every field (including `guest_cid` and `seqpacket_allow`) must be explicitly initialized in `vhost_vsock_dev_open()`, and `vhost_vsock_set_features()` must unconditionally assign `vsock->seqpacket_allow`. `struct vhost_vsock::vqs` has only 2 elements (`VSOCK_VQ_RX`, `VSOCK_VQ_TX`), not `VSOCK_VQ_MAX` (3), so bound loops with `ARRAY_SIZE(vsock->vqs)` and never index `VSOCK_VQ_EVENT`. [F55, F83]
- In `virtio_transport_has_space()`, evaluate `(vvs->tx_cnt - vvs->peer_fwd_cnt)` as a 32-bit unsigned difference before subtracting from `(s64)vvs->peer_buf_alloc` and clamping negative results to `0`. Every insertion and lookup on `vhost_vsock_hash` (`vhost_vsock_set_cid()`, `vhost_vsock_get()`) must pass a 32-bit `u32` key rather than a `u64` expression because `hash_min()` dispatches on `sizeof(key)`. [F90, F110]
