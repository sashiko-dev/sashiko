# BLOCK LAYER

The block layer manages block device (`bdev`) lifecycles and claiming, `bio` and multiqueue (`blk-mq`) request allocation, merging, scheduling, DMA/buffer mapping, inline encryption (`blk-crypto`), data integrity (`bio-integrity`, `t10-pi`), zoned write plugging, QoS/throttling (`blk-wbt`, `blk-cgroup`), SED Opal, and virtual/hardware block drivers (`loop`, `null_blk`, `xen-blkfront`, `mtip32xx`, `sunvdc`, `ps3disk`).

## Architecture & Data Flow
- `__bio_advance()` must advance `bio_integrity_advance()` and `bio_crypt_advance()` alongside `bio_advance_iter()`. Shrinking `bi_iter.bi_size` in `bio_split()` or `bio_trim()` must call `bio_integrity_trim()` after updating `bi_size`. Attaching/freeing integrity (`bio_integrity_init()`, `bio_integrity_free()`, `bio_integrity_finish()`) must toggle `REQ_INTEGRITY` in `bio->bi_opf` in lockstep with `bio->bi_integrity`. `bio_truncate()` must only reduce `bi_size` without modifying `bi_io_vec` or `bi_vcnt`. [F69, F70, F71, F98]
- `bio_crypt_ctx_mergeable(bc1, bc1_bytes, bc2)` checks DUN continuity in `@bc1` then `@bc2` order, propagating 64-bit overflow across all `u64 dun[BLK_CRYPTO_DUN_ARRAY_SIZE]` limbs and returning `false` if final `carry != 0`. Front-merge (`bio_attempt_front_merge()`) must pass `(bio->bi_crypt_context, bio->bi_iter.bi_size, req->crypt_ctx)` and copy `bc_dun` via `bio_crypt_do_front_merge()`, whereas `bio_attempt_back_merge()` and `blk_rq_append_bio()` must call `bio_crypt_free_ctx(bio)`. [F60, F74, F142]
- Block integrity and inline encryption are mutually exclusive: `blk_crypto_register()` rejects queues with `blk_integrity_queue_supports_integrity(q)`, `bio_integrity_alloc()` returns `ERR_PTR(-EOPNOTSUPP)` if `bio_has_crypt_ctx(bio)`, and `queue_limits_commit_update()` returns `-EINVAL` if both `q->crypto_profile` and `lim->integrity.tag_size` are non-zero. [F210, F383]
- Flush requests entering `blk_insert_flush()` must have a single bio (`rq->bio == rq->biotail`) so `blk_flush_restore_request()` can restore `rq->bio`, `rq->__sector`, and `rq->end_io`. `rq->flush.seq` must only set bits from `REQ_FSEQ_ACTIONS` (pre-setting `REQ_FSEQ_PREFLUSH` for `REQ_FSEQ_DATA | REQ_FSEQ_POSTFLUSH`) so `blk_flush_cur_seq()` yields `REQ_FSEQ_DONE`. In `flush_end_io()`, `fq->flush_running_idx ^= 1` must be toggled before `list_for_each_entry_safe()` unlinks each `rq->queuelist` and calls `blk_flush_complete_seq()`. [F77, F79, F121, F122, F137]
- In `struct blk_mq_tags`, `rqs[]` and `static_rqs[]` map `[0, nr_reserved_tags)` to `breserved_tags` and `[nr_reserved_tags, nr_tags)` to `bitmap_tags`, so `bitmap_tags` bit indices must be offset by `nr_reserved_tags`. `hctx->ctxs[]` and `hctx->ctx_map` are indexed in `[0, hctx->nr_ctx)` by `ctx->index_hw[hctx->type]`, never `ctx->cpu`, and unmapped hardware queues (`!blk_mq_hw_queue_mapped(hctx)`) have `hctx->tags == NULL`. [F275, F315, F316]
- Requests with `RQF_SPECIAL_PAYLOAD` use `rq->special_vec` rather than `rq->bio`, and internal flush requests may have `rq->bio == NULL`. Partial completion in `blk_update_request()` must update `req->__data_len`, `req->__sector`, `REQ_FAILFAST_MASK` (when `RQF_MIXED_MERGE`), and `req->nr_phys_segments` (unless `RQF_SPECIAL_PAYLOAD`). `__blk_mq_requeue_request()` on a started request must reset `rq->state = MQ_RQ_IDLE`, clear `RQF_TIMED_OUT`, release the driver tag, and call `rq_qos_requeue()`. [F277, F294, F296]
- Every BIO added to `zwplug->bio_list` in `disk_zone_wplug_add_bio()` takes an extra `q->q_usage_counter` reference that must be consumed by new request creation in `blk_mq_submit_bio()` or dropped via `blk_queue_exit(q)` on back-merge, abort, cached-rq reuse (`rq != NULL`), or bio-based submission. On plugged write error in `blk_zone_write_plug_bio_endio()`, `disk_zone_wplug_abort()` must abort queued BIOs and set `BLK_ZONE_WPLUG_NEED_WP_UPDATE` until `disk_zone_wplug_set_wp_offset()` runs. [F300, F301, F415]

## Synchronization
- Queue freeze/quiesce and lock ordering: callers must never hold `request_queue` quiesced (`blk_mq_quiesce_queue()`) when calling `blk_mq_freeze_queue()` or helpers that freeze (e.g., `elevator_set_none()`); freeze must precede quiesce. While frozen, code must not acquire `fs_reclaim` or `cpu_hotplug_lock` (e.g., `static_branch_inc()`/`dec()`). Locking order is `set->update_nr_hwq_lock` -> `blk_mq_freeze_queue(q)` -> `q->elevator_lock` -> `q->rq_qos_mutex` (cgroup handlers taking `elevator_lock` must use `blkg_conf_open_bdev_frozen()`). [F31, F192, F256, F257, F390, F398]
- Queue limits and QoS locking: `queue_limits_start_update(q)` acquires `q->limits_lock`, and `queue_limits_commit_update()` / `queue_limits_commit_update_frozen()` always unlocks it on both success and failure (requiring a frozen/idle queue if live); call `queue_limits_cancel_update(q)` only when aborting before commit. `rq_qos_add()` and `rq_qos_del()` require `q->rq_qos_mutex` and a frozen queue around mutating `q->rq_qos` and `QUEUE_FLAG_QOS_ENABLED`, while debugfs registration runs outside freeze under `q->debugfs_mutex`. [F220, F225, F405, F422]
- All `blk-mq` dispatch paths must run inside `__blk_mq_run_dispatch_ops()` / `blk_mq_run_dispatch_ops()` (`srcu_read_lock(tag_set->srcu)` if `BLK_MQ_F_BLOCKING`, else `rcu_read_lock()`), pairing with `blk_mq_wait_quiesce_done()`. When lockless `blk_mq_hw_queue_need_run(hctx)` in `blk_mq_run_hw_queue()` returns `false`, it must recheck under `q->queue_lock` to synchronize with `blk_mq_unquiesce_queue()`. [F250, F251]
- Tag iteration and timeouts: `blk_mq_queue_tag_busy_iter()` must pin `q->q_usage_counter` via `percpu_ref_tryget()` and hold `srcu_read_lock(&q->tag_set->tags_srcu)`. `bt_iter()` / `bt_tags_iter()` must use `blk_mq_find_and_get_req()` (`rq != NULL`, `rq->tag == bitnr`, `req_ref_inc_not_zero(rq)`) and reverify `rq->q == q && (!hctx || rq->mq_hctx == hctx)`. `blk_mq_timeout_work()` must use `percpu_ref_tryget()` (never `blk_queue_enter()`), call `blk_mq_wait_quiesce_done()`, and reset `expired.next = 0` before `blk_mq_handle_expired()`. [F253, F254, F262, F338]
- Atomic `bi_end_io` completion context: `bio_integrity_unpin_bvec()` must only call `unpin_user_page()` (never `set_page_dirty_lock()`). Direct-I/O reads must dirty folios before submission via `bio_set_pages_dirty()` and use `bio_check_pages_dirty()` on completion to defer `folio_lock()`/`folio_mark_dirty()`. Read integrity verification (`__bio_integrity_endio()`) and software fallback decryption (`blk_crypto_fallback_decrypt_endio()`) must defer to `kintegrityd_wq` and `blk_crypto_wq` instead of running in atomic completion context. [F170, F171, F172, F173]
- `blk_zone_wplug_bio_work()` must drop `zwplug->lock` before calling `blk_zone_wplug_bio_io_error(zwplug, bio)` when `blk_zone_wplug_prepare_bio()` returns `false` (avoiding stacked `zwplug->lock` deadlock in `bio_endio()`), and must loop back (`goto again`) to drain the next bio in `zwplug->bio_list`. [F255, F342]
- In `drivers/block/loop.c`, `loop_global_lock_killable(lo, global)` locks `loop_validate_mutex` (when `global` is true, as in `loop_clr_fd()`) before `lo->lo_mutex`. In `loop_change_fd()`, if `!is_loop`, `loop_validate_mutex` must be locked/unlocked after `loop_global_unlock()` before `fput(old_file)`. `fput()`, `loop_reread_partitions()`, and `vfs_getattr()` (after `path_get(&lo_backing_file->f_path)` under `lo_mutex`) must run outside `lo_mutex`. `loop_update_dio()` on a `Lo_bound` device requires `lo_mutex`, a frozen queue, and `vfs_fsync()`. [F430, F431, F451, F454, F602, F603]

## Object Lifetimes
- In `bdev_file_open_by_dev()`, after `alloc_file_pseudo_noaccount()` succeeds, `ihold(BD_INODE(bdev))` is taken and any `bdev_open()` failure must set `bdev_file->private_data = ERR_PTR(ret)` before `fput()` so `bdev_release()` only calls `blkdev_put_no_open()`. In `bdev_fput()`, `private_data` is set to `BDEV_I(bdev_file->f_mapping->host)` (not `NULL`) under `disk->open_mutex` so `bdev_unclaimed()` prevents double yield. Every successful `bd_prepare_to_claim()` must pair with `bd_finish_claiming()` or `bd_abort_claiming()`. [F3, F4, F5, F149]
- Bios initialized with `bio_init()` / `bio_init_inline()` in caller-managed memory (`bio_kmalloc()` or stack) must be cleaned up with `bio_uninit()` before freeing/resetting, never `bio_put()` (`bio->bi_pool != NULL`). Bios from `blk_rq_map_bio_alloc()` must be freed via `blk_mq_map_bio_put()`. Cloned/split bios (`bio_alloc_clone()`, `bio_init_clone()`, `bio_split()`) and cloned requests (`blk_rq_prep_clone()`) borrow the source's `bi_io_vec` / `bip_vec` and pages, so the clone must complete before the source. [F6, F8, F16, F80, F418]
- In `blk_free_queue()`, `percpu_ref_exit(&q->q_usage_counter)` and `kmem_cache_free()` must be deferred to `blk_free_queue_rcu()`. In `blk_mq_exit_queue()`, `blk_mq_exit_hw_queues()` must precede `blk_mq_del_queue_tag_set()`. Before freeing request pages (`blk_mq_free_rqs()` via `call_srcu(&set->tags_srcu, ...)`) or `hctx->fq` (`blk_mq_exit_hctx()`), stale `drv_tags->rqs[]` pointers must be cleared via `blk_mq_clear_rq_mapping()` / `blk_mq_clear_flush_rq_mapping()`, and `exit_request(flush_rq)` must precede `exit_hctx`. [F14, F228, F246, F376, F377, F397]
- Request completion and inline crypto: in `blk_complete_request()` and `blk_update_request()`, the keyslot must be released via `blk_crypto_rq_put_keyslot()` before the `bio_endio()` loop, and `bio->bi_next` must be saved before calling `bio_endio(bio)`. In `__blk_mq_end_request()`, `blk_mq_end_request_batch()`, and `blk_mq_put_rq_ref()`, `rq` is freed only if `rq->end_io()` returns `RQ_END_IO_FREE` (`RQ_END_IO_NONE` retains ownership). In `blk_end_sync_rq()`, `wait->ret = ret` must be written before `complete(&wait->done)`. [F232, F233, F334, F367]
- `rq_qos_wait()` / `rq_qos_wake_function()` and plug caching: in `rq_qos_wake_function()`, `list_del_init_careful(&curr->entry)` must be the final step after setting `data->got_token = true` and calling `default_wake_function()`, and if the first waiter in `rq_qos_wait()` gets a token via `acquire_inflight_cb()`, it must call `cleanup_cb()` after `finish_wait()` if `data.got_token` is also set. `blk_mq_use_cached_rq()` must pop `rq` from `plug->cached_rqs` before `rq_qos_throttle()`, and `blk_mq_get_new_requests()` must call `rq_qos_cleanup()` if allocation fails. [F221, F231, F261, F366]
- In `drivers/block/loop.c`, `lo_rw_aio()` sets `atomic_set(&cmd->ref, 2)` before `read_iter()`/`write_iter()`; only when `atomic_dec_and_test(&cmd->ref)` succeeds in `lo_rw_aio_do_completion()` may `cmd->bvec` be freed, `kiocb_end_write()` called, and `rq` completed. In `loop_handle_cmd()`, `cmd` must not be touched after `do_req_filebacked()` returns `-EIOCBQUEUED`. Before replacing/clearing `lo->lo_backing_file` (cleared under `lo->lo_lock` before `fput()`), `old_file->f_mapping` GFP mask must be restored from `lo->old_gfp_mask`. [F432, F436, F452, F457, F599]

## API Contracts
- Bio ownership on submission/helpers: `submit_bio_wait()` does not consume the caller's reference on `@bio` (caller must still `bio_put()` / `bio_uninit()`). Conversely, `bio_chain(bio, parent)` (requiring `bio->bi_private == NULL && bio->bi_end_io == NULL`) and `bio_check_pages_dirty(bio)` consume `@bio`. `bio_submit_split_bioset()`, `bio_integrity_prep()`, and `__blk_crypto_bio_prep()` consume `@bio` on failure by setting `bi_status` and calling `bio_endio(bio)` before returning `NULL`/`false`, whereas `bio_split()` returns an `ERR_PTR` without ending `@bio`. [F7, F9, F10, F19, F49]
- Return value conventions: `set_blocksize()` returns `0` on success or `-errno`, whereas `sb_set_blocksize()` and `sb_min_blocksize()` return the new block size or `0` on failure. `badblocks_check()` returns `0` (clean), `1` (acked bad blocks), or `-1` (unacked bad blocks). `blk_rq_dma_map_iter_start()` / `_next()` return `false` on both end-of-segments and error (check `iter->status != BLK_STS_OK`). `blk_mq_get_tag()` returns unsigned `BLK_MQ_NO_TAG` (`-1U`) on failure. `opal_unlock_from_suspend()` returns `true` on failure and `false` on success. [F48, F66, F266, F268, F470]
- Allocator error returns: `__blk_mq_alloc_disk()`, `blk_mq_alloc_queue()`, `blk_mq_alloc_request()`, and `blk_mq_alloc_request_hctx()` (which requires `BLK_MQ_REQ_NOWAIT | BLK_MQ_REQ_RESERVED`) return `ERR_PTR()` on failure, whereas `blk_mq_alloc_disk_for_queue()`, `__blk_mq_alloc_requests()`, `blk_mq_alloc_cached_request()`, and `blk_mq_get_new_requests()` return `NULL`. In `xlvbd_alloc_gendisk()` and `probe_disk()`, `blk_mq_alloc_disk()` must be checked with `IS_ERR()` before assigning `info->gd` or `port->disk`. [F267, F269, F285, F671]
- Passthrough requests (`blk_rq_is_passthrough(rq)`) and `REQ_OP_FLUSH` must bypass `q->elevator` in `blk_mq_insert_request()` via `blk_mq_request_bypass_insert()`, and passthrough requests must never be passed to `__rq_qos_done()`, accounted in `RQF_STATS`, or logged on error in `blk_update_request()`. When dispatching via `q->mq_ops->queue_rq`, `blk_mq_commit_rqs()` must be called whenever the loop exits with leftover requests, `ret != BLK_STS_OK`, or on `hctx` switch in `blk_mq_issue_direct()`. [F327, F331, F425, F427]

## Known Pitfalls
- `I_BDEV()` and `BDEV_I()` may only be called on `blockdev_superblock` pseudo-inodes (`bdev_file->f_mapping->host`), never on VFS `/dev` special-file inodes (use `file_bdev(file)` or `blkdev_get_no_open()`). When embedding `struct bio` in an outer struct via `bioset_init()` with `front_pad`, `struct bio` must be the last member because inline `bio_vec`s are placed at `bio + 1`. Conversely, `bip` must be the first member of `struct bio_integrity_alloc`, and `struct blkg_policy_data` must be at offset 0 of a blkcg policy struct. [F144, F148, F152, F155]
- `blk_mq_rq_ctx_init()` reuses pre-allocated `struct request` instances from `tags->static_rqs[tag]` without `memset()`, so any new per-request field added to `struct request` must be explicitly initialized in both `blk_mq_rq_ctx_init()` and `blk_rq_init()`. In `blk_crypto_fallback_decrypt_endio()`, `f_ctx->bi_private_orig` and `f_ctx->bi_end_io_orig` must be read and restored to `bio` before initializing `f_ctx->work` and `f_ctx->bio` because they share an anonymous union. [F23, F362]
- In `blk_mq_get_hctx_type()`, `opf & REQ_POLLED` must be tested before `(opf & REQ_OP_MASK) == REQ_OP_READ`. `blk_account_io_done()` must test `(req->rq_flags & (RQF_IO_STAT | RQF_FLUSH_SEQ)) == RQF_IO_STAT`. In `wbt_should_throttle()`, `REQ_OP_WRITE` must test `(bio->bi_opf & (REQ_SYNC | REQ_IDLE)) == (REQ_SYNC | REQ_IDLE)`. In `xen-blkfront.c`, `info->rinfo` elements have runtime stride `info->rinfo_size` (trailing flexible array `shadow[]`) and must be accessed via `get_rinfo()` / `for_each_rinfo()`, never `info->rinfo[i]`. [F328, F329, F330, F698]
