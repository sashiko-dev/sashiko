# USB NETWORKING DRIVERS

This unit contains `usbnet`-based minidrivers (`aqc111`, `asix`, `ax88179_178a`, `ch9200`, `cx82310_eth`, `gl620a`, `huawei_cdc_ncm`, `int51x1`, `kalmia`, `lg-vl600`, `mcs7830`, `net1080`, `smsc95xx`, `sr9700`, `sr9800`, `zaurus`) and standalone USB network drivers (`catc`, `cdc-phonet`, `ipheth`, `kaweth`, `pegasus`) bridging the Linux networking stack with USB core URBs and pipes.

## Architecture & Data Flow
- Private structs overlaid onto `struct usbnet::data` (`unsigned long[5]`, 20 bytes on 32-bit)—`struct asix_data`, `struct mcs7830_data`, `struct sr_data`, and `struct huawei_cdc_ncm_state`—must not exceed `sizeof(dev->data)`. `huawei_cdc_ncm_state` must keep `struct cdc_ncm_ctx *ctx` at offset 0, and `sr_set_multicast()`/`sr_set_mac_address()` must use `sr_data`'s `multi_filter`/`mac_addr` buffers for async writes rather than stack memory. [F83, F125, F230]
- In `aqc111_rx_fixup()` and `ax88179_rx_fixup()`, `skb` must be trimmed to `desc_offset` (after checking `skb->len >= 8`, `start_of_descs == desc_offset`, and `pkt_count * 2 + desc_offset < skb_len`) or `hdr_off` (after checking `pkt_cnt * 4 + hdr_off <= skb->len`) and descriptor pointers set before `skb_pull()`. `aqc111` must verify `pkt_total_offset <= desc_offset` (equal on `pkt_count == 0`) and `pkt_len <= dev->hard_mtu + AQ_RX_HW_PAD`; `ax88179` must skip `pkt_len == 0` headers and verify `pkt_len_plus_padd <= skb->len` and `pkt_len >= 2 + ETH_HLEN`. [F76, F77, F78, F79, F129]
- In `smsc95xx_rx_fixup()`, `EVENT_NO_IP_ALIGN` and `HW_CFG_RXDOFF_` (`NET_IP_ALIGN << 9`) require pulling `4 + NET_IP_ALIGN` per frame and checking `size <= skb->len` and `size <= ETH_FRAME_LEN + 12`. If `RX_STS_ES_` is set, record stats and still pull `size` and `align_count` so remaining sub-frames are processed. When `NETIF_F_RXCSUM` is set, call `smsc95xx_rx_csum_offload()` before `skb_trim(..., len - 4)` strips the FCS. [F234, F255, F305, F309]
- In `sr9700_rx_fixup()`, signed `int len = (skb->data[1] | (skb->data[2] << 8)) - 4` must be checked for `len < 0`, `len > ETH_FRAME_LEN`, and `len > skb->len`. In `sr_rx_fixup()` (`sr9800`), verify `(header & 0x7ff) == ((~header >> 16) & 0x7ff)`, `size <= dev->net->mtu + ETH_HLEN + VLAN_HLEN`, `size + offset <= skb->len`, and advance `offset` by `(size + 1) & 0xfffe` to exact `skb->len`. In `cx82310_rx_fixup()`, reject `len > CX82310_MTU` before saving partial packets into `dev->partial_data` (`CX82310_MTU + 2`) and pull `(len + 1) & ~1` bytes. [F114, F132, F240, F243]
- `ax88179_status()` must not mark carrier on directly; it must defer to `ax88179_link_reset()` via `usbnet_link_change()`, which verifies `GMII_PHY_PHYSR_LINK`, updates `AX_RX_BULKIN_QCTRL` and `dev->rx_urb_size` in lockstep, and calls `netif_carrier_on()`. Because `ax88179_stop()` clears `AX_MEDIUM_RECEIVE_EN`, every `driver_info` must set `.reset = ax88179_net_reset`, which checks hardware `GMII_PHY_PHYSR` (running `ax88179_reset()` if 0, or setting `AX_MEDIUM_RECEIVE_EN`). [F59, F60, F140]
- In `smsc95xx.c`, `pdata->mac_cr` persists across calls: `smsc95xx_set_multicast()` must clear the other two mode bits among `MAC_CR_PRMS_`, `MAC_CR_MCPAS_`, and `MAC_CR_HPFILT_` in each branch and mask the `smsc95xx_hash()` shift exponent with `0x1F`, while `smsc95xx_mac_update_fullduplex()` must toggle `MAC_CR_FDPX_` and `MAC_CR_RCVOWN_` with opposite polarities. [F247, F248, F261]
- Any function in `ax88179_178a.c` or `asix_devices.c` that switches `GMII_PHY_PAGE_SELECT` (MII reg `0x1f`) must restore page 0 before returning. In `ax88772_init_phy()`, `priv->phydev_int` is only populated when `!priv->embd_phy` and remains `NULL` otherwise. [F44, F62]

## Synchronization
- Atomic/BH/IRQ callbacks must not sleep: `.ndo_set_rx_mode` must use `usbnet_write_cmd_async()` or `update_eth_regs_async()` (`kaweth_set_rx_mode()` only updates `packet_filter_bitmap`, and `kaweth_async_set_rx_mode()` returns early if `!may_sleep`). `driver_info->status` callbacks must defer via `usbnet_defer_kevent()`/`usbnet_link_change()`, `ipheth_sndbulk_callback()` via `schedule_delayed_work()`, and `cx82310_rx_fixup()`/`nc_ensure_sync()` via `schedule_work()`/`usbnet_write_cmd_async()`. [F156, F158, F159, F165, F167, F168]
- Multi-step indirect PHY, MDIO, and EEPROM accesses must hold `dev->phy_mutex`: `mcs7830_read_phy()`/`mcs7830_write_phy()` across command, ready-poll, and data read; `__asix_mdio_read()`/`__asix_mdio_write()` across `asix_check_host_enable(dev, in_pm)`, transfer, and `asix_set_hw_mii()`; `sr9800` `sr_mdio_read()`/`sr_mdio_write()` across `sr_set_sw_mii()`, transfer, and `sr_set_hw_mii()`; `sr9700` `sr_share_read_word()`/`sr_share_write_word()` across `SR_EPAR`/`SR_EPCR`, `wait_phy_eeprom_ready()`, and clearing `SR_EPCR = 0x0`; and `smsc95xx` MDIO/wait helpers. [F21, F137, F231, F287, F298]
- In `smsc95xx_bind()`, `dev->driver_priv = pdata` and `spin_lock_init(&pdata->mac_cr_lock)` must precede `smsc95xx_reset(dev)`, and `pdata->is_internal_phy`, `pdata->mdiobus`, and `pdata->phydev->irq` must be configured before `mdiobus_register()` and `phy_connect_direct()`. Runtime `pdata->mac_cr` updates must use `spin_lock_irqsave(&pdata->mac_cr_lock, flags)` and drop the lock before `smsc95xx_write_reg*()`. In `smsc95xx_status()`, `generic_handle_domain_irq()` requires `local_irq_save(flags)`. [F202, F206, F295, F297]
- In PM callbacks, `smsc95xx_suspend()`, `smsc95xx_resume()`, and `smsc95xx_reset_resume()` must set `pdata->pm_task = current` before register/PHY accesses and reset `pdata->pm_task = NULL` on all exit paths so `_nopm` USB helpers are used; `ax88179_suspend()` and `ax88179_resume()` must bracket device commands with `ax88179_set_pm_mode(dev, true)` and `false`. [F155, F209]
- In `cdc-phonet.c`, `rx_complete()` must hold `spin_lock_irqsave(&pnd->rx_lock, flags)` around `pnd->rx_skb`, copy the 1-byte header into linear SKB data via `skb_put_data()` before attaching the page at offset 1, and clear `pnd->rx_skb = NULL` only when `req->actual_length < PAGE_SIZE`. [F68, F162]

## Object Lifetimes
- In `asix_devices.c`, `ax88772_bind()` uses `devm_kzalloc()`, manually sets up `priv->mdio`, `priv->phylink`, PHY connection, and `pm_runtime_get_noresume(&intf->dev)` (never `devm_mdiobus_*` on `&dev->udev->dev`), and `ax88772_unbind()`/error paths tear them down in reverse order (`pm_runtime_put()`, `phylink_disconnect_phy()` under `rtnl_lock()`—which `phylink_suspend()`/`resume()` also require). `ax88178_bind()` uses `kzalloc()` without `phylink`/`mdio` and requires `ax88178_unbind`. [F1, F2, F46, F134, F152, F153]
- Multi-URB RX state must be cleared on handoff/error and freed on unbind: `asix_rx_fixup_internal()` clears `rx->ax_skb = NULL` on `usbnet_skb_return()`, calls `reset_asix_rx_fixup_info(rx)` on error, and frees it in `asix_rx_fixup_common_free()`; `vl600_rx_fixup()` clears `s->current_rx_buf = NULL` on `usbnet_skb_return()` (returning `0` on the final packet) or error, and `vl600_unbind()` frees it; `cx82310_unbind()` calls `cancel_work_sync(&priv->reenable_work)` before freeing `driver_priv` and `partial_data`. [F3, F4, F16, F108]
- In `smsc95xx.c`, `smsc95xx_bind()` error paths and `smsc95xx_unbind()` must unwind in reverse order: `phy_disconnect`, `mdiobus_unregister`, `mdiobus_free`, `irq_dispose_mapping`, `irq_domain_remove`, `irq_domain_free_fwnode`, `kfree(pdata)`. `smsc95xx_info` must pair `.reset = smsc95xx_reset` and `.check_connect = smsc95xx_start_phy` with `.stop = smsc95xx_stop`. In `smsc95xx_suspend()`, `filter_mask` must be freed on both `WUFF` write error and loop completion. [F192, F195, F198, F274]
- In `huawei_cdc_ncm_bind()`, validate `usb_cdc_wdm_register()` with `IS_ERR()` before assigning `drvstate->subdriver` and clear `usbnet_dev->status = NULL`; `huawei_cdc_ncm_unbind()` must call `drvstate->subdriver->disconnect(ctx->control)` before `cdc_ncm_unbind()`. In `zaurus.c`, any `driver_info` with `.bind = zaurus_bind` must set `.unbind = usbnet_cdc_unbind`. [F8, F45, F193]
- In `.tx_fixup` callbacks (`asix_tx_fixup`, `smsc95xx_tx_fixup`, `sr9700_tx_fixup`, `sr_tx_fixup`, `zaurus_tx_fixup`), unshare/expand `skb` before mutating it and call `dev_kfree_skb_any(skb)` whenever returning `NULL`. [F174, F308]

## API Contracts
- Direct callers of `usb_control_msg()` or `usb_bulk_msg()` (`__aqc111_write_cmd`, `ch9200` `control_read`/`control_write`, `cx82310_cmd`, `kalmia_init_and_get_ethernet_addr`, `catc_probe`) must pass heap-allocated buffers, never stack or rodata pointers. In `catc_ctrl_async()`, callers must pass persistent buffers `<= 64` bytes. When reinitializing coherent-buffer URBs in `ipheth` and `kaweth`, restore `URB_NO_TRANSFER_DMA_MAP` before `usb_submit_urb()`. In `.tx_fixup`/`.rx_fixup`, never pass `GFP_KERNEL`. [F127, F163, F169, F300]
- Minidrivers with `FLAG_MULTI_PACKET` (`aqc111`, `asix_devices`, `ax88172a`, `sr9800`) must pass every valid frame (including the final frame) to `usbnet_skb_return()` in `rx_fixup` and call `usbnet_set_skb_tx_stats()` in `tx_fixup`. Minidrivers without `FLAG_MULTI_PACKET` (`smsc95xx_rx_fixup`, `sr9700_rx_fixup`, `ax88179_rx_fixup`) allocate new SKBs via `netdev_alloc_skb_ip_align()` for non-final frames and trim/return the outer `skb` in-place on the final frame. Never use `skb_clone()` or overwrite `skb->truesize` on aggregated RX buffers. [F170, F173, F190, F191, F256, F302, F304]
- `usbnet` does not pre-check `skb->len >= dev->net->hard_header_len` before `rx_fixup` and does not set `dev->maxpacket` until after `driver_info->bind` returns (so `.bind` must never call helpers that divide/modulo by `dev->maxpacket` like `ax88178_change_mtu()` or `*_tx_fixup()`). [F95, F117]
- `smsc95xx_read/write_reg()` and `sr_read/write*()` return positive byte counts on success, so callers must check `ret < 0` and polling loops must not return positive `ret` as an errno; `ax88179_read/write_cmd*()` byte-swap `u16 *`/`u32 *` for `size == 2` or `4`; `asix_read_phy_addr()` returns signed `int` (check `< 0` before storing in unsigned `phy_addr` and set `phy_mask = ~(BIT(priv->phy_addr & 0x1f) | BIT(AX_EMBD_PHY_ADDR))` in `ax88772_init_mdio()`); `asix_rx_fixup_common*()` requires `struct asix_common_private *`. [F39, F116, F123, F126, F177, F212]

## Error Handling
- Synchronous USB read/write wrappers (`aqc111_read_cmd*`, `mcs7830_get_reg`, `ch9200` `control_read`, `smsc95xx_read_reg`, `sr_read*`, `sr_write*`) must treat non-negative short transfers (`0 <= ret < size`) as errors (`-ENODATA` or `-EINVAL`), and callers (including `ax88179_read_cmd()` with `size != 2 && size != 4`, and `usb_bulk_msg()` callers reading `act_len`/`actual_len` in `kalmia` and `cx82310`) must check for errors before reading uninitialized output buffers. In `aqc111_suspend()`, zero `struct aqc111_wol_cfg` with `memset()` before sending it. [F34, F36, F37, F38, F48, F49, F210]
- In `huawei_cdc_ncm_suspend()` and `smsc95xx_suspend()` (when `PMSG_IS_AUTO(message)`), roll back with `usbnet_resume(intf)` if device suspend fails after `usbnet_suspend()`; in `huawei_cdc_ncm_resume()`, roll back with `subdriver->suspend(intf, PMSG_SUSPEND)` if `usbnet_resume()` fails. Every `driver_info.bind` must check `usbnet_get_endpoints()`, and `smsc95xx_bind()` must set `ret` to a negative errno before `goto` cleanup after functions returning `0` or `4`. [F9, F213, F214, F278]

## External Contracts
- `smsc95xx_bind()` must only advertise `NETIF_F_IP_CSUM` (never `NETIF_F_IPV6_CSUM` or `NETIF_F_HW_CSUM`). In `smsc95xx_tx_fixup()`, hardware TX checksum offload pushes the 4-byte `csum_preamble` before `tx_cmd_a`/`tx_cmd_b` and adds 4 to both lengths; if `smsc95xx_can_tx_checksum()` is false (`skb->len <= 45` or checksum in the last 4 bytes), fold `csum_partial()` in software after `skb_cow_head()` and omit the preamble. `smsc95xx_handle_link_change()` must call both `smsc95xx_mac_update_fullduplex()` and `usbnet_defer_kevent(dev, EVENT_LINK_CHANGE)`. [F222, F236, F237, F306, F307]
- Any `ZAURUS_MASTER_INTERFACE` or `ZAURUS_FAKE_INTERFACE` device added to `drivers/net/usb/zaurus.c` must have a matching `.driver_info = 0` blacklist entry in `drivers/net/usb/cdc_ether.c`. [F292]

## Known Pitfalls
- In RX fixup loops, keep cursors synchronized on `continue`/allocation failure: in `aqc111_rx_fixup()`, every `continue` must call `skb_pull(skb, pkt_len_with_padd)` and `pkt_desc_ptr++`; in `ax88179_rx_fixup()`, `pkt_len == 0` dummy headers `continue` without pulling, whereas non-zero dropped packets must call `skb_pull(skb, pkt_len_plus_padd)`; in `asix_rx_fixup_internal()`, if `netdev_alloc_skb_ip_align()` returns `NULL`, still set `rx->remaining = size` and advance `offset` while guarding `rx->ax_skb`. [F42, F99, F100, F101]
- When shifting an uncloned SKB in `*_tx_fixup()`, use `memmove()` (not `memcpy()`) and call `skb_set_tail_pointer()`. In `smsc95xx_tx_fixup()`, call `skb_cow_head()` first and evaluate `tx_cmd_b`, `smsc95xx_can_tx_checksum()`, and `smsc95xx_calc_csum_preamble()` (truncating offsets to `u16`) before `skb_push()`. In `sr9700_tx_fixup()`, sample `len = skb->len` before `__skb_push(skb, SR_TX_OVERHEAD)`, but check `(skb->len % dev->maxpacket) == 0` after `__skb_push()`. [F128, F226, F228, F229, F265]
- Use `get_unaligned*()`/`put_unaligned*()` for multi-byte headers/trailers in `smsc95xx` and `sr9800` SKB/URB buffers; in `aqc111_tx_fixup()`, cast `AQ_TX_DESC_MSS_MASK` and `AQ_TX_DESC_VLAN_MASK` values to `u64` before shifting by `0x20`/`0x30`; in `smsc95xx_enter_suspend*()`, clear `PM_CTL_SUS_MODE_ | PM_CTL_WUPS_ | PM_CTL_PHY_RST_` when modifying `PM_CTRL`. [F115, F283, F301]
