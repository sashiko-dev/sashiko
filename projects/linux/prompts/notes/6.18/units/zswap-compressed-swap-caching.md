# ZSWAP COMPRESSED SWAP CACHING

Zswap is a RAM-based compressed cache for swap pages in the Linux memory management subsystem. It intercepts folios being swapped out, compresses their pages via the crypto acomp API into zsmalloc memory pools indexed by swap-offset XArrays, and decompresses them on swap-in. Under memory pressure or pool limits, a memcg-aware shrinker and background worker evict cold compressed entries back to the underlying swap device.

## Architecture & Data Flow
- When `zswap_store()` returns `false` for any reason (including `zswap_enabled == false`, cgroup/pool limit rejection, or mid-folio `zswap_store_page()` failure), the `check_old:` loop must iterate from `index = 0` to `nr_pages - 1` and `xa_erase()` plus `zswap_entry_free()` any entry at `offset + index`. Broken by: returning `false` before `check_old:` or only erasing up to the failed `index`. [F71]
- `zswap_store_page()` must acquire per-entry `pool` and `objcg` references, charge `objcg` via `obj_cgroup_charge_zswap()`, increment `zswap_stored_pages`, and call `zswap_lru_add()` only after `xa_store()` succeeds, freeing any overwritten entry with `zswap_entry_free()`. Broken by: batching charges/counters after the per-page loop in `zswap_store()` or charging before `xa_store()`. [F2]
- In `zswap_load()`, if `folio_test_swapcache(folio)` is true, the entry must be erased from the XArray and freed via `zswap_entry_free()` with `folio_mark_dirty(folio)`; for non-swapcache faults (`SWP_SYNCHRONOUS_IO`), the entry must remain in zswap. [F47]
- `struct zswap_entry::objcg` is nullable (when `get_obj_cgroup_from_folio()` returns `NULL`), so every path accessing `entry->objcg`—including `mem_cgroup_from_entry()`, `zswap_entry_free()`, `zswap_writeback_entry()`, `zswap_store_page()`, and `zswap_load()`—must check `entry->objcg` is non-NULL before calling `obj_cgroup_*` helpers. [F36]
- Whenever `zswap_store()` fails (`!ret`) while `zswap_pool_reached_full` is true, it must queue `zswap_shrink_work`, and `shrink_worker()` must loop until `zswap_total_pages() <= zswap_accept_thr_pages()` (or `failures == MAX_RECLAIM_RETRIES`). Broken by: queuing work only when `cur_pages >= max_pages` or shrinking only one page/memcg per run. [F69]
- Every stored `zswap_entry` has `0 < entry->length <= PAGE_SIZE`, where `entry->length == PAGE_SIZE` indicates an uncompressed page. In `zswap_compress()`, a page that fails to compress below `PAGE_SIZE` (`comp_ret || !dlen || dlen >= PAGE_SIZE`) may be stored uncompressed (`dlen = PAGE_SIZE`) only if `mem_cgroup_zswap_writeback_enabled(folio_memcg(page_folio(page)))` is true, and `zswap_decompress()` must copy `PAGE_SIZE` entries directly without `crypto_acomp_decompress()`. [F59, F104]
- Each per-CPU `acomp_ctx->buffer` is allocated with a fixed size of `PAGE_SIZE` bytes in `zswap_cpu_comp_prepare()`, so `zswap_compress()` and `zswap_decompress()` must bound any read, write, or `memcpy` involving `acomp_ctx->buffer` to at most `PAGE_SIZE` bytes. [F79]
- Once a pool is created in `zswap_setup()`, `static_branch_enable(&zswap_ever_enabled)` must be called so `zswap_never_enabled()` remains `false` even if `zswap_enabled` is later disabled, preventing unsupported large-folio swap-ins. When `zswap_setup()` fails, it must set `zswap_enabled = false` (leaving `zswap_has_pool` false or setting `zswap_init_state = ZSWAP_INIT_FAILED`), and `zswap_enabled_param_set()` must reject enabling unless `zswap_init_state == ZSWAP_INIT_SUCCEED` and `zswap_has_pool` is true. [F53, F95]
- Global synchronization primitives and counters accessed by external MM hooks when zswap is disabled or uninitialized—such as `zswap_shrink_lock` in `zswap_memcg_offline_cleanup()` and `zswap_stored_pages`—must be statically initialized at compile time rather than in `zswap_setup()`. [F26]
- `zswap_swapon()` must compute the XArray count `nr` using `DIV_ROUND_UP(nr_pages, ZSWAP_ADDRESS_SPACE_PAGES)` so every swap offset up to `nr_pages - 1` maps to an allocated `struct xarray` when `swap_zswap_tree()` indexes `zswap_trees[type]` by `swp_offset(swp) >> ZSWAP_ADDRESS_SPACE_SHIFT`. [F74]
- `zswap_pool_create()` must generate a unique pool name for `zs_create_pool()` using `atomic_inc_return(&zswap_pools_count)` so a new `zswap_pool` does not collide with an older pool still draining in `zswap_pools`. [F52]

## Synchronization
- In `zswap_writeback_entry()`, `entry` must not be dereferenced until `get_swap_device()` and `__read_swap_cache_async()` have newly allocated and locked the swapcache folio (`folio_was_allocated` is true) and `xa_load(swap_zswap_tree(swpentry), offset)` equals `entry`. [F21]
- Before `shrink_memcg_cb()` unlocks `l->lock` to call `zswap_writeback_entry()`, it must rotate `item` to the tail of `l->list` (`list_move_tail()`) and copy `entry->swpentry` to the stack, and it must return `LRU_REMOVED_RETRY`, `LRU_RETRY`, or `LRU_STOP` (never `LRU_ROTATE` or `LRU_SKIP`). [F65]
- `acomp_ctx_get_cpu_lock()` must recheck that `acomp_ctx->req` is non-NULL after locking `acomp_ctx->mutex` and, if `NULL`, unlock and re-fetch `raw_cpu_ptr(pool->acomp_ctx)` because the task may have migrated while `zswap_cpu_comp_dead()` offlined the old CPU. [F49]
- In `zswap_cpu_comp_prepare()`, all `GFP_KERNEL` allocations (`kmalloc_node()`, `crypto_alloc_acomp_node()`, `acomp_request_alloc()`) must complete before acquiring `acomp_ctx->mutex`, because direct reclaim can enter `zswap_compress()` and deadlock on `acomp_ctx->mutex`. In `zswap_cpu_comp_dead()`, `acomp_ctx->req`, `acomp`, and `buffer` must be saved to locals and set to `NULL` under `acomp_ctx->mutex`, and freed via `acomp_request_free()`, `crypto_free_acomp()`, and `kfree()` only after unlocking. [F16, F83]
- In `zswap_compress()`, `zs_malloc()` is called while holding `acomp_ctx->mutex` (and potentially with an active `kmap_local_page()` mapping) and must use `GFP_NOWAIT | __GFP_NORETRY | __GFP_HIGHMEM | __GFP_MOVABLE` without sleeping or triggering reclaim. [F91]
- In `zswap_pool_create()`, `pool->tfm_name`, `pool->acomp_ctx`, and every possible CPU's `acomp_ctx->mutex` must be initialized before registering the pool with `cpuhp_state_add_instance(CPUHP_MM_ZSWP_POOL_PREPARE, &pool->node)`. [F14]
- All modifications to `zswap_pools` must use RCU list primitives under `spin_lock_bh(&zswap_pools_lock)`, and lockless readers (`zswap_pool_current_get()`, `zswap_pool_find_get()`) must hold `rcu_read_lock()` and pin any pool for use outside RCU via `zswap_pool_tryget()`. In `zswap_compressor_param_set()`, `zswap_pools_lock` must be released before calling sleeping functions (`zswap_pool_create()`, `param_set_charp()`, or `percpu_ref_kill()`). [F19, F82]
- `__zswap_pool_empty()` runs in atomic/softirq context as a `percpu_ref` release callback, so it must unlink `pool->list` via `list_del_rcu()` under `spin_lock_bh(&zswap_pools_lock)` and defer `synchronize_rcu()`, `percpu_ref_exit()`, and `zswap_pool_destroy()` to process context via `schedule_work(&pool->release_work)` (`__zswap_pool_release()`). [F18, F80]
- `mem_cgroup_from_entry()` and the subsequent `list_lru_add()` or `list_lru_del()` call in `zswap_lru_add()` and `zswap_lru_del()` must execute within an `rcu_read_lock()` critical section to safely resolve `obj_cgroup_memcg(entry->objcg)` against concurrent memcg offlining and LRU reparenting. [F89]
- Runtime inspection and transitions of `zswap_init_state` and lazy invocation of `zswap_setup()` in `zswap_enabled_param_set()` and `zswap_compressor_param_set()` must be serialized under `zswap_init_lock`. [F25]

## Object Lifetimes
- In `zswap_entry_free()`, `zswap_lru_del()` must be called before `obj_cgroup_put(entry->objcg)` and `zswap_entry_cache_free(entry)`, and `zs_free(entry->pool->zs_pool, entry->handle)` must be called before `zswap_pool_put(entry->pool)`. [F1]
- Because `zswap_entry_cache` is created with `KMEM_CACHE(zswap_entry, 0)` without zeroing, `zswap_store_page()` must explicitly initialize every `struct zswap_entry` field before adding `entry` to `zswap_list_lru`, and error paths before initialization must call `zswap_entry_cache_free()` rather than `zswap_entry_free()`. [F38]
- In `zswap_writeback_entry()`, every exit path after `__read_swap_cache_async()` returns a non-NULL `folio` must call `folio_put(folio)`, and error paths where `folio_was_allocated` is true (`ret != 0 && ret != -EEXIST`) must also call `swap_cache_del_folio(folio)` and `folio_unlock(folio)`. Broken by: omitting cleanup on error or unlocking `folio` when `!folio_was_allocated`. [F4]
- Whenever `zswap_next_shrink` is updated under `zswap_shrink_lock` in `shrink_worker()` or `zswap_memcg_offline_cleanup()`, `mem_cgroup_iter()` must loop until `zswap_next_shrink` is `NULL` or online, and `shrink_worker()` must take an extra reference with `mem_cgroup_tryget_online()` and drop it with `mem_cgroup_put()` after `shrink_memcg()`. [F9]
- In `zswap_compressor_param_set()`, reusing an existing pool from `zswap_pool_find_get()` requires calling `percpu_ref_resurrect(&pool->ref)` and `zswap_pool_put(pool)`. When `param_set_charp()` succeeds (`!ret`), `put_pool` must capture the old `zswap_pool_current()` before `list_add_rcu(&pool->list, &zswap_pools)`; when `ret != 0` and `pool != NULL`, `pool` must be re-linked at the tail via `list_add_tail_rcu(&pool->list, &zswap_pools)` and assigned to `put_pool` before calling `percpu_ref_kill(&put_pool->ref)`. [F11, F72]
- `zswap_compress()` and `zswap_decompress()` attach stack-allocated `struct scatterlist` variables to the persistent per-CPU `acomp_ctx->req` via `acomp_request_set_params()`, so the request must complete via `crypto_wait_req()` before returning. [F78]

## API Contracts
- Callers of `zswap_store()`, `zswap_load()`, and `zswap_folio_swapin()` must hold the folio lock on `folio`, and `zswap_store()` additionally requires `folio_test_swapcache(folio)`. `zswap_load()` only supports order-0 folios and must reject `folio_test_large(folio)` by unlocking `folio` and returning `-EINVAL`. [F24, F60]
- `swap_zswap_tree(swp)` selects the XArray chunk via `swp_offset(swp) >> ZSWAP_ADDRESS_SPACE_SHIFT`, while XArray operations (`xa_load()`, `xa_store()`, `xa_erase()`) on that tree must pass the unshifted `swp_offset(swp)` as the index, and multi-page folio loops must re-evaluate `swap_zswap_tree()` for each page's `offset + index`. [F42]
- `zswap_store()` must obtain the `obj_cgroup` from the folio via `get_obj_cgroup_from_folio(folio)` (never `current`) and store it on `entry->objcg` for charges, `list_lru`, and VM events, and must preallocate the per-memcg `list_lru` via `memcg_list_lru_alloc(memcg, &zswap_list_lru, GFP_KERNEL)` before calling `zswap_store_page()`. [F99, F102]
- `obj_cgroup_charge_zswap()` and `obj_cgroup_uncharge_zswap()` take byte sizes (`entry->length`), whereas `zswap_shrinker_count()` must convert `memcg_page_state(memcg, MEMCG_ZSWAP_B)` from bytes to pages via `>> PAGE_SHIFT` to match the page units of `MEMCG_ZSWAPPED` and `nr_freeable` in `mult_frac()`. [F40]
- In `zswap_decompress()`, if `zs_obj_read_begin()` returns a pointer failing `virt_addr_valid(obj)` (highmem kmap address), the compressed data must be copied into `acomp_ctx->buffer` before passing it to `sg_init_one()`, and `zs_obj_read_end()` must be called on all paths including the uncompressed `entry->length == PAGE_SIZE` path. [F103]
- `zswap_shrinker_scan()` must return `SHRINK_STOP` (never `0`) whenever shrinking is disabled, aborted due to `encountered_page_in_swapcache`, or `list_lru_shrink_walk()` reclaims zero objects (`!shrink_ret`). `shrink_memcg_cb()` must check that its `void *arg` (`encountered_page_in_swapcache`) is non-NULL before dereferencing it or returning `LRU_STOP` on `-EEXIST`, because `shrink_memcg()` passes `NULL`. [F32, F34]
- `zswap_shrinker_count()` must return `0` when `!gfp_has_io_fs(sc->gfp_mask)`, and must guard `mem_cgroup_flush_stats(sc->memcg)` and `memcg_page_state(sc->memcg, ...)` with `!mem_cgroup_disabled()`. [F101]
- Because `module_param_cb(compressor, ...)` registers `&zswap_compressor` (`char **`) as `kp->arg`, `zswap_compressor_param_set()` must dereference `*(char **)kp->arg` to read the current compressor name, strip whitespace from user input with `strstrip()`, and (when `zswap_init_state == ZSWAP_INIT_SUCCEED`) validate it with `crypto_has_acomp()` before looking up or creating a `zswap_pool` (whose `tfm_name` is bounded to `CRYPTO_MAX_ALG_NAME` via `strscpy()`). [F62, F77]
- `zswap_init()` must be registered with `late_initcall()`, and `zswap_enabled_param_set()` must return `param_set_bool(val, kp)` immediately without calling `zswap_setup()` when `system_state != SYSTEM_RUNNING`. [F105]

## Error Handling
- In `zswap_store_page()`, the return value `old` from `xa_store()` must be checked with `xa_is_err(old)` before testing `if (old)` and calling `zswap_entry_free(old)`. [F29]
- In `zswap_compress()`, `zs_malloc()` encodes allocation failures as error values in the returned `unsigned long` handle rather than `0`, so callers must check `IS_ERR_VALUE(handle)` and extract the errno via `PTR_ERR((void *)handle)`. In the `unlock:` accounting chain, `comp_ret == -ENOSPC || alloc_ret == -ENOSPC` must be tested before the general `else if (comp_ret)` and `else if (alloc_ret)` branches so `-ENOSPC` increments `zswap_reject_compress_poor`. [F28, F63]
- In `zswap_decompress()`, for compressed entries (`entry->length < PAGE_SIZE`), `acomp_request_set_params()` must pass `entry->length` as `slen` and `PAGE_SIZE` as `dlen`, and decompression succeeds only if both `crypto_wait_req()` returns `0` and `acomp_ctx->req->dlen == PAGE_SIZE`. Failures must be logged with `pr_alert_ratelimited()` and counted in `zswap_decompress_fail` without `WARN_ON`/`BUG_ON`. [F41, F106]
- `shrink_memcg()` must return `-ENOENT` when writeback is disabled, `memcg` is offline, or `scanned == 0` (and `-EAGAIN` only when `scanned > 0` and `shrunk == 0`), and `shrink_worker()` must `continue` on `-ENOENT` without incrementing `attempts` or `failures` and reset `attempts = 0` at each `!memcg` tree-walk boundary. [F68]
- In `zswap_cpu_comp_prepare()`, callers of `crypto_alloc_acomp_node()` must check `IS_ERR(acomp)` (not `IS_ERR_OR_NULL()` or `!acomp`) before calling `PTR_ERR(acomp)`, because `crypto_alloc_acomp_node()` returns an `ERR_PTR` and never `NULL`. [F27]

## External Contracts
- `zswap_load()` must leave `folio` locked without changing its uptodate state when returning `-ENOENT`, must mark `folio` uptodate and unlock it when returning `0`, and must unlock `folio` without marking it uptodate when returning `-EIO` or `-EINVAL` so swap-in callers emit an IO error instead of reading stale disk data. [F30]
- In `include/linux/zswap.h`, the `!CONFIG_ZSWAP` stub for `zswap_never_enabled()` must return `true` (while `zswap_is_enabled()` returns `false`), matching the runtime state when zswap has never been enabled. [F56]

## Known Pitfalls
- In `zswap_shrinker_count()`, `nr_stored` must be checked for zero before calling `mult_frac(nr_freeable, nr_backing, nr_stored)` even when `nr_freeable` is non-zero (since `MEMCG_ZSWAPPED` or `zswap_stored_pages` can read as zero and `mult_frac()` divides by its third argument), and `mult_frac()` must be used instead of `(nr_freeable * nr_backing) / nr_stored` to avoid `unsigned long` overflow. [F73, F75]
- In `zswap_shrinker_count()`, subtracting `nr_disk_swapins` from unsigned `nr_freeable` must clamp `nr_remain` to `0` when `nr_freeable >= nr_disk_swapins_cur` and subtract `nr_disk_swapins_cur - nr_remain` so `nr_freeable` never underflows. [F61]
