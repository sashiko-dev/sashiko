# GPIO UAPI

This component implements the Linux GPIO character device userspace ABI (v2 and deprecated v1) in `drivers/gpio/gpiolib-cdev.c` and `include/uapi/linux/gpio.h`, along with utilities in `tools/gpio/`. It exposes `/dev/gpiochipN` devices and anonymous inode file descriptors (`gpio-line`, `gpio-linehandle`, `gpio-event`) to inspect chip/line metadata, watch line state changes, request and configure lines, read/write line values, and monitor hardware or software-debounced edge events.

## Architecture & Data Flow

- In `linereq_get_values()` and `linereq_set_values()`, sparse `__aligned_u64` UAPI bitmasks (`lv.mask`, `lv.bits`) must be tested/set with `BIT_ULL()` (never cast to `unsigned long *`) and compacted into dense `0..num_get-1` (`num_set-1`) `descs` and `vals` bitmap arrays for `gpiod_get/set_array_value_complex()`. `linereq_get_values()` must zero `lv.bits` and increment `didx` for every line in `lv.mask` even when `sw_debounced` is true; `linereq_set_values()` must zero `vals` and call `__set_bit(num_set, vals)` before `num_set++`. [F64, F80, F81, F93]
- `gpio_v2_line_config_flags_to_desc_flags()` and `linehandle_flags_to_desc_flags()` must stage updates to `desc->flags` in a local `unsigned long` initialized via `READ_ONCE(*flagsp)` and publish them with a single `WRITE_ONCE(*flagsp, flags)` (paired with `READ_ONCE(desc->flags)` in `gpio_desc_to_lineinfo()`), using `assign_bit()`/`set_bit()`/`clear_bit()` to preserve non-config bits like `GPIOD_FLAG_REQUESTED`. `GPIOD_FLAG_IS_OUT` must only be modified when `GPIO_V2_LINE_FLAG_OUTPUT` or `GPIO_V2_LINE_FLAG_INPUT` is set (`if ... set_bit else if ... clear_bit`). [F25, F53, F77]
- In `linereq_set_config()`, `line->edflags` must only be updated to the new `edflags` after `edge_detector_stop()` or `edge_detector_update()` finishes, because both read the previously active `line->edflags` to detect changes and release `line->hdesc` when `GPIO_V2_LINE_FLAG_EVENT_CLOCK_HTE` was active. [F50]
- `edge_detector_stop()` must reset `line->irq`, `line->sw_debounced`, `line->edflags`, and `line->desc->debounce_period_us` to 0 (and release `line->hdesc` if `GPIO_V2_LINE_FLAG_EVENT_CLOCK_HTE` was set), but must not clear `line->level` because `linereq_get_values()` reads `line->sw_debounced` and calls `debounced_value()` without holding `lr->config_mutex`. [F18, F46]
- `line->level` and `line->raw_level` store physical (raw) pin levels from `gpiod_get_raw_value_cansleep()` or HTE; `process_hw_ts_thread()`, `debounce_work_func()`, and `debounced_value()` must invert the level when `ACTIVE_LOW` is set before computing `line_event_id()` or returning the logical value. For software-debounced HTE lines, `process_hw_ts()` increments `line->total_discard_seq` and saves `line->last_seqno = ts->seq`, and `debounce_work_func()` decrements `line->total_discard_seq` by 1 and sets `line->line_seqno = line->last_seqno - line->total_discard_seq`. [F89, F112]
- In `linereq_create()`, `linereq_set_config()`, `linehandle_create()`, `linehandle_set_config()`, and `debounce_setup()`, direction and debounce setup must use `gpiod_direction_output_nonotify()`, `gpiod_direction_input_nonotify()`, and `gpio_do_set_config()` so `gpiod_line_state_notify()` is emitted once. `debounce_setup()` must fall back to software debounce only when `gpio_do_set_config()` returns `-ENOTSUPP` and `debounce_period_us` is non-zero, propagating any other error immediately. [F56, F110]
- In `linereq_create()`, `lr->num_lines` must be set to `ulr.num_lines` before indexing `lr->lines` (`__counted_by(num_lines)`), and `lr->event_buffer_size` must default to `ulr.num_lines * 16` when 0 and be capped at `GPIO_V2_LINES_MAX * 16`. In `linereq_create()`, `linehandle_create()`, and `lineevent_create()`, consumer strings must be copied with `kstrndup(str, sizeof(str) - 1, GFP_KERNEL)` only when `str[0] != '\0'`. [F69, F70, F90]

## Synchronization

- Every `file_operations` `open`, `unlocked_ioctl`, `read`, and `poll` handler in `gpiolib-cdev.c` must hold `gdev->srcu` and verify `rcu_access_pointer(gdev->chip)` is non-NULL before accessing the `gpio_chip`, returning `-ENODEV` (or `EPOLLHUP | EPOLLERR` in `poll`) when NULL. Inside `gdev->srcu`, non-NULL checks use `rcu_access_pointer(gdev->chip)`, while dereferences (`lineinfo_changed_func()`, `gpiolib_cdev_register()`) must use `srcu_dereference(gdev->chip, &gdev->srcu)`. [F109, F120]
- In `gpio_desc_to_lineinfo()`, `desc->gdev->desc_srcu` must be held across `gpiod_get_label(desc)` and `strscpy(info->consumer, label, ...)` while `CLASS(gpio_chip_guard, guard)(desc)` holds `desc->gdev->srcu`. [F24]
- In `linereq_set_config()` and `linereq_set_values()`, `lr->config_mutex` must be held across descriptor flag updates, direction changes, edge detector reconfiguration, and output value writes. [F21]
- Registration and unregistration of `cdev->lineinfo_changed_nb` on `gdev->line_state_notifier` in `gpio_chrdev_open()` and `gpio_chrdev_release()` must be serialized by `write_lock_irqsave(&gdev->line_state_lock)`. `lineinfo_changed_notify()` runs in atomic context under `read_lock_irqsave(&desc->gdev->line_state_lock)`, so it must allocate `struct lineinfo_changed_ctx` with `GFP_ATOMIC` and pass `atomic = true` to `gpio_desc_to_lineinfo()` to defer sleeping `pinctrl_gpio_can_use_line()` calls to `lineinfo_changed_func()`. [F12, F113]
- `lr->wait.lock` and `le->wait.lock` are acquired without disabling IRQs in `linereq_put_event()`, `linereq_read()`, `linereq_poll()`, `lineevent_irq_thread()`, and `lineevent_poll()`, so hardirq/HTE callbacks (`edge_irq_handler()`, `debounce_irq_handler()`, `lineevent_irq_handler()`, `process_hw_ts()`) must never lock `wait.lock` or push events directly. [F115]
- `edge_irq_thread()` and `lineevent_irq_thread()` must handle `line->timestamp_ns == 0` (and `le->timestamp == 0`) by capturing the timestamp and incrementing `lr->seqno` in the thread handler, and `edge_irq_thread()` must reset `line->timestamp_ns = 0` after consuming it. [F116]
- In `linereq_read()`, `lineevent_read()`, and `lineinfo_watch_read()`, `wait.lock` must be held continuously across `kfifo_is_empty()`, `wait_event_interruptible_locked()`, and `kfifo_out()`, and dropped before `copy_to_user()`. Under `CONFIG_GPIO_CDEV_V1`, `lineinfo_watch_read()` must read `cdev->watch_abi_version` and validate `count < event_size` only after verifying `cdev->events` is non-empty, because `watch_abi_version` is lazily initialized by `lineinfo_ensure_abi_version()`. [F22, F23]

## Object Lifetimes

- Once `anon_inode_getfile()` succeeds in `linehandle_create()`, `linereq_create()`, or `lineevent_create()`, ownership of `lh`, `lr`, or `le` transfers to `file->private_data`; a `copy_to_user()` failure must clean up via `fput(file)` and `put_unused_fd(fd)` without calling `linehandle_free()`, `linereq_free()`, or `lineevent_free()`. `linereq_free()` must deallocate `lr` with `kvfree(lr)` rather than `kfree(lr)` to match `kvzalloc()`. [F1, F91]
- Every `request_irq()` or `request_threaded_irq()` call in `debounce_setup()`, `edge_detector_setup()`, and `lineevent_create()` must pass a dedicated label from `make_irq_label()` (never borrowing `line->req->label` or `le->label`), call `free_irq_label(label)` if IRQ registration fails, and assign `line->irq` or `le->irq` only after IRQ registration succeeds (with `edge_detector_stop()` resetting `line->irq = 0` after `free_irq()`). [F2, F3]
- `edge_detector_stop()` must release the IRQ (`free_irq()`) and HTE descriptor (`hte_ts_put()`) before `cancel_delayed_work_sync(&line->work)`, and `linereq_free()` / `lineevent_free()` must stop edge detection / free the IRQ before calling `gpiod_free()`, `kfifo_free()`, and `kfree(label)`. [F5]
- In `edge_detector_setup()` and `edge_detector_update()`, when `edflags & GPIO_V2_LINE_EDGE_FLAGS` is non-zero, `edge_detector_fifo_init(line->req)` must allocate `lr->events` before `debounce_setup()`, `hte_edge_setup()`, or `request_threaded_irq()` enables event callbacks or `edflags` is published. [F19]
- `linereq_get_values()` and `linereq_set_values()` borrow `&lr->lines[i].desc` for `descs` when `num_get == 1` or `num_set == 1` and only call `kmalloc_array()` when the count is `> 1`, so `kfree(descs)` on all exit paths must be guarded by `num_get != 1` / `num_set != 1`. [F6]
- `lineinfo_changed_notify()` must take references to both `desc->gdev` (`gpio_device_get()`) and `cdev->fp` (`get_file()`) before queueing `ctx->work` onto `gdev->line_state_wq`, and `lineinfo_changed_func()` must release them via `gpio_device_put(ctx->gdev)` and `fput(ctx->cdev->fp)` after all accesses to `ctx->gdev` and `ctx->cdev`. [F7]
- In `gpio_chrdev_release()` and `gpio_chrdev_open()` error paths, `cdev->device_unregistered_nb` and `cdev->lineinfo_changed_nb` must be unregistered before freeing `cdev->watched_lines`, dropping `gdev`, or freeing `cdev`. In `gpiolib_cdev_register()`, `gdev->line_state_wq` must be allocated before `cdev_device_add()`, and `gpiolib_cdev_unregister()` must call `destroy_workqueue(gdev->line_state_wq)` before `cdev_device_del()` and `blocking_notifier_call_chain(&gdev->device_notifier, 0, NULL)`. [F13, F101]
- When `watch` is true in `lineinfo_get()` or `lineinfo_get_v1()`, `lineinfo_ensure_abi_version()` must succeed before `test_and_set_bit()` marks the offset in `cdev->watched_lines`, and a subsequent `copy_to_user()` failure must roll back the bit with `clear_bit()`. [F8]

## API Contracts

- In `linereq_set_config()`, any line whose resolved flags do not set `GPIO_V2_LINE_DIRECTION_FLAGS` must be skipped via `continue` before modifying `desc->flags`, stopping/updating the edge detector, or changing direction. Similarly, `linehandle_set_config()` must verify `gcnf.flags & GPIOHANDLE_REQUEST_DIRECTION_FLAGS` before `linehandle_flags_to_desc_flags()` modifies `desc->flags` on any line. [F49, F76]
- `linehandle_flags_to_desc_flags()` and `gpio_v2_line_config_flags_to_desc_flags()` must update `desc->flags` before calling `gpiod_direction_output_nonotify()`, `gpiod_direction_input_nonotify()`, `gpiod_direction_input()`, or `edge_detector_setup()` / `edge_detector_update()`. In `linereq_set_config()`, when reconfiguring a line to `GPIO_V2_LINE_FLAG_OUTPUT`, `edge_detector_stop(line)` must be called before `gpiod_direction_output_nonotify(desc, val)`. [F104, F105]
- When configuring edge triggers in `edge_detector_setup()`, `hte_edge_setup()`, and `lineevent_create()`, logical rising and falling edge flags must be inverted to falling and rising hardware triggers respectively whenever `GPIOD_FLAG_ACTIVE_LOW` is set in `desc->flags`. [F111]
- In `struct gpio_v2_line_values` and `struct gpio_v2_line_config_attribute`, bit `i` of `mask`, `bits`, and `attr.values` indexes `lr->lines[i]` (`0 <= i < lr->num_lines`), whereas `gpio_v2_line_event.offset` and `gpio_v2_line_info.offset` store the chip-local hardware offset `gpio_chip_hwgpio(desc)`. [F63]
- In the `do-while` loops of `linereq_read()`, `lineevent_read()`, and `lineinfo_watch_read()`, when `kfifo_is_empty()` is true, `if (bytes_read) return bytes_read;` must be checked before returning `-EAGAIN` for `O_NONBLOCK` or sleeping in `wait_event_interruptible_locked()`. [F82]

## Error Handling

- In `linereq_create()`, `linehandle_create()`, and `lineevent_create()`, `gpio_device_get_desc()` returns an `ERR_PTR` that must be checked with `IS_ERR(desc)`, and `desc` must not be stored into `lr->lines[i].desc`, `lh->descs[i]`, or `le->desc` until `gpiod_request_user()` succeeds. Because `lr->num_lines` and `lh->num_descs` are set before requesting all descriptors, `linereq_free()`, `edge_detector_stop()`, and `linehandle_free()` must check that each `desc` pointer is non-NULL before dereferencing it or passing it to `gpiod_free()`. [F29, F30]
- `make_irq_label()` returns `NULL` when `orig` is `NULL` (unlabeled consumer) and `ERR_PTR(-ENOMEM)` on allocation failure; callers (`debounce_setup`, `edge_detector_setup`, `lineevent_create`) must check `IS_ERR(label)` rather than `!label`. `gpiod_get_raw_value_cansleep()` and `gpiod_get_value_cansleep()` return `0`, `1`, or negative errno; callers must store the result in a signed `int` and check `< 0` before storing into `line->level` (`unsigned int`) or `ghd.values[0]` (`__u8`). [F28, F31]

## External Contracts

- Userspace hardware line offsets must be validated against `gdev->ngpio` before indexing `gdev->descs` or `cdev->watched_lines`: `linereq_create()`, `linehandle_create()`, `lineevent_create()`, `lineinfo_get()`, and `lineinfo_get_v1()` must resolve descriptors via `gpio_device_get_desc()` (which uses `array_index_nospec()`), and `lineinfo_unwatch()` must check `offset >= cdev->gdev->ngpio` before accessing `cdev->watched_lines`. [F94, F127]
- `linereq_create()` and `linehandle_create()` must reject `num_lines == 0 || num_lines > GPIO_V2_LINES_MAX` (`GPIOHANDLES_MAX`) with `-EINVAL` before validating config, allocating `struct linereq`, or indexing `ulr.offsets` / `handlereq.lineoffsets`. `gpio_v2_line_config_validate()` must verify `lc->num_attrs <= GPIO_V2_LINE_NUM_ATTRS_MAX` before calling `gpio_v2_line_config_flags()` or `gpio_v2_line_config_debounced()`. [F59, F60]
- In `struct gpio_v2_line_attribute`, the union of `flags`, `values`, and `debounce_period_us` is discriminated by `id`; `gpio_v2_line_config_*()` attribute helpers must scan `lc->attrs` from `0` to `lc->num_attrs - 1`, verify both `lc->attrs[i].attr.id` and `lc->attrs[i].mask & BIT_ULL(line_idx)`, and return on the first match. [F37, F79]
- Stack-allocated UAPI output and event structures (`gpio_v2_line_event`, `gpioevent_data`, `gpioline_info_changed`, `gpio_v2_line_info`, `gpiochip_info`, `gpiohandle_data`) must be zeroed with `memset()` before field assignment and `copy_to_user()` or `kfifo` insertion. Conversely, ABI v2 input handlers (`gpio_v2_line_config_validate()`, `linereq_create()`, `lineinfo_get()`) must verify `mem_is_zero(padding, sizeof(padding))` and return `-EINVAL` if any byte is non-zero. [F41, F125]
- In `lineevent_read()`, when `compat_need_64bit_alignment_fixup()` is true, `ge_size` must be `sizeof(struct compat_gpioeevent_data)` (12 bytes) rather than `sizeof(struct gpioevent_data)` (16 bytes) for `count < ge_size`, `copy_to_user()`, and `count >= bytes_read + ge_size`. Under `CONFIG_GPIO_CDEV_V1`, `lineinfo_watch_read()` must convert `cdev->events` entries via `gpio_v2_line_info_changed_to_v1()` and size/copy `struct gpioline_info_changed` whenever `cdev->watch_abi_version != 2`. [F66, F98]
- `linereq_create()`, `linehandle_create()`, and `lineevent_create()` must acquire lines via `gpiod_request_user()` rather than `gpiod_request()` so internal `-EPROBE_DEFER` errors map to `-ENODEV`. [F124]

## Known Pitfalls

- In `lineevent_irq_thread()`, the dual-edge condition `(le->eflags & GPIOEVENT_REQUEST_RISING_EDGE && le->eflags & GPIOEVENT_REQUEST_FALLING_EDGE)` must precede the single-edge `else if` branches so dual-edge requests sample `gpiod_get_value_cansleep(le->desc)`. In `debounce_work_func()`, filtering of unmonitored edges must compare `eflags` (`edflags & GPIO_V2_LINE_EDGE_FLAGS`) using equality (`eflags == GPIO_V2_LINE_FLAG_EDGE_RISING` / `FALLING`) rather than bitwise `&`. [F73, F75]
- All bit shifts indexing 64-bit ABI v2 line masks (`lv.mask`, `lv.bits`, `lc->attrs[i].mask`, `lc->attrs[i].attr.values`, and `tools/gpio/gpio-utils.h` helpers) must use `BIT_ULL()` or `_BITULL()` rather than `BIT()` or `1UL << n`, and `gpio_v2_line_config_output_value()` and `gpiotools_test_bit()` must normalize the 64-bit bitwise AND result with `!!` before returning `int`. [F87, F88]
- In `gpio_ioctl()` and `linereq_ioctl()`, large command-specific UAPI structures (`gpiochip_info`, `gpioline_info`, `gpio_v2_line_info`, `gpio_v2_line_request`, `gpio_v2_line_config`) must be allocated on the stack of per-command helper functions rather than declared together in the top-level ioctl dispatcher. [F130]
