# GENERIC PM DOMAINS

This unit provides the public header definitions for the Linux Generic Power Domain (genpd) framework (`include/linux/pm_domain.h`) and vendor-specific SoC power domain controller drivers under `drivers/pmdomain/` (MediaTek SCPSYS and Airoha CPU PM domains, Qualcomm RPM/RPMh, Rockchip PMU, Samsung Exynos, Allwinner PPU/PCK-600, NVIDIA Tegra BPMP powergates, and Xilinx ZynqMP).

## Architecture & Data Flow

- In `mtk-pm-domains.c`, `rockchip/pm-domains.c`, `rpmhpd.c`, and `rpmpd.c`, domain pointer arrays (`pd_data.domains`, `genpd_data.domains`, `desc->rpmhpds`, `desc->rpmpds`) are sparse and indexed by hardware ID; any loop over `num_domains` or `num_pds` must check for a `NULL` slot before dereferencing or calling `to_scpsys_domain()`/`to_rockchip_pd()`. In `mtk-pm-domains.c`, `scpsys->soc_data->domains_data` is also sparse (`sta_mask == 0` for unpopulated IDs), so `scpsys_add_one_domain()` must check both `id < scpsys->soc_data->num_domains` and `domain_data->sta_mask != 0`. [F35, F36]
- In `rpmhpd.c`, each SoC `*_rpmhpds[]` table that includes a paired active+sleep and active-only domain must use `struct rpmhpd` instances whose `.peer` pointers reference each other and whose `.parent` pointers reference `generic_pm_domain` instances in that same table (e.g., never pair `cx_w_mx_parent` with `cx_ao` whose `.peer` is `&cx`, or include `mmcx_w_cx_parent` alongside `cx_w_mx_parent`). [F46]
- In `rpmhpd_aggregate_corner()`, when `peer && peer->enabled`, the peer corner passed to `to_active_sleep()` must be `max(peer->corner, peer->enable_corner)`. After `rpmhpd_send_corner(pd, RPMH_ACTIVE_ONLY_STATE, active_corner, ...)` succeeds, both `pd->active_corner` and (when `pd->peer` is non-NULL) `pd->peer->active_corner` must be updated to `active_corner` under `rpmhpd_lock`. [F44, F45]
- Before `pd->state_synced` is set by `rpmhpd_sync_state()` or `rpmpd_sync_state()`, `rpmhpd_aggregate_corner()` and `rpmpd_aggregate_corner()` must clamp active and sleep corners to maximum (`pd->level_count - 1` or `pd->max_state - 1`). Because `rpmpd_aggregate_corner()` evaluates `pd->max_state - 1` in `unsigned int` arithmetic when `!pd->state_synced`, `struct rpmpd_desc.max_state` (and `pd->max_state`) must be at least 1. [F47, F90]
- In `rpmhpd_set_performance_state()`, the lookup loop over `pd->level_count` must decrement `i` when `i == pd->level_count`, and when `pd->enabled` is true it must clamp `i` to at least `pd->enable_corner` before calling `rpmhpd_aggregate_corner()`. In `rpmpd_set_performance()`, `rpmpd_aggregate_corner()` must be skipped when `!pd->enabled` unless `pd->key` is `cpu_to_le32(KEY_FLOOR_CORNER)` or `cpu_to_le32(KEY_FLOOR_LEVEL)`. [F84, F86]
- In `scpsys_domain_data::bp_cfg`, valid bus-protection steps must be packed contiguously from index 0 with no zero-`bus_prot_set_clr_mask` gaps (`scpsys_bus_protect_enable()` stops at the first zero mask with `break`, while `scpsys_bus_protect_disable()` iterates backward from `SPM_MAX_BUS_PROT_DATA - 1` and uses `continue` to skip zero slots). Every `bus_prot_block` and `bus_prot_sta_block` must be `< BUS_PROT_BLOCK_COUNT` and listed in `scpsys_soc_data::bus_prot_blocks` (or legacy DT properties) so `scpsys->bus_prot[scpsys->bus_prot_index[block]]` is valid. [F62, F64, F75]
- In `scpsys_ctl_pwrseq_on()`, for `SCPSYS_RTFF_TYPE_GENERIC` and `SCPSYS_RTFF_TYPE_PCIE_PHY` domains, `PWR_RTFF_NRESTORE` must only run if `PWR_RTFF_SAVE_FLAG` is set in `pd->data->ctl_offs` (and must clear `PWR_RTFF_SAVE_FLAG`, set by `scpsys_ctl_pwrseq_off()`), whereas `SCPSYS_RTFF_TYPE_STOR_UFS` must always execute `PWR_RTFF_NRESTORE`. [F49]
- In `rockchip_pd_power()`, while `pd->clks` are enabled and `rockchip_pmu_ungate_clk(pd, true)` is active under `pmu->mutex`, `rockchip_pmu_save_qos(pd)` must run before `rockchip_pmu_set_idle_request(pd, true)` on power-off, and `rockchip_pmu_restore_qos(pd)` must run after `rockchip_pmu_set_idle_request(pd, false)` succeeds on power-on. `pd->qos_save_regs` must be indexed as `qos_save_regs[reg_idx][qos_idx]` (`0 <= reg_idx < MAX_QOS_REGS_NUM`, `0 <= qos_idx < pd->num_qos`). [F54, F69]
- In `rockchip_do_pmu_set_power_domain()`, when powering on (`on == true`) a domain with a non-zero `pd->info->mem_status_mask`, `rockchip_pmu_domain_is_mem_on(pd)` must be sampled before writing `pmu->info->pwr_offset + pd_pwr_offset` so `rockchip_pmu_domain_mem_reset(pd)` runs if memory was already on. After polling `rockchip_pmu_domain_is_on()` confirms `on`, the driver must call `arm_smccc_smc(ROCKCHIP_SIP_SUSPEND_MODE, ROCKCHIP_SLEEP_PD_CONFIG, ...)` whenever `arm_smccc_1_1_get_conduit() != SMCCC_CONDUIT_NONE`. [F53, F55]
- In `rockchip_pm_add_one_domain()`, domains must set `GENPD_FLAG_NO_STAY_ON` in `pd->genpd.flags` because `rockchip_pd_regulator_enable()` lazily acquires `pd->supply` via `devm_of_regulator_get()` on power-on. If `pmu->genpd_data.domains[id]` is already non-NULL, `rockchip_pm_add_one_domain()` must return `0` without reallocating so shared child domains with multiple DT parents reuse the existing instance. [F56, F116]
- In `rockchip/pm-domains.c`, all mask arguments to `DOMAIN*` macros must be pre-shifted bitmasks (`BIT(n)`), and `pwr`, `req`, and `g_mask` on HIWORD_UPDATE SoCs (`DOMAIN_M*`) must fit in bits `0..15` because `pwr_w_mask`, `req_w_mask`, and `clk_ungate_w_mask` shift them left by 16. [F43]
- In `tegra/powergate-bpmp.c`, `max_id` from `tegra_bpmp_powergate_get_max_id()` is an inclusive bound requiring `max_id + 1` entries and `id <= max_id` iteration in `tegra_bpmp_probe_powergates()`, and powergate IDs must be resolved via `tegra_powergate_xlate()` rather than indexing `genpd->domains[id]` directly because unnamed holes are compacted out. [F70]
- In `zynqmp-pm-domains.c`, `zynqmp_gpd_probe()` must allocate all `ZYNQMP_NUM_DOMAINS` `struct zynqmp_pm_domain` instances as a single contiguous array and assign `domains[i] = &pd->gpd` in index order because `zynqmp_gpd_xlate()` derives the array base from `to_zynqmp_pm_domain(genpd_data->domains[0])` and indexes `pd[i]`. [F92]
- In `sun20i-ppu.c`, `sun20i_ppu_pd_set_power()` must poll `PD_STATUS_REG` until `!(status & PD_STATUS_BUSY)` before writing `PD_COMMAND_REG`, poll until `FIELD_GET(PD_STATUS_STATE, status) == state && (status & PD_STATUS_COMPLETE)`, and write `status` back to `PD_STATUS_REG` to clear `PD_STATUS_COMPLETE`. In `sun50i-h6-prcm-ppu.c`, `sun50i_h6_ppu_desc::offset` is relative to PRCM `0x0`, so `sun50i_h6_ppu_probe()` must subtract `PD_H6_PPU_OFFSET` (`0x250`) from `base + desc->offset`. [F42, F88]

## Synchronization

- On a successful return (`0`), `rockchip_pmu_block()` leaves `dmc_pmu_mutex` held—and when `dmc_pmu` is non-NULL, also leaves `dmc_pmu->mutex` held and every non-NULL domain's `pd->clks` bulk-enabled—so callers must pair every successful `rockchip_pmu_block()` with `rockchip_pmu_unblock()`. `dmc_pmu_mutex` always nests outside `pmu->mutex`, and must also be held in `rockchip_pm_domain_probe()` across domain registration, `of_genpd_add_provider_onecell()`, and setting `dmc_pmu = pmu`. [F1, F24, F125]
- In `rpmhpd.c` and `rpmpd.c`, `rpmhpd_lock` must be held across `rpmhpd_aggregate_corner()` and any read/update of runtime state (`enabled`, `corner`, `active_corner`, `state_synced`) on `struct rpmhpd` or `pd->peer`, but `of_genpd_sync_state()` in `rpmhpd_sync_state()`/`rpmpd_sync_state()` must be called outside `rpmhpd_lock`/`rpmpd_lock` because it invokes `rpmhpd_power_off`/`rpmpd_power_off`. `rpmhpd_send_corner()` must use `rpmh_write()` when `sync` is true (`active_corner > pd->active_corner`), and `rpmh_write_async()` otherwise. [F19, F109, F126]
- In `scpsys_add_one_domain()`, domains without `MTK_SCPD_KEEP_DEFAULT_OFF` must be powered on via `scpsys_power_on()` before `pm_genpd_init()`. In `scpsys_add_subdomain()`, after `scpsys_add_one_domain()` initializes `child_pd`, recursive `scpsys_add_subdomain(scpsys, child)` must complete before linking `child_pd` to `parent_pd` via `pm_genpd_add_subdomain()`. [F15, F16]
- In `rockchip_pmu_set_idle_request()`, `rockchip_pmu_domain_mem_reset()`, and `rockchip_do_pmu_set_power_domain()`, a `wmb()` must follow each PMU request or power register write before polling ACK/status registers. In `sunxi_pck600_pd_set_power()`, a readback `readl(pd->base + PPU_PWPR)` must follow `writel(reg, pd->base + PPU_PWPR)` before polling `PPU_PWSR`. [F26, F27]

## Object Lifetimes

- In `rockchip/pm-domains.c`, `rockchip_pm_add_one_domain()` acquires `pd->clks` via `of_clk_get()` and prepares them once via `clk_bulk_prepare()` (so `rockchip_pd_power()` uses `clk_bulk_enable()`, all under `pmu->mutex`). `rockchip_pm_remove_one_domain()` must call `clk_bulk_unprepare()` and `clk_bulk_put()` on `pd->clks` and then zero `pd->num_clks` under `pd->pmu->mutex`. [F4, F25, F117]
- `scpsys_add_one_domain()` acquires unmanaged clocks via `of_clk_get()`, so errors before `scpsys->domains[id]` is set must call `clk_bulk_put()` on `pd->subsys_clks` and `pd->clks`, and later errors in `scpsys_probe()` must call `scpsys_domain_cleanup()`. In `scpsys_remove_one_domain()`, `pm_genpd_remove(&pd->genpd)` must be called before `scpsys_power_off(&pd->genpd)` and `clk_bulk_put()`. [F9, F17]
- Because `tegra_bpmp_init_powergates()` frees `powergates` and every `powergates[i].name` before returning, `tegra_powergate_add()` must duplicate `info->name` via `kstrdup()` into `powergate->genpd.name`, and both `tegra_powergate_remove()` and the `pm_genpd_init()` failure path must `kfree(genpd->name)`. [F10]
- During driver teardown (e.g., `airoha_cpu_pmdomain_remove()`), `of_genpd_del_provider()` must precede `pm_genpd_remove()`, and if `of_genpd_add_provider_simple()` fails in probe, `pm_genpd_remove()` must roll back `pm_genpd_init()`. In `zynqmp-pm-domains.c`, `zynqmp_gpd_attach_dev()`/`zynqmp_gpd_detach_dev()` must only request/release `pd->node_id` (and update `pd->requested`) when `domain->device_count == 0`, and `zynqmp_gpd_power_off()` must return `0` if `!pd->requested`. [F12, F122]

## API Contracts

- All `GENPD_FLAG_*` flags on `genpd->flags` must be set before calling `pm_genpd_init()`. When a domain sets `GENPD_FLAG_IRQ_SAFE`, every parent domain linked via `pm_genpd_add_subdomain()` must also have `GENPD_FLAG_IRQ_SAFE` set. In `mtk-pm-domains.h` and `scpsys_add_one_domain()`, a domain must not set both `MTK_SCPD_KEEP_DEFAULT_OFF` and `MTK_SCPD_ALWAYS_ON` (`GENPD_FLAG_ALWAYS_ON` requires `is_off = false` in `pm_genpd_init()`). [F13, F133, F137]
- Every `genpd_xlate_t` callback (e.g., `tegra_powergate_xlate`, `zynqmp_gpd_xlate`) must return an `ERR_PTR(...)`—never `NULL`—when lookup fails, because the genpd core checks `!IS_ERR(genpd)` and dereferences `NULL`. When a genpd OF provider defines `.driver.sync_state` (`rpmhpd_sync_state`, `rpmpd_sync_state`), it must call `of_genpd_sync_state(dev->of_node)`. [F28, F141]
- Any change to declarations or return conventions under `#ifdef CONFIG_PM_GENERIC_DOMAINS*` or `#ifdef CONFIG_PM` in `include/linux/pm_domain.h` must update the `#else` stub in lockstep. When disabled, `simple_qos_governor` and `pm_domain_always_on_gov` expand to `(*(struct dev_power_governor *)(NULL))` (take address only), `dev_gpd_data()`/`dev_to_genpd_dev()` return `ERR_PTR`, and `*_dev_pm_attach_by_id()`/`*_by_name()` return `NULL`. [F61, F134, F135]
- Because `rockchip_pm_add_one_domain()` sets `GENPD_FLAG_PM_CLK`, `rockchip_pd_attach_dev()` must initialize the device's PM clock list via `pm_clk_create(dev)` and `pm_clk_add_clk()` (cleaning up with `clk_put()` and `pm_clk_destroy(dev)` on error), and `rockchip_pd_detach_dev()` must call `pm_clk_destroy(dev)`. [F143]
- In `mtk-scpsys.c`, `init_scp()` must convert `-ENODEV` from `devm_regulator_get_optional()` into `scpd->supply = NULL` while propagating other `ERR_PTR` values, because `scpsys_regulator_enable()`/`scpsys_regulator_disable()` treat only `NULL` as absent. In `airoha_cpu_pmdomain_probe()`, `priv->hw` must use `CLK_GET_RATE_NOCACHE` and `airoha_cpu_pmdomain_clk_get()` must convert the MHz SMCCC result to Hz. [F136, F139]

## Error Handling

- When `clk_bulk_enable()` fails at domain index `i` in `rockchip_pmu_block()`, the error path must disable clocks for `i - 1` down to `0` and unlock `pmu->mutex` and `dmc_pmu_mutex` in reverse order. In `rockchip_pd_power()`, once `clk_bulk_enable()` and `rockchip_pmu_ungate_clk(pd, true)` run, every exit path must go through `out:` to re-gate and disable clocks. [F2, F6]
- In `rockchip_pd_regulator_enable()` and `rockchip_pd_regulator_disable()`, `pd->supply` must be tested with `IS_ERR_OR_NULL(pd->supply)` rather than `!pd->supply`, because `rockchip_pd_regulator_enable()` assigns `devm_of_regulator_get()` directly to `pd->supply` and leaves an `ERR_PTR` stored there on failure. [F33]
- In `scpsys_power_on()`, `pd->subsys_clks` are enabled before `scpsys_sram_enable()` only when `!MTK_SCPD_CAPS(pd, MTK_SCPD_STRICT_BUS_PROTECTION)` and after `scpsys_bus_protect_disable()` otherwise, so `err_disable_subsys_clks:` must gate `clk_bulk_disable_unprepare(pd->num_subsys_clks, ...)` on that same check. [F7]
- In `mtk-scpsys.c`, `scpsys_domain_is_on()` returns `1` when both status bits are set, `0` when both are clear, and `-EINVAL` when only one is set; callers must store the result in a signed `int` (never `bool`) and poll for `tmp > 0` on power-on and `tmp == 0` on power-off. [F29]
- Every Tegra BPMP powergate MRQ helper (`tegra_bpmp_powergate_*`) must zero-initialize its `request`, `response`, and `msg` structs and check both `tegra_bpmp_transfer() < 0` and `msg.rx.ret < 0`. In `airoha_cpu_pmdomain_set_performance_state()`, `AIROHA_AVS_OP_FREQ_DYN_ADJ` signals success by clearing `BIT(0)` in `res.a0`, so callers must check `res.a0 & BIT(0)` for failure. [F30, F31]
- In `scpsys_probe()` and `rockchip_pm_domain_probe()`, `ret`/`error` must be initialized to `-ENODEV` immediately before `for_each_available_child_of_node*` so an empty DT node fails with `-ENODEV`. During probe rollback in `scpsys_remove_one_domain()` and `rockchip_pm_remove_one_domain()`, a `pm_genpd_remove()` failure must only be logged and must not abort clock/power teardown. [F37, F140]

## External Contracts

- In `rpmpd.c`, `struct rpmpd_req` payloads sent via `qcom_rpm_smd_write()` must encode `nbytes` and `value` with `cpu_to_le32()` and use little-endian ASCII fourcc values for `key` and `res_type`, and any comparison against `pd->key` must use `cpu_to_le32()`. In `mtk-pm-domains.c`, when DT uses `access-controllers`, `scpsys_get_bus_protection()` requires the phandle count and order to match `scpsys->soc_data->bus_prot_blocks`. [F68, F107]

## Known Pitfalls

- In `struct rockchip_pm_domain`, `num_clks` and `num_qos` come from `of_clk_get_parent_count()` and `of_count_phandle_with_args()`, which return negative errnos when absent; `num_clks` must be clamped to `0` before `clk_bulk_*()`, and `num_qos` and its loop counters in `rockchip_pmu_save_qos()`/`rockchip_pmu_restore_qos()` must remain signed `int`. [F32]
- In `mtk-pm-domains.c`, `scpsys_bus_protect_clear()` must poll `(val & sta_mask) == sta_mask` when `bpd->bus_prot_sta_block == BUS_PROT_BLOCK_INFRA_NAO` and `(val & sta_mask) == 0` for all other blocks. In `scpsys_add_one_domain()`, `clock-names` without `'-'` (`pd->num_clks`) must precede those with `'-'` (`pd->num_subsys_clks`), and `clk_ind` must not be reset between the two loops. [F76, F80]
