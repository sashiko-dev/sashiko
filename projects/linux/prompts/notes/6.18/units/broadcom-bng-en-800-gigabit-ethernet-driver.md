# BROADCOM BNG_EN 800 GIGABIT ETHERNET DRIVER

Broadcom `bng_en` (BCM57708) 800Gb Ethernet PCIe driver implementing device probe/teardown, Hardware Resource Manager (HWRM) firmware command transport, context backing-store and ring DMA memory management, MSI-X interrupt allocation, devlink device info reporting, and `net_device` lifecycle operations (with ring, VNIC, RSS, L2 filter, and `page_pool` setup).

## Architecture & Data Flow

- Hardware descriptor rings (`rx_desc_ring`, `rx_agg_desc_ring`, `tx_desc_ring`) are two-level page pointer arrays indexed via `[RX_RING(bn, idx)][RX_IDX(idx)]` (or `RX_AGG_RING`/`TX_RING` and `TX_IDX`), whereas software buffer rings (`rx_buf_ring`, `rx_agg_buf_ring`, `tx_buf_ring`) are flat `vzalloc` arrays. Broken by: indexing descriptor rings flatly or indexing `rx_agg_buf_ring` by `RING_RX_AGG(bn, prod)` instead of `sw_prod` from `rxr->rx_agg_bmap`. [F72]
- Occupancy of `rxr->rx_agg_buf_ring[i].netmem` and bit `i` in `rxr->rx_agg_bmap` must be updated in lockstep in `bnge_alloc_rx_netmem` and `bnge_free_one_agg_ring_bufs`. `bnge_alloc_rx_agg_bmap` stores `bn->rx_agg_ring_mask + 1` (`bn->rx_agg_nr_pages * RX_DESC_CNT`) in `u16 rxr->rx_agg_bmap_size`, requiring `MAX_RX_AGG_PAGES * RX_DESC_CNT` to be `< 65536` and a multiple of `BITS_PER_LONG`. [F56, F102]
- When `bnge_is_agg_reqd(bd)` is true, firmware RX ring counts (`bd->hw_resc.resv_rx_rings`, `bd->hw_resc.max_rx_rings`, `hwr.rx`) count total hardware RX rings (`2 * bd->rx_nr_rings`), whereas `bd->rx_nr_rings` and `hwr.grp` count RX ring pairs and must be shifted by 1 (`<< 1` or `>> 1`) when converting between them. [F43]
- `BNGE_RX_PAGE_SHIFT` must remain capped at 15 (`BNGE_RX_PAGE_SIZE` < 64 KiB) even when `PAGE_SHIFT >= 16` because the 16-bit `RX_BD_LEN` field in `struct rx_bd` and HWRM `rx_buf_size` (`hwrm_ring_alloc_send_msg`) would truncate 64 KiB to 0; cast `BNGE_RX_PAGE_SIZE` to `u32` before shifting by `RX_BD_LEN_SHIFT` (16) so `0x8000 << 16` does not overflow signed `int`. [F61, F92]
- In `bnge_set_ring_params` and `bnge_init_rx_rings`, `bn->rx_buf_size` (allocated from `rxr->head_pool`) must include `bn->rx_buf_use_size`, `NET_SKB_PAD` (`bn->rx_dma_offset`) headroom, and `SKB_DATA_ALIGN(sizeof(struct skb_shared_info))` tailroom, while only `bn->rx_buf_use_size` is programmed into hardware RX descriptors. [F151]
- In `struct bnge_napi`, `bnapi->rx_ring` is only populated for `i < bd->rx_nr_rings` (`NULL` on TX-only channels when `BNGE_EN_SHARED_CHNL` is unset), and `bnapi->tx_ring` must be traversed with `bnge_for_each_napi_tx` or NULL-checked. In `bnge_alloc_nq_tree`, `nqr->cp_ring_arr` places RX completion at `k == 0` when `rx == 1` and TX completions at `k = rx .. cp_count - 1` so `tc = k - rx` and `j` (incremented only when `tx == 1`) index `bn->tx_ring[BNGE_TC_TO_RING_BASE(bd, tc) + j]`. [F39, F90]
- Adjusting `bd->tx_nr_rings` or `bd->rx_nr_rings` requires updating `bd->nq_nr_rings` and `bd->tx_nr_rings_per_tc` in lockstep, and changing `bd->hw_resc.resv_rx_rings` or `bd->rx_nr_rings` requires calling `bnge_set_dflt_rss_indir_tbl`. `bd->rss_indir_tbl` stores logical RX indices (`0 .. bd->rx_nr_rings - 1`) that `bnge_fill_hw_rss_tbl` translates into `__le16` `(rx_fw_ring_id, cp_fw_ring_id)` pairs in `vnic->rss_table` (`BNGE_RSS_TABLE_SIZE` per RSS context). [F49, F50, F74]
- When `bn->rss_hash_key` is updated (`bn->rss_hash_key_updated`), `bnge_init_vnics` must copy it into `vnic0->rss_hash_key`, recompute `bn->toeplitz_prefix` from its first 8 bytes, and propagate `vnic0->rss_hash_key` to all other VNICs. [F59]
- `struct bnge_filter_base base` must remain the first member of `struct bnge_l2_filter`, and unlike host-order `fw_vnic_id`/`fw_ring_id`, `base.filter_id` is stored in `__le64` directly from `resp->l2_filter_id` and copied without byte-swapping to `req->l2_filter_id`. In `struct bnge_vnic_info`, `l2_filters[0]` is reserved for `netdev->dev_addr` while secondary unicast MACs from `netdev->uc` use 0-based offsets in `uc_list` (sized `(BNGE_MAX_UC_ADDRS - 1) * ETH_ALEN`) and 1-based indices `l2_filters[1 .. uc_filter_count - 1]`. [F60, F70, F78]
- In `bnge_alloc_ring` and `bnge_free_ring`, `rmem->vmem` is only populated and dereferenced when `rmem->vmem_size > 0`, and `rmem->nr_pages`, `rmem->page_size`, and `rmem->flags & BNGE_RMEM_USE_FULL_PAGE_FLAG` must not change between allocation and free because they determine the `dma_free_coherent` size of `rmem->pg_tbl`. [F40, F80]
- When `ctxm->instance_bmap` is non-zero, `ctxm->pg_info` has `hweight32(ctxm->instance_bmap)` dense entries, so `bnge_hwrm_func_backing_store` must advance a separate dense index `j` into `ctxm->pg_info[j]` only for set bits `i` while passing `i` as `req->instance`. `bnge_setup_ctxm_pg_tbls` must reject `ctxm->entry_size == 0` and guard `roundup(entries, ctxm->entry_multiple)` with `if (ctxm->entry_multiple)`, and `bnge_alloc_ctx_pg_tbls` must reject `ctx_pg->nr_pages > MAX_CTX_TOTAL_PAGES`. [F66, F67, F97]
- Clamp `ctxm->split_entry_cnt` to `BNGE_MAX_SPLIT_ENTRY` (4) before stepping `__le32 *p` across `split_entry_0..3` in backing-store HWRM helpers, clamp `bd->max_tc` to `BNGE_MAX_QUEUE` (8) before walking `qptr = &resp->queue_id0` in `bnge_hwrm_queue_qportcfg`, and in `bnge_hwrm_func_qcfg` fall back `bd->db_size` to `pci_resource_len(bd->pdev, 2)` if 0, `> pci_resource_len`, or `<= bd->db_offset`. [F69, F114, F115]

## Synchronization

- `bnge_hwrm_create_token` returns a non-NULL `bnge_hwrm_wait_token` with `bd->hwrm_cmd_lock` held and must be paired with `bnge_hwrm_destroy_token` to unlink/free the token and unlock `bd->hwrm_cmd_lock`, setting `token = NULL` if destroyed early in `__hwrm_send_ctx`. [F2]
- In `__hwrm_send_ctx`, `wmb()` must execute after populating `ctx->req` (and any DMA slices) before copying to `bd->bar0` and ringing `BNGE_GRCPF_REG_CHIMP_COMM_TRIGGER`. When polling DMA responses, verify `READ_ONCE(ctx->resp->resp_len)` and `READ_ONCE(ctx->resp->seq_id) == ctx->req->seq_id`, execute `dma_rmb()` before testing the trailing `*valid` byte (`((u8 *)ctx->resp) + len - 1`), and clear `*valid = 0` before reading `error_code` or payload; held contexts (`BNGE_HWRM_INTERNAL_RESP_DIRTY`) must `memset(ctx->resp, 0, PAGE_SIZE)` before re-sending. [F17, F18, F64]
- All 64-bit MMIO doorbell writes must go through `bnge_writeq` (via `bnge_db_write`, `bnge_db_nq`, or `bnge_db_cq`) so `bd->db_lock` serializes `lo_hi_writeq` on 32-bit builds. [F19]
- In `bnge_hwrm_ring_alloc`, each NQ's MSI-X vector (`bd->irq_tbl[map_idx].vector`) must be disabled with `disable_irq_nosync` before `hwrm_ring_alloc_send_msg` and re-enabled with `enable_irq` only after `bnge_set_db` and `bnge_db_nq` initialize and arm `nqr->nq_db` (or on failure). When `bnge_is_agg_reqd(bd)` is true, do not write `rxr->rx_db` in `bnge_hwrm_rx_ring_alloc`; write `rxr->rx_agg_db` before `rxr->rx_db` in `bnge_hwrm_rx_agg_ring_alloc`. [F20, F21]
- In `bnge_cfg_def_vnic`, hold `netif_addr_lock_bh(dev)` while reading `dev->uc`, drop it before sleeping HWRM calls (`bnge_hwrm_l2_filter_free`, `bnge_hwrm_set_vnic_filter`), and recheck `netdev_uc_count(dev) > (BNGE_MAX_UC_ADDRS - 1)` after relocking before copying into `vnic->uc_list`. [F24]
- Because `bnge_netdev_alloc` sets `netdev->request_ops_lock = true`, `bnge_init_napi`, `bnge_request_irq`, and `bnge_del_napi` must use `_locked` NAPI helpers with `bn->netdev->lock` held, and `bnge_del_napi` must clear RX/TX queue NAPI pointers and call `synchronize_net()` before freeing `bn->bnapi`. [F14, F135]
- `bnge_lookup_l2_filter` must hold `rcu_read_lock()` while calling `__bnge_lookup_l2_filter` and `refcount_inc(&fltr->refcnt)`. `bnge_alloc_l2_filter` returns `ERR_PTR` or a filter with incremented `refcnt`; callers must release it via `bnge_del_l2_filter` (after `bnge_hwrm_l2_filter_free` if firmware-allocated), which unlinks (`hlist_del_rcu`) and frees (`kfree_rcu`) only when `refcount_dec_and_test(&fltr->refcnt)` is true. [F11, F27]

## Object Lifetimes

- `bnge_hwrm_req_send` and `bnge_hwrm_req_send_silent` free the request context via `__hwrm_ctx_invalidate` on both success and failure unless the caller first called `bnge_hwrm_req_hold`, in which case the caller must release it with `bnge_hwrm_req_drop`. [F1]
- In `bnge_probe_one` and `bnge_remove_one`, `bnge_map_db_bar` and `bnge_devlink_register` must run after `bnge_fw_register_dev` (`bnge_hwrm_func_qcfg`), and teardown must run `bnge_netdev_free` and `bnge_devlink_unregister` before `bnge_fw_unregister_dev` (which calls `bnge_hwrm_func_drv_unrgtr` before `bnge_free_ctx_mem`), followed by `bnge_cleanup_hwrm_resources`, `bnge_unmap_bars`, and `bnge_devlink_free(bd)`. [F4, F15, F26, F120]
- Because 2-level context page tables alias `pg_tbl->ring_mem.pg_tbl` to `ctx_pg->ctx_pg_arr[i]` in `bnge_alloc_ctx_pg_tbls`, `bnge_free_ctx_pg_tbls` must clear `ctx_pg->ctx_pg_arr[i] = NULL` after `bnge_free_ring(bd, &pg_tbl->ring_mem)` and before `bnge_free_ring(bd, &ctx_pg->ring_mem)`. For NQ and completion rings, `bnge_free_ring` must run before `bnge_free_nq_desc_arr` (`bnge_free_nq_arrays`) or `bnge_free_cp_desc_arr` frees `desc_ring` and clears `ring_mem.pg_arr`. [F5, F6]
- `bnge_alloc_core` allocates `bn->bnapi` and all `struct bnge_napi` elements in one `kzalloc` block, and `bnge_alloc_vnic_attributes` places `vnic->rss_hash_key` inside the `vnic->rss_table` DMA buffer; teardown must only `kfree(bn->bnapi)` (never `bn->bnapi[i]`) and `dma_free_coherent` `vnic->rss_table` (only setting `vnic->rss_hash_key = NULL`). [F7, F8]
- In `bnge_alloc_rx_page_pool`, check `IS_ERR(pool)` before assigning `rxr->page_pool` or `rxr->head_pool` (destroying and NULLing `rxr->page_pool` if `head_pool` fails), and call `page_pool_get(pool)` before `rxr->head_pool = rxr->page_pool` when `!bnge_separate_head_pool(rxr)` because `bnge_free_rx_rings` destroys both. In `bnge_close_core`, `bnge_free_all_rings_bufs` must recycle all RX/agg buffers before `bnge_free_core` destroys the pools. [F9, F10, F29]
- Before `bnge_init_chip` runs, all `fw_ring_id`, `grp_info[i].*`, `fw_vnic_id`, and `fw_rss_cos_lb_ctx[j]` fields must be initialized to `INVALID_HW_RING_ID` (`(u16)-1`) and `hw_stats_ctx_id` to `INVALID_STATS_CTX_ID` (`-1`). `bnge_init_chip` must allocate stats contexts, then NQ, CMPL, TX, RX, and AGG rings in parent-first order; `bnge_hwrm_resource_free` must free in reverse order (VNICs/filters, TX/RX/AGG, CMPL/NQ, stat contexts) and reset each ID to invalid. [F13, F38, F124]

## API Contracts

- `bnge_hwrm_req_create`/`init` and `bnge_hwrm_req_send`/`silent` require sleeping process context without `bd->hwrm_cmd_lock` or spinlocks held. `bnge_hwrm_req_create` takes `void **req`, places `req` at offset 0 and `bnge_hwrm_ctx` at `BNGE_HWRM_CTX_OFFSET`, and sets `ctx->sentinel` from `req_type`; other `bnge_hwrm_req_*` helpers take `void *req` and verify `ctx->sentinel` against `le16_to_cpu(req->req_type)`, so `req_len` must cover the full request (`<= BNGE_HWRM_CTX_OFFSET`) and `req->req_type` must not be modified. [F33, F62, F136]
- `bnge_hwrm_req_dma_slice` carves inline slices downward toward `ctx->req_len` using 32-bit unsigned (`u32`) `offset = max_offset - size` (relying on unsigned wrap when `size > max_offset`) and permits at most one fallback `dma_alloc_coherent` (`ctx->slice_addr`) per `bnge_hwrm_ctx`, owned and freed by `__hwrm_ctx_invalidate`. [F3, F99]
- `bnge_hwrm_ver_get` must be the first HWRM command in `bnge_fw_register_dev` (initializing `hwrm_max_req_len`, `hwrm_max_ext_req_len`, and timeouts), and `bnge_hwrm_func_qcaps` must precede `bnge_hwrm_queue_qportcfg`, `bnge_aux_init_dflt_config`, and `bnge_net_init_dflt_config` (which check `bnge_is_roce_en(bd)`). [F119, F121]
- `hwrm_ring_alloc_send_msg`, `bnge_set_db`, and `bnge_set_db_mask` require `HWRM_RING_ALLOC_*` bitmasks, whereas `hwrm_ring_free_send_msg` requires `RING_FREE_REQ_RING_TYPE_*` constants. In `hwrm_ring_alloc_send_msg`, `map_index` must be `ring->grp_idx + bd->rx_nr_rings` for `HWRM_RING_ALLOC_AGG` and `bnapi->index` for `HWRM_RING_ALLOC_CMPL`, and for `HWRM_RING_ALLOC_TX`, `ring` must be `&txr->tx_ring_struct` with `txr->tx_cpr` already initialized. [F34, F36, F109]
- `bnge_db_write`, `bnge_db_cq`, and `bnge_db_nq` require unmasked wrapping indices (`rx_prod`, `rx_agg_prod`, `cp_raw_cons`, `nq_raw_cons`) rather than ring-masked indices (`RING_RX`, `RING_RX_AGG`) because `DB_RING_IDX(db, idx)` extracts the epoch bit from `idx & db->db_epoch_mask` (`db_ring_mask + 1`). [F37]

## Error Handling

- In `bnge_cfg_def_vnic`, `vnic->l2_filters[0]` is reserved for `dev_addr` (`vnic->uc_filter_count` starts at 1), and if `bnge_hwrm_set_vnic_filter` fails at index `i >= 1`, `vnic->uc_filter_count` must be truncated to `i` before returning so teardown only frees populated `vnic->l2_filters[0 .. i-1]` entries. [F12]
- `bnge_alloc_one_rx_ring_bufs` succeeds (returning `0` and advancing `rxr->rx_prod`) whenever at least one buffer (`i > 0`) is allocated, whereas `bnge_alloc_one_agg_ring_bufs` requires at least `MAX_SKB_FRAGS` buffers (`i >= MAX_SKB_FRAGS`) and frees partial allocations via `bnge_free_one_agg_ring_bufs` before returning `-ENOMEM`. [F30]

## External Contracts

- `bnge_backing_store_cfg` must set `ctx->ctx_arr[last_type].last = 1` on the final enabled context type (`BNGE_CTX_MAX - 1` when `FUNC_BACKING_STORE_CFG_REQ_ENABLES_TIM` is set, else `BNGE_CTX_L2_MAX - 1`) so `bnge_hwrm_func_backing_store` sets `BNGE_BS_CFG_ALL_DONE` on the last request. [F129]
- In `bnge_devlink_info_get` and `bnge_vpd_read_info`, 16-bit version fields in `bd->ver_resp` require `VER_GET_RESP_FLAGS_EXT_VER_AVAIL`, NVM version fields require `NVM_GET_DEV_INFO_RESP_FLAGS_FW_VER_VALID`, and fixed-width strings (`active_pkg_name`, `pkg_name`, VPD fields) must be bounded to `HWRM_FW_VER_STR_LEN` or `BNGE_VPD_FLD_LEN - 1` into a NUL-terminated buffer. [F45, F79]

## Known Pitfalls

- In `struct bnge_ring_struct`, `map_idx` is used on NQ rings (`nqr->ring_struct`) to store `ulp_msix + i` (indexing `bd->irq_tbl`), whereas `grp_idx` is used on RX, RX_AGG, and TX rings to store `0 .. bd->nq_nr_rings - 1` (indexing `bn->grp_info`); never index `bn->grp_info` by `map_idx` or `bd->irq_tbl` by NQ index `i`. [F35]
- Cast `xid` (`u32`) to `u64` before `<< DBR_XID_SFT` (32) in `bnge_set_db`, and cast 16-bit version fields to `u64` before shifting by 48, 32, and 16 in `BNGE_FW_VER_CODE`. [F93, F94]
- In `bnge_hwrm_func_backing_store_qcaps`, bind `ctxm = &ctx->ctx_arr[type]` before sending the request, and update `type = le16_to_cpu(resp->next_valid_type)` before the `FUNC_BACKING_STORE_QCAPS_V2_RESP_FLAGS_TYPE_VALID` `continue` check. In `bnge_alloc_ctx_pg_tbls`, keep `rmem->nr_pages = MAX_CTX_PAGES` on the last table (`i == nr_tbls - 1`) when `ctx_pg->nr_pages % MAX_CTX_PAGES == 0`. [F82, F98]
- When `!shared`, `bnge_fix_rings_count` must reject `max < 2` before `while (_rx + _tx > max)`. In `bnge_alloc_l2_filter`, `sizeof(struct bnge_l2_key)` must be a multiple of 4 bytes without padding and callers must initialize both `dst_mac_addr` and `vlan` before hashing `BNGE_L2_KEY_SIZE` `u32` words. [F84, F110]
