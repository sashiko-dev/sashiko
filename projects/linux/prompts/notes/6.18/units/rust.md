# RUST

Core Rust-for-Linux kernel crate (`rust/kernel/*`), C FFI and UAPI bindings (`rust/bindings/*`, `rust/uapi/*`), C helper wrappers (`rust/helpers/*.c`), procedural macros (`rust/macros/*`), and the target specification generator (`scripts/generate_rust_target.rs`). It provides safe abstractions for reference counting, intrusive collections, synchronization, workqueues, userspace/iovec access, strings, tasks, error handling, and device drivers.

## Architecture & Data Flow

- `UserSliceReader::read_raw` and `IovIterSource::copy_from_iter_raw` must never write uninitialized bytes into `out: &mut [MaybeUninit<u8>]`, even on failure or partial copy, because `read_slice` and `copy_from_iter` cast `&mut [u8]` directly to `&mut [MaybeUninit<u8>]`. [F33]
- `UserSliceReader` (`skip`, `read_raw`, `read`) and `UserSliceWriter` (`write_slice`, `write`) must check `len <= self.length` and verify `copy_from_user`/`copy_to_user` returned `0` before advancing `self.ptr` (via `UserPtr::wrapping_byte_add`) and decrementing `self.length`. [F51, F88]
- `ListLinks<ID>` has null `prev`/`next` iff the item is not in a `List`, and `ListItem::view_links` must return links with two null pointers outside `prepare_to_insert`..`post_remove`. In `List::remove_internal_inner`, after relinking `(*next).prev` and `(*prev).next`, both `(*item).prev` and `(*item).next` must be set to `ptr::null_mut()` before setting `self.first = (*prev).next` and calling `T::post_remove` and `ListArc::from_raw`. [F7, F41]
- `ListArc` lifecycle transitions must keep `T`'s `ListArcSafe<ID>` tracker synchronized: `From<Pin<UniqueArc<T>>>` and `pair_from_pin_unique` call `on_create_list_arc_from_unique`, `into_arc` and `Drop::drop` call `on_drop_list_arc`, and `into_raw` uses `transmute_to_arc` so tracking stays active while raw. [F48]
- `ListLinksSelfPtr<T, ID>` must stay `#[repr(C)]` with `inner: ListLinks<ID>` first, and `ListItem::prepare_to_insert` must write `me` into `self_ptr` before returning `links_field` so `view_value` and `post_remove` can recover `*const Self`. [F100]
- `List::push_all_back` must reset `other.first = ptr::null_mut()` after splicing `other` into `self` so dropping `other` does not double-remove nodes. In `list::Cursor::prev_ptr`, `next == first` must be checked before `next.is_null()` substitutes `next = first`, and `list::Iter::next` / `list::Cursor::move_next` must reset to `ptr::null_mut()` when `(*current).next` reaches `first` (`stop`). [F46, F74, F75]
- `ArcInner<T>` must stay `#[repr(C)]` with `data: T` last so `*const T` and `*const ArcInner<T>` share fat-pointer metadata and `ArcInner::container_of` can subtract `Layout::new::<Refcount>().extend(Layout::for_value(&*ptr)).unwrap_unchecked().1`. [F67]
- `ForeignOwnable::into_foreign` must return a non-null pointer aligned to `>= Self::FOREIGN_ALIGN`, and `borrow_mut` must never let callers change the foreign-owned allocation's address (e.g. yielding `&mut Self` on a pointer wrapper). [F107]
- `unsafe impl AlwaysRefCounted` is only sound when every instance is refcounted and `inc_ref` keeps the allocation alive until a matching `dec_ref`, because `From<&T> for ARef<T>` upgrades any `&T` to `ARef<T>`. [F109]
- `unsafe trait AsBytes` forbids uninitialized padding bytes, interior mutability, and kernel pointers; `unsafe trait FromBytes` allows padding only if every bit pattern is valid and there is no interior mutability. [F60]
- `HasWork<T, ID>` and `HasDelayedWork<T, ID>` require `raw_get_work` and `work_container_of` to be exact inverses for `ID`, and `HasDelayedWork`'s `Work<T, ID>` pointer must point to the `work` field of `bindings::delayed_work`. [F99]
- `LockClassKey` must only be instantiated uninitialized in static storage via `static_lock_class!` or registered in-place via `LockClassKey::new_dynamic()`, never via a safe `new()` or `Default`. [F106]
- `CStr` requires a non-empty, NUL-terminated slice without interior NULs (`len_with_nul` calls `unreachable_unchecked()` if empty; `Index<RangeFrom<usize>>` bounds-checks `index.start` against `as_bytes()`). `CString::try_from_fmt` must write `args` and `"\0"` in both the `RawFormatter` and `Formatter` passes, then scan `f.bytes_written() - 1` bytes with `bindings::memchr` for interior NULs. [F64, F80]
- `RawFormatter::write_str` must advance `self.pos` via `saturating_add(s.len())` while clamping copied bytes to `min(pos_new, self.end).saturating_sub(self.pos)`. `NullTerminatedFormatter::write_str` must check `len > self.buffer.len() - 1`, advance `self.buffer = &mut buffer[len..]`, and set `self.buffer[0] = 0`. [F65, F66]
- In `rust/kernel/bits.rs`, `impl_genmask_fn!` must compute `(high | (high - 1)) & !(low - 1)` from `high = 1 << end` after checking `start <= end` and `end < <$ty>::BITS`. In `rust/kernel/ptr.rs`, `Alignable::align_down` and `align_up` must convert `alignment` into `Self` via `try_from` rather than truncating with `as Self`. [F85, F87]
- `kernel::Module` and `kernel::InPlaceModule` must require `Send + Sync` supertraits. In `module!`, `THIS_MODULE` wraps `ptr::null_mut()` under `#[cfg(not(MODULE))]`, so `ThisModule::as_ptr` users must tolerate null, and `__MOD`, `unsafe fn __init`/`__exit`, and `extern "C"` entry points must stay inside double-nested `mod __module_init`. [F115, F156, F182]

## Synchronization

- `Revocable::try_access` must call `rcu::read_lock` before loading `self.is_available`, and callers holding `RevocableGuard` (or a reference from `try_access_with_guard`) must not sleep. `Revocable::revoke_internal` atomically swaps `is_available` to `false` and only on `true -> false` calls `bindings::synchronize_rcu()` (when `SYNC` is true in `revoke`; `revoke_nosync` skips it and requires no concurrent readers) before `drop_in_place(self.data.get())`; `PinnedDrop::drop` only calls `drop_in_place` if `*p.is_available.get_mut()` is `true`. [F10, F15, F120, F125]
- `CondVar::wait_internal` must call `prepare_to_wait_exclusive` before releasing `guard` via `guard.do_unlocked`, and call `finish_wait` after `do_unlocked` reacquires the lock and before `wait` goes out of scope. When calling `CondVar::wait_interruptible_freezable`, no lock other than `guard` may be held. [F11, F129]
- `Arc::into_unique_or_drop` must wrap `self` in `ManuallyDrop` and use `refcount.dec_and_test()` followed by `refcount.set(1)` on success, never dereferencing `this` if `dec_and_test()` returns `false`. [F21]
- `AtomicTracker::on_drop_list_arc` must store `false` with `Ordering::Release` and `AtomicTracker::try_new_list_arc` must transition `false -> true` with `Ordering::Acquire`. [F19]
- Calling `bindings::task_active_pid_ns` without RCU protection or refcount elevation is only sound on `current` (`CurrentTask::active_pid_ns`); arbitrary `Task`s must use `Task::get_pid_ns` (`rust_helper_task_get_pid_ns`). [F146]
- `IovIterSource` and `IovIterDest` must remain `!Send` (`kmap_local_page()` thread-local mappings). In `usb::Adapter::register`, `name`, `probe`, `disconnect`, and `id_table` on `struct usb_driver` must be initialized before `bindings::usb_register_driver`. [F26, F133]

## Object Lifetimes

- `ForeignOwnable::from_foreign` must be called at most once per `into_foreign` call and only after all borrows from `ForeignOwnable::borrow` or `borrow_mut` on that pointer have ended. [F2]
- In `RBTree::drop`, `bindings::rb_next_postorder(next)` must be called before `drop(KBox::from_raw(this))`; in `rbtree::Cursor::remove_current`, `get_neighbor_raw` must be called before `bindings::rb_erase`. [F9]
- `CurrentTask` references (`current!()`, `Task::current()`) must never escape the active task context (including across `kthread_use_mm()`/`kthread_unuse_mm()`, `begin_new_exec()`, `release_task()`, or return to userspace); closures entering a new mm/task sub-context must require `Send` to be blocked by `NotThreadSafe`. [F113]
- A dynamic `LockClassKey` (`LockClassKey::new_dynamic()`) calls `bindings::lockdep_unregister_key` in `PinnedDrop::drop`, so all locks initialized with a reference to that key must be dropped before the `LockClassKey` is reclaimed and dropped. [F14]
- `usb::Adapter::probe_callback` stores `Pin<KBox<T>>` via `dev.set_drvdata(data)`, and `disconnect_callback` must reclaim and drop that exact `Pin<KBox<T>>` via `dev.drvdata_obtain::<Pin<KBox<T>>>()` after `T::disconnect`. Deriving a parent/related `&usb::Device` from `&usb::Interface<Ctx>` via `AsRef` must not propagate `Ctx: device::DeviceContext`. [F13, F110]
- `print_macro!` must bind `fmt!($($arg)+)` as the scrutinee of a `match` around `call_printk` (not a `let` statement), and `call_printk`'s `module_name` (`__LOG_PREFIX`) must be NUL-terminated. [F92]

## API Contracts

- `ARef::from_raw` takes ownership of an existing refcount increment without calling `AlwaysRefCounted::inc_ref`, whereas `ARef::from(&T)` and `ARef::clone` call `inc_ref` before `ARef::from_raw`. [F4]
- Callers of `UserSlice` must construct one `UserSlice` per userspace region and validate the kernel copy rather than calling `UserSlice::new` or `UserSliceReader::clone_reader` twice (TOCTOU). Dynamically-sized copies in `read_raw`/`write_slice` must use `bindings::copy_from_user`/`copy_to_user`, reserving `_copy_from_user`/`_copy_to_user` for compile-time-sized `read`/`write`. [F56, F94]
- Before advancing a `Vec<u8, A>` length via `unsafe { buf.inc_len(len) }` after an FFI read into `spare_capacity_mut()`, `len` must be bounded to the bytes actually initialized (e.g. `_copy_from_iter`'s return value in `copy_from_iter_vec` or `Ok(())` from `read_raw`). [F116]
- `FromBytes::from_bytes` and `from_bytes_mut` require `bytes.len() == size_of::<Self>()` and `slice_ptr.is_aligned()`; unaligned slices must use `FromBytes::from_bytes_copy`. `Opaque::ffi_init` and `try_ffi_init` pass an uninitialized `*mut T` that closures must not read before initializing, and `Opaque::get` requires prior initialization before dereferencing. [F61, F105]
- `DelayedWork::new` must initialize `(*slot).work` via `init_work_with_key` and `(*slot).timer` via `timer_init_key` with `Some(bindings::delayed_work_timer_fn)` and `bindings::TIMER_IRQSAFE`. Work items on `workqueue::system_bh()` or `system_bh_highpri()` run in softirq context and must not sleep; `task::might_sleep` requires sleepable context. [F23, F128, F132]
- `IovIterSource::from_raw` and `IovIterDest::from_raw` require `iov_iter.data_source` to equal `ITER_SOURCE` or `ITER_DEST` respectively, with buffers valid for `'data` and exclusively accessed for `'iov`. [F112]
-In `#[vtable]` traits, optional methods' default bodies must call `build_error!(VTABLE_DEFAULT_ERROR)`. `vtable` in `rust/macros/vtable.rs` must record emitted `HAS_*` names in `consts` to skip duplicate `#[cfg]` overloads, and only scans direct `fn <ident>` tokens in outer braces (macro-generated methods need explicit `const HAS_*`). [F157, F171, F199]

## Error Handling

- `Error` wraps a `NonZeroI32` in `-(bindings::MAX_ERRNO as i32)..=-1`; `Error::from_errno` and `to_result` warn and return `EINVAL` if `< -MAX_ERRNO` (and `from_errno` if `>= 0`). `to_result` maps any `err >= 0` to `Ok(())`, so never use it for C functions returning positive errors or counts/handles. `from_err_ptr` only checks `bindings::IS_ERR` and returns `Ok(ptr)` on `NULL`, so callers must check for null separately when C can return `NULL`. [F28, F29, F69]
- In `<Arc<T> as RawWorkItem<ID>>::__enqueue`, `Arc::into_raw(self)` transfers a refcount before `queue_work_on(work_ptr)`, and if `queue_work_on` returns `false`, ownership must be reclaimed via `Err(unsafe { Arc::from_raw(ptr) })`. [F12]
- `copy_from_user`/`copy_to_user` (and `_` variants) return uncopied byte counts (`res != 0` maps to `Err(EFAULT)` without advancing `ptr`/`length`), whereas `strncpy_from_user` returns negative errno or copied length. `UserSliceReader::strcpy_into_buf` must return `Err(EINVAL)` if `buf.is_empty()`, cap `raw_strncpy_from_user` to `self.length`, return `Err(EFAULT)` if `len == dst.len() < buf.len()`, and write `0` to `buf`'s last byte when `len == buf.len()`. [F34, F59]
- `IovIterDest::simple_read_from_buffer` must return `Err(EINVAL)` if `*ppos < 0`, return `Ok(0)` without modifying `*ppos` if `*ppos` exceeds `usize::MAX` or `contents.len()`, and otherwise advance `*ppos` by bytes copied. `CondVar::wait_interruptible_timeout` must check `crate::current!().signal_pending()` before checking if remaining jiffies is `0`. [F42, F63]

## External Contracts

- Rust functions called from C (`rust_fmt_argument`, `WorkItemPointer::run`, `usb::Adapter` callbacks) must be `extern "C"` and use `crate::ffi::{c_char, c_long, c_ulong}` rather than `core::ffi`. `#[export]` functions must keep the `::kernel::bindings::#name` check and be declared in `rust/bindings/bindings_helper.h`. All exports in `rust/exports.c` must use `EXPORT_SYMBOL_RUST_GPL`. [F90, F134, F139, F184]
- In `rust/bindings/bindings_helper.h`, headers defining C `enum`s must precede forward declarations, and C expression/bit-macro constants (`VM_MERGEABLE`, `BLK_FEAT_ROTATIONAL`, `FOP_UNSIGNED_OFFSET`, `GFP_*`) must use `const <type> RUST_CONST_HELPER_<NAME> = <NAME>;` with their exact C typedef. `rust/uapi/lib.rs` must keep `pin_init::MaybeZeroable` and `__kernel_{size,ssize,ptrdiff}_t` before `uapi_generated.rs`. [F81, F82, F200]
- In `rust/helpers/io.c`, 64-bit MMIO helpers (`rust_helper_readq`/`writeq` family) require `#ifdef CONFIG_64BIT`. In `rust/helpers/regulator.c`, helpers for functions that are `static inline` stubs only when `!CONFIG_REGULATOR` require `#ifndef CONFIG_REGULATOR`. Do not hand-edit `rust/helpers/atomic.c` without `scripts/atomic/gen-rust-atomic-helpers.sh`. [F55, F122, F123]
- `module!` must format NUL-terminated `.modinfo` strings with `{module}.` prefix under `#[cfg(not(MODULE))]` and unprefixed under `#[cfg(MODULE)]`; place `init_module` in `.init.text` (never call after init) and `cleanup_module` in `.exit.text`; and for built-in `.initcall6.init` use `global_asm!` (`.long __{ident}_init - .`) under `CONFIG_HAVE_ARCH_PREL32_RELOCATIONS` and a fn pointer static otherwise. [F186, F188, F189, F191]
- Every `usb::DeviceId` constructor must zero-initialize unused `usb_device_id` fields and set `match_flags` to the populated bitmask, with `RawDeviceIdIndex` using `offset_of!(bindings::usb_device_id, driver_info)`. C-header inline asm (`jump_label.rs`, `bug.rs`) must use `$crate::asm!` for x86 `att_syntax`. [F68, F135]

## Known Pitfalls

- In `list::CursorPeek::remove`, `self.cursor.move_next()` must run before `self.cursor.list.remove_internal(self.ptr)` when `ISNEXT` is true, and callers in a `while let Some(next) = cursor.peek_next()` loop must not call `cursor.move_next()` after `next.remove()`. [F76]
- `Kuid::into_uid_in_current_ns` and `Kuid::current_euid` query `current_user_ns()` and `current_euid()`, so they must only be called in the target task's process context, never from a workqueue or kthread. [F148]
- In `impl_list_arc_safe!`, the `tracked_by` arm must invoke `::pin_init::assert_pinned!($t, $field, $fty, inline)` (not `$crate::assert_pinned!`). In `static_branch_unlikely!`, the `#[cfg(not(CONFIG_JUMP_LABEL))]` arm must pass `_key.cast_mut()` to `$crate::bindings::static_key_count`. [F49, F54]
