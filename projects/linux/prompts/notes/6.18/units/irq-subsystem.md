# IRQ SUBSYSTEM

The Generic IRQ (`genirq`) subsystem manages interrupt descriptors (`struct irq_desc`), hardware interrupt controller abstractions (`struct irq_chip`), flow handlers, and device interrupt action registration (`request_threaded_irq` / `free_irq`). It handles hardirq and threaded execution, SMP CPU affinity and hotplug migration, wakeup and suspend/resume power management, spurious interrupt detection, IPI multiplexing, vector matrix allocation, and interrupt timing prediction.

## Architecture & Data Flow

- Converting `struct irq_data *` to `struct irq_desc *` must use `irq_data_to_desc()`, not `container_of(data, struct irq_desc, irq_data)`, and obtaining the top-level `irq_data` must use `irq_desc_get_irq_data(irq_data_to_desc(data))`. When `CONFIG_IRQ_DOMAIN_HIERARCHY` may be disabled, parent traversal must use `irqd_get_parent_data()` instead of `d->parent_data`. [F128, F174]
- Updating `desc->status_use_accessors` via `irq_modify_status()`, `__irq_set_trigger()`, or `__setup_irq()` must synchronize the mirrored `IRQD_NO_BALANCING`, `IRQD_PER_CPU`, `IRQD_LEVEL`, and `IRQD_TRIGGER_MASK` bits in `desc->irq_data` under `desc->lock`. Any new `IRQD_*` flag in `include/linux/irq.h` requires a matching `BIT_MASK_DESCR(IRQD_*)` entry in `irqdata_states[]`. [F62, F79]
- In `__setup_irq()`, installing the first action (`!shared`) must clear `IRQS_AUTODETECT | IRQS_SPURIOUS_DISABLED | IRQS_ONESHOT | IRQS_WAITING` and `IRQD_IRQ_INPROGRESS`, and installing any action must reset `desc->irq_count` and `desc->irqs_unhandled` to 0 (and re-enable `desc` if `shared && (desc->istate & IRQS_SPURIOUS_DISABLED)`). For shared actions, if `old->flags & IRQF_ONESHOT` and `new->flags & IRQF_COND_ONESHOT`, promote `new->flags |= IRQF_ONESHOT` before checking `(old->flags ^ new->flags) & IRQF_ONESHOT`. [F75, F98]
- Adding an `irqaction` to `desc->action` must call `irq_pm_install_action(desc, new)` and removing one in `__free_irq()` or `__cleanup_nmi()` must call `irq_pm_remove_action(desc, action)` under `desc->lock` so `nr_actions` and `*_suspend_depth` counters stay balanced. [F68]
- Shutting down a started IRQ in `irq_shutdown()` must increment `desc->depth` (and aborting managed startup in `irq_startup()` must set `desc->depth = 1` with `IRQD_MANAGED_SHUTDOWN`), while `irq_startup_managed()` must clear `IRQD_MANAGED_SHUTDOWN`, decrement `desc->depth`, and only call `irq_startup()` when `desc->depth == 0`. In `irq_startup()`, normal IRQs must call `irq_setup_affinity(desc)` before `__irq_startup(desc)` when `IRQCHIP_AFFINITY_PRE_STARTUP` is set, and after otherwise. [F64, F136]
- Setting affinity before activation (`alloc_descs()` with `irq_affinity_desc` or `irq_set_affinity_deactivated()` on `IRQD_AFFINITY_ON_ACTIVATE` IRQs) must set `IRQD_AFFINITY_SET` alongside updating `affinity` and `effective_affinity`. In `irq_update_affinity_desc()`, if `irqd_is_activated(&desc->irq_data)` is true, call `irq_domain_deactivate_irq()` before setting `IRQD_AFFINITY_MANAGED | IRQD_MANAGED_SHUTDOWN` and updating `affinity`, then `irq_domain_activate_irq(&desc->irq_data, false)`. [F63, F81]
- In `irq_move_masked_irq()`, `IRQD_SETAFFINITY_PENDING` is cleared before `irq_do_set_affinity(data, desc->pending_mask, false)`; if it returns `-EBUSY`, re-set `IRQD_SETAFFINITY_PENDING` and keep `desc->pending_mask`, otherwise clear `desc->pending_mask`. [F72]
- In `cond_unmask_eoi_irq()`, when `desc->istate & IRQS_ONESHOT` is set and `!irqd_irq_disabled(&desc->irq_data) && irqd_irq_masked(&desc->irq_data) && !desc->threads_oneshot` holds, `chip->irq_eoi(&desc->irq_data)` must be called before `unmask_irq(desc)` even if `IRQCHIP_EOI_THREADED` is set. [F110]
- In `__irq_do_set_handler()`, when installing a chained handler and `irqd_get_trigger_type(&desc->irq_data) != IRQ_TYPE_NONE`, re-assign `desc->handle_irq = handle` after `__irq_set_trigger(desc, type)` and before `desc->action = &chained_action`. Uninstalling a chained handler must clear `desc->action = NULL` and call `irq_chip_pm_put()`. [F74]
- In `irq_sw_resend()`, nested threaded IRQs (`irq_settings_is_nested_thread(desc)`) must redirect `desc` to `irq_to_desc(desc->parent_irq)`, and queueing `desc->resend_node` onto `irq_resend_list` under `irq_resend_lock` must check `hlist_unhashed(&desc->resend_node)` (with `clear_irq_resend()` unlinking it in `irq_shutdown()`). [F71]
- In `suspend_device_irq()`, non-wakeup IRQs on `IRQCHIP_MASK_ON_SUSPEND` chips must call `mask_irq(desc)` in addition to `__disable_irq(desc)`. Disabled wakeup IRQs on `IRQCHIP_ENABLE_WAKEUP_ON_SUSPEND` chips must apply `__enable_irq(desc)` and `IRQD_IRQ_ENABLED_ON_SUSPEND` on suspend, reversed by `__disable_irq(desc)` in `resume_irq()`. In `irq_set_irq_wake()`, reject NMIs with `-EINVAL` and only call `set_irq_wake_real()` on `wake_depth` `0 <-> 1` transitions under `scoped_irqdesc_get_and_buslock()`, rolling back `wake_depth` on error. [F152, F154, F155]
- An initialized `struct irq_desc` never has a NULL `desc->irq_data.chip` because defaults and teardown install `&no_irq_chip`; unassigned-chip checks must test `chip == &no_irq_chip`. `irq_sysfs_del()` must only call `kobject_del(&desc->kobj)` when `desc->istate & IRQS_SYSFS` is set. [F7, F49]
- In `kernel/irq/matrix.c`, `irq_alloc_matrix()` must allocate `2 * BITS_TO_LONGS(matrix_bits)` longs for `scratch_map` and `alloc_map` because `system_map` and `managed_map` alias the second half. Mutating `cm->alloc_map` or `cm->managed_map` must update `cm->available`, `cm->allocated`, `cm->managed`, and `cm->managed_allocated` in lockstep, adjusting `m->global_available` and `m->total_allocated` only when `cm->online` is true (leaving `available`/`global_available` unchanged on managed alloc/free). [F66, F88]
- In `lib/group_cpus.c`, after `sort()` reorders `struct node_groups` by `ncpus`, `alloc_nodes_groups()` and `__group_cpus_evenly()` must skip `UINT_MAX` entries, index `node_to_cpumask` by `nv->id`, and intersect `node_to_cpumask[n]` with `cpu_mask` into `nmsk` before spreading CPUs. [F57, F77]

## Synchronization

- IRQ management paths must lock in the order `desc->request_mutex` -> `chip_bus_lock(desc)` -> `desc->lock` (using `raw_spinlock_irq` or `raw_spinlock_irqsave` in process context), and slow-bus `irq_chip` callbacks (`irq_set_wake`, `irq_set_type`, `irq_get_irqchip_state`) must use `scoped_irqdesc_get_and_buslock()`. `scoped_irqdesc_get_and_lock()` / `buslock()` callers must not re-lock `desc->lock` manually, and `class_irqdesc_lock_constructor()` must finish the `class_irqdesc_lock_t _t` initializer before calling `__irq_get_desc_lock(irq, &_t.flags, ...)`. [F22, F23, F40, F156]
- In `__free_irq()`, release `desc->lock` and `chip_bus_sync_unlock(desc)` (keeping `desc->request_mutex`) before `__synchronize_irq(desc)` and `kthread_stop_put(action->thread)`, then reacquire both to deactivate when `!desc->action`; in both `__setup_irq()` error paths and `__free_irq()`, `irq_release_resources(desc)` must be called after unlocking `desc->lock` and before `chip_bus_sync_unlock(desc)`. [F4, F162]
- Any loop waiting for `irqd_irq_inprogress(&desc->irq_data)` to clear (`irq_wait_on_inprogress()`, `__synchronize_hardirq()`, `irq_finalize_oneshot()`) must drop `desc->lock` (and `chip_bus_sync_unlock(desc)` in `irq_finalize_oneshot()`) before spinning, then relock and recheck state: `irq_wait_on_inprogress()` rechecks `!irqd_irq_disabled() && desc->action`; `irq_finalize_oneshot()` rechecks `IRQTF_RUNTHREAD` before clearing `thread_mask` and unmasking; `__synchronize_hardirq()` rechecks `irqd_irq_inprogress()` and, if `sync_chip`, queries `IRQCHIP_STATE_ACTIVE` under `desc->lock`. [F27, F28, F34, F108]
- Because `handle_irq_event()` drops and reacquires `desc->lock`, the `IRQS_PENDING` retry loops in `handle_edge_irq()` and `try_one_irq()` must re-verify `desc->action` on every iteration (and `!irqd_irq_disabled(&desc->irq_data)` in `handle_edge_irq()`). [F109]
- `irq_set_thread_affinity()` runs under `desc->lock` and must only set `IRQTF_AFFINITY` and wake kthreads; `irq_thread_check_affinity()` copies the mask under `desc->lock` and calls `set_cpus_allowed_ptr()` after unlocking. `sched_set_fifo(current)` must run inside `irq_thread()`, not `setup_irq_thread()`. `irq_forced_thread_fn()` must wrap `irq_thread_fn()` with `local_bh_disable()` and (on `!CONFIG_PREEMPT_RT`) `local_irq_disable()`. [F29, F159, F160]
- `irq_resend_lock` nests inside `desc->lock`, so `resend_irqs()` must `hlist_del_init(&desc->resend_node)` under `irq_resend_lock` and drop `irq_resend_lock` before calling `desc->handle_irq(desc)`. In `suspend_device_irqs()`, `desc->lock` must be released after `suspend_device_irq(desc)` before calling `synchronize_irq(irq)`. `probe_irq_on()` holds `probing_active` mutex until `probe_irq_off()` or `probe_irq_mask()`. [F18, F35, F37]
- Unserialized flow handlers (`handle_percpu_irq`, `handle_percpu_devid_irq`, `handle_fasteoi_nmi`, `handle_percpu_devid_fasteoi_nmi`) must call `__kstat_incr_irqs_this_cpu(desc)` without touching `desc->tot_count`, and `kstat_irqs_desc()` must sum per-CPU counts when `_IRQ_PER_CPU`, `_IRQ_PER_CPU_DEVID`, or `IRQS_NMI` is set. [F65]

## Object Lifetimes

- Callers of `__setup_irq()` must call `irq_chip_pm_get(&desc->irq_data)` beforehand and `irq_chip_pm_put()` if `__setup_irq()` fails (teardown drops it on success). `request_threaded_irq()` must `kfree(action->secondary)` when `__setup_irq()` fails. `setup_irq_thread()` calls `get_task_struct(t)`, so teardown and error rollback must use `kthread_stop_put()`, `__setup_irq()` must call `wake_up_and_wait_for_irq_thread_ready()`, and `irq_thread()` must register `irq_thread_dtor` via `task_work_add()` and cancel it via `task_work_cancel_func()` on normal exit. [F1, F2, F3, F14, F25]
- Under `CONFIG_SPARSE_IRQ`, `sparse_irqs` lookups and `desc` dereferences racing with `free_desc()` must hold RCU or `sparse_irq_lock`. `free_desc()` must remove debugfs, procfs, and sysfs entries before `delete_irq_desc(irq)` and free `desc`, cpumasks, and `kstat_irqs` via `call_rcu(&desc->rcu, delayed_free_desc)`. [F30, F158]
- `irq_shutdown_and_deactivate()` must call `irq_domain_deactivate_irq(&desc->irq_data)` unconditionally after `irq_shutdown(desc)` even when `!irqd_is_started(&desc->irq_data)`. In `migrate_one_irq()`, `irq_force_complete_move(desc)` must run before checking `irqd_is_per_cpu(d) || !irqd_is_started(d) || !irq_needs_fixup(d)`. [F9, F11]
- `irq_set_affinity_notifier()` must initialize `notify` before taking `desc->lock` to swap `desc->affinity_notify`, and call `cancel_work_sync(&old_notify->work)` and `kref_put()` after unlocking (dropping an extra kref if `cancel_work_sync()` returns true). Callers must clear `affinity_notify` and `affinity_hint` before `free_irq()`. Callers of `free_percpu_irq()` / `free_percpu_nmi()` must first disable the IRQ on all CPUs so `desc->percpu_enabled` is empty. [F13, F19, F33]
- `irq_domain_alloc_generic_chips()` allocates `dgc` and `numchips` variable-sized `gc` structs (`struct_size(gc, chip_types, info->num_ct)`) in one block (stepping `dgc->gc[i]` by `gc_sz` and freeing only via `kfree(dgc)`) using `raw_spinlock_irqsave` for `gc_lock` and `gc->lock`. `irq_remove_generic_chip()` must call `irq_set_handler(virq, NULL)` before `irq_set_chip(virq, &no_irq_chip)`. `irq_domain_remove_sim()` must call `irq_work_sync(&work_ctx->work)` before freeing `work_ctx` or removing the domain. [F17, F38, F126, F138, F143, F157]

## API Contracts

- `request_threaded_irq()` requires non-NULL `dev_id` with `IRQF_SHARED`, forbids `IRQF_SHARED | IRQF_NO_AUTOEN` and `IRQF_COND_SUSPEND | IRQF_NO_SUSPEND`, requires `IRQF_SHARED` with `IRQF_COND_SUSPEND`, and requires `IRQF_ONESHOT` when `handler == NULL` unless `IRQCHIP_ONESHOT_SAFE` is set. `devm_request_*_irq()` IRQs must be freed with `devm_free_irq()`. `_IRQ_PER_CPU_DEVID` IRQs must use `IRQ_GET_DESC_CHECK_PERCPU` and `handle_percpu_devid_*()` handlers; global APIs must pass `IRQ_GET_DESC_CHECK_GLOBAL`. [F15, F51, F131, F185]
- `irq_data_get_*(struct irq_data *d)` accessors unconditionally dereference `d`, so callers (`ipi_send_verify()`, `ipi_send_single()`, `ipi_get_hwirq()`) must check `d != NULL` first. `irq_can_handle*()` return `true` when an IRQ can be serviced (`if (!irq_can_handle*(desc)) return;`). [F42, F97]
- In `irq_do_set_affinity()`, `force == false` filters `prog_mask` by `cpu_online_mask` (`-EINVAL` if empty), whereas `force == true` passes `mask` directly. `irq_set_affinity_deactivated()` only defers `chip->irq_set_affinity()` when `CONFIG_IRQ_DOMAIN_HIERARCHY`, `!irqd_is_activated(data)`, and `irqd_affinity_on_activate(data)` hold. `IRQ_SET_MASK_OK` and `IRQ_SET_MASK_OK_DONE` update state and fall through to `IRQ_SET_MASK_OK_NOCOPY` (which resets `ret = 0`); `irq_set_affinity` must populate `effective_affinity`. [F43, F100, F112, F179, F180]
- In `struct irq_chip_generic` (max 32 IRQs per chip), `gc->irq_base` is a domain hwirq base when `gc->domain != NULL` (requiring `irq_find_mapping()`), `d->mask` is `1 << idx`, `ct->mask_cache` is initialized under `gc->lock` when `!gc->installed`, and `irq_chip_regs` offsets are in bytes. [F41, F58, F73, F118, F127, F150]
- Wildcard Linux IRQ allocation (`irq_alloc_desc()`) passes `from = 1`, whereas hwirq `0` is valid and `ipi_get_hwirq()` returns `INVALID_HWIRQ` (`~0UL`) on failure. `group_cpus_evenly()` returns `NULL` if `numgrps == 0`, and callers must bound iteration by `*nummasks`. [F48, F82, F84, F132]

## Error Handling

- Because `scoped_irqdesc_get_and_lock()` and `scoped_irqdesc_get_and_buslock()` skip their body when `__irq_get_desc_lock()` returns `NULL`, any status variable returned after the block must default to an error before the guard. [F50]
- `request_any_context_irq()` returns `0` (`IRQC_IS_HARDIRQ`) or `1` (`IRQC_IS_NESTED`) on success and `< 0` on error; wrappers (`devm_request_result()`) must test `rc < 0` and preserve positive `rc`. `__irq_get_domain_generic_chip()` returns `ERR_PTR`, whereas `irq_get_domain_generic_chip()` returns `NULL`. Callers of `__irq_get_irqchip_state()` and `irq_chip_get_parent_state()` must initialize `*state` before the call. [F44, F47, F55]
- `matrix_alloc_area()` returns `>= m->alloc_end` and `matrix_find_best_cpu*()` returns `UINT_MAX` on failure; `irq_matrix_alloc*()` must return `-ENOSPC`, and `irq_matrix_reserve_managed()` error unwind must stop `irq_matrix_remove_managed()` at `cpu == failed_cpu`. [F59, F60]

## Known Pitfalls

- In `note_interrupt()`, use `if (action_ret == IRQ_WAKE_THREAD)` inside `if (action_ret & IRQ_WAKE_THREAD)` so `SPURIOUS_DEFERRED` is only used when no primary handler returned `IRQ_HANDLED`, compare `desc->threads_handled_last` with `!=` (bit 31 is `SPURIOUS_DEFERRED`), and use `time_after()` for `jiffies`. [F111, F123]
- In `__setup_irq()`, all `goto mismatch;` branches must precede the `do { ... } while (old);` loop because `old` is `NULL` after it, and `IRQF_ONESHOT` bitmask allocation must check `thread_mask == ~0UL` and shift `1UL << ffz(thread_mask)`. [F99, F115]
- `try_retrigger()` and `irq_chip_retrigger_hierarchy()` return `0` on failure and non-zero on success, whereas `irq_sw_resend()` returns `0` on success and `< 0` on error. `irq_chip_shutdown_parent()` / `startup_parent()` pass `data` (not `parent`) to fallback `irq_chip_disable_parent()` / `enable_parent()`. [F46, F104]
- `irq_matrix_alloc*()` must check `cpumask_empty(msk)` before `matrix_find_best_cpu*()` (`for_each_cpu()` ignores `msk` on `SMP=n`). `__ipi_send_mask()` must save `base = data->irq` before the loop overwrites `data`. `for_each_irq_desc_reverse(irq, desc)` requires a signed `int irq`. [F87, F101, F106]
