# DRM DRIVER FOR GENERIC USB DISPLAY

The GUD (Generic USB Display) driver implements a DRM/KMS display driver for USB-connected displays using a vendor-specific USB control and bulk protocol defined in `include/drm/gud.h`. It probes device descriptors, supported pixel formats, properties, and connectors over USB control transfers, and flushes damaged framebuffer rectangles (with optional pixel format conversion and LZ4 compression) over USB bulk transfers either synchronously or via an asynchronous workqueue.

## Architecture & Data Flow

- Every non-backlight connector property in `gud_connector_add_properties()` must have matching cases in `gud_connector_property_lookup()`, `gud_connector_tv_state_val()`, and `gud_connector_atomic_check()`, and every device property in `gud_get_properties()` must have a case in `gud_plane_atomic_check()`. Unknown property IDs must be skipped without adding them to `gdrm->properties` or `gconn->properties`, as `gud_plane_atomic_check()` and `gud_connector_fill_properties()` fail with `-EINVAL` (and `WARN_ON_ONCE`) on unrecognized IDs. [F41, F91]
- In `gud_connector_add_properties()`, `GUD_PROPERTY_BACKLIGHT_BRIGHTNESS` `val` must be validated `<= 100` before narrowing to signed `int gconn->initial_brightness`, and recorded in `gconn->properties` (with `initial_brightness` copied to `connector->state->tv.brightness`) without calling `gud_connector_property_lookup()` or attaching a DRM property. `gconn->initial_brightness` must be initialized to `-ENODEV` in `gud_connector_create()` (`0` is valid), and `gconn->backlight` assigned in `gud_connector_backlight_register()` only after `!IS_ERR(bd)`. [F29, F72, F92]
- Any change to plane or connector state serialized into `struct gud_state_req` must set `crtc_state->mode_changed = true` (in `gud_plane_atomic_check()`) or `new_crtc_state->connectors_changed = true` (in `gud_connector_atomic_check()`) so `GUD_REQ_SET_STATE_CHECK` and `GUD_REQ_SET_STATE_COMMIT` run in lockstep. [F40]
- Internal transfer formats `GUD_DRM_FORMAT_R1` and `GUD_DRM_FORMAT_XRGB1111` in `gud_probe()` must update `xrgb8888_emulation_format` and `max_buffer_size` in the format loop and `continue` before `formats[num_formats++]` so they are never exposed to DRM. Every `xrgb8888_emulation_format` must have an XRGB8888 conversion branch in `gud_prep_flush()` (and `gud_xrgb8888_to_color()` for sub-byte color formats), and `formats` must be allocated with `GUD_FORMATS_MAX_NUM + 1` elements for emulated `DRM_FORMAT_XRGB8888`. [F42, F49, F62]
- `gdrm->compress_buf` and `gdrm->lz4_comp_mem` are allocated in `gud_probe()` only when `gdrm->compression & GUD_COMPRESSION_LZ4` is set and remain `NULL` otherwise; `gud_prep_flush()` must only dereference them when compression is enabled, and when `LZ4_compress_default()` fails (`complen <= 0`), the `retry` path must clear local `compression = 0`, rebind `buf` and `dst` to `gdrm->bulk_buf`, and re-populate `gdrm->bulk_buf` and `req` with uncompressed data. [F27, F39]
- `gud_alloc_bulk_buffer()` must allocate `gdrm->bulk_buf` with `vmalloc_32()` rather than `vmalloc()`, and step `void *ptr` by `PAGE_SIZE` across `num_pages = DIV_ROUND_UP(gdrm->bulk_len, PAGE_SIZE)` pages via `vmalloc_to_page()`, so `gdrm->bulk_sgt` pages are 32-bit addressable (non-highmem) for `usb_sg_init()` in `gud_usb_bulk()`. [F80, F99]
- In `gud_probe()`, `drm_mode_config_reset(drm)` must run only after `gud_get_connectors(gdrm)` populates `gconn->initial_tv_state` and `gconn->initial_brightness`. Inside `gud_connector_reset()`, `connector->state->tv = gconn->initial_tv_state` must be applied before `drm_atomic_helper_connector_tv_margins_reset(connector)` and before restoring `connector->state->tv.brightness = gconn->initial_brightness` (when `>= 0`). [F43, F88]
- Connectors must be registered with `drm_connector_init()` in the exact 0-based order returned by `GUD_REQ_GET_CONNECTORS` without any prior connectors on `gdrm->drm`, because `connector->index` is passed directly as the USB protocol connector index (`wValue`) in connector and state requests. [F93]
- When `GUD_DISPLAY_FLAG_FULL_UPDATE` is set in `gdrm->flags`, `gud_flush_rect()` skips `GUD_REQ_SET_BUFFER` unless `gdrm->prev_flush_failed` is true, so `gud_flush_damage()` must set `gdrm->prev_flush_failed = true` whenever `gud_flush_rect()` returns an error. [F44]
- When splitting a damage rectangle in `gud_flush_damage()`, `lines` must use truncating division (`gdrm->bulk_len / pitch`), the loop bound must use `DIV_ROUND_UP(drm_rect_height(damage), lines)` with `rect.y2` clamped to `damage->y2`, and each iteration must re-initialize `struct drm_rect rect = *damage` before `rect.y1 += i * lines` and `gud_flush_rect()` (which may mutate `rect.x1`). [F63, F70]

## Synchronization

- `gud_fb_queue_damage()` and `gud_flush_work()` must hold `gdrm->damage_lock` while accessing `gdrm->fb`, `gdrm->damage`, and `gdrm->shadow_buf`. `gdrm->fb` holds at most one reference: `gud_fb_queue_damage()` only gets `fb` and puts the old `gdrm->fb` when `fb != gdrm->fb`, while `gud_flush_work()` moves `gdrm->fb` to a local variable (`gdrm->fb = NULL`) and resets `gdrm->damage` via `gud_clear_damage(gdrm)` (`x1 = y1 = INT_MAX`, `x2 = y2 = 0`) before unlocking, checking `fb != NULL` (`shadow_buf` may be `NULL` when `fb` is `NULL`), and calling `gud_flush_damage()`. [F3, F16, F28, F37]
- `gud_plane_atomic_update()` brackets `gud_fb_handle_damage()` with `drm_gem_fb_begin_cpu_access(fb, DMA_FROM_DEVICE)` and `drm_gem_fb_end_cpu_access(fb, DMA_FROM_DEVICE)`. Therefore, asynchronous flushing via `gud_fb_queue_damage()` must copy framebuffer pixels into `gdrm->shadow_buf` synchronously while CPU access is active, and `gud_flush_work()` must only read from `gdrm->shadow_buf`. [F105, F113]
- In `gud_usb_transfer()`, `gdrm->ctrl_lock` must be held continuously across `gud_usb_control_msg()` and the follow-up `gud_usb_get_status()` call whenever a control transfer fails with `-EPIPE` or `GUD_DISPLAY_FLAG_STATUS_ON_SET` is set on an OUT transfer. [F13]
- `gud_connector_backlight_update_status()` must defer DRM atomic commits to `gud_connector_backlight_update_status_work()` via `gconn->backlight_work` rather than acquiring DRM modeset locks directly (avoiding lock inversion with backlight locks). When `drm_atomic_get_connector_state()` or `drm_atomic_commit()` returns `-EDEADLK` in `gud_connector_backlight_update_status_work()`, the worker must call `drm_atomic_state_clear(state)` and `drm_modeset_backoff(&ctx)` before jumping to `retry` to re-fetch `connector_state` and re-read `gconn->backlight->props.brightness`. [F20, F101]
- `gud_probe()` must initialize `gdrm->ctrl_lock` and `gdrm->flags` before calling `gud_usb_get()`, `gud_usb_set()`, `gud_get_properties()`, or `gud_get_connectors()`, and must initialize `gdrm->damage_lock`, `gdrm->work`, and `gud_clear_damage(gdrm)` before `drm_dev_register()`. [F21]
- `gud_disconnect()` must call `drm_kms_helper_poll_fini()` and `drm_dev_unplug()` before `drm_atomic_helper_shutdown()`. [F19]

## Object Lifetimes

- In `gud_plane_atomic_update()`, when `crtc->state->mode_changed || !crtc->state->enable`, `cancel_work_sync(&gdrm->work)` must run outside `gdrm->damage_lock` before `vfree(gdrm->shadow_buf)`, and both `gdrm->shadow_buf` and `gdrm->fb` (after `drm_framebuffer_put()`) must be reset to `NULL` under `gdrm->damage_lock`. This block must run before `drm_dev_enter(drm, &idx)` so `drm_atomic_helper_shutdown()` cleans up async state after `drm_dev_unplug()` in `gud_disconnect()`. [F2, F81]
- In `gud_connector_early_unregister()`, `backlight_device_unregister(gconn->backlight)` must be called before `cancel_work_sync(&gconn->backlight_work)` so `gud_connector_backlight_update_status()` cannot re-queue `gconn->backlight_work` after cancellation. [F83]
- `struct gud_connector` (`gconn`, where `struct drm_connector connector` must remain the first member) and `gconn->properties` must be allocated with unmanaged `kzalloc()`/`kcalloc()` and freed only in `gud_connector_destroy()` (or via `kfree(connector)` before `drm_connector_init()` succeeds), never via `devm_*` or on error paths after `drm_connector_init()` succeeds. [F78, F85]
- In `gud_probe()`, `mutex_init(&gdrm->ctrl_lock)` and `devm_add_action(dev, gud_free_buffers_and_mutex, gdrm)` must run before `gud_alloc_bulk_buffer()` and `gdrm->compress_buf = vmalloc(...)` so `bulk_buf`, `bulk_sgt`, `compress_buf`, and `ctrl_lock` are freed on probe failure or unbind. The `dma_dev` returned by `usb_intf_get_dma_device(intf)` must be released with `put_device(dma_dev)` immediately after `drm_dev_set_dma_dev(drm, dma_dev)`. [F86, F87]
- In `gud_usb_bulk()`, `ctx.timer` must be initialized with `timer_setup_on_stack()` only after `usb_sg_init(&ctx.sgr, ...)` succeeds, and must be stopped with `timer_delete_sync(&ctx.timer)` and destroyed with `timer_destroy_on_stack(&ctx.timer)` after `usb_sg_wait(&ctx.sgr)` before returning. [F97]
- In `gud_flush_damage()`, `fmtcnv_state` must be initialized with `DRM_FORMAT_CONV_STATE_INIT` and released via `drm_format_conv_state_release(&fmtcnv_state)` after the `gud_flush_rect()` loop on both normal completion and error `break` paths. [F12]
- In `gud_plane_atomic_check()`, `connector_state` must be initialized to `NULL` before `for_each_new_connector_in_state()`, and if no connector with a CRTC is found in `state`, it must fall back to iterating `plane->dev` connectors with `drm_connector_list_iter_begin()`/`drm_connector_list_iter_end(&conn_iter)`, breaking out of the loop rather than returning directly so `drm_connector_list_iter_end()` always runs. [F65, F110]

## API Contracts

- Buffers passed to `gud_usb_get()`, `gud_usb_transfer()`, or `gud_usb_control_msg()` must be heap-allocated (DMA-capable) rather than stack-allocated; callers with stack buffers must use `gud_usb_get_u8()`, `gud_usb_set()`, or `gud_usb_set_u8()`. [F94]
- In `gud_usb_transfer()`, the `u16 index` parameter (carrying the connector index for `GUD_REQ_*_CONNECTOR_*` requests) is passed as `wValue` (`value`) of `gud_usb_control_msg()`, while `wIndex` in `usb_control_msg()` is always the USB interface number `bInterfaceNumber`. [F35]
- Callers of `gud_usb_get()` that receive arrays of fixed-size wire structures (`gud_get_properties()`, `gud_connector_get_modes()`, `gud_connector_add_tv_mode()`, `gud_connector_add_properties()`, and `gud_get_connectors()`) must verify `ret > 0 && ret % sizeof(*elem) == 0` before dividing to get the element count, and functions returning `ret` must reset `ret = 0` after validating a positive byte count. [F23, F47]
- When copying damaged pixels into `gdrm->shadow_buf` in `gud_fb_queue_damage()`, `shadow_map` must be advanced by `drm_fb_clip_offset()` and passed to `drm_fb_memcpy()` with `dst_pitch = fb->pitches`, whereas `gud_flush_work()` must pass the un-offset base of `gdrm->shadow_buf` to `gud_flush_damage()` where `gud_prep_flush()` passes `dst_pitch = NULL`. [F34]
- In `gud_plane_atomic_check()`, `struct gud_state_req *req` must be allocated with `struct_size(req, properties, size_add(GUD_PROPERTIES_MAX_NUM, GUD_CONNECTOR_PROPERTIES_MAX_NUM))` and sent to `gud_usb_set()` with `struct_size(req, properties, num_properties)`. [F73]
- In `gud_get_properties()`, the device-reported `GUD_PROPERTY_ROTATION` value must be masked with `GUD_ROTATION_MASK` before passing it to `drm_plane_create_rotation_property()`. [F107]
- In `gud_connector_detect()`, when `GUD_REQ_GET_CONNECTOR_STATUS` has `GUD_CONNECTOR_STATUS_CHANGED` set, `connector->epoch_counter` must be incremented so DRM probe helpers emit a hotplug uevent even if the connection status did not change. [F111]

## Error Handling

- In `gud_usb_transfer()`, when `gud_usb_get_status()` runs after a stalled (`-EPIPE`) transfer or a `GUD_DISPLAY_FLAG_STATUS_ON_SET` OUT transfer, `ret` must only be overwritten with `status` when `status < 0`, and if `status >= 0` while `ret < 0`, `ret` must be forced to `-EPIPE`. Broken by: unconditionally setting `ret = gud_usb_get_status(intf)`, which turns a stalled transfer with `GUD_STATUS_OK` into `0` and zeroes the byte-count return of successful OUT transfers so `gud_usb_set()` fails with `-EIO`. [F57]
- `gud_connector_property_lookup()` and `gud_connector_tv_state_val()` return `ERR_PTR(-EINVAL)` rather than `NULL` for unrecognized property IDs (requiring `IS_ERR()`), `gud_connector_fill_properties()` returns a non-negative count or negative errno (requiring a signed `< 0` check), and `gud_xrgb8888_to_r124()` returns `size_t` `0` on `kmalloc()` failure (requiring `!len` translation to `-ENOMEM`). [F25, F26]

## External Contracts

- In `gud_get_display_descriptor()` and `gud_probe()`, a display descriptor with both `GUD_DISPLAY_FLAG_FULL_UPDATE` and compression enabled must be rejected, and `max_buffer_size` must be capped to `SZ_64M` before allocating `bulk_buf` and `compress_buf`. [F55]
- Conversions between `drm_display_mode` and `gud_display_mode_req` in `gud_from_display_mode()` and `gud_to_display_mode()` must mask mode flags with `GUD_DISPLAY_MODE_FLAG_USER_MASK` and map `DRM_MODE_TYPE_PREFERRED` to and from `GUD_DISPLAY_MODE_FLAG_PREFERRED`. [F54]

## Known Pitfalls

- In `gud_xrgb8888_to_r124()` and `gud_xrgb8888_to_color()`, `rect->x1` must be aligned down to `block_width` in place before computing `width` and `len`, and `format` must have `char_per_block[0] == 1` with `block_width` dividing 8. Because these helpers OR bits into reused buffers (`*block |= pix << pixshift`), they must zero `*block = 0` at the start of every byte (`!pixpos`), and `gud_prep_flush()` must set `gud_set_buffer_req` (`x`, `y`, `width`, `height`, `length`) and LZ4 input length only after conversion. [F32, F51, F71]
- In `gud_xrgb8888_to_color()`, the byte row offset `y * fb->pitches[0]` must be added to the byte-addressed `void *src` pointer before assigning to `__le32 *sbuf32`, while the pixel X offset `rect->x1` must be added to `sbuf32` so it scales by `sizeof(__le32)`. [F76]
- Stack-allocated `struct iosys_map` variables in `gud_pipe.c` must be initialized via `iosys_map_set_vaddr()` or zero-initialization before being passed to `iosys_map_incr()` or `drm_fb_*` helpers so `is_iomem` is never read uninitialized. [F33]
- In `gud_plane_atomic_check()`, `old_fb->format != format` must be compared while `format` still holds `new_plane_state->fb->format`, before `format` is reassigned to `gdrm->xrgb8888_emulation_format` for `gud_from_fourcc(format->format)`. [F66]
- In `gud_connector_get_modes()`, `edid_ctx.edid_override` must be initialized to `true` before `drm_edid_read_custom()` and set to `false` inside `gud_connector_get_edid_block()`, and `GUD_REQ_GET_CONNECTOR_MODES` must be skipped when `drm_edid && edid_ctx.edid_override` so `drm_edid_connector_add_modes()` is used at `out`. [F64]
- In `gud_flush_rect()`, when `gdrm->stats_length += len` wraps (`gdrm->stats_length <= len && gdrm->stats_actual_length`), `stats_length` and `stats_actual_length` must be reset together (`stats_length = len`, `stats_actual_length = 0`) before adding `trlen`; in `gud_stats_debugfs()`, 64-bit divisions on these counters must use `div64_u64_rem()` and `div64_u64()` rather than `/` or `%`. [F45, F67]
