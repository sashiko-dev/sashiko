# STMMAC ETHERNET DRIVER

This driver manages the `net_device` lifecycle, NAPI/page_pool/XDP/AF_XDP zero-copy TX and RX datapaths, phylink/PCS/MDIO bus glue, PTP 1588 hardware clocks, TC hardware offloads (u32, flower, CBS, ETF, taprio/EST, mqprio), VLAN filtering, ethtool selftests, and platform/PCI integration for Synopsys DesignWare Ethernet (DWMAC/DWXGMAC) controllers.

## Architecture & Data Flow

- In `struct stmmac_tx_queue`, `tx_skbuff` and `xdpf` share an anonymous union discriminated per slot by `tx_q->tx_skbuff_dma[entry].buf_type` (`STMMAC_TXBUF_T_SKB` for `tx_skbuff`, `STMMAC_TXBUF_T_XDP_TX` or `STMMAC_TXBUF_T_XDP_NDO` for `xdpf`, and neither for `STMMAC_TXBUF_T_XSK_TX`). Never read or free `tx_skbuff[entry]` or `xdpf[entry]` without checking `buf_type`. [F34]
- In `stmmac_setup_dma_desc()`, `STMMAC_TBS_AVAIL` must be set on `dma_conf->tx_queue[chan].tbs` before `alloc_dma_desc_resources()` runs, because `__alloc_dma_tx_desc_resources()` and `__free_dma_tx_desc_resources()` size the coherent TX ring (`struct dma_edesc` vs `struct dma_desc`) and select `dma_entx` vs `dma_tx` from `tx_q->tbs`. In `stmmac_hw_setup()`, `stmmac_enable_tso()` must skip any channel with `tx_q->tbs & STMMAC_TBS_AVAIL`. [F61, F117]
- Before `__stmmac_open()` overwrites `priv->dma_conf` via `memcpy()`, it must copy any `tx_queue[i].tbs` with `STMMAC_TBS_EN` from `priv->dma_conf` into the new `dma_conf` so ETF offload survives reopen/MTU change. Every full ring init/reinit path (`__stmmac_open()`, `stmmac_xdp_open()`, `stmmac_resume()`) must call `stmmac_reset_queues_param(priv)` to reset `cur_rx`, `dirty_rx`, `cur_tx`, `dirty_tx`, `mss`, and BQL in lockstep. [F48, F49]
- In `stmmac_tso_xmit()`, any VLAN tag in `skb` must be pushed into the payload via `__vlan_hwaccel_push_inside(skb)` before computing `proto_hdr_len`, `pay_len`, or mapping `skb->data`. Each DMA address `des` must be saved to `tx_q->tx_skbuff_dma[tx_q->cur_tx].buf` only after `stmmac_tso_allocator()` advances `tx_q->cur_tx` to that buffer's last descriptor, and `tx_q->tx_skbuff[tx_q->cur_tx] = skb` must be set only on the frame's final descriptor. [F57, F100]
- `STMMAC_GET_ENTRY(x, size)` wraps ring indices via `((x + 1) & (size - 1))`, so `dma_tx_size` and `dma_rx_size` must be powers of two, and `stmmac_tx_avail()` / `stmmac_rx_dirty()` must handle wrap-around. In `stmmac_rx()`, the NAPI poll `limit` must be capped to `min(priv->dma_conf.dma_rx_size - 1, (unsigned int)limit)` so `cur_rx` cannot wrap onto `dirty_rx`, and `read_again:` must precede `if (count >= limit) break;`. [F70, F86, F115]
- When `stmmac_rx()` or `stmmac_rx_zc()` exits its polling loop before the last segment of a multi-descriptor frame (`status & rx_not_ls`, or non-NULL `skb` in `stmmac_rx()`), it must save `error`, `len`, and `skb` into `rx_q->state` and set `rx_q->state_saved = true`. [F62]
- `struct stmmac_xdp_buff` must keep `struct xdp_buff xdp` at offset 0 and satisfy `XSK_CHECK_PRIV_TYPE(struct stmmac_xdp_buff)` (`<= offsetofend(struct xdp_buff_xsk, cb)`), because `xsk_buff_to_stmmac_ctx()` overlays it onto `xdp_buff_xsk` and `stmmac_xdp_rx_timestamp()` casts `const struct xdp_md *` to `const struct stmmac_xdp_buff *`. [F124]
- In `stmmac_xdp_enable_pool()` and `stmmac_xdp_disable_pool()`, the queue bit in `priv->af_xdp_zc_qps` must be updated only after stopping the old NAPI/DMA queues and before `stmmac_enable_rx_queue()` / `stmmac_enable_tx_queue()`. In `stmmac_enable_rx_queue()` and `stmmac_xdp_open()`, `rx_q->xsk_pool` must be paired with `rx_q->buf_alloc_num > 0` before setting `xsk_pool_get_rx_frame_size(rx_q->xsk_pool)` via `stmmac_set_dma_bfsize()`. [F46, F55]
- In `__alloc_dma_rx_desc_resources()`, `pp_params.flags` must always include both `PP_FLAG_DMA_MAP` and `PP_FLAG_DMA_SYNC_DEV`, and when Header-Payload Split (`priv->sph`) is enabled, `pp_params.offset` must be `0` and `pp_params.max_len` increased by `stmmac_rx_offset(priv)`. [F154]
- `stmmac_msi_intr_rx()` and `stmmac_msi_intr_tx()` recover `priv` via runtime-indexed `container_of(rx_q, struct stmmac_dma_conf, rx_queue[rx_q->queue_index])` (and `tx_queue`), so `queue_index` must equal the array index passed as `dev_id` to `request_irq()`. In `stmmac_reinit_queues()`, `stmmac_napi_del(dev)` must run before mutating `rx_queues_to_use` or `tx_queues_to_use` and `stmmac_napi_add(dev)` after. [F54, F123]
- Because `tc_taprio_configure()` zeroes `priv->est` via `memset(priv->est, 0, sizeof(*priv->est))`, `priv->est_lock` must live in `struct stmmac_priv`, never in `struct stmmac_est`. In `stmmac_adjust_time()`, if `priv->est` is enabled, the driver must disable EST under `priv->est_lock`, adjust systime under `priv->ptp_lock`, and recompute `priv->est->btr` from `btr_reserve` and current PTP time before re-enabling EST. [F50, F53]
- `struct stmmac_tc_entry::val` must remain a 16-byte `__packed` struct matching the 4-word hardware RX Parser layout written as `u32 *` to `MTL_RXP_IACC_DATA` by `dwmac5_rxp_update_single_entry()`. In `tc_init()`, `priv->tc_entries[count - 1]` is reserved as a catch-all (`in_use = true`, `is_last = true`) via `tc_fill_all_pass_entry()`, and `tc_find_entry()` must never allocate the `is_last` slot to a user filter. [F77, F78]

## Synchronization

- TX descriptor rings are shared across the netdev stack, XDP TX/redirect, and NAPI/AF_XDP zero-copy transmit: `stmmac_tx_clean()` must hold `__netif_tx_lock_bh()` and `stmmac_xdp_xmit_back()` / `stmmac_xdp_xmit()` must hold `__netif_tx_lock()` across all accesses to `tx_q->cur_tx`, `tx_q->dirty_tx`, and TX descriptors. Every call to `stmmac_enable_dma_irq()` or `stmmac_disable_dma_irq()` on an active channel must be serialized by `spin_lock_irqsave(&ch->lock, flags)`. [F16, F145]
- In `stmmac_tso_xmit()` and `stmmac_xmit()`, fragment descriptors must be prepared and `tx_q->cur_tx` advanced before setting the OWN bit on `first`, and `stmmac_flush_tx_descriptors()` must execute `wmb()` before writing the TX tail pointer. In `stmmac_tx_clean()`, `dma_rmb()` must run after `stmmac_tx_status()` sees `tx_dma_own` cleared and before reading timestamp/status fields, while `stmmac_rx_refill()` and `stmmac_rx_refill_zc()` must execute `dma_wmb()` before `stmmac_set_rx_owner()`. [F18, F19]
- `stmmac_dvr_probe()` must not set `NETDEV_XDP_ACT_NDO_XMIT` in `ndev->xdp_features`; `stmmac_xdp_set_prog()` must call `xdp_features_clear_redirect_target(dev)` when `prog` is NULL and `xdp_features_set_redirect_target(dev, false)` only after `xchg(&priv->xdp_prog, prog)` and `stmmac_xdp_open(dev)` complete. Disabling an XSK pool in `stmmac_xdp_disable_pool()` or disabling queues while any `rx_q->xsk_pool` is active in `stmmac_disable_all_queues()` requires `synchronize_rcu()` before unmapping or teardown. [F14, F152]
- In `stmmac_resume()`, `phylink_prepare_resume()` must run before `stmmac_hw_setup()` so PHY clocks required for MAC DMA reset are running, while `phylink_resume()` must run only after `stmmac_hw_setup()`, `stmmac_enable_all_queues()`, and `stmmac_enable_all_dma_irq()` complete and `priv->lock` is released. [F134]

## Object Lifetimes

- `stmmac_setup_dma_desc()` populates a temporary `struct stmmac_dma_conf` that `__stmmac_open()` shallow-copies via `memcpy(&priv->dma_conf, dma_conf, sizeof(*dma_conf))` without freeing DMA resources on failure: callers (`stmmac_open()`, `stmmac_change_mtu()`) must call only `kfree(dma_conf)` on success, but `free_dma_desc_resources(priv, dma_conf)` before `kfree(dma_conf)` on error. `stmmac_init_coalesce()` and `stmmac_request_irq_multi_msi()` must run on `priv->dma_conf` after that `memcpy()`. [F2, F118]
- `free_dma_desc_resources()` must call `free_dma_tx_desc_resources()` before `free_dma_rx_desc_resources()` so pending `XDP_TX` frames in `tx_q->xdpf[]` return to their RX page pool before `rx_q->page_pool` is destroyed. In `stmmac_tx_clean()` and `stmmac_free_tx_buffer()`, descriptors with `buf_type == STMMAC_TXBUF_T_XDP_TX` must never be passed to `dma_unmap_single()` or `dma_unmap_page()`. [F4, F5]
- During teardown in `__stmmac_release()` and `stmmac_xdp_release()`, `stmmac_disable_all_queues()` and `hrtimer_cancel(&priv->dma_conf.tx_queue[chan].txtimer)` must complete before `stmmac_free_irq()`, `stmmac_stop_all_dma()`, and `free_dma_desc_resources()`. In `stmmac_xdp_set_prog()`, when `if_running && need_update`, `stmmac_xdp_release(dev)` must run before `xchg(&priv->xdp_prog, prog)`, and `stmmac_xdp_open(dev)` must run after updating `priv->xdp_prog` and `priv->sph`. [F6, F23]
- In `stmmac_free_irq()`, per-queue MSI IRQs (`priv->tx_irq[j]`, `priv->rx_irq[j]`) must clear `irq_set_affinity_hint(..., NULL)` before calling `free_irq()` with `&priv->dma_conf.tx_queue[j]` or `&priv->dma_conf.rx_queue[j]`, whereas MAC, WoL, LPI, and safety IRQs use `dev`. `stmmac_mdio_unregister()`, `stmmac_pcs_clean()`, and `stmmac_ptp_unregister()` must null `priv->mii`, `priv->hw->xpcs`, and `priv->ptp_clock`, and `stmmac_ptp_register()` must reset `priv->ptp_clock = NULL` when `ptp_clock_register()` returns `ERR_PTR`. [F8, F9]

## API Contracts

- `stmmac_set_rx_mode()`, `stmmac_vlan_rx_add_vid()`, and `stmmac_vlan_rx_kill_vid()` may run with bottom halves disabled and must not call `phylink_rx_clk_stop_block()` or `phylink_rx_clk_stop_unblock()`. Callers of `stmmac_dvr_probe()` (`stmmac_get_platform_resources()`, `stmmac_pci_probe()`) must zero-initialize `struct stmmac_resources`. [F40, F144]
- In `stmmac_napi_poll_rxtx()`, if `max(tx_done, rx_done) >= budget`, it must return `budget` without calling `napi_complete_done()`; only when `rxtx_done < budget` may it call `napi_complete_done(napi, rxtx_done)`, re-enable RX and TX DMA interrupts under `ch->lock`, and return `min(rxtx_done, budget - 1)`. [F165]
- `stmmac_xsk_tx_metadata_ops` splits its `void *_priv` context by phase: `xsk_tx_metadata_request()` in `stmmac_xdp_xmit_zc()` must pass `struct stmmac_metadata_request *`, while `xsk_tx_metadata_complete()` in `stmmac_tx_clean()` must pass `struct stmmac_xsk_tx_complete *`. `stmmac_xdp_set_prog()` and `stmmac_change_mtu()` must disallow `mtu > ETH_DATA_LEN` while XDP is enabled, and `stmmac_xdp_enable_pool()` must reject XSK pools with `frame_size < ETH_FRAME_LEN + VLAN_HLEN * 2`. [F83, F125]
- Parameter conversions: `stmmac_set_rings_length()` must pass `dma_tx_size - 1` and `dma_rx_size - 1` to `stmmac_set_tx_ring_len()` / `stmmac_set_rx_ring_len()`; `stmmac_tso_xmit()` must pass `hdr / 4` (32-bit words) as `tcphdrlen` to `stmmac_prepare_tso_tx_desc()`; `stmmac_pcs_setup()` must pass `ffs(pcs_mask) - 1` to `xpcs_create_mdiodev()`; `tc_add_vlan_flow()` must pass `BIT(match.key->vlan_priority)` to `stmmac_rx_queue_prio()`. [F25, F41, F42, F44]

## Error Handling

- Zero-divisor guards: `stmmac_init_tstamp_counter()` must check `priv->plat->clk_ptp_rate != 0` before `stmmac_config_sub_second_increment()` or dividing for `priv->default_addend`, and `stmmac_ptp_register()` must only run after `stmmac_init_timestamping()` succeeds; `tc_taprio_configure()` must check `qopt->cycle_time != 0` before `stmmac_calc_tas_basetime()`; `tc_setup_cbs()` must divide slopes only when `qopt->enable` is true; TX paths must check `priv->tx_coal_frames[queue] != 0` before `%`. [F85, F104, F105, F110, F113]
- Pointer and state guards: in `__alloc_dma_rx_desc_resources()`, if `page_pool_create()` returns `ERR_PTR`, `rx_q->page_pool` must be reset to `NULL`; in `stmmac_pcs_setup()`, `xpcs` remains `NULL` when `priv->plat->pcs_init` succeeds and must be checked before `xpcs_config_eee_mult_fact()`; in `stmmac_tx_clean()`, `xsk_tx_metadata_complete()` requires both `tx_q->xsk_pool` and `xp_tx_metadata_enabled(tx_q->xsk_pool)`; in `tc_setup_dwmac510_mqprio()`, any failure or `qopt->num_tc == 0` must call `stmmac_reset_tc_mqprio()`. [F24, F26, F35, F169]
- Return conventions: `stmmac_xdp_run_prog()` returns `NULL` for `STMMAC_XDP_PASS` and `ERR_PTR(-res)` otherwise, so `stmmac_rx()` must reset `skb = NULL` when `IS_ERR(skb)`; `stmmac_do_callback()` returns `-EINVAL` when unimplemented, so `stmmac_safety_feat_interrupt()` and `stmmac_xmit()` (`stmmac_jumbo_frm()`) must ignore `-EINVAL`; in `stmmac_mdio_register()`, `-ENODEV` from `of_mdiobus_register()` must be converted to `0` before freeing `new_bus`; `stmmac_get_tx_timestamp_status()` returns `1` on success whereas fallback `stmmac_get_mac_tx_timestamp()` returns `0`. [F27, F29, F30, F31]

## External Contracts

- In `stmmac_xmit()`, when `skb->ip_summed == CHECKSUM_PARTIAL`, hardware TX checksum insertion must be bypassed via `skb_checksum_help(skb)` and clearing `csum_insertion` whenever `priv->plat->tx_queues_cfg[queue].coe_unsupported` is set or `!stmmac_has_ip_ethertype(skb)`. In `stmmac_rx()` and `stmmac_dispatch_skb_zc()`, `skb->ip_summed = CHECKSUM_UNNECESSARY` requires `priv->hw->rx_csum`, `stmmac_has_ip_ethertype(skb)` after `eth_type_trans()`, and (in `stmmac_rx()`) `!(status & csum_none)`; otherwise call `skb_checksum_none_assert(skb)`. [F158, F159]

## Known Pitfalls

- In `stmmac_setup_dma_desc()` and all its callees (`alloc_dma_desc_resources()`, `init_dma_desc_rings()`, `free_dma_desc_resources()`, etc.), queue rings and buffer sizes must be accessed on the passed `dma_conf` pointer rather than `priv->dma_conf`. When indexing extended descriptor rings (`rx_q->dma_erx`, `tx_q->dma_etx`) as `struct dma_desc *`, parenthesize pointer addition before casting (`(struct dma_desc *)(rx_q->dma_erx + entry)`) so stride scales by 32B instead of 16B. [F91, F120]
- In `stmmac_rx()` and `stmmac_rx_zc()`, `if (unlikely(error && (status & rx_not_ls))) goto read_again;` must precede `if (unlikely(error))` so non-last descriptors of a discarded multi-descriptor frame are drained first. In `stmmac_rx_buf1_len()`, `if (priv->sph && len) return 0;` and `if (priv->sph && hlen) return hlen;` must precede `if (status & rx_not_ls) return priv->dma_conf.dma_buf_sz;`, and `len += buf1_len` must run before `stmmac_rx_buf2_len(priv, p, status, len)`. [F88, F89]
- In `stmmac_get_rx_hwtstamp()` and `stmmac_xdp_rx_timestamp()`, `stmmac_get_rx_timestamp_status()` takes both `p`/`desc` and `np`/`ndesc`, whereas `stmmac_get_timestamp()` must be passed `np`/`ndesc` when `priv->plat->has_gmac4 || priv->plat->has_xgmac` and `p`/`desc` otherwise. [F101]
- In `stmmac_xdp_xmit_zc()`, the unsigned `budget` is tested after the loop in `return !!budget && work_done;` and must be decremented in `for (; budget > 0; budget--)`, never `while (budget-- > 0)`. In `struct stmmac_txq_stats`, TX submission paths must update `txq_stats->q` under `q_syncp`, while NAPI paths (`stmmac_tx_clean()`, `stmmac_xdp_xmit_zc()`, `stmmac_napi_poll_tx()`, `stmmac_napi_poll_rxtx()`) must update `txq_stats->napi` under `napi_syncp`. [F71, F92]
