# GFS2 FILE SYSTEM

This unit (`fs/gfs2`) implements GFS2 core subsystems: superblock lifecycle (`main.c`, `ops_fstype.c`, `super.c`), DLM integration (`lock_dlm.c`), journal logging, AIL, and recovery (`log.c`, `lops.c`, `recovery.c`), resource group block allocation and bitmaps (`rgrp.c`), quota management (`quota.c`), metadata buffer I/O (`meta_io.c`), and sysfs interfaces (`sys.c`).

## Architecture & Data Flow
- Every GFS2 metadata `address_space` (`gfs2_aspace(sdp)` and `gfs2_glock2aspace(gl)`) must set `mapping->host` to `sdp->sd_inode`. `gfs2_mapping2sbd()` checks `mapping->a_ops == &gfs2_meta_aops` before downcasting `mapping` to `struct gfs2_glock_aspace` (`gfs2_rgrp_aops` must remain distinct for `gfs2_aspace(sdp)`), and `gfs2_glock2aspace(gl)` checks `gl->gl_ops->go_flags & GLOF_ASPACE`. [F50, F132, F165]
- In `rgblk_free()`, if `bi->bi_clone` is NULL it must be allocated to full block size (`bi->bi_bh->b_size`, copying `[bi->bi_offset, bi->bi_offset + bi->bi_bytes)`) before `gfs2_setbit()` mutates `b_data` with `do_clone = false`; callers increment `rd_free` but not `rd_free_clone`. Conversely, `gfs2_alloc_blocks()` and `gfs2_alloc_extent()` call `gfs2_setbit()` with `do_clone = true` and decrement `rd_reserved`, `rd_free_clone`, and `rd_free` under `rd_rsspin`. [F66, F67, F134]
- In `maybe_release_space()`, when `bi->bi_clone` is non-NULL, `gfs2_rgrp_send_discards()` must run before copying `bd->bd_bh->b_data` into `bi->bi_clone`, and `GBF_FULL`, `rd_free_clone`, and `rd_extfail_pt` must be updated to match `rd_free` under `rgrp_lock_local(rgd)`. Mutations to `rd_flags`, `rd_free`, `rd_dinodes`, or `rd_igeneration` must be written via `gfs2_rgrp_out()`, and `rd_rgl->rl_unlinked` adjusted in lockstep in `gfs2_unlink_di()` and `gfs2_free_di()`. [F68, F69]
- Whenever `ip->i_res` is initialized (`gfs2_init_inode_once()`, `gfs2_alloc_inode()`) or erased from `rgd->rd_rstree` (`__rs_deltree()`), `RB_CLEAR_NODE(&rs->rs_node)` must be called because `gfs2_rs_active()` tests `!RB_EMPTY_NODE(&rs->rs_node)`. `rs_insert()`, `gfs2_adjust_reservation()`, and `__rs_deltree()` must update `rd_requested` in lockstep with `rs_requested` under `rd_rsspin`, and `__rs_deltree()` must add `rs_requested` to `rd_extfail_pt`. [F59, F70]
- `gfs2_add_revoke()` must increment `sd_log_num_revoke`, hold `bd->bd_gl` on the 0-to-1 transition of `gl->gl_revokes`, save `bd->bd_blkno = bh->b_blocknr`, detach `bh->b_private` and `bd->bd_bh`, call `gfs2_remove_from_ail(bd)`, and set `GLF_LFLUSH`. Because `gfs2_log_update_flush_tail()` uses `list_last_entry(&sdp->sd_ail1_list)`, `gfs2_ail1_empty()` must iterate `sd_ail1_list` in reverse and clear `oldest_tr` on the first non-empty transaction. [F80, F103]
- `gfs2_log_flush()` must check `test_bit(SDF_JOURNAL_LIVE, &sdp->sd_flags)` under `sd_log_flush_lock` before reserving/flushing log blocks, and `gfs2_evict_inode()` must check `sdp->sd_jdesc != NULL` before journaled eviction. Journal recovery on an arbitrary `gfs2_jdesc` (`clean_journal()`, `gfs2_write_log_header()` with `GFS2_LOG_HEAD_RECOVERY`, or `gfs2_recover_func()` on a remote `jd_jid`) must not touch `sd_log_flush_head` or write local statfs/quota fields to the log header. [F55, F73]
- Spectator mounts (`sd_args.ar_spectator`) do not populate `sd_sc_inode`, `sd_sc_bh`, `sd_sc_gh`, `sd_qc_inode`, `sd_qc_gh`, `sd_journal_gh`, or `sd_jinode_gh`, so statfs, journal, per-node, and unmount paths must guard them with `!sdp->sd_args.ar_spectator`. [F54]
- Because `qd_hash_table` and `gfs2_qd_lru` are module-global, `gfs2_qd_search_bucket()` must match both `qid_eq(qd->qd_id, qid)` and `qd->qd_sbd == sdp`, and `gfs2_quota_cleanup()` must iterate only `sdp->sd_quota_list`. `gfs2_adjust_quota()` must update `qd->qd_qb` under `qd->qd_lockref.lock` and set `QDF_REFRESH` on `qd->qd_flags` so `do_glock()` refreshes the LVB via `update_qd()`. [F78, F79]

## Synchronization
- Every `dlm_lock()` or `dlm_unlock()` call on `ls->ls_dlm` in `lock_dlm.c` (`gdlm_lock`, `gdlm_put_lock`, `gdlm_cancel`, `sync_lock`, `sync_unlock`) must hold `down_read(&ls->ls_sem)` and check `ls->ls_dlm != NULL`, synchronizing with `gdlm_unmount()` taking `down_write(&ls->ls_sem)`. When `!DFL_NO_DLM_OPS`, `gdlm_unmount()` must set `DFL_UNMOUNT` under `ls->ls_recover_spin` and flush `sd_control_work` before releasing `ls_dlm` and calling `free_recover_size(ls)`. Drop `ls_recover_spin` before sleeping. [F21, F24, F148]
- `sdp->sd_ail_lock` protects AIL lists and `bd_tr`, is required by `gfs2_remove_from_ail()`, and nests inside `sdp->sd_log_lock` (`gfs2_log_lock()`). When `gfs2_ail1_start_one()` drops `sd_ail_lock` for writeback (`gfs2_jdata_writeback()` for jdata inodes, else `a_ops->writepages()`), it must return `-EBUSY` after relocking so `gfs2_ail1_flush()` restarts iteration; `gfs2_ail1_wait()` must call `get_bh(bh)` before dropping `sd_ail_lock` for `wait_on_buffer(bh)`. [F27, F28, F151]
- `gfs2_pin()` requires `sd_log_lock` held and `current->journal_info != NULL`. In `gfs2_before_commit()`, drop `sd_log_lock` before `gfs2_get_log_desc()`, `gfs2_log_write_page()`, `lock_buffer()`, or `mempool_alloc(gfs2_page_pool, GFP_NOIO)`, and call `get_bh(bd2->bd_bh)` before dropping `sd_log_lock` to write `bd2->bd_bh`. [F29, F154]
- Callers of `gfs2_log_try_reserve()` and `gfs2_log_release_revokes()` must hold `sd_log_flush_lock`, whereas callers of `gfs2_log_reserve()` and `__gfs2_log_reserve()` must never hold it. If `__gfs2_log_try_reserve_revokes()` succeeds (`revoke_blks == 0`) in `gfs2_log_try_reserve()` but `__gfs2_log_try_reserve()` fails, restore revokes via `gfs2_log_release_revokes(sdp, revokes)`. [F10, F150]
- In `gfs2_recover_func()`, journal replay must hold `sd_freeze_mutex` (with `SDF_FROZEN` clear) and `down_read(&sdp->sd_log_flush_lock)`; every exit from replay must call `up_read(&sdp->sd_log_flush_lock)` before `fail_gunlock_nofreeze:`, and `j_gh`/`ji_gh` must only be dequeued when `jlocked` is non-zero (`jd_jid != ls_jid`). [F5, F30]
- Resource group locks nest as `rgd->rd_gl` -> `rgd->rd_mutex` (`rgrp_lock_local()`, required for node-local updates under `LM_FLAG_NODE_SCOPE`) -> `rgd->rd_rsspin` (protecting `rd_rstree`, `rd_requested`, `rd_reserved`); release `rd_rsspin` before `rgrp_unlock_local()` or `gfs2_rgrp_error()`. `gfs2_rs_delete(ip)` requires holding `ip->i_rw_mutex` in write mode and `atomic_read(&inode->i_writecount) <= 1` before calling `gfs2_rs_deltree(&ip->i_res)`. [F6, F34, F160]
- Quota spinlocks nest as `qd_lock` -> `spin_lock_bucket` -> `qd->qd_lockref.lock` -> `gfs2_qd_lru` lock or `sd_bitmap_lock`; `gfs2_qd_isolate()` must use `spin_trylock(&qd->qd_lockref.lock)`. Sort multiple `qd` pointers with `sort_qd` before locking `qd->qd_gl` in `do_sync()` or `gfs2_quota_lock()`, and lock `sd_quota_inode` in order `inode_lock(&ip->i_inode)` -> `qd->qd_gl` -> `ip->i_gl`. [F31, F159]
- When `rs->rs_rgd->rd_gl` is already locked by the caller (`gfs2_glock_is_locked_by_me()`), `gfs2_inplace_reserve()` must leave `ip->i_rgd_gh` uninitialized and `gfs2_inplace_release()` must check `gfs2_holder_initialized(&ip->i_rgd_gh)`. Likewise, `gfs2_dirty_inode()` and `gfs2_rindex_update()` must check `gfs2_glock_is_locked_by_me()` (and `current->journal_info == NULL` in `gfs2_dirty_inode()`) and only release what they acquired. [F17, F18]
- In `gfs2_fill_super()`, `init_threads(sdp)` must precede `gfs2_freeze_lock_shared(sdp)` and `gfs2_destroy_threads(sdp)` must follow `gfs2_freeze_unlock(sdp)`. In `gfs2_put_super()`, set `SDF_NORECOVERY`, `smp_mb()`, and wait on `JDF_RECOVERY` before `gfs2_make_fs_ro()` stops threads, runs a normal `gfs2_log_flush()` before `GFS2_LOG_HEAD_FLUSH_SHUTDOWN`, and calls `gfs2_quota_cleanup()`. [F36, F155, F169, F170]
- In `evict_should_delete()`, lock `ip->i_gl` with `GL_SKIP` and verify `gfs2_check_blk_type(..., GFS2_BLKST_UNLINKED)` before `gfs2_instantiate(gh)`. In `evict_linked_inode()`, `truncate_inode_pages()` on `&inode->i_data` and `metamapping` must run inside a transaction before releasing `ip->i_gl`. Under `PF_MEMALLOC`, defer deletion via `gfs2_queue_verify_delete()` and release glocks via `gfs2_glock_put_async()`. [F161, F172, F173]

## Object Lifetimes
- `sb->s_fs_info` must remain set to `sdp` until `free_sbd()` after all superblock inodes are released (`gfs2_drop_inode()` dereferences `GFS2_SB(inode)`). Because `gfs2_gl_hash_clear()` destroys and zeroes `sd_glock_wq`, `gfs2_fill_super()` must check `sd_glock_wq != NULL` before `destroy_workqueue()`. Release the unreferenced alias `sdp->sd_sc_inode` only via `free_local_statfs_inodes(sdp)`, never `iput(sdp->sd_sc_inode)`. [F1, F2, F117]
- In `gdlm_put_lock()`, skipping `dlm_unlock()` under `SDF_SKIP_DLM_UNLOCK` requires `!gl->gl_lksb.sb_lvbptr || gl->gl_state != LM_ST_EXCLUSIVE` and must defer freeing `gl` via `gfs2_glock_free_later(gl)` onto `sd_dead_glocks`; `gdlm_ast()` (unless `sb_status == -DLM_EUNLOCK`) and `gdlm_bast()` must ignore glocks with `__lockref_is_dead(&gl->gl_lockref)`. [F4, F22]
- `gfs2_pin()` calls `get_bh(bh)` and `gfs2_unpin()` must call `brelse(bh)` if `bd->bd_tr` was already set so `bd` holds one reference until `gfs2_remove_from_ail()`. `gfs2_ail_drain()` must call `gfs2_ail_empty_tr()` on both `&tr->tr_ail1_list` and `&tr->tr_ail2_list`. In `gfs2_log_flush()`, clear `tr = NULL` whenever `tr` is queued to `sd_ail1_list`, preserve `reserved_blocks` across `goto repeat;` (releasing it via `gfs2_log_release()` if `tr || sd_log_num_revoke`), and never add buffers to `TR_ONSTACK` transactions. [F8, F9, F105, F109, F133]
- `gfs2_qd_search_bucket()` must use `lockref_get_not_dead(&qd->qd_lockref)` before removing `qd` from `gfs2_qd_lru`. `gfs2_qd_dispose()` must unlink with `hlist_bl_del_rcu()` and free via `call_rcu(&qd->qd_rcu, gfs2_qd_dealloc)`; `gfs2_quota_cleanup()` waits on `sd_kill_wait` for `sd_quota_count == 0` and `exit_gfs2_fs()` calls `rcu_barrier()` before destroying caches. `qdsb_get()`/`qdsb_put()` pair `qd_get()`, `slot_get()`, and `bh_get()`, and `do_qc()` holds `__qd_hold()` and `slot_hold()` while `QDF_CHANGE` is set. [F14, F15, F32, F37]
- `gfs2_rgrp_brelse()` and the failure path of `gfs2_rgrp_go_instantiate()` must set `bi->bi_bh = NULL` after `brelse(bi->bi_bh)` (and `gfs2_rgrp_brelse()` sets `GLF_INSTANTIATE_NEEDED`), because `gfs2_rgrp_go_instantiate()` checks `rd_bits[0].bi_bh != NULL` to skip I/O. [F16]
- In `gfs2_evict_inode()`, detaching `ip->i_gl` requires `glock_clear_object(ip->i_gl, ip)`, `wait_on_bit_io()` on `GIF_GLOP_PENDING`, `gfs2_glock_put_eventually()`, and `rcu_assign_pointer(ip->i_gl, NULL)`. In `gfs2_evict_inodes()`, hold `__iget(inode)` across dropping `s_inode_list_lock` by deferring `iput()` via `toput_inode`. [F20, F106]

## API Contracts
- Pages passed to `gfs2_log_write_page()` (or `gfs2_log_write()` without `buffer_head`s) must come from `gfs2_page_pool` (freed by `gfs2_end_log_write()`). `gfs2_meta_read()` and `gfs2_meta_buffer()` call `brelse(bh)` on error, so callers only `brelse(*bhp)` on `0`. Callers of `gfs2_queue_verify_delete(gl, ...)` must hold a `gl` reference and drop it only if it returns `false`. [F7, F12, F19]
- Return conventions: `gfs2_lookupi()` returns `NULL` or `ERR_PTR` (`IS_ERR_OR_NULL()`), while `gfs2_lookup_meta()` and `filemap_grab_folio()` return `ERR_PTR` (`IS_ERR()`); `get_log_header()`/`__get_log_header()` return `1` for corrupt headers (convert to `-EIO`); `gfs2_revoke_add()` returns `1` on insert, `0` on update; `read_rindex_entry()` returns `1` at EOF; `gfs2_reservation_check_and_update()` returns `1` when `rbm` advanced; `gfs2_bitfit()` returns `BFITNOENT` (`(u32)~0`) on miss. [F41, F42, F43, F44, F46, F47, F48]
- `gfs2_internal_read()` advances `*pos` by `size`, so `gfs2_adjust_quota()` must subtract `sizeof(q)` from `loc` before writing back. Shift by `sb_bsize_shift` between `gfs2_quota`/`gfs2_quota_lvb` (blocks) and VFS `qc_dqblk` (bytes), and use `gfs2_get/set/add_inode_blocks()` to convert `inode->i_blocks` (512B sectors). Both `GFS2_QUOTA_QUIET` and `GFS2_QUOTA_ON` enforce limits and must fall through to `GFS2_QUOTA_ACCOUNT` in `gfs2_quota_get_state()`. [F49, F64, F65, F76, F102]

## Error Handling
- In `init_statfs()` and `init_per_node()`, set `pn = NULL` after `iput(pn)` because error labels call `iput(pn)`, and `kfree(lsi)` if `init_statfs()` fails before `list_add_tail()`. In `gfs2_lock_fs_check_clean()`, store `gfs2_freeze_lock_shared()` in `error2` at `relock_shared:` to preserve `error`. In `gfs2_rgrp_go_instantiate()`, use variable `y` in the second loop so `while (x--)` at `fail:` releases all `length` buffers. [F3, F57, F112]
- Check `ip->i_iopen_gh.gh_gl != NULL` before `gfs2_glock_hold()` and `gfs2_queue_verify_delete()`. When `evict_should_delete()` fails to lock `ip->i_gl`, or `gfs2_evict_inode()` cannot defer deletion (`gh_gl == NULL` or `SDF_KILL`), fall back to `EVICT_SHOULD_SKIP_DELETE` (`evict_linked_inode()`), never `EVICT_SHOULD_DELETE`. Check `ip->i_gl != NULL` in `gfs2_journal_wipe()`, `gfs2_dirty_inode()`, and `gfs2_evict_inode()`, and check `rgd->rd_rgl != NULL` in `gfs2_rgrp_dump()`. [F51, F52, F53, F101]

## Known Pitfalls
- In `gfs2_rbm_find()`, read `bh->b_data` (not `bi_clone`) when searching for `GFS2_BLKST_UNLINKED`, and on wrap-around compute `last_bii = rbm->bii - (rbm->offset == 0)`, break at `rbm->bii == 0` if `wrapped` is already true before setting `wrapped = true`, and break at `next_iter:` when `wrapped && rbm->bii > last_bii`. In `try_rgrp_unlink()`, advance `rbm` via `gfs2_rbm_from_block(&rbm, block + 1)` before any `continue`. [F98, F113, F114]
- Use `lh.lh_sequence >= head->lh_sequence` in `gfs2_jhead_folio_search()` so `lh_sequence == 0` is recorded; increment `ptr` before `gfs2_revoke_check()` in `buf_lo_scan_elements()` and `databuf_lo_scan_elements()`; reset `force_refresh = 0` before `goto restart;` in `do_glock()`; demote `mounted_lock` to `DLM_LOCK_NL` at `restart:` in `control_mount()`; and check `glock_needs_demote(ip->i_gl)` (not `gh->gh_gl`) in `gfs2_upgrade_iopen_glock()`. [F99, F110, F111, F115, F116]
