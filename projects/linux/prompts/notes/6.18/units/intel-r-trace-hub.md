# INTEL(R) TRACE HUB

The Intel(R) Trace Hub (Intel TH) subsystem manages hardware trace aggregation, routing, and storage on Intel SoCs and PCHs via a custom `intel_th` device bus. It attaches to PCI (`intel_th_pci`) or ACPI (`intel_th_acpi`) parent controllers and enumerates subdevices for trace sources such as the Software Trace Hub (`sth`), the central Global Trace Hub switch (`gth`), and trace outputs including Memory Storage Unit controllers (`msc`), MIPI-PTI/LPP ports (`pti`), and pluggable MSU buffer sinks (`msu_buffer`).

## Architecture & Data Flow
- `INTEL_TH_OUTPUT` devices have `&th->hub->dev` as `dev.parent`, whereas `INTEL_TH_SWITCH` and `INTEL_TH_SOURCE` devices have `th->dev` as `dev.parent`. `to_intel_th()`, `to_intel_th_hub()`, and all MSC DMA calls (`dma_alloc_coherent`, `dma_free_coherent`, `dma_map_sg`, `dma_unmap_sg`) must traverse the extra parent level (`msc_dev(msc)->parent->parent` or `priv->dev->parent->parent`), never `msc_dev(msc)` or `msc_dev(msc)->parent`. [F35, F88]
- `msc->user_count` is a tri-state atomic counter: `-1` means no buffer is allocated, `0` means allocated with no active users, and `> 0` counts active users (enabled tracing, open `read()` calls, active `mmap` mappings, and `WIN_LOCKED` sink windows). Never access buffer memory unless `atomic_inc_unless_negative(&msc->user_count)` succeeds, or free the buffer unless `atomic_cmpxchg(&msc->user_count, 0, -1)` returns `0`. [F6]
- Even when `msc->mode == MSC_MODE_MULTI`, `msc->win_list` can be empty and `msc->cur_win` can be NULL before `nr_pages_store` allocates pages; paths reachable without a positive `msc->user_count` (`msc_win_switch`, `msc_find_window`, `msc_oldest_window`, `intel_th_msc_interrupt`) must check `list_empty(&msc->win_list)` or `!msc->cur_win`. [F32]
- Mutating `msc->win_list` (`msc_buffer_win_alloc`, `msc_buffer_win_free`) or rotating `msc->cur_win` (`msc_win_switch`) must keep `msc->base`, `msc->base_addr`, `msc->nr_pages`, and each window's cumulative `win->pgoff` synchronized, and `msc_buffer_multi_alloc()` must call `msc_buffer_relink()` to chain descriptors. `msc_buffer_relink()` must reset `sw_tag = 0` per window and only OR `MSC_SW_TAG_LASTBLK` when `blk == win->nr_segs - 1`. [F46, F83]
- In `struct msc_block_desc`, software-initialized fields (`sw_tag`, `block_sz`, `next_blk`, `next_win`, `res0`) must precede `hw_tag`, because `msc_buffer_relink()` writes them only at allocation time while `msc_buffer_clear_hw_header()` zeroes from `hw_tag` to the end via `memset_startat(bdesc, 0, hw_tag)` on each trace start. `msc_data_sz()` must return `0` when `bdesc->valid_dw == 0` before `bdesc->valid_dw * 4 - MSC_BDESC` to avoid unsigned underflow. [F90, F100]
- `msc_configure()` must save `REG_MSU_MSC0BAR`/`REG_MSU_MSC0SIZE` into `msc->orig_addr`/`msc->orig_sz` and sync `msc->thdev->output.multiblock` before enabling trace; `msc_disable()` must sample `msc->single_wrap` and `msc->single_sz` after `intel_th_trace_disable()` and restore `orig_addr`/`orig_sz` after clearing `MSC_EN`. Because `msc0` and `msc1` share `REG_MSU_MINTCTL` and `REG_MSU_MSUSTS`, callers must modify or clear only the bit for `msc->index`, and `intel_th_msu_init()` must verify `REG_MSU_MINTCTL` latched or set `msc->do_irq = 0`. [F50, F52, F112]
- GTH master arrays (`gth->master`), per-output bitmaps (`gth->output[port].master`), and `intel_th_master_attributes()` must be sized for `TH_CONFIGURABLE_MASTERS + 1` (257) entries (`0..256`). `intel_th_gth_set_output()` must clamp `master > TH_CONFIGURABLE_MASTERS` to `TH_CONFIGURABLE_MASTERS`, and `gth_master_set()` must route `master >= 256` to `REG_GTH_GSWTDEST` at shift 0 and only OR `(0x8 | port) << shift` when `port >= 0`. [F61, F93, F104]
- When `intel_th_gth_unassign()` clears `gth->output[port].output` to `NULL`, it must also reset every `gth->master[master] == port` across `0..TH_CONFIGURABLE_MASTERS` to `-1` under `gth->gth_lock`. `master_attr_store()` must validate `port` is in `[-1, TH_POSSIBLE_OUTPUTS - 1]` and, when `port >= 0`, check `gth->output[port].output != NULL` under `gth->gth_lock` before accessing it. [F43, F76]
- `REG_GTH_GTHOPT0`/`1`, `REG_GTH_SMCR0`..`3`, `REG_GTH_SWDEST0`..`31`, and `REG_GTH_SCRPD0` pack state for multiple ports, masters, and outputs into shared 32-bit registers and must be updated via masked read-modify-write (preserving `SCRPD_STH_IS_ENABLED | SCRPD_TRIGGER_IS_ENABLED` in `REG_GTH_SCRPD0`). `intel_th_output_activate()` must call `intel_th_trace_prepare()` before `thdrv->activate`, and deactivation must call `intel_th_trace_disable()` before clearing `MSC_EN` or `PTI_EN`. [F54, F58, F124]
- `th->drvdata` and `thdev->drvdata` are NULL when `.driver_data = 0` in `intel_th_pci_id_table`, so capabilities must be read via `INTEL_TH_CAP(th, cap)`. When `multi_is_broken` is set, `intel_th_msc_init()` must default `msc->mode` to `MSC_MODE_SINGLE` and `mode_store()` must reject `MSC_MODE_MULTI` with `-EOPNOTSUPP`. In host debugger mode (`host_mode_only`, `host_mode`, or `SCRPD_DEBUGGER_IN_USE`), the driver must not reset GTH, create `INTEL_TH_OUTPUT` subdevices or GTH sysfs groups, assign ports, or change GTH routing. [F33, F111, F113]

## Synchronization
- The lock hierarchy nests `msc->buf_mutex` outside `msu_buffer_mutex`, `gth->gth_lock`, and `win->lo_lock`. Callers of `msc_configure`, `msc_disable`, `msc_buffer_contig_alloc`, `msc_buffer_win_alloc`, `msc_buffer_win_free`, `msc_buffer_relink`, `msc_buffer_free`, `msc_buffer_alloc`, `msc_buffer_unlocked_free_unless_used`, and `msc_buffer_unassign` must hold `msc->buf_mutex`, and none of these helpers may drop it. [F15, F130]
- `intel_th_msc_interrupt()` runs in hardirq context and calls `msc_win_switch()` (`intel_th_trace_switch` -> `intel_th_gth_switch` -> `intel_th_gth_stop` -> `intel_th_msc_wait_empty`) and `msc->mbuf->ready()`; none of these or `intel_th_msc_window_unlock()` may sleep or take `msc->buf_mutex`. When `msc->stop_on_full` is set and the next window is locked, `intel_th_msc_interrupt()` must defer `intel_th_msc_deactivate()` via `schedule_work(&msc->work)`, and release `win->lo_lock` before calling `mbuf->ready()`. [F23, F126, F127]
- `gth->gth_lock` must be held across all reads and updates of `gth->master[]`, `gth->output[port].master` bitmaps, `gth->output[port].output`, `output->active`, and SWDEST registers via `gth_master_set()`. Because `gth->gth_lock` is taken with plain `spin_lock()` in process context, it must never be acquired from hardirq paths such as `intel_th_gth_switch()` or `intel_th_gth_stop()`. [F18, F129]
- In `msu.c`, `msc->buf_mutex` must be held across checking `msc->enabled` and adding to `msc->iter_list` in `msc_iter_install()`, and across checking `list_empty(&msc->iter_list)` and calling `msc_configure()` in `intel_th_msc_activate()`. Manual window switching in `win_switch_store()` must only call `msc_win_switch()` under `msc->buf_mutex` when `msc->mode == MSC_MODE_MULTI` and `!msc->mbuf`. [F19, F25]
- When `win->msc->mbuf` is assigned, `msc_win_set_lockout()` must increment `msc->user_count` when transitioning `win->lockout` to `WIN_LOCKED` and decrement it when leaving `WIN_LOCKED` under `win->lo_lock`, and `intel_th_msc_window_unlock()` must clear `msc->switch_on_unlock` and call `msc_win_switch()` when unlocking that pending window. [F47]
- In `msc_buffer_alloc()`, `smp_mb__before_atomic()` must order all buffer, window list, and `msc_buffer_set_uc()` setup before `atomic_cmpxchg(&msc->user_count, -1, 0)` publishes the buffer to lockless readers. In `msc_buffer_relink()`, `wmb()` must execute after writing all multiblock descriptor fields (`sw_tag`, `block_sz`, `next_blk`, `next_win`) across `msc->win_list` before enabling hardware tracing. [F20, F24]
- Static `msu_buffer_mutex` must be initialized with `DEFINE_MUTEX()` and held across all accesses to `msu_buffer_list`. `sth_stm_packet()` in `sth.c` must remain marked `notrace` and perform only lockless, non-sleeping MMIO writes. [F16, F138]

## Object Lifetimes
- Once `intel_th_device_alloc()` calls `device_initialize(&thdev->dev)`, `thdev` and `thdev->resource` are freed by `intel_th_device_release()`; cleanup paths must call `put_device(&thdev->dev)` rather than `kfree(thdev)`. In `intel_th_subdevice_alloc()`, error paths jumping to `fail_free_res` or `fail_put_device` must not call `put_device(&thdev->dev)` before the `goto`. [F1, F108]
- In `intel_th_subdevice_alloc()`, `th->hub` must be assigned before `device_add(&thdev->dev)` and `intel_th_request_hub_module(th)`. `intel_th_free()` must flush `th->request_module_work` and call `intel_th_device_remove(th->hub)` before iterating over `th->thdev[]` (removing the `INTEL_TH_SWITCH` hub in `intel_th_remove()` disconnects and removes child `INTEL_TH_OUTPUT` devices from `th->thdev[]`, updating `th->num_thdevs = lowest` only if `lowest >= 0`). When `intel_th_populate()` fails, `intel_th_alloc()` must call `intel_th_free(th)`. [F2, F3, F17, F26, F45]
- `intel_th_free()` must explicitly free all `th->num_irqs` handlers via `devm_free_irq()` before `intel_th_pci_remove()` calls `pci_free_irq_vectors(pdev)` (which is not devres-managed and BUGs if any vector still has an active action); `intel_th_pci_probe()` must also call `pci_free_irq_vectors(pdev)` when `intel_th_alloc()` fails. [F4, F105]
- `intel_th_output_activate()` acquires `thdrv->driver.owner`, runtime PM on `thdev->dev`, `th->activate(th)`, and `thdrv->activate(thdev)` (or `intel_th_trace_enable(thdev)`), and must unwind them in reverse order on failure and in `intel_th_output_deactivate()`. [F5]
- In `intel_th_msc_mmap()`, `msc->user_count` is incremented once for the initial mapping (`mmap_count = 1`), and while VMA splits increment `msc->mmap_count` in `msc_mmap_open()`, `msc->user_count` is only decremented in `msc_mmap_close()` when `atomic_dec_and_mutex_lock(&msc->mmap_count, &msc->buf_mutex)` reaches zero. [F7]
- In `mode_store()`, `kstrndup()`'s buffer must be freed with `kfree(mode)` on all paths (including `goto found`). If `msu_buffer_get()` returns `mbuf == msc->mbuf`, drop the duplicate ref with `msu_buffer_put(mbuf)` and jump to `unlock` with `ret == 0`; otherwise free any existing buffer via `msc_buffer_unlocked_free_unless_used(msc)` before `msc_buffer_unassign(msc)` or `msc->mode = i` alters deallocation dispatch. [F11, F12]
- `msc_buffer_alloc()` must call `msc_buffer_set_uc()` before `msc->user_count` becomes `0`, and `msc_buffer_free()` must call `msc_buffer_set_wb()` after `msc->user_count` becomes `-1` before freeing pages. In `MSC_MODE_SINGLE`, `msc_buffer_contig_alloc()` must call `split_page(page, order)` and `msc_buffer_contig_free()` must free each page with `__free_page()`. When `msc_buffer_win_free()` removes the last window, clear `msc->base = NULL` and `msc->base_addr = 0`; `msc_buffer_multi_alloc()` must call `msc_buffer_multi_free(msc)` on error. [F13, F49, F146]

## API Contracts
- Every `struct intel_th_driver` must provide non-NULL `.probe` and `.remove` callbacks. An `INTEL_TH_SWITCH` driver must also provide non-NULL `assign`, `unassign`, `prepare`, `enable`, `trig_switch`, and `disable` callbacks. An `INTEL_TH_OUTPUT` driver with custom `.activate`/`.deactivate` callbacks must call `intel_th_trace_enable(thdev)` and `intel_th_trace_disable(thdev)` itself. [F115, F125, F140]
- `intel_th_output_open()` sets `file->private_data` to `struct intel_th_device *` before `file->f_op->open`, and `intel_th_msc_open()` overwrites `file->private_data` with `struct msc_iter *`; all other `intel_th_msc_fops` and `msc_mmap_ops` callbacks must treat `file->private_data` as `struct msc_iter *`. [F98]
- In `msc_buffer_win_alloc()`, initialize `win->sgt = &win->_sgt` before calling `alloc_window`. `msu_buffer.alloc_window` takes byte sizes and must return a positive scatterlist entry count or a negative errno (never 0), with multi-page entries backed by physically contiguous `struct page`s for `msc_buffer_get_page()`. `msc_buffer_win_alloc()`, `REG_MSU_MSC0SIZE`, `REG_MSU_MSC0BAR`, and `next_blk`/`next_win` take pages/PFNs, `block_sz` uses 64-byte units, and `msc_buffer_iterate()` callbacks return uncopied bytes in `0..tocopy`. [F27, F28, F39, F41, F102]
- In `sth.c`, MMIO channel indexing (`sth_channel()`, `sth_stm_mmio_addr()`) must subtract `sth->stm.sw_start` from `master`, while `sth_stm_link()` must pass the unadjusted global `master` ID to `intel_th_set_output()`. [F40]

## Error Handling
- Callers of `intel_th_subdevice_alloc()` (`intel_th_populate()` and `intel_th_output_enable()`) must check `IS_ERR(thdev)` before storing `thdev` into `th->thdev[th->num_thdevs++]`, and must treat `-ENODEV` as a non-fatal absent optional subdevice. Before invoking callbacks or taking module references on a companion subdevice's driver (`hub->dev.driver` or `thdev->dev.driver`), code must verify `.driver` is non-NULL and pin its module with `try_module_get()`. [F29, F31]
- In `nr_pages_store()`, because `krealloc_array(win, ...)` does not free `win` on failure, `kfree(win)` must be called explicitly when `krealloc_array()` returns `NULL` as well as at `free_win:`. [F14]

## External Contracts
- `intel_th_msc_open()`, `mode_store()`, and `nr_pages_store()` must check `capable(CAP_SYS_RAWIO)` and return `-EPERM` if lacking, and `msu.c` functions returning to userspace must use `-EINVAL` or `-EOPNOTSUPP` rather than `-ENOTSUPP`. `intel_th_msc_mmap()` must reject mappings where `size == 0`, `offset_in_page(size) != 0`, `vma->vm_pgoff != 0`, or `size >> PAGE_SHIFT != msc->nr_pages`, and `msc_mmap_fault()` must return `VM_FAULT_SIGBUS` when `msc_buffer_get_page()` returns `NULL`. [F68, F149, F152]

## Known Pitfalls
- Contiguous single-mode MSC buffers in `msc_buffer_contig_alloc()` must be allocated with `GFP_DMA32` and mapped via `dma_map_sg(msc_dev(msc)->parent->parent, ..., DMA_FROM_DEVICE)` to obtain `msc->base_addr`. In multiblock mode, `msc_sg_page()` must be used instead of `sg_page()` because `dma_alloc_coherent()` pages may lie in vmalloc space (`is_vmalloc_addr()`). [F134, F135]
- In `__msc_buffer_win_alloc()`, the `err_nomem` rollback loop `for_each_sg(win->sgt->sgl, sg_ptr, i, ret)` must use `ret` as the 4th argument rather than `i`, because `i` holds the limit of allocated segments and `for_each_sg` resets its loop variable to 0. In `nr_pages_store()`, when advancing `p = end + 1` past a comma, decrement `len` by `end - p + 1` (not `end - p`). [F62, F82]
- In `msc_win_total_sz()`, cast `win->nr_blocks` (`unsigned int`) to `size_t` before `<< PAGE_SHIFT` to avoid 32-bit overflow. In `msc_buffer_iterate()`, cast `msc_iter_bdesc(iter)` (`struct msc_block_desc *`, 64-byte stride) to `void *` before adding byte offsets `MSC_BDESC`, `data_bytes`, or `iter->block_off`. [F89, F101]
- In `sth_stm_packet()`, `STP_PACKET_GERR` (`reg += 4`), `STP_PACKET_XSYNC` (`reg += 8`), and `STP_PACKET_TRIG` rely on ordered switch fallthrough from `reg = REG_STH_TRIG`; `STP_PACKET_DATA` pointer arithmetic on `u64 __iomem *outp = &out->Dn` requires `Dn`, `DnM`, `DnTS`, and `DnMTS` in `struct intel_th_channel` to remain contiguous `u64` fields; and `size` must be clamped to `<= 4` for `STP_PACKET_MERR` (and when `!CONFIG_64BIT`) and rounded down to a power of two before `sth_iowrite()`. [F72, F77, F99]
