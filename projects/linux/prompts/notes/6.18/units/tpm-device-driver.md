# TPM DEVICE DRIVER

`drivers/char/tpm` implements the core subsystem and hardware/firmware device drivers for Trusted Platform Module (TPM 1.2 and TPM 2.0) chips, managing lifecycles, character devices (`/dev/tpm#` and `/dev/tpmrm#`), command transmission, HMAC/encrypted sessions, event logs, `hwrng`, sysfs/PPI attributes, and hardware transports.

## Architecture & Data Flow

- `tpm2_prepare_space()` stages `space` into `chip->work_space` and only `tpm2_commit_space()` copies it back on success; on failure in prepare, `tpm_transmit()`, or commit, `tpm2_flush_space(chip)` must flush `chip->work_space` without updating `space`. Every `struct tpm_space` must be initialized via `tpm2_init_space()` with `buf_size == TPM2_SPACE_BUFFER_SIZE`, as both functions `memcpy()` `space->buf_size` bytes unchecked. [F68, F121]
- In `struct tpm_space`, `tpm2_map_to_vhandle()` encodes handles as `TPM2_HT_TRANSIENT | (0xFFFFFF - i)` and `tpm2_map_to_phandle()` decodes via `i = 0xFFFFFF - (vhandle & 0xFFFFFF)` with `i < ARRAY_SIZE(space->context_tbl)`. `context_tbl[i]` is `0` when empty and `~0` when saved/flushed, so `tpm2_flush_space()` and `tpm2_save_space()` must test both `context_tbl[i]` and `~context_tbl[i]`, while `tpm2_load_space()` requires `~context_tbl[i] == 0`. [F81, F82]
- In `tpm2_map_response_body()`, before iterating `data->handles[]`, verify `len >= TPM_HEADER_SIZE + 9`, `be32_to_cpu(data->count) <= (UINT_MAX - TPM_HEADER_SIZE - 9) / 4`, and `len == TPM_HEADER_SIZE + 9 + 4 * be32_to_cpu(data->count)`. Unmapped handles (`tpm2_map_to_vhandle(space, phandle, false) == 0`) are filtered in place using read/write indices `i`/`j`, updating `header->length` and `data->count` from `j`. [F80, F101]
- In `struct tpm2_auth`, `session_key` and `passphrase` must remain adjacent so `tpm_buf_fill_hmac_session()` and `tpm_buf_check_hmac_response()` can pass `auth->session_key` (`SHA256_DIGEST_SIZE + auth->passphrase_len`) as one buffer. `auth->session` holds the sessions offset (`>= TPM_HEADER_SIZE`) until `tpm_buf_fill_hmac_session()` sets the 1-based ordinal (`< TPM_HEADER_SIZE`), which `tpm_buf_check_hmac_response()` checks before resetting to `TPM_HEADER_SIZE`. [F83, F84]
- In `tpm_buf_fill_hmac_session()`, CFB encryption (`TPM2_SA_DECRYPT`) must run after appending parameters and before computing `cphash`/HMAC; in `tpm_buf_check_hmac_response()`, CFB decryption (`TPM2_SA_ENCRYPT`) must run only after verifying `rphash`/HMAC. Buffers passed to `sg_set_buf()`/`sg_init_one()` in `tpm_buf_append_salt()` (`buf->data`, `null_ec_key_x/y`, `auth->salt`) must be in direct-mapped kernel memory, never `vmalloc()` or stack. [F64, F162]
- In `tpm_transmit()`, `TPM_HEADER_SIZE + 3 * sizeof(u32)` bytes of `buf` must be saved before the `tpm_try_transmit()` loop and restored before each retry because `tpm_try_transmit()` overwrites `buf` in place. Any loop re-sending via `tpm_transmit_cmd()` (`tpm2_get_random()`, `tpm1_get_random()`, `tpm1_pm_suspend()`) must call `tpm_buf_reset()` and re-append the command payload on every iteration. [F66, F102]
- Because `tpm_buf_read_u8/u16/u32()` return 0 and set `TPM_BUF_BOUNDARY_ERROR` on out-of-bounds reads, callers advancing an offset by a returned length must validate the new offset against `tpm_buf_length(buf)` or `total_len` before indexing `&buf->data[offset]`. In `tpm2_get_random()`, initialize `offset = TPM_HEADER_SIZE` and add 4 when `be16_to_cpu(head->tag) == TPM2_ST_SESSIONS` before casting `&buf.data[offset]`. [F87, F96]
- `chip->locality` must be initialized to `-1` in `tpm_chip_alloc()` and reset to `-1` in `tpm_relinquish_locality()` so `tpm_chip_start()` requests locality. In `tpm2_get_cc_attrs_tbl()`, override `TPM2_CC_ATTR_CHANDLES` to 1 for `TPM2_CC_CONTEXT_SAVE` and `TPM2_CC_FLUSH_CONTEXT`. When `tpm_is_firmware_upgrade(chip)` is true, skip PCR allocation, sysfs, `hwrng`, legacy sysfs, and `tpm_devs_add/remove()`. [F54, F70, F142]
- In `crb_map_io()`, balance `__crb_request_locality(0)`/`__crb_cmd_ready()` with `__crb_go_idle()`/`__crb_relinquish_locality()` around reading `regs_t`, cast `pa_high` to `u64` before `<< 32`, clamp sizes via `crb_fixup_cmd_size()`, and require `cmd_size == rsp_size` if `cmd_pa == rsp_pa`. `crb_map_res()` must check `start != new_res.start` for 32-bit truncation and cache the base `devm_ioremap_resource()` in `*iobase_ptr`. [F92, F111, F112, F139, F144]

## Synchronization

- `tpm_try_get_ops()` acquires `chip->dev`, read-locks `chip->ops_sem`, locks `chip->tpm_mutex`, checks `TPM_CHIP_FLAG_SUSPENDED`, and calls `tpm_chip_start(chip)` in that order; its error paths and `tpm_put_ops()` must release them in reverse LIFO order. `tpm_pm_suspend()` sets `TPM_CHIP_FLAG_SUSPENDED` before `tpm_put_ops(chip)`, and `tpm_pm_resume()` clears it before `wmb()`. `chip->work_space`, `chip->last_cc`, and `chip->auth` require holding `chip->tpm_mutex` or `down_write(&chip->ops_sem)`. [F1, F26, F151]
- `dev_nums_idr` is allocated with `NULL` in `tpm_chip_alloc()`, set to `chip` via `idr_replace()` under `idr_lock` in `tpm_add_char_device()` after `cdev_device_add()`, reset to `NULL` under `idr_lock` in `tpm_del_char_device()` after `cdev_device_del()` and before `down_write(&chip->ops_sem)` clears `chip->ops = NULL`, and removed via `idr_remove()` in `tpm_dev_release()`. Unlock `idr_lock` after `get_device(&chip->dev)` and before `tpm_try_get_ops()` or `put_device()`. [F27, F130, F155]
- In `tpm_chip_unregister()`, `tpm2_end_auth_session()`, `hwrng_unregister()`, `tpm_bios_log_teardown()`, and `tpm_devs_remove()` must run before `tpm_del_char_device()` clears `chip->ops = NULL`, and drivers must call `tpm_chip_unregister()` before freeing bus/TEE resources. Both `tpm_add_hwrng()`, `out_hwrng` in `tpm_chip_register()`, and `tpm_chip_unregister()` must check `tpm_is_hwrng_enabled(chip)` (which checks `TPM_CHIP_FLAG_HWRNG_DISABLED`, set on non-Pluton AMD x86 CRB). [F7, F28, F141]
- In `struct file_priv`, `data_buffer`, `response_length`, `response_read`, `command_enqueued`, and `space` are protected by `priv->buffer_mutex` (acquired outside `ops_sem` and `tpm_mutex`). `tpm_common_write()` must run `copy_from_user()` under `buffer_mutex` before queuing `async_work`, holding `tpm_try_get_ops()` only around `tpm_dev_transmit()`. Softirq `user_reader_timeout()` must schedule `timeout_work` rather than locking `buffer_mutex`. [F30, F157, F159]
- In `tpm_common_release()`, `flush_work(&priv->async_work)` must precede `timer_delete_sync(&priv->user_read_timer)`, which must precede `flush_work(&priv->timeout_work)`; all three must finish before `tpm2_del_space()`/`kfree(priv)` in `tpmrm_release()` and before `clear_bit(0, &priv->chip->is_open)` in `tpm_release()`. When `priv->response_length` reaches 0 in `tpm_common_read()`, reset `*off = 0` and cancel/flush `user_read_timer` and `timeout_work` under `buffer_mutex`. [F29, F38, F76]
- In `st33zp24` and `tpm_i2c_nuvoton`, `wait_for_stat()` and `i2c_nuvoton_wait_for_stat()` must snapshot `intrs` into `cur_intrs` before `enable_irq()` (which `nuvoton` only calls when `queue != NULL`), while IRQ handlers increment `intrs`, wake `read_queue`, and call `disable_irq_nosync()` without bus transfers. Hold `tpm_crb_ffa->msg_data_lock` across FF-A `direct_msg_data` send/receive, `i2c_lock_bus(..., I2C_LOCK_SEGMENT)` across `tpm_i2c_infineon` transfers, and mutex `tpm_ppi_lock` around `ppi_operations_cache`. [F33, F37, F134, F160, F165, F169]

## Object Lifetimes

- After `device_initialize(&chip->dev)` in `tpm_chip_alloc()`, free `chip` only via `put_device(&chip->dev)` (`tpm_dev_release()`). If `tpm2_init_space()` fails allocating `session_buf`, free `context_buf` and set `space->context_buf = NULL`. `tpm_devs_add()` takes `get_device(&chip->dev)` for `chip->devs` (released in `tpm_devs_release()`), so errors after `device_initialize(&chip->devs)` and `tpm_devs_remove()` must call `put_device(&chip->devs)`. [F4, F6, F9]
- Because `tpm_buf_append_hmac_session()` sets `TPM2_SA_CONTINUE_SESSION`, `tpm2_end_auth_session(chip)` must be called before userspace commands in `tpm_dev_transmit()`, before `TPM2_SU_STATE` in `tpm_pm_suspend()`, in `tpm_class_shutdown()` and `tpm_chip_unregister()`, and on any error path after `tpm2_start_auth_session(chip)` that fails before `tpm_buf_check_hmac_response()` or during a `TPM2_SA_CONTINUE_SESSION` loop. [F12, F13]
- `tpm_buf_init()` and `tpm_buf_init_sized()` allocate a `PAGE_SIZE` page in `buf->data` that must be freed via `tpm_buf_destroy()` on every return path, whereas `tpm_buf_reset()`/`tpm_buf_reset_sized()` reinitialize `buf` in place. Any `struct tpm_buf` passed to `tpm_transmit_cmd()` must have a `PAGE_SIZE`-backed `buf->data` from `tpm_buf_init()`. [F15, F122]
- In `tpm_read_log_acpi()`, `log->bios_event_log` must be allocated with `kvmalloc()` and freed via `kvfree()` in `tpm_bios_log_free()`, registered with `devm_add_action()` after validation succeeds, and freed and set to `NULL` on error. Every exit path after `acpi_get_table()` in `crb_acpi_add()`, `check_acpi_tpm2()`, and `tpm_read_log_acpi()` must call `acpi_put_table()`. In `tpm_bios_measurements_open()`, call `put_device(&chip->dev)` if `seq_open()` fails. [F17, F20, F77, F138]
- `ftpm_tee_probe()` error paths and `ftpm_tee_remove()` must release `tpm_chip_register()`, `pvt_data->chip`, `pvt_data->shm`, `pvt_data->session`, and `pvt_data->ctx` in reverse LIFO order. `ftpm_mod_init()` and `init_tis()` must roll back earlier driver/device registrations on failure. [F21, F22]

## API Contracts

- `tpm_chip_alloc()` and `tpmm_chip_alloc()` return `ERR_PTR(-errno)` (`IS_ERR()`), whereas `tpm_default_chip()` and `tpm_find_get_ops()` return `NULL`. `tpm_default_chip()` increments `chip->dev`'s refcount, so `tpm_find_get_ops(NULL)` must call `put_device(&chip->dev)` after `tpm_try_get_ops(chip)`. `tpmm_chip_alloc(pdev, ops)` sets `dev_set_drvdata(pdev, chip)`, so drivers using it must store private data on `&chip->dev`. [F3, F5, F44]
- `tpm_transmit_cmd()` takes `min_rsp_body_length` excluding `TPM_HEADER_SIZE` (10 bytes) and returns `0`, `< 0` errno, or `> 0` `TPM_RC`. Callers returning 0 or `-errno` (`tpm2_start_auth_session()`) must use `tpm_ret_to_err()`; bootstrap functions (`tpm_get_pcr_allocation()`, `tpm2_get_cc_attrs_tbl()`, `tpm2_auto_startup()`, `tpm1_auto_startup()`) must map unhandled `rc > 0` to `-ENODEV`; `tpm1_get_random()` and `tpm2_get_random()` must map `rc > 0` to `-EIO`. [F39, F40, F41, F58]
- For HMAC-protected TPM2 commands, append handles (`<= 3`) via `tpm_buf_append_name()` right after the header before sessions/parameters. Without `chip->auth`, append handles via `tpm_buf_append_handle()` so `buf->handles` tracks the session offset; never call `tpm_buf_append_handle()` on `TPM_BUF_TPM2B` sized buffers. If a command bypasses `tpm2_start_auth_session()` (e.g., `disable_pcr_integrity`), it must bypass `tpm_buf_fill_hmac_session()`, `tpm_buf_check_hmac_response()`, and error-path `tpm2_end_auth_session()` in lockstep. [F62, F63, F85, F86]
- `tpm2_KDFa()` requires `bytes` to be a positive multiple of `SHA256_DIGEST_SIZE`. `tpm2_read_public()` and `tpm2_parse_read_public()` require a `name` buffer of `>= 2 + SHA512_DIGEST_SIZE` (66) bytes (not `TPM2_NAME_SIZE`). `tpm_pcr_extend()` requires `chip->nr_allocated_banks` digests ordered identically to `chip->allocated_banks[]`. `tpm2_pcr_read()` requires `pcr_idx < TPM2_PLATFORM_PCR` (24) and `digest_size <= sizeof(digest->digest)`. [F88, F89, F117, F125]
- In `tpm_chip_register()`, `tpm_chip_bootstrap()`, `tpm_sysfs_add_device()`, and `tpm_add_ppi()` must precede `tpm_add_char_device()`. `tpm_chip_start()` calls `tpm_clk_enable()`, `tpm_request_locality()`, and `tpm_cmd_ready()`, while `tpm_chip_stop()` and start error paths unwind in reverse. `tpm_pm_suspend()` must skip `TPM2_SU_STATE`/`tpm1_pm_suspend()` when `TPM_CHIP_FLAG_ALWAYS_POWERED` or `(TPM_CHIP_FLAG_FIRMWARE_POWER_MANAGED && !pm_suspend_via_firmware())`. [F131, F152, F153]
- In `struct tpm_class_ops`, when `TPM_CHIP_FLAG_SYNC` is set, `send()` writes the response into `buf` and returns its byte length; otherwise `send()` returns 0 and `recv()` reads it. In `tpm1_get_timeouts()`, `update_timeouts()` takes microseconds, whereas `update_durations()` takes a 3-element `unsigned long` array in jiffies and must initialize all 3 if setting `duration_adjusted = true`. All exported TPM APIs sleep and require process context. [F124, F170, F171, F172]

## Error Handling

- `tpm_buf_append_name()`, `tpm_buf_append_hmac_session()`, and `tpm_buf_append_hmac_session_opt()` must check `tpm2_chip_auth(chip)` before dereferencing `chip->auth`. `tpm_buf_fill_hmac_session()`, `tpm_buf_check_hmac_response()`, and `tpm2_end_auth_session()` must check `if (!auth)` before dereferencing `auth` fields, and `tpm_buf_check_hmac_response()` must jump to `out` on `rc != 0` to preserve `rc` while cleaning up or resetting `auth->session`. [F45, F46, F52]
- In `tpm2_map_response_header()`, if a new transient/session `phandle` cannot be allocated a slot in `chip->work_space`, flush it immediately via `tpm2_flush_context(chip, phandle)`. `tpm2_prepare_space()` and `tpm2_commit_space()` must check `if (!space) return 0;` for `/dev/tpm#`. [F11, F48]
- In `struct tpm_class_ops`, `cancel`, `status`, `req_canceled`, `go_idle`, `cmd_ready`, `request_locality`, `relinquish_locality`, `clk_enable`, `update_timeouts`, and `update_durations` are optional (`NULL`-checked), except every TPM 1.x driver must provide a non-NULL `cancel` for sysfs `cancel_store()`. [F47, F173]
- `tpm2_sessions_init()` must return immediately on `tpm2_create_null_primary()` failure. `tpm2_get_tpm_pt()` must check `be32_to_cpu(out->property_cnt) > 0` before reading `out->value` (else `-ENODATA`). On TPM2, `tpm_read_log_acpi()` must validate the log with `tpm_is_tpm2_log()` and return `-ENODEV` on failure so `tpm_read_log()` falls back to EFI. [F50, F78, F79]

## External Contracts

- `/dev/tpm#` (`tpm_open`) enforces single-open via `test_and_set_bit(0, &chip->is_open)` with `space = NULL`, whereas `/dev/tpmrm#` (`tpmrm_open`) allows concurrent opens with per-file `space`. `tpm_common_write()` rejects writes with `-E2BIG` (`size > TPM_BUFSIZE`), `-EBUSY` (unread response or `command_enqueued`), or `-EINVAL` (`size < 6` or `< header length`). Consumed or timed-out `data_buffer` bytes must be zeroed with `memset()` under `buffer_mutex`. [F179, F182, F183]
- When `tpm2_prepare_space()` returns `-EOPNOTSUPP` in `tpm_dev_transmit()`, synthesize a 10-byte `TPM2_ST_NO_SESSIONS` header with `TPM2_RC_COMMAND_CODE | TSS2_RESMGR_TPM_RC_LAYER` and return `sizeof(*header)`. [F95]

## Known Pitfalls

- Use `to_tpm_chip()` only on `&chip->dev` (`tpm_class`); use `container_of(dev, struct tpm_chip, devs)` for `tpmrm_class` and `container_of(inode->i_cdev, struct tpm_chip, cdevs)` in `tpmrm_open()`. [F126]
- `tpm_bios_log_setup()` must return early if `TPM_CHIP_FLAG_VIRTUAL` is set. In `eventlog/tpm2.c`, branch on `v == SEQ_START_TOKEN` before casting, and size `tcg_pcr_event2_head` entries via `calc_tpm2_event_size()`. In `tpm_read_log_efi()`, copy `efi_tpm_final_log_size` to a local before subtracting `final_events_preboot_size`, and recompute `bios_event_log_end` from `bios_event_log` after `devm_krealloc()`. [F72, F73, F103, F118, F120]
- In `tpm2_get_pcr_allocation()`, advance `marker` by `sizeof(hash_alg) + sizeof(size_of_select) + size_of_select`, not `sizeof(struct tpm2_pcr_selection)`. In `crb_send()`, clear `ctrl_cancel` before `memcpy_toio()`, run `wmb()` before start, and keep `CRB_START_INVOKE` and `crb_do_acpi_start()` as separate `if` statements. In TIS FIFO `send` callbacks (`st33zp24`, `tpm_tis_i2c`, `i2c_nuvoton`), burst-write `len - 1` bytes and write `buf[len - 1]` separately to check `TPM_STS_DATA_EXPECT`. [F104, F105, F119, F149]
