# MEMBLOCK AND MEMORY MANAGEMENT INITIALIZATION

This unit manages physical memory regions during early boot via the memblock allocator and transitions the system to the runtime page/buddy and slab allocators during memory management initialization. It discovers, reserves, allocates, and trims physical memory ranges, initializes NUMA node (`pg_data_t`), zone (`struct zone`), and `struct page` metadata (including parallelized deferred page initialization), and hands free memory over to the buddy allocator in `mm_core_init()`, alongside early `memtest`, bootmem page tracking for hotplug, and `reserve_mem=` reservations with Kexec Handover (KHO) support.

## Architecture & Data Flow

- Under `CONFIG_DEFERRED_STRUCT_PAGE_INIT`, only the highest populated zone per node (`end_pfn == pgdat_end_pfn(pgdat)`) may defer pages, with `first_deferred_pfn` aligned to `PAGES_PER_SECTION` (or `ULONG_MAX` when none remain); `defer_init()` must reset `nr_initialised = 0` when `prev_end_pfn != end_pfn` so the first section of each new zone is initialized before deferring. In `deferred_init_memmap_chunk()`, `deferred_init_pages()` must initialize the full `MAX_ORDER_NR_PAGES` chunk (and reserved/hole pages must already be initialized) before `deferred_free_pages()` runs. [F21, F78, F98]
- Clamp `size` via `memblock_cap_size(base, &size)` before computing `base + size` in `memblock_overlaps_region()`, `memblock_add_range()`, `memblock_isolate_range()`, or `memblock_is_region_memory()`. Physical-to-PFN conversions must round usable/free memory inward via `[PFN_UP(start), PFN_DOWN(end))` (`memblock_region_memory_base_pfn()`, `__free_memory_core()`) and reserved ranges outward via `[PFN_DOWN(start), PFN_UP(end))` (`reserve_bootmem_region()`). [F62, F102]
- Before passing a `struct memblock_region` node ID `nid` to `NODE_DATA(nid)`, `node_online(nid)`, or `reserve_bootmem_region()`, verify `numa_valid_node(nid)` and fall back to `early_pfn_to_nid()`, because `memblock_add()` sets `nid = MAX_NUMNODES` and `memblock_reserve()` sets `nid = NUMA_NO_NODE`. [F65]
- `memblock_memory` must remain a `__refdata` pointer to `&memblock.memory` cleared to `NULL` by `memblock_discard()` so `should_skip_region()` and `__next_mem_range()` never touch discarded `__initdata_memblock` data when `!CONFIG_ARCH_KEEP_MEMBLOCK`. Conversely, `physmem` and `memblock_physmem_init_regions` must never be marked `__initdata_memblock` or freed in `memblock_discard()` because `for_each_physmem_range()` accesses them at runtime. [F124, F125]
- Region shifts in `memblock_remove_region()`, `memblock_merge_regions()`, and `memblock_insert_region()` must use `memmove()` scaled by `sizeof(*rgn)`. When `memblock_isolate_range()` splits a region, subtract the split length from both `rgn->size` and `type->total_size` before `memblock_insert_region()`; when `memblock_remove_region()` reaches `type->cnt == 0`, reset `type->regions[0]` (`base = size = flags = 0`, `nid = MAX_NUMNODES`); and in `memblock_merge_regions()`, decrement `type->cnt` and `end_rgn` without incrementing `i`. [F49, F70, F89, F114]
- `memblock.current_limit` must only clamp explicit upper-bound addresses in `memblock_alloc_internal()` (for virtual allocations) and must not clamp explicit `end` addresses in `memblock_alloc_range_nid()` or `memblock_find_in_range_node()`. `memblock_cap_memory_range()` must test `!memblock_memory->total_size` (not region count) for empty memory, and both `memblock_cap_memory_range()` and `memblock_enforce_memory_limit()` must truncate `memblock.reserved` in lockstep with `memblock.memory`. [F43, F54]
- Before accessing newly allocated physical memory via `__va()` or `phys_to_virt()`, `memblock_double_array()` and `memblock_alloc_range_nid()` must call `accept_memory()` on the physical range, and `deferred_free_pages()` must call `accept_memory()` upfront for chunks not naturally aligned to `MAX_ORDER_NR_PAGES`. [F135]
- In `memmap_init_zone_range()` and `memmap_init()`, PFNs in intermediate holes `[hole_pfn, start_pfn)` and in the trailing hole up to `round_up(end_pfn, PAGES_PER_SECTION)` (`CONFIG_SPARSEMEM`) or `round_up(end_pfn, MAX_ORDER_NR_PAGES)` (`CONFIG_FLATMEM`) must be initialized via `init_unavailable_range()`. [F77]
- Under `CONFIG_FLATMEM`, `alloc_node_mem_map()` must round `pgdat->node_start_pfn` down and `pgdat_end_pfn(pgdat)` up to `MAX_ORDER_NR_PAGES`, offset `pgdat->node_mem_map = map + (pgdat->node_start_pfn - start)`, and account pages globally via `memmap_boot_pages_add()`. Under `!CONFIG_SPARSEMEM`, `usemap_size()` must add `zone_start_pfn & (pageblock_nr_pages - 1)` to `zonesize` before rounding to `pageblock_nr_pages`, multiplying by `NR_PAGEBLOCK_BITS`, and rounding to `BITS_PER_LONG`. [F13, F75, F76]
- When `!IS_ENABLED(CONFIG_HIGHMEM)`, `__free_memory_core()` must clamp `end_pfn` to `max_low_pfn`, and under `WANT_PAGE_VIRTUAL`, `__init_single_page()` must only call `set_page_address(page, __va(pfn << PAGE_SHIFT))` when `!is_highmem_idx(zone)`. [F138]

## Synchronization

- In `page_alloc_init_late()`, `atomic_set(&pgdat_init_n_undone, num_node_state(N_MEMORY))` must run before spawning any `deferred_init_memmap` kthread, and `wait_for_completion(&pgdat_init_all_done_comp)` must finish before `static_branch_disable(&deferred_pages)`, `memblock_discard()`, `shuffle_free_memory()`, `set_zone_contiguous()`, and `page_ext_init()` execute. Every exit path of `deferred_init_memmap()` (including `first_init_pfn == ULONG_MAX`) must call `pgdat_init_report_one_done()`. [F10, F16, F17]
- `deferred_init_memmap()` must read `pgdat->first_deferred_pfn`, set `pgdat->first_deferred_pfn = ULONG_MAX`, and release `pgdat_resize_unlock(pgdat, &flags)` before calling `padata_do_multithreaded(&job)`. Conversely, `deferred_grow_zone()` must revalidate `first_deferred_pfn == pgdat->first_deferred_pfn` after acquiring `pgdat_resize_lock(pgdat, &flags)` and hold it across `deferred_init_memmap_chunk()` and the update to `pgdat->first_deferred_pfn`. [F18, F19]
- In `deferred_init_memmap_chunk()` and `deferred_grow_zone()`, align `spfn + 1` (`ALIGN(spfn + 1, MAX_ORDER_NR_PAGES)` / `SECTION_ALIGN_UP(spfn + 1)`) so already-aligned `spfn` values advance; because `deferred_init_memmap_chunk()` runs both from preemptible `padata_do_multithreaded()` workers and with IRQs disabled under `pgdat_resize_lock()` in `deferred_grow_zone()`, it must check `irqs_disabled()` and call `touch_nmi_watchdog()` instead of `cond_resched()` when IRQs are disabled. [F95, F129]
- In `mm_core_init()` and `page_alloc_init_late()`, `kho_memory_init()`, `page_ext_init_flatmem()`, and `mem_debugging_and_hardening_init()` (where active `CONFIG_PAGE_POISONING` forces `init_on_alloc` and `init_on_free` off) must run before `memblock_free_all()`; `page_ext_init_flatmem_late()` must run after `memblock_free_all()` and `kmem_cache_init()`; and `page_ext_init()` must run only after `vmalloc_init()` and (when `deferred_struct_pages` is true) after `wait_for_completion(&pgdat_init_all_done_comp)`. [F15, F28, F148, F149]
- All accesses to `early_pfnnid_cache` via `__early_pfn_to_nid()` must hold `early_pfn_lock`. Runtime accesses to `reserved_mem_table` in `reserve_mem_find_by_name()` and `reserve_mem_release_by_name()` must hold `reserve_mem_lock` continuously across lookup, `free_reserved_area()`, and `map->size = 0`; and in `reserve_mem_init()`, `prepare_kho_fdt()` must finish constructing `kho_fdt` before `register_kho_notifier(&reserve_mem_kho_nb)`. [F22, F23, F25]

## Object Lifetimes

- `memblock_discard()` and `memblock_double_array()` must never free static `memblock_memory_init_regions` or `memblock_reserved_init_regions`; `memblock_discard()` must check `memblock_reserved_in_slab` and `memblock_memory_in_slab` to release slab arrays with `kfree()` and non-slab arrays with `memblock_free_late()` using `PAGE_ALIGN(sizeof(struct memblock_region) * type->max)` (matching the `new_alloc_size` reserved by `memblock_double_array()`), and reset `memblock_memory = NULL`. [F4, F85, F112]
- `memblock_free_late()` must release pages through `memblock_free_pages()` rather than `__free_pages_core()` directly so PFNs above `first_deferred_pfn` with uninitialized buddy `struct page`s are skipped under `CONFIG_DEFERRED_STRUCT_PAGE_INIT`; and both `memblock_free_pages()` and `init_cma_reserved_pageblock()` must call `clear_page_tag_ref(page)` before `__free_pages_core()` / `__free_pages()`. [F6, F7, F27]
- `get_page_bootmem()` / `put_page_bootmem()` pack `enum bootmem_type` in the low 4 bits of `page->private` (`1..0xf`) and `info` in `info << 4`. When `put_page_bootmem()` drops a page's refcount to 1 (`page_ref_dec_return(page) == 1`), it must clear `PagePrivate` and `page->private`, reinitialize `page->lru`, call `kmemleak_free_part_phys(PFN_PHYS(page_to_pfn(page)), PAGE_SIZE)`, and release the page via `free_reserved_page(page)`. [F1, F73]
- In `__init_zone_device_page()`, every `ZONE_DEVICE` page must have `__SetPageReserved` set, `pgmap` bound, `zone_device_data` cleared to `NULL`, and its refcount zeroed (`set_page_count(page, 0)`) for all `pgmap->type` values except `MEMORY_DEVICE_GENERIC`; and `compound_nr_pages()` must check `vmemmap_can_optimize(altmap, pgmap)` and return `pgmap_vmemmap_nr(pgmap)` when optimization is inactive. [F127, F143]

## API Contracts

- Physical memblock allocation/search functions (`memblock_phys_alloc*()`, `memblock_alloc_range_nid()`, `memblock_find_in_range*()`, `__memblock_find_range_*()`) return physical address `0` on failure, whereas virtual allocators (`memblock_alloc*()`, `memmap_alloc()`) return `NULL`. `memblock_alloc_try_nid()` zeroes memory, `memblock_alloc_*_raw()` and `memblock_phys_alloc*()` leave it uninitialized, and `memmap_alloc()` poisons it with `page_init_poison()`. [F29, F38]
- All memblock region-mutation APIs (`memblock_set_node()`, `memblock_add*()`, `memblock_remove()`, `memblock_phys_free()`, `memblock_reserve*()`, `memblock_mark_*()`, `memblock_clear_*()`) take `(base, size)` in bytes rather than `(start, end)` addresses, and range overlap checks on `[base, base + size)` must use strict inequalities via `memblock_addrs_overlap()`, never `<=` or `>=`. [F42, F63]
- Because `memblock_mark_nomap()` does not notify kmemleak, callers marking a memblock-allocated range with `MEMBLOCK_NOMAP` must call `kmemleak_ignore_phys()` (or free it in kmemleak). Reserved regions marked with `MEMBLOCK_RSRV_NOINIT` via `memblock_reserved_mark_noinit()` are skipped by `memmap_init_reserved_pages()`, so the caller must initialize their `struct page` entries itself. [F5, F40]
- In `should_skip_region()`, `MEMBLOCK_HOTPLUG` (when `movable_node` is enabled), `MEMBLOCK_NOMAP`, and `MEMBLOCK_DRIVER_MANAGED` regions are skipped unless set in `flags` (so `for_each_mem_range()` / `for_each_mem_range_rev()` must pass `MEMBLOCK_HOTPLUG | MEMBLOCK_DRIVER_MANAGED`), whereas setting `MEMBLOCK_MIRROR` or `MEMBLOCK_KHO_SCRATCH` in `flags` causes `should_skip_region()` to skip all regions lacking that flag. [F83, F84]
- When `memblock_alloc_range_nid()` is called after `slab_is_available()`, it must `WARN_ON_ONCE` and fall back to `kzalloc_node(size, GFP_NOWAIT, nid)`. Any function (including `static inline` helpers in `include/linux/memblock.h` like `memblock_set_bottom_up()`) that directly references `memblock` or other `__initdata_memblock` state must be annotated with `__init`, `__init_memblock`, or `__ref`. [F134, F142]

## Error Handling

- To free virtual pointers from `memblock_alloc*()`, callers must use `memblock_free(ptr, size)` rather than `memblock_phys_free(__pa(ptr), size)` because `memblock_free()` guards `if (ptr)` while `memblock_phys_free()` does not check for `NULL`/`0`. [F33]
- In `prepare_kho_fdt()` and `reserve_mem_init()`, if FDT construction or `register_kho_notifier()` fails after `kho_fdt` is allocated, `kho_fdt` must be freed via `put_page(kho_fdt)` and reset to `NULL` while preserving the non-zero `err`. In `reserve_mem_kho_retrieve_fdt()`, if `fdt_node_check_compatible()` fails after assigning `static void *fdt = phys_to_virt(fdt_phys)`, `fdt` must be reset to `NULL` before returning. [F35, F36]

## Known Pitfalls

- Inside `memblock_double_array()`, update `type->regions` and `type->max` to `new_array` before freeing `old_array` or calling `memblock_reserve_kern()`, update `*in_slab` to `use_slab` only after freeing `old_array`, and in `memset(new_array + type->max, 0, old_size)` use element count `type->max` for pointer addition and byte size `old_size` for length. [F50, F111]
- Because `memblock_double_array()` replaces `type->regions` and invalidates interior pointers, callers must resize before iterating (`memblock_isolate_range()` ensuring `type->cnt + 2 <= type->max` and passing `idx--` when splitting `rend > end`) or retry when `memblock.reserved.max` changes (`memmap_init_reserved_pages()`). [F51, F52, F113]
- Because `memblock_remove_region()` shifts higher regions down via `memmove()`, multi-region removal loops (`memblock_remove_range()`, `memblock_cap_memory_range()`) must iterate in reverse, and `memblock_trim_memory()` must decrement `r--` after removing a region in `for_each_mem_region(r)`. [F90]
- In `__memblock_find_range_top_down()`, verify `this_end >= size` before subtracting `this_end - size` in `round_down(this_end - size, align)`; in `__memblock_find_range_bottom_up()`, after `cand = round_up(this_start, align)`, verify `cand < this_end` before evaluating `this_end - cand >= size` (never `cand + size <= this_end`) to prevent unsigned wraparound or underflow. [F68, F69]
- Guard `__ffs(start)` with `if (start)` in `__free_pages_memory()` and `node_map_pfn_alignment()`, and cast node/zone PFNs to `u64` (or `PFN_PHYS()`) before `<< PAGE_SHIFT` whenever PFNs can reach 4 GiB / `ZONE_HIGHMEM`. [F101, F106]
- `memmap_init_range()` omits `pfn++` from its `for (pfn = start_pfn; pfn < end_pfn; )` header because `overlap_memmap_init(zone, &pfn)` advances `pfn` to `memblock_region_memory_end_pfn(r)` before `continue`; any other `continue` path must increment `pfn`. In `free_memmap()`, compute hole boundary page pointers as `pfn_to_page(start_pfn - 1) + 1` and `pfn_to_page(end_pfn - 1) + 1`, and round their physical addresses inward via `PAGE_ALIGN(__pa(start_pg))` and `PAGE_ALIGN_DOWN(__pa(end_pg))`. [F94, F116]
- `deferred_init_memmap()` must check `!cpumask_empty(cpumask)` before calling `set_cpus_allowed_ptr(current, cpumask)` with `cpumask_of_node(pgdat->node_id)`, and `deferred_page_init_max_threads()` must clamp `cpumask_weight(node_cpumask)` to at least `1U` so CPU-less NUMA nodes still initialize their deferred pages. [F140]
