# LIVE PATCHING

The LIVE PATCHING subsystem applies and reverts function-level patches to a running Linux kernel and loadable modules without rebooting. It redirects patched functions via ftrace (`klp_ftrace_handler`), enforces per-task consistency using reliable stack traces and `TIF_PATCH_PENDING` during transitions, resolves deferred ELF relocations (`.klp.rela.*` / `SHN_LIVEPATCH`) across module load/unload events, and provides shadow variable (`klp_shadow_*`) and system state (`klp_state`) APIs.

## Architecture & Data Flow
- When `func->transition` is true and `current->patch_state == KLP_TRANSITION_UNPATCHED`, `klp_ftrace_handler()` advances `func` to `list_entry_rcu(func->stack_node.next, struct klp_func, stack_node)` and must exit to `unlock` if `&func->stack_node == &ops->func_stack` before reading `func->nop` or `func->new_func`. [F67]
- For a NOP `struct klp_func` (`func->nop == true`), `func->new_func` is `NULL` while the target object is unloaded and is set to `func->old_func` only in `klp_init_object_loaded()`; `klp_init_func()` and `klp_ftrace_handler()` must check `func->nop` before inspecting `func->new_func` or redirecting the instruction pointer. [F33]
- In `klp_check_stack_func()`, stack entries must be checked against `func->new_func`/`new_size` when `klp_target_state == KLP_TRANSITION_UNPATCHED`, `func->old_func`/`old_size` when patching with a singular `ops->func_stack`, and `prev->new_func`/`new_size` (`prev = list_next_entry(func, stack_node)`) when stacked. [F74]
- Every transition pass touching `patch_state` or `TIF_PATCH_PENDING` (`klp_init_transition`, `klp_start_transition`, `klp_try_complete_transition`, `klp_complete_transition`, `klp_reverse_transition`, `klp_force_transition`) must iterate `idle_task(cpu)` via `for_each_possible_cpu()` alongside `for_each_process_thread()`. `klp_try_complete_transition()` must not break early on `klp_try_switch_task()` failure, must call `wake_up_if_idle(cpu)` for unswitched online idle tasks, and must directly switch offline CPUs' idle tasks under `cpus_read_lock()`. [F43, F73]
- When `nops_only` is true in `__klp_unpatch_object()` and `__klp_free_objects()`, only `klp_func` entries with `func->nop` set may be unpatched and freed, and `obj->patched` and `obj` itself must only be cleared or freed if `obj->dynamic` is true. [F47]
- Because `klp_init_patch()` appends `new_patch` to the tail of `klp_patches`, `klp_unpatch_replaced_patches()` and `klp_free_replaced_patches_async()` must `return` immediately upon reaching `old_patch == new_patch` (not `continue`), and functions that unlink entries (`__klp_free_funcs()`, `__klp_free_objects()`, `klp_free_replaced_patches_async()`) must use `*_safe` list iterators. [F68, F69]
- In `klp_write_section_relocs()`, when `apply` is true, `klp_resolve_symbols()` must populate `sym->st_value` for all `SHN_LIVEPATCH` symbols before `apply_relocate_add()`, rejecting `vmlinux` symbols in module `.klp.rela.*` sections; `%55[^.]` and `%511[^,]` `sscanf()` widths must stay `< MODULE_NAME_LEN` and `< KSYM_NAME_LEN` per `BUILD_BUG_ON`. [F55, F56]
- In `klp_match_callback()`, when `args->pos == 0`, the callback must return `0` on the first match (`args->count == 1`) and only return `1` when `args->count > 1`, so `klp_find_object_symbol()` detects duplicate symbols and rejects `sympos == 0` with `-EINVAL`. [F64]

## Synchronization
- `klp_ftrace_handler()` (`notrace`) must disable preemption via `ftrace_test_recursion_trylock()`, and `klp_update_patch_state()` must wrap `test_and_clear_tsk_thread_flag(task, TIF_PATCH_PENDING)` and `task->patch_state = READ_ONCE(klp_target_state)` in `preempt_disable_notrace()` / `preempt_enable_notrace()` (with `task` being `current` or inactive unless forcing), so `klp_synchronize_transition()` (`schedule_on_each_cpu(klp_sync)`) waits for them even when RCU is not watching. [F24, F84, F90]
- In `klp_init_transition()`, `klp_target_state` and all tasks'/idle threads' `patch_state` must be set followed by `smp_wmb()` before `func->transition = true`; in `__klp_enable_patch()`, `klp_init_transition()` and another `smp_wmb()` must precede `klp_patch_object()`, pairing with `smp_rmb()` in `klp_ftrace_handler()` so newly patched functions never see `KLP_TRANSITION_IDLE`. [F16, F17]
- In `__klp_disable_patch()` and `klp_reverse_transition()`, `smp_wmb()` must precede `klp_start_transition()` (`TIF_PATCH_PENDING`), pairing with `test_and_clear_tsk_thread_flag()` in `klp_update_patch_state()`; `klp_reverse_transition()` must also call `klp_synchronize_transition()` after clearing `TIF_PATCH_PENDING` before inverting `klp_transition_patch->enabled` and `klp_target_state`. [F18, F23]
- In `klp_complete_transition()`, when `klp_target_state == KLP_TRANSITION_UNPATCHED`, `klp_unpatch_objects()` and `klp_synchronize_transition()` must precede `func->transition = false`; when `KLP_TRANSITION_PATCHED`, `klp_synchronize_transition()` must run after `func->transition = false` and before resetting `task->patch_state` to `KLP_TRANSITION_IDLE`. [F21, F22]
- Every `for_each_process_thread()` loop in `transition.c` must hold `read_lock(&tasklist_lock)` to serialize with `klp_copy_process()`, which explicitly syncs `child->patch_state` and `TIF_PATCH_PENDING` with `current`; `klp_try_complete_transition()` must release `tasklist_lock` before acquiring the sleeping `cpus_read_lock()`. [F29, F42, F93]
- `klp_check_and_switch_task()` and `klp_check_stack()` require preemption disabled (`lockdep_assert_preemption_disabled()`) to protect per-CPU `klp_stack_entries` (`MAX_STACK_ENTRIES`, with `klp_check_stack_func()` testing the half-open `[func_addr, func_addr + func_size)`); for `task != current`, `klp_try_switch_task()` must invoke `klp_check_and_switch_task()` via `task_call_func()` so the task is pinned inactive. [F28, F61]
- `enabled_store()`, `force_store()`, and `klp_transition_work_fn()` must hold `klp_mutex` while checking `klp_transition_patch` and calling transition functions; in `klp_enable_patch()`, every error path after `mutex_lock(&klp_mutex)` must unlock `klp_mutex`. [F4, F26]
- `klp_find_object_module()` must hold `rcu_read_lock()` (`guard(rcu)()`) while calling `find_module(obj->name)` and reading `mod->klp_alive`, and must only set `obj->mod` when `mod->klp_alive` is true (updated by `klp_module_coming()` / `klp_module_going()` under `klp_mutex`). [F27]
- `klp_shadow_get()` traverses `klp_shadow_hash` under `rcu_read_lock()`, while mutations hold `spin_lock_irqsave(&klp_shadow_lock, flags)` and free via `hash_del_rcu()` + `kfree_rcu()`; in `__klp_shadow_get_or_alloc()`, after unlocked `kzalloc()`, `klp_shadow_lock` must be acquired to re-check `klp_shadow_get()` and run `ctor` before `hash_add_rcu()`. [F30, F86]

## Object Lifetimes
- Every `klp_free_patch_start(patch)` (under `klp_mutex`) must pair with `klp_free_patch_finish(patch)` outside `klp_mutex`. `klp_free_patch_finish()` must `wait_for_completion(&patch->finish)` (`klp_kobj_release_patch()`) before calling `module_put(patch->mod)` (skipped if `patch->forced` is true, set by `klp_force_transition()` on removed/replaced patches) and must not access `patch` after. [F1, F2, F3]
- Asynchronous patch freeing (`klp_free_patch_async()` or `klp_free_replaced_patches_async()`) must be triggered in `klp_try_complete_transition()`, not inside `klp_complete_transition()`, because `klp_cancel_transition()` also calls `klp_complete_transition()` when `klp_enable_patch()` will free the patch synchronously. [F12]
- Once `klp_alloc_object_dynamic()` or `klp_alloc_func_nop()` calls `klp_init_object_early()` or `klp_init_func_early()`, ownership transfers to its `kobject` and it must only be freed by `klp_kobj_release_object()` or `klp_kobj_release_func()` via `kobject_put()`, never by direct `kfree()`. [F5]
- When completing a `replace` transition to `KLP_TRANSITION_PATCHED` in `klp_complete_transition()`, `klp_unpatch_replaced_patches(klp_transition_patch)` must run before `klp_discard_nops(klp_transition_patch)` so each NOP `klp_func` is the sole remaining entry on `ops->func_stack` when `klp_unpatch_func()` unpatches it. [F6]
- Because `klp_find_ops()` inspects `list_first_entry(&ops->func_stack, struct klp_func, stack_node)->old_func`, `klp_patch_func()` must link `ops->node` and `func->stack_node` before `register_ftrace_function(&ops->fops)` (clearing `ftrace_set_filter_ip()` on error), and `klp_unpatch_func()` must only unregister `ops->fops` (and clear the filter before `list_del_rcu(&func->stack_node)` and `kfree(ops)`) when `list_is_singular(&ops->func_stack)`. [F7, F8, F48]
- `klp_find_object_module()` and `klp_module_coming()` store a borrowed `struct module *` in `obj->mod` without a module refcount; `klp_free_object_loaded()` must clear `obj->mod = NULL`, `func->old_func = NULL`, and (for `func->nop`) `func->new_func = NULL` on unload. [F9]
- `klp_post_unpatch_callback(obj)` only invokes `obj->callbacks.post_unpatch` when `obj->callbacks.post_unpatch_enabled` is true (set by a successful `klp_pre_patch_callback(obj)`) and must clear `post_unpatch_enabled = false` afterwards. [F11]
- `copy_module_elf()` allocates `mod->klp_info`, `sechdrs`, and `secstrings` and redirects `mod->klp_info->sechdrs[symndx].sh_addr` to `mod->core_kallsyms.symtab` (as the init symtab is freed after `do_init_module()`), unwinding in reverse order on error and in `free_module_elf()`. [F15]

## API Contracts
- `klp_object.name` (and `objname` in symbol/reloc helpers) is `NULL` for `vmlinux` and non-NULL for modules (`klp_is_module(obj)` must be checked before string calls; `klp_module_coming()` rejects modules named `"vmlinux"`). Static arrays require zeroed sentinels: `patch->objs` ends at `!obj->funcs && !obj->name`, `obj->funcs` at `!func->old_name && !func->new_func && !func->old_sympos`, and `patch->states` at `!state->id`. [F32, F60, F99]
- In `struct klp_func` and `klp_find_object_symbol()`, `old_sympos` / `sympos` uses `0` to require a unique symbol and a 1-based index (`> 0`) for the Nth match, whereas sysfs naming in `klp_init_func()` maps `old_sympos == 0` to `1` (`func->old_sympos ? func->old_sympos : 1`). [F37]
- When `klp_patch_func()` allocates a `klp_ops`, it must resolve the ftrace address via `ftrace_location((unsigned long)func->old_func)` and set `ops->fops.flags` with `FTRACE_OPS_FL_DYNAMIC | FTRACE_OPS_FL_IPMODIFY | FTRACE_OPS_FL_PERMANENT` (plus `FTRACE_OPS_FL_SAVE_REGS` when `!CONFIG_HAVE_DYNAMIC_FTRACE_WITH_ARGS`). [F107]
- `klp_get_prev_state()` requires `klp_transition_patch != NULL` and must scan `klp_patches` up to `klp_transition_patch` (updating `last_state`, not returning the first match). In `klp_is_patch_compatible()`, a `patch->replace` patch must declare a `klp_state` with `state->version >= old_state->version` for every active state in `klp_patches`. [F53, F75, F101]
- `klp_shadow_get*()` and `klp_shadow_alloc()` allocate `size + sizeof(*new_shadow)` zeroed bytes outside `klp_shadow_lock` and pass/return a borrowed pointer to `shadow->data` (never `struct klp_shadow` or `ERR_PTR`); `ctor`/`dtor` run in atomic context under `spin_lock_irqsave(&klp_shadow_lock, flags)`, non-zero `ctor` return frees the struct and returns `NULL`, and `shadow->data` must not be accessed after `klp_shadow_free*()`. [F13, F38, F77, F85]
- `klp_module_going()` must accept `mod->state == MODULE_STATE_COMING` in addition to `MODULE_STATE_GOING`, because `prepare_coming_module()` calls `klp_module_going()` while still `MODULE_STATE_COMING` if coming notifiers fail after `klp_module_coming()`. [F76]

## Error Handling
- `klp_init_patch_early()`, `klp_init_object_early()`, and `klp_init_func_early()` must initialize `kobj` and link every static and dynamic `klp_object` and `klp_func` into `patch->obj_list` and `obj->func_list` before any fallible step in `klp_init_patch()`, because error cleanup unconditionally calls `list_del()` and `kobject_put()` on all entries. [F34]
- `__klp_unpatch_object()` must iterate `klp_for_each_func(obj, func)` and unpatch every function with `func->patched == true` even when `obj->patched` is `false`, because `klp_patch_object()` calls `klp_unpatch_object(obj)` to roll back partially patched functions before `obj->patched = true` is set. [F72]
- In `klp_module_coming()`, jumping to `err:` is only valid inside `klp_for_each_object(patch, obj)` after `obj->mod = mod` is set; `err:` runs `klp_post_unpatch_callback(obj)`, clears `mod->klp_alive = false` and `obj->mod = NULL`, and calls `klp_cleanup_module_patches_limited(mod, patch)` to revert only patches preceding `patch`. [F10, F71]
- In `klp_init_object_loaded()`, `klp_find_object_symbol()` returns `0` on success and negative errno on error, whereas `kallsyms_lookup_size_offset()` returns non-zero on success and `0` on failure (which must be converted to `-ENOENT`). [F35]
- Callers of `klp_check_and_switch_task()` / `klp_check_stack(task, &old_name)` must pass a valid non-NULL `const char **`, and because `*oldname` is only assigned when returning `-EADDRINUSE`, `klp_try_switch_task()` must not read `old_name` on `0`, `-EBUSY`, `-EINVAL`, or default paths. [F39, F83]

## External Contracts
- In `enabled_store()`, after rejecting `patch->enabled == enabled`, `if (patch == klp_transition_patch)` (`klp_reverse_transition()`) must precede `else if (!enabled)` (`__klp_disable_patch()`, which fails with `-EBUSY` during transitions), and re-enabling a disabled idle patch returns `-EINVAL`. In `force_store()`, writing `false` is a no-op, while `true` requires `patch == klp_transition_patch` under `klp_mutex`. [F63, F105, F106]

## Known Pitfalls
- `klp_shadow_free_all()` iterates `klp_shadow_hash` with `hash_for_each()` (not `hash_for_each_safe()`) while calling `klp_shadow_free_struct()`; this is only safe because `klp_shadow_free_struct()` unlinks with `hash_del_rcu()` (preserving `shadow->node.next`) and frees via `kfree_rcu()` under `klp_shadow_lock`. [F70]
- In `arch/powerpc/include/asm/livepatch.h`, `klp_init_thread_info()` computes `end_of_stack(p) + 1` using typed `unsigned long *` pointer arithmetic to advance `livepatch_sp` by one `unsigned long` word past `STACK_END_MAGIC`. Broken by: adding `sizeof(unsigned long)` without casting to a byte pointer, or casting to `void *`/`char *` while adding `1`. [F79]
