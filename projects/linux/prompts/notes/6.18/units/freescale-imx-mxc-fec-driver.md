# FREESCALE IMX / MXC FEC DRIVER

This driver manages the Freescale/NXP Fast Ethernet Controller (FEC) and Enhanced Network (ENET) MAC IP blocks on ColdFire, i.MX, Vybrid (MVF600), and S32V234 SoCs. It implements a multi-queue Ethernet `net_device` with up to 3 TX/RX hardware rings (with AVB credit-based shaping), NAPI polling, `page_pool` RX buffer management, XDP (`DROP`, `PASS`, `TX`, `REDIRECT`), software TSO with hardware checksum/VLAN acceleration, C22/C45 MDIO bus management, and an IEEE 1588 PTP Hardware Clock (PHC) with PPS/PEROUT support.

## Architecture & Data Flow

- Because `struct bufdesc` (8B) and `struct bufdesc_ex` (32B) share `struct bufdesc *` ring pointers and use arch-dependent endianness (`__le*` on ARM/ARM64 vs `__be*` on ColdFire) with swapped `cbd_datlen`/`cbd_sc` order, all ring traversal must use `fec_enet_get_nextdesc()` / `fec_enet_get_prevdesc()` and `fec_enet_get_bd_index()` (`>> bd->dsize_log2`), never C pointer arithmetic, and all field accesses must use `cpu_to_fec16()`/`fec16_to_cpu()` and `cpu_to_fec32()`/`fec32_to_cpu()`. [F68, F73]
- In `struct fec_enet_priv_tx_q`, `txq->dirty_tx` starts at `txq->bd.last` and points to the descriptor immediately before the next slot to reclaim; `fec_enet_get_free_txdesc_num()` must compute `(((const char *)txq->dirty_tx - (const char *)txq->bd.cur) >> txq->bd.dsize_log2) - 1` in a signed `int` (adding `txq->bd.ring_size` if `< 0`) so `bd.cur` never catches `dirty_tx`. [F70, F102]
- When recycling TX or RX descriptors in `fec_enet_txq_submit_skb()`, `fec_enet_txq_submit_frag_skb()`, `fec_enet_txq_put_data_tso()`, `fec_enet_txq_put_hdr_tso()`, `fec_enet_txq_xmit_frame()`, or `fec_enet_rx_queue()`, `bdp->cbd_sc` must be masked with `~BD_ENET_TX_STATS` or `~BD_ENET_RX_STATS` rather than zeroed so `BD_SC_WRAP` is preserved. [F59]
- For multi-descriptor `FEC_TXBUF_T_SKB` frames (`fec_enet_txq_submit_skb()`, `fec_enet_txq_submit_tso()`), `txq->tx_buf[index].buf_p` is set to `skb` only on the final descriptor and left `NULL` on earlier ones. Any SKB buffer with low bits set in `fep->tx_align` or with `FEC_QUIRK_SWAP_FRAME` must be copied into `txq->tx_bounce[index]` (and byte-swapped there via `swap_buffer()`, never in-place on `skb->data`) before `dma_map_single()`. [F71, F74]
- In `fec_enet_rx_queue()`, `pkt_len` from `bdp->cbd_datlen` includes the 4-byte FCS (`sub_len = 4`) plus 2 bytes of `FEC_RACC_SHIFT16` padding when `FEC_QUIRK_HAS_RACC` is set (`data_start = FEC_ENET_XDP_HEADROOM + 2`, `sub_len = 6`); both `xdp_prepare_buff()` and `skb_reserve()`/`skb_put()` must apply `data_start` and `pkt_len - sub_len`. [F154]
- All PTP state/timer calls (`fec_ptp_init()`, `fec_ptp_save_state()`, `fec_ptp_restore_state()`, `fec_ptp_start_cyclecounter()`) and `struct bufdesc_ex` accesses must be gated on `fep->bufdesc_ex` (forced `false` in `fec_probe()` if `devm_clk_get(&pdev->dev, "ptp")` fails). When `fep->bufdesc_ex` is true, any `fec_ctrl_reset()` in `fec_restart()` or `fec_stop()` must be bracketed by `fec_ptp_save_state(fep)` beforehand and by re-setting `FEC_ECR_EN1588`, `fec_ptp_start_cyclecounter(ndev)`, and `fec_ptp_restore_state(fep)` afterward. [F48, F117]
- `fec_ptp_restore_state()` must clear `fep->pps_enable = 0` under `fep->tmreg_lock` before calling `fec_ptp_enable_pps(fep, 1)` (which returns early if `fep->pps_enable == enable`). Every timestamp written to `FEC_ATIME`, `FEC_TCCR`, or `fep->next_counter` must be masked with `fep->cc.mask` (`CLOCKSOURCE_MASK(31)`). `fec_ptp_init()` must replace a zero `clk_get_rate(fep->clk_ptp)` with `NSEC_PER_SEC` in `fep->cycle_speed` and run before `fec_enet_init()`. [F49, F96, F98]
- `fec_change_mtu()` requires `!netif_running(ndev)` and updates `fep->pagepool_order` and `fep->rx_frame_size` in lockstep. Toggling `NETIF_F_RXCSUM` via `fec_enet_set_netdev_features()` must update `FLAG_RX_CSUM_ENABLED` in `fep->csum_flags` and restart the MAC in `fec_set_features()` if running. `fec_enet_close()` must call `fec_enet_update_ethtool_stats(ndev)` before `fec_enet_clk_enable(ndev, false)`. `fec_enet_get_ethtool_stats()` must advance `u64 *data` by element counts (`FEC_STATS_SIZE / sizeof(u64)` and `XDP_STATS_TOTAL`), not byte sizes. [F51, F52, F54, F80, F105]

## Synchronization

- Before setting `BD_ENET_TX_READY` or `BD_ENET_RX_EMPTY` in `bdp->cbd_sc`, descriptor fields and `tx_buf` must be written before a `wmb()`/`dma_wmb()`. Lockless TX ring coordination also requires `wmb()`/`dma_wmb()` before updating `txq->bd.cur`, and in `fec_enet_tx_queue()` an `rmb()` between `READ_ONCE(txq->bd.cur)` and `READ_ONCE(bdp->cbd_sc)` plus a `wmb()` before updating `txq->dirty_tx`. [F140, F141]
- Because XDP shares hardware TX queues with the network stack, `fec_enet_xdp_tx_xmit()` and `fec_enet_xdp_xmit()` must hold `__netif_tx_lock(nq, cpu)` across `txq_trans_cond_update(nq)` and `fec_enet_txq_xmit_frame()`. [F21]
- When `netif_running(ndev)` is true, callers of `fec_restart()` or `fec_stop()` must disable NAPI (`napi_disable(&fep->napi)`) and stop/lock TX queues (`netif_tx_lock_bh` or `netif_tx_disable`) beforehand; in `fec_enet_adjust_link()`, `netif_stop_queue(ndev)` must precede `napi_disable()`. [F20, F137]
- Because `fec_restart()` and `fec_stop()` run under `netif_tx_lock_bh()`, functions on their paths (`fec_enet_bd_init()`, `fec_ptp_save_state()`, `fec_ptp_restore_state()`, `fec_ptp_start_cyclecounter()`) must use `spin_lock_irqsave(&fep->tmreg_lock, ...)` and `dev_kfree_skb_any()`, never `fep->ptp_clk_mutex` or sleeping calls. [F134]
- Whenever both `fep->ptp_clk_mutex` and `fep->tmreg_lock` are acquired (`fec_ptp_gettime()`, `fec_ptp_settime()`, `fec_ptp_enable()`, `fec_time_keep()`), `fep->ptp_clk_mutex` must be locked outer to `fep->tmreg_lock` and `fep->ptp_clk_on` verified true before touching `fep->tc` or PTP registers. In `fec_ptp_enable_pps()`, `fep->tmreg_lock` must be held with `spin_lock_irqsave()` before reading `fep->pps_enable` until `fep->pps_enable` and timer registers are updated. [F16, F18]
- Synchronous cancellations in `fec_drv_remove()` (`cancel_work_sync(&fep->tx_timeout_work)`) and `fec_ptp_stop()` (`cancel_delayed_work_sync(&fep->time_keep)` and `hrtimer_cancel(&fep->perout_timer)`) must execute outside `rtnl_lock()`, `fep->ptp_clk_mutex`, and `fep->tmreg_lock`. In `fec_enet_collect_events()` and `fec_restart()`, `FEC_ENET_MII` must be masked out (`& ~FEC_ENET_MII`) of writes to `FEC_IEVENT` so `fec_enet_mdio_wait()` can poll it. [F125, F145]

## Object Lifetimes

- Every TX ring cleanup path (`fec_enet_tx_queue()`, `fec_enet_bd_init()`, `fec_enet_free_buffers()`) must free `txq->tx_buf[i].buf_p` according to `txq->tx_buf[i].type` (`FEC_TXBUF_T_SKB`, `FEC_TXBUF_T_XDP_NDO`, `FEC_TXBUF_T_XDP_TX`), clear `buf_p` to `NULL`, and reset `type` to `FEC_TXBUF_T_SKB` (since SKB/TSO submit paths do not write `type`). Outside NAPI poll context (`fec_enet_bd_init()`, `fec_enet_free_buffers()`), XDP entries must use `xdp_return_frame()` and `page_pool_put_page(..., false)`, never `xdp_return_frame_rx_napi()` or `allow_direct = true`. [F2, F133]
- In `fec_enet_rx_queue()`, after `fec_enet_update_cbd()` replaces the descriptor's page, the old `page` is owned by the RX path and must be recycled via `page_pool_put_page()` or `xdp_do_redirect()` in `fec_enet_run_xdp()`, `page_pool_recycle_direct()` if `build_skb()` fails, or `skb_mark_for_recycle(skb)` on success. [F155]
- In `fec_enet_close()`, `phy_stop()`, `napi_disable()`, `netif_tx_disable()`, `fec_stop()`, and `phy_disconnect()` must complete before `fec_enet_free_buffers()` releases `rxq->rx_skb_info[i].page` via `page_pool_put_full_page()` (not `page_pool_release_page()`), unregisters `rxq->xdp_rxq`, destroys `rxq->page_pool`, and clears `rxq->page_pool = NULL`. [F5, F29]
- In `fec_enet_bpf()` (`XDP_SETUP_PROG`), the old program from `xchg(&fep->xdp_prog, bpf->prog)` must be released with `bpf_prog_put(old_prog)`; `xdp_features_clear_redirect_target(dev)` must precede disabling NAPI/TX queues and `fec_restart(dev)` on removal, and `xdp_features_set_redirect_target(dev, false)` must follow `fec_restart(dev)` on install. [F13, F113]
- In `fec_ptp_init()`, `fep->tmreg_lock`, `fep->cc`, `fep->tc`, `fep->time_keep`, and `fep->perout_timer` must be initialized before requesting `fec_pps_interrupt`, calling `ptp_clock_register()`, and scheduling `fep->time_keep`. `fec_ptp_stop()` must call `fec_ptp_enable_pps(fep, 0)`, `cancel_delayed_work_sync(&fep->time_keep)`, and `hrtimer_cancel(&fep->perout_timer)` before unregistering `fep->ptp_clock` or freeing `ndev`. [F15, F27]
- Non-devres allocations from `fec_enet_alloc_queue()` must be freed via `fec_enet_free_queue(ndev)` if `fec_enet_init()` fails before `netif_napi_add()`, and via `fec_enet_deinit(ndev)` on post-`fec_enet_init()` failure and in `fec_drv_remove()`. `free_netdev(ndev)` must be called last after all `ndev`/`fep` accesses. In `fec_drv_remove()`, `clk_disable_unprepare()` on `clk_ahb`/`clk_ipg` requires `pm_runtime_get_sync(&pdev->dev) >= 0`, while `pm_runtime_put_noidle()` and `pm_runtime_disable()` are unconditional. [F7, F8, F9]
- `fec_runtime_suspend()`/`resume()` manage `clk_ahb`/`clk_ipg`, while `fec_enet_clk_enable()` manages `clk_enet_out`, `clk_ptp`, `clk_ref`, and `clk_2x_txclk`. In `fec_suspend()`, a running interface must stop PHY/NAPI/TX/MAC and mask IRQs before `fec_enet_clk_enable(ndev, false)`, and gate `pm_runtime_force_suspend()`/`resume()` on `fep->rpm_active`. [F30, F131]
- With `FEC_WOL_FLAG_ENABLE` on a running interface, `fec_suspend()` must set `FEC_WOL_FLAG_SLEEP_ON` before `fec_stop()`, pair `disable_irq()`/`enable_irq_wake(fep->wake_irq)`, call `fec_enet_stop_mode(fep, true)`, and keep `fep->reg_phy` on, while `fec_resume()` must clear `FEC_WOL_FLAG_SLEEP_ON` and `FEC_ECR_MAGICEN | FEC_ECR_SLEEP` before `fec_restart()`. [F65, F130]
- With `FEC_QUIRK_SINGLE_MDIO`, secondary instances (`fep->dev_id > 0`) reuse `fec0_mii_bus` and increment `mii_cnt`, and `fec_enet_mii_remove()` must only unregister/free `fep->mii_bus` when `--mii_cnt == 0`. OF nodes, PHY device lookups, and fixed-link registrations must be balanced with `of_node_put()`, `put_device()`, and `of_phy_deregister_fixed_link()` on all paths. [F12, F114]

## API Contracts

- When `fec_enet_txq_xmit_frame()` fails (`-EBUSY` or `-ENOMEM`), it must not free `frame`; `fec_enet_xdp_xmit()` must stop on the first negative return and return `sent_frames` so the caller frees unsent frames, and `fec_enet_run_xdp()` recycles the page on `XDP_TX` failure. In `fec_enet_start_xmit()` paths, any error branch that frees `skb` via `dev_kfree_skb_any()` must return `NETDEV_TX_OK` (`0`), never `NETDEV_TX_BUSY`. [F1, F34, F148]
- In `fec_enet_tx_queue()`, on a completed non-SKB descriptor (`type != FEC_TXBUF_T_SKB`), the loop must break if `budget == 0` before unmapping DMA or calling `xdp_return_frame_rx_napi()` / `page_pool_put_page(..., true)`, while SKBs use `napi_consume_skb(skb, budget)`. In `fec_enet_rx_napi()`, each iteration must poll both `fec_enet_rx(ndev, budget - done)` and `fec_enet_tx(ndev, budget)` across queues from highest index down to 0, calling `napi_complete_done(napi, done)` only when `done < budget`. [F152, F153]
- Before DMA-mapping an SKB in `fec_enet_txq_submit_skb()` or `fec_enet_txq_submit_tso()`, `fec_enet_clear_csum()` must be called (using `skb_cow_head(skb, 0)` when `CHECKSUM_PARTIAL` before zeroing IPv4/L4 checksums). Hardware TX timestamping (`BD_ENET_TX_TS`, `SKBTX_IN_PROGRESS`, `skb_tstamp_tx()`) must be gated on both `fep->hwts_tx_en` and `fep->bufdesc_ex`. [F149, F151]
- In `fec_enet_run_xdp()`, DMA sync length must be `max(xdp->data_end - xdp->data, len)` after `bpf_prog_run_xdp()`, and `fec_enet_rx_queue()` must call `xdp_do_flush()` if `FEC_ENET_XDP_REDIR` occurred. With `FEC_QUIRK_SWAP_FRAME`, XDP is unsupported (`fec_enet_bpf()` returns `-EOPNOTSUPP`). In `fec_enet_rx_queue()`, `fec_enet_rx_vlan()` must run before `eth_type_trans()` when `fep->bufdesc_ex` and `BD_ENET_RX_VLAN` are set. [F156, F157, F159]
- For `PTP_CLK_REQ_PEROUT`, `fec_ptp_enable()` requires `flags == 0`, `index == fep->pps_channel`, `period_ns <= FEC_PTP_MAX_NSEC_PERIOD` (4s), and `perout_stime > curr_time`, sets `fep->reload_period = div_u64(period_ns, 2)`, and defers `FEC_TCCR` setup via `fep->perout_timer` when `perout_stime - curr_time > FEC_PTP_MAX_NSEC_COUNTER`. [F46, F78]

## Error Handling

- In `fec_enet_txq_submit_frag_skb()`, because the forward loop advances `bdp` from `txq->bd.cur` via `fec_enet_get_nextdesc()` before mapping each fragment, the error rollback loop must reset `bdp = txq->bd.cur` and advance `bdp` before each `dma_unmap_single()` for `i < frag`, returning `ERR_PTR(-ENOMEM)` without freeing `skb`; `fec_enet_txq_submit_skb()` must check `IS_ERR(last_bdp)`, unmap `txq->bd.cur`, and call `dev_kfree_skb_any(skb)`. [F4, F36, F88]
- In `fec_enet_rx_queue()`, `page` and `cbd_bufaddr` must be saved before `fec_enet_update_cbd()`; if `page_pool_dev_alloc_pages()` returns NULL, `fec_enet_update_cbd()` leaves the existing descriptor intact while `fec_enet_rx_queue()` increments `rx_dropped` and jumps to `rx_processing_done`. In `fec_enet_run_xdp()`, `XDP_REDIRECT`/`XDP_TX` errors must jump to `xdp_err` after `rxq->stats[RX_XDP_DROP]++`, calling `trace_xdp_exception()` only when `act != XDP_DROP`. [F32, F84]
- When acquisitions for `rxq->page_pool`, `fep->stop_gpr.gpr`, `fep->clk_2x_txclk`, `fep->clk_ptp`, `fep->reg_phy`, or `fep->ptp_clock` return `IS_ERR()`, the field must be reset to `NULL`. `of_phy_connect()` and `of_phy_find_device()` return NULL on failure, whereas `phy_connect()` returns `ERR_PTR`. `fec_get_mac()` must propagate `-EPROBE_DEFER` from `of_get_mac_address()`. [F31, F37, F41, F44]

## Known Pitfalls

- In `fec_enet_rx_queue()`, `status` is XORed with `BD_ENET_RX_LAST` before error checks so a missing `BD_ENET_RX_LAST` tests nonzero while a valid bit is cleared, and every per-frame error or non-`FEC_ENET_XDP_PASS` path inside the loop must use `goto rx_processing_done` (never `continue`) so `BD_ENET_RX_EMPTY` is restored and `bdp` advances. [F81, F89]
- After a full-ring loop (`i < ring_size`) advancing `bdp` via `fec_enet_get_nextdesc()`, `bdp` wraps to `bd.base`, so `fec_enet_bd_init()`, `fec_enet_alloc_rxq_buffers()`, and `fec_enet_alloc_txq_buffers()` must call `fec_enet_get_prevdesc()` before setting `BD_SC_WRAP` or `txq->dirty_tx`. [F85]
- In `fec_enet_txq_submit_skb()`, `bdp` must remain at `txq->bd.cur` to set `BD_ENET_TX_READY` on the first descriptor while `last_bdp` sets `tx_buf[index].buf_p = skb` and `txq->bd.cur`. In `fec_enet_txq_submit_tso()`, `index` must retain the last data descriptor index from the inner loop before the outer loop advances `bdp` for `txq->bd.cur`. [F86, F92]
- In `fec_ptp_adjfine()`, `ppb == 0` must return early, `rhs = (u64)ppb * (u64)fep->ptp_inc` and `lhs` must use 64-bit arithmetic, and 64-bit divisions (`div_u64(lhs, rhs)` inside `1 <= i <= fep->ptp_inc` and `div_u64(period_ns, 2)`) must use `div_u64()`, never `/`. [F93, F94, F95]
- Hardware quirks: `FEC_QUIRK_ERR007885` requires polling `readl(txq->bd.reg_desc_active)` up to 4 times before writing `0` only if a read returns `0`; `FEC_QUIRK_BUG_CAPTURE` requires `udelay(1)` after setting `FEC_T_CTRL_CAPTURE` in `fec_ptp_read()`; `FEC_MII_DATA` in `fec_enet_mii_init()` must only be cleared when `FEC_QUIRK_CLEAR_SETUP_MII` is set. [F120, F126, F127]
