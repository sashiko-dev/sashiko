# ANALOG DEVICES INC IIO DRIVERS

This unit contains Linux Industrial I/O (IIO) accelerometer, ADC, and DAC drivers for Analog Devices and Linear Technology hardware, bridging SPI, I2C, parallel-bus, and IIO-backend interfaces to the IIO subsystem.

## Architecture & Data Flow

- In `ad7124` and `ad7173`, runtime changes to channel configs must update `cfg` and set `cfg->live = false` rather than writing directly to slot registers. Hardware-relevant fields must be inside `struct_group(config_props, ...)` and mirrored in `static_assert`, `ad7124_find_similar_live_cfg()`, and `ad7173_is_setup_equal()`. Slot eviction (`ad7124_pop_config()`, `ad7173_free_config_slot_lru()`) must clear `cfg.live = false` across all `st->num_channels` sharing the evicted `cfg_slot`. [F44, F45, F106]
- In `ad7124.c`, `ad7124_set_filter_type_attr()` must call `ad7124_set_channel_odr()` after changing `cfg->filter_type`, clamping `odr_sel_bits` to `[1, 2047]`, and `cfg_slots_status` must remain `unsigned long`. In `ad7173.c`, setting sampling rate must update both `sinc5_odr_index` and `sinc3_odr_div` (clamped to `[1U, AD7173_FILTER_SINC3_MAP_DIV]`); `ad_sigma_delta_info.num_slots` must equal `info->num_channels` (4/8/16), while setup slot IDA allocation is bounded by `info->num_configs` (4/8). [F47, F49, F95, F97, F112, F123]
- In `ad7606.c`, scale accesses index `st->chan_info[0]` when `!st->sw_mode_en` and `st->chan_info[chan->scan_index]` when `st->sw_mode_en`; `st->write_scale()` takes `i + ci->reg_offset` while `ci->range` stores `i`. In `ad7606_get_chan_config()`, 1-based DT `"reg"` maps to `st->chan_info[reg - 1]`. In `ad7616_write_scale_sw()`, split `ch` into `ch & 0x1` and `ch >> 1` before `AD7616_RANGE_CH_*`. In `ad7606_set_sampling_freq()`, sample `ad7606_pwm_is_swinging(st)` and `duty_cycle == period` before overwriting `period`. [F56, F57, F69, F71]
- In `adxl345_core.c`, runtime FIFO, event, or measurement updates (`adxl345_set_fifo`, `adxl345_set_act_inact_en`, `adxl345_write_raw`, `adxl345_write_event_value`, `adxl345_fifo_reset`) must bracket writes with `adxl345_set_measure_en(st, false)` and `true`. `adxl345_set_range()` must sample `range_old` first and rescale `ADXL345_REG_THRESH_ACT` and `st->inact_threshold` (via `adxl345_set_inact_threshold()`) by `adxl345_range_factor_tbl`, clamped to `[1, U8_MAX]`. `adxl345_set_odr()` must call `adxl345_set_inact_time(st, 0, 0)`. [F26, F54, F55, F104]
- In `adxl345_state`, `ad7266_state`, `ad7280_state`, `ad7298_state`, `ad7606_state`, `ad7766`, and `ad7779_state`, `__aligned(IIO_DMA_MINALIGN)` transfer/scan buffers must stay at the end of the struct after all non-DMA fields and be sized to hold all channel samples plus an 8-byte aligned `s64` timestamp (`aligned_s64`). [F136, F156]
- In `ad3552r-hs.c`, `st->config_d` must mirror `AD3552R_REG_ADDR_INTERFACE_CONFIG_D`; while `AD3552R_MASK_SPI_CONFIG_DDR` is set, register updates must use `st->data->bus_reg_write()` rather than `ad3552r_hs_update_reg_bits()` or `ad3552r_hs_reg_read()`. Secondary-region multi-byte registers (`>= AD3552R_SECONDARY_REGION_START`) stream in descending address order, so two-channel streaming (`loop_len = 4`) in `ad3552r_hs_buffer_postenable()` must start at `AD3552R_REG_ADDR_CH_DAC_16B(1)` (0x2C). [F200, F215]
- In `ad5592r-base.c`, `ad5592r_alloc_channels()` must verify child `'reg' < ARRAY_SIZE(st->channel_modes)` and allocate `1 + 2 * num_channels` `iio_chan_spec` entries; `ad5592r_gpio_read()` must OR `st->gpio_in` with `AD5592R_GPIO_READBACK_EN` when writing `AD5592R_REG_GPIO_IN_EN`; `ad5592r_write_raw()` (`SCALE`) must update `st->cached_gp_ctrl` under `st->lock`. In `ad5064`, `ad5446`, and `ad5686`, `pwr_down_mode` stores 1-based hardware codes (`1..3`) while IIO enum callbacks use 0-based indices (`mode - 1`), so probe must initialize `pwr_down_mode` to `1`. [F195, F205, F206, F217]
- In `ad5686.c`, 2-bit fields in `st->pwr_down_mask` and `st->pwr_down_mode` are indexed by `chan->channel * 2` (never `chan->address`), and on 16-channel `AD5686_REGMAP` chips, channels `> 0x7` use powerdown register `address = 0x8` with `val >> 16`. When packing/unpacking 24-bit big-endian frames in `union { __be32 d32; u8 d8[4]; }` via `cpu_to_be32()`/`be32_to_cpu()`, 3-byte transfers must use `&data[i].d8[1]`. In `ad5360.c`, `ad5380.c`, and `ad5755.c`, `chip_info->channel_template` must be copied into per-device `iio_chan_spec` arrays before mutating fields. [F208, F220, F223]

## Synchronization

- In `ad7124.c`, `st->cfgs_lock` protects `cfg`, `cfg_slots_status`, and `live_cfgs_fifo`; `ad7124_update_scan_mode()` must call `__ad7124_set_channel()` while holding `st->cfgs_lock`. Callers must acquire `iio_device_claim_direct()` before `st->cfgs_lock` because `ad7124_update_scan_mode()` takes `st->cfgs_lock` under IIO `mlock`. In `ad7173.c`, `ad7173_write_raw()`, `ad7173_set_filter_type()`, and `ad7173_write_syscalib()` must hold `iio_device_claim_direct()`, and `ad7173_set_channel()` must run in process context (`GFP_KERNEL` IDA). [F15, F16, F143]
- In `ad7606.c`, `ad7606_write_raw()` acquires `st->lock` before `iio_device_claim_direct()`, so callbacks invoked under IIO `mlock` (`ad7606_update_scan_mode()`, `ad7606_buffer_ops`, `ad7606_backend_buffer_ops`) must never acquire `st->lock`. `ad7606_interrupt()` is a threaded IRQ calling `iio_trigger_poll_nested(st->trig)`, so `ad7606_trigger_handler()` must use `iio_get_time_ns(indio_dev)` rather than `pf->timestamp`. [F17, F138]
- Direct-mode reads and writes in `ad7606` (`ad7606_read_raw`), `ad7779` (`__ad7779_read_raw`, `__ad7779_write_raw`), `ad7266` (`ad7266_read_single`), `ad7298` (`ad7298_scan_direct`, `ad7298_scan_temp`), and `ad3552r-hs` (`ad3552r_hs_write_raw`) must be wrapped in `iio_device_claim_direct()` and `iio_device_release_direct()` so bus transfers and shared buffers do not race with buffered streaming or DDR mode. [F18, F20, F142, F172]
- In `ad5592r-base.c` and `ad3552r-hs.c`, functions using `guard(mutex)` or `scoped_guard` must never call `mutex_unlock()`. In `ad5592r-base.c`, `gpio_chip` callbacks must hold `st->gpio_lock` across `st->gpio_out`/`in`/`val` and GPIO register accesses, while IIO callbacks must hold `st->lock` across `st->ops` and `st->cached_dac`/`cached_gp_ctrl`. Post-probe writes and cache updates must also hold `st->lock` in `ad5064.c`, `ad5446.c`, `ad5758.c`, and around `*_write_unlocked` in `ad5360.c`, `ad5421.c`, and `ad5755.c`. [F159, F176, F177, F178, F182, F184, F290]

## Object Lifetimes

- In `ad7606_probe()`, when `!st->gpio_convst || st->offload_en`, `st->cnvst_pwm` must be set low via `ad7606_pwm_set_low()` and registered with `ad7606_pwm_disable` via `devm_add_action_or_reset()` before `st->bops->iio_backend_config()`; runtime stop paths (`ad7606_scan_direct()`, buffer predisable) must call `ad7606_pwm_set_low()` (not `pwm_disable()`) on all exit paths. In `ad7606_spi_offload_buffer_postenable()`, unwind `spi_optimize_message`, `spi_offload_trigger_enable`, and `ad7606_pwm_set_swing` in reverse order on error and in predisable. [F1, F9, F10, F127]
- In `ad7124_probe()` and `ad7173_probe()`, `devm_ad_sd_setup_buffer_and_trigger()` must run before `ad7124_calibrate_all()` and `ad7173_setup()`. In `ad4111_openwire_event()` and `ad7173_fw_parse_channel_config()`, `cfg.openwire_comp_chan` must be initialized and restored to `-1` (and `AD4111_GPIO_GP_OW_EN` cleared) on all exit paths so `ad7173_set_channel()`/`ad7173_disable_one()` do not redirect register accesses. [F4, F14, F34]
- In `ad3552r_hs_probe()`, call `ad3552r_hs_debugfs_init()` after `devm_iio_device_register()`. In `ad3552r_hs_buffer_predisable()`, switch the bus to `AD3552R_IO_MODE_SPI` and disable DDR on both target (`st->config_d`) and backend (`iio_backend_ddr_disable()`) before `ad3552r_hs_update_reg_bits()`. In `ad5592r_probe()`, run `ad5592r_set_channel_modes()` before `ad5592r_gpio_init()`, and in non-devres `iio_device_register()` drivers (`ad5360`, `ad5449`, `ad5592r`, `ad5764`), call `iio_device_unregister()` before disabling regulators or freeing channels. [F162, F165, F174, F279, F297]

## API Contracts

- In `ad7173.c` and `ad7124.c`, `ad_sd_calibrate()` and `ad_sigma_delta_info` callbacks (`set_channel`, `disable_one`) take the 0-based channel slot index (`chan->address` or `i`), never `chan->channel` or `ch->ain`. In `ad7124_calibrate_all()`, lower `AD7124_ADC_CONTROL_POWER_MODE` to `AD7124_MID_POWER` when `>= AD7124_FULL_POWER` before `__ad7124_calibrate_all()` and restore it afterward. In `ad7173_update_scan_mode()`, if enabled channels have unequal setups sharing a `cfg_slot`, clear `cfg.live = false` on all channels before returning `-EINVAL`. [F29, F118, F157]
- In `ad7606`, when `st->bops->iio_backend_config` or `st->offload_en` is active, omit `IIO_CHAN_SOFT_TIMESTAMP` (and omit `INDIO_DIRECT_MODE` and `BIT(IIO_CHAN_INFO_RAW)` when `iio_backend_config` is set); when `st->offload_en` is true, `ad7606_spi_update_scan_mode()` must reject partial `scan_mask`s (`bitmap_weight != num_adc_channels`) with `-EINVAL`. `ad7606_spi_reg_read()` must set `.cs_change = 1` on the first `spi_transfer`, and `ad7606_write_os_hw()`/`ad7606b_sw_mode_setup()` must pass a `DECLARE_BITMAP(..., 3)` bitmap to `gpiod_multi_set_value_cansleep()`. [F107, F125, F147, F149]
- Triggered buffer handlers (`ad7606`, `ad7779`, `ad7266`, `ad7298`, `ad7766`, `ad5766`) must call `iio_trigger_notify_done()` on all exit paths (`ad7606` also re-asserts `gpio_convst`; `ad5766` holds `st->lock`). When `.read_avail` returns `IIO_AVAIL_LIST` for a `[][2]` table, set `*length` to twice the pair count. `ext_info.write` callbacks must return `len` on success, and `.debugfs_reg_access` callbacks must branch on `if (readval)`, store `*readval`, and return `0`. [F111, F152, F153, F155, F167, F288, F302]
- Register read helpers returning payload or errno (`ad5360`, `ad5421`, `ad5504`, `ad5686`, `ad5755`, `ad5758`) must be checked with `ret < 0` (including before `!(ret & mask)` in `ad5758_wait_for_task_complete()`). I2C write callbacks (`ad5064`, `ad5622`, `ad5686`) must normalize positive byte counts from `i2c_master_send()` to `0`. `ad3552r_hs_update_reg_bits()` requires `val` pre-shifted to `mask`. Shared core code in dual-bus drivers (`ad7606`, `ad5064`, `ad5446`, `ad5592r`/`93r`, `ad5686`/`96`) must never downcast `st->dev`. [F113, F188, F189, F196, F242, F261]

## Error Handling

- In `ad7606.c`, optional callbacks in `struct ad7606_bus_ops` (`sw_mode_config`, `update_scan_mode`, `offload_config`, `iio_backend_config`) must be checked for `NULL` before invocation; SPI offload presence must be checked via `st->offload_en` (not `st->bus_data` or `bus_data->offload`, which holds `ERR_PTR(-ENODEV)`), and `st->cnvst_pwm` / `IIO_CHAN_INFO_SAMP_FREQ` must only be used when `!st->gpio_convst || st->offload_en`. [F28, F31, F41]
- When a hardware helper runs between `iio_device_claim_direct()` and `iio_device_release_direct()`, release direct mode and check `ret < 0` before using `*val` or mutating state, and store return values of fallible write helpers (`ad5360_write_unlocked`, `ad5421_write_unlocked`) in signed `int` variables. In `ad3552r_hs_buffer_postenable()` and `ad5592r_probe()`, error unwind labels must not overwrite `ret` with teardown return values. [F30, F187, F194]
- When `devm_regulator_get_optional()` returns `ERR_PTR(-ENODEV)`, `ad7291_probe()`, `ad7298_probe()`, `ad5592r_probe()`, and `ad7303_probe()` must reset the stored pointer (`reg` / `vref_reg`) to `NULL`, whereas `ad7124_probe()` must leave `st->vref[i]` as `ERR_PTR(-ENODEV)` so `ad7124_init_config_vref()` can reject unpopulated external references with `IS_ERR()`. [F32, F33, F191]
- In `ad7124.c`, after any `ad_sd_calibrate()` call in `__ad7124_calibrate_all()` or `ad7124_syscalib_locked()`, read back `AD7124_GAIN(cfg_slot)` or `AD7124_OFFSET(cfg_slot)` into `cfg->calibration_gain` or `cfg->calibration_offset`; in `ad7124_write_raw()`, reject negative values and `val == 0 && val2 == 0` before `ad7124_set_channel_odr()`. In `adxl345_core.c`, store the tri-state `int` return of `adxl345_is_act_inact_ac()` and `adxl345_is_act_inact_en()` in a signed `int` and check `< 0` before treating it as boolean. [F35, F36, F94]

## Known Pitfalls

- In `ad7173_fw_parse_channel_config()`, when `st->info->has_temp` is true, index 0 holds `ad7173_temp_iio_channel_template` and the child-node loop starts at `chan_index = 1`, resetting `is_current_chan = false` and `*chan = ad7173_channel_template` on every iteration; ODR indices in `ad7173` must start at `st->info->odr_start_value` (not 0). When updating shadow registers like `st->adc_mode` (`ad7173`) or `st->adc_control` (`ad7124`), clear the mask with `& ~mask` before `|= FIELD_PREP(mask, val)`. [F81, F82, F83, F122]
- In `ad7606`, `ad7606_spi_offload_buffer_postenable()` must compute `xfer->len` from `scan_type->realbits`, not `storagebits`; `ad7606_scan_direct()` must read `buf32[ch]` when `realbits > 16` else `buf16[ch]` and mask with `GENMASK(realbits - 1, 0)` before `sign_extend32()`; `ad7606_spi_reg_write()` must mask `val & 0xFF`; `ad7606_par8_read_block()` must pass byte count `num * 2` to `insb()` after `_buf++`; `ad7606_par_probe()` with `dev_fwnode()` must use `device_get_match_data()` and check `"io-backends"` before IRQ/MMIO setup. [F72, F73, F109, F126, F128]
- In `ad5064`, `ad5360`, `ad5504`, `ad5686`, and `ad5770r`, pass `chan->address` to hardware helpers while using `chan->channel` to index state arrays and bitmasks. In `ad3552r_get_custom_gain()`, read custom gain properties from `"custom-output-range-config"` (`gain_child`), not `child`. In `ad5504.c`, `st->pwr_down_mask` is active-high (1 = powered up) and every `AD5504_ADDR_CTRL` write requires a follow-up `AD5504_ADDR_NOOP`. In `ad5766.c`, `st->dither_enable` is active-low (0 = enabled) and `ad5766_get_dither_source()` must subtract 1 from the shifted field. [F197, F233, F241, F245]
