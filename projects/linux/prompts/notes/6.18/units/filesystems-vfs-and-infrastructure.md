# FILESYSTEMS (VFS and infrastructure)

This unit implements VFS pathname resolution and directory operations (`fs/namei.c`), mount namespaces and propagation (`fs/namespace.c`, `fs/pnode.c`, `fs/mount.h`), file opening/truncation (`fs/open.c`), pipes (`fs/pipe.c`), POSIX ACLs (`fs/posix_acl.c`), `nsfs` and `pidfs` (`fs/nsfs.c`, `fs/pidfs.c`), pseudo-filesystem and block I/O helpers (`fs/libfs.c`, `fs/mpage.c`, `fs/mbcache.c`), early boot rootfs/initramfs (`init/do_mounts*.c`, `init/initramfs.c`), VFS headers (`include/linux/fs*.h`), and Rust VFS abstractions (`rust/kernel/fs*.rs`).

## Architecture & Data Flow
- In `handle_mounts()`, save `nd->next_seq` before `__follow_mount_rcu(nd, path)`; if it returns `false`, restore `path->mnt`, `path->dentry`, and `nd->next_seq` before `try_to_unlazy_next(nd, dentry)`. In `open_last_lookups()`, if `step_into()` returns a non-NULL symlink target, clear `LOOKUP_OPEN | LOOKUP_CREATE | LOOKUP_EXCL` from `nd->flags`. [F85, F86]
- `struct mount::mnt_ns` can be `NULL`, `MNT_NS_INTERNAL` (`ERR_PTR(-EINVAL)`), or a `struct mnt_namespace *`, so test `is_mounted()` (`!IS_ERR_OR_NULL(mnt->mnt_ns)`) before dereferencing `mnt->mnt_ns`. `mnt_pprev_for_sb` steals bit 0 for `WRITE_HOLD`, requires `__aligned(1)`, and must not be dereferenced while `WRITE_HOLD` is set. [F138, F238]
- In `attach_recursive_mnt()`, look up any preexisting mount `q` at `child->mnt_mountpoint` via `__lookup_mnt()`, call `commit_tree(child)` (folding `ns->pending_mounts` into `ns->nr_mounts`, or zeroing `pending_mounts` on rollback), and run `lock_mnt_tree(child)` on cross-`user_ns` attaches before `mnt_change_mountpoint()` reparents `q` onto `topmost_overmount(child)`. [F252, F254, F285, F349]
- `make_visible()` and `__umount_mnt()` must update `parent->overmount` in lockstep when attaching/detaching at `parent->mnt.mnt_root`. In `propagate_umount()`, call `reparent(m->overmount)` only when `!will_be_unmounted(over)`, do not unlink `candidates` in `trim_ancestors()` during `list_for_each_entry_safe()` while draining `handle_locked()` with `while (!list_empty(&candidates))`, and clear transient `T_MARKED`/`T_UMOUNT_CANDIDATE` flags in `mnt_t_flags`. [F250, F251, F257, F287]
- Cached `struct posix_acl` objects on an inode store `s_user_ns` IDs (apply `mnt_idmap` only at VFS boundaries `vfs_set_acl_idmapped_mnt()`, `vfs_posix_acl_to_xattr()`, and `posix_acl_permission()`) and are shared across readers, so `__posix_acl_create()`, `__posix_acl_chmod()`, and `posix_acl_create()` must `posix_acl_clone()` before in-place mutation. [F266, F360]

## Synchronization
- Lock hierarchy: `sb_start_write` (`SB_FREEZE_WRITE`) -> `inode->i_rwsem` / `sb->s_umount`; when mounting, `inode_lock(dentry->d_inode)` -> `namespace_lock()` (`namespace_sem`) -> `mount_lock`, and `__unlock_mount()` must release `inode_unlock()` and `unpin_mountpoint()` (under `read_seqlock_excl(&mount_lock)`) before `namespace_unlock()`. [F213, F214, F376]
- Code that unmounts (`umount_tree()`, `umount_mnt()`) or sets `emptied_ns` must use `namespace_lock()`/`namespace_unlock()` rather than raw `down_write`/`up_write(&namespace_sem)`. Never call `path_put()` (or `__free(path_put)`) while holding `namespace_sem` unless the path retains a non-zero refcount, and never call `path_overmounted()` under `lock_mount_hash()`. [F193, F325, F327]
- Walking `mnt->mnt_mounts` or `mnt->mnt_parent` requires `mount_lock` (`read_seqlock_excl` or `write_seqlock`) or `namespace_sem`; modifying propagation state requires exclusive `namespace_lock()` outside `lock_mount_hash()`. Callers of `__lookup_mnt()` under `rcu_read_lock()` must check `read_seqretry(&mount_lock, ...)` and retry or take `read_seqlock_excl(&mount_lock)`. [F211, F216, F218]
- After `lock_mount_hash()`, `mntput_no_expire()` and synchronous `do_umount()` must issue `smp_mb()` before `mnt_get_count()` or `propagate_mount_busy()` (pairing with `__legitimize_mnt()`). In `mnt_get_write_access()`, disable preemption around `mnt_writers`, issue `smp_mb()` before spinning on `__test_write_hold()`, and `smp_rmb()` before `mnt_is_readonly()`, pairing with `mnt_hold_writers()`/`mnt_unhold_writers()` under `mount_lock`. [F208, F209, F210, F328]
- In `lock_rename()` and `lock_rename_child()`, hold `s_vfs_rename_mutex` whenever `lock_two_directories()` walks `d_parent` to lock two distinct directories, and drop it if both directories are equal (in `lock_rename_child(c1, p2)`, unlock `p2->d_inode` before taking `s_vfs_rename_mutex` if `c1->d_parent != p2`). In `vfs_rename()`, lock any directory child before any non-directory child, and lock two non-directories via `lock_two_nondirectories()`. [F41, F43, F154]
- When `vfs_unlink()`, `vfs_link()`, or `vfs_rename()` populates `*delegated_inode`, callers (`do_unlinkat`, `do_linkat`, `do_renameat2`) must release all directory `i_rwsem` locks and `s_vfs_rename_mutex` before `break_deleg_wait(&delegated_inode)`; `do_unlinkat()` must also pin the victim with `ihold(inode)` and defer `iput(inode)` until after `inode_unlock()`, resetting `inode = NULL` (and `should_retry = false` in `do_renameat2()`) before retry jumps. [F9, F44, F126]
- During `LOOKUP_RCU`: `inode_operations.permission` (`MAY_NOT_BLOCK`), `check_acl()` (`get_cached_acl_rcu()`, returning `-ECHILD` on `is_uncached_acl()`), `get_inode_acl(..., true)` when `ACL_DONT_CACHE` is used, `pick_link()` (`get_link(NULL, ...)` and `__page_get_link()`), `nd_alloc_stack()` (`GFP_ATOMIC`, falling back to `try_to_unlazy()` in `reserve_stack()`), and `generic_ci_d_compare()` (using `READ_ONCE()` and stack-copied `d_shortname`) must never sleep or block. [F146, F147, F148, F164, F463, F466]
- In `__follow_mount_rcu()` and `follow_dotdot_rcu()`, sample the target dentry's `d_seq` via `read_seqcount_begin()` before checking `read_seqretry(&mount_lock, nd->m_seq)` or `read_seqcount_retry(&old->d_seq, nd->seq)`. When `LOOKUP_IS_SCOPED` is set, `path_init()` and `handle_dots()` (`LAST_DOTDOT`) must pair `smp_rmb()` with sequence checks on both `mount_lock.seqcount` and `rename_lock.seqcount`, and `complete_walk()` must keep `nd->root.mnt` across `try_to_unlazy()` to verify `path_is_under(&nd->path, &nd->root)`. [F39, F40, F185]
- Because `struct file` uses `SLAB_TYPESAFE_BY_RCU`, RCU readers must acquire references via `get_file_rcu()` or `get_file_active()`, never `get_file()`. `i_size_write()` requires an exclusive lock (such as `inode->i_rwsem`) to avoid corrupting `i_size_seqcount` on 32-bit SMP. Freeze protection started with `kiocb_start_write()` must be ended with `kiocb_end_write()`. [F468, F470, F474]

## Object Lifetimes
- `kern_path_parent()` and `__start_removing_path()` must transfer `parent_path` ownership to the caller via `no_free_ptr()` on every non-`ERR_PTR` return and release `parent_path` (plus `inode_unlock` and `mnt_drop_write` in `__start_removing_path()`) only on `ERR_PTR`. In `terminate_walk()`, run `drop_links(nd)` before dropping paths or calling `leave_rcu()`, drop `nd->root` only when `ND_ROOT_GRABBED` is set (preserving `ND_ROOT_PRESET`), and when `try_to_unlazy*()` fails, `legitimize_links()` must call `drop_links(nd)` at full `nd->depth` then truncate `nd->depth = i + 1` and zero ungrabbed `nd->path` pointers before `leave_rcu()`. [F1, F4, F83, F84, F119]
- `__legitimize_path()` must null out `path->mnt` only when `__legitimize_mnt()` returns `> 0` and always null out `path->dentry` on failure; when `__legitimize_mnt()` returns `< 0`, the mount refcount was incremented and must still be released by `path_put()` / `mntput()`. [F5, F239]
- When `d_alloc_parallel()` returns an in-lookup dentry (`d_in_lookup(dentry)`), `__lookup_slow()`, `lookup_open()`, and `atomic_open()` must call `d_lookup_done(dentry)` after `i_op->lookup` / `i_op->atomic_open` and before calling `dput(dentry)` on error or replacement. [F13]
- In `path_from_stashed()` and `prepare_anon_dentry()`, call `sops->put_data(data)` when reusing an existing dentry or when `new_inode_pseudo()` fails, but once `sops->init_inode(inode, data)` runs, `@data` is owned by the inode (`iput`/`dput`). Accordingly, `open_namespace()` unconditionally consumes the caller's `struct ns_common *ns` reference on both success and failure. [F18, F188]
- In `move_from_ns()`, update `ns->mnt_last_node` and `ns->mnt_first_node` if they point to `&mnt->mnt_node` before `rb_erase()`, call `RB_CLEAR_NODE(&mnt->mnt_node)`, and keep `mnt->mnt_ns` non-NULL until `umount_tree()`'s final loop. Any path clearing `mnt->mnt_ns` to `NULL` (`mnt_make_shortterm()`, `umount_tree()`) must wait for an RCU grace period before final `mntput()`, and `mntput_no_expire()` must defer non-`MNT_INTERNAL` `cleanup_mnt()` to task_work/workqueue and `free_vfsmnt()` via `call_rcu()`. [F22, F215, F256, F334]
- `lookup_mnt_ns()` and `grab_requested_mnt_ns()` increment `mnt_ns->passive` (whose initial reference `mnt_ns_tree_remove()` must drop via `call_rcu(..., mnt_ns_release_rcu)`), so callers (`statmount()`, `listmount()`) must release the namespace with `mnt_ns_release()`, not `put_mnt_ns()`. [F199, F333]
- In `rust/kernel/`, `FileDescriptorReservation::fd_install()` must `core::mem::forget` both `self` and `file` after `bindings::fd_install()`; `<PollCondVar as PinnedDrop>::drop` must only run in sleepable context and call `bindings::__wake_up_pollfree()` before `bindings::synchronize_rcu()`. [F362, F364, F476]

## API Contracts
- Successful calls to `filename_create()`, `start_creating_path()`, `start_creating_user_path()`, `start_removing_path()`, or `start_removing_user_path_at()` return with `path` pinned, `mnt_want_write(path->mnt)` held, and `path->dentry->d_inode` locked, and must be paired with `end_creating_path()` / `end_removing_path()`. [F2]
- Reference-consumption asymmetries: `vfs_mkdir()` consumes `@dentry` on all paths (assign `dentry = vfs_mkdir(...)`); `nd_jump_link()` always consumes its `struct path` argument; `finish_no_open(file, dentry)` consumes a non-`ERR_PTR` `dentry` whereas `finish_open()` does not; `scan_positives()` and `find_next_child()` consume `@last`/`@prev`; `mb_cache_entry_find_next()` consumes `@entry` while `mb_cache_entry_delete_or_get()` returns a referenced entry if busy (`e_refcnt > 2`); `mount_subtree()` consumes `@m` and returns with `s_active` and `s_umount` write-locked; `__posix_acl_create()` and `__posix_acl_chmod()` consume `*acl` whereas `set_cached_acl()` and `vfs_set_acl()` do not. [F3, F6, F15, F20, F194, F206, F355]
- Write-access pairing: `mnt_want_write()` / `mnt_want_write_file()` include `sb_start_write()` freeze protection and must pair with `mnt_drop_write()` / `mnt_drop_write_file()` (never `mnt_put_write_access*()`), and `*_file()` variants must never be mixed with non-`*_file()` variants. [F197, F347]
- Return-value tri-states: `d_revalidate()` and `d_weak_revalidate()` return `> 0` on valid, `0` on stale (translate to `-ESTALE`/invalidate), and `< 0` on error; `d_op->d_manage()` and `follow_automount()` return `-EISDIR` to stop mount traversal and succeed (while `LOOKUP_NO_XDEV` must return `-EXDEV` before calling them); `lock_rename()` and `lock_rename_child()` return `ERR_PTR(-EXDEV)` unlocked, `NULL` locked, or a `trap` dentry locked; `do_lock_mount()` / `lock_mount_exact()` store `ERR_PTR(err)` in `res->parent` on unlocked failure; `wants_mount_setattr()` returns `1` only when `do_mount_setattr()` and `finish_mount_kattr()` should run; `posix_acl_equiv_mode()` and `posix_acl_create_masq()` return `0` when mode-equivalent and `1` when ACL entries remain. [F47, F50, F51, F168, F229, F233, F240]
- Permission and ID mapping: callers of `inode_permission()` checking `MAY_APPEND` must also set `MAY_WRITE`; all permission/ownership checks in `fs/namei.c`, `FS_ALLOW_IDMAP` filesystems (`inode_fsuid_set()`, `i_uid_update()`, `ia_vfsuid`), and `->set_acl()` (`posix_acl_update_mode()`) must map UIDs/GIDs through `struct mnt_idmap *`. [F64, F180, F361, F489]
- File and inode helpers: `kernel_tmpfile_open()` and `kernel_file_open()` use `alloc_empty_file_noaccount()` and must never be passed to `fd_install()`; `inode->i_nlink` must be modified only via `inc_nlink()`/`drop_nlink()`/`set_nlink()`/`clear_nlink()`; `i_ctime_nsec` (`I_CTIME_QUERIED` in bit 31) and `i_version` (`I_VERSION_QUERIED` in bit 0) must be accessed only via their accessor helpers; `struct file_operations` must not set both `.mmap` and `.mmap_prepare` (and nested `.mmap` callers must use `vfs_mmap()`). [F133, F182, F356, F388, F482, F484, F485]

## Error Handling
- In `lookup_open()` and `vfs_mkdir()`, check `IS_ERR(res)` on a non-NULL return from `i_op->lookup()` or `i_op->mkdir()` before assigning `dentry = res` and jumping to cleanup (`dput(dentry)`). In `lookup_open()`, when `!got_write` or `may_o_create()` fails, record `create_error`, clear `O_CREAT` (and `O_TRUNC` if `!got_write`), complete the lookup, and return `create_error` only if the dentry is negative or `-ENOENT`. [F48, F122]
- In `__start_removing_path()` and `filename_create()`, preserve the return value of `mnt_want_write()` in `error` across `lookup_one_qstr_excl()` so `if (!error) mnt_drop_write()` only drops write access when `mnt_want_write()` succeeded. In `mount_setattr_prepare()`, if `mnt_hold_writers(m)` fails (`-EBUSY` leaves `WRITE_HOLD` set), advance `m = next_mnt(m, mnt)` before breaking so rollback calls `mnt_unhold_writers(m)`. [F52, F241]
- Sentinel and special return values: `ACL_NOT_CACHED` (`-1`), `ACL_DONT_CACHE` (`-3`), and `uncached_acl_sentinel(task)` (`task + 1`) all have bit 0 set (`is_uncached_acl(acl)`), so callers must check `is_uncached_acl()` and `IS_ERR()` before dereferencing; `atomic_open()` initializes `file->__f_path.dentry` to `DENTRY_NOT_SET` (`(void *)-1UL`), requiring `finish_open()` or `finish_no_open()` before returning `0`. [F67, F390]

## Known Pitfalls
- Return-value and argument-order traps: `generic_ci_d_compare()` returns `0` on match and `1` on mismatch, whereas `generic_ci_match()` returns `1` on match and `0` on mismatch; `simple_read_from_buffer(to, count, ppos, from, available)` and `simple_write_to_buffer(to, available, ppos, from, count)` swap `count` and `available`; `generic_fh_to_dentry()` and `generic_fh_to_parent()` take `fh_len` in 4-byte `__u32` words, not bytes. [F62, F69, F94]
- Rename and truncate subtleties: in `do_renameat2()`, `lock_rename(new_path.dentry, old_path.dentry)` passes `new_path` first, so `old_dentry == trap` is `-EINVAL` and `new_dentry == trap` is `-ENOTEMPTY` (or `-EINVAL` under `RENAME_EXCHANGE`); in `vfs_rename()`, `may_delete()` on `new_dentry` takes `is_dir` when `!(flags & RENAME_EXCHANGE)` and `new_is_dir` when `flags & RENAME_EXCHANGE`; `do_ftruncate()` must test `IS_APPEND(file_inode(file))`, not `IS_APPEND(inode)`. [F123, F125, F302]
- Iteration and retry traps: `skip_mnt_tree(p)` returns the last descendant inside `p`, so `for (...; p = next_mnt(p, root))` loops use `p = skip_mnt_tree(p); continue;` whereas `while` loops (`copy_mnt_ns()`) must call `next_mnt(skip_mnt_tree(p), root)`; `mark_mounts_for_expiry()` and `shrink_submounts()` must drain `graveyard` with `while (!list_empty(&graveyard))` rather than `list_for_each_entry_safe()` because `umount_tree()` unlinks peers/children; `chown_common()` must initialize `newattrs` inside `retry_deleg:`, whereas `vfs_set_acl()` must call in-place `vfs_set_acl_idmapped_mnt()` before `retry_deleg:`. [F244, F267, F290, F298]
