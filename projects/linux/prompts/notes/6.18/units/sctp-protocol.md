# SCTP PROTOCOL

This unit implements core SCTP protocol infrastructure in `net/sctp/`: module/netns init, IPv4/UDP-encap glue (`protocol.c`), `/proc/net/sctp` dumps (`proc.c`), ULP primitives (`primitive.c`), outbound queueing/SACK/retransmission (`outqueue.c`), chunk/cookie/ASCONF/RECONF construction and parsing (`sm_make_chunk.c`), and the state-machine command interpreter and timer handlers (`sm_sideeffect.c`).

## Architecture & Data Flow
- Host-order 32-bit TSN comparisons must use `TSN_lt()`/`TSN_lte()`: `sctp_insert_list()` converts `subh.data_hdr->tsn` with `ntohl()` to keep `q->retransmit` and `q->abandoned` sorted; `sctp_outq_sack()` and `sctp_check_transmitted()` use them for `highest_sacked`, `ctsn_ack_point`, `*highest_new_tsn_in_sack`, and `primary->cacc.next_tsn_at_change`; and `sctp_do_ecn_ecne_work()` checks `TSN_lt(asoc->last_cwr_tsn, lowest_tsn)` before `sctp_transport_lower_cwnd()`. [F100, F102, F103]
- Data chunks on `q->out_chunk_list` must also link `ch->stream_list` into `SCTP_SO(&q->asoc->stream, stream)->ext->outq` and update `q->out_qlen` (`+= ch->skb->len` in `sctp_outq_head/tail_data()`, reversed in `sctp_sched_dequeue_common()`). When `sctp_retransmit_mark()` moves an unacked (`!chunk->tsn_gap_acked`) chunk off `transport->transmitted`, it must subtract `sctp_data_size(chunk)` from `flight_size` and `outstanding_bytes`, add it to `peer.rwnd`, and if `chunk->rtt_in_progress`, zero both it and `transport->rto_pending`. [F61, F62, F63]
- In `sctp_check_transmitted()`, because `sctp_list_dequeue(transmitted_queue)` removes each `lchunk`, every iteration must re-link it into `q->abandoned`, `q->sacked`, or `tlist`. In `__sctp_outq_flush_rtx()`, when `rtx_timeout || fast_rtx`, `q->fast_rtx` is reset to 0 and all `SCTP_NEED_FRTX` chunks (both appended to `pkt` and left in `q->retransmit`) must become `SCTP_DONT_FRTX`; on `SCTP_XMIT_PMTU_FULL` with `!pkt->has_data && !pkt->has_cookie_echo`, it must transmit `pkt` and `goto redo` before stopping after one packet. [F64, F93, F94]
- In `sctp_outq_flush_ctrl()`, every queued control chunk type needs a `switch (chunk->chunk_hdr->type)` case (`SCTP_CID_ABORT` and response chunks fall through to set `one_packet = 1`, `default:` calls `BUG()`). Every transmitted control chunk (bundled or via `sctp_packet_singleton()`) must increment `ctx->asoc->stats.octrlchunks`, and `SCTP_CID_FWD_TSN`/`SCTP_CID_I_FWD_TSN` must call `sctp_transport_reset_t3_rtx(ctx->transport)` and set `last_time_sent = jiffies`. [F54, F65, F92]
- In `sctp_process_asconf()` and `sctp_process_asconf_ack()`, `all_param_pass` and `no_err` must latch to false on the first failed ASCONF TLV and never reset. In `sctp_asconf_param_success()`, when `SCTP_PARAM_ADD_IP` or `SCTP_PARAM_DEL_IP` updates `asoc->base.bind_addr`, `sctp_transport_dst_release()` must be called on every transport in `asoc->peer.transport_addr_list`. [F67, F95]
- `sctp4_rcv()` and `sctp_udp_rcv()` must never overwrite `SCTP_INPUT_CB(skb)->header`; `sctp_udp_rcv()` sets `encap_port = udp_hdr(skb)->source` and pulls `sizeof(struct udphdr)` before `sctp_rcv()`, while `sctp4_rcv()` zeroes `encap_port`. [F55, F142]
- In `sctp_make_init_ack()` and `sctp_make_cookie_ack()`, `retval->transport` must be looked up on `asoc` via `sctp_assoc_lookup_paddr(asoc, &chunk->transport->ipaddr)` rather than copied from `chunk->transport`. In `sctp_process_init()`, `sctp_assoc_update_frag_point(asoc)` must be called after `sctp_stream_init()`. [F58, F59]

## Synchronization
- Timer callbacks in `sm_sideeffect.c` (`sctp_generate_*_event()`) must take `bh_lock_sock(sk)`, reschedule via `mod_timer()` (taking an object reference if `!mod_timer()`) when `sock_owned_by_user(sk)`, revalidate state before calling `sctp_do_sm(..., GFP_ATOMIC)` (`asoc->base.dead` in `sctp_generate_timeout_event()`/`sctp_generate_proto_unreach_event()`, `asoc->strreset_chunk` in `sctp_generate_reconf_event()`), and drop their reference after `bh_unlock_sock(sk)`. [F33, F130]
- `net->sctp.addr_wq_lock` (`spin_lock_bh`) serializes `addr_waitq`, `auto_asconf_splist`, and `addr_wq_timer` across `sctp_addr_wq_timeout_handler()`, `sctp_free_addr_wq()`, `sctp_addr_wq_mgmt()`, and `sctp_addr_wq_lookup()`; it nests inside `net->sctp.local_addr_lock` and outside `bh_lock_sock(sk)`. [F26, F126]
- `sctp_inetaddr_event()` updates `net->sctp.local_addr_list` under `spin_lock_bh(&net->sctp.local_addr_lock)` using RCU list ops and `kfree_rcu(addr, rcu)`. Unlocked readers of `local_addr_list` (`sctp_copy_local_addr_list()`) and `bind_addr.address_list` (`sctp_seq_dump_local_addrs()`, `sctp_v4_get_dst()`, which also calls `__ip_dev_find(..., false)`) must use `list_for_each_entry_rcu()` under `rcu_read_lock()` and check `valid`; writers in `sctp_asconf_param_success()` wrap `sctp_del_bind_addr()` in `local_bh_disable/enable()`. [F28, F29, F128]
- In `sctp_outq_flush_transports()` (under socket lock), comparing `__sk_dst_get(sk)` against `t->dst` and calling `dst_hold(t->dst)` and `sk_setup_caps(sk, t->dst)` before `sctp_packet_transmit()` must occur inside `rcu_read_lock()`/`rcu_read_unlock()` so `sk_route_caps` is updated without pinning a `dst` on `net->sctp.ctl_sock`. [F35, F140]
- `sctp_v4_copy_ip_options()` and `sctp_v4_ip_options_len()` must read `inet->inet_opt` via `rcu_dereference()` under `rcu_read_lock()` (duplicating with `GFP_ATOMIC` and `RCU_INIT_POINTER()`). `sctp_eps_seq_show()` must lock `sctp_ep_hashtable[hash].chain` with `read_lock_bh(&head->lock)`. [F30, F127]

## Object Lifetimes
- Before `sctp_chunk_put/free()` can drop `refcnt` to 0, `chunk->list` must be unlinked via `list_del_init(&chunk->list)` (`sctp_chunk_destroy()` has `BUG_ON(!list_empty(&chunk->list))`). When `chunk->auth` is set, `sctp_control_set_owner_w()` calls `sctp_auth_shkey_hold(chunk->shkey)` and sets `skb->destructor = sctp_control_release_owner`. In `sctp_outq_flush_ctrl()`, `sctp_packet_singleton()` consumes `chunk`, whereas if `sctp_packet_transmit_chunk()` returns `!= SCTP_XMIT_OK`, `chunk` must be re-added to `control_chunk_list`. [F10, F11, F12]
- Callers of `sctp_outq_dequeue_data(q)` must either call `sctp_sched_dequeue_done(q, chunk)` or push it back via `sctp_outq_head_data(q, chunk)`. In `sctp_prsctp_prune_unsent()`, pruning `q->out_chunk_list` via `sctp_sched_dequeue_common()` and `sctp_chunk_free()` must be bracketed by `unsched_all()` and `sched_all()`, clearing `asoc->stream.out_curr = NULL` if its last fragment is pruned. [F9, F21]
- In `sctp_v4_get_dst()`, `ip_route_output_key()` returns an `ERR_PTR` or a new `&rt->dst` reference; any superseded `dst` or rejected `&rt->dst` must be released via `dst_release()`, and `t->dst` set to `NULL` if no route remains. `sctp_v4_xmit()` consumes `skb` and must pass `dst_clone(t->dst)` to `skb_dst_set()` or `udp_tunnel_xmit_skb(dst_rtable(dst), ...)`, leaving `t->dst` intact. [F6, F18, F42]
- Pending `asoc->timers[]`, `hb_timer`, and `T3_rtx_timer` timers own a reference to their `asoc` or `sctp_transport`: callers must hold the object iff a non-pending timer is armed (using `timer_reduce()` for `SCTP_CMD_TIMER_START`, never `add_timer()`) and put it iff `timer_delete()` returns true. [F131, F132]
- `sctp_process_asconf()` links `asconf_ack->transmitted_list` into `asoc->asconf_ack_list` and calls `sctp_chunk_hold(asconf_ack)`. `sctp_process_asconf_ack()` must unlink `asconf->transmitted_list`, call `sctp_chunk_free(asconf)`, and null `asoc->addip_last_asconf` (and on `SCTP_PARAM_DEL_IP` success, `kfree` and null `asoc->asconf_addr_del_pending`). `sctp_process_param()` must `kfree()` existing `peer.cookie`, `peer_random`, `peer_hmacs`, or `peer_chunks` before reassignment, and `sctp_cmd_new_state()` must null `peer.cookie` on free. [F13, F14, F15]
- In `sctp_cmd_interpreter()`, if `local_cork` is set, `sctp_outq_uncork(&asoc->outqueue, gfp)` must be called and `local_cork` reset before `asoc` is replaced or cleared (`SCTP_CMD_NEW_ASOC`, `SCTP_CMD_DELETE_TCB`, `SCTP_CMD_SET_ASOC`) and at function exit; `SCTP_CMD_FORCE_PRIM_RETRAN` must restore `asoc->peer.retran_path = t` after `sctp_outq_uncork()`; and `SCTP_CMD_PROCESS_CTSN`'s dummy `struct sctp_sackhdr sackh` must stay in outer function scope with `sackh.num_gap_ack_blocks = 0`. [F22, F23, F117]
- `sctp_transport_seq_start/next/stop()` keep the rhashtable walk and `rcu_read_lock()` active across `show` (relied on by `sctp_seq_dump_remote_addrs()` and `sctp_remaddr_seq_show()` for `list_for_each_entry_rcu()` on `transport_addr_list`); all callbacks must check `v != SEQ_START_TOKEN` before dereferencing or calling `sctp_transport_put(v)`, and `stop` must call `sctp_transport_walk_stop(&iter->hti)`. [F44, F122, F123]

## API Contracts
- `sctp_outq_tail()` takes ownership of the caller's `struct sctp_chunk` reference without calling `sctp_chunk_hold()`, so callers of `sctp_primitive_SEND()` must free `msg` with `sctp_datamsg_free()` (not `sctp_datamsg_put()`) if it fails before `SCTP_CMD_SEND_MSG` runs. [F8]
- `_sctp_make_chunk()` requires `SCTP_PAD4(sizeof(*chunk_hdr) + paylen) <= SCTP_MAX_CHUNK_LEN`. Because `sctp_addto_chunk()` 4-byte-aligns the prior chunk length on every call, `paylen` passed to `_sctp_make_chunk()`, `sctp_make_control()`, or `sctp_make_reconf()` must sum `SCTP_PAD4()` of each variable-length segment; to append a continuation of an already-started TLV or error cause without alignment padding, use `sctp_addto_param()` instead of `sctp_addto_chunk()`. [F106, F109, F110]
- Callers of `sctp_make_strreset_req()` with untrusted `stream_num` must pre-validate that `sizeof(outreq/inreq) + stream_num * sizeof(__u16)` does not exceed `SCTP_MAX_CHUNK_LEN - sizeof(struct sctp_reconf_chunk)` and pass `stream_list` as `__be16`. Callers accumulating causes into a bounded error chunk (`sctp_make_op_error_limited()`) must check `sctp_init_cause() == 0` before `sctp_addto_chunk()`. `sctp_walk_params(pos, chunk)` requires `chunk` to be a composite chunk header pointer (`struct sctp_init_chunk *`, `struct sctp_addip_chunk *`, `struct sctp_reconf_chunk *`). [F73, F77, F114]
- `sctp_user_addto_chunk()` and `sctp_make_abort_user()` (`paylen > 0`) copy from user iterators with `GFP_KERNEL`, whereas `sctp_pack_cookie()` and state-machine control chunk builders in `sm_make_chunk.c` must use `GFP_ATOMIC`. `sctp_copy_local_addr_list()` and `sctp_v4_copy_addrlist()` run under `rcu_read_lock()`, so their inner allocations must use `GFP_ATOMIC`; `sctp_copy_local_addr_list()` must also set `sin_port = htons(bp->port)` on a local copy before `sctp_bind_addr_state()` and check `SCTP_ADDR4_ALLOWED | SCTP_ADDR4_PEERSUPP` for `AF_INET`. [F51, F87, F125, F135]

## Error Handling
- In `sctp_cmd_interpreter()`, `SCTP_CMD_GEN_COOKIE_ECHO` owns the optional `ERROR` chunk in `cmd->obj.chunk` (freeing it if `sctp_make_cookie_echo()` fails, or passing it to `SCTP_CMD_REPLY` on success). On any non-zero `error`, `sctp_cmd_interpreter()` must drain remaining `commands` via `sctp_next_cmd()` and free `cmd->obj.chunk` on every queued `SCTP_CMD_REPLY`. Transmit errors in `sctp_cmd_send_msg()`/`SCTP_CMD_SEND_MSG`/`SCTP_CMD_REPLY` are not returned; `sctp_outq_flush_*()` sets `sk->sk_err = -error` while keeping DATA chunks queued. [F5, F40, F96]
- In `sctp_verify_init()` and its helpers (`sctp_process_inv_paramlength()`, `sctp_process_hn_param()`), any existing error chunk in `*errp` must be freed via `sctp_chunk_free(*errp)` before assigning a new fatal error/abort chunk. On failure in `sctp_process_init()` (`goto clean_up`), all non-active transports (`transport->state != SCTP_ACTIVE`) must be removed via `sctp_assoc_rm_peer(asoc, transport)`. [F16, F17]
- `sctp_verify_param()` and `sctp_process_unk_param()` return positive `enum sctp_ierror` values, whereas `sctp_verify_init()`, `sctp_process_init()`, and `sctp_process_param()` return 1 on success and 0 on failure. `sctp_unpack_cookie()` returns `NULL` on failure with a negated `-SCTP_IERROR_*` in `*error`, populating `*errp` only on `-SCTP_IERROR_STALE_COOKIE`. [F38, F39]
- OOTB-capable chunk builders (`_sctp_make_chunk()`, `sctp_control_set_owner_w()`, `sctp_make_op_error_limited()`, `sctp_make_abort()`, `sctp_make_shutdown_complete()`) accept a `NULL` `asoc` and must check `if (asoc)` before dereferencing it. Callers of `sctp_get_af_specific(param_type2af(...))` must check that the returned `struct sctp_af *` is non-NULL. [F41, F46]

## Known Pitfalls
- Because `sctp_walk_params()` only checks `ntohs(pos.p->length) >= sizeof(struct sctp_paramhdr)` and stops early on malformed trailing parameters, verifiers must check `param.v == chunk->chunk_end` and validate subtype minimum lengths before handlers subtract larger header sizes; `sctp_verify_asconf()` must verify a single IPv4/IPv6 address parameter at `addip + 1` (none in ASCONF-ACK), validate all parameter lengths, and check `param.v == chunk->chunk_end`. [F74, F75]
- For nested address subparameters inside ADD-IP parameters in `sctp_process_param()` and `sctp_process_asconf_param()`, `param_type2af()` must be passed the inner `addr_param->p.type` (at `sizeof(struct sctp_addip_param)` past the outer header), never the outer `param.p->type`. In `sctp_verify_param()`, disabled optional extensions (`SCTP_PARAM_SET_PRIMARY`, `SCTP_PARAM_FWD_TSN_SUPPORT`, `SCTP_PARAM_RANDOM`, `SCTP_PARAM_CHUNKS`, `SCTP_PARAM_HMAC_ALGO`) must `goto unhandled` so `sctp_process_unk_param()` runs. [F89, F90]
- `SCTP_PARAM_*` and `SCTP_ERROR_*` constants are already `__be16` (`cpu_to_be16`), so variables storing or comparing them (`last` in `sctp_verify_reconf()`, `cause_code` in `sctp_init_cause()`) must be `__be16` without `htons()`/`ntohs()`. For a synthetic `struct sctp_sackhdr` passed to `sctp_outq_sack()` (`SCTP_CMD_PROCESS_CTSN`), `sackh.a_rwnd` must be `htonl(asoc->peer.rwnd + asoc->outqueue.outstanding_bytes)` and `sackh.cum_tsn_ack` must be `__be32`. [F79, F80]
- SACK Gap Ack Block `start`/`end` are 16-bit offsets from `cum_tsn_ack` for `[cum_tsn_ack + start, cum_tsn_ack + end]`; `sctp_acked()` must check `TSN_lte(tsn, ctsn)` before subtracting `ctsn` from `tsn`. `sctp_outq_sack()` must clamp `asoc->peer.rwnd = sack_a_rwnd - q->outstanding_bytes` to 0 when `q->outstanding_bytes >= sack_a_rwnd`, and `sctp_check_transmitted()` must run `!tchunk->tsn_gap_acked` checks (RTT update and `cacc_saw_newack = 1`) before setting `tchunk->tsn_gap_acked = 1`. [F60, F83, F101, F107]
- When indexing `chunk->skb->data` directly, inbound chunks (`sctp_process_asconf()`, `sctp_get_asconf_response()`) start at `struct sctp_addiphdr` (`sctp_inq_pop()` pulled `sctp_chunkhdr`), whereas cached outbound chunks (`asoc->addip_last_asconf` in `sctp_process_asconf_ack()`) start at `struct sctp_addip_chunk`. In `sctp_cmd_process_operr()`, `err_hdr` must be read from `chunk->skb->data` before `sctp_ulpevent_make_remote_error()` pulls the cause TLV. [F115, F116]
- In `sctp_cmd_interpreter()`, the `union sctp_arg` member read from `cmd->obj` must match the exact width of the `SCTP_*` constructor (`cmd->obj.u16` for `SCTP_PERR()`, `cmd->obj.u8` for `SCTP_U8()`), and `event_arg` is only a `struct sctp_chunk *` when `event_type == SCTP_EVENT_T_CHUNK` (or after `SCTP_CMD_INIT_CHOOSE_TRANSPORT`). [F78, F118]
- In `sctp_v4_get_dst()`, route lookups must use a local `struct flowi _fl` and copy `_fl` to `*fl` only when storing `rt->dst` into `t->dst`, and when `saddr` is non-NULL, set `fl4->fl4_sport = saddr->v4.sin_port` only if `!fl4->fl4_sport`. In `sctp_make_asconf_update_ip()`, packed `addrs` must be advanced by `af->sockaddr_len` rather than `sizeof(*addrs)`. [F56, F57, F111]
