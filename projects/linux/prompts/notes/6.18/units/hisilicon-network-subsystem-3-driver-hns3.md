# HISILICON NETWORK SUBSYSTEM 3 DRIVER (HNS3)

This unit implements the Hisilicon Network Acceleration Engine 3 (HNAE3) bus/matching framework, the HNS3 Ethernet client driver (`hns3_enet` for `net_device`, TX/RX ring datapath, NAPI, ethtool, DCBNL, and debugfs), and the PF/VF common hardware library (`hclge_comm` for command queues, RSS, and TQP statistics).

## Architecture & Data Flow
- `priv->ring` holds `2 * h->kinfo.num_tqps` rings: `[0, num_tqps)` are TX and `[num_tqps, 2 * num_tqps)` are RX, while `ring->queue_index` and `ring->tqp->tqp_index` stay in `[0, num_tqps)`. Because `hns3_dbg_bd_file_init()` creates files for `hns3_get_max_available_channels()` queues, `hns3_dbg_tx_bd_info()` and `hns3_dbg_rx_bd_info()` must check `data->qid >= h->kinfo.num_tqps` before indexing `priv->ring`. [F63, F64]
- `hns3_init_tx_spare_buffer()` leaves `ring->tx_spare` as `NULL` (and resets `kinfo.tx_spare_buf_size = 0`) if `tx_spare_buf_size` is `0`, `get_order(alloc_size) > MAX_PAGE_ORDER`, or allocation/mapping fails. Callers must check `ring->tx_spare != NULL`, and `hns3_set_tunable()` (`ETHTOOL_TX_COPYBREAK_BUF_SIZE`) must revert if `priv->ring->tx_spare` is `NULL` when `new_tx_spare_buf_size != 0`. [F33, F47, F68]
- `hns3_tx_spare_space()` computes `max(ntc, tx_spare->len - ntu) - 1` in `u32` and `hns3_tx_spare_alloc()` aligns `size` to `dma_get_cache_alignment()`. `tx_spare->next_to_use` must stay `< tx_spare->len`, callers must verify space via `hns3_can_use_tx_bounce()`/`hns3_can_use_tx_sgl()` (using `HNS3_SGL_SIZE(nfrag)`), and when wrapping `ntu` to `0`, `hns3_tx_spare_alloc()` must add `tx_spare->len - ntu` to `*cb_len` so rollback and `hns3_tx_spare_reclaim_cb()` use `*cb_len`. [F69, F107, F121, F122]
- `hns3_skb_bd_num()` and `hns3_tx_bd_num()` must abort once `bd_num > HNS3_MAX_TSO_BD_NUM` to keep `bd_size[HNS3_MAX_TSO_BD_NUM + 1U]` in bounds. In `hns3_nic_maybe_stop_tx()`, an SKB with `bd_num > priv->max_non_tso_bd_num` must be linearized via `hns3_skb_linearize()` (which rejects `skb->len > HNS3_MAX_TSO_SIZE`, or `> HNS3_MAX_NON_TSO_SIZE` when `!skb_is_gso(skb)`) unless `skb_is_gso(skb)` is true, `bd_num <= HNS3_MAX_TSO_BD_NUM`, and `!hns3_skb_need_linearized()`. [F70, F108, F139, F166]
- In `hns3_nic_net_xmit()`, every TX packet must be padded to `HNS3_MIN_TX_LEN` (33) via `skb_put_padto()`, and every exit path (including errors and `-EBUSY`) must call `hns3_tx_doorbell()` to flush `ring->pending_buf`. In `hns3_tx_doorbell()`, `hns3_tx_push_bd()` is only valid when `HNS3_NIC_STATE_TX_PUSH_ENABLE` is set, `ring->pending_buf == 0`, `0 < num <= HNS3_MAX_PUSH_BD_NUM`, and `doorbell` is true. [F96, F163]
- Per-packet RX metadata (`pkt_len`, `l234_info`, `ol_info`, `csum`, `rss_hash`, VLAN tags, timestamps) is only valid on the last descriptor (`BIT(HNS3_RXD_FE_B)`), so `hns3_handle_bdinfo()` must read it from `pre_ntc`. In `hns3_clean_rx_ring()`, when `hns3_handle_rx_bd()` returns `-ENXIO` or `!ring->skb`, jump to `out` without adding `ring->pending_buf` to `unused_count` or clearing `ring->skb`/`ring->pending_buf`; other errors must reset `ring->skb = NULL` and reclaim `ring->pending_buf`. [F42, F93]
- `hns3_rx_ptype_tbl` is indexed by `HNS3_RXD_PTYPE_M` only when `HNS3_NIC_STATE_RXD_ADV_LAYOUT_ENABLE` is set; otherwise `ptype` is `HNS3_INVALID_PTYPE`, which `hns3_checksum_complete()` and `hns3_rx_handle_csum()` must reject. In `hns3_rx_checksum()`, `hns3_checksum_complete()` must not return before checking `BIT(HNS3_RXD_L3L4P_B)` and RX error bits (`HNS3_RXD_L3E_B`, `HNS3_RXD_L4E_B`, `HNS3_RXD_OL3E_B`, `HNS3_RXD_OL4E_B`) to reset `skb->ip_summed = CHECKSUM_NONE`. [F71, F158, F159]
- In `hns3_set_ringparam()`, `hns3_change_all_ring_bd_num()` and `hns3_change_rx_buf_len()` must update `h->kinfo` (`num_tx_desc`, `num_rx_desc`, `rx_buf_len`, `tqp[i]->buf_size`) in lockstep with `priv->ring`, reverting both on `hns3_init_all_ring()` failure, with descriptor counts aligned to `HNS3_RING_BD_MULTIPLE` (8). Copybreak updates in `hns3_set_tunable()` must propagate to every ring, and V3+ devices with `iommu_is_dma_domain()` must enforce `tx_copybreak >= HNS3_MAX_PACKET_SIZE` and `tx_spare_buf_size >= HNS3_MIN_SPARE_BUF_SIZE`. [F46, F48, F80, F153]
- `hns3_get_max_available_channels()` divides by `h->kinfo.tc_info.num_tc` and `hns3_nic_init_vector_data()` computes `i % priv->vector_num` without zero checks, so `num_tc >= 1` and `priv->vector_num >= 1` (when `num_tqps > 0`) must always hold; `hns3_nic_common_poll()` must clamp `budget / tqp_vector->num_tqps` to `>= 1`. `ring_space()` and `hclge_comm_ring_space()` must subtract 1 (`desc_num - used - 1`), and BQL accounting must be reset via `hns3_reset_tx_queue()` whenever TX rings are cleared on down/reset/loopback. [F66, F104, F105, F109, F168]
- Single-descriptor command structs cast onto `hclge_desc::data` must fit in 24 bytes (`HCLGE_DESC_DATA_LEN * sizeof(__le32)`), and `#pragma pack(1)` mailbox structs in `hclge_mbx.h` must fit in `HCLGE_MBX_MAX_MSG_SIZE` (14) or `HCLGE_MBX_MAX_RESP_DATA_SIZE` (8) bytes. Programming `HCLGE_COMM_NIC_CSQ_DEPTH_REG` in `hclge_comm_cmd_config_regs()` must preserve `HCLGE_COMM_NIC_SW_RST_RDY`, and `hclge_comm_set_rss_hash_key()`/`hclge_comm_set_rss_tuple()` must update `rss_cfg` shadow fields only after the firmware command succeeds. [F54, F55, F112, F113]

## Synchronization
- Traversals and mutations of `hnae3_ae_algo_list`, `hnae3_client_list`, and `hnae3_ae_dev_list` (and `HNAE3_DEV_INITED_B`) must hold `hnae3_common_lock`. However, `hnae3_unregister_ae_algo_prepare()` must hold `device_lock(&ae_dev->pdev->dev)` around `pci_disable_sriov()` and must not hold `hnae3_common_lock`. Module exit (`hns3_exit_module()`) must hold `hnae3_acquire_unload_lock()` / `hnae3_release_unload_lock()`. [F16, F19, F143]
- `hclge_comm_cmd_send()` must hold `spin_lock_bh(&hw->cmq.csq.lock)` across checking `HCLGE_COMM_STATE_CMD_DISABLE` and `hclge_comm_ring_space()`, writing descriptors/registers, and polling in `hclge_comm_wait_for_resp()` with `udelay(1)` and per-opcode timeout `hclge_get_cmdq_tx_timeout()`. `hclge_comm_cmd_init()` and `hclge_comm_cmd_uninit()` nest `crq.lock` inside `csq.lock`. [F27, F137, F141]
- `hns3_tx_doorbell()` must update `ring->last_to_use` with `smp_store_release()` (paired with `smp_load_acquire()` in `hns3_nic_reclaim_desc()`) before `hns3_tx_push_bd()`, `hns3_tx_mem_doorbell()`, or writing `HNS3_RING_TX_RING_TAIL_REG`. `hns3_tx_push_bd()` and `hns3_tx_mem_doorbell()` require `dma_wmb()` before `__iowrite64_copy()`, and `hns3_handle_rx_bd()`/`hns3_add_frag()` require `dma_rmb()` after checking `HNS3_RXD_VLD_B`. [F23, F151]
- `hns3_nic_reclaim_desc()` must publish `ring->next_to_clean` with `smp_store_release()` (paired with `smp_load_acquire()` in `ring_space()`), and `hns3_nic_maybe_stop_tx()`/`hns3_clean_tx_ring()` must issue `smp_mb()` before rechecking `ring_space()`. `hns3_tx_spare_reclaim_cb()` must complete DMA sync/unmap before `hns3_tx_spare_update()` publishes `tx_spare->last_to_clean` via `smp_store_release()` (paired with `smp_load_acquire()` in `hns3_tx_spare_space()`). [F24, F149]
- In `hns3_reset_notify_uninit_enet()`, if `!test_bit(HNS3_NIC_STATE_DOWN, &priv->state)`, `hns3_nic_net_stop(netdev)` must run before clearing `HNS3_NIC_STATE_INITED` and calling `hns3_nic_uninit_vector_data()`. `hns3_external_lb_prepare()`/`restore()` must gate ring resets and IRQ/NAPI changes on `HNS3_NIC_STATE_DOWN`, `!hns3_nic_resetting(ndev)`, and `hns3_nic_reset_all_ring() == 0`. [F22, F52]
- Lockless debugfs ring readers must check `HNS3_NIC_STATE_INITED` and `!HNS3_NIC_STATE_RESETTING` before reading `priv->ring`, and `hns3_dump_page_pool_info()` must use `READ_ONCE()` on `pages_state_hold_cnt`. `ring->stats` updates must use `u64_stats_update_begin(&ring->syncp)`/`end()`. Process-context `hns3_clean_rx_ring()` in `hns3_lb_check_rx_ring()` requires `preempt_disable()`/`enable()` (and saving/restoring `rx_group->total_packets`), and `hns3_init_all_ring()`/`hns3_alloc_ring_buffers()` must call `cond_resched()`. [F26, F28, F62, F91, F147]

## Object Lifetimes
- `ae_dev->ops->init_client_instance` must call `hnae3_set_client_init_flag(client, ae_dev, 1)` on success so `hnae3_uninit_client_instance()` will run `ops->uninit_client_instance`. In `hnae3_unregister_ae_algo()` and `hnae3_unregister_ae_dev()`, all clients must be uninitialized via `hnae3_uninit_client_instance()` before calling `ops->uninit_ae_dev(ae_dev)` and clearing `HNAE3_DEV_INITED_B` and `ae_dev->ops`. [F1, F2]
- In `hns3_client_init()`, `hns3_state_init()` (`HNS3_NIC_STATE_INITED`) and `register_netdev()` must run only after rings, vectors, IRQs, `hns3_client_start()`, and `hns3_dbg_init()` succeed; if `register_netdev()` fails, rollback must call `hns3_state_uninit()`, `hns3_dbg_uninit()`, and `hns3_client_stop()`. Both `hns3_client_uninit()` (after `unregister_netdev()`) and `hns3_reset_notify_uninit_enet()` must gate IRQ/ring/vector teardown on `test_and_clear_bit(HNS3_NIC_STATE_INITED, &priv->state)`. [F5, F6, F20]
- `hns3_nic_init_irq()` must set `IRQ_NOAUTOEN` before `request_irq()`. `hns3_enable_irqs_and_tqps()` must run `hns3_irq_enable()` for all vectors before `hns3_mask_vector_irq(..., 1)` and `hns3_tqp_enable()` in separate loops; `hns3_disable_irqs_and_tqps()` must reverse these three phases so TQPs are disabled and vector IRQs masked before `hns3_irq_disable()` calls `disable_irq()`, `napi_disable()`, and `cancel_work_sync()` on RX/TX `dim.work`. [F21, F127, F128]
- `priv->ring`, `priv->tqp_vector`, `ring->desc_cb`, `ring->tx_spare`, and `hnae3_ring_chain_node` are allocated with `devm_*` on `&pdev->dev` but reallocated across resets, channel changes, and ringparam updates, so teardown paths must explicitly call `devm_kfree()`. In `hns3_fini_ring()`, `hns3_free_desc(ring)` must run before freeing `ring->desc_cb`, `ring->tx_spare`, and `ring->page_pool`. [F7, F8]
- When `ring->page_pool` is active, `hns3_alloc_and_map_buffer()` and `hns3_unmap_buffer()` must skip manual DMA map/unmap on `DESC_TYPE_PP_FRAG`, `hns3_alloc_skb()`/`hns3_add_frag()` must call `skb_mark_for_recycle()`, and `hns3_rx_skb()` must call `napi_gro_flush(..., false)` before `napi_gro_receive()` when `skb_has_frag_list(skb)`. For non-`page_pool` `DESC_TYPE_PAGE` buffers, `cb->pagecnt_bias` must be drained via `__page_frag_cache_drain()` when `reuse_flag == 0`. [F12, F154, F167]
- While `hns3_nic_resetting(netdev)` is true, `hns3_nic_net_down()` and `hns3_external_lb_prepare()` must skip `hns3_clear_all_ring()` and `hns3_nic_reset_all_ring()`, leaving `hns3_reset_notify_uninit_enet()` to call `hns3_clear_all_ring(handle, true)`. In `hclge_comm_cmd_uninit()`, `HCLGE_COMM_STATE_CMD_DISABLE` and `msleep(HCLGE_COMM_CMDQ_CLEAR_WAIT_TIME)` must precede clearing registers and `hclge_comm_free_cmd_desc()`. [F3, F9]

## API Contracts
- `hns3_handle_rx_copybreak()` returns `0` on success and `-ENOMEM` on failure, so `hns3_nic_reuse_page()` must return early on `0`. `hns3_handle_vtags()` returns negative errno, `0`, or `HNS3_INNER_VLAN_TAG` (`1`) / `HNS3_OUTER_VLAN_TAG` (`2`). Before mutating packet headers in `hns3_handle_vtags()` or `hns3_set_tso()`, call `skb_cow_head(skb, 0)`. Callers of `hns3_free_buffer()`, `hns3_free_buffer_detach()`, and `hns3_clean_tx_ring()` outside NAPI poll must pass `budget = 0`. [F32, F44, F146, F162]
- `hns3_nic_set_features()` must only program hardware for `netdev->features ^ features` without modifying `netdev->features`. `hns3_set_default_feature()` must not set `NETIF_F_GSO_GRE_CSUM` in `gso_partial_features` and must clear `NETIF_F_GSO_GRE`/`NETIF_F_GSO_GRE_CSUM` on V3+ devices. `hclge_comm_rss_init_cfg()` requires PF callers to pre-initialize `rss_cfg->rss_size > 0` and VF callers `kinfo.rss_size > 0`, and `hclge_comm_get_rss_tc_info()` requires `rss_size` in `[1, 32768]`. [F101, F102, F156, F157]

## Error Handling
- On TX descriptor filling errors in `hns3_handle_skb_desc()`, `hns3_handle_tx_bounce()`, or `hns3_handle_tx_sgl()`, `hns3_clear_desc()` and `hns3_tx_spare_rollback()` must rewind `ring->next_to_use` and `tx_spare->next_to_use`; in `hns3_clear_desc()`, zero `ring->desc[ring->next_to_use]` before checking `ring->next_to_use == next_to_use_orig`, and only move `next_to_use` backward and unmap `desc_cb` after that check. [F11, F89]
- In `hns3_change_channels()` and `hns3_set_tx_spare_buf_size()`, if `HNAE3_UP_CLIENT` fails after `HNAE3_INIT_CLIENT`, call `hns3_reset_notify(handle, HNAE3_UNINIT_CLIENT)`, and in `hns3_set_channels()`/`hns3_set_tunable()` store rollback status in `ret1` so `ret` is preserved. In `hclge_comm_cmd_init()`, any failure after clearing `HCLGE_COMM_STATE_CMD_DISABLE` must jump to `err_cmd_init` to set it again. [F4, F14, F36]
- In `hns3_set_ringparam()`, `hns3_backup_ringparam()` saves `priv->ring` to `tmp_rings` with `skb = NULL` so `hns3_fini_ring(&tmp_rings[i])` runs only after `hns3_init_all_ring()` succeeds. Ethtool callbacks must check both `hns3_nic_resetting(ndev)` and `priv->ring != NULL`. `hns3_alloc_page_pool()` must set `ring->page_pool = NULL` on error. In `hns3_nic_alloc_rx_buffers()`, allocation failure at `i` must still write `i` to `HNS3_RING_RX_RING_HEAD_REG` and return `true` so `hns3_clean_rx_ring()` returns `budget`. [F15, F34, F35, F161]

## External Contracts
- `hclge_comm_cmd_check_retval()` reads `desc[0].retval` when `hclge_comm_is_special_opcode(opcode)` is true and `desc[num - 1].retval` otherwise; in `hclge_dev_specs_1_cmd`, `tnl_num` must stay at byte offset 18. In `hclge_comm_set_rss_indir_table()` and `hclge_comm_set_rss_algo_key()`, `hclge_comm_cmd_setup_basic_desc()` must be called inside each loop iteration before `|=` updates. TX descriptor L2 length and csum start/offset use `>> 1` and L3/L4 lengths use `>> 2`. `hns3_set_reset()` must clear handled bits (`*flags &= ~rst_flags`). [F74, F76, F77, F88, F110, F160]

## Known Pitfalls
- `hnae3_set_bit()`/`hnae3_get_bit()` use signed 32-bit `0x1 << (shift)` (`shift` in `[0, 30]`), and `hnae3_set_field()` requires a 64-bit `mask` and 64-bit `val` (when `shift >= 31`) on 64-bit `origin`; `hns3_set_field()` in `hns3_enet.c` only ORs bits without clearing, requiring `hns3_init_desc_data()`. `hns3_desc_unused()` must check `!ring->desc_cb[ntc].refill` when `ntc == ntu`. In `hns3_add_frag()`, accumulate `truesize`/`data_len`/`len` on `head_skb` before reassigning `skb = ring->tail_skb`. [F65, F81, F95, F97, F98]
- Never call `hnae3_seq_file_to_handle(s)` or `hnae3_seq_file_to_ae_dev(s)` in `hns3_dbg_bd_info_show()`/`tx_bd_info()`/`rx_bd_info()` where `s->private` is `struct hns3_dbg_data *`. `hclge_comm_capability_to_bitmap()` must use `__le32_to_cpu()` and `bitmap_from_arr32()`, `hclge_comm_get_rss_indir_tbl()` must copy `u16` to `u32` element-wise, DMA high 32 bits must use `upper_32_bits(dma)` or `(dma >> 31) >> 1`, and `hns3_nic_select_queue()` must bounds-check `dscp < HNAE3_MAX_DSCP` and map `HNAE3_PRIO_ID_INVALID` to `0`. [F75, F79, F100, F117, F124]
