# LOCKING PRIMITIVES

This component provides the core Linux kernel locking primitives—spinlocks, rwlocks, mutexes, rwsems, and seqlocks—alongside architecture-specific implementations, the runtime locking correctness validator (`lockdep`), and per-CPU locking event counters (`lock_events`).

## Architecture & Data Flow

- Every `struct lock_class` resides in `lock_classes[MAX_LOCKDEP_KEYS]` (on `all_lock_classes`, `free_lock_classes`, or `delayed_free.pf[].zapped`), and helpers (`zap_class()`, `lock_stats()`, `clear_lock_stats()`, `get_lock_stats()`, `debug_class_ops_*()`) derive indices via `class - lock_classes`. `register_lock_class()`, `mark_lock()`, and `zap_class()` must update `lock_classes_in_use`, `classhash_table`, `nr_lock_classes`, `max_lock_class_idx`, and `nr_unused_locks` (decremented when `usage_mask` transitions from 0 or is zapped at 0) in lockstep. [F47, F48, F105]
- In `struct lock_class`, `hash_entry`, `lock_entry`, `locks_after`, and `locks_before` must precede `key` and the struct must remain `__no_randomize_layout`, because `reinit_class()` runs `memset_startat(class, 0, key)` to preserve those list heads. [F70]
- `sizeof(struct lock_class_key)` must not exceed `sizeof(struct lockdep_map)` or `sizeof(raw_spinlock_t)` because static locks use the lock's address as `lock->key` and index `lock->key->subkeys + subclass`. `lockdep_map::class_cache` has only `NR_LOCKDEP_CACHING_CLASSES` (2) slots while `subclass` reaches `MAX_LOCKDEP_SUBCLASSES - 1` (7), so `register_lock_class()` and `__lock_acquire()` must check `subclass < NR_LOCKDEP_CACHING_CLASSES`. [F69, F98]
- In `spinlock_types.h` on `!CONFIG_PREEMPT_RT` with `CONFIG_DEBUG_LOCK_ALLOC`, `spinlock_t`'s union member `dep_map` must be preceded by `LOCK_PADSIZE` (`offsetof(struct raw_spinlock, dep_map)`) bytes so `spinlock->dep_map` aliases `spinlock->rlock.dep_map`. [F61]
- Every `struct lock_list` in `list_entries[]` has its bit set in `list_entries_in_use` iff linked into `locks_after` or `locks_before`, and `check_prev_add()` must add or update both `prev->locks_after` (`calc_dep`) and `next->locks_before` (`calc_depb`) in lockstep. [F49]
- Modifying or releasing `curr->held_locks[i]` below the top of the stack (`__lock_set_class()`, `__lock_downgrade()`, or `i < depth - 1` in `__lock_release()`) requires rewinding `curr->lockdep_depth = i` and `curr->curr_chain_key = hlock->prev_chain_key` and replaying via `reacquire_held_locks()`. Reverse scans in `find_held_lock()`, `check_prevs_add()`, and `get_first_held_lock()` require `depth > 0` and must stop when `prev_hlock->irq_context != hlock->irq_context`. [F51, F72]
- When `__lock_acquire()` coalesces a nested lock (`nest_lock != NULL && !sync`) onto the top `held_lock`, it sets `hlock->references` to 1 if 0 before adding `references`, checks 11-bit bitfield overflow via `hlock->references < references`, and `__lock_release()` only pops `hlock` when `--hlock->references` reaches 0. [F11, F94]
- In `check_deadlock()`, same-class read-after-read recursion on `curr->held_locks` is allowed only when `next->read == 2` and `prev->read != 0`; non-recursive readers (`next->read == 1`) must not be exempted. [F78]
- `add_chain_block()` must reject `size < 2` and insert blocks with `size > MAX_CHAIN_BUCKETS` into `chain_block_buckets[0]` sorted in descending `chain_block_size(curr)` order. `size_to_bucket()` maps `1..MAX_CHAIN_BUCKETS` to `size - 1`, so `alloc_chain_hlocks()` must only pass a split remainder to `add_chain_block(curr + req, size - req)` when `size > req`. [F64, F86]
- Because `task_irq_context()` sets both `LOCK_CHAIN_HARDIRQ_CONTEXT` and `LOCK_CHAIN_SOFTIRQ_CONTEXT` when hardirq interrupts softirq, `inc_chains()` and `dec_chains()` must test `LOCK_CHAIN_HARDIRQ_CONTEXT` first. In `iterate_chain_key()`, `k1` must be cast to `u64` before `<< 32`. [F84, F90]
- In `__bfs()`, Step 4 must call `visit_lock_entry(entry, lock)` (`entry->parent = lock`) for every sibling in `get_dep_list(lock, offset)` before `if (!first) continue;`, because `__bfs_next()` reaches non-first siblings via `lock->parent`. [F82]
- `clear_lock_stats()` must zero both `per_cpu(cpu_lock_stats, cpu)[class - lock_classes]` across all possible CPUs and the class's `contention_point` and `contending_point` arrays. [F57]
- `raw_seqcount_begin()` must mask `raw_read_seqcount(s) & ~1` so an odd sequence count forces `do___read_seqcount_retry()` inequality comparison to fail. [F96]
- On PA-RISC (`arch/parisc/include/asm/spinlock*.h`), `arch_spinlock_t` embeds `volatile unsigned int lock[4]` initialized in all 4 words to `__ARCH_SPIN_LOCK_UNLOCKED_VAL` (`0x1a46`) for `__ldcw_align(x)`, and unlock/init paths must write `0x1a46` because `arch_spin_val_check()` traps if any other bit is set. [F60, F74]

## Synchronization

- `lockdep_lock()` and `lockdep_unlock()` require local IRQs disabled: `lockdep_lock()` increments per-CPU `lockdep_recursion` before taking `__lock`, and `lockdep_unlock()` clears `__owner` and releases `__lock` before decrementing `lockdep_recursion`. Key/class teardown paths (`lockdep_unregister_key()`, `lockdep_free_key_range_*()`, `free_zapped_rcu()`) must acquire `lockdep_lock()` rather than `graph_lock()` so classes are zapped even when `debug_locks == 0`. [F2, F9]
- Lockdep helpers called under `graph_lock` (`save_trace()`, `alloc_list_entry()`, `add_chain_cache()`, `valid_state()`, `mark_lock_irq()`, `check_deadlock()`, `check_prevs_add()`) drop `graph_lock` on failure (`NULL` or `0`), so callers must return immediately without `graph_unlock()`. Conversely, `print_usage_bug()` calls `debug_locks_off()` without releasing `graph_lock`, so callers holding `graph_lock` (like `valid_state()`) must call `graph_unlock()` first. [F7, F37]
- `register_lock_class()`, `lookup_chain_cache_add()`, and `mark_lock()` do a lockless check before taking `graph_lock()`, and must re-verify that the class, chain, or `usage_mask` bit was not concurrently added after acquiring `graph_lock()`. [F21]
- Under `lockdep_lock()`, `zap_class()` and `remove_class_from_lock_chain()` must RCU-unlink class/chain/list entries, clear `class->key` and `class->name` via `WRITE_ONCE()`, clear `lock_classes_in_use`, decrement `nr_lock_classes` (and `nr_unused_locks` if unused), call `free_chain_hlocks()` and `dec_chains()`, reset `chain_key` to `INITIAL_CHAIN_KEY`, stage in `delayed_free.pf[]`, queue `call_rcu(..., free_zapped_rcu)` after unlock, and defer `reinit_class()` and `lock_chains_in_use` clearing to `free_zapped_rcu()`. [F5, F23, F50, F121]
- `check_wait_context()` must initialize `curr_inner = task_wait_context(curr)` and test `next_outer > curr_inner` even when `curr->lockdep_depth == 0`, verifying for any `!next->trylock` lock with non-zero `wait_type_inner` that `wait_type_outer ?: wait_type_inner` does not exceed `curr_inner` across held locks in the active `irq_context` (narrowing via `min(curr_inner, prev_inner)` unless `LD_LOCK_WAIT_OVERRIDE` resets `curr_inner = prev_inner`). [F79, F119]
- In NMI context (`lockdep_nmi() && !trylock`), `lock_acquire()` must not modify `current->held_locks` or take `graph_lock()`, instead only calling `verify_lock_unused()` to locklessly check `LOCKF_USED` (or `LOCKF_USED_READ` when `!hlock->read`). [F123]
- `lock_is_held_type()` and its callees (`lockdep_enabled()`, `check_flags()`, `lockdep_recursion_inc()`, `lockdep_recursion_finish()`, `__lock_is_held()`, `match_held_lock()`, `look_up_lock_class()`) must be `noinstr` or `__always_inline` and use `hlist_for_each_entry_rcu_notrace()`, wrapping diagnostic slow paths (`WARN_ONCE()`, `printk()`, `dump_stack()`, etc.) in `instrumentation_begin()`/`end()`. [F113, F114]
- `__lockdep_enabled`, `lockdep_enabled()`, and `lockdep_assert_*()` in `lockdep.h` must read per-CPU state via `this_cpu_read()` (not `raw_cpu_read()` or `__this_cpu_read()`) because they run in preemptible context. In `lockdep_hardirqs_on*()`, use `this_cpu_read(lockdep_recursion)` and `__debug_atomic_inc()` before `irqs_disabled()` is confirmed, and `__this_cpu_write(hardirqs_enabled, ...)` afterwards. [F59, F115, F116]
- In SMP raw spinlock/rwlock helpers, blocking lock disables IRQs/preemption/BH before `spin_acquire`/`rwlock_acquire*` and `do_raw_*_lock`, whereas trylock restores disabled preemption/BH/IRQs on contention and calls `spin_acquire`/`rwlock_acquire*` only after `do_raw_*_trylock()` succeeds; unlock calls `spin_release`/`rwlock_release` and `do_raw_*_unlock` before restoring IRQs/preemption/BH. [F16, F17, F30]
- `do_raw_spin_unlock()` (and MIPS `queued_spin_unlock()`, SuperH `arch_spin_unlock()`) must execute `mmiowb_spin_unlock()`/`mmiowb()` before releasing the arch lock, and `do_raw_spin_trylock()` must call `mmiowb_spin_lock()` only on trylock success. `spin_needbreak()` and `rwlock_needbreak()` must check `preempt_model_preemptible()` at runtime. [F108, F109, F111]
- `write_seqlock*()` and `[raw_]write_seqcount_begin*()` must lock `sl->lock` or have preemption disabled before incrementing `sequence` (calling `seqcount_acquire()` before `do_raw_write_seqcount_begin()`), and `write_sequnlock*()` / `write_seqcount_end*()` must increment `sequence` before unlocking or re-enabling preemption. [F14, F26, F125]
- On `CONFIG_PREEMPT_RT`, `__seqprop_##lockname##_sequence()` locks and unlocks `s->lock` when `seq & 1` on a preemptible `seqcount_LOCKNAME_t` (`spinlock`, `rwlock`, `mutex`) before re-reading `s->seqcount.sequence` with `smp_load_acquire()`, so readers cannot run in atomic contexts where sleeping on `s->lock` is invalid. [F28, F126]
- Non-raw `seqcount_latch_t` helpers (`read_seqcount_latch*()`, `write_seqcount_latch*()`) require `kcsan_atomic_next()` / `kcsan_nestable_atomic_begin()`/`end()`, whereas read-begin helpers (`__read_seqcount_begin()`, `raw_read_seqcount()`, `read_seqcount_latch()`) must use bounded `kcsan_atomic_next(KCSAN_SEQLOCK_REGION_MAX)` because callers may exit without `read_seqcount_retry()`. [F13, F27]

## Object Lifetimes

- Dynamically allocated `struct lock_class_key` objects (`!static_obj(key)`)—and never static/per-CPU keys—must be registered with `lockdep_register_key()` before `lockdep_init_map_type()` (which also requires a non-NULL `name`), and unregistered from sleepable context via `lockdep_unregister_key()` (which unlinks `key->hash_entry` under `lockdep_lock()` even when `!debug_locks` and calls `synchronize_rcu_expedited()`) before freeing. [F1, F45, F122, F129]
- Memory containing a held lock must not be freed or reinitialized (`debug_check_no_locks_freed()`), and tasks must not exit or return to user space with `current->lockdep_depth > 0`. `struct mutex` must be initialized via `mutex_init()`/`DEFINE_MUTEX()` (never `memset()` or copied), and `devm_mutex_init()` must evaluate `mutex` once, run `mutex_init()` before `__devm_mutex_init()`, and have its return value checked. [F12, F106, F110]

## API Contracts

- A lock pinned via `lock_pin_lock()` must be unpinned with `lock_unpin_lock()` using the exact `pin_cookie` before `lock_release()`. `__lock_pin_lock()` runs with hardirqs disabled and generates 16-bit cookies (`1 + (sched_clock() & 0xffff)`) from lockless `sched_clock()` so `__lock_unpin_lock()` detects mismatches via `(int)hlock->pin_count < 0`. [F10, F95, F112]
- `lock_is_held_type()` returns `LOCK_STATE_UNKNOWN` (-1), `LOCK_STATE_NOT_HELD` (0), or `LOCK_STATE_HELD` (1) (compare explicitly rather than boolean truthiness). Because `held_lock::read` stores 0 (write), 1 (read), or 2 (recursive read), `__lock_is_held()`, `__lock_contended()`, and `__lock_acquired()` must normalize with `!!hlock->read` before comparing or indexing `stats->bounces[]`, so `lock_is_held_type()` only accepts `read` in -1, 0, or 1 (passing 2 returns `LOCK_STATE_NOT_HELD`). [F32, F33, F77]
- Trylocks (`*spin_trylock*`, `read_trylock`, `write_trylock*`, `mutex_trylock*`, `down_*_trylock`) return 1 on acquisition and 0 on contention; interruptible/killable waits return 0 on acquisition and `-errno` on signal. On `CONFIG_PREEMPT_RT`, `spin_lock*()` and `read_lock*()`/`write_lock*()` (including `_irq`/`_irqsave`) take sleeping locks without disabling hardware IRQs or preemption. [F38, F124]
- `lockdep_init_map_waits()` must forward its outer wait-type to `lockdep_init_map_type()`, and reclassification helpers (`lockdep_set_class*()`, `lockdep_set_subclass()`, `__lock_set_class()`) must preserve existing `wait_type_inner`, `wait_type_outer`, `lock_type`, and `(lock)->dep_map.name`. When `!CONFIG_DEBUG_LOCK_ALLOC`, `_nested`/`_nest_lock` macros must map to the non-nested variant with identical wait/signal/IO semantics. [F43, F55, F58]
- `DEFINE_WAIT_OVERRIDE_MAP()` maps require `lock_map_acquire_try()`. Between `lockdep_hardirqs_on_prepare()` and `lockdep_hardirqs_on()`, `current->curr_chain_key` must not change. Callers of `read_seqbegin_or_lock*()` must initialize `*seq` to even, pass updated `*seq` across retries, and call `done_seqretry*()`. Callers of `[raw_]read_seqcount_latch()` index with `seq & 1` and pass untruncated `seq` to `*_retry()`. [F15, F52, F75, F120]

## Error Handling

- Lockdep BFS helpers (`__bfs*`, `check_path`, `find_usage_*`) return `< 0` on error (`bfs_error(res)`), `BFS_RMATCH` (0) on match, and `BFS_RNOMATCH` (1) on no match. `reacquire_held_locks()` returns 1 on failure and 0 on success. `alloc_chain_hlocks()` returns a 0-based index or `-1` on failure (check `< 0`). `hlock_class()` can return `NULL` when `class_idx` is cleared in `lock_classes_in_use`. [F34, F35, F36, F39]

## External Contracts

- In `kernel/locking/lock_events.c`, `fops_lockevent` debugfs files store `(void *)(long)id` in `i_private`. `LOCKEVENT_reset_cnts` equals `lockevent_num` (valid in `lockevent_names[lockevent_num + 1]` but out of bounds for `lockevents[lockevent_num]`), so `lockevent_read()` must reject `id >= lockevent_num`. [F68, F136]

## Known Pitfalls

- Runtime lock initializers declaring a per-callsite `static struct lock_class_key __key` (`mutex_init`, `init_rwsem`, `*spin_lock_init`, `rwlock_init`, `seqcount*_init`, `seqlock_init`) must be macros, never `static inline` functions. [F54]
- `class->usage_mask` bitwise ops require shifted `LOCKF_*` / `lock_flag(bit)` masks, while `usage_traces[]` indexing takes unshifted `LOCK_*` bits bounded by `< LOCK_TRACE_STATES` (`LOCK_USAGE_STATES` is only valid in `usage_str[]`). [F44, F66]
- `held_lock::class_idx` and `chain_hlock_class_idx()` are 0-based indices into `lock_classes[]` (do not subtract 1), and `__lock_contended()` must check `lock_point() < LOCKSTAT_POINTS` before indexing `contention_point[]`/`contending_point[]`. [F63, F71]
- In `save_trace()`, `int max_entries = MAX_STACK_TRACE_ENTRIES - nr_stack_trace_entries - LOCK_TRACE_SIZE_IN_LONGS` must be signed and checked for `<= 0`, and `stack_trace[]` uses `unsigned long` units (`LOCK_TRACE_SIZE_IN_LONGS`). [F67, F99]
- `lockdep_copy_map()` must clear `to->class_cache[]` after `*to = *from`. `get_dep_list(lock, offset)` must cast `lock->class` to `void *` before adding `offset`. In `check_prev_add()`, the inner `locks_before` loop reuses the outer `locks_after` cursor `entry`, so `if (entry->class == hlock_class(next))` must unconditionally return. [F76, F83, F102]
