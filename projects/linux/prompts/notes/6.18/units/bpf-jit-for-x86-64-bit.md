# BPF JIT for X86 64-BIT

This component implements the x86-64 Just-In-Time (JIT) compiler for eBPF programs, BPF trampolines (`fentry`/`fexit`/`fmod_ret`/`struct_ops`), and BPF dispatchers. It translates verified eBPF bytecode into native x86-64 machine instructions across multiple convergence passes, manages executable text packing and runtime text poking for direct tail calls and trampolines, and provides exception fixup handling (`ex_handler_bpf`) and ORC-based stack walking for BPF exceptions.

## Architecture & Data Flow
- Every JITed exit and unwind path (`BPF_EXIT` in `do_jit()`, `emit_bpf_tail_call_indirect()`, `emit_bpf_tail_call_direct()`, and `is_exception_cb` in `emit_prologue()`) must pop callee-saved registers in reverse prologue order (`pop_callee_regs()` then `pop_r12()`), using `all_callee_regs_used` plus `r12` on `exception_boundary` frames. When `arena_vm_start` is non-zero, `do_jit()` must save `X86_REG_R12`, load `arena_vm_start` into it before the loop, and never use it as scratch. [F9, F102, F111]
- `emit_prologue()` must emit `X86_TAIL_CALL_OFFSET` (`12 + ENDBR_INSN_SIZE`) bytes between `prog->bpf_func` (`image + cfi_get_offset()`) and the post-frame-setup `EMIT_ENDBR()` so tail calls jumping to `target->bpf_func + X86_TAIL_CALL_OFFSET` land on that `ENDBR`. Before jumping there, `emit_bpf_tail_call_indirect()` and `emit_bpf_tail_call_direct()` must pop callee-saved registers and `r12`, pop both 8-byte tail-call stack slots from `emit_prologue_tail_call()`, and add `round_up(stack_depth, 8)` to `rsp`. [F10, F52]
- Stack offsets depending on `stack_depth` (including `emit_prologue()`, `BPF_TAIL_CALL_CNT_PTR_STACK_OFF()`, `LOAD_TAIL_CALL_CNT_PTR()`, and `LOAD_TRAMP_TAIL_CALL_CNT_PTR()`) must use `round_up(..., 8)`. When `tail_call_reachable` is true, `emit_prologue_tail_call()` stores `tail_call_cnt_ptr` at `BPF_TAIL_CALL_CNT_PTR_STACK_OFF(stack_depth)` (`-16 - round_up(stack_depth, 8)` from `%rbp`), and `BPF_PSEUDO_CALL` must load it into `%rax` via `LOAD_TAIL_CALL_CNT_PTR(stack_depth)` before `emit_call()`. [F44, F104]
- When `prog->aux->jits_use_priv_stack` is set, `priv_stack_ptr` is allocated as `round_up(stack_depth, 8) + 2 * PRIV_STACK_GUARD_SZ` bytes. When `priv_stack_ptr` is non-NULL in `do_jit()`, `priv_frame_ptr` is set to `(alloc_size - PRIV_STACK_GUARD_SZ) >> 3`, `stack_depth` is zeroed for kernel-stack prologue/tail-call emission, `BPF_REG_FP` is remapped to `X86_REG_R9`, and caller-saved `X86_REG_R9` must be preserved with `push_r9`/`pop_r9` around every `BPF_JMP | BPF_CALL`. [F38, F57]
- `addrs` in `bpf_int_jit_compile()` and `do_jit()` has `prog->len + 1` elements (`addrs[0]` is prologue length; `addrs[1..prog->len]` are 1-based instruction end offsets), so `bpf_prog_fill_jited_linfo()` must receive `addrs + 1`, and 2-slot `BPF_LD | BPF_IMM | BPF_DW` must increment both `insn` and `i` inside the switch. [F43, F48]
- The loop in `bpf_int_jit_compile()` must continue while `pass < MAX_PASSES || image`, and the `if (image)` branch must always `break` on size match or jump to `out_image` (resetting `image = NULL`), ensuring one final emission pass runs even if convergence occurs on pass `MAX_PASSES - 1`. In `do_jit()`, `seen_exit` must be initialized to `false` on each pass so only the first `BPF_JMP | BPF_EXIT` updates `ctx->cleanup_addr = proglen` and emits the epilogue inline. [F61, F64]
- Short jump offsets in `do_jit()` must use `is_imm8_jmp_offset()` (`[-128, 123]`) rather than `is_imm8()`, and when `jmp_padding` is active, any shrinkage from a near jump to a short or elided jump must be padded with `INSN_SZ_DIFF` NOPs before the jump instruction. When `do_jit()` compiles `BPF_JMP | BPF_JA` with `insn->off == -1` or `BPF_JMP32 | BPF_JA` with `insn->imm == -1`, it must set `jmp_offset = -2` directly instead of using `addrs[]`. [F53, F59]
- In `do_jit()`, every `BPF_PROBE_MEM` or `BPF_PROBE_MEMSX` load must be preceded by an unsigned check `(src_reg + insn->off) - VSYSCALL_ADDR > TASK_SIZE_MAX + PAGE_SIZE - VSYSCALL_ADDR` that zeroes `dst_reg` and skips the load on non-kernel addresses. When populating an `exception_table_entry`, `_insn` must be `image + proglen + (start_of_ldx - temp)` and `FIXUP_INSN_LEN_MASK` in `ex->fixup` must be `prog - start_of_ldx` (excluding runtime check bytes before `start_of_ldx`), and any register indexed in `reg2pt_regs[]` must be `<= BPF_REG_9`. [F51, F81, F109]
- In `do_jit()` for `BPF_JMP | BPF_TAIL_CALL`, a non-zero `imm32` is a 1-based index into `bpf_prog->aux->poke_tab` (`&bpf_prog->aux->poke_tab[imm32 - 1]`), whereas `imm32 == 0` selects `emit_bpf_tail_call_indirect()`, which must zero-extend `%edx` (`mov edx, edx`) and use a 32-bit `cmp` against `array->map.max_entries`. In `bpf_tail_call_direct_fixup()`, each `poke_tab` entry must satisfy `(!poke->aux || poke->aux == prog->aux)` and `poke->reason == BPF_POKE_REASON_TAIL_CALL` before downcasting `poke->tail_call.map` to `struct bpf_array`. [F28, F45, F47]
- `reg2hex[]` stores only the lower 3 bits of each register number, so encoders using `reg2hex[]` (`add_1reg()`, `add_2reg()`, `emit_3vex()`) must test `is_ereg()` to set the REX/VEX bit for `r8`..`r15`. For 8-bit register stores (`BPF_B` in `emit_stx()`), `is_ereg_8l(src_reg)` must also be checked so `BPF_REG_1` (`%rdi`), `BPF_REG_2` (`%rsi`), and `BPF_REG_FP` (`%rbp`) emit a `0x40` REX prefix for `%dil`, `%sil`, and `%bpl`. [F49, F112]
- In `__arch_prepare_bpf_trampoline()`, when `BPF_TRAMP_F_CALL_ORIG` is set, emit `__bpf_tramp_enter(im)` before `fentry`/`fmod_ret`, emit `__bpf_tramp_exit(im)` after `do_fexit` and `fexit` links while recording `im->ip_after_call` and `im->ip_epilogue`, and restore `[rbp - 8]` into `BPF_REG_0` (`if (save_ret)`) after `__bpf_tramp_exit`. Under `BPF_TRAMP_F_TAIL_CALL_CTX`, push `%rax` after allocating `stack_size`, restore it via `LOAD_TRAMP_TAIL_CALL_CNT_PTR(stack_size)` before `orig_call` or exit (when `!BPF_TRAMP_F_CALL_ORIG`), and use `%rbx` for `BPF_TRAMP_F_ORIG_STACK`. [F8, F71, F105]
- In `get_nr_used_regs()`, `save_args()`, and `restore_regs()`, when a multi-register struct argument exceeds the 6 argument registers (`nr_regs + arg_regs > 6`), the loop must not `break` early or increment `nr_regs`, because a later smaller argument may fit in remaining registers. When `nr_regs > 6` and `BPF_TRAMP_F_CALL_ORIG` is set, `stack_size` must satisfy `stack_size % 16 == 8` (`stack_size + 24` aligned to 16), and `save_args()` must copy stack arguments from `rbp + 0x18 + nr_stack_slots * 8` (initializing `first_off = 0`) and call `clean_stack_garbage()`. [F25, F65, F106]
- All indirect jumps and function returns emitted into JITed BPF programs, trampolines, and dispatchers must use `emit_indirect_jump()` and `emit_return()` (passing the exact runtime `ip`). When inspecting or skipping a function entry in `bpf_arch_text_poke()` and `__arch_prepare_bpf_trampoline()` (`BPF_TRAMP_F_SKIP_FRAME`), the code must advance past `ENDBR_INSN_SIZE` if `is_endbr()` is true before patching or skipping `X86_PATCH_SIZE` bytes. [F94, F96]

## Synchronization
- In `bpf_arch_poke_desc_update()` and `bpf_tail_call_direct_fixup()`, installing a direct tail-call target must patch `poke->tailcall_target` before NOP-ing `poke->tailcall_bypass`. When clearing a target (`new == NULL`), `poke->tailcall_bypass` must first be patched to jump to `poke->bypass_addr` and, if code was modified (`!ret`), followed by `synchronize_rcu()` before `poke->tailcall_target` is patched to `NULL` (NOP). [F12, F41]
- In `bpf_int_jit_compile()`, `bpf_jit_binary_pack_finalize(header, rw_header)` must succeed before `bpf_tail_call_direct_fixup(prog)` is called. In `bpf_tail_call_direct_fixup()`, reading `array->ptrs[poke->tail_call.key]`, patching `poke->tailcall_target` and `poke->tailcall_bypass`, and publishing `WRITE_ONCE(poke->tailcall_target_stable, true)` must all occur under `array->aux->poke_mutex`. In `__bpf_arch_text_poke()`, checking `memcmp(ip, old_insn, X86_PATCH_SIZE)` and calling `smp_text_poke_single()` must occur under a single hold of `text_mutex`. [F13, F15, F16]
- In `invoke_bpf_prog()`, every generated call to `p->bpf_func` must be bracketed by `bpf_trampoline_enter(p)` (storing the returned timestamp in callee-saved `BPF_REG_6` / `%rbx` and skipping `p->bpf_func` on zero return) and an unconditional call to `bpf_trampoline_exit(p)` receiving `(p, rbx, &run_ctx)`. [F107]

## Object Lifetimes
- In `bpf_int_jit_compile()`, once `bpf_jit_blind_constants()` returns a cloned program (`tmp != prog`), every fallback or failure path where `!image` holds must reset `prog = orig_prog` before reaching `out:` so `bpf_jit_prog_release_other()` frees `tmp` and returns `orig_prog`, and when `extra_pass` is true, must clear `prog->bpf_func`, `prog->jited`, and `prog->jited_len`. [F1, F32]
- When `bpf_int_jit_compile()` aborts via `out_image:` with a non-NULL `header` prior to `bpf_jit_binary_pack_finalize()`, it must copy `rw_header->size` into `header->size` via `bpf_arch_text_copy()` before calling `bpf_jit_binary_pack_free(header, rw_header)` and resetting `image = NULL`. Because `bpf_jit_binary_pack_finalize(header, rw_header)` frees both headers even on error, `header` must be set to `NULL` before jumping to `out_image:` on finalization failure. [F2, F3]
- In `bpf_int_jit_compile()`, `addrs`, `priv_stack_ptr` (when `!image`), and `jit_data` must be freed and `prog->aux->priv_stack_ptr` and `prog->aux->jit_data` cleared whenever `!image || !prog->is_func || extra_pass` holds. In `bpf_jit_free()`, if `prog->jited` is set and `prog->aux->jit_data` is non-NULL, it must call `bpf_jit_binary_pack_finalize()` and free `jit_data->addrs` and `jit_data` before `bpf_jit_binary_pack_free()`, and must always call `bpf_prog_unlock_free(prog)`. [F4, F6]

## API Contracts
- All relative branch and call emitters (`emit_patch`, `emit_call`, `emit_rsb_call`, `emit_jump`, `emit_cond_near_jump`, `emit_indirect_jump`, `emit_return`, and `x86_call_depth_emit_accounting`) require `ip` to be the target instruction's address in the final executable `image` buffer while writing bytes to `*pprog` in the temporary or `rw_image` buffer, and callers must advance `ip` by the exact byte count of all instructions emitted since base `ip`. [F19, F30]
- In `add_2mod(byte, r1, r2)` and `add_2reg(byte, dst_reg, src_reg)`, the first register is ModR/M `r/m` (REX.B) and the second is ModR/M `reg` (REX.R), while `add_1reg(byte, dst_reg)` encodes bits 0..2. In `add_3mod(byte, r1, r2, index)`, `r1` sets REX.B (SIB base), `r2` sets REX.R (ModR/M reg), and `index` sets REX.X (SIB index), matching `(ptr_reg, val_reg, index_reg)` of `emit_insn_suffix_SIB()`. Broken by: passing `(dst_reg, src_reg)` to `add_2mod`/`add_2reg` for `IMUL`, `MOVZX`, `MOVSX`, or `CMOVcc` where destination is in ModR/M `reg`. [F17, F18]
- `bpf_arch_poke_desc_update()` and `bpf_tail_call_direct_fixup()` must invoke `__bpf_arch_text_poke()` directly rather than `bpf_arch_text_poke()`. `arch_bpf_trampoline_size()` must allocate its temporary buffer via `bpf_jit_alloc_exec(PAGE_SIZE)` rather than `kvmalloc()`, and `__arch_prepare_bpf_trampoline()` must only dereference `im` when `flags & BPF_TRAMP_F_CALL_ORIG` is set (`bpf_struct_ops` passes `im = NULL` with `BPF_TRAMP_F_INDIRECT`). [F14, F108, F121]

## Error Handling
- `bpf_arch_text_copy()` returns `dst` on success and `ERR_PTR(-EINVAL)` (never `NULL`) when `text_poke_copy()` returns `NULL`, so callers such as `arch_prepare_bpf_trampoline()` must check `IS_ERR()` rather than `NULL`. [F21]

## External Contracts
- `emit_prologue()` must emit `cfi_bpf_subprog_hash` (arity 5) for subprograms and `cfi_bpf_hash` (arity 1) for main programs. In `__arch_prepare_bpf_trampoline()`, the entry must emit `emit_cfi()` with `cfi_get_func_hash(func_addr)` and `cfi_get_func_arity(func_addr)` (with `emit_fineibt()` calling `__bhi_args[arity]` at `ip + 11`) when `BPF_TRAMP_F_INDIRECT` is set, and `x86_call_depth_emit_accounting(&prog, NULL, image)` when not set. [F87, F97]
- `bpf_jit_supports_exceptions()` must return `IS_ENABLED(CONFIG_UNWINDER_ORC)` to match `#if defined(CONFIG_UNWINDER_ORC)` in `arch_bpf_stack_walk()`. When `in_arena` is true, `bpf_jit_supports_insn()` must return `false` for 32/64-bit `BPF_STX | BPF_ATOMIC` instructions with `imm` equal to `BPF_AND/OR/XOR | BPF_FETCH`, because `BPF_PROBE_ATOMIC` lowers via `emit_atomic_rmw_index()`, which rejects them. [F114, F115]

## Known Pitfalls
- In `do_jit()`, sequences saving `BPF_REG_0` (`%rax`) to `BPF_REG_AX` (`%r10`) before clobbering `%rax` (like `BPF_AND/OR/XOR | BPF_FETCH` `cmpxchg` loops) must remap `src_reg` and `dst_reg` to `BPF_REG_AX` if either equals `BPF_REG_0`. Instructions needing fixed registers (`%rcx`/`BPF_REG_4` for shifts, `%rax`/`BPF_REG_0` and `%rdx`/`BPF_REG_3` for `BPF_DIV`/`BPF_MOD`) must stage conflicting operands via `AUX_REG` (`%r11`), only push/pop non-destination fixed registers, and check `insn->dst_reg == BPF_REG_4` (not `dst_reg`) after shifts. [F33, F34, F66]
- `emit_insn_suffix()` always emits a 1-byte or 4-byte displacement (never `mod=00`) because `BPF_REG_7` (`R13`) and `BPF_REG_FP` (`RBP`) require an offset in ModR/M, and `X86_REG_R12` (`reg2hex` = 4) must only be addressed via `emit_insn_suffix_SIB()`. Memory operands with 1-byte displacements are only valid if the offset fits in `is_imm8()`; larger offsets like `offsetof(struct bpf_array, ptrs)` require `EMIT*_off32()`. [F46, F50]
- In `do_jit()`, `bpf_prog->aux->extable[excnt++]` must compute `delta = _insn - (u8 *)&ex->insn` while `ex` points into `image`, then remap `ex` via `(void *)rw_image + ((void *)ex - (void *)image)`; on `extra_pass` in `bpf_int_jit_compile()`, `rw_image` must be `(void *)rw_header + ((void *)image - (void *)header)`. In `ex_handler_bpf()`, `FIXUP_REG_MASK`/`FIXUP_ARENA_REG_MASK` are byte offsets requiring `(void *)regs` casts, and `FIELD_GET(DATA_ARENA_OFFSET_MASK, x->data)` must be stored in a signed `s16` before adding to the base register. [F77, F82, F83, F85]
- `struct jit_context::cleanup_addr` and `addrs[]` elements in `do_jit()` must be signed `int` so `s64 jmp_offset = ctx->cleanup_addr - addrs[i]` and `addrs[i + insn->off] - addrs[i]` perform signed subtraction before widening to `s64`. In `emit_mov_imm64()`, `imm32_lo` must be cast to `u32` and `is_uimm32(imm64)` (`sign_propagate = false`) checked before `is_simm32(imm64)`. [F72, F74]
- In `do_jit()`, `BPF_ALU64 | BPF_MOV | BPF_X` must check `insn_is_cast_user(insn)` and `insn_is_mov_percpu_addr(insn)` and `break` before falling through to `BPF_ALU | BPF_MOV | BPF_X` (which passes non-zero `insn->off` to `emit_movsx_reg()`). Emitting `add <reg>, gs:[&this_cpu_off]` in `emit_priv_frame_ptr()` and `insn_is_mov_percpu_addr(insn)` must be guarded by `#ifdef CONFIG_SMP`. [F62, F116]
