# XFS FILESYSTEM

This unit implements XFS VFS superblock and mount operations (`xfs_super.c`), copy-on-write and file range remapping (`xfs_reflink.c`), realtime extent allocation and growfs (`xfs_rtalloc.c`), symlinks (`xfs_symlink.c`), refcount/rmap log items and recovery (`xfs_refcount_item.c`, `xfs_rmap_item.c`), and sysfs/stats glue, alongside core `libxfs` metadata algorithms for shortform/node directories, inode allocation and inobt/finobt B+trees, in-core extent trees (`xfs_iext_tree.c`), atomic mapping exchange (`xfs_exchmaps.c`), dquot buffers, and per-AG/RT-group management (`xfs_group.c`).

## Architecture & Data Flow

- In `xfs_iext_tree.c`, a height-1 root in `ifp->if_data` has no `prev`/`next` pointers; bound leaf indices by `xfs_iext_max_recs(ifp)` and only access `leaf->next`/`prev` when `ifp->if_height > 1`. Inner nodes (`xfs_iext_node`) mark unused keys with `XFS_IEXT_KEY_INVALID` (`1ULL << 63`, not `0`), leaves check `rec->hi == 0`, reading file offset from `rec->lo` requires masking with `XFS_IEXT_STARTOFF_MASK`, and any key change at `pos == 0` requires `xfs_iext_update_node()` to update ancestor keys. [F61, F86, F87, F103]
- In `xfs_dir2_sf.c`, shortform inode numbers sit at `sfep->name + sfep->namelen + (xfs_has_ftype(mp) ? 1 : 0)` and require `get_unaligned_be32`/`64` and `put_unaligned_be32`/`64`. Set `sfp->i8count` before calling `xfs_dir2_sf_put_parent_ino()`, `xfs_dir2_sf_firstentry()`, `xfs_dir2_sf_nextentry()`, or `xfs_dir2_sf_put_ino()`, use `xfs_dir2_sf_hdr_size(i8count)` (never `sizeof(struct xfs_dir2_sf_hdr)`), and call `xfs_dir2_sf_toino4()`/`toino8()` when `i8count` crosses 0 and 1 while keeping `dp->i_disk_size == dp->i_df.if_bytes`. [F65, F123, F126]
- In `xfs_ialloc.c`, AG block bounds (`max_agbno`) must use `xfs_ag_block_count(mp, pag_agno(pag))` rather than `mp->m_sb.sb_agblocks`. In `xfs_ialloc_ag_alloc()`, call `xfs_inobt_insert_sprec()` before `xfs_finobt_insert_sprec()` to merge sparse records first, and reset `args.minalignslop = 0` after `xfs_alloc_vextent_exact_bno()`. In `xfs_dialloc_ag_inobt()`, save `pagl_leftrec` and `pagl_rightrec` before `rec = trec`, and reset `pagl_pagino`, `pagl_leftrec`, and `pagl_rightrec` to `NULLAGINO` before `restart_pagno`. [F54, F55, F57, F58, F73]
- In `xfs_exchmaps_finish_one()`, recheck `xmi_has_more_exchange_work(xmi)` after `xfs_exchmaps_find_mappings()`, and return `-EAGAIN` if `xmi_has_more_exchange_work(xmi)` or `xmi_has_postop_work(xmi)` holds. In `xfs_exchmaps_one_step()`, `xfs_exchmaps_update_size()` advances `i_disk_size` (ignoring negative `xmi_isize*` sentinels) using `irec2` for `xmi_ip1` and `irec1` for `xmi_ip2` after swapping `br_startoff`. [F42, F69, F90]
- In `struct xfs_rtgroup`, `rtg_rsum_cache` shares a union with `rtg_open_zone` (valid only when `!xfs_has_zoned(mp)`), is initialized to `0xFF` (`memset(..., -1, rbmblocks)`), and stores a strict upper bound `log + 1` in `xfs_rtany_summary()`. In `xfs_rtallocate_range()`, update summary counts via `xfs_rtmodify_summary()` for the split free extent before `xfs_rtmodify_range()`. In `xfs_rtallocate_clamp_len()`, clamp `rtxlen` against `rtg->rtg_extents` before rounding down to a multiple of `prod` via `xfs_rtalloc_align_len()`. [F213, F233, F234, F260]
- In `xfs_reflink_end_cow_extent_locked()`, copy `got` to `del` and trim `del` to `[*offset_fsb, end_fsb)` and `data.br_blockcount` before remapping, while passing untrimmed `got` to `xfs_bmap_del_extent_cow()`. In `xfs_reflink_clear_inode_flag()`, check `xfs_can_free_cowblocks(ip)` before canceling CoW blocks or clearing `XFS_DIFLAG2_REFLINK`. [F256, F320]
- `xfs_cui_init()`/`xfs_cui_item_free()` and `xfs_rui_init()`/`xfs_rui_item_free()` must use `kzalloc()`/`kfree()` when `nextents > 16` (`XFS_{CUI,RUI}_MAX_FAST_EXTENTS`) and slab caches only when `nextents <= 16`. Pass2 recovery (`xlog_recover_{cui,rtcui,rui,rtrui}_commit_pass2()`) must check `iov_len` against both the 0-extent header size and `xfs_{cui,rui}_log_format_sizeof(nextents)`, and `xfs_{refcount,rmap}_recover_work()` must validate every extent with `xfs_cui_validate_phys()`/`xfs_rui_validate_map()`. [F252, F253, F254]
- In `xfs_super.c`, `fc->s_fs_info` (`parsing_mp`/`new_mp`) has `m_super == NULL`, so `xfs_fs_parse_param()` must not dereference `m_super` and `xfs_fs_reconfigure()` must run `xfs_finish_flags()` on `mp = XFS_M(fc->root->d_sb)`. Clear `XFS_QFLAGS_MNTOPTS` in `xfs_fs_fill_super()` and `xfs_fs_reconfigure()`, call `xfs_set_inode_alloc()` when toggling `XFS_FEAT_SMALL_INUMS`, and pair `xfs_save_resvblks()` in `xfs_remount_ro()`/`xfs_fs_freeze()` with `xfs_restore_resvblks()` in `xfs_remount_rw()`/`xfs_fs_unfreeze()`. [F223, F237, F238, F247]

## Synchronization

- `xfs_group_insert()` must initialize all `struct xfs_group` fields and set `xg_active_ref` to 1 before `xa_insert()`. Accessing `xg_checked` or `xg_sick` requires `xg->xg_state_lock`. `xfs_ialloc_read_agi()` must set `pagi_freecount` and `pagi_count` before `XFS_AGSTATE_AGI_INIT`, and `xfs_dialloc_try_ag()` must recheck `pagi_freecount` after locking the AGI buffer. [F25, F28, F29, F31]
- Callers of `xfs_exchange_mappings()` and `xfs_exchmaps_estimate()` must flush both `req->ip1` and `req->ip2` and hold `XFS_ILOCK_EXCL` on both; `xfs_exchange_mappings()` requires both joined to `tp`, calls `xfs_exchmaps_ensure_reflink()` and `xfs_exchmaps_upgrade_extent_counts()`, and leaves both locked and joined. Every in-core extent tree mutation must call `xfs_iext_inc_seq(ifp)`. [F16, F32, F33, F161]
- `xfs_reflink_fill_cow_hole()` and `xfs_reflink_fill_delalloc()` drop `XFS_ILOCK` before `xfs_trans_alloc_inode()`, so they must re-run `xfs_find_trim_cow_extent()` after reacquiring `XFS_ILOCK_EXCL`. In `xfs_reflink_remap_prep()`, hold `xfs_ilock2_io_mmap(src, dest)` and only demote `src` after setting `XFS_IREMAPPING` when `inode_in != inode_out`. In `xfs_reflink_set_inode_flag()`, every locked inode (`src`, and `dest` if distinct) must be joined to `tp` with `XFS_ILOCK_EXCL` or unlocked before commit. [F181, F206, F242]
- In `xfs_rtallocate_rtg()` on `xfs_has_rtgroups(mp)` mounts, `args.rtg` is locked with `XFS_RTGLOCK_BITMAP` without joining `tp` until `xfs_rtallocate_adjust_for_busy()`; earlier errors jump to `out_unlock` (`*rtlocked = false`), whereas after `xfs_rtgroup_trans_join()` `tp` owns the lock (`out_release`). `xfs_rtmount_rtg()` must call `xfs_rtmount_iread_extents()` under `XFS_ILOCK_EXCL`, and `xfs_growfs_rt_bmblock()` requires `XFS_RTGLOCK_BITMAP | XFS_RTGLOCK_RMAP` while updating `i_disk_size` and `i_size_write()`. [F186, F187, F197]
- `xfs_refcount_defer_add()` and `xfs_rmap_defer_add()` must dispatch `ri->ri_realtime` intents to `xfs_rtrefcount_update_defer_type` and `xfs_rtrmap_update_defer_type`. In `xfs_remount_ro()`, stop `blockgc`, run `xfs_blockgc_free_space()` with `XFS_ICWALK_FLAG_SYNC`, and stop `inodegc` and `zone_gc` before `xfs_log_clean()`. Wrap `xfs_fs_freeze()` log quiesce in `memalloc_nofs_save()`/`restore()`, and never call `xfs_flush_inodes()` under `XFS_ILOCK` or folio locks. [F192, F200, F303, F308]

## Object Lifetimes

- `struct xfs_group` must be at offset 0 of `struct xfs_perag` and `struct xfs_rtgroup` for `kfree_rcu_mightsleep(xg)` in `xfs_group_free()`; `xfs_group_insert()` does not free `xg` on error, and `xg_busy_extents` requires `xfs_group_has_extent_busy(mp, type)`. Do not mix passive (`xfs_group_get`/`hold` -> `xfs_group_put`) and active (`xfs_group_grab` via `atomic_inc_not_zero()` -> `xfs_group_rele`) refs, hold `rcu_read_lock()` across lookups, and release `@xg` on early loop exits from `xfs_group_next_range()`. [F1, F2, F3, F26, F27, F35, F119]
- In `xfs_dir2_node.c`, after `xfs_trans_brelse()` or `xfs_dir2_shrink_inode()` (which invalidates the buffer), clear the buffer pointers (`*bpp = NULL` in `__xfs_dir3_free_read()`, `fbp = NULL` and `fblk->bp = NULL` in `xfs_dir2_node_find_freeblk()`, `dblk->bp = NULL` in `xfs_dir2_leafn_remove()`, `fbp = NULL` in `xfs_dir3_data_block_free()`). `xfs_dir2_node_lookup()` and `xfs_dir2_node_replace()` must `xfs_trans_brelse()` all `state->path.blk[i].bp` and `state->extrablk.bp` before `xfs_da_state_free()`. [F4, F5, F6, F7, F8]
- In `xfs_dir2_sf.c`: `xfs_dir2_sf_addname_easy()` must recompute `sfep` after `xfs_idata_realloc()`; `xfs_dir2_sf_addname_hard()` and `xfs_dir2_sf_toino4()`/`toino8()` must copy to a temp buffer, shrink to 0 before growing via `xfs_idata_realloc()`, and `kfree(buf)`; `xfs_dir2_sf_removename()` must `memmove()` before shrinking; and `xfs_dir2_block_to_sf()` must copy entries from `bp->b_addr` before `xfs_dir2_shrink_inode()` invalidates `bp`. [F9, F10, F12, F125]
- `xfs_inobt_init_cursor()` and `xfs_finobt_init_cursor()` borrow `agbp` (which is `NULL` for staging cursors; callers must `xfs_trans_brelse(agbp)`). In `xfs_dialloc_roll()`, hold `agibp` (`xfs_trans_bhold`) and detach `t_dqinfo` before `xfs_trans_roll(&tp)`, and restore `t_dqinfo`, `xfs_trans_bjoin(tp, agibp)`, and `*tpp = tp` even on error. In `xfs_ialloc_inode_init()`, release `fbuf` via `xfs_buf_relse()` only when `tp == NULL`. [F17, F19, F20, F43]
- In `xfs_iext_realloc_root()`, expand `new_size` to `NODE_SIZE` at `RECS_PER_LEAF`, zero `[ifp->if_bytes, new_size)`, and update `cur->leaf = new`; in `xfs_iext_rebalance_leaf()`, redirect `cur->leaf` and adjust `cur->pos` before freeing a merged leaf; and in `xfs_iext_destroy()`, recursively free child nodes at `level > 1`. [F22, F23, F24, F53, F122]
- `xfs_cui_init()`/`xfs_rui_init()` set refcount to 2, freed via `xfs_cui_release()`/`xfs_rui_release()`; do not call `xfs_{refcount,rmap}_update_cancel_item()` when `finish_item` returns `-EAGAIN` with remaining blocks; and in `xfs_{refcount,rmap}_recover_work()`, allocate `tp` with `xlog_recover_resv(&M_RES(mp)->tr_itruncate)` (`xlog_recover_finish_intent()` transfers `dfp` ownership to `tp`). [F163, F164, F166]
- In `xfs_open_devices()`, close unconsumed device files with `bdev_fput()` (never `fput()`) and clear `ERR_PTR` from `mp->m_*_targp`. In `xfs_fs_fill_super()`, jump to `out_unmount` on errors after `xfs_mountfs(mp)` succeeds and leave `xfs_mount_free()` to `xfs_kill_sb()`/`xfs_fs_free()`. `xfs_destroy_caches()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F170, F175, F176, F316, F319]

## API Contracts

- `xfs_iext_remove()` positions `cur` at the next extent (do not call `xfs_iext_next()`), and when `cur->leaf == NULL`, `xfs_iext_prev()`/`next()` reset `cur` to `xfs_iext_last()`/`first()`. Callers of `xfs_exchmaps_estimate()` must zero `struct xfs_exchmaps_req` output fields, and callers of `xfs_exchmaps_find_mappings()` must call `xmi_advance()` after handling a returned mapping pair. Runtime corruption paths must call `xfs_*_mark_sick()`, never `xfs_*_mark_corrupt()`. [F40, F89, F92, F93, F157]
- Callers of `xfs_reflink_cancel_cow_blocks()` and `xfs_reflink_clear_inode_flag()` must join `ip` with `lock_flags == 0`. In `xfs_reflink.c`, convert byte ranges to FSBs with floor `XFS_B_TO_FSBT()` for start and ceiling `XFS_B_TO_FSB()` for end; pass inclusive `offset + len - 1` to `filemap_write_and_wait_range()` in `xfs_reflink_unshare()`; always advance `*offset_fsb` in `xfs_reflink_end_cow_extent_locked()`; always set `*remapped` in `xfs_reflink_remap_blocks()`; and never call `xfs_reflink_recover_cow()` when cached inodes hold live CoW extents. [F179, F217, F219, F220, F241, F287]
- In `xfs_rtallocate_rtgs()`/`rtg()`, `bno_hint` is `NULLFSBLOCK` when absent, `minlen`/`maxlen`/`prod` are in rtextents (multiples of `prod`), and `*bno`/`*blen` are in FSBs; `xfs_rtany_summary()` sets signed `*maxlog = -1` when empty. When bulk-copying CUI/RUI extents, set `{cui,rui}_next_extent` via `atomic_set()`, and pass the intent type (`XFS_LI_{CUI,CUI_RT,RUI,RUI_RT}`) to `xlog_recover_release_intent()`. `xfs_sysfs_ops` attributes must be in `struct xfs_sysfs_attr`, and `err_to_mp()` attributes must only attach to `mp->m_error_kobj`. [F207, F208, F209, F212, F228, F229, F299, F300]

## Error Handling

- `xfs_failaddr_t` verifiers return `NULL` on success and `__this_address` on corruption; post-read checks in `xfs_dir2_node.c` must use `xfs_buf_mark_corrupt()`, never `xfs_verifier_error()`. Roll back `xfs_dir2_sf_toino8()` with `xfs_dir2_sf_toino4()` on `-ENOENT` in `xfs_dir2_sf_replace()`, and call `xfs_irele(ip)` on validation failure in `xfs_dqinode_load()`. [F11, F13, F34, F146]
- In `xfs_dialloc()`, reset `error = 0` on `-EAGAIN`, clear `flags = 0` before `retry`, and verify `ino != parent && xfs_verify_dir_ino(mp, ino)`. In `xfs_{refcount,rmap}_finish_one_cleanup()`, read `rcur->bc_ag.agbp` before `xfs_btree_del_cursor()` and only `xfs_trans_brelse()` on error. In `xfs_symlink()`, call `xfs_trans_cancel(tp)` before unlocking/releasing `du.ip`. [F95, F151, F165, F167]
- Restart `inodegc`, `blockgc`, and `zone_gc` if `xfs_fs_freeze()` fails; unwind `mp->m_free[i].count` with `while (--i >= 0)` in `xfs_init_percpu_counters()`; in `xfs_rtallocate_rtg()`, release the cached buffer and reset `error = 0` on `-ENOSPC` from `xfs_rtallocate_extent_near()`; and in `xfs_growfs_rt()`/`rtg()`, restore `old_rsum_cache` on error, call `xfs_rtunmount_rtg()` before `xfs_rtgroup_free()`, and use `error2` for post-loop calls. [F172, F173, F184, F185, F211, F214]

## Known Pitfalls

- Never use `sizeof(struct xfs_btree_block)` (use `XFS_BTREE_*_LEN` / `XFS_INOBT_BLOCK_LEN`), and always use `xfs_finobt_init_cursor()` for `finobt`. Mask sparse `irec->ir_free` with `xfs_inobt_irec_to_allocmask(irec)`. In `xfs_dquot_buf.c`, fall back to `xfs_calc_dquots_per_chunk(bp->b_length)` when `mp->m_quotainfo == NULL` during log recovery. [F82, F83, F88, F149]
- In `xfs_reflink.c`, delay `xfs_iext_count_extend()` until after no-op checks, call `xfs_iext_prev()` in `xfs_reflink_cancel_cow_blocks()` only when not deleting an extent, and loop `xfs_bmapi_write()` in `xfs_reflink_fill_delalloc()` until `cmap` covers `imap->br_startoff`. In `xfs_rtalloc.c`, restore `ap->offset`/`length` on `xfs_bmap_rtalloc()` retry, reset `bno_hint = NULLFSBLOCK` per RTG in `xfs_rtallocate_rtgs()`, and pass `&M_RES(nmp)->tr_growrtfree` to `xfs_trans_alloc()` in `xfs_growfs_rt_{bmblock,zoned}()`. [F243, F246, F249, F267, F274, F275]
