# NFS, SUNRPC, AND LOCKD CLIENTS

This unit implements the Linux NFS client (`fs/nfs`), including client and superblock lifecycle management, VFS file and directory operations, buffered and direct/swap I/O engines, attribute and access caching, fscache/netfs integration, local client-to-server bypass I/O (`localio`), NFSv4 delegations and callbacks, and the pNFS core framework along with its block/SCSI, file, and flexfile layout drivers.

## Architecture & Data Flow

- Whenever `NFS4CLNT_DELEGRETURN`, `NFS4CLNT_DELEGRETURN_DELAYED`, or `NFS4CLNT_DELEGATION_EXPIRED` is set on `clp->cl_state` (including error-retry paths in `nfs_server_return_marked_delegations()` and `nfs_server_reap_expired_delegations()`), the matching `NFS4SERV_*` bit must be set on `server->delegation_flags`. `server->nr_active_delegations` is decremented only when `NFS_DELEGATION_REVOKED` is newly set in `nfs_mark_delegation_revoked()`, and incremented when attaching or clearing `NFS_DELEGATION_REVOKED`. [F59, F61]
- Bit 0 (`1UL`) of `dentry->d_time` is the delegation verifier tag while `nfs_force_lookup_revalidate(dir)` advances `NFS_I(dir)->cache_change_attribute` by 2 under `dir->i_lock`; `nfs_clear_verifier_delegated()` must be called whenever an attached delegation is revoked or transitions to `NFS_DELEGATION_RETURNING`. [F25, F60]
- In `nfs_set_cache_invalid()`, setting `NFS_INO_INVALID_DATA` must also call `nfs_fscache_invalidate()` and, if `nrpages == 0` or `NFS_INO_INVALID_DATA` remains set, `nfs_ooo_clear()`. In `nfs_ooo_merge()`, if `cnt` reaches `ARRAY_SIZE(nfsi->ooo->gap)`, `nfsi->ooo` must be freed/nulled and `NFS_INO_DATA_INVAL_DEFER` set; when `nfs_inode_attach_open_context()` adds the first entry to `nfsi->open_files` while `nfs_ooo_test(nfsi)` is true, it must set `NFS_INO_INVALID_DATA | NFS_INO_REVAL_FORCED` under `inode->i_lock`. [F246, F250, F279]
- In `nfs_direct_write_completion()`, when `NFS_IOHDR_UNSTABLE_WRITES` is set without `NFS_IOHDR_ERROR`, `dreq->flags` must only be set to `NFS_ODIRECT_DO_COMMIT` if `!dreq->flags` so `NFS_ODIRECT_RESCHED_WRITES` is preserved. `nfs_direct_write_schedule_work()` must sample and zero `dreq->flags` before calling `nfs_direct_commit_schedule()` or `nfs_direct_write_reschedule()`, and `nfs_direct_write_reschedule()` must call `nfs_clear_pnfs_ds_commit_verifiers(&dreq->ds_cinfo)`. [F77, F118]
- In `nfs_lock_and_join_requests()`, after locking `head`, acquiring `nfs_page_group_lock(head)`, and verifying `head == folio->private`, `nfs_cancel_remove_inode(head, inode)` must be called to clear `PG_REMOVE` and restore `PG_INODE_REF` before subrequests are locked and joined. When `nfs_can_extend_write()` extends a buffered write in `nfs_update_folio()`, the range (`offset` and `end`) must be rounded only to `PAGE_SIZE` boundaries (capped at `pagelen`), not `folio_size(folio)`. [F360, F503]
- `lo->plh_stateid.seqid` is big-endian `__be32`, whereas `lo->plh_barrier`, `lo->plh_return_seq`, and `lseg->pls_seq` are host-endian `u32` compared via `(s32)(s1 - s2) > 0` in `pnfs_seqid_is_newer()`, requiring `be32_to_cpu()`/`cpu_to_be32()` at every boundary. In `pnfs_set_layout_stateid()`, when `!update_barrier` and `atomic_read(&lo->plh_outstanding) == 1`, `pnfs_barrier_update()` must be called; in `pnfs_layoutreturn_free_lsegs()`, `pnfs_reset_return_info(lo)` must be called after `pnfs_set_layout_stateid()`. [F414, F442, F471]
- Flexible arrays annotated with `__counted_by` must have their counter set immediately after allocation and before indexing or error cleanup: `dsaddr->ds_num = num` in `nfs4_fl_alloc_deviceid_node()`, `fls->mirror_array_cnt = mirror_array_cnt` in `ff_layout_alloc_lseg()`, `p->nbuckets = n` in `pnfs_alloc_commit_array()`, and `array->size++` (after `nfs_readdir_array_can_expand()`) before indexing `array->array[array->size - 1]` in `nfs_readdir_folio_array_append()`. [F135, F308, F309, F439]

## Synchronization

- `nfs_mark_client_ready()` must execute `smp_wmb()` before storing `clp->cl_cons_state`, paired with `smp_rmb()` in `nfs_found_client()` after `nfs_wait_client_init_complete()` confirms `NFS_CS_READY`. In `nfs_match_client()`, when `clp->cl_cons_state > NFS_CS_READY`, the loop must increment `clp->cl_count`, drop `nn->nfs_client_lock`, wait in `nfs_wait_client_init_complete(clp)`, put `clp`, re-acquire `nn->nfs_client_lock`, and `goto again` to restart the `nn->nfs_client_list` walk. [F15, F122]
- Attaching or detaching an inode's delegation (`nfsi->delegation`, `server->delegations`, `server->delegation_hash_table`) in `nfs_inode_set_delegation()` and `nfs_detach_delegation_locked()` requires `clp->cl_lock`, with `delegation->lock` nested inside `clp->cl_lock`. `nfs4_get_valid_delegation()` uses `rcu_dereference()` without taking a refcount, so callers must hold `rcu_read_lock()` across the call and all accesses unless pinned via `nfs_get_delegation()`. [F20, F21]
- `nfs_client_return_marked_delegations()` and `nfs_server_return_marked_delegations()` must not call `nfs_wb_all()` and must pass `issync = 0` to `nfs_end_delegation_return()`, re-verifying `rcu_dereference(NFS_I(place_holder)->delegation) == place_holder_deleg` on `restart` after dropping `rcu_read_lock()`. In `nfs4_inode_set_return_delegation_on_close()` and `nfs_mark_return_if_closed_delegation()`, if `NFS_I(inode)->open_files` is non-empty under `delegation->lock`, only `NFS_DELEGATION_RETURN_IF_CLOSED` may be set. [F69, F108, F156, F157]
- Setting `dentry->d_fsdata = NFS_FSDATA_BLOCKED` in `block_revalidate()` requires `dentry->d_lock`, and clearing it in `unblock_revalidate()` must use `store_release_wake_up(&dentry->d_fsdata, NULL)` to pair with `wait_var_event()` / `smp_load_acquire()` in `__nfs_lookup_revalidate()`. Both `nfs_lookup_revalidate()` and `nfs4_lookup_revalidate()` must call `__nfs_lookup_revalidate()` first, and `d_move()` in `nfs_rename()` must run in process context after `rpc_wait_for_completion_task()`. [F26, F79, F155]
- On any published inode (`!(inode->i_state & I_NEW)`), `nfs_set_cache_invalid()`, `nfs_set_inode_stale_locked()`, `nfs_zap_caches_locked()`, and `nfs_ooo_merge()` (which must allocate with `GFP_ATOMIC`) require `inode->i_lock`, and `nfs_access_lru_lock` nests outside `inode->i_lock`. In `nfs_clear_invalid_mapping()`, the lockless check after waiting on `NFS_INO_INVALIDATING` requires `smp_rmb()` and `smp_load_acquire(&nfsi->cache_validity)`, then re-checking and clearing `NFS_INO_INVALID_DATA` under `inode->i_lock` before `nfs_invalidate_mapping()`. [F29, F206, F207, F247, F325, F328]
- `nfs_file_block_o_direct()` requires exclusive `inode->i_rwsem` (and must be called before `nfs_sync_inode()` in `nfs_setattr()`); when the optimistic `down_read_killable(&inode->i_rwsem)` check of `NFS_INO_ODIRECT` fails in `nfs_start_io_read()` or `nfs_start_io_direct()`, the caller must drop `i_rwsem`, take `down_write_killable(&inode->i_rwsem)`, re-test `NFS_INO_ODIRECT`, and `downgrade_write()`. `nfs_vmtruncate()` must be entered and exited with `inode->i_lock` held, dropping `inode->i_lock` across `truncate_pagecache()`. [F209, F210, F211]
- Attaching a head `nfs_page` to `folio->private` in `nfs_inode_add_request()` requires locking `req` first and holding `mapping->i_private_lock`. Detaching `folio->private` in `nfs_inode_remove_request()` and verifying `head == folio->private` in `nfs_lock_and_join_requests()` must both be serialized under `nfs_page_group_lock(head)`. `nfs_page_group_lock_subreq()` must drop `nfs_page_group_unlock(head)` before `nfs_wait_on_request(subreq)` and re-acquire it afterward. [F378, F393, F486]
- `nfs_request_add_commit_list_locked()`, `nfs_request_remove_commit_list()`, and `pnfs_generic_clear_request_commit()` require both `NFS_I(cinfo->inode)->commit_mutex` and the request lock (`PG_BUSY`), updating `PG_CLEAN`/`cinfo->mds->ncommit` or `PG_COMMIT_TO_DS`/`cinfo->ds->nwritten`/`ncommitting` in lockstep. Mutating `fl_cinfo->commits` requires `inode->i_lock` and `kfree_rcu()`, while RCU readers pin `array` via `pnfs_get_commit_array()` and drop RCU before per-bucket work. [F383, F424, F430, F492, F493]
- `pnfs_free_lseg()` and `pnfs_free_lseg_list()` must only be called after releasing `inode->i_lock` because `free_lseg` callbacks acquire `inode->i_lock`. Clearing wait bits in `nfs_layoutget_end()`, `pnfs_clear_layoutreturn_waitbit()`, `pnfs_clear_first_layoutget()`, and `pnfs_clear_layoutcommitting()` must be followed by `smp_mb__after_atomic()` before `wake_up_bit()`. `pnfs_prepare_layoutreturn()` only defers for `lo->plh_outstanding != 0` when `lo->plh_return_seq == 0`. [F379, F450, F489]

## Object Lifetimes

- Once `nfs_get_client()` links a new `nfs_client` onto `nn->nfs_client_list`, `rpc_ops->init_client` must call `nfs_mark_client_ready(clp, error)` before `nfs_put_client(clp)` on failure, and schedule LOCALIO probing asynchronously via `nfs_local_probe_async(new)`. `nfs_free_server()` must call `nfs_server_remove_lists()` (which unlinks `client_link` and `master_link` and updates `NFS_CS_STOP_RENEW` under `nn->nfs_client_lock`, then calls `synchronize_rcu()`) before `server->destroy()`, shutting down RPC clients, or `call_rcu(&server->rcu, delayed_free)`. [F1, F19, F65, F158]
- `nfs_detach_delegation_locked()` transfers the initial `delegation->refcount` reference to a caller receiving a non-NULL return without decrementing it. Inserting a `pnfs_layout_segment` into `lo->plh_segs` takes a `pnfs_get_layout_hdr(lo)` reference dropped in `pnfs_layout_remove_lseg()`, so `pnfs_put_lseg()` must hold an extra `pnfs_get_layout_hdr(lo)` across `pnfs_layout_remove_lseg()` and `spin_unlock(&inode->i_lock)`. In `pnfs_read_resend_pnfs()`, `hdr->lseg` must be put and nulled before `nfs_pageio_resend(&pgio, hdr)` to avoid deadlocking against `LAYOUTRETURN`. [F3, F368, F369]
- `nfs_direct_req_alloc()` initializes `dreq->kref` to 2 (caller + `nfs_direct_complete()`), so any path in `nfs_file_direct_read/write()` exiting before scheduling I/O or scheduling 0 bytes must call `nfs_direct_req_release(dreq)` twice (and balance `inode_dio_begin/end()`). `nfs_direct_read/write_schedule_iovec()` and `nfs_direct_write_reschedule()` must hold `get_dreq(dreq)` across the submission loop through `nfs_pageio_complete(&desc)`. `dreq->iocb = iocb` must only be set when `!is_sync_kiocb(iocb)`. [F6, F33, F139]
- In `nfs4_callback_compound()`, `nfs4_cb_free_slot(&cps)` must be called before `nfs_put_client(cps.clp)` because freeing the backchannel slot accesses `cps->clp->cl_session->bc_slot_table`. In `nfs_local_call_read/write()`, `revert_creds(save_cred)` must precede `nfs_local_pgio_release(iocb)`, every `struct nfsd_file *` from `nfs_local_open_fh()` must be released via `nfs_local_file_put()`, and callers passing a new `alloc_nfs_open_context()` to `nfs_file_set_open_context()` must still call `put_nfs_open_context(ctx)`. [F7, F184, F185, F189]

## API Contracts

- `nfs_read_add_folio()` consumes the caller's folio lock on every return path, so `nfs_do_read_folio()` and `nfs_readahead()` must never unlock `folio` afterward; in `nfs_return_empty_folio()`, `nfs_readpage_release()`, and `nfs_read_add_folio()` error paths, `folio_unlock(folio)` must only be called when `nfs_netfs_folio_unlock(folio)` returns non-zero (`!netfs_inode(inode)->cache`). In `nfs_write_begin()`, `nfs_read_folio()` unlocks `folio` so only `folio_put()` is called afterward, while earlier errors require both `folio_unlock()` and `folio_put()`. [F14, F347, F358, F403]
- Ownership-consuming helpers: `nfs_init_commit()` consumes `@lseg` into `data->lseg`; `filelayout_initiate_commit()` and `ff_layout_initiate_commit()` consume `data` (calling `pnfs_generic_prepare_to_resend_writes()` and `pnfs_generic_commit_release()` on error); `nfs_local_commit()` consumes `localio` and `data`; `ext_tree_insert(bl, new)` consumes `new` and `new->be_device` on `0` but leaves them with the caller on negative errno; `pnfs_add_commit_array()` and `nfs4_pnfs_ds_add()` leave `new` / `@dsaddrs` unconsumed when an entry already exists. [F10, F186, F204, F363, F365, F366]

## Error Handling

- `nfs_alloc_client()` and `nfs_alloc_server()` initialize `clp->cl_rpcclient`, `server->client`, and `server->client_acl` to `ERR_PTR(-EINVAL)` rather than `NULL` (and `nfs_init_server_rpcclient()` stores `ERR_PTR` on failure), so all checks must use `!IS_ERR()`. `nfs_alloc_server()` returns `NULL` on failure, whereas `nfs_alloc_client()`, `nfs_get_client()`, and `nfs_create_server()` return `ERR_PTR`. In `nfs_init_server()`, error paths after `server->nfs_client = clp` must reset `server->nfs_client = NULL` before `nfs_put_client(clp)`. [F44, F45, F47]
- DS preparation returns: `nfs4_ff_layout_prepare_ds()` and `ff_layout_choose_*_ds_for_read()` return `ERR_PTR` on failure (never `NULL`, despite comments), and in `ff_layout_read/write_pagelist()` errors must be tested with `nfs_error_is_fatal(PTR_ERR(ds))` so fatal errors return `PNFS_NOT_ATTEMPTED`; `nfs4_fl_prepare_ds()` returns `NULL` (never `ERR_PTR`); `mirror->dss[dss_id].mirror_ds` can be `NULL` (lazy init, treated as available in `ff_read/rw_layout_has_available_ds()`) or `ERR_PTR(-ENODEV)`, requiring `IS_ERR_OR_NULL()` before dereferencing. [F225, F227, F228, F229, F288]
- `block_revalidate()` passes `dentry->d_fsdata` to `kfree()` and sets `NFS_FSDATA_BLOCKED`, so `nfs_unlink()` and `nfs_rename()` must first verify `!(dentry->d_flags & DCACHE_NFSFS_RENAMED)` and call `unblock_revalidate()` on every exit path. In `pnfs_update_layout()`, when `pgio->pg_lseg` receives an `ERR_PTR`, `pg_init` handlers must copy `PTR_ERR(pgio->pg_lseg)` to `pgio->pg_error` and reset `pgio->pg_lseg = NULL`, and any jump to `lookup_again` after `first = true` must call `pnfs_clear_first_layoutget(lo)`. [F54, F395, F451]

## Known Pitfalls

- Stale comments and return conventions: `nfs_delegation_find_inode()` and `nfs_layout_find_inode()` never return `NULL` (returning `ERR_PTR(-ENOENT/-EAGAIN)` on failure and an inode + `nfs_sb_active` reference released via `nfs_iput_and_deactive()` on success); `pnfs_mark_matching_lsegs_return()` and `pnfs_mark_layout_stateid_return()` return negative `-EBUSY` / `-ENOENT` despite kernel-doc listing positive values; `nfs_local_pgio/commit_done()` must translate negative VFS errno to NFSv4 wire status via `nfs_localio_errno_to_nfs4_stat()` for `res.op_status`. [F48, F230, F396]
- Loop state and cursor pitfalls: callers iterating an extent rbtree (`ext_tree_mark_written/committed()`) must assign `be = ext_try_to_merge_left(root, be)` because merging frees `be`; `ff_layout_choose_ds_for_read()` must reset `ds = ERR_PTR(-EINVAL)` before `continue` when `check_device` rejects a prepared DS; in `pnfs_ld_read/write_done()`, `if (hdr->pnfs_error)` must be re-tested sequentially after `if (!hdr->pnfs_error) rpc_call_done()`, because short I/O with `!task->tk_ops` sets `hdr->pnfs_error = -EAGAIN` inside `rpc_call_done()`. [F102, F282, F401]
