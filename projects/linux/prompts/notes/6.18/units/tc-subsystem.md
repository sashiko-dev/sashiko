# TC subsystem

This unit implements the Traffic Control (TC) action lifecycle and execution engine (`act_api.c`), concrete packet actions (`act_ct`, `act_mirred`, `act_gate`, `act_csum`, `act_nat`, `act_mpls`, `act_ife`, `act_connmark`, `act_ctinfo`, `act_gact`), the generic packet scheduler core (`sch_generic.c`), and queuing disciplines (`sch_htb`, `sch_hfsc`, `sch_qfq`, `sch_prio`, `sch_multiq`, `sch_mq`, `sch_mqprio`, `sch_ingress`, `sch_gred`, `sch_red`, `sch_pie`, `sch_hhf`, `sch_sfb`, `sch_sfq`, `sch_skbprio`, `sch_plug`).

## Architecture & Data Flow

- Layout invariants: every `struct tcf_*` action must embed `struct tc_action common` at offset 0 for direct casts in `to_<act>()` and `free_tcf()`; per-netns structs registered via `tcf_register_action()` must embed `struct tc_action_net` at offset 0; `struct tc_mqprio_qopt_offload` must keep `struct tc_mqprio_qopt qopt` at offset 0 for `TC_SETUP_QDISC_MQPRIO` casts; `struct sfq_slot` must keep `skblist_next` and `skblist_prev` as its first two members for `(struct sk_buff *)slot` casts. [F128, F129, F130, F318]
- `struct Qdisc` instances (`qdisc_alloc()` and `noop_qdisc`) must initialize `.owner = -1`. Mutations to `qdisc->state`, `refcnt`, or `dev_queue` must guard against `TCQ_F_BUILTIN` (`noop_qdisc`). When a Qdisc `->change()` handler drops packets to enforce a lowered `sch->limit`, it must dequeue via `qdisc_dequeue_internal()` (draining `sch->gso_skb`) and pass accumulated packet/byte counts to `qdisc_tree_reduce_backlog()`. [F238, F247, F250]
- Actions created via `tcf_idr_create_from_flags()` have NULL `cpu_bstats`/`cpu_qstats` when `TCA_ACT_FLAGS_NO_PERCPU_STATS` is set, so stats updates must use `tcf_action_update_bstats()`, `tcf_action_inc_drop_qstats()`, and `tcf_action_inc_overlimit_qstats()` instead of `this_cpu_ptr()`. On shared filter blocks (`tcf_block_shared(block)`), `tp->chain->block->q` is NULL; `tcf_bind_filter()`, `tcf_unbind_filter()`, and `tcf_block_q()` callers must check `q` before dereferencing. [F53, F55]
- In `tcf_mirred_init()`, `tcfm_dev` and `tcfm_blockid` are mutually exclusive: setting `parm->ifindex` under `m->tcf_lock` must zero `m->tcfm_blockid` and update `m->tcfm_mac_header_xmit`, whereas setting `TCA_MIRRED_BLOCKID` must call `tcf_mirred_replace_dev(m, NULL)` and set `m->tcfm_mac_header_xmit = false`. `mirred_device_event()` on `NETDEV_UNREGISTER` must only release `m->tcfm_dev_tracker` and clear `m->tcfm_dev` when `tcf_mirred_dev_dereference(m) == dev`, leaving `m->tcfm_blockid` intact. [F60, F61]
- In `act_ct`, `tcf_ct_flow_table_lookup()` must call `nf_conn_act_ct_ext_fill()` and `tcf_ct_flow_ct_ext_ifidx_update()` before `flow_offload_refresh()`; if `IPS_ASSURED_BIT` is unset on `ct->status`, it must still call `flow_offload_refresh()` and return `false`. `tcf_ct_flow_is_outdated()` must require `IPS_HW_OFFLOAD_BIT` and `!NF_FLOW_HW_PENDING` in addition to `IPS_SEEN_REPLY_BIT` and `!NF_FLOW_HW_ESTABLISHED`. [F64, F65, F104]
- Child Qdisc `dequeue()`/`peek()` callbacks (`netem`, `codel`) can drop packets and invoke `qdisc_tree_reduce_backlog()`: `htb_deactivate()` must return early if `!cl->prio_activity`, `htb_lookup_leaf()`/`htb_dequeue_tree()` must handle `hprio->row.rb_node` becoming NULL mid-dequeue (updating `start = next` if an emptied `cl == start`), `hfsc_enqueue()` must increment `sch->q.qlen` and `sch->qstats.backlog` before `init_ed()`, `init_vf()`, or `peek()`, and `hfsc_change_class()`/`hfsc_dequeue()` must re-check `cl->qdisc->q.qlen != 0` after `qdisc_peek_len()`. [F207, F254, F257, F258, F285]

## Synchronization

- Every process-context acquisition of `tc_action.tcfa_lock` (`tcf_lock`) must use `spin_lock_bh()`/`spin_unlock_bh()`. In action `->init()`, `tcf_action_set_ctrlact()` and `rcu_replace_pointer()` must run under `spin_lock_bh(&a->tcfa_lock)`, and `tcf_chain_put_by_act()` must be called after unlocking. `gate_setup_timer()` (`!do_init`) must drop `gact->tcf_lock` around `hrtimer_cancel(&gact->hitimer)`. In `act_mirred.c`, `mirred_list_lock` is outer to `m->tcf_lock`. [F18, F29, F34, F151]
- `offload_action_init()` and `tc_setup_action()` call `act->ops->offload_act_setup()` under `spin_lock_bh(&act->tcfa_lock)`, and `tcf_gate_init()` calls `parse_gate_list()` under `spin_lock_bh(&gact->tcf_lock)`: these paths and their helpers must use `GFP_ATOMIC`, never sleep, and not re-lock `tcfa_lock`. Conversely, `to_ct_params()`, `tcf_tunnel_info()`, and `tcf_police_rate_bytes_ps()` require `tcfa_lock`. [F30, F154, F157]
- Lockless RCU lookups in `idrinfo->action_idr` (`tcf_idr_check_alloc()`) must reject `IS_ERR(p)` and use `refcount_inc_not_zero(&p->tcfa_refcnt)`, paired with `refcount_dec_and_mutex_lock(&p->tcfa_refcnt, &idrinfo->lock)` in `__tcf_action_put()`. Callers already holding `idrinfo->lock` (`tcf_del_walker()`, `tcf_reoffload_del_notify()`) must call `tcf_idr_release_unsafe()` instead of `tcf_idr_release()` or `__tcf_action_put()`. [F25, F160, F161]
- Because `sch_tree_lock(sch)` disables BH and takes a spinlock, `GFP_KERNEL` allocations (`kzalloc`, `qdisc_create_dflt`, `fifo_create_dflt`), `ndo_setup_tc` calls, and `qdisc_put()` / `*_destroy_class()` (which call sleeping `lockdep_unregister_key()`) must occur outside `sch_tree_lock(sch)`. When detaching/replacing a child Qdisc, call `qdisc_purge_queue()` (or `qdisc_replace()`) under `sch_tree_lock(sch)` before unlocking and calling `qdisc_put()`. `qdisc_put()` requires `rtnl_lock`; unlocked callers must use `qdisc_put_unlocked()`. [F220, F221, F223, F338]
- In `sch_qfq`, because `qfq_enqueue()` can replace `cl->agg` via `qfq_change_agg()` (`GFP_ATOMIC`) in softirq, all control/dump accesses to `cl->agg` (`qfq_change_class()`, `qfq_delete_class()`, `qfq_dump_class()`, `qfq_dump_class_stats()`) must hold `sch_tree_lock(sch)`. Timer callbacks (`pie_timer`, `red_adaptative_timer`, `sfq_perturbation`) must hold `rcu_read_lock()` while locking `qdisc_lock(qdisc_root_sleeping(sch))`, and callers under `sch_tree_lock(sch)` must use `timer_delete()` instead of `timer_delete_sync()`. [F222, F340, F345]
- In `sch_direct_xmit()`, drop `qdisc_lock(q)` before `validate_xmit_skb_list()` and `HARD_TX_LOCK()`, and re-acquire it after `HARD_TX_UNLOCK()` before `dev_requeue_skb()`. On `TCQ_F_NOLOCK` Qdiscs: `q->gso_skb` and `q->skb_bad_txq` require `qdisc_lock(q)` (re-checking `skb_peek(&q->gso_skb)` after locking); `dev_reset_queue()` must lock `qdisc->seqlock` before `qdisc_lock(qdisc)`; `qdisc_run_begin()`, `qdisc_run_end()`, and `qdisc_maybe_clear_missed()` must preserve their `smp_mb()`/`smp_mb__after_atomic()` sequences around `__QDISC_STATE_MISSED`. [F210, F211, F212, F214, F350]

## Object Lifetimes

- In action `->init()`, if `tcf_idr_check_alloc()` returns 0 (`ERR_PTR(-EBUSY)` placeholder), error paths before `tcf_idr_create()` succeeds must call `tcf_idr_cleanup(tn, index)`; once `tcf_idr_check_alloc()` returns 1 or `tcf_idr_create()` succeeds, error paths must call `tcf_idr_release(*a, bind)`. In `tcf_action_init()`/`tcf_action_add()`, `tcf_action_offload_add()` must succeed before `tcf_idr_insert_many()`, `tc_action_load_ops()` refs must be released via `module_put()`, and `tcf_action_add()` must call `tca_put_bound_many()`. [F1, F2, F5, F75, F143]
- `tcf_action_destroy()` and `tcf_action_delete()` must set `actions[i] = NULL` as each element is released. `tcf_action_cleanup()` must call `tcf_action_offload_del(p)` before `p->ops->cleanup(p)` and `free_tcf(p)`. When `offload_act_setup` (`bind == true`) takes a ref or allocates memory, it must set `entry->destructor` and `entry->destructor_priv`, and callers must call `tc_cleanup_offload_action()`. [F6, F142, F144]
- In `act_ct`, `flowtable_ct` must set `.get = tcf_ct_nf_get` and `.put = tcf_ct_nf_put` on `ct_ft->ref`; `tcf_ct_flow_table_get()` must use `refcount_inc_not_zero(&ct_ft->ref)`; and `tcf_ct_flow_table_put()` must defer `nf_flow_table_free()` and `kfree(ct_ft)` via `queue_rcu_work(act_ct_wq, &ct_ft->rwork)`. In `tcf_ct_act()`, after `nf_conntrack_confirm(skb)`, re-read `ct = nf_ct_get(skb, &ctinfo)` before `tcf_ct_flow_table_process_conn()`. In `tcf_ctinfo_act()`, call `nf_ct_put(ct)` if and only if `thash != NULL`. [F11, F14, F163, F177]
- In `tcf_mirred_to_dev()`, `tcf_mirred_forward()` consumes `skb_to_send` even on error; when `skb == skb_to_send` (uncloned ingress redirect), `retval` must be `TC_ACT_CONSUMED` and never overwritten with `TC_ACT_SHOT`. In `tcf_ct_act()`, when `tcf_ct_handle_fragments()` returns non-zero or a netfilter hook returns `NF_STOLEN`, return `TC_ACT_CONSUMED` rather than `TC_ACT_SHOT`. Replacing or unregistering `m->tcfm_dev` must call `netdev_put(odev, &m->tcfm_dev_tracker)` and update `m->tcfm_dev`. [F8, F9, F16]
- `qdisc_alloc()` error paths and `__qdisc_destroy()` must call `lockdep_unregister_key(&sch->root_lock_key)`, `bpf_module_put(ops, ops->owner)`, and `netdev_put()`. Qdisc `.destroy` callbacks must synchronously cancel timers/work (`cancel_work_sync()`, `qdisc_watchdog_cancel()`, `timer_delete_sync()`), call `tcf_block_put()` on all filter blocks before freeing classes, and in `ingress_destroy()`/`clsact_destroy()` call `tcf_block_put_ext()` before `tcx_miniq_dec()` and `tcx_entry_free()` (when `!tcx_entry_is_active(entry)`). [F190, F191, F200, F201, F330, F346, F372]

## API Contracts

- `tc_action_ops->init` must validate `parm->action` via `tcf_action_check_ctrlact()` (releasing `goto_ch` via `tcf_chain_put_by_act()` on error or swap), return `ACT_P_CREATED` (`1`) for new actions or `ACT_P_BOUND` (`0`) when binding/replacing, and when `tcf_idr_check_alloc()` finds an existing action (`err > 0`) with `TCA_ACT_FLAGS_BIND` set, return `ACT_P_BOUND` immediately without modifying parameters even if `TCA_ACT_FLAGS_REPLACE` is set. [F3, F43, F73, F86]
- `tc_action_ops.offload_act_setup` must check `bind` before casting `entry_data` (`struct flow_action_entry *` with non-NULL `index_inc` when `bind == true`, vs `struct flow_offload_action *` with NULL `index_inc` when `bind == false`) and reject software-only options (`tcf_ct_helper(act)`, `TCA_MPLS_ACT_DEC_TTL`/`MAC_PUSH`, `continue`/`reclassify`/`pipe` in gact) with `-EOPNOTSUPP`. `tcf_tunnel_info_copy()` must `kmemdup` `sizeof(*tun) + tun->options_len` bytes, and `tcf_ct_flow_table_restore_skb()` must mask `cookie` with `NFCT_PTRMASK`. [F131, F133, F137, F146]
- In `tcf_ct_act()`, pull `nh_ofs` via `skb_pull_rcsum()`, set `tc_skb_cb(skb)->mru = mru` on defrag, and on non-drop exit push `nh_ofs` back and update `qdisc_skb_cb(skb)->pkt_len = skb->len`. `tcf_mirred_to_dev()` clones `skb` unless `skb_at_tc_ingress(skb) && is_redirect && tcf_mirred_can_reinsert(retval)`, calls `nf_reset_ct()`, queues egress-to-ingress via `netif_rx()`, and transmits egress via `tcf_dev_queue_xmit()`. `act_csum` skips GSO packets, validates `[ipl, ihl + jhl]` via `tcf_csum_skb_nextlayer()`, and pushes back pulled VLAN headers. [F35, F62, F88, F119, F172, F176, F178, F180]
- `qdisc_alloc()` and `fifo_create_dflt()` return `ERR_PTR` on failure, whereas `qdisc_create_dflt()` returns `NULL` (classful callers must fall back to `&noop_qdisc` and skip `qdisc_hash_add()`). `qdisc_dequeue_skb_bad_txq()` returns `SKB_XOFF_MAGIC` (`(struct sk_buff *)1UL`) when the queue is stopped; `htb_classify()` returns `HTB_DIRECT` (`(struct htb_class *)-1L`) for direct flows. Array-indexed classful Qdiscs (`prio`, `multiq`, `mq`, `mqprio`, `sfq`, `skbprio`) return 1-based class cookies and must subtract 1 before indexing arrays. [F229, F230, F231, F242, F245, F275]

## Error Handling

- Before jumping to `tcf_idr_release()` on a new action (`ACT_P_CREATED`), `ops->init` must initialize fields torn down by `cleanup` (`hitimer`/`entries` in `tcf_gate_init()`, `tcfm_list` in `tcf_mirred_init()`, `metalist` in `tcf_ife_init()`). Because `qdisc_create()` calls `reset()`/`destroy()` on failed `init()`, `htb_init()`/`hfsc_init_qdisc()` must init watchdogs/work first, `htb_init()` must set `q->offload = true` only after `TC_HTB_CREATE` succeeds, `ingress`/`clsact_destroy()` must check `sch->parent`, and `destroy()` must NULL-check pointers. [F47, F225, F234, F236, F331]
- When `tcf_idr_check_alloc()` finds an `IS_ERR(p)` reservation (`ERR_PTR(-EBUSY)`), it must return `-EAGAIN` immediately rather than looping in-place. In `htb_destroy_class_offload()` and `htb_change_class()`, if `htb_offload()` fails while `!destroying` after `old = htb_graft_helper(dev_queue, NULL)`, restore `old` via `htb_graft_helper(dev_queue, old)`. Classful schedulers must handle empty child Qdiscs after `qdisc_enqueue()` or NULL `dequeue`/`peek` returns via `qdisc_warn_nonwc()`, never `WARN_ON`. [F103, F241, F364]

## External Contracts

- `tc_act_flags_valid()` and `tc_flags_valid()` forbid setting both `SKIP_HW` and `SKIP_SW`. When `tc_act_bind(flags)` is true in `tcf_action_init()`, only classifier-created actions (`tc_act_bind(act->tcfa_flags)`) may inherit `SKIP_SW`/`SKIP_HW`; standalone actions (`!tc_act_bind(act->tcfa_flags)`) must not be mutated and fail with `-EINVAL` on mismatch. Standalone actions with `TCA_ACT_FLAGS_SKIP_SW` must fail if `!tc_act_in_hw(action)` on add, and be deleted via `tcf_reoffload_del_notify()` if `in_hw_count` drops to 0. [F74, F150, F183]

## Known Pitfalls

- Every lookup or walker over `idrinfo->action_idr` (`tcf_idr_search()`, `tcf_dump_walker()`, `tcf_del_walker()`, `tcf_action_reoffload_cb()`) must check `IS_ERR(p)` before dereferencing `p` because concurrent allocations insert `ERR_PTR(-EBUSY)`. In `tcf_action_delete()`, save `a->ops`, `a->idrinfo`, and `a->tcfa_index` into locals before calling `tcf_action_put(a)` and pass the saved values to `tcf_idr_delete_index()`. [F44, F72]
- Packet-inspecting and mangling actions (`tcf_csum_*`, `tcf_ct_flow_table_fill_tuple_ipv4/ipv6`, `tcf_nat_act`) must re-fetch `skb_network_header(skb)`, `ip_hdr(skb)`, or `ipv6_hdr(skb)` after every `pskb_may_pull()`, `pskb_network_may_pull()`, `skb_try_make_writable()`, or `tcf_csum_skb_nextlayer()` call. Ematch callbacks computing offsets from `tcf_get_base_ptr()` must validate `[ptr, ptr + len]` via `tcf_valid_offset(skb, ptr, len)`. [F91, F136]
- In `act_ct.c`, `zones_ht` is keyed by `struct zones_ht_key` (`struct net *net` and `u16 zone`), and `zones_params.key_len` must be `offsetofend(struct zones_ht_key, zone)` rather than `sizeof(struct zones_ht_key)` so trailing alignment padding is not hashed. In `tcf_blockcast_redir()`, lag one iteration using `dev_prev` in `xa_for_each(&block->ports, ...)` so only the final port receives the redirect `m_eaction` while earlier ports mirror. [F49, F116, F174]
- Child Qdiscs (`netem`) can re-enter the parent's `enqueue()` callback during `qdisc_enqueue()`; therefore `hfsc_enqueue()` must check `!cl_in_el_or_vttree(cl)` and `qfq_enqueue()` must check `cl_is_active(cl)` after `qdisc_enqueue()` before inserting `cl` into active trees/lists. In `multiq_tune()`, size the `removed` array for `q->max_bands - qopt->bands` elements because `q->bands` is overwritten before the removal loop. [F206, F315]
