# AMD KFD

This component implements device-level queue scheduling, Memory Queue Descriptor (MQD) management, interrupt processing, HSA event signaling, doorbell mapping, flat memory aperture configuration, and HMM-based Shared Virtual Memory (SVM) page migration for AMD GPUs in KFD.

## Architecture & Data Flow
- Under `dqm_lock(dqm)`, `qpd->evicted` is a nesting counter: `evict_process_queues_cpsch` and `evict_process_queues_nocpsch` only deactivate queues when `qpd->evicted++ == 0`, and `restore_process_queues_cpsch` and `restore_process_queues_nocpsch` only reactivate when `qpd->evicted == 1`. In `nocpsch` evict/restore, every queue in `qpd->queues_list` must have `q->properties.is_evicted` updated before skipping inactive queues, and if `destroy_mqd` or `load_mqd` fails, the loop must record the first error and continue. [F9, F110]
- When creating a queue in `create_queue_nocpsch` or `create_queue_cpsch`, `q->properties.is_evicted` must be initialized to `!!qpd->evicted` under `dqm_lock(dqm)`, even if inactive. Whenever `q->properties.is_active` or `q->gws` changes on an active queue, `dqm->active_queue_count`, `dqm->active_cp_queue_count`, `dqm->gws_queue_count`, and `qpd->mapped_gws_queue` must be updated in lockstep via `increment_queue_count`, `decrement_queue_count`, or `update_queue`. [F60, F63]
- In `update_queue`, `prev_active = q->properties.is_active` must be sampled and the queue unmapped/destroyed on hardware before `mqd_mgr->update_mqd` mutates the MQD and overwrites `q->properties.is_active` in place. Every MQD manager's `restore_mqd` and `restore_mqd_sdma` callback must overwrite the MQD doorbell offset register with `qp->doorbell_off` and set `qp->is_active = 0` after copying `mqd_src`. [F62, F75]
- In `struct kernel_queue`, `queue_size` is in bytes while `pq_kernel_addr` is a `uint32_t *` ring of `queue_size_dwords = queue_size / 4` (max capacity `queue_size_dwords - 1`). `kq_acquire_packet_buffer` and `kq_rollback_packet` keep `pending_wptr` modulo `queue_size_dwords` while incrementing `pending_wptr64` monotonically; on wrap, `kq_acquire_packet_buffer` must verify `packet_size_in_dwords < rptr` before NOP-padding to index 0 (incrementing `wptr64` per NOP), and callers aborting before `kq_submit_packet` must call `kq_rollback_packet`. [F72, F80, F111, F123, F132]
- In `dqm->hiq_sdma_mqd` allocated by `allocate_hiq_sdma_mqd`, `NUM_XCC(dev->xcc_mask)` HIQ MQDs occupy the base region and SDMA MQDs in `allocate_sdma_mqd` start at byte offset `mqd_mgrs[KFD_MQD_TYPE_HIQ]->mqd_size * NUM_XCC(dev->xcc_mask)`. When MES is enabled on GFX11 and GFX12, `allocate_mqd` and `init_mqd` (plus `init_mqd_sdma` on GFX11) must allocate and zero a full `PAGE_SIZE` buffer rather than `sizeof` the MQD struct. [F89, F91]
- On GFX9 (`kfd_mqd_manager_v9.c`), when `cwsr_enabled` is true for a compute queue, each XCC's MQD slot has stride `ALIGN(q->ctl_stack_size, PAGE_SIZE) + ALIGN(sizeof(struct v9_mqd), PAGE_SIZE)` (`mqd_stride_v9`) with `struct v9_mqd` in the first page and the control stack at `(uintptr_t)mqd + PAGE_SIZE`. [F90]
- In `kfd_mqd_manager_v9.c`, `for_each_inst(xcc_id, xcc_mask)` loops must index contiguous MQD buffer offsets by a 0-based counter `inst` incremented each iteration while passing `xcc_id` to KGD callbacks, and `NUM_XCC(mm->dev->xcc_mask)` loops must pass the per-XCC MQD pointer (`base mqd + stride * xcc`) and `xcc` index to helpers (`update_mqd`, `update_cu_mask`, `checkpoint_mqd`, `get_wave_state`) rather than the base `mqd` pointer. [F100, F101]
- In `kfd_process::event_idr`, ID 0 is reserved as `NULL`, IDs `1` through `(p->signal_mapped_size / 8) - 1` (up to `KFD_SIGNAL_EVENT_LIMIT - 1`) are for signal/debug events and index `page_slots(p->signal_page)`, and `[KFD_FIRST_NONSIGNAL_EVENT_ID, KFD_LAST_NONSIGNAL_EVENT_ID]` are for non-signal events. `ev->event_age` starts at 1, `last_event_age == 0` disables age checking in `init_event_waiter`, and `set_event` must wrap `++ev->event_age` to 2 on overflow to 0. [F82, F83]
- Because `dequeue_ih_ring_entry` peeks at `node->ih_fifo` via `kfifo_out_linear_ptr`, `interrupt_wq` must call `kfifo_skip_count(&dev->ih_fifo, dev->kfd->device_info.ih_ring_entry_size)` on every iteration and re-queue `dev->interrupt_work` when breaking after `start_jiffies + HZ`. In `event_interrupt_isr_v9`, `v10`, and `v11`, the KFD VMID bounds check (`vmid < first_vmid_kfd || vmid > last_vmid_kfd`) must be guarded by `!KFD_IRQ_IS_FENCE(client_id, source_id)` so process-close fence interrupts reach `kfd_process_close_interrupt_drain`. [F104, F105]
- In `svm_migrate_copy_to_ram`, `addr` must be initialized from `migrate->start` (not `prange->start << PAGE_SHIFT`) and incremented by `PAGE_SIZE` in the loop header so early `continue` paths still advance it. In `svm_migrate_copy_to_vram` and `svm_migrate_copy_to_ram`, whenever a page is skipped or discontiguous (or `cursor.size` is exhausted), any pending contiguous batch of length `j` at offset `i - j` must be flushed via `svm_migrate_copy_memory_gart` and `j` reset to 0. [F102, F103]

## Synchronization
- Acquiring and releasing a `device_queue_manager` lock must use `dqm_lock` and `dqm_unlock` so `mutex_lock(&dqm->lock_hidden)` is paired with `memalloc_noreclaim_save()` and `memalloc_noreclaim_restore(dqm->saved_flags)`. Callers of `map_queues_cpsch`, `unmap_queues_cpsch`, `execute_queues_cpsch`, `suspend_single_queue`, `resume_single_queue`, `detect_queue_hang`, `reset_hung_queues`, and `destroy_queue_nocpsch_locked` must hold `dqm_lock(dqm)`. [F26, F153]
- Under `dqm_lock(dqm)`, `add_queue_mes`, `remove_queue_mes`, `suspend_all_queues_mes`, `resume_all_queues_mes`, `unmap_queues_cpsch`, and `execute_queues_cpsch` must acquire `adev->reset_domain->sem` via `down_read_trylock` (returning `-EIO` on contention), release it with `up_read(&adev->reset_domain->sem)` on every subsequent return path, and wrap `adev->mes.funcs` calls with `amdgpu_mes_lock(&adev->mes)`. [F1, F28]
- Functions that allocate or free GTT BOs via `amdgpu_amdkfd_alloc_gtt_mem` or `amdgpu_amdkfd_free_gtt_mem` (`mqd_mgr->allocate_mqd`, `mqd_mgr->free_mqd`, and `pdd->proc_ctx_bo` allocation for `add_queue_mes`) must not be called under `dqm_lock(dqm)` or `adev->reset_domain->sem`. In `process_termination_nocpsch` and `process_termination_cpsch`, draining `qpd->queues_list` to call `free_mqd` outside `dqm_lock` must use `while (!list_empty(&qpd->queues_list))` unlinking `list_first_entry` under `dqm_lock` rather than `list_for_each_entry_safe`. [F21, F107]
- `kfd_inc_compute_active`, `kfd_dec_compute_active`, and `mqd_mgr->get_wave_state` (which calls `copy_to_user`, and in `copy_context_work_handler` requires `get_task_mm` + `kthread_use_mm`) must be called outside `dqm_lock(dqm)`. [F151, F158]
- Lock ordering is `p->event_mutex` outer to `dqm_lock(dqm)` inner, so DQM paths such as `destroy_queue_cpsch` must call `dqm_unlock(dqm)` before `kfd_dbg_ev_raise`. When `wait_on_destroy_queue` sleeps on `dqm->destroy_wait`, it must set `q->properties.is_being_destroyed = true` first, release `dqm_lock(dqm)` and `q->process->mutex` before `wait_event_interruptible`, and reacquire `q->process->mutex` before `dqm_lock(dqm)`. [F24, F155]
- Mutations to `p->event_idr` and `p->signal_page` in `kfd_event_create`, `kfd_criu_restore_event`, and `kfd_event_destroy` require `p->event_mutex`, with `ev->lock` and `ev->wq` initialized before `idr_alloc`. In `destroy_event`, every waiter on `ev->wq.head` must have `waiter->event = NULL` set under `ev->lock` before waking `&ev->wq`, and `ev` must be freed via `kfree_rcu(ev, rcu)` after `idr_remove`. Updates to `ev->signaled`, `ev->event_age`, `ev->wq`, and `waiter->activated` / `waiter->event` require `spin_lock(&ev->lock)`, while `test_event_condition` uses `READ_ONCE`. [F18, F33, F34]
- In `kfd_wait_on_events`, `set_current_state(TASK_INTERRUPTIBLE)` must precede `test_event_condition` and `schedule_timeout`; after dropping `p->event_mutex` to sleep, task state must be restored to `TASK_RUNNING` and `p->event_mutex` reacquired before calling `copy_signaled_event_data` (which must re-verify `waiter->event != NULL`) and `free_waiters`. [F35, F169]
- Callers of `svm_migrate_to_vram`, `svm_migrate_ram_to_vram`, and `svm_migrate_vram_to_vram` must hold `mmap_lock`, `svms->lock`, and `prange->migrate_mutex` in that order, while `svm_migrate_copy_memory_gart` holds `adev->mman.gtt_window_lock`. [F40]
- In `svm_migrate_to_ram`, the fault handler must pin `svm_bo->eviction_fence->mm` (`mmget_not_zero`) and `p` (`kfd_lookup_process_by_mm`), skip migration if `READ_ONCE(p->svms.faulting_task) == current`, lock `p->svms.lock` then `prange->migrate_mutex` before rechecking `prange->actual_loc`, and pass `vmf->vma->vm_mm` to `svm_migrate_vram_to_ram`. [F39, F170]

## Object Lifetimes
- `kfd_free_mqd_cp` checks `mqd_mem_obj->gtt_mem`: non-NULL means a BO from `amdgpu_amdkfd_alloc_gtt_mem` + `kzalloc` (freed via `amdgpu_amdkfd_free_gtt_mem` + `kfree`, and callers must `kfree(mqd_mem_obj)` if `amdgpu_amdkfd_alloc_gtt_mem` fails), whereas NULL means a sub-allocation from `kfd_gtt_sa_allocate` (freed via `kfd_gtt_sa_free`, and callers must not `kfree(mqd_mem_obj)` on `kfd_gtt_sa_allocate` failure). MQDs from `allocate_hiq_mqd` or `allocate_sdma_mqd` use `free_mqd_hiq_sdma`, whereas MES-enabled GFX11/GFX12 SDMA MQDs use `allocate_mqd` and `kfd_free_mqd_cp`. [F4, F49, F140]
- Workqueue handlers that look up `struct kfd_process` by PASID (`kfd_signal_event_interrupt`, `kfd_signal_hw_exception_event`, `kfd_signal_poison_consumed_event`, `kfd_dqm_suspend_bad_queue_mes`) must call `kfd_unref_process(p)` on every exit path. In `kfd_signal_reset_event`, iterating `kfd_processes_table` with `hash_for_each_rcu` requires `srcu_read_lock(&kfd_processes_srcu)` outside and `rcu_read_lock()` around `idr_for_each_entry_continue(&p->event_idr, ev, id)`. [F36, F167]
- In `svm_migrate_ram_to_vram` and `svm_migrate_vram_to_ram`, `amdgpu_amdkfd_reserve_mem_limit` must pair with `amdgpu_amdkfd_unreserve_mem_limit`, `svm_range_vram_node_new` must precede reading `prange->offset`, and when `prange->vram_pages` reaches 0 (or `!mpages && !prange->actual_loc`), `prange->actual_loc` must be set to 0 and `svm_range_vram_node_free(prange)` called. [F12, F70]
- In `svm_migrate_vma_to_vram` and `svm_migrate_vma_to_ram`, once `migrate_vma_setup(&migrate)` succeeds with `migrate.cpages > 0`, `migrate_vma_pages`, `svm_migrate_copy_done`, `migrate_vma_finalize`, and `svm_range_dma_unmap_dev` must all run before freeing `buf`; if `svm_migrate_copy_to_vram` or `svm_migrate_copy_to_ram` fails after initializing `migrate->dst`, it must first put every allocated destination page (`svm_migrate_put_vram_page` or `svm_migrate_put_sys_page`) and clear `migrate->dst[i] = 0`. [F14, F15]
- In `svm_migrate_get_vram_page`, `svm_range_bo_ref(prange->svm_bo)` and `page->zone_device_data = prange->svm_bo` must be set before `zone_device_page_init(page)`, and `svm_migrate_page_free` must drop the reference asynchronously via `svm_range_bo_unref_async(svm_bo)`. [F42]

## API Contracts
- `svm_migrate_vma_to_vram` and `svm_migrate_vma_to_ram` return a `long` page count (`>= 0`) or negative errno; callers `svm_migrate_ram_to_vram` and `svm_migrate_vram_to_ram` must store it in `long r` and return `r < 0 ? r : 0`. `svm_migrate_addr_to_pfn` and `svm_migrate_put_vram_page` take a 0-based VRAM byte offset `addr`, whereas `svm_migrate_get_vram_page` takes a host PFN prior to `migrate_pfn` encoding. [F46, F55]
- In `kfd_dqm_evict_pasid_mes` and `kfd_dqm_suspend_bad_queue_mes`, removing active queues on MES must be bracketed by `suspend_all_queues_mes(dqm)` and `resume_all_queues_mes(dqm)`. Under `KFD_SCHED_POLICY_NO_HWS`, `create_queue_nocpsch` and `update_queue` must verify `q->process->mm == current->mm` before passing `current->mm` to `mqd_mgr->load_mqd`, while `restore_process_queues_nocpsch` must use `get_task_mm(pdd->process->lead_thread)` and `mmput(mm)`. [F152, F187]
- Top-half `interrupt_isr` callbacks run in hardirq context under `node->interrupt_lock` and must not sleep or mutate `ih_ring_entry` in place (instead setting `*patched_flag = true` and writing `patched_ihre`). `kfd_signal_event_interrupt(pasid, partial_id, valid_id_bits)` and `lookup_signaled_event_by_partial_id` require `valid_id_bits` to be a bit count and `partial_id` to have upper non-ID bits masked off when `valid_id_bits < 32`. [F56, F164]

## Error Handling
- In `create_queue_cpsch`, if `execute_queues_cpsch` or `add_queue_mes` fails for an active queue, `cleanup_queue` must undo `qpd->queue_count++`, `list_add(&q->list, &qpd->queues_list)`, `increment_queue_count`, `allocate_mqd`, `allocate_doorbell`, and `allocate_sdma_queue` in reverse order without incrementing `dqm->total_queue_count`. [F6]
- In `kfd_criu_restore_event`, `mutex_unlock(&p->event_mutex)` must precede `exit:` (as earlier errors jump to `exit:` unlocked), and `kfree(ev)` at `exit:` must only run when `ret != 0`. Callers of `lookup_event_by_id` must check `ev != NULL` before locking or dereferencing `ev`. When `kfd_wait_on_events` aborts with `-ERESTARTSYS`, `free_waiters` must be called with `undo_auto_reset = true` (`ret == -ERESTARTSYS`), and `*wait_result` must be set to `KFD_IOC_WAIT_RESULT_FAIL` whenever `ret != 0`. [F17, F43, F58]
- `dbgdev_wave_reset_wavefronts` must verify `dev->kfd2kgd->get_atc_vmid_pasid_mapping_info != NULL` and `vmid <= last_vmid_to_scan` before calling `wave_control_execute`. In `kgd2kfd_init_zone_device`, if `devm_memremap_pages` fails, cleanup must check `pgmap->type == MEMORY_DEVICE_PRIVATE` to call `devm_release_mem_region` before resetting `pgmap->type = 0`. [F44, F45]

## External Contracts
- `svm_migrate_to_ram` must return a `vm_fault_t` (`0` or `VM_FAULT_SIGBUS`), translating negative errnos from `svm_migrate_vram_to_ram` or range lookup into `VM_FAULT_SIGBUS`. [F47]
- In `suspend_queues` and `resume_queues`, `q_array_invalidate` sets `KFD_DBG_QUEUE_INVALID_MASK` on all `queue_ids` entries upfront, so `q_array_get_index` must mask off `~KFD_DBG_QUEUE_INVALID_MASK` when matching `queue_id` before clearing `KFD_DBG_QUEUE_INVALID_MASK` on success or setting `KFD_DBG_QUEUE_ERROR_MASK` on failure. [F99]

## Known Pitfalls
- In `qpd->doorbell_bitmap` and `kfd->doorbell_bitmap`, `0` means free and `1` means allocated (and on SOC15 `deallocate_doorbell` must not clear `qpd->doorbell_bitmap` for SDMA/XGMI-SDMA queues), whereas in `dqm->sdma_bitmap`, `dqm->xgmi_sdma_bitmap`, and `dqm->allocated_queues[pipe]`, `1` means free and `0` means allocated. [F87, F88]
- `kfd_get_process_doorbells` must multiply `amdgpu_doorbell_index_on_bar` by `sizeof(uint32_t)` (not `doorbell_size`), while `kfd_get_kernel_doorbell` and `kfd_release_kernel_doorbell` scale the `doorbell_bitmap` bit index `inx` by 2 when indexing `kfd->doorbell_kernel_ptr`. [F125]
- Because `struct kfd_mem_obj.cpu_ptr` is `uint32_t *`, `allocate_sdma_mqd`, `kfd_get_hiq_xcc_mqd`, and `get_xcc_mqd` must cast `cpu_ptr` to an integer or byte pointer before adding byte offsets. When programming `cp_hqd_eop_control` in VI, GFX9, GFX10, GFX11, and GFX12 MQD managers, the log2 EOP ring size field must be clamped with `min(0xA, ...)`. [F92, F127]
- In `set_sched_resources` and `detect_queue_hang`, `cp_queue_bitmap` iteration must skip `mec > 0` and guard `1ull << amdgpu_queue_mask_bit_to_set_resource_bit(...)` with `i >= sizeof(res.queue_mask) * 8`. In `unmap_queues_cpsch`, after `amdkfd_fence_wait_timeout` succeeds, the driver must still check `mqd_mgr->check_preemption_failed` and `sdma_has_hang(dqm)` to detect and reset hung queues. [F98, F149]
- `lookup_signaled_event_by_partial_id` and `kfd_signal_event_interrupt` must check `bits > 31` before `1U << bits` and `id < KFD_SIGNAL_EVENT_LIMIT` before indexing `page_slots(p->signal_page)[id]`. In `create_other_event`, `KFD_LAST_NONSIGNAL_EVENT_ID` (`INT_MAX`) must be cast to `uint32_t` before adding `1` for `idr_alloc`. In `event_interrupt_wq_v9`/`v10`/`v11`, `ih_ring_entry[5] & 0xf` must be cast to `uint64_t` before `<< 32`, and in `svm_migrate_to_ram`, granularity size must use a 64-bit shift (`1UL << prange->granularity`). [F84, F115, F116, F122]
