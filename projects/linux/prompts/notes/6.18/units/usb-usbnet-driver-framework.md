# USB "USBNET" DRIVER FRAMEWORK

The usbnet framework provides generic USB network device infrastructure for USB Ethernet adapters, host-to-host cables, WLAN/WWAN dongles, and smart USB peripherals. It manages `net_device` registration, bulk RX/TX URB queues, optional interrupt status polling, runtime power management, and deferred error recovery, while delegating device-specific initialization and packet framing to minidrivers via `struct driver_info` callbacks.

## Architecture & Data Flow

- In `usbnet_probe()`, after `info->bind()`, `net->mtu` must be clamped to `dev->hard_mtu - net->hard_header_len` if `bind()` lowered `dev->hard_mtu`, and `dev->rx_urb_size` defaults to `dev->hard_mtu` if unset. Minidrivers enabling `dev->can_dma_sg` without `FLAG_SEND_ZLP` or `FLAG_MULTI_PACKET` must set `dev->can_dma_sg = 1` inside `info->bind()` (not later in `reset()` or `open()`) so `dev->padding_pkt` is allocated in `usbnet_probe()`. [F29, F45]
- `build_dma_sg()` must allocate and initialize `num_sgs + 1` scatterlist entries while setting `urb->num_sgs = num_sgs`, reserving one trailing slot so `usbnet_start_xmit()` can append `dev->padding_pkt` when `length % dev->maxpacket == 0`. [F46]
- Whenever `dev->hard_mtu` or `dev->rx_urb_size` may have changed (`usbnet_change_mtu()`, `usbnet_open()` after `info->reset()`, `usbnet_set_link_ksettings_mii()` after `link_reset()`, `__handle_link_change()`, or `usbnet_probe()`), `usbnet_update_max_qlen(dev)` must be called, and it must check `!dev->rx_urb_size || !dev->hard_mtu` before dividing `MAX_QUEUE_MEMORY`. [F43, F80]
- `usbnet_change_mtu()` must reject `new_mtu` with `-EDOM` if `(new_mtu + net->hard_header_len) % dev->maxpacket == 0`, and when `dev->rx_urb_size` tracks `old_hard_mtu` and increases, call `usbnet_pause_rx()`, `usbnet_unlink_rx_urbs()`, and `usbnet_resume_rx()`. [F44]
- `usbnet_probe()` must reject devices where `dev->maxpacket` is 0. In `usbnet_get_endpoints()`, candidate pointers `in`, `out`, and `status` must be reset to `NULL` on each `intf->num_altsetting` iteration, endpoints with `usb_endpoint_maxp(&e->desc) == 0` must be skipped, and in both functions `usb_set_interface()` must be skipped when the target altsetting is 0 and `FLAG_NO_SETINT` is set. [F63, F75, F97]
- Every URB anchored on `dev->deferred` must have `urb->context` pointing to a `struct sk_buff` (and `urb->sg` either `NULL` or a heap-allocated scatterlist), because `usbnet_disconnect()` and `usbnet_resume()` cast `urb->context` unconditionally to `struct sk_buff *` and free it. Broken by: anchoring a control or status URB onto `dev->deferred`. [F87]
- All `EVENT_*` bit numbers on `struct usbnet::flags` must be `<= 31` (`EVENT_UNPLUG` is 31), because `dev->flags` is a single `unsigned long` rather than `DECLARE_BITMAP`. [F90]
- `usbnet_probe()` must leave `net->dev_addr` zeroed before `info->bind()`, evaluate `usbnet_needs_usb_name_format()` immediately after `info->bind()`, and only afterward call `eth_hw_addr_random(net)` if `!is_valid_ether_addr(net->dev_addr)`. [F53]
- Because `rx_complete()` sets `EVENT_RX_KILL` when `dev->pkt_err > 20` within 30 packets (`dev->pkt_cnt`) and `rx_submit()` aborts with `-ENOLINK` while `EVENT_RX_KILL` is set, `usbnet_open()` must reset `pkt_cnt = 0`, `pkt_err = 0`, and `EVENT_RX_KILL`, `usbnet_bh()` must clear `EVENT_RX_KILL`, and on `-ENOLINK` neither `usbnet_bh()` nor `usbnet_deferred_kevent()` may re-queue `dev->bh_work`. [F55, F77]
- In `rx_submit()`, RX SKBs must be allocated with `__netdev_alloc_skb()` when `EVENT_NO_IP_ALIGN` is set in `dev->flags` and `__netdev_alloc_skb_ip_align()` otherwise. [F118]

## Synchronization

- Callers of `__usbnet_queue_skb()` must hold `list->lock` (`dev->rxq.lock` or `dev->txq.lock`) across both `usb_submit_urb()` and `__usbnet_queue_skb()` so concurrent completion (`defer_bh()`) or `unlink_urbs()` cannot race before the SKB is queued as `rx_start` or `tx_start`. In `rx_submit()`, under `dev->rxq.lock`, `!usbnet_going_away(dev)` (and open/running/present/not-halted/not-asleep state) must be verified before `usb_submit_urb()`, and on `0` the SKB must be queued before unlocking. [F14, F48]
- `defer_bh()` acquires `list->lock` (`rxq.lock` or `txq.lock`) and nests `dev->done.lock` inside it, so `defer_bh()` must never be called with `list == &dev->done` and `dev->done.lock` must never be acquired before `rxq.lock` or `txq.lock`. In `rx_complete()`, the previous state returned by `defer_bh()` must be checked for `old_state != unlink_start` before resubmitting `urb` via `rx_submit()`. [F73, F109]
- In `unlink_urbs()`, before dropping `q->lock` to call `usb_unlink_urb(urb)`, the loop must mark `entry->state = unlink_start` and acquire `usb_get_urb(urb)`, and after re-acquiring `q->lock` it must restart `skb_queue_walk(q, skb)` from the head while skipping `unlink_start` entries. [F52]
- `dev->txq.lock` must be held when setting, clearing, or checking `EVENT_DEV_ASLEEP`, and when anchoring or draining `dev->deferred` in `usbnet_start_xmit()`, `usbnet_suspend()`, and `usbnet_resume()`. `usbnet_suspend()` and `usbnet_resume()` gate hardware quiescing/restoration on `!dev->suspend_count++` and `!--dev->suspend_count`; if `usbnet_suspend()` aborts an autosuspend due to non-empty `dev->txq`, it must decrement `dev->suspend_count` under `dev->txq.lock`. [F17, F103]
- To break cyclic rescheduling among `dev->delay`, `dev->bh_work`, and `dev->kevent`, teardown in `usbnet_disconnect()` and `usbnet_probe()` failure paths must call `usbnet_mark_going_away(dev)` (`EVENT_UNPLUG`) before draining work/timers, and `usbnet_stop()` must synchronously drain `delay`, `bh_work`, and `kevent` in two passes. `usbnet_terminate_urbs()` must keep a waiter registered on `dev->wait` until `rxq`, `txq`, and `done` are empty so `usbnet_bh()` suppresses RX refills and TX wakeups. [F18, F19]
- In `usbnet_open()`, `EVENT_DEV_OPEN` must be set and `EVENT_RX_KILL` cleared before scheduling `dev->bh_work` so `rx_submit()` accepts RX URB submissions. [F23]
- `usbnet_link_change()` must never call `netif_carrier_on()` directly; when `link && !need_reset`, it sets `EVENT_LINK_CARRIER_ON` (otherwise clearing it and calling `netif_carrier_off()`) so `__handle_link_change()` enables the carrier serialized with `unlink_urbs()` in `usbnet_deferred_kevent()`, where `test_and_clear_bit(EVENT_LINK_CARRIER_ON, &dev->flags)` and `netif_carrier_on()` must run before checking `netif_carrier_ok()`. [F51, F69]
- Sleeping operations (`usb_clear_halt()`, `driver_info->link_reset()`, `driver_info->set_rx_mode()`, `usb_autopm_get/put_interface()`) must not be called in atomic contexts (`rx_complete()`, `tx_complete()`, `usbnet_set_rx_mode()`, `usbnet_bh()`, `usbnet_start_xmit()`, or `usbnet_device_suggests_idle()`); defer work via `usbnet_defer_kevent()` and use `usb_autopm_*_async()`. [F113, F114]
- `__usbnet_read_cmd()` and `__usbnet_write_cmd()` must allocate buffers with `GFP_NOIO` (not `GFP_KERNEL`), and per-CPU `dev->net->tstats` updates in `usbnet_skb_return()` and `tx_complete()` must use `u64_stats_update_begin_irqsave()`. [F106, F108]

## Object Lifetimes

- `rx_submit()` always consumes its `struct urb *urb` argument (queueing it on `dev->rxq` or calling `usb_free_urb(urb)` on error), so callers must never free `urb`. In `rx_complete()`, `entry->urb` must be set to `NULL` when retaining `urb` for resubmission or local freeing, and set to `urb` (with `state = rx_cleanup` and local `urb = NULL`) only on the `block:` path where `usbnet_bh()` frees it via `usb_free_skb(skb)`. [F1, F49]
- Every TX URB in `usbnet_start_xmit()` acquires `usb_autopm_get_interface_async(dev->intf)` under `dev->txq.lock`, which must be balanced by `usb_autopm_put_interface_async(dev->intf)` in `tx_complete()`, on synchronous submission failure, or in `usbnet_resume()` if deferred submission fails. `dev->deferred` must be drained in `usbnet_resume()` under `dev->txq.lock` before clearing `EVENT_DEV_ASLEEP` (freeing `skb`, `res->sg`, `res`, and the async PM ref on error), and any left at `usbnet_disconnect()` must be freed with their `sg` and `urb->context`. [F8, F57]
- `usbnet_open()` retains its `usb_autopm_get_interface(dev->intf)` reference unless `info->manage_power(dev, 1)` succeeds (if `manage_power` fails after `EVENT_DEV_OPEN`, it sets `EVENT_NO_RUNTIME_PM` and resets `retval = 0`), so `usbnet_stop()` must read `EVENT_NO_RUNTIME_PM` before zeroing `dev->flags`. Similarly, `usbnet_device_suggests_idle()` drops an async PM ref with `test_and_set_bit(EVENT_DEVICE_REPORT_IDLE, &dev->flags)`, which `usbnet_resume()` must restore via `test_and_clear_bit()` and `usb_autopm_get_interface_no_resume()`. [F9, F34, F58]
- In `usbnet_probe()`, if `info->bind()` fails, `info->unbind()` must not be called; failures after `info->bind()` succeeds must unwind `dev->padding_pkt`, `dev->interrupt`, `info->unbind()`, `kevent`/`delay`, and `free_netdev()` in reverse order. [F10]
- In `usbnet_disconnect()`, `usbnet_mark_going_away(dev)` and `unregister_netdev(net)` must run before draining `dev->deferred`, calling `info->unbind()`, freeing `dev->interrupt`, and calling `free_netdev(net)`. Because `init_status()` sets `URB_FREE_BUFFER` on `dev->interrupt`, never pass `dev->interrupt->transfer_buffer` to `kfree()`. [F93, F95]
- `usbnet_status_start()` and `usbnet_status_stop()` manage `dev->interrupt` via `dev->interrupt_count` under `dev->interrupt_mutex`, whereas `usbnet_suspend()` and `usbnet_resume()` must use `__usbnet_status_stop_force()` and `__usbnet_status_start_force()` to preserve `dev->interrupt_count`. [F11]

## API Contracts

- `driver_info->rx_fixup()` uses a boolean return convention (non-zero on success, `0` on failure, never negative errnos). `rx_process()` transfers `skb` ownership to `usbnet_skb_return()` when returning `0`, while `usbnet_bh()` frees `skb` via `usb_free_skb()` whenever `rx_process()` returns non-zero (including when `rx_fixup()` returns `0` or `FLAG_MULTI_PACKET` is set), so `rx_fixup()` must never free the input `skb`. Minidrivers calling `usbnet_skb_return()` directly must either set `skb->protocol` or ensure `skb->len >= ETH_HLEN`. [F3, F24, F66]
- `driver_info->tx_fixup()` must return a valid `struct sk_buff *` or `NULL` (never an `ERR_PTR`) and must free or consume the input `skb` before returning `NULL`. Minidrivers with `FLAG_MULTI_PACKET` must call `usbnet_set_skb_tx_stats(skb, packets, bytes_delta)` in `tx_fixup()` with a signed byte delta rather than the total frame length. [F25, F47]
- `driver_info->check_connect()` must return `0` when connected and a negative errno when disconnected or on error. [F26]
- Suspend, resume, and `reset_resume` callbacks must call `usbnet_read_cmd_nopm()` / `usbnet_write_cmd_nopm()` rather than `usbnet_read_cmd()` / `usbnet_write_cmd()` to avoid runtime PM deadlock. Control transfers in `__usbnet_read_cmd()`, `__usbnet_write_cmd()`, and `usbnet_write_cmd_async()` must use `kmalloc()`/`kmemdup()` buffers; `__usbnet_read_cmd()` returns transferred bytes and leaves trailing `data` bytes unmodified on short reads, while `__usbnet_write_cmd()` requires `size == 0` when `data == NULL`. [F21, F27, F40, F99]
- Callers must verify `dev->interrupt != NULL` before calling `usbnet_status_start()`, and both `usbnet_status_start()` and `usbnet_status_stop()` must only be called from process context because they lock `dev->interrupt_mutex`. [F30, F115]
- `usbnet_defer_kevent()` takes an `EVENT_*` bit index (not `BIT(EVENT_...)`) and indexes `usbnet_event_names[work]`. MII ethtool helpers must check `dev->mii.mdio_read` / `mdio_write` before calling MII core functions, and `dev->rx_speed` / `dev->tx_speed` must be in bps (or `SPEED_UNSET = -1`). [F31, F42, F124]

## Error Handling

- In `usbnet_probe()`, any error check after `info->bind()`, `usbnet_get_endpoints()`, or `init_status()` has set `status = 0` must explicitly assign a negative errno to `status` before jumping to `out3`, `out4`, or `out5`. [F32]
- In `usbnet_write_cmd_async()`, after `urb->transfer_flags |= URB_FREE_BUFFER` is set, any error path calling `kfree(buf)` before `usb_free_urb(urb)` must clear `urb->transfer_flags = 0`. In `usbnet_get_ethernet_addr()`, `tmp` must be initialized to `-1` and non-negative `usb_string()` returns clamped to `-EINVAL` when `ret != 12` or `hex2bin()` fails. [F28, F59]
- On transient USB bus errors (`-EPROTO`, `-ETIME`, `-EILSEQ`), `rx_complete()` and `tx_complete()` must arm `dev->delay` for `THROTTLE_JIFFIES`, and `usbnet_bh()` must not refill RX URBs or wake the TX queue while `timer_pending(&dev->delay)` is true. [F127]

## External Contracts

- `usbnet_skb_return()` must compute `skb->protocol` via `eth_type_trans()` only when `skb->protocol == 0` and must zero `skb->cb` (`sizeof(struct skb_data)`) before passing `skb` to the network stack. In `usbnet_probe()`, `FLAG_WLAN` and `FLAG_WWAN` name checks must remain separate `if` statements after `FLAG_ETHER` so they can override `"eth%d"`. [F50, F71]

## Known Pitfalls

- In `usbnet_probe()`, the `struct usb_interface *` parameter is named `udev` and the `struct usb_device *` local is named `xdev`; interface-level device calls (`pm_runtime_enable()`, `SET_NETDEV_DEV()`, `.driver->name`) must use `udev->dev` (`dev->intf->dev`), not `xdev->dev`. Also, `info->bind()` runs before `register_netdev()` resolves `"%d"` in `net->name` and before `FLAG_ETHER`/`FLAG_WLAN`/`FLAG_WWAN` overwrite `net->name`. [F79, F130]
