# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS

This unit implements core Linux device model subsystems (platform and SoC buses, NUMA node and CPU topology sysfs interfaces, syscore power management, pinctrl binding, MSI helpers, and transport classes), the kobject/kset lifecycle and uevent delivery engine, the sysfs and debugfs virtual filesystems, and the Rust abstractions for devices, buses, fwnode properties, ID tables, devres, and debugfs.

## Architecture & Data Flow

- In `fs/sysfs/group.c`, `__first_visible()` must check both `grp->attrs` and `grp->attrs[0]` (or `bin_attrs` and `bin_attrs[0]`) for non-NULL because groups like `initiators` and `targets` in `drivers/base/node.c` have non-NULL `{ NULL }` arrays. When a group defines both `attrs` and `bin_attrs`, directory visibility is determined solely by `grp->is_visible(kobj, grp->attrs[0], 0)`. In `create_files()`, `mode &= ~SYSFS_GROUP_INVISIBLE` must be applied before testing `if (!mode)` or `WARN(mode & ~(SYSFS_PREALLOC | 0664))`. [F51, F69, F96]
- `struct bin_attribute` must keep `struct attribute attr` at offset 0 because `sysfs_add_bin_file_mode_ns()` passes `&battr->attr` as `priv` to `__kernfs_create_file()`, while `sysfs_kf_bin_*()` cast `of->kn->priv` directly to `const struct bin_attribute *`. In `internal_create_group()` and `sysfs_remove_group()`, `kernfs_remove(kn)` must only be called when `grp->name` is non-NULL because `kn` aliases `kobj->sd` when `grp->name` is NULL. [F98, F118]
- In `__debugfs_create_file()`, `real_fops` may be NULL—setting `inode->i_fop` to `&debugfs_noop_file_operations` rather than a proxy fops table—and `mode` must only specify `S_IFREG`. Every `FULL_PROXY_FUNC` or `SHORT_PROXY_FUNC` callback in `debugfs_full_proxy_file_operations` and `debugfs_full_short_proxy_file_operations` requires `__debugfs_file_get()` to set its corresponding `HAS_*` bit in `fsd->methods`. [F49, F65]
- All pointers in `env->envp[0..env->envp_idx]` must point into `env->buf` in contiguous ascending order starting at `env->envp[0]` (populated via `add_uevent_var()`). `zap_modalias_env()` relies on this layout to compact `env->buf` and adjust subsequent `env->envp[j]` pointers, and its outer loop must only increment `i` when `env->envp[i]` does not match `"MODALIAS="`. [F237, F247]
- In `struct property_entry`, `is_inline` discriminates between `value` (`true`) and `pointer` (`false`), and `length` stores total byte size (`_len_ * sizeof(element)`), not element count. In Rust (`rust/kernel/device/property.rs`), `PropertyInt::read_array_from_fwnode_property` and `FwNode::property_read_array_vec` must check `to_result(ret)?` from `fwnode_property_read_*_array` before transmuting `MaybeUninit<Self>` or calling `val.inc_len(len)`. [F56, F277]
- In `rust/kernel/debugfs/file_ops.rs`, `ReadWriteFile::FILE_OPS` (`writer_open` / `single_open`) must pair with `file_ops::write` (casting `file->private_data` to `seq_file`), whereas `WriteFile::FILE_OPS` (`write_only_open`) must pair with `write_only_write` (casting `file->private_data` to `T`). `FileOps::adapt()` transmutes `&FileOps<T>` to `&FileOps<T::Inner>`, so `Adapter` types must be `#[repr(transparent)]` over `T::Inner`. [F213, F269]
- `RawIdArray<T, N>` and `IdArray<T, U, N>` must be `#[repr(C)]` with `raw_ids` first in `IdArray` and `ids` followed by a zeroed `sentinel` in `RawIdArray`, and `IdTable::as_ptr` must cast `self` (not `self.raw_ids.ids.as_ptr()`) so pointer provenance covers `sentinel`. [F241]

## Synchronization

- In `__debugfs_file_get()`, all fields of a new `struct debugfs_fsdata` (`active_users`, `active_users_drained`, `cancellations`, `cancellations_mtx`) must be initialized before `cmpxchg(&dentry->d_fsdata, NULL, fsd)` (destroying `cancellations_mtx` before `kfree(fsd)` if `cmpxchg` loses). `d_unlinked(dentry)` must be checked after `cmpxchg` and before `refcount_inc_not_zero(&fsd->active_users)`, pairing with `smp_mb()` before `READ_ONCE(dentry->d_fsdata)` in `__debugfs_file_removed()`. [F20, F21]
- In `__debugfs_file_removed()`, `refcount_dec_and_test(&fsd->active_users)` returns `true` when the initial reference was the last; it must return immediately when `true` and enter the `wait_for_completion(&fsd->active_users_drained)` loop only when `false`. Under `fsd->cancellations_mtx`, `__debugfs_file_removed()` must dequeue `fsd->cancellations` via `list_del_init(&c->list)` and call `c->cancel()`, while `debugfs_enter_cancellation()` must check `if (d_unlinked(dentry)) complete(&fsd->active_users_drained);` after unlocking `cancellations_mtx`. [F22, F23, F90]
- In `fs/sysfs/file.c`, `sysfs_file_kobj()` must dereference `kn->__parent` inside an RCU read-side critical section via `rcu_dereference(kn->__parent)->priv`, and `sysfs_file_ops()` must only be called while holding an active reference on `kn`. [F27]
- In `drivers/base/platform.c`, `platform_dma_configure()` must load `dev->driver` once via `READ_ONCE(dev->driver)` and check for non-NULL before casting with `to_platform_driver(drv)` and reading `driver_managed_dma`. `driver_override_show()` must hold `device_lock(dev)` while reading `pdev->driver_override`. [F29, F30]
- In `lib/kobject.c`, `kset_find_obj()` (and any traversal of `kset->list` under `kset->list_lock`) must acquire references via `kobject_get_unless_zero()` into a separate `ret` variable (never returning the `list_for_each_entry` cursor `k` directly). `kobj_kset_leave()` must unlock `kobj->kset->list_lock` before calling `kset_put(kobj->kset)`. [F253, F300, F301]
- `kobject_get_path()` and `fill_kobj_path()` run without a lock preventing concurrent `kobject_rename()` (which requires external caller mutual exclusion); `get_kobj_path_length()` starts at 1 for the NUL byte in the `kzalloc()` buffer, `fill_kobj_path()` must pre-decrement `length` and check `length <= 0` before each backward `memcpy()`, and `kobject_get_path()` must free `path` and retry on error. [F192, F194, F263]
- `kobj_ns_current_may_mount()`, `kobj_ns_grab_current()`, and `kobj_ns_drop()` invoke `kobj_ns_ops_tbl[type]` callbacks under the `kobj_ns_type_lock` spinlock (atomic context; callbacks must not sleep). Conversely, `kobject_uevent()` and `kobject_uevent_env()` allocate with `GFP_KERNEL` and acquire `uevent_sock_mutex`, so they must only be called from sleepable process context. [F302, F303]
- In `rust/kernel/devres.rs`, `Devres<T>`, `Inner<T>`, `devres::register`, and `platform::Driver` require `Send`, and `Devres<T>` must not expose `Revocable<T>` or `revoke*()` publicly. `Devres::devres_callback()` must call `inner.data.revoke()` (waiting for RCU) rather than `revoke_nosync()`. In `<Devres<T> as PinnedDrop>::drop`, if `revoke_nosync()` is `true` and `remove_action()` is `false`, `inner().revoke.complete_all()` must precede `inner().devm.wait_for_completion()`, and both branches must wait on `devm` before `drop_in_place(self.inner.get())`. [F200, F257, F278, F304]

## Object Lifetimes

- In `register_one_node()`, `INIT_LIST_HEAD(&node->access_list)` must precede setting `node_devices[nid]` and `register_node()`. On `device_register()` failure, `put_device()` frees `node` via `node_device_release()`, so `register_one_node()` must clear `node_devices[nid] = NULL` without calling `kfree(node)`. `unregister_node()` must unregister child devices (`node_remove_accesses()` and `node_remove_caches()` via `list_for_each_entry_safe()`) before `device_unregister(&node->dev)`, and `unregister_one_node()` must clear `node_devices[nid]`. [F1, F2, F32, F101]
- `debugfs_start_creating()` pins `debugfs_mount` via `simple_pin_fs()` and locks the parent inode; on error after it succeeds, callers must call `failed_creating(dentry)`, while successful dentries release the pin in `remove_one()`. `full_proxy_release()` must invoke `real_fops->release(inode, file)` unconditionally without gating on `debugfs_file_get()`, and debugfs `.release` callbacks must not assume `inode->i_private` is still valid after `debugfs_remove()`. [F15, F24]
- A `kobject` holds a reference on `kobj->parent` only while `state_in_sysfs` is 1, plus `sysfs_get(kobj->sd)` from `create_dir()` until `__kobject_del()` calls `sysfs_put(sd)`. If `create_dir()` fails in `kobject_add_internal()`, it must call `kobj_kset_leave()`, `kobject_put(parent)`, and clear `kobj->parent = NULL` with `state_in_sysfs == 0`. `__kobject_del()` clears `state_in_sysfs` and `kobj->parent` without dropping `parent`, so `kobject_del()` and `kobject_cleanup()` must cache `parent` and `name` before `t->release(kobj)`, freeing them only after. [F173, F174, F175, F224]
- Early exit from `fwnode_for_each_child_node()`, `fwnode_for_each_available_child_node()`, or `device_for_each_child_node()` requires `fwnode_handle_put(child)`. In Rust (`rust/kernel/device/property.rs`), `Device::fwnode()` must return a borrowed `Option<&FwNode>` (not `FwNode::from_raw`); `FwNode::children()` must pass `ARef::into_raw(prev)` to `fwnode_get_next_child_node()`, wrap `next` in `FwNode::from_raw(next)`, and store `Some(next.clone())` in `prev`; and `FwNodeReferenceArgs::drop` must release non-null `self.0.fwnode` via `FwNode::from_raw`. [F19, F186, F187, F188]
- In `rust/kernel/debugfs.rs`, `Entry<'static>` created by `Entry::dynamic_dir` or `Entry::dynamic_file` must retain `Option<Arc<Entry<'static>>>` in `_parent` so the parent dentry is not recursively removed while child handles exist. `Scope<T>` must initialize `data: T` in pinned memory before `init(&scope.data)` creates debugfs entries, and must declare `_entry: Entry<'static>` before `data: T` so `Entry::drop` calls `debugfs_remove()` before `data` is dropped. [F181, F203]
- In `platform::Adapter`, `probe_callback` stores `Pin<KBox<T>>` via `set_drvdata`, and `remove_callback` must reclaim it once via `drvdata_obtain::<Pin<KBox<T>>>()` before calling `T::unbind(pdev, data.as_ref())` (and `drvdata_obtain`/`drvdata_borrow` must always use the exact type `T` passed to `set_drvdata`). `Devres::access` must verify `self.dev.as_raw() == dev.as_raw()` on the caller's `&'a Device<Bound>` before calling `self.data().access()`. [F190, F276, F280]

## API Contracts

- Once `kobject_init()`, `kobject_init_and_add()`, `platform_device_alloc()`, or `platform_device_register()` has initialized an object, callers must release it via `kobject_put()` or `platform_device_put()` even on registration failure, never `kfree()`. Conversely, when `kset_register()` fails, it frees `k->kobj.name` and sets it to NULL without calling `kobject_put()`, so `kset_create_and_add()` must free the `struct kset` with `kfree()` rather than `kset_unregister()`, and `kset_register()` requires `k->kobj.ktype` to be non-NULL beforehand. [F5, F171, F283, F311]
- `__devm_add_action_or_reset()` and `devm_add_action_or_reset()` call `action(data)` immediately when `__devm_add_action()` fails, so callers must not call `action(data)` again on error; `rust/kernel/devres.rs::register_foreign` relies on `devm_add_action_or_reset` to reconstruct and drop `P::from_foreign` on registration failure. [F18, F185]
- `platform_get_irq*()` functions treat IRQ 0 as invalid (returning `-EINVAL`), return `> 0` on success or negative errno on failure (`-ENXIO` when missing), and `platform_get_irq_optional()` must fall through from non-`-EPROBE_DEFER` errors in `of_irq_get()` to `platform_get_resource()`. `platform_get_resource*()`, `platform_get_mem_or_io()`, and `platform_device_alloc()` return NULL on failure, whereas `devm_platform_get_and_ioremap_resource()`, `devm_platform_ioremap_resource*()`, `platform_device_register_full()`, and `__platform_create_bundle()` return `ERR_PTR()`. [F34, F35, F36, F106]
- `debugfs_file_get()` passes `DBGFS_GET_ALREADY` to `__debugfs_file_get()` (returning `-EINVAL` if `d_fsdata` is unallocated); initial proxy `.open` handlers must pass `DBGFS_GET_REGULAR` or `DBGFS_GET_SHORT` and translate `-EIO` to `-ENOENT`. `debugfs_create_file_unsafe()` replaces `filp->f_op` with `real_fops`, so its callbacks must bracket private-data access with `debugfs_file_get()`/`put()`. `debugfs_enter_cancellation()` requires non-NULL `cancel`, calls `INIT_LIST_HEAD(&cancellation->list)` before early returns, and pairs with `debugfs_leave_cancellation()`. [F13, F44, F48, F161]
- `sysfs_emit()` and `sysfs_emit_at()` require `buf` to be page-aligned (`!offset_in_page(buf)`), and `sysfs_emit_at()` returns the bytes written at `buf + at` (not the new offset). Dynamically allocated sysfs attributes must be initialized with `sysfs_attr_init()` or `sysfs_bin_attr_init()`. Any `bin_attribute` using `sysfs_bin_attr_simple_read()` (`BIN_ATTR_SIMPLE_RO`) must set `.private` and a non-zero `.size` (or `.bin_size`). [F50, F52, F75]

## Error Handling

- In `Devres::new()`, `inner` (`Opaque<Inner<T>>`) must be initialized before `bindings::devm_add_action()`, and if `devm_add_action()` fails, `core::ptr::drop_in_place(inner)` must be called explicitly. In `rust/kernel/platform.rs`, `TryFrom<&device::Device<Ctx>>` for `&platform::Device<Ctx>` must check `bindings::dev_is_platform(dev.as_raw())` before `container_of!`. [F183, F220]

## Known Pitfalls

- CPU topology and NUMA node cpumask/cpulist attributes in `drivers/base/topology.c` and `drivers/base/node.c` must use `BIN_ATTR_RO()` sized with `CPUMAP_FILE_MAX_BYTES` or `CPULIST_FILE_MAX_BYTES`, and their read callbacks must snapshot live cpumasks into a local `cpumask_var_t` before formatting. [F59, F126]
- In `kobject_set_name_vargs()`, `kvasprintf_const()` may return a `.rodata` pointer, so strings containing `'/'` must be duplicated with `kstrdup()` before `strreplace()` mutates `'/'` to `'!'`, and the old `kobj->name` must only be freed after the new allocation succeeds. In `kobject_action_args()`, sysfs buffers are bounded by `buf_end = buf + count - 1` (requiring `count > 0` first and `%.*s` formatting), and after `action_arg_word_end(buf, buf_end, '=')` the caller must check `!next || next > buf_end || *next != '='`. [F228, F236, F249]
- In `rust/kernel/debugfs.rs`, `ScopedDir` wraps its `Entry` in `ManuallyDrop` and `ScopedDir::create_file` forgets child `Entry` handles because the owning `Scope` removes the tree on drop; any root `ScopedDir` from `Dir::scoped_dir` or `ScopedDir::new` must have its `Entry` extracted via `into_entry()` into a `Scope`. In `rust/kernel/devres.rs`, `Devres<T>` must store `Self::devres_callback` in `self.callback` and pass `Some(self.callback)` to both `devm_add_action` and `devm_remove_action_nowarn` so the function pointer address matches. [F182, F287]
