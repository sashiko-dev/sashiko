# NTB DRIVER CORE

The NTB (Non-Transparent Bridge) driver core and ecosystem provide a bus abstraction (`ntb_bus`), an MSI-over-MW library (`ntb_msi`), a queue-pair transport layer (`ntb_transport` and `ntb_transport_bus`), a virtual Ethernet driver (`ntb_netdev`), hardware endpoint/switch drivers (`ntb_hw_epf`, `ntb_hw_idt`), and diagnostic/benchmark modules (`ntb_tool`, `ntb_perf`, `ntb_pingpong`, `ntb_msi_test`).

## Architecture & Data Flow

- `ntb_transport_init_queue()` and `ntb_transport_link_work()` must cap `nt->mw_vec[i].phys_size` at `max_mw_size` (if non-zero), and `ntb_transport_init_queue()` and `ntb_transport_setup_qp_mw()` must partition each MW across `num_qps_mw = qp_count / mw_count + (mw_num < qp_count % mw_count ? 1 : 0)` (`QP_TO_MW`) and subtract `sizeof(struct ntb_rx_info)` at the end of each slice (`qp->remote_rx_info`/`qp->rx_info`), while each frame slot reserves `sizeof(struct ntb_payload_header)` at the end of `rx_max_frame`/`tx_max_frame`. [F51, F68, F97, F110]
- `qp->remote_rx_info` is `NULL` until `ntb_transport_setup_qp_mw()` runs at link-up, so code reachable while link is down (`ntb_qp_link_down_reset()`, `debugfs_read()`) must check `qp->remote_rx_info` or `qp->link_is_up` before dereferencing it or calling `ntb_transport_tx_free_entry()`. Free TX entries are `tail >= head ? tail - head : qp->tx_max_entry + tail - head`, and `remote_rx_info->entry` is initialized/reset to `qp->rx_max_entry - 1` (`rx_max_frame`/`tx_max_frame` capped at `rx_size / 2` and `tx_size / 2` so `max_entry >= 2`). [F41, F67, F98]
- In `ntb_process_rxc()`, test `!(hdr->flags & DESC_DONE_FLAG)` before `hdr->flags & LINK_DOWN_FLAG` because `ntb_send_link_down()` and `ntb_tx_copy_callback()` send link-down frames with `LINK_DOWN_FLAG | DESC_DONE_FLAG`, and cast `qp->rx_pkts` to `u32` when comparing with `hdr->ver`. In `ntb_rx_copy_callback()` and `ntb_tx_copy_callback()`, `DMA_TRANS_READ_FAILED`, `DMA_TRANS_WRITE_FAILED`, and `DMA_TRANS_ABORTED` must `return` immediately after `ntb_memcpy_rx()`/`ntb_memcpy_tx()`, which synchronously re-invoke the callback with `res == NULL`. [F86, F87, F100]
- Recycled `struct ntb_queue_entry` nodes popped from `qp->rx_free_q` or `qp->tx_free_q` in `ntb_transport_rx_enqueue()` and `ntb_transport_tx_enqueue()` must have `flags`, `retries`, `errors`, and `rx_index`/`tx_index` reset to 0. `ntb_transport_link_cleanup()` must zero local scratchpads on link down, and `ntb_transport_link_work()` must write `VERSION` to the peer scratchpad last after `MW0_SZ_*`, `NUM_MWS`, and `NUM_QPS`. [F55, F56]
- When `nt->use_msi` is enabled in `ntb_transport_probe()`, `ntb_msi_init()` and `ntb_msi_setup_mws()` reserve the highest-indexed MW per peer, so `mw_count` and `qp_count` must be decremented by 1 and `BIT_ULL(qp_count)` reserved in `nt->msi_db_mask`. In `drivers/ntb/msi.c`, all devres calls (`ntbm_msi_setup_callback()`, `devm_request_threaded_irq()`, `devm_free_irq()`, `devres_destroy()`) must target `&ntb->dev` (not `&ntb->pdev->dev`) because `ntbm_msi_callback_match()` uses `dev_ntb(dev)`. [F58, F108]
- In `ntb_perf.c`, `perf_init_service()` requires `ntb_peer_mw_count(perf->ntb) >= perf->pcnt`, `PERF_SPAD_CNT(perf->pcnt)` (`3 * (perf->pcnt + 1)`) scratchpads, and `GENMASK_ULL(perf->pcnt, 0)` doorbell bits. `perf_setup_inbuf()` must check `peer->inbuf_size <= size_max` before allocating `peer->inbuf`, and `PERF_CMD_CLEAR` in `perf_service_work()` must reinit `peer->init_comp`, clear `PERF_STS_DONE`, and call `perf_terminate_test()` before freeing buffers. [F65, F76, F77]

## Synchronization

- `ntb_link_event()`, `ntb_db_event()`, and `ntb_msg_event()` invoke `ntb->ctx_ops` callbacks under `spin_lock_irqsave(&ntb->ctx_lock)`. `ntb_ctx_ops` handlers run in atomic context with IRQs disabled and must never sleep, call `ntb_set_ctx()`/`ntb_clear_ctx()`, synchronously flush work, or call sleeping helpers like `ntb_msi_setup_mws()`, `ntbm_msi_request_threaded_irq()`, or `ntb_epf_send_command()`-backed ops (`ntb_link_enable()`, `ntb_link_disable()`, `ntb_mw_set_trans()`, `ntb_mw_clear_trans()`, which take `ndev->cmd_lock` mutex and `usleep_range()`). [F18, F138, F139]
- In `ntb_complete_rxc()`, drain `qp->rx_post_q` in a `while (!list_empty(&qp->rx_post_q))` loop that re-evaluates `list_first_entry()` under `qp->ntb_rx_q_lock` on each iteration, stops at the first entry lacking `DESC_DONE_FLAG`, and copies `entry->cb_data`/`entry->len` into locals, updates `entry->rx_hdr->flags` and `qp->rx_info->entry`, and moves `entry` to `qp->rx_free_q` before dropping `qp->ntb_rx_q_lock` to call `qp->rx_handler()`. [F23, F88]
- In `ntb_transport.c`, CPU copies in `ntb_memcpy_tx()` and `ntb_memcpy_rx()` must execute `wmb()` before setting `DESC_DONE_FLAG` in `hdr->flags` or clearing `entry->rx_hdr->flags` / updating `qp->rx_info->entry`, and `ntb_transport_rxc_db()` must call `ntb_db_read(qp->ndev)` after `ntb_db_clear()` before checking `qp->active`. `ntb_async_rx_submit()` and `ntb_async_tx_submit()` must use `GFP_NOWAIT` and fall back to CPU `memcpy` without sleeping, and QP link works must never acquire `nt->link_event_lock` because `ntb_transport_link_cleanup()` cancels them under it. [F24, F134, F141, F148]
- In `ntb_netdev.c`, `__ntb_netdev_maybe_stop_tx()` must execute `smp_mb()` after `netif_stop_queue(netdev)` and before rechecking `ntb_transport_tx_free_entry(qp)`, paired with `smp_mb()` in `ntb_netdev_tx_handler()` and `ntb_netdev_tx_timer()` between checking `ntb_transport_tx_free_entry(dev->qp)` and `netif_queue_stopped(ndev)`. `ntb_netdev_rx_handler()` and `ntb_netdev_tx_handler()` must use `dev_kfree_skb_any()` and `netif_rx()` because they run in tasklet or DMA completion contexts. [F21, F140]
- In `ntb_hw_idt.c`, `IDT_NT_INDBELLMSK` and `IDT_NT_MSGSTSMSK` updates must use `idt_reg_set_bits()`/`idt_reg_clear_bits()` under `ndev->db_mask_lock` or `ndev->msg_mask_lock`, and `idt_write_temp()` must clear `IDT_TMPALARM_IRQ_MASK` when updating `IDT_SW_TMPALARM`. Indirect register pairs (`IDT_NT_GASAADDR`/`GASADATA`, `IDT_NT_NTMTBLADDR`/`NTMTBLDATA`, `IDT_NT_LUTOFFSET`/`LUT*DATA`) require `spin_lock_irqsave()` (`gasa_lock`, `mtbl_lock`, `lut_lock`), with `gasa_lock` nesting inside `ndev->msg_locks[midx]` and `ndev->hwmon_mtx`. [F62, F150]
- In `ntb_perf.c`, `perf_spad_cmd_send()` and `perf_msg_cmd_send()` sleep and must only run from `perf_service_work()` via `perf_cmd_exec()`, writing data registers before `PERF_SPAD_CMD`/`PERF_MSG_CMD` while receivers read both data registers before clearing status. `perf_terminate_test()` must set `atomic_set(&perf->tsync, -1)` and `wake_up(&perf->threads[tidx].dma_wait)` before `cancel_work_sync()`, and DebugFS access to `perf->tcnt`, `perf->test_peer`, or `perf->threads[]` requires `test_and_set_bit_lock(0, &perf->busy_flag)`. [F32, F152, F153, F154]

## Object Lifetimes

- `ntb_probe()` takes a `get_device(dev)` reference (dropped on probe failure or in `ntb_remove()`), and hardware PCI `.remove` callbacks (`ntb_epf_pci_remove()`, `idt_pci_remove()`) must call `ntb_unregister_device()`—which waits on `ntb->released`—before freeing IRQs (`idt_deinit_isr()` must also call `devm_free_irq()` before `pci_free_irq_vectors()`), disabling PCI, or unmapping BARs. [F2, F17, F19]
- In `ntb_transport_register_client_dev()`, once `dev->release` is set and `dev_set_name()` is called, a `device_register(dev)` failure must call `put_device(dev)` (not `kfree(client_dev)`) and then `ntb_transport_unregister_client_dev(device_name)` to roll back prior iterations; `ntb_netdev` must likewise call `ntb_transport_unregister_client_dev(KBUILD_MODNAME)` if `ntb_transport_register_client()` fails or after `ntb_transport_unregister_client()` on exit. [F3, F4]
- `ntb_transport_free_queue()` must set `qp->active = false`, null `qp->tx_dma_chan`/`rx_dma_chan` before `dma_sync_wait()` and `dmaengine_terminate_all()`, mask `qp_bit`, `tasklet_kill(&qp->rxc_db_work)`, and `cancel_delayed_work_sync(&qp->link_work)` before freeing entries. `ntb_transport_link_cleanup()` and `ntb_transport_free()` must finish `ntb_qp_link_cleanup()` and cancel `qp->link_cleanup` before calling `ntb_free_mw()`, so `ntb_qp_link_down_reset()` does not write to freed `qp->remote_rx_info`. [F25, F52]
- Inbound MW DMA buffers allocated on `&ntb->pdev->dev` (`ntb_set_mw()`, `perf_setup_inbuf()`, `tool_setup_mw()`) must have translations cleared via `ntb_mw_clear_trans()` before `dma_free_coherent()`. `ntb_alloc_mw_buffer()` must use `DMA_ATTR_FORCE_CONTIGUOUS` (for `virt_to_page()` in `ntb_async_rx_submit()`), and `ntb_free_mw()` must pass `mw->alloc_size` and `mw->alloc_addr` (not aligned `mw->buff_size`/`mw->virt_addr`) to `dma_free_coherent()` and zero all size/address fields. [F9, F123, F164]
- In `ntb_async_rx_submit()`, `ntb_async_tx_submit()`, and `perf_copy_chunk()`, `dma_set_unmap()` takes a descriptor reference on `unmap`, so callers must drop their `dmaengine_get_unmap_data()` reference with `dmaengine_unmap_put(unmap)` after `dmaengine_submit()` without duplicating the put on error paths. [F10]
- In `ntb_netdev`, clamp `ndev->mtu <= ntb_transport_max_size(dev->qp) - ETH_HLEN` in probe and `ntb_netdev_change_mtu()` (or oversize frames cause `ntb_process_tx()` to invoke `tx_handler` with `data = NULL`, leaking the `sk_buff`). `ntb_netdev_open()` must enqueue RX buffers and run `timer_setup(&dev->tx_timer, ...)` before `ntb_transport_link_up()`, `ntb_netdev_close()` must call `ntb_transport_link_down()` before `ntb_transport_rx_remove()`, and `ntb_netdev_remove()` must call `unregister_netdev()` before `ntb_transport_free_queue()`. [F22, F119, F162]
- When `ntb_msi_init()` fails, it must `devm_iounmap()` all mapped `peer_mws[i]`, `devm_kfree()` `ntb->msi`, and reset `ntb->msi = NULL`. In `perf_disable_service()`, mask interrupts and call `ntb_clear_ctx(perf->ntb)` before queueing `PERF_CMD_CLEAR` and flushing `peer->service`. Across all NTB modules, unregister clients/drivers before `debugfs_remove_recursive()`, zero `mm_base`/`io_base` and `dbgfs_file` in `tool_free_mw()`/`tool_free_peer_mw()`, and `kfree(buf)` on all early error paths in DebugFS handlers. [F7, F12, F15, F16, F117]

## API Contracts

- NTB clients must call `ntb_set_ctx()` before `ntb_link_enable()` and `ntb_clear_ctx()` on teardown. `ntb_dev_ops_is_valid()` requires port, doorbell-vector, scratchpad, and message callback groups to be all-or-nothing, and requires `mw_set_trans` or `peer_mw_set_trans`; because `ntb_mw_set_trans()` returns 0 when `ops->mw_set_trans` is `NULL`, `ntb_transport_probe()` must check `ndev->ops->mw_set_trans` directly. `ntb_mw_get_align()` requires link up (`-ENOTCONN` otherwise), and `ntb_dev_ops` callbacks must check output pointers for `NULL`. [F38, F39, F66, F116, F159]
- Outbound peer MWs (`ntb_peer_mw_*`) are bounded by `ntb_peer_mw_count(ntb)`, whereas inbound MWs (`ntb_mw_*`) are bounded by `ntb_mw_count(ntb, pidx)`. `ntb_link_is_up()` bitmasks use 0-based `BIT_ULL(pidx)`, whereas port-based doorbell masks (`ntb_pingpong`, `ntb_msi_test`) shift by physical port number from `ntb_port_number()` / `ntb_peer_port_number()`. `db_set`/`clear`/`set_mask`/`clear_mask` take a `u64` bitmask, `peer_db_addr` takes a bit index, and `ntb_spad_*`/`ntb_msg_*` use CPU-endian `u32` values without `cpu_to_le32()`/`le32_to_cpu()`. [F45, F46, F73, F158]
- Because `&ntb->dev` lacks IOMMU/DMA configuration, DMA mask setup and coherent allocations (`dma_alloc_coherent()`, `dma_free_coherent()`) must use `&ntb->pdev->dev`, and DMA engine transfers to outbound peer MWs (`qp->tx_mw`, `peer->outbuf`) must map the physical BAR address on `chan->device->dev` with `dma_map_resource()` (never `virt_to_page()` on `ioremap_wc` pointers). On `ntb_transport_bus`, pass `client_dev->parent` (not `client_dev`) to `dev_ntb()`. [F107, F143, F144]
- `ntb_msi_setup_mws()` and `ntbm_msi_request_threaded_irq()` require `ntb_msi_init()` first and must hold `msi_descs_lock` on `&ntb->pdev->dev`; MSI IRQs freed before `&ntb->dev` teardown must use `ntbm_msi_free_irq()` (not `devm_free_irq()`). `ntb_transport_rx_enqueue()` transfers `sk_buff` ownership only when returning 0; `ntb_transport_tx_enqueue()` requires caller-side serialization per QP and must drop the packet and return 0 when `!qp->link_is_up`; `rx_handler` and `tx_handler` must check for `len < 0` (`-EIO`) and `data == NULL`. [F5, F8, F20, F26, F33, F34]

## Error Handling

- `ntbm_msi_request_threaded_irq()` and `ntbm_msi_request_irq()` return a positive Linux IRQ or negative errno (check `< 0` in a signed `int`). `devm_kzalloc()`/`devm_kcalloc()` return `NULL`, whereas internal helpers (`idt_create_dev()`, `idt_scan_mws()`, `pp_create_data()`, `tool_create_data()`, `perf_create_data()`) return `ERR_PTR(-ENOMEM)` (check `IS_ERR()`). When `ntb_set_mw()` fails in `ntb_transport_link_work()`, `out1` must only call `ntb_free_mw()` and return when `rc < 0` without calling `ntb_link_disable(ndev)`. [F35, F36, F167]
- In `ntb_tool.c`, `tool_peer_mw_read()` and `tool_peer_mw_write()` must check `pos >= outmw->size` before `outmw->size - pos`, access `outmw->io_base` via a `kmalloc()` bounce buffer with `memcpy_fromio()`/`memcpy_toio()` and `copy_to_user()`/`copy_from_user()`, and return `-EFAULT` only when `ret == size` (subtracting `ret` from `size` otherwise). DebugFS write handlers using `sscanf()` must use `memdup_user_nul()` or `copy_from_user()` with explicit NUL termination, never `simple_write_to_buffer()` into an uninitialized buffer. [F37, F44, F75, F165]

## Known Pitfalls

- Use `BIT_ULL()` for 64-bit QP/doorbell masks in `ntb_transport.c`, `upper_32_bits()`/`lower_32_bits()` when splitting `resource_size_t`/`dma_addr_t`, and `(u64)` casts before `<< 32`. In `ntb_transport_probe()`, clamp `qp_count` against `nt->mw_count` (not `mw_count`); in `ntb_transport_create_queue()`, pass `nt->qp_bitmap_free` (not `nt->qp_bitmap`) to `ffs()`; in `ntb_msi_peer_trigger()`, divide `desc->addr_offset` by `sizeof(*ntb->msi->peer_mws[peer])`; in `ntb_netdev.c`, pass `usecs_to_jiffies(tx_time)` to `mod_timer()`. [F48, F84, F85, F94, F95, F96, F103]
- In `ntb_epf_init_pci()`, if `BAR_PEER_SPAD` equals `BAR_CONFIG` (`mx8_map`, `rcar_barno`), compute `ndev->peer_spad_reg` as an offset from `ndev->ctrl_reg` rather than calling `pci_iomap()` twice; in `ntb_epf_send_command()`, sample `timedout` before reading `NTB_EPF_CMD_STATUS` and check `COMMAND_STATUS_OK`/`ERROR` before `timedout`. In `ntb_hw_idt.c`, `idt_scan_mws()` must reset `bar_64bit = false` on disabled BARs and update `bar_64bit` before skipping config-space BARs, and 64-bit direct BARs must program `(bar + 1)->limit`. [F89, F93, F111, F127]
