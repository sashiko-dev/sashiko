# SECURITY SUBSYSTEM

The SECURITY SUBSYSTEM implements the core Linux Security Module (LSM) framework (`security/security.c`, `include/linux/lsm_hooks.h`, `include/linux/lsm_hook_defs.h`, `include/linux/security.h`), dispatching security mediation and lifecycle hooks via static calls and managing composite per-object security blobs. It also provides the LSM userspace syscall interface (`security/lsm_syscalls.c`, `include/uapi/linux/lsm.h`), `securityfs` (`security/inode.c`), common LSM audit helpers (`security/lsm_audit.c`), the device cgroup controller (`security/device_cgroup.c`), the `vm.mmap_min_addr` sysctl (`security/min_addr.c`), and Rust wrappers for Binder LSM hooks and security contexts (`rust/kernel/security.rs`).

## Architecture & Data Flow

- Keep `LSM_HOOK(RET, DEFAULT, NAME, ...)` in `include/linux/lsm_hook_defs.h`, the `security_*()` wrapper in `security/security.c`, both the `CONFIG_SECURITY*` prototype and `#else` stub in `include/linux/security.h`, and every `LSM_HOOK_INIT(NAME, ...)` callback in lockstep with identical return and parameter types under matching Kconfig guards. [F61, F103]
- `lsm_set_blob_size(need, lbs)` aligns `*lbs` up to `sizeof(void *)`, sets `*lbs = offset + *need`, and overwrites `*need` with `offset` (making `needed->lbs_*` a byte offset, not a size); for `lbs_inode`, `lsm_set_blob_sizes()` must first reserve `sizeof(struct rcu_head)` at offset `0` of `blob_sizes.lbs_inode`. [F70]
- In `devcgroup_update_access()`, `DEVCG_ALLOW` rules must be verified against the parent via `may_allow_all()`, `parent_allows_removal()`, or `parent_has_perm()` (where `verify_new_ex()`'s `dev_cgroup` is the parent and `behavior` is `childcg->behavior`), while `DEVCG_DENY` rules must call `propagate_exception()` so online descendants update exceptions and run `revalidate_active_exceptions()`. [F47, F89, F145]
- In `security/device_cgroup.c`, `match_exception()` requires all requested `access` bits (`!(access & ~ex->access)`) and only treats `~0` on `ex` as a wildcard, whereas `match_exception_partial()` matches if any bit overlaps (`access & ex->access`) and treats `~0` on either `ex` or the query as a wildcard. [F85]
- Per-association SCTP hooks (`security_sctp_assoc_request()`, `security_sctp_sk_clone()`, `security_sctp_assoc_established()`) must pass `struct sctp_association *asoc` (not `struct sctp_endpoint *`) to isolate per-association state from the shared `struct sock`. [F59]
- `ordered_lsms` is sized `MAX_LSM_COUNT + 1` and `append_ordered_lsm()` must reject additions at `last_lsm == MAX_LSM_COUNT` to preserve a trailing `NULL` sentinel; in `ordered_lsm_parse()`, `strcmp(lsm->name, name) == 0` must set `found = true` before gating `append_ordered_lsm()` on `lsm->order == LSM_ORDER_MUTABLE`. [F69, F79]
- In `security_add_hooks()`, a new `lsmid` must be recorded in `lsm_idlist[lsm_active_cnt++]` and passed to `lsm_append(lsmid->name, &lsm_names)`, guarding `lsm_append()` (`GFP_KERNEL`) with `slab_is_available()` for `early_security_init()` and deferring early LSM names to `security_init()`. [F54, F123]
- Every `enum lockdown_reason` up to `LOCKDOWN_CONFIDENTIALITY_MAX` must have a matching entry in `lockdown_reasons[]` in `security/security.c`, and every `LSM_ATTR_*` constant in `include/uapi/linux/lsm.h` (except `LSM_ATTR_UNDEF`) must be mapped in `lsm_name_to_attr()`. [F63, F77]
- In `struct common_audit_data`, union `u` must not exceed `2 * sizeof(void *)` bytes (`BUILD_BUG_ON` in `audit_log_lsm_data()`), and its active member must match `a->type`. [F42]

## Synchronization

- In `lsm_static_call_init()`, `__static_call_update()` and `scall->hl = hl` must complete before `static_branch_enable(scall->active)` enables the static key checked by `__CALL_STATIC_VOID` and `__CALL_STATIC_INT`. [F18]
- In `propagate_exception()`, `devcgroup_mutex` must be held and `css_for_each_descendant_pre()` requires `rcu_read_lock()` on every step and normal exit: `!is_devcg_online(devcg)` and `continue` paths must precede `rcu_read_unlock()`, `rcu_read_lock()` must be re-acquired before advancing or exiting, and error returns after `rcu_read_unlock()` must return directly. [F48, F88]
- Modifying a live `dev_cgroup->exceptions` list in `dev_exception_add()`, `dev_exception_rm()`, and `__dev_exception_clean()` must use `list_add_tail_rcu()`, `list_del_rcu()`, and `kfree_rcu(ex, rcu)` for concurrent RCU readers in `devcgroup_legacy_check_permission()` and `devcgroup_seq_show()`. [F22]
- `common_lsm_audit()` allocates with `GFP_ATOMIC`, and neither `common_lsm_audit()`, `dump_common_audit_data()`, `audit_log_lsm_data()`, nor any `pre_audit`/`post_audit` callback may sleep or use `GFP_KERNEL`. [F27]
- In `audit_log_lsm_data()`, logging `dentry->d_name.name` requires `spin_lock(&dentry->d_lock)` (with `d_find_alias_rcu(inode)` and `d_lock` inside `rcu_read_lock()` for `LSM_AUDIT_DATA_INODE`), and lockless `AF_UNIX` `LSM_AUDIT_DATA_NET` logging must load `unix_sk(sk)->addr` via `smp_load_acquire(&u->addr)`. [F25, F26]
- In `securityfs_create_dentry()`, `lookup_noperm()`, `new_inode()` initialization (`i_mode`, `i_private`, `i_op`, `i_fop`, `i_link`, link counts), and `d_instantiate(dentry, inode)` must execute in that order under `inode_lock(dir)`. [F24]
- Callers of `security_inode_killpriv()`, `security_inode_notifysecctx()`, and `security_inode_setsecctx()` must hold `inode_lock()` on the target inode; callers of `security_file_set_fowner()` must hold `file->f_owner.lock`. [F28]

## Object Lifetimes

- `security_inode_free()` runs `inode_free_security` synchronously but defers `inode_free_security_rcu` and `kmem_cache_free(lsm_inode_cache, ...)` of `inode->i_security` via `call_rcu(..., inode_free_by_rcu)`, so state read by `security_inode_permission()` under RCU must only be freed in `inode_free_security_rcu`. [F8]
- In `security_inode_init_security()`, `inode_init_security` hooks claiming a slot via `lsm_get_xattr_slot()` transfer ownership of `kmalloc`-allocated `xattr->value` to `security_inode_init_security()`, which must `kfree()` `new_xattrs[0..xattr_count - 1].value` and `new_xattrs` on all paths. [F12]
- `security_release_secctx()` zeroes `*cp` after `release_secctx`; `security_free_mnt_opts()`, `security_cred_free()`, and `security_bdev_free()` must guard against `NULL` (`*mnt_opts`, `cred->security`, `bdev->bd_security`), and `security_free_mnt_opts()` must set `*mnt_opts = NULL`. [F14, F38]
- `securityfs_create_symlink()` `kstrdup()`s non-`NULL` `target` into `inode->i_link` and must `kfree(link)` if `securityfs_create_dentry()` fails, while `securityfs_free_inode()` must `kfree(inode->i_link)` when `S_ISLNK(inode->i_mode)`; `securityfs_create_dentry()` calls `simple_pin_fs()` only when `parent == NULL` (releasing on error if `pinned`) and `remove_one()` calls `simple_release_fs()` only when `victim->d_parent == victim->d_sb->s_root`. [F2, F55]
- In `dev_exception_add()`, if a matching `dev_exception_item` already exists, its `access` is updated in place and `excopy` must be freed with `kfree(excopy)` and set to `NULL` before `list_add_tail_rcu()`. [F6]
- In `audit_log_lsm_data()` (`LSM_AUDIT_DATA_NET`), `dev_get_by_index(&init_net, a->u.net->netif)` when `netif > 0` must be paired with `dev_put(dev)` right after logging `dev->name`. [F17]
- In `rust/kernel/security.rs`, `SecurityCtx::from_secid()` must zero-initialize `bindings::lsm_context` and check `to_result` on `bindings::security_secid_to_secctx` before constructing `SecurityCtx`, and `SecurityCtx::as_bytes()` must return `&[]` when `self.ctx.context` is null. [F40, F107]

## API Contracts

- Multi-LSM hooks where `0` is a non-default success return value yet all active LSMs must run must use `lsm_for_each_hook()` instead of `call_int_hook()`: `security_fs_context_parse_param()` continues on `0` (setting `rc = 0`) or `-ENOPARAM`; `security_task_prctl()` ignores `-ENOSYS`, records `rc = thisrc`, and breaks only when `thisrc != 0`; `security_inode_init_security()` continues on `0` or `-EOPNOTSUPP` (normalizing `-EOPNOTSUPP` to `0` on return). [F31, F80, F81, F82]
- Cross-process/async hooks (`security_binder_*`, `security_post_notification`, `security_dentry_create_files_as`) must use the explicitly passed `struct cred *` rather than `current_cred()` or `task_struct` credentials; credential-transition hooks (`bprm_creds_for_exec`, `bprm_creds_from_file`, `task_fix_setuid/gid/groups`) must only mutate `@bprm->cred` or `@new`, never `current->cred`. [F143, F144]
- LSM allocators taking `gfp_t` (`security_inode_alloc`, `security_cred_alloc_blank`, `security_prepare_creds`, `security_sk_alloc`, `security_xfrm_policy_alloc`, `security_audit_rule_init`, `lsm_inode/cred/sock_alloc`) must propagate that `gfp_t`, `security_inode_init_security()` and its hooks must use `GFP_NOFS`, and `security_sock_rcv_skb()`, `security_file_send_sigiotask()`, `security_task_free()`, and `security_file_set_fowner()` hooks must not sleep. [F114, F115, F116]
- `vm_enough_memory` hooks (and `cap_vm_enough_memory`) return `0` to grant `CAP_SYS_ADMIN` overcommit and `< 0` to deny, which `security_vm_enough_memory_mm()` and its stub must invert into `1` (`>= 0`) or `0` (`< 0`) for `__vm_enough_memory()`. [F32]
- `security_inode_init_security()` allocates `blob_sizes.lbs_xattr_count + 1` zeroed `new_xattrs` elements, and hooks must claim slots only via `lsm_get_xattr_slot()` up to their `lbs_xattr_count`; `security_dentry_init_security()` sets `*xattr_name` to a static string (not to be freed) and `@lsmctx` to a context freed via `security_release_secctx()`. [F13, F71]
- `security_mmap_file(file, prot, flags)` passes `prot` as `reqprot` first and `mmap_prot(file, prot)` as `prot` second; `security_inode_rename()` with `RENAME_EXCHANGE` calls `inode_rename` twice (reversed `(new_dir, new_dentry, old_dir, old_dentry)` first, then normal order); `security_inode_setxattr()` and `security_inode_removexattr()` run `cap_inode_setxattr()`/`cap_inode_removexattr()` first when `call_int_hook(inode_xattr_skipcap, name)` is `0`. [F44, F45, F91]
- `xfrm_decode_session` hooks must return `0` when `ckall == 0` (`security_skb_classify_flow()` asserts `BUG_ON(rc)`); `file_ioctl`, `file_ioctl_compat`, and `file_fcntl` hooks must never dereference or `copy_from_user()` `@arg`; `securityfs_create_symlink()` with `target == NULL` requires non-`NULL` `iops` implementing `.readlink` and `.get_link`. [F131, F135, F139]
- `ipv4_skb_to_auditdata()` and `ipv6_skb_to_auditdata()` require non-`NULL` `ad->u.net`, treat `proto` as nullable, and return `0` with `sport`/`dport` unset when L4 headers cannot be read; IPv4 must return `0` on non-initial fragments (`ntohs(ih->frag_off) & IP_OFFSET`), and IPv6 must use `ipv6_skip_exthdr()` and `skb_header_pointer()`. [F41, F133]

## Error Handling

- In `include/linux/lsm_hook_defs.h`, any `int`-returning `LSM_HOOK` where `0` means handled or populates an out-parameter must use a negative error sentinel (`-EOPNOTSUPP`, `-ENOPROTOOPT`, `-ENOPARAM`, `-EINVAL`) as `DEFAULT` rather than `0`, or `call_int_hook()` treats `0` as unhandled. [F30]
- In `devcgroup_update_access()`, handling `DEVCG_ALLOW` for `'a'` with a `parent` must back up `devcgroup->exceptions` before `dev_exception_clean()`, restore via `dev_exceptions_move()` if `dev_exceptions_copy()` fails, and set `DEVCG_DEFAULT_ALLOW` only on success; `dev_exceptions_copy()` must `list_del()` and `kfree()` already-copied `dest` entries on `kmemdup()` failure. [F4, F5]
- In `securityfs_create_dentry()`, any failure after `lookup_noperm()` succeeds under `inode_lock(dir)` must jump to `out1` to `dput(dentry)` before unlocking; `securityfs_create_file/dir/symlink()` always return `ERR_PTR(-errno)` on failure (never `NULL`), and `securityfs_remove()` accepts `IS_ERR_OR_NULL(dentry)`. [F3, F39]

## External Contracts

- LSM syscalls and helpers (`sys_lsm_get/set_self_attr`, `sys_lsm_list_modules`, `security_get/setselfattr`, `lsm_fill_user_ctx`, and `get/setselfattr` hooks) must use `u32` (not `size_t`) for buffer sizes; in `security_setselfattr()`, `size` must be in `[sizeof(struct lsm_ctx), PAGE_SIZE]` and satisfy `size >= lctx->len`, `!check_add_overflow(sizeof(*lctx), lctx->ctx_len, &required_len)`, and `lctx->len >= required_len`. [F64, F137]
- In `security_getselfattr()`, non-zero `flags` must equal `LSM_FLAG_SINGLE` with non-`NULL` `uctx` and `lctx.id != LSM_ID_UNDEF`, destination pointers advance by byte offset `(struct lsm_ctx __user *)(base + total)`, and `-E2BIG` sets `left = 0` while adding `entrysize` to `total`; `lsm_fill_user_ctx()` must align size to `sizeof(void *)`, always write `*uctx_len`, and `kzalloc()` padding before `copy_to_user()`. [F66, F67, F140]
- In `sys_lsm_list_modules()`, `flags` must be `0`, byte size `total_size = lsm_active_cnt * sizeof(*ids)` must be written to `*size` before returning `-E2BIG` when `*size < total_size`, and success returns the count `lsm_active_cnt`. [F68]
- 32-bit compat ioctl paths must call `security_file_ioctl_compat()`, and any LSM registering `file_ioctl` must also register `file_ioctl_compat`; `min_addr_sysctl_table` (`vm.mmap_min_addr`) must bind `.data` to `&dac_mmap_min_addr`, require `CAP_SYS_RAWIO` on writes, and call `update_mmap_min_addr()`. [F138, F142]
- In `devcgroup_update_access()`, major/minor fields after `'b'`/`'c'` must be `'*'` (`~0U`) or at most 11 digits (`sizeof(temp) - 1`) followed by `':'`, whitespace, and `'r'`/`'w'`/`'m'`; in `devcgroup_seq_show()`, `DEVCG_DEFAULT_ALLOW` must print only `"a *:* rwm\n"` and omit `devcgroup->exceptions`. [F72, F74]

## Known Pitfalls

- In `set_enabled()`, when `lsm->enabled` is `NULL` or points to `lsm_enabled_true`/`lsm_enabled_false`, reassign `lsm->enabled` to `&lsm_enabled_true` or `&lsm_enabled_false` instead of mutating `*lsm->enabled`; in `kernel_load_data_id_str()`, cast `enum kernel_load_data_id` to `unsigned` before comparing `>= LOADING_MAX_ID`. [F51, F95]
- Loops that unlink or free `struct dev_exception_item` entries (`dev_exception_rm()`, `__dev_exception_clean()`, `dev_exceptions_move()`, `dev_exceptions_copy()` cleanup, `revalidate_active_exceptions()`) must use `_safe` list iterators; in `audit_log_lsm_data()`, abstract `AF_UNIX` addresses (`*p == '\0'`) must use `audit_log_n_hex(ab, p, addr->len - sizeof(short))` rather than `audit_log_untrustedstring()`. [F76, F86]

## Other

- `static_calls_table` in `security/security.c` must keep `__aligned(sizeof(u64))` despite `struct lsm_static_calls_table` being `__packed`, as early LSMs access it before unaligned-access fault handlers are ready. [F122]
