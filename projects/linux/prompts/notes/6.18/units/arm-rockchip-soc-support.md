# ARM/Rockchip SoC support

This unit implements Rockchip SoC infrastructure and peripheral drivers: Clock and Reset Units (CRU), hardware timers, DDR Frequency Interface (DFI) devfreq-event and perf PMU monitors, GPIO/IRQ bank controllers, v1/v2 IOMMU, AXI PCIe Root Complex and Endpoint controllers, RK3x I2C, SARADC (IIO), CPU-to-MCU mailbox, DesignWare MMC platform glue, eFuse/OTP NVMEM providers, and MIPI D-PHY, CSI D-PHY, eMMC, HDMI, and USB2 PHYs.

## Architecture & Data Flow

- `rockchip_clk_init_base()` fills `ctx->clk_data.clks` with `ERR_PTR(-EPROBE_DEFER)` or `ERR_PTR(-ENOENT)`, so callers of `rockchip_clk_get_lookup()` must check `IS_ERR()`, not `NULL`. `rockchip_clk_register_branches()` writes `ctx->clk_data.clks[list->id]` even when `list->id == 0` (overwritten by unexported clocks), so ID `0` must never be a DT clock ID or `GATE_LINK` `.linked_clk_id`. [F27, F59]
- `rockchip_pll_rate_table` arrays must be sorted in descending `.rate` order, end with a zeroed `{ /* sentinel */ }` entry, and have `RK3036_PLL_RATE`/`RK3588_PLL_RATE` dividers that arithmetically evaluate to `.rate` from 24 MHz. For `COMPOSITE_FRACMUX`/`COMPOSITE_FRACMUX_NOGATE`, `child->branch_type` must be `branch_mux` and `child->parent_names` must contain the exact fractional divider `name`. [F53, F55, F60]
- When `ROCKCHIP_SOFTRST_HIWORD_MASK` is set, `rockchip_softrst_assert()`/`deassert()` compute register byte offsets as `(id / 16) * 4`, so LUT macros in `rst-rk3562.c`, `rst-rk3576.c`, and `rst-rk3588.c` must scale any 4-byte-aligned sub-CRU byte offset `B` by `4` (`B * 4 + reg * 16 + bit`, with `bit < 16`). [F63]
- In `rockchip-dfi.c`, `dfi->clk` must be a valid `struct clk *` or `NULL` (never `ERR_PTR`), and `dfi->max_channels <= DMC_MAX_CHANNELS` (4). Per-channel loops must skip `!(dfi->channel_mask & BIT(i))` (with `rockchip_dfi_enable()`/`disable()` breaking after the first channel if `dfi->ddrmon_ctrl_single` is true). Counter deltas (`now - last`) must be truncated to `u32` before widening to 64-bit, and every `dfi->ddr_type` must set `dfi->burst_len` in `rockchip_ddr_perf_init()`. [F35, F65, F77, F78, F84]
- In `gpio-rockchip.c`, `rockchip_get_bank_data()` must normalize all v2 hardware IDs (`GPIO_TYPE_V2`, `GPIO_TYPE_V2_1`, `GPIO_TYPE_V2_2`) to `bank->gpio_type = GPIO_TYPE_V2`. In `rockchip_irq_set_type()`, changing trigger type off `IRQ_TYPE_EDGE_BOTH` must clear `BIT(d->hwirq)` in `int_bothedge` on `GPIO_TYPE_V2` and in `bank->toggle_edge_mode` on `GPIO_TYPE_V1`; on V1 with `toggle_edge_mode`, `rockchip_irq_demux()` must loop re-reading `ext_port` until the pin level stabilizes. [F42, F43, F80]
- In `rockchip-iommu.c`, `iommu->domain` must be initialized to `&rk_identity_domain` only once in `rk_iommu_probe()` (never in `rk_iommu_of_xlate()`, which would clobber a shared domain), and any path calling `to_rk_domain(iommu->domain)` must check `iommu->domain != &rk_identity_domain`. `RK_IOMMU_PGSIZE_BITMAP` (`0x007ff000`) must not include sizes `>= 8 MiB` because `rk_iommu_map()`/`unmap()` index a single 4 MiB second-level page table. [F183, F194, F220]
- In `pcie-rockchip`, set `rockchip->dev` and `rockchip->is_rc` before `rockchip_pcie_parse_dt()`. Only RC paths (`rockchip->is_rc`) may call `pci_host_bridge_from_priv(rockchip)` or dereference `rockchip->reg_base` (and `rockchip_pcie_wr_own_conf()` must use 32-bit RMW for `size < 4`), while EP paths (`!rockchip->is_rc`) use `rockchip->mem_res`. `rockchip_pci_core_rsts` must stay ordered `"pipe"`, `"mgmt"`, `"core"`, `"mgmt-sticky"` for reverse bulk deassert. [F180, F228, F264, F272]
- In `i2c-rk3x.c`, `rk3x_i2c_adapt_div()` stores v1 timing in `REG_CON` (`REG_CON_TUNING_MASK`), so every `REG_CON` write (`rk3x_i2c_start()`, `rk3x_i2c_stop()`, and timeout abort in `rk3x_i2c_xfer_common()`) must preserve `i2c_readl(i2c, REG_CON) & REG_CON_TUNING_MASK`. Combined write-then-read (`REG_CON_MOD_REGISTER_TX`) in `rk3x_i2c_setup()` requires `msgs[0].len < 4`, and RX/TX buffer chunks must respect the 32-byte hardware buffer limit. [F198, F216, F217, F218]
- In `rockchip_rk3328_efuse_read()`, `rockchip_rk3399_efuse_read()`, and `rk3588_otp_read()`, unaligned byte reads must round start offset down and end offset (`offset + bytes`) up to 4-byte word boundaries (`RK3399_NBYTES`/`RK3588_NBYTES`), read `addr_end - addr_start` words into a bounce buffer, and copy from `buf + (offset % 4)`. [F223]
- In `phy-rockchip-inno-usb2.c`, when a `USB2PHY_PORT_OTG` port has `rport->mode` set to `USB_DR_MODE_HOST` or `USB_DR_MODE_UNKNOWN`, `rport->otg_sm_work` and `rport->chg_work` are left uninitialized, so `rockchip_usb2phy_init()`, `exit()`, and `irq()` must check against both modes before touching OTG works/IRQs. Writable `usb2phy_reg` descriptors passed to `property_enable()` must have `bitend <= 15` (`BIT_WRITEABLE_SHIFT` is 16). [F175, F233]

## Synchronization

- In `rockchip_softrst_assert()`/`deassert()`, when `ROCKCHIP_SOFTRST_HIWORD_MASK` is absent, serialize the 32-bit RMW on `softrst->reg_base + (bank * 4)` under `spin_lock_irqsave(&softrst->lock, flags)`. In `rockchip-dfi.c`, hold `dfi->mutex` in `rockchip_dfi_enable()`/`disable()` across `usecount`, `dfi->clk`, and `DDRMON_CTRL` updates, and protect `dfi->total_count` and `dfi->last_perf_count` together with `dfi->count_seqlock`. [F15, F47, F112]
- In `gpio-rockchip.c`, `bank->slock` (`raw_spinlock_t`) protects GPIO registers and `bank->toggle_edge_mode` across process and hardirq context and must never be held across sleeping pinctrl or clock calls (`pinctrl_gpio_direction_input`/`output`, `clk_prepare_enable`). In `rockchip_gpio_probe()`, both `rockchip_gpiolib_register(bank)` and draining `bank->deferred_pins` must execute under `mutex_lock(&bank->deferred_lock)`. [F18, F119]
- In `rockchip-iommu.c`, `rk_domain->dt_lock` nests outside `rk_domain->iommus_lock` and must never be acquired while holding `iommus_lock`. Hold `dt_lock` across `rk_dte_get_page_table()` (which must allocate with `GFP_ATOMIC | rk_ops->gfp_flags`), `rk_iommu_map_iova()`, and `rk_iommu_unmap_iova()`. Hold `iommus_lock` for all `rk_domain->iommus` and `iommu->node` accesses, and in `rk_iommu_zap_iova()`/`rk_iommu_irq()` only touch MMU registers or clocks when `pm_runtime_get_if_in_use(iommu->dev) > 0` (balanced with `clk_bulk_disable()` and `pm_runtime_put()`). [F143, F158, F159, F288]
- In `i2c-rk3x.c`, `rk3x_i2c_xfer_common()` must hold `i2c->lock` across `clk_enable()`, `rk3x_i2c_setup()`, timeout recovery, and `clk_disable()`, dropping it only while waiting for transfer completion and re-acquiring it before inspecting `time_left`/`i2c->error` or exiting. When `polling == true`, call `disable_irq(i2c->irq)` (while `i2c->lock` is unlocked) before `rk3x_i2c_start()` and `rk3x_i2c_wait_xfer_poll()`, and `enable_irq(i2c->irq)` before re-acquiring `i2c->lock`. [F149, F162]
- In `rockchip_saradc.c`, `rockchip_saradc_conversion()` must set `info->last_chan = chan` under `info->lock` before `rockchip_saradc_start()`, and on timeout error the caller must call `rockchip_saradc_power_down(info)` before unlocking `info->lock`. In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_linestate_irq()` must unlock `rport->mutex` before calling `rockchip_usb2phy_sm_work()`. [F150, F167, F214]

## Object Lifetimes

- For `GATE_LINK` clocks, `linked_clk_id` must already be populated in `ctx->clk_data.clks` before `rockchip_clk_register_late_branches()` processes the entry, and late-branch arrays (`rk3588_clk_branches`) and their `parent_names` must not be marked `__initdata`/`__initconst` (`PNAME()`). `rockchip_aux_grf` regmaps must be inserted into `ctx->aux_grf_table` after `rockchip_clk_init()` and before `rockchip_clk_register_branches()` processes any branch with `grf_type != grf_type_sys`. [F4, F6, F110]
- In `gpio-rockchip.c`, `rockchip_get_bank_data()` enables `bank->clk` via unmanaged `clk_prepare_enable()`, so `rockchip_gpio_probe()` error paths and `rockchip_gpio_remove()` must call `clk_disable_unprepare(bank->clk)`. Release every `of_get_parent()`/`of_parse_phandle()` node in `gpio-rockchip.c` and `rockchip-dfi.c` with `of_node_put()`. In `rockchip_ddr_perf_init()`, initialize `count_seqlock`, cpuhp, `rockchip_dfi_enable()`, and `dfi->timer` before `perf_pmu_register()`. [F11, F16, F109]
- In `rockchip-iommu.c`, `rk_iommu_attach_device()` must detach from the old domain via `rk_iommu_identity_attach(&rk_identity_domain, dev)` before adding `iommu->node` to `rk_domain->iommus`, and roll back via `rk_iommu_identity_attach()` if `rk_iommu_enable()` fails. `rk_iommu_of_xlate()` must call `platform_device_put(iommu_dev)`, `rk_iommu_release_device()` must call `device_link_del(data->link)` (`DL_FLAG_STATELESS`), and `rk_iommu_shutdown()` must call `devm_free_irq()` before `pm_runtime_force_suspend()`. [F141, F142, F170, F269]
- In `pcie-rockchip`, `rockchip_pcie_init_port()` powers on all `MAX_LANE_NUM` PHYs and `rockchip_pcie_host_init_port()` powers off unused lanes not in `rockchip->lanes_map`, so `rockchip_pcie_deinit_phys()` must call `phy_power_off()` only on lanes in `lanes_map` while calling `phy_exit()` on all `MAX_LANE_NUM` PHYs. In `i2c-rk3x.c`, `rk3x_i2c_remove()` must call `clk_unprepare()` on both `i2c->pclk` and `i2c->clk` even when `pclk == clk`. [F144, F148]

## API Contracts

- Callers sizing `nr_clks` from `rockchip_clk_find_max_clk_id()` must pass `max_clk_id + 1` to `rockchip_clk_init()`/`rockchip_clk_init_early()`, and `rockchip_clk_find_max_clk_id()` must assign `max = list->child->id` (not `list->id`) when `list->child->id > max`. When initialized via `rockchip_clk_init_early()`, platform probe must call `rockchip_clk_finalize(ctx)`, `of_clk_del_provider(np)`, and `rockchip_clk_of_add_provider(np, ctx)` after registering late branches (`branch_linked_gate` only). [F51, F58, F70, F72]
- In `rockchip_register_softrst_lut()`, when `lookup_table` is non-NULL, `num_regs` must equal `ARRAY_SIZE(lookup_table)` and every entry must be non-negative. In `gpio-rockchip.c`, `rockchip_gpio_readl_bit()` returns `0` or `1` and both `rockchip_gpio_readl_bit()` and `rockchip_gpio_writel_bit()` take a `0..31` bit index, not `BIT(offset)`, and `irq_chip` callbacks must read `((struct irq_chip_generic *)irq_data_get_irq_chip_data(d))->private` to get `struct rockchip_pin_bank *`. [F38, F62, F97]
- In `rockchip-iommu.c`, `rk_table_flush()` takes `count` in 4-byte `u32` entries, whereas `rk_iommu_unmap_iova()` and `rk_iommu_zap_iova()` take `size` in bytes. `rk_iommu_enable_stall()` must return early if `!rk_iommu_is_paging_enabled(iommu)`, and `rk_iommu_attach_device()` must return `0` when `rk_iommu_from_dev(dev)` is `NULL` (for virtual DRM master devices). [F185, F270, F303]
- In `pcie-rockchip-host.c`, `rockchip_pcie_prog_ob_atu()` and `rockchip_pcie_prog_ib_atu()` expect `num_pass_bits` as `bits - 1` (and `prog_ib_atu` shifts `lower_addr` left by 8), whereas `rockchip_pcie_prog_ep_ob_atu()` in `pcie-rockchip-ep.c` takes the full bit count and subtracts 1 internally. In `pcie-rockchip-ep.c`, `rockchip_pcie_ep_set_bar()` must index `BAR_CFG0` for BARs `0..3` and `BAR_CFG1` for `4..5` (`b = bar - BAR_4`), reject odd BARs for 64-bit BARs, and round size with `1ULL << fls64(sz - 1)`. [F179, F227, F305]
- In `rockchip_saradc.c`, `rockchip_saradc_trigger_handler()` must zero-initialize its stack `data` buffer, use a separate counter `j` (not sparse channel bit `i`) to index `data.values[j]`, and call `iio_trigger_notify_done(i_dev->trig)` on all exit paths. In `phy-rockchip-inno-usb2.c`, `phy_set_drvdata()` stores `struct rockchip_usb2phy_port *` on `phy->dev` while `struct rockchip_usb2phy *` is on `phy->dev.parent`. [F245, F266, F297, F298]

## Error Handling

- When jumping to cleanup after a call returning `0`/`NULL` on failure (such as `irq_of_parse_and_map()` in `rk_timer_probe()` or `pci_epc_mem_alloc_addr()` in `rockchip_pcie_ep_init_ob_mem()`), explicitly set a negative errno before `goto`; in `rockchip_usb2phy_otg_port_init()`, do not overwrite `ret` with boolean `property_enabled()` queries. In `rockchip_iommu.c`, if `rk_iommu_map_iova()` hits an already-valid PTE at `pte_count`, roll back prior entries with `rk_iommu_unmap_iova(..., pte_count * SPAGE_SIZE)` under `dt_lock`. [F33, F140, F172, F174]
- In `rockchip_dfi_probe()`, fail if `"rockchip,pmu"` is missing, set `dfi->regmap_pmu` before `soc_init(dfi)`, and register `dfi->edev` before `rockchip_ddr_perf_init()`/`rockchip_dfi_enable()` (checking `cpuhp_setup_state_multi()` with `ret < 0`). In `gpio-rockchip.c`, `bank->db_clk` is `NULL` on `GPIO_TYPE_V1` and `gpio_regs_v1` aliases `dbclk_div_en`/`con` to `port_dr`, so guard debounce accesses with `bank->gpio_type == GPIO_TYPE_V2 && !IS_ERR(bank->db_clk)`. Check optional `vpcie*` regulators and `drv_clk`/`sample_clk` with `!IS_ERR()`. [F34, F36, F37, F39, F177, F190]

## Known Pitfalls

- In `rockchip_clk_register_branches()`, local `grf` is initialized to `ctx->grf` only once before the loop and overwritten whenever a GRF branch has `list->grf_type != grf_type_sys`, so placing a `grf_type_sys` branch after a non-`grf_type_sys` branch without resetting `grf` uses the wrong regmap. Also, `rockchip_clk_register_branch()` and `rockchip_clk_register_frac_branch()` treat `gate_offset < 0` (`-1`) as "no gate", whereas `rockchip_clk_register_factor_branch()` treats `gate_offset == 0` as "no gate". [F52, F61]
- On `GPIO_TYPE_V2` banks, per-pin control registers split pins `0..15` and `16..31` with HIWORD masks and require `rockchip_gpio_writel*()`/`readl*()`, whereas `ext_port`, `int_status`, and `dbclk_div_con` are single 32-bit registers accessed via plain `readl()`/`writel()`. In `rockchip_irq_set_type()`, test `type == IRQ_TYPE_EDGE_BOTH` (exact equality, not `type & IRQ_TYPE_EDGE_BOTH`) when configuring both-edge mode vs single-edge polarity. [F67, F79]
- In `rockchip-iommu.c`, cast `phys_to_virt(pt_phys)` to `u32 *` before adding `rk_iova_pte_index(iova)`, multiply indices by `sizeof(u32)` when adding to `pt_phys` or `dt_dma`, and in `rk_dte_pt_address_v2()` widen `u32 dte` to `u64` before shifting by `DTE_HI_SHIFT2` (32) or `DTE_HI_SHIFT1` (24). In `pcie-rockchip-ep.c`, do not mask unshifted `pci_epf_header` fields with upper-bit masks before shifting, keep `PCIE_ADDR_MASK` 64-bit (`GENMASK_ULL`), and store `ROCKCHIP_PCIE_EP_MSI_CTRL_REG` in `u32`. [F173, F246, F247, F249, F261]
- In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_cfg` arrays must end with `{ .reg = 0 }`, and any valid entry with `.reg == 0` (as in `rk3576_phy_cfgs` and `rk3588_phy_cfgs`) must be at index `0` because `rockchip_usb2phy_probe()` uses a `do { ... } while (phy_cfgs[index].reg)` loop. Across 32-bit/64-bit shared drivers (`gpio-rockchip.c`, `phy-rockchip-inno-hdmi.c`, `phy-rockchip-inno-dsidphy.c`), use `u64` casts and `DIV_ROUND_CLOSEST_ULL()`/`do_div()`/`div_u64()` instead of 32-bit `unsigned long` products or raw 64-bit `/`. [F89, F232, F256, F257]
