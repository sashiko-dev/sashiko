# SOUND - SOC LAYER / DYNAMIC AUDIO POWER MANAGEMENT (ASoC)

This unit implements core ASoC card, AC'97, ACPI, and SoundWire machine utilities (`sdw_utils`), along with platform, DAI, codec, and crossbar drivers for MediaTek MT8365, Freescale MXS, Renesas SuperH, Allwinner sunxi, and NVIDIA Tegra (Tegra20/30/186/210/234/264 AHUB and audio processing engines).

## Architecture & Data Flow
- In Tegra runtime PM, volatile RAM/control registers are not restored by `regcache_sync()`: `tegra210_adx_runtime_resume()` and `tegra210_amx_runtime_resume()` must call `write_map_ram()` after sync; `tegra210_mvc_runtime_suspend()`/`resume()` must save `TEGRA210_MVC_CTRL` before cache-only and rewrite `mvc->ctrl_value` plus `TEGRA210_MVC_VOLUME_SWITCH_TRIGGER` after sync; `tegra186_asrc_runtime_resume()` must write `GLOBAL_SCRATCH_ADDR`/`GLOBAL_ENB` before sync and restore software-ratio `int_part`/`frac_part` after sync. [F176, F178, F297, F357]
- In `tegra210_ope_runtime_suspend()`/`resume()`, `ope->regmap`, `peq_regmap`, and `mbdrc_regmap` must transition cache-only/dirty/synced together, calling `tegra210_peq_save()` before cache-only and `tegra210_peq_restore()` after `regcache_sync()`. All Tegra AHUB and child drivers must use normal `SYSTEM_SLEEP_PM_OPS` rather than late system sleep ops. [F305, F344]
- Readable hardware FIFO and auto-incrementing RAM data registers in Tegra20/30/210 (`TEGRA20_*_FIFO*`, `CHANNEL_*FIFO`, `TEGRA210_*_RAM_*DATA`) must be marked both `.volatile_reg` and `.precious_reg` in `regmap_config`. Sequential RAM helpers (`tegra210_*_read_ram`/`write_ram`, `write_map_ram`) must write `*_ADDR_INIT_EN | *_SEQ_ACCESS_EN` to `*_RAM_CTRL` once and loop over the fixed `*_RAM_DATA` address. [F246, F330, F361]
- Regmap offset normalization in Tegra: `tegra186_asrc_wr_reg`/`rd_reg`/`volatile_reg` must only apply `reg %= TEGRA186_ASRC_STREAM_STRIDE` when `reg < TEGRA186_ASRC_STREAM_LIMIT` (`0x2f0`); `tegra210_mixer_wr_reg`/`rd_reg`/`volatile_reg` must check `reg < TEGRA210_MIXER_RX_LIMIT` before `reg < TEGRA210_MIXER_TX_LIMIT` (which adds `TEGRA210_MIXER_TX1_ENABLE`); `tegra210_mbdrc_wr_reg`/`rd_reg`/`volatile_reg`/`precious_reg` must reduce `reg >= TEGRA210_MBDRC_IIR_CFG` modulo `TEGRA210_MBDRC_FILTER_PARAM_STRIDE * TEGRA210_MBDRC_FILTER_COUNT` before `switch (reg)`. [F210, F327, F328]
- Fixed DAI array layouts in Tegra210/186: `tegra186_asrc_out_hw_params()` indexes `asrc->lane[]` (`TEGRA186_ASRC_STREAM_MAX = 6`) via `dai->id - 7` (6 `OUT_DAI`s after 7 `IN_DAI`s); `tegra210_adx_out_hw_params()` uses `dai->id - 1` (`IN_DAI` at index 0); `tegra210_amx_dais` places 4 `IN_DAI`s at `0..3` and `OUT_DAI` at `TEGRA_AMX_OUT_DAI_ID` (`4`); `tegra210_mixer_dais` places `TEGRA210_MIXER_RX_MAX` (`10`) `IN_DAI`s at `0..9` before `OUT_DAI`s. [F189, F195, F317, F318]
- In `tegra186_dspk_hw_params()`, `tegra_admaif_hw_params()`, and `tegra210_adx_set_audio_cif()`, `cif_conf.client_bits` must match `cif_conf.audio_bits` (including `TEGRA_ACIF_BITS_16` for `S16_LE`). On 32-channel Tegra264 variants (`max_stream_ch == TEGRA264_ADMAIF_MAX_CHANNEL` or `soc_data->max_ch == 32`), ADMAIF, ADX, I2S, and AMX must call `tegra264_set_cif()` instead of `tegra_set_cif()`, and `tegra210_i2s`/`tegra210_amx` must add `soc_data->tx_offset`, `i2s_ctrl_offset`, or `reg_offset` to shifted registers. [F181, F239, F362]
- In `tegra_ahub_put_value_enum()`, selecting a crossbar RX mux input must iterate over all `ahub->soc_data->reg_count` (`<= TEGRA_XBAR_UPDATE_MAX_REG`) parts, setting `update[i].val = reg_val` for `i == reg_idx` and `0` for all other parts via `snd_soc_dapm_mux_update_power()`. `MUX_VALUE(npart, nbit)` uses 1-based bit positions (`1 + nbit + npart * 32`, `0` = `"None"`), and `tegra*_ahub_mux_values` must match `tegra*_ahub_mux_texts` in length and order. [F310, F312, F313, F314]
- Whenever `TEGRA186_ASRC_RATIO_INT_PART` or `FRAC_PART` is written for a `TEGRA186_ASRC_RATIO_SOURCE_SW` lane, `tegra186_asrc_lock_stream(asrc, id)` must be called afterward; `tegra186_asrc_put_ratio_int()`/`frac()` must return `-EINVAL` when `ratio_source == TEGRA186_ASRC_RATIO_SOURCE_ARAD`. [F177, F179]
- In `tegra210_mvc.c`, `tegra210_mvc_put_curve_type()` must verify `TEGRA210_MVC_EN` is clear and call `tegra210_mvc_reset_vol_settings()`. `tegra210_mvc_update_vol()` and `tegra210_mvc_update_mute()` must poll `tegra210_mvc_volume_switch_timeout()` before mutating state and set `TEGRA210_MVC_VOLUME_SWITCH_TRIGGER` in `TEGRA210_MVC_SWITCH` afterward; when `!per_ch_enable`, `tegra210_mvc_update_vol()` must clear `TEGRA210_MVC_PER_CHAN_CTRL_EN` and propagate `mvc->volume[0]` across `mvc->volume[1..TEGRA210_MVC_MAX_CHAN_COUNT-1]`. [F300, F301, F302]
- In MT8365 backend DAIs (`mt8365_dai_int_adda_prepare`, `mt8365_dai_i2s_prepare`, `mt8365_afe_hw_gain1_prepare`), `be->prepared[substream->stream]` must guard enabling refcounted clocks/blocks and be cleared in `.shutdown`. In `struct mt8365_afe_private`, `be_data` is indexed by `dai_id - MT8365_AFE_BACKEND_BASE`, whereas `dai_priv` and `dai_on` use unshifted `dai->id`, and every DAI using `mt8365_afe_i2s_ops` or `2nd_i2s_ops` must have a `struct mtk_afe_i2s_priv` at `afe_priv->dai_priv[dai->id]`. [F10, F61, F97]
- In `sun8i-codec.c`, `clk_set_rate_exclusive()` and `scodec->sysclk_refcnt++` run only when `aif->open_streams == 0` in `sun8i_codec_hw_params()`, and `clk_rate_exclusive_put()`, `sysclk_refcnt--`, and zeroing `lrck_div_order`/`sample_rate` run only when `open_streams == BIT(substream->stream)` in `sun8i_codec_hw_free()`. `sun8i_codec_update_sample_rate()` must run whenever `sample_rate` or `active_streams` changes, and `AIF2`/`AIF3` dividers are written to `SUN8I_AIF_CLK_CTRL(AIF2)` after verifying any open partner stream matches. [F184, F185, F206]

## Synchronization
- In `sound/soc/mediatek/mt8365/`, updates to `afe_priv->top_cg_ref_cnt`, `afe_on_ref_cnt`, `adda_afe_on_ref_cnt` (`mt8365_dai_enable/disable_adda_on()`), and `i2s_data->i2s_out_on_ref_cnt` (`mt8365_afe_set_i2s_out_enable()`, required for both `MT8365_AFE_IO_I2S` with `adda_link` and `MT8365_AFE_IO_INT_ADDA` playback) must hold `spin_lock_irqsave(&afe_priv->afe_ctrl_lock, flags)`. By contrast, `mt8365_afe_enable/disable_apll_tuner_cfg()` acquire `afe_priv->afe_clk_mutex` and must only run in sleepable context outside `afe_ctrl_lock`. [F50, F51, F125, F126]
- `mxs_saif_trigger()` runs in atomic trigger context and must only call non-sleeping `clk_enable()`, `clk_disable()`, and `udelay()`. `tegra_admaif_stop()` (from `.trigger`) must use `regmap_read_poll_timeout_atomic()` on volatile `STATUS`/`SOFT_RESET` registers, whereas process-context helpers (`tegra210_adx_startup`, `tegra210_i2s_sw_reset`, `tegra210_i2s_init`, `tegra210_mixer_write_ram`/`configure_gain`, `tegra210_mvc_volume_switch_timeout`, `tegra210_sfc_soft_reset`) sleep via `regmap_read_poll_timeout()` and must not run in `.trigger`. [F127, F244, F250, F364]
- Probe ordering: `mt8365_afe_pcm_dev_probe()` must initialize `afe->regmap`, `memif`, and `irqs[].irq_data` before `devm_request_irq()`; `sun8i_codec_enable_jack_detect()` must set `scodec->jack` and `SUN8I_HMIC_*` registers before `devm_request_threaded_irq()` (and `jack_irq()`/`jack_work()` must hold `scodec->jack_mutex`); `tegra30_ahub_probe()` must initialize `ahub` and `pm_runtime_enable()` before `of_platform_populate()`; `tegra210_ope_probe()` and `amx_platform_probe()` must initialize regmaps/`map` before registering components. [F19, F156, F252, F277, F279, F281]
- In `soc-card.c`, `jack_new()` must initialize `jack->mutex`, `card`, `pins`, `jack_zones`, and `notifier` before `snd_jack_new()` or `snd_soc_jack_add_pins()`, and `snd_soc_card_get_kcontrol()` must return `NULL` if `!name` and use `snd_ctl_find_id_mixer(soc_card->snd_card, name)` rather than walking `controls` unlocked. In `sdw_utils`, DAI lookups before `snd_soc_register_card()` (e.g., `is_sdca_endpoint_present()`) must call `snd_soc_find_dai_with_mutex()`, whereas lookups inside `.rtd_init` callbacks must call `snd_soc_find_dai()` (`client_mutex` is already held). [F27, F28, F133, F135]

## Object Lifetimes
- Reverse-order teardown: `snd_soc_free_ac97_component()` must call `snd_soc_ac97_free_gpio(ac97)` before `device_del(&ac97->dev)`, clear `ac97->bus = NULL`, and call `put_device(&ac97->dev)`. `sun8i_codec_disable_jack_detect()` must call `devm_free_irq()` before `cancel_delayed_work_sync(&scodec->jack_work)` before clearing `scodec->jack`; `siu_pcm_free()` must `cancel_work_sync()` on `capture.work` and `playback.work` before `siu_free_port()`. `tegra20_ac97`, `tegra20_i2s`, and `tegra30_i2s` must unregister the PCM platform before unregistering the component. [F2, F14, F152, F154, F271]
- Clock/reset sequencing: `mt8365_afe_disable_main_clk()` and `mt8365_afe_disable_apll_associated_cfg()` must tear down clocks, top CGs, and AFE/tuner enables in exact reverse order of enable. `tegra20_i2s_runtime_resume()`, `tegra20_spdif_runtime_resume()`, and `tegra30_ahub_runtime_resume()` must assert reset, enable clocks, wait `usleep_range(10, 100)`, and deassert reset before leaving cache-only mode and calling `regcache_sync()`. `sun4i_i2s_runtime_resume()`/`suspend()` must keep `i2s->bus_clk` enabled across regcache sync and `SUN4I_I2S_CTRL_REG` updates. [F8, F9, F148, F231, F352]
- Resource pairing: `rt711_add_codec_device_props()`, `rt_sdca_jack_add_codec_device_props()`, and `rt_amp_add_device_props()` must call `fwnode_handle_put(fwnode)` after `device_add_software_node()`, and their `.init` callbacks must run before `snd_soc_register_card()` and pair with `.exit` via `asoc_sdw_mc_dailink_exit_loop()`. Every `device_node *` from `of_parse_phandle()`, `of_get_child_by_name()`, or `of_graph_get_endpoint_by_regs()` must be released with `of_node_put()`, and `snd_soc_acpi_find_package()` must `kfree(buffer.pointer)` on `AE_OK`. [F6, F16, F113, F118, F275]

## API Contracts
- ALSA `snd_kcontrol` contracts in Tegra and sunxi: custom `.put` callbacks must return `1` if changed, `0` if unchanged, or negative errno on error. `SOC_ENUM_EXT`/`NV_SOC_ENUM_EXT` callbacks must use `ucontrol->value.enumerated.item[0]` (`struct soc_enum *`), `SOC_SINGLE_EXT` must use `ucontrol->value.integer.value[0]` (`struct soc_mixer_control *`), and `SOC_SINGLE_EXT_FRAC` must cast `private_value` to `struct soc_mreg_control *`. `TEGRA_SOC_BYTES_EXT` with `tegra210_peq_param_info()` uses `integer.value[]`, while `tegra210_mbdrc_param_info()` uses `bytes.data`. [F159, F161, F226, F284]
- In `tegra210_adx` and `tegra210_amx`, `map` is allocated as `ram_depth` `u32` words for `write_map_ram()` but cast to `unsigned char *` in `get_byte_map`/`put_byte_map` (requiring `reg < soc_data->ram_depth * 4` and `reg / 32 < soc_data->byte_mask_size`). Because control value `256` (disabled) does not fit in `unsigned char`, `put` must store `value % 256` and clear bit `reg % 32` in `byte_mask[reg / 32]`, and `get` must return `256` when that bit is clear. [F194, F224, F315, F370]
- Callers of `tegra_set_cif()` and `tegra264_set_cif()` must zero-initialize `struct tegra_cif_conf` and pass 1-based channel counts (`>= 1`) in `audio_ch` and `client_ch`; `tegra30_ahub_set_cif()` and `tegra124_ahub_set_cif()` likewise require 1-based `audio_channels` and `client_channels`. `snd_dmaengine_dai_dma_data.addr` in `sun4i-*`, `tegra20_*`, `tegra210_admaif`, and `*fiforeg` in `tegra30_ahub_allocate_rx_fifo`/`tx_fifo` (`ahub->apbif_addr`) must be computed from the physical `struct resource` start (`res->start`), never from the ioremapped `void __iomem *`. [F254, F288, F363, F371]
- SoundWire (`sdw_utils`) and ACPI contracts: machine drivers using `sdw_utils` must store `struct asoc_sdw_mc_private *` in `card->drvdata`, initialize `ctx->codec_info_list_count`, and call `asoc_sdw_mc_dailink_exit_loop(card)` on error/remove to reset `rtd_init_done` in `codec_info_list[]`; multi-amp `.rtd_init` callbacks (`asoc_sdw_cs_spk_rtd_init`, `ti_spk_rtd_init`, `rt_amp_spk_rtd_init`) must loop over `for_each_rtd_codec_dais(rtd, i, codec_dai)`. `struct snd_soc_acpi_mach` tables using `comp_ids` must be writable and end with a zeroed sentinel. [F45, F47, F67, F78, F102]

## Error Handling
- Signed return checks: `platform_get_irq()`, `mt8365_afe_fs_timing()`, `sun4i_codec_get_hw_rate()` (`0` is valid for 48/44.1 kHz, unlike `sun4i_codec_get_mod_freq()`), and divider/format helpers in `sun4i-i2s.c` and `sun8i-codec.c` return `< 0` on error, requiring signed `int` variables. `tegra210_i2s.client_sample_format` must be initialized to `-EINVAL` and checked with `>= 0` (`0` is `S8`). `is_sdca_endpoint_present()` returns `1`, `0`, or `< 0`, so callers must check `ret < 0` before `!ret`. [F30, F31, F34, F43, F171, F172, F236, F286]
- Cleanup and pointer checks: in `tegra210_mvc_update_vol()`, `tegra210_mvc_update_mute()`, and `tegra210_mixer_configure_gain()`, every exit path after `pm_runtime_get_sync(cmpnt->dev)` (including timeouts and unchanged-volume checks) must jump to the `pm_runtime_put(cmpnt->dev)` label. `snd_soc_alloc_ac97_component()` and `snd_soc_new_ac97_component()` return `ERR_PTR` (never `NULL`), and post-allocation cleanup must use `put_device(&ac97->dev)` rather than `kfree()`. [F36, F276]

## Known Pitfalls
- In `sun4i-codec.c`, `sun50i-codec-analog.c`, `sun8i-codec-analog.c`, and `sun8i-codec.c`, single-bit macros (`SUN4I_CODEC_DAC_FIFOC_*`, `SUN50I_ADDA_*`, `SUN8I_ADDA_*`, `SUN8I_HMIC_CTRL1_*`) are unshifted bit indices and must be wrapped in `BIT()`. In `tegra210_mbdrc_hw_params()`, multi-bit mode fields with a zero-valued constant (`TEGRA210_MBDRC_CFG_MBDRC_MODE_BYPASS = 0`) must be masked with `MODE_MASK` and compared with `==` (never `&`). In `tegra210_mbdrc_vol_get()` and `tegra210_peq_ram_get()`, 32-bit values must be stored in signed `int`/`s32` to sign-extend. [F174, F325, F334, F335]
- Indexing conventions: in `tegra210_admaif.c`, `CH_REG`, `CH_TX_REG`, `CH_RX_REG`, `NV_SOC_ENUM_EXT`, `admaif->mono_to_stereo`, and `stereo_to_mono` take 0-based channel indices (`0..num_ch - 1`), whereas `ADMAIF_REG_DEFAULTS(id, chip)` and `TEGRA_ADMAIF_CIF_CTRL(reg)` take 1-based channel numbers (`1..num_ch`). In `tegra186_dspk.c`, `dspk->ch_sel` is 0-based, so `tegra186_dspk_hw_params()` must write `(dspk->ch_sel + 1) << CH_SEL_SHIFT` and clamp `dspk->rx_fifo_th` to `(TEGRA186_DSPK_RX_FIFO_DEPTH / cif_conf.audio_ch) - 1`. [F164, F167, F191, F196]
