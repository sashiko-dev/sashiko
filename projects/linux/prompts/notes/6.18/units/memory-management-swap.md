# MEMORY MANAGEMENT - SWAP

Manages swap devices and files (`swapon`/`swapoff`), swap slot allocation and reference counting (`swap_map`, clusters, and count continuations), the per-cluster RCU-protected swap cache (`swap_table`), swap-in readahead, page-level swap I/O (`mm/page_io.c`), and non-present PTE swap-entry encodings (`swp_entry_t`).

## Architecture & Data Flow
- `swap_range_alloc()` increments `si->inuse_pages` (`swap_usage_add()`) and decrements `nr_swap_pages` when `cluster_alloc_range()` allocates slots, symmetrically with `swap_range_free()`. `si->inuse_pages` embeds `SWAP_USAGE_OFFLIST_BIT`: readers must mask it via `swap_usage_in_pages()`, and only `del_from_avail_list()` / `add_to_avail_list()` under `swap_avail_lock` may modify `SWAP_USAGE_OFFLIST_BIT`. Broken by: deferring `nr_swap_pages` decrement out of `swap_range_alloc()` past fallible steps that roll back via `put_swap_folio()`. [F7, F67]
- `swap_table_alloc()` must zero-initialize every `struct swap_table`. When `ci->count` reaches 0 in `__free_cluster()`, `ci->table` must be freed (`swap_cluster_free_table()`, requiring `cluster_is_empty(ci)` and all `SWAPFILE_CLUSTER` entries null) and `ci->order` reset to 0; isolating from `si->free_clusters` in `isolate_lock_cluster()` must allocate `ci->table` via `swap_cluster_alloc_table()`. [F58, F66]
- `swap_cache_add_folio()` and `__swap_cache_del_folio()` must update all `folio_nr_pages(folio)` entries in `ci->table`, `folio->swap`, `PG_swapcache`, `NR_FILE_PAGES`, and `NR_SWAPCACHE` together under `ci->lock`, while callers update `SWAP_HAS_CACHE` in `si->swap_map`. [F69]
- In `swap_writeout()`, non-zero folios must call `swap_zeromap_folio_clear(folio)` before `zswap_store()` or `__swap_writepage()`. `swap_zeromap_folio_set()` and `swap_read_folio_zeromap()` must account `folio_nr_pages(folio)` to `SWPOUT_ZERO`/`SWPIN_ZERO` in both `count_vm_events()` and (when `get_obj_cgroup_from_folio(folio)` is non-NULL) `count_objcg_events()` followed by `obj_cgroup_put()`. [F72, F168]
- Every swap-out write path (`swap_writepage_fs()`, `swap_writepage_bdev_sync()`, `swap_writepage_bdev_async()`) must call `folio_start_writeback(folio)` before `folio_unlock(folio)`, and completion (`__end_swap_bio_write()`, `sio_write_complete()`) must mark the folio dirty and clear `PG_reclaim` on error before ending writeback. Block-device swap-out BIOs must call `bio_associate_blkg_from_page(bio, folio)`. [F169, F172]
- In `struct swap_iocb`, `sio->pages` counts `sio->bvec[]` elements (+1 per folio) while `sio->len` tracks total bytes (`folio_size(folio)`). `swap_writepage_fs()` and `swap_read_folio_fs()` must use `sio->len` for contiguity and completion checks, and unplug whenever `sio->iocb.ki_filp != swap_file || sio->iocb.ki_pos + sio->len != pos` or `sio->pages == ARRAY_SIZE(sio->bvec)`. [F100, F137]
- `si->bdev` can be `NULL` (check `si->bdev` or `SWP_BLKDEV`), and `si->global_cluster` is only allocated when `!(si->flags & SWP_SOLIDSTATE)`. High-order allocations (`order > 0`) in `cluster_alloc_swap_entry()` require `si->flags & SWP_BLKDEV` because `swap_folio_sector()` resolves only the head page's extent. [F50, F165]
- In `sys_swapon()`, `setup_swap_extents()` must run before allocating `swap_map`, `zeromap`, and `cluster_info`, refreshing `maxpages` from `si->max` afterward. `setup_swap_map()` and `setup_clusters()` must check `page_nr < maxpages` for `badpages[]`, reserve slot 0 (`SWAP_ENTRY_INVALID`, also skipped by `discard_swap()` and `swap_cluster_readahead()`), size `cluster_info` via `DIV_ROUND_UP(maxpages, SWAPFILE_CLUSTER)`, and call `inc_cluster_info_page()` for `maxpages .. round_up(maxpages, SWAPFILE_CLUSTER) - 1`. [F63, F89, F91, F132]
- `free_cluster()` must check `(si->flags & (SWP_WRITEOK | SWP_PAGE_DISCARD)) == (SWP_WRITEOK | SWP_PAGE_DISCARD)` before `swap_cluster_schedule_discard()`. `relocate_cluster()` must return early if `cluster_is_discard(ci)` and check `ci->flags` does not already match `CLUSTER_FLAG_FREE`, `CLUSTER_FLAG_FRAG`, or `CLUSTER_FLAG_FULL` before `free_cluster()` or `move_cluster()`. [F110, F111]
- Swap PTE/PMD software flags (`exclusive`, `soft_dirty`, `uffd_wp`) must be stripped by `pte_swp_clear_flags()` in `pte_to_swp_entry()` and `pte_same_as_swp()` and by `pmd_to_swp_entry()`, and transferred from `old_pte` to `new_pte` and `rmap_flags` in `unuse_pte()`. [F83]
- `SWP_TYPE_SHIFT` is `BITS_PER_XA_VALUE - MAX_SWAPFILES_SHIFT` so `swp_to_radix_entry()` does not truncate `swp_type`. `is_pfn_swap_entry()` must return true for all PFN-bearing entries (`is_migration_entry()`, `is_device_private_entry()`, `is_device_exclusive_entry()`, `is_hwpoison_entry()`), and callers must extract PFNs via `swp_offset_pfn(entry)` (`swp_offset(entry) & SWP_PFN_MASK`) because migration entries pack flags above `SWP_PFN_BITS`. [F98, F99, F105]

## Synchronization
- Lock hierarchy: `swap_lock` -> `si->lock` -> `swap_avail_lock` (and `swap_lock` -> `mmlist_lock`); `folio lock` -> `ci->lock` -> `si->lock` (and `ci->lock` -> `si->cont_lock`). `isolate_lock_cluster()` holding `si->lock` must use `spin_trylock(&ci->lock)`. Callers holding `ci->lock` (`cluster_reclaim_range()`, `swap_reclaim_full_clusters()`) must drop `ci->lock` before `__try_to_reclaim_swap()`, which must use `folio_trylock()`. [F28, F151]
- After `cluster_reclaim_range()` drops `ci->lock` for `__try_to_reclaim_swap()`, it must re-verify all slots in `[start, end)` of `si->swap_map` are 0 after re-acquiring `ci->lock`, and `alloc_swap_scan_cluster()` must re-check `cluster_is_usable(ci, order)` and reset `offset` if `cluster_is_empty(ci)`. [F75]
- Swap cluster lock helpers (`__swap_cluster_lock`, `swap_cluster_lock`, `swap_cluster_get_and_lock`, `swap_cluster_get_and_lock_irq`) require task context (`in_task()`) with `!percpu_ref_is_zero(&si->users)`. Callers of `cluster_alloc_swap_entry()` and `isolate_lock_cluster()` on `&si->free_clusters` must hold `local_lock(&percpu_swap_cluster.lock)`, and `swap_cluster_alloc_table()` must drop `ci->lock`, `si->global_cluster_lock`, and `percpu_swap_cluster.lock` before `GFP_KERNEL` allocation. [F145, F146]
- `ci->table` is RCU-protected: writers (`__swap_table_set()`, `__swap_table_xchg()`, `swap_cluster_free_table()`) require `ci->lock`; lockless readers under `rcu_read_lock()` must use `swap_table_get()` (which null-checks `rcu_dereference(ci->table)`, unlike `__swap_table_get()`), and `swap_table_free()` must defer reclamation via `call_rcu()` or `SLAB_TYPESAFE_BY_RCU`. [F32, F47, F157]
- `swap_cache_get_folio()` uses `folio_try_get()` on a lockless `swap_table_get()` result; callers must lock the folio and verify `folio_matches_swap_entry(folio, entry)` rather than comparing `folio->swap.val == entry.val`. `swap_cache_add_folio()` requires the folio locked, swapbacked, not in swapcache, and `SWAP_HAS_CACHE` set in `si->swap_map`. `__swap_cache_del_folio()` and `swap_cache_del_folio()` require the folio locked, `folio_test_swapcache(folio)`, and `!folio_test_writeback(folio)`. [F33, F34, F61, F158]
- Clearing `SWP_WRITEOK` in `del_from_avail_list(si, true)` and setting it in `add_to_avail_list(si, true)` require both `si->lock` and `swap_avail_lock`. `cluster_alloc_range()` must verify `si->flags & SWP_WRITEOK` under `ci->lock`, and `swapoff()` must call `wait_for_allocation()` (stepping `offset` by `SWAPFILE_CLUSTER` up to `ALIGN(si->max, SWAPFILE_CLUSTER)` and locking/unlocking every cluster) after clearing `SWP_WRITEOK` and before `try_to_unuse()`. [F20, F21, F120]
- `enable_swap_info()` must finish `setup_swap_info()` and drop `si->lock` and `swap_lock` before `percpu_ref_resurrect(&si->users)` and `_enable_swap_info()`, pairing with `smp_rmb()` after `percpu_ref_tryget_live(&si->users)` in `get_swap_device_info()`. `swap_range_free()` must use atomic `clear_bit()` on `si->zeromap` and execute `smp_wmb()` after all slot cleanup before `swap_usage_sub()`, pairing with `smp_mb()` in `try_to_unuse()`. [F18, F22, F134]
- Swap count continuation pages on `vmalloc_to_page(si->swap_map + offset)->lru` are indexed by `offset & ~PAGE_MASK`; `add_swap_count_continuation()` and `swap_count_continued()` must hold `si->cont_lock` (inside `ci->lock`), and `swap_count_continued()` must zero `*map = 0` on initial carry. [F81, F101]
- In `swap_read_folio()`, `zswap_folio_swapin(folio)` must be called while `folio` is locked, after `swap_read_folio_zeromap(folio)` is false and `zswap_load(folio)` returns `-ENOENT`, and before `swap_read_folio_fs()` / `swap_read_folio_bdev_*()`. [F37, F73]
- In `swap_alloc_slow()`, iterate `swap_avail_heads[node]` with `plist_for_each_entry_safe(si, next, ...)`, and after re-acquiring `swap_avail_lock`, check `plist_node_empty(&next->avail_lists[node])` to jump to `start_over`. In `unuse_mm()`, after `mmap_read_lock(mm)`, check `check_stable_address_space(mm)` before `for_each_vma()`, and check both `vma->anon_vma` and `!is_vm_hugetlb_page(vma)` before `unuse_vma()`. [F38, F112, F113]

## Object Lifetimes
- Paths accessing `swap_info_struct` without holding a swapcache folio lock, PTL, or RCU read lock—or after dropping a PTE reference so only `SWAP_HAS_CACHE` remains, as in `free_swap_and_cache_nr()`—must pin `si` with `get_swap_device()` and `put_swap_device()`. [F8]
- In `swapoff()`, after `try_to_unuse()` succeeds, call `percpu_ref_kill(&p->users)`, `synchronize_rcu()`, `wait_for_completion(&p->comp)`, `flush_work(&p->discard_work)`, `flush_work(&p->reclaim_work)`, and `flush_percpu_swap_cluster(p)` before freeing extents, continuations, `swap_map`, `zeromap`, or `cluster_info` (via `free_cluster_info(cluster_info, maxpages)` with `p->max` saved before zeroing). [F23, F139]
- `alloc_swap_info()` allocates `swap_info_struct` with `struct_size(p, avail_lists, nr_node_ids)` and never frees a published `swap_info[type]`; when reusing an entry with `!(p->flags & SWP_USED)`, do not memset or overwrite `p->type`, and free `defer` via `percpu_ref_exit(&defer->users)` and `kvfree(defer)` after dropping `swap_lock`. [F12, F135]

## API Contracts
- Callers passing non-NULL `struct swap_iocb **plug` to `swap_read_folio()` or `swap_writeout()` must call `swap_read_unplug()` or `swap_write_unplug()`, which must invoke `sio_read_complete()` or `sio_write_complete()` synchronously whenever `swap_rw()` does not return `-EIOCBQUEUED`. [F2, F45]
- `__swap_cache_del_folio()` only removes `folio` from `ci->table`, clears `folio->swap.val` and `PG_swapcache`, and updates stats; callers must separately call `put_swap_folio()` and `folio_ref_sub(folio, folio_nr_pages(folio))`. [F3]
- `__try_to_reclaim_swap()` returns `+nr_pages` (reclaimed), `-nr_pages` (unreclaimed), or `0` (uncached); test `> 0` for success. In `free_swap_and_cache_nr()`, save `end_offset = start_offset + nr` before reusing `nr` as the step, and advance by `ALIGN(offset + 1, abs(nr)) - offset` on non-zero return. [F41, F121]
- Non-`_nr` range helpers (`swap_entries_free()`, `swap_entries_put_cache()`, `swap_entries_put_map()`, `swapcache_clear()`, `__swap_duplicate()`, `swap_cache_add_folio()`, `__swap_cache_del_folio()`, `__swap_cache_clear_shadow()`) require `[offset, offset + nr)` within one `SWAPFILE_CLUSTER`; multi-cluster ranges must use `*_nr()` helpers. [F60]
- `__swap_duplicate()` must validate all `nr` slots before mutating any, and requires `usage` to be `SWAP_HAS_CACHE` or `SWAP_MAP_SHMEM` when `nr > 1`. `swapcache_prepare()` returns the raw negative errno from `__swap_duplicate()`, whereas `swap_duplicate()` retries with `add_swap_count_continuation(entry, GFP_ATOMIC)` on `-ENOMEM` and returns `0` even on `-EINVAL`/`-ENOENT`. [F43, F85, F149]
- Check `swp_tb_is_folio()` before `swp_tb_to_folio()` and `swp_tb_is_shadow()` before `swp_tb_to_shadow()` on `swap_table` entries. Filter `!non_swap_entry(entry)` (`swp_type(entry) < MAX_SWAPFILES`, subtracting all `SWP_*_NUM` counts) before `__swap_entry_to_info()` / `__swap_type_to_info()`. `pfn_swap_entry_to_page()` and `pfn_swap_entry_folio()` require the page/folio locked when `is_migration_entry(entry)`. [F46, F97, F154, F162]
- `swap_writeout()` must unlock `folio` on every path except `AOP_WRITEPAGE_ACTIVATE`, which must re-mark `folio` dirty and leave it locked. Swap writeout and runtime cluster discard must use `GFP_NOIO`, and block-device swap I/O paths must use a 1-vector `struct bio` with `bio_add_folio_nofail(bio, folio, folio_size(folio), 0)`. [F148, F166, F167]
- Before mTHP swap-in allocation, `non_swapcache_batch()` must verify no covered `si->swap_map` entries have `SWAP_HAS_CACHE`. In `swap_read_folio_zeromap()`, check `swap_zeromap_batch(folio->swap, nr_pages, &is_zeromap) != nr_pages` before `!is_zeromap`, returning `true` without `folio_mark_uptodate(folio)` on mixed zeromap bits. [F74, F106]
- Continuation page accesses and `is_folio_zero_filled()` must pair `kmap_local_page()` / `kmap_local_folio()` with `kunmap_local()` before advancing or returning. In `unuse_pte()`, call `arch_swap_restore()` before `swap_free()`. Pass `flush = false` to `workingset_test_recent()` in RCU/atomic context. [F86, F150, F160, F161]

## Error Handling
- In `__read_swap_cache_async()`, set `*new_page_allocated = false` upfront and only set `true` after `new_folio` is locked, charged, in swapcache, and on LRU; on failure after `swapcache_prepare()` succeeds, jump to `fail_unlock` (`put_swap_folio()` and `folio_unlock()`) before `folio_put()`. [F4, F56]
- In `folio_alloc_swap()`, return `-EAGAIN` silently when `folio_order(folio) > 0` and `!IS_ENABLED(CONFIG_THP_SWAP)`. Always call `mem_cgroup_try_charge_swap(folio, entry)` even when `!entry.val`, then check `if (!entry.val)` afterward before `swap_cache_add_folio()`. [F53, F175]
- In `SYSCALL_DEFINE2(swapon)`: reset `name`, `swap_file`, or `cluster_info` to `NULL` after `PTR_ERR()`; set `SWP_ACTIVATED` immediately when `swap_activate()` succeeds; set `S_SWAPFILE` and run `inode_drain_writes(inode)` before `enable_swap_info()`; and jump to `bad_swap_unlock_inode` (or `free_swap_zswap` after `zswap_swapon()`, clearing `S_SWAPFILE`) on errors after `inode_lock(inode)`. In `swapoff()`, call `vm_unacct_memory(p->pages)` after `security_vm_enough_memory_mm()` succeeds, and `reinsert_swap_info(p)` if `try_to_unuse()` fails. [F11, F13, F14, F51, F180]
- In `unuse_pte()`, save `swapcache = folio` before `folio = ksm_might_need_to_copy()`; on `ERR_PTR(-EHWPOISON)` restore `folio = swapcache`, and unlock/put `folio` at `out:` only when `folio != swapcache`. Install `make_hwpoison_entry(page)` on `ERR_PTR(-EHWPOISON)` / `PageHWPoison(page)`, or `make_poisoned_swp_entry()` on `!folio_test_uptodate(folio)`, decrementing `MM_SWAPENTS` and calling `swap_free(entry)`. [F40, F123, F183]

## Known Pitfalls
- Block-layer callers (`swap_folio_sector()`, `discard_swap()`, `discard_swap_cluster()`) must cast `PAGE_SIZE`-unit `swap_extent` fields to `sector_t` before `<< (PAGE_SHIFT - 9)`, and `swap_dev_pos()` must cast `swp_offset(entry)` to `loff_t` before `<< PAGE_SHIFT`. [F62, F126, F127]
- In `swap_vma_ra_win()`, compute `right` before clamping `(long)left < 0` to `0`, and clamp `[start, end)` to `[faddr & PMD_MASK, (faddr & PMD_MASK) + PMD_SIZE)`. In `swap_vma_readahead()` and `unuse_pte_range()`, the `!pte++` loop requires `pte_unmap(pte); pte = NULL;` before any sleep or return, and `if (pte) pte_unmap(pte);` after the loop. [F96, F118]
- In `__try_to_reclaim_swap()`, keep `entry` unchanged across `goto again`, updating `offset = swp_offset(folio->swap)` only after `folio_matches_swap_entry(folio, entry)` succeeds. In `swap_entry_put_locked()`, check `count == SWAP_MAP_SHMEM` before `(count & ~COUNT_CONTINUED) <= SWAP_MAP_MAX`, and call `swap_count_continued()` when `count == COUNT_CONTINUED`. [F109, F116]
