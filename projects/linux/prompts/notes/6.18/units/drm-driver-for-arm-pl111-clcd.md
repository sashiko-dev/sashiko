# DRM DRIVER FOR ARM PL111 CLCD

This component is the DRM/KMS display driver for the ARM PrimeCell PL110/PL111 Color LCD Controllers (CLCD) and ST Microelectronics Nomadik LCDC variants on the AMBA bus. It exposes a single-pipe KMS display pipeline (`drm_simple_display_pipe`), registers an internal Common Clock Framework divider (`pl111_div`) for the pixel clock, manages GEM DMA framebuffers (including device-specific reserved memory), and handles platform-specific syscon and FPGA multiplexing for ARM Integrator, Versatile, RealView, Versatile Express, and ST-Ericsson Nomadik platforms.

## Architecture & Data Flow

- All accesses to the interrupt-enable and control registers must use dynamic byte offsets `priv->ienb` and `priv->ctrl` rather than hardcoded `CLCD_PL110_*` or `CLCD_PL111_*` constants, because PL110/LCDC and PL111/Versatile swap offsets `0x18` and `0x1c`. `pl111_drm_dev_private.regs` is a byte-addressed `void *`, so all MMIO offsets (`CLCD_*`, `priv->ienb`, `priv->ctrl`, `pl111_reg_defs[].reg`) must remain byte offsets and `priv->regs` must not be changed to a word-typed pointer like `u32 __iomem *`. [F49, F54]
- In `pl111_amba_probe()`, `pl111_versatile_init()` must run before `writel(0, priv->regs + priv->ienb)` and `pl111_modeset_init()`, and subsequent code must read `priv->variant` rather than caching the initial `id->data` pointer, because `pl111_versatile_init()` overrides `priv->variant`, `priv->ienb`, and `priv->ctrl`. [F27]
- `pl111_display_check()` must enforce that `mode->hdisplay` is a multiple of 16, the framebuffer DMA address (`drm_fb_dma_get_gem_addr`) is 4-byte aligned, and `fb->pitches[0]` equals `mode->hdisplay * fb->format->cpp[0]`. If both `old_fb` and `fb` are non-NULL and `old_fb->format != fb->format`, it must set `cstate->mode_changed = true` because pixel format bits in `priv->ctrl` and `priv->variant_display_enable` are only programmed in `pl111_display_enable()`, not `pl111_display_update()`. [F25, F61]
- In `pl111_display_enable()`, the bridge timing check (`btimings->setup_time_ps >= 3000`) must run after the connector `DRM_BUS_FLAG_PIXDATA_DRIVE_NEGEDGE` check and toggle `TIM2_IPC` with XOR (`tim2 ^= TIM2_IPC`) rather than OR so that it inverts whichever clock edge polarity the connector selected. [F36]
- `priv->connector` and `bridge->timings` can be NULL at runtime (when using a non-panel bridge or a bridge without timings), so `pl111_display_enable()` must null-check `priv->connector`, `priv->bridge`, and `bridge->timings` before dereferencing them. [F17]
- `priv->variant_display_enable` and `priv->variant_display_disable` are independently optional callbacks (e.g., `INTEGRATOR_CLCD_CM` sets `variant_display_enable` while leaving `variant_display_disable` NULL), so both must be null-checked before invocation. [F18]
- In `pl111_clk_div_set_rate()` and `pl111_clk_div_recalc_rate()`, a pixel clock divisor `div == 1` is represented in `CLCD_TIM2` by setting `TIM2_BCD`, whereas any divisor `div >= 2` is encoded as `div - 2` split across `TIM2_PCD_LO_MASK` (low 5 bits) and `TIM2_PCD_HI_MASK` (high 5 bits at `TIM2_PCD_HI_SHIFT`) with `TIM2_BCD` cleared. [F33]
- In `pl111_clk_div_choose_div()`, `*prate` must not be modified inside the `for (div = 1; div < max_div; div++)` loop and must only be written with `best_prate` after the loop terminates, because each iteration with `set_parent == false` reads `*prate` as the input parent rate. [F42]
- In `pl111_vexpress_clcd_init()`, `mux_motherboard` must be cleared when either `has_coretile_hdlcd && IS_ENABLED(CONFIG_DRM_HDLCD)` or `has_coretile_clcd` holds before selecting `val`, so that coretile graphics takes precedence and deactivates a motherboard CLCD instance with `-ENODEV`. Broken by: using `else if` between the checks or evaluating `mux_motherboard` before both. [F43]
- Every non-sentinel entry in `pl111_id_table` must store a non-NULL `const struct pl111_variant_data *` in `amba_id.data`, whereas every non-sentinel entry in `versatile_clcd_of_match` and `impd1_clcd_of_match` must store an `enum versatile_clcd` constant cast to `void *` in `of_device_id.data`. [F52]
- In every `struct pl111_variant_data` instance, `nformats` must be the element count (`ARRAY_SIZE`) of the `u32` array pointed to by `formats` rather than its byte size (`sizeof`), as `pl111_display_init()` passes both to `drm_simple_display_pipe_init()`. [F51]

## Synchronization

- Read-modify-write updates to `CLCD_TIM2` in `pl111_display_enable()` and `pl111_clk_div_set_rate()` must hold `priv->tim2_lock`, with `pl111_display_enable()` preserving `TIM2_BCD | TIM2_PCD_LO_MASK | TIM2_PCD_HI_MASK` (when `!broken_clockdivider`) and `pl111_clk_div_set_rate()` preserving all other `CLCD_TIM2` bits. `pl111_display_enable()` must call `clk_set_rate(priv->clk, ...)` and `clk_prepare_enable(priv->clk)` outside `priv->tim2_lock` because `clk_set_rate()` sleeps on the clock prepare lock and invokes `pl111_clk_div_set_rate()`, which acquires `priv->tim2_lock`. [F66, F67]
- In `pl111_init_clock_divider()`, `spin_lock_init(&priv->tim2_lock)` must be called before the early return for `priv->variant->broken_clockdivider` and before `devm_clk_hw_register()`, because `pl111_display_enable()` unconditionally acquires `priv->tim2_lock`. [F7]
- `pl111_display_enable_vblank()` and `pl111_display_disable_vblank()` must be non-sleeping atomic callbacks because DRM vblank core invokes them under spinlocks with interrupts disabled (including from `drm_crtc_vblank_get()` inside `spin_lock_irq(&crtc->dev->event_lock)` in `pl111_display_update()`). [F65]
- In `pl111_amba_remove()`, `drm_dev_unregister(drm)` and `drm_atomic_helper_shutdown(drm)` must be called before `drm_panel_bridge_remove(priv->bridge)`, `drm_dev_put(drm)`, and `of_reserved_mem_device_release(dev)` so that userspace access and active scanout are stopped before bridge and memory teardown. [F12]

## Object Lifetimes

- `pl111_display_disable()` must tear down hardware state in reverse order of `pl111_display_enable()`: calling `drm_crtc_vblank_off(crtc)` (when `!priv->variant->broken_vblank`), clearing `CNTL_LCDPWR`, waiting 20ms, invoking `priv->variant_display_disable`, zeroing `priv->ctrl`, and calling `clk_disable_unprepare(priv->clk)`. Conversely, `pl111_display_enable()` must call `drm_crtc_vblank_on(crtc)` (when `!priv->variant->broken_vblank`) only after enabling `priv->clk` and setting `CNTL_LCDPWR` in `priv->ctrl`. [F3, F13]
- In `pl111_vexpress_clcd_init()`, `ct_clcd` saves the `child` pointer during `for_each_available_child_of_node(root, child)` right before `of_node_put(child)` and `break`, so after the loop `ct_clcd` must only be compared by pointer equality (`ct_clcd == dev->of_node`) and never dereferenced or passed to an OF helper. [F39]
- In `pl111_vexpress_clcd_init()` and `pl111_versatile_init()`, every `device_node` obtained from `of_find_node_by_path()`, `of_find_matching_node_and_match()`, or an early break from `for_each_available_child_of_node()` must be released with `of_node_put()`, and `pdev` from `of_find_device_by_node()` must be released with `platform_device_put()`. [F59]

## API Contracts

- In `pl111_display_update()`, when `crtc->state->event` is non-NULL, the driver must clear `crtc->state->event = NULL` and, under `spin_lock_irq(&crtc->dev->event_lock)`, call `drm_crtc_arm_vblank_event()` only if `crtc->state->active && drm_crtc_vblank_get(crtc) == 0`, falling back to `drm_crtc_send_vblank_event()` otherwise (such as when `broken_vblank` causes `drm_crtc_vblank_get()` to fail). [F75]
- Because `pl111_display_funcs` is a single file-scope mutable struct in `pl111_display.c`, `enable_vblank` and `disable_vblank` are only assigned when `!priv->variant->broken_vblank`, and `drm_vblank_init()`, `drm_crtc_vblank_on()`, and `drm_crtc_vblank_off()` must all be gated on `!priv->variant->broken_vblank`. [F76]
- `amba_set_drvdata()` stores `struct drm_device *` on the `amba_device` (with `struct pl111_drm_dev_private *` in `drm->dev_private`), whereas `devm_request_irq()` passes `struct pl111_drm_dev_private *` directly as the `void *data` argument to `pl111_irq()`. [F50]
- When `priv->use_device_memory` is `true` (because `of_reserved_mem_device_init()` bound device-specific reserved memory in `pl111_amba_probe()`), `pl111_gem_import_sg_table()` must return `ERR_PTR(-EINVAL)` instead of importing external scatter-gather tables via `drm_gem_dma_prime_import_sg_table()`. [F69]
- `struct pl111_variant_data.fb_depth` specifies color depth in bits (such as 15 on `pl110_impd1`) for `drm_client_setup_with_color_mode()`, so converting `fb_depth` to bytes-per-pixel in `pl111_mode_valid()` must use `DIV_ROUND_UP(priv->variant->fb_depth, 8)` rather than truncating `/ 8` division. [F21]
- Because `drm_display_mode.clock` is in kHz while the Common Clock Framework and `priv->memory_bw` (`max-memory-bandwidth`) use Hz and bytes/s, `pl111_display_enable()` and `pl111_mode_valid()` must scale `mode->clock` by 1000 (`1000ULL` in `pl111_mode_valid()` to prevent 32-bit overflow before multiplying by resolution and `cpp`). [F74]

## Error Handling

- In `pl111_modeset_init()`, if `drm_panel_bridge_add_typed()` fails, `IS_ERR(bridge)` must jump to `finish` rather than `out_bridge` and before assigning `priv->bridge`. Furthermore, `drm_panel_bridge_remove(priv->bridge)` in `out_bridge` and `pl111_amba_remove()` must be guarded by `panel` / `priv->panel`. [F16]
- In `pl111_modeset_init()`, the `for_each_endpoint_of_node(np, remote)` loop must not abort immediately on `-EPROBE_DEFER` or overwrite `panel`/`bridge` when `tmp_panel`/`tmp_bridge` is NULL, and must return `-EPROBE_DEFER` only after scanning all endpoints if `(!panel && !bridge) && defer`. [F41]
- `pl111_versatile_init()` must return 0 when no node matches `versatile_clcd_of_match`, and `pl111_nomadik_init()` must silently return when `syscon_regmap_lookup_by_compatible()` returns `IS_ERR()`, because both run unconditionally from `pl111_amba_probe()` on all platforms. [F19]
- In `pl111_amba_probe()`, both `drm_dev_alloc()` and `devm_ioremap_resource()` return error-encoded pointers rather than NULL on failure and must be checked with `IS_ERR()` and converted with `PTR_ERR()`. [F14]

## Known Pitfalls

- In `pl111_display_enable()`, because ARM PL110/PL111 reads the red channel from the least-significant bits while DRM fourcc codes list channels MSB-to-LSB, `CNTL_BGR` must be set for `DRM_FORMAT_*RGB*` and omitted for `DRM_FORMAT_*BGR*` when `priv->variant->st_bitmux_control` is false, and then cleared if `priv->variant->external_bgr` is true. [F34]
- In `pl111_vexpress_clcd_init()`, `dev->of_node` (the CLCD AMBA device's node) must be used when testing `ct_clcd == dev->of_node`, whereas `np` (the matched `"arm,vexpress-muxfpga"` node) must be passed to `of_find_device_by_node(np)` to obtain `pdev` for `devm_regmap_init_vexpress_config(&pdev->dev)`. [F40]
- In `pl111_clk_div_recalc_rate()`, the `CLCD_TIM2` register value `tim2` must be stored in an unsigned 32-bit type (`u32`) when extracting `TIM2_PCD_HI_MASK` (`GENMASK(31, 27)`) with `>> (TIM2_PCD_HI_SHIFT - TIM2_PCD_LO_BITS)` so that bit 31 is logically right-shifted without sign extension. [F48]
- 64-bit bandwidth and clock divider divisions in `pl111_mode_valid()`, `pl111_clk_div_choose_div()`, `pl111_clk_div_round_rate()`, and `pl111_clk_div_recalc_rate()` must use explicit 64-bit division helpers (`div_u64` or `DIV_ROUND_UP_ULL`) rather than `/` on `u64` or `unsigned long long` operands. [F46]
