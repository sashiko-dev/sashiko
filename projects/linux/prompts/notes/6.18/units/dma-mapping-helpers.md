# DMA MAPPING HELPERS

This component implements the architecture-independent Linux DMA mapping subsystem (`kernel/dma/` and headers), abstracting coherent/non-coherent allocations and streaming DMA mappings across `dma-direct`, `iommu-dma`, and `dma_map_ops`, along with `swiotlb` bounce buffering, CMA integration, reserved/atomic coherent pools, vmalloc remapping, and `dma-debug`.

## Architecture & Data Flow
- In `swiotlb_release_slots()`, `index` must be decremented by `swiotlb_align_offset(dev, 0, tlb_addr)` and `mem->slots[index].pad_slots` before reading `mem->slots[index].alloc_size`, and `swiotlb_align_offset(dev, 0, tlb_addr)` must be added back before `nr_slots()` (`DIV_ROUND_UP`). All `nslots` must reset `orig_addr = INVALID_PHYS_ADDR`, `alloc_size = 0`, and `pad_slots = 0` while decrementing `area->used` and `mem->total_used`. [F14, F59, F118]
- In `swiotlb_bounce()`, `tlb_offset` must be a signed `int` (`(tlb_addr & (IO_TLB_SIZE - 1)) - swiotlb_align_offset(dev, 0, orig_addr)`) applied to both `orig_addr` and `alloc_size`, clamping `size` to `alloc_size`. For `PageHighMem` buffers crossing pages in `while (size)`, `offset` starts at `orig_addr & ~PAGE_MASK` and resets to `0` after the first page. [F81, F108]
- `swiotlb_tbl_map_single()` must copy the original buffer via `swiotlb_bounce(..., DMA_TO_DEVICE, ...)` even when `dir == DMA_FROM_DEVICE` so partial device writes preserve unwritten bytes. In `dma_direct_sync_*_for_device()`, `swiotlb_sync_single_for_device()` must precede `arch_sync_dma_for_device()`; in `dma_direct_sync_*_for_cpu()`, `arch_sync_dma_for_cpu()` must precede `swiotlb_sync_single_for_cpu()`. [F64, F155]
- Because `swiotlb_dev_init()` sets `dev->dma_io_tlb_mem = &io_tlb_default_mem` unconditionally, callers like `swiotlb_tbl_map_single()` and `is_swiotlb_active()` must check `mem && mem->nslabs` rather than just `mem != NULL`. Non-transient pools must be added via `add_mem_pool()` so `mem->nslabs` and `mem->pools` update in lockstep under `mem->lock`. [F41, F62]
- Whenever SWIOTLB `nslabs` is initialized or shrunk in `swiotlb_init_remap()`, `swiotlb_init_late()`, or `swiotlb_alloc_pool()`, `nareas` must be clamped via `limit_nareas(nareas, nslabs)`, and subsequent allocations and `swiotlb_init_io_tlb_pool()` must use the local `nslabs`/`nareas` rather than `default_nslabs`/`default_nareas`. [F58, F94]
- In `swiotlb_init_io_tlb_pool()`, `mem->slots[i].list` must be capped to `min(IO_TLB_SEGSIZE - io_tlb_offset(i), mem->nslabs - i)`. In `swiotlb_search_pool_area()`, `index` is in `[0, pool->area_nslabs)` and must be wrapped via `wrap_area_index()` (not a bitwise mask) before adding `slot_base = area_index * pool->area_nslabs`. [F77, F80]
- `dma_direct_alloc()` strips `__GFP_ZERO` before `__dma_direct_alloc_pages()`, calls `arch_dma_prep_coherent(page, size)` before `dma_common_contiguous_remap()` or `arch_dma_set_uncached()` (also required in `atomic_pool_expand()`), and zeroes via `memset(ret, 0, size)` after decryption/remapping and before `arch_dma_set_uncached()`. [F47, F164]
- `dma_to_phys()` must strip encryption bits via `dma_addr_canonical(dma_addr)` before `translate_dma_to_phys(dev, dma_addr)`, and unencrypted buffers (such as SWIOTLB slots) or `dma_direct_supported()` mask checks must use `phys_to_dma_unencrypted()` instead of `phys_to_dma()`. [F151]
- In `mapping.c`, `dma_alloc_attrs()` and `dma_free_attrs()` must check `dma_alloc_from_dev_coherent()` / `dma_release_from_dev_coherent()` before stripping GFP zone flags, `WARN_ON(irqs_disabled())`, or dispatching. Streaming ops must check `dma_map_direct(dev, ops)` (`*dev->dma_mask`), whereas coherent/page alloc, free, mmap, and sgtable ops must check `dma_alloc_direct(dev, ops)` (`dev->coherent_dma_mask`). All five `dma_*_noncontiguous()` helpers must branch on `use_dma_iommu(dev)` in lockstep. [F74, F76, F109]
- `dev->dma_skip_sync` is `false` by default, set to `true` only by `dma_setup_need_sync()`, and reset to `false` by `dma_reset_need_sync()` on first SWIOTLB mapping; therefore `dma_need_unmap(dev)` must only be called after all potentially-bounced mappings are performed. [F33, F46]
- `dma_coherent_mem.size` is in `PAGE_SIZE` pages, so byte bounds in `coherent.c` must shift `mem->size` by `PAGE_SHIFT`. Shared/global pools (`dma_init_global_coherent()`, `rmem_dma_device_init()`) must set `use_dma_pfn_offset = true` so `dma_get_device_base()` translates `mem->pfn_base` per device. [F71, F122]
- In `debug.c`, `active_cacheline_insert()` and `active_cacheline_remove()` must both ignore `DMA_TO_DEVICE` and delete the radix entry only when `active_cacheline_dec_overlap(cln) < 0`. `debug_dma_map_sg()` records only `mapped_ents` output segments, so `debug_dma_unmap_sg()` and `debug_dma_sync_sg_for_*()` must stop at `mapped_ents = get_nr_mapped_entries()`. [F18, F103]

## Synchronization
- Under `CONFIG_SWIOTLB_DYNAMIC`, `swiotlb_find_slots()` must execute `WRITE_ONCE(dev->dma_uses_io_tlb, true)` then `smp_mb()` before returning a slot, pairing with `smp_rmb()` before `READ_ONCE(dev->dma_uses_io_tlb)` in `swiotlb_find_pool()`. Every `io_tlb_mem` init path (including `rmem_swiotlb_device_init()`) must initialize `mem->lock` and `INIT_LIST_HEAD_RCU(&mem->pools)` before `add_mem_pool()`. [F19, F20]
- A `struct io_tlb_pool` must be initialized by `swiotlb_init_io_tlb_pool()`—and for transient pools in `swiotlb_find_slots()`, have its slot reserved by `swiotlb_search_pool_area()` and `pool->transient = true` set—before `list_add_rcu()` publishes `pool->node`. In `__swiotlb_find_pool()`, if `paddr` is not found in either RCU list, `pool` must be reset to `NULL` before returning. [F21, F106]
- In `swiotlb.c`, `area->lock` (`spin_lock_irqsave()`) protects slot search, free-list coalescing, and `area->used`/`area->index`, and each area's slot count must be a multiple of `IO_TLB_SEGSIZE`. The search loop in `swiotlb_search_pool_area()` must bound iteration via `slots_checked < pool->area_nslabs` (incrementing by `1` or `stride`) rather than `index != wrap`. [F24, F95]
- When `!gfpflags_allow_blocking(gfp)`: `dma_alloc_contiguous()` must return `NULL` immediately; `dma_direct_alloc()` and `dma_direct_alloc_pages()` must use `dma_direct_alloc_from_pool()` when `remap` or `force_dma_unencrypted(dev)` holds and `!is_swiotlb_for_alloc(dev)`; and `swiotlb_alloc_tlb()` must use `dma_alloc_from_pool()` when `dev && force_dma_unencrypted(dev)` instead of `alloc_dma_pages()`. [F142, F143, F144]
- In `coherent.c`, `__dma_alloc_from_coherent()` and `__dma_release_from_coherent()` must hold `mem->spinlock` (`spin_lock_irqsave()`) while modifying `mem->bitmap`, releasing it before `memset()`. [F32]
- In `debug.c`, `check_unmap()` must call `put_hash_bucket(bucket, flags)` before `dma_mapping_error()` (which re-locks the bucket) and before `dma_entry_free()` (which takes `radix_lock`). When `bucket_find_contain()` steps across buckets (bounded to `min(HASH_SIZE, (index.dev_addr >> HASH_FN_SHIFT) + 1)`), it must `put_hash_bucket(*bucket, *flags)` and update caller's `*bucket` and `*flags` via `get_hash_bucket(&index, flags)`. [F16, F67, F86]
- In `debug.c`, `dma_entry_alloc()` must call `__dma_entry_alloc_check_leak()` only after releasing `free_entries_lock`, and `dma_active_cacheline` must use `GFP_ATOMIC | __GFP_NOWARN` to prevent console DMA re-entrancy deadlocks. [F148]

## Object Lifetimes
- `dmam_alloc_attrs()` buffers must be freed via `dmam_free_coherent()` (never `dma_free_coherent()`), and `dmam_free_coherent()` must call `devres_destroy()` before `dma_free_coherent()` so a concurrent allocation cannot reuse `vaddr` and collide. [F1, F133]
- `dma_release_coherent_memory()` must set `dev->dma_mem = NULL` after `_dma_release_coherent_memory()` (`dma_assign_coherent_memory()` rejects non-NULL `dev->dma_mem` with `-EBUSY`). `rmem_swiotlb_device_release()` must restore `dev->dma_io_tlb_mem = &io_tlb_default_mem` (never `NULL`, as `is_swiotlb_for_alloc()` dereferences it unconditionally). Neither `rmem_*_device_release()` callback may free shared `rmem->priv`. [F2, F4, F135]
- Memory from atomic coherent pools (`dma_alloc_from_pool()`) is already decrypted and never shrinks, so `dma_direct_free()`, `dma_direct_free_pages()`, and `swiotlb_free_tlb()` must check `dma_free_from_pool()` and return before calling `dma_set_encrypted()` or `set_memory_encrypted()`. [F9]
- `dma_common_pages_remap()` retains the caller's `struct page **pages` in `find_vm_area(vaddr)->pages` for `dma_common_find_pages()`, whereas `dma_common_contiguous_remap()` frees its temporary `pages` array with `kvfree(pages)` before returning. [F10]
- In `__swiotlb_tbl_unmap_single()`, if `swiotlb_del_transient()` returns `true`, `swiotlb_release_slots()` must not be called because `swiotlb_del_transient()` updates `mem->total_used`, unlinks the pool, and schedules `call_rcu(&pool->rcu, swiotlb_dyn_free)`. Because `swiotlb_alloc_pool()` allocates `pool->areas` inline inside `pool`, `swiotlb_dyn_free()` frees both with a single `kfree(pool)`. [F13, F121]
- `swiotlb_create_debugfs_files()` must not zero `mem->total_used`, `mem->used_hiwater`, or `mem->transient_nslabs` (as `io_tlb_default_mem` is already active at `late_initcall`), must pass `mem` as `debugfs_create_file()` private data rather than reading `io_tlb_default_mem`, and must never pass stack-local addresses to `debugfs_create_ulong()`. [F22, F63, F128]

## API Contracts
- When `use_dma_iommu(dev)` is true, `get_dma_ops(dev)` is `NULL` and `dma_go_direct()` is `false`, so helpers in `mapping.c` and `ops_helpers.c` must check `use_dma_iommu(dev)` before dereferencing `ops` or treating `!ops` as `dma-direct`. `dma_supported()` must call `ops->dma_supported()` even if `dev->dma_ops_bypass` is set, whereas `dma_pci_p2pdma_supported()` must return `false` whenever `get_dma_ops(dev)` is non-NULL. [F34, F172]
- When `(attrs & DMA_ATTR_NO_KERNEL_MAPPING) && !force_dma_unencrypted(dev) && !is_swiotlb_for_alloc(dev)` holds, `dma_direct_alloc()` returns a `struct page *` cast to `void *`, and `dma_direct_free()` must match this exact predicate first before treating `cpu_addr` as a virtual address. [F43]
- Callers of `dma_unmap_sg_attrs()` and `dma_sync_sg_for_*()` must pass `sgt->orig_nents`, not `sgt->nents`. `struct dma_iova_state::__size` reserves bit 63 for `DMA_IOVA_USE_SWIOTLB`, so callers must use `dma_iova_size(state)`. [F51, F88]
- When `dev->dma_mem` is set, `dma_alloc_from_dev_coherent()` must always return `1` (preventing fallback to generic memory on failure), whereas `dma_release_from_dev_coherent()` and `dma_mmap_from_dev_coherent()` must return `0` if `vaddr` is outside `mem->virt_base`. [F70]
- DMA mmap paths must validate `vma->vm_pgoff < count` and `vma_pages(vma) <= count - vma->vm_pgoff` (returning `-ENXIO` otherwise) before `remap_pfn_range()`, and `dma_direct_mmap()` / `dma_common_mmap()` must set `vma->vm_page_prot` via `dma_pgprot()` (and `pgprot_decrypted()`) before calling `dma_mmap_from_dev_coherent()` or `dma_mmap_from_global_coherent()`. [F82, F171]
- When `attrs & DMA_ATTR_MMIO` is set in `dma_map_phys()`, `dma_unmap_phys()`, `dma_direct_map_phys()`, and `dma_direct_unmap_phys()`, paths must skip `phys_to_page()`, `kmsan_handle_dma()`, SWIOTLB bouncing, and CPU cache syncs, and dispatch to `ops->map_resource`/`ops->unmap_resource`. [F101]
- `dma_alloc_contiguous()` requires a `PAGE_ALIGN()`ed byte `size` (and `dma_free_contiguous()` takes byte `size`, falling back to `__free_pages()` if non-CMA), whereas `dma_alloc_from_contiguous()` / `dma_release_from_contiguous()` take `count` in pages. `dma_set_decrypted()`, `dma_set_encrypted()`, `alloc_dma_pages()`, and `swiotlb_free_tlb()` must pass `PFN_UP(size)` (not `1 << get_order(size)`) to `set_memory_decrypted()`/`set_memory_encrypted()`. [F123, F167, F179]

## Error Handling
- When `dma_direct_map_sg()` fails at entry `i`, it must unmap only the `i` mapped entries via `dma_direct_unmap_sg(dev, sgl, i, dir, attrs | DMA_ATTR_SKIP_CPU_SYNC)`. `PCI_P2PDMA_MAP_BUS_ADDR` segments call `sg_dma_mark_bus_address(sg)` and skip `sg_dma_len(sg) = sg->length`, and `dma_direct_unmap_sg()` must call `sg_dma_unmark_bus_address(sg)` instead of `dma_direct_unmap_phys()`. [F11, F45]
- In `swiotlb_map()`, if the bounce buffer from `swiotlb_tbl_map_single()` fails `dma_capable(dev, dma_addr, size, true)`, it must release the slot via `__swiotlb_tbl_unmap_single(..., attrs | DMA_ATTR_SKIP_CPU_SYNC, ...)` before returning `DMA_MAPPING_ERROR`. [F12]
- When `dma_set_encrypted()` or `set_memory_encrypted()` fails during rollback or free in `direct.c`, `atomic_pool_expand()`, `alloc_dma_pages()`, or `swiotlb_free_tlb()`, the pages must be leaked rather than freed. [F168]
- `dma_map_sg_attrs()` returns `0` on failure and positive count on success; `dma_map_sgtable()` stores the count in `sgt->nents` and returns `0` on success or negative errno on failure; `ops->map_sg` callbacks must return a positive count or `-EINVAL`, `-ENOMEM`, `-EIO`, or `-EREMOTEIO`. [F36, F165]
- `alloc_dma_pages()` returns `ERR_PTR(-EAGAIN)` when a page exceeds `phys_limit` and `NULL` on OOM or decryption failure. In `dma_direct_alloc()`, `dma_common_contiguous_remap()` returns `NULL` on failure whereas `arch_dma_set_uncached()` returns an `ERR_PTR` that must be checked with `IS_ERR()` and converted to `NULL`. [F38, F39]

## Known Pitfalls
- `translate_phys_to_dma()` returns `DMA_MAPPING_ERROR` when no `bus_dma_region` matches, so `dma_capable()` and `dma_coherent_ok()` must check `addr == DMA_MAPPING_ERROR` before `addr + size - 1`, and when `is_ram && !CONFIG_ARCH_DMA_ADDR_T_64BIT`, `dma_capable()` must check `min(addr, end) < phys_to_dma(dev, PFN_PHYS(min_low_pfn))` against 32-bit wraparound. [F40, F89]
- In `swiotlb_search_pool_area()` and `swiotlb_release_slots()`, backward slot-merging loops starting at `slot_index - 1` must test `io_tlb_offset(i) != IO_TLB_SEGSIZE - 1` before indexing `pool->slots[i].list` to avoid index `-1` underflow. `swiotlb_adjust_nareas()` must clamp `nareas == 0` to `1` before `roundup_pow_of_two(nareas)`. [F52, F78]
- Shift and mask hazards: `slot_addr()` must widen the slot index to `phys_addr_t` before `<< IO_TLB_SHIFT`; `get_max_slots()` and `dma_get_seg_boundary_nr_pages()` must compute `(boundary_mask >> shift) + 1`; `dma_direct_get_required_mask()` must cast `(max_pfn - 1)` to `phys_addr_t` before `<< PAGE_SHIFT` and compute `(1ULL << (fls64(max_dma) - 1)) * 2 - 1`. [F85, F111, F113]
- In `dma_direct_unmap_phys()`, after calling `dma_direct_sync_single_for_cpu()`, `swiotlb_tbl_unmap_single()` must pass `attrs | DMA_ATTR_SKIP_CPU_SYNC` so `swiotlb_bounce()` is not executed twice. [F156]
- In `__dma_direct_alloc_pages()`, when `!allow_highmem`, any `PageHighMem(page)` from `dma_alloc_contiguous()` must be freed via `dma_free_contiguous()` to fall back to `alloc_pages_node()`, whereas `dma_direct_alloc()` passes `allow_highmem = true` and forces `remap = true` (`set_uncached = false`) for `PageHighMem(page)`. [F152]
- Early boot `RESERVEDMEM_OF_DECLARE` setup callbacks (`rmem_swiotlb_setup()`, `rmem_dma_setup()`, `rmem_cma_setup()`) must not call `pfn_to_page()` or `PageHighMem()` (defer to `device_init`), and `debug.c`'s `virt_to_paddr(virt)` must use `vmalloc_to_page(virt)` when `is_vmalloc_addr(virt)` and add `offset_in_page(virt)` to `page_to_phys(page)`. [F132, F163]
