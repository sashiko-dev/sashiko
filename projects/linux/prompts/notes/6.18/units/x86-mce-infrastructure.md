# X86 MCE INFRASTRUCTURE

The x86 Machine Check Exception (MCE) infrastructure handles hardware error detection, severity grading, recovery, polling, thresholding, and logging across Intel, AMD, Hygon, Zhaoxin, and legacy x86 processors. It processes synchronous `#MC` exceptions (Monarch/Subject rendezvous and local MCEs), asynchronous APIC interrupts for corrected error thresholding (CMCI/AMD threshold) and deferred errors, and periodic timer polling, queuing records locklessly via a `gen_pool` `llist` to process-context decoders, APEI/ERST, `memory_failure`, `/dev/mcelog`, sysfs, and debugfs.

## Architecture & Data Flow
- In `noinstr` `#MC` functions (`do_machine_check()`, `mce_start()`, `mce_end()`, `mce_panic()`, `mce_gather_info()`, `mce_rdmsrq()`, `mce_wrmsrq()`, `error_context()`), instrumented helpers must be wrapped in `instrumentation_begin()`/`instrumentation_end()`, and code outside them must use `raw_atomic_*` and `arch_*` bitops. Every `exc_machine_check` entry point must bracket `exc_machine_check_kernel()`/`exc_machine_check_user()` with `local_db_save()`/`local_db_restore()`, and `mce_rdmsrq()`/`mce_wrmsrq()` must use `EX_TYPE_RDMSR_IN_MCE`/`EX_TYPE_WRMSR_IN_MCE`. [F151, F152, F153]
- At the end of `__mc_scan_banks()`, `*err = *final` must copy the highest-severity record into stack-local `err` before `mce_end()` runs, because `mce_reign()` zeroes `per_cpu(hw_errs_seen, cpu)` (`*final`). In `__mc_scan_banks()`, `toclear` must be cleared at the start of each bank iteration and set only after skipping `MCE_KEEP_SEVERITY` and `MCE_UCNA_SEVERITY` (when `!no_way_out`), so `mce_clear_state()` does not erase errors left for `machine_check_poll()`. [F91, F92]
- `severities[]` must end with an unconditional catch-all rule (`BITSET(0)`), narrower rules (`MCACOD_DATA`/`MCACOD_INSTR` and `MCG_STATUS_SEAM_NR`-qualified `KERNEL` rules) must precede broader catch-all rules (`MCI_UC_SAR`, `MCI_STATUS_UC`), and `BANK_RANGE(l, h)` rules require `bank_lo > 0` because `mce_severity_intel()` tests `if (s->bank_lo && ...)`. In `error_context()`, `is_copy_from_user(regs)` must be evaluated before switching on `ex_get_fixup_type(m->ip)`. [F77, F87, F88]
- `queue_task_work()` must only populate `current->mce_*` fields and call `task_work_add()` when `++current->mce_count == 1`, and every `mce_kill_me` callback (`kill_me_now`, `kill_me_maybe`, `kill_me_never`) must reset `p->mce_count = 0`. [F65]
- When `machine_check_poll()` runs without `MCP_UC`, `should_log_poll_error()` must reject uncorrected errors (`MCI_STATUS_UC`) unless `mca_cfg.ser` is set and `ser_should_log_poll_error()` matches an unenabled (`!MCI_STATUS_EN`) or UCNA (`!MCI_STATUS_PCC && !MCI_STATUS_S`) error. [F89]
- When arming `mce_timer` outside storm mode (in `mce_timer_fn()` and `mce_start_timer()`), `should_enable_timer(iv)` (`!mca_cfg.ignore_ce && iv`) must be checked before updating `mce_next_interval` and calling `__start_timer()`. When `mce_restart()` runs `mce_cpu_restart()` across all CPUs, it must call `mce_schedule_work()` afterward to drain records queued with `MCP_QUEUE_LOG` by `__mcheck_cpu_init_prepare_banks()`. [F55, F56]
- In `mcheck_cpu_init()`, `__mcheck_cpu_init_vendor()` must run after `__mcheck_cpu_cap_init()` initializes `mce_banks_array` defaults (`ctl = -1ULL`, `init = true`) and before `__mcheck_cpu_init_prepare_banks()` writes `b->ctl` to `MCA_CTL` MSRs for banks with `b->init` set. In `mce_disable_cpu()`, `mce_reenable_cpu()`, and `mce_cpu_dead()`, `cmci_clear()`, `cmci_reenable()`, and `cmci_rediscover()` must only be called when `!cpuhp_tasks_frozen`. [F120, F138]
- Bank counts from `MSR_IA32_MCG_CAP & MCG_BANKCNT_MASK` must be capped to `MAX_NR_BANKS` (64) before storing in `mce_num_banks` or indexing per-bank arrays/bitmaps, and per-CPU `bank_map` in `amd.c` must use 64-bit `BIT_ULL(bank)` rather than `BIT(bank)` or `1 << bank`. In `smca_extract_err_addr()` and `mce_read_aux()`, the address LSB must be masked with `0x3f` before shifting or passing to `GENMASK_ULL()`. [F73, F102, F105]
- On AMD SMCA systems (`mce_flags.smca`), when `_log_error_deferred()` logs a `MCI_STATUS_DEFERRED` error from `MCA_STATUS`, it must also clear `MSR_AMD64_SMCA_MCx_DESTAT(bank)` to 0. On non-SMCA systems (`!mce_flags.smca`), `amd_mce_usable_address()` must evaluate bank 4 (`legacy_mce_is_memory_error(m)`) before testing `m->status & MCI_STATUS_POISON`. [F57, F93]
- Every `enum smca_bank_types` before `N_SMCA_BANK_TYPES` must have a non-NULL entry in `smca_names[]` (with `MAX_MCATYPE_NAME_LEN` exceeding the longest name plus 9 bytes), and on SMCA `get_name()` must format `"th_block_%u"` / `"th_bank_%u"` into `buf_mcatype` rather than returning `NULL`. `default_attrs[]` in `amd.c` must retain two trailing `NULL` entries at indices 2 and 3 for `allocate_threshold_blocks()`. [F68, F78, F95, F113]
- `apei_smca_report_x86_error()` must verify `ctx_info->msr_addr`, `ctx_info->reg_arr_size >> 3 > 0`, and `apicid_found` after `for_each_possible_cpu(cpu)` before calling `mce_prep_record_per_cpu(cpu, m)`, and cap `num_regs` at `15` with its descending `switch (num_regs)` falling through all lower cases. `apei_mce_report_mem_error()` must check `CPER_MEM_VALID_PA` and bound `find_first_bit(..., PAGE_SHIFT)` by `PAGE_SHIFT`. [F96, F97, F163, F164]
- In `do_inject()`, when `inj_type == DFR_INT_INJ`, `i_mce.status` must set `MCI_STATUS_DEFERRED` and clear `MCI_STATUS_UC` (`i_mce.status &= ~MCI_STATUS_UC`). In `check_hw_inj_possible()`, the test `MCI_STATUS_VAL` written to `MCA_STATUS` must be cleared back to 0 before disabling `toggle_hw_mce_inject()`. [F58, F100]

## Synchronization
- `mce_log()` must not invoke `x86_mce_decoder_chain` or `printk()` directly; it must enqueue records locklessly via `mce_gen_pool_add()` (`gen_pool_alloc()` + `llist_add()` to `mce_event_llist`) and queue `mce_irq_work` so `mce_gen_pool_process()` runs the blocking decoder chain and `gen_pool_free()` in workqueue context. [F33]
- In `mce_start()`, each CPU entering `#MC` rendezvous must update `global_nwo` via `raw_atomic_add()` before `raw_atomic_inc_return(&mce_callin)`, and issue `smp_rmb()` after waiting for `mce_callin == num_online_cpus()` before reading `global_nwo`. In `mce_end()`, Subjects (`order > 1`) wait for `atomic_read(&mce_executing) != 0` and return without resetting global state, while the Monarch (`order == 1`) runs `mce_reign()` and resets `global_nwo`, `mce_callin`, and `mce_missing_cpus` before `barrier()` and `atomic_set(&mce_executing, 0)`. [F26, F27]
- All RMW operations on `MSR_IA32_MCx_CTL2(bank)` and updates to `mce_banks_owned` (`cmci_discover()`, `cmci_set_threshold()`, `cmci_clear()`, `cmci_disable_bank()`) must hold `cmci_discover_lock`, and `cmci_set_threshold()` must preserve `MCI_CTL2_CMCI_EN`. When CMCI is unsupported/disabled, periodic polling must use `cmci_mc_poll_banks()` holding `cmci_poll_lock`. [F21, F134]
- `__start_timer()` must use `local_irq_save()`/`local_irq_restore()` around checking `timer_pending(t)`/`t->expires` and calling `mod_timer()`, as `mce_timer` is armed from both timer softirq and CMCI hardirq. `mce_timer_delete_all()` must never be called from atomic context, and sysfs callers (`mce_restart()`, `set_ignore_ce()`) must hold `mce_sysfs_mutex`. [F23, F143]
- In `threshold_create_bank()` and `mce_threshold_create_device()`, `bp[bank]` and per-CPU `threshold_banks` must only be assigned after all kobjects and `threshold_block` lists are initialized, and `mce_threshold_remove_device()` must clear `threshold_banks` to `NULL` before `__threshold_remove_device()` frees them. `threshold_restart_block()` must abort early only when both `!this_cpu_read(threshold_banks)` and `!tr->set_lvt_off` hold. [F17, F94]
- `mce_chrdev_read_mutex` must protect `mcelog->next`, `mcelog->entry[]`, and `mce_apei_read_done` in `dev_mce_log()` and `mce_chrdev_read()`, whereas `mcelog->flags` must use atomic `set_bit()` (bit `< 32`) and 32-bit `xchg(&mcelog->flags, 0)` because `mce_chrdev_ioctl()` is lockless. [F22, F116]
- `inject_mce()` must clear `i->finished = 0` and issue `mb()` before writing `per_cpu(injectm, m->extcpu)`, and issue `mb()` before setting `i->finished = 1`. `raise_mce()` must hold `mce_inject_mutex` and `cpus_read_lock()`, passing `wait = 0` to `smp_call_function_many(mce_inject_cpumask, mce_irq_ipi, NULL, 0)`. In `do_inject()`, `cpus_read_lock()` and `cpu_online(cpu)` must guard `toggle_hw_mce_inject()`, `prepare_msrs()`, and `smp_call_function_single()`. [F28, F29, F32]

## Object Lifetimes
- `mce_cpu_online()` must call `mce_device_create(cpu)` before `mce_threshold_create_device(cpu)` (which requires `this_cpu_read(mce_device)`). In `mce_cpu_pre_down()`, `mce_disable_cpu()` and `timer_delete_sync(t)` must run before `mce_threshold_remove_device(cpu)` and `mce_device_remove(cpu)` (which must check `cpumask_test_cpu(cpu, mce_device_initialized)` and clear `mce_device_initialized` and `per_cpu(mce_device, cpu)`). [F7, F24, F47]
- In `mce_threshold_create_device()`, if `threshold_create_bank()` fails before `bp` is stored into `threshold_banks`, rollback must call `__threshold_remove_device(bp)` directly rather than `mce_threshold_remove_device(cpu)`. After `kobject_init_and_add()` on a `struct threshold_block`, free it solely via `kobject_put(&b->kobj)`, whereas `struct threshold_bank` requires both `kobject_put(bank->kobj)` and `kfree(bank)`. [F1, F3]
- `mce_gen_pool_prepare_records()` and `mce_gen_pool_process()` must iterate `mce_event_llist` with `llist_for_each_entry_safe()`, and `mce_gen_pool_process()` must call `gen_pool_free()`. When `__cmci_disable_bank()` releases a bank with `CMCI_STORM_THRESHOLD`, it must call `cmci_storm_end(bank)`, and `cmci_claim_bank()` claiming one must call `mce_inherit_storm(bank)` and `cmci_storm_begin(bank)`. Cross-CPU IPIs passing stack pointers (`threshold_restart_block`, `__mce_disable_bank`) must pass `wait = 1`. [F9, F11, F99, F118]

## API Contracts
- `exc_machine_check_kernel()` must bracket `do_machine_check(regs)` with `irqentry_nmi_enter()`/`irqentry_nmi_exit()`, and `exc_machine_check_user()` with `irqentry_enter_from_user_mode()`/`irqentry_exit_to_user_mode()`. `mcheck_cpu_init()` and `mce_amd_feature_init()` require preemption disabled. [F144, F150]
- `mce_severity()`, `error_context()`, and `is_copy_from_user()` must NULL-check `regs` and `msg`; callers passing `&msg` to `mce_severity()` must initialize `msg` first (as `mce_severity_amd()` only writes `*msg` when `panic_msg` is non-NULL); and `m->bank` and `m->status` must be populated before `mce_severity()` or `mce_panic()`. [F40, F41, F42]
- In `uc_decode_notifier()`, `kill_me_maybe()`, and `kill_me_never()`, compute `pfn` as `(addr & MCI_ADDR_PHYSADDR) >> PAGE_SHIFT` and call `set_mce_nospec(pfn)` only when `memory_failure()` returns `0`. In `kill_me_maybe()`, `-EHWPOISON` and `-EOPNOTSUPP` from `memory_failure()` return without calling `kill_me_now()`, whereas any other non-zero return calls `kill_me_now()`. [F38, F39]
- `smca_get_bank_type()` returns sentinel `N_SMCA_BANK_TYPES` (not negative errno) on invalid/unpopulated banks; callers must check `bank_type < N_SMCA_BANK_TYPES`. `msr_to_offset()` must only return offsets of 64-bit (`__u64`) fields in `struct mce` or `-1` on mismatch, and `mce_rdmsrq()`/`mce_wrmsrq()` must check signed `offset >= 0` before dereferencing `(u64 *)((char *)this_cpu_ptr(&injectm) + offset)`. [F36, F37, F109]
- Access `MSR_IA32_MCG_EXT_CTL` only after `lmce_supported()`, use `rdmsrq_safe()`/`wrmsrq_safe()` for model-specific MSRs like `MSR_ERROR_CONTROL` in `intel_imc_init()`, and in `cmci_claim_bank()` read back `MSR_IA32_MCx_CTL2(bank)` after writing `MCI_CTL2_CMCI_EN` to verify it stuck before updating `mce_banks_owned` or `mce_poll_banks`. [F126, F127, F133]
- Writing read-only AMD MCA registers (`MCx_MISC[CntP]` or MCA injection MSRs) requires setting and restoring `McStatusWrEn` (`BIT(18)` in `MSR_K7_HWCR`). In `smca_configure()`, `MSR_AMD64_SMCA_MCx_CONFIG(bank)` must set `MCA_CONFIG[MCAX]` (`BIT(0)` of `high`), and set `DeferredIntType` (`BIT(5)` of `high`) only if `low & BIT(5)` is set and bits `[6:5]` of `high` are `0`. [F130, F135]
- Userspace injection (`mce_chrdev_write()`, `inj_extcpu_set()`) must verify CPU bounds and `cpu_online()` before indexing `per_cpu(injectm, ...)` or calling cross-CPU helpers; `inj_bank_set()` must reject `val >= (cap & MCG_BANKCNT_MASK)` on `m->extcpu` (and on SMCA, non-SW injections when `IPID == 0`); `flags_write()` must reject `!cnt` and `cnt > MAX_FLAG_OPT_SIZE`. [F70, F84, F85]

## Error Handling
- `apei_read_mce()` returns `sizeof(struct mce)` on read, `0` when empty, and negative errno on failure (except `-ENOENT` from `erst_read_record()`, which jumps to `retry:`), and all exits after `erst_get_record_id_begin(&pos)` must pass through `out:` (`erst_get_record_id_end()`). `__mce_read_apei()` masks `-ENODEV` to `0` without advancing `*ubuf`, so `mce_chrdev_read()` must check both `err` and `buf != ubuf`. [F34, F35, F98]

## External Contracts
- Do not change existing field offsets in `struct mce` or `struct mce_hw_err` (append vendor fields only to `struct mce_hw_err::vendor` and shared fields to the end of `struct mce`), or rename/reorder `HW_ERR` fields in `__print_mce()`. In `dev-mcelog.c`, `dev_mce_log()` drops records and sets `MCE_OVERFLOW` once `mcelog->next >= mcelog->len` and clears `entry.kflags = 0` only on the ring-buffer copy; `mce_chrdev_read()` requires `*off == 0` and `usize >= mcelog->len * sizeof(struct mce)`; and ioctl/write require `capable(CAP_SYS_ADMIN)`. [F69, F76, F81, F82, F117, F161]

## Known Pitfalls
- `machine_check_poll()` and `__mc_scan_banks()` must reset `m->misc = 0`, `m->addr = 0`, and `m->bank = i` on each bank iteration before `mce_read_aux()`, and `machine_check_poll()` must never clear `MSR_IA32_MCG_STATUS`. `mce_prep_record_common()` must use `__ktime_get_real_seconds()`. `vendor_disable_error_reporting()` must not clear socket-shared `MCA_CTL` MSRs on Intel/AMD/Hygon/Zhaoxin, and `intel_apply_cpu_quirks()` must set `mce_banks_array[0].init = false` rather than `ctl = 0`. [F90, F129, F136, F137, F139]
- `show_bank()` and `set_bank()` on shared `mce_bank_devs` must index `per_cpu(mce_banks_array, s->id)` and `per_cpu(mce_num_banks, s->id)` using `s->id` rather than `smp_processor_id()`. Callers of `get_name()` in `amd.c` must pass the shared `buf_mcatype` result to `kobject_create_and_add()`/`kobject_init_and_add()` before the next `get_name()` call. [F63, F114]
- In `get_block_address()`, SMCA block 0 maps to `MSR_AMD64_SMCA_MCx_MISC(bank)` (`MISC0`), whereas blocks `1..NR_BLOCKS - 1` must pass `block - 1` to `MSR_AMD64_SMCA_MCx_MISCy(bank, block - 1)` only when `low & MASK_BLKPTR_LO` is non-zero. In `threshold_restart_block()`, when `tr->old_limit != 0`, `new_count` must be masked with `THRESHOLD_MAX` (`0xFFF`) before ORing into `hi & ~MASK_ERR_COUNT_HI`. [F75, F106]
- Cast `mca_cfg.monarch_timeout` to `u64` before `* NSEC_PER_USEC` in `mce_start()`/`mce_end()`, and check `(s64)*t < SPINUNIT` before subtracting `SPINUNIT` in `mce_timed_out()`. Use `time_before()` for jiffies in `__start_timer()` and `raise_mce()`. In `mce_track_storm()`, non-storm shift is `(delta + HZ) / HZ` and `history << shift` requires `shift < NUM_HISTORY_BITS` (64). In `mce_gen_pool_create()`, `mce_poolsz` is `mce_numrecords * (1 << order)` where `order = order_base_2(sizeof(struct mce_evt_llist))`. [F103, F104, F107, F111]
