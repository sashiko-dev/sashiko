# SCHEDULER

The Linux scheduler subsystem implements the scheduling classes (`stop_sched_class`, `dl_sched_class`, `rt_sched_class`, `fair_sched_class` using EEVDF, `ext_sched_class` for BPF `sched_ext`, and `idle_sched_class`), hierarchical cgroup/autogroup task grouping, PELT load tracking, SMP/NUMA/EAS load balancing and topology, CPU isolation, scheduling clocks, and waitqueue/completion primitives.

## Architecture & Data Flow

- `sched_dl_entity` instances with `dl_se->dl_server` set are standalone servers (`rq->fair_server`), not tasks: never pass them to `dl_task_of()`, `update_stats_dequeue_dl()`, `add_nr_running()`/`sub_nr_running()`, or `dl_scaled_delta_exec()`. Stop the server via `dl_server_stop(dl_se)` if `server_pick_task(dl_se)` returns NULL in `__pick_task_dl()`, and if `update_curr_dl_se()` throttles a `dl_server` when `is_dl_boosted(dl_se)` or `!start_dl_timer()`, call `replenish_dl_new_period()` and `start_dl_timer()`. [F43, F66, F67, F68, F143]
- In `enqueue_task_fair()`, sample `rq->cfs.h_nr_queued` before `for_each_sched_entity(se)` and start `rq->fair_server` on a `0` to non-zero transition. Always call `__put_prev_set_next_dl_server(rq, prev, next)` in `put_prev_set_next_task()` (even when `next == prev`), `__dl_server_attach_root(&rq->fair_server, rq)` in `rq_attach_root()`, and `dl_rebuild_rd_accounting()` in `partition_sched_domains_locked()`. In `dl_clear_root_domain()`, reset `cpu_rq(i)->dl.extra_bw = cpu_rq(i)->dl.max_bw` before re-adding server bandwidth. [F64, F263, F435, F436, F445]
- Delayed-dequeued CFS tasks (`se->sched_delayed == 1`) decrement `cfs_rq->h_nr_runnable` via `set_delayed()` (`set_delayed()`/`clear_delayed()` must return early when `!entity_is_task(se)`) while staying in `h_nr_queued` and `rq->nr_running`; subtract `cfs_h_nr_delayed(rq)` when counting runnable tasks. `util_est_dequeue()` runs only when `!p->se.sched_delayed`, and `util_est_enqueue()` runs when `!p->se.sched_delayed || (flags & ENQUEUE_DELAYED)`. [F190, F256, F257]
- In `dequeue_entities()`, when breaking from the first `for_each_sched_entity(se)` loop, sample `slice = cfs_rq_min_slice(cfs_rq)` at the break point, and if `cfs_rq->load.weight` is non-zero, advance `se = parent_entity(se)` before breaking so the second loop does not decrement the same `cfs_rq` twice. Whenever `se->slice` of a queued non-current entity changes, call `min_vruntime_cb_propagate(&se->run_node, NULL)`. [F254, F282, F283]
- In `enqueue_entity()`, call `place_entity()` before `update_curr()` when `cfs_rq->curr == se`, but after `update_curr()`, `update_load_avg()`, and `update_cfs_group()` when `cfs_rq->curr != se`. Overwrite `se->slice` with `sysctl_sched_base_slice` only when `!se->custom_slice`. In `reweight_entity()`, rescale `se->vlag` and relative `se->deadline` before `update_load_set()`, and always zero or update `load_weight::inv_weight` when `weight` changes. [F251, F270, F272, F309]
- In `__pick_eevdf()`, check if `node->rb_left` is non-NULL with `vruntime_eligible(cfs_rq, __node_2_se(left)->min_vruntime)` and descend left before testing `entity_eligible(cfs_rq, se)`. `vruntime_eligible()` must cross-multiply `avg >= (s64)(vruntime - cfs_rq->min_vruntime) * load`, `avg_vruntime()` must bias negative `avg` by `-(load - 1)` before `div_s64()`, and preempting `se` in `check_preempt_wakeup_fair()` for idle or `PREEMPT_SHORT` must call `cancel_protect_slice(se)`. [F255, F284, F305]
- Under proxy execution (`cfs_rq->curr == &rq->donor->se`), `update_se()` accounts task runtime to `rq->curr` and cgroup/EEVDF virtual time to `rq->donor`; `check_preempt_wakeup_fair()` uses `se = &rq->donor->se` while testing `test_tsk_need_resched(rq->curr)`. [F268, F290]
- `list_add_leaf_cfs_rq()` and `list_del_leaf_cfs_rq()` maintain bottom-up child-before-parent order on `rq->leaf_cfs_rq_list` via `rq->tmp_alone_branch`: walk ancestors until `list_add_leaf_cfs_rq()` returns true, step `rq->tmp_alone_branch` back to `.prev` in `list_del_leaf_cfs_rq()` if it equals `&cfs_rq->leaf_cfs_rq_list`, and check `prev != &rq->leaf_cfs_rq_list` before `container_of()` in `child_cfs_rq_on_list()`. [F201, F262, F286, F314]
- In `throttle_cfs_rq_work()`, reset `p->sched_throttle_work.next = &p->sched_throttle_work` (self-pointing unqueued sentinel, also used by `p->numa_work`) and call `dequeue_task_fair(rq, p, DEQUEUE_SLEEP | DEQUEUE_THROTTLE)` before setting `p->throttled = true`. [F246, F271]
- In `struct sched_ext_ops`, all fields before `init` must be function pointers (online ops before `cpu_online`, hotplug ops before `init`) and updated in lockstep with `enum scx_opi`, `__bpf_ops_sched_ext_ops`, `bpf_scx_check_member()`, and `bpf_scx_init_member()`. User DSQs must never mix FIFO and `SCX_ENQ_DSQ_PRIQ`; only downcast `dsq` to `rq` when `dsq->id == SCX_DSQ_LOCAL`, and test `(dsq_id & SCX_DSQ_LOCAL_ON) == SCX_DSQ_LOCAL_ON`. [F74, F82, F95, F147, F148]
- In `dequeue_rt_stack()`, dequeue `sched_rt_entity` nodes top-down from root to `rt_se` before `dequeue_top_rt_rq()`. Paired `DEQUEUE_*` and `ENQUEUE_*` flags must share bit values; `dequeue_entity()` and `move_entity()` test `(flags & (DEQUEUE_SAVE | DEQUEUE_MOVE)) != DEQUEUE_SAVE`, and `__sched_setscheduler()` clears `DEQUEUE_MOVE` if PI `rt_effective_prio()` is unchanged. [F293, F423, F432, F444, F474]

## Synchronization

- When temporarily dropping a pinned `rq->__lock`, pair `rq_unpin_lock(rq, rf)` with `rq_repin_lock(rq, rf)` using the same `struct rq_flags *rf` (preserving `rf.cookie` and `RQCF_UPDATED` while invalidating `SCX_RQ_CLK_VALID`). Never call `rq_clock*()` without `rq->__lock` held and `update_rq_clock(rq)` called since pinning. [F25, F176, F339, F375, F388, F446]
- `double_lock_balance(this_rq, busiest)` requires `this_rq` locked and IRQs disabled, orders locks via `rq_order_less()`, and pairs with `double_unlock_balance()`. Because it may drop `this_rq->__lock`, callers (`push_dl_task()`, `push_rt_task()`, `find_lock_*_rq()`) must pin `next_task` with `get_task_struct()` beforehand and revalidate `!is_migration_disabled(task)`, `task->cpus_mask`, and `pick_next_pushable_*_task(rq)`. Before `stop_one_cpu_nowait(..., push_cpu_stop, ...)`, obtain `push_task` via `get_push_task()` under `rq->__lock`, disable preemption, and unlock all `rq->__lock`s. [F22, F177, F376, F395, F396, F517, F518]
- Lock nesting around `rq->__lock`: non-local `dsq->lock` (`sched_ext`), `cfs_b->lock`, `cfs_rq->removed.lock` (`raw_spin_lock_irqsave` when `rq->__lock` is not held), `rt_b->rt_runtime_lock` (outer to `rt_rq->rt_runtime_lock`), and `dl_b->lock` all nest inside `rq->__lock`, whereas `shares_mutex` nests outside `rq->__lock`. `do_sched_cfs_period_timer()`/`slack_timer()` must drop `cfs_b->lock` before `distribute_cfs_runtime()`. [F23, F28, F230, F327, F328, F520]
- In `__sched_setscheduler()`, blocking calls (`uclamp_validate()`, `cpuset_lock()`—which must be paired with `cpuset_unlock()` on all exit and `recheck` paths) must precede `task_rq_lock()`; before `task_rq_unlock()`, disable preemption and `splice_balance_callbacks(rq)`, then run `rt_mutex_adjust_pi(p)` and `balance_callbacks()` after unlocking. `sched_class::switched_from` may drop `rq->__lock`. [F368, F399, F400, F521]
- In `sched_ext`, `move_remote_task_to_local_dsq()` unlocks `src_rq` and returns with `dst_rq` locked, so callers must update `locked_rq` and relock the entry `rq` before returning. In `direct_dispatch()` during enqueue, `rq->__lock` is pinned, so remote `SCX_DSQ_LOCAL` dispatches must queue onto `rq->scx.ddsp_deferred_locals` via `schedule_deferred(rq)` and be drained in `process_ddsp_deferred_locals()` by popping the head with `list_first_entry_or_null()`. [F9, F29, F115]
- Clear `SCX_OPSS_QUEUEING`/`SCX_OPSS_DISPATCHING` on `p->scx.ops_state` with `atomic_long_set_release()`, clear `SCX_OPSS_DISPATCHING` in `dispatch_to_local_dsq()` before locking `src_rq`, and pass the constant `SCX_OPSS_DISPATCHING` (not `opss`) to `wait_ops_state()` on fallthrough in `ops_dequeue()`. Pass non-NULL `rq` to `SCX_CALL_OP*()` only when `rq->__lock` is held, and check `scx_root` for NULL under RCU/RCU-bh in timer-callable kfuncs. [F27, F30, F112, F164]
- In waitqueues and completions: `prepare_to_wait*()` and unlocked wait loops must call `set_current_state()` (full barrier) before testing the condition; on `signal_pending_state()` in `prepare_to_wait_event()`/`prepare_to_swait_event()`, unlink the entry under the queue lock before returning `-ERESTARTSYS`. Lockless `waitqueue_active()`, `wake_up_bit()`, and `wake_up_var()` require `smp_mb()`/`smp_mb__after_atomic()` after storing the condition. `completion_done()` must lock and unlock `x->wait.lock` after seeing `x->done != 0`. [F381, F382, F385, F550, F578, F579]

## Object Lifetimes

- For `dl_se->dl_timer` and `inactive_timer`, call `get_task_struct(dl_task_of(dl_se))` only when `!dl_server(dl_se) && !hrtimer_is_queued(timer)`, and `put_task_struct()` on cancel only when `hrtimer_try_to_cancel() == 1 && !dl_server(dl_se)`. In `dl_task_timer()` and `inactive_task_timer()`, call `put_task_struct(p)` only after `task_rq_unlock()` and never dereference `p` or `timer` afterwards. [F2, F3]
- `__block_task(rq, p)` clears `p->on_rq` via `smp_store_release(&p->on_rq, 0)` last; callers (including `pick_next_entity()` and `dequeue_task_fair()` on `DEQUEUE_DELAYED`, where `pick_next_entity()` must return NULL so `pick_task_fair()` restarts at `again:`) must not dereference `p` or `se` afterwards. Before `remove_entity_load_avg(se)` or class switch in `__sched_setscheduler()`, if `se->sched_delayed` is set, lock `rq` and dequeue with `DEQUEUE_SLEEP | DEQUEUE_DELAYED`. [F192, F238, F291, F391, F431]
- In `sched_balance_rq()` and `active_load_balance_cpu_stop()`, `detach_task()` must call `deactivate_task()` and `set_task_cpu()` before unlocking `src_rq`, every detached task must be attached under `dst_rq` lock, and `busiest_rq->active_balance` must be cleared under `busiest_rq->__lock` on all exits. In `destroy_cfs_bandwidth()`, cancel both hrtimers before flushing every CPU's `rq->cfsb_csd_list` via `__cfsb_csd_unthrottle(rq)`. [F195, F196, F199, F225, F226]
- In `scx_enable()` and `scx_disable_workfn()`: update `scx_root` and `scx_idle_enable(ops)` (before `ops.init()`) under `cpus_read_lock()`; run cgroup and task init/exit under `scx_cgroup_lock()`; pin tasks with `tryget_task_struct(p)` before `scx_task_iter_unlock()` and skip `SCX_TASK_CURSOR` entries. After `SCX_ENABLING`, errors in `scx_enable()` must jump to `err_disable`, flush `disable_work`, and return `0`. `destroy_dsq()` sets `SCX_DSQ_INVALID` and defers `kfree_rcu()` via `dsqs_to_free`. [F12, F13, F32, F33, F35, F36, F146]
- In `autogroup_destroy()`, reset `ag->tg->rt_se = NULL` and `ag->tg->rt_rq = NULL` before `sched_destroy_group(ag->tg)` and do not `kfree(ag)` directly. `finish_wait()`/`finish_swait()` must use `!list_empty_careful()`, `do_wait_for_common()` must call `__finish_swait()` under `x->wait.lock` on all exits, and `__wait_event_hrtimeout()` must call `hrtimer_cancel()` and `destroy_hrtimer_on_stack()` on all exits. [F383, F546, F547, F551, F554]

## API Contracts

- Verify entity type before downcasting: `entity_is_task(se)` (`!se->my_q`) before `task_of(se)` (group `sched_entity`s are in `struct sched_entity_stats` and `root_task_group.se[cpu]` is NULL), and `rt_entity_is_task(rt_se)` before `rt_task_of(rt_se)`. `sched_class::task_tick` callbacks can run remotely via `nohz_full` tick offload and must use `@rq` and `@curr`/`@p`, never `this_rq()`, `smp_processor_id()`, or `current`. [F233, F235, F316, F326, F409, F522]
- Return contracts: `util_fits_cpu()` returns `1`, `0`, or `-1` (check `> 0` for full fit); `select_idle_*()`, `find_energy_efficient_cpu()`, `find_new_ilb()`, and `find_lowest_rq()` return `-1` on failure whereas `wake_affine_*()` and `sched_numa_find_nth_cpu()` return `nr_cpumask_bits`/`nr_cpu_ids`; `yield_to()` returns `> 0`, `0`, or `-ESRCH`; jiffies `wait_event_*_timeout()` returns `0` on timeout or `>= 1` on success, whereas `wait_event_*hrtimeout()` returns `0` on success or `-ETIME`. [F236, F239, F403, F405, F417, F583, F584]
- In `sched_ext`: `KF_ACQUIRE` kfuncs without `KF_RET_NULL` (`scx_bpf_task_cgroup()`, `scx_bpf_get_idle_cpumask*()`, `scx_bpf_get_idle_smtmask*()`) must never return NULL. Validate CPUs with `ops_cpu_valid()`, nodes with `validate_node()`, and callback errors with `ops_sanitize_err()`. Use `SCX_CALL_OP_TASK*()` for task callbacks under `rq->__lock`, `SCX_HAS_OP()` to check optional ops, and `rhashtable_lookup_insert_fast()` in `scx_bpf_create_dsq()`. [F18, F48, F50, F53, F56, F85, F87, F183]
- Scale conversions: convert real-ns `se->slice` and `delta_exec` via `calc_delta_fair()` before virtual-time arithmetic; widen 32-bit us/ms durations (`sysctl_sched_cfs_bandwidth_slice`, `sysctl_sched_dl_period_min`/`max`, `curr->numa_scan_period`) to `u64` before multiplying by `NSEC_PER_USEC`/`NSEC_PER_MSEC`; convert `sysctl_numa_balancing_scan_size` and `promote_rate_limit` with `MB_TO_PAGES()`. [F46, F248, F313, F348, F349]

## Error Handling

- In `scx_cgroup_init()`, call `css_put(css)` before returning on error inside `css_for_each_descendant_pre()`. In `scx_cgroup_can_attach()`, set `p->scx.cgrp_moving_from` only after `ops.cgroup_prep_move()` succeeds on `from != to`, and on rollback or `scx_cgroup_cancel_attach()`, invoke `ops.cgroup_cancel_move()` only where `cgrp_moving_from != NULL` and clear it. `bpf_iter_scx_dsq_new()` must initialize `kit->dsq = NULL` before any error check. [F15, F16, F17]
- `start_dl_timer()` returns `0` when the activation time is in the past; callers throttling a deadline entity must check `!start_dl_timer(dl_se)` and replenish or re-enqueue on `0`. In `alloc_fair_sched_group()`, if per-CPU allocation fails before `init_tg_cfs_entry()`, free only the uncommitted local `cfs_rq` at `err_free_rq`. In `__wait_on_bit_lock()`, when `action` returns non-zero, call `finish_wait()` before `test_and_set_bit()`. [F44, F200, F374]

## External Contracts

- In `sched_copy_attr()`, zero `*attr`, map `uattr->size == 0` to `SCHED_ATTR_SIZE_VER0`, require `SCHED_ATTR_SIZE_VER1` when `SCHED_FLAG_UTIL_CLAMP` is set, and on size errors write `sizeof(*attr)` to `uattr->size` and return `-E2BIG`. Reject `(int)policy < 0` and user `SCHED_FLAG_SUGOV` in syscalls, mask `kattr.sched_flags &= SCHED_FLAG_ALL` in `sys_sched_getattr()`, and exit `rcu`/`task_rq_lock` guards before `copy_to_user()`. [F413, F414, F415, F449, F450, F528, F689]

## Known Pitfalls

- Compare CFS virtual times (`vruntime`, `deadline`, `min_vruntime`), `sched_ext` `dsq_seq`/`dsq_vtime`/`core_sched_at`, `sched_clock` timestamps, and PELT `now - sa->last_update_time` using signed differences (`(s64)(a - b) < 0`, `entity_before()`, `u32_before()`, `time_before64()`), never `<` or `>`. Guard unsigned subtractions against underflow in `grub_reclaim()`, `__sub_running_bw()`/`__sub_rq_bw()`, and `update_curr_scx()` (skipping `SCX_SLICE_INF`). [F133, F134, F138, F139, F303, F489, F639]
- In `nldsq_next_task()`, `cur` may be a fake `container_of(&kit->cursor, ...)` from `bpf_iter_scx_dsq_next()`, so only take `&cur->scx.dsq_list.node` without dereferencing `cur`, skip `SCX_DSQ_LNODE_ITER_CURSOR`, and skip `u32_before(kit->cursor.priv, p->scx.dsq_seq)`. `scx_dsq_move()` must clear `__SCX_DSQ_ITER_HAS_SLICE | __SCX_DSQ_ITER_HAS_VTIME` on all exits, and `scx_bpf_reenqueue_local()` must move tasks (skipping only `p->migration_pending`) to a private list before `do_enqueue_task()`. [F79, F116, F117, F124, F144]
- In `__wake_up_common()`, snapshot `curr->flags` before `curr->func` and use `list_for_each_entry_safe_from()`; in `swake_up_all()`, `list_splice_init(&q->task_list, &tmp)` before dropping `q->lock`. Because `bit_waitqueue()` and `__var_waitqueue()` share `bit_wait_table`, `var_wake_function()` must use `bit_nr = -1` and never call `test_bit()` on `key->flags`. `struct task_struct` must keep `thread_info` first and `unsigned :0;` before `sched_remote_wakeup`, and `struct rq::nr_pinned` must remain `unsigned int`. [F443, F469, F471, F509, F529, F620, F621]
