# KERNEL VIRTUAL MACHINE FOR POWERPC (KVM/powerpc)

This unit implements KVM for PowerPC across Book3S Problem State (PR) guest execution, PAPR hypercalls, paired-single floating-point emulation, and HPTE MMU caching; BookE guest execution and instruction/SPR emulation; Ultravisor secure guest memory management (`uvmem`) using `ZONE_DEVICE` private pages; and Book3S virtual interrupt controllers (XICS, XICS-on-XIVE, XIVE native mode, and RTAS token/hcall handling).

## Architecture & Data Flow
- In `struct kvmppc_uvmem_slot`, `pfns[gfn - base_pfn]` ORs `KVMPPC_GFN_FLAG_MASK` into the upper 3 bits; `kvmppc_gfn_is_uvmem_pfn()` must mask with `KVMPPC_GFN_PFN_MASK`, and every non-breaking iteration of `kvmppc_uv_migrate_mem_slot()`'s `while (kvmppc_next_nontransitioned_gfn(...))` loop must set a `KVMPPC_GFN_FLAG_MASK` bit via `kvmppc_svm_page_in()`. [F99, F107]
- `kvmppc_xive_find_source()` and `kvmppc_xics_find_ics()` must check `(irq >> KVMPPC_XICS_ICS_SHIFT) <= KVMPPC_XICS_MAX_ICS_ID`, while loops over `xics->ics[]` or `xive->src_blocks[]` must use `<= max_icsid` / `<= max_sbid` (`max_icsid + 1` in `icp_check_resend()`). Callers of `kvmppc_xive_find_source()` must check `state->valid` before `kvmppc_xive_select_irq()`, and `kvmppc_xive_set_mapped()` / `clr_mapped()` must update `state->pt_number` and `state->pt_data` together under `sb->lock`. [F44, F45, F89, F90]
- In XIVE queues (`__xive_read_eq()`, `xive_vm_scan_for_rerouted_irqs()`), `qpage[idx]` is valid iff `(be32_to_cpup(qpage + idx) >> 31) != toggle`, advancing `idx = (idx + 1) & msk` and flipping `toggle ^= 1` on wrap to 0; `xive_vm_scan_for_rerouted_irqs()` must use `goto next` (not `continue`) and preserve `entry & 0x80000000` when writing `XICS_DUMMY`. [F92, F114]
- In `xive_vm_scan_interrupts()`, `if (prio >= xc->mfrr && xc->mfrr < xc->cppr)` must run before updating `q->idx`/`q->toggle`, `hirq == XICS_IPI || (prio == 0 && !qpage)` must only jump to `skip_ipi:` when `hirq != 0`, and `scan_fetch` must sync `xc->hw_cppr` and `TM_QW1_OS + TM_CPPR` when `xc->cppr != xc->hw_cppr`. [F65, F112, F113]
- In `xive_set_source()`, when `KVM_XICS_PENDING` is set, `state->old_q` must be `true` and `state->old_p` `false` (even if `KVM_XICS_PRESENTED` is set) so `xive_finish_unmask()` sets PQ=11 and calls `xive_vm_source_eoi()`; `xive->src_count` must only increment when `!state->valid` so `xive_get_source()` runs `xive_pre_save_scan()` at `saved_src_count == 0` and `xive_post_save_scan()` at `++saved_src_count == src_count`. [F61, F63]
- `xive_try_pick_queue()` must cap targeted interrupts to `(q->msk + 1) - XIVE_Q_GAP`, and priority values in `book3s_xive.c` must be `< 8` before `1 << prio` or indexing `xc->queues[prio]`. `kvmppc_xive_vcpu_id_valid()` / `compute_vp_id()` must check `kvmppc_pack_vcpu_id(xive->kvm, cpu) < xive->nr_servers`, and `kvmppc_xive_set_nr_servers()` must return `-EBUSY` under `xive->lock` if `xive->vp_base != XIVE_INVALID_VP`. [F86, F87, F94, F132]
- `kvmppc_xive_push_vcpu()` must verify `local_paca->kvm_hstate.xive_tima_virt` and `vcpu->arch.xive_cam_word` are non-zero before writing TIMA; `kvmppc_xive_pull_vcpu()` must reset `xive_saved_state.lsmfb = 0`, `ack = 0xff`, and `xive_pushed = 0`. In `icp_deliver_irq()`, both `goto again` paths must set `check_resend = false`, and `kvmppc_xics_hcall()` must handle `H_IPOLL` before `kvmppc_xics_rm_complete()`. [F46, F67, F117, F118]
- In `book3s_pr.c` / `book3s_pr_papr.c`, `kvmppc_copy_from_svcpu()` must return immediately if `!svcpu->in_use` before copying registers, adding timebase deltas, and clearing `svcpu->in_use`; `kvmppc_recalc_shadow_msr()` must run whenever guest MSR or `guest_owned_ext` changes; `kvmppc_unfixup_split_real()` must clear `SPLIT_HACK_MASK` and `BOOK3S_HFLAG_SPLIT_HACK` before `kvmppc_inject_interrupt_pr()`, `kvmppc_core_vcpu_put_pr()`, or leaving split-real mode; `kvmppc_set_pvr_pr()` must only overwrite `hior` when `!hior_explicit`; and `kvmppc_h_pr_bulk_remove()` must mask `tsh` with `H_BULK_REMOVE_TYPE` before testing `H_BULK_REMOVE_END` and `H_BULK_REMOVE_REQUEST`. [F71, F72, F73, F74, F119]
- In `book3s_paired_singles.c`, every opcode in `kvmppc_emulate_paired_single()` must be in `kvmppc_inst_is_paired_single()`, and single-precision ops must call `kvmppc_sync_qpr()`. In `booke.c`, `kvmppc_set_msr()` must be used for MSR changes beyond EE/CE/ME/DE/RI; `kvmppc_set_tcr()`/`set_tsr()`/`clr_tsr_bits()` must call `arm_next_watchdog()` and `update_timer_ints()` while guest `mtspr(SPRN_TCR)` preserves `TCR_WRC_MASK`; and `kvmppc_booke_irqprio_deliver()` must remap `BOOKE_IRQPRIO_EXTERNAL_LEVEL` to `EXTERNAL` (`keep_irq = true`) before `update_epr` and mask `crit_raw`/`crit_r1` to 32 bits when `!(msr & MSR_SF)`. [F79, F80, F81, F120, F122, F126]

## Synchronization
- In `book3s_hv_uvmem.c`, lock order is `kvm->srcu` -> `kvm->mm->mmap_lock` -> `kvm->arch.uvmem_lock` -> `kvmppc_uvmem_bitmap_lock`; `uvmem_lock` protects `uvmem_pfns` and `p->pfns[]`. In `kvmppc_share_page()`, drop `uvmem_lock` before `gfn_to_page()`, and before jumping to `retry:` hold `uvmem_lock`, call `kvm_release_page_unused(page)`, and set `pvt->skip_page_out = true` and `pvt->remove_gfn = false`. [F5, F27, F108]
- In `book3s_mmu_hpte.c`, `kvmppc_mmu_hpte_cache_map()` and `invalidate_pte()` must hold `vcpu3s->mmu_lock` while updating `hpte_cache_count` and all five `hpte_hash_*` lists in lockstep; readers use `hlist_for_each_entry_rcu()` under `rcu_read_lock()`, so `invalidate_pte()` must recheck `hlist_unhashed(&pte->list_pte)` under `mmu_lock`, unlink via `hlist_del_init_rcu()`, and free via `kfree_rcu()`. [F26, F70, F109]
- In `book3s_xics.c`, `kvmppc_xics_create_ics()` must order `ics` init with `smp_wmb()` under `kvm->lock` before setting `xics->ics[icsid]`; `arch_spin_lock(&ics->lock)` requires `local_irq_save()`/`restore()` with no user copies inside; `icp_try_update()` must only enqueue `BOOK3S_INTERRUPT_EXTERNAL`; and failed `icp_try_to_deliver()` in `icp_deliver_irq()` must set `state->resend = 1`, `smp_wmb()` (paired with `smp_rmb()` in `icp_check_resend()`), `set_bit(ics->icsid, icp->resend_map)`, `smp_mb()`, and retry if `!icp->state.need_resend`. [F19, F32, F33, F166]
- In XIVE, sleeping `xive->lock` ranks outside `arch_spin_lock(&sb->lock)`; `kvmppc_xive_create_src_block()` must order `sb->irq_state[]` init with `smp_wmb()` under `xive->lock` before setting `xive->src_blocks[bid]`; and `xive_check_provisioning()` must provision all vCPU queues and execute `mb()` under `xive->lock` before setting `xive->qmap |= (1 << prio)`. [F20, F21, F167]
- In `xive_vm_h_eoi()`, order `state->in_eoi = true` before `state->guest_priority` with `smp_mb()` and `mb()` after `xive_vm_source_eoi()` before `state->in_eoi = false`; `xive_lock_and_mask()` / `xive_lock_for_unmask()` spin under `sb->lock` until `!state->in_eoi`, and `xive_lock_and_mask()` must restore `state->guest_priority = old_prio` before dropping `sb->lock` to retry. [F34, F115]
- In `book3s_xive.c`, `xive_vm_h_ipi()` must execute `mb()` between writing `xc->mfrr` and reading `xc->cppr`, pairing with `smp_mb()` after `xc->cppr` updates in `xive_vm_h_cppr()` and `xive_vm_h_eoi()`; `xive_vm_ack_pending()` must bracket `__raw_readw(xive_tima + TM_SPC_ACK_OS_REG)` with `eieio()` and `mb()`; and `xive_vm_scan_interrupts()` must snapshot `READ_ONCE(q->qpage)` once. [F35, F36, F147]
- In single-escalation mode, `xive_cleanup_single_escalation()` must synchronize `xd->stale_p` and `vcpu->arch.xive_esc_on` with `smp_mb()` (paired with `smp_wmb()` in `xive_esc_irq()`) before `free_irq()`; `kvmppc_xive_push_vcpu()` must only clear `xive_esc_on` if `XIVE_ESB_SET_PQ_01` returns `!(pq & XIVE_ESB_VAL_P)`, and `kvmppc_xive_rearm_escalation()` must set `XIVE_ESB_SET_PQ_10` and return `false` if `xive_esc_on` is still set. [F23, F37]
- In `book3s_xive_native.c`, memslot calls (`kvm_host_page_size()`, `gfn_to_page()`, `mark_page_dirty()`) must hold `srcu_read_lock(&kvm->srcu)`, and `kvmppc_xive_native_release()` / `reset_mapped()` must hold `xive->mapping_lock` when clearing or unmapping `xive->mapping`. [F25, F155, F160]
- In `book3s_pr.c` and `book3s_paired_singles.c`, `svcpu` accesses require `svcpu_get()`/`svcpu_put()`, and `load_fp_state()`/`load_vr_state()` or host FP helpers (after `kvmppc_giveup_ext(vcpu, MSR_FP)`) require `preempt_disable()` and `enable_kernel_fp()`/`altivec()`. In `book3s_rtas.c`, `rtas_tokens` requires `rtas_token_lock` while `kvm_read_guest()` holds `kvm->srcu` outside it; in `book3s_pr_papr.c`, HPT hcalls require `hpt_mutex`. [F162, F163, F164, F173, F174]

## Object Lifetimes
- `kvmppc_get_secmem_size()` must call `of_node_put(np)` on `"ibm,uv-firmware"`; when secmem size is 0, `kvmppc_uvmem_init()` returns 0 with `kvmppc_uvmem_bitmap == NULL`, and `kvmppc_uvmem_free()` must return immediately if `!kvmppc_uvmem_bitmap` or else call `memunmap_pages(&kvmppc_uvmem_pgmap)` before `release_mem_region()` and `bitmap_free()`. `__kvmppc_uvmem_memslot_create()` and `delete()` must unwind `kvmppc_memslot_page_merge()`, `kvmppc_uvmem_slot_init()`, and `uv_register_mem_slot()` in reverse order. [F1, F2, F156, F157]
- Once `migrate_vma_setup(&mig)` succeeds in `__kvmppc_svm_page_out()` or `kvmppc_svm_page_in()`, every exit path must call `migrate_vma_finalize(&mig)`, and if `__kvmppc_svm_page_out()` aborts after `alloc_page_vma()` and `lock_page(dpage)`, it must `unlock_page(dpage)` and `__free_page(dpage)` before finalizing. [F3]
- `kvmppc_core_vcpu_create_pr()` must free `shared`, `shadow_vcpu`, and `vcpu_book3s` if `kvmppc_mmu_init_pr()` fails, and `kvmppc_core_vcpu_free_pr()` must call `kvmppc_mmu_destroy_pr()` first. Unmapped `kvmppc_mmu_hpte_cache_next()` entries must be freed via `kvmppc_mmu_hpte_cache_free()`. In `booke.c`, `kvmppc_core_vcpu_create()` must call `vcpu_free(vcpu)` if `kvmppc_core_vcpu_setup()` fails; `arm_next_watchdog()` must hold `wdt_lock` and call `mod_timer()` only when `nr_jiffies < TIMER_NEXT_MAX_DELTA` (else `timer_delete()`), and `kvmppc_subarch_vcpu_uninit()` must call `timer_delete_sync(&vcpu->arch.wdt_timer)`. [F6, F8, F18, F38, F125]
- In XICS/XIVE create callbacks, assign `kvm->arch.xics`/`xive` only after all fallible steps succeed; `kvmppc_xics_get_device()` and `kvmppc_xive_get_device()` must `memset` recycled structs to 0; and release callbacks must clean up all vCPUs under `vcpu->mutex` before clearing `kvm->arch.xics`/`xive` and freeing source blocks/`vp_base`, and must `kfree(dev)` without freeing the cached `xics`/`xive` struct. [F9, F10, F11, F51]
- In XIVE vCPU connect, call `xive_native_enable_vp()` before queue/escalation setup (skipping queue 7 when single escalation is enabled), and in `kvmppc_xive_native_connect_vcpu()` set `xive_vcpu = xc` and `irq_type = KVMPPC_IRQ_XIVE` before `bail:`. In vCPU cleanup, set `xc->valid = false`, call `kvmppc_xive_disable_vcpu_interrupts()`, free escalation IRQs (`free_irq()` before `irq_dispose_mapping()` and `kfree()`), call `xive_native_disable_vp()`, and zero `xive_cam_word` before freeing `q->qpage`. [F14, F15, F49, F152]
- In `kvmppc_xive_native_set_queue_config()`, validate queue size, alignment, and `(1ull << kvm_eq.qshift) <= kvm_host_page_size(vcpu, gfn)` before `gfn_to_page()`; `kvmppc_xive_native_configure_queue()` must `put_page(virt_to_page(qpage_prev))` on success while later errors call `kvmppc_xive_native_cleanup_queue()`. `kvmppc_xive_free_sources()` must never free passthrough IRQs (`state->pt_number`), and `xive_target_interrupt()` must call `xive_inc_q_pending()` on the old queue when `state->act_priority != MASKED`. [F12, F16, F17, F97]

## API Contracts
- In `book3s_hv_uvmem.c`, `kvmppc_send_page_to_uv()` returns `RESUME_GUEST` (0) or `-EFAULT`; `uv_page_in()`/`out()` take byte addresses (`pfn << page_shift`, `gpa`) while `kvmppc_gfn_*` helpers take frame numbers; `kvmppc_uvmem_bitmap` is indexed by `pfn - (kvmppc_uvmem_pgmap.range.start >> PAGE_SHIFT)`; `__kvmppc_svm_page_out()` must set `mig.pgmap_owner = &kvmppc_uvmem_pgmap` and `dst_pfn = 0` before `migrate_vma_setup(&mig)`; and `kvmppc_memslot_page_merge()` must hold `mmap_write_lock` and `vma_start_write(vma)` and pass a local `vm_flags` copy to `ksm_madvise()`. [F40, F41, F42, F43, F177]
- In `book3s_xive.c`, `xive_native_configure_queue()` takes byte shift `xive->q_order` while `__get_free_pages()`/`free_pages()` take page order `xive->q_page_order` (clamped to 0 when `q_order < PAGE_SHIFT`). `kvmppc_xive_push_vcpu()` and `pull_vcpu()` must only access `tima + TM_QW1_OS` when `!kvmppc_xive_vcpu_has_save_restore(vcpu)` (after reading `TM_SPC_PULL_OS_CTX` on pull). [F52, F131, F150]
- `kvmppc_giveup_fac()`/`handle_fac()`/`trigger_fac_interrupt()` take bit numbers (`FSCR_*_LG`); `kvmppc_h_pr_*` handlers write `H_*` to GPR3 and return `EMULATE_DONE` (or `EMULATE_FAIL` without writing GPR3); `kvmppc_ld()`/`st()` callers in `book3s_paired_singles.c` must call `kvmppc_inject_pf()` on `< 0`, handle `EMULATE_DO_MMIO`, and update `RA` only on `EMULATE_DONE`; and `kvmppc_prepare_to_enter()` is only called when `!(r & RESUME_HOST)` (encoding `(s << 2) | RESUME_HOST | (r & RESUME_FLAG_NV)` in `booke.c` when `s <= 0`). [F56, F58, F59, F60, F121]

## Error Handling
- Check `gfn_to_hva()` with `kvm_is_error_hva(hva)`; initialize and compare `xive->vp_base` against `XIVE_INVALID_VP` (`0xffffffff`); and in `kvmppc_xics_set_icp()`, zero `new_state.raw` before setting fields and keep `pending_pri == 0xff` whenever `xisr == 0` (including in `kvmppc_xive_get_icp()`). [F39, F47, F54, F88]

## External Contracts
- In `kvmppc_rtas_hcall()`, verify `be32_to_cpu(args.nargs) < ARRAY_SIZE(args.args)` before setting `args.rets = &args.args[be32_to_cpu(args.nargs)]`, restore `args.rets = orig_rets` before `kvm_write_guest()`, check exact `nargs`/`nret` in every handler before accessing `args[]`/`rets[1..]`, and match token names via `rtas_name_matches()` (`strncmp`). `kvmppc_h_svm_page_in()`/`out()` require `page_shift == PAGE_SHIFT`, valid flags, and `[start, end)` within one VMA. [F53, F84, F101, F139]

## Known Pitfalls
- In `book3s_hv_uvmem.c`, allocate `p->pfns` with `vcalloc()` (not `kvcalloc`/`kvzalloc`) and save matched `list_for_each_entry()` nodes in a `NULL`-initialized pointer in `kvmppc_next_nontransitioned_gfn()`. In XICS/XIVE, widen `prio` to `u64` before `<< KVM_XICS_PRIORITY_SHIFT` (32), index `xc->queues[j]` by inner index `j` in nested vCPU/queue loops, read `TM_PIPR` via 64-bit `__raw_readq(xive_tima + TM_QW1_OS)` in `xive_vm_h_ipoll()`, and in `xive_vm_esb_load()` OR `XIVE_ESB_LD_ST_MO` into `XIVE_ESB_SET_PQ_10` for `XIVE_IRQ_FLAG_STORE_EOI` and shift `__raw_readq()` right by 56 on `__LITTLE_ENDIAN__`. [F106, F110, F128, F135, F146, F148]
- In `book3s_pr.c` / `book3s_pr_papr.c`, truncate `magic_page_pa` to `uint32_t` when `!(msr & MSR_SF)`, and in `kvmppc_h_pr_enter()` advance `__be64 *hpte` by `i * 2` and `pteg_addr` by `i * HPTE_SIZE` (16). In `booke.c`, use `1ULL << (63 - period)`, `do_div()`, and `min_t(unsigned long long, ..., TIMER_NEXT_MAX_DELTA)` in `watchdog_next_timeout()`, and use bitwise `~` and separate `b++`/`w++` counters in `kvm_arch_vcpu_ioctl_set_guest_debug()`. [F104, F111, F123, F124, F140]
