# NVM EXPRESS TARGET DRIVER

`drivers/nvme/target` implements the Linux NVMe Target (`nvmet`) subsystem, managing target subsystems, controllers, queues, namespaces, ANA groups, discovery services, persistent reservations, and tracepoints via configfs and debugfs across loopback (`nvme-loop`), PCI Endpoint Function (`nvmet-pci-epf`), RDMA (`nvmet-rdma`), and TCP (`nvmet-tcp`) transports.

## Architecture & Data Flow

- Before Fabrics Connect binds a queue, `req->sq->ctrl` is `NULL` and `req->sq->size == 0`; `nvmet_req_init()`, `nvmet_req_transfer_len()`, `nvmet_set_error()`, and trace helpers (`nvmet_req_to_ctrl_id()`, `__assign_req_name()`) must null-check `req->sq->ctrl` (and `req->ns`), `nvmet_update_sq_head()` must guard `(old_sqhd + 1) % req->sq->size` with `if (req->sq->size)`, and `nvmet_rdma_error_comp()` / `nvmet_tcp_fatal_error()` must disconnect or shut down the socket directly when `ctrl` is `NULL`. [F50, F127, F242, F347]
- In `nvmet_parse_admin_cmd()` and `nvmet_admin_cmd_data_len()`, `nvme_is_fabrics(cmd)` and `nvmet_is_disc_subsys()` must precede `nvmet_check_ctrl_status()` and `nvmet_is_passthru_req()`; in `nvmet_parse_io_cmd()`, `nvme_is_fabrics(cmd)` must precede `nvmet_check_auth_status()` and `nvmet_is_passthru_req()` must precede `nvmet_req_find_ns()`; and in `trace.h`, `parse_nvme_cmd()` must check `opcode == nvme_fabrics_command` before branching on `qid`. [F101, F102, F281]
- In `struct nvmet_ns`, `ns->bdev` is `NULL` when file-backed or `ns->buffered_io` is set (`ns->file != NULL`), so shared helpers must check `ns->bdev` before dereferencing it or `nvmet_ns_dev(ns)`, and file I/O handlers must check that offset plus length does not exceed `req->ns->size` (`-ENOSPC`). [F48, F87]
- Every non-reservation I/O opcode must be classified in `nvmet_is_req_write_cmd_group()` or `nvmet_is_req_read_cmd_group()` in `pr.c` so `nvmet_pr_check_cmd_access()` enforces reservation conflicts. In `nvmet_pr_preempt()`, `original_rtype` must be sampled from `holder->rtype` and `nvmet_pr_set_new_holder()` must update `pr->holder` before `nvmet_pr_unreg_all_others*()` calls `nvmet_pr_unregister_one()`. [F72, F80]
- In `nvmet_set_feat_kato()`, `nvmet_stop_keep_alive_timer()` must be called before overwriting `req->sq->ctrl->kato` and `nvmet_start_keep_alive_timer()` after, because `nvmet_stop_keep_alive_timer()` returns early without cancelling `ctrl->ka_work` when `ctrl->kato == 0`. [F71]
- In `rdma.c`, when `nvmet_rdma_read_data_done()` or `nvmet_rdma_write_data_done()` refunds `rsp->n_rdma` to `queue->sq_wr_avail` and calls `nvmet_rdma_rw_ctx_destroy(rsp)`, it must reset `rsp->n_rdma = 0` before `nvmet_rdma_release_rsp(rsp)`. Recycled responses in `nvmet_rdma_recv_done()` must clear `flags`, `n_rdma`, and `invalidate_rkey` to 0, and `nvmet_rdma_queue_response()` must reset `rsp->send_wr.opcode = IB_WR_SEND` when `!rsp->invalidate_rkey`. [F202, F256]
- In `rdma.c`, `cm_id->context` always points to `struct nvmet_rdma_port` while `struct nvmet_rdma_queue *` is in `cm_id->qp->qp_context`; on `RDMA_CM_EVENT_ADDR_CHANGE` in `nvmet_rdma_cm_handler()`, `if (!queue)` must schedule `port->repair_work` and `break` before `nvmet_rdma_queue_disconnect(queue)`. Even when `nvmet_rdma_use_srq` is true, `ndev->srqs` is `NULL` if the device lacks SRQ support, so code must test `ndev->srqs`, `queue->nsrq`, or `cmd->nsrq`. [F243, F288, F313]
- In `tcp.c`, `nvme_tcp_pdu_sizes[]`, `nvmet_tcp_pdu_valid()`, and `nvmet_tcp_done_recv_pdu()` must be updated in lockstep, and `nvmet_tcp_try_recv_pdu()` must validate `hdr->type` and `hdr->hlen == nvmet_tcp_pdu_size(hdr->type)` before computing `queue->left`. `nvmet_tcp_handle_h2c_data_pdu()` must subtract `sizeof(*data)` and header/data digest lengths when computing `exp_data_len` and verify `cmd->pdu_len` (`> 0`, `== exp_data_len`, `<= NVMET_TCP_MAXH2CDATA`) and `data_offset == cmd->rbytes_done` before `nvmet_tcp_build_pdu_iovec()`. [F261, F262, F263, F266]
- In `nvmet_tcp_try_send_one()` and `nvmet_tcp_try_recv_one()`, phase checks on `cmd->state` and `queue->rcv_state` must remain sequential `if` statements (not `else if` or `switch`). In `nvmet_tcp_io_work()`, the loop must return immediately without requeuing `io_work` on `ret < 0`, and requeue `io_work` if `pending` is true when `ops >= NVMET_TCP_IO_WORK_BUDGET` or `nvmet_tcp_check_queue_deadline()` (`!time_after(jiffies, queue->poll_end)`) triggers. [F295, F296, F302]

## Synchronization

- The lock hierarchy is `nvmet_config_sem` -> `subsys->lock` -> `ctrl->lock` (and `ns->pr.pr_sem` -> `subsys->lock` -> `ctrl->pr_log_mgr.lock` / `ctrl->lock`). `nvmet_config_sem` protects `nvmet_transports`, `nvmet_genctr`, `nvmet_disc_subsys->subsysnqn`, `port->subsystems`, `port->referrals`, `subsys->hosts`, and `subsys->allow_any_host` (mutations must call `nvmet_port_disc_changed()` or `nvmet_subsys_disc_changed()`); `nvmet_ana_sem` protects `nvmet_ana_group_enabled[]`, `nvmet_ana_chgcnt`, `port->ana_state[]`, and `ns->anagrpid`. [F29, F31, F35, F69, F70]
- `nvmet_req_init()` and synchronous parse helpers (`nvmet_parse_io_cmd()`, `nvmet_req_find_ns()`, `nvmet_pr_check_cmd_access()`, `nvmet_pr_get_ns_pc_ref()`) can run under `rcu_read_lock()` from `nvme_loop_queue_rq()`, and `nvmet_req_complete()`, `__nvmet_req_complete()`, and `req->ops->queue_response` can run in IRQ/softirq or RCU context, so none of them may sleep or do blocking allocations; in `nvmet_async_events_process()` and `nvmet_async_events_failall()`, `ctrl->lock` must be dropped before `nvmet_req_complete()`. [F36, F162, F163]
- `nvmet_ns_enable()` must initialize device state, P2P mappings, `nvmet_pr_init_ns()`, and `ns->ref` under `subsys->lock` before setting `ns->enabled` and `NVMET_NS_ENABLED`. `nvmet_ns_disable()` clears `ns->enabled`, `NVMET_NS_ENABLED`, and `ctrl->p2p_ns_map` under `subsys->lock`, then unlocks it before `percpu_ref_kill(&ns->ref)`, `synchronize_rcu()`, `wait_for_completion(&ns->disable_done)`, and `percpu_ref_exit(&ns->ref)` (before `nvmet_pr_exit_ns()` and `nvmet_ns_dev_disable()`), with configfs holding `down_write(&nvmet_config_sem)`. [F20, F22, F68, F171]
- In `pr.c`, `ns->pr.holder` and `ns->pr.registrant_list` are read under `rcu_read_lock()` and mutated under `ns->pr.pr_sem` using RCU primitives (`rcu_assign_pointer()`, `list_*_rcu()`, `kfree_rcu()`); when `nvmet_execute_pr_acquire()` queues `req->r.abort_work` for `NVME_PR_ACQUIRE_ACT_PREEMPT_AND_ABORT`, `pr_sem` must remain held and be released by `nvmet_pr_do_abort()` after `pc_ref` drains and resurrects (`reinit_completion()` on `confirm_done` and `free_done` before `percpu_ref_resurrect()`). [F33, F73, F173]
- In `rdma.c`, `nvmet_rdma_recv_not_live()` and `nvmet_rdma_queue_established()` must use `spin_lock_irqsave(&queue->state_lock, flags)` and drop `state_lock` before `nvmet_rdma_handle_command()`; `queue->rsp_wr_wait_list` must be protected by `rsp_wr_wait_lock` and dropped before `nvmet_rdma_execute_command()`; `nvmet_rdma_find_get_device()` must use `kref_get_unless_zero(&ndev->ref)` under `device_list_mutex`; and removals from `nvmet_rdma_queue_list` must hold `nvmet_rdma_queue_mutex`, use `list_for_each_entry_safe()`, and call `list_del_init()`. [F223, F229, F231, F286, F330]
- In `tcp.c`, `sk->sk_user_data` and socket callbacks are protected by `read_lock_bh` / `write_lock_bh(&sk->sk_callback_lock)` (`sk_state == TCP_ESTABLISHED` checked under `write_lock_bh` in `nvmet_tcp_set_queue_sock()`). `queue->state_lock` must use `spin_lock_bh()` nested inside `sk_callback_lock`, and `nvmet_tcp_schedule_release_queue()` must set `NVMET_TCP_Q_DISCONNECTING` under `state_lock` before `kref_put(&queue->kref, nvmet_tcp_release_queue)` (which runs in BH context and must defer teardown to `queue->release_work`). [F219, F220, F337, F338, F339]
- In `tcp.c`, `nvmet_prepare_receive_pdu()` must clear `WRITE_ONCE(queue->cmd, NULL)` before `smp_store_release(&queue->rcv_state, NVMET_TCP_RECV_PDU)`, pairing with `smp_load_acquire(&queue->rcv_state)` before `READ_ONCE(queue->cmd)` in `nvmet_tcp_queue_response()`. Cross-CPU completions use `llist_add()` on `queue->resp_list`, while `resp_send_list` and `free_list` are modified only from `queue->io_work`; callers iterating `nvmet_tcp_queue_list` must only call `kernel_sock_shutdown()` and let `nvmet_tcp_release_queue_work()` unlink `queue->queue_list`. [F287, F341, F342]

## Object Lifetimes

- `nvmet_req_complete()` must save `req->sq` into a local pointer before calling `__nvmet_req_complete(req, status)` and pass that saved pointer to `percpu_ref_put(&sq->ref)`, because `req->ops->queue_response(req)` inside `__nvmet_req_complete()` may free `req`. [F3]
- In `nvmet_sq_destroy()`, if `ctrl->sqs[0] == sq`, `nvmet_async_events_failall(ctrl)` must be called before killing `sq->ref` and waiting on `sq->confirm_done` and `sq->free_done`; after `wait_for_completion(&sq->free_done)`, `ctrl = sq->ctrl` must be re-read before clearing `ctrl->sqs[sq->qid] = NULL`, `sq->ctrl = NULL`, and calling `nvmet_ctrl_put(ctrl)`. [F5, F23]
- In `nvmet_alloc_ctrl()`, once `ctrl` is added to `subsys->ctrls` under `subsys->lock`, any later failure must tear down `ctrl` via `nvmet_ctrl_put(ctrl)`. In `nvmet_ctrl_free()`, after removing `ctrl` from `subsys->ctrls`, `nvmet_stop_keep_alive_timer(ctrl)`, `flush_work(&ctrl->async_event_work)`, and `cancel_work_sync(&ctrl->fatal_err_work)` must complete before freeing async events, queue arrays, or `ctrl`. [F11, F24]
- `nvmet_req_bio_put()` must call `bio_uninit(bio)` when `bio == &req->b.inline_bio` (`inline_bio` must remain first in `req->b`, `req->p`, `req->z`) and `bio_put(bio)` otherwise. In `io-cmd-file.c`, `req->f.bvec` must only be freed when `req->f.bvec != req->inline_bvec`, using `mempool_free()` when `req->f.mpool_alloc` is true and `kfree()` otherwise; `nvmet_file_ns_disable()` must call `flush_workqueue(buffered_io_wq)` when `ns->buffered_io` is set before destroying `ns->bvec_pool` and closing `ns->file`. [F7, F13, F25, F141]
- `nvmet_req_alloc_sgls()` sets `req->p2p_dev` only after `nvmet_req_alloc_p2pmem_sgls()` succeeds, and `nvmet_req_free_sgls()` must free `sg` and `metadata_sg` with `pci_p2pmem_free_sgl()` when `req->p2p_dev` is non-NULL and `sgl_free()` otherwise. `nvmet_copy_to_sgl()` does not take ownership of its buffer, so callers that `kzalloc()` a temporary buffer must `kfree()` it before `nvmet_req_complete()`. [F14, F16]
- In `rdma.c`, queue disconnect/fail in `nvmet_rdma_cm_handler()` must never call `rdma_destroy_id(queue->cm_id)` directly (deferring to `queue->release_work` on `nvmet_wq`, flushed in `nvmet_rdma_remove_one()`), and `nvmet_rdma_free_queue()` must call `ib_drain_qp(queue->qp)` before destroying CM/QP/CQ, freeing cmds/rsps, and dropping `dev->ref`. In `nvmet_rdma_release_rsp()`, `nvmet_req_free_sgls(&rsp->req)` must only run when `rsp->req.sg != rsp->cmd->inline_sg`, and `nvmet_rdma_put_rsp()` requires `rsp->queue` to be set. [F201, F203, F204, F205, F227, F331]
- In `tcp.c`, `nvmet_tcp_alloc_queue()` must unconditionally initialize `tls_handshake_tmo_work`, `release_work`, and `io_work`, and after `sock_alloc_file()` runs, cleanup must use `fput(queue->sock->file)` instead of `sock_release()`. In `nvmet_tcp_release_queue_work()`, `nvmet_tcp_uninit_data_in_cmds()` must run between the first `cancel_work_sync(&queue->io_work)` and `nvmet_sq_destroy()`, followed by a second `cancel_work_sync(&queue->io_work)` before freeing buffers, `sock->file`, and `cmds`. [F209, F210, F217]
- In `tcp.c`, before `nvmet_tcp_install_queue()` succeeds (or if `nvmet_tcp_alloc_cmds()` fails), `queue->nr_cmds` must be 0 so `queue->connect` is used; `nvmet_tcp_put_cmd()` must never put `queue->connect` onto `free_list`, `nvmet_tcp_free_cmds()` and `nvmet_tcp_free_cmd_data_in_buffers()` must clean up both `cmds` and `connect`, and `nvmet_tcp_free_cmd_buffers()` must null out `cmd->iov` and `cmd->req.sg`. In `nvmet_tcp_tls_handshake()`, the extra `queue->kref` is dropped on completion or on timeout only if `tls_handshake_cancel()` returns `true`. [F208, F211, F212, F238]

## API Contracts

- When `nvmet_req_init()` returns `false`, it has already called `__nvmet_req_complete()` without taking `sq->ref`, so callers must not call `nvmet_req_complete()` or `nvmet_req_uninit()`, whereas failures after it returns `true` must call one of them. `nvmet_check_transfer_len()` and `nvmet_check_data_len_lte()` also call `nvmet_req_complete()` on `false`, so callers must invoke them before allocating per-command resources and return immediately on `false`. [F4, F42]
- Before `nvmet_req_alloc_sgls(req)`, `req->transfer_len` must be set to total transfer length including `req->metadata_len`. `nvmet_copy_to_sgl()` / `nvmet_copy_from_sgl()` require a kernel virtual address buffer (never `ZERO_PAGE(0)`; use `nvmet_zero_sgl()`). Internal NVMe status codes (`u16 status`) are unshifted: CQE/error-slot writers (`nvmet_set_error()`, `nvmet_pci_epf_cq_work()`) shift left by 1 and `nvmet_pci_epf_queue_response()` shifts right by 1. [F57, F176, F184]

## Error Handling

- In `nvmet_req_init()`, `req->cqe->result.u64`, `req->cqe->status`, `req->cqe->sq_head`, `req->ns`, `req->pc_ref`, `req->error_loc`, and `req->error_slba` must be initialized before any `goto fail`. When `nvmet_req_find_ns()` finds `!ns->enabled`, it must reset `req->ns = NULL` before returning `NVME_SC_INTERNAL_PATH_ERROR`, and `IS_ERR()` results from `bdev_file_open_by_path()`, `filp_open()`, or `key_lookup()` must reset `ns->bdev_file`, `ns->file`, or `port->keyring` to `NULL`. [F51, F52, F54]
- In `tcp.c`, if `nvmet_req_init()` fails on an inline-write command in `nvmet_tcp_done_recv_pdu()`, `nvmet_tcp_queue_response()` defers queuing `cmd` while `rcv_state == NVMET_TCP_RECV_PDU` and `nvmet_tcp_handle_req_failure()` sets `NVMET_TCP_F_INIT_FAILED` and maps a drain buffer (checking `sgl.length` directly, not `nvmet_tcp_has_inline_data()`). If `nvmet_tcp_map_data()` fails without inline data, it must complete `req`, reset PDU state, and return `-EAGAIN`; errors in `nvmet_tcp_handle_h2c_data_pdu()` must call `nvmet_tcp_fatal_error()` and return `-EPROTO`. [F207, F237, F239, F294]

## Known Pitfalls

- `nvmet_execute_admin/io_connect()` must NUL-terminate `d->subsysnqn[NVMF_NQN_FIELD_LEN - 1]` and `d->hostnqn[NVMF_NQN_FIELD_LEN - 1]`. In `nvmet_execute_pr_report()`, `registrant_list` iteration must increment `num_ctrls` for all registrants while guarding `ctrl_eds` writes with `(void *)ctrl_eds + sizeof(*ctrl_eds) <= (void *)data + num_bytes`, and multi-registrant unregistration loops must use `list_for_each_entry_safe()` and copy `reg->hostid` before `nvmet_pr_unregister_one()`. [F85, F96, F109, F136]
- In `tcp.c`, `nvmet_tcp_handle_icreq()` must read `icreq` before `memset(icresp, 0, sizeof(*icresp))` (aliased in `queue->pdu`), and `nvmet_tcp_verify_hdgst()` must read `recv_digest` at `pdu + hdr->hlen` before `nvmet_tcp_hdgst()` overwrites it. [F241, F251]
