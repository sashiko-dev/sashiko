# EXT4 FILE SYSTEM

This unit implements the ext4 filesystem: superblock and mount lifecycle, multi-block allocation (`mballoc`), HTree and casefolded directories, extent migration/defragmentation, orphan tracking, MMP, buffered read/writeback I/O with fscrypt and fs-verity, online resize, xattrs, sysfs/procfs interfaces, UAPI ioctls, and ftrace instrumentation.

## Architecture & Data Flow
- In `mb_set_largest_free_order()`, when `grp->bb_largest_free_order` changes from `old >= 0`, erase `grp->bb_group` from `sbi->s_mb_largest_free_orders[old]` unconditionally (even if `MB_OPTIMIZE_SCAN` is clear); in `mb_update_avg_fragment_size()`, when `grp->bb_fragments == 0`, set `new = -1`, erase from `s_mb_avg_fragment_size[old]`, and set `grp->bb_avg_fragment_size_order = -1`. [F72, F73]
- Per-order arrays (`s_mb_largest_free_orders`, `s_mb_avg_fragment_size`, `s_mb_offsets`, `s_mb_maxs`, `bb_counters`) have `MB_NUM_ORDERS(sb)` (`s_blocksize_bits + 2`) elements; clamp any cluster-length order below `MB_NUM_ORDERS(sb)` before indexing, and check `bb_fragments != 0` before dividing `bb_free / bb_fragments`. [F100, F152, F160]
- In `mb_free_blocks()`, update `bb_free`, `bb_first_free`, and `bb_fragments` only after `mb_test_and_clear_bits()` returns `-1`. When freeing clusters in `ext4_free_data_in_buddy()` or `ext4_mb_clear_bb()`, call `EXT4_MB_GRP_CLEAR_TRIMMED()` unconditionally; if `(block, count)` is adjusted for partial clusters or split across a group boundary (`do_more:`), clear `EXT4_FREE_BLOCKS_VALIDATED` from `flags`. [F74, F75, F127]
- Orphan inodes may use either the orphan file (`EXT4_STATE_ORPHAN_FILE`) or `sbi->s_orphan`; always test `ext4_inode_orphan_tracked(inode)` rather than `list_empty(&ei->i_orphan)`. When dropping `i_nlink` on a failed new inode before `ext4_orphan_add()`, call `ext4_mark_inode_dirty()` because `ext4_orphan_file_add()` only journals the orphan block. [F83, F85]
- For in-inode xattrs, `e_value_offs` and `s->base` are relative to `IFIRST(header)`, whereas for block xattrs they are relative to `BHDR(bh)`. `ext4_expand_extra_isize_ea()` must shift in-inode xattrs and adjust non-external `e_value_offs` via `ext4_xattr_shift_entries()`, while `ext4_xattr_make_inode_space()` must never move `system.data` to an external block. [F293, F359, F404]

## Synchronization
- Lock ordering in `mballoc.c`: `s_buddy_cache` folio locks nest outside `ext4_lock_group(sb, group)`, which nests outside `ei->i_prealloc_lock` and `lg->lg_prealloc_lock`. Never call `ext4_mb_load_buddy*()`, `ext4_mb_init_group()`, or `ext4_mb_init_cache()` while holding `ext4_lock_group()`, and never acquire `ext4_lock_group()` while holding `i_prealloc_lock` or `lg_prealloc_lock`. Inside `mb_set_largest_free_order()` and `mb_update_avg_fragment_size()` (under `ext4_lock_group()`), `xa_insert()` must use `GFP_ATOMIC` without `__GFP_NOFAIL`. [F37, F179, F181]
- For `MB_GROUP_PA`, `ext4_mb_use_group_pa()` must not advance `pa_pstart`, `pa_lstart`, `pa_free`, or `pa_len`; update them only in `ext4_mb_release_context()` under `pa->pa_lock` after `ext4_mb_mark_diskspace_used()`. For `MB_INODE_PA` in `ext4_mb_use_preallocated()`, hold `tmp_pa->pa_lock` continuously across `pa_deleted == 0`, range checks, `atomic_inc(&tmp_pa->pa_count)`, and `ext4_mb_use_inode_pa()`. Accessing `grp->bb_prealloc_list` requires `ext4_lock_group(sb, group)`. [F40, F41, F42]
- When searching `ei->i_prealloc_node` (`ext4_mb_use_preallocated()`, `ext4_mb_pa_adjust_overlap()`), descend by immutable `pa_lstart` without checking `pa_deleted`, then walk `rb_prev()` / `rb_next()` past entries with `pa_deleted != 0`. In `ext4_discard_preallocations()`, if `pa_count != 0` or `pa_deleted != 0`, drop `pa_lock` and `i_prealloc_lock`, sleep, and restart from `rb_first()`. [F123, F124, F125]
- Lock two inodes' `i_data_sem` (`ext4_double_down_write_data_sem()`) or two folios (`mext_folio_double_lock()`) in ascending `struct inode *` pointer order (swapping `folio[0]` and `folio[1]` back afterward if `inode1 > inode2`). `ext4_move_extents()` must drop `i_data_sem` before `move_extent_per_page()`, and if `unwritten` was true, reacquire `i_data_sem` under folio locks and recheck `mext_check_coverage()`. [F16, F32, F33]
- In `ext4_end_bio()`, `ext4_put_io_end_defer()`, and `ext4_put_io_end()`, use `ext4_io_end_defer_completion(io_end)` consistently: when true, `ext4_end_bio()` atomically chains `bio` via `xchg(&io_end->bio, bio)` before `ext4_put_io_end_defer(io_end)`; when false, call `ext4_put_io_end_defer(io_end)` before `ext4_finish_bio(bio)`. Serialize `i_rsv_conversion_list` under `spin_lock_irqsave(&ei->i_completed_io_lock, flags)`, and folio buffer `BH_Async_Write` updates under `spin_lock_irqsave(&head->b_uptodate_lock, flags)`. [F29, F30, F31, F94]
- In `ext4_xattr_set_handle()`, after acquiring `ext4_write_lock_xattr()`, re-read the xattr block via `ext4_xattr_get_block()` and reverify `jbd2_handle_buffer_credits(handle) >= credits`. Before modifying (`h_refcount == 1`) or freeing an xattr block, remove its `ea_block_cache` entry via `mb_cache_entry_delete_or_get()` under `lock_buffer(bh)`. In `ext4_xattr_block_set()`, call `ext4_xattr_inode_lookup_create()` before `lock_buffer(bs->bh)`. [F256, F259, F298]
- RCU-protected superblock arrays (`s_group_info`, `s_group_desc`, `s_flex_groups`, `s_qf_names[]`) must be populated before `rcu_assign_pointer()`, read under `rcu_read_lock()` (or `sbi_array_rcu_deref`), and freed via `ext4_kvfree_array_rcu()` or `kfree_rcu_mightsleep()`. In `ext4_update_super()` (`resize.c`), issue `smp_wmb()` before incrementing `sbi->s_groups_count` (pairing with `smp_rmb()` in `ext4_get_groups_count()`). [F47, F243, F248, F375]
- In `__ext4_grp_locked_error()`, when `!test_opt(sb, ERRORS_CONT)`, drop `ext4_unlock_group(sb, grp)` around `ext4_handle_error()`; under `ERRORS_CONT`, defer superblock flush to `s_sb_upd_work`. `ext4_handle_error()` must set `EXT4_FLAGS_EMERGENCY_RO` (never `SB_RDONLY`), suppress `ERRORS_PANIC` if `system_going_down()`, and only queue `s_sb_upd_work` when `continue_fs && journal && !ext4_test_mount_flag(sb, EXT4_MF_JOURNAL_DESTROY)`. [F240, F244, F398]
- Tracepoints `ext4__es_extent`, `ext4_es_find_extent_range_exit`, `ext4_es_lookup_extent_exit`, and `ext4_es_insert_delayed_extent` run outside `i_es_lock` and require a caller-private `struct extent_status` snapshot (zero-initialized on lookup miss). Tracepoints under `i_block_reservation_lock` (`ext4_da_*_space`), `ext4_lock_group` (`ext4__mb_new_pa`, `ext4_mb_release_*_pa`, `ext4_mballoc_discard`), or `i_lock` (`ext4_drop_inode`) must never sleep. [F408, F413, F445, F446, F447]

## Object Lifetimes
- When `ext4_mb_free_metadata()` inserts the first entry into an empty `db->bb_free_root` (`!*n`), it pins `bd_buddy_folio` and `bd_bitmap_folio` with `folio_get()`, which `ext4_free_data_in_buddy()` drops with `folio_put()` when `rb_erase()` empties `bb_free_root`. `ext4_mb_use_best_found()` also pins both folios in `ac` until `ext4_mb_release_context()` (after `ext4_mb_mark_diskspace_used()`). [F20, F38]
- `MB_GROUP_PA` objects on `lg_prealloc_list` are unlinked via `list_del_rcu()` and freed via `call_rcu(&pa->u.pa_rcu, ext4_mb_pa_callback)` after unlinking `u.pa_tmp_list` (which shares union `u`), whereas `MB_INODE_PA` is freed via `ext4_mb_pa_free()`. On unmount/exit, `ext4_mb_release()` must `flush_work(&sbi->s_discard_work)` before freeing `s_group_info` or `s_buddy_cache`, and `ext4_exit_mballoc()` and `destroy_inodecache()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F24, F45, F170, F260]
- Before `ext4_release_io_end()`, `ext4_end_io_end()` must clear `io_end->handle = NULL`, consume the reserved handle via `jbd2_journal_free_reserved()` (on `EXT4_IO_END_FAILED`) or `ext4_convert_unwritten_io_end_vec()`, and call `ext4_clear_io_unwritten_flag()`. In `ext4_finish_bio()`, when `fscrypt_is_bounce_folio(folio)` is true, update buffer flags and `folio_end_writeback()` on `fscrypt_pagecache_folio(folio)` and call `fscrypt_free_bounce_page()` only when `!under_io`. [F7, F202]
- `ext4_mark_iloc_dirty()` unconditionally consumes `iloc.bh` (even on error), so callers that skip it (`ext4_orphan_add()` / `ext4_orphan_del()`) must call `brelse(iloc.bh)`, while callers with a shared `brelse(iloc.bh)` cleanup (`ext4_xattr_set_handle()`, `add_new_gdb()`) must set `iloc.bh = NULL` after calling it. [F11, F230]
- In `ext4_xattr_inode_cache_find()` and `ext4_xattr_block_cache_find()`, `mb_cache_entry_find_next()` consumes `ce`, while early loop returns must call `mb_cache_entry_put(ea_block_cache, ce)`. After `ext4_xattr_inode_lookup_create()` succeeds, callers must `iput(ea_inode)` and on error also call `ext4_xattr_inode_dec_ref()` and `ext4_xattr_inode_free_quota()`. [F231, F232, F340]

## API Contracts
- On success, `ext4_add_nondir()` consumes `*inodep` via `d_instantiate_new()` and sets `*inodep = NULL`; on failure, it drops `i_nlink`, adds the inode to the orphan list, unlocks it, and leaves `*inodep` non-NULL for the caller to `iput(*inodep)` after `ext4_journal_stop()`. [F1]
- `make_indexed_dir()` always consumes the caller's `bh` reference, so callers must set `bh = NULL`. `do_split()` takes `struct buffer_head **bh`, may swap `*bh` with `bh2` on success, and on failure releases `*bh` (and `bh2`), sets `*bh = NULL`, and returns an `ERR_PTR`. In `dx_release()`, copy `info->indirect_levels` to a local variable before `brelse(frames[0].bh)` frees the buffer backing `info`. [F2, F3, F133]
- `__ext4_read_dirblock()` returns `ERR_PTR` on error (or any hole when `type` is `INDEX`, `DIRENT_HTREE`, or `block == 0`), but returns `NULL` for an unmapped hole at `block > 0` with `EITHER` or `DIRENT`. Unlike `sb_bread()`, `ext4_sb_bread*()` never returns `NULL` (always `ERR_PTR(-errno)`), whereas `ext4_bread()` and `ext4_getblk()` return `ERR_PTR(-errno)` on error and `NULL` for an unmapped hole. [F57, F70, F261, F262]
- `ext4_mb_new_blocks()` and `ext4_mb_new_blocks_simple()` return physical block (`0` on failure), set `ar->len` (`0` on failure), and require every return path to assign `*errp`. `ext4_mb_get_buddy_page_lock()` leaves `e4b->bd_buddy_folio == NULL` when `PAGE_SIZE / sb->s_blocksize >= 2`, so callers must NULL-check `bd_buddy_folio`. `ext4_mb_mark_context()` sets `*ret_changed`; callers must skip in-core buddy/counter updates only when `err && changed == 0`. [F50, F54, F55]
- In `struct ext4_free_extent` and `struct ext4_prealloc_space`, `fe_logical` and `pa_lstart` are in blocks (`ext4_lblk_t`) and `pa_pstart` is in physical blocks (`ext4_fsblk_t`), whereas `fe_start`, `fe_len`, `pa_len`, and `pa_free` are in clusters (`ext4_grpblk_t`) requiring `EXT4_C2B()` / `EXT4_NUM_B2C()` conversion. Use `mb_*_bit()` wrappers rather than `ext4_*_bit()` on buddy bitmaps because `mb_find_buddy()` returns byte-aligned pointers. [F56, F159]
- `__ext4_error*`, `save_error_info`, `ext4_error_err`, `EXT4_ERROR_INODE_ERR`, and `ext4_abort` take a positive `errno` (or `0` for `EFSCORRUPTED`), whereas `ext4_decode_error` and `__ext4_std_error` take a negative `-errno`. `ext4_journal_ensure_credits_fn()` returns `< 0` on error, `0` if unchanged/extended, and `1` if the transaction restarted (requiring callers to re-call `ext4_journal_get_write_access()` on `bh`). [F265, F273]

## Error Handling
- In `ext4_mb_new_blocks()`, if `ac->ac_pa` was allocated by `ext4_mb_pa_alloc()` but not linked to `grp->bb_prealloc_list`, free and NULL it via `ext4_mb_pa_put_free(ac)`. On failure, run `ext4_discard_allocated_blocks(ac)` before `errout` zeroes `ac->ac_b_ex.fe_len = 0`, and always jump to `out:` with `ar->len = 0` so reserved clusters and `inquota` are refunded. [F21, F22, F23]
- `ext4_get_group_info()` can return `NULL` (check `!grp` before `EXT4_MB_GRP_BBITMAP_CORRUPT(grp)` or field access). In `ext4_mb_load_buddy_gfp()`, check `!IS_ERR_OR_NULL(folio)` at `err:`. `dx_probe()`, `ext4_dx_find_entry()`, and `ext4_dx_add_entry()` return `ERR_BAD_DX_DIR` on HTree corruption; callers must intercept it to fall back to linear scan or translate to `-EFSCORRUPTED`. [F48, F51, F58]
- Callers of `ext4_new_inode_start_handle()` must check `handle = ext4_journal_current_handle()` and call `ext4_journal_stop(handle)` if non-NULL even when `IS_ERR(inode)`. Whenever a `buffer_head *` or `inode *` variable cleaned up at a shared `brelse()` / `iput()` label receives an `ERR_PTR` or error, reset it to `NULL` before jumping; in `ext4_resize_fs()`, any jump to `retry:` must release and NULL `resize_inode` and `flex_gd`. [F61, F236, F263, F264]

## External Contracts
- On-disk validation: `dx_probe()` must bound `indirect_levels < ext4_dir_htree_level(sb)`, `count <= dx_get_limit(entries)`, and reject cycle blocks; `ext4_dx_csum_verify()` / `ext4_dx_csum_set()` must verify `count_offset + limit * sizeof(struct dx_entry) <= blocksize - sizeof(struct dx_tail)` and cast `struct dx_countlimit *c` to `struct dx_entry *` before `+ limit`; `check_xattrs()` must check both unpadded `size > end - value` and `EXT4_XATTR_SIZE(size) > end - value`. [F106, F107, F166, F402]

## Known Pitfalls
- Prevent 32-bit overflow before shifting or adding: use `extent_logical_end()` / `pa_logical_end()` (`loff_t`) for extent ends; cast `fe_logical`, `EXT4_C2B()`, `orig_page_offset`, `folio->index`, `end_lblk`, and `ext4_group_t` to 64-bit before left-shifting or multiplying by blocks-per-group; use `do_div()` / `div64_u64()` / `div_u64()` for 64-bit divisions; and use `EXT4_NUM_B2C()` (not `EXT4_B2C()`) to round metadata block counts up to clusters. [F141, F142, F143, F153, F349, F350, F351, F353, F355, F435]
- Directory entry manipulation: never use `sizeof(struct ext4_dir_entry_2)` or `de++` on variable-length dirents; pass `dir = NULL` to `ext4_dir_rec_len()` for `.` and `..`; when clearing an entry without merging, zero from `&de->name_len` so `de->rec_len` is preserved; in `dx_pack_dirents()`, compute `ext4_next_entry()` before modifying `to->rec_len` and use `memmove()`; and in `ext4_rename()`, re-verify or re-lookup `old.de` after `ext4_add_entry()` / `ext4_setent()`. [F162, F163, F164, F165, F167]
- In `page-io.c`, `bio->bi_private` holds `ext4_io_end_t *` in flight, but `ext4_end_bio()` overwrites it via `xchg(&io_end->bio, bio)` on deferred completion to form a `struct bio *` list. In `ext4_bio_write_folio()`, if `io->io_bio` is already non-NULL, call `fscrypt_encrypt_pagecache_blocks()` with `GFP_NOWAIT` (or submit `io->io_bio` before retrying with `GFP_NOFS`) to avoid deadlocking the fscrypt bounce-page mempool. [F173, F178]
- In `ext4_xattr_make_inode_space()`, restart the scan from `IFIRST(header)` after each `ext4_xattr_move_to_block()` call. In `ext4_xattr_block_set()`, when cloning a shared block, copy `bs->s` to a local `s_copy`, rebase `s->first`, `s->here`, and `s->end` into the `kmemdup`ed buffer, and zero `s->here->e_value_inum` and `e_value_size`. In `ext4_xattr_set_handle()`, if `!is.s.not_found` hits `-ENOSPC`, call `ext4_xattr_block_find()` before `ext4_xattr_block_set()`. [F294, F297, F334]
