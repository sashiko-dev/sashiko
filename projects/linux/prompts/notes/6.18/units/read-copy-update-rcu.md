# READ-COPY UPDATE (RCU)

This unit implements the Linux Read-Copy Update (RCU) synchronization subsystem, including Tree RCU (normal/expedited grace periods, NOCB offloading, preemptible reader tracking, priority boosting, and stall detection), Tiny RCU, Tasks/Rude/Trace RCU, segmented callback lists, the Rust RCU `Guard`, and public RCU APIs.

## Architecture & Data Flow

- NOCB GP state (`nocb_gp_lock`, `nocb_defer_wakeup`, `nocb_timer`, `nocb_gp_sleep`, `nocb_gp_wq`, `nocb_head_rdp`, `nocb_toggling_rdp`) must only be accessed on the leader `rdp->nocb_gp_rdp`. Canceling `rdp_gp->nocb_timer` in `__wake_nocb_gp()` or `nocb_gp_wait()` must reset `rdp_gp->nocb_defer_wakeup = RCU_NOCB_WAKE_NOT` under `nocb_gp_lock`; in `nocb_gp_wait()`, schedule `RCU_NOCB_WAKE_LAZY` only when `lazy && !bypass`, and update `wait_gp_seq = cur_gp_seq` when `!needwait_gp || ULONG_CMP_LT(cur_gp_seq, wait_gp_seq)`. [F54, F55, F82, F83]
- `rdp->cblist.len` counts both `rdp->cblist` and `rdp->nocb_bypass`: enqueuing a new callback in `rcu_nocb_try_bypass()` or `rcu_nocb_do_flush_bypass()` must call `rcu_segcblist_inc_len(&rdp->cblist)`, whereas flushing bypass entries into `rdp->cblist` must not add their count again. `rdp->lazy_len` tracks only lazy callbacks in `rdp->nocb_bypass`; `rcu_nocb_do_flush_bypass()` must enqueue a new lazy `rhp` onto `rdp->nocb_bypass` and set `rhp = NULL` before calling `rcu_cblist_flush_enqueue()` and resetting `rdp->lazy_len = 0`. [F56, F57]
- In `struct rcu_segcblist`, `RCU_DONE_TAIL` (0) spans `[rsclp->head, *rsclp->tails[0])` while `seg > 0` spans `[*rsclp->tails[seg - 1], *rsclp->tails[seg])`. `rcu_segcblist_extract_done_cbs()` must iterate `i` backwards down to `RCU_DONE_TAIL` when resetting `tails[i]` to `&rsclp->head`, while `rcu_segcblist_insert_done_cbs()` iterates forwards and breaks at the first non-empty segment. `RCU_WAIT_TAIL` must never be empty while `RCU_NEXT_READY_TAIL` is non-empty, and `gp_seq[seg]` is valid only for non-empty `RCU_WAIT_TAIL` or `RCU_NEXT_READY_TAIL`. [F196, F208, F232, F248, F276]
- Index `rnp->nocb_gp_wq[2]` and `rnp->exp_wq[4]` with `rcu_seq_ctr(seq) & 0x1` and `rcu_seq_ctr(s) & 0x3`, never the raw sequence number. At GP completion, `rcu_future_gp_cleanup()` must advance `rnp->gp_seq_needed` to `rnp->gp_seq` when `!ULONG_CMP_LT(rnp->gp_seq, rnp->gp_seq_needed)`, and `rcu_exp_wait_wake()` must advance `rnp->exp_seq_rq` to `s` when `ULONG_CMP_LT(rnp->exp_seq_rq, s)` so unrequested trackers do not wrap. [F94, F237, F272]
- On `rnp->blkd_tasks` (under `rnp->lock`), `rcu_preempt_check_blocked_tasks()` must set `rnp->gp_tasks = rnp->blkd_tasks.next` before advancing `rnp->gp_seq` when `rcu_preempt_has_tasks(rnp) && (rnp->qsmaskinit || rnp->wait_blkd_tasks)`; `rcu_preempt_ctxt_queue()` may insert after `rnp->{exp,gp}_tasks` only when `RCU_{EXP,GP}_TASKS` is set; and `rcu_preempt_deferred_qs_irqrestore()` must advance any of `rnp->{gp,exp,boost}_tasks` matching `&t->rcu_node_entry` to `rcu_next_node_entry(t, rnp)` and clear `t->rcu_blocked_node = NULL`. [F10, F62, F86]
- In `rcu_report_qs_rnp()`, keep `&& mask` in `(!(rnp->qsmask & mask) && mask)` so `rcu_gp_init()` passing `mask == 0` for `rnp->wait_blkd_tasks` on an all-offline leaf propagates QS to `rnp->parent`. Never clear a CPU's bit in `rnp->expmaskinitnext` on CPU offline, and increment `rcu_state.ncpus` in `rcutree_report_cpu_starting()` only when `!(rnp->expmaskinitnext & mask)`. [F218, F259]
- In Tasks Trace RCU, `rcu_read_unlock_trace()` sets `current->trc_reader_nesting = INT_MIN + nesting` after a compiler `barrier()` before checking `trc_reader_special.s`; `trc_read_check_handler()`, `trc_inspect_reader()`, and `rcu_tasks_trace_qs()` must treat negative/`INT_MIN` nesting as an in-progress unlock. `rcu_read_unlock_trace_special()` must transition `trc_reader_special.b.need_qs` to `TRC_NEED_QS_CHECKED` (not `0`) and clear `blocked` before restoring `trc_reader_nesting = 0`. Update `per_cpu(trc_ipi_to_cpu, cpu)` and `t->trc_ipi_to_cpu` in lockstep. [F205, F226, F254, F314]

## Synchronization

- Lock-consuming helpers must release caller-held locks on every path (including `#ifdef`/`#else` stubs of `rcu_nocb_unlock_irqrestore()`, `rcu_initiate_boost()`, and `rcu_print_task_stall()`): `__wake_nocb_gp()` and `do_nocb_deferred_wakeup_common()` unlock `rdp_gp->nocb_gp_lock` before `swake_up_one()`; `__call_rcu_nocb_wake()` calls `rcu_nocb_unlock(rdp)` before `wake_nocb_gp()` (only if `!irqs_disabled_flags(flags)`) or `wake_nocb_gp_defer()`; `rcu_initiate_boost()`, `rcu_print_task_stall()`, `rcu_report_*qs_rnp()`, `__rcu_report_exp_rnp()`, and `rcu_report_exp_cpu_mult()` unlock `rnp->lock` and restore `flags`; `rcu_preempt_ctxt_queue()` unlocks `rnp->lock` leaving IRQs disabled; `rcu_start_this_gp()` keeps `rnp_start->lock` held while unlocking ancestors, and `rcu_gp_kthread_wake()` requires all `rnp->lock`s released. [F1, F4, F9, F12, F28, F66, F113, F145, F146, F300]
- Every `struct rcu_node` and `struct rcu_tasks_percpu` `->lock` must use `raw_spin_lock*_rcu_node()` / `raw_spin_unlock*_rcu_node()` with IRQs disabled. Lock order: `rcu_state.ofl_lock` (IRQs disabled) -> `rcu_state.barrier_lock` -> `rdp->nocb_lock` (`rcu_nocb_lock_irqsave()` must disable IRQs before testing `rcu_segcblist_is_offloaded()`) -> `rdp->nocb_bypass_lock` or leaf `rnp->lock` -> `rnp_root->lock`. Release `rnp->lock` and `rdp->nocb_lock` before waking `rdp->nocb_cb_wq` or `rcu_gp_kthread_wake()`. [F29, F34, F117, F168, F296, F298, F299]
- `rcu_rdp_is_offloaded(rdp)` requires holding `barrier_mutex`, hotplug lock, `rdp->nocb_lock`, or `nocb_mutex`, or running on `rdp`'s CPU with preemption/BH disabled or in its NOCB kthreads. Toggling offload in `rcu_nocb_cpu_{de}offload()` requires acquiring `cpus_read_lock()` before `nocb_mutex` with `!cpu_online(cpu)`, synchronizing `SEGCBLIST_OFFLOADED`, `rdp->nocb_entry_rdp` in `rdp_gp->nocb_head_rdp` under `rdp->nocb_lock` (modified only by `nocb_gp_toggle_rdp()` when `nocb_gp_kthread` is running), and `rcu_nocb_mask`. `rcu_gp_cleanup()` must not call `rcu_accelerate_cbs()` when `rcu_rdp_is_offloaded(rdp)`. [F23, F25, F26, F58, F84, F173]
- In `rcu_preempt_deferred_qs_irqrestore()`, snapshot `rt_mutex_owner(&rnp->boost_mtx.rtmutex) == t` and `sync_rcu_exp_done(rnp)` under `rnp->lock` before unlocking to report QS or call `rt_mutex_futex_unlock()`. In `rcu_boost()`, recheck `rnp->exp_tasks` / `rnp->boost_tasks` and call `rt_mutex_init_proxy_locked(&rnp->boost_mtx.rtmutex, t)` under `rnp->lock`, unlocking with IRQs restored before `rt_mutex_lock(&rnp->boost_mtx)`. In `rcu_print_task_stall()`, pin tasks with `get_task_struct(t)` under `rnp->lock` before unlocking to call `task_call_func()`. [F31, F33, F60]
- In `rcu_read_unlock_special()`, return immediately if `in_nmi()`; when preemption, BH, or IRQs are disabled, call `raise_softirq_irqoff(RCU_SOFTIRQ)` only if `use_softirq && (in_hardirq() || (needs_exp && !irqs_were_disabled))`, and queue `rdp->defer_qs_iw` only if `irqs_were_disabled && needs_exp && cpu_online(rdp->cpu) && rdp->defer_qs_iw_pending != DEFER_QS_PENDING`. [F109, F110, F111]
- `__rcu_read_unlock()` needs a compiler `barrier()` before `rcu_preempt_read_exit()` and another before reading `t->rcu_read_unlock_special.s` when it returns 0. `rcu_all_qs()` and `!CONFIG_PREEMPT_RCU` `rcu_note_context_switch()` must `smp_load_acquire(this_cpu_ptr(&rcu_data.rcu_urgent_qs))` before reading `rcu_need_heavy_qs`. `record_gp_stall_check_time()` must order `WRITE_ONCE(rcu_state.gp_start, j)` before `WRITE_ONCE(rcu_state.jiffies_stall, j + j1)` with `smp_mb()`, pairing with `smp_rmb()` in `check_cpu_stall()`. [F35, F37, F38]
- In `rcu_gp_init()`, run `rcu_sr_normal_gp_init()` then `rcu_seq_start(&rcu_state.gp_seq)` under the root `rcu_node` lock before applying leaf `qsmaskinitnext` changes; under `ofl_lock` and `rnp->lock`, `rcutree_report_cpu_starting()` sets `qsmaskinitnext` before `rcu_report_qs_rnp()`, whereas `rcutree_report_cpu_dead()` calls `rcu_report_qs_rnp()` before clearing `qsmaskinitnext`. `rcu_sr_normal_gp_cleanup*()` must access `srs_done_tail` with release-acquire ordering, keep the `done` dummy node (`done->next = NULL`), and increment `srs_cleanups_pending` before `queue_work()`. [F152, F171, F175, F217]
- In Tasks RCU: `call_rcu_tasks_generic()` must keep queue selection and enqueue inside `rcu_read_lock()` / `rcu_read_unlock()` and never lock `rtp->cbs_gbl_lock` inside `rtpcp->lock`; `exit_tasks_rcu_finish()` must lock `per_cpu_ptr(rcu_tasks.rtpcpu, t->rcu_tasks_exit_cpu)` (not `this_cpu_ptr`); `rcu_tasks_postscan()` must anchor an on-stack `struct list_head tmp` after `t` before dropping `rtpcp->lock` (and no other code may downcast `rtp_exit_list` entries); `rcu_tasks_trace_pregp_step()` and `check_all_holdout_tasks_trace()` require `cpus_read_lock()`, and `rcu_tasks_trace_postgp()` must wait for `trc_ipi_to_cpu` to clear. [F160, F178, F180, F224, F284]

## Object Lifetimes

- In `nocb_gp_wait()`, clear `my_rdp->nocb_toggling_rdp = NULL` under `my_rdp->nocb_gp_lock` before `nocb_gp_toggle_rdp()` and waking `rdp_toggling->nocb_state_wq`. `rcu_nocb_rdp_deoffload()` must call `rcu_barrier()` before `kthread_park(rdp->nocb_cb_kthread)` and clearing `SEGCBLIST_OFFLOADED`; `nocb_cb_wait()` may call `kthread_parkme()` only when `rdp->nocb_cb_sleep` is true (`rcu_segcblist_n_cbs(&rdp->cblist) == 0` under `rcu_nocb_lock_irqsave`); `rcu_nocb_rdp_offload()` must wait for `SEGCBLIST_OFFLOADED` before `kthread_unpark(rdp->nocb_cb_kthread)`. [F6, F7, F21]
- On-stack `struct rcu_synchronize` in `synchronize_rcu_normal()` and `__wait_rcu_gp()` must call `init_rcu_head_on_stack()` and `init_completion()` before queuing and `destroy_rcu_head_on_stack()` only after `wait_for_completion*()` returns (both loops in `__wait_rcu_gp()` must use identical `checktiny` and deduplication filters). Because waiters return upon completion, `rcu_sr_normal_complete()` must read `rcu->next` and `rs->oldstate` before `complete(&rs->completion)`, and `wait_rcu_exp_gp()` must read `rewp->rew_s` before `rcu_exp_sel_wait_wake()`. [F67, F131, F153, F282, F283]
- In `rcu_do_batch()` and `rcu_tasks_invoke_cbs()`, `rcu_segcblist_extract_done_cbs()` does not decrement `cblist.len` (updates via `rcu_segcblist_add_len()` / `rcu_segcblist_inc_len()` require preceding and trailing `smp_mb()` unless hotplug lock is held); callers must reinsert uninvoked callbacks via `rcu_segcblist_insert_done_cbs()` and subtract the invoked count via `rcu_segcblist_add_len()`. `rcutree_migrate_callbacks()` must merge all callbacks via `rcu_segcblist_merge()` before `rcu_segcblist_disable()`. [F147, F154, F310]
- Holdout tasks in Classic RCU Tasks (`rcu_tasks_pertask()`, `rcu_tasks_postscan()`, `check_holdout_task()`) and Tasks Trace (`trc_add_holdout()`, `trc_del_holdout()`, plus `trc_wait_for_one_reader()` around `task_call_func()`) must balance `get_task_struct(t)` and `put_task_struct(t)` guarded by `list_empty()` on the holdout list entry. Rust `kernel::sync::rcu::Guard` must remain `!Send`, acquire `rcu_read_lock()` only in `Guard::new()`, and call `rcu_read_unlock()` only in `Drop::drop()`. [F17, F158, F159]

## API Contracts

- When `rcu_nocb_try_bypass()` returns `false`, it has not enqueued `rhp`, must set `*was_alldone = !rcu_segcblist_pend_cbs(&rdp->cblist)`, and returns with `rdp->nocb_lock` held (if offloaded); when it returns `true`, `rhp` is enqueued and `rdp->nocb_lock` is not held. `rcu_nocb_do_flush_bypass()` and `rcu_nocb_flush_bypass()` return `false` only when `rhp_in` is non-NULL and `rdp->nocb_bypass` was empty (leaving `rhp_in` for the caller to enqueue onto `rdp->cblist`). [F3, F41, F42]
- `rcu_dereference_protected()` is legal only under the update-side lock (never `rcu_read_lock()` alone), and `RCU_INIT_POINTER()` must not publish newly initialized structs to concurrent readers. `list_bidir_prev_rcu()` lists must remove entries with `list_bidir_del_rcu()` (never `list_del_rcu()` / `list_replace_rcu()`); `hlist_bl` RCU accesses must use `hlist_bl_first_rcu()` / `hlist_bl_set_first_rcu()`; `hlist_nulls` loops must test `!is_a_nulls()`. `rcuref_t` deconstruction must check `rcuref_put*()` or `rcuref_is_dead()`, never `rcuref_read() == 0`. [F184, F192, F203, F246, F278, F304]
- `exp_funnel_lock()` returns `true` with `rcu_state.exp_mutex` unlocked if GP `s` already completed, and `false` with `exp_mutex` held otherwise. Callers of `rcu_segcblist_extract_done_cbs()` and `rcu_segcblist_extract_pend_cbs()` must pre-initialize the destination `struct rcu_cblist` via `rcu_cblist_init()`. `wakeme_after_rcu()` requires a `struct rcu_head` embedded in `struct rcu_synchronize`. [F103, F189, F198]

## Error Handling

- Kthread/kworker creation in `rcu_spawn_cpu_nocb_kthread()`, `rcu_spawn_one_boost_kthread()`, `rcu_spawn_exp_par_gp_kworker()`, and `rcu_start_exp_gp_kworker()` must check `IS_ERR()` / `IS_ERR_OR_NULL()` before storing into task/kworker pointers (which are NULL-checked elsewhere, including `rcu_state.gp_kthread`, `rdp->nocb_gp_rdp`, and `cpumask_available(rcu_nocb_mask)`); on failure, `rcu_spawn_cpu_nocb_kthread()` must de-offload `rdp` and clear `cpu` from `rcu_nocb_mask` under `rcu_state.nocb_mutex`. [F8, F39, F40, F44, F45, F52, F106, F188]
- `task_call_func()` return conventions differ: `check_slow_task()` (`rcu_print_task_stall()`) and `trc_inspect_reader()` return `0` on success and negative errno when output is uninitialized/failed, whereas `trc_check_slow_task()` returns `true` (`1`) when `*trc_rdrp` is populated and `false` (`0`) when uninitialized. In `rcu_barrier_entrain()`, if `rcu_segcblist_entrain()` returns `false`, call `debug_rcu_head_unqueue(&rdp->barrier_head)` without incrementing `barrier_cpu_count`. [F48, F148, F193]

## Known Pitfalls

- In `wake_nocb_gp_defer()`, `RCU_NOCB_WAKE_LAZY` (2) must only arm `rdp_gp->nocb_timer` when `rdp_gp->nocb_defer_wakeup == RCU_NOCB_WAKE_NOT` (0), whereas `RCU_NOCB_WAKE_BYPASS` (1) unconditionally overrides any pending deferral. `rcu_segcblist_empty()` returns `true` while extracted callbacks are still running in `rcu_do_batch()`, so `rcu_barrier()` and `rcu_segcblist_entrain()` must check `rcu_segcblist_n_cbs()` instead. [F81, F197]
- Node-local CPU bitmasks (`rnp->qsmask`, `rnp->expmask`) are indexed relative to `rnp->grplo` using `1UL << (cpu - rnp->grplo)` or `leaf_node_cpu_bit(rnp, cpu)` (never `1 << ...` or `BIT(cpu)`), and `rcu_find_next_bit(rnp, cpu, mask)` expects `@cpu` to be a 0-based offset `cpu - rnp->grplo`. To iterate blocking tasks on `rnp->blkd_tasks`, seed `t = list_entry(rnp->{gp,exp}_tasks->prev, ...)` before `list_for_each_entry_continue()`, and in `rcu_print_task_stall()` iterate `ts[]` via `while (i) { t = ts[--i]; ... }` so `ts[0]` is not skipped. [F76, F88, F92, F234, F251, F261]
