# ROCKER DRIVER

The Rocker driver is a PCI switchdev network device driver for the QEMU-emulated Rocker Ethernet switch. It manages PCI BAR0 MMIO registers, MSI-X interrupts, and descriptor-based DMA rings (command, event, per-port TX, and per-port RX) formatted with 8-byte-aligned TLVs. It implements a pluggable "world" architecture, currently providing an OF-DPA (`rocker_ofdpa.c`) pipeline that offloads L2 bridging, VLANs, FDB learning/ageing, and IPv4 FIB/ARP routing via Linux netdevice, netevent, FIB, and switchdev notifiers.

## Architecture & Data Flow
- `struct ofdpa_flow_tbl_entry` and `struct ofdpa_fdb_tbl_entry` must be allocated with `kzalloc` because `ofdpa_flow_tbl_add()`, `ofdpa_flow_tbl_find()`, `ofdpa_port_fdb()`, and `ofdpa_fdb_tbl_find()` compute `crc32` and `memcmp` over `key_len` or `sizeof(key)`, including alignment padding and unused union tail bytes. For `ROCKER_OF_DPA_TABLE_ID_UNICAST_ROUTING`, `ofdpa_flow_tbl_ucast4_routing()` must set `entry->key_len` to `offsetof(struct ofdpa_flow_tbl_key, ucast_routing.group_id)` so `ucast_routing.group_id` is excluded from key hashing and comparison. [F31, F62]
- When `ofdpa_flow_tbl_add()` replaces an existing entry matched by `ofdpa_flow_tbl_find()`, it must preserve `found->cookie` and set `cmd` to `ROCKER_TLV_CMD_TYPE_OF_DPA_FLOW_MOD` rather than allocating from `ofdpa->flow_tbl_next_cookie`. [F46]
- In `ofdpa_port_vlan()`, `change_bit(ntohs(internal_vlan_id), ofdpa_port->vlan_bitmap)` must run before `ofdpa_port_vlan_l2_groups()` and `ofdpa_port_vlan_flood_group()`, and be toggled back on error. Because the bit is toggled first, `ofdpa_port_vlan_l2_groups()` must program the CPU port (`out_pport = 0`) L2 interface group only when `(adding && ref == 1)` or `(!adding && ref == 0)`. [F43, F68]
- In `ofdpa_port_bridge_join()` and `ofdpa_port_bridge_leave()`, `ofdpa_port_vlan_del(ofdpa_port, OFDPA_UNTAGGED_VID, 0)` must run before updating `ofdpa_port->internal_vlan_id` and `ofdpa_port->bridge_dev`, and `ofdpa_port_vlan_add(ofdpa_port, OFDPA_UNTAGGED_VID, 0)` must run after both fields are updated. [F44]
- A port's per-VLAN L2 interface group (`ROCKER_GROUP_L2_INTERFACE(vlan_id, ofdpa_port->pport)`) and learned FDB entries may exist only while `ofdpa_port->stp_state` is `BR_STATE_LEARNING` or `BR_STATE_FORWARDING`, and `ofdpa_port_stp_update()` must update `ofdpa_port->stp_state` before calling `ofdpa_port_fdb_flush()` and `ofdpa_port_fwding()`. [F45]
- `struct ofdpa_group_tbl_entry` is discriminated by `ROCKER_GROUP_TYPE_GET(entry->group_id)`: only `ROCKER_OF_DPA_GROUP_TYPE_L2_FLOOD` and `ROCKER_OF_DPA_GROUP_TYPE_L2_MCAST` allocate `entry->group_ids` (freed in `ofdpa_group_tbl_entry_free()`). The union in `struct rocker_fib_event_work` is discriminated by `fib_work->event`: `FIB_EVENT_ENTRY_REPLACE`/`DEL` use `fen_info` (`fen_info.fi`), whereas `FIB_EVENT_RULE_ADD`/`DEL` use `fr_info` (`fr_info.rule`). [F33, F34]
- Pointer arithmetic on `struct rocker_tlv *` and descriptor buffers (`rocker_tlv_next()`, `rocker_tlv_data()`, `rocker_tlv_start()`, `rocker_tlv_nest_end()`, `rocker_tlv_nest_cancel()`, `rocker_tlv_put()`) must use `char *` byte pointers and `ROCKER_TLV_ALIGN` (8-byte) offsets rather than `sizeof(struct rocker_tlv)` (6 bytes). `rocker_tlv_put()` must store unpadded `rocker_tlv_attr_size(attrlen)` in `tlv->len` while advancing `desc_info->tlv_size` by 8-byte-aligned `rocker_tlv_total_size(attrlen)` and zeroing `rocker_tlv_padlen(attrlen)` trailing bytes. [F57, F85]
- Before `rocker_dma_rx_ring_skb_alloc()` allocates or maps an RX `sk_buff` (and in `rocker_dma_rx_ring_skb_map()` on `tlv_put_failure`), `desc_info->tlv_size` must be set to `0` and the descriptor cookie to `NULL` so hardware skips the descriptor on error and `rocker_dma_rx_ring_skb_free()` does not free a stale `sk_buff`. [F29]
- `struct rocker_dma_ring_info` treats `info->tail == info->head` as empty and `__pos_inc(info->head, info->size) == info->tail` as full, so a ring holds at most `info->size - 1` active descriptors and `rocker_dma_ring_pass_to_producer()` must advance `head` only `info->size - 1` times. [F59]

## Synchronization
- Callers of `rocker_cmd_exec()` (or OF-DPA helpers checking `ofdpa_flags_nowait()`) in hardirq (`ofdpa_port_ev_mac_vlan_seen()`), timer (`ofdpa_fdb_cleanup()`), atomic neighbour (`ofdpa_port_neigh_update()`, `ofdpa_port_neigh_destroy()`), or spinlock (`ofdpa_port_fdb_flush()`, `ofdpa_fib4_abort()`) context must set `OFDPA_OP_FLAG_NOWAIT` (`nowait = true`). [F103]
- In `rocker_cmd_exec()`, reserving a descriptor (`rocker_desc_head_get()`), initializing `wait` (`rocker_wait_init()`, `wait->nowait`), running `prepare`, and publishing (`rocker_desc_head_set()`) execute under `rocker->cmd_ring_lock` with IRQs disabled; when `nowait == true`, `process` is never invoked and the command completes asynchronously after `rocker_cmd_exec()` returns. [F13, F87]
- `rocker->cmd_ring_lock` is acquired in hardirq `rocker_cmd_irq_handler()` with `spin_lock()`, so all non-hardirq acquisitions (`rocker_cmd_exec()`) must use `spin_lock_irqsave()`. `ofdpa->fdb_tbl_lock` and `ofdpa->flow_tbl_lock` must also use `spin_lock_irqsave()`, and when nested (`ofdpa_port_fdb_flush()`, `ofdpa_fdb_cleanup()`), `fdb_tbl_lock` must be acquired outer to `flow_tbl_lock`. [F19, F105]
- `ofdpa_port_ipv4_neigh()`, `ofdpa_flow_tbl_bridge()`, and `ofdpa_port_fdb_learn()` must allocate `ofdpa_neigh_tbl_entry`, `ofdpa_flow_tbl_entry`, and `ofdpa_fdb_learn_work` with `GFP_ATOMIC` because they run in atomic neighbour callbacks, `ofdpa_fdb_cleanup()`, `ofdpa_port_fdb_flush()`, and `ofdpa_port_ev_mac_vlan_seen()`. [F104]
- Hash table scans that unlink entries via `hash_del()` (`ofdpa_port_fdb_flush()`, `ofdpa_fdb_cleanup()`, `ofdpa_fini()`, `ofdpa_fib4_abort()`) must use `hash_for_each_safe` while holding the table spinlock. In `ofdpa_port_internal_vlan_id_get()` and `ofdpa_port_internal_vlan_id_put()`, `ofdpa->internal_vlan_tbl_lock` must be held with `spin_lock_irqsave()` across the table lookup, `ref_count` update, and `ofdpa->internal_vlan_bitmap` mutation. [F23, F71]
- In `ofdpa_port_ipv4_neigh()` and `ofdpa_port_ipv4_nh()`, any fields needed from an existing `ofdpa_neigh_tbl_entry` (`found`) after releasing `ofdpa->neigh_tbl_lock` must be copied out while holding `neigh_tbl_lock` before calling `ofdpa_neigh_del(found)` or unlocking. [F22]
- Work items on `rocker->rocker_owq` (`rocker_router_fib_event_work()`, `rocker_switchdev_event_work()`) acquire `rtnl_lock()`, so `ofdpa_fini()` and any caller of `flush_workqueue(rocker->rocker_owq)` or `destroy_workqueue(rocker->rocker_owq)` must never hold `rtnl_lock()`. [F109]
- When publishing or returning a descriptor on `tx_ring`, `rx_ring`, or `event_ring`, `rocker_desc_gen_clear()` must clear `ROCKER_DMA_DESC_COMP_ERR_GEN` before `rocker_desc_head_set()`. In `rocker_event_irq_handler()` and `rocker_port_poll_rx()`, every descriptor from `rocker_desc_tail_get()` must have `rocker_desc_gen_clear()`, `rocker_desc_head_set()`, and `credits++` executed before the next iteration, even on descriptor or processing error. [F14, F75]

## Object Lifetimes
- `ofdpa_flow_tbl_do()`, `ofdpa_flow_tbl_add()`, and `ofdpa_flow_tbl_del()` unconditionally consume the caller-allocated `struct ofdpa_flow_tbl_entry *`, and `ofdpa_group_tbl_do()`, `ofdpa_group_tbl_add()`, and `ofdpa_group_tbl_del()` unconditionally take ownership of the caller-allocated `struct ofdpa_group_tbl_entry *` (including `entry->group_ids` for `L2_FLOOD` and `L2_MCAST`). Callers must not free or dereference `entry` (or `entry->group_ids`) after calling them, even on error. [F1, F2]
- In `ofdpa_port_ipv4_neigh()` and `ofdpa_port_ipv4_nh()`, the pre-allocated `struct ofdpa_neigh_tbl_entry *entry` is inserted into `ofdpa->neigh_tbl` only when `adding` is true; `updating` (`found && adding`) and `removing` (`found && !adding`) must be evaluated before `adding = !found && adding`, and every `!adding` path after unlocking must call `kfree(entry)`. [F4, F66]
- In `rocker_router_fib_event()` and `rocker_switchdev_event()` (under `rcu_read_lock()`), transient payloads must be copied and objects pinned (`fib_info_hold()`, `fib_rule_get()`, `dev_hold()`, `GFP_ATOMIC` copy of `fdb_info->addr`) before queueing on `rocker_owq`, and released in the worker. Because `queue_work()` runs unconditionally after `switch (event)`, any error or ignored-event branch after `kzalloc()` must `kfree()` the work item, drop any taken references, and `return` directly rather than using `break`. [F5, F21, F69]
- In `rocker_probe()`, `rocker_dma_rings_init()`, `ROCKER_MSIX_VEC_CMD` `request_irq()`, and `rocker_owq` allocation must precede `rocker_probe_ports()`, which must precede registering FIB and switchdev notifiers. In `rocker_remove()`, notifiers must be unregistered before `rocker_remove_ports()` (which calls `ofdpa_fini()` to run `timer_delete_sync(&ofdpa->fdb_cleanup_timer)` and `flush_workqueue(rocker->rocker_owq)`), before `destroy_workqueue(rocker->rocker_owq)`, freeing command/event IRQs, and `rocker_dma_rings_fini()`. [F10, F90, F91, F92]
- In `rocker_probe_port()`, `rocker_world_port_pre_init()` must allocate `rocker_port->wpriv` before `rocker->ports[port_number]` is set and before `register_netdev()`, while `rocker_world_port_init()` must run after `register_netdev()`. On `err_world_port_init`, `rocker->ports[port_number]` must be reset to `NULL` before `unregister_netdev()` and `free_netdev()`, and `ofdpa_port_get()` callers iterating `port_count` must check for `NULL`. [F7, F15, F93]
- In `rocker_port_open()`, `rocker_port_dma_rings_init()`, TX/RX `request_irq()`, `rocker_world_port_open()`, and `napi_enable()` must precede `rocker_port_set_enable(rocker_port, true)` and `netif_start_queue()`, and `rocker_port_stop()` must tear them down in reverse order. Per-port DMA rings/IRQs and `ROCKER_MSIX_VEC_TEST` in `rocker_basic_hw_test()` must not use `devm_*` or `dmam_*`. [F94, F95]
- In `rocker_port_xmit()`, if `rocker_desc_head_get()` returns `NULL`, return `NETDEV_TX_BUSY` without freeing `skb`; any failure after acquiring `desc_info` must call `rocker_tx_desc_frags_unmap()`, `rocker_tlv_nest_cancel()`, and `dev_kfree_skb(skb)`, and return `NETDEV_TX_OK` without advancing `tx_ring` head. [F9]

## API Contracts
- `rocker_tlv_parse()` (and `rocker_tlv_parse_nested()`, `rocker_tlv_parse_desc()`) requires a `tb` array of at least `maxtype + 1` elements and leaves missing attributes as `NULL`; callers must check `tb[attr]` for non-`NULL` before passing it to `rocker_tlv_get_*()`, `rocker_tlv_data()`, `rocker_tlv_len()`, or `rocker_tlv_parse_nested()`. In `ofdpa_cmd_group_tbl_add_group_ids()`, `ROCKER_TLV_OF_DPA_GROUP_IDS` entries must use 1-based attribute types (`i + 1`). [F30, F38, F55]
- `rocker_port->port_number` is 0-based (`0 .. rocker->port_count - 1`) for indexing `rocker->ports[]`, MSI-X vectors, and DMA rings, whereas `rocker_port->pport` is 1-based (`port_number + 1`, up to 62) for hardware TLVs, OF-DPA ports, and `1ULL << rocker_port->pport` shifts in 64-bit `PORT_PHYS_ENABLE` and `PORT_PHYS_LINK_STATUS`. Event handlers (`rocker_event_link_change()`, `rocker_event_mac_vlan_seen()`) must subtract 1 into `unsigned int port_number` and check `port_number < rocker->port_count` before indexing `rocker->ports[]`. [F37, F54, F77]
- `ROCKER_GROUP_L2_INTERFACE()`, `ROCKER_GROUP_L2_MCAST()`, and `ROCKER_GROUP_L2_FLOOD()` take a `__be16 vlan_id` (calling `ntohs()` internally), whereas `ROCKER_GROUP_VLAN_SET()` takes a host-byte-order VLAN ID. `ofdpa_port->vlan_bitmap` uses host-byte-order `ntohs(vlan_id)` (`0..4095`), whereas `ofdpa->internal_vlan_bitmap` uses `ntohs(vlan_id) - OFDPA_INTERNAL_VLAN_ID_BASE` (`0..254`). [F39, F89]
- In `ofdpa_fib4_add()` and `ofdpa_fib4_del()`, host-byte-order `fen_info->dst` must be converted via `htonl(fen_info->dst)` before `ofdpa_port_fib_ipv4()`. In `ofdpa_port_attr_bridge_ageing_time_set()`, switchdev's `ageing_time` must be converted via `clock_t_to_jiffies(ageing_time)`. [F40, F41]
- Notifiers and device walks receiving an arbitrary `struct net_device *` must verify `rocker_port_dev_check(dev)` (or `rocker_port_dev_check_under(dev, rocker)`) before calling `netdev_priv(dev)`. [F86]
- In `rocker_port_rx_proc()`, `rocker_dma_rx_ring_skb_unmap()` must unmap the RX SKB before reading packet data or calling `rocker_dma_rx_ring_skb_alloc()`. `rocker_port_poll_rx()` must bound processing by `budget`, call `napi_complete_done(napi, credits)` only when `credits < budget`, and return `credits`; `rocker_port_poll_tx()` (`netif_napi_add_tx()`) must unmap fragments, free SKBs with `dev_kfree_skb_any()`, call `napi_complete(napi)`, and return `0`. [F110, F112, F113]
- In `rocker_port_change_mtu()`, a running port must be stopped with `rocker_port_stop()` before updating `dev->mtu` and reopened with `rocker_port_open()` so RX buffers are reallocated at `rocker_port_rx_buf_len()`. [F116]

## Error Handling
- If adding child TLVs or mapping fragments fails after `rocker_tlv_nest_start()` in `rocker_tx_desc_frag_map_put()` or `rocker_port_xmit()`, `rocker_tlv_nest_cancel()` must rewind `desc_info->tlv_size`. [F28]
- In `ofdpa_port_ipv4_resolve()`, `neigh_create()` must be checked with `IS_ERR(n)` and converted via `PTR_ERR(n)` rather than returning `IS_ERR(n)`. In `rocker_world_check_init()`, a `rocker->wops->mode != mode` mismatch must return `-EINVAL` rather than `err` (`0`). [F25, F26, F97]

## External Contracts
- 64-bit MMIO registers (`TEST_REG64`, `TEST_DMA_ADDR`, `DMA_DESC_ADDR`, `PORT_PHYS_LINK_STATUS`, `PORT_PHYS_ENABLE`, `SWITCH_ID`) require `rocker_read64()`/`rocker_write64()`, and `rocker_port_set_enable()` must read-modify-write `PORT_PHYS_ENABLE` using `1ULL << rocker_port->pport`. [F50, F100]
- `ofdpa_port_fdb_learn()` must defer bridge notifications to `ofdpa_port_fdb_learn_work()`, which maps internal VLANs to VID `0` via `ofdpa_port_vlan_to_vid()` and calls `call_switchdev_notifiers()` under `rtnl_lock()`. Stack `struct switchdev_notifier_fdb_info` in `ofdpa_port_fdb_learn_work()` and `rocker_fdb_offload_notify()` must be zero-initialized (`= {}`). [F24, F27, F126]
- `rocker_switchdev_event_work()` must ignore FDB entries with `!fdb_info->added_by_user || fdb_info->is_local` and call `rocker_fdb_offload_notify()` under `rtnl_lock()` on add; `rocker_switchdev_port_attr_set_event()` and `rocker_switchdev_port_obj_event()` must set `handled = true`. [F123, F124]
- `rocker_router_fib_event()` must reject `fib_nh_is_v6` or `fi->nh` synchronously via `NL_SET_ERR_MSG_MOD()` and `notifier_from_errno(-EINVAL)`, whereas async failures in `rocker_router_fib_event_work()` must call `rocker_world_fib4_abort()`. `ofdpa_fib4_add()` must set `RTNH_F_OFFLOAD` on `nh->fib_nh_flags`, and `ofdpa_fib4_del()`/`ofdpa_fib4_abort()` must clear it. [F120, F121]
- In `rocker_port_rx_proc()`, when `ROCKER_RX_FLAGS_FWD_OFFLOAD` is set in `ROCKER_TLV_RX_FLAGS`, `skb->offload_fwd_mark = 1` must be set before `netif_receive_skb()`. [F111]

## Known Pitfalls
- In `ofdpa_port_fdb()`, `if (!found == removing)` handles both `found && !removing` (refreshing an existing entry via `OFDPA_OP_FLAG_REFRESH`) and `!found && removing` and must `kfree(fdb)` in both cases. [F67]
- `struct fib_info` must be stored by pointer (`fen_info.fi`, `ofdpa_flow_tbl_entry.fi`) rather than copied by value so `fib_info_nh(fi, 0)` can access its trailing `fib_nh[]` flexible array. [F82]
- In `rocker_dma_ring_bufs_alloc()`, `rocker_dma_cmd_ring_waits_alloc()`, and `rocker_dma_rx_ring_skbs_alloc()`, loop counter `i` must be a signed `int` for the `for (i--; i >= 0; i--)` rollback loop. [F72]
- In `rocker_port_attr_set()`, each `case` in `switch (attr->id)` must end with `break` so `SWITCHDEV_ATTR_ID_PORT_PRE_BRIDGE_FLAGS` does not fall through into `SWITCHDEV_ATTR_ID_PORT_BRIDGE_FLAGS`. [F70]
