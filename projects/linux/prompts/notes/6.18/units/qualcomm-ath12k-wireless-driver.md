# QUALCOMM ATH12K WIRELESS DRIVER

`drivers/net/wireless/ath/ath12k` (`mac.c`) implements the mac80211 interface layer (`ath12k_ops`) for the Qualcomm 802.11be (Wi-Fi 7) wireless driver, managing multi-radio hardware groups (`ath12k_hw_group`, `ath12k_hw`, `ath12k`), VDEV and Multi-Link Operation (MLO) link lifecycles (`ath12k_vif`, `ath12k_link_vif`), station/peer state transitions (`ath12k_sta`, `ath12k_link_sta`), channel contexts, scanning, key management, regulatory/TPC power, and TX routing to WMI or data path layers.

## Architecture & Data Flow
- `ahvif->link` holds `ATH12K_NUM_MAX_LINKS` entries (including scan links `>= ATH12K_FIRST_SCAN_LINK`), whereas `ahvif->cache` and `vif->link_conf` hold only `IEEE80211_MLD_MAX_NUM_LINKS` entries and require checking `link_id < IEEE80211_MLD_MAX_NUM_LINKS` before indexing. Fallback scan link selection in `ath12k_mac_find_link_id_by_ar()` must mask `~ahvif->links_map` with `ATH12K_SCAN_LINKS_MASK`, and callers must reject `link_id >= ATH12K_NUM_MAX_LINKS`. [F62, F63]
- Unstarted or deleted link VIFs have `arvif->is_created == false` and `arvif->ar == NULL`, so VIF/link iterators (`ath12k_get_arvif_iter`, `ath12k_mac_handle_beacon_iter`, `ath12k_mac_handle_beacon_miss`, `ath12k_mac_change_chanctx_*_iter`) must verify `arvif->is_created` before reading `arvif->ar` or `arvif->vdev_id`. [F36]
- In `ath12k_mac_peer_cleanup_all()`, `ath12k_dp_rx_peer_tid_cleanup()` must only be called when `peer->sta` is non-NULL because AP VDEV self-peers have `sta == NULL` and uninitialized RX TID state. [F38]
- Once `ath12k_mac_mgmt_tx()` queues an `skb` onto `ar->wmi_mgmt_tx_queue` and increments `ar->num_pending_mgmt_tx`, any drop/free path (`ath12k_mgmt_over_wmi_tx_work()`, `ath12k_mgmt_over_wmi_tx_purge()`, `ath12k_mac_tx_mgmt_pending_free()`) must release it via `ath12k_mgmt_over_wmi_tx_drop()` rather than freeing it directly. [F5]
- When a scan or remain-on-channel reuses an active started `arvif` (`arvif->is_started`), `ath12k_scan_vdev_clean_work()` and `ath12k_mac_op_cancel_hw_scan()` must skip it, and `ath12k_mac_initiate_hw_scan()` / `ath12k_mac_op_remain_on_channel()` must reject moving it to another `ar`. [F85]
- When copying HE/EHT capability arrays between `ieee80211_he_cap_elem` / `ieee80211_eht_cap_elem_fixed` (`u8[]`) and `ath12k_wmi_peer_assoc_arg` or `ath12k_band_cap` (`u32[]`) in `ath12k_peer_assoc_h_he()`, `ath12k_peer_assoc_h_eht()`, `ath12k_mac_copy_he_cap()`, and `ath12k_mac_copy_eht_cap()`, `memcpy()` must be bounded by `sizeof()` the smaller `u8[]` field. [F99, F100]
- In `ath12k_mac_parse_tx_pwr_env()`, `tpc_info->num_pwr_levels` must be clamped with `min3()` against both `ATH12K_NUM_PWR_LEVELS` and the source TPE array bound (`IEEE80211_TPE_PSD_ENTRIES_320MHZ` or `IEEE80211_TPE_EIRP_ENTRIES_320MHZ`). Because `ath12k_a_rates` is `ath12k_legacy_rates + 4` (`ATH12K_MAC_FIRST_OFDM_RATE_IDX`), 5/6 GHz legacy rate indices must add `ATH12K_MAC_FIRST_OFDM_RATE_IDX` before indexing `ath12k_legacy_rates`. [F64, F67]
- In `ath12k_mac_hw_register()`, per-wiphy capabilities (`max_ap_assoc_sta`, `mbssid_max_interfaces`, `available_antennas_rx/tx`, `ht_cap`) and per-radio init (`ath12k_regd_update()`, `ath12k_fw_stats_init()`, `ath12k_debugfs_register()`) must run across all radios via `for_each_ar(ah, ar, i)`, and `__ath12k_set_antenna()` must clamp `tx_ant`/`rx_ant` to `ar->pdev->cap.tx_chain_mask` and `rx_chain_mask`. [F58, F106, F111]

## Synchronization
- Spinlocks shared with softirq/tasklet WMI, HTT, and data-path handlers (`ar->data_lock`, `ab->base_lock`, `ar->txmgmt_idr_lock`, `dp->tx_desc_lock`) must always use `spin_lock_bh()` / `spin_unlock_bh()`. [F122]
- `ath12k_mac_op_tx()`, `ath12k_mac_get_tx_link()`, and `ath12k_mlo_mcast_update_tx_link_address()` run in atomic RCU read-side context: all link dereferences (`ahvif->link`, `vif->link_conf`, `sta->link`) must use `rcu_dereference()`, SKB allocations must use `GFP_ATOMIC` (including `pskb_expand_head()` under `ar->data_lock` before `skb_put_data()` in `ath12k_mac_add_p2p_noa_ie()`), and WMI management TX must be deferred to `ar->wmi_mgmt_tx_work`. [F118, F135]
- `ath12k_mac_op_link_sta_rc_update()` runs in atomic context without `wiphy_lock`: it must hold `rcu_read_lock()` while dereferencing links, stage `arsta->changed`, `bw`, `bw_prev`, `nss`, and `smps` under `spin_lock_bh(&ar->data_lock)`, and defer WMI calls to `arsta->update_wk` (`ath12k_sta_rc_update_wk()`), which snapshots those fields under `ar->data_lock` and drops it before sending WMI commands or waiting on `ar->peer_assoc_done`. [F25, F119]
- In `ath12k_mac_set_key()`, `ab->base_lock` is dropped across blocking calls `ath12k_install_key()` and `ath12k_dp_rx_peer_pn_replay_config()`, so `peer` must be re-looked up via `ath12k_peer_find()` after relocking `ab->base_lock` before updating `peer->keys[]`. [F24]
- In `ath12k_bss_assoc()`, `ieee80211_find_sta()`, `ath12k_peer_assoc_prepare()`, and `ath12k_mac_vif_recalc_sta_he_txbf()` (`&link_sta->he_cap`) must run inside `rcu_read_lock()`, which must be released before calling blocking WMI commands `ath12k_wmi_vdev_set_param_cmd()` and `ath12k_wmi_send_peer_assoc_cmd()`. [F127]
- In `ath12k_scan_abort()`, `ar->data_lock` must be held while checking `ar->scan.state` and transitioning `ATH12K_SCAN_RUNNING` to `ATH12K_SCAN_ABORTING`, but released before calling `ath12k_scan_stop(ar)`. On scan cleanup or abort (`ath12k_scan_vdev_clean_work()`, `ath12k_mac_op_hw_scan()`, `ath12k_mac_op_remove_interface()`), `ar->scan.arvif = NULL`, `ar->scan.state = ATH12K_SCAN_IDLE`, `ar->scan_channel = NULL`, and `ar->scan.roc_freq = 0` must be reset together under `ar->data_lock`. [F22, F60]
- In `ath12k_mac_assign_link_sta()`, all `arsta` fields (`addr`, `link_idx`, `link_id`, `arvif`, `ahsta`), `ahsta->links_map`, and `wiphy_work_init(&arsta->update_wk, ...)` must be initialized before `rcu_assign_pointer(ahsta->link[link_id], arsta)`. [F20]
- `ath12k_mac_op_start()` and `ath12k_mac_op_stop()` must call `ath12k_drain_tx(ah)` under `wiphy_lock` before acquiring `ah->hw_mutex`, and `ath12k_mac_start()` / `ath12k_mac_stop()` require both locks. Before waiting on `ar->dp.tx_empty_waitq` and `ar->txmgmt_empty_waitq` in `ath12k_mac_flush()`, `ath12k_mac_drain_tx(ar)` must call `synchronize_net()`, cancel `ar->wmi_mgmt_tx_work`, and purge `ar->wmi_mgmt_tx_queue`. [F27, F30, F117]

## Object Lifetimes
- `ath12k_mac_assign_link_vif()` uses embedded `ahvif->deflink` for the first non-scan link and `kzalloc`s others; `ath12k_mac_unassign_link_vif()` and `ath12k_mac_free_unassign_link_sta()` must clear `ahvif->link[link_id]` or `ahsta->link[link_id]` (and `ahsta->links_map`) with `rcu_assign_pointer(..., NULL)`, call `synchronize_rcu()`, and when `arvif == &ahvif->deflink` or `arsta == &ahsta->deflink`, `memset` `arvif` or reset `arsta->link_id = ATH12K_INVALID_LINK_ID`, `arsta->ahsta = NULL`, and `arsta->arvif = NULL` instead of `kfree()`. [F2, F3, F19]
- When moving an `arvif` to a different `ar` in `ath12k_mac_initiate_hw_scan()`, `ath12k_mac_assign_vif_to_vdev()`, or `ath12k_mac_op_remain_on_channel()`, `ath12k_mac_unassign_link_vif(arvif)` frees or zeroes `arvif`, so `arvif` must be re-acquired via `ath12k_mac_assign_link_vif()` before further use. [F55]
- Before tearing down a station or link interface, pending work items must be synchronously cancelled: `arsta->update_wk` via `wiphy_work_cancel()` in `ath12k_mac_station_remove()`, `arvif->connection_loss_work` via `cancel_delayed_work_sync()` in `ath12k_mac_remove_link_interface()`, and `ar->scan.vdev_clean_wk` via `wiphy_work_cancel()` (plus clearing `ar->scan.arvif` under `ar->data_lock`) when removing `ar->scan.arvif`. [F23, F129]
- In `ath12k_mac_op_tx()`, neither `ath12k_mac_mgmt_tx()` nor `ath12k_dp_tx()` consumes `skb` on failure: `ath12k_mac_op_tx()` must free the original `skb` via `ieee80211_free_txskb()` on every error or after the MLO multicast `skb_copy()` loop, while the loop operates on `tmp_arvif`, `tmp_ar = tmp_arvif->ar`, and `msdu_copied = skb_copy(skb, GFP_ATOMIC)` (freeing failed clones via `dev_kfree_skb_any()`). [F4, F88]
- `ath12k_mac_start()` publishes `ab->pdevs_active[ar->pdev_idx]` via `rcu_assign_pointer()` only after WMI/channel/counter/monitor setup succeeds; `ath12k_mac_stop()` must cancel `scan.timeout`, `scan.vdev_clean_wk`, `regd_channel_update_work`, `regd_update_work`, `ab->rfkill_work`, and `ab->update_11d_work`, drain `ppdu_stats_info` and `regd_channel_update_queue` under `ar->data_lock`, and clear `pdevs_active[ar->pdev_idx]` followed by `synchronize_rcu()`. [F29, F125]
- In `ath12k_mac_hw_unregister()`, per-radio regulatory work, debugfs, and `ath12k_fw_stats_reset(ar)` must run before `ieee80211_unregister_hw(hw)`, whereas `txmgmt_idr` destruction, channel array deallocation, and `ath12k_mac_cleanup_iface_combinations()` must run after. `ath12k_mac_get_fw_stats()` must also call `ath12k_fw_stats_reset(ar)` under `ah->hw_mutex` before requesting new stats. [F12, F108]
- `ath12k_mac_hw_allocate()` allocates `ah` with `struct_size(ah, radio, num_pdev_map)` and sets `pdev->ar = ar`; `ath12k_mac_destroy()` must clear `pdev->ar = NULL` across all `ag->ab[i]->pdevs[j]` and clear `ag->ah[i]` via `ath12k_ag_set_ah(ag, i, NULL)` when freeing `ah`. [F14, F101]

## API Contracts
- Callers of `ath12k_mac_get_arvif()`, `ath12k_mac_get_arvif_by_vdev_id()`, `ath12k_mac_get_ar_by_vdev_id()`, and `ath12k_mac_get_ar_by_pdev_id()` must hold `rcu_read_lock()` across the call and for the entire use of the returned `arvif` or `ar`. [F120]
- `ath12k_mac_init_arvif()` takes a signed `link_id`: `link_id < 0` (passed as `-1` in `ath12k_mac_op_add_interface()` for `ahvif->deflink`) sets `arvif->link_id = 0` without populating `ahvif->link[]` or `ahvif->links_map`, whereas `link_id >= 0` publishes `arvif` in `ahvif->link[link_id]` and `ahvif->links_map`. [F46]
- Callers of `ath12k_wmi_send_peer_assoc_cmd()` must set `peer_arg->is_assoc = true` only during initial association (`ath12k_bss_assoc()`, `ath12k_mac_station_assoc()`) and `false` during post-association updates (`ath12k_sta_rc_update_wk()`). Before calling `ath12k_reg_handle_chan_list()` on interface add or station state change, `ah->regd_updated = false` must be reset. [F53, F54]
- In `ath12k_install_key()`, a STA `WMI_KEY_GROUP` `SET_KEY` arriving while `!arvif->pairwise_key_done` must be cached in `arvif->group_key` (`group_key_valid = true`) and deferred until `WMI_KEY_PAIRWISE` installation finishes. In `ath12k_mac_update_vif_chan()`, `ath12k_mac_vdev_restart()` is only called when `arvif->is_up`; otherwise call `vdev_stop()`, `vdev_start()`, and `continue` without `ath12k_wmi_vdev_up()`. [F79, F83]

## Error Handling
- In `ath12k_mac_mgmt_tx_wmi()`, `skb_put(skb, mic_len)` (via `ath12k_dp_rx_crypto_mic_len()`) for protected management frames without `IEEE80211_TX_CTL_HW_80211_ENCAP` must precede `dma_map_single()`; on error or any removal from `ar->txmgmt_idr`, `skb_cb->paddr` must be unmapped with `dma_unmap_single()` without freeing `skb` in `ath12k_mac_mgmt_tx_wmi()`. [F6, F128, F133]
- Creating/deleting a WMI VDEV in `ath12k_mac_vdev_create()`, `ath12k_mac_vdev_delete()`, and `ath12k_mac_monitor_vdev_delete()` must update `ab->free_vdev_map`, `ar->allocated_vdev_map`, and `ar->num_created_vdevs` in lockstep and link/unlink `arvif->list` in `ar->arvifs` under `ar->data_lock`. Any error after `ath12k_wmi_vdev_create()` in `ath12k_mac_vdev_create()` must jump to `err_peer_del` or `err_vdev_del`. [F8, F49]
- All `ar->txmgmt_idr` operations require `spin_lock_bh(&ar->txmgmt_idr_lock)`. In `ath12k_mac_vdev_delete()`, even if WMI delete fails or `ar->vdev_delete_done` times out, `err_vdev_del` must still unlink `arvif->list`, clean up peers and link cache, purge `vif` from `ar->txmgmt_idr` and `dp->tx_desc_used_list` under `dp->tx_desc_lock[i]` (`ath12k_mac_vif_unref()`), release `arvif->bank_id`, and clear `arvif->is_created` and `arvif->ar`. [F7, F28]
- In `ath12k_mac_station_add()`, error labels (`free_peer`, `dec_num_station`) and `ath12k_mac_station_post_remove()` must symmetrically undo `ath12k_peer_create()`, `kfree(arsta->rx_stats)` (setting `rx_stats = NULL`), and `ath12k_mac_inc_num_stations()`. [F10]
- `ath12k_mac_get_rate_hw_value()` has return type `u32` but returns `-EINVAL` on miss, so callers must store its result in a signed `int` and check `< 0`. In `ath12k_scan_stop()`, positive jiffies from `wait_for_completion_timeout()` must be normalized to `0` (and `0` to `-ETIMEDOUT`) before `out:`. [F32, F33]
- In `ath12k_mac_vdev_setup_sync()`, `__ath12k_mac_mlo_setup()`, and `ath12k_mac_set_key()`, callers must check both `wait_for_completion_timeout()` for `0` and the status field on `ar` (`last_wmi_vdev_start_status`, `mlo_setup_status`, `install_key_status`). When `ath12k_mac_assign_vif_to_vdev()` returns `NULL`, `arvif->ar` is `NULL`, so callers must log with `ath12k_hw_warn(ah, ...)`. [F34, F35]

## External Contracts
- Because `ath12k_mac_op_add_interface()` defers VDEV creation, per-link callbacks (`ath12k_mac_op_link_info_changed()`, `ath12k_mac_op_set_key()`, `ath12k_mac_op_conf_tx()`) when `!arvif || !arvif->is_created` must cache state via `ath12k_ahvif_get_link_cache()` for `ath12k_mac_vif_cache_flush()`. VIF-level flags (`BSS_CHANGED_PS`, `BSS_CHANGED_ASSOC`) must be handled in `ath12k_mac_op_vif_cfg_changed()` across `ahvif->links_map`, associating `ahsta->assoc_link_id` first and clearing `BIT(ahsta->assoc_link_id)` before partner links. [F86, F130, F139]
- On `IEEE80211_STA_AUTHORIZED` to `IEEE80211_STA_ASSOC`, `ath12k_mac_station_unauthorize()` must clear `peer->is_authorized` under `ab->base_lock` and call `ath12k_clear_peer_keys()` synchronously. In `ath12k_sta_rc_update_wk()` under `IEEE80211_RC_BW_CHANGED`, `bw > bw_prev` must send `WMI_PEER_PHYMODE` before `WMI_PEER_CHWIDTH`, and `bw <= bw_prev` must reverse that order. [F50, F52]

## Known Pitfalls
- Narrow bitmaps (`ahvif->links_map`, `ahsta->links_map`, `vif->valid_links`, `sta->valid_links`) must be copied into a local `unsigned long` before passing to `for_each_set_bit()`. 64-bit bitmaps (`free_vdev_map`, `allocated_vdev_map`, `free_vdev_stats_id_map`) must use `1LL << ...` and `__ffs64()`, and `sinfo->filled` / `link_sinfo->filled` must use `BIT_ULL()`. [F91, F92, F104]
- Validate lengths before reading/stripping SKB IEs: check `datalen` in `ath12k_mac_set_arvif_ies()`, check `skb->len >= IEEE80211_MIN_ACTION_SIZE` and `remaining_len >= iv_len` in `ath12k_mac_mgmt_action_frame_fill_elem_data()`, and in `ath12k_mac_remove_vendor_ie()` check `skb->len < ie_offset` and `next > end` before compacting `[next, end)` with `memmove()` (never `memcpy()`). [F68, F69, F70, F103]
- In `ath12k_mac_update_key_cache()`, a matching `key_conf->key == key` on `cmd == SET_KEY` must return `0` before `list_del()`/`kfree()`, and new insertion after the loop requires `if (cmd == SET_KEY)`. In `ath12k_install_key()`, `ahvif->key_cipher` is updated when `arg.macaddr` matches `arvif->bssid` (not `vif->addr`). [F78, F80]
