# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS

This unit (`fs/nfsd`) implements the Linux kernel NFSv2/v3/v4 server, including SunRPC service management, filehandle verification/encoding, the duplicate reply cache (DRC), ACL translation, ID mapping, the NFSv4 state manager, pNFS layouts, backchannel callbacks, client recovery tracking, lockd bindings, and LOCALIO support.

## Architecture & Data Flow

- `nfs4_stid` (`dl_stid`, `st_stid`, `ls_stid`) must remain at offset 0 of `nfs4_delegation`, `nfs4_ol_stateid`, and `nfs4_layout_stateid`; `nfs4_stateowner` (`oo_owner`, `lo_owner`) must remain at offset 0 of `nfs4_openowner` and `nfs4_lockowner`. `nfs4_cb_fattr` for `NFSPROC4_CLNT_CB_GETATTR` must be embedded at `nfs4_delegation.dl_cb_fattr`, and `nfsd4_cb_offload` for `nfsd4_cb_offload_ops` at `nfsd4_copy.cp_cb_offload`. [F133, F295, F296]
- Check `so->so_is_open_owner` before `openowner(so)`/`lockowner(so)` on `cl_ownerstr_hashtbl` entries, `st->st_openstp == NULL` before treating `fi_stateids` entries as open stateids, `stid->sc_type == SC_TYPE_LAYOUT` before `container_of` in `nfsd4_preprocess_layout_stateid`, `cs_type == NFS4_COPYNOTIFY_STID` before `container_of` on `nn->s2s_cp_stateids` entries, and `fl->fl_lmops` against `&nfsd_lease_mng_ops` or `&nfsd_posix_mng_ops` before casting `fl->c.flc_owner`. [F131, F221, F224, F298]
- `se_cb_seq_nr` is 0-indexed up to `se_cb_highest_slot` (clamped to `NFSD_BC_SLOT_TABLE_SIZE - 1` in `alloc_session` and `update_cb_slot_table`); `update_cb_slot_table` under `se_lock` must reset `se_cb_seq_nr[i] = 1` for newly exposed slots `(se_cb_highest_slot + 1 .. target)`. `grab_slot`/`highest_slotid` must subtract 1 from `ffs`/`fls`. `cb->cb_held_slot` uses `-1` for "no slot held"; verify `0 <= idx <= se_cb_highest_slot` in `grab_slot` and `cb_held_slot >= 0` in `nfsd41_cb_release_slot` before `BIT()`. [F50, F57, F85, F126, F262]
- `nfsd4_cb_prepare()` must set `cb->cb_seq_status = 1` and `cb->cb_status = 0` before each RPC task (and before sleeping on `-NFS4ERR_DELAY`). In `nfsd4_cb_sequence_done()`, increment `session->se_cb_seq_nr[cb->cb_held_slot]` only when `cb->cb_seq_status == 0`; on `-NFS4ERR_SEQ_MISORDERED` or `-NFS4ERR_BADSLOT`, call `nfsd4_mark_cb_fault()` and set `cb->cb_held_slot = -1` before `nfsd41_cb_release_slot()` so the desynchronized slot is never reused. [F58, F59, F60]
- Each bit in `stp->st_access_bmap` holds one `fi_access[O_RDONLY]`/`fi_access[O_WRONLY]` ref; check `test_access()` before `__nfs4_file_get_access()`/`nfs4_file_put_access()`. `fi_share_deny` caches the union of `bmap_to_share_mode(stp->st_deny_bmap)` across `fp->fi_stateids` and must be updated under `fi_lock` or recomputed via `recalculate_deny_mode()`/`reset_union_bmap_deny()`. When `nfsd4_add_rdaccess_to_wrdeleg()` sets `fi_rdeleg_file`, `put_deleg_file()` must release it via `nfs4_file_put_access(fp, NFS4_SHARE_ACCESS_READ)` when `--fi_delegees == 0`. [F237, F238, F240]
- Paired state counters must stay in lockstep: `ls->ls_recalled = true` in `nfsd4_recall_file_layout` with `atomic_inc(&fi_lo_recalls)` under `ls_lock` (decremented in `nfsd4_free_layout_stateid` iff `ls_recalled`); `dp->dl_recalled = true` in `nfsd_break_deleg_cb` under `flc_lock` with `cl_delegs_in_recall` (decremented in `nfsd_change_deleg_cb` on `F_UNLCK` iff `dl_recalled`); `SC_STATUS_ADMIN_REVOKED` with `atomic_inc(&clp->cl_admin_revoked)`; and `nn->reclaim_str_hashtbl` entries with `reclaim_str_hashtbl_size`. [F64, F198, F254, F255]
- Compare `stateid_t` `si_generation` values with `nfsd4_stateid_generation_after(a, b)` (`(s32)(a->si_generation - b->si_generation) > 0`), and in `nfs4_inc_and_copy_stateid`, skip wraparound to `0` by setting `src->si_generation = 1`. In `nfsd4_decode_compound`, force `argp->opcnt = 0` when `argp->minorversion > NFSD_SUPPORTED_MINOR_VERSION`, and guard any `OPDESC(op)` or `NFSD_STATS_NFS4_OP(op->opnum)` indexing before `op->status` check against `op->opnum == OP_ILLEGAL`. [F98, F292, F293, F424]

## Synchronization

- Spinlock nesting in `fs/nfsd/nfs4state.c`: `state_lock` -> `clp->cl_lock` -> `fp->fi_lock`, and `nn->client_lock` -> `clp->cl_lock` -> `nfsd_session_list_lock` (`reduce_session_slots` under `nfsd_session_list_lock` must use `spin_trylock(&nn->client_lock)`). In `nfs4layouts.c`, `ls->ls_lock` nests inside `fp->fi_lock` and `clp->cl_lock`, and `fp->fi_lock` nests inside `ls->ls_mutex`. In `nfsd4_async_copy_reaper`, `clp->async_lock` nests inside `nn->client_lock`, and `cleanup_async_copy` must be called only after dropping both locks. [F146, F155, F209, F308]
- `stp->st_mutex` nests outside `cl_lock` and `fi_lock`: pin `sc_count`, drop spinlocks, and call `nfsd4_lock_ol_stateid(stp)`. In `init_open_stateid`/`init_lock_stateid`, lock candidate `stp->st_mutex` with `OPEN_STATEID_MUTEX` before `retry:`; if `retstp` is found, `nfsd4_lock_ol_stateid(retstp)` uses `LOCK_STATEID_MUTEX` (keep `stp->st_mutex` locked across `goto retry`, or unlock it before returning `retstp`), and check `!nfs4_openowner_unhashed(oo)` or `!nfs4_ol_stateid_unhashed(open_stp)` under `cl_lock`. [F211, F212, F287, F313]
- VFS lease-break callbacks (`nfsd_break_deleg_cb`/`nfsd_break_one_deleg` and `nfsd4_layout_lm_break`/`nfsd4_recall_file_layout`) run under the atomic VFS `flc_lock` spinlock and must never sleep, block on allocations, or take `state_lock` (`del_recall_lru` queuing is deferred to `nfsd4_cb_recall_prepare`). If `nfsd4_run_cb(&dp->dl_recall)` fails in `nfsd_break_one_deleg`, drop the ref with `refcount_dec(&dp->dl_stid.sc_count)` rather than `nfs4_put_stid(&dp->dl_stid)`, and `nfs4_free_deleg` must never sleep. [F148, F204, F306]
- While holding `clp->cl_lock`, drop open/lock stateid references via `put_ol_stateid_locked(stp, &reaplist)` (only after `unhash_open_stateid` has drained child lock stateids from `stp->st_locks`, which is reused as the reaplist link) and call `free_ol_stateid_reaplist(&reaplist)` after unlocking `cl_lock`. `nfsd4_drop_revoked_stid` is entered with `s->sc_client->cl_lock` held and must release `cl_lock` on every branch before `free_ol_stateid_reaplist` or `nfs4_put_stid`. [F191, F201, F276]
- `destroy_unhashed_deleg` and `revoke_delegation` must be called only after `unhash_delegation_locked` and dropping `state_lock`. Callers invoking `revoke_delegation` must pin `dp->dl_stid.sc_count` before dropping `state_lock`; `dp->dl_recall_lru` is reused as the `reaplist` link and must be unlinked with `list_del_init(&dp->dl_recall_lru)` before `revoke_delegation`/`destroy_unhashed_deleg`. `nfsd4_free_stateid` must set `SC_STATUS_CLOSED` under `sc_lock` and `SC_STATUS_FREED` under `cl_lock` before dropping `cl_lock` to call `nfs4_put_stid(s)`. [F206, F207, F277, F315]
- In `nfsd4_insert_layout`, after dropping `ls->ls_lock` and `fp->fi_lock` for `GFP_KERNEL` allocation, reacquire both and re-run `nfsd4_recall_conflict` and `layouts_try_merge` before inserting. In `nfsd4_close_layout`, extract and clear `ls->ls_file = NULL` under `fi_lock` before `kernel_setlease(..., F_UNLCK, ...)` and `nfsd_file_put` outside the lock. In `nfsd4_cb_layout_done`, pin `ls->ls_file` via `nfsd_file_get` under `rcu_read_lock()` before `ops->fence_client` or `nfsd4_cb_layout_fail`. [F25, F27, F149]
- In `nfsd4_copy`, fully initialize `async_copy` before adding `async_copy->copies` to `cp_clp->async_copies` under `async_lock` and calling `wake_up_process(copy_task)`. `nfsd4_do_async_copy` and `nfsd4_stop_copy` synchronize via `!test_and_set_bit(NFSD4_COPY_F_STOPPED, &copy->cp_flags)` before `kthread_stop(copy->copy_task)`. In `nfsd4_shutdown_copy`/`nfsd4_offload_cancel`, increment `copy->refcount` (and unlink `copy->copies` in `nfsd4_unhash_copy`) under `clp->async_lock` and drop `async_lock` before `nfsd4_stop_copy`. [F28, F30, F156]
- Lookups in `nfs4_file_rhltable` must hold `rcu_read_lock()` and use `refcount_inc_not_zero(&fi->fi_ref)`; `nfsd4_file_hash_insert` must hold `inode->i_lock` across lookup, setting `fi_aliased = true` on both existing sibling entries and the new entry, `nfsd4_file_init`, and `rhltable_insert`. In `nfsd4_check_conflicting_opens`, `smp_mb__after_atomic()` must follow `atomic_read(&ino->i_writecount)` before reading `fp->fi_fds[]`. In `nfsd4_delegreturn`, `smp_mb__after_atomic()` must follow `destroy_delegation(dp)` before `wake_up_var(inode)`. [F215, F216, F218, F249]
- In `nfsd4_lock`, queue a blocking lock (`FL_SLEEP`) onto `lock_sop->lo_blocked` and `nn->blocked_locks_lru` with `kref_get(&nbl->nbl_kref)` under `nn->blocked_locks_lock` before `vfs_lock_file`; `nfsd4_lock()` cleanup must check `!list_empty(&nbl->nbl_list) && !list_empty(&nbl->nbl_lru)` under `blocked_locks_lock` before unlinking and putting `nbl_kref`, and `locks_delete_block`/`free_blocked_lock` must be called only after dropping `blocked_locks_lock`. [F217, F278, F316]

## Object Lifetimes

- Callers of `fh_verify()`/`fh_verify_local()` must call `fh_put(fhp)` even on error because `nfsd_set_fh_dentry()` sets `fh_dentry`/`fh_export` before `__fh_verify()` checks can fail; `fh_put()` must call `fh_drop_write(fhp)` before `exp_put(fhp->fh_export)`. `nfsd3_proc_fsstat`/`fsinfo`/`pathconf` lack `.pc_release` and must call `fh_put(&argp->fh)`; NFSv2 `.pc_release` only puts `resp->fh`; `nfsacld_proc_setacl` and `nfsd3_proc_setacl` must call `posix_acl_release` on `argp->acl_access` and `acl_default`. [F3, F20, F337, F338, F341]
- `nfsd4_run_cb` calls `nfsd41_cb_inflight_begin` before `nfsd4_queue_cb` (calling `nfsd41_cb_inflight_end` immediately if queueing returns `false`), and every queued callback work must terminate through `nfsd41_destroy_cb` or `nfsd4_cb_probe_release` to call `nfsd41_cb_inflight_end(clp)`. In `nfsd4_cb_getattr_release`, `nfsd4_cb_recall_release`, `nfsd4_cb_notify_lock_release`, and `nfsd4_cb_recall_any_release`, dropping the enclosing reference (`nfs4_put_stid`, `free_blocked_lock`, `drop_client`) must be the final action. [F7, F192]
- In `nfsd4_copy`, when `nfsd4_copy_is_async(copy)` is true, never pass stack/arg `copy` or `copy->cp_src` to `nfsd4_do_async_copy`; allocate `async_copy` and `async_copy->cp_src` via `dup_copy_fields`, and run `INIT_LIST_HEAD(&async_copy->copies)` and `refcount_set(&async_copy->refcount, 1)` immediately after `kzalloc` before any jump to `out_dec_async_copy_err` or `out_err`. Decrement `nn->pending_async_copies` once per `atomic_inc_return`: at `out_dec_async_copy_err` before `wake_up_process` or at the end of `nfsd4_do_async_copy`, never in `cleanup_async_copy`. [F11, F12, F138]
- In `nfsd4_open`, once `nfsd4_process_open1` is called, every exit path must reach `out:` (`fput(open->op_filp)`, `fh_put`/`kfree(resfh)`, `nfsd4_cleanup_open_state`, `nfsd4_bump_seqid`). When `nfsd4_process_open2` or `init_open_stateid` hashes `open->op_file`, `open->op_stp`, or `open->op_odstate`, clear that `open->op_*` pointer to `NULL` so `nfsd4_cleanup_open_state` only frees unconsumed objects. `nfsd4_sequence_check_conn` unconditionally consumes `new`, so `nfsd4_sequence` must set `conn = NULL` immediately after calling it. [F15, F185, F186]
- In `destroy_unhashed_deleg` or `nfs4_set_delegation` rollback, remove the VFS lease via `nfs4_unlock_deleg_lease` (`nfsd4_finalize_deleg_timestamps` + `kernel_setlease(..., F_UNLCK, ...)`) before `nfs4_put_stid(&dp->dl_stid)`. Clear `s->st_stid.sc_file = NULL` after `put_nfs4_file` in `move_to_close_lru`, and in `__nfs4_file_put_access` and `put_deleg_file`, clear `fp->fi_fds[]`, `fp->fi_deleg_file`, and `fp->fi_rdeleg_file` to `NULL` under `fp->fi_lock` before calling `nfsd_file_put` outside the lock. [F189, F193, F195, F322]

## API Contracts

- `nfs4_preprocess_stateid_op` leaves `*cstid` untouched for `ZERO_STATEID`/`ONE_STATEID` and transfers the `s` ref to `*cstid` only on `nfs_ok` when `cstid != NULL` (calling `nfs4_put_stid(s)` otherwise); callers must init `*cstid = NULL` and check `if (st)` on `nfs_ok`. `nfs4_preprocess_seqid_op` and `nfs4_preprocess_confirmed_seqid_op` only accept `SC_TYPE_OPEN`/`SC_TYPE_LOCK` and return `nfs_ok` with `*stpp` referenced and `st_mutex` locked; `nfsd4_preprocess_layout_stateid` returns `0` with `ls_stid` referenced and `ls_mutex` locked. [F51, F188, F199, F230, F299]
- `nfsd4_deleg_getattr_conflict(rqstp, dentry, pdp)` pins `dp->dl_stid.sc_count` under `ctx->flc_lock` before waiting or breaking the lease, and only writes `*pdp = dp` when returning `nfs_ok` with `ncf->ncf_file_modified` true (putting `dp->dl_stid` on all other paths); callers must initialize `*pdp = NULL` beforehand and call `nfs4_put_stid(&dp->dl_stid)` if `*pdp != NULL`. `get_client_locked(clp)` returns `nfserr_expired` without incrementing `cl_rpc_users` if `is_client_expired(clp)` is true; callers must check for `nfs_ok`. [F208, F219, F234]
- In `struct nfs4_file`, `fi_fds[3]` is indexed by `O_RDONLY`/`O_WRONLY`/`O_RDWR` via `nfs4_access_to_omode()`, whereas `fi_access[2]` and `__nfs4_file_put_access(fp, oflag)` only accept `O_RDONLY` (0) or `O_WRONLY` (1). `stp->st_access_bmap` and `stp->st_deny_bmap` store `1 << mode` (bits 1..3), so converting to wire `NFS4_SHARE_*` masks or calling `reset_union_bmap_deny(deny, stp)` requires `bmap_to_share_mode()`. [F225, F226]

## Error Handling

- Backchannel XDR reply decoders in `fs/nfsd/nfs4callback.c` must return negative errno `-EIO` on XDR stream/bounds failures (never `-NFSERR_BAD_XDR` or positive `NFS4ERR_*`), and callers of `decode_cb_sequence4res` and `decode_cb_op_status` must check that both `status` and `cb->cb_seq_status`/`cb->cb_status` are zero before decoding further payload. [F34, F35]
- In `nfsd_open_local_fh`, validate `nfs_fh->size <= NFS4_FHSIZE` before `memcpy`, convert a non-zero `__be32` `beres` from `nfsd_file_acquire_local` via `ERR_PTR(nfs_stat_to_errno(be32_to_cpu(beres)))` before checking `IS_ERR(localio)`, and call `put_group_info(rq_cred.cr_group_info)` if non-NULL. In `fs/nfsd/nfsfh.c`, `__fh_verify()`, `nfsd_set_fh_dentry()`, and `nfsd_setuser_and_check_port()` must guard every `rqstp` dereference for NULL (LOCALIO), and `nfsd_set_fh_dentry()` must check `exportfs_decode_fh_raw()` with `IS_ERR_OR_NULL()`. [F38, F89, F163, F376, F377]

## External Contracts

- In `encode_cb_getattr4args()`, set `FATTR4_WORD0_CHANGE` in `bmap[0]` only when `!ncf->ncf_file_modified`. `nfs4_open_delegation()` must snapshot initial timestamps via `nfs4_delegation_stat()` into `dp->dl_atime`/`dl_mtime`/`dl_ctime` using `file_dentry(nf->nf_file)` on `dp->dl_stid.sc_file` (never `currentfh->fh_dentry`). In `nfsd4_setattr` (`vet_deleg_attrs`) and `cb_getattr_update_times()`, vet delegated timestamps against `dp->dl_*time` via `nfsd4_vet_deleg_time()`, and set `ATTR_*_SET` and `ATTR_DELEG` before `notify_change()`. [F56, F84, F241, F268, F321]

## Known Pitfalls

- In `fs/nfsd/nfs4xdr.c` encoders (`nfsd4_encode_read`, `nfsd4_encode_read_plus*`, `nfsd4_encode_fattr4`, `nfsd4_encode_operation`), never dereference `__be32 *p` from `xdr_reserve_space()` after subsequent XDR encoding or `xdr_commit_encode()`; save `xdr->buf->len` and backfill via `write_bytes_to_xdr_buf()`. XDR strings (`nfsd4_decode_component4`, `nfsd4_decode_opaque`, `nfsd4_decode_nl4_server`, `svcxdr_decode_filename`), `xdr_netobj_dup` buffers, and `idmap_name_to_id`/`numeric_name_to_id` inputs are not NUL-terminated; bound all reads by `.len`/`namelen`. [F137, F303, F396, F470]
