# ARM PORT

Platform and SoC support for Samsung Exynos (`mach-exynos`), Samsung S5PV210 (`mach-s5pv210`), Freescale/NXP i.MX (`mach-imx`), Freescale MXS (`mach-mxs`), and NXP LPC18xx (`mach-lpc18xx`). It implements early machine initialization, SMP secondary CPU bring-up and hotplug, Multi-Cluster Power Management (MCPM), TrustZone secure firmware SMC calls, system suspend/resume (including OCRAM-resident assembly routines), cpuidle drivers, interrupt controller hierarchies (PMU, GPC, AVIC, TZIC), reset control (SRC), and MMDC memory controller performance monitoring.

## Architecture & Data Flow

- `struct imx6_cpu_pm_info` and `struct imx5_cpu_suspend_info` must stay `__aligned(8)` because `imx6q_suspend_init()` and `imx5_suspend_init()` pass `suspend_ocram_base + sizeof(...)` to `fncpy()`, which `BUG_ON`s if unaligned. Layout changes to `imx6_cpu_pm_info` or `imx6_pm_base` must update `PM_INFO_*_OFFSET` in `suspend-imx6.S` (keeping `pm_info_size` equal to the relocated `imx6_suspend` offset), and changes to `imx5_cpu_suspend_info` or `imx5_suspend_io_state` must update `SUSPEND_INFO_MX53_*_OFFSET` and strides in `suspend-imx53.S`. [F76, F77, F79]
- `imx6q_suspend_init()` must map `suspend_ocram_base` with `__arm_ioremap_exec()`, zero it with `memset(suspend_ocram_base, 0, sizeof(*pm_info))` (since `l2_base` is only populated when `socdata->pl310_compat` is non-NULL, and `imx6q_suspend_finish()` and `suspend-imx6.S` check `l2_base.vbase` for NULL), populate `imx6_cpu_pm_info`, and copy `imx6_suspend` via `fncpy()` before calling `__arm_iomem_set_ro(suspend_ocram_base, MX6Q_SUSPEND_OCRAM_SIZE)`. [F29, F108]
- On i.MX6, `imx6_pm_ccm_init()` must run before `imx6_pm_common_init()` and `imx6q_suspend_init()` so `ccm_base` is mapped before use and copied into `pm_info->ccm_base.vbase`. In `imx6_pm_stby_poweroff()`, `gic_cpu_if_down(0)` must precede `imx6_set_lpm(STOP_POWER_OFF)` and `imx6q_suspend_finish(0)`. In `mx5_suspend_enter()`, `mx5_cpu_lp_set(IMX5_DEFAULT_CPU_IDLE_STATE)` must be restored before returning. [F46, F84, F85]
- In `imx6_set_lpm()`, when `mode != WAIT_CLOCKED`, GPC hwirq 0 (GIC SPI #0 / IOMUX IRQ #32, held pending by `IMX6Q_GPR1_GINT` in `imx6_pm_common_init()`) must be unmasked via `imx_gpc_hwirq_unmask(0)` right before writing `ccm_base + CLPCR` and masked via `imx_gpc_hwirq_mask(0)` right after (ERR007265). Both helpers take a 0-based GIC SPI hwirq (`< GPC_MAX_IRQS`), not the 32-based SoC IRQ. [F35, F92]
- In `struct mmdc_pmu` (`arch/arm/mach-imx/mmdc.c`), `struct pmu pmu` must remain the first member at offset 0 because `mmdc_pmu_cpumask_show()` casts `dev_get_drvdata(dev)` (`&pmu_mmdc->pmu`) directly to `struct mmdc_pmu *`. Also, `mmdc_pmu_event_add()` must check `pmu_mmdc->mmdc_events[cfg] != NULL` before storing `event` and incrementing `active_events`, and `mmdc_pmu_event_del()` must clear `mmdc_events[cfg] = NULL`, decrement `active_events`, and call `hrtimer_cancel(&pmu_mmdc->hrtimer)` when `active_events` reaches 0. [F3, F74]
- In `exynos_pm_init()`, when `exynos_secure_firmware_available()` is true, `pm_state.sysram_base` must point to `sysram_ns_base_addr` (not `sysram_base_addr`) and `pm_state.secure_firmware` must be set. `exynos5420_pm_prepare()` must save `pm_state.cpu_state` from `sysram_base + EXYNOS5420_CPU_STATE` before zeroing it, and `exynos5420_pm_resume()` must restore it before `exynos_pm_central_resume()`, issuing `exynos_smc(SMC_CMD_REG, SMC_REG_ID_SFR_W(pm_state.sysram_phys + EXYNOS5420_CPU_STATE), ...)` using the physical address when `pm_state.secure_firmware` is true. [F11, F37, F89]
- On Exynos5420/5800, `exynos_cpu_power_down()` must not clear `S5P_CORE_LOCAL_PWR_EN` for CPU 0 when `EXYNOS5_ARM_CORE0_SYS_PWR_REG` has `S5P_CORE_LOCAL_PWR_EN` cleared during system suspend, and `exynos5420_pm_resume()` must restore `S5P_CORE_LOCAL_PWR_EN` in `EXYNOS5_ARM_CORE0_SYS_PWR_REG`. On Exynos4, `exynos_set_delayed_reset_assertion(false)` must be called in `exynos_pm_prepare()` and `exynos_set_delayed_reset_assertion(true)` on all exit paths of `exynos_pm_resume()` (including `early_wakeup`). [F12, F98]
- In `mcpm-exynos.c`, `exynos_cpu_powerup()`, `exynos_cpu_powerdown_prepare()`, and `exynos_wait_for_powerdown()` must check `cpu < EXYNOS5420_CPUS_PER_CLUSTER` and `cluster < EXYNOS5420_NR_CLUSTERS` before computing `cpunr`. `exynos_cpu_powerup()` must call `exynos_cpu_power_up(cpunr)` unconditionally after `state = exynos_cpu_power_state(cpunr)`, running `EXYNOS_SWRESET` (`EXYNOS5420_KFC_CORE_RESET(cpu)`) only when `!state && secure_firmware`, `S5P_PMU_SPARE2` is ready, and the boot CPU is in the same non-zero cluster. [F59, F87]
- In `arch/arm/mach-exynos/firmware.c`, `EXYNOS_SLEEP_MAGIC` at `sysram_ns_base_addr + EXYNOS_BOOT_FLAG` written by `exynos_suspend()` must be cleared to `0` both in `exynos_resume()` and when `exynos_smc(SMC_CMD_SLEEP, ...)` returns in `exynos_cpu_suspend()`. In `exynos_l2_write_sec()`, enabling `L2X0_CTRL_EN` when `l2cache_enabled == 0` must first call `exynos_smc(SMC_CMD_L2X0INVALL, 0, 0, 0)` and set `l2cache_enabled = 1`, and clearing `L2X0_CTRL_EN` must reset `l2cache_enabled = 0`. [F45, F47]

## Synchronization

- In `arch/arm/mach-imx/src.c`, read-modify-write updates to `SRC_SCR` and `SRC_A7RCR1` in `src_base` across `imx_src_reset_module()`, `imx_enable_cpu()`, and `imx_src_init()` must be serialized under `scr_lock`. `imx_src_reset_module()` must release `scr_lock` before its 1000ms reset-completion polling loop, whereas `imx_gpcv2_set_core1_pdn_pup_by_software()` is called under `scr_lock` from `imx_enable_cpu()` and must use non-sleeping `readl_relaxed_poll_timeout_atomic()`. [F14, F106]
- Because `exynos_cpu_die()` calls `v7_exit_coherency_flush(louis)` before `platform_do_lowpower()` and `exynos_cpu_power_down()`, code on that path runs with cache coherency disabled and must use lockless checks like `soc_is_exynos5420()` rather than functions like `of_machine_is_compatible()` that execute `LDREX`/`STREX` atomics. [F100]
- In `imx6q_enter_wait()` (`arch/arm/mach-imx/cpuidle-imx6q.c`), state 1 sets `CPUIDLE_FLAG_RCU_IDLE`: `num_idle_cpus` and `imx6_set_lpm()` must be protected by `raw_spin_lock(&cpuidle_lock)` outside the `ct_cpuidle_enter()`/`ct_cpuidle_exit()` pair wrapping `cpu_do_idle()`, incrementing `num_idle_cpus` before `cpu_do_idle()` (`WAIT_UNCLOCKED` when `++num_idle_cpus == num_online_cpus()`) and decrementing after (`WAIT_CLOCKED` when `num_idle_cpus-- == num_online_cpus()`). [F10, F104]
- In `imx_cpu_die()` and `imx_cpu_kill()`, the dying CPU must flush caches via `v7_exit_coherency_flush(louis)` before signaling `imx_set_cpu_arg(cpu, ~0)`, and `imx_cpu_kill()` must wait for `imx_get_cpu_arg(cpu)` to become non-zero before calling `imx_enable_cpu(cpu, false)` and clearing the arg to `0`. Variables written by a coherent CPU and read by a secondary CPU outside cache coherency (`exynos_pen_release` in `exynos_write_pen_release()`, `g_diag_reg` in `imx_smp_prepare_cpus()`) must be cleaned with `sync_cache_w()`. [F20, F109]
- In `arch/arm/mach-imx/mmdc.c`, `imx_mmdc_perf_init()` must initialize `pmu_mmdc->hrtimer`, `cpu`, `devtype_data`, and hotplug `node` before `perf_pmu_register()`. `mmdc_pmu_event_update()` runs from both perf callbacks and hardirq `mmdc_pmu_timer_handler()`, so it must update `event->hw.prev_count` via `local64_cmpxchg()` and mask the delta `new_raw_count - prev_raw_count` with `0xFFFFFFFF` (32-bit hardware counter) before `local64_add()` to `&event->count`. [F16, F70, F107]

## Object Lifetimes

- In `arch/arm/mach-imx/mmdc.c`, `imx_mmdc_probe()` enables `mmdc_ipg_clk` (`clk_prepare_enable`) and maps `mmdc_base` (`of_iomap`), and `mmdc_pmu_init()` allocates `pmu_mmdc->id` (`ida_alloc(&mmdc_ida, GFP_KERNEL)`). On failure in `imx_mmdc_perf_init()` after `mmdc_pmu_init()`, `pmu_mmdc->id` must be freed via `ida_free(&mmdc_ida, pmu_mmdc->id)` (`pmu_release_id`), and `imx_mmdc_probe()` must call `iounmap(mmdc_base)` and `clk_disable_unprepare(mmdc_ipg_clk)`; on success, `imx_mmdc_remove()` owns all three before `kfree(pmu_mmdc)`. [F1, F2]
- In `imx6q_suspend_init()` (`pm-imx6.c`) and `imx_suspend_alloc_ocram()` (`pm-imx5.c`), `pdev` from `of_find_device_by_node(node)` must be released with `put_device(&pdev->dev)` on both normal and error paths before `of_node_put(node)`. In `imx6q_suspend_init()`, any failure while mapping `mmdc_base`, `src_base`, `iomuxc_base`, `gpc_base`, or optional `l2_base` via `imx6_pm_get_base()` must unwind already-mapped `.vbase` regions in reverse order before `put_device`. [F4, F5]
- In `exynos_sysram_init()`, `exynos_map_pmu()`, `imx_init_revision_from_anatop()`, and `imx_gpc_check_dt()`, Device Tree nodes from `of_find_compatible_node()`, `of_find_matching_node()`, or an early `break` from `for_each_compatible_node()` must be released with `of_node_put()`. In `imx_init_revision_from_anatop()`, the inner `MXC_CPU_IMX6ULL` branch must pass `src_np` (not outer `np`) to `of_iomap()` and `of_node_put()`. [F63, F91]
- In `mxs_machine_init()` (`mach-mxs.c`), `soc_dev_attr`, `soc_dev_attr->revision` (`mxs_get_revision`), and `soc_dev_attr->serial_number` (`kasprintf`) must all be `kfree()`d if `of_property_read_string()` or `soc_device_register()` fails. In `update_fec_mac_prop()`, `newmac` (`kzalloc(sizeof(*newmac) + 6, ...)`, where `newmac->value = newmac + 1` points to the trailing 6-byte payload) must be `kfree()`d if `kstrdup()` for `newmac->name` fails, whereas `of_update_property(np, newmac)` takes ownership on success. [F6, F7, F80]

## API Contracts

- In `mach-exynos/platsmp.c`, `exynos_write_pen_release()`, `exynos_cpu_power_*()`, `exynos_core_restart()`, `exynos_set_boot_addr()`, and `call_firmware_op(cpu_boot, ...)` take the hardware core ID (`MPIDR_AFFINITY_LEVEL(cpu_logical_map(cpu), 0)`), not logical `cpu` (and `exynos_cpu_boot()` must clamp `cpu` to `0` on `soc_is_exynos4212()`). Conversely, in `mach-imx/src.c`, `imx_enable_cpu()`, `imx_set_cpu_jump()`, and `imx_get/set_cpu_arg()` take logical `cpu` and call `cpu_logical_map(cpu)` internally. [F32, F33, F34]
- System-suspend finisher callbacks passed to `cpu_suspend()` in Exynos and S5PV210 (`exynos_cpu_suspend`, `exynos_cpu_do_idle`, `exynos5420_cpu_suspend`, `s5pv210_cpu_suspend`) must return non-zero (`1`) if execution falls through `wfi`, `exynos_smc`, or `mcpm_cpu_suspend` without powering down. [F25]
- In `arch/arm/mach-exynos/mcpm-exynos.c`, `exynos_pm_power_up_setup()` runs before MMU/caches or a stack exist and must remain `__naked` stackless assembly. In `exynos_power_ops`, `exynos_cpu_powerup()` and `exynos_cpu_is_up()` run with the MCPM lock held and IRQs disabled (requiring `udelay()`, never sleeping), while only `exynos_wait_for_powerdown()` may sleep (`msleep()`). [F102, F103]
- In `exynos_pmu_irq_init()` (`suspend.c`) and `imx_gpc_init()` (`gpc.c`), `of_node_clear_flag(node, OF_POPULATED)` must be called before returning `0` so platform device probing is not blocked. In `imx_gpc_domain_ops` and `exynos_pmu_domain_ops`, `.translate` and `.alloc` must reject `param_count != 3` or `param[0] != 0` (non-SPI / PPI interrupts), `imx_gpc_domain_alloc()` must reject `hwirq >= GPC_MAX_IRQS`, and `imx_gpc_irq_set_wake()` / `exynos_irq_set_wake()` must not call `irq_chip_set_wake_parent()`. [F9, F117, F118]
- `mmdc_pmu_event_init()` (`mmdc.c`) must reject task-attached (`PERF_ATTACH_TASK` or `event->cpu < 0`) and sampling (`is_sampling_event` or `sample_period`) events, pin `event->cpu` to `cpumask_first(&pmu_mmdc->cpu)`, and check `cfg >= 0 && cfg < MMDC_NUM_COUNTERS` before `mmdc_pmu_group_is_valid()`. `mmdc_pmu_group_is_valid()` must use `for_each_sibling_event(sibling, leader)` (also checking `event` if `event != leader`), and `mmdc_pmu_group_event_is_valid()` must reject software/non-MMDC events before `test_and_set_bit(cfg, used_counters)`. [F62, F75, F115]
- In `arch/arm/mach-imx/cpuidle-imx6sx.c`, `imx6sx_enter_wait()` must call `cpu_pm_enter()` and `cpu_cluster_pm_enter()` before `ct_cpuidle_enter()`, and `cpu_cluster_pm_exit()` and `cpu_pm_exit()` after `ct_cpuidle_exit()`. `v7_cpu_resume` in `arch/arm/mach-imx/common.h` must remain unconditionally declared/built outside `#ifdef CONFIG_SUSPEND` for `imx6sx_enter_wait()`. Runtime cpuidle state toggles (`imx6q_cpuidle_fec_irqs_used` / `unused`) must use `cpuidle_driver_state_disabled()`. [F105, F112, F113]
- `mxc_arch_reset_init()` (`system.c`) must call `clk_prepare(wdog_clk)` during init so atomic `mxc_restart()` only calls `clk_enable(wdog_clk)`. `mxc_set_irq_fiq()` (`irq-common.c`) casts `gc->private` directly to `struct mxc_extra_irq *`, so any i.MX `irq_chip_generic` setting `gc->private` must store that type. [F81, F111]

## Error Handling

- In `exynos_set_boot_addr()` and `exynos_get_boot_addr()`, `call_firmware_op()` returns `-ENOSYS` when no firmware hook is registered and another errno on failure; only `-ENOSYS` triggers fallback to `cpu_boot_reg()`. Because `cpu_boot_reg()` returns `IOMEM_ERR_PTR(-ENODEV)` (not `NULL`) when `cpu_boot_reg_base()` is `NULL`, callers must check `IS_ERR(boot_reg)` / `PTR_ERR(boot_reg)` and reset `ret = 0` after the MMIO access. [F23, F24]
- In `exynos_pmu_irq_init()` (`suspend.c`), if `irq_domain_create_hierarchy()` fails after `of_iomap(node, 0)`, the error path must call `iounmap(pmu_base_addr)` and reset `pmu_base_addr = NULL`. Because `mx5_suspend_ops` and `imx6q_pm_ops` are registered even when OCRAM suspend init is skipped or fails, `mx5_suspend_enter()`, `imx6q_pm_enter()`, and `imx6q_suspend_finish()` must check that `imx5_suspend_in_ocram_fn` or `imx6_suspend_in_ocram_fn` is non-NULL before calling it. [F8, F30]
- In `imx_mmdc_perf_init()`, `cpuhp_setup_state_multi()` and `mmdc_pmu_init()` return non-negative IDs on success, so `ret` must be tested with `ret < 0`, and if `devm_kasprintf()` returns `NULL`, `ret = -ENOMEM` must be set before jumping to `pmu_release_id`. In `imx_mmdc_probe()`, an `IS_ERR(mmdc_ipg_clk)` from `devm_clk_get()` must be normalized to `NULL` before `clk_prepare_enable()`. [F26, F27]

## External Contracts

- In `ls1021a_smp_prepare_cpus()` (`arch/arm/mach-imx/platsmp.c`), the physical entry address must be byte-swapped with `cpu_to_be32()` before `writel_relaxed(..., dcfg_base + DCFG_CCSR_SCRATCHRW1)`, because the LS1021A DCFG CCSR block is big-endian while `writel_relaxed()` is little-endian. [F60]

## Known Pitfalls

- `imx6_enable_rbc()` (`pm-imx6.c`) must mask all GPC interrupts (`imx_gpc_mask_all()`), write `ccm_base + CCR`, delay `udelay(65)`, and call `imx_gpc_restore_all()`; it must never be called between `imx_gpc_pre_suspend()` and `imx_gpc_post_resume()` because both `imx_gpc_mask_all()` and `imx_gpc_pre_suspend()` overwrite the single `gpc_saved_imrs[]` array in `gpc.c`. [F42, F93]
- In `arch/arm/mach-imx/src.c`, `imx_enable_cpu()` computes bit shifts using `cpu - 1` (requiring a 1-based secondary hardware CPU ID >= 1), whereas `imx_set_cpu_jump()`, `imx_get_cpu_arg()`, and `imx_set_cpu_arg()` index `SRC_GPR1` by `cpu * 8` (supporting 0-based CPU IDs). [F54]
- In `arch/arm/mach-exynos/mcpm-exynos.c`, `exynos_v7_exit_coherency_flush` must clear `SCTLR.C`, call `v7_flush_dcache_*`, perform a dummy read from `pmu_base_addr + S5P_INFORM0` with a data dependency into `r0`, and clear `ACTLR` bit 6 in one `asm volatile` block without stack accesses, clobbering `r0`-`r6`, `r9`, `r10`, `ip`, `lr`, and `memory`. [F101]
- In `arch/arm/mach-s5pv210/pm.c`, `s3c_pm_do_restore_core()` (called from `s5pv210_pm_resume()`) must only perform raw register writes (`writel_relaxed`) and must not contain debug logging (`S3C_PMDBG`, `pr_debug`) or calls that touch memory or peripherals while clocks/registers are being restored. [F110]
