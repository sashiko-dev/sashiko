# IO_URING

The `io_uring` subsystem implements the asynchronous I/O engine (`io_uring/io_uring.c`), its bounded/unbound worker pool (`io-wq.c`), memory mapping and provided buffer rings (`memmap.c`, `kbuf.c`), fixed resource tables (`register.c`, `rsrc.c`), SQPOLL offload (`sqpoll.c`), zero-copy RX/TX (`zcrx.c`, `notif.c`), and opcode handlers (`rw.c`, `net.c`, `poll.c`, `timeout.c`, `futex.c`, `uring_cmd.c`, `msg_ring.c`, `cancel.c`, `waitid.c`, and VFS/process ops).

## Architecture & Data Flow

- `struct io_kiocb` union/cached fields are not zeroed on recycle (`io_req_add_to_cache()` poisons `creds`/`apoll` under `CONFIG_KASAN`): access `req->kbuf` only when `REQ_F_BUFFER_SELECTED` is set, `req->buf_node` only when `REQ_F_BUF_NODE` is set, `req->creds` only when `REQ_F_CREDS` is set, and `req->apoll` only when `REQ_F_POLLED` is set. [F47, F50]
- `io_req_flags_t` (`u64 __bitwise`) reserves bits 0..7 for UAPI `IOSQE_*` flags; internal `REQ_F_*_BIT` values start at bit 8 (`REQ_F_FAIL_BIT`), must not exceed bit 63, and use `IO_REQ_FLAG()` (`BIT_ULL`). Always mark failures via `req_set_fail(req)` so `REQ_F_CQE_SKIP` is converted to `REQ_F_SKIP_LINK_CQES`. [F60, F78, F121]
- In `struct io_buffer_list`, `buf_list` and `buf_ring` share a union gated by `bl->flags & IOBL_BUF_RING`. `struct io_uring_buf_ring` overlays `tail` with `bufs[0].resv` at offset 14, so `io_register_pbuf_ring()` must size it via `flex_array_size(br, bufs, reg.ring_entries)` and enforce power-of-2 `reg.ring_entries < 65536` (`MAX_BIDS_PER_BGID`). [F48, F92, F139]
- On `IORING_SETUP_CQE_MIXED` rings, 32-byte CQEs must set `IORING_CQE_F_32` (`ctx_cqe32_flags()`) and advance `cqe_cached` and `cached_cq_tail` by 2 slots (emitting an `IORING_CQE_F_SKIP` pad via `io_fill_nop_cqe()` if wrapping), whereas `IORING_SETUP_CQE32` advances `cached_cq_tail` by 1. For 32-byte overflow CQEs, `io_alloc_ocqe()` adds `sizeof(struct io_uring_cqe)` to `sizeof(struct io_overflow_cqe)`, and `__io_cqring_overflow_flush()` copies `2 * sizeof(struct io_uring_cqe)` bytes. [F66, F132]
- Before `__io_cqring_overflow_flush()` drops `completion_lock` and `uring_lock` while `ctx->cq_overflow_list` is non-empty, it must set `ctx->cqe_sentinel = ctx->cqe_cached`. Transitions of `cq_overflow_list` between empty and non-empty under `completion_lock` must update `IO_CHECK_CQ_OVERFLOW_BIT` in `ctx->check_cq` and `IORING_SQ_CQ_OVERFLOW` in `ctx->rings->sq_flags` in lockstep. [F64, F65]
- Even on `ctx->task_complete` or `IORING_SETUP_SINGLE_ISSUER` rings, `ctx->submitter_task` can be `NULL` (e.g., `IORING_SETUP_R_DISABLED` before enabling); always check `ctx->submitter_task` before dereferencing or queuing `task_work`. [F52]
- `req_cachep` whitelists only `req->cmd.data` for usercopy, so direct `copy_from_user()`/`copy_to_user()` into `struct io_kiocb` must stay within `req->cmd.data`. Because `ctx->sq_sqes` has element type `struct io_uring_sqe` (64B), indexing `ctx->sq_sqes` must shift the index left by 1 when `IORING_SETUP_SQE128` is set, and SQE byte copies (including `io_uring_cmd_sqe_copy()`) must use `uring_sqe_size(ctx)`. [F135, F137, F256]
- `struct iou_vec` aliases `iovec` and `bvec`, so `io_prep_reg_iovec()` and `io_import_reg_vec()` must right-align `iovec` entries at `vec->iovec + (vec->nr - nr_iovs)`. For user fixed buffers (`!imu->is_kbuf`), only `imu->bvec[0]` may have non-zero `bv_offset`, which `io_import_fixed()` and `io_vec_fill_bvec()` must add before shifting by `imu->folio_shift`. [F273, F306]
- Save `io->iter_state` and `io->meta_state` when importing/advancing `io->iter`/`io->meta`, and restore them via `iov_iter_restore()` and `io_meta_restore()` before advancing on partial read in `__io_read()`, returning `-EAGAIN` in `io_write()`, or reissuing in `io_rw_should_reissue()`. [F265]

## Synchronization

- Pair `io_ring_submit_lock()` on every exit path with `io_ring_submit_unlock()` using the same `IO_URING_F_UNLOCKED` bit in `issue_flags`. Per-context caches (`io_alloc_req()`, `io_cache_alloc()`, `io_cache_free()`, `io_uring_alloc_async_data()`) require `ctx->uring_lock`. `io_uring_poll()` must never take `ctx->uring_lock`, and `io_uring_show_fdinfo()` must only use `mutex_trylock(&ctx->uring_lock)`. [F5, F152, F169]
- Lock ordering: `sqd->lock` nests outside `ctx->uring_lock` (drop `uring_lock` before `io_sq_thread_park()` or `io_put_sq_data()`, and verify `sqpoll_task_locked(sqd)` is non-NULL under `sqd->lock`). `__io_uring_add_tctx_node()` and `io_uring_alloc_task_context()` acquire `ctx->uring_lock` internally. In `io_register_clone_buffers()`, when `src_ctx != ctx`, drop `uring_lock`, call `lock_two_rings(ctx, src_ctx)`, and unlock only `src_ctx->uring_lock`. [F201, F221, F225, F336]
- CQE allocation/filling requires `ctx->completion_lock` unless `ctx->lockless_cq` is set (which requires `ctx->uring_lock`, and `current == ctx->submitter_task` for `ctx->task_complete`). `ctx->completion_lock` nests outside `raw_spinlock_t ctx->timeout_lock`, which is taken in hardirq and requires `raw_spin_lock_irq()`/`irqsave()`. Walking `req->link` when `REQ_F_LINK_TIMEOUT` is set requires `ctx->timeout_lock`; in `io_link_timeout_fn()`, pin `prev = timeout->head` via `req_ref_inc_not_zero(prev)` under `timeout_lock`. [F28, F29, F331, F334, F342]
- Async wakeup/completion callbacks (`io_poll_wake`, `io_waitid_wait`, `io_async_buf_func`, `io_timeout_fn`, `io_link_timeout_fn`, `io_complete_rw`, `io_tx_ubuf_complete`) run in atomic/irq/waitqueue context and must defer user copies and `ctx->uring_lock` to `task_work`. `io_req_local_work_add()` must hold `guard(rcu)()` while reading `first_req->nr_tw` and updating `ctx->work_llist.first` via `try_cmpxchg`. [F38, F330]
- In `io_poll_remove_entries()` and `io_poll_double_prepare()`, hold `rcu_read_lock()` from before `smp_load_acquire(&poll->head)` until after `spin_unlock_irq(&head->lock)`, and lock the first `head->lock` in `io_poll_double_prepare()` before setting `REQ_F_DOUBLE_POLL | REQ_F_ASYNC_DATA`. In `__io_arm_poll_handler()`, set `req->poll_refs = 1` before `vfs_poll()` when `IO_URING_F_UNLOCKED` is set and release via `atomic_cmpxchg(&req->poll_refs, 1, 0)` (or `__io_poll_execute()`). [F209, F216, F217]
- In `io_waitid()`, set `iw->refs = 1` before `add_wait_queue()` and call `io_waitid_drop_issue_ref()` on `-ERESTARTSYS`; in `io_waitid_wait()`, call `list_del_init(&wait->entry)` before checking `atomic_fetch_inc(&iw->refs) & IO_WAITID_REF_MASK`. [F207, F213]
- For `IORING_SETUP_IOPOLL`, add requests to `ctx->iopoll_list` via `io_iopoll_req_issued()` only after `def->issue` returns `IOU_ISSUE_SKIP_COMPLETE` (locking `uring_lock` if `IO_URING_F_UNLOCKED`). Issue/reissue must clear `req->iopoll_completed = 0`, while completion callbacks must finish updating `req` before `smp_store_release(&req->iopoll_completed, 1)`. Check `req->opcode == IORING_OP_URING_CMD` before downcasting `req->cmd` or calling `io_req_rw_cleanup()` in `io_do_iopoll()`. [F23, F226, F261, F323]
- In `zcrx.c`, `ifq->rq_lock` (required for `io_zcrx_put_niov_uref()`) and `area->freelist_lock` require `spin_lock_bh()`, and refill paths must call `io_zcrx_sync_for_device(pp, niov)` before `net_mp_netmem_place_in_cache()`. In `io_close_queue()`, move `ifq->netdev` to a local and clear it under `ifq->pp_lock`, then drop `ifq->pp_lock` before `net_mp_close_rxq()`. [F218, F223, F332, F344]
- In `io_ring_buffer_select()`, if `IO_URING_F_UNLOCKED` is set or `!io_file_can_poll(req)`, commit `IOBL_BUF_RING` buffers immediately via `io_kbuf_commit()` under `uring_lock` and clear `sel.buf_list = NULL`; in `io_recv_buf_select()`, use `io_buffers_peek()` only when `!(issue_flags & IO_URING_F_UNLOCKED)`. Read user-updated `rings->sq.tail` and `br->tail` with `smp_load_acquire()`, and write `rings->cq.tail` and `rings->sq.head` with `smp_store_release()`. [F161, F162, F219]

## Object Lifetimes

- Assigning `req->async_data` requires setting `REQ_F_ASYNC_DATA`, and freeing/recycling it before `io_clean_op()` must clear both via `io_req_async_data_free()`/`clear()`. In `io_req_rw_cleanup()`, never recycle `req->async_data` via `io_rw_recycle()` when `REQ_F_REISSUE | REQ_F_REFCOUNT` is set. Call `io_alloc_cache_vec_kasan(&...->vec)` before putting `io_async_rw`, `io_async_msghdr`, or `io_async_cmd` into `io_alloc_cache`. [F1, F196, F316]
- Requests targeting an `io_uring` file (`io_is_uring_fops(file)`) or relying on `current->mm` (`io_futex_prep()`, `io_futexv_prep()`) must call `io_req_track_inflight(req)`, while `io_is_uring_fops(file)` files must be rejected (`-EBADF`) in fixed-file registration/updates and `io_close()`. Assigning `io_file_get_fixed()` to `req->file` requires setting `REQ_F_FIXED_FILE` so `io_put_file()` does not `fput()` it. [F2, F8, F164, F357]
- Requests from `io_alloc_req()` hold `ctx->nr_req_allocated` and `ctx->refs` and must be returned via `io_req_add_to_cache()`, never `kmem_cache_free()`. Remote `msg_ring` requests posted via `io_req_task_work_add_remote()` must be freed with `kfree_rcu(req, rcu_head)`. [F10, F144]
- In `io_send_select_buffer()` and `io_recv_buf_select()`, if `arg.iovs` is dynamically allocated, save it in `kmsg->vec` and set `REQ_F_NEED_CLEANUP` before branching on `ret == 1`. In `io_send_zc()`/`io_sendmsg_zc()`, clear `zc->notif = NULL` when flushing `zc->notif` inline (`!IO_URING_F_UNLOCKED`), and in `io_send_zc_import()`, pass `sr->notif` (not `req`) to `io_import_reg_buf()`. [F193, F194, F195]
- In `io_pollfree_wake()`, execute `smp_store_release(&poll->head, NULL)` only after `io_poll_mark_cancelled(req)`, `io_poll_execute(req, 0)`, and `list_del_init(&poll->wait.entry)`. In `fs.c`, clear `REQ_F_NEED_CLEANUP` once the VFS helper consumes `struct filename`. When `io_kiocb_start_write()` sets `IOCB_WRITE` on `REQ_F_ISREG`, every completion/retry/error path must call `io_req_end_write()`. Release coalesced ubuf pages via `unpin_user_folio(page_folio(page), 1)`. [F7, F191, F204, F349, F350]

## API Contracts

- `io_fixed_fd_install()` consumes `file` via `fput(file)` on error, whereas `__io_fixed_fd_install()` takes ownership only on success (`ret >= 0`). Both (and `io_close_fixed()`) take 1-based `file_slot` indices (or `IORING_FILE_INDEX_ALLOC`), whereas `io_fixed_fd_remove()`, `__io_close_fixed()`, and `io_rsrc_node_lookup()` take 0-based offsets. Callers of `io_uring_register_get_file()` must `fput()` non-`ERR_PTR` returns. [F6, F205, F274]
- `io_cache_alloc()` only zeroes `cache->init_clear` bytes on fresh allocations/KASAN unpoisoning; callers must initialize fields above `init_clear` and modified fields. `io_alloc_cache_init()` and `io_futex_cache_init()` return `false` on success and `true` on error. Destructor callbacks passed to `io_alloc_cache_free()` must have exact type `void (*)(const void *)` for kCFI. [F42, F57, F317]
- `io_add_aux_cqe()`, `io_req_post_cqe()`, and `io_req_post_cqe32()` must only be called from inline `task_work` holding `ctx->uring_lock` (never `io-wq`); `io_req_post_cqe()` must flush `ctx->submit_state.compl_reqs` first and set `cq_flush = true`. Callers holding `ctx->completion_lock` must use `io_cqe_overflow_locked()` (`GFP_ATOMIC`), not `io_cqe_overflow()` (`GFP_KERNEL`). [F68, F153, F154]
- Pass core `issue_flags` (never hardcoded constants) to `__io_uring_cmd_done()`, `io_uring_cmd_done()`, and `io_uring_cmd_mark_cancelable()`; `__io_uring_cmd_done()` may call `io_req_complete_defer()` only when `(issue_flags & (IO_URING_F_COMPLETE_DEFER | IO_URING_F_UNLOCKED)) == IO_URING_F_COMPLETE_DEFER`. Pass buffers from `io_uring_cmd_buffer_select()` (checking `sel.val < 0`) to `io_uring_mshot_cmd_post_cqe()`. Mirror `#if defined(CONFIG_IO_URING)` signature changes in `include/linux/io_uring/cmd.h` and `io_uring.h` in `#else` stubs. [F61, F82, F206, F247, F328]

## Error Handling

- In `io_create_region()` and `io_pin_pages()`, validate page alignment, overflow (`check_add_overflow()`), and `nr_pages <= INT_MAX`; on partial return from `pin_user_pages_fast()` or `alloc_pages_bulk_node()`, unpin/release partial pages and `kvfree(pages)`. Assign `mr->pages` only after all pages succeed (never an `ERR_PTR`), set `mr->nr_pages` only after `__io_account_mem()` succeeds, and `memset(mr, 0, sizeof(*mr))` in `io_free_region()`. [F12, F13, F53, F93, F123]
- In `io_init_req()`, return early errors before `def->prep()` via `io_init_fail_req(req, err)` to zero `req->cmd.data`. In `io_sendmsg_prep()`, `io_recvmsg_prep()`, and `io_send_zc_prep()`, zero `sr->done_io = 0` before any early error return. In `*xattr`, initialize `ix->filename = NULL` before setting `REQ_F_NEED_CLEANUP`, and clear `ix->filename = NULL` immediately after `filename_getxattr()`/`setxattr()`. [F56, F240, F244]
- Set `imu->nr_bvecs` after `io_alloc_imu()` before indexing `imu->bvec[]` or calling `io_free_imu()`. Check `ret == IOU_REQUEUE` (-3072) before `ret < 0` in `io_poll_check_events()` and `io_recvzc()`. Translate synchronous `-ERESTARTSYS` to `-EINTR` in `.issue` handlers, except in `io_waitid()`/`io_waitid_cb()` where `-ERESTARTSYS` from `__do_wait()` means an armed wait. [F249, F289, F310]

## External Contracts

- `struct io_uring_sqe` must remain 64B using fixed-width UAPI types (`BUILD_BUG_SQE_ELEM`). Load `sqe` fields with `READ_ONCE()`, clamp untrusted UAPI indices (`sqe->opcode < IORING_OP_LAST`, `sq_array[head]`, registered ring `fd`, `ext_arg` offset, resource `index`, `io_parse_rqe()` `niov_idx`) with `array_index_nospec()`, verify `io_is_uring_fops(file)` when resolving ring fds, and reject non-zero unused/reserved/pad fields and unknown flags with `-EINVAL`. [F83, F84, F85, F142, F143, F175, F276]

## Known Pitfalls

- Width and wrapping arithmetic: cast `mr->nr_pages` to `size_t` before `<< PAGE_SHIFT`, `reg.bgid` (`__u16`) to `unsigned long` before `<< IORING_OFF_PBUF_SHIFT`, and `area->area_id` (`u16`) to `u64` before `<< IORING_ZCRX_AREA_SHIFT`; use `min_t(u32, len, buf_len)` in `io_kbuf_inc_commit()` and `min_t(__u16, tail - head, UIO_MAXIOV)` in `io_ring_buffers_peek()` (rejecting `len == 0` before division, and setting `arg->partial_map = 1` and truncating `buf->len` only on `iov == arg->iovs` for `!IOBL_INC`). [F71, F119, F120, F122, F126, F130, F304]
- Loop/UAF hazards: save `node = req->comp_list.next` before queuing/putting/caching `req` in `io_free_batch_list()`, and save `next_hashed = wq_next_work(work)` before `io_wq_submit_work()`/`io_wq_free_work()`. Zero `req->big_cqe` after copying it in `io_fill_cqe_req()`/`io_alloc_ocqe()`. In `io_handle_tw_list()`, reset `ctx = NULL` after `ctx_flush_and_put()` before `cond_resched()`. In `io_read_mshot()`, reset `rw->len = 0` after recycle/completion; in `io_sendmsg()`/`io_sendmsg_zc()`, restore `msg_control_user = sr->msg_control`. [F67, F101, F104, F110, F264, F267]
