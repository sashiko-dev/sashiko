# AMD IOMMU (AMD-VI)

The AMD IOMMU (AMD-Vi) driver implements DMA address translation, device isolation, Shared Virtual Addressing (SVA/PASID), I/O page fault (PPR/IOPF) handling, and interrupt remapping (including Guest Virtual APIC / AVIC) for x86 systems with AMD IOMMU hardware. It parses ACPI IVRS (IVHD/IVMD) tables during boot, manages v1 (host) and v2 (guest/x86-64 compatible) IO page tables, and exposes `iommu_ops`, `irq_domain_ops`, and KVM/perf interfaces.

## Architecture & Data Flow

- When `dev_data->gcr3_info.gcr3_tbl != NULL`, the DTE domain ID (`set_dte_entry()`) and all guest/v2 page invalidations (`domain_flush_pages_v2()`, `amd_iommu_dev_flush_pasid_pages()`) must use `dev_data->gcr3_info.domid` instead of `domain->id`. Domain IDs from `pdom_id_alloc()` are 1-based (`[1, MAX_DOMAIN_ID - 1]`), as `domid == 0` with `DTE_FLAG_TV` is prohibited under `amd_iommu_snp_en`. [F69, F105]
- In `init_gcr3_table()` and `destroy_gcr3_table()`, `GCR3[0]` (PASID 0) is bound to `iommu_virt_to_phys(pdom->iop.pgd)` and cleared via `update_gcr3(dev_data, 0, ...)` if and only if `pdom_is_v2_pgtbl_mode(pdom)` is true (unset for `IOMMU_DOMAIN_IDENTITY`). In `struct protection_domain`, `iop.root` and `iop.mode` are only populated for `PD_MODE_V1` (`iop.mode != PAGE_MODE_NONE`), while `iop.pgd` is only populated for `PD_MODE_V2`. [F49, F75]
- Physical addresses written to IOMMU registers, DTEs, IRTEs, GCR3 tables (`update_gcr3()`, `amd_iommu_set_gcr3()`), and IO page tables must include the SME mask via `iommu_virt_to_phys()` or `__sme_set()`, and addresses read back for CPU mapping or `iova_to_phys` must strip it via `iommu_phys_to_virt()` or `__sme_clr()`. In `build_completion_wait()`, use `iommu->cmd_sem_paddr` rather than `iommu_virt_to_phys(iommu->cmd_sem)`. [F63, F178, F179]
- In `set_dte_entry()`, sample `old_domid` (`dte->data[1] & DEV_DOMID_MASK`) before `update_dte256()`, and if non-zero, call `amd_iommu_flush_tlb_domid(iommu, old_domid)` afterwards. `set_dte_gcr3_table()` only ORs bits into `target->data[0..2]`, so callers must zero GCR3/GPT fields first via `make_clear_dte()`. [F58, F68]
- Whenever a DTE is modified (`dev_update_dte()`, `amd_iommu_update_and_flush_device_table()`), propagate it to `alias_table[devid]` and PCI DMA aliases via `clone_aliases()` and flush all alias DTEs via `device_flush_dte()`. Toggling `pdomain->dirty_tracking` in `amd_iommu_set_dirty_tracking()` must update `DTE_FLAG_HAD` under `dte_lock`, call `device_flush_dte()` for every device in `dev_list`, and call `amd_iommu_domain_flush_all()`. [F70, F77]
- `irq_remap_table->table` is `u32 *` but holds 128-bit `struct irte_ga` when `AMD_IOMMU_GUEST_IR_GA(amd_iommu_guest_ir)` is true and 32-bit `union irte` otherwise; indexing/sizing must branch on `AMD_IOMMU_GUEST_IR_GA()` or use `iommu->irte_ops`. In `irte_ga_set_affinity()`, do not write host `vector`/`dest_apicid` to `irte` when `guest_mode` is set. `amd_ir_data.ga_root_ptr` must be `u64`. [F78, F102, F124]
- Because `amd_iommu_resume()` restores hardware via `early_enable_iommu()` (`iommu_init_flags()`, `iommu_enable_gt()`) and `amd_iommu_enable_interrupts()`, runtime `MMIO_CONTROL_OFFSET` features must be configured in those helpers, not only during PCI probe. Because the driver manages both PCI and ACPI HID devices, check `dev_is_pci(dev)` before `to_pci_dev(dev)`. [F138, F164]

## Synchronization

- Lock ordering is `iommu_dev_data.mutex` -> `{ protection_domain.lock, iommu_table_lock }` -> `iommu_dev_data.dte_lock` -> `amd_iommu.lock`. `amd_iommu.lock` (a leaf lock) and `irq_remap_table.lock` must remain `raw_spinlock_t` because IRQ remapping callbacks acquire them under raw `irq_desc` locks. [F31, F170]
- `protection_domain.lock` (`spin_lock_irqsave()`) must be held for: all mutations/traversals of `domain->dev_list`; all calls to `amd_iommu_domain_flush_pages()` and `amd_iommu_domain_flush_all()`; all operations on `sva_pdom->dev_data_list` in `pasid.c`; and all accesses/refcnt updates on `domain->iommu_array` (`pdom_attach_iommu()`, `pdom_detach_iommu()`, `domain_flush_pages_v1()`, `domain_flush_complete()`). [F27, F28, F29, F30]
- Sleeping PCI cap and IOPF calls (`pdev_enable_caps()`, `pdev_disable_caps()`, `amd_iommu_iopf_add_device()`, `amd_iommu_iopf_remove_device()`, `iopf_queue_flush_dev()`) must run under `dev_data->mutex` outside `domain->lock`. Allocations under `domain->lock` (`pdom_attach_iommu()`, `__get_gcr3_pte()`) must use `GFP_ATOMIC`, while `alloc_pte()`, `increase_address_space()`, and `v2_alloc_pte()` must forward the caller's `gfp` flag. [F167, F168, F169]
- In `increase_address_space()`, hold `domain->lock`, recheck `pgtable->mode`, initialize `*pte`, and wrap `pgtable->root` and `pgtable->mode` updates in `write_seqcount_begin()`/`write_seqcount_end(&pgtable->seqcount)`, while lockless readers (`alloc_pte()`, `fetch_pte()`) retry with `read_seqcount_begin()`/`read_seqcount_retry()`. [F25, F26]
- Updates to `dev_table_entry` must hold `dev_data->dte_lock`, and `write_dte_upper128()` must read `ptr->data128[1]` and preserve `DTE_DATA2_INTR_MASK` in `new->data[2]` inside `dte_lock`. In `iommu_completion_wait()` and `iommu_flush_irt_and_complete()`, hold `iommu->lock` continuously across `__iommu_queue_command_sync()` for `CMD_COMPL_WAIT` and `wait_on_sem(iommu, data)`. [F32, F34]
- IRTE operations in `struct irq_remap_table` must hold `table->lock`, and 128-bit updates in `__modify_irte_ga()` must use `try_cmpxchg128()`. In `pte_test_and_clear_dirty()`, inspect all `PAGE_SIZE_PTE_COUNT(size)` replicated PTEs and use atomic `test_and_clear_bit()` across every replicated PTE. [F36, F181]

## Object Lifetimes

- In `detach_device()`, `dev_update_dte()` and `amd_iommu_domain_flush_all()` must execute before `list_del(&dev_data->list)`, `destroy_gcr3_table()`, and `pdom_detach_iommu()`. When `dev_data->ppr` is true, call `iopf_queue_flush_dev(dev)` before `amd_iommu_iopf_remove_device()`, and only call `amd_iommu_iopf_remove_device()` when `dev_data->ppr` is true. [F1, F6]
- In `attach_device()`, if `init_gcr3_table()` fails after `pdom_attach_iommu()`, call `pdom_detach_iommu()` before unlocking `dev_data->mutex`. `amd_iommu_attach_device()` must return `0` immediately if `dev_data->domain == domain`. [F4, F7]
- Callers failing after `protection_domain_alloc()` (`do_iommu_domain_alloc()`, `amd_iommu_domain_alloc_sva()`) must free both `domain->id` (`pdom_id_free()`) and `domain`. `iommu_sva_domain_free()` must call `mmu_notifier_unregister(&sva_pdom->mn, domain->mm)` when `sva_pdom->mn.ops` is set before `amd_iommu_domain_free()`. [F3, F14]
- `free_gcr3_table()` must free `gcr3_info->domid`, free the pages, and reset `gcr3_tbl = NULL` and `glx = 0`. In `pasid.c`, `remove_dev_pasid()` must call `amd_iommu_clear_gcr3()`, `list_del()`, and `kfree(pdom_dev_data)`. [F5, F13]
- In `iommu_v1_map_pages()`, old page-table pages in `freelist` from `free_clear_pte()` must not be freed via `iommu_put_pages_list(&freelist)` until after `amd_iommu_domain_flush_pages()` completes. When `try_cmpxchg64()` fails in `alloc_pte()` or `v2_alloc_pte()`, free `page` via `iommu_free_pages()`. [F8, F23]
- In `iommu_init_device()`, `dev_iommu_priv_set(dev, dev_data)` must precede `setup_aliases()`. `acpihid_device_group()` must call `iommu_group_ref_get(entry->group)` when returning a cached group. In `state_next()`, if initialization fails after `irq_remapping_enabled` is set, call `free_dma_resources()` and `uninit_device_table_dma()` rather than `disable_iommus()` or `free_iommu_resources()`. [F11, F12, F19]

## API Contracts

- `blocked_domain` and `release_domain` are standalone `struct iommu_domain` instances; callbacks receiving them (`blocked_domain_attach_device()`, `blocked_domain_set_dev_pasid()`) must never call `to_pdomain(domain)`. `protection_domain_alloc()` returns `NULL` on failure, whereas `iommu_ops` domain allocation callbacks must return `ERR_PTR(-errno)`. [F46, F137]
- `amd_iommu_domain_alloc_paging_flags()` must decode `flags` by matching exact combinations in `switch (flags & supported_flags)` so unsupported multi-bit combinations return `ERR_PTR(-EOPNOTSUPP)`. When `IOMMU_HWPT_ALLOC_DIRTY_TRACKING` is requested, force `PD_MODE_V1` and verify `amd_iommu_hd_support(iommu)` at allocation and in `amd_iommu_attach_device()`. [F106, F185]
- `amd_iommu_def_domain_type()` must check `dev_is_pci(dev) && to_pci_dev(dev)->untrusted` (returning `IOMMU_DOMAIN_DMA`) before identity heuristics, and never return `IOMMU_DOMAIN_IDENTITY` when `CC_ATTR_MEM_ENCRYPT` or `amd_iommu_snp_en` is active. Probe-time paths must use `rlookup_amd_iommu()` rather than `get_amd_iommu_from_dev()`. [F50, F183]
- `amd_iommu_activate_guest_mode()` and `amd_iommu_deactivate_guest_mode()` must save `valid`, zero `entry->lo.val` and `entry->hi.val`, rebuild all fields (even if `guest_mode` is already set), and call `modify_irte_ga()`. `amd_iommu_register_ga_log_notifier(NULL)` must call `synchronize_rcu()` after clearing `iommu_ga_log_notifier`. [F22, F79]
- In `iommu_call_iopf_notifier()`, if a PRI request fails `ppr_is_valid()` or has an invalid PASID, still complete it with `IOMMU_PAGE_RESP_FAILURE` via `amd_iommu_complete_ppr()`. `amd_iommu_dev_flush_pasid_pages(dev_data, pasid, address, size)` takes `pasid` second, `address` third, and byte `size` fourth. [F60, F190]

## Error Handling

- In `early_amd_iommu_init()`, error paths after `acpi_get_table("IVRS", ...)` must `goto out` to call `acpi_put_table()`. `get_device_sbdf_id()`, `get_acpihid_device_id()`, `get_devid()`, and `pdom_id_alloc()` return negative/non-positive values on error; check in a signed `int` before casting to `u16`/`u32`. Check `search_dev_data()` for `NULL` in IRQ remapping paths. [F2, F44, F45, F54]
- `amd_iommu_domain_free()` must check `domain->domain.type & __IOMMU_DOMAIN_PAGING` before `free_io_pgtable_ops()`. `destroy_gcr3_table()` must check `gcr3_info->gcr3_tbl == NULL` before `free_gcr3_table()`. In `iommu_v1_map_pages()` and `iommu_v2_map_pages()`, if PTE allocation fails after `updated` is true, `out:` must still call `amd_iommu_domain_flush_pages()`. [F48, F53, F55]

## External Contracts

- In `update_dte256()`, `write_dte_upper128()` must precede `write_dte_lower128()` when setting `DTE_FLAG_V` or `DTE_FLAG_GV`, `write_dte_lower128()` must precede `write_dte_upper128()` when clearing either bit, and changing `DTE_GPT_LEVEL_MASK` on an active `GV=1` DTE requires clearing `data128[0]` and calling `iommu_flush_dte_sync()` first. [F65, F156]
- `build_completion_wait()` must write both `lower_32_bits(data)` to `cmd->data[2]` and `upper_32_bits(data)` to `cmd->data[3]`. Non-leaf v2 directory entries in `set_pgtable_attr()` must not set `IOMMU_PAGE_DIRTY`. In `pdev_enable_caps()`, enable PASID before ATS, and ATS before PRI. [F125, F142, F162]

## Known Pitfalls

- Command builders (`build_*`) must `memset(cmd, 0, sizeof(*cmd))` before `CMD_SET_TYPE()`. In `set_dte_entry()`, after `make_clear_dte()`, use `|=` (not `=`) on `new.data[0]` and OR in `amd_iommu_get_ivhd_dte_flags()`. `iommu_feature_enable()`/`disable()` take a bit index (`CONTROL_*`), `check_feature()` takes a shifted mask (`FEATURE_*`), and `set_dte_bit()` takes a `0..255` bit index (`DEV_ENTRY_*`). [F57, F62, F67]
- `amd_iommu_iotlb_sync()` must pass `gather->end - gather->start + 1` to `amd_iommu_domain_flush_pages()`, whereas `sva_arch_invalidate_secondary_tlbs()` passes `end - start`. In `amd_iommu_domain_flush_pages()`, guard `__ffs(address)` against `address == 0`. [F92, F127]
- `PM_LEVEL_SIZE(x)` must guard `(x) < 6` before shifting. `PAGE_SIZE_ALIGN()` and `PAGE_SIZE_PTE()` require a 64-bit unsigned power-of-two `pagesize` (`> 4096` for `PAGE_SIZE_PTE`), and `first_pte_l7()` must scale `PAGE_SIZE_PTE_COUNT(pg_size)` by `<< 3`. In `free_sub_pt()`, `PAGE_MODE_7_LEVEL` must remain a no-op. [F111, F123, F129, F136]
- Loops over `pdom->dev_data_list` calling `remove_dev_pasid()` must use `for_each_pdom_dev_data_safe()` or break immediately. Callbacks in `amd_iommu_irq_ops` must not be marked `__init`. [F112, F154]
