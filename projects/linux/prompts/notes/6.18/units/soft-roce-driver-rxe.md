# SOFT-ROCE DRIVER (rxe)

The Soft-RoCE (`rxe`) driver is a software implementation of the RDMA over Converged Ethernet (RoCE v2) protocol in the Linux InfiniBand subsystem. It attaches to Ethernet devices via `rdma_link_ops`, encapsulates RDMA BTH packets over UDP (port 4791), and exposes verbs, user-mapped lockless queues, Memory Regions/Windows, and On-Demand Paging (ODP).

## Architecture & Data Flow

- MR and MW keys encode the pool XArray index in `key >> 8` and an 8-bit key in `key & 0xff`. `rxe_reg_fast_mr()` and `rxe_do_bind_mw()` must preserve the upper 24-bit index (`~0xff`). `rxe_pool_get_index()` callers on `mr_pool`/`mw_pool` must pass `key >> 8` and verify the full 32-bit `key` against `mr->lkey`/`mr->rkey` or `mw->rkey` (calling `rxe_put()` on mismatch). In `rxe_invalidate_mr()`, compare `key` against `mr->rkey` if `mr->access & RXE_ACCESS_REMOTE` else `mr->lkey`, and require `mr->ibmr.type == IB_MR_TYPE_MEM_REG` and `atomic_read(&mr->num_mw) == 0`. [F56, F77, F92]
- Because kernel DMA and fast-reg MRs have `mr->umem == NULL`, check `is_odp_mr(mr)` rather than dereferencing `mr->umem->is_odp`, and check `mr->ibmr.type == IB_MR_TYPE_DMA` before accessing `mr->page_list`. Every MR operation with an ODP split (`rxe_mr_init_user`, `rxe_mr_copy`, `rxe_flush_pmem_iova`, `rxe_mr_do_atomic_op`, `rxe_mr_do_atomic_write`) must have a matching implementation in `rxe_odp.c` and `#else` stubs in `rxe_loc.h`. [F44, F82]
- When `qp->srq` is set, `get_srq_wqe()` must verify `wqe->dma.num_sge <= srq->rq.max_sge` before copying `sizeof(*wqe) + wqe->dma.num_sge * sizeof(struct rxe_sge)` bytes into `&qp->resp.srq_wqe` (where `srq_wqe.sge` must immediately follow `srq_wqe.wqe`), set `qp->resp.wqe = &qp->resp.srq_wqe.wqe`, and advance the SRQ consumer under `srq->rq.consumer_lock`; `do_complete()` must only advance `qp->rq.queue` when `!qp->srq`. [F69, F133]
- Because `get_req()` routes any packet directly to `RESPST_READ_REPLY` whenever `qp->resp.res` is non-NULL, single-packet responder operations that set `qp->resp.res` (`send_atomic_ack()`, `send_read_response_ack()`) and completed `read_reply()` flows must clear `qp->resp.res = NULL`. [F74]
- When `rxe_completer()` clears a requester stall flag (`wait_fence`, `wait_psn`, `need_rd_atomic`) or sets `qp->req.need_retry = 1`, it must also set `qp->req.again = 1` so `rxe_sender()` reruns `rxe_requester()`. When scheduling `qp->rnr_nak_timer` in `COMPST_RNR_RETRY`, it must set `qp->req.wait_for_rnr_timer = 1`; `rxe_requester()` must not call `req_retry()` while it is set, and `rnr_nak_timer()` and QP reset paths must clear it. [F63, F64]
- In `rxe_qp_from_attr()`, `IB_QP_SQ_PSN` must mask `attr->sq_psn` with `BTH_PSN_MASK` and update `qp->attr.sq_psn`, `qp->req.psn`, and `qp->comp.psn` together (`IB_QP_RQ_PSN` updates `qp->attr.rq_psn` and `qp->resp.psn`). `IB_QP_MAX_QP_RD_ATOMIC` must set both `qp->attr.max_rd_atomic` and `qp->req.rd_atomic` to the same power-of-two rounded value so `rxe_wqe_is_fenced()` works. [F58, F59]
- 24-bit PSNs in `u32` fields must be masked with `BTH_PSN_MASK` after arithmetic and compared only via `psn_compare()`. In `update_wqe_psn()` and `rxe_prepare_res()`, packet counts must use ceiling division by `qp->mtu` clamped to at least 1 so zero-length operations consume 1 PSN instead of underflowing `last_psn`. [F122, F124]
- In `rxe_resp_check_length()`, the `(pkt->mask & RXE_START_MASK) && (pkt->mask & RXE_END_MASK)` branch for `*_ONLY` packets must precede the single-flag branches, and MTU checks must be restricted to `IB_QPT_RC` and `IB_QPT_UC`. For `IB_QPT_GSI` and `IB_QPT_UD`, verify `payload_size(pkt) + sizeof(union rdma_network_hdr)` fits in `qp->resp.wqe->dma.sge[i].length` and return `RESPST_ERR_LENGTH` before `execute()`. [F90, F105]
- In `req_retry()`, clear `first` only after skipping `wqe_state_done` entries, and for that first retried WQE reset `wqe->dma` only when `(mask & WR_READ_MASK) == 0` (`WR_READ_MASK` preserves `wqe->dma` and advances `wqe->iova`). Every path in `rxe_requester()` jumping to `err:` must set `wqe->status` to a non-`IB_WC_SUCCESS` status before marking `wqe->state = wqe_state_error`. [F65, F115]

## Synchronization

- `qp->state_lock`, `task->lock`, `cq->cq_lock`, `qp->sq.sq_lock`, `rq->producer_lock`, and `rq->consumer_lock` must always use `spin_lock_irqsave()`. Lock order is `qp->state_lock` before `task->lock`: code holding `task->lock` must never acquire `qp->state_lock`. `rxe->mcg_lock` and `port->port_lock` are taken in softirq and must use `spin_lock_bh()`, keeping `GFP_KERNEL` allocations and `rxe_mcast_add()`/`rxe_mcast_del()` outside `mcg_lock`. [F151, F152, F153]
- For user-shared queues (`QUEUE_TYPE_FROM_CLIENT` and `QUEUE_TYPE_TO_CLIENT`), the driver must maintain its own index in `q->index` (publishing updates to `q->buf` via `smp_store_release()` in `queue_advance_producer()`/`queue_advance_consumer()`), read the peer-owned index from `q->buf` via `smp_load_acquire()` in `queue_get_producer()`/`queue_get_consumer()`, and mask untrusted indices with `q->index_mask` (`queue_addr_from_index()`). [F34, F163]
- For ODP MRs, any access to `umem_odp->map.pfn_list` must hold `umem_odp->umem_mutex` via `rxe_odp_map_range_and_lock()` and unlock it on all paths after success. `rxe_odp_do_pagefault_and_lock()` locks `umem_mutex` on return `>= 0` and leaves it unlocked on `< 0`; in `rxe_odp_map_range_and_lock()`, if `rxe_check_pagefault()` finds a missing page under `umem_mutex`, drop `umem_mutex` before calling `rxe_odp_do_pagefault_and_lock()` and re-run `rxe_check_pagefault()` afterward. [F14, F30, F31]
- `rxe_cleanup_task()` and `rxe_disable_task()` busy-wait with `cond_resched()` and must only run in process context (`rxe_qp_do_cleanup()` via `execute_in_process_context()`, and `rxe_qp_reset()`). In `rxe_qp_do_cleanup()`, clear `qp->valid` under `qp->state_lock`, stop RC timers with `timer_delete_sync()`, and drain tasks via `rxe_cleanup_task()` before calling `rxe_sender()`/`rxe_receiver()` and freeing queues/refs. In `rxe_qp_reset()`, drain tasks with `rxe_disable_task()` before resetting queues/state and re-enable via `rxe_enable_task()`. [F22, F23, F157]
- In `rxe_cq_post()`, checking `queue_full()`, writing the CQE, advancing the producer index, testing/clearing `cq->notify`, and calling `cq->ibcq.comp_handler()` must all occur within a single `cq->cq_lock` critical section. Conversely, in `comp_check_sq_drain_done()`, `req_check_sq_drain_done()`, `rxe_cq_post()`, and `get_srq_wqe()`, release `qp->state_lock`, `cq->cq_lock`, or `srq->rq.consumer_lock` after clearing `sq_draining` or `srq->limit` before invoking `event_handler`. [F26, F33]
- Index-looked-up pool objects (`rxe_ah`, `rxe_qp`, `rxe_mr`, `rxe_mw`) reserve a `NULL` XArray slot in `__rxe_add_to_pool()` and must not be published via `rxe_finalize()` until all fields, locks, tasks, and keys are initialized. `do_mmap_info()` must complete `copy_to_user()` before taking `rxe->pending_lock` and adding `ip->pending_mmaps` to `rxe->pending_mmaps`. [F17, F19]
- After enqueuing `skb` onto `qp->resp_pkts` (`rxe_comp_queue_pkt()`) or `qp->req_pkts` (`rxe_resp_queue_pkt()`), the caller must not dereference `skb` or `SKB_TO_PKT(skb)`. `rxe_queue_resize()` must run `rxe_queue_init()` and `do_mmap_info()` outside locks, then take `consumer_lock` before `producer_lock` in `resize_finish()`. In `rxe_bind_mw()` and `rxe_invalidate_mw()`, run check and update helpers together under `spin_lock_bh(&mw->lock)`. [F25, F32, F37]
- Responder Atomic Ops (`rxe_mr_do_atomic_op()`, `rxe_odp_do_atomic_op()`) must validate `mr->state == RXE_MR_STATE_VALID`, `mr_check_range()`, and 8-byte alignment before taking `atomic_ops_lock` and saving `*orig_val = va[page_offset >> 3]`. Atomic Write must use `smp_store_release(&va[page_offset >> 3], value)`, and `process_flush()` must issue `wmb()` (after `rxe_flush_pmem_iova()` for `IB_FLUSH_PERSISTENT`) before advancing `qp->resp.psn`. [F78, F167]

## Object Lifetimes

- Once `rxe_send()` or `rxe_loopback()` sets `skb->destructor = rxe_skb_tx_dtor`, takes `sock_hold(sk)` and `rxe_get(pkt->qp)`, and increments `pkt->qp->skb_out`, any subsequent error path calling `kfree_skb(skb)` must not manually release `qp`, `sk`, or `skb_out`. [F1]
- Every `sk_buff` queued on `qp->req_pkts` or `qp->resp_pkts` holds both `rxe_get(qp)` and `ib_device` (`qp->ibqp.device`) references, which must be released alongside `kfree_skb(skb)` when dequeued (`cleanup()`, `drain_req_pkts()`, `free_pkt()`, `drain_resp_pkts()`). In `rxe_rcv_mcast_pkt()`, non-final entries in `mcg->qp_list` get `skb_clone()` while the final entry takes `skb` (`skb = NULL`), and the post-loop check must free `skb` and put `ib_dev` if `skb` was not consumed. [F3, F113]
- Whenever `qp->resp.mr` is released—in `read_reply()` (when transferring ownership to local `mr`), `cleanup()`, `do_class_d1e_error()`, or `rxe_qp_reset()`—`qp->resp.mr` must be set to `NULL` so `check_rkey()` does not trigger `WARN_ON_ONCE(qp->resp.mr)` and later cleanup paths do not double-put it. [F9]
- Every MW bind to a `struct rxe_mr` (`rxe_bind_mw()`, `rxe_do_bind_mw()`) must pair `rxe_get(mr)` with `atomic_inc(&mr->num_mw)` (after dropping any prior `mw->mr` when rebinding), and every unbind/cleanup (`rxe_do_invalidate_mw()`, `rxe_mw_cleanup()`) must pair `atomic_dec(&mr->num_mw)` with `rxe_put(mr)` and `mw->mr = NULL`. Binding/unbinding a QP's `rcq`/`scq` in `rxe_qp_from_init()` and `rxe_qp_do_cleanup()` must pair `atomic_inc`/`atomic_dec(&cq->num_wq)` with `rxe_get`/`rxe_put(cq)`. [F10, F60]
- Under `task->lock`, `__reserve_if_idle()` sets `TASK_STATE_BUSY`, increments `task->num_sched`, and calls `rxe_get(task->qp)`; `do_task()` must balance every reservation by incrementing `task->num_done` and calling `rxe_put(task->qp)` on all exits. When `do_task()` exhausts `RXE_MAX_ITERATIONS` with `ret == 0`, set `TASK_STATE_IDLE` and `resched = 1` unless `task->state == TASK_STATE_DRAINING`, where `cont = 1` finishes draining inline. [F16, F117]
- `struct rxe_mr` is driver-allocated with `kzalloc()` and must be freed via `kfree(mr)` on init failure and `kfree_rcu_mightsleep(mr)` in `rxe_dereg_mr()` after `rxe_cleanup(mr)`. In `__rxe_cleanup()`, erase `elem->index` from `pool->xa` and call `__rxe_put(elem)` before waiting on `elem->complete`, and wait on `elem->complete` before calling `pool->cleanup(elem)`. [F8, F20]
- In `rxe_queue_resize()`, `resize_finish()` swaps `*q` and `*new_q` in place (`swap(*q, *new_q)`) and `rxe_queue_cleanup(new_q)` must run unconditionally afterward; callers must never cache `q->buf` or WQE/CQE pointers across `rxe_queue_resize()`. In `rxe_queue_cleanup()`, release `q->ip->ref` when `q->ip` is non-NULL and call `vfree(q->buf)` directly only when `q->ip` is NULL. [F7, F50, F139]
- Pair `rxe_get_dev_from_net(ndev)` with `ib_device_put(&rxe->ib_dev)` and `rxe_ib_device_get_netdev(ibdev)` with `dev_put(ndev)`. In `rxe_register_device()`, never dereference `rxe` after `ib_register_device()` succeeds; before registration, `rxe_net_add()` frees `rxe` on error via `ib_dealloc_device()`. [F12, F144, F145]

## API Contracts

- `rxe_xmit_packet()` always consumes `skb` (via `rxe_loopback()`, `rxe_send()`, or `kfree_skb()`), so callers (`rxe_requester()`, `read_reply()`, `send_common_ack()`) must never free `skb` after calling it, even on error. `rxe_get_av(pkt, ahp)` returns a borrowed `rxe_av *` for RC/UC and `ah_num == 0` UD WQEs, but for UD/GSI with `ah_num != 0` it acquires an `ah_pool` reference on `*ahp` (checking `rxe_ah_pd(ah) == pkt->qp->pd`) that the caller must `rxe_put(ah)`. [F2, F11, F178]
- `rxe_pool_get_index()`, `lookup_mr()`, `rxe_lookup_mw()`, `rxe_recheck_mr()`, and `rxe_lookup_mcg()` return `NULL` (never `ERR_PTR`) on failure, whereas `rxe_get_mcg()`, `rxe_create_mmap_info()`, and `rxe_setup_udp_tunnel()` return `ERR_PTR` (never `NULL`), and `rxe_rereg_user_mr()` returns `NULL` on in-place success and `ERR_PTR` on failure. [F38, F39]
- Responder atomic helpers (`rxe_mr_do_atomic_op()`, `rxe_mr_do_atomic_write()`, `rxe_odp_atomic_op()`, `rxe_odp_do_atomic_write()`) must check `(page_offset & 0x7) == 0` (returning `RESPST_ERR_MISALIGNED_ATOMIC`) before indexing `u64 *va` via `va[page_offset >> 3]`, and return `enum resp_states` rather than negative errnos. Task callbacks (`rxe_sender()`, `rxe_requester()`, `rxe_completer()`, `rxe_receiver()`) return `0` when more work remains and non-zero (`-EAGAIN`) when idle. [F41, F43, F95, F138]
- For zero-length RDMA Read/Write (`reth_len(pkt) == 0`), `check_rkey()` sets `qp->resp.mr = NULL`; `rxe_mr_copy()`, `rxe_odp_mr_copy()`, and `rxe_flush_pmem_iova()` must return `0` when `length == 0` before checking `!mr` or calling `rxe_odp_map_range_and_lock()` (which rejects `length < 1`), though `rxe_flush_pmem_iova()` requires a non-NULL `mr`. For zero-based MWs (`IB_ZERO_BASED`), `check_rkey()` sets `qp->resp.offset = mw->addr`, which all responder MR checks/accesses must add to `qp->resp.va`. [F45, F94, F110]
- On ingress, `rxe_udp_encap_recv()` must `skb_linearize()` before setting `pkt->hdr`, `rxe_udp_encap_recv()`/`rxe_loopback()` must `skb_pull()` outer headers before `rxe_rcv(skb)`, and `rxe_rcv()` must verify `skb->len >= RXE_BTH_BYTES` and `skb->len >= header_size(pkt)` before reading BTH or extended headers/ICRC. `rxe_post_send_kernel()` must call `rxe_sched_task(&qp->send_task)` whenever `good > 0`, even if a later WR fails. [F66, F89, F168]

## Error Handling

- Because `rxe_create_qp()` calls `rxe_cleanup(qp)` when `rxe_qp_from_init()` fails midway, `rxe_qp_do_cleanup()`, `flush_send_queue()`, and `flush_recv_queue()` must check optional/partially initialized fields (`sq.queue`, `rq.queue`, `srq`, `scq`, `rcq`, `pd`, `sk`, timers, tasks) for `NULL`. On `err_cleanup` paths, capture `rxe_cleanup()` in `cleanup_err` so it does not overwrite `err`. In `rxe_ib_advise_mr_prefetch()`, roll back `rxe_put(work->frags[i].mr)` for all prior indices on failure. [F15, F46, F51]

## Known Pitfalls

- `struct rxe_pkt_info` in `skb->cb` occupies all 48 bytes on 64-bit builds and must never grow; `SKB_TO_PKT()`/`PKT_TO_SKB()` must only be used on RX packets because TX paths put `rxe_pkt_info` on the stack while `IPCB(skb)` uses `skb->cb`. Never call `queue_producer_addr()`/`queue_consumer_addr()` on a client-owned index (use `queue_addr_from_index()`), and always scale queue offsets by `1 << q->log2_elem_size`, never `q->elem_size`. [F83, F84, F131, F134]
- Test `enum rxe_hdr_mask` flags against `pkt->mask`, never `pkt->opcode`. `rxe_check_bind_mw()` must validate `wqe->wr.wr.mw` fields, not `mw->*`. Never call `rxe_dbg_<obj>()`/`rxe_err_<obj>()` on NULL or before `rxe_add_to_pool()` and `ibmr.device` init; during `rxe_init()`, use `ndev` rather than `rxe_ib_device_get_netdev()`. Check `if (node)` (not `if (mcg)`) after `while (node)` in `__rxe_lookup_mcg()`, and compute `(iova >> mr->page_shift) - (mr->ibmr.iova >> mr->page_shift)` in `rxe_mr_iova_to_index()`. [F49, F104, F112, F120, F127, F141]
