# TRACING

This unit implements the `tracefs` and JIT `eventfs` pseudo-filesystems (`fs/tracefs/`), core tracepoint, trace event, recursion-protection, sequence-buffer, and BPF raw-tracepoint headers (`include/linux/trace*.h`, `include/trace/`), subsystem trace event definitions (`include/trace/events/`), and advanced ftrace event mechanisms (`kernel/trace/`) including event triggers, histograms, synthetic events, user-space trace events, and event injection.

## Architecture & Data Flow
- In `trace_events_synth.c`, `synth_field.offset` and `synth_event.n_u64` count 8-byte `union trace_synth_field` slots in `synth_trace_event.fields[]` (`STR_VAR_LEN_MAX / sizeof(u64)` for static strings, 1 otherwise), whereas `trace_define_field()` and `trace_dynamic_info.offset` use byte offsets. Numeric fields must be accessed via the width-matched `as_u8`/`as_u16`/`as_u32`/`as_u64` union member based on `field->size` (and dynamic fields via `as_dynamic`), never by casting `u64` elements. [F94, F128]
- In `trace_events_user.c`, `ftrace_event_field.offset` and `user_event_validator.offset` include `sizeof(struct trace_entry)`, whereas `user_event.min_size` excludes it; `user_event_ftrace()` and `user_event_perf()` copy user data into `entry + 1` (scaled by `sizeof(struct trace_entry)`) but must pass `entry` to `user_event_validate()`. [F137]
- In `struct action_data`, `match_data` is valid only when `data->handler == HANDLER_ONMATCH`, whereas `track_data` is valid only for `HANDLER_ONMAX` or `HANDLER_ONCHANGE`. For `ACTION_TRACE` actions, `data->synth_event_name` is non-NULL only when `data->use_trace_keyword` is true; otherwise the synthetic event name is in `data->action_name`. [F58, F59]
- In `struct tracefs_inode`, `ti->private` points to a root `struct inode` when `TRACEFS_EVENT_INODE` is clear, to `struct eventfs_inode` on eventfs directories, and is `NULL` on eventfs regular files (which store their parent `eventfs_inode` in `dentry->d_fsdata`). Broken by: passing an eventfs inode to `set_tracefs_inode_owner()` or dereferencing `ti->private` when `TRACEFS_EVENT_INODE` is set without a `NULL` check. [F213]
- Loops over `file->triggers` must check `cmd_ops->trigger_type` before dereferencing `private_data` as `hist_trigger_data *` or `enable_trigger_data *`, and loops over `dyn_event_list` must check `is_synth_event(pos)` before calling `to_synth_event(pos)`. In `struct trace_event_fields`, `type == TRACE_FUNCTION_TYPE` selects the union's `define_fields` callback; in `struct tracepoint`, `tp->ext` is non-NULL only for `DEFINE_TRACE_FN`/`DEFINE_TRACE_SYSCALL` and must be checked before accessing `faultable`, `regfunc`, or `unregfunc`. [F60, F141, F217, F218]
- `hist_trigger_elt_data_alloc()` sizes `elt_data->field_var_str` from `n_field_var_str + n_save_var_str + n_var_str` and allocates `elt_data->comm` only when a field has `HIST_FIELD_FL_EXECNAME` (so `elt_data->comm` must be NULL-checked before use). In `event_hist_trigger_parse()`, `create_actions()` must precede `save_hist_vars()` (called whenever `has_hist_vars(hist_data) || hist_data->n_var_refs`) and `tracing_map_init()`; in `event_hist_trigger()`, `resolve_var_refs()` must run with `self = false` before `hist_trigger_elt_update()` and `self = true` after it. [F62, F69, F74, F117]
- `event_hist_trigger()` must zero `hist_pad->compound_key` (`hist_data->key_size <= HIST_KEY_SIZE_MAX`) and `hist_pad->entries` (`HIST_STACKTRACE_SIZE`) with `memset()` before building keys, and `add_to_key()` must clamp string copies to `key_field->size - 1`. Histogram stacktrace variables store the frame count at `((unsigned long *)str)[0]` and frames starting at index 1. [F64, F95, F103]

## Synchronization
- In `trace_events_user.c`, lock ordering is `group->reg_mutex` -> `event_mutex` -> `mm->mmap_lock`. `user_event_parse()` must hold `group->reg_mutex` for `user_event_set_tp_name()` and `event_mutex` when checking `current_user_events` against `max_user_events`, registering the event, and inserting into `group->register_table`. `user_event_put(user, locked)` and `user_event_enabler_destroy(enabler, locked)` require `locked == true` iff the caller already holds `event_mutex`. [F32, F154]
- In `trace_events_trigger.c`, `event_mutex` nests outside `trigger_cmd_mutex`. All mutations of `file->triggers` and updates to `EVENT_FILE_FL_TRIGGER_COND_BIT` via `update_cond_flag()` must hold `event_mutex` and use RCU list primitives (`list_add_rcu`/`list_del_rcu`), and concurrent writers to `trace_event_file->flags` must use atomic `set_bit()`/`clear_bit()`. [F35, F155, F205]
- Because `event_triggers_call()`, `event_triggers_post_call()`, and `trace_synth()` run under `rcu_read_lock_sched()`, `trigger_data_free()`, `set_trigger_filter()`, and `hist_clear()` must call `tracepoint_synchronize_unregister()` before freeing a trigger/filter or clearing a `tracing_map`. `event_hist_trigger_free()` must call `trigger_data_free(data)` before `remove_hist_vars()`, `unregister_field_var_hists()`, `destroy_hist_data()`, and `free_hist_pad()`; `hist_clear()` must pause all sibling `named_triggers` sharing `data->name` before synchronizing. [F38, F77, F156]
- `user_event_enabler_write()` runs under `event_mutex` and `mmap_read_lock(mm->mm)`: it must pass `FOLL_WRITE | FOLL_NOFAULT` to `pin_user_pages_remote()` and unpin via `unpin_user_pages_dirty_lock(&page, 1, true)`. On fault, `user_event_enabler_create()` and `user_event_mm_clear_bit()` must drop both `mmap_read_lock` and `event_mutex` before `user_event_mm_fault_in()` (bounded by `attempt <= 10`), whereas `user_event_enabler_write()` with `fixup_fault` true must queue `user_event_enabler_fault_fixup()` via `GFP_NOWAIT`. [F27, F116, F151, F169]
- `user_event_enabler_update()` must not hold `rcu_read_lock()` while calling `mmap_read_lock()` or `user_event_enabler_write()`; under `event_mutex`, it must collect a refcounted `mm->next` list via `user_event_mm_get_all()` under `rcu_read_lock()` and drop RCU first. `user_event_mm_remove()` must cycle `mmap_write_lock(mm->mm)` after decrementing `mm->tasks` to zero and unlinking `mm->mms_link` under `user_event_mms_lock`, and defer `user_event_mm_put()` via `queue_rcu_work()`, while remote writers and fault handlers check `refcount_read(&mm->tasks) != 0` under `mmap_read_lock`. [F30, F150]
- `user_events_write_core()` must call `fault_in_iov_iter_readable()` before `rcu_read_lock_sched()`, read `info->refs` via `rcu_dereference_sched()` (updated under `group->reg_mutex` in `user_events_ref_add()` via `rcu_assign_pointer()` and `kfree_rcu()`), and copy payload data in `user_event_ftrace()`/`user_event_perf()` via `copy_nofault()`. [F149, F158]
- `event_hist_trigger()` runs across normal, IRQ, and NMI contexts: it must acquire its per-CPU buffer via `get_hist_pad()` and release it via `put_hist_pad()`, and `hist_poll_wakeup()` must wake `hist_poll_wq` via `irq_work_queue(&hist_poll_work)`. In `trace_event_raw_event_synth()` and `trace_string()`, strings must be read only via `fetch_store_strlen()`, `fetch_store_string()`, or `strncpy_from_*_nofault()`. [F145, F147, F287]
- In `fs/tracefs/`, `eventfs_create_dir()` must initialize all `ei` fields before locking `eventfs_mutex` and linking `ei->list` into `parent->children` (only if `!parent->is_freed`). In `eventfs_iterate()`, `srcu_read_lock(&eventfs_srcu)` spans the walk, while `eventfs_mutex` is held to check `!ei->is_freed` and run `entry->callback` (which must never re-enter tracefs/eventfs) and dropped before `dir_emit()`. `tracefs_d_revalidate()` must not take sleeping locks under `LOOKUP_RCU`, and `eventfs_set_attr()` allocations under `eventfs_mutex` must use `GFP_NOFS`. [F194, F196, F197, F277, F278]
- Non-syscall tracepoints (`__DECLARE_TRACE`) invoke `__DO_TRACE_CALL` under `guard(preempt_notrace)()`, whereas faultable syscall tracepoints (`__DECLARE_TRACE_SYSCALL`) use `guard(rcu_tasks_trace)()` and disable preemption around `bpf_trace_run*`. After `tracepoint_probe_unregister()`, callers must call `tracepoint_synchronize_unregister()` (or `call_rcu_tasks_trace()` if `tracepoint_is_faultable(tp)` else `call_rcu()`) before freeing probe data. [F190, F203]

## Object Lifetimes
- Only `dentry->d_fsdata` holds a `kref` on `struct eventfs_inode` (via `get_ei()`/`put_ei()`), whereas `tracefs_inode.private` is uncounted. Because `ei->list` and `ei->rcu` share a union, `eventfs_remove_rec()` must call `list_del_rcu(&ei->list)` under `eventfs_mutex` before `free_ei(ei)`; `free_ei_rcu()` must use `kfree_const(ei->name)` and free `get_root_inode(ei)` when `ei->is_events` is set. Creation errors in `eventfs_create_dir()`/`eventfs_create_events_dir()` must use `cleanup_ei(ei)` (zeroing `nr_entries`), and `eventfs_remove_events_dir()` must clear `rei->events_dir` and call `eventfs_remove_dir(ei)` before `d_invalidate()`/`dput()`. [F180, F181, F182, F183, F184]
- In `event_trigger_parse()`, `trigger_data_alloc()` is bracketed across `event_trigger_register()` by `event_trigger_init()`/`event_trigger_free()` and freed via `trigger_data_free()` (never `kfree()`). `register_snapshot_trigger()` must call `tracing_disarm_snapshot(file->tr)` if `register_trigger()` fails, and `unregister_snapshot_trigger()` disarms only when `try_unregister_trigger()` returns `true`. `event_enable_trigger_parse()`/`free()` must pair `trace_event_try_get_ref()` and soft-mode `trace_event_enable_disable(..., 1)` on `enable_data->file`, while calling `trace_event_trigger_enable_disable()` and `update_cond_flag()` on the triggering `file`. [F3, F5, F6, F119]
- In `event_hist_trigger_parse()`, all fallible setup (`create_actions()`, `save_hist_vars()`, `tracing_map_init()`) must precede `event_trigger_register()`. `create_hist_data()` takes ownership of `attrs` and `alloc_synth_event()` takes ownership of `fields[]` only on success; `destroy_hist_field()` is a no-op on `HIST_FIELD_FL_VAR_REF` fields (freed once via `__destroy_hist_field()` in `destroy_hist_fields()`). `event_hist_trigger_init()` calls `alloc_hist_pad()` before `++data->ref`, so `event_hist_trigger_free()` must call `free_hist_pad()` on every invocation regardless of `--data->ref`, and `save_hist_vars()` must be paired with `remove_hist_vars()` before `destroy_hist_data()`. [F8, F11, F12, F13, F15, F16]
- When `user_event_put()` drops the last reference to a non-persistent `user_event`, it must hold `event_mutex`, reset `user->refcnt` to 1 while `user` stays in `group->register_table`, and schedule `delayed_destroy_user_event()`. Under `event_mutex`, `destroy_user_event()` must call `user_event_destroy_fields(user)` before `user_event_set_call_visible(user, false)`, and only after that succeeds unlink `user`, free names (freeing `EVENT_TP_NAME(user)` when `!= EVENT_NAME(user)`), and decrement `current_user_events`. When `user_events_ioctl_unreg()` sets `ENABLE_VAL_FREEING_BIT`, it must defer `user_event_enabler_destroy()` if `ENABLE_VAL_FAULTING_BIT` is set; `user_event_enabler_dup()` must skip `ENABLE_VAL_FREEING_BIT` and mask `orig->values` with `ENABLE_VAL_DUP_MASK`. [F17, F18, F19, F22, F82, F85]
- `parse_entry()` in `trace_events_inject.c` leaves `*pentry` allocated on non-`-ENOMEM` errors, so `event_inject_write()` must unconditionally call `kfree(entry)` after `parse_entry()`. In `user_event_ftrace()` and `user_event_perf()`, payload copy or `user_event_validate()` failure after reservation must call `__trace_event_discard_commit()` or `perf_swevent_put_recursion_context()`. [F1, F23]

## API Contracts
- `trace_event_raw_event_synth()` and `__synth_event_trace_start()`/`end()` must bracket `trace_event_buffer_reserve()` and `commit()` with `ring_buffer_nest_start()`/`end()`; once `synth_event_trace_start()` or `__synth_event_trace_start()` succeeds, the caller must invoke `synth_event_trace_end()`/`__synth_event_trace_end()` even on error. `trace_test_and_set_recursion()` sets the bit in `current->trace_recursion` (ordered `[BASE, NMI, IRQ, SIRQ, TRANSITION]`), issues `barrier()`, and disables preemption only when returning `bit >= 0`; callers must call `trace_clear_recursion(bit)` iff `bit >= 0` with the unshifted `bit` index (never `BIT(bit)`), and `tracing_gen_ctx_dec()` requires preemption to already be disabled. [F9, F148, F188, F224, F242, F259, F286]
- `eventfs_create_events_dir()` returns `NULL` under `LOCKDOWN_TRACEFS` or `ERR_PTR` on error, `eventfs_create_dir()` always returns `ERR_PTR` on failure (never `NULL`), and `tracefs_create_file()`/`tracefs_create_dir()`/`tracefs_create_instance_dir()` always return `NULL` on failure (with `tracefs_start_creating()` always paired with `tracefs_end_creating()` or `tracefs_failed_creating()`). `eventfs_callback` functions return `> 0` to instantiate an entry and `<= 0` to skip it, and callers must reset `data = ei->data` before each callback. [F185, F208, F209, F210, F221]
- Across `trace_events_inject.c`, `trace_events_hist.c`, and `trace_events_user.c`, a 32-bit `__data_loc` (`FILTER_DYN_STRING`) offset in bits 0..15 is relative to the start of the event record, whereas a `__rel_loc` (`FILTER_RDYN_STRING` / `VALIDATOR_REL`) offset is relative to `field->offset + field->size` (`sizeof(u32)`). [F67, F99, F236]

## Error Handling
- In tracefs file operations where `inode->i_private` holds a `struct trace_event_file`, the first access under `event_mutex` must call `event_file_file(filp)` rather than `event_file_data(filp)` and return `-ENODEV` if `NULL` (`EVENT_FILE_FL_FREED`). `set_trigger_filter()` assigns `data->filter = filter` even when `create_event_filter()` fails, so callers of `event_trigger_set_filter()` must call `event_trigger_reset_filter()` on error. [F4, F44]
- In `trace_events_hist.c`, `create_hist_field()` returns `NULL` (never `ERR_PTR`) on failure; `parse_field()` returns `ERR_PTR` on error but `NULL` on success for synthetic/common fields (`common_timestamp`, `common_stacktrace`, `common_cpu`, `common_comm`, `hitcount`) while setting `*flags`; and `find_match_var()`, `find_synthetic_field_var()`, and `create_target_field_var()` can return `NULL`, a valid pointer, or `ERR_PTR`. When `event->tp` or `hist_data->map` receives `IS_ERR()`, it must be reset to `NULL` before teardown; `register_trace_event()` returns `0` on failure (`-ENODEV`), and `event_hist_trigger()` must return early if `unlikely(!rbe)`. [F46, F47, F51, F52, F53, F61]

## Known Pitfalls
- In `user_events_write_core()`, verify `0 <= idx < refs->count` and `i->count >= user->min_size`, and pass a fresh `iov_iter` copy (`copy = *i`) to each `probe_func`. For enablement bitops, `user_event_enabler.values` must be `unsigned long`, and `align_addr_bit()` must align `uaddr` to `sizeof(long)` and add `+32` to `bit` for `ENABLE_VAL_32_ON_64_BIT` on big-endian aligned or little-endian unaligned addresses. [F84, F88, F90, F138]
