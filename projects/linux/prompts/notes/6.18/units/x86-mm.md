# X86 MM

This unit implements core x86 (32-bit and 64-bit) memory management, including direct and identity mappings, page fault and exception table handling, I/O remapping (`ioremap`), KASLR, NUMA topology, and AMD SME/SEV memory encryption. It also contains the Page Attribute Table (PAT) and Change Page Attribute (CPA) subsystem (`arch/x86/mm/pat/`), which tracks physical range caching attributes and splits, collapses, and updates kernel page tables (`set_memory_*`, `set_pages_*`) while maintaining cache and TLB coherency.

## Architecture & Data Flow

- In `struct cpa_data`, `cpa->vaddr` is `NULL` when `CPA_PAGES_ARRAY` is set and an address array when `CPA_ARRAY` is set; deriving a single-address alias (`vaddr = &addr` in `cpa_process_alias()`) must clear `CPA_PAGES_ARRAY | CPA_ARRAY` and reset `curpage = 0`. Without `CPA_NO_CHECK_ALIAS`, `cpa_process_alias()` must update both the direct map (`PAGE_OFFSET`) and 64-bit highmap (`[_text, _brk_end)`), clearing `_PAGE_NX` from `alias_cpa.mask_clr`/`mask_set` and setting `cpa->force_flush_all = 1` on the caller's `cpa` (not `alias_cpa`). [F49, F97, F182]
- `cpa->mask_set` and `cpa->mask_clr` use 4K PTE bit positions (`_PAGE_PAT` at bit 7), so large-page PMD/PUD paths must convert via `pgprot_large_2_4k()` and `pgprot_4k_2_large()`, and `collapse_pmd_page()` must return 0 when `!cpu_feature_enabled(X86_FEATURE_PSE)`. Because `_PAGE_GLOBAL` aliases `_PAGE_PROTNONE` on non-present PTEs and `_PAGE_PSE` makes `pmd_present()` true on non-present PMDs, `pgprot_clear_protnone_bits()` and `cea_set_pte()` must clear `_PAGE_GLOBAL` when `!(_PAGE_PRESENT)`, and `__split_large_page()` must clear `_PAGE_PSE` on a `!_PAGE_PRESENT` PUD. [F60, F61, F127]
- In `change_page_attr_set_clr()` and `__change_page_attr_set_clr()`, the early return when both `mask_set` and `mask_clr` are zero is only taken if `force_split` (`cpa->force_split`) is false. In `_set_memory_wc()` and `_set_pages_array()`, changing RAM pages to `_PAGE_CACHE_MODE_WC` must first transition them to `_PAGE_CACHE_MODE_UC_MINUS` before setting `_PAGE_CACHE_MODE_WC`. [F85, F138]
- Because `set_mce_nospec()` passes a non-canonical decoy address (`PAGE_OFFSET ^ BIT(63)`), `cpa_flush()` must canonicalize addresses with `fix_addr()` (casting `addr << 1` to `signed long` before `>> 1`) before `flush_tlb_kernel_range()` and `clflush_cache_range_opt()`, and `memtype_reserve()`/`memtype_free()` must mask physical addresses with `sanitize_phys()`. [F108, F193]
- In `memtype_interval.c`, `struct memtype` stores an exclusive `entry->end`, but `INTERVAL_TREE_DEFINE` uses inclusive endpoints (`entry->end - 1`); every `interval_iter_first()` and `interval_iter_next()` call on `memtype_rbroot` must pass `end - 1` as the query upper bound. In `init.c`, `__cachemode2pte_tbl[]` is indexed by `enum page_cache_mode` whereas `__pte2cachemode_tbl[]` is indexed by 3-bit PTE indices via `__pte2cm_idx()`, so checking the effective mode of a `page_cache_mode` requires translating through `__cachemode2pte_tbl[]` first. [F66, F69]
- Checks for NX support in page tables (`verify_rwx()`, `set_memory_x/nx/rox()`, `note_wx()`, `ptdump_walk_pgd_level_checkwx()`) must test `__supported_pte_mask & _PAGE_NX` rather than `cpu_feature_enabled(X86_FEATURE_NX)`, and `verify_rwx()` must incorporate the accumulated non-leaf `_PAGE_NX` (OR-ed) and `_PAGE_RW` (AND-ed) from `lookup_address_in_pgd_attr()`. [F88, F160]
- When kernel page tables are populated, removed, split, or collapsed, `direct_pages_count[]` must be updated under `pgd_lock` only for direct-mapped PFNs (not `vmemmap` where `direct == false` or highmap aliases). In `add_pages()`, `update_end_of_memory_vars()` must only be called when `params->pgmap` is `NULL`, and `end` must not exceed `DIRECT_MAP_PHYSMEM_END`. [F181, F186]
- In `access_error()`, `error_code & X86_PF_SHSTK` must precede `error_code & X86_PF_WRITE` because `X86_PF_WRITE` rejects any `VM_SHADOW_STACK` VMA. `spurious_kernel_fault()` must compare `error_code` for exact equality against `(X86_PF_WRITE | X86_PF_PROT)` and `(X86_PF_INSTR | X86_PF_PROT)` rather than testing bits with `&`. In `extable.c`, handlers inspecting `regs->ip` (`ex_handler_zeropad/fprestore/msr()`) must do so before `ex_handler_default()` overwrites `regs->ip`. [F91, F92, F194]

## Synchronization

- When `!debug_pagealloc_enabled()`, `split_large_page()` drops `cpa_lock` around `alloc_pages()` and must re-acquire `cpa_lock` before checking `!base` and returning `-ENOMEM`. Because `cpa_lock` was dropped, `__split_large_page()` and `__should_split_large_page()` must acquire `pgd_lock` and re-verify via `_lookup_address_cpa()` that the looked-up `pte_t *` still equals `kpte` before splitting or updating. [F9, F183]
- In `__split_large_page()`, all `PTRS_PER_PTE` entries in `pbase` must be populated via `split_set_pte()` before `__set_pmd_pte()` publishes `base`, and `flush_tlb_all()` must be called after `__set_pmd_pte()` while holding `pgd_lock` and `cpa_lock`. On `CONFIG_X86_32`, modifying a kernel PMD in `__set_pmd_pte()` or `collapse_pmd_page()` must propagate the PMD across all PGDs in `pgd_list` under `pgd_lock`. [F26, F187]
- When walking `pgd_list` in `arch_sync_kernel_mappings()` and `sync_global_pgds_l4/l5()`, hold `pgd_lock` outside each entry's `pgd_page_get_mm(page)->page_table_lock`. In `__kernel_physical_mapping_init()`, initialize child tables via `phys_p4d_init()` before locking `init_mm.page_table_lock` to publish the top-level entry, and call `sync_global_pgds()` afterward (as in `vmemmap_populate()`). [F29, F40]
- `cpa_flush()` and `cpa_flush_all()` must not be called with IRQs disabled after early boot, and `clflush_cache_range_opt()` must be bracketed by `mb()` fences (after `flush_tlb_kernel_range()` in `cpa_flush()`). When `debug_pagealloc_enabled()`, `probe_page_size_mask()` must keep 2M/1G direct-map pages disabled and `__kernel_map_pages()` must use `CPA_NO_CHECK_ALIAS` and local `__flush_tlb_all()` under `preempt_disable()`. [F39, F157, F158]
- Non-RAM PAT interval tree accesses must hold `memtype_lock`; `lookup_memtype()` and `memtype_get_idx()` must copy data out of the matched `struct memtype` before unlocking, whereas `memtype_erase()` unlinks the node under `memtype_lock` and returns it to `memtype_free()` to `kfree()`. For RAM pages, `set_page_memtype()` must update `_PGMT_MASK` in `pg->flags.f` via `READ_ONCE()` and `try_cmpxchg()`. [F2, F33, F34]
- `__set_memory_enc_dec()` must pair `down_read_trylock(&mem_enc_lock)` with `up_read(&mem_enc_lock)` around `__set_memory_enc_pgtable()`, whereas `set_memory_enc_stop_conversion()` intentionally acquires `mem_enc_lock` for write without releasing it. [F15]
- In `exc_page_fault()`, `read_cr2()` / `fred_event_data(regs)` and `kvm_handle_async_pf()` must run before `irqentry_enter()` and `instrumentation_begin()`, and `handle_page_fault()` must call `local_irq_disable()` immediately after `do_user_addr_fault()`. In `do_user_addr_fault()`, kernel instruction fetches from user addresses, `X86_PF_RSVD`, supervisor SMAP violations, `faulthandler_disabled() || !mm`, and `!(regs->flags & X86_EFLAGS_IF)` must be rejected before `local_irq_enable()` or locking VMA/mm. [F143, F144, F146]
- In `do_user_addr_fault()`, `__bad_area()` unlocks `mm` or `vma` on access error; after `handle_mm_fault()`, the RCU path must call `vma_end_read(vma)` unless `VM_FAULT_RETRY | VM_FAULT_COMPLETED` is set (setting `FAULT_FLAG_TRIED` if `fault & VM_FAULT_MAJOR` on `VM_FAULT_RETRY`), and the `mmap_lock` path must call `mmap_read_unlock(mm)` unless `fault_signal_pending()`, `VM_FAULT_COMPLETED`, or `VM_FAULT_RETRY` holds. [F20, F195]

## Object Lifetimes

- `memtype_check_insert()` transfers ownership of `entry_new` into `memtype_rbroot` only when it returns `0`; on error, `memtype_reserve()` must `kfree(entry_new)`. In `memtype_seq_ops`, the temporary `struct memtype` from `memtype_get_idx()` must be freed in `memtype_seq_next()` and `memtype_seq_stop()`, never in `memtype_seq_show()`. In `iounmap()`, `kmsan_iounmap_page_range()` and `memtype_free()` must finish before `remove_vm_area()` and `kfree(p)`. [F1, F5, F7]
- In `__memremap_is_setup_data()`, every mapping from `early_memremap_decrypted()` / `memremap()` must be unmapped on all paths; before accessing `(struct setup_indirect *)data->data` when `data->type == SETUP_INDIRECT`, the initial `sizeof(struct setup_data)` mapping must be unmapped and remapped for `sizeof(struct setup_data) + data->len` bytes (which is also the bound for checking whether `phys_addr` falls inside the entry). [F8, F116, F117]
- `collapse_pmd_page()` and `collapse_pud_page()` must only queue replaced page-table pages onto `pgtables` under `pgd_lock`, and `cpa_collapse_large_pages()` must call `flush_tlb_all()` before freeing them with `__free_page()`. When `try_to_free_pte_page()` or `try_to_free_pmd_page()` frees an empty table page, its caller must clear the parent entry via `pmd_clear()` or `pud_clear()`. [F11, F12]
- When `!pgtable_l5_enabled()`, P4D is folded into PGD (`pgd_none()` is always false), so `sync_global_pgds_l4()` and `preallocate_vmalloc_pages()` must operate on P4D/PUD levels, and `free_p4d()` / `remove_p4d_table()` must not free the folded P4D page. In `ident_map.c`, `free_pmd()` and `free_pud()` must skip `pmd_leaf()` and `pud_leaf()` entries. [F16, F104]
- In `init_64.c`, `remove_pte_table()` and `remove_pmd_table()` must free mapped leaf pages via `free_pagetable()` or `free_hugepage_table()` only when `direct` is `false` (and when `direct` is `true`, only clear entries and call `update_page_count()`). `free_hugepage_table()` must release `altmap` blocks via `vmem_altmap_free()`, and `free_pagetable()` must release `PageReserved()` pages via `put_page_bootmem()` or `free_reserved_pages()`. [F17, F18]
- In `mem_encrypt_free_decrypted_mem()`, when `sme_me_mask` is non-zero, `[__start_bss_decrypted_unused, __end_bss_decrypted)` must be re-encrypted with `set_memory_encrypted()` before `free_init_pages()`, aborting if it fails. In `free_init_pages()`, when `!debug_pagealloc_enabled()`, `[begin, end)` must be marked NX and RW before `free_reserved_area()`. [F19, F22]

## API Contracts

- `__change_page_attr_set_clr()` overwrites `cpa->numpages` during its `while (rempages)` loop and must restore `cpa->numpages = numpages` on exit so callers flush the full range in `cpa_flush()`. `lookup_address*()` returns a non-NULL `pte_t *` even for non-present/empty entries and points to a `p4d_t`/`pud_t`/`pmd_t` when `*level > PG_LEVEL_4K`, so callers must check `pte_present()`/`!pte_none()` and dispatch on `*level`. [F13, F43, F123]
- `__should_split_large_page()` and `should_split_large_page()` return `0` (keep), `1` (split), or `-EINVAL`, so `__change_page_attr()` must call `split_large_page()` only when `do_split > 0`. `populate_pmd()` and `populate_pud()` return the positive mapped 4K page count or `-1` on error, so `populate_pgd()` must use a signed `ret`, unmap on `ret < 0`, and set `cpa->numpages = ret` before returning `0`. [F44, F46]
- `pat_pagerange_is_ram()` returns `1` (RAM), `0` (non-RAM), or `-1` (mixed), so callers must test `< 0` and `== 1` explicitly. Every success path of `memtype_reserve()` must populate `*new_type` when `new_type != NULL`, and `memtype_reserve()` must sanitize its exclusive `end` as `sanitize_phys(end - 1) + 1`. In `__ioremap_caller()`, `phys_addr` and `size` must be page-aligned (and `phys_addr` masked with `PHYSICAL_PAGE_MASK`) before reservation and mapping. [F41, F54, F68, F177]
- `prepare_pte_enc()` returns `1` without initializing `d->pa` or `d->size` when `!d->pfn` or `old_prot == d->new_pgprot`, so callers must abort on non-zero return. `enc_dec_hypercall()`, `early_set_mem_enc_dec_hypercall()`, and `early_set_memory_enc_dec()` take `size` in bytes, whereas `amd_enc_status_change_prepare/finish()` and `notify_page_enc_status_changed()` take page counts (`npages`). [F47, F57]
- `bad_area_access_error()` and `__bad_area()` take a nullable `mm` (`mm != NULL` for `mmap_lock`, `mm == NULL` for RCU VMA lock) and must not dereference `mm` unconditionally. In `do_user_addr_fault()`, `FAULT_FLAG_USER` must be set from `user_mode(regs)` (not `error_code & X86_PF_USER`), and `FAULT_FLAG_WRITE` from `error_code & (X86_PF_SHSTK | X86_PF_WRITE)`. [F50, F178]

## Error Handling

- `reserve_ram_pages_type()` must verify `get_page_memtype(page) == _PAGE_CACHE_MODE_WB` for every PFN in `[start, end)` before calling `set_page_memtype()` in a second pass, because it does not roll back on `-EBUSY`. `memtype_erase()` returns `ERR_PTR(-EINVAL)` (not `NULL`) when no entry matches, so callers must check `IS_ERR()` before `kfree()`. [F3, F42]
- `set_memory_uc/wc()` and `_set_pages_array()` must reserve PAT memtypes before changing PTEs and roll back via `memtype_free()` on CPA failure (saving `free_idx = i` before resetting `i` and skipping `PageHighMem` in `_set_pages_array()`), whereas `set_memory_wb()` and `set_pages_array_wb()` must restore WB PTEs before `memtype_free()`. [F14, F98]
- Non-RAM PAT reservations in `__ioremap_caller()`, `memtype_reserve_io()`, and `reserve_pfn_range()` must call `memtype_kernel_map_sync()` after `memtype_reserve()`, and `__ioremap_caller()` must call `free_vm_area(area)` before `memtype_free()` on failure. [F6, F189]
- `split_large_page()` must free `base` when `__split_large_page()` returns `1` (aborted due to concurrent split) while still returning `0` so `__change_page_attr()` retries. When `__change_page_attr_set_clr()` fails after setting `CPA_FLUSHTLB` or during `__set_memory_enc_pgtable()`, callers must still flush TLBs/caches before returning `ret`. [F45, F53]

## Known Pitfalls

- `pte_pfn()`, `pmd_pfn()`, `pud_pfn()`, and `pg_level_to_pfn()` always return a 4K PFN regardless of level, so callers (`prepare_pte_enc()`, `slow_virt_to_phys()`) must convert via `(phys_addr_t)pfn << PAGE_SHIFT` (never `<< page_level_shift(level)`). Also widen `pfn` to `resource_size_t`/`phys_addr_t` before `<< PAGE_SHIFT` in `pfnmap_*()` and `valid_mmap_phys_addr_range()`. [F58, F107]
- In `set_memory.c`, `overlaps()` compares inclusive endpoints, so `static_protections()` and its helpers must subtract 1 from exclusive end addresses, section end symbols (`_etext`, `__end_rodata`, `BIOS_END`), and PFN counts. In `__should_split_large_page()`, `cpa->pfn` must be set to the sub-page offset PFN for `cpa_process_alias()`, whereas whole-large-page checks and `pfn_pte()` must use the base `old_pfn` and `lpaddr`. [F71, F96]
- Virtual-address loops near the top of the address space (`sync_global_pgds_l5()`, `setup_cpu_entry_area_ptes()`, `cpa_collapse_large_pages()`) must guard against unsigned wraparound (`addr < start`), and `copy_from_kernel_nofault_allowed()` must verify `boot_cpu_data.x86_virt_bits != 0` before calling `__is_canonical_address()`. Standalone `pgd_t` variables not in a two-page KPTI PGD allocation (`trampoline_pgd_entry`) must be assigned directly, not via `set_pgd()`. [F100, F105, F118]
