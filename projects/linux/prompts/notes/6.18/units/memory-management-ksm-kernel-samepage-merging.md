# MEMORY MANAGEMENT - KSM (Kernel Samepage Merging)

Kernel Samepage Merging (KSM) dynamically scans anonymous memory areas marked `VM_MERGEABLE` across processes and deduplicates identical pages into shared copy-on-write (COW) pages or the special zero page. It tracks candidate virtual addresses with `ksm_rmap_item` structures in per-process `ksm_mm_slot` lists, uses an unstable red-black tree to detect unchanged pages within a scan pass, and promotes matched pages into a write-protected stable red-black tree (`ksm_stable_node`) while providing rmap, swap-in copy, migration, and memory failure hooks.

## Architecture & Data Flow
- `ksm_rmap_item::address` packs `STABLE_FLAG`, `UNSTABLE_FLAG`, and `SEQNR_MASK` (`0x0ff`, bits `0..7`) into its low bits. Code reading the address (`get_next_rmap_item()`, `rmap_walk_ksm()`, `collect_procs_ksm()`), detaching (`remove_rmap_item_from_tree()`), or inserting into the unstable tree must mask `address` with `PAGE_MASK`. `remove_rmap_item_from_tree()` computes `age = (unsigned char)(ksm_scan.seqnr - rmap_item->address)` (`BUG_ON(age > 1)`), only calls `rb_erase()` when `age == 0`, and always decrements `ksm_pages_unshared`. [F46, F60, F87]
- In `ksm_stable_node`, `head` overlays `node.__rb_parent_color`: `head == &migrate_nodes` means `list` is on `migrate_nodes`, `head == STABLE_NODE_DUP_HEAD` means `hlist_dup` is in a chain, and any other value means `node` is in `root_stable_tree`. `rmap_hlist_len` uses `STABLE_NODE_CHAIN` (`-1024`, not `-1`) to tag chain nodes (`is_stable_node_chain()`), and non-chain paths (`remove_node_from_stable_tree()`, `__is_page_sharing_candidate()`, `stable_tree_append()`) must assert `rmap_hlist_len >= 0`. [F62, F85]
- When `stable_node_dup()` collapses a 1-entry chain via `rb_replace_node(&stable_node->node, &found->node, root)`, it must free the chain node, decrement `ksm_stable_node_chains` and `ksm_stable_node_dups`, and set `*_stable_node = found` so callers of `__stable_node_chain()` (`chain()`, `chain_prune()`) see `*_stable_node == *_stable_node_dup` and treat it as a non-chain node. [F48]
- Every addition or removal of a `ksm_rmap_item` on `stable_node->hlist` (`stable_tree_append()`, `remove_rmap_item_from_tree()`, `remove_node_from_stable_tree()`) must update `stable_node->rmap_hlist_len`, `rmap_item->mm->ksm_merging_pages`, and `ksm_pages_shared` (sole entry) or `ksm_pages_sharing` (multiple entries) in lockstep. [F44]
- When `replace_page()` maps the KSM zero page (`is_zero_pfn(page_to_pfn(kpage))`), it must mark the PTE dirty (`pte_mkdirty()`, checked by `is_ksm_zero_pte()` on unmap), call `ksm_map_zero_page(mm)`, and `dec_mm_counter(mm, MM_ANONPAGES)` instead of taking a folio ref or anon rmap. In `ksm_fork()`, `mm->ksm_merging_pages` and `mm->ksm_rmap_items` must be reset to 0 while inherited `mm->ksm_zero_pages` is added to global `ksm_zero_pages`. [F10, F43]
- In `write_protect_page()`, `ptep_clear_flush()` must precede `folio_mapcount(folio) + 1 + swapped != folio_ref_count(folio)` and `folio_try_share_anon_rmap_pte()` (restoring the PTE via `set_pte_at()` on failure). In `replace_page()`, after `write_protect_page()` drops the PTE lock, it must reacquire `pte_offset_map_lock()` inside `mmu_notifier_invalidate_range_start()`/`end()` and verify `pte_same(ptep_get(ptep), orig_pte)`. When `try_to_merge_one_page()` upgrades an anonymous folio in-place (`kpage == NULL`), it must call `folio_mark_dirty(folio)`. [F24, F53, F113]
- `root_stable_tree` and `root_unstable_tree` point to 1-element `one_stable_tree` and `one_unstable_tree` until `merge_across_nodes_store()` allocates `nr_node_ids` roots (copying `root_unstable_tree[0] = one_unstable_tree[0]` and setting `ksm_nr_node_ids = knob ? 1 : nr_node_ids`). PFN lookups must index via `get_kpfn_nid()`, full-tree loops must bound `nid` by `ksm_nr_node_ids`, and `rb_erase()` in `stable_node_dup_del()` or `remove_rmap_item_from_tree()` must index via `NUMA(dup->nid)` or `NUMA(rmap_item->nid)`. [F50, F57, F58]
- In `ksm_check_stable_tree()`, when `stable_node_chain_remove_range()` returns `true` (a node or emptied chain was erased from `root_stable_tree + nid`), `node` must be reset via `rb_first(root_stable_tree + nid)` rather than `rb_next(node)`. [F49]
- In `scan_get_next_rmap_item()`, after `get_next_rmap_item()` returns non-NULL, `ksm_scan.rmap_list` must advance to `&rmap_item->rmap_list` before `should_skip_rmap_item()` and `goto next_page`. In `unmerge_and_remove_all_rmap_items()`, if `unmerge_ksm_pages()` fails, `ksm_scan.mm_slot` must be reset to `&ksm_mm_head` under `ksm_mmlist_lock`. [F72, F73]
- When `MMF_VM_MERGE_ANY` is set across `execve()`, `ksm_execve()` must call `__ksm_enter(mm)`, and every path freeing a `ksm_mm_slot` (`__ksm_exit()`, `scan_get_next_rmap_item()`, `unmerge_and_remove_all_rmap_items()`) must clear both `MMF_VM_MERGEABLE` and `MMF_VM_MERGE_ANY` before `mmdrop(mm)`. [F51]
- Because `alloc_stable_node()` uses `kmem_cache_alloc()` (not `zalloc`), callers (`stable_tree_insert()`, `alloc_stable_node_chain()`) must explicitly initialize `hlist`, `rmap_hlist_len`, `kpfn` or `chain_prune_time`, `nid`, and tree/chain links before insertion. [F41]

## Synchronization
- `ksm_mmlist_lock` is a spinlock nesting inside `mmap_read_lock(mm)`: `mm_slot_alloc()`, `mm_slot_free()`, `mmdrop()`, and `mmap_read_lock()`/`mmap_write_lock()` must run outside `ksm_mmlist_lock`. In `scan_get_next_rmap_item()`, when `ksm_scan.address != 0` and `mm_slot` stays in `mm_slots_hash` after advancing `ksm_scan.mm_slot`, `mmap_read_unlock(mm)` must precede `spin_unlock(&ksm_mmlist_lock)`. [F5, F93]
- After taking `mmap_read_lock(mm)` on an `mm` from a `ksm_mm_slot` or `ksm_rmap_item`, callers (`scan_get_next_rmap_item()`, `unmerge_and_remove_all_rmap_items()`, `find_mergeable_vma()`) must check `ksm_test_exit(mm)` before accessing VMAs. In `try_to_merge_with_ksm_page()` and `try_to_merge_with_zero_page()`, `mmap_read_lock(mm)` must be held continuously across `find_mergeable_vma()`, `try_to_merge_one_page()`, and `get_anon_vma(vma->anon_vma)`. [F17, F21]
- Modifying a KSM folio's `folio->mapping` (`folio_set_stable_node()`) or `ksm_stable_node->hlist` (`stable_tree_insert()`, `stable_tree_append()`, `remove_rmap_item_from_tree()`) requires `folio_lock()`. In `stable_tree_insert()`, `folio_set_stable_node(kfolio, stable_node_dup)` must only run after `stable_node_dup` is initialized and linked into `root_stable_tree` or a chain (after fallible `alloc_stable_node_chain()`). [F13, F95]
- In `folio_migrate_ksm()`, `stable_node->kpfn = folio_pfn(newfolio)` and `smp_wmb()` must precede `folio_set_stable_node(folio, NULL)`, and `ksm_get_folio()` must execute `smp_rmb()` and recheck `READ_ONCE(stable_node->kpfn) != kpfn` before calling `remove_node_from_stable_tree(stable_node)`. [F55]
- In `ksm_get_folio()`, if `folio_try_get(folio)` fails while `folio->mapping == expected_mapping`, it must spin with `cpu_relax()` while `folio_test_swapcache(folio)` is set, and re-verify `READ_ONCE(folio->mapping) == expected_mapping` after `folio_try_get()` and `folio_lock()`/`folio_trylock()`. In `stable_tree_search()`, a match found with `KSM_GET_FOLIO_NOLOCK` must be re-fetched via `ksm_get_folio(stable_node_dup, KSM_GET_FOLIO_TRYLOCK)` and unlocked before returning. [F25, F97]
- Walking `anon_vma` interval trees in `rmap_walk_ksm()` and `collect_procs_ksm()` requires `anon_vma_lock_read()` (or `anon_vma_trylock_read()`) on `rmap_item->anon_vma`. In `rmap_walk_ksm()`, if `rwc->try_lock` is true and trylock fails, set `rwc->contended = true` and return immediately. In `collect_procs_ksm()`, `rcu_read_lock()` must nest inside `anon_vma_lock_read()`. [F27, F101]
- Every `ksm_thread_mutex` holder accessing stable/unstable trees (`ksm_scan_thread()`, `run_store()`, `merge_across_nodes_store()`, `max_page_sharing_store()`) must call `wait_while_offlining()`, which must drop `ksm_thread_mutex` while waiting on `KSM_RUN_OFFLINE`. [F94]
- Callers of `unmerge_ksm_pages()` and `break_ksm()` must pass `lock_vma = true` when holding `mmap_write_lock(mm)` before clearing `VM_MERGEABLE` (`__ksm_del_vma()`, `ksm_madvise()`), and `lock_vma = false` when holding only `mmap_read_lock(mm)` (`break_cow()`, `unmerge_and_remove_all_rmap_items()`). [F102]
- Global `ksm_zero_pages` and `mm->ksm_zero_pages` are updated concurrently without a shared lock, so all accesses must use `atomic_long_t` helpers (`ksm_map_zero_page()`, `ksm_might_unmap_zero_page()`, `mm_ksm_zero_pages()`). [F26]

## Object Lifetimes
- When `ksm_get_folio()`, `chain_prune()`, or `chain()` returns `NULL`, `remove_node_from_stable_tree()` has already erased and freed `stable_node`, whereas `ERR_PTR(-EBUSY)` from `ksm_get_folio(..., KSM_GET_FOLIO_TRYLOCK)` drops the folio ref without freeing `stable_node`. Callers in `stable_tree_search()` and `stable_tree_insert()` must not dereference `stable_node`/`stable_node_dup` on `NULL` and must `goto again`; chain `hlist` walks (`stable_node_dup()`, `remove_stable_node_chain()`, `stable_node_chain_remove_range()`) must use `hlist_for_each_entry_safe()`. [F1, F47, F70, F71]
- When `remove_rmap_item_from_tree()` detaches a `STABLE_FLAG` `rmap_item`, it must call `put_anon_vma(rmap_item->anon_vma)`, set `rmap_item->head = NULL`, and clear low flag bits on `rmap_item->address`. [F2]
- `__ksm_exit(mm)` may only unlink/free `mm_slot` and call `mmdrop(mm)` when `ksm_scan.mm_slot != mm_slot` and `mm_slot->rmap_list == NULL` under `ksm_mmlist_lock`; otherwise it must leave `mm_slot` for `ksmd` and take/release `mmap_write_lock(mm)`. `mm_slot_cache` allocates `struct ksm_mm_slot`, so `struct mm_slot *` pointers must be converted via `mm_slot_entry(slot, struct ksm_mm_slot, slot)` before freeing. [F6, F90]
- `scan_get_next_rmap_item()` only transfers its `folio_get(folio)` reference via `*page` when returning a non-NULL `rmap_item` (which `ksm_do_scan()` drops via `put_page(page)`), and must call `folio_put(folio)` whenever `get_next_rmap_item()` returns `NULL` or `should_skip_rmap_item()` returns `true`. [F8]
- `unstable_tree_search_insert()` must call `put_page(tree_page)` on every comparison step where `tree_page` is not returned (including `page == tree_page`, `<` or `>`, and cross-node mismatch), only transferring `*tree_pagep` ownership when returning a non-NULL `tree_rmap_item`. [F9]

## API Contracts
- In `ksm_might_need_to_copy()`, `PageHWPoison(page)` and `copy_mc_user_highpage()` failures must return `ERR_PTR(-EHWPOISON)` (checked before `!folio_test_uptodate(folio)`), while allocation or `mem_cgroup_charge(new_folio, vma->vm_mm, ...)` failure returns `NULL` (calling `folio_put(new_folio)` if allocated). On success it returns `new_folio` locked, uptodate, dirty, and refcounted without unlocking or putting the input `folio`. [F7, F32]
- `folio_set_stable_node(folio, NULL)` sets `folio->mapping` to `(void *)FOLIO_MAPPING_KSM`, so `folio_test_ksm(folio)` can be true while `folio_stable_node(folio)` returns `NULL`; callers must null-check `folio_stable_node(folio)`. [F88]
- `write_protect_page()` requires order-0 folios (`WARN_ON_ONCE(folio_test_large(folio))`), so `try_to_merge_one_page()` must split large folios with `split_huge_page(page)` under `folio_trylock(folio)` and refresh `folio = page_folio(page)` first. [F110]
- In `break_ksm()`, `handle_mm_fault()` must be called with `FAULT_FLAG_UNSHARE | FAULT_FLAG_REMOTE` (never `FAULT_FLAG_WRITE`) in a loop with `folio_walk_start()` until `!ksm_page` or `VM_FAULT_SIGBUS | VM_FAULT_SIGSEGV | VM_FAULT_OOM`. [F74, F106]
- `ksm_process_mergeable()` requires `mmap_assert_locked(mm)`, whereas `ksm_disable()`, `ksm_enable_merge_any()`, `ksm_disable_merge_any()`, and `ksm_madvise()` require `mmap_write_lock(mm)`. [F28, F29]
- Candidate pages obtained in `get_mergeable_page()` or `scan_get_next_rmap_item()` via `folio_walk_start()` must call `flush_anon_page(vma, page, addr)` and `flush_dcache_page(page)` before `mmap_read_unlock(mm)`, and `calc_checksum()` must use `kmap_local_page()` / `kunmap_local()`. [F104]

## Error Handling
- If the second merge in `try_to_merge_two_pages()` or `stable_tree_insert()` in `cmp_and_merge_page()` fails after `try_to_merge_with_ksm_page()` succeeded, `break_cow()` must be called on each already-merged `rmap_item`. [F4]
- `__ksm_del_vma()` and `ksm_madvise(..., MADV_UNMERGEABLE, ...)` must not clear `VM_MERGEABLE` if `unmerge_ksm_pages()` fails, and `ksm_disable_merge_any()` must call `ksm_add_vmas(mm)` and keep `MMF_VM_MERGE_ANY` set if `ksm_del_vmas(mm)` fails. [F11]
- Callers of `ksm_get_folio(..., KSM_GET_FOLIO_TRYLOCK)` (such as `stable_tree_search()`) must check both `!folio` and `IS_ERR(folio)` (`-EBUSY`) before dereferencing or unlocking `folio`. [F31]
- In `try_to_merge_one_page()`, `err` starts at `-EFAULT` and must not be overwritten with `0` by intermediate calls like `split_huge_page(page)` before `write_protect_page()` and `replace_page()` succeed. [F33]
- Callers of `find_mergeable_vma()` must null-check the returned `vma`, and `write_protect_page()` / `replace_page()` must check `page_address_in_vma() != (unsigned long)-EFAULT` before page table walks. [F34, F40]
- In `remove_stable_node()`, `folio_mapped(folio)` is a valid race with `__mmput()` and must return `-EBUSY` without warning. When `cmp_and_merge_page()` merges an already-KSM folio with `!is_page_sharing_candidate(stable_node)`, it must pass `max_page_sharing_bypass = true` to `stable_tree_append()`. [F107, F116]

## External Contracts
- `run_store()` must reject `flags > KSM_RUN_UNMERGE` (`2`) with `-EINVAL` (protecting `KSM_RUN_OFFLINE`), bracket `unmerge_and_remove_all_rmap_items()` with `set_current_oom_origin()` / `clear_current_oom_origin()`, and reset `ksm_run = KSM_RUN_STOP` on error. [F64, F115]
- `merge_across_nodes_store()` and `max_page_sharing_store()` must return `-EBUSY` unless `ksm_pages_shared == 0` and `remove_all_stable_nodes() == 0` (and `-EINVAL` if `max_page_sharing < 2`). `advisor_mode_store()` must reset `advisor_ctx` and `ksm_thread_pages_to_scan` via `set_advisor_defaults()`, and `pages_to_scan_store()` must return `-EINVAL` when `ksm_advisor != KSM_ADVISOR_NONE`. [F56, F117]
- `ksm_compatible()` rejects `VM_SHARED | VM_MAYSHARE | VM_SPECIAL | VM_HUGETLB | VM_DROPPABLE`, `VM_SAO`, `VM_SPARC_ADI`, and DAX files, and `ksm_madvise(..., MADV_MERGEABLE, ...)` must return `0` (not an error) on incompatible VMAs. `pages_volatile_show()` must compute its value in a signed `long` and clamp `< 0` to `0`. [F67, F119]

## Known Pitfalls
- In `ksm_rmap_item`, `nid`/`node` (`UNSTABLE_FLAG`) share unions with `anon_vma` and `{head, hlist}` (`STABLE_FLAG`), so `remove_rmap_item_from_tree()` must precede setting `rmap_item->anon_vma` or calling `stable_tree_append()`. [F86]
- During `MEM_OFFLINE`, `stable_node_dup_remove_range()` must remove nodes in `[start_pfn, end_pfn)` directly via `remove_node_from_stable_tree(stable_node)` without calling `ksm_get_folio()`. [F105]
- In `cmp_and_merge_page()`, if `try_to_merge_two_pages()` fails because `page` and `tree_page` share a compound page (`compound_head(page) == compound_head(tree_page)`), `put_page(tree_page)` must precede `split_huge_page(page)`. [F111]
- `ksm_run` is an `unsigned long` whose bit waiters/wakers (`wait_while_offlining()`, `ksm_memory_callback()`) must pass `ilog2(KSM_RUN_OFFLINE)`. `should_skip_rmap_item()` must guard `rmap_item->age++` with `if (age != U8_MAX)`, `scan_time_advisor()` must use `div_s64()`, and `stable_node_dup()` must compare `chain_prune_time` with `time_before()`. [F63, F79, F82, F89]
