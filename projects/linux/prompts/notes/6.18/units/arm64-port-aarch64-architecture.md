# ARM64 PORT (AARCH64 ARCHITECTURE)

This unit provides core AArch64 architecture headers, UAPI definitions, low-level ACPI/NUMA initialization, the memory management subsystem (`arch/arm64/mm/`), architecture library routines (`arch/arm64/lib/`), and confidential computing guest drivers (`drivers/virt/coco/`).

## Architecture & Data Flow

- `pte_present_invalid()`, `pte_valid_not_user()`, and `pte_access_permitted_no_overlay()` must test exact multi-bit combinations (`(val & mask) == expected`) because `PTE_PRESENT_INVALID` aliases `PTE_NG` and execute-only user PTEs clear `PTE_USER`. Hardware-bit predicates (`pte_young`, `pte_write`, `pte_user`, `pte_user_exec`, `pte_special`, `pte_cont`, `pte_tagged`) require `pte_present(pte)`. `pte_protnone()` must check `pte_present_invalid(pte) && !pte_user(pte) && !pte_user_exec(pte)`, and `pmd_trans_huge()` must OR `PTE_VALID` into `pmd` before `!pmd_table()`. [F42, F84, F85]
- Before `pte_wrprotect()` or `pte_modify()` alters `PTE_WRITE` or `PTE_RDONLY`, it must check `pte_hw_dirty(pte)` (`pte_write(pte) && !pte_rdonly(pte)`) and set `PTE_DIRTY`, and `pte_modify()` must then call `pte_mkdirty(pte)` if `pte_sw_dirty(pte)` is set. [F86]
- Under `pgattr_change_is_safe()`, live valid kernel PTE/PMD/PUD updates without break-before-make may only modify `PTE_PXN | PTE_RDONLY | PTE_WRITE | PTE_NG | PTE_SWBITS_MASK` (and `PTE_ATTRINDX_MASK` between `MT_NORMAL`, which must remain index 0, and `MT_NORMAL_TAGGED`), must reject `PTE_CONT` entries and PFN changes, and must reject Non-Global-to-Global transitions (`if (old & ~new & PTE_NG) return false`). Regions mapped in `map_mem()` for later in-place `update_mapping_prot()` must use `NO_CONT_MAPPINGS`. [F79, F138, F206, F259, F309]
- In `contpte_convert()`, `contpte_ptep_get*()`, and `__get_and_clear_full_ptes()`, dirty and young bits must be ORed across all entries. Before clearing or write-protecting a partial `CONT_PTES` range, unfold via `contpte_try_unfold_partial()`. In `contpte_ptep_set_access_flags()`, compare `entry` against `orig_pte = pte_mknoncont(ptep_get(ptep))`; if `pte_write()` is unchanged, update all `CONT_PTES` entries via `__ptep_set_access_flags()`, else unfold via `__contpte_try_unfold()`. [F91, F199, F212, F214, F255, F322]
- When breaking present contiguous HugeTLB entries in `clear_flush()` or `get_clear_contig()` (including in `huge_ptep_set_access_flags()`, which merges `orig_pte` dirty/young bits back before `__set_ptes_anysz()`), `__ptep_get_and_clear_anysz()` must be used rather than `__pte_clear()` to keep `page_table_check` synchronized, and `get_clear_contig()` must guard `pte_dirty()`/`pte_young()` propagation with `if (pte_present(pte))`. [F194, F215, F216]
- `mm->context.id`, `active_asids`, and `reserved_asids` store 64-bit context IDs, so `asid_map`/`pinned_asid_map` bit operations must strip the generation via `ctxid2asid(asid)`. `new_context()` must start `find_next_zero_bit()` at index `>= 1` and run `check_update_reserved_asid()` across all CPUs before checking `mm->context.pinned`. On rollover in `flush_context()`, if `atomic64_xchg_relaxed(&per_cpu(active_asids, i), 0)` returns 0, preserve `per_cpu(reserved_asids, i)` and set its bit in `asid_map`. [F174, F209, F239, F285]
- `switch_mm()` must call `update_saved_ttbr0(tsk, next)` unconditionally even when `prev == next`, and `enter_lazy_tlb()` must reset saved `ttbr0` to `reserved_pg_dir` via `update_saved_ttbr0(tsk, &init_mm)`. [F52]
- In `do_page_fault()`, if `faulthandler_disabled() || !mm`, jump to `no_context` before taking any locks. Check `is_gcs_fault(esr)` before `is_write_abort(esr)` and read-fault branches so all GCS faults set `VM_WRITE` and `FAULT_FLAG_WRITE`. When `handle_mm_fault()` under `FAULT_FLAG_VMA_LOCK` returns `VM_FAULT_RETRY | VM_FAULT_MAJOR`, set `FAULT_FLAG_TRIED` before retrying under `mmap_lock`. In `fault_from_pkey()`, validate `POR_EL0` against `vma_pkey(vma)` via `arch_vma_access_permitted()` instead of trusting `ESR_ELx_Overlay`. [F221, F252, F299, F303]
- `untagged_addr(addr)` must bitwise-AND `__addr` with `__untagged_addr(__addr)` (`sign_extend64((__force u64)(addr), 55)`) so user addresses (bit 55 == 0) clear bits [63:56] while kernel addresses (bit 55 == 1) preserve them. [F99]

## Synchronization

- Synchronous TLB invalidations in `asm/tlbflush.h` must issue `dsb(ishst)` (or `dsb(nshst)`) before `__tlbi()` and `dsb(ish)` (or `dsb(nsh)`) after, plus `isb()` for kernel mappings (`local_flush_tlb_all`, `flush_tlb_all`, `flush_tlb_kernel_range`, `__flush_tlb_kernel_pgtable`). In `flush_tlb_mm()`, `__flush_tlb_page_nosync()`, and `__flush_tlb_range_nosync()`, `dsb(ishst)` must execute after clearing the PTE and before reading `ASID(mm)` via `atomic64_read(&mm->context.id)` so a concurrent ASID rollover cannot walk stale PTEs. [F13, F26]
- Live valid PTE permission or access/dirty updates (`__ptep_test_and_clear_young()`, `___ptep_set_wrprotect()`, `__clear_young_dirty_pte()`, `__ptep_set_access_flags()`) must use a `cmpxchg_relaxed()` loop to avoid racing with hardware AF/DBM updates: `___ptep_set_wrprotect()` and `__clear_young_dirty_pte()` must transfer `pte_hw_dirty(pte)` to `PTE_DIRTY` before clearing `PTE_WRITE`, and `__ptep_set_access_flags()` must mask `entry` to `(PTE_RDONLY | PTE_AF | PTE_WRITE | PTE_DIRTY)` and invert `PTE_RDONLY` before ORing and inverting back. [F23, F223]
- In `contpte_ptep_get_lockless()`, any `contpte_is_consistent()` failure in either the outer loop or the inner dirty/young loops must jump to `retry` to re-read `*orig_ptep` and reset `orig_pte`, discarding any accumulated dirty or young bits. [F256]
- When `CONFIG_PGTABLE_LEVELS <= 4` and runtime folding is active, `p4d_offset_lockless_folded()` must pass the original page-table pointer `pgdp` (via `p4d_offset(pgdp, addr)`) rather than `&pgd` on the stack, because `p4d_to_folded_pud()` aligns the pointer down to `PAGE_SIZE`. [F25]
- `queue_pte_barriers()` and `arch_*_lazy_mmu_mode()` must check `in_interrupt()` first (emitting `emit_pte_barriers()` immediately and bypassing `TIF_LAZY_MMU*` in interrupt context); in process context, `arch_leave_lazy_mmu_mode()` must flush pending barriers via `arch_flush_lazy_mmu_mode()` before clearing `TIF_LAZY_MMU`. [F56, F123]
- In `check_and_switch_context()`, the lockless `atomic64_cmpxchg_relaxed()` fastpath on `this_cpu_ptr(&active_asids)` requires `old_active_asid != 0` and `asid_gen_match(asid)`; if it fails, `mm->context.id` must be reloaded and rechecked with `asid_gen_match()` after acquiring `cpu_asid_lock` before calling `new_context(mm)`. [F172, F296]
- In `do_page_fault()`, pre-fault rejections must release `vma_end_read(vma)` or `mmap_read_unlock(mm)` before `goto bad_area` (sampling `vma_pkey(vma)` first on `fault_from_pkey()`). After `handle_mm_fault()`, call `vma_end_read(vma)` only when `!(fault & (VM_FAULT_RETRY | VM_FAULT_COMPLETED))`, and call `mmap_read_unlock(mm)` only when `!fault_signal_pending(fault, regs) && !(fault & (VM_FAULT_COMPLETED | VM_FAULT_RETRY))`. [F164, F165, F222]
- `set_swapper_pgd()` (`noinstr`) must hold `swapper_pgdir_lock` across `FIX_PGD` access when `!rodata_is_rw`, while `__create_pgd_mapping()` holds `fixmap_lock` for `FIX_P4D..FIX_PTE`. `update_range_prot()` must call `split_kernel_leaf_mapping()` (under `pgtable_split_lock`) before walking page tables. In `split_pmd()`, `split_pud()`, and `init_clear_pgtable()` (required after `__pgd_pgtable_alloc()`, which strips `__GFP_ZERO`), execute `dsb(ishst)` before `__p*d_populate()`. [F179, F180, F186, F204, F306]
- When freeing kernel tables in `__pmd_free_pte_page()` (with `acquire_mmap_lock`) or `pud_free_pmd_page()`, if `arm64_ptdump_lock_key` is enabled, cycle `mmap_read_lock/unlock(&init_mm)` after `__flush_tlb_kernel_pgtable()`. [F227]
- In `mte_restore_tags()`, `copy_highpage()`, and `tag_clear_highpage()`, callers must acquire the per-page/folio lock via `try_page_mte_tagging()` or `folio_try_hugetlb_mte_tagging()` before writing tags and call `set_page_mte_tagged()` or `folio_set_hugetlb_mte_tagged()` (which issue `smp_wmb()` before `set_bit(PG_mte_tagged, ...)` paired with `smp_rmb()` in `page_mte_tagged()` / `folio_test_hugetlb_mte_tagged()`) afterwards. `mte_check_tfsr_exit()` must execute `dsb(nsh); isb()` before `mte_check_tfsr_el1()`. [F17, F19, F182]
- `preempt_count_set()`, `__preempt_count_add()`, `__preempt_count_sub()`, and `__preempt_count_dec_and_test()` must write only the 32-bit `ti->preempt.count` field to preserve sibling `ti->preempt.need_resched`, and `__preempt_count_dec_and_test()` must reload `!READ_ONCE(ti->preempt_count)` after writing `--pc` in case an interrupt cleared `need_resched`. [F27, F63]

## Object Lifetimes

- Transitions of `TTBR0_EL1` and `TCR_EL1.T0SZ` in `cpu_uninstall_idmap()`, `cpu_install_idmap()`, and `cpu_install_ttbr0()` must install `reserved_pg_dir` via `cpu_set_reserved_ttbr0()`, call `local_flush_tlb_all()`, and update `TCR_EL1.T0SZ` before installing the new `TTBR0_EL1`. [F5]
- `pgd_alloc()` and `pgd_free()` must use matching allocators gated by `pgdir_is_page_size()` (`__pgd_alloc`/`__pgd_free` vs `pgd_cache` created with size and alignment `PGD_SIZE` in `pgtable_cache_init()`). When `CONFIG_PGTABLE_LEVELS > 3`, `pud_free()` must return without calling `__pud_free()` when `!pgtable_l4_enabled()`. [F4, F169, F249]
- In `mte_save_tags()`, after `xa_store(&mte_pages, ...)`, free `tag_storage` if `xa_is_err(ret)` or free any non-NULL displaced `ret` via `mte_free_tag_storage()`. `mte_restore_tags()` must only `xa_load()` without erasing or freeing; tags are freed only in `mte_invalidate_tags*()` (`mte_invalidate_tags_area()` must pass inclusive max `swp_entry(type + 1, 0).val - 1` to `xas_for_each()`). In `arch_prepare_to_swap()`, unwind on failure with `while (i--) __mte_invalidate_tags(folio_page(folio, i))`. [F158, F159, F160, F245]

## API Contracts

- Under `CONFIG_ARM64_CONTPTE`, all public PTE accessors/mutators except `ptep_get_lockless()` require holding the PTL; `ptep_get()` can return `PTE_CONT`, so public setters (`set_pte`, `set_ptes`, `ptep_set_access_flags`) must strip it via `pte_mknoncont()`, while `PTE_CONT`-aware callers (hugetlb, kernel mappers) must call `__set_ptes`/`__ptep_get`. [F24, F45]
- `contpte_set_ptes()` requires `nr > 1`, `__contpte_try_fold/unfold()` and `contpte_set_ptes()` require `mm_is_user(mm)`, and `__contpte_try_fold()` requires `pte_valid(pte) && !pte_special(pte)` with a single folio spanning `CONT_PTE_SIZE`. [F197, F198, F320]
- Because `huge_pte_alloc()` and `huge_pte_offset()` return `pud_t *`/`pmd_t *` cast to `pte_t *`, HugeTLB helpers in `arch/arm64/mm/hugetlbpage.c` (`set_huge_pte_at`, `huge_pte_clear`, `huge_ptep_get_and_clear`) must derive `ncontig` and `pgsize` from `sz` via `num_contig_ptes(sz, &pgsize)` (never from `pte_cont(pte)`) and use `__set_ptes_anysz()` and `__ptep_get_and_clear_anysz()`. [F195, F278]
- `set_page_mte_tagged()`, `page_mte_tagged()`, and `try_page_mte_tagging()` require a non-hugetlb page (`!folio_test_hugetlb(page_folio(page))`), whereas hugetlb folios must use `folio_*_hugetlb_mte_tagged/tagging()`; in `copy_highpage()`, when `folio_test_hugetlb(src)` is true, MTE handling must stay within the hugetlb branch and never fall through to `page_mte_tagged()`. [F48, F317]
- `__TLBI_VADDR(addr, asid)` takes an unshifted virtual address and `__tlbi_level()` accepts `level` in `0..3`, whereas `__TLBI_VADDR_RANGE(baddr, asid, scale, num, ttl)` requires a pre-shifted `baddr` (`addr >> 16` when LPA2 is enabled, else `addr >> PAGE_SHIFT`) and `ttl` in `1..3`. Callers of `__flush_tlb_range_op()` must bound `pages <= MAX_TLBI_RANGE_PAGES`. [F40, F96]
- `*_offset_kimg()` helpers use `__phys_to_kimg()` and must only be used on static kernel-image tables. `__pa_symbol()` requires `[KERNEL_START, KERNEL_END]`, whereas `virt_to_phys()` requires `__is_lm_address(__tag_reset(x))`. `early_fixmap_init*()` must populate `bm_pud`/`bm_pmd`/`bm_pte` using `__p*d_populate()` with `__pa_symbol()`. `__set_fixmap()` requires `idx` in `(FIX_HOLE, __end_of_fixed_addresses)` and may run in hardirq context (must not sleep or IPI). `__create_pgd_mapping_locked()` requires `((phys ^ virt) & ~PAGE_MASK) == 0`. [F43, F202, F203, F205, F236, F307]

## Error Handling

- `__pgd_pgtable_alloc()` and `try_pgd_pgtable_alloc_init_mm()` return `INVALID_PHYS_ADDR` (`-1ULL`) rather than `0` on failure, so callers (`split_pmd()`, `split_pud()`) must check `pa == INVALID_PHYS_ADDR`. When `pud_free_pmd_page()` iterates over an unlinked PUD table, it must check `pmd_present(pmdp_get(pmdp))` before calling `__pmd_free_pte_page()`. In `arch_add_memory()`, if `__add_pages()` fails after `__create_pgd_mapping()`, roll back with `__remove_pgd_mapping()`. [F167, F187, F193]

## External Contracts

- In `asm/uaccess.h`, `access_ok()` must untag the pointer via `untagged_addr()` when `CONFIG_ARM64_TAGGED_ADDR_ABI` is enabled and `current` has `PF_KTHREAD` or `TIF_TAGGED_ADDR` set, and all uaccess primitives must sanitize the pointer via `uaccess_mask_ptr()` / `__uaccess_mask_ptr()` before dereferencing. [F69, F149]

## Known Pitfalls

- When advancing a PTE across consecutive physical pages (as in `__set_ptes_anysz()`), use `pte_advance_pfn()` rather than adding `PAGE_SIZE` to `pte_val(pte)`, because 52-bit OAs split high bits into `PTE_ADDR_HIGH`. In `pfn_pte/pmd/pud()`, cast `pfn` to `phys_addr_t` before `<< PAGE_SHIFT`; in `pfn_is_map_memory()`, verify `PHYS_PFN(PFN_PHYS(pfn)) == pfn` before `memblock_is_map_memory()`. In `pte/pmd_cont_addr_end()`, compare `(__boundary - 1 < (end) - 1)` to handle wraparound to `0`. [F68, F94, F101, F271]
- `__TLBI_RANGE_NUM(pages, scale)` must clamp `pages` to `__TLBI_RANGE_PAGES(31, scale)` before shifting and returns a signed `int` in `[-1, 31]` (callers must check `num >= 0`). `__TLBI_VADDR()` and `__TLBI_RANGE_PAGES()` must cast to `unsigned long` before shifting. `__flush_tlb_range_op()` must copy `start` and `pages` into local variables before mutating them, and non-range flushes must `continue` before `scale` is decremented from 3 down to 0. [F41, F58, F66, F87, F95]
- In `sysreg_clear_set*()`, cast `clear` to `u64` before negation (`~(u64)(clear)`). In `__raw_get/put_user()` and `__get/__put_kernel_nofault()`, evaluate macro arguments outside the `uaccess_ttbr0_enable()` / `__mte_enable_tco_async()` region and disable TTBR0/TCO on both normal and fault paths. `is_write_abort()` must check `(esr & ESR_ELx_WNR) && !(esr & ESR_ELx_CM)` so EL0 cache maintenance faults are not treated as writes. [F90, F93, F253]
