# config-riscv

This unit implements core parts of the GCC RISC-V backend, including RISC-V Vector ('V' extension) RTL expansion and constant synthesis (`riscv-v.cc`), inline string/memory expansion (`riscv-string.cc`), RTL optimization passes for AVL propagation (`riscv-avlprop.cc`), memory reference shortening (`riscv-shorten-memrefs.cc`), and `-msave-restore` cleanup (`riscv-sr.cc`), as well as built-in functions (`riscv-builtins.cc`), C/D front-end hooks (`riscv-c.cc`, `riscv-d.cc`), target attribute parsing (`riscv-target-attr.cc`), and mode, core, option, and subset definitions.

## Architecture & Data Flow

- In `insn_expander::emit_insn`, `m_opno` indexes destination pattern operands in `m_ops` (including synthesized mask, `RVV_VUNDEF` merge, VL, policy, `avl_type`, and rounding-mode operands) while `opno` indexes only caller-supplied `ops[]`; `insn_data[(int) icode].operand` lookups must use `m_opno` rather than `opno`. [F2]
- In `expand_load_store`, `expand_strided_load`, `expand_gather_scatter`, and `expand_lanes_load_store`, masked load patterns place a `maskload_else_operand` before the length operand that store patterns omit, so load expansion must advance the `ops` index by one past the else operand before reading `len`. [F1]
- In `riscv_expand_builtin_direct`, `opno` tracks the destination slot in `ops[]` (incremented before the argument loop only when `has_target_p` is true) separately from the call argument index `argno`, so `CALL_EXPR` arguments must be read at `argno` and written at `ops[opno++]`, passing `opno` as `n_ops` to `riscv_expand_builtin_insn`. [F3]
- During `lra_in_progress`, `legitimize_move` must emit `gen_mov_lra (mode, Pmode, dest, src)` for VLS modes with `GET_MODE_NUNITS (mode).to_constant () > 31`, fractional-LMUL VLA modes (`known_lt (GET_MODE_SIZE (mode), BYTES_PER_RISCV_VECTOR)`), and `MODE_VECTOR_BOOL` modes so expansion is deferred until after LRA. [F41]
- When `lra_in_progress` is true, `expand_const_vector` must emit predicated RVV instructions directly via `emit_vlmax_insn` (`code_for_pred_broadcast` or `code_for_pred_scalar`) instead of calling `vec_duplicate_optab`, `expand_vector_broadcast`, or `expand_simple_binop`, which require new VL pseudos. [F40]
- When `!can_create_pseudo_p ()`, `can_be_broadcasted_p` must reject non-float operands with `maybe_gt (GET_MODE_SIZE (mode), GET_MODE_SIZE (Pmode))` unless `satisfies_constraint_Wdm (op)` holds, preventing RA reload from generating `(vec_duplicate:DI reg)` on RV32 while allowing memory broadcasts. [F39]
- In `expand_const_vector`, packing two interleaved stepped series into `new_smode` and combining them with `IOR` requires `known_ge (step1, 0) && known_ge (step2, 0)`, a constant `step1`, and `((base1_val + (elem_count - 1) * step1_val) >> builder.inner_bits_size ()) == 0`, falling back to `code_for_pred_merge` otherwise. [F42]
- `rvv_builder::get_merge_scalar_mask` must bound the repeated scalar bitmask width by `elen = TARGET_VECTOR_ELEN_64 ? 64 : 32` rather than `BITS_PER_WORD` (`XLEN`), because the maximum broadcast width of `vmv.v.x` and `vmv.s.x` is determined by `ELEN` (32 on `-march=rv64..._zve32*`). [F43]
- In `prepare_ternary_operands`, if the merge operand `ops[5]` is not `RVV_VUNDEF (mode)` and is distinct from `ops[2]`, `ops[3]`, and `ops[4]`, `ops[5]` and `ops[4]` must be pre-merged into `ops[0]` with `ops[5] = ops[4] = ops[0]` before emitting the ternary instruction. [F55]
- In `expand_reduction`, when `need_mask_operand_p (insn_flags)` is true and `vl_op` is neither `CONST_INT_P` nor `CONST_POLY_INT_P` (`need_vl0_safe`), `init` must be broadcast into `m1_tmp` with length `const1_rtx` (not `vl_op`) and reduced with `unspec_for_vl0_safe`. [F54]
- When copying register-to-register tuple modes (`REG_P (ops[0]) && REG_P (ops[1])`), `expand_tuple_move` must copy subparts in descending order (`index = nf - 1 - i`) when `REGNO (ops[0]) > REGNO (ops[1])` and ascending order (`index = i`) otherwise. [F56]
- In `expand_vec_cmp_float`, unordered comparisons (`UNEQ`, `ORDERED`, `UNORDERED`, `UNLT`, `UNLE`, `UNGT`, `UNGE`) must mask out NaNs using `EQ` before any signaling comparison; when `HONOR_SNANS (data_mode)` is true, `op1 == op1` must be evaluated unmasked and combined with `AND`. [F58]
- `expand_vec_nearbyint` must save and restore FP exception flags around `emit_vec_cvt_x_f` and `emit_vec_cvt_f_x` via `gen_riscv_frflags`/`gen_riscv_fsflags` (whereas `expand_vec_rint` must not), while masking conversions to `|x| < get_fp_rounding_coefficient` and restoring sign via `emit_vec_copysign`. [F59]
- When converting `HFmode` vectors to `DImode` (`maybe_eq (vec_fp_size * 4, vec_int_size)`), `emit_vec_rounding_to_integer` must first widen `HF -> SF` via `emit_vec_widen_cvt_f_f` with `UNARY_OP` (no rounding mode) before converting `SF -> DI` via `emit_vec_widen_cvt_x_f` with the requested rounding `type`. [F60]
- `riscv_vector::expand_vec_perm_const` must return false when `vmode` has class `MODE_VECTOR_BOOL`, and `shuffle_generic_patterns` must return false when `d->perm.encoding ().npatterns ()` is not a power of two. [F33]
- `riscv_vector::gather_scatter_valid_offset_p` must return false when the offset element size is smaller than `UNITS_PER_WORD` and no RVV vector mode exists with inner mode `Pmode` and `GET_MODE_NUNITS (mode)` elements. [F36]
- `vls_mode_valid_p` must reject non-mask VLS modes when `rvv_vector_bits == RVV_VECTOR_BITS_SCALABLE` and `!ordered_p (TARGET_MAX_LMUL * BITS_PER_RISCV_VECTOR, GET_MODE_PRECISION (vls_mode))`, and when `RVV_VECTOR_BITS_ZVL` requires `GET_MODE_PRECISION (vls_mode) < TARGET_MIN_VLEN / (64 / precision)`. [F44]
- In `riscv-modes.def`, every fixed-length and scalable `VECTOR_BOOL_MODE` must have its precision set via `ADJUST_PRECISION` to 1 bit per boolean element (matching `NUNITS`), and `MAX_BITSIZE_MODE_ANY_MODE` must not exceed `4096 * 8`. [F37]
- In `riscv_vector::estimated_poly_value`, when `BITS_PER_RISCV_VECTOR` is not constant (`RVV_VECTOR_BITS_SCALABLE`), `POLY_VALUE_LIKELY` must return the same conservative base estimate (`val.coeffs[0]`) as `POLY_VALUE_MIN` rather than scaling `val.coeffs[1]`. [F35]
- In `pass_avlprop`, `avl_can_be_propagated_p` must reject `TYPE_VGATHER`, `TYPE_VSLIDEDOWN`, `TYPE_VISLIDE1DOWN`, `TYPE_VFSLIDE1DOWN`, and `TYPE_VCOMPRESS` instructions because their RVV semantics can read source elements at indices >= AVL. [F27]
- `pass_avlprop::get_vlmax_ta_preferred_avl` must abort AVL propagation for a candidate instruction if any non-debug use references the defined register in its merge operand (`merge_op_idx`) without satisfying constraint `'vu'` and the use instruction is not `tail_agnostic_p`. [F28]
- When propagating a register AVL (`REG_P`) from `use_insn` to `insn` in `pass_avlprop::get_vlmax_ta_preferred_avl`, the AVL register must have the exact same real RTL-SSA definition (`def1 == def2 && def1->insn ()->is_real ()`) reaching both instructions and dominating `insn`. [F29]
- In `riscv_vector::expand_block_move`, `movmem_p` (potentially overlapping `memmove`) must be rejected when `info.need_loop` is true, and unpredicated `emit_move_insn` may only be emitted when `!info.need_loop && known_eq (GET_MODE_SIZE (info.vmode), INTVAL (length_in))`. [F48]
- In `riscv-string.cc`, sub-word loads in `do_load` and final byte loads in `expand_vec_cmpmem` must zero-extend (`do_zero_extendqi2`, `do_zero_extendhi2`, or `gen_zero_extendsidi2` on `TARGET_64BIT`) into the destination register before subtraction. [F51]
- `pass_shorten_memrefs` must skip basic blocks where `optimize_bb_for_speed_p (bb)` is true, ignore store-zero instructions (`CONST0_RTX`), only rewrite base registers referenced at least 4 times in the block, and call `df_insn_rescan (insn)` on each modified instruction. [F31]
- `riscv_remove_unneeded_save_restore_calls` must bail out if `known_ne (crtl->args.size, 0)`, if any non-call instruction uses a callee-saved register (`!call_used_regs[DF_REF_REGNO (use)]`), if `epilogue_count != 1` or `call_count > 1`, or if a register call target fails `SIBCALL_REG_P (REGNO (target))`. [F50]
- `riscv_option_valid_attribute_p` and `riscv_option_valid_version_attribute_p` must save `global_options` on entry, initialize `global_options` from `DECL_FUNCTION_SPECIFIC_TARGET (fndecl)` if present or from the default/current target option node before parsing, and restore `global_options` before returning. [F63]
- In `riscv_target_attr_parser`, `handle_cpu` only initializes `m_subset_list` from `cpu_info->arch` when `m_subset_list` is `nullptr`, whereas `parse_arch` always replaces any existing `m_subset_list` (initializing relative `+ext` lists by parsing `global_options.x_riscv_arch_string` or cloning `riscv_cmdline_subset_list ()`, never mutating the command-line list in place). [F25, F61]
- In `riscv_pragma_intrinsic`, after temporarily enabling vector flags via `riscv_pragma_intrinsic_flags_pollute` to register RVV builtins and pragma state, the original flags must be restored via `riscv_pragma_intrinsic_flags_restore` followed by `riscv_option_override` and `init_adjust_machine_modes`. [F21]
- Before formatting `__riscv_<ext>` predefined macros with `sprintf`, `riscv_cpu_cpp_builtins` must compute the maximum `subset->name.length ()` across `subset_list` and allocate `buf` to at least `max_ext_len + 10` bytes to fit `"__riscv_"` and the null terminator. [F6]

## Object Lifetimes

- `pass_avlprop` is a persistent pass object reused across functions; `pass_avlprop::avlprop_done` must call `m_candidates.release ()`, free `CDI_DOMINATORS` dominance info, call `cleanup_cfg (0)` if `crtl->ssa->perform_pending_updates ()` returns true, and delete and null out `crtl->ssa` and `m_avl_propagations`. [F14, F30]
- Per-function target architecture state in `riscv-target-attr.cc` must be persisted in `DECL_FUNCTION_SPECIFIC_TARGET (fndecl)` (including `x_riscv_arch_string` in `riscv_target_attr_parser::update_settings`) rather than in a side table keyed by raw `tree` `fndecl` pointers. [F62]
- Before replacing `opts->x_riscv_arch_string` with `xstrdup (local_arch_str)`, `riscv_target_attr_parser::update_settings` must guard `free (opts->x_riscv_arch_string)` with `opts->x_riscv_arch_string != default_opts->x_riscv_arch_string` where `default_opts` is `TREE_TARGET_OPTION (target_option_default_node)`. [F16]
- `riscv_target_attr_parser::parse_arch`, `riscv_process_one_target_attr`, and `riscv_process_target_attr` must allocate mutable attribute string buffers on the heap sized to `strlen(...) + 1` via `std::unique_ptr<char[]>` (never freeing the mutated `str_to_check` pointer advanced by `strtok_r` or using fixed/stack buffers). [F7, F17]
- `pass_shorten_memrefs::analyze` must call `regstat_free_n_sets_and_refs ()` before returning the GGC-allocated `regno_map` so the `regstat_n_sets_and_refs` table initialized by `regstat_init_n_sets_and_refs ()` is released on every basic-block iteration. [F18]
- `RVV_VLMAX` and `RVV_VUNDEF` in `riscv-protos.h` must reference the shared `regno_reg_rtx[X0_REGNUM]` RTX singleton rather than allocating via `gen_rtx_REG (..., X0_REGNUM)` on each call. [F65]

## API Contracts

- In `riscv_vector::expand_vec_perm_const`, when `target` is `NULL_RTX` (`d.testing_p` is true), `expand_vec_perm_const_1` and all `shuffle_*_patterns` helpers must not emit any RTL instructions into the instruction stream before returning. [F32]
- `riscv_resolve_overloaded_builtin` must substitute a non-null empty `vec<tree, va_gc>` pointer when `uncast_arglist` is `NULL` before calling `riscv_vector::resolve_overloaded_builtin` or `build_function_call_vec`, and must return `NULL_TREE` without building a call when `new_fndecl` is `NULL_TREE`. [F23]
- `riscv_builtin_decl` must return `error_mark_node` when the `RISCV_BUILTIN_GENERAL` subcode is `>= ARRAY_SIZE (riscv_builtins)` or when `(code & RISCV_BUILTIN_CLASS)` is not a recognized builtin class. [F26]
- `cpu_vector_cost` in `riscv-protos.h` must provide separate `common_vector_cost` (`vls`), `scalable_vector_cost` (`vla`), and `regmove_vector_cost` (`regmove` with `GR2VR`, `FR2VR`, `VR2GR`, `VR2FR`) tables, and `autovectorize_vector_modes` must return `VECT_COMPARE_COSTS`. [F34]
- Dynamic stack allocations in RISC-V host code (such as `alloca` and `XALLOCAVEC` in `riscv_cpu_cpp_builtins` and `riscv_block_move_straight`) must rely on `"system.h"` and `"libiberty.h"` rather than including non-portable `<alloca.h>` or `<malloc.h>`. [F13]

## Error Handling

- In `riscv_target_attr_parser::parse_arch`, entry must delete any non-null `m_subset_list` before reassigning it, and any error after allocating or cloning `m_subset_list` must jump to the `fail` label to delete `m_subset_list` and reset it to `nullptr`. [F15]
- When `maybe_expand_insn` fails in `riscv_expand_builtin_insn`, it must emit an error and still return a valid fallback rtx (`gen_reg_rtx (ops[0].mode)` when `has_target_p` is true, or `const0_rtx` otherwise) rather than returning `NULL_RTX`. [F22]
- `riscv_process_target_attr` and `riscv_process_target_version_attr` must unwrap `TREE_LIST` nodes and verify that the argument tree is a non-null `STRING_CST` before reading `TREE_STRING_POINTER (args)`. [F24]

## External Contracts

- In `riscv_target_attr_parser::parse_arch`, full `arch=rv...` strings starting with `"rv"` must be rejected if `TARGET_64BIT` is true and the string starts with `"rv32"`, or if `!TARGET_64BIT` and it starts with `"rv64"`, before calling `riscv_subset_list::parse`. [F49]
- `riscv_cpu_cpp_builtins` in `riscv-c.cc` must define exactly one of `__riscv_misaligned_avoid`, `__riscv_misaligned_slow`, or `__riscv_misaligned_fast` (with value 1), using the `misaligned` spelling required by the RISC-V C API specification rather than `unaligned`. [F66]

## Known Pitfalls

- In `riscv_block_move_straight`, the temporary register array `regs` is allocated with `length / delta - 1` elements when `2 * delta <= length`, so the load and store loops must keep the upper bound `offset + 2 * delta <= length` and leave the final `delta..2*delta - 1` bytes to `move_by_pieces`. [F5]
- In `simplify_replace_avl`, when replacing the AVL operand of a fault-only-first load (`TYPE_VLDFF` or `TYPE_VLSEGDFF`), the entire pattern must be regenerated with `gen_pred_fault_load (..., get_avl_type_rtx (avl_type::NONVLMAX))` rather than relying on `simplify_replace_rtx`. [F46]
- C++ standard library selector macros (`INCLUDE_STRING`, `INCLUDE_VECTOR`, `INCLUDE_MAP`, `INCLUDE_ALGORITHM`, `INCLUDE_FUNCTIONAL`, `INCLUDE_ARRAY`) must be defined before `#include "system.h"` (and never included directly after `"system.h"`), and any unit including `"riscv-subset.h"` or using `std::string` APIs in `"riscv-protos.h"` must define `INCLUDE_STRING` before `"system.h"`. [F9, F10]
- Because `"riscv-protos.h"` guards `rtx_code`-taking declarations (such as `riscv_emit_binary`, `riscv_expand_int_scc`, `riscv_vector::expand_vec_cmp`, and `th_mempair_output_move`) with `#ifdef RTX_CODE` inside `GCC_RISCV_PROTOS_H`, any file calling them must include `"rtl.h"` before `"tm_p.h"` or `"riscv-protos.h"`. [F11]
