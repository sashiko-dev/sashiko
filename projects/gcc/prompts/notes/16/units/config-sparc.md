# config-sparc

The `config-sparc` unit (`gcc/config/sparc/`) implements the GCC backend for SPARC, including OS target headers, C/D front-end hooks, native CPU detection, RTL machine descriptions (`sparc.md`, `sync.md`, `constraints.md`, `predicates.md`), VIS intrinsics (`visintrin.h`), and C++ backend logic (`sparc.cc`).

## Architecture & Data Flow

- `tm_file` and header ordering: `sparc/biarch64.h` (`SPARC_BI_ARCH`) must precede `sparc.h`, `linux64.h`, and `netbsd-elf.h`; `sparc/default64.h` (`TARGET_64BIT_DEFAULT`) must precede `linux64.h` and `sol2.h` (with `TARGET_DEFAULT` before `#if DEFAULT_ARCH32_P`); `sparc/openbsd1-64.h` (`OBSD_HAS_DECLARE_*`) must precede `openbsd.h`; `sparc/sysv4.h` must follow `elfos.h` (leaving `SET_ASM_OP` undefined); `sparc/vxworks.h` must follow `sparc.h`, `sysv4.h`, and `vxworks.h`. In `sparc.h`, include `config/vxworks-dummy.h` before `PIC_OFFSET_TABLE_REGNUM`. D hooks (`TARGET_D_CPU_VERSIONS`, `TARGET_D_REGISTER_CPU_TARGET_INFO`) and prototypes must live in `sparc-d.h` (`tm_d.h`), not `sparc.h`/`sparc-protos.h`. [F5, F6, F7, F8, F89, F90, F91]
- CPU tables and specs: `enum sparc_processor_type` in `sparc-opts.h` (before `PROCESSOR_NATIVE`) must match the `cpu` attribute order in `sparc.md` and `cpu_table` in `sparc_option_override`. Every `TARGET_CPU_*` assignable to `TARGET_CPU_DEFAULT` must have a `#if TARGET_CPU_DEFAULT == ...` branch in `sparc.h` defining `CPP_CPU32_DEFAULT_SPEC` and `CPP_CPU64_DEFAULT_SPEC`. In `OPTION_DEFAULT_SPECS` (`linux64.h`, `sol2.h`), `"cpu_32"`/`"cpu_64"` must precede `"cpu"` (guarded by `%{!m64:...}` or `%{!m32:...}`), and `"tune_32"`/`"tune_64"` must precede `"tune"`. [F1, F30, F92]
- GNU-ld ELF subtarget headers (`freebsd.h`, `linux.h`, `linux64.h`, `netbsd-elf.h`, `sp-elf.h`, and `sol2.h` under `USE_GLD`) must `#undef CTORS_SECTION_ASM_OP` and `#undef DTORS_SECTION_ASM_OP` so `attribute((init_priority))` uses named priority sections. [F14]
- VIS versioning: `sparc_target_macros` (`sparc-c.cc`) must test `TARGET_VIS4B`, `TARGET_VIS4`, `TARGET_VIS3B`, `TARGET_VIS3`, `TARGET_VIS2`, and `TARGET_VIS` in descending `if`/`else if` order. OSA2011 SIMD builtins (`__builtin_vis_fpadd64`, `__builtin_vis_fpsub64`, `__builtin_vis_fucmp{le,ne,gt,eq}8`) and patterns (`vec_cmp*`, `vec_cmpu*`, `vcond_mask_*`, `fp<plusminus_insn>64_vis`, `fpcmpu*`, and `V8QImode` `EQ`/`NE` in `fpcmp*`) must require `TARGET_VIS3B` (or `TARGET_VIS4`), not `TARGET_VIS3`. `sparc_option_override` must clear all `MASK_VIS*`, `MASK_FMAF`, and `MASK_FSMULD` when `!TARGET_FPU`. [F26, F74, F108]
- Constraints and predicates: in `constraints.md`, register constraints (`b`, `c`, `d`, `e`, `f`, `h`) must use `define_register_constraint`, and 8-byte-aligned 32-bit memory constraint `"T"` (`memory_ok_for_ldd`) must use `define_special_memory_constraint`. In `predicates.md`, `input_operand` must reject non-`VOIDmode` mode mismatches, unwrap `SUBREG` before checking `MEM`, and accept any `MEM` when `lra_in_progress`; `arith_double_add_operand` must only accept `const_4096_operand` when `TARGET_ARCH64`. [F15, F16, F18, F19]
- Condition codes: `icc_comparison_operator` must restrict `CCNZmode`/`CCXNZmode` to `nz_comparison_operator`, `CCCmode`/`CCXCmode` to `c_comparison_operator`, and `CCVmode`/`CCXVmode` to `v_comparison_operator`. `select_cc_mode` must return `CCFPEmode` for `LT`, `LE`, `GT`, `GE`, `LTGT` and `CCFPmode` for `EQ`, `NE`, `UNORDERED`, `ORDERED`, `UN*`. `REVERSIBLE_CC_MODE` is false for `CCFPmode`/`CCFPEmode`; `ctrapsi4`/`ctrapdi4` must `FAIL` unless `gen_compare_reg` returns `CCmode`/`CCXmode`; `output_cbranch` and `sparc_expand_conditional_move` must use `reverse_condition_maybe_unordered` on FP comparisons. [F20, F78, F79, F113]
- Registers and classes: hard-register tables (`FIXED_REGISTERS`, `CALL_REALLY_USED_REGISTERS`, `REGISTER_NAMES`) must include all 32 upper V9 FP indices (`64..95`). In `enum reg_class`, `FPCC_REGS` must precede `GENERAL_REGS` and `FP_REGS`, and `GENERAL_OR_EXTRA_FP_REGS` must include all general and all 64 V9 FP registers. Under `TARGET_V9`, `sparc_modes_tieable_p` must return `false` when tying a 4-byte `MODE_FLOAT`/`MODE_VECTOR_INT` mode with a mode `> 4` bytes. [F58, F83, F100]
- Register zeroing, renaming, and globals: `sparc_zero_call_used_regs` must skip `CC` regs (`regno >= SPARC_FCC_REG`), FP regs when `!TARGET_VIS`, and odd upper V9 FP regs (`regno >= SPARC_FIRST_V9_FP_REG && (regno & 1)`), zeroing lower FP regs in `SFmode` and even upper V9 FP regs in `DFmode` via `gen_raw_REG`. `HARD_REGNO_RENAME_OK` must reject `FROM == 1` (`%g1`) and `STATIC_CHAIN_REGNUM` must not be 1. In `ASM_DECLARE_REGISTER_GLOBAL`, bound `reg < 8`, set `sparc_hard_reg_printed[reg] = 1`, and format `reg != REGNO` as `.gnu.part%d.%s` with offset `reg - (REGNO)`. [F77, F82, F106]
- Splits and peepholes: `sparc_split_reg_mem`, `sparc_split_reg_reg`, and post-reload `sparc.md` splitters (`TImode`, `TFmode`, `!TARGET_V9` `DFmode` moves/neg/abs) must check `reg_overlap_mentioned_p` between `high_part`/`dest1` and `word1`/`src2`, emitting `low_part`/`dest2` first on overlap. `registers_ok_for_ldd_peep` requires non-`SUBREG` consecutive hard regs starting at an even non-V9-int reg; `mems_ok_for_ldd_peep` requires non-volatile 64-bit-aligned `MEM`s with `offset1 % 8 == 0`, `offset2 == offset1 + 4`, and `reg1 != REGNO (dependent_reg_rtx)`. Move+compare `define_peephole2` patterns (`*cmp_cc_set`, `*cmp_ccx_set64`) require `!SPARC_FP_REG_P` on both operands. [F65, F76, F107, F111]
- Addressing and 64-bit checks: `sparc_legitimate_address_p` must reject `REG + REG` for `TImode`, `TFmode` (unless `TARGET_ARCH64 && TARGET_HARD_QUAD`), and unoptimized 32-bit `DFmode`/`DImode`, and bound `REG + CONST_INT` by `0x1000 - GET_MODE_SIZE (MODE)`. In `sparc_legitimize_tls_address`, TLS `sethi`/`or` pseudos must use `Pmode` (not `SImode`). In `sparc_check_64`, backward scanning may only cross `CODE_LABEL`/`CALL_INSN` when `flag_expensive_optimizations && df && DF_REG_DEF_COUNT (REGNO (y)) == 1`, returning `0` on overlapping writes; `output_v8plus_shift` and `output_v8plus_mult` must emit `srl %L1, 0, %L1` (or `%L2`) before `or` whenever `sparc_check_64 <= 0`. [F61, F62, F64, F68]
- Stack, prologue, and epilogue: `STACK_ADDRESS_OFFSET` must equal `STACK_POINTER_OFFSET` (`FIRST_PARM_OFFSET(0) + SPARC_STACK_BIAS`). Prologue and epilogue expanders (`sparc_expand_*`, `sparc_flat_expand_*`) must emit `gen_frame_blockage ()` after `%sp` frame setup and before frame destruction. `emit_save_or_restore_regs` requires even-aligned `low` and `high` when `!(TARGET_ARCH64 && high <= 32)`. `epilogue_renumber` (`test == 0`) must use `gen_raw_REG` and preserve `ORIGINAL_REGNO` when rewriting regs `24..31`, and reject `%fp` + offset `< SPARC_STACK_BIAS` or `MEM (%fp)` when `SPARC_STACK_BIAS != 0`. [F33, F71, F75, F105]
- ABI and va_arg: in `function_arg_record_value`, `assign_int_registers`, and `assign_fp_registers`, when `data.stack` is true, index 0 of `data.ret` is a `NULL_RTX` `EXPR_LIST`, so registers go at `XVECEXP (data->ret, 0, data->stack + data->nregs)`. In `sparc_struct_value_rtx` and `print_operand` `')'`, 32-bit `unimp` handling must verify the return/result size tree is a non-null `INTEGER_CST`. In `untyped_call`/`untyped_return`, save/restore `%f0` at offset 8 in `TARGET_ARCH64 ? TFmode : DFmode`. In `sparc_gimplify_va_arg`, gimplify `incr` before deriving `addr` and updating `valist` in `post_p`, and set `TREE_ADDRESSABLE (tmp) = 1` on over-aligned temporaries. [F31, F46, F47, F85]
- Builtins and FENV: in `sparc_expand_builtin`, `op[0]` is target (or `NULL_RTX` when `!nonvoid`) and call args start at `op[1]`, while `insn_data[icode].operand` is indexed by `idx = arg_count - !nonvoid`. `sparc_atomic_assign_expand_fenv` must return immediately when `!TARGET_FPU`, set `TREE_ADDRESSABLE = 1` and wrap `create_tmp_var_raw` vars in `TARGET_EXPR` before passing their address to `SPARC_BUILTIN_STFSR`/`LDFSR`, clear `0x1f << 5` and `0x1f << 23` in `*hold`, and shift `%fsr` right by 5 bits before `BUILT_IN_ATOMIC_FERAISEEXCEPT` when `SPARC_LOW_FE_EXCEPT_VALUES` is non-zero. [F32, F50, F80]
- Vectors and instruction patterns: `sparc_get_mask_mode` must always return scalar `Pmode`. In `vector_init_bshuffle`, `vector_init_fpmerge`, and `vector_init_faligndata`, zero-extend `QImode`/`HImode` `elt` via `convert_modes (SImode, ..., elt, true)` into `gen_lowpart (SImode, t1)`. `clzsi2`/`clzsi_v8plus` must clear the upper 32 bits and subtract 32 from `lzd`. Shift-based sub-word extension expanders must unwrap any incoming `SUBREG` and align `SUBREG_BYTE` to word size before `gen_rtx_SUBREG`. In `prefetch_64`/`prefetch_32`, mask `operands[1]` (`0..2`) with `read_or_write & 1`. On `!TARGET_V9`, 32-bit hardware division patterns (`divsi3_sp32`, `*cmp_sdiv_cc_set`, `udivsi3_sp32`, `*cmp_udiv_cc_set`) must emit at least 3 instructions between `wr ..., %y` and `sdiv`/`udiv`. [F52, F63, F97, F102, F110, F112]
- Branches, PIC, costs, and alignment: `sparc_can_follow_jump` must return `false` when `CROSSING_JUMP_P (followee) && !CROSSING_JUMP_P (follower)`, and `output_ubranch` must not use `INSN_ADDRESSES` when `CROSSING_JUMP_P (insn)`. In `tablejump`, `SIGN_EXTEND` `operands[0]` (`CASE_VECTOR_MODE`) to `Pmode` when `flag_pic && CASE_VECTOR_MODE != Pmode`. `sparc_init_pic_reg` must insert and commit PIC init on the entry edge whenever `flag_pic && (crtl->uses_pic_offset_table || optimize)`. In `sparc_rtx_costs` for `MEM` under `ZERO_EXTEND`/`SIGN_EXTEND`, subtract `COSTS_N_INSNS (1)` from `int_zload`/`int_sload`. In `sparc.h`, check `RECORD_OR_UNION_TYPE_P` before `TYPE_FIELDS` in `ROUND_TYPE_ALIGN`, and `TREE_CODE (TYPE) == ARRAY_TYPE` before `TYPE_MODE (TREE_TYPE (TYPE))` in `DATA_ALIGNMENT`/`LOCAL_ALIGNMENT`. [F53, F55, F56, F93, F94, F99]

## Object Lifetimes

- Duplicate stack-allocated symbol names with `ggc_strdup` before `gen_rtx_SYMBOL_REF` (`load_got_register`, `sparc_profile_hook`), and allocate `struct machine_function` via `ggc_cleared_alloc<machine_function>()` in `sparc_init_machine_status`. [F41, F42]

## API Contracts

- Sentinel-terminated tables and D strings: `cpu_names` (`driver-sparc.cc`) must end with `{ NULL, NULL }` outside `#if defined __sun__ && defined __svr4__`; `handlers` in `sparc_d_register_target_info` (`sparc-d.cc`) with `{ NULL, NULL }`; `sparc_option_optimization_table` (`sparc-common.cc`) with `{ OPT_LEVELS_NONE, 0, NULL, 0 }`. In `sparc-d.cc`, `d_target_info_spec` handlers using `build_string_literal` (`sparc_d_handle_target_float_abi`) must pass `strlen (str) + 1`. [F2, F4, F12]
- Guard any inspection of `type` (`TREE_CODE`, `TYPE_ALIGN`, `TREE_ADDRESSABLE`, `VECTOR_TYPE_P`) with `type != NULL_TREE` in `function_arg_slotno`, `sparc_function_arg_1`, `sparc_function_value_1`, and `sparc_pass_by_reference` (libcalls pass `NULL_TREE`). In `predicates.md`, `fp_register_operand` must unwrap `SUBREG` and verify `REG_P (op)` before `REGNO (op)`. [F17, F45]
- Vector comparison and permutation hooks: `vec_cmp<FPCMP:mode><P:mode>` and `vec_cmpu<FPCMP:mode><P:mode>` must use `vec_cmp_operator` / `vec_cmpu_operator` (rejecting non-`EQ`/`NE` for `V8QImode` in `vec_cmp_operator` and for non-`V8QImode` in `vec_cmpu_operator` when `!TARGET_VIS4`, instead of calling `FAIL` in the expander) and swap `LT`/`GE` (`LTU`/`GEU`) operands. `sparc_vectorize_vec_perm_const` must return `GET_MODE_SIZE (vmode) == 8` when `target == NULL_RTX` (under `TARGET_VIS2` and `vmode == op_mode`) and reject modes other than `V8QImode` when `target != NULL_RTX`. Pre-allocate `VECTOR_CST_NELTS (cst0)` elements in `*n_elts` before calling `sparc_handle_vis_mul8x16`. [F21, F40, F73, F98, F109]
- Reload and TFmode: `sparc_secondary_memory_needed` must require secondary memory between `FP_REG_CLASS_P` and non-FP classes whenever `!TARGET_VIS3` or `GET_MODE_SIZE (mode)` is outside `[4, 8]`, and `sparc_secondary_memory_needed_mode` under `TARGET_ARCH64` must widen sub-32-bit modes to 32 bits (not `BITS_PER_WORD`). `sparc_secondary_reload` must return `GENERAL_REGS` for `HImode`/`QImode` reloads between `FP_REG_CLASS_P` and `MEM`/stack pseudos (`true_regnum (x) == -1`), and `FP_REGS` for unaligned 32-bit `DFmode` `MEM` or 32-bit `TARGET_VIS3` integer-reg reloads with `EXTRA_FP_REGS`. `emit_hard_tfmode_operation` must force inputs into registers and route non-register `operands[0]` through a `gen_reg_rtx` pseudo. [F59, F60, F72]
- `sparc.h` must leave `SPARC_LONG_DOUBLE_TYPE_SIZE` undefined for OS headers to define. In `visintrin.h`, every `__vis_*` wrapper must be `extern __inline` with `__gnu_inline__, __always_inline__, __artificial__` inside the matching `__VIS__` guard, using `long` for `TARGET_ARCH64`-dependent `SImode`/`DImode` builtins (`__vis_alignaddr`, `__vis_edge8`) and `__i64` for unconditionally `DImode` builtins (`__vis_pdist`, `__vis_faligndatadi`). [F86, F95, F96]

## Error Handling

- When `sparc_option_override` rejects `-mlong-double-64` with `-m64` or `-fcall-saved-REG` on `call_used_regs[8..15]`, restore `MASK_LONG_DOUBLE_128` or reset `call_used_regs[i] = 1`. In `sparc_expand_builtin`, return `NULL_RTX` on `error_mark_node` args and `const0_rtx` when `check_constant_argument` fails. [F43, F48]

## External Contracts

- Solaris (`sol2.h`) and specs: `ASM_DECLARE_OBJECT_NAME` must use `tree_to_uhwi (DECL_SIZE_UNIT (DECL))`; `TARGET_BUGGY_QP_LIB` and `SPARC_LOW_FE_EXCEPT_VALUES` must be `1`; `GGC_QUIRE_SIZE` must be `510`. Guard `crtfastmath.o%s` with `%{!shared:...}` in `ENDFILE_SPEC`, expand `GNU_USER_TARGET_ENDFILE_SPEC` in `linux.h`/`linux64.h`, and pass `-m32` in `%{mv8plus:...}` in 64-bit-default `CC1_SPEC` (`sol2.h`, `linux64.h`). [F22, F23, F24, F25, F27, F28]
- ABI and libfuncs: `sparc_promote_function_mode` and `sparc_function_value_1` must both promote sub-word `MODE_INT` to `word_mode` (except 32-bit `AGGREGATE_TYPE_P` returns) and pointers to `Pmode`. Under `SUN_V9_ABI_COMPATIBILITY`, `fp_type_for_abi` and `compute_fp_layout` must handle `ARRAY_TYPE` of FP elements. In `emit_soft_tfmode_cvt` (`TARGET_ARCH64`), wrap `SImode` `operands[1]` in `SIGN_EXTEND`/`ZERO_EXTEND` to `DImode` before `emit_soft_tfmode_libcall`. `sparc_init_libfuncs` must clear `SImode` `smul`/`sdiv`/`udiv`/`smod`/`umod` optabs under `TARGET_ARCH64` and only register `_Q_sqrt` under `TARGET_ARCH32` when `TARGET_FPU`. [F66, F67, F69, F70]

## Known Pitfalls

- In `sparc_do_work_around_errata`, the `sparc_fix_ut699` FP errata loop must increment `i` (`++i == n_insns`) on branch instructions so the branch and delay slot count as two instructions. In `sparc_flat_expand_prologue`, keep `size_rtx` initialized to `size_int_rtx` (`GEN_INT (-size)`) across both immediate and `%g1` paths for `frame_pointer_needed`. `HARD_REGNO_CALLER_SAVE_MODE` (`sparc.h`) must preserve a non-`VOIDmode` `MODE` rather than calling `choose_hard_reg_mode`. [F34, F35, F101]
