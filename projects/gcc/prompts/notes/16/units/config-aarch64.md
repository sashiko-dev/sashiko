# config-aarch64

The `config-aarch64` unit implements the AArch64 target backend for GCC, including `targetm` hooks, AAPCS64 and SVE/SME calling conventions, PSTATE.SM/ZA switching, RTL expansion and machine descriptions (AdvSIMD, SVE, atomics, predicates, constraints, iterators), built-in intrinsics, vectorization cost modeling (`aarch64_vector_costs`), Cortex-A57 FMA steering, native CPU detection, and OS/ABI target headers.

## Architecture & Data Flow

- In `aarch64.cc`, `#include "target-def.h"` must follow all `#include`s and precede `#undef`/`#define TARGET_*` overrides. `#ifdef HAVE_AS_TLS` redefining `TARGET_HAVE_TLS` must precede `aarch64_tls_referenced_p` and `aarch64_tls_symbol_p`, whereas `#undef`/`#define TARGET_ASM_FILE_END` must follow `aarch64_asm_file_end ()` so it calls the subtarget hook instead of recursing. [F11, F12, F13]
- In `tm_file`, `aarch64/biarchilp32.h` or `aarch64/biarchlp64.h` must precede `aarch64/aarch64.h` and OS headers; for `aarch64-*-mingw*`, `aarch64/cygming.h` must precede `mingw/mingw32.h`, which tests `#if HAVE_64BIT_POINTERS` and `#if DWARF2_UNWIND_INFO` at preprocessing time. [F104, F106]
- In `aarch64_option_valid_attribute_p`, if `DECL_FUNCTION_SPECIFIC_TARGET (fndecl)` is null and `args == current_target_pragma`, assign `target_option_current_node` and return `true` without re-parsing; when processing a `target` attribute on a `fndecl` that already has `target_version` in `DECL_ATTRIBUTES (fndecl)`, reapply `aarch64_process_target_version_attr` before building `DECL_FUNCTION_SPECIFIC_TARGET`. [F7, F28]
- When merging duplicate `arm::` state-string attributes in `aarch64_merge_string_arguments`, `handle_arm_new` (`FUNCTION_DECL`) passes `can_merge_in_place = true`, whereas `handle_arm_shared` (function type) must pass `false` because `tree` types are shared. [F27]
- AArch64 `BUILT_IN_MD` codes pack `aarch64_builtin_class` in the low `AARCH64_BUILTIN_SHIFT` bits and the subcode above; `aarch64_general_builtin_decl` and `aarch64_general_check_builtin_call` require the right-shifted subcode, not raw `DECL_MD_FUNCTION_CODE`. [F74]
- Identity checks against `aarch64_mfp8_type_node`, `aarch64_fp16_type_node`, and `float16_type_node` must compare `TYPE_MAIN_VARIANT (type)`. In `aarch64_function_arg_alignment`, strip variants with `TYPE_MAIN_VARIANT (type)` and for `ENUMERAL_TYPE` with non-null `TREE_TYPE (type)` resolve `TYPE_MAIN_VARIANT (TREE_TYPE (type))` before asserting `!TYPE_USER_ALIGN (type)` and reading `TYPE_ALIGN (type)`. [F17, F22]
- In `aarch64_gimplify_va_arg_expr`, every reuse of `valist`, `f_off`, `stack`, and `on_stack` across constructed `tree` expressions (including `COND_EXPR_THEN`) must be wrapped in `unshare_expr`. [F29]
- In `aarch64_sme_mode_switch_regs::add_reg`, `end_regno` is `regno + 1` for single-register modes, and `end_regno > regno + 1` is only allowed when `aarch64_classify_vector_mode (mode)` has `VEC_STRUCT`. In `pass_switch_pstate_sm::execute`, every block modified by `aarch64_switch_pstate_sm_for_landing_pad`, `aarch64_switch_pstate_sm_for_call`, or `aarch64_switch_pstate_sm_for_jump` must be set in `blocks` before `find_many_sub_basic_blocks (blocks)` and `clear_aux_for_blocks ()`. [F3, F43]
- In `aarch64_vector_costs::add_stmt_cost` and `count_ops`, `stmt_info` can be null (e.g., synthetic SLP `VEC_PERM_EXPR`s); `count_ops` must still run when `stmt_info` is null and guard every `stmt_info` access. In `add_stmt_cost`, `vec_promote_demote` on a `FLOAT_EXPR` `gassign` sets `count = count * 2 - m_num_last_promote_demote` and saves the prior `count` in `m_num_last_promote_demote`, while all other statements reset `m_num_last_promote_demote = 0`. [F24, F34]
- `aarch64_sve_element_int_mode` uses `BITS_PER_SVE_VECTOR` when `GET_MODE_CLASS (mode) == MODE_VECTOR_BOOL` and `GET_MODE_BITSIZE (mode)` otherwise, mapping SVE predicates to their data container's integer mode. `aarch64_can_change_mode_class` (`aarch64_modes_compatible_p`) must reject mode changes between predicate and non-predicate modes, incompatible partial SVE modes, or SVE modes with different element sizes when `BYTES_BIG_ENDIAN`. [F46, F53]
- In `aarch64_maybe_expand_sve_subreg_move`, only strip `SUBREG` on `dest`/`src` when `!LRA_SUBREG_P`. `aarch64_hard_regno_caller_save_mode` must return `mode` unchanged for `PR_REGNUM_P (regno)`. `aarch64_compute_pressure_classes` must report `PR_LO_REGS` and `PR_HI_REGS` separately rather than `PR_REGS`. [F41, F52, F54]
- `aarch64_float_const_representable_p` must return `false` for `DECIMAL_FLOAT_MODE_P (mode)` before reading `*CONST_DOUBLE_REAL_VALUE (x)`. `aarch64_valid_fp_move` must accept `aarch64_can_const_movi_rtx_p (src, mode)` alongside `aarch64_float_const_representable_p` and `aarch64_float_const_zero_rtx_p` before rejecting `aarch64_float_const_rtx_p (src)` when `!can_create_pseudo_p ()`. [F48, F49]
- `aarch64_classify_address` must reject all writeback/auto-increment codes when `vec_flags & (VEC_SVE_DATA | VEC_SVE_PRED)` is nonzero. `aarch64_expand_cpymem` must call `aarch64_expand_cpymem_mops` when `operands[2]` is not `CONST_INT_P` and cap inline chunk modes at `GET_MODE_SIZE (mode) <= MIN (size, 16)`; `aarch64_expand_cpymem_mops` must copy dest, src, and count via `copy_to_mode_reg` before `gen_aarch64_movmemdi`/`gen_aarch64_cpymemdi`. [F55, F56, F57]
- `aarch64_evpc_dup` must create the `VEC_SELECT` `PARALLEL` with `VOIDmode`, not `vmode`. `aarch64_sve_expand_vector_init_subvector` must iteratively pack any even number of partial SVE subvectors (`while (nelts >= 2)`) via `related_vector_mode` and `gen_aarch64_pack_partial`. `aarch64_emit_opt_vec_rotate` requires `can_create_pseudo_p ()`. [F50, F60, F61]
- In `aarch64-simd.md`, `vec_cmp*` expanders must produce all-ones (`CONSTM1_RTX`) / all-zeros (`CONST0_RTX`) masks in `<V_INT_EQUIV>` (expected by `vcond_mask_<mode><v_int_equiv>`), and unordered FP comparisons (`UNGE`, `UNGT`, `UNLE`, `UNLT`) in `vec_cmp<mode><v_int_equiv>` must mask NaN lanes to zero via `aarch64_cmeq<mode>` and `and` before `aarch64_cmge<mode>`/`aarch64_cmgt<mode>` so quiet NaNs do not trap. [F80, F87]
- In `aarch64-simd.md`, `aarch64_abs<mode>` must remain `UNSPEC_ABS` (not `(abs:M ...)`), and `aarch64_<su>abd<mode>` must use `(minus (smax/umax op1 op2) (smin/umin op1 op2))` rather than `(abs (minus ...))`. `movmisalign<mode>` must never `FAIL` and must `force_reg` `operands[1]` if neither operand is a register. `store_pair_lanes<mode>` must precede `*aarch64_combine_internal<mode>`. [F82, F85, F90]
- In `aarch64-simd.md`, post-reload `V8DImode` memory move splits must use `DImode` subregs when `STRICT_ALIGNMENT` is true and defer any subreg pair overlapping the `MEM` base register until last. `aarch64_simd_bsldi_internal`/`_alt` require `&r` on post-reload splits, a pseudo when `can_create_pseudo_p ()`, and `FAIL` otherwise; for `FLOAT_MODE_P (<MODE>mode)`, `@aarch64_simd_bsl<mode>` must emit `gen_aarch64_simd_bsl<v_int_equiv>_internal` into a `<V_INT_EQUIV>mode` temporary before moving to `operands[0]`. [F86, F91, F92]
- In `predicates.md`/`constraints.md`, `aarch64_comparison_operator_mode` must remain a `define_predicate`; `aarch64_simd_general_operand`/`_nonimmediate_operand` only allow `REG` or `POST_INC` `MEM` addresses; `aarch64_plushi_immediate` (`Uih`) only accepts `CONST_INT` where `(val & 0xfff) == val` or `sext_hwi (val & 0xf000, 16) == val`; `aarch64_sve_float_maxmin_immediate` (`vsB`) rejects `BFmode`; 16-bit lane-indexed ops must use `x` (`h_con`/`vwx`) or `y` (`sve_lane_con`/`sve_lane_pair_con`) instead of `w`; and indirect `blr` addresses must use `Ucr` for SLS hardening. [F122, F123, F124, F127, F128, F132]
- In `atomics.md`, `@aarch64_compare_and_swap<JUST_TI:mode>_lse` requires operand 2 to be `register_operand` with `"r"` (not `"rZ"`) because `casp` prints `%2, %R2`; `aarch64_atomic_<atomic_ldoptab><mode>_lse` must emit `ld<atomic_ldop>*` with a scratch register (`"=r"`) rather than `st<atomic_ldop>*` or `xzr`/`wzr`, which are not ordered by `dmb ishld`. [F125, F126]

## Object Lifetimes

- Local vectors in `aarch64.cc` must use `auto_vec` rather than `vec<T>`, and local non-escaping bitmaps (like `blocks` in `pass_switch_pstate_sm::execute`) must use `auto_sbitmap`, whereas `sbitmap_alloc` is reserved for hooks (`aarch64_get_separate_components`, `aarch64_components_for_bb`) that transfer ownership to the caller. [F14, F15]
- In `cortex-a57-fma-steering.cc`, `func_fma_steering::dfs` with `free = true` must defer deleting `to_free` nodes until `to_process` finishes for the current `fma_forest`, and must check `node->root_p ()` and cast to `fma_root_node *` before `delete` because `fma_node::~fma_node` is non-virtual. `fma_forest::merge_forest` must reparent roots via `set_forest (this)`, call `m_globals->remove_forest (other_forest)`, splice `m_roots`, and `delete other_forest`. [F109, F110, F111]

## API Contracts

- System register lookups in `sysreg_map` must use `aarch64_lookup_sysreg_map` rather than `sysreg_map->get`. In `aapcs_vfp_sub_candidate`, verify `COMPLETE_TYPE_P (type)` and `TREE_CODE (TYPE_SIZE (type)) == INTEGER_CST` (returning `-1` otherwise) before traversing `ARRAY_TYPE`, `RECORD_TYPE`, `UNION_TYPE`, or `QUAL_UNION_TYPE`. [F9, F20]
- `aarch64_simd_lane_bounds` requires `CONST_INT_P` and checks `[low, high)` (with `high` divided by `<nregs>` in `@aarch64_ld<nregs>_lane<vstruct_elt>` and `@aarch64_st<nregs>_lane<vstruct_elt>`), whereas `aarch64::report_out_of_range` takes a 0-based `argno` and closed interval `[min, max]`. [F65, F75]
- Every FP8 intrinsic depending on `FPMR` must use flag `FP8` in `aarch64-simd-pragma-builtins.def` and include `(reg:DI FPM_REGNUM)` in the `unspec` operands of its `define_insn` in `aarch64-simd.md`. [F89]
- `fractional_cost::fractional_cost (uint32_t a, uint32_t b)` asserts `SCALE % b == 0` (`11531520`), and all `fractional_cost` arithmetic and conversions (`ceil`, `scale`) must saturate at `0` and `~uint64_t(0)` / `~uint32_t(0)`. [F98, F119]
- `arm_sme.h` and `arm_neon_sve_bridge.h` must `#include <arm_sve.h>` before `#pragma GCC aarch64`, because `handle_arm_sme_h` errors if `handle_arm_sve_h` has not initialized `function_table`. [F115]

## Error Handling

- In `aarch64_validate_sls_mitigation` and `aarch64_parse_override_string`, early returns must precede buffer allocation, cursor advances must preserve the root pointer, and loop errors must `break` to reach `free`. In `host_detect_local_cpu`, error paths while `f` is open must `goto not_found`, and `f = NULL` must be set right after `fclose (f)` to avoid double-close. [F16, F114]
- `handle_arm_new` must check `TREE_TYPE (decl) == error_mark_node` before `aarch64_check_arm_new_against_type`. `pure_scalable_type_info::analyze` must check `type == error_mark_node` (returning `NO_ABI_IDENTITY`) before querying `TYPE_SIZE` or `aarch64_sve::builtin_type_p`. When `aarch64_layout_arg` errors on a named PST passed to an unprototyped function (`pcum->pcs_variant != ARM_PCS_SVE`), it must set `pcum->pcs_variant = ARM_PCS_SVE`. [F25, F26, F31]

## External Contracts

- When traversing `TYPE_FIELDS`: `aarch64_function_arg_alignment` must include zero-sized `FIELD_DECL`s in `DECL_ALIGN` and only fold `TYPE_ALIGN (DECL_BIT_FIELD_TYPE (field))` into `bitfield_alignment` when `!DECL_PACKED (field)`; `aapcs_vfp_sub_candidate` (with `warn_psabi_flags != NULL`) must skip `DECL_FIELD_ABI_IGNORED (field)` and zero-width bit-fields; and `pure_scalable_type_info::analyze_record` must ignore non-`FIELD_DECL`s, zero-`DECL_SIZE` fields, and `NO_ABI_IDENTITY` fields while requiring all others to be `IS_PST`. [F18, F19, F21]
- `aarch64_function_ok_for_sibcall` allows tail calls when `expr_callee_abi (exp).id ()` preserves a superset of `crtl->abi->id ()` (`ARM_PCS_SVE` > `ARM_PCS_SIMD` > `ARM_PCS_AAPCS64`). `aarch64_simd_clone_usable` must reject `'n'` (AdvSIMD) clones when `aarch64_sve_mode_p (vector_mode)` is true, and `'s'` (SVE) clones when false. [F58, F62]
- In `aarch64-simd-builtin-types.def`, `G` in `ENTRY (E, M, Q, G)` must equal `strlen(#E) + 2`. In `arm_sme.h`, runtime helpers (`__arm_za_disable`, `__arm_sc_memcpy`, `__arm_sc_memmove`, `__arm_sc_memset`, `__arm_sc_memchr`) must have `__arm_streaming_compatible`. In `arm_private_fp8.h`, `__arm_fpm_init` and `__arm_set_fpm_*` must remain macros expanding to `(uint64_t)`-cast integer constant expressions. [F72, F116, F117]

## Known Pitfalls

- In `aarch64.cc`, C++ headers gated by `system.h` must use `#define INCLUDE_<HEADER>` before `#include "system.h"`. In `host-aarch64-darwin.cc`, `"hosthooks-def.h"` must precede `"config/host-darwin.h"`. In `aarch64-protos.h`, declarations using `RTX_CODE`/`rtx_code` must be inside `#if defined (RTX_CODE)`, and those using `target.h` types (`type_context_kind`) inside `#ifdef GCC_TARGET_H`. [F10, F69, F70, F105]
- In `aarch64_simd_clone_compute_vecsize_and_simdlen`, the `clonei->args[i]` loop must test `COMPLEX_FLOAT_TYPE_P (type)` on `type` (not `ret_type`), update both `nds_elt_bits` and `wds_elt_bits`, and only increment `j` in the `clones` filtering loop when `clones.ordered_remove (j)` is not called. [F1, F2]
- `aarch64_process_target_attr` and `aarch64_process_one_target_attr` must buffer strings in `auto_vec<char, 32>` via `safe_grow (len + 1)`, not `alloca`. Mutations in `aarch64_override_options_after_change_1` must be idempotent (`x_flag_omit_frame_pointer` transitions `0` -> `2`, with `aarch64_use_frame_pointer = opts->x_flag_omit_frame_pointer != 1`). [F6, F45]
- Attribute-list scans (as in `aarch64_lookup_shared_state_flags`) must use `is_attribute_namespace_p` and `get_attribute_name` rather than dereferencing `TREE_PURPOSE (attr)` directly. In `aarch64_vectorize_vec_perm_const`, `d.one_vector_p` must use `rtx_equal_p (op0, op1)` and `d.op1 = copy_rtx (d.op0)`. [F23, F51]
- In `aarch64-simd-builtins.def` and `aarch64-simd-pragma-builtins.def`, `DEFAULT` (`FLAG_AUTO_FP`) only sets `FLAG_FP` when `FLOAT_MODE_P` holds on the primary mode; FP builtins with integer/`mf8` primary modes must use `FP`/`FP8`, and non-trapping builtins on float modes must use `QUIET`. [F76]
- In `aarch64-simd.md`, `<su><maxmin><mode>3` on `VHSDF` maps to `fmaxnm`/`fminnm` (not `fmax`/`fmin`). Multi-element group lane patterns (`aarch64_fcmlaq_lane*`, `aarch64_bfdot_lane*`, `aarch64_<sur>dot_lane*`) must pass `nunits / 2` or `nunits / 4` to `ENDIAN_LANE_N` instead of `aarch64_endian_lane_rtx`. In `iterators.md`, `define_mode_iterator`s used as `BUILTIN_<ITERATOR>` must list explicit alphanumeric modes without nested iterators or `_`. [F67, F81, F103]
- In `cortex-a57-fma-steering.cc`, the inner `int i` inside `FOR_BB_INSNS` in `func_fma_steering::analyze` must not be merged with the outer `bb_dfs_preorder` index `i`; in `rename_fma_trees`, `dfs (..., true)` frees all forests and nodes without clearing `m_fma_forests` or `m_insn_fma_head_map`, which must not be dereferenced afterwards. [F94, F112]
