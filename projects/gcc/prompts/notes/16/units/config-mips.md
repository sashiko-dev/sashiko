# config-mips

This component defines the core target architecture configuration, RTL instruction patterns, operand predicates, command-line options, pipeline scheduling automata, and subtarget OS/ABI headers for the MIPS backend in GCC. It bridges the target-independent middle-end and RTL passes to MIPS ISA variants (MIPS I-IV, MIPS32/64 R1-R6, MIPS16, microMIPS, Octeon, and MSA SIMD extensions) and ABIs (o32, n32, n64, o64, EABI), and provides the `<msa.h>` vector intrinsic header.

## Architecture & Data Flow

- In `DRIVER_SELF_SPECS` (`mips.h`, `mti-elf.h`, `mti-linux.h`), `MIPS_ISA_LEVEL_SPEC` (and `MIPS_DEFAULT_ISA_LEVEL_SPEC` when used) must precede `MIPS_32BIT_OPTION_SPEC`, `MIPS_FPXX_OPTION_SPEC`, `MIPS_ISA_SYNCI_SPEC`, and `BASE_DRIVER_SELF_SPECS`. Broken by: evaluating those specs or `MIPS_ISA_NAN2008_SPEC` before `MIPS_ISA_LEVEL_SPEC` infers `-mips*` from `-march=*`. [F10]
- In `mips.h`, `FUNCTION_ARG_REGNO_P(N)` must reject odd-numbered floating-point argument registers (`(N) % 2 != 0`) when `mips_abi == ABI_32 && !TARGET_FLOAT32` (under O32-FPXX and O32-FP64). [F27]
- In `mips.md`, the `enabled` attribute must disable alternatives with `move_type` equal to `mtc` or `mfc` and `dword_mode` equal to `yes` whenever `(TARGET_FLOATXX && !ISA_HAS_MXHC1) || TARGET_O32_FP64A_ABI` holds. Broken by: adding a 64-bit GPR-to-FPR or FPR-to-GPR move alternative without `move_type` set to `mtc`/`mfc` or `dword_mode` set to `yes`. [F24]
- In `mips.md`, `move_doubleword_fpr<mode>` must keep the `FP_REG_RTX_P` operand in its full `SPLITF` mode and access the non-FPR operand via `mips_subword` using `load_low<mode>`, `load_high<mode>`/`mthc1<mode>`, and `store_word<mode>`/`mfhc1<mode>`, rather than taking subword `SUBREG`s of the FPR before asm emission. [F23]
- On `TARGET_64BIT`, `PROMOTE_MODE` and `LOAD_EXTEND_OP` in `mips.h` require 32-bit `SImode` values in registers to be sign-extended to 64 bits (`UNSIGNEDP = 0`), so `truncdi<mode>2` in `mips.md` must emit `sll %0,%1,0` for register destinations rather than a no-op move. [F26]
- In `mips.h` and `mips.md`, call patterns (`call_internal`, `call_internal_direct`, `call_value_internal`, `call_value_internal_direct`, `call_value_multiple_internal`) must gate splitting out the post-call `$gp` reload on `TARGET_SPLIT_CALLS` (which requires `epilogue_completed`), never before reload. [F29]
- When `TARGET_USE_GOT` is true in `mips.md`, `load_call<mode>` must read `(reg:SI GOT_VERSION_REGNUM)`, and `exception_receiver` and `nonlocal_goto_receiver` must emit `gen_set_got_version ()` so GOT call-address loads cannot be hoisted across calls or abnormal edges. [F30]
- In `builtin_longjmp` (`mips.md`), `fp` and `gpv` must be loaded from the jump buffer into temporary registers via `copy_to_reg` before `emit_stack_restore`, and moved into `hard_frame_pointer_rtx` and `gp` only after `gen_blockage ()` and the register clobbers. [F28]
- In `predicates.md`, `splittable_const_int_operand` must return `false` when `GET_MODE_SIZE (mode) > UNITS_PER_WORD` so multi-word `CONST_INT` moves are not split into word-mode moves before reload. [F35]
- In `mips.md`, instructions with attribute `type` set to `"ghost"` must have `insn_count` evaluate to `0` (zero byte length) and a `0`-cycle `define_insn_reservation "ghost"` on `"nothing"` so they do not perturb branch range, alignment, scheduling, or `md_reorg` hazard detection before being split. [F12]
- `ENABLE_LD_ST_PAIRS` in `mips.h` must remain disabled when `TARGET_MICROMIPS` or `TARGET_FIX_24K` is active, and `JOIN_MODE` in `mips.md` must exclude `QImode`, because microMIPS, 24K errata workarounds, and byte accesses (`lb`/`sb`) do not support load/store bonding. [F15]
- In `mips.h`, `CASE_VECTOR_SHORTEN_MODE(MIN, MAX, BODY)` must only narrow switch jump-table entries to `HImode` when `TARGET_MIPS16_SHORT_JUMP_TABLES` is true and `(MIN) >= -32768 && (MAX) < 32768`, falling back to `SImode` (or `ptr_mode` when `!TARGET_MIPS16_SHORT_JUMP_TABLES`) so PC-relative `lh` table loads do not overflow. [F16]
- The `GPR` `mov<mode>cc` expander in `mips.md` must `FAIL` when `!ISA_HAS_FP_CONDMOVE` and the comparison operand mode is not integral (`!INTEGRAL_MODE_P (GET_MODE (XEXP (operands[1], 0)))`). Broken by: checking `ISA_HAS_SEL` or `ISA_HAS_CONDMOVE` instead of `!ISA_HAS_FP_CONDMOVE`. [F20]
- In `mips.md`, `mov<GPR:mode>_on_<MOVECC:mode>`, `mov<GPR:mode>_on_<MOVECC:mode>_mips16e2`, and `*mov<SCALARF:mode>_on_<MOVECC:mode>` must leave `match_operator 4 "equality_operator"` mode-unconstrained, and `mov<GPR:mode>_on_<GPR2:mode>_ne` must match a bare `GPR2` register condition. [F22]
- The `<u>mulditi3` expander in `mips.md` must accept `ISA_HAS_R6DMUL` in addition to `ISA_HAS_DMULT`, and when `!ISA_HAS_DMULT` it must emit `gen_muldi3_mul3_nohilo` into `mips_subword (operands[0], 0)` and `gen_<su>muldi3_highpart_r6` into `mips_subword (operands[0], 1)`. [F32]
- In `mips.md`, the anonymous `exts` combiner pattern matching `(ashiftrt:SI (truncate:SI (ashift:DI op1 op2)) op3)` must verify `UINTVAL (operands[2]) < 32 && UINTVAL (operands[3]) < 32 && UINTVAL (operands[3]) >= UINTVAL (operands[2])`. [F33]
- In `mips.md`, floating-point `abs<mode>2` and `neg<mode>2` must be gated on `mips_abs == MIPS_IEEE_754_2008 || !HONOR_NANS (<MODE>mode)`. [F37]
- In `mips.md`, `fnma<mode>4`, `*fnma<mode>4_nmsub3`, `*fnma<mode>4_nmsub4`, `fnms<mode>4`, `*fnms<mode>4_nmadd3`, `*fnms<mode>4_nmadd4`, `*nmadd4<mode>_fastmath`, and `*nmsub4<mode>_fastmath` must require `!HONOR_SIGNED_ZEROS (<MODE>mode)`. [F38]
- In `mips.h` and `mips.md`, `ISA_HAS_FP_RECIP_RSQRT(MODE)` must disallow `DFmode` on `ISA_HAS_FP4` targets when `!TARGET_FLOAT64 && mips_isa_rev < 2`, and `*recip<mode>3`, `*rsqrt<mode>a`, and `*rsqrt<mode>b` must require `flag_unsafe_math_optimizations`. [F39]
- In `mips.md`, the `prefetch` insn pattern must normalize `operands[1]` from `const2_rtx` to `const0_rtx` before passing it to `mips_loongson_ext2_prefetch_cookie` or `mips_prefetch_cookie`, because those helpers only handle read (`0`) and write (`1`) values. [F41]
- In `mips.md`, the lowercase `unitmode` mode attribute must map every scalar and vector floating-point or integer vector mode (`SF`, `DF`, `V2SF`, `V4SF`, `V16QI`, `V8QI`, `V8HI`, `V4HI`, `V4SI`, `V2SI`, `V2DI`, `V2DF`) to its lowercase scalar unit mode name so two-mode optabs resolve inner element modes. [F19]
- Host-only backend declarations and `GTY(())` structures in `mips.h` (`struct mips_asm_switch`, `struct mips_frame_info`, `struct machine_function`, and `extern` backend variables) must remain inside the `#ifndef USED_FOR_TARGET` block. [F8]
- `mips.h` must `#include "config/vxworks-dummy.h"` before defining `TARGET_RTP_PIC`, `TARGET_USE_PIC_FN_ADDR_REG`, or `TARGET_CPU_CPP_BUILTINS()` so fallback definitions of `TARGET_VXWORKS` and `TARGET_VXWORKS_RTP` are present on non-VxWorks targets. [F5]
- `do { ... } while (0)` statement macros in `mips.h` (such as `ASM_OUTPUT_BEFORE_CASE_LABEL`, `ASM_OUTPUT_CASE_END`, `ASM_OUTPUT_ADDR_DIFF_ELT`, `ASM_OUTPUT_LABELREF`, `DBR_OUTPUT_SEQEND`, `ASM_OUTPUT_REG_PUSH`, `ASM_OUTPUT_REG_POP`, `MIPS_CPP_SET_PROCESSOR`, and `TARGET_CPU_CPP_BUILTINS`) must not end with a trailing semicolon. [F1]

## API Contracts

- In `*join2_load_store<JOIN_MODE:mode>` in `mips.md`, calls to `output_asm_insn` using the template returned by `mips_output_move (operands[2], operands[3])` must pass `&operands[2]` rather than `operands` as the operand array because `mips_output_move` formats its template string with `%0` and `%1`. [F2]
- Integer multiply-accumulate patterns in `mips.md` must set the `accum_in` attribute to the operand index (`"0"` through `"5"`) of their input accumulator operand so `mips_linked_madd_p` can identify chained multiply-add dependencies for `TUNE_MACC_CHAINS` ready-queue reordering and scheduler bypasses. [F13]

## External Contracts

- `TARGET_CPU_CPP_BUILTINS()` in `mips.h` must not define the unprefixed `mips` macro when `TARGET_VXWORKS` is true, because VxWorks headers construct `#include` filenames from an unquoted architecture macro that expands to `mips`. Broken by: using `builtin_define_std ("mips")` or removing the `!TARGET_VXWORKS` guard. [F6]
- `TARGET_CPU_CPP_BUILTINS()` in `netbsd.h` must override the generic `mips.h` definition and omit namespace-invasive macros such as `_R3000`, `R3000`, `_R4000`, `R4000`, and non-underscore-prefixed `MIPSEB`/`MIPSEL`. [F7]
- In `mips.opt`, every target `-m` option definition must include the leading `m` prefix in its stanza header name (such as `mmad`, `mabicalls`, and `mimadd`), because option stanza headers specify the full flag name following `-` rather than a suffix after `-m`. [F44]

## Known Pitfalls

- In `mips.opt`, new boolean target options must use `Var(TARGET_...)` rather than `Mask(...)` on `target_flags`, because `mips.opt` plus subtarget option files such as `vxworks.opt` already consume 31 of the 32 bits in `target_flags` before `opth-gen.awk` emits `#error too many target masks`. [F43]
- In `mips.h`, immediate range-check macros that add a positive offset to `VALUE` (`IMM10_OPERAND`, `SMALL_OPERAND`, and `LUI_OPERAND`) must cast `VALUE` to `unsigned HOST_WIDE_INT` before the addition so large positive `HOST_WIDE_INT` values do not trigger signed integer overflow. [F42]
- Subtarget headers included after `mips/mips.h` in `tm_file` (such as `r3900.h`, `netbsd.h`, `rtems.h`, `n32-elf.h`, `mti-elf.h`, and `mti-linux.h`) must `#undef` any target default or spec macro already defined in `mips.h` (e.g., `MIPS_ABI_DEFAULT`, `MULTILIB_DEFAULTS`, `DRIVER_SELF_SPECS`, `SUBTARGET_CC1_SPEC`, `MIPS_DEFAULT_GVALUE`) before redefining it. [F4]
- D front-end target hook macros (`TARGET_D_CPU_VERSIONS` and `TARGET_D_REGISTER_CPU_TARGET_INFO`) must be defined in `mips-d.h` rather than `mips.h` because `tm_d.h` does not include `tm.h` (`mips.h`). [F11]
- In `mips.md`, bonded load patterns `*join2_load_store<JOIN_MODE:mode>` and `*join2_loadhi` must require `non_volatile_mem_operand` in their peephole2s and must emit the second load (`operands[2], operands[3]`) before the first (`operands[0], operands[1]`) when `reg_overlap_mentioned_p (operands[0], operands[1])` is true. [F25]
- The `SCALARF` `mov<mode>cc` expander in `mips.md` must fail when `ISA_HAS_SEL` and either `!FLOAT_MODE_P (GET_MODE (XEXP (operands[1], 0)))` or `<MODE>mode == DFmode && (!TARGET_ODD_SPREG || TARGET_FLOATXX)`. [F21]
- In `mips.md`, `define_expand` patterns that emit a final `code_label` (such as `fixuns_truncdfsi2`, `fixuns_truncdfdi2`, `fixuns_truncsfsi2`, and `fixuns_truncsfdi2`) must emit `emit_use (stack_pointer_rtx)` after that label so callers can attach `REG_NOTES` to the last emitted insn. [F17]
- In `mips.md`, multiply-accumulate patterns with both `LO` (`=l`) and GPR (`=d`) destination alternatives (`*mul_acc_si`, `*mul_acc_si_r3900`, `*macc`, `*msac`, `*msac_using_macc`, `*mul_sub_si`) must constrain the accumulator input operand with `"l"` rather than matching constraint `"0"` on the `=l` alternatives. [F31]
- In `mips.md`, `<optab>_internal` (`return_internal` and `simple_return_internal`) must pass its matched `(use (match_operand 0 "pmode_register_operand" ""))` directly to `mips_output_jump (operands, 0, -1, false)` without overwriting `operands[0]` with `RETURN_ADDR_REGNUM`. [F34]
- In `mips.md`, `tls_get_tp_<mode>` must constrain destination operand 0 with `"=d"` and clobber `(reg:P TLS_GET_TP_REGNUM)` before reload, splitting only after `reload_completed` into `*tls_get_tp_<mode>_split` plus a move from `TLS_GET_TP_REGNUM` (`$3`). Broken by: constraining operand 0 directly to register class `v` (`$3`) before `reload_completed`. [F36]
