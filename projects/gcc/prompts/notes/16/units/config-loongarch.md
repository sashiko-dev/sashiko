# config-loongarch

The `config-loongarch` unit implements the LoongArch GCC backend, including target option resolution, `cpucfg` hardware probing, `target` attribute/pragma handling, C/C++/D front-end hooks, intrinsic headers and built-in expansion, cost and pipeline models, and RTL machine descriptions for scalar, 128-bit LSX, 256-bit LASX, and atomic synchronization instructions.

## Architecture & Data Flow

- In `tm_file` (`gcc/config.gcc`), `loongarch/musl.h` must precede `loongarch/linux.h` (which tests `!defined(LA_DEFAULT_TARGET_MUSL)` for `ABI_LIBDIR`), and `loongarch/gnu-user.h` and `loongarch/elf.h` must precede `loongarch/loongarch-driver.h` (which defines `#ifndef` defaults for `SUBTARGET_{CPP,CC1,ASM}_SPEC`). In `loongarch-opts.h` and `loongarch-evolution.h`, `"loongarch-def.h"`, `"options.h"`, and C++/host-only declarations (`loongarch_target`, `gcc_options`, `HOST_WIDE_INT`) must stay inside `#if !defined(IN_LIBGCC2) && !defined(IN_TARGET_LIBS) && !defined(IN_RTS)`. [F6, F7, F51]
- Every `HAVE_AS_*` macro evaluated in the backend must have an `#ifndef` fallback to `0` in `loongarch-opts.h`. Default linker relaxation (`MASK_LINKER_RELAXATION` in `loongarch_init_misc_options` and `ASM_MRELAX_DEFAULT` in `loongarch-driver.h`) requires both `HAVE_AS_MRELAX_OPTION` and `HAVE_AS_COND_BRANCH_RELAXATION`, while `ASM_MRELAX_SPEC` passes `-mrelax`/`-mno-relax` by default whenever `HAVE_AS_MRELAX_OPTION` is true. [F49, F101]
- `cache_cpucfg` only populates `cpucfg_cache` (size `N_CPUCFG_WORDS`) at word indices in `cpucfg_useful_idx`, so any index read in `fill_native_cpu_config` or `cpucfg_map` must be in `cpucfg_useful_idx` and `< N_CPUCFG_WORDS`. When `arch_native_p` is true in `fill_native_cpu_config`, `preset.evolution` (`loongarch_cpu_default_isa[tgt->cpu_arch].evolution`) must be overwritten (not OR-ed) with `hw_isa_evolution`. [F2, F40]
- Every per-function field in `struct loongarch_target` (`cpu_arch`, `cpu_tune`, `cmodel`, `tls_dialect`, `isa.fpu`, `isa.simd`, `isa.evolution`) must be saved in `loongarch_update_gcc_opt_status` and restored in `loongarch_option_restore`. In `loongarch_handle_option`, `OPT_march_` must reset `x_la_opt_simd` and `x_la_opt_fpu` to `M_OPT_UNSET` and `x_la_isa_evolution` to `0`, and `OPT_mtune_` must reset `x_str_align_{functions,loops,jumps}` to `NULL`. In `loongarch_target_option_override`, `loongarch_cpu_align[target->cpu_tune]` defaults apply to unset `opts->x_str_align_*` only when `!opts->x_optimize_size`. [F73, F97, F99]
- When `loongarch_set_current_function` switches to a non-NULL `fndecl`, it must restore `TREE_TARGET_OPTION (new_tree)` when `new_tree != old_tree` and call both `loongarch_reg_init ()` and `loongarch_save_restore_target_globals (new_tree)`. [F72]
- `loongarch_init_builtins` must register every `loongarch_builtins` entry into `loongarch_builtin_decls` and `loongarch_get_builtin_decl_index` unconditionally without checking `d->avail ()` (deferred to `loongarch_expand_builtin`). In `loongarch_update_cpp_builtins`, every option-dependent predefined macro—including each `la_evo_macro_name` entry—must be undefined with `builtin_undef` (or `loongarch_def_or_undef`) before conditional redefinition so `#pragma GCC target` removes stale macros. [F32, F35]
- In `loongarch_expand_builtin_direct`, when `has_target_p` is true, `ops[0]` is the output and `opno` starts at 1 while `argno` starts at 0, placing argument `argno` at `ops[argno + 1]` (except `CODE_FOR_recipv*`, which puts `CONST1_RTX` at `ops[1]` and argument 0 at `ops[2]`). In `loongarch_expand_builtin_insn`, scalar arguments to `CODE_FOR_{lsx_vreplgr2vr,lasx_xvreplgr2vr,lsx_vinsgr2vr,lasx_xvinsgr2vr}_*` must be narrowed to `GET_MODE_INNER (ops[0].mode)` via `lowpart_subreg` with `ops[1].mode` updated, and built-ins for `vilvh`, `vilvl`, `vpackev`, `vpackod`, `vpickev`, `vpickod`, `vandn_v` (and `lasx_xv*` counterparts), `lsx_vftintrz_w_d`, and `lsx_vffint_s_l` must swap `ops[1]` and `ops[2]`. [F1, F19, F24]
- Because 256-bit LASX `xvpickev`, `xvfcvt.s.d`, `xvffint.s.l`, `xvftintrz.w.d`, `xvfcvtl.d.s`, and `xvfcvth.d.s` operate within each 128-bit lane, full-vector `vec_pack_*` and `vec_unpack*` patterns in `lasx.md` must permute lanes with `xvpermi.d` (masks `0xd8`, `0x50`, `0xfa`, `0xe8`, or `0xd4`). In `lasx.md`, `vec_select` patterns for per-128-bit-lane instructions (`lasx_xvrepl128vei_{b,h,w,d}_internal`, `lasx_xvshuf4i_<lasxfmt_f>_1`, `lasx_xvpermi_<lasxfmt_f_wd>_1`) must require in their insn condition that each upper-lane index equals the corresponding lower-lane index plus the lane element count (16, 8, 4, or 2). [F25, F26]
- `ALLVEC_TI` in `simd.md` must include `(V1TI "ISA_HAS_LSX")` and `(V2TI "ISA_HAS_LASX")` in `mov<mode>` and `mov<mode>_simd` for reload moves of `TImode`-lane vector immediates, and `<simd_isa>_<x>vldx` must expand to `(mem:QIVEC (plus:DI ...))` rather than an `UNSPEC` so RTL passes see the memory read. [F114, F115]
- In `loongarch_expand_vector_init_same`, when `GET_MODE (same) != imode` and `GET_CODE (same) == MEM`, `same` must be loaded into a pseudo via `loongarch_emit_move` before `simplify_gen_subreg`/`lowpart_subreg` and forced with `force_reg (imode, temp)`. In `loongarch_expand_vector_init`, every element `val[i]`, `val_hi[i]`, or `val_lo[i]` passed to `loongarch_vec_repl1_*`, `loongarch_vec_repl2_*`, `loongarch_vec_set*`, or `VEC_CONCAT` must first be forced into an `imode` register with `force_reg`. [F83, F92]
- In `loongarch_expand_lsx_cmp`, integer vector comparisons with `GE`, `GT`, `GEU`, or `GTU` must `force_reg` `op1` into `cmp_mode` and swap `op0`/`op1` via `swap_condition (cond)`, and FP vector comparisons (`V4SF`, `V2DF`, `V8SF`, `V4DF`) must always `force_reg` `op1` into `cmp_mode`. In `loongarch_vectorize_vec_perm_const`, `orig_perm`, `op0`, and `op1` must stay unmodified when folding `which == 3` with `rtx_equal_p (d.op0, d.op1)` into a single-vector permute so the `!ok && which == 3` fallback can restore `d.op0`, `d.op1`, `d.one_vector_p = false`, and `d.perm`. [F48, F93]
- In `loongarch_split_vector_move`, GPR-to-GPR moves must copy `loongarch_subword_at_byte` words from byte `0` upward when `REGNO (low_dest) <= REGNO (low_src)` and from `GET_MODE_SIZE (GET_MODE (dest)) - UNITS_PER_WORD` downward otherwise to avoid clobbering overlapping source registers. [F94]
- `loongarch_optab_supported_p` only enables `rsqrt_optab` when `opt_type == OPTIMIZE_FOR_SPEED && use_rsqrt_p ()`, and `loongarch_emit_swrsqrtsf` must zero out estimate `x0` when `a == 0.0` and `!recip` so `sqrt(0.0)` is not `NaN`. In `lasx.md`, `div<mode>3` and `sqrt<mode>2` only expand `V8SFmode` to `loongarch_emit_swdivsf` / `loongarch_emit_swrsqrtsf` when `flag_finite_math_only && !flag_trapping_math && flag_unsafe_math_optimizations && optimize_insn_for_speed_p ()` and `TARGET_RECIP_VEC_{DIV,SQRT}` hold. [F29, F96]
- `loongarch_compute_frame_info`, `loongarch_for_each_saved_reg`, `loongarch_get_separate_components`, and `loongarch_process_components` must use identical `[GP_REG_FIRST, GP_REG_LAST]` and `[FP_REG_FIRST, FP_REG_LAST]` bounds and decrement `offset` on every set bit in `frame.mask` and `frame.fmask` before any `continue`. [F42]
- In `loongarch_expand_conditional_move`, `REG_P` must be verified on `op0`, `op1`, `operands[2]`, and `operands[3]` before reading `REGNO`. In both `loongarch_expand_conditional_move` and `loongarch_expand_atomic_qihi`, shift counts passed to `ASHIFT`, `ASHIFTRT`, `LSHIFTRT`, `ROTATE`, or `ROTATERT` must be converted via `gen_lowpart (SImode, ...)`. [F65, F84]
- For non-LSX/LASX modes with `GET_MODE_SIZE (mode) > UNITS_PER_WORD`, `loongarch_valid_offset_p` requires `IMM12_OPERAND (INTVAL (x) + GET_MODE_SIZE (mode) - UNITS_PER_WORD)` and `splittable_const_int_operand` (`predicates.md`) must return `false`. [F85, F112]
- In `loongarch_rtx_cost_data` and `loongarch_rtx_cost_optimize_size`, multi-cycle arithmetic and `movcf2gr` costs must remain `> COSTS_N_INSNS (1)` (`COST_COMPLEX_INSN` when optimizing for size). In `loongarch_rtx_costs`, `DIV`/`MOD`/`UDIV`/`UMOD` must add `COSTS_N_INSNS (2)` for non-`DImode` when `TARGET_64BIT && !ISA_HAS_DIV32` and add `COSTS_N_INSNS (2)` when `TARGET_CHECK_ZERO_DIV` holds. `loongarch_vector_costs::determine_suggested_unroll_factor` must return `1` when `m_has_avg`, `m_has_recip`, unrolling is disabled, or `m_stmts - m_loads - m_stores == 0`. [F38, F70, F102]
- In `sync.md`: both `GPR` and `SHORT` `atomic_compare_and_swap<mode>` expanders must write `mod_s` back to `operands[6]` when promoting to `GEN_INT (MEMMODEL_ACQ_REL)` before branching on `ISA_HAS_LAMCAS`, sign-extend `compare` to `word_mode` before `gen_rtx_EQ (SImode, compare, const0_rtx)`, and for `SHORT` modes convert `operands[1]` and `operands[3]` to `SImode` before subtracting; `atomic_test_and_set` must call `set_mem_alias_set (aligned_mem, 0)` when widening a `QImode` `MEM` to `SImode` via `change_address`. [F107, F111, F123]

## Synchronization

- When `!ISA_HAS_LAM_BH`, `atomic_exchange<mode>` for `SHORT` modes in `sync.md` must expand via `loongarch_expand_atomic_qihi` using `gen_atomic_cas_value_exchange_7_si` (with `oldval = const0_rtx`), not `gen_atomic_cas_value_cmp_and_7_si`, so the `ll`/`sc` loop stores unconditionally without aborting on concurrent writes. [F124]

## Object Lifetimes

- `loongarch_config_target` must initialize `msg_obstack` with `obstack_init` before calling `abi_str`, `isa_str`, `arch_str`, or `multilib_enabled_abi_list` and call `obstack_free (&msg_obstack, NULL)` on every non-fatal return path; their returned pointers must not outlive `msg_obstack`. `loongarch_process_target_attr` must keep its mutable copy of `TREE_STRING_POINTER (args)` in an RAII `auto_vec<char, N>` because `strtok_r` mutates `str_to_check` across early returns. [F55, F56, F57]

## API Contracts

- `loongarch_pragma_target_parse` must call `loongarch_reset_previous_fndecl`, refresh macros via `loongarch_update_cpp_builtins (parse_in)` with `warn_unused_macros` suppressed and `BUILTINS_LOCATION` forced, and call `loongarch_save_restore_target_globals (pop_target)` when `pop_target` is non-null. `loongarch_option_valid_attribute_p` must save `global_options` and `global_options_set`, seed from `DECL_FUNCTION_SPECIFIC_TARGET (fndecl)` if present so attributes stack, and restore via `cl_target_option_restore` before returning. [F34, F61]
- In `loongarch_expand_builtin_insn`, immediate-operand vector built-ins (`CODE_FOR_lsx_vaddi_bu`, `CODE_FOR_lsx_vseqi_b`, etc.) must only convert `ops[2].value` via `loongarch_gen_const_int_vector` (and set `ops[2].mode = ops[0].mode`) when `CONST_INT_P (ops[2].value)` holds and `INTVAL (ops[2].value)` is in `[0, 31]` or `[-16, 15]` respectively. [F18]
- In `lasx.md`, `vec_set<mode>_internal` and `lasx_xvinsgr2vr_<mode256_i_half>_internal` for `ILASX_HB` (`V16HI`, `V32QI`) emit 128-bit `vinsgr2vr.<lasxfmt> %w0,%z1,%y3` and must only be used by `loongarch_expand_vector_init` on lower half-vector indices prior to `xvpermi.q` lane merging. `vect_par_cnst_even_or_odd_half` must verify `GET_MODE_NUNITS (mode) == nunits * 2`, `XVECEXP (op, 0, 0)` is `CONST_INT` 0 or 1, and each `i` in `1 .. nunits - 1` equals `INTVAL (first) + i * 2`. [F23, F106]
- `loongarch_address_insns` must pass `reg_reg_cost = 1` (not `la_addr_reg_reg_cost`) to `loongarch_address_insns_1` so `ADDRESS_REG_REG` returns a positive count. In `loongarch_variable_issue`, `!USEFUL_INSN_P (insn)` and `TYPE_GHOST` insns must not decrement `more`, and after `reload_completed` no recognized insn may have `TYPE_MULTI`. [F71, F86]

## Error Handling

- Error paths in `loongarch_expand_builtin`, `loongarch_expand_builtin_lsx_test_branch`, and `loongarch_expand_builtin_insn` must return a non-null RTX (`target ? target : const0_rtx`, `const0_rtx`, or `gen_reg_rtx`), never `NULL_RTX` or an unchecked `target`. [F36]
- In `loongarch_target_option_override`, when `target->cmodel == CMODEL_EXTREME` and `opts->x_flag_plt` is non-zero, `opts->x_flag_plt` must be cleared to `0` unconditionally while `error` is emitted only if `opts_set->x_flag_plt` is set. In `loongarch_config_target`, when `t.isa.simd != ISA_EXT_NONE && t.isa.fpu != ISA_EXT_FPU64` and `constrained.fpu` is true, `t.isa.simd` must be reset to `ISA_EXT_NONE` unconditionally while `inform`/`fatal_error` is emitted only if `constrained.simd` is true. [F62, F63]

## External Contracts

- In `loongarch_update_cpp_builtins`, `OPTION_MASK_ISA_FRECIPE` in `la_evo_feature_masks` must also require `TARGET_HARD_FLOAT` before defining `__loongarch_frecipe` because `larchintrin.h` gates FP intrinsics (`__frecipe_{s,d}`, `__frsqrte_{s,d}`) solely on `#ifdef __loongarch_frecipe`. `GNU_USER_TARGET_MATHFILE_SPEC` in `gnu-user.h` must guard `crtfastmath.o%s` with `%{!shared:...}`. [F33, F39]
- `loongarch_pass_by_reference` must check `cum != NULL` (since `std_gimplify_va_arg_expr` passes null) before calling `loongarch_get_arg_info` to check `info.num_fprs` ahead of `!IN_RANGE (size, 0, 2 * UNITS_PER_WORD)`, and `loongarch_get_arg_info` must align `info->gpr_offset` to an even register for unnamed varargs with `alignment > BITS_PER_WORD`. [F67, F91]
- `loongarch_promote_function_mode` must promote sub-word integers via `PROMOTE_MODE` even when `type == NULL_TREE`, and `loongarch_function_value_1` must call `promote_function_mode` when `type != NULL_TREE`. In `loongarch_setup_incoming_varargs`, `loongarch_function_arg_advance` must run whenever `!TYPE_NO_NAMED_ARGS_STDARG_P (TREE_TYPE (current_function_decl)) || arg.type != NULL_TREE`. When `crtl->calls_eh_return` is true, `loongarch_expand_epilogue` must pass `skip_eh_data_regs_p = (crtl->calls_eh_return && style != EXCEPTION_RETURN)` to `loongarch_for_each_saved_reg` so normal returns do not clobber `$r4`–`$r7`. [F88, F89, F90]

## Known Pitfalls

- `"config.h"` must precede `"tm.h"`, `"loongarch-opts.h"`, and `"loongarch-driver.h"` so `auto-host.h` defines `HAVE_AS_*` before fallback `0`s are set. Prototypes in `loongarch-protos.h` using `enum rtx_code` (`loongarch_emit_binary`) must stay inside `#ifdef RTX_CODE` and callers must include `"rtl.h"` before `"tm_p.h"`. [F50, F52]
- In `fill_native_cpu_config`, when the hardware PRID is unknown, `tgt->cpu_arch` and `tgt->cpu_tune` remain `ARCH_NATIVE` / `TUNE_NATIVE` (slot 0) when indexing `loongarch_cpu_default_isa` and `loongarch_cpu_cache`, so `loongarch_def_array` tables must keep valid fallback entries at slot 0. In `loongarch_init_builtins`, multiple built-ins alias the same `icode`, so `loongarch_get_builtin_decl_index[icode]` holds only the last entry; use `loongarch_builtin_decls[fcode]` for unique lookup. [F3, F4]
- Require `force_reg` on `ops[1].value` if `GET_CODE (ops[1].value) != REG` in `loongarch_expand_builtin_lsx_test_branch`; `trunc_int_for_mode` to `<UNITMODE>mode` on `operands[1]` when `<MODE>mode == V32QImode` in `lasx_xvrepli<mode>` before `loongarch_gen_const_int_vector`; `gen_int_mode (UINTVAL (mask), mode)` before `simplify_const_binary_operation` in `loongarch_reassoc_shift_bitwise`; `simplify_gen_subreg` (not `gen_rtx_SUBREG`) in `loongarch_expand_vec_cond_expr` and `loongarch_expand_vec_cond_mask_expr`; and `true_regnum (x) == -1 || MEM_P (x)` (not `MEM_P (x)` alone) for `FCCmode` in `loongarch_secondary_reload`. [F21, F27, F80, F81, F82]
- In `simd.md`, scalar `<simd_frint_pattern><mode>2` (`ANYF`) via `LSX_SCALAR_FRINT` must broadcast operand 1 with `vec_duplicate:<VLSX_FOR_FMODE>` (not a paradoxical `subreg`) to avoid upper-lane FP exceptions; `<simd_isa>_<x>vfcmp_<fcond>_<simdfmt>` (`fcond_simd_rev`: `ge`, `gt`, `unge`, `ungt`) and `<simd_isa>_<x>vfcmp_<fcond_inv>_<simdfmt>` (`fcond_inv_rev`: `le`, `lt`, `unle`, `unlt`) must emit reversed operands `%<wu>2,%<wu>1`; and `<fmaxmin><mode>3` / `reduc_<fmaxmin>_scal_<mode>` must use `UNSPEC_FMAXMIN` rather than `smax`/`smin`. In `sync.md`'s `atomic_cas_value_strong<mode>`, when `TARGET_64BIT && REG_P (operands[2]) && GET_MODE (operands[2]) == SImode`, `operands[2]` must be sign-extended with `addi.w %5,%2,0` before `bne %0,%5,2f` with `length` set to 32. [F109, F118, F126, F127]
