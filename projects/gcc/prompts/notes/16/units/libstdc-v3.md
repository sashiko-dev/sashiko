# libstdc++-v3

This unit provides internal standard library headers (`include/bits`) for pointer traits, range access, algorithm predicates, stream manipulators, and `<random>` engines and distributions, alongside compiled runtime sources (`src`) for C++17–C++26 facilities including Ryu floating-point `to_chars`, `<chrono>` time zone database (`tzdb`) and localized formatting, `std::print`, `<stacktrace>`, `<text_encoding>`, and string instantiations.

## Architecture & Data Flow

- In `piecewise_constant_distribution::param_type(_InputIteratorB, _InputIteratorB, _InputIteratorW)`, the loop must advance `__bbegin` and break on `__bbegin == __bend` before dereferencing `__wbegin`, because `__wbegin` has one fewer element than `[__bbegin, __bend)`. [F1]
- `normal_distribution::__generate_impl` must guard its pair-generation loop with `__f + 1 < __t` (not `__f != __t` or `__f < __t`) and handle a single-element tail (`__f != __t`) separately by saving the second variate in `_M_saved` and setting `_M_saved_available = true`. [F2]
- In `linear_congruential_engine::seed(_Sseq&)`, `__arr` must be sized `__k + 3` and populated over `[__arr, __arr + __k + 3)`, while the accumulation loop iterates `__j` over `[0, __k)` and reads `__arr[__j + 3]` to skip the first 3 generated words. [F3]
- `mersenne_twister_engine::_M_gen_rand` must split the state twist into `[0, __n - __m)`, `[__n - __m, __n - 1)`, and a final step for `__n - 1` pairing `_M_x[__n - 1]` with `_M_x[0]` and XORing with `_M_x[__m - 1]` before resetting `_M_p = 0`; `discard` must use strict `>` (`__z > state_size - _M_p`) before calling `_M_gen_rand()` so discarding the remaining buffer leaves `_M_p == state_size`. [F4, F5]
- In `std::subtract_with_carry_engine`, `default_seed` and the internal `std::linear_congruential_engine` in `seed(result_type)` must use `uint_least32_t` (not `result_type`), with `0u` as the default `seed` argument and `__value % 2147483563u` passed for non-zero seeds. [F37]
- In the count-based `param_type(size_t __nw, ...)` constructors of `discrete_distribution`, `piecewise_constant_distribution`, and `piecewise_linear_distribution`, `__nw == 0` must be normalized to `__n = 1` before dividing `(__xmax - __xmin) / __n` and reserving vector capacities; their `param_type` classes must also explicitly default copy construction/assignment without declaring move operations. [F10, F36]
- `std::chi_squared_distribution::param(const param_type& __param)` must update its internal `std::gamma_distribution` via `_M_gd.param(param_type{__param.n() / 2})` in addition to assigning `_M_param = __param`; in `std::poisson_distribution::operator()`, the `else if (__u <= __c5)` branch of the `mean() >= 12` rejection loop must assign both `__x = 1` and `__w = __178` (`1.0 / 78.0`). [F42, F43]
- Header inclusion order in `include/bits`: `ptr_traits.h` and `range_access.h` must include `<type_traits>` (or `<bits/move.h>`) before testing `__glibcxx_*` feature macros; `ptr_traits.h` must `#include <concepts>` when `__cplusplus > 201703L` before `__ptr_traits_ptr_to::pointer_to` tests `__cpp_lib_concepts`; `predefined_ops.h` must include `<bits/move.h>` and `range_access.h` must include `<bits/stl_iterator.h>` directly for standalone C++20 header-unit builds. [F11, F12, F13]
- In `to_chars` (`d2s.c`, `f2s.c`) and `generic_to_chars` (`generic_128.c`), mantissa digits after the leading digit are written at a `+1` offset (ending at `result[index + 2]`) to reserve `result[index + 1]` for `'.'`, and `index` must advance by `olength + 1` when `olength > 1` but by `1` when `olength == 1`; in `d2fixed_buffered_n` and `d2exp_buffered_n`, the `POW10_SPLIT_2` index `p` must subtract skipped leading zero blocks (`POW10_OFFSET_2[idx] + i - MIN_BLOCK_2[idx]`) and stay `< POW10_OFFSET_2[idx + 1]`; declarations in `src/c++17/ryu/` must not use `extern "C"` since they are `#include`d inside an anonymous namespace in `floating_to_chars.cc`. [F46, F47, F66]
- In `std::chrono::time_zone::_M_get_sys_info` (`tzdb.cc`), `result_index = i - infos.begin()` must be recorded before `infos.insert` invalidates iterator `i` and used to rotate and overwrite `infos[result_index]`; when partially expanding a rule-based `ZoneInfo`, it must try to finish on a DST `sys_info` (`info.save != 0min`) so later expansion starting at standard time (`info.save = 0min`) is valid. [F48, F70]
- In `tzdb.cc`: `ZoneInfo::m_pos` when non-zero must be `prefix.size() + 1` (with `m_buf` holding `prefix + ' ' + format`) so `rules()` slices `m_pos - 1u` bytes and `format()` starts at `m_buf.data() + m_pos`; `ZoneInfo::m_save` uses `minutes` while `at_time::time` and `Rule::save` use `sec32_t`, requiring `duration_cast<minutes>`; in `operator>>(istream&, on_day&)`, `day_of_month` must be checked with `d <= 31` and `day_of_week` populated with `weekday::c_encoding()` (`[0, 6]`) so `7` remains the invalid sentinel for `on_day::ok()`; and in `reload_tzdb` and `_S_init_tzdb`, `zones` and `links` must be sorted by name and `rules` stable-sorted by `Rule::name` before publishing the node. [F49, F58, F68, F69]
- In `std::__format::__encoding::conv` (`format.cc`), the `resize_and_overwrite` callback must resume `iconv` from `input.data() + input.size() - inbytesleft`, write at `p + written` with `n - written` bytes available, and return `written = outbytes - p` on `E2BIG` so already-converted UTF-8 bytes are preserved on buffer growth. [F54]
- In `to_valid_unicode` (`print.cc`) when `sizeof(_CharT) == 1`, an invalid multibyte prefix of `1 + seen` bytes must be overwritten in `s` as one `0xFF` byte followed by `seen` `0xFE` bytes and `needed = seen = 0` reset before reprocessing `*q`, so the final loop expands `0xFF` to `U+FFFD` and skips `0xFE`. [F50]

## Synchronization

- In `tzdb.cc`, `USE_ATOMIC_LIST_HEAD` and `USE_ATOMIC_SHARED_PTR` (for `_S_head_cache` and `_S_head_owner`) must be enabled only when `defined __GTHREADS && ATOMIC_POINTER_LOCK_FREE == 2`, and `time_zone::_Impl::RulesCounter` must only instantiate `atomic_signed_lock_free` when `__cpp_lib_atomic_lock_free_type_aliases` is defined and `_Tp::is_always_lock_free` holds, falling back to `list_mutex()` / `RulesCounter<void>` otherwise so `libstdc++.so` never depends on `libatomic`; when `!defined _GLIBCXX_HAS_GTHREADS`, `tzdb.cc` and `format.cc` must provide fallback `mutex` types (`__gnu_cxx::__mutex` under `__GTHREADS`, requiring `<ext/concurrence.h>` after `<mutex>`, or a no-op `mutex`), and `list_mutex()` must use a placement-new local static when `__GTHREAD_MUTEX_INIT` is undefined. [F64, F84, F85, F91]

## Object Lifetimes

- In `tzdb.cc`: every `tzdata_stream` constructor path must construct union member `fb` or `sb` via `std::construct_at` and pass its address to `this->init(...)`, and `rdbuf()` must never be repointed afterward since `~tzdata_stream()` calls `std::destroy_at(this->rdbuf())`; `time_zone::_M_get_sys_info` must hold `_M_impl->node.lock()` in a local `shared_ptr` across the entire function so concurrent `tzdb_list::erase_after` cannot destroy the owning `_Node` and its `rules` vector; and static globals `_S_the_list`, `_S_head_owner`, and `_S_head_cache` must use `[[gnu::init_priority(98)]]` (never `99`, reserved by `-fvtable-verify=std`) so they outlive user static objects under `-static-libstdc++`. [F75, F81, F82, F83]
- In `__format::__with_encoding_conversion` (`format.cc`), the newly allocated `__encoding` facet must be held in a `std::unique_ptr` across `locale(loc, facetp.get())` and released via `facetp.release()` immediately after; when restoring `loc2._M_impl->_M_names[0]`, it must be allocated as a distinct `new char[]` copy rather than aliasing `loc._M_impl->_M_names[0]`. [F77, F78]
- In `__locale_encoding` (`format.cc`) and `text_encoding::_M_is_environment` (`text_encoding.cc`), any non-zero `locale_t` from `::newlocale` must be freed via `::freelocale(loc)` only after all uses of `::nl_langinfo_l(CODESET, loc)` complete; in `demangle` and `stacktrace_entry::_Info::_M_set_desc`, the `__cxxabiv1::__cxa_demangle` buffer must be freed with `std::free` both on failure (`status != 0` in `demangle`) and after `_M_set` copies the string. [F76, F79]

## API Contracts

- In `bits/ptr_traits.h`, when `_Ptr::element_type` and a leading type parameter in `_SomeTemplate<_Tp, _Types...>` are both absent, `std::__ptr_traits_elem_t<_Ptr>` must resolve to `std::__undefined` and instantiate the empty `std::__ptr_traits_impl<_Ptr, __undefined>` specialization so `std::pointer_traits<_Ptr>` stays SFINAE-friendly; `std::__ptr_traits_ptr_to<_Ptr, _Elt, is_void<_Elt>::value>` must omit `pointer_to` when `_Elt` is `cv void` and, under `__cpp_lib_concepts`, constrain `pointer_to(element_type& __r)` with `requires requires { { pointer::pointer_to(__r) } -> convertible_to<pointer>; }`. [F17, F19]
- In `bits/random.h` and `bits/random.tcc`, engine `_Sseq&` constructors and `seed(_Sseq&)` methods must be constrained with `std::__detail::_If_seed_seq_for<_Sseq, _Engine, result_type>`; every distribution's `__generate_impl` must check `__glibcxx_function_requires(_ForwardIteratorConcept<_ForwardIterator>)`; and `seed_seq(_InputIterator, _InputIterator)` must guard `_M_v.reserve(std::distance(__begin, __end))` with `if _GLIBCXX17_CONSTEXPR (__is_random_access_iter<_InputIterator>::value)`. [F24, F26]
- In `src/c++17/ryu/`, `log2pow5` and `pow5bits` require `0 <= e <= 3528`, `log10Pow2` requires `0 <= e <= 1650`, and `log10Pow5` requires `0 <= e <= 2620`; `decimalLength9(v)` and `decimalLength17(v)` require `v < 10^9` and `v < 10^17`; `append_n_digits` and `append_d_digits` require `10^(olength-1) <= digits < 10^olength`; `append_c_digits` requires `count > 0` because `i < count - 1` is evaluated in `uint32_t`; and the fallback `uint128_t` (`uint128_t.h`) only supports `operator/` for divisors `5, 10` and `operator%` for divisors `2, 5, 10`. [F44, F52, F53, F74]
- `do_locate_zone` (`tzdb.cc`) must resolve `time_zone_link` targets iteratively through chained links using Floyd's tortoise-and-hare cycle detection and throw `std::runtime_error` on a cycle; on POSIX targets (`_GLIBCXX_HAVE_UNISTD_H` and not `_WIN32` or `__AVR__`), `__open_terminal(std::streambuf*)` returns a newly allocated `FILE*` via `::fdopen(::dup(fd), "w")` for a terminal `std::filebuf*`, which the caller must close with `fclose`. [F71, F80]

## Error Handling

- In `bits/random.tcc`, `operator>>` for `discrete_distribution`, `piecewise_constant_distribution`, and `piecewise_linear_distribution` must check `(__is >> __n)` before passing `__n` to `__detail::__extract_params` and only call `__x.param(...)` when all extractions succeed; their `param_type::_M_initialize` must check `__glibcxx_assert(__sum > 0)` before `__detail::__normalize`; and `normal_distribution` `operator>>` must update `__x._M_saved_available` and `__x.param(...)` whenever `!__saved_avail || (__is >> __x._M_saved)` holds. [F8, F27, F38]

## External Contracts

- In `std::__format::__with_encoding_conversion` and `__locale_encoding_to_utf8` (`format.cc`), localized `<chrono>` strings from a locale whose encoding is not `'C'`, `'*'`, `UTF8`, `ASCII`, or `unknown` must be converted to UTF-8 via the `__encoding` facet's `iconv` descriptor under `mx` lock. [F73]
- On targets disallowing weak undefined symbols (`__APPLE__`, `__hpux__`, or `__VXWORKS__` when `!defined(__RTP__)`), `tzdb.cc` must provide a weak definition of `__gnu_cxx::zoneinfo_dir_override()` returning `_GLIBCXX_ZONEINFO_DIR` (if defined) or `nullptr`, and `zoneinfo_file` must suppress `-Waddress` around `if (__gnu_cxx::zoneinfo_dir_override)`. [F86, F87]
- In `std::chrono::tzdb::current_zone()` (`tzdb.cc`): on `_AIX` it must query `std::getenv("TZ")` instead of `/etc/localtime`; when extracting a name from `/etc/localtime` (`std::distance(first, last) > 2`), it must look up the final component (`last->string()`) with `do_locate_zone` before prepending the parent component; on non-`_AIX` targets, if `/etc/localtime`, `/etc/timezone`, and `/var/db/zoneinfo` fail, it must fall back to `/etc/sysconfig/clock` (`"TIMEZONE="` or `"ZONE="`, stripping quotes); and on all targets it must fall back to `do_locate_zone(this->zones, this->links, "UTC")` before throwing. [F88, F89, F90]

## Known Pitfalls

- In `poisson_distribution` and `binomial_distribution` (`_M_initialize` and `operator()`), `#if _GLIBCXX_USE_C99_MATH_FUNCS` wraps `if (...) { ... } else` with the `if` body's closing brace inside `#if` so the code after `#endif` serves as both the `else` branch and the non-C99 fallback; local variables declared before `#if` (`__ret`, `__t`, `__p`, `__p12`, `__aurng`) must stay consistent across both paths, and all C99 math calls (`std::lgamma`, `std::round`, `std::nextafter`) and rejection-sampling `param_type` members (`_M_d1`, `_M_d2`, `_M_lfm`, `_M_scx`) must be guarded by `_GLIBCXX_USE_C99_MATH_FUNCS`. [F6, F7, F14]
- In `bits/random.h` and `bits/random.tcc`: `__detail::_Select_uint_least_t<__s, 1>::type` must only be used in `(_Tp2(__a) * __x + __c) % __m` expressions; `std::__detail::__mod<_Tp, __m, __a, __c>` must guard `std::__detail::_Mod` instantiation behind `if constexpr (__a == 0)` to avoid division by zero in `_Mod`'s default template arguments; `seed_seq::generate` must keep the `#ifndef __UINT32_TYPE__` fallback `struct _Up`; `normal_distribution::_M_saved` must be default-initialized (`= 0`); and `#if ! __cpp_inline_variables` out-of-line definitions of engine `static constexpr` members must be maintained in `random.tcc`. [F15, F16, F33, F35, F39]
- In `bits/ptr_traits.h`, `_Ptr::element_type` detection must stay in `std::__ptr_traits_elem` rather than a constrained partial specialization of `std::pointer_traits<_Ptr>` (which clashes with user specializations); `std::__ptr_traits_impl::rebind` must pass `std::__replace_first_arg<_Ptr, _Up>` (and `_Tp::template rebind<_Up>` wrapped in `__type_identity`) to `__detected_or_t` before accessing `::type`; in `std::to_address(const _Ptr& __ptr)`, when `pointer_traits<_Ptr>::to_address` is ill-formed and `is_base_of_v<__gnu_debug::_Safe_iterator_base, _Ptr>` holds, it must unwrap via `__ptr.base().operator->()`; and in `bits/range_access.h`, `std::begin`/`std::end` for `std::valarray<_Tp>` must be forward-declared before `std::cbegin`/`std::cend`. [F18, F20, F23, F31]
- In `tzdb.cc`: the outer `if` in `zoneinfo_file` must keep explicit braces around its nested `if` so the `#ifdef _GLIBCXX_ZONEINFO_DIR` `else` binds to the outer condition, and `#ifndef TZDB_DISABLED` in `tzdb_list::_Node::_S_init_tzdb` must close right after `__catch (const std::exception&)` before the fallback block; in `reload_tzdb` and `_S_read_leap_seconds`, the line string moved into `istringstream` must be moved back via `std::move(is).str()` at the end of the loop; `sec32_t` must be widened to `chrono::seconds` before adding to `sys_days` to avoid 32-bit overflow; and `filesystem::read_symlink` in `tzdb::current_zone()` must stay guarded by `defined(_GLIBCXX_HAVE_READLINK) && defined(_GLIBCXX_HAVE_SYS_STAT_H)` to avoid pulling in `fs_ops.o`. [F51, F57, F65, F67]
- In `text_encoding.cc`, `format.cc`, and `print.cc`, standard C++ headers must be included before testing `<bits/c++config.h>` macros (`_GLIBCXX_USE_NL_LANGINFO_L`, `_GLIBCXX_HAVE_ICONV`, `_GLIBCXX_HAVE_UNISTD_H`), and `<xlocale.h>` must be guarded by `#if __has_include(<xlocale.h>)`; in `std::__open_terminal` (`print.cc`), `fileno` must be parenthesized as `(::fileno)(f)` (for AIX), `::isatty` guarded by `defined _GLIBCXX_HAVE_UNISTD_H && ! defined __AVR__`, and `dynamic_cast` on `std::streambuf*` guarded by `defined __cpp_rtti`. [F61, F62, F63, F93]
