# libcpp

This unit encompasses shared top-level C/C++ headers (`include`) and the `libiberty` portability and utility library used across GCC, GDB, binutils, libctf, and libgomp. It defines debug and type format schemas (DWARF, CTF, BTF, GDB index), C/C++ front-end oracle interfaces for GDB, compiler portability macros, core data structures (`htab`, `fibheap`, `dyn_string`), target-independent floating-point descriptors (`floatformat`), command-line argument parsing (`buildargv`/`expandargv`), and symbol demanglers for C++, D, Java, and Ada.

## Architecture & Data Flow

- In `struct demangle_component` (`include/demangle.h`, `libiberty/cp-demangle.c`), `u.s_unary_num.sub` must stay first in `s_unary_num` at the same offset as `u.s_binary.left` (`d_left`), and tree walks (`d_count_templates_scopes`, `d_find_pack`, `d_dump`) must dispatch `DEMANGLE_COMPONENT_CTOR`, `DEMANGLE_COMPONENT_DTOR`, `DEMANGLE_COMPONENT_EXTENDED_OPERATOR`, and leaf kinds before accessing `d_left (dc)` or `d_right (dc)`. [F29, F97]
- Every `struct demangle_component` initializer (`d_make_empty`, `cplus_demangle_fill_*`) must zero `d_printing` and `d_counting`, and `d_print_comp` and `d_count_templates_scopes` must reject nodes with `d_printing > 1`, `d_counting > 1`, or `dpi->recursion > MAX_RECURSION_COUNT`; `cplus_demangle_init_info` sizes `di->num_comps` to `2 * len` and `di->num_subs` to `len` without dynamic reallocation, so `d_make_empty` and `d_add_substitution` must reject indices `>= di->num_comps` or `di->num_subs`, and `d_demangle_callback` must bound `di.num_comps` by `DEMANGLE_RECURSION_LIMIT` when `DMGL_NO_RECURSE_LIMIT` is unset. [F61, F96]
- `d_count_templates_scopes` must mirror `d_print_comp` by counting every `DEMANGLE_COMPONENT_TEMPLATE` in `dpi->num_copy_templates` and every `d_save_scope` trigger in `dpi->num_saved_scopes`; in `cplus_demangle_print_callback`, `#ifdef CP_DYNAMIC_ARRAYS` VLA dimensions must clamp both counts to at least 1 (`> 0 ? ... : 1`). [F54, F104]
- Before pushing `DEMANGLE_COMPONENT_TEMPLATE` onto `dpi->templates`, `d_print_comp_inner` must hoist any `DEMANGLE_COMPONENT_CONSTRAINTS` wrapper off `d_right (typed_name)` so `d_right (dpi->templates->template_decl)` is a `DEMANGLE_COMPONENT_TEMPLATE_ARGLIST` for `d_lookup_template_argument`; C++ conversion operators must use `DEMANGLE_COMPONENT_CONVERSION` while unary typecasts use `DEMANGLE_COMPONENT_CAST`, because `d_print_conversion` pushes `dpi->current_template` onto `dpi->templates` whereas `d_print_cast` must not. [F42, F100]
- In `d_print_comp_inner`, resolving a non-lambda `DEMANGLE_COMPONENT_TEMPLATE_PARAM` must temporarily pop `dpi->templates` to `dpi->templates->next` while recursively printing the argument and restore it afterward; when `dpi->lambda_tpl_parms != 0` inside `DEMANGLE_COMPONENT_LAMBDA`, it must not call `d_lookup_template_argument` or `d_find_pack`, instead resolving indices `< dpi->lambda_tpl_parms - 1` against `d_left (dpi->templates->template_decl)` or printing `auto:<index+1>`. [F101, F102]
- In `libiberty/cp-demangle.c`, `d_prefix` must only call `d_add_substitution` when `substable` is non-zero, and `d_unresolved_name` must pass `substable = 0` to `d_prefix` and set `di->unresolved_name_state = -1` so `d_demangle_callback` retries with `di.unresolved_name_state = 0` if parsing fails; subroutines parsing suffix attachments after a base name (`d_template_args_1`, `d_abi_tags`) must save and restore `di->last_name` for `d_ctor_dtor_name`, and in `d_unqualified_name`, `'F'` must wrap the unqualified name in `DEMANGLE_COMPONENT_FRIEND` before attaching `scope` with `DEMANGLE_COMPONENT_QUAL_NAME`. [F103, F111, F115]
- In `d_print_comp_inner`, `DEMANGLE_COMPONENT_BINARY` must verify `d_right (dc)->type == DEMANGLE_COMPONENT_BINARY_ARGS` (and wrap `">"` expressions in `'('` and `')'`) and `DEMANGLE_COMPONENT_TRINARY` must verify `DEMANGLE_COMPONENT_TRINARY_ARG1` and `DEMANGLE_COMPONENT_TRINARY_ARG2` before inspecting operands; for `ARGLIST` / `TEMPLATE_ARGLIST`, `d_print_flush (dpi)` must be called when `dpi->len >= sizeof (dpi->buf) - 2` before appending `", "` so `dpi->len -= 2` can safely erase it. [F52, F71, F99]
- In `cp-demangle.c`, `d_number` must check `ret > ((INT_MAX - (peek - '0')) / 10)` and return `-1` on overflow; in `d_operator_name`, `cplus_demangle_operators` must stay sorted by two-char `code` with `high` initialized to `ARRAY_SIZE - 1` to exclude the `{ NULL, NULL, 0, 0 }` sentinel; in `include/demangle.h`, `gnu_v3_complete_object_ctor..gnu_v3_object_ctor_group` and `gnu_v3_deleting_dtor..gnu_v3_object_dtor_group` bound the valid ranges in `cplus_demangle_fill_ctor` and `cplus_demangle_fill_dtor`. [F43, F49, F58]
- In `libiberty/d-demangle.c`, `dlang_decode_backref` must check `val > (ULONG_MAX - 25) / 26` and `(long) val <= 0`, `dlang_backref` must verify `refpos <= qpos - info->s` before subtracting, and `dlang_type_backref` must check `mangled - info->s < info->last_backref`, lower `info->last_backref` to `mangled - info->s` before recursing into `dlang_function_type` or `dlang_type`, and restore `save_refpos` afterward. [F56, F64]
- In `d-demangle.c`, `dlang_number` must reject `val > (UINT_MAX - digit) / 10`, and callers slicing length-prefixed substrings (`dlang_symbol_backref`, `dlang_identifier`, `dlang_template_args`) must verify `strlen(endptr) >= len` before advancing by `len`; in `dlang_parse_template`, if `len != TEMPLATE_LENGTH_UNKNOWN`, `(unsigned long) (mangled - start)` must equal `len` after `dlang_template_args`; in `dlang_lname`, suffixes `__initZ`, `__vtblZ`, `__ClassZ`, `__InterfaceZ`, and `__ModuleInfoZ` matched with `strncmp (..., len + 1)` must advance `mangled` by `len` (leaving `'Z'`); in `dlang_parse_qualified`, `'0'` anonymous markers must be skipped via `continue` before incrementing `n` or appending `'.'`. [F57, F63, F72, F114]
- In `struct floatformat`, `sign_start`, `exp_start`, and `man_start` use big-endian bit numbering (bit 0 = MSB after byte concatenation per `byteorder`), `exp_bias` must be signed `int`, and `exp_nan` holds the raw biased exponent; when `intbit == floatformat_intbit_yes`, the explicit integer bit is at `man_start` inside `man_len` (and in `floatformat_i387_ext_is_valid`, must be 0 iff `exponent == 0`), whereas when `floatformat_intbit_no`, `floatformat_to_double` seeds `dto = ldexp (1.0, exponent)` and `floatformat_from_double` strips bit 31 (`mant_long &= 0x7fffffff`) and decrements `mant_bits` on the first chunk. [F36, F37, F105, F108]
- For composite split `floatformat`s (IBM double-double), `split_half` points to the component format while `sign_start`..`intbit` on the outer struct describe the first half; in `floatformat_ibm_long_double_is_valid`, if the high double is infinity (`top_exp == hfmt->exp_nan`), zero, or denormal (`top_exp == 0`), the low double at `ufrom + 8` must have `bot_exp == 0` and zero mantissa, and if finite normal, the low double must not exceed 0.5 ULP (`top_exp - 53`), with the high double's LSB (`hfmt->man_start + hfmt->man_len - 1`) required to be 0 on a 0.5 ULP tie. [F38, F106, F107]
- In `buildargv`, whitespace splits arguments only when `squote`, `dquote`, and `bsquote` are 0, and `'\\'` sets `bsquote` only when `!squote` and either `!dquote` or followed by `'$'`, `` '`' ``, `'"'`, `'\\'`, or `'\n'`; in `expandargv`, the `while (++i < *argcp)` loop starts at `i = 0` and must decrement `--i` after splicing `file_argc` elements at `i` and updating `*argcp += file_argc - 1`. [F51, F66]

## Object Lifetimes

- A `struct dyn_string` initialized via `dyn_string_init` must have its buffer freed via `free (ds.s)` (`dyn_string_buf (&ds)`) rather than `dyn_string_delete` or `dyn_string_release`, which both `free (ds)`; after `dyn_string_release (ds)`, the caller owns the returned `char *` and must not pass `ds` to `dyn_string_delete` or any `dyn_string_*` function. [F20, F21]
- `fibheap_union (heapa, heapb)` frees one input `struct fibheap` header (`heapa` if `heapa->root == NULL`, else `heapb`), so callers must only use or delete the returned `fibheap_t`; `fibheap_delete`, `fibheap_extract_min`, and `fibheap_delete_node` never free user `void *data` pointers stored in nodes; in `struct htab`, `del_f` (`htab_del`) is invoked by `htab_delete`, `htab_empty`, `htab_remove_elt`, `htab_remove_elt_with_hash`, and `htab_clear_slot`, but NOT when a caller overwrites a non-empty `*slot` returned by `htab_find_slot` or `htab_find_slot_with_hash`. [F22, F23, F24]
- Callers of `cplus_demangle_v3_components` must free the component tree by passing `*mem` (not the returned `struct demangle_component *`) to `free`, and only when `cplus_demangle_v3_components` returns non-NULL (or `mem` was pre-initialized to `NULL`); in `cplus_demangle_print_callback`, `d_demangle_callback`, and `is_ctor_or_dtor`, the `#ifdef CP_DYNAMIC_ARRAYS` VLA declarations (`scopes`, `temps`, `comps`, `subs`) and `#else` `alloca` fallback must stay inside the same `{ ... }` block enclosing the entire demangling or printing traversal. [F26, F53]
- In `libiberty/d-demangle.c`, every local `string` initialized with `string_init` that is not returned to the caller must be freed with `string_delete` before returning; in `expandargv`, before splicing `file_argv` into `*argvp` at `i`, `*argvp` must be cloned with `dupargv` if `*argvp == original_argv`, `(*argvp)[i]` must be freed, and after copying `file_argv` pointers into `*argvp`, only `free (file_argv)` (never `freeargv (file_argv)`) may be called; in `buildargv`, `copybuf` must be heap-allocated via `xmalloc(strlen(input) + 1)` and freed before returning (not `alloca`). [F65, F85, F90]

## API Contracts

- In `include/gcc-c-fe.def` and `include/gcc-cp-fe.def`, `build_vla_array_type` requires `UPPER_BOUND_NAME` to name a local variable holding the inclusive upper bound (`size - 1`), whereas `build_array_type` takes the element count `NUM_ELEMENTS` (or `-1`); `get_function_parameter_decl` indexes explicit user parameters from `0` (skipping artificial parameters) and uses `INDEX` `-1` for `this`; `start_template_decl` is popped by `build_decl`, `start_class_type` and `start_closure_class_type` are popped by `finish_class_type`, and only `push_namespace`, `push_class`, and `push_function` are popped by `pop_binding_level`. [F3, F4, F5]
- In `include/gcc-cp-interface.h` and `include/gcc-cp-fe.def`, `gcc_cp_template_args::kinds[i]` must match the active union member of `elements[i]` (`GCC_CP_TPARG_VALUE`, `GCC_CP_TPARG_CLASS`, `GCC_CP_TPARG_TEMPL`, `GCC_CP_TPARG_PACK`); `GCC_CP_FLAG_PURE_VIRTUAL_FUNCTION` and `GCC_CP_FLAG_FINAL_VIRTUAL_FUNCTION` require `GCC_CP_FLAG_VIRTUAL_FUNCTION`; and cdtor base declarations via `build_decl` (`GCC_CP_FLAG_SPECIAL_FUNCTION` with `NAME` starting with `'C'` or `'D'`) require null/zero `SUBSTITUTION_NAME` and `ADDRESS` (clones use `define_cdtor_clone`). [F30, F32, F33]
- Callers of `struct d_info` helpers in `cp-demangle.h` must never call `d_peek_next_char (di)` when `d_peek_char (di) == '\0'`, never call `d_check_char (di, '\0')`, and never pass `i` to `d_advance (di, i)` past the terminating `'\0'`; before returning `string.b` in `dlang_demangle` or passing `name.b` to `dlang_value` in `dlang_template_args`, the caller must reserve one byte with `string_need (&s, 1)` and set `*s.p = '\0'`. [F50, F86]
- `buildargv` must run its outer `do`-`while` loop at least once for non-NULL `input` so empty or whitespace-only strings return an allocated vector with `argv[0] == NULL`; `writeargv` must escape whitespace, `'\\'`, `'\''`, and `'"'` with `'\\'` and emit `""""` for empty arguments; `reconcat` must not free `optr` until after `vconcat_length` and `vconcat_copy` finish reading all variadic arguments; callers checking if two paths refer to the same file must use `canonical_filename_eq` (`include/filenames.h`) rather than `filename_cmp` or `filename_eq`. [F45, F67, F68, F93]

## Error Handling

- Callers of `gcc_base_vtable` methods `set_arguments`, `set_triplet_regexp`, and `set_driver_filename` must free any non-NULL returned error string; in `libiberty/cp-demangle.c`, `d_growable_string_resize` frees `dgs->buf` and sets `dgs->allocation_failure = 1` on `realloc` failure, while `cplus_demangle_print` and `d_demangle` must call `free (dgs.buf)` when the callback returns 0; in `cplus_demangle_v3_components`, `di.subs` is always freed before return, and `di.comps` must be freed when `dc == NULL`; in `ada_demangle`, every failure path after `demangled = XNEWVEC (char, len0)` must jump to `unknown:` to free `demangled`. [F27, F87, F89, F94]

## External Contracts

- In `struct gcc_base_vtable`, `struct gcc_c_fe_vtable` (`include/gcc-c-fe.def`), and `struct gcc_cp_fe_vtable` (`include/gcc-cp-fe.def`), `version` must remain first and new methods must only be appended at the end while keeping deprecated `*_v0` slots in place; in `include/dwarf2.def`, each section opens with `DW_FIRST_<KEY>` and closes with `DW_END_<KEY>`, using `DW_<KEY>` for preferred names and `DW_<KEY>_DUP` for duplicate-value aliases. [F2, F39]
- In `include/ctf.h` (v2/v3), type sizes `> CTF_MAX_SIZE` (`0xfffffffe`, `CTF_MAX_SIZE_V1` in v1) must use `ctf_type_t` with `ctt_size = CTF_LSIZE_SENT` (`0xffffffff`, `CTF_LSIZE_SENT_V1` in v1) and the 64-bit size in `ctt_lsizehi`/`ctt_lsizelo`, structs reaching `CTF_LSTRUCT_THRESH` (`536870912` bytes, `CTF_LSTRUCT_THRESH_V1` in v1) must store all members as `ctf_lmember_t` (`ctf_lmember_v1_t` in v1) with 64-bit bit offsets in `ctlm_offsethi`/`ctlm_offsetlo`, and `ctf_stype`/`ctf_type` union changes must update both `#ifndef __GNUC__` (`_u` + macros) and `#else` branches. [F1, F7, F8]
- In `include/btf.h`, when `BTF_INFO_KFLAG(info)` is 1 on a struct/union, `btf_member.offset` packs the 8-bit bitfield size in bits 24..31 and 24-bit bit offset in `0x00ffffff` (vs 32-bit offset when `kflag == 0`); in `include/gdb/gdb-index.h`, `*_SET_VALUE` macros OR bits via `|=` without clearing prior values, and when `GDB_INDEX_SYMBOL_KIND_VALUE(cu_index)` is `GDB_INDEX_SYMBOL_KIND_NONE` (`0`), bits 24..31 must be 0. [F6, F10]
- In `__cxa_demangle`, `mangled_name == NULL` or `output_buffer != NULL && length == NULL` must set `*status = -3` and return `NULL`, while a failed `d_demangle` sets `*status = -1` if `alc == 1` and `-2` otherwise; on success with `output_buffer != NULL`, it must copy `demangled` into `output_buffer` and `free (demangled)` if `strlen (demangled) < *length`, or else `free (output_buffer)`, set `*length = alc`, and return `demangled`. [F88, F109]

## Known Pitfalls

- Internal `libctf` code must call `ctf_type_isparent`/`ctf_type_ischild` and never use `CTF_V2_TYPE_ISPARENT`, `CTF_V2_TYPE_ISCHILD`, `CTF_V2_TYPE_TO_INDEX`, or `CTF_V2_INDEX_TO_TYPE` (or `CTF_V1_*`), because v1 dicts upgraded in memory to v2 retain the v1 `CTF_MAX_PTYPE_V1` boundary; in `libiberty/cp-demangle.c`, callers of `d_compact_number` that add 1 to the 0-based index (e.g., `'fp'` in `d_expression_1` calling `d_make_function_param`) must reject both `-1` and `INT_MAX` before incrementing, `d_lambda` must not call `d_add_substitution` on `DEMANGLE_COMPONENT_LAMBDA`, and in `d_print_comp_inner` (`case DEMANGLE_COMPONENT_UNARY`), unary operators requiring parenthesized operands (`"st"`, `"nx"`) must explicitly print `'('` and `')'` around `d_print_comp` instead of using `d_print_subexpr`; in `include/filenames.h`, `HAVE_DOS_BASED_FILE_SYSTEM` and DOS path macros must not be enabled when `__CYGWIN__` is defined. [F9, F14, F59, F112, F116]
