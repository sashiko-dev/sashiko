# omp-sanitizer

This unit implements AddressSanitizer (ASan) and Hardware-assisted AddressSanitizer (HWASan) GIMPLE/RTL instrumentation (`gcc/asan.cc`, `gcc/asan.h`), OpenMP/OpenACC built-ins and runtime API helpers (`gcc/omp-builtins.def`, `gcc/omp-api.h`), and shared OpenMP/OpenACC directive processing (`gcc/omp-general.cc`, `gcc/omp-general.h`).

## Architecture & Data Flow

- In `asan_emit_stack_protection`, `offsets` has `length` reverse-ordered gap offsets and `decls` has `length / 2 - 1` elements: the description loop (`l = length - 2`) indexes `decls[l / 2 - 1]` with size `offsets[l - 1] - offsets[l]`, while the epilogue loop (`l = length, l > 2`) indexes `decls[l / 2 - 2]` with size `offsets[l - 3] - offsets[l - 2]`. When `alignb > ASAN_RED_ZONE_SIZE`, add `ASAN_RED_ZONE_SIZE` to `adjusted_frame_size` if `crtl->stack_protect_guard` is set, and recompute `use_after_return_class` from `asan_frame_size + base_align_bias` (disabling if `> 10`). [F1, F51]
- In `asan_expand_mark_ifn`, if the `ADDR_EXPR` operand of `IFN_ASAN_MARK` is a `COMPONENT_REF` with `DECL_NONLOCAL_FRAME (TREE_OPERAND (decl, 0))`, unwrap `decl` to `TREE_OPERAND (decl, 0)` before asserting `VAR_DECL` and inserting into `asan_handled_variables`. Direct stores via `asan_store_shadow_bytes` require `tree_fits_uhwi_p (len) && tree_to_uhwi (len) <= param_use_after_scope_direct_emission_threshold` (falling back to poison/unpoison builtins), and `asan_emit_stack_protection` only unpoisons variable slots in `asan_handled_variables`. [F6, F21, F22]
- On `STRICT_ALIGNMENT` targets, `build_check_stmt` must clear `is_scalar_access` whenever a power-of-two access with `size_in_bytes > 1` has `align < size_in_bytes * BITS_PER_UNIT`, and `asan_expand_mark_ifn` must restrict direct multi-byte shadow stores to sizes `<= shadow_align`. `build_check_stmt` must also call `unshare_expr` on `base` and non-null `len` before evaluating them into SSA names. [F20, F43]
- In `instrument_derefs`, guard `DECL_THREAD_LOCAL_P (inner)` with `VAR_P (inner)` (`inner` may be `RESULT_DECL`); if `inner` is a `DECL_P` in `current_function_decl`, call `mark_addressable (inner)` if `!TREE_ADDRESSABLE (inner)` before `build_fold_addr_expr (t)`. For a `COMPONENT_REF` whose field has `DECL_BIT_FIELD_REPRESENTATIVE`, recurse on that representative field, or return if `!multiple_p (bitpos, BITS_PER_UNIT)`. Both `instrument_derefs` and `asan_protect_global` must skip non-generic address spaces (`!ADDR_SPACE_GENERIC_P`). [F18, F19, F35, F52]
- For non-builtin, non-internal calls with `gimple_store_p (stmt)`, `has_stmt_been_instrumented_p` and `maybe_instrument_call` must skip caller-side LHS store instrumentation when `aggregate_value_p` holds, while `instrument_derefs` must not skip `RESULT_DECL` accesses as local variables when `aggregate_value_p (inner, current_function_decl)` holds. In `maybe_instrument_call`, if `gimple_call_noreturn_p (stmt)` holds, return `false` without `BUILT_IN_ASAN_HANDLE_NO_RETURN` for `IFN_ABNORMAL_DISPATCHER`, `BUILT_IN_UNREACHABLE`, `BUILT_IN_UNREACHABLE_TRAP`, or `BUILT_IN_TRAP`. [F28, F53]
- `transform_statements` must call `empty_mem_ref_hash_table ()` at extended basic block boundaries (when `prev_bb` after skipping newly created blocks with `index >= saved_last_basic_block` is not `last_bb`) and after any uninstrumented call where `!nonfreeing_call_p (s)` or `asan_mark_p (s, ASAN_MARK_POISON)`. When `asan_expand_poison_ifn` expands a `poisoned_var` used in a `gphi`, skip `EDGE_ABNORMAL` edges, insert a copy of the report call on each non-abnormal edge via `gsi_insert_seq_on_edge`, and set `*need_commit_edge_insert = true`. [F30, F33]
- In `asan_finish_file`, the counting pass (`FOR_EACH_DEFINED_VARIABLE` and `count_string_csts`) must use the exact same `TREE_ASM_WRITTEN` and `asan_protect_global` predicates as the emission pass (`asan_add_global` and `add_string_csts`), and `asan_protect_global` must exclude artifacts created by `asan_add_global`. `asan_finish_file` and `hwasan_finish_file` must clear `SANITIZE_ADDRESS` / `SANITIZE_HWADDRESS` in `flag_sanitize` while emitting global descriptors and calling `cgraph_build_static_cdtor`, and in `asan_add_global` when `in_lto_p` is true, derive the module name from `get_ultimate_context ((const_tree)decl)` (or `aux_base_name` if null). [F10, F25, F56]
- In `asan_emit_stack_protection`, `asan_emit_allocas_unpoison`, `hwasan_emit_prologue`, and `hwasan_emit_untag_frame`, convert `Pmode` addresses to `ptr_mode` via `convert_memory_address` before `emit_library_call` and back to `Pmode` for results. `handle_builtin_stack_restore` must pass `restored_stack` directly to `BUILT_IN_ASAN_ALLOCAS_UNPOISON` or `IFN_HWASAN_ALLOCA_UNPOISON` at GIMPLE time, deferring `virtual_stack_dynamic_rtx - stack_pointer_rtx` (`STACK_DYNAMIC_OFFSET`) to RTL expansion. [F40, F48]
- `asan_clear_shadow` requires `(len & 3) == 0` and must reject any `clear_storage` sequence containing a `CALL_P`, falling back to an inline `SImode` loop. `asan_redzone_buffer::flush_redzone_payload` requires `WORDS_BIG_ENDIAN == BYTES_BIG_ENDIAN` and `m_prev_offset - m_original_offset` to be a multiple of `ASAN_RED_ZONE_SIZE` (32 bytes). [F41, F42]
- Every `hwasan_stack_var` in `hwasan_record_stack_var` must have `nearest_offset` and `farthest_offset` ordered (`known_ge` or `known_le`) and aligned to `HWASAN_TAG_GRANULE_SIZE`. `hwasan_emit_prologue` must call `hwasan_tagged_stack_vars.truncate (0)` before returning so `hwasan_record_frame_init`'s `is_empty ()` assertion holds. `hwasan_truncate_to_tag_size` requires a `QImode` `tag` and masks it when `HWASAN_TAG_SIZE < GET_MODE_PRECISION (QImode)`. [F13, F45, F46]
- In `omp-builtins.def`, do not reorder or insert inside the `BUILT_IN_GOMP_LOOP_*_START` (and `*_NEXT` / `*_ULL_*`) or `BUILT_IN_GOMP_PARALLEL_LOOP_*` blocks because `omp-expand.cc` indexes them by offset from `BUILT_IN_GOMP_LOOP_STATIC_START` and `BUILT_IN_GOMP_PARALLEL_LOOP_STATIC`. [F49]
- In `omp_extract_for_data`, the loop over `cnt` (`fd->ordered ? fd->ordered : fd->collapse`) populates `loops[i]` and `iter_type` for all `i < cnt`, but must skip `collapse_count` accumulation once `i >= fd->collapse`; when widening `iter_type`, call `build_bitint_type` rather than `build_nonstandard_integer_type` if either `iter_type` or `TREE_TYPE (loop->v)` is `BITINT_TYPE` (also valid in `omp_adjust_for_condition`). [F60, F87]
- In `omp_apply_tile`, wrap `ub` and `step` in `save_expr` (as `omp_device_num_check` must wrap a non-constant, non-API-call `*device_num`), and when `minmax_needed` is true, convert inclusive `LE_EXPR`/`GE_EXPR` bounds `ub` to exclusive bounds by adding `+1`/`-1`. When `omp_maybe_apply_loop_xforms` splices `inner_for_stmt` into `for_stmt` at the first null slot `i`, index `inner_for_stmt` with `j` and `for_stmt` with `i + j`. `find_combined_omp_for` and `find_nested_loop_xform` must handle `CLEANUP_POINT_EXPR` identically to `TRY_FINALLY_EXPR`. [F58, F59, F81, F83]
- `make_trait_selector` prepends a `TREE_LIST` node with `TREE_PURPOSE == OMP_TS_SCORE_NODE` to `TREE_VALUE (ts)` when a score is present, so callers must read `OMP_TS_PROPERTIES (ts)` rather than `TREE_VALUE (ts)`. `struct GTY(()) omp_variant` and score helpers (`omp_context_compute_score`, `omp_construct_traits_match`) must use `score_wide_int` (`generic_wide_int <fixed_wide_int_storage <1024> >`) rather than `widest_int` or `wide_int`. [F80, F86]
- `omp_mark_declare_variant` must `unshare_expr (construct)` in `"omp declare variant variant"`, and `omp_complete_construct_context` must `copy_node` each trait selector from it before chaining onto `construct_context` and set `*completep = false` for `"omp declare simd"` functions when `(cfun->curr_properties & PROP_gimple_any) == 0`. `omp_maybe_offloaded` must return `false` once `cfun && cfun->after_inlining` holds, and `omp_dynamic_cond` must set `cgraph_node::get (cfun->decl)->has_omp_variant_constructs = 1` when building `OMP_TARGET_DEVICE_MATCHES` with `PROP_gimple_any` set. [F82, F89, F90]
- In `omp_construct_simd_compare`, call `v->safe_grow_cleared (argno + 1, true)` when `argno >= v->length ()` before indexing `data_sharing` or `aligned`. In `omp_context_selector_props_compare`, compare anonymous expression properties (`OMP_TP_NAME (p1) == NULL_TREE`) by `integer_zerop` for `OMP_TRAIT_USER_CONDITION` and by `tree_int_cst_compare` for `OMP_TRAIT_DEVICE_NUM`, returning `2` if either is not an `INTEGER_CST`. [F64, F98]
- `oacc_verify_routine_clauses` distinguishes OpenMP `declare target` from OpenACC `routine` on `fndecl` via `TREE_VALUE (attr)` of `"omp declare target"` (`NULL_TREE` for `#pragma omp declare target`, non-null clause list for `#pragma acc routine`). In `omp_addr_tokenizer`, `omp_parse_component_selector` must stop when `TREE_CODE (TREE_TYPE (expr)) == REFERENCE_TYPE`, `omp_parse_ref` and `omp_parse_pointer` require `integer_zerop (TREE_OPERAND (expr, 1))` on `MEM_REF`, and `omp_parse_pointer` must apply `STRIP_NOPS` after unwrapping `INDIRECT_REF`, `MEM_REF`, `COMPOUND_EXPR`, or `POINTER_PLUS_EXPR`. [F73, F77, F93]

## Object Lifetimes

- `set_sanitized_sections` must `free` every `char *` in `sanitized_sections` before `truncate (0)`. `free_mem_ref_resources` must both `delete asan_mem_ref_ht` (setting it to `NULL`) and call `asan_mem_ref_pool.release ()`. Deleting `asan_handled_variables` or `asan_used_labels` in `asan_emit_stack_protection` or `hwasan_record_frame_init` must immediately set the pointer to `NULL`. [F11, F12, F14]
- Before `gsi_replace (iter, poison_call, false)` on `IFN_ASAN_POISON` in `asan_expand_poison_ifn`, detach `poisoned_var` via `SSA_NAME_IS_DEFAULT_DEF (poisoned_var) = true` and `SSA_NAME_DEF_STMT (poisoned_var) = gimple_build_nop ()`. [F31]
- Functions returning `vec<struct omp_variant>` from a local `auto_vec` (`omp_get_dynamic_candidates`, `omp_declare_variant_candidates`, `omp_metadirective_candidates`) must return `.copy ()` rather than `to_vec_legacy ()`. Token vectors spliced into `addr_tokens` in `omp_parse_structured_expr`, `omp_parse_array_expr`, and `omp_parse_expr` must be `auto_vec<omp_addr_token *>` (not `auto_delete_vec` or raw `vec`). [F68, F71]

## API Contracts

- `asan_protect_global` must reject any `VAR_DECL` where `DECL_SIZE (decl) == 0`, `TREE_CODE (DECL_SIZE_UNIT (decl)) != INTEGER_CST`, or `!valid_constant_size_p (DECL_SIZE_UNIT (decl))`, and requires `DECL_RTL_SET_P (decl)` unless `ignore_decl_rtl_set_p` is true. `sanitize_flags_p` and `sanitize_coverage_p` in `gcc/asan.h` must check `fn != NULL_TREE` before reading `DECL_ATTRIBUTES (fn)`. [F9, F17, F23]
- When `flag_sanitize & SANITIZE_OBJECT_SIZE` is set, `initialize_sanitizer_builtins` must register both `BUILT_IN_OBJECT_SIZE` and `BUILT_IN_DYNAMIC_OBJECT_SIZE`. HWASan entry points that skip `asan_init_shadow_ptr_types` (`asan_instrument` when `hwasan_sanitize_p ()` and `hwasan_finish_file`) must call `initialize_sanitizer_builtins ()`. [F37, F50]
- When `before_p == true`, `maybe_create_ssa_name`, `maybe_cast_to_ptrmode`, `build_check_stmt`, `maybe_instrument_call`, and `asan_expand_mark_ifn` must call `gsi_safe_insert_before` rather than `gsi_insert_before`, and `build_check_stmt` must pass its caller's `gimple_stmt_iterator *iter` directly rather than a local copy. `create_cond_insert_point` must add `then_bb` to `cond_bb->loop_father` (setting `LOOPS_NEED_FIXUP`), set `cond_bb` edge probabilities and `then_bb->count`, update `CDI_DOMINATORS`, and set `*iter = gsi_start_bb (fallthru_bb)`. [F26, F27, F32]
- `omp_adjust_for_condition` normalizes `*cond_code` to `LT_EXPR` or `GT_EXPR` by adjusting `*n2` by `+1`/`-1` (scaled by `TYPE_SIZE_UNIT (TREE_TYPE (TREE_TYPE (v)))` for pointers) on `LE_EXPR`/`GE_EXPR`, and mapping `NE_EXPR` from `step` without modifying `*n2`. In `gcc/omp-general.h`, keep `TREE_*` accessors (`OMP_TSS_ID`, `OMP_TS_SCORE`, `OMP_TS_PROPERTIES`) as macros because `fortran/parse.cc` includes `omp-general.h` without `tree.h`. [F57, F67]
- On the host (`#ifndef ACCEL_COMPILER`), `omp_context_name_list_prop` requires `TREE_STRING_LENGTH (val) == strlen (ret) + (lang_GNU_Fortran () ? 0 : 1)`. `omp_check_optional_argument (decl, true)` returns a separate hidden `BOOLEAN_TYPE` presence argument for Fortran `VALUE` optionals rather than a pointer; `omp_mappable_type` only checks `type != error_mark_node && COMPLETE_TYPE_P (type)`; and `omp_build_component_ref` must copy `TREE_THIS_VOLATILE` and `TREE_READONLY` from `field`. [F72, F74, F79, F91]
- `omp_max_vf` must return `1` when `!optimize`, `optimize_debug`, `!flag_tree_loop_optimize`, or `!flag_tree_loop_vectorize && OPTION_SET_P (flag_tree_loop_vectorize)`, and when `ENABLE_OFFLOADING && offload` with `"amdgcn"` in `OFFLOAD_TARGET_NAMES`, return `ordered_max (poly_uint64 (64), omp_max_vf (false))`. All VF comparisons must use `ordered_max` on `poly_uint64`, and the `preferred_simd_mode (QImode)` fallback must check `GET_MODE_CLASS (vqimode) == MODE_VECTOR_INT`. [F88, F94]

## Error Handling

- `asan_emit_stack_protection` must check `if (seen_error ()) return NULL;` before inspecting frame offsets or emitting RTL. When `stmt_can_throw_internal (cfun, call)` is true on the ASan path in `handle_builtin_alloca`, return early if `!lhs`, replace `call` via `gsi_replace (iter, gg, true)` after clearing its LHS, and insert all follow-up statements on `find_fallthru_edge (gsi_bb (*iter)->succs)`. [F7, F29]
- In `omp_construct_simd_compare`, verify `tree_fits_uhwi_p` on both `e0` and `e1` before calling `tree_to_uhwi`. In `omp_get_dynamic_candidates`, every abort path must call `variants.truncate (0)` before `return variants.copy ()`. [F65, F69]
- For `OMP_TRAIT_INVALID`, `omp_check_context_selector` skips it, `omp_mark_declare_variant` returns early, `omp_context_selector_matches` returns `0`, and `omp_context_selector_set_compare` returns `2`; when `directive != OMP_CTX_METADIRECTIVE`, `omp_check_context_selector` must reject `PARM_DECL` references in `OMP_TRAIT_DEVICE_NUM` and `OMP_TRAIT_USER_CONDITION` via `expr_uses_parm_decl`. `oacc_verify_routine_clauses` must unlink conflicting level clauses from `*clauses` and prepend `OMP_CLAUSE_SEQ` if none remains, and `omp_maybe_apply_loop_xforms` must set `*expr_p = void_node` on invalid `OMP_CLAUSE_ORDERED` with generated loops. [F75, F76, F78, F99]

## External Contracts

- Pass untagged base pointers to `__hwasan_tag_memory` (`BUILT_IN_HWASAN_TAG_MEM` and the prologue libfunc), and when `hwasan_sanitize_p ()` holds, `asan_intercepted_p` must only match `BUILT_IN_MEMCMP`, `BUILT_IN_MEMCPY`, `BUILT_IN_MEMMOVE`, and `BUILT_IN_MEMSET`. [F44, F55]
- In `oacc_set_fn_attrib` and `oacc_build_routine_dims`, `ids` must match `GOMP_DIM` order and `OACC_FN_ATTRIB` must be prepended while iterating `ix` downward from `GOMP_DIM_MAX`. In `omp_runtime_api_procname`, place Fortran `_8`-capable APIs after the second `NULL` sentinel in `omp_runtime_apis`, and in `omp_ts_map`, use `OMP_TRAIT_PROPERTY_DEV_NUM_EXPR` for `"device_num"` and `OMP_TRAIT_PROPERTY_BOOL_EXPR` for `"condition"`. [F95, F96, F97]

## Known Pitfalls

- In `asan_expand_check_ifn` (without `use_calls`) and `hwasan_expand_check_ifn`, when `!is_non_zero_len`, guard the check inside `if (len != 0)` via `insert_if_then_before_iter` before dereferencing shadow memory or computing `len - 1`, keeping `*iter` on the original IFN in `fallthrough_bb` while emitting into `then_bb` via local `gsi` before `gsi_remove (iter, true)`. [F5, F34]
- In `oacc_verify_routine_clauses`, when `c_diag_p == NULL_TREE`, `incompatible:` must read the location from `OMP_CLAUSE_LOCATION (c_level_p)` and the clause name from `OMP_CLAUSE_CODE (c_diag)`. In `gcc/omp-general.cc`, test `if (ENABLE_OFFLOADING)` by value (never `#ifdef ENABLE_OFFLOADING`), and keep `#ifdef ACCEL_COMPILER` / `#ifndef ACCEL_COMPILER` blocks inside `{ ... }` or provide complete statements in both branches inside `if`/`else` chains. [F62, F63, F66]
