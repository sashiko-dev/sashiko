# cp

The `cp` unit is the GCC C++ front end, implementing lexing, parsing, name lookup, declarations, types, templates, C++20 concepts and modules, `constexpr` evaluation, AST utilities, mangling, and diagnostics.

## Architecture & Data Flow
- Array `CONSTRUCTOR`s must never use 1-element `RANGE_EXPR`s (`lo == hi`) or length-1 `RAW_DATA_CST`s, must represent multi-element zero/value/trailing initializers with a single `RANGE_EXPR` (dropping zero trailing initializers in `build_vec_init`), and in `find_array_ctor_elt` must keep indices either all null or all non-null (backfilling `0..len-1` when inserting at `i > end`). [F1, F2, F3, F11, F306, F314, F315, F511]
- Array `CONSTRUCTOR_ELTS` loops (`maybe_deduce_size_from_array_init`, `process_init_constructor_array`, `reshape_init_array_1`, `build_vec_init`, `split_nonconstant_init_1`) must track the array index separately from the vector index, advancing by `RAW_DATA_LENGTH` for `RAW_DATA_CST` and `range_expr_nelts` for `RANGE_EXPR`. In `reshape_init_array_1` and `process_init_constructor`, clear `TREE_CONSTANT` whenever any element is non-constant; in `split_nonconstant_init_1`, clear `index`, update `tidx`, increment `num_split_elts`, and set `last_split_elt = field_index`. [F106, F111, F132, F307, F504, F505, F506, F507, F526]
- In `cxx_eval_call_expression`, `constexpr_call_table->find_slot` only passes `INSERT` when `depth_ok < constexpr_cache_depth`; in-progress slots use `unknown_type_node` (copying `mce_unknown` results to empty `mce_true`/`mce_false` slots); and calls with `addr_of_non_const_var` args, net heap allocations/undeleted heap vars, or `heap_deleted_identifier` refs in `result` must not be cached. [F9, F39, F40]
- `maybe_constant_value` must bypass `cv_cache` when `manifestly_const_eval != mce_unknown` and must not insert into `cv_cache` when `uid_sensitive_constexpr_evaluation_checker::evaluation_restricted_p ()` is true; `DECL_IMMEDIATE_FUNCTION_P` calls force `manifestly_const_eval = mce_true`, whereas `CP_BUILT_IN_IS_CONSTANT_EVALUATED` and `IF_STMT_CONSTEVAL_P` set `*non_constant_p = true` when `ctx->manifestly_const_eval == mce_unknown`. [F28, F29, F30]
- In `satisfy_atom`, after `tsubst_parameter_mapping` on an uninstantiated `satisfaction_cache` miss, query a second `satisfaction_cache (t, NULL_TREE, info)` with `ATOMIC_CONSTR_MAP_INSTANTIATED_P (t) = true`, pass `mce_true` to `maybe_constant_value` when `!info.noisy ()`, and save through both caches; in `satisfy_declaration_constraints`, do not cache if `failed_type_completions` grew, and return `error_mark_node` on a quiet cache mismatch in `satisfaction_cache::save`. [F14, F32, F55]
- Single-level template argument vectors are flat `TREE_VEC`s (not 1-element `TREE_VEC`s of levels) in `get_innermost_template_args`, `strip_innermost_template_args`, and `template_parms_to_args`; when `coerce_template_parms`, `tsubst_template_args`, or `expand_template_argument_pack` expands packs, adjust output indices and `NON_DEFAULT_TEMPLATE_ARGS_COUNT` by `pack_len - 1`. [F447, F448, F449, F450, F453]
- Dependent opaque aliases (`dependent_opaque_alias_p` or `dependent_alias_template_spec_p (..., nt_opaque)`) must have `TYPE_DEPENDENT_P`, `TYPE_DEPENDENT_P_VALID`, and `SET_TYPE_STRUCTURAL_EQUALITY` set, must not be stripped by `strip_typedefs` without `STF_STRIP_DEPENDENT`, must increment `comparing_dependent_aliases` in `template_args_equal` when `!comparing_for_partial_ordering` (checked in `structural_comptypes`), and must hash via `TYPE_ALIAS_TEMPLATE_INFO` in `iterative_hash_template_arg`. [F243, F478, F479, F480, F481, F530]
- In `instantiate_decl`, `VAR_P (d)` must force `defer_ok = false`, call `note_vague_linkage_variable (d)` for variable templates, and only call `add_pending_template (d)` when `cp_unevaluated_operand == 0 && !(external_p && VAR_P (d))`; in `instantiate_template` and `tsubst_decl` (`TYPE_DECL`), re-check `retrieve_specialization` after `tsubst` on `DECL_ALIAS_TEMPLATE_P` in case recursion already registered it. [F490, F495, F496]
- `DECL_EXTERNAL` stays set until emission; check `DECL_REALLY_EXTERN` (`!DECL_NOT_REALLY_EXTERN`) to test if a decl is truly external, and when `at_eof` in `module_state::read_cluster` or `post_load_processing`, clear `DECL_EXTERNAL` after `expand_or_defer_fn` if `DECL_COMDAT && DECL_NOT_REALLY_EXTERN`. [F83, F208]
- `lang_decl_min::template_info` and `access` are unioned across decl kinds (`THUNK_ALIAS` on `DECL_THUNK_P`, `DECL_LOCAL_DECL_ALIAS` on `DECL_LOCAL_DECL_P`, `DECL_DISCRIMINATOR`), and `lang_decl_vals` under `lds_fn` discriminates `u5` by `thunk_p` and `decl_tls_wrapper_p (t)`. `cp_get_fndecl_from_callee` must map `DECL_LOCAL_DECL_P` functions through `DECL_LOCAL_DECL_ALIAS`. [F77, F84, F199]
- In `BINDING_VECTOR`, `BINDING_SLOT_CURRENT` (0) and `BINDING_SLOT_GLOBAL` (1) are in `cluster[0]`, while `BINDING_SLOT_PARTITION` (2) is in `cluster[1].slots[0]` (`base == 0, span == 1`) when `BINDING_VECTOR_SLOTS_PER_CLUSTER == 2`; imported module slots must be appended in increasing module-index order (clamping `want` to `(unsigned short)~0`) and scanned by checking both `base != 0` and `span != 0`, and `TREE_LANG_FLAG_*` must never be used on `BINDING_VECTOR`. [F356, F357, F358, F367, F389]
- In `cp_walk_subtrees`, `DECLTYPE_TYPE`, `ALIGNOF_EXPR`, `SIZEOF_EXPR`, `NOEXCEPT_EXPR`, and `REQUIRES_EXPR` must be walked under `cp_unevaluated` (walking `TREE_TYPE (parm)` for `REQUIRES_EXPR_PARMS`); `DECL_EXPR` for local artificial or template vars must walk `TREE_TYPE (decl)` and `INTEGER_TYPE` must walk `TYPE_MIN_VALUE`/`TYPE_MAX_VALUE`; and `replace_placeholders_r`/`find_placeholders_r` must not descend into nested `CONSTRUCTOR`s with `CONSTRUCTOR_PLACEHOLDER_BOUNDARY` set. [F251, F252, F258]
- When `trees_in::read_class_def`, `trees_in::install_implicit_member`, `switch_to_class`, `save_template_attributes`, or `complete_type` (for `ARRAY_TYPE`) updates `TYPE_FIELDS`, `TYPE_ATTRIBUTES`, `TYPE_NEEDS_CONSTRUCTING`, or `TYPE_HAS_NONTRIVIAL_DESTRUCTOR` on a main variant, it must propagate the update across `TYPE_NEXT_VARIANT` (via `fixup_type_variants` for classes). [F188, F295, F430, F528]
- Internal helper temporaries must use `get_internal_target_expr` (`TARGET_EXPR_INTERNAL_P`) so `extend_ref_init_temps` ignores them; `build_target_expr` always sets `TREE_SIDE_EFFECTS` and only sets `TREE_READONLY` on the slot when `type` is `const`, non-`volatile`, without non-trivial dtor or `mutable` member, and `reduced_constant_expression_p (value)` holds; and `INDIRECT_REF`s built in `convert_from_reference` and `cp_build_indirect_ref_1` must set `TREE_READONLY` from `CP_TYPE_CONST_P` and `TREE_THIS_VOLATILE` from `CP_TYPE_VOLATILE_P`. [F82, F85, F240, F536]

## Object Lifetimes
- Temporary `vec<tree, va_gc> *` vectors from `make_tree_vector`, `make_tree_vector_single`, or `sorted_abi_tags` must be freed via `release_tree_vector` or held in `releasing_vec`; initialize a `releasing_vec` with `NULL` if later assigned via `*&r = ...`, and call `r.release ()` (never `release_tree_vector (r.get ())`) for early release. [F64, F65, F66, F116, F321, F322, F377, F463]
- Non-RAII `vec<T>` instances (`get_mapped_args` inner `vec<tree>`s, `depset::hash::connect()`, `namespace_hints::m_candidates`, `class_decl_loc_t::locvec`, `cp_parser_omp_declare_simd`/`cp_parser_oacc_routine` `data.tokens`, `omp_privatization_save` in `instantiate_body`) must be `.release()`d on all exit paths (unlike `cx_error_context ()` in `maybe_print_constexpr_context`, which is non-owning). [F15, F184, F272, F273, F375, F426, F427, F466]
- Increment `function_depth` (and pair with `processing_template_decl_sentinel` in `lazy_load_binding` and `lazy_load_pendings`) around `c_parse_final_cleanups` `priority_map_t` partitioning, `mark_used`/`maybe_instantiate_decl` calls to `synthesize_method`/`instantiate_decl`, and `maybe_add_lambda_conv_op` body synthesis when `!nested` so `ggc_collect` does not collect unrooted stack references. [F210, F274, F298, F324]
- Reference-counted `tinst_level` pointers (`current_tinst_level`, `tinst_level::next`, `pending_template::tinst`) must be updated via `set_refcount_ptr` (clearing `drop->tinst` before `pending_template_freelist ().free (drop)`), and `local_specializations` must be managed via `local_specialization_stack`. [F464, F467]
- Freeing a `CONSTRUCTOR` requires `free_constructor` (not `ggc_free`); `build_disable_temp_cleanup` immediately `ggc_free`s a `TREE_LIST` argument; `duplicate_decls` (and `pushdecl_namespace_level` in `tsubst_friend_function`) `ggc_free`s `newdecl` after detaching its `DECL_LANG_SPECIFIC`, `DECL_STRUCT_FUNCTION`, symtab node, constraints, and module data; and `declarator_obstack` watermarks must be freed via `obstack_free` before returning. [F19, F119, F423, F501, F514]

## API Contracts
- `maybe_constant_init*`, `fold_non_dependent_expr`, `maybe_constant_value`, and `fold_for_warn` must skip `cxx_eval_outermost_constant_expr` when `cp_unevaluated_operand` is non-zero and `manifestly_const_eval != mce_true` (with `fold_for_warn` using `uid_sensitive_constexpr_evaluation_sentinel` and `fold_non_dependent_expr (x, tf_none)` in templates); `maybe_constant_init*` must preserve tri-state `mce_value`, while `cp_check_const_attributes` (for `"aligned"`), `store_init_value` (for `decl_maybe_constant_var_p || TREE_STATIC`), and `check_narrowing` must pass `manifestly_const_eval = true`. [F27, F49, F279, F280, F523, F524]
- Before querying `CLASSTYPE_LITERAL_P`, `type_has_nontrivial_copy_init`, `TYPE_BINFO` (`name_lookup::adl_class`, `get_template_base`), `get_class_binding`, or `build_offset_ref`, callers must strip array types where applicable, normalize to `TYPE_MAIN_VARIANT`, and call `complete_type` (whereas `layout_var_decl` must not complete `DECL_EXTERNAL` vars, and `convert_to_void` only completes `INDIRECT_REF`/`VAR_DECL` types when `TYPE_VOLATILE`). [F33, F93, F134, F245, F335, F381, F382, F469]
- C++20 module flags (`DECL_MODULE_PURVIEW_P`, `DECL_MODULE_ATTACH_P`, `DECL_MODULE_IMPORT_P`, `DECL_MODULE_ENTITY_P`, `DECL_MODULE_KEYED_DECLS_P`) must be accessed on `STRIP_TEMPLATE (decl)` (`DECL_MODULE_CHECK` rejects `TEMPLATE_DECL`); `decl_constant_var_p` must call `maybe_instantiate_decl (decl)` before reading `DECL_INITIALIZED_BY_CONSTANT_EXPRESSION_P`; and `value_dependent_expression_p` requires its caller to have verified `potential_constant_expression (expr)` first. [F79, F289, F475]
- In `mark_used`, return `true` immediately when `complain & tf_conv` is set (used by `tsubst_expr` on dependent `koenig_p` `CALL_EXPR` callees before `perform_koenig_lookup`), and when `cp_unevaluated_operand || in_discarded_stmt` is set, return `true` after deduction and constraint/deleted checks without setting `DECL_ODR_USED`, synthesizing methods, or calling `instantiate_decl`. [F297, F492]
- Vector `quick_push` callers (`set_class_bindings`, `insert_late_enum_def_bindings`, `store_bindings`, `store_class_bindings`, `name_lookup::preserve_state`, `CPP_EMBED` expansion, and deferred token lexers) must pre-reserve capacity first; before dereferencing an imported `binding_slot` via `operator tree &()`, check `!slot.is_lazy ()`; and before calling `is_capture_proxy`, strip location wrappers (`!location_wrapper_p`). [F345, F369, F370, F371, F372, F390, F417, F419]
- `push_to_top_level` / `maybe_push_to_top_level` (paired with `pop_from_top_level` / `maybe_pop_from_top_level`), `cp_evaluated` (in `cp_parser_enclosed_template_argument_list`, lambdas, `cp_parser_constant_expression` when `allow_non_constant_p <= 1`, `maybe_instantiate_nsdmi_init`, and `PARM_DECL` chain `tsubst`), `get_nsdmi` (when `!in_ctor`), and `instantiate_class_template_1` (when `fn_context` is non-null) must clear and restore `cp_unevaluated_operand`. [F332, F339, F398, F431, F441, F474, F493]

## Error Handling
- Because `-fpermissive` in a template body downgrades `DK_ERROR` to `DK_WARNING` (`OPT_Wtemplate_body`) in `cp_adjust_diagnostic_info` and records `erroneous_templates`, template error checks must call `cp_seen_error ()` / `seen_error ()` rather than `(seen_error) ()` or `errorcount`; and `error.cc` functions (`dump_decl`, `dump_function_name`, `function_category`) must check `DECL_LANG_SPECIFIC` on `FUNCTION_DECL`s before using `lang_decl` macros. [F292, F294]

## Known Pitfalls
- Pointers into `CONSTRUCTOR_ELTS` (`cep`, `valp`, `ctors[i]`) in `cxx_eval_bare_aggregate`/`cxx_eval_store_expression` and `tree *slot` pointers into namespace binding tables in `push_namespace` are invalidated by recursive evaluation or `pushdecl`; save index hints and re-fetch via `get_or_insert_ctor_field` or `find_namespace_slot`. Likewise, growing a local `member_vec` via `vec_safe_*` requires writing it back to `CLASSTYPE_MEMBER_VEC (klass)`. [F8, F12, F364, F379]
- Whenever an incomplete or placeholder variable type is completed (`start_decl_1`, `maybe_deduce_size_from_array_init`, `cp_finish_decl` after `do_auto_deduction`, `complete_vars`, `finish_static_data_member_decl`), `cp_apply_type_quals_to_decl (cp_type_quals (type), decl)` must be re-run (and `maybe_push_cleanup_level` must run after `complete_type` in `start_decl_1`). [F133, F285]
- `TYPE_TEMPLATE_INFO` ignores alias templates, whereas `TYPE_TEMPLATE_INFO_MAYBE_ALIAS` returns `TYPE_ALIAS_TEMPLATE_INFO` for `typedef_variant_p` types; `cp_walk_subtrees` (when `*walk_subtrees_p == 1`) and `find_parameter_packs_r` on a `typedef_variant_p` type only walk `TI_ARGS (TYPE_ALIAS_TEMPLATE_INFO (t))` and set `*walk_subtrees = 0`; and `replace_placeholders` must pass `NULL` as `pset` to `cp_walk_tree` so shared `PLACEHOLDER_EXPR` nodes are not skipped. [F74, F228, F244, F482]
- `CLASSTYPE_AS_BASE` (`IS_FAKE_BASE_TYPE`) lacks `TYPE_LANG_SPECIFIC` and stores the complete class in `TYPE_CONTEXT`; it must be used by `build_clobber_this` (when `!CLASSTYPE_VBASECLASSES`) and `expand_aggr_init_1` (passing `TYPE_SIZE (CLASSTYPE_AS_BASE (type))` to `build_zero_init_1` for base subobjects), while `trees_in::read_class_def` must not overwrite `ANON_AGGR_TYPE_FIELD` when `DECL_NAME (defn) == as_base_identifier`. [F69, F127, F189, F326]
- In `ocp_convert`, when `same_type_ignoring_top_level_qualifiers_p` holds and no temporary is forced, return `e` without calling `fold` (which would infinitely recurse back to `ocp_convert`) and update `TARGET_EXPR`/`CONSTRUCTOR` types in place rather than wrapping in `NOP_EXPR`; in `digest_nsdmi_init` and `replace_placeholders_for_class_temp_r`, do not run `replace_placeholders` on a `TARGET_EXPR` with `TARGET_EXPR_ELIDING_P` set, and in `process_init_constructor_record`, clear `TARGET_EXPR_ELIDING_P` when `unsafe_copy_elision_p (field, next)` holds. [F86, F544, F545]
- In `satisfy_declaration_constraints`, pass unaugmented `orig_args` (not `args`) to `push_tinst_level`; in `spec_hasher`, reset `elt.hash = 0` whenever `elt.tmpl` or `elt.args` is mutated on a reused `spec_entry`; and when temporarily decrementing `TREE_VEC_LENGTH (args)` in `add_outermost_template_args` or `coerce_template_parameter_pack`, restore the original length immediately after the call. [F53, F454, F455]
- In `mangle.cc`, `maybe_check_abi_tags` must be called before `start_mangling` (which resets global state `G` and `name_obstack`); `write_encoding` on a template `FUNCTION_DECL` must pass `get_mostly_instantiated_function_type (decl)` and `NULL_TREE` to `write_bare_function_type`; and `write_type` must handle `ARRAY_TYPE` via `write_array_type` before taking `TYPE_MAIN_VARIANT (type)` (which strips element cv-qualifiers). [F323, F352, F353]
