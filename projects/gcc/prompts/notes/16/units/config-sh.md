# config-sh

This unit (`gcc/config/sh/sh.h` and `gcc/config/sh/sh.cc`) implements the Renesas / SuperH (SH1 through SH4A) target backend configuration, ABI conventions, addressing modes, register allocation rules, cost models, instruction scheduling hooks, branch shortening, constant pool placement, FPU mode switching, and target-specific built-ins and attributes.

## Architecture & Data Flow

- In `gcc/config/sh/sh.cc`, `#include "config.h"` must precede `#ifdef HAVE_AS_TLS` (so `TARGET_HAVE_TLS` is overridden when supported), and `#include "target-def.h"` must appear after all other headers (`tm.h` via `backend.h`/`target.h`) and before `#undef`/`#define TARGET_*` overrides and `targetm = TARGET_INITIALIZER`. In `gcc/config/sh/sh.h`, `#include "config/vxworks-dummy.h"` must stay at the top so fallback VxWorks macros (`TARGET_VXWORKS_RTP`, `VXWORKS_GOTT_BASE`, `VXWORKS_GOTT_INDEX`) exist before subtarget overrides. [F13, F15, F17]
- In `gcc/config/sh/sh.h`, `MASK_ARCH` must contain every `MASK_*` bit used by any `SELECT_SH*` macro (including `MASK_FPU_SINGLE_ONLY` in `SELECT_SH2A_SINGLE_ONLY` and `SELECT_SH4_SINGLE_ONLY`) so clearing `MASK_ARCH` completely resets prior architecture flags. [F64]
- In `sh_option_override`, SH4-300 FPU features (`TARGET_FSCA`, `TARGET_FSRRA`) and `gen_toggle_pr` in `sh_emit_mode_set` must be gated on `TARGET_FPU_SH4_300` (`TARGET_FPU_ANY && TARGET_SH4_300`) rather than `TARGET_SH4_300` (which is also set by `-m4-300-nofpu` and `-m4-340`). `TARGET_FSRRA` also requires both `flag_unsafe_math_optimizations` and `flag_finite_math_only`, and `TARGET_IEEE` must default to `!flag_finite_math_only` when unset. [F55, F61]
- When `targetm.small_register_classes_for_mode_p (VOIDmode)` is true, `sh_option_override` must force `flag_schedule_insns` to `0` whenever `!TARGET_HARD_SH4`, `flag_pic`, `flag_exceptions`, or `!OPTION_SET_P (flag_schedule_insns)` holds, avoiding `R0` spill failures. [F30]
- Every non-empty register class in `REG_CLASS_CONTENTS` (after `sh_conditional_register_usage` populates `SIBCALL_REGS`) must have a unique hard-register bitmask; duplicate bitmasks (such as matching `DF_REGS` or `FP_REGS`) cause IRA's `find_costs_and_classes` to ICE. [F63]
- `sh_modes_tieable_p` must never allow `SFmode` to be tieable with any other floating-point mode because `sh_hard_regno_mode_ok` allows `DFmode` in `XD_REGISTER_P` registers while rejecting `SFmode`. [F39]
- In `sh_can_change_mode_class`, changing from a vector mode with `SFmode` elements to `SFmode` must reject register classes intersecting `GENERAL_REGS` when `optimize` is nonzero, but must allow it when `!optimize` so stack-allocated vector subregs can use displacement addressing. [F41]
- `SUBREG_OK_FOR_INDEX_P` and `MAYBE_INDEX_REGISTER_RTX_P` must require `OFFSET == 0` (`SUBREG_BYTE (X) == 0`) when matching a `SUBREG` of `R0_REG`, because `INDEX_REG_CLASS` (`R0_REGS`) is a single-register class. [F42]
- In `CALL_REALLY_USED_REGISTERS`, the `gbr` (`GBR_REG`) entry must remain `0` unless `-fcall-used-gbr` is active, so `GBR_REG` is not marked call-clobbered by default and `sh_find_equiv_gbr_addr` can preserve GBR-relative addressing across calls. `sh_find_equiv_gbr_addr` must also reject `MEM` operands where `side_effects_p (XEXP (mem, 0))` is true so `POST_INC`/`PRE_DEC` addresses are never rewritten to `(plus (reg GBR_REG) disp)`. [F45, F62]
- In `sh_max_mov_insn_displacement`, when `GET_MODE_SIZE (mode)` exceeds `mov_insn_size (mode, consider_sh2a)`, the maximum displacement must be reduced by `mode_sz - mov_insn_sz`, and `sh_legitimate_index_p` must reject even displacement `0` when `!allow_zero && max_disp < 1`. [F51]
- In `sh_legitimize_reload_address`, displaced `SFmode` addresses on `TARGET_SH2E` must reload the entire `PLUS` address `*p` into `BASE_REG_CLASS`, and `QImode`/`HImode` displaced addresses must not be legitimized there because `mov.b`/`mov.w` displacement moves require `R0` as the data operand. [F52]
- In `prepare_move_operands`, before reload: if emitting `gen_GOTaddr2picreg` for non-PIC TLS accesses (`TLS_MODEL_GLOBAL_DYNAMIC`, `TLS_MODEL_LOCAL_DYNAMIC`, or `TLS_MODEL_INITIAL_EXEC`) with `flag_schedule_insns` enabled, `gen_blockage ()` must be emitted immediately before and after the GOT setup; and if `operands[1]` refers to `R0_REG` while storing to a `MEM` with `(plus base (reg index))` addressing, `operands[1]` must be copied to a mode register so `R0` is not needed for both value and index. [F31, F53]
- In `output_movedouble`, when moving a 64-bit value between overlapping register pairs (`REGNO (src) + 1 == REGNO (dst)`) or from a non-`POST_INC` memory operand whose base `ptrreg` equals `REGNO (dst)`, the high-offset word (`%T1` -> `%T0`) must be moved before the low-offset word (`%1` -> `%0`). [F50]
- When `sh_find_extending_set_of_reg` treats a non-UNSPEC `QImode` or `HImode` `MEM` load as an implicit `SIGN_EXTEND`, `sh_extending_set_of_reg::use_as_extended_reg` must replace that load with an explicit `extendqisi2` or `extendhisi2` into a new `SImode` pseudo and re-attach `REG_INC` notes via `sh_check_add_incdec_notes`. [F43]
- `sh_is_nott_insn` must verify both `i != NULL_RTX` and `PATTERN (i) != NULL_RTX` before calling `GET_CODE (PATTERN (i))`, because an `rtx_insn *` in a sequence (such as `insnlist.second` in `sh_split_treg_set_expr`) may be a `CODE_LABEL` with a null `PATTERN`. [F21]
- In `gcc/config/sh/sh.h`, `INSN_SETS_ARE_DELAYED(X)` and `INSN_REFERENCES_ARE_DELAYED(X)` must check `NONJUMP_INSN_P (X)` and reject `PATTERN (X)` codes `SEQUENCE`, `USE`, and `CLOBBER` before calling `get_attr_is_sfunc (X)`. [F29]
- In `sh_rtx_costs`, every `MEM` load/store cost branch (`case MEM`, `case SIGN_EXTEND`, `case ZERO_EXTEND`, and `SET` elements in `case PARALLEL`) must set `*total` to `sh_address_cost (..., speed) + COSTS_N_INSNS (1)`, forwarding `speed` and adding the 1-insn base cost. [F58]
- In `push_regs` and `sh_expand_epilogue`, when `interrupt_handler` (`current_function_interrupt`) is true, banked registers `FIRST_BANKED_REG..LAST_BANKED_REG` are handled separately, so the main loop must start at `LAST_BANKED_REG + 1` in `push_regs` and bound `i < FIRST_PSEUDO_REGISTER - LAST_BANKED_REG - 1` in `sh_expand_epilogue`. Furthermore, when `sh_cfun_interrupt_handler_p ()` and `TARGET_FMOVD` hold and any `DF_REGS` register is saved, `push_regs` must push `FPSCR_REG` and set `FPSCR` to `NORMAL_MODE (FP_MODE)` before pushing `FIRST_FP_REG`, and `sh_expand_epilogue` must pop `FPSCR_REG` only after `FIRST_FP_REG` is popped. [F3, F57]
- In `output_stack_adjust` and `sh_expand_epilogue`, partial stack adjustments must be aligned to `STACK_BOUNDARY / BITS_PER_UNIT` (`size / 2 & -align`), and `gen_blockage ()` must precede epilogue stack pointer restoration so interrupts cannot see an unaligned stack or clobber live frame data. [F54]
- When `CROSSING_JUMP_P` holds on a jump between hot and cold partitions, `sh_can_follow_jump` must return `false`, `output_far_jump` must not select the 16-bit `mov.w` + `braf` sequence, and `split_branches` must emit `gen_block_branch_redirect (const0_rtx)` before `insn` and skip redirecting it. [F33]
- `get_dest_uid` must advance `dest = NEXT_INSN (dest)` past any instruction with `INSN_UID (dest) >= max_uid` before returning `dest_uid`, because `split_branches` sizes `uid_branch` to `max_uid = get_max_uid ()` before inserting branch-redirection blocking instructions. [F8]
- In `find_barrier`, `label_to_alignment (from)` and `barrier_align (from)` must be guarded by `CODE_LABEL_NUMBER (from) <= max_labelno_before_reorg` (set from `max_label_num ()` on entry to `sh_reorg`) because recursive scans encounter constant-table labels created after `compute_alignments`. If `find_barrier` encounters a `BARRIER_P (from)` followed immediately by `NOTE_INSN_SWITCH_TEXT_SECTIONS`, it must stop scanning (`break`) immediately. When synthesizing a barrier, `from` must be backed up before any unpaired `last_got` (`last_got != orig`), any call with `REG_EH_REGION` under `flag_exceptions`, and any `NOTE_P`, `JUMP_P`, or `LABEL_P`; if `SIBLING_CALL_P (from)` holds, only `emit_barrier_after (from)` may be emitted. [F10, F34, F35]
- `dump_table` and `output_jump_label_table` must reset `pool_size = 0` after emitting a literal pool because `add_constant` appends to the fixed-size `pool_vector[MAX_POOL_SIZE]` (`372` entries) without bounds-checking `pool_size`. [F11]
- In `sh_init_builtins`, the `for (int i = 3; ; i--)` loop must map `signature_args[signature][i]` to `insn_data[d->icode].operand[i - 1 + has_result]` and `break` when `i == 0` before writing `args[i - 1]` (since `i == 0` computes the return type in `arg_type`). In `sh_expand_builtin`, `nop` must be incremented when `signature_args[signature][0]` is non-zero before `for (int i = 1; i <= 3; i++, nop++)`, placing `CALL_EXPR_ARG (exp, i - 1)` into `op[nop]` and validating against `insn_data[icode].operand[nop]`. [F1, F2]
- In `sh_gimplify_va_arg_expr`, the `pass_as_float` branch must end with `valist = next_fp_tmp;` so the shared `std_gimplify_va_arg_expr (valist, type, pre_p, NULL)` call reads the updated pointer temporary, and when `result` is set under `#ifdef FUNCTION_ARG_SCmode_WART`, emitting `lab_over` must wait until after `result` is assigned. [F5]
- When `find_sole_member` scans `TYPE_FIELDS (type)`, it must skip non-`FIELD_DECL` nodes and return `NULL_TREE` if any `FIELD_DECL` has a null `DECL_SIZE (field)` before testing `integer_zerop (DECL_SIZE (field))`. [F23]

## Object Lifetimes

- `regmode_weight[0]` and `regmode_weight[1]` are allocated with `xcalloc (old_max_uid, sizeof (short))` in `sh_md_init_global` and must be freed and reset to `NULL` in `sh_md_finish_global`; `INSN_REGMODE_WEIGHT (insn, mode)` must only be indexed while live and with `INSN_UID (insn) < old_max_uid`. [F12, F19]
- All `label_ref_list_d` nodes allocated from `label_ref_list_d_pool.allocate ()` in `add_constant` during the `SH_FIXUP_PCLOAD` phase of `sh_reorg` must be bulk-released via `label_ref_list_d_pool.release ()` after the literal-table insertion loop (`dump_table`) finishes, and never while `pool_vector` still holds live `wend` lists. [F18]
- In `sh_recog_treg_set_expr` and `sh_split_treg_set_expr`, increments to `sh_recog_treg_set_expr_reent_count` must be guarded by a local `scope_counter` instance, and `recog_data` must be saved and restored around re-entrant `recog` or `sh_try_split_insn_simple` calls on all return paths. [F20]

## API Contracts

- In `gcc/config/sh/sh.h`, C++-only declarations (`struct sh_atomic_model`, `selected_atomic_model`, `struct sh_args`, `CUMULATIVE_ARGS`, and `current_function_interrupt`) must be guarded by `#ifdef __cplusplus` because `sh.h` is included when compiling C target runtime files (`crtstuff.c` with `CRT_BEGIN`/`CRT_END`). [F16]
- When `optimize` is true, `untangle_mova` must check `INSN_ADDRESSES_SIZE () <= (unsigned) INSN_UID (new_mova)` and return `-1` before reading `INSN_ADDRESSES (INSN_UID (new_mova))`, because `mova` instructions emitted during `sh_reorg` after `shorten_branches` have UIDs beyond `INSN_ADDRESSES_SIZE ()`. [F9]
- In `sh_insert_attributes`, when `sh_deferred_function_attributes` is non-null on a `FUNCTION_DECL`, `*attributes` is chained onto `*sh_deferred_function_attributes_tail` and `sh_deferred_function_attributes` and `sh_deferred_function_attributes_tail` must be reset (`NULL_TREE` and `&sh_deferred_function_attributes`). If neither `attrs` nor `DECL_ATTRIBUTES (node)` has `interrupt_handler`, `trapa_handler` implicitly prepends `interrupt_handler`, whereas `sp_switch`, `trap_exit`, `nosave_low_regs`, and `resbank` must be stripped from `*attributes` with an `OPT_Wattributes` warning. [F25, F26]
- `sh_init_builtins` must cache the `FUNCTION_DECL`s for `CODE_FOR_sts_fpscr` and `CODE_FOR_set_fpscr` in `sh_builtin_get_fpscr` and `sh_builtin_set_fpscr`, and `sh_atomic_assign_expand_fenv` must return early when `!TARGET_FPU_ANY` before building calls to them. [F28]
- Before reload, when `high_pressure` holds (`r0_life_regions >= R0_MAX_LIFE_REGIONS` or mode pressure exceeds `SFMODE_MAX_WEIGHT`/`SIMODE_MAX_WEIGHT`), `sh_reorder2` sets `skip_cycles = 1` and `sh_dfa_new_cycle` must skip up to `MAX_SKIPS` cycles with `*sort_p = 0` before setting `*sort_p = 1` on cycle `MAX_SKIPS`. [F32]
- `sh_check_pch_target_flags` must reject a precompiled header whenever `old_flags ^ target_flags` has any bit set in `MASK_SH1 | MASK_SH2 | MASK_SH3 | MASK_SH_E | MASK_HARD_SH4 | MASK_FPU_SINGLE | MASK_SH4`, `MASK_HITACHI`, or `MASK_LITTLE_ENDIAN`. [F37]
- When `CASE_VECTOR_SHORTEN_MODE` selects `QImode` for an `ADDR_DIFF_VEC` switch table `BODY`, it must set `ADDR_DIFF_VEC_FLAGS (BODY).offset_unsigned` to `0` when `MIN_OFFSET >= 0 && MAX_OFFSET <= 127` and to `1` when `MIN_OFFSET >= 0 && MAX_OFFSET <= 255`. [F38]
- In `sh_hard_regno_caller_save_mode`, `FP_REGISTER_P` registers with `SFmode`, `SCmode`, or even-aligned `DFmode`/`DCmode` must return `mode` directly rather than calling `choose_hard_reg_mode`, which selects an integer mode and breaks LRA splitting. [F40]
- Move instructions emitted from `peephole2` patterns must use `sh_peephole_emit_move_insn` (or call `sh_remove_overlapping_post_inc` and `sh_check_add_incdec_notes`) so `POST_INC` loads overlapping the destination register are downgraded to plain `MEM` and dropped `REG_INC` notes are restored. [F44]
- In `sh_use_by_pieces_infrastructure_p`, `MOVE_BY_PIECES` must pass `MOVE_MAX_PIECES + 1` and both `STORE_BY_PIECES` and `SET_BY_PIECES` must pass `STORE_MAX_PIECES + 1` as the `max_size` bound to `by_pieces_ninsns`. [F46]

## Error Handling

- `sh_attr_renesas_p` must check `td == NULL_TREE`, unwrap `DECL_P (td)` via `td = TREE_TYPE (td)`, and then check `td == error_mark_node` before accessing `TYPE_ATTRIBUTES (td)`. [F22]
- `sh_expand_builtin` must check each argument `CALL_EXPR_ARG (exp, i - 1)` against `error_mark_node` and return `const0_rtx` before inspecting `TREE_TYPE (arg)` or expanding the operand. [F27]

## External Contracts

- `sh_promote_function_mode` and `sh_function_value` must promote scalar integer modes narrower than 4 bytes to `SImode` only when `sh_promote_prototypes` returns true (when neither `TARGET_HITACHI` nor the `renesas` attribute applies). [F47]
- On `TARGET_SH4 && TARGET_LITTLE_ENDIAN` with `FUNCTION_ARG_SCmode_WART`, `sh_function_arg` passes `SCmode` in swapped `SFmode` registers (`PARALLEL` with `^ 1` indices) only when `sh_round_reg` is odd, and `sh_gimplify_va_arg_expr` must read `imag` before `real` from the saved FP register area. [F48]
- In `sh_load_function_descriptor`, a `gen_blockage ()` barrier must be emitted between loading the function entry address from `[funcdesc]` into `R1_REG` and loading the GOT address from `[funcdesc + 4]` into `PIC_REG`. [F49]

## Known Pitfalls

- In `gcc/config/sh/sh.cc`, C++ standard library headers (such as `<sstream>`) and `INCLUDE_*` macros (such as `#define INCLUDE_VECTOR`) must appear before `#include "system.h"`, which includes `"safe-ctype.h"` and poisons `<ctype.h>` identifiers. [F14]
- Analysis and predicate helpers reachable from `sh_rtx_costs` (such as `sh_recog_treg_set_expr`) must allocate temporary non-emitted `rtx_insn` nodes via `rtx_alloc (INSN)` with a fixed `INSN_UID` instead of `make_insn_raw`, because `make_insn_raw` increments the global UID counter and causes `-fcompare-debug` failures. [F59]
- In `sh_try_split_insn_simple`, the loop `for (i = seq; ; i = NEXT_INSN (i))` that recursively splits replacement instructions must update `seq = ii.first` when `i == seq`, update `seqlast = ii.second` and `break` when `i == seqlast`, and reset `i = ii.first` before advancing `NEXT_INSN (i)`. [F7]
- In `sh_insert_attributes`, when filtering out interrupt-only attributes on a function without `interrupt_handler`, the loop `for (tail = attributes; attrs; attrs = TREE_CHAIN (attrs))` must advance `tail = &TREE_CHAIN (*tail)` only for retained attributes and update `attrs = *attributes` before the final `*attributes = attrs` assignment. [F6]
