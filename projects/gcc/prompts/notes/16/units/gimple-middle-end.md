# gimple-middle-end

This unit implements GCC's GIMPLE IR tuples, predicates, walkers, and LTO streamers; `_BitInt(N)` lowering, CRC loop optimization, array-bounds and uninitialized-variable diagnostics; built-in folding and expansion; per-function state and stack frame layout; and GIMPLE-to-RTL expansion, call generation, loop analysis, and CFG infrastructure.

## Architecture & Data Flow

- In `gimple.def`, `DEFGSCODE` order must keep `GIMPLE_COND..GIMPLE_RETURN` contiguous for `gimple_has_ops`, `GIMPLE_ASSIGN..GIMPLE_RETURN` for `gimple_has_mem_ops`, and `GIMPLE_OMP_ATOMIC_LOAD..GIMPLE_OMP_ORDERED` for `gimple_omp_subcode`. In `gswitch`, `op[1]` (label index 0) is the default label; non-default `args[i]` go at `i + 1`. In `gasm`, `op[]` stores outputs at `[0, no)`, inputs at `[no, no + ni)`, clobbers, then labels despite `gimple_build_asm_vec` taking inputs before outputs. [F79, F80, F106]
- In `gcall`, `gcall::u` is discriminated by `subcode & GF_CALL_INTERNAL`: internal calls store `internal_fn` (`gimple_call_fntype` returns `NULL_TREE`); non-internal calls store `fntype` and forbid `gimple_call_internal_fn`. `gimple_phi_num_args` (`phi->nargs`) must equal `EDGE_COUNT (gimple_bb (phi)->preds)` (`phi->args` is indexed by `e->dest_idx`), and `disconnect_dest` must update the swapped edge's `dest_idx` after `unordered_remove`. [F105, F117, F207]
- Callers of `get_gimple_for_ssa_name` (`get_def_for_expr`, `get_def_for_expr_class`, `optimize_bitfield_assignment_op`) must check `is_gimple_assign` before `gimple_assign_rhs_code`/`rhs1` because TER defs can be `gcall`s. When `expand_expr_real_1` expands a TER `gcall *` for `SSA_NAME` `exp`, temporarily set the call's LHS to `make_tree (TREE_TYPE (exp), dest)` around `expand_internal_call` and restore `exp` afterward. [F25, F26]
- `expand_expr_real_gassign` must try `expand_ccmp_expr (g, TYPE_MODE (ops.type))` when `targetm.have_ccmp ()` for ternary/binary RHS before `expand_expr_real_2`. In `do_store_flag`, candidate operand rewrites for `expand_single_bit_test` must use a local `narg0` rather than mutating `arg0`, and require `TREE_CODE (TREE_TYPE (arg1)) != VECTOR_TYPE`. In `expand_cond_expr_using_cmove`, return `NULL_RTX` if `expanding_cond_expr_using_cmove` is already true, and do not decompose `treeop0` when the compared operand has `VECTOR_TYPE_P`. [F2, F37, F38, F39, F76]
- For `VECTOR_BOOLEAN_TYPE_P` with `SCALAR_INT_MODE_P (mode)`, `store_constructor` may only use `convert_move` sign-extension when `elt_size == 1`, and both `store_constructor` and `do_store_flag` (`EQ`/`NE`) must mask bits above `nunits` (`TYPE_VECTOR_SUBPARTS`) with `(HOST_WIDE_INT_1U << nunits) - 1` when `GET_MODE_PRECISION (mode) != nunits`. [F34, F69]
- In `expand_assignment` and `expand_expr_real_1`, if `get_inner_reference` returns `maybe_lt (bitpos, 0)`, move `bits_to_bytes_round_down (bitpos)` into `offset` (`NULL_TREE` beforehand) and set `bitpos = num_trailing_bits (bitpos)`. When `expand_expr_real_1` expands a `MEM_REF` with `mem_ref_refers_to_non_mem_p`, if `TYPE_MODE (type) == BLKmode` or `maybe_lt (offset, 0)`, spill to `assign_stack_temp` (using `expand_misaligned_mem_ref` if misaligned); when lowering to `BIT_FIELD_REF`, clamp `offset` to 0 if `!ranges_maybe_overlap_p`. [F44, F45, F56, F57]
- In `useless_type_conversion_p`, differing `TYPE_MODE`s or conversions between `BITINT_TYPE` and non-`BITINT_TYPE` always return `false`; conversions involving `BOOLEAN_TYPE` are useless only when mode, signedness, and precision match and either both are `BOOLEAN_TYPE` or `TYPE_PRECISION (outer_type) == 1`; matching-mode `VECTOR_TYPE_P` types require equal `TYPE_VECTOR_SUBPARTS`, recursive `useless_type_conversion_p` on element types, and `targetm.compatible_vector_types_p`. [F417, F418, F419, F431]
- While `currently_expanding_to_rtl` is true, `mark_addressable_1` must queue decls in `mark_addressable_queue` rather than setting `TREE_ADDRESSABLE` immediately (which changes `is_gimple_reg`), and `flush_mark_addressable_queue` must run only after clearing `currently_expanding_to_rtl`. Marking a local non-external, non-static `VAR_DECL` in `mark_addressable` must also mark its entry in `cfun->gimple_df->decls_to_pointers`. [F420, F421]
- In `set_rtl`, when `use_register_for_decl (t)` holds for `SSA_NAME` `t` (`x != pc_rtx`), `GET_MODE (x)` must equal `promote_ssa_mode (t, NULL)` (except uncoalesced or `BLKmode` `RESULT_DECL`s), and `expand_one_ssa_partition` must zero-initialize `SA.partitions_for_undefined_values` registers when `reg_mode` is promoted. In `pass_expand::execute`, `FOR_EACH_SSA_NAME` loops querying `SA.map` must skip `!SSA_NAME_DEF_STMT (name)`. [F301, F319, F320]
- In `partition_stack_vars`, index `stack_vars` via `i = stack_vars_sorted[si]`, skipping `stack_vars[i].representative != i`; never union variables across `MAX_SUPPORTED_STACK_ALIGNMENT`, or of different sizes under `asan_sanitize_stack_p ()`. In `stack_var_conflict_p`, `TREE_CODE (decl) == SSA_NAME` conflicts with all entries; in `add_scope_conflicts_1`, only whole-variable clobbers (`VAR_P (lhs)`) clear `work`, and merge conflicts are recorded only after leading clobbers. [F271, F276, F291, F293, F295]
- In `expand_asm_stmt`, never pass `CONCAT` RTXes in `output_rvec` or `input_rvec` (buffer outputs via `gen_reg_rtx` and force inputs with `force_reg`). `constraints` stores `noutputs` outputs then `ninputs` inputs (at `i + noutputs`), and after `ninout` in-out operands are added to `ninputs`, loops over `input_tvec` or non-matching inputs must stop at `ninputs - ninout`. In `match_asm_constraints_1`, an input matching `output` must not replace `input` in other inputs if `output` is earlyclobber (`'&'`). [F269, F327, F447]
- In `expand_call`, when `promote_mode` / `promote_function_mode` promotes a `MODE_INT` register argument in `precompute_arguments` or a `REG` return `target`, wrap it in a lowpart `SUBREG` with `SUBREG_PROMOTED_VAR_P` and `SUBREG_PROMOTED_SET`. Disable tail-call optimization if caller/callee return promotions disagree in mode, signedness, or `partial_subreg_p`, or if `shift_return_value` (using `ashr_optab` when `!left_p`) shifts an MSB-returned `valreg`. [F251, F252, F253, F254]
- In `cfgrtl.cc` and `cfgcleanup.cc`, blocks in different `BB_PARTITION`s must never be merged, have jumps across them replaced/removed or forwarded (`try_forward_edges`, unless `EDGE_CROSSING` is set), or be cross-jumped/jump-threaded once `reload_completed` is true. When `crtl->has_bb_partition` is set, no `BB_COLD_PARTITION` block may dominate a non-cold block (`fixup_partitions`), and `rtl_split_edge` on a non-entry edge must inherit `BB_PARTITION (edge_in->src)`. [F243, F244, F363, F364, F365]
- In `copy_bbs`, keep `BB_DUPLICATED` set on all source `bbs` during duplication and intra-region edge redirection so `execute_on_growing_pred`/`shrinking_pred` skip `cfg_hooks` callbacks, and pass a single shared `copy_bb_data` to every `duplicate_block` call so `dependence_map` remaps `MR_DEPENDENCE_CLIQUE` (after `unshare_expr (MEM_EXPR)`) consistently. [F304, F306, F357]
- In `bitint_large_huge`, every `handle_operand`, `handle_cast`, and `handle_stmt` path must advance `m_data_cnt` by the exact same slot count whether `m_first` is true or false (with top-level limb loops resetting `m_data_cnt = 0`). `m_var_msb` may only be set to `true` for `LSHIFT_EXPR` in `lower_shift_stmt` so partial MSB limbs are otherwise accessed only with constant `idx` (`tree_to_uhwi (idx) * limb_prec < TYPE_PRECISION (type)` in `limb_access_type`). [F449, F450, F451, F486]
- In `build_bitint_stmt_ssa_conflicts`, if a `GIMPLE_ASSIGN` has a large/huge `_BitInt` `lhs` not in `names`, return immediately; for non-`names` `SSA_OP_USE` operands, walk `SSA_NAME_DEF_STMT` via `worklist` to mark transitive in-`names` uses live; and for `MULT_EXPR`, `TRUNC_DIV_EXPR`, `EXACT_DIV_EXPR`, and `TRUNC_MOD_EXPR`, call `def (live, lhs, graph)` after marking all `SSA_OP_USE`s live. [F474, F475, F476]

## Object Lifetimes

- In `gimple_seq_discard`, unlink each statement via `gsi_remove (&gsi, true)` and call `release_defs (stmt)` before `ggc_free (stmt)`. `gimple_assign_set_rhs_with_ops` reallocates `stmt` in `*gsi` when `gimple_num_ops (stmt) < new_rhs_ops + 1` (invalidating cached pointers), and both it and `gimple_move_vops` must update `SSA_NAME_DEF_STMT` on the LHS and `vdef`. [F94, F96, F115]
- In `gimple_copy`, clear `use_ops` via `gimple_set_use_ops (copy, NULL)`, allocate a fresh `iter` vector for `GIMPLE_OMP_FOR`, `unshare_expr` all tree operands, and for `gimple_has_substatements` deep-copy nested `gimple_seq`s via `gimple_seq_copy` and unshare extra tree fields. Callers inserting the copy into SSA must update operand caches and replace duplicated `vdef`s. [F95, F112, F119]
- Statement `visited`, `plf`, and `uid` fields are undefined at pass boundaries and must be initialized before reading. `auto_edge_flag` and `auto_bb_flag` only release the bit in `cfg->*_flags_allocated` on destruction; callers must clear the bit from all marked edges or blocks before returning. [F118, F226]
- `vec<T>` (unlike `auto_vec<T>`) has no destructor: callers of `get_loop_latch_edges` and `assign_parms_augmented_arg_list` must call `.release ()` on all return paths. In `gimple-predicate-analysis.cc`, destroying or clearing `predicate::m_preds` (`vec<pred_chain>`) must call `.release ()` on every inner `m_preds[i]` first, copying `pred_chain`s must use `.copy ()`, and abandoned local `pred_chain`s must call `.release ()`. Callers of `get_loop_body*` and `get_block_vector` must `free` the returned array on all paths. [F280, F282, F398, F403, F464, F465, F466, F467]
- Bitmaps on `stack_var_bitmap_obstack` may only be allocated between `init_vars_expansion` and `fini_vars_expansion`; `vars_ssa_cache::add_one` and `update` must call `unshare` before mutating the shared `empty` bitmap, `vars_ssa_cache::operator()` must call `create (use)` before walking `use`'s operands, and `add_scope_conflicts` must `BITMAP_FREE (bb->aux)` across all blocks before returning. Passes calling `enable_ranger (fun)` must call `disable_ranger (fun)` before returning and query via `get_range_query (fun)`. [F274, F275, F283, F284, F425, F493]

## API Contracts

- `expand_expr_real_2` and `do_store_flag` take `const_sepops` and must copy `*ops` into a local `separate_ops` before mutating `code` or operands. Callers of `emit_push_insn` must pass a non-null `tree` `type`, and callers of `emit_library_call_value_1` must pre-convert every argument to its non-`BLKmode` `arg.mode`. [F27, F75, F256]
- `gimple_call_builtin_p` and `gimple_call_combined_fn` must verify `gimple_builtin_call_types_compatible_p` (resolving `BUILT_IN_NORMAL` decls via `builtin_decl_explicit` and checking `targetm.calls.promote_prototypes`). `gimple_call_arg_flags`/`retslot_flags` must mask modref flags with `interposable_eaf_flags` when `!node->binds_to_current_def_p ()`, and `fndecl_abi` requires `flag_ipa_ra && decl_binds_to_current_def_p (fndecl)` to use `function_used_regs`. `infer_nonnull_range_by_dereference` requires `flag_delete_null_pointer_checks`, `!gimple_clobber_p`, non-`GIMPLE_ASM`, and `!targetm.addr_space.zero_address_valid (as)`. [F99, F124, F127, F128, F134, F435]
- `set_cfun`/`push_cfun`/`pop_cfun` calls `redirect_edge_var_map_empty ()` when switching functions, so flush pending edge-redirection PHI updates first. `set_loops_for_fn` asserts `fn->x_current_loops == NULL || loops == NULL`, and `flow_loops_find` asserts `loops->exits == NULL` (call `release_recorded_exits` first). Never call `insert_insn_on_edge` or `prepend_insn_to_edge` on an abnormal critical edge, and `commit_one_edge_insertion` must split `e` whenever `e->src` ends in a non-`simplejump_p` jump (`asm goto`). [F308, F368, F423, F424]

## Error Handling

- `expand_assignment` must check `TREE_CODE (to) == ERROR_MARK` before inspecting `TREE_TYPE (to)` (still calling `expand_normal (from)`), `expand_expr_real` must check `ERROR_MARK` on `exp` and `TREE_TYPE (exp)`, and `fold_builtin_1`/`2`/`3` must check `error_operand_p` on all args. In `bitint_large_huge::lower_muldiv_stmt` and `lower_float_conv_stmt`, only set `gimple_call_set_nothrow` when `!stmt_ends_bb_p (stmt)`, and when a lowered statement or load ends a BB (`eh`), split the BB and call `add_eh_edge` (copying non-virtual PHI args while skipping `virtual_operand_p` PHIs). [F29, F158, F487, F488, F505]

## External Contracts

- In `expand_expr_real_1`, when reading a non-`BLKmode` `BITINT_TYPE` from memory, `CALL_EXPR`, `PARM_DECL`, or `RESULT_DECL`, `EXTEND_BITINT` must call `reduce_to_bit_field_precision`, but must NOT call it when `modifier` is `EXPAND_MEMORY`, `EXPAND_WRITE`, `EXPAND_INITIALIZER`, or `EXPAND_CONST_ADDRESS`, or when `SSA_NAME_VAR` is null or a `VAR_DECL`. `emit_block_op_via_libcall` and `set_storage_via_libcall` must use `build_call_expr`/`expand_call` (marking `MEM_EXPR`s addressable) rather than `emit_library_call`. [F40, F64, F67]

## Known Pitfalls

- In `expand_expr_real_2`, never assign an intermediate RTX (like a `VOIDmode` `CONST_INT`) to `target` before `REDUCE_BIT_FIELD`, which passes `target` to `reduce_to_bit_field_precision` (asserting `!target || GET_MODE (target) == mode`). In `expand_gimple_stmt_1`, if a non-`GIMPLE_SINGLE_RHS` `GIMPLE_ASSIGN` LHS expands to a `SUBREG_PROMOTED_VAR_P` `target`, pass `NULL_RTX` to `expand_expr_real_gassign` and `convert_move` into `SUBREG_REG (target)`. [F1, F321]
- For `GIMPLE_SINGLE_RHS` assignments, always use `gimple_assign_rhs_code` (`TREE_CODE (gs->op[1])`) rather than `gs->subcode`. `gimple_build_assign_1` with `COND_EXPR` forbids `COMPARISON_CLASS_P (op1)`, and `canonicalize_cond_expr_cond` results must pass `is_gimple_condexpr_for_cond` (`!tree_could_throw_p`) before `GIMPLE_COND`. `is_a <scalar_int_mode>` includes `MODE_PARTIAL_INT` (unlike `is_int_mode`), and `GET_MODE_NEXT_MODE` can yield a same-precision mode (use `GET_MODE_WIDER_MODE` for strictly wider). [F104, F107, F131, F132, F422]
- In `expand_builtin_*`, stabilize `CALL_EXPR_ARG` with `builtin_save_expr` before a fallible optab expansion that may fall back to `expand_call`; set `TREE_SIDE_EFFECTS (call) = 1` before `save_expr` on `IFN_*_OVERFLOW` calls; and clear `CALL_EXPR_TAILCALL (exp) = 0` before `expand_call` in `expand_builtin_atomic_fetch_op` when `!ignore`. In `gimple_lower_bitint`, force single-use large/huge `_BitInt` SSA names into `m_names` when feeding `VIEW_CONVERT_EXPR` to huge/non-int types, bit-field stores from shift/mul/div/`FIX_TRUNC`/`REALPART`, or signed-to-unsigned/nested casts into div/mod/mul/`FLOAT_EXPR`. [F162, F163, F189, F490, F491]
