# fortran

The `fortran` unit implements the GNU Fortran (`gfortran`) front end, parsing and resolving Fortran declarations, expressions, symbols, interfaces, and intrinsics, running AST-level optimization and warning passes, and lowering the Fortran parse tree (`gfc_symbol`, `gfc_expr`, `gfc_code`) into GCC GENERIC `tree` nodes, descriptors, and runtime calls.

## Architecture & Data Flow

- For `BT_CLASS` symbols, components, and expressions, `ts.u.derived` is the class container; the declared type, `as`, `dimension`, `codimension`, `allocatable`, `alloc_comp`, `pointer_comp`, and pointer status (`attr.class_pointer`, because `attr.pointer` is always set on class containers) reside on `CLASS_DATA (...)` (`sym->ts.u.derived->components`), except `compare_rank` uses `sym->as` when `sym->ts.u.derived->attr.unlimited_polymorphic` is set [F14, F16, F123, F124, F168, F174, F217, F405, F449].
- Before reading `CLASS_DATA` on a `BT_CLASS` symbol or expression, callers (`IS_POINTER`, `IS_PROC_POINTER`, `compare_allocatable`, `compare_parameter`, `matching_typebound_op`, `gfc_compare_types`) must verify `class_ok` and non-NULL `CLASS_DATA` (falling back to `sym->attr.pointer`/`proc_pointer` when unbuilt), and `gfc_type_compatible` must unwrap `ts->u.derived->components->ts.u.derived` when `attr.is_class` is set [F169, F208, F210, F216, F253].
- When checking if a `TREE_TYPE` is a class container in `build_array_ref` and `gfc_get_class_from_expr`, walk `TYPE_CANONICAL` to test `GFC_CLASS_TYPE_P` (dereferencing a pointer-typed base `VAR_P`/`PARM_DECL` first in `gfc_get_class_from_expr`), and in `gfc_class_vptr_get`, `gfc_class_len_get`, and `get_array_span`, replace `decl` with `GFC_DECL_SAVED_DESCRIPTOR (decl)` when present before accessing class fields [F315, F350, F357, F452].
- In `gfc_get_symbol_decl`, a `BT_CLASS` symbol with null `CLASS_DATA (sym)->ts.u.derived->backend_decl` must call `gfc_find_derived_vtab` and `gfc_get_derived_type` before building its decl; for a dummy `IS_CLASS_COARRAY_OR_ARRAY (sym)`, call `gfc_build_dummy_array_decl` when `GFC_DECL_SAVED_DESCRIPTOR` is unset and only set `GFC_DECL_CLASS = 1` when `!IS_CLASS_COARRAY_OR_ARRAY (sym)` [F18, F35].
- Coarray dimensions in `gfc_array_spec` and `gfc_array_ref` sit at indices `rank .. rank + corank - 1` (`ar.dimen .. ar.dimen + ar.codimen - 1`); `merge_array_spec` must shift existing cobounds down from `corank - 1` to `0` by `from->rank`, track `k = from->rank + i` and `j = to->rank + i` separately, clamp at `GFC_MAX_DIMENSIONS`, and forbid `corank > 0` on `AS_ASSUMED_RANK` [F59, F60, F63, F89, F107].
- The final dimension of an `AS_ASSUMED_SIZE` array (`dim == rank - 1`) and the final codimension (`dim == rank + corank - 1`) have no upper bound: `gfc_build_qualified_array` must not create `GFC_TYPE_ARRAY_UBOUND` for them, `check_dummy_characteristics` must stop at `rank + MAX(0, corank - 1)`, `gfc_caf_get_image_index` must guard extent multiplication with `i < dimen + codimen - 1`, and `scalarized_expr` must stop at `ar->dimen - 1` (`AR_SECTION`) [F1, F150, F188, F337].
- Scalarizer loops omit `DIMEN_ELEMENT` dimensions: `gfc_walk_array_ref` records only `DIMEN_RANGE`/`DIMEN_VECTOR` in `newss->dim[0..dimen-1]`, so mapping between scalarizer loop dimensions and array-ref/descriptor dimensions in `trans-array.cc`, `gfc_conv_expr_descriptor`, `gfc_dep_resolver`, `find_array_section`, and `scalarized_expr` must use `ss->dim`, `get_scalarizer_dim_for_array_dim`, `get_array_ref_dim_for_loop_dim`, or a separate non-`DIMEN_ELEMENT` counter [F58, F104, F149, F282, F283, F285].
- In `gfc_trans_create_temp_array`, shifting `loop->from[n]` and `loop->to[n]` to zero-based bounds requires clearing `loop->specloop[n] = NULL` so `gfc_set_delta` recalculates delta; in `gfc_alloc_allocatable_for_assignment`, LHS reallocation must update `linfo->saved_offset` (not `linfo->offset`) and `linfo->delta[lss->dim[n]]` (when `VAR_P`) [F284, F286].
- When initializing scalarizer loops for masked reductions (`gfc_conv_intrinsic_arith`, `gfc_conv_intrinsic_minmaxloc`, `gfc_conv_intrinsic_findloc`, `gfc_conv_intrinsic_minmaxval`), `maskss` must be added via `gfc_add_ss_to_loop` before `arrayss` because loop bounds come from the last `gfc_ss` added; scalarized bound/cobound/`this_image` intrinsics (`se->ss != NULL`) must call `gfc_advance_se_ss_chain (se)` [F388, F393].
- In an extended derived type (`sym->attr.extension`, checked `< 255` before incrementing), the parent type is the first component (`sym->components->ts.u.derived`) and parent PDT `formal` parameters are prepended to `sym->formal`; `gfc_get_derived_super_type` must unwrap `attr.generic` via `gfc_find_dt_in_generic`, `find_component_ref` must step into parent constructors, and `gfc_conv_variable`/`conv_base_obj_fcn_val` must call `conv_parent_component_references` before `gfc_conv_component_ref` [F65, F73, F122, F252, F348].
- Before dispatching in `gfc_conv_variable` or `gfc_conv_expr`, call `gfc_fixup_inferred_type_refs` (when `IS_INFERRED_TYPE (expr) && expr->ref`) and `gfc_fix_class_refs`, and rewrite `BT_DERIVED` `ISO_C_BINDING` void pointers (`ts.f90_type == BT_VOID && attr.is_bind_c`) in place to `EXPR_NULL` (for `C_NULL_PTR`/`C_NULL_FUNPTR`) or `BT_INTEGER` of `gfc_index_integer_kind` [F354, F355].
- When lowering Fortran bit intrinsics (`dshift`, `ibits`, `shift`, `ishft`, `mask`, `mvbits`), guard `LSHIFT_EXPR`/`RSHIFT_EXPR` with `COND_EXPR` for shift counts `>= TYPE_PRECISION` and convert to `unsigned_type_for (type)` for logical right shifts; for `leadz`, `trailz`, and `popcnt_poppar`, convert to `gfc_build_uint_type (argsize)` before the C unsigned type, guard 0 inputs in `leadz`/`trailz`, subtract `TYPE_PRECISION (arg_type) - argsize` in `leadz`, and split `argsize > LONG_LONG_TYPE_SIZE` into two `long_long_unsigned_type_node` halves [F424, F425, F427, F432, F433].

## Object Lifetimes

- In `gfc_replace_expr (dest, src)`, `free_expr0 (dest)` frees all sub-allocations of `dest` before shallow-copying `*src` into `*dest` and calling `free (src)` without freeing `src`'s sub-allocations: any sub-allocation moved from `dest` to `src` must be detached from `dest` first, and in `gfc_convert_type_warn`/`gfc_convert_chartype` the outer `new_expr` shell copied back into `*expr` must be freed with `free (new_expr)`, not `gfc_free_expr` [F115, F207].
- Because `free_expr0` switches on `expr_type` and (for `EXPR_CONSTANT`) `ts.type`, any temporary `gfc_expr` whose `expr_type` was mutated in place (e.g., `get_proc_ptr_comp`) must restore `expr_type` before `gfc_free_expr`, any non-owning `EXPR_CONSTANT` (e.g., `gfc_get_iokind_expr`) must use a non-owning `ts.type` like `BT_LOGICAL`, and `match_clist_expr` must clear `expr->value.constructor = NULL` before freeing `expr` and `array_head` [F69, F116, F345].
- Every `gfc_ss` chain from `gfc_walk_expr`/`walk_coarray` must belong to at most one `gfc_loopinfo` and either be attached via `gfc_add_ss_to_loop` and cleaned up with `gfc_cleanup_loop` (not `gfc_free_ss_chain`, and never by an inner function on a `ploop` from `enter_nested_loop`) or freed with `gfc_free_ss_chain` on all non-loop paths (including `gfc_walk_elemental_function_args` when `scalar == 1`); `ss_info->data.array.subscript` is only freed by `free_ss_info` when `type == GFC_SS_SECTION` [F295, F296, F297, F298, F398, F446].
- Every `stmtblock_t` opened with `gfc_start_block` pushes a binding level (`has_scope = 1`) that must be popped on all paths via `gfc_finish_block` or `gfc_merge_block_scope` (and cannot be passed as `append` to `gfc_add_block_to_block`), and any temporary `VAR_DECL` used outside that inner scope must be created before `gfc_start_block` or via `gfc_create_var_np` / `gfc_evaluate_now_function_scope` [F441, F442].
- Callers of `gfc_array_dimen_size`, `gfc_array_size`, `gfc_ref_dimen_size`, `gfc_dep_difference`, `spec_size`, and `insert_index` must call `mpz_clear` on the output `mpz_t` if and only if the function returned `true`; in `find_array_section` and `do_subscript`, all initialized `mpz_t` variables must be cleared on every exit path [F67, F117, F118, F164, F165].
- Before freeing a symbol with `gfc_free_symbol` outside undo rollback or namespace teardown, call `gfc_commit_symbol (sym)`; `gfc_delete_symtree` does not decrement `sym->refs` (callers must call `gfc_release_symbol`, which breaks `formal_ns` cycles via `cyclic_reference_break_needed` before decrementing `refs`); `free_old_symbol` must only free `as`, `value`, and `formal` when distinct from `sym`'s pointers (and `CLASS_DATA (sym)->as`); and `gfc_free_interface_mapping` must null `new_sym->n.sym->formal` before `gfc_free_symbol` and be called on every exit after `gfc_init_interface_mapping` [F247, F248, F249, F271, F343, F344].

## API Contracts

- Before inspecting `sym->components` on an `FL_DERIVED` symbol, `gfc_find_component` and `gfc_match_data_decl` must resolve `sym` via `gfc_use_derived (sym)` (and lowercase derived-type lookups must unwrap `attr.generic` via `gfc_find_dt_in_generic`), whereas `gfc_add_component` must scan `sym->components` directly and only call `gfc_find_component` on the parent type when `sym->attr.extension` is set [F82, F84, F255, F256].
- `gfc_reduce_init_expr` must hold `gfc_init_expr_flag = true` across `gfc_resolve_expr` and `gfc_check_init_expr` and reset it to `false` on exit, and does not free `expr` on failure; `scalarize_intrinsic_call` must receive `init_flag = true` from `gfc_check_init_expr` and `false` from `gfc_simplify_expr`; and `gfc_is_constant_expr` requires prior simplification because it returns `false` for unexpanded `FL_PARAMETER` `EXPR_VARIABLE`s [F120, F125, F126, F128].
- When matching a `BT_CLASS` or `UNLIMITED_POLY` dummy or pointer LHS against a target (`compare_parameter`, `gfc_compare_actual_formal`, `gfc_find_specific_dtio_proc`, `gfc_check_pointer_assign`), call `gfc_find_derived_vtab` or `gfc_find_vtab` to ensure the vtable exists; before walking or converting a `BT_CLASS` array descriptor in `trans-intrinsic.cc`, call `gfc_add_class_array_ref` (or `gfc_add_data_component` for scalars in `gfc_conv_allocated`), and pass class vtable sizes through `gfc_resize_class_size_with_len` when computing storage sizes or array spans [F133, F218, F404, F406, F412, F455].
- In `gfc_add_modify_loc`, the LHS and RHS of a `MODIFY_EXPR` must share `TYPE_MAIN_VARIANT` unless `AGGREGATE_TYPE_P (TREE_TYPE (lhs))`; `gfc_evaluate_data_ref_now` must take the address of an lvalue (`DECL_P`, `REFERENCE_CLASS_P`, `INDIRECT_REF_P`) into a pointer temporary and dereference it rather than copying by value; and `gfc_build_array_ref` with `span == NULL_TREE` may only build `ARRAY_REF` when `non_negative_offset` is true (using `POINTER_PLUS_EXPR` + `INDIRECT_REF` otherwise) and must set `TREE_ADDRESSABLE = 1` on `DECL_P` bases (as must `gfc_build_addr_expr`) [F465, F467, F469, F470].

## Error Handling

- Speculative simplification and trial checks (`gfc_match_char_spec`, `insert_index` in `frontend-passes.cc`, `gfc_extend_expr` for `UNLIMITED_POLY` operator interfaces, and `gfc_intrinsic_func_interface`/`gfc_intrinsic_sub_interface` when `!error_flag`) must be bracketed by `gfc_push_suppress_errors ()` and `gfc_pop_suppress_errors ()` on all return paths; `gfc_try_simplify_expr` must save/clear `gfc_seen_div0`, simplify a copy `n`, replace `e` only if `gfc_simplify_expr (n, type) && !gfc_seen_div0` (freeing `n` otherwise), and restore `gfc_seen_div0` [F95, F141, F179, F225, F226].

## External Contracts

- Procedure argument lists in `create_function_arglist`, `gfc_get_function_type`, and `gfc_conv_procedure_call` must be ordered identically: `__entry` (which `gfc_get_symbol_decl` must skip via `DECL_CHAIN` when `attr.entry_master` is set to locate `__result`), by-reference `__result` (and character `.__result`), explicit dummy arguments, `optval_arglist` `boolean_type_node` presence flags for every scalar dummy with `attr.optional && attr.value && !attr.dimension && ts.type != BT_CLASS` (including derived types), and `hidden_arglist`/`stringargs` (omitted when `sym->attr.is_bind_c` or for `C_PTR`/`TYPE(*)`/`CLASS(*)` dummies, except `__vtab_CHARACTER` copy calls) [F4, F21, F49, F365, F386].
- In `gfc_conv_cfi_to_gfc` and `gfc_conv_gfc_desc_to_cfi_desc`, `CFI_cdesc_t` fields must be indexed as `base_addr` (0), `elem_len` (1), `version` (2), `rank` (3), `attribute` (4), `type` (5), `dim` (6) and `CFI_dim_t` as `lower_bound` (0), `extent` (1), `sm` (2); even when `!sym->attr.referenced`, `gfc_conv_cfi_to_gfc` must free/nullify `INTENT(OUT)` `ALLOCATABLE` descriptors and emit bounds checks (guarded by `cfi_desc != null_pointer_node` when `optional`); and GFC descriptor `span` must be set to `(cfi->dim[0].sm % elem_len) ? cfi->dim[0].sm : elem_len` (or `cfi->dim[0].sm` for `allocatable` in `gfc_conv_gfc_desc_to_cfi_desc`) and multiplied back into `cfi->dim[i].sm` on exit [F23, F24, F335, F364].

## Known Pitfalls

- When `gfc_code_walker` traverses statements, capture `co = *c` before walking subexpressions/subcodes because callbacks like `create_var` can replace `*c` with an `EXEC_BLOCK`; optimization callbacks in `frontend-passes.cc` must bail out when `in_assoc_list` is true (`co->ext.block.assoc`), and namespace passes recursing over `ns->contained` after `gfc_code_walker` must skip child namespaces where `ns->code && ns->code->op == EXEC_BLOCK` [F155, F171, F183].
- Because `gfc_typenode_for_spec` mutates its `gfc_typespec` argument for `ISO_C_BINDING` types (setting `ts.type = BT_INTEGER`) and `gfc_add_vptr_component` / `gfc_add_size_component` / `gfc_add_hash_component` overwrite `arg->ts`, callers must pass a local `ts` copy in `gfc_element_size`, special-case `ISOCBINDING_PTR`/`ISOCBINDING_FUNPTR` before `gfc_typenode_for_spec` in `gfc_interpret_derived`, and test `UNLIMITED_POLY (arg)` before adding `_vptr`/`_size`/`_hash` components in `gfc_conv_intrinsic_storage_size` and `gfc_conv_same_type_as` [F264, F281, F402].
- Variable-length character and array types (`GFC_TYPE_ARRAY_DATAPTR_TYPE` in `gfc_trans_create_temp_array`/`gfc_conv_ss_descriptor`, by-reference character results in `gfc_conv_procedure_call`, and `-fstack-arrays` allocations in `gfc_trans_allocate_array_storage`/`gfc_trans_auto_array_allocation`) require emitting a `DECL_EXPR` for the VLA `TYPE_DECL` or stack `VAR_DECL` in `pre` so the gimplifier evaluates its size [F325, F326, F328, F366].
