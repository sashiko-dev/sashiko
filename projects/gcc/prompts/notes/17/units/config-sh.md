# config-sh

This unit implements the core Renesas/SuperH (SH1 through SH4A and SH2A) target backend in `gcc/config/sh/sh.h` and `gcc/config/sh/sh.cc`. It defines machine layout, register classes, calling conventions (GNU, Renesas/Hitachi, and FDPIC ABIs), instruction cost models, and `targetm` hooks, alongside RTL expansion, prologue/epilogue generation, FPU FPSCR mode switching, register-pressure-aware scheduling, machine-dependent reorganization (`sh_reorg`) for constant pools and far-branch splitting, and T-bit expression recognition/splitting.

## Architecture & Data Flow

- In `split_branches`, `get_dest_uid` must advance `dest` past any instruction with `INSN_UID (dest) >= max_uid`, because `uid_branch` and `INSN_ADDRESSES` are sized to `max_uid` at entry and cannot be indexed by newly emitted branch-redirection blocking instructions; when `optimize` is nonzero, `untangle_mova` must also check `INSN_ADDRESSES_SIZE () <= (unsigned) INSN_UID (new_mova)` before reading `INSN_ADDRESSES (INSN_UID (new_mova))`, returning `-1` if `new_mova` was emitted after `shorten_branches`. [F8, F9]
- In `find_barrier`, `label_to_alignment (from)` must only be queried when `CODE_LABEL_NUMBER (from) <= max_labelno_before_reorg` (captured from `max_label_num ()` at `sh_reorg` entry), because recursive calls to `find_barrier` can encounter newly inserted constant-table labels created after `compute_alignments`. [F10]
- Because `pool_vector` has a fixed capacity of `MAX_POOL_SIZE` (372) entries sized for a single PC-relative constant pool window (up to 1018 bytes), `dump_table` and `output_jump_label_table` must reset `pool_size = 0` (and `pool_window_label = NULL`, `pool_window_last = 0` in `dump_table`) after emitting each table. [F12]
- In `sh_reorg`, when chaining consecutive FP constant pool loads by rewriting `*last_float_addr` to `r0_inc_rtx` (`@r0+`), any `REG_UNUSED` note for `r0` on `last_float_move` must be changed to `REG_INC`; similarly, when `sh_extending_set_of_reg::use_as_extended_reg` converts a non-extending `QImode`/`HImode` `MEM` load into `gen_extendqisi2`/`gen_extendhisi2`, it must pass the emitted insn through `sh_check_add_incdec_notes`. [F53, F54]
- In `sh_try_split_insn_simple`, the recursive splitting loop must check `if (i == seq)` and `if (i == seqlast)` (updating `seq = ii.first` and `seqlast = ii.second; break;`) before assigning `i = ii.first`, because `i` is unlinked and replaced by `[ii.first, ii.second]` during the recursive call. [F7]
- In `sh_split_movrt_negc_to_movt_xor`, deleting the redundant subsequent T-bit setting instruction `t_after_negc.insn` requires checking `can_create_pseudo_p ()` and verifying that `t_after_negc.insn` is not `sh_unspec_insn_p`, `volatile_insn_p`, `side_effects_p`, or `may_trap_or_fault_p`. [F40]
- `sh_is_nott_insn` must check both `i != NULL_RTX` and `PATTERN (i) != NULL_RTX` before inspecting `GET_CODE (PATTERN (i))`. [F26]
- `sh_find_equiv_gbr_addr` must return `NULL_RTX` when `df == NULL` or `side_effects_p (XEXP (mem, 0))` is true, and when `sh_find_base_reg_disp` resolves to `GBR_REG`, it must return `NULL_RTX` if `DF_REG_DEF_CHAIN (GBR_REG)` contains any non-`CALL_P` insn or any `CALL_P` insn when `GBR_REG` is in `regs_invalidated_by_call`. [F42]
- In `sh_init_builtins`, each enabled builtin's function code passed to `add_builtin_function` must be its index `d - bdesc` in `bdesc` (not an enabled-builtin counter) because `sh_builtin_decl` and `sh_expand_builtin` index `bdesc` directly by `code`; when iterating `i` from `3` down to `0` over `signature_args[signature][i]`, `insn_data[d->icode].operand` must be indexed at `opno = i - 1 + has_result` and `args[i - 1]` written only after breaking on `i == 0`, while in `sh_expand_builtin`, `nop` indexes `op[]` and `insn_data[icode].operand[nop]` and `i` (`1..3`) indexes `signature_args[signature][i]` and `CALL_EXPR_ARG (exp, i - 1)`. [F3, F4, F5]
- In `push_regs` and `sh_expand_epilogue`, the general register loops for interrupt handlers must exclude `0 .. LAST_BANKED_REG` (`i = LAST_BANKED_REG + 1` in `push_regs`, `last_reg = FIRST_PSEUDO_REGISTER - LAST_BANKED_REG - 1` in `sh_expand_epilogue`) because banked registers are handled in a separate pass. [F6]
- In `sh_insert_attributes`, when applying `sh_deferred_function_attributes` to a `FUNCTION_DECL` lacking `interrupt_handler`, `trapa_handler` must synthesize `interrupt_handler`, whereas `sp_switch`, `trap_exit`, `nosave_low_regs`, and `resbank` must be stripped with an `OPT_Wattributes` warning before resetting `sh_deferred_function_attributes` and `sh_deferred_function_attributes_tail` (`&sh_deferred_function_attributes`). [F30]
- `find_sole_member` must ignore non-`FIELD_DECL` nodes and zero-sized `FIELD_DECL`s (`integer_zerop (DECL_SIZE (field))`) in `TYPE_FIELDS (type)`, and return `NULL_TREE` if any `FIELD_DECL` has a null `DECL_SIZE` or if more than one non-zero-sized `FIELD_DECL` exists; when `sh_gimplify_va_arg_expr` unwraps single-member `RECORD_TYPE`s via `find_sole_member`, it must only advance `eff_type` to `TREE_TYPE (member)` if `TYPE_MODE (eff_type) == TYPE_MODE (field_type)` and break otherwise. [F22, F23]
- In `sh_hard_regno_mode_ok`, `V2SFmode` must only be accepted in even-numbered FP registers (`FP_REGISTER_P (regno) && (regno - FIRST_FP_REG) % 2 == 0`) and rejected for general registers; in `sh_modes_tieable_p`, `SFmode` must never be tieable with any other FP mode (`mode1 != SFmode && mode2 != SFmode` when `mode1 != mode2`), because `XD_REGISTER_P` registers accept `DFmode` but cannot hold `SFmode`. [F44, F48]
- In `sh_can_change_mode_class`, changing from a vector mode with `SFmode` inner elements to `SFmode` must disallow register classes intersecting `GENERAL_REGS` when `optimize` is nonzero, and allow it when `!optimize`; in `sh_hard_regno_caller_save_mode`, caller-save mode selection for `FP_REGISTER_P (regno)` with `SFmode`, `SCmode`, or even-register `DFmode`/`DCmode` must return `mode` directly before falling back to `choose_hard_reg_mode`. [F46, F47]
- `sh_cannot_substitute_const_equiv_p` must return `true` when `subst` is an `SFmode` `CONST_DOUBLE` equal to `0.0` (`dconst0`) or `1.0` (`dconst1`) so LRA does not substitute them into moves that become single-mode-only `fldi0`/`fldi1` instructions after mode switching. [F61]
- In `sh_max_mov_insn_displacement`, when `!consider_sh2a && TARGET_FPU_ANY`, all modes satisfying `FLOAT_MODE_P (mode)` (including vector float modes) must return `0` displacement; in `sh_legitimate_index_p`, when `!allow_zero` and `sh_max_mov_insn_displacement (mode, consider_sh2a) < 1`, even a `0` displacement must return `false`. [F45, F55]
- In `output_movedouble`, when copying a 64-bit value (`DImode`/`DFmode`) where `REGNO (src) + 1 == REGNO (dst)` or loading from a `MEM` whose base register `ptrreg` equals `REGNO (dst)`, the second word (`%T1`, `%T0`) must be moved before the first (`%1`, `%0`); in `sh_print_operand`, `%R` (LSW) and `%S` (MSW) must always treat `FP_REGISTER_P (regno)` pairs as big-endian (`regno + 1` for `%R`, `regno + 0` for `%S`), whereas non-FP registers and `MEM` addresses use `SH_REG_LSW_OFFSET` and `SH_REG_MSW_OFFSET`. [F59, F60]
- In `sh_emit_mode_set`, emitting `gen_toggle_pr ()` (and `gen_toggle_sz ()` when `TARGET_FMOVD`) must be gated on `(TARGET_SH4A_FP || TARGET_FPU_SH4_300) && prev_mode != FP_MODE_NONE && prev_mode != mode`; in `sh_emit_set_t_insn`, when `TARGET_FPU_ANY && GET_MODE_CLASS (mode) == MODE_FLOAT` and `GET_CODE (insn) != PARALLEL`, the T-bit-setting instruction must be wrapped in a `PARALLEL` containing a `CLOBBER` of `FPSCR_STAT_REG` and a `USE` of `FPSCR_MODES_REG`. [F62, F63]
- For `MODE_FLOAT` `GE` (and swapped `LE`) comparisons when `TARGET_IEEE` is enabled, `sh_emit_compare_and_branch` (on `TARGET_SH2E`) and `sh_emit_compare_and_set` must decompose `GE` into separate `GT` and `EQ` comparisons rather than inverting `LT` (which fails on NaN). [F64]
- In `sh_option_override`: when `targetm.small_register_classes_for_mode_p (VOIDmode)` is true, `flag_schedule_insns` must be forced to `0` if `!TARGET_HARD_SH4 || flag_pic`, `flag_exceptions`, or `!OPTION_SET_P (flag_schedule_insns)`; `TARGET_FSRRA` requires `flag_unsafe_math_optimizations && flag_finite_math_only`, and `TARGET_IEEE` (if `!OPTION_SET_P`) must be enabled whenever `!flag_finite_math_only`; `-mdiv=call-table` (`SH_DIV_CALL_TABLE`) must be gated on `TARGET_DYNSHIFT` (`TARGET_SH3 || TARGET_SH2A`) and never enabled for plain `TARGET_SH2`. [F34, F65, F72]
- In `find_regmode_weight`, after `get_ebb_head_tail (b, b, &head, &tail)` obtains the inclusive instruction bounds of basic block `b`, the exclusive loop bound must be `next_tail = NEXT_INSN (tail)` so `for (insn = head; insn != next_tail; insn = NEXT_INSN (insn))` processes `tail` even when `head == tail`. [F1]
- In `sh_adjust_cost` on `TARGET_SH4_300`, when reducing a true-dependency (`dep_type == 0`) cost by 2 for a store whose `SET_SRC` equals `SET_DEST (dep_set)`, the cost must be clamped to at least `1` if the store address `XEXP (SET_DEST (set), 0)` is `modified_in_p (..., dep_insn)`. [F38]
- `sh_can_follow_jump` must reject following `branch2` when `flag_reorder_blocks_and_partition && simplejump_p (branch2) && CROSSING_JUMP_P (branch2)`, and only allow following when `flag_expensive_optimizations && simplejump_p (branch2)` and the target label is within a cumulative `get_attr_length` distance of `< 256` from `NEXT_INSN (branch1)`. [F37]

## Object Lifetimes

- In `sh_reorg`, `label_ref_list_d` nodes allocated from `label_ref_list_d_pool` in `add_constant` are not freed when `dump_table` resets `pool_size` and `pool_window_last`; `sh_reorg` must call `label_ref_list_d_pool.release ()` after the `SH_FIXUP_PCLOAD` loop completes. [F18]
- Before invoking `split_branches` (which calls `shorten_branches`), `sh_reorg` must release the non-RAII `vec<int> insn_addresses_` buffer via `INSN_ADDRESSES_FREE ()`, and `split_branches` must call `init_insn_lengths ()` on exit, because `shorten_branches` calls `INSN_ADDRESSES_ALLOC` (`insn_addresses_.create`) without freeing prior allocations. [F19]
- `sh_md_init_global` allocates `regmode_weight[0]` and `regmode_weight[1]` with `xcalloc`, and `sh_md_finish_global` must `free` both buffers and reset their pointers to `NULL` at the end of the scheduling pass. [F20]

## API Contracts

- When `output_branchy_insn` emits a new label during assembly output via `emit_label_after`, it must register the label's address using `INSN_ADDRESSES_NEW` so that `INSN_ADDRESSES` grows to cover the new label's UID. [F11]
- When `fpscr_set_from_mem` is called after register allocation (`!can_create_pseudo_p ()`), callers such as `push_regs` must pass a `HARD_REG_SET` `regs_live` with at least `r1` or `r7` dead, and `fpscr_set_from_mem` must emit `gen_lds_fpscr` with a `POST_INC` address and `REG_INC` note using `get_free_reg (regs_live)`. [F68]
- `sh_peephole_emit_move_insn` must strip `POST_INC` from a `MEM` source via `sh_remove_overlapping_post_inc` whenever the incremented base register overlaps `dst` (`reg_overlap_mentioned_p (XEXP (addr, 0), dst)`), and must attach `REG_INC` notes via `sh_check_add_incdec_notes`. Broken by: calling `emit_move_insn` directly in a peephole2 pattern. [F52]
- `sh_movsf_ie_y_split_p` and `sh_movsf_ie_subreg_multiword_p` must match `SFmode` moves between a `REG_P` operand and a `SUBREG_P` of `SImode` or a multiword mode (`SCmode`, `DImode`, `TImode`) so `sh.md` predicates and splits them explicitly under LRA. [F49]
- In `sh_rtx_costs`, every memory access cost calculation (`MEM`, `MEM` inside `SIGN_EXTEND` or `TARGET_SH2A` `ZERO_EXTEND`, and `MEM` inside a `PARALLEL` `SET`) must add `COSTS_N_INSNS (1)` to `sh_address_cost` and pass the caller's `speed` argument through to `sh_address_cost`. [F35]
- In `sh_handle_resbank_handler_attribute`, `sh_handle_interrupt_handler_attribute`, `sh2a_handle_function_vector_handler_attribute`, `sh_handle_sp_switch_attribute`, and `sh_handle_trap_exit_attribute`, every validation failure that emits an `OPT_Wattributes` warning must also set `*no_add_attrs = true`. [F31]

## Error Handling

- Functions that recursively invoke `recog` or `split_insns` for T-bit expressions (`sh_recog_treg_set_expr` and `sh_split_treg_set_expr`) must guard `sh_recog_treg_set_expr_reent_count` with a local `scope_counter` and global `recog_data` with a local `recog_state_saver` before any re-entrant call or early return. [F21]
- `sh_attr_renesas_p` must check `td == NULL_TREE` before `DECL_P (td)`, and after replacing a decl with `TREE_TYPE (td)` must check `td == error_mark_node` before `TYPE_ATTRIBUTES (td)`; `sh_builtin_decl` must return `error_mark_node` when `code >= ARRAY_SIZE (bdesc)` or `!bdesc[code].is_enabled ()`, and `sh_expand_builtin` must return `const0_rtx` if any `CALL_EXPR_ARG (exp, i - 1)` is `error_mark_node` before reading `TREE_TYPE (arg)`. [F27, F28]
- In `split_branches`, when `get_dest_uid (far_label, max_uid)` returns 0 for a `TYPE_JUMP` instruction, `NEXT_INSN (far_label)` must be checked for non-null before redirecting the jump to `ret_rtx`, because parse errors can leave labels outside the instruction stream. [F33]

## External Contracts

- Sub-word integer argument and return mode promotion to `SImode` at ABI boundaries must be enforced via `TARGET_PROMOTE_FUNCTION_MODE` (`sh_promote_function_mode`) and `sh_function_value` using `sh_promote_prototypes` (which disables promotion under `TARGET_HITACHI` or `renesas` attribute), without defining `TARGET_PROMOTE_PROTOTYPES`; in `sh_c_mode_for_floating_type`, `TI_DOUBLE_TYPE` must map to `SFmode` when `TARGET_FPU_SINGLE_ONLY` is nonzero and `DFmode` otherwise. [F56, F66]
- Under `FUNCTION_ARG_SCmode_WART` on little-endian `TARGET_SH4`, `sh_function_arg` passes `SCmode` at an even FP offset in `(frN, frN+1)` and at an odd offset via a `PARALLEL` of XOR-1-swapped `SFmode` regs, while `sh_gimplify_va_arg_expr` extracts `imag` before `real` from the `DFmode`-saved `va_arg` slot; in `sh_build_builtin_va_list`, `TREE_PUBLIC (type_decl)` must be set to `1` on the `TYPE_DECL` assigned to `TYPE_NAME (record)` for `__va_list_tag` on non-Renesas SH2E/SH4 targets. [F25, F57]
- In `sh_load_function_descriptor`, `emit_insn (gen_blockage ())` must be emitted between loading the function entry point into `R1_REG` (`r1`) from `[funcdesc]` and loading the GOT address into `PIC_REG` (`r12`) from `[funcdesc + 4]`. [F58]
- In `gcc/config/sh/sh.h`, `UNSUPPORTED_SH2A` (expanded in `DRIVER_SELF_SPECS`) must account for both explicit command-line options (`-m2a*`, `-ml`, `-mb`) and build-time defaults (`TARGET_ENDIAN_DEFAULT` via `IS_LITTLE_ENDIAN_OPTION` and `TARGET_CPU_DEFAULT & MASK_HARD_SH2A` unless overridden by `-m1`, `-m2*`, `-m3*`, or `-m4*`). [F70]

## Known Pitfalls

- In `sh_recog_treg_set_expr`, the function must return `false` when `currently_expanding_to_rtl` is true or when `sh_recog_treg_set_expr_reent_count` exceeds 1, and must allocate its temporary `INSN` via `rtx_alloc (INSN)` with a constant `INSN_UID` rather than `make_insn_raw`. [F36]
- In `split_branches`, before calling `redirect_jump` on a jump instruction when `!optimize`, `JUMP_LABEL (insn)` must be set to the original target label and `LABEL_NUSES` of that label must be incremented so `redirect_jump` does not delete a still-referenced label. [F41]
- In `find_insn_regmode_weight`, the `PARALLEL` loop overwrites local variable `x` with `XVECEXP (PATTERN (insn), 0, j)` on each iteration, so the vector length `XVECLEN (x, 0)` must only be evaluated once in the loop initializer before `x` is mutated. Broken by: rewriting as a forward loop `for (j = 0; j < XVECLEN (x, 0); j++)` while still reassigning `x`. [F2]
