# config-i386

Implements the IA-32/x86-64 target backend (`i386.cc`, `i386-expand.cc`, `i386-features.cc`, `i386-options.cc`, `sse.md`, and related files), covering RTL expansion and splitting, SIMD patterns, calling conventions, stack frame layout and shrink-wrapping, register allocation/reload hooks, cost models, built-in folding, target options/attributes, and x86 RTL optimization passes (STV, x86 CSE, vzeroupper).

## Architecture & Data Flow

- Before reload (`can_create_pseudo_p ()`), `ix86_expand_move` and `ix86_expand_vector_move` must check `ix86_hardreg_mov_ok (op0, op1)` and route through a pseudo if false; after reload, `ix86_expand_clear` must assert `reload_completed` before widening a sub-32-bit `dest` to `gen_rtx_REG (SImode, REGNO (dest))`, and `split_double_mode` may only call `gen_reg_rtx (half_mode)` when `simplify_gen_subreg` returns NULL if `can_create_pseudo_p ()` is true (falling back to `CONST0_RTX (half_mode)` post-reload). [F29, F30, F32]
- In `ix86_expand_set_or_cpymem` and `ix86_expand_set_or_movmem`, constant `count > (HOST_WIDE_INT_1U << 30)` must return `false` before `decide_alg`; for `iscpymem || issetmem`, `ix86_expand_set_or_movmem` must return `false` if `count != 0`, `max_size == 0`, or `max_size == GET_MODE_MASK (counter_mode (count_exp))` (and assert `min_size != max_size` when `!CONST_INT_P (count_exp)`). `ix86_expand_unroll_movmem` must return `false` when `moves > 8` (`tmp[9]` limit). [F7, F8, F9, F36]
- Subroutines of `ix86_expand_vec_perm_const_1` must copy `*d` into a local `expand_vec_perm_d` before mutating `perm`, `vmode`, `nelt`, `op0`, `op1`, or `one_operand_p` on any failable path, and multi-step helpers (`expand_vec_perm_interleave2`, `expand_vec_perm_vperm2f128_vblend`, `expand_vec_perm_2perm_interleave`, `expand_vec_perm_2perm_pblendv`) must wrap tentative `expand_vec_perm_1` calls in `start_sequence ()`/`end_sequence ()` and emit only when all steps succeed and `!d->testing_p`. [F21, F22]
- In `ix86_vectorize_vec_perm_const`, if `canonicalize_perm (&d)` sets `d.one_operand_p = true` for `two_args` (`rtx_equal_p (d.op0, d.op1)`) and `ix86_expand_vec_perm_const_1 (&d)` fails, it must reset `d.one_operand_p = false` and restore `d.perm` from `perm` to retry. In `ix86_expand_vec_perm`, when `TARGET_AVX2` rewrites `V4DI`/`V4DF`/`V16HI` into `V8SI`/`V32QI`, it must update both `mask` and `operands[3]` to `t1` and copy the new `target` back via `gen_lowpart`. [F4, F20]
- `expand_vselect` and `expand_vselect_vconcat` must restore GTY-rooted `vselect_insn` fields (`SET_DEST`, `VEC_SELECT` source, `VEC_CONCAT` operands to `const0_rtx`, `INSN_CODE` to `-1`) and emit `copy_rtx (PATTERN (vselect_insn))`. [F12]
- `ix86_convert_const_wide_int_to_broadcast`, `ix86_broadcast_from_constant`, and `vec_duplicate<mode>` (over `INT_BROADCAST_MODE`, which includes `V64QI`/`V32HI` under `TARGET_AVX512F`) require `TARGET_INTER_UNIT_MOVES_TO_VEC` for integer modes; `ix86_broadcast_from_constant` must `simplify_subreg` `constant` to `mode`, `ix86_broadcast_inner` must ignore `REG_EQUAL`/`REG_EQUIV` `CONST_VECTOR`s with `GET_MODE (equal) != mode`, and `ix86_vec_bcast_map_simode` must stay sorted by ascending `unsigned int` key for `bsearch`. [F10, F31, F99, F194]
- `ix86_expand_vector_set` must check `IN_RANGE (elt, 0, GET_MODE_NUNITS (mode))` before `1 << elt` or indexing, emitting a no-op move and returning early if out of range. `ix86_expand_vector_extract` and `ix86_expand_pextr` must wrap `QImode`/`HImode` `VEC_SELECT` in `gen_rtx_ZERO_EXTEND (SImode, ...)`. In `ix86_expand_vector_set_var`, 512-bit byte/word vectors (`V32HI`, `V32HF`, `V32BF`, `V64QI`) without `TARGET_AVX512BW` must split into 256-bit halves, and `V8DImode`/`V4DImode` insertion in `ix86_expand_vector_init_one_nonzero`/`_one_var` requires `TARGET_64BIT`. [F39, F40, F42, F43]
- For `BFmode` compares when `!TARGET_AVX10_2 || flag_trapping_math`, `ix86_prepare_fp_compare_args` must promote to `SFmode` (`ix86_expand_branch` asserts `TARGET_AVX10_2 && !flag_trapping_math`). In `ix86_expand_fp_compare`, `UNSPEC_OPTCOMX` (`TARGET_AVX10_2`, `EQ`/`NE`) is only valid for `HFmode`/`SFmode`/`DFmode`, and `UNSPEC_NOTRAP` on `IX86_FPCMP_COMI` must exclude `BFmode`. In `ix86_fp_cmp_code_to_pcmp_immediate` and `ix86_print_operand` `'D'` (`TARGET_AVX`), `UNLE`/`UNLT`/`UNGE`/`UNGT`/`UNEQ` must map to quiet `_UQ`/`_uq` predicates. [F44, F45, F46, F170]
- `ix86_gen_ccmp_first` must reject `ORDERED`/`UNORDERED` and only call `split_comparison` when `!HONOR_NANS (op_mode)`. In `ix86_expand_int_movcc`, `reverse_condition_maybe_unordered` must be suppressed (`new_code = UNKNOWN`) on relational FP comparisons when `HONOR_NANS (cmp_mode) && flag_trapping_math`. In `ix86_expand_truncsfbf2`, software bit-manipulation must branch on `(reg1_si & 0x7f800000) == 0` to flush denormals to `tmp0 & 0x8000`; `ix86_expand_fast_convert_bf_to_sf` must fall back to an `SImode` `<< 16` shift when `simplify_const_unary_operation` returns NULL (sNaN). [F26, F47, F49, F50]
- In STV (`scalar_chain`): `convert_op` may only use `gen_lowpart (vmode, *op)` on a `SUBREG` if `modes_tieable_p` and `validate_subreg` hold; `convert_insn` must compute non-`REG` sources into a vector pseudo when `MEM_P (dst)`, use `gen_raw_REG (V1TImode, REGNO (...))` instead of `PUT_MODE` on hard registers, and wrap mutated `TImode` `DECL_ARGUMENTS` `DECL_RTL`/`DECL_INCOMING_RTL` back in `SUBREG (TImode, r, 0)`; `emit_conversion_insns` must split the fallthru edge if `control_flow_insn_p (after)`; and `convert_scalars_to_vector` (`converted_insns > 0`) must raise stack alignment to `>= 128` and call `fixup_tail_calls ()` if setting `drap_rtx`. [F86, F88, F100, F101, F102, F105]
- `rest_of_handle_insert_vzeroupper` must strip `REG_DEAD`/`REG_UNUSED` notes and call `df_remove_problem (df_note)` before `df_analyze ()`. Before `ix86_place_single_vector_set` or `ix86_place_single_tls_call`, `calculate_dominance_info (CDI_DOMINATORS)` and `loop_optimizer_init (AVOID_CFG_MODIFICATIONS)` must run. `ix86_place_single_vector_set` must keep `X86_CSE_VEC_DUP`/`X86_CSE_CONST_VECTOR` in the nearest common dominator (hoisting `CONST0`/`CONSTM1`/`nullptr` out of loops) and wrap `reg` in an integer `SUBREG` when `inner_scalar` is `CONST_INT_P` and `!SCALAR_INT_MODE_P (reg_mode)`. [F89, F90, F91, F98]
- In `pass_x86_cse::x86_cse`, `X86_CSE_VEC_DUP`/`X86_CSE_CONST_VECTOR` must only be CSEed within the same BB when `cfun->machine->recursive_function` is true, word-sized constant int vector loads must not be hoisted across `call_bbs`, and `CONST_INT_P` `load->val` in non-`MODE_VECTOR_INT` modes must convert `mode` via `int_mode_for_mode`/`mode_for_vector` before `gen_rtx_CONST_VECTOR`. `ix86_emit_tls_call` must hoist past live clobbered regs in `DF_LIVE_IN`/`DF_LR_IN` (and `crtl->drap_reg` in `DF_LR_IN`) via `ix86_get_dominator_for_reg`. [F92, F93, F96]
- In `ix86_emit_save_regs_using_mov`, `ix86_emit_restore_regs_using_mov`, `ix86_emit_prologue_components`, and `ix86_emit_epilogue_components`, `cfa_offset -= UNITS_PER_WORD` must execute for every `ix86_save_reg` even when skipped by shrink-wrapping. In `ix86_argument_passed_on_stack_p`, a `PARM_DECL` `MEM_EXPR` is caller-stack-passed only when `DECL_INCOMING_RTL (var) && MEM_P (DECL_INCOMING_RTL (var))`. [F113, F167]
- `ix86_hard_regno_mode_ok` must reject 16-bit modes in `SSE_REGNO_P` when `!TARGET_SSE2` (unless AVX512F/VL handles it); `ix86_can_change_mode_class` must return `false` for `MAYBE_FLOAT_CLASS_P` when `from != to`; `ix86_modes_tieable_p` must only tie `< 16`-byte `mode1` with `>= 16`-byte SSE `mode2` when `VECTOR_MODE_P (mode1) || SCALAR_FLOAT_MODE_P (mode1)`; `ix86_validate_address_register` must reject `SUBREG`s with inner `GET_MODE_SIZE > UNITS_PER_WORD` or failing `register_no_elim_operand`; and `ix86_get_ssemov` on `EXT_REX_SSE_REG_P` with `< 64` bytes and `!TARGET_AVX512VL` must assert `!memory_operand` on both operands. [F157, F158, F159, F160, F169]
- `ix86_gimple_fold_builtin` must check `ix86_check_builtin_isa_match` first; require `expr_not_equal_to (arg0, 0)` before lowering `TZCNT`/`LZCNT` to `CTZ`/`CLZ`; fold `PABS*` to `ABSU_EXPR` in `unsigned_type_for` with `VIEW_CONVERT_EXPR`; convert `PBLENDVB`/`BLENDVP*` masks to signed integer vectors before `< 0`; and in both `ix86_fold_builtin` and `ix86_gimple_fold_builtin`, must not fold AVX/AVX-512 min/max when `HONOR_NANS (arg0)` if SAE (`arg4 == 8`) in GIMPLE or if NaN elements lack SAE (`!= 8`) in constant folding. `ix86_vectorize_builtin_scatter` must reject unsigned indices narrower than `POINTER_SIZE`. [F151, F154, F155, F156, F172]
- In `sse.md` expanders: `VI_256_AVX2` in `vcond_mask_<mode><sseintvecmodelower>` must include `V8SI`/`V4DI` under `TARGET_AVX`; `V_ANY_CBRANCH` requires `TARGET_AVX512VL && TARGET_AVX512DQ` and `cond_vec_cbranch_all<mode>` must test `(cmp_mask & operands[1]) == 0`; `round<mode>2`/`lround*` require `!flag_trapping_math` while `floor`/`ceil`/`btrunc` must not; and `truncv*sfv*bf2` requires `!HONOR_NANS (BFmode) && !flag_rounding_math` (plus `flag_unsafe_math_optimizations` for permutation fallback). [F177, F180, F184, F195]
- In `sse.md` patterns/splitters: scalar `*andnot<mode>3`/`<code><mode>3` (`MODEF248`) and `sse4_1_blendv<ssemodesuffix>` (`MODEF`) must restrict all inputs to `register_operand`; 512-bit `vec_extract_lo_*` post-reload splitters with `!TARGET_AVX512VL && REG_P (operands[0]) && EXT_REX_SSE_REG_P (operands[1])` must rewrite `operands[0]` to a 512-bit `lowpart_subreg`; `<sse2p4_1>_pinsr<ssemodesuffix>` must format sub-32-bit GPR operands with `%k2`; and `*avx2_pcmp<mode>3_{1,2,7}` splitters must not put a `MEM` in the first `GT` operand. [F187, F188, F190, F191]

## Object Lifetimes

- In `scalar_chain`, `bitmap_obstack_initialize (NULL)` must precede `BITMAP_ALLOC (NULL)` for `insns`, `defs`, `defs_conv`, and `insns_conv`, and `BITMAP_FREE` on all four must precede `bitmap_obstack_release (NULL)` in `~scalar_chain`; `scalar_chain::build` must call `BITMAP_FREE (queue)` on both early-abort and normal return paths; and in `convert_scalars_to_vector`, `bitmap_release (&candidates[i])` and any `auto_bitmap` destruction must precede `bitmap_obstack_release (NULL)`. [F62, F63, F64]
- In `ix86_get_separate_components` and `ix86_components_for_bb`, the returned `sbitmap` must be allocated with `sbitmap_alloc` (never `auto_sbitmap`) and cleared with `bitmap_clear`, and any early `return NULL` in `ix86_get_separate_components` after allocation must call `sbitmap_free (components)`. `ix86_set_handled_components` must copy bits out of `components` and never retain the pointer. [F123, F124, F125]
- Heap allocations that must be freed before returning: `new redundant_pattern` entries in `pass_x86_cse::x86_cse` (`delete load`); `ix86_target_string` results (`free`); `get_loop_body (loop)` in `ix86_loop_unroll_adjust` (`free (bbs)`); `candidates_list_and_hint` and `sorted_attr_string` (`XDELETEVEC`); and `parse_mtune_ctrl_str` must save the initial `xstrdup` pointer in `orig` before advancing the cursor and pass `orig` to `free`. [F11, F65, F68, F69, F127]

## API Contracts

- Built-in expanders taking `unsigned char` or `short` immediate/mask arguments (`ix86_expand_args_builtin`, `ix86_expand_round_builtin`, `ix86_expand_special_args_builtin`, `ix86_expand_ace_builtin`, gather/scatter) must use `ix86_expand_unsigned_small_int_cst_argument` instead of `expand_normal`, and `ix86_expand_args_builtin` must pass each `op` through `fixup_modeless_constant (op, mode)` before checking `predicate (op, mode)`. [F15, F16]
- When `ix86_vectorize_vec_perm_const` is called with `target == NULL_RTX` (`d.testing_p`), it must populate `d.target`/`d.op0`/`d.op1` with dummy `LAST_VIRTUAL_REGISTER` raw `REG`s and wrap `ix86_expand_vec_perm_const_1 (&d)` in `start_sequence ()`/`end_sequence ()`. `ix86_gen_ccmp_first` and `ix86_gen_ccmp_next` must call `end_sequence ()` on every failure path after starting/pushing a sequence, and `ix86_gen_ccmp_next` must reject non-scalar-integer modes before `expand_operands`. [F19, F27]
- `ix86_function_arg_boundary` and `ix86_mangle_type` must normalize `type = TYPE_MAIN_VARIANT (type)` before inspecting alignment/empty status or comparing against `float128_type_node`/`float64x_type_node`; `ix86_gimplify_va_arg` must clamp `type_align` to `<= 64` bits when reading from the GPR save area (`needed_intregs && !need_temp`) and to `<= arg_boundary` (from `TYPE_MAIN_VARIANT`). [F129, F134, F138]
- In `ix86_secondary_reload`, an input reload (`in_p`) of a scalar integer `PLUS` into `SSE_CLASS_P` must return `GENERAL_REGS`; in `ix86_preferred_reload_class`, non-zero `CONSTANT_P` into MMX/MASK/SSE classes must return `NO_REGS` except `constm1_rtx` for `MAYBE_MASK_CLASS_P` and `standard_sse_constant_p (x, mode)` (`mode != VOIDmode`) for `MAYBE_SSE_CLASS_P`. [F161, F162]
- In `sse.md`, `reduc_sbool_and_scal_<mode>` and `reduc_sbool_ior_scal_<mode>` (`SWI1248_AVX512BWDQ`) must mask `operands[1]` with `(1u << n_elt) - 1` in `QImode` when `n_elt < 8`; `vec_pack_sbool_trunc_qi` and `vec_unpacks_sbool_{lo,hi}_qi` must `FAIL` unless `nunits` is 4 or 8 and shift/mask by `nunits / 2`. [F178, F179]

## Error Handling

- In `ix86_expand_ace_builtin`, constant operands (`i == 0 || i == constant`) must pass `insn_p->operand[i + arg_adjust].predicate (op, SImode)` before reading `INTVAL (op)`. In `ix86_expand_sse_comi_round`, `op2` must satisfy `CONST_INT_P (op2)` in `[0, 31]` and `op3` must pass `insn_p->operand[2].predicate (op3, SImode)` before indexing `comparisons`/`ordereds`/`non_signalings` or reading `INTVAL (op3)`. [F13, F14]
- In `ix86_valid_target_attribute_tree`, `option_strings` entries must be copied with `ggc_strdup` when stored into `opts`, freed via `release_options_strings` on all paths, and the function must return `error_mark_node` on invalid options and `NULL_TREE` when matching `target_option_default_node`. In `ix86_fold_builtin`, folding masked shifts or min/max (`n_args > 2`) must verify `!TREE_SIDE_EFFECTS` on the merge-source operand. [F67, F77, F140]

## Known Pitfalls

- `ix86_expand_sse_fp_minmax` must check `!flag_finite_math_only || flag_signed_zeros` (not `HONOR_NANS || HONOR_SIGNED_ZEROS`) when choosing `UNSPEC_IEEE_MIN`/`MAX`, and only swap operands for `LE` when `!HONOR_NANS (mode)`. In `ix86_expand_vector_init_v4sf` without `TARGET_SSE2`, zeroing a `V2SFmode` reg must use `emit_move_insn` (not `gen_rtx_SET`). [F25, F41]
- When modifying `DECL_FUNCTION_SPECIFIC_TARGET` on the active function (e.g., `ix86_simd_clone_adjust`), call `ix86_reset_previous_fndecl ()` before `ix86_set_current_function`. In `ix86_set_func_type`, promoting `TREE_THIS_VOLATILE` to `TYPE_NO_CALLEE_SAVED_REGISTERS` requires `call_saved_registers == TYPE_DEFAULT_CALL_SAVED_REGISTERS`, and `ix86_handle_interrupt_attribute` must inspect `TYPE_ARG_TYPES (*node)`/`TREE_TYPE (*node)` (never `DECL_ARGUMENTS`/`DECL_RESULT`). [F74, F76, F78]
- In STV, `convert_scalars_to_vector` must call `bitmap_tree_view (&candidates[i])` before `scalar_chain::build`, and `scalar_chain::convert_insn_common` must defer `df_insn_rescan_debug_internal` into `to_reset_debug_insns` until after the `DF_REF_CHAIN` loop. In `i386.cc` and `sse.md`, merging adjacent scalar loads/stores must use `widen_memory_access` (not `adjust_address`), `ix86_operands_ok_for_move_multiple` must reject loads from two distinct `PARM_DECL`s, and `ix86_split_stlf_stall_load` must check `memory_address_addr_space_p` on `adjust_address_nv` before `adjust_address`. [F58, F85, F163, F164, F181]
- In `ix86_vector_costs::add_stmt_cost`, `DImode` `MULT_HIGHPART_EXPR`/`CFN_MULH` emulation cost must not fall through to `MULT_EXPR`, and in `ix86_default_vector_cost`, `vec_to_scalar` must add `COSTS_N_INSNS (ix86_cost->sse_to_integer) / 2` for `!FLOAT_MODE_P` instead of falling through to `scalar_to_vec`. In `ix86_gimple_fold_builtin`, lowering `IX86_BUILTIN_PAVG*` to `IFN_AVG_CEIL` requires an unmasked or `ix86_masked_all_ones` call, `direct_internal_fn_supported_p` on `unsigned_type_for`, and `VIEW_CONVERT_EXPR` to unsigned and back. [F144, F145, F153]
