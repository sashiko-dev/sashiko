# config-loongarch

The `config-loongarch` unit implements the LoongArch GCC backend, including option and `target` attribute resolution, `cpucfg` probing, ABI calling conventions, frame layout, RTL constant/address/vector synthesis, cost models, built-in expansion, C/C++/D front-end hooks, and scalar, LSX, and LASX machine descriptions.

## Architecture & Data Flow

- `.cc` files must define `IN_TARGET_CODE 1` and `INCLUDE_*` before `config.h` (which precedes `system.h`, `coretypes.h`, `loongarch-cpu.h`, `loongarch-opts.h`), `loongarch-opts.h` must precede `loongarch-driver.h` and `loongarch.h`'s `#ifdef IN_LIBGCC2` `TARGET_64BIT` override, and `target-def.h` goes last in `loongarch.cc`. Every `HAVE_AS_*` value macro needs `#ifndef ... #define ... 0` in `loongarch-opts.h`; guard host-only declarations with `!IN_LIBGCC2 && !IN_TARGET_LIBS && !IN_RTS` (`loongarch-opts.h`/`loongarch-evolution.h`), `#ifndef USED_FOR_TARGET` (`loongarch.h`), and `#ifdef RTX_CODE` (`loongarch-protos.h`). [F7, F8, F68, F69, F70, F72, F111, F112, F113, F114]
- Edit `genopts/loongarch.opt.in`, `loongarch-strings`, and `isa-evolution.in` (via `genstr.sh`) instead of generated `loongarch.opt`, and mark per-function options `Save` or `TargetVariable`. `loongarch_option_restore` must recompute `la_target.isa.base = loongarch_cpu_default_isa[la_target.cpu_arch].base` alongside restoring all `la_target` fields. [F155, F166, F187]
- `loongarch_init_builtins` must register all `loongarch_builtins` unconditionally without checking `d->avail ()` (checked in `loongarch_expand_builtin`), keeping `movfcsr2gr` and `movgr2fcsr` at indices 0 (`LARCH_MOVFCSR2GR`) and 1 (`LARCH_MOVGR2FCSR`). `loongarch_atomic_assign_expand_fenv` must return if `!TARGET_HARD_FLOAT_ABI`, and otherwise mask `fcsr 0` (`0xffe0ffe0`) and read accrued exceptions before restoring `fcsr_orig_var`. [F2, F18, F37]
- In `loongarch_expand_builtin_direct`, when `has_target_p`, `ops[0]` is the output (`opno == 1`) while `argno` starts at `0`, so index `ops[opno++]` and `argno` separately; single-arg `CODE_FOR_recip{v8sf,v4df,v4sf,v2df}3` built-ins put the arg in `ops[2]` and `CONST1_RTX (ops[0].mode)` in `ops[1]`. [F1, F23]
- In `loongarch_expand_builtin_insn`, GPR broadcast/insert built-ins (`*vreplgr2vr_*`, `*vinsgr2vr_*`) must narrow `ops[1]` to `GET_MODE_INNER (ops[0].mode)` via `lowpart_subreg`; `vec_concat` interleave/pack/pick and `andn<mode>3` built-ins (`*vilv*`, `*vpack*`, `*vpick*`, `*vandn_v`, `lsx_vftintrz_w_d`, `lsx_vffint_s_l`) must swap `ops[1]` and `ops[2]`. `loongarch_expand_builtin_lsx_test_branch` must `force_reg` non-`REG` `ops[1].value`. [F27, F32, F34]
- `loongarch_update_cpp_builtins` must `builtin_undef` every target-dependent macro (including `la_evo_macro_name[i]`) before defining it, and require `TARGET_HARD_FLOAT` for `OPTION_MASK_ISA_FRECIPE`. `loongarch_pragma_target_parse` must call `loongarch_update_cpp_builtins` (suppressing `warn_unused_macros` at `BUILTINS_LOCATION`) and `loongarch_save_restore_target_globals` (if `pop_target`). `loongarch_set_current_function` must call `loongarch_reg_init` and `loongarch_save_restore_target_globals (new_tree)` even when `new_tree == old_tree`. [F5, F40, F41, F158]
- In `loongarch-cpu.cc`, every read `cpucfg_cache` index must be in `cpucfg_useful_idx` and `< N_CPUCFG_WORDS`, and `fill_native_cpu_config` must overwrite `preset.evolution = hw_isa_evolution` (not `|=`). [F3, F48]
- Map `cpu_arch` (`ARCH_*`) via `default_tune_for_arch` before indexing `TUNE_*` tables. `loongarch_cpu_default_isa` presets with `simd != ISA_EXT_NONE` must set `fpu = ISA_EXT_FPU64`; `ISA_HAS_LSX` holds for both `ISA_EXT_SIMD_LSX` and `ISA_EXT_SIMD_LASX`. In `loongarch_config_target`, if `t.isa` fails `isa_base_compat_p` and `!constrained.arch`, set `t.cpu_arch = abi_default_cpu_arch(t.abi, NULL)`, `constrained.arch = 1`, and `goto config_target_isa`. [F54, F89, F90, F91]
- `loongarch_target_option_override` must apply `loongarch_cpu_align` defaults only when `!opts->x_optimize_size` and `x_flag_align_*` is set with null `x_str_align_*`, enable `MASK_STRICT_ALIGN` on `TARGET_32BIT` unless explicitly set, and clear `x_flag_plt` on `CMODEL_EXTREME`. Default linker relaxation requires `HAVE_AS_MRELAX_OPTION && HAVE_AS_COND_BRANCH_RELAXATION`, and `x_la_opt_explicit_relocs` must be initialized after `LINKER_RELAXATION` from `TARGET_LINKER_RELAXATION`. [F83, F93, F96, F97]
- In `loongarch_for_each_saved_reg`, `loongarch_get_separate_components`, and `loongarch_process_components`, decrement `offset` on every set bit in `frame.mask`/`fmask` even when skipped, and iterate `[FP_REG_FIRST, FP_REG_LAST]` with bit `regno - FP_REG_FIRST` matching `loongarch_compute_frame_info`. In `loongarch_flatten_aggregate_field`, check `TYPE_P (TREE_TYPE (f))`, skip zero-sized `FIELD_DECL`s, and return `-1` if `n >= 2` (or `n != 0` for `COMPLEX_TYPE`) before writing `fields[2]`. [F103, F104, F105, F118]
- In `loongarch_split_move`, GPR-to-GPR multi-word moves must iterate `byte` ascending if `REGNO (low_dest) <= REGNO (low_src)` and descending otherwise. `loongarch_split_vector_move` must explicitly check `FP_REG_RTX_P` and `GP_REG_RTX_P` in every branch without a catch-all `else`. In `move_doubleword_2_<mode>` (`SPLITF`), keep FPR operands whole and use `movgr2frh<mode>`/`movfrh2gr<mode>` (`!TARGET_64BIT`) or `load_high<mode>`/`store_word<mode>` (`TARGET_64BIT`). [F107, F140, F175]
- `loongarch_compute_pressure_classes` must return `GENERAL_REGS`, `FP_REGS`, and `FCC_REGS`; `loongarch_ira_change_pseudo_allocno_class` must never return `ALL_REGS` (`FP_REGS` for float/vector, `GR_REGS` otherwise); `loongarch_hard_regno_mode_ok_uncached` forbids LSX/LASX and odd multi-word pairs in GPRs and sub-word `MODE_INT` in FPRs; and `loongarch_can_change_mode_class` forbids `FP_REGS` mode changes except int<->float, same-width vector, or LSX<->scalar float. [F129, F130, F144, F145]
- In `loongarch_mangle_decl_assembler_name`, clear `SET_DECL_RTL (decl, NULL)` when `DECL_ASSEMBLER_NAME_SET_P (decl)` holds on a `target_version` decl. `loongarch_generate_version_dispatcher_body` must check `DECL_VIRTUAL_P` on `node_version_info->next` (calling `sorry`), start remangling at `node_version_info->next->next`, and wrap `dispatch_function_versions` in `push_cfun`/`cgraph_edge::rebuild_edges ()`/`pop_cfun`. [F124, F125, F139]
- Memory and address rules: constraint `"R"` requires `loongarch_address_insns (XEXP (op, 0), mode, false) == 1`; `"k"` requires `TARGET_64BIT && loongarch_base_index_address_p`; `loongarch_valid_offset_p` and `loongarch_valid_lo_sum_p` must check that all words of non-vector multiword `MEM`s fit in 12-bit signed offsets without `LO_SUM` carry; `movsi`/`*movsi_internal` must reject 14-bit shifted non-12-bit offset `MEM`s on `TARGET_32BIT`; and `*zero_extendsidi2_internal` (`ZC`) must split after `reload_completed` when `!paradoxical_subreg_p (operands[0])`. [F33, F151, F178, F179]
- In `.md` files: `lasx_xvinsve0_<lasxfmt_f>_scalar` operand 1 needs `reg_or_0_operand`; `lasx_xvldi` must call `sorry` when `INTVAL (operands[1]) < 0` and `((val & 0xf00) >> 8) >= 13`; `PARALLEL` vector-select predicates must use `define_special_predicate` with explicit vector modes on `match_operand`; patterns writing `operands[0]` before reading inputs (`both_non_zero*`, `<optab>_alsl_reversesi_extended`, `*join2_load*`) need `=&r` and `reload_completed`; scalar `popcount<mode>2` (`=f`/`f`) splits only after `reload_completed`; and multi-block `fixuns_trunc*` expanders must call `do_pending_stack_adjust ()` and `emit_use (stack_pointer_rtx)`. [F26, F35, F167, F170, F181, F183, F184]
- Math guards: `div<mode>3`/`sqrt<mode>2` (`FLASX`) sw-recip requires `V8SFmode`, speed, `flag_finite_math_only`, `!flag_trapping_math`, and `flag_unsafe_math_optimizations`; `rsqrt_optab` requires speed and `use_rsqrt_p ()`, and `loongarch_emit_swrsqrtsf` must zero-mask `0.0` when `!recip`; `<FCLASS_MASK:fclass_optab><ANYF:mode>2` requires `<FCLASS_MASK> != 3 || flag_signaling_nans`; `UNSPEC_FTINTRM`/`UNSPEC_FTINTRP` require `flag_fp_int_builtin_inexact || !flag_trapping_math`; and negated-FMA patterns require `!HONOR_SIGNED_ZEROS (<MODE>mode)`. [F36, F154, F171, F172, F173]
- On `TARGET_64BIT`, `SImode` expanders (`shift_w`, `arith_w`, `any_div`, `addsi3`) allocating `DImode` pseudos must check `can_create_pseudo_p ()`, and `any_div` when `!ISA_HAS_DIV32` must `SIGN_EXTEND` `SImode` inputs to `DImode`. Sub-`word_mode` int comparisons must call `loongarch_extend_comparands`. `PROMOTE_MODE` must preserve `UNSIGNEDP` for `BITINT_TYPE_P` (`< 32` bits), and `loongarch_promote_function_mode` must run `PROMOTE_MODE` even when `type == NULL_TREE`. `splittable_const_int_operand` must reject `GET_MODE_SIZE (mode) > UNITS_PER_WORD`. [F122, F148, F169, F176, F177]

## Object Lifetimes

- `loongarch-builtins.cc` must include `"gt-loongarch-builtins.h"`. In `loongarch_config_target`, every return path after `obstack_init (&msg_obstack)` must call `obstack_free (&msg_obstack, NULL)`, and helpers using `msg_obstack` must finish nested `isa_str`/`abi_str` calls before calling `APPEND_STRING`/`APPEND1`. [F45, F73, F74]
- Size tokenization buffers dynamically from `strlen` (`len + 1`), using `auto_vec<char, 32> buffer` in `loongarch_process_target_attr` rather than freeing `str_to_check` after `strtok_r`. Use `auto_vec<unsigned int>` for `loongarch_parse_fmv_features` priority vectors, never release/delete `fndecls` in `dispatch_function_versions`, and use `sbitmap_alloc` for returned shrink-wrap bitmaps vs `auto_bitmap` for temporaries. [F57, F75, F76, F115, F116]

## API Contracts

- Store vector built-ins (`vst*`, `xvst*`) must use `LARCH_ATYPE_VPOINTER` (not `CVPOINTER`). In `loongarch-ftypes.def`, `DEF_LARCH_FTYPE (NARGS, LIST)` must parenthesize `LIST` with `NARGS` excluding the return type. Guard `lsxintrin.h` with `#if defined(__loongarch_sx)` (and `#if defined(__loongarch_frecipe)`). Keep `vec_set<mode>_internal` (`ILASX_HB`), `lasx_vecinit_merge_<LASX:mode>`, and `lasx_xvilvl_<lasxfmt_f>_internal` private to `loongarch_expand_vector_init`. [F12, F31, F67, F165]
- Canary patterns (`@stack_protect_combined_*`) must remain unsplit `UNSPEC_SSP` insns using `ZE` (`ssp_normal_operand`) vs `ZF` (extreme model), passing non-null `tmp` to `loongarch_output_asm_load_canary` iff `!ssp_normal_operand` and zeroing scratch regs; `loongarch_print_operand` `'v'` must accept `E_SImode` (`"w"`) and `E_DImode` (`"d"`). [F42, F156, F157, F186]
- `loongarch_handle_option` must reset `x_la_opt_simd`, `x_la_opt_fpu`, and `x_la_isa_evolution` on `OPT_march_`, and `x_str_align_*` on `OPT_mtune_`. `loongarch_can_inline_p` must reject inlining if `callee` is versioned and `caller` is not, or if `x_target_flags`, `x_la_isa_evolution`, or `x_la_opt_simd` are incompatible. [F55, F128]
- `loongarch_parse_fmv_features` must bound `loongarch_attributes` loops by `num_features - 1`, allow at most one `";"` (`priority=<num>`, forbidden on `"default"`), verify all `prio_str` chars satisfy `ISDIGIT` (`len == prio_str.size ()`) before `sscanf`, push `tmp_prio + LA_PRIO_MAX` alongside feature priority, and use `warning_at` guarded by `loc != UNKNOWN_LOCATION` (not `error_at`). [F49, F56, F62, F87, F100]
- Hook guards: check `vectype != NULL` in `add_stmt_cost` and `loongarch_builtin_vectorization_cost`; check `cum != NULL` in `loongarch_pass_by_reference`; skip `loongarch_function_arg_advance` in `loongarch_setup_incoming_varargs` when `TYPE_NO_NAMED_ARGS_STDARG_P && arg.type == NULL_TREE`; return `mode` in `loongarch_split_reduction` when `!VECTOR_MODE_P (mode)`; and set `info->extended = bitint_ext_partial` in `loongarch_bitint_type_info`. [F117, F119, F120, F126, F142]

## Error Handling

- Built-in expansion (`loongarch_expand_builtin*`) must return a non-null fallback `rtx` (`target ? target : const0_rtx`, `gen_reg_rtx`, or `const0_rtx`) after `error`/`error_at`, never `NULL_RTX`. [F15]
- `loongarch_process_one_target_attr` must reject a NULL `arg` for `loongarch_attr_enum` and report unmutated `arg_str` on error. `loongarch_option_valid_attribute_p` and `loongarch_option_valid_version_attribute_p` must save and restore `global_options`/`global_options_set` (plus optimization state in `loongarch_option_valid_attribute_p`) on all return paths. [F86, F99, F123]

## External Contracts

- Define `__loongarch_{double,single,hard,soft}_float` from `TARGET_*_FLOAT_ABI` and `__loongarch_frlen` from `TARGET_{DOUBLE,SINGLE}_FLOAT`; return `TFmode` for `'q'` in `loongarch_c_mode_for_suffix`; require `HAVE_IFUNC_FOR_LIBATOMIC_16B && targetm.has_ifunc_p () && TARGET_64BIT && ISA_HAS_LSX && ISA_HAS_SCQ` in `loongarch_16b_atomic_lock_free_p`; and keep optab names `@bitreverse<mode>2`, `bitreverseqi2`, and `bitreversehi2`. [F38, F121, F149, F185]

## Known Pitfalls

- In `loongarch_expand_builtin_direct`, `loongarch_gen_stepped_int_parallel` must use `sel_high_p = true` for `vec_extract_hi_*` and `vec_insert_lo_*`, and `false` for `vec_extract_lo_*` and `vec_insert_hi_*`. In `recip_options`, keep `"all"`/`"none"` at 0..1 and flags at `>= 2` (fitting in 127 bytes of `recip_scheme_str`). In `loongarch_process_target_attr`, count `','` before `strtok_r` and require `num_attrs == num_commas + 1`. [F24, F58, F59, F66]
- In `loongarch_vector_costs`: return unroll factor `1` if `m_has_avg`, `m_has_recip`, or `m_stmts - m_loads - m_stores == 0`; and apply the `stmt_cost = 0` `loongarch_multiply_add_p` discount only when `kind == vector_stmt && GET_MODE_SIZE (mode) == 16 && !vect_is_reduction (stmt_info)`. [F132, F133]
- Vector permutations: in `loongarch_vectorize_vec_perm_const`, wrap `d.testing_p` trials in `start_sequence ()`/`end_sequence ()`, mask `d.perm[i]` with `nelt - 1` when collapsing to `d.one_vector_p = true`, and restore `d.op0`/`d.op1`/`d.one_vector_p`/`orig_perm` if `which == 3` fails; in `loongarch_expand_vec_perm_1`, mask `mask` with `2 * w - 1` in `maskmode` when `(maskmode != V8SImode && maskmode != V4DImode) || !one_operand_shuffle`; and in `loongarch_try_expand_lsx_vshuf_const`/`loongarch_expand_vec_perm_const`, `force_reg` `sel` into a fresh `sel_mode` pseudo rather than subreg-punning `d->target`. [F110, F135, F136, F150, F153]
- Vector modes/constants: use `force_reg (imode, same)` in `loongarch_expand_vector_init_same`; extract `MODE_VECTOR_FLOAT` bits via `CONST_DOUBLE_REAL_VALUE` in `loongarch_const_vector_bitimm_clr_p`; `force_reg` non-reg-to-non-reg `const_0_operand` moves for LSX/LASX modes in `loongarch_legitimize_move`; use `MODE_VECTOR_INT` for vector bitwise logic/`%V`; truncate `operands[1]` via `trunc_int_for_mode` for `V16QImode` in `lsx_vrepli<mode>`; and in pre-reload `bstrins` splitters, copy `operands[3]` to a fresh pseudo (even for `lo == 0`) or check `!reg_overlap_mentioned_p (operands[0], operands[3])`. [F141, F143, F152, F160, F168, F182]
