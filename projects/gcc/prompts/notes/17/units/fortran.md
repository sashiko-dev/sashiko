# fortran

The `fortran` unit implements the GNU Fortran (`gfortran`) front end and compiler driver filter, handling declaration and expression parsing, symbol and namespace management, interface and operator resolution, constant target-memory simulation, front-end AST optimization passes, and translation of Fortran AST nodes, array descriptors, scalarizer loops, and intrinsics into GCC GENERIC trees.

## Architecture & Data Flow

- For `BT_CLASS` entities, `ts.u.derived` is the class wrapper; the declared derived type, `as`, and class attributes (`allocatable`, `class_pointer`, `pointer_comp`, `alloc_comp`, `codimension`, `target`) reside on `CLASS_DATA(...)` (`u.derived->components`), which requires `attr.class_ok` and non-null `CLASS_DATA`. Because `attr.pointer` is unconditionally set on `_data`, pointer checks must read `CLASS_DATA(...)->attr.class_pointer`. In `gfc_compare_types`, check `ts->u.derived->components != NULL` before reading `unlimited_polymorphic` on it, falling back to `ts->u.derived->attr.unlimited_polymorphic`. [F54, F55, F56, F116, F124, F161, F248, F409]
- In `gfc_get_symbol_decl`, completing a `BT_CLASS` symbol's type requires calling `gfc_find_derived_vtab` on `CLASS_DATA (sym)->ts.u.derived` (declared type) and `gfc_get_derived_type` on `sym->ts.u.derived` (container type). In `gfc_trans_deferred_vars`, PDT component allocation, deallocation, and dummy checks for `IS_CLASS_PDT (sym)` must operate on `CLASS_DATA (sym)->ts.u.derived` and `gfc_class_data_get (sym->backend_decl)`, and non-dummy, non-associate scalar `UNLIMITED_POLY` pointers (`CLASS_DATA (sym)->attr.class_pointer`) must be registered via `gfc_defer_symbol_init` to initialize `_vptr`. [F247, F249, F250]
- Whenever a `BT_CLASS` expression satisfies `UNLIMITED_POLY` in `gfc_conv_intrinsic_storage_size`, `gfc_conv_intrinsic_transfer`, `get_array_span`, or `gfc_build_array_ref`, the element byte size from `_vptr->_size` must be scaled via `gfc_resize_class_size_with_len` (and `get_array_span` must return `NULL_TREE` if `gfc_class_data_get (decl)` is not a descriptor type). In `conv_intrinsic_move_alloc` on `BT_CLASS`, `to`'s `_vptr` must be updated via `gfc_class_set_vptr`, `from`'s reset via `gfc_reset_vptr` if `from_is_class`, and `_len` updated/reset when `UNLIMITED_POLY` holds. [F367, F369, F412]
- Coarray dimensions in `ref->u.ar` follow array dimensions at `[dimen, dimen + codimen)` (used by `gfc_caf_get_image_index`), while `gfc_add_full_array_ref` sets only `dimen = e->rank` and leaves `codimen` unset for resolution. In `gfc_walk_array_ref` (`AR_SECTION`), `DIMEN_ELEMENT` uses `subscript[n]` at full dimension `n`, whereas `DIMEN_RANGE`/`DIMEN_VECTOR` append `newss->dim[newss->dimen++] = n`. Separate counters are likewise required in `find_array_section` (`shape_i`, with `end[d] = begin->value.integer` on `DIMEN_ELEMENT`), `gfc_copy_shape_excluding` (`s`), and `scalarized_expr` (`i_index`). [F35, F36, F37, F38, F74, F184, F297]
- In `gfc_trans_create_temp_array`, mapping scalarizer loop dimension `n` to a temp descriptor dimension requires `get_scalarizer_dim_for_array_dim (ss, s->dim[n])`, and normalizing `loop->from[n]` to zero must clear `loop->specloop[n] = NULL` so `gfc_set_delta` recalculates `info->delta`. When `gfc_alloc_allocatable_for_assignment` reallocates an LHS before the loop, `update_reallocated_descriptor` must re-evaluate `data`, `offset`, `saved_offset`, `start`, `end`, `stride`, and `delta` afterwards. In `gfc_trans_scalarized_loop_boundary`, `info->offset` for arrays with `useflags & 2` must be restored from `info->saved_offset`. [F182, F183, F186, F187]
- `is_subref_array` returns `true` if `sym->attr.subref_array_pointer` or `gfc_is_span_addressed_dummy (sym)` holds, and `gfc_span_folds_into_stride` only folds spans into strides for `AS_ASSUMED_SHAPE` (`rank >= 1`) `BT_INTEGER`/`BT_REAL`/`BT_LOGICAL` dummies where `TYPE_SIZE_UNIT` equals `min_align_of_type (etype)`. Otherwise, `gfc_build_dummy_array_decl` (`PACKED_NO`) sets `GFC_DECL_PTR_ARRAY_P` and allocates `GFC_DECL_SPAN` via `create_index_var ("span", in_parent_function)` (initialized on entry by `gfc_trans_dummy_array_bias`), and `gfc_get_array_span` / `get_array_span` must check `GFC_DECL_GET_SPAN (decl)` before falling back to `gfc_get_span_descriptor` (which unwraps `GFC_DECL_SAVED_DESCRIPTOR`). [F69, F208, F209, F255, F416, F417]
- Semantic queries on `ASSOCIATE` or `SELECT TYPE` variables (`check_inquiry`, `gfc_is_simply_contiguous`, `gfc_check_vardef_context`) must unwrap `sym->assoc->target`: in `gfc_is_simply_contiguous`, forward to `sym->assoc->target` only when no `REF_COMPONENT` (`part_ref`) precedes it and still check any trailing `AR_SECTION` (`ar`); in `gfc_check_vardef_context`, a pointer `REF_COMPONENT` clears `check_intentin` only when `!sym->assoc && !sym->attr.is_protected` (or `!pointer` on a later pointer component), walking `sym->assoc->target` if `check_intentin` remains true. [F66, F68, F75]
- In `gfc_conv_unary_op`, `INTRINSIC_NOT` must be lowered to `EQ_EXPR` against `build_int_cst (type, 0)` (not unary `TRUTH_NOT_EXPR`), and in `gfc_conv_expr_op`, all logical/comparison operators (`lop != 0`, including `EQV`/`NEQV` as `EQ_EXPR`/`NE_EXPR`) must be built with `logical_type_node` and `convert`-ed to `gfc_typenode_for_spec (&expr->ts)`. In Fortran bit-shift/mask intrinsics (`dshift`, `ibits`, `shift`, `ishft`), shifts by `TYPE_PRECISION (type)` must be guarded with `COND_EXPR`, and in `gfc_conv_intrinsic_leadz`/`trailz`/`popcnt_poppar`, arguments must be converted to `gfc_build_uint_type (argsize)` before widening to `arg_type`, guarding `BUILT_IN_CLZ*`/`CTZ*` against `arg == 0` with `COND_EXPR` and subtracting `TYPE_PRECISION (arg_type) - argsize` for `leadz`. [F329, F330, F354, F386, F387]

## Object Lifetimes

- Every `gfc_charlen` from `gfc_new_charlen` is tracked in `latest_undo_chgset->cls` for rollback: any path that frees an unattached `gfc_charlen` (`discard_pending_charlen`, `discard_pending_charlens`) or attaches it to state not rolled back by `gfc_undo_symbols` (`build_struct` component `c->ts.u.cl`, `gfc_merge_new_implicit`) must call `gfc_remove_saved_charlen(cl)` first, and `add_init_expr_to_sym` must null out `sym->ts.u.cl` and `init->ts.u.cl` before `discard_pending_charlens`. In `gfc_free_namespace`, purge `cl->cl_ns == ns` entries from `latest_undo_chgset->cls` using `unordered_remove (j--)` before freeing `ns->cl_list`, and in `restore_old_symbol`, restore the full `p->ts = old->ts` struct. [F8, F9, F10, F140, F151, F152, F168]
- `gfc_delete_symtree` only frees the `gfc_symtree` node without decrementing `sym->refs`; callers removing a symbol from a namespace must also call `gfc_release_symbol`. In `gfc_release_symbol`, when `cyclic_reference_break_needed (sym)` holds (`formal_ns != NULL && formal_ns != sym->ns && refs == 2` and not `host_assoc && used_in_submodule`), `sym->formal_ns` must be nulled and freed via `gfc_free_namespace` before decrementing `sym->refs`. In `gfc_free_symbol`, when `sym->attr.pdt_type` is set, never call `gfc_free_namespace (sym->f2k_derived)` (which shares trees with `pdt_template`); only `free` the `gfc_finalizer` nodes and `sym->f2k_derived` struct directly. In `free_old_symbol`, only free `as`, `value`, and `formal` if they differ from `sym`'s current pointers (and `CLASS_DATA (sym)->as`), and never free `namelist`. [F153, F154, F155, F156]
- When grafting a source `gfc_expr` onto a destination `gfc_expr` in place (`gfc_replace_expr`, `scalarize_intrinsic_call`), call `free_expr0 (dest)` before shallow-copying `*src` and calling `free (src)` (not `gfc_free_expr (src)`). In `gfc_extend_expr` and `gfc_extend_assign`, free unmatched temporary `gfc_actual_arglist` nodes with `free` (not `gfc_free_actual_arglist`) because their `expr` pointers alias live operands; in `gfc_free_formal_arglist`, only `free` the list nodes and never `p->sym`; in `gfc_compare_actual_formal`, `free (a->associated_dummy)` before reassigning it; and in `gfc_finish_var_decl`, null `code->expr2` after moving it to `sym->value` before calling `gfc_free_statement (code)` and `free (code)`. [F50, F109, F110, F112, F243]
- Heap-allocated `gfc_ss` chains from `gfc_get_ss` must either be freed via `gfc_free_ss_chain` on early exits (such as in `gfc_conv_expr_descriptor` before `gfc_add_ss_to_loop`, or in `gfc_walk_elemental_function_args` when `scalar != 0`) or attached to at most one `gfc_loopinfo` and freed via `gfc_cleanup_loop` (except in `gfc_conv_intrinsic_arith` and `gfc_conv_intrinsic_minmaxloc` when `enter_nested_loop` owns the loop). Every local `gfc_interface_mapping` (`get_array_charlen`, `gfc_conv_procedure_call`) must be freed with `gfc_free_interface_mapping` on all return paths, which must clear `sym->new_sym->n.sym->formal = NULL` before `gfc_free_symbol`. [F192, F193, F194, F199, F302, F303, F362, F405, F406]

## API Contracts

- Because a derived type's lowercase name resolves to its generic constructor symbol while the `FL_DERIVED` symbol is stored under `gfc_dt_upper_string` in `sym->generic`, lookups by lowercase name (`check_extended_derived_type`, `gfc_match_derived_decl`) and supertype traversals (`gfc_get_derived_super_type` on both `derived` and `derived->components->ts.u.derived`) must unwrap `attr.generic` via `gfc_find_dt_in_generic`. Outside a structure definition in `gfc_match_data_decl`, `current_ts.u.derived` must be resolved via `gfc_use_derived` before inspecting `components`. [F22, F24, F160]
- `gfc_reduce_init_expr` and `gfc_match_init_expr` must set `gfc_init_expr_flag = true` before matching/resolving/checking and reset `gfc_init_expr_flag = false` on every exit path (and `gfc_reduce_init_expr` must return `false` immediately without resolving an `EXPR_COMPCALL` on a `BT_CLASS` symbol). `scalarize_intrinsic_call` requires `init_flag = true` from `gfc_check_init_expr` and `false` from `gfc_simplify_expr`; `check_inquiry` must call `gfc_check_init_expr` only when `not_restricted != 0` and `check_restricted` when `not_restricted == 0`; and `gfc_check_assign_symbol` on `pointer || proc_pointer` must call `gfc_check_pointer_assign` with `is_init_expr = true`. [F58, F59, F60, F61, F65]
- Because `gfc_compare_actual_formal` mutates and relinks the `gfc_actual_arglist` in place and `specific_intrinsic_symbol` destructively removes empty actual arguments via `remove_empty_actual_arguments`, `matching_typebound_op` must pass a `gfc_copy_actual_arglist` copy (freed with `gfc_free_actual_arglist`) and `gfc_conv_intrinsic_funcall` must pass a `gfc_copy_expr` copy (freed with `gfc_free_expr`). Callbacks to `gfc_traverse_symtree` or `gfc_traverse_ns` must never delete `gfc_symtree` nodes because `do_traverse_symtree` snapshots all node pointers into `st_vec` upfront. [F111, F149, F361]
- In `trans-descriptor.cc`, dimension indices passed to `gfc_conv_descriptor_{stride,lbound,ubound}_{get,set}` must be 0-based `tree` expressions; `gfc_conv_descriptor_stride_get` on `dim == 0` returns `gfc_index_one_node` for allocatable/contiguous `GFC_TYPE_ARRAY_AKIND`s; `gfc_conv_descriptor_data_get` returns a read-only `fold_convert` tree (mutations must use `gfc_conv_descriptor_data_set`); and code must call `gfc_get_dtype` rather than reading `GFC_TYPE_ARRAY_DTYPE (node)` directly. In `gfc_conv_shift_descriptor_lbound`, new `ubound` and `offs` must be written before `gfc_conv_descriptor_lbound_set` updates the lower bound. [F239, F270, F278, F279, F415]
- Before inspecting refs or lowering in `gfc_conv_expr` and `gfc_trans_assignment_1`, `gfc_fix_class_refs` must be called to insert missing `_data` `REF_COMPONENT`s, and in `gfc_conv_variable`, `gfc_fixup_inferred_type_refs (expr)` must be called when `IS_INFERRED_TYPE (expr) && expr->ref`. When `gfc_conv_initializer` or `gfc_conv_array_initializer` lowers static `EXPR_STRUCTURE`s, it must call `gfc_conv_structure (&se, ..., 1)` (`init = 1`), whereas runtime lowering passes `init = 0` and delegates to `gfc_trans_structure_assign` with `init` set to `expr->symtree != NULL`. [F205, F311, F312, F313, F314]

## External Contracts

- In `gfc_conv_procedure_call`, call arguments must be concatenated in the exact ABI sequence: hidden by-reference return arguments (`retargs`), formal arguments (`arglist`), hidden `boolean_type_node` presence flags for scalar non-`BT_CLASS` `OPTIONAL, VALUE` dummies (`optionalargs`), hidden string lengths and coarray tokens/offsets (`stringargs`), and `append_args`. `parmse.string_length` must be omitted from `stringargs` when `sym->attr.is_bind_c` or the dummy is `TYPE(C_PTR)`, `BT_ASSUMED`, or `UNLIMITED_POLY (fsym)`, and passed by address (`gfc_build_addr_expr`) when `fsym->ts.deferred` is set. [F263, F338, F341]
- When copying an assumed-rank (`rank == -1`) array descriptor into a `GFC_MAX_DIMENSIONS` class data descriptor in `gfc_conv_array_parameter` (`gfc_resize_assumed_rank_dim_field`) or `gfc_conv_derived_to_class`, never emit a whole-struct assignment; copy `data`, `offset`, and `dtype` individually and copy only `rank` dimension entries via `BUILT_IN_MEMCPY`. [F237, F344]

## Known Pitfalls

- Before `gfc_simplify_expr` recursively simplifies arguments of `LBOUND`, `UBOUND`, `LCOBOUND`, `UCOBOUND`, or `SHAPE`, it must skip the first (`ARRAY`) argument (`ap = ap->next`) so an `FL_PARAMETER` variable is not turned into a 1-based `EXPR_ARRAY`. In `simplify_parameter_variable`, copy `p->ref` onto `e` only when `e->expr_type != EXPR_CONSTANT`, and call `gfc_replace_expr (p, e)` only when `gfc_simplify_expr` succeeds and `!e->ref`. In `find_inquiry_ref`, detach `REF_INQUIRY` from a copy `tmp`, call `gfc_resolve_expr (tmp)`, and abort if `IS_INFERRED_TYPE (tmp)` holds. [F62, F63, F64]
- When recomputing a symbol's type via `gfc_sym_type` after populating `sym->ts.u.cl->backend_decl` (`gfc_build_dummy_array_decl`, `create_function_arglist`), clear `sym->backend_decl = NULL_TREE` first so `gfc_sym_type` does not return the cached incomplete type. In `gfc_trans_vla_one_sizepos` and `gfc_trans_vla_type_sizes_1`, replace non-constant, non-`DECL_P` bounds/sizes on `TYPE_MAIN_VARIANT` with a temporary initialized from `unshare_expr (val)` (if `t` is a `SAVE_EXPR`, unwrap `TREE_OPERAND (t, 0)` if `SAVE_EXPR_RESOLVED_P`, else assign the `VAR_DECL` to both `TREE_OPERAND (t, 0)` and `*tp`) and propagate across `TYPE_NEXT_VARIANT`. [F252, F267, F273]
- In `structure_alloc_comps` under `NULLIFY_ALLOC_COMP`, handle `BT_CLASS` components (including `gfc_reset_vptr`) before `c->attr.pointer || c->attr.allocatable`; under `COPY_ALLOC_COMP`, copy recursive `same_type` components via `_gfortran_cfi_deep_copy_array` using `generate_element_copy_wrapper` (which must save/clear/restore `seen_derived_types` and finalize via `cgraph_node::finalize_function (fndecl, true)`), wrapping scalars with `gfc_conv_scalar_to_descriptor`. In `gfc_trans_alloc_subarray_assign`, explicit-length (`!cm->ts.deferred`) `BT_CHARACTER` allocatable array components must be copied via `gfc_trans_alloc_char_subarray_assign`, not `gfc_duplicate_allocatable`. [F202, F216, F217, F218, F325]
- When copying a full array descriptor in `gfc_conv_expr_descriptor` (`se->direct_byref && !se->byref_noassign`), wrap `desc` in `VIEW_CONVERT_EXPR` if `lhs_ls->akind != rhs_ls->akind` (for equal rank) and explicitly set the destination's `span` via `gfc_conv_descriptor_span_set`. For `BT_CHARACTER` equivalence/COMMON members in `trans-common.cc`, call `gfc_conv_const_charlen` before querying `gfc_sym_type`/`gfc_typenode_for_spec` for byte sizes, and for `pdt_string` descriptor arrays in `gfc_conv_scalarized_array_ref` / `gfc_conv_array_ref`, pass the descriptor `decl` (not `NULL_TREE`) to `gfc_build_array_ref` / `build_array_ref`. [F206, F210, F212, F233]
