# gimple-middle-end

This unit implements GCC's core GIMPLE and `tree` IRs (`gimple.*`, `tree.h`, `stor-layout.cc`, `machmode.*`), middle-end passes (`_BitInt` lowering, predicate analysis, array bounds, CRC, recursion warnings), CFG and loop infrastructure (`cfg*.cc`), and RTL expansion (`cfgexpand.cc`, `expr.cc`, `builtins.cc`, `calls.cc`, `function.cc`).

## Architecture & Data Flow
- In `gimple_statement_with_ops`, `gimple_statement_with_memory_ops`, `gcall`, and `gasm`, `tree op[1]` must be the final member (`gimple_ops` uses `sizeof (STRUCT)`). `gcall` reserves `op[0..2]` for LHS, callee, and static chain (args at `op[index + 3]`, `num_ops == nargs + 3`), and `gcall::u` is discriminated by `gimple_call_internal_p` (`u.internal_fn` vs `u.fntype`/`op[1]`). `gasm::op` stores `no` outputs before `ni` inputs, clobbers, and labels (`walk_gimple_asm` must populate `oconstraints` over outputs before parsing input constraints). [F402, F404, F425, F429]
- In `gswitch`, `op[0]` is the index, `op[1]` (label 0) is the non-NULL default `CASE_LABEL_EXPR` (`CASE_LOW` and `CASE_HIGH` NULL), and sorted non-default labels occupy `1..nlabels`; `gimple_switch_num_labels` includes the default label whereas `gimple_build_switch_nlabels` excludes it and allocates `2 + nlabels` ops. `preprocess_case_label_vec_for_gimple` folds bounds to `index_type`, clears `CASE_HIGH` if equal to `CASE_LOW`, and extracts the default label when `default_casep` is non-NULL. [F403, F428, F441]
- `gimple_set_modified (s, true)` invalidates an `SSA_NAME` LHS's range via `get_range_query (cfun)->update_range_info (def)` (`gimple_init` must set `g->modified = 1` directly). When `gimple_assign_set_rhs_with_ops` grows a tuple (`new_rhs_ops + 1 > gimple_num_ops`), it must reallocate via `gimple_alloc`, call `gimple_assign_set_lhs`, and `gsi_replace` so `SSA_NAME_DEF_STMT` is updated; `gimple_move_vops` must likewise update `SSA_NAME_DEF_STMT` on a non-null `SSA_NAME` `gimple_vdef`. [F413, F438, F439, F440]
- In `useless_type_conversion_p`, types must match in `TYPE_MODE` and `BITINT_TYPE_P`. `POINTER_TYPE_P` conversions must verify equal `TYPE_ADDR_SPACE` and reject non-function/method to `FUNC_OR_METHOD_TYPE_P` casts before stripping `TYPE_MAIN_VARIANT`. Integral conversions between `BOOLEAN_TYPE` and non-boolean types require `TYPE_PRECISION (outer_type) == 1`. Same-mode `VECTOR_TYPE_P` types require equal `TYPE_VECTOR_SUBPARTS`, compatible element types, and `targetm.compatible_vector_types_p`. [F319, F320, F322, F340]
- In `gimple_could_trap_p_1`, when `include_mem` is true, operand 0 is skipped in the `tree_could_trap_p` loop if `gimple_has_lhs (s)` holds, checking `include_stores && gimple_store_p (s) && lhs_could_trap_p (gimple_get_lhs (s))` instead. `tcc_comparison` `GIMPLE_ASSIGN`s must pass `FLOAT_TYPE_P (TREE_TYPE (gimple_assign_rhs1 (s)))` (not the boolean LHS type) to `operation_could_trap_p`, and float-returning normal builtin calls trap under `flag_trapping_math` except `BUILT_IN_COPYSIGN`. [F434, F450, F451]
- `infer_nonnull_range_by_dereference` must return `false` if `!flag_delete_null_pointer_checks`, `!POINTER_TYPE_P (TREE_TYPE (op))`, `GIMPLE_ASM`, or `gimple_clobber_p (stmt)`. In `check_loadstore`, `MEM_REF` and `TARGET_MEM_REF` must not infer non-null when `targetm.addr_space.zero_address_valid` holds for `TYPE_ADDR_SPACE (TREE_TYPE (op))`, and `TARGET_MEM_REF` requires `TMR_INDEX2 == NULL` and (`TMR_INDEX == NULL` or `expr_not_equal_to` proving `TMR_STEP != 1`). [F436, F437, F452]
- When `precompute_register_parameters` or `expand_value_return` promotes a `SCALAR_FLOAT_MODE_P` value (`old_mode`) to a wider `SCALAR_INT_MODE_P` (`mode`), it must use `convert_float_to_wider_int` rather than `convert_modes`. Conversely, in `expand_call`, `expand_expr_real_1`, and `assign_parm_setup_stack`, extracting a `SCALAR_FLOAT_MODE_P` value from a wider `SCALAR_INT_MODE_P` register must use `convert_wider_int_to_float` rather than `gen_lowpart_SUBREG` or direct `convert_to_mode`. [F104, F105, F172, F279, F338]
- In `expand_call`, sibling calls (`try_tail_call`) must be disabled if `caller_mode != VOIDmode` and caller/callee disagree on `promote_function_mode` or promotion signedness (`caller_unsignedp != callee_unsignedp`) or `partial_subreg_p`, or if the callee uses stack args while a caller parameter has `DECL_HIDDEN_STRING_LENGTH` in `MEM`. All `store_one_arg` calls must precede `load_register_parameters`, and in `expand_function_start`, `targetm.calls.struct_value_rtx` must be copied to a pseudo before `assign_parms`. [F88, F106, F112, F345]
- In `expand_expr_real_1`, `expand_assignment`, `expand_asm_stmt`, `expand_builtin_strub_update`, and `expand_builtin_strub_leave`, `EXPAND_MEMORY` and `set_mem_attributes` treat any `modifier != EXPAND_NORMAL` and assignment LHSs as potential stores (`lhs_could_trap_p`); read-only memory expansions (and `EXPAND_MEMORY` loads in `expand_asm_stmt` or `strub`) must use `store_p = false` in `get_memory_rtx` or restore `MEM_NOTRAP_P` from `!tree_could_trap_p` (on a `shallow_copy_rtx` if also stored to). [F29, F30, F155, F258]
- In `partition_stack_vars`, `union_stack_vars` must never merge partitions across `MAX_SUPPORTED_STACK_ALIGNMENT`, nor merge differently sized supported-alignment partitions when `asan_sanitize_stack_p ()` holds. `stack_var` entries for `SSA_NAME` decls conflict with all other entries in `stack_var_conflict_p`. Non-addressable decls accessed via `TARGET_MEM_REF`, `POLY_INT_CST`-sized `MEM_REF`, `BLKmode` `VIEW_CONVERT_EXPR`, `IFN_LOAD_LANES`/`IFN_STORE_LANES`, or sub-bitsize float modes written as int/`BLKmode` must be added to `forced_stack_vars`. [F141, F143, F175, F176, F184]
- In `bitint_large_huge`, every `handle_operand` and `handle_stmt` helper that pushes `N` trees to `m_data` when `m_first` is true must advance `m_data_cnt` by the exact same `N` when `!m_first`. Lowering loops that call `handle_operand` with a non-`INTEGER_CST` index that can access the most significant partial limb (`LSHIFT_EXPR` in `lower_shift_stmt` and `lower_bswap_bitreverse`) must set `m_var_msb = true`, and internal-EH (`stmt_ends_bb_p`) limb loads/stores must call `maybe_duplicate_eh_stmt`, split the block, and call `add_eh_edge`. [F347, F379, F386]
- In `predicate::init_from_control_deps`, when an edge lacks a valid predicate (`!has_valid_pred`), a definition predicate (`!is_use`) aborts the path and releases the entire `t_chain` OR disjunct, whereas a use predicate (`is_use`) drops only that edge from the `t_chain` AND conjunction. When `compute_control_dep_chain` or `compute_control_dep_chain_pdom` hits limits, it must set `*complete_p = false`, causing `init_use_preds` to fall back to `simple_control_dep_chain` and `init_from_phi_def` to skip standalone PHI-edge chains. [F354, F356, F369, F391]
- In `layout_decl`, `place_field`, and `finalize_type_size`, any non-null, non-`INTEGER_CST` size or offset must be wrapped in `variable_size`. Any non-zero bit alignment passed to `SET_TYPE_ALIGN` or `SET_DECL_ALIGN` must be a power of two (`ffs_hwi` encoding). On a `FIELD_DECL`, `DECL_FIELD_ABI_IGNORED` and `DECL_FIELD_CXX_ZERO_WIDTH_BIT_FIELD` share `decl_common.decl_flag_0` discriminated by `DECL_BIT_FIELD`, and `DECL_BIT_FIELD_TYPE` must be set to `TREE_TYPE (decl)` before `DECL_BIT_FIELD` is cleared. [F460, F468, F560, F562]
- On `ARRAY_REF` or `ARRAY_RANGE_REF`, `TREE_THIS_NOTRAP` only guarantees the index is in bounds (the base access or a store to `TREE_READONLY` memory can still trap). A `LABEL_DECL` with `FORCED_LABEL` set must never be deleted. Calls to `TREE_READONLY` or `DECL_PURE_P` functions with `DECL_LOOPING_CONST_OR_PURE_P` set may be commoned by CSE but must not be dead-code eliminated. Rewriting memory refs must preserve `REF_REVERSE_STORAGE_ORDER` and respect `storage_order_barrier_p`. [F549, F550, F551, F552]

## Object Lifetimes
- Non-RAII `vec<T>` (`va_heap`), `bitmap`, and heap buffers must be explicitly freed on all exit paths: `get_loop_latch_edges` and `assign_parms_augmented_arg_list` callers must `.release ()` the returned `vec`; `get_loop_body*`, `get_block_vector`, `create_edge_list` (`free_edge_list`), `compute_idf` (`BITMAP_FREE`), and `single_pred_before_succ_order` callers must free the returned pointers; and `predicate::m_preds` (`pred_chain_union`) must `.release ()` each element `pred_chain` before `m_preds.release ()` (and `.copy ()` elements on assignment). [F82, F132, F133, F303, F305, F360, F361]
- `free_cfg` and `free_block` require dominance info to be freed first and must release `va_gc` vectors (`bb->succs`, `bb->preds`, `x_label_to_block_map`, `basic_block_info_for_fn`) via `vec_free` before `ggc_free`. `flow_loop_free` must `vec_free (loop->superloops)` and self-link every node in the circular `loop->exits` list before `ggc_free`. `gimple_seq_discard` must unlink each stmt with `gsi_remove (&gsi, true)` and call `release_defs (stmt)` before `ggc_free (stmt)`. [F83, F135, F420]
- `auto_edge_flag` and `auto_bb_flag` only reserve and release a flag bit in `fun->cfg`; the user must clear that bit from all marked edges or basic blocks before the guard is destroyed. Every `record_layout_info` from `start_record_layout` must be freed via `finish_record_layout (rli, true)` (or `vec_free (rli->pending_statics)` and `free (rli)`), and `ggc_collect` must never run while `rli` is live because `record_layout_info_s` is `XNEW`-allocated and not a GTY root. [F102, F463, F464]

## API Contracts
- `tree_to_shwi`, `tree_to_uhwi`, `tree_to_poly_int64`, and `tree_to_poly_uint64` assert that `t` satisfies the corresponding `tree_fits_*_p` predicate. `wi::extended_tree<N>` requires `TYPE_PRECISION (TREE_TYPE (t)) <= N` and only supports `N == ADDR_MAX_PRECISION` (`wi::to_offset`) or `N >= WIDEST_INT_MAX_PRECISION` (`wi::to_widest`), so wide `BITINT_TYPE` constants exceeding `ADDR_MAX_PRECISION` must not be passed to `wi::to_offset` or `wi::to_poly_offset`. [F508, F509]
- `TYPE_PRECISION` rejects `VECTOR_TYPE` via `TREE_NOT_CHECK`; vector element counts must use `TYPE_VECTOR_SUBPARTS` and `SET_TYPE_VECTOR_SUBPARTS` (with `valid_vector_subparts_p`). `DECL_FUNCTION_CODE`, `DECL_MD_FUNCTION_CODE`, and `DECL_FE_FUNCTION_CODE` assert `DECL_BUILT_IN_CLASS` equals `BUILT_IN_NORMAL`, `BUILT_IN_MD`, or `BUILT_IN_FRONTEND` respectively (`fndecl_built_in_p` with class must be checked first). `as_builtin_fn` and `as_internal_fn` assert `builtin_fn_p` and `internal_fn_p`. [F507, F527, F528, F536]
- Before comparing types via `TYPE_CANONICAL`, callers must verify `!TYPE_STRUCTURAL_EQUALITY_P` (`TYPE_CANONICAL != NULL_TREE`), and middle-end TBAA/canonical queries must not use `TYPE_CANONICAL` when `canonical_type_used_p` is false (`POINTER_TYPE_P`, `ARRAY_TYPE`, `VECTOR_TYPE`). When `DECL_NONADDRESSABLE_P` is set on a `FIELD_DECL`, TBAA queries on a `COMPONENT_REF` must use the containing aggregate's alias set. `TREE_HASH` (`tree_hash`) hashes pointers and must never be used in `GTY` PCH-saved tables. [F515, F516, F546, F553]
- To test whether a `GIMPLE_CALL` is a valid built-in call, use `gimple_call_builtin_p` (or `gimple_call_combined_fn`), which verifies `gimple_builtin_call_types_compatible_p` in addition to `fndecl_built_in_p`. `canonicalize_cond_expr_cond` permits trapping comparisons and `_Complex` operands, whereas `GIMPLE_COND` statements require `is_gimple_condexpr_for_cond` (which rejects `tree_could_throw_p`). [F325, F427]
- `layout_type` must switch `type` to `TYPE_MAIN_VARIANT (type)` before checking `TYPE_SIZE` or computing layout, and `AGGREGATE_TYPE_P` types must not have `TYPE_ALIAS_SET_KNOWN_P` set before layout completes. `align_local_variable` must only call `SET_DECL_ALIGN` when `really_expand` is true (and `decl` is not an `SSA_NAME`), and `defer_stack_allocation` must defer whenever `align_local_variable (var, false) * BITS_PER_UNIT > MAX_SUPPORTED_STACK_ALIGNMENT`, `flag_stack_protect`, or `asan_sanitize_stack_p ()` holds. [F124, F138, F139, F478]
- In `build_bitint_stmt_ssa_conflicts`, `def` for the statement LHS must be called after recording all direct and merged operand `use`s whenever `muldiv_p` holds (multiply/divide/modulo, `.MUL_OVERFLOW`, `.BSWAP`, `.BITREVERSE`, and on `bitint_big_endian` targets `.ADD_OVERFLOW`/`.SUB_OVERFLOW` or ops with mismatched limb counts) so the LHS and inputs cannot coalesce into the same partition. [F400]

## Known Pitfalls
- On a `GIMPLE_ASSIGN` tuple `gs`, `gs->subcode` is not updated when a `GIMPLE_SINGLE_RHS` operand (`gs->op[1]`) is rewritten by SSA or propagation; always call `gimple_assign_rhs_code (gs)` instead of reading `gs->subcode`. In `walk_gimple_seq_mod`, only call `gsi_next (&gsi)` when `wi->removed_stmt` is false (resetting `wi->removed_stmt = false` otherwise), because removing the current statement already advances `gsi`. [F407, F426]
- `DECL_RTL (NODE)` lazily invokes `make_decl_rtl` when unset, and `DECL_ASSEMBLER_NAME (NODE)` lazily mangles the declaration; use `DECL_RTL_SET_P`/`DECL_RTL_IF_SET`/`COPY_DECL_RTL` and `DECL_ASSEMBLER_NAME_RAW`/`COPY_DECL_ASSEMBLER_NAME` when probing or copying without triggering creation. On a `VECTOR_TYPE`, `TYPE_MODE` calls `vector_type_mode` for the current target ISA, whereas `TYPE_MODE_RAW` returns the raw `type_common.mode` field. [F538, F557, F561]
- `CALL_EXPR_ARGP (NODE)` must use `(&(TREE_OPERAND (CALL_EXPR_CHECK (NODE), 0)) + 3)` rather than `&CALL_EXPR_ARG (NODE, 0)` (which fails bounds checking on 0-arg calls). `BITINT_TYPE_P (type)` must be used instead of `TREE_CODE (type) == BITINT_TYPE` so bit-precise `ENUMERAL_TYPE`s are included, and `layout_type` for multi-limb `BITINT_TYPE` must call `finalize_type_size` while `TYPE_MODE` is still `BLKmode` so `TYPE_ALIGN` stays at `limb_mode` alignment. [F484, F494, F501, F523]
- `real_zerop` and `real_negzerop` return true for `VECTOR_CST`, `COMPLEX_CST`, and location wrappers in addition to `REAL_CST`, so never pass a `real_zerop` node to `TREE_REAL_CST` without checking `TREE_CODE == REAL_CST`. `VECTOR_INTEGER_TYPE_P` matches only `INTEGER_TYPE` elements (excluding `VECTOR_BOOLEAN_TYPE_P`, enums, and `_BitInt`), and signed 1-bit integral types (`TYPE_PRECISION == 1 && !TYPE_UNSIGNED`) represent truth as `-1` (`constm1_rtx`) rather than `1`. [F262, F525, F542]
- In `pass_expand::execute`, `FOR_EACH_SSA_NAME` loops querying `SA.map` after `expand_used_vars` must skip names with `SSA_NAME_DEF_STMT (name) == NULL`, `verify_partition_mem_exprs ()` must run only after `PARM_DECL`/`RESULT_DECL` default-def `MEM_EXPR`s are restored, and post-expand `cleanup_cfg` must pass `CLEANUP_NO_INSN_DEL`. During `expand_debug_locations`, `flag_strict_aliasing` must be zeroed and `expand_debug_expr` must never emit RTL insns (`last == get_last_insn ()`). [F148, F150, F167, F178, F182]
- In `cfgrtl.cc` and `cfgloopmanip.cc`, any `sbitmap` or array indexed by `bb->index` must be sized to `last_basic_block_for_fn (cfun)` (not `n_basic_blocks_for_fn`), raw RTL insn walks must guard `BLOCK_FOR_INSN`/`set_block_for_insn`/`df_insn_change_bb` with `!BARRIER_P (insn)`, and in `gcc/machmode.h`, `is_a<scalar_int_mode>`/`is_a<scalar_float_mode>` accept `MODE_PARTIAL_INT`/`MODE_DECIMAL_FLOAT` whereas `is_int_mode`/`is_float_mode` only match `MODE_INT`/`MODE_FLOAT`. [F192, F219, F447]
