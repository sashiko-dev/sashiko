# config-riscv

The `config-riscv` unit implements the RISC-V GCC driver and backend, covering ISA/CPU option and target-attribute parsing (`riscv-common.cc`, `riscv-target-attr.cc`), `targetm` hooks, ABI calling conventions, frame layout, constant/address legitimization, cost/scheduling models, and FMV dispatch (`riscv.cc`), RVV vector codegen (`riscv-v.cc`), inline stringops (`riscv-string.cc`), RTL optimization passes, machine descriptions (`riscv.md`, `autovec*.md`, `bitmanip.md`, `sync*.md`), and vendor extensions/pipelines.

## Architecture & Data Flow

- In `autovec.md`, `vec_duplicate<mode>` and `vec_init<mode>qi` for `VB` mask modes must mask the `QImode` scalar/vector input with `1` before comparing `NE` against `CONST0_RTX`. In `vec_set<mode>` and `vec_extract<mode><vel>`, non-zero index `operands[2]` must be unsigned-converted to `Pmode` via `convert_to_mode (Pmode, operands[2], true)` (not `gen_lowpart`). When `TARGET_XTHEADVECTOR` holds and `GET_MODE_NUNITS (<MODE>mode) < BYTES_PER_RISCV_VECTOR`, `vec_init<mode>qi` and `vec_extract<mode>qi` must use `get_m1_mode (QImode, ...)` with a `get_mask_mode` lowpart subreg. [F21, F22, F23]
- In `autovec.md` and `autovec-opt.md`, vector FP FMA patterns must match `(fma ...)` RTXes rather than unfused `(plus/minus (mult ...))`. IEEE 754 `fmax`/`fmin` patterns (`<ieee_fmaxmin_op><mode>3`, `cond_*`, `*v<ieee_fmaxmin_op>_vf_*`, `reduc_fmax_scal_*`, `reduc_fmin_scal_*`) require `!HONOR_SNANS (<MODE>mode)` and `reduc_fmax/fmin_scal_*` must initialize with `real_nan`. `mask_len_fold_left_*` (`UNSPEC_REDUC_SUM_ORDERED`) must emit a plain move when `operands[4]` is `const0_rtx`. [F31, F32, F33]
- In `riscv.md`, outer-negated FMA patterns (`*fma<mode>4`, `*fms<mode>4`, `*fnms<mode>4`, `*fnma<mode>4`) require `!HONOR_SIGNED_ZEROS (<MODE>mode)` and `fmin<mode>3`/`fmax<mode>3` require `!HONOR_SNANS (<MODE>mode)`. In `riscv_emit_float_compare`, `UNLT`/`UNGT`/`UNLE`/`UNGE` must emit `gen_f*_quiet*` tested against `const0_rtx` and `ORDERED`/`UNORDERED`/`UNEQ` must use quiet `EQ` (`feq`). In `expand_vec_cmp_float`, `UN*`/`ORDERED` must compute `vmfeq.vv` orderedness masks (unmasked on both operands when `HONOR_SNANS`) to mask signaling compares. [F85, F151, F194]
- In `bitmanip.md`, sub-word `bswaphi2` and `bitreverse<mode>2` (`<MODE>mode != word_mode && <MODE>mode != QImode`) using `word_mode` `bswap` must logically right-shift by `GET_MODE_BITSIZE (word_mode) - GET_MODE_BITSIZE (<MODE>mode)` before `gen_lowpart`. 64-bit `TARGET_ZBS` splitters rewriting `DImode` ops with `(sign_extend:DI (ashift:SI (const_int 1) op1))` into `bset`/`binv`/`bclr` require `num_sign_bit_copies (operands[2], DImode) >= 33` and a trailing `(sign_extend:DI (subreg:SI (match_dup 0) 0))`. `bext` patterns folding `(and pos mask)` require `mask == GET_MODE_BITSIZE (<MODE>mode) - 1`. [F24, F25, F27]
- In `constraints.md`, `B1`/`B2` (loads) and `B3`/`B4` (stores) require register-indirect constraint `A` under `TARGET_ZALASR` for `MEMMODEL_ACQUIRE` loads or `MEMMODEL_RELEASE`/`MEMMODEL_SEQ_CST` stores, and allow `m` otherwise; `sync-rvwmo.md` and `sync-ztso.md` patterns emitting `.aq`/`.rl` must pair `'m,A'` with `'B2,B1'` or `'B4,B3'`. In `sync.md`, every AMO, LR/SC, CAS, exchange, and test-and-set pattern with `'+A'` must use `riscv_atomic_memory_operand` (not `memory_operand`), and `zacas_atomic_cas_value_strong<mode>` must write `riscv_union_memmodels` to `operands[4]`, leaving `operands[5]` intact for the length attribute. [F29, F157, F189, F190]
- In `riscv-v.cc`, `shuffle_slide_patterns` on the `!slideup && !slidedown` path must check `d->perm[0] == vlen - slideup_cnt` and `d->perm[vlen - 1] == 2 * vlen - 1 - slideup_cnt` alongside the `slideup_cnt` boundary, and its monotonicity scan must reject a second pivot (`i != pivot` where `maybe_ne (d->perm[i], d->perm[i - 1] + 1)`) when `need_slideup_p`, `pivot == -1`, `len != 0`, or `known_ge (d->perm[i], vec_len)`. `shuffle_compress_patterns` must verify strictly increasing indices across `1 <= i < compress_point` and unit-step indices starting at `1 + compress_point`. `shuffle_generic_patterns` must reject `!pow2p_hwi (d->perm.encoding ().npatterns ())`. [F35, F36, F41, F61]
- In `riscv_vector::legitimize_move`, when `lra_in_progress` holds, moves for VLS modes with `NUNITS > 31`, fractional-LMUL modes (`GET_MODE_SIZE (mode) < BYTES_PER_RISCV_VECTOR`), and `MODE_VECTOR_BOOL` masks must emit `gen_mov_lra` without allocating a scratch VL register; `expand_vector_subreg_extract` is only valid when `!lra_in_progress`, for non-tuple inner modes whose bit-size is a constant power-of-two multiple (`> 1`) of the outer mode and not a multi-register LMUL rename. In `expand_tuple_move`, reg-to-reg moves must iterate in reverse (`nf - 1 - i`) when `REGNO (ops[0]) > REGNO (ops[1])`. [F70, F71, F79]
- In `riscv-v.cc`, `riscv_v_widen_constraint_ok` must return `false` for tuple modes, `wide_mode == mode`, `regno == wide_regno`, or `wide_nregs < nregs`, return `nregs == 1` when `wide_nregs == nregs`, and allow overlap only when `!is_frac_vlmul_p (mode)` and `(regno % wide_nregs) == wide_nregs - nregs`; widening reductions must instead use `riscv_v_widen_non_overlap_constraint_ok` to reject any `riscv_v_reg_group_overlap_p`. In `prepare_ternary_operands`, if `ops[5]` is not `RVV_VUNDEF (mode)` and differs from `ops[2..4]`, `ops[5]` and `ops[4]` must be pre-merged into `ops[0]`. [F77, F78, F82]
- In `riscv-v.cc`, `imm_avl_p` must divide `GET_MODE_NUNITS (mode)` by `get_nf (mode)` when `riscv_tuple_mode_p (mode)` before checking `IN_RANGE (..., 0, 31)`. `get_gather_scatter_code` must pass `UNSPEC_ORDERED` for scatter stores (`!is_load`) and `UNSPEC_UNORDERED` for gather loads. `insn_expander::emit_insn` must index caller `ops` with `opno` and `m_ops`/`insn_data[(int) icode].operand` with `m_opno`. Under `RVV_VECTOR_BITS_SCALABLE` and `!allow_up_to_lmul_8`, `vls_mode_valid_p` must reject `MODE_VECTOR_BOOL` modes where `ordered_p (TARGET_MAX_LMUL * BITS_PER_RISCV_VECTOR, GET_MODE_PRECISION (mode))` holds. [F37, F62, F80, F81]
- In `riscv.cc`, `riscv_for_each_saved_reg` and `riscv_process_components` must advance `offset` and `num_masked_fp` for every bit in `frame.mask` and `frame.fmask` even when a register is skipped for `reg_is_wrapped_separately`, `components`, or `riscv_is_eh_return_data_register`. `riscv_for_each_saved_v_reg` must iterate `V_REG_FIRST..V_REG_LAST` with pre-decremented SP in the prologue and `V_REG_LAST..V_REG_FIRST` with post-incremented SP in the epilogue. In `riscv_v_adjust_scalable_frame`, when `flag_stack_clash_protection && !epilogue && !frame_pointer_needed`, `REG_CFA_DEF_CFA` and `RTX_FRAME_RELATED_P` must attach to the `insn` from `emit_move_insn (stack_ptr_copy, stack_pointer_rtx)` followed by `riscv_emit_stack_tie (stack_ptr_copy)`. [F87, F88, F147]
- Callers of `riscv_gen_multi_push_pop_insn` must compute `regs_num` via `riscv_multi_push_regs_count` so `code_for_push_pop[regs_num - 1]` never indexes the `nullptr` slot at 11 (`ZCMP_INVALID_S0S10_SREGS_COUNTS`). In `vector_zero_call_used_regs`, the `vl_regno` search in `need_zeroed_hardregs` must start at `GP_REG_FIRST + 1` (skipping `x0`). In `riscv_get_vector_arg`, `i + V_REG_FIRST` is the register number while `idx = i - (V_ARG_FIRST - V_REG_FIRST)` indexes `cum->used_vrs`. [F89, F92, F149]
- In `riscv.cc`, `riscv_regmode_natural_size` must return one hardware vector register size for `riscv_vector_mode_p` (`BYTES_PER_RISCV_VECTOR` for VLA, `TARGET_MIN_VLEN / BITS_PER_UNIT` for VLS, or subpart size if `< BYTES_PER_RISCV_VECTOR` for tuples), and `HARD_REGNO_CALLER_SAVE_MODE` must preserve a non-`VOIDmode` `MODE` rather than calling `choose_hard_reg_mode`. `riscv_can_change_mode_class` must reject all `FP_REGS` changes and `V_REGS` changes when precisions are unordered or when a constant-`NUNITS` `from` differs in precision from `to` and is unordered with `BITS_PER_RISCV_VECTOR`. `riscv_modes_tieable_p` must reject mixing vector and non-vector modes, tuples with different inner element modes, or distinct `MODE_FLOAT` modes. [F135, F136, F137, F176]
- In `riscv.cc`, `spill_subreg_move` must offset the `GET_MODE (SUBREG_REG (op))` stack slot by `SUBREG_BYTE (op)` via `adjust_address` and pre-spill `inner` to `mem` before writing `mem_outer` when `maybe_gt (GET_MODE_SIZE (mode_inner), GET_MODE_SIZE (GET_MODE (dest)))`. `riscv_legitimize_move` moving `HFmode`/`BFmode` from a non-FP reg to an `FP_REG_P` when `TARGET_HARD_FLOAT && !TARGET_ZFHMIN && can_create_pseudo_p ()` must zero-extend the `HImode` lowpart to `word_mode`, OR with `-65536`, and emit `UNSPEC_FMV_FP16_X`. In `riscv_move_integer`, `codes[i].code == FMA` must be handled before `codes[i].use_uw`, masking the shifted operand with `0xffffffffULL << value` when `use_uw` is also set. [F133, F145, F148]
- In `riscv.cc`, `riscv_legitimate_address_p` must reject `SUBREG`s of `riscv_vector_mode_p` registers, and `riscv_classify_address` for `riscv_vector_mode_p` must disallow `PLUS` and `LO_SUM` and only accept `const0_rtx` for `CONST_INT`. `riscv_legitimize_call_address` (for `sibcall_p`) and `riscv_force_address` must check `can_create_pseudo_p ()`, falling back in `riscv_in_thunk_func` to `STATIC_CHAIN_REGNUM` and `RISCV_PROLOGUE_TEMP2 (Pmode)`. Every `SYMBOL_REF_DECL (x)` access must first verify `SYMBOL_REF_P (x)` and non-null `SYMBOL_REF_DECL (x)`. [F114, F141, F146]

## Object Lifetimes

- In `riscv-common.cc`, `riscv_get_valid_option_values` must initialize `vec<const char *> v` with `v.create (0)` and return it by value without `v.release ()` or `auto_vec`; `riscv_parse_arch_string` must `delete` any existing non-null `cmdline_subset_list` before reassigning it. In `riscv.cc`, `riscv_get_separate_components` and `riscv_components_for_bb` must allocate with `sbitmap_alloc` (not `auto_sbitmap`) and return or `sbitmap_free` it on all paths; strings stored in `opts->x_riscv_arch_string` (`riscv_target_attr_parser::update_settings`) or passed to `gen_rtx_SYMBOL_REF` (`riscv_split_symbol`) must be copied with `ggc_strdup`. [F9, F12, F51, F102, F103]

## API Contracts

- When `testing_p` is true (`target == NULL_RTX` in `riscv_vector::expand_vec_perm_const`, or `testing_p == true` in `riscv_expand_setmem` and its helpers `expand_vec_setmem`, `riscv_expand_block_clear`, `riscv_expand_block_clear_zicboz_zic64b`, and `expand_scalar_setmem`), functions and `shuffle_*_patterns` helpers must only test preconditions and return without emitting any RTL or allocating registers (`expand_vec_perm_const` asserts `get_last_insn ()` is unchanged). [F60, F67]
- In `riscv-target-attr.cc` and `riscv.cc`, `riscv_option_valid_attribute_p` and `riscv_option_valid_version_attribute_p` must save and restore `global_options` and `global_options_set` via `cl_target_option_save`/`cl_target_option_restore` and only update `DECL_FUNCTION_SPECIFIC_TARGET` on success; `parse_features_for_version` and `riscv_check_target_clone_version` must also reset `global_options` to `TREE_TARGET_OPTION (target_option_default_node)` before calling `riscv_process_target_version_str`. `riscv_can_inline_p` must reject inlining when `DECL_FUNCTION_VERSIONED (callee) && !DECL_FUNCTION_VERSIONED (caller)` or when `x_target_flags` differ or fail `riscv_ext_is_subset`, before checking `always_inline`. [F56, F116, F122]

## Error Handling

- In `riscv_subset_list::parse`, after `new riscv_subset_list`, every error path must `goto fail` to delete `subset_list` and set `riscv_subset_list::parse_failed = true` (which stays set permanently, causing all subsequent `parse` calls to return `NULL`); in `parse_single_multiletter_ext`, `subset` (`xstrdup (p)`) must be freed on all early returns and on the normal path only after `p += end_of_version - subset`. In `riscv-target-attr.cc`, every error path in `parse_arch` after allocating `m_subset_list` must `goto fail`, cloning `riscv_cmdline_subset_list()` must call `m_subset_list->set_loc(m_loc)`, and all diagnostics must guard `error_at` on non-null `loc`/`m_loc`. [F10, F11, F15, F50, F54, F55]

## External Contracts

- In `riscv.h` and `riscv.cc`, `PROMOTE_MODE` must force `UNSIGNEDP = 0` when promoting `SImode` to `word_mode` on `TARGET_64BIT`, `riscv_promote_function_mode` must apply `PROMOTE_MODE` even when `type == NULL_TREE`, and `riscv_function_value` must call `promote_function_mode` before `riscv_get_arg_info`. `riscv_get_vls_container_type` must map the inner element byte size to an integer mode (`QImode`..`DImode`) before `get_lmul_mode (smode, lmul).require ()`, and `riscv_pass_vls_in_vr` must restore the VLS `mode` via `PUT_MODE`. [F142, F144, F174]

## Known Pitfalls

- In `autovec-opt.md` and `autovec.md`, splitting a `VB_VLS` mask instruction whose `UNSPEC_VPREDICATE` has both mask-policy (`operands[5]`) and `avl_type` (`operands[6]`) into `gen_pred_mov` must pass `operands[6]` (not `operands[5]`) as the final argument; `*vwsll_sign_extend_<mode>` may only emit `code_for_pred_vwsll_scalar` when `INTVAL (operands[2]) >= GET_MODE_PRECISION (GET_MODE_INNER (<V_DOUBLE_TRUNC>mode))`; and `len_fold_extract_last_<mode>` must use iterator `V` rather than `V_VLS`. [F1, F19, F28]
- In `riscv-v.cc` and `riscv-vect-permconst.cc`, `expand_const_vector_single_step_npatterns` must compute the step element index and shift count after `v.build ()` from `builder->npatterns ()` rather than `v.npatterns ()`; and `const_vector_hasher::equal` must compare `CONST_VECTOR` elements with `rtx_equal_p` rather than pointer equality on `normalized_vec`. [F34, F63]
- In `riscv.cc`, the bitwise-NOT constant synthesis case (`~value` followed by `XOR -1`) must remain in `riscv_build_integer` guarded by `value < 0` (never in `riscv_build_integer_1`, which causes mutual recursion); and in `riscv_rtx_costs`, the `LSHIFTRT` case must recognize a `2XWIDER_MODE (word_mode)` `MULT` of `ZERO_EXTEND`/`SIGN_EXTEND` shifted right by `BITS_PER_WORD` inside `outer_code == TRUNCATE` and return `tune_param->int_mul[mode == TImode]` before falling through to `ASHIFTRT`. [F94, F117]
- In `riscv.md`, the `SImode`-in-`DImode` shift-add splitter (lines 5174–5206) must assign `operands[6] = operands[3]` (not `operands[4]`) in its `SMALL_OPERAND` fallback; `*seq_sne_qi` requires `shamt` in `1..7`, constant in `-128..127` with low `shamt` bits zero, and must compute `operands[3]` from `INTVAL (operands[2])` before overwriting `operands[2]`; `p2m1_shift_operand` `AND` splitters must write the `ashift` to scratch `operands[3]` using `GET_MODE (operands[1])`; and `*branch<ANYI:mode>_shiftedmask_equals_zero` requires `INTVAL (operands[3]) >= 0 || !partial_subreg_p (operands[2])`. [F156, F158, F180, F181, F182]
- In `riscv.md` and `sync.md`, `stack_protect_set_<mode>` and `stack_protect_test_<mode>` must never be split, must emit memory ops via `riscv_output_move`, and must zero their scratch registers; `atomic_compare_and_swap<mode>` when `word_mode != <MODE>mode` (`SImode` on RV64) must sign-extend a non-zero expected `operands[3]` and the post-CAS difference to `word_mode`; non-Zfa `<round_pattern><ANYF:mode>2` requires `(flag_fp_int_builtin_inexact || !flag_trapping_math)`, `(TARGET_64BIT || mode != DFmode)`, and `mode != HFmode`, bypassing `fcvt` on NaN and quieting sNaNs with `gen_add<ANYF:mode>3` under `flag_trapping_math`; and non-Zfa `f<quiet_pattern>_quiet<ANYF:mode><X:mode>4` must bracket the compare with `UNSPECV_FRFLAGS`/`UNSPECV_FSFLAGS` and emit `UNSPECV_FSNVSNAN` when `HONOR_SNANS`. [F188, F191, F192, F193]
- In `thead.cc`, `th_fmemidx_output_index` indexes `insn[load][index]` by `exact_log2 (GET_MODE_SIZE (mode).to_constant ()) - 2`, so `is_fmemidx_mode` must only accept 4-byte (`SFmode`) and 8-byte (`DFmode`) modes; and in `th_asm_output_opcode`, all `xtheadvector` FP conversion handlers (`TYPE_VF*CVT*`) must advance the returned opcode pointer by 4 extra bytes when `p` contains `".rtz"` or `".rod"`. [F155, F187]
