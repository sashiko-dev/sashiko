# vectorizer

This unit implements GCC's middle-end loop and basic-block vectorization driver, cost modeling, and transformation phases (`gcc/tree-vect-loop.cc`), data-reference and dependence analysis (`gcc/tree-vect-data-refs.cc`), predictive commoning (`gcc/tree-predcom.cc`), and generic vector-to-scalar GIMPLE lowering (`gcc/tree-vect-generic.cc`).

## Architecture & Data Flow

- Tree expressions reused across GIMPLE emission must be cloned with `unshare_expr`: `cond` in `do_cond`; `base_address`, `offset`, `init`, and `DR_REF` in `vect_analyze_data_refs` and `vect_create_addr_base_for_vector_ref` (passing `DR_REF` through `strip_zero_offset_components` first in BB mode); `addr` in `ref_at_iteration`, `niters` in `prepare_finalizers_chain`, and `val` in `replace_ref_with`; `expr` in `cse_and_gimplify_to_preheader`; and `niter` / `LOOP_VINFO_NITERSM1` in `vect_get_loop_niters` and `vect_transform_loop`. [F30, F31, F32, F85, F86]
- Keep paired locals synchronized on mutation: in `vect_prune_runtime_alias_test_list`, canonicalizing a grouped access to `DR_GROUP_FIRST_ELEMENT` must update both `stmt_info_a`/`b` and `dr_info_a`/`b` (`STMT_VINFO_DR_INFO`); in `expand_vector_operations_1`, `gimple_assign_set_rhs2 (stmt, first)` must also update local `rhs2`; in `vect_create_epilog_for_reduction`, demoting a mask `vectype` to `VECT_REDUC_INFO_VECTYPE_FOR_MASK` must also update `compute_vectype`, and `vectype1` must be initialized from `compute_vectype` (or `stype` when `mode1 != mode`). [F7, F8, F63, F64]
- In `vect_transform_reduction`, when `effec_ncopies < total_ncopies` pads `vec_oprnds` with null entries, call `vect_get_loop_mask` with unpadded `vec_in_num` and a separate `mask_index++` advanced only on non-null vector operations rather than loop index `i`. [F65]
- When indexing `LOOP_VINFO_MASKS (loop_vinfo).rgc_vec`, `vect_partial_vectors_while_ult` indexes by `nvectors - 1` (`rgm->factor == 1`), whereas `vect_partial_vectors_avx512` indexes by `nscalars_per_iter - 1` (`rgm->factor = nvectors`). `vect_verify_full_masking_avx512` requires every mask type in `rgc_vec` to have `GET_MODE_CLASS (TYPE_MODE (mask_type)) == MODE_INT` and 1-bit element precision for integer-shift splitting in `vect_get_loop_mask`. [F69, F105]
- In `vect_analyze_loop_2`, `LOOP_VINFO_USING_SELECT_VL_P` requires a single `LOOP_VINFO_LENS` rgroup with `factor == 1`, `!LOOP_VINFO_NITERS_KNOWN_P || !LOOP_VINFO_VECT_FACTOR.is_constant ()`, `IFN_SELECT_VL` support, and no non-`ldst_lanes` SLP instance with `SLP_TREE_LANES != 1`. `vect_verify_loop_lens` must reject length-based partial vectors when `internal_len_load_store_bias` is `-1` and `LOOP_VINFO_LENS (loop_vinfo).length () > 1`. [F94, F106]
- `needs_fold_left_reduction_p` requires in-order `FOLD_LEFT_REDUCTION` when `SCALAR_FLOAT_TYPE_P (type) && !flag_associative_math` (except `MIN_EXPR`, `MAX_EXPR`, `CFN_FMIN`, `CFN_FMAX`) or `INTEGRAL_TYPE_P (type) && !operation_no_trapping_overflow (type, tree_code (code))`. When `vect_get_loop_niters` folds a `COMPARISON_CLASS_P` `may_be_zero` into `COND_EXPR <may_be_zero, 0, niter>`, it must wrap `niter` in `rewrite_to_non_trapping_overflow (niter)`. [F99, F112]
- In `vectorize_fold_left_reduction` and `neutral_op_for_reduction`, floating-point addition uses `-0.0` as identity when `HONOR_SIGNED_ZEROS` holds, and `vect_reduction_update_partial_vector_usage` must disable partial vectors when `internal_fn_mask_index (reduc_fn) == -1` and `HONOR_SIGN_DEPENDENT_ROUNDING` holds. [F113]
- When reducing a `VECTOR_BOOLEAN_TYPE_P` vector in `vectorizable_reduction` and `vect_create_epilog_for_reduction`, `IFN_REDUC_AND/IOR/XOR` require `MODE_VECTOR_BOOL` on `vectype_out`; otherwise use `sbool_reduction_fn_for_fn` (`IFN_REDUC_SBOOL_*`) or convert to `VECT_REDUC_INFO_VECTYPE_FOR_MASK` via `VEC_COND_EXPR`. In `vect_find_reusable_accumulator`, reusing an accumulator for a narrower epilogue `vectype` requires `MODE_VECTOR_INT` for `VECTOR_BOOLEAN_TYPE_P (vectype)` and `directly_supported_p` plus `can_vec_extract` at each halving step. [F103, F107]
- Guard against variable-length vectors (`!is_constant ()` subparts) before constant-lane decomposition in `lower_vec_perm`, `optimize_vector_constructor` (`nunits_for_known_piecewise_op`), `vect_grouped_store_supported` / `vect_grouped_load_supported` (`count == 3`), and `have_whole_vector_shift`. On variable-length vectors, `vectorizable_reduction` requires `EXTRACT_LAST_REDUCTION` or `reduc_fn != IFN_LAST`, and requires `direct_internal_fn_supported_p (IFN_VEC_SHL_INSERT, vectype_out, OPTIMIZE_FOR_BOTH)` when `get_initial_defs_for_reduction` uses `CFN_VEC_SHL_INSERT`. [F58, F59, F110, F111]
- For a `vect_nested_cycle` PHI in `vectorizable_reduction`, each SLP child must pass `vect_maybe_update_slp_op_vectype` and any `vect_internal_def` child must satisfy `useless_type_conversion_p (SLP_TREE_VECTYPE (slp_node), SLP_TREE_VECTYPE (child))`. `vect_is_simple_iv_evolution` must set `STMT_VINFO_LOOP_PHI_EVOLUTION_TYPE = vect_step_op_add`, which `is_nonwrapping_integer_induction` must verify before treating an `INTEGER_CST` base/step induction as linear non-wrapping. [F91, F104]
- In `vect_analyze_data_ref_dependence`, both `dist == 0` and negative-distance (`dist > 0 && DDR_REVERSED_P (ddr)`) branches must verify `vect_preserves_scalar_order_p (dr_info_a, dr_info_b)`. When `vect_slp_analyze_store_dependences` sinks a store, it must pass `tbaa_p = false` to `stmt_may_clobber_ref_p_1` and `ref_maybe_used_by_stmt_p`, and `vect_slp_analyze_load_dependences` must insert `DR_GROUP_FIRST_ELEMENT (stmt_info)` into `grp_visited` so grouped stores are walked at most once per load. [F14, F35, F42]
- When `vect_analyze_early_break_dependences` walks blocks before the early-exit destination (`check_deps == true`), any non-DR statement or statement in its `STMT_VINFO_PATTERN_DEF_SEQ` satisfying `gimple_could_trap_p` must fail vectorization. [F36]
- In `vect_enhance_data_refs_alignment`, clearing `dr_safe_speculative_read_required` and setting `LOOP_VINFO_MUST_USE_PARTIAL_VECTORS_P` for `DR_SCALAR_KNOWN_BOUNDS` with variable `vf` must run in a dedicated loop before the peeling loop (which can `break` early), and the subgroup loop must run to `i <= datarefs.length ()` and check `i == datarefs.length ()` first to flush `[i0, i - 1]`. [F6, F37]
- In BB vectorization (`is_a <bb_vec_info> (vinfo)`), when a data reference fails analysis or lacks an addressable base or `vectype`, `vect_analyze_data_refs` and `vect_analyze_data_ref_accesses` must set `STMT_VINFO_VECTORIZABLE (stmt_info) = false` and `continue` rather than aborting. `vect_analyze_data_ref_accesses` must sort a copy (`datarefs_copy`) with `dr_group_sort_cmp` rather than reordering `vinfo->shared->datarefs`. [F12, F39]
- In `vect_create_addr_base_for_vector_ref`, call `vect_duplicate_ssa_name_ptr_info` only when `TREE_CODE (addr_base) == SSA_NAME && SSA_NAME_VAR (addr_base) == dest` (which must call `mark_ptr_info_alignment_unknown`). In `vect_create_data_ref_ptr`, if `get_alias_set (aggr_type)` does not conflict with `get_alias_set (DR_REF (dr))` (or any `DR_REF (sdr)` in a `DR_GROUP_SIZE > 1` group), pass `can_alias_all = true` to `build_pointer_type_for_mode`. [F33, F44]
- In `vect_transform_loop`: split `LOOP_VINFO_MAIN_EXIT` into a single-predecessor block (when `!LOOP_VINFO_EARLY_BREAKS`) before `vect_loop_versioning` and split `LOOP_VINFO_SCALAR_MAIN_EXIT` before `vect_do_peeling`; add `bias_for_lowest` (or `bias_for_assumed`) before dividing loop iteration bounds/estimates by VF and subtract 1 afterward; for `LOOP_VINFO_EARLY_BREAKS`, `vect_update_early_break_profiles` must scale early-exit edges (and uncounted main exits) to `1 - (1 - P)^vf` and update fallthrough BB counts before `scale_loop_profile`; and reset `loop->safelen = 0`. [F67, F95, F96, F101]
- When `vect_create_epilog_for_reduction` replaces an exit PHI result with `scalar_result` on a `gphi` argument with an `EDGE_ABNORMAL` incoming edge, set `SSA_NAME_OCCURS_IN_ABNORMAL_PHI (scalar_result) = 1`. In `vectorizable_recurr`, check `gsi_stmt (gsi2) != NULL` before calling `gimple_uid (gsi_stmt (gsi2))`. In `optimize_mask_stores`, stop sinking backward through `store_bb` if `gimple_get_lhs (stmt1)` is NULL or not `SSA_NAME`, `gimple_vdef` is non-NULL, `gimple_has_volatile_ops` holds, non-debug uses exist outside `store_bb`, or a non-null `gimple_vuse` differs from `gimple_vuse (last_store)`. [F81, F87, F97, F98]

## Object Lifetimes

- `vec<T, va_heap, vl_ptr>` (including `stmt_vector_for_cost`) has no destructor (`~vec () = default`): local `vec<T>` variables allocated with `.create (...)` (such as `datarefs_copy` in `vect_analyze_data_ref_accesses`, `loop_nest` in `vect_slp_analyze_instance_dependence`, and cost vectors in `vect_peeling_hash_get_lowest_cost` and `vect_enhance_data_refs_alignment`) must call `.release ()` on every exit path and before re-calling `.create (...)`, or use `auto_vec<T>`. [F19, F20, F80]
- Any `vec<rgroup_controls>` (`LOOP_VINFO_MASKS (loop_vinfo).rgc_vec`, `LOOP_VINFO_LENS`) must be freed via `release_vec_loop_controls` to release each element's `rgc->controls`, and `LOOP_VINFO_SLP_INSTANCES` must have `vect_free_slp_instance` called on every element before `.release ()`. In `vect_slp_analyze_store_dependences` and `vect_slp_analyze_load_dependences`, every `ddr_p` from `initialize_data_dependence_relation` must be freed with `free_dependence_relation (ddr)` before any `continue` or `return false`. [F24, F74, F75]
- `_loop_vec_info` owns `bbs`, so `update_epilogue_loop_vinfo` must call `free (LOOP_VINFO_BBS (epilogue_vinfo))` before reassigning `LOOP_VINFO_BBS`. `~_loop_vec_info` must only clear `loop->aux` when `loop->aux == this`, and every rejected or replaced `loop_vec_info` in `vect_analyze_loop_1` and `vect_analyze_loop` (`unroll_vinfo`, `first_loop_vinfo`, `orig_loop_vinfo->epilogue_vinfo`) must be `delete`d. [F77, F79, F92]
- In `gcc/tree-predcom.cc`, discarding a `component` before `determine_roots` moves `comp->refs` into chains requires calling `free (ref)` on each `dref` (`release_components` only deletes `component` structs). Destroy `chain_p` via `pcom_worker::release_chain` (not `delete`), and clear `chain->init_seq` / `chain->fini_seq` to `NULL` once inserted into the CFG. [F22, F23]

## API Contracts

- Define `INCLUDE_ALGORITHM` (or `INCLUDE_*`) before `#include "system.h"` in `tree-vect-data-refs.cc`, `tree-predcom.cc`, and `tree-vect-generic.cc`; never `#include <algorithm>` directly after `system.h` (which poisons identifiers and omits `<algorithm>` when `HAVE_SWAP_IN_UTILITY` is set). [F16, F17]
- `vect_analyze_loop_form` must check `inner.number_of_iterations != chrec_dont_know` before `expr_invariant_in_loop_p`, and place the main exit condition at `info->conds[0]` so `vect_create_loop_vinfo` consumes `info->conds[0]` into `LOOP_VINFO_LOOP_IV_COND` (when `!LOOP_VINFO_NITERS_UNCOUNTED_P`) before pushing the rest into `LOOP_VINFO_LOOP_CONDS`. [F66, F82]
- `info_for_reduction` asserts its `slp_tree` argument is non-null, so reduction lookups and statement costing must pass a non-null `slp_tree`. In `vectorizable_reduction`, because `neutral_op_for_reduction` can return `NULL_TREE`, any `(double_reduc || neutral_op)` path must check `neutral_op != NULL_TREE` before calling `operand_equal_p`. [F84, F88]
- `vectorizable_induction`, `vectorizable_lane_reducing`, and `vectorizable_reduction` must reject non-mode-precision integral types (`!type_has_mode_precision_p`, except bitwise `AND`/`IOR`/`XOR` reductions), and `vectorizable_induction` must derive integral `step_vectype` via `signed_or_unsigned_type_for (TYPE_UNSIGNED (stept), vectype)`. Callers of `vect_slp_induction_reuse_p` must ensure `nivs * const_nunits <= group_size`. [F68, F102]
- In `vect_gather_scatter_fn_p`, pass 1 and pass 3 must verify `TYPE_SIGN (configs[i].offset_vectype) == TYPE_SIGN (offset_vectype)`, and pass 3 must set `*supported_offset_vectype = configs[i].offset_vectype` when `!useless_type_conversion_p (offset_vectype, configs[i].offset_vectype)`. In `vect_copy_ref_info`, verify `TREE_CODE (dest) == MEM_REF` and strip `handled_component_p` from `src` to confirm a `MEM_REF` or `TARGET_MEM_REF` before copying `MR_DEPENDENCE_CLIQUE`/`BASE`. In `expand_vector_operation` and `expand_vector_mult`, verify `VECTOR_CST` before `VECTOR_CST_ELT` and `INTEGER_CST` before querying integer values. [F25, F34, F41]

## Error Handling

- When `vect_analyze_loop_2` rolls back at `again:` (`goto start_over`) to retry with single-lane SLP, it must release/empty `LOOP_VINFO_SLP_INSTANCES`, `LOOP_VINFO_COMP_ALIAS_DDRS`, `LOOP_VINFO_CHECK_UNEQUAL_ADDRS`, `vector_costs`, `masks`, and `lens` (`release_vec_loop_controls`), and restore `STMT_VINFO_DEF_TYPE` on `STMT_VINFO_REDUC_DEF (stmt_info)` and its pattern stmt from the header PHI. [F78, F89]
- In `vect_find_stmt_data_reference`, any `data_reference_p` in `refs` not pushed into `*datarefs` must be freed with `free_data_ref`. When `vect_analyze_group_access_1` fails, `vect_analyze_group_access` must dissolve the entire group by clearing `DR_GROUP_FIRST_ELEMENT` and `DR_GROUP_NEXT_ELEMENT` on every member. [F21, F38]
- In `vectorizable_reduction`, after walking the SLP reduction chain to `slp_node`, check `slp_for_stmt_info != NULL` before accessing `SLP_TREE_REPRESENTATIVE (slp_for_stmt_info)`. In `vectorizable_lane_reducing`, check `vect_get_num_copies_for_invariant` for `false` and pass `ncopies_for_cost` to `vect_record_loop_len` / `vect_record_loop_mask` before multiplying it by 4 for `vect_is_emulated_mixed_dot_prod`. [F83, F90]

## Known Pitfalls

- In `vect_grouped_load_supported` (`count == 3`), the second permutation loop must reset `j = 0` on each `k` iteration and advance `j++` only when `3 * i + k >= 2 * nelt`. In `vect_grouped_store_supported` (`count == 3`), initialize `j0`, `j1`, and `j2` to `0` before the outer `j = 0..2` loop and increment them only when `3 * i + nelt0/1/2 < nelt`. [F4, F5]
- In `lower_vec_perm`, query output `elements` (`res_vect_type`) and input `in_elements` (`vect_type`) separately, and mask/bound constant permutation indices against `in_elements`. In `vector_element`, extracting a constant index from a `CONSTRUCTOR` must verify `TREE_CODE (TREE_TYPE (CONSTRUCTOR_ELT (vect, 0)->value)) != VECTOR_TYPE` and return `build_zero_cst (vect_elt_type)` when `index >= CONSTRUCTOR_NELTS (vect)`. [F27, F45]
- In `expand_vector_mult`, when `!TYPE_OVERFLOW_WRAPS (scalar_type)` holds, convert `op0` via `VIEW_CONVERT_EXPR` to `unsigned_type_for (type)` before emitting arithmetic, and in `alg_sub_factor` compute `tmp_var - accumulator`. Exclude clobbers (`gimple_clobber_p` / `TREE_CLOBBER_P`) from `optimize_vector_constructor` and `is_inv_store_elimination_chain`, and replace them with `get_or_create_ssa_default_def` in `replace_ref_with` and `initialize_root_vars_store_elim_2`. [F29, F46]
