# ipa-lto

Implements the core callgraph infrastructure (`cgraph.cc`, `cgraph.h`, `cgraphbuild.cc`) and AutoFDO sampling-based profile optimization (`auto-profile.cc`, `auto-profile.h`). It constructs and maintains the interprocedural multi-graph of functions (`cgraph_node`), call sites (`cgraph_edge`), variables (`varpool_node`), and symbol table entries (`symtab_node`), while using AutoFDO profile data to drive early inlining, indirect call speculation, and CFG profile annotation.
Drives the overall compilation and IPA pass pipeline (`cgraphunit.cc`), manages virtual and materialized function clones (`cgraphclones.cc`), localizes static symbols into COMDAT groups (`ipa-comdats.cc`), and implements interprocedural constant propagation and specialization (`ipa-cp.cc`, `ipa-cp.h`). It bridges front-end symbol finalization with GIMPLE lowering, early optimization, whole-program IPA analysis, and late RTL expansion.
Provides whole-program type inheritance analysis and devirtualization (`ipa-devirt.cc`), context-sensitive function size/time summaries (`ipa-fnsummary.cc`, `ipa-fnsummary.h`), front-end language data stripping (`ipa-free-lang-data.cc`), and GIMPLE semantic equality checking (`ipa-icf-gimple.cc`, `ipa-icf-gimple.h`). These passes prepare the IR for LTO streaming and supply cost models and equivalence predicates to inlining and identical code folding.
Implements Interprocedural Identical Code Folding (`ipa-icf.cc`, `ipa-icf.h`), the early and whole-program inliner (`ipa-inline.cc`, `ipa-inline-analysis.cc`, `ipa-inline-transform.cc`, `ipa-inline.h`), code-locality callchain cloning (`ipa-locality-cloning.cc`, `ipa-locality-cloning.h`), and the modref alias decision tree (`ipa-modref-tree.cc`, `ipa-modref-tree.h`). Together these passes merge duplicate functions/variables, inline call edges based on greedy badness heuristics, clone functions to co-locate hot callchains in LTO partitions, and summarize interprocedural memory loads, stores, and kills.
Implements the Link-Time Optimization (LTO) front end (`lto1`), callgraph and section streaming (`lto-cgraph.cc`, `lto-section-in.cc`, `lto-section-out.cc`, `lto-compress.cc`), symbol merging (`lto/lto-symtab.cc`), WPA callgraph partitioning (`lto/lto-partition.cc`), and LTRANS object file caching (`lto-ltrans-cache.cc`). It reads GIMPLE bytecode sections from object files, unifies declarations and prevailing symbols using linker resolution data, partitions the whole-program graph into balanced LTRANS units, and streams out partition files.
Contains the GIMPLE/tree bytecode serializer and deserializer (`lto-streamer-in.cc`, `lto-streamer-out.cc`, `lto-streamer.cc`, `lto-streamer.h`), the `lto-wrapper` driver utility (`lto-wrapper.cc`), and static branch prediction (`predict.cc`). It handles pickling and unpickling of CFG basic blocks, GIMPLE statements, and tree SCCs, orchestrates WPA and parallel LTRANS invocations from the linker plugin, and computes static branch probabilities and basic block frequencies using Ball-Larus and Wu-Larus heuristics.
Provides the symbol table core (`symtab.cc`, `varpool.cc`, `symtab-clones.cc`, `symtab-thunks.cc`), profile count and probability fixed-point arithmetic (`profile-count.cc`, `profile-count.h`), gcov branch/condition coverage instrumentation and feedback reading (`profile.cc`, `profile.h`), and value profiling histograms and transformations (`value-prof.cc`, `value-prof.h`). It underpins all profile-guided and interprocedural optimizations by maintaining symbol resolution, alias/thunk chains, execution counts, and indirect-call/value histograms.

## Architecture & Data Flow

- Once `cgraph_node::get_edge` lazily allocates `call_site_hash` (after traversing more than 100 edges in `callees` and `indirect_calls`), `cgraph_node::get_edge` only consults `call_site_hash`, so every subsequent edge addition, removal, or `call_stmt` update on a node with non-null `call_site_hash` must update `call_site_hash`. [F6]
- In `afdo_adjust_guessed_profile`, `bbs` and `stack` are pre-sized to `n_basic_blocks_for_fn (cfun)` and use `quick_push`, so `component` must be marked with `component_id` when a basic block is pushed onto `stack` rather than when it is popped. [F8]
- In `gcc/auto-profile.cc`, `gcc/cgraph.cc`, and `gcc/cgraphbuild.cc`, `#include "config.h"` must appear first, any `INCLUDE_*` selector macros (such as `INCLUDE_MAP` and `INCLUDE_SET`) must be defined before `#include "system.h"`, and C++ standard library or GCC headers (including `cgraph.h`, which tests `CHECKING_P`) must not precede `system.h`. [F10]
- `record_reference` must canonicalize `*tp` via `canonicalize_constructor_val (t, NULL)` and write back `*tp = t` when it changes before switching on `TREE_CODE (t)`, where bare `VAR_DECL` and `FUNCTION_DECL` trees are forbidden (`gcc_unreachable ()`). [F19]
- When `record_reference` encounters an `ADDR_EXPR` or `FDESC_EXPR` whose base `VAR_DECL` has `DECL_HAS_VALUE_EXPR_P (decl)`, it must replace the `decl` operand in-place with `unshare_expr (DECL_VALUE_EXPR (decl))` and recursively re-invoke `record_reference` instead of creating a `varpool_node` for `decl`. [F26]
- In `pass_build_cgraph_edges::execute`, local static declarations iterated via `FOR_EACH_LOCAL_DECL` must be checked for `!DECL_HAS_VALUE_EXPR_P (decl)` and `TREE_TYPE (decl) != error_mark_node` before calling `varpool_node::finalize_decl (decl)`. [F27]
- `cgraph_node::release_body` sets `DECL_INITIAL (decl) = error_mark_node` when `!used_as_abstract_origin`, so callers walking a function's block tree (such as `autofdo_source_profile::offline_unrealized_inlines` calling `walk_block`) must check `DECL_INITIAL (n->decl) != error_mark_node` first. [F28]
- In `autofdo::auto_profile`, functions with `DECL_SOURCE_LOCATION (node->decl) == BUILTINS_LOCATION` must be skipped before `autofdo::afdo_annotate_cfg` is called. [F31]
- When constructing or rebuilding callgraph edges in `pass_build_cgraph_edges::execute` and `cgraph_edge::rebuild_edges`, a `gcall *` statement with `gimple_call_fndecl (call_stmt) == NULL` must be checked for `gimple_call_internal_p (call_stmt)` before calling `node->create_indirect_edge`. [F32]
- In `autofdo::auto_profile`, `execute_fixup_cfg ()` (and `cleanup_tree_cfg ()` when `TODO_cleanup_cfg` is returned) must be invoked on each function after `push_cfun` and before `autofdo::afdo_annotate_cfg ()` so that stale virtual SSA `VDEF`s from newly const/pure callees are cleaned up. [F33]
- When `cgraph_edge::make_speculative` creates a speculative direct call edge `e2` on an indirect `cgraph_edge`, it must increment `indirect_info->num_speculative_call_targets`, subtract `e2->count` from the indirect edge's `count`, and create a matching `IPA_REF_ADDR` reference with the same `speculative_id` and `lto_stmt_uid`. [F34]
- In `cgraph_edge::resolve_speculation`, the removed edge `e2`'s `count` must be added back to the surviving `edge->count`, and if `edge->num_speculative_call_targets_p ()` is nonzero, `edge->speculative` must remain true until `edge->indirect_info->num_speculative_call_targets` decrements to zero. [F35]
- When `cgraph_edge::redirect_call_stmt_to_callee` expands a speculative direct edge `e` into a conditional GIMPLE call via `gimple_ic`, the probability passed to `gimple_ic` must be `e->count.probability_in (all)` where `all` is the sum of `indirect->count` and all remaining speculative direct target edges' counts. [F36]
- When `cgraph_edge::redirect_call_stmt_to_callee` removes the ` SSA_NAME` LHS of a call statement that has become `noreturn`, it must attach a fresh temporary register via `SET_SSA_NAME_VAR_OR_IDENTIFIER`, set `SSA_NAME_DEF_STMT (lhs)` to `gimple_build_nop ()`, and register `lhs` via `set_ssa_default_def`. [F37]
- In `cgraph_node::call_site_hash`, a call statement with speculative edges or callback edges must always map to the first direct speculative edge (never the indirect edge) or the callback-carrying edge (never a `callback` edge). [F39]
- In `cgraph_edge::rebuild_references`, speculative `ipa_ref` entries (`ref->speculative`) on the current `cgraph_node` must not be removed when clearing existing references before rescanning the function's GIMPLE statements. [F40]
- When `cgraph_node::make_local` transitions a `DECL_COMDAT` or `DECL_EXTERNAL` function node to local visibility, it must clear both the node's section (`node->set_section (NULL)`) and its COMDAT group (`node->set_comdat_group (NULL)`). [F42]
- In `set_const_flag_1`, a function whose `cgraph_node` does not bind to the current definition (`!node->binds_to_current_def_p ()`) or is called through a virtual thunk (`thunk_info::get (e->caller)->virtual_offset_p`) must not be marked `TREE_READONLY` (const) and must instead be downgraded to `DECL_PURE_P` (pure). [F43]
- In `cgraph_edge::maybe_hot_p`, a call edge whose caller has `optimize_size` enabled (`opt_for_fn (caller->decl, optimize_size)`) must never be considered hot (`return false`), regardless of its `profile_count` or caller `NODE_FREQUENCY_HOT` frequency. [F44]
- In `autofdo::afdo_annotate_cfg`, any basic block whose `bb->count` still does not satisfy `bb->count.ipa_p ()` after `afdo_calculate_branch_prob` must be set to `profile_count::zero ().afdo ()` for `ENTRY_BLOCK_PTR_FOR_FN (cfun)` or `profile_count::uninitialized ()` for other blocks, with `cfun->cfg->full_profile` set to `false`. [F45]
- In `cgraph_simd_clone` and `cgraph_simd_clone_arg`, `mask_mode` is `VOIDmode` when masks are passed as vectors of characteristic type, whereas when `arg_type == SIMD_CLONE_ARG_TYPE_MASK` and `mask_mode != VOIDmode`, `cgraph_simd_clone_arg::linear_step` stores the number of integer bitmask arguments rather than a step or argument index. [F48]
- In `enum cgraph_simd_clone_arg_type`, `SIMD_CLONE_ARG_TYPE_LINEAR_CONSTANT_STEP` and `SIMD_CLONE_ARG_TYPE_LINEAR_VARIABLE_STEP` must only be used for integer or pointer arguments passed by value, while the `SIMD_CLONE_ARG_TYPE_LINEAR_REF_*`, `UVAL_*`, and `VAL_*` variants are only for reference-type arguments or arguments passed by reference. [F49]
- Unlike `symtab_node::force_output`, `symtab_node::forced_by_abi` only marks a symbol as required by the ABI when externally visible and must be cleared (`node->forced_by_abi = false`) when `cgraph_node::make_local` promotes a `DECL_COMDAT` or `DECL_EXTERNAL` function to local linkage. [F50]
- When a callback-carrying `cgraph_edge` (`e->has_callback`) has its callee redirected to `BUILT_IN_UNREACHABLE`, all of its callback edges (`first_callback_edge` / `next_callback_edge`) must also be redirected to `BUILT_IN_UNREACHABLE`, as enforced by `cgraph_node::verify_node`. [F54]
- When matching sibling speculative or callback `cgraph_edge`s or `ipa_ref`s for the same call site (or iterating via `first_speculative_call_target` and `next_speculative_call_target`, as in `cgraph_edge::get_next_speculative_id`), both `call_stmt` (or `stmt`) and `lto_stmt_uid` must match. [F55]
- When `cgraph_edge::redirect_callee` redirects a callback edge (`callback` is true) from `old_callee` to `n`, it must replace the `IPA_REF_ADDR` reference, call `n->mark_address_taken ()`, and only clear `old_callee->address_taken` when `!old_callee->iterate_referring (0, old_ref)` (not `!old_callee->referred_to_p ()`). [F57]
- In `ipa-cp.cc`, `known_contexts` vectors (`ipa_node_params::known_contexts` and `ipa_call_arg_values::m_known_contexts`) remain empty (`vNULL`) when no useful polymorphic contexts exist, so callers must verify `known_contexts.length () > (unsigned) index` before indexing `known_contexts[index]`. [F58]
- In `propagate_constants_across_call`, when `call_passes_through_thunk (cs)` is true, parameter 0's lattices must be marked with `set_all_contains_variable` and the jump-function propagation loop must start at index `i = 1`, followed by a trailing loop from `i` to `parms_count` marking unpassed parameters as variable. [F59]
- Any `vec<ipa_argagg_value>` backing an `ipa_argagg_value_list` (such as `avals.m_known_aggs` in `estimate_local_effects`) must be maintained in strictly ascending order of `(index, unit_offset)` with no duplicate `(index, unit_offset)` pairs. [F60]
- In `create_specialized_node`, when building `new_params` from `old_adjustments->m_adj_params`, each kept adjustment's `prev_clone_index` must be set to its index `i` in `old_adjustments->m_adj_params`, whereas `known_csts` and `ipa_is_param_used` must be indexed by `old_adj->base_index`. [F61]
- In `expand_all_functions`, filtering `order` (of length `order_pos`) in-place into `tp_first_run_order` and `order` uses separate write cursors `tp_first_run_order_pos` and `new_order_pos`, and all subsequent passes over `order` must bound their index by `new_order_pos` rather than `order_pos`. [F62]
- In `ipcp_lattice<valtype>::add_value`, `values_count` is only bounded against `param_ipa_cp_value_list_size` when `same_lat_gen_level` is zero; values added with non-zero `same_lat_gen_level` bypass the `param_ipa_cp_value_list_size` check and still increment `values_count`. [F65]
- `propagate_vals_across_arith_jfunc` must never use a value where `src_val->self_recursion_generated_p ()` is true as a propagation source, neither when collecting `val_seeds` for self-recursive SCC edges nor when propagating across non-SCC or `NOP_EXPR` edges. [F66]
- During SCC propagation, `propagate_vals_across_arith_jfunc` (when `opcode != NOP_EXPR` and `src_lat != dest_lat`) and `propagate_vals_across_ancestor` must not generate new values across an edge where `ipa_edge_within_scc (cs)` is true, and must instead call `dest_lat->set_contains_variable ()`. [F67]
- In `ipcp_lattice<valtype>::add_value`, when `values_equal_for_ipcp_p (val->value, newval)` matches an existing value on an intra-SCC edge (`ipa_edge_within_scc (cs)`), `val->add_source` must not be called if `val->sources` already contains an entry with the same `cs` and `src_val`. [F68]
- When `merge_agg_lats_step` returns false without setting `dest_plats->aggs_bottom` (because `dest_plats->aggs_count == max_agg_items`), callers `merge_aggregate_lattices` and `propagate_aggs_across_jump_function` must continue iterating remaining items and call `set_chain_of_aglats_contains_variable` on any trailing destination aggregate lattices. [F69]
- In `value_topo_info<valtype>::propagate_effects`, `src->val->prop_size_cost` and `val->prop_size_cost` must be capped below `INT_MAX` using `HOST_WIDE_INT` addition (`size + src->val->prop_size_cost < INT_MAX`), and if `size >= INT_MAX`, both `val->prop_time_benefit` and `val->prop_size_cost` must be reset to `0`. [F70]
- When evaluating or propagating an `ipa_polymorphic_call_context` across an `IPA_JF_ANCESTOR` or `IPA_JF_PASS_THROUGH` jump function in `ipa_context_from_jfunc` and `propagate_context_across_jump_function`, `offset_by` and `possible_dynamic_type_change(cs->in_polymorphic_cdtor)` must be applied to the caller context before `combine_with`. [F77]
- `ipa_get_jf_arith_result` must verify `is_gimple_ip_invariant` on both the input `tree` (when `opcode != NOP_EXPR`) and the folded result of `fold_unary` or `fold_binary`, returning `NULL_TREE` if either is not an interprocedural GIMPLE invariant. [F80]
- Before evaluating an `IPA_JF_LOAD_AGG` aggregate jump-function item on a source constant, `ipa_agg_value_from_jfunc` and `get_val_across_arith_op` must verify `useless_type_conversion_p(load_type, TREE_TYPE(value))` and reject the value if the conversion is not useless. [F81]
- In `cgraph_node::analyze`, when analyzing a thunk node, `t->analyze()` must be called on `info->alias` and, if `t->alias` is true, on `t->get_alias_target()` as well before calling `expand_thunk(this, false, false)`. [F83]
- In `cgraph_node::finalize_function` and `varpool_node::finalize_decl`, `node->definition = true` must be set before calling `notice_global_symbol (decl)`. [F87]
- In `cgraph_node::analyze`, `gimplify_function_tree (decl)` must only be called when `!gimple_has_body_p (decl)` because lowering an outer function gimplifies its nested functions before `cgraph_node::analyze` runs on those nested functions. [F88]
- In `cgraph_node::expand`, when `DECL_STRUCT_FUNCTION (decl)` is null after `gimple_set_body (decl, NULL)` and `DECL_INITIAL (decl)` is nonzero, `DECL_INITIAL (decl)` must be set to `error_mark_node` rather than `NULL_TREE`. [F90]
