# omp-sanitizer

This unit implements memory error sanitization passes and GIMPLE/RTL instrumentation for ASan, HWASan, and AArch64 MTE (`gcc/asan.cc`, `gcc/asan.h`), alongside shared OpenMP and OpenACC middle-end/front-end helpers for canonical loop extraction, loop transformations (`tile`/`unroll`), context selector and variant resolution, clause handling, address tokenization, and builtin definitions (`gcc/omp-general.cc`, `gcc/omp-general.h`, `gcc/omp-api.h`, `gcc/omp-builtins.def`).

## Architecture & Data Flow

- `transform_statements` records `saved_last_basic_block = last_basic_block_for_fn (cfun)` before iterating, skipping blocks with `bb->index >= saved_last_basic_block` and walking `single_pred (prev_bb)` until `< saved_last_basic_block`. It must clear `asan_mem_ref_ht` via `empty_mem_ref_hash_table ()` across extended basic block boundaries and after any uninstrumented call where `!nonfreeing_call_p (s)` or `asan_mark_p (s, ASAN_MARK_POISON)` holds, freeing it via `free_mem_ref_resources ()` at the end. [F6, F37]
- `update_mem_ref_hash_table` must only replace a slot in `asan_mem_ref_ht` when `*slot == NULL || (*slot)->access_size < access_size` so `has_mem_ref_been_instrumented` retains the largest access size. In `has_stmt_been_instrumented_p`, a `gimple_assign_single_p` that is both a store (`r_is_store`) and a load (`gimple_assign_load_p (stmt)`) is instrumented only if `has_mem_ref_been_instrumented` holds for both the destination and `gimple_assign_rhs1 (stmt)`. [F10, F55]
- `asan_redzone_buffer::emit_redzone_byte` requires `offset` to be a multiple of `ASAN_SHADOW_GRANULARITY` and `>= m_prev_offset`. On a non-contiguous jump, if `m_shadow_bytes` is non-empty and `offset < m_prev_offset + ASAN_SHADOW_GRANULARITY * RZ_BUFFER_SIZE`, zero-pad the gap in `m_shadow_bytes` without flushing; otherwise flush and back `offset` down by `(offset - m_prev_offset) % ASAN_RED_ZONE_SIZE` with zero-padding so `flush_redzone_payload` stays `ASAN_RED_ZONE_SIZE`-aligned. [F4, F56]
- On `STRICT_ALIGNMENT` targets, `asan_emit_stack_protection` must align `base` down to `(GET_MODE_ALIGNMENT (SImode) / BITS_PER_UNIT) << ASAN_SHADOW_SHIFT` and set `set_mem_align (shadow_mem, GET_MODE_ALIGNMENT (SImode))`. In `build_check_stmt` and `asan_expand_mark_ifn`, potentially misaligned multi-byte shadow accesses (8-byte-aligned 16-byte scalar accesses, or 2-/4-byte shadow stores with `shadow_align < size`) must only be emitted when `!STRICT_ALIGNMENT`. [F46, F53]
- In `asan_expand_mark_ifn`, before asserting `TREE_CODE (decl) == VAR_DECL` on the `ADDR_EXPR` operand of `IFN_ASAN_MARK`, unwrap any `COMPONENT_REF` whose base satisfies `DECL_NONLOCAL_FRAME (TREE_OPERAND (decl, 0))`. Expanding `ASAN_MARK_POISON` for ASan must insert `decl` into `asan_handled_variables` (for epilogue unpoisoning), and inline `asan_store_shadow_bytes` emission must be gated by `tree_fits_uhwi_p (len) && tree_to_uhwi (len) <= param_use_after_scope_direct_emission_threshold`. [F7, F25, F26]
- In `asan_finish_file`, the global and string-constant filtering predicates used to count `gcount` (`count_string_csts`) must exactly match those used to populate `v` (`add_string_csts` and `asan_add_global`). In `asan_add_global`, when `in_lto_p` is true, `__module_name` must come from `IDENTIFIER_POINTER (DECL_NAME (get_ultimate_context (decl)))` if non-null or `aux_base_name` otherwise, never `main_input_filename`. [F9, F54]
- In `asan_protect_global`, when `ignore_decl_rtl_set_p` is true, `DECL_RTL (decl)` must only be inspected if `DECL_RTL_SET_P (decl)` is already true. Both `asan_protect_global` and `instrument_derefs` (on the inner object type from `get_inner_reference`) must check `ADDR_SPACE_GENERIC_P (TYPE_ADDR_SPACE (...))` and skip non-generic address spaces. [F29, F38]
- `asan_protect_stack_decl` and `instrument_derefs` must treat addressable local variables (including `DECL_ARTIFICIAL`) as subject to stack protection and access instrumentation whenever `asan_sanitize_use_after_scope ()` is enabled. For non-builtin, non-internal calls whose return type satisfies `aggregate_value_p`, `maybe_instrument_call` and `has_stmt_been_instrumented_p` must not treat the call LHS as a store, and `instrument_derefs` must not skip `RESULT_DECL` inner references when `aggregate_value_p (inner, current_function_decl)` holds. [F31, F39]
- In `asan_emit_stack_protection`, `asan_emit_allocas_unpoison`, `hwasan_emit_prologue`, and `hwasan_emit_untag_frame`, convert between `Pmode` addresses and `ptr_mode` runtime libcall values via `convert_memory_address`. In `hwasan_emit_untag_frame`, order `top_rtx` and `bot_rtx` by `FRAME_GROWS_DOWNWARD` before `simplify_gen_binary (MINUS, ptr_mode, top_rtx, bot_rtx)`, and `force_reg` non-`CONST_INT_P` `size_rtx` into `ptr_mode` before `targetm.gen_tag_memory`. [F48, F51]
- Every stack variable range in `hwasan_tagged_stack_vars` (`nearest_offset`, `farthest_offset`), dynamic `alloca` size in `handle_builtin_alloca`, and `CFN_HWASAN_MARK` length in `asan_expand_mark_ifn` must be a multiple of `HWASAN_TAG_GRANULE_SIZE`. `hwasan_emit_prologue` must call `hwasan_tagged_stack_vars.truncate (0)` before returning whenever non-empty, because `hwasan_record_frame_init` asserts `hwasan_tagged_stack_vars.is_empty ()`. [F18, F50]
- `build_check_stmt` must call `unshare_expr` on `base` and (when non-null) `len` before gimplifying them into SSA names for `IFN_ASAN_CHECK` or `IFN_HWASAN_CHECK`. In `report_error_func`, when `size_in_bytes` is `-1`, not a power of two (`exact_log2 (size_in_bytes) == -1`), or `>= 32` (`size_log2 >= 5`), set `*nargs = 2` and select `BUILT_IN_ASAN_REPORT_{LOAD,STORE}_N{,_NOABORT}`. [F27, F40]
- When `stmt_can_throw_internal (cfun, call)` is true in `handle_builtin_alloca`, replace the throwing `call` in place via `gsi_replace` with `BUILT_IN_ALLOCA_WITH_ALIGN` and insert all post-allocation statements on `find_fallthru_edge (gsi_bb (*iter)->succs)`. When `asan_expand_poison_ifn` instruments a `gphi` use of `poisoned_var`, skip `EDGE_ABNORMAL` incoming edges, insert copied report calls on remaining matching edges with `*need_commit_edge_insert = true`, and turn `poisoned_var` into a default SSA definition backed by `gimple_build_nop ()`. [F35, F36]
- `omp_adjust_for_condition` converts `LE_EXPR` to `LT_EXPR` with `*n2` incremented by `1` (or `TYPE_SIZE_UNIT` for pointers) and `GE_EXPR` to `GT_EXPR` with `*n2` decremented by `1` (or negated `ptrofftype` `TYPE_SIZE_UNIT` for pointers). Similarly, in `omp_apply_tile`, clamping `end` against an inclusive outer bound `ub` (`LE_EXPR`/`GE_EXPR`) must offset `ub` by `+1` or `-1` before building `MIN_EXPR`/`MAX_EXPR`. [F58, F59]
- When `omp_maybe_apply_loop_xforms` hoists canonical loops from `inner_for_stmt` into a `NULL_TREE` slot at index `i` in `for_stmt`, index `inner_for_stmt` vectors by 0-based `j` (clearing moved entries at `j` to `NULL_TREE`) and `for_stmt` vectors by `i + j`. In `omp_extract_for_data`, when `fd->ordered > fd->collapse`, the loop runs to `fd->ordered` to populate `fd->loops[i]` and `iter_type`, but must skip collapsed iteration count computation once `i >= fd->collapse`. [F60, F61]
- During late variant resolution (`PROP_gimple_any` set on `cfun` and `cfun->after_inlining`), `omp_context_selector_matches` must resolve every trait to `0` or `1` and never `-1` (which `omp_get_dynamic_candidates` asserts against). Earlier (after parsing), if `targetm.omp.device_kind_arch_isa (omp_device_isa, isa)` returns `-1`, `OMP_TRAIT_DEVICE_ISA` must defer (`ret = -1`) when `targetm.simd_clone.compute_vecsize_and_simdlen` is set, inlining has not run, and `current_function_decl` has `"omp declare simd"`. When `omp_dynamic_cond` emits `OMP_TARGET_DEVICE_MATCHES` while `PROP_gimple_any` is set, set `cgraph_node::get (cfun->decl)->has_omp_variant_constructs = 1`. [F89, F90, F95]
- An `"omp declare variant base"` attribute stores a `TREE_LIST` in `TREE_VALUE (attr)` with the variant `FUNCTION_DECL` in `TREE_PURPOSE` and the context selector in `TREE_VALUE`; readers must access `TREE_PURPOSE (TREE_VALUE (attr))` and check `TREE_CODE (fndecl) == FUNCTION_DECL`. Inspect selector properties via `OMP_TS_PROPERTIES (ts)` rather than `TREE_VALUE (ts)` (which starts with an optional `OMP_TS_SCORE_NODE`), and unshare non-constant expressions and properties copied out of selectors (`omp_dynamic_cond`, `omp_mark_declare_variant`, `omp_combine_trait_sets`, `omp_complete_construct_context`) via `unshare_expr` or `copy_node`. [F77, F78, F82]

## Object Lifetimes

- `set_sanitized_sections` must `free` every `xstrndup`-allocated `char *` in `sanitized_sections` before `sanitized_sections.truncate (0)`. Reset global `hash_set<tree> *` pointers `asan_handled_variables` and `asan_used_labels` to `NULL` immediately after `delete` in `asan_emit_stack_protection` and `hwasan_record_frame_init`. In `asan_memfn_rtl`, save and restore `DECL_NAME`, `DECL_ASSEMBLER_NAME_RAW`, and `DECL_RTL` on the shared `fndecl` around evaluating `DECL_RTL (fndecl)`. [F17, F19, F44]
- In `omp_get_dynamic_candidates`, any failure path after pushing candidates to `auto_vec<struct omp_variant> variants` must call `variants.truncate (0)` before returning `variants.copy ()`. `score_wide_int` in `struct GTY(()) omp_variant` must remain `fixed_wide_int_storage<1024>` (not `widest_int` or `wide_int`) for GC-compatible, trivially copyable, target-independent storage. [F65, F66]

## API Contracts

- `asan_emit_stack_protection` requires `offsets` to hold `length` even-numbered gap boundaries in descending order (end then start offset per redzone gap) and `decls` to hold `length / 2 - 1` elements, indexing `decls[l / 2 - 1]` for `[offsets[l], offsets[l - 1]]` and `decls[l / 2 - 2]` when `l > 2` in the epilogue loop. [F3]
- `create_cond_insert_point` splits the basic block at `*iter`, updates `*iter` in place to `gsi_start_bb (*fallthrough_block)`, and returns `gsi_last_bb` of the condition block; callers in `transform_statements` must not call `gsi_next` after `maybe_instrument_assignment` or `maybe_instrument_call` returns true. In `build_check_stmt`, `maybe_create_ssa_name`, `maybe_cast_to_ptrmode`, `maybe_instrument_call`, and `asan_expand_mark_ifn`, insertions before an iterator that may point to a `returns_twice` call must call `gsi_safe_insert_before` directly on the caller's `gimple_stmt_iterator *iter`, never `gsi_insert_before` or a local iterator copy. [F5, F33]
- Per-function sanitizer checks must call `sanitize_flags_p (flag, fn)` rather than testing `flag_sanitize` directly so `"no_sanitize"` attributes are respected. Entry points that emit sanitizer builtins (`asan_instrument`, `asan_finish_file`, `asan_dynamic_init_call`, `asan_emit_stack_protection`, `hwasan_finish_file`) must ensure `initialize_sanitizer_builtins ()` (or `asan_init_shadow_ptr_types ()`) has been called before `builtin_decl_implicit`, and `BT_PTRMODE` argument types in `initialize_sanitizer_builtins` and `asan_expand_poison_ifn` must use `lang_hooks.types.type_for_mode (ptr_mode, 0)`, not `pointer_sized_int_node`. [F22, F41, F42]
- `oacc_verify_routine_clauses` must normalize `*clauses` to contain exactly one parallelism-level clause (`GANG`, `WORKER`, `VECTOR`, or `SEQ`), unlinking duplicates/conflicts and prepending an implicit `OMP_CLAUSE_SEQ` if none was present. When `omp_remove_duplicate_maps` is called from the gimplifier (`!first`), it must only remove duplicate `OMP_CLAUSE_MAP` clauses with `(OMP_CLAUSE_MAP_KIND (c1) & ~0b11111) == 0`. [F76, F85]

## Error Handling

- `sanitize_flags_p` and `sanitize_coverage_p` in `gcc/asan.h` must check `fn != NULL_TREE` before accessing `DECL_ATTRIBUTES (fn)`. `create_odr_indicator` must check `decl_name != NULL_TREE` before `IDENTIFIER_POINTER (decl_name)` (returning `build_int_cst (uptr, 0)` when unnamed). `asan_emit_stack_protection` must check `if (seen_error ()) return NULL;` at entry before frame-offset assertions. [F21, F23, F28]

## External Contracts

- In `asan_emit_stack_protection`, emitting `__asan_stack_malloc_N` requires `asan_frame_size > 32 && asan_frame_size <= 65536`, `alignb <= (use_after_return_class < 6 ? (64U << use_after_return_class) : 4096U)`, and `use_after_return_class <= 10` after adding `base_align_bias` (otherwise resetting `use_after_return_class = -1`). [F8]
- `hwasan_emit_prologue` and `handle_builtin_alloca` must pass an untagged base pointer (`cur.untagged_base` or `untagged_addr`) as the address argument to `__hwasan_tag_memory` (`BUILT_IN_HWASAN_TAG_MEM`) while extracting the tag from `cur.tagged_base`. When `!param_hwasan_random_frame_tag`, `hwasan_record_frame_init` and `hwasan_increment_frame_tag` must never leave `hwasan_frame_tag_offset` at `0` (nor `1` when `sanitize_flags_p (SANITIZE_KERNEL_HWADDRESS)`) after wrapping modulo `1 << HWASAN_TAG_SIZE`. [F49, F52]

## Known Pitfalls

- In `maybe_instrument_call`, noreturn instrumentation must return early without emitting `BUILT_IN_ASAN_HANDLE_NO_RETURN` for `IFN_ABNORMAL_DISPATCHER`, `BUILT_IN_UNREACHABLE`, `BUILT_IN_UNREACHABLE_TRAP`, `BUILT_IN_TRAP`, and `BUILT_IN_ASAN_REPORT_*`. [F34]
- In `omp_adjust_for_condition` (`*cond_code == NE_EXPR`), handle `BITINT_TYPE` alongside `INTEGER_TYPE` rather than falling into the pointer branch (`TYPE_SIZE_UNIT (TREE_TYPE (TREE_TYPE (v)))`). In `omp_extract_for_data`, when widening `iter_type` and either `iter_type` or `TREE_TYPE (loop->v)` is `BITINT_TYPE`, use `build_bitint_type` instead of `build_nonstandard_integer_type`. For downward loops (`GT_EXPR`) in unsigned types in `omp_extract_for_data` and `omp_loop_number_of_iterations`, negate both dividend and negative step before `TRUNC_DIV_EXPR`/`CEIL_DIV_EXPR`. [F86, F87, F88]
- In `omp_context_selector_matches` and `omp_target_device_matches_on_host`, `#ifdef/#ifndef ACCEL_COMPILER` blocks inside `if`/`else` chains must be braced or provide a complete statement in both branches. Before checking selector expressions like `device_num` in `omp_device_num_check` for integer constants or `CALL_EXPR`, unwrap any enclosing C++ `CLEANUP_POINT_EXPR`. [F63, F79]
