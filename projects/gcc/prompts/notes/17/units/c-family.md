# c-family

The `c-family` unit implements the C front end (`gcc/c/`) and shared C-family infrastructure (`gcc/c-family/`) for C, C++, Objective-C, and Objective-C++, covering lexical analysis, C/OpenMP/GIMPLE parsing, declaration and scope management, type checking, initializer folding, attribute handling, diagnostics, UBSan instrumentation, and GENERIC/GIMPLE lowering.

## Architecture & Data Flow

- When building a cv-qualified `ARRAY_TYPE` in `grokdeclarator`, `composite_type_internal`, `fix_string_type`, or `complete_array_type`, strip qualifiers from the element type with `c_build_qualified_type (..., TYPE_UNQUALIFIED)` before building the unqualified array `TYPE_MAIN_VARIANT`, then re-apply qualifiers afterward. Strip outer arrays via `strip_array_types` and `TYPE_MAIN_VARIANT` before checking `C_TYPE_FIELDS_*`, `TYPE_QUALS`, or `C_TYPE_INCOMPLETE_VARS` in `pushdecl`, `finish_struct`, `grokdeclarator`, or `diagnose_uninitialized_cst_member`. [F22, F23, F28, F179, F298]
- In `finish_struct`, copy `TYPE_FIELDS`, `TYPE_LANG_SPECIFIC`, `TYPE_TRANSPARENT_AGGR` (cleared first if `UNION_TYPE` has no fields or `TYPE_MODE (t) != DECL_MODE (TYPE_FIELDS (t))`), `TYPE_TYPELESS_STORAGE`, `TYPE_INCLUDES_FLEXARRAY`, and `C_TYPE_*` flags to all `TYPE_NEXT_VARIANT` nodes before `comptypes_same_p` or `c_update_type_canonical`. In C23 (`flag_isoc23 && !C_TYPE_VARIABLE_SIZE (t)`), set `TYPE_CANONICAL (t)` to `TYPE_CANONICAL (*e)` if in `c_struct_htab` or `c_type_canonical (t)` otherwise, then call `c_update_type_canonical (t)`. [F18, F35, F65]
- In `finish_struct`, bit-fields keep their declared type during `layout_type (t)` (`DECL_INITIAL`/`DECL_SIZE` hold width), and only afterward have `DECL_INITIAL` cleared, `TREE_TYPE` narrowed (to `build_bitint_type` if `BITINT_TYPE_P` and `width >= ((TYPE_UNSIGNED || flag_isoc2y) ? 1 : 2)` or `c_build_bitfield_integer_type`), and `SET_DECL_MODE` updated. `tagged_types_tu_compatible_p`, `composite_type_internal`, and `.`/`->` in `c_parser_postfix_expression_after_primary` must use `DECL_BIT_FIELD_TYPE` when `DECL_C_BIT_FIELD` is set. [F45, F53, F64, F102, F169]
- Test variably-modified types via `c_type_variably_modified_p` rather than reading `C_TYPE_VARIABLY_MODIFIED` directly, because derived types with `TYPE_STRUCTURAL_EQUALITY_P` set it lazily, whereas `!TYPE_STRUCTURAL_EQUALITY_P` requires `C_TYPE_VARIABLY_MODIFIED` to match `TREE_TYPE`. When `finish_struct` completes a variably-modified struct/union, it must call `c_update_variably_modified (t)` and `add_decl_expr`. [F34, F139, F142]
- When `pushdecl` checks an external-linkage decl against an `external_scope` binding `b_ext`, temporarily set `TREE_TYPE (b_ext->decl) = b_ext->u.type` before `duplicate_decls`, save the merged composite type into `b_ext->u.type`, and reset `TREE_TYPE (b_ext->decl)` to the visible composite type. When `pop_scope` or `temp_pop_parm_decls` unlinks `b` with `b->shadowed && b->shadowed->u.type`, restore `TREE_TYPE (b->shadowed->decl) = b->shadowed->u.type`. [F29, F41]
- Whenever an incomplete `ARRAY_TYPE` is completed via `complete_array_type` (`finish_decl`, `build_compound_literal`), update `TREE_TYPE (DECL_INITIAL (decl))` and call `relayout_decl (decl)`. In `complete_array_type`, build `main_type` with `build_distinct_type_copy (TYPE_MAIN_VARIANT (type))`, build `TYPE_DOMAIN` with `build_range_type` (so `{}` gets `[0, -1]` in `ssizetype`), advance `curindex` by `RAW_DATA_LENGTH - 1` for `RAW_DATA_CST` at `!cnt` or with `ce->index`, and set `*ptype = error_mark_node` on size overflow. [F36, F268, F310, F311]
- Before folding or saving an expression for assignment, initialization, return, or omitted-middle ternary (`build_modify_expr`, `build_atomic_assign`, `digest_init`, `output_init_element`, `process_init_element`, `c_finish_return`, `c_parser_conditional_expression`), strip outer `EXCESS_PRECISION_EXPR` before `c_fully_fold` or `save_expr` and re-wrap with the semantic type afterward. In `build_unary_op`, any operator changing the semantic result type (`TRUTH_NOT_EXPR`, `REALPART_EXPR`, `IMAGPART_EXPR`) must clear or update `eptype` before `return_build_unary_op`. [F122, F201, F203]
- When `common_handle_aligned_attribute` or `handle_btf_type_tag_attribute` modifies a `TYPE_DECL` without `ATTR_FLAG_TYPE_IN_PLACE` and `!DECL_ORIGINAL_TYPE`, or when `set_underlying_type` processes a non-builtin/array `TYPE_DECL`, save `TREE_TYPE` in `DECL_ORIGINAL_TYPE`, clone via `build_variant_type_copy`, and set `TYPE_NAME` to the `TYPE_DECL`. Out-of-place `handle_scalar_storage_order_attribute` (`reverse` true in C) and `handle_transparent_union_attribute` must instead call `build_duplicate_type` so casts are not stripped. [F233, F234, F263, F265, F291]
- In `ubsan_walk_array_refs_r`, `BIND_EXPR` must set `*walk_subtrees = 0` and only walk `DECL_INITIAL`/`DECL_SIZE`/`DECL_SIZE_UNIT` of non-`TREE_STATIC` `BIND_EXPR_VARS`; `MODIFY_EXPR` must set `*walk_subtrees = 0` and walk RHS (`op1`) before LHS (`op0`); and instrumenting `ADDR_EXPR` of `ARRAY_REF` or `INDIRECT_REF` of `.ACCESS_WITH_SIZE` `POINTER_PLUS_EXPR` must insert `TREE_OPERAND (*tp, 0)` into `pset`, set `*walk_subtrees = 0`, and manually walk its operands. [F374, F375, F406]
-In `build_binary_op`, apply `default_conversion` only when `VECTOR_TYPE_P (TREE_TYPE (op0)) == VECTOR_TYPE_P (TREE_TYPE (op1))`; lower GNU vector comparisons via `build_vec_cmp` into a `VEC_COND_EXPR` with `truth_type_for` mask and `-1`/`0` signed integer vector arms; and for vector shifts (`code0 == VECTOR_TYPE`), check constant shift counts against `TYPE_PRECISION (TREE_TYPE (type0))` without setting `short_shift`. `shorten_binary_op` must return `result_type` immediately on vector types. [F191, F193, F194, F320]

## Object Lifetimes

- When `merge_decls` copies `FUNCTION_DECL` or `VAR_DECL` fields from `newdecl` to `olddecl` via `memcpy`, save and restore `olddecl->decl_with_vis.symtab_node` and call `set_decl_section_name (olddecl, newdecl)` if `DECL_SECTION_NAME (newdecl)` is non-null. Before `duplicate_decls` calls `ggc_free (newdecl)`, clear `DECL_STRUCT_FUNCTION (newdecl)` on a `FUNCTION_DECL` and call `snode->remove ()` on any `symtab_node::get (newdecl)`. [F49, F50]
- Every caller of `c_parser_expr_list` must release the returned `vec<tree, va_gc> *` (and `*p_orig_types`) with `release_tree_vector`; `pop_scope` must call `release_tree_vector (b->u.label->decls_in_scope)` before unchaining `b->u.label`. `make_tree_vector` must always return a non-null vector (`>= 4` slots), and `release_tree_vector` must `vec_free` any vector with `allocated () >= 16` instead of caching it in `tree_vector_cache`. [F13, F91, F278, F282]
- Parser AST structs (`c_declspecs`, `c_declarator`, `c_arg_info`, `c_type_name`, `c_parm`, `maybe_used_decl`) are allocated on `parser_obstack` and bulk-freed via `obstack_free` without running destructors, so they must never contain `auto_vec` or RAII members (`c_declspecs::gimple_or_rtl_pass` must be explicitly `free`d on error paths). Conversely, local/member vectors in functions with early returns in `c-parser.cc`, `gimple-parser.cc`, `c-attribs.cc`, `c-ubsan.cc`, and `c-warn.cc` (`c_struct_parse_info`, `gimple_parser`) must use `auto_vec` or be `.release ()`d on every exit path. [F15, F92, F93, F135, F136, F225, F428]
- Clean up state on all normal and error exits: `c_start_switch`/`c_finish_switch` (`splay_tree_delete`, `c_release_switch_bindings`, `XDELETE`), `start_init`/`finish_init` (drain `constructor_stack`, `XDELETE (spelling_base)`, restore and `XDELETE` `initializer_stack`), `c_parser_braced_init` (`pop_init_level` and `obstack_free (&braced_init_obstack, NULL)`), `lex_string` (`obstack_free` on `str_ob` and `loc_ob` iff `concats > 0`), `verify_sequence_points` (clear `warned_ids`/`save_expr_cache` and `obstack_free (&tlist_obstack, tlist_firstobj)`), and `bitmap_obstack_initialize (NULL)`/`bitmap_obstack_release (NULL)` in `c_finish_omp_clauses`, `dump_ada_specs`, and `c_parser_parse_gimple_body`. [F16, F96, F161, F162, F163, F224, F287, F364]
- Callers must `free` heap buffers returned by `to_ada_name`, `get_ada_package`, `fname_as_string`, `get_format_for_type`, `get_corrected_substring`, and `cpp_interpret_string*` (`cstr.text`/`istr.text` in `cb_ident` and `lex_string`). Conversely, `expr_to_str` (`c-warn.cc`) returns an uncopied pointer into the caller's `pretty_printer`, and `gimple_bind_expr_stack ()` in `add_block_to_enclosing` returns a non-owning `vec` handle on which `.release ()` must never be called. [F226, F285, F363, F365, F367, F431]

## API Contracts

- `c_update_type_canonical` requires an unqualified main-variant type `t` (`TYPE_MAIN_VARIANT (t) == t && !TYPE_QUALS (t)`), must splice any variant `c` relocated by `c_build_qualified_type` back before `x` so no `TYPE_NEXT_VARIANT` node is skipped, and must pass `TYPE_MODE (p)` to `c_build_pointer_type_for_mode` when updating `TYPE_POINTER_TO (x)`. `initialize_elementwise_p` also requires `TYPE_MAIN_VARIANT (type) == type`, and `user_facing_original_type_p` requires `typedef_variant_p (type)`. [F20, F63, F177, F289, F290]
- `c_wrap_maybe_const` must never be called when `c_dialect_cxx ()` is true and must call `STRIP_TYPE_NOPS (expr)` before building `C_MAYBE_CONST_EXPR`. When calling `build_binary_op` in C on already-folded operands whose result will not be passed to `c_fully_fold` again, temporarily set `in_late_binary_op = true`. [F292, F293, F294]
- Callers of `digest_init` (`store_init_value`, `output_init_element`) must compute `null_pointer_constant_p` and `int_const_expr` before calling `c_fully_fold`. In `output_init_element`, when `require_constexpr_value && npc` holds on a `POINTER_TYPE`, do not call `digest_init` on the inner element, and in `pop_init_level` use `build_zero_cst (ptr_type_node)` for empty `{}` pointer initializers. [F173, F174]
- Checks for boolean types in C must use `C_BOOLEAN_TYPE_P (type)` rather than `TREE_CODE (type) == BOOLEAN_TYPE` so C23 fixed-underlying-type boolean enums and `hardbool` attribute enums (`c_hardbool_type_attr`) are included. For unscoped enums without `ENUM_FIXED_UNDERLYING_TYPE_P`, `ENUM_UNDERLYING_TYPE` is not set until `finish_enum` completes. [F140, F299]

## Error Handling

- Before calling `tree_to_uhwi` or building types: in `declspecs_add_type` (`RID_BITINT`) and `interpret_integer` (`CPP_N_BITINT`), verify positive/unsigned precision `<= WIDE_INT_MAX_PRECISION - 1` (and `prec + shift <= bitint_maxwidth` before `wi::lshift`) and `targetm.c.bitint_type_info`; in `check_bitfield_type_and_width`, clamp non-negative `INTEGER_CST` `*width` to `TYPE_PRECISION (*type)` via `compare_tree_int`; in `grokdeclarator`, check `int_fits_type_p (size, index_type)` and `valid_array_size_p`; and in `type_valid_for_vector_size`, verify `vecsize <= max_object_size ()` and power-of-two `nunits < INT_MAX`. [F5, F6, F7, F67, F221, F264, F355, F398]
- `c_parser_string_literal` and `lex_string` must never produce `error_mark_node` on failed string interpretation; they must return a NUL-terminated empty `STRING_CST` passed through `fix_string_type`. In `c_parser_omp_loop_nest`, an invalid comparison operator in the loop condition must set `cond = build1 (NOP_EXPR, boolean_type_node, error_mark_node)`. When setting a `c_expr` to error, call `expr.set_error ()` rather than only assigning `value = error_mark_node`. [F110, F111, F143, F279, F386]
- Guard against invalid or dependent trees before inspecting types: check `TREE_TYPE (type) != error_mark_node` before `mark_decl_used` on a `TYPE_DECL` in `declspecs_add_type`; check `error_operand_p` in `c_parser_postfix_expression`, `sizeof_pointer_memaccess_warning`, and `warn_for_omitted_condop` (`TREE_TYPE (cond) != NULL_TREE`); check `COMPLETE_OR_VOID_TYPE_P` (using `size_one_node` for `VOID_TYPE_P`) on `.ACCESS_WITH_SIZE` pointee types in `build_access_with_size_for_counted_by` and `get_index_from_pointer_addr_expr`; and check `TREE_TYPE (x) != NULL_TREE && !VOID_TYPE_P (TREE_TYPE (x))` before calling `lvalue_p (x)` in `warning_candidate_p`. [F31, F108, F185, F302, F447, F449]

## External Contracts

- In `c_common_has_attribute`, every standard C and C++ attribute must be explicitly matched in the unscoped dispatch table with its `YYYYMM` value; diagnostic-only or target-disabled attributes (`gnu::trivial_abi`, `gnu::no_specializations`, unsupported `init_priority`) must set `attr_name = NULL_TREE`; and scoped namespace `"_Clang"` maps to `"clang"` while `"__clang__"` must not be passed to `canonicalize_attr_name`. Every `objc_*` function declared in `c-objc.h` must have a matching stub in `stub-objc.cc`. [F383, F384, F388, F403]

## Known Pitfalls

- Header ordering: in `c-decl.cc` and `c-errors.cc`, request C++ standard headers via `#define INCLUDE_*` before `#include "system.h"`; in `c-parser.cc`, `#include "config.h"` must precede all headers and `#if ENABLE_ANALYZER`; in `c-parser.cc`, `c-cppbuiltin.cc`, `c-lex.cc`, and `c-format.cc`, `#include "target.h"` or `"tm.h"` must precede target macro `#ifdef`s (`JOIN_STR`, `TARGET_OS_CPP_BUILTINS`, `SYSTEM_IMPLICIT_EXTERN_C`, `TARGET_FORMAT_TYPES`); and in `c-common.h`, guard `#define GCC_DIAG_STYLE __gcc_cdiag__` with `#ifndef GCC_DIAG_STYLE` before `diagnostic-core.h`. [F10, F89, F90, F280, F281, F360, F361]
- In `gcc/c-family/c.opt`, every non-blank, non-comment line must start at column 1 and all option properties must stay on the second line of a record; property names must have no space before `(`; arguments containing `)` (such as `Warn({...})`) must be wrapped in `{...}`; and `Alias(...)` arguments must not have trailing spaces before `,` or `)`. [F423, F424, F425, F426]
- In `start_decl` and `finish_decl`, never write `DECL_INITIAL` on a `PARM_DECL` when rejecting an invalid parameter initializer, because `DECL_INITIAL` aliases `DECL_ARG_TYPE` in `PARM_DECL` nodes. In `handle_packed_attribute`, `DECL_PACKED` must only be set on a `FIELD_DECL`, never on a `VAR_DECL` or `TYPE_DECL`. [F59, F243]
- Evaluation-dependent warnings (`overflow_warning`, `warn_for_div_by_zero`, `do_warn_double_promotion`, `maybe_warn_shift_overflow`, `warnings_for_convert_and_check`) must be suppressed when `c_inhibit_evaluation_warnings != 0` (which `c_parser_generic_selection` must also increment for `default` associations after a prior association matched), but `maybe_warn_shift_overflow` must still return `true` on signed left-shift overflow so callers invalidate integer constant expressions, and `warnings_for_convert_and_check` must reset `TREE_OVERFLOW (result) = TREE_OVERFLOW (expr)` on narrowing `INTEGER_CST` conversions and exclude `BOOLEAN_TYPE`-underlying enums. [F106, F304, F434, F435, F437, F443]
- Canonicalize types with `TYPE_MAIN_VARIANT` before comparing against built-in scalar type nodes (`char_type_node`, `integer_type_node`, `void_type_node`, etc.) or calling `lang_hooks.types_compatible_p` in `c-format.cc`, `c-warn.cc`, or `ubsan_instrument_division`; in `matching_type_p` (`c-format.cc`), return `false` if either type has `TYPE_STRUCTURAL_EQUALITY_P` before comparing `TYPE_CANONICAL`; and in `remove_qualifiers` (`c-typeck.cc`), preserve `TYPE_QUAL_ATOMIC`. [F178, F370, F371, F438, F439]
