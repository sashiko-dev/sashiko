# libstdc++-v3

`libstdc++-v3` is the GNU C++ Standard Library implementation, providing internal headers (`include/bits/*`) for containers, ranges, iterators, allocators, streams, random number generation, smart pointers, Unicode, and vocabulary types alongside compiled runtime support (`src/c++17` through `src/c++26`) for floating-point formatting, atomic waiting, time zones, stacktraces, terminal `std::print`, and locale encodings.

## Architecture & Data Flow

- In `_Hashtable`, non-empty `_M_buckets[__bkt]` and `__location_type::_M_before` store the `_Hash_node_base` preceding the target node (possibly `&_M_before_begin`), so only their `_M_nxt` pointer may be cast to `__node_ptr`. Inserting into an empty bucket prepends at `_M_before_begin._M_nxt`, sets `_M_buckets[__bkt] = &_M_before_begin`, and updates any prior first node's bucket to the new node; unlinking or tail-inserting must update `_M_buckets[__next_bkt]` when the successor node belongs to another bucket. [F5, F6, F7]
- In `_Power2_rehash_policy::_M_next_bkt`, `__n == 0` returns `1` without modifying `_M_next_resize`, `__n == 1` returns `2` so `_Hashtable::_M_single_bucket` is not used, and if `__clp2(__n)` overflows to `0` or equals `__max_bkt`, the result is capped at `__max_bkt` with `_M_next_resize = size_t(-1)`. [F12, F13]
- When traversing a singly-linked list via a predecessor pointer or iterator while conditionally extracting or splicing out the next node (`_Hashtable::_M_merge_unique`, `forward_list::remove`, `remove_if`, `unique`), the predecessor must advance only when the next node is kept. [F10]
- In `std::vector`, every reallocation path growing by `__n` elements must compute the size via `_M_check_len(__n, ...)` and record `_M_allocate_at_least`'s returned `_Alloc_result::__count` (not the requested size) in `_Guard_alloc`, rollback `_M_deallocate`, and `_M_end_of_storage`. When inserting `__n` elements into spare capacity (`__elems_after = end() - __position`), split on `__elems_after > __n` so writes at/past `__old_finish` use uninitialized construction while writes before `__old_finish` use assignment. [F143, F148, F172]
- In `basic_filebuf`, when `_M_buf_size > 1`, usable get/put capacity is `_M_buf_size - 1` (reserving 1 slot for `overflow()`); when `_M_buf_size == 1`, get capacity is 1 and put capacity is 0. In `xsputn`, when `_M_codecvt->always_noconv()` and `!_M_writing && _M_buf_size > 1`, `__bufavail` must be `_M_buf_size - 1` rather than `epptr() - pptr()`. Whenever `underflow` or `imbue` moves unconverted bytes (`__remainder = _M_ext_end - _M_ext_next`) to `_M_ext_buf`, reset `_M_ext_next = _M_ext_buf` and `_M_ext_end = _M_ext_buf + __remainder`. [F3, F4, F18]
- In `piecewise_constant_distribution` and `piecewise_linear_distribution`, `param_type` represents the default uniform `[0, 1)` state with empty `_M_int`, `_M_den`, and `_M_cp` vectors (`_M_initialize2` must leave them empty when 2-boundary input matches default `[0, 1]`), and `discrete_distribution::param_type` uses an empty `_M_prob` for a single outcome; `intervals()`, `densities()`, `probabilities()`, `min()`, and `max()` must check `.empty()` before indexing or subtracting 1 from `.size()`, and `param_type` constructors must verify at least two boundaries before computing `_M_int.size() - 1`. [F54, F55, F104, F106]
- In `std::uniform_int_distribution`, every raw sample from `__g()`/`__urng()` in `_S_nd`, `operator()`, and `__generate_impl` must subtract `min()` before scaling/masking. In `_S_nd`, because `_Up` can be wider than `_Bits`, mask `__low` and `_Up(__product >> _Bits)` with `__mask`, compute `__back_threshold` from `__mask` (not `_Up_traits::__max`), and alternate front (`__low < __threshold`) and back (`__low <= __mask - __threshold` break) rejection. [F176, F177, F178]
- In `ranges::__advance_fn` with `sized_sentinel_for<_Sent, _It>`, bound saturation must branch on the sign of `__diff = __bound - __it` (`__diff > 0 ? __n >= __diff : __n <= __diff`) and assert `(__n < 0) == (__diff < 0)` when `__n != 0`. In `ranges::subrange::advance(__n)`, when `_It` is `bidirectional_iterator` and `__n < 0`, call unbounded `ranges::advance(_M_begin, __n)` (never passing `_M_end`) and add `__to_unsigned_like(-__n)` to `_M_size._M_size`; when `__n >= 0`, subtract `__to_unsigned_like(__n - ranges::advance(_M_begin, __n, _M_end))`. [F101, F102, F137]
- In `ranges::__stable_sort_fn`, `ranges::__detail::__stable_sort_adaptive_resize`, and `ranges::__inplace_merge_fn`, `_stable_sort` must round up buffer size and split point as `(__last - __first + 1) / 2`, and `__stable_sort_adaptive` / `__merge_adaptive` may only be called directly when `__buf.size() == __buf._M_requested_size()`. Every call to `__stable_partition_adaptive` requires `__len > 0` and `!__pred(*__first)` because its base case unconditionally moves `*__first` into `__buffer`. [F96, F97, F107, F108]
- In `tzdb.cc`, `reload_tzdb` must match both cases of `'r'`/`'l'`/`'z'` and normalize `type[0]` to uppercase, sort `zones`/`links` by `name` and `rules` by `(name, from, save)`, and run `ZoneInfo::calc_save(node->rules)` before publishing `node`. In transition lookup: `find_surrounding_transitions` must widen `[first_year, last_year]` by 1 year when `std_offset > 0` on Dec 31 or `< 0` on Jan 1 and guard `start_after` with `rule_start < start_after`; `find_active_rule` must return before adding `std_offset` when `tran.rule` is null and cascade the preceding `save` onto `at_time::Wall` transitions. [F183, F196, F207, F208, F209, F210, F222]
- In `time_zone::_M_get_sys_info` (`tzdb.cc`), call `find_active_rule` at `info.begin` (not `info.begin - 1s`), fold rules firing within `merge_window = prev_offset - info.offset` into `info.begin` without emplacing a pre-rule `sys_info`, only decrement the final `num_after` step when `!next_rule || next_rule->save == 0s`, and save the integer offset `i - infos.begin()` before calling `infos.insert(...)` which invalidates `i`. [F184, F211, F212, F213]

## Synchronization

- In `atomic.cc`, `use_proxy_wait(__args)` in `__notify_impl` must match `__wait_args::_M_setup_proxy_wait` so notifications target `__state->_M_ver` with `__all = true` whenever waiters slept on the proxy, and `Table::hash` must mix high/low pointer bits with the per-process random `seed`. In `__wait_until_impl`, after `__spin_impl` returns with `_M_timeout == true` and `!__spin_only`, check `__wait_clock_t::now() >= __atime` and return immediately before blocking. [F188, F220, F221]

## Object Lifetimes

- In `std::_Hashtable`, `_M_buckets` may point to inline `_M_single_bucket`: `_M_deallocate_buckets` must skip deallocation when `_M_uses_single_bucket(__bkts)` is true, and move/swap must rebind `_M_buckets = &_M_single_bucket` and call `_M_update_bbegin()`. Newly allocated nodes must be held in `_Scoped_node` until `_M_insert_unique_node`/`_M_insert_multi_node` succeeds (then setting `__node._M_node = nullptr`). In `_M_erase_some`, find the upper bound `__n_last` of equal keys before deallocating any node in `[__n, __n_last)` so a key aliased to an erased node stays valid. [F9, F11, F37, F39]
- In `std::_Node_handle_common`, `_Optional_alloc` has a no-op destructor: every transition from non-empty to empty (`_M_reset`, `release`, `_M_move`, `operator=`) must call `_M_alloc.release()`; `_M_move` into an empty handle must placement-new `_M_alloc` rather than assigning it; and move-assigning into a non-empty handle must destroy/deallocate `_M_ptr` with the old `_M_alloc` before `_M_alloc = __nh._M_alloc.release()` propagates the source allocator. [F67, F77, F78]
- In `std::indirect`, `std::polymorphic`, and `std::vector` copy assignment, when the old object/buffer must be destroyed and deallocated before allocator propagation (`propagate_on_container_copy_assignment` in `indirect`/`polymorphic` after allocating with `__other._M_alloc`, or unequal propagating allocator in `vector::operator=`), deallocation with the old allocator must happen before replacing the allocator. In `indirect`/`polymorphic` allocator-extended move constructors with `_M_alloc != __other._M_alloc`, restore `_M_objp` to `__other._M_objp` before allocating the new object. [F31, F44, F173]
- In `std::forward_list`, `_Node` uses uninitialized storage with a no-op destructor, so `_M_create_node` must guard allocation with `__allocate_guarded_obj` and `_M_destroy_node` must destroy `_M_valptr()` (and `~_Node()` if `_Base_ptr` is non-trivially destructible) before `_M_put_node`. In `remove`, `remove_if`, and `unique`, splice removed nodes into a local `forward_list __to_destroy(get_allocator())` instead of destroying in-loop, and pass `get_allocator()` to all temporary `forward_list` instances in modifiers. [F29, F41, F42]
- In `bits/ranges_uninitialized.h`, non-trivial construction loops must wrap the output iterator in `ranges::__detail::_DestroyGuard`, advance that exact local iterator variable in place (since `_DestroyGuard` stores `std::__addressof(__iter)`), and call `__guard.release()` before returning. `ranges::__destroy_fn` and `__destroy_n_fn` may skip `ranges::destroy_at` on `is_trivially_destructible_v` types only when `!is_constant_evaluated()`. [F103, F130, F132]

## API Contracts

- In `_Hashtable`, heterogeneous lookup/insert/erase helpers (`try_emplace`, `_M_insert_tr`, `_M_erase_tr`) must call `_M_locate_tr(__k)` rather than `_M_locate(__k)`. When `size() <= __small_size_threshold()`, `_M_locate_tr` linearly scans `_M_before_begin` before hashing, skips `_M_find_before_node_tr` on miss, and returns matches with `_M_bucket_index == size_type(-1)`, so callers needing the bucket index (`erase`, `_M_erase_tr`) must compute `_M_bucket_index(*__n)` when `_M_bucket_index == size_type(-1)`. [F8, F15, F25]
- In `__new_allocator<_Tp>`, `allocate` and `allocate_at_least` must call `_S_check_allocation_limit(__n)` before multiplying `__n * sizeof(_Tp)`, throwing `bad_array_new_length` when `__n > size_t(-1) / sizeof(_Tp)` and `bad_alloc` when `__n > _S_max_size()`. In `pmr::polymorphic_allocator`, `allocate` and `allocate_object` must check `(size_t(-1) / sizeof(...)) >= __n` and throw `bad_array_new_length` before multiplying, `construct` must pass `*this` (not `resource()`) for uses-allocator construction, and `select_on_container_copy_construction` must return `polymorphic_allocator()`. [F56, F58, F65, F66]
- Algorithms and distributions taking a C++20 `uniform_random_bit_generator` (`ranges::sample`, `ranges::shuffle`, `generate_canonical`, `uniform_int_distribution`) must deduce the generator output type via `decltype(__g())` or `decltype(_Urbg::max())` rather than `result_type`. Random engine seed-sequence templates in `bits/random.h` must constrain `_Sseq` via `__detail::_If_seed_seq_for`. [F71, F114, F156]

## Error Handling

- In `vector::_M_realloc_insert`, `_M_realloc_append`, and `_M_default_append`, when `!_S_use_relocate()`, `_Guard_alloc` and `_Guard_elts` must guard the new buffer and constructed elements until all moves succeed, then retarget to `__old_start`/`__old_finish`. In `vector::_M_fill_insert`'s reallocation branch, reset `__new_finish = pointer()` immediately after `__uninitialized_fill_n_a` so `__catch` distinguishes a first-move throw from a fill/second-move throw. [F170, F171]
- When recycling `_Hashtable` nodes via `_ReuseOrAllocNode`, detach `_M_before_begin._M_nxt` first, and guard non-assignable value reconstruction in `operator()` with `_NodePtrGuard` after `destroy`. In `forward_list::sort`, wrap `__comp` in `__try`/`__catch(...)` that relinks `__list`/`__tail`, the remaining `__psize` nodes of `__p`, and `__q` to `_M_impl._M_head._M_next` before rethrowing. [F38, F45]

## External Contracts

- When `_GLIBCXX_USE_NEW_PIECEWISE_DISTRIBUTIONS` is enabled (gated on its numeric value `== 0`, `!= 0`, `== 2`, never `#ifdef`), `piecewise_constant_distribution` and `piecewise_linear_distribution` `param_type::densities()` must carry `[[__gnu__::__abi_tag__("__rt")]]` and convert `_M_den` to `vector<result_type>`, while `operator>>` in `bits/random.tcc` must extract densities into `vector<_StorageType>`. When `_GLIBCXX_USE_OLD_GENERATE_CANONICAL` is not defined, `__generate_canonical_pow2` and `__generate_canonical_any` must loop and draw fresh entropy whenever `__ret` is not strictly less than `_RealT(1.0)`. [F72, F87, F117, F135]

## Known Pitfalls

- Preprocessor conditionals with a trailing `else` before `#endif` (or guarding `__try`/`__catch` before a shared `{ ... }` block) in `path::_S_str_convert`, `__new_allocator::allocate`/`deallocate`, `basic_ostream::_S_cast_flt`, `poisson_distribution`, `binomial_distribution`, `uniform_int_distribution::operator()`, `vector::reserve`/`_M_realloc_insert`/`_M_realloc_append`, `simd::__vec_get`, and `tzdb.cc` (`zoneinfo_file`, `_S_init_tzdb`) attach the following statement or brace block as the fallback branch; never insert statements or split braces across those `#endif` boundaries. [F2, F52, F94, F145, F189]
- Header/source macro and include rules: `bits/funcref_impl.h` and `bits/mofunc_impl.h` must have no include guards and `#undef` all `_GLIBCXX_MOF_*` macros at EOF; `bits/fs_path.h`, `bits/ostream.h`, and `bits/ostream_insert.h` must include `<bits/iosfwd.h>` (not `<iosfwd>`/`<ios>`); `bits/unique_ptr.h` must gate `<bits/ostream.h>` and `operator<<` on `_GLIBCXX_HOSTED`; `format.cc`, `tzdb.cc`, `sstream-inst.cc`, `cow-string-inst.cc`, and `string-inst.cc` must define `_GLIBCXX_USE_CXX11_ABI` before any `#include`; `print.cc` must define `_GLIBCXX_NO_INLINE_PRINT 1` before stream/print headers; and `src/c++17/ryu/` headers must not use `extern "C"`. [F19, F21, F61, F63, F154, F198, F200, F204]
- In `bits/ranges_uninitialized.h`, uninitialized construction algorithms must check triviality and placement-construct using `remove_reference_t<iter_reference_t<_Out>>` rather than `iter_value_t<_Out>`. When checking whether existing container elements can be assigned in-place (`forward_list::assign`, `_ReuseOrAllocNode::operator()`), test `is_assignable<_Tp&, ...>` with an lvalue reference target. [F26, F120]
- In `ranges::__equal_fn`, `__copy_or_move`, `__copy_or_move_backward`, and `__lexicographical_compare_fn`, unwrapping iterator wrappers via `.base()` must be guarded by `same_as<_Iter, _Sent>`. In `ranges::__find_fn`, dispatching to `__builtin_memchr` requires checking `static_cast<_Vt>(__value) == __value` at runtime. In `ranges::__detail::__less_builtin_ptr_cmp`, require `__not_overloaded_spaceship<_Tp, _Up>` before comparing converted pointers. In C++26 `constexpr` sorting/merging/partitioning, guard `_Temporary_buffer` with `if consteval`. [F115, F122, F123, F126]
- In `std::vector`, save the insertion offset (`__position - cbegin()`) before any reallocation or element insertion in `insert`, `_M_insert_rval`, `_M_emplace_aux`, and `insert_range`; check `__n > max_size()` in `reserve` before checking `capacity() < __n`; and call `_S_check_init_len` in `_M_assign_aux` before `_M_replace_with`. In `std::hash<std::vector<bool>>`, only dereference `_M_finish._M_p` when `__extrabits = __b.size() % _S_word_bit` is non-zero and mask off bits `>= __extrabits`. [F142, F144, F146, F147]
- In `tzdb.cc`, convert `sec32_t` (`duration<int_least32_t>`) to `chrono::seconds` before adding to `sys_days` (avoiding 32-bit `sys_days::rep` overflow); check `num_positive_leaps != 0` in `__recent_leap_second_info` before indexing `pos[-1]`; and in `at_time` / `at_time::Indicator` stream extractors, skip whitespace with `ws(in)` before peeking for `'-'`, resolve `'-'` at EOF to `0s`, and guard every `in.peek()` with `!in.eof()`. [F185, F206, F225]
