# config-sparc

The `config-sparc` unit implements the SPARC target backend (`gcc/config/sparc/`), including 32-bit/64-bit calling conventions and ABI layout, machine descriptions (`sparc.md`, `sync.md`, `predicates.md`, `constraints.md`), CPU pipeline models, OS subtarget headers, VIS intrinsics (`visintrin.h`), and LEON/UT699/GR712RC hardware errata workarounds.

## Architecture & Data Flow

- In `tm_file`, `sparc/biarch64.h` (`SPARC_BI_ARCH`) must precede `sparc/sparc.h`, `sparc/linux64.h`, and `sparc/netbsd-elf.h`; `sparc/default64.h` (`TARGET_64BIT_DEFAULT`) must precede `sparc/linux64.h` and `sparc/sol2.h`; `sparc/openbsd1-64.h` (`OBSD_HAS_DECLARE_*`) must precede `openbsd.h`; `sparc/sysv4.h` (which `#undef`s `SET_ASM_OP`) must follow `elfos.h`; and `sparc/vxworks.h` must follow `sparc.h` (which includes `config/vxworks-dummy.h`), `sysv4.h`, and `vxworks.h`. [F7, F8, F9, F91, F92]
- `sparc.opt` must declare `HeaderInclude` for `config/sparc/sparc-opts.h` and `sparc.h` must guard `SUBTARGET_DEFAULT_MEMORY_MODEL` (`SMM_DEFAULT`) with `#ifndef` so `tso.h` (`SMM_TSO`) is not clobbered; `sparc.h` must keep `enum attr_cpu` (`sparc_cpu_attr`) inside macro bodies because not all includers include `insn-attr.h`; D hooks (`TARGET_D_*`, `sparc_d_*`) belong in `sparc-d.h`; and in `sparc.cc`, `#include "target-def.h"` must follow all includes and precede all `TARGET_*` overrides and `targetm = TARGET_INITIALIZER`. [F5, F43, F94, F95]
- `enum sparc_processor_type` in `sparc-opts.h` must stay in 1-to-1 order with the `cpu` attribute in `sparc.md` and the processor table in `sparc_option_override`; in `enum sparc_builtins`, `SPARC_BUILTIN_DICTUNPACK*` and `SPARC_BUILTIN_FPCMP*SHL` enumerators must remain contiguous within their `FIRST`/`LAST` markers; and in `sparc_target_macros`, `TARGET_VIS*` checks must stay an `if`/`else if` chain from highest to lowest VIS level because `sparc_option_override` sets all lower `MASK_VIS*` bits. [F4, F14, F56]
- All 32 V9 FP slots (`SPARC_FIRST_V9_FP_REG`..`SPARC_LAST_V9_FP_REG`, including odd ones) must stay in `[0, FIRST_PSEUDO_REGISTER)`, `REG_ALLOC_ORDER`, and `REG_LEAF_ALLOC_ORDER` so `CLASS_MAX_NREGS` is contiguous; `enum reg_class` must order `FPCC_REGS` before `GENERAL_REGS`, keep `FP_REGS` (`%f0`-`%f31`) separate from `EXTRA_FP_REGS` (`%f0`-`%f63`), and keep `GENERAL_OR_FP_REGS`/`GENERAL_OR_EXTRA_FP_REGS`; and in `sparc_modes_tieable_p` (`TARGET_V9`), 4-byte `MODE_FLOAT`/`MODE_VECTOR_INT` modes must not tie with >4-byte modes. [F66, F89, F107]
- In `gen_df_reg` and `sparc_hard_regno_nregs`, 64-bit integer regs hold 8 bytes (`+ 1` per `DFmode` half) while FP and 32-bit integer regs hold 4 bytes (`+ 2`); constraints `e`/`f` must return `NO_REGS` when `!TARGET_FPU` (`b`/`d` when `!(TARGET_V9 && TARGET_VIS)`); and `sparc_secondary_reload` must return `GENERAL_REGS` for `HImode`/`QImode` between `FP_REG_CLASS_P` and memory/spilled pseudos, and `FP_REGS` on `TARGET_ARCH32` for `DFmode` between unaligned memory and `EXTRA_FP_REGS` or VIS3 moves between `EXTRA_FP_REGS` and `GENERAL_REGS`. [F35, F70, F77]
- `TARGET_DEFAULT` must include `MASK_APP_REGS` (`%g2`-`%g4`); `HARD_REGNO_RENAME_OK` must reject hard reg `1` (`%g1`); `HARD_REGNO_CALLER_SAVE_MODE` must return `MODE` directly when `MODE != VOIDmode`; and in `epilogue_renumber` (when `test == 0`), replacement `OUTGOING_REGNO` regs for `%i[0-7]` must be allocated via `gen_raw_REG` with nonzero `ORIGINAL_REGNO` copied over for `sparc_pic_register_p`. [F81, F102, F103, F104]
- `ACCUMULATE_OUTGOING_ARGS` must be `1` for `longjmp`; `STACK_ADDRESS_OFFSET` must equal `STACK_POINTER_OFFSET` (`FIRST_PARM_OFFSET(0) + SPARC_STACK_BIAS`); `INIT_EXPANDERS` must set `REGNO_POINTER_ALIGN` of `STACK_POINTER_REGNUM` and `HARD_FRAME_POINTER_REGNUM` to `BITS_PER_UNIT` when `SPARC_STACK_BIAS` is nonzero; and `sparc_function_ok_for_sibcall` must require non-null `decl`, `flag_delayed_branch`, `TARGET_ARCH64 || !cfun->returns_struct`, and `targetm.binds_local_p (decl)` when `TARGET_VXWORKS_RTP && flag_pic`. [F64, F105, F106, F109]
- `INT_MODE (OI, 32)` must stay in `sparc-modes.def` for 64-bit 32-byte aggregate returns; in `function_arg_record_value`, `assign_int_registers`, and `assign_fp_registers`, when `data.stack` is true, index 0 of `data.ret` is a `NULL_RTX` marker so regs go at `XVECEXP(data->ret, 0, data->stack + data->nregs)` while `data->nregs` counts only regs; `traverse_record_type` must skip fields with `!DECL_SIZE (field) || integer_zerop (DECL_SIZE (field))` and propagate `bitpos` and `packed` into nested `RECORD_TYPE`s; and `ROUND_TYPE_ALIGN` must check `RECORD_OR_UNION_TYPE_P (STRUCT) && TYPE_FIELDS (STRUCT) != 0` before applying `BIGGEST_ALIGNMENT`. [F15, F38, F48, F49, F96]
- In `sparc_legitimate_address_p`, `RTX_OK_FOR_OFFSET_P` and `RTX_OK_FOR_OLO10_P` must subtract `GET_MODE_SIZE (MODE)` from the upper offset limit, and `REG + REG` addresses must be rejected for `TImode`, for `TFmode` unless `TARGET_ARCH64 && TARGET_HARD_QUAD`, and for `DFmode`/`DImode` when `TARGET_ARCH32 && !optimize`; `input_operand` must reject operands with mismatched non-`VOIDmode` modes, return `true` for `MEM` during `lra_in_progress`, and accept any `DImode` `CONST_INT` when `TARGET_ARCH32` while rejecting multi-insn `DImode` `CONST_INT`s when `TARGET_ARCH64`; and constraint `T` (`memory_ok_for_ldd`) must use `define_special_memory_constraint`. [F18, F19, F36, F76]
- In `predicates.md`, `icc_comparison_operator` must restrict `CCNZmode`/`CCXNZmode` to `nz_comparison_operator`, `CCCmode`/`CCXCmode` to `c_comparison_operator`, and `CCVmode`/`CCXVmode` to `v_comparison_operator`; `cc_arith_operator` must exclude `plus`, `minus`, `neg`, and `ashift`; `compare_operand` must only accept `ZERO_EXTRACT` when `INTVAL (XEXP (op, 2))` is `> 19` (`SImode`) or `> 51` (`DImode`, `TARGET_ARCH64`); and `arith_double_add_operand` must only accept `const_4096_operand` when `TARGET_ARCH64` because negating 4096 alters the carry flag. [F20, F21, F22, F27]
- `REVERSIBLE_CC_MODE` must be false for `CCFPmode`/`CCFPEmode`; `select_cc_mode` must return `CCFPEmode` (`fcmpe*`) for `LT`/`LE`/`GT`/`GE`/`LTGT` and `CCFPmode` (`fcmp*`) for `EQ`/`NE`/`ORDERED`/`UN*`; and `output_cbranch` (`CCFPmode`/`CCFPEmode`) and `sparc_expand_conditional_move` (`MODE_FLOAT`) must invert FP conditions with `reverse_condition_maybe_unordered` rather than `reverse_condition`. [F83, F84, F111]
- `sparc_vis_init_builtins` and `sparc.md` must gate OSA2011 SIMD operations (`__builtin_vis_fp{add,sub}64`, `__builtin_vis_fucmp{le,ne,gt,eq}8`, `fp<plusminus_insn>64_vis`, `fpcmpu*`, `V8QImode` `fpcmp*` `EQ`/`NE`, `vec_cmp*`, `vec_cmpu*`, `vcond_mask_*`) on `TARGET_VIS3B` (or `TARGET_VIS4`) rather than `TARGET_VIS3`; `vec_cmp_operator` (`V8QImode`) and `vec_cmpu_operator` (non-`V8QImode`) must restrict comparisons to `EQ`/`NE` when `!TARGET_VIS4`; `vector_init_bshuffle`, `vector_init_fpmerge`, and `vector_init_faligndata` must unsigned-convert scalar `elt` to `SImode` into `gen_lowpart (SImode, t1)`; and in `sparc_expand_builtin`, `op[0]` holds the target (or `NULL_RTX`), args go at `op[arg_count]`, and `insn_data[icode].operand` is indexed by `arg_count - !nonvoid`. [F17, F39, F71, F80, F123]
- `TARGET_HARD_MUL` must exclude `TARGET_V8PLUS` and `TARGET_HARD_MUL32` must be `(TARGET_HARD_MUL && TARGET_ARCH32 && !TARGET_V8PLUS)`; `output_v8plus_shift` and `output_v8plus_mult` must emit `srl %Li, 0, %Li` before `or` when `sparc_check_64 (operands[i], insn) <= 0`; `emit_hard_tfmode_operation` must `force_reg` inputs and use a temp pseudo if `operands[0]` is not a `register_operand`; and shift-based sub-word extension expanders (`zero_extendhisi2`, `extendqihi2`, etc.) must strip any existing `SUBREG` and align `SUBREG_BYTE` to word size before forming the word `SUBREG`. [F73, F79, F116, F129]
- In `sparc.md`/`sync.md`, post-reload multi-word `define_split`s (`TImode`, `TFmode`, non-V9 `DFmode`) must check `reg_overlap_mentioned_p` between `dest1` and `src2`/`word1` and emit `dest2` first on overlap; V9 conditional move patterns (`*mov*_cc_v9`, `*mov*_cc_reg_sp64`) must tie operand 4 (false arm) to constraint `"0"`; move-plus-compare `define_peephole2`s must check `!SPARC_FP_REG_P` on both operands; `prefetch_64`/`prefetch_32` must accept `operands[1]` in `[0, 2]` and index `prefetch_instr[read_or_write & 1]`; `sparc_can_follow_jump` must return `false` when `CROSSING_JUMP_P (followee) && !CROSSING_JUMP_P (follower)`; and `frame_blockage` (`UNSPEC_FRAME_BLOCKAGE`) and `membar` (`UNSPEC_MEMBAR`) must set `MEM_VOLATILE_P` to 1 on their `BLKmode` `SCRATCH` `MEM`. [F61, F101, F114, F115, F121, F122]
- On `!TARGET_V9`, 32-bit V8 division patterns (`divsi3_sp32`, `udivsi3_sp32`, `*cmp_{s,u}div_cc_set`) must emit at least 3 insns between `wr ..., %y` and `{s,u}div{,cc}` (with `&r` earlyclobber when loading into dest); when `sparc_fix_ut699` is active, `divsf3`, `sqrtsf2`, `swapsi`, and `ldstub` are disabled, `*divdf3_fix`/`*sqrtdf2_fix` append `std %0, [%sp-8]\n\tnop`, `in_branch_delay` rejects `load`, `sload`, and `single` FP (`fptype`/`fptype_ut699`), and in `sparc_do_work_around_errata`'s UT699 lookahead loop, hitting a branch (`!NONJUMP_INSN_P` or `rtx_sequence`) must pre-increment `i` and break if `++i == n_insns` before inspecting the delay slot; and when `sparc_fix_gr712rc` is active, `ldstub`/`swap`/`casa` patterns must emit `.align\t16` before the atomic insn and add `3` to `length`. [F41, F113, F118, F125]
- In `supersparc_adjust_cost`/`hypersparc_adjust_cost`, the 3-cycle `TYPE_STORE`/`TYPE_FPSTORE` penalty applies only when `SET_DEST (PATTERN (dep_insn))` is not `rtx_equal_p` to `SET_SRC (PATTERN (insn))`; in `ultra1_2.md`/`ultra3.md`, `define_bypass 0` to `us1_store`/`us3_store` must use `"store_data_bypass_p"` and exclude `fdivs`; and `ultra1_2.md` must keep `(absence_set "us1_ieu0" "us1_ieu1")` and cascading `us1_slot0`..`us1_slot3` absence sets. [F65, F98, F99]
- In `!DEFAULT_ARCH32_P` `CC1_SPEC` (`linux64.h`, `sol2.h`), `%{mv8plus:...}` must pass `-m32` alongside `-mptr32 -mno-stack-bias`; and `sol2.h` must define `GGC_QUIRE_SIZE` to `510` to stay under 4 MB with Solaris `mmap` red-zone pages. [F29, F30]

## Object Lifetimes

- In `host_detect_local_cpu` (`driver-sparc.cc`), non-Solaris `/proc/cpuinfo` loops must `break` rather than returning early so `fclose (f)` runs, and `cpu` must point to static storage (`cpu_names[i].cpu`) rather than `buf` or kstat memory because `concat` reads `cpu` after `kstat_close (kc)` / `fclose (f)`; and `sparc_output_deferred_case_vectors` must reset both GTY-rooted globals `sparc_addr_list` and `sparc_addr_diff_list` to `NULL_RTX` after emitting jump tables. [F10, F11, F47]

## API Contracts

- Register constraints in `constraints.md` (`"b"`, `"c"`, `"d"`, `"e"`, `"f"`, `"h"`) must use `define_register_constraint` (not `define_constraint`) so LRA resolves a non-`NO_REGS` class; on `TARGET_ARCH64`, `sparc_secondary_memory_needed_mode` must widen sub-32-bit modes only to 32 bits (not `BITS_PER_WORD`); in `sparc.md`, `vec_cmp<FPCMP:mode><P:mode>` and `vec_cmpu<FPCMP:mode><P:mode>` must swap `LT`/`GE` and `LTU`/`GEU` via `swap_condition` and `std::swap (operands[2], operands[3])`; and in `sparc_vectorize_vec_perm_const` (`TARGET_VIS2`), when `target` is null it must accept any 8-byte `vmode`, but when `target` is non-null it must reject `vmode != V8QImode` so the middle-end lowers to `V8QImode`. [F16, F60, F69, F100]
- In `sparc.cc`, callers of `emit_save_or_restore_regs` must pass even-aligned `low`/`high` bounds whenever `!TARGET_ARCH64 || high > 32`; callers of `sparc_handle_vis_mul8x16` must pre-allocate `n_elts` for at least `VECTOR_CST_NELTS (cst0)` elements (`quick_push`); `compute_fp_layout` must unwrap `ARRAY_TYPE` fields with `strip_array_types (TREE_TYPE (field))` to match `fp_type_for_abi`; `sparc_atomic_assign_expand_fenv` must create temporaries with `create_tmp_var_raw`, set `TREE_ADDRESSABLE = 1`, and bind them via `TARGET_EXPR` before passing addresses to `SPARC_BUILTIN_STFSR`/`SPARC_BUILTIN_LDFSR`; `sparc_rtx_costs` must subtract `COSTS_N_INSNS (1)` from `int_zload`/`int_sload` when `outer_code` is `ZERO_EXTEND`/`SIGN_EXTEND`; and subtargets with a non-128-bit `long double` (such as `vxworks.h`) must `#undef` and redefine `SPARC_LONG_DOUBLE_TYPE_SIZE`. [F40, F46, F50, F59, F62, F128]

## Error Handling

- In `sparc_option_override`, after calling `error(...)` for `-m64`/`-mlong-double-64` or `-fcall-saved-REG` on output regs (`8 <= i < 16`), the invalid state must still be normalized (`target_flags |= MASK_LONG_DOUBLE_128`, `call_used_regs[i] = 1`); and in `sparc_expand_builtin`, each arg must be checked against `error_mark_node` (returning `NULL_RTX`) before `expand_normal`, and failed `check_constant_argument` calls must return `const0_rtx` without calling `GEN_FCN (icode)`. [F53, F55]

## External Contracts

- `ENDFILE_SPEC` in `freebsd.h`, `linux.h`, `linux64.h`, `sp-elf.h`, and `sp64-elf.h` must guard `crtfastmath.o%s` with `%{!shared:crtfastmath.o%s}`; `ENDFILE_SPEC` in `linux.h` and `linux64.h` must use `GNU_USER_TARGET_ENDFILE_SPEC` for default-PIE; both `%{!nolibc:...}` clauses in `LINK_GCC_C_SEQUENCE_SPEC` (`sparc.h`) must include `LINK_LIBATOMIC_SPEC`; `freebsd.h`, `linux.h`, `linux64.h`, `netbsd-elf.h`, `sp-elf.h`, and `sol2.h` (`!HAVE_SOLARIS_LD`) must `#undef CTORS_SECTION_ASM_OP` and `DTORS_SECTION_ASM_OP`; and in `sol2.h`, `ASM_DECLARE_OBJECT_NAME` must size symbols from `tree_to_uhwi (DECL_SIZE_UNIT (DECL))` rather than `TREE_TYPE (DECL)`. [F23, F28, F31, F33, F127]
- `sol2.h` must define `TARGET_BUGGY_QP_LIB 1` and `SUN_V9_ABI_COMPATIBILITY 1`; `linux.h`, `linux64.h`, and `sol2.h` must define `DITF_CONVERSION_LIBFUNCS 1` (plus `SUN_CONVERSION_LIBFUNCS 1` in `sol2.h`), while in `sparc.h`/`sparc.md` they default to `0` and non-`TARGET_HARD_QUAD` `TFmode` conversion expanders calling `emit_tfmode_cvt` must require `TARGET_ARCH64`; and `sparc_init_libfuncs` must only register `_Q_sqrt` on `TARGET_ARCH32` when `TARGET_FPU` is true and must clear `SImode` `smul`/`sdiv`/`udiv`/`smod`/`umod` libfuncs on `TARGET_ARCH64`. [F24, F25, F26, F74, F112]
- `sparc_function_value_1` and `sparc_promote_function_mode` must promote sub-word `MODE_INT` scalars to `word_mode`, and `emit_soft_tfmode_cvt` (`TARGET_ARCH64`) must sign/zero-extend `SImode` inputs to `DImode` for `_Qp_itoq`/`_Qp_uitoq`; and in `sparc_atomic_assign_expand_fenv` (`TARGET_FPU`), holding exceptions must mask out `0x1f << 5` and `0x1f << 23` in `%fsr` and right-shift by 5 when `SPARC_LOW_FE_EXCEPT_VALUES` is nonzero. [F72, F86]

## Known Pitfalls

- In `driver-sparc.cc`, the non-Solaris `#else` branch of `host_detect_local_cpu` matches via `strstr (buf, cpu_names[i].name)` and breaks on the first match, so more specific substring matches (e.g., `"UltraSparc T2+"`) must precede shorter prefixes (`"UltraSparc T2"`); and in `linux.h`, `linux64.h`, and `sol2.h`, `host_detect_local_cpu` and `MCPU_MTUNE_NATIVE_SPECS` must be guarded by both `defined(__sparc__)` and the host OS macro (`__linux__` or `__SVR4`). [F2, F34]
- In `sparc-protos.h`, prototypes using `tree` must be inside `#ifdef TREE_CODE` and those using `rtx`, `rtx_insn *`, or `enum rtx_code` must be inside `#ifdef RTX_CODE`; in `sparc.h`, any optional `HAVE_AS_*` macro expanded as a value (such as `#define TARGET_TLS HAVE_AS_TLS`) must have an `#ifndef ... #define ... 0` fallback; `SPARC_SETHI_P(X)` masks with `0x00000000fffffc00` and rejects negative sign-extended `SImode` `HOST_WIDE_INT`s unless masked or checked via `SPARC_SETHI32_P(X)`; and in `sparc.md`, `-4096` negation (`arith_add_operand`, `arith_double_add_operand`, constraint `O`) must never be used in carry-testing patterns (`CCCmode`/`CCXCmode`/`CCmode`/`CCXmode`, `uaddv*`, `usubv*`). [F6, F108, F117, F126]
- In `sparc_gimplify_va_arg`, when a direct argument has `align == 0 && TYPE_ALIGN (type) > BITS_PER_WORD`, it must be copied into an addressable temporary (`TREE_ADDRESSABLE (tmp) = 1`) via `BUILT_IN_MEMCPY` in `pre_p` rather than dereferencing `addr` directly; and in `sparc-d.cc` (`sparc_d_handle_target_float_abi`), the length passed to `build_string_literal` must be `strlen (abi) + 1` to include the NUL byte. [F12, F58]
