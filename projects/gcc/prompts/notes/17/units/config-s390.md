# config-s390

The `config-s390` unit implements the GCC backend and front-end target hooks for IBM S/390 and zSeries architectures, covering table-driven built-in registration and C-family overload resolution, machine modes, RTL expansion and machine descriptions, ABI calling conventions, instruction scheduling/costing, literal pool management, and target intrinsics.

## Architecture & Data Flow

- In `s390_resolve_overloaded_builtin`, any `OB_DEF` with `FIRST_VAR_NAME == MAX` (`desc_start_for_overloaded_builtin[ob_fcode] == S390_OVERLOADED_BUILTIN_VAR_MAX`) or matched variant with `bt_for_overloaded_builtin_var[last_match_index] == S390_BUILTIN_MAX` (where `target_builtin_decl` is set to `ob_fndecl`) must be handled by a `case` in `s390_expand_overloaded_builtin` and return early before the inclusive `bindex <= desc_end_for_overloaded_builtin[ob_fcode]` loop or `s390_adjust_builtin_arglist`. [F1, F4, F22]
- In `s390_adjust_builtin_arglist`, `folded_args` is allocated with `(*arglist)->allocated () + 1` and populated via `quick_push` (allowing at most one extra argument unless `vec_safe_push` is used); `dest_arg_index` advances per low-level `DECL` parameter while `src_arg_index` advances only when consuming an input from `**arglist`, so inserting a synthetic/duplicated argument sets `arg_assigned_p` without incrementing `src_arg_index`, whereas transforming or swapping an input must do both. [F2, F11]
- In `s390_builtin_ov_types[typeindex]`, index `0` is the return type and index `i + 1` is 0-based argument `i` (up to `MAX_OV_OPERANDS - 1`); in `s390_resolve_overloaded_builtin`, `all_op_flags` must be right-shifted by `O_SHIFT` on every argument `i` before any `continue`. [F5]
- Target source files (`s390-c.cc`, `s390-d.cc`) must `#define IN_TARGET_CODE 1` before `#include "config.h"`, `"system.h"`, and `"coretypes.h"`; `s390-builtins.h` must not include general GCC headers or reference `rtx`/`tree` internals (preprocessed standalone for `gengtype`); and in `s390-protos.h`, `enum rtx_code` prototypes must be inside `#ifdef RTX_CODE` (`rtl.h` is poisoned in `s390-c.cc` and must precede `tm_p.h` in backend TUs) while `s390_valid_target_attribute_tree` and `s390_pragma_target_parse` must be inside `#if S390_USE_TARGET_ATTRIBUTE`. [F6, F7, F8, F10]
- In `s390.h`, macros referencing `insn-flags.h` symbols (like `HAVE_TF`) must have a `#ifdef GENERATOR_FILE` fallback expanding to a non-constant runtime expression like `TARGET_HARD_FLOAT`; compiler-internal types using `rtx` or `enum indirect_branch` (`struct s390_frame_layout`, `struct machine_function`) must be inside `#ifndef USED_FOR_TARGET`; subtarget option flags (`TARGET_TPF_PROFILING`) must use `#ifndef` while OS defaults (`TARGET_TPF`, `STACK_POINTER_OFFSET`, `TARGET_DEFAULT`) are `#undef`-ed in `tpf.h`; and `"tune"` must precede `"arch"` in `OPTION_DEFAULT_SPECS`. [F88, F89, F90, F121]
- In `s390-builtins.def`, immediate operand flags `O_U1`..`O_M12` and `O_S2`..`O_S32` must stay contiguous, fit in `O_SHIFT` (5) bits per operand (up to 4 operands), and stay in sync with `bitwidths` and `bitmasks` in `s390_const_operand_ok`; any `OB_DEF_VAR` operand with `O_ELEM` must have `BT_INT` in `s390_builtin_ov_types` and a `target_builtin_decl` whose vector parameter/return types all share the same `TYPE_VECTOR_SUBPARTS`. [F21, F30]
- In `s390-builtins.def`, non-CC vector FP relational comparison builtins (`s390_vfchesb`, `s390_vfchedb`, `s390_vfchsb`, `s390_vfchdb`, `vec_cmplev4sf`, `vec_cmplev2df`, `vec_cmpltv4sf`, `vec_cmpltv2df`) must use `vec_cmp<ge|gt|le|lt><mode>_quiet_nocc` patterns rather than signaling patterns, and `s390_vec_sel` variants must map to `s390_vsel*` (`vsel<mode>`) with their first two arguments swapped in `s390_adjust_builtin_arglist`. [F24, F26]
- In `s390-modes.def`, `CCAmode` and `CCTmode` are request-only (never returned by `s390_select_ccmode` or set on `CC_REGNUM`), while `CCVIALLmode`, `CCVIANYmode`, `CCVFALLmode`, and `CCVFANYmode` are consumer-only (never passed as `req_mode` to `s390_match_ccmode`); `CCSFPSmode` (signaling FP comparisons when `HONOR_NANS` holds), `CCVFALLmode`, and `CCVFANYmode` must be reversed with `reverse_condition_maybe_unordered` in `s390_reverse_condition`. [F25, F27]
- On `TARGET_VXE` (z14+), `TFmode` resides in a single 128-bit vector register whereas `FPRX2mode` is an FPR pair: `s390_can_change_mode_class` must reject `VEC_REGS` mode changes between `s390_is_fpr128` and `s390_is_vr128` (and size changes when the smaller mode is `< 8` bytes or the larger mode is a single register); `FP_ALL`, `FP`, `BFP`, `TD_TF`, and `FP_COPYSIGN` gate `TF` on `!TARGET_VXE` and `FPRX2` on `TARGET_VXE` (use `FP_ANYTF` or `EXPAND_TF` for both); and FPR-pair sign-bit insns (`lcdfr`, `lpdfr`, `lndfr`, `cpsdr`) must constrain operand 1 with `<fT0>`. [F29, F65, F108, F109]
- `enum processor_type` in `s390-opts.h` must stay in exact order and sync with `processor_table` and `processor_flags_table` in `s390.cc`, the `cpu` attribute in `s390.md`, and `s390_tune_attr` in `s390.h`, and `s390_arch` must be resolved away from `PROCESSOR_NATIVE` before `s390_cpu_cpp_builtins_internal` runs. [F34]
- In `s390_register_info` and `s390_optimize_register_info`, `s390_register_info_set_ranges` must run before `s390_register_info_arg_gpr` marks `r2`..`r5` as `SAVE_SLOT_STACK`; GPR save-area offsets in `s390_initial_elimination_offset`, `s390_emit_prologue`, and `s390_emit_epilogue` must use `cfun_frame_layout.first_save_gpr_slot` (not `first_save_gpr` or `first_restore_gpr`); and `save_gprs`/`restore_gprs` must emit `gen_movdi` when `first == last` (or `start == last` for the frame note) instead of `gen_store_multiple`/`gen_load_multiple`. [F36, F37, F38]
- `load_multiple` and `store_multiple` expanders/insns in `s390.md` must require `reload_completed`, `SImode`/`DImode` GPRs (`REGNO < 16`), and constant counts in `[2, 16]`, and `*load_multiple_di`/`si` and `*store_multiple_di`/`si` must compute the inclusive end register in `operands[0]` as `REGNO(start_reg) + XVECLEN(operands[0], 0) - 1`. [F86, F115]
- Index offsets: in `s390_expand_builtin`, `op` is indexed by `arity` while `insn_data[icode].operand` is indexed by `arity + nonvoid`; in `s390_md_asm_adjust`, input constraint `i` is at `constraints[noutputs + i]`; in `s390_execute_target` (`XVECLEN (pattern, 0) > 2`), element `0` (`UNSPEC_EXECUTE`) is skipped by copying `XVECEXP (pattern, 0, i + 1)` to `RTVEC_ELT (vec, i)`; and in `s390_emit_call` (`elts > 1`), destination index `e` in `RTVEC_ELT (v, e)` increments only when `vec[i] != NULL_RTX`. [F39, F40, F41, F42]
- In `s390.cc`, `s390_valid_target_attribute_inner_p` with `!force_pragma` on a `TREE_LIST` must treat only the first `list_length (current_target_pragma)` elements as pragma arguments; `s390_set_current_function` must call `s390_activate_target_options` only when `fndecl != s390_previous_fndecl` and `old_tree != new_tree`, and `s390_activate_target_options` must reset `s390_previous_fndecl = NULL_TREE` when restoring target globals; and in `s390_can_inline_p`, `all_masks` must include every `x_target_flags` bit. [F54, F55, F61]
- In `s390_expand_cpymem`, `s390_expand_movmem`, and `s390_expand_setmem`, any variable-length expansion using `len - 1` (`vllv16qi`, `vstlv16qi`, `mvcrl`, `cpymem_short`, `clrmem_short`) must branch around the operation on `len == 0` when `min_len == 0`, and `s390_expand_setmem` with `val != const0_rtx` using a 1-byte store plus overlapping `cpymem_short` of `len - 2` bytes must branch around `cpymem_short` on `len == 1` when `min_len <= 1`. [F70, F71]
- In `s390.md`: the `bswaphi2` reg-to-reg `define_split` must require `reload_completed` and `FAIL` if `simplify_gen_subreg (SImode, ..., HImode, 0)` returns `NULL_RTX`; `*extzv_<mode>_srl*` and `*extzv_<mode>_sll*` must clear `operands[3]` mask bits overlapping the shift's vacated positions (using `unsigned int` in `SImode`) and require the adjusted mask to be non-zero; `*anddi3_cconly` and `*andsi3_cconly` must require `s390_single_part (operands[2], <MODE>mode, HImode, 0) < 0`; on `TARGET_Z15`, `popcountsi2` and `popcounthi2` must `zero_extend:DI` before `popcount:DI` while `popcountqi2` uses `UNSPEC_POPCNT`; `movstrictqi`/`hi`/`si` destinations must use `subreg_register_operand`; and `mov<HQI:mode>cc` must `force_reg` any `MEM_P` `then`/`els` operand before `simplify_gen_subreg (E_SImode, ...)` and `gen_movsicc`. [F99, F101, F105, F110, F113, F118]
- In `s390.md`: pre-reload `define_insn_and_split` patterns like `*brx_stage1_<DSI:mode>` that split into CC-clobbering insns must include `(clobber (reg:CC CC_REGNUM))` before `(clobber (match_scratch ...))`; and the `movdi` constant-pool-splitting `define_peephole2` must verify `peep2_reg_dead_p` on `CC_REGNUM` and emit a single `emit_move_insn` + `DONE` if either 32-bit half (`operands[2]` or `operands[3]`) is `const0_rtx`. [F102, F104]

## Object Lifetimes

- Every `struct constant_pool` from `s390_alloc_pool` (and its constant chains and `BITMAP_ALLOC` `insns` bitmap) must be freed via `s390_free_pool` on all paths (`s390_mainpool_start` overflow error, `s390_mainpool_finish` empty-pool return, and every `pool_list` node in `s390_chunkify_finish`); in `s390_chunkify_start`, `far_labels` (`BITMAP_ALLOC(NULL)`) must be freed with `BITMAP_FREE(far_labels)`; and in `s390_loop_unroll_adjust`, `bbs` from `get_loop_body` must be freed on all paths (and `mem_count != 0` checked before dividing). [F47, F48, F60]

## API Contracts

- In `s390-builtins.h`, `bflags_for_builtin` must only be called with `fcode < S390_OVERLOADED_BUILTIN_VAR_OFFSET` (in `s390_resolve_overloaded_builtin`, call it before subtracting `S390_BUILTIN_MAX` from `ob_fcode`, whereas `desc_start_for_overloaded_builtin`, `desc_end_for_overloaded_builtin`, `s390_expand_overloaded_builtin`, and `s390_adjust_builtin_arglist` require the post-subtraction `ob_fcode`), and `opflags_for_builtin` must never be called with unresolved `OB_DEF` codes in `[S390_OVERLOADED_BUILTIN_OFFSET, S390_OVERLOADED_BUILTIN_VAR_OFFSET)`. [F3, F33]
- Because `s390_resolve_overloaded_builtin` checks `opflags_overloaded_builtin_var` before calling `s390_adjust_builtin_arglist`, `OB_DEF_VAR` operand flags in `s390-builtins.def` must reflect pre-adjustment argument positions and ranges, while `B_DEF` operand flags reflect the post-adjustment low-level signature; and when `s390_expand_overloaded_builtin` lowers `vec_xl*`/`vec_xst*`, it must build a `MEM_REF` with second operand `build_int_cst (ptr_type_node, 0)` and access type aligned via `build_aligned_type`. [F14, F23]
- `s390_can_inline_p` must only enforce `always_inline_safe_masks` (`MASK_MVCLE | MASK_BACKCHAIN | MASK_SMALL_EXEC`) and `x_s390_tune` equality when the callee is not marked both `DECL_DISREGARD_INLINE_LIMITS` and `always_inline`, and must check `ipa_fn_summaries != NULL` before querying `fp_expressions` to relax `MASK_HARD_DFP | MASK_SOFT_FLOAT`; and `s390_invalid_arg_for_unprototyped_fn` (`TARGET_VX_ABI`, `typelist == 0`) must exempt both `BUILT_IN_MD` and `BUILT_IN_CLASSIFY_TYPE`. [F49, F56, F57]
- `EXPAND_TF(icode, nops)` in `s390.h` loops `i` from `1` to `nops - 1` using `GET_MODE (operands[i])`, so `nops` must only count non-`VOIDmode` operands `0..nops-1` (excluding trailing `const_int` operands); in `vecintrin.h`, `vec_step(x)` must pass `* (__typeof__ (x) *) 0` to `__builtin_s390_vec_step`, and `vec_all_nan`/`vec_all_numeric`/`vec_any_nan`/`vec_any_numeric` must remain `__extension__` statement-expression macros using `&__cc` and `__cc`. [F85, F87, F93, F94]

## Error Handling

- In `s390_pragma_target_parse`, if `s390_valid_target_attribute_tree` returns `NULL_TREE` or `error_mark_node`, `cl_target_option_restore` must restore `global_options` and `global_options_set` from `prev_tree` before returning `false`, and `cpp_opts->warn_unused_macros` must be temporarily zeroed and restored around `s390_cpu_cpp_builtins_internal`. [F13]
- `s390_check_type_for_vector_abi` must guard against `type == NULL_TREE || TREE_CODE (type) == ERROR_MARK` at entry and skip non-`FIELD_DECL` nodes when iterating `TYPE_FIELDS (type)` on `RECORD_OR_UNION_TYPE_P (type)`; and in `s390_expand_builtin`, each `arg` must be checked against `error_mark_node` and (when `O_IMM_P (op_flags)` holds) verified to be `INTEGER_CST` before calling `s390_const_operand_ok` (which must check `tree_fits_uhwi_p`/`tree_fits_shwi_p`). [F50, F51]

## External Contracts

- `s390_scalar_mode_supported_p` and `s390_libgcc_floating_mode_supported_p` must only report `HFmode` as supported when `TARGET_Z10` is enabled; `s390_call_saved_register_used` must reject sibling calls passing an argument in a call-saved register (like `%r6`) unless it is a default-definition `SSA_NAME` of a `PARM_DECL` whose `DECL_INCOMING_RTL` occupies the exact same register; and `DWARF_FRAME_REGISTERS` in `s390.h` must remain `34`. [F73, F74, F114]

## Known Pitfalls

- Every `#include` of `s390-builtins.def` or `s390-builtin-types.def` in `s390-builtins.h` and `s390-c.cc` must first `#undef` and `#define` all entry macros (`B_DEF`, `OB_DEF`, `OB_DEF_VAR`, or the `DEF_*_TYPE` family); in `s390.cc`, `"target-def.h"` must be included last among top-level includes and before any `#undef`/`#define` of `TARGET_*` hooks, and all `TARGET_*` overrides must precede `struct gcc_target targetm = TARGET_INITIALIZER;` (after headers defining any guarding macros like `S390_USE_TARGET_ATTRIBUTE`). [F9, F43, F44]
- New builtin facility flags in `s390-builtins.def` (such as `B_NNPA` or `B_Z17`) are not enforced unless corresponding `!TARGET_*` checks are added to both `s390_resolve_overloaded_builtin` in `s390-c.cc` and `s390_expand_builtin` in `s390.cc`. [F35]
- In `s390-c.cc`, overloaded builtin argument and return conversions must use `fully_fold_convert` (not bare `fold_convert`), which only calls `c_fully_fold` when `!c_dialect_cxx ()`; and in `s390_adjust_builtin_arglist` (`S390_OVERLOADED_BUILTIN_s390_vec_load_bndry` arg 1) and `fully_fold_convert`, C++ `NON_LVALUE_EXPR` wrappers must be stripped before checking `INTEGER_CST` and re-wrapped when `c_dialect_cxx ()` holds. [F15, F19]
- Because middle-end condition inversion flips the comparison code on `CC_REGNUM` without changing its mode, `CCVIALLmode`/`CCVFALLmode` and `CCVIANYmode`/`CCVFANYmode` represent ALL/ANY only for `EQ`, `GT`, and `GE`, and represent the opposite (ANY/ALL) for inverted codes (`NE`, `LE`, `LEU`, `UNLE`, `UNLT`), so `s390_expand_vec_compare_gen_cc` must invert `all_p` for those codes. [F28]
- In `s390.cc`: in `s390_md_asm_adjust`, copying the second half of a `TFmode` `"f"`-constrained hard FP register (`s390_hard_fp_reg_p`) under `TARGET_VXE` must use `gen_vec_permiv2df` (not a `DFmode` subreg); `s390_split_access_reg` must split a `DImode` access register using `gen_rtx_REG (SImode, REGNO (reg) + 1)` (low) and `REGNO (reg)` (high), never `gen_lowpart`/`gen_highpart`; `s390_expand_builtin` and `s390_rawmemchr` must truncate `CONST_INT` scalar operands with `trunc_int_for_mode`; `s390_valid_shift_count` must validate `AND` masks with `const_int_operand` (not `immediate_operand`) before `INTVAL`; and `s390_rtx_costs` must check that an `IF_THEN_ELSE` condition `cond` has class `RTX_COMPARE` or `RTX_COMM_COMPARE` before accessing `XEXP (cond, 0/1)`. [F66, F67, F69, F77, F78]
- In `s390.md`: in `stack_protect_set` and `stack_protect_test`, `#ifdef TARGET_THREAD_SSP_OFFSET` inside the `else` branch must stay enclosed within the `else` branch's `{ ... }` braces; in `usubc<mode>5`, `general_operand` inputs passed to `gen_xor<mode>3` or `gen_sub<mode>3_borrow_cc` must use `force_reg` when `CONSTANT_P` holds; in `addv<mode>4`, constants failing `addv_const_operand` must use `force_reg` and `VOIDmode` constants must be sign-extended via `simplify_unary_operation (SIGN_EXTEND, ...)`; and post-reload `define_split` patterns for `*cpymem_short`, `*clrmem_short`, and `*cmpmem_short` must match the unused scratch with `(clobber (match_scratch N))` rather than `(clobber (scratch))`. [F84, F100, F103, F112]
