# rtl-optimization

This unit implements GCC's core Register Transfer Language (RTL) representation, analysis (`rtlanal.cc`), algebraic simplification (`simplify-rtx.cc`), instruction recognition and transactional changes (`recog.cc`), RTL dump/MD parsing (`read-rtl*.cc`), the Integrated Register Allocator (`ira*.cc`), and major RTL optimization passes including instruction combination (`combine.cc`), if-conversion (`ifcvt.cc`), loop invariant motion and `doloop` lowering (`loop-*.cc`), basic-block reordering/partitioning (`bb-reorder.cc`), store-forwarding avoidance, stack adjustment combination, redundant extension elimination (`ree.cc`), and hard-register copy propagation (`regcprop.cc`).

## Architecture & Data Flow

- Fixed/dynamic table bounds: in `combine.cc`, guard `REG_N_SETS (regno)` with `regno < reg_n_sets_max`, never call `INSN_COST` or `LOG_LINKS` on insns with `INSN_UID > max_uid_known`, and split insns only via `combine_split_insns` (which grows `reg_stat`); in `ree.cc` (`find_and_remove_re`), emit `reinsn_copy_list` copies only after the candidate loop since UID tables are sized once to `max_insn_uid`; in `bb-reorder.cc`, grow `bbd` before indexing with a new block; in `ira-build.cc`, bound `ira_bb_nodes` in `finish_loop_tree_nodes` by `last_basic_block_before_change` and do not index `ira_regno_allocno_map` with post-emit regnos before `rebuild_regno_allocno_maps`; in `loop-invariant.cc`/`loop-iv.cc`, call `check_invariant_table_size ()` / `check_iv_ref_table_size ()` before indexing. [F5, F59, F60, F68, F118, F119, F182, F183, F243]
- `combine.cc` value tracking: `init_reg_last` clears `reg_stat_type` via `memset (p, 0, offsetof (reg_stat_type, sign_bit_copies))`, so flow-sensitive fields must precede `sign_bit_copies` and whole-function fields (`sign_bit_copies`, `nonzero_bits`) must be at or after it, with `nonzero_sign_valid == 0` until the initial scan finishes; `record_value_for_reg` must set `last_set_invalid = true` if `last_set_table_tick >= label_tick_ebb_start` and replace prior `tem` with `CLOBBER` if `count_occurrences (value, reg, 1) >= 2` and `count_rtxs (tem) > param_max_last_value_rtl`; `get_last_value_validate` invalidates non-readonly `MEM`s when `tick != label_tick` or `DF_INSN_LUID (insn) <= mem_last_set`; across EBBs, `last_set_*` is valid only for single-set non-entry-live pseudos. [F61, F70, F71, F74, F75, F91]
- Subregs and paradoxical high bits: `partial_subreg_p`, `paradoxical_subreg_p`, `read_modify_subreg_p`, `subreg_get_info`, and `maybe_mode_change`/`copy_value` (`regcprop.cc`) require `ordered_p` on mode precisions/sizes; a `SUBREG` destination is a read-modify-write when `read_modify_subreg_p` holds; `general_operand` rejects paradoxical `SCALAR_FLOAT_MODE_P` subregs when `!lra_in_progress`; never drop an outer mask/commute `SUBREG` inward across `NOT` (`non_paradoxical_subreg_not_p`) or `LSHIFTRT` or distribute `(and (xor B C) (not A))` when paradoxical subregs are present; in `ree.cc` (`combine_reaching_defs`), when `copy_needed` under `WORD_REGISTER_OPERATIONS` and precision `< BITS_PER_WORD`, reject if any non-debug use is `paradoxical_subreg_p`; in `ira.cc`, pseudos with `pdx_subregs` never get `MEM` equivalences. [F85, F212, F278, F283, F293, F334, F335, F383]
- `WORD_REGISTER_OPERATIONS` and `simplify_subreg`: in `rtlanal.cc` (`nonzero_bits1`, `num_sign_bit_copies1`), propagating upper bits to a wider mode/paradoxical `SUBREG` requires `WORD_REGISTER_OPERATIONS && word_register_operation_p (x)` (and matching `load_extend_op` for `MEM`); in `simplify-rtx.cc`, `simplify_truncation` must use `simplify_gen_unary (TRUNCATE, ...)` (not `SUBREG`) and not distribute `TRUNCATE` over `PLUS`/`MINUS`/`MULT` when `precision < BITS_PER_WORD` under `WORD_REGISTER_OPERATIONS`, and `AND` must query `nonzero_bits (trueop0, word_mode)` for sub-word modes; in `simplify_subreg`, modes must not be `VOIDmode`/`BLKmode`, hard-reg folding via `simplify_subreg_regno` copies `ORIGINAL_REGNO` only on lowpart offsets, and `SUBREG_PROMOTED_VAR_P` is copied only onto non-paradoxical lowpart subregs. [F340, F379, F384, F385, F386, F393]
- Vector/float constant subregs and trapping/FP folds: compute vector element bit-sizes via `vector_element_size (GET_MODE_PRECISION (mode), GET_MODE_NUNITS (mode))` (for `MODE_VECTOR_BOOL`); `simplify_const_vector_subreg` rejects `paradoxical_subreg_p` and rejects `CONST_VECTOR_STEPPED_P` when inner modes differ; `simplify_immed_subreg` on `FLOAT_MODE_P` must re-encode via `native_encode_rtx` and verify byte equality; `vec_duplicate_p` requires `!VECTOR_MODE_P` on its inner operand; in `may_trap_p_1`, `MEM_NOTRAP_P` only bypasses `rtx_addr_can_trap_p_1` when `!code_changed`, `SYMBOL_REF_WEAK` always potentially traps/is zero, comparisons check `HONOR_SNANS`/`HONOR_NANS` on operands, and FP folds in `simplify-rtx.cc`, `combine.cc`, and `ifcvt.cc` must check `HONOR_NANS`, `HONOR_SNANS`, `HONOR_SIGNED_ZEROS`, `flag_trapping_math`, and `flag_rounding_math`. [F97, F151, F327, F329, F338, F344, F374, F387, F388, F396, F397, F398, F400]
- Auto-increment (`RTX_AUTOINC` / `REG_INC`): only valid inside `MEM` addresses (`info->mode != VOIDmode` for inc/dec; `{PRE,POST}_MODIFY` requires `(plus base step)` with `rtx_equal_p` base); in `combine.cc`, `subst` returns `CLOBBER` when substituting `CONST_SCALAR_INT_P` into `RTX_AUTOINC`, and `try_combine` must never duplicate `REG_INC` or combine across overlapping `REG_INC` on `i3`; in `ifcvt.cc`, `noce_get_condition`, `noce_operand_ok`, and `noce_process_if_block` reject `side_effects_p`; in `ira.cc`, auto-inc/`REG_INC` invalidate equivalences and `equiv_init_movable_p` rejects them; in `recog.cc`/`regcprop.cc`, never substitute into `RTX_AUTOINC` operands, reject `REG_INC` overlapping stored regs in `insn_invalid_p`, and require `'<'`/`'>'` constraints for auto-inc `MEM`s in asm. [F92, F156, F215, F286, F287, F342]
- Exception handling and CFG updates: in `combine.cc`, `distribute_notes` only allows `REG_EH_REGION` with `lp_nr > 0` from `i3` (kept on non-call `i3` only if `may_trap_p (i3)`), and `try_combine` simplifying into an unconditional jump/return/`TRAP_IF` must update CFG edges and set `*new_direct_jump_p = 1`; in `recog.cc` (`split_all_insns`, `peep2_attempt`) and `regcprop.cc` (`pass_cprop_hardreg::execute`, `copyprop_hardreg_forward_1`), deleting or splitting trapping/`REG_EH_REGION` insns must use `delete_insn_and_edges`, split basic blocks on non-final throwing/nonlocal-goto peephole2 insns, purge dead edges, and run `cleanup_cfg (0)`; in `bb-reorder.cc`, `create_eh_forwarder_block` must split `old_bb` via `split_block_after_labels` so EH landing pads keep only EH preds. [F48, F78, F79, F267, F268, F271, F272]
- Store-forwarding (`avoid-store-forwarding.cc`) and stack adjustments (`combine-stack-adj.cc`): in `process_store_forwarding`, moving `stores[move_to_front]` to execute first after `load_insn` requires moving it to the back of `stores` (`safe_push` then `ordered_remove`), overlapping stores in `forwarded_bytes` must `return false`, hard-reg `CLOBBER`s in `bits_insert_insns` must not intersect `m_bb_live_after.get (load_insn)`, and `outer_mode != load_mem_mode` extensions must be re-applied even when `!load_elim`; in `avoid_store_forwarding`, increment `removed_count` whenever setting `it->remove = true` and truncate `store_exprs` on `!single_set`, `insn_could_throw_p`, `BLKmode`, or non-constant `MEM_SIZE`; in `combine_stack_adjustments_for_block`, stack allocations only combine into the first adjustment `last_sp_set` and deallocations never combine with a preceding allocation. [F2, F3, F26, F37, F38, F41, F42, F44]
- If-conversion (`ifcvt.cc`): every path emitting into `test_bb` (`end_ifcvt_sequence`, `noce_convert_multiple_sets`, `find_cond_trap`) must reject when `noce_clobbers_live_cc_p (test_bb, seq)` holds; `find_cond_trap` and `noce_find_if_block` require `!reload_completed` and non-`BLKmode` conditions; `noce_try_minmax`/`noce_try_abs` write `noce_get_alt_condition` results to `if_info->cond`/`cond_earliest` (and clear `rev_cond`) only after `end_ifcvt_sequence` succeeds; hoisting insns above a branch must strip `REG_EQUAL` notes. [F116, F139, F159, F163, F169]
- `noce_convert_multiple_sets` (`ifcvt.cc`): require pseudo `SET_DEST`s and `!contains_mem_rtx_p (src)`; map `count >= then_count` via `else_only_indices[(unsigned) count - then_count]`; scan `dests` backwards in `init_noce_multiple_sets_info`; clamp `*last_needs_comparison` from `-1` to `0` after pass 1 (allocating pass 2 temps only when `count < *last_needs_comparison`); emit final target moves in reverse once per `REGNO`. [F102, F108, F140, F154, F165, F166]
- IRA (`ira-build.cc`, `ira.cc`) and `loop-invariant.cc`: `ira_allocnos`, `ira_object_id_map`, `ira_prefs`, and `ira_copies` alias internal `vec` buffers, so every `safe_push` must refresh the global pointer/length; set `regno_allocno_map = NULL` when skipping/freeing a loop node; when propagating `ALLOCNO_CALLS_CROSSED_NUM`, also OR `ALLOCNO_CROSSED_CALLS_ABIS` and `ALLOCNO_CROSSED_CALLS_CLOBBERED_REGS`; when `lra_simple_p` triggers (via `get_max_insn_count ()`, not `get_max_uid ()`), set `flag_ira_region = IRA_REGION_ONE` and `ira_conflicts_p = false` and restore flags before returning; under `flag_ira_loop_pressure`, index `N_REG_CLASSES` arrays by `ira_pressure_classes[i]`. [F130, F132, F162, F175, F185, F227]
- Hard-register copy propagation (`regcprop.cc`): `kill_value_regno` must kill all constituent regs of any lower multi-reg entry overlapping `regno`; reject narrowing that reduces `REG_NREGS` if `maybe_ne (subreg_lowpart_offset (...), 0U)`; reject `incompatible_frame_status` on `RTX_FRAME_RELATED_P` insns and never replace explicit register asm operands (`register_asm_p` or `REGNO == ORIGINAL_REGNO`); run `df_analyze ()` unconditionally after each pass without `DF_LR_RUN_DCE`. [F236, F273, F279, F290, F297]
- `recog.cc` and `rtlanal.cc` iterators: `cancel_changes` must revert `changes` in reverse order (`num_changes - 1` down to `num`), and `cancel_changes`/`swap_change` must set `recog_data.insn = nullptr` when restoring/swapping `INSN_CODE` on `recog_data.insn`; any non-static `recog_data_d` must initialize `insn = nullptr`; in `peep2_insn_data`, slot `peep2_buf_position (peep2_current + peep2_current_count)` holds `PEEP2_EOB` and post-window `live_before`; in `generic_subrtx_iterator<T>::add_subrtxes_to_queue`, assign `add_single_to_queue` back to `base`; in `vec_rtx_properties_base::grow (start)`, reset `ref_iter = ref_begin + start`; in `nonzero_bits1`, never call `num_sign_bit_copies` and keep binary arithmetic cases in sync with `*_binary_arith_p`. [F234, F240, F269, F294, F301, F304, F305, F306, F331]

## Object Lifetimes

- Explicit cleanup: in `try_combine`, every return after `SUBST` must call `undo_all ()` or `undo_commit ()`; in `combine_stack_adjustments_for_block`, every reset of `last_sp_set` or return must call `free_csa_reflist (reflist)` and `BITMAP_FREE (copy)`; in `avoid-store-forwarding.cc`, call `m_bb_live_after.remove (load_insn)` before `delete_insn (load_insn)`; in IRA, call `ira_remove_allocno_prefs (a)` before `finish_allocno (a)`, set `OBJECT_LIVE_RANGES (from_obj) = NULL` in `move_allocno_live_ranges`, set `ira_copies[cp->num] = NULL` after `finish_copy (cp)`, and return cost vectors to the matching `aclass` pool before `finish_cost_vectors`; in `regcprop.cc`, when `cprop_hardreg_bb` copies `all_vd[single_pred (bb)->index]` (never across `EDGE_EH` or `EDGE_ABNORMAL_CALL`), null `all_vd[bb->index].e[regno].debug_insn_changes` without calling `free_debug_insn_changes`. [F22, F25, F66, F133, F134, F135, F136, F259, F260, F274]

## API Contracts

- In `combine.cc`, `combine_validate_cost` and `recog_for_combine_1` must temporarily set `INSN_CODE (insn)` (with `PATTERN` and `REG_NOTES`) to the recognized candidate code before calling `insn_cost`, `extract_insn`, or `targetm.legitimate_combined_insn`, and restore old values afterward; `recog_for_combine_1` must reject any candidate with `'{'` in `recog_data.constraints`; in `recog.cc`, never call `validate_change_1`, `confirm_change_group`, or `cancel_changes` while `undo_recog_changes::is_active ()`. [F94, F99, F100, F235]
- `subreg_get_info` does not check `REG_CAN_CHANGE_MODE_P`, `HARD_REGISTER_NUM_P`, or `targetm.hard_regno_mode_ok`; callers replacing a hard-reg `SUBREG` with a `REG` must call `simplify_subreg_regno` (and in `set_noop_p`, check `validate_subreg` first); in `simplify-rtx.cc`, callers of `native_encode_rtx` must pre-reserve `num_bytes` in `bytes` (and `native_encode_rtx` must `truncate (start)` on failure), and lowpart conversions on arbitrary RTX must use `rtl_hooks.gen_lowpart_no_emit` (not `gen_lowpart`). [F336, F353, F363, F367, F378]
- RTX accessors and multi-reg/ABI queries: check `CONSTANT_POOL_ADDRESS_P` before `SYMBOL_REF_DECL` vs `CONSTANT` and `SYMBOL_REF_HAS_BLOCK_INFO_P` before `SYMBOL_REF_BLOCK` (reallocating to `RTX_HDR_SIZE + sizeof (struct block_symbol)` in `read-rtl-function.cc`); check `VOIDmode` vs float on `CONST_DOUBLE`, `MEM_OFFSET/SIZE_KNOWN_P` on `MEM`, `DEBUG_BIND_INSN_P` before `INSN_VAR_LOCATION*`, `LABEL_P (JUMP_LABEL (insn))` before `jump_target ()`, and `INSN_P` / `REG_P` on `REG_NOTES`; iterate all `[REGNO (x), END_REGNO (x))` in `try_to_add_reg` and `dead_or_set_p`, and query `insn_callee_abi (insn)` directly (`full_and_partial_reg_clobbers ()` / `caller_save_regs`) for partial/full call clobbers. [F217, F226, F262, F319, F320, F321, F322, F323, F324, F326, F347, F348]

## Error Handling

- When `recog_for_combine` performs speculative `SUBST` modifications after `get_undo_marker ()`, it must call `undo_to_marker (marker)` if `recog_for_combine_1` fails; in `combine-stack-adj.cc`, `force_move_args_size_note` must never move a `REG_ARGS_SIZE` note across `CALL_P` or `!insn_nothrow_p` insns. [F36, F67]

## External Contracts

- `pass_partition_blocks::gate` (`bb-reorder.cc`) must reject hot/cold partitioning when `!optimize_function_for_speed_p (fun)`, `DECL_COMDAT_GROUP`, `"section"`/`"naked"` attributes, or `in_lto_p && MAIN_NAME_P`; in `setup_incoming_promotions` (`combine.cc`), language-level promotion (`mode1 != mode2`) may be recorded only if `strictly_local` and `uns1 || !uns3`. [F34, F93]

## Known Pitfalls

- Headers, `DEBUG_INSN`s, and `recog_data`: `tm.h`/`backend.h` must precede `rtl.h`, `bb-reorder.h` (`SWITCHABLE_TARGET`), `pass_stack_adjustments::gate` (`PUSH_ROUNDING`), and `#ifndef MAX_CONDITIONAL_EXECUTE` in `ifcvt.cc`; keep `#include "insn-attr.h"` in `combine.cc` (`INSN_SCHEDULING`), `#include "tm_p.h"` in `ifcvt.cc`, `rtlhooks-def.h` before `RTL_HOOKS_*` in `combine.cc`, and `bconfig.h`/`#undef ENABLE_RTL_CHECKING` before `rtl.h` in `read-rtl.cc`; filter insn scans in `can_combine_p` and `noce_get_alt_condition` with `NONDEBUG_INSN_P`; in `copyprop_hardreg_forward_1`, re-run `extract_constrain_insn` and `preprocess_constraints` whenever a speculative `validate_change` fails and falls through. [F13, F15, F63, F64, F98, F123, F124, F164, F238, F251, F252, F313]
- Reversals, `combine.cc`, `simplify-rtx.cc`, and `rtlanal.cc`: in `ifcvt.cc`, check `reversed_comparison_code` / `noce_reversed_cond*` for `!= UNKNOWN`, and in `simplify_unary_operation_1` guard `STORE_FLAG_VALUE` under `NOT` with `SCALAR_INT_MODE_P (mode)`; in `combine.cc`, never call `force_const_mem` when `SET_DEST (pat) == pc_rtx`, unwrap `PARALLEL` on `newi2pat` before `SET_DEST`, and check `make_compound_operation` for `CLOBBER` before `simplify_subreg`; in `simplify-rtx.cc`, shallow-copy in `simplify_replace_fn_rtx` on first change, and in `simplify_plus_minus` reject `(const (ncode lhs rhs))` wraps and check `n_ops != ARRAY_SIZE (ops)` before `n_ops++`; in `nonzero_bits1`, unary bit-count ops must use inner `op_mode_width` (bailing out on `CLZ`/`CTZ` if `op_mode != mode`) and only apply `REGNO_POINTER_ALIGN` to `stack`/`frame`/`arg_pointer_rtx`. [F57, F95, F101, F150, F167, F332, F333, F360, F364, F371, F381]
