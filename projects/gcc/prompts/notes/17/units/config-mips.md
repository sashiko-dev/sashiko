# config-mips

This unit (`gcc/config/mips`) defines core target architecture macros, command-line options, RTL instruction patterns, operand predicates, DFA pipeline descriptions, MSA C intrinsics, and subtarget configurations (`mti-elf.h`, `mti-linux.h`, `n32-elf.h`, `netbsd.h`, `r3900.h`, `rtems.h`) for the MIPS backend in GCC.

## Architecture & Data Flow

- In `mips.h`, `COP0`, `COP2`, and `COP3` hardware register numbers must remain contiguous from `COP0_REG_FIRST` through `COP3_REG_LAST` because `ALL_COP_REG_NUM` and `ALL_COP_REG_P` test membership with a single range check across that span. [F1]
- In `mips.h`, `enum reg_class` entries must be ordered so a larger-numbered class is never completely contained in a smaller-numbered class, and `REG_CLASS_NAMES` and `REG_CLASS_CONTENTS` must have one entry per class in the exact `enum reg_class` order. [F2]
- In `mips.h`, `FIRST_PSEUDO_REGISTER` (188) bounds hardware register indices; `FIXED_REGISTERS`, `CALL_REALLY_USED_REGISTERS`, `REG_ALLOC_ORDER`, and `REGISTER_NAMES` must each contain entries for all `FIRST_PSEUDO_REGISTER` hardware registers. [F3]
- In `mips.h`, declarations and types depending on host compiler internals (`struct mips_asm_switch`, `struct mips_frame_info`, `struct machine_function`, `rtx`, `HOST_WIDE_INT`, `reg_class`, `GTY(())`, and backend globals) must stay inside `#ifndef USED_FOR_TARGET`. [F6]
- When `IN_LIBGCC2` is defined, `mips.h` must `#undef TARGET_64BIT` (removing the `options.h` definition referencing runtime `target_flags`) and redefine it as a preprocessor constant (`1` or `0`) based on `__mips64` so layout macros like `UNITS_PER_WORD` are compile-time constants in `libgcc`. [F7]
- Target headers `mips.h` and `n32-elf.h` must not define `MAX_FIXED_MODE_SIZE` to `MIPS_LONG_DOUBLE_TYPE_SIZE` because `TARGET_64BIT` targets support 128-bit `TImode` integers (`movti`) even when `MIPS_LONG_DOUBLE_TYPE_SIZE` is 64. [F11]
- In `mips.h` and `mips.md`, `PROMOTE_MODE` must set `UNSIGNEDP = 0` when promoting `SImode` to `Pmode` (`DImode`) on 64-bit targets, `LOAD_EXTEND_OP` must return `SIGN_EXTEND` for `SImode` and `ZERO_EXTEND` for `QImode`/`HImode`, and `truncdi<mode>2` must emit `sll %0,%1,0` for register destinations so `SImode` registers stay sign-extended. [F19]
- In `mips.md`, `move_doubleword_fpr<mode>` and its helpers (`load_low<mode>`, `load_high<mode>`, `store_word<mode>`, `mthc1<mode>`, `mfhc1<mode>`) must keep the FPR operand in `SPLITF` mode in the RTL pattern and apply `mips_subword` only to the non-FPR operand or during assembly output. Broken by: wrapping the FPR operand in a word-mode `subreg` before assembly emission. [F12]
- In `mips.md`, patterns reading or writing the `HI` register (`mfhi<GPR:mode>_<HILO:mode>`, `mthi<GPR:mode>_<HILO:mode>`) must represent the accumulator as a full `HILO`-mode register (`DImode` for `!TARGET_64BIT`, `TImode` for `TARGET_64BIT`) at `MD_REG_FIRST` using `UNSPEC_MFHI` or `UNSPEC_MTHI` rather than `(reg:GPR HI_REGNUM)`. [F13]
- In `predicates.md`, `splittable_const_int_operand` must return `false` when `GET_MODE_SIZE (mode) > UNITS_PER_WORD` so `move_operand` accepts multi-word `CONST_INT`s and defers splitting them into word-mode moves until after `reload_completed`. [F15]
- In `mips.h` and `mips.md`, general addresses disallow index registers (`INDEX_REG_CLASS` is `NO_REGS`, `REGNO_OK_FOR_INDEX_P` is `0`, `MAX_REGS_PER_ADDRESS` is `1`), and `(mem:ANYF (plus:P reg reg))` must be matched only by `*<ANYF:loadx>_<P:mode>` and `*<ANYF:storex>_<P:mode>` when `ISA_HAS_LXC1_SXC1`. [F17]
- In `mips.md`, `mov<mode>cc` on `GPR` must `FAIL` when `!ISA_HAS_FP_CONDMOVE && !INTEGRAL_MODE_P (GET_MODE (XEXP (operands[1], 0)))`, and `mov<mode>cc` on `SCALARF` must `FAIL` when `ISA_HAS_SEL` if `!FLOAT_MODE_P (GET_MODE (XEXP (operands[1], 0)))` or `<MODE>mode == DFmode && (!TARGET_ODD_SPREG || TARGET_FLOATXX)`. [F14]
- In `mips.md`, the 64-bit `ISA_HAS_EXTS` sign-extraction pattern matching `(ashiftrt:SI (truncate:SI (ashift:DI ...)))` must include the explicit `truncate:SI` between `ashift:DI` and `ashiftrt:SI` and require `UINTVAL (operands[2]) < 32 && UINTVAL (operands[3]) < 32 && UINTVAL (operands[3]) >= UINTVAL (operands[2])`. [F16]
- In `mips.md`, `<u>mulditi3` and `<su>muldi3_highpart` must allow `ISA_HAS_R6DMUL` in addition to `ISA_HAS_DMULT && !(<CODE> == ZERO_EXTEND && TARGET_FIX_VR4120)`, decomposing `<u>mulditi3` into `muldi3_mul3_nohilo` (`mips_subword(operands[0], 0)`) and `<su>muldi3_highpart_r6` (`mips_subword(operands[0], 1)`) when `!ISA_HAS_DMULT`. [F23]
- In `mips.md`, `<optab>_internal` (`return_internal` and `simple_return_internal`) must pass its matched `operands[0]` (`pmode_register_operand`) directly to `mips_output_jump (operands, 0, -1, false)` without overwriting `operands[0]` with `RETURN_ADDR_REGNUM`. [F24]
- In `mips.md`, floating-point `abs<mode>2` and `neg<mode>2` must be guarded by `mips_abs == MIPS_IEEE_754_2008 || !HONOR_NANS (<MODE>mode)` because `MIPS_IEEE_754_LEGACY` `abs.<fmt>` and `neg.<fmt>` instructions trap on NaN inputs instead of only updating the sign bit. [F28]
- In `mips.md`, patterns emitting non-R6 `nmsub.<fmt>` (`-((op1 * op2) - op3)`) or `nmadd.<fmt>` (`-((op1 * op2) + op3)`) for `fnma<mode>4` (`*fnma<mode>4_nmsub3`, `*fnma<mode>4_nmsub4`), `fnms<mode>4` (`*fnms<mode>4_nmadd3`, `*fnms<mode>4_nmadd4`), `*nmadd4<mode>_fastmath`, or `*nmsub4<mode>_fastmath` must require `!HONOR_SIGNED_ZEROS (<MODE>mode)` because factoring out the outer negation flips the sign of a zero result. [F29]
- In `mips.h` and `mips.md`, `divide_condition` must disable `SFmode` and `V2SFmode` division when `TARGET_FIX_SB1 && !flag_unsafe_math_optimizations`, and `ISA_HAS_FP_RECIP_RSQRT(MODE)` (`*recip<mode>3`, `*rsqrt<mode>a`, `*rsqrt<mode>b`) must require `flag_unsafe_math_optimizations` and disallow `DFmode` on pre-R2 ISA levels when `!TARGET_FLOAT64`. [F30]
- In `mips.md`, `(define_automaton "alu,imuldiv")` and its `alu`/`imuldiv` CPU units must precede all processor pipeline `(include ...)` directives, and `(include "generic.md")` must appear after all processor-specific pipeline `.md` includes (`p5600.md`, `p6600.md`, `octeon.md`, etc.). [F9]

## Object Lifetimes

- In `MIPS_CPP_SET_PROCESSOR` in `mips.h`, the heap buffer returned by `concat ((PREFIX), "_", (INFO)->name, NULL)` is only borrowed by `builtin_define` and must be released with `free (macro)` before exiting the macro block. [F10]

## API Contracts

- In `mips.h` (`MIPS_ICACHE_SYNC`), calls to `emit_library_call` must use the typed overload `emit_library_call (sym, LCT_NORMAL, VOIDmode, arg1, mode1, ...)` without an integer parameter-count argument that would pass `machine_mode` objects through C variadic `...` parameters. [F21]

## External Contracts

- In `mips.h` and `mips.md`, when targeting O32 (`mips_abi == ABI_32`), `FUNCTION_ARG_REGNO_P(N)` must reject odd-numbered FPRs when `!TARGET_FLOAT32`, and the `enabled` attribute in `mips.md` must disable `dword_mode` `mtc` and `mfc` alternatives when `(TARGET_FLOATXX && !ISA_HAS_MXHC1) || TARGET_O32_FP64A_ABI`. [F20]
- Every `Target` option entry in `mips.opt` for a `-m*` command-line flag (such as `mmad`) must include the leading `m` in the option header name, because GCC's option parser matches the entry name directly after `-`. [F35]
- In `TARGET_CPU_CPP_BUILTINS()` in `mips.h`, `builtin_define ("mips")` must be guarded by `!flag_iso && !TARGET_VXWORKS`, and in `netbsd.h`, the overridden `TARGET_CPU_CPP_BUILTINS()` must not define `R3000`, `_R3000`, `R4000`, or `_R4000`. [F36]

## Known Pitfalls

- Because `elfos.h` and `*-stdint.h` precede `mips/mips.h` in `tm_file`, `mips.h` must `#undef` macros already defined there (`ASM_DECLARE_OBJECT_NAME`, `ASM_OUTPUT_BEFORE_CASE_LABEL`, `SIZE_TYPE`, `PTRDIFF_TYPE`) before redefining them, or guard fallback defaults with `#ifndef`. Likewise, because `mips/mips.h` precedes subtarget headers (`mti-elf.h`, `mti-linux.h`, `n32-elf.h`, `netbsd.h`, `r3900.h`, `rtems.h`), subtarget headers overriding `mips.h` macros (`DRIVER_SELF_SPECS`, `MIPS_ABI_DEFAULT`, `MULTILIB_DEFAULTS`, `MIPS_DEFAULT_GVALUE`, etc.) must `#undef` them first. [F4, F5]
- Signed immediate range-checking macros in `mips.h` (`IMM10_OPERAND`, `SMALL_OPERAND`, and `LUI_OPERAND`) must cast `VALUE` to `unsigned HOST_WIDE_INT` before adding a positive offset (`+ 0x200`, `+ 0x8000`, or `+ 0x10000`) to avoid signed integer overflow when `VALUE` is negative. [F32]
- Boolean target options added to `mips.opt` (such as `mloongson-ext2`) must use `Var(TARGET_...)` instead of `Mask(...)` so they do not allocate new bits in `target_flags`. [F34]
- D front-end target hooks (`TARGET_D_CPU_VERSIONS` and `TARGET_D_REGISTER_CPU_TARGET_INFO`) must be defined in `mips-d.h` (included via `tm_d.h`), not in `mips.h`. [F8]
- In `mips.md`, multiply-accumulate patterns (`*mul_acc_si`, `*mul_acc_si_r3900`, `*macc`, `*msac`, `*msac_using_macc`, `*mul_sub_si`) whose output alternatives use the single-register `LO` constraint `"=l"` must constrain the accumulator input operand with `"l"` rather than matching constraint `"0"` when another alternative allows GPR (`"d"`) operands. [F22]
- In `mips.md`, bonded load patterns (`*join2_load_store<JOIN_MODE:mode>` on load alternatives and `*join2_loadhi`) must emit the second load (`operands[2]`, `operands[3]`) before the first load (`operands[0]`, `operands[1]`) whenever `reg_overlap_mentioned_p (operands[0], operands[1])` is true. [F26]
- In `mips.md`, `tls_get_tp_<mode>` and `tls_get_tp_mips16_<mode>` must accept any `"=d"` register for `operands[0]` with `(clobber (reg:P TLS_GET_TP_REGNUM))` before reload and only split into an explicit set of `(reg:P TLS_GET_TP_REGNUM)` when `reload_completed`. [F27]
- In the `builtin_longjmp` expander in `mips.md`, the saved frame pointer (`fp`) and global pointer (`gpv`) must be copied into temporary registers with `copy_to_reg` before `emit_stack_restore` and moved into `hard_frame_pointer_rtx` and `gp` only after `emit_insn (gen_blockage ())` and register clobbers. [F33]
- In `mips.md`, `fixuns_truncdfsi2`, `fixuns_truncdfdi2`, `fixuns_truncsfsi2`, and `fixuns_truncsfdi2` expanders must emit `emit_use (stack_pointer_rtx)` after their final `emit_label (label2)` before `DONE` so middle-end callers can attach `REG_NOTES` to the last emitted instruction. [F31]
- In `mips.md`, `prefetch` must normalize `operands[1]` from `const2_rtx` (read-shared) to `const0_rtx` (read) before calling `mips_loongson_ext2_prefetch_cookie` or `mips_prefetch_cookie`. [F25]
