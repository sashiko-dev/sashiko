# db

Persistence layer (`Database`, `DatabaseTransaction`) and SQL migrations over local SQLite or remote libSQL for patchsets, AI reviews, bug triage/analysis, maintainer attribution, and outboxes; exports shared wire types without `server`.

## Architecture & Data Flow
- SQL updates to `bugs.lifecycle_status` or `duplicate_of_id` must preserve `(lifecycle_status = 'duplicate') = (duplicate_of_id IS NOT NULL)` and `duplicate_of_id != id`. `mark_bug_as_duplicate` sets `pipeline_state = 'succeeded'` in the same statement while keeping `locked_by`/`lease_expires_at` when `self.bug_claim.is_some()` so `link_review_to_bug` can run before `release_bug_lease`. Automated updates (`update_bug_outcome`, `mark_bug_as_duplicate` with `preserve_triage`, `fail_bug_analysis`, `recover_stale_running_bugs`) only change `lifecycle_status` when `'new'`. [F2, F51, F83]
- Writes to `bugs.assignee` and `assigned_at` (`insert_bug`, `assign_bug`) must update both in one statement, normalizing whitespace-only strings to `NULL` and clearing `assigned_at` when `assignee` is `NULL`. Mutations of `lifecycle_status`, `title`, `duplicate_of_id`, `assignee`, or `bug_subsystems` must set `audit_author`, `audit_tool`, and `audit_model` on `bugs` in the same statement/transaction for `trg_bugs_audit_*` and `trg_bug_subsystems_audit_*`. [F3, F164]
- `insert_bug_enrichment` mirrors any `bug_enrichments` row with `tokens_in`/`tokens_out`/`tokens_cached` into `ai_interactions` (`id = format!("bug_enrichment:{id}")`), and `add_bug_enrichment` skips starting a transaction when `self.in_transaction` is true. `insert_bug_review` updates `is_newly_discovered` via `MAX(is_newly_discovered, excluded.is_newly_discovered)` on conflict, whereas deduplication (`mark_bug_as_duplicate`, `migrate_review_bugs`) inserts migrated links with `is_newly_discovered = 0` via `INSERT OR IGNORE`. [F6, F10]
- `Bug::severity` and trigger `trg_bug_enrichments_project_severity` must use identical precedence on `severity_calibration` `data_json`: `$.severity` string (`critical`=4..`low`=1) wins over `$.severity_int`, else `0` (`Severity::Unknown`). `list_bugs`, `claim_open_bug_for_fix_check`, and `list_open_bugs_for_fix_check` filter/sort via projected indexed columns (`severity_int`, `verified_on_sha`, `introducing_commit_sha`, `fixed_in_commit_sha`), not `json_extract` subqueries, and recursive CTEs over `bugs.duplicate_of_id` (`bug_family`, `bug_discovery_summaries`, `list_bugs`) must use `UNION`, not `UNION ALL`. [F88, F102, F106]
- Bug and embargoed patchset ACL checks must query `source = 'maintainers_section'` via `authorizing_sections_for_bug(s)` / `authorizing_sections_for_patchset(s)`, never `Bug::subsystems`, `get_subsystems_for_bug`, `patchset_maintainer_sections`, or `patchsets_subsystems`. `BugVisibility::default()` must be `BugVisibility::Sections(&[])` (zero rows), and non-empty `Sections` must filter `source = 'maintainers_section' AND subsystem COLLATE NOCASE IN (...)` in SQL before counts/pagination. Incremental `add_patchset_maintainer_sections` only upserts, whereas `replace_patchset_maintainer_sections` and `replace_bug_subsystems` prune removed sections. [F8, F9, F160]
- While `embargo_until > now`, `get_patchsets`, `get_patchset_details`, and `get_patchset_summary` must mask `'Reviewed'` as `'Embargoed'`, zero finding counts in `get_patchsets`, and omit `reviews` unless fetched via `get_embargoed_patchset_reviews` and `get_patchset_finding_counts`. `release_patchset_embargo` must set `embargo_until = now` (non-`NULL`) so `get_releasable_embargoed_patchsets` (`embargo_until IS NOT NULL`) flushes outboxes before `clear_patchset_embargo` clears it. [F14, F161]
- `update_patchset_status` guards non-`'Cancelled'` updates with `WHERE id = ? AND status != 'Cancelled'`, and `cancel_patchset` sets `patchsets.status = 'Cancelled'` before cancelling child reviews, patches, and outboxes. `CLOSED_TO_NEW_PARTS_SQL` and `is_closed_to_new_parts` must match: true when `status == 'Cancelled'`, or `status` in `('Reviewed', 'Failed', 'Failed To Apply')` with `received_parts >= total_parts`. [F13, F87]
- `adopt_series_identity` and `create_patchset_inner` must never assign a `cover_letter_message_id` owned by another `patchsets` row, nor overwrite a non-placeholder `0/N` cover letter (`identity_part_index` is `None`). In `create_patchset_inner`, the `format!("{message_id}@sashiko.local")` fallback is only used when `cover_letter_message_id.is_none() || total_parts == 1` with `AND thread_id = ?`; candidate matching requires `thread_compatible = same_thread || is_singleton || msgid_prefix_match` (splitting `Message-ID`s on `'-'`, prefix len > 10), rejects `index_collision` or mismatched `clean_subject` unless `is_same_series_redelivery`, and accepts messages already held (`patchset_holds_message`) even if closed or full. [F15, F16, F17, F136]
- `record_series_baseline` and `create_patchset_inner` overwrite `patchsets.baseline_id` only when `baseline_id IS NULL OR baseline_part_index IS NULL OR ? <= baseline_part_index`, and `received_parts` is always set via `SELECT COUNT(*) FROM patches WHERE patchset_id = ?` in `write_patch_transaction` and `create_patchset_inner`. Merging patchsets in `create_patchset_inner` must re-point/delete FK references on `bugs`, `reviews`, `email_outbox`, `patches_subsystems`, `patchsets_subsystems`, `patchset_maintainer_sections`, and `forge_outbox` before deleting duplicate `patches` and `merge_from_id`. Before setting `patchsets.slug` in `update_patchset_mr_metadata` or `create_fetching_patchset`, `rotate_mr_slug` renames any current holder to `{slug}-v{old_ver}` (or `-{old_id}`). [F18, F19, F23, F36]
- `reconcile_superseded_pr_patchsets` (`LIMIT 200` on `mr_number`) and `reconcile_superseded_series_patchsets` (30-day window, `LIMIT 100`) drop `rows` before `cancel_patchset` and always call `cancel_outbox_for_patchset` even if `cancel_patchset(old_id, true)` returns `false`. On startup, `reset_reviewing_status` resets `'In Review'`/`'Reviewing'` rows to `'Pending'`, while `fail_interrupted_fetching_patchsets` marks `'Fetching'` rows `'Failed'` without failing `'Incomplete'` mailing-list cover letters (`mr_url IS NULL`). `has_failed_review` and `rerun_patchset` match infra-failed reviews by `status IN ('Failed', 'FailedToApply') AND interaction_id IS NULL`; `rerun_patchset` deletes referencing `tool_usages` and `findings` before `reviews` and increments `target_review_count` only if prior status was `'Reviewed'`. [F115, F141, F142, F143, F165]
- Before claiming `'Pending'` rows, `lock_pending_email`, `lock_pending_patchwork`, and `lock_pending_forge_outbox` cancel rows in the same transaction if the patchset is `'Cancelled'`, a `'sign_in_link'` email expired past `SIGN_IN_LINK_LIFETIME_SECONDS`, or a newer PR revision exists. `insert_email_outbox` deduplicates by `patch_id` and `insert_patchwork_notification` by `(to_addresses, subject, in_reply_to)` with `patch_id IS NULL`, while `insert_transactional_email` never deduplicates; `insert_forge_outbox` skips if `'Cancelled'`, a newer `patchsets` row (`id > patchset_id`) exists for `(pr_number, repo)`, or a `forge_outbox` row exists for `patchset_id`. [F21, F146, F149]
- `get_messages` and `get_patchset_summary` select `NULL as body` and pass `include_logs = false` to `get_patchset_reviews_for_patches`, and thread message queries (`get_message_details`, `get_patchset_details`, `get_patchset_summary`, `build_search`) filter `subject != '(placeholder)'`. [F116, F167]

## Synchronization
- `Database` helpers locking `tx_lock` (`execute`, `execute_batch`, `query_returning_i64`, `get_bug_on_write_conn`, `ensure_person`, `ensure_subsystem`) skip locking `tx_lock` when `self.in_transaction` is true, and callers inside an active `DatabaseTransaction` invoke helpers via `self.with_connection((*tx).clone())`. Migrations 5 and 12 (`CREATE INDEX` on `patches`) run outside `begin_transaction`. [F25, F108]
- Queue claimers (`claim_pending_bug`, `claim_open_bug_for_fix_check`, `lock_pending_email`, `lock_pending_patchwork`, `lock_pending_forge_outbox`) use a single `UPDATE ... WHERE id = (SELECT id ... LIMIT 1) RETURNING ...` statement, and bug claimers (`claim_pending_bug`, `claim_open_bug_for_fix_check`, `claim_specific_open_bug_for_fix_check`) read the hydrated `Bug` via `get_bug_on_write_conn` on `tx_conn`, not `self.conn`. [F33, F34]
- `claim_pending_bug` requires `attempt_count < max_attempts`, and `abandon_exhausted_bugs` sets `attempt_count >= max_attempts` to `BugPipelineState::Abandoned`. `renew_bug_lease` requires `locked_by = worker_id`, `pipeline_state IN ('running', 'succeeded')`, and `lease_expires_at >= now`. `fail_bug_analysis` guards `UPDATE` with `(? = 0 OR pipeline_state = 'running')` (`?` = `self.bug_claim.is_some() as i64`) and errors if `self.bug_claim.is_some()` and 0 rows changed. [F31, F32, F105]
- `claim_open_bug_for_fix_check` and `claim_specific_open_bug_for_fix_check` clamp `lease_ttl_seconds` to `1..=86_400`, and `touch_bug_fix_check_timestamp` / `touch_open_bugs_fix_check_batch` set `lease_expires_at = now + 60` while bumping `updated_at`. `advance_open_bugs_without_llm_batch` and `touch_open_bugs_fix_check_batch` commit per `SUB_BATCH_SIZE` (100) chunk via `begin_immediate_transaction`. [F98, F114]
- `create_patch_with_git_patch_id` (`select_git_patch_id`) compresses/decompresses diffs outside `tx_lock`, preserves stored `git_patch_id` when re-ingesting with `git_patch_id: None` iff the decompressed stored diff equals the new diff (else `None`), verifies in `write_patch_transaction` via `write_patch_if_unchanged` that `(diff, git_patch_id)` match the pre-lock snapshot, and retries `PatchWriteOutcome::SnapshotChanged` up to `PATCH_WRITE_MAX_ATTEMPTS`. [F20, F35]
- `assign_bug` reads current `assignee`, updates `bugs` (`assignee`, `assigned_at`), inserts the optional comment enrichment, and queues the optional `TransactionalEmail` (when old/new assignees differ ignoring ASCII case) in one transaction. `get_releasable_embargoed_patchsets` and `claim_patchset_embargo_release` use a 600s lease on `embargo_release_started_at` and allow early release before `embargo_until <= now` only when `CLEAN_PATCHSET_PREDICATE` (`PatchsetReviewOutcome::Clean`) holds. [F41, F145]

## Object Lifetimes
- For file-backed SQLite, `Database::new` opens `tx_conn` alongside `conn`, sets `PRAGMA busy_timeout = 5000` and `PRAGMA foreign_keys = ON` on both, and routes writes/transactions through `tx_conn` under `tx_lock`. `with_bug_actor`, `with_bug_claim`, and `with_connection` scope `bug_actor`, `bug_tool`, `bug_model`, `bug_claim` (`BugAnalysisClaim`), and `in_transaction` by value to the returned `Database` while sharing `tx_lock`. [F45, F46]
- `DatabaseTransaction::commit` and `rollback` run raw `COMMIT`/`ROLLBACK` SQL on `self.tx` (rolling back if `COMMIT` fails while `!tx.is_autocommit()`), and `Drop` drops `self.tx` via `drop_quietly` (`catch_unwind`) before `_guard` releases `tx_lock`. Any `libsql::Rows` cursor on `tx_conn` or `DatabaseTransaction` must be drained/dropped before releasing `tx_lock` or executing writes and `tx.commit().await`. [F47, F122]
- `create_bug_with_enrichment` inserts `bugs`, `bug_subsystems`, `bug_vectors`, and the discovery `bug_enrichments` row in one transaction, and `update_bug_outcome` (`write_bug_outcome`) writes all outcome enrichments before setting `BugPipelineState::Succeeded` in the same transaction. When `self.bug_claim` is `Some(claim)`, `begin_bug_write` verifies `claim.bug_id == bug_id` and checks in an `IMMEDIATE` transaction that `locked_by = claim.owner`, `lease_expires_at >= now`, and `pipeline_state IN ('running', 'succeeded')` before any bug analysis write. `record_upstream_fix_check` (`write_upstream_fix_check`) guards `UPDATE bugs` with `lifecycle_status = 'open' AND (? IS NULL OR locked_by = ?)` and `rollback()`s returning `Ok(false)` without inserting enrichments if 0 rows changed. [F49, F50, F56]

## API Contracts
- Queries passed to `parse_bug_row_core` or `parse_bug_row` must select the exact 16 `BUG_ROW_COLUMNS` (`id` at 0..`updated_at` at 15), appending extras like `v.vector_json` at 16+. `BUG_ROW_COLUMNS` and `parse_bug_row_core` exclude `bug_vectors.vector_json`; only `list_all_bugs_for_vector_search` joins `bug_vectors`. [F75, F101]
- `SubsystemSource::default()`, `SubsystemSource::from_stored` on unknown strings, and `AttributedSubsystem::deserialize` on bare strings or objects without `source` resolve to `SubsystemSource::CallerSupplied`. Maintainer section calculation must use `patch_diffs_only`, not `get_patch_diffs` (which inner-joins `messages`). [F78, F89]
- `get_patchset_details` and `get_patchset_summary` select and serialize `p.status` (masked as `'Embargoed'` while `embargo_until > now`) and `p.apply_error` on each entry in `patches`. `get_stored_prerequisite_series` returns `Ok(None)` when missing or `received_parts < total_parts`, and `Err` when `total_parts > maximum_parts`, `received_parts > total_parts`, or a complete series has missing diffs or invalid/duplicate `part_index`. [F84, F95]
- `hydrate_bugs_batch` chunks `bugs` by `HYDRATE_CHUNK_SIZE` (200) for `IN (?)` queries, and page-level checks use batch helpers `authorizing_sections_for_bugs`, `authorizing_sections_for_patchsets`, and `get_patchset_finding_counts` (returning early when empty). `list_open_bugs_for_fix_check` clamps `limit` to `1..=250`, keyset-paginates by `(updated_at, id)` on `idx_bugs_fix_check`, and hydrates only `('verification', 'origin_discovery', 'candidate', 'raw_candidate')` with `NULL as logs`; `patchsets_missing_maintainer_sections` keyset-paginates (`WHERE p.id > ? ORDER BY p.id ASC LIMIT ?`), not `OFFSET`. [F97, F99, F112, F113]
- Without `feature = "server"`, `src/db.rs` exports shared wire/domain types (`Bug`, `PatchsetRow`, `MessageRow`, `Severity`, `BugLifecycleStatus`, `BugPipelineState`, `SubsystemSource`, `AttributedSubsystem`, `BugVisibility`, `EmailKind`) without `libsql`, gating `Database`, `DatabaseTransaction`, and SQL methods behind `#[cfg(feature = "server")]`. [F169]

## Error Handling
- `BugLifecycleStatus::from_str` and `BugPipelineState::from_str` return `Err` on unknown strings, whereas `EmailKind::from_stored` logs a warning and maps unknown strings to `EmailKind::Unrecognized` (`transactional_list_label` -> `None`) so `lock_pending_email` still delivers them. `lock_pending_email`, `lock_pending_patchwork`, `lock_pending_forge_outbox`, and `create_patchset` (`patch_part_index`, `identity_part_index`, `adopt_series_identity`) must propagate `rows.next().await?` errors. [F66, F68, F70]
- `create_message_with_references` runs all split-thread merge statements and the message upsert in one `IMMEDIATE` transaction. `claim_pending_bug`, `abandon_exhausted_bugs`, and `recover_stale_running_bugs` must match `pipeline_state = 'running' AND (lease_expires_at IS NULL OR lease_expires_at < ?)`. [F71, F72]

## External Contracts
- `bug_evidence`, `get_bug_enrichments`, and `hydrate_bugs_batch` omit raw `logs` (`NULL as logs`, stripping `data_json`, `logs`, and token fields from `bug_evidence` activity items), reserving full payloads/logs for `bug_family(id, true)` and `get_bug_logs`. After `Database::migrate`, `ensure_project_stamp` verifies `meta.key = 'project'` matches `ProjectId` (or inserts it) and errors on mismatch. [F86, F92]

## Known Pitfalls
- `create_baseline` queries `WHERE repo_url IS ? AND branch IS ? AND last_known_commit IS ?` (not `=`) so `NULL` columns match existing rows. Migrations creating temp tables on a shared connection (`_shadow_cover_fold` in `007_fold_shadow_cover_rows.sql`) must `DROP TABLE IF EXISTS temp.<name>` before `CREATE TEMP TABLE` and `DROP TABLE` after. Callers of `build_search` with `target == "patchset"` (`get_patchsets`, `count_patchsets`) must alias `patchsets` as `p`. [F134, F153, F168]
