# ai

The `ai` component defines the unified LLM abstraction (`AiProvider`, `AiRequest`, `AiResponse`, `LlmSession`) and implements HTTP API backends (Gemini, Claude, OpenAI-compatible, Ollama, vLLM, Bedrock, Vertex AI), CLI agents (`claude-cli`, `codex-cli`, `copilot-cli`, `devin-cli`, `kiro-cli`, `goose-cli`), and stdio IPC proxies (`stdio-gemini`, `stdio-claude`), plus SQLite caching, rate-limit/transient backoff, concurrency limiting, session orchestration, token truncation, and bug-vector similarity search.

## Architecture & Data Flow
- In `AiUsage`, `cached_tokens` is a subset of `prompt_tokens` (not an addend): `ClaudeClient`/`BedrockClient` fold `cache_read`/`cache_write` into `prompt_tokens`, `OpenAiCompatClient::translate_ai_response` drops (`None`, not clamps) `cached_tokens > prompt_tokens`, and `CachingAiProvider::generate_content` sets `usage.cached_tokens = Some(usage.prompt_tokens)` on cache hits. Gemini's `UsageMetadata::output_token_count` and `merge_continuation_response` must sum `thoughts_token_count` with `candidates_token_count` for `completion_tokens`. [F1, F2, F63, F143]
- In `gemini::translate_ai_request_with_options` and `translate_ai_response`, never serialize `AiMessage.thought` into outbound `Part`s; preserve `thought_signature` on `AiResponse` (when `tool_calls` is empty) or `ToolCall` and re-attach to outbound `model` parts. On `Part::FunctionCall`, unconditionally `take()` `last_thought_signature` before checking the call's own signature so an earlier signature never leaks to a later `FunctionCall`. In `#[serde(untagged)]` `gemini::Part`, `Text` and `FunctionCall` must precede `ThoughtSignature`, whose `thought_signature: String` must stay required. [F3, F4, F111]
- In `gemini::translate_ai_request_with_options` and `bedrock::translate_request`, consecutive `AiRole::Tool` (and in Gemini, `AiRole::User`) messages must be coalesced into a single `user` turn. `BedrockClient` and `OpenAiCompatClient` cache temperature rejection in `temperature_unsupported: AtomicBool`: when `rejects_temperature_parameter` matches, set it `true`, retry with `temperature = None`, and strip `temperature` thereafter (and when `thinking` is enabled in `bedrock::translate_request`). [F19, F20]
- `SessionRunner::run` seeds `history` (`initial_user_prompt()` for `AiRequest`) and `log_history` (`log_user_prompt()` for `SessionResult`/`SessionFailure`), appending every subsequent message to both. Retries on `Transient`/`RateLimit`, `ErrorAction::RetryWithFeedback`, or `ValidationError::FormatViolation` must decrement `turns` (`saturating_sub(1)`) under `max_transient_retries`, `max_provider_error_retries`, and `max_validation_attempts`. On `turns == self.max_turns`, set `request.tools = None` (appending `TURN BUDGET EXHAUSTED` if `turns > 1`), ignore any emitted `tool_calls`, and run `session.validate(&resp)`. [F6, F9, F99]
- `CachingAiProvider::compute_cache_key` must strip `context_tag`, scrub `thought_signature`/`thoughtSignature` via `scrub_thought_signatures`, and hash `inner.cache_identity()` + `\0` + canonical request JSON. `create_provider_cached` bypasses `CachingAiProvider` for `stdio-` providers, while `StdioGeminiClient::forget` and `StdioClaudeClient::forget` forward evictions via `ipc_forget`. [F10, F144]
- `cli_common::build_prompt` must pass all system, message, tool-call, and tool-result fields through `escape_frames` (escaping `<tag`/`</tag` only for `FRAME_TAGS` followed by `>`, space, tab, `\n`, or `\r`). `parse_inner_response` and `parse_single_json` must call `assign_unique_ids` once across the merged batch of `ToolCall`s (not per JSONL line), keeping first-seen non-empty IDs and assigning the lowest unused `c{N}` to empty/duplicate IDs. [F5, F114]
- `cli_common::extract_json` scans only line-starting triple-backtick fences (`find_fence_opener`) with single-word tags, using `tag.get(..4)` (never `&tag[..4]`) to check `"json"`, returning the first fenced JSON object/array, or falling back to the first `json` block, `{`/`[` untagged block, or `normalized.trim()`. [F104, F119]
- Diagnostics in `AcpProcess` (`record_stderr_line`/`trim_stderr_preview`) and `cli_common::idle` must cap stderr/stdout at 4096 bytes (`STDERR_PREVIEW_LIMIT`/`TAIL`) and call `redact_secret`. Byte cuts in `trim_stderr_preview` and `Truncator::head_of` must align to UTF-8 boundaries via `char_indices()`/`utf8_prefix`. [F97, F103]
- `TokenBudget::approximate_tokens` uses `text.len().div_ceil(3)` (`BYTES_PER_TOKEN = 3`). `Truncator::truncate_diff` and `truncate_sequential` reserve notice bytes and fall back to `head_of` if 0 lines fit or output exceeds `max_tokens`. `VllmClient::generate_content` reserves generation tokens (`max_tokens` or `context_window_size / 4`), scales remaining budget by `9 / 10`, and truncates smallest-message-first via `fit_messages_to_budget`. [F89, F90, F91]
- `BugVector::cosine_similarity` computes a plain dot product, relying on `extract_bug_vector` L2-normalizing weights (`weight / l2_norm`). `find_top_candidates` filters by `sim >= threshold`, sorts descending, and truncates to `top_n`. [F22, F98]

## Synchronization
- `StdioGeminiClient` and `StdioClaudeClient` `generate_content` must `ipc_registry().register(tx_id, tx).await?` before `ipc_writer().write_line(&line).await?` (`ipc_forget` sends one-way `ai_forget` without `tx_id`). `IPC_REGISTRY`, `IPC_WRITER`, and `IPC_READER` are process-wide singletons; `ensure_stdin_reader` checks `JoinHandle::is_finished()` under `IPC_READER` to respawn stopped readers unless `registry.is_closed()`. Unregistered/duplicate `tx_id` or bad stdin JSON calls `std::process::exit(1)`. [F24, F25, F75, F133]
- `IpcRegistry::abort_all` locks `pending`, sets `closed = true`, and drains senders with `AiErrorClass::Fatal`; `IpcRegistry::register` must check `closed` while holding `pending.lock().await`. [F59]
- `QuotaManager::report_quota_error` caps `retry_after` at `MAX_RETRY_AFTER` (5m) and advances `blocked_until` only if `now + retry_after > current`; `report_success` clears it. `wait_for_access` must drop `blocked_until.lock()` before `tokio::time::sleep` and re-check in a loop, `DeadlineBudget` must never hold its `std::sync::Mutex` across `.await`, and `GeminiClient::post_request` must clone `Client` and drop `self.client.read().await` before `send().await` or `read_generate_content_response`, calling `refresh_client` (`write().await`) on both `send()` errors and `TransientError` while reading a 2xx body. [F14, F26, F31, F47, F107]
- `BackoffProvider` wraps outside `ConcurrencyLimitedProvider` so sleeping retries hold no permits. It reports `RateLimit` to `QuotaManager`, credits `wait_for_access` sleeps via `RetryBudget::credit_wait`, checks `RetryBudget::check` before each attempt, caps attempts at `MAX_ATTEMPTS` (6) when `budget` is `None`, and sleeps locally on `Transient` (capped at `60.0`s + jitter) without touching `QuotaManager`. `DeadlineBudget::credit_wait` tracks `last_credit_end` and only credits non-overlapping `now - max(sleep_start, last_credit_end) >= 1ms`. [F15, F28, F94]
- `write_prompt_and_wait` must drain `stdout`/`stderr` concurrently with writing `stdin` (dropping `stdin` when done) and drop rather than await the `write` future if `drain` finishes first. [F38]

## Object Lifetimes
- Children in `write_prompt_and_wait` must be spawned via `spawn_cli` (`process_group(0)`), calling `GroupGuard::disarm` right after `child.wait()` succeeds so reaped PIDs are never `SIGKILL`ed. `kill_and_reap` must call both `group.kill()` and `child.start_kill()` before `child.wait().await`. Lock `LIVE_GROUPS` via `unwrap_or_else(|e| e.into_inner())`, and call `kill_live_groups()` before any `std::process::exit`. [F16, F37, F39, F102]
- `GeminiClient::start_proxy_command` must wrap the proxy `Child` and `port_file` in `ProxyGuard` before polling readiness, and `effective_base_url` must store `Arc<ProxyGuard>` in `self.proxy_guard`. [F42]
- Keep per-call temp dirs/files (`ClaudeCliProvider` `working_directory`, `GooseCliProvider` `IsolatedHome`, `KiroCliProvider` `isolated_workspace`, and `DevinCliProvider` `prompt_file` written via `spawn_blocking`) alive until the child exits or is killed. `AcpProcess::run_prompt` must set `kill_on_drop(true)`, drain `stderr` into `StderrPreview`, and drop `stdin` before `child.kill().await`. [F43, F44, F108]

## API Contracts
- `SessionRunner::run` calls `provider.forget(request)` for `rejected` (and `sent` if `resp.truncated`) only when giving up on truncation or `max_validation_attempts`, never on tool turns or when a later attempt succeeds. Every `Err` from `SessionRunner::run` must carry `SessionFailure` (with `log_history` and accumulated `AiUsage`). [F7, F67]
- Providers must include all output-shaping config (`max_tokens`, `base_url`, `thinking`, `effort`, `num_ctx`, `guided_json`, `enable_tools`, `agent`, and `GooseCliProvider::env` via `digest_env`) in `cache_identity_with`. Because `BackoffProvider`, `ConcurrencyLimitedProvider`, and `LoggingProvider` do not override `cache_identity()`, `CachingAiProvider` must wrap the concrete provider inside them. [F64, F141, F142]
- `llm_permits` returns `1` when `concurrency < 2` and `concurrency * 3` otherwise. `create_provider_cached` and `create_provider_from_ai` must keep `"bedrock"`, `"vertex"`, and `ai.response_cache` arms compiled in all profiles with `#[cfg(not(feature = ...))]` `bail!` fallbacks. [F96, F145]

## Error Handling
- `classify_ai_error` downcasts `&anyhow::Error` to registered `ClassifyAiError` types (`RemoteAiError`, `OpenAiCompatError`, `ClaudeError`, `ClaudeCliError`, `GeminiError`, `ReviewError`, `OllamaError`, `VllmError`), defaulting to `Fatal`. `gemini`/`claude` `transport_error` checks `is_permanent_transport_error` (`is_builder() || is_redirect()`) first to return untyped `Fatal` errors. On non-2xx, `read_generate_content_response` extracts `RETRY_AFTER` first and uses `res.text().await.unwrap_or_else(...)` so body read failures do not mask HTTP status in `classify_generate_content_failure`. [F46, F48, F68]
- `LlmSession::call_tools` catches `Err(e)` from `call_tool` and returns `Ok` with `{"error": e.to_string()}`, since `Err` from `call_tools` aborts `SessionRunner::run`. [F54]
- In `write_prompt_and_wait`, stdin `BrokenPipe` (or `drain` finishing before `write`) returns `Ok(output)` only if `!output.status.success()`, and `Err(CliIoError::Write(e))` if status is 0. Even on exit 0, `CodexCliProvider::generate_content` checks all JSON events via `check_error_message`, failing if `self.effort.is_some()` and `is_effort_substitution` matches while logging `is_approval_policy_substitution` at `debug!`. [F55, F57]

## External Contracts
- `OpenAiCompatClient` and `VllmClient` `normalize_base_url` require `scheme://host` and only allow paths ending in `"/chat/completions"` or matching `""`, `"/v1"`, `"/v1/chat/completions"` (plus `"/api/v1"`/`"/api/v1/chat/completions"` for OpenAI). `default_base_url_for_model` and `default_context_window_for_model` must match vendor prefixes (`"abab7-"`, `"MiniMax-"`, `"glm-"`, `"moonshot-"`) identically. `translate_ollama_request` maps `AiResponseFormat::Json` to top-level `OllamaRequest.format` (not `OllamaOptions`). [F78, F79, F80]
- Gemini/Vertex resolve unconfigured `max_tokens` via `default_gemini_max_tokens_for_model` and filter out `0` (`max_output_tokens.filter(|&n| n > 0)`). `GeminiClient` checks `GOOGLE_GEMINI_BASE_URL`/`GEMINI_BASE_URL` before settings, reads `GEMINI_API_KEY`/`LLM_API_KEY`, and sends `x-goog-api-key` headers (never `?key=`). `finishReason == "CONTINUATION"` loops cap at `MAX_CONTINUATION_HOPS` (16) and `next_continuation_token` stops if `block_reason` is set or token is empty/unchanged. [F81, F82, F84]
- CLI isolation: `ClaudeCliProvider` (`build_claude_args`) runs in `tempdir()` disabling tools/MCPs/hooks/memory/commands/`CLAUDE.md`; `CopilotCliProvider` (`build_copilot_args`) passes `--deny-tool=shell,write,read`, `--disable-builtin-mcps`, `--no-custom-instructions` with stdin prompt; `GooseCliProvider` uses `IsolatedHome` (`CONFIG_YAML`) with `build_env` setting `XDG_*`/`GOOSE_*` after `extra` env; `KiroCliProvider` (`agent: None`) runs in `create_isolated_workspace()` (`AGENT_JSON`, `DENY_ALL_HOOK`). [F115, F116, F117, F118]

## Known Pitfalls
- `response_cache_path` must reject `database` strings containing `"://"` (falling back to `data_home.join("sashiko").join("response_cache.db")`) and filter out empty `.parent()` paths (`.filter(|dir| !dir.as_os_str().is_empty()).unwrap_or(Path::new("."))`) before joining `"response_cache.db"`. [F77, F139]
