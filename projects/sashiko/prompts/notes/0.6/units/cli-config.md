# cli-config

This unit provides the top-level binaries (`sashiko` in `src/main.rs` and `sashiko-cli` in `src/bin/sashiko-cli.rs`), prompt bundling (`build.rs`, `src/prompt_bundle.rs`, `src/prompt_fingerprint.rs`, `src/prompt_namespaces.rs`), and central configuration (`src/settings.rs`), project identity (`src/project.rs`), event-tracking (`src/events.rs`), compression (`src/compression.rs`), metrics, and utility modules across local CLI and daemon pipelines.

## Architecture & Data Flow
- `effective_project` returns `Err` if CLI/env `--project` and `settings.project.kind` are both `Some` and differ. `run_daemon` writes back `settings.project.kind = Some(project)`, updates `settings.review.email_policy_path` to `project.mailing_lists_path()` if it still holds a default Linux/legacy path, and in `handle_review_command` unconditionally overwrites `settings.git.repository_path` with `current_git_toplevel()`. [F6, F7, F8]
- `run_daemon` runs `db.migrate()`, `db.ensure_project_stamp(project)`, `db.fail_interrupted_fetching_patchsets()`, `init_global_maintainers`, and `backfill_patchset_maintainer_sections(&db)` in order before starting `FetchAgent`, parsers, `db_worker_handle`, or workers. [F135]
- For single-patch submissions (`total == 1`), `Event::PatchSubmitted` sets `in_reply_to = None` (else `Some(format!("{}@sashiko.local", article_id))`), and `process_parsed_article` sets `cover_letter_id` on `api-submit` and `git-import` to `Some(metadata.message_id.clone())` (else `Some(root_msg_id.clone())`). [F15]
- In `process_parsed_article`, omitting `metadata.body` (`body_to_store = ""`) with `git_hash_opt = Some(article_id.as_str())` is only allowed when `article_id` is a 40-char hex SHA and `group.starts_with("git-import")` (not `git-fetch`). For `git-import:<count>:<range>`, `<count>` is parsed as `git_import_total` and passed as `total_parts` to `create_patchset` (when `> 0`) with `strict_author = false`. [F16, F17]
- `process_parsed_article` calls `ensure_thread_for_message` before `create_message_with_references` and `create_patchset`, and for multi-part NNTP patches only uses `metadata.in_reply_to` as `cover_letter_id` if `message_is_cover_letter_for` is true. If `EmailRouter::is_ignored_author` is true, it sets `metadata.is_patch_or_cover = false` and `patch_opt = None` before message creation so the message is stored without creating/updating a patchset. [F124, F127]
- In `process_parsed_article`, `create_patch_with_git_patch_id` and subsystem/maintainer attribution only run when `create_patchset` returns `Ok(Some(patchset_id))` (returning `ProcessStatus::Ingested` on `Ok(None)`). `subsystem_ids` (`identify_subsystems` + `SubsystemMapping`) and `maintainer_sections` (`sections_for_diff`) must stay separate via `add_subsystem_to_patchset` and `add_patchset_maintainer_sections` because only `maintainer_sections` govern transcript access. `calculate_embargo_hours` takes the minimum `embargo_hours` across matched policies (preferring `subject_prefixes` over unprefixed, then `defaults.embargo_hours`), stored via `set_patchset_embargo_until_if_non_terminal`. [F18, F19, F126]
- Every `ProjectId` must be in `ProjectId::ALL` and have a `(project.as_str(), project.prompt_dir())` entry in `PROJECT_PROMPT_NAMESPACES` (`Linux` is `("linux", "kernel")`), with `"kernel/severity.md"` and `"sashiko/severity.md"` always bundled for `kernel_severity_guide`/`sashiko_severity_guide`. `install_prompt_bundle` skips extraction when `.sashiko-prompts-complete` exists unless `force` is true, so `PROMPT_BUNDLE_REVISION` hashes every file's path and bytes via `content_fingerprint`, `build.rs` panics on duplicate paths, and `collect_files` skips `.git` and `*.facts.json`. [F89, F93, F100, F106]
- `paint_progress` only reserves a scroll region when `state.reservation_capable` and `worth_reserving(state.patches.len() + 1, state.terminal_rows)` (`wanted * 4 <= rows * 3`) hold, calling `release_progress_region(..., RegionExit::Erased)` before `paint_progress_plain` if `state.reserved > 0` when that bound fails. `release_progress_region(..., RegionExit::Kept)` sets `state.finished = true` and `state.reserved = 0`; both `paint_progress` (when `finished`) and `release_progress_region(..., RegionExit::Kept)` (when `reserved == 0`) must emit nothing because `\x1b[r` homes the cursor. [F20, F80]
- In `status_label`, when `with_turns` is `false` (`paint_progress_plain`), `active_stages` uses `BTreeSet` order without turn counts to avoid duplicate status lines. `patch_stage_total` returns `p.completed_stages` when `p.status` is `Finished` or `Failed`, else `p.preliminary_stages + planned` (`default_stage_count(project)` when `planned_stages` is empty). [F22, F23]
- In `handle_local` (`src/bin/sashiko-cli.rs`), worker stderr lines prefixed with `PROGRESS_LINE_PREFIX` containing `" turn "` must `continue` before `tail.push_back(line)` (`STDERR_TAIL_LINES` = 100). In `is_mbox_separator`, the `len < 30` guard (after stripping `\r`/`\n`) and `len >= 31` check before `line[len - 25]` must precede suffix byte-index checks. [F82, F91]

## Synchronization
- `run_daemon` bounds ingestion with `mpsc::channel(1000)` (`raw_tx`, `parsed_tx`) and `Semaphore::new(50)`, running `parse_email` on `spawn_blocking` under the permit. The DB worker drains up to 100 items via `parsed_rx.recv_many(&mut buffer, 100).await` and computes git patch IDs once per batch via `calculate_git_patch_id_batch` before `process_parsed_article`. [F84, F85]
- `IngestTracker::wait_until_quiet` must create `self.inner.settled.notified()` before locking `self.inner.state` to check `in_flight == 0` and drop the guard before `quiet.await`. Callers of `take_safe_mark` must ensure no receipts remain in flight (awaiting `wait_until_quiet`) because `take_safe_mark` clears `lowest_lost` without checking `in_flight`. [F28, F95]
- `run_daemon` must call `ensure_gc_disabled(&repo_path)` before spawning `write_commit_graph` (in a background `tokio::spawn` task, never awaited inline), `GitSyncWorker`, and `RepackWorker`. When supervising `Ingestor` with `cli.track`, the factory closure must consume `cli.download` via `first_run.swap(false, Ordering::Relaxed)` so restarts pass `None`. [F36, F86, F119]
- `compress_string_async` offloads gzip compression for `input.len() >= BLOCKING_COMPRESSION_THRESHOLD_BYTES` (64 KiB) to `spawn_blocking`, falling back to `compress_string_if_needed` on join error. [F94]
- `watch_for_resize` must re-check `window_size(&stream)` under the `ProgressState` mutex after registering `signal(SignalKind::window_change())`. `on_stderr` buffers each progress frame in a `termcolor::Buffer` and emits it in one `stderr.print(&frame)` call. `release_region_on_panic` writes `\x1b7\x1b[r\x1b8\n` directly to `std::io::stderr()` without locking `ProgressState`. [F30, F33, F34]

## Object Lifetimes
- Before `std::process::exit` on daemon shutdown (`run_daemon`) or interrupt (`exit_on_interrupt`), `sashiko` must call `sashiko::ai::cli_common::kill_live_groups()`, and `run_daemon` must remove `local_token_path`. [F40, F121]
- `handle_review_command` must both `resize.abort()` and `let _ = resize.await;` on the `watch_for_resize` handle before the final `finish_progress`. [F42]
- When `handle_local` spawns `sashiko worker` via `find_worker_command`, it must pass `--baseline`, `--repo` (`repo_path`), and `--project` (`project().as_str()`), set `SASHIKO_LOG_PLAIN=1` and `.kill_on_drop(true)`, drop `child.stdin` right after writing `ReviewInput` JSON, and drain `child.stderr` concurrently before `child.wait_with_output()`. [F45, F115]
- `spawn_supervised_worker_with_backoff` holds `AbortOnDrop(handle.abort_handle())` across `handle.await`, restarts after `backoff` on `Ok(())` or panic (`!join_err.is_cancelled()`), and exits immediately when `join_err.is_cancelled()`. [F59]
- `Settings::validate_for_daemon` rejects an empty `review.worktree_dir`, and `run_daemon` runs `cleanup_worktree_dir` and `prune_worktrees` before starting `Reviewer`. [F118]

## API Contracts
- `Settings` and all nested settings structs use `#[serde(deny_unknown_fields)]`; daemon-only fields (`database.url`, `git.repository_path`, `review.worktree_dir`) are required only by `validate_for_daemon`. Without `feature = "server"`, `src/lib.rs` gates out server-only modules while `src/main.rs` keeps full `Cli`/`Commands` definitions and errors at runtime on `Commands::Benchmark` or daemon mode. [F9, F138]
- `Settings::apply_overrides` returns startup log strings only for `no_ai`, `read_only`, `port`, and `stages` in that exact order, applying `repository_path`, `worktree_dir`, `ai_provider`, `ai_model`, and `effort` silently. [F76]
- When `Settings::smtp` is `Some`, `validate_sign_in_delivery` requires `server.public_base_url` to pass `is_reachable_base_url` (`http`/`https`, non-empty host not in `::`, `0.0.0.0`, `*`, `localhost`, `127.0.0.1`, `::1`), and `mailed_link_base_url` never falls back to `host:port`. `SmtpSettings::validate` requires `server` and `port` for `MailTransport::Smtp`, rejects `username`/`password` for `Sendmail`, and `sendmail_command` defaults to `DEFAULT_SENDMAIL_PATH` (`/usr/sbin/sendmail`). [F11, F68]
- `AclSettings::has_permission` and `is_known_identity` trim and match emails ASCII case-insensitively (`list_contains`) and check `is_blocklisted` before any grant (including `admins`). `security` and `bug_reporters` allow sign-in via `is_known_identity` without granting `Permission::Ingest`, `Cancel`, or `Review`, and `Permission::granted_by_local_token` never covers bug-database access. [F66, F132]
- `Settings::local_token_path` puts `.sashiko-local-token` in the parent of `database.url` (or `.` if it has `"://"` or no parent). In `build_client` (`sashiko-cli`), when `explicit_token` is `Some(raw)`, `.sashiko-local-token` is never read, empty trimmed `raw` yields an unauthenticated `Client`, and invalid header chars return `Err`; when `None`, `Settings::new()` or `LocalToken::read_from()` errors are ignored. [F60, F134]
- `ForgePostMode::outbox_status(embargoed)` maps `Off` -> `"Disabled"`, `DryRun` -> `"Dry-Run"`, and `Live` -> `"Embargoed"` (if `embargoed`) or `"Pending"`. `should_start_nntp_ingestor` disables NNTP when `settings.forge.enabled && settings.forge.disable_nntp` (`disable_nntp` defaults to `true`). [F128]
- `process_recipients` and `identify_subsystems` must unpack `To`/`Cc` with `sashiko::patch::split_address_list`, not `str::split(',')`. `clean_json_string` (`src/utils.rs`) escapes literal `\n`, `\r`, `\t`, and `< '\x20'` (`\u{:04x}`) only when `in_string && !escape`, flushing a trailing `'\\'` if input ends with `escape == true`. [F62, F110]

## Error Handling
- In `main`, `Settings::load` is called once into `settings_result`: `Init`, `Notes`, and `Repo` tolerate `Err`, whereas `Review`, `Worker`, `Benchmark`, and `run_daemon` fail on `Err`. In `run_daemon`, `validate_for_daemon`, `check_daemon_tree`, `validate_sign_in_delivery`, and `check_sendmail_path` are fatal before `Database::new`, while `publish_local_token`, `backfill_patchset_maintainer_sections`, and `add_patchset_maintainer_sections` failures only log and continue. [F49, F53, F55]
- On `Event::ArticleFetched`, `IngestReceipt::settle()` is called on `ProcessStatus::Ingested` and deterministic rejection (before `cutoff_timestamp`, `parse_email` error, or parser panic), but dropped unsettled on transient error (`ProcessStatus::Error` or closed channel). In `process_parsed_article`, `ParsedArticle.failed_error` records the error via `update_patchset_error` and returns `ProcessStatus::Ingested`, whereas fatal DB errors call `fail_fetching_patchset_logged` on `root_msg_id` (and distinct `in_reply_to`/`cover_letter_id`) before returning `ProcessStatus::Error`. [F47, F48]
- `project_prompts_path` checks `path.is_dir()` on `root.join(project.prompt_dir())` and returns `Err` if missing. `IgnoreBrokenPipeWriter` swallows `io::ErrorKind::BrokenPipe` on `write`/`flush` and propagates all other `io::Error`s. [F56, F57]

## External Contracts
- `compress_string_if_needed` stores strings `<= COMPRESSION_THRESHOLD_BYTES` (1024) as `Value::Text` and longer ones as gzip `Value::Blob` (`GZIP_MAGIC`). Decompression helpers fall back to UTF-8 if `Value::Blob` lacks `GZIP_MAGIC`; `get_compressed_string` and `decompress_string_value` map `Value::Null` to `Ok(String::new())`, while `get_compressed_string_opt` returns `Ok(None)`. [F25, F130]
- `ReviewStatus` uses spaces for `"In Review"` and `"Failed To Apply"`, whereas `sashiko-cli` also checks `"Embargoed"` and `"Error"` (not `ReviewStatus` variants). `sashiko worker` always writes JSON to stdout (`exit_worker_with_error` prints `{"patchset_id": 0, "error": ...}` and exits `1`), while `handle_review_command` and `sashiko-cli` `handle_local` exit `3` on review error and `1` on new high/critical findings. [F72, F105]
- `prepare_mbox_payload` parses non-UTF-8 mbox messages via `parse_email` and returns `Err` if `meta.is_patch_or_cover` is true (or `parse_email` fails), decoding non-patch replies with `from_utf8_lossy`; `Event::RawMboxSubmitted` drops mboxes over 100 messages. [F61, F74]
- `GeminiSettings::max_tokens` and `VertexSettings::max_tokens` are `Option<u32>` defaulting via `default_gemini_max_tokens_for_model(model)` (`131_072` only when `model_supports_effort(model)` is true, else `0`). List fields in `MailingListsSettings` and `AclSettings` must use `deserialize_string_or_vec`. [F63, F65]

## Known Pitfalls
- Use `settings.effective_effort()` rather than `settings.review.effective_effort(&settings.ai.model)`: when `review.effort` is `None`, `Settings::effective_effort` checks provider thinking settings (`ai.vertex` when `ai.provider == "vertex"`, else `ai.gemini`) for `"low"` (`EffortMode::Low`) before `EffortMode::Mid`. `AiSettings` gates `bedrock` and `vertex` behind `#[cfg(feature = ...)]` with `#[serde(deny_unknown_fields)]`, so uncommented `[ai.bedrock]`/`[ai.vertex]` tables fail to load when built without those features. [F112, F137]
- In `release_progress_region` with `RegionExit::Erased`, clearing reserved rows (`\x1b[2K`) must be gated on `state.region_rows == state.terminal_rows` (`held = 0` on mismatch). Byte-bounded truncation must use `utf8_prefix(input, max_bytes)` instead of `&input[..max_bytes]`. Test scripts must be created via `write_executable_script` (`install -m 755` from `.source`) to avoid `ETXTBSY` on concurrent `fork`. [F46, F78, F81]

## Other
- `build.rs` includes `src/prompt_namespaces.rs` via `include!("src/prompt_namespaces.rs")`, so it must contain only plain items with no `//!` comments or `crate::` paths. [F99]
